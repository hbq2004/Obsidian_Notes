Q: MAR、MDR 与主存容量之间有什么关系？  
A: MAR（Memory Address Register，存储器地址寄存器）用于保存要访问的存储单元地址，MAR 的位数决定可寻址存储单元的数量；若 MAR 为 \(n\) 位，则最多可寻址 \(2^n\) 个存储单元。MDR（Memory Data Register，存储器数据寄存器）用于暂存 CPU 与主存之间交换的数据，MDR 的位数通常反映每个存储单元一次可读写的数据位数；若 MDR 为 \(m\) 位，则每个存储单元大小为 \(m\text{ bit}\)。因此主存容量为 \(\text{存储容量}=2^n\times m\text{ bit}\)。可记为：MAR 决定“有多少个存储单元”，MDR 决定“每个存储单元有多大”。

Q: 什么是时钟周期和主频？二者有什么关系？  
A: 时钟周期 \(T\) 是 CPU 中最基本的时间单位，CPU 的操作通常至少需要一个或若干个时钟周期；主频（时钟频率）\(f\) 表示 CPU 每秒产生的时钟周期数，单位为 Hz。二者互为倒数：\(f=\frac{1}{T}\)，\(T=\frac{1}{f}\)。主频越高表示单位时间内时钟周期越多，时钟周期越短。例如 \(1\text{ GHz}=10^9\text{ Hz}\)，对应时钟周期为 \(1\text{ ns}=10^{-9}\text{ s}\)。

Q: 什么是 CPI？如何计算程序的平均 CPI 和总时钟周期数？  
A: CPI（Cycles Per Instruction）表示执行一条指令平均需要的时钟周期数，因此 \(CPI=\frac{\text{总时钟周期数}}{\text{指令条数}}\)。若程序共执行 \(IC\) 条指令，则 \(\text{总时钟周期数}=IC\times CPI\)。若程序含多类指令，第 \(i\) 类指令条数为 \(IC_i\)，其 CPI 为 \(CPI_i\)，则 \(\text{总时钟周期数}=\sum_i IC_iCPI_i\)，总指令数为 \(IC=\sum_i IC_i\)，平均 CPI 为 \(CPI_{\text{avg}}=\frac{\sum_i IC_iCPI_i}{\sum_i IC_i}\)，即按照各类指令出现比例对 CPI 进行加权平均。

Q: CPU 执行时间的核心公式是什么？应如何理解？  
A: 若程序执行的指令条数为 \(IC\)，平均 CPI 为 \(CPI\)，时钟周期为 \(T\)，则 CPU 执行时间为 \(T_{\text{CPU}}=IC\times CPI\times T\)。由于 \(T=\frac{1}{f}\)，也可写成 \(T_{\text{CPU}}=\frac{IC\times CPI}{f}\)。其本质是“总时间 = 指令条数 × 每条指令平均所需周期数 × 每个周期所需时间”。因此程序性能同时受到指令条数、CPI 和主频影响，不能只根据其中一个指标判断计算机性能。

Q: 什么是 IPS 和 MIPS？它们与主频、CPI 有什么关系？  
A: IPS（Instructions Per Second）表示每秒执行的指令条数。由于 CPU 每秒有 \(f\) 个时钟周期，而平均每条指令需要 \(CPI\) 个周期，因此 \(IPS=\frac{f}{CPI}\)。MIPS（Million Instructions Per Second）表示每秒执行多少百万条指令，因此 \(MIPS=\frac{IPS}{10^6}=\frac{f}{CPI\times10^6}\)。IPS 或 MIPS 越大通常表示指令执行速率越高，但不同计算机的指令系统和指令功能可能不同，因此不能单独依靠 MIPS 公平比较不同体系结构的性能。

Q: 什么是 FLOPS？它与 IPS 有什么区别？  
A: FLOPS（Floating-point Operations Per Second）表示每秒完成的浮点运算次数，主要用于衡量浮点计算能力；IPS 表示每秒执行的机器指令条数。一次机器指令可能完成零次、一次或多次浮点运算，因此 \(FLOPS\neq IPS\)。常见单位有 \(1\text{ KFLOPS}=10^3\text{ FLOPS}\)、\(1\text{ MFLOPS}=10^6\text{ FLOPS}\)、\(1\text{ GFLOPS}=10^9\text{ FLOPS}\)、\(1\text{ TFLOPS}=10^{12}\text{ FLOPS}\)。

Q: 吞吐量和响应时间分别衡量计算机系统的什么性能？  
A: 吞吐量（Throughput）表示系统单位时间内完成的任务数量，可表示为 \(\text{吞吐量}=\frac{\text{完成任务数}}{\text{时间}}\)，通常越大越好；响应时间（Response Time）表示从任务提交到任务完成所经历的时间，通常越小越好。二者关注角度不同：响应时间关注“一个任务多久完成”，吞吐量关注“单位时间能完成多少任务”，提高吞吐量不一定意味着单个任务的响应时间一定缩短。

Q: 什么是数据通路宽度和基准程序？  
A: 数据通路宽度是 CPU 内部或 CPU 与其他部件之间一次能够并行传输的数据位数，如 32 bit、64 bit，它会影响一次数据传输或运算能够处理的数据规模，但不能简单认为某个“64 位计算机”的所有部件宽度都一定为 64 位。基准程序（Benchmark）是用于评价计算机性能的一组具有代表性的程序，通过在不同计算机上运行相同基准程序并比较执行时间等指标，可以比单独比较主频、CPI、IPS 等参数更综合地反映实际性能。

Q: 408 计组中存储容量单位与频率、速率单位如何换算？  
A: 描述存储容量、文件大小时通常采用二进制数量级：\(K=2^{10}\)、\(M=2^{20}\)、\(G=2^{30}\)、\(T=2^{40}\)，且 \(1\text{ B}=8\text{ bit}\)，因此 \(1\text{ KB}=2^{10}\text{ B}\)、\(1\text{ MB}=2^{20}\text{ B}\)、\(1\text{ GB}=2^{30}\text{ B}\)、\(1\text{ TB}=2^{40}\text{ B}\)。描述频率、传输速率和性能指标时通常采用十进制数量级：\(k=10^3\)、\(M=10^6\)、\(G=10^9\)、\(T=10^{12}\)，例如 \(1\text{ GHz}=10^9\text{ Hz}\)。可记忆为“容量常用 \(2\) 的幂，频率和速率常用 \(10\) 的幂”。

Q: 计组性能计算中常见的时间单位如何换算？  
A: 常见时间单位为 \(1\text{ ms}=10^{-3}\text{ s}\)、\(1\text{ }\mu\text{s}=10^{-6}\text{ s}\)、\(1\text{ ns}=10^{-9}\text{ s}\)、\(1\text{ ps}=10^{-12}\text{ s}\)。频率与周期互为倒数，因此常见对应关系为 \(1\text{ kHz}\leftrightarrow1\text{ ms}\)、\(1\text{ MHz}\leftrightarrow1\text{ }\mu\text{s}\)、\(1\text{ GHz}\leftrightarrow1\text{ ns}\)，但只有频率恰为对应的 \(1\) 倍数量级时周期才恰好等于上述数值，例如 \(2\text{ GHz}\) 对应的时钟周期为 \(0.5\text{ ns}\)。

Q: 比较计算机性能时，主频、CPI、CPU 执行时间等指标应如何判断？  
A: 时钟周期 \(T\)、CPI、CPU 执行时间和响应时间通常越小越好；主频 \(f\)、IPS、FLOPS 和吞吐量通常越大越好。但单独比较主频、CPI 或 IPS 往往不能确定两台计算机执行同一程序时谁更快，因为 CPU 执行时间由 \(T_{\text{CPU}}=\frac{IC\times CPI}{f}\) 共同决定。对于同一任务，评价性能最直接的指标通常是执行时间，执行时间越短，性能越高。

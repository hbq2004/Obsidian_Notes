# 错题打卡与筛选

> 做题后点按钮打卡（对/错/半对/蒙对），结果写入笔记 frontmatter；
> 「只看错题」一键筛出全部错题，可按学科 / 书 / 知识点收窄，可导出 PDF 打印成卷。

```dataviewjs
dv.view("_Scripts/wrong-question-filter")
```

---

## 使用说明

- **打卡**：每道题一行四个按钮 —— `✅ 对` / `❌ 错` / `🟡 半对` / `🎲 蒙对`，点击即写入该题笔记的 frontmatter：
  - `status`：当前状态（wrong / half / guessed / correct）
  - `wrong_count`：累计做错次数（错/半对/蒙对各 +1）
  - `result_history`：最近 30 次结果时间线
  - `last_reviewed`：最近打卡时间
- **只看错题**：默认显示 `status ∈ {错/半对/蒙对}` 的题；未打卡的老题若评级 ≤1 级或已降级，也会作为「候选错题」被纳入（可取消勾选「含低级/降级」）。
- **筛选**：学科（高数/线代/概率/DS/CO/OS/CN）、书（27_900、27_方浩概统500题…）、知识点关键词（Enter 确认）。
- **导出**：`📑 导出带目录 PDF` 把当前筛选结果打印成一页一题的试卷，适合错题二刷。
- **与评级的关系**：本视图的打卡记录单次做题结果；掌握程度（0~5 级评级、复习排期）仍由 question-recommender / daily-review 负责，两边互不干扰。

## 数据字段速查

| 字段 | 含义 | 取值 |
|---|---|---|
| `status` | 最近一次打卡结果 | `wrong` / `half` / `guessed` / `correct`（清除=删除字段） |
| `wrong_count` | 累计做错次数 | 数字，错类结果 +1 |
| `result_history` | 打卡时间线 | `YYYY-MM-DD HH:mm:ss \| 结果（旧→新）`，保留 30 条 |
| `last_reviewed` | 最近打卡时间 | 日期时间 |

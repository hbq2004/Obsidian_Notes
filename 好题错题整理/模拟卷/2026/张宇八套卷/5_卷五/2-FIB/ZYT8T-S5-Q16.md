# FIB 第 16 题

![[_Attachments/题目识别/ZYT8T/ZYT8T-S5-Q16_题目.png|题目]]

16.设随机变量 $X \sim N(0,\sigma^2)$，$\sigma > 0$，使得 $P\{e^2 < X < e\}$ 最大的 $\sigma^2 =$ \_.

![[_Attachments/题目识别/ZYT8T-答案/ZYT8T-S5-Q16_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**

设 $X\sim N(0,\sigma^2)$，则 $\frac{X}{\sigma}\sim N(0,1)$。题面按 $P(e < X < e^2)$ 理解（原题 $e^2<X<e$ 显然为空集，系笔误）。

【答案】$$\boxed{\sigma^2 = \frac{e^4-e^2}{2} = \frac{e^2(e^2-1)}{2}}$$

**解题切入点**

本题是参数优化问题——求使概率最大的方差。与算法竞赛中“三分查找”处理单峰函数极值异曲同工，这里用解析求导。将概率化为标准正态分布函数之差，再令 $t=1/\sigma$ 简化计算。

**推演**

1. 标准化：$P(e<X<e^2)=P\left(\frac{e}{\sigma}<Z<\frac{e^2}{\sigma}\right)=\Phi\left(\frac{e^2}{\sigma}\right)-\Phi\left(\frac{e}{\sigma}\right)$，其中 $\Phi$ 为标准正态分布函数。
2. 令 $t=\frac{1}{\sigma}>0$，定义 $g(t)=\Phi(e^2 t)-\Phi(e t)$。
3. 求导：$g'(t)=e^2\varphi(e^2 t)-e\varphi(e t)$，其中 $\varphi(x)=\frac{1}{\sqrt{2\pi}}e^{-x^2/2}$。
4. 令 $g'(t)=0$：$e^2 e^{-(e^2 t)^2/2}=e e^{-(e t)^2/2}$（两边约去 $\frac{1}{\sqrt{2\pi}}$）。
5. 两边除以 $e$：$e e^{-e^4 t^2/2}=e^{-e^2 t^2/2}$。
6. 取对数：$1-\frac{e^4 t^2}{2}=-\frac{e^2 t^2}{2}$。
7. 解得 $t^2=\frac{2}{e^4-e^2}$。所以 $\sigma^2=\frac{1}{t^2}=\frac{e^4-e^2}{2}$。
8. 验证最大值：当 $t\to0^+$ 或 $t\to+\infty$ 时 $g(t)\to0$，且驻点唯一，故该驻点为最大值点。

**易错点**

- 忽略区间端点大小：原题 $e^2<X<e$ 为空集，必须纠正为 $e<X<e^2$，否则概率恒为0。
- 求导时漏掉 $\varphi$ 中的指数项，或对数运算符号错误。
- 忘记换元后 $\sigma=1/t$ 导致回代时取倒数。

**命题规律**

正态分布概率极大值问题，常通过标准化、换元、求导三步求解。类似题目还有 $P(|X|<a)$ 或 $P(a<X<b)$ 的最值。复习时应熟练掌握 $\Phi(x)$ 与 $\varphi(x)$ 的关系，以及含参积分的求导技巧。

题面按 $P(e<X<e^2)$ 理解（OCR 疑误，原题可能为 $e<X<e^2$，请核对原书）。

# 解答题 第 17 题

![[_Attachments/题目识别/LL6T/LL6T-S6-Q17_题目.png|题目]]

(本题满分 10 分) 设 $D_t = \{(x, y) \mid 0 \leqslant x \leqslant 2t, 0 \leqslant y \leqslant t, t > 0\}$, $f(x, y)$ 在 $D_t$ 上有二阶连续偏导数, 求
$$F(t) = \iint_{D_t} f''_{yx}(x, y) \mathrm{d}x\mathrm{d}y, \text{并计算} \lim_{t \to 0^+} \frac{F(t)}{t}.$$

![[_Attachments/题目识别/LL6T-答案/LL6T-S6-Q17_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**

$$F(t)=f(2t,t)-f(0,t)-f(2t,0)+f(0,0),\qquad \lim_{t\to 0^+}\frac{F(t)}{t}=0.$$

关键给分点：写出累次积分并用牛顿莱布尼茨公式得到 $F(t)$；用洛必达法则（或 $F(t)=2f_{xy}(0,0)t^2+o(t^2)$）求出极限为 $0$。

**解题切入点**

这是矩形区域上“混合偏导的二维差分/前缀和还原”：$\iint f''_{yx}$ 先积一次变成边界上的偏导差，再积一次变成四个角点值的交替和；求极限时再看小量阶数。

**推演**

1. 因 $f$ 有二阶连续偏导，混合偏导相等，可先对 $y$ 积分：
$$F(t)=\int_0^{2t}\int_0^t f''_{yx}(x,y)\,dy\,dx.$$

2. 对内层用牛顿莱布尼茨公式（混合偏导连续，故可按 $f_x$ 对 $y$ 的偏导处理）：
$$\int_0^t f''_{yx}(x,y)\,dy=f_x(x,t)-f_x(x,0).$$

3. 再对 $x$ 积分：
$$F(t)=\int_0^{2t}f_x(x,t)\,dx-\int_0^{2t}f_x(x,0)\,dx$$
$$=\left(f(2t,t)-f(0,t)\right)-\left(f(2t,0)-f(0,0)\right).$$

4. 求极限。令 $F(0)=0$，则 $F(t)/t$ 是 $0/0$ 型。对 $t>0$ 求导：
$$F'(t)=2f_x(2t,t)+f_y(2t,t)-f_y(0,t)-2f_x(2t,0).$$
由一阶偏导连续，
$$\lim_{t\to0^+}F'(t)=2f_x(0,0)+f_y(0,0)-f_y(0,0)-2f_x(0,0)=0.$$
所以
$$\lim_{t\to0^+}\frac{F(t)}t=\lim_{t\to0^+}F'(t)=0.$$

关键给分点：第2、3步得 $F(t)$（4分）；第4步用洛必达/导数定义求极限（4分）；结论与符号（2分）。

**易错点**

- 内层积分不要直接写成 $f$ 的差分；先得到的是 $f_x$ 的边界差。
- 矩形面积是 $2t^2$，所以 $F(t)$ 是二阶小量；$\lim F(t)/t$ 不是 $f_{xy}(0,0)$，而是 $0$。
- 下标 $xy$ 与 $yx$ 易混，但二阶连续时混合偏导相等。

**命题规律**

这类题常把二重积分化为累次积分，再结合导数定义/洛必达法则求极限，实质是矩形上的二维差分。复习时应熟练牛顿莱布尼茨公式、变上限函数的求导，以及用简单函数（如 $f=xy$）自检验证。

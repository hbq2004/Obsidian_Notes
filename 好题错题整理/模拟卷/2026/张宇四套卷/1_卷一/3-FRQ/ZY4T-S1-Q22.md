# 解答题 第 22 题

![[_Attachments/题目识别/ZY4T/ZY4T-S1-Q22_题目.png|题目]]

设随机变量 $(X,Y)$ 的概率密度为 $f(x,y) = \begin{cases} a\left(x^2 + \frac{xy}{2}\right), & 0 < x < 1, 0 < y < 2, \\ 0, & \text{其他}. \end{cases}$

(1) 求 $a$ 的值；

(2) $X,Y$ 是否相互独立，说明理由；

(3) 计算 $P\left\{ Y > 1 \middle| X = \frac{1}{2} \right\}$.

![[_Attachments/题目识别/ZY4T-答案/ZY4T-S1-Q22_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**

(1) 由密度归一性：$$\int_0^1\int_0^2 a(x^2+xy/2)dydx=1.$$ 先对 $y$ 积分得 $$\int_0^2 (x^2+xy/2)dy=2x^2+x,$$ 再对 $x$ 积分得 $$\int_0^1(2x^2+x)dx=7/6,$$ 因此 $a=6/7$。

(2) $X,Y$ 不独立。求边缘密度：$$f_X(x)=\int_0^2 f(x,y)dy=\frac{6}{7}(2x^2+x),\quad 0<x<1;$$ $$f_Y(y)=\int_0^1 f(x,y)dx=\frac{6}{7}(1/3+y/4),\quad 0<y<2.$$ 若独立应有 $f=f_Xf_Y$。取 $x=1/2,y=1/2$：$$f(1/2,1/2)=\frac{6}{7}(1/4+1/8)=\frac{9}{28},$$ $$f_X(1/2)f_Y(1/2)=\frac{6}{7}\cdot\frac{11}{28}=\frac{33}{98},$$ 二者不等，故不独立。

(3) 条件密度：$$f_{Y|X}(y|1/2)=\frac{f(1/2,y)}{f_X(1/2)}.$$ 其中 $f_X(1/2)=6/7$，$f(1/2,y)=\frac{6}{7}(1+y)/4$，所以 $$f_{Y|X}(y|1/2)=\frac{1+y}{4},\quad 0<y<2.$$ 因此 $$P(Y>1|X=1/2)=\int_1^2\frac{1+y}{4}dy=\frac{5}{8}.$$

给分点：①归一化积分正确；②边缘密度计算正确；③独立判断有依据；④条件密度公式使用正确；⑤最终积分结果正确。

**解题切入点**

考查联合密度归一性、边缘密度、独立性和条件密度。类比二维数组：总面积归一为1；按行列求和得边缘；联合密度能否分离变量对应独立性；固定 $x$ 后把密度归一化即得条件密度。

**推演**

(1) 求 $a$ 的完整积分：$$\int_0^1\int_0^2 a(x^2+xy/2)dydx=1.$$ 先内层：$$\int_0^2(x^2+xy/2)dy=2x^2+x.$$ 再外层：$$\int_0^1(2x^2+x)dx=2/3+1/2=7/6.$$ 故 $a=6/7$。

(2) 边缘密度与独立判断：由 $$f_X(x)=\int_0^2 f(x,y)dy=\frac{6}{7}(2x^2+x),\quad 0<x<1;$$ $$f_Y(y)=\int_0^1 f(x,y)dx=\frac{6}{7}(1/3+y/4),\quad 0<y<2.$$ 若独立则 $f(x,y)=f_X(x)f_Y(y)$。取 $x=1/2,y=1/2$：$$f(1/2,1/2)=\frac{9}{28},\quad f_X(1/2)f_Y(1/2)=\frac{33}{98},$$ 不相等，因此不独立。

(3) 条件概率：由条件密度定义，对 $0<y<2$，$$f_{Y|X}(y|1/2)=\frac{f(1/2,y)}{f_X(1/2)}=\frac{1+y}{4}.$$ 所以 $$P(Y>1|X=1/2)=\int_1^2\frac{1+y}{4}dy=\frac{5}{8}.$$ 自检：条件密度在 $(0,2)$ 上积分为 $1$，概率在 $0$ 到 $1$ 之间，结果合理。

**易错点**

1. 连续型随机变量 $P(X=1/2)=0$，不能写成 $P(X=1/2,Y>1)/P(X=1/2)$，应使用条件密度 $f_{Y|X}(y|x)=f(x,y)/f_X(x)$。
2. 求边缘密度时不要丢掉非零区间；条件密度也需标明 $0<y<2$。
3. 独立性判断要比较联合密度与边缘密度乘积是否处处相等，而不是看个别点相等；但反例取一个内点不等即可。
4. 归一化积分必须等于 $1$，且积分区域是 $0<x<1,0<y<2$ 的矩形。

**命题规律**

二维连续型随机变量常考“归一化求参数→求边缘密度→判断独立→求条件概率”的标准链。复习时应熟练掌握二重积分、边缘密度和条件密度公式；考试中条件概率一般用条件密度积分处理。建议把此类题归纳为“概率密度计算模板”，反复训练。

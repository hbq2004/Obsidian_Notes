# MCQ 第 2 题

![[_Attachments/题目识别/JJ8T/JJ8T-S4-Q02_题目.png|题目]]

2. 设函数 $f(x) = \begin{cases} \frac{1}{1 + x^2}, & x \leq 0, \\ \sin x + 1, & x > 0, \end{cases}$，则 $f(x)$ 的一个原函数是(\_)。

A. $F(x) = \begin{cases} \arctan x, & x \leq 0, \\ x - \cos x, & x > 0, \end{cases}$

B. $F(x) = \begin{cases} \arctan x - 1, & x \leq 0, \\ x - \cos x, & x > 0, \end{cases}$

C. $F(x) = \begin{cases} \arctan x, & x \leq 0, \\ x + 1, & x > 0, \end{cases}$

D. $F(x) = \begin{cases} \arctan x - 1, & x \leq 0, \\ x + 1, & x > 0, \end{cases}$


---

## 解析（AI 生成，仅供参考）

【考点】本题考查原函数的定义：若 $F'(x)=f(x)$，则 $F(x)$ 是 $f(x)$ 的原函数。解题关键在于分段积分后，利用原函数在分段点处的连续性与可导性确定常数，这与算法竞赛中拼接状态时检查边界条件类似，必须保证“接口处”连续且导数匹配。

【解】
设 $f(x)$ 的一个原函数为 $F(x)$，则 $F'(x)=f(x)$。

当 $x \leq 0$ 时，$f(x)=\frac{1}{1+x^2}$，积分得
$$
F(x) = \arctan x + C_1 \quad (x \leq 0)
$$

当 $x > 0$ 时，$f(x)=\sin x + 1$，积分得
$$
F(x) = -\cos x + x + C_2 \quad (x > 0)
$$

由于原函数可导，故必连续。在 $x=0$ 处：
左极限：$\lim_{x\to 0^-} F(x) = \arctan 0 + C_1 = C_1$
右极限：$\lim_{x\to 0^+} F(x) = -\cos 0 + 0 + C_2 = -1 + C_2$
由连续性要求 $C_1 = -1 + C_2$，即 $C_2 = C_1 + 1$。

再验证可导性：
左导数：$(\arctan x)'|_{x=0} = \frac{1}{1+0^2}=1$
右导数：$(-\cos x + x)'|_{x=0} = (\sin x + 1)|_{x=0}=1$
左右导数相等，故可导性自动满足。

因此原函数通式为
$$
F(x) = \begin{cases} \arctan x + C_1, & x \leq 0 \\ -\cos x + x + C_1 + 1, & x > 0 \end{cases}
$$

对比选项：
- A：$x \leq 0$ 时 $C_1=0$，则 $x>0$ 时应为 $-\cos x + x + 1$，但A给的是 $-\cos x + x$，差常数1，故不满足连续性，错误。
- B：$x \leq 0$ 时 $C_1=-1$，则 $x>0$ 时为 $-\cos x + x + 0$，即 $x - \cos x$，与B一致，且连续可导，正确。
- C：$x>0$ 部分 $x+1$ 的导数为 $1$，不等于 $\sin x + 1$，故错误。
- D：$x>0$ 部分 $x+1$ 同样不满足导数条件，故错误。

【答案】正确选项为 **(B)**。

【易错点】
1. 忽略原函数必须在分段点连续，导致常数项选取错误。本题A项就是典型的“忘了加常数”的干扰项。
2. 误以为只要每段分别积分即可，忽略分段点处左右极限的一致性。
3. 对 $x>0$ 部分积分时漏掉 $-\cos x$，错选C或D。
4. 防错提醒：求分段函数的原函数，务必先积分，再令分段点处左极限=右极限确定常数，最后检查导数是否处处等于 $f(x)$。

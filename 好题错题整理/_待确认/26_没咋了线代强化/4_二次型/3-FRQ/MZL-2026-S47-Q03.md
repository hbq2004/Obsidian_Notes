# FRQ 第 3 题

![[_Attachments/题目识别/MZL-2026/MZL-2026-S47-Q03_题目.png|题目]]

设二次型 $f(x_1,x_2,x_3) = x^{T} A x = x_1^2 + x_2^2 + 2x_3^2 + 2x_2x_3$，$g(y_1,y_2,y_3) = y^{T} B y = \sum\limits_{i=1}^{3} \sum\limits_{j=1}^{3} A_{ij} y_i y_j$ 其中 $A_{ij}$ 是 $A$ 中 $a_{ij} (i,j=1,2,3)$ 的代数余子式，$A, B$ 均是实对称矩阵．

（1）是否存在正交矩阵 $Q$，使得 $Q^{T} A Q = B$．若不存在请说明理由；若存在，试求出一个正交矩阵 $Q$．

（2）是否存在可逆矩阵 $P$，使得 $P^{T} A P = B$．若不存在请说明理由；若存在，试求出一个可逆矩阵 $P$．

# FRQ 第 3 题

![[_Attachments/题目识别/MZL-2026/MZL-2026-S37-Q03_题目.png|题目]]

(1) 求 $a, b$ 的值；
(2) 求 $A, B$ 的全部公共特征向量；
(3) 是否存在可逆矩阵 $P$，使得 $A, B$ 均可相似对角化，若存在，写出一个矩阵 $P$；若不存在，说明理由.

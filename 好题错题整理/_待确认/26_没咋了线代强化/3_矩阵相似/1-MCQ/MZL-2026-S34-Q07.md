# MCQ 第 7 题

![[_Attachments/题目识别/MZL-2026/MZL-2026-S34-Q07_题目.png|题目]]

设 $A$，$B$ 是可逆矩阵，且 $A$ 与 $B$ 相似，则下列结论错误的是（ ）.

(A) $A^{T}$ 与 $B^{T}$ 相似.
(B) $A^{-1}$ 与 $B^{-1}$ 相似.
(C) $A + A^{T}$ 与 $B + B^{T}$ 相似.
(D) $A + A^{-1}$ 与 $B + B^{-1}$ 相似.

## V4 Flash Max 解析

**答案**: C。设 $B=P^{-1}AP$，则 (A) 可用 $P^T$ 证明，(B)(D) 可用同一个 $P$ 证明；但 (C) 不是必然成立。反例：  
$A=\begin{pmatrix}1&1\\0&1\end{pmatrix}$，取 $P=\begin{pmatrix}1&0\\0&2\end{pmatrix}$，则 $B=P^{-1}AP=\begin{pmatrix}1&2\\0&1\end{pmatrix}$，$A$ 与 $B$ 相似且都可逆。但  
$$A+A^T=\begin{pmatrix}2&1\\1&2\end{pmatrix},\quad \det(A+A^T)=3,$$  
$$B+B^T=\begin{pmatrix}2&2\\2&2\end{pmatrix},\quad \det(B+B^T)=0.$$  
相似矩阵行列式必须相等，所以 $A+A^T$ 与 $B+B^T$ 不相似。

**解题切入点**:  
先写相似的定义 $B=P^{-1}AP$，然后看每个选项能否写成“某个可逆矩阵乘以原矩阵再乘其逆”的形式。类似算法竞赛里的“换坐标系”问题：逆运算、多项式运算可以和坐标变换交换；但转置会出现 $P^T$，不能与原变换直接合并，往往是陷阱。推不出来的选项就构造反例。

**推演**:  
设 $P$ 可逆，且 $B=P^{-1}AP$。

(A)  
$$B^T=(P^{-1}AP)^T=P^TA^T(P^{-1})^T=P^TA^T(P^T)^{-1},$$  
所以 $A^T\sim B^T$。

(B)  
$$B^{-1}=(P^{-1}AP)^{-1}=P^{-1}A^{-1}P,$$  
所以 $A^{-1}\sim B^{-1}$。

(D)  
$$B+B^{-1}=P^{-1}AP+P^{-1}A^{-1}P=P^{-1}(A+A^{-1})P,$$  
所以 $A+A^{-1}\sim B+B^{-1}$。

(C) 不能由上述方法保证，并且有反例：  
取 $A=\begin{pmatrix}1&1\\0&1\end{pmatrix}$，$P=\begin{pmatrix}1&0\\0&2\end{pmatrix}$，则  
$$B=P^{-1}AP=\begin{pmatrix}1&2\\0&1\end{pmatrix},$$  
$A,B$ 相似且都可逆。但  
$$\det(A+A^T)=3,\qquad \det(B+B^T)=0,$$  
二者不可能相似。因此错误的是 C。

**易错点**:  
1. 不要因为 $A\sim B\Rightarrow A^T\sim B^T$ 就认为 $A+A^T\sim B+B^T$。$A^T$ 的相似变换用的是 $P^T$，与原来的 $P$ 不同，两个相似关系不能随便相加。  
2. 展开逆矩阵时注意反序：$(P^{-1}AP)^{-1}=P^{-1}A^{-1}P$。  
3. 反例要自检：这里 $A,B$ 确实由同一个 $P$ 验证相似，且都可逆。  
4. 若 $P$ 是正交矩阵，即 $P^T=P^{-1}$，则 C 也成立；但一般相似没有这个条件。

**命题规律**:  
考查相似关系下哪些量是“相似不变量”。$A^k$、多项式 $f(A)$、$A^{-1}$ 等保持；涉及 $A^T$ 的组合如 $A+A^T$、$AA^T$、$A^TA$ 不一定保持。常见命题角度是结合行列式、迹、秩、特征值等不变量判断是否相似，或与正交相似、合同关系对比。

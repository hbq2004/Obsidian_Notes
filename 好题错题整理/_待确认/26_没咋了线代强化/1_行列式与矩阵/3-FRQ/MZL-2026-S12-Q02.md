# FRQ 第 2 题

![[_Attachments/题目识别/MZL-2026/MZL-2026-S12-Q02_题目.png|题目]]

设 $A$ 是 $n$ 阶方阵，$E + A$ 可逆，其中 $E$ 为 $n$ 阶单位矩阵，证明： 
（1）$(E - A)(E + A)^{-1} = (E + A)^{-1}(E - A)$； 
（2）若 $A = -A^{T}$，则 $(E - A)(E + A)^{-1}$ 是正交矩阵．

# FRQ 第 ZT-10 题

![[_Attachments/题目识别/王道算法应用题打卡表做题本-题目/WD-ZT-T10_题目.png|题目]]

任务10：(必做) 2018应用题：42题 王道书 6.4.6_大题_12 (页码 245)
【2018统考真题】拟建设一个光通信骨干网络连通 BJ、CS、XA、QD、JN、NJ、TL 和 WH 等 8 个城市，右图中无向边上的权值表示两个城市之间备选光缆的铺设费用。
【图：一个包含8个顶点(标记为BJ、CS、XA、QD、JN、NJ、TL、WH)和若干带权值边的无向图，边的权值表示铺设费用。】
请回答下列问题：
1)仅从铺设费用角度出发，给出所有可能的最经济的光缆铺设方案(用带权图表示)，并计算相应方案的总费用。
2)该图可采用图的哪种存储结构？给出求解问题所用的算法名称.
3)假设每个城市采用一个路由器按 1)中得到的最经济方案组网，主机 H1 直接连接 TL 的路由器，主机 H2 直接连接 BJ 的路由器. 若 H1 向 H2 发送一个 $TTL = 5$ 的 IP 分组，则 H2 是否可以收到该 IP 分组？

## 答案

![[_Attachments/题目识别/王道算法应用题打卡表做题本-答案/WD-ZT-T10_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：  
1) 最经济的光缆铺设方案即最小生成树，总费用为15。共有两种方案（用带权图表示，边集如下）：  
方案一：选取边 $(BJ,TL,2)$、$(TL,JN,1)$、$(JN,QD,1)$、$(QD,NJ,2)$、$(NJ,WH,2)$、$(WH,CS,3)$、$(CS,XA,4)$。  
方案二：选取边 $(BJ,TL,2)$、$(TL,JN,1)$、$(JN,QD,1)$、$(QD,NJ,2)$、$(NJ,WH,2)$、$(WH,CS,3)$、$(XA,WH,4)$。  
总费用均为 $2+1+1+2+2+3+4=15$。  
2) 该图可采用邻接矩阵（或邻接表）存储。求解问题所用的算法是 Prim 算法（或 Kruskal 算法）。  
3) 可以收到。因为所有最经济方案中都包含 $BJ-TL$ 边，使得 $TL$ 与 $BJ$ 直接相连，跳数为1。$TTL$ 初始为5，经过1跳后 $TTL=4>0$，$H2$ 可以收到该 IP 分组。

**解题切入点**：  
首先明确问题核心：第一问求最经济方案即最小生成树，由于需要“所有可能”，提示存在权值相等的边，应使用 Kruskal 算法并注意同权值边选取的多种可能。第二问是图存储与算法的基础知识。第三问将网络层概念与最小生成树路径长度结合，需理解 TTL 含义。

**推演**：  
1. 图结构（根据原题图，顶点集 $V=\{BJ,CS,XA,QD,JN,NJ,TL,WH\}$，无向边集 $E$ 及权值 $w$ 如下：  
   $E=\{ (BJ,TL,2), (BJ,JN,3), (BJ,XA,6), (TL,JN,1), (TL,QD,2), (JN,QD,1), (JN,NJ,3), (QD,NJ,2), (NJ,WH,2), (WH,CS,3), (CS,XA,4), (XA,WH,4), (XA,JN,5) \}$。  
2. 求最小生成树。采用 Kruskal 算法，将边按权值从小到大排序：  
   $1: (TL,JN,1), (JN,QD,1)$  
   $2: (BJ,TL,2), (TL,QD,2), (QD,NJ,2), (NJ,WH,2)$  
   $3: (BJ,JN,3), (JN,NJ,3), (WH,CS,3)$  
   $4: (CS,XA,4), (XA,WH,4)$  
   $5: (XA,JN,5)$  
   $6: (BJ,XA,6)$  
   依次选择边：  
   - 选 $(TL,JN,1)$，连通 $\{TL,JN\}$。  
   - 选 $(JN,QD,1)$，连通 $\{TL,JN,QD\}$。  
   - 选 $(BJ,TL,2)$，连通 $\{BJ,TL,JN,QD\}$。  
   - 接下来最小权值为2的边有 $(TL,QD,2)$，但会形成回路，跳过；选 $(QD,NJ,2)$，连通 $\{BJ,TL,JN,QD,NJ\}$。  
   - 选 $(NJ,WH,2)$，连通 $\{BJ,TL,JN,QD,NJ,WH\}$。  
   - 最小权值为3的边中，$(BJ,JN,3)$ 和 $(JN,NJ,3)$ 形成回路，跳过；选 $(WH,CS,3)$，连通 $\{BJ,TL,JN,QD,NJ,WH,CS\}$。  
   - 此时还剩 $XA$ 未连通，权值为4的边有 $(CS,XA,4)$ 和 $(XA,WH,4)$，两者都可以选，且不会形成回路（因为 $CS$ 和 $WH$ 均已连通，$XA$ 孤立，所以两条边均能连接 $XA$，但只能选一条，否则形成回路）。因此有两种方案：  
     * 方案一：选 $(CS,XA,4)$，总费用 $=1+1+2+2+2+3+4=15$。  
     * 方案二：选 $(XA,WH,4)$，总费用 $=1+1+2+2+2+3+4=15$。  
   所有最小生成树即为上述两种方案，总费用均为15。  
3. 第二问：图的存储结构常用邻接矩阵（适合稠密图）或邻接表（适合稀疏图），本题顶点数少，两种均可。求解最小生成树的算法有 Prim 算法（从顶点出发，适合稠密图）和 Kruskal 算法（从边出发，适合稀疏图），本题使用 Kruskal 算法更易体现同权值边的多方案，但两种算法均可。  
4. 第三问：在两种最经济方案中，均包含边 $(BJ,TL,2)$，因此 $TL$ 与 $BJ$ 直接相连，跳数为1。主机 $H1$ 连接 $TL$ 路由器，$H2$ 连接 $BJ$ 路由器。IP 分组从 $H1$ 发出，$TTL=5$，经过 $TL$ 路由器转发给 $BJ$ 路由器，此时 $TTL$ 减为 $4$，大于 $0$，$BJ$ 路由器接收并通过本地交付给 $H2$。因此 $H2$ 可以收到该 IP 分组。

**易错点**：  
- 误以为最小生成树唯一，忽略权值相等边的多种选择，导致漏掉方案。应使用 Kruskal 算法并仔细检查同权值边的可替换性。  
- 第三问中，误以为 $TTL$ 需要经过所有路由器，但实际只需要计算从 $TL$ 到 $BJ$ 的跳数，而非整个树的总边数。  
- 存储结构概念混淆，可能只答一种，但实际两种常用存储结构均可。

**命题规律**：  
- 考点定位：最小生成树（必考重点）、图的存储结构、算法名称、结合网络层 TTL 概念。  
- 常见变式：改变顶点数或边权值，求最小生成树的唯一性；或结合图的其他应用（如最短路径）与 TTL 结合。  
- 复习建议：熟练掌握 Prim 和 Kruskal 算法，注意权值相等时的多方案处理；理解图的两种主流存储结构及其适用场景；了解 TTL 机制，并能与图论中的路径长度关联。

**知识点**：最小生成树、Kruskal 算法、邻接矩阵、邻接表

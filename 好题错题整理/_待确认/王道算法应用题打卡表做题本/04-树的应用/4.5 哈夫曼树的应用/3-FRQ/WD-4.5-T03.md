任务 3：(低优先级) 3.4.3 基于你所构造的哈夫曼树，写出 10 个字符的哈夫曼编码.

**答案**：

题目没有给出 10 个字符的权值/频度，也没有给出上一问构造好的树，因此严格来说不能给出唯一的哈夫曼编码表。哈夫曼编码由哈夫曼树决定：  
> 约定左分支为 `0`、右分支为 `1`，从根结点走到每个字符所在的叶子结点，把路径上的 `0/1` 依次连接起来，就是该字符的哈夫曼编码。

例如，若以 $A\sim J$ 表示 10 个字符，权值取 $1,2,\dots,10$，按“左 0 右 1”读出的一种合法编码表为：

| 字符 | 权值 | 哈夫曼编码 |
|---|---|---|
| A | 1 | 01110 |
| B | 2 | 01111 |
| C | 3 | 0110 |
| D | 4 | 1110 |
| E | 5 | 1111 |
| F | 6 | 010 |
| G | 7 | 100 |
| H | 8 | 101 |
| I | 9 | 110 |
| J | 10 | 00 |

注意：若左右分支标记互换，则所有编码中的 `0/1` 整体互换，仍然是合法哈夫曼编码。

---

**解题切入点**：

看到“哈夫曼编码”，先不要背编码表。核心是：**编码 = 根到叶子结点的路径**。

- 如果树已经构造好，直接对树做 DFS，路径上标 `0/1` 即可；
- 如果树没有给出，则需要先根据字符权值构造哈夫曼树；
- 哈夫曼编码考查的是“前缀码”思想和贪心构造过程，不是记忆固定编码。

可以类比：哈夫曼树就像一棵字典树，每个字符都在叶子结点，从根走到叶子的路径就是它的“代码”。

---

**推演**：

设 10 个字符为 $c_1,c_2,\dots,c_{10}$，对应叶子结点为 $v_1,v_2,\dots,v_{10}$。

若树未给出，构造哈夫曼树的贪心过程为：

1. 将每个字符看作一棵只有根结点的树，根权值为该字符的频度；
2. 每次选择根权值最小的两棵树合并；
3. 新树的根权值等于这两棵树根权值之和；
4. 重复 $10-1=9$ 次，得到一棵有 $10$ 个叶子结点的哈夫曼树。

编码时，令：

- 左分支边记为 $0$；
- 右分支边记为 $1$。

若从根到叶子 $v_i$ 的路径依次经过的边为 $e_1,e_2,\dots,e_k$，则字符 $c_i$ 的哈夫曼编码为：

$$
code(c_i)=\ell(e_1)\ell(e_2)\cdots\ell(e_k)
$$

其中 $\ell(e)\in\{0,1\}$。

例如路径为“根—左—左—右”，则编码为：

$$
001
$$

由于哈夫曼树中所有字符都放在叶子结点上，所以任意一个字符的编码都不可能是另一个字符编码的前缀。这就是哈夫曼编码能无歧义译码的原因。

如果要用程序输出编码，本质上就是一次 DFS：

```c
void getHuffmanCode(Node *root, char path[], int depth) {
    if (root == NULL) {
        return;
    }

    // 叶子结点：输出字符和路径编码
    if (root->left == NULL && root->right == NULL) {
        path[depth] = '\0';
        printf("%c: %s\n", root->ch, path);
        return;
    }

    // 左 0
    path[depth] = '0';
    getHuffmanCode(root->left, path, depth + 1);

    // 右 1
    path[depth] = '1';
    getHuffmanCode(root->right, path, depth + 1);
}
```

调用时传根结点和空路径即可。若题目中树的左右标记相反，只需把 `'0'` 和 `'1'` 两行互换。

---

**易错点**：

1. **不说明“左 0 右 1”**  
   哈夫曼编码不是全局唯一的，必须约定左右分支标记。左右整体互换不影响正确性，但要说明。

2. **把字符放在中间结点上**  
   哈夫曼树中字符一定在叶子结点。若放在中间结点，编码可能成为其他编码的前缀，导致无法唯一译码。

3. **从叶子往根读编码**  
   编码是从根到叶子的路径。如果从叶子往根读，会得到反串。

4. **认为哈夫曼树/编码唯一**  
   当出现相等权值或左右标记不同时，哈夫曼树可以不同，编码也会不同，但带权路径长度 WPL 相同。

5. **构造时没有“每次取两个最小权值”**  
   哈夫曼树是贪心构造，必须动态选择当前最小的两个根权值合并，不能只按原始权值顺序硬凑。

---

**命题规律**：

本题属于“树与二叉树”中“哈夫曼树与哈夫曼编码”的应用题。408 中常考：

- 给一组权值，构造哈夫曼树；
- 求 WPL（带权路径长度）；
- 写出哈夫曼编码；
- 判断一组编码是否为前缀码；
- 给定编码反推哈夫曼树。

复习建议：不要死记编码结果，要熟练画出哈夫曼树。尤其要掌握“每次选两个最小权值合并”的贪心过程，以及“编码长度 = 叶子深度”“WPL = 各叶子权值 × 编码长度之和”这两个核心计算。

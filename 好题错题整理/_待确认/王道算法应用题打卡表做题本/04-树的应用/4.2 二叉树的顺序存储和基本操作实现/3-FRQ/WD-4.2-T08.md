# FRQ 第 3.1.8 题

![[_Attachments/题目识别/王道算法应用题打卡表做题本-题目/WD-4.2-T08_题目.png|题目]]

任务7：(高优先级)3.1.8 基于上述定义，写一个函数
```c
int findFather(i)
```
返回结点 $i$ 的父节点编号.

---

## 答案

![[_Attachments/题目识别/王道算法应用题打卡表做题本-答案/WD-4.2-T08_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：

按二叉树的顺序存储编号定义：根结点编号为 $1$，结点 $i$ 的左孩子编号为 $2i$，右孩子编号为 $2i+1$。因此：

$$
\operatorname{parent}(i)=
\begin{cases}
-1, & i=1 \text{（根结点无双亲）}\\[2mm]
\left\lfloor \dfrac{i}{2} \right\rfloor, & i>1
\end{cases}
$$

C 代码实现：

```c
int findFather(int i) {
    if (i <= 1) {
        return -1;        // 根结点没有父节点
    }
    return i / 2;         // 整数除法等价于向下取整
}
```

时间复杂度：$O(1)$；空间复杂度：$O(1)$。

---

**解题切入点**：

拿到题目先看函数签名：`findFather(i)` 只有结点编号 $i$，没有传入树结构指针。这说明本题不是遍历树找父节点，而是利用**二叉树顺序存储的编号性质**。

这和算法竞赛/数据结构中“堆”的数组存储很像：已知下标为 $i$，父节点下标直接由编号运算得到，不需要存父指针，也不需要递归遍历。

---

**推演**：

顺序存储的二叉树按满二叉树层次编号：

- 根结点编号为 $1$；
- 结点 $p$ 的左孩子编号为 $2p$；
- 结点 $p$ 的右孩子编号为 $2p+1$。

若结点 $i$ 的父结点为 $p$，则 $i$ 只可能是 $p$ 的左孩子或右孩子：

- 若 $i=2p$，则 $p=\dfrac{i}{2}$；
- 若 $i=2p+1$，则 $p=\dfrac{i-1}{2}$。

两种情况下，父结点编号统一为：

$$
p=\left\lfloor \dfrac{i}{2} \right\rfloor
$$

例如：

- 结点 $4,5$ 的父结点都是 $2$；
- 结点 $6,7$ 的父结点都是 $3$；
- 结点 $1$ 是根，没有父结点，返回 $-1$。

C 语言中，整数除法 `i / 2` 对于非负整数会自动向下取整，所以直接写 `i / 2` 即可。

---

**易错点**：

1. **忘记处理根结点**  
   若 $i=1$，`1 / 2 = 0`，可能被误认为父结点是 $0$。但根结点没有父结点，应返回 $-1$。

2. **混淆 1 起始编号和 0 起始编号**  
   若结点编号从 $0$ 开始，则根结点为 $0$，父结点公式应改为：

   $$
   \operatorname{parent}(i)=
   \begin{cases}
   -1, & i=0\\
   (i-1)/2, & i>0
   \end{cases}
   $$

   不能继续用 `i / 2`。

3. **把问题想复杂**  
   不要写成递归遍历二叉树找父结点。顺序存储编号定义下，直接下标运算即可，$O(1)$ 完成。

4. **不要和双亲表示法混淆**  
   如果题目定义的是“双亲表示法”，即结点结构中有 `parent` 域，则应直接返回 `T.nodes[i].parent`；本题按顺序存储编号规则求解。

---

**命题规律**：

本题核心考点是**二叉树顺序存储**与**完全二叉树编号性质**。

常见变式：

- 求结点 $i$ 的左孩子：$2i$；
- 求结点 $i$ 的右孩子：$2i+1$；
- 求结点 $i$ 的父结点：$\lfloor i/2 \rfloor$；
- 求结点 $i$ 所在层次：$\lfloor \log_2 i \rfloor + 1$；
- 堆的插入、删除中调整操作的父结点定位。

复习时应熟练记住 1 起始编号和 0 起始编号两套公式，并能写出简洁的迭代代码。

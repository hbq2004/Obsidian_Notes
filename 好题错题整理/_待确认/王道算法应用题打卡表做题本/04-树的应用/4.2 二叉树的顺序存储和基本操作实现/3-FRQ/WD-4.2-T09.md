# FRQ 第 3.1.9 题

![[_Attachments/题目识别/王道算法应用题打卡表做题本-题目/WD-4.2-T09_题目.png|题目]]

任务 8： (高优先级) 3.1.9 基于上述定义，写一个函数 
```c
int leftChild(i)
```
返回结点 $i$ 的左孩子编号.

---

## 答案

![[_Attachments/题目识别/王道算法应用题打卡表做题本-答案/WD-4.2-T09_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：按完全二叉树层序编号（从 1 开始）定义，结点 \(i\) 的左孩子编号为

\[
2i
\]

因此核心函数实现为：

```c
int leftChild(int i) {
    return 2 * i;
}
```

若需要判断左孩子是否存在，即已知总结点数为 \(n\)，则可用：

```c
int leftChild(int i, int n) {
    if (i < 1 || 2 * i > n) {
        return -1;   // 表示不存在左孩子
    }
    return 2 * i;
}
```

**解题切入点**：看到“编号 \(i\) 找左孩子编号”，应立刻定位到完全二叉树的顺序存储编号性质。这类题本质是“下标映射”，不是遍历树。可以把它类比成数组随机访问：给定一个下标，直接计算另一个下标，时间复杂度是 \(O(1)\)。

**推演**：在按层序从 1 开始编号的完全二叉树中，任意结点 \(j\) 的双亲编号为

\[
\lfloor j/2 \rfloor
\]

所以若求结点 \(i\) 的孩子编号，就相当于解：

\[
\lfloor j/2 \rfloor = i
\]

满足该式的候选编号只有两个：

\[
j = 2i \quad \text{或} \quad j = 2i + 1
\]

层序遍历时，同一双亲的左孩子总是先于右孩子出现，因此编号较小的是左孩子，即：

\[
\text{leftChild}(i) = 2i
\]

右孩子为：

\[
\text{rightChild}(i) = 2i + 1
\]

若整棵树共有 \(n\) 个结点，则左孩子存在当且仅当：

\[
2i \le n
\]

即：

\[
i \le \lfloor n/2 \rfloor
\]

否则该结点没有左孩子。整体时间复杂度为 \(O(1)\)，空间复杂度为 \(O(1)\)。

**易错点**：

- 忘记判断 \(2i > n\)，导致返回一个不存在的结点编号。
- 把左孩子写成 \(2i + 1\)，右孩子写成 \(2i\)，顺序颠倒。
- 混淆数组下标从 0 开始和从 1 开始的存储方式。本题按王道常用定义，编号从 1 开始；若从 0 开始，则左孩子下标为 \(2i+1\)。
- 没有必要递归建树或遍历整棵树，直接用编号公式即可。

**命题规律**：这是完全二叉树顺序存储的基础性质，也是堆排序、优先队列实现的基础。常考变式包括：求右孩子编号 \(2i+1\)、求双亲编号 \(\lfloor i/2 \rfloor\)、判断结点 \(i\) 是否为叶子结点、利用该性质实现堆的“上滤”和“下滤”。复习时应重点掌握 1 起始编号下的父子下标关系，并能快速手算。

**知识点**：完全二叉树、顺序存储、二叉树编号性质、时间复杂度

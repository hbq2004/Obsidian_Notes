# FRQ 第 3.1.3 题

任务2：(高优先级) 3.1.3 基于上述定义，写一个函数 `int findFather(i)`，返回结点 $i$ 的父节点编号。
```c
int findFather(i)
{
    // 函数实现
}
```

## 答案

![[_Attachments/题目识别/王道算法应用题打卡表做题本-答案/WD-4.2-T03_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：假设树的存储采用**双亲表示法**（顺序存储），即每个结点记录其父结点的下标，根结点的父结点记为 -1。则 `findFather(i)` 直接返回结点 i 的父结点编号即可。C 语言实现如下：

```c
#define MAX 100
int parent[MAX];   // parent[i] 表示结点 i 的父结点下标，根结点为 -1

int findFather(int i)
{
    return parent[i];   // 若 i 是根结点，则 parent[i] == -1，表示无父结点
}
```

若题目给定的“上述定义”是更完整的树结构体，例如：

```c
typedef struct {
    int data;
    int parent;      // 父结点下标
} PTNode;

typedef struct {
    PTNode nodes[MAX];
    int n;           // 结点数
} PTree;
```

则函数可写成：

```c
PTree T;   // 假设全局树变量

int findFather(int i)
{
    return T.nodes[i].parent;
}
```

**解题切入点**：看到“返回结点 i 的父节点编号”，立刻联想到**双亲表示法**。双亲表示法用数组存储树，每个元素增加一个 `parent` 字段指向父结点，因此找父结点是它的“招牌操作”，时间复杂度为 O(1)。题目没有要求“找孩子”或“找根”，所以不需要孩子链表或并查集的向上查找，直接访问数组即可。

**推演**：

1. 双亲表示法的结点定义为：

   ```c
   typedef struct {
       int data;      // 数据域
       int parent;    // 父结点下标
   } PTNode;
   ```

2. 对任意结点 i，其父结点信息就存放在 `PTNode.parent` 中，因此：

   $$ \text{父结点编号} = parent[i] $$

3. 根结点没有父结点，通常约定 `parent[根] = -1`。因此函数返回 `parent[i]` 即可，无需额外判断；如果调用者需要判断是否为根，可依据返回值是否为 -1。

4. 时间复杂度：$O(1)$；空间复杂度：$O(1)$。

**易错点**：

- 忘记处理根结点。根结点的 `parent` 字段通常为 -1，返回 -1 是合法结果，不应报错。
- C 语言函数定义中参数必须标明类型，不能写 `int findFather(i)`，应写 `int findFather(int i)`。
- 若题目规定结点编号从 1 开始，而数组下标从 0 开始，需要确认下标映射关系，避免越界或取错元素。
- 不要把 `findFather` 和并查集中的 `find`（找根结点）混淆：前者一步到位，后者需要循环向上查找祖先。
- 如果使用结构体 `PTree`，注意函数是否需要传树对象；题目给的签名只有一个参数，应理解为使用全局变量或默认访问外部数组。

**命题规律**：本题是“树与二叉树”章节中最基础的应用，考点是树的三种存储结构之一——**双亲表示法**。常考变式包括：利用双亲数组求树的高度、求结点所在层数、判断两个结点是否具有兄弟关系/祖先关系，或与孩子表示法、孩子兄弟表示法互相转换。复习时应掌握各存储结构的定义、优缺点，以及基本操作的复杂度：双亲表示法找父亲 O(1)、找孩子 O(n)；孩子表示法找孩子 O(1)、找父亲 O(n)；孩子兄弟表示法便于树与二叉树的转换。

**知识点**：树的存储结构、双亲表示法、顺序存储、时间复杂度

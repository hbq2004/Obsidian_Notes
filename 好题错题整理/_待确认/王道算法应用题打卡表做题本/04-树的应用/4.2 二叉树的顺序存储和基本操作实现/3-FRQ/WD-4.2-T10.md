# FRQ 第 3.1.10 题

![[_Attachments/题目识别/王道算法应用题打卡表做题本-题目/WD-4.2-T10_题目.png|题目]]

任务 9：(高优先级) 3.1.10 基于上述定义，写一个函数 `int rightChild(i)`，返回结点 `i` 的右孩子编号.

---

## 答案

![[_Attachments/题目识别/王道算法应用题打卡表做题本-答案/WD-4.2-T10_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：

按完全二叉树顺序存储、编号从 1 开始，结点 \(i\) 的右孩子编号为：

$$
R(i)=2i+1
$$

因此直接实现为：

```c
int rightChild(int i) {
    return 2 * i + 1;
}
```

若需要判断右孩子是否存在，必须知道当前二叉树结点总数 \(n\)。可用全局变量 \(n\) 表示结点总数：

```c
int n; // 当前完全二叉树的结点总数

int rightChild(int i) {
    if (i < 1 || i > n || 2 * i + 1 > n)
        return 0;               // 0 表示无右孩子
    return 2 * i + 1;
}
```

注意：这是编号从 1 开始时的结论；如果数组下标从 0 开始存储根结点，则右孩子下标应为 \(2i+2\)。时间复杂度为 \(O(1)\)，空间复杂度为 \(O(1)\)。

---

**解题切入点**：

看到“返回结点 \(i\) 的右孩子编号”，要立刻定位到“完全二叉树的顺序存储结构”。这和数组模拟堆时的下标规律一致：根为 1，左孩子是 \(2i\)，右孩子是 \(2i+1\)。不要试图去二叉链表里找右指针，先写出编号公式，再补边界判断即可。

---

**推演**：

完全二叉树按层序编号，根结点编号为 1。对于结点 \(i\)，设它位于第 \(h\) 层，且是该层第 \(k\) 个结点，则它在编号序列中的位置为：

$$
i = (2^h - 1) + k
$$

其中 \(2^h-1\) 是它前面所有层的结点总数。

结点 \(i\) 的左孩子位于第 \(h+1\) 层。第 \(h+1\) 层中，在结点 \(i\) 的左孩子之前，有前 \(k-1\) 个结点各自贡献 2 个孩子，所以左孩子是该层第：

$$
2(k-1)+1 = 2k-1
$$

个结点。因此左孩子编号为：

$$
L = (2^{h+1}-1) + (2k-1)
$$

化简：

$$
L = 2^{h+1}+2k-2 = 2(2^h-1+k)=2i
$$

右孩子紧跟在左孩子之后，所以：

$$
R = L + 1 = 2i + 1
$$

若右孩子存在，则必须满足：

$$
1 \le i \le n,\quad 2i+1 \le n
$$

若 \(2i+1 > n\)，说明编号越界，即结点 \(i\) 没有右孩子，返回 0 表示空。

---

**易错点**：

- 容易把根结点编号误记为 0，从而写成 \(2i+2\)。本题编号从 1 开始，右孩子是 \(2i+1\)。
- 容易忘记判断边界。完全二叉树最后一层可能缺结点，若直接返回 \(2i+1\)，可能返回一个不存在的编号。
- 容易混淆“结点编号”和“数组下标”。若数组下标从 0 开始，则公式要相应改变。
- 如果顺序存储的不是完全二叉树，而是普通二叉树补空位存储，则不能只靠编号判断，还要检查目标位置是否为空结点。

---

**命题规律**：

本题属于“完全二叉树顺序存储”的固定考点。常以选择题形式考查左右孩子、双亲编号；在大题中常作为堆排序、优先队列的基础操作。常见变式有：

- 求左孩子编号：\(2i\)
- 求双亲编号：\(\lfloor i/2 \rfloor\)
- 判断结点是否有右孩子
- 求最后一个非叶结点编号：\(\lfloor n/2 \rfloor\)

复习时要把 1-based 和 0-based 两套下标公式分开记忆，并熟练运用“边界判断”。

## DeepSeek V4 Flash Max 解析

**答案**：  
下面是用长度为 $n$ 的数组实现并查集的完整代码，包含初始化、查找（含路径压缩）和合并三个基本操作。  

```c
#include <stdio.h>
#include <stdlib.h>

#define MAXN 100  // 假设最大元素个数，实际可用动态数组

int parent[MAXN]; // 父节点数组，下标表示元素，值表示父节点下标

// 初始化：每个元素独立成集合，父节点指向自身
void init(int n) {
    for (int i = 0; i < n; i++) {
        parent[i] = i;
    }
}

// 查找操作：递归实现路径压缩
int find(int x) {
    if (parent[x] != x) {
        parent[x] = find(parent[x]); // 路径压缩
    }
    return parent[x];
}

// 合并操作：将两个元素所在的集合合并
void unionSet(int x, int y) {
    int rootX = find(x);
    int rootY = find(y);
    if (rootX != rootY) {
        parent[rootX] = rootY; // 简单合并，未考虑秩
    }
}
```

如需按秩合并，可增加 `rank` 数组，在合并时将秩小的树挂到秩大的树下，进一步优化复杂度。

**解题切入点**：  
拿到题目首先明确“用数组实现并查集”的实质：用数组下标表示元素，数组元素存储其父节点下标，从而构建树形结构。核心考点是集合的表示与基本操作。可以类比“找朋友”游戏——每个人先记住自己的编号，然后通过父指针不断向上找到“老大”，并通过路径压缩让后续查找更快。本题只要求定义，但通常需要写出初始化、查找、合并三个关键函数。

**推演**：  
1. **集合的表示**：并查集用一棵树（森林）表示集合，树中每个节点指向其父节点，根节点指向自身。数组 `parent[x]` 存储 $x$ 的父节点，初始时 `parent[x] = x`，表示每个元素自成一集。  
2. **查找操作**：从 $x$ 出发，沿父指针向上直到根节点 $r$（`parent[r] == r`）。路径压缩：在递归返回时，将路径上所有节点的父指针直接指向根，使后续查找近乎 $O(1)$。  
   $$ \text{find}(x) = \begin{cases} x & \text{if } parent[x] = x \\ \text{find}(parent[x]) & \text{otherwise} \end{cases} $$  
   实现时可递归或迭代，递归写法更简洁且自动完成路径压缩。  
3. **合并操作**：先找到两个元素的根，若不同根，则将其中一个根设为另一个的子节点。为平衡树高，可使用按秩合并（记录树的高度或大小），但简单实现直接合并也能满足基本需求。  
   $$ \text{unionSet}(x, y): \text{rootX} = \text{find}(x), \text{rootY} = \text{find}(y); \text{if rootX} \neq \text{rootY}: parent[\text{rootX}] = \text{rootY} $$  
4. **复杂度**：经过路径压缩和按秩合并后，每次操作的平均时间复杂度近似 $O(\alpha(n))$，其中 $\alpha$ 为反阿克曼函数，可视为常数。  

**易错点**：  
- 忘记初始化 `parent` 数组，导致查找时返回随机值。  
- 查找时未使用路径压缩，导致树高过大，合并或查找效率退化。  
- 合并时直接 `parent[x] = y` 而不是先查找根，导致集合合并不完整。  
- 数组下标越界，尤其是使用 $n$ 个元素但忽略下标范围（通常从 $0$ 到 $n-1$）。  
- 递归深度过大导致栈溢出，可改用循环实现查找（但考研中递归通常可接受）。  

**命题规律**：  
并查集是408应用题常考数据结构，常见于图论（如Kruskal算法判环、无向图连通分量个数）和集合类问题（如是否属于同一集合）。变式包括：  
- 带权并查集（维护元素间关系，如距离、种类）。  
- 并查集存储集合大小或秩，用于优化或统计。  
- 与离散化结合处理大范围元素。  
复习建议：熟练掌握数组实现，理解路径压缩和按秩合并的原理，并能写出精简代码；同时能灵活运用并查集解决实际问题，如动态连通性、冗余连接等。  

**知识点**：并查集、数组、路径压缩、按秩合并

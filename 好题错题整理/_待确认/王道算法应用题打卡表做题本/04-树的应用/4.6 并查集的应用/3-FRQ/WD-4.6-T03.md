## DeepSeek V4 Flash Max 解析

**答案**：

并查集的“查”操作 `Find(S, x)` 的功能是：给定元素下标 $x$，沿着双亲链不断向上找，最终返回 $x$ 所在集合的根结点下标。实现约定：根结点存负数，非根结点存其父结点下标。

基本实现：

```c
int Find(int S[], int x) {
    while (S[x] >= 0)   // x 不是根，就继续向上找父结点
        x = S[x];
    return x;           // 此时 S[x] < 0，x 是根
}
```

若需优化，可使用带路径压缩的版本：

```c
int Find(int S[], int x) {
    if (S[x] < 0) return x;            // x 本身就是根
    int root = Find(S, S[x]);          // 先找到根
    S[x] = root;                        // 路径压缩：把 x 直接挂到根上
    return root;
}
```

路径压缩不改变集合关系，只是把查询路径上的结点直接连到根，降低后续查询代价。

**解题切入点**：

拿到并查集的 `Find`，先抓它的存储结构：数组 + 双亲表示法。

数组下标是元素编号，数组值指向“父亲”是谁；根结点没有父亲，所以存负数。  
可以理解为“找老大”：沿着“下级找上级”的链一直往上问，直到问到没有上级的人，那个人就是根老大。

所以 `Find` 的核心只有一句话：

> 不断执行 $x = S[x]$，直到 $S[x] < 0$，返回此时的 $x$。

**推演**：

设并查集数组为 $S$，约定：

- $S[i] < 0$：$i$ 是根结点；
- $S[i] \ge 0$：$i$ 的父结点是 $S[i]$。

初始化时所有元素各自成集合，所以 $S[i] = -1$。

对于 `Find(S, x)`：

1. 如果 $S[x] < 0$，说明 $x$ 已经是根，直接返回 $x$；
2. 否则令 $x \leftarrow S[x]$，继续向上找；
3. 因为树结构有限且无双亲环，最终一定会到达根结点。

循环过程可以写成：

$$
x \rightarrow S[x] \rightarrow S[S[x]] \rightarrow \cdots \rightarrow \text{根}
$$

普通 `Find` 的时间复杂度为 $O(h)$，其中 $h$ 是树高；最坏情况下树退化为链，$h = O(n)$。

若使用路径压缩，则在查找过程中把路径上所有结点的父指针直接指向根，例如：

设初始数组：

$$
S = [-1, 0, 1, 2, -1, 4, 5]
$$

表示两棵树：

$$
3 \rightarrow 2 \rightarrow 1 \rightarrow 0
$$

$$
6 \rightarrow 5 \rightarrow 4
$$

执行 `Find(S, 3)`：

- 3 不是根，到 2；
- 2 不是根，到 1；
- 1 不是根，到 0；
- 0 的 $S[0] = -1$，是根，返回 0。

路径压缩后：

$$
S[1] = 0,\quad S[2] = 0,\quad S[3] = 0
$$

树被压扁，后续查询几乎为 $O(1)$。

在“按秩合并 + 路径压缩”的经典优化下，$m$ 次操作的均摊时间复杂度为：

$$
O(m \alpha(n))
$$

其中 $\alpha(n)$ 是反阿克曼函数，增长极慢，可视为常数。

**易错点**：

1. **终止条件写错**  
   不能只判断 `S[x] != -1`，因为按大小或按高度合并时，根结点可能存 `-2`、`-3` 等负数。  
   正确写法是：

   ```c
   while (S[x] >= 0)
       x = S[x];
   ```

2. **返回值搞错**  
   `Find` 返回的是根结点下标，不是父结点下标，也不是元素本身。  
   例如元素 3 的父结点是 2，但 `Find(S, 3)` 返回的是 0，不是 2。

3. **路径压缩递归写法顺序错误**  
   必须先用变量保存递归结果，再赋值：

   ```c
   int root = Find(S, S[x]);
   S[x] = root;
   return root;
   ```

   不能写成：

   ```c
   S[x] = Find(S, S[x]);
   return x;   // 错误：x 不是根，返回了当前结点
   ```

4. **忽略越界问题**  
   如果题目没有保证 $x$ 合法，需要先判断：

   ```c
   if (x < 0 || x >= n) return -1;
   ```

   408 代码题通常默认输入合法，但实现时要有这个意识。

**命题规律**：

考点定位：并查集是 408 中常考的数据结构之一，`Find` 操作常与 `Union` 操作结合考查，也常作为 Kruskal 算法、判断连通分量等问题的子程序。

常见变式：

- 判断两个元素是否属于同一个集合：`Find(S, x) == Find(S, y)`；
- 统计集合个数：数一数数组中有多少个负数；
- 给定初始数组，模拟若干次 `Find` / `Union` 后写出最终数组；
- 路径压缩前后树高、时间复杂度的变化。

复习建议：把基本版 `Find` 和路径压缩版 `Find` 都亲手默写一遍，并在纸上模拟数组变化过程。理解根结点存负数的含义，远比死记代码重要。

## DeepSeek V4 Flash Max 解析

**答案**：  
构造一棵 **12 个结点**的树 $T$，根为 $A$，结点集合为 $\{A,B,C,D,E,F,G,H,I,J,K,L\}$。其逻辑结构如下：

```text
        A
      / | \
     B  C  D
    / \ / \ |
   E  F G H I
  /     | |
 J      K L
```

按层次编号：$0:A,\ 1:B,\ 2:C,\ 3:D,\ 4:E,\ 5:F,\ 6:G,\ 7:H,\ 8:I,\ 9:J,\ 10:K,\ 11:L$。

---

### 1. 双亲表示法

| 数组下标 | 数据 | 双亲下标 |
|---|---|---|
| 0 | A | -1 |
| 1 | B | 0 |
| 2 | C | 0 |
| 3 | D | 0 |
| 4 | E | 1 |
| 5 | F | 1 |
| 6 | G | 2 |
| 7 | H | 2 |
| 8 | I | 3 |
| 9 | J | 4 |
| 10 | K | 6 |
| 11 | L | 7 |

根结点 $A$ 没有双亲，所以双亲下标为 $-1$。

---

### 2. 孩子表示法（孩子链表表示法）

| 数组下标 | 数据 | firstchild | 孩子链表（child → next） |
|---|---|---|---|
| 0 | A | 1 | 1 → 2 → 3 → ∧ |
| 1 | B | 4 | 4 → 5 → ∧ |
| 2 | C | 6 | 6 → 7 → ∧ |
| 3 | D | 8 | 8 → ∧ |
| 4 | E | 9 | 9 → ∧ |
| 5 | F | -1 | ∧ |
| 6 | G | 10 | 10 → ∧ |
| 7 | H | 11 | 11 → ∧ |
| 8 | I | -1 | ∧ |
| 9 | J | -1 | ∧ |
| 10 | K | -1 | ∧ |
| 11 | L | -1 | ∧ |

其中 `∧` 表示空指针。每个孩子链表按从左到右的顺序存放该结点的所有孩子。

---

### 3. 孩子兄弟表示法

| 数组下标 | 数据 | firstchild | nextsibling |
|---|---|---|---|
| 0 | A | 1 | -1 |
| 1 | B | 4 | 2 |
| 2 | C | 6 | 3 |
| 3 | D | 8 | -1 |
| 4 | E | 9 | 5 |
| 5 | F | -1 | -1 |
| 6 | G | 10 | 7 |
| 7 | H | 11 | -1 |
| 8 | I | -1 | -1 |
| 9 | J | -1 | -1 |
| 10 | K | -1 | -1 |
| 11 | L | -1 | -1 |

其中：

- `firstchild`：指向该结点的最左孩子；
- `nextsibling`：指向该结点在原树中的下一个兄弟。

若将其看成二叉树，则等价于下面的二叉树：

```text
          A
         /
        B
       / \
      E   C
     / \ / \
    J  F G  D
         / \ /
        K  H I
           /
          L
```

---

**解题切入点**：  
拿到题目先画一棵结点数不少于 10 的树，并给每个结点按层次编号。之后把编号作为数组下标，再分别按“双亲是谁”“孩子有哪些”“最左孩子和下一个兄弟是谁”三个角度填表。可以类比为“给家族成员做户口登记”：双亲表示法只记父亲；孩子表示法记录儿子列表；孩子兄弟表示法记录“大儿子”和“下一个兄弟”。

---

**推演**：

1. 构造树时，先确定根，再逐层添加孩子，保证连通、无环，且结点数 $n=12\ge 10$。  
2. 为了用数组描述，给结点编号。编号顺序不影响结构，但后面所有指针都必须与编号一致。  
3. 双亲表示法：  
   - 对每个结点 $i$，记录 `parent[i]` 为双亲结点下标；  
   - 根无双亲，记为 $-1$。  
4. 孩子表示法：  
   - 表头数组存放每个结点的数据和 `firstchild`；  
   - 把每个结点的所有孩子用单链表串起来，链表结点中的 `child` 域存孩子下标，`next` 域存下一个孩子。  
5. 孩子兄弟表示法：  
   - 每个结点只有两个指针，`firstchild` 指向最左孩子，`nextsibling` 指向下一个兄弟；  
   - 这是用二叉链表存储一般树的方法，转换后的“二叉树”并不改变原树逻辑关系。

对应 C 语言结构体定义如下：

双亲表示法：

```c
typedef struct {
    char data;
    int parent;
} PTNode;
```

孩子表示法：

```c
typedef struct CNode {
    int child;
    struct CNode *next;
} CNode;

typedef struct {
    char data;
    CNode *firstchild;
} CTBox;
```

孩子兄弟表示法：

```c
typedef struct CSNode {
    char data;
    struct CSNode *firstchild;
    struct CSNode *nextsibling;
} CSNode;
```

---

**易错点**：

- 根结点的双亲下标写为 0 或写为自身，正确应为 $-1$。  
- 孩子表示法中，孩子链表里的 `next` 指向的是“下一个兄弟”，不是“孙子结点”。  
- 孩子兄弟表示法中，`nextsibling` 容易与二叉树右孩子混淆：它表示原树中的兄弟，不是父子关系。  
- 叶子结点的 `firstchild` 和 `nextsibling` 都要置空，容易漏写。  
- 编号顺序前后不一致会导致指针混乱，建议先固定编号再填表。

---

**命题规律**：  
本考点属于“树与二叉树的存储结构”，在 408 中常以选择题或应用题形式出现。常见变式有：给一棵树写出三种存储结构；由双亲数组还原树；比较求双亲、求孩子的时间复杂度；森林与二叉树转换；利用孩子兄弟表示法统计叶子结点等。复习时应自己动手画一棵结点较多的树，反复练习三种表示法之间的转换，并理解每种存储结构的优缺点。

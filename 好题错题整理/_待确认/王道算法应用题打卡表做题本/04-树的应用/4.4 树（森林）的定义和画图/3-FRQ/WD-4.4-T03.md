任务 3: (必做) 3.3.3 对比: 树的孩子表示法存储 v.s. 图的邻接表存储 v.s. 散列表的拉链法 v.s. 基数排序. 你发现了什么？

## 答案

![[_Attachments/题目识别/王道算法应用题打卡表做题本-答案/WD-4.4-T03_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：  
这四者的共同本质是 **“数组（顺序表）+ 链表”的复合结构**。具体说，都是用一个数组作为“表头/槽/桶/入口”，再让每个数组元素挂接一条链表；数组负责 $O(1)$ 定位“属于哪个集合”，链表负责动态存储该集合中数量不确定的元素。区别只在于链表表达的关系不同：

- 树的孩子表示法：数组存结点，链表存孩子；
- 图的邻接表：数组存顶点，链表存邻接点；
- 散列表拉链法：数组是散列槽，链表存同义词；
- 基数排序（链式实现）：数组是 $r$ 个桶，每个桶是一条链式队列。

所以可以总结为：**“表头数组 + 链表扩展”**，本质上都是“链地址/分桶”思想。

---

**解题切入点**：  
拿到题先别急着背定义，而要抓“存储结构共性”。这种跨章节对比题，核心问题是：

1. 数组/顺序表里存什么？
2. 链表里挂什么？
3. 数组下标起什么作用？

可以联想算法竞赛/刷题中常见的写法：

```c
int head[N];   // 每个起点/槽/桶对应一个链表头
int to[M], nxt[M];
```

这就是“数组 + 链表”的典型形态。本题目中的四个对象，本质上都长这样。

---

**推演**：  

用一张表对比它们的“数组 + 链表”结构：

| 对象 | 数组/表头部分 | 挂接的链表 | 链表表达的关系 |
|---|---|---|---|
| 树的孩子表示法 | 用数组存放 $n$ 个树结点，每个结点带 `firstchild` 指针 | 孩子链表结点存孩子下标 `child` | 双亲 → 孩子 |
| 图的邻接表 | 用顶点表存放 $n$ 个顶点，每个顶点带 `firstarc` 指针 | 边表结点存邻接点下标 `adjvex` | 顶点 → 邻接点 |
| 散列表拉链法 | 用散列表 $HT[0..m-1]$，每个槽是一个链表头指针 | 同义词结点存关键字/记录 | 散列地址 → 同义词 |
| 链式基数排序 | 用 $r$ 个桶，桶用链式队列实现，$f[i]$、$e[i]$ 分别存队头、队尾指针 | 队列结点存记录 | 关键字位 → 同一位的记录 |

四者可以抽象成统一模式：

$$
Head[0], Head[1], \dots, Head[m-1]
$$

$$
Head[i] \to Node_{i1} \to Node_{i2} \to \cdots
$$

用 C 语言表达，就是：

```c
typedef struct Node {
    int idx;                 // 孩子下标 / 邻接点下标 / 记录位置 / 记录本身
    struct Node *next;
} Node;

typedef struct Head {
    ElemType data;           // 树/图的顶点信息；散列表槽/基数排序桶可另作处理
    Node *first;             // 指向第一条链表/队列
} Head;

Head H[M];
```

进一步看：

**树的孩子表示法**可以看作“把树看成有向图，边由双亲指向孩子”后的邻接表；**图的邻接表**是它的直接推广。  
**散列表拉链法**和**链式基数排序**则都是“分桶”思想：散列表按散列函数分桶，基数排序按关键字当前位的值分桶；前者用链表解决冲突，后者用链式队列完成“分配—收集”。

因此，这四者的发现是：

> 它们都使用了“数组 + 链表”的复合存储结构。数组提供随机访问和索引，链表提供动态扩展；既避免了预分配大二维数组的空间浪费，也避免了插入/删除时大量移动元素。

---

**易错点**：  

1. **只答“链表”，丢掉“数组”**。  
   它们不只是链表，而是“数组 + 链表”的组合；数组是索引，链表是扩展。

2. **混淆“孩子表示法”和“孩子兄弟表示法”**。  
   孩子表示法是“数组 + 孩子链表”；孩子兄弟表示法是“二叉树链表”，用 `firstchild` 和 `nextsibling` 把树转为二叉树存储。

3. **混淆拉链法和开放定址法**。  
   散列表拉链法把同义词挂在同一个链表中；开放定址法是在散列表本身探测空位，不额外挂链。

4. **基数排序的桶不是“散列表桶”**。  
   基数排序的桶是“按位分类”，不是解决冲突；链式实现时必须同时保存队头和队尾指针，否则收集时需要遍历到队尾，降低效率。

---

**命题规律**：  
这是典型的跨章节综合题，考点定位在“存储结构对比”和“链式存储的通用性”。常考变式有：

- 给结构体定义，判断是树的孩子表示法、图的邻接表还是拉链法；
- 让孩子表示法和图的邻接表互相转化；
- 给一组关键字，用拉链法画散列表；
- 用基数排序写出每趟分配、收集的结果。

复习建议：把四种结构都画成“表头数组 + 链表”的示意图，记清每个数组元素是什么、每个链表结点存什么，就能以不变应万变。

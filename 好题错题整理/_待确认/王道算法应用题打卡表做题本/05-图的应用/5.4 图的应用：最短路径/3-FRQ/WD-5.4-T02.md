## 答案

![[_Attachments/题目识别/王道算法应用题打卡表做题本-答案/WD-5.4-T02_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：  
BFS 可以在**无权图**（或所有边权值相等）中求单源最短路径。从源点出发，按层扩散访问顶点，某个顶点**第一次被访问时的层数**就是从源点到该顶点的最短路径长度；同时记录前驱顶点，可还原出最短路径。用邻接表存储图时，时间复杂度为 $O(|V|+|E|)$。

**解题切入点**：  
拿到“单源最短路径”先别急着套 Dijkstra，先看图的边权：**无权图用 BFS，带权非负图用 Dijkstra，带负权图用 Bellman-Ford/SPFA**。BFS 的核心是“一层一层往外扩”，就像水面涟漪，先扩散到的岸边一定是最近的路线；而 DFS 是一条路走到黑，不能保证首次到达就是最短。

**推演**：  

设源点为 $s$，用数组 $dist[v]$ 记录 $s$ 到 $v$ 的最短距离，用 $path[v]$ 记录最短路径上 $v$ 的前驱结点。

1. 初始化：

$$
dist[v] = \begin{cases}
0, & v = s \\
+\infty, & v \ne s
\end{cases}
$$

$$
path[s] = -1
$$

创建一个空队列 $Q$，将源点 $s$ 入队。

2. BFS 主过程：

```c
while (队列Q非空) {
    u = Q出队;
    for (v in u的邻接点集合) {
        if (dist[v] == INF) {   // 相当于 v 尚未被访问
            dist[v] = dist[u] + 1;
            path[v] = u;
            Q入队(v);
        }
    }
}
```

3. 结果解释：  
算法结束后，$dist[v]$ 就是源点 $s$ 到顶点 $v$ 的最短路径长度；若 $dist[v] = \infty$，说明 $v$ 不可达。要还原最短路径，只需从目标顶点 $t$ 出发，不断取 $path[t]$ 回退到 $s$，再逆序输出即可。

4. 正确性证明：  
BFS 按层访问顶点，第 $0$ 层只有源点 $s$。假设第 $0 \sim k$ 层的所有顶点都已经被正确访问，且 $dist$ 值正确。当处理第 $k$ 层的某个顶点 $u$ 时，如果它的邻接点 $v$ 尚未被访问，那么 $v$ 不可能在第 $0 \sim k$ 层中，否则它已经被访问；同时 $v$ 与第 $k$ 层的 $u$ 相邻，所以 $s$ 到 $v$ 至少存在一条长度为 $k+1$ 的路径。因此：

$$
dist[v] = dist[u] + 1 = k + 1
$$

当第 $k$ 层的所有顶点处理完后，所有第 $k+1$ 层的顶点都会被访问。由归纳法可知，BFS 按距离从小到大访问顶点，**每个顶点第一次被发现时得到的距离一定是最短距离**。

**易错点**：  
- 不要把 BFS 用在**带权图**上，否则可能得到错误结果。例如某条路径边数少但权值大，BFS 会先访问它并标记，导致真正权值小的路径被忽略。  
- 必须用队列实现 BFS，不能用栈模拟 DFS；DFS 首次访问也不保证最短。  
- 一定要用 $dist$ 或 $visited$ 标记已访问，否则图中有环时可能重复入队，甚至死循环。  
- 记录最短路径时不要忘记维护 $path$ 数组，否则只能得到距离，无法还原路径。  
- 对于有向图，遍历的是当前顶点的**出边邻接点**，不能把反向边也当作可走路径。

**命题规律**：  
该考点属于“图的应用”中的最短路径问题，常与图的遍历结合考查。常见命题形式有：写出 BFS 后某源点到各顶点的 $dist$ 和 $path$ 数组；判断某个 BFS 序列是否对应最短路径；比较 BFS 与 Dijkstra 的适用条件；给出无向无权图求最短路径。复习时应熟练画出 BFS 分层过程，理解“第一次访问就是最短路”的原因，并注意与 DFS、Dijkstra 的区分。

**知识点**：BFS、单源最短路径、队列、图的遍历

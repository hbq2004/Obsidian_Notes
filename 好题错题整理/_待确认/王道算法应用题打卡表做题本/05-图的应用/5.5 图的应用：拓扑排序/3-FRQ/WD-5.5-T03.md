## 答案

## DeepSeek V4 Flash Max 解析

**答案**：
无向图的邻接矩阵是对称矩阵，因此压缩存储时只需保留下三角（含对角线）。判断结点 \(i,j\) 之间是否有边，就是在压缩数组中查找原邻接矩阵元素 \(A[i][j]\) 是否为 1，不需要遍历。

设顶点编号为 \(1\sim n\)，压缩数组按行优先存下三角，逻辑下标从 1 开始。令
\[
r=\max(i,j),\qquad c=\min(i,j)
\]
则 \((i,j)\) 对应的一维下标为
\[
pos=\frac{r(r-1)}2+c
\]
若 C 数组下标从 0 开始，则实际下标为
\[
k=\frac{r(r-1)}2+c-1
\]
判断：
\[
sa[k]=1 \Rightarrow \text{有边};\qquad sa[k]=0 \Rightarrow \text{无边}
\]
时间复杂度为 \(O(1)\)。

**解题切入点**：
看到“压缩存储的数组”，先定位到“特殊矩阵压缩存储”。无向图的邻接矩阵天然对称，所以不需要存 \(n^2\) 个元素，只需要存一半。判断两个结点之间是否有边，等价于查一个对称矩阵元素是否为 1。

这类题的核心思路是“二维下标转一维下标”：先通过 \(\max/\min\) 把无序的 \((i,j)\) 统一到下三角，再用等差数列求和算出偏移。就像竞赛中遇到对称的 DP 表，也常用 `r=max(i,j), c=min(i,j)` 来避免分类讨论，一次数组访问就能得到答案。

**推演**：
下三角按行优先存放时，第 1 行有 1 个元素，第 2 行有 2 个元素，第 \(t\) 行有 \(t\) 个元素。

若要查 \((i,j)\)，且 \(i\ge j\)，则前 \(i-1\) 行共有
\[
1+2+\cdots+(i-1)=\frac{i(i-1)}2
\]
个元素。第 \(i\) 行中，第 \(j\) 列是该行第 \(j\) 个元素，所以逻辑下标为
\[
pos=\frac{i(i-1)}2+j
\]

若 \(i<j\)，由对称性交换 \(i,j\) 即可。统一写成：
\[
r=\max(i,j),\qquad c=\min(i,j)
\]
\[
pos=\frac{r(r-1)}2+c
\]

C 数组中下标从 0 开始，所以要减 1：
```c
// sa[] 为下三角压缩数组，顶点编号 1~n，sa 中存 0/1
int hasEdge(int sa[], int i, int j) {
    int r = i > j ? i : j;
    int c = i < j ? i : j;
    int k = r * (r - 1) / 2 + c - 1;
    return sa[k] == 1;
}
```

例如 \((3,2)\) 下三角逻辑下标为
\[
\frac{3\times2}{2}+2=5
\]
按行优先存放下三角时，第 5 个位置确实是 \((3,2)\)，公式正确。

**易错点**：
- 忘记交换下标。若 \(i<j\) 时仍把 \(i\) 当行、\(j\) 当列，会访问到错误位置甚至越界。应统一使用 \(r=\max(i,j), c=\min(i,j)\)。
- 数组起点混淆。教材公式常按逻辑下标从 1 开始，C 语言数组下标从 0 开始，必须整体减 1。
- 压缩时是否含对角线。若之前压缩时省略了全 0 的对角线，数组长度为 \(\frac{n(n-1)}2\)，则不能直接套用上述公式；此时 \(r>c\) 的映射为
\[
pos=\frac{(r-1)(r-2)}2+c
\]
同样，若顶点编号从 0 开始，公式也要相应调整。
- 有向图不能按对称矩阵压缩。有向图邻接矩阵不一定对称，不能直接用本方法判断。

**命题规律**：
本题是“特殊矩阵压缩存储”与“图的基本操作”的结合点，属于 408 高频基础考点。常见变式有：下三角/上三角、按行/按列优先、含/不含对角线、已知 \((i,j)\) 求一维下标，或已知一维下标反求 \((i,j)\)。复习时建议画一个 \(3\sim4\) 阶小矩阵，自己推一遍映射公式，不要死记硬背。

**知识点**：
邻接矩阵、对称矩阵压缩存储、一维数组映射、图的基本操作

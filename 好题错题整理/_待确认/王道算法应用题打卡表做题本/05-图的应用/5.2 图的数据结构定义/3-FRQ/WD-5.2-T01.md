## DeepSeek V4 Flash Max 解析

**答案**：邻接矩阵实现的顺序存储图，核心是用一维数组存顶点、二维数组存边。代码如下：

```c
#define MaxVertexNum 100

typedef char VertexType;   // 顶点数据类型
typedef int EdgeType;      // 边或权值类型

typedef struct {
    VertexType Vex[MaxVertexNum];                 // 顶点表
    EdgeType Edge[MaxVertexNum][MaxVertexNum];    // 邻接矩阵
    int vexnum, arcnum;                           // 当前顶点数和边数
} MGraph;
```

说明：若为无权图，`Edge[i][j] = 1` 表示从 $i$ 到 $j$ 有边，`0` 表示无边；若为有权图，`Edge[i][j]` 存权值，无边用 `INF` 表示。

**解题切入点**：题目要求“顺序存储”且“邻接矩阵实现”，应立刻定位到图的存储结构考点。图必须保存两类信息：顶点集合和边集合。邻接矩阵就是用数组下标表示顶点编号，用矩阵元素表示边是否存在或权值大小。写代码时直接“套模板”：一维顶点数组 + 二维邻接矩阵 + 两个计数器（顶点数、边数）。好比做一个“城市直达表”：第一行/第一列是城市名，交叉处标记是否直达。

**推演**：

1. 设图 $G=(V,E)$ 有 $n$ 个顶点，将顶点编号为 $0,1,\dots,n-1$，用一维数组 `Vex[]` 保存顶点信息。
2. 用二维数组 `Edge[][]` 表示顶点之间的边关系：
   - 无权图：$Edge[i][j]=1$ 表示存在边 $(i,j)$，$Edge[i][j]=0$ 表示不存在边；
   - 有权图：$Edge[i][j]$ 保存权值，不存在边时设为 $\infty$。
3. 为了知道当前图有多少顶点和多少条边，结构体中需要维护 `vexnum` 和 `arcnum`。
4. 因此定义结构体 `MGraph`。

例如初始化一个无向无权图：

```c
void InitMGraph(MGraph *G) {
    G->vexnum = 0;
    G->arcnum = 0;
    for (int i = 0; i < MaxVertexNum; i++)
        for (int j = 0; j < MaxVertexNum; j++)
            G->Edge[i][j] = 0;   // 初始全部无边
}
```

无向图加边：

```c
G->Edge[i][j] = 1;
G->Edge[j][i] = 1;
G->arcnum++;
```

有向图加边：

```c
G->Edge[i][j] = 1;
G->arcnum++;
```

采用邻接矩阵后，判断任意两个顶点之间是否有边只需 $O(1)$ 时间，但存储空间为：

$$
S(n)=O(n^2)
$$

因此邻接矩阵适合表示稠密图。

**易错点**：

- 忘记初始化矩阵。无权图应初始化为 `0`，有权图应初始化为 `INF`，否则可能出现随机值。
- 无向图加边时只写 `Edge[i][j]=1`，忘记写 `Edge[j][i]=1`，导致矩阵不对称。
- 顶点编号不统一。建议统一从 0 开始；若题目从 1 开始，数组下标 0 通常留空。
- 结构体中漏掉 `vexnum` 和 `arcnum`，导致后续无法知道顶点数和边数。
- 把邻接矩阵与邻接表混淆。题目明确要求“顺序存储”，必须使用二维数组实现，不能写成链式邻接表。

**命题规律**：这是图章节最基础的定义题，常以“写出邻接矩阵存储结构”的形式出现，也可能后续结合 DFS、BFS、Dijkstra、Floyd、Prim、Kruskal 等算法一起考查。常见变式有：根据邻接矩阵求顶点的度、判断两个顶点是否相邻、求图的边数等。复习时要把结构体定义背熟，并理解“无向图矩阵对称，有向图矩阵不一定对称”这一核心原则。

**知识点**：图、邻接矩阵、顺序存储、结构体定义

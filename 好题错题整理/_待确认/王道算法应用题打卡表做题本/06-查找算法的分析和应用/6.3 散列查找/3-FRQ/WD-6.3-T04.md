## DeepSeek V4 Flash Max 解析

**答案**：
一种合理设计如下（开放题，答案不唯一）：

- 散列表总长度 $m=17$，下标范围 $0\sim16$，共 17 个桶；
- 散列函数：除留余数法 $H(key)=key\bmod 17$；
- 关键字集合取 $\{19,14,23,1,68,20,84,27,55,11,10,79\}$，$n=12$，装填因子 $\alpha=\dfrac{n}{m}=\dfrac{12}{17}\approx0.71$；
- 拉链法构造结果（按给定顺序尾插）：
  - 0：$68\to\wedge$
  - 1：$1\to\wedge$
  - 2：$19\to\wedge$
  - 3：$20\to\wedge$
  - 4：$55\to\wedge$
  - 5：$\wedge$
  - 6：$23\to\wedge$
  - 7：$\wedge$
  - 8：$\wedge$
  - 9：$\wedge$
  - 10：$27\to10\to\wedge$
  - 11：$11\to79\to\wedge$
  - 12：$\wedge$
  - 13：$\wedge$
  - 14：$14\to\wedge$
  - 15：$\wedge$
  - 16：$84\to\wedge$
- 查找成功：$ASL_{succ}=\dfrac{7}{6}\approx1.17$；
- 查找失败：$ASL_{fail}=\dfrac{29}{17}\approx1.71$。

**解题切入点**：
拿到这种开放设计题，先抓住三要素：散列表长度、散列函数、冲突解决方法。题目已经指定用拉链法，因此核心变成“设计一个长度合理、散列效果好的表，并模拟冲突链”。

散列函数优先考虑除留余数法 $H(key)=key\bmod m$，且表长 $m$ 通常取质数，这样能有效减少规律性聚集。这就像算法竞赛里要设计一个均匀映射，把尽量多的数据“打散”到不同位置；拉链法相当于每个位置挂一条链表，冲突后在同一条链上继续查找。

**推演**：
1. 选取 $m=17$。因为关键字个数 $n=12$ 时，装填因子 $\alpha=12/17\approx0.71$，既不会太稀疏浪费空间，也不会太拥挤；且 17 是质数，适合做除留余数法的模数。

2. 计算各关键字的散列地址：
   $$19\to2,\ 14\to14,\ 23\to6,\ 1\to1,\ 68\to0,\ 20\to3,$$
   $$84\to16,\ 27\to10,\ 55\to4,\ 11\to11,\ 10\to10,\ 79\to11.$$

   可以看到 $27$ 与 $10$ 都映射到地址 10，$11$ 与 $79$ 都映射到地址 11，发生冲突；其余关键字各自独占一个桶。

3. 使用拉链法解决冲突，按给定顺序尾插后，桶中链表为：
   - 地址 0：$68\to\wedge$
   - 地址 1：$1\to\wedge$
   - 地址 2：$19\to\wedge$
   - 地址 3：$20\to\wedge$
   - 地址 4：$55\to\wedge$
   - 地址 6：$23\to\wedge$
   - 地址 10：$27\to10\to\wedge$
   - 地址 11：$11\to79\to\wedge$
   - 地址 14：$14\to\wedge$
   - 地址 16：$84\to\wedge$
   - 地址 5、7、8、9、12、13、15 为空。

4. 计算查找成功平均查找长度。设每个关键字等概率被查找：
   - 8 条长度为 1 的链，每个元素比较 1 次，共 $8\times1=8$；
   - 2 条长度为 2 的链，每条链中两个元素分别比较 1 次、2 次，共 $2\times(1+2)=6$。

   所以：
   $$ASL_{succ}=\frac{8+6}{12}=\frac{14}{12}=\frac{7}{6}\approx1.17.$$

5. 计算查找失败平均查找长度。按考试常用口径，失败关键字的散列地址等概率落在 $0\sim16$，且最后一次需要判空指针：
   - 7 个空桶，失败时比较 1 次；
   - 8 个单元素桶，失败时比较 2 次；
   - 2 个双元素桶，失败时比较 3 次。

   因此：
   $$ASL_{fail}=\frac{7\times1+8\times2+2\times3}{17}=\frac{29}{17}\approx1.71.$$

6. 拉链法下，插入、查找、删除的平均时间复杂度均为 $O(1)$，最坏情况为 $O(n)$。删除时只需在链表中摘除对应结点，不需要像开放定址法那样做“删除标记”。

核心操作可用如下 C 代码表示：
```c
#include <stdio.h>
#include <stdlib.h>

#define M 17

typedef struct Node {
    int key;
    struct Node *next;
} Node;

Node *hashTable[M] = {NULL};

int H(int key) {
    return key % M;
}

Node *hashSearch(int key) {
    int addr = H(key);
    Node *p = hashTable[addr];
    while (p != NULL && p->key != key) {
        p = p->next;
    }
    return p;
}

void hashInsert(int key) {
    if (hashSearch(key) != NULL) return; // 不插入重复关键字
    int addr = H(key);
    Node *t = (Node*)malloc(sizeof(Node));
    t->key = key;
    t->next = NULL;
    if (hashTable[addr] == NULL) {
        hashTable[addr] = t;
    } else {
        Node *p = hashTable[addr];
        while (p->next != NULL) {
            p = p->next;
        }
        p->next = t;
    }
}
```

**易错点**：
- 表长取合数，例如 $m=12$，若关键字都是偶数，则 $key\bmod12$ 的余数也必为偶数，会导致一半桶空、冲突加剧；应优先取质数。
- 散列函数中使用的模数必须与表长一致，不能表长为 17 却写 $H(key)=key\bmod13$。
- 画拉链法示意图时，数组元素应存链表头指针，而不是直接存第一个数据元素；空桶应画 $\wedge$ 或 NULL。
- 成功 ASL 的分母是元素个数 $n$，失败 ASL 的分母是表长 $m$，二者不能混淆。
- 失败 ASL 漏算“判空指针”的一次比较，导致空桶算 0、非空桶少算 1。
- 拉链法可以直接删除结点；不要和线性探测法“不能随意删除”搞混。

**命题规律**：
散列表是 408 高频考点，常以选择题或应用题形式出现，核心是构造散列表、计算平均查找长度、比较不同冲突处理方法。

常见变式有：
- 给定关键字和散列函数，分别用线性探测法、平方探测法、拉链法构造散列表；
- 计算查找成功和查找失败的 ASL；
- 分析装填因子对查找效率的影响；
- 讨论开放定址法与拉链法删除操作的差异。

复习建议：熟练掌握除留余数法，理解“表长取质数”的原因；会手动画拉链法示意图；能快速计算成功/失败 ASL；理解拉链法在删除和空间利用上的优势。

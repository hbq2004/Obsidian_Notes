## DeepSeek V4 Flash Max 解析

**答案**：本题是开放性自创题，答案不唯一。下面给出一个满足“多层小括号、中括号”要求的算术表达式：
$$
E=\left[\,(15+3)\times\left(8-\left[(2+1)\times4\right]\right)\,\right]\div\left(6+\left[2\times(9-5)\right]\right)
$$
该表达式共有 $8$ 对括号（小括号 $5$ 对、中括号 $3$ 对），最大嵌套深度为 $4$。用栈进行括号匹配后，所有括号均正确配对，表达式合法。若进一步求值，$E=-\dfrac{36}{7}$。

**解题切入点**：拿到“自己出题”这种开放任务，先想清楚它想考什么：带多层括号的算术表达式，考点就是栈的经典应用——括号匹配。可以把自己想象成编译器：遇到左括号就“压箱底”（入栈），遇到右括号只能和“最上面”的左括号配对（弹栈）。自创表达式时不要随手乱写，而要从匹配规则反向构造：先想好嵌套几层，再写出表达式，最后用栈手动验证一遍。

**推演**：

### 1. 自创表达式

$$
E=\left[\,(15+3)\times\left(8-\left[(2+1)\times4\right]\right)\,\right]\div\left(6+\left[2\times(9-5)\right]\right)
$$

该表达式中既有小括号 `()`，又有中括号 `[]`，并且出现了
$$[\,(\,(\,(\,\cdots\,)\,)\,)\,]$$
这种多层嵌套结构。

### 2. 提取括号序列

忽略数字和运算符，只保留括号，得到括号序列：
$$
[ \quad ( \quad ) \quad ( \quad [ \quad ( \quad ) \quad ] \quad ) \quad ] \quad ( \quad [ \quad ( \quad ) \quad ] \quad )
$$
共 $16$ 个括号符号，即 $8$ 对括号。

### 3. 括号匹配算法

从左到右扫描表达式：

- 遇到左括号 `(` 或 `[`，将其入栈；
- 遇到右括号 `)` 或 `]` 时：
  - 若栈空，说明右括号多余，匹配失败；
  - 否则弹出栈顶符号，判断是否同型：`(` 配 `)`，`[` 配 `]`，不同型则匹配失败；
- 扫描结束后，若栈空则全部匹配成功，否则说明存在未配对的左括号，匹配失败。

C 语言实现如下：

```c
#include <stdio.h>
#define MAXSIZE 100

typedef struct {
    char data[MAXSIZE];
    int top;
} SqStack;

void InitStack(SqStack *S) {
    S->top = -1;
}

int Push(SqStack *S, char x) {
    if (S->top == MAXSIZE - 1) return 0;   /* 栈满 */
    S->data[++S->top] = x;
    return 1;
}

int Pop(SqStack *S, char *x) {
    if (S->top == -1) return 0;            /* 栈空 */
    *x = S->data[S->top--];
    return 1;
}

int isMatch(char left, char right) {
    return (left == '(' && right == ')') ||
           (left == '[' && right == ']');
}

int bracketMatch(const char *expr) {
    SqStack S;
    InitStack(&S);
    for (int i = 0; expr[i] != '\0'; i++) {
        char c = expr[i];
        if (c == '(' || c == '[') {
            if (!Push(&S, c)) return 0;    /* 栈满，匹配失败 */
        } else if (c == ')' || c == ']') {
            char top;
            if (!Pop(&S, &top)) return 0;  /* 右括号多余 */
            if (!isMatch(top, c)) return 0; /* 类型不匹配 */
        }
        /* 数字、空格、运算符直接跳过 */
    }
    return S.top == -1;                    /* 栈空则全部匹配 */
}

int main() {
    char expr[] = "[ (15+3)*(8-[(2+1)*4]) ]/(6+[2*(9-5)])";
    if (bracketMatch(expr))
        printf("括号匹配，表达式合法。\n");
    else
        printf("括号不匹配，表达式非法。\n");
    return 0;
}
```

### 4. 手动模拟栈过程

只跟踪括号符号，数字和运算符跳过：

| 步骤 | 当前符号 | 栈操作 | 栈内容（自底向上） | 结果 |
|---|---|---|---|---|
| 1 | `[` | 入栈 | `[` | 继续 |
| 2 | `(` | 入栈 | `[ (` | 继续 |
| 3 | `)` | 弹出 `(` 并匹配 | `[` | 匹配 |
| 4 | `(` | 入栈 | `[ (` | 继续 |
| 5 | `[` | 入栈 | `[ ( [` | 继续 |
| 6 | `(` | 入栈 | `[ ( [ (` | 继续 |
| 7 | `)` | 弹出 `(` 并匹配 | `[ ( [` | 匹配 |
| 8 | `]` | 弹出 `[` 并匹配 | `[ (` | 匹配 |
| 9 | `)` | 弹出 `(` 并匹配 | `[` | 匹配 |
| 10 | `]` | 弹出 `[` 并匹配 | 空 | 匹配 |
| 11 | `(` | 入栈 | `(` | 继续 |
| 12 | `[` | 入栈 | `( [` | 继续 |
| 13 | `(` | 入栈 | `( [ (` | 继续 |
| 14 | `)` | 弹出 `(` 并匹配 | `( [` | 匹配 |
| 15 | `]` | 弹出 `[` 并匹配 | `(` | 匹配 |
| 16 | `)` | 弹出 `(` 并匹配 | 空 | 匹配 |

扫描结束后栈为空，说明所有括号全部正确配对。最大栈深出现在第 6 步，栈内有 4 个左括号，故最大嵌套深度为 $4$。

**易错点**：

- **只数括号对数、不判类型和顺序**：例如 `[(])`，左右括号数量相等但非法，因为 `]` 需要匹配栈顶的 `(`，而栈顶却不是 `[`。必须“同型配对、就近配对”。
- **右括号先于左括号出现**：如 `)(`，扫描到第一个 `)` 时栈为空。此时必须先判断栈空，再弹栈，否则会下溢出错。
- **扫描结束后忘记检查栈是否为空**：如 `(()`，扫描过程中看似正常，但最后栈中残留一个 `(`，表达式仍然非法。
- **中英文括号混用**：全角 `（`、`）` 与半角 `()` 不是同一字符，自创表达式时要统一使用半角符号。
- **代码边界处理不当**：顺序栈实现时要处理栈满和栈空两种情况，408 代码题常在这里设坑。

**命题规律**：本题的考点是栈“后进先出”特性的经典应用——括号匹配，属于 408 数据结构栈和队列章节的高频基础题。常见变式有：判断含 `()[]{}` 的括号序列是否合法；给定入栈序列判断某个出栈序列是否可能；中缀表达式转后缀表达式、表达式求值；用栈模拟递归等。复习建议：不仅要会做题，还要能自己构造测试用例并手算栈的状态变化，做到“给一个表达式能写出匹配过程，给一个匹配算法能默写代码”。

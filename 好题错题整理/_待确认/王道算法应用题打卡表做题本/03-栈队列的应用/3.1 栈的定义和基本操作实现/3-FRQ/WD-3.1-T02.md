## DeepSeek V4 Flash Max 解析

**答案**：按常见顺序栈定义（`top` 指向栈顶元素，初始为 `-1`）实现四个基本操作。  
```c
#include <stdbool.h>

#define MaxSize 50
typedef int ElemType;   // 示例，可替换为其他类型

typedef struct {
    ElemType data[MaxSize];
    int top;            // top 指向栈顶元素，空栈时 top = -1
} SqStack;

// 初始化栈（通常需要）
void InitStack(SqStack *S) {
    S->top = -1;
}

// 判空
bool StackEmpty(SqStack S) {
    return S.top == -1;
}

// 判满
bool StackFull(SqStack S) {
    return S.top == MaxSize - 1;
}

// 入栈
bool Push(SqStack *S, ElemType x) {
    if (S->top == MaxSize - 1)   // 栈满
        return false;
    S->data[++S->top] = x;       // 先 top 加 1，再存入元素
    return true;
}

// 出栈
bool Pop(SqStack *S, ElemType *x) {
    if (S->top == -1)            // 栈空
        return false;
    *x = S->data[S->top--];      // 先取栈顶元素，再 top 减 1
    return true;
}
```

**解题切入点**：拿到题先抓住栈的存储结构——顺序栈本质是“数组 + 栈顶指针”。本题的考点就是围绕 `top` 指针展开：判空、判满看 `top` 与边界的关系；入栈、出栈是“移动 `top` + 操作数据”的组合。可以把顺序栈想象成子弹弹匣：压子弹入栈时先看是否装满，装填后弹匣指针上移；退子弹出栈时先看是否为空，取出后弹匣指针下移。核心就是“先判边界，再动指针”。

**推演**：设顺序栈最大容量为 $n$（即 `MaxSize`），数组下标为 $0 \sim n-1$。本实现约定 `top` 指向栈顶元素，初始时栈为空，令 $top = -1$。

- **判空条件**：栈中无任何元素，等价于 $top = -1$，即 `S.top == -1`。
- **判满条件**：数组中 $n$ 个位置全部被占用，此时栈顶元素在下标 $n-1$ 处，即 $top = n-1$，即 `S.top == MaxSize - 1`。
- **入栈操作**：必须保证栈未满。执行两步：  
  \[
  top := top + 1,\quad data[top] := x
  \]  
  合并为一步：`S->data[++S->top] = x`。先自增 `top` 再赋值，顺序不能颠倒。
- **出栈操作**：必须保证栈非空。执行两步：  
  \[
  x := data[top],\quad top := top - 1
  \]  
  合并为一步：`*x = S->data[S->top--]`。先取值再自减 `top`，顺序不能颠倒。

四个操作均只涉及常数次基本运算，因此时间复杂度均为 $O(1)$。

**易错点**：
- 入栈/出栈前忘记判满/判空，导致数组越界。
- 入栈写成 `data[top++] = x`，出栈写成 `x = data[--top]`，使 `top` 指向错误位置，元素覆盖或读取错误。
- 修改栈内容的函数（入栈、出栈）没有传结构体指针，导致形参改变而实参不变。
- 出栈时不用指针参数带回元素，导致栈空时无法安全返回。
- 初始化时忘记令 `top = -1`，产生未知初值。
- 若改约定 `top` 指向栈顶元素的下一个位置，则判空为 `top == 0`，判满为 `top == MaxSize`，入栈为 `data[top++] = x`，出栈为 `x = data[--top]`；注意与本题约定区分。

**命题规律**：本题是顺序栈基础操作，属于“栈”章节的必会内容。常考变式包括：`top` 不同初始含义下的判空判满条件；共享栈如何设计及判断栈满；链栈的实现；括号匹配、表达式求值等栈的应用题。复习时应熟练掌握“先判空/满，再操作指针”的模板，并能快速写出顺序栈、链栈的基本操作。在 408 真题中，这类代码题常与队列、循环队列对比考查，注意区分栈“一端操作”和队列“一端入一端出”的边界差异。

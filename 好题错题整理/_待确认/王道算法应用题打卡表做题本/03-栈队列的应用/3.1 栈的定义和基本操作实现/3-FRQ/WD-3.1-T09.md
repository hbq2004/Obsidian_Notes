## DeepSeek V4 Flash Max 解析

**答案**：  
使用栈进行括号匹配的基本过程是：初始化一个空栈；从左到右扫描表达式中的每个字符；若遇到左括号（如 `(`、`[`、`{`），将其压入栈顶；若遇到右括号（如 `)`、`]`、`}`），先检查栈是否为空：若栈空，则说明右括号多余，匹配失败；若栈非空，则取出栈顶元素，判断该栈顶左括号是否与当前右括号类型匹配：若匹配，则弹出栈顶元素，继续扫描；若不匹配，则说明括号交叉嵌套，匹配失败。扫描完整个表达式后，若栈为空，则所有括号正确匹配；若栈非空，则说明有左括号未被匹配，匹配失败。

**解题切入点**：  
看到“括号匹配”，应立刻联想到栈的“后进先出”特性。括号匹配的核心规律是：一个右括号必须与它前面最近的一个尚未匹配的左括号配对。这正好与栈顶元素“最后压入、最先弹出”的特点吻合。可以类比“消消乐”游戏：每个右括号出现时，试图“消除”栈顶对应的左括号，消除成功则继续，否则失败。因此解题时先建立“遇左压栈、遇右弹栈并检查类型”的框架，再模拟几个典型例子即可。

**推演**：  
设表达式为 $S$，长度为 $n$，用栈 $stack$ 保存左括号。定义匹配函数：
\[
\text{match}(left, right)=
\begin{cases}
\text{true}, & (left,right) \in \{('(',')'),('[',']'),('\{','\}')\}\\
\text{false}, & \text{otherwise}
\end{cases}
\]

算法步骤：
1. 初始化空栈 $stack$。
2. 令 $i=0$；当 $i<n$ 时，执行：
   - 若 $S[i]$ 是左括号，则 `push(S[i])`。
   - 若 $S[i]$ 是右括号：
     - 若 `stack` 为空，则匹配失败，返回 false（右括号多余）。
     - 否则，设 $top$ 为栈顶元素，若 $\text{match}(top, S[i])$ 为 true，则 `pop()`；否则匹配失败，返回 false（类型不匹配）。
   - $i \leftarrow i+1$。
3. 扫描结束后，若 `stack` 为空，则匹配成功；否则匹配失败（左括号多余）。

以表达式 `{[()]}` 为例，栈的变化如下表：

| 扫描字符 | 操作 | 栈内容（栈底→栈顶） |
|---|---|---|
| `{` | 左括号入栈 | `{` |
| `[` | 左括号入栈 | `{[` |
| `(` | 左括号入栈 | `{[(` |
| `)` | 与栈顶 `(` 匹配，弹出 | `{[` |
| `]` | 与栈顶 `[` 匹配，弹出 | `{` |
| `}` | 与栈顶 `{` 匹配，弹出 | 空 |

扫描结束栈空，匹配成功。

再以表达式 `{[(])}` 为例：

| 扫描字符 | 操作 | 栈内容（栈底→栈顶） |
|---|---|---|
| `{` | 左括号入栈 | `{` |
| `[` | 左括号入栈 | `{[` |
| `(` | 左括号入栈 | `{[(` |
| `]` | 当前右括号是 `]`，栈顶是 `(`，类型不匹配，失败 | 匹配失败 |

因此该表达式不匹配。

对应 C 语言核心代码（示意）：

```c
#include <stdio.h>
#include <string.h>
#define MAXSIZE 100

char stack[MAXSIZE];
int top = -1;

int match(char left, char right) {
    return (left == '(' && right == ')') ||
           (left == '[' && right == ']') ||
           (left == '{' && right == '}');
}

int check(const char *s) {
    int n = strlen(s);
    for (int i = 0; i < n; i++) {
        if (s[i] == '(' || s[i] == '[' || s[i] == '{') {
            if (top == MAXSIZE - 1) return 0; // 栈满
            stack[++top] = s[i];
        } else if (s[i] == ')' || s[i] == ']' || s[i] == '}') {
            if (top == -1) return 0; // 栈空，右括号多余
            if (match(stack[top], s[i])) {
                top--;
            } else {
                return 0; // 类型不匹配
            }
        }
        // 其他字符忽略
    }
    return top == -1; // 栈空则匹配
}
```

**易错点**：  
- 只统计左右括号数量相等就认为匹配，忽略了类型和顺序，如 `([)]` 左右数量相等但实际不匹配。  
- 遇到右括号时先弹栈再判断栈空，导致对空栈执行 pop 出错；应先检查栈空，再取栈顶。  
- 匹配后忘记弹出栈顶，导致后续比较错误。  
- 匹配类型时写反，例如把 `match` 参数顺序弄反，或误认为 `(` 应与 `]` 匹配。  
- 扫描结束后不检查栈是否为空，导致忽略了左括号多余的情况，如 `(()`。  
- 忽略非括号字符时没有跳过，导致错误判断。

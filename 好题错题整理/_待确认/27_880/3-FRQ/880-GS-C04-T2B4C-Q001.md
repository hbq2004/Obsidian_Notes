# FRQ 第 1 题

![[_Attachments/题目识别/880-GS/880-GS-C04-T2B4C-Q001_题目.png|题目]]

(1) 求平行于平面 $x + y + z = 9$ 且与球面 $x^2 + y^2 + z^2 = 4$ 相切的平面方程.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C04-T2B4C-Q001_答案.png|答案]]

## V4 Pro Max 解析

**考点**：平面方程与点到平面的距离。

**解**

与平面 $x+y+z=9$ 平行的平面族为
$$x+y+z=d.$$
与球面 $x^2+y^2+z^2=4$ 相切，即球心 $O(0,0,0)$ 到平面的距离等于半径 $2$：
$$\frac{|d|}{\sqrt{1^2+1^2+1^2}}=2\ \Rightarrow\ d=\pm2\sqrt3.$$

**答案**：$x+y+z=2\sqrt3$ 与 $x+y+z=-2\sqrt3$。

**易错点**：平行平面只改常数项 $d$；距离公式分母是法向量模长 $\sqrt3$ 而非 3；$d$ 有正负两解，勿漏。

# FRQ 第 1 题

![[_Attachments/题目识别/880-GS/880-GS-C08-T2B4C-Q001_题目.png|题目]]


(1) 判别下列级数的敛散性:

(I) $\sum\limits_{n=1}^{\infty} \frac{n^{\frac{1}{n}}}{\left( n + \frac{1}{n} \right)^{n}}$

(II) $\sum\limits_{n=1}^{\infty} \frac{a^{n}}{n^{p}} (a > 0, p > 0);$

(III) $\sum\limits_{n=1}^{\infty} \frac{1}{\int_{0}^{n} \sqrt{1 + x^{3}} \, dx};$

(IV) $\sum\limits_{n=1}^{\infty} \left( a^{\frac{1}{n}} - a^{\frac{1}{n+1}} \right) (a > 0);$

(V) $\sum\limits_{n=1}^{\infty} \left[ \frac{1}{n} - \ln \left( 1 + \frac{1}{n} \right) \right]$;

(VI) $\sum\limits_{n=1}^{\infty} \left( \sqrt[n]{a} - \sqrt{1 + \frac{1}{n}} \right) (a > 0)$.

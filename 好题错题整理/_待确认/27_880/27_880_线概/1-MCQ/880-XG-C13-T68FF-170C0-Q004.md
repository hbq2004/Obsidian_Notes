# MCQ 第 4 题

![[_Attachments/题目识别/880-XG/880-XG-C13-T68FF-170C0-Q004_题目.png|题目]]

(4) 设三个不同平面的方程为 $a_{i1}x + a_{i2}y + a_{i3}z = b_i (i = 1, 2, 3)$ 相交于一条直线，三个平面方程组成方程组的系数矩阵和增广矩阵分别记为 $A$ 和 $\overline{A}$，则（）。

A. $r(A) = 2, r(\overline{A}) = 2$ B. $r(A) = 2, r(\overline{A}) = 3$ C. $r(A) = 1, r(\overline{A}) = 2$ D. $r(A) = 1, r(\overline{A}) = 1$

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C13-T68FF-170C0-Q004_答案.png|答案]]

## V4 Pro Max 解析

**考点**：三平面交于一条直线时系数矩阵与增广矩阵的秩。

**解**

三个平面交于一条直线 $\Longleftrightarrow$ 方程组 $Ax=b$ 的解集为一条直线（1 维仿射空间），即

$$r(A)=r(\overline A)=2.$$

- 若 $r(A)=r(\overline A)=2$：有解且解空间维数 $3-2=1$，解集为直线，恰为"三平面交于一条直线"；
- 若 $r(A)=2,\ r(\overline A)=3$：$r(A)\ne r(\overline A)$，无解（三平面两两相交但无公共点等情形）；
- 若 $r(A)=1,\ r(\overline A)=2$：无解（平面平行或部分平行）；
- 若 $r(A)=r(\overline A)=1$：三平面重合为同一平面，交线不是一条直线。

题设三个平面**不同**且交于一条直线，故 $r(A)=r(\overline A)=2$。

**答案**：A。$r(A)=2,\ r(\overline A)=2$。

**易错点**：平面交线的维数与解空间维数对应——解空间 1 维才是直线；"三个平面不同"排除了重合的 $r(A)=1$ 情形。

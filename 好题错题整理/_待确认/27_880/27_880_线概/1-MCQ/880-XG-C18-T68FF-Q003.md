# MCQ 第 3 题

![[_Attachments/题目识别/880-XG/880-XG-C18-T68FF-Q003_题目.png|题目]]

(3) 设随机变量 $X_1$ 与 $X_2$ 同分布，$Y_1$ 与 $Y_2$ 同分布，则().

A. $X_1 + Y_1$ 与 $X_2 + Y_2$ 同分布

B. $X_1 - Y_1$ 与 $X_2 - Y_2$ 同分布

C. $(X_1, Y_1)$ 与 $(X_2, Y_2)$ 同分布

D. $kX_1$ 与 $kX_2$ 同分布，$kY_1$ 与 $kY_2$ 同分布 (常数 $k \neq 0$)

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C18-T68FF-Q003_答案.png|答案]]

## V4 Pro Max 解析

**考点**：同分布不等于联合分布相同——"边缘同分布"只能推出"函数的边缘同分布"。

**解**

题干只给 $X_1$ 与 $X_2$ 同分布、$Y_1$ 与 $Y_2$ 同分布，未给 $(X_1,Y_1)$ 与 $(X_2,Y_2)$ 的联合分布关系。

A：$X_1+Y_1$ 与 $X_2+Y_2$ 的分布取决于联合分布，可不同（例：取 $X_1\perp Y_1$ 而 $Y_2=X_2$ 时 $X_2+Y_2$ 与 $X_1+Y_1$ 分布一般不同），错。

B：同理，错。

C：$(X_1,Y_1)$ 与 $(X_2,Y_2)$ 同分布需要联合分布相同，边缘同分布不能保证，错。

D：$kX_1$ 与 $kX_2$ 分别是 $X_1,X_2$ 的（可测）函数，同分布的随机变量经同一可测函数作用后仍同分布；同理 $kY_1$ 与 $kY_2$ 同分布 ✓。

**答案**：D。

**易错点**：本题核心是"边缘同分布 $\nRightarrow$ 联合同分布、也不保证和的分布相同"；选项 D 只涉及单变量函数的分布，由同分布变量的函数仍同分布直接成立，$k\neq0$ 保证可测变换一一性无关紧要。

# MCQ 第 7 题

![[_Attachments/题目识别/880-XG/880-XG-C19-T68FF-6AE8F-Q007_题目.png|题目]]

(7) 设随机变量 $X_1 \sim B(1, p)$, $X_2 \sim B(2, p)$ ($0 < p < 1$)，且 $X_1$ 与 $X_2$ 相互独立，记 $Z_1 = 2X_1 + X_2$，$Z_2 = X_1 - X_2$，则 ( )。

A. $Z_1$ 与 $Z_2$ 不相关，$Z_1$ 与 $Z_2$ 相互独立
B. $Z_1$ 与 $Z_2$ 不相关，$Z_1$ 与 $Z_2$ 不相互独立
C. $Z_1$ 与 $Z_2$ 相关，$Z_1$ 与 $Z_2$ 相互独立
D. $Z_1$ 与 $Z_2$ 相关，$Z_1$ 与 $Z_2$ 不相互独立

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C19-T68FF-6AE8F-Q007_答案.png|答案]]

## V4 Pro Max 解析

**考点**：线性组合的协方差计算(不相关判定),以及对"函数相关必不独立"的判别。

**解**
$X_1\sim B(1,p)$,$X_2\sim B(2,p)$ 独立,则 $DX_1=p(1-p)$,$DX_2=2p(1-p)$,且 $0<p<1$ 时 $p(1-p)>0$。
$$\operatorname{Cov}(Z_1,Z_2)=\operatorname{Cov}(2X_1+X_2,\ X_1-X_2)$$
$$=2DX_1-2\operatorname{Cov}(X_1,X_2)+\operatorname{Cov}(X_2,X_1)-DX_2=2DX_1-DX_2=2p(1-p)-2p(1-p)=0,$$
故 $Z_1$ 与 $Z_2$ **不相关**。

再看独立性。$Z_1=0\iff X_1=0,X_2=0$,故 $P\{Z_1=0\}=(1-p)(1-p)^2=(1-p)^3$。而
$$P\{Z_2=0\}=P\{X_1=X_2\}=P\{(0,0)\}+P\{(1,1)\}=(1-p)^3+2p^2(1-p),$$
$$P\{Z_1=0,Z_2=0\}=P\{X_1=0,X_2=0\}=(1-p)^3.$$
若独立则须 $P\{Z_1=0,Z_2=0\}=P\{Z_1=0\}P\{Z_2=0\}$,即 $1=(1-p)[(1-p)^2+2p^2]$,对一般 $p\in(0,1)$ 不成立(例如 $p=\frac12$ 时左边 $=1$,右边 $=\frac12(\frac14+\frac12)=\frac38$)。故不独立。

选 $\boxed{B}$。

**答案**：B。

**易错点**：协方差为 0(不相关)只说明无线性关系,$Z_1,Z_2$ 都是 $X_1,X_2$ 的复合函数,检验独立性要找联合概率与边缘概率乘积不等的事件,不能凭"不相关"下结论。

# MCQ 第 3 题

![[_Attachments/题目识别/880-XG/880-XG-C10-T68FF-Q003_题目.png|题目]]

(3)设3阶矩阵 $A=\left(a_{ij}\right)_{3\times3}$ 满足 $A^{T}=kA^{*}(k>0)$，若 $a_{11}=a_{12}=a_{13}=c>0$，则 $c=$(\_)

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C10-T68FF-Q003_答案.png|答案]]

## V4 Pro Max 解析

**考点**：$A^T = kA^*$ 两边取行列式 + 首行元素与对应代数余子式的关系,联立求 $c$。

**解**
对 $A^T = kA^*$ 两边取行列式($A$ 为 3 阶):
$$|A| = |A^T| = k^3|A^*| = k^3|A|^2 \implies |A|\big(k^3|A| - 1\big) = 0.$$

若 $|A| = 0$,则 $A$ 奇异,3 阶奇异矩阵的伴随 $A^*$ 的秩 $\le 1$,故 $A^T = kA^*$ 的秩 $\le 1$,与首行 $(c,c,c) \neq 0$ 矛盾。所以 $|A| \neq 0$,从而
$$|A| = \frac{1}{k^3}.$$

由 $A^T = kA^*$ 的 $(j,1)$ 分量($A_{1j}$ 为 $a_{1j}$ 的代数余子式):
$$a_{1j} = kA_{1j},\qquad j = 1,2,3,$$
即 $A_{11} = A_{12} = A_{13} = \dfrac{c}{k}$。沿第一行展开 $|A|$:
$$|A| = a_{11}A_{11} + a_{12}A_{12} + a_{13}A_{13} = c\cdot\frac{3c}{k} = \frac{3c^2}{k} = \frac{1}{k^3},$$
$$c^2 = \frac{1}{3k^2} \implies c = \frac{1}{k\sqrt3}\quad(c > 0).$$

**答案**：$c = \dfrac{1}{k\sqrt3}$(若原书取 $k = 1$,即 $A^T = A^*$ 情形,则 $c = \dfrac{1}{\sqrt3}$)。

**易错点**：先排除 $|A| = 0$(秩矛盾),再用 $|A| = k^3|A|^2$ 得 $|A| = 1/k^3$;第一行三个代数余子式均为 $c/k$ 是关键;$c > 0$ 用于取正根。

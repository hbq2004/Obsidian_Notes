# MCQ 第 4 题

![[_Attachments/题目识别/880-XG/880-XG-C19-T68FF-Q004_题目.png|题目]]

(4) 设 $(X, Y)$ 服从二维正态分布，则 $U = X + Y$ 与 $V = X - Y$ 不相关的充分必要条件是 ( )。

A. $EX = EY$

B. $E(X^2) = E(Y^2)$

C. $E(X^2) + (EY)^2 = E(Y^2) + (EX)^2$

D. $E(X^2) + (EX)^2 = E(Y^2) + (EY)^2$

```$latex
\begin{option}
A.$ $ EX = EY 
B. $ $E(X^2) = E(Y^2) 
C.$ $ E(X^2) + (EY)^2 = E(Y^2) + (EX)^2 
D. $ $E(X^2) + (EX)^2 = E(Y^2) + (EY)^2 
\end{option}$
```

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C19-T68FF-Q004_答案.png|答案]]

## V4 Pro Max 解析

**考点**：二维正态分布下线性组合的协方差:$U=X+Y$ 与 $V=X-Y$ 不相关 $\iff DX=DY$。

**解**
$U=X+Y$,$V=X-Y$:
$$\operatorname{Cov}(U,V)=\operatorname{Cov}(X+Y,X-Y)=DX-\operatorname{Cov}(X,Y)+\operatorname{Cov}(Y,X)-DY=DX-DY.$$
故 $U$ 与 $V$ 不相关 $\iff \operatorname{Cov}(U,V)=0\iff DX=DY$。

又 $DX=E(X^2)-(EX)^2$,$DY=E(Y^2)-(EY)^2$,所以
$$DX=DY\iff E(X^2)-(EX)^2=E(Y^2)-(EY)^2\iff E(X^2)+(EY)^2=E(Y^2)+(EX)^2.$$

选 $\boxed{D}$。

**答案**：D。

**易错点**：二维正态分布中"不相关 $\iff$ 独立",但本题只问不相关的充要条件;方差相等要展开成二阶矩等式,注意 C 是 $E(X^2)+(EY)^2$ 与 $E(Y^2)+(EX)^2$ 配对(即 $DX=DY$),D 才是正确形式。

# MCQ 第 1 题

![[_Attachments/题目识别/880-XG/880-XG-C17-T68FF-Q001_题目.png|题目]]

(1) 设随机变量 $X_1$ 与 $X_2$ 的分布函数分别为 $F_1(x)$ 与 $F_2(x)$, $F(x) = aF_1(x) - bF_2(x)$ 是某一随机变量的分布函数, 则().

A. $a = \frac{3}{5}$, $b = -\frac{2}{5}$
B. $a = \frac{2}{3}$, $b = \frac{2}{3}$
C. $a = -\frac{1}{2}$, $b = \frac{3}{2}$
D. $a = \frac{1}{2}$, $b = -\frac{3}{2}$

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C17-T68FF-Q001_答案.png|答案]]

## V4 Pro Max 解析

**考点**：分布函数的规范性 $F(+\infty)=1$ 与线性组合系数的确定。

**解**

分布函数须满足 $F(-\infty)=0$（自动成立）与 $F(+\infty)=1$。令 $x\to+\infty$：
$$F(+\infty)=aF_1(+\infty)-bF_2(+\infty)=a-b=1.$$
逐项检验：
- A. $\frac35-(-\frac25)=1$ ✓，且系数 $a=\frac35\ge0$、$-b=\frac25\ge0$，$F$ 是 $F_1,F_2$ 的非负线性组合，单调不减、右连续性均保持；
- B. $\frac23-\frac23=0\ne1$，✗；
- C. $-\frac12-\frac32=-2\ne1$，✗；
- D. $\frac12+\frac32=2\ne1$，✗。

**答案**：A. $a=\frac35,\ b=-\frac25$。

**易错点**：线性组合 $aF_1-bF_2$ 作分布函数不仅要 $a-b=1$，还要求"$a$ 与 $-b$"两个系数都非负（保证单调不减），只验 $F(+\infty)$ 会漏掉非负性。

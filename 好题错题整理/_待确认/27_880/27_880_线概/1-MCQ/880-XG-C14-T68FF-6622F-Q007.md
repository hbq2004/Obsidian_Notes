# MCQ 第 7 题

![[_Attachments/题目识别/880-XG/880-XG-C14-T68FF-6622F-Q007_题目.png|题目]]

(7) 设 3 维列向量 $\alpha_1, \alpha_2, \alpha_3$ 线性无关，$A = (\alpha_{ij})_{3 \times 3}$ 满足 $A\alpha_1 = \alpha_1$, $A\alpha_2 = \alpha_2 + \alpha_3$, $A\alpha_3 = \alpha_1 + \alpha_3$, $A_{ij}$ 是 $\alpha_{ij}$ 的代数余子式，则 $A_{11} + A_{22} + A_{33} = ($ \_).$

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C14-T68FF-6622F-Q007_答案.png|答案]]

## V4 Pro Max 解析

**考点**：由 $A$ 在基上的作用求表示矩阵与特征值，用 $\operatorname{tr}(A^*)=$ 主对角线代数余子式之和。

**解**

在基 $(\alpha_1,\alpha_2,\alpha_3)$ 下（$\alpha_i$ 线性无关），由 $A\alpha_1=\alpha_1$，$A\alpha_2=\alpha_2+\alpha_3$，$A\alpha_3=\alpha_1+\alpha_3$，$A$ 的表示矩阵为

$$[A]=\begin{pmatrix}1&0&1\\0&1&0\\0&1&1\end{pmatrix}.$$

特征多项式：$|\lambda E-[A]|=\begin{vmatrix}\lambda-1&0&-1\\0&\lambda-1&0\\0&-1&\lambda-1\end{vmatrix}=(\lambda-1)^3$，故 $A$ 的特征值全为 $1$（三重），$|A|=1$。

$A_{11}+A_{22}+A_{33}$ 为主对角线三个代数余子式之和，即 $\operatorname{tr}(A^*)$。由 $A^*=|A|A^{-1}=A^{-1}$，其特征值为 $\frac{1}{1},\frac{1}{1},\frac{1}{1}$，故

$$A_{11}+A_{22}+A_{33}=\operatorname{tr}(A^*)=\operatorname{tr}(A^{-1})=1+1+1=3.$$

**答案**：$A_{11}+A_{22}+A_{33}=3$。

**易错点**：对角线代数余子式之和 $=\operatorname{tr}(A^*)$；$A^*=|A|A^{-1}$ 的特征值为 $|A|/\lambda_i$，本题 $|A|=1$ 且特征值全为 $1$，结果为 $3$。勿把 $A_{ij}$ 与矩阵元素 $a_{ij}$ 混淆（题目 $A_{ij}$ 表示 $a_{ij}$ 的代数余子式）。

# MCQ 第 1 题

![[_Attachments/题目识别/880-XG/880-XG-C13-T68FF-Q001_题目.png|题目]]

(1) 已知 $n_1, n_2$ 是非齐次线性方程组 $Ax=b$ 的两个不同解，$\xi_1, \xi_2$ 是对应齐次线性方程组 $Ax=0$ 的基础解系，$k_1, k_2$ 为任意常数，则 $Ax=b$ 的通解为(\_)。

A. $k_1 \xi_1 + k_2 \left( \xi_1 + \xi_2 \right) + \frac{n_1 - n_2}{2}$

B. $k_1 \xi_1 + k_2 \left( \xi_1 - \xi_2 \right) + \frac{n_1 + n_2}{2}$

C. $k_1 \xi_1 + k_2 \left( n_1 + n_2 \right) + \frac{n_1 - n_2}{2}$

D. $k_1 \xi_1 + k_2 \left( n_1 - n_2 \right) + \frac{n_1 + n_2}{2}$

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C13-T68FF-Q001_答案.png|答案]]

## V4 Pro Max 解析

**考点**：解的结构——非齐次通解 = 特解 + 齐次通解，且齐次部分须为线性无关的基础解系组合。

**解**

$n_1,n_2$ 是 $Ax=b$ 的两个不同解，$\xi_1,\xi_2$ 是 $Ax=0$ 的基础解系，$k_1,k_2$ 为任意常数。通解必须满足两条：

1. **特解**部分须是 $Ax=b$ 的解：
   - $\dfrac{n_1+n_2}{2}$：$A\left(\dfrac{n_1+n_2}{2}\right)=\dfrac{b+b}{2}=b$ ✓ 是特解；
   - $\dfrac{n_1-n_2}{2}$：$A\left(\dfrac{n_1-n_2}{2}\right)=\dfrac{b-b}{2}=0$ ✗ 是齐次解而非特解。

2. **齐次部分**须构成 $Ax=0$ 的基础解系（两个线性无关解）：
   - $\{\xi_1,\ \xi_1+\xi_2\}$：$\xi_1+\xi_2$ 是齐次解且与 $\xi_1$ 线性无关（否则 $\xi_2\parallel\xi_1$），✓；
   - $\{\xi_1,\ \xi_1-\xi_2\}$：同理 ✓；
   - $\{\xi_1,\ n_1+n_2\}$：$n_1+n_2$ 满足 $A(n_1+n_2)=2b\ne0$（$b\ne0$），不是齐次解，✗；
   - $\{\xi_1,\ n_1-n_2\}$：$n_1-n_2$ 是齐次解，但题面未排除它与 $\xi_1$ 线性相关（如 $n_1-n_2$ 恰为 $\xi_1$ 的倍数），不保证构成基础解系，✗。

逐一检查选项：A 的特解部分是齐次解，排除；C 的齐次部分含非齐次解 $n_1+n_2$，排除；D 的齐次部分不保证线性无关，排除。

B：齐次部分 $\{k_1\xi_1+k_2(\xi_1-\xi_2)\}$ 为基础解系组合，特解 $\dfrac{n_1+n_2}{2}$ 正确，为通解。✓

**答案**：B。

**易错点**：$n_1+n_2$ 是"二倍特解"（$A(n_1+n_2)=2b$），不是齐次解；$n_1-n_2$ 虽为齐次解但可能与 $\xi_1$ 相关，不能保证其为基础解系——"两解之差"作基础解系的前提是与已有基向量线性无关。

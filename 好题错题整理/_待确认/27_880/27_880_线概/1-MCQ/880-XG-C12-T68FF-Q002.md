# MCQ 第 2 题

![[_Attachments/题目识别/880-XG/880-XG-C12-T68FF-Q002_题目.png|题目]]

(2) 向量组 $\alpha_1, \alpha_2, \cdots, \alpha_n$ 线性无关等价于 ( ).

A. 存在一组不全为 0 的数, 使其线性组合不为 0
B. 存在一个向量不能由其他向量线性表示
C. 任何一个向量均不能由其他向量线性表示
D. 其中任意两个向量线性无关

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C12-T68FF-Q002_答案.png|答案]]

## V4 Pro Max 解析

**考点**：线性无关的等价定义:任一向量均不能由其余向量线性表示。

**解**

**C 正确**:若某一向量可由其余向量线性表示,移项得非平凡零组合,向量组相关;反之若向量组相关,存在不全为零的 $c_i$ 使 $\sum c_i\alpha_i=0$,取 $c_j\ne 0$ 的项移项,$\alpha_j$ 即由其余向量表示。故"任何一个向量均不能由其他向量线性表示"与线性无关等价。

**A 错**:对任何非零向量组,$\alpha_1+0\cdot\alpha_2+\cdots$ 就不为零,故"存在不全为 0 的数使组合不为 0"恒成立,不是充要条件。

**B 错**:线性相关组中也可能有向量不能由其余向量表示。例:$\alpha_1=(1,0),\alpha_2=(2,0),\alpha_3=(0,1)$,相关($\alpha_2=2\alpha_1$),但 $\alpha_3$ 不能由 $\alpha_1,\alpha_2$ 表示。

**D 错**:两两无关不保证整体无关。例:$\alpha_3=\alpha_1+\alpha_2$ 时三向量两两不成比例,但整体相关。

**答案**：C。

**易错点**：必须"任何一个"都不能表示;相关组中也可能存在"不能由其余表示"的向量,这是 B 的反例来源。

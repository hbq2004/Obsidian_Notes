# FRQ 第 19 题

![[_Attachments/题目识别/880-XG/880-XG-C22-T29FD-Q019_题目.png|题目]]

(19) 设随机变量 $X$ 与 $Y$ 相互独立, $X \sim N\left(0, \sigma^{2}\right)\left(\sigma > 0\right), Y$ 的分布律为 $P\{Y = -1\} = P\{Y = 1\} = \frac{1}{2}$，记 $Z = XY, Z_{1}, Z_{2}, \cdots, Z_{n}$ 为来自总体 $Z$ 的简单随机样本.

(I) 求 $Z$ 的概率密度 $f_{Z}(z)$;

(II) 求 $\sigma^{2}$ 的最大似然估计量 $\sigma^{2}$;

(III) 若 $U = \sum\limits_{i=1}^{n} a_{i} Z_{i}$，其中 $a_{i} \geqslant 0, \sum\limits_{i=1}^{n} a_{i} = 1$，求 $DU$ 的最小值.

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C22-T29FD-Q019_答案.png|答案]]

## V4 Pro Max 解析

**考点**：正态与对称符号变量乘积仍正态;方差 MLE;凸组合方差最小化(柯西-施瓦茨不等式)。

**解**
(I) $Z=XY$,$X\sim N(0,\sigma^2)$ 与 $Y=\pm1$(各 $\frac12$)独立。分布函数
$$P\{Z\le z\}=\frac12P\{X\le z\}+\frac12P\{-X\le z\}=\frac12\Phi\Big(\frac z\sigma\Big)+\frac12\Big(1-\Phi\Big(-\frac z\sigma\Big)\Big)=\Phi\Big(\frac z\sigma\Big),$$
故 $Z\sim N(0,\sigma^2)$:
$$\boxed{f_Z(z)=\frac1{\sqrt{2\pi}\,\sigma}e^{-\frac{z^2}{2\sigma^2}},\quad -\infty<z<+\infty}.$$

(II) 同正态方差 MLE:
$$\boxed{\hat\sigma^2=\frac1n\sum_{i=1}^nZ_i^2}.$$

(III) $Z_i$ 独立同 $N(0,\sigma^2)$,$DZ_i=\sigma^2$。$U=\sum_{i=1}^na_iZ_i$,$a_i\ge0$,$\sum a_i=1$:
$$DU=\sum_{i=1}^na_i^2DZ_i=\sigma^2\sum_{i=1}^na_i^2.$$
由柯西-施瓦茨(或 $a_i^2$ 与 1 的均值不等式)$\sum a_i^2\ge\frac{(\sum a_i)^2}{n}=\frac1n$,等号当且仅当 $a_1=\cdots=a_n=\frac1n$,故
$$\boxed{\min DU=\frac{\sigma^2}{n}}\quad(\text{取 }a_i=\tfrac1n).$$

**答案**：(I) $f_Z(z)=\frac1{\sqrt{2\pi}\sigma}e^{-z^2/(2\sigma^2)}$,即 $Z\sim N(0,\sigma^2)$;(II) $\hat\sigma^2=\frac1n\sum Z_i^2$;(III) $DU$ 的最小值为 $\dfrac{\sigma^2}{n}$。

**易错点**：$Z$ 与 $X$ 同分布但由 $Y$ 加扰,分布函数推导用 $\Phi$ 对称性;$\sum a_i^2\ge\frac1n$ 是平方和最小化的标准结论,取等条件 $a_i$ 全相等。

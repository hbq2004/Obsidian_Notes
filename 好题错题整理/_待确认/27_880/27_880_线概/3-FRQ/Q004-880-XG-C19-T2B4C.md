# FRQ 第 4 题

![[_Attachments/题目识别/880-XG/880-XG-C19-T2B4C-Q004_题目.png|题目]]

(4) 设 $X$ 的概率密度为 $f(x) = \frac{1}{2} e^{-|x|}$，$-\infty < x < +\infty$。

(I) 求 $EX$ 和 $DX$；

(II) 求 $Cov(X, |X|)$，并判别 $X$ 与 $|X|$ 是否不相关；

(III) 问 $X$ 与 $|X|$ 是否相互独立？

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C19-T2B4C-Q004_答案.png|答案]]

## V4 Pro Max 解析

**考点**：对称(拉普拉斯)分布的数字特征;不相关与独立的判别。

**解**
(I) 密度 $f(x)=\frac12 e^{-|x|}$ 为偶函数,故
$$EX=\int_{-\infty}^{+\infty}xf(x)dx=0.$$
$$DX=E(X^2)=\int_{-\infty}^{+\infty}x^2\cdot\frac12e^{-|x|}dx=\int_0^{+\infty}x^2e^{-x}dx=\Gamma(3)=2.$$
故 $\boxed{EX=0,\ DX=2}$。

(II) $g(x)=x|x|$ 是奇函数,$f(x)$ 是偶函数,故
$$E\big(X|X|\big)=\int_{-\infty}^{+\infty}x|x|f(x)dx=0,$$
$$\operatorname{Cov}(X,|X|)=E\big(X|X|\big)-EX\cdot E|X|=0.$$
协方差为 0,故 $X$ 与 $|X|$ **不相关**。

(III) 不独立。取事件 $A=\{X>1\}$,$B=\{|X|<2\}$:
$$P\{X>1,\ |X|<2\}=P\{1<X<2\}=\frac12(e^{-1}-e^{-2}),$$
而
$$P\{X>1\}P\{|X|<2\}=\frac12e^{-1}\cdot(1-e^{-2})=\frac12(e^{-1}-e^{-3}),$$
两者不相等(当 $e^{-2}\ne e^{-3}$),故 $X$ 与 $|X|$ 不独立。

**答案**：(I) $EX=0$,$DX=2$;(II) $\operatorname{Cov}(X,|X|)=0$,不相关;(III) 不独立。

**易错点**：奇函数积分直接得 0,无需分部;本题是"不相关但不独立"的经典反例——相关性只刻画线性关系,函数关系(如 $|X|$)不保证相关。

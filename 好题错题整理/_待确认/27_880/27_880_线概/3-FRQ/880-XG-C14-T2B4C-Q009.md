# FRQ 第 9 题

![[_Attachments/题目识别/880-XG/880-XG-C14-T2B4C-Q009_题目.png|题目]]

(9) (I) 设 $A$ 是 $n$ 阶实对称矩阵，且 $A^2 = A$，$r(A) = r(r < n)$，计算 $|3E - A|$；

(II) 设 $A$ 是 $n$ 阶矩阵，且 $A^2 = A$，$r(A) = r(r < n)$，计算 $|3E - A|$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C14-T2B4C-Q009_答案.png|答案]]

## V4 Pro Max 解析

**考点**：幂等矩阵 $A^2=A$ 的特征值结构（仅 $0$ 与 $1$）与可对角化性，求矩阵多项式的行列式。

**解**

(I) $A$ 为实对称矩阵且 $A^2=A$。若 $\lambda$ 是 $A$ 的特征值、$\xi$ 为对应特征向量，则

$$A^2\xi=A\xi\Rightarrow \lambda^2\xi=\lambda\xi\Rightarrow \lambda(\lambda-1)=0\Rightarrow \lambda\in\{0,1\}.$$

$A$ 实对称 $\Rightarrow$ 可正交对角化，$A\sim\operatorname{diag}(\underbrace{1,\cdots,1}_{r},\underbrace{0,\cdots,0}_{n-r})$（$r(A)=r$）。于是 $3E-A$ 的特征值为 $3-1=2$（$r$ 个）、$3-0=3$（$n-r$ 个），故

$$|3E-A|=2^{r}\cdot 3^{n-r}.$$

(II) 去掉对称性，仅 $A^2=A$。同上先证特征值 $\subseteq\{0,1\}$；再由 $A^2-A=O$ 知 $A$ 的最小多项式整除 $x^2-x=x(x-1)$，无重根，故 $A$ 可对角化，$A\sim\operatorname{diag}(1,\cdots,1,0,\cdots,0)$（$r$ 个 $1$）。因此

$$|3E-A|=2^{r}\cdot 3^{n-r},$$

与 (I) 结果相同。（注意：幂等矩阵 $r(A)=\operatorname{tr}(A)=r$，特征值 $1$ 恰有 $r$ 个。）

**答案**：(I) $|3E-A|=2^r\cdot3^{n-r}$；
(II) $|3E-A|=2^r\cdot3^{n-r}$。

**易错点**：$A^2=A$ 蕴含特征值只能是 $0,1$；幂等矩阵（即便不对称）恒可对角化，这是本题两问答案相同的根源；(II) 中勿以为缺少对称性就不能对角化——最小多项式无重根即可。

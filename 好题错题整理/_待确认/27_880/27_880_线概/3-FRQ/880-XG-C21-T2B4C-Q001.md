# FRQ 第 1 题

![[_Attachments/题目识别/880-XG/880-XG-C21-T2B4C-Q001_题目.png|题目]]

(1) 设 $(X_1, X_2, \cdots, X_9)$ 为总体 $X \sim N(0, 2^2)$ 的简单随机样本，若 $a, b, c$ 使 $X = a(X_1 + X_2)^2 + b(X_3 + X_4 + X_5)^2 + c(X_6 + X_7 + X_8 + X_9)^2$ 服从 $\chi^2$ 分布，求 $a, b, c$ 的值及 $\chi^2$ 分布的自由度.

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C21-T2B4C-Q001_答案.png|答案]]

## V4 Pro Max 解析

**考点**：标准正态线性组合标准化后平方和构成 $\chi^2$ 分布（定系数与自由度）。

**解**

$X_i$ 独立同分布 $N(0,2^2)$，方差 $4$。

若 $a(X_1+X_2)^2$ 为 $\chi^2(1)$，须 $\sqrt a\,(X_1+X_2)\sim N(0,1)$，即 $a\cdot D(X_1+X_2)=a\cdot(4+4)=8a=1\Rightarrow a=\frac18$。

同理 $b\cdot D(X_3+X_4+X_5)=b\cdot 3\cdot4=12b=1\Rightarrow b=\frac1{12}$；$c\cdot D(X_6+\cdots+X_9)=c\cdot 4\cdot4=16c=1\Rightarrow c=\frac1{16}$。

此时

$$\sqrt a(X_1+X_2),\quad \sqrt b(X_3+X_4+X_5),\quad \sqrt c(X_6+X_7+X_8+X_9)$$

为三个相互独立的标准正态变量，其平方和为

$$X=a(X_1+X_2)^2+b(X_3+X_4+X_5)^2+c(X_6+X_7+X_8+X_9)^2\sim\chi^2(1+1+1)=\chi^2(3).$$

**答案**：$a=\dfrac18$，$b=\dfrac1{12}$，$c=\dfrac1{16}$，$X\sim\chi^2(3)$。

**易错点**：每个分组线性组合须标准化为 $N(0,1)$，系数取方差的倒数（注意 $D(X_i)=2^2=4$，勿误用 2）；三组互不相交故独立，自由度相加。

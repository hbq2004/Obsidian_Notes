# FRQ 第 2 题

![[_Attachments/题目识别/880-XG/880-XG-C12-T2B4C-8AA8B-Q002_题目.png|题目]]

(2) 设向量组 $\alpha_1 = (1, 0, 1)^T$, $\alpha_2 = (0, 1, 1)^T$, $\alpha_3 = (1, 3, 5)^T$ 不能由向量组 $\beta_1 = (1, 1, 1)^T$, $\beta_2 = (1, 2, 3)^T$, $\beta_3 = (3, 4, a)^T$ 线性表示，求 $a$ 的值，并将 $\beta_1$, $\beta_2$, $\beta_3$ 用 $\alpha_1$, $\alpha_2$, $\alpha_3$ 线性表示.

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C12-T2B4C-8AA8B-Q002_答案.png|答案]]

## V4 Pro Max 解析

**考点**：向量组能否线性表示取决于表示向量组的秩是否等于 3。

**解**

先看 $\alpha_1,\alpha_2,\alpha_3$:$\det\begin{pmatrix}1&0&1\\0&1&3\\1&1&5\end{pmatrix}=1\cdot(5-3)-0+1\cdot(0-1)=1\neq 0$,故 $\alpha_1,\alpha_2,\alpha_3$ 是 $\mathbb{R}^3$ 的一组基。

若 $\beta_1,\beta_2,\beta_3$ 也满秩(构成基),则 $\mathbb{R}^3$ 中任何向量(包括 $\alpha_1,\alpha_2,\alpha_3$)都可由其线性表示。故"$\alpha$ 不能由 $\beta$ 线性表示"等价于 $r(\beta_1,\beta_2,\beta_3)\le 2$,即

$$\det\begin{pmatrix}1&1&3\\1&2&4\\1&3&a\end{pmatrix}=1\cdot(2a-12)-1\cdot(a-4)+3\cdot(3-2)=a-5=0,$$

得 $a=5$。此时 $\beta_3=(3,4,5)^T=2\beta_1+\beta_2$,$r(\beta)=2$。

将 $\beta$ 用 $\alpha$ 表示:设 $\beta_j=x_1\alpha_1+x_2\alpha_2+x_3\alpha_3$,即解

$$x_1+x_3=c_1,\quad x_2+3x_3=c_2,\quad x_1+x_2+5x_3=c_3.$$

- $\beta_1=(1,1,1)^T$:由 $x_1+x_3=1,\ x_2+3x_3=1,\ x_1+x_2+5x_3=1$ 得 $x_3=-1,\ x_1=2,\ x_2=4$,即 $\beta_1=2\alpha_1+4\alpha_2-\alpha_3$;
- $\beta_2=(1,2,3)^T$:得 $x_3=0,\ x_1=1,\ x_2=2$,即 $\beta_2=\alpha_1+2\alpha_2$;
- $\beta_3=(3,4,5)^T$:得 $x_3=-2,\ x_1=5,\ x_2=10$,即 $\beta_3=5\alpha_1+10\alpha_2-2\alpha_3$。

**答案**：$a=5$;$\beta_1=2\alpha_1+4\alpha_2-\alpha_3$,$\beta_2=\alpha_1+2\alpha_2$,$\beta_3=5\alpha_1+10\alpha_2-2\alpha_3$。

**易错点**："不能由 $\beta$ 表示"的关键是 $r(\beta)<3$(因为 $\alpha$ 自身构成基);切勿直接令 $\alpha_3$ 与某个 $\beta$ 比较。

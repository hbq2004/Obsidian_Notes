# FRQ 第 9 题

![[_Attachments/题目识别/880-XG/880-XG-C19-T2B4C-A0C9F-Q009_题目.png|题目]]

(9) 设 2 维随机变量 $(X, Y)$ 的概率密度为 $f(x, y) = \begin{cases} 2e^{-(x+y)}, & 0 < x < y, \\ 0, & 其他. \end{cases}$

(I) 求 $(X, Y)$ 的联合分布函数 $F(x, y)$;

(II) 求 $P\left\{X + Y > 1 \mid X < \frac{1}{2}\right\}$;

(III) 求 $E(Y - X)$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C19-T2B4C-A0C9F-Q009_答案.png|答案]]

## V4 Pro Max 解析

**考点**：三角形区域上联合密度对应的分布函数(分区域积分),条件概率,以及 $E(Y-X)$ 用边缘期望计算。

**解**
(I) $f(x,y)=2e^{-(x+y)}$,支撑为 $0<x<y$。$F(x,y)=P\{X\le x,Y\le y\}$ 分区域:

1. $x\le0$ 或 $y\le0$:$F=0$;
2. $0\le x\le y$:
$$F=\int_0^x\int_u^y 2e^{-(u+v)}\,dv\,du=\int_0^x2(e^{-2u}-e^{-u-y})du$$
$$=\Big[-e^{-2u}+2e^{-u-y}\Big]_0^x=1-2e^{-y}-e^{-2x}+2e^{-x-y};$$
3. $0\le y\le x$:此时只需 $0<u<v\le y$,即 $F=P\{Y\le y\}$:
$$F=\int_0^y\int_u^y2e^{-(u+v)}dv\,du=\int_0^y2(e^{-2u}-e^{-u-y})du=(1-e^{-2y})-(2e^{-y}-2e^{-2y})$$
$$=1-2e^{-y}+e^{-2y}.$$

(II) 边缘密度 $f_X(x)=\int_x^{+\infty}2e^{-(x+y)}dy=2e^{-2x}\,(x>0)$,故
$$P\{X<\tfrac12\}=\int_0^{1/2}2e^{-2x}dx=1-e^{-1}.$$
$$P\{X+Y>1,\ X<\tfrac12\}=\int_0^{1/2}\int_{1-x}^{+\infty}2e^{-(x+y)}dy\,dx=\int_0^{1/2}2e^{-x}\cdot e^{-(x-1)}dx=2e^{-1}\cdot\frac12=e^{-1}.$$
(注意 $x<\frac12$ 时 $1-x>x$,区域约束自动满足。)
$$P\{X+Y>1\mid X<\tfrac12\}=\frac{e^{-1}}{1-e^{-1}}=\boxed{\frac{1}{e-1}}.$$

(III) $EX=\int_0^{+\infty}x\cdot2e^{-2x}dx=\frac12$;$f_Y(y)=2e^{-y}(1-e^{-y})\,(y>0)$,故
$$EY=\int_0^{+\infty}y\cdot2(e^{-y}-e^{-2y})dy=2\cdot1-2\cdot\frac14=\frac32,$$
$$E(Y-X)=EY-EX=\frac32-\frac12=\boxed{1}.$$

**答案**：(I) $F(x,y)$ 分段表达式见解;(II) $\dfrac{1}{e-1}$;(III) $1$。

**易错点**：分布函数必须在支撑区域的两个不同位置关系下分别积分(第 3 种情形退化为 $Y$ 的边缘分布);条件概率的分子要同时满足 $X<\frac12$ 与 $Y>1-x$。

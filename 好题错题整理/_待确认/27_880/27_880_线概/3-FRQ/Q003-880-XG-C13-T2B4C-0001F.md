# FRQ 第 3 题

![[_Attachments/题目识别/880-XG/880-XG-C13-T2B4C-0001F-Q003_题目.png|题目]]

(3) 设 $A$ 为 $3 \times 4$ 矩阵, $r(A) = 1$，若向量组 $\alpha_1 = (1, 2, 0, 2)^T$，$\alpha_2 = (-1, -1, 1, a)^T$，$\alpha_3 = (1, -1, a, 5)^T$，$\alpha_4 = (2, a, -3, -5)^T$ 与方程组 $Ax = 0$ 的基础解系等价，求 $Ax = 0$ 的通解.

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C13-T2B4C-0001F-Q003_答案.png|答案]]

## V4 Pro Max 解析

**考点**：向量组与基础解系等价的转化——向量组的张成空间即解空间，先定参数再写通解。

**解**

$r(A)=1$，$A$ 为 $3\times 4$，故 $Ax=0$ 的解空间维数为 $4-1=3$，基础解系含 3 个向量。向量组 $\alpha_1,\alpha_2,\alpha_3,\alpha_4$ 与基础解系等价，故其张成空间恰为解空间，秩为 3，且每个 $\alpha_i$ 都是 $Ax=0$ 的解。

由 $\operatorname{rank}(\alpha_1,\alpha_2,\alpha_3,\alpha_4)=3$ 得 $\det(\alpha_1,\alpha_2,\alpha_3,\alpha_4)=0$。记 $M=(\alpha_1,\alpha_2,\alpha_3,\alpha_4)$，作行变换：

$$M=\begin{pmatrix}1&-1&1&2\\2&-1&-1&a\\0&1&a&-3\\2&a&5&-5\end{pmatrix}\sim\begin{pmatrix}1&-1&1&2\\0&1&-3&a-4\\0&1&a&-3\\0&a+2&3&-9\end{pmatrix},$$

$$\det M=\det\begin{pmatrix}1&-3&a-4\\1&a&-3\\a+2&3&-9\end{pmatrix}=(a-4)(-a^2-2a+3)=-(a-4)(a+3)(a-1).$$

故 $a\in\{-3,1,4\}$。逐一检查（均存在非零法向量 $\boldsymbol n$ 使 $\boldsymbol n^T\alpha_i=0$，即存在秩 1 矩阵 $A$）：

- $a=1$：$\boldsymbol n=(-2,0,-3,1)^T$，解空间 $-2x_1-3x_3+x_4=0$；
- $a=4$：$\boldsymbol n=(4,-3,-3,1)^T$，解空间 $4x_1-3x_2-3x_3+x_4=0$；
- $a=-3$：$\boldsymbol n=(4,-3,4,1)^T$，解空间 $4x_1-3x_2+4x_3+x_4=0$。

三值均满足"与基础解系等价"，题面无附加条件时有三解。

**答案**：

- $a=1$：$x=k_1(1,0,0,2)^T+k_2(0,1,0,0)^T+k_3(0,0,1,3)^T$；
- $a=4$：$x=k_1(1,0,0,-4)^T+k_2(0,1,0,3)^T+k_3(0,0,1,3)^T$；
- $a=-3$：$x=k_1(1,0,0,-4)^T+k_2(0,1,0,3)^T+k_3(0,0,1,-4)^T$。

（$k_1,k_2,k_3$ 为任意常数；每个基向量均已代入对应方程验证。）

**易错点**：本题文字疑似 OCR 有误或漏写附加条件——$\det M=0$ 给出 $a\in\{-3,1,4\}$ 三个可行值，若原题要求唯一 $a$ 值，应另有约束（如 $a$ 的范围）。解答按三情形给出完整通解。

# FRQ 第 5 题

![[_Attachments/题目识别/880-XG/880-XG-C12-T2B4C-Q005_题目.png|题目]]

(5) 设向量组 $(I)$：$\alpha_1 = (1, 3, 0, 5)^T$，$\alpha_2 = (1, 2, 1, 4)^T$，$\alpha_3 = (1, 1, 2, 3)^T$；$(II)$：$\beta_1 = (1, -3, 6, -1)^T$，$\beta_2 = (a, 0, b, 2)^T$。若向量组 $(I)$ 与 $(II)$ 等价，求 $a, b$ 的值.

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C12-T2B4C-Q005_答案.png|答案]]

## V4 Pro Max 解析

**考点**：向量组等价的充要条件:相互线性表示且秩相同。

**解**

先求 $r(I)$:$\alpha_1-\alpha_2=(0,1,-1,1)^T$,$\alpha_2-\alpha_3=(0,1,-1,1)^T$,故 $\alpha_1-\alpha_2=\alpha_2-\alpha_3$,即 $\alpha_1+\alpha_3=2\alpha_2$;且 $\alpha_1,\alpha_2$ 线性无关,所以 $r(I)=2$,$\mathrm{span}(I)=\mathrm{span}(\alpha_1,\alpha_2)$。

(I) 与 (II) 等价 $\Rightarrow$ $\beta_1,\beta_2$ 均可由 $I$ 表示(且 $r(II)=2$)。

对 $\beta_1=(1,-3,6,-1)^T$,设 $\beta_1=p\alpha_1+q\alpha_2$:

$$p+q=1,\quad 3p+2q=-3,\quad q=6,\quad 5p+4q=-1\ \Rightarrow\ p=-5,\ q=6,$$

检验:$3p+2q=-15+12=-3$,$5p+4q=-25+24=-1$ ✓。故 $\beta_1=-5\alpha_1+6\alpha_2$。

对 $\beta_2=(a,0,b,2)^T=p\alpha_1+q\alpha_2$:

$$p+q=a,\quad 3p+2q=0,\quad q=b,\quad 5p+4q=2\ \Rightarrow\ p=-2,\ q=3,$$

得 $a=p+q=1$,$b=q=3$。$\beta_2=-2\alpha_1+3\alpha_2=(1,0,3,2)^T$ ✓。

此时 $\beta_1,\beta_2$ 线性无关($\det\begin{pmatrix}-5&-2\\6&3\end{pmatrix}=-3\ne 0$),$r(II)=2$;且 $\mathrm{span}(II)\subseteq\mathrm{span}(I)$,维数相同,故两组等价。✓

**答案**：$a=1$,$b=3$。

**易错点**：等价 $\Rightarrow$ $\beta$ 可由 $\alpha$ 表示;同时要验证 $r(II)=2$(即 $\beta_1,\beta_2$ 无关),并利用"同维包含 $\Rightarrow$ 相等"完成等价性。

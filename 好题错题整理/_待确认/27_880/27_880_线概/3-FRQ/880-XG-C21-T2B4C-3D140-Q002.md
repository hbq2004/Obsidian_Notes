# FRQ 第 2 题

![[_Attachments/题目识别/880-XG/880-XG-C21-T2B4C-3D140-Q002_题目.png|题目]]

(2) 设随机变量 $X_1, X_2, X_3$ 相互独立且均服从 $N(0, \sigma^2)$，证明: $T = \sqrt{\frac{2}{3}} \frac{X_1 + X_2 + X_3}{\left| X_2 - X_3 \right|}$ 服从 $t(1)$ 分布.

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C21-T2B4C-3D140-Q002_答案.png|答案]]

## V4 Pro Max 解析

**考点**：由正态线性组合的正交性与独立性构造 $t(1)$（柯西分布）统计量。

**解**

记 $U=\dfrac{X_1+X_2+X_3}{\sqrt3}$，$V=\dfrac{X_2-X_3}{\sqrt2}$。因 $X_i$ 独立同分布 $N(0,\sigma^2)$，$U,V$ 均为标准正态的线性组合，服从 $N(0,\sigma^2)$；且

$$\mathrm{Cov}(U,V)=\mathrm{Cov}\left(\frac{X_1+X_2+X_3}{\sqrt3},\frac{X_2-X_3}{\sqrt2}\right)=\frac{1}{\sqrt6}\big(\sigma^2-\sigma^2\big)=0.$$

联合正态且协方差为 0 $\Rightarrow$ $U$ 与 $V$ 相互独立。

原统计量可改写：

$$T=\sqrt{\frac23}\,\frac{X_1+X_2+X_3}{|X_2-X_3|}=\sqrt{\frac23}\cdot\frac{\sqrt3\,U}{\sqrt2\,|V|}=\frac{U}{|V|}.$$

$U,V$ 独立同分布 $N(0,\sigma^2)$。因 $(U,V)$ 的联合分布在 $V\to-V$ 下不变，$U/|V|$ 与 $U/V$ 同分布；而 $U/V$ 是两个独立标准正态（同方差）之比，服从 $t(1)$ 分布（标准柯西分布）。故 $T\sim t(1)$，证毕。

**答案**：$T\sim t(1)$（证明见上）。

**易错点**：$t(1)$ 即标准柯西分布，需分母是独立正态的绝对值或符号——关键两步：① 用协方差为 0 证 $U,V$ 独立（联合正态才可）；② $U/|V|\overset{d}{=}U/V$（对称性），避免因绝对值而误判分布。

# FRQ 第 2 题

![[_Attachments/题目识别/880-XG/880-XG-C13-T2B4C-Q002_题目.png|题目]]

(2) 设方程组 $\left\{\begin{array}{l} 2x_1 + \lambda x_2 - x_3 = 1, \\ \lambda x_1 - x_2 + x_3 = 2, \\ 4x_1 + 5x_2 - 5x_3 = -1, \end{array}\right.$ 问 $\lambda$ 为何值时, 方程组无解、有唯一解、有无穷多解? 当有无穷多解时, 求其通解.

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C13-T2B4C-Q002_答案.png|答案]]

## V4 Pro Max 解析

**考点**：含参数方程组解的判定——行列式判别唯一解，再分参数讨论无解/无穷多解。

**解**

系数矩阵 $A=\begin{pmatrix}2&\lambda&-1\\\lambda&-1&1\\4&5&-5\end{pmatrix}$，其行列式

$$|A|=\det\begin{pmatrix}2&\lambda&-1\\\lambda&-1&1\\4&5&-5\end{pmatrix}=5\lambda^2-\lambda-4=(5\lambda+4)(\lambda-1).$$

**(1) 唯一解**：$|A|\ne0$，即 $\lambda\ne1$ 且 $\lambda\ne-\dfrac45$ 时，由克拉默法则方程组有唯一解。

**(2) $\lambda=-\dfrac45$**：增广矩阵为

$$\begin{pmatrix}2&-\frac45&-1&1\\-\frac45&-1&1&2\\4&5&-5&-1\end{pmatrix}\xrightarrow{\times 5}
\begin{pmatrix}10&-4&-5&5\\-4&-5&5&10\\4&5&-5&-1\end{pmatrix}.$$

第 2 行加第 3 行得 $(0,0,0,9)$，即 $0=9$ 矛盾，方程组无解。

**(3) $\lambda=1$**：增广矩阵

$$\begin{pmatrix}2&1&-1&1\\1&-1&1&2\\4&5&-5&-1\end{pmatrix}\xrightarrow{R_2\leftrightarrow R_1}
\begin{pmatrix}1&-1&1&2\\2&1&-1&1\\4&5&-5&-1\end{pmatrix}$$

$$\xrightarrow{R_2-2R_1,\ R_3-4R_1}
\begin{pmatrix}1&-1&1&2\\0&3&-3&-3\\0&9&-9&-9\end{pmatrix}
\xrightarrow{\frac13R_2,\ \frac19R_3}
\begin{pmatrix}1&-1&1&2\\0&1&-1&-1\\0&1&-1&-1\end{pmatrix}.$$

$r(A)=r(A|b)=2<3$，无穷多解。由 $x_2-x_3=-1$ 与 $x_1-x_2+x_3=2$ 得 $x_2=x_3-1$，$x_1=1$。令 $x_3=t$：

$$x=\begin{pmatrix}1\\-1\\0\end{pmatrix}+t\begin{pmatrix}0\\1\\1\end{pmatrix},\quad t\in\mathbb R.$$

验证：第 2 式 $1-(t-1)+t=2$；第 3 式 $4+5(t-1)-5t=-1$，成立。

**答案**：$\lambda\ne1$ 且 $\lambda\ne-\dfrac45$ 时唯一解；$\lambda=-\dfrac45$ 时无解；$\lambda=1$ 时无穷多解，通解 $x=(1,-1,0)^T+t(0,1,1)^T$。

**易错点**：$\lambda$ 的临界值要分别代入增广矩阵检查相容性，不能只由 $|A|=0$ 断言"无解或无穷多解"；$\lambda=-\frac45$ 时记得先通分再比较行。

# FRQ 第 11 题

![[_Attachments/题目识别/880-XG/880-XG-C14-T2B4C-2FE63-Q011_题目.png|题目]]

(11) 设向量组 $(I)$：$\alpha_1 = (-a, 0, 1)^T$，$\alpha_2 = (1 - a, a, 1 - a)^T$，$\alpha_3 = (1, 0, -a)^T$；$(II)$：$\beta_1 = (-1, 0, a)^T$，$\beta_2 = (-1, 1, a)^T$，$\beta_3 = (1, -1, -a)^T$（$a \neq 0$），向量组 $(I)$ 与 $(II)$ 等价.

(I) 求 $a$ 的值;

(II) 记 $A = (\alpha_1, \alpha_2, \alpha_3)$，问当 $a$ 为何值时，存在正交矩阵 $Q$，使得 $Q^{-1} A Q = \Lambda$？并求 $Q$ 及 $\Lambda$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C14-T2B4C-2FE63-Q011_答案.png|答案]]

## V4 Pro Max 解析

**考点**：向量组等价 $\Rightarrow$ 秩相等与张成空间相同，由此定 $a$；正交相似于对角矩阵 $\iff$ 实对称矩阵。

**解**

(I) 两组均为 3 个三维向量。计算行列式：

$$\det(\alpha_1,\alpha_2,\alpha_3)=\begin{vmatrix}-a&1-a&1\\0&a&0\\1&1-a&-a\end{vmatrix}=a\cdot(a^2-1)=a(a-1)(a+1),$$

$$\beta_3=-\beta_2,\quad \beta_1,\beta_2\ \text{线性无关}\ \Rightarrow\ r(II)=2.$$

两组等价 $\Rightarrow r(I)=r(II)=2$。由 $\det(\alpha_1,\alpha_2,\alpha_3)=a(a^2-1)=0$ 且 $a\ne0$ 得 $a=\pm1$。

- $a=1$：$\alpha_1=(-1,0,1),\ \alpha_2=(0,1,0),\ \alpha_3=-\alpha_1$；$\beta_1=(-1,0,1)=\alpha_1,\ \beta_2=(-1,1,1)=\alpha_1+\alpha_2,\ \beta_3=-\beta_2$，两组都张成平面 $\{z=-x\}$ ✓。
- $a=-1$：$\alpha_1=(1,0,1),\ \alpha_2=(2,-1,2),\ \alpha_3=\alpha_1$；$\beta_1=-a_1\cdot(-1)^{?}$——直接验证：$\beta_1=(-1,0,-1)=-\alpha_1$，$\beta_2=(-1,1,-1)=\alpha_1-\alpha_2$，$\beta_3=-\beta_2$，两组都张成平面 $\{z=x\}$ ✓。

故 $a=1$ 或 $a=-1$。

(II) 存在正交矩阵 $Q$ 使 $Q^{-1}AQ=\Lambda$（对角）$\iff A$ 为实对称矩阵。

- $a=1$：$A=\begin{pmatrix}-1&0&1\\0&1&0\\1&0&-1\end{pmatrix}$ 为实对称 ✓；
- $a=-1$：$A=\begin{pmatrix}1&2&1\\0&-1&0\\1&2&1\end{pmatrix}$ 不对称（$a_{12}=2\ne a_{21}=0$）✗。

故仅当 $a=1$。此时 $A$ 的特征多项式 $|\lambda E-A|=(\lambda-1)\big((\lambda+1)^2-1\big)=\lambda(\lambda-1)(\lambda+2)$，特征值 $0,1,-2$，对应特征向量

$$\xi_1=(1,0,1)^T,\quad \xi_2=(0,1,0)^T,\quad \xi_3=(1,0,-1)^T,$$

取

$$Q=\begin{pmatrix}\frac1{\sqrt2}&0&\frac1{\sqrt2}\\0&1&0\\\frac1{\sqrt2}&0&-\frac1{\sqrt2}\end{pmatrix},\qquad \Lambda=\operatorname{diag}(0,1,-2).$$

**答案**：(I) $a=1$ 或 $a=-1$；
(II) 仅当 $a=1$ 时存在正交矩阵 $Q=\begin{pmatrix}\frac1{\sqrt2}&0&\frac1{\sqrt2}\\0&1&0\\\frac1{\sqrt2}&0&-\frac1{\sqrt2}\end{pmatrix}$，使 $Q^{-1}AQ=\operatorname{diag}(0,1,-2)$。

**易错点**：(I) 中"等价"需同时满足秩相等与张成空间相同，$a=\pm1$ 都要代入验证；(II) 利用"正交相似于对角阵 $\iff$ 实对称"排除 $a=-1$，这是最快判别。

# FRQ 第 7 题

![[_Attachments/题目识别/880-XG/880-XG-C19-T2B4C-A0C9F-Q007_题目.png|题目]]

(7) 设随机变量 $X$ 的概率密度为 $f(x) = \frac{1}{e^{\sqrt{\pi}} e^{x(2-x)}}$，$x \in (-\infty, +\infty)$，$Y = \sqrt{2}(X - EX)$，求 $\rho_{XY}$ 与 $D(Y^2)$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C19-T2B4C-A0C9F-Q007_答案.png|答案]]

## V4 Pro Max 解析

**考点**：由正态密度识别分布并求线性变换的相关系数与 $\chi^2$ 型变量的方差。

**解**
题目给出的密度写作 $f(x)=\dfrac{1}{e^{\sqrt{\pi}}e^{x(2-x)}}$ 明显无法在全实轴上归一化,应为 OCR 误差。按最合理读法,该密度是
$$f(x)=\frac{1}{\sqrt{\pi}}e^{-(x-1)^2},\quad -\infty<x<+\infty,$$
即 $X\sim N\big(1,\frac12\big)$。于是 $EX=1$,$DX=\frac12$。

$Y=\sqrt2(X-EX)=\sqrt2(X-1)$,故
$$EY=0,\qquad DY=2\cdot\frac12=1,$$
即 $Y\sim N(0,1)$。

(I) $Y=\sqrt2\,X-\sqrt2$ 是 $X$ 的线性函数且系数为正,由 $|\rho_{XY}|=1$ 且同增,得
$$\boxed{\rho_{XY}=1}.$$

(II) $Y\sim N(0,1)$,则 $Y^2\sim\chi^2(1)$,$E(Y^2)=1$,$E(Y^4)=3$,故
$$D(Y^2)=E(Y^4)-\big[E(Y^2)\big]^2=3-1=\boxed{2}.$$

**答案**：$\rho_{XY}=1$,$D(Y^2)=2$。

**易错点**：密度原文疑似 OCR 有误(无法归一化),此处按 $f(x)=\frac{1}{\sqrt\pi}e^{-(x-1)^2}$ 即 $N(1,\frac12)$ 处理;$\rho=\pm1$ 的符号取决于线性系数正负,勿漏。

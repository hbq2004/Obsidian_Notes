# FRQ 第 8 题

![[_Attachments/题目识别/880-XG/880-XG-C19-T2B4C-A0C9F-Q008_题目.png|题目]]

(8) 设随机变量 $X_1$ 与 $X_2$ 相互独立，且均服从 $N(0,1)$，$X_3$ 的分布律为 $P\left\{X_3 = -1\right\} = \frac{1}{4}$，$P\left\{X_3 = 1\right\} = \frac{3}{4}$，且 $X_1$ 与 $X_3$ 相互独立。

(I) 求 $Z = X_1 X_3$ 的概率密度 $f_Z(z)$；

(II) 求 $X_1$ 与 $Z$ 的相关系数 $\rho_{X_1 Z}$；

(III) $\left(X_1 + X_2\right)^2$ 与 $\left(X_1 - X_2\right)^2$ 是否相互独立？说明理由.

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C19-T2B4C-A0C9F-Q008_答案.png|答案]]

## V4 Pro Max 解析

**考点**：独立正态与符号随机变量乘积的分布,相关系数,以及正态组合平方的独立性。

**解**
(I) $X_1\sim N(0,1)$ 与 $X_3$ 独立,$X_3$ 取 $\pm1$。对任意 $z$:
$$P\{Z\le z\}=\frac14P\{-X_1\le z\}+\frac34P\{X_1\le z\}$$
$$=\frac14P\{X_1\ge -z\}+\frac34\Phi(z)=\frac14\Phi(z)+\frac34\Phi(z)=\Phi(z),$$
其中用 $1-\Phi(-z)=\Phi(z)$。故 $Z\sim N(0,1)$,概率密度
$$\boxed{f_Z(z)=\frac{1}{\sqrt{2\pi}}e^{-\frac{z^2}{2}},\quad -\infty<z<+\infty}.$$

(II) $EX_1=0$,$EZ=0$,$DX_1=DZ=1$。
$$\operatorname{Cov}(X_1,Z)=E(X_1Z)=E(X_1^2X_3)=E(X_1^2)E(X_3)=1\cdot\left(\frac14(-1)+\frac34\cdot1\right)=\frac12,$$
$$\rho_{X_1Z}=\frac{\operatorname{Cov}(X_1,Z)}{\sqrt{DX_1\cdot DZ}}=\boxed{\frac12}.$$

(III) 记 $U=X_1+X_2$,$V=X_1-X_2$。$X_1,X_2$ 独立标准正态,$(U,V)$ 为二维正态且
$$\operatorname{Cov}(U,V)=DX_1-DX_2=0,$$
故 $U$ 与 $V$ 相互独立(二维正态不相关即独立)。于是 $(X_1+X_2)^2=U^2$ 与 $(X_1-X_2)^2=V^2$ 作为独立变量的函数仍相互独立。

**答案**：(I) $f_Z(z)=\frac{1}{\sqrt{2\pi}}e^{-z^2/2}$;(II) $\rho_{X_1Z}=\frac12$;(III) 相互独立,因为 $X_1+X_2$ 与 $X_1-X_2$ 独立,独立变量的函数仍独立。

**易错点**：$Z$ 与 $X_1$ 同分布但不等于 $X_1$,相关但非函数关系;$X_1,X_2$ 联合正态下"不相关 $\Rightarrow$ 独立"成立,这是第 (III) 问的关键前提。

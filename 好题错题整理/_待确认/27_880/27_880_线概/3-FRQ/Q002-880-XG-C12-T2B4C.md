# FRQ 第 2 题

![[_Attachments/题目识别/880-XG/880-XG-C12-T2B4C-Q002_题目.png|题目]]

(2) 设向量组 $\alpha_1 = (0, 4, 2)^T$, $\alpha_2 = (1, 1, 0)^T$, $\alpha_3 = (-2, 4, 3)^T$, $\alpha_4 = (-1, 1, 1)^T$，求 $\alpha_1$, $\alpha_2$, $\alpha_3$, $\alpha_4$ 的一个极大线性无关组，并将其余向量用极大线性无关组线性表示.

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C12-T2B4C-Q002_答案.png|答案]]

## V4 Pro Max 解析

**考点**：求极大线性无关组并用其线性表示其余向量(行变换保持列关系)。

**解**

对 $A=(\alpha_1,\alpha_2,\alpha_3,\alpha_4)=\begin{pmatrix}0&1&-2&-1\\4&1&4&1\\2&0&3&1\end{pmatrix}$ 作行变换:

$$\xrightarrow{R_1\leftrightarrow R_3}\begin{pmatrix}2&0&3&1\\4&1&4&1\\0&1&-2&-1\end{pmatrix}\xrightarrow{R_2-2R_1}\begin{pmatrix}2&0&3&1\\0&1&-2&-1\\0&1&-2&-1\end{pmatrix}\xrightarrow{R_3-R_2}\begin{pmatrix}2&0&3&1\\0&1&-2&-1\\0&0&0&0\end{pmatrix}.$$

主元在第 1、2 列,故 $\{\alpha_1,\alpha_2\}$ 是一个极大线性无关组,$r=2$。

行变换不改变列之间的线性关系,由阶梯形第 3、4 列:

$$\begin{pmatrix}3\\-2\\0\end{pmatrix}=\frac32\begin{pmatrix}2\\0\\0\end{pmatrix}-2\begin{pmatrix}0\\1\\0\end{pmatrix},\qquad \begin{pmatrix}1\\-1\\0\end{pmatrix}=\frac12\begin{pmatrix}2\\0\\0\end{pmatrix}-\begin{pmatrix}0\\1\\0\end{pmatrix},$$

故 $\alpha_3=\dfrac32\alpha_1-2\alpha_2$,$\alpha_4=\dfrac12\alpha_1-\alpha_2$。

验证:$\frac32(0,4,2)^T-2(1,1,0)^T=(0,6,3)^T-(2,2,0)^T=(-2,4,3)^T=\alpha_3$;$\frac12(0,4,2)^T-(1,1,0)^T=(0,2,1)^T-(1,1,0)^T=(-1,1,1)^T=\alpha_4$。

**答案**：极大线性无关组 $\{\alpha_1,\alpha_2\}$;$\alpha_3=\dfrac32\alpha_1-2\alpha_2$,$\alpha_4=\dfrac12\alpha_1-\alpha_2$。

**易错点**：行初等变换保持列向量组的线性关系,可直接从阶梯形读出组合系数;不要对列向量做列变换(会破坏列关系)。

# FRQ 第 2 题

![[_Attachments/题目识别/880-XG/880-XG-C18-T2B4C-Q002_题目.png|题目]]

(2) 设随机变量 $(X, Y)$ 的概率密度为 $f(x, y) = \begin{cases} 1, & 0 < x < 1, -x < y < x, \\ 0, & 其他. \end{cases}$ 求：

(I) 边缘概率密度 $f_X(x), f_Y(y)$;

(II) 条件概率密度 $f_{X|Y}(x|y), f_{Y|X}(y|x)$;

(III) $P\left\{X > \frac{1}{2} | Y > 0\right\}$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C18-T2B4C-Q002_答案.png|答案]]

## V4 Pro Max 解析

**考点**：三角形区域上均匀分布的边缘密度、条件密度及条件概率计算。

**解**

$f(x,y)=1$，区域 $0<x<1,\ -x<y<x$（以 $x$ 为横坐标的三角形，顶点 $(0,0),(1,1),(1,-1)$），面积为 $\int_0^1 2x\,dx=1$，密度归一化 ✓。

(I) 边缘密度：

$$f_X(x)=\int_{-x}^{x}1\,dy=2x,\qquad 0<x<1;$$

$$f_Y(y)=\int_{|y|}^{1}1\,dx=1-|y|,\qquad -1<y<1.$$

(II) 条件密度（支撑处）：

$$f_{X|Y}(x|y)=\frac{f(x,y)}{f_Y(y)}=\begin{cases}\dfrac{1}{1-|y|},&|y|<x<1,\\[6pt] 0,&\text{其他};\end{cases}$$

$$f_{Y|X}(y|x)=\frac{f(x,y)}{f_X(x)}=\begin{cases}\dfrac{1}{2x},&-x<y<x,\\[6pt] 0,&\text{其他}.\end{cases}$$

(III) $P\{Y>0\}=\int_0^1 f_Y(y)\,dy=\int_0^1(1-y)\,dy=\frac12$；

$$P\left\{X>\frac12,\ Y>0\right\}=\int_{1/2}^{1}\int_0^{x}1\,dy\,dx=\int_{1/2}^{1}x\,dx=\frac{1}{2}\left(1-\frac14\right)=\frac38.$$

$$P\left\{X>\frac12\,\Big|\,Y>0\right\}=\frac{P\{X>\frac12,\ Y>0\}}{P\{Y>0\}}=\frac{3/8}{1/2}=\frac34.$$

**答案**：(I) $f_X(x)=2x\ (0<x<1)$，$f_Y(y)=1-|y|\ (-1<y<1)$；(II) $f_{X|Y}(x|y)=\frac{1}{1-|y|}\ (|y|<x<1)$，$f_{Y|X}(y|x)=\frac{1}{2x}\ (-x<y<x)$；(III) $P\{X>\frac12\mid Y>0\}=\dfrac34$。

**易错点**：区域 $0<x<1,\ -x<y<x$ 中 $|y|<x$；求 $f_Y(y)$ 时对 $x$ 从 $|y|$ 积到 $1$（分 $y>0$ 与 $y<0$ 对称）；条件概率用"交事件/边缘概率"，勿直接对条件密度积分区间出错。

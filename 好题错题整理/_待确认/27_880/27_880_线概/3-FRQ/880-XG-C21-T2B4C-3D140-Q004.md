# FRQ 第 4 题

![[_Attachments/题目识别/880-XG/880-XG-C21-T2B4C-3D140-Q004_题目.png|题目]]

(4) 设随机变量 $X$ 与 $Y$ 相互独立，$X \sim N(0, \sigma^2) (\sigma > 0)$，$Y$ 的分布律为 $P \{ Y = -1 \} = a$，$P \{ Y = 1 \} = 1 - a (0 < a < 1)$，记 $Z = XY$。

(I) 求 $Z$ 的概率密度 $f_Z(z)$;

(II) 当 $a$ 为何值时，$X$ 与 $Z$ 不相关;

(III) 若 $Z_1, Z_2, \cdots, Z_n$ 为来自总体 $Z$ 的简单随机样本，$\overline{Z}$ 为样本均值，$S^2$ 为样本方差，记 $T = \overline{Z}^2 - S^2$，求 $DT$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C21-T2B4C-3D140-Q004_答案.png|答案]]

## V4 Pro Max 解析

**考点**：正态与对称两点分布之积的分布、不相关条件（协方差为 0）、样本均值与方差的独立性。

**解**

(I) 条件于 $Y$：$Z|Y=1=X\sim N(0,\sigma^2)$，$Z|Y=-1=-X\sim N(0,\sigma^2)$，二者分布相同，故无条件地

$$Z=XY\sim N(0,\sigma^2),\qquad f_Z(z)=\frac{1}{\sqrt{2\pi}\,\sigma}e^{-\frac{z^2}{2\sigma^2}}.$$

(II) $X$ 与 $Z$ 不相关 $\Leftrightarrow\mathrm{Cov}(X,Z)=0$。由 $E[X]=0$、$E[XY]=E[X]E[Y]=0$：

$$\mathrm{Cov}(X,XY)=E[X^2Y]-E[X]E[XY]=E[X^2]E[Y]=\sigma^2\big[1\cdot(1-a)+(-1)\cdot a\big]=\sigma^2(1-2a).$$

令其为 $0$，得 $a=\dfrac12$。

(III) $Z\sim N(0,\sigma^2)$，$Z_1,\dots,Z_n$ 独立同分布。$\overline{Z}\sim N(0,\frac{\sigma^2}{n})$，$\overline{Z}$ 与 $S^2$ 独立（正态总体），且

$$\overline{Z}^2=\frac{\sigma^2}{n}\chi^2(1),\qquad \frac{(n-1)S^2}{\sigma^2}\sim\chi^2(n-1).$$

$$D(\overline{Z}^2)=\left(\frac{\sigma^2}{n}\right)^2\cdot 2=\frac{2\sigma^4}{n^2},\qquad D(S^2)=\frac{2\sigma^4}{n-1},\qquad \mathrm{Cov}(\overline{Z}^2,S^2)=0.$$

$$DT=D(\overline{Z}^2-S^2)=\frac{2\sigma^4}{n^2}+\frac{2\sigma^4}{n-1}=2\sigma^4\left(\frac{1}{n^2}+\frac{1}{n-1}\right).$$

**答案**：(I) $f_Z(z)=\frac{1}{\sqrt{2\pi}\sigma}e^{-\frac{z^2}{2\sigma^2}}$；(II) $a=\dfrac12$；(III) $DT=2\sigma^4\left(\dfrac{1}{n^2}+\dfrac{1}{n-1}\right)$。

**易错点**：$Z$ 与 $X$ 同分布但不相关仅当 $a=\frac12$（此时 $EY=0$）；$D(S^2)=\frac{2\sigma^4}{n-1}$ 是正态总体 $S^2$ 的方差；$\overline{Z}^2$ 与 $S^2$ 独立是正态总体特有的性质。

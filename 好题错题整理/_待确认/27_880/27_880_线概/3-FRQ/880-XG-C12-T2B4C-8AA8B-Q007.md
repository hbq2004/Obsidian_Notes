# FRQ 第 7 题

![[_Attachments/题目识别/880-XG/880-XG-C12-T2B4C-8AA8B-Q007_题目.png|题目]]

(7) 设 $\alpha_1, \alpha_2, \alpha_3$ 与 $\beta_1, \beta_2, \beta_3$ 是 3 维向量空间的两组基，若向量 $\gamma$ 在这两组基下的坐标分别为 $(x_1, x_2, x_3)$ 与 $(y_1, y_2, y_3)$，且 $x_1 = y_1$, $x_2 = -y_1 + y_2$, $x_3 = -y_2 + y_3$。

(I) 求由基 $\alpha_1, \alpha_2, \alpha_3$ 到基 $\beta_1, \beta_2, \beta_3$ 的过渡矩阵；

(II) 若 $\alpha_1 = (1, 2, 3)^T$, $\alpha_2 = (2, 3, 1)^T$, $\alpha_3 = (3, 1, 2)^T$，求 $\beta_1, \beta_2, \beta_3$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C12-T2B4C-8AA8B-Q007_答案.png|答案]]

## V4 Pro Max 解析

**考点**：基变换与过渡矩阵:坐标变换矩阵与过渡矩阵互为转置关系。

**解**

(I) 设 $\gamma=(x_1,x_2,x_3)^T_{\{\alpha\}}=(y_1,y_2,y_3)^T_{\{\beta\}}$,即

$$\gamma=(\alpha_1,\alpha_2,\alpha_3)\begin{pmatrix}x_1\\x_2\\x_3\end{pmatrix}=(\beta_1,\beta_2,\beta_3)\begin{pmatrix}y_1\\y_2\\y_3\end{pmatrix}.$$

由 $x_1=y_1,\ x_2=-y_1+y_2,\ x_3=-y_2+y_3$,即 $x=Cy$,其中

$$C=\begin{pmatrix}1&0&0\\-1&1&0\\0&-1&1\end{pmatrix}.$$

于是 $(\beta_1,\beta_2,\beta_3)=(\alpha_1,\alpha_2,\alpha_3)C$,故由基 $\{\alpha\}$ 到基 $\{\beta\}$ 的过渡矩阵为 $P=C$。

(II) 由 $(\beta)=(\alpha)P$:

$$\beta_1=\alpha_1-\alpha_2=(1,2,3)^T-(2,3,1)^T=(-1,-1,2)^T,$$

$$\beta_2=\alpha_2-\alpha_3=(2,3,1)^T-(3,1,2)^T=(-1,2,-1)^T,$$

$$\beta_3=\alpha_3=(3,1,2)^T.$$

**答案**：(I) $P=\begin{pmatrix}1&0&0\\-1&1&0\\0&-1&1\end{pmatrix}$;(II) $\beta_1=(-1,-1,2)^T$,$\beta_2=(-1,2,-1)^T$,$\beta_3=(3,1,2)^T$。

**易错点**：过渡矩阵的列向量是 $\beta_j$ 在 $\{\alpha\}$ 基下的坐标;坐标变换 $x=Py$ 与基变换 $(\beta)=(\alpha)P$ 必须配对使用,方向别搞反。

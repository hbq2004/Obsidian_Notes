# FRQ 第 1 题

![[_Attachments/题目识别/880-XG/880-XG-C10-TB0B2-Q001_题目.png|题目]]

(1) 设矩阵 $A$ 为 3 阶非零实矩阵，$A^T = A^*$，且 $|E + A| = |E - A| = 0$，计算行列式 $|A^2 - A - 3E|$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C10-TB0B2-Q001_答案.png|答案]]

## V4 Pro Max 解析

**考点**：$A^T = A^*$ 蕴含 $A$ 正交;$|E \pm A| = 0$ 给出特征值,再求矩阵多项式的行列式。

**解**
由 $A^T = A^*$ 两边取行列式:$|A| = |A^T| = |A^*| = |A|^2$,即 $|A|(|A|-1) = 0$。

若 $|A| = 0$,则 $AA^T = AA^* = |A|E = O$,故 $\mathrm{tr}(AA^T) = \sum_{i,j} a_{ij}^2 = 0$,得 $A = O$,与 $A$ 非零实矩阵矛盾。故
$$|A| = 1,\qquad AA^T = AA^* = E,$$
即 $A$ 是正交矩阵。

$|E + A| = 0$ 且 $|E - A| = 0$,说明 $-1$ 与 $1$ 都是 $A$ 的特征值。正交矩阵的特征值模为 1,设第三个特征值为 $\lambda_3$,则
$$|A| = (-1)\cdot1\cdot\lambda_3 = 1 \implies \lambda_3 = -1.$$
故 $A$ 的特征值为 $1, -1, -1$。

矩阵多项式 $A^2 - A - 3E$ 的特征值为 $f(\lambda) = \lambda^2 - \lambda - 3$:
$$f(1) = 1 - 1 - 3 = -3,\qquad f(-1) = 1 + 1 - 3 = -1,$$
$$|A^2 - A - 3E| = (-3)\cdot(-1)\cdot(-1) = -3.$$

**答案**：$|A^2 - A - 3E| = -3$.

**易错点**：$|A| = 0$ 时由 $AA^T = O$ 推出 $A = O$(实矩阵满足 $AA^T = O$ 则 $A = O$),用非零条件排除;正交矩阵特征值模为 1,再结合 $|A| = 1$ 定出第三个特征值为 $-1$。

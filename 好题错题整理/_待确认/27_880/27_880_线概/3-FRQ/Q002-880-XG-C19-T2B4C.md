# FRQ 第 2 题

![[_Attachments/题目识别/880-XG/880-XG-C19-T2B4C-Q002_题目.png|题目]]

(2) 设随机变量 $X, Y, Z$，满足 $EX = EY = 1, EZ = -1$. $DX = DY = DZ = 1$, $\rho_{XY} = 0$, $\rho_{XZ} = \frac{1}{2}$， $\rho_{YZ} = -\frac{1}{2}$，求 $E(X + Y - 2Z)$, $D(X + Y + Z)$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C19-T2B4C-Q002_答案.png|答案]]

## V4 Pro Max 解析

**考点**：期望的线性性,以及方差公式 $D(\sum a_iX_i)=\sum a_i^2DX_i+2\sum_{i<j}a_ia_j\operatorname{Cov}(X_i,X_j)$。

**解**
由 $\rho_{XY}=\frac{\operatorname{Cov}(X,Y)}{\sqrt{DX\,DY}}$ 且 $DX=DY=DZ=1$,得
$$\operatorname{Cov}(X,Y)=\rho_{XY}\cdot1=0,\quad \operatorname{Cov}(X,Z)=\frac12,\quad \operatorname{Cov}(Y,Z)=-\frac12.$$

(I)
$$E(X+Y-2Z)=EX+EY-2EZ=1+1-2(-1)=\boxed{4}.$$

(II)
$$D(X+Y+Z)=DX+DY+DZ+2\operatorname{Cov}(X,Y)+2\operatorname{Cov}(X,Z)+2\operatorname{Cov}(Y,Z)$$
$$=1+1+1+0+2\cdot\frac12+2\cdot\left(-\frac12\right)=3-1+1=\boxed{3}.$$

**答案**：$E(X+Y-2Z)=4$,$D(X+Y+Z)=3$。

**易错点**：相关系数转协方差要乘以 $\sqrt{DX\,DY}$(本题恰为 1);和的方差展开时交叉项系数是 2,且每对协方差只算一次。

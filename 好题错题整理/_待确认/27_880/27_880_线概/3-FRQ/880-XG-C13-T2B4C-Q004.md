# FRQ 第 4 题

![[_Attachments/题目识别/880-XG/880-XG-C13-T2B4C-Q004_题目.png|题目]]

(4) 设有方程组 $(I) \begin{cases} x_1 + x_2 = 0, \\ x_2 - x_4 = 0, \end{cases}$ $(II) Ax = 0$，其中 $(II)$ 的基础解系为 $\alpha_1 = (-1, 2, 2, 1)^T$，$\alpha_2 = (0, -1, -1, 0)^T$，求方程组 $(I)$ 与 $(II)$ 的非零公共解.

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C13-T2B4C-Q004_答案.png|答案]]

## V4 Pro Max 解析

**考点**：两个齐次方程组（其一仅知基础解系）的公共解，用解空间的参数表示联立。

**解**

(I) 方程组(I)：$x_1+x_2=0,\ x_2-x_4=0$，其解为 $x=(s,-s,t,-s)^T$（自由变量 $s,t$），即 $x\in\operatorname{span}\{(1,-1,0,-1)^T,(0,0,1,0)^T\}$。

(II) 方程组(II) $Ax=0$ 的基础解系为 $\alpha_1=(-1,2,2,1)^T$，$\alpha_2=(0,-1,-1,0)^T$，故其解为

$$x=c_1\alpha_1+c_2\alpha_2=\begin{pmatrix}-c_1\\2c_1-c_2\\2c_1-c_2\\c_1\end{pmatrix}.$$

公共解须同时满足(I)(II)。由(I)的形式 $x=(s,-s,t,-s)$ 与(II)的形式比对各分量：

$$\begin{cases}s=-c_1,\\ -s=2c_1-c_2,\\ t=2c_1-c_2,\\ -s=c_1.\end{cases}$$

前两式给出 $c_1=s$，$c_2=2c_1+s=2s+s=3s$；第三式 $t=2c_1-c_2=2s-3s=-s$。故公共解

$$x=(s,-s,-s,-s)=s(1,-1,-1,-1)^T,\quad s\in\mathbb R.$$

非零公共解要求 $s\ne0$。

验证：代入(I) $x_1+x_2=1-1=0$，$x_2-x_4=-1+1=0$ ✓；代入(II) 表示 $x=s\alpha_1+s\alpha_2$（因 $c_1=c_2=s$）确属(II)解空间 ✓。

**答案**：非零公共解 $x=s(1,-1,-1,-1)^T$（$s\ne0$）。

**易错点**：两解空间的参数名要分开设（$s,t$ 与 $c_1,c_2$），比对分量时注意(I)解中第二、四分量都是 $-s$，第四分量 $x_4$ 与 $x_2$ 相等，这是最容易漏的一致性条件。

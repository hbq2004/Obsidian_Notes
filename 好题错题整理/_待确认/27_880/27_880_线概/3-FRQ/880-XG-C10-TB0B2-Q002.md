# FRQ 第 2 题

![[_Attachments/题目识别/880-XG/880-XG-C10-TB0B2-Q002_题目.png|题目]]

(2) 设 $A$ 为 3 阶非零实矩阵，且 $A^T = kA^*$（$k$ 为非零常数）。

(I) 证明：$A$ 是可逆矩阵；

(II) 求行列式 $|A^{-1}| + |(A^*)^{-1}|$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C10-TB0B2-Q002_答案.png|答案]]

## V4 Pro Max 解析

**考点**：$A^T = kA^*$ 的秩分析证明可逆;伴随矩阵行列式公式 $|A^*| = |A|^{n-1}$ 求值。

**解**
**(I) 证明 $A$ 可逆。**

反证。若 $|A| = 0$,即 $\mathrm{rank}(A) \le 2$:

- 若 $\mathrm{rank}(A) = 2$:3 阶伴随矩阵 $A^*$ 的秩为 1(奇异矩阵伴随的秩:$\mathrm{rank}(A) = n-1 \Rightarrow \mathrm{rank}(A^*) = 1$),则 $A^T = kA^*$ 的秩为 1,与 $\mathrm{rank}(A^T) = \mathrm{rank}(A) = 2$ 矛盾;
- 若 $\mathrm{rank}(A) \le 1$:则 $A^* = O$,得 $A^T = O$,即 $A = O$,与 $A$ 非零矛盾。

故 $|A| \neq 0$,$A$ 可逆。∎

**(II) 求 $|A^{-1}| + |(A^*)^{-1}|$。**

对 $A^T = kA^*$ 两边取行列式($A$ 为 3 阶):
$$|A| = k^3|A^*| = k^3|A|^2 \implies |A| = \frac{1}{k^3}.$$
$$|A^{-1}| = \frac{1}{|A|} = k^3,\qquad |(A^*)^{-1}| = \frac{1}{|A^*|} = \frac{1}{|A|^2} = k^6,$$
$$|A^{-1}| + |(A^*)^{-1}| = k^3 + k^6.$$

**答案**：(I) $A$ 可逆(证毕);(II) $k^3 + k^6$.

**易错点**：$k \neq 0$ 是前提;反证时区分 $\mathrm{rank}(A) = 2$ 与 $\mathrm{rank}(A) \le 1$ 两种情形;$|A^*| = |A|^{n-1}$ 对 $n$ 阶方阵成立,这里 $n = 3$。

(8)设 $A, B$ 均为 $n$ 阶方阵，且 $|A| = |B| = |A^{-1} + B| = 2$，则 $|A + B^{-1}| =$ \_ .

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C10-TC67C-Q008_答案.png|答案]]

## V4 Pro Max 解析

**考点**：$A^{-1} + B = A^{-1}(E + AB)$ 与 $A + B^{-1} = (E + AB)B^{-1}$ 的互化,把和式行列式化为积式。

**解**
$$A + B^{-1} = AB B^{-1} + B^{-1} = (AB + E)B^{-1} = A\big(A^{-1} + B\big)B^{-1},$$
两边取行列式:
$$|A + B^{-1}| = |A|\cdot\big|A^{-1} + B\big|\cdot\big|B^{-1}\big| = |A|\cdot\big|A^{-1}+B\big|\cdot\frac{1}{|B|}.$$

代入 $|A| = |B| = |A^{-1} + B| = 2$:
$$|A + B^{-1}| = 2\cdot2\cdot\frac{1}{2} = 2.$$

**答案**：$2$.

**易错点**：因式分解方向要准:$A^{-1} + B = A^{-1}(E + AB)$,$A + B^{-1} = (E + AB)B^{-1}$,公共因子都是 $E + AB$;别把 $B^{-1}$ 的行列式写成 $|B|$。

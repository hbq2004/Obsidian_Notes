# FIB 第 2 题

![[_Attachments/题目识别/880-XG/880-XG-C12-TC67C-Q002_题目.png|题目]]

(2) 已知 3 维线性空间的一组基为 $\alpha_1 = (1, 1, 0)$，$\alpha_2 = (1, 0, 1)$，$\alpha_3 = (0, 1, 1)$，则向量 $\beta = (2, 0, 0)$ 在上述基下的坐标为 \_ .

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C12-TC67C-Q002_答案.png|答案]]

## V4 Pro Max 解析

**考点**：向量在基下的坐标:解线性组合方程组。

**解**

设 $\beta=x\alpha_1+y\alpha_2+z\alpha_3$,即

$$x(1,1,0)+y(1,0,1)+z(0,1,1)=(2,0,0),$$

得方程组

$$\begin{cases}x+y=2,\\x+z=0,\\y+z=0.\end{cases}$$

由 $x+z=0$ 得 $z=-x$;由 $y+z=0$ 得 $y=x$;代入 $x+y=2$ 得 $2x=2$,即 $x=1,\ y=1,\ z=-1$。

故 $\beta$ 在该基下的坐标为 $(1,1,-1)$。

**答案**：$(1,\ 1,\ -1)$。

**易错点**：坐标是组合系数 $(x,y,z)$,不是 $\beta$ 本身的分量;三个方程要同时满足。

# FIB 第 3 题

![[_Attachments/题目识别/880-XG/880-XG-C12-TC67C-073D7-Q003_题目.png|题目]]

(3) 设 $\alpha_1 = (1, 1, 1)^T$, $\alpha_2 = (1, 0, -1)^T$, $\alpha_3 = (1, 0, 1)^T$ 与 $\beta_1 = (1, 2, 1)^T$, $\beta_2 = (3, 3, 3)^T$, $\beta_3 = (2, 4, 3)^T$ 是 $R^3$ 的两组基，则在两组基下有相同坐标的向量为 \_\_\_\_\_\_.

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C12-TC67C-073D7-Q003_答案.png|答案]]

## V4 Pro Max 解析

**考点**：两组基下坐标相同的向量 $\iff$ 解齐次方程组 $(A-B)x=0$。

**解**

设向量 $\gamma$ 在两组基下的坐标同为 $x=(x_1,x_2,x_3)^T$,则

$$(\alpha_1,\alpha_2,\alpha_3)x=(\beta_1,\beta_2,\beta_3)x\ \Longleftrightarrow\ (A-B)x=0,\qquad A-B=\begin{pmatrix}0&-2&-1\\-1&-3&-4\\0&-4&-2\end{pmatrix}.$$

解 $(A-B)x=0$:由第一行 $-2x_2-x_3=0$ 得 $x_3=-2x_2$;由第二行 $-x_1-3x_2-4x_3=0$ 得 $x_1=-3x_2-4x_3=5x_2$;第三行 $-4x_2-2x_3=0$ 自动满足。故

$$x=t(5,1,-2)^T\ (t\in\mathbb{R}).$$

于是 $\gamma=t(5\alpha_1+\alpha_2-2\alpha_3)=t\big(5(1,1,1)^T+(1,0,-1)^T-2(1,0,1)^T\big)=t(4,5,2)^T$。

检验:在 $\{\beta\}$ 基下 $5\beta_1+\beta_2-2\beta_3=(5,10,5)^T+(3,3,3)^T-(4,8,6)^T=(4,5,2)^T$ ✓。

**答案**：$\gamma=t(4,5,2)^T\ (t\in\mathbb{R})$,即 $k(4,5,2)^T$ 形式的所有向量($k\ne 0$ 的非零向量亦可)。

**易错点**：相同坐标 $\iff$ 两组基的矩阵差为奇异、$(A-B)x=0$ 有非零解;解是一维子空间,务必写通解。

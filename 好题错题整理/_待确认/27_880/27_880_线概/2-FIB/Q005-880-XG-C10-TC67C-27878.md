# FIB 第 5 题

![[_Attachments/题目识别/880-XG/880-XG-C10-TC67C-27878-Q005_题目.png|题目]]

设 $\alpha, \beta, \alpha_1, \alpha_2, \alpha_3$ 均为 4 维列向量，$A = (\alpha, \alpha_1, \alpha_2, \alpha_3)$，$B = (\beta, \alpha_1, \alpha_2, \alpha_3)$，且 $|A| = 2$，$|B| = 1$，则 $|A^{-1} + B^{-1}| =$ \_ .

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C10-TC67C-27878-Q005_答案.png|答案]]

## V4 Pro Max 解析

**考点**：$A^{-1} + B^{-1} = A^{-1}(A+B)B^{-1}$,把"和"的行列式化为"积"的行列式。

**解**
$$|A^{-1} + B^{-1}| = \big|A^{-1}(A + B)B^{-1}\big| = |A|^{-1}\cdot|A+B|\cdot|B|^{-1}.$$

$$A + B = (\alpha + \beta,\ 2\alpha_1,\ 2\alpha_2,\ 2\alpha_3),$$
$$|A + B| = 2^3\big|\alpha+\beta,\ \alpha_1,\ \alpha_2,\ \alpha_3\big| = 8\big(|\alpha,\alpha_1,\alpha_2,\alpha_3| + |\beta,\alpha_1,\alpha_2,\alpha_3|\big) = 8(2+1) = 24.$$

代入 $|A| = 2,\ |B| = 1$:
$$|A^{-1} + B^{-1}| = \frac{1}{2}\cdot24\cdot1 = 12.$$

**答案**：$12$.

**易错点**：因式分解次序 $A^{-1} + B^{-1} = A^{-1}(A+B)B^{-1}$ 不要写反;4 阶矩阵中第 2、3、4 列的数因子各提一次,共 $2^3$。

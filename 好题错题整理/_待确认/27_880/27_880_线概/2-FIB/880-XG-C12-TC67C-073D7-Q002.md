# FIB 第 2 题

![[_Attachments/题目识别/880-XG/880-XG-C12-TC67C-073D7-Q002_题目.png|题目]]

(2) 设向量组 $(I) \alpha_1 = (1, 1, 2)^T, \alpha_2 = (2, 3, 3)^T$; $(II) \beta_1 = (2, 3, 5)^T, \beta_2 = (-1, 0, 1)^T$，则既可由 $(I)$ 线性表示，又可由 $(II)$ 线性表示的非零列向量为 \_\_\_\_\_\_.

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C12-TC67C-073D7-Q002_答案.png|答案]]

## V4 Pro Max 解析

**考点**：两个子空间的交:同时被两组向量线性表示的非零向量。

**解**

设所求向量 $\gamma=x\alpha_1+y\alpha_2=u\beta_1+v\beta_2$($\gamma$ 非零)。代入:

$$x(1,1,2)^T+y(2,3,3)^T=u(2,3,5)^T+v(-1,0,1)^T,$$

即

$$\begin{cases}x+2y=2u-v,\\x+3y=3u,\\2x+3y=5u+v.\end{cases}$$

由前两式:$x=3u-3y$,代入第一式得 $3u-3y+2y=2u-v$,即 $y=u+v$,从而 $x=-3v$。代入第三式:

$$2(-3v)+3(u+v)=5u+v\ \Rightarrow\ 3u-3v=5u+v\ \Rightarrow\ u=-2v.$$

取 $v=1$,则 $u=-2$,$y=-1$,$x=-3$,得

$$\gamma=-3\alpha_1-\alpha_2=-3(1,1,2)^T-(2,3,3)^T=(-5,-6,-9)^T,$$

检验:$\gamma=-2\beta_1+\beta_2=-2(2,3,5)^T+(-1,0,1)^T=(-5,-6,-9)^T$ ✓。

**答案**：$k(-5,-6,-9)^T\ (k\ne 0)$,即 $(-5,-6,-9)^T$ 及其非零倍数。

**易错点**：答案是一整条直线(一维子空间),写通解 $k(-5,-6,-9)^T$ 更严谨;解方程组时注意自由参数只能取一个。

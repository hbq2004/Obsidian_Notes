# FIB 第 9 题

![[_Attachments/题目识别/880-XG/880-XG-C10-TC67C-Q009_题目.png|题目]]

(9) 设 $|A| = 2$，$|B| = -2$，其中 $A$，$B$ 均为 $n$ 阶方阵，则 $|A^{-1}B^* - A^*B^{-1}| = \＿$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C10-TC67C-Q009_答案.png|答案]]

## V4 Pro Max 解析

**考点**：用 $A^* = |A|A^{-1}$ 化简含伴随的差式,整体提公因子求行列式。

**解**
$A,\ B$ 均可逆($|A| \ne 0$、$|B| \ne 0$),故 $A^* = |A|A^{-1}$、$B^* = |B|B^{-1}$:
$$A^{-1}B^* - A^*B^{-1} = A^{-1}\cdot|B|B^{-1} - |A|A^{-1}\cdot B^{-1} = \big(|B| - |A|\big)A^{-1}B^{-1} = (-2-2)A^{-1}B^{-1} = -4A^{-1}B^{-1}.$$

两边取行列式($n$ 阶方阵):
$$\big|A^{-1}B^* - A^*B^{-1}\big| = (-4)^n\cdot|A|^{-1}\cdot|B|^{-1} = (-4)^n\cdot\frac{1}{2}\cdot\frac{1}{-2} = \frac{(-4)^n}{-4} = (-4)^{n-1}.$$

**答案**：$(-4)^{n-1}$.

**易错点**：伴随在可逆情形 $A^* = |A|A^{-1}$ 可整体替换;差式提因子后是 $n$ 阶矩阵 $A^{-1}B^{-1}$,行列式因子要乘 $n$ 次方。

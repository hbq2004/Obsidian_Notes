## V4 Pro Max 解析

**考点**：伯努利方程,令 $z = y^{-1}$ 化为一阶线性方程。

**解**
方程 $y' - \dfrac{6}{x}y + xy^2 = 0$,即 $y' - \dfrac{6}{x}y = -xy^2$。两边除以 $y^2$:
$$y^{-2}y' - \frac{6}{x}y^{-1} = -x.$$
令 $z = y^{-1}$,则 $z' = -y^{-2}y'$,得
$$-z' - \frac{6}{x}z = -x\;\Longrightarrow\; z' + \frac{6}{x}z = x.$$
积分因子 $\mu = e^{\int \frac{6}{x}dx} = x^6$:
$$(zx^6)' = x^7\;\Longrightarrow\; zx^6 = \frac{x^8}{8} + C.$$
故
$$\frac{1}{y} = \frac{x^2}{8} + \frac{C}{x^6}.$$

验证:$z = \dfrac{x^2}{8}+\dfrac{C}{x^6}$ 时 $z' + \dfrac{6}{x}z = \dfrac{x}{4} - \dfrac{6C}{x^7} + \dfrac{3x}{4} + \dfrac{6C}{x^7} = x$ ✓。

**答案**：$\dfrac{1}{y} = \dfrac{x^2}{8} + \dfrac{C}{x^6}$,即 $y = \dfrac{1}{\frac{x^2}{8} + \frac{C}{x^6}}$。

**易错点**：伯努利方程 $n=2$,换元 $z=y^{1-2}$;除以 $y^2$ 时勿把 $-6y/x$ 处理错符号。

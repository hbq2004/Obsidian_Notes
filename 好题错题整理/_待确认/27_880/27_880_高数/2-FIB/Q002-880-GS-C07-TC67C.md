# FIB 第 2 题

(2) $y' = \frac{y}{x} + \tan \frac{y}{x}$ 满足 $y(1) = \frac{\pi}{6}$ 的特解为 \_ .

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-TC67C-Q002_答案.png|答案]]

## V4 Pro Max 解析

**考点**：齐次方程(令 $u=y/x$)求解并代入初值。

**解**
令 $u = \dfrac{y}{x}$,则 $y = ux$,$y' = u + xu'$。代入
$$y' = \frac{y}{x} + \tan\frac{y}{x}$$
得
$$u + xu' = u + \tan u \;\Longrightarrow\; xu' = \tan u.$$
分离变量:
$$\cot u\,du = \frac{dx}{x}\;\Longrightarrow\; \ln|\sin u| = \ln|x| + C.$$
故 $\sin u = Cx$,即 $\sin\dfrac{y}{x} = Cx$。
由 $y(1) = \dfrac{\pi}{6}$:$\sin\dfrac{\pi}{6} = \dfrac{1}{2} = C$。

**答案**：$\sin\dfrac{y}{x} = \dfrac{x}{2}$。

**易错点**：齐次方程 $u + xu' = f(u)$ 的标准代换;注意 $u=\pi/6$ 处 $\tan u$ 无奇异性,直接代入即可。

# FIB 第 10 题

![[_Attachments/题目识别/880-GS/880-GS-C07-TC67C-BA690-Q010_题目.png|题目]]

(10) 设 $f(x)$ 有二阶连续导数，且 $f(x) = \int_{0}^{x} f(1-t) \, dt + 1$，则 $f(x) = \＿$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-TC67C-BA690-Q010_答案.png|答案]]

## V4 Pro Max 解析

**考点**：对积分等式求导两次化为一阶/二阶方程,再回代验证条件定常数。

**解**
$$f(x) = \int_0^x f(1-t)\,dt + 1.$$
求导得
$$f'(x) = f(1-x).$$
再求导:
$$f''(x) = -f'(1-x) = -f\big(1-(1-x)\big) = -f(x),$$
即
$$f'' + f = 0,\qquad f(x) = C_1\cos x + C_2\sin x.$$
由 $f(0) = 1$ 得 $C_1 = 1$。又 $f'(x) = f(1-x)$ 必须恒成立,代入:
$$f'(x) = -\sin x + C_2\cos x,\qquad f(1-x) = \cos(1-x) + C_2\sin(1-x).$$
比较 $\cos x,\ \sin x$ 的系数:
$$\cos x:\ C_2 = \cos 1 + C_2\sin 1 \;\Longrightarrow\; C_2(1-\sin 1) = \cos 1,$$
$$\sin x:\ -1 = \sin 1 - C_2\cos 1,$$
两者均给出 $C_2 = \dfrac{\cos 1}{1-\sin 1} = \dfrac{1+\sin 1}{\cos 1}$(二者相等,因为 $\cos^2 1 = (1-\sin1)(1+\sin1)$)。

**答案**：$f(x) = \cos x + \dfrac{\cos 1}{1-\sin 1}\sin x$。

**易错点**：$f''(x) = -f'(1-x)$ 中的链式求导别丢负号;定 $C_2$ 时必须把 $f'(x)=f(1-x)$ 作为恒等式回代(仅用 $f'(0)=f(1)$ 不足以确定)。

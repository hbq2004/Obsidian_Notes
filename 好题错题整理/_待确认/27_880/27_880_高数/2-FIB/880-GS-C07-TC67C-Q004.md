(4) 微分方程 $\left(1 + e^{\frac{x}{y}}\right) dx + e^{\frac{x}{y}} \left(1 - \frac{x}{y}\right) dy = 0 (y > 0)$ 的通解为 \_ .

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-TC67C-Q004_答案.png|答案]]

## V4 Pro Max 解析

**考点**：齐次方程(令 $u = x/y$)求解,注意 $y>0$ 的限制。

**解**
方程
$$\left(1+e^{x/y}\right)dx + e^{x/y}\left(1-\frac{x}{y}\right)dy = 0.$$
令 $u = \dfrac{x}{y}$,则 $x = uy$,$dx = udy + ydu$。代入:
$$\left(1+e^u\right)(u\,dy + y\,du) + e^u(1-u)dy = 0,$$
整理 $dy$ 的系数:
$$\big[u + ue^u + e^u - ue^u\big]dy + y(1+e^u)du = 0,$$
即
$$(u + e^u)dy + y(1+e^u)du = 0.$$
分离变量:
$$\frac{dy}{y} = -\frac{1+e^u}{u+e^u}du.$$
因 $d(u+e^u) = (1+e^u)du$,积分得
$$\ln|y| = -\ln|u+e^u| + C\;\Longrightarrow\; y(u+e^u) = C.$$
代回 $u = x/y$:$y\left(\dfrac{x}{y} + e^{x/y}\right) = C$,即
$$x + ye^{x/y} = C.$$

验证:$1 + y'e^{x/y} + e^{x/y}\left(1 - \dfrac{x}{y}\right)\cdot$ 隐式求导得 $(1+e^{x/y})dx + e^{x/y}(1-x/y)dy = 0$ ✓。

**答案**：$x + ye^{x/y} = C$($y>0$,$C$ 为任意常数)。

**易错点**：这里应令 $u = x/y$(分母含 $e^{x/y}$),不是 $y/x$;$dy$ 的系数 $u+e^u$ 的微分恰为 $(1+e^u)du$,是本题的精妙之处。

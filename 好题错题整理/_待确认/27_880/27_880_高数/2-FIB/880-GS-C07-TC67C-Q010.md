(10) 设二阶线性非齐次微分方程 $y'' + p(x)y' + q(x)y = f(x)$ 有三个特解为 $x, e^x, e^{-x}$，则该方程的通解为 \_ .

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-TC67C-Q010_答案.png|答案]]

## V4 Pro Max 解析

**考点**：线性微分方程解的结构:非齐次方程任意两个特解之差是齐次方程的解。

**解**
设 $y_1 = x,\ y_2 = e^x,\ y_3 = e^{-x}$ 是非齐次方程
$$y'' + p(x)y' + q(x)y = f(x)$$
的三个特解。则
$$y_1 - y_3 = x - e^{-x},\qquad y_2 - y_3 = e^x - e^{-x}$$
均为对应齐次方程的解,且二者线性无关($x,\ e^x,\ e^{-x}$ 线性无关,可验证 Wronskian 非零)。
故齐次通解为 $C_1(x-e^{-x}) + C_2(e^x - e^{-x})$,非齐次通解为
$$y = y_3 + C_1(x - e^{-x}) + C_2(e^x - e^{-x}) = x + C_1(e^x - x) + C_2(e^{-x} - x).$$

**答案**：$y = x + C_1(e^x - x) + C_2(e^{-x} - x)$(也可写为 $y = C_1e^x + C_2e^{-x} + (1-C_1-C_2)x$)。

**易错点**：特解之差才是齐次解,不要把 $x,e^x,e^{-x}$ 直接当作齐次基础解系;答案需保留两个独立任意常数。

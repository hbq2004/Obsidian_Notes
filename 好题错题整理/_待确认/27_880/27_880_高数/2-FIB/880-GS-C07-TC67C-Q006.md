(6) 方程 $y'' + 2y' + y = xe^x$ 满足 $y(0) = 0$，$y'(0) = 0$ 的特解为 \_ .

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-TC67C-Q006_答案.png|答案]]

## V4 Pro Max 解析

**考点**：二阶常系数非齐次方程(重根 $r=-1$,$e^x$ 项非共振),待定系数 + 初值。

**解**
齐次方程 $y''+2y'+y=0$ 的特征方程 $(r+1)^2 = 0$,重根 $r=-1$:
$$y_h = (C_1 + C_2x)e^{-x}.$$
对非齐次项 $xe^x$,$\lambda = 1$ 不是特征根,设 $y_p = (Ax+B)e^x$:
$$y_p' = (Ax + A + B)e^x,\qquad y_p'' = (Ax + 2A + B)e^x.$$
代入:
$$y_p'' + 2y_p' + y_p = (4Ax + 4A + 4B)e^x = xe^x,$$
得 $4A = 1,\ 4A+4B = 0$,即 $A = \dfrac{1}{4},\ B = -\dfrac{1}{4}$。故
$$y = (C_1 + C_2x)e^{-x} + \frac{x-1}{4}e^x.$$
由 $y(0) = 0$ 得 $C_1 - \dfrac{1}{4} = 0$,即 $C_1 = \dfrac{1}{4}$;由 $y'(0) = 0$ 得 $C_2 - C_1 = 0$,即 $C_2 = \dfrac{1}{4}$。

**答案**：$y = \dfrac{1+x}{4}e^{-x} + \dfrac{x-1}{4}e^x$。

**易错点**：齐次通解含 $(C_1+C_2x)e^{-x}$(重根);$y'$ 求导时 $(Ax+B)e^x$ 的链式项别丢。

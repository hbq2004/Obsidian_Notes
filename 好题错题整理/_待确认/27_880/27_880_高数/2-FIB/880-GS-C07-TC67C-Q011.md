(11) 设二阶常系数线性微分方程 $y'' + ay' + by = ce^x$ 有特解 $y^* = e^{-x}(1 + xe^{2x})$，则该方程的通解为 \_ .

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-TC67C-Q011_答案.png|答案]]

## V4 Pro Max 解析

**考点**：由特解反推微分方程的系数(线性叠加与共振分析),再写通解。

**解**
特解 $y^* = e^{-x}(1 + xe^{2x}) = e^{-x} + xe^x$。设算子 $L = D^2 + aD + b$。
$$L[e^{-x}] = (1 - a + b)e^{-x},$$
$$L[xe^x] = (x+2)e^x + a(x+1)e^x + bxe^x = \big[(1+a+b)x + (2+a)\big]e^x.$$
由 $L[y^*] = ce^x$ 知 $e^{-x}$ 的系数必须为 0,且 $x e^x$ 的系数必须为 0:
$$1 - a + b = 0,\qquad 1 + a + b = 0,$$
解得 $a = 0,\ b = -1$。此时 $L[xe^x] = (2+a)e^x = 2e^x = ce^x$,故 $c = 2$。
方程为 $y'' - y = 2e^x$。特征根 $r = \pm1$,齐次通解 $C_1e^x + C_2e^{-x}$。因 $xe^x$ 为共振特解,通解为
$$y = C_1e^x + C_2e^{-x} + xe^x.$$

**答案**：$y = C_1e^x + C_2e^{-x} + xe^x$。

**易错点**：$y^* = e^{-x} + xe^x$ 中 $xe^x$ 的出现说明 $r=1$ 是特征根且与 $e^x$ 共振;用叠加法分别作用 $L$ 时系数匹配要仔细。

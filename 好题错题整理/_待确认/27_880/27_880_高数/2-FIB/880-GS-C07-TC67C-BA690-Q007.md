# FIB 第 7 题

![[_Attachments/题目识别/880-GS/880-GS-C07-TC67C-BA690-Q007_题目.png|题目]]

(7)设函数y(x)满足y'' + 2ay' $+ b^2y = 0 (a > b > 0)$，且y(0) = 1，y'(0) = 1，则$\int_{0}^{+\infty}y(x)dx = ＿ .$

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-TC67C-BA690-Q007_答案.png|答案]]

## V4 Pro Max 解析

**考点**：特征根均为负实根时解趋于 0,利用积分与微分可交换(或直接积分方程)求 $\int_0^{+\infty}y\,dx$。

**解**
特征方程 $r^2 + 2ar + b^2 = 0$,判别式 $\Delta = 4(a^2-b^2) > 0$(因 $a>b>0$),两根
$$r_{1,2} = -a \pm \sqrt{a^2-b^2} < 0,$$
故 $y(x) \to 0,\ y'(x) \to 0\ (x\to+\infty)$,且 $\int_0^{+\infty}y\,dx$ 收敛。
对方程 $y'' + 2ay' + b^2 y = 0$ 在 $[0,+\infty)$ 上积分:
$$\int_0^{+\infty}y''\,dx + 2a\int_0^{+\infty}y'\,dx + b^2\int_0^{+\infty}y\,dx = 0.$$
其中
$$\int_0^{+\infty}y''dx = \lim_{x\to+\infty}y'(x) - y'(0) = -1,\qquad
\int_0^{+\infty}y'dx = \lim_{x\to+\infty}y(x) - y(0) = -1,$$
代入得 $-1 - 2a + b^2\int_0^{+\infty}y\,dx = 0$。

**答案**：$\displaystyle\int_0^{+\infty}y(x)\,dx = \frac{2a+1}{b^2}$。

**易错点**：不要先解出 $y$ 再积分(含指数项也可做但繁琐);直接对微分方程积分,注意 $\int y'' = y'(\infty)-y'(0)$ 的负号。

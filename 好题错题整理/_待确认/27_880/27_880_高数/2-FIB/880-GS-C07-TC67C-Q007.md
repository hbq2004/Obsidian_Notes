# FIB 第 7 题

(7) 方程 $y'' - 3y' + 2y = 10e^{-x}\sin x$ 满足当 $x \to +\infty$ 时， $y(x) \to 0$ 的特解为 \_ .

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-TC67C-Q007_答案.png|答案]]

## V4 Pro Max 解析

**考点**：二阶常系数非齐次方程,$e^{-x}\sin x$ 项非共振,由 $x\to+\infty$ 条件消去增长项。

**解**
齐次方程 $y''-3y'+2y=0$ 的特征方程 $r^2-3r+2=0$,根 $r=1,2$:
$$y_h = C_1e^x + C_2e^{2x}.$$
非齐次项 $10e^{-x}\sin x$ 对应 $\lambda = -1\pm i$,不是特征根,设
$$y_p = e^{-x}(A\cos x + B\sin x).$$
计算:
$$y_p' = e^{-x}\big[(B-A)\cos x - (A+B)\sin x\big],$$
$$y_p'' = e^{-x}\big[-2B\cos x + 2A\sin x\big].$$
代入 $y''-3y'+2y$:
$$y_p''-3y_p'+2y_p = e^{-x}\big[5(A-B)\cos x + 5(A+B)\sin x\big] = 10e^{-x}\sin x.$$
得 $A-B = 0,\ A+B = 2$,即 $A = B = 1$,$y_p = e^{-x}(\cos x+\sin x)$。
通解 $y = C_1e^x + C_2e^{2x} + e^{-x}(\cos x+\sin x)$。因 $x\to+\infty$ 时 $y\to 0$,必须 $C_1 = C_2 = 0$。

**答案**：$y = e^{-x}(\cos x + \sin x)$。

**易错点**：$e^{-x}\sin x$ 对应 $\lambda=-1\pm i$,与特征根 $1,2$ 不同,特解不乘 $x$;增长项 $e^x,e^{2x}$ 的系数必须为 0。

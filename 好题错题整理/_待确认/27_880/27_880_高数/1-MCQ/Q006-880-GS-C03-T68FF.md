# MCQ 第 6 题

![[_Attachments/题目识别/880-GS/880-GS-C03-T68FF-Q006_题目.png|题目]]

(6) $f(x) = \begin{cases} x^2 + 1, & x \leq 0, \\ \cos x, & x > 0 \end{cases}$ 的一个原函数为().

A. $F(x) = \begin{cases} \frac{1}{3} x^3 + x, & x \leq 0 \\ \sin x + 1, & x > 0 \end{cases}$

B. $F(x) = \begin{cases} \frac{1}{3} x^3 + x + 1, & x \leq 0 \\ \sin x + 2, & x > 0 \end{cases}$

C. $F(x) = \begin{cases} \frac{1}{3} x^3 + x + 1, & x \leq 0 \\ \sin x, & x > 0 \end{cases}$

D. $F(x) = \begin{cases} \frac{1}{3} x^3 + x, & x \leq 0 \\ \sin x, & x > 0 \end{cases}$

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C03-T68FF-Q006_答案.png|答案]]

## V4 Pro Max 解析

**考点**：分段函数求原函数：逐段求不定积分后，用连续性（在分段点处）衔接常数，并验证可导性。

**解**
逐段积分：
$$x\le0:\quad F_1(x)=\int(x^2+1)\,dx=\frac13x^3+x+C_1,\qquad x>0:\quad F_2(x)=\int\cos x\,dx=\sin x+C_2.$$
原函数须连续，故在 $x=0$ 处 $F_1(0)=F_2(0)$，即 $C_1=\sin0+C_2=C_2$。记 $C_1=C_2=C$，得
$$F(x)=\begin{cases}\frac13x^3+x+C,&x\le0,\\ \sin x+C,&x>0.\end{cases}$$
取 $C=0$ 得选项 D 的函数；其余选项 $C_1\ne C_2$ 均在 $x=0$ 处不连续，不可能为原函数。再验证可导性：$F'_-(0)=1$，$F'_+(0)=\cos0=1$，$F'(0)=1=f(0)$，且各分段内 $F'=f$，故 D 确为 $f$ 的一个原函数。

**答案**：**D**。

**易错点**：原函数必须在分段点连续——先满足连续性（$C_1=C_2$）再谈可导；选项 A、B、C 的错误都出在常数不匹配。

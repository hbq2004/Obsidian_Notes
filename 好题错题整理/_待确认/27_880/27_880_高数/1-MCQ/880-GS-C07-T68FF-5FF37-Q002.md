# MCQ 第 2 题

![[_Attachments/题目识别/880-GS/880-GS-C07-T68FF-5FF37-Q002_题目.png|题目]]

(2) 若二阶常系数线性齐次微分方程 $y'' + py' + qy = 0$ 的通解为 $y = C_1 e^x + C_2 x e^x$，则非齐次微分方程 $y'' + py' + qy = x$ 满足 $y(0) = 2$，$y'(0) = 0$ 的特解为 $y = (\＿)$。

A. $xe^x - x - 2$

B. $xe^x - x + 2$

C. $-xe^x + x + 2$

D. $-xe^x - x + 2$

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-T68FF-5FF37-Q002_答案.png|答案]]

## V4 Pro Max 解析

**考点**：由齐次通解定特征根,再求非齐次特解与初值。

**解**
齐次通解 $C_1e^x + C_2xe^x$ 说明特征根为二重根 $r = 1$,特征多项式 $(r-1)^2 = r^2 - 2r + 1$,故 $p = -2,\ q = 1$,方程为
$$y'' - 2y' + y = x.$$
设特解 $y_p = ax + b$:$y_p'' - 2y_p' + y_p = -2a + ax + b = x$,得 $a = 1,\ b = 2$,$y_p = x + 2$。通解
$$y = C_1e^x + C_2xe^x + x + 2.$$
由 $y(0) = 2$ 得 $C_1 = 0$;由 $y' = C_2e^x(1+x) + 1$ 及 $y'(0) = 0$ 得 $C_2 = -1$。
$$y = -xe^x + x + 2.$$

**答案**：C。

**易错点**：齐次通解 $C_1e^x + C_2xe^x$ 对应重根 $r=1$,$p=-2$ 而非 $p=2$;待定特解 $ax+b$ 不含 $x$ 因子(0 不是特征根)。

# MCQ 第 12 题

![[_Attachments/题目识别/880-GS/880-GS-C03-T68FF-Q012_题目.png|题目]]

(12) 设 $\lim\limits_{x \to 0} \frac{1}{\sin x - ax} \int_{b}^{x} \frac{t^2}{\sqrt{1 + t^2}} dt = c$，且 $c \neq 0$，则( ).

A. $a = 1, b = 0, c = -2$

B. $a = 1, b = -2, c = -2$

C. $a = 0, b = 1, c = -2$

D. $a = 1, b = 1, c = 1$

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C03-T68FF-Q012_答案.png|答案]]

## V4 Pro Max 解析

**考点**：变上限积分在 $x\to0$ 处的等价无穷小展开，与分母（$\sin x-ax$）匹配确定参数。

**解**
设 $G(x)=\int_b^x\frac{t^2}{\sqrt{1+t^2}}\,dt$。若 $b\ne0$，则 $G(0)=\int_b^0\frac{t^2}{\sqrt{1+t^2}}dt\ne0$，此时 $x\to0$ 时分子趋于非零常数而分母趋于 $0$，极限为无穷大，与 $c\ne0$ 矛盾。故 $b=0$。

于是 $G(x)=\int_0^x\frac{t^2}{\sqrt{1+t^2}}dt$。因 $\dfrac{t^2}{\sqrt{1+t^2}}\sim t^2$，有 $G(x)\sim\dfrac{x^3}{3}$。又 $\sin x-ax=(1-a)x-\dfrac{x^3}{6}+o(x^3)$，为使极限为有限非零数，$x$ 的最低次项必须抵消，故 $a=1$。此时
$$c=\lim_{x\to0}\frac{\frac{x^3}{3}+o(x^3)}{-\frac{x^3}{6}+o(x^3)}=-2.$$

**答案**：**A**（$a=1,\ b=0,\ c=-2$）。

**易错点**：先由"分子趋于非零常数"排除 $b\ne0$；再匹配无穷小阶数定 $a=1$；分母 $\sin x-x\sim-\frac{x^3}{6}$ 的符号决定 $c<0$。

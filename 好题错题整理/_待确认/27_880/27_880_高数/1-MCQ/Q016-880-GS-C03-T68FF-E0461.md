# MCQ 第 16 题

![[_Attachments/题目识别/880-GS/880-GS-C03-T68FF-E0461-Q016_题目.png|题目]]

(16) 已知 $I = \int_{0}^{+\infty} \left( \frac{1}{\sqrt{x^2 + 4}} - \frac{a}{x + 2} \right) dx$ 收敛，则()。

A. $a = 1$，$I = \ln 4$

B. $a > 1$，$I = \ln 2$

C. $a = 1$，$I = \ln 2$

D. $a < 1$，$I = \ln 4$

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C03-T68FF-E0461-Q016_答案.png|答案]]

## V4 Pro Max 解析

**考点**：先由无穷远端的"无穷大抵消"定出 $a$，再求反常积分值。

**解**
$x\to+\infty$ 时 $\dfrac{1}{\sqrt{x^2+4}}\sim\dfrac1x$，$\dfrac{a}{x+2}\sim\dfrac{a}{x}$。若积分收敛，两项的无穷大必须抵消，故 $a=1$。

此时
$$I=\int_{0}^{+\infty}\left(\frac{1}{\sqrt{x^2+4}}-\frac{1}{x+2}\right)dx.$$
因 $\int\frac{dx}{\sqrt{x^2+4}}=\ln\big(x+\sqrt{x^2+4}\big)$（可求导验证），故
$$I=\Big[\ln\big(x+\sqrt{x^2+4}\big)-\ln(x+2)\Big]_{0}^{+\infty}
=\lim_{x\to+\infty}\ln\frac{x+\sqrt{x^2+4}}{x+2}-\ln\frac{2}{2}.$$
$$\lim_{x\to+\infty}\frac{x+\sqrt{x^2+4}}{x+2}=\lim_{x\to+\infty}\frac{1+\sqrt{1+\frac4{x^2}}}{1+\frac2x}=2,$$
故 $I=\ln2$。

**答案**：$a=1,\ I=\ln2$，选 **C**。

**易错点**：$a\ne1$ 时积分发散（被积函数 $\sim\frac{1-a}{x}$），先定 $a$ 再积分；上下限代入时 $x=0$ 处 $\ln\frac{0+\sqrt4}{2}=\ln1=0$。

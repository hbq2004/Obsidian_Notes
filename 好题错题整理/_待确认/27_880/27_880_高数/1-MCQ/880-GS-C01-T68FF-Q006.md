# MCQ 第 6 题

![[_Attachments/题目识别/880-GS/880-GS-C01-T68FF-Q006_题目.png|题目]]

(6) 已知 $\lim\limits_{x \to \infty} \left( \frac{x^2}{x + 1} - ax - b \right) = 0$，则()。

A. $a = 1, b = 1$

B. $a = -1, b = 1$

C. $a = 1, b = -1$

D. $a = -1, b = -1$

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C01-T68FF-Q006_答案.png|答案]]

## V4 Pro Max 解析

**考点**：$\dfrac{\infty}{\infty}$ 型极限的分离（多项式长除法/待定系数）。

**解**

由长除法
$$\frac{x^{2}}{x+1}=x-1+\frac{1}{x+1}$$
于是
$$\frac{x^{2}}{x+1}-ax-b=(1-a)x-(1+b)+\frac{1}{x+1}$$
当 $x\to\infty$ 时 $\dfrac{1}{x+1}\to 0$，故极限为 $0$ 当且仅当一次项与常数项系数均为 $0$：
$$1-a=0,\qquad -(1+b)=0\ \Longrightarrow\ a=1,\ b=-1$$

**答案**：C

**易错点**：先把假分式化为"整式+真分式"，再令整式部分为零，不要直接对 $x^{2},ax,b$ 逐项取极限（各项均发散）。

# MCQ 第 5 题

![[_Attachments/题目识别/880-GS/880-GS-C07-T68FF-Q005_题目.png|题目]]

(5) 设 $y_1(x)$, $y_2(x)$, $y_3(x)$ 是微分方程 $y'' + p(x)y' + q(x)y = f(x)$ 的三个线性无关的解, $f(x) \neq 0$, 则该方程的通解为 (\_).

A. $C_1y_1(x) + C_2y_2(x) + y_3(x)$

B. $C_1y_1(x) + (1 - 2C_1)y_2(x) + C_1y_3(x)$

C. $(C_1 - C_2)y_1(x) + C_2y_2(x) + y_3(x)$

D. $C_1y_1(x) + C_2y_2(x) + C_3y_3(x)(C_1 + C_2 + C_3 = 1)$

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-T68FF-Q005_答案.png|答案]]

## V4 Pro Max 解析

**考点**：非齐次线性方程通解 = 特解 + 齐次通解(两参数);解的结构判断。

**解**
$y_1, y_2, y_3$ 线性无关,且都是非齐次方程的解。则 $y_1 - y_3,\ y_2 - y_3$ 是对应齐次方程的两个线性无关解。通解为
$$y = y_3 + C_1(y_1 - y_3) + C_2(y_2 - y_3) = C_1y_1 + C_2y_2 + (1 - C_1 - C_2)y_3,$$
即三个系数的和为 1,对应选项 D。
排除其余项:A 中 $C_1y_1 + C_2y_2 + y_3$ 的系数和为 $C_1 + C_2 + 1 \ne 1$,代入算子得 $(C_1+C_2+1)f \ne f$;C 同理系数和 $C_1 + 1 \ne 1$;B 只含一个任意常数,不是二阶方程的通解。

**答案**：D。

**易错点**：通解必须含两个独立参数(B 只有 $C_1$,排除);系数和 $\Sigma C_i = 1$ 是"三解线性组合仍为非齐次解"的充要条件,而 D 恰好由此给出两参数族。

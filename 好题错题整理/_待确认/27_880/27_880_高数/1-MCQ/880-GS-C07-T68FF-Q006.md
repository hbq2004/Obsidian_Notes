# MCQ 第 6 题

![[_Attachments/题目识别/880-GS/880-GS-C07-T68FF-Q006_题目.png|题目]]

(6) 设 $y_1 = e^{-x}$，$y_2 = 2x$ 是常系数齐次线性微分方程 $y''' + ay'' + by' + cy = 0$ 的两个解，则该方程的通解是 ( )。

A. $C_1 e^{-x} + C_2 + C_3 x$

B. $C_1 e^{-x} + C_2 e^x + C_3 x$

C. $C_1 e^{-x} + C_2 e^x + C_3$

D. $C_1 e^{-x} + C_2 x e^x + C_3$

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-T68FF-Q006_答案.png|答案]]

## V4 Pro Max 解析

**考点**：由特解反推特征根与通解(含"$x$ 是解 $\Rightarrow$ 0 是特征根")。

**解**
方程 $y''' + ay'' + by' + cy = 0$ 为常系数齐次方程。
$y_1 = e^{-x}$ 是解 $\Rightarrow r = -1$ 是特征根。$y_2 = 2x$ 是解 $\Rightarrow$ 因 $L[2x] = 2b + 2cx$,$x$ 与常数项系数须同时为 0,即 $b = c = 0$;且 $L[1] = c = 0$。故特征多项式为
$$r^3 + ar^2 = r^2(r + a),$$
特征根 $0$(二重)、$-a$。由 $e^{-x}$ 是解得 $-a = -1$,即 $a = 1$。故通解
$$y = C_1 + C_2x + C_3e^{-x}.$$

**答案**：A。

**易错点**：$2x$ 是解意味着 $x$ 与 $1$ 都是解(线性空间封闭),由此推出 0 是二重特征根;通解中 $C_1 + C_2x$ 对应 $r=0$ 二重根。

# FRQ 第 6 题

![[_Attachments/题目识别/880-GS/880-GS-C07-T2B4C-Q006_题目.png|题目]]

(6) 求微分方程 $y''' - y' = 0$ 的一条积分曲线，使此积分曲线在原点处有拐点，且以直线 $y = 2x$ 为切线.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-T2B4C-Q006_答案.png|答案]]

## V4 Pro Max 解析

**考点**：三阶常系数齐次方程 + 拐点/切线几何条件定常数。

**解**
$y''' - y' = 0$ 的特征方程 $r^3 - r = r(r^2-1) = 0$,根 $r = 0, \pm1$,通解
$$y = C_1 + C_2e^x + C_3e^{-x}.$$
条件:(1) 在原点有拐点,$y''(0) = 0$;(2) 原点处切线为 $y = 2x$,即 $y(0) = 0,\ y'(0) = 2$。
$$y' = C_2e^x - C_3e^{-x},\qquad y'' = C_2e^x + C_3e^{-x},$$
$$y(0) = C_1 + C_2 + C_3 = 0,\qquad y'(0) = C_2 - C_3 = 2,\qquad y''(0) = C_2 + C_3 = 0.$$
解得 $C_2 = 1,\ C_3 = -1,\ C_1 = 0$。

**答案**：$y = e^x - e^{-x} = 2\sinh x$。

**易错点**：拐点条件 $y''(0)=0$ 之外还要验证 $y''$ 变号(本题 $y'' = 2\sinh x$,在 $x=0$ 两侧变号 ✓);三阶方程要写全三个条件。

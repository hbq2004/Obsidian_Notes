# FRQ 第 3 题

![[_Attachments/题目识别/880-GS/880-GS-C07-T2B4C-B9B29-Q003_题目.png|题目]]

(3) 设微分方程 $\frac{d^2 y}{dx^2} + \frac{dy}{dx} + e^{-2x} y = e^{-3x}$.

(I) 利用变换 $t = e^{-x}$ 将微分方程化为 $y$ 关于 $t$ 的方程，并求原方程的通解 $y(x)$;

(II) 若 (I) 中的 $y(x)$ 满足 $\lim\limits_{x \to +\infty} y(x) = 1, y(0) = 1$，求 $y(x)$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-T2B4C-B9B29-Q003_答案.png|答案]]

## V4 Pro Max 解析

**考点**：$t = e^{-x}$ 换元化简变系数二阶方程($y_{tt}+y=t$),极限与初值定常数。

**解**
令 $t = e^{-x}$,则 $\dfrac{dt}{dx} = -e^{-x} = -t$。
$$\frac{dy}{dx} = \dot y\cdot\frac{dt}{dx} = -t\dot y,$$
$$\frac{d^2y}{dx^2} = \frac{d}{dx}\big(-t\dot y\big) = -t(-t\dot y) - t\frac{d}{dx}\dot y = t^2\dot y - t\cdot(-t\ddot y) = t^2\ddot y + t\dot y,$$
其中 $\dot y = \dfrac{dy}{dt}$。代入原方程:
$$y'' + y' + e^{-2x}y = t^2\ddot y + t\dot y - t\dot y + t^2y = t^2(\ddot y + y) = e^{-3x} = t^3,$$
故
$$\ddot y + y = t.$$
齐次通解 $C_1\cos t + C_2\sin t$,特解 $y_p = t$(因 $\ddot t + t = t$),故
$$y = C_1\cos t + C_2\sin t + t = C_1\cos(e^{-x}) + C_2\sin(e^{-x}) + e^{-x}.$$
**(II)** 由 $\lim\limits_{x\to+\infty}y(x) = 1$:$t\to 0$ 时 $y\to C_1 = 1$。由 $y(0) = 1$:
$$y(0) = \cos 1 + C_2\sin 1 + 1 = 1\;\Longrightarrow\; C_2 = -\cot 1.$$

**答案**：(I) 化为 $\ddot y + y = t$,通解 $y = C_1\cos(e^{-x}) + C_2\sin(e^{-x}) + e^{-x}$;(II) $y = \cos(e^{-x}) - \cot 1\cdot\sin(e^{-x}) + e^{-x}$。

**易错点**：$t = e^{-x}$ 时 $\dfrac{dt}{dx} = -t$,二阶导的 $t^2\ddot y + t\dot y$ 中 $t\dot y$ 与 $-t\dot y$ 恰好抵消,这是出题点;极限条件只定出 $C_1$。

# FRQ 第 1 题

![[_Attachments/题目识别/880-GS/880-GS-C07-T2B4C-Q001_题目.png|题目]]

(1) 求 $x^2 y'' - y'^2 = 0$ 过点 $P(1,0)$，且在点 $P$ 与 $y = x - 1$ 相切的积分曲线.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-T2B4C-Q001_答案.png|答案]]

## V4 Pro Max 解析

**考点**：缺 $y$ 的可降阶方程(令 $p=y'$),初值(过点 + 相切)定常数。

**解**
方程 $x^2y'' - y'^2 = 0$,缺 $y$。令 $p = y'$,$y'' = p'$,得
$$x^2p' = p^2\;\Longrightarrow\; \frac{dp}{p^2} = \frac{dx}{x^2}.$$
积分:
$$-\frac{1}{p} = -\frac{1}{x} + C\;\Longrightarrow\; p = \frac{x}{1 - Cx}.$$
曲线过 $P(1,0)$ 且与 $y = x-1$ 相切,故 $y(1) = 0$,$y'(1) = 1$。由 $p(1) = 1$:
$$\frac{1}{1 - C} = 1\;\Longrightarrow\; C = 0,$$
故 $y' = x$,积分得 $y = \dfrac{x^2}{2} + D$。由 $y(1) = 0$ 得 $D = -\dfrac12$。

**答案**：$y = \dfrac{x^2 - 1}{2}$。

**易错点**："与 $y = x-1$ 相切"给出 $y'(1) = 1$ 与 $y(1) = 0$ 两个条件,都用来定常数;积分时 $-\dfrac{1}{p} = -\dfrac{1}{x} + C$ 的整理别出错。

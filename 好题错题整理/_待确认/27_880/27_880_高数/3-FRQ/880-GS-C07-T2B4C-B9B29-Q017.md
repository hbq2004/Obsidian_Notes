# FRQ 第 17 题

![[_Attachments/题目识别/880-GS/880-GS-C07-T2B4C-B9B29-Q017_题目.png|题目]]

(17)一架质量为4.5t的歼击机以600km/h的航速开始着陆，在减速伞的作用下滑跑500m后速度减为100km/h，设减速伞的阻力与飞机的速度成正比，忽略飞机所受的其他外力，求减速伞的阻力系数.若保障飞机安全着陆，跑道长度至少应为多少？

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-T2B4C-B9B29-Q017_答案.png|答案]]

## V4 Pro Max 解析

**考点**：牛顿第二定律建模(阻力与速度成正比),一阶可分离变量方程,单位换算。

**解**
取运动方向为正,飞机质量 $m = 4.5\,\text{t} = 4500\,\text{kg}$,阻力 $F = kv$($k$ 为阻力系数,方向与速度相反)。由牛顿第二定律:
$$m\frac{dv}{dt} = -kv.$$
利用 $\dfrac{dv}{dt} = v\dfrac{dv}{ds}$($s$ 为滑跑路程):
$$mv\frac{dv}{ds} = -kv\;\Longrightarrow\; \frac{dv}{ds} = -\frac{k}{m},$$
积分得
$$v(s) = v_0 - \frac{k}{m}s.$$
初速 $v_0 = 600\,\text{km/h} = \dfrac{600\times10^3}{3600} = \dfrac{500}{3}\,\text{m/s}$,滑跑 $s = 500\,\text{m}$ 后 $v = 100\,\text{km/h} = \dfrac{250}{9}\,\text{m/s}$:
$$\frac{250}{9} = \frac{500}{3} - \frac{k}{m}\cdot500
\;\Longrightarrow\; \frac{k}{m} = \frac{\frac{500}{3} - \frac{250}{9}}{500} = \frac{5}{18}\,(\text{s}^{-1}).$$
故阻力系数
$$k = 4500\times\frac{5}{18} = 1250\ \text{kg/s}.$$
停机条件 $v = 0$:
$$0 = \frac{500}{3} - \frac{5}{18}s\;\Longrightarrow\; s = 600\ \text{m}.$$

**答案**：阻力系数 $k = 1250\ \text{kg/s}$;跑道长度至少 $600\ \text{m}$。

**易错点**：单位换算 $600\,\text{km/h} = \dfrac{500}{3}\,\text{m/s}$ 不能错;由 $m\dfrac{dv}{dt} = -kv$ 换到 $\dfrac{dv}{ds}$ 时 $v$ 约掉,速度关于位移是线性递减。

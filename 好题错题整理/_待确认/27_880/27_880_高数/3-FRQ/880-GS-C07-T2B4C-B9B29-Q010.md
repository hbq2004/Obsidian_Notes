# FRQ 第 10 题

![[_Attachments/题目识别/880-GS/880-GS-C07-T2B4C-B9B29-Q010_题目.png|题目]]

(10) 设 $f(t)$ 在 $(0, +\infty)$ 内有二阶连续导数，记 $g(x, y) = f\left(\frac{y}{x}\right)$。若 $g(x, y)$ 满足

$$x^{3} \frac{\partial^{2} g}{\partial x^{2}} + x^{2} y \frac{\partial^{2} g}{\partial x \partial y} + xy^{2} \frac{\partial^{2} g}{\partial y^{2}} = y,$$

且 $g(y, y) = 1$，$\left. \frac{\partial g}{\partial y}\right|＿{(y, y)} = \frac{2}{y}$，

求 $f(t)$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-T2B4C-B9B29-Q010_答案.png|答案]]

## V4 Pro Max 解析

**考点**：复合函数高阶偏导(链式法则)化为 $f$ 的常微分方程,初值定常数。

**解**
设 $u = \dfrac{y}{x}$,$g(x,y) = f(u)$。求偏导:
$$g_x = f'(u)\left(-\frac{y}{x^2}\right),\qquad g_y = f'(u)\cdot\frac{1}{x},$$
$$g_{xx} = f''(u)\frac{y^2}{x^4} + f'(u)\frac{2y}{x^3},\qquad
g_{xy} = -f''(u)\frac{y}{x^3} - f'(u)\frac{1}{x^2},\qquad
g_{yy} = f''(u)\frac{1}{x^2}.$$
代入
$$x^3g_{xx} + x^2yg_{xy} + xy^2g_{yy} = f''(u)\frac{y^2}{x} + 2f'(u)y - f''(u)\frac{y^2}{x} - f'(u)y + f''(u)\frac{y^2}{x},$$
$$= f''(u)\frac{y^2}{x} + f'(u)y = y\left[u f''(u) + f'(u)\right] = y,$$
故
$$u f''(u) + f'(u) = 1.$$
即 $(u f'(u))' = 1$,积分得 $u f'(u) = u + C_1$,$f'(u) = 1 + \dfrac{C_1}{u}$,再积分:
$$f(u) = u + C_1\ln|u| + C_2.$$
由 $g(y,y) = f(1) = 1$ 得 $1 + C_2 = 1$,即 $C_2 = 0$;由 $\left.\dfrac{\partial g}{\partial y}\right|_{(y,y)} = \dfrac{f'(1)}{y} = \dfrac{2}{y}$ 得 $f'(1) = 2$,而 $f'(1) = 1 + C_1 = 2$,故 $C_1 = 1$。

**答案**：$f(t) = t + \ln t$($t > 0$)。

**易错点**：$g_{xx}$ 含 $f''(u)\dfrac{y^2}{x^4}$ 与 $f'(u)\dfrac{2y}{x^3}$ 两项,代入后 $f''$ 项部分抵消,最终只剩 $y[uf'' + f']$;$\ln$ 前系数 $C_1 = 1$ 由 $f'(1)=2$ 确定。

# FRQ 第 4 题

![[_Attachments/题目识别/880-GS/880-GS-C07-T2B4C-B9B29-Q004_题目.png|题目]]

(4) 设 $y'' + (4x + e^{2y}) y' = 0$.

(I) 若视 $x$ 为因变量, $y$ 为自变量, 试化简该方程;

(II) 求该方程的通解.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-T2B4C-B9B29-Q004_答案.png|答案]]

## V4 Pro Max 解析

**考点**：互换自变量与因变量化简方程并求解(含 $e^{2y}$ 项,化 $x$ 关于 $y$ 的二阶线性方程)。

**解**
设 $y = y(x)$,视 $x$ 为因变量:$x = x(y)$,记 $\varphi = \dfrac{dx}{dy} = \dfrac{1}{y'}$,则
$$y' = \frac{1}{\varphi},\qquad y'' = \frac{d}{dx}\left(\frac{1}{\varphi}\right) = \frac{d}{dy}\left(\frac{1}{\varphi}\right)\cdot y' = -\frac{\varphi'}{\varphi^2}\cdot\frac{1}{\varphi} = -\frac{\varphi'}{\varphi^3}.$$
代入 $y'' + (4x + e^{2y})y' = 0$:
$$-\frac{\varphi'}{\varphi^3} + (4x+e^{2y})\frac{1}{\varphi} = 0,$$
两边乘 $\varphi^3$:
$$\frac{d^2x}{dy^2} = \varphi' = (4x + e^{2y})\varphi^2 = (4x+e^{2y})\left(\frac{dx}{dy}\right)^2.$$

**【注】题目文字疑似 OCR 有误**:按题干文字 $y''+(4x+e^{2y})y'=0$ 化简得 $\dfrac{d^2x}{dy^2} = (4x+e^{2y})\left(\dfrac{dx}{dy}\right)^2$,该方程无初等通解,与 (II) 问"求通解"不匹配,故 $y'$ 的上标幂次疑似在 OCR 中丢失。按最合理读法,原题应为 $y'' + (4x+e^{2y})(y')^3 = 0$,此时
$$y'' = -\frac{\varphi'}{\varphi^3},\qquad (y')^3 = \frac{1}{\varphi^3},$$
代入得
$$-\frac{\varphi'}{\varphi^3} + \frac{4x+e^{2y}}{\varphi^3} = 0\;\Longrightarrow\; \frac{d^2x}{dy^2} = 4x + e^{2y},$$
即 $x'' - 4x = e^{2y}$。特征根 $r = \pm 2$,$x_h = C_1e^{2y} + C_2e^{-2y}$;因 $2$ 是特征根,设 $x_p = Aye^{2y}$:
$$x_p' = Ae^{2y}(1+2y),\qquad x_p'' = Ae^{2y}(4+4y),\qquad x_p'' - 4x_p = 4Ae^{2y} = e^{2y},$$
得 $A = \dfrac{1}{4}$。

**答案**：(I) $\dfrac{d^2x}{dy^2} = (4x+e^{2y})\left(\dfrac{dx}{dy}\right)^2$(按 OCR 文字);(II) 按疑似原题 $y''+(4x+e^{2y})(y')^3=0$,通解 $x = C_1e^{2y} + C_2e^{-2y} + \dfrac{1}{4}ye^{2y}$。

**易错点**：$y'' = -\varphi'/\varphi^3$ 中链式求导要完整(先对 $y$ 求导再乘 $y'$);遇到"化简后无法求通解"的情况,优先怀疑 OCR 丢幂次,本题 $(y')^3$ 版本化简为线性方程 $x''-4x=e^{2y}$,且 $e^{2y}$ 与特征根 $2$ 共振需乘 $y$。

# FRQ 第 7 题

![[_Attachments/题目识别/880-GS/880-GS-C06-T2B4C-Q007_题目.png|题目]]

(7) 设 $D: 0 \leqslant x \leqslant 2, 0 \leqslant y \leqslant 2$，计算 $I = \iint_{D} [1 + x + y] \, dx \, dy$，其中 $[1 + x + y]$ 表示不超过 $1 + x + y$ 的最大整数.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C06-T2B4C-Q007_答案.png|答案]]

## V4 Pro Max 解析

**考点**：含取整（高斯）函数的二重积分，按整数跳跃线 $x+y=k$ 划分区域后按常量求和。

**解**

在正方形 $[0,2]\times[0,2]$ 上，$1+x+y\in[1,5)$，故 $[1+x+y]$ 只取 $1,2,3,4$。以直线 $x+y=1,2,3$ 为界划分区域（边界线面积为 $0$，不影响积分）：

- $[1+x+y]=1$：$0\le x+y<1$，面积 $S_1=\dfrac12$（三角形）；
- $[1+x+y]=2$：$1\le x+y<2$，面积 $S_2=2-\dfrac12=\dfrac32$；
- $[1+x+y]=3$：$2\le x+y<3$，面积 $S_3=4-2-\dfrac12=\dfrac32$；
- $[1+x+y]=4$：$3\le x+y\le4$，面积 $S_4=\dfrac12$（右上角三角形）。

故
$$I=1\cdot S_1+2\cdot S_2+3\cdot S_3+4\cdot S_4=\frac12+3+\frac92+2=10.$$

**答案**：$10$。

**易错点**：$[1+x+y]$ 在 $x+y=1,2,3$ 处发生跳跃，各子区域按 $<$ 与 $\le$ 划分即可，边界线测度为零不贡献积分值；$S_3$ 应为 $4-2-\frac12=\frac32$，勿漏右上角三角形。

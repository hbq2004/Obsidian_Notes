# FRQ 第 11 题

![[_Attachments/题目识别/880-GS/880-GS-C07-T2B4C-Q011_题目.png|题目]]

(11) 设 $f(x)$ 满足 $x f'(x) - f(x) = a(1 - \ln x) + x^2 (x > 0, a \neq 0)$，$f(1) = 1 - a$。

(I) 求 $f(x)$ 的表达式；

(II) 若方程 $f(x) = 0$ 在 $x \in (0, +\infty)$ 内有唯一实根，求 $a$ 的取值范围.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-T2B4C-Q011_答案.png|答案]]

## V4 Pro Max 解析

**考点**：一阶线性方程解出 $f(x)$(含参数 $a$),再由根的唯一性反求参数范围(单调性 + 极值分析)。

**解**
**(I)** $xf'(x) - f(x) = a(1-\ln x) + x^2$,即 $f' - \dfrac{1}{x}f = \dfrac{a(1-\ln x)}{x} + x$。积分因子 $\dfrac{1}{x}$:
$$\left(\frac{f}{x}\right)' = \frac{a(1-\ln x)}{x^2} + 1.$$
利用 $\displaystyle\int\frac{1-\ln x}{x^2}dx = \frac{\ln x}{x}$,积分得
$$\frac{f(x)}{x} = a\cdot\frac{\ln x}{x} + x + C\;\Longrightarrow\; f(x) = a\ln x + x^2 + Cx.$$
由 $f(1) = 1 - a$:$1 + C = 1 - a$,得 $C = -a$。故
$$f(x) = x^2 - ax + a\ln x.$$

**(II)** $f'(x) = 2x - a + \dfrac{a}{x} = \dfrac{2x^2 - ax + a}{x}$,$f''(x) = 2 - \dfrac{a}{x^2}$。
分情形:
- 若 $a < 0$:当 $x\to 0^+$ 时 $f(x)\to +\infty$,当 $x\to+\infty$ 时 $f\to+\infty$,且 $f''>0$($f'$ 严格增),$f$ 只有一个极小值点 $x_0$。由 $f'(x_0)=0$ 得 $a = \dfrac{2x_0^2}{x_0-1}$($x_0<1$),此时
$$f(x_0) = x_0^2\left[\frac{2\ln x_0 - x_0 - 1}{x_0-1}\right],$$
而 $2\ln x_0 - x_0 - 1 < 0$(因 $h(x) = 2\ln x - x - 1$ 最大值 $h(2) = 2\ln 2 - 3 < 0$),故 $f(x_0) > 0$,方程 $f = 0$ 无根,矛盾。
- 若 $0 < a \le 8$:$xf'(x) = 2x^2 - ax + a$,判别式 $\Delta = a^2 - 8a \le 0$,故 $f'(x) \ge 0$,$f$ 单调递增;由 $f(0^+) = -\infty$(因 $a\ln x\to-\infty$)、$f(+\infty) = +\infty$,恰有一个根。
- 若 $a > 8$:$xf' = 0$ 有两个正根 $x_1 < x_2$,$f$ 在 $(0,x_1)$ 增、$(x_1,x_2)$ 减、$(x_2,+\infty)$ 增。在 $x_1$ 处 $a = \dfrac{2x_1^2}{x_1-1}$($x_1>1$),且
$$f(x_1) = x_1^2\left[\frac{2\ln x_1 - x_1 - 1}{x_1-1}\right] < 0,$$
故 $f$ 在 $(0, x_2]$ 上恒负,在 $(x_2, +\infty)$ 恰有一次穿越 $0$:唯一实根 ✓。
综合 $a > 0$ 且 $a \ne 0$(题设 $a\ne0$),得

**答案**：(I) $f(x) = x^2 - ax + a\ln x$;(II) $a \in (0, +\infty)$。

**易错点**：$a<0$ 时 $f(0^+)=+\infty$ 且 $f''>0$,极值为正故无根,需用 $2\ln x - x - 1 < 0$ 证明;分类讨论的临界点 $a=8$ 对应 $f'\ge0$。

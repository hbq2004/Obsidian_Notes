# FRQ 第 3 题

![[_Attachments/题目识别/880-GS/880-GS-C07-T2B4C-Q003_题目.png|题目]]

(3) 设 $f(x)$ 是连续函数，且 $f(x) = \cos x - \int_{0}^{x} (x-t) f(t) \, dt$，求 $f(x)$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-T2B4C-Q003_答案.png|答案]]

## V4 Pro Max 解析

**考点**：含变限积分的积分方程:求导两次化为二阶常系数非齐次方程。

**解**
$$f(x) = \cos x - \int_0^x (x-t)f(t)\,dt = \cos x - x\int_0^x f(t)dt + \int_0^x t f(t)dt.$$
求导:
$$f'(x) = -\sin x - \int_0^x f(t)dt - xf(x) + xf(x) = -\sin x - \int_0^x f(t)dt.$$
再求导:
$$f''(x) = -\cos x - f(x)\;\Longrightarrow\; f'' + f = -\cos x.$$
初值:$f(0) = 1$,$f'(0) = 0$。齐次通解 $C_1\cos x + C_2\sin x$;对 $-\cos x$($\pm i$ 为特征根,共振)设 $y_p = x(A\cos x + B\sin x)$:
$$y_p' = A\cos x - Ax\sin x + B\sin x + Bx\cos x,$$
$$y_p'' = -2A\sin x + 2B\cos x - x(A\cos x + B\sin x),$$
$$y_p'' + y_p = -2A\sin x + 2B\cos x = -\cos x,$$
得 $A = 0,\ B = -\dfrac12$,故 $f = C_1\cos x + C_2\sin x - \dfrac{x}{2}\sin x$。
由 $f(0) = 1$ 得 $C_1 = 1$;由 $f'(x) = -\sin x + C_2\cos x - \dfrac12(\sin x + x\cos x)$ 及 $f'(0) = 0$ 得 $C_2 = 0$。

**答案**：$f(x) = \cos x - \dfrac{x}{2}\sin x$。

**易错点**：$\dfrac{d}{dx}\int_0^x(x-t)f(t)dt = \int_0^x f(t)dt$ 的链式(上限与下限两处 $x$ 都要求导,正好抵消);$\cos x$ 共振,特解需乘 $x$。

# FRQ 第 12 题

![[_Attachments/题目识别/880-GS/880-GS-C07-T2B4C-B9B29-Q012_题目.png|题目]]

(12) 设 $f(x)$ 满足 $f'(x) + f(x) = e^{-x}$，$f(0) = 0$。

(I) 求 $y = f(x)$ 的极值与拐点；

(II) 当 $0 < x_1 < 1 < x_2$ 时，有 $f(x_1) = f(x_2)$，证明：$x_1 + x_2 > 2$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-T2B4C-B9B29-Q012_答案.png|答案]]

## V4 Pro Max 解析

**考点**：一阶线性方程求函数 + 极值拐点 + 利用单调性/凹凸性证明不等式。

**解**
**解方程**:$f' + f = e^{-x}$,即 $(fe^x)' = 1$,得 $fe^x = x + C$。由 $f(0) = 0$ 得 $C = 0$,故
$$f(x) = xe^{-x}.$$

**(I)** $f' = e^{-x}(1-x)$,$f'' = e^{-x}(x-2)$。
$f' = 0 \Rightarrow x = 1$,且 $f''(1) = -e^{-1} < 0$,故 $x=1$ 为极大值点,$f(1) = \dfrac{1}{e}$;$\lim\limits_{x\to-\infty}f = -\infty$,$\lim\limits_{x\to+\infty}f = 0$,故无极小值。
$f'' = 0 \Rightarrow x = 2$,且 $f''$ 在 $x=2$ 两侧变号($e^{-x}>0$,符号由 $x-2$ 决定),故 $(2, 2e^{-2})$ 为拐点。

**(II)** 设 $g(x) = \ln f(x) = \ln x - x$(在 $(0,+\infty)$ 上 $f>0$),则 $g(x_1) = g(x_2)$,且
$$g'(x) = \frac{1}{x} - 1,\qquad g''(x) = -\frac{1}{x^2} < 0,$$
故 $g$ 在 $(0,1)$ 递增、$(1,+\infty)$ 递减,严格凹。对 $0<x_1<1$,令 $\varphi(x) = g(2-x) - g(x) = \ln\dfrac{2-x}{x} - 2 + 2x$,则
$$\varphi'(x) = -\frac{1}{2-x} - \frac{1}{x} + 2 = 2 - \left(\frac{1}{x} + \frac{1}{2-x}\right) \le 0,$$
(因 $\dfrac{1}{x}+\dfrac{1}{2-x} \ge \dfrac{4}{x+2-x} = 2$),故 $\varphi$ 在 $(0,1)$ 上递减,$\varphi(x) > \varphi(1) = 0$,即 $g(2-x_1) > g(x_1) = g(x_2)$。因 $g$ 在 $(1,+\infty)$ 递减且 $2-x_1 > 1$,$x_2 > 1$,由 $g(2-x_1) > g(x_2)$ 得 $2 - x_1 < x_2$。

**答案**：(I) 极大值 $f(1) = \dfrac{1}{e}$(无极小值),拐点 $\left(2, \dfrac{2}{e^2}\right)$;(II) 证得 $x_1 + x_2 > 2$。

**易错点**：$f = xe^{-x}$ 在 $x<0$ 时 $f<0$,取对数 $g = \ln f$ 仅在 $x>0$ 有效,而题目范围 $0<x_1<1<x_2$ 恰在其中;拐点判定要验证 $f''$ 变号。

# FRQ 第 9 题

![[_Attachments/题目识别/880-GS/880-GS-C07-T2B4C-Q009_题目.png|题目]]

(9) 设 $L$ 是一条平面曲线，其上任意一点 $P(x, y)$ ($x > 0$) 到原点的距离恒等于该点处的切线在 $y$ 轴上的截距，且 $L$ 过点 $\left( \frac{1}{2}, 0 \right)$. 求:

(I) 曲线 $L$ 的方程;

(II) $L$ 位于第一象限部分的一条切线，使该切线与 $L$ 以及两坐标轴所围的面积最小.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-T2B4C-Q009_答案.png|答案]]

## V4 Pro Max 解析

**考点**：几何条件(到原点距离 = 切线截距)建模解曲线;再求切线围成面积的最小值。

**解**
**(I)** 过 $P(x,y)$ 的切线 $Y - y = y'(X-x)$,在 $y$ 轴上的截距 $b = y - xy'$。题设
$$\sqrt{x^2+y^2} = |y - xy'|.$$
平方:$x^2 + y^2 = (y - xy')^2 = y^2 - 2xyy' + x^2y'^2$,即
$$x^2y'^2 - 2xyy' - x^2 = 0,$$
解出 $y' = \dfrac{y \pm \sqrt{x^2+y^2}}{x}$。取负号支 $y' = \dfrac{y - \sqrt{x^2+y^2}}{x}$,则截距 $b = y - xy' = \sqrt{x^2+y^2} > 0$(正截距;另一支给负截距,舍去)。
令 $u = \dfrac{y}{x}$,$y' = u + xu'$:
$$u + xu' = u - \sqrt{1+u^2}\;\Longrightarrow\; xu' = -\sqrt{1+u^2},$$
$$\frac{du}{\sqrt{1+u^2}} = -\frac{dx}{x}\;\Longrightarrow\; \operatorname{arsinh}u = -\ln x + C.$$
由 $y\left(\dfrac12\right) = 0$ 得 $0 = -\ln\dfrac12 + C$,即 $C = -\ln 2$。于是
$$u = \sinh\left(-\ln(2x)\right) = \frac{\frac{1}{2x} - 2x}{2} = \frac{1}{4x} - x,$$
$$y = \frac14 - x^2.$$

验证:$y' = -2x$,截距 $b = y - xy' = \dfrac14 + x^2$,$\sqrt{x^2+y^2} = \sqrt{x^2 + \left(\frac14 - x^2\right)^2} = \dfrac14 + x^2$ ✓。

**(II)** 设切点为 $(a, \frac14 - a^2)$,切线 $Y = \dfrac14 + a^2 - 2aX$。它与 $y$ 轴交于 $(0, \frac14+a^2)$,与 $x$ 轴交于 $\left(\dfrac{\frac14+a^2}{2a}, 0\right)$。切线与曲线及两坐标轴围成的面积为
$$A(a) = \int_0^{1/2}\left[\frac14 + a^2 - 2aX - \left(\frac14 - X^2\right)\right]dX + \int_{1/2}^{\frac{\frac14+a^2}{2a}}\left(\frac14 + a^2 - 2aX\right)dX.$$
化简得 $A(a) = \dfrac{(\frac14 + a^2)^2}{4a} - \dfrac{1}{12}$。求导:
$$A'(a) = \frac{3a^2}{4} + \frac18 - \frac{1}{64a^2} = 0\;\Longrightarrow\; 48a^4 + 8a^2 - 1 = 0,$$
令 $s = a^2$,$48s^2 + 8s - 1 = 0$,得 $s = \dfrac{1}{12}$,即 $a = \dfrac{1}{2\sqrt3}\in\left(0, \frac12\right]$($A'' > 0$,为最小值点)。
切点为 $\left(\dfrac{1}{2\sqrt3}, \dfrac16\right)$,切线
$$Y = \frac14 + \frac{1}{12} - \frac{1}{\sqrt3}X = \frac13 - \frac{X}{\sqrt3}.$$

**答案**：(I) $y = \dfrac14 - x^2$;(II) 在点 $\left(\dfrac{1}{2\sqrt3}, \dfrac16\right)$ 处的切线 $Y = \dfrac13 - \dfrac{X}{\sqrt3}$ 使面积最小。

**易错点**：平方去绝对值后有两支,须由"切线在 $y$ 轴截距等于(正的)距离"舍弃 $b<0$ 的一支;面积要对切线在曲线之上、$X$ 从 $0$ 到 $\frac12$、再从 $\frac12$ 到切线与 $x$ 轴交点分段积分。

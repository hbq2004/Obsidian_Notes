# FRQ 第 2 题

![[_Attachments/题目识别/880-GS/880-GS-C07-T2B4C-B9B29-Q002_题目.png|题目]]

(2) 利用变量替换 $x = \sin t$，$y = y(t)$（$0 < t < \frac{\pi}{2}$）化简方程 $\left(1 - x^2\right) \frac{d^2y}{dx^2} - x \frac{dy}{dx} + y = 0$，并求该方程的通解.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-T2B4C-B9B29-Q002_答案.png|答案]]

## V4 Pro Max 解析

**考点**：参数变换法化简二阶方程($x=\sin t$ 消去变系数),再求通解。

**解**
令 $x = \sin t$,$0<t<\dfrac{\pi}{2}$,则 $\dfrac{dx}{dt} = \cos t$,且 $1 - x^2 = \cos^2 t$。
$$\frac{dy}{dx} = \frac{dy/dt}{dx/dt} = \frac{\dot y}{\cos t},$$
$$\frac{d^2y}{dx^2} = \frac{d}{dt}\left(\frac{\dot y}{\cos t}\right)\cdot\frac{dt}{dx}
= \frac{\ddot y\cos t + \dot y\sin t}{\cos^2 t}\cdot\frac{1}{\cos t}
= \frac{\ddot y\cos t + \dot y\sin t}{\cos^3 t}.$$
代入 $(1-x^2)\dfrac{d^2y}{dx^2} - x\dfrac{dy}{dx} + y = 0$:
$$\cos^2 t\cdot\frac{\ddot y\cos t + \dot y\sin t}{\cos^3 t} - \sin t\cdot\frac{\dot y}{\cos t} + y
= \frac{\ddot y\cos t + \dot y\sin t}{\cos t} - \frac{\dot y\sin t}{\cos t} + y = \ddot y + y = 0.$$
故化为 $\ddot y + y = 0$,通解
$$y = C_1\cos t + C_2\sin t = C_1\sqrt{1-x^2} + C_2x.$$

验证:对 $y = C_1\sqrt{1-x^2}+C_2x$,$y' = -\dfrac{C_1x}{\sqrt{1-x^2}} + C_2$,$y'' = -\dfrac{C_1}{(1-x^2)^{3/2}}$,代入原方程:$(1-x^2)y'' = -\dfrac{C_1}{\sqrt{1-x^2}}$,$-xy' = \dfrac{C_1x^2}{\sqrt{1-x^2}} - C_2x$,相加得 $-C_1\sqrt{1-x^2} - C_2x + C_1\sqrt{1-x^2} + C_2x = 0$ ✓。

**答案**：$y = C_1\cos t + C_2\sin t$,即 $y = C_1\sqrt{1-x^2} + C_2x$。

**易错点**：二阶导换元要按 $\dfrac{d}{dx} = \dfrac{d}{dt}\cdot\dfrac{dt}{dx}$ 链式做两遍,$\dfrac{dt}{dx} = \dfrac{1}{\cos t}$,勿忘。

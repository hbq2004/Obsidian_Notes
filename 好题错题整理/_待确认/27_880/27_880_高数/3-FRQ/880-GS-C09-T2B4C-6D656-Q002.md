# FRQ 第 2 题

![[_Attachments/题目识别/880-GS/880-GS-C09-T2B4C-6D656-Q002_题目.png|题目]]

(2) 设 $f(x, y)$ 在 $\frac{x^2}{4} + y^2 \leq 1$ 上有二阶偏导数，$L$ 为 $\frac{x^2}{4} + y^2 = 1$，取顺时针方向，计算

$$I = \oint_{L} \left[ -3y + f_x'(x, y) \right] dx + f_y'(x, y) dy.$$

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C09-T2B4C-6D656-Q002_答案.png|答案]]

## V4 Pro Max 解析

**考点**：格林公式 + 二阶混合偏导相等化简；注意 $L$ 为顺时针方向。

**解**
记 $P=-3y+f_x'(x,y)$，$Q=f_y'(x,y)$。因 $f$ 在椭圆域 $\dfrac{x^2}{4}+y^2\le1$ 上有二阶偏导数（混合偏导连续、相等），$L$ 取顺时针，由格林公式（取负号）：

$$I=\oint_L P\,dx+Q\,dy=-\iint_D\left(\frac{\partial Q}{\partial x}-\frac{\partial P}{\partial y}\right)dxdy=-\iint_D\big(f_{yx}+3-f_{xy}\big)dxdy=-3\iint_D dxdy.$$

椭圆 $\dfrac{x^2}{4}+y^2=1$ 的半轴为 $2$ 与 $1$，面积 $S_D=\pi\cdot2\cdot1=2\pi$。

**答案**：$I=-6\pi$。

**易错点**：① 顺时针闭曲线用格林公式前面要加负号；② 混合偏导 $f_{xy}=f_{yx}$ 相互抵消后只剩常数 $3$，这是本题的巧点。

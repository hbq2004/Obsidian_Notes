# FRQ 第 7 题

![[_Attachments/题目识别/880-GS/880-GS-C07-T2B4C-B9B29-Q007_题目.png|题目]]

(7) 设 $y = y(x)$ 有一阶连续导数, $y(0) = 1$，且满足 $y'(x) + 3\int_{0}^{x} y'(t)dt + 2x\int_{0}^{1} y(xu)du + e^{-x} = 0$，求 $y = y(x)$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-T2B4C-B9B29-Q007_答案.png|答案]]

## V4 Pro Max 解析

**考点**：含变限积分与定积分(参数)的方程:换元化简 → 求导降阶 → 二阶常系数非齐次方程。

**解**
先化简 $\displaystyle\int_0^1 y(xu)\,du$:令 $xu = s$,$du = \dfrac{ds}{x}$,得
$$\int_0^1 y(xu)\,du = \frac{1}{x}\int_0^x y(s)\,ds.$$
原方程乘以 $x$ 后变为
$$xy' + 3x\int_0^x y'(t)dt + 2\int_0^x y(s)ds + xe^{-x} = 0.$$
但更直接的:原方程中 $2x\cdot\dfrac{1}{x}\int_0^x y\,ds = 2\int_0^x y\,ds$,故方程即
$$y' + 3\int_0^x y'(t)dt + 2\int_0^x y(s)ds + e^{-x} = 0.$$
利用 $\displaystyle\int_0^x y'(t)dt = y(x) - y(0) = y(x) - 1$,得
$$y' + 3y - 3 + 2\int_0^x y\,ds + e^{-x} = 0.$$
求导:
$$y'' + 3y' + 2y - e^{-x} = 0\;\Longrightarrow\; y'' + 3y' + 2y = e^{-x}.$$
特征根 $r = -1, -2$,$y_h = C_1e^{-x} + C_2e^{-2x}$。因 $-1$ 是特征根,设 $y_p = Axe^{-x}$:
$$y_p' = Ae^{-x}(1-x),\quad y_p'' = Ae^{-x}(x-2),\quad y_p'' + 3y_p' + 2y_p = Ae^{-x} = e^{-x},$$
得 $A = 1$。故 $y = C_1e^{-x} + C_2e^{-2x} + xe^{-x}$。
初值:由原方程在 $x=0$ 处取值,$y'(0) + 0 + 0 + 1 = 0$,即 $y'(0) = -1$;且 $y(0) = 1$。
$$y(0) = C_1 + C_2 = 1,\qquad y'(0) = -C_1 - 2C_2 + 1 = -1,$$
得 $C_1 = 0,\ C_2 = 1$。

**答案**：$y = e^{-2x} + xe^{-x}$。

**易错点**：$\int_0^1 y(xu)du$ 换元后是 $\dfrac{1}{x}\int_0^x y(s)ds$,再乘 $2x$ 得 $2\int_0^x y\,ds$;$y'(0) = -1$ 由原方程取 $x=0$ 得到,不要漏。

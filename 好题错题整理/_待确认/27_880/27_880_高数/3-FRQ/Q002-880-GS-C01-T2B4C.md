# FRQ 第 2 题

![[_Attachments/题目识别/880-GS/880-GS-C01-T2B4C-Q002_题目.png|题目]]

(2) 求下列极限:

(I) $\lim\limits_{x \to \infty} \frac{x^2 - x \sin x}{x^2 + x \sin \frac{1}{x}}$;

(II) $\lim\limits_{x \to +\infty} \left( \frac{x^{\frac{1}{x}} + b^{\frac{1}{x}} + c^{\frac{1}{x}}}{3} \right)^x$ (a, b, c 为正数);

(III) $\lim\limits_{x \to 0} \frac{\ln(\sin^2 x + e^x) - x}{\ln(e^{2x} - x^2) - 2x}$;

(IV) $\lim\limits_{x \to 0} \frac{(1 + x)^{\frac{3}{x}} - e^3}{x}$;

(V) $\lim\limits_{x \to 0} \frac{e^{\tan x} - e^x}{x^3};$

(VI) $\lim\limits_{x \to 0} \cot x \left( \frac{1}{\sin x} - \frac{1}{x} \right);$

(VII) $\lim\limits_{x \to 0} \left( 1 - x^2 \right)^{\frac{1}{1 - \sqrt{1 - x^2}}} ;$

(VII) $\lim\limits_{x \to 0^+} x^{\sin x}.$

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C01-T2B4C-Q002_答案.png|答案]]

## V4 Pro Max 解析

**考点**：极限计算综合——抓大头、$1^\infty$ 型、对数化、等价无穷小、洛必达法则、泰勒展开。

**解**

(I) 分子分母同除以 $x^2$：
$$\lim_{x\to\infty}\frac{x^2-x\sin x}{x^2+x\sin\frac1x}=\lim_{x\to\infty}\frac{1-\frac{\sin x}{x}}{1+\frac{\sin\frac1x}{x}}=\frac{1-0}{1+0}=1.$$

(II) 属 $1^\infty$ 型，取对数：
$$\ln L=\lim_{x\to+\infty}x\ln\frac{a^{1/x}+b^{1/x}+c^{1/x}}3=\lim_{t\to0^+}\frac{\ln(a^t+b^t+c^t)-\ln3}{t}.$$
洛必达：
$$\ln L=\lim_{t\to0^+}\frac{a^t\ln a+b^t\ln b+c^t\ln c}{a^t+b^t+c^t}=\frac{\ln a+\ln b+\ln c}{3},$$
故 $L=(abc)^{1/3}$。

(III)
$$\lim_{x\to0}\frac{\ln(\sin^2x+e^x)-x}{\ln(e^{2x}-x^2)-2x}=\lim_{x\to0}\frac{\ln(1+\sin^2x\,e^{-x})}{\ln(1-x^2e^{-2x})}=\lim_{x\to0}\frac{\sin^2x\,e^{-x}}{-x^2e^{-2x}}=-1.$$

(IV) $(1+x)^{3/x}=e^{\frac3x\ln(1+x)}=e^{3-\frac32x+o(x)}$，故
$$\lim_{x\to0}\frac{(1+x)^{3/x}-e^3}{x}=e^3\lim_{x\to0}\frac{e^{-\frac32x+o(x)}-1}{x}=e^3\cdot\left(-\frac32\right)=-\frac{3e^3}{2}.$$

(V) $\tan x-x\sim\frac{x^3}{3}$：
$$\lim_{x\to0}\frac{e^{\tan x}-e^x}{x^3}=\lim_{x\to0}e^x\cdot\frac{e^{\tan x-x}-1}{x^3}=\lim_{x\to0}\frac{\tan x-x}{x^3}=\frac13.$$

(VI)
$$\lim_{x\to0}\cot x\left(\frac1{\sin x}-\frac1x\right)=\lim_{x\to0}\cos x\cdot\frac{x-\sin x}{x\sin^2x}=\lim_{x\to0}\frac{x-\sin x}{x^3}=\frac16.$$

(VII) 由 $1-\sqrt{1-x^2}\sim\frac{x^2}{2}$ 及 $\ln(1-x^2)\sim-x^2$：
$$\lim_{x\to0}(1-x^2)^{\frac{1}{1-\sqrt{1-x^2}}}=\exp\left(\lim_{x\to0}\frac{\ln(1-x^2)}{1-\sqrt{1-x^2}}\right)=e^{-2}.$$

(VIII) 取对数：$\ln L=\sin x\ln x\sim x\ln x\to0$，故
$$\lim_{x\to0^+}x^{\sin x}=e^0=1.$$

**答案**：(I) $1$；(II) $\sqrt[3]{abc}$；(III) $-1$；(IV) $-\dfrac{3e^3}{2}$；(V) $\dfrac13$；(VI) $\dfrac16$；(VII) $e^{-2}$；(VIII) $1$。

**易错点**：(I) 不能用洛必达（$\sin x$ 在无穷远处振荡）；(II) 记住 $\frac{\ln(a^t+b^t+c^t)-\ln3}{t}$ 的模板；(IV) 是"幂指函数的 $\frac00$"型，先展开指数再提 $e^3$；(VI) 中 $\cot x$ 的 $\cos x$ 因子趋于 1，勿丢。

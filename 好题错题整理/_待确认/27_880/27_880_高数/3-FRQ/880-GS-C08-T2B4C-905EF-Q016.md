# FRQ 第 16 题

![[_Attachments/题目识别/880-GS/880-GS-C08-T2B4C-905EF-Q016_题目.png|题目]]

(16) 设 $f(x) = \sum\limits_{n=0}^{\infty} \frac{a_n}{n!} x^n$ 满足 $\begin{cases} f''(x) - f'(x) - 2f(x) = 0, \\ f(0) = 0, f'(0) = 1, \end{cases}$ 求 $f(x)$ 及 $a_n$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C08-T2B4C-905EF-Q016_答案.png|答案]]

## V4 Pro Max 解析

**考点**：由二阶常系数线性微分方程初值问题解出 $f(x)$，再由 $f(x)=\sum\dfrac{a_n}{n!}x^n$ 反求 $a_n=f^{(n)}(0)$。

**解**
特征方程 $r^2-r-2=0$ 得 $r_1=2,\ r_2=-1$，故
$$f(x)=C_1e^{2x}+C_2e^{-x}.$$
由 $f(0)=0$，$f'(0)=1$：
$$C_1+C_2=0,\qquad 2C_1-C_2=1\Rightarrow C_1=\frac13,\ C_2=-\frac13.$$
所以
$$f(x)=\frac13\left(e^{2x}-e^{-x}\right).$$
又
$$f(x)=\frac13\sum_{n=0}^{\infty}\frac{(2x)^n}{n!}-\frac13\sum_{n=0}^{\infty}\frac{(-x)^n}{n!}
=\sum_{n=0}^{\infty}\frac{2^n-(-1)^n}{3}\cdot\frac{x^n}{n!},$$
与 $f(x)=\sum\limits_{n=0}^{\infty}\dfrac{a_n}{n!}x^n$ 比较得
$$a_n=\frac{2^n-(-1)^n}{3}.$$

**答案**：$f(x)=\dfrac13(e^{2x}-e^{-x})$；$a_n=\dfrac{2^n-(-1)^n}{3}$。

**易错点**：$a_n$ 是 $f^{(n)}(0)$ 而非 $f$ 的泰勒系数本身，展开时 $\dfrac{x^n}{n!}$ 的系数要与 $a_n$ 对应，不要漏掉分母 $n!$；特征根 $2,-1$ 是相异实根，无共振项。

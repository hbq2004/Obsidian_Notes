# FRQ 第 1 题

![[_Attachments/题目识别/880-GS/880-GS-C07-T2B4C-B9B29-Q001_题目.png|题目]]

(1) 设 $y = y(x)$ 满足 $x^2 y' + y = x^2 e^{\frac{1}{x}}$ ($x > 0$)，且 $y(1) = 3e$。

(I) 求 $y = y(x)$ ($x > 0$) 的全部渐近线方程；

(II) 讨论曲线 $y = y(x)$ ($x > 0$) 与 $y = k$ ($k > 0$) 不同交点的个数.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-T2B4C-B9B29-Q001_答案.png|答案]]

## V4 Pro Max 解析

**考点**：一阶线性微分方程 + 渐近线 + 由函数值域讨论交点个数(数形结合)。

**解**
**解方程**:$x^2y' + y = x^2e^{1/x}$,即 $y' + \dfrac{1}{x^2}y = e^{1/x}$。积分因子 $\mu = e^{\int\frac{dx}{x^2}} = e^{-1/x}$:
$$\big(ye^{-1/x}\big)' = e^{1/x}\cdot e^{-1/x} = 1\;\Longrightarrow\; ye^{-1/x} = x + C.$$
由 $y(1) = 3e$ 得 $3e\cdot e^{-1} = 1 + C$,即 $C = 2$。故
$$y = (x+2)e^{1/x}.$$

**(I) 渐近线**:$x\to 0^+$ 时 $y = (x+2)e^{1/x}\to +\infty$,故 $x = 0$ 为垂直渐近线。$x\to+\infty$ 时 $e^{1/x} = 1 + \dfrac{1}{x} + \dfrac{1}{2x^2} + \cdots$,
$$y - x = (x+2)e^{1/x} - x = x+3 + o(1) - x \to 3,$$
故 $y = x + 3$ 为斜渐近线(水平渐近线不存在)。

**(II) 交点个数**:令 $g(x) = (x+2)e^{1/x}\ (x>0)$,
$$g'(x) = e^{1/x}\left(1 - \frac{x+2}{x^2}\right) = e^{1/x}\cdot\frac{x^2-x-2}{x^2} = e^{1/x}\cdot\frac{(x-2)(x+1)}{x^2}.$$
故 $g$ 在 $(0,2)$ 单调递减、在 $(2,+\infty)$ 单调递增,$g(2) = 4\sqrt e$,$\lim\limits_{x\to0^+}g = +\infty$,$\lim\limits_{x\to+\infty}g = +\infty$。值域为 $[4\sqrt e, +\infty)$。
方程 $g(x) = k$ 的解数即 $y = k$ 与 $y = g(x)$ 的交点数:
$$k < 4\sqrt e:\ 0\ \text{个};\qquad k = 4\sqrt e:\ 1\ \text{个};\qquad k > 4\sqrt e:\ 2\ \text{个}.$$

**答案**：(I) 垂直渐近线 $x = 0$,斜渐近线 $y = x + 3$;(II) $0 < k < 4\sqrt e$ 时 0 个交点,$k = 4\sqrt e$ 时 1 个,$k > 4\sqrt e$ 时 2 个。

**易错点**：$x=0$ 不在定义域内,只需考察 $x\to 0^+$;斜渐近线要算 $\lim(y - x)$,不能只算 $y/x\to 1$;求 $g'$ 时勿丢 $e^{1/x}$ 项。

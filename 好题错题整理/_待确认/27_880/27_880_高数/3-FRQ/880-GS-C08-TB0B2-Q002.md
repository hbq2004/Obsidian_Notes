# FRQ 第 2 题

![[_Attachments/题目识别/880-GS/880-GS-C08-TB0B2-Q002_题目.png|题目]]

(2) 设 $f(x)$ 满足 $f''(x) + 2f'(x) + f(x) = 0$，且 $f(0) = 1$，$f'(0) = 0$，$a_n = \int_n^{+\infty} f(x) \, dx$。

求：(I) $f(x)$ 及 $a_n$；

(II) 级数 $\sum\limits_{n=1}^{\infty} a_n$ 的和.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C08-TB0B2-Q002_答案.png|答案]]

## V4 Pro Max 解析

**考点**：解二阶常系数线性微分方程得 $f(x)$，计算广义积分 $a_n=\int_n^{+\infty}f(x)dx$，再用 $e^{-1}$ 的幂级数求和。

**解**
(I) 特征方程 $(r+1)^2=0$，$r=-1$（二重根），故
$$f(x)=(C_1+C_2x)e^{-x}.$$
由 $f(0)=C_1=1$，$f'(x)=(C_2-C_1-C_2x)e^{-x}$，$f'(0)=C_2-1=0\Rightarrow C_2=1$，得
$$f(x)=(1+x)e^{-x}.$$
于是
$$a_n=\int_n^{+\infty}(1+x)e^{-x}dx=\left[-(x+2)e^{-x}\right]_n^{+\infty}=(n+2)e^{-n}.$$

(II)
$$\sum_{n=1}^{\infty}a_n=\sum_{n=1}^{\infty}(n+2)e^{-n}=\sum_{n=1}^{\infty}ne^{-n}+2\sum_{n=1}^{\infty}e^{-n}.$$
利用 $\sum\limits_{n=1}^{\infty}r^n=\dfrac r{1-r}$、$\sum\limits_{n=1}^{\infty}nr^n=\dfrac r{(1-r)^2}$（$|r|<1$），取 $r=e^{-1}$：
$$\sum_{n=1}^{\infty}e^{-n}=\frac1{e-1},\qquad \sum_{n=1}^{\infty}ne^{-n}=\frac{e}{(e-1)^2}.$$
故
$$\sum_{n=1}^{\infty}a_n=\frac{e}{(e-1)^2}+\frac2{e-1}=\frac{3e-2}{(e-1)^2}.$$

**答案**：(I) $f(x)=(1+x)e^{-x}$，$a_n=(n+2)e^{-n}$；(II) $\sum\limits_{n=1}^{\infty}a_n=\dfrac{3e-2}{(e-1)^2}$。

**易错点**：$\int(1+x)e^{-x}dx$ 的原函数是 $-(x+2)e^{-x}$（不是 $-(x+1)e^{-x}$），端点代入别算错；$\sum ne^{-n}$ 用 $\dfrac r{(1-r)^2}$ 公式时 $r=e^{-1}$，化简到 $\dfrac e{(e-1)^2}$ 时容易把 $e$ 的位置写反；两个分式合并通分后分子 $e+2(e-1)=3e-2$。

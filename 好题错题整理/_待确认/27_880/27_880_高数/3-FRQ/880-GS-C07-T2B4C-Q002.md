# FRQ 第 2 题

![[_Attachments/题目识别/880-GS/880-GS-C07-T2B4C-Q002_题目.png|题目]]

(2) 求微分方程 $(x \cos y + \cos x) \frac{dy}{dx} - y \sin x + \sin y = 0$ 的通解.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-T2B4C-Q002_答案.png|答案]]

## V4 Pro Max 解析

**考点**：全微分方程(凑微分/验证恰当性)求通解。

**解**
改写为
$$(\sin y - y\sin x)\,dx + (x\cos y + \cos x)\,dy = 0.$$
记 $M = \sin y - y\sin x$,$N = x\cos y + \cos x$,则
$$\frac{\partial M}{\partial y} = \cos y - \sin x,\qquad
\frac{\partial N}{\partial x} = \cos y - \sin x,$$
二者相等,方程为全微分方程。求势函数 $F$:
$$F = \int M\,dx = x\sin y + y\cos x + g(y),$$
$$\frac{\partial F}{\partial y} = x\cos y + \cos x + g'(y) = x\cos y + \cos x,$$
得 $g'(y) = 0$,取 $g \equiv 0$。

**答案**：$x\sin y + y\cos x = C$。

**易错点**：先验证 $\dfrac{\partial M}{\partial y} = \dfrac{\partial N}{\partial x}$ 再积分;$\int M\,dx$ 中 $\sin y$ 视为常数,$\int y\sin x\,dx = -y\cos x$。

# FRQ 第 5 题

![[_Attachments/题目识别/880-GS/880-GS-C07-T2B4C-Q005_题目.png|题目]]

(5) 求微分方程 $y'' + \frac{1}{2} y'^2 = 2y$ 满足 $y(0) = y'(0) = 2$ 的特解.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-T2B4C-Q005_答案.png|答案]]

## V4 Pro Max 解析

**考点**：缺 $x$ 的可降阶方程(令 $p=y'$,$y'' = p\frac{dp}{dy}$)。

**解**
方程 $y'' + \dfrac12 y'^2 = 2y$,缺 $x$。令 $p = y'$,则 $y'' = p\dfrac{dp}{dy}$:
$$p\frac{dp}{dy} + \frac12 p^2 = 2y.$$
令 $u = p^2$,$\dfrac{du}{dy} = 2p\dfrac{dp}{dy}$,得
$$\frac12 u' + \frac12 u = 2y\;\Longrightarrow\; u' + u = 4y.$$
积分因子 $e^y$:
$$(ue^y)' = 4ye^y\;\Longrightarrow\; ue^y = 4e^y(y-1) + C,$$
$$p^2 = 4(y-1) + Ce^{-y}.$$
由 $y(0) = 2,\ y'(0) = 2$:$p(0)^2 = 4 = 4(2-1) + Ce^{-2}$,得 $C = 0$。故
$$y'^2 = 4(y-1)\;\Longrightarrow\; y' = 2\sqrt{y-1}\quad(\text{取正号,因 } y'(0) = 2 > 0).$$
分离变量:
$$\frac{dy}{\sqrt{y-1}} = 2dx\;\Longrightarrow\; 2\sqrt{y-1} = 2x + C_1.$$
由 $y(0) = 2$ 得 $C_1 = 2$,$\sqrt{y-1} = x + 1$。

**答案**：$y = (x+1)^2 + 1$。

**易错点**：$y'' = p\dfrac{dp}{dy}$ 是缺 $x$ 型的核心;开方取号要由 $y'(0)=2>0$ 确定;特解含 $Ce^{-y}$ 项由初值恰好消去。

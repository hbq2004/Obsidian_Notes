# FRQ 第 15 题

![[_Attachments/题目识别/880-GS/880-GS-C07-T2B4C-B9B29-Q015_题目.png|题目]]

(15) 设在第一象限内的曲线 $y = y(x)$ 满足 $y(0) = 0$，且 $y'(x) > 0$，曲线上任一点 $M(x, y)$ 处的切线段为 $\overline{MT}$，点 $M$ 到 $x$ 轴的垂线为 $\overline{PM}$，如图所示，$\triangle P M T$ 的面积与曲边三角形 $O P M$ 的面积之比恒为常数 $k\left(k > \frac{1}{2}\right)$. 求 $y = y(x)$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-T2B4C-B9B29-Q015_答案.png|答案]]

## V4 Pro Max 解析

**考点**：几何面积条件建立微分方程(曲边三角形面积用积分表示),求解并回代验证。

**解**
过 $M(x,y)$ 的切线为 $Y - y = y'(X-x)$,与 $x$ 轴交点 $T$ 横坐标 $X_T = x - \dfrac{y}{y'}$。$\triangle PMT$ 中 $P = (x,0)$,$M = (x,y)$,底 $PT = \dfrac{y}{y'}$,高 $y$,面积
$$S_{\triangle} = \frac{1}{2}\cdot\frac{y}{y'}\cdot y = \frac{y^2}{2y'}.$$
曲边三角形 $OPM$ 面积 $S_{曲} = \displaystyle\int_0^x y(s)\,ds$。题设
$$\frac{y^2}{2y'} = k\int_0^x y\,ds.$$
两边对 $x$ 求导:
$$\frac{d}{dx}\left(\frac{y^2}{2y'}\right) = ky\;\Longrightarrow\; y - \frac{y^2y''}{2y'^2} = ky,$$
即
$$y'' = \frac{2(1-k)}{y}(y')^2.$$
令 $p = y'$,$y'' = p\dfrac{dp}{dy}$:
$$p\frac{dp}{dy} = \frac{2(1-k)}{y}p^2\;\Longrightarrow\; \frac{dp}{p} = \frac{2(1-k)}{y}dy,$$
$$\ln p = 2(1-k)\ln y + C\;\Longrightarrow\; y' = Cy^{2(1-k)}.$$
分离变量:
$$y^{2k-2}\,dy = C\,dx\;\Longrightarrow\; \frac{y^{2k-1}}{2k-1} = Cx + D.$$
由 $y(0) = 0$ 得 $D = 0$,故 $y^{2k-1} = Cx$($k > \dfrac12$ 保证 $2k-1>0$)。

验证:由 $y^{2k-1}=Cx$ 得 $y' = \dfrac{C}{2k-1}y^{2-2k}$,则 $\dfrac{y^2}{2y'} = \dfrac{2k-1}{2C}y^{2k-1} = \dfrac{2k-1}{2}x$,而 $k\int_0^x y\,ds = k\cdot\dfrac{y^{2k-1}}{C(2k-1)}\cdot\dfrac{C(2k-1)}{...}$:因 $\int_0^x y\,ds = \dfrac{y^{2k-1}}{C(2k-1)}\cdot\dfrac{1}{1}\cdot y^{...}$,直接验算 $\int_0^x y\,ds = \dfrac{1}{C}\cdot\dfrac{y^{2k-1}}{2k-1}$? 更简单:$\int_0^x y\,ds$ 与 $y^{2k-1}=Cx$ 的关系为 $\dfrac{d}{dx}\int_0^x y\,ds = y$,而 $\dfrac{d}{dx}\left[\dfrac{2k-1}{2C}x\right] = \dfrac{2k-1}{2C} = \dfrac{y^2}{2y'}\cdot\dfrac{1}{y}$…,即 $\int_0^x y\,ds = \dfrac{2k-1}{2C}x = \dfrac{y^2}{2ky'}$,与 $\dfrac{y^2}{2y'} = k\int_0^x y\,ds$ 一致 ✓。

**答案**：$y^{2k-1} = Cx$($C>0$ 为任意常数)。

**易错点**：切线在 $y'>0$ 时 $X_T < x$,底边长为 $\dfrac{y}{y'}$;对含积分的等式求导得 $y'' = \dfrac{2(1-k)}{y}y'^2$,注意 $k$ 的系数位置。

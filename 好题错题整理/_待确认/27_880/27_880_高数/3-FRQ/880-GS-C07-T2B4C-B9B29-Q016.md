# FRQ 第 16 题

![[_Attachments/题目识别/880-GS/880-GS-C07-T2B4C-B9B29-Q016_题目.png|题目]]

(16) 设 $y(x)$ 在 $[0, +\infty)$ 上有二阶连续导数，点 $P(x, y)$ ($x > 0$) 为凹曲线 $y = y(x)$ 上的任意一点，沿曲线从点 $(0, 1)$ 到点 $P(x, y)$ 的弧长在数值上等于该曲线在点 $P(x, y)$ 处的切线的斜率，且曲线在点 $(0, 1)$ 处有水平切线。

(I) 求 $y = y(x)$ 的表达式；

(II) 求曲线 $y = y(x)$ 从点 $\left(\ln 2, \frac{5}{4}\right)$ 到点 $\left(\ln 3, \frac{5}{3}\right)$ 的一段弧长.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-T2B4C-B9B29-Q016_答案.png|答案]]

## V4 Pro Max 解析

**考点**：弧长公式与切线斜率相等建立方程 $y'' = \sqrt{1+y'^2}$,可降阶求解,再算弧长。

**解**
**(I)** 从 $(0,1)$ 到 $P(x,y)$ 的弧长 $s(x) = \displaystyle\int_0^x\sqrt{1 + y'(t)^2}\,dt$。题设弧长等于 $P$ 处切线斜率 $y'(x)$:
$$\int_0^x\sqrt{1+y'^2}\,dt = y'(x).$$
两边对 $x$ 求导:
$$\sqrt{1 + y'^2} = y''.$$
令 $p = y'$,则 $y'' = p'$,得 $\dfrac{dp}{dx} = \sqrt{1+p^2}$,分离变量:
$$\int\frac{dp}{\sqrt{1+p^2}} = \int dx\;\Longrightarrow\; \operatorname{arsinh}p = x + C.$$
由 $(0,1)$ 处水平切线,得 $p(0) = 0$,$C = 0$。故 $p = \sinh x$,再积分:
$$y = \cosh x + D,$$
由 $y(0) = 1$ 得 $D = 0$,故 $y = \cosh x$(凹曲线,$y'' = \cosh x > 0$ ✓)。

**(II)** 验证两点:$\cosh(\ln 2) = \dfrac{2 + 1/2}{2} = \dfrac54$,$\cosh(\ln 3) = \dfrac{3 + 1/3}{2} = \dfrac53$ ✓。弧长
$$s = \int_{\ln 2}^{\ln 3}\sqrt{1+\sinh^2 x}\,dx = \int_{\ln 2}^{\ln 3}\cosh x\,dx = \sinh(\ln 3) - \sinh(\ln 2) = \frac43 - \frac34 = \frac{7}{12}.$$

**答案**：(I) $y = \cosh x$;(II) 弧长 $\dfrac{7}{12}$。

**易错点**：$y'' = \sqrt{1+y'^2}$ 由弧长公式对 $x$ 求导得到,注意"弧长等于斜率"是 $s(x) = y'(x)$;$\sinh(\ln 3) = \dfrac{4}{3}$ 的计算别出错。

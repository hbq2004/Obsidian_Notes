# FRQ 第 12 题

![[_Attachments/题目识别/880-GS/880-GS-C06-T2B4C-871F5-Q012_题目.png|题目]]

(12) 设 $D = \left\{ (\theta, r) \mid 0 \leq \theta \leq \frac{\pi}{2}, 0 \leq r \leq 1 \right\}$，计算 $I = \iint_{D} r^{3} e^{r^{2} \cos 2\theta} \sin 2\theta \, d\theta \, dr$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C06-T2B4C-871F5-Q012_答案.png|答案]]

## V4 Pro Max 解析

**考点**：$(\theta,r)$ 平面上的二重积分——被积函数恰为 $e^{r^2\cos2\theta}$ 对 $\theta$ 的导数，先对 $\theta$ 积分。

**解**
$D=\{(\theta,r):\ 0\le\theta\le\dfrac{\pi}{2},\ 0\le r\le1\}$ 是 $(\theta,r)$ 平面上的矩形，$d\theta dr$ 就是普通面积元，无需雅可比因子。注意到
$$\frac{\partial}{\partial\theta}e^{r^2\cos2\theta}=-2r^2\sin2\theta\,e^{r^2\cos2\theta},$$
故
$$I=\int_0^1 r^3\int_0^{\pi/2}e^{r^2\cos2\theta}\sin2\theta\,d\theta\,dr
=\int_0^1 r^3\Bigl[-\frac{1}{2r^2}e^{r^2\cos2\theta}\Bigr]_{\theta=0}^{\pi/2}dr
=\int_0^1 r^3\cdot\frac{e^{r^2}-e^{-r^2}}{2r^2}\,dr.$$

于是
$$I=\frac12\int_0^1 r\bigl(e^{r^2}-e^{-r^2}\bigr)dr
=\frac12\Bigl[\frac{e^{r^2}+e^{-r^2}}{2}\Bigr]_0^1
=\frac{e+e^{-1}-2}{4}=\frac{\cosh 1-1}{2}.$$

**答案**：$I=\dfrac{e+e^{-1}-2}{4}=\dfrac{\cosh 1-1}{2}$。

**易错点**：本题区域以 $(\theta,r)$ 为坐标变量，$d\theta dr$ 直接积分，不能误加极坐标雅可比 $r$；先对 $\theta$ 积分时利用 $\dfrac{\partial}{\partial\theta}e^{r^2\cos2\theta}=-2r^2\sin2\theta\,e^{r^2\cos2\theta}$（注意 $\cos2\theta$ 的链式法则系数 $-2r^2$）。

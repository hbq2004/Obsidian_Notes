# FRQ 第 16 题

![[_Attachments/题目识别/880-GS/880-GS-C05-T2B4C-0C25E-Q016_题目.png|题目]]

(16) 设 $w = xy - z$，$z = z(x, y)$ 有二阶连续偏导数，且满足 $\frac{\partial^2 z}{\partial x^2} + 2 \frac{\partial^2 z}{\partial x \partial y} + \frac{\partial^2 z}{\partial y^2} = 0$。作变换 $u = x + y$，$v = x - y$。

(I) 求 $\frac{\partial^2 w}{\partial u^2}$；

(II) 若 $\frac{\partial w(0, v)}{\partial u} = ve^{-v}$，$w(0, v) = \frac{v^2}{4}$，求 $z(x, y)$ 的表达式.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C05-T2B4C-0C25E-Q016_答案.png|答案]]

## V4 Pro Max 解析

**考点**：变量替换化简二阶偏导方程（方向导数型 PDE）+ 由初值条件反解函数。

**解**
(I) 由 $u=x+y$，$v=x-y$ 得 $x=\frac{u+v}{2}$，$y=\frac{u-v}{2}$。链式法则：
$$z_x=\frac{z_u+z_v}{2},\qquad z_y=\frac{z_u-z_v}{2}.$$
$$z_{xx}=\frac{z_{uu}+2z_{uv}+z_{vv}}{4},\quad z_{xy}=\frac{z_{uu}-z_{vv}}{4},\quad z_{yy}=\frac{z_{uu}-2z_{uv}+z_{vv}}{4}.$$
代入 $z_{xx}+2z_{xy}+z_{yy}=0$：
$$\frac{4z_{uu}}{4}=z_{uu}=0.$$
故
$$\frac{\partial^{2}w}{\partial u^{2}}=\frac{\partial^{2}}{\partial u^{2}}\left(\frac{u^{2}-v^{2}}{4}-z\right)=\frac{1}{2}-z_{uu}=\frac{1}{2}.$$

(II) 由 $z_{uu}=0$ 得 $z=A(v)u+B(v)$。又 $w_u=\frac{u}{2}-z_u$，由 $w_u(0,v)=ve^{-v}$：
$$-z_u(0,v)=-A(v)=ve^{-v}\Rightarrow A(v)=-ve^{-v}.$$
再由 $w(0,v)=\frac{v^{2}}{4}$：
$$w(0,v)=-\frac{v^{2}}{4}-B(v)=\frac{v^{2}}{4}\Rightarrow B(v)=-\frac{v^{2}}{2}.$$
故
$$z(u,v)=-uv\,e^{-v}-\frac{v^{2}}{2},$$
换回 $u=x+y$，$v=x-y$：
$$z(x,y)=-(x^{2}-y^{2})e^{-(x-y)}-\frac{(x-y)^{2}}{2}.$$

**答案**：(I) $\dfrac{\partial^{2}w}{\partial u^{2}}=\dfrac12$；(II) $z(x,y)=-(x^{2}-y^{2})e^{-(x-y)}-\dfrac{(x-y)^{2}}{2}$。

**易错点**：$z_{xx}+2z_{xy}+z_{yy}$ 恰好等于 $4z_{uu}/4=z_{uu}$，即沿 $(1,1)$ 方向的二阶导为零；由 $w(0,v)$ 定 $B(v)$ 时注意 $w$ 中含 $-\frac{v^{2}}{4}$ 项。

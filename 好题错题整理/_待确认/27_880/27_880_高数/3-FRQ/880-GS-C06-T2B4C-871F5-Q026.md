# FRQ 第 26 题

![[_Attachments/题目识别/880-GS/880-GS-C06-T2B4C-871F5-Q026_题目.png|题目]]

(26) 设非负函数 $f(x)$ 在区间 $[0, a](a > 0)$ 上有连续的二阶导数，且 $f(0) = f'(0) = 0$，$f''(x)$ 严格单调递增，平面区域 $D = \{(x, y) \mid 0 \leq x \leq a, 0 \leq y \leq f(x)\}$ 的形心坐标为 $(\overline{x}, \overline{y})$。证明：$x > \frac{3}{4}a$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C06-T2B4C-871F5-Q026_答案.png|答案]]

## V4 Pro Max 解析

**考点**：形心坐标的积分表示 + 利用 $f''$ 严格单调递增比较积分不等式。

**解**

题意即证 $\bar x>\dfrac34a$（原文 "$x>\frac34a$" 中的 $x$ 应为 $\bar x$，疑为 OCR 漏掉上划线）。

形心横坐标
$$\bar x=\frac{\displaystyle\iint_D x\,dx\,dy}{\displaystyle\iint_D dx\,dy}
=\frac{\displaystyle\int_0^a xf(x)\,dx}{\displaystyle\int_0^a f(x)\,dx}.$$

由 $f(0)=f'(0)=0$ 与泰勒/分部积分：
$$f(x)=\int_0^x(x-t)f''(t)\,dt.$$
先说明分母为正：若 $f''(0)<0$，由连续性 $f''<0$ 于 $(0,\delta)$，则 $f'<0$、$f<0$ 于 $(0,\delta)$，与 $f\ge0$ 矛盾，故 $f''(0)\ge0$；又 $f''$ 严格递增，故 $f''(x)>0$（$0<x\le a$），从而 $f(x)>0$（$0<x\le a$），分母 $\int_0^af>0$。

交换积分次序：
$$\int_0^a xf(x)\,dx=\int_0^a f''(t)\int_t^a x(x-t)\,dx\,dt
=\int_0^a f''(t)\,\frac{(a-t)^2(2a+t)}{6}\,dt,$$
$$\int_0^a f(x)\,dx=\int_0^a f''(t)\int_t^a (x-t)\,dx\,dt
=\int_0^a f''(t)\,\frac{(a-t)^2}{2}\,dt.$$
故
$$\bar x-\frac34a
=\frac{\displaystyle\int_0^a f''(t)(a-t)^2\left(\frac{2a+t}{6}-\frac{3a}{8}\right)dt}{\displaystyle\frac12\int_0^a f''(t)(a-t)^2\,dt}
=\frac{\displaystyle\frac1{24}\int_0^a f''(t)\,W(t)\,dt}{\displaystyle\frac12\int_0^a f''(t)(a-t)^2\,dt},$$
其中 $W(t)=(a-t)^2(4t-a)$。

验证 $\displaystyle\int_0^a W(t)\,dt=0$：
$$\int_0^a(a-t)^2(4t-a)\,dt
=\int_0^a s^2\bigl(3a-4s\bigr)\,ds=3a\cdot\frac{a^3}{3}-4\cdot\frac{a^4}{4}=0.$$
且 $W$ 在 $[0,\frac a4)$ 上为负、在 $(\frac a4,a]$ 上非负。因 $f''$ 严格递增，$f''(t)<f''(\frac a4)$（$t<\frac a4$）、$f''(t)>f''(\frac a4)$（$t>\frac a4$），故（在正测度集上严格成立）
$$\int_0^a f''(t)W(t)\,dt
>f''\left(\frac a4\right)\int_0^a W(t)\,dt=0.$$
于是 $\bar x-\dfrac34a>0$，即 $\bar x>\dfrac34a$。$\blacksquare$

**答案**：$\bar x>\dfrac34a$ 得证。

**易错点**：先把 $\bar x$ 化成 $\frac{\int xf}{\int f}$，再用 $f(x)=\int_0^x(x-t)f''(t)dt$ 与换序把分子分母表成 $f''$ 的加权积分；比较的关键是 $\int_0^a(a-t)^2(4t-a)\,dt=0$ 与 $f''$ 严格递增（配 $t=\frac a4$ 比较）；还需由非负性推出 $f''(0)\ge0$ 以保证 $f''>0$ 于 $(0,a]$、分母为正。

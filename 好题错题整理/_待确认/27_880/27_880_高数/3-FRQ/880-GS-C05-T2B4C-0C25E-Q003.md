# FRQ 第 3 题

![[_Attachments/题目识别/880-GS/880-GS-C05-T2B4C-0C25E-Q003_题目.png|题目]]

(3) 求椭球面 $\frac{x^2}{a^2} + \frac{y^2}{b^2} + \frac{z^2}{c^2} = 1(a, b, c > 0)$ 在第一卦限上的切平面与三个坐标面围成的四面体的最小体积.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C05-T2B4C-0C25E-Q003_答案.png|答案]]

## V4 Pro Max 解析

**考点**：椭球面切平面截距 + 条件极值（拉格朗日乘数法 / 均值不等式）求最小体积。

**解**
设切点为 $(x_0,y_0,z_0)$（第一卦限，各坐标 $>0$）。椭球面 $F=\frac{x^2}{a^2}+\frac{y^2}{b^2}+\frac{z^2}{c^2}-1=0$ 在切点的切平面为
$$\frac{x_0x}{a^{2}}+\frac{y_0y}{b^{2}}+\frac{z_0z}{c^{2}}=1.$$
与三坐标面的截距分别为 $\dfrac{a^{2}}{x_0},\ \dfrac{b^{2}}{y_0},\ \dfrac{c^{2}}{z_0}$，故四面体体积
$$V=\frac{1}{6}\cdot\frac{a^{2}b^{2}c^{2}}{x_0y_0z_0}.$$

最小化 $V$ 等价于在约束 $\frac{x_0^{2}}{a^{2}}+\frac{y_0^{2}}{b^{2}}+\frac{z_0^{2}}{c^{2}}=1$ 下最大化 $x_0y_0z_0$。由拉格朗日乘数法（或均值不等式）：
$$x_0y_0z_0\le abc\left(\frac{\frac{x_0^{2}}{a^{2}}+\frac{y_0^{2}}{b^{2}}+\frac{z_0^{2}}{c^{2}}}{3}\right)^{3/2}=\frac{abc}{3\sqrt{3}},$$
等号当 $\frac{x_0}{a}=\frac{y_0}{b}=\frac{z_0}{c}=\frac{1}{\sqrt3}$ 时取得。

故
$$V_{\min}=\frac{1}{6}\cdot\frac{a^{2}b^{2}c^{2}}{abc/(3\sqrt3)}=\frac{\sqrt3}{2}\,abc.$$

**答案**：最小体积为 $\dfrac{\sqrt3}{2}abc$。

**易错点**：切平面截距要写对（$a^2/x_0$ 而非 $a/x_0$）；最大化 $x_0y_0z_0$ 时勿忘约束，等号条件 $\frac{x_0}{a}=\frac{y_0}{b}=\frac{z_0}{c}$ 是最值点。

# FRQ 第 10 题

![[_Attachments/题目识别/880-GS/880-GS-C07-T2B4C-Q010_题目.png|题目]]

(10) 设 $\overparen{OA}$ 是连接 $O(0,0)$ 和 $A(1,1)$ 的一段向上凸的曲线弧，$P(x,y)$ 为 $\overparen{OA}$ 上任一点，曲线弧 $\overparen{OP}$ 与有向线段 $\overparen{OP}$ 所围图形的面积为 $x^2$，求曲线弧 $\overparen{OA}$ 的方程.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-T2B4C-Q010_答案.png|答案]]

## V4 Pro Max 解析

**考点**：面积条件(弧与弦围成面积)建模得一阶线性方程。

**解**
设 $P(x,y)$ 在弧 $\overparen{OA}$ 上($0\le x\le1$),弧 $\overparen{OP}$ 与弦 $OP$ 围成的面积为
$$S = \int_0^x y(t)\,dt - \frac{1}{2}xy$$
(上凸曲线在弦之上,曲边梯形面积减三角形面积)。题设 $S = x^2$:
$$\int_0^x y(t)\,dt - \frac12 xy = x^2.$$
对 $x$ 求导:
$$y - \frac12(y + xy') = 2x\;\Longrightarrow\; y - xy' = 4x,$$
即
$$y' - \frac{1}{x}y = -4.$$
积分因子 $\dfrac{1}{x}$:
$$\left(\frac{y}{x}\right)' = -\frac{4}{x}\;\Longrightarrow\; \frac{y}{x} = -4\ln x + C.$$
由 $A(1,1)$ 在曲线上得 $y(1) = 1$,$C = 1$。

**答案**：$y = x(1 - 4\ln x)$。

**易错点**：面积是"弧与弦围成"而非曲边梯形面积本身,要减去 $\triangle OPM$ 的面积 $\dfrac12 xy$;求导后 $y' - y/x = -4$ 是一阶线性方程。

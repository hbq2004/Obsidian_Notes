# FRQ 第 5 题

![[_Attachments/题目识别/880-GS/880-GS-C06-T2B4C-871F5-Q005_题目.png|题目]]

(5)设上半平面的有界区域 $D = \{ (x, y) \mid 1 \leq x^2 + (y - |x|)^2 \leq 2, 0 \leq y \}$，计算 $I = \iint_D \frac{x + 1}{2x^2 + y^2} \, dx \, dy$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C06-T2B4C-871F5-Q005_答案.png|答案]]

## V4 Pro Max 解析

**考点**：二重积分——极坐标变换与对称性；区域是以曲线 $y=|x|$ 为中心的"圆环"型区域。

**解**
先由对称性消项：区域 $D$ 关于 $y$ 轴对称，$\dfrac{x}{2x^2+y^2}$ 为 $x$ 的奇函数，故
$$\iint_D\frac{x}{2x^2+y^2}dxdy=0,\qquad I=\iint_D\frac{dxdy}{2x^2+y^2}.$$

令 $x=r\cos\theta$，$y=r\sin\theta$。因 $y\ge 0$，$\theta\in[0,\pi]$。记
$$g(\theta)=1+\cos^2\theta-2\sin\theta|\cos\theta|,$$
则
$$x^2+(y-|x|)^2=r^2\bigl[\cos^2\theta+(\sin\theta-|\cos\theta|)^2\bigr]=r^2g(\theta).$$
区域条件 $1\le x^2+(y-|x|)^2\le 2$ 化为
$$\sqrt{\frac{1}{g(\theta)}}\le r\le \sqrt{\frac{2}{g(\theta)}}.$$

且 $2x^2+y^2=r^2(2\cos^2\theta+\sin^2\theta)=r^2(1+\cos^2\theta)$，故
$$I=\int_0^\pi\int_{\sqrt{1/g}}^{\sqrt{2/g}}\frac{r\,dr}{r^2(1+\cos^2\theta)}\,d\theta
=\int_0^\pi\frac{1}{1+\cos^2\theta}\Bigl[\ln r\Bigr]_{\sqrt{1/g}}^{\sqrt{2/g}}d\theta
=\frac{\ln 2}{2}\int_0^\pi\frac{d\theta}{1+\cos^2\theta}.$$

利用常用结论 $\displaystyle\int_0^\pi\frac{d\theta}{1+\cos^2\theta}=\frac{\pi}{\sqrt2}$，得
$$I=\frac{\ln 2}{2}\cdot\frac{\pi}{\sqrt2}=\frac{\pi\ln 2}{2\sqrt2}.$$

**答案**：$I=\dfrac{\pi\ln 2}{2\sqrt2}$。

**易错点**：先由关于 $y$ 轴对称消去被积函数的奇部 $\dfrac{x}{2x^2+y^2}$（也可用 $\theta\to\pi-\theta$ 对称性消去 $\cos\theta$ 项）；极坐标下 $r$ 的上下限随 $\theta$ 变化（$\sqrt{1/g}\le r\le\sqrt{2/g}$），$\ln$ 之差恰为 $\dfrac12\ln2$，与 $\theta$ 无关。

# FRQ 第 14 题

![[_Attachments/题目识别/880-GS/880-GS-C06-T2B4C-871F5-Q014_题目.png|题目]]

(14) 设 $D = \{(x, y) \mid 0 \leq x \leq 1, 0 \leq y \leq x\}$，计算 $I = \iint_{D} \arcsin \left(2\sqrt{x - x^2}\right) dx dy$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C06-T2B4C-871F5-Q014_答案.png|答案]]

## V4 Pro Max 解析

**考点**：二重积分——被积函数与 $y$ 无关先积 $y$，再作三角代换 $x=\sin^2\theta$，利用 $\arcsin(\sin2\theta)$ 的分段表达式化简。

**解**
被积函数 $\arcsin\bigl(2\sqrt{x-x^2}\bigr)$ 不含 $y$，先对 $y$ 积分：
$$I=\int_0^1\Bigl(\int_0^x dy\Bigr)\arcsin\bigl(2\sqrt{x-x^2}\bigr)dx=\int_0^1 x\arcsin\bigl(2\sqrt{x-x^2}\bigr)dx.$$

令 $x=\sin^2\theta$，$\theta\in\Bigl[0,\dfrac{\pi}{2}\Bigr]$，则 $dx=\sin2\theta\,d\theta$，且
$$2\sqrt{x-x^2}=2\sin\theta\cos\theta=\sin2\theta.$$
故
$$I=\int_0^{\pi/2}\sin^2\theta\cdot\arcsin(\sin2\theta)\cdot\sin2\theta\,d\theta.$$

按 $\theta$ 分段：
$$\arcsin(\sin2\theta)=
\begin{cases}
2\theta, & 0\le\theta\le\dfrac{\pi}{4},\\[2mm]
\pi-2\theta, & \dfrac{\pi}{4}\le\theta\le\dfrac{\pi}{2}.
\end{cases}$$

于是
$$I=\int_0^{\pi/4}2\theta\sin^2\theta\sin2\theta\,d\theta
+\int_{\pi/4}^{\pi/2}(\pi-2\theta)\sin^2\theta\sin2\theta\,d\theta.$$

第二项中令 $\phi=\dfrac{\pi}{2}-\theta$，则 $\sin^2\theta=\cos^2\phi$，$\sin2\theta=\sin2\phi$，得
$$\int_{\pi/4}^{\pi/2}(\pi-2\theta)\sin^2\theta\sin2\theta\,d\theta=\int_0^{\pi/4}2\phi\cos^2\phi\sin2\phi\,d\phi.$$

两段合并：
$$I=\int_0^{\pi/4}2\theta\bigl(\sin^2\theta+\cos^2\theta\bigr)\sin2\theta\,d\theta
=\int_0^{\pi/4}2\theta\sin2\theta\,d\theta
=\Bigl[-\theta\cos2\theta+\frac{\sin2\theta}{2}\Bigr]_0^{\pi/4}=\frac12.$$

**答案**：$I=\dfrac{1}{2}$。

**易错点**：被积函数与 $y$ 无关，先积 $y$ 得到因子 $x$（$\int_0^xdy=x$）；$\arcsin(\sin2\theta)$ 在 $\theta\in[\tfrac{\pi}{4},\tfrac{\pi}{2}]$ 上等于 $\pi-2\theta$ 而非 $2\theta$，这是本题的关键分段；第二段经 $\theta\to\dfrac{\pi}{2}-\theta$ 后恰好与第一段配成 $\sin^2\theta+\cos^2\theta=1$。

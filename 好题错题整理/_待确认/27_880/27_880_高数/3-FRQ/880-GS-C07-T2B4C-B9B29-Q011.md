# FRQ 第 11 题

![[_Attachments/题目识别/880-GS/880-GS-C07-T2B4C-B9B29-Q011_题目.png|题目]]

(11) 设 $f(x)$ 在 $[0,1]$ 上有连续导数, $f(0)=1$, $f_{+}^{\prime}(0)=1$, 且

$$\iint_{D} f''(x+y) \, dx \, dy = \iint_{D} \left[ f(x+y) + (x-y)^{3} \right] dx \, dy$$

其中 $D = \{(x,y) \mid 0 \leqslant y \leqslant t-x, 0 \leqslant x \leqslant t\}$ ($0 < t \leqslant 1$), 求 $f(x)$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-T2B4C-B9B29-Q011_答案.png|答案]]

## V4 Pro Max 解析

**考点**：二重积分换序/换元 + 对参数 $t$ 求导,化为 $f''=f$ 的常微分方程。

**解**
区域 $D = \{(x,y): 0\le x\le t,\ 0\le y\le t-x\}$,即 $x\ge0,\ y\ge0,\ x+y\le t$(三角形)。作换元 $u = x+y$:对固定的 $u\in[0,t]$,$x$ 从 $0$ 到 $u$,故
$$\iint_D f''(x+y)\,dxdy = \int_0^t\int_0^u f''(u)\,dx\,du = \int_0^t u f''(u)\,du.$$
右边:
$$\iint_D\big[f(x+y) + (x-y)^3\big]dxdy = \int_0^t\int_0^u \big[f(u) + (2x-u)^3\big]dx\,du,$$
而 $\displaystyle\int_0^u (2x-u)^3dx = \left[\frac{(2x-u)^4}{8}\right]_0^u = 0$,故右边 $= \displaystyle\int_0^t u f(u)\,du$。
因此对一切 $0<t\le1$:
$$\int_0^t u f''(u)\,du = \int_0^t u f(u)\,du.$$
两边对 $t$ 求导得 $t f''(t) = t f(t)$,即 $f'' = f$。通解 $f = C_1e^x + C_2e^{-x}$。由 $f(0) = 1$ 得 $C_1 + C_2 = 1$;由 $f'_+(0) = 1$ 得 $C_1 - C_2 = 1$。解得 $C_1 = 1,\ C_2 = 0$。

**答案**：$f(x) = e^x$。

**易错点**：$(x-y)^3$ 在三角形区域上对固定 $u=x+y$ 积分恰好为 0(奇函数在对称区间);等式两边对 $t$ 求导时用变上限积分求导公式。

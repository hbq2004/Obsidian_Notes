# FRQ 第 5 题

![[_Attachments/题目识别/880-GS/880-GS-C07-T2B4C-B9B29-Q005_题目.png|题目]]

(5) 设 $f(x)$ 有二阶连续导数，且 $f(1) = 1$，$f'(1) = 2$，求 $u(x, y)$，使得

$$du = -6yf(x)dx + [x^2f'(x) - 4xf(x)]dy.$$

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-T2B4C-B9B29-Q005_答案.png|答案]]

## V4 Pro Max 解析

**考点**：全微分存在的充要条件(混合偏导相等)反求 $f(x)$,再积分求势函数 $u$。

**解**
设 $P = -6yf(x)$,$Q = x^2f'(x) - 4xf(x)$。$du$ 是全微分 $\Leftrightarrow \dfrac{\partial P}{\partial y} = \dfrac{\partial Q}{\partial x}$:
$$\frac{\partial P}{\partial y} = -6f(x),\qquad
\frac{\partial Q}{\partial x} = 2xf'(x) + x^2f''(x) - 4f(x) - 4xf'(x) = x^2f'' - 2xf' - 4f.$$
令相等:
$$x^2f'' - 2xf' - 4f = -6f\;\Longrightarrow\; x^2f'' - 2xf' + 2f = 0.$$
欧拉方程,令 $x = e^t$,$D = \dfrac{d}{dt}$:
$$\big[D(D-1) - 2D + 2\big]f = (D^2 - 3D + 2)f = 0,$$
特征根 $r = 1, 2$,故 $f = C_1x + C_2x^2$。由 $f(1) = 1,\ f'(1) = 2$:
$$C_1 + C_2 = 1,\qquad C_1 + 2C_2 = 2\;\Longrightarrow\; C_1 = 0,\ C_2 = 1,$$
故 $f(x) = x^2$。
于是 $du = -6x^2y\,dx + (2x^3 - 4x^3)dy = -6x^2y\,dx - 2x^3\,dy$。由 $\dfrac{\partial u}{\partial x} = -6x^2y$:
$$u = -2x^3y + g(y),\qquad \frac{\partial u}{\partial y} = -2x^3 + g'(y) = -2x^3\;\Longrightarrow\; g'(y) = 0.$$

**答案**：$f(x) = x^2$;$u(x,y) = -2x^3y + C$。

**易错点**：$\dfrac{\partial Q}{\partial x}$ 求导时 $x^2f'(x)$ 与 $-4xf(x)$ 都要用乘积法则;欧拉方程特征根求完记得用 $f(1),f'(1)$ 定常数。

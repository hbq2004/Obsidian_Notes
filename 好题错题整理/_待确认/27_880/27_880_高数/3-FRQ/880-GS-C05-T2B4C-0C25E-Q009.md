# FRQ 第 9 题

![[_Attachments/题目识别/880-GS/880-GS-C05-T2B4C-0C25E-Q009_题目.png|题目]]

(9) 设可微函数 $f(x, y)$ 在点 $P(x, y)$ 处沿 $l_1 = (-1, 0)$ 与 $l_2 = (0, -1)$ 的方向导数分别为 $x^2 - y$ 与 $1 - x$，且 $f(1, 1) = -\frac{1}{3}$。

(I) 求 $f(x, y)$；

(II) 求 $f(x, y)$ 在 $D = \{(x, y) | 0 \leq y \leq 7 - x, 0 \leq x \leq 7\}$ 上的最大值.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C05-T2B4C-0C25E-Q009_答案.png|答案]]

## V4 Pro Max 解析

**考点**：方向导数与偏导数的关系反求函数（解偏微分方程）+ 闭区域上最值。

**解**
(I) 沿单位方向 $l$ 的方向导数 $\frac{\partial f}{\partial l}=\nabla f\cdot l$。

沿 $l_1=(-1,0)$：$-f_x=x^{2}-y\Rightarrow f_x=y-x^{2}$。
沿 $l_2=(0,-1)$：$-f_y=1-x\Rightarrow f_y=x-1$。

积分：$f=\int(y-x^{2})dx=xy-\frac{x^{3}}{3}+\varphi(y)$，则 $f_y=x+\varphi'(y)=x-1\Rightarrow\varphi'(y)=-1$，$\varphi(y)=-y+C$。

由 $f(1,1)=1-\frac13-1+C=-\frac13\Rightarrow C=0$。故
$$f(x,y)=xy-\frac{x^{3}}{3}-y.$$

(II) $D$ 为顶点 $(0,0),(7,0),(0,7)$ 的闭三角形。

内部驻点：$f_x=y-x^{2}=0$，$f_y=x-1=0\Rightarrow(1,1)$，$f(1,1)=-\frac13$。

边界：$x=0$ 上 $f=-y\in[-7,0]$；$y=0$ 上 $f=-\frac{x^{3}}{3}\in[-\frac{343}{3},0]$；斜边 $y=7-x$ 上
$$f=x(7-x)-\frac{x^{3}}{3}-(7-x)=-\frac{x^{3}}{3}-x^{2}+8x-7,$$
$f'=-x^{2}-2x+8=0\Rightarrow x=2$（另一根 $-4$ 不在区间），$f(2,5)=\frac73$。

比较得最大值 $\frac73$。

**答案**：(I) $f(x,y)=xy-\dfrac{x^{3}}{3}-y$；(II) 在 $D$ 上的最大值为 $\dfrac73$（在 $(2,5)$ 处取得）。

**易错点**：方向 $(-1,0)$ 是 $-x$ 方向，方向导数 $=-f_x$，符号不要搞反；闭区域最值要逐段检查边界。

# FRQ 第 3 题

![[_Attachments/题目识别/880-GS/880-GS-C03-T2B4C-Q003_题目.png|题目]]

(3) 求下列积分:

(I) $\int \frac{dx}{\sin^2 x \cos^4 x}$;

(II) $\int \frac{dx}{1 + \sin x}$;

(III) $\int \frac{\sin x}{\sin x + \cos x} dx$;

(IV) $\int \frac{3 \sin x + \cos x}{\sin x + 2 \cos x} dx$;

(V) $\int \frac{dx}{\sin 2x + 2\sin x};$

(VI) $\int \frac{dx}{a^2 \sin^2 x + b^2 \cos^2 x} (a^2 + b^2 > 0).$

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C03-T2B4C-Q003_答案.png|答案]]

## V4 Pro Max 解析

**考点**：三角有理式积分——凑微分、分子有理化、线性组合拆分、万能代换。

**解**

(I) 利用 $\sin^2x+\cos^2x=1$ 拆项：
$$\frac1{\sin^2x\cos^4x}=\frac1{\cos^4x}+\frac1{\sin^2x\cos^2x}=\sec^4x+\sec^2x+\csc^2x,$$
$$\int\frac{dx}{\sin^2x\cos^4x}=\int(1+\tan^2x)\,d(\tan x)+\tan x-\cot x=2\tan x+\frac13\tan^3x-\cot x+C.$$

(II) 分子有理化：
$$\int\frac{dx}{1+\sin x}=\int\frac{1-\sin x}{\cos^2x}dx=\int(\sec^2x-\sec x\tan x)dx=\tan x-\sec x+C.$$

(III) 待定系数：$\sin x=\frac12(\sin x+\cos x)-\frac12(\cos x-\sin x)$，
$$\int\frac{\sin x}{\sin x+\cos x}dx=\frac12x-\frac12\ln|\sin x+\cos x|+C.$$

(IV) 待定系数：$3\sin x+\cos x=(\sin x+2\cos x)-(\cos x-2\sin x)$，
$$\int\frac{3\sin x+\cos x}{\sin x+2\cos x}dx=x-\ln|\sin x+2\cos x|+C.$$

(V) 先化简：$\sin2x+2\sin x=2\sin x(1+\cos x)$。万能代换 $t=\tan\frac x2$（$dx=\frac{2dt}{1+t^2}$，$\sin x=\frac{2t}{1+t^2}$，$\cos x=\frac{1-t^2}{1+t^2}$）：
$$\int\frac{dx}{\sin2x+2\sin x}=\frac14\int\frac{1+t^2}{t}dt=\frac14\ln\left|\tan\frac x2\right|+\frac18\tan^2\frac x2+C.$$

(VI) 分子分母同除 $\cos^2x$：
$$\int\frac{dx}{a^2\sin^2x+b^2\cos^2x}=\int\frac{d(\tan x)}{a^2\tan^2x+b^2}=\frac1{ab}\arctan\left(\frac ab\tan x\right)+C\quad(a\neq0);$$
（$a=0$ 时原式 $=\frac1{b^2}\tan x+C$；$b=0$ 时 $=-\frac1{a^2}\cot x+C$。）

**答案**：(I) $2\tan x+\dfrac13\tan^3x-\cot x+C$；(II) $\tan x-\sec x+C$；(III) $\dfrac x2-\dfrac12\ln|\sin x+\cos x|+C$；(IV) $x-\ln|\sin x+2\cos x|+C$；(V) $\dfrac14\ln\left|\tan\dfrac x2\right|+\dfrac18\tan^2\dfrac x2+C$；(VI) $\dfrac1{ab}\arctan\left(\dfrac ab\tan x\right)+C$。

**易错点**：(I) 用 $\sin^2+\cos^2=1$ 拆项比万能代换快得多；(III)(IV) 待定系数模板：分子 $=a$ 分母 $+b$ 分母的导数；(V) 先化成 $2\sin x(1+\cos x)$ 再万能代换；(VI) $a=0$ 或 $b=0$ 的退化情形要单独说明。

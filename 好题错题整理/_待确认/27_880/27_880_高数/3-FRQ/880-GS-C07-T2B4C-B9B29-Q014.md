# FRQ 第 14 题

![[_Attachments/题目识别/880-GS/880-GS-C07-T2B4C-B9B29-Q014_题目.png|题目]]

y(0)=1,y′(x)>0,求 y=y(x).

14) 设 y=y(x) 是向上凸的连续曲线, 其上任一点 (x,y) 处的曲率为 $\frac{1}{\sqrt{1+y'^2}}$, 且此曲线上点 (0,1) 处的切线方程为 y=x+1, 求该曲线的方程.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-T2B4C-B9B29-Q014_答案.png|答案]]

## V4 Pro Max 解析

**考点**：由曲率公式建立二阶方程($|y''| = 1 + y'^2$),结合上凸性与切线条件求解。

**解**
曲率 $K = \dfrac{|y''|}{(1+y'^2)^{3/2}} = \dfrac{1}{\sqrt{1+y'^2}}$,故 $|y''| = 1 + y'^2$。曲线向上凸,故 $y'' < 0$,于是
$$-y'' = 1 + y'^2.$$
令 $p = y'$,$p' = y''$:
$$-p' = 1 + p^2\;\Longrightarrow\; \frac{dp}{1+p^2} = -dx\;\Longrightarrow\; \arctan p = -x + C.$$
由 $(0,1)$ 处切线为 $y = x+1$,得 $p(0) = 1$,$\arctan 1 = \dfrac{\pi}{4} = C$,故
$$p = \tan\left(\frac{\pi}{4} - x\right).$$
积分($u = \dfrac{\pi}{4}-x$):
$$y = \int\tan\left(\frac{\pi}{4}-x\right)dx = \ln\left|\cos\left(\frac{\pi}{4}-x\right)\right| + D.$$
由 $y(0) = 1$:$\ln\dfrac{\sqrt2}{2} + D = 1$,得 $D = 1 + \dfrac{1}{2}\ln 2$。故
$$y = 1 + \ln\left(\sqrt2\cos\left(\frac{\pi}{4}-x\right)\right) = 1 + \ln(\cos x + \sin x).$$

验证:$y' = \dfrac{\cos x - \sin x}{\cos x + \sin x}$,$y'(0) = 1$;$y'' = -\dfrac{2}{(\cos x+\sin x)^2} < 0$,且 $K = \dfrac{|y''|}{(1+y'^2)^{3/2}} = \dfrac{|\cos x + \sin x|}{\sqrt2} = \dfrac{1}{\sqrt{1+y'^2}}$ ✓。

**答案**：$y = 1 + \ln(\cos x + \sin x)$。

**易错点**：曲率公式分母是 $(1+y'^2)^{3/2}$;上凸决定 $y''<0$ 去掉绝对值;$\int\tan(\frac{\pi}{4}-x)dx$ 的结果符号易错,记得回代验证 $y'(0)=1$。

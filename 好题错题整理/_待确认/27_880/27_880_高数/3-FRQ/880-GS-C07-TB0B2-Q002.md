# FRQ 第 2 题

![[_Attachments/题目识别/880-GS/880-GS-C07-TB0B2-Q002_题目.png|题目]]

(2) 设全微分方程为 $[xy(x+y)-f(x)y] \, dx + [x^2y + f'(x)] \, dy = 0$，其中 $f(x)$ 有二阶连续导数，且 $f(0) = 0, f'(0) = 1$，求 $f(x)$ 及全微分方程的通解.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-TB0B2-Q002_答案.png|答案]]

## V4 Pro Max 解析

**考点**：全微分方程条件反求 $f(x)$(二阶常系数非齐次),再求势函数得通解。

**解**
记 $M = xy(x+y) - f(x)y$,$N = x^2y + f'(x)$。全微分方程 $\Leftrightarrow \dfrac{\partial M}{\partial y} = \dfrac{\partial N}{\partial x}$:
$$\frac{\partial M}{\partial y} = x^2 + 2xy - f(x),\qquad
\frac{\partial N}{\partial x} = 2xy + f''(x),$$
令相等得
$$f''(x) + f(x) = x^2.$$
齐次通解 $C_1\cos x + C_2\sin x$;设特解 $f_p = ax^2 + bx + c$:$f_p'' + f_p = 2a + ax^2 + bx + c = x^2$,得 $a = 1,\ b = 0,\ 2 + c = 0$,即 $c = -2$。故
$$f(x) = C_1\cos x + C_2\sin x + x^2 - 2.$$
由 $f(0) = 0$ 得 $C_1 = 2$;由 $f'(x) = -2\sin x + C_2\cos x + 2x$ 及 $f'(0) = 1$ 得 $C_2 = 1$:
$$f(x) = x^2 - 2 + 2\cos x + \sin x.$$
求势函数 $u$:先化简 $M = xy(x+y) - f(x)y = x^2y + xy^2 - (x^2 - 2 + 2\cos x + \sin x)y = xy^2 + 2y - 2y\cos x - y\sin x$,于是
$$u = \int (xy^2 + 2y - 2y\cos x - y\sin x)\,dx = \frac{x^2y^2}{2} + 2xy - 2y\sin x + y\cos x + g(y).$$
再由 $\dfrac{\partial u}{\partial y} = x^2y + 2x - 2\sin x + \cos x + g'(y) = N = x^2y + f'(x) = x^2y - 2\sin x + \cos x + 2x$,得 $g'(y) = 0$。

**答案**：$f(x) = x^2 - 2 + 2\cos x + \sin x$;全微分方程通解 $\dfrac{x^2y^2}{2} + 2xy - 2y\sin x + y\cos x = C$。

**易错点**：$\dfrac{\partial M}{\partial y}$ 中 $f(x)y$ 对 $y$ 求导得 $-f(x)$;势函数积分时把 $M$ 中 $x^2y$ 与 $-x^2y$ 抵消后再积分,可简化计算。

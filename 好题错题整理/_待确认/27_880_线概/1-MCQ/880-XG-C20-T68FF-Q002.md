# MCQ 第 2 题

![[_Attachments/题目识别/880-XG/880-XG-C20-T68FF-Q002_题目.png|题目]]

(2)设随机变量 $X_1, X_2, \cdots, X_n$ 相互独立，记 $Y_n = X_1 + X_2 + \cdots + X_n$，根据列维一林德伯格中心极限定理，$Y_n$ 近似服从正态分布 ($n$ 充分大)，则只要 $X_1, X_2, \cdots, X_n($ )。

A. 服从同一离散型分布
B. 服从同一连续型分布
C. 服从同一指数分布
D. 具有相同的期望与方差

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C20-T68FF-Q002_答案.png|答案]]

## V4 Pro Max 解析

**考点**：林德伯格-莱维中心极限定理的适用条件(独立同分布 + 方差存在)。

**解**
列维-林德伯格(林德伯格-莱维)中心极限定理要求 $X_1,\dots,X_n$ **独立同分布且方差有限**。逐一检验:

- A、B 选项只说"服从同一离散(连续)型分布",未保证方差存在——例如柯西分布是连续型但方差不存在,故不足以保证 CLT 成立;
- C 选项"服从同一指数分布":指数分布由参数确定分布,且二阶矩有限,同时满足同分布与方差存在,充分保证定理适用;
- D 选项"具有相同的期望与方差"不保证同分布,定理不适用。

**答案**：C。

**易错点**：CLT 的充分条件是"独立同分布 + 方差存在"两个条件缺一不可;仅同分布不够(可能无方差),仅期望方差相同也不够(可能不同分布)。

# MCQ 第 4 题

![[_Attachments/题目识别/880-XG/880-XG-C16-T68FF-Q004_题目.png|题目]]

(4)设 $A$,$B$,$C$ 是三个相互独立的随机事件，且 $0<P(C)<1$，则下列四对事件中不相互独立的是().

A. $\overline{A \cup B}$ 与 $C$

B. $\overline{A}$ 与 $\overline{C}$

C. $\overline{A-B}$ 与 $\overline{C}$

D. $\overline{AB}$ 与 $\overline{C}$

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C16-T68FF-Q004_答案.png|答案]]

## V4 Pro Max 解析

**考点**：相互独立事件组的并、交、补运算性质(区分两两独立与相互独立)。

**解**
若 $A,B,C$ 相互独立,则"由其中部分事件经有限次并、交、补运算所得的事件"与"由其余事件运算所得的事件"仍相互独立。逐一检验:

- A 选项:$\overline{A\cup B}=\overline A\cap\overline B$ 是 $A,B$ 的运算结果,与 $C$ 独立;
- B 选项:$\overline A$ 与 $\overline C$ 是独立事件 $A,C$ 的补事件,独立;
- C 选项:$\overline{A-B}=\overline A\cup B$ 是 $A,B$ 的运算结果,与 $\overline C$ 独立;
- D 选项:$\overline{AB}=\overline A\cup\overline B$ 是 $A,B$ 的运算结果,与 $\overline C$ 独立。

以 D 为例验证:记 $X=\overline{AB},\ Y=\overline C$,
$$P(XY)=P\big(\overline{AB\cup C}\big)=1-P(AB)-P(C)+P(ABC),$$
$$P(X)P(Y)=\big(1-P(AB)\big)\big(1-P(C)\big)=1-P(AB)-P(C)+P(AB)P(C),$$
两者相等当且仅当 $P(ABC)=P(AB)P(C)$,而 $A,B,C$ 相互独立时 $P(ABC)=P(A)P(B)P(C)=P(AB)P(C)$,成立。

**结论**：按题干"$A,B,C$ 相互独立",四个选项中两两事件均相互独立,题目无正确选项,题干疑似 OCR 有误(该经典题的常见版本以"两两独立"为条件,此时选项 D 中 $\overline{AB}$ 与 $\overline C$ 的独立要求 $P(ABC)=P(AB)P(C)$,仅两两独立不能保证,教材多以 D 为答案;但两两独立时 A、C 选项同样可能不独立,原题设置本身存在瑕疵)。

**答案**：按题干文字无正确选项(四对均独立);若条件实为"两两独立",教材答案通常为 D。

**易错点**：区分"两两独立"与"相互独立"——只有相互独立才保证 $P(ABC)=P(A)P(B)P(C)$;"对独立组作并交补运算仍独立"要求所涉两组事件整体独立。

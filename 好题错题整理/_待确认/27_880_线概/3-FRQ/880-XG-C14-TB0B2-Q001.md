# FRQ 第 1 题

![[_Attachments/题目识别/880-XG/880-XG-C14-TB0B2-Q001_题目.png|题目]]

(1) 设 $A$ 是 3 阶实对称矩阵，存在可逆矩阵 $P$，使得 $P^{-1}AP = diag(1, 2, -1)$，且 $\alpha_1 = (1, k + 1, 2)^T$，$\alpha_2 = (k - 1, -k, 1)^T$ 分别为 $A$ 的特征值 $\lambda_1 = 1$，$\lambda_2 = 2$ 对应的特征向量，$A^*$ 的特征值 $\lambda_0$ 对应的特征向量 $\beta = (2, -5k, 2k + 1)^T$. 求：

(I) $\lambda_0$ 与 $k$ 的值；

(II) 矩阵 $(A^{-1})^*$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C14-TB0B2-Q001_答案.png|答案]]

## V4 Pro Max 解析

**考点**：由实对称矩阵正交性定参数，利用伴随矩阵特征值公式 $A^*=|A|A^{-1}$ 求 $(A^{-1})^*$。

**解**

(I) $A$ 实对称 $\Rightarrow$ 不同特征值的特征向量正交：

$$0=\alpha_1^T\alpha_2=(1,k+1,2)\cdot(k-1,-k,1)=(k-1)-(k+1)k+2=1-k^2\Rightarrow k=\pm1.$$

$A^*=|A|A^{-1}$，$|A|=1\cdot2\cdot(-1)=-2$，故 $A^*$ 的特征值为 $\frac{-2}{1}=-2,\ \frac{-2}{2}=-1,\ \frac{-2}{-1}=2$，且 $A^*$ 与 $A$ 有相同特征向量。$\beta=(2,-5k,2k+1)$ 是 $A$（或 $A^*$）的某特征向量：

- $k=1$：$\alpha_1=(1,2,2)$，$\alpha_2=(0,-1,1)$，$\beta=(2,-5,3)$。$\beta^T\alpha_1=2-10+6=-2\ne0$，$\beta^T\alpha_2=5+3=8\ne0$，$\beta$ 不垂直于 $\alpha_1,\alpha_2$，矛盾 ✗；
- $k=-1$：$\alpha_1=(1,0,2)$，$\alpha_2=(-2,1,1)$，$\beta=(2,5,-1)$。$\beta^T\alpha_1=2+0-2=0$ ✓，$\beta^T\alpha_2=-4+5-1=0$ ✓。

故 $k=-1$，$\beta$ 是 $A$ 的属于 $\lambda=-1$ 的特征向量，对应 $A^*$ 的特征值 $\lambda_0=\frac{-2}{-1}=2$。

(II) 由 (I) 知 $A$ 的特征向量 $\alpha_1=(1,0,2)^T$（$\lambda=1$）、$\alpha_2=(-2,1,1)^T$（$\lambda=2$）、$\beta=(2,5,-1)^T$（$\lambda=-1$）。记 $P=(\alpha_1,\alpha_2,\beta)$，则 $A=P\operatorname{diag}(1,2,-1)P^{-1}$，直接计算得

$$A=\begin{pmatrix}\frac75&-1&-\frac15\\-1&-\frac12&\frac12\\-\frac15&\frac12&\frac{11}{10}\end{pmatrix}.$$

（验证 $A\alpha_1=(1,0,2)^T$、$A\alpha_2=(-4,2,2)^T$、$A\beta=(-2,-5,1)^T$ ✓）

由 $(A^{-1})^*=|A^{-1}|(A^{-1})^{-1}=\frac1{|A|}A=-\frac12A$，得

$$(A^{-1})^*=-\frac12A=\begin{pmatrix}-\frac7{10}&\frac12&\frac1{10}\\\frac12&\frac14&-\frac14\\\frac1{10}&-\frac14&-\frac{11}{20}\end{pmatrix}.$$

**答案**：(I) $k=-1$，$\lambda_0=2$；
(II) $(A^{-1})^*=\begin{pmatrix}-\frac7{10}&\frac12&\frac1{10}\\\frac12&\frac14&-\frac14\\\frac1{10}&-\frac14&-\frac{11}{20}\end{pmatrix}$。

**易错点**：$k=\pm1$ 必须用"$\beta$ 与 $\alpha_1,\alpha_2$ 正交"（即 $\beta$ 属于 $\lambda=-1$ 的特征子空间）筛选；$A^*$ 对应特征值 $|A|/\lambda$，勿把 $\lambda_0$ 与 $A$ 的 $-1$ 混淆；$(A^{-1})^*=|A|^{-1}A=-\frac12A$。

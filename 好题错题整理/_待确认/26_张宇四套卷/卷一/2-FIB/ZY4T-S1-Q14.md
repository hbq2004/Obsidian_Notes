# 填空题 第 14 题

![[_Attachments/题目识别/ZY4T/ZY4T-S1-Q14_题目.png|题目]]

微分方程 $ (x - y - 1)dx + (x + 4y - 1)dy = 0 $ 的通解为 \_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_.

![[_Attachments/题目识别/ZY4T-答案/ZY4T-S1-Q14_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**

【答案】：$\boxed{\ln\left[(x-1)^2+4y^2\right]+\arctan\frac{2y}{x-1}=C}$，其中 $C$ 为任意常数。

**解题切入点**

本题是一阶微分方程中“两个一次式之比”的典型题。先求两直线的交点并平移，化成齐次型，再令 $u=Y/X$ 分离变量；类似算法竞赛中“坐标偏移 + 齐次变换”的处理技巧。

**推演**

令 $X=x-1,\ Y=y$，则 $dx=dX,\ dy=dY$。由
$$\begin{cases}x-y-1=0\\x+4y-1=0\end{cases}$$
得奇点 $x=1,\ y=0$，原方程化为
$$(X-Y)dX+(X+4Y)dY=0.$$

令 $u=\dfrac YX$，即 $Y=uX$，$dY=u\,dX+X\,du$，代入得
$$X(1+4u^2)dX+X^2(1+4u)du=0.$$
当 $X\ne 0$ 时分离变量：
$$\frac{dX}{X}+\frac{1+4u}{1+4u^2}du=0.$$

积分得
$$\ln|X|+\frac12\arctan(2u)+\frac12\ln(1+4u^2)=C.$$

回代 $u=\dfrac YX$，注意 $1+4u^2=\dfrac{X^2+4Y^2}{X^2}$：
$$\ln|X|+\frac12\arctan\frac{2Y}{X}+\frac12\ln\frac{X^2+4Y^2}{X^2}=C,$$
即
$$\frac12\ln(X^2+4Y^2)+\frac12\arctan\frac{2Y}{X}=C,$$
故
$$\ln(X^2+4Y^2)+\arctan\frac{2Y}{X}=C_1.$$

代回 $X=x-1,\ Y=y$，得
$$\ln\left[(x-1)^2+4y^2\right]+\arctan\frac{2y}{x-1}=C.$$

自检：令
$$F=\frac12\ln(X^2+4Y^2)+\frac12\arctan\frac{2Y}{X},$$
则
$$dF=\frac{(X-Y)dX+(X+4Y)dY}{X^2+4Y^2}.$$
所以 $dF=0$ 正是原方程，隐式通解正确。

**易错点**

1. 忘记先平移奇点，直接按齐次方程处理会出错。
2. 分离变量时不要丢掉 $X=0$ 的跨越；最终隐式解中的 $\arctan$ 按连续分支理解，通常填空题写上式即可。
3. 合并对数时注意 $\ln|X|$ 与 $-\ln|X|$ 抵消，不能多留 $\ln|X|$。

**命题规律**

考研常把“一阶微分方程”与“平移奇点”“齐次型”结合考查。复习时应熟练“一次式比一次式”方程的固定步骤：先求交点平移，再令 $u=Y/X$，最后写成隐式通解。

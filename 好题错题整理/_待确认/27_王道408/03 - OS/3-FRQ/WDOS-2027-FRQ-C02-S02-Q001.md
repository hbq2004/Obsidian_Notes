# FRQ 第 1 题

![[_Attachments/题目识别/WDOS-2027-FRQ/WDOS-2027-FRQ-C02-S02-Q001_题目.png|题目]]

1. 有一个 CPU 和两台外设 $D_1, D_2$，且在能够实现抢占式优先级调度算法的多道程序环境中，同时进入优先级由高到低的 $P_1, P_2, P_3$ 三个作业，每个作业的处理顺序和使用资源的时间如下：
$P_1: D_2 (30ms), CPU (10ms), D_1 (30ms), CPU (10ms)$
$P_2: D_1 (20ms), CPU (20ms), D_2 (40ms)$
$P_3: CPU (30ms), D_1 (20ms)$
假设忽略不计其他辅助操作的时间，每个作业的周转时间 $T_1, T_2, T_3$ 分别为多少？ CPU 和 $D_1$ 的利用率各是多少？

## DeepSeek V4 Flash Max 解析
**答案**：
所有作业同时到达，因此周转时间等于完成时间。按题意 $P_1$ 优先级最高，$P_2$ 次之，$P_3$ 最低。模拟后得到：

$$T_1=80\text{ ms},\quad T_2=90\text{ ms},\quad T_3=90\text{ ms}$$

总历时为 $90\text{ ms}$。CPU 忙 $70\text{ ms}$，$D_1$ 忙 $70\text{ ms}$，所以：

$$\eta_{CPU}=\frac{70}{90}=\frac{7}{9}\approx77.8\%,\quad \eta_{D_1}=\frac{70}{90}=\frac{7}{9}\approx77.8\%$$

**解题切入点**：
把每个作业看成一个状态机：当前占用哪个资源，资源完成后再转移到下一阶段。CPU 采用抢占式优先级调度，所以一旦更高优先级进程就绪，就立即抢占 CPU；本题中优先级关系为 $P_1>P_2>P_3$。

同时，CPU、$D_1$、$D_2$ 是三个可并行推进的资源，不能把三个作业串成一条 CPU 执行序列。模拟时维护三条“资源时间线”，每次处理最早完成的资源事件，类似算法竞赛里的事件驱动扫描。

**推演**：

| 时间区间 | CPU | $D_1$ | $D_2$ |
|---|---|---|---|
| $0\sim20$ | $P_3$ | $P_2$ | $P_1$ |
| $20\sim30$ | $P_2$ | — | $P_1$ |
| $30\sim40$ | $P_1$ | — | — |
| $40\sim50$ | $P_2$ | $P_1$ | — |
| $50\sim60$ | $P_3$ | $P_1$ | $P_2$ |
| $60\sim70$ | — | $P_1$ | $P_2$ |
| $70\sim80$ | $P_1$ | $P_3$ | $P_2$ |
| $80\sim90$ | — | $P_3$ | $P_2$ |

关键抢占点：

- $t=20$ 时，$P_2$ 的 $D_1$ 完成，$P_2$ 申请 CPU，优先级高于 $P_3$，因此抢占 CPU。
- $t=30$ 时，$P_1$ 的 $D_2$ 完成，$P_1$ 申请 CPU，优先级高于 $P_2$，因此抢占 CPU。

$t=60$ 时，$P_3$ 申请 $D_1$，但 $D_1$ 被 $P_1$ 占用到 $t=70$，所以 $P_3$ 阻塞，CPU 空闲。

CPU 忙时段：

$$[0,20)\cup[20,30)\cup[30,40)\cup[40,50)\cup[50,60)\cup[70,80)$$

总计：

$$20+10+10+10+10+10=70$$

$D_1$ 忙时段：

$$[0,20)\cup[40,70)\cup[70,90)$$

总计：

$$20+30+20=70$$

因此：

$$T_1=80,\quad T_2=90,\quad T_3=90$$

$$\eta_{CPU}=\frac{70}{90}=\frac79,\quad \eta_{D_1}=\frac{70}{90}=\frac79$$

**易错点**：
- 不要把三个作业从头到尾串行执行，多道程序下外设和 CPU 是并行的。
- 不要漏掉两个抢占点：$t=20$ 时 $P_2$ 抢占 $P_3$，$t=30$ 时 $P_1$ 抢占 $P_2$。
- $t=60\sim70$ 时 CPU 是空闲的，因为 $P_3$ 在等 $D_1$，$P_1$ 和 $P_2$ 都在 I/O，CPU 没有就绪进程。
- 利用率分母应用总历时 $90\text{ ms}$，不能用 $P_1$ 的完成时间 $80\text{ ms}$。

**命题规律**：
这是典型的“抢占式优先级调度 + 多道资源并行”模拟题，408 常把优先调度、周转时间、资源利用率结合考查。解法本质是维护每条资源的占用区间，相当于算法竞赛中的事件驱动模拟题：每次处理最早完成事件，再按优先级重新分配 CPU。遇到此类题，先画 CPU、$D_1$、$D_2$ 三条时间线，抢占只发生在 CPU 上，外设区间按实际完成时间推进即可。

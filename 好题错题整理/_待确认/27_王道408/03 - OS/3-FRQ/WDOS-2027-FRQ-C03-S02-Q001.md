# FRQ 第 1 题

![[_Attachments/题目识别/WDOS-2027-FRQ/WDOS-2027-FRQ-C03-S02-Q001_题目.png|题目]]

1. 假定某操作系统存储器采用页式存储管理，一个进程在相联存储器中的页表项见表 $A$，不在相联存储器的页表项见表 $B$.
表 $A$ 相联存储器中的页表
| $页号$ | $页帧号$ |
| :-- | :-- |
| $0$ | $f1$ |
| $1$ | $f2$ |
| $2$ | $f3$ |
| $3$ | $f4$ |
表 $B$ 内存中的页表
| $页号$ | $页帧号$ |
| :-- | :-- |
| $4$ | $f5$ |
| $5$ | $f6$ |
| $6$ | $f7$ |
| $7$ | $f8$ |
| $8$ | $f9$ |
| $9$ | $f10$ |
注：只列出不在相联存储器中的页表项.

假定该进程长度为 $320B$，每页 $32B$。现有逻辑地址（八进制）为 $101,204,576$，若上述逻辑地址能转换成物理地址，说明转换的过程，并指出具体的物理地址；若不能转换，说明其原因.

## DeepSeek V4 Flash Max 解析
**答案**：

- $101_8$：可转换。$101_8=65_{10}$，页号 $p=2$，页内偏移 $d=1$；页号 $2$ 在快表（表 A）中命中，页帧号为 $f_3$，故物理地址为 $32f_3+1$（页帧 $f_3$，偏移 $1$）。
- $204_8$：可转换。$204_8=132_{10}$，页号 $p=4$，页内偏移 $d=4$；页号 $4$ 不在快表中，转查内存页表（表 B），页帧号为 $f_5$，故物理地址为 $32f_5+4$。
- $576_8$：不能转换。$576_8=382_{10}$，页号 $p=11$，页内偏移 $d=30$；进程只有 $320/32=10$ 页，合法页号为 $0\sim9$，$p=11$ 越界，页表中无对应页表项，不能完成地址转换。

**解题切入点**：

不要先把八进制数“直觉”当十进制；先转十进制或用二进制拆位。页大小 $32=2^5$，于是页内偏移占低 5 位；逻辑地址 $A$ 的页号与偏移为

$$
p=\left\lfloor\frac{A}{32}\right\rfloor,\qquad d=A\bmod 32
$$

接着按“快表（TLB）→ 内存页表”的顺序查映射。快表就是地址翻译的 cache，命中相当于 `map[p]` 的缓存命中；未命中再去查内存页表，查不到或越界则异常。从流程上看，它是一个状态机：快表命中 → 输出；未命中 → 查内存页表；越界/无效 → 异常，和搜索中先判边界再扩展状态一致。

**推演**：

1. 进程总页数 $N=320/32=10$，合法页号为 $0,1,\dots,9$；最大合法逻辑地址是 $320-1=319_{10}=477_8$。
2. 物理地址公式：$\mathrm{PA}=f\cdot 32+d$，其中 $f$ 是页帧号，$d$ 是页内偏移。
3. $101_8=65_{10}$，有 $p=2$，$d=1$。表 A 中页号 $2$ 对应 $f_3$，TLB 命中，所以 $\mathrm{PA}=32f_3+1$。
4. $204_8=132_{10}$，有 $p=4$，$d=4$。表 A 中没有页号 $4$，TLB 未命中；表 B 中页号 $4$ 对应 $f_5$，页表项有效，所以 $\mathrm{PA}=32f_5+4$。这不是缺页，只是 TLB miss。
5. $576_8=382_{10}$，有 $p=11$，$d=30$。$p=11>9$，等价于 $382_{10}\ge 320_{10}$，地址越界；页表没有页号 $11$ 的合法项，因此不能转换。

**易错点**：

- 把八进制数直接当十进制算。比如 $204_8$ 是 $132_{10}$，不是 $204_{10}$。
- 页偏移不是 3 位八进制位，而是 5 个二进制位；不要用“最高八进制位就是页号”来拆位。
- TLB miss 不等于缺页。$p=4$ 不在快表中，但在内存页表中有效，所以仍可转换；只有页表项无效或页号越界才会异常。
- 合法页数 $10$ 的页号是 $0\sim9$，不是 $1\sim10$，也不允许 $p=10$。$576_8$ 的页号是 $11$，明显越界。
- 物理地址是“帧号 × 页大小 + 偏移”，等价于二进制中把帧号放在高位移位、偏移放在低 5 位；不能简单把 $f_i$ 和 $d$ 相加。

**命题规律**：

408 中这类题属于“送分题”，但常设三个坎：进制转换、TLB 命中/未命中、越界判断。核心能力就是把逻辑地址看成 `(page, offset)` 的二元组，TLB 看成小容量 cache，内存页表看成完整映射表；这和竞赛中“用位运算拆状态、用哈希表缓存结果、访问前先判边界”完全一致。熟练后先求页数和最大合法地址，再查表，基本不会错。

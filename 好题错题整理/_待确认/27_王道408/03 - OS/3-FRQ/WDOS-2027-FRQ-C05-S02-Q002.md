# FRQ 第 2 题

![[_Attachments/题目识别/WDOS-2027-FRQ/WDOS-2027-FRQ-C05-S02-Q002_题目.png|题目]]

在某系统中,若采用双缓冲区(每个缓冲区可存放一个数据块),将一个数据块从磁盘传送到缓冲区的时间为 $80 \mu s$,从缓冲区传送到用户的时间为 $20 \mu s$,CPU 计算一块数据的时间为 $50 \mu s$.总共处理 4 个数据块,每个数据块的平均处理时间是多少?

## DeepSeek V4 Flash Max 解析
**答案**：$97.5\ \mu s$

**解题切入点**：这道题的核心是双缓冲区的并行流水线模型。可以将每个数据块的处理过程抽象为两个阶段：输入阶段（从磁盘到缓冲区，时间 $T_1=80\ \mu s$）和处理阶段（从缓冲区到用户及 CPU 计算，时间 $T_2+T_3=20+50=70\ \mu s$）。双缓冲区使得相邻数据块的输入阶段和处理阶段可以重叠，如同算法竞赛中利用双线程实现的任务流水线。关键是找出瓶颈阶段，利用总时间公式 $T_{\text{总}} = n \cdot \max(T_1,\ T_2+T_3) + \min(T_1,\ T_2+T_3)$，然后求平均。

**推演**：对于 $n=4$ 个数据块，首先确定输入时间 $T_{\text{in}}=80\ \mu s$，输出+计算时间 $T_{\text{out+cpu}}=20+50=70\ \mu s$。由于 $T_{\text{in}} > T_{\text{out+cpu}}$，输入是瓶颈。在双缓冲区下，第一个数据块必须顺序经过输入、输出、计算，总时间 $T_1 = 80+20+50=150\ \mu s$。之后，每一个新数据块可以在前一个数据块输入完成后立即开始输入，而前一个数据块的输出+计算可能已经完成或尚未完成。由于 $T_{\text{in}} > T_{\text{out+cpu}}$，前一个数据块的输出+计算总会先于下一个数据块的输入完成，所以每个后续数据块只需等待其输入完成即可立即开始输出+计算，因此每个后续数据块从开始输入到完成的时间正好等于输入时间 $80\ \mu s$（因为输入过程中前一个数据块已处理完，无需额外等待）。故总时间 $T_{\text{总}} = 150 + (4-1)\times 80 = 390\ \mu s$，平均时间 $= \dfrac{390}{4} = 97.5\ \mu s$。更一般地，总时间公式为 $n\cdot\max(T_{\text{in}}, T_{\text{out+cpu}}) + \min(T_{\text{in}}, T_{\text{out+cpu}})$，代入得 $4\times 80 + 70 = 390\ \mu s$，平均 $97.5\ \mu s$。

**易错点**：1. 忽略输出阶段，错误地将处理阶段只考虑 CPU 计算，导致 $T_{\text{out+cpu}}=50\ \mu s$，从而误判瓶颈。2. 认为双缓冲区可以完全并行，直接计算总时间为 $n\cdot\max(T_{\text{in}}, T_{\text{out+cpu}})$，忘记加上第一块的额外阶段或最后一块的收尾。3. 混淆单缓冲区与双缓冲区的区别，在单缓冲区中输出阶段可能与输入冲突，公式不同。4. 错误地将三个阶段都视为可完全重叠，得出总时间 $n\cdot\max(T_{\text{in}}, T_{\text{out}}, T_{\text{cpu}})$ 等。

**命题规律**：本题是操作系统设备管理中的经典题型，常考察 I/O 操作与 CPU 计算的并行性，通过缓冲区数量的变化（单缓冲区、双缓冲区、多缓冲区）来设计流水线，计算处理一批数据的总时间或平均时间。解题关键是识别出每个数据块必须顺序经历的阶段，并利用流水线思想找出瓶颈阶段。此类题目在 408 中反复出现，考生需熟练掌握单双缓冲区的公式推导，如同掌握算法竞赛中的关键路径和状态转移。

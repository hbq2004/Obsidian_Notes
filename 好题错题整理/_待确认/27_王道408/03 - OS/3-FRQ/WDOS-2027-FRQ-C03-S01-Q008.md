# FRQ 第 8 题

![[_Attachments/题目识别/WDOS-2027-FRQ/WDOS-2027-FRQ-C03-S01-Q008_题目.png|题目]]

8. 在某页式系统中,假设在查找主存页表的过程中不发生缺页的情况,请回答:
(1) 若对主存的一次存取需 $1.5\mu s$，问实现一次页面访问时存取时间是多少?
(2) 若系统有快表且其平均命中率为 $85\%$，而页表项在快表中的查找时间可忽略不计，试问此时的存取时间为多少?

## DeepSeek V4 Flash Max 解析
**答案**：

(1) 无快表时，一次页面访问需要访问主存两次：一次查页表，一次取数据，所以

$$T_1=2\times 1.5\,\mu s=3\,\mu s.$$

(2) 有快表时，命中率 $h=0.85$ ，快表查找时间忽略，则

$$T_2=0.85\times 1.5+0.15\times (1.5+1.5)
=1.275+0.45=1.725\,\mu s.$$

因此两次结果分别为 $3\,\mu s$ 和 $1.725\,\mu s$ 。

**解题切入点**：

“一次页面访问”不能等同于“一次主存访问”。在页式系统中，逻辑地址要先经过页表完成地址变换，再访问真正的物理地址。本题相当于一个两分支状态：TLB 命中是一条快速路径，TLB 未命中是一条慢速路径；有效存取时间就是按概率加权的期望时间。这和在竞赛里做期望 DP 类似：先枚举所有路径，再对每条路径“概率 $\times$ 代价”求和。快表本质上是页表项的 memoization，命中就省掉一次主存查页表。

**推演**：

设一次主存访问时间为 $t=1.5\,\mu s$ 。

无快表时，一次页面访问必然经过：

$$t_{\text{查页表}}+t_{\text{取数据}}=t+t=2t=3\,\mu s.$$

有快表时，设命中率为 $h=0.85$ 。若命中，只需访问一次主存取数据，代价为 $t$ ；若未命中，仍需先到主存查页表，再取数据，代价为 $2t$ 。于是：

$$EAT=h\cdot t+(1-h)\cdot 2t
=(2-h)t
=(2-0.85)\times 1.5
=1.725\,\mu s.$$

也可以理解为：无快表时基线是 $3\,\mu s$ ，每次命中省掉一次主存访问 $1.5\,\mu s$ ，所以

$$3-0.85\times 1.5=1.725\,\mu s.$$

边界检查：若 $h=1$ ，则 $EAT=1.5\,\mu s$ ；若 $h=0$ ，则 $EAT=3\,\mu s$ ，符合直觉。

**易错点**：

- 容易漏算页表访问：无快表时按一次主存访问计算，会错误得到 $1.5\,\mu s$ 。
- TLB 未命中不等于缺页：题目已经明确不发生缺页，不能再加入磁盘 I/O 时间。
- 注意 $85\%$ 是命中率，未命中率是 $15\%$ ，不要用反。
- 快表查找时间已经说明可忽略，不需要额外加 $\lambda$ ；若题目给出快表查找时间，才需要加上。
- 不要机械套公式，要先明确每条路径的访存次数：命中路径 $1$ 次，未命中路径 $2$ 次。

**命题规律**：

408 常考“有效存取时间 EAT”的计算，常与 TLB 命中率、缺页率、Cache 命中率组合出题。核心方法是列出命中/未命中两条路径的代价，再按概率加权求和，类似竞赛中的期望计算。本题是基础版本，后续可能变形为：加入快表查找时间、加入缺页处理时间、多级页表、Cache 与 TLB 同时考虑等。无论怎么变，核心都是先写路径代价，再做加权和。

# FRQ 第 18 题

![[_Attachments/题目识别/WDOS-2027-FRQ/WDOS-2027-FRQ-C02-S03-Q018_题目.png|题目]]

18.【2011 统考真题】某银行提供 1 个服务窗口和 10 个供顾客等待的座位。顾客到达银行时,若有空座位,则到取号机上领取一个号,等待叫号。取号机每次仅允许一位顾客使用。当营业员空闲时,通过叫号选取一位顾客,并为其服务。顾客和营业员的活动过程描述如下:

coBegin
{
    process 顾客 i
    {
        从取号机获取一个号码;
        等待叫号;
        获取服务;
    }
    process 营业员
    {
        While (TRUE)
        {
            叫号;
            为客户服务;
        }
    }
} coEnd

请添加必要的信号量和 $P,V$(或 $wait()$,$signal()$) 操作,实现上述过程中的互斥与同步。要求写出完整的过程,说明信号量的含义并赋初值.

## DeepSeek V4 Flash Max 解析
**答案**：
定义信号量：
$$\begin{aligned}
&empty = 10 \quad \text{// 空座位数}\\
&mutex = 1 \quad \text{// 取号机互斥}\\
&full = 0 \quad \text{// 等待叫号的顾客数}\\
&service = 0 \quad \text{// 叫号信号量}
\end{aligned}$$

顾客 $i$ 进程：
$$\begin{aligned}
&\text{P(empty);} \\
&\text{P(mutex);} \\
&\text{从取号机获取一个号码;} \\
&\text{V(mutex);} \\
&\text{V(full);} \\
&\text{P(service);} \\
&\text{V(empty);} \\
&\text{获取服务;}
\end{aligned}$$

营业员进程：
$$\begin{aligned}
&\text{while (TRUE) \{} \\
&\qquad \text{P(full);} \\
&\qquad \text{V(service);} \\
&\qquad \text{为客户服务;} \\
&\text{\}}
\end{aligned}$$

**解题切入点**：
本题是典型的“有界缓冲区”同步互斥问题，可将 $10$ 个座位看作容量为 $10$ 的缓冲区，顾客是生产者（生产“等待顾客”这一资源），营业员是消费者（消费“等待顾客”）同时也是生产者（生产“叫号”资源），顾客又是“叫号”资源的消费者。类似于算法竞赛中构造辅助函数简化问题，这里通过信号量将复杂的并发访问抽象为对资源的申请与释放。取号机是临界资源，对应竞赛中的互斥锁（锁变量）。整个流程可看作一个状态机：顾客状态由“等待座位”“取号”“等待叫号”“服务”等转移，营业员状态由“等待顾客”“叫号”“服务”转移，通过信号量进行状态同步。

**推演**：
1. 首先，顾客必须获取空座位才能进入，因此用 $empty$ 信号量表示空座位数，初值 $10$，顾客 $P(empty)$ 申请座位，服务开始前释放座位。
2. 取号机每次只允许一位顾客使用，故设互斥信号量 $mutex=1$，在取号前后施以 $P,V$ 操作。
3. 顾客取号后已有一个等待叫号的顾客，需通知营业员，故用 $full$ 信号量表示等待顾客数，顾客 $V(full)$ 增加计数，营业员 $P(full)$ 等待顾客。
4. 顾客取号后需等待叫号，营业员叫号唤醒顾客，故用 $service$ 信号量实现这一同步：顾客 $P(service)$ 阻塞，营业员 $V(service)$ 叫号。
5. 顾客被叫到后应离开座位去窗口，故在 $P(service)$ 后立即 $V(empty)$ 释放座位，随后开始服务。服务完成后顾客离开，无需额外同步。
6. 注意 $P(empty)$ 必须位于 $P(mutex)$ 之前，否则若座位满，顾客持有 $mutex$ 阻塞于 $P(empty)$，将导致其他顾客无法取号，且座位释放只能由顾客完成，形成死锁。

**易错点**：
- $P(empty)$ 与 $P(mutex)$ 的顺序：若颠倒，可能因座位满导致死锁。
- $V(empty)$ 的位置：应在 $P(service)$ 之后、服务之前，表示顾客离开座位，若放在服务之后则服务期间座位仍被占用，不符合实际。
- 信号量初值：$full$ 与 $service$ 初值均为 $0$，表示初始无顾客等待、无叫号信号。
- 营业员 $P(full)$ 与 $V(service)$ 顺序：必须先等待顾客，再叫号，否则若先叫号则无顾客可叫。
- 顾客“获取服务”后无需额外操作，若误加 $V(empty)$ 会导致重复释放座位。

**命题规律**：
$408$ 操作系统 $PV$ 操作题常以现实场景为背景，考查同步互斥模型的能力。本题是“生产者-消费者”的变式，涉及多个信号量组合，要求考生识别出资源（座位、取号机、等待顾客、叫号）并建立正确的同步关系。类似题型还有“读者-写者”、“哲学家进餐”等，但核心都是分析进程间的互斥与同步关系，用信号量模拟资源分配，类似于算法竞赛中图论匹配问题（资源分配）或状态机（进程状态转移）。备考时需熟练掌握典型模型，并能灵活迁移。

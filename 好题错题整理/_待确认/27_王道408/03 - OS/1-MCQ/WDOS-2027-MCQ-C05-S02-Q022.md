# MCQ 第 22 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C05-S02-Q022_题目.png|题目]]

22. 采用 SPOOLing 技术的计算机系统，外围计算机需要 ( ) .
(A) 一台
(B) 多台
(C) 至少一台
(D) 0 台

## DeepSeek V4 Flash Max 解析
**答案**：  
$ ext{D}$（$0$ 台）

**解题切入点**：  
SPOOLing 技术本质是通过**磁盘缓冲区**和**进程模拟**将独占设备虚拟化为共享设备，所有控制逻辑均在**主计算机**的 OS 内核中完成，不依赖额外硬件。题目考察对 SPOOLing 系统组成（输入井/输出井、输入/输出进程）的理解，核心是区分“外围计算机”与“外围设备”。

**推演**：  
- SPOOLing 系统由**输入井、输出井**（磁盘上的缓冲区域）、**输入进程、输出进程**（用户态或内核态软件）以及**预输入/缓输出程序**构成，全部运行在主计算机上。  
- 类比算法竞赛中的**构造题**：我们可以通过**软件模拟**（如用队列模拟磁盘调度）代替专用硬件，从而“零额外成本”实现多任务并行。  
- 不存在“外围计算机”这一硬件组件，故所需数量为 $0$。若误选“至少一台”则混淆了“设备”与“计算机”的概念。

**易错点**：  
- 易将“外围计算机”等同于“外围设备控制器”或“通道”，但 SPOOLing 纯属软件技术，不需额外 CPU。  
- 误以为 SPOOLing 需要专用硬件（如早期脱机 I/O 中的外围机），但现代 OS 通过**中断+缓冲区**即可实现，故答案为 $0$。

**命题规律**：  
- 常与“SPOOLing 系统组成”“独占到共享的转化”结合考查，选项常设“一台”“多台”等干扰项。  
- 解题关键：**SPOOLing 是软件方案**，不依赖硬件数量（类似算法中的**状态机**：用内存模拟硬件状态，而非增加物理状态机）。

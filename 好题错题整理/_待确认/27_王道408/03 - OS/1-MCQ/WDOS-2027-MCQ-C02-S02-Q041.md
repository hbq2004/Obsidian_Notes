# MCQ 第 41 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C02-S02-Q041_题目.png|题目]]

若某单处理器多进程系统中有多个就绪态进程，则下列关于处理机调度的叙述中，错误的是（ ）
(A) 在进程结束时能进行处理机调度
(B) 创建新进程后能进行处理机调度
(C) 在进程处于临界区时不能进行处理机调度
(D) 在系统调用完成并返回用户态时能进行处理机调度

## DeepSeek V4 Flash Max 解析
**答案**：
$C$。错误的是 “在进程处于临界区时不能进行处理机调度”。进程处于临界区只表示它在访问共享资源，不等于 CPU 被“锁死”；在单处理器中，时钟中断/外部中断到来后，调度器完全可能被调用。

**解题切入点**：
把处理机调度看作进程状态机上的“可选边”：每当当前运行进程可能不再占用 CPU 时，就产生一个调度点。可记
$$ \text{调度点} \subseteq \{ \text{运行}\to\text{终止},\ \text{运行}\to\text{等待},\ \text{运行}\to\text{就绪} \}. $$
题目等价于问哪个选项不是这种“边”的合法触发条件。竞赛中类似“当前搜索状态可以从哪些入口转移”；临界区只是一个同步边界，不是阻止状态机转移的硬墙。

**推演**：
- $A$：进程结束时，运行态自动消失，CPU 必须从就绪队列选择新的进程。合法。
- $B$：创建新进程后，新进程进入就绪队列；调度器可以决定是否抢占当前进程。合法。
- $C$：进程处于临界区时可以被时钟中断打断，中断返回前可调用调度程序；另一个进程即使不能同时进入同一临界区，也可以运行其他代码。因此 “不能调度” 错。
- $D$：系统调用完成并返回用户态时，是一个经典的“返回前检查”点；若当前进程需要被切换，调度器会在此运行。合法。

综上，错误的是 $C$。

**易错点**：
- 将“临界区”误认为“原子操作/关中断”。临界区只对共享资源的访问互斥，不禁止 CPU 调度。
- 将“能调度”理解成“一定调度”。题目问的是“能”，表示存在该调度时机即可，不要求每次必然发生。
- 忽略中断这个入口。只要进程在运行时时钟中断到来，调度器就可能被激活；调度器能否运行，和临界区的互斥性是两回事。
- 单处理器也一样可能被抢占；多个就绪进程时，时间片到、优先级抢占等都会触发调度。

**命题规律**：
408 常把“处理机调度的时机”和“进程状态转换”放一起考，选项往往给出几个进程生命周期事件，再混入一个同步概念（临界区、互斥、原子操作）作为干扰。考生应形成“状态机 + 调度时机”的框架：先画进程三态/五态图，再把每个可能引起状态转移的事件标出来。本质上和竞赛中“找出所有可从当前状态转移到目标状态的操作”一样，不能只背固定结论，要理解调度器是被动地由中断/异常/系统调用驱动的。

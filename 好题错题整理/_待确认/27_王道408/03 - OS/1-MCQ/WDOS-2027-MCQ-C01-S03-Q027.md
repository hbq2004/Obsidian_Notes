# MCQ 第 27 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C01-S03-Q027_题目.png|题目]]

下列与中断相关的操作中，由操作系统完成的是 ( ).
$I$. 保存被中断程序的中断点
$II$. 提供中断服务
$III$. 初始化中断向量表
$IV$. 保存中断屏蔽字
(A) 仅 $I$、$II$
(B) 仅 $I$、$II$、$IV$
(C) 仅 $III$、$IV$
(D) 仅 $II$、$III$、$IV$

## DeepSeek V4 Flash Max 解析
**答案**：
D（仅 $\mathrm{II}$、$\mathrm{III}$、$\mathrm{IV}$）。

**解题切入点**：
先把中断处理拆成“硬件自动完成”和“操作系统完成”两类。CPU 响应中断时，由中断隐指令完成的是：关中断、保存断点、引出中断服务程序；这三步不是 OS 代码，而是硬件的“自动机行为”。算法竞赛类比：$\mathrm{I}$ 就像评测系统在异常入口自动把返回地址压栈，不需要你写；而 $\mathrm{II,III,IV}$ 是你需要写的 $\text{handler}$、初始化跳转表、保存现场，属于系统代码的工作。

**推演**：
- $\mathrm{I}$：保存被中断程序的中断点，即保存断点 $PC$。这是硬件中断隐指令完成的，OS 尚未开始执行，所以不是 OS 完成。
- $\mathrm{II}$：提供中断服务由中断服务程序完成，中断服务程序是 OS 内核代码，所以是 OS 完成。
- $\mathrm{III}$：初始化中断向量表是建立“中断号 $\to$ 服务程序入口”的映射表；该表由 OS 在启动/初始化时设置，所以是 OS 完成。
- $\mathrm{IV}$：保存中断屏蔽字属于保护现场。OS 在处理中断、准备中断嵌套时保存旧屏蔽字，返回前再恢复，所以是 OS 完成。

因此只有 $\mathrm{II}$、$\mathrm{III}$、$\mathrm{IV}$ 正确，选 D。

**易错点**：
- 不要把 $\mathrm{I}$ 当 OS 操作：硬件会自动保存断点，看到“保存”不一定就是软件。
- 不要把 $\mathrm{IV}$ 当硬件操作：硬件只完成中断隐指令中的基本动作，完整的中断屏蔽字保存/恢复是 OS 在中断服务程序里做的现场保护。
- 区分“中断响应”和“中断服务”：响应主要由硬件完成，服务主要由 OS 完成。

**命题规律**：
408 常考硬件/软件职责边界，题眼是“中断隐指令三件事”：关中断、保存断点、引出中断服务程序。凡在这三件事之外且需要管理中断资源、建立映射、保护现场的操作，通常归 OS。算法竞赛里这类题相当于给操作建一个二分图，左侧操作、右侧执行者，把每个操作匹配到“硬件自动机”或“内核代码”一侧，匹配完即可选答案。

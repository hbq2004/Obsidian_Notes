# MCQ 第 31 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C02-S01-Q031_题目.png|题目]]

下列关于信号发送和处理的描述中,错误的是( )
(A) 一个进程可以给自己发送信号
(B) 操作系统的内核可以给进程发送信号
(C) 操作系统的内核
对每种信号都有默认处理程序
(D) 用户可以对每种信号自定义处理函数

## DeepSeek V4 Flash Max 解析
**答案**：
D

**解题切入点**：
把信号看成异步事件回调：发送者是“事件源”，进程用 handler 注册“回调”。A / B 是问事件源能否是自身 / 内核，C / D 是问有没有默认回调与能否覆盖回调。内核为每个信号都预置了默认回调；用户注册自定义回调时，系统保留两个不可覆盖的硬回调 $\text{SIGKILL}$ 和 $\text{SIGSTOP}$。所以看到“每种”就要警惕。

**推演**：
- A：一个进程可以给自己发信号。正确。例如进程调用 $\text{raise}(\text{SIGUSR1})$ 或 $\text{kill}(\text{getpid()}, \text{SIGUSR1})$，等价于算法竞赛中“自己触发自己的事件”。
- B：内核可以给进程发信号。正确。内核负责产生大量信号，如非法内存访问产生 $\text{SIGSEGV}$，除零产生 $\text{SIGFPE}$，Ctrl-C 产生 $\text{SIGINT}$。这些信号都是内核向目标进程发送的。
- C：内核对每种信号都有默认处理程序。正确。每个信号都有默认动作，例如终止、忽略、产生 core dump、暂停、继续；若进程没有注册自定义 handler，则按该默认动作处理。
- D：用户可以对每种信号自定义处理函数。错误。虽然用户可用 $\text{signal()}$ 或 $\text{sigaction()}$ 为大多数信号安装自定义 handler，但 $\text{SIGKILL}$ 的默认动作是强制终止，$\text{SIGSTOP}$ 的默认动作是暂停进程。它们不能被捕获、不能被忽略、不能被阻塞，因此不存在“每种”信号都可自定义处理函数。

$$
\forall sig \in S,\ \exists \text{ default action};\quad
sig \in \{\text{SIGKILL}, \text{SIGSTOP}\} \Rightarrow \text{用户 handler 不可安装}
$$

**易错点**：
- 把 C 错判为错误：默认“处理程序”不等于用户自定义 handler。$\text{SIGKILL}$ 虽然不可捕获，但它的默认处理是“强制终止”，是内核预置动作，所以“每种信号都有默认处理程序”成立。
- 把 D 错判为正确：容易只记“用户可以为信号设置处理函数”，忘记 $\text{SIGKILL}$ 和 $\text{SIGSTOP}$ 两个特例。
- 忽视绝对化表述：“每种 / 所有”在操作系统信号题中几乎总能推出反例；反例就是这两个不可捕获信号。

**命题规律**：
- 408 喜欢以“下列说法错误的是”考查信号发送者、默认处理、捕获条件。核心结论：除 $\text{SIGKILL}$ 和 $\text{SIGSTOP}$ 外，大多数信号可被捕获或忽略；任何信号都有默认处理动作。
- 可联想到“系统全局事件表 + 回调注册”：默认回调由内核维护，用户可覆盖多数回调，但系统保护了两个关键回调不可覆盖。答题时先找绝对化选项，再用特例验证。

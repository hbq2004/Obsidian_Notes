# MCQ 第 22 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C04-S02-Q022_题目.png|题目]]

下列有关文件组织管理的描述中,错误的是 ( ).
(A) 记录是对文件进行存取操作的单位,一个文件中各记录的长度可以不等
(B) 采用链接分配的文件,它的物理块必须连续排列
(C) 创建一个文件时,可以分配连续的区域,也可以分配不连续的物理块
(D) Hash 结构文件的优点是能够实现物理块的动态分配和回收

## DeepSeek V4 Flash Max 解析
**答案**：
$\boxed{B}$ 。采用链接分配时，文件按逻辑顺序把离散的物理块用指针串成链，物理块号无须连续；“必须连续排列”恰恰是连续分配的特征。

**解题切入点**：
把文件物理分配方式映射为竞赛里常见的“底层数据结构选型”：

- 连续分配 $\approx$ 静态数组：$p = p_0 + k$ ；
- 链接分配 $\approx$ 单链表：$p_{i+1} = \mathrm{next}[p_i]$ ；
- 索引分配 $\approx$ 索引数组/页表：$p_k = \mathrm{index}[k]$ ；
- Hash 文件 $\approx$ 哈希表：$p = H(\mathrm{key})$ 。

看到 B 说“链接分配的物理块必须连续”，相当于说“链表的结点必须连续存放在数组里”，这立刻与链式结构矛盾。判错题可先找绝对化表述，再构造反例。

**推演**：
1. A 正确。文件按逻辑结构可分为定长记录文件与变长记录文件；记录是记录式文件的存取单位，变长记录文件中各记录长度可以不同。
2. B 错误。合法反例：某文件逻辑块 $0,1,2$ 分别存放在物理块 $4,17,9$ ，用指针 $4\to17\to9$ 串联。物理块号完全离散，但仍是合法的链接分配文件。
3. C 正确。创建文件时可以根据采用的分配策略不同，申请连续区域（连续分配）或申请非连续物理块（链接分配、索引分配）。当然，“可以”指不同分配方式可选，不是同一时刻要求两者同时成立。
4. D 正确。Hash 文件通过散列映射进行定位，插入记录时可按需申请物理块，删除记录时可回收物理块；这正是 Hash 结构在物理块管理上的优点。它的主要缺点是可能产生散列冲突，且不易顺序访问。

**易错点**：
- 不要把连续分配的特点（物理块连续）移植到链接分配上；链接分配本质上就是单链表式的离散存储。
- 不要因为 B 过于直白而怀疑 D。D 描述的是教材中 Hash 文件的特点，应结合“散列文件支持动态增删”来理解。
- 注意 A 的“可以不等”是合法情况，不是说所有记录式文件都必须变长；定长记录文件也允许存在。
- C 的“连续/不连续”是分配方式层面的二选一，不是同一文件在物理上既连续又不连续。

**命题规律**：
408 文件管理部分常考“连续/链接/索引/Hash”四种物理组织方式的对比，尤其喜欢在“是否连续、能否随机访问、是否便于动态增长、能否动态回收”这些特征上设置干扰项。复习时可用竞赛数据结构类比记忆：连续分配=数组，链接分配=链表，索引分配=页表/索引表，Hash 文件=哈希表。遇到“必须”“只能”等绝对化表述，先回到定义验证，往往就是题眼。

# MCQ 第 53 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C04-S02-Q053_题目.png|题目]]

设文件索引结点中有 7 个地址项，其中 4 个地址项是直接地址索引，2 个地址项是一级间接地址索引，1 个地址项是二级间接地址索引，每个地址项大小为 $4B$，若磁盘索引块和磁盘数据块大小均为 $256B$，则可表示的单个文件最大长度是（ ）.
(A) $33KB$
(B) $519KB$
(C) $1057KB$
(D) $16516KB$

## DeepSeek V4 Flash Max 解析
**答案**：$\boxed{C}$（$1057\text{KB}$）

**解题切入点**：根据索引结点中直接地址项、一级间接地址项、二级间接地址项的数量，结合磁盘块大小和地址项大小，计算出各级索引可寻址的数据块数目，再乘以数据块大小，求和得到最大文件长度。

**推演**：设磁盘块大小 $B=256\text{B}$，地址项大小 $s=4\text{B}$，则每个磁盘索引块可容纳地址项数 $n = \frac{B}{s} = 64$。  
- 直接地址索引 $4$ 个，对应 $4$ 个数据块，大小 $4 \times B = 4 \times 256 = 1024\text{B} = 1\text{KB}$。  
- 一级间接地址索引 $2$ 个，每个一级间接块指向 $n$ 个数据块，故每个一级间接项可寻址 $n \times B = 64 \times 256 = 16384\text{B} = 16\text{KB}$，两个共 $2 \times 16 = 32\text{KB}$。  
- 二级间接地址索引 $1$ 个，二级间接块指向 $n$ 个一级间接块，每个一级间接块又指向 $n$ 个数据块，故可寻址数据块数 $n \times n = 64 \times 64 = 4096$，大小 $4096 \times 256 = 1048576\text{B} = 1024\text{KB}$。  
因此总长度 $= 1\text{KB} + 32\text{KB} + 1024\text{KB} = 1057\text{KB}$。

**易错点**：① 混淆单位，忘记将字节转换为 $\text{KB}$（除 $1024$）；② 忽略索引块本身不占用文件长度，只计算数据块；③ 计算二级间接时误用 $n^3$ 或遗漏层级；④ 误将直接地址项数当作直接块指针数，但本题已明确。

**命题规律**：$408$ 操作系统常考索引结构计算，关键在于理解多级间接寻址的块数递推关系。通常给出索引结点中各类地址项数量、磁盘块大小和指针大小，求解最大文件长度。此类问题可类比算法竞赛中的“多级指针”或“数组指针”构造，通过逐层展开计算指针可访问的数据块总数。

# MCQ 第 1 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C01-S02-Q001_题目.png|题目]]

1. 提高单机资源利用率的关键技术是（ ）

(A) 脱机技术
(B) 虚拟技术
(C) 交换技术
(D) 多道程序设计技术

## DeepSeek V4 Flash Max 解析
**答案**：
D. 多道程序设计技术

**解题切入点**：
本题考察提高单机资源利用率的关键技术。单机资源利用率主要指 CPU 和 I/O 设备的利用率。在单道程序系统中，CPU 和 I/O 设备串行工作，导致资源大量空闲。多道程序设计技术通过在内存中同时存放多个程序，使得 CPU 和 I/O 设备能够并行工作，从而显著提升资源利用率。其他选项：脱机技术主要用于 I/O 管理，虚拟技术用于资源抽象和共享，交换技术用于内存管理，它们都不是最核心的关键技术。

**推演**：
1. 资源利用率问题：在单道程序系统中，CPU 利用率 = $1 - p$，其中 $p$ 为 I/O 等待时间占比。若 $p=0.8$，则 CPU 利用率仅 $20\%$。
2. 多道程序设计通过“并发”执行，当一道程序等待 I/O 时，CPU 立即切换至另一道程序，使得 CPU 和 I/O 设备始终忙碌。例如，设有 $n$ 道程序，每道程序 I/O 等待概率为 $p$，则 CPU 空闲概率降至 $p^n$，利用率大幅提升。
3. 脱机技术（如 SPOOLing）虽能缓解 I/O 瓶颈，但本质是 I/O 缓冲，并非多道并发；虚拟技术（如虚拟内存）主要解决地址空间和内存隔离问题；交换技术用于进程换入换出，解决内存容量不足。三者均非提高资源利用率的关键技术，多道程序设计才是操作系统实现资源高效利用的基石。
4. 类比算法竞赛：单道程序相当于顺序处理单道题，遇到 I/O 等待（如输入数据）时只能空闲等待；多道程序则像同时处理多道题，当一道题在等待输入时，立刻切换到另一道题计算，从而最大化 CPU（即你）的利用率。这类似于状态机中的状态切换，将 CPU 时间片分配给不同任务，实现资源的最优匹配。

**易错点**：
- 容易混淆“多道程序设计”与“分时系统”或“虚拟技术”。分时系统是时间片轮转，多道程序是并发执行的基础，分时是多道的一种实现方式。
- 误以为虚拟技术是提高资源利用率的关键，因为虚拟化可以共享资源。但多道程序设计是更早且更基础的技术，虚拟技术建立在多道之上。
- 忽略“单机”限定，脱机技术常用于多机或 I/O 脱机，但并非提高单机资源利用率的关键。

**命题规律**：
- 基本概念题，常出现在操作系统概述章节，考察对多道程序设计作用的理解。
- 常与单道程序对比，要求识别提高资源利用率的技术。
- 在选择题中，干扰项常包括脱机、虚拟、交换等，需明确各技术的核心功能。
- 类似题目可能深入考察多道程序与并发、并行之间的关系，以及其在操作系统发展历史中的地位。

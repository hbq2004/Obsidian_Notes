# MCQ 第 28 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C02-S02-Q028_题目.png|题目]]

使用抢占式最短剩余时间优先调度算法对下列进程进行调度，总周转时间是 ( ) .
| 进程名 | 到达时间 | 运行时间 |
| :---: | :---: | :---: |
| $P_1$ | $0$ | $3$ |
| $P_2$ | $1$ | $1$ |
| $P_3$ | $2$ | $4$ |
| $P_4$ | $3$ | $5$ |
| $P_5$ | $4$ | $2$ |
(A) $25h$
(B) $26h$
(C) $27h$
(D) $28h$

## DeepSeek V4 Flash Max 解析
**答案**：$27h$（对应选项 C）

**解题切入点**：本题是抢占式最短剩余时间优先调度算法的模拟，类似于算法竞赛中基于优先队列（最小堆）的贪心调度。每次调度时，选择剩余运行时间最少的进程执行，且当新进程到达时需要检查是否抢占当前运行进程。这类似于“事件驱动”的状态机，其中进程到达和完成是事件，每次事件后重新选择最短剩余时间的进程运行。

**推演**：建立时间轴模拟，记录每个时刻的进程状态。

设进程 $P_i$ 到达时间 $a_i$，运行时间 $t_i$，剩余时间 $r_i$ 初始为 $t_i$。

- 初始 $t=0$，$P_1$ 到达，$r_1=3$，运行 $P_1$。
- $t=1$：$P_2$ 到达，$r_2=1$。此时 $P_1$ 已运行 $1$，$r_1=2$。比较 $r_1=2$，$r_2=1$，$P_2$ 更短，抢占 $P_1$，切换运行 $P_2$。
- $t=2$：$P_2$ 完成（运行 $1$），同时 $P_3$ 到达。此时 $P_1$ 剩余 $2$，$P_3$ 剩余 $4$，选择 $P_1$ 运行。
- $t=3$：$P_4$ 到达，$r_4=5$。此时 $P_1$ 已从 $t=2$ 运行 $1$，$r_1=1$。比较 $r_1=1$，$r_3=4$，$r_4=5$，$P_1$ 最短，继续运行 $P_1$。
- $t=4$：$P_1$ 完成，同时 $P_5$ 到达。此时就绪队列：$P_3$（$r=4$）、$P_4$（$r=5$）、$P_5$（$r=2$）。选择最短剩余 $P_5$ 运行。
- $t=6$：$P_5$ 完成（运行 $2$）。就绪队列：$P_3$（$r=4$）、$P_4$（$r=5$）。选择 $P_3$ 运行。
- $t=10$：$P_3$ 完成（运行 $4$）。就绪队列：$P_4$（$r=5$）。运行 $P_4$。
- $t=15$：$P_4$ 完成。

各进程完成时间：
$C_1=4$，$C_2=2$，$C_3=10$，$C_4=15$，$C_5=6$。

周转时间 $T_i = C_i - a_i$：
$T_1=4-0=4$，$T_2=2-1=1$，$T_3=10-2=8$，$T_4=15-3=12$，$T_5=6-4=2$。

总周转时间 $\sum T_i = 4+1+8+12+2 = 27$（小时）。

故答案为 $27h$，对应选项 C。

**易错点**：
1. 抢占时机：新进程到达时，要比较当前正在运行进程的剩余时间与新进程所需时间，若新进程更短，则立即抢占。本题 $t=1$ 时 $P_2$ 抢占 $P_1$ 是典型例子。
2. 同时事件处理：当进程完成时刻与进程到达时刻重合时，通常先处理完成事件，再将新到达进程加入就绪队列，然后重新调度。本题 $t=2$ 和 $t=4$ 均如此，若不注意可能导致错误调度。
3. 剩余时间更新：模拟时需准确记录每个进程已运行时间，避免算错剩余时间。
4. 忽略后续到达：在运行过程中，不能只考虑当前就绪队列，还要考虑未来到达的进程可能抢占，但抢占式算法会在新到达时立即检查，所以只需按时间顺序处理事件即可。

**命题规律**：调度算法是操作系统进程管理常考知识点，尤其抢占式最短剩余时间优先（SRTF）是计算周转时间的典型题型。解题关键是建立清晰的时间轴，逐一事件模拟。类似题目还可能出现“非抢占式短作业优先”、“时间片轮转”、“优先级调度”等，需掌握各类算法的特点。在算法竞赛视角下，这类模拟类似于“事件驱动 + 优先队列”的经典问题，运用贪心思想每次选择最优任务执行，考察细心和逻辑严密性。

# MCQ 第 52 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C02-S03-Q052_题目.png|题目]]

下列关于管程的叙述中,错误的是 ().
(A) 管程只能用于实现进程的互斥
(B) 管程是由编程语言支持的进程同步机制
(C) 任何时候只能有一个进程在管程中执行
(D) 管程中定义的变量只能被管程内的过程访问

## DeepSeek V4 Flash Max 解析
**答案**：
$$\boxed{\text{A}}$$

**解题切入点**：
管程不是一把“只能做互斥的锁”，而是“互斥锁 + 条件变量 + 私有数据封装”的集合体。用算法竞赛类比，管程就像一个封装好的辅助类：共享变量是私有成员，入口过程是公有接口，条件变量是内部维护的等待队列。选项 A 把管程的能力缩小成“只能用于进程互斥”，相当于只看到了锁，没看到条件变量实现的同步能力；而 B、C、D 分别对应管程的语言机制、互斥性和封装性。

**推演**：
1. 管程的标准结构为
$$\text{Monitor}=\left(\text{共享变量},\ \text{入口过程},\ \text{条件变量},\ \text{初始化代码}\right)$$
其中入口过程提供互斥，条件变量提供同步。

2. 互斥性：任一时刻至多一个进程在管程中处于执行状态，即
$$|\text{Active}(t)|\le 1$$
因此 C 正确。多个进程可以等在条件变量队列上，但等待不等于“在管程中执行”。

3. 同步性：管程内进程可执行 $\mathrm{wait}(c)$ 释放管程并进入条件变量 $c$ 的等待队列；执行 $\mathrm{signal}(c)$ 唤醒等待者。这类似搜索算法中“当前状态不可继续展开时，先挂起，等其他状态推进后再恢复”。所以 A 说“只能用于互斥”是错误的。

4. 管程是编程语言提供的高级同步机制，进入管程时由语言运行时保证互斥，因此 B 正确。

5. 管程内定义的变量是私有的，外部只能通过管程内的过程访问，因此 D 正确。

故错误的是 A。

**易错点**：
- 容易把“管程能实现互斥”等价于“管程只能实现互斥”，忽略条件变量 $\mathrm{wait}/\mathrm{signal}$ 的同步功能。
- 对 C 的疑问：$\mathrm{wait}$ 之后进程还在管程中吗？准确地说，$\mathrm{wait}$ 会让进程释放管程并进入条件变量等待队列，此时它不处于“执行”状态；管程保证的是“执行中的进程”至多一个。
- 不要把管程条件变量和信号量混淆：信号量的 $V$ 会累积资源计数，而管程条件变量的 $\mathrm{signal}$ 在无等待者时是空操作，条件变量本身没有值，只有等待队列。
- 题目问“错误”的选项，不要因为 A 看起来像常见结论就直接放过。

**命题规律**：
408 对管程的考查以概念辨析为主，常与信号量对比，题干常见“下列关于管程的叙述中，正确的是/错误的是”。核心考点有三个：管程既能互斥也能同步、条件变量的语义、管程的封装性。应对策略是把管程看成“自动加锁 + 条件队列”的封装类：互斥由入口保证，同步由条件变量保证，数据由私有作用域保护。若考算法题，通常是生产者消费者问题，此时注意 $\mathrm{wait}$ 必须释放管程，$\mathrm{signal}$ 在无等待者时不产生累积效果。

# MCQ 第 7 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C01-S01-Q007_题目.png|题目]]

7.操作系统提供给编程人员的接口是（ ）
(A) 库函数
(B) 高级语言
(C) 系统调用
(D) 子程序

## DeepSeek V4 Flash Max 解析
**答案**：C（系统调用）

**解题切入点**：操作系统面向编程人员的接口是程序接口，即系统调用。这与面向用户的命令接口不同，系统调用是用户程序请求内核服务的唯一合法入口，类似于算法竞赛中通过特定底层 API 访问硬件资源，而高级语言和库函数只是封装后的上层工具。

**推演**：操作系统运行在核心态，用户程序运行在用户态，两者之间通过系统调用切换。编程人员通过软中断或专用指令陷入内核，执行对应服务例程，这一过程类似图论中必须经过唯一桥接点才能访问另一子图，而库函数（如 `printf`）只是对系统调用（如 `write`）的封装，本身不直接由操作系统提供。因此，操作系统直接暴露给编程人员的接口是系统调用，而非库函数、高级语言或子程序。

**易错点**：容易误选库函数，因为日常编程中大量使用库函数，但库函数属于用户态程序库，底层依赖系统调用，并非操作系统直接提供的接口。注意区分“接口”与“封装”，系统调用才是操作系统与用户程序之间的契约。

**命题规律**：常以选择题形式考查操作系统两类接口（命令接口与程序接口），强调系统调用是编程人员唯一可用的程序接口，有时结合系统调用与库函数的区别出题。加深对用户态/核心态切换的理解有助于快速选出正确答案。

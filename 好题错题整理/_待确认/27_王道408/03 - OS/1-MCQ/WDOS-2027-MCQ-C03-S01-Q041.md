# MCQ 第 41 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C03-S01-Q041_题目.png|题目]]

对主存储器的访问，( ).
(A) 以块(页)或段为单位
(B) 以字节或字为单位
(C) 随存储器的管理方案不同而异
(D) 以用户的逻辑记录为单位

## DeepSeek V4 Flash Max 解析
**答案**：B

**解题切入点**：  
题干问的是“访问主存储器”这个动作的粒度，而不是“进程地址空间 / 主存与外存之间的交换粒度”。在竞赛中类比：线段树把区间抽象成若干结点，但底层数组仍是按下标访问；页、段是 OS 在逻辑层建立的“抽象结构”，而 CPU 真正落到主存的读/写，按可寻址的字节或字进行。

**推演**：  
- 主存是随机访问存储器，硬件按地址访问可寻址单元。现代计算机大多按字节编址，指令可以按字节、半字、字等粒度读写，因此硬件访存的基本单位是字节或字。
- 页、页框、块是 OS 为实现虚拟存储 / 离散分配而引入的单位。例如缺页时从磁盘调入一页（如 $4\text{KB}$）到内存，那是“主存与外存”的交换单位，不是 CPU 每次访问主存的单位。
- 段是按逻辑模块划分的地址空间单位，属于存储管理 / 链接视角，不改变访存动作的粒度。
- 用户的逻辑记录是文件系统 / 数据库中的记录单位，离主存访问更远。
- 存储管理方案不同会改变地址映射：  
  $$ \text{逻辑地址} \xrightarrow{\text{页表/段表等}} \text{物理地址} $$  
  但地址变换完成后，CPU 对物理主存的访问仍是按字节 / 字进行的，所以 C 也不正确。

**易错点**：  
1. 把“以页为单位的缺页调入”当成“主存访问单位”。这相当于把图论里“一次匹配一个连通块”和“每次 DFS 访问一个顶点”混为一谈。  
2. 看到“随存储管理方案不同而异”就选 C。实际上，方案不同改变的是“如何管理 / 分配 / 映射”，不是“访存的最小动作”。  
3. 把“逻辑记录”与“记录为单位的 I/O”联系到主存访问；要注意这是用户 / 文件系统层的单位。  
4. 有些题会用“块（页）或段”描述“内存分配单位”或“地址空间分区单位”，但本题明确考查“访问”，需按层次区分。

**命题规律**：  
408 常通过容易混淆的概念考查“分层”意识：CPU / 主存层面用字节或字，OS / 外存交换层面用块 / 页，文件系统 / 用户层面用记录。今后遇到“以什么为单位”的选择题，先判断是硬件访存、地址映射、缺页中断，还是 I/O 读写。可以类比竞赛中“先看题目要你输出的是点坐标还是边编号，再决定用哪个数据结构”。

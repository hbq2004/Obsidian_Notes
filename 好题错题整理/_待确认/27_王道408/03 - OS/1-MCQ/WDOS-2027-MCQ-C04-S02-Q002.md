# MCQ 第 2 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C04-S02-Q002_题目.png|题目]]

2. 目录文件存放的信息是（ ）.
(A) 某一文件存放的数据信息
(B) 某一文件的文件目录
(C) 该目录中所有数据文件目录
(D) 该目录中所有子目录文件和数据文件的目录

## DeepSeek V4 Flash Max 解析
**答案**：
选 D。目录文件存放的是当前目录中所有直接子项的目录项，即“该目录中所有子目录文件和数据文件的目录”。它保存的是目录项（文件名、inode/FCB 等信息），不是文件的数据内容。

**解题切入点**：
把目录结构看成一棵有根树，目录文件就是“当前节点的邻接表”。算法竞赛中我们常用 `vector<int> adj[u]` 表示 $u$ 的直接儿子；目录文件就是 $\text{adj}[\mathcal{D}]$，其中 $\mathcal{D}$ 是某个目录节点。它只存 $\mathcal{D}$ 的直接子节点：既有普通数据文件，也有子目录文件。普通文件是叶子，子目录是内部节点；目录文件并不递归保存整棵子树的信息。

**推演**：
设目录 $\mathcal{D}$ 的直接子项集合为 $\mathrm{Ch}(\mathcal{D})$，则目录文件内容可表示为：

$$
\mathrm{EntrySet}(\mathcal{D}) = \{\mathrm{entry}(x) \mid x \in \mathrm{Ch}(\mathcal{D})\}
$$

- 选项 A 错：某一文件存放的数据信息属于普通文件内容，目录文件不管数据正文。
- 选项 B 错：某一文件的“文件目录”只是一个目录项/FCB，不能代表整个目录文件；目录文件是所有直接子项目录项的集合。
- 选项 C 错：只包含数据文件，遗漏了子目录文件；在树形目录中，子目录也是父目录的孩子。
- 选项 D 对：同时包含子目录文件和数据文件的目录项，正是目录文件的核心内容。

**易错点**：
1. 误把“目录文件”当成存放文件内容的地方，容易误选 A；本质是混淆“数据信息”和“元数据/目录项”。
2. 忽略了子目录文件也是文件，父目录中也要有它的目录项，容易误选 C。
3. 误以为目录文件存“所有后代文件”的信息。它只存直接子项，子目录内部的项由子目录自己的目录文件保存。这就像邻接表只存相邻节点，不存整棵子树。
4. 注意目录项和 inode 不是一回事：目录项负责“名字到 inode 的映射”，inode 负责文件的元数据；但无论哪种实现，目录文件管理的是“该目录有哪些直接子项”。

**命题规律**：
408 爱考“概念边界”题，尤其是文件系统元数据与数据分离、目录项与 inode 的关系、直接子项与后代节点的区别。这类题相当于算法竞赛里的“构造题 + 树上邻接表”：先画出目录树，再看题目问的是哪个节点的邻接表。后续还可能结合路径解析、硬链接、软链接出题，核心还是理解“目录项就是一条边，目录文件就是邻接表”。

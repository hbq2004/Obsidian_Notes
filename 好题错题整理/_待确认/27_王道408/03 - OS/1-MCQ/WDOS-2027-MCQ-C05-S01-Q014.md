# MCQ 第 14 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C05-S01-Q014_题目.png|题目]]

关于通道、设备控制器和设备之间的关系,以下叙述中正确的是（ ）
(A) 设备控制器和通道可以分别控制设备
(B) 对于同一组输入/输出命令，设备控制器、通道和设备可以并行工作
(C) 通道控制设备控制器、设备控制器控制设备工作
(D) 以上答案都不对

## DeepSeek V4 Flash Max 解析
**答案**：
C

**解题切入点**：
从 I/O 控制方式的三级层次结构入手，明确通道、设备控制器和设备之间的控制关系：通道 $\rightarrow$ 设备控制器 $\rightarrow$ 设备，形成类似算法竞赛中“总控函数”调用“模块函数”、模块函数调用“原子操作”的递进控制链。

**推演**：
- 选项 A：设备控制器和通道可以分别控制设备。实际上，通道只能通过设备控制器间接控制设备，设备控制器必须在通道指令下工作，二者不能独立控制设备，故 A 错误。这好比在算法中，主函数不能直接调用底层基本操作，必须通过中间层函数。
- 选项 B：对于同一组输入/输出命令，设备控制器、通道和设备可以并行工作。在通道程序执行时，通道发出命令后必须等待设备控制器完成当前命令才能发出下一条，因此通道与设备控制器对同一组命令是串行的；设备控制器与设备在操作阶段虽有重叠，但整体并非严格并行，故 B 错误。这类似于流水线中同一数据只能顺序经过各阶段，不能同时处于不同阶段。
- 选项 C：通道控制设备控制器、设备控制器控制设备工作，是标准的三级层次关系，正确。
- 选项 D：因 C 正确，故 D 错误。

因此选 C。

**易错点**：
容易混淆通道与设备控制器在控制链中的位置，误认为通道可直接控制设备，或设备控制器能自发启动设备。在算法竞赛中，这类似于忽略分层封装，试图跨层访问，导致模块耦合度增加，应时刻保持“通道 $\rightarrow$ 设备控制器 $\rightarrow$ 设备”的清晰层次。

**命题规律**：
本知识点常以选择题形式考查，要求准确区分 I/O 控制方式中各级模块的功能与关系。复习时应结合王道教材，重点掌握通道方式下的三级结构、并行工作特性（不同设备间并行）以及通道程序的执行过程。类似题目在 408 中多次出现，属于基础题，务必理解透彻。

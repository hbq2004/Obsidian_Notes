# MCQ 第 33 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C05-S02-Q033_题目.png|题目]]

下列选项中，（ ）不属于设备驱动程序的功能。
(A) 接收进程发来的 I/O 命令和参数,并检查其合法性
(B) 查询 I/O 设备的状态
(C) 发出 I/O 命令,启动 I/O 设备
(D) 对 I/O 设备传回的数据进行分析和缓冲

## DeepSeek V4 Flash Max 解析
**答案**：
D。对 I/O 设备传回的数据进行分析和缓冲，不属于设备驱动程序的功能。

**解题切入点**：
设备驱动程序可以看成 I/O 分层中“贴硬件”的翻译/状态机层。它不关心数据语义，只负责把上层的 I/O 请求翻译成设备控制器能识别的命令，并完成状态查询、启动设备和中断响应。类比算法竞赛：驱动是底层 `transition()` 函数，给定当前状态和事件，输出下一状态和动作；而不是主算法里做“数据怎么用、缓冲区怎么调度”的逻辑。

**推演**：
一次 I/O 路径可看成状态转移：

$$
\text{request} \to \text{driver: check} \to \text{device: start} \to \text{controller: IRQ} \to \text{driver: copy} \to \text{buffer}
$$

对应选项：

- A：驱动接收上层转来的 I/O 命令和参数，并检查其合法性，相当于对输入先做 `assert`。
- B：驱动启动设备前必须查询设备状态，等价于状态搜索前判断当前状态是否可扩展。
- C：驱动向设备控制器发出启动命令，这是驱动的核心动作。
- D：对设备传回的数据做“分析”和“缓冲”，属于数据语义处理和缓冲策略，由设备独立性软件或用户进程完成；驱动最多只做面向设备的数据搬运。

所以不属于的是 D。

**易错点**：
1. 看到 A 中“进程发来”就以为 A 是用户层功能。实际上 408 教材口径中，驱动要接收上层传来的 I/O 命令和参数，并检查其合法性。
2. 不要把“驱动搬运数据”和“数据缓冲/分析”混为一谈。驱动可以把数据从设备搬到内核缓冲区，但“缓冲策略”和“数据分析”不是驱动职责。
3. 题目问“不属于”，相当于竞赛中的找反例。要按 I/O 分层职责排除，不能凭“像不像底层代码”去猜。

**命题规律**：
408 常把用户层 I/O、设备独立性软件、设备驱动程序、中断处理程序的功能混在一起考归属。设备分配和缓冲管理类似图论匹配/队列调度，属于设备独立性软件；驱动负责命令翻译、状态查询、启动设备，类似状态机转移函数。复习时背熟“层次职责表”，这类题就是送分题。

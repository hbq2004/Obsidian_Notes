# MCQ 第 2 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C02-S03-Q002_题目.png|题目]]

不需要信号量就能实现的功能是 ( ) .
(A) 进程同步
(B) 进程互斥
(C) 执行的前驱关系
(D) 进程的并发执行

## DeepSeek V4 Flash Max 解析
**答案**：
D（进程的并发执行）。信号量解决的是并发进程之间的制约与协作问题；并发执行本身不需要靠信号量来“开启”。

**解题切入点**：
看到“不需要信号量”，先列出信号量的标准应用：互斥、同步、前驱关系。信号量在 408 中几乎就是这三个考点的代名词，排除后只剩“进程的并发执行”。类比算法竞赛：多线程并行跑不需要锁；只有多个线程要访问共享数据、需要顺序约束时才上锁。

**推演**：
- A 进程同步：需要信号量。设同步信号量 $S=0$ 表示初值；前驱完成后执行 $V(S)$ 操作，后继开始前执行 $P(S)$ 操作。这相当于用状态量做“闸门”，类似状态机中根据状态决定是否放行。
$$S=0;\quad \text{前驱执行 } V(S),\ \text{后继执行 } P(S).$$

- B 进程互斥：需要信号量。设互斥信号量 $mutex=1$ 表示可用；进入临界区前执行 $P(mutex)$ 操作，离开临界区后执行 $V(mutex)$ 操作。这就是共享资源的加锁/解锁，和并发编程中的 `lock/unlock` 等价。
$$mutex=1;\quad P(mutex);\ \text{临界区};\ V(mutex).$$

- C 执行的前驱关系：需要信号量。前驱关系是 DAG 上的依赖约束。对每条边 $u \to v$ 设置初值为 $0$ 的信号量 $S_{uv}$ 作为同步约束；$u$ 完成后执行 $V(S_{uv})$ 操作，$v$ 开始前执行 $P(S_{uv})$ 操作。这很像拓扑排序：后继要等前驱把“入度”清完才放行。
$$S_{uv}=0;\quad u\text{ 完成后 } V(S_{uv}),\quad v\text{ 开始前 } P(S_{uv}).$$

- D 进程的并发执行：不需要信号量。并发仅要求多个进程在时间上重叠推进，由系统调度保证即可；若它们没有共享资源且没有先后依赖，直接并行运行即可。信号量是用来“规范并发”的，不是“产生并发”的。

所以选 D。

**易错点**：
1. 混淆“并发”与“同步/互斥”：并发是现象，同步/互斥是对并发的约束。开多个线程本身不需要锁；锁只在共享数据竞争时才需要。
2. 前驱关系看似只是图上的先后关系，但实现先后顺序仍然需要同步工具，信号量就是教科书中的标准实现。不能因为它是“关系”就认为不需要信号量。
3. 互斥是信号量最经典的应用，但题目问“不需要”，不能用“它常见”来选。
4. 有些同学看到 A 和 C 都带“顺序”就犹豫；记住它们都需要强制顺序，而强制顺序正是信号量的职责。

**命题规律**：
408 喜欢考“工具边界”：某个机制到底能做什么、不能做什么。信号量的典型应用就是互斥、同步、前驱关系；本题用“不需要”反衬信号量的应用范围，答案落在非典型的“并发执行”上。以后类似的题，先列工具的典型应用再用排除法；遇到“不需要信号量”的表述，优先选与共享、协作、顺序无关的基础并发概念。

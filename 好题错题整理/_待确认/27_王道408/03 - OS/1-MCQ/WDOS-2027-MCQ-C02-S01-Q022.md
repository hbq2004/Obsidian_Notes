# MCQ 第 22 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C02-S01-Q022_题目.png|题目]]

若一个进程实体由 $PCB、共享正文段、数据堆段和数据栈段组成，请指出下列 $C 语言程序中的内容及相关数据结构各位于哪一段中。
$I. 全局赋值变量，( )
$II. 未赋值的局部变量，( )
$III. 函数调用实参传递值，( )
$IV. 用 $malloc() 要求动态分配的存储区，( )
$V. 常量值（如 1995、"string"），( )
$VI. 进程的优先级，( )
(A) $PCB
(B) 正文段
(C) 堆段
(D) 栈段

## DeepSeek V4 Flash Max 解析
**答案**：

按题意把四段记为：$A=PCB$，$B=$ 正文段，$C=$ 数据堆段，$D=$ 数据栈段。

| 编号 | 内容 | 所在段 |
|---|---|---|
| $I$ | 全局赋值变量 | $C$（数据堆段中的初始化数据区） |
| $II$ | 未赋值的局部变量 | $D$（栈段） |
| $III$ | 函数调用实参传递值 | $D$（栈段） |
| $IV$ | $malloc()$ 动态分配的存储区 | $C$（堆段） |
| $V$ | 常量值 | $B$（正文段 / 只读常量区） |
| $VI$ | 进程的优先级 | $A$（$PCB$） |

$$I\to C,\quad II\to D,\quad III\to D,\quad IV\to C,\quad V\to B,\quad VI\to A.$$

> 若严格区分“数据段”与“堆段”，则 $I$ 应归初始化数据段；本题的 $C$ 按题干“数据堆段”理解。

**解题切入点**：

核心是区分变量的存储类别与生命周期：全局变量编译期分配，局部变量和函数参数在运行栈上分配，$malloc$ 动态分配在堆上，常量只读且随代码装入，进程属性在内核 $PCB$ 中。

算法竞赛类比：全局数组开在静态区，递归函数里的局部变量和参数在递归栈上，`new` 出来的结点在堆上，评测系统记录进程状态的数据结构相当于 $PCB$。

**推演**：

1. **全局赋值变量**：编译期已经确定，不随函数调用创建，也不在只读正文段中，故归入数据堆段中的初始化数据区。

2. **未赋值的局部变量**：函数被调用时在栈帧中分配，“未赋值”只表示初值不确定，不影响它位于栈段。

3. **函数调用实参传递值**：实参值要进入被调函数的栈帧，属于活动记录的一部分，因此位于栈段。这就像递归时每一层参数都保存在递归栈中。

4. **$malloc()$ 动态分配区**：由堆分配器管理，在堆段中分配；指针变量本身可能在栈上，但它指向的对象在堆中。

5. **常量值**：数值常量通常作为指令立即数出现在代码中，字符串常量放在只读常量区，二者随正文段装入，不占堆和栈。

6. **进程优先级**：属于进程控制信息，由内核存放在 $PCB$ 中，不属于用户进程的正文、堆或栈。

**易错点**：

- 不要把“全局赋值变量”误认为在堆中；本题的“数据堆段”是合并概念，若严格区分，全局变量应在数据段。
- “未赋值的局部变量”不是 BSS 段；BSS 段存放未初始化的全局变量或静态局部变量。
- `malloc` 的指针变量和指针指向的对象位置不同：指针变量可能在栈上，对象在堆上。
- 常量值如果是字符串字面量，可能位于只读常量区；但如果 `char s[]="string"`，数组本身可能分配在栈上，是拷贝后的结果。
- 进程优先级不是程序中的全局变量，而是调度器需要的 $PCB$ 字段。

**命题规律**：

$408$ 喜欢用“C 语言 + 进程映像”交叉考查进程实体与虚拟内存布局，本质是给存储对象分类。题目只是换了变量名或数据结构，但对应的段基本不变。

备考时记住一张图：正文段、数据段、堆段、栈段、$PCB$ 分别放什么，并分清“全局、局部、动态、常量、内核数据”五类对象即可。以后遇到 `static` 局部变量、未初始化全局变量、字符串常量、指针变量、函数返回地址等变体，都是同一套映射规则。

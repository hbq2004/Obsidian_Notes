# MCQ 第 59 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C03-S01-Q059_题目.png|题目]]

分区分配内存管理方式的主要保护措施是（ ）.
(A) 界地址保护
(B) 程序代码保护
(C) 数据保护
(D) 栈保护

## DeepSeek V4 Flash Max 解析
**答案**：
A. 界地址保护

**解题切入点**：
分区分配把内存看成若干连续区间，每个进程占一个区间。保护的本质是“边界检查”，而不是检查内容类型。用算法竞赛类比：每个进程的地址空间就是一个 `pair<base, limit>`，每次访问都等价于隐式 `assert(0 <= offset && offset < limit)`，越界就触发中断，相当于数组越界 RE / 段错误。

**推演**：
1. 分区分配中，进程的逻辑地址从 $0$ 开始编址，CPU 发出的逻辑地址 $A$ 要经过基址寄存器 $B$ 和界限寄存器 $L$ 共同检查：
$$
0 \le A < L
$$
若越界则产生越界中断；否则物理地址为：
$$
P = B + A
$$
2. 因此保护的关键是“界地址”，即给每个分区的下界和上界加限制，防止进程访问其他分区。
3. 程序代码保护、数据保护、栈保护都需要更细粒度的权限控制，例如分页/分段中的页表项或段表项的读、写、执行权限位（R/W/X）。分区分配只是连续分配，不区分代码段、数据段、栈的不同权限，所以不是它的主要保护措施。

**易错点**：
- 容易误选“程序代码保护”，但那是分页/分段中靠权限位实现的，不是分区分配的核心手段。
- 界限检查不是只检查上界，而是上下界同时限制；逻辑地址从 $0$ 开始，所以形式为 $0 \le A < L$。
- 不要混淆“界地址保护”和“重定位”：重定位负责地址转换，界地址保护负责越界检查；二者配合使用，但题目问的是保护措施。

**命题规律**：
常以选择题形式对比各种内存管理方式的保护机制：
- 分区分配 / 连续分配 → 界地址保护（基址/界限寄存器）；
- 分页 / 分段 → 页表项 / 段表项的权限位保护；
- 覆盖 / 交换 → 解决容量问题，不提供地址保护。

解题时抓住“地址转换那一刻做了什么检查”，就能快速定位答案。

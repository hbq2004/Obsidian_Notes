03. 【2020 统考真题】若任意一个字符的编码都不是其他字符编码的前缀，则称这种编码具有前缀特性。现有某字符集（字符个数 $\ge 2$）的不等长编码，每个字符的编码均为二进制的 0、1 序列，最长为 $L$ 位，且具有前缀特性。请回答下列问题：
1）哪种数据结构适宜保存上述具有前缀特性的不等长编码？

## DeepSeek V4 Flash Max 解析

**答案**：用一棵“0/1 二叉树”（前缀树 / Trie）保存：每个字符的编码就是从根到某个结点的唯一路径，左分支代表 0、右分支代表 1；译码时从根按位走到编码终点，输出对应字符后回到根继续；判定前缀特性时，将所有编码插入该树，检查是否存在编码终点互为前缀或重复的情况。

**解题切入点**：看到“前缀”和“0/1 序列”，应立刻联想到字典树（Trie）。二进制只有 0、1 两个分支，所以它本质是一棵二叉树。前缀关系在树中恰好对应“祖先关系”，因此用树路径表示编码最直观，也最适合译码。

**推演**：

设字符集为 $C=\{c_1,c_2,\dots,c_n\}$，字符 $c_i$ 的编码为 $w_i$，且 $|w_i|\le L$。构造一棵二叉树：

- 根结点对应空前缀；
- 从父结点到左孩子记作 0；
- 从父结点到右孩子记作 1。

这样，任意一个 0/1 串都唯一对应从根开始的一条路径；反之，任意一条从根开始的路径也唯一对应一个 0/1 串。

若 $u$ 是 $v$ 的前缀，当且仅当 $u$ 对应的结点是 $v$ 对应结点的祖先，或 $u=v$ 时对应同一结点。因此，前缀特性等价于：不存在两个字符的编码终点互为祖先或重合。在只保存编码及其前缀的最小二叉树中，合法的编码终点都应是叶子，并且不能重复。

数据结构可定义为：

```cpp
struct Node {
    char ch;          // 当该结点是某个字符编码终点时，保存该字符
    bool isEnd;       // 从根到该结点的 0/1 串是否是一个字符的编码
    Node *left, *right;
};
```

译码过程：

从根结点出发，依次读入 0/1 串的每一位：

- 遇到 0 走向左孩子；
- 遇到 1 走向右孩子；
- 若走到空指针，说明输入的 0/1 串不是合法编码串；
- 若到达一个 `isEnd == true` 的结点，说明一个字符译码完成，输出该字符，并回到根结点继续译下一个字符。

由于编码具有前缀特性，每次到达编码终点时就可以确定一个字符，不需要回溯。

判断某字符集不等长编码是否具有前缀特性，可以逐个编码插入二叉树：

```cpp
root = new Node();

for (每个字符 c 的编码 s) {
    p = root;

    for (i = 1; i <= s.length(); i++) {
        if (p->isEnd == true)
            return false;          // 已有编码是 s 的前缀

        if (s[i] == 0) {
            if (p->left == NULL) p->left = new Node();
            p = p->left;
        } else {
            if (p->right == NULL) p->right = new Node();
            p = p->right;
        }
    }

    if (p->isEnd == true)
        return false;              // 出现重复编码

    if (p->left != NULL || p->right != NULL)
        return false;              // s 是已有更长编码的前缀

    p->isEnd = true;
    p->ch = c;
}

return true;
```

上述三种失败情况分别对应：

1. 插入未结束就经过已标记的编码终点：说明已有编码是当前编码的前缀；
2. 当前编码终点已经被标记：说明出现重复编码，也违反前缀特性；
3. 当前编码终点还有孩子：说明当前编码是已有更长编码的前缀。

若所有编码插入后都没有触发上述情况，则具有前缀特性。

设字符数为 $n$，最长编码长度为 $L$，则判定复杂度为 $O(nL)$；译码时每处理一位只需 $O(1)$，总复杂度为输入长度的一次方级别。

**易错点**：

- 不要把任意前缀编码都等同于哈夫曼树。哈夫曼树是带权最优的前缀编码树，本题只要求保存、译码和判定，普通二叉树即可。
- 判定时不能只检查“当前编码不是已有编码的前缀”，还要检查“已有编码不是当前编码的前缀”。用插入树中“终点是否有孩子”可以同时处理这种情况。
- 译码时到达编码终点后必须回到根结点，否则后续字符会从错误位置开始译码。
- 注意重复编码问题：若严格按前缀定义，相同编码也互为前缀，应在判定时排除。
- 若编码串不完整或走到空指针，应视为非法输入，不能强行输出。

**命题规律**：

本题的考点是“树与二叉树的应用——前缀编码、哈夫曼编码”，核心是树的路径与编码的对应关系。常见变式有：给定一组编码判断是否为前缀码；根据字符频率构造哈夫曼树并写出哈夫曼编码；利用编码树计算 WPL；或者给出编码树要求译码。复习时应重点掌握 Trie/前缀树思想、哈夫曼树构造过程，以及编码树在译码中的唯一性作用。

> 03. 【解答】
> 1）使用一棵二叉树保存字符集中各字符的编码，每个编码对应于从根开始到达某叶结点的一条路径，路径长度等于编码位数，路径到达的叶结点中保存该编码对应的字符。

> 3）二叉树既可用于保存各字符的编码，又可用于检测编码是否具有前缀特性。判定编码是否具有前缀特性的过程，也是构建二叉树的过程。初始时，二叉树中仅含有根结点，其左子指针和右子指针均为空。
>     依次读入每个编码C，建立/寻找从根开始对应于该编码的一条路径，过程如下：
>     对每个编码，从左至右扫描C的各位，根据C的当前位（0或1）沿结点的指针（左子指针或右子指针）向下移动。当遇到空指针时，创建新结点，让空指针指向该新结点并继续移动。沿指针移动的过程中，可能遇到三种情况：
>     ① 若遇到了叶结点（非根），则表明不具有前缀特性，返回。
>     ② 若在处理C的所有位的过程中，均没有创建新结点，则表明不具有前缀特性，返回。
>     ③ 若在处理C的最后一个编码位时创建了新结点，则继续验证下一个编码。
>     若所有编码均通过验证，则编码具有前缀特性。

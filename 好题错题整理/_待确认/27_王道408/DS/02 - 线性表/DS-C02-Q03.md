# 综合题 第 3 题

03. 试编写算法将带头结点的单链表就地逆置，所谓“就地”是指辅助空间复杂度为 $O(1)$.

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C02-Q03_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：采用头插法，将单链表中的结点依次摘下并插入到头结点之后，实现原地逆置，辅助空间复杂度为 $O(1)$，时间复杂度为 $O(n)$。

**解题切入点**：看到“就地”和“辅助空间 $O(1)$”，立即想到不能使用额外数组或递归栈，只能通过调整指针完成。单链表逆置的经典方法有两种：头插法和迭代反转（三个指针）。对于带头结点的链表，头插法更为简洁——它利用头结点作为新链表的固定头，每次将当前结点插入到头结点之后，从而逐步反转顺序。本题核心是考察对指针操作和链表基本操作的熟练度，尤其是如何防止断链与正确更新指针。

**推演**：  
设带头结点的单链表 `L`，头结点 `L` 不存储数据，其 `next` 指向第一个数据结点。  
算法步骤：  
1. 定义指针 `p` 指向 `L->next`（第一个数据结点），若链表为空则直接返回。  
2. 将 `L->next` 置为 `NULL`，使头结点成为空链表的头。  
3. 循环遍历原链表，对每个结点 `p` 执行：  
   - 用指针 `r` 暂存 `p->next`（保存后继，防止断链）。  
   - 将 `p->next` 指向 `L->next`（即当前新链表的第一个结点）。  
   - 将 `L->next` 指向 `p`（将 `p` 插入到头结点之后，完成头插）。  
   - 将 `p` 更新为 `r`，继续处理下一个结点。  
4. 循环结束后，原链表已逆置。  

关键代码思路（C语言风格）：
```c
void Reverse(LinkList L) { // L是带头结点的单链表
    LNode *p, *r;
    p = L->next;          // 指向第一个数据结点
    L->next = NULL;       // 头结点分离，新链表初始为空
    while (p != NULL) {
        r = p->next;      // 保存后继
        p->next = L->next; // 头插
        L->next = p;
        p = r;
    }
}
```
该算法只使用了常数个指针变量，空间复杂度 $O(1)$；每个结点处理一次，时间复杂度 $O(n)$。

**易错点**：  
- 忘记将 `L->next` 初始化为 `NULL`，会导致链表形成环或未完全逆置。  
- 循环中未保存 `p->next` 就修改 `p->next`，导致断链，后续结点丢失。  
- 边界条件处理：空链表或只有一个结点时，算法应正确运行（空链表时 `p` 为 `NULL`，循环不执行，`L->next` 保持 `NULL`；单结点时，头插后 `L->next` 指向该结点，其 `next` 为 `NULL`，均正确）。  
- 混淆头结点与数据结点，错误地移动头结点或修改其指针位置。

**命题规律**：  
- 考点定位：单链表的基本操作（插入、删除、遍历），就地逆置是经典题型，常出现在选择题、综合应用题中，考察对指针的掌握和算法设计能力。  
- 常见变式：不带头结点的单链表逆置、双向链表逆置、只逆置前 $k$ 个结点、递归逆置（但递归栈空间为 $O(n)$，不符合“就地”要求）、按指定区间逆置等。  
- 复习建议：务必动手画图模拟指针变化，理解头插法和迭代反转的本质；掌握带头结点与不带头结点两种情况的处理差异；多练习链表类的算法题，培养“先保存后继、再修改指针”的习惯，避免断链错误。

# 综合题 第 8 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-Q08_题目.png|题目]]

08. 设 $A$ 和 $B$ 是两个单链表（带头结点），其中元素递增有序。设计一个算法从 $A$ 和 $B$ 中的公共元素产生单链表 $C$，要求不破坏 $A$、$B$ 的结点.

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C02-Q08_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：利用 $A$、$B$ 递增有序的特点，用双指针同步扫描两个链表，遇到相等元素时新建结点并尾插到链表 $C$，否则将较小值的指针后移；时间复杂度 $O(m+n)$，空间复杂度 $O(\min(m,n))$ 或正比于公共元素个数。

**解题切入点**：拿到题目先抓住两个关键：一是“递增有序”，这提示可以用双指针线性扫描，类似归并排序中合并有序序列的思想；二是“不破坏 $A$、$B$ 的结点”，说明不能借用原结点，必须为 $C$ 新建结点。如果把两个有序链表看成两路递增数据流，公共元素就是两条数据流中“值相同”的位置，比较当前值的大小即可决定移动哪一边。

**推演**：

设 $A$、$B$ 均为带头结点的单链表，头结点分别为 $A$ 和 $B$，首元结点为 $A\to\text{next}$、$B\to\text{next}$。用两个工作指针 $pa$、$pb$ 分别指向 $A$、$B$ 中当前待比较的结点。因为链表递增有序，所以：

- 若 $pa\to\text{data} < pb\to\text{data}$，则 $pa$ 所指元素不可能在 $B$ 中找到相等元素，于是 $pa=pa\to\text{next}$，跳过较小值；
- 若 $pa\to\text{data} > pb\to\text{data}$，同理 $pb=pb\to\text{next}$；
- 若 $pa\to\text{data} = pb\to\text{data}$，则找到一个公共元素，新建结点 $s$，令 $s\to\text{data}=pa\to\text{data}$，$s\to\text{next}=\text{NULL}$，将 $s$ 尾插到 $C$ 中，然后 $pa$、$pb$ 同时后移。

初始时创建 $C$ 的头结点，并令尾指针 $pc$ 指向头结点，使 $C$ 初始为空链表。循环直到 $pa$ 或 $pb$ 为空，此时较短链表已经扫描完毕，不可能再有公共元素，算法结束。

关键代码思路如下：

```c
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;

LinkList Intersect(LinkList A, LinkList B) {
    LinkList C = (LNode*)malloc(sizeof(LNode));
    C->next = NULL;
    LNode *pa = A->next, *pb = B->next;
    LNode *pc = C;                     // 尾指针
    while (pa != NULL && pb != NULL) {
        if (pa->data < pb->data) {
            pa = pa->next;
        } else if (pa->data > pb->data) {
            pb = pb->next;
        } else {
            LNode *s = (LNode*)malloc(sizeof(LNode));
            s->data = pa->data;
            s->next = NULL;
            pc->next = s;
            pc = s;
            pa = pa->next;
            pb = pb->next;
        }
    }
    return C;
}
```

正确性证明要点：

循环过程中始终维持不变式：$pa$ 之后的最小值不小于 $pb$ 当前值之前已比较过的所有值，$pb$ 同理；每当两值相等，该值一定同时出现在 $A$ 和 $B$ 中，且由于同步后移，不会重复产生同一个公共元素。循环结束时，至少一个链表已扫描完，剩余部分即使有值也不会与另一链表的值相等，因此不会漏解。

时间复杂度：$pa$、$pb$ 各自最多移动 $m$ 和 $n$ 次，其中 $m=|A|$，$n=|B|$，每次比较和移动都是 $O(1)$，故总时间 $O(m+n)$。

空间复杂度：新建的结点个数等于公共元素个数，最多为 $\min(m,n)$，额外辅助空间为常数，因此空间复杂度 $O(\min(m,n))$（严格说，输出链表本身不计入辅助空间，则辅助空间为 $O(1)$；若计入输出结点，则为 $O(\min(m,n))$）。

**易错点**：

1. **误用原结点导致破坏 $A$、$B$**：有些同学为了省空间，直接将 $A$ 或 $B$ 中的公共结点链入 $C$，这违反了“不破坏 $A$、$B$ 的结点”的要求，必须 `malloc` 新结点。
2. **头结点处理遗漏**：$C$ 也必须带头结点，创建后要初始化 `C->next = NULL`，否则尾插时可能出现野指针。
3. **尾指针没有同步更新**：尾插法插入新结点后，若忘记让 `pc = s`，后续插入会覆盖原链接，导致链表断裂。
4. **相等时只移动一个指针**：若只移动 $pa$ 或 $pb$，可能造成重复输出同一个公共元素，甚至死循环，必须同时后移两个指针。
5. **比较顺序写反**：先判断 `>` 或先判断 `<` 都可以，但要保证三个分支互斥且完整，否则可能漏掉相等情况。
6. **忽略边界条件**：$A$ 或 $B$ 为空时，循环不执行，直接返回空链表 $C$，这是正确的；但若忘记带头结点，返回 `NULL` 会引起调用者错误。
7. **重复元素语义不清**：若题目中的“递增”理解为“非递减”，即可能有重复值，上述算法按集合交集处理，只保留一个公共值；若要求按多重交集的次数输出，则相等时需要额外计数，但考研通常按集合交集理解。

**命题规律**：本题是“有序链表归并”类算法的直接变形，是 408 统考或自主命题中线性表算法设计题的高频考点。核心考查线性表的基本操作、双指针技巧、链表结点动态申请与尾插法。常见变式有：

- 从两个有序单链表中求交集，但允许破坏原链表（可将原结点摘下，空间复杂度降为 $O(1)$）；
- 求两个有序单链表的并集，算法类似，相等时只保留一个并同时后移；
- 求两个有序单链表的差集（$A-B$），需要根据不同结果分支处理；
- 将两个有序单链表合并为一个有序单链表，允许借用原结点；
- 改为不带头结点，或递归实现。

复习建议：熟练掌握带头结点链表的插入、删除、遍历操作，理解双指针在有序序列上的单调移动性质。做题时先明确“是否允许修改原链表”“是否要求空间 $O(1)$”，然后选择“新建结点”或“摘下原结点”的写法。最好能手写完整代码，注意边界条件与指针更新的正确性。

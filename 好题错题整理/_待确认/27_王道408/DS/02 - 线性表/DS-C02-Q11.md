11. 设计一个算法用于判断带头结点的循环双链表是否对称。

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C02-Q11_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：用首尾双指针从两端向中间扫描，依次比较对应结点的 `data`；若所有对称位置的 `data` 都相等，则链表对称，否则不对称。最坏时间复杂度 \(O(n)\)，空间复杂度 \(O(1)\)。

**解题切入点**：看到“对称/回文”，立即想到“两端向中间”的双指针扫描。该链表是带头结点的循环双链表，所以首结点是 `L->next`，尾结点是 `L->prior`，都能 \(O(1)\) 得到，不需要像单链表那样先找中点或反转后半段。核心考点是：链表遍历 + 双指针边界处理，尤其要注意偶数长度时指针会“交叉”。

**推演**：

设带头结点的循环双链表中，实际数据结点沿 `next` 方向依次为：

\[
a_1,a_2,\dots,a_n
\]

对称当且仅当：

\[
a_i=a_{n-i+1}\quad (i=1,2,\dots,\lfloor n/2\rfloor)
\]

因此，令指针 \(p\) 指向第一个结点 \(a_1\)，指针 \(q\) 指向最后一个结点 \(a_n\)。每次比较 `p->data` 与 `q->data`，若相等，则：

\[
p=p\to next,\qquad q=q\to prior
\]

继续向中间移动。

循环结束条件有两种情况：

- 若 \(n\) 为奇数，最后 \(p\) 和 \(q\) 会同时指向中间结点，即 `p == q`；
- 若 \(n\) 为偶数，最后一对中间结点比较完后，\(p\) 会到右侧，\(q\) 会到左侧，此时满足 `q->next == p`。

所以关键代码思路如下：

```c
typedef struct DNode {
    ElemType data;
    struct DNode *prior, *next;
} DNode, *DLinkList;

bool isSymmetric(DLinkList L) {
    DNode *p = L->next;   // 第一个数据结点
    DNode *q = L->prior;  // 最后一个数据结点

    while (p != q && q->next != p) {
        if (p->data != q->data)
            return false;
        p = p->next;   // 从左向右
        q = q->prior;  // 从右向左
    }
    return true;
}
```

空链表时 `L->next == L->prior == L`，循环不执行，返回 `true`，空表按对称处理；单结点表也显然对称。

正确性说明：每次循环比较的都是当前还没检查的最外层一对对称结点。若发现不等，则一定不对称；若循环自然结束，说明所有对称位置都已比较且相等，因此链表对称。

**易错点**：

1. 忘记带头结点的循环双链表中 `L->prior` 就是尾结点，导致无法从尾部开始扫描。
2. 用 `while (p != q)` 作为唯一结束条件：奇数长度可以，但偶数长度时中间一对比较完后指针已经交叉，会多扫描已比较过的结点，不够严谨。
3. 写成 `while (p != q && p->next != q)` 是错误的。偶数长度时，在比较中间一对之前就可能满足 `p->next == q`，导致漏比中间一对。例如序列 `1,2,3,1` 会被误判为对称。
4. 比较时误将头结点数据参与比较。必须从 `L->next` 和 `L->prior` 开始，头结点 `L` 本身不参与对称比较。
5. 指针移动方向写反：`p` 应沿 `next` 向右移动，`q` 应沿 `prior` 向左移动。

**命题规律**：本题属于线性表链式存储中的经典操作题，常与“回文判断”“双链表遍历”“循环链表边界处理”结合考查。常见变式有：判断单链表是否回文（需快慢指针找中点，再反转后半段或借助栈）；判断非循环双链表是否对称；判断循环双链表是否对称并返回不对称位置等。复习时应重点掌握带头结点链表的特点，画图模拟奇数长度和偶数长度两种情况，避免边界条件错误。


> **原书解答（OCR）**
>
> 11. 【解答】
> 算法思想：让 p 从左向右扫描，q 从右向左扫描，直到它们指向同一结点（p==q，当循环双链表中结点个数为奇数时）或相邻（p->next=q 或 q->prior=p，当循环双链表中结点个数为偶数时）为止，若它们所指结点值相同，则继续进行下去，否则返回 0。若比较全部相等，则返回 1。
> 本题代码如下：
> ```c
> int Symmetry(DLinkList L){
>     DNode *p=L->next,*q=L->prior;       //两头工作指针
>     while(p!=q&&p->next!=q)             //循环跳出条件
>         if(p->data==q->data){           //所指结点值相同则继续比较
>             p=p->next;
>             q=q->prior;
>         }
>         else                            //否则，返回 0
>             return 0;
>     return 1;                           //比较结束后返回 1
> }
> ```
>
> 注 意
> while 循环第二个判断条件易误写成 q->next!=p，分析这样会产生什么问题。

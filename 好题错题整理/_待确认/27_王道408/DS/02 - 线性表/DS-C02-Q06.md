# 综合题 第 6 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-Q06_题目.png|题目]]

06. 设 $C = \{a_1, b_1, a_2, b_2, \cdots, a_n, b_n\}$ 为线性表，采用带头结点的单链表存放，设计一个就地算法，将其拆分为两个线性表，使得 $A = \{a_1, a_2, \cdots, a_n\}$, $B = \{b_n, \cdots, b_2, b_1\}$.

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C02-Q06_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：一次扫描原链表，把奇数位结点 $a_i$ 用“尾插法”链成 $A$，把偶数位结点 $b_i$ 用“头插法”链成 $B$；于是 $A$ 保序，$B$ 自动逆序为 $b_n,\dots,b_1$。时间复杂度 $O(n)$，辅助空间 $O(1)$。

**解题切入点**：看到 $A$ 保持原序，应立刻想到“尾插法”；看到 $B$ 要求逆序，应立刻想到“头插法”。链表题目中头插法天然产生逆序，尾插法天然保持顺序。本题又要求“就地”，所以不能复制数据结点，只能原地修改 `next` 指针。

**推演**：设结点类型为
```c
typedef struct LNode {
    ElemType data;
    struct LNode *next;
} LNode, *LinkList;
```

算法思想是：用 $p$ 指向当前待处理的 $a_i$，$q = p \rightarrow next$ 指向对应的 $b_i$，$r = q \rightarrow next$ 保存下一轮的 $a_{i+1}$。  
$A$ 复用原链表 $C$ 的头结点，设尾指针 `ra` 始终指向 $A$ 的尾结点；$B$ 另设一个头结点，初始为空。每轮：

1. 将 $p$ 尾插到 $A$，保持 $a_1,a_2,\dots$ 的顺序；
2. 将 $q$ 头插到 $B$，使 $B$ 的顺序逐步变成 $b_i,b_{i-1},\dots,b_1$；
3. 令 $p = r$，继续处理下一对。

关键代码思路如下：

```c
void SplitList(LinkList C, LinkList *A, LinkList *B) {
    LinkList p = C->next, q, r, ra;

    *A = C;                 // A 复用原头结点
    (*A)->next = NULL;

    *B = (LinkList)malloc(sizeof(LNode)); // B 的头结点
    (*B)->next = NULL;

    ra = *A;                // ra 始终指向 A 的尾结点

    while (p != NULL) {
        q = p->next;        // q = b_i
        p->next = NULL;     // 摘下 a_i

        ra->next = p;       // a_i 尾插到 A
        ra = p;

        if (q != NULL) {    // 处理 b_i
            r = q->next;    // r = a_{i+1}，必须提前保存
            q->next = (*B)->next; // b_i 头插到 B
            (*B)->next = q;
            p = r;
        } else {
            p = NULL;
        }
    }

    ra->next = NULL;        // 保证 A 表尾为空
}
```

正确性证明要点：

- 对 $A$：每次把 $a_i$ 接到当前表尾，则最终为
  \[
  A=(a_1,a_2,\dots,a_n)
  \]
- 对 $B$：头插顺序依次为 $b_1,b_2,\dots,b_n$，因此最终为
  \[
  B=(b_n,b_{n-1},\dots,b_1)
  \]
- 每个数据结点只被处理一次，且只修改指针，不复制数据，因此符合“就地”要求。

复杂度：
\[
T(n)=O(n),\qquad S(n)=O(1)
\]

**易错点**：

- 头插 $b_i$ 前必须先保存 $r=q \rightarrow next$，否则会丢失后面的 $a_{i+1}$。
- $A$ 不能使用头插法，否则 $A$ 会变成 $a_n,\dots,a_1$；$B$ 不能使用尾插法，否则 $B$ 不会逆序。
- 尾插到 $A$ 时必须维护尾指针 `ra`，否则每次找尾结点会使时间复杂度退化为 $O(n^2)$。
- 最后要置 `ra->next = NULL`，否则 $a_n$ 原来的 `next` 仍可能指向 $b_n$，导致遍历 $A$ 时进入 $B$。
- 更新循环变量时，处理完 $b_i$ 后应令 `p = r`，不能写 `p = p->next`，因为 $p$ 是 $a_i$，而下一轮需要的 $a_{i+1}$ 已被保存为 $r$。

**命题规律**：本题是“链表拆分 + 头插法逆置”的典型综合题，属于 408 线性表章节的高频考点。常见变式有：按序号奇偶拆分后两个链表都保持原序；拆分后对其中一个链表再逆置；两个有序链表合并；就地逆置整个单链表等。复习时应该熟练掌握尾插法、头插法、尾指针优化，并养成画图模拟指针修改的习惯。答题时务必写明算法思想、代码和复杂度三部分，这是综合应用题的常规得分点。

> 06.【解答】
> 算法思想：循环遍历链表 C，采用尾插法将一个结点插入表 A，这个结点为奇数号结点，这样建立的表 A 与原来的结点顺序相同；采用头插法将下一结点插入表 B，这个结点为偶数号结点，这样建立的表 B 与原来的结点顺序正好相反。
> 本题代码如下：
> ```c
> LinkList DisCreat_2(LinkList &A){
>     LinkList B=(LinkList)malloc(sizeof(LNode)); //创建 B 表表头
>     B->next=NULL;                       //B 表的初始化
>     LNode *p=A->next,*q;               //p 为工作指针
>     LNode *ra=A;                        //ra 始终指向 A 的尾结点
>     while(p!=NULL){
>         ra->next=p; ra=p;              //将*p 链到 A 的表尾
>         p=p->next;
>         if(p!=NULL){
>             q=p->next;                 //头插后，*p 将断链，因此用 q 记忆*p 的后继
>             p->next=B->next;           //将*p 插入到 B 的前端
>             B->next=p;
>             p=q;
>         }
>     }
>     ra->next=NULL;                     //A 尾结点的 next 域置空
>     return B;
> }
> ```
> 要特别注意的是，该算法采用头插法插入结点后，*p 的指针域已改变，若不设变量保存其后继结点，则会引起断链，从而导致算法出错。

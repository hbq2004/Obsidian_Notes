# 综合题 第 9 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-Q09_题目.png|题目]]

09. 已知两个链表 $A$ 和 $B$ 分别表示两个集合，其元素递增排列。编制函数，求 $A$ 与 $B$ 的交集，并存放于 $A$ 链表中。

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C02-Q09_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：用双指针 $pa,pb$ 分别扫描递增链表 $A,B$，按大小关系归并比较：相等时保留 $A$ 中该结点作为交集结点，$A$ 中较小结点删除，$B$ 中较小结点舍弃；最后释放 $A$ 中剩余结点并把结果链尾置空。时间复杂度 $O(\mathrm{len}(A)+\mathrm{len}(B))$，空间复杂度 $O(1)$。

**解题切入点**：拿到“有序链表 + 求交集”先定位为双指针归并题。类比“合并两个有序表”：两个指针从头开始比较，但合并条件是“只有相等才输出”。题目要求结果存放在 $A$ 中，因此不能新建链表，而应把 $A$ 当作结果链表，保留相等结点、删除 $A$ 中无用结点；对 $B$ 则只需向后移动指针，必要时也可释放无用结点。

**推演**：

设带头结点的单链表结点定义为：

```c
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;
```

核心思路是：

- $pa$ 指向 $A$ 的当前结点，$pb$ 指向 $B$ 的当前结点；
- $pc$ 指向结果链表的尾结点，初始 $pc = A$；
- 比较 $pa$ 与 $pb$ 的 `data` 值：

1. 若 $pa\text{->}data == pb\text{->}data$，则该元素属于交集，把 $pa$ 结点接到结果链表尾部，$pc$ 后移；$pa,pb$ 同时后移。

2. 若 $pa\text{->}data < pb\text{->}data$，由于两个链表都递增，$pa$ 小于 $B$ 当前元素，也小于 $B$ 后面所有元素，因此 $pa$ 不可能出现在交集中，删除并释放 $pa$。

3. 若 $pa\text{->}data > pb\text{->}data$，则 $B$ 当前元素小于 $A$ 当前元素，也不可能出现在交集中，$pb$ 后移。

循环结束后，若 $B$ 已空而 $A$ 还有剩余结点，则 $A$ 剩余结点都不是交集，全部释放；若 $A$ 已空，则 $B$ 剩余结点也无需再处理。

关键代码如下：

```c
void Intersection(LinkList &A, LinkList &B) {
    LNode *pa = A->next, *pb = B->next;
    LNode *pc = A, *u;

    while (pa && pb) {
        if (pa->data == pb->data) {
            // 保留 A 中当前结点
            pc->next = pa;
            pc = pa;
            pa = pa->next;

            // B 中该结点已匹配完，可释放
            u = pb;
            pb = pb->next;
            free(u);
        } else if (pa->data < pb->data) {
            // A 当前元素不可能在交集中
            u = pa;
            pa = pa->next;
            free(u);
        } else {
            // B 当前元素不可能在交集中
            u = pb;
            pb = pb->next;
            free(u);
        }
    }

    // A 中剩余结点均不在 B 中
    while (pa) {
        u = pa;
        pa = pa->next;
        free(u);
    }

    // 若 B 已无需要保留，可释放剩余 B 结点
    while (pb) {
        u = pb;
        pb = pb->next;
        free(u);
    }

    // 结果链表尾结点置空
    pc->next = NULL;
}
```

若题目要求不修改 $B$，则只需把代码中对 `pb` 结点的 `free` 删除，改为 `pb = pb->next` 即可。

**易错点**：

- 删除结点前必须先用临时变量保存其后继，否则 `free` 后无法继续遍历。模板为：
  ```c
  u = p;
  p = p->next;
  free(u);
  ```
- 循环结束后容易忘记把 `pc->next` 置为 `NULL`，导致结果链表尾部仍指向已经释放的结点，形成野指针。
- 比较方向不能写反：$pa < pb$ 时删除 $pa$，$pa > pb$ 时移动 $pb$。
- 不要新建链表存放结果，否则空间复杂度不再是 $O(1)$，也不符合“存放在 $A$ 链表中”的要求。
- 注意带头结点与不带头结点的区别。本文按常见教材约定采用带头结点；若链表不带头结点，函数应返回新的头指针，并单独处理结果为空的情况。

**命题规律**：本题属于“线性表”中的高频考点：有序链表归并、双指针、原地链表操作。常见变式有：求两个有序链表的并集、差集，判断子集，或把结果存放到新链表；也可能改为顺序表版本，考查“双指针 + 原地覆盖”。复习时应熟练掌握链表删除结点的三步写法，会画图分析指针变化，并注意时间、空间复杂度分析。

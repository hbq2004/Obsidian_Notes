# 综合题 第 2 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-Q02_题目.png|题目]]

02. 试编写在带头结点的单链表 $L$ 中删除一个最小值结点的高效算法（假设该结点唯一）.

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C02-Q02_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：用两个指针 `minp` 和 `minpre` 在遍历过程中分别保存“当前最小值结点”和“它的前驱”，一趟扫描结束后直接通过前驱指针完成删除；时间复杂度 $O(n)$，空间复杂度 $O(1)$。

**解题切入点**：
- 单链表中删除任意结点，关键是找到它的前驱，核心操作为 `pre->next = q->next`。
- 找最小值可以使用“打擂台”的思想：遍历链表，不断更新当前最小值；但链表不能随机访问，所以不仅要记住最小值结点，还要记住其前驱。
- “高效”通常指线性时间内完成，即 $O(n)$ 时间、$O(1)$ 辅助空间；因为必须比较所有数据结点的值才能确认最小值，所以 $O(n)$ 已经是最优下界。

**推演**：

设链表带头结点。用四个指针：

- `pre`：当前扫描结点 `p` 的前驱；
- `p`：当前扫描结点；
- `minpre`：当前最小值结点 `minp` 的前驱；
- `minp`：当前最小值结点。

初始化：

- `minpre = L`，`minp = L->next`，即首元结点为初始最小值；
- `pre = L`，`p = L->next`，从首元结点开始扫描。

遍历时：

1. 若 `p->data < minp->data`，说明遇到了更小的结点，则更新：
   \[
   minp = p,\qquad minpre = pre
   \]
2. 然后继续移动：
   \[
   pre = p,\qquad p = p->next
   \]

循环结束后，`minp` 指向唯一的最小值结点，`minpre` 指向其前驱。删除操作：

\[
minpre->next = minp->next;\qquad free(minp);
\]

关键代码：

```c
void DeleteMin(LinkList L) {
    if (L == NULL || L->next == NULL)
        return;

    LNode *pre = L, *p = L->next;
    LNode *minpre = L, *minp = L->next;

    while (p != NULL) {
        if (p->data < minp->data) {
            minp = p;
            minpre = pre;
        }
        pre = p;
        p = p->next;
    }

    minpre->next = minp->next;  // 跨过最小值结点
    free(minp);                 // 释放被删除结点
}
```

正确性说明：循环过程中，`minp` 始终是“已扫描部分”的最小值结点，`minpre` 是它的前驱；当 `p = NULL` 时，所有结点已扫描完毕，因此 `minp` 就是全局最小值结点。由于题目保证该结点唯一，直接删除即可。

**易错点**：
- 只记录最小值结点，不记录其前驱；这样在单链表中无法直接删除该结点。
- 更新顺序写错：必须先 `minpre = pre`，再 `pre = p`；若先移动 `pre`，会让前驱指向自己。
- 遍历时忘记移动 `pre`，导致后续结点的前驱记录错误。
- 删除前不判空；空链表或只有头结点时，`L->next` 为空，直接访问 `minp->next` 会出错。
- 删除时先 `free(minp)` 再改指针，会造成悬空指针；应先让前驱结点跨过 `minp`，再释放。

**命题规律**：
- 本题是链表操作的基础题，考点集中在“单链表删除需要前驱”和“一趟遍历维护最值”。
- 常见变式：删除最大值结点；删除所有最小值结点；删除链表中所有值为 $x$ 的结点；查找链表倒数第 $k$ 个结点；链表逆置、去重、排序等。
- 复习建议：链表算法题多画图分析指针变化；答题时写清“算法思想 + 关键代码 + 复杂度分析”，代码不要求完全可编译，但指针修改步骤必须准确。

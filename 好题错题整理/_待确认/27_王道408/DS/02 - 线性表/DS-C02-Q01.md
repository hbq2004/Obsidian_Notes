# 综合题 第 1 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-Q01_题目.png|题目]]

01. 在带头结点的单链表 L 中，删除所有值为 $x$ 的结点，并释放其空间，假设值为 $x$ 的结点不唯一，试编写算法以实现上述操作。

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C02-Q01_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：用前驱指针 $\text{pre}$ 与工作指针 $p$ 遍历带头结点的单链表，遇到值为 $x$ 的结点就先摘链再 `free`，否则指针同步前移；时间复杂度 $O(n)$，空间复杂度 $O(1)$。

**解题切入点**：单链表删除结点必须知道“被删结点的前驱”，这是链表删除操作的共性。题目给定带头结点，正好可以用头结点作为初始前驱，使首元结点的删除与其他结点完全统一；因此核心思路就是维护一个“前驱指针” $\text{pre}$，让 $\text{pre}$ 始终指向当前工作指针 $p$ 的前一个结点。可以类比为“边走边检查，看见目标就剪断前一个结点与它的链接，再释放空间”，这样既不会断链，也不会漏删。

**推演**：设单链表结点定义如下：
```c
typedef struct LNode {
    ElemType data;
    struct LNode *next;
} LNode, *LinkList;
```
带头结点的链表 $L$ 中，$L$ 是头结点，不存储有效数据；$L\to \text{next}$ 指向首元结点。算法中令：
- $\text{pre} = L$，表示前驱指针；
- $p = L\to \text{next}$，表示当前待检查结点。

核心代码：
```c
void DeleteAllX(LinkList L, ElemType x) {
    LNode *pre = L;
    LNode *p = L->next;
    while (p != NULL) {
        if (p->data == x) {
            pre->next = p->next;  // 摘除当前结点
            free(p);              // 释放空间
            p = pre->next;        // p 指向原后继，继续判断
        } else {
            pre = p;              // 前驱指针前进
            p = p->next;          // 工作指针前进
        }
    }
}
```

推导过程如下：
1. 初始时，$p$ 指向首元结点，$\text{pre}$ 指向头结点。若链表为空，则 $p = \text{NULL}$，循环不执行，正确。
2. 循环不变量：每次循环开始时，$\text{pre}$ 是 $p$ 的直接前驱，且 $\text{pre}$ 之前的结点已经处理完毕，不包含值为 $x$ 的结点。
3. 若 $p \to \text{data} == x$，需要删除 $p$。此时先执行 `pre->next = p->next`，让 $p$ 的前驱直接指向 $p$ 的后继，将 $p$ 从链中断开；再执行 `free(p)` 释放其空间；最后执行 `p = pre->next`，使 $p$ 指向原后继。注意此时 $\text{pre}$ 不动，因为新的 $p$ 仍需判断是否等于 $x$。
4. 若 $p \to \text{data} \ne x$，说明 $p$ 应保留，则将 $\text{pre}$ 移到 $p$，$p$ 移到 $p\to\text{next}$，二者同步前进。

以链表 $H \to 1 \to x \to 2 \to x \to \text{NULL}$ 为例：
- 初始：$\text{pre}=H$，$p=1$；$1 \ne x$，更新 $\text{pre}=1$，$p=x$。
- 第一次遇到 $x$：$\text{pre}=1$，$p$ 指向第一个 $x$；执行删除后，$1\to 2$，$p$ 指向 $2$，$\text{pre}$ 仍为 $1$。
- 当前 $p=2$，$2 \ne x$，更新 $\text{pre}=2$，$p$ 指向第二个 $x$。
- 第二次遇到 $x$：$\text{pre}=2$，$p$ 指向第二个 $x$；执行删除后，$2\to \text{NULL}$，$p=\text{NULL}$，循环结束。
- 最终链表为 $H \to 1 \to 2 \to \text{NULL}$，两个 $x$ 结点均已被释放。

边界情况验证：
- 链表全为 $x$：每次删除后 $\text{pre}$ 始终指向头结点，$p$ 不断后移，最后头结点的 $\text{next}$ 为 $\text{NULL}$，全部结点被释放。
- 链表没有 $x$：算法走 `else` 分支，等价于普通遍历，不删除任何结点。
- 连续多个 $x$：删除第一个后 $p$ 自动指向后一个 $x$，而 $\text{pre}$ 未变，因此下一个 $x$ 仍能被正确删除。

**易错点**：
1. **删除后指针更新顺序错误**：例如写成 `p = p->next; free(p);`，会先丢失待删结点的后继地址，或释放了错误结点。应先摘链、再释放、最后更新 $p$。
2. **删除后 $\text{pre}$ 错误移动**：如果删除结点后还把 $\text{pre}$ 移到 $p$ 上，当连续出现两个 $x$ 时，第二个 $x$ 的前驱就会变成已删除的第一个 $x$，导致断链或漏删。删除时必须保持 $\text{pre}$ 不动。
3. **忘记释放空间**：只断链不 `free`，虽然链表的逻辑结构正确，但不满足题目“释放其空间”的要求，会造成内存泄漏。
4. **`free` 后继续访问**：`free(p)` 后，$p$ 指向的空间已回收，不能再通过 `p->data` 或 `p->next` 访问。正确做法是在 `free` 前先通过 `pre->next` 保存后继，或使用临时指针保存待删结点。
5. **忽略带头结点的优势**：由于有头结点，$\text{pre}$ 初始化为 $L$ 即可，不需要特判首元结点；如果不带头结点，则需额外处理删除首元结点时头指针的更新。
6. **空链表处理**：$p$ 初始为 $\text{NULL}$ 时循环直接结束，无需单独判断，但要注意不能对 `L->next` 进行非法访问。

**命题规律**：本题是 408 数据结构“线性表”部分的经典操作题，考查单链表删除操作中“前驱指针”的核心思想。命题变式常见有：删除链表中所有值为 $x$ 的结点、删除最小值结点、删除重复元素、删除倒数第 $k$ 个结点、将链表按值分组等。复习时应熟练掌握带头结点与不带头结点两种链表的操作区别，能画出删除过程的指针变化图，并写出完整可运行的 C 函数。建议把单链表的插入、删除、逆置、归并等基本操作整理成模板，反复默写，以应对大题中的“算法设计”题型。


> **原书解答（OCR）**
>
> 01.【解答】
> 解法 1：用 p 从头至尾扫描单链表，pre 指向*p 结点的前驱。若 p 所指结点的值为 x，则删除，并让 p 移向下一个结点，否则让 pre、p 指针同步后移一个结点。
> 本题代码如下：
> ```c
> void Del_X_1(Linklist &L,ElemType x){
>     LNode *p=L->next,*pre=L,*q;//置p和pre的初始值
>     while(p!=NULL){
>         if(p->data==x){
>             q=p;               //q指向被删结点
>             p=p->next;
>             pre->next=p;       //将*q结点从链表中断开
>             free(q);           //释放*q结点的空间
>         }
>         else{                 //否则，pre和p同步后移
>             pre=p;
>             p=p->next;
>         }//else
>     }//while
> }
> ```
> 本算法是在无序单链表中删除满足某种条件的所有结点，这里的条件是结点的值为 x。实际上，这个条件是可以任意指定的，只要修改 if 条件即可。比如，我们要求删除值介于 mink 和 maxk 之间的所有结点，只需将 if 语句修改为 if (p->data>mink&&p->data<maxk)。
> 解法 2：采用尾插法建立单链表。用 p 指针扫描 L 的所有结点，当其值不为 x 时，将其链接到 L 之后，否则将其释放。
> 本题代码如下：
> ```c
> void Del_X_2(Linklist &L,ElemType x){
>     LNode *p=L->next,*r=L,*q;  //r指向尾结点，其初值为头结点
>     while(p!=NULL){
>         if(p->data!=x){        // *p结点值不为x时将其链接到L尾部
>             r->next=p;
>             r=p;
>             p=p->next;         //继续扫描
>         }
>         else{                 // *p结点值为x时将其释放
>             q=p;
>             p=p->next;         //继续扫描
>             free(q);           //释放空间
>         }
>     }//while
>     r->next=NULL;              //插入结束后置尾结点指针为NULL
> }
> ```
> 上述两个算法扫描一遍链表，时间复杂度为 $O(n)$，空间复杂度为 $O(1)$。

# 综合题 第 16 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-Q16_题目.png|题目]]

16. 设有一个长度 $n$（$n$ 为偶数）的不带头结点的单链表，且结点值都大于 0，设计算法求这个单链表的最大孪生和。孪生和定义为一个结点值与其孪生结点值之和，对于第 $i$ 个结点（从 0 开始），其孪生结点为第 $n-i-1$ 个结点。要求：
1）给出算法的基本设计思想。
2）根据设计思想，采用 C 或 C++语言描述算法，关键之处给出注释。
3）说明你的算法的时间复杂度和空间复杂度.

## 答案

## DeepSeek V4 Flash Max 解析

**答案**：用快慢指针找到后半段起点，将后半段单链表原地逆置，再同步扫描前半段与逆置后的后半段，求所有孪生和并取最大值；时间复杂度 $O(n)$，空间复杂度 $O(1)$。

**解题切入点**：孪生对是“首尾对称”的，例如第 $0$ 个结点配第 $n-1$ 个结点，第 $1$ 个结点配第 $n-2$ 个结点。数组可以直接用双指针从两端向中间走，但单链表只能从 `head` 向后走，不能从尾部向前走。因此关键操作是：**先找中点，再把后半段链表反转**，让后半段能“从尾到头”访问。这类似于给单链表装上一个“反向指针”，从而把问题转化为两个链表的同步遍历。

**推演**：

设链表结点依次为  
$$p_0,p_1,p_2,\ldots,p_{n-1}$$

孪生对为：
$$
(p_0,p_{n-1}),\ (p_1,p_{n-2}),\ \ldots,\ (p_{\frac n2-1},p_{\frac n2})
$$

### 1. 基本设计思想

1. 用快慢指针找中点。`slow` 每次走一步，`fast` 每次走两步。当 `fast` 走到链表末尾时，由于 $n$ 是偶数，`slow` 正好指向第 $\frac n2$ 个结点，即后半段第一个结点 $p_{\frac n2}$。

2. 将从 `slow` 开始的后半段链表原地反转。反转后，原最后一个结点 $p_{n-1}$ 成为后半段的新表头，且：
   $$
   p_{n-1}\to p_{n-2}\to\cdots\to p_{\frac n2}\to \text{NULL}
   $$

3. 用两个指针：
   - `p` 从原链表头 $p_0$ 开始；
   - `q` 从逆转后的后半段表头 $p_{n-1}$ 开始。

   同步向后遍历，每次都计算：
   $$
   \text{sum}=p\text{->data}+q\text{->data}
   $$
   不断更新最大值。因为 $q$ 恰好按照 $p_{n-1},p_{n-2},\ldots,p_{\frac n2}$ 的顺序移动，所以第 $k$ 次比较的就是：
   $$
   p_k + p_{n-1-k}
   $$

   恰好覆盖所有孪生对。

### 2. 算法代码

```cpp
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode;

int maxTwinSum(LNode *head) {
    if (head == NULL || head->next == NULL) {
        return 0;   // 空表或长度不足，题目保证 n 为偶数，这里做防御
    }

    // 1. 快慢指针找中点
    LNode *slow = head;
    LNode *fast = head;

    while (fast != NULL && fast->next != NULL) {
        slow = slow->next;         // 慢指针走一步
        fast = fast->next->next;   // 快指针走两步
    }
    // 此时 slow 指向后半段第一个结点，即 p_{n/2}

    // 2. 反转后半段链表
    LNode *prev = NULL;
    LNode *cur = slow;
    while (cur != NULL) {
        LNode *nxt = cur->next;   // 先保存后继
        cur->next = prev;         // 反转指针方向
        prev = cur;
        cur = nxt;
    }

    // 3. 前半段与反转后的后半段同步扫描
    LNode *p = head;      // 前半段头
    LNode *q = prev;      // 后半段反转后的头，即原链表最后一个结点
    int maxSum = 0;       // 题目说明结点值都大于 0

    while (q != NULL) {
        int sum = p->data + q->data;
        if (sum > maxSum) {
            maxSum = sum;
        }
        p = p->next;
        q = q->next;
    }

    return maxSum;
}
```

### 3. 复杂度分析

- 找中点：快慢指针扫描约 $\frac n2$ 轮，时间复杂度 $O(n)$；
- 反转后半段：只需处理 $\frac n2$ 个结点，时间复杂度 $O(n)$；
- 同步扫描求最大孪生和：共比较 $\frac n2$ 对，时间复杂度 $O(n)$。

因此总时间复杂度为：
$$
O(n)
$$

整个算法只使用了若干个指针变量，没有额外使用数组或递归栈，因此辅助空间为：
$$
O(1)
$$

**易错点**：

1. **中点定位错误**。奇数长度和偶数长度对“中点”的定义不同。本题 $n$ 为偶数，应使用：
   ```cpp
   while (fast != NULL && fast->next != NULL)
   ```
   这样 `slow` 才指向 $p_{\frac n2}$。如果写成 `fast->next != NULL && fast->next->next != NULL`，`slow` 会指向 $p_{\frac n2-1}$，导致后半段划分错误。

2. **反转时丢失后继结点**。反转链表时，必须先保存 `cur->next`，再修改 `cur->next = prev`。否则原后继丢失，链表断裂。

3. **反转后 `q` 的起点错误**。后半段反转后，新表头是原来的尾结点，即代码中的 `prev`，不是 `slow`。因为 `slow` 在经过反转后已经变成了后半段的尾结点，它的 `next` 为 `NULL`。

4. **循环次数控制不当**。用 `while (q != NULL)` 最安全，因为反转后的后半段长度正好是 $\frac n2$，循环结束后恰好比较完全部孪生对。

5. **最大值初值问题**。本题结点值都大于 $0$，所以 `maxSum` 初始化为 $0$ 是安全的。如果题目没有这个条件，应初始化为 `INT_MIN`，或者先取第一对孪生和作为初值。

**命题规律**：本题是链表综合题中的高频题型，核心考点是**快慢指针找中点**、**链表原地反转**和**双指针同步遍历**。408 中类似变式很多，例如：判断链表是否回文、重排链表为 $L_0\to L_n\to L_1\to L_{n-1}\to\cdots$、求链表倒数第 $k$ 个结点等。复习时要熟练掌握“快慢指针 + 反转链表”这一套组合技巧，注意边界条件和指针修改顺序。这类题通常要求 $O(n)$ 时间、$O(1)$ 空间，避免使用数组或递归栈。

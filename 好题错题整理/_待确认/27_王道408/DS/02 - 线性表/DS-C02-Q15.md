# 综合题 第 15 题

15. 单链表有环，是指单链表的最后一个结点的指针指向了链表中的某个结点（通常单链表的最后一个结点的指针域是空的）。试编写算法判断单链表是否存在环。
1）给出算法的基本设计思想。
2）根据设计思想，采用 C 或 C++语言描述算法，关键之处给出注释。
3）说明你所设计算法的时间复杂度和空间复杂度。

## DeepSeek V4 Flash Max 解析

**答案**：使用快慢指针判断单链表是否有环；若快指针最终为空则无环，若快指针与慢指针相遇则有环。时间复杂度 $O(n)$，空间复杂度 $O(1)$。

**解题切入点**：拿到题先想“链表有环会造成遍历不终止”。可以类比两人同向绕圈跑步：速度不同，若有圈，快者一定会追上慢者；若无圈，快者会先到终点。因此只需要设置两个移动速度不同的指针，看它们是否会相遇。

**推演**：

### 1）算法的基本设计思想

设两个指针 $slow$ 和 $fast$，初始都指向头结点 $head$。$slow$ 每次移动一个结点，$fast$ 每次移动两个结点。

- 若链表无环，则 $fast$ 会先到达链表尾部，即出现 `fast == NULL` 或 `fast->next == NULL`，此时停止并判断为无环。
- 若链表有环，则 $fast$ 永远不会遇到 `NULL`，并且由于 $fast$ 每次比 $slow$ 多走一步，二者在环内必然相遇。

**正确性证明**：设链表环入口为 $E$，头结点到 $E$ 的距离为 $a$，环长为 $r$。当 $slow$ 第一次到达 $E$ 时，$fast$ 已在环内，设它沿运动方向距离 $E$ 为 $d$（$0 \le d < r$）。若 $d = 0$，二者在 $E$ 处相遇；若 $d > 0$，$fast$ 每轮比 $slow$ 多前进 $1$ 个结点，因此需要 $r - d$ 轮追上，不超过 $r$ 轮。所以只要存在环，二者必然相遇。

### 2）算法描述（C++）

```cpp
bool hasCycle(ListNode *head) {
    if (head == nullptr || head->next == nullptr)
        return false;          // 空表或只有一个结点，不可能成环

    ListNode *slow = head;
    ListNode *fast = head;

    while (fast != nullptr && fast->next != nullptr) {
        slow = slow->next;          // 慢指针走一步
        fast = fast->next->next;    // 快指针走两步

        if (slow == fast)           // 指向同一个结点，说明有环
            return true;
    }

    return false;   // fast 到达链表末尾，说明无环
}
```

注意：循环条件必须同时判断 `fast` 和 `fast->next` 是否为空，否则访问空指针会出现错误。

### 3）时间复杂度与空间复杂度

- 无环时，$fast$ 每次前进 $2$ 步，循环最多约 $n/2$ 次，时间复杂度为 $O(n)$。
- 有环时，$slow$ 进入环后最多再走 $r$ 步即与 $fast$ 相遇，而到环入口前最多走 $a$ 步；因为总节点数 $n = a + r$，所以 $slow$ 总步数不超过 $n$，$fast$ 总步数不超过 $2n$，时间复杂度仍为 $O(n)$。
- 只使用了两个指针，空间复杂度为 $O(1)$。

**易错点**：

- 忘记判断 `fast->next` 是否为空，导致空指针解引用。循环条件应写成 `fast != nullptr && fast->next != nullptr`。
- 快慢指针初始位置通常都设为 `head`，不能在 `while` 中先判断 `slow == fast` 再移动，因为初始时二者都指向头结点，会误判为有环。
- 判断相遇必须用指针地址相等 `slow == fast`，不能比较结点值，因为链表中可能存在重复值。
- 快指针步长应固定为 $2$。若步长过大，速度差大于 $1$，可能造成“跳过”相遇点，且证明复杂，无法保证一定相遇。
- 要单独处理空链表和只有一个结点的情况，避免访问非法内存。

**命题规律**：本题是链表“是否存在环”的经典双指针问题，属于 408 数据结构线性表中链表的常考综合题。核心考点是快慢指针的相遇判定与复杂度分析。常见变式有：求环的入口结点、求环的长度、判断两个链表是否相交（可转化为是否有环）。复习时应熟练掌握双指针的数学推导，能独立写出无 bug 的 C/C++ 代码，并注意边界条件，如空表、单结点、整表成环等。

> 15. 【解答】
> 1) 算法的基本设计思想：
> 设置快慢两个指针分别为fast和slow最初都指向链表头head。slow每次走一步，即 slow=slow->next; fast每次走两步，即fast=fast->next->next。fast比slow走得快，若有环，则fast一定先进入环，而slow后进入环。两个指针都进入环后，经过若干操作后两个指针定能在环上相遇。这样就可以判断一个链表是否有环。
> 如下图所示，当slow刚进入环时，fast早已进入环。因为fast每次比slow多走一步且fast与slow的距离小于环的长度，所以fast与slow相遇时，slow所走的距离不超过环的长度。
> 【图：快慢指针在链表环中相遇的示意图】
> 如下图所示，设头结点到环的入口点的距离为 a，环的入口点沿着环的方向到相遇点的距离为 x，环长为 r，相遇时 fast 绕过了 n 圈。
> a
> 则有 $2(a+x)=a+n \cdot r+x$，即 $a=nr-x$。显然从头结点到环的入口点的距离等于 $n$ 倍的环长减去环的入口点到相遇点的距离。因此可设置两个指针，一个指向 head，另一个指向相遇点，两个指针同步移动（均为一次走一步），相遇点即环的入口点。
> 2) 本题代码如下：
> ```c
> LNode* FindLoopStart(LNode *head) {
>     LNode *fast=head, *slow=head;   //设置快慢两个指针
>     while(fast!=NULL&&fast->next!=NULL) {
>         slow=slow->next;            //每次走一步
>         fast=fast->next->next;      //每次走两步
>         if(slow==fast)  break;      //相遇
>     }
>     if(fast==NULL||fast->next==NULL)
>         return NULL;                 //没有环，返回NULL
>     LNode *p1=head, *p2=slow ;      //分别指向开始点、相遇点
>     while(p1!=p2){
>         p1=p1->next;
>         p2=p2->next;
>     }
>     return p1;                       //返回入口点
> }
> ```
> 3) 当 fast 与 slow 相遇时，slow 肯定没有遍历完链表，故算法的时间复杂度为 $O(n)$，空间复杂度为 $O(1)$。

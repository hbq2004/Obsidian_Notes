# 综合题 第 4 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-Q04_题目.png|题目]]

04. 设在一个带表头结点的单链表中, 所有结点的元素值无序, 试编写一个函数, 删除表中所有处于给定的两个值（作为函数参数给出）之间的元素（若存在）.

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C02-Q04_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：  
对带头结点的无序单链表，应采用线性扫描，用前驱指针逐个检查并摘除所有满足  
$$
l=\min(a,b),\quad h=\max(a,b),\quad l<\text{data}<h
$$
的结点；时间复杂度 $O(n)$，空间复杂度 $O(1)$。  
（若题意要求包含端点，则将条件改为 $l\le \text{data}\le h$。）

**解题切入点**：  
先抓题眼：“无序”意味着不能像有序表那样找到区间边界后提前停止，必须遍历到表尾；“带头结点”意味着删除首元结点也有统一的前驱；“删除所有”意味着删完一个后还要继续检查下一个元素。

可以类比“队伍清人”：要删除某个人，必须记住他前面那个人是谁，否则链表会断。头结点就是这个队伍的固定队首，它让我们删除第一个元素时也不需要特殊处理。

**推演**：  

设单链表结点定义如下：

```c
typedef int ElemType;

typedef struct LNode {
    ElemType data;
    struct LNode *next;
} LNode, *LinkList;
```

若给定的两个值大小未定，先取：

$$
l=\min(a,b),\quad h=\max(a,b)
$$

若题目已保证 $a<b$，则直接令 $l=a,h=b$。

核心代码如下：

```c
void DelBetween(LinkList head, ElemType a, ElemType b) {
    if (head == NULL) {
        return;
    }

    ElemType l = a < b ? a : b;
    ElemType h = a < b ? b : a;

    LNode *pre = head;   // pre 始终指向待检查结点的前驱

    while (pre->next != NULL) {
        // 若当前待检查结点位于 l 和 h 之间，则删除
        if (pre->next->data > l && pre->next->data < h) {
            LNode *q = pre->next;   // q 是要删除的结点
            pre->next = q->next;    // 先接链
            free(q);                // 再释放
        } else {
            // 当前结点安全，前驱后移
            pre = pre->next;
        }
    }
}
```

正确性说明：  
每次循环检查 `pre->next`。若该结点在区间内，则摘下它并释放，此时 `pre` 不动，因此下一个结点仍会被继续检查，不会因连续删除而漏删；若该结点不在区间内，则 `pre` 后移到该结点，表示它已被保留。循环结束时 `pre->next == NULL`，说明所有数据结点都被检查过，区间内的结点均被删除。

复杂度分析：  
设链表共有 $n$ 个数据结点，每个结点至多被检查一次，每次检查、删除操作都是 $O(1)$，因此：

$$
T(n)=O(n),\quad S(n)=O(1)
$$

**易错点**：  

1. **断链顺序错误**：不能先 `free(q)` 再使用 `q->next`，必须先让前驱结点指向删除结点的后继，再释放结点。  
2. **删除后 `pre` 直接后移**：连续删除时会漏删；删除后 `pre` 应保持不变，继续检查新的 `pre->next`。  
3. **没有处理 $a,b$ 大小关系**：若 $a>b$ 而不取 $\min,\max$，会导致判断条件错误。  
4. **边界判断不清**：不含端点用 `> l && < h`；含端点用 `>= l && <= h`。  
5. **误用有序表思想**：本题链表元素无序，不能遇到一个不在区间内的结点就停止，必须扫描到表尾。  
6. **忘记释放被删结点空间**：在 408 中删除链表结点通常要求释放空间，否则造成内存泄漏。

**命题规律**：  
本题是“单链表遍历删除”的模板题，核心考点是：前驱指针的维护、带头结点的优势、删除操作的断链顺序、时间空间复杂度分析。

常见变式包括：

- 删除单链表中所有值等于给定值 $x$ 的结点；
- 删除递增有序链表中值位于 $[l,r]$ 区间内的结点；
- 删除无序链表中的重复元素；
- 保留链表中介于某区间内的元素，删除区间外的元素。

复习时应把“带头结点/不带头结点”“前驱指针维护”“先接链再释放”作为固定套路，并手画链表模拟“首结点删除”“连续删除”“删除尾结点”三种情况。

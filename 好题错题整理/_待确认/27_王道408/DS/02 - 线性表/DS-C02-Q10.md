# 综合题 第 10 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-Q10_题目.png|题目]]

10. 两个整数序列 $A = a_1, a_2, a_3, \cdots, a_m$ 和 $B = b_1, b_2, b_3, \cdots, b_n$ 已经存入两个单链表中，设计一个算法，判断序列 $B$ 是否是序列 $A$ 的连续子序列.

## 答案

## DeepSeek V4 Flash Max 解析

**答案**：采用朴素模式匹配思想，依次以 $A$ 中每个结点为起点，将 $B$ 作为“模式串”与 $A$ 从该起点开始的连续段逐结点比较；若某次 $B$ 能全部匹配完，则返回真，否则继续向后移动起点。时间复杂度 $O(mn)$，空间复杂度 $O(1)$。

**解题切入点**：看到“连续子序列”应立刻联想到字符串/序列匹配，核心是“从每个可能起点试一次”。链表不能随机访问，也不能往前回退，所以要用两个角色分开的指针：外层指针保存当前匹配起点，内层指针负责向后比较。这就像在一串珠子中找一段连续花色：固定一段起点，依次比对花色，失败就把起点往后移动一颗珠子再看。

**推演**：

设 $A$ 的长度为 $m$，$B$ 的长度为 $n$，两个单链表均带头结点，则 $A \to \text{next}$ 才是 $A$ 的第一个数据结点，$B \to \text{next}$ 是 $B$ 的第一个数据结点。

算法步骤：

1. 若 $B$ 为空，按串匹配惯例，空序列是任意序列的连续子序列，返回真。
2. 令 $pa$ 指向 $A$ 的首元结点。
3. 对每个起点 $pa$：
   - 令 $pb = B \to \text{next}$，即从 $B$ 的第一个结点开始比较；
   - 令 $pc = pa$，即从 $A$ 的当前起点开始比较；
   - 当 $pb \neq \text{NULL}$、$pc \neq \text{NULL}$ 且二者数据相等时，同时后移；
   - 若 $pb$ 变成 $\text{NULL}$，说明 $B$ 已全部匹配成功，返回真；
   - 否则说明该起点失配，令 $pa = pa \to \text{next}$，检查下一个起点。
4. 若循环结束仍未成功匹配，返回假。

关键代码：

```c
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;

bool IsContinuousSubSeq(LinkList A, LinkList B) {
    if (B->next == NULL) return true;          // 空 B 特判
    LNode *pa = A->next;                        // A 的当前匹配起点
    while (pa != NULL) {
        LNode *pb = B->next;                    // 每次都从 B 的第一个结点开始
        LNode *pc = pa;                         // 工作指针，不能用 pa 自身去移动
        while (pb != NULL && pc != NULL && pb->data == pc->data) {
            pb = pb->next;
            pc = pc->next;
        }
        if (pb == NULL) return true;            // B 已走完，说明匹配成功
        pa = pa->next;                          // 换下一个起点
    }
    return false;
}
```

正确性分析：

若算法返回真，则说明某个起点 $pa$ 开始，$B$ 的 $n$ 个结点与 $A$ 中从 $pa$ 开始的连续 $n$ 个结点一一对应且数据相等，因此 $B$ 确实是 $A$ 的连续子序列。

若 $B$ 确实是 $A$ 的连续子序列，设其起点是 $A$ 的第 $i$ 个结点。外层循环会依次取 $A$ 的每一个结点作为起点，当 $pa$ 恰好指向第 $i$ 个结点时，内层循环会依次比较 $A_i$ 与 $b_1$、$A_{i+1}$ 与 $b_2$、……、$A_{i+n-1}$ 与 $b_n$，因为对应数据全部相等，$pb$ 会走完整个 $B$ 而成为 $\text{NULL}$，算法返回真。外层不会跳过任何起点，因此不会漏解。

复杂度：

外层最多执行 $m$ 次，内层每次最多比较 $n$ 个结点，因此最坏时间复杂度为

$$
T(m,n)=O(mn)
$$

例如 $A$ 全部为相同数据，$B$ 的前 $n-1$ 个数据与 $A$ 相同而最后一个不同，则每个起点几乎都要比较到 $B$ 末尾才发现失败。算法只使用常数额外空间，故空间复杂度为 $O(1)$。

**易错点**：

- 直接让 $pa$ 参与内层移动，匹配失败后外层无法找到下一个起点。必须使用辅助指针 $pc$ 保存并移动当前位置。
- 内层 `while` 中漏写 `pc != NULL`。当 $A$ 剩余长度小于 $B$ 时，$pc$ 会先走到空，再访问 `pc->data` 会造成空指针错误。
- 每次换起点时忘记把 $pb$ 重新置为 $B$ 的首元结点。如果不重置，第二次匹配会从 $B$ 的中间位置开始比较，结果错误。
- 不明确链表是否带头结点。带头结点时首元结点是 `head->next`，无头结点时首元结点就是 `head` 本身；答题时应先说明约定。
- 将“连续子序列”误当成“子序列”。例如 $A=(1,2,3)$，$B=(1,3)$ 是子序列但不是连续子序列，本题应返回假。
- 对空 $B$ 的处理不统一。按模式匹配惯例应返回真；如果题目明确 $n \ge 1$，则可省略空 $B$ 特判。

**命题规律**：本题属于线性表链式存储与模式匹配的综合题，是 408 算法设计题常见题型。考点在于单链表遍历、指针控制和连续子串判断。常见变式有：判断 $A$ 是否是 $B$ 的连续子序列；返回 $B$ 在 $A$ 中首次出现的起始位置；要求输出所有匹配位置；将链表换成无头结点链表；或要求时间复杂度达到 $O(m+n)$。若要求线性时间，可先将两个链表中的值拷贝到数组中，再用 KMP 算法；但朴素法仍是链表题的基本功。复习时应重点练习“起点指针”和“工作指针”分离的思想，并养成先写明链表是否带头结点、再写循环条件的习惯。

> 10. 【解答】
> 算法思想：因为两个整数序列已存入两个链表中，操作从两个链表的第一个结点开始，若对应数据相等，则后移指针；若对应数据不等，则 A 链表从上次开始比较结点的后继开始，B 链表仍从第一个结点开始比较，直到 B 链表到尾表示匹配成功。A 链表到尾而 B 链表未到尾表示失败。操作中应记住 A 链表每次的开始结点，以便下次匹配时好从其后继开始。
> 本题代码如下：
> ```c
> int Pattern(LinkList A,LinkList B){
>     LNode *p=A;               //p 为 A 链表的工作指针，本题假定 A 和 B 均无头结点
>     LNode *pre=p;             //pre 记住每趟比较中 A 链表的开始结点
>     LNode *q=B;               //q 是 B 链表的工作指针
>     while(p&&q)
>         if(p->data==q->data){ //结点值相同
>             p=p->next;
>             q=q->next;
>         }
>         else{
>             pre=pre->next;
>             p=pre;             //A 链表新的开始比较结点
>             q=B;               //q 从 B 链表第一个结点开始
>         }
>     if(q==NULL)               //B 已经比较结束
>         return 1;             //说明 B 是 A 的子序列
>     else
>         return 0;             //B 不是 A 的子序列
> }
> ```

> 该题其实是字符串模式匹配的链式表示形式，读者应该结合字符串模式匹配的内容重新考虑能否优化该算法。

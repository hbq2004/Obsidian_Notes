## DeepSeek V4 Flash Max 解析

**答案**：利用 $|data|\le n$ 的值域限制，设置长度为 $n+1$ 的辅助标记数组，一趟扫描单链表；首次出现的绝对值保留并标记，再次出现的绝对值直接删除。时间复杂度为 $O(m)$（若严格计入辅助数组清零，则为 $O(n+m)$），空间复杂度为 $O(n)$。

**解题切入点**：看到 $|data|\le n$，要立刻想到“值域有界”，可以用数组下标直接对应绝对值，这是典型的“以空间换时间”。链表删除结点必须知道前驱，所以用 `pre` 指向前一个保留结点；这样去重查找从 $O(m)$ 降为 $O(1)$，总时间降到线性。

**推演**：

1. **基本设计思想**

数据绝对值只能是：
$$0,1,2,\dots,n$$
共 $n+1$ 个可能值。申请一个辅助标记数组 `visited[0..n]`，`visited[d]==0` 表示绝对值 $d$ 还没有出现过，`visited[d]==1` 表示已经出现过。

然后从头到尾扫描单链表：

- 若当前结点的绝对值 $d$ 未出现过，则保留该结点，并令 `visited[d]=1`；
- 若当前结点的绝对值 $d$ 已出现过，则说明当前结点不是第一次出现，删除该结点。

这样每个结点只被扫描一次，且保留的是每个绝对值第一次出现的结点。

2. **单链表结点类型定义**

```c
#include <stdlib.h>

typedef struct LNode {
    int data;               /* 数据域 */
    struct LNode *link;     /* 指针域 */
} LNode, *LinkList;
```

3. **C 语言算法描述**

```c
/* head 是带头结点单链表的头指针，n 是 |data| 的上界 */
void DeleteAbsEqual(LinkList head, int n) {
    if (head == NULL || head->link == NULL)
        return;

    /* 申请标记数组并清零，下标 0~n 分别对应绝对值 0~n */
    int *visited = (int *)calloc(n + 1, sizeof(int));
    if (visited == NULL)
        return;

    LNode *pre = head;          /* pre 指向已保留链表的最后一个结点 */
    LNode *p = head->link;      /* p 为当前待检查结点 */

    while (p != NULL) {
        int d = abs(p->data);   /* 取绝对值，0 <= d <= n */

        if (visited[d] == 0) {
            /* 该绝对值第一次出现，保留当前结点 */
            visited[d] = 1;
            pre = p;
            p = p->link;
        } else {
            /* 该绝对值已经出现过，删除当前结点 */
            pre->link = p->link;
            LNode *q = p;
            p = p->link;
            free(q);
        }
    }

    free(visited);
}
```

例如链表数据依次为 $21,-15,-15,-7,15$：

- $21$：绝对值 $21$，第一次出现，保留；
- $-15$：绝对值 $15$，第一次出现，保留；
- 第二个 $-15$：绝对值 $15$ 已出现，删除；
- $-7$：绝对值 $7$，第一次出现，保留；
- $15$：绝对值 $15$ 已出现，删除。

最终链表为 $21,-15,-7$，与题目要求一致。

4. **正确性与复杂度**

正确性：从链表头开始依次扫描，若某绝对值第一次出现，当前结点就是该绝对值的第一个结点，保留它不会丢失首次出现；若某绝对值已经出现过，则当前结点必为重复结点，删除后不影响“保留第一次出现结点”的要求。由于只是摘除结点，没有改变结点相对顺序，因此结果中每个绝对值只保留第一次出现的那个结点。

复杂度：

- 链表结点数为 $m$。每个结点最多被访问一次，保留或删除操作均为 $O(1)$，所以扫描链表部分为 $O(m)$；
- 辅助数组长度为 $n+1$，空间复杂度为 $O(n)$；
- 若把辅助数组清零的 $O(n)$ 也严格计入，则总时间复杂度为 $O(n+m)$。考研中常把扫描链表的线性时间记为 $O(m)$。

**易错点**：

- 不能直接用 `data` 作为数组下标，因为 `data` 可能为负数，必须先取绝对值。
- 数组大小要开 $n+1$，不是 $n$，因为绝对值可能是 $0$。
- 辅助数组必须初始化为 0，否则判断“是否出现过”会出错。
- 删除结点时必须用前驱指针 `pre` 链接后继，否则链表会断裂。
- 只有保留结点时才移动 `pre`；删除结点时 `pre` 不动。
- 删除后要释放结点空间，并正确移动到下一个待检查结点。
- 朴素二重循环遍历虽然空间 $O(1)$，但时间 $O(m^2)$，不符合本题“时间尽可能高效”的要求。

**命题规律**：

本题是“链表遍历删除 + 值域受限哈希/标记数组”的典型综合题。命题人给出 $|data|\le n$，就是为了引导考生用辅助数组降低查找时间。常见变式有：

- 将“绝对值相等”改为“数值相等”，此时标记数组下标可以平移或直接使用哈希表；
- 去掉 $|data|\le n$ 条件，则可用哈希表记录已出现元素，期望时间 $O(m)$、空间 $O(m)$；
- 若限制不允许使用辅助空间，则只能退化为二重循环删除，时间 $O(m^2)$。

复习时应重点掌握“链表删除必须知道前驱”“值域有界用数组标记”“时间与空间复杂度权衡”这三个要点。

# 综合题 第 14 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-Q14_题目.png|题目]]

14. 设将$n(n>1)$个整数存放到不带头结点的单链表$L$中，设计算法将$L$中保存的序列循环右移$k(0<k<n)$个位置。例如，若$k=1$，则将链表$\{0,1,2,3\}$变为$\{3,0,1,2\}$。要求:
1) 给出算法的基本设计思想。
2) 根据设计思想，采用C或C++语言描述算法，关键之处给出注释.
3) 说明你所设计算法的时间复杂度和空间复杂度.

## 答案

## DeepSeek V4 Flash Max 解析

**答案**：算法通过遍历链表得到长度，并找到第 $n-k$ 个节点作为新尾节点，调整指针使链表循环右移 $k$ 个位置，时间复杂度 $O(n)$，空间复杂度 $O(1)$。

**解题切入点**：首先理解循环右移的本质是将链表的后 $k$ 个节点整体移动到链表的前面，相当于将链表在某个位置断开然后重新拼接。由于是单链表，不能随机访问，需要先确定断点的位置，即正数第 $n-k$ 个节点（倒数第 $k+1$ 个节点）。因此核心是遍历链表求长度并定位该节点，同时注意保存尾节点。

**推演**：

设链表长度为 $n$，将序列循环右移 $k$ 个位置，等价于将链表分成两段：前 $n-k$ 个节点（记为 $A$ 段）和后 $k$ 个节点（记为 $B$ 段），则移动后变为 $B$ 段接 $A$ 段。因此需要找到 $A$ 段的尾节点（即第 $n-k$ 个节点）和 $B$ 段的尾节点（即原链表的尾节点）。

具体算法步骤：
1. 遍历链表，计算节点个数 $n$，同时记录尾节点 $tail$。
2. 找到第 $n-k$ 个节点 $p$（即 $A$ 段的尾节点）。
3. 令 $p->next = NULL$，将 $tail->next$ 指向原头结点 $head$，并返回 $p->next$ 作为新头结点（即 $B$ 段的第一个节点）。

注意：题目限定 $0<k<n$，因此 $n-k \ge 1$，$p$ 一定存在。若考虑一般情况，可先对 $k$ 取模 $k = k \% n$，再处理 $k=0$ 的情况。

时间复杂度：遍历链表一次计算长度并定位节点，共 $O(n)$ 次操作，空间复杂度 $O(1)$。

C语言实现（关键代码）：
```c
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;

LinkList RightShift(LinkList head, int k) {
    if (head == NULL || head->next == NULL) // 空表或只有一个节点，直接返回
        return head;
    // 计算长度并找尾节点
    int n = 1;
    LinkList p = head;
    while (p->next != NULL) {
        n++;
        p = p->next;
    }
    LinkList tail = p;  // 尾节点
    // 题目保证 k < n，故无需取模，但可加上 k %= n; if (k == 0) return head;
    // 找到第 n-k 个节点
    int steps = n - k - 1; // 从 head 开始需要移动的步数
    p = head;
    while (steps > 0) {
        p = p->next;
        steps--;
    }
    // 此时 p 指向第 n-k 个节点，即新链表的尾节点
    LinkList newHead = p->next; // 新头结点
    p->next = NULL;             // 断开 A 段与 B 段
    tail->next = head;          // B 段尾接 A 段头
    return newHead;
}
```

**易错点**：
- 忽视链表不带头结点，头指针直接指向第一个节点，更新头指针时必须返回新头或使用二级指针。
- 在定位第 $n-k$ 个节点时，步数计算容易出错（例如 $n=2, k=1$ 时，$n-k-1=0$，$p$ 即为头结点，正确）。
- 指针操作顺序：先保存新头（$p->next$），再断开，最后连接尾与头，否则可能丢失节点。
- 虽然题目给定 $0<k<n$，但实际编程时最好考虑 $k$ 可能等于 $0$ 或 $n$ 的情况，取模后处理。

**命题规律**：
- 考点：单链表的遍历、长度计算、指针修改，以及循环移位的等价变换。
- 常见变式：
  - 循环左移 $k$ 个位置（只需找到第 $k$ 个节点断开，将原尾接原头，返回第 $k+1$ 个节点）。
  - 带头结点的单链表：操作类似，但头结点固定，注意返回时需更新头结点的 next 指针。
  - 双向链表：循环移位思路相同，但需同时修改前驱指针。
  - $k$ 可能大于等于 $n$：此时需先取模 $k \%= n$，再处理 $k=0$ 的情况。
- 复习建议：熟练掌握链表的基本操作（遍历、插入、删除、逆置等），理解循环移位与分段拆接的关系，强化边界条件（如 $n=1, k=0$ 等）的测试。

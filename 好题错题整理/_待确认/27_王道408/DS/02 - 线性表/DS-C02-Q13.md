# 综合题 第 13 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-Q13_题目.png|题目]]

13. 设有一个带头结点的非循环双链表 L，其每个结点中除有 pre、data 和 next 域外，还有一个访问频度域 freq，其值均初始化为零。每当在链表中进行一次 Locate(L,x) 运算时，令值为 x 的结点中 freq 域的值增 1，并使此链表中的结点保持按访问频度递减的顺序排列，且最近访问的结点排在频度相同的结点之前，以便使频繁访问的结点总是靠近表头。试编写符合上述要求的 Locate(L,x) 函数，返回找到结点的地址，类型为指针型。

## DeepSeek V4 Flash Max 解析

**答案**：
`Locate(L,x)` 的核心是：先线性查找数据域为 $x$ 的结点 $p$，若不存在则返回 `NULL`；否则令 `p->freq++`，将 $p$ 从原位置摘下，再从表头找到第一个频度不大于 `p->freq` 的结点 $q$，把 $p$ 插到 $q$ 之前；若 $q$ 不存在则插入表尾。这样始终保证链表按频度递减，且同频结点中最近访问的在前。时间复杂度 $O(n)$，空间复杂度 $O(1)$。

**解题切入点**：
看到“访问频度 + 最近访问 + 双链表”，应立刻想到这是“动态维护有序链表”，不是每次重新排序。可以类比图书馆热门书榜：每次借阅，把某本书的次数加 1，再把它插入到合适位置。双链表的作用是让“摘下结点”和“插入结点”都能 $O(1)$ 完成；真正的难点是确定插入位置：应该越过所有频度更大的结点，停在第一个 `freq <= p->freq` 的结点前，而不是停在 `freq < p->freq` 的结点前，否则同频结点中“最近访问在前”的要求会被破坏。

**推演**：

设结点类型为：

```c
typedef struct DNode {
    ElemType data;
    int freq;
    struct DNode *pre, *next;
} DNode, *DLinkList;
```

维护不变量：链表中任意时刻按 `freq` 递减排列；若两个结点 `freq` 相同，则先被访问的结点排在后面，最近访问的排前面。

算法步骤：

1. 从 `L->next` 开始查找 `data == x` 的结点 $p$；
2. 若找不到，返回 `NULL`；
3. 令 `p->freq++`；
4. 把 $p$ 从当前双链表中摘下；
5. 从表头开始找插入点 $q$：$q$ 是第一个满足 `q->freq <= p->freq` 的结点；
6. 将 $p$ 插入到 $q$ 之前；若 $q$ 为 `NULL`，则插入到表尾。

对应函数如下：

```c
DNode* Locate(DLinkList L, ElemType x) {
    DNode *p = L->next;

    // 查找值为 x 的结点
    while (p != NULL && p->data != x)
        p = p->next;
    if (p == NULL)
        return NULL;          // 不存在值为 x 的结点

    p->freq++;                // 访问次数加 1

    // 1. 把 p 从原位置摘下
    p->pre->next = p->next;
    if (p->next != NULL)
        p->next->pre = p->pre;

    // 2. 找插入位置
    DNode *r = L;             // r 是 q 的前驱
    DNode *q = L->next;       // q 指向第一个 freq <= p->freq 的结点

    while (q != NULL && q->freq > p->freq) {
        r = q;
        q = q->next;
    }

    // 3. 将 p 插入到 r 与 q 之间
    p->pre = r;
    p->next = q;
    r->next = p;
    if (q != NULL)
        q->pre = p;

    return p;
}
```

为什么这样能保持有序？设 `p->freq` 增加后为 $f$。摘除 $p$ 后，剩余链表仍然保持原来的相对顺序，因此仍是有序的。接着从表头扫描，跳过所有 `freq > f` 的结点，停在第一个 `freq <= f` 的结点 $q$ 前。因此 $p$ 的前驱频度一定大于 $f$，后继频度一定不大于 $f$。

若后继频度等于 $f$，则由于 $p$ 是刚刚被访问的，它应该排在所有同频结点之前，而插入到 $q$ 前正好满足这一点；若后继频度小于 $f$，也不破坏递减性；若 $q$ 为 `NULL`，则 $p$ 成为表尾，同样合法。

**易错点**：

1. **插入位置找成 `freq < p->freq`**：这是最容易犯的错误。若使用 `<`，则 $p$ 会被插到同频结点的后面，违反“最近访问的结点排在频度相同的结点之前”。必须找第一个 `freq <= p->freq` 的结点。
2. **摘下结点时漏掉后继的 `pre` 指针**：双链表删除必须同时修改前驱的 `next` 和后继的 `pre`；若 `p->next` 为 `NULL`，不能访问 `p->next->pre`。
3. **找到 $x$ 后不摘除直接交换相邻结点**：因为 $p$ 可能要跨过多个结点向前移动，只交换相邻结点无法一次完成，必须先摘除再插入。
4. **未处理 $x$ 不存在的情况**：若 `p == NULL` 仍执行 `p->freq++` 会空指针异常；题目若保证一定存在，可以省略该判断，但写上空判更严谨。
5. **尾插情况漏处理**：当 $q$ 为 `NULL` 时，不能用 `q->pre = p`，需要把 $p$ 接到链表尾部。

**命题规律**：
本题是 408 线性表大题中的典型“查找 + 删除 + 插入”组合题，考查双链表指针修改和动态有序维护。常见变式包括：改成循环双链表、增加尾指针、同频时按“先进先出”排列、只要求按频度递减不要求同频顺序、或把链表换成静态链表等。复习时建议把双链表的插入删除过程画图理解，特别注意空指针和指针修改顺序；同时要能说明时间复杂度和空间复杂度：本题两次线性扫描均为 $O(n)$，辅助空间为 $O(1)$。

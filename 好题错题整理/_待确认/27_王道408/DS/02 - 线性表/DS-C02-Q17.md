## DeepSeek V4 Flash Max 解析

**答案**：采用“固定距离双指针”（尺取法）：
令两个指针 $p,q$ 都指向第一个数据结点；$p$ 先向前走 $k$ 步，然后 $p,q$ 同步后移。当 $p$ 到达表尾 `NULL` 时，$q$ 正好指向倒数第 $k$ 个结点。时间复杂度 $O(n)$，空间复杂度 $O(1)$。

**解题切入点**：单链表只能从表头向表尾单向移动，题目又要求不改变链表，所以不能先反转再找。倒数第 $k$ 个结点本质上是正数第 $n-k+1$ 个结点，但 $n$ 未知。此时可用“两把相距 $k$ 的尺子”的思想：后面一把尺子的起点，就是要求的结点。这就是链表双指针中的“固定距离追赶”，类似两个运动员保持 $k$ 步间距跑到终点。

**推演**：

设链表数据结点为 $a_1,a_2,\dots,a_n$，则倒数第 $k$ 个结点是 $a_{n-k+1}$，其中 $1\le k\le n$；若 $k>n$，查找失败。

算法基本设计思想：

1. 初始化两个指针 $p,q$ 都指向第一个数据结点，即 `list->link`。
2. 让 $p$ 先走 $k$ 步。若在走满 $k$ 步之前 $p$ 已经为 `NULL`，说明链表结点数少于 $k$，返回 0。
3. 然后让 $p,q$ 同步向后移动，直到 $p$ 为 `NULL`。
4. 此时 $q$ 恰好指向倒数第 $k$ 个结点，输出 `q->data` 并返回 1。

详细实现步骤：

- 若 `list == NULL` 或 `k <= 0`，返回 0。
- 令 `p = q = list->link`。
- 执行循环 `for (i = 0; i < k; i++)`：
  - 若 `p == NULL`，说明结点数不足 $k$，返回 0；
  - 否则 `p = p->link`。
- 执行循环 `while (p != NULL)`：
  - `p = p->link`；
  - `q = q->link`。
- 输出 `q->data`，返回 1。

正确性说明：

$p$ 先走 $k$ 步后，从 $q$ 到 $p$ 之前（不含 $p$）正好有 $k$ 个结点。之后 $p,q$ 同步移动，这个“相距 $k$ 个结点”的窗口保持不变。当 $p$ 到达表尾后的 `NULL` 时，从 $q$ 到尾结点正好有 $k$ 个结点，因此 $q$ 就是倒数第 $k$ 个结点。

C 语言代码如下：

```c
#include <stdio.h>

typedef int ElemType;

typedef struct LNode {
    ElemType data;
    struct LNode *link;
} LNode, *LinkList;

int SearchK(LinkList list, int k) {
    LNode *p, *q;
    int i;

    if (list == NULL || k <= 0)
        return 0;               // 输入保护；题目已保证 k 为正整数

    p = q = list->link;         // p、q 都指向第一个数据结点

    // p 先走 k 步
    for (i = 0; i < k; i++) {
        if (p == NULL)
            return 0;           // 链表结点数少于 k，查找失败
        p = p->link;
    }

    // p、q 同步前进
    while (p != NULL) {
        p = p->link;
        q = q->link;
    }

    // 此时 q 指向倒数第 k 个结点
    printf("%d", q->data);      // 若 ElemType 不是 int，按实际类型输出
    return 1;
}
```

复杂度分析：

设链表数据结点个数为 $n$。$p$ 从头到尾遍历一次链表，$q$ 最多移动 $n-k$ 步，故时间复杂度为 $O(n)$；只使用了两个指针，空间复杂度为 $O(1)$。

**易错点**：

1. **把表头结点当成第一个数据结点**。  
   本题链表带有表头结点，所以 $p,q$ 应初始化为 `list->link`，而不是 `list`。否则计数会出错。

2. **当表长恰好等于 $k$ 时误判失败**。  
   例如链表有 3 个结点且 $k=3$，$p$ 先走 3 步后恰好为 `NULL`，这时应输出第一个结点并返回 1，而不是返回 0。  
   正确判断是：**在走满 $k$ 步之前**遇到 `NULL` 才失败。

3. **未处理 $k>$ 表长的情况**。  
   如果 $k$ 大于链表长度，$p$ 会在循环中变成 `NULL`，必须先判断再移动，否则可能发生空指针解引用。

4. **把 data 值作为函数返回值**。  
   题目要求返回 1 或 0 表示成功或失败，data 值应输出，不能用函数返回值代替。

5. **尝试修改链表**。  
   例如反转链表或改变 `link` 方向，不符合题目“不改变链表”的要求；双指针法只读不写，符合题意。

**命题规律**：本题是 408 线性表双指针类算法题的经典母题，核心考点是单链表遍历、倒数第 $k$ 个结点与固定距离窗口的关系、边界条件处理。常见变式有：查找链表的中间结点、判断链表是否有环、找环的入口、删除倒数第 $k$ 个结点、求两个链表交点等。复习时建议多画图模拟指针移动，尤其注意表头结点、空链表、$k$ 等于表长、$k$ 大于表长这几类边界情况；算法题作答时要同时给出设计思想、实现步骤、代码和复杂度分析。

> 问题的关键是设计一个尽可能高效的算法，通过链表的一次遍历，找到倒数第 $k$ 个结点的位置。定义两个指针变量 $p$ 和 $q$，初始时均指向头结点的下一个结点（链表的第一个结点），$p$ 指针沿链表移动；当 $p$ 指针移动到第 $k$ 个结点时，$q$ 指针开始与 $p$ 指针同步移动；当 $p$ 指针移动到最后一个结点时，$q$ 指针所指示结点为倒数第 $k$ 个结点。以上过程对链表仅进行一遍扫描。

> ③ 若 count 等于 $k$，则 $q$ 指向下一个结点；否则，count=count+1。
> ④ $p$ 指向下一个结点，转②。
> ⑤ 若 count 等于 $k$，则查找成功，输出该结点的 data 域的值，返回 1；否则，说明 $k$ 值超过了线性表的长度，查找失败，返回 0。

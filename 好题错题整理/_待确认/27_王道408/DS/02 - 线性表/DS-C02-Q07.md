# 综合题 第 7 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-Q07_题目.png|题目]]

07. 在一个递增有序的单链表中，存在重复的元素。设计算法删除重复的元素，例如 (7, 10, 10, 21, 30, 42, 42, 42, 51, 70) 将变为 (7, 10, 21, 30, 42, 51, 70)。

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C02-Q07_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：利用递增有序单链表中重复元素必然相邻的性质，从链表头部单遍扫描，凡是当前结点与后继结点值相同就删除后继结点，最终每个值只保留第一次出现的结点；时间复杂度 $O(n)$，空间复杂度 $O(1)$。

**解题切入点**：拿到题先抓“递增有序”和“单链表”。递增有序说明重复元素不是分散的，而是连续成段，因此无需哈希表或二重循环；单链表的特点是只能向后访问，且删除后继结点只需修改一次 `next` 指针。可以把它看作有序数组去重中的“快慢指针”在链表上的实现：$p$ 相当于慢指针，指向已去重部分的最后一个结点；每次检查 $p$ 和后继。

**推演**：假设链表带头结点，$L$ 为头指针。设 $p$ 指向当前已经去重部分的最后一个结点，初始 $p=L\to next$。循环条件为 $p\neq NULL$ 且 $p\to next\neq NULL$。令 $q=p\to next$。

1. 若 $p\to data = q\to data$，说明 $q$ 是重复结点，应该删除：
$$
p\to next = q\to next,\quad \text{释放 } q。
$$
删除后 $p$ **不移动**，因为 $p$ 的新后继仍可能有相同的值，例如 $42,42,42$ 需要连续删除两个后继。

2. 若 $p\to data \ne q\to data$，说明 $q$ 是第一次出现的新值，保留 $q$ 并令 $p=q$，继续检查后面的结点。

以题中数据为例，链表为
$$
(7,10,10,21,30,42,42,42,51,70)。
$$
指针 $p$ 先到 7，遇到 10 不同则到 10；10 的后继还是 10，删除第二个 10；此时 10 的后继变为 21，不同，$p$ 到 21；同理，到 42 后连续删除两个后继 42，直到后继为 51。最终得到
$$
(7,10,21,30,42,51,70)。
$$

正确性由循环不变量保证：每次比较前，从链表头到 $p$ 的已处理部分已经无重复，且 $p$ 是这部分最后一个结点。由于链表递增有序，若 $p\to data = q\to data$，$q$ 必是重复结点；若不等，$q$ 不可能和已处理部分的其他元素重复。因此 $p$ 的移动或不移动都维持不变量。循环结束时 $p\to next=NULL$，所有结点都处理完毕，链表无重复。

核心代码为：
```c
void DelSame(LinkList L) {   // L 为带头结点链表的头指针
    if (L == NULL) return;
    LNode *p = L->next;
    while (p != NULL && p->next != NULL) {
        LNode *q = p->next;
        if (p->data == q->data) {
            p->next = q->next;
            free(q);
        } else {
            p = q;
        }
    }
}
```
若链表不带头结点，只需把初始的 `LNode *p = L->next;` 改为 `LNode *p = L;` 即可。

复杂度：每个结点至多被访问常数次，时间复杂度 $O(n)$；只用了 $p,q$ 等常数个指针，空间复杂度 $O(1)$。

**易错点**：
1. **删除后继后马上让 `p = p->next`**：会导致连续三个以上重复元素时漏删，例如 $42,42,42$ 删除一个 42 后 $p$ 移到第三个 42，最终仍有两个 42。正确做法是删除后 $p$ 不动。  
2. **在无序链表上也直接用相邻比较**：无序时相同元素不一定相邻，必须改用哈希表或双重循环；本题能使用相邻比较完全依赖“递增有序”。  
3. **忘记处理空表或单结点表**：直接访问 `p->next` 会出错。循环条件要包含 `p != NULL && p->next != NULL`。  
4. **释放顺序错误**：应先用 $q\to next$ 把后继链好，再 `free(q)`，避免访问已释放结点。  
5. **带头结点与不带头结点混淆**：初始 $p$ 的指向不同，考试时最好先说明链表是否带头结点。

**命题规律**：本题属于 408 数据结构“线性表”部分的经典算法设计题，核心是链表指针操作与有序表性质。常见变式有：删除有序链表中所有重复元素（一个都不留）、合并两个有序链表并去重、判断链表是否严格递增、无序链表去重等。复习时应熟练掌握带头结点和不带头结点两种写法，并养成“先写算法思想、再写伪代码/代码、最后写复杂度”的答题习惯。链表题尤其适合画图模拟指针变化，避免指针修改顺序出错。

> 07.【解答】
> 算法思想：题中链表是有序表，因此所有相同值域的结点都是相邻的。用 p 扫描递增单链表 L，若 \*p 结点的值域等于其后继结点的值域，则删除后者，否则 p 移向下一个结点。
> 本题代码如下：
> ```c
> void Del_Same(LinkList &L){
>     LNode *p=L->next,*q;                //p 为扫描工作指针
>     if(p==NULL)
>         return;
>     while(p->next!=NULL){
>         q=p->next;                      //q 指向*p 的后继结点
>         if(p->data==q->data){           //找到重复值的结点
>             p->next=q->next;            //释放*q 结点
>             free(q);                    //释放相同元素值的结点
>         }
>         else
>             p=p->next;
>     }
> }
> ```
> 本算法的时间复杂度为 $O(n)$，空间复杂度为 $O(1)$。
> 本题也可采用尾插法，将头结点摘下，然后从第一结点开始，依次与已经插入结点的链表的最后一个结点比较，若不等则直接插入，否则将当前遍历的结点删除并处理下一个结点，直到最后一个结点为止。

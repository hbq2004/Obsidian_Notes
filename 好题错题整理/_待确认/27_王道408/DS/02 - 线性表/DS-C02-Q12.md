# 综合题 第 12 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-Q12_题目.png|题目]]

有两个循环单链表，链表头指针分别为 $h_1$ 和 $h_2$，之后，要求链接后的链表仍保持循环链表形式。

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C02-Q12_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：核心是分别找到两个循环单链表的尾结点，把 $h_1$ 的尾结点接到 $h_2$ 链表的第一个数据结点，再把 $h_2$ 的尾结点接回 $h_1$ 链表的第一个数据结点，使两条“回边”交叉连接成一个环；时间复杂度 $O(n_1+n_2)$，空间复杂度 $O(1)$。

**解题切入点**：拿到题先抓“循环”二字：循环单链表没有 `NULL` 结尾，尾结点的 `next` 等于头指针。所以合并两个循环链表的关键是找尾结点，并修改两条“回边”。打比方：两个环形跑道要并成一个环，必须先找到各自的“最后一棒”，让第一队的最后一棒跑到第二队起点，第二队的最后一棒再跑回第一队起点。

**推演**：

设两个链表非空且不带头结点，$h_1$ 指向首元结点 $a_1$，$h_2$ 指向首元结点 $b_1$：

$$
h_1:\ a_1\to a_2\to\cdots\to a_n\to a_1
$$

$$
h_2:\ b_1\to b_2\to\cdots\to b_m\to b_1
$$

目标是把它们合并成：

$$
a_1\to a_2\to\cdots\to a_n\to b_1\to b_2\to\cdots\to b_m\to a_1
$$

因此需要找到：

- $p$：$h_1$ 的尾结点 $a_n$，满足 `p->next == h1`；
- $q$：$h_2$ 的尾结点 $b_m$，满足 `q->next == h2`。

然后执行两步指针修改：

```c
p->next = h2;   // a_n -> b_1
q->next = h1;   // b_m -> a_1
```

关键代码如下：

```c
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode;

LNode* MergeCircularList(LNode *h1, LNode *h2) {
    if (h1 == NULL) return h2;   // 空表处理
    if (h2 == NULL) return h1;

    LNode *p = h1, *q = h2;

    // 找 h1 的尾结点
    while (p->next != h1)
        p = p->next;

    // 找 h2 的尾结点
    while (q->next != h2)
        q = q->next;

    // 交叉链接，形成一个循环单链表
    p->next = h2;
    q->next = h1;

    return h1;
}
```

正确性：

1. 循环结束时 `p->next == h1`，而循环单链表中只有尾结点才指向头指针，所以 $p$ 是第一条链表的尾结点；同理，$q$ 是第二条链表的尾结点。
2. `p->next = h2` 把第一条链表的尾结点连到第二条链表的首元结点。
3. `q->next = h1` 把第二条链表的尾结点接回第一条链表的首元结点。

于是从 $h_1$ 出发能依次经过 $a_1,\dots,a_n,b_1,\dots,b_m$ 后回到 $h_1$，并且每个结点仍只有一个 `next` 后继，所以结果仍然是循环单链表。

设两条链表长度分别为 $n_1,n_2$，找尾结点分别需要遍历两条链表一次，时间为 $O(n_1+n_2)$；只使用了常数个辅助指针，空间为 $O(1)$。

**易错点**：

- 用 `p->next == NULL` 判断表尾是错的。循环链表没有 `NULL` 结尾，应该判断 `p->next == h1`。
- 不能在头结点位置直接连接，例如写 `h1->next = h2` 会丢掉 $h_1$ 链表的后半部分；必须找到尾结点再修改。
- 应先定位两个尾结点，再统一修改指针，避免操作过程中丢失链表。
- 要处理空表；若题目默认非空，可省略空表判断。
- 注意“带头结点”和“不带头结点”的区别。本题按不带头结点处理；若题目明确带头结点，则连接时应让 $h_1$ 的尾结点指向 $h_2$ 的首元结点，即 `h2->next`，并把 $h_2$ 的头结点释放，不能把 $h_2$ 头结点当作数据结点串进结果。

**命题规律**：

考点定位在 408 线性表的链式存储：循环单链表的基本操作。常以算法设计题、代码填空题或复杂度选择题形式出现。

常见变式：

1. 若题目给出的是带尾指针的循环链表，则合并两个链表不需要遍历，可以达到 $O(1)$ 时间。
2. 若要求带头结点的循环链表合并，需要处理多余头结点。
3. 判断循环单链表是否为空、求表长、找尾结点等，都是同一类基础操作。

复习建议：链表题先画图，明确“头指针、头结点、首元结点、尾结点”四个概念；答题时按“算法思想 + 关键代码 + 复杂度分析”三步写，容易拿全分。

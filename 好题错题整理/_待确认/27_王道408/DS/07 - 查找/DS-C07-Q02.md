# 综合题 第 2 题

![[_Attachments/题目识别/27_王道408-题目/DS-C07-Q02_题目.png|题目]]

02. 假定把关键字 key 散列到有 $n$ 个表项（从 0 到 $n-1$ 编址）的散列表中。对于下面的每个函数 $H(\text{key})$（key 为整数），这些函数能够当作散列函数吗？若能，它是一个好的散列函数吗？说明理由。设函数 $\text{random}(n)$ 返回一个 0 到 $n-1$ 之间的随机整数（包括 0 与 $n-1$ 在内）。
1）$H(\text{key}) = \text{key}/n$.
2）$H(\text{key}) = 1$.
3）$H(\text{key}) = (\text{key} + \text{random}(n)) \% n$.
4）$H(\text{key}) = \text{key} \% p(n)$; 其中 $p(n)$ 是不大于 $n$ 的最大素数.

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C07-Q02_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：四个函数中，只有 $H(\text{key})=1$ 和 $H(\text{key})=\text{key} \% p(n)$ 能够当作散列函数，但都不是好的散列函数；$H(\text{key})=\text{key}/n$ 和 $H(\text{key})=(\text{key}+\text{random}(n))\% n$ 不能当作散列函数。

**解题切入点**：判断一个函数能否作为散列函数，必须满足两个基本条件：① 对于任意关键字 $\text{key}$，$H(\text{key})$ 的值必须在 $0$ 到 $n-1$ 的地址范围内；② 同一个关键字必须映射到同一个地址（确定性）。在此基础上，好的散列函数还应满足：计算简单、冲突尽可能少（即关键字尽可能均匀分布在整个地址空间）。可以类比算法竞赛中的“哈希函数设计”，首要保证合法，再追求均匀。

**推演**：
1. **$H(\text{key}) = \text{key}/n$**  
   $\text{key}$ 为整数，$\text{key}/n$ 可能为小数（如 $\text{key}=1, n=2$ 得 $0.5$），无法直接作为整数地址；即使取整，当 $\text{key} \ge n$ 时，结果 $\ge 1$，可能超出 $0$~$n-1$ 的范围（例如 $n=10, \text{key}=100$ 得 $10$，超出）。因此不能当作散列函数。

2. **$H(\text{key}) = 1$**  
   若 $n>1$，则 $1 \in [0, n-1]$，所有关键字均映射到地址 $1$，满足地址范围要求且确定性成立，故能当作散列函数。但所有关键字都落在同一位置，冲突极为严重，完全无法实现均匀分布，因此不是好的散列函数。若 $n=1$，地址只有 $0$，$1$ 不在范围内，此时不能当作散列函数（通常散列表 $n\ge2$，故一般判定为“能但不好”）。

3. **$H(\text{key}) = (\text{key} + \text{random}(n)) \% n$**  
   $\text{random}(n)$ 每次调用返回 $0$~$n-1$ 的随机整数，因此同一个 $\text{key}$ 在不同时刻可能得到不同的散列地址，违反散列函数的确定性（要求相同的输入必须产生相同的输出）。故不能当作散列函数。

4. **$H(\text{key}) = \text{key} \% p(n)$，其中 $p(n)$ 是不大于 $n$ 的最大素数**  
   输出范围是 $0$~$p(n)-1$，因 $p(n) \le n$，所以结果均在 $0$~$n-1$ 内，且对于同一个 $\text{key}$ 结果固定，故能当作散列函数。但是：
   - 若 $p(n) < n$（即 $n$ 不是素数），则地址空间只使用了 $p(n)$ 个位置，其余 $n-p(n)$ 个位置永远空闲，空间利用率低，且冲突概率增大（因为映射范围缩小），不是好的散列函数。
   - 若 $p(n) = n$（即 $n$ 是素数），则退化为标准的除留余数法，此时可算作好的散列函数（但题目未限定 $n$ 的性质，通常认为 $p(n)$ 一般小于 $n$，故整体上判定为“不是好的散列函数”）。  
   综上，它能当作散列函数，但通常不是好的选择。

**易错点**：
- 误将 $\text{key}/n$ 取整后认为范围正确，忽略取整方式（向下取整或四舍五入）可能仍导致地址越界，且 $\text{key}$ 较大时结果必然超出 $n-1$。
- 认为 $H(\text{key})=1$ 是“函数”就能用，忽略 $n=1$ 的边界情况，但更重要的是未意识到“总是冲突”意味着极差。
- 认为 $(\text{key}+\text{random}(n))\% n$ 利用随机数可以“均匀分布”，但混淆了散列函数的确定性要求；散列函数必须是确定性的，不能依赖随机数。
- 对 $H(\text{key})=\text{key}\% p(n)$，只看到取模素数能减少冲突，却忽略了 $p(n)<n$ 时地址空间缩小导致的新冲突，认为“取模素数就是好的”。

**命题规律**：本题直接考查散列函数的基本要求（确定性、映射范围）和性能评价（均匀性、冲突率）。在考研 408 中，常以选择题或简答题形式出现，可能结合除留余数法、平方取中法、折叠法等具体构造，或要求判断给定函数是否合法、是否高效。复习时需牢记：① 散列函数必须将关键字映射到表长范围内且确定；② 评价好坏主要看冲突是否少、计算是否快；③ 除留余数法选模素数是为了均匀分布，但若素数小于表长则会浪费空间。变式可能涉及 $H(\text{key})=\text{key} \% m$ 中 $m$ 的选择（常考 $m$ 取素数或 $2^k$ 的优劣），或与开放地址法、链地址法等结合。

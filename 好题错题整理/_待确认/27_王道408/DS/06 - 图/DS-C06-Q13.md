# 综合题 第 13 题

![[_Attachments/题目识别/27_王道408-题目/DS-C06-Q13_题目.png|题目]]

13. 【2024 统考真题】2023 年 10 月 26 日，神舟十七号载人飞船发射取得圆满成功，再次彰显了中国航天事业的辉煌成就。载人航天工程是包含众多子工程的复杂系统工程，为了保证工程的有序开展，需要明确各子工程的前导子工程，以协调各子工程的实施。该问题可以简化、抽象为有向图的拓扑序列问题。已知有向图 $G$ 采用邻接矩阵存储，类型定义如下。
```c
typedef struct //图的类型定义
{
    int numVertices, numEdges; //图的顶点数和有向边数
    char VerticesList[MAXV]; //顶点表, MAXV 为已定义常量
    int Edge[MAXV][MAXV]; //邻接矩阵
} MGraph;
```
请设计算法：`int uniquely(MGraph G)`，判定 $G$ 是否存在唯一的拓扑序列，若是，则返回 1，否则返回 0。要求如下。
1）给出算法的基本设计思想。
2）根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。

## DeepSeek V4 Flash Max 解析

**答案**：判定有向图是否存在唯一的拓扑序列，可通过拓扑排序（Kahn算法）过程中检查每次入度为 $0$ 的顶点个数是否始终为 $1$，且最终所有顶点均被输出；若同时满足，则存在唯一的拓扑序列，返回 $1$，否则返回 $0$。

**解题切入点**：拿到题目，首先应明确拓扑排序唯一性的条件：在拓扑排序的每一步，当前入度为 $0$ 的顶点必须恰好有一个，否则序列不唯一（有多个选择）或存在环（无序列）。可以类比为“做菜工序”：如果每一步只有一道菜可以开始准备，则顺序唯一；否则有多种可能。本题正是基于这一核心思想，利用 Kahn 算法模拟排序过程，并实时监控入度为 $0$ 的顶点个数。因此，考点可定位为“拓扑排序的变形——唯一性判定”，复习时应重点掌握 Kahn 算法的实现、入度计算及唯一性判断的时机。

**推演**：

### 1. 算法基本设计思想
- 计算每个顶点的入度（遍历邻接矩阵，若 $Edge[i][j] = 1$ 则顶点 $j$ 的入度加 $1$）。
- 将初始入度为 $0$ 的顶点全部入队。
- 使用变量 $count$ 记录已处理（输出）的顶点数。
- 当队列非空时：
  - 检查队列中元素个数是否等于 $1$。若大于 $1$，说明当前存在多个入度为 $0$ 的顶点，拓扑序列不唯一，直接返回 $0$。
  - 若队列中元素个数等于 $1$，则取出队首顶点 $u$，$count$ 加 $1$。
  - 遍历所有顶点 $v$，若 $Edge[u][v] = 1$，则将 $v$ 的入度减 $1$；若入度变为 $0$，则将 $v$ 入队。
- 循环结束后，若 $count$ 等于顶点数 $n$，说明所有顶点均被处理（无环）且每一步入度为 $0$ 的顶点始终只有一个，故拓扑序列唯一，返回 $1$；否则返回 $0$（有环或序列不唯一）。

### 2. 算法复杂度分析
- **时间复杂度**：计算入度需遍历整个邻接矩阵，耗时 $O(n^2)$；拓扑排序过程中，每条边（邻接矩阵中每个 $1$）被访问一次，同时每个顶点最多入队出队一次，总耗时 $O(n^2)$。故时间复杂度为 $O(n^2)$，其中 $n$ 为顶点数。
- **空间复杂度**：需要入度数组 $O(n)$，队列数组 $O(n)$，故空间复杂度为 $O(n)$。

### 3. C 语言代码实现（含关键注释）
```c
int uniquely(MGraph G) {
    int n = G.numVertices;
    int indegree[MAXV] = {0};          // 入度数组
    int queue[MAXV];                   // 模拟队列（线性存储）
    int front = 0, rear = 0;           // 队首、队尾指针
    int count = 0;                     // 已处理顶点数

    // 1. 计算各顶点入度
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            if (G.Edge[i][j] == 1)      // 有向边 i -> j
                indegree[j]++;

    // 2. 初始入度为 0 的顶点入队
    for (int i = 0; i < n; i++)
        if (indegree[i] == 0)
            queue[rear++] = i;

    // 3. 拓扑排序并判断唯一性
    while (front != rear) {            // 队列非空
        // 若当前队列中入度为 0 的顶点个数不为 1，则不唯一
        if (rear - front != 1)
            return 0;

        int u = queue[front++];        // 出队
        count++;                       // 处理一个顶点

        // 更新 u 的所有后继顶点的入度
        for (int v = 0; v < n; v++) {
            if (G.Edge[u][v] == 1) {
                indegree[v]--;
                if (indegree[v] == 0)  // 入度变为 0，则入队
                    queue[rear++] = v;
            }
        }
    }

    // 4. 若所有顶点均被处理，则唯一；否则有环，不唯一
    return (count == n) ? 1 : 0;
}
```

**易错点**：
1. **忽略环的检测**：只检查队列大小是否始终为 $1$，但未在循环结束后核对 $count$ 是否等于 $n$。若图中有环，队列可能在处理部分顶点后变空，但 $count < n$，应返回 $0$，否则会误判为唯一。
2. **唯一性判断时机不当**：在入队时检查队列大小，可能遗漏初始多个入度为 $0$ 的情况（初始入队后队列大小可能大于 $1$，但入队时检查能发现）；若在出队后检查，可能因队列中新入队多个顶点而延迟到下一轮，但算法仍能正确拦截，但应确保在每次出队前（或入队时）检查，避免逻辑遗漏。
3. **队列实现错误**：使用线性队列时，$front$ 和 $rear$ 持续增加，若 $MAXV$ 较小可能溢出，但题目中 $MAXV$ 为常量且顶点数小于该值，通常安全；更稳妥的做法是使用循环队列或动态数组，但本题线性队列足以。
4. **入度更新时方向错误**：邻接矩阵 $Edge[i][j]$ 表示从 $i$ 到 $j$ 的有向边，故入度应更新 $j$；若误更新 $i$，则结果完全错误。
5. **自环或平行边处理**：若存在自环（$Edge[i][i]=1$），该顶点入度至少为 $1$，永远不会入队，最终 $count < n$，返回 $0$，符合题意；平行边在邻接矩阵中通常用 $0/1$ 表示，不影响算法。

**命题规律**：
- **考点定位**：拓扑排序的唯一性判断，属于图算法中的经典应用，常出现在综合应用题中，要求考生设计算法并分析复杂度。
- **常见变式**：① 判断图是否有唯一的拓扑序列（本题）；② 输出唯一的拓扑序列（若存在）；③ 在 DFS 拓扑排序中判断唯一性；④ 结合邻接表实现，要求 $O(n+e)$ 的时间复杂度；⑤ 给定图，问是否可以通过调整顶点顺序得到唯一的拓扑序列。
- **复习建议**：熟练掌握 Kahn 算法（基于入度）和 DFS 算法（基于完成时间）两种拓扑排序方法，并深刻理解唯一性等价于“排序过程中始终只有一个入度为 $0$ 的顶点”。同时，注意邻接矩阵与邻接表的不同实现，并能对算法进行复杂度分析。在解题时，先明确唯一性条件，再选择合适的遍历方式，最后检查边界情况（如环、单顶点、多顶点等）。

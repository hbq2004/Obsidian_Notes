## 答案

## DeepSeek V4 Flash Max 解析

**答案**：利用 DFS 的“完成时刻”逆序实现拓扑排序：在 DFS 中每当一个顶点的所有邻接点都处理完毕后，将该顶点压入结果栈；全部 DFS 结束后依次弹栈，所得序列就是有向无环图的拓扑序列。若 DFS 中遇到回边，则说明图中存在环，不能得到拓扑排序。

**解题切入点**：拿到题目先抓两个关键词：**DFS** 和 **有向无环图拓扑排序**。拓扑排序要求每条边 $u\to v$ 中 $u$ 排在 $v$ 前面。DFS 的递归返回顺序天然满足“所有后继都先于当前点完成”，因此把完成顺序反过来就是拓扑序。可以类比“课程修读”：DFS 深入访问先修课程，先修课完成后才返回；最后再反向输出就是正确的修读顺序。不要与 Kahn 算法混淆，Kahn 是不断删除入度为 0 的顶点，而 DFS 法是按“出边全部处理完”的顺序记录。

**推演**：

设 $G=(V,E)$ 是有向无环图，$f(v)$ 表示顶点 $v$ 在 DFS 中的完成时刻。对于任意一条边 $u\to v$，在 DFS 遍历 $u$ 时：

- 若 $v$ 尚未访问，则 DFS 会先递归访问 $v$，等 $v$ 返回后才继续处理 $u$，所以 $f(v)<f(u)$；
- 若 $v$ 已经访问完毕，则显然 $f(v)<f(u)$；
- 若 $v$ 还在递归栈中，则 $v$ 是 $u$ 的祖先，加上边 $u\to v$ 会形成环，这与 DAG 矛盾。

因此在有向无环图中，任意边 $u\to v$ 都满足

$$
f(v)<f(u)
$$

也就是说，边的起点完成得更晚，边的终点完成得更早。若按照 DFS 完成时刻的逆序，即从 $f$ 大的顶点到 $f$ 小的顶点输出，则对于任意边 $u\to v$，$u$ 一定先于 $v$ 输出，因此得到拓扑序列。

算法步骤如下：

1. 初始化所有顶点为“未访问”；
2. 从每个未访问顶点开始执行 DFS；
3. DFS 过程中把顶点标记为“在递归栈中”；若遇到邻接点也在递归栈中，则说明有环；
4. 当顶点 $v$ 的所有出边都处理完毕时，将 $v$ 压入结果栈；
5. 所有 DFS 结束后，依次弹出结果栈，即为拓扑序列。

关键代码如下：

```c
int visited[MAXV];   // 0: 未访问  1: 在递归栈中  2: 已结束
int topo[MAXV], top = -1;

bool DFS(ALGraph G, int v) {
    visited[v] = 1;                     // 标记为灰色，进入递归栈
    for (ArcNode *p = G.vertices[v].firstarc; p; p = p->nextarc) {
        int w = p->adjvex;
        if (visited[w] == 0) {          // 未访问，递归访问
            if (!DFS(G, w)) return false;
        } else if (visited[w] == 1) {   // 遇到回边，有环
            return false;
        }
    }
    visited[v] = 2;                     // 标记为黑色，表示处理完毕
    topo[++top] = v;                    // 完成时入栈
    return true;
}

bool DFSTopoSort(ALGraph G) {
    for (int i = 0; i < G.vexnum; i++) visited[i] = 0;
    top = -1;
    for (int i = 0; i < G.vexnum; i++) {
        if (visited[i] == 0) {
            if (!DFS(G, i)) {
                printf("图中有环，不存在拓扑排序\n");
                return false;
            }
        }
    }
    while (top >= 0) {
        printf("%d ", topo[top--]);     // 弹栈顺序即拓扑序
    }
    return true;
}
```

时间复杂度：每个顶点和每条边各访问一次，故为 $O(n+e)$，其中 $n=|V|$，$e=|E|$。空间复杂度：递归栈和辅助数组均为 $O(n)$。

**易错点**：

- **不能把 DFS 的访问顺序直接当作拓扑序**。DFS 先访问到的顶点不一定满足拓扑序，必须使用 DFS 的完成顺序，再取逆序。
- **注意记录的是完成时刻的逆序**。如果使用数组存放完成顶点，最后需要逆序输出；如果使用栈存放完成顶点，则弹栈输出即可，二者不要混淆。
- **只用一个 bool visited 无法判断有向图的环**。需要用三色标记：0 未访问，1 在递归栈中，2 已结束。遇到 `visited[w] == 1` 才说明存在回边。
- **必须从所有顶点分别启动 DFS**。若只从一个顶点开始 DFS，可能漏掉不连通分量或孤立点，导致拓扑序列不完整。
- **若题目已保证是有向无环图**，环检测可以省略；但保留环检测能使算法更健壮。

**命题规律**：本考点属于“图”中的拓扑排序应用。408 选择题常给出一个有向图或 DFS 遍历过程，要求判断哪个序列是拓扑序列；综合题可能要求手写 DFS 拓扑排序、判断有向图是否有环，或与 Kahn 算法对比。常见变式包括：

- 用 DFS 判断有向图是否有环；
- 给出 DFS 的发现时间和完成时间，要求写出拓扑序列；
- 在 AOV 网中求一个可行的拓扑序列；
- 将拓扑序用于关键路径或 DAG 上的动态规划。

复习建议：熟练掌握 DFS 三色标记法、完成时间性质，以及 Kahn 算法与 DFS 算法的区别；注意拓扑序列通常不唯一，邻接表顺序不同可能得到不同但都合法的拓扑序。

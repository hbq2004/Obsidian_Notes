# 综合题 第 5 题

![[_Attachments/题目识别/27_王道408-题目/OS-C05-Q05_题目.png|题目]]

05. 有一个交叉存放信息的磁盘，信息在其上的存放方法如右图所示。每个磁道有 8 个扇区，每个扇区大小为 512B，旋转速度为 3000 转/分，顺时针读扇区。假定磁头已在读取信息的磁道上，0 扇区转到磁头下需要 $1/2$ 转，且设备对应的控制器不能同时进行输入/输出，在数据从控制器传送至内存的这段时间内，从磁头下通过的扇区数为 2，请回答：
1）依次读取一个磁道上的所有扇区需要多少时间？
2）该磁盘的数据传输速率是多少？

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/OS-C05-Q05_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：依次读取一个磁道全部扇区共需 $70\text{ ms}$；该磁盘的数据传输速率约为 $6.83\times10^4\text{ B/s}$，即约 $68.3\text{ KB/s}$（若把起始半转也摊入本次读取过程，则等效平均速率为 $58.5\text{ KB/s}$，但通常不把定位延迟计入“数据传输速率”）。

**解题切入点**：  
先抓住磁盘旋转的基本节拍：转一圈的时间 $T_{\text{rot}}$ 和一个扇区经过磁头的时间 $T_s$。再抓住“控制器不能同时输入/输出”这一瓶颈：读一个扇区进控制器需要 $T_s$，控制器再向内存传送数据需要 $2T_s$，二者串行；扇区交叉存放就是为了让传送期间错过的扇区正好是“不该读的扇区”，使下一个逻辑扇区刚好在传送完成后到达磁头下。

可以把这个过程类比为“生产者—消费者”环形队列：磁盘是生产者，控制器/内存是消费者；旋转不会停，所以扇区交叉编号相当于给消费者预留处理时间。

**推演**：

1. 基本时间参数

转速：
$$3000\text{ 转/分}=50\text{ 转/秒}$$

转一圈所需时间：
$$T_{\text{rot}}=\frac{1}{50}\text{ s}=20\text{ ms}$$

每个磁道有 8 个扇区，所以一个扇区经过磁头的时间：
$$T_s=\frac{20}{8}=2.5\text{ ms}$$

题目说数据从控制器传送至内存期间，磁头下经过的扇区数为 2，所以：
$$T_{\text{传送}}=2T_s=5\text{ ms}$$

由于控制器不能同时进行输入/输出，读一个扇区并送入内存的串行时间为：
$$T_s+T_{\text{传送}}=2.5+5=7.5\text{ ms}$$

2. 交叉存放的含义

按题图交叉方式，逻辑相邻扇区在物理位置上相隔 3 个扇区位置。例如顺时针物理顺序为：
$$0,3,6,1,4,7,2,5$$

读完扇区 0 后，控制器传送期间会经过扇区 3 和 6；传送完毕时，扇区 1 刚好到达磁头下，因此无需额外等待。所以每读一个逻辑扇区平均需要 $7.5\text{ ms}$。

因此，从 0 扇区到达磁头下开始，读完 8 个扇区并全部传送到内存的时间为：
$$8\times 7.5=60\text{ ms}$$

又因为开始时 0 扇区转到磁头下需要半转：
$$T_{\text{初始等待}}=\frac{1}{2}T_{\text{rot}}=10\text{ ms}$$

所以总时间为：
$$T_{\text{总}}=10+60=70\text{ ms}$$

3. 数据传输速率

8 个扇区总数据量：
$$8\times 512\text{ B}=4096\text{ B}=4\text{ KB}$$

纯数据传送阶段（从 0 扇区到磁头下开始读，到最后一个扇区传送完毕）为 $60\text{ ms}$，因此数据传输速率：
$$D=\frac{4096\text{ B}}{60\text{ ms}}
=\frac{4096}{0.06}\text{ B/s}
\approx 6.83\times10^4\text{ B/s}
\approx 68.3\text{ KB/s}$$

若把初始半转 $10\text{ ms}$ 也算入本次读命令的总耗时，则等效平均速率为：
$$\frac{4096\text{ B}}{70\text{ ms}}\approx 5.85\times10^4\text{ B/s}\approx 58.5\text{ KB/s}$$
但这属于“本次读取命令的平均访问速率”，不是通常定义下的数据传输速率。

**易错点**：

- 忘记加 0 扇区的初始半转，得到 $60\text{ ms}$；题目明确说明 0 扇区转到磁头下需要 $1/2$ 转，所以要加 $10\text{ ms}$，答案为 $70\text{ ms}$。
- 把传输速率算成 $512\text{ B}/2.5\text{ ms}=204.8\text{ KB/s}$。这是磁盘介质本身的瞬时读出速率，没有考虑控制器传送期间不能同时读盘的限制，不符合本题“磁盘 + 控制器”整体传输过程。
- 把 $70\text{ ms}$ 直接代入速率公式得到 $58.5\text{ KB/s}$，这是把旋转等待延迟也平均到数据传送速率中；若题目问“本次读取命令的平均速率”可以这样算，但问“磁盘的数据传输速率”时应使用纯传送阶段的 $60\text{ ms}$。

**命题规律**：

本题是操作系统“设备管理”中磁盘 I/O 时间的典型考点。核心公式是：
$$T_{\text{访问}}=T_{\text{寻道}}+T_{\text{旋转延迟}}+T_{\text{传输}}$$

常见变式包括：

- 给出交叉因子或“传送期间经过的扇区数”，求读完整条磁道的时间；
- 求为避免丢失扇区所需的最小扇区间隔；
- 结合寻道时间和平均旋转延迟（常取半转）求平均磁盘访问时间；
- 把磁盘读写与 DMA/中断传送方式结合，考查控制器瓶颈。

复习时建议以“转一圈时间 ÷ 每磁道扇区数”作为基本时间片，画出扇区圆周排列图模拟读取过程，并严格区分“定位时间”“传输时间”和“总访问时间”。

> 05.【解答】
> 磁盘逆时针方向旋转按扇区来看即0, 3, 6, …这个顺序。每个号码连续的扇区正好相隔2个扇区，即数据从控制器传送到内存的时间，所以相当于磁头连续工作。
> 1）由题中条件可知，旋转速度为3000转/分 = 50转/秒，即20ms/转。
> 读一个扇区需要的时间为$20/8 = 2.5\text{ms}$。

> 2）每个磁道的数据量为$8 \times 512 = 4\text{KB}$。
> 所以数据传输速率为$4\text{KB}/0.07\text{s} = 4 \times 1024\text{kB}/(1000 \times 0.07\text{s}) = 58.5\text{kB/s}$。

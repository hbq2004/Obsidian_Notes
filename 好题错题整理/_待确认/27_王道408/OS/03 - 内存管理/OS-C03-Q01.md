# 综合题 第 1 题

![[_Attachments/题目识别/27_王道408-题目/OS-C03-Q01_题目.png|题目]]

01. 假定某操作系统存储器采用页式存储管理，一个进程在相联存储器中的页表项见表A，不在相联存储器中的页表项见表B。

表A 相联存储器中的页表

| 页 号 | 页 帧 号 |
|-------|----------|
| 0     | f1       |
| 1     | f2       |
| 2     | f3       |
| 3     | f4       |

表B 内存中的页表

| 页 号 | 页 帧 号 |
|-------|----------|
| 4     | f5       |
| 5     | f6       |
| 6     | f7       |
| 7     | f8       |
| 8     | f9       |
| 9     | f10      |

注: 只列出不在相联存储器中的页表项。

假定该进程长度为320B，每页32B。现有逻辑地址（八进制）为101,204,576，若上述逻辑地址能转换成物理地址，说明转换的过程，并指出具体的物理地址；若不能转换，则说明其原因。

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/OS-C03-Q01_答案.png|答案]]


> **原书解答（OCR）**

01.【解答】
一页的大小为 $32\text{B}$，逻辑地址结构为：低 $5$ 位为页内位移，其余高位为页号。
$101\text{（八进制）} = 001000001\text{（二进制）}$，则页号为 $2$，在相联存储器中，对应的页帧号为 $\text{f3}$，即物理地址为 $(\text{f3}, 1)$。
$204\text{（八进制）} = 010000100\text{（二进制）}$，则页号为 $4$，不在相联存储器中，查内存的页表得页帧号为 $\text{f5}$，即物理地址为 $(\text{f5}, 4)$，并用其更新相联存储器中的一项。
$576\text{（八进制）} = 101111110\text{（二进制）}$，则页号为 $11$，已超出页表范围，即产生越界中断。

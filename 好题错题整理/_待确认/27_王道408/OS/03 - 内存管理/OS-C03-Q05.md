# 综合题 第 5 题

![[_Attachments/题目识别/27_王道408-题目/OS-C03-Q05_题目.png|题目]]

05. 一个页式虚拟存储系统，其并发进程数固定为 4 个。最近测试了它的 CPU 利用率和用于页面交换的磁盘的利用率，得到的结果就是下列 3 组数据中的一组。针对每组数据，说明系统发生了什么事情。增加并发进程数能提升 CPU 的利用率吗？页式虚拟存储系统有用吗?
1）CPU 利用率为 13%；磁盘利用率为 97%。
2）CPU 利用率为 87%；磁盘利用率为 3%。
3）CPU 利用率为 13%；磁盘利用率为 3%。

## 答案

![[_Attachments/题目识别/27_王道408-答案/OS-C03-Q05_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：  
- (1) 系统处于**抖动**状态，增加并发进程数会进一步降低 CPU 利用率，页式虚拟存储系统此时无效。  
- (2) 系统运行**正常**，CPU 利用率已较高，增加并发进程数可能略微降低 CPU 利用率，页式虚拟存储系统有效。  
- (3) 系统处于**资源空闲**（进程被阻塞或进程数不足），增加并发进程数可提高 CPU 利用率，页式虚拟存储系统有效但当前未发挥优势。

**解题切入点**：  
第一眼抓住两个关键指标：CPU 利用率与磁盘（页面交换）利用率。  
- 磁盘利用率高（接近 100%）说明大量页面换入换出，常伴随频繁缺页；CPU 利用率低说明 CPU 在等待 I/O，典型**抖动**现象。  
- 磁盘利用率低且 CPU 利用率高，说明缺页很少，系统在高效执行。  
- 两者均低，说明系统并未满负荷工作，可能存在进程阻塞或进程数不足。  
定位考点：**虚拟存储系统性能分析**，特别是**抖动（thrashing）** 的识别与影响。  
结合操作系统经验：  
- 若系统处于抖动，增加并发进程数会加剧内存竞争，使缺页更严重，CPU 利用率更低。  
- 若 CPU 已饱和，增加进程数往往引入额外开销（上下文切换、缓存失效），可能降低 CPU 利用率。  
- 若资源空闲，增加进程数可提高资源利用率。

**推演**：  
**（1）CPU 利用率 $13\%$，磁盘利用率 $97\%$**  
- 磁盘利用率极高，说明页面交换几乎不间断，系统频繁发生缺页中断。  
- 由于并发进程数固定为 4，但磁盘仍繁忙，说明物理内存不足，进程的工作集总和超过物理内存，导致每个进程都频繁缺页，形成**抖动**。  
- CPU 利用率低是因为 CPU 大部分时间等待磁盘 I/O，无法有效执行指令。  
- **增加并发进程数**：会进一步增加内存需求，缺页率上升，磁盘 I/O 更忙，CPU 等待时间更长，利用率可能降得更低。  
- **页式虚拟存储系统有用吗**：此时系统几乎将所有时间用于交换，真正的计算很少，虚拟存储的“透明扩充内存”效果被抖动抵消，因此**无用**（需调整工作集或增加物理内存）。  

**（2）CPU 利用率 $87\%$，磁盘利用率 $3\%$**  
- CPU 利用率高，磁盘利用率很低，说明缺页极少，内存能够容纳当前进程的工作集，系统在高效执行。  
- 可能进程是 CPU 密集型的，或 I/O 操作很少（磁盘利用率低）。  
- **增加并发进程数**：若 CPU 利用率已接近饱和，增加进程数会导致更多上下文切换、缓存竞争，可能小幅降低 CPU 利用率（开销增大）。若新进程也需 CPU，可能使 CPU 更忙，但提升空间有限，且可能因内存不足引发少量缺页，故通常认为**不能提升** CPU 利用率，甚至可能降低。  
- **页式虚拟存储系统有用吗**：系统运行良好，虚拟存储提供了内存扩充且未造成性能下降，因此**有用**。  

**（3）CPU 利用率 $13\%$，磁盘利用率 $3\%$**  
- 两者都很低，说明系统资源空闲。可能原因：所有进程被阻塞（等待 I/O 设备、同步信号等），或并发进程数过少，导致 CPU 空闲。  
- 磁盘利用率低说明页面交换极少，内存压力不大。  
- **增加并发进程数**：可以让更多进程进入就绪队列，提高 CPU 调度机会，从而提升 CPU 利用率。  
- **页式虚拟存储系统有用吗**：虚拟存储本身提供内存管理，但当前系统未受到内存限制，其优势未体现，但系统结构依然有效，只是当前场景下无显著作用。通常认为**有用**（因为虚拟存储的存在并不妨碍系统运行，且能够在需要时发挥作用）。  

**易错点**：  
1. 混淆“磁盘利用率高”与“正常 I/O”：页面交换磁盘利用率高专指缺页导致的交换，若误认为普通 I/O 则可能错误判断系统状态。  
2. 认为情况（2）中增加进程数一定提升 CPU 利用率：忽略 CPU 已接近饱和，且过多进程会带来额外开销，实际可能降低。  
3. 认为情况（3）中系统“正常”：实际上 CPU 利用率低且磁盘利用率低表明系统未充分利用，应识别为资源空闲或进程阻塞。  
4. 对“页式虚拟存储系统有用吗”的回答过于绝对：需结合具体情境，如在抖动时无用，在正常运行时有用。

**命题规律**：  
- **考点定位**：虚拟存储系统性能分析，核心是**抖动**的识别与应对。  
- **常见变式**：  
  - 给出多组 CPU/磁盘利用率数据，判断系统状态（正常、抖动、空闲）。  
  - 结合进程数变化，分析对 CPU 利用率的影响。  
  - 扩展为工作集、缺页率、多道程序度等概念的综合题。  
- **复习建议**：  
  - 理解抖动产生的原因（物理内存不足，工作集总和 > 可用内存）。  
  - 掌握工作集模型、缺页率与 CPU 利用率的关系。  
  - 会分析不同利用率组合对应的系统行为，并判断增加进程数或调整内存的影响。

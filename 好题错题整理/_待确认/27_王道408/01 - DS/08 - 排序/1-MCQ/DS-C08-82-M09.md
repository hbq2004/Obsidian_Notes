## DeepSeek V4 Flash Max 解析

**答案**：采用直接插入排序（选项 C）。第一趟将第二个元素 $9$ 插入到 $15$ 之前，得到 $\{9,15,7,8,20,-1,4\}$。

**解题切入点**：看到“一趟排序后的序列”，先抓各排序算法一趟后的标志性特征：

- 直接插入排序：每趟把无序区第一个元素插入前面有序区，因此有序区长度增加 1，后面未处理元素保持原序。
- 冒泡排序：一趟会从一端到另一端做完整的相邻比较交换，使当前最大（或最小）元素到达端部。
- 选择排序：一趟必须选出无序区的最小（或最大）元素并交换到无序区开头。
- 快速排序：一趟要按枢轴划分整个当前区间，枢轴到达最终位置。

打比方：直接插入排序像打扑克摸牌后插牌，第一趟只摸第二张牌，插到手里已有牌中，后面的牌完全没动；而冒泡、选择、快速排序的第一趟动作范围更大。

**推演**：

设数组下标从 1 开始，初始序列为  
$$
a=[15,9,7,8,20,-1,4].
$$

采用直接插入排序时，初始有序区为 $[15]$，无序区为 $[9,7,8,20,-1,4]$。

第一趟取无序区第一个元素 $9$，与有序区元素 $15$ 比较：

$$
9<15
$$

因此将 $15$ 后移一位，把 $9$ 插入到 $15$ 之前：

$$
[9,15,7,8,20,-1,4].
$$

与题目给出的结果完全一致。

直接插入排序关键代码思路如下：

```c
// a[1..n] 为待排序序列，下标从 1 开始
for (int i = 2; i <= n; i++) {
    int temp = a[i];
    int j = i - 1;
    while (j >= 1 && a[j] > temp) {
        a[j + 1] = a[j];
        j--;
    }
    a[j + 1] = temp;
}
```

第一轮 $i=2$ 时，$temp=9$，$a[1]=15>9$，所以 $15$ 后移，$9$ 放到第一个位置。

排除其他选项：

1. **选择排序**：第一趟应选出全局最小值 $-1$，并与第一个元素 $15$ 交换，结果为  
$$
\{-1,9,7,8,20,15,4\}
$$
不是给定序列。

2. **冒泡排序**：若从左向右做一趟相邻比较，最大元素 $20$ 会冒到最后，结果为  
$$
\{9,7,8,15,-1,4,20\}
$$
不是给定序列。

3. **快速排序**：一趟快速排序后，枢轴应到达最终位置，且枢轴左侧元素都不大于枢轴，右侧元素都不小于枢轴。给定序列中若枢轴为 $15$，其后有 $7,8,-1,4$ 小于 $15$；若枢轴为 $9$，其前有 $15$ 大于 $9$；其他可能的枢轴也不能满足划分性质，因此不是快速排序一趟的结果。

所以正确答案是 C。

**易错点**：

- 看到第一个元素和第二个元素交换，就误选冒泡排序。实际上冒泡排序一趟不会只交换一次，还会继续向后比较并交换，把最大元素送到末尾。
- 误以为快速排序一趟也可以只交换相邻两个元素。快速排序一趟必须对当前区间进行划分，结果必须满足枢轴左右的大小关系。
- 忽略选择排序第一趟必须找出整个序列的最小值 $-1$，再与第一个元素交换；不是简单比较前两个元素。
- 对“一趟”的理解要与教材一致：直接插入排序的一趟指插入一个元素；冒泡、选择排序的一趟指完整的一轮扫描/选择。

**命题规律**：

本题属于排序算法的过程分析题，常以选择题或填空题形式出现，给出“一趟排序后”的序列，要求判断是哪种排序方法。常见变式还有：

- 给出初始序列和若干趟排序后的结果，判断排序方法；
- 给出排序中间过程，问下一趟结果；
- 与排序稳定性、时间复杂度结合考查。

复习建议：对插入排序、冒泡排序、选择排序、快速排序、希尔排序、堆排序、归并排序，都要手动模拟前两趟，掌握每趟操作的“确定性特征”。快速排序要注意不同划分实现结果可能略有不同，但“枢轴归位、左右划分”的核心性质不变。

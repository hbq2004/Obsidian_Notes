## 答案

## DeepSeek V4 Flash Max 解析

**答案**：按“插入到末尾后向上调整”的堆插入规则，最终 $H$ 的层序序列为 $9,8,7,5,6,1,4$，因此选 **B**。

**解题切入点**：  
本题考点是**大根堆的插入操作**。看到“依次插入初始为空”时，要立刻想到堆的 `push` 过程：新元素先放到完全二叉树末尾，再沿父链“上滤”。不能把它当成给定序列的一次性整体建堆。可以类比优先队列的 `push`：不是把整个队列重新排序，而是新元素“向上冒泡”到合适位置。

**推演**：  
用数组表示堆，下标从 1 开始。结点 $i$ 的父结点为 $\lfloor i/2 \rfloor$，大根堆要求：

$$
H[\lfloor i/2 \rfloor] \ge H[i]
$$

插入算法核心思路：

```c
// 下标从 1 开始，n 为当前堆大小
void insert(int H[], int &n, int x) {
    H[++n] = x;
    for (int i = n; i > 1 && H[i] > H[i / 2]; i /= 2)
        swap(H[i], H[i / 2]);
}
```

逐步模拟如下：

| 插入关键字 | 暂放末尾后的 $H$ | 上滤过程 | 调整后的 $H$ |
|---|---|---|---|
| $6$ | $[6]$ | 无需调整 | $[6]$ |
| $9$ | $[6,9]$ | $9 > H[1]=6$，交换 | $[9,6]$ |
| $1$ | $[9,6,1]$ | $1 < H[1]=9$，不动 | $[9,6,1]$ |
| $5$ | $[9,6,1,5]$ | $5 < H[2]=6$，不动 | $[9,6,1,5]$ |
| $8$ | $[9,6,1,5,8]$ | $8 > H[2]=6$，交换；后 $8 < H[1]=9$，停止 | $[9,8,1,5,6]$ |
| $4$ | $[9,8,1,5,6,4]$ | $4 > H[3]=1$，交换；后 $4 < H[1]=9$，停止 | $[9,8,4,5,6,1]$ |
| $7$ | $[9,8,4,5,6,1,7]$ | $7 > H[3]=4$，交换；后 $7 < H[1]=9$，停止 | $[9,8,7,5,6,1,4]$ |

最终对应的完全二叉树为：

```
        9
       / \
      8   7
     / \ / \
    5  6 1  4
```

所以最终层序序列为 $9,8,7,5,6,1,4$，对应选项 **B**。

**易错点**：  
- 容易把题目误以为“给定序列直接建堆”。若用整体调整建堆，会得到 $[9,8,7,5,6,4,1]$，即选项 C。题目说的是“依次插入”，必须模拟插入上滤。
- 只检查最终序列是否满足大根堆性质不够，因为选项 A、C 也满足大根堆性质，但不一定是插入过程得到的结果。
- 上滤要一直进行到父结点不小于新元素为止，不能只交换一次就停。
- 注意完全二叉树中下标定位：例如下标 3 的父结点是下标 1，不是下标 2；插入 $1$ 时应与堆顶 $9$ 比较。

**命题规律**：  
这是 2021 年统考真题，考查堆的基本操作。408 中常见的变式有：小根堆插入、删除堆顶后的“下滤”调整、堆排序初始堆的建立、判断给定序列是否为堆等。复习时要重点区分“插入建堆”和“整体数组建堆”，并熟练掌握下标父子关系与上滤、下滤过程。

# 选择题 第 6 题

6. 若只需3趟排序就可完成64个元素的多路归并排序,则选取的归并路数最少是 ( ).
A. 2
B. 3
C. 4
D. 5

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C08-87-M06_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：最少选取 4 路归并，选 C；因为 $4^3=64$，恰好 3 趟可以把 64 个元素归并成一个有序段。

**解题切入点**：  
拿到题目先抓“多路归并排序”的趟数模型。归并排序中每趟会把若干个有序段合并成更长的有序段；$k$ 路归并相当于“每轮把 $k$ 个有序流合并成一个有序流”。因此直接建立关系：

$$k^3 \ge 64$$

题目固定需要 3 趟，反求最小的 $k$ 即可。

**推演**：  
设归并路数为 $k$。初始 64 个元素可以看作 64 个长度为 1 的有序段。

每经过一趟 $k$ 路归并，$k$ 个有序段被合并成一个有序段，所以生成的有序段长度最多扩大到原来的 $k$ 倍：

- 第 1 趟后：每段最长 $k$；
- 第 2 趟后：每段最长 $k^2$；
- 第 3 趟后：每段最长 $k^3$。

要 3 趟完成全部排序，第 3 趟后必须把所有 64 个元素合并成一个有序段，因此必须满足：

$$k^3 \ge 64$$

逐项验证：

- $k=2$：$2^3=8<64$，不可能；
- $k=3$：$3^3=27<64$，不可能；
- $k=4$：$4^3=64$，刚好满足；
- $k=5$：$5^3=125>64$，也能完成，但不是最少。

也可以从归并段个数看：设第 $i$ 趟后有 $r_i$ 个归并段，则 $r_i=\lceil r_{i-1}/k\rceil$，$r_0=64$。当 $k=4$ 时：

$$64 \xrightarrow{\text{第 }1\text{ 趟}} 16 \xrightarrow{\text{第 }2\text{ 趟}} 4 \xrightarrow{\text{第 }3\text{ 趟}} 1$$

当 $k=3$ 时：

$$64 \xrightarrow{\text{第 }1\text{ 趟}} 22 \xrightarrow{\text{第 }2\text{ 趟}} 8 \xrightarrow{\text{第 }3\text{ 趟}} 3$$

仍不能完成。

关键代码思路：

```python
def min_merge_ways(n, passes):
    k = 2
    while k ** passes < n:
        k += 1
    return k

# n = 64, passes = 3，返回 4
```

所以最少选取：

$$\min k = 4$$

**易错点**：  
1. 把“归并路数”和“归并趟数”弄反：题目固定 3 趟，要求的是每趟几路归并。  
2. 忘记初始每个元素可看作一个有序段；没有这个视角，难以理解 $k^3$ 的来源。  
3. 把不等号方向记反：应是 $k^3\ge64$，不是 $k^3\le64$。  
4. 验证了 $k=5$ 可行就直接选 D，忽略题目问的是“最少”；必须排除 $k=2,3$ 后，再选 $k=4$。  
5. 用归并段数递推时，注意 $k=3$ 时第 3 趟后还剩 3 个归并段，并不是 1 段，因此不能完成。

**命题规律**：  
本考点属于“排序 / 外部排序”中的多路归并。常见命题形式有：

- 已知元素个数和归并路数，求最少归并趟数；
- 已知元素个数和允许趟数，反求最少归并路数；
- 结合败者树或选择树考查多路归并的比较次数；
- 外部排序中给出初始归并段数，求归并趟数和 I/O 次数。

复习时熟记核心关系：

$$k \text{ 路归并，趟数 } t=\lceil \log_k m\rceil$$

其中 $m$ 为初始归并段数；若每个元素初始就是一个有序段，则 $m=n$。做题时要先判断题目给的是“元素数”还是“初始归并段数”。

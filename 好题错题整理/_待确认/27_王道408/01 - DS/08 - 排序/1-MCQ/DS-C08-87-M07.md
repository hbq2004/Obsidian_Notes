# 选择题 第 7 题

![[_Attachments/题目识别/27_王道408-题目/DS-C08-87-M07_题目.png|题目]]

7.置换一选择排序的作用是 ( )。
A. 用于生成外部排序的初始归并段
B. 完成将一个磁盘文件排序成有序文件的有效的外部排序算法
C. 生成的初始归并段的长度是内存工作区的2倍
D. 对外部排序中输入/归并/输出的并行处理

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C08-87-M07_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：置换—选择排序的作用是生成外部排序的初始归并段，故选 **A**。

**解题切入点**：看到“置换—选择排序”要立刻定位到外部排序的知识点，它是外部排序中“初始归并段”的生成方法。做这类概念题可用“功能定义”法：明确每个选项对应的算法/阶段，而不是凭印象。就像打竞赛时，先判断题在考“排序的哪个环节”，再匹配算法。

**推演**：

外部排序的整体流程为：

1. **生成初始归并段**：将大文件分割成若干个长度尽可能大的有序段（归并段）；
2. **多路归并**：对这些归并段进行多路归并，最终得到一个有序文件。

置换—选择排序正是第 1 步中的核心算法。它的基本思想如下：

- 设内存工作区可容纳 $w$ 个记录；
- 先从输入文件读入 $w$ 个记录到内存；
- 每次从内存中选择一个最小的记录输出到归并段文件，同时从输入文件读入下一个记录补入内存；
- 若新读入的记录比刚输出的记录小，则它不能属于当前归并段，应暂时“冻结”，否则它属于当前归并段；
- 当内存中所有未被冻结的记录都小于当前归并段最后一个输出记录时，当前归并段结束，然后对“冻结”的记录重新开始下一个归并段。

关键伪代码思路如下：

```
输入: 待排序文件 F, 内存容量 w
输出: 初始归并段序列

读入 w 个记录到内存 W
while (输入文件未读完 或 内存中有未被冻结记录):
    if 当前归并段为空:
        以 W 中最小记录开始新归并段
    else:
        在未被冻结的记录中选择最小者 min
        if min > 当前归并段最后输出的记录:
            输出 min 到当前归并段
            从 F 读入新记录 x 补入 W
            if x < min: 标记 x 为冻结
        else:
            # 当前归并段结束
            结束当前归并段
            将所有冻结记录解冻，开始下一归并段
```

由此可知，置换—选择排序专门用于生成初始归并段，而不是完成整个外部排序，也不直接负责 I/O 并行处理。故：

- A 正确；
- B 错在“完成整个排序”，它只是外部排序的一个环节；
- C 错在“长度是内存工作区的 2 倍”，实际是平均长度约为 $2w$，但并不是精确的固定值，具体长度取决于输入序列；
- D 错在“输入/归并/输出的并行处理”是外部排序中利用多缓冲区、败者树等技术实现的手段，与置换—选择排序无直接关系。

**易错点**：

1. **混淆“生成初始归并段”与“完整外部排序”**  
   易误选 B。要记住完整外部排序 = 生成初始归并段 + 多路归并，置换—选择排序只负责前者。

2. **误认为归并段长度固定为 $2w$**  
   教材中说“平均长度约为 $2w$”，但这是经验值/平均值，不是严格等于。若题目说“是内存工作区的 2 倍”，即为错误表述。

3. **误将“并行处理”归功于它**  
   D 描述的是对外排序中通过多缓冲区和并行操作提高效率的技术，属于整体优化手段，不属于置换—选择排序的功能。

4. **忽略“冻结”记录的处理**  
   若题目考查算法细节，可能问“什么时候结束当前归并段”。需明确：当内存中所有未冻结记录都小于刚输出的记录时结束；冻结记录属于后续归并段。

**命题规律**：

- **考点定位**：外部排序中初始归并段的生成方法，常与败者树、多路归并、最佳归并树等知识点结合考查。
- **常见变式**：
  - 计算给定内存容量和输入序列下，置换—选择排序生成的初始归并段长度；
  - 判断某记录属于当前归并段还是下一个归并段；
  - 与“败者树”一起考查如何在置换—选择排序中高效选出最小记录；
  - 比较置换—选择排序与简单排序（如将所有记录排序后分段）的优劣。
- **复习建议**：
  - 理解置换—选择排序的“动态筛选”思想，能手动模拟一个长度为 $w$ 的例子；
  - 记住“平均长度约 $2w$”这个结论，但注意它不是精确值；
  - 将其放在外部排序完整流程中学习，明确各步骤的分工，防止概念混淆。

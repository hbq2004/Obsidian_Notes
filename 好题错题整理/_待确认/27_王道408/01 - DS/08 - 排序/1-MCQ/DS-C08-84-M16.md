16.【2011 统考真题】 已知序列 $\{25,13,10,12,9\}$ 是大根堆，在序列尾部插入新元素 $18$，再将其调整为大根堆，调整过程中元素之间进行的比较次数是 ( )。

(B) 2

## DeepSeek V4 Flash Max 解析

**答案**：插入 $18$ 后沿父链向上调整；需与父结点 $10$ 比较一次并交换，再与根结点 $25$ 比较一次后停止，因此元素比较次数为 $2$，选 **(B)**。

**解题切入点**：拿到题先识别这是“堆的插入操作”，对应的是**向上调整**，而不是建堆或堆排序中的向下调整。只需沿新插入元素到根结点的父链比较；可类比优先队列的 `push` 操作：新元素只和直接父结点比，不需要和所有元素比较。

**推演**：  
初始堆用 1-based 数组表示为：

$$
A[1..5]=\{25,13,10,12,9\}
$$

对应完全二叉树：

```
       25
      /  \
     13   10
    / \
   12  9
```

在尾部插入 $18$，数组变为：

$$
A[1..6]=\{25,13,10,12,9,18\}
$$

对应树：

```
       25
      /  \
     13   10
    / \  /
   12  9 18
```

调整过程：

1. $i=6$，父结点下标为 $\lfloor 6/2\rfloor=3$。  
   比较 $A[6]=18$ 与 $A[3]=10$，$18>10$，交换。  
   比较次数：$1$。  
   当前数组变为：

   $$
   \{25,13,18,12,9,10\}
   $$

2. $i=3$，父结点下标为 $\lfloor 3/2\rfloor=1$。  
   比较 $A[3]=18$ 与 $A[1]=25$，$18<25$，不交换，停止。  
   比较次数：$1$。

关键代码思想：

```cpp
void insertMaxHeap(int A[], int &n, int x) {
    A[++n] = x;
    for (int i = n; i > 1 && A[i] > A[i / 2]; i /= 2)
        swap(A[i], A[i / 2]);
}
```

其中 `A[i] > A[i/2]` 就是元素间比较。本题该条件共执行 $2$ 次，所以比较次数为 $2$。

**易错点**：

1. 误把“堆的插入”当成“建堆”或“向下调整”，可能数出 $4$ 或 $5$ 次；本题应该用向上调整。
2. 漏算最后一次失败的比较：$18$ 与 $25$ 比较后虽然不交换，但这次比较仍然存在，必须计入。
3. 把交换操作当成比较，`swap` 不算元素比较。
4. 不要将循环判断中的 `i > 1` 算入比较次数，题目问的是“元素之间”的比较次数。

**命题规律**：本题属于堆操作基础题，408 常以选择题考查堆插入、堆删除、建堆过程中的比较次数和移动次数。常见变式有：插入后询问堆序列、删除堆顶后询问调整次数、给定序列建堆求比较次数等。复习时需熟练掌握完全二叉树数组下标的父子和兄弟关系：

$$
parent(i)=\left\lfloor \frac{i}{2} \right\rfloor,\quad left(i)=2i,\quad right(i)=2i+1
$$

并严格区分“向上调整”与“向下调整”的计数方式。

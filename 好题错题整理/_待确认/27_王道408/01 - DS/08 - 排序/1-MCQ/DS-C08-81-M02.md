# 选择题 第 2 题

![[_Attachments/题目识别/27_王道408-题目/DS-C08-81-M02_题目.png|题目]]

2. 排序算法的稳定性是指(    ).
(A) 经过排序后，能使关键字相同的元素保持原顺序中的相对位置不变
(B) 经过排序后, 能使关键字相同的元素保持原顺序中的绝对位置不变
(C) 排序算法的性能与被排序元素个数关系不大
(D) 排序算法的性能与被排序元素的个数关系密切

## DeepSeek V4 Flash Max 解析

**答案**：选 A。排序稳定性是指：若两个元素关键字相等，则排序后它们在原序列中的相对先后次序保持不变。

**解题切入点**：这是数据结构中的概念辨析题。拿到题目先圈定“稳定性”三个字，它描述的是排序结果的一种性质，而不是时间复杂度或空间复杂度。打比方说：考试按总分排名，同分考生按报名号先后排序；稳定排序就是“同分者先报名的人仍然排在前面”，不会因为排序而把他们的原有次序打乱。

**推演**：

设原序列中有两条记录 $R_i$ 和 $R_j$，它们的关键字分别为 $K_i$ 和 $K_j$，并且原序列中 $R_i$ 排在 $R_j$ 前面，即 $i<j$。

若 $K_i=K_j$，稳定排序要求排序后 $R_i$ 仍然排在 $R_j$ 前面。用公式表达就是：

$$
i<j,\ K_i=K_j \quad \Rightarrow \quad pos(R_i)<pos(R_j)
$$

其中 $pos(R)$ 表示记录 $R$ 在排序后序列中的位置。

例如原序列为：

$$
[2_a,\ 1,\ 2_b]
$$

下标 $a,b$ 表示原序列中的先后次序，$2_a$ 与 $2_b$ 关键字相等。

按关键字从小到大稳定排序，结果为：

$$
[1,\ 2_a,\ 2_b]
$$

可以看到，$2_a$ 仍然在 $2_b$ 前面，所以相对位置保持不变。但 $2_a$ 从原序列的第 1 位变到了第 2 位，绝对位置发生了变化。因此稳定性只要求“相对位置不变”，不要求“绝对位置不变”。

逐项分析：

- A：关键字相同的元素保持原顺序中的相对位置不变，这正是稳定性的定义，正确。
- B：关键字相同的元素保持绝对位置不变，要求过强，排序本身通常会使大量元素移动，不正确。
- C、D：讨论的是排序算法性能与元素个数 $n$ 的关系，属于时间复杂度范畴，与“稳定性”无关，不能作为稳定性的定义。

若用代码思想理解稳定性：当两个元素的关键字相等时，不能随意交换它们。更一般地，可以让“原下标”作为次级关键字：

```
if (a.key != b.key)
    return a.key < b.key;
return a.originalIndex < b.originalIndex;
```

这个比较器等价于把排序关键字看作二元组 $(key,\ originalIndex)$，从而保证关键字相同者按原先后次序排列。

**易错点**：

1. 把“相对位置”误读成“绝对位置”。  
   稳定排序不保证元素最终仍落在原来的数组下标上，只保证相同关键字元素的先后次序不被破坏。

2. 误以为“稳定”就是“相同关键字排序后相邻”。  
   按关键字排序后相同关键字确实会归为一组，但稳定性的本质是组内保持原顺序，而不是“相邻”本身。

3. 把稳定性与时间复杂度混为一谈。  
   例如快速排序平均时间复杂度低，但通常不稳定；归并排序时间复杂度同样是 $O(n\log n)$，却是稳定的。稳定性和快慢没有必然关系。

4. 误选 D。  
   D 论述的是排序性能与元素个数关系密切，这更像在说时间复杂度，不是稳定性定义。

**命题规律**：本题考查排序算法基本概念，属于 408 选择题中的基础送分题。常见变式有：

- “下列排序算法中，哪些是稳定的？”
- “快速排序、堆排序、希尔排序、简单选择排序通常是不稳定的；插入排序、冒泡排序、归并排序、基数排序是稳定的。”
- 结合基数排序考察：基数排序要求内部按位排序必须稳定，否则会破坏之前位的排序结果。

复习时建议把各类排序算法的“时间复杂度、空间复杂度、稳定性”整理成表格，并重点理解：凡是发生“远距离交换”的排序，如快排、堆排、简单选择排序，容易破坏相同关键字的相对次序；凡是相邻比较或按原序列合并的排序，如插入、冒泡、归并，更容易保持稳定。

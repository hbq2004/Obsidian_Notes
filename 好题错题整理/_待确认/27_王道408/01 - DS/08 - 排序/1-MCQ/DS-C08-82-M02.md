# 选择题 第 2 题

2. 在待排序的元素序列基本有序的前提下，效率最高的排序算法是( ).
(A) 直接插入排序
(B) 简单选择排序
(C) 快速排序
(D) 归并排序

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C08-82-M02_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 **(A) 直接插入排序**。在待排序序列基本有序时，直接插入排序的比较和移动次数可降到 $O(n)$，是四个选项中效率最高的。

**解题切入点**：看到“基本有序”和“效率最高”，应立刻联想到排序算法对初始序列的敏感性。直接插入排序是“自适应”的：序列越有序，效率越高；而快速排序若固定选端点作枢轴，在基本有序时反而会退化。可以类比整理一副几乎排好的扑克牌：每张牌只需往后挪一两位就能插入，不需要像归并排序那样重新分成两半再合并。

**推演**：

设待排序序列为升序，长度为 $n$，且“基本有序”表示逆序数很小。

### 1. 直接插入排序

直接插入排序的基本思想是：将序列分为有序区和无序区，每次从无序区取一个元素，插入到有序区的合适位置。

关键代码思路：

```c
for (i = 2; i <= n; i++) {
    key = A[i];
    j = i - 1;
    while (j >= 1 && A[j] > key) {
        A[j + 1] = A[j];  // 后移
        j--;
    }
    A[j + 1] = key;
}
```

若原序列基本有序，则第 $i$ 个元素离其最终位置很近，内层 `while` 循环只需执行常数次。因此总时间约为

$$
\sum_{i=2}^{n} O(1)=O(n)
$$

更严谨地说，直接插入排序的总移动次数与序列的逆序数有关；基本有序时逆序数为 $O(n)$，所以总时间为 $O(n)$。

### 2. 简单选择排序

简单选择排序第 $i$ 趟要在后面的 $n-i+1$ 个元素中找最小值，比较次数不受初始序列影响：

$$
(n-1)+(n-2)+\cdots+1=\frac{n(n-1)}2
$$

所以它始终是 $O(n^2)$，即使序列已经有序也不能提前结束。

### 3. 快速排序

若固定选择第一个或最后一个元素作为枢轴，在基本有序的序列上，每次划分都会产生极度不平衡的两个子区间，递归式近似为

$$
T(n)=T(n-1)+O(n)
$$

解得

$$
T(n)=O(n^2)
$$

并且递归栈深度为 $O(n)$。

虽然使用随机化快速排序或三数取中法可以避免这种最坏情况，但一般仍为 $O(n\log n)$，在“基本有序”的前提下不如直接插入排序的 $O(n)$。

### 4. 归并排序

归并排序的时间复杂度与初始序列无关：

$$
T(n)=2T\left(\frac n2\right)+O(n)=O(n\log n)
$$

它需要额外 $O(n)$ 空间，而且即使序列基本有序也必须完整执行“分”和“治”的过程，不能像直接插入排序那样获得 $O(n)$ 的优势。

综上，本题选 **(A) 直接插入排序**。

**易错点**：

1. **误以为快速排序平均最快就选快速排序。**  
   快速排序在基本有序且固定端点作枢轴时，会退化为 $O(n^2)$，是本题最大的陷阱。

2. **误以为归并排序稳定且 $O(n\log n)$，所以效率最高。**  
   归并排序不受初始有序性影响，但 $O(n\log n)$ 比直接插入排序在基本有序时的 $O(n)$ 慢。

3. **忽视简单选择排序的比较次数与初始序列无关。**  
   简单选择排序即使输入已经有序，比较次数仍然是 $\frac{n(n-1)}2$，不能提前结束。

4. **把“平均复杂度”和“某特定输入下的复杂度”混淆。**  
   排序算法题必须看清是否强调初始序列状态。基本有序时应优先考虑“自适应”的插入类排序。

**命题规律**：本题属于“排序算法与初始序列关系”的高频考点。408 中常以选择题考查：

- 在基本有序或完全有序时，效率最高的排序算法；
- 快速排序在有序/逆序序列下的最坏情况；
- 哪些排序算法的最好时间复杂度为 $O(n)$；
- 排序算法的稳定性、空间复杂度与初始序列的关系。

复习时要重点掌握：直接插入排序和优化后的冒泡排序具有“自适应”性，最好情况为 $O(n)$；快速排序在最坏情况下为 $O(n^2)$；简单选择排序和归并排序对初始序列不敏感。建议将各排序算法按“最好、平均、最坏时间复杂度、空间复杂度、稳定性、是否依赖初始序列”列成表格对比记忆。

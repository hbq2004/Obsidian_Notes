# 选择题 第 20 题

![[_Attachments/题目识别/27_王道408-题目/DS-C08-83-M20_题目.png|题目]]

20.【2024统考真题】使用快速排序算法对含 $n(n\geqslant3)$ 个元素的数组 $M$ 进行排序，若第一趟排序将 $M$ 中除枢轴外的 $n-1$ 个元素划分为均不为空的 $P$ 和 $Q$ 两块，则下列叙述中,正确的是 ( ).
(A) $P$ 与 $Q$ 块间有序
(B) $P$ 与 $Q$ 均块内有序
(C) $P$ 和 $Q$ 的元素个数大致相等
(D) $P$ 中和 $Q$ 中均不存在相等的元素

## DeepSeek V4 Flash Max 解析

**答案**：选 $\boxed{\text{A}}$。快速排序第一趟划分后，枢轴到达最终位置，枢轴左侧块 $P$ 整体不大于枢轴，枢轴右侧块 $Q$ 整体不小于枢轴，因此 $P$ 与 $Q$ 块间有序；但块内是否有序、两块是否均匀、是否存在相等元素都不能由一趟划分保证。

**解题切入点**：拿到题目先抓住快速排序第一趟的本质：一趟 `Partition` 做了什么？它只是确定一个枢轴的最终位置，并把数组分成“左边整体 $\le$ 枢轴 $\le$ 右边整体”的两块。这就像按某个人的身高为基准把队伍分成两队：只保证左队整体不比右队高，不保证每队内部按身高排好，也不保证两队人数接近。所以直接定位到划分不变式。

**推演**：

设第一趟划分后枢轴的最终位置为 $k$，令 $P$ 为枢轴左侧块，$Q$ 为枢轴右侧块。一趟划分的核心性质是：

$$
\max(P)\le M[k]\le \min(Q)
$$

因此：

$$
\max(P)\le \min(Q)
$$

也就是 $P$ 中任意元素不大于 $Q$ 中任意元素，所以 $P$ 与 $Q$ 块间有序，A 正确。

常见划分伪代码如下：

```c
int Partition(int A[], int low, int high) {
    int pivot = A[low];              // 取第一个元素为枢轴
    while (low < high) {
        while (low < high && A[high] >= pivot) high--;
        A[low] = A[high];
        while (low < high && A[low] <= pivot) low++;
        A[high] = A[low];
    }
    A[low] = pivot;
    return low;                       // 枢轴最终位置
}
```

其他选项排除：

- B 错：一趟划分不保证 $P$、$Q$ 内部有序。例如 $M=[3,1,4,2]$，取 $3$ 为枢轴，一趟后为 $[2,1,3,4]$，$P=[2,1]$ 显然块内无序。
- C 错：划分是否均衡取决于枢轴在数组中的大小位置。例如 $M=[2,1,3,4,5,6]$，取 $2$ 为枢轴，一趟后为 $[1,2,3,4,5,6]$，$P=[1]$，$Q=[3,4,5,6]$，个数相差很大。
- D 错：一趟划分不能保证没有相等元素。例如 $M=[3,2,2,4]$，取 $3$ 为枢轴，一趟后为 $[2,2,3,4]$，$P=[2,2]$ 内就有相等元素。

**易错点**：

1. 误以为快速排序一趟后左右两块内部也有序。实际上只有枢轴到达最终位置，左右两块内部还要递归排序。
2. 误以为“$P$、$Q$ 均非空”等价于“划分均衡”。非空只说明枢轴不在两端，仍可能出现极端不平衡划分。
3. 忽略相等关键字。快速排序是不稳定排序，划分过程中等于枢轴的关键字可能留在任一侧，因此不能断言 $P$、$Q$ 内或两块之间没有相等元素。
4. 模拟 `Partition` 时注意比较符号：右扫描找小于枢轴的元素，左扫描找大于枢轴的元素；等号的处理会影响相等元素的位置。

**命题规律**：考点是快速排序一趟划分的性质，属于 408 高频概念题。常见变式有：给一个序列和枢轴，写出第一趟划分结果；给第一趟划分后的序列，判断哪个元素可能是枢轴；以及比较快排、堆排、归并排序每趟排序后的确定信息。复习时要亲手模拟挖坑法和交换法两种划分过程，并牢记结论：快速排序一趟划分后“块间有序、块内无序、枢轴落位、划分不一定均衡、不稳定”。

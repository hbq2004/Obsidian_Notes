1. 对5个不同的数据元素进行直接插入排序，最多需要进行的比较次数是 (   )。注意，哨兵的比较不计入次数.

B. 10

## 答案

## DeepSeek V4 Flash Max 解析

**答案**：对 5 个不同数据元素进行直接插入排序，最多需要比较  
$$\sum_{i=2}^{5}(i-1)=1+2+3+4=10$$  
次，因此选 **B**。

**解题切入点**：  
直接插入排序的“最多比较次数”对应**最坏情况**，即初始序列为**逆序**。可以类比打扑克牌理牌：新抓到的牌如果最小，就要和手里所有已经排好的牌各比较一次，才能放到最前面。插入第 $i$ 个元素时，前面有序区已有 $i-1$ 个元素，所以这一趟最多比较 $i-1$ 次。题目特别说明**哨兵比较不计入次数**，因此不能每趟再加 1。

**推演**：  
设 5 个元素为 $a_1,a_2,\dots,a_5$，最坏情况如逆序序列：

$$5,4,3,2,1$$

直接插入排序从第 2 个元素开始，逐个插入前面已经有序的部分。

带哨兵的核心过程为：

```c
for (i = 2; i <= n; i++) {
    r[0] = r[i];              // r[0] 为哨兵
    j = i - 1;
    while (r[0].key < r[j].key) {
        r[j + 1] = r[j];
        j--;
    }
    r[j + 1] = r[0];
}
```

当插入 $a_i$ 时，若它比有序区中所有 $i-1$ 个元素都小，就需要依次与这些元素比较；最后和哨兵 $r[0]$ 的比较只用于判断“是否已到表头”，不计入次数。

各趟最多比较次数如下：

- 插入第 2 个元素：比较 $1$ 次；
- 插入第 3 个元素：比较 $2$ 次；
- 插入第 4 个元素：比较 $3$ 次；
- 插入第 5 个元素：比较 $4$ 次。

因此总次数为：

$$
C_{\max}(5)=\sum_{i=2}^{5}(i-1)=1+2+3+4=10.
$$

一般地，对 $n$ 个元素进行直接插入排序，最多比较次数为：

$$
C_{\max}(n)=\sum_{i=2}^{n}(i-1)=\frac{n(n-1)}{2}.
$$

所以本题选 **B**。

**易错点**：  
1. 把哨兵比较也算进去，容易算成 $2+3+4+5=14$，或误用 $\frac{n(n+1)}{2}$ 得到 $15$，从而错选 C。  
2. 把“最多”误当作“升序正序”的最好情况，只算 $n-1=4$ 次，得不到选项。  
3. 混淆“比较次数”和“移动次数”。最坏情况下移动次数也比较多，但本题只问比较次数。  
4. 忽略“不同数据元素”这个条件：若有关键字相等，比较可能提前结束，但最坏情况仍由逆序产生，题设条件不影响最大值。

**命题规律**：  
本题属于排序章节的基础考点，常以选择题考查直接插入排序在最坏情况、最好情况下的比较次数和移动次数。常见变式有：

- $n$ 个元素直接插入排序最少比较次数为 $n-1$；
- 折半插入排序的比较次数分析；
- 希尔排序、冒泡排序、快速排序最坏情况的对比。

复习时应以手算模拟为主，把 $n=5$ 的正序、逆序过程各推一遍，再记住关键结论。遇到“最多比较次数”可直接套用：

$$
C_{\max}(n)=\frac{n(n-1)}{2}.
$$

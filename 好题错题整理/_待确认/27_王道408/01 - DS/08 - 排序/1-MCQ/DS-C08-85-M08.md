8. 用归并排序算法对序列 {1,2,6,4,5,3,8,7} 进行排序，共需要进行 ( \_ ) 次比较。
(A) 12
(B) 13
(C) 14
(D) 15

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C08-85-M08_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：对该序列执行二路归并排序，共需要进行 $14$ 次关键字比较，故选 **C**。

**解题切入点**：归并排序中真正产生“关键字比较”的地方只有合并两个有序子序列的过程，递归划分不比较。做题时应按归并段长度 $1\to2\to4\to8$ 逐层展开，统计每一层每个 Merge 中双指针 while 循环的执行次数。可以把它类比为“小组赛”：每个小组内部比完后再合并，比较次数不是直接套 $O(n\log n)$。

**推演**：

归并排序合并两段有序表的代码思路是：

```c
while (i <= mid && j <= high) {
    if (a[i] <= a[j]) tmp[k++] = a[i++];   // 比较 1 次
    else tmp[k++] = a[j++];
}
// 某一侧先耗尽后，剩余元素直接复制，不再比较
```

因此，统计每次进入 while 循环的次数即可。

初始序列：

$$
\{1,2,6,4,5,3,8,7\}
$$

看成 8 个长度为 1 的有序段。

**第 1 趟：段长 $1\to2$**

- $[1]$ 与 $[2]$：比较 $1<2$，左段空，$2$ 直接移入，比较 $1$ 次，得 $[1,2]$；
- $[6]$ 与 $[4]$：比较 $6>4$，右段空，$6$ 直接移入，比较 $1$ 次，得 $[4,6]$；
- $[5]$ 与 $[3]$：比较 $5>3$，右段空，$5$ 直接移入，比较 $1$ 次，得 $[3,5]$；
- $[8]$ 与 $[7]$：比较 $8>7$，右段空，$8$ 直接移入，比较 $1$ 次，得 $[7,8]$。

第 1 趟共比较：

$$
1+1+1+1=4
$$

得到：

$$
[1,2],\;[4,6],\;[3,5],\;[7,8]
$$

**第 2 趟：段长 $2\to4$**

- 合并 $[1,2]$ 与 $[4,6]$：
  - 比较 $1<4$，取 $1$；
  - 比较 $2<4$，取 $2$；
  - 左段空，$[4,6]$ 直接复制。

  比较 $2$ 次。

- 合并 $[3,5]$ 与 $[7,8]$：
  - 比较 $3<7$，取 $3$；
  - 比较 $5<7$，取 $5$；
  - 左段空，$[7,8]$ 直接复制。

  比较 $2$ 次。

第 2 趟共比较：

$$
2+2=4
$$

得到：

$$
[1,2,4,6],\;[3,5,7,8]
$$

**第 3 趟：段长 $4\to8$**

合并 $[1,2,4,6]$ 与 $[3,5,7,8]$：

1. 比较 $1$ 与 $3$，$1<3$，取 $1$；
2. 比较 $2$ 与 $3$，$2<3$，取 $2$；
3. 比较 $4$ 与 $3$，$4>3$，取 $3$；
4. 比较 $4$ 与 $5$，$4<5$，取 $4$；
5. 比较 $6$ 与 $5$，$6>5$，取 $5$；
6. 比较 $6$ 与 $7$，$6<7$，取 $6$；

此时左段已空，右段剩余 $[7,8]$ 直接复制。

第 3 趟共比较 $6$ 次。

所以总比较次数为：

$$
4+4+6=14
$$

答案：**C（14 次）**。

**易错点**：

1. **把每次归并都按最坏情况计算**：两个长度分别为 $m,n$ 的有序表归并，最多比较 $m+n-1$ 次，但不一定每次都达到最大值。例如 $[1,2]$ 与 $[4,6]$ 只需 $2$ 次，不是 $3$ 次。
2. **忽略“某一段先空后直接复制”**：当一侧子序列为空时，剩余元素不需要再比较，直接放入结果即可。若把第 3 趟误算成 $7$ 次，就会错选 D。
3. **把“趟数”当“比较次数”**：8 个元素二路归并有 $3$ 趟，但比较次数不是简单等于 $8\times3$。
4. **认为归并排序比较次数与初始序列无关**：实际上归并排序的比较次数与数据排列有关，本题中因为某些子序列提前耗尽，比较次数少于对应最坏情况。

**命题规律**：本题属于 408 中“内部排序”的常考知识点，重点考查归并排序的执行过程、比较次数统计、归并趟数、稳定性与空间复杂度。常见变式包括：给一个特定序列要求手算归并排序过程中的某趟结果；求两个有序表归并的最多比较次数；判断某个序列是否可能是某趟归并后的结果。复习时应熟练掌握段长 $1,2,4,\dots$ 的手算流程，并牢记 Merge 循环退出后直接复制剩余元素，不再比较。

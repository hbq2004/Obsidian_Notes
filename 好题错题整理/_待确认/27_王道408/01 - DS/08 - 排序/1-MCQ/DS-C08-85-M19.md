# 选择题 第 19 题

![[_Attachments/题目识别/27_王道408-题目/DS-C08-85-M19_题目.png|题目]]

19.【2022 统考真题】使用 2 路归并排序对含 $n$ 个元素的数组 $M$ 进行排序时,2 路归并排序的功能是 ( ).  
A. 将两个有序表合并为一个新的有序表  
B. 将 $M$ 划分为两部分, 两部分的元素个数大致相等  
C. 将 $M$ 划分为 $n$ 个部分, 每个部分中仅含有一个元素  
D. 将 $M$ 划分为两部分, 一部分元素的值均小于另一部分元素的值

## DeepSeek V4 Flash Max 解析

**答案**：选 A。2 路归并排序（二路归并）的功能是“将两个有序表合并为一个新的有序表”。

**解题切入点**：  
题干核心词是“2 路归并”，要立刻定位到归并排序中的 **Merge（归并）操作**，而不是“排序全过程”。做题经验：看到“两个有序输入、一个有序输出”，就是归并；看到“一部分元素小于另一部分元素”，应想到快速排序的 partition，而不是归并排序。B、C 只是归并排序的“分”阶段或初始状态，不是“归并”本身。

**推演**：  

“归并”的定义是：把两个或两个以上已经有序的序列合并成一个新的有序序列。  
2 路归并就是每次取 **两个有序表** 进行合并。

设两个有序表为 $A[1..m]$、$B[1..n]$，合并结果存入 $C[1..m+n]$。比较 $A[i]$ 与 $B[j]$，把较小者写入 $C[k]$，然后相应指针后移；若其中一个表已经取完，则把另一个表剩余部分直接复制到 $C$ 中。

关键过程可写成：

```c
Merge(A, B) {
    i = j = k = 1;
    while (i <= m && j <= n) {
        if (A[i] <= B[j])
            C[k++] = A[i++];
        else
            C[k++] = B[j++];
    }
    while (i <= m) C[k++] = A[i++];
    while (j <= n) C[k++] = B[j++];
    return C;
}
```

一次 Merge 的时间复杂度为 $O(m+n)$。  
对含 $n$ 个元素的数组 $M$ 做 2 路归并排序时，初始可把 $M$ 看成 $n$ 个长度为 1 的有序子表，然后反复进行“两两归并”，每趟后有序子表长度翻倍，直到只剩一个有序表。

选项辨析：

- A：正是“归并”的定义，正确。  
- B：将 $M$ 分成元素个数大致相等的两部分，是递归归并排序中的“分”阶段，不是“归并”功能；且“2 路”指的是每次合并两个有序表，不是指把数组分成两半。  
- C：将 $M$ 划分成 $n$ 个单元素部分，只是归并排序的初始状态，不是归并操作本身。  
- D：将 $M$ 分成“一部分元素均小于另一部分元素”的两部分，是快速排序的划分操作，不是归并。

**易错点**：  
1. 把 B 误选为答案。二分划分是分治策略中的“分”，不是“归并”。  
2. 把 C 误选为答案。$n$ 个单元素子表是归并排序开始前的状态，不是归并功能。  
3. 把 D 误选为答案。D 是快速排序的 partition，按枢轴划分；归并排序是按元素大小合并两个有序表。  
4. 实现 Merge 时，若两个表元素相等，为保持稳定性应先取左表元素；不能随意选择。  
5. 忘记 Merge 需要额外辅助数组，归并排序空间复杂度为 $O(n)$，不是原地排序。

**命题规律**：  
考点是排序章节中的“归并排序基本概念”，属于概念辨析题。常见变式有：给出一趟归并后的序列，求下一趟归并结果；求归并趟数 $\lceil \log_2 n\rceil$；将二路归并扩展到 $k$ 路归并；以及区分快速排序 partition 与归并排序 merge。复习时应熟练手写 Merge 函数，理解归并排序“分解—归并”的分治框架，并掌握其时间 $O(n\log n)$、空间 $O(n)$、稳定性等性质。

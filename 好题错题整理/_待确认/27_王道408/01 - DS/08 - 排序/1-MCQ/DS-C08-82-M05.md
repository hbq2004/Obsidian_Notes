# 选择题 第 5 题

5. 用直接插入排序算法对下列4个表进行（从小到大）排序，比较次数最少的是（ ）.
A. 94, 32, 40, 90, 80, 46, 21, 69
B. 21, 32, 46, 40, 80, 69, 90, 94
C. 32, 40, 21, 46, 69, 94, 90, 80
D. 90, 69, 80, 46, 21, 32, 94, 40

## DeepSeek V4 Flash Max 解析

**答案**：选 B。四个表的直接插入排序关键字比较次数分别为 A：22、B：9、C：11、D：22，B 最少。

**解题切入点**：直接插入排序就像打扑克理牌：新元素从右往左与前面已排好序的元素比较，遇到第一个“不大于”它的元素就停下；如果它比前面所有元素都小，则要比较完整个有序区。本题只数“比较次数”，不要被移动次数干扰。

**推演**：

直接插入排序核心过程为：

```cpp
for (int i = 1; i < n; i++) {
    int tmp = a[i], j = i - 1;
    while (j >= 0 && tmp < a[j]) {
        a[j + 1] = a[j];
        j--;
    }
    a[j + 1] = tmp;
}
```

这里“关键字比较”发生在 `tmp < a[j]`，数组下标判断 `j >= 0` 不计入关键字比较次数。

设第 $k$ 个元素插入时，插入完成后它前面有 $p_k$ 个元素。则：

- 若 $p_k = 0$，说明它是最小的，比较次数为 $k-1$；
- 若 $p_k > 0$，说明它不是最小的，需要与比它大的元素比较，再与它前面的元素比较一次停止，比较次数为 $k-p_k$。

逐项模拟得到：

| 表 | 第 $2\sim 8$ 个元素插入时的比较次数 | 合计 |
|---|---|---|
| A | $1,2,2,3,4,6,4$ | $22$ |
| B | $1,1,2,1,2,1,1$ | $9$ |
| C | $1,2,1,1,1,2,3$ | $11$ |
| D | $1,2,3,4,5,1,6$ | $22$ |

例如 B 中第 4 个元素是 $40$，前面有序区为 $[21,32,46]$，先与 $46$ 比较，再与 $32$ 比较，共 $2$ 次。

所以比较次数最少的是 B。

**易错点**：

- 容易漏算“停止位置”的那一次比较。比如 D 中插入 $32$ 时，先与 $90,80,69,46$ 比较，还要再与 $21$ 比较一次才知道停止。
- 容易把移动次数、交换次数与比较次数混淆；直接插入排序中比较次数和移动次数不是一回事。
- 不要凭“大致有序”直接选 C；C 虽然前一段比较有序，但 $21$、$90$、$80$ 的插入仍带来较多比较。
- 插入到最前面时，比较次数等于前面元素个数，不要再额外加一次。

**命题规律**：本题属于排序算法性能分析中的常考点，核心是直接插入排序与初始序列的关系。常见变式包括：求给定序列的“移动次数”“比较次数”“排序趟数”，或比较直接插入排序、冒泡排序、简单选择排序在同一序列下的性能。复习时应熟练掌握直接插入排序的一趟过程，理解“逆序数”对比较次数的影响，并能手工模拟排序过程。

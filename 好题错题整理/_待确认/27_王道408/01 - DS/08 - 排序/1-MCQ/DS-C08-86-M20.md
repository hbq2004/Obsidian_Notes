20.【2022统考真题】对数据进行排序时,若采用直接插入排序而不采用快速排序,则可能的原因是( )
$I$.大部分元素已有序
$II$.待排序元素数量很少
$III$.要求空间复杂度为$O(1)$
$IV$.要求排序算法稳定
A. 仅$I$、$II$
B. 仅$III$、$IV$
C. 仅$I$、$II$、$IV$
D. $I$、$II$、$III$、$IV$

## DeepSeek V4 Flash Max 解析

**答案**：选 **D**。四个条件 $I、II、III、IV$ 都是“采用直接插入排序而不采用快速排序”的可能原因。

**解题切入点**：  
拿到题目先不要急着比较“谁快”，而应列出排序算法的“四维性质”：时间复杂度、空间复杂度、稳定性、常数/递归开销。快速排序平均最快，但它在“基本有序”“规模很小”“要求稳定”“要求 $O(1)$ 空间”这些场景下并不占优；直接插入排序却正好在这些场景下有优势。可以把快速排序比作“重型工具”，直接插入排序比作“轻量工具”，小规模或近似有序时轻量工具反而更合适。

**推演**：  
先比较两种排序的核心性质。

| 排序算法 | 最好时间 | 平均时间 | 最坏时间 | 空间复杂度 | 稳定性 |
|---|---|---|---|---|---|
| 直接插入排序 | $O(n)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | 稳定 |
| 快速排序 | $O(n\log n)$ | $O(n\log n)$ | $O(n^2)$ | 平均 $O(\log n)$，最坏 $O(n)$ | 不稳定 |

直接插入排序核心代码思路：

```c
for (i = 2; i <= n; i++) {
    key = A[i];
    j = i - 1;
    while (j >= 1 && A[j] > key) {
        A[j + 1] = A[j];
        j--;
    }
    A[j + 1] = key;
}
```

该代码只用常数个辅助变量，空间为 $O(1)$；判断条件用 `>` 而不是 `>=$，因此相等元素不会交换，排序稳定；若序列基本有序，内层 `while` 多数情况下只需比较一次，复杂度接近 $O(n)$。

逐项判断：

$I.$ 大部分元素已有序：直接插入排序接近最好情况，复杂度接近 $O(n)$；而基础快速排序若选择端点元素作枢轴，在基本有序序列上会划分严重不平衡，递推式为  
$$
T(n)=T(n-1)+\Theta(n)=\Theta(n^2),
$$
效率很低。因此 $I$ 是可能原因。

$II.$ 待排序元素数量很少：$n$ 很小时，$O(n^2)$ 与 $O(n\log n)$ 的渐近差距不足以抵消常数因子和递归开销；直接插入排序实现简单、无递归调用，通常更快。因此 $II$ 是可能原因。

$III.$ 要求空间复杂度为 $O(1)$：直接插入排序原地排序，只用常数个辅助变量；快速排序需要递归工作栈，平均空间为 $O(\log n)$，最坏为 $O(n)$，不满足 $O(1)$。因此 $III$ 是可能原因。

$IV.$ 要求排序算法稳定：直接插入排序稳定；常规快速排序在划分时交换相距较远的元素，不能保证稳定性。因此 $IV$ 是可能原因。

所以 $I、II、III、IV$ 都正确，答案选 **D**。

**易错点**：  
- 误以为“快速排序平均最快，所以任何情况下都应该选快速排序”。复杂度是渐近性质，$n$ 很小或序列基本有序时，直接插入排序反而更优。  
- 误以为“快速排序是原地排序，所以空间复杂度是 $O(1)$”。快速排序的原地划分确实只用常数个辅助空间，但递归调用栈的空间不能忽略。  
- 误以为“快速排序可以改为稳定版本，所以 $IV$ 不成立”。408 中默认讨论的是经典快速排序，它是不稳定的。  
- 直接插入排序的稳定性来自 `>` 而非 `>=`，若代码写成 `A[j] >= key`，稳定性就会被破坏。

**命题规律**：  
本题属于“排序算法性质与适用场景”的高频考点。常见变式有：  
1. 根据稳定性、空间复杂度、时间复杂度选择排序算法；  
2. 判断“某算法在所有情况下都优于另一算法”这类说法；  
3. 对八大排序的性质列表进行综合比较。  
复习时应熟记：快速排序平均最快但最坏 $O(n^2)$、不稳定、空间 $O(\log n)$；直接插入排序稳定、空间 $O(1)$、适合基本有序和小规模数据；堆排序空间 $O(1)$ 但不稳定；归并排序稳定但空间 $O(n)$。

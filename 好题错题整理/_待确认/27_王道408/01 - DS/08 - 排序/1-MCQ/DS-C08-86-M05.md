5. 就排序算法所用的辅助空间而言,堆排序、快速排序和归并排序的关系是(  ).
A. 堆排序<快速排序<归并排序
B. 堆排序<归并排序<快速排序
C. 堆排序>归并排序>快速排序
D. 堆排序>快速排序>归并排序

## 答案

## DeepSeek V4 Flash Max 解析

**答案**：选 A。堆排序、快速排序、归并排序的辅助空间关系为：堆排序 $O(1)$ < 快速排序 $O(\log n)$（教材/统考默认平均/常规划分情况） < 归并排序 $O(n)$。

**解题切入点**：拿到题先区分“时间开销”和“空间开销”。空间开销要问：除了输入数组本身，算法额外还用了什么？  
堆排序是在原数组上“原地整理”，只需要常数个临时变量；快速排序虽然不需要额外数组，但递归需要栈；归并排序合并两个有序段时，通常需要一块与原数组等长的辅助数组。这样就能快速定位：堆排序空间最小，归并排序空间最大，快速排序居中。

**推演**：

辅助空间指算法运行时额外开辟的空间，不计入待排数组本身。分别看三种算法：

1. **堆排序**  
   堆排序建堆、调整、交换都在原数组上进行。  
   每次把堆顶与当前末尾元素交换后，只需要对堆顶做“下滤”调整，下滤过程可用迭代实现，不需要额外数组，也不需要递归栈。  
   因此：
   $$
   S_{\text{堆排序}}=O(1)
   $$

2. **快速排序**  
   快速排序的每趟划分是在原数组内通过交换完成的，不需要与原数组等长的辅助数组。  
   但快速排序是递归算法，每次递归调用都要把待排序区间的边界压入递归工作栈。若每次划分较均匀，递归栈深度为 $O(\log n)$；平均/常规情况下也取 $O(\log n)$。  
   因此：
   $$
   S_{\text{快速排序}}=O(\log n)
   $$

   补充说明：若快速排序最坏退化到每次划分极不平衡，递归栈深度可达 $O(n)$，但本题按教材/统考默认口径，取平均/常规划分，故记为 $O(\log n)$。

3. **归并排序**  
   二路归并排序的“合并”操作需要把两个有序段合并成一个有序段。在数组实现中，通常需要申请一个与原数组等长的辅助数组来暂存合并结果，再复制回原数组。  
   虽然递归栈也会占用 $O(\log n)$ 空间，但相对于 $O(n)$ 的辅助数组，$O(n)$ 是主导项。  
   因此：
   $$
   S_{\text{归并排序}}=O(n)
   $$

三种排序算法辅助空间的渐近阶为：

$$
O(1)<O(\log n)<O(n)
$$

对应关系就是：

$$
\text{堆排序}<\text{快速排序}<\text{归并排序}
$$

所以选 **A**。

对应实现判断思路如下：

```cpp
// 堆排序：原地建堆 + 交换，无额外数组
BuildMaxHeap(A, n);
for (i = n - 1; i > 0; --i) {
    swap(A[0], A[i]);
    AdjustDown(A, 0, i); // 下滤，只需要常数辅助空间
}

// 快速排序：递归栈决定辅助空间
void QuickSort(A, l, r) {
    if (l < r) {
        p = Partition(A, l, r); // 原数组内划分
        QuickSort(A, l, p - 1);
        QuickSort(A, p + 1, r);
    }
}

// 归并排序：合并时需要长度为 n 的辅助数组 B
void MergeSort(A, l, r) {
    if (l < r) {
        mid = (l + r) / 2;
        MergeSort(A, l, mid);
        MergeSort(A, mid + 1, r);
        Merge(A, l, mid, r, B); // B 为与原数组等长的辅助数组
    }
}
```

**易错点**：

- 容易把快速排序误判为 $O(1)$：快排确实不需要额外数组，但递归栈本身就是辅助空间，不能忽略。
- 容易把归并排序只算递归栈 $O(\log n)$：实际上 merge 需要的辅助数组是 $O(n)$，这才是主导项。
- 容易把堆排序误认为需要额外建堆数组：堆排序是在原数组上建堆的，不需要额外数组。
- 本题按教材默认取快速排序 $O(\log n)$；如果题目明确问“最坏情况下”，快速排序的递归栈最坏可达 $O(n)$，但这不是该题选项比较的口径。

**命题规律**：本题属于排序算法性能横向比较，是 408 选择题常考考点。常见变式包括：问“辅助空间最大/最小的排序算法”、把堆排序/快速排序/归并排序与直接插入、希尔、基数排序混合比较，或者把时间、空间、稳定性交叉出题。复习时应把各内部排序算法的时间复杂度、空间复杂度、稳定性整理成表，特别注意快速排序的平均空间复杂度 $O(\log n)$、最坏空间复杂度 $O(n)$，以及归并排序辅助数组 $O(n)$ 这一关键区别。

6. 就平均性能而言，目前最好的内部排序算法是 ( ).

(A). 冒泡排序
(B). 直接插入排序
(C). 希尔排序
(D). 快速排序

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C08-83-M06_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 **(D) 快速排序**。快速排序在平均情况下的时间复杂度为 $O(n\log n)$，且常数因子较小，通常被认为是平均性能最好的内部排序算法。

**解题切入点**：
- 看到“平均性能”四个字，首先应该比较各算法的**平均时间复杂度**，而不是最坏情况或最好情况。
- 冒泡排序和直接插入排序的平均时间复杂度都是 $O(n^2)$；希尔排序虽然是对插入排序的改进，但平均性能依增量序列而定，通常不如快速排序。
- 四个选项中，只有快速排序的平均复杂度达到 $O(n\log n)$，因此直接选 D。
- 可以类比竞赛中的做法：先看算法复杂度，再看常数因子；快速排序平均情况下的常数比其他 $O(n\log n)$ 的比较排序更小，所以“平均性能最好”。

**推演**：

### 1. 各选项平均性能比较

| 算法 | 平均时间复杂度 | 最坏时间复杂度 | 稳定性 |
|---|---|---|---|
| 冒泡排序 | $O(n^2)$ | $O(n^2)$ | 稳定 |
| 直接插入排序 | $O(n^2)$ | $O(n^2)$ | 稳定 |
| 希尔排序 | 约为 $O(n^{1.3})$ 或 $O(n(\log n)^2)$，视增量序列而定 | 与增量序列有关 | 不稳定 |
| 快速排序 | $O(n\log n)$ | $O(n^2)$ | 不稳定 |

由上表可见，就平均性能而言，快速排序明显优于前三者。

### 2. 快速排序平均复杂度为什么是 $O(n\log n)$

快速排序是分治算法：

- 每次选择基准元素 `pivot`；
- 通过一趟划分把序列分成左右两部分，左侧元素都不大于 `pivot`，右侧元素都不小于 `pivot`；
- 再对左右两部分递归排序。

若每次划分都能把序列近似分成两半，则递归式为：

$$
T(n)=2T\left(\frac n2\right)+O(n)
$$

解得：

$$
T(n)=O(n\log n)
$$

这是快速排序的平均情况。即使在平均意义下划分不完全均匀，设基准元素在所有位置等概率出现，则期望复杂度满足：

$$
T(n)=n-1+\frac{1}{n}\sum_{k=1}^{n}\big(T(k-1)+T(n-k)\big)
$$

同样可以解得 $T(n)=O(n\log n)$。因此平均情况下快速排序足够快。

### 3. 快速排序关键代码思路

快速排序的核心在于划分过程 `Partition`：

```c
// 以 A[low] 为基准，将数组划分为左右两部分
int Partition(int A[], int low, int high) {
    int pivot = A[low];          // 取第一个元素为基准
    while (low < high) {
        while (low < high && A[high] >= pivot) --high;
        A[low] = A[high];        // 把小于等于 pivot 的值移到左边
        while (low < high && A[low] <= pivot) ++low;
        A[high] = A[low];        // 把大于等于 pivot 的值移到右边
    }
    A[low] = pivot;              // 基准归位
    return low;                  // 返回划分位置
}

void QuickSort(int A[], int low, int high) {
    if (low < high) {
        int pos = Partition(A, low, high);
        QuickSort(A, low, pos - 1);
        QuickSort(A, pos + 1, high);
    }
}
```

这种“挖坑 + 双指针移动”的实现是 408 中常见的考法。

**易错点**：
- **误选希尔排序**：希尔排序确实比直接插入排序快，但平均性能仍不如快速排序，而且复杂度与增量序列有关，不够稳定。
- **因为快速排序最坏情况是 $O(n^2)$ 而否定它**：题干问的是“平均性能”，不是“最坏性能”，所以不能依据最坏情况排除 D。
- **认为所有 $O(n\log n)$ 排序算法一样好**：堆排序、归并排序也是 $O(n\log n)$，但平均常数因子通常比快速排序大；快速排序在平均意义下更优。
- **忽略稳定性**：快速排序是不稳定的，但稳定性与“平均性能”是两回事；不能因为不稳定就认为它不是最优选项。
- **忽略适用场景**：若数据规模很小或基本有序，直接插入排序可能更快；但题目问的是普遍平均性能，仍选快速排序。

**命题规律**：
- 本题属于“内部排序算法比较”的基础题，考查各排序算法的平均时间复杂度。
- 常考变式包括：给定一个序列，写出快速排序第一趟划分结果；判断排序稳定性；比较平均/最坏复杂度；给出应用场景选择合适的排序算法。
- 复习时应熟记常见排序算法的时间复杂度、空间复杂度、稳定性表，并重点掌握快速排序的 `Partition` 过程与分治复杂度推导。
- 408 选择题中，若题干出现“平均性能最好”或“平均情况下最快”，优先考虑快速排序；若题目强调“最坏情况也好”，则优先考虑堆排序或归并排序。

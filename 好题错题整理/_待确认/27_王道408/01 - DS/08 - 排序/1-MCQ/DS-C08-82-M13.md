13. 折半插入排序算法的时间复杂度为 ( ).

(A) $O(n)$

(B) $O(n \log_2 n)$

(C) $O(n^2)$

(D) $O(n^3)$

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C08-82-M13_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 (C) $O(n^2)$。折半插入排序只把“查找插入位置”的比较次数优化为 $O(n\log_2 n)$，但“腾出插入位置”的移动次数仍为 $O(n^2)$，因此总时间复杂度为 $O(n^2)$。

**解题切入点**：拿到题先不要把“折半”当成全部复杂度。插入排序的每一趟插入都包含两件事：找位置和腾位置。折半查找只能优化“找位置”的比较次数，无法优化“腾位置”的移动次数。类似地，很多算法优化了某一步，但总复杂度仍由未被优化的瓶颈步骤决定。

**推演**：

折半插入排序的插入过程可以写成如下关键思路（数组下标从 1 开始）：

```c
for (i = 2; i <= n; i++) {
    x = A[i];
    low = 1; high = i - 1;

    // 折半查找插入位置
    while (low <= high) {
        mid = (low + high) / 2;
        if (A[mid] <= x)
            low = mid + 1;
        else
            high = mid - 1;
    }

    // 移动元素，空出位置 low
    for (j = i - 1; j >= low; j--)
        A[j + 1] = A[j];

    A[low] = x;
}
```

第 $i$ 次插入时，前面有序表长度为 $i-1$，折半查找的比较次数为：

$$
C_i = O(\log_2 i)
$$

所以总的比较次数为：

$$
C(n) = \sum_{i=2}^{n} O(\log_2 i) = O(n\log_2 n)
$$

但移动次数没有减少。最坏情况下，原序列逆序，每次插入的元素都最小，插入位置是第一个位置，第 $i$ 次插入需要移动 $i-1$ 个元素：

$$
M_w(n) = \sum_{i=2}^{n}(i-1) = \frac{n(n-1)}{2} = O(n^2)
$$

平均情况下，插入位置大致均匀分布，第 $i$ 次插入平均移动 $\frac{i-1}{2}$ 个元素，所以：

$$
M_{\text{avg}}(n) = O(n^2)
$$

因此总时间复杂度为：

$$
T(n) = C(n) + M(n) = O(n\log_2 n) + O(n^2) = O(n^2)
$$

所以本题选 C。

注意：如果题目问的是“折半插入排序的关键字比较次数”，才是 $O(n\log_2 n)$；但问“时间复杂度”时，必须把移动开销算进去，答案是 $O(n^2)$。

**易错点**：

1. 看到“折半”就直接选 $O(n\log_2 n)$。这是最常见的错误，混淆了“比较次数”和“总时间复杂度”。
2. 忽略移动元素的开销。折半插入排序并没有减少移动次数，移动次数最坏仍为 $\frac{n(n-1)}{2}$。
3. 稳定性写法错误。若想在相等元素时保持稳定，折半查找遇到 `A[mid] <= x` 时应该继续向右半区找，即 `low = mid + 1`，最终插入到相等元素之后；若写成 `A[mid] < x`，可能插入到相等元素之前，破坏稳定性。
4. 混淆直接插入排序的最好情况。直接插入排序在序列基本有序时比较次数可降为 $O(n)$；但折半插入排序即使对有序序列，每趟仍需折半查找，比较总数为 $O(n\log_2 n)$，不能达到 $O(n)$。

**命题规律**：本题属于“插入排序”考点，核心是排序算法中“比较次数”和“移动次数”的分离分析。408 选择题常把 $O(n\log_2 n)$ 作为干扰项，因为这是折半查找本身或快速排序、归并排序的复杂度，不是折半插入排序的整体时间复杂度。常见变式有：

- 问“折半插入排序的比较次数” → 选或答 $O(n\log_2 n)$；
- 问“移动次数”或“时间复杂度” → 选或答 $O(n^2)$；
- 问“稳定性” → 稳定；
- 问“链表能否使用折半插入” → 不能高效使用，因为折半查找需要随机访问。

复习建议：把各排序算法的“比较次数、移动次数、时间复杂度、稳定性”分开整理，不要只背结论；遇到折半插入排序，先写出“比较 + 移动”两部分，再判断总复杂度。

6. 若对 27 个元素只进行三趟多路归并排序，则选取的归并路数最少为 (  ).

## DeepSeek V4 Flash Max 解析

**答案**：最少应选取 3 路归并，故选 **B**。

**解题切入点**：  
本题考的是“多路归并排序的趟数”计算。核心关系是：$k$ 路归并每一趟最多能把当前有序段的数量压缩为原来的 $1/k$；三趟后要完成排序，等价于三趟最多能覆盖 $k^3$ 个元素/初始段。于是由 $k^3 \ge 27$ 确定最小 $k$。可以类比“一棵 $k$ 叉树，3 层最多有 $k^3$ 个叶子；要容纳 27 个元素，$k\ge 3$”。

**推演**：  
设归并路数为 $k$。把 27 个元素看成 27 个初始有序段，记当前有序段数为 $r$。

一趟 $k$ 路归并时，把当前所有段每至多 $k$ 段合成一组，组内归并生成一个新有序段，因此段数更新为  
$$
r \leftarrow \left\lceil \frac{r}{k}\right\rceil .
$$

初始 $r=27$。三趟后要得到一个完整有序序列，等价于剩余段数为 1。于是有  
$$
\left\lceil \frac{\left\lceil \frac{\left\lceil 27/k\right\rceil}{k}\right\rceil}{k}\right\rceil = 1.
$$

重复使用上取整运算，可化简为  
$$
\left\lceil \frac{27}{k^3}\right\rceil = 1,
$$
即  
$$
\frac{27}{k^3}\le 1
\Rightarrow k^3\ge 27
\Rightarrow k\ge 3.
$$

由于 $k$ 为正整数，所以最小归并路数为 **3**。

验证：

- $k=2$：第一趟 $r=14$，第二趟 $r=7$，第三趟 $r=4$，不能完成排序；
- $k=3$：第一趟 $r=9$，第二趟 $r=3$，第三趟 $r=1$，刚好完成；
- $k=4$：第一趟 $r=7$，第二趟 $r=2$，第三趟 $r=1$，也能完成，但不是最少。

也可直接用趟数公式：
$$
T(k)=\left\lceil \log_k 27\right\rceil .
$$
$k=2$ 时 $T=5$；$k=3$ 时 $T=3$，故最少为 3。

关键伪代码思路如下：

```c
int passes(int n, int k) {
    int runs = n;
    int cnt = 0;
    while (runs > 1) {
        runs = (runs + k - 1) / k; // 相当于 ceil(runs/k)
        cnt++;
    }
    return cnt;
}
```

代入 $n=27$，找满足 `passes(27,k) <= 3` 的最小 $k$，得到 $k=3$。

**易错点**：  
1. 不要把“路数 $k$”和“一趟”混淆：一趟 $k$ 路归并不是只归并 $k$ 个元素，而是把若干组、每组至多 $k$ 个有序段分别归并成一个新段。  
2. 计算段数时要用上取整：$r\leftarrow \lceil r/k\rceil$，不能直接写成 $r/k$。  
3. 判断“最少”时，不能只看 $k=3$ 可行，还要说明 $k=2$ 不可行，才能确认是最小值。  
4. 不要死记 $\lceil \log_2 n\rceil$，路数为 $k$ 时底数应为 $k$。

**命题规律**：  
本题属于“多路归并排序/外部排序”中的基础计算题，核心公式为  
$$
\text{归并趟数}=\left\lceil \log_k N\right\rceil,
$$  
其中 $N$ 为初始有序段数，有时题目直接给元素数。常见变式有：已知 $N$ 和 $k$ 求趟数；已知趟数限制求最小 $k$；结合败者树求比较次数；结合磁盘 I/O 次数求总时间。复习时应抓住“每趟段数除以 $k$ 并上取整”的本质，熟练掌握 $k^t\ge N$ 的判定方法。

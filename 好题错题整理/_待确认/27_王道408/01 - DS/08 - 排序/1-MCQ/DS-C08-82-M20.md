# 选择题 第 20 题

![[_Attachments/题目识别/27_王道408-题目/DS-C08-82-M20_题目.png|题目]]

20.【2018统考真题】对初始数据序列 (8,3,9,11,2,1,4,7,5,10,6) 进行希尔排序。若第一趟排序结果为 (1,3,7,5,2,6,4,9,11,10,8)，第二趟排序结果为 (1,2,6,4,3,7,5,8,11,10,9)，则两趟排序采用的增量(间隔)依次是( )。

A. 3,1
B. 3,2
C. 5,2
D. 5,3

## DeepSeek V4 Flash Max 解析

**答案**：两趟排序采用的增量依次是 5 和 3，即选项 D。

**解题切入点**：希尔排序的核心是分组插入排序，给定排序前后的序列，通过验证每组内元素是否有序来反推增量。类比“拼图游戏”：每一趟排序相当于将整个序列按增量拆分成若干条“子链”，每条子链内部完成排序；最终结果就是这些子链排序后的拼接。因此，只需检查每个候选增量下，排序结果中对应位置的元素是否构成递增序列即可。

**推演**：
设初始序列为 $S_0 = (8,3,9,11,2,1,4,7,5,10,6)$，第一趟排序结果 $S_1 = (1,3,7,5,2,6,4,9,11,10,8)$，第二趟排序结果 $S_2 = (1,2,6,4,3,7,5,8,11,10,9)$。序列长度为 $n=11$。

对每个选项中的增量对 $(d_1, d_2)$（$d_1 > d_2$），验证 $S_1$ 是否是在 $S_0$ 上按增量 $d_1$ 进行希尔排序的结果，以及 $S_2$ 是否是在 $S_1$ 上按增量 $d_2$ 进行希尔排序的结果。希尔排序中，对于增量 $d$，将所有相距 $d$ 的元素划分为一组，每组内部应有序（递增）。

- **选项 A**：$(3,1)$  
  取 $d_1=3$，将 $S_0$ 按间隔 3 分组：
  - 组1：索引 1,4,7,10 → 8,11,4,10
  - 组2：索引 2,5,8,11 → 3,2,7,6
  - 组3：索引 3,6,9 → 9,1,5  
  排序后每组应为递增，但 $S_1$ 中对应位置：
  - 组1：1,5,4,10 → 不是递增（1,4,5,10 才是）
  故 $d_1=3$ 不成立，排除 A。

- **选项 B**：$(3,2)$  
  同样 $d_1=3$ 不成立，直接排除。

- **选项 C**：$(5,2)$  
  取 $d_1=5$，将 $S_0$ 按间隔 5 分组：
  - 组1：索引 1,6,11 → 8,1,6
  - 组2：索引 2,7 → 3,4
  - 组3：索引 3,8 → 9,7
  - 组4：索引 4,9 → 11,5
  - 组5：索引 5,10 → 2,10  
  排序后每组应为递增，$S_1$ 中对应位置：
  - 组1：1,6,8 → 递增 ✓
  - 组2：3,4 → 递增 ✓
  - 组3：7,9 → 递增 ✓
  - 组4：5,11 → 递增 ✓
  - 组5：2,10 → 递增 ✓  
  故 $d_1=5$ 成立。  
  再取 $d_2=2$，将 $S_1$ 按间隔 2 分组：
  - 组1（奇数索引）：1,3,5,7,9,11 → 1,7,2,4,11,8
  - 组2（偶数索引）：2,4,6,8,10 → 3,5,6,9,10  
  排序后每组应为递增，$S_2$ 中对应位置：
  - 组1：1,6,3,5,11,9 → 不是递增（1,3,5,6,9,11 才是）
  故 $d_2=2$ 不成立，排除 C。

- **选项 D**：$(5,3)$  
  已验证 $d_1=5$ 成立。  
  取 $d_2=3$，将 $S_1$ 按间隔 3 分组：
  - 组1：索引 1,4,7,10 → 1,5,4,10
  - 组2：索引 2,5,8,11 → 3,2,9,8
  - 组3：索引 3,6,9 → 7,6,11  
  排序后每组应为递增，$S_2$ 中对应位置：
  - 组1：1,4,5,10 → 递增 ✓
  - 组2：2,3,8,9 → 递增 ✓
  - 组3：6,7,11 → 递增 ✓  
  故 $d_2=3$ 成立。因此答案为 D。

**易错点**：
1. **索引混淆**：分组时容易将索引与元素值混淆，务必明确分组依据是位置间隔，而非元素大小。
2. **忽略排序方向**：希尔排序每组内部是递增排序，不能误认为递减或无序。
3. **遗漏分组完整性**：当序列长度不是增量整数倍时，部分组元素个数可能不同，需全部检查。
4. **直接套用常见增量序列**：题目中增量并非标准序列（如Shell增量、Hibbard增量），需从结果反推，避免主观臆断。

**命题规律**：
- **考点定位**：希尔排序的增量选择与分组排序原理，属于排序算法中的基础应用题型。
- **常见变式**：给定初始序列和若干趟排序结果，要求反推增量序列；或给定增量序列，要求写出某趟排序结果。
- **复习建议**：熟练掌握希尔排序的“分组-排序”过程，练习通过观察子序列有序性反推增量。可结合具体实例手算，加深对“相隔增量”元素组内有序的理解。注意区分希尔排序与直接插入排序的稳定性差异。

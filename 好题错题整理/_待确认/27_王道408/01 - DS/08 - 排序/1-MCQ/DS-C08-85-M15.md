15.【2013 统考真题】已知两个长度分别为 $m$ 和 $n$ 的升序链表，若将它们合并为长度为 $m+n$ 的一个降序链表，则最坏情况下的时间复杂度为( )。
A. $O(n)$
B. $O(mn)$
C. $O(\min(m,n))$
D. $O(\max(m,n))$

## DeepSeek V4 Flash Max 解析

**答案**：选 D。最坏情况时间复杂度为 $O(\max(m,n))$，等价于 $O(m+n)$。

**解题切入点**：拿到题先定位为“两个有序链表的归并”。有序表归并不是对每个元素在结果链表中重新查找插入位置，而是用双指针从两链表头各扫一遍。降序只是改变了插入方式：用头插法构建即可，复杂度仍是线性的。可以类比归并排序中的 merge：两支升序队伍每次出队最小者，并把出队者放到新队伍最前面，最终自然得到降序。

**推演**：

设两个链表为 $L_1,L_2$，长度分别为 $m,n$。令指针 $p,q$ 分别指向两个链表的当前首元结点。

1. 因为 $L_1,L_2$ 都是升序链表，所以 $p$ 与 $q$ 中较小者就是当前所有未合并结点中的最小者。  
2. 每次取出较小结点，将其头插到结果链表 $C$ 的头部。由于选取顺序是从小到大，头插后 $C$ 从头到尾就是从大到小，即为降序。  
3. 当某一条链表为空时，剩余链表中的结点都不小于最后选出的结点，继续依次头插到 $C$ 头部即可，无需再比较。

关键代码如下：

```c
while (A && B) {
    if (A->data <= B->data) { t = A; A = A->next; }
    else                    { t = B; B = B->next; }
    t->next = C;
    C = t;
}
p = A ? A : B;
while (p) {
    t = p;
    p = p->next;
    t->next = C;
    C = t;
}
```

复杂度分析：

- 每个结点恰好被取出并插入一次，每次插入为 $O(1)$，所以插入总代价为 $O(m+n)$；
- 最坏情况下两链表元素交错，比较次数最多为 $m+n-1$，也为 $O(m+n)$。

因此

$$
T(m,n)=O(m+n).
$$

又因为 $m,n$ 为正整数时，

$$
\max(m,n)\le m+n\le 2\max(m,n),
$$

所以 $O(m+n)$ 与 $O(\max(m,n))$ 同阶，故选 **D**。

**易错点**：

1. 误以为“降序”后每次都要在新链表中从头找插入位置，从而错选 $O(mn)$。实际上有序表归并只需双指针，不需要在新链表中查找。  
2. 误以为只需处理较短链表，错选 $O(\min(m,n))$。即使较短链表先被取完，较长链表的剩余结点也都要接入结果链表，且最坏比较次数可达到 $m+n-1$。  
3. 只看其中一个长度而选 $O(n)$，忽略了 $m,n$ 的对称性；用 $\max(m,n)$ 或 $m+n$ 表达才完整。  
4. 不必担心“降序”增加复杂度，头插法每次只改结果链表头指针，是 $O(1)$ 的；也可以先合并成升序链表再整体逆置，总复杂度仍是 $O(m+n)$。

**命题规律**：

考点是“有序表归并 + 链表头插/尾插 + 时间复杂度分析”，是 408 常考基础题。常见变式包括：合并两个有序数组、链表原地逆置、求两个有序链表的交集或并集，以及在大题中作为排序算法的子过程。复习时应熟练掌握双指针归并模板，理解头插法和尾插法对结果顺序的影响，并能快速判断 $O(m+n)$ 与 $O(\max(m,n))$ 的等价性。

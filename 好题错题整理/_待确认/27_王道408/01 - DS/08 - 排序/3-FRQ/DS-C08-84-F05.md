## DeepSeek V4 Flash Max 解析

**答案**：在单链表上实现简单选择排序的核心是：每一趟从“未排序子链表”中选出关键字最小的结点，把它摘下并接到“已排序子链表”的末尾；重复 $n-1$ 趟后，整个链表按关键字递增有序。时间复杂度 $O(n^2)$，空间复杂度 $O(1)$。

**解题切入点**：先抓住两个考点：一是简单选择排序“每趟选最小”的思想，二是单链表不能随机访问、删除结点必须知道前驱结点的特点。可以这样打比方：就像每次从一堆乱牌中抽出最小的一张，按顺序放到另一堆牌尾；在单链表中想“抽出”某个结点，必须知道它前面是哪张牌，否则链就断了。

**推演**：

算法思路如下：

1. 设一个临时头结点 `head`，用它统一处理“最小结点就是第一个结点”的情况。
2. 用指针 `tail` 表示已排序部分的尾结点，初始时 `tail = head`，已排序部分为空。
3. 在 `tail->next` 到链表末尾之间扫描，寻找关键字最小的结点，同时记录其前驱 `preMin`。
4. 若最小结点不是未排序部分的第一个结点，则将最小结点摘下并插入到 `tail` 之后；若它就是第一个，则不用移动。
5. 令 `tail` 指向这个刚归位的最小结点，继续下一趟，直到未排序部分只剩下一个结点。

关键代码实现如下：

```c
typedef struct LNode {
    int key;
    struct LNode *next;
} LNode, *LinkList;

// L 指向第一个有效结点；返回排序后的头指针
LinkList SelectSort(LinkList L) {
    if (L == NULL || L->next == NULL)
        return L;

    LNode dummy;             // 临时头结点，不存放有效数据
    dummy.next = L;
    LNode *tail = &dummy;    // 已排序部分的尾结点

    while (tail->next != NULL && tail->next->next != NULL) {
        // 在未排序部分找最小结点及其前驱
        LNode *preMin = tail;        // 最小结点的前驱
        LNode *min = tail->next;     // 最小结点
        LNode *pre = min;            // 当前扫描结点的前驱
        LNode *p = min->next;        // 当前扫描结点

        while (p != NULL) {
            if (p->key < min->key) {
                preMin = pre;
                min = p;
            }
            pre = p;
            p = p->next;
        }

        // 若最小结点不是未排序部分第一个结点，摘下来插到 tail 之后
        if (min != tail->next) {
            preMin->next = min->next;    // 摘下 min
            min->next = tail->next;      // 将 min 插入 tail 之后
            tail->next = min;
        }

        tail = tail->next;               // 本轮最小结点已归位
    }

    return dummy.next;
}
```

正确性说明：每趟开始时，`head` 到 `tail` 这一段已经按关键字升序排列，且包含当前全局最小的前若干个结点；本趟选出的 `min` 是未排序部分的最小结点，将其接到 `tail` 之后不会破坏有序性。因此经过 $n-1$ 趟后，所有结点都有序。

复杂度分析：

- 比较次数：
  $$
  (n-1)+(n-2)+\cdots+1=\frac{n(n-1)}2=O(n^2)
  $$
- 移动/摘链次数：每趟最多执行一次摘链插入，所以为 $O(n)$。
- 额外空间：只用了常数个辅助指针，为 $O(1)$。

**易错点**：

- 忘记记录最小结点的前驱 `preMin`。单链表删除结点必须知道前驱，否则无法把 `min` 摘下。
- 摘链和插入的顺序不能写反。应先执行 `preMin->next = min->next`，再执行 `min->next = tail->next`，最后执行 `tail->next = min`；若先改 `tail->next`，会丢失原来的链。
- 扫描结束后忘记令 `tail = tail->next`，会导致死循环。
- 对空链表或只有一个结点的链表没有特殊处理。
- 如果采用“交换 data”的简化写法，虽然也能排序，但若结点中记录较大，交换代价较高；题目若强调链表操作，应优先采用改链方式。

**命题规律**：该题综合考查“单链表操作”和“简单选择排序”，是 408 常考的链表排序题型。常见变式包括：带头结点与不带头结点的单链表排序、按递减序排序、用直接插入排序或冒泡排序在链表上排序、删除链表中的最小结点等。复习时要把单链表中“插入、删除、找前驱”练成条件反射；排序算法的复杂度分析要会用求和式说明，不能只背结论。

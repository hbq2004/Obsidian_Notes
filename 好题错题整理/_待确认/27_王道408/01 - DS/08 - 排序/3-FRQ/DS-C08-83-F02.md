# 综合题 第 2 题

![[_Attachments/题目识别/27_王道408-题目/DS-C08-83-F02_题目.png|题目]]

2. 试编写一个算法，使之能够在数组 $L[1\cdots n]$ 中找出第 $k$ 小的元素（从小到大排序后处于第 $k$ 个位置的元素）.

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C08-83-F02_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：利用快速排序的一趟划分（Partition）思想，每次把枢轴元素放到最终有序位置，再比较枢轴在当前区间中的名次与 $k$，只向第 $k$ 小所在的一侧递归；平均时间复杂度 $O(n)$，最坏 $O(n^2)$。

**解题切入点**：看到“无序数组中找第 $k$ 小”，不要直接完整排序；完整排序是 $O(n\log n)$，而只找一个元素时，可以利用快速排序划分“一次确定一个元素最终位置”的性质来剪枝。这类似于刷题中的 Top-K 问题：数组可修改、可交换时常用 QuickSelect；数据流或内存受限时才用堆。

**推演**：下面的类 C 伪代码按题目要求使用 $1\sim n$ 的下标。快速排序的一趟划分可写成：

```c
int Partition(int L[], int low, int high) {
    int pivot = L[low];                // 暂存基准元素
    while (low < high) {
        while (low < high && L[high] >= pivot) high--;
        L[low] = L[high];              // 小于等于 pivot 的移到左边
        while (low < high && L[low] <= pivot) low++;
        L[high] = L[low];              // 大于等于 pivot 的移到右边
    }
    L[low] = pivot;                    // 基准归位
    return low;                        // 返回基准最终位置
}
```

选择算法为：

```c
int SelectKth(int L[], int low, int high, int k) {
    if (low == high) return L[low];    // 区间内只剩一个元素

    int pos = Partition(L, low, high);
    int leftSize = pos - low + 1;      // 枢轴在当前区间内的名次

    if (k == leftSize) return L[pos];
    else if (k < leftSize)
        return SelectKth(L, low, pos - 1, k);
    else
        return SelectKth(L, pos + 1, high, k - leftSize);
}
```

调用方式为：

```c
int ans = SelectKth(L, 1, n, k);       // 约定 1 <= k <= n
```

正确性：一趟划分后，枢轴元素满足：

$$
L[low..pos-1] \le L[pos] \le L[pos+1..high]
$$

所以枢轴在当前区间中的名次是：

$$
leftSize = pos - low + 1
$$

若 $k = leftSize$，则 $L[pos]$ 就是要找的第 $k$ 小元素；若 $k < leftSize$，则第 $k$ 小元素只可能在左半区间；若 $k > leftSize$，则左半区间和枢轴共 $leftSize$ 个元素都不大于右半区间的元素，所以到右半区间找第 $k - leftSize$ 小即可。

复杂度：每次 Partition 需要线性扫描当前区间。快速排序要递归处理两侧，所以是 $O(n\log n)$；本算法只递归处理一侧，若划分较均衡，则

$$
T(n)=T(n/2)+O(n)=O(n)
$$

即平均时间复杂度为 $O(n)$。最坏情况下每次枢轴都是当前区间的最小值或最大值，则

$$
T(n)=T(n-1)+O(n)=O(n^2)
$$

递归栈空间平均为 $O(\log n)$，最坏为 $O(n)$；若改成循环写法，辅助空间可降到 $O(1)$。

**易错点**：

- 直接对数组完整排序后再取第 $k$ 个元素：答案正确，但不是本题考查的高效算法，复杂度为 $O(n\log n)$。
- 递归到右半区间时忘记修改 $k$，仍传原来的 $k$；必须传 $k - leftSize$。
- 把 `leftSize` 直接写成 `pos`；当 `low` 不为 1 时，`pos` 不是当前区间内的名次。
- 手写 Partition 时忘记先用 `pivot` 暂存基准，导致基准值被覆盖后无法归位。
- 忽略边界条件：$k$ 必须满足 $1\le k\le n$，递归出口为 `low == high`。
- 固定取 `L[low]` 作基准时，输入有序或大量重复元素可能使算法退化为 $O(n^2)$；可随机选基准或使用三路划分来改善。

**命题规律**：本题是快速排序划分思想的重要延伸，属于“选择问题 / 第 $k$ 小 / 中位数 / Top-K”这一高频考点。常见变式有：求中位数（令 $k=(n+1)/2$）、求第 $k$ 大（转化为求第 $n-k+1$ 小）、求前 $k$ 小或前 $k$ 大。复习时要把 `Partition`、`QuickSort`、`SelectKth` 三者对比掌握：快排递归两侧，QuickSelect 只递归一侧。堆方法（维护大小为 $k$ 的最大堆求第 $k$ 小）可作为补充，适合数据流或不能修改原数组的场景。考研 408 中，写清划分性质、递归边界和复杂度即可。

## DeepSeek V4 Flash Max 解析

**答案**：  
对序列 $\{4,5,1,2,6,3\}$ 执行直接插入排序，共需 $5$ 趟，最终得到有序序列 $\{1,2,3,4,5,6\}$。

**解题切入点**：  
拿到“给出排序过程”的题，先判断排序算法。直接插入排序的核心是：**把待排序区第一个元素，插入到前面已经有序的子序列中的合适位置**。可以把前面部分看作左手已经理好的牌，新摸到的牌从右往左依次比较，找到位置后插入。模拟时，我们用方括号标出当前有序区，每次只处理未排序区的第一个元素。

**推演**：  
设序列为 $a_1,a_2,\dots,a_6$，初始时 $a_1=4$ 单独构成有序区：

$$
[4],\;5,\;1,\;2,\;6,\;3
$$

直接插入排序的代码思路如下（$a[1..n]$ 保存序列）：

```c
for (i = 2; i <= n; i++) {
    temp = a[i];          // 暂存待插入元素
    j = i - 1;
    while (j >= 1 && a[j] > temp) {
        a[j + 1] = a[j];  // 比 temp 大的元素后移
        j--;
    }
    a[j + 1] = temp;      // 插入到正确位置
}
```

逐趟模拟过程如下：

| 趟序 | 待插入关键字 | 比较/移动过程 | 本趟结果 |
|---|---|---|---|
| 初始 | — | $4$ 作为有序区 | $[4],5,1,2,6,3$ |
| 第1趟 | $5$ | $5>4$，不移动 | $[4,5],1,2,6,3$ |
| 第2趟 | $1$ | $1<5$，$5$ 后移；$1<4$，$4$ 后移；$1$ 插入最前面 | $[1,4,5],2,6,3$ |
| 第3趟 | $2$ | $2<5$，$5$ 后移；$2<4$，$4$ 后移；$2>1$，插入 $1$ 后面 | $[1,2,4,5],6,3$ |
| 第4趟 | $6$ | $6>5$，不移动 | $[1,2,4,5,6],3$ |
| 第5趟 | $3$ | $3<6$，$6$ 后移；$3<5$，$5$ 后移；$3<4$，$4$ 后移；$3>2$，插入 $2$ 后面 | $[1,2,3,4,5,6]$ |

因此每趟之后，方括号内的有序区长度增加 1；第 5 趟结束后，整个序列有序：

$$
\{1,2,3,4,5,6\}
$$

直接插入排序的时间复杂度：最坏和平均为 $O(n^2)$，最好为 $O(n)$；空间复杂度为 $O(1)$；是**稳定排序**。

**易错点**：  
1. **与冒泡排序混淆**：直接插入排序是“后移空位再插入”，不是相邻元素交换。  
2. **比较方向搞反**：必须从已有序区**从右往左**比较，不能从左往右，否则会破坏有序性。  
3. **忘记暂存待插入元素**：后移时会覆盖原值，因此必须先 `temp = a[i]` 或使用监视哨。  
4. **相等元素处理错误**：当 $a[j] > temp$ 时才后移，等于时停止，保证相等元素相对顺序不变，维持稳定性。  
5. **趟数写错**：第一个元素默认有序，所以 $n$ 个元素只需要 $n-1$ 趟；本题为 $6$ 个元素，需要 $5$ 趟。  
6. **本趟结果写错**：每一趟完成后，前 $i$ 个元素已经有序，未排序区从第 $i+1$ 个元素开始。

**命题规律**：  
直接插入排序是 408 常考的基础排序算法，可单独考察“手工模拟排序过程”，也常与以下内容结合命题：  
- 计算某一趟后的序列状态；  
- 比较次数与移动次数；  
- 排序稳定性判断；  
- 与折半插入排序、希尔排序对比；  
- 给定初始序列，判断某个中间序列是否为直接插入排序某趟的合法结果。  

复习建议：多动手手动模拟各排序算法，注意区分“插入类”“交换类”“选择类”“归并类”排序的每一趟特征；同时熟记时间复杂度、空间复杂度和稳定性，这是 408 选择题和综合题的高频考点。

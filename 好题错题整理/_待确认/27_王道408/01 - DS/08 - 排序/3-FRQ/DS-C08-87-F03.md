# 综合题 第 3 题

![[_Attachments/题目识别/27_王道408-题目/DS-C08-87-F03_题目.png|题目]]

3. 设初始归并段为 $(10,15,31),(9,20),(22,34,37),(6,15,42),(12,37),(84,95)$。试利用败者树进行 $m$ 路归并，手工执行选择最小的 5 个关键字的过程。

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C08-87-F03_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：
利用 6 路败者树归并，依次选出的最小 5 个关键字为 $6,9,10,12,15$。

**解题切入点**：
先把每个归并段的当前关键字看成“选手”。败者树的特点是：内部结点只记录两两比较的“败者”，胜者继续向上，最终冠军放在根上。手工模拟时，每输出一个最小值，只需让该归并段读入的下一个关键字沿“该叶结点到根”的路径，与路径上各个祖先中记录的败者重新比较即可，不需要把整棵树重建。

**推演**：

设 6 个归并段为  
$$
R_1=(10,15,31),\ R_2=(9,20),\ R_3=(22,34,37),\ R_4=(6,15,42),\ R_5=(12,37),\ R_6=(84,95).
$$

初始各叶结点的当前关键字为  
$$
10,\ 9,\ 22,\ 6,\ 12,\ 84.
$$

采用如下两两比较的败者树结构：  
- $I_1$ 比较 $R_1,R_2$；  
- $I_2$ 比较 $R_3,R_4$；  
- $I_3$ 比较 $R_5,R_6$；  
- $I_4$ 比较 $I_1$ 的胜者与 $I_2$ 的胜者；  
- $I_5$ 比较 $I_4$ 的胜者与 $I_3$ 的胜者；  
- $I_5$ 的胜者作为全局冠军。

约定：相等时归并段号小者胜。

初始败者树如下：

| 内部结点 | 参与比较的关键字 | 败者记录 | 胜者上送 |
|---|---|---|---|
| $I_1$ | $R_1(10),R_2(9)$ | $R_1(10)$ | $R_2(9)$ |
| $I_2$ | $R_3(22),R_4(6)$ | $R_3(22)$ | $R_4(6)$ |
| $I_3$ | $R_5(12),R_6(84)$ | $R_6(84)$ | $R_5(12)$ |
| $I_4$ | $R_2(9),R_4(6)$ | $R_2(9)$ | $R_4(6)$ |
| $I_5$ | $R_4(6),R_5(12)$ | $R_5(12)$ | 冠军 $R_4(6)$ |

所以第 1 个最小关键字是 $6$，来自 $R_4$。

接着手工执行 5 次选择：

| 轮次 | 输出 | 替换 | 沿路径调整要点 | 新冠军 |
|---|---|---|---|---|
| 1 | $R_4(6)$ | $R_4$ 读入 $15$ | $R_4(15)$ 胜 $R_3(22)$，但负于 $R_2(9)$；$I_4$ 败者改为 $R_4(15)$ | $R_2(9)$ |
| 2 | $R_2(9)$ | $R_2$ 读入 $20$ | $R_2(20)$ 负于 $R_1(10)$；$I_1$ 败者改为 $R_2(20)$ | $R_1(10)$ |
| 3 | $R_1(10)$ | $R_1$ 读入 $15$ | $R_1(15)$ 战胜 $R_2(20)$；与 $R_4(15)$ 相等，按约定 $R_1$ 胜；根处负于 $R_5(12)$ | $R_5(12)$ |
| 4 | $R_5(12)$ | $R_5$ 读入 $37$ | $R_5(37)$ 战胜 $R_6(84)$，但根处负于 $R_1(15)$；$I_5$ 败者改为 $R_5(37)$ | $R_1(15)$ |
| 5 | $R_1(15)$ | $R_1$ 读入 $31$ | $R_1(31)$ 负于 $R_2(20)$；$R_2(20)$ 又负于 $R_4(15)$；$I_5$ 不变 | $R_4(15)$ |

因此前 5 个输出依次为  
$$
6,\ 9,\ 10,\ 12,\ 15.
$$

对应代码思路可概括为：

```text
b[i]：第 i 个归并段的当前关键字；
ls[t]：内部结点 t 中记录的败者叶编号；
ls[0]：冠军叶编号。

void adjust(int s) {
    int t = father[s];              // s 是被替换的叶结点
    while (t != 0) {
        if (b[s] > b[ls[t]])        // 当前胜者比该祖先的败者还大
            swap(s, ls[t]);         // 当前胜者成为新败者，旧败者继续上送
        t = father[t];
    }
    ls[0] = s;                      // 最终胜者作为冠军
}
```

**易错点**：

1. **混淆败者与胜者**：内部结点存的是败者，不是胜者；冠军单独存在根上。
2. **替换后重建整棵树**：败者树的关键优化是只沿被替换叶结点到根的祖先路径调整，不需要全量比较。
3. **忽略平局规则**：本题出现两个 $15$，若比较相等时不约定规则，可能影响输出来自哪个归并段；但关键字序列仍为 $6,9,10,12,15$。
4. **归并段取空时忘记用 $+\infty$ 占位**：如果某个归并段已空，应把该叶结点关键字设为 $+\infty$，防止再次被选中；前 5 次输出中尚未出现取空情况。

**命题规律**：

本题属于外部排序中的多路归并与败者树综合题。408 中常见考法有：构造初始败者树、手工模拟输出前 $k$ 小、比较败者树与胜者树的区别、计算 $k$ 路归并趟数或磁盘 I/O 次数。复习时要把“败者树”“置换-选择排序”“最佳归并树”联系起来，重点理解：败者树把每趟从 $m$ 个关键字中选最小的时间降到 $O(\log_2 m)$，且替换后只需沿祖先路径调整。

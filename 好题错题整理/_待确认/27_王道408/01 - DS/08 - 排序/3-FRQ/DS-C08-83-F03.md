## DeepSeek V4 Flash Max 解析

**答案**：用三个指针 $i,j,k$ 维护“红、白、蓝”三个连续区间，一趟原地扫描完成排序；时间复杂度 $O(n)$，空间复杂度 $O(1)$。

**解题切入点**：看到“仅由三种颜色组成”“顺序表”“$O(n)$ 时间复杂度”，应立即想到 **荷兰国旗问题**，本质是快速排序中“三向切分”（three-way partition）的变形。做题时可用“三指针圈地”的思路：让左指针管红色区，中间指针扫白色区，右指针管蓝色区，未知区域不断缩小，最终所有颜色各归其位。

**推演**：

设顺序表为 $a[0..n-1]$，定义三个下标：

- $i$：红色区的右边界，$a[0..i-1]$ 全为红色；
- $j$：当前扫描位置，$a[i..j-1]$ 全为白色；
- $k$：蓝色区的左边界，$a[k+1..n-1]$ 全为蓝色；
- $a[j..k]$ 是待处理区间。

初始时令

$$
i=0,\quad j=0,\quad k=n-1
$$

此时红色区、白色区、蓝色区均为空，待处理区间是整个数组，循环不变式成立。

每次检查 $a[j]$：

1. 若 $a[j]=\mathrm{RED}$，交换 $a[i]$ 与 $a[j]$，然后 $i++,\ j++$。  
   因为 $a[i..j-1]$ 原本全是白色，交换后红色区向右扩展一格，白色区也保持连续。

2. 若 $a[j]=\mathrm{WHITE}$，直接 $j++$。  
   白色区向右扩展一格。

3. 若 $a[j]=\mathrm{BLUE}$，交换 $a[j]$ 与 $a[k]$，然后 $k--$。  
   注意此时不能 $j++$，因为换到 $a[j]$ 的是原来 $a[k]$ 处的未知元素，必须留在下一轮继续判断。

当 $j>k$ 时，待处理区间为空，循环结束，此时数组已经按红、白、蓝排好。

算法实现如下：

```c
typedef enum { RED, WHITE, BLUE } color;

void swap(color *a, color *b) {
    color tmp = *a;
    *a = *b;
    *b = tmp;
}

void Flag_Arrange(color a[], int n) {
    int i = 0, j = 0, k = n - 1;

    while (j <= k) {
        switch (a[j]) {
            case RED:
                swap(&a[i], &a[j]);
                i++;
                j++;
                break;
            case WHITE:
                j++;
                break;
            case BLUE:
                swap(&a[j], &a[k]);
                k--;
                break;
        }
    }
}
```

正确性由循环不变式保证：每一步都维持“红区在前、白区居中、蓝区在后、中间未知”的格局；算法结束时未知区间长度为 0，因此所有元素恰好按红、白、蓝排列。

复杂度分析：每执行一次循环，待处理区间 $[j,k]$ 的长度要么因 $j++$ 减少 1，要么因 $k--$ 减少 1，因此最多执行 $O(n)$ 次交换和比较；只使用常数个辅助变量，空间复杂度 $O(1)$。

**易错点**：

1. **处理蓝色后误写 $j++$**。  
   蓝色交换后，$a[j]$ 是从后面换来的未知元素，贸然 $j++$ 会漏判该元素，导致排序错误。正确做法是只 $k--$，下一轮继续处理 $a[j]$。

2. **循环条件写成 $j<k$**。  
   当 $j=k$ 时，还有一个元素未处理，必须使用 $j\le k$，否则最后一个元素可能被遗漏。

3. **处理红色时只 $i++$ 而不 $j++$**。  
   交换后红色区扩展，但扫描位置也必须后移，否则可能造成重复处理或死循环。

4. **混淆三指针含义**。  
   $i$ 指向红色区的下一个位置，$j$ 是扫描指针，$k$ 指向蓝色区的前一个位置。三者必须同步维护，否则颜色区间会被破坏。

5. **忽略稳定性**。  
   该算法通过交换完成，是不稳定的。如果题目额外要求“相同颜色的相对顺序不变”，荷兰国旗问题就无法用这种简单交换做到，需要另想办法。

**命题规律**：这是快速排序划分思想的经典应用，在 408 中常以代码填空、手写算法或时间复杂度分析的形式出现。常见变式包括：“把奇数放在偶数前”“把负数放在正数前”“把 0、1、2 排序”等，本质上都是三向切分。复习时应重点掌握“循环不变式 + 双边界指针”的推导方法，并能快速写出类似代码；同时注意区分“一趟划分”与“完整快速排序”的联系。建议把荷兰国旗问题作为“原地三向切分”的模板题反复默写。

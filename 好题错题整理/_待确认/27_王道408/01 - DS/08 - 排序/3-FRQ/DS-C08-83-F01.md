# 综合题 第 1 题

1. 已知线性表按顺序存储，且每个元素都是不相同的整数型元素，设计把所有奇数移动到所有偶数前边的算法 (要求时间最短，辅助空间最小)。

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C08-83-F01_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：采用快速排序划分中的“两端夹逼、遇错交换”策略：用下标 $i$ 从左向右找偶数，下标 $j$ 从右向左找奇数，找到后交换，直到 $i \ge j$；时间复杂度 $O(n)$，辅助空间 $O(1)$。

**解题切入点**：拿到题目先抓“顺序存储”“奇数移到偶数前”“时间最短、辅助空间最小”这三个条件，本质是把数组按奇偶性做一次二划分，而不是排序。可以类比快速排序第一趟的 `Partition` 操作：把满足某类条件的元素放到前面，另一类放到后面。408 和算法题中，只要看到“原地、线性时间、按某性质分两堆”，优先想到双指针从两端向中间扫描。

**推演**：

设顺序存储的线性表用数组 $A[0..n-1]$ 表示。用两个下标：

- $i$ 从左侧向右移动，专门跳过奇数；
- $j$ 从右侧向左移动，专门跳过偶数；
- 若 $A[i]$ 是偶数且 $A[j]$ 是奇数，说明它们放反了，交换。

关键代码思路如下：

```c
void moveOddBeforeEven(int A[], int n) {
    int i = 0, j = n - 1;
    while (i < j) {
        while (i < j && A[i] % 2 != 0) i++; // 左指针跳过奇数
        while (i < j && A[j] % 2 == 0) j--; // 右指针跳过偶数
        if (i < j) {
            int tmp = A[i];
            A[i] = A[j];
            A[j] = tmp;
            i++;
            j--;
        }
    }
}
```

正确性证明：

循环过程中始终保持如下不变量：

$$
A[0..i-1]\text{ 中全是奇数},\qquad A[j+1..n-1]\text{ 中全是偶数}
$$

- 初始时 $i=0$，$j=n-1$，左右两个区间都为空，不变量成立。
- 左指针 $i$ 遇到奇数就跳过，所以它停下的位置一定是偶数；右指针 $j$ 遇到偶数就跳过，所以它停下的位置一定是奇数。
- 若此时仍有 $i<j$，则交换 $A[i]$ 和 $A[j]$，交换后 $A[i]$ 是奇数，$A[j]$ 是偶数，左右区间各自扩展，不变量继续保持。
- 当 $i \ge j$ 时，说明左右两个“正确区间”已经覆盖所有元素，所有奇数都在偶数前面。

复杂度分析：

- 每个元素最多被指针扫描常数次，$i$ 只向右走，$j$ 只向左走，因此时间复杂度为

$$
T(n)=O(n)
$$

- 只使用了 $i,j,tmp$ 等常数个临时变量，因此辅助空间为

$$
S(n)=O(1)
$$

满足“时间最短、辅助空间最小”的要求。

**易错点**：

1. 内层 `while` 忘记加 `i < j` 边界条件。例如全为奇数时，$i$ 会一直向右越界，应该写成：

   ```c
   while (i < j && A[i] % 2 != 0) i++;
   ```

2. 开一个新数组，把奇数、偶数分别复制进去。这样时间也可以是 $O(n)$，但辅助空间变成 $O(n)$，不满足“辅助空间最小”。

3. 误以为必须保持奇数之间、偶数之间原来的相对顺序。本题没有要求稳定，直接交换即可；如果额外要求稳定，不能简单使用两端交换法。

4. 用 `%2==1` 判断奇数。C 语言中负奇数 `%2` 可能得到 `-1`，所以更稳妥的判断是 `A[i] % 2 != 0`。

5. 把本题当成“排序”问题处理，去比较元素大小；实际上只需要判断奇偶性，不需要比较大小。

**命题规律**：本题是“数组/线性表按某种性质原地二划分”的典型题，考点本质是快速排序中的 `Partition` 思想，在 408 中常以算法设计题或选择题形式出现。常见变式包括：把负数移动到正数前面、把能被某个数整除的元素放在前面、把 0 移动到数组末尾等；若扩展到三种元素，则可用“荷兰国旗”三指针方法。复习时要熟练掌握双指针夹逼的写法，特别注意边界条件 `i < j`，考场上写出核心思想、代码和复杂度分析即可。

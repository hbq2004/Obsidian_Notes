# 选择题 第 34 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-23-M34_题目.png|题目]]

34.【2021统考真题】已知头指针 $h$ 指向一个带头结点的非空循环单链表，结点结构为 $data \mid next$，其中 $next$ 是指向直接后继结点的指针， $p$ 是尾指针， $q$ 是临时指针。现要删除该链表的第一个元素，正确的语句序列是( )。

(A)
```
h -> next = h -> next -> next; q = h -> next; free(q);
```
(B)
```
q = h -> next; h -> next = h -> next -> next; free(q);
```
(C)
```
q = h -> next; h -> next = q -> next; if(p != q) p = h; free(q);
```
(D)
```
q = h -> next; h -> next = q -> next; if(p == q) p = h; free(q);
```

## DeepSeek V4 Flash Max 解析

**答案**：选 **D**。删除首元结点时应先保存 $q=h\to next$，再令 $h\to next=q\to next$；若 $p==q$，说明原表只有一个数据结点，尾指针应改为指向头结点，即 $p=h$；最后释放 $q$。

**解题切入点**：  
拿到链表删除题，先画图，尤其要区分两种情形：原链表有多个数据结点、原链表只有一个数据结点。本题的考点是“带头结点的循环单链表 + 尾指针 $p$”。删除首元结点通常只改头结点的 $next$，但因为还要维护尾指针 $p$，所以必须考虑“被删结点是否同时也是尾结点”。这等价于判断：

$$
p == q
$$

如果成立，说明首元结点就是尾结点，即链表中只有一个数据结点。

**推演**：  
设头结点为 $H$，原链表有 $n\ge 1$ 个数据结点 $a_1,a_2,\dots,a_n$，则：

$$
h=H,\qquad h\to next=a_1,\qquad p=a_n,\qquad a_n\to next=H
$$

若 $n=1$，则 $a_1$ 同时是首元结点和尾结点，且：

$$
a_1\to next=H
$$

要删除首元结点 $a_1$，正确语句序列是：

```c
q = h->next;          // q 指向待删结点 a1
h->next = q->next;    // 让头结点跨过 a1，接到下一个结点
if (p == q)           // 如果 a1 也是尾结点
    p = h;            // 删除后表为空，尾指针指向头结点
free(q);              // 释放被删结点
```

分两种情况验证：

1. 若 $n>1$，则：

$$
q=a_1,\qquad p=a_n,\qquad p\ne q
$$

删除后：

$$
h\to next=a_2
$$

尾指针 $p$ 仍指向 $a_n$，不需要修改。

2. 若 $n=1$，则：

$$
q=a_1=p
$$

删除后：

$$
h\to next=a_1\to next=H
$$

链表变成空的带头结点循环链表，此时必须令：

$$
p=h
$$

否则 $p$ 会指向已释放的结点。

因此 **D 正确**。

各选项错误原因：

- **A**：先改了 $h\to next$，再取 $q=h\to next$，此时 $q$ 已经不是原来的首元结点，导致释放错误结点；若原表只有一个结点，还会释放头结点。
- **B**：缺少尾指针修正。当原表只有一个数据结点时，$p$ 会变成野指针。
- **C**：尾指针修正条件写反了。当 $p\ne q$ 时，说明被删结点不是尾结点，尾指针本应保持不变，却把 $p$ 改成了 $h$，错误。

整个操作只修改常数个指针，时间复杂度为 $O(1)$。

**易错点**：  
- 先改链再取 $q$，会导致待删结点丢失或释放错误的结点。  
- 忽略链表只有一个数据结点的情况，忘记更新尾指针 $p$。  
- 把条件写成 `if (p != q) p = h;`，这是常见反向错误。  
- 混淆头结点和首元结点：头结点不是“第一个元素”，不能释放头结点。  
- 循环链表中尾结点的 $next$ 指向头结点，画图时不要画成指向空。

**命题规律**：  
本题属于 408 常考的链表操作题，核心是“带头结点/不带头结点链表、循环链表、头指针/尾指针维护、插入删除时的指针修改顺序”。常见变式有：

- 删除尾结点；
- 在尾部插入结点；
- 判断循环链表是否为空；
- 两个循环链表合并；
- 在链表头部/尾部操作时维护头指针和尾指针。

复习建议：做链表题时一定要画图，至少分析 $n=0,1,2$ 三种情况；牢记步骤“先保存待操作结点，再断链，再修改受影响的头指针/尾指针，最后释放结点”。

27. 某线性表用带头结点的循环单链表存储,头指针为 $head$, 当 $head \rightarrow next \rightarrow next == head$ 成立时, 线性表的长度可能是 ( ) .
A. 0
B. 1
C. 2
D. 可能为0或1

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C02-23-M27_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 **D**。当 $head\to next\to next=head$ 成立时，带头结点循环单链表中线性表的长度可能为 0 或 1。

**解题切入点**：  
拿到题先抓两个关键词：“带头结点”和“循环单链表”。

- 带头结点的循环单链表空表不是 `head->next == NULL`，而是 `head->next == head`。
- 最后一个数据结点的 `next` 指向头结点，而不是 `NULL`。

所以 $head\to next\to next=head$ 可以理解为：从头结点出发，沿 `next` 指针走 2 步，又回到头结点。只需要分别画出空表、1 个元素、2 个元素三种情况即可判断。

**推演**：  
设头结点为 $H$，线性表长度为 $n$，数据结点为 $a_1,a_2,\dots,a_n$。

1. 当 $n=0$ 时，空表：

$$H\to next=H$$

因此：

$$H\to next\to next=H\to next=H$$

条件成立。

2. 当 $n=1$ 时：

$$H\to next=a_1,\qquad a_1\to next=H$$

因此：

$$H\to next\to next=a_1\to next=H$$

条件也成立。

3. 当 $n\ge 2$ 时：

$$H\to next=a_1,\qquad a_1\to next=a_2\ne H$$

因此：

$$H\to next\to next=a_2\ne H$$

条件不成立。

更本质地看：包括头结点在内，整个循环链表共有 $n+1$ 个结点。从任一结点出发绕一圈回到自身需要 $n+1$ 次 `next`。条件等价于走 2 次 `next` 回到头结点，因此要求：

$$(n+1)\mid 2$$

所以：

$$n+1=1 \text{ 或 } 2$$

即：

$$n=0 \text{ 或 } 1$$

因此选 **D**。

**易错点**：  
- 误以为空表时 `head->next==NULL`，实际上循环单链表空表时头结点自成环，`head->next==head`。
- 只想到 1 个元素时成立，忽略空表时也成立。
- 把“最后一个结点的 next 指向头结点”误用到 2 个元素的情况；2 个元素时 `head->next->next` 是第二个数据结点，不是头结点。
- 题目问的是“线性表长度”，不含头结点；如果把头结点也算入长度，会得到 1 或 2，但不符合题意。

**命题规律**：  
本题属于链表基础题，考查带头结点循环单链表的空表判断和尾结点判断。常见变式有：

- `head->next == head`：判断空表；
- `p->next == head`：判断 $p$ 是否为最后一个结点；
- `head->next->next == head`：判断表长可能为 0 或 1。

复习链表时一定要画图理解，尤其是带头结点、不带头结点、循环链表三种结构的差异。遇到指针跳转条件，可转化为“从某点出发走 $k$ 步回到原点”的环长整除问题。

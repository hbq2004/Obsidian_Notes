# 选择题 第 14 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-23-M14_题目.png|题目]]

14. 下面关于线性表的一些说法中,正确的是 ( )。
A. 对一个设有头指针和尾指针的单链表执行删除最后一个元素的操作与链表长度无关
B. 线性表中每个元素都有一个直接前驱和一个直接后继
C. 为了方便插入和删除数据，可以使用双链表存放数据
D. 取线性表第 $i$ 个元素的时间与 $i$ 的大小有关

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C02-23-M14_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 **C**。双链表在已知结点位置时，插入和删除操作能直接利用前驱/后继指针，在 $O(1)$ 时间内完成；A、B、D 均因绝对化或未指明存储结构而错误。

**解题切入点**：拿到题目先定位为“线性表逻辑结构 + 顺序表/链表存储结构操作复杂度”的基础题。这类题常用“绝对化”词语设陷阱，例如 A 的“与长度无关”、B 的“每个元素”、D 的“与 $i$ 的大小有关”。可以类比竞赛中判断“能否不遍历就完成操作”：有尾指针的单链表方便在尾部插入，但删除尾结点仍然要先找到它的前驱；只有双链表或维护了前驱指针的结构才能直接找到前驱。

**推演**：

逐一分析各选项。

1. **选项 A：错**

对一个设有头指针 `head` 和尾指针 `tail` 的单链表，删除最后一个结点时，必须先把倒数第二个结点的 `next` 改为 `NULL`，并更新尾指针。但单链表结点只有 `next` 指针，无法从尾结点直接得到前驱结点。

以表长 $n \ge 2$ 为例，需要执行类似：

```c
p = head;
while (p->next != tail)
    p = p->next;
free(tail);
p->next = NULL;
tail = p;
```

循环次数约为 $n-2$，时间复杂度为 $O(n)$，与链表长度有关。故 A 错误。

2. **选项 B：错**

线性表的逻辑定义是：

- 第一个元素没有直接前驱；
- 最后一个元素没有直接后继；
- 除第一个元素外，每个元素有且仅有一个直接前驱；
- 除最后一个元素外，每个元素有且仅有一个直接后继。

所以不能说“每个元素都有一个直接前驱和一个直接后继”。B 忽略了首尾元素的特殊性。

3. **选项 C：对**

双链表每个结点同时包含 `prior` 和 `next` 两个指针，因此已知某结点 $p$ 时，可以在 $O(1)$ 时间内完成前插、后插或删除 $p$。

例如在结点 $p$ 后插入新结点 $s$：

```c
s->prior = p;
s->next = p->next;
if (p->next != NULL)
    p->next->prior = s;
p->next = s;
```

删除结点 $p$：

```c
p->prior->next = p->next;
if (p->next != NULL)
    p->next->prior = p->prior;
free(p);
```

相比单链表，双链表不需要从头查找前驱，因此确实更方便插入和删除。C 正确。

4. **选项 D：错**

“取线性表第 $i$ 个元素”的时间取决于存储结构。

- 若采用顺序存储，即顺序表，则第 $i$ 个元素的地址为：

$$
\mathrm{LOC}(a_i)=\mathrm{LOC}(a_1)+(i-1)\times l
$$

其中 $l$ 为每个元素占用的存储单元数。这是随机存取，时间复杂度为 $O(1)$，与 $i$ 无关。

- 若采用链式存储，即链表，则需要从头指针开始遍历，时间复杂度为 $O(i)$，与 $i$ 有关。

D 没有说明线性表采用哪种存储结构，就说“与 $i$ 的大小有关”，属于以偏概全，故 D 错误。

综上，只有 C 正确。

**易错点**：

- **误选 A**：以为有了头指针和尾指针，删除尾结点也是 $O(1)$。实际上尾指针只能给出尾结点地址，不能给出它的前驱地址；单链表删除尾结点必须遍历。
- **误选 B**：忽略线性表首元素无前驱、尾元素无后继。特殊情况如空表或只有一个元素时，更不可能“每个元素都有前驱和后继”。
- **误选 D**：把“线性表”默认成“链表”。顺序表按位查找是 $O(1)$，链表按位查找是 $O(n)$，必须区分存储结构。
- **对 C 理解过度**：双链表方便插入删除的前提是“已知插入/删除位置或已知结点指针”。如果还要先按值查找该结点，则查找部分仍是 $O(n)$。

**命题规律**：本题是线性表部分的基础概念题，考点包括：

- 线性表的逻辑特性：首尾元素特殊；
- 顺序表与链表的操作复杂度对比；
- 单链表、双链表在插入删除时的指针操作特点。

常见变式有：

- 带头尾指针的单链表在表尾插入是 $O(1)$，但删除表尾是 $O(n)$；
- 带头尾指针的双链表删除尾结点是 $O(1)$；
- 顺序表按位查找是 $O(1)$，链表按位查找是 $O(n)$；
- “线性表中每个元素都有直接前驱和直接后继”常作为错误选项出现。

复习时建议多画单链表、双链表的指针变化图，尤其要模拟“删除尾结点”的过程，并熟记顺序表与链表各基本操作的复杂度。

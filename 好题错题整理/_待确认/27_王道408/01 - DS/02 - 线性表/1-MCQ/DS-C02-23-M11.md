# 选择题 第 11 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-23-M11_题目.png|题目]]

11. 对于一个头指针为 $head$ 的带头结点的单链表，判定该表为空表的条件是 (  )；对于不带头结点的单链表，判定空表的条件为 (  ).

A. $head == NULL$
B. $head \rightarrow next == NULL$
C. $head \rightarrow next == head$
D. $head != NULL$

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C02-23-M11_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：带头结点的单链表判空选 **B**（$head \rightarrow next == \text{NULL}$）；不带头结点的单链表判空选 **A**（$head == \text{NULL}$）。

**解题切入点**：拿到题目先看链表有没有“头结点”。头结点是哨兵结点，不存数据；不带头结点时，头指针直接指向第一个数据结点。判断空表，本质是判断“是否存在数据结点”，所以关键看头指针本身是否为空，或头指针的下一个指针是否为空。可以类比：带头结点像一个固定存在的哨兵，只要哨兵后面没有士兵就是空；不带头结点则像队首指针，队里没人时指针就是空。

**推演**：

设头指针为 $head$。

1. **带头结点的单链表**

   带头结点时，创建链表时会先分配一个头结点：

   $$
   head = \text{LNode}();
   \quad head \rightarrow next = \text{NULL};
   $$

   其中 $head$ 指向头结点，头结点不存放数据。链表为空，说明头结点后面没有数据结点，即：

   $$
   head \rightarrow next = \text{NULL}
   $$

   所以应选 B。

   此时 $head$ 本身只要链表存在就不会是 $\text{NULL}$，因此 A 不能作为判空条件。C 中 $head \rightarrow next == head$ 是**带头结点的循环单链表**的判空条件，不是普通单链表的判空条件。D 中的 $head \ne \text{NULL}$ 只能说明头指针存在，无法说明表是否为空。

2. **不带头结点的单链表**

   不带头结点时，$head$ 直接指向链表的第一个数据结点。若链表为空，则没有任何数据结点，因此头指针只能为空：

   $$
   head == \text{NULL}
   $$

   所以应选 A。

   若此时用 $head \rightarrow next == \text{NULL}$ 判断，当 $head$ 为 $\text{NULL}$ 时，访问 $head \rightarrow next$ 是非法的空指针操作，因此不能选 B。

关键判断代码思路如下：

```c
// 带头结点判空
bool isEmptyWithHead(LNode *head) {
    return head->next == NULL;
}

// 不带头结点判空
bool isEmptyWithoutHead(LNode *head) {
    return head == NULL;
}
```

**易错点**：

- 易错把带头结点的空表条件误选为 $head == \text{NULL}$。实际上带头结点时，头结点始终存在，$head$ 不应为 $\text{NULL}$，空表只看头结点后面有没有数据结点。
- 易错把不带头结点的空表条件误选为 $head \rightarrow next == \text{NULL}$。这会忽略 $head == \text{NULL}$ 的情况，且会产生空指针访问。
- 易错将单链表的判空和循环链表的判空混淆。$head \rightarrow next == head$ 是带头结点循环链表的判空条件，不是普通单链表。
- 易混淆“头指针”和“头结点”：头指针是保存链表起始地址的指针变量；头结点是链表中的一个附加结点，不存放有效数据。

**命题规律**：本题是数据结构链表部分的经典概念题，考点为带头结点和不带头结点单链表的判空条件。408 中常以选择题形式考查，也可能结合链表初始化、插入、删除等操作一起考查。常见变式包括：带头结点循环链表判空、不带头结点循环链表判空、判断链表尾结点等。复习时建议通过画图理解头指针、头结点、首元结点之间的关系，并掌握链表初始化的代码写法，这样能快速应对选择题和程序分析题。

# 选择题 第 3 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-22-M03_题目.png|题目]]

3. 通常说顺序表具有随机存取的特性，指的是 ( )。
(A) 查找值为$x$的元素的时间与顺序表中元素个数$n$无关
(B) 查找值为$x$的元素的时间与顺序表中元素个数$n$有关
(C) 查找序号为i的元素的时间与顺序表中元素个数$n$无关
(D) 查找序号为i的元素的时间与顺序表中元素个数$n$有关

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C02-22-M03_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 **C**。顺序表的“随机存取”是指按序号（位置）直接访问元素，时间复杂度为 $O(1)$，与表长 $n$ 无关。

**解题切入点**：拿到题目先抓“随机存取”这四个字。它对应的是“按下标/序号直接取元素”，例如数组 `a[i]` 这种访问方式；而不是“按值查找”。可以类比：知道座位号可以直接走到对应座位，但只知道人名就必须要逐个找人。因此先排除“查找值为 $x$”的 A、B，再在 C、D 中选“与 $n$ 无关”的一项。

**推演**：

顺序表在内存中用一段连续地址存储元素。设首元素地址为 $\mathrm{LOC}(a_1)$，每个元素占 $L$ 个存储单元，则第 $i$ 个元素的地址为

$$
\mathrm{LOC}(a_i)=\mathrm{LOC}(a_1)+(i-1)L
$$

该计算公式中不含顺序表长度 $n$，所以只要知道起始地址和下标 $i$，就可以直接计算出目标地址，无需从头遍历，因此：

$$
T(i)=O(1)
$$

时间复杂度与 $n$ 无关。

再看按值查找：

```c
for (int i = 0; i < n; i++) {
    if (a[i] == x) return i;
}
```

若长度为 $n$ 且等概率查找成功，平均比较次数为

$$
\frac{1+2+\cdots+n}{n}=\frac{n+1}{2}
$$

最坏情况需要比较 $n$ 次。因此按值查找的时间与 $n$ 有关，不是随机存取的体现。

逐项判断：

- A：查找值为 $x$ 的时间与 $n$ 无关 —— 错误，按值查找一般是 $O(n)$。
- B：查找值为 $x$ 的时间与 $n$ 有关 —— 这个说法本身正确，但不是“随机存取”的含义。
- C：查找序号为 $i$ 的元素的时间与 $n$ 无关 —— 正确，这是随机存取。
- D：查找序号为 $i$ 的元素的时间与 $n$ 有关 —— 错误。

所以答案为 **C**。

**易错点**：

1. **混淆“按值查找”和“按序号查找”**。随机存取指的是按位置直接访问，不是按内容查找。  
2. **看到 B 说法正确就误选**。题目问的是“随机存取指的是”，B 虽然是对的，但不是随机存取的特性。  
3. **把链表也当作随机存取**。链表必须从头开始沿指针遍历，按序号访问是 $O(n)$，属于顺序存取。  
4. **忽略地址计算公式**。顺序表能随机存取的根源是连续存储，地址可由首地址和下标直接算出，公式中出现的是下标 $i$ 和元素大小 $L$，不出现 $n$。

**命题规律**：本题属于“线性表存储结构特点”的基础题，常以选择题形式考查。核心考点是**顺序表随机存取、链表顺序存取**的对比。常见变式有：给出首地址和元素大小，求某个元素地址；判断“数组支持随机存取”是否正确；比较按值查找和按位查找的时间复杂度；或给出访问模式选择合适存储结构。复习时要把概念与复杂度绑定记忆：**随机存取 = 按位置 $O(1)$ 访问；顺序存取 = 按位置 $O(n)$ 访问；按值查找一般另算，通常为 $O(n)$**。

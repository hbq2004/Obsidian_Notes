# 选择题 第 22 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-23-M22_题目.png|题目]]

22. 对于一个带头结点的循环双链表 $L$, 判断该表为空表的条件是 ( ).
A. $L \rightarrow prior == L \ \&\& \ L \rightarrow next == NULL$
B. $L \rightarrow prior == NULL \ \&\& \ L \rightarrow next == NULL$
C. $L \rightarrow prior == NULL \ \&\& \ L \rightarrow next == L$
D. $L \rightarrow prior == L \ \&\& \ L \rightarrow next == L$

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C02-23-M22_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 D。带头结点的循环双链表为空时，头结点 $L$ 的前驱和后继都指向自身，即  
$$L\to prior == L \quad \text{且} \quad L\to next == L.$$

**解题切入点**：先抓“循环”和“带头结点”。循环链表正常状态下不存在 NULL 指针；带头结点意味着有一个固定哨兵结点。因此判断空表不是看“指针是否为 NULL”，而是看“头结点之后有没有数据结点”。可以理解为：空表就是只有哨兵结点自己构成一个环。

**推演**：

设 $L$ 是指向头结点的指针，表中共有 $n$ 个数据结点。

- 若 $n>0$，则 $L\to next$ 指向第一个数据结点，$L\to prior$ 指向最后一个数据结点；
- 若 $n=0$，则不存在第一个或最后一个数据结点，但循环链表的指针不能指向 NULL，因此 $L\to next$ 和 $L\to prior$ 都只能指向头结点自身。

所以空表的充要条件为：

$$
L\to prior == L \quad \text{且} \quad L\to next == L.
$$

这正好对应 D 选项。

用关键代码判断：

```c
bool isEmpty(DNode *L) {
    return L->prior == L && L->next == L;
}
```

排除选项：A、B 中出现 `NULL`，不符合循环链表定义；C 中 $L\to prior == NULL$ 与循环链表矛盾，且若 $L\to next == L$，则前驱也应自指，不应为 NULL。

**易错点**：

- 把循环链表当成普通链表，看见空表就选 `next == NULL`，容易误选 A 或 B。
- 只记单循环链表判空条件 $L\to next == L$，忘记双链表还需确认 $L\to prior == L$。虽然合法结构中二者同时成立，但考试应选最严谨的 D。
- 混淆“带头结点”和“不带头结点”：不带头结点的循环双链表判空是 `L == NULL`；带头结点则是头结点自指。
- 遍历循环链表时，若用 `p != NULL` 作为结束条件会死循环，应使用 `p != L`。

**命题规律**：

本题属于“线性表—链表”的基础概念题，核心考点是带头结点循环双链表的定义和空表判定。常见变式有：

- 带头结点单循环链表判空：$L\to next == L$；
- 带头结点非循环双链表判空：$L\to next == NULL$；
- 不带头结点链表判空：$L == NULL$；
- 循环双链表中插入、删除结点时对 `prior` 和 `next` 的维护；
- 循环链表遍历结束条件 $p == L$。

复习建议：把“带头结点/不带头结点”和“循环/非循环”两两组合画空表图，牢记判断核心是“是否存在数据结点”，而不是“指针是否为空”。

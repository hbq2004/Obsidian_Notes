# 选择题 第 10 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-23-M10_题目.png|题目]]

10. 在一个长度为$n$的带头结点的单链表$h$上,设有尾指针$r$,则执行( )操作与链表的表长有关.
A. 删除单链表中的第一个元素
B. 删除单链表中的最后一个元素
C. 在单链表第一个元素前插入一个新元素
D. 在单链表最后一个元素后插入一个新元素

## DeepSeek V4 Flash Max 解析

**答案**：选 **B**。删除单链表中的最后一个元素时，必须从头结点出发找到尾结点的前驱，时间复杂度为 $O(n)$，与表长 $n$ 有关；其余三个操作均可在 $O(1)$ 时间内完成。

**解题切入点**：  
拿到题先抓住两个关键：**带头结点的单链表** + **尾指针 $r$**。单链表只能沿 `next` 域向后走，不能像双向链表一样向前回溯；尾指针 $r$ 只是让我们直接知道“尾结点是谁”，但不能直接知道“尾结点的前驱是谁”。所以遇到“删除尾结点”一定要警惕：需要遍历找前驱。

可以这样打比方：只知道队伍最后一个人是谁，要删除他，必须从头问到倒数第二个人，让倒数第二个人变成新的队尾；但在队尾后面加新人，直接让队尾接住新人即可。

**推演**：  
设带头结点的单链表长度为 $n$，$h$ 是头结点，$r$ 指向最后一个元素结点。结点结构可理解为：

```c
typedef struct LNode {
    ElemType data;
    struct LNode *next;
} LNode;
```

逐项分析：

**A. 删除单链表中的第一个元素**  
删除首元结点只需修改头结点的 `next` 域：

```c
p = h->next;
h->next = p->next;
if (r == p) r = h;   // n=1 时删除后表空，更新尾指针
free(p);
```

无论 $n$ 是多少，都不需要遍历整个链表，时间复杂度为 $O(1)$，与表长无关。

**B. 删除单链表中的最后一个元素**  
删除尾结点必须让尾结点的前驱的 `next` 指向空，否则链表会断裂。但单链表没有前驱指针，只能从头结点开始找尾结点的前驱：

```c
pre = h;
while (pre->next != r)
    pre = pre->next;

pre->next = NULL;
free(r);
r = pre;
```

这个过程需要从表头移动到倒数第二个结点，指针移动次数约为 $n-1$ 次，时间复杂度为 $O(n)$。因此该操作与表长 $n$ 有关。

**C. 在单链表第一个元素前插入一个新元素**  
这是“头插法”的核心操作：

```c
s->next = h->next;
h->next = s;
if (s->next == NULL) r = s; // 原表为空时更新尾指针
```

不需要遍历链表，时间复杂度为 $O(1)$，与表长无关。

**D. 在单链表最后一个元素后插入一个新元素**  
因为已经有了尾指针 $r$，所以可以直接在 $r$ 后插入：

```c
s->next = r->next;
r->next = s;
r = s;
```

同样不需要遍历链表，时间复杂度为 $O(1)$，与表长无关。

各操作复杂度对比：

| 选项 | 操作 | 时间复杂度 |
|---|---|---|
| A | 删除第一个元素 | $O(1)$ |
| B | 删除最后一个元素 | $O(n)$ |
| C | 第一个元素前插入 | $O(1)$ |
| D | 最后一个元素后插入 | $O(1)$ |

所以正确答案是 **B**。

**易错点**：  
1. 误以为“尾部插入需要遍历到尾部”，而忽略了题目已经给出尾指针 $r$，因此 D 是 $O(1)$。  
2. 误以为“有了尾指针 $r$ 就可以 $O(1)$ 删除尾结点”，但单链表没有 `prior` 指针，删除尾结点必须知道其前驱，前驱需要从头遍历寻找。  
3. A 在 $n=1$ 时需要额外更新尾指针 $r$，但这也是常数时间操作，不能因此认为 A 与表长有关。  
4. 做题时要注意“带头结点”这一条件：带头结点时，A 和 C 操作无需修改头指针本身，更简洁；但 B 的遍历操作仍然不可避免。

**命题规律**：  
本题属于线性表中“单链表插入删除操作时间复杂度”的高频考点。常见变式有：

- 给出带头结点单链表和尾指针，问哪些操作可在 $O(1)$ 完成；  
- 将单链表换成循环单链表或双向链表，再比较删除尾结点的复杂度；  
- 若改为带头结点的双向链表且带尾指针，则删除尾结点也可在 $O(1)$ 完成。

复习建议：把“带头结点/不带头结点”“单链表/循环链表/双向链表”“有头指针/有尾指针”等几种情况分别画图分析，重点判断**能否在 $O(1)$ 内找到目标结点的前驱**。这是解决链表操作复杂度问题的核心。

# 选择题 第 23 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-23-M23_题目.png|题目]]

23. 一个链表最常用的操作是在末尾插入结点和删除结点,则选用 ( ) 最节省时间.
A. 带头结点的循环双链表
B. 循环单链表
C. 带尾指针的循环单链表
D. 单链表

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C02-23-M23_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 **A. 带头结点的循环双链表**。因为它能同时以 $O(1)$ 时间完成末尾插入结点和删除末尾结点，其余结构至少有一个操作需要 $O(n)$ 遍历。

**解题切入点**：拿到题目先明确“末尾插入”和“删除末尾结点”各自需要什么指针。插入末尾只需要知道尾结点；删除末尾不仅要知道尾结点，还必须知道它的**前驱结点**。单链表只有 `next` 指针，无法从尾结点直接得到前驱；双链表有 `prior` 指针，可以 $O(1)$ 找到前驱。因此优先考虑带有前驱指针的结构。

**推演**：

设链表带头结点，记头结点为 `head`。

1. **带头结点的循环双链表（A）**  
   - 在末尾插入结点 `p`：  
     末尾结点为 `head->prior`，插入操作只需修改 `p` 和末尾结点、`head` 的指针：  
     ```
     p->next = head;
     p->prior = head->prior;
     head->prior->next = p;
     head->prior = p;
     ```
     时间复杂度 $O(1)$。
   - 删除末尾结点：  
     末尾结点为 `head->prior`，它的前驱为 `head->prior->prior`，直接摘除并修改指针：
     ```
     q = head->prior;
     q->prior->next = head;
     head->prior = q->prior;
     free(q);
     ```
     不需要遍历，时间复杂度 $O(1)$。

2. **循环单链表（B）**  
   若只有头指针，则末尾插入需要从头遍历到尾结点，时间 $O(n)$；删除末尾结点需要遍历到尾结点的前驱，时间 $O(n)$。显然不优。

3. **带尾指针的循环单链表（C）**  
   - 末尾插入：直接利用尾指针 `tail`，修改 `tail->next` 和 `tail`，时间 $O(1)$。  
   - 删除末尾结点：虽然知道尾结点 `tail`，但单链表结点没有 `prior` 指针，无法从 `tail` 得到前驱，必须从头遍历找到尾结点的前驱，时间 $O(n)$。  
   因此只满足“末尾插入”高效，“删除末尾”不高效。

4. **单链表（D）**  
   尾部插入和删除都需要遍历到尾部附近，时间均为 $O(n)$。

各选项时间复杂度汇总：

| 选项 | 末尾插入 | 删除末尾 |
|:---:|:---:|:---:|
| A. 带头结点的循环双链表 | $O(1)$ | $O(1)$ |
| B. 循环单链表 | $O(n)$ | $O(n)$ |
| C. 带尾指针的循环单链表 | $O(1)$ | $O(n)$ |
| D. 单链表 | $O(n)$ | $O(n)$ |

故最节省时间的是 **带头结点的循环双链表**。

**易错点**：
- **误以为带尾指针的循环单链表也能 $O(1)$ 删除尾结点**。单链表没有前驱指针，即使知道尾结点，也必须从头遍历寻找前驱，这是最常见错误。
- **忽略“循环”和“带头结点”带来的边界简化**。带头结点的循环双链表用 `head` 作为哨兵，末尾插入相当于在 `head` 前插入，删除末尾也只需通过 `prior` 找到前驱，代码无需特判空表，容易遗漏指针修改顺序。
- **混淆“插入”和“删除”两个操作**。若题目只问尾插，选 C 也可以；但本题明确两种操作都常用，必须同时满足两种操作 $O(1)$。
- **删除时忘记释放结点或指针修改顺序错误**。在双链表中摘除结点应先修改前驱结点的 `next` 和 `head->prior`，再释放结点。

**命题规律**：
- **考点定位**：线性表中链表存储结构的操作时间复杂度分析，重点考查单链表、循环链表、双链表以及带头结点、尾指针等变体。
- **常见变式**：
  1. 给出不同链表结构，判断“在表头/表尾插入、删除”的时间复杂度；
  2. 已知尾指针，问能否 $O(1)$ 删除末尾结点；
  3. 给出具体指针操作，选择正确的结点删除语句；
  4. 编写循环双链表尾插、尾删的算法代码。
- **复习建议**：总结一张“链表结构 × 插入/删除位置”的时间复杂度表，牢记单链表删除结点必须知道前驱，双链表可以 $O(1)$ 找到前驱；同时注意“带头结点”“循环”“尾指针”等条件对边界处理的影响。做这类题时先画图模拟指针修改，再判断时间复杂度。

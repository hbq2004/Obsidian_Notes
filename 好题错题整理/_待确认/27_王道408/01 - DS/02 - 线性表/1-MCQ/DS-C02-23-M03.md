# 选择题 第 3 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-23-M03_题目.png|题目]]

3.链式存储设计时，结点内的存储单元地址( ).  
A. 一定连续  
B. 一定不连续  
C. 不一定连续  
D. 部分连续,部分不连续

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C02-23-M03_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选择 A（一定连续）。链式存储中，一个结点作为一个整体一次性分配，其内部各存储单元地址连续；“不一定连续”描述的是结点之间，而不是结点内。

**解题切入点**：拿到题先圈出关键定语“结点内”还是“结点间”。这就像在竞赛/工程中定义 `struct Node { int val; Node* next; };`，`malloc` 或 `new` 返回的是一整块连续内存；链表之所以叫“链式”，只是每个结点里存放了下一个结点的地址，结点与结点之间物理上不必挨着。所以题目问“结点内”就是在问“这块结点内存内部是否连续”，答案显然是一定的。

**推演**：设某结点类型为
```c
typedef struct LNode {
    ElemType data;
    struct LNode *next;
} LNode;
```
当执行 `p = (LNode*)malloc(sizeof(LNode))` 或 `p = new LNode()` 时，系统为这个结点分配一块大小为 `sizeof(LNode)` 的连续存储空间。设该块空间的首地址为 $A$，末地址为 $A+\text{size}-1$，则该结点内任意两个存储单元的地址 $a_i,a_j$ 都满足
$$
A \le a_i, a_j \le A+\text{size}-1
$$
且结点内从首地址到末地址的各个字节地址是连续的：
$$
A,\ A+1,\ A+2,\ \dots,\ A+\text{size}-1.
$$
因此“结点内的存储单元地址”一定连续。

至于链式结构中，当前结点的 `next` 指针保存的是下一个结点的首地址。由于各结点分别由 `malloc` 分配，前后两次分配得到的内存地址不保证相邻，所以
$$
address(p_{i+1}) \quad \text{与} \quad address(p_i)
$$
不一定连续。因此“不一定连续”描述的是“结点与结点之间”，而不是“结点内”。

**易错点**：
1. 把“结点内”看成“结点间”，从而误选 C。规避方法：读题先划出“内/外”等限定词。
2. 误以为链式存储所有单元都离散，于是选 D“部分连续、部分不连续”。实际上结点内部是一个整体，全部连续；结点之间才是不一定连续。
3. 误选 B“一定不连续”。除非题目显式说明两个结点必须分开存放，否则没有“一定不连续”的保证，而且实际动态分配也常常可能连续（尽管不保证）。

**命题规律**：该题属于“数据结构基本概念/存储结构”高频考点，考查顺序存储与链式存储的本质区别。常见变式有：①“链式存储中结点间的存储单元地址（不一定连续）”；②“顺序存储中逻辑相邻元素的物理位置（一定相邻）”；③“链式存储能否随机存取（不能，需从头遍历）”。复习时要把“逻辑结构”与“存储结构”分开记忆，并掌握 C 语言中 `malloc`/`struct` 所代表的物理语义，这类题在选择题中常以 1~2 分出现。

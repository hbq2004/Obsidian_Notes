## DeepSeek V4 Flash Max 解析

**答案**：第1题：一趟扫描确定唯一最小值下标，用最后一个元素覆盖该位置并删除，返回被删值；第2题：首尾双指针交换对称元素，原地逆置，空间复杂度 $O(1)$。

**解题切入点**：拿到第1题，先抓住“顺序表”和“最小值删除”。顺序表支持随机访问，找最小值只需一次线性遍历；而“空出的位置由最后一个元素填补”这句话暗示不需要保持原相对顺序，因此可以避免大量移动元素，直接用表尾元素覆盖待删位置。这类似于算法竞赛中“用末尾元素补空洞，再弹出末尾”的 $O(1)$ 删除技巧。拿到第2题，看到“逆置”且“空间复杂度 $O(1)$”，立刻排除新建数组的方案，应该想到从两端向中间交换元素，即双指针法。

**推演**：设顺序表存储定义为
```cpp
typedef struct {
    ElemType data[MaxSize];
    int length;
} SqList;
```
其中 `ElemType` 为元素类型。以下用 C++ 引用描述，若使用纯 C，可将 `SqList &L` 改为 `SqList *L`，并相应使用 `L->data` 和 `L->length`。

**第1题：删除最小值**

算法步骤：
1. 若 `L.length == 0`，输出错误信息并退出运行。
2. 令 `minPos = 0`，从 `i = 1` 扫到 `i = L.length - 1`，若 `L.data[i] < L.data[minPos]`，则更新 `minPos = i`。
3. 用 `value` 保存被删元素的值：`value = L.data[minPos]`。
4. 用最后一个元素填补被删位置：`L.data[minPos] = L.data[L.length - 1]`。
5. `L.length--`，返回 `value`。

关键代码如下：
```cpp
ElemType DeleteMin(SqList &L) {
    if (L.length == 0) {
        printf("顺序表为空，无法删除！");
        exit(0);
    }
    int minPos = 0;
    for (int i = 1; i < L.length; i++) {
        if (L.data[i] < L.data[minPos])
            minPos = i;
    }
    ElemType value = L.data[minPos];
    L.data[minPos] = L.data[L.length - 1];
    L.length--;
    return value;
}
```

正确性：扫描结束后，`minPos` 指向表中唯一最小值的下标。若最小值不在表尾，则表尾元素移到 `minPos` 处，原最小值被覆盖；若最小值恰好在表尾，则 `L.data[minPos] = L.data[L.length - 1]` 是自我赋值，随后 `L.length--` 直接删除末尾最小值。两种情况均满足“删除最小值且由最后一个元素填补空位”的要求。

时间复杂度：一趟扫描 $O(n)$，覆盖与长度修改 $O(1)$，总时间 $O(n)$；只使用常数个辅助变量，空间 $O(1)$。

**第2题：逆置顺序表**

算法步骤：
1. 令 $i=0$，$j=L.length-1$。
2. 当 $i<j$ 时，交换 `L.data[i]` 与 `L.data[j]`。
3. $i++$，$j--$，继续循环；当 $i \ge j$ 时结束。

关键代码如下：
```cpp
void Reverse(SqList &L) {
    int i = 0, j = L.length - 1;
    while (i < j) {
        ElemType temp = L.data[i];
        L.data[i] = L.data[j];
        L.data[j] = temp;
        i++;
        j--;
    }
}
```

正确性：设表长为 $n$。每次交换使首尾对称的两个元素互换位置，经过若干轮后，两端已逆置的区间向中间扩展。当 $n$ 为偶数时，$i$ 与 $j$ 会交错，循环停止；当 $n$ 为奇数时，$i$ 与 $j$ 会相遇在中间元素，该元素不需交换。因此共交换 $\lfloor n/2 \rfloor$ 次，所有元素恰好被逆置。

时间复杂度：交换 $\lfloor n/2 \rfloor$ 次，每次 $O(1)$，总时间 $O(n)$；只使用一个临时变量 `temp`，空间 $O(1)$。

**易错点**：第1题删除前必须检查空表，否则访问 `data[0]` 会越界；删除操作顺序应为“保存最小值 → 用表尾元素覆盖 → 长度减一”，不能先把长度减一，否则取不到原表尾元素；题设说“最小值唯一”，若实际有多个最小值，该算法只删除一个，不满足假设。第2题循环条件应写 `i < j`，不要写成 `i <= j`，后者虽然结果不变但会多做一次自我交换；空表和单元素表必须能直接退出，避免越界；交换两个元素时建议使用临时变量，虽然异或或加减法也能实现，但可读性差且容易出错。

**命题规律**：这两题属于顺序表基本操作的经典考题，核心考点是线性表的顺序存储、边界条件、时间与空间复杂度分析。常见变式包括：删除所有值为 $x$ 的元素、删除值在 $[s,t]$ 内的元素、有序顺序表去重、将顺序表循环左移或右移 $p$ 个位置、合并两个有序顺序表等。复习时应重点掌握“覆盖法”“双指针法”“逆向移动法”等典型技巧，并熟练分析空表、单元素、元素在表尾等边界情况。

## 答案

## DeepSeek V4 Flash Max 解析

**答案**：采用迭代头插法，将原链表结点依次摘下插入到头结点之后，实现就地逆置，辅助空间为$O(1)$。

**解题切入点**：单链表逆置是链表操作的基本题型，要求“就地”即空间复杂度常数，因此不能用递归（隐含栈空间）或创建新结点。核心是改变指针方向。常见思路：遍历链表，将每个结点插入到头结点之后（头插法），这样原链表顺序被逆转。注意头结点不动，第一个结点变成最后一个。算法需要三个指针：p指向当前结点，r指向后继以防断链；或者使用前驱和当前指针反转。

**推演**：算法步骤：设带头结点的单链表L，头结点为L。1. 初始化指针p = L->next（第一个结点），并将L->next置空，使其成为新链表的头结点（头结点不动）。2. 遍历原链表：当p不为空时，暂存p的后继r = p->next；然后将p插入到头结点之后：p->next = L->next; L->next = p; p = r; 3. 重复直到p为空。此时链表逆置完成。关键代码（C语言描述）：
```c
void Reverse(LinkList &L) {
    LNode *p = L->next, *r;
    L->next = NULL; // 将头结点摘开
    while (p != NULL) {
        r = p->next; // 暂存后继
        p->next = L->next; // 头插
        L->next = p;
        p = r;
    }
}
```
时间复杂度$O(n)$，空间复杂度$O(1)$。

也可以使用三指针迭代反转：pre=NULL, cur=p, nxt。但原理相同。

**易错点**：1. 忘记将头结点next置空，导致最后形成环或未逆置完全。2. 头插法时顺序搞错，导致断链。3. 循环条件判断，注意空表处理。4. 指针类型错误，如混用头结点和第一个结点。5. 递归方法虽然简洁但空间复杂度O(n)，不符合“就地”要求。

**命题规律**：本题是链表操作的基础题，408真题中常出现，如2019年考察双向链表逆置等。变式：不带头结点单链表逆置，需要返回新头指针；给定区间逆置；k个一组逆置；递归逆置等。复习建议：熟练掌握链表基本操作，画图理解指针变化，重视边界条件。

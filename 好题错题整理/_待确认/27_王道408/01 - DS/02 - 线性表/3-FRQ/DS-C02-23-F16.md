# 综合题 第 16 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-23-F16_题目.png|题目]]

16. 设有一个长度 $n$($n$ 为偶数)的不带头结点的单链表，且结点值都大于 0，设计算法求这个单链表的最大孪生和. 孪生和定义为一个结点值与其孪生结点值之和，对于第 $i$ 个结点 (从 0 开始)，其孪生结点为第 $n-i-1$ 个结点. 要求:
1) 给出算法的基本设计思想.
2) 根据设计思想，采用 $C$ 或 $C++$ 语言描述算法，关键之处给出注释.
3) 说明你的算法的时间复杂度和空间复杂度.

## DeepSeek V4 Flash Max 解析

**答案**：将链表后半段原地反转，再与前半段逐结点配对求和，取最大值；时间复杂度 $O(n)$，空间复杂度 $O(1)$。

**解题切入点**：孪生和本质上是“首尾配对”的折半问题。数组可以直接用双指针从两端向中间走，但单链表不能倒着访问，所以核心技巧是：先找到后半段起点，把后半段反转，这样原来的尾结点就变成了第二个链表的头结点，从而可以和前半段同步遍历。这个思路和“判断回文链表”“重排链表”是同一类套路。

**推演**：

设链表长度为 $n=2k$，结点值依次为 $a_0,a_1,\dots,a_{2k-1}$。要求的是

$$
\max_{0\le i<k}\left(a_i+a_{2k-1-i}\right)
$$

算法分四步：

1. 快慢指针找中点。`slow`、`fast` 都从 `head` 出发，`fast` 每次走两步，`slow` 每次走一步。当 `fast` 为空时，`slow` 正好指向后半段第一个结点。
2. 断开前半段和后半段，记录前半段最后一个结点 `firstTail`。
3. 反转以 `slow` 为头结点的后半段，得到新头 `rHead`。
4. 用两个指针 `p`、`q` 分别从 `head` 和 `rHead` 出发，同步向后走，每次计算 `p->data + q->data`，更新最大值。

C/C++ 代码描述如下：

```cpp
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode;

int maxTwinSum(LNode *head) {
    if (head == NULL || head->next == NULL)
        return 0;

    LNode *slow = head, *fast = head, *firstTail = NULL;

    // 1. 快慢指针找中点
    while (fast != NULL && fast->next != NULL) {
        firstTail = slow;
        slow = slow->next;
        fast = fast->next->next;
    }
    // 此时 slow 指向后半段第一个结点
    // firstTail 指向前半段最后一个结点

    // 2. 断开前后两半，便于分别遍历
    firstTail->next = NULL;

    // 3. 反转后半段链表
    LNode *prev = NULL, *cur = slow;
    while (cur != NULL) {
        LNode *next = cur->next; // 先保存后继，防止断链
        cur->next = prev;
        prev = cur;
        cur = next;
    }
    LNode *rHead = prev; // 反转后半段后的新头

    // 4. 前半段和反转后的后半段同步遍历
    int maxSum = 0; // 题目说明结点值均大于 0
    LNode *p = head, *q = rHead;

    while (q != NULL) {
        int sum = p->data + q->data;
        if (sum > maxSum)
            maxSum = sum;
        p = p->next;
        q = q->next;
    }

    return maxSum;
}
```

正确性证明：

- 因为 $n=2k$，快慢指针循环恰好执行 $k$ 次。`fast` 从第 $0$ 个结点移动到空指针，`slow` 从第 $0$ 个结点移动到第 $k$ 个结点，也就是后半段第一个结点。
- 后半段反转后，`rHead` 开始的序列为

$$
a_{2k-1}, a_{2k-2}, \dots, a_k
$$

- 于是第 $j$ 次配对时，`p` 指向 $a_j$，`q` 指向 $a_{2k-1-j}$，正好是题目定义的孪生结点。
- 循环遍历了所有 $k$ 对孪生结点，每次更新最大值，因此结果正确。

时间复杂度：找中点、反转后半段、遍历配对都是 $O(n)$，总时间 $O(n)$。  
空间复杂度：只使用了常数个辅助指针，没有使用额外数组或递归栈，因此空间 $O(1)$。

**易错点**：

- 快慢指针的终止条件必须写 `fast != NULL && fast->next != NULL`，否则当 `fast` 已经为空时再访问 `fast->next` 会空指针异常。
- 反转链表时，必须先保存 `cur->next`，再修改 `cur->next = prev`，否则会丢失后续结点。
- 遍历配对时建议用 `while (q != NULL)`，不要用 `while (p != NULL)`。如果前后两半没有断开，`p` 可能多走进入后半段，导致空指针或重复计算。
- 题目给出结点值都大于 $0$，所以 `maxSum` 初始化为 $0$ 是安全的；如果没有这个条件，应初始化为第一个孪生和或 `INT_MIN`。
- 该算法会修改原链表。如果题目要求不改变链表结构，则需要借助辅助栈或数组，但空间复杂度会变为 $O(n)$。

**命题规律**：本题是链表综合题的经典考法，核心考点是“快慢指针找中点 + 链表原地反转 + 双指针配对”。常见变式有：判断回文链表、重排链表（$L_0,L_n,L_1,L_{n-1},\dots$）、求链表中间结点、两半链表交替合并等。复习时应熟练掌握链表反转的迭代写法，注意边界条件，并养成“先写设计思想，再写注释代码，最后写复杂度”的答题习惯。

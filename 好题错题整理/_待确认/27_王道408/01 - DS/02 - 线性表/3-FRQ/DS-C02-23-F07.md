# 综合题 第 7 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-23-F07_题目.png|题目]]

7. 在一个递增有序的单链表中，存在重复的元素。设计算法删除重复的元素，例如 (7, 10, 10, 21, 30, 42, 42, 42, 51, 70) 将变为 (7, 10, 21, 30, 42, 51, 70)。

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C02-23-F07_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：利用链表“递增有序”的性质，重复元素必连续相邻；只需一趟扫描，保留每个重复段的第一个结点，删除后续所有相同值的结点。时间复杂度 $O(n)$，空间复杂度 $O(1)$。

**解题切入点**：
看到“递增有序”且“有重复元素”，应立刻想到：重复元素一定相邻。例如序列 $a_1\le a_2\le\cdots\le a_n$ 中，若 $a_i=a_j(i<j)$，则夹在中间的 $a_k$ 必然也等于 $a_i$，所以相同值一定连成一个连续区段。

再看单链表删除操作：删除一个结点必须知道它的前驱。这里让指针 `p` 指向“当前保留区段的最后一个结点”，`q=p->next` 就是待检查结点，于是 `p` 正好是 `q` 的前驱，可以直接完成删除。

如果不用有序性，而用哈希表或二重循环也能去重，但会丢掉题目给的最关键条件，不是最优解法。考研算法题应充分利用“有序”带来的相邻性。

**推演**：

设原链表值为
$$
a_1\le a_2\le\cdots\le a_n.
$$
若 $a_i=a_j\ (i<j)$，则对任意 $i\le k\le j$，由单调性有
$$
a_i\le a_k\le a_j=a_i,
$$
所以 $a_k=a_i$。因此所有相同值的结点必然连续成段。去重时，只需保留段首结点，删除段内其余结点。

以带头结点的单链表为例，结点定义与算法如下：

```c
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;

void DeleteDuplicates(LinkList L) {          // L 指向头结点
    LNode *p = L->next;                      // p 指向首元结点

    while (p != NULL && p->next != NULL) {
        LNode *q = p->next;

        if (p->data == q->data) {            // 重复，删除 q
            p->next = q->next;               // 先连后继
            free(q);                         // 再释放结点
        } else {
            p = q;                           // 遇到不同值，p 后移
        }
    }
}
```

若链表不带头结点，只需把初始化改为 `LNode *p = L;`，并在函数开头判断 `if (L == NULL) return;`，其余逻辑完全相同。因为本算法永远保留每个重复段的第一个结点，所以头指针不会变。

正确性可从循环不变量理解：

- 每次进入循环时，从头结点到 `p` 之间的链表已经满足“无重复值”；
- `p` 是当前已保留链表的最后一个结点；
- 若 `p->data == q->data`，说明 `q` 与当前段首相同，应删除；
  删除后 `p` 不动，继续检查新后继，因为后面可能还有相同值；
- 若 `p->data != q->data`，由于有序，必有 `q->data > p->data`，说明 `q` 是一个新值的首结点，将其保留并让 `p = q`。

示例执行过程：

$$
(7,10,10,21,30,42,42,42,51,70)
$$

- 删除第二个 $10$，得到 $(7,10,21,30,42,42,42,51,70)$；
- 删除第二个、第三个 $42$，得到 $(7,10,21,30,42,51,70)$。

每个结点最多被检查一次，若被删除也只需 $O(1)$ 修改指针，因此时间复杂度 $O(n)$；只用若干指针变量，空间复杂度 $O(1)$。

**易错点**：

1. **对“删除重复元素”理解错误**。本题示例表明是“每个值保留一个”，不是把重复值全部删光。如果要求一个不留，则需要额外判断该段是否出现多次，并删除整段。
2. **删除时先 `free(q)` 再取 `q->next`**。必须先让 `p->next = q->next`，再释放 `q`，否则 `q->next` 已经无法访问，链表会断链。
3. **删除后立即后移 `p`**。例如对 $42,42,42$，删除第二个 $42$ 后若让 `p = p->next`，`p` 会指向第三个 $42$，最后会留下两个 $42$。正确做法是：删除时 `p` 不动，继续检查新的后继；只有遇到不同值才让 `p = q`。
4. **忽略空表和单结点情况**。若 `p == NULL` 或 `p->next == NULL`，应直接结束。
5. **没有利用有序性**。用哈希表虽然能去重，但在 408 算法题中通常需要优先使用原地、线性、常数空间的解法。

**命题规律**：

本题属于“线性表（链表）的算法设计”，是 408 综合应用高频考点。核心考查点有三个：

1. 有序表性质：重复元素相邻；
2. 单链表删除操作：必须知道前驱；
3. 指针修改顺序：先连接、后释放。

常见变式：

- 有序顺序表去重：用快慢指针，$O(n)$ 时间、$O(1)$ 空间；
- 无序单链表去重：可用双重循环，$O(n^2)$，若有额外空间也可用哈希表；
- 删除有序链表中的所有重复结点，即重复值一个不留：需要增加前驱指针，并判断整个重复段；
- 两个有序链表合并后去重；
- 求两个有序链表的交集、并集。

复习建议：这类题必须动手画链表指针变化图，尤其是“删除后 `p` 不动”这一细节。写代码时养成先写出结点结构、再写算法步骤、最后写循环不变量的习惯，并在结尾标注时间复杂度和空间复杂度。

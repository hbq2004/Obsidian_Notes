## DeepSeek V4 Flash Max 解析

**答案**：核心思想是“正数乘后缀最大值，负数乘后缀最小值”。从右向左扫描，同时维护后缀最大值和最小值，即可在 $O(n)$ 时间内、$O(1)$ 额外空间内求出所有 $res[i]$。

**解题切入点**：  
看到“对每个 $A[i]$ 求它与右侧 $A[j]$ 的乘积最大值”，最容易想到暴力二重循环 $O(n^2)$。但 $A[i]$ 是固定因子，乘积只取决于右侧 $A[j]$ 的取值；又因为 $A[i]$ 有正负之分，所以真正需要维护的是右侧后缀的最大值和最小值。这就像“手里是正数就找最大的数乘，手里是负数就找最小的数乘”。

**推演**：

设
$$
M_i=\max\{A[k]\mid i\le k\le n-1\},\qquad
m_i=\min\{A[k]\mid i\le k\le n-1\}.
$$

对于固定的 $i$，若 $A[i]\ge 0$，乘法不改变大小顺序，所以应选后缀最大值：
$$
res[i]=A[i]\cdot M_i.
$$

若 $A[i]<0$，乘法会改变大小顺序，所以应选后缀最小值：
$$
res[i]=A[i]\cdot m_i.
$$

由于 $M_i,m_i$ 都只与后缀有关，可以从右向左滚动维护：
$$
M_i=\max(A[i],M_{i+1}),\qquad m_i=\min(A[i],m_{i+1}).
$$

**C 语言代码**：

```c
void calMulMax(int A[], int res[], int n) {
    if (n <= 0) return;

    int maxSuf = A[n - 1];  // 后缀最大值
    int minSuf = A[n - 1];  // 后缀最小值
    int i;

    for (i = n - 1; i >= 0; --i) {
        // 注意：先把 A[i] 并入后缀集合，再计算结果
        if (A[i] > maxSuf) maxSuf = A[i];
        if (A[i] < minSuf) minSuf = A[i];

        if (A[i] >= 0)
            res[i] = A[i] * maxSuf;
        else
            res[i] = A[i] * minSuf;
    }
}
```

**复杂度**：循环执行 $n$ 次，每次只做常数次比较和乘法，所以时间复杂度为 $O(n)$；只用了 `maxSuf`、`minSuf` 等常数个辅助变量，额外空间复杂度为 $O(1)$。因为至少要输出 $n$ 个结果，$O(n)$ 已达到最优。

**易错点**：

- **扫描方向错误**：本题依赖右侧后缀，必须从右向左扫描；从左向右维护的是前缀，不能直接使用。
- **漏掉 $j=i$ 的情况**：$j$ 可以等于 $i$，尤其负数乘以自己可能得到最大值，例如 $A=\{-5,2,3\}$ 时，$A[0]\times A[0]=25$ 才是最大。因此必须先更新后缀最值，再计算 `res[i]`。
- **只维护后缀最大值**：当 $A[i]<0$ 时必须乘后缀最小值，否则会出错，例如 $A=\{-1,-10,2\}$，$A[0]\times A[1]=10$ 是最大，而不是 $A[0]\times 2=-2$。
- **复杂度误判**：使用后缀最值数组也可行，但额外空间为 $O(n)$；本题要求尽可能高效，滚动两个变量即可做到 $O(1)$ 额外空间。

**命题规律**：  
该题属于线性表/数组综合应用题，核心是“将二重循环优化为一次扫描”。常见变式包括：把 $j$ 的范围改为 $0\le j\le i$，则变成维护前缀最值；或求两个元素的乘积最大值/最小值，则需要同时维护最大、次大和最小、次小等。复习时应重点掌握利用单调性和符号分类来维护扫描过程中的最值信息。

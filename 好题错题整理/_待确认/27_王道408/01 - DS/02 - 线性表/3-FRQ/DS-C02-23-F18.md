# 综合题 第 18 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-23-F18_题目.png|题目]]

18.【2012统考真题】假定采用带头结点的单链表保存单词,当两个单词有相同的后缀时,可共享相同的后缀存储空间，例如，loading 和 being 的存储映像如下图所示.
【图：两个带头结点的单链表str1和str2。str1指向的链表结点依次为字符‘l’, ‘o’, ‘a’, ‘d’, ‘i’, ‘n’, ‘g’，其中‘i’结点是共享结点。str2指向的链表结点依次为字符‘b’, ‘e’，然后其next指针指向str1链表中的‘i’结点。共享结点‘i’后为‘n’, ‘g’，‘g’的next为NULL。一个指针p指向共享结点‘i’.】
设 str1 和 str2 分别指向两个单词所在单链表的头结点,链表结点结构为 datanext 请设计一个时间上尽可能高效的算法，找出由 str1 和 str2 所指向两个链表共同后缀的起始位置 (如图中字符i所在结点的位置 p). 要求:
1) 给出算法的基本设计思想.
2) 根据设计思想，采用 C 或 C++ 或 Java 语言描述算法，关键之处给出注释.
3) 说明你所设计算法的时间复杂度.

# 综合题 第 18 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-23-F18_题目.png|题目]]

18.【2012统考真题】假定采用带头结点的单链表保存单词，当两个单词有相同的后缀时，可共享相同的后缀存储空间，例如，$loading$和$being$的存储映像如下图所示。
【图：形态简述】两个带头结点的单链表str1和str2，其中str1指向的链表存储“loading”，str2指向的链表存储“being”。两个链表从字符'i'开始共享后续结点（i, n, g, ^），指针p指向共享后缀的起始结点i。

设 $str1$ 和 $str2$ 分别指向两个单词所在单链表的头结点，链表结点结构为 $data \ next$。请设计一个时间上尽可能高效的算法，找出由 $str1$ 和 $str2$ 所指向两个链表共同后缀的起始位置（如图中字符i所在结点的位置 $p$）。要求：
1) 给出算法的基本设计思想.
2) 根据设计思想，采用 $C$ 或 $C++$ 或 $Java$ 语言描述算法，关键之处给出注释.
3) 说明你所设计算法的时间复杂度.

## DeepSeek V4 Flash Max 解析

**答案**：用“长度对齐双指针法”：先分别统计两个链表的长度，让较长链表的指针先走长度差，再同步移动，返回第一个地址相同的结点，即为共同后缀的起始位置；时间 $O(L_1+L_2)$，空间 $O(1)$。

**解题切入点**：单链表每个结点只有一个 `next` 指针，所以一旦两个链表在某个结点处地址相同，后续所有结点必然完全相同。题目本质是“求两个单链表的第一个相交结点”。拿到题先想到：单链表不能从尾向头走，必须用“从表头出发”的办法；若两链表长度不同，直接同步遍历会错位。于是先计算长度，把两条链表的“尾部对齐”，再同步扫描。类比跑步：两个人要跑到同一个终点，先把路程差补平，再同时起跑，就能在同一个时刻到达汇合点。

**推演**：

（1）基本设计思想：

设两个链表的数据结点长度分别为 $L_1$、$L_2$，公共后缀长度为 $s$，第一个公共结点为 $P$。则公共结点 $P$ 之前两链表的结点数分别为

$$
a=L_1-s,\qquad b=L_2-s.
$$

若 $L_1\ge L_2$，则

$$
L_1-L_2=(a+s)-(b+s)=a-b.
$$

让较长链表的指针先走 $L_1-L_2=a-b$ 步，它到公共结点 $P$ 的距离变成

$$
a-(a-b)=b,
$$

恰好等于较短链表头指针到 $P$ 的距离 $b$。此后两个指针同步后移，第一次出现“指针地址相同”的结点，就是共同后缀的起始位置。若无公共后缀，则两个指针会同时走到 `NULL`。

（2）C 语言算法描述：

```c
#include <stddef.h>

typedef struct LNode {
    char data;
    struct LNode *next;
} LNode;

/* 求链表数据结点长度，不带头结点 */
int listLength(LNode *L) {
    int len = 0;
    LNode *p = L->next;      // 跳过不含数据的头结点
    while (p != NULL) {
        len++;
        p = p->next;
    }
    return len;
}

LNode *findCommonSuffix(LNode *str1, LNode *str2) {
    int len1 = listLength(str1);
    int len2 = listLength(str2);

    LNode *p = str1->next;   // p 指向 str1 的第一个字符结点
    LNode *q = str2->next;   // q 指向 str2 的第一个字符结点

    int diff = len1 - len2;

    if (diff > 0) {
        // str1 较长，先走长度差
        for (int i = 0; i < diff; i++) {
            p = p->next;
        }
    } else if (diff < 0) {
        // str2 较长，先走长度差
        for (int i = 0; i < -diff; i++) {
            q = q->next;
        }
    }

    // 同步移动，比较的是结点地址，而不是 data 值
    while (p != NULL && p != q) {
        p = p->next;
        q = q->next;
    }

    return p;   // 若无公共后缀，p 为 NULL
}
```

（3）复杂度说明：

求两链表长度需扫描两条链表各一遍，时间为 $O(L_1+L_2)$；长度对齐和同步比较扫描的总步数也不超过 $O(L_1+L_2)$。因此总时间复杂度为

$$
O(L_1+L_2).
$$

只使用了若干指针变量和整型变量，没有使用额外数组或栈，因此空间复杂度为

$$
O(1).
$$

**易错点**：

- 统计长度时容易把“头结点”也算进去。头结点不存放字符，求长度必须从 `str1->next` 开始计数，否则长度多 1，导致移动步数错误。
- 比较时一定要用 `p != q` 来判断结点地址是否相同，不能比较 `p->data == q->data`。两个不同位置的结点可能存放相同字符，但并不是共享后缀。
- 不要使用二重循环暴力比较两链表的所有结点，那样时间复杂度是 $O(L_1L_2)$，不符合“时间上尽可能高效”的要求。
- 不要通过反转链表或破坏链表结构来解决问题；题目只要求找出位置，不应修改原链表。
- 用栈或递归从尾到头比较虽然也可行，但会引入 $O(n)$ 的额外空间；在 408 算法设计中，能用常数空间解决的应优先用常数空间。
- 边界情况：两链表长度相等、没有公共后缀、链表为空等，返回值应能正确处理为 `NULL`。

**命题规律**：本题是 408 统考中的高频链表综合题，考点为“单链表基本操作 + 双指针”。“找两个链表的公共后缀/第一个相交结点”是经典变式，类似的还有“判断两个链表是否相交”“判断链表是否有环并找环入口”“找倒数第 $k$ 个结点”等。复习时应重点掌握头结点与头指针的区别、链表长度统计、指针移动步数的画图推导，并牢记：判断共享结点看地址，不看数据值。对于“时间尽可能高效”的链表题，最终答案通常应达到 $O(n)$ 时间、$O(1)$ 空间。

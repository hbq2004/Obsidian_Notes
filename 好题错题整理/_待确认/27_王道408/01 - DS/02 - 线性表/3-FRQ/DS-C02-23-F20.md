# 综合题 第 20 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-23-F20_题目.png|题目]]

20.【2019 统考真题】设线性表 $L=(a_1,a_2,a_3,\cdots,a_{n-2},a_{n-1},a_n)$ 采用带头结点的单链表保存,链表中的结点定义如下:
```c
typedef struct node {
    int data;
    struct node *next;
} NODE;
```
请设计一个空间复杂度为 $O(1)$ 且时间上尽可能高效的算法, 重新排列 $L$ 中的各结点, 得到线性表 $L'=(a_1,a_n,a_2,a_{n-1},a_3,a_{n-2},\cdots)$。 要求:
1) 给出算法的基本设计思想。
2) 根据设计思想, 采用 $C$ 或 $C++$ 语言描述算法, 关键之处给出注释。
3) 说明你所设计的算法的时间复杂度。

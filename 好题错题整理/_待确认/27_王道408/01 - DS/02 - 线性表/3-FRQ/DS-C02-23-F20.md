# 综合题 第 20 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-23-F20_题目.png|题目]]

20.【2019 统考真题】设线性表 $L = (a_1, a_2, a_3, \cdots, a_{n-2}, a_{n-1}, a_n)$ 采用带头结点的单链表保存, 链表中的结点定义如下:

```c
typedef struct node {
    int data;
    struct node*next;
}NODE;
```

请设计一个空间复杂度为 $O(1)$ 且时间上尽可能高效的算法, 重新排列 $L$ 中的各结点, 得到线性表 $L' = (a_1, a_n, a_2, a_{n-1}, a_3, a_{n-2}, \cdots)$. 要求:
1) 给出算法的基本设计思想.
2) 根据设计思想, 采用 $C$ 或 $C++$ 语言描述算法, 关键之处给出注释.
3) 说明你所设计的算法的时间复杂度.

## DeepSeek V4 Flash Max 解析

**答案**：采用“快慢指针找中点 → 后半段原地逆置 → 两段交替合并”的方法，时间复杂度为 $O(n)$，空间复杂度为 $O(1)$。

**解题切入点**：  
先观察目标序列：
\[
L'=(a_1,a_n,a_2,a_{n-1},a_3,a_{n-2},\cdots)
\]
它本质上就是把后半段结点**从尾到头**依次插入前半段对应结点之后。单链表不支持随机访问，且题目要求空间 $O(1)$，所以不能复制到数组，也不能每次从头找尾结点。应立刻定位到三个基本链表操作：

1. 找中间结点：快慢指针；
2. 逆置链表：原地头插；
3. 合并两段链表：交替“拉链式”插入。

可以理解为：把链表从中间“折一下”，再把后半段掉头，最后像拉链一样交叉合并。

---

**推演**：

### 1. 基本设计思想

设链表长度为 $n$，令
\[
m=\left\lceil \frac{n}{2} \right\rceil
\]

先用快慢指针找到第 $m$ 个结点，即前半段的最后一个结点。然后从该结点后面把链表拆成两段：

- 前半段：
\[
F=(a_1,a_2,\cdots,a_m)
\]

- 后半段：
\[
S=(a_{m+1},a_{m+2},\cdots,a_n)
\]

将后半段 $S$ 原地逆置，得到：
\[
S'=(a_n,a_{n-1},\cdots,a_{m+1})
\]

最后把 $S'$ 中的结点依次插入到 $F$ 中对应结点之后：

\[
a_1,a_n,a_2,a_{n-1},a_3,a_{n-2},\cdots
\]

最终得到题目要求的 $L'$。

### 2. 算法步骤

1. 用快慢指针找中间结点：
   - `slow` 每次走一步；
   - `fast` 每次走两步；
   - 当 `fast` 不能继续走两步时，`slow` 指向前半段最后一个结点。

2. 令 `second = slow->next`，并令 `slow->next = NULL`，将链表拆成前后两段。

3. 将 `second` 指向的后半段链表原地逆置。

4. 用两个指针分别指向前半段和逆置后的后半段，交替合并：
   - 把后半段当前结点插入到前半段当前结点之后；
   - 前半段指针移动到下一个原前半段结点；
   - 后半段指针移动到下一个结点。

### 3. C 语言代码描述

```c
typedef struct node {
    int data;
    struct node *next;
} NODE;

void rearrangeList(NODE *L) {
    // L 是带头结点的单链表头指针
    if (L == NULL || L->next == NULL) {
        return;
    }

    // 1. 快慢指针找中间结点
    NODE *slow = L->next;
    NODE *fast = L->next;

    while (fast->next != NULL && fast->next->next != NULL) {
        slow = slow->next;          // 慢指针走一步
        fast = fast->next->next;    // 快指针走两步
    }

    // 2. 拆成前后两段
    NODE *second = slow->next;      // 后半段第一个结点
    slow->next = NULL;              // 断开前后两段

    // 3. 将后半段原地逆置
    NODE *rev = NULL;
    while (second != NULL) {
        NODE *temp = second->next;
        second->next = rev;
        rev = second;
        second = temp;
    }

    // 4. 交替合并两段链表
    NODE *p = L->next;   // 指向前半段
    NODE *q = rev;       // 指向逆置后的后半段

    while (q != NULL) {
        NODE *pNext = p->next;  // 保存前半段下一个结点
        NODE *qNext = q->next;  // 保存后半段下一个结点

        q->next = pNext;        // 将 q 插入到 p 后面
        p->next = q;

        p = pNext;              // p 移动到原前半段下一个结点
        q = qNext;              // q 移动到未插入的后半段结点
    }
}
```

### 4. 正确性说明

当 $n$ 为偶数时，设 $n=2m$：

\[
F=(a_1,\cdots,a_m),\qquad S'=(a_{2m},a_{2m-1},\cdots,a_{m+1})
\]

交替合并后为：

\[
a_1,a_{2m},a_2,a_{2m-1},\cdots,a_m,a_{m+1}
\]

这正是要求的 $L'$。

当 $n$ 为奇数时，设 $n=2m+1$：

\[
F=(a_1,\cdots,a_{m+1}),\qquad S'=(a_{2m+1},a_{2m},\cdots,a_{m+2})
\]

交替合并后为：

\[
a_1,a_{2m+1},a_2,a_{2m},\cdots,a_m,a_{m+2},a_{m+1}
\]

也正好符合要求。

### 5. 时间复杂度

- 找中间结点：约扫描 $\dfrac{n}{2}$ 个结点；
- 逆置后半段：约 $\dfrac{n}{2}$ 个结点；
- 交替合并：约 $\dfrac{n}{2}$ 个结点。

总时间复杂度为：

\[
O(n)
\]

算法只使用了若干临时指针变量，没有申请额外结点空间，因此空间复杂度为：

\[
O(1)
\]

---

**易错点**：

1. **快慢指针循环条件写错**  
   应写为：
   ```c
   while (fast->next != NULL && fast->next->next != NULL)
   ```
   这样可以保证 `slow` 停在前半段最后一个结点。如果写成 `fast != NULL && fast->next != NULL`，在偶数长度时可能让后半段比前半段少一个或多个结点，虽然有时结果仍正确，但容易在边界出错，不如采用标准的“两步判断”稳妥。

2. **忘记断开前后两段**  
   拆链表时必须执行：
   ```c
   slow->next = NULL;
   ```
   否则后半段仍与原链表相连，合并时会产生环或重复插入。

3. **逆置时丢失后继结点**  
   逆置时不能直接写：
   ```c
   second->next = rev;
   second = second->next;
   ```
   必须先保存 `second->next`：
   ```c
   NODE *temp = second->next;
   second->next = rev;
   rev = second;
   second = temp;
   ```

4. **合并时错误地移动前半段指针**  
   插入 `q` 之后，`p` 不能简单地写 `p = p->next`，因为此时 `p->next` 已经变成刚刚插入的 `q`。应该先保存原 `p->next`：
   ```c
   NODE *pNext = p->next;
   q->next = pNext;
   p->next = q;
   p = pNext;
   ```
   这样 `p` 才会移动到原前半段的下一个结点。

5. **忽略 $n=0$ 或 $n=1$ 的情况**  
   当链表为空或只有一个数据结点时，不需要重排，直接返回。

---

**命题规律**：

这是 408 中典型的“链表综合应用题”，核心考点是：

- 单链表遍历；
- 快慢指针找中点；
- 链表原地逆置；
- 两链表交替合并。

题目要求空间 $O(1)$，本质上就是禁止使用辅助数组或递归栈。此类题常见的变式有：

- 判断链表是否是回文结构；
- 重排链表，如 $a_1,a_n,a_2,a_{n-1},\cdots$；
- 将链表右半部分逆置后插入左半部分；
- 合并两个有序链表等。

复习建议：链表题一定要**画图模拟**，尤其分别验证 $n$ 为奇数和偶数两种情况。答题时先写设计思想，再写代码，最后明确说明时间和空间复杂度。本题代码虽然只有三步，但每一步都是高频考点，值得熟练掌握。

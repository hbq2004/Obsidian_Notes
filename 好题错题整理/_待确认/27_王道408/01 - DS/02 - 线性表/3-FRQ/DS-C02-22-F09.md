# 综合题 第 9 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-22-F09_题目.png|题目]]

9. 给定三个序列 $A$、 $B$、 $C$, 长度均为 $n$, 且均为无重复元素的递增序列, 请设计一个时间上尽可能高效的算法, 逐行输出同时存在于这三个序列中的所有元素。例如, 数组 $A$ 为 {1,2,3}, 数组 $B$ 为 {2,3,4}, 数组 $C$ 为 {-1,0,2}, 则输出 2。要求:
1) 给出算法的基本设计思想.
2) 根据设计思想, 采用 $C$ 或 $C++$ 语言描述算法, 关键之处给出注释.
3) 说明你的算法的时间复杂度和空间复杂度.

## DeepSeek V4 Flash Max 解析

**答案**：用三个指针 $i,j,k$ 分别扫描 $A,B,C$；当前三值相等就输出并同时后移，否则把当前最小者判定为不可能成为交集元素并后移所有等于该最小值的指针。时间复杂度为 $O(n)$，空间复杂度为 $O(1)$。

**解题切入点**：看到“三个长度均为 $n$ 的递增序列”和“同时存在”，应立刻定位到“有序序列求交集”问题。最自然的做法不是哈希表或二分查找，而是“多路归并式”的三指针扫描：每个序列看成一个队首最小的队列，每次只淘汰当前不可能成为答案的最小值。这也是两有序序列求交集的直接推广。

**推演**：

基本设计思想：

维护三个下标 $i,j,k$，初始均为 $0$。每一轮比较 $A[i],B[j],C[k]$：

- 若三者相等，则 $A[i]$ 是三个序列的公共元素，输出它，并让 $i,j,k$ 同时后移；
- 否则，设当前最小值为 $m$。因为三个序列都是严格递增的，任何当前队首大于 $m$ 的序列，其后续元素都大于 $m$，所以 $m$ 不可能再成为三序列公共元素，可以安全丢弃。若有多个当前队首均等于 $m$，也一起后移。

重复直到某个下标到达 $n$。

算法描述：

```c
#include <stdio.h>

void PrintCommon(int A[], int B[], int C[], int n) {
    int i = 0, j = 0, k = 0;

    while (i < n && j < n && k < n) {
        if (A[i] == B[j] && B[j] == C[k]) {
            printf("%d\n", A[i]);
            i++;
            j++;
            k++;
        } else {
            int minVal = A[i];
            if (B[j] < minVal) minVal = B[j];
            if (C[k] < minVal) minVal = C[k];

            // 当前最小值不可能再成为公共元素，将其淘汰
            if (A[i] == minVal) i++;
            if (B[j] == minVal) j++;
            if (C[k] == minVal) k++;
        }
    }
}
```

正确性分析：

- 若 $A[i]=B[j]=C[k]=x$，则 $x$ 是当前的公共元素，输出并移过它不会遗漏，因为三个序列都无重复元素；
- 若三者不全相等，设 $m=\min\{A[i],B[j],C[k]\}$。至少有一个序列的当前元素大于 $m$，而该序列严格递增，后续元素也都大于 $m$，因此 $m$ 不可能出现在该序列中，也就不可能成为三序列公共元素。所以淘汰所有等于 $m$ 的当前元素是安全的；
- 每轮至少有一个指针后移，每个指针最多移动 $n$ 次，因此算法必然终止。

复杂度分析：

每个指针最多从 $0$ 移动到 $n$，三个指针总移动次数不超过 $3n$，所以时间复杂度为 $O(n)$。额外只使用了 $i,j,k,minVal$ 等常数个变量，空间复杂度为 $O(1)$。输出元素最多 $n$ 个，不影响总复杂度。

**易错点**：

- 循环条件不能写成 `i < n || j < n || k < n`。只要有一个序列扫描完，就不可能有新的三序列公共元素，应使用 `&&`。
- 三者相等输出后，必须同时移动三个指针。只移动一个或两个会造成重复比较，甚至可能重复输出。
- 在不等分支中，如果两个当前元素同时等于最小值，要同时后移。只移动一个会增加无效比较。
- 不要用二分查找逐个元素检查，那样会得到 $O(n\log n)$ 甚至更差的复杂度；也不要优先用哈希表，虽然平均时间可以是 $O(n)$，但空间为 $O(n)$，没有充分利用序列有序这一点。
- 本题明确无重复元素，因此输出一个公共元素后可以直接让三个指针都后移，不需要处理同一序列中重复出现的情况。

**命题规律**：本题属于“有序顺序表/数组的归并型算法设计”，是 408 数据结构算法题的高频考点。常见变式包括：两有序序列求交集、求并集、三序列求第一个公共元素、求交集元素个数、合并多个有序序列等。复习时应重点掌握“多指针扫描 + 最小值淘汰”的模型，并能从“为什么不会漏掉答案”的角度说明算法正确性；同时要熟练写出带注释的 C/C++ 代码并进行复杂度分析。

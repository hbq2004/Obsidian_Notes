9. 已知两个链表$A$和$B$分别表示两个集合，其元素递增排列。编制函数，求$A$与$B$的交集，并存放于$A$链表中。

## DeepSeek V4 Flash Max 解析

**答案**：采用双指针归并比较，$A$ 中元素等于 $B$ 中当前元素则保留，$A$ 中元素小于 $B$ 中当前元素则删除该 $A$ 结点，$A$ 中元素大于 $B$ 中当前元素则跳过 $B$ 结点，最后清除 $A$ 中剩余元素，从而将交集存放到链表 $A$ 中；时间复杂度 $O(\mathrm{len}_A+\mathrm{len}_B)$，空间复杂度 $O(1)$。

**解题切入点**：看到“$A$、$B$ 递增排列”和“求交集”，立刻想到有序表的归并思想——用两个指针分别扫描两个序列，谁小移动谁，相等则保留。链表与数组不同的地方在于：要删除 $A$ 中结点，必须知道其前驱结点，因此需要额外设置一个前驱指针 `pre`。这相当于“有序数组合并”的算法迁移到链表上，并叠加链表删除操作。

**推演**：

设链表 $A$、$B$ 均带头结点。初始化：

- `pre` 指向 $A$ 的头结点，它是当前 $A$ 结点 `pa` 的前驱；
- `pa` 指向 $A$ 的第一个有效结点；
- `pb` 指向 $B$ 的第一个有效结点。

比较 `pa` 与 `pb` 的数据域，由递增性可知：

1. 若 `pa->data == pb->data`，说明该元素同时属于两个集合，是交集元素，应保留在 $A$ 中。此时将 `pre` 后移到 `pa`，然后 `pa`、`pb` 同时后移，继续比较。
2. 若 `pa->data < pb->data`，由于 $B$ 递增，$B$ 中后续元素只会比当前 `pb` 更大，所以 `pa` 不可能在 $B$ 中出现，应删除该结点。删除时 `pre` 不动，令 `pre->next` 指向 `pa->next`，释放 `pa`，再将 `pa` 指向新的后继。
3. 若 `pa->data > pb->data`，由于 $A$ 递增，$A$ 中后续元素只会比当前 `pa` 更大，所以 `pb` 不可能在 $A$ 中出现，因此只需将 `pb` 后移，`pa`、`pre` 均不动。

循环直到 `pa` 为空或 `pb` 为空。循环结束后：

- 如果 `pa` 为空，说明 $A$ 已扫描完，交集已经生成；
- 如果 `pb` 为空，说明 $B$ 已扫描完，$A$ 中剩余元素都大于 $B$ 中最大元素，不可能出现在交集中，需要删除 `pa` 及其后的所有结点。

最后 $A$ 中留下的元素正是 $A$ 与 $B$ 的交集，且仍然递增排列。

关键代码思路如下：

```c
void Intersection(LinkList &A, LinkList B) {
    // 假设 A、B 带头结点
    LNode *pre = A;          // A 中当前结点的前驱
    LNode *pa = A->next;     // 扫描 A
    LNode *pb = B->next;     // 扫描 B

    while (pa != NULL && pb != NULL) {
        if (pa->data == pb->data) {
            // 交集元素，保留 pa
            pre = pa;
            pa = pa->next;
            pb = pb->next;
        } else if (pa->data < pb->data) {
            // pa 不可能在 B 中，删除
            pre->next = pa->next;
            free(pa);
            pa = pre->next;
        } else {
            // pb 不可能在 A 中，跳过
            pb = pb->next;
        }
    }

    // B 已空，删除 A 中剩余结点
    while (pa != NULL) {
        pre->next = pa->next;
        free(pa);
        pa = pre->next;
    }
}
```

例如：$A:1,3,5,7$，$B:3,5,9$。

- `pa=1, pb=3`，$1<3$，删除 $1$；
- `pa=3, pb=3`，相等，保留 $3$，两者后移；
- `pa=5, pb=5`，相等，保留 $5$，两者后移；
- `pa=7, pb=9`，$7<9$，删除 $7$；
- `pa` 为空，结束。$A$ 中剩余 $3,5$，即交集。

**易错点**：

- 在相等分支中，必须先令 `pre = pa`，再移动 `pa`；否则 `pre` 可能仍指向已被保留结点的前驱，导致后续删除操作断链。
- 在 `pa->data < pb->data` 删除结点时，`pre` 不能移动；移动 `pa` 时应写成 `pa = pre->next`，否则容易造成指针丢失或死循环。
- 在 `pa->data > pb->data` 时，只移动 `pb`，不能删除 `pb`，也不能移动 `pa`。
- 循环结束后，若 `pb` 已空而 `pa` 非空，必须删除 $A$ 中剩余全部结点；若漏掉这一步，结果中会混入不属于交集的多余元素。
- 若不带头结点，删除首结点时需要单独更新头指针；若题目默认带头结点，则可以直接使用上述写法。考试时要注意题目给出的链表定义。

**命题规律**：本题是“有序链表归并”的典型变形，核心考点是链表遍历、前驱指针维护、结点删除和空间释放。类似的变式包括：求两个有序链表的并集、差集、对称差集，合并两个有序链表，删除有序链表中的重复元素等。408 综合题常要求编写完整函数或补全关键代码，复习时应多画图模拟指针移动，尤其重视“删除结点后指针如何更新”和“循环结束后剩余链表如何处理”这两个边界；同时注意空间复杂度要求，及时释放无用结点。

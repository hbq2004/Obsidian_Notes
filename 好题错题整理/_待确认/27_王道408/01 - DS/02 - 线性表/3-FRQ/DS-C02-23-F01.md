## DeepSeek V4 Flash Max 解析

**答案**：第1题用单趟遍历配合前驱指针删除所有值为 $X$ 的结点；第2题同样一趟遍历记录最小值结点及其前驱后删除，二者时间复杂度均为 $O(n)$，空间复杂度均为 $O(1)$。

**解题切入点**：拿到题目先抓两个关键点：一是“带头结点的单链表”，这意味删除首元结点时无需单独处理头指针，统一用前驱结点“搭桥”即可；二是“删除”操作的本质是“修改前驱的 next 指针，再释放目标结点”，所以核心任务是找到待删结点的前驱。做题时可以类比“拆项链”：想拆掉某一颗珠子，必须先握住它前面那颗珠子，否则整串链子就断了。本题是链表基础操作题，考点定位为“单链表的遍历、删除、指针修改与空间释放”。

**推演**：

链表结点结构定义如下：

```c
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;
```

### 第1题：删除所有值为 $X$ 的结点

设头指针为 $L$，头结点为 $L$ 本身指向的结点。用指针 $pre$ 指向当前结点 $p$ 的前驱，初始时：

$$
pre = L,\quad p = L \to next
$$

从第一个数据结点开始遍历。若 $p \to data == X$，则执行：

$$
pre \to next = p \to next,\quad free(p),\quad p = pre \to next
$$

这里 $pre$ 不变，因为删除后 $pre$ 仍然是下一待检查结点的前驱。若 $p \to data \neq X$，则：

$$
pre = p,\quad p = p \to next
$$

继续遍历，直到 $p == NULL$。

核心代码如下：

```c
void DeleteAllX(LinkList L, int X) {
    LNode *pre = L, *p = L->next;
    while (p != NULL) {
        if (p->data == X) {
            pre->next = p->next;
            free(p);
            p = pre->next;
        } else {
            pre = p;
            p = p->next;
        }
    }
}
```

例如，链表为 $L \to 1 \to 2 \to 3 \to 2 \to 4$，删除 $X=2$ 时：

- $p$ 指向 $1$，不删除，$pre$ 移到 $1$；
- $p$ 指向 $2$，删除，$pre$ 不动，$p$ 指向 $3$；
- $p$ 指向 $3$，不删除，$pre$ 移到 $3$；
- $p$ 指向 $2$，删除，$pre$ 不动，$p$ 指向 $4$；
- 最终得到 $L \to 1 \to 3 \to 4$。

### 第2题：删除最小值结点（唯一）

同样用一趟遍历。设置四个关键指针：

- $pre$：当前结点 $p$ 的前驱；
- $p$：当前遍历到的结点；
- $minpre$：当前最小值结点的前驱；
- $minp$：当前最小值结点。

初始时：

$$
pre = L,\quad p = L \to next,\quad minpre = pre,\quad minp = p
$$

若链表为空，即 $L \to next == NULL$，直接返回。

遍历过程中，若发现 $p \to data < minp \to data$，则更新：

$$
minp = p,\quad minpre = pre
$$

然后继续推进：

$$
pre = p,\quad p = p \to next
$$

当遍历结束时，$minp$ 指向最小值结点，$minpre$ 指向其前驱。执行删除：

$$
minpre \to next = minp \to next,\quad free(minp)
$$

核心代码如下：

```c
void DeleteMin(LinkList L) {
    if (L->next == NULL) return;

    LNode *pre = L, *p = L->next;
    LNode *minpre = pre, *minp = p;

    while (p != NULL) {
        if (p->data < minp->data) {
            minp = p;
            minpre = pre;
        }
        pre = p;
        p = p->next;
    }

    minpre->next = minp->next;
    free(minp);
}
```

例如链表为 $L \to 5 \to 2 \to 7 \to 3$：

- 初始 $minp=5, minpre=L$；
- $p=2$，$2<5$，更新 $minp=2, minpre=L$；
- $p=7$，不更新；$p=3$，不更新；
- 最后删除 $2$，得到 $L \to 5 \to 7 \to 3$。

该算法只需要一趟扫描，时间复杂度为 $O(n)$，额外空间为 $O(1)$，符合“高效”要求。

**易错点**：

- **忘记带头结点的优势**：若没有头结点，删除第一个结点时需要特殊修改头指针；本题带头结点，必须用 $pre=L$ 初始化，不能直接让 $pre=NULL$ 然后进入循环。
- **删除后指针移动错误**：删除值为 $X$ 的结点后，$pre$ 不应移动，$p$ 应变为 $pre \to next$；若把 $pre$ 也往后移，会漏掉连续重复的 $X$ 结点。
- **释放空间后误用指针**：$free(p)$ 后不能再访问 $p \to next$，必须先用 $pre \to next$ 保存后继，否则产生悬垂指针。
- **最小值初始化不当**：若链表为空，$minp$ 为 $NULL$，直接执行 $minp \to data$ 会崩溃，所以要先判空。
- **忘记同步更新 $minpre$**：只更新 $minp$ 而不更新 $minpre$，删除时无法正确连接链表，导致断链。
- **时间复杂度退化**：不要用两趟扫描（先找最小值，再删除），虽然仍为 $O(n)$，但一趟扫描更简洁；更不能用排序或反复遍历，那样会破坏高效性。

**命题规律**：本题是“线性表”章节的经典应用题，考点集中在单链表删除操作对前驱结点的依赖、遍历框架的写法、动态内存释放。408 统考中这类题目常以“设计高效算法”出现，要求手写完整函数或补充关键代码。常见变式包括：删除所有值大于/小于某个阈值的结点、删除重复结点（有序或无序）、求链表倒数第 $k$ 个结点、就地逆置单链表、拆分链表为奇偶两条等。复习时应重点掌握“前驱指针 + 遍历指针”的双指针技巧，理解带头结点与不带头结点的区别，并养成随手分析时间/空间复杂度的习惯。

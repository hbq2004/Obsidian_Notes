# 综合题 第 3 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-22-F03_题目.png|题目]]

3. 对长度为 $n$ 的顺序表 $L$, 编写一个时间复杂度为 $O(n)$、空间复杂度为 $O(1)$ 的算法，该算法删除顺序表中所有值为 $x$ 的数据元素.

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C02-22-F03_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：用单次扫描 + 原地覆盖：令 $k$ 指向下一个保留元素的位置，凡 $L.data[i] \ne x$ 的元素就放到 $L.data[k]$ 并令 $k=k+1$；扫描结束后令 $L.length=k$。时间复杂度 $O(n)$，空间复杂度 $O(1)$。

**解题切入点**：看到“删除所有值为 $x$ 的元素”且限制 $O(n)$、$O(1)$，要立刻想到不能“每删一个 $x$ 就把后面所有元素前移”，否则最坏复杂度为 $O(n^2)$。顺序表删除的本质是覆盖：把不等于 $x$ 的元素保留下来，等于 $x$ 的元素跳过。这与有序表去重、数组原地筛选的“快慢指针”思路一致：快指针读原表，慢指针写新表。

**推演**：设顺序表数组下标为 $0 \sim n-1$。定义 $k$ 为当前已保留的非 $x$ 元素个数，也是下一个保留元素应写入的位置，初始 $k=0$。

对 $i=0,1,\ldots,n-1$ 进行单趟扫描：

- 若 $L.data[i]=x$，则该元素被删除，不保留；
- 若 $L.data[i]\ne x$，则执行
$$
L.data[k]=L.data[i],\quad k=k+1.
$$

因为 $k\le i$ 恒成立，所以写入位置 $L.data[k]$ 只可能是当前位置或已经扫描过的旧位置，不会覆盖尚未扫描的 $L.data[j]\ (j>i)$，因此可以原地完成。

循环不变式：处理完 $L.data[0..i-1]$ 后，$L.data[0..k-1]$ 中保存的是这些元素中所有不等于 $x$ 的元素，且相对顺序不变。初始 $i=0,k=0$ 时显然成立；遇到 $x$ 时跳过，不破坏不变式；遇到非 $x$ 元素时复制到下一个保留位置，不变式继续成立。

循环结束后，$L.data[0..k-1]$ 正好是原顺序表中所有不等于 $x$ 的元素。此时必须更新表长：
$$
L.length=k.
$$

关键代码为：

```c
void DeleteX(SqList &L, ElemType x) {
    int k = 0;                          // 下一个保留元素的写入位置
    for (int i = 0; i < L.length; i++) {
        if (L.data[i] != x) {
            L.data[k++] = L.data[i];    // 保留非 x 元素并向前覆盖
        }
    }
    L.length = k;                       // 删除后新的表长
}
```

若采用教材中从下标 1 开始存储的写法，等价于：

```c
for (i = 1; i <= L.length; i++)
    if (L.data[i] != x)
        L.data[++k] = L.data[i];
L.length = k;
```

复杂度分析：每个元素只被扫描一次，每次操作时间为 $O(1)$，总时间为 $O(n)$；辅助变量只有 $k$ 和循环变量 $i$ 等常数个，空间复杂度为 $O(1)$。

**易错点**：
- 忘记更新 $L.length=k$，导致值为 $x$ 的元素仍然被计入表长，逻辑上删除失败。
- 采用“找到 $x$ 后把后续元素全部前移”的方法，最坏时间复杂度为 $O(n^2)$，不满足题目要求。
- 只删除第一个 $x$，或循环内删除后下标处理不当，导致漏删、越界。
- 下标为 0 时写 `data[k++] = data[i]`，下标为 1 时写 `data[++k] = data[i]`，两者容易混淆。
- 不允许额外开一个数组保存非 $x$ 元素，否则空间复杂度会变成 $O(n)$；本题要求原地覆盖。

**命题规律**：该题是顺序表基础算法题，核心考点是“顺序表删除 + 原地优化”，也是 408 算法设计题中非常常见的模板。常见变式有：删除值在 $[s,t]$ 区间内的所有元素、有序顺序表去重、按条件划分元素、把指定值 $x$ 移到表尾等。复习时应熟练掌握“快慢指针/单次覆盖”思想，并能用循环不变式说明正确性；考场中注意边界情况：不删、全删、连续重复元素、删除位置在开头或结尾。

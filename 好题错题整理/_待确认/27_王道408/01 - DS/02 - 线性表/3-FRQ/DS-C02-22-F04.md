# 综合题 第 4 题

4. 从顺序表中删除其值在给定值$s$和$t$之间（包含$s$和$t$，要求$s < t$）的所有元素，若$s$或$t$不合理或顺序表为空，则显示出错信息并退出运行.

## DeepSeek V4 Flash Max 解析

**答案**：采用“扫描—覆盖”法（双指针）原地删除：只保留所有不在 $[s,t]$ 内的元素，最后将表长改为保留元素的个数。若表空或 $s\ge t$，则显示出错信息并退出。时间复杂度 $O(n)$，空间复杂度 $O(1)$。

**解题切入点**：  
拿到题先定位存储结构：顺序表。顺序表删除的本质是“后面元素向前覆盖”。因此不能每遇到一个待删元素就把后面所有元素整体前移一次，否则最坏会达到 $O(n^2)$。  
可以类比整理抽屉：不是每看见一个不要的东西就把抽屉里的东西全部往前挪一格，而是准备一个“新位置指针”，把要保留的东西依次放到前面，最后只更新抽屉“有效长度”。这正是数组/顺序表题目中常用的“快慢指针”技巧：快指针 $j$ 扫描原表，慢指针 $i$ 记录新表写入位置。  
还要注意题面要求：删除值在 $[s,t]$ 之间的元素，包含 $s$ 和 $t$，且要求 $s<t$。所以“保留”的条件是 $x<s$ 或 $x>t$；若 $s\ge t$ 或表空，应先报错。

**推演**：  
设顺序表为 $L$，元素为 $L.data[0],L.data[1],\dots,L.data[L.length-1]$。

算法步骤：

1. 若 $L.length=0$，输出“顺序表为空”，退出；
2. 若 $s\ge t$，输出“$s$ 或 $t$ 不合理”，退出；
3. 令 $i=0$，$i$ 表示新表下一个写入位置；
4. 用 $j$ 从 $0$ 到 $L.length-1$ 扫描原表：
   - 若 $L.data[j]<s$ 或 $L.data[j]>t$，说明该元素应保留，执行：
     $$
     L.data[i]=L.data[j],\quad i++
     $$
   - 否则说明 $s\le L.data[j]\le t$，跳过，不复制；
5. 扫描结束后令 $L.length=i$，此时前 $i$ 个元素就是删除后剩下的所有元素。

关键代码如下：

```c
void DelRange(SqList *L, ElemType s, ElemType t) {
    if (L->length == 0) {
        printf("顺序表为空！\n");
        exit(1);
    }
    if (s >= t) {
        printf("s或t不合理！\n");
        exit(1);
    }

    int i = 0;
    for (int j = 0; j < L->length; j++) {
        // 保留不在 [s, t] 区间内的元素
        if (L->data[j] < s || L->data[j] > t) {
            L->data[i] = L->data[j];
            i++;
        }
    }
    L->length = i;
}
```

正确性证明：  
扫描过程中始终保持不变式：

$$
L.data[0..i-1]
$$

中保存的是已经扫描过的元素中所有不在 $[s,t]$ 内的元素，并且它们的相对顺序与原顺序表一致。  
当 $j$ 扫描完所有元素后，所有不在 $[s,t]$ 内的元素都被保留到前 $i$ 个位置，所有在 $[s,t]$ 内的元素都被跳过。因此令 $L.length=i$ 后，顺序表中正好只剩值不在 $[s,t]$ 内的元素。

边界情况：

- 若所有元素都在 $[s,t]$ 内，则 $i=0$，删除后为空表；
- 若没有元素在 $[s,t]$ 内，则 $i=L.length$，顺序表不变；
- 若表空或 $s\ge t$，则提前报错退出。

复杂度：只需一趟扫描，每个元素访问常数次，时间复杂度为 $O(n)$；只使用 $i,j$ 等常数个变量，空间复杂度为 $O(1)$。

**易错点**：  
1. 判断条件写反。题目要求删除 $s\le x\le t$ 的元素，因此保留条件应写成 `L.data[j] < s || L.data[j] > t`，不要把条件写成“大于等于 `s` 且小于等于 `t` 时保留”。  
2. 忘记更新表长。删除后 `L.length` 必须改为 $i$，否则后面旧数据仍会被当作有效元素。  
3. 误用“每删除一个就移动后面所有元素”。这样虽然结果可能正确，但时间复杂度会变成 $O(n^2)$，不符合高效算法要求。  
4. 忽略空表或 $s\ge t$ 的错误判断。题目明确要求这些情况要显示出错并退出，不能继续扫描。  
5. 注意 $s=t$ 也不合法，因为题面要求 $s<t$，所以错误条件要写成 `s >= t`，不能只写 `s > t`。

**命题规律**：  
本题是“顺序表基本操作与高效算法设计”的典型代表。408 综合应用题常以顺序表为载体，考查“删除满足条件的元素”“去重”“逆置”“按规则重排”等操作。其核心都是利用顺序表随机存取和连续存储的特点，用一趟扫描加覆盖写完成原地修改。  
常见变式有：删除所有值为 $x$ 的元素；删除值在 $(s,t)$ 之间的元素；删除有序顺序表中的重复元素；将奇数移到偶数前面等。  
复习建议：把“快慢指针/覆盖写”作为顺序表原地处理的通用模板，并养成三个习惯：先判空、再判参数合法性、最后记得更新表长。考试时除了写清代码，还要写出时间、空间复杂度分析。

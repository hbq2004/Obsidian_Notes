# 综合题 第 14 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-22-F14_题目.png|题目]]

14.【2020 统考真题】定义三元组 $(a,b,c)(a,b,c$ 均为整数) 的距离 $D=|a-b|+|b-c|+|c-a|$。给定 3 个非空整数集合 $S_1$、$S_2$ 和 $S_3$，按升序分别存储在 3 个数组中。请设计一个尽可能高效的算法，计算并输出所有可能的三元组 $(a,b,c)(a \in S_1,b \in S_2,c \in S_3)$ 中的最小距离。例如 $S_1=\{-1,0,9\},S_2=\{-25,-10,10,11\},S_3=\{2,9,17,30,41\}$，则最小距离为 $2$，相应的三元组为 $(9,10,9)$。要求：
1) 给出算法的基本设计思想。
2) 根据设计思想，采用 $C$ 语言或 $C++$ 语言描述算法，关键之处给出注释。
3) 说明你所设计算法的时间复杂度和空间复杂度.

## DeepSeek V4 Flash Max 解析

**答案**：最小距离可化为 $2(\max-\min)$；采用三指针贪心，每次把当前三元组中的最小值所在数组的指针后移，即可在 $O(n_1+n_2+n_3)$ 时间、$O(1)$ 空间内求出最小距离。

**解题切入点**：看到三个绝对值相加，先不要枚举 $a,b,c$ 的 6 种大小关系。任意三个数的距离只取决于其中的最大值和最小值。这等价于“从三个有序数组中各取一个数，使最大值与最小值的差最小”，也就是经典的“三个有序序列找最小覆盖区间”问题。做法类似归并排序：当前三个数中，谁最小就移动谁，因为只有提高最小值才可能缩小区间。

**推演**：

设任意三元组 $(a,b,c)$ 中，三个数从小到大为 $u\le v\le w$，则

$$
D=|a-b|+|b-c|+|c-a|
=(v-u)+(w-v)+(w-u)
=2(w-u).
$$

因此

$$
D=2\big(\max(a,b,c)-\min(a,b,c)\big).
$$

所以原问题等价于：

$$
\min D
=
2\min_{a,b,c}\big(\max(a,b,c)-\min(a,b,c)\big).
$$

算法思想：用三个指针 $i,j,k$ 分别指向三个升序数组的当前元素。每轮计算当前三元组的最小值和最大值，更新最小距离；然后将指向当前最小值的指针向后移动一位，直到某个数组被遍历完。

正确性说明：设当前三元组为

$$
(A[i],B[j],C[k]),
$$

记

$$
m=\min(A[i],B[j],C[k]),\quad M=\max(A[i],B[j],C[k]).
$$

当前距离为 $2(M-m)$。若 $A[i]=m$，则对任意 $p\ge j,\ q\ge k$，有三元组 $(A[i],B[p],C[q])$ 的最小值仍为 $A[i]$，最大值至少为 $M$，所以它的距离至少为 $2(M-m)$。也就是说，所有仍包含当前 $A[i]$ 的三元组都不可能比当前三元组更优，可以安全地令 $i++$。$B[j]$ 或 $C[k]$ 为最小值时同理。因此每步丢弃的候选都不可能改进答案，最终得到全局最小距离。

算法步骤：

1. 令 $i=j=k=0$，$ans=+\infty$。
2. 当 $i<n_1,\ j<n_2,\ k<n_3$ 时：
   - 计算 $a=S_1[i],\ b=S_2[j],\ c=S_3[k]$；
   - 计算 $m=\min(a,b,c)$，$M=\max(a,b,c)$；
   - 更新 $ans=\min(ans,2(M-m))$；
   - 若 $ans=0$，直接结束；
   - 若 $a$ 最小则 $i++$，否则若 $b$ 最小则 $j++$，否则 $k++$。
3. 返回 $ans$。

C/C++ 代码描述：

```c
#include <limits.h>

int minDistance(int S1[], int n1, int S2[], int n2, int S3[], int n3) {
    int i = 0, j = 0, k = 0;
    int ans = INT_MAX;

    while (i < n1 && j < n2 && k < n3) {
        int a = S1[i], b = S2[j], c = S3[k];

        // 求当前三个数的最小值
        int mn = a;
        if (b < mn) mn = b;
        if (c < mn) mn = c;

        // 求当前三个数的最大值
        int mx = a;
        if (b > mx) mx = b;
        if (c > mx) mx = c;

        int d = 2 * (mx - mn);
        if (d < ans) ans = d;

        if (ans == 0) break;  // 距离不可能小于 0

        // 移动当前最小值所在数组的指针，尝试缩小跨度
        if (mn == a) i++;
        else if (mn == b) j++;
        else k++;
    }

    return ans;
}
```

若题目还要求输出对应的三元组，只需在 `if (d < ans)` 更新答案时用 `bestA=a; bestB=b; bestC=c;` 记录即可。

时间复杂度：每次循环只移动一个指针，三个指针最多移动 $n_1,n_2,n_3$ 次，所以总时间复杂度为

$$
O(n_1+n_2+n_3).
$$

空间复杂度：只用了常数个变量，所以为 $O(1)$。

例如题给数据中，算法会找到三元组 $(9,10,9)$，此时

$$
D=|9-10|+|10-9|+|9-9|=2.
$$

**易错点**：

- 不要直接三重循环枚举所有三元组，那样是 $O(n_1n_2n_3)$，不符合“尽可能高效”的要求。
- 计算距离时不要忘记乘 2；只输出跨度 $M-m$ 会少一倍。
- 指针只能移动“当前最小值”所在的指针。移动最大值或中间值无法缩小跨度，甚至会使跨度变大。
- 若最小值同时出现在两个甚至三个数组中，任选一个最小值指针移动即可；用 `if-else` 顺序判断不会出错。
- 每轮要先更新答案，再移动指针；否则可能漏掉当前合法三元组。
- 循环停止条件是“任一数组遍历完”，而不是三个数组都遍历完。

**命题规律**：本题属于 408 中典型的“有序表 + 双指针/三指针 + 数学化简”综合题。核心考点是把绝对值距离转化为最大值与最小值之差，再利用有序性贪心移动指针。常见变式有：两个有序数组求最小差、三个无序数组求最小距离（先排序再套用本算法）、$k$ 个有序序列求最小覆盖区间、或要求输出对应三元组。复习时应重点掌握“为什么移动最小指针”的贪心证明，并熟练写出线性的双指针/多指针代码。

5. 从有序顺序表中删除所有其值重复的元素,使表中所有元素的值均不同.

## DeepSeek V4 Flash Max 解析

**答案**：按“每个重复值保留一个副本”理解，利用有序顺序表重复值必相邻的性质，用双指针一趟完成去重：慢指针 $i$ 指向去重后最后一个元素，快指针 $j$ 扫描原表，遇到与 $L.data[i]$ 不同的值就放到 $i+1$ 位置，最后更新表长 $L.length=i+1$；时间复杂度 $O(n)$，空间复杂度 $O(1)$。

**解题切入点**：拿到题目先抓两个关键词：“有序”和“顺序表”。有序意味着相等元素一定连续，因此去重不需要哈希表或集合；顺序表是连续存储结构，删除元素通常用覆盖前移完成。这正好对应“快慢指针”的套路：快指针负责扫描，慢指针维护去重后结果表的末尾。如果每遇到一个重复元素就把后面所有元素整体前移，复杂度会退化到 $O(n^2)$，不是 408 算法题期望的解法。

**推演**：

设顺序表为 $A[0..n-1]$，且非递减有序，即 $A[0]\le A[1]\le\cdots\le A[n-1]$。目标是从中取出每个不同值的第一个副本，使结果仍然有序且值互异。

核心代码如下：

```c
void Delete_Same(SqList &L) {
    if (L.length == 0) return;   // 空表直接返回
    int i = 0;                   // i 指向去重后最后一个元素
    for (int j = 1; j < L.length; j++) {
        if (L.data[j] != L.data[i]) {
            L.data[++i] = L.data[j]; // 发现新值，保留到结果末尾
        }
        // 相等则跳过，相当于删除重复副本
    }
    L.length = i + 1;            // 逻辑删除后面的多余元素
}
```

正确性可由循环不变式说明：

- 初始化：$i=0$，处理范围 $A[0..0]$ 已经是去重后的结果。
- 保持：假设扫描到 $j$ 之前，$A[0..i]$ 已经是 $A[0..j-1]$ 去重后的结果。因为 $A$ 有序，所以 $A[j]\ge A[i]$。若 $A[j]=A[i]$，则 $A[j]$ 与最后一个保留值重复，跳过；若 $A[j]\ne A[i]$，则必有 $A[j]>A[i]$，它不可能与前面任何一个已保留值重复，所以执行 `A[++i]=A[j]` 将其加入结果末尾。
- 终止：$j$ 扫描完整个表后，$A[0..i]$ 就是原表去重后的结果，令表长等于 $i+1$ 即可。

例如：

$$
A=(1,2,2,2,3,3,5)
$$

处理过程为：保留 $1$；$j=1$ 时发现 $2\neq 1$，保留 $2$；$j=2,3$ 时 $A[j]=2$ 与最后保留值相等，跳过；$j=4$ 时发现 $3\neq 2$，保留 $3$；$j=5$ 时 $3$ 重复，跳过；$j=6$ 时发现 $5\neq 3$，保留 $5$。最终：

$$
A=(1,2,3,5),\quad L.length=4
$$

覆盖写是安全的：写入位置 $i+1\le j$，只会覆盖已经扫描过的位置，不会破坏未扫描的数据。时间复杂度为 $O(n)$，空间复杂度为 $O(1)$。

**易错点**：

1. 不判空表：若 $L.length=0$，没有保护直接执行 `L.length=i+1` 会把空表长度错误地变成 $1$，应该先判断空表。
2. 忘记更新表长：只覆盖前部数据但不更新 `L.length`，重复元素在逻辑上仍然存在，不算真正删除。
3. 使用“整体前移”删除：每遇到一个重复元素就把后面元素全部前移，虽然可行，但最坏时间复杂度达到 $O(n^2)$，不符合考研算法题对效率的要求。
4. 题意理解偏差：本题按常规“每个值保留一个副本”处理。若题目明确要求“重复值的所有元素全部删除”，则需先统计频次，只保留出现一次的值，那是另一种算法。

**命题规律**：考点定位在顺序表基本操作、有序表性质、双指针/覆盖法。常考变式包括：无序顺序表去重（可先排序再双指针，或借助哈希表）、删除有序顺序表中所有值为 $x$ 的元素、删除有序顺序表中值在区间 $[s,t]$ 内的元素、有序链表去重、合并两个有序顺序表等。复习时应重点掌握“一次扫描 + 原地覆盖”的线性表算法模板，同时注意边界条件与复杂度分析，这是 408 算法设计题的主要得分点。

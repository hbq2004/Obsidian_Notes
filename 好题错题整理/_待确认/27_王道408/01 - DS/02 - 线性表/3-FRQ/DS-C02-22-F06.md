## DeepSeek V4 Flash Max 解析

**答案**：
采用双指针二路归并：同时扫描两个有序表 $A,B$，每次将当前较小元素放入结果表 $C$ 末尾；其中一个表扫描完后，把另一表剩余元素全部复制到 $C$，最后返回 $C$。若 $A,B$ 长度分别为 $m,n$，时间复杂度为 $O(m+n)$；不计结果表时辅助空间为 $O(1)$，若把新建结果表计入则为 $O(m+n)$。

**解题切入点**：
看到“两个有序表合并”，应立刻想到归并排序中的 $\text{Merge}$ 操作。因为两个表都有序，所以全局最小值一定只可能出现在两个表的表头，不需要对整张表重新排序。这类似于将两堆已排好序的牌合并成一堆，每次从两堆顶部取较小的一张；也等价于合并两条有序链表，只不过顺序表用下标移动代替链表指针移动。

**推演**：
设 $A[0..m-1]$、$B[0..n-1]$ 均为非递减有序表，结果表为 $C[0..m+n-1]$。用 $i,j,k$ 分别指向 $A,B,C$ 的当前处理位置。

在任意时刻，剩余元素为 $A[i..m-1]$ 和 $B[j..n-1]$。由于两个子表分别有序，剩余元素中的最小值只可能是 $A[i]$ 或 $B[j]$，即：

$$
\min\big(A[i..m-1]\cup B[j..n-1]\big)=\min(A[i],B[j])
$$

若 $A[i]\le B[j]$，则 $A[i]$ 不大于 $A[i+1..m-1]$，也不大于 $B[j..n-1]$，因此 $A[i]$ 是当前全局最小元素，将其放入 $C[k]$ 不会破坏 $C$ 的有序性；反之若 $B[j]<A[i]$，则放入 $B[j]$。每轮操作后，被选中的元素从原表中删除（下标后移），循环不变量保持。

当某个表先被扫描完时，另一个表剩余的所有元素都不小于 $C$ 中最后一个元素，并且该剩余段本身有序，所以直接依次复制到 $C$ 末尾即可。

关键代码思路如下：

```c
typedef struct {
    ElemType *data;   // 动态数组，实际可换为固定数组
    int length;
} SqList;

SqList Merge(SqList A, SqList B) {
    int m = A.length, n = B.length;
    SqList C;
    C.data = (ElemType *)malloc((m + n) * sizeof(ElemType));

    int i = 0, j = 0, k = 0;

    while (i < m && j < n) {
        if (A.data[i] <= B.data[j])
            C.data[k++] = A.data[i++];
        else
            C.data[k++] = B.data[j++];
    }

    while (i < m)
        C.data[k++] = A.data[i++];

    while (j < n)
        C.data[k++] = B.data[j++];

    C.length = k;
    return C;
}
```

若采用固定数组 `data[MaxSize]`，则需先判断 `m + n <= MaxSize`，否则结果表容量不够。核心循环完全一样。

每个元素只被复制一次，所以复制次数为 $m+n$；比较次数最多为 $m+n-1$，因此时间复杂度为 $O(m+n)$。辅助变量只有 $i,j,k$ 等常数个，所以不计结果表时额外空间为 $O(1)$；若把新建结果表空间也算入，则为 $O(m+n)$。

**易错点**：
- 只写一个 `while` 合并循环，忘记处理某个表剩余的元素。两个收尾 `while` 不能省略，否则结果表会缺少元素。
- 循环边界写错。应使用 `i < m`、`j < n`，不是 `i <= m`、`j <= n`，否则数组越界。
- 使用静态顺序表时不检查容量，导致 `C.data` 越界写入。应先判断 `m + n` 是否超过 `MaxSize`。
- 相等元素的处理。若希望稳定归并，可用 `<=`，相等时先取 $A$ 中元素；若只要求非递减，等号放哪边都可以，但不能造成死循环或漏元素。
- 忘记给结果表赋值 `C.length = k`，导致返回的“顺序表”长度错误。
- 空间复杂度表述不严谨。若题目问“额外空间”，可答 $O(1)$；若问结果表占用的总空间，则应答 $O(m+n)$。

**命题规律**：
本题是线性表部分“有序表归并”的经典模板题，与归并排序的 $\text{Merge}$ 同源。408 中常以选择题考查边界条件、比较次数、空间复杂度，也可能以综合题要求手写合并函数。常见变式有：合并两个有序链表、求两个有序表的交集/并集、归并排序中的有序子表合并、在多个有序表中进行多路归并。复习时应把“双指针归并”作为基础模板熟练掌握，并注意顺序表与链表两种实现下的代码区别。

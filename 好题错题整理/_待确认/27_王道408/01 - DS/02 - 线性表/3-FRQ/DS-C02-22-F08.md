# 综合题 第 8 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-22-F08_题目.png|题目]]

8. 线性表 $(a_1,a_2,a_3,\cdots,a_n)$ 中的元素递增有序且按顺序存储于计算机内. 要求设计一个算法,完成用最少时间在表中查找数值为 $x$ 的元素, 若找到, 则将其与后继元素位置相交换, 若找不到, 则将其插入表中并使表中元素仍然递增有序.

## DeepSeek V4 Flash Max 解析

**答案**：采用折半查找定位 $x$；若命中且 $x$ 不是表尾元素，则与后继元素交换；若未命中，则以折半查找结束后的 $\mathrm{low}$ 为插入位置，从表尾向 $\mathrm{low}$ 移动元素后插入 $x$，保持递增有序。查找阶段为 $O(\log n)$；若需插入，整体最坏为 $O(n)$；空间复杂度为 $O(1)$。

**解题切入点**：  
看到“递增有序”＋“顺序存储”＋“最少时间查找”，应立刻想到折半查找。顺序存储保证可以随机访问中间元素，有序保证可以每次排除一半区间。类比查字典：先翻中间页，而不是从第一页开始逐页找。

**推演**：  
下面按 0 基下标书写，即元素存放在 `L.data[0..L.length-1]` 中，题目中的 $a_1$ 对应 `L.data[0]`。

### 1. 折半查找定位

设：

$$
\mathrm{low}=0,\quad \mathrm{high}=L.length-1
$$

每次取中间位置：

$$
\mathrm{mid}=\left\lfloor \frac{\mathrm{low}+\mathrm{high}}{2}\right\rfloor
$$

若 `L.data[mid] == x`，查找成功；  
若 `L.data[mid] < x`，说明 $x$ 只可能在右半部分，令 `low = mid + 1`；  
若 `L.data[mid] > x`，说明 $x$ 只可能在左半部分，令 `high = mid - 1`。

循环条件为 `low <= high`。

### 2. 查找成功后的处理

若查找成功，且 `mid < L.length - 1`，说明 $x$ 不是最后一个元素，存在后继，则直接交换：

```cpp
tmp = L.data[mid];
L.data[mid] = L.data[mid + 1];
L.data[mid + 1] = tmp;
```

若 $x$ 是表尾元素，则没有后继，不进行交换。

交换后仍然递增有序。因为原表严格递增，设 $x=a_{\mathrm{mid}}$，则：

$$
a_{\mathrm{mid}-1}<x<a_{\mathrm{mid}+1}
$$

交换后，位置 $\mathrm{mid}$ 变成 $a_{\mathrm{mid}+1}$，其左邻仍小于它；位置 $\mathrm{mid}+1$ 变成 $x$，其右邻 $a_{\mathrm{mid}+2}$ 仍大于 $x$。

### 3. 查找失败后的插入

若折半查找结束时有 `low > high`，说明表中不存在 $x$。此时 `low` 正好是 $x$ 应插入的位置。

原因：折半查找过程中始终有：

- 下标小于 `low` 的元素都小于 $x$；
- 下标大于 `high` 的元素都大于 $x$。

结束时 `low = high + 1`，所以：

$$
0..\mathrm{low}-1 \text{ 中的元素都小于 } x,\quad
\mathrm{low}..n-1 \text{ 中的元素都大于 } x
$$

因此将 $x$ 插入到 `low` 位置即可保持递增有序。

插入时需要从后向前移动元素：

```cpp
for (int j = L.length - 1; j >= low; --j)
    L.data[j + 1] = L.data[j];
L.data[low] = x;
L.length++;
```

### 4. 完整算法伪代码

```cpp
void SearchExchangeInsert(SqList &L, ElemType x) {
    int low = 0, high = L.length - 1, mid;

    while (low <= high) {
        mid = low + (high - low) / 2;
        if (L.data[mid] == x) break;
        else if (L.data[mid] < x) low = mid + 1;
        else high = mid - 1;
    }

    if (low <= high) {               // 查找成功
        if (mid < L.length - 1) {    // 有后继才交换
            ElemType tmp = L.data[mid];
            L.data[mid] = L.data[mid + 1];
            L.data[mid + 1] = tmp;
        }
        return;
    }

    // 查找失败，low 是插入位置
    for (int j = L.length - 1; j >= low; --j)
        L.data[j + 1] = L.data[j];

    L.data[low] = x;
    L.length++;
}
```

### 5. 复杂度分析

设表长为 $n$。

- 折半查找的比较次数为 $O(\log n)$；
- 查找成功时，交换操作为 $O(1)$；
- 查找失败时，插入需要移动元素，最坏移动 $n$ 次，因此整体最坏为 $O(n)$；
- 辅助空间为 $O(1)$。

$$
T(n)=
\begin{cases}
O(\log n), & x \text{ 命中}\\
O(\log n)+O(n)=O(n), & x \text{ 未命中}
\end{cases}
$$

**易错点**：  
1. 未命中时插入位置写错。折半查找结束后应插入到 `low`，不是 `mid`，更不是覆盖 `high` 位置。  
2. 移动元素方向错误。插入时只能从后往前移动，若从前往后会覆盖后面未移动的元素。  
3. 忘记判断表尾。若 `mid == L.length - 1`，则 `L.data[mid + 1]` 越界，必须先判断是否存在后继。  
4. 二分循环条件写错。应使用 `low <= high`，若写成 `low < high`，可能漏判 `low == high` 时的相等元素。  
5. 插入后忘记 `L.length++`，导致表长错误。  
6. 若将“递增”理解为“非递减”，查找任意一个 $x$ 后直接交换可能破坏有序性；但本题通常按严格递增处理，不存在该问题。

**命题规律**：  
本题是“顺序表 + 折半查找”的典型综合题，408 中常以算法设计题出现。核心考查两个能力：一是对有序顺序表使用折半查找定位；二是顺序表插入时的元素移动。常见变式包括：在有序顺序表中查找并插入、查找并删除、查找 $x$ 的个数、用折半查找实现 `lower_bound` 等。复习时应重点掌握二分查找的循环不变式，以及顺序表插入移动的边界处理，并注意 0 基下标和 1 基下标书写时的自洽性。

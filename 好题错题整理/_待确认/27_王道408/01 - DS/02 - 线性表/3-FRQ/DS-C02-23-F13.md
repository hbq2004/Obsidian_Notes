# 综合题 第 13 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-23-F13_题目.png|题目]]

13. 设有一个带头结点的非循环双链表 $L$, 其每个结点中除有 $pre$、 $data$ 和 $next$ 域外,还有一个访问频度域 $freq$, 其值均初始化为零. 每当在链表中进行一次 $Locate(L, x)$ 运算时, 令值为 $x$ 的结点中 $freq$ 域的值增 1, 并使此链表中的结点保持按访问频度递减的顺序排列,且最近访问的结点排在频度相同的结点之前,以便使频繁访问的结点总是靠近表头. 试编写符合上述要求的 $Locate(L, x)$ 函数,返回找到结点的地址,类型为指针型.

## DeepSeek V4 Flash Max 解析

**答案**：先查找值为 $x$ 的结点 $p$，令 $p\to freq$ 增 1，然后从 $p$ 的前驱开始向前找插入位置，直到前驱是头结点或前驱频度严格大于 $p$ 的频度为止，把 $p$ 摘下并插入到该位置之后；单次 `Locate` 最坏时间复杂度 $O(n)$，空间复杂度 $O(1)$。

**解题切入点**：拿到题先识别考点：带头结点双链表 + 按访问频度维护有序性。可以把它看成“维护有序序列的插入”：主关键字是 `freq`，次关键字是访问时间；由于刚访问的结点全局最新，所以同频结点也应排在它之后。于是移动条件不是 `pre->freq < p->freq`，而是 `pre->freq <= p->freq$。这就像打牌时把一张牌从当前位置往前插到合适位置。

**推演**：

设链表当前已满足：
$$
u \text{ 在 } v \text{ 前} \iff u\to freq > v\to freq
\quad\text{或}\quad
(u\to freq = v\to freq \text{ 且 } u \text{ 比 } v \text{ 后访问})
$$

访问结点 $p$ 后，$p\to freq$ 增加 1。由于 $p$ 刚被访问，它对同频结点而言最新，因此凡是前驱频度 $\le p\to freq$ 的结点，$p$ 都应放到它们之前；只有前驱频度 $> p\to freq$ 时才停止。

所以插入位置为：从 $p\to pre$ 开始向前扫描，直到
$$
q = L \quad\text{或}\quad q\to freq > p\to freq
$$
停止，然后把 $p$ 插入到 $q$ 之后。

关键代码实现如下：

```c
typedef int ElemType;

typedef struct DNode {
    ElemType data;
    int freq;
    struct DNode *pre, *next;
} DNode;

DNode* Locate(DNode *L, ElemType x) {
    DNode *p = L->next;

    // 1. 查找值为 x 的结点
    while (p != NULL && p->data != x)
        p = p->next;
    if (p == NULL)
        return NULL;            // 找不到

    // 2. 访问频度加 1
    p->freq++;

    // 3. 从 p 的前驱开始向前找插入位置
    DNode *q = p->pre;
    while (q != L && q->freq <= p->freq)
        q = q->pre;

    // 4. 若需要移动，则摘除 p 并插入到 q 之后
    if (q != p->pre) {
        // 摘下 p
        p->pre->next = p->next;
        if (p->next != NULL)
            p->next->pre = p->pre;

        // 将 p 插入到 q 之后
        p->pre = q;
        p->next = q->next;
        if (q->next != NULL)
            q->next->pre = p;
        q->next = p;
    }

    return p;
}
```

正确性要点：`while` 停止时，$q$ 之前所有结点的频度都大于 $p$ 的新频度；$q$ 之后到 $p$ 原位置之间的结点频度都不超过 $p$ 的新频度。把 $p$ 移到这段之前，既保持频度递减，又保证同频结点中 $p$ 最新。其余结点相对次序不变，因此整个链表仍然有序。

**易错点**：

- 移动条件写成 `q->freq < p->freq` 是常见错误。这样会漏掉“同频结点中最近访问的在前”，必须写成 `<=`。
- 摘除或插入结点时忘记判断 `p->next` 或 `q->next` 是否为空，会导致空指针访问；非循环双链表最后一个结点的 `next` 是 `NULL`。
- 把头结点当作普通结点比较 `L->freq`。头结点不参与排序，停止条件应为 `q != L`。
- 找到结点后先返回或先移动再 `freq++` 都会使排序依据不正确；必须先 `p->freq++`，再调整位置。
- 如果题目保证 $x$ 存在，可以不写 `return NULL`；但写上更严谨，不影响正确性。

**命题规律**：本题是“双链表插入删除 + 有序表维护”的综合题，属于 408 高频考点。常见变式包括：单链表版本、循环双链表版本、不带头结点版本、只按频度排序不要求同频最新优先等。复习时应先画图模拟指针变化，再重点检查边界条件：头结点、空指针、同频比较。理解“主关键字 + 次关键字”的排序思想后，这类题可以统一处理。

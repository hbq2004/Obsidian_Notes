20. 某二叉树采用二叉链表存储结构，若要删除该二叉链表中的所有结点，并释放它们占用的存储空间，则采用（ ）遍历方法最合适.
(A) 中序
(B) 层次
(C) 后序
(D) 先序

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C05-53-M20_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：采用后序遍历最合适（C）。

**解题切入点**：删除二叉树结点时，核心矛盾是“先释放根结点会导致左右孩子指针丢失”。因此要确定一种遍历顺序，使得在释放任何一个结点时，它的左右子树都已经被释放完毕。后序遍历正好满足“先左、后右、再根”的递归次序，天然适合释放二叉树所有结点。这就像拆一座树形结构的积木，必须先把所有“枝杈”拆完，最后才能拆“主干”。

**推演**：二叉链表存储结构中，每个结点包含数据域和指向左右孩子的指针。若释放所有结点，必须对每个结点执行 `free`。设某结点为 $p$，其左右孩子指针为 $p\to lchild$ 和 $p\to rchild$。

- 先序遍历顺序：根、左、右。若先释放 $p$，则 $p\to lchild$ 和 $p\to rchild$ 所在内存已被释放，无法再通过 $p$ 访问左右子树，导致后续无法删除。
- 中序遍历顺序：左、根、右。若在访问完左子树后释放 $p$，则右子树指针 $p\to rchild$ 仍保存在 $p$ 中，但 $p$ 已被释放，仍然丢失右子树访问入口。
- 层次遍历顺序：从上到下逐层释放。释放父结点后，其孩子结点地址未保存，同样无法继续访问下一层；若提前用队列保存所有孩子指针，则需要额外存储空间，且并非最高效、最自然的方法。
- 后序遍历顺序：左、右、根。先递归释放左子树，再递归释放右子树，最后释放根结点。这样释放根结点时，左右子树内存均已释放，不会丢失任何尚未释放的结点。

因此，删除整个二叉树并释放空间的最合适遍历方法是后序遍历。对应代码思路如下：

```cpp
void deleteTree(BiTree &T) {
    if (T != NULL) {
        deleteTree(T->lchild);   // 释放左子树
        deleteTree(T->rchild);   // 释放右子树
        free(T);                 // 释放根结点
        T = NULL;
    }
}
```

**易错点**：

- 误选先序：认为“先释放根也可以”，但释放根后左右孩子指针丢失，无法继续遍历，这是最常见的错误。
- 误选中序：只注意到左子树已释放，却忽略释放根结点后右子树指针也会丢失。
- 误选层次：层次遍历需要借助队列保存孩子指针才能实现释放，但题目要求“最合适”，后序无需额外空间且递归实现简洁，是标准解法。
- 注意 `free` 后应将指针置空，否则可能产生“野指针”问题；在算法题中建议将根指针设为 `NULL`。

**命题规律**：本题属于“二叉树遍历的应用”考点，常以选择题或算法设计题出现。核心在于理解遍历顺序与递归过程的内存访问关系。常见变式包括：求二叉树深度、统计结点数、销毁二叉树、表达式树求值等，这些都需要后序遍历“先子树、后根”的性质。复习时应熟练掌握二叉树三种遍历的递归模板，并能将具体操作与遍历顺序对应起来。

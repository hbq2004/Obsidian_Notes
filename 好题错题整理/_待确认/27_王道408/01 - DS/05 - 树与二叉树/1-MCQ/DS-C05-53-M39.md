39.【2017统考真题】某二叉树的树形如右图所示，其后序序列为e,a,c,b,d，g,f，树中与结点$a$同层的结点是( ).

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C05-53-M39_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 **B（$d$）**。结点 $a$ 与结点 $d$ 同层。

**解题切入点**：  
拿到“后序序列 + 树形”的题，先抓后序遍历的递归性质：**最后一个结点一定是根**。再利用题给树形（7 个结点的满二叉树）把后序序列按“左子树、右子树、根”分成三段，像剥洋葱一样逐层确定每个结点的位置。

**推演**：  
题给后序序列为：

$$e,a,c,b,d,g,f$$

后序遍历顺序是“左子树、右子树、根”，所以最后一个结点 $f$ 是整棵树的根。

题图是 7 个结点的满二叉树，根 $f$ 的左、右子树各有 3 个结点。因此后序序列可分成：

$$
\underbrace{e,a,c}_{\text{左子树后序}}\quad
\underbrace{b,d,g}_{\text{右子树后序}}\quad
\underbrace{f}_{\text{根}}
$$

左子树后序为 $e,a,c$，因此左子树根为 $c$，且：

- $c$ 的左孩子是 $e$；
- $c$ 的右孩子是 $a$。

右子树后序为 $b,d,g$，因此右子树根为 $g$，且：

- $g$ 的左孩子是 $b$；
- $g$ 的右孩子是 $d$。

画出对应的二叉树：

```
        f
       / \
      c   g
     / \ / \
    e  a b  d
```

若根为第 1 层，则：

- 第 1 层：$f$
- 第 2 层：$c,\ g$
- 第 3 层：$e,\ a,\ b,\ d$

所以与结点 $a$ 同层的是 $e,\ b,\ d$，选项中为 $d$。

若用程序验证，可按后序遍历顺序给结点贴标签并记录深度：

```cpp
void dfs(Node* u, int depth) {
    if (!u) return;
    dfs(u->left, depth + 1);
    dfs(u->right, depth + 1);
    label[u] = post[idx++];
    dep[u] = depth;
}
```

最后比较深度即可。

**易错点**：  
- 不要把后序序列的左右子树分错。后序序列中，**子树的根在该子树序列的最后一个位置**，不是第一个。  
- 不要认为“同层”一定是亲兄弟。$a$ 与 $d$ 只是堂结点，二者同层但不在同一子树中。  
- 注意根层数从 1 开始计；即使从 0 开始计，也不影响选项。  
- 若忽略树形，仅由后序序列不能唯一确定二叉树，因此必须结合题给树形。

**命题规律**：  
本题考点是二叉树的遍历序列与树形结构。常见变式包括：给先序/后序序列和树形求某结点层次；或给两种遍历序列重建二叉树。复习时要熟练运用“后序序列末尾为根”的递归分割法，并结合树形确定左右子树结点个数。

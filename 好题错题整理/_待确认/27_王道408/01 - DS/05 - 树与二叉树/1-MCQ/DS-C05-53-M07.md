# 选择题 第 7 题

![[_Attachments/题目识别/27_王道408-题目/DS-C05-53-M07_题目.png|题目]]

7. 对二叉树的结点从 1 开始进行连续编号,要求每个结点的编号大于其左右孩子的编号,同一结点的左右孩子中，其左孩子的编号小于其右孩子的编号，可采用(  )次序的遍历实现编号.
(A) 先序遍历
(B) 中序遍历
(C) 后序遍历
(D) 层次遍历

## 答案

## DeepSeek V4 Flash Max 解析

**答案**：采用后序遍历次序实现编号，故选 **(C)**。

**解题切入点**：抓住题目中的两个核心约束：“每个结点的编号大于其左右孩子编号”意味着父结点必须在孩子之后被编号；“左孩子编号小于右孩子编号”意味着同一父结点下必须先左后右。这与后序遍历“左子树 → 右子树 → 根结点”的访问顺序完全一致。可以类比算法竞赛中“DFS 后序时间戳”的思想：先递归处理完所有子树，再给当前结点打上时间戳，这样祖先的时间戳一定大于后代。

**推演**：设编号函数 $f(v)$ 表示按遍历顺序为结点 $v$ 分配的连续编号。连续编号等价于：每访问一个结点，就将其编号置为当前递增计数器加 $1$。因此“先访问的结点编号小，后访问的结点编号大”。

若采用后序遍历，对任意结点 $v$，其访问顺序严格为：

1. 遍历 $v$ 的左子树；
2. 遍历 $v$ 的右子树；
3. 访问 $v$ 本身。

于是对 $v$ 的左右孩子 $L$ 和 $R$，有：

$$
f(L) < f(R) < f(v)
$$

因为左子树整体先于右子树访问，所以 $f(L)<f(R)$；右子树整体先于根结点访问，所以 $f(R)<f(v)$。因此：

- 每个结点的编号大于其左右孩子的编号；
- 同一结点的左孩子编号小于右孩子编号。

均满足要求。可用后序遍历递归编号：

```cpp
int cnt = 0;

void postOrder(Node* root) {
    if (root == NULL) return;
    postOrder(root->left);
    postOrder(root->right);
    root->val = ++cnt;   // 后序编号
}
```

排除其他选项：

- **先序遍历**：顺序为“根 → 左 → 右”，根结点最先访问，编号最小，不满足“父大于孩子”。
- **中序遍历**：顺序为“左 → 根 → 右”，根结点编号介于左右孩子之间，无法保证根大于右孩子。
- **层次遍历**：按层从上到下、每层从左到右访问，父结点先于孩子访问，编号小于孩子，不满足条件。

故只能采用后序遍历。

**易错点**：

1. **混淆“访问顺序”与“编号大小”**：先访问的结点编号小，后访问的结点编号大。题目要求父结点编号大于孩子，所以父结点必须后访问，而不是先访问。
2. **忽略“左孩子编号小于右孩子编号”**：若只要求父大于孩子，逆后序“根 → 右 → 左”也能让父大于孩子，但会使右孩子编号小于左孩子，不满足题目要求。必须严格采用“左 → 右 → 根”的后序遍历。
3. **递归代码位置写错**：编号操作必须放在左右子树递归调用之后，否则变成先序编号，导致错误。

**命题规律**：本题属于“二叉树遍历性质”的基础题，常以选择题或填空题出现。核心考点是四种遍历顺序与结点编号/输出顺序的关系。常见变式有：

- 若要求“每个结点编号小于其左右孩子编号”，则应采用先序遍历或层次遍历；
- 若给定某种编号序列，判断对应遍历方式；
- 结合完全二叉树、堆等结构考查编号与遍历的关系。

复习时应掌握四种遍历的递归顺序，并能通过画一棵简单二叉树，按不同遍历顺序编号，直观对比条件。理解“递归调用时机”与“访问次序”之间的关系，是解决此类题目的关键。

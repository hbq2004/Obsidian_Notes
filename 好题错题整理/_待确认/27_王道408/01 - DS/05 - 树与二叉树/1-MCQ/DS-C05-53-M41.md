# 选择题 第 41 题

![[_Attachments/题目识别/27_王道408-题目/DS-C05-53-M41_题目.png|题目]]

41.【2022统考真题】若结点$p$与$q$在二叉树$T$的中序遍历序列中相邻，且$p$在$q$之前，则下列$p$与$q$的关系中，不可能的是( )。
I.$q$是$p$的双亲  II.$q$是$p$的右孩子
III.$q$是$p$的右兄弟  IV.$q$是$p$的双亲的双亲
(A) 仅$I$
(B) 仅$III$
(C) 仅$II$、$III$
(D) 仅$II$、$IV$

## DeepSeek V4 Flash Max 解析

**答案**：选 B。即 $p$ 与 $q$ 中序相邻且 $p$ 在 $q$ 前时，只有 III“$q$ 是 $p$ 的右兄弟”不可能。

**解题切入点**：  
“中序相邻”等价于“$q$ 是 $p$ 的中序后继”。中序后继的固定求法是：  
- 若 $p$ 有右子树，则后继是 $p$ 右子树中最左下的结点；  
- 若 $p$ 无右子树，则沿父指针上溯，找到第一个“其左孩子包含 $p$”的祖先。  

所以不要把题目当作“画很多树去猜”，要直接转化为“中序后继”问题。

**推演**：

中序遍历顺序为：

$$左子树,\ 根,\ 右子树$$

若 $q$ 紧跟 $p$，则 $q=\operatorname{succ}(p)$。求中序后继的关键代码思路如下：

```cpp
Node* inorderSuccessor(Node* p) {
    if (p->right != NULL) {          // 有右子树
        Node* q = p->right;
        while (q->left != NULL)      // 找右子树最左下结点
            q = q->left;
        return q;
    }
    // 无右子树：向上找祖先
    Node* child = p;
    Node* q = p->parent;
    while (q != NULL && child == q->right) {
        child = q;
        q = q->parent;
    }
    return q;
}
```

因此，$q$ 只可能是两类结点：

1. $p$ 右子树中的后代；
2. 当 $p$ 无右子树时，$p$ 的某个祖先。

逐项判断：

| 关系 | 是否可能 | 理由/构造 |
|---|---|---|
| I. $q$ 是 $p$ 的双亲 | 可能 | 例：$p$ 是 $q$ 的左孩子，且 $p$ 无右孩子，则中序为 $p,q$。 |
| II. $q$ 是 $p$ 的右孩子 | 可能 | 例：$q$ 是 $p$ 的右孩子，且 $q$ 无左孩子，则中序为 $p,q$。 |
| III. $q$ 是 $p$ 的右兄弟 | 不可能 | 设 $p,q$ 的共同双亲为 $r$。中序遍历 $r$ 的子树时，$p$ 在 $r$ 的左子树中，$q$ 在 $r$ 的右子树中，顺序必为 $p,\ r,\ q$（中间还可能夹有其他结点），所以 $p,q$ 不可能相邻。 |
| IV. $q$ 是 $p$ 的双亲的双亲 | 可能 | 例：$f$ 是 $q$ 的左孩子，$p$ 是 $f$ 的右孩子，且 $p$ 无右孩子；若 $f$ 无左孩子，则中序为 $f,p,q$，故 $p,q$ 相邻。 |

所以四个关系中，只有 III 不可能。

**易错点**：

1. 不要把“右孩子”直接等同于“中序后继”。若 $p$ 的右孩子有左子树，则中序后继是右孩子左子树中的最左下结点，而不是右孩子本身。
2. 不要认为“双亲一定夹在 $p$ 和 $q$ 之间”，从而误判 I 或 IV。  
   - I 中，$p$ 是 $q$ 的左孩子时，$q$ 正好紧跟 $p$；  
   - IV 中，$p$ 是其父 $f$ 的右孩子时，$f$ 在 $p$ 之前，祖父 $q$ 可以在 $p$ 之后。
3. 右兄弟不可能相邻，是因为共同双亲 $r$ 作为真实结点必然出现在中序序列中，且位于左右子树之间，不能被跳过。

**命题规律**：  
本题考点是二叉树中序遍历性质、中序前驱/后继、结点关系判断。常见变式包括：中序线索二叉树中求前驱/后继、根据遍历序列判断两个结点能否相邻、前序/后序相邻关系判断等。复习时牢记口诀“有右子树找左下，无右子树找祖先”，并多画小树验证即可。

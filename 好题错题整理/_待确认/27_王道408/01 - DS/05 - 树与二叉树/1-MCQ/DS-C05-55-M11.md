# 选择题 第 11 题

![[_Attachments/题目识别/27_王道408-题目/DS-C05-55-M11_题目.png|题目]]

11. 并查集中最核心的两个操作是:①查找，查找两个元素是否属于同一个集合; ②合并，若两个元素不属于同一个集合，且所在的两个集合互不相交，则合并这两个集合. 假设初始长度为 $10(0 \sim 9)$ 的并查集，按 $1-2$、$3-4$、$5-6$、$7-8$、$8-9$、$1-8$、$0-5$、$1-9$ 的顺序进行查找和合并操作，最终并查集共有( )个集合.

A. 1
B. 2
C. 3
D. 4

## 答案

## DeepSeek V4 Flash Max 解析

**答案**：最终并查集中有 $3$ 个集合，选 C。

**解题切入点**：  
把每个元素看成一个点，把每次“查找/合并”操作看成尝试在两个点之间加一条边。并查集中的集合数就是无向图中的连通分量数。每次“有效合并”会使集合数减 1；“查找”本身不改变集合数。所以不要直接算 $10-8=2$，而要判断哪些操作是冗余的。

**推演**：  
初始时 $10$ 个元素各自成集，集合数 $C=10$：

$$C=10$$

逐个处理：

| 操作 | 查找结果 | 合并后的变化 | 集合数 $C$ |
|---|---|---|---|
| $1-2$ | 不同集合 | 合并为 $\{1,2\}$ | $9$ |
| $3-4$ | 不同集合 | 合并为 $\{3,4\}$ | $8$ |
| $5-6$ | 不同集合 | 合并为 $\{5,6\}$ | $7$ |
| $7-8$ | 不同集合 | 合并为 $\{7,8\}$ | $6$ |
| $8-9$ | 不同集合 | 合并为 $\{7,8,9\}$ | $5$ |
| $1-8$ | 不同集合 | 合并为 $\{1,2,7,8,9\}$ | $4$ |
| $0-5$ | 不同集合 | 合并为 $\{0,5,6\}$ | $3$ |
| $1-9$ | 同一集合 | 不合并 | $3$ |

最终三个集合为：

$$
\{0,5,6\},\quad \{1,2,7,8,9\},\quad \{3,4\}
$$

所以最终共有 $3$ 个集合。

关键代码思路如下：

```c
cnt = 10;

for (每个操作 (a, b)) {
    if (find(a) != find(b)) {   // 不在同一集合
        merge(a, b);            // 合并
        cnt--;                  // 只有成功合并才使集合数减 1
    }
}
```

**易错点**：  
1. 容易把 $1-9$ 也当成一次有效合并，从而算出 $10-8=2$，误选 B。实际上在 $1-8$ 之后，$1$ 和 $9$ 已经在同一集合中，所以 $1-9$ 不改变集合数。  
2. 容易忽略元素 $0$。$0$ 通过操作 $0-5$ 与 $\{5,6\}$ 合并，最终不是单独一个集合。  
3. 查找操作不会改变集合数；只有“两个元素原本不在同一集合”的合并才会使集合数减 1。  
4. 并查集的具体树形结构可能因合并策略不同而不同，但最终集合数只取决于哪些元素被连通，与父结点挂接方式无关。

**命题规律**：  
本题考查并查集最核心的“查找”和“合并”操作，本质上等价于求无向图的连通分量数。408 中常与 Kruskal 算法结合考查：若 `find(u) == find(v)`，则加入边 $(u,v)$ 会形成回路。变式可能包括：给定若干合并操作求最终集合数、判断两个元素是否连通、求最小生成树中的有效合并次数等。复习时应熟练掌握并查集的集合计数思想，并理解路径压缩与按秩合并的优化作用。

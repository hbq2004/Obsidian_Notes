# 选择题 第 21 题

![[_Attachments/题目识别/27_王道408-题目/DS-C05-53-M21_题目.png|题目]]

21. 某二叉树 $T$ 采用二叉链表存储结构, $T$ 的中序遍历序列为一个升序序列, 要求采用某种方法对 $T$ 进行某种操作之后得到一棵新的二叉树 $T'$, 要求 $T'$ 的中序遍历序列为一个降序序列，则下列关于该算法的叙述中，正确的是 ( )。
A. 采用中序遍历的方法最合适
B. 采用后序遍历的方法最合适
C. $T'$ 中的根结点一定不是原 $T$ 中的根结点
D. $T'$ 中的叶结点不一定是原 $T$ 中的叶结点

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C05-53-M21_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 **B**。该操作是“镜像”：把原二叉树每个结点的左右子树互换；这样 $T'$ 的中序序列正好是原 $T$ 中序序列的逆序，原升序就变为降序。实现该操作最合适的是后序遍历。

**解题切入点**：

- $T$ 的中序序列是升序，则原树中序形如：
  $$a_1,a_2,\dots,a_n$$
- 要让新树中序变为：
  $$a_n,a_{n-1},\dots,a_1$$
  在树结构上最直接的做法就是“左右子树互换”，即求二叉树的镜像。
- 因此考点定位为：二叉树遍历的应用 + 二叉链表指针修改。类似“反转链表”的思路，这里不是修改结点值，而是调整左右孩子指针。

**推演**：

设原树中以 $p$ 为根的子树的原中序序列为：
$$I_L,\ p,\ I_R$$

其中 $I_L$ 是 $p$ 的左子树中序序列，$I_R$ 是 $p$ 的右子树中序序列。

先把左右子树分别镜像，则左子树中序变为：
$$\operatorname{rev}(I_L)$$
右子树中序变为：
$$\operatorname{rev}(I_R)$$

再交换 $p$ 的左右孩子，则新子树中序序列为：
$$\operatorname{rev}(I_R),\ p,\ \operatorname{rev}(I_L)$$

这正好等于原中序序列的逆序：
$$\operatorname{rev}(I_L,\ p,\ I_R)$$

所以整棵树的原中序序列：
$$a_1,a_2,\dots,a_n$$
变为：
$$a_n,a_{n-1},\dots,a_1$$

原序列升序，则新序列降序。

标准后序递归实现如下：

```c
void Mirror(BiTree &T) {
    if (T == NULL)
        return;
    Mirror(T->lchild);   // 先镜像左子树
    Mirror(T->rchild);   // 再镜像右子树
    swap(T->lchild, T->rchild); // 最后交换根结点的左右孩子
}
```

时间复杂度为 $O(n)$，递归栈空间为 $O(h)$，其中 $h$ 为树高。

选项分析：

- **A 错**：中序遍历的普通递归写法在交换根结点左右孩子后，右指针已不是原来的右子树，容易造成某棵子树被重复处理或漏处理；后序遍历最合适。
- **C 错**：镜像操作只交换左右孩子，不改变根结点，$T'$ 的根结点仍是原 $T$ 的根结点。
- **D 错**：叶结点的左右指针都为空，交换后仍为空；内部结点交换后仍有孩子，因此 $T'$ 的叶结点集合与原 $T$ 的叶结点集合相同。

**易错点**：

1. 误以为要把结点值重新排序，实际上只需交换左右指针。
2. 后序递归时忘记递归出口 `T == NULL`，导致空指针访问。
3. 把后序写成中序框架：
   ```c
   Mirror(T->lchild);
   swap(T->lchild, T->rchild);
   Mirror(T->rchild);
   ```
   交换后 `T->rchild` 已经不是原来的右子树，不能直接继续递归。
4. 误以为 $T'$ 的根结点一定改变；镜像操作中根结点不变。
5. 误以为叶结点会改变；镜像只交换子树，不改变结点的孩子个数。

**命题规律**：

本题属于二叉树遍历应用，常结合“二叉排序树中序有序”的性质命题。常见变式有：

- 求二叉树的镜像，并输出其先序/层序序列；
- 判断一棵二叉树是否是对称二叉树；
- 利用 BST 中序序列求第 $k$ 小或第 $k$ 大结点；
- 用非递归方式实现左右子树交换。

复习时应把遍历理解为处理结点的框架，而不只是输出序列；同时要能熟练写出二叉链表下的指针修改递归算法。

# 选择题 第 17 题

![[_Attachments/题目识别/27_王道408-题目/DS-C05-53-M17_题目.png|题目]]

17. 已知一棵二叉树的先序遍历结果为 $ABCDEF$, 中序遍历结果为 $CBAEDF$, 则后序遍历的结果为 ( )
A. $CBEFDA$
B. $FEDCBA$
C. $CBEDFA$
D. 不确定

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C05-53-M17_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：由先序序列和中序序列可唯一确定该二叉树，后序遍历结果为 $CBEFDA$，故选 A。

**解题切入点**：先序序列的第一个结点就是根结点；利用根在中序序列中的位置，可以把中序序列分成左子树和右子树，再按左子树结点个数把先序剩余序列也分成左、右两部分。这是一个典型的“递归分治重建二叉树”过程，可类比为：先序给出“根的优先级”，中序给出“左右子树的分界线”。

**推演**：

1. 先序序列为 $ABCDEF$，第一个结点是 $A$，所以根结点为 $A$。

2. 在中序序列 $CBAEDF$ 中，$A$ 左侧为 $CB$，右侧为 $EDF$，因此：
$$
L_{\text{in}} = CB, \qquad R_{\text{in}} = EDF
$$

3. 左子树结点个数为 $2$，所以先序剩余序列 $BCDEF$ 中，前 $2$ 个属于左子树，后 $3$ 个属于右子树：
$$
L_{\text{pre}} = BC, \qquad R_{\text{pre}} = DEF
$$

4. 重建左子树：  
先序为 $BC$，中序为 $CB$，根为 $B$。  
$C$ 在中序中位于 $B$ 的左侧，所以 $C$ 是 $B$ 的左孩子，$B$ 的右子树为空。

5. 重建右子树：  
先序为 $DEF$，中序为 $EDF$，根为 $D$。  
$E$ 在中序中位于 $D$ 的左侧，$F$ 位于 $D$ 的右侧，所以 $E$ 是 $D$ 的左孩子，$F$ 是 $D$ 的右孩子。

二叉树结构为：

```
        A
       / \
      B   D
     /   / \
    C   E   F
```

6. 后序遍历顺序为“左子树、右子树、根”：

- $A$ 的左子树后序：$CB$
- $A$ 的右子树后序：$EFD$
- 最后访问根 $A$

因此：
$$
\text{Postorder} = CB + EFD + A = CBEFDA
$$

所以选 **A**。

**易错点**：

- 先序剩余序列不能简单按“前半段、后半段”切分，必须根据左子树的中序长度来划分左右子树。
- 后序遍历顺序容易写成“根左右”或“左根右”，本题应牢记后序是“左右根”。
- 不要误选 D。虽然“先序 + 后序”不能唯一确定二叉树，但“先序 + 中序”在结点值互异时可以唯一确定二叉树。
- 重建时容易把左右孩子方向搞反：中序中位于根左侧的结点属于左子树，位于根右侧的结点属于右子树。

**命题规律**：本题属于二叉树遍历序列的相互确定，是 408 数据结构选择题中的高频基础题。常见变式有：由“中序 + 后序”求先序，由“先序 + 中序”求后序，或给出层次遍历序列与中序序列重建二叉树。复习时应熟练掌握“利用根在中序中的位置递归划分左右子树”的方法，并能快速手绘二叉树结构。

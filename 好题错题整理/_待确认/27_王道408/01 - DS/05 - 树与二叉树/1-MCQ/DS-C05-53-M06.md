# 选择题 第 6 题

6. 在二叉树的先序序列、中序序列和后序序列中，所有叶结点的先后顺序( ).
(A) 都不相同
(B) 完全相同
(C) 先序和中序相同，而与后序不同
(D) 中序和后序相同，而与先序不同

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C05-53-M06_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 B。二叉树的先序、中序、后序序列中，所有叶结点的相对顺序完全相同，都按结点从左到右的次序出现。

**解题切入点**：
抓住“叶结点的先后顺序”而不要看“所有结点的位置”。三种遍历的递归定义中，根结点的访问位置不同，但对左右子树的整体顺序都是“左子树在前、右子树在后”。因此可以把内部结点看成“干扰项”，比较叶结点序列时只考虑二叉树自左向右的叶序。做题经验：当只需关注某类结点的相对顺序时，把其他结点从遍历序列中删掉，剩下的序列即为该类结点的相对顺序。

**推演**：
设 $T$ 的左右子树为 $L,R$，根为 $r$。记 $S_{\mathrm{pre}}(T),S_{\mathrm{in}}(T),S_{\mathrm{post}}(T)$ 分别为按先序、中序、后序遍历时 $T$ 中叶结点组成的序列，$\epsilon$ 表示空序列。

对树高归纳证明三者相等。

1. 若 $T$ 为空，则 $S_{\mathrm{pre}}(T)=S_{\mathrm{in}}(T)=S_{\mathrm{post}}(T)=\epsilon$。
2. 若 $T$ 只有一个结点 $r$，则 $r$ 是叶结点，三种遍历中叶结点序列都是 $[r]$。
3. 否则 $r$ 不是叶结点，$T$ 的叶结点全在 $L$ 或 $R$ 中。由归纳假设，$L$ 和 $R$ 自身的三种叶结点序列分别相等。先序遍历顺序为 $r,L,R$，所以
$$
S_{\mathrm{pre}}(T)=S_{\mathrm{pre}}(L)+S_{\mathrm{pre}}(R);
$$
中序遍历顺序为 $L,r,R$，而 $r$ 不是叶结点，所以
$$
S_{\mathrm{in}}(T)=S_{\mathrm{in}}(L)+S_{\mathrm{in}}(R);
$$
后序遍历顺序为 $L,R,r$，同样 $r$ 不输出，所以
$$
S_{\mathrm{post}}(T)=S_{\mathrm{post}}(L)+S_{\mathrm{post}}(R).
$$
由于 $S_{\mathrm{pre}}(L)=S_{\mathrm{in}}(L)=S_{\mathrm{post}}(L)$，$S_{\mathrm{pre}}(R)=S_{\mathrm{in}}(R)=S_{\mathrm{post}}(R)$，故
$$
S_{\mathrm{pre}}(T)=S_{\mathrm{in}}(T)=S_{\mathrm{post}}(T).
$$
当某棵子树为空时，对应项取 $\epsilon$，结论仍成立。

例如：树根为 $A$，左孩子为叶 $B$，右孩子为内部结点 $C$，$C$ 的左孩子为叶 $D$。先序：$A,B,C,D$，删去非叶 $A,C$ 得叶序 $B,D$；中序：$B,A,D,C$，删去 $A,C$ 得 $B,D$；后序：$B,D,C,A$，删去 $A,C$ 得 $B,D$。三种叶序相同。

验证代码思路如下，把输出叶结点的分支放在先序/中序/后序的相应位置，三种输出序列一致：
```c
void printLeaves(BTNode *p) {
    if (p == NULL) return;
    if (p->lchild == NULL && p->rchild == NULL)
        printf("%c ", p->data);
    printLeaves(p->lchild);
    printLeaves(p->rchild);
}
```
（中序、后序版本只需将该 if 语句分别移到左右子树递归调用之间或之后。）

**易错点**：
- 误以为后序中根最后访问，所以叶结点顺序也与先序不同。实际上叶结点只分布在子树中，根结点是否插入遍历序列不影响叶结点之间的相对顺序。
- 把“叶结点的相对顺序”误认为“叶结点在序列中的绝对位置”。位置可能不同，但相对顺序相同。
- 画反例时只画单链树，叶结点只有一个，三种叶序当然相同；应画左右子树都含叶结点的二叉树，更能体会结论。
- 把只有一个孩子的结点当成叶结点。叶结点定义为左、右孩子都为空的结点，单孩子结点不是叶结点。

**命题规律**：
本考点是“二叉树的遍历”基本性质。408 中常以选择题形式考查三种遍历的特点，如判断某种序列能否对应一棵二叉树、由两种遍历序列还原二叉树、求第一个/最后一个叶结点等。常见变式有：若给出一棵树的先序序列，问其中序序列中叶结点相对顺序是否相同；或把二叉树的叶结点依次输出，问三种遍历输出序列是否一致。复习建议：熟练掌握三种遍历的递归定义，能画出简单例子验证；理解“先/中/后”只改变根的访问位置，不改变左右子树之间的整体次序。

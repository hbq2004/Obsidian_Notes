# 选择题 第 19 题

![[_Attachments/题目识别/27_王道408-题目/DS-C05-54-M19_题目.png|题目]]

19.【2020统考真题】 已知森林 $F$ 及与之对应的二叉树 $T$, 若 $F$ 的先根遍历序列是 $a,b,c,d,e,f$, 后根遍历序列是 $b,a,d,f,e,c$, 则 $T$ 的后序遍历序列是 ( ) .
A. $b,a,d,f,e,c$
B. $b,d,f,e,c,a$
C. $b,f,e,d,c,a$
D. $f,e,d,c,b,a$

## DeepSeek V4 Flash Max 解析

**答案**：$T$ 的后序遍历序列是 $b,f,e,d,c,a$，选 C。

**解题切入点**：

看到“森林 $F$ 与二叉树 $T$ 对应”，立即想到“孩子兄弟表示法”。核心考点是：

- 森林 $F$ 的先根遍历序列 = 二叉树 $T$ 的先序遍历序列；
- 森林 $F$ 的后根遍历序列 = 二叉树 $T$ 的中序遍历序列。

所以本题本质上是：已知二叉树 $T$ 的先序序列和中序序列，求 $T$ 的后序序列。这是“由先序 + 中序重建二叉树”的经典题型。

**推演**：

设森林 $F$ 对应二叉树 $T$。由孩子兄弟表示法：

$$
\operatorname{PRE}(F)=\operatorname{Pre}(T)
$$

$$
\operatorname{POST}(F)=\operatorname{In}(T)
$$

因此由题意：

$$
\operatorname{Pre}(T):\ a,b,c,d,e,f
$$

$$
\operatorname{In}(T):\ b,a,d,f,e,c
$$

用先序序列确定根，用中序序列划分左右子树。

1. 先序序列第一个元素是 $a$，所以 $T$ 的根为 $a$。
2. 中序序列中，$a$ 左边是 $b$，右边是 $d,f,e,c$，所以：
   - 左子树先序为 $b$，中序为 $b$；
   - 右子树先序为 $c,d,e,f$，中序为 $d,f,e,c$。
3. 右子树根为 $c$。中序中 $c$ 在最后，所以 $c$ 无右子树，左子树中序为 $d,f,e$，先序为 $d,e,f$。
4. 左子树根为 $d$。中序中 $d$ 在最前，所以 $d$ 无左子树，右子树中序为 $f,e$，先序为 $e,f$。
5. 右子树根为 $e$。中序中 $f$ 在 $e$ 前面，所以 $f$ 是 $e$ 的左孩子。

得到的二叉树结构为：

```
      a
     / \
    b   c
       /
      d
       \
        e
       /
      f
```

后序遍历顺序为“左-右-根”：

- $a$ 的左子树：$b$；
- $a$ 的右子树以 $c$ 为根，其后序序列为 $f,e,d,c$；
- 最后访问根 $a$。

所以：

$$
\operatorname{Post}(T)=b,f,e,d,c,a
$$

故选择 **C**。

关键代码思路如下：

```cpp
// 已知 pre[] 和 in[]，pos[x] 记录 x 在中序中的位置
TreeNode* build(int preL, int preR, int inL, int inR) {
    if (preL > preR) return nullptr;

    TreeNode* root = new TreeNode(pre[preL]);
    int k = pos[pre[preL]];   // 根在中序中的位置
    int leftLen = k - inL;    // 左子树长度

    root->left  = build(preL + 1, preL + leftLen, inL, k - 1);
    root->right = build(preL + leftLen + 1, preR, k + 1, inR);

    return root;
}
```

建树后按“左-右-根”输出即可。

**易错点**：

1. **把森林后根序列直接当成二叉树后序序列**，会误选 A。  
   实际上森林后根序列对应的是二叉树的中序序列，不是后序序列。

2. 重建二叉树时容易算错左右子树范围。  
   用中序定位根后，左子树长度为 `k - inL`，右子树先序起点是 `preL + leftLen + 1`。

3. 混淆孩子兄弟法中“右子树”的含义。  
   二叉树 $T$ 中，右子树可能表示森林中的“下一棵兄弟树/下一棵树”，但在求 $T$ 的遍历序列时，仍按普通二叉树的左、右子树处理。

4. 只凭选项猜测，不实际重建，容易错。  
   建议画出二叉树或用递归切分序列验证。

**命题规律**：

本题属于“树、森林与二叉树的转换”和“遍历序列的相互确定”的结合考点，是 408 选择题常考形式。常见变式有：

- 已知二叉树先序、中序，求森林先根、后根序列；
- 已知树的先根、后根序列，求对应二叉树的中序或后序序列；
- 判断某个序列是否可能是某种遍历结果。

复习时务必记住：

$$
\text{森林先根} \leftrightarrow \text{二叉树先序}
$$

$$
\text{森林后根} \leftrightarrow \text{二叉树中序}
$$

并熟练掌握“先序找根、中序分左右”的递归重建方法。

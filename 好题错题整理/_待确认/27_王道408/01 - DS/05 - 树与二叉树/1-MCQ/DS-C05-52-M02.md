# 选择题 第 2 题

2. “二叉树为空”意味着二叉树 ( ).

A. 根结点没有子树
B. 不存在
C. 没有结点
D. 由一些没有赋值的空结点构成

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C05-52-M02_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：“二叉树为空”的含义是二叉树**没有结点**，因此选 **C**。

**解题切入点**：拿到这种概念题，先回到“二叉树”的递归定义：二叉树是结点的有限集合，且允许为空。空树不是“没有子树”，也不是“不存在”，而是结点集合大小为 $0$。可以类比链表中的空链表：空链表并不是没有“链表”这个概念，而是头指针为 `NULL`，不包含任何结点。

**推演**：

二叉树的标准递归定义是：

> 二叉树是 $n(n \ge 0)$ 个结点的有限集合：
> - 当 $n=0$ 时，称为空二叉树；
> - 当 $n>0$ 时，它由一个根结点和两棵互不相交的、分别称为左子树和右子树的二叉树组成。

因此，空二叉树就是

$$
T = \varnothing,\quad |T|=0
$$

即树中不含任何结点。

逐项分析选项：

- **A. 根结点没有子树**：这表示二叉树中确实存在一个根结点，根结点的左右子树都为空，但根结点本身是一个结点，所以此时二叉树至少含有一个结点，不是空树。例如只有一个根结点的二叉树：
  
  ```
      A
     / \
   NULL NULL
  ```
  
  这棵树结点数 $n=1$，显然不是空树。

- **B. 不存在**：这是对“空”的误解。空树是二叉树的一种合法状态，在递归定义、递归遍历、空表判断中很重要。比如遍历二叉树时的递归出口就是：

  ```c
  if (root == NULL) return;
  ```

  这里的 `root == NULL` 表示空树，但空树的概念是存在的，不是“不存在”。

- **C. 没有结点**：完全符合二叉树定义中 $n=0$ 的情况，是空二叉树的准确描述。

- **D. 由一些没有赋值的空结点构成**：这是错误说法。“空结点”本身就是结点，与空树没有结点相矛盾。空树中没有任何结点，既没有赋值的结点，也没有未赋值的结点；链式存储中的空指针 `NULL` 只是用来表示“没有子树”或“空树”的标记，并不是结点本身。

因此，正确选项是 **C**。

**易错点**：

1. **把“根结点没有子树”当成空树**：根结点没有子树时，根结点仍然存在，树中至少有一个结点。二者有本质区别。
2. **把“空树”理解为“不存在”**：在数据结构的抽象定义中，空树是合法的二叉树，是递归定义的基例，也是遍历、插入、删除等算法的重要终止条件。
3. **把“空指针”或“空结点”当成空树**：链式存储中，`NULL` 指针表示“没有结点”，但空指针本身不是结点；不能认为空树由若干空结点组成。
4. **误选 D**：命题人常用“空结点”制造干扰，必须明确：空树 = 结点集合为空，而不是存在一些没有赋值的结点。

**命题规律**：本题属于数据结构中“树与二叉树”的基本概念题，考查二叉树的递归定义中对空树的理解。408选择题中常以类似概念题考查树的性质，例如空树的结点数、深度、叶子结点个数，或者结合递归遍历判断 `root == NULL` 的含义。变式可能包括：
- 空二叉树的高度是多少？（一般规定空树高度为 $0$ 或 $-1$，取决于定义）
- 空二叉树的叶子结点数是多少？（$0$）
- 在递归先序、中序、后序遍历中，空树作为递归出口的作用。

复习建议：准确记忆二叉树递归定义中的“空树合法”思想，分清“结点数 $n=0$”“根结点存在”“指针为空”三者的不同。做题时遇到“空”字，优先回到“集合中有没有元素”来判断。

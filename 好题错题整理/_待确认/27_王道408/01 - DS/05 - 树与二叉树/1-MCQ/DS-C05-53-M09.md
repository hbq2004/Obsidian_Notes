# 选择题 第 9 题

![[_Attachments/题目识别/27_王道408-题目/DS-C05-53-M09_题目.png|题目]]

9. 先序序列为 $A, B, C$, 后序序列为 $C, B, A$ 的二叉树共有 (  ).
(A) 1 棵
(B) 2 棵
(C) 3 棵
(D) 4 棵

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C05-53-M09_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：满足条件的二叉树共有 $4$ 棵，选 **D**。

**解题切入点**：先由先序第一个结点和后序最后一个结点锁定根为 $A$。然后判断根 $A$ 有几个孩子；若根只有一个孩子，先序第二个结点一定等于后序倒数第二个结点，此时左右位置有两种可能。本题中 $A$ 和 $B$ 都是单分支结点，各自有左右两种选择，所以总数是 $2\times 2=4$。

**推演**：

设先序序列为 $P=(A,B,C)$，后序序列为 $Q=(C,B,A)$。

1. 确定根结点：
   $$P[0]=A,\qquad Q[2]=A$$
   所以根为 $A$。

2. 判断根 $A$ 是否可能有两个非空子树。  
   如果 $A$ 同时有左、右子树，则先序去掉根后为 $B,C$，左子树根必为 $B$，右子树根必为 $C$。后序中一定是“左子树后序 + 右子树后序 + 根”，即为：
   $$B,C,A$$
   但题目给定后序是 $C,B,A$，矛盾。  
   因此 $A$ 只能有一个孩子。又因为先序去掉根后的第一个结点是 $B$，所以 $A$ 的唯一孩子子树根为 $B$。  
   $B$ 可以作为 $A$ 的左孩子或右孩子，共 $2$ 种。

3. 再看以 $B$ 为根的子树。  
   它的先序为 $B,C$，后序为 $C,B$，所以 $B$ 是根，$C$ 是 $B$ 的唯一孩子。  
   $C$ 可以作为 $B$ 的左孩子或右孩子，共 $2$ 种。

4. 两步选择相互独立，因此总数为：
   $$2\times 2=4$$

这 $4$ 棵二叉树分别是：

- $A$ 的左孩子为 $B$，$B$ 的左孩子为 $C$；
- $A$ 的左孩子为 $B$，$B$ 的右孩子为 $C$；
- $A$ 的右孩子为 $B$，$B$ 的左孩子为 $C$；
- $A$ 的右孩子为 $B$，$B$ 的右孩子为 $C$。

关键代码思路：

```text
count(P, Q):
    若 P 为空: return 1
    若 P 长度为 1: return 1
    若 P[1] == Q[-2]:
        根只有一个孩子，左右位置有 2 种
        return 2 * count(P[1:], Q[:-1])
    否则:
        根有两个孩子，按先序/后序划分子树，递归相乘
```

本题中先遇到 $A$ 是单分支，再遇到 $B$ 是单分支，因此结果为 $2\times 2=4$。

**易错点**：

- 容易只想到“左单链”或“右单链”，忘记单分支结点的孩子可以放在左边或右边，导致漏数。
- 不要把 $A$ 同时有左右孩子 $B,C$ 的情况也算进去，那种树的后序是 $B,C,A$，不是 $C,B,A$。
- 不要认为先序 + 后序可以唯一确定一棵二叉树；只有先序 + 中序或中序 + 后序可以唯一确定。
- 二叉树中左右子树是有严格次序的，左右互换应算作不同的树。

**命题规律**：该题考查二叉树的遍历序列与树形结构之间的对应关系，尤其是“先序 + 后序不能唯一确定二叉树”的考点。常见变式有：已知先序和后序求二叉树个数、已知先序和中序还原二叉树、判断某个序列能否作为二叉树的遍历序列等。复习时应熟练掌握三种遍历中根、左子树、右子树在序列中的位置关系，并特别注意单分支结点的左右歧义。

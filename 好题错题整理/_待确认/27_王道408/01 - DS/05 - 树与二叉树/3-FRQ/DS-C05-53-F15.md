# 综合题 第 15 题

![[_Attachments/题目识别/27_王道408-题目/DS-C05-53-F15_题目.png|题目]]

15.【2014 统考真题】二叉树的带权路径长度 ($WPL$) 是二叉树中所有叶结点的带权路径长度之和。给定一棵二叉树 $T$, 采用二叉链表存储, 结点结构为

| left | weight | right |
| :---: | :---: | :---: |

其中叶结点的 $weight$ 域保存该结点的非负权值。设 $root$ 为指向 $T$ 的根结点的指针,请设计求 $T$ 的 $WPL$ 的算法, 要求:
1) 给出算法的基本设计思想.
2) 使用 $C$ 或 $C++$ 语言, 给出二叉树结点的数据类型定义.
3) 根据设计思想, 采用 $C$ 或 $C++$ 语言描述算法, 关键之处给出注释.

## 答案

## DeepSeek V4 Flash Max 解析

**答案**：采用带“当前深度”参数的先序遍历（DFS）递归遍历二叉树，每次进入左右孩子时深度加 1，遇到叶结点时累加 `weight * depth`，最后得到的和就是 $WPL$。

**解题切入点**：拿到题先抓两个关键点：只有**叶结点**参与求和，且每个叶结点的贡献是**权值 × 根到该叶结点的路径长度**。因此这是一个“遍历整棵树并记录深度”的问题。可以类比 DFS 中维护“当前步数”的模板：进入左右子树时 `depth + 1`，到达叶子时把答案累加。

**推演**：

### 1）基本设计思想

设递归函数 $F(T,d)$ 表示“以 $T$ 为根结点的子树中所有叶结点对 $WPL$ 的贡献之和”，其中 $d$ 是从二叉树根结点到 $T$ 的路径长度，即经过的边数。

- 若 $T$ 为空，则没有叶结点，贡献为 $0$；
- 若 $T$ 是叶结点，则贡献为 $T$ 的权值乘以当前路径长度 $d$；
- 若 $T$ 是非叶结点，则 $T$ 本身不贡献，只需要递归求左右子树，进入左右子树时路径长度都增加 1。

写成递归式：

$$
F(T,d)=
\begin{cases}
0, & T=\varnothing,\\[2mm]
w(T)\cdot d, & T \text{ 是叶结点},\\[2mm]
F(T_L,d+1)+F(T_R,d+1), & \text{否则}.
\end{cases}
$$

最终：

$$
WPL(T)=F(root,0)
$$

根结点到自身的路径长度为 0。

### 2）二叉树结点的数据类型定义

使用 C 语言定义如下：

```c
typedef struct BiTNode {
    struct BiTNode *left;   // 左孩子指针
    int weight;             // 叶结点权值；非叶结点该域不参与计算
    struct BiTNode *right;  // 右孩子指针
} BiTNode, *BiTree;
```

### 3）算法实现

```c
// 先序遍历求 WPL
// T 为当前子树根结点，depth 为 T 到原树根的路径长度
int WPLPreOrder(BiTree T, int depth) {
    if (T == NULL)
        return 0;                     // 空树没有叶结点

    // 叶结点：左右孩子都为空
    if (T->left == NULL && T->right == NULL)
        return T->weight * depth;     // 叶结点贡献 = 权值 × 路径长度

    // 非叶结点：递归求左右子树，进入子树时深度 +1
    return WPLPreOrder(T->left, depth + 1) +
           WPLPreOrder(T->right, depth + 1);
}

// 对外接口：从根结点开始，根结点深度为 0
int WPL(BiTree root) {
    return WPLPreOrder(root, 0);
}
```

每个结点在递归中只访问一次，因此时间复杂度为 $O(n)$；递归栈深度等于二叉树高度 $h$，因此空间复杂度为 $O(h)$，最坏情况下树退化为单链时是 $O(n)$。

**易错点**：

1. **根结点深度设置错误**：$WPL$ 中的路径长度是“边数”，所以根结点深度应为 0；如果误把根结点深度设为 1，所有叶结点都会多算一次权值，结果偏大 $\sum w_{\text{leaf}}$。
2. **把非叶结点当叶结点处理**：叶结点判断必须是 `T->left == NULL && T->right == NULL`，不能用 `||`。只有一个孩子的结点不是叶结点，不能直接累加。
3. **忘记处理空指针**：当某个非叶结点只有一个孩子时，另一个孩子为 `NULL`，递归前必须先判断 `T == NULL`，否则运行时会访问空指针。
4. **深度参数使用不当**：递归调用时应该传 `depth + 1`，不能写 `depth++`，否则会改变当前层的 `depth`，导致回溯时深度错误。
5. **用 `weight` 判断叶结点**：叶结点的权值可能为 0，因此不能通过 `weight > 0` 判断是否为叶结点，必须通过左右孩子是否为空判断。

**命题规律**：本题是 408 中典型的“二叉树遍历应用”算法设计题，核心考点是树的递归遍历和“带状态遍历”。同类型变式包括：求二叉树所有叶结点个数、求二叉树高度/宽度、求所有结点路径长度之和、统计满足某种条件的结点数，以及用层次遍历求 $WPL$。复习时应以“遍历框架 + 递归参数”为主线，熟练掌握先序、中序、后序、层次遍历的递归与非递归写法，并能用递归式清晰描述算法思想。考场上建议先写递归式，再翻译为 C/C++ 代码，最后补充时间复杂度和空间复杂度。

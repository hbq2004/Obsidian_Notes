## 答案

## DeepSeek V4 Flash Max 解析

**答案**：用层序遍历（队列）判断完全二叉树；核心是“空位标志”：队列中把空孩子也入队，一旦出现过空指针，后面若再出现非空结点，则不是完全二叉树；否则是。

**解题切入点**：看到“完全二叉树”，要立刻联想到它的层序编号性质：若结点编号为 $i$，则左孩子编号为 $2i$，右孩子编号为 $2i+1$。完全二叉树的 $n$ 个结点必须连续占据前 $n$ 个编号，不能中间缺一个、后面又冒出来。  
这就像排队点名：名单编号必须连续，中间空一个号，后面又有人应答，就说明顺序不完整。所以用层序遍历队列自然模拟“编号从小到大”的检查过程。

**推演**：

完全二叉树的条件可等价为：按层序遍历，把每个非空结点的空孩子也当作“空位”入队后，非空结点不能出现在“空位”之后。

因此算法如下：

```c
int IsComplete(BiTree T) {
    if (T == NULL) return 1;   // 空树按完全二叉树处理

    Queue Q;
    InitQueue(Q);
    EnQueue(Q, T);

    int flag = 0;              // flag = 1 表示已经出现过空位
    while (!QueueEmpty(Q)) {
        BiTNode *p = DeQueue(Q);

        if (p == NULL) {
            flag = 1;
        } else {
            if (flag == 1) return 0;   // 空位之后还有非空结点，不是完全二叉树
            EnQueue(Q, p->lchild);
            EnQueue(Q, p->rchild);
        }
    }

    return 1;
}
```

正确性说明：

- 若算法返回 0，说明在层序扩展序列中，某个空位之后又出现了非空结点，即编号出现缺口，不符合完全二叉树定义。
- 若算法返回 1，说明所有非空结点都排在空位之前，实际结点连续占据前 $n$ 个编号位置，因此是完全二叉树。

例如：
- 根结点只有左孩子：层序为“根、左孩子、空”，没有“空后非空”，是完全二叉树。
- 根结点只有右孩子：层序为“根、空、右孩子”，出现“空后非空”，不是完全二叉树。

时间复杂度为 $O(n)$，每个结点入队、出队一次；最坏情况下队列空间为 $O(n)$。

**易错点**：

1. 不能遇到第一个空指针就立刻返回 false。  
   完全二叉树的叶子结点也会产生空孩子，例如只有一个根结点时，层序扩展序列为“根、空、空”，仍然是完全二叉树。必须设置标志，看空位后面是否还有非空结点。

2. 不能只用递归判断左右子树是否都是完全二叉树。  
   完全二叉树是全局层序编号性质，递归只能判断局部结构，容易漏判“左边缺位、右边却有孩子”的情况。

3. 注意空树处理。  
   通常约定空树是完全二叉树；若题目约定“空树不是”，则把 `if (T == NULL) return 1;` 改为 `return 0;` 即可。

4. 队列中允许存放空指针。  
   不要因为 `p == NULL` 而继续访问 `p->lchild`，否则会空指针异常；空指针出队时只置标志，不继续入队。

**命题规律**：本题属于“二叉树遍历”与“完全二叉树性质”结合的综合题。层序遍历是高频考点，常见变式有：

- 判断一棵树是否为满二叉树；
- 统计完全二叉树结点个数；
- 在完全二叉树中插入新结点；
- 利用层序序列判断完全二叉树；
- 给出层序数组，还原二叉链表。

复习时要重点掌握队列在层序遍历中的使用，并理解完全二叉树和堆数组下标编号的对应关系。考试中代码不要求唯一，只要体现“层序遍历 + 空位检查”即可。

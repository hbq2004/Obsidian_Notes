17.【2022 统考真题】 已知非空二叉树 $T$ 的结点值均为正整数，采用顺序存储方式保存，数据结构定义如下:
```c
typedef struct {
    int SqBiTNode[MAX_SIZE];    // MAX_SIZE 为已定义常量
    int ElemNum;                // 保存二叉树结点值的数组
} SqBiTree;                     // 实际占用的数组元素个数
```
$T$ 中不存在的结点在数组 $SqBiTNode$ 中用 $-1$ 表示。例如，对于下图所示的两棵非空二叉树 $T_1$ 和 $T_2$,

## DeepSeek V4 Flash Max 解析

**答案**：对顺序存储的二叉树从下标 $0$ 开始做中序遍历，同时维护前驱值 `pre`；若中序序列严格递增，则为二叉搜索树，否则返回 `false`。

**解题切入点**：判定二叉搜索树不能只检查“根结点大于左孩子、小于右孩子”，因为深层结点可能破坏全局有序性。看到“判定 BST”，应立刻想到它的充要条件：**中序遍历序列严格递增**。顺序存储又直接给出了孩子下标，所以不需要重建链式树，直接按下标递归中序遍历即可。

**推演**：

1. **BST 与中序遍历的关系**  
   对任意结点 $x$，若树是 BST，则左子树所有值小于 $x$，右子树所有值大于 $x$。中序遍历顺序为：左子树、$x$、右子树，所以 BST 的中序序列必然严格递增。  
   反过来，若某二叉树的中序序列严格递增，则任意结点 $x$ 的左子树结点都排在 $x$ 之前，因此值都小于 $x$；右子树结点都排在 $x$ 之后，因此值都大于 $x$。所以该树是 BST。

2. **顺序存储的下标关系**  
   根结点下标为 $0$；下标为 $i$ 的结点：
   $$
   \text{左孩子下标}=2i+1,\qquad \text{右孩子下标}=2i+2
   $$
   若下标越界，或 `SqBiTNode[i] == -1`，说明该子树为空。

3. **算法设计**  
   从根开始递归中序遍历：
   - 先遍历左子树；
   - 再访问当前结点，若当前值 $\le pre$，说明中序序列不是严格递增，返回 `false`；
   - 否则更新 `pre` 为当前值；
   - 最后遍历右子树。

   由于题目说明结点值均为正整数，可令 `pre = -1` 作为初始前驱，它小于任意正整数，相当于 $-\infty$。

4. **代码实现**：

```cpp
bool InOrder(SqBiTree *T, int i, int *pre) {
    // 空子树：下标越界，或该位置为 -1
    if (i >= T->ElemNum || T->SqBiTNode[i] == -1)
        return true;

    // 中序遍历左子树
    if (!InOrder(T, 2 * i + 1, pre))
        return false;

    // 访问当前结点：BST 要求严格递增，所以 <= 即失败
    if (T->SqBiTNode[i] <= *pre)
        return false;
    *pre = T->SqBiTNode[i];

    // 中序遍历右子树
    if (!InOrder(T, 2 * i + 2, pre))
        return false;

    return true;
}

bool IsBST(SqBiTree *T) {
    int pre = -1;   // 小于所有正整数，相当于 -∞
    return InOrder(T, 0, &pre);
}
```

5. **正确性与复杂度**  
   上述递归恰好按中序顺序访问所有非空结点；只有当中序序列出现“当前值不大于前驱”时才返回 `false`。因此返回 `true` 当且仅当中序序列严格递增，等价于该树是 BST。  
   设树中实际结点数为 $n$，树高为 $h$。每个结点访问一次，时间复杂度为 $O(n)$；递归深度为 $O(h)$，最坏情况下 $O(n)$，辅助空间为 $O(h)$。

**易错点**：

1. **只比较父结点与左右孩子**：只能判断局部，不能判断全局 BST，必须通过中序遍历或上下界约束。
2. **把 $-1$ 当作结点值参与比较**：`-1` 只是“空结点”标记，遇到 `-1` 应直接返回，不能更新 `pre`。
3. **忘记下标越界检查**：递归进入孩子前要判断 `i >= ElemNum`，否则可能访问数组越界。
4. **重复值的处理**：按 408 常规严格定义，BST 不允许相等值，所以用 `<=` 判失败；若题目特别说明允许左 $\le$ 根 $\le$ 右，则应改为 `<`。
5. **递归传参时不要按值传整个结构体**：`SqBiTree` 内含大数组，按值传参会复制数组；应传指针或引用。

**命题规律**：本题考查 BST 定义、中序遍历性质、顺序存储二叉树的下标映射。常见变式有：判断链式二叉树是否为 BST、求 BST 中第 $k$ 小元素、找中序序列中的逆序对并恢复 BST、用区间 $(low, high)$ 约束递归判断 BST。复习时应熟练掌握“中序遍历 + 前驱指针”的模板，并会分析时间复杂度与空间复杂度。

# 综合题 第 2 题

![[_Attachments/题目识别/27_王道408-题目/DS-C05-51-F02_题目.png|题目]]

2. 已知一棵度为4的树中，度为$0,1,2,3$的结点数分别为$14,4,3,2$，设度为$4$的结点数为$x$，则结点总数$n = 14 + 4 + 3 + 2 + x$。树的边数$e$满足$e = n - 1$，同时各度结点的度数和为$0×14 + 1×4 + 2×3 + 3×2 + 4x = 4 + 6 + 6 + 4x = 16 + 4x$，而边数也等于度数和的一半，即$e = \frac{16 + 4x}{2} = 8 + 2x$。因此有$n - 1 = 8 + 2x$，代入$n = 23 + x$，得$23 + x - 1 = 8 + 2x$，解得$x = 14$，结点总数$n = 23 + 14 = 37$。

# 综合题 第 13 题

![[_Attachments/题目识别/27_王道408-题目/DS-C05-53-F13_题目.png|题目]]

13. 设计一个算法将二叉树的叶结点按从左到右的顺序连成一个单链表,表头指针为 $head$ 。二叉树按二叉链表方式存储，链接时用叶结点的右指针域来存放单链表指针.

## 答案

## DeepSeek V4 Flash Max 解析

**答案**：采用二叉树的中序遍历（先左后右）遍历二叉链表，遇到左右孩子均为空的叶结点时，用尾插法将其右指针域 `rchild` 作为单链表后继指针，最终使所有叶结点按从左到右连成以 `head` 为头指针的单链表；时间复杂度 $O(n)$，空间复杂度 $O(h)$。

**解题切入点**：  
拿到题先抓三个关键信息：

1. **叶结点**：度为 0，即 `lchild == NULL && rchild == NULL`。  
2. **从左到右**：二叉树中叶子结点的“从左到右”顺序，应通过遍历时“先左子树、后右子树”来保证，最直观的是中序遍历。  
3. **用右指针域存放链表指针**：说明不需要新建链表结点，直接复用原二叉树的叶结点，并把它的 `rchild` 当作单链表的 `next` 使用。

可以这样打比方：这是一次“树上 DFS + 链表尾插”的题目。搜索过程中遇到目标结点，就把目标结点挂到链表尾部；关键是不能在遍历还没结束时破坏掉还需要使用的指针，尤其是非叶结点的右孩子指针。

**推演**：  

二叉树结点定义可写成：

```c
typedef struct BiTNode {
    ElemType data;
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;
```

设全局指针：

```c
BiTree head = NULL;   // 单链表头指针
BiTree tail = NULL;   // 单链表尾指针
```

核心算法如下：

```c
void InOrderLinkLeaves(BiTree T) {
    if (T == NULL)
        return;

    // 先处理左子树，保证左边的叶结点先被链接
    InOrderLinkLeaves(T->lchild);

    // 判断当前结点是否为叶结点
    if (T->lchild == NULL && T->rchild == NULL) {
        if (head == NULL) {
            head = tail = T;          // 第一个叶结点
        } else {
            tail->rchild = T;         // 用右指针域作为链表 next
            tail = T;                 // 更新尾指针
        }
    }

    // 再处理右子树
    InOrderLinkLeaves(T->rchild);
}
```

最后封装：

```c
void BuildLeafList(BiTree root) {
    head = tail = NULL;
    InOrderLinkLeaves(root);
    if (tail != NULL)
        tail->rchild = NULL;   // 链表末尾置空
}
```

为什么中序遍历能保证从左到右？

对于任意一棵子树 $T$，算法输出的叶子顺序满足：

$$
\text{叶子顺序}(T)=
\text{叶子顺序}(T.lchild),\ 
(\text{若 }T\text{ 为叶结点则输出 }T),\ 
\text{叶子顺序}(T.rchild)
$$

因为左子树中的所有叶结点都位于当前结点左侧，右子树中的所有叶结点都位于当前结点右侧，所以先递归左子树、再处理当前叶结点、最后递归右子树，正好是按从左到右输出叶结点。

为什么不会破坏二叉树的遍历？

因为在链接过程中，只有 `tail->rchild` 会被修改，而 `tail` 永远指向已经链入单链表的叶结点，不会是内部结点。因此非叶结点的 `rchild` 仍然保留原右孩子指针，不会影响继续遍历右子树。

时间复杂度：每个结点被访问一次，所以为 $O(n)$，其中 $n$ 为二叉树结点个数。  
空间复杂度：递归工作栈深度等于树高 $h$，所以为 $O(h)$；最坏情况下二叉树退化为单支树时，空间复杂度为 $O(n)$。

**易错点**：

1. **不使用尾指针，而是每次从头遍历找链表末尾**，会使复杂度退化为 $O(n^2)$。必须维护 `tail` 指针。
2. **误把非叶结点的右指针也修改掉**，会导致右子树丢失。应保证 `tail` 始终是叶结点，只修改叶结点的 `rchild`。
3. **用头插法**会导致叶结点顺序反过来，不符合“从左到右”，必须用尾插法。
4. **误用层序遍历**。本题“叶结点从左到右”应按二叉树的中序顺序理解，层序遍历是按层次分层的，可能破坏严格的左右位置关系。
5. **忘记考虑空树或无叶结点的情况**。此时 `head` 应保持 `NULL`，不要对空指针操作。
6. **C 语言中若不用全局变量，要使用二级指针或返回指针来修改 `head` 和 `tail`**。

**命题规律**：

本题是 408 常考的“二叉树遍历 + 链表操作”综合题。核心考点是：

- 二叉树的递归遍历；
- 单链表尾插法；
- 在遍历过程中原地修改指针，且不能破坏还未访问的树结构。

常见变式有：

1. 把叶结点按从右到左的顺序连接，只需把左右子树的递归顺序反过来；
2. 改成非递归遍历实现；
3. 统计叶结点个数并输出叶结点路径；
4. 把度为 1 或度为 2 的结点按要求串成链表；
5. 要求不用递归、只用 $O(1)$ 辅助空间等。

复习建议：熟练掌握二叉树的先序、中序、后序、层序遍历的递归与非递归写法；遇到“边遍历边改指针”的题，要特别标注哪些指针还能用、哪些已经被复用，避免破坏遍历路径。算法题作答时，最好写出“算法思想 + 核心代码 + 复杂度分析”三部分。

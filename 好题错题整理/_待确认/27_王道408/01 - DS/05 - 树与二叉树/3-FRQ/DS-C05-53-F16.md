# 综合题 第 16 题

![[_Attachments/题目识别/27_王道408-题目/DS-C05-53-F16_题目.png|题目]]

16.【2017统考真题】请设计一个算法,将给定的表达式树(二叉树)转换为等价的中缀表达式(通过括号反映操作符的计算次序)并输出。例如,当下列两棵表达式树作为算法的输入时:

【图：第一棵表达式树：以*为根；其左子树以+为根，叶子为a和b；其右子树以*为根，其左子树为叶子c，其右子树以-为根，叶子为d。第二棵表达式树：以+为根；其左子树以*为根，叶子为a和b；其右子树以-为根，其左子树为叶子c，其右子树为叶子d。】

输出的等价中缀表达式分别为 $(a+b)*(c*(-d))$ 和 $(a*b)+(-(c-d))$.

二叉树结点定义如下:
```c
typedef struct node
{
    char data[10];              //存储操作数或操作符
    struct node *left, *right;
} BTree;
```
要求:
1) 给出算法的基本设计思想.
2) 根据设计思想，采用$C$或$C++$语言描述算法，关键之处给出注释.

## DeepSeek V4 Flash Max 解析

**答案**：采用带“是否根结点”标记的递归遍历算法：二元运算符按“左子树-根-右子树”输出，一元运算符先输出运算符再输出其唯一孩子；对每个非根的操作符结点整体加一对圆括号，即可得到等价中缀表达式。

**解题切入点**：看到“表达式树转中缀表达式”，首先应想到二叉树的中序遍历。但中序遍历只解决“左操作数、操作符、右操作数”的输出顺序，括号才是本题的关键。可以把括号理解为递归输出子表达式时的“边界符号”，就像在做 DFS 序列化时给子树加分隔符。同时要特别注意一元负号：只有一个孩子的结点不能按普通二元结点处理。

**推演**：

1. **基本设计思想**

表达式树中：
- 叶子结点是操作数；
- 内部结点是操作符；
- 二元操作符的左、右子树分别是左、右操作数；
- 一元操作符（如负号 `-`）只有一个孩子，该孩子是操作数。

对于二元操作符，采用中序遍历：

\[
L \quad op \quad R
\]

对于一元操作符，采用前缀输出：

\[
op \quad U
\]

其中 \(U\) 是唯一的操作数子树。

为了反映计算次序，凡是“非根内部结点”，都把它对应的整个子树表达式用一对括号括起来。根结点是最外层的运算，不加最外层括号。

2. **递归形式化描述**

设函数 \(F(v,d)\) 表示输出以 \(v\) 为根的子树对应的中缀表达式，其中 \(d=0\) 表示 \(v\) 是整棵表达式树的根，\(d>0\) 表示 \(v\) 不是根。

\[
F(v,d)=
\begin{cases}
\mathrm{data}(v), & v\text{ 是操作数}\\[2mm]
\mathrm{op}(v)\,F(c,1), & v\text{ 是一元操作符且 } d=0\\[2mm]
\bigl(\mathrm{op}(v)\,F(c,1)\bigr), & v\text{ 是一元操作符且 } d>0\\[2mm]
F(L,1)\,\mathrm{op}(v)\,F(R,1), & v\text{ 是二元操作符且 } d=0\\[2mm]
\bigl(F(L,1)\,\mathrm{op}(v)\,F(R,1)\bigr), & v\text{ 是二元操作符且 } d>0
\end{cases}
\]

其中 \(L\)、\(R\) 分别表示二元操作符的左右孩子，\(c\) 表示一元操作符的唯一孩子。

3. **算法代码**

```c
#include <stdio.h>

typedef struct node
{
    char data[10];          //存储操作数或操作符
    struct node *left, *right;
} BTree;

// depth = 0 表示当前结点是整棵表达式树的根；depth > 0 表示非根
void ToInfix(BTree *root, int depth)
{
    if (root == NULL)
        return;

    // 叶子结点：操作数，直接输出
    if (root->left == NULL && root->right == NULL)
    {
        printf("%s", root->data);
        return;
    }

    // 只有一个孩子：按一元运算符处理，例如负号 '-'
    if (root->left == NULL || root->right == NULL)
    {
        if (depth > 0)
            printf("(");

        printf("%s", root->data);          // 先输出运算符
        ToInfix(root->left, depth + 1);    // 输出唯一的孩子
        ToInfix(root->right, depth + 1);

        if (depth > 0)
            printf(")");

        return;
    }

    // 两个孩子都非空：二元运算符，按中序输出
    if (depth > 0)
        printf("(");

    ToInfix(root->left, depth + 1);
    printf(" %s ", root->data);            // 左右加空格，仅为与题面格式一致
    ToInfix(root->right, depth + 1);

    if (depth > 0)
        printf(")");
}

void PrintExpr(BTree *root)
{
    ToInfix(root, 0);
    printf("\n");
}
```

例如题中第一棵表达式树，输出为：

\[
(a + b) * (c * (-d))
\]

第二棵表达式树输出为：

\[
(a * b) + (-(c - d))
\]

4. **复杂度分析**

- 时间复杂度：每个结点访问一次，\(O(n)\)，其中 \(n\) 为二叉树结点个数。
- 空间复杂度：递归栈深度等于树高，最坏情况下为 \(O(n)\)，平均/一般记为 \(O(h)\)。

**易错点**：

- 只做普通中序遍历而不加括号，会丢失操作符的计算次序。例如第一棵可能被错误输出为 `a + b * c * -d`，不符合原表达式树含义。
- 把根结点也加括号，会得到 `((a + b) * (c * (-d)))`，虽然等价，但不符合题面示例形式。根结点不应加最外层括号。
- 把只有一个孩子的结点仍按二元结点处理，会导致一元负号位置错误。例如第二棵树的 `-(c - d)` 可能被错误输出为 `((c - d)-)`。
- 叶子结点不需要加括号，不能对操作数也统一加括号。
- `data` 是字符串数组，输出时用 `%s`，不要用 `==` 比较字符。

**命题规律**：本题是“二叉树遍历 + 表达式处理”的典型 408 综合题。考点定位在树的递归遍历，尤其是对遍历结果增加上下文信息（如深度、括号、优先级）的能力。常见变式有：表达式树转前缀/后缀表达式、由中缀表达式建表达式树、利用栈对表达式树求值、输出无多余括号的中缀表达式等。复习时应熟练掌握二叉树递归遍历框架，并注意一元运算符、根结点边界、括号生成等细节。

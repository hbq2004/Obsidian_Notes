## DeepSeek V4 Flash Max 解析

**答案**  
题4：从 $v_i$ 出发分别做 DFS 和 BFS，若能访问到 $v_j$，则存在路径，否则不存在。  
题5：用带 `visited` 标记的 DFS 回溯，把当前路径存入 `path`，每当走到 $v_j$ 就输出，然后撤销标记并回退，即可得到全部简单路径。

**解题切入点**  
先分清题目问的是“判断可达性”还是“枚举所有路径”。

- 题4只问“是否存在路径”，等价于从 $v_i$ 出发能否到达 $v_j$，所以普通 DFS/BFS 遍历即可，不需要记录完整路径。
- 题5要求“所有简单路径”，不能找到 $v_j$ 就停止，必须 DFS 回溯枚举。
- 可以类比走迷宫：`visited` 是走过的标记；只判断能否到出口，走到出口立即返回；要输出所有路线，则每到出口先记录，再退回岔路并擦掉脚印继续试。

**推演**

设顶点编号为 $0 \sim n-1$，邻接表结点定义为：

```c
#define MAXV 100

typedef struct ArcNode {
    int adjvex;               // 弧头顶点编号
    struct ArcNode *nextarc;
} ArcNode;

typedef struct VNode {
    int data;                 // 顶点信息
    ArcNode *firstarc;
} VNode;

typedef struct {
    VNode vertices[MAXV];
    int vexnum, arcnum;
} ALGraph;

int visited[MAXV];
```

下面的算法直接扫描邻接表单链表，等价于在邻接表存储结构上实现了图的基本操作。有向图只沿出边扩展。

### 题4：DFS 判定存在路径

```c
int DFSReach(ALGraph G, int u, int v) {
    visited[u] = 1;
    if (u == v) return 1;

    for (ArcNode *p = G.vertices[u].firstarc; p; p = p->nextarc) {
        int w = p->adjvex;
        if (!visited[w] && DFSReach(G, w, v))
            return 1;
    }
    return 0;
}

int ExistPath_DFS(ALGraph G, int i, int j) {
    for (int k = 0; k < G.vexnum; k++)
        visited[k] = 0;
    return DFSReach(G, i, j);
}
```

**正确性**：DFS 从 $v_i$ 出发，沿有向边不断深入，所有从 $v_i$ 可达且未访问过的顶点都会被访问到。若 $v_j$ 可达，必定在某次递归中被访问并返回真；若不可达，搜索结束后也不会访问到 $v_j$。

### 题4：BFS 判定存在路径

```c
int ExistPath_BFS(ALGraph G, int i, int j) {
    for (int k = 0; k < G.vexnum; k++)
        visited[k] = 0;

    int Q[MAXV], front = 0, rear = 0;
    visited[i] = 1;
    Q[rear++] = i;

    while (front < rear) {
        int u = Q[front++];
        if (u == j) return 1;

        for (ArcNode *p = G.vertices[u].firstarc; p; p = p->nextarc) {
            int w = p->adjvex;
            if (!visited[w]) {
                visited[w] = 1;
                Q[rear++] = w;
            }
        }
    }
    return 0;
}
```

**正确性**：BFS 按层扩展，从 $v_i$ 出发能访问到的所有顶点都会依次入队。若 $v_j$ 入队并被访问，说明存在路径；若队列为空仍未见 $v_j$，则 $v_j$ 不可达。

题4的时间复杂度为 $O(n+e)$，空间复杂度为 $O(n)$，其中 $n$ 为顶点数，$e$ 为边数。

### 题5：输出 $v_i$ 到 $v_j$ 的所有简单路径

```c
int path[MAXV], d;

void PrintPath(int d) {
    for (int k = 0; k < d; k++) {
        printf("%d", path[k]);
        if (k < d - 1) printf(" -> ");
    }
    printf("\n");
}

void DFSAllSimplePaths(ALGraph G, int u, int v) {
    visited[u] = 1;
    path[d++] = u;

    if (u == v) {
        PrintPath(d);
    } else {
        for (ArcNode *p = G.vertices[u].firstarc; p; p = p->nextarc) {
            int w = p->adjvex;
            if (!visited[w])
                DFSAllSimplePaths(G, w, v);
        }
    }

    // 回溯：撤销当前顶点的占用
    visited[u] = 0;
    d--;
}

void AllSimplePaths(ALGraph G, int i, int j) {
    for (int k = 0; k < G.vexnum; k++)
        visited[k] = 0;
    d = 0;
    DFSAllSimplePaths(G, i, j);
}
```

**正确性**：`path[0..d-1]` 始终保存从 $v_i$ 到当前顶点的一条无重复顶点路径。每进入一个新顶点，先标记 `visited`，避免路径中重复经过顶点；到达 $v_j$ 时输出当前路径。回溯时撤销标记并让 `d--`，使得同一个顶点可以在后续其他路径中被再次使用。

题5最坏情况下简单路径数量是指数级的，因此算法最坏时间复杂度为指数级；辅助空间为 $O(n)$，用于递归栈和 `path` 数组。

**易错点**

1. 忘记初始化 `visited`。每次调用前必须把所有标记清零。
2. 题4只判断是否存在路径，DFS 访问过的顶点不需要回溯；但题5输出所有路径，**必须回溯撤销 `visited`**，否则会漏解。
3. 在题5中，到达 $v_j$ 后不应再继续扩展 $v_j$ 的邻接点，否则输出的不是从 $v_i$ 到 $v_j$ 的简单路径。
4. 有向图只能沿出边搜索，即沿 `firstarc` 链走；不能把入边当作路径方向。
5. BFS 中应在顶点入队时就置 `visited = 1`，而不是出队时再置，否则可能重复入队，产生大量无效操作。
6. 题目要求用邻接表实现，不要转换成邻接矩阵再求解。

**命题规律**

这是 408 中“图的遍历应用”典型题，常考 DFS/BFS 在连通性、可达性、路径枚举中的应用。常见变式有：

- 判断无向图是否连通；
- 判断有向图中两个顶点之间是否存在路径；
- 输出两个顶点之间的所有简单路径；
- 输出长度为 $k$ 的路径；
- 判断图中是否存在回路。

复习时务必熟练掌握邻接表结构下 DFS/BFS 的手写代码，特别是 `visited` 的标记与回溯、`path` 数组的更新，以及从“是否存在路径”到“枚举所有路径”的思维转换。

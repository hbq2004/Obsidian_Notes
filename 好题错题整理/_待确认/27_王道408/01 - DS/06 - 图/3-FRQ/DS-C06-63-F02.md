# 综合题 第 2 题

![[_Attachments/题目识别/27_王道408-题目/DS-C06-63-F02_题目.png|题目]]

2. 给定一个连通无向图,采用邻接表存储,将图的所有顶点分别染成红色或蓝色,若存在一种染色方法使图中每条边的两个顶点的颜色都不相同,则称这个图能被二分.

【图：左侧为一个由7个顶点构成的无向连通图，其结构近似一个五边形并附加两个顶点。右侧为一个由7个顶点构成的无向连通图，其结构近似一个六边形并附加一个顶点。】

1) 判断上面两个无向图是否能被二分,若能被二分,则请标出每个顶点的颜色.
2) 请设计一种算法用来判断图是否能被二分,仅用语言描述算法的思想即可.
3) 给出你设计的算法的时间复杂度和空间复杂度.

## DeepSeek V4 Flash Max 解析

**答案**：两个给定无向图都不能被二分；判定算法采用“红蓝染色 + BFS/DFS”的思想，时间复杂度为 $O(n+e)$，额外空间复杂度为 $O(n)$。

**解题切入点**：看到“每条边的两个顶点颜色不同”，应立刻定位到二分图判定问题。做法不是枚举所有环，而是从某个顶点出发，用 BFS/DFS 按层数奇偶交替染色：相邻顶点必须异色，若某条边两端被迫同色，则说明图中存在奇环，不可二分。这就像给两组人交替分队，遇到矛盾就说明分组方案不存在。

**推演**：

### 1. 判定依据

设红色为 $0$，蓝色为 $1$。若图可二分，则对每条边 $(u,v)$ 都必须满足：

$$
c(u)\ne c(v)
$$

即：

$$
c(u)\oplus c(v)=1
$$

因此沿任意一条路径走，颜色都会交替变化。若图中存在奇数长度的环，则从某点出发绕环一周后，该点颜色被迫与自己相反，产生矛盾。所以：

> 无向图可二分 $\iff$ 图中不含奇环。

### 2. 判断题目给出的两个图

- **左图**：左图含有一个五边形环，环长为 $5$，是奇数环。若图中还有对角线，则会直接形成三角形，更是奇环。因此左图不能被二分。
- **右图**：右图中含有一个三角形，环长为 $3$，是奇数环。三角形中若一个顶点染红，则另外两个顶点都必须染蓝，但这两个蓝顶点之间又有边相连，矛盾。因此右图也不能被二分。

所以两个图都不存在合法染色方案，不需要标出颜色。

### 3. 判断二分图的算法

用 BFS 染色即可，算法思想如下：

1. 初始化颜色数组 `color`，全部设为 $-1$，表示未染色。
2. 任选一个起点 $s$，令 `color[s]=0`，表示红色，将 $s$ 入队。
3. 使用 BFS 遍历：
   - 出队顶点 $u$；
   - 遍历 $u$ 的所有邻接点 $v$；
   - 若 `color[v]==-1`，则令 `color[v]=1-color[u]`，即强制染成相反颜色，并入队；
   - 若 `color[v]!=-1` 且 `color[v]==color[u]`，说明边 $(u,v)$ 两端同色，直接返回“不可二分”。
4. BFS 结束后若始终无冲突，则图可二分。

关键伪代码如下：

```c
bool isBipartite(ALGraph G) {
    for (i = 0; i < G.n; i++)
        color[i] = -1;                 // 未染色

    InitQueue(Q);

    for (s = 0; s < G.n; s++) {        // 若图不连通，则每个连通分量都要判断
        if (color[s] == -1) {
            color[s] = 0;              // 染红色
            EnQueue(Q, s);

            while (!QueueEmpty(Q)) {
                DeQueue(Q, u);

                for (p = G.adjlist[u].first; p; p = p->next) {
                    v = p->adjvex;

                    if (color[v] == -1) {
                        color[v] = 1 - color[u];   // 染相反颜色
                        EnQueue(Q, v);
                    } else if (color[v] == color[u]) {
                        return false;              // 出现同色边
                    }
                }
            }
        }
    }

    return true;
}
```

也可以使用 DFS 实现：递归访问邻接点时，若未染色则染相反色；若已染色且同色则失败。本质上都是“红蓝交替染色”。

### 4. 复杂度分析

- 时间复杂度：每个顶点入队一次、出队一次，每条无向边在邻接表中对应两条边节点，因此总共扫描 $O(n+e)$ 个边节点，时间复杂度为：

$$
O(n+e)
$$

- 空间复杂度：需要 `color[]` 数组和 BFS 队列，大小均为 $O(n)$，因此额外空间复杂度为：

$$
O(n)
$$

若把邻接表存储本身计入，则存储空间为 $O(n+e)$。

**易错点**：

- 不能只检查“是否有三角形”。无向图不可二分的本质是“存在奇数环”，三角形只是最短的奇环，五边形、七边形等奇数环同样不可二分。
- 不能只从一个起点遍历一次就结束。题目虽说是连通图，但若变式为非连通图，必须对每个连通分量都进行染色判断，否则会漏判。
- 遇到已访问邻接点时，必须检查是否同色，不能直接跳过。
- 复杂度不要写成 $O(n^2)$。邻接表存储时，遍历每个顶点的邻接表总开销是 $O(n+e)$；若用邻接矩阵才是 $O(n^2)$。
- 若图不可二分，不要强行给出染色方案，因为不存在合法染色方案。

**命题规律**：本题是“图的遍历”与“图的应用”结合的综合题，核心考点是二分图判定。408 中常以选择题考查二分图与奇环的关系，以综合题或算法设计题考查 BFS/DFS 染色法。常见变式包括：判断能否将顶点分成两组、判断图中是否存在奇环、判断一个图是否为二分图等。复习时应重点掌握“邻接表 + BFS/DFS”的遍历框架，并能熟练说明“奇数环导致染色冲突”的原理。

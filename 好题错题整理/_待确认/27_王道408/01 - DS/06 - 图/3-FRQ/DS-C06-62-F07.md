# 综合题 第 7 题

![[_Attachments/题目识别/27_王道408-题目/DS-C06-62-F07_题目.png|题目]]

7.【2021统考真题】已知无向连通图$G$由顶点集$V$和边集$E$组成，$|E|>0$，当$G$中度为奇数的顶点个数为不大于2的偶数时，$G$存在包含所有边且长度为$|E|$的路径（称为$EL$路径）。设图$G$采用邻接矩阵存储，类型定义如下：

```c
typedef struct {
    int numVertices, numEdges;    //图的定义
    char VerticesList[MAXV];     //图中实际的顶点数和边数
    int Edge[MAXV][MAXV];        //顶点表。MAXV为已定义常量
} MGraph;                        //邻接矩阵
```

请设计算法intIsExistEL(MGraphG)，判断$G$是否存在$EL$路径，若存在，则返回1，否则返回0. 要求：
1) 给出算法的基本设计思想.
2) 根据设计思想，采用$C$或$C++$语言描述算法，关键之处给出注释.
3) 说明你所设计算法的时间复杂度和空间复杂度.

## DeepSeek V4 Flash Max 解析

**答案**：判断 $G$ 是否存在 $EL$ 路径，只需统计无向连通图 $G$ 中度为奇数的顶点个数；若奇度顶点数为 $0$ 或 $2$，则存在 $EL$ 路径，返回 $1$，否则返回 $0$。

**解题切入点**：看到“包含所有边且长度为 $|E|$ 的路径”，应立刻联想到“一笔画”问题，即**欧拉路径/欧拉回路**。题目给出的“奇度顶点个数为不大于 2 的偶数”正是欧拉定理的变形。因此考点定位为：**欧拉路径判定**。核心操作不是构造路径，而是计算每个顶点的度并统计奇度顶点个数。

**推演**：

### 1. 判定定理

对于无向连通图 $G=(V,E)$，欧拉路径存在的充要条件是：

$$
\text{奇度顶点个数}=0 \quad \text{或} \quad 2
$$

其中：

- 奇度顶点数为 $0$：存在欧拉回路，可以一笔画回到起点；
- 奇度顶点数为 $2$：存在欧拉通路，从一个奇度顶点出发，到另一个奇度顶点结束。

又因为无向图中所有顶点度数之和等于 $2|E|$，由握手定理可知，奇度顶点个数一定是偶数，所以“不大于 2 的偶数”只可能是：

$$
0 \text{ 或 } 2
$$

题目已说明 $G$ 是连通图，且 $|E|>0$，因此不需要再额外判断连通性。

### 2. 算法基本设计思想

遍历邻接矩阵：

- 对每个顶点 $i$，统计其所在行的非零元素个数，即顶点 $i$ 的度；
- 若度为奇数，则奇度顶点计数器 `odd++`；
- 最后若 `odd == 0` 或 `odd == 2`，返回 $1$，否则返回 $0$。

### 3. C/C++ 算法描述

```c
int IsExistEL(MGraph G) {
    int odd = 0;                 // 奇度顶点个数
    int i, j;

    for (i = 0; i < G.numVertices; i++) {
        int degree = 0;          // 顶点 i 的度

        // 邻接矩阵第 i 行中 1 的个数即为顶点 i 的度
        for (j = 0; j < G.numVertices; j++) {
            if (G.Edge[i][j] == 1) {
                degree++;
            }
        }

        // 统计奇度顶点
        if (degree % 2 == 1) {
            odd++;
        }
    }

    // EL 路径存在条件：奇度顶点数为 0 或 2
    if (odd == 0 || odd == 2) {
        return 1;
    } else {
        return 0;
    }
}
```

### 4. 正确性说明

- 如果奇度顶点数为 $0$，所有顶点度数都为偶数，由欧拉定理知存在欧拉回路，回路包含所有边且长度为 $|E|$，因此是 $EL$ 路径；
- 如果奇度顶点数为 $2$，存在从其中一个奇度顶点到另一个奇度顶点的欧拉通路，也满足题意；
- 如果奇度顶点数不是 $0$ 或 $2$，则图中不可能存在经过每条边恰好一次的路径，返回 $0$。

### 5. 复杂度分析

设 $n=|V|$。

- 时间复杂度：需要遍历整个邻接矩阵，双重循环规模为 $n\times n$，故为：

$$
O(n^2)
$$

- 空间复杂度：只使用了常数个辅助变量，故为：

$$
O(1)
$$

**易错点**：

- 容易漏掉 `odd == 2` 的情况，只判断 `odd == 0`。实际上存在欧拉通路时奇度顶点数为 $2$，也必须返回 $1$。
- 不要把“不大于 2 的偶数”误解成只有 $0$。题目中的条件允许奇度顶点数为 $2$。
- 计算顶点度时，邻接矩阵是对称的，**行的和就是该顶点的度**，不要将行和列都相加导致重复计算。
- 如果题目没有说明图连通，则还需要先用 DFS/BFS 检查所有非零度顶点是否位于同一个连通分量；本题已明确“无向连通图”，因此可省略。
- 不要尝试去构造 $EL$ 路径，本题只要求判断是否存在，不需要输出路径。

**命题规律**：

本题是典型的“经典图论定理 + 数据结构遍历”综合题。408 中常把欧拉路径判定与图的存储结构结合考查：

- 已知邻接矩阵时，时间复杂度通常是 $O(n^2)$；
- 若改考邻接表，则统计度数可做到 $O(n+e)$；
- 常见变式：判断是否存在欧拉回路，判断有向图是否存在欧拉路径，或要求输出一条欧拉路径（此时需用 Hierholzer 算法）。

复习时应熟练掌握：

- 无向图欧拉路径/回路的判定条件；
- 图的邻接矩阵、邻接表存储下求顶点度的方法；
- 连通性检查的 DFS/BFS 写法；
- 欧拉路径与哈密顿路径的区别。

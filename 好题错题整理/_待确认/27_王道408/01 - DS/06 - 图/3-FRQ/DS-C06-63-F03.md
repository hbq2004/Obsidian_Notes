## DeepSeek V4 Flash Max 解析

**答案**：判断无向图 $G$ 是否连通，并统计其边数 $m$；若 $G$ 连通且 $m = n-1$（$n$ 为顶点数），则 $G$ 是一棵树，返回 `true`，否则返回 `false`。

**解题切入点**：看到“判断无向图是否为一棵树”，首先抓住树的等价定义：**连通且无环**。在无向图中，还有一个更便于算法实现的等价条件：**连通且边数等于顶点数减 1**。图的遍历（DFS/BFS）天然适合判断连通性，而边数可以通过邻接表统计每个顶点的度得到。这就像“查户口”：先确认所有人都在同一个连通块里，再确认关系数恰好比人数少 1。

**推演**：

设无向图 $G=(V,E)$，$n=|V|$，$m=|E|$。

判定依据为：
$$
G \text{ 是树} \iff G \text{ 连通且 } m=n-1.
$$

理由如下：

- 若 $G$ 是树，则由定义 $G$ 连通且无环；树有 $n-1$ 条边。
- 若 $G$ 连通且 $m=n-1$，假设 $G$ 中存在回路，删去回路上的任意一条边，$G$ 仍然连通，但边数变为 $n-2$；而连通 $n$ 个顶点的无向图至少需要 $n-1$ 条边，矛盾。因此 $G$ 无环，从而是树。

算法步骤：

1. 从任意顶点（如顶点 0）出发做 DFS 或 BFS。
2. 用 `visited` 数组记录已访问顶点，统计实际访问到的顶点数 `cnt`。
3. DFS 结束后，若 `cnt != n`，说明图不连通，返回 `false`。
4. 若图连通，再遍历邻接表，统计所有顶点的度之和 `sum`。无向图中每条边贡献 2 个度，所以边数 $m = \dfrac{sum}{2}$。
5. 若 $m = n-1$，返回 `true`，否则返回 `false`。

关键代码思路如下（邻接表存储）：

```c
int visited[MAXV];
int cnt = 0;

void DFS(AGraph *G, int v) {
    visited[v] = 1;
    cnt++;
    for (ArcNode *p = G->adjlist[v].first; p; p = p->next) {
        int u = p->adjvex;
        if (!visited[u])
            DFS(G, u);
    }
}

bool IsTree(AGraph *G) {
    if (G->n <= 0) return false;

    for (int i = 0; i < G->n; i++)
        visited[i] = 0;
    cnt = 0;

    DFS(G, 0);                     // 从顶点 0 开始遍历

    if (cnt != G->n)               // 不连通
        return false;

    int sum = 0;
    for (int i = 0; i < G->n; i++)
        for (ArcNode *p = G->adjlist[i].first; p; p = p->next)
            sum++;                 // 度之和

    return sum / 2 == G->n - 1;    // 边数等于 n-1
}
```

复杂度：邻接表存储时，DFS 为 $O(n+m)$，统计度之和也是 $O(n+m)$，总时间复杂度 $O(n+m)$；空间复杂度 $O(n)$（`visited` 数组加递归栈）。若用邻接矩阵，时间复杂度为 $O(n^2)$。

**易错点**：

1. **只判断边数 $m=n-1$，不判断连通性**。反例：$n=4$，三个顶点构成三角形，第四个顶点孤立，此时 $m=3=n-1$，但图不连通，不是树。
2. **只判断连通性，不判断边数**。例如三角形 $n=3$，图连通但 $m=3 \ne 2$，不是树。
3. **DFS 判环时误把“已访问且不是父结点”当成有环**。在一条无环路径 $0-1-2$ 中，从 0 访问完 1 后，0 的邻接点 1 已经访问过且不是 0 的父结点，简单按此判断会误报有环。用“连通性 + 边数 $n-1$”可规避。
4. **统计度之和后忘记除以 2**。无向图中每条边在邻接表中出现两次，度之和 $=2m$。
5. **忽略 $n=1$ 的特例**。单顶点无边连通，$m=0=n-1$，是一棵树。
6. **未重置 `visited` 数组**，导致多组测试数据时判断错误。

**命题规律**：本题属于“图的遍历”和“图的基本性质”结合的综合题。408 常考判断图的连通性、有无环、是否为一棵树，常见的变式有：

- 用 DFS/BFS 求连通分量个数；
- 用并查集判断无向图是否有环；
- 判断有向图是否为有向树；
- 给出邻接矩阵或邻接表，判断图是否满足树的条件。

复习时建议熟练掌握 DFS/BFS 的遍历模板，牢记无向图中“度之和 $=2m$”以及“树等价于连通且 $m=n-1$”这两个核心结论；注意处理 $n=1$ 的边界情况，并会分析邻接表/邻接矩阵下的时间空间复杂度。

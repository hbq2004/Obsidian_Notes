11. 在有向图的邻接表存储结构中，顶点$v$在边表中出现的次数是 ( )。
(A) 顶点$v$的度
(B) 顶点$v$的出度
(C) 顶点$v$的入度
(D) 依附于顶点$v$的边数

## DeepSeek V4 Flash Max 解析

**答案**：选 C。在有向图的邻接表（出边表）中，顶点 $v$ 在边表中出现的次数等于以 $v$ 为终点的有向边数，即 $v$ 的入度。

**解题切入点**：
拿到题先确认：这是“有向图 + 邻接表”。有向图的邻接表通常存储出边，即对每条弧 $\langle u,v\rangle$，在 $u$ 的边表中存一个值为 $v$ 的结点。

因此，问“顶点 $v$ 在边表中出现几次”，不能理解成“$v$ 自己的边表有多长”，而要问：哪些顶点的边表里存了 $v$？这正好对应“有哪些边指向 $v$”，也就是入度。  
可简记为：  
- $v$ 出现在别人的边表中 $\Rightarrow$ 入度；  
- $v$ 自己的边表长度 $\Rightarrow$ 出度。

**推演**：
设 $G=(V,E)$，对任意有向边 $\langle u,v\rangle\in E$，在邻接表中会把它挂在顶点 $u$ 的边表末尾，边表结点中记录 $adjvex=v$。

所以：

- 顶点 $u$ 自己的边表长度 $=OD(u)$，即出度；
- 所有边表中值为 $v$ 的结点总数：
$$
|\{\langle u,v\rangle \in E\}|=ID(v)
$$
即入度。

例如有弧 $\langle a,b\rangle,\ \langle c,b\rangle$，则顶点 $b$ 会出现在 $a$ 和 $c$ 的边表中，共出现 $2$ 次，而 $ID(b)=2$。  
若再用代码表示统计过程：

```c
for (u = 1; u <= n; u++) {
    p = adj[u].first;          // u 的出边链表
    while (p != NULL) {
        indegree[p->adjvex]++; // 顶点 p->adjvex 在边表中出现一次
        p = p->next;
    }
}
```

遍历结束后，`indegree[v]` 就是顶点 $v$ 在边表中出现的次数，即入度。

因此：
- A 顶点 $v$ 的度 $=ID(v)+OD(v)$，一般大于入度；
- B 顶点 $v$ 的出度是 $v$ 自己边表的长度；
- D 依附于顶点 $v$ 的边数在有向图中也是 $ID(v)+OD(v)$；
- C 入度才等于顶点 $v$ 在边表中出现的次数。

**易错点**：
1. 容易把“顶点 $v$ 在边表中出现”误认为“顶点 $v$ 的边表中有多少个结点”，前者是入度，后者是出度。  
2. 忽略有向边的方向：邻接表中边表结点存放的是弧头顶点，所以 $v$ 出现是由指向 $v$ 的边造成的。  
3. 若题目改成“逆邻接表”，则边表存储的是入边，$v$ 在边表中出现的次数会变成出度，注意区分。

**命题规律**：
本题属于图存储结构的基础概念题，常考邻接表中有向图顶点出度、入度与边表的关系。常见变式有：  
- 给定邻接表求某顶点入度/出度；  
- 比较用邻接表求入度和出度的复杂度，求入度通常需扫描所有边表；  
- 在拓扑排序中利用入度数组初始化；  
- 改为“逆邻接表”或“十字链表”进行辨析。

复习时应把邻接表、逆邻接表、十字链表对比理解，明确每条弧在存储结构中出现的位置，并能熟练写出统计入度、出度的扫描算法。

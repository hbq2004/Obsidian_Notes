# 选择题 第 10 题

![[_Attachments/题目识别/27_王道408-题目/DS-C06-64-M10_题目.png|题目]]

10. 用 $Dijkstra$ 算法求一个带权有向图的从顶点 0 出发的最短路径，在算法执行的某个时刻，已求得的最短路径的顶点集合 $S = \{0,2,3,4\}$，下一个选取的目标顶点是顶点 1，则可能修改的最短路径是 ( )
(A) 从顶点 0 到顶点 3 的最短路径
(B) 从顶点 0 到顶点 2 的最短路径
(C) 从顶点 2 到顶点 4 的最短路径
(D) 从顶点 0 到顶点 1 的最短路径

## DeepSeek V4 Flash Max 解析

**答案**：选 **D**，即可能被修改的是“从顶点 0 到顶点 1 的最短路径”（在顶点 1 被正式选入 $S$ 之前；一旦选入即固定）。

**解题切入点**：拿到题先抓住 Dijkstra 的核心分类：$S$ 是“已经确定最短路径的顶点集合”，$V-S$ 是“仍可能被更新的候选集合”。这就像考试放榜：已经锁定名单的人，成绩不会再改；还没锁定的人，成绩可能被刷新。本题说“下一个选取的目标顶点是顶点 1”，说明 $1\notin S$，所以它对应的 $0\to1$ 路径仍处于“可能被修改”的状态。

**推演**：

Dijkstra 算法维护：

- $\mathrm{dist}[v]$：从源点 0 到顶点 $v$ 的当前最短路径长度；
- $S$：已经求得最短路径的顶点集合；
- 每次从 $V-S$ 中选出 $\mathrm{dist}$ 最小的顶点 $u$ 加入 $S$；
- 然后用 $u$ 去松弛所有未入 $S$ 的邻接点 $v$：

$$
\mathrm{dist}[v]\leftarrow \min\{\mathrm{dist}[v],\ \mathrm{dist}[u]+w(u,v)\}
$$

关键代码思路如下：

```c
while (S 未包含所有顶点) {
    u = 在 V-S 中 dist 最小的顶点;
    S = S ∪ {u};
    for (v 不属于 S 且存在边 u->v) {
        if (dist[u] + w(u,v) < dist[v])
            dist[v] = dist[u] + w(u,v);   // 修改从 0 到 v 的最短路径
    }
}
```

本题当前 $S=\{0,2,3,4\}$，下一个选取的是顶点 1，因此 $1\notin S$。

逐项判断：

- **A**：从顶点 0 到顶点 3 的最短路径。顶点 3 已经在 $S$ 中，最短路径已确定，不会再被修改。
- **B**：从顶点 0 到顶点 2 的最短路径。顶点 2 已经在 $S$ 中，同样不会再被修改。
- **C**：从顶点 2 到顶点 4 的最短路径。Dijkstra 是单源最短路径算法，只维护从源点 0 出发到各顶点的最短路径，不独立维护“从 2 到 4”的路径；而且 4 也已在 $S$ 中。
- **D**：从顶点 0 到顶点 1 的最短路径。顶点 1 尚未进入 $S$，其 $\mathrm{dist}[1]$ 仍是候选值，所以可能在选入前被新加入 $S$ 的中间顶点松弛修改。

因此选 **D**。

**易错点**：

1. 误以为进入 $S$ 的顶点仍可能被后续顶点更新。Dijkstra 在非负权图中保证：一旦顶点进入 $S$，其最短路径长度就是最终值，不再修改。
2. 不要把“下一个选取顶点 1”理解成“选入 1 后还会回头修改 1”。顶点 1 被选入 $S$ 后，$\mathrm{dist}[1]$ 立刻固定；题目考查的是“在它尚未进入 $S$ 前，仍可能被修改”。
3. 不要把选项 C 的“从 2 到 4”误认为源点路径。Dijkstra 是单源算法，维护的是从顶点 0 出发的最短路径。
4. “可能修改”不等于“一定修改”；需要满足实际存在边且满足松弛条件 $\mathrm{dist}[u]+w(u,v)<\mathrm{dist}[v]$。

**命题规律**：本题定位是“图—单源最短路径—Dijkstra 算法”，属于 408 选择题中的高频基础考点。常见变式有：给出部分 $S$ 集合和 $\mathrm{dist}$ 数组判断下一选中顶点；给出图要求手算模拟若干轮松弛；判断某条路径是否可能被更新。复习时要重点理解 $S$ 集合的含义、松弛操作的执行范围，以及 Dijkstra 算法要求边权非负的前提。

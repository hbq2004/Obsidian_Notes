## DeepSeek V4 Flash Max 解析

**答案**：该有向图的所有拓扑序列共有 \(5\) 个，选 C。核心是先固定唯一源点 \(A\) 与唯一汇点 \(G\)，再数中间 \(4\) 个顶点的受限排列。

**解题切入点**：拿到拓扑排序计数题，不要一开始就全排列；先找“必在队首/队尾”的顶点。本题 \(A\) 是唯一入度为 0 的顶点，必在首位；\(G\) 是唯一出度为 0 的顶点，必在末尾；中间只剩 \(C,D,E,F\) 的受限排列。这等价于“有约束排队”。

**推演**：

图的偏序关系为：
\[
A<B,\quad B<C,\ B<D,\quad C<E,\ C<F,\quad D<E,\ D<G,\quad E<G,\ F<G
\]
其中 \(x<y\) 表示 \(x\) 排在 \(y\) 前。

1. \(A\) 是唯一入度为 0 的顶点，所以 \(A\) 必为第 1 个；又因为 \(A\to B\)，且 \(B\) 无其他前驱，所以前两个顶点固定为：
\[
A,\ B
\]

2. \(G\) 是唯一出度为 0 的顶点，所以 \(G\) 必为最后一个。于是只需在 \(AB\) 与 \(G\) 之间排列 \(C,D,E,F\)。

3. 中间四个顶点的约束为：
\[
C<E,\quad C<F,\quad D<E
\]
没有 \(C,D\) 之间或 \(E,F\) 之间的先后约束。

4. 按 \(E\) 在 \(C,D,E,F\) 四个位置中的位置分类：

- 若 \(E\) 在第 4 位：前三位为 \(C,D,F\)，只需满足 \(C<F\)。三元素全排列有 \(3!=6\) 种，其中 \(C\) 在 \(F\) 前恰好占一半，故有 \(3\) 种。

- 若 \(E\) 在第 3 位：前两位必须是 \(C,D\)，有 \(2! = 2\) 种顺序；第 4 位为 \(F\)，且 \(C<F\) 自动成立，故有 \(2\) 种。

- \(E\) 在第 1、2 位不可能，因为 \(C\) 和 \(D\) 都必须在 \(E\) 之前。

所以：
\[
N=3+2=5
\]

这 5 个拓扑序列分别为：
\[
A B C D E F G,\quad A B C D F E G,\quad A B C F D E G,\quad A B D C E F G,\quad A B D C F E G
\]

若写程序枚举，可使用 Kahn 算法的思路加 DFS 回溯：每层枚举当前入度为 0 且未被选过的顶点，选择后删除其出边并递归，回溯时恢复现场，选出全部顶点时计数加 1。

**易错点**：

- 忘记 \(A,B\) 固定。\(A\) 是唯一源点，不可能有其他开头。
- 没发现 \(G\) 必在最后，导致枚举中间点时多算或漏算。
- 误以为 \(C,D\) 完全对称。实际上先取 \(C\) 后，\(F\) 可能抢在 \(D\) 前；先取 \(D\) 后则必须先取 \(C\)。
- 误以为 \(E,F\) 有先后顺序。图中没有 \(E\to F\) 或 \(F\to E\)，所以 \(EF\) 和 \(FE\) 两种顺序都合法。

**命题规律**：本题属于“图的应用——拓扑排序”中的计数题。常见变式有：判断某个序列是否为拓扑序列、判断拓扑序列是否唯一、增加或删除一条边使拓扑序列唯一等。复习时重点掌握 Kahn 算法中“每次选择入度为 0 的顶点”这一核心思想；若问多个拓扑序列，可画决策树或按强约束点分类计数。

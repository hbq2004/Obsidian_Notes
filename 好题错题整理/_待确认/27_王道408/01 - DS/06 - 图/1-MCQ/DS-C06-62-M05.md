# 选择题 第 5 题

![[_Attachments/题目识别/27_王道408-题目/DS-C06-62-M05_题目.png|题目]]

5. 一个有 $n$ 个顶点的图用邻接矩阵 $A$ 表示，若图为有向图，顶点 $v_i$ 的入度是 ( ); 若图为无向图，顶点 $v_i$ 的度是 ( ).
A. $\sum_{i=1}^{n} A[i][j]$
B. $\sum_{j=1}^{n} A[j][i]$
C. $\sum_{i=1}^{n} A[j][i]$
D. $\sum_{j=1}^{n} A[j][i] \text{ 或 } \sum_{j=1}^{n} A[i][j]$

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C06-62-M05_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：第一空选 **B**，第二空选 **D**。即有向图顶点 $v_i$ 的入度是第 $i$ 列元素之和；无向图顶点 $v_i$ 的度是第 $i$ 行元素之和（也等于第 $i$ 列元素之和）。

**解题切入点**：拿到“邻接矩阵 + 度/入度”先定位到图的存储结构。邻接矩阵中“第 $i$ 行”表示从 $v_i$ 出发能到达谁，“第 $i$ 列”表示谁能到达 $v_i$；所以入度看第 $i$ 列，出度看第 $i$ 行。无向图矩阵对称，行列等价。这就像二维数组按行/列求和，关键是固定顶点编号 $i$ 后看哪个下标在变化。

**推演**：  
按 408 默认约定，$A[i][j]=1$ 表示存在从 $v_i$ 到 $v_j$ 的边（无向图则存在边 $(v_i,v_j)$）。

1. 有向图：

$$ \text{outdegree}(v_i)=\sum_{j=1}^{n}A[i][j],\qquad
\text{indegree}(v_i)=\sum_{j=1}^{n}A[j][i]. $$

所以入度是第 $i$ 列之和，对应选项 **B**。  
选项 A 是第 $j$ 列之和，是 $v_j$ 的入度；选项 C 是第 $j$ 行之和；选项 D 的第一项虽然是入度，但第二项 $\sum_{j=1}^{n} A[i][j]$ 是出度，有向图中二者不一定相等，故 D 不能作为有向图入度。

代码思路：

```c
// 有向图：v_i 的入度
int indeg = 0;
for (int j = 1; j <= n; ++j)
    indeg += A[j][i];

// 无向图：v_i 的度
int deg = 0;
for (int j = 1; j <= n; ++j)
    deg += A[i][j];   // 或 deg += A[j][i];
```

2. 无向图：  
因为无向图的邻接矩阵对称，

$$A[i][j]=A[j][i],$$

所以

$$\deg(v_i)=\sum_{j=1}^{n}A[i][j]=\sum_{j=1}^{n}A[j][i].$$

对应选项 **D**。

**易错点**：
- 入度看成行和。有向图行和是出度，列和才是入度。
- 下标写反：$\sum_{j=1}^{n}A[j][i]$ 固定第二个下标 $i$，对第一个下标求和；不要误写成 $\sum_{j=1}^{n}A[i][j]$。
- 选项偷换顶点：A、C 中固定的是 $j$，计算的是 $v_j$ 的度/出度，不是 $v_i$。
- 无向图求度时不要“行和 + 列和”，二者相等，相加会重复计数。
- 有向图中不要把“入度”写成“行和或列和”，只有无向图才两者相等。

**命题规律**：  
本题属于图的基本概念与邻接矩阵存储的送分题。常见变式包括：求有向图出度/入度、无向图度、根据邻接矩阵判断有向/无向、邻接矩阵与邻接表复杂度对比等。复习时建议熟记“行出列入”，并用 $3\times3$ 的小矩阵手算验证；选择题中特别注意公式里的求和下标是 $i$ 还是 $j$，防止被偷换顶点。

# 选择题 第 2 题

![[_Attachments/题目识别/27_王道408-题目/DS-C06-61-M02_题目.png|题目]]

2. 若从无向图的任意顶点出发进行一次深度优先搜索即可访问所有顶点,则该图一定是 ( ).
(A) 强连通图
(B) 连通图
(C) 有回路
(D) 一棵树

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C06-61-M02_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 **B．连通图**。核心：无向图中一次 DFS 能访问到的顶点，恰好就是起点所在的连通分量；任意起点都能访问全部顶点，说明全图只有一个连通分量，即连通图。

**解题切入点**：  
拿到题目先抓两个关键词：“无向图”和“DFS 一次访问所有顶点”。这直接对应考点：**DFS 与连通分量的关系**。  
可以类比：DFS 一次能走到的范围，就是起点所在的“连通块”。如果从任何一个房间出发都能走遍整栋楼的所有房间，说明整栋楼没有隔成互不相通的区域，所有房间在同一个连通区域内。

**推演**：  
设图 $G=(V,E)$，$|V|=n$。从某个顶点 $s$ 出发做 DFS，访问集合记为 $R(s)$。

在无向图中，DFS 从 $s$ 出发能访问的顶点满足：

$$
R(s)=\{v\in V \mid v \text{ 与 } s \text{ 之间有路径}\}
$$

也就是说，$R(s)$ 恰好是 $s$ 所在的连通分量。

题干说“从任意顶点出发进行一次 DFS 即可访问所有顶点”，即对任意 $s\in V$，都有：

$$
|R(s)|=n
$$

这意味着每个顶点都能到达图中所有其他顶点。任取两个顶点 $u,v\in V$，因为 $u\in R(v)$，所以 $u$ 与 $v$ 之间有路径。因此任意两点连通，图 $G$ 是连通图。

反过来，如果 $G$ 是连通图，则从任意顶点出发 DFS 也一定能访问所有顶点。所以题设与“连通图”等价。

排除其他选项：

- **A．强连通图**：强连通是有向图的概念，题目明确说是无向图，不能选。
- **C．有回路**：连通图不一定有回路。例如两个顶点一条边，是无环连通图，DFS 也能访问所有顶点。
- **D．一棵树**：树是“连通且无回路”的特殊图。但有回路的连通图也满足题设，例如三角形 $C_3$，它不是树。

代码判断思路也很简单：

```
visited = [False] * n
count = 0

def dfs(u):
    visited[u] = True
    count += 1
    for v in adj[u]:
        if not visited[v]:
            dfs(v)

dfs(0)  # 任选一个起点
return count == n
```

如果从起点 DFS 后访问了全部 $n$ 个顶点，则在无向图中该图就是连通图。

**易错点**：  
1. **误选 A“强连通图”**：看到“任意顶点都能访问所有顶点”就联想到强连通，但强连通是**有向图**术语；无向图中对应概念是“连通”。  
2. **误选 D“一棵树”**：树要求连通且无回路，但题目只保证了连通性，没有排除回路；连通图可以带环。例如三个顶点的环 $C_3$，从任意顶点 DFS 都能访问全部顶点，但它不是树。  
3. **误选 C“有回路”**：以为 DFS 必须靠回路才能返回继续遍历，实际上树这种无环连通图也满足条件。  
4. **混淆“任意顶点”与“某一顶点”**：在无向图中，从某个顶点 DFS 能访问全部顶点已经能推出连通；但若是有向图，二者区别很大。

**命题规律**：  
本题属于图遍历基础题，考点是 **DFS 遍历与连通分量的关系**，常在选择题中结合有向图/无向图概念辨析。常见变式有：

- 有向图中，从任意顶点出发 DFS 都能访问所有顶点 ⇒ 强连通图。  
- 有向图中，从一个顶点出发 DFS 能访问所有顶点 ⇒ 只能说明该顶点到其他顶点可达，不能说明强连通。  
- 统计无向图中连通分量个数：DFS/BFS 调用次数就是连通分量数。  
- 判断一棵树：连通且边数 $m=n-1$，或 DFS 访问全部顶点且无回路。

复习时建议把 DFS/BFS 的一次调用理解为“探索一个连通块”，并注意区分无向图的“连通”和有向图的“强连通”。

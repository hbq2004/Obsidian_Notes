# 选择题 第 15 题

![[_Attachments/题目识别/27_王道408-题目/DS-C06-63-M15_题目.png|题目]]

15.【2012统考真题】对有 $n$ 个顶点、 $e$ 条边且使用邻接表存储的有向图进行广度优先遍历，其算法的时间复杂度为( ).
A. $O(n)$
B. $O(e)$
C. $O(n+e)$
D. $O(ne)$

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C06-63-M15_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 C，即 $O(n+e)$。邻接表存储的有向图做 BFS 时，每个顶点最多入队/出队一次，每条有向边最多被扫描一次，加上对 $n$ 个顶点的初始化和遍历检查，总时间复杂度为 $O(n+e)$。

**解题切入点**：看到“邻接表 + BFS + 时间复杂度”，立即想 BFS 的两个基本动作：“队列入出队操作”和“扫描邻接表”。每个顶点只进队一次，所以点操作 $O(n)$；每条边只属于某个顶点的邻接表，所以边扫描总和 $O(e)$。可以类比“发传单”：若有 $n$ 个路口、$e$ 条单行道，从路口出发查看每条路，总共查看的路数是 $e$，不是 $ne$。

**推演**：

有向图的邻接表由顶点表（$n$ 个表头）和边表（$e$ 个边结点）组成，每条弧只存放在其弧尾顶点的邻接表中。标准 BFS 代码思路为：

```
初始化 visited[0..n-1] = false;
for (v = 0; v < n; v++) {
    if (!visited[v]) {
        visited[v] = true; v 入队;
        while (队列不空) {
            u 出队;
            for (p = adj[u]; p != NULL; p = p->next) {
                w = p->adjvex;
                if (!visited[w]) {
                    visited[w] = true; w 入队;
                }
            }
        }
    }
}
```

逐项统计：

- 初始化 `visited` 数组需要 $O(n)$；
- 外层循环逐一检查各顶点，每个顶点最多入队、出队一次，这部分总代价 $O(n)$；
- 当顶点 $u$ 出队后扫描 `adj[u]`，其中存储的是从 $u$ 出发的所有出边。因为每个顶点最多出队一次，所以每条有向边最多被扫描一次，$e$ 条边扫描总量为 $O(e)$。

因此

$$
T(n,e)=O(n)+O(n)+O(e)=O(n+e).
$$

严格说，若只从单个源点 BFS，访问的是可达子图，扫描边的总量不超过 $O(e)$，初始化仍需 $O(n)$，用全图规模表示仍为 $O(n+e)$。

**易错点**：

1. 只看到“每个顶点访问一次”而漏掉扫描邻接表，容易误选 $O(n)$。
2. 只看到“邻接表中共有 $e$ 条边”而忽略 `visited` 数组初始化和对 $n$ 个顶点的外层检查，容易误选 $O(e)$。
3. 选 $O(ne)$ 是把邻接表误当成邻接矩阵，或误以为每个顶点都要检查所有边；邻接表存储时每条边只出现一次，没有 $n$ 倍边数的工作量。
4. 要注意“入队时置 `visited`”的标准写法，否则同一顶点可能被重复入队，队列空间可能从 $O(n)$ 变差；时间复杂度上界虽仍可由 $O(n+e)$ 概括，但标准 BFS 必须避免重复入队。
5. 无向图邻接表有 $2e$ 个边结点，不过 $O(2e)=O(e)$，故 BFS 时间复杂度同样是 $O(n+e)$。

**命题规律**：

本题是 408 常考的基本复杂度题，考点为“图的存储结构 + 遍历算法”的组合。邻接表下的 BFS 与 DFS 均为 $O(n+e)$；邻接矩阵下遍历需检查所有可能的边，为 $O(n^2)$。常见变式包括：问 DFS 的时间复杂度、问 BFS/DFS 的空间复杂度（辅助队列/递归栈最坏 $O(n)$）、求广度优先生成树、对非连通图遍历需外层循环等。复习时应把复杂度结论与“每个顶点访问一次、每条边扫描一次”的计数方法一起记，并区分有向图与无向图邻接表的边结点数。

13. 设某无向图中有 $n$ 个顶点和 $e$ 条边, 则建立该图的邻接表的时间复杂度为 (  ).

A. $O(n+e)$

B. $O(n^2)$

C. $O(ne)$

D. $O(n^3)$

## DeepSeek V4 Flash Max 解析

**答案**：选 **A**。建立 $n$ 个顶点、$e$ 条边的无向图邻接表的时间复杂度为 $O(n+e)$，其中初始化 $n$ 个顶点表头为 $O(n)$，插入 $2e$ 个边表结点为 $O(e)$。

**解题切入点**：拿到题目先明确“邻接表”的结构：一个长度为 $n$ 的顶点表，加上若干条边链表。建立邻接表就是“开 $n$ 个桶，再把每条无向边对应的两个邻接关系放入桶中”。所以复杂度应正比于“桶数 + 记录数”，即 $O(n+e)$，不要与邻接矩阵的 $O(n^2)$ 混淆。

**推演**：

设无向图 $G=(V,E)$，$|V|=n$，$|E|=e$。

建立邻接表分两步。

第一步：初始化顶点表。

```c
for (i = 0; i < n; i++) {
    adjlist[i].data = i;
    adjlist[i].firstarc = NULL;
}
```

这一步执行 $n$ 次，时间复杂度为 $O(n)$。

第二步：读入每条边，并插入边表结点。对于无向边 $(u,v)$，因为图是无向的，所以：

- 在 $u$ 的邻接链表中插入一个值为 $v$ 的边结点；
- 在 $v$ 的邻接链表中插入一个值为 $u$ 的边结点。

因此 $e$ 条边总共要插入 $2e$ 个边结点。若采用头插法，每次插入只需创建结点并修改指针，时间为 $O(1)$，所以插入总时间为

$$
O(2e)=O(e)。
$$

总时间复杂度为

$$
T(n,e)=O(n)+O(e)=O(n+e)。
$$

核心代码思路如下：

```c
for (每条无向边 (u, v)) {
    // 在 u 的邻接表中头插 v
    p = new ArcNode(v);
    p->next = adjlist[u].firstarc;
    adjlist[u].firstarc = p;

    // 在 v 的邻接表中头插 u
    q = new ArcNode(u);
    q->next = adjlist[v].firstarc;
    adjlist[v].firstarc = q;
}
```

因此答案为 A。

**易错点**：

1. 误选 B：邻接矩阵的建立或初始化才需要 $O(n^2)$ 的时间；邻接表只需 $n$ 个表头结点和 $2e$ 个边结点。
2. 忽略无向图特性：无向边 $(u,v)$ 要同时插入两个顶点的邻接表。虽然 $O(2e)=O(e)$，不影响最终复杂度，但理解这一点对求空间复杂度等问题很重要。
3. 混淆“建立”和“遍历”：DFS、BFS 在邻接表上的时间复杂度也是 $O(n+e)$，但本题问的是建立存储结构，不是遍历图。
4. 忘记初始化顶点表：只计算边的插入会漏掉 $O(n)$；合并后仍然是 $O(n+e)$。

**命题规律**：本题属于“图的存储结构”中的基础题。408 常考邻接表与邻接矩阵的时间、空间复杂度对比，有向图和无向图邻接表边结点数量的区别，以及基于邻接表的 DFS、BFS 复杂度。复习时要把邻接矩阵、邻接表、十字链表、邻接多重表的建表、查边、求度等操作放在一起对比记忆。

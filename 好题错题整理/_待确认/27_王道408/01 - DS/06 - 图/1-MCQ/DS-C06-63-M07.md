# 选择题 第 7 题

![[_Attachments/题目识别/27_王道408-题目/DS-C06-63-M07_题目.png|题目]]

7. 无向图 $G = (V,E)$，其中 $V = \{a, b, c, d, e, f\}$，$E = \{(a,b),(a,e),(a,c),(b,e),(c,f),(f,d),(e,d)\}$，对该图从 $a$ 开始进行深度优先遍历，得到的顶点序列正确的是 (  ).
A. $a, b, e, c, d, f$
B. $a, c, f, e, b, d$
C. $a, e, b, c, f, d$
D. $a, e, d, f, c, b$

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C06-63-M07_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 D，深度优先遍历序列可为 \(a\to e\to d\to f\to c\to b\)。本题未指定邻接点访问顺序，DFS 序列不唯一；但 A、B、C 均不可能由 DFS 产生，D 是唯一合法选项。

**解题切入点**：拿到题先画图/列出邻接集合。DFS 的直观特点是“不撞南墙不回头”：在某顶点时，只要还有未访问邻接点，就要先深入其中一个；当前顶点的未访问邻接点全部处理完，才回溯。因此检查选项时不要只看相邻两个点是否有边，而要检查递归栈能否产生该序列。

**推演**：

DFS 递归模型为

```c
DFS(x) {
    visited[x] = true;   // 输出 x
    for y in Adj[x]
        if (!visited[y])
            DFS(y);
}
```

图 \(G\) 的邻接集合为

\[
N(a)=\{b,e,c\},\quad N(b)=\{a,e\},\quad N(c)=\{a,f\},
\]

\[
N(d)=\{f,e\},\quad N(e)=\{a,b,d\},\quad N(f)=\{c,d\}.
\]

判定规则：若当前顶点 \(x\) 还有未访问邻接点，则下一步必须访问 \(x\) 的某个未访问邻接点，不能跳过它去访问别处。

- **A**：\(a,b,e\) 后，\(e\) 的未访问邻接点为 \(d\)，所以下一步只能是 \(d\)，不能是 \(c\)。排除。
- **B**：\(a,c,f\) 后，\(f\) 的未访问邻接点为 \(d\)，所以下一步只能是 \(d\)，不能是 \(e\)。排除。
- **C**：\(a,e,b\) 后，\(b\) 是叶子，回溯到 \(e\)；此时 \(e\) 仍有未访问邻接点 \(d\)，所以下一步只能是 \(d\)，不能是 \(c\)。排除。
- **D**：按如下方式访问即可：

\[
a \xrightarrow{(a,e)} e \xrightarrow{(e,d)} d \xrightarrow{(d,f)} f \xrightarrow{(f,c)} c
\]

然后 \(c\) 无未访问邻接点，依次回溯 \(f,d\) 到 \(e\)，在 \(e\) 访问 \(b\)，得到

\[
a,e,d,f,c,b.
\]

所以 D 合法。注意 D 中最后 \(c\to b\) 虽无边，但这是回溯到 \(e\) 后才访问 \(b\)，符合 DFS 的递归过程。

**易错点**：

- 误把 DFS 序列当成一条简单路径。DFS 允许回溯后再访问新顶点，因此相邻访问顶点未必有边。
- 当前点还有未访问邻接点时提前回溯。A、B、C 都是因为忽略 \(d\) 这个“必经”邻接点而错误。
- 把 DFS 与 BFS 混淆。BFS 按层扩展，DFS 沿一条分支深入到底。
- 题目未给邻接点顺序时，不要以为 DFS 序列唯一；要判断序列能否由某种邻接顺序下的 DFS 产生。

**命题规律**：

考点为图的深度优先遍历、递归栈/DFS 树的形成，以及遍历序列与存储结构中邻接点顺序的关系。常见变式有：给出邻接表/邻接矩阵要求写出 DFS 或 BFS 序列；判断给定序列是否为 DFS 序列；结合 DFS 生成树、连通分量、有向图的拓扑排序等。复习时应熟练手画递归栈模拟 DFS，并掌握复杂度：邻接表 \(O(|V|+|E|)\)，邻接矩阵 \(O(|V|^2)\)。

9. 用邻接表存储的图的深度优先遍历算法类似于树的(\_)，而其广度优先遍历算法类似于树的(\_)

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C06-63-M09_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 **B、D**。用邻接表存储的图进行深度优先遍历时，先访问顶点、再沿邻边递归深入，类似于树的**先序遍历**；广度优先遍历借助队列逐层扩展，类似于树的**按层次遍历**。

**解题切入点**：拿到题目先想遍历过程的“访问次序”而不是存储结构。深度优先遍历天然是“递归/栈”实现的：先访问当前结点，再递归访问它的子结点/邻接点，这与树的先序遍历结构一致；广度优先遍历天然是“队列”实现的：先访问根，再按距离由近到远逐层访问，这与树的层序遍历一致。做题时可以类比竞赛中常说的“DFS 用栈、BFS 用队列”来快速定位。

**推演**：

图的深度优先遍历从顶点 $v$ 出发的伪代码如下：

```c
DFS(v):
    visit(v);                 // 先访问当前顶点
    visited[v] = true;
    for w in Adj[v]:           // 依次考察 v 的邻接点
        if (!visited[w])
            DFS(w);            // 递归深入
```

树的先序遍历伪代码如下：

```c
PreOrder(T):
    visit(T);                  // 先访问根结点
    for child in T.children:
        PreOrder(child);       // 再依次先序遍历各子树
```

对比两者可知：图 DFS 中的当前顶点相当于树的根结点，而对每个邻接点的递归调用相当于对每个子树进行先序遍历。因此，**图的深度优先遍历类似于树的先序遍历**。

图的广度优先遍历从顶点 $v$ 出发的伪代码如下：

```c
BFS(v):
    Q.push(v);
    visited[v] = true;
    while Q 不空:
        u = Q.pop();
        for w in Adj[u]:
            if (!visited[w]):
                visit(w);
                visited[w] = true;
                Q.push(w);
```

树的按层次遍历伪代码如下：

```c
LevelOrder(T):
    Q.push(T);
    while Q 不空:
        u = Q.pop();
        for child in u.children:
            visit(child);
            Q.push(child);
```

两者都是“先进先出”的队列结构，先访问根，再逐层访问所有子结点。因此，**图的广度优先遍历类似于树的按层次遍历**。

综上，答案为 **B、D**。

**易错点**：

1. **误选中序或后序**。中序、后序遍历是二叉树特有的概念，依赖“左子树/右子树”的明确次序；图的邻接表虽然按顺序存储邻接点，但图没有左右子树之分，且 DFS 先访问顶点后递归，不符合后序“先子树后根”的特点。
2. **忽略 visited 数组的作用**。图可能有环，DFS/BFS 都必须借助 visited 数组防止死循环；但题目问的是遍历次序的类比，visited 不影响结论。
3. **把“邻接表”误认为关键条件**。邻接表只影响访问邻接点的顺序和时间复杂度，不改变“DFS 像先序，BFS 像层序”的本质。即使换用邻接矩阵存储，结论仍然是 B、D。
4. **BFS 误选为“先序”**。如果只记得“BFS 用队列”而忽略队列的层次效果，就容易错；BFS 是按距离递增逐层访问的，所以对应树的“按层次遍历”。

**命题规律**：

本题属于“图的基本概念与遍历”中的基础对比题，考查深度优先遍历、广度优先遍历与树遍历的对应关系。408 中常见变式包括：给出邻接表或邻接矩阵，要求写出从某顶点出发的 DFS/BFS 序列；判断某序列是否可能是 DFS/BFS 序列；或者结合连通分量、生成树进行综合考查。复习时应熟练掌握 DFS/BFS 的代码模板，并亲自画图模拟遍历次序；牢记结论：

- 图的深度优先遍历 $\sim$ 树的先序遍历；
- 图的广度优先遍历 $\sim$ 树的按层次遍历；
- 邻接表存储下 DFS/BFS 的时间复杂度为 $O(V+E)$，邻接矩阵存储下为 $O(V^2)$。

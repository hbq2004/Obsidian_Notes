# 综合题 第 1 题

![[_Attachments/题目识别/27_王道408-题目/DS-C04-42-F01_题目.png|题目]]

1. 在字符串模式匹配的 $KMP$ 算法中，求模式的 $next$ 数组值的定义如下：
$$
next[j] = \begin{cases} 0, & j = 1 \\ \max\{k | 1 < k < j \text{且} p_1 \cdots p_{k-1}' = 'p_{j-k+1} \cdots p_{j-1}' \}, & \text{集合不为空} \\ 1, & \text{其他情况} \end{cases}
$$
1) 当 $j=1$ 时，为什么要取 $next[1]=0$?
2) 为什么要取 $\max\{k\}$, $k$ 最大是多少?
3) 其他情况是什么情况，为什么取 $next[j]=1$?

## DeepSeek V4 Flash Max 解析

**答案**：KMP 算法中，$next[j]$ 表示模式串第 $j$ 个字符失配后，模式串指针应回退到的位置；$next[1]=0$ 是让主串指针前进的哨兵，取 $\max\{k\}$ 是为了利用最长的相等前后缀、使回退最少且不漏匹配，$k$ 最大为 $j-1$；当集合为空时 $next[j]=1$，表示从模式串第一个字符重新与当前主串字符比较。

**解题切入点**：拿到题先不要急着套公式，要先明确 $next[j]$ 的“几何含义”：当模式串第 $j$ 个字符 $p_j$ 与主串当前字符 $s_i$ 失配时，接下来应该用模式串的哪一个字符 $p_k$ 继续与 $s_i$ 比较。这个 $k$ 就是 $next[j]$。由此，“$j=1$ 时怎么办”“$k$ 能取多大”“没有候选 $k$ 怎么办”都是围绕这一含义展开。可以类比查字典：已经读到了“ab”，发现下一个字不对，我们不回翻到第一页，而是根据已读到的“ab”尽量少翻页；若连第一个字都不对，就只能换到下一个字条重新开始。

**推演**：  
KMP 匹配算法的主干是（主串和模式串下标均从 $1$ 开始）：

```text
i = 1; j = 1;
while i <= n && j <= m:
    if j == 0:                # 由 next[1]=0 触发
        i = i + 1; j = 1;
    else if s[i] == p[j]:
        i = i + 1; j = j + 1;
    else:
        j = next[j];
```

注意：$next[j]$ 的值只与模式串 $P$ 有关，与主串无关。下面逐问分析。

**1) 为什么 $j=1$ 时取 $next[1]=0$？**  
当 $j=1$ 时失配，说明 $s_i \ne p_1$。此时模式串已经退到第一个字符，没有“更靠前”的字符可以再与 $s_i$ 比较。若令 $next[1]=1$，则失配后执行 $j = next[j]$ 仍得到 $j=1$，而 $i$ 不变，下一轮又会比较同一个 $s_i$ 与 $p_1$，必然再次失配，陷入死循环。  
因此必须用一个特殊值 $0$ 作为哨兵：执行 $j = next[1]$ 后得到 $j=0$，下一次循环进入 $j==0$ 分支，执行 $i \leftarrow i+1,\ j \leftarrow 1$。这样主串指针才能前进。所以 $next[1]=0$ 并不是“相等前后缀长度”，而是一个控制主串前进的标记。

**2) 为什么要取 $\max\{k\}$？$k$ 最大是多少？**  
设模式串第 $j$ 位失配，则前 $j-1$ 位已经与主串匹配：
$$
s_{i-j+1}\cdots s_{i-1}=p_1\cdots p_{j-1}.
$$
若选择某个 $k\ (1<k<j)$，使失配后改用 $p_k$ 与 $s_i$ 比较，那么必须有：
$$
s_{i-k+1}\cdots s_{i-1}=p_1\cdots p_{k-1}.
$$
而已知 $s_{i-k+1}\cdots s_{i-1}$ 正好对应到已匹配前缀的末尾部分 $p_{j-k+1}\cdots p_{j-1}$，所以候选 $k$ 必须满足：
$$
p_1\cdots p_{k-1}=p_{j-k+1}\cdots p_{j-1}.
$$
也就是说，$k-1$ 是已匹配部分 $p_1\cdots p_{j-1}$ 的一个“相等前后缀”长度。

取 $\max\{k\}$，等价于取最长的相等前后缀。原因有二：  
- $k$ 越大，失配后模式串向右滑动的距离 $j-k$ 越小，保留的已匹配信息越多，比较次数越少；  
- 最长相等前后缀能保证主串指针 $i$ 不回溯时不漏掉可能的匹配起点。若取较小的 $k$，模式串会向右滑过更多字符，可能把本可以从更靠前位置开始的匹配“滑过去”。

关于最大值：因为条件限定 $1<k<j$，所以 $k$ 最多为 $j-1$。若 $k=j$，则前缀长度达到 $j-1$，相当于拿 $p_1\cdots p_{j-1}$ 与自身比较，没有意义，且会导致失配后 $j$ 不变，同样会死循环。  
当 $p_1\cdots p_{j-2}=p_2\cdots p_{j-1}$ 时，$k=j-1$ 可以成立，因此理论上 $k$ 的最大值就是 $j-1$。  
例如 $P=ababa$，当 $j=5$ 时，已匹配 $abab$。候选 $k=3$ 满足 $p_1p_2=ab=p_3p_4$，候选 $k=2$ 也满足 $p_1=a=p_4$，但取 $\max$ 后 $next[5]=3$。

**3) “其他情况”是什么情况？为什么取 $next[j]=1$？**  
“其他情况”指的是：$j>1$ 且满足 $1<k<j$ 的候选 $k$ 一个都不存在，即已匹配部分 $p_1\cdots p_{j-1}$ 没有任何非空真前后缀相等。例如 $P=abcd$，$j=4$ 时，$p_1p_2p_3=abc$，$k=2,3$ 均不满足条件，所以 $next[4]=1$。

此时不能利用任何部分匹配信息，只能将模式串移到第一个字符，即令 $j=1$，继续用 $p_1$ 与当前的主串字符 $s_i$ 比较。为什么不是 $0$？因为这里 $j>1$，主串指针 $i$ 还没有动，$s_i$ 尚未与 $p_1$ 比较过（或可能在新的起点上仍值得比较），所以 $j=1$ 是真实有效的比较位置。若在这一轮 $p_1$ 仍与 $s_i$ 失配，则下一轮出现 $j=1$ 失配，再触发 $next[1]=0$，此时才让 $i$ 前进。因此“其他情况取 $1$”与“$next[1]=0$”是两个不同层面的处理。

**易错点**：  
1. 混淆“最长相等前后缀长度”与 $next[j]$ 的定义。本题中 $next[j]$ 是“失配后下一次比较的模式串位置”，若某教材把 $next[j]$ 定义为“最长相等前后缀长度”，两者相差 $1$，审题时必须看清。  
2. 误认为 $next[1]=0$ 是因为“第一个字符没有前后缀”，实际上它是为了跳出死循环、让主串前进的哨兵。  
3. 误认为 $k$ 最大可以是 $j$，这样会产生自身匹配，导致模式串指针不前进，陷入死循环。  
4. 把“其他情况”中的 $next[j]=1$ 与 $next[1]=0$ 混为一谈。若在“其他情况”里取 $0$，会让主串指针前进，从而漏掉 $s_i$ 与 $p_1$ 的比较机会。  
5. 计算 $next$ 数组时忽略模式串下标从 $1$ 开始，或与从 $0$ 开始的实现混淆，导致边界错误。

**命题规律**：  
本题考点是 KMP 算法中 $next$ 数组定义的理解，属于字符串模式匹配章节的核心概念。考研 408 中常见变式有：给定模式串求 $next$ 数组或 $nextval$ 数组；给定 $next$ 数组模拟 KMP 匹配过程；比较 KMP 算法与暴力匹配的复杂度；以及将 $next$ 数组与“最长相等前后缀”相互转化。复习时应注重理解 $next$ 的递推构造过程（利用 $p_{j}$ 与 $p_{next[j]}$ 的关系），并亲自手算若干典型模式串（如 $ababa$、$aaaaab$、$abcabcd$）的 $next$、$nextval$，再模拟一遍匹配过程。这样不仅能应对定义题，也能快速解决求值题。

# 选择题 第 5 题

![[_Attachments/题目识别/27_王道408-题目/DS-C04-42-M05_题目.png|题目]]

5. 在 $KMP$ 算法中,用 $next$ 数组存放模式串的部分匹配信息,当模式串位 $j$ 与主串位 $i$ 比较时,两个字符不相等,则 $i$ 的位移方式是 ( ).

(A) $i = next[i]$
(B) $i$ 不变
(C) $i = 0$
(D) $i = i + 1$

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C04-42-M05_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 B。KMP 算法中主串指针 $i$ 不回溯；当 $S[i]$ 与模式串 $P[j]$ 失配时，$i$ 不变，只修改 $j=next[j]$，继续用同一个 $S[i]$ 与新位置比较。

**解题切入点**：本题直接定位 KMP 与朴素 BF 匹配的本质区别。KMP 的核心思想是“主串指针不回退”，匹配失败后不是把主串指针退回去重比，而是让模式串滑动。可以类比查单词：正文当前读到的位置先不跳过，只把“模式串模板”向右滑动到可能匹配的位置；已经读过的正文不会重新读。

**推演**：设主串为 $S=s_1s_2\cdots s_n$，模式串为 $P=p_1p_2\cdots p_m$，位序从 1 开始。当前比较 $S[i]$ 与 $P[j]$，且已知失配前已经有 $j-1$ 个字符匹配成功，即

$$
S[i-j+1]\cdots S[i-1]=p_1p_2\cdots p_{j-1}.
$$

KMP 中 $next[j]$ 表示：当 $p_j$ 与 $S[i]$ 失配时，模式串指针应回退到的新位置。按定义，$k=next[j]$ 应满足

$$
p_1p_2\cdots p_{k-1}=p_{j-k+1}\cdots p_{j-1}.
$$

也就是说，模式串已匹配部分的前 $k-1$ 个字符，和它最后 $k-1$ 个字符相同。于是由上面两个等式可得

$$
p_1p_2\cdots p_{k-1}=S[i-k+1]\cdots S[i-1].
$$

因此模式串滑动后，$p_1p_2\cdots p_{k-1}$ 正好可以与主串中 $S[i]$ 前面的 $k-1$ 个字符对齐，下一步只需要比较 $p_k$ 与同一个 $S[i]$。所以失配时主串指针不动：

$$
\text{失配时：}\quad i\leftarrow i,\qquad j\leftarrow next[j].
$$

对应 KMP 关键代码思路为：

```c
while (i <= n && j <= m) {
    if (j == 0 || S[i] == P[j]) {
        i++;
        j++;
    } else {
        j = next[j];   // i 不改变
    }
}
```

若 $next[j]=0$，则下一轮借助哨兵 $j=0$ 使 $i$ 前进一位，表示模式串整体右移一位；但这不是主串指针回溯，而是模式串继续滑动。

**易错点**：

1. 误选 A：$i=next[i]$ 是错的。$next$ 数组是模式串的，不是主串的；失配时应改为 $j=next[j]$。
2. 误选 D：$i=i+1$ 容易与朴素 BF 匹配混淆。KMP 的关键改进就是主串指针不回溯，失配时不会简单地把 $i$ 加 1。
3. 混淆 $next$ 与 $nextval$：$nextval$ 是对 $next$ 的优化，但无论用哪个，主串指针 $i$ 在失配时都不变。
4. 注意不同教材对下标和 $next$ 初值定义不同，但“失配时主串指针不回溯”这一结论不变。

**命题规律**：本题属于字符串 KMP 算法中的基础概念题，408 常以选择题形式考查 KMP 与朴素匹配的区别、$next/nextval$ 数组计算，以及给定模式串后模拟匹配过程。复习时应重点掌握 $next$ 数组的定义、手工计算方法，以及 KMP 时间复杂度为 $O(n+m)$ 的原因：主串指针 $i$ 只增不减，不回退。

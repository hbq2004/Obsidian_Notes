# 选择题 第 4 题

![[_Attachments/题目识别/27_王道408-题目/DS-C04-42-M04_题目.png|题目]]

4. 在 $KMP$ 算法中,用 $next$ 数组存放模式串的部分匹配信息,当模式串位 $j$ 与主串位 $i$ 比较时, 两个字符不相等, 则 $j$ 的位移方式是 ( ).
A. $j=0$
B. $j=j+1$
C. $j$不变
D. $j=next[j]$

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C04-42-M04_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 D。KMP 失配时模式串指针 $j$ 应按 $next$ 数组跳转：$j\leftarrow next[j]$。

**解题切入点**：本题定位是 KMP 的失配处理分支。做题第一步要分清“匹配成功”与“匹配失败”：匹配成功时 $i,j$ 同时加 1；匹配失败时主串指针 $i$ 不回溯，模式串指针 $j$ 按 $next$ 表跳转。可以把 $next$ 数组理解为“存档点”：失配后不是从头开始，也不是继续前进，而是跳到最近的可用存档点。

**推演**：

设主串为 $S[1..n]$，模式串为 $P[1..m]$，当前正在比较 $S[i]$ 与 $P[j]$。

若 $S[i]\ne P[j]$，说明此前 $P[1..j-1]$ 已经与主串中对应部分匹配。KMP 的核心是：在已匹配部分 $P[1..j-1]$ 中找到最长的相同前后缀，使下一次比较不必回到 $P[1]$，而是回到某个 $P[next[j]]$。

由 $next$ 数组定义，若

$$
P[1..k-1]=P[j-k+1..j-1]
$$

则当 $P[j]$ 失配时，可直接用 $P[k]$ 与当前 $S[i]$ 比较，其中 $k=next[j]$。因此失配分支为：

$$
i \text{ 不变},\qquad j\leftarrow next[j]
$$

对应关键代码为：

```c
// 假设下标从 1 开始，next[1] = 0
while (i <= n && j <= m) {
    if (j == 0 || S[i] == P[j]) {
        ++i;
        ++j;
    } else {
        j = next[j];   // 失配时按 next 跳转
    }
}
```

若采用 0 下标写法，则只要把哨兵从 0 改为 -1：

```c
// 假设下标从 0 开始，next[0] = -1
while (i < n && j < m) {
    if (j == -1 || S[i] == P[j]) {
        ++i;
        ++j;
    } else {
        j = next[j];
    }
}
```

所以失配时 $j$ 的“位移方式”不是 $j=0$，也不是 $j=j+1$，而是 $j=next[j]$。

**易错点**：

- 不要把失配处理和匹配处理混淆。匹配成功时才是 $i++,j++$；失配时 $i$ 不变，$j=next[j]$。
- 不要选 A。$j=0$ 只是 $next[j]$ 可能取到的一种特殊值，例如 1 基下标中 $next[1]=0$，但失配的统一操作仍是 $j=next[j]$。
- 不要忽略主串指针 $i$ 不回退。KMP 的优化就在于失配时 $i$ 不回溯，只有 $j$ 跳转。
- 注意区分“模式串指针 $j$ 的新位置”和“模式串整体右移的位数”。若问右移位数，1 基下标下通常为 $j-next[j]$；本题问的是指针跳转方式，故选 D。

**命题规律**：该考点属于串的模式匹配，是 408 中 KMP 的常考概念。常见变式有：给一个模式串求 $next$ 或 $nextval$；给出某次失配，判断 $i,j$ 如何变化；判断 KMP 与朴素匹配的区别；问模式串向右移动几位。复习时应重点掌握 $next$ 数组的手算方法、0 基下标与 1 基下标两种表示的区别，以及 $nextval$ 的优化思想。

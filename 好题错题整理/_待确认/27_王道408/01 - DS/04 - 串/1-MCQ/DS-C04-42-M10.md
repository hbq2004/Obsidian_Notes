# 选择题 第 10 题

![[_Attachments/题目识别/27_王道408-题目/DS-C04-42-M10_题目.png|题目]]

10.【2015 统考真题】已知字符串 $s$ 为 'abaabaabacacaaabaabcc'，模式串 $t$ 为 'abaabc'。采用 KMP 算法进行匹配，第一次出现“失配”($s[i] \neq t[j]$) 时，$i = j = 5$，则下次开始匹配时，$i$ 和 $j$ 的值分别是 ( )。
A. $i=1, j=0$
B. $i=5, j=0$
C. $i=5, j=2$
D. $i=6, j=2$

## DeepSeek V4 Flash Max 解析

**答案**：选 C：$i=5,\ j=2$。KMP 失配时主串指针 $i$ 不回退；失配点前已匹配的模式串前缀为 $\text{abaab}$，其最长相等前后缀为 $\text{ab}$，长度为 $2$，所以 $j$ 跳到 $2$，继续与 $s[5]$ 比较。

**解题切入点**：  
先抓住 KMP 与朴素匹配的本质区别：失配时主串指针 $i$ 不回溯，只移动模式串指针 $j$。所以本题先看 $i$，一定是保持失配时的 $i=5$，不会变成 $1$ 或 $6$。再看 $j$：失配点 $j=5$ 之前已经匹配了 $t[0..4]=\text{abaab}$，求这个串的最长相等前后缀长度即可。可以把主串看成已经读到的书页，失配时不需要退回开头，只把模式串“书签”挪到已匹配内容中前后缀重合的位置。

**推演**：  
题中失配时 $i=j=5$，说明按下标从 $0$ 开始计数。匹配过程前几步为：

$$
s[0..4] = \text{abaab},\qquad t[0..4] = \text{abaab}
$$

前 $5$ 个字符都匹配，于是指针走到 $i=5,\ j=5$。此时：

$$
s[5] = a,\qquad t[5] = c
$$

所以第一次失配发生在 $s[5]$ 与 $t[5]$。

失配时，已经匹配成功的模式串前缀是：

$$
t[0..4]=\text{abaab}
$$

求 $\text{abaab}$ 的最长相等真前后缀：

- 长度为 $1$：前缀 $a$，后缀 $b$，不等；
- 长度为 $2$：前缀 $ab$，后缀 $ab$，相等；
- 长度为 $3$：前缀 $aba$，后缀 $aab$，不等；
- 长度为 $4$：前缀 $abaa$，后缀 $baab$，不等。

因此最长相等前后缀长度为 $2$。若用 KMP 失配数组表示，即：

$$
\text{next}[5]=2
$$

注意：这里看的是失配位置之前的 $\text{abaab}$，不是整个模式串 $\text{abaabc}$。

KMP 失配处理的核心代码思路是：

```c
if (j == -1) {       // 模式串第一个字符都不匹配
    i++;
    j = 0;
} else {
    j = next[j];     // 本题：j = next[5] = 2，i 不变
}
```

本题 $j=5\neq -1$，所以只执行 $j=\text{next}[5]=2$，$i$ 保持 $5$。下一次比较的是 $s[5]$ 与 $t[2]$。

因此：

$$
i=5,\qquad j=2
$$

对应选项 C。

**易错点**：  
- 误选 A：把朴素匹配的“主串回溯”用到 KMP 上，即 $i=i-j+1=1$。KMP 中主串指针不回退。  
- 误选 B：虽然知道 $i$ 不变，但忽略了已匹配前缀 $\text{abaab}$ 中有可复用的 $\text{ab}$，错误地把 $j$ 置为 $0$。  
- 误选 D：失配时 $i$ 不应再加 $1$；只有匹配成功时 $i,j$ 才同时增加。  
- 计算 next 时用错对象：失配在 $j=5$，应计算 $t[0..4]=\text{abaab}$ 的前后缀，而不是整个模式串 $\text{abaabc}$ 的前后缀。

**命题规律**：  
本题是 408 中 KMP 算法的经典考法，核心考查失配后 $i$ 和 $j$ 如何变化。常见变式有：

- 给定模式串求 $\text{next}$ 数组或 $\text{nextval}$ 数组；
- 手工模拟 KMP 匹配过程，统计比较次数；
- 根据失配位置求模式串移动位数。

复习时建议熟练掌握“最长相等前后缀”的手工计算方法，并明确不同教材下标从 $0$ 或从 $1$ 开始的区别。核心结论只有一个：失配时 $i$ 不动，$j=\text{next}[j]$。

# 综合题 第 3 题

![[_Attachments/题目识别/27_王道408-题目/DS-C03-31-F03_题目.png|题目]]

3. 栈的初态和终态均为空，以$I$和$O$分别表示入栈和出栈，则出入栈的操作序列可表示为由$I$和$O$组成的序列,可以操作的序列称为合法序列,否则称为非法序列。
1) 下面所示的序列中哪些是合法的?
(A) $IOIIOIOO$
(B) $IOOIOIIO$
(C) $IIIOIOIO$
(D) $III OOI O O$
2) 通过对1) 的分析,写出一个算法,判定所给的操作序列是否合法。若合法,返回 $true$，否则返回 $false$(假定被判定的操作序列已存入一维数组中).

## DeepSeek V4 Flash Max 解析

**答案**：合法序列为 A、D（D 即 \(IIIOOIOO\)），B、C 非法；判定算法用计数器 \(cnt\) 模拟栈深：遇 \(I\) 则 \(cnt+1\)，遇 \(O\) 则先检查 \(cnt>0\) 再 \(cnt-1\)，扫描完要求 \(cnt=0\)。

**解题切入点**：把 \(I\) 看成 \(+1\)，把 \(O\) 看成 \(-1\)。这样问题就等价于判断括号序列是否合法：任一前缀中，\(I\) 的个数不能少于 \(O\) 的个数；整个序列中，\(I\) 的个数必须等于 \(O\) 的个数。算法竞赛中常见的“括号匹配”判断也常用这种计数法，而不必真的建立栈。

**推演**：

设序列长度为 \(n\)，令：

\[
a_i=\begin{cases}
1,& S_i=I\\
-1,& S_i=O
\end{cases}
\]

则合法序列必须满足：

\[
\forall k\in[1,n],\quad \sum_{i=1}^k a_i\ge 0
\]

并且：

\[
\sum_{i=1}^n a_i=0
\]

即任意前缀中 \(I\) 数不少于 \(O\) 数，且最终 \(I\) 数与 \(O\) 数相等。

逐项判断：

- A. \(IOIIOIOO\)

前缀和为：

\[
1,0,1,2,1,2,1,0
\]

任意前缀非负，最终为 0，所以 **A 合法**。

- B. \(IOOIOIIO\)

前缀和为：

\[
1,0,-1,0,-1,0,1,0
\]

出现负数，说明中途出现栈空时还要出栈，所以 **B 非法**。

- C. \(IIIIOIOIO\)

前缀和为：

\[
1,2,3,4,3,4,3,4,3
\]

最终不为 0，说明终态栈非空，所以 **C 非法**。

- D. \(IIIOOIOO\)

前缀和为：

\[
1,2,3,2,1,2,1,0
\]

任意前缀非负，最终为 0，所以 **D 合法**。

算法代码如下：

```c
bool judge(char S[], int n) {   // n 为序列长度
    int cnt = 0;                // cnt 表示当前栈中元素个数
    for (int i = 0; i < n; ++i) {
        if (S[i] == 'I') {
            ++cnt;              // 入栈
        } else {                // S[i] == 'O'
            if (cnt == 0) {
                return false;   // 栈空时出栈，非法
            }
            --cnt;              // 出栈
        }
    }
    return cnt == 0;            // 终态必须为空
}
```

若数组下标从 1 开始，将循环改为 `for (i = 1; i <= n; ++i)` 即可。时间复杂度为 \(O(n)\)，空间复杂度为 \(O(1)\)。

**易错点**：

1. 只检查 \(I\) 和 \(O\) 总数相等。  
   B 中 \(I\) 与 \(O\) 总数都是 4，但中途出现了空栈出栈，所以非法。

2. 只检查中途没有空栈出栈，不检查终态。  
   C 中途不会空栈出栈，但最终栈中还有元素，所以非法。

3. 实现时不能直接写：

   ```c
   if (S[i] == 'O') cnt--;
   return cnt == 0;
   ```

   这样会把 B 误判为合法，因为 B 最终计数器会回到 0。必须在每次出栈前判断栈是否为空。

4. 注意字符是 `'I'` 和 `'O'`，不是数字；如果序列是字符串存储，还要注意遍历到 `'\0'` 结束。

**命题规律**：本题属于栈的经典应用题，本质是“括号匹配”和“前缀和”问题。常见变式有：判断一个括号字符串是否合法；给定入栈序列和出栈序列，判断出栈序列是否合法；求 \(n\) 个元素的合法出栈序列数量，即卡特兰数：

\[
\frac{1}{n+1}\binom{2n}{n}
\]

复习时要把“栈操作序列”和“前缀和/括号匹配”统一起来，掌握用一个计数器模拟栈深的思想，并注意分析时间复杂度和空间复杂度。

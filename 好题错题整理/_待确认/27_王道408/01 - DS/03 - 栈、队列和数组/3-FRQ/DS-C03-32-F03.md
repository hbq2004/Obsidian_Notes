# 综合题 第 3 题

![[_Attachments/题目识别/27_王道408-题目/DS-C03-32-F03_题目.png|题目]]

3. 利用两个栈 S1 和 S2 来模拟一个队列，已知栈的 4 个运算定义如下：
```
Push(S, x);          // 元素 x 入栈 S
Pop(S, x);           // S 出栈并将出栈的值赋给 x
StackEmpty(S);       // 判断栈是否为空
StackOverflow(S);    // 判断栈是否为满
```
如何利用栈的运算来实现该队列的 3 个运算 (形参由读者根据要求自己设计)？
```
Enqueue;             // 将元素 x 入队
Dequeue;             // 出队，并将出队元素存储在 x 中
QueueEmpty;          // 判断队列是否为空
```

## DeepSeek V4 Flash Max 解析

**答案**：用 $S_1$ 作为“入队栈”/队尾栈，用 $S_2$ 作为“出队栈”/队首栈；入队压入 $S_1$，出队从 $S_2$ 出；$S_2$ 空时把 $S_1$ 全部倒栈到 $S_2$ 再出。两个栈都空则队列空。

**解题切入点**：栈是“后进先出”，队列是“先进先出”。把元素先压入一个栈，再全部倒入另一个空栈，顺序就会被反转两次，从而恢复“先进先出”。可以理解为：$S_1$ 负责接收新元素，$S_2$ 负责按正确顺序输出老元素；$S_2$ 空了再从 $S_1$ “倒一次货”。题目给出了 `StackOverflow`，说明还要考虑栈满时的处理。

**推演**：

设两个栈的容量相同。约定：

- $S_1$ 中从栈底到栈顶存放队列中较新的连续段；
- $S_2$ 中从栈顶到栈底存放队列中较旧的连续段；
- 队列顺序可表示为：
  \[
  S_2\text{ 从栈顶到栈底} \;+\; S_1\text{ 从栈底到栈顶}
  \]

关键性质：若 $S_1$ 中从栈底到栈顶为
\[
a_1,a_2,\ldots,a_m
\]
则把 $S_1$ 全部倒入空栈 $S_2$ 后，$S_2$ 从栈顶到栈底正好也是
\[
a_1,a_2,\ldots,a_m
\]
因此连续从 $S_2$ 出栈就能得到 $a_1,a_2,\ldots,a_m$，满足 FIFO。

### 1. 入队 `EnQueue`

```c
Status EnQueue(Stack &S1, Stack &S2, ElemType x) {
    if (!StackOverflow(S1)) {       // S1 未满，直接入队尾栈
        Push(S1, x);
        return OK;
    }

    if (!StackEmpty(S2)) {          // S1 满且 S2 不空：逻辑队满
        return ERROR;
    }

    // S1 满且 S2 空：先把 S1 全部倒入 S2，再入队
    ElemType tmp;
    while (!StackEmpty(S1)) {
        Pop(S1, tmp);
        Push(S2, tmp);
    }

    Push(S1, x);
    return OK;
}
```

注意：若 $S_1$ 满且 $S_2$ 非空，不能盲目倒栈，因为此时 $S_2$ 中已有队首元素；若把 $S_1$ 倒入 $S_2$，新倒入的元素会压到老元素之上，出队顺序就会错乱。

### 2. 出队 `DeQueue`

```c
Status DeQueue(Stack &S1, Stack &S2, ElemType &x) {
    if (StackEmpty(S2)) {           // S2 空，先从 S1 倒栈
        if (StackEmpty(S1)) {
            return ERROR;           // 队列空
        }

        ElemType tmp;
        while (!StackEmpty(S1)) {
            Pop(S1, tmp);
            Push(S2, tmp);
        }
    }

    Pop(S2, x);
    return OK;
}
```

### 3. 判空 `QueueEmpty`

```c
Status QueueEmpty(Stack S1, Stack S2) {
    return StackEmpty(S1) && StackEmpty(S2);
}
```

正确性证明要点：

- 初始时两栈皆空，队列为空，上述顺序不变式成立。
- 入队时，若 $S_1$ 不满，则 `Push(S1,x)` 把新元素追加到队尾。
- 若 $S_1$ 满且 $S_2$ 空，则先倒栈，原队列顺序仍被保留；再把 $x$ 放入空的 $S_1$，$x$ 仍是队尾。
- 出队时，若 $S_2$ 不空，`Pop(S2)` 恰好取出队首。
- 若 $S_2$ 空而 $S_1$ 不空，说明当前队列全部在 $S_1$ 中；倒栈后 $S_2$ 栈顶到栈底恢复原队列顺序，再出栈即为队首。
- 两栈均空时队列必空。

复杂度：单次操作最坏需要倒整个栈，为 $O(n)$；但每个元素最多被倒入 $S_2$ 一次，因此连续操作的均摊代价为 $O(1)$。空间复杂度为两个栈的总容量。

**易错点**：

1. **出队时直接 `Pop(S1,x)`**：$S_1$ 栈顶是最后入队的元素，直接出栈会得到队尾，违反 FIFO。
2. **入队时 $S_1$ 满且 $S_2$ 非空仍强行倒栈**：会把较新的元素压到较老元素之上，之后出队顺序错乱。此时应判定为队列满。
3. **入队时只判断 `StackOverflow(S1)`，忘记“$S_1$ 满且 $S_2$ 空”时先倒栈**：会导致入队失败。
4. **判空只检查一个栈**：例如 $S_1$ 非空而 $S_2$ 空时，队列仍有元素，不能判空。
5. **倒栈时用入队参数 $x$ 当临时变量**：在 `EnQueue` 中会丢失新元素 $x$，应使用临时变量 `tmp`。

**命题规律**：本题是“栈与队列互相模拟”的经典考点，408 中常以选择题或综合题形式考查。常见变式有：用两个队列模拟栈、判断合法出栈序列、共享栈、双端队列等。复习时要重点理解“先入栈再出栈会反转顺序”的本质，并掌握满/空边界条件的代码写法；尤其要会分析倒栈操作的均摊时间复杂度 $O(1)$。

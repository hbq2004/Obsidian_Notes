# 选择题 第 17 题

![[_Attachments/题目识别/27_王道408-题目/DS-C03-33-M17_题目.png|题目]]

17.【2017统考真题】下列关于栈的叙述中，错误的是 ( ).

$I$.采用非递归方式重写递归程序时必须使用栈
$II$.函数调用时,系统要用栈保存必要的信息
$III$.只要确定了入栈次序，即可确定出栈次序
$IV$.栈是一种受限的线性表,允许在其两端进行操作

A. 仅$I$
B. 仅$I$、$II$、$III$
C. 仅$I$、$III$、$IV$
D. 仅$II$、$III$、$IV$

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C03-33-M17_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 C。错误的叙述是 I、III、IV，II 正确。

**解题切入点**：本题是栈基本概念的辨析题。先抓“绝对化”表述：I 中的“必须”、III 中的“只要……即可”，这类词通常可用反例否定；II 是函数调用栈的常识；IV 直接考栈的定义。做题时用“反例 + 定义”即可定位。

**推演**：

I 错误。采用非递归方式重写递归程序不一定必须使用栈。例如阶乘递归：

$$
f(n)=\begin{cases}
1,& n\le 1,\\
n f(n-1),& n>1
\end{cases}
$$

可以改写成循环：

```c
int f(int n) {
    int s = 1;
    for (int i = 2; i <= n; ++i)
        s *= i;
    return s;
}
```

这里并没有使用栈。只有需要模拟递归调用现场时，才常用栈。

II 正确。函数调用时，系统确实要用调用栈保存必要信息，如返回地址、实参、局部变量等；函数返回时弹出对应栈帧。

III 错误。入栈次序固定，但出栈操作可以和入栈操作交错进行，因此出栈序列不一定唯一。例如入栈次序为 $1,2,3$：

- 可得到出栈序列 $1,2,3$：入 $1$、出 $1$、入 $2$、出 $2$、入 $3$、出 $3$；
- 也可得到出栈序列 $2,1,3$：入 $1$、入 $2$、出 $2$、出 $1$、入 $3$、出 $3$。

所以仅知入栈次序不能唯一确定出栈次序。除非额外规定“先全部入栈，再全部出栈”，出栈次序才是入栈次序的逆序。

IV 错误。栈是一种受限的线性表，但只允许在栈顶一端进行插入和删除操作；允许在两端操作的是双端队列。

综上，I、III、IV 错误，II 正确，因此选 C。

**易错点**：

- 看到“递归”就认为必须用栈，忽略了可用循环迭代的递归形式；注意“必须”是强断言。
- 把“入栈次序”误认为“全部入栈后再出栈”，从而认为出栈序列唯一；实际入栈、出栈可以交替。
- 混淆栈、队列、双端队列的操作位置：栈只在一端操作，队列在一端入队、另一端出队，双端队列在两端操作。
- 审题不清，把“错误的是”看成“正确的是”。

**命题规律**：本题属于“栈和队列”的基本概念题，核心考点是栈的定义、递归与栈的关系、函数调用栈、出栈序列的确定性。常见变式有：给定入栈序列判断某个出栈序列是否合法、递归算法与非递归实现的转换、栈在函数调用和表达式求值中的应用。复习时应准确记忆“栈是只允许在一端进行插入或删除的线性表”这一本质，并养成对“必须”“只要”“一定”等绝对化表述举反例的习惯。

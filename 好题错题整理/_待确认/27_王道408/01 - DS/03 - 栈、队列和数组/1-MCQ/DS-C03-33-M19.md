# 选择题 第 19 题

![[_Attachments/题目识别/27_王道408-题目/DS-C03-33-M19_题目.png|题目]]

19.【2024统考真题】与表达式 $x + y * (z - u) / v$ 等价的后缀表达式是 ( ).
(A). $xyzu^{-}*v/ +$
(B). $xyzu - v/* +$
(C). $+x/*y - zuv$
(D). $+x*y/ - zuv$

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C03-33-M19_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 **A**，等价后缀表达式为 $xyzu^{-}*v/+$，即 $x\,y\,z\,u\,-\;*\;v\;/\;+$。

**解题切入点**：拿到中缀表达式，先按“括号优先级最高、乘除优于加减、同优先级从左到右”补全括号，确定运算顺序；再用栈模拟中缀转后缀，或由内向外逐层转换。可类比表达式求值：操作数保持原顺序，操作符按优先级“后来居上”。

**推演**：

原式为  
$$
x + y * (z - u) / v
$$

运算符优先级：括号 > $*$、$/$ > $+$。  
其中 $*$ 与 $/$ 同级，且左结合，所以：

$$
x + y * (z - u) / v
=
x + \Big( \big( y * (z - u) \big) / v \Big)
$$

由内向外转后缀：

1. $z - u$  
   $$
   z\,u\,-
   $$

2. $y * (z - u)$  
   $$
   y\,z\,u\,-\;*
   $$

3. $\big( y * (z - u) \big) / v$  
   $$
   y\,z\,u\,-\;*\;v\;/
   $$

4. $x + \Big( \big( y * (z - u) \big) / v \Big)$  
   $$
   x\,y\,z\,u\,-\;*\;v\;/\;+
   $$

合并后即为：

$$
xyzu^{-}*v/+
$$

与选项 **A** 一致。

也可以用栈模拟验证：

- 操作数直接输出；
- 遇到操作符，弹出栈中优先级不低于当前操作符的操作符，再入栈；
- 左括号入栈，右括号弹出至左括号。

扫描过程简表如下：

| 扫描 | 输出 | 栈 |
|---|---|---|
| $x$ | $x$ |  |
| $+$ | $x$ | $+$ |
| $y$ | $x\,y$ | $+$ |
| $*$ | $x\,y$ | $+$ * |
| $($ | $x\,y$ | $+$ * ( |
| $z$ | $x\,y\,z$ | $+$ * ( |
| $-$ | $x\,y\,z$ | $+$ * ( $-$ |
| $u$ | $x\,y\,z\,u$ | $+$ * ( $-$ |
| $)$ | $x\,y\,z\,u\,-$ | $+$ * |
| $/$ | $x\,y\,z\,u\,-\;*$ | $+$ / |
| $v$ | $x\,y\,z\,u\,-\;*\;v$ | $+$ / |
| 结束 | $x\,y\,z\,u\,-\;*\;v\;/\;+$ |  |

所以答案选 **A**。

**易错点**：

- 乘除同级必须从左到右结合。  
  原式是 $(y * (z - u)) / v$，不是 $y * ((z - u) / v)$。选项 **B** 对应的是后者，表达式树不同，在整数除法下结果也可能不同。
- 右括号弹出时，不要忘掉左括号后的剩余操作符；结束扫描后还需把栈中所有操作符依次弹出。
- 选项 **C、D** 是前缀表达式，不是后缀表达式，不要因为前缀也能算出类似结果而误选。
- 后缀式书写时最好加空格区分操作数，如 $x\,y\,z\,u\,-\;*\;v\;/\;+$，避免把 $zu-$ 误读成两个变量。

**命题规律**：本题考查“中缀表达式转后缀表达式”，核心是栈的应用、运算符优先级和结合性。常见变式有：给后缀式求值、给表达式树求前/中/后序遍历、判断不同表达式是否等价、含单目运算符或幂运算的转换等。复习时建议熟练掌握“括号法”和栈模拟法，遇到此类题先补全括号，再逐层转换，可快速准确得出答案。

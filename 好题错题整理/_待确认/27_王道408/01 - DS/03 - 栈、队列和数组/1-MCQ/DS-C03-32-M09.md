# 选择题 第 9 题

![[_Attachments/题目识别/27_王道408-题目/DS-C03-32-M09_题目.png|题目]]

9. 假设循环队列 $Q[MaxSize]$ 的队首指针为 $front$，队尾指针为 $rear$，队列的最大容量为 $MaxSize$，此外，该队列再没有其他数据成员，则判断该队列已满的条件是(  ).
A. $Q.front == Q.rear$
B. $Q.front + Q.rear \ge MaxSize$
C. $Q.front == (Q.rear + 1) \% MaxSize$
D. $Q.rear == (Q.front + 1) \% MaxSize$

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C03-32-M09_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 **C**。仅用 `front` 和 `rear` 两个指针区分循环队列空/满时，需牺牲一个存储单元，队满条件为  
$$Q.front == (Q.rear+1)\% MaxSize$$

**解题切入点**：拿到题先看“再没有其他数据成员”，说明不能用 `size` 或 `tag` 来区分空满，只能靠 `front` 与 `rear` 的相对位置。把循环队列想象成环形跑道：队空时两个指针重合；队满时若允许完全填满也会重合，所以只能留一个空位，让队尾指针“追到”队首前一个位置即满。

**推演**：

1. 约定：设 `front` 指向队头元素，`rear` 指向队尾元素的**下一个位置**，队列元素存放在 `Q[0..MaxSize-1]`。
2. 初始时：  
   $$front = rear = 0$$  
   此时队列为空，因此判空条件为  
   $$Q.front == Q.rear$$
3. 入队操作：
   ```c
   Q[rear] = x;
   rear = (rear + 1) % MaxSize;
   ```
4. 出队操作：
   ```c
   x = Q[front];
   front = (front + 1) % MaxSize;
   ```
5. 若允许队列填满 `MaxSize` 个元素，那么当填满时同样有  
   $$front == rear$$  
   这就会与队空条件发生冲突。因此循环队列必须牺牲一个存储单元，最多存放 `MaxSize-1` 个元素。
6. 当队列满时，`rear` 再前进一个位置就会追上 `front`，即：  
   $$(rear+1)\% MaxSize == front$$  
   等价于选项中的：  
   $$Q.front == (Q.rear+1)\% MaxSize$$
7. 举例验证：设 `MaxSize = 5`，依次入队 `a,b,c,d` 后：
   - 初始：`front = 0, rear = 0`
   - 入 `a`：`rear = 1`
   - 入 `b`：`rear = 2`
   - 入 `c`：`rear = 3`
   - 入 `d`：`rear = 4`
   此时 `front = 0, rear = 4`，  
   $$(rear+1)\%5 = 0 = front$$  
   队列满，不能再入队。若再入队，`rear` 将变为 0，导致 `front == rear`，与队空混淆。
8. 排除其他选项：
   - **A** `Q.front == Q.rear`：是判空条件，不是判满。
   - **B** `Q.front + Q.rear >= MaxSize`：没有取模运算，且两个指针相加没有实际含义。
   - **D** `Q.rear == (Q.front+1)\%MaxSize`：表示 `rear` 在 `front` 的下一个位置，此时队列中实际上只有一个元素（或处于某种特殊状态），不是满。

**易错点**：

- **误选 A**：分不清队空与队满，二者在指针相等时无法区分，故不能作为满条件。
- **忘记取模**：循环队列的指针移动必须取模，否则会“越界”或无法处理环绕。
- **混淆指针指向约定**：题目默认 `rear` 指向队尾元素的下一个位置。若改为 `rear` 指向队尾元素本身，则判满条件会变化，需小心。
- **忽略“牺牲一个存储单元”**：正是因为没有额外数据成员，才必须牺牲一格，否则无法区分空满。
- **把 D 误认为满**：D 表示 `rear` 位于 `front` 的下一个位置，这通常对应队列中只有一个元素，不是满。

**命题规律**：本题考查循环队列的存储结构与基本操作，是 408 数据结构的常考基础点。常见变式有：

- 给定 `front`、`rear` 和 `MaxSize`，求队列长度：  
  $$(rear - front + MaxSize)\% MaxSize$$
- 增加 `size` 或 `tag` 域后，判空判满条件会改变：  
  - 有 `size`：空为 `size==0`，满为 `size==MaxSize`
  - 有 `tag`：以 `tag` 区分最后一次操作是入队还是出队，从而区分 `front==rear` 时是空还是满
- 改变 `rear` 指向后，判满公式会变化。

复习建议：熟练掌握“牺牲一个单元”的循环队列实现，主动推导判空、判满、长度公式，并对比 `size` 法、`tag` 法，理解其设计动机。做题时先确认指针指向约定，再套用公式，即可避免大部分错误。

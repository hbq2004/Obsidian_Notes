# 选择题 第 25 题

![[_Attachments/题目识别/27_王道408-题目/DS-C03-31-M25_题目.png|题目]]

25. 设有一个顺序共享栈 $Share[0:n-1]$，其中第一个栈顶指针 $top1$ 的初值为 $-1$，第二个栈顶指针 $top2$ 的初值为 $n$，则判断共享栈满的条件是 ( ).
A. $top2 - top1 == 1$
B. $top1 - top2 == 1$
C. $top1 == top2$
D. 都不对

## DeepSeek V4 Flash Max 解析

**答案**：选 A。共享栈满的条件是 $top2 - top1 == 1$，等价于 $top1 + 1 == top2$，即两个栈顶指针紧邻，中间没有空闲位置。

**解题切入点**：  
先画出共享栈的存储模型：第一个栈从数组低地址端向高地址端增长，第二个栈从数组高地址端向低地址端增长。$top1$ 初值为 $-1$，$top2$ 初值为 $n$，说明两个指针都是“指向栈顶元素”的指针。判断共享栈满，不是看某一个栈满，而是看整个数组是否被两个栈占满。这类似于双指针相向扫描数组，两个指针“相邻”时即满。

**推演**：

设数组为 $Share[0:n-1]$。

栈 1 从下标 $0$ 开始向右增长：

- 空栈时：$top1=-1$；
- 入栈时：先 $top1 \gets top1+1$，再存入 $Share[top1]$；
- 因此栈 1 中的元素个数为：
$$
top1+1
$$

栈 2 从下标 $n-1$ 开始向左增长：

- 空栈时：$top2=n$；
- 入栈时：先 $top2 \gets top2-1$，再存入 $Share[top2]$；
- 因此栈 2 中的元素个数为：
$$
n-top2
$$

共享栈中总元素个数为：
$$
(top1+1)+(n-top2)=n+1+top1-top2
$$

当共享栈满时，两个栈的元素总数恰好等于数组容量 $n$：

$$
n+1+top1-top2=n
$$

化简得：

$$
top1-top2=-1
$$

即：

$$
top2-top1=1
$$

也可以用空闲位置来理解。两个栈之间的空闲区间是：

$$
[top1+1,\ top2-1]
$$

空闲元素个数为：

$$
top2-top1-1
$$

当空闲个数为 $0$ 时，栈满：

$$
top2-top1-1=0
$$

$$
top2-top1=1
$$

因此选 **A**。

关键代码思路如下：

```cpp
bool Full() {
    return top2 - top1 == 1;
}

// 入栈 1
bool Push1(ElemType x) {
    if (Full()) return false;
    Share[++top1] = x;
    return true;
}

// 入栈 2
bool Push2(ElemType x) {
    if (Full()) return false;
    Share[--top2] = x;
    return true;
}
```

**易错点**：

1. **误选 B**：方向容易搞反。栈 2 从高地址向低地址增长，满时是 $top2$ 比 $top1$ 大 $1$，不是 $top1$ 比 $top2$ 大 $1$。  
2. **误选 C**：$top1 == top2$ 时两个指针已经指向同一个位置，说明已经发生了“交叉覆盖”，而不是正常的栈满判断。正常入栈前判断满，应该是两个指针相邻，而不是相等。  
3. **忽略 $top2$ 的初值含义**：$top2=n$ 并不是数组最大下标 $n-1$，而是栈 2 空栈时的“哨兵位置”，入栈时要先减一再使用。  
4. **只考虑两个栈都有元素的情况**：即使只有一个栈把整个数组占满，例如 $top1=n-1,\ top2=n$，同样满足 $top2-top1=1$，所以该条件是全局统一的。

**命题规律**：  
本题属于“栈的共享存储结构”这一高频考点。408 中常以选择题形式考查共享栈的判满、判空、入栈、出栈等操作，也可能在代码题中要求实现共享栈。常见变式有：

- 给出不同的 $top1$、$top2$ 初值，问判空条件；
- 改变指针指向“栈顶元素”还是“下一个空闲位置”，满条件的表达式会不同；
- 要求写出共享栈的入栈、出栈函数。

复习建议：画图模拟两个栈从两端向中间增长的过程，明确每个指针的初值和移动方向，做题时先判断指针指向的是“栈顶元素”还是“空闲位置”。

# 选择题 第 20 题

![[_Attachments/题目识别/27_王道408-题目/DS-C03-32-M20_题目.png|题目]]

20.【2010统考真题】某队列允许在其两端进行入队操作，但仅允许在一端进行出队操作。若元素$a,b,c,d,e$依次入此队列后再进行出队操作，则不可能得到的出队序列是( )。
A. $b,a,c,d,e$
B. $d,b,a,c,e$
C. $d,b,c,a,e$
D. $e,c,b,a,d$

## DeepSeek V4 Flash Max 解析

**答案**：不可能得到的出队序列是 **C**，即 $d,b,c,a,e$。

**解题切入点**：  
“两端可入队、一端出队”是**输出受限双端队列**，不能按普通 FIFO 队列理解。判断输出序列时，最有效的办法是倒推：**最后入队的元素必然在最终队列的某一端**；删掉它后，倒数第二个入队的元素又必然在剩余队列的某一端。像剥洋葱一样不断从两端剥除 $e,d,c,b,a$，剥得完即可行，否则不可行。

**推演**：  
设出队端为队头，另一端为队尾。由于题目说“入队后再进行出队操作”，所以出队序列就是最终队列从队头到队尾的排列。

记 $Q_i$ 为前 $i$ 个元素入队后的队列。第 $i$ 个元素 $x_i$ 入队时只能插入队头或队尾，所以

$$
Q_i=x_iQ_{i-1}\quad\text{或}\quad Q_i=Q_{i-1}x_i.
$$

因此 $x_i$ 必在 $Q_i$ 的两端。对最终队列 $S$，先看 $e$，再看删去 $e$ 后的 $d$，依此类推。关键判断逻辑如下：

```python
def possible(S):
    l, r = 0, len(S) - 1
    for x in ['e', 'd', 'c', 'b', 'a']:
        if S[l] == x:
            l += 1
        elif S[r] == x:
            r -= 1
        else:
            return False
    return True
```

逐项检查：

| 选项 | 出队序列 | 反向剥除过程 | 结论 |
|---|---|---|---|
| A | $b,a,c,d,e$ | 删 $e$(队尾)，$d$(队尾)，$c$(队尾)，$b$(队头)，$a$ | 可行 |
| B | $d,b,a,c,e$ | 删 $e$(队尾)，$d$(队头)，$c$(队尾)，$b$(队头)，$a$ | 可行 |
| C | $d,b,c,a,e$ | 删 $e$(队尾)，$d$(队头) 后剩 $b,c,a$，此时应删 $c$，但 $c$ 不在两端 | **不可行** |
| D | $e,c,b,a,d$ | 删 $e$(队头)，$d$(队尾)，$c$(队头)，$b$(队头)，$a$ | 可行 |

所以不可能得到的是 **C**。

**易错点**：  
- 把它当普通队列，只允许队尾入队、队头出队；题中实际可两端入队。  
- 只检查 $e$ 是否在两端，忽略删掉 $e,d$ 后还要继续检查 $c$；判断必须进行到序列为空。  
- 反向删除时，若当前该删的元素既不在剩余序列的队头也不在队尾，则一定不可行，不能强行继续删。  
- 注意出队序列的方向是最终队列从出队端到另一端的次序，不要反向比较。

**命题规律**：  
本题属于“双端队列变种”的经典选择题，常考输出受限双端队列、输入受限双端队列的合法序列判断。常见变式有：改为“一端入队、两端出队”、在入队/出队操作中允许交替、求 $n$ 个元素的合法出队序列数量。复习时建议掌握“反向剥除/倒推”方法，并画队头、队尾示意图快速排除错误选项；这种题在 408 中通常以“不可能的是”形式出现，用选项排除法最稳妥。

## DeepSeek V4 Flash Max 解析

**答案**：选 **B（广度优先搜索图）**。图的广度优先搜索（BFS）按层扩展顶点，必须用队列保存“已发现但尚未访问其邻接点”的顶点。

**解题切入点**：  
这是“算法执行过程与辅助数据结构匹配”的识记题。拿到题先抓关键词：看到“广度”“按层扩展”想到队列；看到“深度”“回溯”想到栈。好比竞赛中的 BFS 模板，核心就是维护一个“待扩展队列”，没有队列就无法保证先被发现的顶点先被扩展。

**推演**：  
队列是先进先出（FIFO）结构，适合按“到达先后”处理任务。逐项分析：

1. **查找散列（哈希）表**  
   散列表查找只涉及散列函数计算、地址定位和关键字比较，冲突处理用开放定址法或链地址法即可完成，不需要队列作为辅助空间。

2. **广度优先搜索图（BFS）**  
   BFS 的基本思想是：从源点出发，先访问所有距离为 1 的顶点，再访问距离为 2 的顶点，以此类推。其伪代码如下：
   $$
   \begin{aligned}
   &\text{visited}[s] \leftarrow \text{true};\quad Q.\text{enqueue}(s)\\
   &\textbf{while } Q \text{ 不空}:\\
   &\qquad u \leftarrow Q.\text{dequeue}()\\
   &\qquad \textbf{for each } v \in \text{Adj}[u]:\\
   &\qquad\qquad \textbf{if } \text{not visited}[v]:\\
   &\qquad\qquad\qquad \text{visited}[v] \leftarrow \text{true};\; Q.\text{enqueue}(v)
   \end{aligned}
   $$
   队列中存放的是“已发现、等待扩展”的顶点。由于队列先进先出，先入队的顶点先出队扩展，从而保证同一层的顶点先于下一层的顶点被访问。这正是 BFS 必须使用队列的原因。

3. **前序（根）遍历二叉树**  
   前序遍历顺序是“根、左、右”。递归实现时使用系统栈；非递归实现时通常显式使用栈。它不需要队列。

4. **深度优先搜索图（DFS）**  
   DFS 的策略是“一条路走到黑，再回溯”，需要使用栈或递归工作栈来保存回溯信息，而不是队列。

因此，只有广度优先搜索图需要使用队列作为辅助存储空间。

**易错点**：  
1. 容易把 BFS 和 DFS 的辅助结构记反。记忆口诀：  
   - BFS：队列，广度优先，一层一层扩展；  
   - DFS：栈，深度优先，一路深入再回溯。  
2. 容易把“前序遍历二叉树”和“层序遍历二叉树”混淆。层序遍历才用队列，前序遍历用递归或栈。  
3. 注意“辅助存储空间”的含义：散列表本身用数组或链表存储，不是算法执行时额外需要的队列。  
4. 若在 BFS 实现中忘记用队列，而用栈模拟，则得到的遍历顺序会退化为类似 DFS 的扩展方式，不符合 BFS 的层次要求。

**命题规律**：  
本题属于数据结构基础概念的常考选择题，难度较低，常与图的遍历、树的遍历结合命题。常见变式有：  
- “层序遍历二叉树”使用的辅助结构；  
- “将递归算法改为非递归算法”时通常使用的辅助结构；  
- “图的广度优先生成树”和“深度优先生成树”对应的遍历方法；  
- “拓扑排序”的队列实现等。  

复习时应建立“算法控制流特征”与“辅助结构”的对应表：栈对应递归、DFS、表达式求值；队列对应 BFS、层序遍历、任务调度。遇到此类题先判断处理顺序是 LIFO 还是 FIFO，即可快速定位答案。

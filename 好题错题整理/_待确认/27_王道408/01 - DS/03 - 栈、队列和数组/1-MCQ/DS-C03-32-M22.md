# 选择题 第 22 题

![[_Attachments/题目识别/27_王道408-题目/DS-C03-32-M22_题目.png|题目]]

22.【2014统考真题】循环队列放在一维数组$A[0..M-1]$中，$end1$指向队首元素，$end2$指向队尾元素的后一个位置。假设队列两端均可进行入队和出队操作，队列中最多能容纳$M-1$个元素。初始时为空。下列判断队空和队满的条件中，正确的是 ( )。
A. 队空:$end1 == end2$; 队满:$end1 == (end2 + 1)\text{mod}M$
B. 队空:$end1 == end2$; 队满:$end2 == (end1 + 1)\text{mod}(M-1)$
C. 队空:$end2 == (end1 + 1)\text{mod}M$; 队满:$end1 == (end2 + 1)\text{mod}M$
D. 队空:$end1 == (end2 + 1)\text{mod}M$; 队满:$end2 == (end1 + 1)\text{mod}(M-1)$

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C03-32-M22_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A. 队空：$end1 == end2$；队满：$end1 == (end2 + 1) \bmod M$。

**解题切入点**：本题是循环队列的经典变式，核心在于理解指针定义与队列容量限制。类似“循环数组双指针”问题，先抓住两个关键：一是 $end1$ 指向队首，$end2$ 指向队尾后一位置（类似 front 和 rear）；二是队列最多容纳 $M-1$ 个元素（牺牲一个单元以区分空满）。即使两端均可操作，指针移动方向不影响元素个数计算公式，因此只需从“元素个数”出发推导空满条件。

**推演**：  
设数组大小为 $M$，队列中元素个数 $n = (end2 - end1 + M) \bmod M$。  
- 队空时 $n=0$，即 $end1 \equiv end2 \pmod{M}$，故 $end1 == end2$。  
- 队满时 $n=M-1$，即 $(end2 - end1) \bmod M = M-1$，等价于 $end2 \equiv end1 - 1 \pmod{M}$，即 $end1 \equiv end2 + 1 \pmod{M}$，故 $end1 == (end2 + 1) \bmod M$。  
上述推导与操作方式无关，仅依赖指针定义。选项 B 中 $\bmod (M-1)$ 错误；选项 C 将空满条件颠倒；选项 D 空满条件均错误。因此 A 正确。

**易错点**：  
1. 混淆 $end1$、$end2$ 与通常的 front、rear 的对应关系，误认为 $end2$ 指向队尾导致 $end1$ 与 $end2$ 的关系反转。  
2. 忽略“最多容纳 $M-1$ 个元素”这一条件，直接使用 $M$ 个元素时的满条件（即 $end1 == (end2+1) \bmod M$ 恰好是牺牲一个单元后的正确形式）。  
3. 误以为两端操作会改变指针移动方向，从而影响空满判断，但实际上元素个数始终由两指针循环距离决定。

**命题规律**：  
循环队列空满条件判断是 408 高频考点，常以选择或填空题出现。本题将指针名称与常规略有不同，并加入“两端均可操作”的干扰，但本质仍考查 $(rear+1) \bmod M == front$ 的满条件。复习时应熟练掌握循环队列的两种常用表示（牺牲单元法、计数法），并注意指针定义与移动方向。变式可包括：修改指针指向方式（如 $end2$ 指向队尾）、改变容量限制（如不牺牲单元）等，但核心是元素个数计算。

# 选择题 第 16 题

![[_Attachments/题目识别/27_王道408-题目/DS-C03-34-M16_题目.png|题目]]

16.【2023 统考真题】若采用三元组表存储结构存储稀疏矩阵 $M$，则除三元组表外，下列数据中还需要保存的是 ( )。

$I. M$ 的行数  
$II. M$ 中包含非零元素的行数  
$III. M$ 的列数  
$IV. M$ 中包含非零元素的列数  

A. 仅 $I$、$III$  
B. 仅 $I$、$IV$  
C. 仅 $II$、$IV$  
D. $I$、$II$、$III$、$IV$

## 答案

## DeepSeek V4 Flash Max 解析

**答案**：采用三元组表存储稀疏矩阵时，除三元组表外，只需额外保存矩阵的行数和列数即可唯一确定矩阵，故正确选项为 A（仅 I、III）。

**解题切入点**：本题直接考查稀疏矩阵三元组存储结构的基本要素。拿到题后立即定位到数据结构中“数组与稀疏矩阵”部分，回忆三元组顺序表的典型定义（如 `TSMatrix` 结构体包含 `mu`（行数）、`nu`（列数）和 `tu`（非零元个数）三个域，以及三元组表 `data`）。问题问的是“除三元组表外还需要保存的数据”，而三元组表已经存储了每个非零元素的行下标、列下标和值，但若缺失矩阵的维度信息（总行数和总列数），则无法恢复矩阵的原形状，也无法进行矩阵运算（如转置、乘法等）。至于“包含非零元素的行数”和“包含非零元素的列数”属于可推导信息，并非必须存储，因此排除 II、IV。

**推演**：
1. 三元组表（`data` 数组）只记录非零元素的位置和值，例如 $(i, j, val)$。如果只保存这些三元组，丢失了矩阵的总体尺寸，那么两个不同尺寸的矩阵可能拥有完全相同的三元组集合（例如 $2\times3$ 矩阵与 $2\times4$ 矩阵可能在相同位置有相同非零元，但最右边多一列零列，三元组表完全相同，但矩阵不同）。因此**必须**保存矩阵的总行数 $I$ 和总列数 $III$。
2. 对于选项 II“包含非零元素的行数”和 IV“包含非零元素的列数”，它们可以从三元组表中通过一次扫描统计得出，并非唯一确定矩阵所必需的信息。即使不知道，也不会影响矩阵的还原和基本运算，因此不是必须保存的。
3. 典型的稀疏矩阵三元组顺序存储结构定义如下（类C语言）：
   ```c
   #define MAXSIZE 100
   typedef struct {
       int i, j;          // 非零元素的行、列下标
       ElemType e;        // 非零元素值
   } Triple;
   typedef struct {
       Triple data[MAXSIZE]; // 三元组表
       int mu, nu, tu;       // 行数、列数、非零元素个数
   } TSMatrix;
   ```
   其中 `mu` 和 `nu` 对应 I 和 III，而 `tu` 是非零元个数，不是 II 或 IV。因此本题答案为 I 和 III。

易错点：
- 误以为必须保存“包含非零元素的行数”用于快速访问，但实际应用中常通过行逻辑链接或十字链表优化，而三元组顺序表的基础实现并不要求此信息；若从信息熵角度，包含非零元素的行/列数可以完全由三元组表推导，不是必须。
- 混淆“包含非零元素的行数”与“非零元素个数”或“总行数”；注意 II 说“包含非零元素的行数”（即至少有一个非零元素的行数目），不是总行数，也不是非零元个数。
- 忽略矩阵维度信息的必要性，只关注非零元素本身，导致多选或选错。

命题规律：
- 本题属于稀疏矩阵存储结构的经典考点，常以选择题或填空题形式出现，主要考察三元组顺序表、行逻辑链接表、十字链表等存储结构的组成要素。
- 类似变式：询问三元组表是否还需要存储非零元素个数、或矩阵的列优先信息等；或者改编为“采用十字链表存储时还需要保存哪些信息”。
- 复习建议：扎实掌握每种稀疏矩阵存储结构的结构体定义，理解每个域的作用（必须存储、方便运算而存储、可推导而省略）。对于三元组顺序表，应明确其基本域是行数、列数、非零元个数以及三元组表，并知道这些信息足以进行矩阵转置、加法等运算。

# 选择题 第 31 题

![[_Attachments/题目识别/27_王道408-题目/DS-C03-31-M31_题目.png|题目]]

31.【2022统考真题】给定有限符号集 $S$, $in$ 和 $out$ 均为 $S$ 中所有元素的任意排列. 对于初始为空的栈 $ST$，下列叙述中，正确的是( )。
(A) 若 $in$ 是 $ST$ 的入栈序列，则不能判断 $out$ 是否为其可能的出栈序列
(B) 若 $out$ 是 $ST$ 的出栈序列，则不能判断 $in$ 是否为其可能的入栈序列
(C) 若 $in$ 是 $ST$ 的入栈序列,$out$ 是对应 $in$ 的出栈序列,则 $in$ 与 $out$ 一定不同
(D) 若 $in$ 是 $ST$ 的入栈序列,$out$ 是对应 $in$ 的出栈序列,则 $in$ 与 $out$ 可能互为倒序

## DeepSeek V4 Flash Max 解析

**答案**：选 **D**。给定入栈序列后，出栈序列是否合法可以通过栈模拟判断；而“入栈序列与出栈序列互为倒序”是可能的，例如按 $in$ 全部入栈后再全部出栈，得到的 $out$ 就是 $in$ 的倒序。

**解题切入点**：看到“入栈序列/出栈序列/是否可能”立即定位考点：**栈的合法出栈序列判定**。核心思想是：出栈序列必须满足栈的 LIFO 特性，判断时用“贪心模拟”即可，不需要枚举所有排列。题目中出现“一定/可能/不能判断”时，优先用**构造例子**和**反例**来验证选项。

**推演**：

设符号集为 $S=\{a_1,a_2,\dots,a_n\}$，给定入栈序列
$$
in=(p_1,p_2,\dots,p_n)
$$
和候选出栈序列
$$
out=(q_1,q_2,\dots,q_n).
$$

判断 $out$ 是否为 $in$ 的合法出栈序列，可用如下贪心模拟：

```text
i = 1, j = 1, 栈为空
while j <= n:
    if 栈非空 and 栈顶 == q[j]:
        弹出栈顶
        j++
    else:
        if i <= n:
            将 p[i] 入栈
            i++
        else:
            返回 false
返回 true
```

该算法正确性在于：当前需要弹出的元素 $q_j$ 必须是栈顶元素；如果不是，就继续按照 $in$ 的顺序压入元素，直到栈顶等于 $q_j$ 或所有元素都已入栈。若所有元素都已入栈而栈顶仍不是 $q_j$，说明 $q_j$ 被压在栈中更下方，不可能合法弹出。时间复杂度为 $O(n)$。

逐项分析选项：

- **A 错误**。若 $in$ 是入栈序列，对任意给定的 $out$，可以用上述模拟算法判断其是否为合法出栈序列，因此并非“不能判断”。例如 $in=(1,2,3)$，$out=(1,3,2)$ 合法，$out=(3,1,2)$ 不合法，均可判断。

- **B 错误**。若 $out$ 是出栈序列，对任意给定的候选入栈序列 $in$，同样可以用上述模拟算法判断。甚至任意 $out$ 都至少存在一个可能的入栈序列，例如取 $in=out$，逐个元素“入栈后立即出栈”即可得到 $out$。

- **C 错误**。“$in$ 与 $out$ 一定不同”说法错误。例如 $S=\{1\}$ 时，$in=out=(1)$；更一般地，对每个元素执行“入栈后立即出栈”，可以得到 $in=out$。

- **D 正确**。若取
  $$
  in=(a_1,a_2,\dots,a_n),
  $$
  先将所有元素依次入栈，再依次弹出，得到
  $$
  out=(a_n,a_{n-1},\dots,a_1),
  $$
  恰好是 $in$ 的倒序。因此“$in$ 与 $out$ 可能互为倒序”成立。

所以正确答案是 **D**。

**易错点**：

1. **误以为给定入栈序列后无法判断出栈序列**。实际上用栈模拟即可判断，不需要枚举全部可能出栈序列。
2. **混淆“出栈序列不唯一”和“不能判断”**。入栈序列固定时，合法出栈序列可能有很多种，但对给定的一个候选序列，合法性可以唯一判断。
3. **误以为入栈序列和出栈序列一定不同**。单个元素时二者相同；多个元素时也可能相同，例如逐个“入栈后立即出栈”。
4. **忽略“可能”与“一定”的区别**。D 只说“可能互为倒序”，并不是说所有合法情况下都互为倒序。例如 $in=(1,2,3)$，$out=(1,3,2)$ 也合法，但二者不是倒序。
5. **若题目限定栈容量，需要另加判断**。本题未限定栈容量，默认容量足够；“全部入栈再全部出栈”的方案在无容量限制时成立。

**命题规律**：本题是 408 中典型的“栈的合法出栈序列”概念辨析题，属于栈应用的基础考点。常见变式包括：

- 给定入栈序列 $1,2,\dots,n$，判断某个出栈序列是否合法；
- 给定出栈序列，反推可能的入栈序列；
- 限制栈容量为 $m$ 时判断合法性；
- 求 $n$ 个元素的合法出栈序列数量，即卡特兰数
  $$
  C_n=\frac{1}{n+1}\binom{2n}{n}.
  $$

复习时应熟练掌握“双指针 + 辅助栈”的模拟判定方法，并善于用简单例子验证“可能/一定/不能判断”等表述。

24. 采用共享栈的好处是 ( ) .
(A) 减少存取时间, 降低发生上溢的可能
(B) 节省存储空间, 降低发生上溢的可能
(C) 减少存取时间, 降低发生下溢的可能
(D) 节省存储空间, 降低发生下溢的可能

## 答案

## DeepSeek V4 Flash Max 解析

**答案**：共享栈让两个栈共用一块连续存储区、相向生长，把两个栈的空闲区合并为公共空闲区，因此能节省存储空间并降低发生上溢的可能，选 **B**。

**解题切入点**：  
拿到题先定位到“栈的顺序存储结构——共享栈”。画一个一维数组，左端是栈 1 的栈底，右端是栈 2 的栈底，两个栈顶向中间移动；中间未使用的区域是公共空闲区。共享栈的本质是“空间复用”，思路类似内存池：空间按需分配，而不是固定划分。因此优先从“节省空间”和“减少上溢”入手；它与“存取时间”“下溢”没有直接关系。

**推演**：  
设共享数组容量为 $M$，栈 1 的栈底在 $data[0]$，栈 2 的栈底在 $data[M-1]$。

令 $top_1$ 指向栈 1 的栈顶元素，$top_2$ 指向栈 2 的栈顶元素。初始时：

$$
top_1=-1,\qquad top_2=M
$$

两个栈均为空。

入栈操作：

$$
S_1:\ data[++top_1]=x;\qquad 
S_2:\ data[--top_2]=x
$$

出栈操作：

$$
S_1:\ x=data[top_1--];\qquad 
S_2:\ x=data[top_2++]
$$

两栈之间若有空闲区，则空闲区为 $data[top_1+1..top_2-1]$，所以：

$$
\text{栈满} \iff top_1+1=top_2
$$

$$
\text{可入栈} \iff top_1+1<top_2
$$

也就是说，共享栈只有在两个栈的元素总数达到 $M$ 时才会发生上溢。若固定把数组分成两个容量分别为 $c_1,c_2$ 的栈，且 $c_1+c_2=M$，则固定分法不溢出的条件是：

$$
n_1\le c_1,\quad n_2\le c_2
$$

而共享栈不溢出的条件是：

$$
n_1+n_2\le M
$$

显然，若固定分法不溢出，则共享栈一定不溢出；但共享栈还能容纳“一个栈较多、另一个栈较少”的情况。因此共享栈降低了发生上溢的可能。

关键代码思路如下：

```cpp
bool Push(SharedStack &S, int i, ElemType x) {
    if (S.top1 + 1 == S.top2) return false;   // 栈满，上溢
    if (i == 1) S.data[++S.top1] = x;
    else        S.data[--S.top2] = x;         // i == 2
    return true;
}

bool Pop(SharedStack &S, int i, ElemType &x) {
    if (i == 1) {
        if (S.top1 == -1) return false;       // 栈1空，下溢
        x = S.data[S.top1--];
    } else {
        if (S.top2 == M) return false;        // 栈2空，下溢
        x = S.data[S.top2++];
    }
    return true;
}
```

关于节省存储空间：若两个栈分别按各自最大容量 $N_1,N_2$ 分配，需要 $N_1+N_2$ 个单元；共享栈只需为任意时刻两栈元素总数上限 $C=\max_t(n_1(t)+n_2(t))$ 分配单元，且：

$$
C\le N_1+N_2
$$

所以通常能节省存储空间。而存取时间仍为 $O(1)$，共享并不会减少存取时间；下溢是“空栈出栈”，共享栈中 $top_1=-1$ 或 $top_2=M$ 时仍然判空，因此也不能降低下溢可能。

**易错点**：  
- 误把“共享”理解为“并行/加速”，从而误选“减少存取时间”。共享栈的本质是空间优化，不是时间优化。  
- 混淆“上溢”和“下溢”：上溢是入栈时栈满，下溢是出栈时栈空。共享栈降低的是上溢可能。  
- 认为共享栈一定不会上溢。实际上当两个栈元素总数达到数组容量 $M$ 时，继续入栈仍会上溢。  
- 判满条件容易写错。本文约定 $top$ 指向栈顶元素，此时满条件为 $top_1+1=top_2$；若实现时让 $top$ 指向下一个可写入位置，判满条件会变为 $top_1=top_2$，不要背混。  
- 栈 2 的方向容易写反：栈 2 入栈是 `data[--top2]=x`，出栈是 `x=data[top2++]`。

**命题规律**：  
考点定位在“栈的顺序存储结构——共享栈”，常以选择题形式考查共享栈的优点、判满条件，也可能在综合题中要求写出共享栈的入栈、出栈算法。常见变式有：给定 $top_1,top_2$ 判断栈是否满；比较普通顺序栈与共享栈的空间利用率；设计双栈共享一个数组的 `Push` 和 `Pop`。复习时应画图理解两栈相向生长的过程，牢记“上溢对应栈满入栈，下溢对应栈空出栈”，并熟练掌握共享栈的满条件与判空条件。

# 选择题 第 3 题

![[_Attachments/题目识别/27_王道408-题目/DS-C03-31-M03_题目.png|题目]]

3. 下列选项中，（ ）不是栈的基本操作.
A. 删除栈顶元素
B. 删除栈底元素
C. 判断栈是否为空
D. 将栈置为空栈

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C03-31-M03_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 B。栈是一种只允许在栈顶进行插入/删除的线性表，“删除栈底元素”不是栈的基本操作。

**解题切入点**：看到“栈的基本操作”，先回到栈的 ADT 定义：栈是受限线性表，所有插入和删除都只能在栈顶一端进行。将选项逐一对照基本操作：A 是出栈，C 是判空，D 是清空/初始化；B 涉及“栈底”，明显违背“栈顶操作受限”的原则，所以直接锁定 B。

**推演**：设栈为
$$
S=(a_1,a_2,\dots,a_n),
$$
其中 $a_1$ 是栈底，$a_n$ 是栈顶。栈的基本操作只对 $a_n$ 这一端开放：
$$
S\xrightarrow{\text{Push}(x)}(a_1,\dots,a_n,x),
$$
$$
S\xrightarrow{\text{Pop}}(a_1,\dots,a_{n-1}).
$$
如果允许直接删除 $a_1$，就破坏了栈“后进先出”的约束。

逐项判断：

- A：删除栈顶元素即出栈操作 $\text{Pop}$，是基本操作。
- B：删除栈底元素即删除 $a_1$。标准栈没有这个基本操作；若要实现，必须先将 $a_2,\dots,a_n$ 全部弹出，或用辅助栈暂存，时间复杂度为 $O(n)$，属于组合操作，不是基本操作。
- C：判断栈是否为空即 $\text{StackEmpty}(S)$，是基本操作。
- D：将栈置为空栈即 $\text{ClearStack}(S)$ 或 $\text{InitStack}(S)$，是基本操作。

补充“删除栈底且保留其他元素”的实现思路，更能说明它是组合操作而非基本操作：

```c
void DeleteBottom(Stack &S) {
    Stack T; InitStack(T); ElemType e;
    while (!StackEmpty(S)) { Pop(S, e); Push(T, e); }
    if (!StackEmpty(T)) Pop(T, e);   // 弹出原栈底
    while (!StackEmpty(T)) { Pop(T, e); Push(S, e); }
}
```

该过程借助多次基本操作完成，而 $\text{DeleteBottom}$ 本身不在栈的 ADT 基本操作集合中。

**易错点**：
- 误选 D：认为“清空栈”可以反复出栈实现，所以不是基本操作。但教材 ADT 中通常明确给出“置空栈”$\text{ClearStack}$，属于基本操作。
- 误以为数组存储下可直接移动元素删除栈底：栈是逻辑结构，不是数组；基本操作由 ADT 定义，不能因底层存储结构而随意增加。
- 忽略“判断栈是否为空”：它是栈的常用基本操作，也是进栈、出栈前的边界判断。

**命题规律**：本题属于“栈和队列”中的 ADT 概念题，408 中常以 1~2 分选择题出现。常见变式有“不是队列基本操作的是”“队列允许插入/删除的一端分别是什么”“递归调用时系统使用的工作栈”等。复习时应把栈、队列的 ADT 基本操作及其受限端记准，并与一般线性表的基本操作区分开。

# 选择题 第 10 题

![[_Attachments/题目识别/27_王道408-题目/DS-C01-12-M10_题目.png|题目]]

10. 下列算法中加下划线的语句的执行次数为（ ）.
```c
int m=0,i,j;
for(i=1;i<=n;i++)
    for(j=1;j<=2*i;j++)
        m++;
```
A. $n(n+1)$
B. $n$
C. $n+1$
D. $n^2$

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C01-12-M10_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：该语句（`m++;`）的执行次数为 $\sum_{i=1}^{n}2i=n(n+1)$，选 **A**。

**解题切入点**：先看循环结构，内层循环的上界与外层循环变量 $i$ 有关，不能直接套用“两层循环都是 $n$ 次”的结论。核心是把执行次数写成求和式：外层循环每执行一次，内层循环执行 $2i$ 次，因此总次数为 $\sum_{i=1}^{n}2i$。这类似于算法竞赛中分析时间复杂度时，遇到“循环变量相关”的嵌套循环，要先写出累加和再化简。

**推演**：

代码结构如下：

```c
int m = 0, i, j;
for (i = 1; i <= n; i++)
    for (j = 1; j <= 2 * i; j++)
        m++;
```

外层循环变量 $i$ 从 $1$ 取到 $n$，共 $n$ 次。

当 $i=1$ 时，内层循环执行 $2 \times 1 = 2$ 次；  
当 $i=2$ 时，内层循环执行 $2 \times 2 = 4$ 次；  
……  
当 $i=n$ 时，内层循环执行 $2 \times n = 2n$ 次。

因此 `m++;` 的执行总次数为

$$
\sum_{i=1}^{n} 2i
= 2\sum_{i=1}^{n} i
= 2 \cdot \frac{n(n+1)}{2}
= n(n+1).
$$

所以执行次数是 $n(n+1)$，对应选项 **A**。

易混淆点：若内层循环写成 `for (j = 1; j <= i; j++)`，则执行次数为 $\frac{n(n+1)}{2}$；本题多乘了一个 $2$，结果变为 $n(n+1)$。

**易错点**：

1. **误选 D（$n^2$）**：有些同学看到两层循环就认为执行次数是 $n \times n$，忽略了内层上界是 $2i$，不是常数 $n$。  
2. **误选 C（$n+1$）**：可能是因为把外层循环判断条件 `i <= n` 的执行次数 $n+1$ 当成了循环体执行次数，题目问的是 `m++;` 的执行次数，不是循环条件的判断次数。  
3. **求和时漏乘 2**：$\sum_{i=1}^{n} 2i$ 与 $\sum_{i=1}^{n} i$ 容易混淆，注意系数 $2$。

**命题规律**：本题属于数据结构与算法分析中的“语句频度”或“基本运算执行次数”问题，是 408 选择题和算法复杂度分析的常见基础考点。命题时常通过改变循环上界（如 $j \le i$、$j \le 2i$、$j \le i^2$ 等）来考查求和能力，也可能结合时间复杂度出题。复习时应熟练掌握：

- 将循环次数写成 $\sum$ 形式；  
- 等差、等比数列求和公式；  
- 常见复杂度阶：$O(n)$、$O(n^2)$、$O(n^3)$、$O(n\log n)$ 等。

建议在复习时把所有“循环次数与循环变量相关”的题目统一练习一遍，并养成先写求和式再化简的习惯。

# 选择题 第 13 题

![[_Attachments/题目识别/27_王道408-题目/DS-C01-12-M13_题目.png|题目]]

13.【2012统考真题】求整数 $n(n\geq0)$ 的阶乘的算法如下, 其时间复杂度是 ( ).
```c
int fact(int n){
    if(n<=1) return 1;
    return n*fact(n-1);
}
```
(A) $O(\log_2 n)$
(B) $O(n)$
(C) $O(n\log_2 n)$
(D) $O(n^2)$

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C01-12-M13_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：该递归算法每次调用只把问题规模从 $n$ 减为 $n-1$，且每次调用内都是常数时间操作，因此时间复杂度为 $O(n)$，选 **B**。

**解题切入点**：看到递归函数，第一反应不是“展开阶乘”，而是建立递推方程。关键在于判断递归调用的规模变化方式：这里是 `fact(n-1)`，即每次只减少 1，不是减半，也不是产生两个子问题，因此是线性递推，类似“剥洋葱”，剥 $n$ 层就是 $O(n)$。

**推演**：设 $T(n)$ 表示 `fact(n)` 的时间复杂度。函数体中的关键操作为：

```c
if (n <= 1) return 1;      // 常数时间 O(1)
return n * fact(n - 1);    // 一次乘法 + 一次递归调用
```

所以递推方程为：

$$
T(n)=
\begin{cases}
O(1), & n\le 1,\\
T(n-1)+O(1), & n>1.
\end{cases}
$$

令每次递归调用的固定开销为常数 $c$，则

$$
T(n)=T(n-1)+c
$$

展开得：

$$
T(n)=T(n-2)+2c=\cdots=T(1)+(n-1)c=O(n)
$$

更直观地看，当 $n\ge 1$ 时，函数会依次调用：

$$
\text{fact}(n),\ \text{fact}(n-1),\ \cdots,\ \text{fact}(1)
$$

共 $n$ 次；每次调用只做判断、乘法和返回，均为常数时间。因此总时间复杂度为：

$$
O(n)
$$

所以选 **B**。

需要注意：如果题目进一步问空间复杂度，递归深度为 $n$，递归栈空间为 $O(n)$；但本题只问时间复杂度，答案是 $O(n)$。

**易错点**：

1. 误以为“阶乘结果很大，所以时间复杂度很大”。408 中默认基本运算，如一次整数乘法，是 $O(1)$，不按大整数乘法展开。
2. 误以为有递归就有 $\log_2 n$ 因子。但本题不是二分递归，而是每次规模减 1，所以没有 $\log$ 因子。
3. 误选 $O(n^2)$。虽然要做 $n-1$ 次乘法，但 $n$ 次常数操作仍是 $O(n)$，不是 $O(n^2)$。
4. 把时间复杂度和空间复杂度混淆。递归深度为 $n$，所以若问空间复杂度应为 $O(n)$，但时间仍是 $O(n)$。

**命题规律**：本题属于“递归算法时间复杂度分析”的基础题。408 中常给出递归函数，要求写出递推方程并求复杂度。常见变式有：

- 朴素递归求斐波那契数列：$T(n)=T(n-1)+T(n-2)+O(1)$，复杂度为指数级 $O(2^n)$；
- 二分递归：$T(n)=2T(n/2)+O(1)$，复杂度为 $O(n)$；
- 分治算法：$T(n)=2T(n/2)+O(n)$，复杂度为 $O(n\log n)$。

复习时应熟练掌握递推方程展开法和主定理，并重点关注递归规模变化方式：“减 1”“减半”“分成两个子问题”分别对应不同的复杂度。

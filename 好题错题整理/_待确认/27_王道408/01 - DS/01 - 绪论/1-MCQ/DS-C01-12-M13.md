![[_Attachments/题目识别/27_王道408-题目/DS-C01-12-M13_题目.png|题目]]

13.【2012统考真题】求整数 $n(n\geq0)$ 的阶乘的算法如下, 其时间复杂度是 ( ).
```c
int fact(int n){
    if(n<=1) return 1;
    return n*fact(n-1);
}
```
(A) $O(\log_2 n)$
(B) $O(n)$
(C) $O(n\log_2 n)$
(D) $O(n^2)$

# 选择题 第 15 题

![[_Attachments/题目识别/27_王道408-题目/DS-C01-12-M15_题目.png|题目]]

15.【2017统考真题】下列函数的时间复杂度是 ( ).
```c
int func(int n){
    int i=0, sum=0;
    while(sum<n) sum += ++i;
    return i;
}
```
A. $O(\log_2 n)$ 
B. $O(n^{1/2})$ 
C. $O(n)$ 
D. $O(n \log_2 n)$

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C01-12-M15_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 **B**。函数的时间复杂度是 \(O(n^{1/2})\)，即循环次数约为 \(\Theta(\sqrt n)\)。

**解题切入点**：  
看到 `while(sum<n) sum += ++i;` 时，不能只看到 `i` 每轮加 1。关键在于 `sum` 的累加方式：`++i` 使每轮加入 `sum` 的数值依次是 \(1,2,3,\dots\)，所以 `sum` 是前若干自然数之和。这类“累加值达到 \(n\)”的题，应设循环执行 \(k\) 次，写出第 \(k\) 次后 `sum` 的表达式，再反解 \(k\)。

**推演**：  
设循环体执行 \(k\) 次后停止。执行第 \(j\) 次循环时：

- `++i` 使第 \(j\) 次循环开始时 \(i\) 变为 \(j\)；
- 然后执行 `sum += j`。

所以执行 \(k\) 次后：

\[
i_k=k,
\]

\[
sum_k=1+2+\cdots+k=\frac{k(k+1)}2.
\]

循环停止时满足：

\[
\frac{(k-1)k}{2}<n\le \frac{k(k+1)}2.
\]

由右边不等式：

\[
n\le \frac{k(k+1)}2\le \frac{(k+1)^2}{2},
\]

所以

\[
k\ge \sqrt{2n}-1.
\]

由左边不等式：

\[
\frac{(k-1)k}{2}<n,
\]

且

\[
\frac{(k-1)^2}{2}<\frac{(k-1)k}{2}<n,
\]

所以

\[
k<\sqrt{2n}+1.
\]

因此：

\[
\sqrt{2n}-1<k<\sqrt{2n}+1.
\]

故

\[
k=\Theta(\sqrt n).
\]

更精确地，由

\[
\frac{k(k+1)}2\ge n
\]

解得：

\[
k=\left\lceil\frac{\sqrt{8n+1}-1}{2}\right\rceil,
\]

仍然是 \(\Theta(\sqrt n)\) 量级。

循环体内只有常数次运算，`return i` 也是 \(O(1)\)，所以总时间复杂度为：

\[
O(n^{1/2}).
\]

选 **B**。

**易错点**：  
- 误把 `sum += ++i` 看成 `sum += i; i++;` 或 `sum += i++;`，会得到 \(sum_k=\frac{k(k-1)}2\)。本题渐近复杂度不变，但精确计数会差一项。  
- 只看到 `i` 每次加 1，误以为循环执行 \(O(n)\) 次。实际上 `sum` 增加得越来越快，第 \(k\) 次后 \(sum\approx k^2/2\)，因此循环次数是根号量级。  
- 写成 \(O(\sqrt{2n})\) 不够规范，应去掉常数，写为 \(O(\sqrt n)\)。  
- 注意循环条件是 `<` 而不是 `<=`，这会影响精确停止位置，但不影响渐近复杂度。

**命题规律**：  
本题属于数据结构绪论中的“时间复杂度分析”，是 408 高频基础考点。命题人常通过循环变量和累加变量的变化设置干扰。常见变式有：

- `while(i*i<n) i++;`
- `while(sum<n) sum += i++;`
- `while(sum<n) sum += i, i++;`

这类题的本质都是：设循环次数为 \(k\)，把相关变量写成 \(k\) 的函数，再解关于 \(k\) 的不等式。复习时建议总结常见增长模型：等差累加对应 \(\sqrt n\) 量级，等比累加或折半对应 \(\log n\) 量级，线性累加对应 \(O(n)\) 量级。

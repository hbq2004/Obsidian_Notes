15.【2017统考真题】下列函数的时间复杂度是 ( ).
```c
int func(int n){
    int i=0, sum=0;
    while(sum<n) sum += ++i;
    return i;
}
```
A. $O(\log_2 n)$ 
B. $O(n^{1/2})$ 
C. $O(n)$ 
D. $O(n \log_2 n)$

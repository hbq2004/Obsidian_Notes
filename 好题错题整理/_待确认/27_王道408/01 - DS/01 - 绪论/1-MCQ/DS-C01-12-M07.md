# 选择题 第 7 题

7. 下列算法的时间复杂度为 ( ).

```c
void fun(int n) {
    int i = 0;
    while (i * i * i <= n) {
        i++;
    }
}
```

(A) $O(n)$
(B) $O(n\log_2 n)$
(C) $O(\sqrt[3]{n})$
(D) $O(\sqrt{n})$

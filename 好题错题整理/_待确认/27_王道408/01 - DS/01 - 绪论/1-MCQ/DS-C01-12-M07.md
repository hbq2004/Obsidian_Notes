# 选择题 第 7 题

![[_Attachments/题目识别/27_王道408-题目/DS-C01-12-M07_题目.png|题目]]

7. 下列算法的时间复杂度为 ( ).

```c
void fun(int n) {
    int i = 0;
    while (i * i * i <= n) {
        i++;
    }
}
```

(A) $O(n)$
(B) $O(n\log_2 n)$
(C) $O(\sqrt[3]{n})$
(D) $O(\sqrt{n})$

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C01-12-M07_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 C，时间复杂度为 $O(\sqrt[3]{n})$，严格地说循环次数为 $\lfloor \sqrt[3]{n}\rfloor+1=\Theta(\sqrt[3]{n})$。

**解题切入点**：  
单层循环的时间复杂度取决于“循环体执行了多少次”，而不是循环变量最大能到多少。本题中 $i$ 每次只增加 1，所以循环次数大致等于 $i$ 从 0 开始增加到使 $i^3>n$ 所需要的步数，因此与 $\sqrt[3]{n}$ 同阶。  
类似地：  
- `while (i * i <= n) i++;` 是 $O(\sqrt n)$；  
- `while (i <= n) i *= 2;` 是 $O(\log n)$；  
- 本题是 `while (i * i * i <= n) i++;`，所以是 $O(\sqrt[3]{n})$。

**推演**：  
设循环体执行次数为 $T(n)$。循环开始时 $i=0$，每执行一次循环体，$i$ 就增加 1，所以执行 $t$ 次之后：

$$
i=t
$$

循环条件为：

$$
i^3 \le n
$$

令

$$
m=\lfloor \sqrt[3]{n}\rfloor
$$

则当 $i=0,1,2,\dots,m$ 时，都有：

$$
i^3 \le n
$$

循环体会继续执行；当 $i=m+1$ 时：

$$
(m+1)^3>n
$$

循环停止。因此循环体执行次数为：

$$
T(n)=m+1=\lfloor \sqrt[3]{n}\rfloor+1
$$

所以：

$$
T(n)=\Theta(\sqrt[3]{n})
$$

即时间复杂度为：

$$
O(\sqrt[3]{n})
$$

循环体中只有常数次基本操作，如自增、乘法、比较，常数因子不影响渐进时间复杂度。

**易错点**：  
1. 不要误以为循环变量从 0 到 $n$，所以时间复杂度是 $O(n)$；循环终止条件是 $i^3\le n$，不是 $i\le n$。  
2. 不要与 $i^2\le n$ 混淆，后者是 $O(\sqrt n)$，本题是三次方，应开三次方。  
3. 条件中的乘法运算虽然不止一次，但是常数次，不影响复杂度量级。  
4. 虽然宽松地说 $O(\sqrt[3]{n})$ 也可以归入 $O(\sqrt n)$，但题目要求最紧凑的时间复杂度描述，所以选 C 而不是 D。

**命题规律**：  
本题属于数据结构第一章“时间复杂度分析”的基础题，核心是统计循环迭代次数。常见变式包括：  
- 循环变量每次乘以 2：$O(\log n)$；  
- 循环变量每次加 1，条件为 $i^2\le n$：$O(\sqrt n)$；  
- 嵌套循环中内外层变量互相影响：需用求和或级数分析。  

复习时应抓住“由循环条件解出循环变量的终值，再看变量从初值到终值的变化方式”：若每次加常数，通常是一次或开方阶；若每次乘以常数，通常是对数阶。

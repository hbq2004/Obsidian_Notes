11. 下列函数代码的时间复杂度是 (  ).
```cpp
int Func(int n){
    if(n==1) return 1;
    else return 2*Func(n/2)+n;
}
```
(A) $O(n)$
(B) $O(n\log_2 n)$
(C) $O(\log_2 n)$
(D) $O(n^2)$

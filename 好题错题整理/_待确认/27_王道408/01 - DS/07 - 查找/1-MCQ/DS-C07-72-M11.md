# 选择题 第 11 题

![[_Attachments/题目识别/27_王道408-题目/DS-C07-72-M11_题目.png|题目]]

11. 若有序表的关键字序列为 $\{b,c,d,e,f,g,q,r,s,t\}$，则在二分查找关键字 $b$ 的过程中，进行比较的关键字依次为( ).

A. $f,c,b$
B. $f,d,b$
C. $g,c,b$
D. $g,d,b$

## DeepSeek V4 Flash Max 解析

**答案**：选 A。按 408 默认的 $mid=\lfloor(low+high)/2\rfloor$ 规则，二分查找关键字 $b$ 时依次比较的关键字为 $f,c,b$。

**解题切入点**：拿到题先确定“下标-关键字”映射，并固定二分查找的写法：查找区间为闭区间 $[low,high]$，每次取 $mid=\lfloor(low+high)/2\rfloor$，然后根据关键字大小向左或向右缩小区间。这类题本质是模拟二分查找流程，也可借助“折半查找判定树”的路径来快速判断。

**推演**：设下标从 1 开始，则有序表为
$$
1:b,\ 2:c,\ 3:d,\ 4:e,\ 5:f,\ 6:g,\ 7:q,\ 8:r,\ 9:s,\ 10:t
$$
查找关键字 $key=b$。

第 1 次比较：
$$
low=1,\ high=10,\ mid=\left\lfloor\frac{1+10}{2}\right\rfloor=5
$$
第 5 个关键字是 $f$，比较 $b$ 与 $f$。因为 $b<f$，所以应到左半区继续查找：
$$
high=mid-1=4
$$

第 2 次比较：
$$
low=1,\ high=4,\ mid=\left\lfloor\frac{1+4}{2}\right\rfloor=2
$$
第 2 个关键字是 $c$，比较 $b$ 与 $c$。因为 $b<c$，继续到左半区：
$$
high=mid-1=1
$$

第 3 次比较：
$$
low=1,\ high=1,\ mid=1
$$
第 1 个关键字是 $b$，与 $key$ 相等，查找成功。

所以比较序列为：
$$
f,\ c,\ b
$$

关键代码思路为：
```c
int low = 1, high = n;
while (low <= high) {
    int mid = (low + high) / 2;
    if (key == a[mid]) return mid;
    else if (key < a[mid]) high = mid - 1;
    else low = mid + 1;
}
```
注意循环条件必须允许 $low=high$，否则最后只剩一个元素时可能漏查。

**易错点**：
1. 不要把第一次中间位置取成第 6 个元素 $g$。那是把 $mid$ 向上取整得到的结果，不是 408 常用的下取整写法。
2. 第一次比较后应令 $high=mid-1$，如果误写成 $high=mid$，会得到选项 B 的 $f,d,b$。
3. 第二次比较后同理要注意边界更新，$b<c$，所以 $high$ 应更新为 $1$。
4. 循环条件不能写成 $low<high$，否则最后 $low=high=1$ 时不会比较 $b$，导致错误。
5. 关键字是字母，应按字典序比较；$b$ 在序列中最靠左，因此每次都应向左半区走。

**命题规律**：本题属于“二分查找过程模拟”，是 408 数据结构常考选择题。常见变式包括：给出有序表与查找关键字求比较序列；根据折半查找判定树求查找成功或失败的平均查找长度 $ASL$；已知比较次数反推表长范围；以及二分查找与顺序查找、分块查找的性能比较。复习时要重点掌握 $mid=\lfloor(low+high)/2\rfloor$ 的判定树画法，以及边界更新规则 $high=mid-1$、$low=mid+1$、循环条件 $low\le high$。

# 选择题 第 6 题

![[_Attachments/题目识别/27_王道408-题目/DS-C07-73-M06_题目.png|题目]]

6. 分别以下列序列构造二叉排序树,与用其他3个序列所构造的结果不同的是 ( ).
A. (100,80,90,60,120,110,130)
B. (100,120,110,130,80,60,90)
C. (100,60,80,90,120,110,130)
D. (100,80,60,90,120,130,110)

![[_Attachments/题目识别/27_王道408-答案/DS-C07-73-M06_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 C。$A,B,D$ 三个序列依次插入空二叉排序树后得到的是同一棵树，$C$ 得到的二叉排序树与其他三个不同。

**解题切入点**：  
先抓住 BST 构造的两个关键：  
1. 第一个插入的结点一定是整棵树的根；  
2. 每个子树只由“该子树中的元素在原序列中出现的相对顺序”决定。

因此拿到题可以先按根 $100$ 把所有元素划分为小于 $100$ 和大于 $100$ 两部分，再递归比较左右子树，而不是盲目完整模拟四个序列。也不要只看中序序列，因为所有序列含相同关键字，中序序列一定是同一个有序序列。

**推演**：

插入规则：从根开始，若待插关键字小于当前结点，向左走；若大于当前结点，向右走；直到空位置插入。

所有序列第一个元素都是 $100$，所以根都是 $100$。  
记：
\[
L=\{60,80,90\},\qquad R=\{110,120,130\}
\]
分别看各序列中小于 $100$ 和大于 $100$ 的元素按原顺序组成的子序列：

| 序列 | 小于 $100$ 的子序列 | 大于 $100$ 的子序列 | 构造结果 |
|---|---|---|---|
| A | $(80,90,60)$ | $(120,110,130)$ | 左子树根为 $80$，$60$ 在左、$90$ 在右；右子树根为 $120$，$110$ 在左、$130$ 在右 |
| B | $(80,60,90)$ | $(120,110,130)$ | 与 A 完全相同 |
| C | $(60,80,90)$ | $(120,110,130)$ | 左子树根为 $60$，形成 $60 \to 80 \to 90$ 的右单链；右子树与 A 相同 |
| D | $(80,60,90)$ | $(120,130,110)$ | 与 A 完全相同 |

因此 A、B、D 得到的二叉排序树为：

```text
        100
       /   \
      80    120
     / \    / \
    60 90  110 130
```

C 得到的二叉排序树为：

```text
        100
       /   \
      60    120
       \    / \
       80  110 130
        \
        90
```

也可用前序遍历序列快速对比：

\[
\operatorname{pre}(A)=\operatorname{pre}(B)=\operatorname{pre}(D)
=(100,80,60,90,120,110,130)
\]

\[
\operatorname{pre}(C)=(100,60,80,90,120,110,130)
\]

关键代码思路就是标准 BST 插入：

```cpp
Node* insert(Node* root, int key) {
    if (root == NULL) return newNode(key);
    if (key < root->val)
        root->left = insert(root->left, key);
    else
        root->right = insert(root->right, key);
    return root;
}
```

**易错点**：

- 不要认为“插入序列不同，二叉排序树一定不同”。A、B、D 的插入顺序不同，但构造结果相同。
- 不要用中序序列判断树形，因为同一组关键字的中序序列都是 $60,80,90,100,110,120,130$，无法区分。
- 插入 C 中的 $90$ 时，路径是 $100 \to 60 \to 80$，所以 $90$ 成为 $80$ 的右孩子，而不是 $60$ 的左孩子。
- D 中 $130$ 先于 $110$ 插入，但 $110$ 仍应插入到 $120$ 的左子树，不会改变右子树形状。

**命题规律**：  
本题属于“二叉排序树的构造”考点，常以选择题形式考查插入序列与树形的关系、平均查找长度、比较次数等。复习时要会用“第一个插入元素为根，递归划分左右子序列”的方法快速判断树形；同时注意区分 BST、AVL、堆等不同结构的构造规则。常见变式包括：给一个 BST 前序/层序序列，判断哪些插入序列能构造出同一棵树；或计算某种插入顺序下的 ASL。

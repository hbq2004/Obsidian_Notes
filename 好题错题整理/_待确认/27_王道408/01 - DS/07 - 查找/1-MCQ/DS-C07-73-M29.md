# 选择题 第 29 题

![[_Attachments/题目识别/27_王道408-题目/DS-C07-73-M29_题目.png|题目]]

29.【2015 统考真题】现有一棵无重复关键字的平衡二叉树 ($AVL$)，对其进行中序遍历可得到一个降序序列。下列关于该平衡二叉树的叙述中，正确的是 ( )。
(A) 根结点的度一定为 2
(B) 树中最小元素一定是叶结点
(C) 最后插入的元素一定是叶结点
(D) 树中最大元素一定是无左子树

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C07-73-M29_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 D。树中最大元素一定是中序遍历的第一个结点，而中序遍历的第一个结点必无左子树。

**解题切入点**：看到“中序遍历”和“降序”同时出现，应立刻把遍历顺序转化为树中关键字的大小分布：中序为“左—根—右”，降序说明左子树元素 $>$ 根元素 $>$ 右子树元素，即“左大右小”。AVL 只是在此基础上加了平衡条件，并不改变 BST 的有序性。然后抓“中序首尾结点”：降序序列的第一个元素是最大值，而中序第一个访问的结点一定是沿左链走到尽头的结点，因此无左子树。

**推演**：中序序列为  
$$
a_1>a_2>\cdots>a_n
$$
对于任意结点 $x$：
- $x$ 的左子树整体在 $x$ 之前访问，所以左子树中所有关键字都大于 $x$；
- $x$ 的右子树整体在 $x$ 之后访问，所以右子树中所有关键字都小于 $x$。

因此该 AVL 树等价于一个“左大右小”的 BST。

中序遍历的第一个结点 $p$ 是从根开始不断沿左孩子指针走到尽头的结点，所以 $p$ 一定没有左子树。又因为中序序列降序，$p$ 的关键字就是全树最大值，所以“树中最大元素一定是无左子树”，D 正确。

排除其余选项：

- A 错：例如  
```
    5
   /
  6
```
中序为 $6,5$，平衡因子绝对值不超过 $1$，根结点度为 $1$，不是 $2$。

- B 错：例如  
```
      3
     / \
    4   1
       /
      2
```
中序为 $4,3,2,1$，是 AVL；最小元素 $1$ 有左孩子 $2$，不是叶结点。

- C 错：最后插入的元素不一定是叶结点。例如按“左大右小”规则依次插入 $5,6,2,4,3$，插入 $3$ 后发生双旋转，最终得到  
```
      5
     / \
    6   3
       / \
      4   2
```
中序为 $6,5,4,3,2$，是 AVL；最后插入的 $3$ 有左右孩子，不是叶结点。

**易错点**：
- 不要把“降序中序”当成普通“升序 BST”来分析，否则容易误判最大元素的位置。降序对应“左大右小”。
- 不要混淆“无左子树”与“是叶结点”。中序第一个结点可以有右孩子，所以最大元素不一定叶，但一定无左子树。
- 误以为“最后插入的结点一定是叶结点”，忽略 AVL 旋转会使新插入的结点从叶子变为内部结点。
- 判断“一定”类选项时，应主动构造 $2\sim 4$ 个结点的反例来排除。

**命题规律**：本题考点是 AVL/BST 中序遍历有序性与树形态的关系，以及 AVL 旋转对结点位置的影响。常见变式：若中序为升序，则最小元素无左子树、最大元素无右子树；或问某元素“一定/可能”有某个孩子。复习时应重点掌握中序遍历第一个/最后一个结点的充要条件、平衡因子计算，以及单旋/双旋后各结点子树的变化。

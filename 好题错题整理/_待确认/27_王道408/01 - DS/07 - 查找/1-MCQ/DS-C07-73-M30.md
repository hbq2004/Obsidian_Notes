30.【2018统考真题】已知二叉排序树如右图所示，元素之间应满足的大小关系是 ( ) .
A. $x_1 < x_2 < x_5$
B. $x_1 < x_4 < x_5$
C. $x_3 < x_5 < x_4$
D. $x_4 < x_3 < x_5$
【图：节点$x_1$为根，其右孩子为$x_2$；$x_2$的左孩子为$x_3$；$x_3$的右孩子为$x_4$；$x_4$的左孩子为$x_5$.】

## DeepSeek V4 Flash Max 解析

**答案**：C. $x_3 < x_5 < x_4$（由二叉排序树性质推导出全局顺序 $x_1 < x_3 < x_5 < x_4 < x_2$，故选项 C 正确）

**解题切入点**：二叉排序树（BST）的核心性质是递归的：左子树所有节点值小于根，右子树所有节点值大于根。本题给出树形结构，只需从根开始，逐层应用该性质，并注意跨越层级的约束（如祖先‑后代关系）。可将 BST 比作“家族辈分”：左子树是“小辈”，右子树是“大辈”，但嵌套时要保持全局一致性。

**推演**：
根据题目描述，树的结构如下：
- $x_1$ 为根；
- $x_2$ 是 $x_1$ 的右孩子；
- $x_3$ 是 $x_2$ 的左孩子；
- $x_4$ 是 $x_3$ 的右孩子；
- $x_5$ 是 $x_4$ 的左孩子。

由 BST 性质逐层推导：
1. 直接父子关系：
   - $x_2 > x_1$（$x_2$ 在 $x_1$ 右子树）
   - $x_3 < x_2$（$x_3$ 在 $x_2$ 左子树）
   - $x_4 > x_3$（$x_4$ 在 $x_3$ 右子树）
   - $x_5 < x_4$（$x_5$ 在 $x_4$ 左子树）
2. 跨越层级的关系：
   - $x_3$ 在 $x_1$ 的右子树中（因为 $x_3$ 是 $x_2$ 的后代），故 $x_3 > x_1$，结合 $x_3 < x_2$ 得：$x_1 < x_3 < x_2$。
   - $x_4$ 在 $x_2$ 的左子树中（因为 $x_4$ 是 $x_3$ 的后代，而 $x_3$ 在 $x_2$ 左子树），故 $x_4 < x_2$，结合 $x_4 > x_3$ 得：$x_3 < x_4 < x_2$。
   - $x_5$ 在 $x_3$ 的右子树中（因为 $x_5$ 是 $x_4$ 的后代，而 $x_4$ 在 $x_3$ 右子树），故 $x_5 > x_3$，结合 $x_5 < x_4$ 得：$x_3 < x_5 < x_4$。
   - $x_5$ 也在 $x_2$ 的左子树中，故 $x_5 < x_2$，自动满足。
3. 综合所有不等式，得到全局顺序：
   $$x_1 < x_3 < x_5 < x_4 < x_2$$
因此，只有选项 C $x_3 < x_5 < x_4$ 与推导一致，其他选项均矛盾。

**易错点**：
- 只关注直接父子关系，忽略祖先与后代之间的全局约束，例如误认为 $x_3$ 与 $x_1$ 的大小不确定。
- 混淆左右子树方向，将左孩子误判为大于根，右孩子误判为小于根。
- 在推导 $x_4$ 与 $x_2$ 的关系时，容易忽略 $x_4$ 仍在 $x_2$ 的左子树中（因为 $x_4$ 是 $x_2$ 的左子树的节点），从而得出 $x_4 > x_2$ 的错误结论。
- 在推导 $x_5$ 与 $x_3$ 的关系时，注意 $x_5$ 是 $x_4$ 的左孩子，但 $x_4$ 是 $x_3$ 的右孩子，所以 $x_5$ 在 $x_3$ 的右子树中，应有 $x_5 > x_3$，而非 $x_5 < x_3$。

**命题规律**：本题属于二叉排序树基础性质的应用，考查对 BST 递归定义的深入理解。常见变式包括：给定树形判断可能的插入顺序、给定中序遍历序列与树形求节点值关系、或结合平衡二叉树等知识点。复习时，应熟练掌握 BST 的中序遍历为递增序列这一重要性质，并能够从任意节点出发递归推导大小关系。对于此类问题，可先画出树形，在每个节点处标注“左<根<右”，然后综合考虑所有不等式，最终得到全局的顺序，从而快速判断选项。

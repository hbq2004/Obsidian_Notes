## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C07-73-M21_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：依次插入 $5,4,3,2,1$ 后，红黑树最终形态为根 $4$（黑），左孩子 $2$（黑）且其左右孩子 $1,3$ 均为红，右孩子 $5$（黑），故选 **D**。

**解题切入点**：看到“依次插入 + 求最终形态”，应按红黑树插入算法逐步模拟，不能只看最终树是否满足红黑树性质，因为可能有多个选项都是合法红黑树。核心口诀是：新结点先染红；父黑不动，父红看叔父；叔红则变色上移，叔黑则旋转变色。

**推演**：

约定：$B$ 表示黑色，$R$ 表示红色；图中省略 NIL 叶结点，但 NIL 叶结点均视为黑色。

红黑树插入规则：
- 新插入结点先染红；
- 若父结点为黑，结束；
- 若父结点为红，则出现“双红”，此时看叔父颜色：
  - 叔父为红：父、叔父变黑，祖父变红，再把祖父作为当前结点继续调整；
  - 叔父为黑：按 LL/RR/LR/RL 情况进行旋转，并令父结点变黑、祖父变红；
- 最后强制根结点为黑色。

逐步模拟：

1. 插入 $5$：
```
5(B)
```

2. 插入 $4$：作为 $5$ 的左孩子，父结点 $5$ 为黑，无需调整：
```
  5(B)
 /
4(R)
```

3. 插入 $3$：出现双红，叔父为 NIL，是黑色，且属于 LL 情况，右旋祖父 $5$，并令 $4$ 变黑、$5$ 变红：
```
  4(B)
 /   \
3(R) 5(R)
```

4. 插入 $2$：
```
    4(B)
   /   \
 3(R)  5(R)
 /
2(R)
```
叔父 $5$ 为红，所以 $3,5$ 变黑，祖父 $4$ 变红；又因 $4$ 是根，再染黑：
```
    4(B)
   /   \
 3(B)  5(B)
 /
2(R)
```

5. 插入 $1$：
```
      4(B)
     /   \
   3(B)  5(B)
   /
 2(R)
 /
1(R)
```
$1$ 的父结点 $2$ 为红，祖父 $3$ 为黑，叔父为 NIL 黑色，且属于 LL 情况，右旋祖父 $3$，并令 $2$ 变黑、$3$ 变红：
```
        4(B)
       /   \
    2(B)   5(B)
   /   \
1(R)  3(R)
```

该形态满足红黑树所有性质，与选项 D 一致，因此答案为 **D**。

**易错点**：
- 只判断最终形态是否满足红黑树性质是不够的，例如选项 C 也可以是一棵合法红黑树，但不是该插入顺序的结果。
- 新插入结点忘记染红，或调整到根时忘记把根染黑。
- 叔父为红时，容易忘记把祖父变红并继续向上调整；当祖父就是根时，还要再染黑。
- 旋转方向容易搞混：本题插入 $3$、插入 $1$ 时都是 LL 情况，应右旋祖父，而不是左旋。

**命题规律**：本题考查红黑树插入调整，属于 408 中较综合、易错的知识点。常见变式有：给出插入序列判断最终树形或某结点颜色；给出红黑树判断插入后是否需要旋转；结合黑高、红结点数量命题。复习时应把红黑树插入的“叔红变色、叔黑旋转”流程手推熟练，尤其要分清 LL/RR/LR/RL 四种旋转情况。

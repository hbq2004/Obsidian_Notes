## DeepSeek V4 Flash Max 解析

**答案**：  
本题包含两道题：  
第 2 题（B 树操作）核心是严格按 3 阶 B 树的“插入分裂、删除借位/合并”规则逐步调整；最终在依次执行 ①~⑤ 后，B 树变为：根为 `[30]`，左子树以 `[20]` 为根，右子树以 `[40,50]` 为根，且各叶子均满足 3 阶 B 树约束。  
第 3 题（B 树索引计算）核心结论为：B 树的阶数应为 \(m=267\)（即每个结点最多 \(266\) 个关键字）；若按结点满载计算，索引部分约需占用 \(75473\) 个磁盘页块；若按最坏半满情况计算，约需 \(151509\) 个磁盘页块。

---

**解题切入点**：  
- 第 2 题：拿到“3 阶 B 树”的第一反应是明确 3 阶 B 树的结点容量：每个结点最多 \(2\) 个关键字，最少 \(1\) 个关键字（根结点可以例外，若根为叶子则允许 \(0\) 个关键字）。然后按“先找到插入位置→插入→若溢出则分裂”“先找到删除位置→删除→若下溢则先借兄弟、借不到就合并”的流程逐步推演。这类题就像“搭积木”，每次操作只看局部结点与邻接兄弟，不要全局重画，抓住“分裂/合并”的触发条件即可。  
- 第 3 题：核心是“一个磁盘页块对应一个 B 树结点”，用结点容量方程求阶数；再根据记录总数算出叶子层结点数，逐层向上累加。本质是“由页块大小求容量，再由数据量求结点数”的存储容量估算题。

## 第 2 题：3 阶 B 树插入与删除

初始 3 阶 B 树：

```
           [50]
         /      \
      [30]      [80]
     /    \     /   \
  [8,20] [35,40] [60] [100]
```

### ① 插入 90

- 从根 `[50]` 开始，\(90 > 50\)，进入右子树；
- 在根 `[80]` 中，\(90 > 80\)，进入右叶子 `[100]\)；
- 插入后叶子为 `[90,100]`，关键字数 \(2\)，对 3 阶 B 树不溢出。

结果：

```
           [50]
         /      \
      [30]      [80]
     /    \     /   \
  [8,20] [35,40] [60] [90,100]
```

---

### ② 插入 25

- 从根 `[50]` 开始，\(25 < 50\)，进入左子树；
- 在结点 `[30]` 中，\(20 < 25 < 30\)，进入左叶子 `[8,20]\)；
- 插入后叶子变为 `[8,20,25]\)，关键字数 \(3>2\)，溢出；
- 分裂：中间关键字 \(20\) 上移到父结点 `[30]\)，父结点变为 `[20,30]\)；
- 原叶子分裂为两个叶子：`[8]` 和 `[25]`；这两个叶子按顺序挂在 `[20,30]` 下：`[8]` 为左子树，`[25]` 为中间子树；
- 原 `[35,40]` 仍作为 `[20,30]` 的右子树。

结果：

```
           [50]
         /      \
     [20,30]    [80]
    /   |   \   /   \
  [8] [25] [35,40] [60] [90,100]
```

注意：结点 `[20,30]` 有 \(2\) 个关键字、\(3\) 个子指针，满足 3 阶 B 树。

---

### ③ 插入 45

- 从根 `[50]` 开始，\(30 < 45 < 50\)，进入中间子树；
- 在结点 `[20,30]` 中，\(45 > 30\)，进入右叶子 `[35,40]\)；
- 插入后叶子为 `[35,40,45]\)，溢出；
- 分裂：中间关键字 \(40\) 上移到父结点 `[20,30]\)，父结点变为 `[20,30,40]\)；
- 但 `[20,30,40]\) 又溢出，继续分裂：中间关键字 \(30\) 上移到根 `[50]\)；
- 根变为 `[30,50]\)；
- 原 `[20,30,40]\) 分裂为 `[20]` 和 `[40]\)：
  - `[20]` 的左子树为 `[8]`，右子树为 `[25]\)；
  - `[40]` 的左子树为 `[35]`，右子树为 `[45]\)；
- 根 `[30,50]\) 的三个子树分别为：`[20]`、`[40]`、`[80]\)。

结果：

```
            [30,50]
          /    |     \
       [20]   [40]   [80]
      /   \  /   \   /   \
    [8] [25] [35] [45] [60] [90,100]
```

此时 B 树高度从 2 变为 3，仍满足 3 阶 B 树性质。

---

### ④ 删除 60

- 找到 `60`：在叶结点 `[60]` 中；
- 删除 `60` 后该叶结点变为空，发生下溢；
- 父结点为 `[80]\)，其右兄弟为 `[90,100]\)，右兄弟有 \(2\) 个关键字，大于最小值 \(1\)，可以借位；
- 进行“旋转借位”：
  - 将父结点关键字 `80` 下移到空叶结点中，得到 `[80]\)；
  - 将右兄弟的最小关键字 `90` 上移到父结点位置，父结点变为 `[90]\)；
  - 右兄弟变为 `[100]\)；
- 此时父结点 `[90]\) 的左子树为 `[80]\)，右子树为 `[100]\)，均不空。

结果：

```
            [30,50]
          /    |     \
       [20]   [40]   [90]
      /   \  /   \   /   \
    [8] [25] [35] [45] [80] [100]
```

---

### ⑤ 删除 80

- 找到 `80`：在叶结点 `[80]` 中；
- 删除 `80` 后该叶结点为空，发生下溢；
- 父结点为 `[90]\)，右兄弟为 `[100]\)，右兄弟只有 \(1\) 个关键字，等于最小值 \(1\)，不能借位，只能合并；
- 合并：将父结点关键字 `90` 与右兄弟关键字 `100` 并入空叶结点，得到 `[90,100]\)；
- 父结点 `[90]\) 变为空结点；
- 继续处理：空结点是根 `[30,50]\) 的右子树；
  - 根 `[30,50]\) 的中间子树为 `[40]\)，左子树为 `[20]\)；
  - 将根中夹在 `[40]\) 与空结点之间的关键字 `50` 下移；
  - 将中间子树 `[40]\) 与关键字 `50` 合并，得到新结点 `[40,50]\)；
  - 根变为 `[30]\)；
- 结点 `[40,50]\) 的三个子树分别为：`[35]`、`[45]`、`[90,100]\)。

最终结果：

```
             [30]
           /      \
        [20]      [40,50]
       /   \      /   |    \
     [8] [25]  [35] [45] [90,100]
```

检查：根 `[30]` 有 \(1\) 个关键字、\(2\) 个子指针；结点 `[20]\) 有 \(1\) 个关键字、\(2\) 个子指针；结点 `[40,50]\) 有 \(2\) 个关键字、\(3\) 个子指针；所有叶子结点关键字数均在 \([1,2]\) 内，满足 3 阶 B 树。

## 第 3 题：B 树索引阶数与磁盘页块数计算

已知：

- 磁盘页块大小：\(4000\,B\)
- 磁盘地址指针：\(5\,B\)
- 每个记录：\(200\,B\)，其中关键字占 \(5\,B\)
- 记录总数：\(N = 20000000\)

由于数据文件未按关键字有序排列，必须建立稠密索引，即每个记录对应一个索引项。

### 1. 求 B 树的阶数 \(m\)

设 B 树为 \(m\) 阶，则每个结点最多有 \(m\) 个子指针，最多有 \(m-1\) 个关键字。

每个索引项需要存储：

- 关键字：\(5\,B\)
- 指向数据记录的磁盘地址指针：\(5\,B\)

所以每个索引项占 \(10\,B\)。

每个 B 树结点的存储空间包括：

- \(m\) 个子指针：\(5m\,B\)
- \(m-1\) 个索引项：\(10(m-1)\,B\)

结点总大小不能超过一个磁盘页块：

\[
5m + 10(m-1) \le 4000
\]

整理：

\[
5m + 10m - 10 \le 4000
\]

\[
15m \le 4010
\]

\[
m \le 267.33
\]

取整数，得：

\[
m = 267
\]

因此 B 树的阶数为 \(267\)，即每个结点最多 \(266\) 个关键字。

---

### 2. 求索引部分占用的磁盘页块数

每个 B 树结点对应一个磁盘页块。

#### 情况一：按结点满载计算

每个叶子结点最多存放 \(266\) 个索引项。

叶子层结点数：

\[
\left\lceil \frac{20000000}{266} \right\rceil = 75188
\]

因为：

\[
266 \times 75187 = 19999742 < 20000000
\]

\[
266 \times 75188 = 20000008 > 20000000
\]

所以需要 \(75188\) 个叶子页块。

向上逐层计算内部结点数：

第 2 层每个结点最多有 \(267\) 个子指针，因此可覆盖 \(267\) 个下层结点：

\[
\left\lceil \frac{75188}{267} \right\rceil = 282
\]

第 3 层：

\[
\left\lceil \frac{282}{267} \right\rceil = 2
\]

第 4 层（根层）：

\[
\left\lceil \frac{2}{267} \right\rceil = 1
\]

总页块数：

\[
75188 + 282 + 2 + 1 = 75473
\]

所以按满载计算，索引部分约需：

\[
\boxed{75473}
\]

个磁盘页块。

---

#### 情况二：按最坏半满情况计算

B 树中每个非根结点关键字数至少为：

\[
\left\lceil \frac{267}{2} \right\rceil - 1 = 133
\]

每个结点至少有 \(134\) 个子指针。

叶子层结点数：

\[
\left\lceil \frac{20000000}{133} \right\rceil = 150376
\]

第 2 层：

\[
\left\lceil \frac{150376}{134} \right\rceil = 1123
\]

第 3 层：

\[
\left\lceil \frac{1123}{134} \right\rceil = 9
\]

第 4 层：

\[
\left\lceil \frac{9}{134} \right\rceil = 1
\]

总页块数：

\[
150376 + 1123 + 9 + 1 = 151509
\]

因此半满情况下约需：

\[
\boxed{151509}
\]

个磁盘页块。

> 通常教材默认按结点满载估算“占用多少页块”，答案为 \(75473\)；若题目强调最坏情况，则用半满估算 \(151509\)。本题未明确填充率，一般以满载为准。

---

**易错点**：  
1. **3 阶 B 树的容量混淆**：3 阶 B 树不是“最多 3 个关键字”，而是“最多 2 个关键字、最多 3 个子指针”。  
2. **插入分裂时中间关键字的选择**：分裂时应取“中间位置”的关键字上移，且上移后左右两半的关键字个数尽量均匀。  
3. **删除时先借后合并**：删除后若下溢，先看兄弟能否借位；只有兄弟也处于最少关键字数时才合并。借位时要注意“父结点关键字下移、兄弟关键字上移”的旋转方向。  
4. **合并后父结点可能继续下溢**：本题删除 80 后，父结点 `[90]` 变空，需要继续向上合并，这是容易遗漏的连锁调整。  
5. **第 3 题结点容量方程漏项**：必须同时计算“子指针 + 关键字 + 记录地址指针”，不能只算关键字和子指针。  
6. **向上取整**：计算每层结点数时，除不尽的必须向上取整，否则会导致索引缺失。  
7. **上层结点数除的是最大子树数 \(m\)，而不是最大关键字数 \(m-1\)**：例如第 2 层结点数应除以 \(267\)，而不是 \(266\)。  
8. **若题目默认满载，不要用半满计算**：交错使用两种填充率会得到错误结果；若题目没有明确，可以在答案中说明假设。

---

**命题规律**：  
1. **考点定位**：B 树是 408 数据结构的常考综合题，重点考查：  
   - B 树的定义与性质（阶数、关键字数范围、高度）；  
   - 插入时的分裂操作；  
   - 删除时的借位与合并操作；  
   - B 树在文件索引中的应用，包括阶数计算与页块数估算。  
2. **常见变式**：  
   - 给定不同阶数的 B 树，要求画出插入/删除全过程；  
   - 将第 3 题改为 B+ 树，计算索引层数与页块数；  
   - 求 B 树的最大高度和最小高度；  
   - 将“数据未有序”改为“数据有序”，可能改用稀疏索引或主索引。  
3. **复习建议**：  
   - 熟练掌握 \(m\) 阶 B 树结点关键字数范围：  
     - 根结点：\(1 \le n \le m-1\)（若根为叶子则 \(0 \le n \le m-1\)）；  
     - 非根结点：\(\lceil m/2 \rceil - 1 \le n \le m-1\)。  
   - 插入操作：先插入后分裂，分裂时中间关键字上移，必要时逐层上溢。  
   - 删除操作：先删除后调整，下溢时优先向兄弟借，借不到则与兄弟合并，必要时逐层下溢。  
   - 对存储容量计算题，列出“结点空间 = 子指针 + 索引项”的方程，注意每个索引项包含关键字和地址指针，不要漏项。  
   - 多练画图题，保证插入删除过程的每一步树形结构都清晰、合法。

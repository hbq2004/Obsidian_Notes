## DeepSeek V4 Flash Max 解析

**答案**：采用中序遍历，判断二叉树的中序序列是否严格递增；若某相邻两结点不满足“当前结点值 $>$ 中序前驱结点值”，则该树不是二叉排序树，否则是。

**解题切入点**：拿到“判断二叉排序树”这类题，先抓 BST 的核心性质——中序遍历结果有序。可以类比“检查数组是否递增”：只要把树中序遍历一遍，就相当于得到一个数组，再检查相邻元素是否严格递增即可。但为了节省空间，不真正开辟数组，而是在遍历过程中用一个指针记录前驱结点，遇到逆序立即返回 `false`。这样就把“树结构判断”转化为“遍历序列判断”。

**推演**：

设二叉树 $T$ 的中序序列为 $I(T)$。对根结点 $r$，有

$$
I(T)=I(T_{\text{left}})+[r]+I(T_{\text{right}})
$$

若 $T$ 是二叉排序树，则左子树所有结点值均小于 $r$，右子树所有结点值均大于 $r$，且左右子树也分别是 BST。由归纳法可知 $I(T_{\text{left}})$ 严格递增，$I(T_{\text{right}})$ 严格递增，并且左边所有值 $<r<$ 右边所有值，所以 $I(T)$ 严格递增。

反过来，若 $I(T)$ 严格递增，由于中序序列中根 $r$ 的位置恰好在左子树序列之后、右子树序列之前，因此左子树所有值均 $<r$，右子树所有值均 $>r$；左右子树的序列又是整体严格递增序列的连续子序列，所以也严格递增。由归纳法，$T$ 是二叉排序树。

因此，判断 BST 等价于判断中序序列是否严格递增。算法只需在中序遍历过程中检查相邻结点：

```c
typedef struct BiTNode {
    int data;
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;

// 中序检查，pre 指向中序序列中当前结点的前驱
bool InorderCheck(BiTNode *p, BiTNode **pre) {
    if (p == NULL)
        return true;

    // 检查左子树
    if (!InorderCheck(p->lchild, pre))
        return false;

    // 检查当前结点与前驱是否构成严格递增
    if (*pre != NULL && p->data <= (*pre)->data)
        return false;

    // 更新前驱为当前结点
    *pre = p;

    // 检查右子树
    return InorderCheck(p->rchild, pre);
}

bool IsBST(BiTree T) {
    BiTNode *pre = NULL;
    return InorderCheck(T, &pre);
}
```

算法说明：

- 空树和单结点树都视为二叉排序树。
- 标准 408 教材中 BST 不含重复关键字，所以当前结点值等于前驱值时应返回 `false`，即条件用 `<=`。
- 每次访问结点时，`pre` 恰好是该结点在中序序列中的前驱；比较后立即更新 `pre`。
- 如果整棵树中序遍历完成且从未出现逆序，则该树是 BST。

时间复杂度：每个结点恰好访问一次，为 $O(n)$，其中 $n$ 为结点个数。

空间复杂度：递归深度为树高 $h$，为 $O(h)$。最坏情况树退化为单链时 $O(n)$，平均/最好情况下 $O(\log n)$。

**易错点**：

- **只比较根与左右孩子**：二叉排序树要求左子树所有结点值小于根，右子树所有结点值大于根，而不是只满足父子关系。例如根为 $10$，左孩子为 $5$，但左孩子的右子树中存在 $12$，只比较根和左右孩子会误判为 BST。
- **等号处理错误**：若用 `p->data < (*pre)->data` 判断，则重复关键字不会报错，会误判为 BST。标准 BST 无重复关键字，必须用 `<=`。
- **前驱指针传递方式错误**：递归中需要修改 `pre` 的指向，必须使用 `BiTNode **pre` 或全局变量；如果传普通指针，`pre = p` 只在当前函数层生效，无法正确更新前驱。
- **忽略空树和单结点**：空树是 BST，单结点树也是 BST。递归出口 `if (p == NULL) return true;` 可以自动处理。
- **左子树已经非法时仍继续遍历**：一旦左子树返回 `false`，应直接返回 `false`，避免用错误的前驱继续比较。

**命题规律**：本题是二叉树遍历与 BST 性质结合的综合应用题，属于 408 高频考点。核心是“中序序列有序等价于 BST”。常见变式包括：判断二叉树是否是平衡二叉树、求 BST 第 $k$ 小结点、将 BST 转化为有序双向链表、判断一个序列是否为 BST 的后序序列、用非递归中序遍历实现 BST 判断等。复习时应熟练掌握递归遍历框架，尤其注意递归中外部变量的更新方式；算法设计题不仅要写代码，还要写出正确性说明和复杂度分析，这样才符合综合应用题的得分要求。

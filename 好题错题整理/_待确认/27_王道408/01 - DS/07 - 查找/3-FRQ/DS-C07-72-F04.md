## DeepSeek V4 Flash Max 解析

**答案**：折半查找的递归算法是在有序顺序表上每次取当前区间中点 $mid=\lfloor(low+high)/2\rfloor$，将目标关键字 $key$ 与 $ST.elem[mid].key$ 比较，若相等则返回 $mid$，若 $key$ 更小则递归查左半区间，否则递归查右半区间，并以 $low>high$ 作为查找失败的递归出口；初始调用为 `Search_Bin(ST, key, 1, ST.length)`。

**解题切入点**：题目要求“写出折半查找的递归算法”，首先定位到“有序表的查找——折半查找”这一考点。折半查找本质是分治：每比较一次，搜索区间减半。递归写法的关键不是循环更新 `low` 和 `high`，而是把它们作为递归参数传递下去，因此要抓住三件事：递归出口、区间中点、左右区间如何更新。可以类比猜数字游戏：每次猜中间数，被告知“大了”或“小了”后，只在对应的一半里继续猜；递归就是把“在更小区间继续猜”这个动作重复执行。

**推演**：

设顺序表 `ST` 的关键字存放在下标 $1 \sim ST.length$ 中，$0$ 号单元留空不参与查找，且关键字递增有序。要查找关键字为 $key$ 的元素。

递归函数需要携带四个信息：查找表 `ST`、目标关键字 `key`、当前区间下界 `low` 和上界 `high`。函数返回目标关键字所在下标，若不存在则返回 $0$。

递归关系如下：

- 若 $low > high$，则当前区间为空，说明表中不存在 $key$，返回 $0$；
- 取中点 $mid=\lfloor(low+high)/2\rfloor$；
- 若 $key = ST.elem[mid].key$，则查找成功，返回 $mid$；
- 若 $key < ST.elem[mid].key$，由于表递增有序，$key$ 只可能出现在左半区间 $[low, mid-1]$，递归调用 `Search_Bin(ST, key, low, mid-1)`；
- 若 $key > ST.elem[mid].key$，则 $key$ 只可能出现在右半区间 $[mid+1, high]$，递归调用 `Search_Bin(ST, key, mid+1, high)`。

伪代码如下：

```c
int Search_Bin(SSTable ST, KeyType key, int low, int high) {
    // 递归出口：区间为空，查找失败
    if (low > high)
        return 0;

    int mid = low + (high - low) / 2;   // 等价于 (low + high) / 2

    if (key == ST.elem[mid].key)
        return mid;                     // 查找成功
    else if (key < ST.elem[mid].key)
        return Search_Bin(ST, key, low, mid - 1);   // 只查左半区间
    else
        return Search_Bin(ST, key, mid + 1, high);  // 只查右半区间
}
```

初始调用为：

```c
Search_Bin(ST, key, 1, ST.length);
```

正确性说明：每次比较后，若没有命中中点，则根据表的有序性可以排除中点及另一半区间，剩余部分仍是有序的，并且区间长度严格减小，因此递归必然终止。若原区间中存在 $key$，则每次保留的区间必定仍包含它，所以最终要么在中点返回其下标，要么区间变为空返回 $0$。

时间复杂度：每次递归只做常数次比较，问题规模减半，因此

$$
T(n)=T\left(\left\lfloor \frac{n}{2}\right\rfloor\right)+O(1)=O(\log n).
$$

空间复杂度：递归深度为 $O(\log n)$，因此递归工作栈空间为 $O(\log n)$；非递归版本可做到 $O(1)$ 辅助空间。

**易错点**：

- 递归出口必须写成 $low>high$，不能写成 $low\ge high$。因为当 $low=high$ 时，区间中还有一个元素需要检查，若直接判定失败，会漏掉最后一个元素。
- 区间更新容易写错：向左递归时是 `high = mid - 1`，向右递归时是 `low = mid + 1`，不能写成 `low = mid` 或 `high = mid`，否则区间可能不缩小，造成无限递归。
- 递归调用必须 `return`，不能只调用不返回，否则上层函数无法获得递归结果，产生未定义行为。
- 注意下标风格：本题明确初始 `low=1, high=ST.length`，说明表是 $1$ 起始下标；若在 C 语言中改为 $0$ 起始下标，则初始调用应为 `low=0, high=ST.length-1`。
- 折半查找要求表必须有序；若表无序，不能直接用折半查找。
- 计算中点时可用 `low + (high - low) / 2` 避免 `low + high` 可能溢出的问题。

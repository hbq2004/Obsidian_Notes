## DeepSeek V4 Flash Max 解析

**答案**：在二叉排序树中，最小关键字是从根一直沿左孩子走到“左孩子为空”的结点的关键字；最大关键字是从根一直沿右孩子走到“右孩子为空”的结点的关键字。时间复杂度为 $O(h)$，空间复杂度为 $O(1)$。

**解题切入点**：二叉排序树的核心性质是“左子树所有关键字小于根结点，右子树所有关键字大于根结点”，因此它中序遍历得到递增序列。求最小/最大关键字，本质就是在“有序序列”中取第一个/最后一个元素；对应到树中，就是沿最左链/最右链走到头。不要对整棵树遍历或逐一比较，否则浪费了二叉排序树的有序性。

**推演**：

设二叉排序树结点结构为：

```c
typedef struct BSTNode {
    KeyType data;
    struct BSTNode *lchild, *rchild;
} BSTNode, *BSTree;
```

由二叉排序树性质：

$$
\min(T)=
\begin{cases}
\text{无定义}, & T=\text{NULL},\\
T.data, & T.lchild=\text{NULL},\\
\min(T.lchild), & T.lchild\neq \text{NULL}.
\end{cases}
$$

因为若当前结点有左孩子，则左子树中所有关键字都小于当前结点关键字，所以最小值不可能在当前结点或右子树中，只能递归地出现在左子树中。

同理：

$$
\max(T)=
\begin{cases}
\text{无定义}, & T=\text{NULL},\\
T.data, & T.rchild=\text{NULL},\\
\max(T.rchild), & T.rchild\neq \text{NULL}.
\end{cases}
$$

将递归改为循环，可写出代码：

```c
KeyType MinKey(BSTree T) {
    if (T == NULL) return ERROR;   // 约定错误值，或由调用方判空
    while (T->lchild != NULL)
        T = T->lchild;
    return T->data;
}

KeyType MaxKey(BSTree T) {
    if (T == NULL) return ERROR;
    while (T->rchild != NULL)
        T = T->rchild;
    return T->data;
}
```

若要求一次同时得到最小和最大关键字：

```c
void GetMinMax(BSTree T, KeyType &minKey, KeyType &maxKey) {
    if (T == NULL) return;
    BSTree p = T;
    while (p->lchild != NULL) p = p->lchild;
    minKey = p->data;

    p = T;
    while (p->rchild != NULL) p = p->rchild;
    maxKey = p->data;
}
```

**正确性说明**：求最小值时，只要当前结点有左孩子，最小值一定在左子树中，因此不断向左走；当左孩子为空时，当前结点就是当前子树中的最小关键字。由于每一步排除的祖先结点及其右子树都大于相应路径上的结点，所以最后到达的结点就是整棵二叉排序树的最小关键字。求最大值完全对称。

**复杂度**：设二叉排序树高度为 $h$，最左链和最右链长度均不超过 $h$，每次移动 $O(1)$，因此时间 $O(h)$；迭代算法不使用递归栈或辅助数组，空间 $O(1)$。若树退化为单支树，则最坏为 $O(n)$。

**易错点**：
- 误以为最小/最大结点一定是叶子结点。事实上，最左下结点可以存在右孩子，最右下结点也可以存在左孩子；判断条件应为“左/右孩子为空”，而不是“左右孩子都为空”。
- 对空树直接访问 `T->data` 会出错，必须先判断 `T == NULL`。
- 容易写错循环：应先判断 `T->lchild != NULL` 再移动，不能写成 `while (T != NULL) T = T->lchild;`，否则最后会访问空指针。
- 用中序遍历找第一个和最后一个关键字也能得到答案，但时间复杂度为 $O(n)$，不如直接沿最左/最右链走到头高效。
- 若关键字类型不是 `int`，不要用 `-1` 作为空树返回值，应使用 `bool found` 或由调用方保证树非空。

**命题规律**：本题对应 408 数据结构“查找—二叉排序树”部分，考查 BST 性质与基本操作。直接求最小/最大关键字属于基础题，常见变式有：求第 $k$ 小/第 $k$ 大关键字、删除二叉排序树中的最小/最大结点、判断一棵二叉树是否为 BST、在区间 $[a,b]$ 内输出关键字等。复习时应熟记“中序有序、最左最小、最右最大”这些 BST 基本结论，并掌握递归与迭代两种写法和复杂度分析。

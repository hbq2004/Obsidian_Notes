# 选择题 第 1 题

![[_Attachments/题目识别/27_王道408-题目/CO-C02-23-M01_题目.png|题目]]

1. 在 $C$ 语言的不同类型的数据混合运算中,要先转换成同一类型后进行运算。设一表达式中包含有 int、long、char 和 double 类型的变量与数据,则表达式最后的运算结果是 ( ),这 4 种类型数据的转换规律是 ( ).

A. $long, int \to char \to double \to long$
B. $long, char \to int \to long \to double$
C. $double, char \to int \to long \to double$
D. $double, char \to int \to double \to long$

## DeepSeek V4 Flash Max 解析

**答案**：C。理由：表达式中含 `double` 类型的量，按 C 语言自动类型转换规则，最终结果一定是 `double`；这 4 种类型的转换规律是 $\text{char} \to \text{int} \to \text{long} \to \text{double}$。

**解题切入点**  
先看题目结构：这是“最终结果类型 + 转换顺序”双空题。先判断最终类型，再看转换顺序。可以类比为开会有多种语言，最后统一说“级别最高”的语言；在 `char`、`int`、`long`、`double` 中，`double` 级别最高，所以最终结果是 `double`。转换顺序则按类型从低到高排列。

**推演**  
C 语言中不同数据类型的混合运算，要先进行隐式类型转换，基本原则是：小范围/低精度类型向大范围/高精度类型转换，尽量减少信息丢失。

对于题目给出的 4 种类型，按常见 C 语言教材的转换等级，从低到高为：

$$
\text{char} \to \text{int} \to \text{long} \to \text{double}
$$

具体过程：

1. `char` 参与算术运算时，先进行整型提升，转换为 `int`。
2. `int` 与 `long` 混合运算时，`int` 转换为 `long`。
3. 只要表达式中出现 `double`，最终结果就是 `double`，所有其他类型最终都要转换为 `double`。

因此，题目表达式中包含 `int`、`long`、`char`、`double` 四种类型时，最终结果是 `double`，转换规律是：

$$
\text{char} \to \text{int} \to \text{long} \to \text{double}
$$

对应选项：  
A 最终结果应为 `double`，不是 `long`，错；  
B 转换顺序正确，但最终结果错；  
C 两项均正确；  
D 最终结果正确，但转换顺序 `char \to int \to double \to long` 错，因为自动转换不会从 `double` 再降回 `long`。

例如：

```c
char c = 'A';
int i = 10;
long l = 20L;
double d = 3.14;

double r = c + i + l + d;
```

按左结合计算：$c+i$ 得到 `int`；再与 `long` 相加得到 `long`；最后与 `double` 相加得到 `double`，正好体现：

$$
\text{char} \to \text{int} \to \text{long} \to \text{double}
$$

**易错点**  
- 容易误选 B：B 的转换顺序正确，但第一空最终结果应是 `double`，不是 `long`。  
- 容易误以为 `int` 和 `long` 在 32 位机器上都占 4 字节，就不需要转换；实际上它们仍然是不同类型，`int + long` 的结果是 `long`。  
- 容易误选 D：D 最终结果是 `double` 正确，但 `int \to double \to long` 不是自动转换顺序；自动转换不会从高精度降到低精度，除非使用强制类型转换。  
- 容易忽略 `char` 的整型提升：`char` 要先变为 `int`，而不是直接与 `long` 或 `double` 运算。

**命题规律**  
本题考的是 C 语言混合运算中的隐式类型转换，属于数据表示与运算部分的常考知识点。常见变式包括：判断表达式最终类型、`printf` 输出格式、有符号/无符号混合运算、强制类型转换等。复习时重点记住：低精度向高精度转换；有浮点类型时最终结果至少是浮点类型；整型运算中 `char/short` 先提升为 `int`。同时注意区分自动转换和强制转换。

# 选择题 第 2 题

![[_Attachments/题目识别/27_王道408-题目/CO-C02-22-M02_题目.png|题目]]

2. 算术逻辑单元($ALU$)的功能通常包括(   ).

(A) 算术运算
(B) 逻辑运算
(C) 算术运算和逻辑运算
(D) 加法运算

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C02-22-M02_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。ALU 的核心功能是同时支持算术运算和逻辑运算；若只说算术运算、逻辑运算或仅加法运算，均不完整。

**解题切入点**：这是概念题，考查 ALU 的功能定义。做题时先回想 ALU 在 CPU 数据通路中的位置：它接收来自寄存器的操作数，由控制信号决定执行哪种运算，输出结果和标志位。ALU 的“算术运算”包括加、减、乘、除等，“逻辑运算”包括与、或、非、异或等。因此选项 A、B 都只覆盖一半，D 只是算术运算中的一个子集，选 C。

**推演**：

1. ALU（Arithmetic Logic Unit）是 CPU 中专门执行算术运算和逻辑运算的组合逻辑电路。其基本功能可由下式概括：
   $$
   F = f(A, B, \text{op})
   $$
   其中 $A$、$B$ 是两个输入操作数，$\text{op}$ 是控制信号（操作码），$F$ 是运算结果。

2. 算术运算至少包括：
   - 加法（ADD）
   - 减法（SUB）
   - 乘法（MUL）（在简单 ALU 中可能仅支持加减，但功能上应归类为算术运算）
   - 除法（DIV）
   - 加 1、减 1、取补等

   逻辑运算包括：
   - 与（AND）
   - 或（OR）
   - 非（NOT）
   - 异或（XOR）
   - 移位（某些 ALU 将移位归入逻辑运算或单独列出）

3. 选项分析：
   - A：“算术运算”只强调了算术部分，缺少逻辑运算，故不完整。
   - B：“逻辑运算”只强调了逻辑部分，缺少算术运算，故不完整。
   - D：“加法运算”只是算术运算中的一种，更不全面。
   - C：“算术运算和逻辑运算”准确涵盖了 ALU 的全部基本功能，故正确。

4. 补充：ALU 的典型标志输出包括零标志 $ZF$、符号标志 $SF$、进位/借位标志 $CF$、溢出标志 $OF$，这些标志为后续条件转移指令提供依据。

**易错点**：
- 误选 A：只记住 ALU 能做加减法，忽略逻辑运算也是 ALU 的基本功能。
- 误选 B：只想到与或非，忽略算术运算。
- 误选 D：把 ALU 等同于加法器，实际上加法器只是 ALU 的核心组成部分，ALU 还包括逻辑运算部件。
- 区分“ALU”和“加法器”：加法器只完成加法（以及减法可转为补码加法），而 ALU 是多功能运算部件。答题时要抓住“算术 + 逻辑”这一完整定义。

**命题规律**：这是计算机组成原理中的基础概念题，常出现在选择题前几题，考查对 ALU 功能定义的准确记忆。变式可能包括：
- 问“ALU 不能完成下列哪项运算？”（干扰项常为浮点运算或某些复杂指令，如乘除有时由独立部件完成）。
- 与 CPU 数据通路结合：给出 ALU 输入、控制信号和输出，判断某项操作是否由 ALU 完成。
- 与标志位结合：问某条指令执行后哪些标志位会变化。

复习建议：熟记 ALU 的定义和基本功能，注意与运算器、加法器的区别；理解 ALU 在指令执行周期中的角色，尤其是它如何根据操作码选择运算。平时复习时可将 ALU 的功能列表与指令系统中的典型指令对应起来，加深记忆。

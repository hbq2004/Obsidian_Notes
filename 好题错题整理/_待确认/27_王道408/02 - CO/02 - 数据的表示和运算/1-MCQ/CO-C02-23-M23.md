# 选择题 第 23 题

![[_Attachments/题目识别/27_王道408-题目/CO-C02-23-M23_题目.png|题目]]

23. 在按字节编址的 32 位计算机中，按边界对齐方式为以下结构型变量 $x$ 分配存储空间：
```c
struct cont_info{
    char id;
    unsigned post;
    char phone;
}x;
```
若 $x$ 的首地址为 `0x8049820`，则成员变量 $phone$ 的起始地址为( )
(A) `0x8049828`
(B) `0x8049826`
(C) `0x8049825`
(D) `0x8049822`

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C02-23-M23_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A。成员变量 `phone` 的起始地址为 `0x8049828`。

**解题切入点**：结构体成员对齐规则要求每个成员的首地址相对于结构体首地址的偏移量必须是该成员对其参数（常为其自身大小）的整数倍。先确定各成员类型大小与对齐要求，再计算偏移量，最后加上首地址。

**推演**：在32位计算机中，`char` 占1字节，`unsigned` 占4字节。按边界对齐，成员 `id` 偏移0，占1字节；为使 `post` 对齐到4的倍数，需在 `id` 后填充3字节，故 `post` 偏移4，占4字节；`phone` 为 `char`，对齐1，紧接 `post` 后偏移8，占1字节。结构体总大小需为最大对齐成员（4）的整数倍，故填充到12字节。已知 `x` 首地址为 `0x8049820`，则 `phone` 起始地址 = `0x8049820` + 8 = `0x8049828`。

**易错点**：误认为结构体成员紧密排列（无对齐填充），从而得到 `phone` 地址为 `0x8049821`（`id` 占1，`post` 占4，无填充则 `post` 偏移1，`phone` 偏移5）或 `0x8049825`（若认为 `post` 对齐到4但忽略 `id` 填充，错误地认为 `post` 从 `0x8049820` 开始，则 `phone` 从 `0x8049824` 开始）。此外，注意 `unsigned` 在32位机中占4字节，且地址加法需16进制正确计算。

**命题规律**：结构体对齐是408常考知识点，重点考查成员偏移计算、结构体大小及对齐规则。常与数组、指针结合，或考查结构体嵌套。复习时需掌握不同数据类型在32位/64位下的对齐要求，以及对齐和填充的规则。

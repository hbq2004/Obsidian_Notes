# 选择题 第 27 题

![[_Attachments/题目识别/27_王道408-题目/CO-C02-23-M27_题目.png|题目]]

27.【2010统考真题】假定变量 $\text{i}$、$f$ 和 $d$ 的数据类型分别为 $\text{int}$、$\textit{float}$ 和 $\textit{double}$（$\text{int}$ 用补码表示，$\textit{float}$ 和 $\textit{double}$ 分别用 $\textit{IEEE}$754 单精度和双精度浮点数格式表示），已知 $\text{i} = 785$、$f = 1.5678\text{E}3$、$d = 1.5\text{E}100$，若在 32 位机器中执行下列关系表达式，则结果为“真”的是（  ）
$I.\ \text{i} == (\text{int})(\textit{float})\text{i} \quad II.\ f == (\textit{float})(\text{int})f \quad III.\ f == (\textit{float})(\textit{double})f \quad IV.\ (d + f) - d == f$
A. 仅 $I$ 和 $II$
B. 仅 $I$ 和 $III$
C. 仅 $II$ 和 $III$
D. 仅 $III$ 和 $IV$

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C02-23-M27_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B（仅 I 和 III）。  
理由：`int` 转 `float` 再转回 `int`，对 785 无损；`float` 转 `double` 再转回 `float` 也无损；而 `float` 转 `int` 会截断小数，且大数加小数会发生“大数吃小数”。

**解题切入点**：  
拿到题目先看每一步类型转换是否可能改变数值，而不是先按实数运算硬算。可以把这题类比为“二进制精度预算”：  
- `int`→`float` 要看整数量级是否超过 24 位有效位数；  
- `float`→`int` 在 C 中是向零截断；  
- `float`→`double` 是扩展精度，不会损失；  
- 浮点加减法不是代数恒等运算，极小量遇到极大量会被舍入吞掉。

**推演**：

### I. $\text{i} == (\text{int})(\textit{float})\text{i}$

$\text{i}=785$。

`float` 是 IEEE 754 单精度，有 24 位有效位数，因此所有绝对值不超过 $2^{24}$ 的整数都能被精确表示。  
$$785 < 2^{24}=16777216$$

所以 $(\textit{float})\text{i}$ 精确等于 785，再 $(\text{int})$ 转回整数仍为 785。  
因此 I 为真。

---

### II. $\text{f} == (\textit{float})(\text{int})\text{f}$

$$\text{f}=1.5678\text{E}3=1567.8$$

C 语言中 `float` 转 `int` 是向零截断，因此  
$$(\text{int})\text{f}=1567$$

再转回 `float`：
$$(\textit{float})(\text{int})\text{f}=1567.0$$

但原 $\text{f}$ 约为 1567.8，二者不相等。  
因此 II 为假。

---

### III. $\text{f} == (\textit{float})(\textit{double})\text{f}$

`double` 是 IEEE 754 双精度，有 53 位有效位数；`float` 只有 24 位有效位数。  
任意有限 `float` 值都能被 `double` 精确表示，所以：

$$(\textit{double})\text{f}$$

不会改变 $\text{f}$ 的数值；再转回 `float` 时，由于该值本来就是精确的 `float` 值，所以也不会改变。

因此 III 为真。

---

### IV. $(\text{d} + \text{f}) - \text{d} == \text{f}$

这是典型的“大数吃小数”问题。

$$\text{d}=1.5\text{E}100$$

其数量级约为：
$$\log_2 \text{d} \approx 332.78$$

所以存储的 `double` 值指数约为 332，相邻可表示数的间隔约为：

$$2^{332-52}=2^{280}\approx 1.94\times 10^{84}$$

而

$$\text{f}\approx 1.5678\times 10^3$$

远远小于半个间隔：
$$\text{f}\ll \frac{1}{2}\times 2^{280}$$

因此在计算 $\text{d}+\text{f}$ 时，$\text{f}$ 被舍入掉，结果仍等于 $\text{d}$：

$$\text{d}+\text{f}=\text{d}$$

于是：

$$(\text{d}+\text{f})-\text{d}=0 \neq \text{f}$$

因此 IV 为假。

综上，真命题为 I 和 III，选 **B**。

**易错点**：  
1. 把 `float` 转 `int` 当成四舍五入。C 语言中强制转换是向零截断，$1567.8$ 转成 $1567$，而不是 $1568$。  
2. 认为 `float` 转 `double` 再转回 `float` 可能不精确。实际上双精度有效位数更多，单精度值一定可以被双精度精确表示，所以往返无损。  
3. 直接用实数运算法则看待浮点运算，认为 $(\text{d}+\text{f})-\text{d}=\text{f}$。浮点运算有舍入，大数加小数会丢失小数部分。  
4. 忽略 `float` 不能精确表示所有整数。本题中 $785$ 很小所以无损；若整数超过 $2^{24}$，`int` 转 `float` 就可能发生舍入。

**命题规律**：  
这是 408 中典型的“数据表示与类型转换”考题，考查 IEEE 754 单/双精度格式、有效位数、强制类型转换方向、浮点运算精度损失。常见变式包括：判断某个较大的 `int` 转 `float` 后是否精确、负数向零截断、大数吃小数、比较不同精度混合运算结果等。复习时应重点掌握：  
- `float` 有效位数 24 位，`double` 有效位数 53 位；  
- 转 `int` 是向零取整；  
- 浮点运算不满足结合律和分配律；  
- 精度扩展一般无损，精度收缩可能舍入。

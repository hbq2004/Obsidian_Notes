# 选择题 第 29 题

![[_Attachments/题目识别/27_王道408-题目/CO-C02-21-M29_题目.png|题目]]

29.【2016统考真题】有如下 C 语言程序段:
```c
short si = - 32767;
unsigned short usi = si;
```
执行上述两条语句后, $usi$ 的值为( )
A. $-32767$
B. $32767$
C. $32768$
D. $32769$

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C02-21-M29_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。`short` 为 16 位有符号数，`-32767` 转换为 `unsigned short` 时要模 $2^{16}$，所以结果为 $-32767+65536=32769$。

**解题切入点**：看到 `short` 转 `unsigned short`，立即定位考点：有符号数到无符号数的转换、补码与无符号数的对应关系。关键不是取绝对值，而是按“模 $2^N$”转换；相当于把负值放到以 $2^N$ 为周期的无符号数轴上。

**推演**：

设常见 408 环境下，`short` 和 `unsigned short` 均为 16 位，即：

$$N=16,\qquad 2^{16}=65536$$

C 语言规定，有符号整数转换为无符号整数时，若原值不在无符号类型范围内，则不断加减“无符号类型最大值 $+1$”，直到落入范围。

`unsigned short` 的最大值为 $65535$，所以模为：

$$65535+1=65536$$

因此：

$$
usi = si \bmod 65536
$$

题目中：

$$si=-32767$$

所以：

$$
usi = -32767 + 65536 = 32769
$$

等价地，从补码位模式看：

16 位补码中：

$$-32767 = 2^{16}-32767 = 32769 = \mathrm{0x8001}$$

把 $\mathrm{0x8001}$ 按 `unsigned short` 解释，其值就是：

$$32769$$

因此正确答案是 D。

**易错点**：

- 误选 B：把 $-32767$ 直接取绝对值得到 $32767$。但 C 语言有符号转无符号不是取绝对值，而是按模 $2^N$ 转换。
- 误选 C：把 $-32767$ 误当成 $-32768$。注意 $-32768$ 的 16 位补码是 $\mathrm{0x8000}$，对应无符号数 $32768$；而 $-32767$ 比它大 $1$，补码是 $\mathrm{0x8001}$，对应无符号数 $32769$。
- 忽略无符号数范围：`unsigned short` 不能表示负数，也不能表示 $65536$ 及以上的数，所以必须取模。

**命题规律**：该题考查 C 语言中有符号整数与无符号整数之间的转换，以及补码与无符号数的对应关系。常见变式包括：

- `short si=-32768; unsigned short usi=si;` 则结果为 $32768$；
- `int x=-1; unsigned int y=x;` 若 `int` 为 32 位，则结果为 $2^{32}-1=4294967295$；
- 可改为 `char`、`int`、`long long` 等不同位宽，考查模 $2^N$ 转换。

复习时应重点掌握：把有符号数转成无符号数，等于对 $2^N$ 取模；补码位模式直接按无符号数解释，两者结论一致。

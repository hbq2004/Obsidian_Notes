# 选择题 第 25 题

![[_Attachments/题目识别/27_王道408-题目/CO-C02-23-M25_题目.png|题目]]

25. 有以下C语言代码段：
```c
int m = 13;
float a = 12.6, x;
x = m/2 + a/2;
printf("%f\n", x);
```
执行上述代码后，输出的 $x$ 值为（  ）
(A) 12.000000
(B) 12.300000
(C) 12.800000
(D) 12

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C02-23-M25_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B（12.300000）。理由：`m/2` 是整数除法得 6，`a/2` 是浮点数除法得 6.3，二者相加为 12.3，按 `%f` 输出为 `12.300000`。

**解题切入点**：拿到本题先盯着运算分量的类型：`m` 是 `int`，`a` 是 `float`。C 语言中不同类型运算时存在隐式类型转换，而 `int/int` 仍是整数除法，会直接截断小数部分。这种“整数除法 vs 浮点除法”的区分是高频考点，可以类比“两个整数相除像下取整，两个浮点数相除才保留小数”。

**推演**：
1. 已知变量：
   - `int m = 13;`
   - `float a = 12.6;`
   - `float x;`

2. 表达式原型：
   $$x = m/2 + a/2;$$

3. 先看 `m/2`：`m` 是 `int`，字面量 `2` 默认为 `int`，因此执行整数除法：
   $$13 / 2 = 6$$
   小数部分 `.5` 被截断，结果仍为 `int` 型 6。

4. 再看 `a/2`：`a` 是 `float`，字面量 `2` 会被自动转换成 `float` 后参与运算，因此执行浮点除法：
   $$12.6 / 2 = 6.3$$

5. 将两部分相加：
   $$6 + 6.3 = 12.3$$
   由于 `6` 是 `int`，`6.3` 是 `float`，运算时 `6` 被转换为 `float`，最终结果是 `float` 型 12.3，赋给 `float x`。

6. `printf("%f\n", x);` 按浮点数格式输出，默认保留 6 位小数，故输出：
   $$12.300000$$

**易错点**：
- 误以为 `m/2` 等于 6.5，从而得到 `12.8`，错选 C。关键要记住 `int` 与 `int` 相除结果仍为 `int`，小数部分直接丢弃。
- 误把 `a/2` 中的 `2` 当作整数，以为结果被截断为 6，再与 6 相加得 12（错选 D）。实际上 `float` 与 `int` 运算时，`int` 会先转为 `float`。
- 选项 D 写成 `12` 也不是 `%f` 的标准输出形式，即使数值为 12，也应按 `12.000000` 输出，但本题数值显然不是 12。
- 忽略字面量 `2` 的默认类型。C 语言中整型字面量默认是 `int`，浮点字面量默认是 `double`，但在与 `float` 运算时可能进行相应转换。本题 `a/2` 中 `2` 会被转成 `float`（或先提升为 `double` 再转换，最终结果赋值给 `float` 时精度不变，数值仍为 6.3）。

**命题规律**：考点是“C 语言表达式中的类型转换与整数除法截断”，属于计算机组成原理中数据表示与运算部分与 C 语言结合的经典题型。常见变式包括：
- 将 `m/2` 改为 `(float)m/2` 或 `m/2.0`，结果变成 6.5，此时输出可能为 `12.8`。
- 将 `a` 改为 `double`，`printf` 用 `%f` 仍可输出，重点仍在于整数除法与浮点数除法的区别。
- 考查 `%d` 与 `%f` 输出格式的匹配，或混合运算中的隐式转换规则。

复习建议：熟练掌握 C 语言算术运算中的类型转换规则，特别是：
- `int/int` 结果截断；
- `int/float` 或 `float/int` 结果为浮点数；
- 赋值时高精度向低精度转换会丢失精度，低精度向高精度转换不会改变数值。

# 选择题 第 24 题

![[_Attachments/题目识别/27_王道408-题目/CO-C02-23-M24_题目.png|题目]]

24. 假定变量 $i$、$f$ 的数据类型分别是 `int`、`float`。已知 $i = 12345, f = 1.2345 \times 2^3$，则在一个 32 位机器中执行下列表达式时，结果为“假”的是 (  )
(A) $i == (int)(double)i$
(B) $f == (float)(double)f$
(C) $i == (int)(float)i$
(D) $f == (float)(int)f$

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C02-23-M24_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。按题面 $f=1.2345\times2^3=9.876$，`(int)f` 截断小数得 9，再转回 `float` 得 9.0，与 $f$ 不相等；A、B、C 三条转换链均无损。

**解题切入点**：  
先看强制类型转换的方向，判断哪些转换可能丢信息。关键规则是：  
- `int→double` 无损；  
- `float→double` 无损；  
- `int→float` 对小整数 $12345$ 这种不超过 $2^{24}$ 的数无损；  
- `float→int` 会截断小数部分，有损。  

所以应优先怀疑 D。

**推演**：  
32 位机中通常 `float` 采用 IEEE 754 单精度格式，有 24 位有效位；`double` 采用双精度格式，有 53 位有效位。

- A：$i == (int)(double)i$  
  `int→double→int`。`double` 能精确表示 32 位 `int`，所以  
  $$(double)i=12345.0,\quad (int)(double)i=12345=i$$  
  为真。

- B：$f == (float)(double)f$  
  `float→double→float`。任意有限 `float` 值都能被 `double` 精确表示，再转回 `float` 仍得到原值，因此为真。

- C：$i == (int)(float)i$  
  因为  
  $$12345<2^{24}=16777216$$  
  且  
  $$12345=(11000000111001)_2$$  
  只有 14 个有效位，`float` 的 24 位有效位可以精确表示 $12345.0$，所以转回 `int` 仍为 12345，为真。

- D：$f == (float)(int)f$  
  由题面  
  $$f=1.2345\times2^3=9.876$$  
  在 C 语言中，浮点转整型是向零截断，不是四舍五入：  
  $$(int)f=9,\quad (float)(int)f=9.0$$  
  而 $f\ne9.0$，故为假。

**易错点**：  
- 误以为 `int→float` 一定丢精度，因此选 C。实际上 $12345$ 只有 14 个有效位，`float` 完全能精确表示。  
- 误以为 `float→int` 会四舍五入。实际是截断，$9.876\to9$；若原题是常见的 $1.2345\times10^3=1234.5$，则截断为 1234，但 D 仍然为假。  
- 忽略 `float→double` 的无损性，`double` 是 `float` 的超集，B 必为真。  
- 注意 `float` 的有效位是 24 位，不是 23 位；隐含位也算一位。

**命题规律**：  
考点是 IEEE 754 浮点数精度与 C 语言强制类型转换规则。常见变式有：把 $i$ 改成 $2^{24}+1$，使 `int→float` 发生舍入，从而 C 为假；把 $f$ 改成负数，考截断方向；或加入 `double→float` 的舍入。复习时记住“`int→double`、`float→double` 无损；`int→float` 看是否超过 24 位有效位；`float→int` 截断”即可快速判断。

# 选择题 第 22 题

![[_Attachments/题目识别/27_王道408-题目/CO-C02-22-M22_题目.png|题目]]

22. 某 C 语言代码段如下:

```c
int si = 65536;
short i = si;
unsigned j = 0;
if(i ≤ j-1) printf("王道");
else printf("做题本集结地");
```

当上述代码段执行到 if 分支条件的判断时, 会根据标志寄存器中的 ( ) 决定执行顺序。最终的输出结果是 ( )

A. $CF$,王道
B. $CF$,做题本集结地
C. $OF$,王道
D. $OF$,做题本集结地

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C02-22-M22_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A，$CF$，王道。  
一句话理由：`short i = 65536` 截断为 $0$，`j-1$ 是无符号数 $2^{32}-1=0\text{xFFFFFFFF}$，因此实际是无符号比较 `0u <= 0xFFFFFFFFu`，由标志寄存器中的 $CF$ 决定分支，条件为真，输出“王道”。

**解题切入点**：看到 `short`、`int`、`unsigned` 混合运算，先想两件事：一是数值截断/补码表示，二是 C 语言的整数提升和“无符号化”规则。`j-1` 中的 `j` 是 `unsigned`，所以不能把 `j-1` 当成数学上的 $-1$，而要当成无符号数回绕。判断分支用哪个标志，关键是看比较的是有符号数还是无符号数：无符号比较看 $CF$，有符号比较看 $OF/SF/ZF$。

**推演**：

按 408 常用模型：`int`/`unsigned` 为 32 位，`short` 为 16 位，补码表示。

1. `int si = 65536;`

$$
65536=2^{16}=0\text{x00010000}
$$

2. `short i = si;`

`short` 只有低 16 位，赋值时发生截断：

$$
i = 0\text{x0000}=0
$$

3. `unsigned j = 0;`

`j-1` 是 `unsigned int` 运算，发生模 $2^{32}$ 回绕：

$$
0-1 \equiv 2^{32}-1 = 0\text{xFFFFFFFF} \pmod{2^{32}}
$$

4. 判断 `i <= j-1`：

`i` 是 `short`，`j-1` 是 `unsigned int`。按 C 语言整数转换规则，`short` 先提升为 `int`，但 `int` 与 `unsigned int` 同等级，且 `unsigned int` 能表示的数值范围不包含于 `int`，所以 `i` 被转换为 `unsigned int`。

因此实际比较的是：

$$
0u <= 0\text{xFFFFFFFF}u
$$

这是一个无符号数比较，显然为真。

5. 标志寄存器角度：

无符号比较时，若前面的数小于后面的数，`CMP`/`SUB` 会产生借位，即 $CF=1$。这里 $0 < 0\text{xFFFFFFFF}$，所以 $CF=1$。条件 “小于等于” 在无符号比较中可借助 $CF$ 与 $ZF$ 判断，本题两数不相等，所以 $ZF=0$，实际由 $CF=1$ 决定跳转到 `if` 分支。

最终输出：

$$
\text{王道}
$$

**易错点**：

1. 误以为 `short i = 65536` 会变成负数。实际上 `65536` 低 16 位全为 0，所以 `i = 0`。
2. 把 `j-1` 当作有符号的 $-1$，然后比较 `0 <= -1`，得到错误结果“做题本集结地”。这是错的，因为 `j` 是 `unsigned`，`j-1` 是无符号数 $0\text{xFFFFFFFF}$。
3. 混淆 $CF$ 与 $OF$：无符号数比较看 $CF$，有符号数比较才看 $OF/SF/ZF$。本题比较双方已转为无符号数，不选 $OF$。
4. 误认为“小于等于”只看 $CF$ 或只看 $ZF$。实际指令如 `JBE` 判断的是 $CF=1$ 或 $ZF=1$；本题不相等，因此是 $CF$ 起作用。

**命题规律**：本题是典型的“C 语言类型转换 + 数据表示 + 标志寄存器”综合题。命题人常把 `short` 换成 `char`，把 `j-1` 换成 `j+1` 或 `i-1`，问最终输出或条件转移依据哪个标志位。复习时要重点掌握：  
- C 语言整数提升与无符号转换规则；  
- 无符号数回绕运算；  
- $CF$、$ZF$、$SF$、$OF$ 在有符号/无符号比较中的不同作用；  
- 8086/x86 中 `JA/JB/JG/JL` 等条件转移指令对应的标志条件。

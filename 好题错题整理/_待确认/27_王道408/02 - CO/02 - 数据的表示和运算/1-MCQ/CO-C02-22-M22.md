# 选择题 第 22 题

![[_Attachments/题目识别/27_王道408-题目/CO-C02-22-M22_题目.png|题目]]

22. 某C语言代码段如下:
```c
int si = 65536;
short i = si;
unsigned j = 0;
if (i <= j-1)  printf("王道");
else printf("做题本集结地");
```
当上述代码段执行到$if$分支条件的判断时, 会根据标志寄存器中的 (   ) 决定执行顺序. 最终的输出结果是 (   )
(A) $CF$,王道
(B) $CF$,做题本集结地
(C) $OF$,王道
(D) $OF$,做题本集结地

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C02-22-M22_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A。`i` 截断为 0，`j-1` 是无符号数 $2^{32}-1$，无符号比较 $0 \le 2^{32}-1$ 为真，所以用 `CF` 决定分支，最终输出“王道”。

**解题切入点**：看到 `unsigned j` 和 `j-1`，第一反应是“无符号数回绕”：`j-1` 不是 $-1$，而是 `0xFFFFFFFF`。再看到选项是 `CF`/`OF`，立刻定位考点：有符号比较主要看 `OF/SF`，无符号比较看 `CF`。

**推演**：

1. `int si = 65536;`，即
   $$65536 = 1\;0000\;0000\;0000\;0000_2$$
   `short` 一般按 16 位补码存储，赋值时保留低 16 位：
   $$i = 0000\;0000\;0000\;0000_2 = 0$$

2. `unsigned j = 0;`，`unsigned` 是 `unsigned int`，按 32 位计算：
   $$j-1 = 0 - 1 \equiv 2^{32}-1 = \text{0xFFFFFFFF} \pmod{2^{32}}$$

3. 比较 `i <= j-1` 时，C 语言会进行整数提升和寻常算术转换。`i` 先提升为 `int`，再因为另一个操作数是 `unsigned int`，所以转换为 `unsigned int`：
   $$0u \le (2^{32}-1)u$$
   条件成立。

4. 机器指令层面，这是无符号比较，通常用 `jbe` 一类条件转移指令，判断的是 `CF`。执行比较时，$0 - (2^{32}-1)$ 需要借位，所以 $CF=1$，条件满足，执行 `printf("王道")`。

**易错点**：

- 把 `j-1` 当成 `-1`，然后得到 $0 \le -1$ 为假，误选“做题本集结地”。这是没有注意 `unsigned` 回绕。
- 把 `short i = 65536` 当成的值仍是 65536，实际上补码截断后 $i=0$。
- 误以为无符号比较也看 `OF`，其实 `OF` 用于有符号溢出判断；无符号比较主要看 `CF`。

**命题规律**：408 常把“C 语言无符号数回绕”和“标志寄存器条件转移”结合考查。常见变式是改为 `if (i > j - 1)`，或把 `j` 改为有符号数，从而把判断标志从 `CF` 改为 `OF/SF`。复习时要重点掌握整数提升、寻常算术转换，以及无符号比较看 `CF`、有符号比较看 `OF/SF` 的区别。

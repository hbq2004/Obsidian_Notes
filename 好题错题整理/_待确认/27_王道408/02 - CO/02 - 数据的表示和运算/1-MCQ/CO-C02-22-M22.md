# 选择题 第 22 题

22. 某 C 语言代码段如下:

```c
int si = 65536;
short i = si;
unsigned j = 0;
if(i ≤ j-1) printf("王道");
else printf("做题本集结地");
```

当上述代码段执行到 if 分支条件的判断时, 会根据标志寄存器中的 ( ) 决定执行顺序。最终的输出结果是 ( )

A. $CF$,王道
B. $CF$,做题本集结地
C. $OF$,王道
D. $OF$,做题本集结地

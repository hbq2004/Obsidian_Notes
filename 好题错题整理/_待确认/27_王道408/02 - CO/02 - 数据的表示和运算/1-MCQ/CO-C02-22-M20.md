# 选择题 第 20 题

![[_Attachments/题目识别/27_王道408-题目/CO-C02-22-M20_题目.png|题目]]

20. 某 8 位计算机中，$x$ 和 $y$ 是两个有符号整数，用补码表示，$[x]_{\text{补}} = 44H$，$[y]_{\text{补}} = DCH$，则 $x/2 + 2y$ 的机器数及相应的溢出标志 $OF$ 分别是 ( )
(A) $CAH、0$
(B) $CAH、1$
(C) $DAH、0$
(D) $DAH、1$

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C02-22-M20_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C（DAH、0），因为计算得 $x/2+2y$ 的补码为 $1101\ 1010$（即 DAH），且加法无溢出。

**解题切入点**：先由补码求得 $x$、$y$ 的真值，再计算算术表达式并转换为补码，或直接对补码进行移位与加法，最后根据有符号加法溢出规则判断 OF。

**推演**：
1. 由 $[x]_{\text{补}} = 44\text{H} = 0100\ 0100_2$，最高位为 $0$，故 $x$ 为正数，真值 $x = 68$。
   由 $[y]_{\text{补}} = \text{DCH} = 1101\ 1100_2$，最高位为 $1$，取反加 $1$ 得原码 $0010\ 0100_2$，故 $y = -36$。
2. 计算 $x/2 = 68/2 = 34$，补码为 $0010\ 0010_2 = 22\text{H}$。
   计算 $2y = 2 \times (-36) = -72$，补码为 $1011\ 1000_2 = \text{B8H}$。
3. 补码加法：$0010\ 0010_2 + 1011\ 1000_2 = 1101\ 1010_2 = \text{DAH}$，即 $x/2 + 2y = -38$。
4. 溢出标志 $OF$：两加数符号不同（$0$ 与 $1$），异号相加不会溢出；或由进位判断，最高位进位 $C_7=0$，次高位进位 $C_6=0$，$OF = C_7 \oplus C_6 = 0$。
   故机器数为 $\text{DAH}$，$OF=0$，对应选项 C。

**易错点**：
- 误将 $x/2$ 当作逻辑右移，导致正数右移补 $0$ 结果正确，但负数右移需补符号位。
- 左移 $2y$ 时忽略符号位变化，可能错误认为溢出；但本题 $y=-36$ 左移一位得 $-72$ 未溢出，结果正确。
- 溢出判断仅依赖最高位进位与次高位进位的异或，或同号相加异号结果，不可仅凭进位标志 $CF$。

**命题规律**：考查补码的算术移位（除 $2$ 与乘 $2$）及有符号加法溢出判断，常与十六进制、二进制转换结合。变式可涉及负数移位、溢出检测或多个运算组合。复习时需熟练掌握补码运算规则及溢出判别方法（双进位法或符号法）。

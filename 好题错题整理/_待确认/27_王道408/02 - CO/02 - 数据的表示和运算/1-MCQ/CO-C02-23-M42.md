# 选择题 第 42 题

![[_Attachments/题目识别/27_王道408-题目/CO-C02-23-M42_题目.png|题目]]

42.【2023 统考真题】已知 $float$ 型变量用 $IEEE754$ 单精度浮点数格式表示. 若 $float$ 型变量 $x$ 的机器数为 $8020\ 0000H$，则 $x$ 的值是 ( )
(A) $-2^{-128}$
(B) $-1.01\times2^{-127}$
(C) $-1.01\times2^{-126}$
(D) 非数 $(NaN)$

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C02-23-M42_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A。  
理由：机器数 $8020\,0000\text{H}$ 中符号位为 1、阶码全 0、尾数非 0，是 IEEE 754 单精度非规格化数，其值为  
$$-2^{-126}\times(0.01)_2=-2^{-128}.$$

**解题切入点**：  
拿到机器数先立刻把它展开成二进制，再按 IEEE 754 单精度的三段划分：符号位、8 位阶码、23 位尾数。本题的关键是看到阶码为 $0000\,0000$ 且尾数不为 0，要马上意识到这是非规格化数，不能直接用规格化数的公式 $(-1)^s\times 1.f\times2^{e-127}$。这就像打比赛时先判断数据范围，看到边界情况要选对应分支，不能套常规公式。

**推演**：  
1. 将十六进制转换为二进制：
$$8020\,0000\text{H}=1000\,0000\,0010\,0000\,0000\,0000\,0000\,0000_2.$$

2. 按单精度格式分段：
- 符号位 $s=1$；
- 阶码 $e=0000\,0000_2=0$；
- 尾数域 $f=010\,0000\,0000\,0000\,0000\,0000_2$，即
  $$f=0\times2^{-1}+1\times2^{-2}=0.25=2^{-2}.$$

3. 因为 $e=0$ 且 $f\ne0$，这是非规格化数，其真值公式为：
$$x=(-1)^s\times 2^{-126}\times(0.f)_2.$$

代入 $s=1$，$(0.f)_2=0.01_2=2^{-2}$，得：
$$x=-2^{-126}\times2^{-2}=-2^{-128}.$$

因此选 A。

**易错点**：  
- 错误地把它当规格化数，套用 $(-1)^s\times1.f\times2^{e-127}$。若代入 $e=0$ 会得到 $-1.01\times2^{-127}$，即错选 B。  
  实际上阶码全 0 时没有隐含的整数位 1，且真实指数固定为 $-126$，而非 $-127$。
- 误以为阶码全 0 且尾数非 0 是 $0$ 或 $NaN$。实际上 $e=0,f=0$ 才是 $\pm0$；$e=255,f\neq0$ 才是 $NaN$；$e=255,f=0$ 才是无穷大。
- 尾数部分读错：$f=010\ldots_2$ 表示二进制小数 $0.01_2$，即 $2^{-2}$，不是 $2^{-1}$。

**命题规律**：  
本题属于 IEEE 754 浮点数表示中的“非规格化数”考点。408 真题常给出一个机器数，要求判断其真值或类型（规格化数、非规格化数、无穷大、$NaN$）。复习时应重点掌握：  
- 单精度/双精度格式中符号、阶码、尾数的位数；  
- 规格化数与非规格化数的公式区别；  
- 特殊值（$0$、无穷大、$NaN$）的阶码和尾数条件；  
- 十六进制与二进制快速转换。  
建议把各类典型机器数（如 $0000\,0000\text{H}$、$7F80\,0000\text{H}$、$FFC0\,0000\text{H}$ 等）分类整理，练习套用公式。

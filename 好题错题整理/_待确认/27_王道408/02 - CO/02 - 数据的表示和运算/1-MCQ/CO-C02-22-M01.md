# 选择题 第 1 题

![[_Attachments/题目识别/27_王道408-题目/CO-C02-22-M01_题目.png|题目]]

1.算术逻辑单元($ALU$)的核心部件是( )

A. 多路选择器
B. 移位器
C. 加法器
D. 寄存器

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C02-22-M01_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。ALU 的核心部件是加法器，因为算术运算（加减、比较等）最终都归结为加法（补码运算），逻辑运算和移位则围绕它配合完成。

**解题切入点**：拿到题目先明确 ALU 的定位——它是一个组合逻辑运算部件，不是存储部件。做这类题可以类比“算法题先找主过程”：ALU 的主过程就是“算”，而加法是最基本的算术操作，所以核心是加法器；其他选项只是辅助通路或外围部件。

**推演**：

1. ALU 是 CPU 中执行算术运算和逻辑运算的组合逻辑电路，其主要功能包括：
   - 算术运算：加、减、乘、除、比较等；
   - 逻辑运算：与、或、非、异或等；
   - 移位运算：左移、右移等。

2. 在计算机中，减法并不单独设置减法器，而是通过补码转换为加法：
   $$
   [x-y]_{\text{补}} = [x]_{\text{补}} + [-y]_{\text{补}}
   $$
   因此，加法器是算术运算的基础。

3. 乘法、除法在硬件实现中也常通过“加法 + 移位”完成，例如：
   - 乘法可看作多次移位相加；
   - 除法可看作多次移位相减，而减法又转为补码加法。

4. 因此 ALU 的核心部件是加法器。

各选项分析：

- A. 多路选择器：用于选择参与运算的数据或运算结果通路，是 ALU 外围的数据选择部件，不是核心。
- B. 移位器：用于移位操作，是 ALU 的辅助部件，但无法独立完成算术运算的核心功能。
- C. 加法器：完成算术运算最基础的加法操作，是 ALU 的核心。
- D. 寄存器：用于暂存数据，属于存储部件；ALU 本身是组合逻辑电路，不含寄存器。

所以选 C。

**易错点**：

- 易误选 D“寄存器”，混淆 CPU 与 ALU 的组成。寄存器属于 CPU 内部存储部件，不是 ALU 的核心运算部件。
- 易误选 B“移位器”，因为乘除法需要移位。但移位只是辅助手段，真正的运算本质仍是加法。
- 易误选 A“多路选择器”，因为 ALU 内部数据输入输出常有多路选择。但选择器只负责“选路”，不负责“计算”。

**命题规律**：本考点属于 408 计算机组成原理中“运算器”的基础概念题，通常以选择题形式考查 ALU 的组成、功能或某个运算部件的地位。常见变式包括：“ALU 属于组合逻辑电路还是时序逻辑电路？”“补码加减法运算部件包含哪些基本组件？”等。复习时应重点掌握 ALU 的组成结构、加法器在运算中的核心作用，以及补码运算和移位操作的关系。

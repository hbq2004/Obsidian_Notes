# 选择题 第 33 题

33.【2024统考真题】C语言代码段如下,执行该代码段后,$j$的值是 (  )
```c
int i = 32777;
short si = i;
int j = si;
```
A. $-32777$
B. $-32759$
C. $32759$
D. $32777$

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C02-22-M33_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。`short` 按 16 位补码处理：$32777$ 的低 16 位为 `0x8009`，按有符号补码解释为 $-32759$；再符号扩展回 `int`，值仍是 $-32759$。

**解题切入点**：看到 `int -> short -> int`，马上定位到“补码的截断与符号扩展”。先明确 `short` 为 16 位、`int` 为 32 位；赋值给 `short` 时保留低 16 位，再由 `short` 转回 `int` 时按符号位扩展。做题时先转十六进制，不要直接盯着十进制做加减。

**推演**：

1. $32777 = 32768 + 9 = 2^{15} + 9$。在 32 位 `int` 中，其补码形式为：
   $$0x00008009_{16}.$$

2. 执行 `short si = i;`。`short` 只有 16 位，因此保留低 16 位：
   $$0x00008009 \rightarrow 0x8009.$$

3. 将 `0x8009` 按 16 位有符号补码解释。最高位为 1，所以是负数。其值为：
   $$-2^{15} + 9 = -32768 + 9 = -32759.$$

   也就是：
   $$si = -32759.$$

4. 执行 `int j = si;`。有符号 `short` 转 `int` 时做符号扩展：
   $$0x8009 \rightarrow 0xFFFF8009.$$

   32 位补码 `0xFFFF8009` 表示的值仍是 $-32759$。

因此 $j=-32759$，选 **B**。

**易错点**：

- 误以为 $32777$ 大于 $32767$ 后直接得到 $-32777$，忽略了补码截断后的位模式应解释为 $-32759$。
- 把 `0x8009` 当作无符号数，得到 $32777$，但 `short` 是有符号类型，最高位是符号位。
- 忘记从 `short` 转回 `int` 时要符号扩展。实际上符号扩展不会改变数值大小。
- 常见快捷算法：若低 16 位大于等于 $2^{15}$，则按有符号解释为“原数减去 $2^{16}$”，即 $32777-65536=-32759$。

**命题规律**：本题属于“数据的表示和运算”中的定点数、补码、类型转换考点。常见变式包括 `char`/`short` 与 `int` 的互相转换、`signed` 与 `unsigned` 的符号扩展/零扩展区别、`%d` 与 `%u` 输出等。复习时重点掌握：补码转十六进制、截断保留低 16 位、符号扩展/零扩展规则，以及 408 默认采用 16 位 `short`、32 位 `int`、补码表示。

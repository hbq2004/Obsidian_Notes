# 选择题 第 2 题

![[_Attachments/题目识别/27_王道408-题目/CO-C02-21-M02_题目.png|题目]]

2. 一个 16 位无符号二进制数的表示范围是 (    )

(A) 0~65536

(B) 0~65535

(C) −32768~32767

(D) −32768~32768

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C02-21-M02_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。一个 16 位无符号二进制数共有 $2^{16}=65536$ 个取值，范围为 $0\sim 65535$，即 $[0,2^{16}-1]$。

**解题切入点**：看到“无符号”三个字，立刻定位到“无符号数范围公式”：

$$0 \sim 2^n-1$$

这里 $n$ 是二进制位数。不要一看到“16 位”就去想补码范围 $-32768\sim 32767$，那是带符号数的范围。可以类比：$n$ 个开关每个有“开/关”两种状态，一共能表示 $2^n$ 种状态；但状态编号从 0 开始，所以最大编号是 $2^n-1$。

**推演**：

设 16 位无符号二进制数为：

$$b_{15}b_{14}\cdots b_1b_0$$

每一位都是 0 或 1，其真值按权展开为：

$$\sum_{i=0}^{15} b_i 2^i$$

最小值：所有位都为 0，即

$$0000\ 0000\ 0000\ 0000$$

对应十进制：

$$0$$

最大值：所有位都为 1，即

$$1111\ 1111\ 1111\ 1111$$

对应十进制：

$$\sum_{i=0}^{15} 2^i = 2^{16}-1 = 65536-1 = 65535$$

所以 16 位无符号二进制数的表示范围是：

$$0\sim 65535$$

选项 A 的 $0\sim65536$ 错在把“个数” $2^{16}=65536$ 当成了“最大值”；选项 C 是 16 位补码的表示范围；选项 D 既不是无符号数范围，也不是标准补码范围。

**易错点**：

1. **混淆“个数”和“最大值”**  
   16 位无符号数一共有 $2^{16}=65536$ 个数，但最大值是 $65535$，因为从 0 开始计数。这是最常见错误。

2. **混淆无符号数与带符号数**  
   无符号数没有符号位，最小值为 0；带符号补码数才有正负之分，16 位补码范围为 $-32768\sim 32767$。题目明确说“无符号”，不能选 C。

3. **认为 $65536$ 也能用 16 位表示**  
   $65536=2^{16}$，写成二进制是 $1\ 0000\ 0000\ 0000\ 0000$，共 17 位，16 位无符号数无法表示。

4. **记错原码、反码、补码范围**  
   16 位原码/反码范围为 $-32767\sim32767$，16 位补码范围为 $-32768\sim32767$，这些都不能与无符号数混淆。

**命题规律**：这是计算机组成原理“数据的表示与运算”中的基础题，主要考查无符号数范围公式：

$$0\sim 2^n-1$$

常见变式包括：

- $n$ 位无符号数范围；
- $n$ 位补码范围：$-2^{n-1}\sim 2^{n-1}-1$；
- $n$ 位原码/反码范围：$-(2^{n-1}-1)\sim 2^{n-1}-1$；
- 结合 C 语言中 `unsigned short`、`short` 等类型考查。

复习时建议把无符号数、原码、反码、补码的范围放在一起对比记忆，并熟练掌握“最小值、最大值、可表示个数”三者之间的关系。

# 选择题 第 2 题

![[_Attachments/题目识别/27_王道408-题目/CO-C02-21-M02_题目.png|题目]]

2. 一个 $16$ 位无符号二进制数的表示范围是（ ）
A. $0 \sim 65536$
B. $0 \sim 65535$
C. $-32768 \sim 32767$
D. $-32768 \sim 32768$

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C02-21-M02_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。$16$ 位无符号二进制数的表示范围为 $0 \sim 2^{16}-1 = 0 \sim 65535$。

**解题切入点**：看到“无符号数”立即想到它没有符号位，所有 $16$ 位都用来表示数值大小。可以类比“有多少个二进制位就能表示多少个不同的状态”：$16$ 位共有 $2^{16}=65536$ 种状态，而无符号数从 $0$ 开始编号，因此最大值是 $2^{16}-1=65535$。这和编程中数组下标从 $0$ 开始类似，状态数比最大编号多 $1$。

**推演**：
一个 $n$ 位无符号二进制数可表示的最小值是全 $0$：
$$0000\ 0000\ 0000\ 0000_2 = 0$$
最大值是全 $1$：
$$1111\ 1111\ 1111\ 1111_2 = 2^{15}+2^{14}+\cdots+2^1+2^0 = 2^{16}-1$$
因此 $n=16$ 时，最大值为：
$$2^{16}-1 = 65536-1 = 65535$$
所以表示范围为：
$$0 \sim 65535$$

选项分析：
- A 的 $65536$ 是 $2^{16}$，即状态总数，不是最大数值，多了 $1$。
- C、D 都涉及负数，是带符号数的表示范围，与“无符号数”矛盾。
- C 是 $16$ 位补码整数的范围（$-2^{15} \sim 2^{15}-1$），D 范围错误。

**易错点**：
1. 混淆“状态数”和“最大值”：$16$ 位有 $2^{16}=65536$ 种状态，但取值从 $0$ 开始，最大值是 $65535$，不是 $65536$。
2. 漏看“无符号”直接套用补码范围，误选 C 或 D。
3. 记忆混淆：$16$ 位补码范围是 $-32768 \sim 32767$，不是 $-32768 \sim 32768$，D 的右端点多了 $1$。

**命题规律**：这是计算机组成原理中数据表示的基础题，常考各种位数下无符号数、原码、反码、补码的表示范围。复习时建议总结表格：  
- $n$ 位无符号数范围：$0 \sim 2^n-1$；  
- $n$ 位原码/反码范围：$-(2^{n-1}-1) \sim 2^{n-1}-1$；  
- $n$ 位补码范围：$-2^{n-1} \sim 2^{n-1}-1$。  

变式常为 $8$ 位、$32$ 位甚至 $n$ 位的范围计算，或结合补码的定点整数表示出题，掌握通式即可快速求解。

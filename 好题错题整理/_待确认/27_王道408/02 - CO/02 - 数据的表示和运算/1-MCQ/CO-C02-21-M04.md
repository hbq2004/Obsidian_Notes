# 选择题 第 4 题

![[_Attachments/题目识别/27_王道408-题目/CO-C02-21-M04_题目.png|题目]]

4. 对真值0表示形式唯一的机器数是( )

(A) 原码

(B) 补码和移码

(C) 反码

(D) 以上都不对

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C02-21-M04_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。补码和移码中，真值 0 只有一种机器数表示；原码和反码中 0 有“+0”和“-0”两种表示。

**解题切入点**：看到“真值 0 表示形式唯一”，立刻联想到定点机器数编码中“零的表示”这一经典考点。可以类比算法竞赛中的“判重”：如果一种编码把同一个对象映射成两个不同值，就无法用该编码唯一表示该对象；只需要分别列出 $+0$ 和 $-0$ 在原码、反码、补码、移码下的编码，看谁重合。

**推演**：设机器字长为 $n$ 位，最高位为符号位，数值部分为 $n-1$ 位。

1. 原码  
   $$[+0]_{\text{原}}=0\underbrace{00\cdots 0}_{n-1\text{ 位}},\qquad [-0]_{\text{原}}=1\underbrace{00\cdots 0}_{n-1\text{ 位}}$$  
   因此原码中 $0$ 有两种表示，不唯一。

2. 反码  
   正数的反码等于原码；负数的反码是符号位不变，数值位按位取反。  
   $$[+0]_{\text{反}}=0\underbrace{00\cdots 0}_{n-1\text{ 位}},\qquad [-0]_{\text{反}}=1\underbrace{11\cdots 1}_{n-1\text{ 位}}$$  
   因此反码中 $0$ 也有两种表示，不唯一。

3. 补码  
   补码中 $+0$ 和 $-0$ 的表示相同：  
   $$[+0]_{\text{补}}=0\underbrace{00\cdots 0}_{n-1\text{ 位}},\qquad [-0]_{\text{补}}=0\underbrace{00\cdots 0}_{n-1\text{ 位}}$$  
   因为 $-0$ 的补码可由“取反加 1”得到：负数的补码是其反码末位加 1，反码为 $1\underbrace{11\cdots 1}_{n-1\text{ 位}}$，末位加 1 后最高位溢出丢弃，结果为全 0。所以补码中 $0$ 表示唯一。

4. 移码  
   移码通常定义为：$[x]_{\text{移}}=2^{n-1}+x$（其中 $x$ 为真值，且 $-2^{n-1}\le x<2^{n-1}$）。  
   对 $x=0$：  
   $$[+0]_{\text{移}}=2^{n-1}+0=1\underbrace{00\cdots 0}_{n-1\text{ 位}}$$  
   $$[-0]_{\text{移}}=2^{n-1}+0=1\underbrace{00\cdots 0}_{n-1\text{ 位}}$$  
   可见 $+0$ 与 $-0$ 的移码完全相同，因此移码中 $0$ 表示也唯一。

综上，补码和移码对真值 0 的表示唯一。

**易错点**：
- 误认为“补码中 0 唯一，移码不唯一”或“原码中 0 唯一”。实际上移码 $0$ 的表示是 $1\underbrace{00\cdots 0}$，它与补码中 $0$ 的表示不同（补码 $0$ 是全 0），但两者各自内部都只有一个 $0$。
- 要注意区分“机器数表示唯一”是指同一编码体系内 $+0$ 和 $-0$ 是否对应同一个编码，而不是比较不同编码体系之间的编码是否相同。
- 计算 $-0$ 的补码时，容易忘记“按位取反后加 1”会产生进位并丢弃最高位溢出；只要记住补码中 $0$ 的表示是唯一的即可。

**命题规律**：该考点属于“数据的表示与运算”中的基础概念，常以选择题形式考查“零的表示唯一/不唯一”的编码类型，也常结合原码、反码、补码、移码的定义域、表示范围一起考，或扩展考查“为什么补码能多表示一个最小负数”。复习时建议把四种编码的 $+0$、$-0$、最小负数、最大正数的表示列成对比表，并掌握补码与移码之间的转换关系（符号位取反），这样既能应对零表示问题，也能应对“移码与补码关系”等常见变式。

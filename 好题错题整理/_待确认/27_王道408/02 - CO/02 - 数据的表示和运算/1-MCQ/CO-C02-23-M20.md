# 选择题 第 20 题

![[_Attachments/题目识别/27_王道408-题目/CO-C02-23-M20_题目.png|题目]]

20. 假设已定义三个 int 型变量 x、y 和 z，sizeof(int)=4，double 型采用 IEEE754 双精度浮点数格式，变量 dx、dy 和 dz 的声明和初始化如下：

```c
double dx=(double)x;
double dy=(double)y;
double dz=(double)z;
```

则下列关系表达式中永远为真的是（  ）
I. $dx + dy == (double)(x + y)$
II. $dx \times dx >= 0$
III. $dx/dx == dy/dy$
IV. $(dx + dy) + dz == dx + (dy + dz)$

A. I 和 II
B. II 和 III
C. III 和 IV
D. II 和 IV

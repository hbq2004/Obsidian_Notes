# 选择题 第 20 题

![[_Attachments/题目识别/27_王道408-题目/CO-C02-23-M20_题目.png|题目]]

20. 假设已定义三个 int 型变量 $x$、$y$ 和 $z$, $\mathrm{sizeof(int)}=4$, $double$ 型采用 IEEE754 双精度浮点数格式, 变量 $dx$、$dy$ 和 $dz$ 的声明和初始化如下:
```c
double dx=(double)x;
double dy=(double)y;
double dz=(double)z;
```
则下列关系表达式中永远为真的是 (   )
$I. dx + dy == (double)(x+y)$ $\quad$ $II. dx \times dx >= 0$
$III. dx/dx == dy/dy$ $\quad$ $\quad$ $\quad$ $\quad$ $IV. (dx+dy) + dz == dx + (dy+dz)$
A. $I$ 和 $II$ $\quad$ $\quad$ $\quad$ $\quad$ $\quad$ B. $II$ 和 $III$
C. $III$ 和 $IV$ $\quad$ $\quad$ $\quad$ $\quad$ D. $II$ 和 $IV$

## DeepSeek V4 Flash Max 解析

**答案**：D（II 和 IV）。  
理由：II 中浮点平方不可能为负；IV 中所有中间整数和都远小于 $2^{53}$，double 可精确表示，因此两种加法顺序结果相同；I 会因 int 加法溢出而假，III 会因 $0/0$ 产生 NaN 而假。

**解题切入点**：  
题目问“永远为真”，所以先找反例，尤其是边界值：

- I 的右端 `(double)(x+y)` 先做 int 加法，要检查 `INT_MAX + INT_MAX` 这类溢出；
- III 要检查分母为 0 的情况，IEEE754 中 $0.0/0.0$ 是 NaN；
- II 只需判断符号和是否溢出；
- IV 是浮点结合律问题，关键看中间结果是否超出 double 可精确表示的整数范围 $2^{53}$。

这就像算法竞赛里判断“恒成立”时要先测边界数据：`0`、`INT_MAX`、`INT_MIN` 往往能一击致命。

**推演**：  

先明确一个事实：IEEE754 double 有 53 位有效数字（52 位尾数 + 隐含 1），因此任意 32 位 int 的绝对值不超过 $2^{31}$，都能精确转换为 double；并且所有绝对值不超过 $2^{53}$ 的整数也都能被 double 精确表示。

### I. $dx + dy == (double)(x+y)$

单独看 $dx+dy$，它的数学值就是 $x+y$，且
$$
|x+y|\le 2^{32}<2^{53}
$$
所以 $dx+dy$ 本身不会发生舍入。

但右端 `(double)(x+y)` 是先做 int 加法，再做转换。32 位 int 加法可能溢出。取反例：
$$
x=y=2^{31}-1
$$
数学上
$$
x+y=2^{32}-2
$$
但按 32 位补码 int 加法回绕后结果是 $-2$，于是
$$
dx+dy=(2^{31}-1)+(2^{31}-1)=2^{32}-2
$$
而右端是 $-2.0$，二者不相等。  
所以 I 不是永远为真。

### II. $dx \times dx \ge 0$

若 $x=0$，则 $dx=0.0$，乘积为 $0.0$，满足 $\ge 0$。

若 $x\neq 0$，则 $dx\neq 0$，且 $dx$ 是有限数；两个同号有限数相乘，符号必为正；最大绝对值为
$$
(2^{31})^2=2^{62}
$$
远小于 double 的上限（约 $1.8\times 10^{308}$），不会溢出为 $\infty$，也不会产生 NaN。  
所以 II 永远为真。

### III. $dx/dx == dy/dy$

取 $x=0$，则 $dx=0.0$。IEEE754 中
$$
0.0/0.0=\text{NaN}
$$
而 NaN 与任何数用 `==` 比较都为假，包括与自身比较也是假。  
所以只要 $x=0$，III 就为假，不是永远为真。

### IV. $(dx+dy)+dz == dx+(dy+dz)$

任意两个 int 的和作为实数，绝对值不超过
$$
2^{32}<2^{53}
$$
所以 $dx+dy$、$dy+dz$ 都能被 double 精确表示。

第一次相加后的结果再与第三个 int 相加，绝对值不超过
$$
2^{32}+2^{31}=3\cdot 2^{31}<2^{53}
$$
因此最终结果也能被 double 精确表示。

由于所有中间结果都是可精确表示的整数，IEEE754 舍入不会改变它们，所以实数加法结合律可以保留：
$$
(dx+dy)+dz = x+y+z = dx+(dy+dz)
$$
因此 IV 永远为真。

**易错点**：

- 把 `(double)(x+y)` 误看成 `dx+dy`，忽略了右端先做 int 加法、可能溢出。
- 认为“分子分母相同一定等于 1”，忽略了 $0.0/0.0$ 在 IEEE754 中是 NaN，而不是 1。
- 看到“浮点加法不满足结合律”就直接判断 IV 为假；但本题的 int32 数据范围太小，所有中间和都小于 $2^{53}$，不会舍入，所以 IV 反而为真。
- 忽略了 C 语言中有符号 int 溢出至少是未定义行为；按 408 常用补码回绕模型，I 也不恒真。

**命题规律**：  
本题核心考点是 IEEE754 双精度格式的有效位数、int 转 double 的精确性、int 溢出、除零产生 NaN、浮点数运算的结合性与舍入。  

常见变式包括：将 double 改成 float，此时由于 float 只有 24 位有效数字，32 位 int 转 float 本身可能不精确，结论会变化；或者考察乘法分配律、加法结合律在某些大数下不成立。  

复习建议：牢记 double 精确整数范围是 $[-2^{53},2^{53}]$，float 是 $[-2^{24},2^{24}]$；遇到“恒真”题，先取 $0$、`INT_MAX`、`INT_MIN` 作为反例。

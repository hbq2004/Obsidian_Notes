# 选择题 第 20 题

![[_Attachments/题目识别/27_王道408-题目/CO-C02-23-M20_题目.png|题目]]

20. 假设已定义三个 int 型变量 x、y 和 z，sizeof(int)=4，double 型采用 IEEE754 双精度浮点数格式，变量 dx、dy 和 dz 的声明和初始化如下：

```c
double dx=(double)x;
double dy=(double)y;
double dz=(double)z;
```

则下列关系表达式中永远为真的是（  ）
I. $dx + dy == (double)(x + y)$
II. $dx \times dx >= 0$
III. $dx/dx == dy/dy$
IV. $(dx + dy) + dz == dx + (dy + dz)$

A. I 和 II
B. II 和 III
C. III 和 IV
D. II 和 IV

## 答案

## DeepSeek V4 Flash Max 解析

**答案**：D。II 和 IV 恒真；I 不恒真（因为 `(double)(x + y)` 先做 int 加法，可能溢出/未定义），III 不恒真（除数为 0 时得到 NaN）。

**解题切入点**：  
拿到题目先判断 “int 转 double 是否精确” 和 “每一步浮点运算是否会发生舍入”。双精度 double 有 53 位有效数字，32 位 int 转换一定精确；本题还要注意 C 语言中 `(double)(x + y)` 是先算 int 加法再转换，不能和 `(double)x + (double)y` 混为一谈。

**推演**：  

IEEE 754 双精度格式的规格化数有效位为  
$$1+52=53\text{ 位}$$  
所以所有满足 $|n|<2^{53}$ 的整数都能被 double 精确表示。32 位 int 的值满足  
$$|x|\le 2^{31}<2^{53}$$  
因此单个 int 转 double 没有精度损失。

### I. $dx+dy == (double)(x+y)$

因为  
$$|x+y|\le 2^{32}<2^{53}$$  
所以 $dx+dy$ 在 double 下能精确表示实数 $x+y$。

但右侧 `(double)(x + y)` 是先把 $x$ 和 $y$ 按 int 相加，再把 int 结果转 double。若 $x+y$ 不溢出，则 I 为真；若溢出，则 int 加法结果已经不是真正的 $x+y$。例如在常见 32 位补码机器上，取  
$$x=y=2^{31}-1$$  
则左侧为  
$$2147483647.0+2147483647.0=4294967294.0$$  
而右侧 int 加法溢出回绕为 $-2$，再转 double 为  
$$-2.0$$  
所以 I 不恒真。

### II. $dx\times dx\ge 0$

$dx$ 是有限 double，且是某个 int 的精确值。无论 $dx$ 为正、负还是 0，其平方的符号必为非负：  
- $dx>0$：结果为正；
- $dx<0$：负负得正；
- $dx=0$：结果为 $+0$。

并且最大也不过约为  
$$(2^{31})^2=2^{62}$$  
远小于 double 的最大有限值，不会溢出。因此 II 恒真。

### III. $dx/dx == dy/dy$

若 $x=0$，则  
$$dx/dx = 0.0/0.0 = \text{NaN}$$  
而任何包含 NaN 的 `==` 比较结果都为假。例如取  
$$x=0,\quad y=1$$  
则  
$$dx/dx=\text{NaN},\qquad dy/dy=1.0$$  
比较结果为假。因此 III 不恒真。

### IV. $(dx+dy)+dz == dx+(dy+dz)$

对任意 int $x,y,z$，有  
$$|x|,|y|,|z|\le 2^{31}$$  
所以  
$$|x+y|\le 2^{32}<2^{53}$$  
因此 $dx+dy$ 精确等于实数 $x+y$，不会舍入。

接着  
$$|(x+y)+z|\le |x|+|y|+|z|\le 3\cdot 2^{31}<2^{33}<2^{53}$$  
所以 $(dx+dy)+dz$ 也能精确表示最终实数 $x+y+z$。同理  
$$dx+(dy+dz)$$  
也精确等于同一个实数 $x+y+z$。因此 IV 恒真。

故恒真的只有 II 和 IV，选 D。

**易错点**：  
- 把 `(double)(x + y)` 误认为 `(double)x + (double)y`，忽略了 int 加法可能先溢出。
- 认为浮点加法“一般不具有结合律”，就直接判断 IV 错；但本题三个 int 的和最多只有 33 位，double 的 53 位有效数字足以精确表示，因此不会因舍入破坏结合律。
- 认为 `0.0/0.0` 等于 1 或 0；IEEE 754 中结果是 NaN，且 `NaN == NaN` 为假。
- 忽略 int 加法溢出在 C 语言中属于未定义行为，不能把它当作普通数学加法处理。

**命题规律**：  
本题属于“数据的表示和运算”中浮点数表示与 C 语言类型转换的结合考点。常见变式包括：把 double 换成 float（24 位有效数字），或比较 int 加法溢出前后的转换结果。复习时应重点掌握：double 能精确表示 $[-2^{53},2^{53}]$ 内所有整数，float 只能精确表示 $[-2^{24},2^{24}]$ 内所有整数；分析浮点表达式时，先判断中间结果是否超过有效位数，再判断是否发生舍入、溢出或产生 NaN。

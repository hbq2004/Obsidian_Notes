# 综合题 第 2 题

![[_Attachments/题目识别/27_王道408-题目/CO-C02-23-F02_题目.png|题目]]

2. 假定变量 $i$ 是一个 32 位的 int 型整数，$f$ 和 $d$ 分别为 float 型 (32 位) 和 double 型 (64 位) 实数。分析下列各布尔表达式，说明结果是否在任何情况下都是“true”。
(1) $i == (int)((double)i)$
(2) $f == (float)((int)f)$
(3) $f == (float)((double)f)$
(4) $d == (double)((float)d)$

## DeepSeek V4 Flash Max 解析

**答案**：

(1) **恒为 true**；(2) **不恒为 true**；(3) **恒为 true**；(4) **不恒为 true**。

一句话理由：32 位 int 的绝对值范围远小于 double 可精确表示的整数范围；float 转 int 会截断小数；float 转 double 无精度损失，但 double 转 float 可能舍入损失精度。

---

**解题切入点**：

先不要急着代数值，先看类型转换的方向：

- 拓宽转换：`int -> double`、`float -> double`，精度通常不损失；
- 收窄转换：`double -> float`、`float/double -> int`，可能损失精度；
- 关键在于浮点数的有效位：float 只有 24 位有效位，double 有 53 位有效位。

可以用“尺子”来类比：用更细的尺子量一个整数，当然量得准；但用一个粗尺子量完，再用细尺子抄一遍，也找不回粗尺子已经丢掉的精度。

---

**推演**：

IEEE 754 中：

- float：1 位符号位 + 8 位阶码 + 23 位尾数，另有隐含 1 位，所以有效位数为 $24$；
- double：1 位符号位 + 11 位阶码 + 52 位尾数，另有隐含 1 位，所以有效位数为 $53$。

一般地，$p$ 位有效位可以精确表示所有绝对值不超过 $2^p$ 的整数。

### (1) $i == (\mathrm{int})((\mathrm{double})i)$

32 位 int 的范围是

$$
[-2^{31},\ 2^{31}-1]
$$

而 double 有 53 位有效位，可以精确表示绝对值不超过

$$
2^{53}
$$

的所有整数。显然

$$
2^{31} < 2^{53}
$$

所以每个 32 位 int 都能被 double 精确表示，即

$$
(\mathrm{double})i = i
$$

再转回 int，值仍在 int 范围内，因此

$$
(\mathrm{int})((\mathrm{double})i) = i
$$

所以该表达式恒为 true。

### (2) $f == (\mathrm{float})((\mathrm{int})f)$

C 语言中浮点数转整数是“向零截断”，即直接把小数部分丢掉。

取反例：

$$
f = 1.5
$$

则

$$
(\mathrm{int})f = 1
$$

$$
(\mathrm{float})((\mathrm{int})f) = 1.0
$$

而

$$
1.0 \ne 1.5
$$

所以该表达式**不恒为 true**。

### (3) $f == (\mathrm{float})((\mathrm{double})f)$

float 有 24 位有效位，double 有 53 位有效位，所以任意有限 float 值都能被 double 精确表示：

$$
(\mathrm{double})f = f
$$

再把该 double 转回 float 时，由于原值本来就是 float 可表示的数，舍入后仍然得到原值：

$$
(\mathrm{float})((\mathrm{double})f) = f
$$

所以该表达式**恒为 true**。

注意：这里虽然发生了 `double -> float` 的收窄转换，但被转换的值恰好落在 float 的表示网格上，因此不会损失精度。

### (4) $d == (\mathrm{double})((\mathrm{float})d)$

double 转 float 会把 53 位有效位数舍入到 24 位，可能损失精度。之后即使再转回 double，损失的信息也无法恢复。

取反例：

$$
d = 1 + 2^{-30}
$$

这个值在 double 中可以精确表示，因为 double 在 $[1,2)$ 区间内的精度远高于 $2^{-30}$。

但 float 在 $[1,2)$ 区间内的精度是 $2^{-23}$，而

$$
2^{-30} < \frac{1}{2} \cdot 2^{-23}
$$

所以按舍入到最接近规则：

$$
(\mathrm{float})d = 1.0
$$

于是

$$
(\mathrm{double})((\mathrm{float})d) = 1.0
$$

显然

$$
1.0 \ne 1 + 2^{-30}
$$

所以该表达式**不恒为 true**。

---

**易错点**：

1. **误以为 float 也是 32 位，就能精确表示所有 32 位 int**  
   float 的 32 位中有一部分给了符号位和阶码，尾数有效位只有 24 位，不能精确表示所有 32 位整数。

2. **把浮点转整数当成四舍五入**  
   C 语言中 `(int)f` 是向零截断，不是四舍五入。例如 `(int)1.9 = 1`。

3. **认为 `float -> double -> float` 一定会有精度损失**  
   不一定。因为原来的 float 本身就在 float 的表示网格上，double 精确表示它之后，再转回 float 仍然能得到原值。

4. **认为 `double -> float -> double` 能恢复原值**  
   不能。double 转 float 时已经丢失了低精度尾数位，再转回 double 只会把这些丢失的位补成 0，不能恢复原来的值。

5. **使用超出 int 范围的浮点数作反例时要小心**  
   在 C 语言中，浮点数转 int 如果超出 int 范围，行为是未定义的。反例最好选在合法范围内，例如 $f = 1.5$。

---

**命题规律**：

本题属于“IEEE 754 浮点数表示与类型转换”的经典考点。

常见变式有：

- 判断 `int -> float -> int` 是否一定相等；
- 判断 `float -> double -> float` 是否一定相等；
- 判断 `double -> float -> double` 是否一定相等；
- 考查 float 和 double 能精确表示的最大连续整数范围。

复习时建议记住一张表：

| 转换 | 是否一定无损 |
|---|---|
| `int -> double` | 一定无损，因为 int 范围小于 $2^{53}$ |
| `int -> float` | 不一定无损，float 只有 24 位有效位 |
| `float -> double` | 一定无损 |
| `double -> float` | 不一定无损，可能舍入 |
| `float/double -> int` | 一定可能损失，向零截断 |

# 综合题 第 1 题

![[_Attachments/题目识别/27_王道408-题目/CO-C02-22-F01_题目.png|题目]]

1. 已知32位寄存器$R1$中存放的变量$x$的机器码为$8000\ 0004H$，*unsigned int* 型的乘除法采用逻辑移位操作，int 型的乘除法采用算术移位操作，请问：
(1) 当$x$是*unsigned int* 型时，$x$的真值是多少？$x/2$存放在$R1$中的机器码是什么？$x/2$的真值是多少？$2x$存放在$R1$中的机器码是什么？$2x$的真值是多少？
(2) 当$x$是 int 型时，$x$的真值是多少？$x/2$存放在$R1$中的机器码是什么？$x/2$的真值是多少？$2x$存放在$R1$中的机器码是什么？$2x$的真值是多少？

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C02-22-F01_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**  
(1) unsigned int：$x$真值=$2147483652$，$x/2$机器码=$4000\ 0002\text{H}$，$x/2$真值=$1073741826$，$2x$机器码=$0000\ 0008\text{H}$，$2x$真值=$8$。  
(2) int：$x$真值=$-2147483644$，$x/2$机器码=$C000\ 0002\text{H}$，$x/2$真值=$-1073741822$，$2x$机器码=$0000\ 0008\text{H}$，$2x$真值=$8$。

**解题切入点**  
首先将机器码转换为二进制，根据数据类型确定真值规则：无符号数直接按位权展开，有符号数（补码）按补码规则求真值。然后利用移位操作模拟乘除：无符号数采用逻辑移位（左/右移补0），有符号数采用算术移位（右移符号位扩展，左移补0但可能溢出）。分别计算移位后的机器码，并重新解释真值。

**推演**  
机器码 $8000\ 0004\text{H}$ 的二进制为 $1000\ 0000\ 0000\ 0000\ 0000\ 0000\ 0000\ 0100$。

(1) *unsigned int* 型：所有位均为数值，真值  
$$x = 2^{31} + 2^{2} = 2147483648 + 4 = 2147483652.$$  
- $x/2$：逻辑右移一位，高位补 $0$，得二进制 $0100\ 0000\ 0000\ 0000\ 0000\ 0000\ 0000\ 0010$，即 $4000\ 0002\text{H}$，真值  
$$x/2 = 2^{30} + 2 = 1073741824 + 2 = 1073741826.$$  
- $2x$：逻辑左移一位，低位补 $0$，高位丢弃，得二进制 $0000\ 0000\ 0000\ 0000\ 0000\ 0000\ 0000\ 1000$，即 $0000\ 0008\text{H}$，真值（模 $2^{32}$）  
$$2x = 8.$$

(2) *int* 型：补码表示，符号位权 $-2^{31}$，真值  
$$x = -2^{31} + 2^{2} = -2147483648 + 4 = -2147483644.$$  
- $x/2$：算术右移一位，符号位 $1$，高位补 $1$，得二进制 $1100\ 0000\ 0000\ 0000\ 0000\ 0000\ 0000\ 0010$，即 $C000\ 0002\text{H}$，真值按补码  
$$x/2 = -2^{31} + 2^{30} + 2 = -2147483648 + 1073741824 + 2 = -1073741822,$$  
与 $x/2$ 精确值一致（$x$ 为偶数）。  
- $2x$：算术左移一位（与逻辑左移相同），低位补 $0$，高位丢弃，得 $0000\ 0008\text{H}$，真值（补码）  
$$2x = 8,$$  
溢出但移位结果如此。

**易错点**  
1. 真值计算混淆：无符号数直接按位权，有符号数需考虑补码中符号位的负权，如 $8000\ 0004\text{H}$ 作为 int 真值为 $-2^{31}+4$ 而非 $-4$。  
2. 移位规则错误：逻辑右移高位补 $0$，算术右移高位补符号位（负数补 $1$）。左移时两者相同，但需注意溢出后机器码的解释。  
3. 机器码书写遗漏前导零：如 $2x$ 结果应为 $0000\ 0008\text{H}$ 而非 $8\text{H}$，保持 32 位表示。  
4. 忽略溢出影响：有符号数左移可能改变符号，但移位结果直接对应补码真值，不能擅自修正。

**命题规律**  
本题考察计算机中数的表示（无符号数、补码）与移位操作实现乘除的关系。常见变式包括：不同机器码（如奇数、负数）、不同移位次数、结合溢出判断或算术右移对奇数的向下取整效果。复习时需熟练掌握二进制/十六进制转换、补码求真值，以及逻辑/算术移位的硬件实现细节，并对比 C 语言中整数除法与算术右移的差异（向零取整 vs. 向下取整）。

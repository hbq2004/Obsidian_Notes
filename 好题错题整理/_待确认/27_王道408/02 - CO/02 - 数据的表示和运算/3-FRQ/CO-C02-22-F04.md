# 综合题 第 4 题

![[_Attachments/题目识别/27_王道408-题目/CO-C02-22-F04_题目.png|题目]]

4.【2020统考真题】有实现 $x \times y$ 的两个C语言函数如下：
```c
unsigned umul(unsigned x, unsigned y){ return x*y; }
int imul(int x, int y) { return x*y; }
```
假定某计算机 $M$ 中的 $ALU$ 只能进行加减运算和逻辑运算。请回答下列问题。
(1) 若 $M$ 的指令系统中没有乘法指令，但有加法、减法和位移等指令，则在 $M$ 上也能实现上述两个函数中的乘法运算，为什么？
(2) 若 $M$ 的指令系统中有乘法指令，则基于 $ALU$、位移器、寄存器及相应控制逻辑实现乘法指令时，控制逻辑的作用是什么？
(3) 针对以下三种情况：①没有乘法指令；②有使用 $ALU$ 和位移器实现的乘法指令；③有使用阵列乘法器实现的乘法指令，函数 $umul()$ 在哪几种情况下执行的时间最长？在哪几种情况下执行的时间最短？说明理由。
(4) $n$ 位整数乘法指令可保存 $2n$ 位乘积，当只取低 $n$ 位作为乘积时，其结果可能会发生溢出。当 $n=32$，$x=2^{31}-1$，$y=2$ 时，有符号整数乘法指令和无符号整数乘法指令得到的 $x \times y$ 的 $2n$ 位乘积分别是什么（用十六进制表示）？此时函数 $umul()$ 和 $imul()$ 的返回结果是否溢出？对于无符号整数乘法运算，当仅取乘积的低 $n$ 位作为乘法结果时，如何用 $2n$ 位乘积进行溢出判断？

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C02-22-F04_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：(1) 因为乘法可通过加法和移位实现，所以利用加法、减法和位移指令可编程模拟乘法。(2) 控制逻辑的作用是产生乘法指令执行所需的控制信号，如控制ALU进行加法/移位、位移器移位、寄存器更新、循环计数等。(3) 执行时间最长的是①，最短的是③；理由：①需软件循环，耗时最长；②硬件迭代乘法需多个时钟周期；③阵列乘法器为组合逻辑，单周期完成。(4) 无符号和有符号2n位乘积均为0x00000000FFFFFFFE；umul()不溢出，imul()溢出；无符号溢出判断：高n位全0则无溢出，否则溢出。

**解题切入点**：首先抓住乘法运算的本质——分解为加法和移位，因此即使没有乘法指令也可通过循环程序实现。然后从硬件实现角度区分迭代乘法（多周期）和阵列乘法（单周期），理解控制逻辑在数据通路中的作用。最后聚焦溢出判断，根据无符号乘法的高位全零条件判断。整体定位在计算机运算方法与CPU设计章节。

**推演**：
(1) 乘法运算可分解为加法和移位。例如无符号整数乘法：设被乘数$x$，乘数$y$，乘积$P$初始为0。对$y$的二进制位从低到高，若当前位为1则$P \leftarrow P + (x \ll i)$，然后$x$左移一位，$y$右移一位，重复直到$y=0$。有符号乘法可先处理符号再对绝对值运算，或使用补码乘法算法。指令系统中有加法、减法、位移指令，故可通过编程实现上述算法，从而完成乘法。

(2) 基于ALU、位移器、寄存器实现的乘法指令通常采用迭代方式。控制逻辑在每个时钟周期：①根据乘数最低位决定是否将移位后的被加数通过ALU加到部分积；②控制位移器完成对被乘数的左移和乘数的右移；③控制寄存器存储部分积、乘数、被乘数，并更新；④对已处理位数计数，当达到n时输出结果。因此控制逻辑的核心是产生正确的时序控制信号，协调各部件完成乘法迭代。

(3) 三种情况对比：
- ①无乘法指令：乘法由软件循环实现，每条指令需取指、译码、执行，循环次数等于乘数位数（32），执行时间最长。
- ②有ALU和位移器实现的乘法指令：硬件迭代，每个时钟周期处理一位，需n个时钟周期，但指令周期内完成，比软件快。
- ③有阵列乘法器实现的乘法指令：全组合逻辑并行计算所有位积与求和，一个时钟周期内完成，速度最快。
故umul()在情况①执行时间最长，情况③最短。

(4) $n=32$，$x=2^{31}-1$（0x7FFFFFFF），$y=2$（0x00000002）。乘积$=2^{32}-2=0\text{xFFFFFFFE}$。64位表示：无符号乘法高位补0，得0x00000000FFFFFFFE；有符号乘法（补码）因$x,y$为正，64位补码亦为0x00000000FFFFFFFE。函数umul()返回低32位0xFFFFFFFE，对应无符号数$2^{32}-2$，等于真实乘积，故无溢出。imul()返回低32位0xFFFFFFFE，对应有符号数-2，不等于真实乘积$2^{32}-2$，且超出32位有符号范围，故溢出。无符号整数乘法仅取低$n$位时，溢出判断：若$2n$位乘积的高$n$位全为0，则低$n$位即为正确乘积，无溢出；否则溢出。

**易错点**：
- 易错点1：误认为没有乘法指令就不能实现乘法，忽略加法和移位可模拟。应对：熟记乘法分解算法。
- 易错点2：控制逻辑作用描述不具体，只泛泛说“控制”。应对：结合迭代乘法数据通路，说明具体控制信号（加法/移位选择、寄存器更新、计数等）。
- 易错点3：误认为阵列乘法器也需多个时钟周期，或认为软件模拟可能更快。应对：明确阵列乘法器是组合逻辑，单周期完成；软件模拟总有循环开销。
- 易错点4：混淆有符号与无符号的64位乘积表示，但本题$x,y$均为正，故相同；但需注意有符号负数会符号扩展。溢出判断时，无符号仅看高n位全零，有符号需考虑符号位等。
- 易错点5：函数返回的是低32位，不是64位，要区分“返回结果”与“2n位乘积”。溢出指返回结果不能正确表示真实乘积。

**命题规律**：本题综合考查乘法运算的软硬件实现与溢出判定，考点在“计算机运算方法”和“中央处理器”章节。常见变式：分析具体迭代乘法器或阵列乘法器逻辑图，计算延迟；考察Booth补码乘法；结合ALU设计溢出检测电路。复习建议：深入理解乘法分解为加法和移位的原理，掌握无符号/有符号乘法算法，熟悉硬件乘法器（迭代与阵列）的组成与速度差异，熟练溢出判断条件（无符号看高n位，有符号看符号位与进位等）。同时，注意C语言中乘法截断行为与底层硬件对应。

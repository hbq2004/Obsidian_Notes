# 综合题 第 1 题

![[_Attachments/题目识别/27_王道408-题目/CO-C02-23-F01_题目.png|题目]]

1. 现有一计算机字长32位 $(D_{31} \sim D_0)$，符号位是第31位。

对于二进制 $1000\ 1111\ 1110\ 1111\ 1100\ 0000\ 0000\ 0000$，回答下列问题：

(1) 表示一个补码整数，其十进制值是多少？

(2) 表示一个无符号整数，其十进制值是多少？

(3) 表示一个 IEEE754 标准的单精度浮点数，其值是多少？

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C02-23-F01_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：
(1) 补码整数的十进制值为 $-1880113152$。  
(2) 无符号整数的十进制值为 $2414854144$。  
(3) IEEE754 单精度浮点数的值为 $-1.873046875 \times 2^{-96}$（或等价形式 $-\dfrac{959}{2^{105}}$）。

**解题切入点**：
题目给出一个32位二进制串，要求按三种不同编码解释。首先应明确每种编码的规则：补码整数符号位权值为 $-2^{31}$，其余位权值正；无符号整数所有位权值正；IEEE754 单精度浮点数需分割符号位、阶码（移码）、尾数（隐含1）。然后根据规则计算对应的十进制数值。

**推演**：
给定二进制串：$1000\ 1111\ 1110\ 1111\ 1100\ 0000\ 0000\ 0000$。

(1) 补码整数  
将二进制串视为补码，符号位 $D_{31}=1$，故为负数。数值可用两种方法求：  
方法一：设无符号整数 $U = \sum_{i=0}^{31} D_i 2^i$，则补码值 $= U - 2^{32}$。  
计算 $U$：  
$U = 2^{31} + 2^{27} + 2^{26} + 2^{25} + 2^{24} + 2^{23} + 2^{22} + 2^{21} + 2^{19} + 2^{18} + 2^{17} + 2^{16} + 2^{15} + 2^{14}$。  
具体值：  
$2^{31}=2147483648$，$2^{27}=134217728$，$2^{26}=67108864$，$2^{25}=33554432$，$2^{24}=16777216$，$2^{23}=8388608$，$2^{22}=4194304$，$2^{21}=2097152$，$2^{19}=524288$，$2^{18}=262144$，$2^{17}=131072$，$2^{16}=65536$，$2^{15}=32768$，$2^{14}=16384$。  
求和得 $U=2414854144$。  
$2^{32}=4294967296$，故补码值 $= 2414854144 - 4294967296 = -1880113152$。  
方法二：取反加1。取反得 $0111\ 0000\ 0001\ 0000\ 0011\ 1111\ 1111\ 1111$，加1得 $0111\ 0000\ 0001\ 0000\ 0100\ 0000\ 0000\ 0000$，即 $0x70104000$，十进制 $1880113152$，所以原数为 $-1880113152$。

(2) 无符号整数  
直接按无符号整数解释，即 $U$，故十进制值为 $2414854144$。

(3) IEEE754 单精度浮点数  
将32位按IEEE754标准分割：  
- 符号位 $s = D_{31} = 1$。  
- 阶码 $e$ 为第30-23位，二进制 $0001\ 1111$，即 $e = 31$。  
- 尾数 $M$ 为第22-0位，二进制 $110\ 1111\ 1100\ 0000\ 0000\ 0000$，即 $M = 0x6FC000 = 7323648$。  
因 $e=31$ 既不全0（$e=0$）也不全1（$e=255$），故为规格化数。IEEE754 单精度规格化数的公式：  
$$(-1)^s \times 2^{e-127} \times (1 + \frac{M}{2^{23}})$$  
代入：  
$$-2^{31-127} \times \left(1 + \frac{7323648}{8388608}\right) = -2^{-96} \times \left(1 + \frac{447}{512}\right) = -2^{-96} \times \frac{959}{512} = -\frac{959}{2^{105}}$$  
其中 $\frac{7323648}{8388608} = \frac{447}{512} = 0.873046875$，所以 $1 + \frac{M}{2^{23}} = 1.873046875$。因此浮点数值为 $-1.873046875 \times 2^{-96}$（或等价形式 $-\dfrac{959}{2^{105}}$）。

**易错点**：
- 补码负数：易错误地直接转换为无符号数，或取反加1时忘记加1。使用 $U-2^{32}$ 时需注意 $U$ 是32位无符号值。  
- 无符号数：直接计算时注意不要遗漏高位1的权值。  
- IEEE754：易混淆阶码偏移量（单精度为127）或忘记隐含的1。需注意判断规格化/非规格化，阶码全0时尾数隐含0，阶码全1时表示无穷大或NaN。本题阶码 $31$ 为正常规格化。

**命题规律**：
常见题型，覆盖三种基本编码的转换。变式可能包括浮点数与整数的比较、浮点数表示范围、精度等。复习时应熟练掌握补码、无符号、IEEE754的表示规则，以及它们之间的转换方法，特别是补码的快速计算和浮点数的规格化处理。

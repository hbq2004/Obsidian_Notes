# 选择题 第 14 题

![[_Attachments/题目识别/27_王道408-题目/CO-C06-61-M14_题目.png|题目]]

14. 下列信号中,可在系统总线中的控制总线上传输的有 ( )
I. 存储器和 I/O 设备的地址信息  
II. 存储器和 I/O 设备的时序信号、控制信号  
III. 存储器和 I/O 设备的响应信号  
IV. 存储器中存放的数据

A. I 和 IV  
B. II 和 III  
C. I、II 和 III  
D. II、III 和 IV

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C06-61-M14_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。理由：控制总线传输的是控制、时序和响应类信号；地址信息走地址总线，数据走数据总线，因此只有 II 和 III 正确。

**解题切入点**：本题本质是“按信号功能给总线分类”。拿到题先抓关键词：“地址”归地址总线，“数据”归数据总线，“控制/时序/响应/状态/请求/应答”归控制总线。类似快递分拣：地址是门牌号，数据是包裹，控制信号是“放行/签收”的指令与回执，三者走不同通道。

**推演**：系统总线是 CPU、主存、I/O 设备之间传送信息的公共通路，按传送内容可分为三类：
$$
\text{地址总线 AB：传送地址信息},\quad
\text{数据总线 DB：传送数据信息},\quad
\text{控制总线 CB：传送控制、时序、状态及响应信号}.
$$

逐项判断：

- I：存储器和 I/O 设备的地址信息。地址信息用于选择访问的存储单元或 I/O 端口，由 CPU 经地址总线发出，不属于控制总线。
- II：存储器和 I/O 设备的时序信号、控制信号。如时钟、读命令、写命令、存储器请求、I/O 请求等，都属于控制总线上的信号。
- III：存储器和 I/O 设备的响应信号。如设备就绪（READY）、中断响应、总线响应等，是从存储器或 I/O 设备返回给 CPU 的状态/响应信号，同样由控制总线传输。
- IV：存储器中存放的数据。数据必须在数据总线上传输，不能由控制总线完成。

因此能在控制总线上传输的只有 II 和 III，选 B。

**易错点**：
1. 误把地址信息当成控制信息：地址信息虽然由 CPU 产生并用于选择访问位置，但它走的是地址总线，不是控制总线。
2. 误以为响应信号只是状态信息而不属于控制总线：响应/状态信号（如 READY、中断应答）恰好是控制总线的常见组成部分。
3. 看到“存储器中存放的数据”受“数据”二字干扰，以为它也可能在控制总线上传：数据信息只能走数据总线，控制总线负责协调传输而非承载数据。

**命题规律**：本考点定位在“系统总线的组成与分类”。常见变式有：给出若干信号（时钟、复位、读/写命令、地址、数据、中断请求、总线请求、设备就绪等），要求选择属于控制总线/数据总线/地址总线的信号；或判断题总线“单向/双向”的特性。复习时可用三总线结构图把典型信号归类，并记住：地址线由 CPU 单向发出，数据线双向传输，控制线中每根信号方向固定、整体起控制与协调作用。

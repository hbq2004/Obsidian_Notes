# 选择题 第 14 题

![[_Attachments/题目识别/27_王道408-题目/CO-C06-61-M14_题目.png|题目]]

14. 下列信号中，可在系统总线中的控制总线上传输的有 (  )

$I$. 存储器和 $I/O$ 设备的地址信息  
$II$. 存储器和 $I/O$ 设备的时序信号、控制信号  
$III$. 存储器和 $I/O$ 设备的响应信号  
$IV$. 存储器中存放的数据

A. $I$ 和 $IV$  
B. $II$ 和 $III$  
C. $I$、 $II$ 和 $III$  
D. $II$、 $III$ 和 $IV$

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C06-61-M14_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B（$\mathrm{II}$ 和 $\mathrm{III}$）。控制总线传送的是控制命令、时序信号和各设备的响应/应答信号，地址信息由地址总线传送，数据由数据总线传送。

**解题切入点**：先不要逐个背信号名，而按系统总线的三大功能总线对信号分类。把地址总线想成“门牌/收件地址”，数据总线想成“货物运输通道”，控制总线则是“快递员的命令（签收/派送）和收件人的回执”。题目列举四组信号，只要判断它们属于“地址/数据/控制”中的哪一类即可定位到考点。

**推演**：
系统总线分为：

- 地址总线（$\mathrm{AB}$）：  
  传送 CPU 要访问的存储单元或 I/O 端口地址，方向一般由 CPU 发出，是单向的。

- 数据总线（$\mathrm{DB}$）：  
  传送 CPU 与存储器、I/O 设备之间交换的数据/指令码等，是双向的。

- 控制总线（$\mathrm{CB}$）：  
  传送控制/时序/响应信号。例如：  
  - 控制信号：存储器读、存储器写、I/O 读、I/O 写、中断请求、DMA 请求/允许、总线请求/允许、复位等；  
  - 时序信号：时钟、节拍/周期信号；  
  - 响应信号：从设备对操作的应答，如“已准备好”“操作完成”等。

逐项判断：

- $\mathrm{I}$：地址信息属于地址总线，不属于控制总线。  
- $\mathrm{II}$：时序信号、控制信号属于控制总线。  
- $\mathrm{III}$：响应信号属于控制总线。  
- $\mathrm{IV}$：存储器中存放的数据属于数据总线。  

所以可在控制总线上传输的是 $\mathrm{II}$ 和 $\mathrm{III}$，选 B。

**易错点**：

1. 把“响应信号”误归为数据总线或状态信息。响应信号是从设备对主设备控制命令的应答，属于总线握手信号，应在控制总线中传输。  
2. 把“地址信息”误选入控制总线。地址信息有专门地址总线，不占控制总线。  
3. 把“存储器中存放的数据”误选入控制总线。数据线上既可以传数据也可以传指令，但不能归为控制信号。  
4. 记混方向：地址总线单向、数据总线双向、控制总线中不同信号线方向不同；本题不直接考方向，但判断信号归属时可帮助排除。

**命题规律**：

考点是“系统总线的分类与各总线信号归属”，属于计算机组成原理总线部分的低频但基础选择题。常见变式包括：给出“中断请求信号、存储器读命令、时钟信号、DMA 响应信号、地址译码信号、设备就绪信号”等，要求判断其属于哪类总线，或判断某条总线的方向。复习时应背熟总线分类图，并记牢结论：控制总线是“命令/时序/响应”信号线的集合，是系统总线中最灵活、最能体现控制功能的部分。

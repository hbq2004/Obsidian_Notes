# 选择题 第 6 题

![[_Attachments/题目识别/27_王道408-题目/CO-C06-61-M06_题目.png|题目]]

6. 系统总线中地址线的功能是（ ）.
(A) 选择主存单元地址
(B) 选择进行信息传输的设备
(C) 选择外存地址
(D) 指定主存和 I/O 设备接口电路的地址

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C06-61-M06_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。理由：系统总线中的地址线用于传送地址信息，可指定主存单元地址，也用于指定 I/O 设备接口电路（端口）地址，因此 D 最完整准确。

**解题切入点**：拿到题目先抓住“地址线”这一关键字，确认它传送的是“地址信息”，而不是数据或控制信息。然后思考地址线的寻址对象有哪些：主存单元、I/O 端口。可以把地址线想象成快递单上的“地址栏”，它必须能同时标明“内存单元”和“外部设备接口”两类位置，否则数据无法准确送达。外存地址一般不直接通过系统总线地址线给出，而是由外存设备控制器负责解释。

**推演**：

1. 系统总线分为数据总线、地址总线和控制总线。地址线的核心功能是传送地址信息，用来选择总线上的目标设备或存储单元。
2. 在计算机系统中，CPU 既需要访问主存，也需要访问 I/O 设备接口电路中的寄存器/端口。这些 I/O 端口和主存单元一样，都有唯一地址。
3. 在统一编址方式下，主存单元和 I/O 端口统一编址，地址线给出的地址既可能指向主存单元，也可能指向 I/O 端口；在独立编址方式下，地址线也会给出主存地址或 I/O 端口地址，由控制线区分是访问主存还是访问 I/O。因此，地址线必须能够指定“主存单元”和“I/O 设备接口电路”两类地址。
4. 若地址线根数为 $n$，则最多可寻址 $2^n$ 个地址单元，包括主存单元和 I/O 端口。这也说明地址线是整个系统地址空间的“定位工具”，而不只是主存专用。
5. 逐项分析：  
   - A 只说“选择主存单元地址”，遗漏了 I/O 端口地址，不完整。  
   - B 说“选择进行信息传输的设备”，过于笼统，且设备的选择本质上是地址译码的结果，不是地址线直接选择设备实体。  
   - C 说“选择外存地址”，但外存（如磁盘）的物理地址通常由磁盘控制器管理，CPU 通过系统总线访问的是外存接口电路，而不是直接把外存物理地址放到地址线上。  
   - D 准确概括了地址线的作用：指定主存单元地址和 I/O 设备接口电路地址。

综上，正确答案为 D。

**易错点**：

- 容易误选 A，因为教材常强调“地址线用于选择存储单元”，但忽略了 I/O 端口也需要地址线寻址。  
- 容易误选 C，误以为外存地址也需要系统总线地址线直接传送；实际上外存是 I/O 设备，其地址由设备控制器解释，系统总线访问的是控制器端口。  
- 容易误选 B，因为“选择设备”听起来合理，但地址线并不直接“选择设备”，而是通过地址译码选择设备接口中的寄存器或端口，最能体现“地址”本质的是 D。  
- 规避方法：记住地址线的功能是“寻址主存单元和 I/O 端口”，做题时优先选覆盖“主存 + I/O”两个对象的选项。

**命题规律**：这是总线基础部分的常考概念题。408 中常结合以下角度命题：  
- 给出地址线根数，求最大可寻址空间（例如 $n$ 根地址线最大寻址 $2^n$ 个单元）；  
- 考查统一编址与独立编址的区别；  
- 考查地址线的方向性：地址线一般是单向的，由 CPU 发出；数据线是双向的；  
- 结合总线带宽、时钟频率等计算总线性能。  

复习时应将总线知识与存储器、I/O 接口章节结合起来，重点理解“地址线用于寻址主存和 I/O 端口”这一核心，并记住地址线、数据线、控制线各自的功能区别。

# 选择题 第 18 题

![[_Attachments/题目识别/27_王道408-题目/CO-C06-61-M18_题目.png|题目]]

18.【2011统考真题】在系统总线的数据线上,不可能传输的是( )
(A) 指令
(B) 操作数
(C) 握手(应答)信号
(D) 中断类型号

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C06-61-M18_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。理由：握手（应答）信号属于控制总线上的控制信号，不在数据线上传输；指令、操作数和中断类型号都是可经数据线传输的二进制信息。

**解题切入点**：看到“数据线上”立即定位考点为“系统总线的组成与功能”。数据线像一条“货运通道”，凡是需要在 CPU、内存、I/O 之间传送的编码信息——指令、操作数、中断类型号——都可能通过它；握手/应答信号是协调传输的“红绿灯”，属于控制总线。因此首先要区分传“内容”与发“控制信号”。

**推演**：系统总线按功能分为地址总线、数据总线、控制总线。

- 地址总线 $A_0 \sim A_{n-1}$：传输存储器地址或 I/O 端口地址，通常由 CPU 发出，是单向的；其位数决定寻址范围。
- 数据总线 $D_0 \sim D_{n-1}$：传输 CPU 与存储器或 I/O 接口之间的信息，是双向的；其位数决定一次能同时传输的二进制信息位数。
- 控制总线：传输读/写命令、中断请求/响应、时钟、复位以及握手（应答）等控制信号。

分别看四个选项：

1. 指令：取指阶段，CPU 把程序计数器 PC 送到地址总线，存储器按地址读出指令，指令代码经数据总线送入 CPU 的指令寄存器，所以指令可经数据线传输。
2. 操作数：执行阶段访存或 I/O 时，读出的操作数经数据总线送入 CPU，写操作数也经数据总线送到目的地址，所以操作数可经数据线传输。
3. 握手（应答）信号：如 READY、ACK、WAIT 等，表示设备“准备好”“已收到”或“可以传输”，用于协调总线操作，属于控制总线上的控制信号，不通过数据线传输。
4. 中断类型号：中断响应时，CPU 发出中断响应信号后，中断控制器或外设接口把中断类型号（中断向量号）放到数据总线上，CPU 读取后用于形成中断向量表地址，所以中断类型号可经数据线传输。

因此，“不可能传输”的是握手（应答）信号，选 C。

**易错点**：
- 误选 A：以为“指令”不是“数据”。但总线上的“数据”是广义的二进制信息代码，指令在取指阶段也通过数据总线进入 CPU。
- 误选 D：把“中断”都看作控制过程，但中断类型号是设备送给 CPU 的具体编号，本质上是一个数据；中断请求/响应信号才在控制总线上。
- 握手（应答）信号虽然也是电平/脉冲，但它在总线分类上属于控制总线，不能按“电平就是数据”判断。

**命题规律**：本题直接考查系统总线的分类，属于总线部分的高频考点。常见变式有：地址总线不能传输什么、数据总线宽度与吞吐率的关系、控制总线包括哪些信号、结合取指/中断/DMA 判断信号所在总线。复习时建议将地址总线、数据总线、控制总线的“方向、作用、典型信息/信号”列表对比记忆；看到“握手/应答”优先联想到控制总线。

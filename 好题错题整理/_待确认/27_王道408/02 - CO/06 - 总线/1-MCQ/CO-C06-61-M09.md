# 选择题 第 9 题

9.主存通过(   )来识别信息是地址还是数据.

(A) 总线的类型
(B) 存储器数据寄存器 ($MDR$)
(C) 存储器地址寄存器 ($MAR$)
(D) 控制单元 ($CU$)

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C06-61-M09_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A。主存通过总线类型（地址总线/数据总线）来区分接收到的信息是地址还是数据，因为地址信息总是出现在地址总线上，数据信息总是出现在数据总线上。

**解题切入点**：  
先想清 CPU 与主存之间有几类总线，分别传输什么信息。这就像快递分拣：地址总线是“门牌号通道”，数据总线是“货物通道”，主存只看信息从哪个通道来，就能判断它是“门牌号”还是“货物”。不要一看到“识别”就联想到控制器，要回到总线的物理分工。

**推演**：  
CPU 通过系统总线与主存相连，系统总线按功能分为三类：

- 地址总线（Address Bus, $AB$）：传输 CPU 发出的地址信息，用于选择主存单元或 I/O 端口。
- 数据总线（Data Bus, $DB$）：传输数据信息，既可以是 CPU 写入主存的数据，也可以是主存读出的数据。
- 控制总线（Control Bus, $CB$）：传输控制信号，如读写命令、时序信号、中断请求等。

主存芯片有专门的地址引脚和数据引脚，分别连接到地址总线和数据总线。当主存收到地址总线上的信号时，它根据地址信号选中对应的存储单元；当主存收到数据总线上的信号时，它根据读写控制信号完成数据的写入或读出。因此，主存并不需要“分析”某个信号本身是地址还是数据，它天然通过信号所出现的总线类型来区分：

- 出现在地址总线上的信息一定是地址；
- 出现在数据总线上的信息一定是数据。

对应选项逐一判断：

- (A) 总线的类型：正确。地址总线和数据总线是不同类型的总线，主存据此区分地址和数据。
- (B) 存储器数据寄存器 $MDR$：$MDR$ 是 CPU 内部与数据总线相连的寄存器，用于暂存数据，它不是主存区分地址/数据的依据。
- (C) 存储器地址寄存器 $MAR$：$MAR$ 是 CPU 内部与地址总线相连的寄存器，用于暂存地址，同样不是主存区分地址/数据的依据。
- (D) 控制单元 $CU$：$CU$ 产生控制信号，但这些控制信号通过控制总线传输，用于指示读/写等操作，不负责区分“是地址还是数据”。

因此，主存通过总线的类型来识别信息是地址还是数据，答案为 A。

**易错点**：  
1. **误选 D（控制单元）**：容易把“识别”理解为“控制”。实际上，主存区分地址和数据靠的是物理连接的总线类型，而不是靠 $CU$ 的判断。$CU$ 只发出读写控制信号，不参与在地址和数据之间的语义识别。  
2. **误选 B/C（$MDR$/$MAR$）**：$MAR$ 和 $MDR$ 是 CPU 内部的寄存器，它们分别与地址总线、数据总线相连，但它们是“暂存部件”，不是主存用来识别信息的依据。如果问“CPU 中哪个寄存器保存地址/数据”，才选 $MAR$/$MDR$。  
3. **混淆“地址总线和数据总线”与“控制总线”**：控制总线传的是控制信号，不对应具体的地址或数据信息，不能用来区分地址和数据。

**命题规律**：  
本题属于“系统总线与存储器接口”的基础概念题，考查总线分类及其功能。常见变式有：  
- CPU 对主存进行读操作时，地址由哪个寄存器提供、数据经哪个寄存器传输？  
- 主存与 CPU 连接时，地址线根数决定什么？数据线根数决定什么？  
- 给定地址线数和数据线数，求主存容量或片选方式等。  

复习建议：把总线结构、$MAR$/$MDR$、$CU$、读写控制信号之间的配合关系理清，记住“地址走地址总线，数据走数据总线，控制信号走控制总线”这一基本分工，同时注意区分 CPU 内部寄存器和外部总线的职责。这类题通常送分，关键是不要混淆概念。

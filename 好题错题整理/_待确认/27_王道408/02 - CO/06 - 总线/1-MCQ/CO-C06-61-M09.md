# 选择题 第 9 题

![[_Attachments/题目识别/27_王道408-题目/CO-C06-61-M09_题目.png|题目]]

9. 主存通过（ ）来识别信息是地址还是数据.

A. 总线的类型
B. 存储器数据寄存器 ($MDR$)
C. 存储器地址寄存器 ($MAR$)
D. 控制单元 ($CU$)

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C06-61-M09_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A。主存通过总线的类型来区分传过来的是地址还是数据：地址走地址总线，数据走数据总线。

**解题切入点**：看到“识别信息是地址还是数据”，立刻定位到总线的分类。总线按传输信息不同分为三类：地址总线、数据总线、控制总线。这就像快递分拣时，通过“不同快递通道”来区分是“快递单号信息”还是“包裹内容”，不需要打开包裹再判断。

**推演**：

主存与 CPU 之间通过三类总线连接：

- 地址总线（AB）：由 CPU 输出到主存，用来传送 CPU 要访问的存储单元地址，其内容来自存储器地址寄存器 $MAR$。
- 数据总线（DB）：双向传输，用来在 CPU 与主存之间传送数据，数据先经过存储器数据寄存器 $MDR$。
- 控制总线（CB）：由 CPU 发出控制信号，如读信号、写信号，用来控制主存进行读操作或写操作。

在主存内部，地址引脚与数据引脚是分开的。主存看到地址引脚上有信号，就把该信号作为地址进行译码，选中相应存储单元；看到数据引脚上有信号，就把该信号作为数据进行读写。也就是说，主存并不需要“分析”信号内容本身，而是根据信号出现在哪一类总线上来判断它是地址还是数据。

$MAR$、$MDR$ 是 CPU 内部的寄存器，分别暂存地址和数据；$CU$ 产生控制信号，但控制信号主要用于指定读/写操作，而不是用来区分地址与数据。因此正确选项是 A。

**易错点**：

- 误选 $MAR$ 或 $MDR$：这两个寄存器是 CPU 与总线之间的缓冲部件，不是主存判断地址/数据的依据。
- 误选 $CU$：控制单元负责产生控制信号，如读/写命令，但不承担“识别地址/数据”的功能。
- 要牢记：地址与数据使用不同的物理总线，所以主存通过“总线类型”即可区分二者。

**命题规律**：

- 考点：总线分类及其功能，主存与 CPU 的连接方式。
- 常见变式：给出总线上的信号流，要求判断该信号是地址、数据还是控制信号；或问 $MAR$、$MDR$ 的作用；或考控制总线的作用。
- 复习建议：把地址总线、数据总线、控制总线传输的内容和方向记清楚，并联系 $MAR$、$MDR$ 在读写过程中的位置。$CPU \rightarrow MAR \rightarrow AB \rightarrow 主存$，$MDR \leftrightarrow DB \leftrightarrow 主存$，$CU \rightarrow CB \rightarrow 主存$，这三条链路是解题的关键。

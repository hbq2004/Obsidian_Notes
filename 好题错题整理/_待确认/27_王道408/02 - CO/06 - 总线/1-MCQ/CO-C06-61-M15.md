# 选择题 第 15 题

![[_Attachments/题目识别/27_王道408-题目/CO-C06-61-M15_题目.png|题目]]

15. 总线中，有些信息是单向传输的，有些信息是双向传输的，下列说法中正确的是 ( )

(A) 数据信息是单向传输的，由内存或外设传送至 $CPU$
(B) 地址信息是单向传输的，由 $CPU$ 发送至内存或外设
(C) 控制信息是双向传输的，由 $CPU$ 发送至内存或外设，也可反向
(D) 状态信息是双向传输的，由 $CPU$ 发送至内存或外设，也可反向

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C06-61-M15_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。地址信息用于选择内存单元或外设端口，方向固定为总线主设备（通常是 CPU）发送至内存或外设，是单向传输；数据信息双向，控制/状态信息各有固定方向，不能统称双向。

**解题切入点**：拿到题先判断各类信息在总线周期中的“流向”：谁发出、谁接收。可以把一次总线操作类比为“寄信”：地址是信封上的收件人地址，由寄件人单向写出；数据是信纸，可寄出也可寄回；控制命令是“发信指令”，由主设备发出；状态信息是“回执”，由从设备返回。抓住“谁发起、谁响应”即可定位考点。

**推演**：

- **数据信息**：CPU 读内存/外设时，数据从内存或外设流向 CPU；CPU 写内存/外设时，数据从 CPU 流向内存或外设。因此数据信息是双向传输的，不是单向的。A 错。

- **地址信息**：CPU 要访问某个内存单元或外设端口，必须先把地址放在地址线上；地址信息由 CPU 或总线主设备送往内存/外设，从设备不会把地址“传回” CPU。因此地址信息是单向传输的。B 对。

- **控制信息**：读命令、写命令等控制信号确实由 CPU 发往内存或外设；但中断请求、准备好等信号又是由外设发往 CPU 的。这些是不同方向、方向固定的若干条信号线，不能因此说“控制信息”是同一条线上的双向传输。C 错。

- **状态信息**：状态信息通常表示外设/内存当前的状态，如“就绪”“忙”等，一般由外设或内存送往 CPU，而不是由 CPU 发往外设，也不是双向传输。D 错。

**易错点**：

1. 误以为“控制信息有时从 CPU 发出、有时从外设发出，所以是双向的”。实际上，不同控制信号线有各自的固定方向，不等于同一根控制线双向传输。
2. 用 DMA 场景质疑 B：DMA 时地址可由 DMA 控制器发出，但方向依然是总线主设备到从设备，地址线的单向性不变。
3. 将“数据信息双向”误记为“数据由外设到 CPU”，忽略写操作时数据由 CPU 发出。
4. 混淆“控制信息”与“状态信息”：控制信息主要是 CPU 对外设/内存的命令，状态信息主要是外设/内存对 CPU 的反馈。

**命题规律**：考点是总线按传输信息分类时各信号线的方向，即“数据双向、地址单向，控制/状态按具体信号定方向”。常见变式有：结合 DMA 判断地址线来源；给出具体的控制信号如读命令、写命令、中断请求、准备好信号，判断方向；或结合三态门考查总线隔离。复习时应把一次完整总线读写周期的流程梳理清楚：先发地址，再发命令，最后传数据/返回状态，方向自然不易混淆。

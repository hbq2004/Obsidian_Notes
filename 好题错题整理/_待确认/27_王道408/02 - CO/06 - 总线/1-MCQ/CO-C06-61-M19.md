# 选择题 第 19 题

![[_Attachments/题目识别/27_王道408-题目/CO-C06-61-M19_题目.png|题目]]

19.【2012统考真题】 * 下列关于 $USB$ 总线特性的描述中,错误的是 (   )

(A) 可实现外设的即插即用和热拔插
(B) 可通过级联方式连接多台外设
(C) 是一种通信总线,连接不同外设
(D) 同时可传输 2 位数据,数据传输率高

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C06-61-M19_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。USB 是串行总线，采用差分信号线逐位传输数据，不能“同时传输 2 位数据”；其余三项均符合 USB 特性。

**解题切入点**：题目问“错误的是”，四个选项分别对应 USB 的典型特性。看到 D 中的“同时可传输 2 位数据”时，应立即联想到 USB 的全称 Universal Serial Bus，关键词是“Serial（串行）”。串行意味着按位传输，不可能同时传多位；这就像单车道公路一次只能过一辆车，D 却说可以两辆车并行，显然是陷阱。因此先锁定 D。

**推演**：逐一分析四个选项。

- (A) USB 支持即插即用和热拔插。USB 设备在接入时由主机通过枚举自动识别并配置，无需关机断电，故正确。
- (B) USB 可以通过 USB Hub 级联方式连接多台外设。USB 拓扑中允许通过集线器扩展，最多可连接 $127$ 台设备，故正确。
- (C) USB 是一种通信总线，连接不同外设。它属于外部设备总线，可以连接键盘、鼠标、U 盘、打印机等不同外设，故正确。
- (D) USB 物理层使用 D$+$、D$-$ 两根线构成差分对。差分传输是指两根线上的电压差共同表示一个逻辑位，两根线并不是两条独立的数据位线；因此 USB 一次只能传输 $1$ 位串行数据，不能“同时传输 2 位数据”。USB 数据传输率高是因为采用了高频信号和高效编码，而不是因为并行多位传输。故 D 错误。

综上，错误的是 D。

**易错点**：

- 误以为 USB 有 D$+$ 和 D$-$ 两根数据线，所以能同时传输 2 位数据。实际上 D$+$ 和 D$-$ 是差分信号线，共同表示一位，不是两个独立数据通道。
- 把“数据传输率高”等同于“并行传输位数多”。串行总线同样可以达到很高速率，高速率依赖频率和编码，而非数据位宽。
- 混淆系统总线与通信总线。USB 是外设通信总线，连接主机和外设，不是 CPU、内存、I/O 接口之间的系统总线。
- 忽视 USB 名称中的 “Serial”，将其误判为并行总线。

**命题规律**：本题考查总线分类与常用总线特性，属于计算机组成原理“总线与 I/O 系统”部分的常见考点。常见变式包括：对比 USB 与 IEEE 1394、SATA、PCIe 等总线，判断串行/并行、同步/异步、是否支持热插拔、是否支持级联等。复习时建议把常用总线的特性整理成对比表，重点关注：串行还是并行、是否支持即插即用、是否支持热插拔、最大设备数、典型速率等，并注意“差分信号”与“并行多位传输”的区别。

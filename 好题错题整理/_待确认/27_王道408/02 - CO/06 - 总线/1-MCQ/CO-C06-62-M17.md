# 选择题 第 17 题

![[_Attachments/题目识别/27_王道408-题目/CO-C06-62-M17_题目.png|题目]]

17.【2017统考真题】下列关于多总线结构的叙述中,错误的是（  ）.
(A) 靠近 $CPU$ 的总线速度较快
(B) 存储器总线可支持突发传送方式
(C) 总线之间须通过桥接器相连
(D) $PCI-Express \times 16$ 采用并行传输方式

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C06-62-M17_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。PCI-Express ×16 采用的不是并行传输方式，而是高速串行传输方式；其余三项关于多总线结构的叙述均正确。

**解题切入点**：拿到题目先逐个选项定位到“总线分类”与“总线互连”考点。可类比竞赛做题时的“概念排除法”：先划掉绝对正确/明显错误的选项，再看剩余选项是否有模糊点。本题核心在于分清“并行总线”与“串行总线”的代表，PCIe 是串行点对点互连，不是老式并行 PCI。

**推演**：

- 选项 A：“靠近 CPU 的总线速度较快”。在多总线结构中，速度较高的总线通常更靠近 CPU，例如 CPU 总线（前端总线/系统总线）与存储器总线速度高于 I/O 总线。这样可以减少高速设备与 CPU 之间的速度瓶颈，因此 A 正确。
- 选项 B：“存储器总线可支持突发传送方式”。突发传送（猝发传送）允许一次总线事务传输多个连续数据块，只需给出起始地址，后续地址自动递增。存储器总线在读取主存连续数据时广泛采用这种模式，以提高带宽，因此 B 正确。
- 选项 C：“总线之间须通过桥接器相连”。多总线结构中，不同速度、不同协议的总线不能直接相连，需要通过桥接器（Bridge）进行协议转换、速度匹配和信号隔离，例如 PCI 总线与 PCIe 总线之间通过 PCIe 桥接器相连，因此 C 正确。
- 选项 D：“PCI-Express ×16 采用并行传输方式”。PCI-Express（PCIe）采用串行传输方式，每条 lane 是一对差分信号线，数据以串行比特流传输；×16 表示拥有 16 条 lane，提高的是并行通道数，而不是并行传输方式。因此 D 错误。

**易错点**：

1. 将“多 lane”误认为“并行传输”。PCIe 的 ×16 是 16 条串行链路并行工作，但每条链路上的数据是串行传输的，总线整体属于串行总线。
2. 误以为“靠近 CPU 的总线速度不一定更快”。在多总线结构中，设计原则正是让高速总线靠近 CPU，否则 CPU 与高速缓存/主存之间的数据交换会成为瓶颈。
3. 混淆“桥接器”与“总线仲裁器”。桥接器用于连接不同总线，完成协议转换；总线仲裁器用于解决同一总线上多个主设备的总线使用权竞争，二者作用不同。
4. 对“突发传送”理解不深。突发传送的前提是一段连续地址，而不是随机访问；存储器总线支持突发传送不等于对所有访问都能突发。

**命题规律**：本题属于计算机组成原理中“总线系统”的基础概念题，考点是总线分类、总线结构及总线互连方式。常见变式包括：区分并行总线与串行总线（PCI、PCIe、USB、SATA 等）；考查桥接器的作用；考查猝发传送的特点；考查多总线结构中各级总线的速度关系。复习时应掌握典型总线的特点：传统 PCI 是并行共享总线，PCIe 是串行点对点总线，USB 也是串行总线，并理解“靠近 CPU 的总线速度较快”这一分层设计思想。

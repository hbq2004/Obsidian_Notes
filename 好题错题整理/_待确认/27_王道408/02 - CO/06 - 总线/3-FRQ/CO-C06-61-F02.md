# 综合题 第 2 题

![[_Attachments/题目识别/27_王道408-题目/CO-C06-61-F02_题目.png|题目]]

2. 某总线支持二级 $Cache$ 块传输方式,若每块 $6$ 个字,每个字长 $4$ 字节,时钟频率为 $100\mathrm{MHz}$。

(1) 读操作时,第一个时钟周期接收地址,第二、三个为延时周期,另用 $4$ 个周期传送一个块。读操作的总线传输速率为多少?

(2) 写操作时,第一个时钟周期接收地址,第二个为延时周期,另用 $4$ 个周期传送一个块,写操作的总线传输速率是多少?

(3) 设在全部的传输中,$70\%$ 的时间用于读,$30\%$ 的时间用于写,该总线在本次传输中的平均传输速率是多少?

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C06-61-F02_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：  
(1) 读操作总线传输速率为 $\frac{24}{7}\times10^8\ \mathrm{B/s}\approx342.86\ \mathrm{MB/s}$；  
(2) 写操作总线传输速率为 $4\times10^8\ \mathrm{B/s}=400\ \mathrm{MB/s}$；  
(3) 平均传输速率为 $3.6\times10^8\ \mathrm{B/s}=360\ \mathrm{MB/s}$。

**解题切入点**：  
总线传输速率等于每次传输的数据量除以传输所用的总时间。本题的关键是确定读、写操作传输一个块所需的时钟周期数，结合时钟频率得到每个周期的时间，再计算每秒传输的字节数。读操作有 2 个延时周期，写操作有 1 个延时周期，加上地址周期和传送周期，即可得到总周期数。

**推演**：  
每块包含 $6$ 个字，每个字 $4$ 字节，故块大小为 $6\times4=24$ 字节。  
时钟频率 $f=100\ \mathrm{MHz}$，所以时钟周期 $T=\frac{1}{f}=10^{-8}\ \mathrm{s}=10\ \mathrm{ns}$。

(1) 读操作：  
   - 接收地址：1 个周期；  
   - 延时：2 个周期；  
   - 传送块：4 个周期。  
   共需 $1+2+4=7$ 个时钟周期，总时间 $7\times10^{-8}\ \mathrm{s}$。  
   传输速率 $R_{\text{读}} = \dfrac{24\ \mathrm{B}}{7\times10^{-8}\ \mathrm{s}} = \dfrac{24}{7}\times10^{8}\ \mathrm{B/s} \approx 3.4286\times10^{8}\ \mathrm{B/s} = 342.86\ \mathrm{MB/s}$。

(2) 写操作：  
   - 接收地址：1 个周期；  
   - 延时：1 个周期；  
   - 传送块：4 个周期。  
   共需 $1+1+4=6$ 个时钟周期，总时间 $6\times10^{-8}\ \mathrm{s}$。  
   传输速率 $R_{\text{写}} = \dfrac{24\ \mathrm{B}}{6\times10^{-8}\ \mathrm{s}} = 4\times10^{8}\ \mathrm{B/s} = 400\ \mathrm{MB/s}$。

(3) 平均传输速率：  
   题目指明 $70\%$ 的时间用于读，$30\%$ 的时间用于写。设总时间为 $T$，则读时间 $0.7T$，写时间 $0.3T$。  
   读时间内传输字节数 $=0.7T \times R_{\text{读}}$，写时间内传输字节数 $=0.3T \times R_{\text{写}}$。  
   总字节数 $=0.7T R_{\text{读}} + 0.3T R_{\text{写}}$，平均速率 $R_{\text{avg}} = \dfrac{0.7T R_{\text{读}} + 0.3T R_{\text{写}}}{T} = 0.7R_{\text{读}} + 0.3R_{\text{写}}$。  
   代入数值：  
   $$R_{\text{avg}} = 0.7\times\frac{24}{7}\times10^{8} + 0.3\times4\times10^{8} = 0.1\times24\times10^{8} + 1.2\times10^{8} = 2.4\times10^{8} + 1.2\times10^{8} = 3.6\times10^{8}\ \mathrm{B/s} = 360\ \mathrm{MB/s}.$$

**易错点**：  
1. 误将读操作的延时周期数当作 1 个，或忽略地址周期，导致周期数错误。  
2. 混淆时间比例与操作比例：若误认为“70%的操作是读”，则平均速率计算会不同，但本题明确是“时间用于读”，所以直接加权平均。  
3. 单位换算疏忽：$1\ \mathrm{MHz}=10^6\ \mathrm{Hz}$，时钟周期 $10^{-6}\ \mathrm{s}$ 是错误，应为 $10^{-8}\ \mathrm{s}$。  
4. 计算平均速率时错误使用调和平均（如 $1/(0.7/R_{\text{读}}+0.3/R_{\text{写}})$），那适用于操作比例固定且每次操作时间不同，但本题是时间比例，故用算术平均。

**命题规律**：  
- 考点：总线传输速率的计算，与块传输、时钟周期、延时周期结合。  
- 常见变式：改变块大小、字长、时钟频率、延时周期数；或给出时间比例求平均；或从操作比例求平均（需用调和平均）。  
- 复习建议：掌握总线传输速率的基本概念 $R = \frac{\text{数据量}}{\text{时间}}$，明确各操作阶段消耗的时钟周期数，注意区分时间比例与操作比例，熟练进行单位换算。

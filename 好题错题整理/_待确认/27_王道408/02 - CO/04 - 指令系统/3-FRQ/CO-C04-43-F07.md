7.【2025统考真题】现有 C 语言程序 P 的部分代码如下所示。假定运行程序 P 的计算机 M 字长为 32 位，按字节编址。假定 P 的部分机器级代码如图 (a) 所示，其中，R0R4 为通用寄存器，SEXT 表示按符号扩展；M 中补码除法器逻辑结构如图 (b) 所示。

```c
int x,d[2048],i;
...
for(i=0;i<2048;i++)
  d[i]=d[i]/x;
...
```

```asm
...
//x 在 R2 中，i 在 R4 中
//数组 d 的首地址在 R3 中
mov R1, (R3+R4*4)  // R1←d[i]
sccv R1            // (R0,R1)←SEXT(R1)
idiv R1, R2        // R1←{R0,R1}/R2
...
```

【图(b)：补码除法器逻辑结构图，包含除数寄存器 Y、32 位 ALU、余数寄存器 R、余数/商寄存器 Q、控制逻辑，另有 ALUop、左移、写使能等信号】

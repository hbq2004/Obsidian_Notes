# 综合题 第 7 题

![[_Attachments/题目识别/27_王道408-题目/CO-C04-43-F07_题目.png|题目]]

7.【2025统考真题】现有C语言程序P的部分代码如下所示。假定运行程序P的计算机M字长为32位，按字节编址。假定P的部分机器级代码如图(a)所示，其中，R0R4为通用寄存器，SEXT表示按符号扩展；M中补码除法器逻辑结构如图(b)所示。
```c
int x,d[2048],i;
...
for(i=0;i<2048;i++)
    d[i]=d[i]/x;
...
```
图(a)中的机器级代码如下：
//x在R2中，i在R4中
//数组d的首地址在R3中
mov R1, (R3+R4*4)   // R1←d[i]
scov R1             // {R0, R1}←SEXT(R1)
idiv R1, R2         // R1←{R0, R1}/R2
...
图(b)为补码除法器逻辑结构，其文字标注内容包括：除数寄存器Y（32位）、32位ALU、ALUop控制信号、余数寄存器R（32位）、余数/商寄存器Q（32位）、左移信号、写使能信号、控制逻辑、时钟。【图：补码除法器逻辑结构示意图】
(1) 若执行图(a)中idiv指令的除运算时，d[i] = 0x87654321，x = 0xff，则补码除法器中寄存器R、Q和Y的初始内容分别是什么（用十六进制表示）？图(b)中哪个部件包含计数器？在补码除法器执行过程中，由ALUop所控制的ALU运算有哪几种？
(2) 假设idiv指令执行过程中会检测并触发除法异常，则执行idiv指令时，哪些情况下会发生除法异常（要求给出此时d[i]和x的十六进制机器数）？发生除法异常时，在异常响应过程中，CPU需要完成哪些操作？

## DeepSeek V4 Flash Max 解析

**答案**：  
(1) R=0xFFFFFFFF，Q=0x87654321，Y=0x000000FF；包含计数器的部件是控制逻辑；ALUop控制的ALU运算有加法运算和减法运算。  
(2) 除法异常情况：①除数为0（x=0x00000000，d[i]任意，如0x00000000）；②商溢出（d[i]=0x80000000，x=0xFFFFFFFF）。异常响应时CPU需完成：保存断点（PC）到异常返回地址寄存器，保存程序状态字（PSW），设置异常原因，跳转到异常处理程序入口。

**解题切入点**：  
首先从指令序列理解idiv的行为：被除数是经过SEXT的64位数值，除数是32位整数。补码除法器的初始状态由被除数的高32位、低32位和除数决定，据此写出R、Q、Y。补码除法器通常用计数器控制迭代次数，该计数器位于控制逻辑内；ALUop只控制加/减两种运算。除法异常聚焦于除数为0和商溢出（最小负数除以-1），异常响应是CPU硬件自动完成的常规操作（保存断点、现场，设置原因，跳转处理）。

**推演**：  
(1) 由程序片段知，idiv执行前，scov R1将R1（d[i]）符号扩展为64位存入{R0,R1}，故被除数为SEXT(d[i])，除数为R2（x）。d[i]=0x87654321，最高位为1，符号扩展后高32位全1，即R0=0xFFFFFFFF，R1=0x87654321；x=0xff，即0x000000FF。补码除法器初始时，余数寄存器R存放被除数高32位，商寄存器Q存放被除数低32位，除数寄存器Y存放除数，所以R=0xFFFFFFFF，Q=0x87654321，Y=0x000000FF。  
在补码除法器中，通常使用一个计数器记录迭代次数（32次），该计数器位于控制逻辑部件内。ALUop信号控制ALU执行加法或减法，具体取决于当前余数和除数的符号，以进行补码除法的不恢复余数算法，故ALU运算有加法和减法两种。

(2) idiv指令可能触发除法异常的情况：  
- 除数为0：x=0x00000000，此时任何被除数都会导致异常，d[i]可取任意值（如0x00000000）。  
- 商溢出：当被除数为32位有符号数的最小负数（-2^31，即0x80000000）且除数为-1（0xFFFFFFFF）时，商为2^31，超出32位有符号整数的表示范围（-2^31~2^31-1），故发生溢出异常，此时d[i]=0x80000000，x=0xFFFFFFFF。  
发生除法异常时，CPU硬件自动完成以下操作：  
① 保存断点：将当前指令的PC值（异常返回地址）存入异常返回地址寄存器（如EPC）。  
② 保存程序状态：将程序状态字（PSW）保存到特定寄存器或栈中。  
③ 设置异常原因：将异常类型编码写入异常原因寄存器（如Cause寄存器）。  
④ 跳转处理：将PC更新为异常处理程序的入口地址（通常由硬件指定或通过异常向量表获得），开始执行异常处理程序。

**易错点**：  
- 初始R、Q的值容易混淆高32位和低32位的放置位置，误将R当成低32位。注意补码除法器中通常R存放余数（初始为被除数高32位），Q存放商（初始为被除数低32位）。  
- 忽略符号扩展对补码除法器初始化的影响，若d[i]为正数，则R0=0，但本题为负数，故R0全1。  
- 在除法异常中，只考虑除数为0，忽略商溢出情况；或商溢出时误认为被除数为0x7FFFFFFF且除数为-1等。  
- 异常响应操作中，可能遗漏保存现场或设置异常原因等步骤，需答全要点。

**命题规律**：  
本题结合C语言程序、机器级代码和补码除法器硬件结构，考查对补码除法运算及异常处理的理解。常见变式包括：给出不同被除数和除数，要求写出除法器初值；或结合不同除法算法（如恢复余数法）考查ALU操作；或考查除法异常处理中硬件与软件的职责划分。复习时需熟练掌握补码除法的运算过程、除法器结构（特别是寄存器分配）、除法异常的检测条件，以及异常响应流程。建议结合教材中补码除法器具体实现来理解。

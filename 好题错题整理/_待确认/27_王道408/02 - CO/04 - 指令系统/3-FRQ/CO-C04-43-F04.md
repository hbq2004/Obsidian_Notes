# 综合题 第 4 题

![[_Attachments/题目识别/27_王道408-题目/CO-C04-43-F04_题目.png|题目]]

4.【2023统考真题】已知计算机 $M$ 的字长为 32 位，按字节编址，采用请求调页策略的虚拟存储管理方式，虚拟地址为 32 位，页大小为 4KB，某 C 语言程序段在计算机 $M$ 上的部分机器级代码如下，数组 $a$ 的定义为 `int a[24][64];`，每个机器级代码行中依次包含指令序号、虚拟地址、机器指令和汇编指令. 请回答下列问题.

| 指令序号 | 虚拟地址 | 机器指令 | 汇编指令 |
|---|---|---|---|
|  |  |  | `for(i = 0; i < 24; i++)` |
| 1 | 00401072 | C7 45 F8 00 00 00 00 | `mov [ebp-8], 0` |
| 2 | 00401079 | EB 09 | `jmp 00401084h` |
| 3 | 0040107B | 8B 55 F8 | `mov eax, [ebp-8]` |
| ... | ... | ... | ... |
| 7 | 00401088 | 7D 32 | `jge 004010bch` |
|  |  |  | `for(j = 0; j < 64; j++)` |
| 8 | 0040108A | C7 45 FC 00 00 00 00 | `mov [ebp-4], 0` |
| ... | ... | ... | ... |
|  |  |  | `a[i][j] = 10;` |
| ... | ... | ... | ... |
| 19 | 004010AE | C7 84 82 00 20 42 00 0A 00 00 00 | `mov [ecx+edx*4+00422000h], 0Ah` |
| 20 | ... | ... | ... |

(1) 第20条指令的虚拟地址是多少？  
(2) 已知第2条 `jmp` 和第7条 `jge` 都是跳转指令，其操作码分别是 `EBH` 和 `7DH`，跳转目标地址分别为 `00401084H`、`004010BCH`，这两条指令都采用什么寻址方式？给出第2条指令 `jmp` 的跳转目标地址计算过程.  
(3) 现已知第19条 `mov` 指令的功能为 `a[i][j] <- 10`，其中 `ecx` 和 `edx` 为寄存器名，`00422000H` 是数组 $a$ 的首地址，指令中源操作数采用什么寻址方式？已知 `edx` 中存放的是变量 $j$，`ecx` 中存放的是什么？根据该指令的机器码判断 $M$ 采用的是大端还是小端方式.  
(4) 第一次执行第19条指令时，取指令过程中是否会发生缺页异常？为什么？

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C04-43-F04_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：  
（1）第20条指令的虚拟地址是 $004010B9_{16}$。  
（2）第2条 `jmp` 和第7条 `jge` 都采用相对寻址。第2条目标地址计算为  
$$00401079_{16}+02_{16}+09_{16}=00401084_{16}$$  
（3）第19条指令的源操作数采用立即寻址；$ecx$ 中存放的是 $i\times 64\times 4=i\times256$，即数组第 $i$ 行的字节偏移量；$M$ 为小端方式。  
（4）不会发生缺页异常。第19条指令与第1条指令在同一4KB代码页中，该页此前已被调入内存，且第19条指令没有跨页。

---

**解题切入点**：  
先把“虚拟地址 + 机器指令字节数”看成“指针 + 步长”，推出下一条指令地址；跳转指令看操作码后的偏移量是相对于谁的；数组访问要按行优先换算成字节偏移；大小端看指令中多字节数据的最低字节是否放在低地址；缺页问题要先分清是“取指令”还是“访问数据”，再看虚拟地址所在页是否已调入。

---

**推演**：

### （1）第20条指令的虚拟地址

第19条指令的机器码为

`C7 84 82 00 20 42 00 0A 00 00 00`

共 11 个字节，即 $0B_{16}$。已知第19条指令虚拟地址为 $004010AE_{16}$，所以第20条指令地址为

$$004010AE_{16}+0B_{16}=004010B9_{16}$$

---

### （2）跳转指令的寻址方式与目标地址计算

第2条指令在 $00401079_{16}$，机器码为 `EB 09`。其中 `EB` 是操作码，`09` 是 8 位相对偏移量。CPU 取出该指令后，$PC$ 已经指向下一条指令：

$$PC=00401079_{16}+02_{16}=0040107B_{16}$$

因此跳转目标为

$$0040107B_{16}+09_{16}=00401084_{16}$$

第7条指令同理，指令地址为 $00401088_{16}$，偏移量为 $32_{16}$，所以目标为

$$00401088_{16}+02_{16}+32_{16}=004010BC_{16}$$

所以这两条跳转指令都采用相对寻址，也称 PC 相对寻址。

---

### （3）第19条指令的源操作数、$ecx$ 的内容与字节序

源操作数是立即数 `0AH`，它直接出现在指令的立即数字段中，因此采用立即寻址。

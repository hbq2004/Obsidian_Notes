# 综合题 第 1 题

![[_Attachments/题目识别/27_王道408-题目/CO-C04-43-F01_题目.png|题目]]

1.【2017统考真题】在按字节编址的计算机 $M$ 上，$f1$ 部分源程序（阴影部分）如下。将 $f1$ 中的 $\mathit{int}$ 都改成 $\mathit{float}$，可得到计算 $f(n)$ 的另一个函数 $f2$。

```c
int f1(unsigned n) {
    int sum=1, power=1;
    for(unsigned i=0; i<=n-1; i++) {
        power *= 2;
        sum += power;
    }
    return sum;
}
```

对应的机器级代码（包括指令的虚拟地址）如下：

    1     00401020    55              push ebp
    ...
    ...
    for(unsigned i = 0; i <= n - 1; i++)
    ...
    ...
    20    0040105E    39 4D F4        cmp dword ptr [ebp - 0Ch], ecx
    ...
    ...
    {       power *= 2;
    ...
    ...
    23    00401066    D1 E2           shl edx, 1
    ...
    ...
    return sum;
    35    0040107F    C3              ret

其中，机器级代码行包括行号、虚拟地址、机器指令和汇编指令。
(1) 计算机 $M$ 是 $\mathit{RISC}$ 还是 $\mathit{CISC}$？为什么？
(2) $f1$ 的机器指令代码共占多少字节？要求给出计算过程。
(3) 第20条指令 $\mathit{cmp}$ 通过 $\mathit{i}$ 减 $n-1$ 实现对 $\mathit{i}$ 和 $n-1$ 的比较。在执行 $f1(0)$ 的过程中，当 $\mathit{i}=0$ 时，$\mathit{cmp}$ 指令执行后，进位/借位标志 $CF$ 的内容是什么？要求给出计算过程。
(4) 第23条指令 $\mathit{shl}$ 通过左移操作实现了 $power*2$ 运算，那么在 $f2$ 中能否用 $\mathit{shl}$ 指令实现 $power*2$？为什么？

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C04-43-F01_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：  
(1) CISC。理由：指令长度不固定，且 `cmp` 等指令可直接访问存储器操作数。  
(2) $96$ 字节。  
(3) $CF=1$。  
(4) 不能；`float` 的机器数整体左移一位不等于浮点数乘 $2$。

---

**解题切入点**：  
看到指令地址和汇编代码，先判断指令集风格：固定长度且只有 Load/Store 访存的是 RISC，反之为 CISC。函数占用字节数直接用首末地址差计算；$CF$ 由 `cmp` 的无符号减法决定；`shl` 是对整数位串左移，换成 `float` 后不能照搬。

---

**推演**：

### (1) RISC 还是 CISC？

给出的机器指令有：

- `55`：`push ebp`，占 $1$ 字节；
- `39 4D F4`：`cmp dword ptr [ebp-0Ch], ecx`，占 $3$ 字节；
- `D1 E2`：`shl edx, 1`，占 $2$ 字节；
- `C3`：`ret`，占 $1$ 字节。

可见指令长度不固定，且 `cmp` 的其中一个操作数可直接为内存单元 `[ebp-0Ch]`，这是典型的 CISC 特征，而不是 RISC 的定长指令和 Load/Store 结构。  
因此，计算机 $M$ 是 **CISC**。

---

### (2) $f1$ 的机器指令代码占多少字节？

第 1 条指令的虚拟地址为：

$$00401020_{16}$$

最后一条指令 `ret` 在第 35 行，虚拟地址为：

$$0040107F_{16}$$

`ret` 指令 `C3` 占 $1$ 字节，所以整个函数代码的字节数为：

$$0040107F_{16} + 1 - 00401020_{16}
= 00401080_{16} - 00401020_{16}
= 60_{16}
= 96$$

因此，$f1$ 的机器指令代码共占 **96 字节**。

---

### (3) 执行 $f1(0)$ 且 $i=0$ 时，$CF$ 是多少？

第 20 条指令：

```asm
cmp dword ptr [ebp-0Ch], ecx
```

在 Intel 语法中，它执行：

$$[ebp-0Ch] - ecx$$

其中 $[ebp-0Ch]$ 对应变量 $i$，$ecx$ 中存放 $n-1$。

因为 $n$ 是 `unsigned` 类型，当 $n=0$ 时：

$$n-1 = 0 - 1 \equiv 2^{32}-1 = 0\text{FFFFFFFF}_{16}$$

所以此时：

$$i - (n-1) = 0 - 0\text{FFFFFFFF}_{16}$$

在 32 位无符号减法中，$0$ 减 $0\text{FFFFFFFF}_{16}$ 需要向更高位借位，因此：

$$CF=1$$

用另一种等价说法：`cmp` 做的是无符号比较，$CF=1$ 表示被减数小于减数，即：

$$0 < 0\text{FFFFFFFF}_{16}$$

所以 $CF=1$。

---

### (4) $f2$ 中能否用 `shl` 实现 `power*2`？

不能。

在 $f1$ 中，`power` 是 `int` 类型，机器指令：

```asm
shl edx, 1
```

等价于把整数左移一位，即乘 $2$。

但在 $f2$ 中，`power` 变成了 `float` 类型。`float` 在计算机中按 IEEE 754 单精度格式存储，分为符号位、阶码和尾数三部分。`shl` 是对整个 32 位机器数做左移，会同时改变符号位、阶码和尾数，并不是把浮点数乘 $2$。

例如：

$$1.0_f = 0\text{3F800000}_{16}$$

若对其左移一位：

$$\text{shl}(0\text{3F800000}_{16}, 1) = 0\text{7F000000}_{16}$$

而：

$$2.0_f = 0\text{40000000}_{16}$$

所以左移结果并不是 $2.0_f$。

因此，在 $f2$ 中不能用 `shl` 实现 `power*2`，而应使用浮点乘法指令，如 `mulss`、`fmul` 等。

---

**易错点**：  
1. 判断 RISC/CISC 时只看到 `shl` 就下结论，应抓住“指令长度不固定”和“指令可直接访存”两个核心特征。  
2. 计算代码长度时容易忘记加 $1$。地址是起始地址，最后一条 `ret` 还占 $1$ 字节，所以应使用“末地址 $+1$ 减首地址”。  
3. 第(3)问容易把 $n-1$ 当成 $-1$。由于 $n$ 是 `unsigned`，$n=0$ 时 $n-1=0\text{FFFFFFFF}_{16}$，不是 $-1$。  
4. 在浮点数中使用 `shl` 会破坏 IEEE 754 位模式；乘 $2$ 对应阶码加 $1$，而不是整个机器数左移一位。

---

**命题规律**：  
本题是 408 计算机组成原理中“指令系统 + 机器级代码 + 数据表示”的综合考点。常见变式有：根据汇编指令判断 RISC/CISC；根据虚拟地址计算函数或指令长度；分析 `cmp/sub` 后的 $CF/ZF/SF/OF$；结合 IEEE 754 考查整数移位与浮点数乘法的区别。  
复习时应熟练掌握 x86 常用指令格式、标志位含义、函数栈布局，以及 IEEE 754 单精度浮点数的位结构。

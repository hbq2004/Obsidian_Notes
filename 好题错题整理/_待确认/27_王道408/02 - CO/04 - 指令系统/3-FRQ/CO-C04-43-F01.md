# 综合题 第 1 题

![[_Attachments/题目识别/27_王道408-题目/CO-C04-43-F01_题目.png|题目]]

1.【2017统考真题】在按字节编址的计算机 $M$ 上，$f1$ 部分源程序（阴影部分）如下。将 $f1$ 中的 $\mathit{int}$ 都改成 $\mathit{float}$，可得到计算 $f(n)$ 的另一个函数 $f2$。

```c
int f1(unsigned n) {
    int sum=1, power=1;
    for(unsigned i=0; i<=n-1; i++) {
        power *= 2;
        sum += power;
    }
    return sum;
}
```

对应的机器级代码（包括指令的虚拟地址）如下：

    1     00401020    55              push ebp
    ...
    ...
    for(unsigned i = 0; i <= n - 1; i++)
    ...
    ...
    20    0040105E    39 4D F4        cmp dword ptr [ebp - 0Ch], ecx
    ...
    ...
    {       power *= 2;
    ...
    ...
    23    00401066    D1 E2           shl edx, 1
    ...
    ...
    return sum;
    35    0040107F    C3              ret

其中，机器级代码行包括行号、虚拟地址、机器指令和汇编指令。
(1) 计算机 $M$ 是 $\mathit{RISC}$ 还是 $\mathit{CISC}$？为什么？
(2) $f1$ 的机器指令代码共占多少字节？要求给出计算过程。
(3) 第20条指令 $\mathit{cmp}$ 通过 $\mathit{i}$ 减 $n-1$ 实现对 $\mathit{i}$ 和 $n-1$ 的比较。在执行 $f1(0)$ 的过程中，当 $\mathit{i}=0$ 时，$\mathit{cmp}$ 指令执行后，进位/借位标志 $CF$ 的内容是什么？要求给出计算过程。
(4) 第23条指令 $\mathit{shl}$ 通过左移操作实现了 $power*2$ 运算，那么在 $f2$ 中能否用 $\mathit{shl}$ 指令实现 $power*2$？为什么？

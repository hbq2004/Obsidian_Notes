# 选择题 第 6 题

![[_Attachments/题目识别/27_王道408-题目/CO-C04-43-M06_题目.png|题目]]

6. 程序 $P$ 中有两个变量 $\textit{i}$ 和 $\textit{j}$，被分别分配在寄存器 $\textit{eax}$ 和 $\textit{edx}$ 中，$P$ 中语句“if(i < j) {...}”对应的指令序列如下 (左边为指令地址，中间为机器代码，右边为汇编指令)，其中 $\textit{jle}$ 指令的偏移量为 $0d$:

```
804846a   39   c2    cmp dword ptr edx,eax
804846c   7e   0d    jle xxxxxxxx
```

若执行到 $804846aH$ 处的 $\textit{cmp}$ 指令时，$\textit{i} = 105$，$\textit{j} = 100$，则 $\textit{jle}$ 指令执行后将会转到 ( ) 处的指令执行.
(A) $8048461H$
(B) $804846eH$
(C) $8048479H$
(D) $804847bH$

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C04-43-M06_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。因为 $i=105>j=100$，$\textit{cmp edx, eax}$ 结果为负且不为零，满足 $\textit{jle}$ 的跳转条件（$\mathrm{SF} \neq \mathrm{OF}$），故跳转发生；目标地址为下一条指令地址 $804846e\mathrm{H}$ 加上偏移量 $0d\mathrm{H}$，得 $804847b\mathrm{H}$。

**解题切入点**：拿到题目首先识别指令含义，明确 $\textit{jle}$ 的跳转条件及偏移量计算方式（相对于下一条指令地址）。定位考点为“指令寻址方式与条件转移”，类似算法竞赛中根据条件判断是否跳转并计算目标地址的套路。重点抓住 $\textit{cmp}$ 操作数顺序对标志位的影响和偏移量的用法。

**推演**：  
1. 指令地址与机器码：  
   $\textit{cmp}$ 指令：$804846a\mathrm{H}$，机器码 $39\ c2$（对应 $\textit{cmp edx, eax}$，Intel 语法）；  
   $\textit{jle}$ 指令：$804846c\mathrm{H}$，机器码 $7e\ 0d$（$\textit{jle rel8}$，偏移量为 $0d\mathrm{H}=13$）。  
2. 计算跳转目标：  
   下一条指令地址 $=$ $\textit{jle}$ 地址 $+2$（因为 $\textit{jle rel8}$ 为 2 字节）$= 804846c\mathrm{H}+2 = 804846e\mathrm{H}$。  
   目标地址 $=$ 下一条指令地址 $+$ 偏移量 $= 804846e\mathrm{H} + 0d\mathrm{H} = 804847b\mathrm{H}$。  
3. 判断是否跳转：  
   $i=105$ 在 $\textit{eax}$，$j=100$ 在 $\textit{edx}$。$\textit{cmp edx, eax}$ 计算 $\textit{edx}-\textit{eax}=100-105=-5$，结果不为零且为负，故 $\mathrm{SF}=1,\mathrm{ZF}=0,\mathrm{OF}=0$。  
   $\textit{jle}$ 条件为 $\mathrm{ZF}=1$ 或 $\mathrm{SF}\neq\mathrm{OF}$，此处 $\mathrm{SF}\neq\mathrm{OF}$ 成立，因此跳转发生。  
4. 结论：转到 $804847b\mathrm{H}$ 处指令执行，对应选项 D。

**易错点**：  
- 误将 $\textit{jle}$ 理解为“$i<j$ 时跳转”，而实际 $\textit{jle}$ 是根据标志位判断，需根据 $\textit{cmp}$ 操作数顺序正确解读。  
- 计算偏移量时忘记加上指令自身长度，或错误地将偏移量相对于 $\textit{cmp}$ 地址。  
- 混淆 $\textit{cmp}$ 的减法方向，导致标志位判断相反。  
- 忽略 $\textit{jle}$ 为有符号跳转，与无符号跳转 $\textit{jbe}$ 区分。

**命题规律**：本题是典型的指令系统与程序控制流考点，常以选择题形式考查相对寻址计算和条件转移标志位判断。常见变式包括：更换条件跳转指令（如 $\textit{jg, jge, jl}$ 等）、改变 $\textit{cmp}$ 操作数顺序、或给定寄存器值计算目标地址。复习时应深入理解各条件跳转的符号/无符号含义，熟练掌握偏移量计算公式：目标地址 $=$ 当前指令地址 $+$ 指令长度 $+$ 偏移量。

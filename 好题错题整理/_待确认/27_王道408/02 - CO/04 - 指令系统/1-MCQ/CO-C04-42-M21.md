# 选择题 第 21 题

![[_Attachments/题目识别/27_王道408-题目/CO-C04-42-M21_题目.png|题目]]

21. 某计算机字长为 16 位,标志寄存器中存在 $ZF$、$SF$、$OF$ 和 $CF$ 标志位,采用双字节字长指令字。假定 $bgt$(大于零转移)指令的第一个字节指明操作码和寻址方式,第二个字节为立即数 $Imm8$,用补码表示。指令功能是:若跳转条件成立,则 $PC = PC + 2 + Imm8 \times 2$;否则,$PC = PC + 2$。则下列叙述中错误的是(    )

(A) 该计算机按字节编址

(B) 若 $bgt$ 指令是无符号整数的比较,则跳转条件可以是 $ZF + CF = 0$

(C) 若 $bgt$ 指令是有符号整数的比较,则跳转条件可以是 $SF \oplus OF = 0$

(D) 转移目标地址的范围是相对于 $bgt$ 指令的前 127 条指令到后 128 条指令之间

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C04-42-M21_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。有符号“大于”应满足 $ZF=0$ 且 $SF\oplus OF=0$；C 只写 $SF\oplus OF=0$ 会漏掉 $ZF=0$，相等时也满足该式，不能作为严格“大于零”的跳转条件。

**解题切入点**：  
看到“双字节指令字”和“否则 $PC=PC+2$”，先判断编址方式；看到 $Imm8$ 用补码表示，要注意转移范围要乘 2 且还要加上指令长度 2。比较条件则要分清楚：无符号比较看 $CF$ 和 $ZF$，有符号比较看 $SF$、$OF$ 和 $ZF$。就像写比较器时先确定是 `unsigned` 还是 `signed`，否则会把负数当成很大的无符号数。

**推演**：

1. **A 正确：按字节编址。**  
   当前 `bgt` 指令地址设为 $A$。若不跳转，则
   $$PC=A+2$$
   说明下一条指令地址比当前指令地址大 2，而一条指令占 2 字节，所以一个地址对应一个字节，即按字节编址。

2. **B 正确：无符号比较，$X>Y$ 等价于 $ZF=0$ 且 $CF=0$。**  
   执行比较运算 $X-Y$ 后：
   - 若 $X<Y$，无符号减法发生借位，$CF=1$；
   - 若 $X=Y$，$ZF=1$；
   - 若 $X>Y$，则既不借位也不相等，即 $CF=0$ 且 $ZF=0$。

   因此
   $$X>Y \iff ZF+CF=0$$
   这里 $+$ 表示逻辑或，$ZF+CF=0$ 等价于 $ZF=0$ 且 $CF=0$。

3. **C 错误：有符号比较的“大于”漏掉了 $ZF=0$。**  
   有符号比较 $X-Y$ 时，需要用 $SF$ 和 $OF$ 共同判断符号是否正确。常用结论：
   $$X<Y \iff SF\oplus OF=1$$
   $$X\ge Y \iff SF\oplus OF=0$$
   但严格“大于”还要排除相等的情况：
   $$X>Y \iff SF\oplus OF=0 \text{ 且 } ZF=0$$
   若只写 $SF\oplus OF=0$，则 $X=Y$ 时也满足，但此时不应跳转，所以 C 错误。

4. **D 正确：转移范围是相对于当前指令的前 127 条到后 128 条。**  
   $Imm8$ 是 8 位补码，因此
   $$-128 \le Imm8 \le 127$$
   设当前指令地址为 $A$，由题意：
   $$PC_{\text{目标}}=A+2+Imm8\times 2$$
   所以相对当前指令的字节偏移为
   $$\Delta=PC_{\text{目标}}-A=2(Imm8+1)$$
   因此
   $$\Delta_{\min}=2(-128+1)=-254\text{ 字节}$$
   $$\Delta_{\max}=2(127+1)=256\text{ 字节}$$
   每条指令占 2 字节，换成指令条数为
   $$-127 \le \frac{\Delta}{2} \le 128$$
   即前 127 条指令到后 128 条指令之间，D 正确。

**易错点**：

- 有符号“大于”不能只写 $SF\oplus OF=0$，必须同时要求 $ZF=0$；$SF\oplus OF=0$ 只是“大于或等于”。
- 转移范围计算时容易忘记公式中的 $+2$，或忘记 $Imm8$ 要乘 2。由题中公式，相对当前指令的字节偏移是 $2(Imm8+1)$，不是 $2Imm8$。
- 不要把无符号比较和有符号比较的条件混用：无符号看 $CF$、$ZF$，有符号看 $SF$、$OF$、$ZF$。

**命题规律**：  
本题综合考查编址方式、标志位判断和 PC 相对寻址范围，是 408 中“指令系统 + CPU 寻址”的常见综合小题。常见变式包括改成 `ble`、`bge` 等有符号比较，或改成无符号的 `bhi`、`bls`，也可能改变指令长度或 $Imm$ 位数来重新计算转移范围。复习时应熟记：

- 无符号：$X>Y \iff CF=0, ZF=0$
- 有符号：$X>Y \iff SF\oplus OF=0, ZF=0$

并注意 PC 相对寻址中，“当前指令地址 + 指令长度 + 偏移量”的关系。

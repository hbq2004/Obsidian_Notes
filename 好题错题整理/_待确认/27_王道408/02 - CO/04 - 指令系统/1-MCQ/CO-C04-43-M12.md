# 选择题 第 12 题

![[_Attachments/题目识别/27_王道408-题目/CO-C04-43-M12_题目.png|题目]]

12. 假设 $P$ 为调用过程，$Q$ 为被调用过程，程序在 32 位 $x86$ 处理器上执行，以下是 $C$ 语言程序中过程调用所涉及的操作：
①过程 $Q$ 保存 $P$ 的现场，并为非静态局部变量分配空间
②过程 $P$ 将实参存放到 $Q$ 能访问到的地方
③过程 $P$ 将返回地址存放到特定处，并转跳到 $Q$ 执行
④过程 $Q$ 取出返回地址，并转跳回到过程 $P$ 执行
⑤过程 $Q$ 恢复 $P$ 的现场，并释放局部变量所占空间
⑥执行过程 $Q$ 的函数体
过程调用的正确执行步骤是 ( )
(A) ②→③→④→①→⑤→⑥ (B) ②→③→①→④→⑥→⑤
(C) ②→③→①→⑥→⑤→④ (D) ②→③→①→⑤→⑥→④

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C04-43-M12_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。  
理由：过程调用应先传参，再 `call`（压入返回地址并跳转），被调函数进入后保存现场/分配局部变量，执行函数体，最后恢复现场/释放局部变量，再 `ret` 弹出返回地址跳回调用过程。

**解题切入点**：  
把函数调用看成一次“栈帧压栈/弹栈”的过程：调用前准备好参数，`call` 指令压入返回地址并跳转，被调函数建立自己的栈帧，执行完销毁栈帧，再按返回地址跳回。拿到题目先确定 ④、⑤、⑥ 的相对位置：函数体一定在“保存现场”之后、“恢复现场”之前；“返回”一定在“恢复现场/释放局部变量”之后。

**推演**：  

以 32 位 x86 的栈传参为例，过程调用实际对应如下指令序列：

```asm
; P 中
push 实参            ; ② 将实参放入 Q 可访问的栈中
call Q               ; ③ 将返回地址压栈，并跳转到 Q

; Q 入口
push ebp             ; ① 保存 P 的 EBP（现场）
mov ebp, esp
sub esp, K           ; ① 为非静态局部变量分配空间

...                  ; ⑥ 执行 Q 的函数体

mov esp, ebp         ; ⑤ 释放局部变量空间
pop ebp              ; ⑤ 恢复 P 的 EBP（现场）
ret                  ; ④ 弹出返回地址，跳回 P
```

在 32 位 x86 中：

- `call Q` 等价于  
$$
\text{ESP} \leftarrow \text{ESP} - 4,\quad [\text{ESP}] \leftarrow \text{返回地址},\quad \text{EIP} \leftarrow Q\text{ 的入口地址}
$$
对应操作 ③。

- Q 入口的 `push ebp; mov ebp, esp; sub esp, K` 保存调用过程 P 的现场，并分配局部变量空间，对应操作 ①。

- 函数体执行，对应操作 ⑥。

- 返回前的 `mov esp, ebp; pop ebp` 释放局部变量空间，并恢复 P 的现场，对应操作 ⑤。

- `ret` 从栈顶弹出返回地址到 EIP，并跳回 P，对应操作 ④。

因此正确顺序为：

$$
② \rightarrow ③ \rightarrow ① \rightarrow ⑥ \rightarrow ⑤ \rightarrow ④
$$

所以选 **C**。

**易错点**：  

- 容易把 ④“取出返回地址并跳回”误放在函数体之前。实际上函数体还没执行就返回，逻辑上不可能。
- 容易把 ⑤“恢复现场/释放局部变量”放在函数体之前。局部变量在函数体执行期间必须存在，不能提前释放。
- 容易混淆 `call` 与 `ret` 的职责：`call` 压入返回地址并跳转；`ret` 弹出返回地址并跳回。两者成对出现。
- 注意“返回地址”在 x86 中由 `call` 压入栈中，不需要调用过程手动保存到寄存器；`ret` 会从栈中弹出它。

**命题规律**：  
本题考点是过程调用与栈帧管理，常结合 x86 的 `call/ret`、`push/pop`、栈指针变化一起考查。常见变式包括：

- 给出函数调用汇编片段，判断返回地址、栈指针或栈顶位置变化；
- 结合递归调用，分析栈帧的压入与弹出；
- 给出若干步骤，让考生排出正确调用顺序；
- 对比不同架构，如 MIPS 中用 `$ra` 保存返回地址，x86 中用栈保存返回地址。

复习建议：把“参数传递 → 保存返回地址 → 保存现场/分配局部变量 → 执行函数体 → 恢复现场/释放局部变量 → 返回”这条主线记牢，并会画栈帧图，即可快速应对此类题目。

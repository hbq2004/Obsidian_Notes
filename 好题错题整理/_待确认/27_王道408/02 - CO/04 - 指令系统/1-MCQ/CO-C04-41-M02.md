# 选择题 第 2 题

![[_Attachments/题目识别/27_王道408-题目/CO-C04-41-M02_题目.png|题目]]

2. 下列有关指令集体系结构($ISA$)的叙述中,错误的是(  )

(A) $ISA$规定了执行每条指令时所包含的控制信号
(B) $ISA$规定了指令获取操作数的方式,即寻址方式
(C) $ISA$规定了所有指令的集合,包括指令格式和操作类型
(D) $ISA$规定了程序可访问的寄存器个数、存储空间大小、编址方式和大端/小端方式

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C04-41-M02_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A。  
ISA 是程序员/编译器可见的软硬件接口，规定指令集、指令格式、操作类型、寻址方式、寄存器、存储空间和大小端等；而“执行每条指令时所包含的控制信号”属于 CPU 内部微架构/控制单元设计，不属于 ISA。

**解题切入点**：  
看到“指令集体系结构（ISA）”，立刻抓住一个核心分界：**ISA 管“软件能看见什么”，微架构管“硬件内部怎么做”**。  
四个选项中，A 提到“控制信号”，应马上警觉——控制信号是 CPU 执行指令时硬件实际产生的内部信号，属于实现细节，不是指令集层面的规定。  
这就像算法竞赛里，题目只给出函数接口（ISA），而函数内部如何优化、用什么数据结构实现（微架构），由参赛者自己决定。

**推演**：  

先明确 ISA 的定义：

$$\text{ISA 是计算机硬件与软件之间的约定（Contract）。}$$

它规定了程序员/编译器可以直接观察和使用的属性。常见 ISA 内容有：

- 指令集合：所有指令的操作类型、指令格式；
- 寻址方式：指令如何获取操作数；
- 寄存器：程序员可访问寄存器的个数、宽度；
- 存储器：可寻址空间大小、编址单位、编址方式；
- 数据表示：大端/小端等字节序规则。

逐项分析：

**(A) ISA 规定了执行每条指令时所包含的控制信号**  
错误。控制信号由 CPU 的控制器根据当前指令在具体微架构中产生，属于硬件实现。  
例如，同样执行指令 `ADD R1, R2, R3`，如果 CPU 采用硬连线控制，控制逻辑可能是一套组合逻辑电路；如果采用微程序控制，则可能是另一串微指令产生的微操作控制信号。  
同一种 ISA 可以有不同的控制信号，所以控制信号不是 ISA 的规定。

**(B) ISA 规定了指令获取操作数的方式，即寻址方式**  
正确。寻址方式如立即寻址、直接寻址、寄存器寻址、寄存器间接寻址、变址寻址、相对寻址等，都是 ISA 层面定义的，程序员编译出的程序中要依赖这些寻址方式。

**(C) ISA 规定了所有指令的集合，包括指令格式和操作类型**  
正确。指令系统是 ISA 的核心，包括指令共有哪些功能、指令格式怎样编码、操作码表示什么操作。

**(D) ISA 规定了程序可访问的寄存器个数、存储空间大小、编址方式和大端/小端方式**  
正确。ISA 明确规定了程序员可见的寄存器数量、位宽，以及内存可寻址空间、编址单位（按字节或按字编址）、数字在内存中的字节序等。

因此，错误的选项是 A。

**易错点**：  

- **把“控制信号”当成 ISA 内容**：控制信号属于微架构，不属于 ISA。这是最核心的易错点。
- **把“寄存器个数”误认为微架构内容**：ISA 规定的是“程序员可见寄存器”，如通用寄存器、PC、PSW 等；微架构中还有临时寄存器、流水线寄存器等，但这些对程序员不可见，不属于 ISA。
- **把“指令格式”与“控制信号”混淆**：指令格式是 ISA 规定的二进制编码规则；控制信号是 CPU 内部电路产生的，不是指令编码的一部分。
- **审题错误**：题目问“错误的是”，有人先入为主找“正确的”，容易选反。
- **看到 C 中“所有指令的集合”觉得绝对化**：ISA 确实要规定指令系统，不是说所有计算机的指令都必须完全一样，而是该 ISA 所定义的指令集合是确定且公开的，所以 C 正确。

**命题规律**：  
本题属于 408 中“计算机系统概述”和“指令系统”的经典概念判断题，核心考点是：

$$\text{ISA（指令集体系结构）与微架构（Microarchitecture）的区别}$$

常见变式有：

- “以下哪个选项不属于 ISA 的内容？”
- “同一 ISA 的不同 CPU，以下哪个可能不同？”——答案通常是：控制信号的产生方式、流水线结构、ALU 实现方式、时钟频率等。
- “ISA 规定了哪些程序员可见属性？”——答案是：指令集、寻址方式、寄存器、存储空间、编址方式、字节序等。

复习建议：  
整理一张“ISA vs 微架构”对照表，左边写“ISA：指令集、格式、寻址方式、寄存器、内存编址、大小端”，右边写“微架构：控制信号、数据通路、流水线、缓存结构、时钟频率、ALU 内部结构”。  
做题时遇到“控制信号”“流水线”“数据通路”“物理寄存器”“硬件实现”等词，应优先排除出 ISA 范围。

# 选择题 第 4 题

![[_Attachments/题目识别/27_王道408-题目/CO-C04-44-M04_题目.png|题目]]

4. 下列关于 $RISC$ 和 $CISC$ 的说法中,不正确的是（ ）.

(A) $RISC$ 指令格式种类少,寻址方式少,指令长度固定,更容易用硬布线电路实现.

(B) $CISC$ 指令功能强大,寻址方式多,便于汇编程序员编程.

(C) $CISC$ 指令格式种类多,所以更有利于编译优化.

(D) $RISC$ 多数指令能够在一个时钟周期内完成,特别适合流水线工作.

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C04-44-M04_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。CISC 的“指令格式种类多”并不是编译优化的优势；指令格式多、长度通常可变，会使译码和调度更复杂，反而不利于编译优化。RISC 的指令格式少、定长、语义简单，才更有利于编译优化。

**解题切入点**：

拿到题先建立 $RISC$ 和 $CISC$ 的对比框架：

- $RISC$：指令少、格式少、寻址方式少、指令定长、大多数指令单周期、硬布线控制为主、适合流水线、有利于编译优化。
- $CISC$：指令多、格式多、寻址方式多、指令长度常可变、指令功能强、微程序控制为主、不利于流水线，对编译优化并不友好。

题干问“不正确的是”，所以看到选项中的因果词“所以”要格外小心。C 项把“CISC 格式多”说成“更有利于编译优化”，方向正好反了。

**推演**：

$RISC$ 与 $CISC$ 的主要区别如下：

| 对比项 | $RISC$ | $CISC$ |
|---|---|---|
| 指令格式 | 少，长度固定 | 多，长度常可变 |
| 寻址方式 | 少 | 多 |
| 指令功能 | 简单，复杂功能由简单指令组合实现 | 强大，一条指令可完成复杂操作 |
| 控制方式 | 硬布线控制为主 | 微程序控制为主 |
| 执行周期 | 大多数指令一个时钟周期完成 | 周期差异大 |
| 流水线 | 很适合 | 难以高效实现 |
| 编译优化 | 有利 | 不利 |
| 汇编编程 | 相对繁琐 | 指令功能强，汇编编程相对方便 |

逐项判断：

- A：$RISC$ 指令格式种类少、寻址方式少、指令长度固定，因此指令译码和控制逻辑简单，更容易用硬布线电路实现。正确。
- B：$CISC$ 指令功能强大，寻址方式多，在汇编编程时可以使用功能更强的指令完成较多工作，这是 $CISC$ 的常见特点。正确。
- C：$CISC$ 指令格式种类多，不是“更有利于编译优化”的原因。指令格式多、长度可变，会使编译器在指令选择、指令调度、寄存器分配等方面更复杂；而 $RISC$ 指令格式规整、长度固定、语义简单，更有利于编译优化。故 C 不正确。
- D：$RISC$ 大多数简单指令为寄存器-寄存器型操作，能够在一个时钟周期内完成，指令流水线运作时效率高。正确。

因此不正确的是 C。

**易错点**：

1. 把“汇编程序员编程方便”和“编译优化方便”混为一谈。  
   $CISC$ 指令功能强，对汇编程序员可能有好处；但“编译优化”更看重指令是否简单规整，$RISC$ 更有利。

2. 以为“格式多、选择多”就有利于编译优化。  
   编译优化需要规律性和可预测性，指令格式越多、长度越不固定，编译器和处理器要处理的特殊情况就越多，优化越困难。

3. 把 $RISC$ 的“单周期”绝对化。  
   $RISC$ 也不是所有指令都严格单周期，如访存、乘除等指令可能更复杂。但大多数简单指令可以单周期完成，或流水线中达到理想 $CPI\approx 1$。

4. 混淆控制方式。  
   $RISC$ 以硬布线控制为主，$CISC$ 以微程序控制为主；复杂指令系统若用硬布线实现会非常困难。

**命题规律**：

考点是“指令系统”中 $RISC$ 与 $CISC$ 的对比。常见变式有：

- 给出一组特征，判断属于 $RISC$ 还是 $CISC$；
- 问“下列哪项是 $RISC$ 的特点”或“哪项不是 $CISC$ 的特点”；
- 结合流水线，问 $RISC$ 为什么适合流水线；
- 结合控制方式，问硬布线/微程序分别更适合哪种指令系统。

复习建议：把 $RISC$ 和 $CISC$ 做成对比表记忆，重点注意因果链：

$$RISC: \text{指令少、定长、格式少} \rightarrow \text{译码简单} \rightarrow \text{硬布线、单周期、适合流水线、利于编译优化}$$

$$CISC: \text{指令复杂、格式多、长度可变} \rightarrow \text{译码复杂} \rightarrow \text{微程序控制、不利于流水线、不利于编译优化}$$

考试中若选项出现“所以”“因此”等因果词，要仔细判断因果关系是否成立。

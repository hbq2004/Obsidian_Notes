# 选择题 第 4 题

![[_Attachments/题目识别/27_王道408-题目/CO-C04-44-M04_题目.png|题目]]

4. 下列关于 $RISC$ 和 $CISC$ 的说法中,不正确的是( )
(A) $RISC$ 指令格式种类少,寻址方式少,指令长度固定,更容易用硬布线电路实现
(B) $CISC$ 指令功能强大,寻址方式多,便于汇编程序员编程
(C) $CISC$ 指令格式种类多,所以更有利于编译优化
(D) $RISC$ 多数指令能够在一个时钟周期内完成,特别适合流水线工作

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C04-44-M04_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。CISC 指令格式种类多、寻址方式多、指令长度不固定，反而使译码和编译优化更困难；真正更有利于编译优化的是指令格式规整、寻址方式少的 RISC。

**解题切入点**：题目问“不正确”，所以先圈定关键词，再用 RISC 和 CISC 的典型特征逐项核对。可以类比做选择题时先找“因果倒置”的选项：C 把 CISC 的“指令格式种类多”说成是“编译优化”的优点，这与教材结论相反，因此优先怀疑 C。

**推演**：

本题直接考查 RISC 与 CISC 的指令系统特征对比。

对选项 A 分析：

RISC 的设计目标是精简指令系统，因此指令条数少、指令格式种类少、寻址方式少、指令长度固定。指令规整、译码简单，更适合用硬布线控制电路实现。所以 A 说法正确。

对选项 B 分析：

CISC 的指令系统复杂、功能强大，一条指令往往能完成较复杂的功能，而且寻址方式多，汇编程序员可以更直接地利用这些复杂指令编写程序。所以 B 说法正确。

对选项 C 分析：

CISC 指令格式种类多、寻址方式多，意味着译码器需要处理更多不同的指令编码，编译程序也需要在大量指令和寻址方式之间进行选择与匹配，这会增加编译优化的难度，而不是“更有利于编译优化”。相比之下，RISC 指令格式简单、长度固定、语义规整，编译器更容易生成高效的目标代码。所以 C 说法错误。

对选项 D 分析：

RISC 的大部分指令采取简单的寄存器操作，除 load/store 访存指令外，指令在一个时钟周期内完成的可能性很大，平均 $\mathrm{CPI}$ 接近 $1$；指令长度固定、格式统一，也特别适合流水线工作。所以 D 说法正确。

因此，不正确的是 C。

**易错点**：

1. 误选 B。有同学看到“CISC 指令功能强大，便于汇编程序员编程”，会误以为“便于人写汇编”就是“便于编译器优化”，但二者不是一回事。CISC 的复杂指令对汇编程序员友好，但对编译器自动生成和优化目标代码反而更困难。

2. 误选 D。不要把“多数指令一个时钟周期完成”理解成“所有指令都必须一个时钟周期完成”。RISC 中 load/store、乘除、分支等指令也可能需要多个时钟周期，题目说“多数”是准确的。

3. 混淆 RISC 与 CISC 的控制器实现。RISC 通常更适合硬布线控制，CISC 通常采用微程序控制。选项中 A 说的是“更容易用硬布线电路实现”，这也是 RISC 的重要特征。

4. 把“指令格式多”等同于“表达能力强”。表达能力强的未必利于编译优化；编译优化更看重指令规整、寻址方式少、语义简单。

**命题规律**：RISC 与 CISC 的对比是 408 计算机组成原理的基础考点，常以选择题形式考查，也常与指令流水线、控制器设计结合出题。常见变式包括：“下列说法正确的是”“下列不属于 RISC 特点的是”“RISC 更适合流水线的理由”等。复习时建议整理对比表，从指令条数、指令格式、寻址方式、指令长度、周期数、控制器实现、访存方式、编译优化难度、流水线适应性等角度记忆，重点抓住一句话：RISC 以简化硬件和利于流水线/编译优化为目标，CISC 以增强指令功能和方便汇编编程为目标。

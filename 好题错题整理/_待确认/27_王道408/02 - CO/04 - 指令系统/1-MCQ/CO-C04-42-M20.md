# 选择题 第 20 题

![[_Attachments/题目识别/27_王道408-题目/CO-C04-42-M20_题目.png|题目]]

20. 关于指令的功能及分类，下列叙述中正确的是（ ）
(A) 算术与逻辑运算指令，通常完成算术运算或逻辑运算，都需要两个数据
(B) 移位操作指令，通常用于把指定的两个操作数左移或右移一位
(C) 转移指令、子程序调用与返回指令，用于解决数据调用次序的需求
(D) 特权指令，通常仅用于实现系统软件，这类指令一般不提供给用户

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C04-42-M20_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。特权指令通常仅用于实现系统软件，需要在内核态下执行，不提供给用户程序使用。

**解题切入点**：先定位考点为“指令的功能及分类”，然后对每个选项中的关键词（“都”“两个”“数据调用次序”等）进行审视。这类题常用绝对化表述设置陷阱，如同算法题中先检查边界条件，逐项排除即可。

**推演**：

指令按功能可分为算术与逻辑运算指令、移位操作指令、转移指令、子程序调用与返回指令、特权指令等，下面逐项分析。

**(A) 算术与逻辑运算指令**：  
算术运算如加、减、乘、除通常需要两个操作数，如：
$$
\text{ADD } R_1, R_2
$$
表示 $R_1 \leftarrow R_1 + R_2$。但某些算术指令只需一个操作数，例如取负（NEG）、加一（INC）、求补等。逻辑运算中，“与”“或”“异或”需要两个操作数，但“逻辑非”（NOT）只需要一个操作数。因此“都需要两个数据”说法过于绝对，错误。

**(B) 移位操作指令**：  
移位指令的典型格式为：
$$
\text{SHL } R_1, n
$$
其中 $R_1$ 是被移位的操作数，$n$ 是移位位数（可为立即数或存放在寄存器中）。功能是将 $R_1$ 中的内容左移或右移 $n$ 位，而不是“把指定的两个操作数左移或右移一位”。移位指令通常只有一个操作数（被移位的数据），移位位数不是被移位的操作数。故该选项表述错误。

**(C) 转移指令、子程序调用与返回指令**：  
这类指令通过修改程序计数器（PC）的值来改变指令执行的顺序，实现程序的跳转、循环、子程序调用等控制流需求。例如：
- 无条件转移指令：$\text{JMP } \text{addr}$，使 PC 指向 addr。
- 条件转移指令：根据条件码决定是否跳转。
- 子程序调用指令：$\text{CALL } \text{addr}$，将返回地址压栈，然后跳转到子程序入口。
- 返回指令：$\text{RET}$，从栈中弹出返回地址，恢复原执行流。

它们解决的是“程序执行顺序”或“控制流”的问题，而不是“数据调用次序”的问题。数据调用次序通常涉及堆栈、寄存器、存储器间的数据传递，与这些指令的主要功能不符。故该选项错误。

**(D) 特权指令**：  
特权指令是指只能在内核态（管态）下执行的指令，如中断屏蔽、设置定时器、内存保护、启动 I/O 等。这些指令直接控制系统资源，若允许用户程序随意使用，会破坏系统安全和稳定性。因此，特权指令通常仅由操作系统等系统软件使用，不提供给一般用户。故该选项正确。

综上，正确选项为 **D**。

**易错点**：

1. 误选 A：认为算术与逻辑运算指令都要两个操作数，忽略了取负、逻辑非等单操作数指令。  
2. 误选 B：将移位指令中的“移位位数”误认为第二个操作数，或忽略“一位”与“若干位”的差异。  
3. 误选 C：将子程序调用与返回指令涉及到的“参数传递”误认为“数据调用次序”，而忽略了其本质是控制流转移。  
4. 混淆特权指令与普通指令的使用权限，注意特权指令只能在内核态执行，用户程序不能使用。

**命题规律**：  
本题属于计算机组成原理中“指令系统”的基础考点，常以选择题形式考查指令的分类与功能。常见变式包括：考查某类指令的典型举例（如算术、移位、转移、特权指令）；考查指令的执行权限与状态切换（用户态/内核态）；考查指令中操作数的个数与寻址方式。复习时应系统整理各类指令的定义、操作数特点、典型指令助记符及其在 CPU 中的执行过程，特别关注“绝对化表述”和“概念偷换”的陷阱。

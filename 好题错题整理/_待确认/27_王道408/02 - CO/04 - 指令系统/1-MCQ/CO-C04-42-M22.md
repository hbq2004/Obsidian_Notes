# 选择题 第 22 题

![[_Attachments/题目识别/27_王道408-题目/CO-C04-42-M22_题目.png|题目]]

22. 下列关于指令寻址与数据寻址的描述中,错误的是  
(A) 中断响应时,中断隐指令的执行不属于指令寻址的范畴  
(B) 指令格式中,每个操作数字段均需通过显式编码或隐含约定确定其寻址方式  
(C) 在含 $Cache$ 的系统中,指令访存遵循“$Cache$ 优先”原则,未命中时再访问主存  
(D) 数据寻址方式不属于指令集体系结构 ($ISA$) 规定的内容

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C04-42-M22_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。数据寻址方式恰恰是指令集体系结构（ISA）规定的重要内容；说它“不属于 ISA 规定的内容”是错误的。

**解题切入点**：  
拿到题目先抓两个概念：“指令寻址/数据寻址”和“ISA”。可以用算法竞赛/工程中的“API 契约”来类比：ISA 就是 CPU 和编译器之间的“接口契约”，而寻址方式相当于“参数该如何定位”。既然编译器要生成正确指令、CPU 要正确解释指令，那么“操作数如何寻址”这种程序员可见的规定必然属于 ISA。选项 D 把“寻址方式”推到 ISA 之外，明显是概念错位。

**推演**：  
逐项判断：

1. **选项 A 正确**。  
   指令寻址讨论的是“确定下一条要执行指令地址”的方式，常见为顺序寻址和跳跃寻址：
   $$
   \text{顺序寻址：}\mathrm{PC}\leftarrow\mathrm{PC}+L
   $$
   $$
   \text{跳跃寻址：}\mathrm{PC}\leftarrow\text{目标地址}
   $$
   其中 $L$ 为指令长度，目标地址由转移/调用等指令给出。  
   中断响应时的“中断隐指令”并不是指令系统中真正存在的一条指令，而是 CPU 硬件自动完成的一组中断响应操作，通常包括关中断、保存断点、将中断服务程序入口地址送入 $\mathrm{PC}$。它属于中断响应机制，不属于常规的“指令寻址”范畴。因此 A 说法正确。

2. **选项 B 正确**。  
   指令中每个操作数都必须能让 CPU 知道“去哪里取数”或“操作数是什么”。这种确定方式可以“显式编码”，例如指令中设置寻址方式字段；也可以通过“隐含约定”确定，例如操作码隐含操作数为累加器或栈顶。因此“每个操作数字段均需通过显式编码或隐含约定确定其寻址方式”正确。

3. **选项 C 正确**。  
   在含 Cache 的存储系统中，CPU 无论取指令还是取数据，都先访问 Cache。若 Cache 命中，则直接取得指令；若 Cache 未命中，再访问主存，并将相应块调入 Cache。所以“指令访存遵循 Cache 优先原则，未命中时再访问主存”正确。

4. **选项 D 错误**。  
   ISA 规定的内容包括：指令系统、指令格式、数据类型、寄存器组织、寻址方式、存储模型、异常/中断等。数据寻址方式正是 ISA 中面向程序员和编译器可见的规范部分。比如 MIPS、x86、RISC-V 等不同 ISA 都有各自规定的寻址方式。因此“数据寻址方式不属于 ISA 规定的内容”说法错误。

综上，错误的是 D。

**易错点**：  
- 容易误选 A：中断隐指令虽然会把中断服务程序入口地址送入 $\mathrm{PC}$，但它是硬件中断响应过程，不是真正的可执行指令，也不是程序中的指令寻址方式。  
- 容易误选 B：如果想到零地址指令没有操作数，会犹豫。但 B 说的是“每个操作数字段”，没有操作数字段的指令不受影响；对确实存在的操作数，CPU 必须通过显式字段或隐含约定知道其寻址方式。  
- 容易误选 C：把 Cache 视为“硬件优化细节”而忽略它同样影响取指过程。在含 Cache 系统中，取指令也要先查 Cache。  
- 最核心的错误是把“寻址方式”误当作纯硬件实现细节。记住：ISA 决定“软件可见的接口”，寻址方式是接口的一部分；Cache 大小、流水线级数等才是微结构实现细节。

**命题规律**：  
本题考点集中在“指令寻址与数据寻址的区别”“ISA 的组成”“中断隐指令的性质”“Cache 访存原则”。常见变式有：判断哪些内容属于 ISA，如指令格式、寻址方式、寄存器个数属于 ISA，而 Cache 容量、流水线级数、乘法器实现方式不属于 ISA。复习时应把“ISA”和“微结构”严格区分开，同时熟练记忆中断隐指令的三个硬件动作：关中断、保存断点、引出中断服务程序入口地址。

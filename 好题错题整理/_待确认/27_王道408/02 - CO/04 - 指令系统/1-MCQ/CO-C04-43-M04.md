# 选择题 第 4 题

![[_Attachments/题目识别/27_王道408-题目/CO-C04-43-M04_题目.png|题目]]

4. 某$C$语言程序中对数组变量$b$的声明为“int $b[10][5]$;”，有一条$for$语句如下:
```c
for (i=0; i<10; i++)
    for (j=0; j<5; j++)
        sum += b[i][j];
```
假设执行到“$sum += b[i][j]$;”时，$sum$的值在$eax$中，$b[i][0]$所在地址在$edx$中，$j$在$esi$中，则“$sum += b[i][j]$;”所对应的指令($Intel$格式)可以是(　)
(A) add dword ptr $eax$, [edx + esi * 4]
(B) add dword ptr $eax$, [esi + edx * 4]
(C) add dword ptr $eax$, [edx + esi * 2]
(D) add dword ptr $eax$, [esi + edx * 2]

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C04-43-M04_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A。理由：$b[i][j]$ 的地址比 $b[i][0]$ 多 $j$ 个 `int`，即多 $4j$ 字节，因此有效地址应为 `[edx + esi*4]`，对应指令为 `add eax, dword ptr [edx+esi*4]`。

**解题切入点**：看到二维数组和寄存器寻址，先不要直接背指令，而是先写出地址公式：目标地址 = 已知地址 + 下标 × 元素大小。题目已经给出 $b[i][0]$ 的地址在 `edx`，$j$ 在 `esi`，只需确定 $j$ 对应的字节偏移是 $4j$，对应 x86 寻址中的 `index * scale`。

**推演**：

数组声明为 `int b[10][5]`，C 语言中二维数组按行优先存放。每个 `int` 占 4 字节，因此

$$ \text{Addr}(b[i][j]) = \text{Addr}(b[i][0]) + j \times 4. $$

已知执行到 `sum += b[i][j]` 时，`edx` 中保存的是 $b[i][0]$ 的地址，`esi` 中保存的是 $j$，所以：

$$ \text{Addr}(b[i][j]) = edx + esi \times 4. $$

x86 的 Intel 格式内存寻址可以写成：

$$ [\text{base} + \text{index} \times \text{scale}] $$

其中 scale 可以是 1、2、4、8。这里 `int` 大小为 4 字节，所以 scale 应取 4，基址为 `edx`，索引为 `esi`：

$$ [edx + esi \times 4] $$

又因为 `sum` 的值在 `eax` 中，`sum += b[i][j]` 表示将内存中的 `b[i][j]` 加到 `eax`，因此指令为：

```asm
add eax, dword ptr [edx + esi * 4]
```

对应选项 A。

**易错点**：

- 容易忘记 `int` 占 4 字节，误选成 `[edx + esi*2]`。若元素是 `short`（2 字节）或 `char`（1 字节），比例因子才会变化。
- 容易把基址和索引写反，例如选 B：`[esi + edx*4]` 表示地址为 $j + 4 \times \text{Addr}(b[i][0])$，完全错误。
- 要注意 Intel 格式中 `dword ptr` 修饰的是内存操作数，严格写法应为 `add eax, dword ptr [edx+esi*4]`；不要把目的操作数写成内存。
- 不要忘了 `sum` 在 `eax` 中，因此 `add` 的目的寄存器是 `eax`，而不是把内存加到 `esi` 或 `edx` 上。

**命题规律**：本题考查 x86 寻址方式与 C 语言数组地址计算的结合，是 408 计算机组成原理常考题型。常见变式包括：把二维数组换成 `b[j][i]` 按列访问、把 `int` 换成 `short` 或 `double`、用 `lea` 指令取地址、或给出 `ebp`/`esp` 相对寻址等。复习时应重点掌握：

$$ \text{有效地址} = \text{基址} + \text{变址} \times \text{比例因子} + \text{位移量} $$

并牢记 x86 中比例因子只能是 1、2、4、8，同时结合 C 语言中数据类型大小和数组行优先存储规则进行换算。

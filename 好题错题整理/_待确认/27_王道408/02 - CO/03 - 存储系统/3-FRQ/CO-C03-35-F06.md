# 综合题 第 6 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-35-F06_题目.png|题目]]

6. 【2020 统考真题】假定主存地址为 32 位, 按字节编址, 指令 $Cache$ 和数据 $Cache$ 与主存之间均采用 8 路组相联映射方式, 直写 ($WriteThrough$) 写策略和 $LRU$ 替换算法, 主存块大小为 $64B$, 数据区容量各为 $32KB$. 开始时 $Cache$ 均为空. 请回答下列问题.

(1) $Cache$ 每行中标记 ($Tag$)、 $LRU$ 位各占几位? 是否有修改位?

(2) 有如下 $C$ 语言程序段:
```c
for(k=0; k<1024; k++)
    s[k]=2*s[k];
```
若数组 $s$ 及其变量 $k$ 均为 int 型, int 型数据占 $4B$, 变量 $k$ 分配在寄存器中, 数组 $s$ 在主存中的起始地址为 $008000C0H$, 则在该程序段执行过程中, 访问数组 $s$ 的数据 $Cache$ 缺失次数为多少?

(3) 若 $CPU$ 最先开始的访问操作是读取主存单元 $00010003H$ 中的指令, 简要说明从 $Cache$ 中访问该指令的过程, 包括 $Cache$ 缺失处理过程.

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-35-F06_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：  
(1) $Tag$ 占 $20$ 位，$LRU$ 占 $3$ 位；没有修改位（直写策略不需要脏位）。  
(2) 数据 Cache 缺失次数为 $64$ 次。  
(3) 第一次访问 $00010003\mathrm{H}$ 时指令 Cache 缺失；该地址对应组号为 $0$，块内偏移为 $3$，标记为 $00010\mathrm{H}$。Cache 会把主存 $00010000\mathrm{H}\sim 0001003F\mathrm{H}$ 的整个 $64\mathrm{B}$ 块调入第 $0$ 组的某个空闲行，再取出偏移为 $3$ 的指令。

---

**解题切入点**：  
先做 Cache 地址划分：已知容量、组相联度、块大小，先求组数；组数决定组号位数，块大小决定块内地址位数，剩下就是 Tag 位数。直写和写回决定有没有修改位。第(2)问本质是看数组占多少个主存块、这些块映射到哪些 Cache 组，是否发生冲突替换；第(3)问只需按地址位划分，完整描述一次 Cache 缺失处理流程。

---

**推演**：

### (1) Cache 每行的 Tag、LRU 位

数据区容量为 $32\mathrm{KB}$，采用 $8$ 路组相联，主存块大小为 $64\mathrm{B}$。

Cache 组数：

$$
N_{\text{sets}}=\frac{32\mathrm{KB}}{8\times 64\mathrm{B}}
=\frac{32768}{512}
=64=2^6
$$

块内地址位数：

$$
b=\log_2 64=6
$$

组号位数：

$$
s=\log_2 64=6
$$

主存地址共 $32$ 位，因此 Tag 位数：

$$
t=32-6-6=20
$$

$8$ 路组相联采用 $LRU$ 替换时，需要从 $8$ 个 Cache 行中确定一个 LRU 行，因此 LRU 信息位宽为：

$$
\lceil \log_2 8\rceil=3
$$

所以 $LRU$ 位占 $3$ 位。

采用直写策略时，Cache 写命中会同时写主存，Cache 行与主存内容始终一致，不需要修改位（脏位）。

### (2) 数组访问缺失次数

数组 $s$ 共有 $1024$ 个 int 型数据，每个 int 占 $4\mathrm{B}$，总大小为：

$$
1024\times 4\mathrm{B}=4096\mathrm{B}=64\times 64\mathrm{B}
$$

即数组恰好占 $64$ 个主存块。

数组起始地址为 $008000C0\mathrm{H}$。因为块大小为 $64\mathrm{B}=40\mathrm{H}$，而：

$$
008000C0\mathrm{H}=00800000\mathrm{H}+C0\mathrm{H}=00800000\mathrm{H}+3\times 40\mathrm{H}
$$

所以该地址块内偏移为 $0$，数组起始地址正好落在主存块边界上。

每个 $64\mathrm{B}$ 块可放：

$$
\frac{64\mathrm{B}}{4\mathrm{B}}=16
$$

个 int 型数据。因此每个块第一次被访问时，读 $s[k]$ 发生一次缺失，并调入整个块；随后该块内其他 $15$ 个元素的读、写都命中。所以每个块只产生 $1$ 次缺失。

再看这 $64$ 个块是否发生组冲突。Cache 共有 $64$ 组，数组的 $64$ 个连续主存块依次映射到 $64$ 个不同的 Cache 组，即每组恰好放一个数组块，不会发生组内替换。因此缺失次数就是缺块次数：

$$
64
$$

### (3) 访问指令 $00010003\mathrm{H}$ 的过程

地址 $00010003\mathrm{H}$ 分解如下：

- 低 $6$ 位为块内地址：$3$
- 中间 $6$ 位为 Cache 组号：$0$
- 高 $20$ 位为 Tag：$00010\mathrm{H}$

访问过程为：

1. CPU 将指令地址 $00010003\mathrm{H}$ 送到指令 Cache。
2. 指令 Cache 根据地址中的组号 $0$，找到第 $0$ 组。
3. 将访问地址的 Tag $00010\mathrm{H}$ 与第 $0$ 组中 $8$ 个 Cache 行的 Tag 进行比较。由于开始时 Cache 为空，有效位均为 $0$，没有匹配项，因此 Cache 缺失。
4. Cache 向主存发出读块请求，主存块起始地址为：

$$
00010003\mathrm{H}\ \text{低6位清零}=00010000\mathrm{H}
$$

5. 主存将 $00010000\mathrm{H}\sim 0001003F\mathrm{H}$ 共 $64\mathrm{B}$ 数据送到指令 Cache。
6. 指令 Cache 在第 $0$ 组中选择一个空闲行，写入该 $64\mathrm{B}$ 数据块，设置 Tag 为 $00010\mathrm{H}$，有效位置 $1$，并更新 LRU 状态。
7. 重新访问该 Cache 行，从块内偏移 $3$ 处取出指令，完成取指。

---

**易错点**：  
- 求组号位数时，容易忘记除以相联度。$32\mathrm{KB}/64\mathrm{B}=512$ 是总行数，而不是组数；$8$ 路组相联应再除以 $8$，得到 $64$ 组。  
- $8$ 路组相联的 LRU 位不是每路 $1$ 位共 $8$ 位，而是用 $3$ 位二进制数表示 $8$ 路中的某一候选路/年龄编号。  
- 缺失次数不能按数组元素个数 $1024$ 计算，也不能按“读一次、写一次”算成 $2048$；应按主存块个数计算，一个块首次调入时缺失一次，块内其他访问均命中。  
- 要检查数组起始地址是否块对齐。本题 $008000C0\mathrm{H}$ 的块内偏移正好为 $0$，所以只涉及 $64$ 个块；若偏移不为 $0$，可能涉及 $65$ 个块。  
- 第(3)问中，地址 $00010003\mathrm{H}$ 所在主存块起始地址是 $00010000\mathrm{H}$，不是 $00010003\mathrm{H}$。Cache 缺失时以块为单位调入。

---

**命题规律**：  
本题是 408 中 Cache 部分的典型综合题，核心考点是地址位划分、Cache 容量/位数的计算、映射方式、替换算法、写策略以及缺失次数分析。常见变式包括：  
- 改成写回策略，要求判断是否需要修改位；  
- 改成直接映射或 $2$ 路组相联，重新计算 Tag 位和缺失次数；  
- 给定数组访问步长，分析 Cache 命中率；  
- 求 Cache 总容量或标记阵列容量。  

复习时要熟练掌握“组数 = 容量 /（相联度 × 块大小）”这一公式，会按“Tag | 组号 | 块内地址”拆分地址，并能结合写策略判断是否有脏位。分析缺失次数时，务必按访问序列逐块判断映射到的 Cache 组，再看是否发生冲突替换。

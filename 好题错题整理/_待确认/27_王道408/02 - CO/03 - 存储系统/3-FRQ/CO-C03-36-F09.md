# 综合题 第 9 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-36-F09_题目.png|题目]]

9. 【2025 统考真题】现有 $C$ 语言程序 $P$ 的部分代码如下所示。假定运行程序 $P$ 的计算机 $M$ 字长为 32 位，按字节编址，数据 $Cache$ 的数据区大小为 $32KB$，采用 8 路组相联映射方式，主存块大小为 $64B$，$Cache$ 的命中时间为 2 个时钟周期，缺失损失为 200 个时钟周期；采用页式虚拟存储管理方式，页大小为 $4KB$。数组 $d$ 的起始虚拟地址 $VA_{31} \sim VA_0$ 为 $01800020H$。请回答下列问题。

```c
int x, d[2048], i;
...
for(i=0; i<2048; i++)
    d[i] = d[i] / x;
...
```

(1) 主存地址中 $Cache$ 组号字段和块内地址字段分别占几位? 虚拟地址中哪些位可作为 $Cache$ 索引?
(2) $d[100]$ 的虚拟地址为多少? $d[100]$ 所在主存块对应的 $Cache$ 组号是多少?
(3) 假定执行 $for$ 语句时对应代码已在 $Cache$ 中，变量 $i$ 和 $x$ 已装入寄存器，数组 $d$ 已调入主存但不在 $Cache$ 中，则 $d[0]$ 在其所在主存块内的偏移量是多少 (用十六进制数表示)? 在 $for$ 语句的执行过程中，访问数组 $d$ 的 $Cache$ 缺失率和数组元素的平均访问时间分别是多少? ($Cache$ 缺失率的计算结果要求用百分比表示，保留两位小数)
(4) 数组 $d$ 分布在几个页中? 若执行 $for$ 语句时对应代码已在主存中，但数组 $d$ 还未调入主存，则在执行 $for$ 语句的过程中，访问数组 $d$ 所引起的缺页次数是多少?

## DeepSeek V4 Flash Max 解析

**答案**：

(1) Cache 组号字段占 6 位，块内地址字段占 6 位；虚拟地址中 $VA_{11}\sim VA_6$ 可作为 Cache 索引。

(2) $d[100]$ 的虚拟地址为 $018001B0H$；其所在主存块对应的 Cache 组号为 6。

(3) $d[0]$ 在其所在主存块内的偏移量为 $20H$。  
按所有读、写 Cache 访问统计，访问数组 $d$ 的 Cache 缺失率为 $3.15\%$；每次 Cache 访问平均时间为 $8.30$ 个时钟周期；若按“一个数组元素”的读+写两次访存计，则每个数组元素平均访存时间为 $16.60$ 个时钟周期。

(4) 数组 $d$ 分布在 3 个页中；执行 for 语句过程中，访问数组 $d$ 引起的缺页次数为 3 次。

---

**解题切入点**：

先做“位宽分解”：Cache 的地址分成【块内地址 | Cache 组号 | 标记】三段。  
先由 Cache 容量、块大小、相联度算出组数，得到组号位数；再结合页大小判断虚拟地址中哪些位可以做 Cache 索引。  
之后所有数组地址计算都转化为“地址偏移量”问题，注意数组起始地址没有按块对齐，这是本题的关键陷阱。

---

**推演**：

### (1) Cache 组号位数与块内地址位数

数据 Cache 数据区大小：

$$32KB=2^{15}B$$

主存块大小：

$$64B=2^6B$$

所以 Cache 总块数为：

$$\frac{2^{15}}{2^6}=2^9=512$$

采用 8 路组相联，因此 Cache 组数为：

$$\frac{512}{8}=64=2^6$$

所以：

- 块内地址字段占 $\log_2 64=6$ 位；
- Cache 组号字段占 $\log_2 64=6$ 位。

页大小为：

$$4KB=2^{12}B$$

因此虚拟地址低 12 位是页内偏移。而 Cache 索引需要的“块内地址 + 组号”位数是：

$$6+6=12$$

正好等于页内偏移位数。所以虚拟地址低 12 位中：

- $VA_5\sim VA_0$ 是块内地址；
- $VA_{11}\sim VA_6$ 是 Cache 组号，可作为 Cache 索引。

### (2) $d[100]$ 的虚拟地址和 Cache 组号

$C$ 语言中 `int` 为 32 位，占 4 字节。

$$d[100] = 01800020H + 100 \times 4$$

$$= 01800020H + 190H = 018001B0H$$

因此 $d[100]$ 的虚拟地址为：

$$018001B0H$$

取低 12 位页内偏移：

$$1B0H$$

Cache 组号是 $VA_{11}\sim VA_6$，即：

$$(1B0H >> 6) \& 3F = 000110B = 6$$

所以对应 Cache 组号为 6。

### (3) $d[0]$ 的块内偏移、Cache 缺失率与平均访问时间

$d[0]$ 的虚拟地址是：

$$01800020H$$

一个主存块大小为 $64B=40H$，块起始地址按 $40H$ 对齐。  
$01800020H$ 的低 6 位是：

$$20H$$

所以 $d[0]$ 在所在主存块内的偏移量为：

$$20H$$

数组 $d$ 共占：

$$2048 \times 4B = 8192B = 2000H$$

但数组首地址不是按主存块对齐的，首地址块内偏移为 $20H$，因此数组 $d$ 跨越的主存块数为：

$$\left\lceil \frac{20H + 2000H}{40H} \right\rceil
= \left\lceil \frac{8224}{64} \right\rceil
= 129$$

for 循环中，每个数组元素 $d[i]$ 先读一次，再写一次，所以对数组 $d$ 的总 Cache 访问次数为：

$$2 \times 2048 = 4096$$

每个主存块第一次被访问时产生一次缺失，之后同一块内的读写都命中，因此缺失次数为：

$$129$$

所以 Cache 缺失率为：

$$\frac{129}{4096} \times 100\% \approx 3.15\%$$

平均每次 Cache 访问时间为：

$$T = 2 + 3.15\% \times 200 \approx 8.30$$

即：

$$T \approx 8.30 \text{ 个时钟周期}$$

由于每个数组元素要读一次、写一次，因此每个数组元素的平均访存时间为：

$$2 \times 8.30 = 16.60 \text{ 个时钟周期}$$

### (4) 数组 $d$ 的页数与缺页次数

数组 $d$ 起始地址为：

$$01800020H$$

数组大小为：

$$8192B = 2000H$$

所以数组 $d$ 的结束地址（不包含）为：

$$01802020H$$

$$01800000H,\ 01801000H,\ 01802000H,\cdots$$

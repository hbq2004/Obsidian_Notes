# 综合题 第 8 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-36-F08_题目.png|题目]]

8.【2023统考真题】已知计算机 $M$ 的字长为 32 位,按字节编址,采用请求调页策略的虚拟存储管理方式,虚拟地址为 32 位,页大小为 $4KB$; 数据 $Cache$ 采用 4 路组相联映射方式,数据区大小为 $8KB$,主存块大小为 $32B$。现有 $C$ 语言程序段如下:
```c
int a[24][64];
...
for(i=0;i<24;i++)
    for(j=0;j<64;j++) a[i][j]=10;
```
现已知二维数组 $a$ 按行优先存放,在虚拟地址空间中分配的起始地址为 $00422000H$,$sizeof(\mathrm{int}) = 4$,假定在 $M$ 上执行上述程序段之前数组 $a$ 不在主存,且在该程序段执行过程中不会发生页面置换。问:
(1) 数组 $a$ 分布在几个页面中? 对于数组 $a$ 的访问,会发生几次缺页异常? 页故障地址各是什么?
(2) 不考虑变量 i 和 $j$, 该程序段的数据访问是否具有时间局部性? 为什么?
(3) 该计算机 $M$ 的虚拟地址 ($A31\sim A0$) 中哪几位用作块内地址? 哪几位用作 $Cache$ 组号?$a[1][0]$ 的虚拟地址是多少? 其所在主存块对应的 $Cache$ 组号是多少?
(4) 数组 $a$ 占用多少主存块? 假设上述程序段执行过程中数组 $a$ 的访问不会和其他数据发生 $Cache$ 访问冲突,则数组 $a$ 的 $Cache$ 命中率是多少? 将循环中 $i$ 和 $j$ 的次序按如下方式调换:
```c
for(j=0;j<64;j++)
    for(i=0;i<24;i++)
        a[i][j]=10;
```
则数组 $a$ 的 $Cache$ 命中率又是多少?

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-36-F08_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：  
(1) 数组 $a$ 分布在 $2$ 个页面中；发生 $2$ 次缺页异常；页故障地址分别为 $00422000\text{H}$ 和 $00423000\text{H}$。  
(2) 不具有时间局部性，因为每个数组元素只被访问一次。  
(3) 虚拟地址 $A_4\sim A_0$ 用作块内地址，$A_{10}\sim A_5$ 用作 Cache 组号；$a[1][0]$ 的虚拟地址为 $00422100\text{H}$，其所在主存块对应的 Cache 组号为 $8$。  
(4) 数组 $a$ 占用 $192$ 个主存块；两种循环次序下的 Cache 命中率均为 $7/8$（$87.5\%$）。

**解题切入点**：  
首先抓住存储层次的关键参数：页大小 $4\text{KB}$、块大小 $32\text{B}$、Cache 总容量 $8\text{KB}$ 与 4 路组相联。计算数组总大小 $6\text{KB}$，结合起始地址判断跨页情况。对于缺页，关注首次访问新页面时的触发点；对于 Cache，利用地址低位划分块内偏移和组索引，并分析访问模式下的局部性。注意区分页缺失与 Cache 缺失，并利用数组完全装入 Cache 的特性简化命中率计算。

**推演**：  
(1) 数组大小：$24\times 64\times 4 = 6144\ \text{B} = 6\ \text{KB}$。页大小 $4\ \text{KB}$，起始地址 $00422000\text{H}$ 页内偏移为 $0$，故第一页范围 $00422000\text{H}\sim00422\text{FFFH}$，第二页 $00423000\text{H}\sim00423\text{FFFH}$。数组结束地址 $00422000\text{H}+0x17FF = 004237\text{FFH}$，落在第二页，因此分布在 $2$ 个页面。  
按行优先遍历，首先访问 $a[0][0]$（地址 $00422000\text{H}$），第一页不在主存，发生缺页，故障地址 $00422000\text{H}$；随后访问 $a[0][0]\sim a[15][63]$ 均在第一页内，不触发缺页。当访问 $a[16][0]$ 时，地址为 $00422000\text{H}+16\times 256 = 00423000\text{H}$，第二页不在主存，发生第二次缺页，故障地址 $00423000\text{H}$。此后所有访问都在第二页内，共 $2$ 次缺页。

(2) 时间局部性指近期访问的地址可能很快再次被访问。程序段对每个元素只赋值一次，没有重复访问同一地址，故无时间局部性。（但具有空间局部性，因连续访问相邻元素。）

(3) Cache 数据区 $8\ \text{KB}$，4 路组相联，块大小 $32\ \text{B}$。组数 $= \frac{8\ \text{KB}}{4\times 32\ \text{B}} = 64$，组索引需 $6$ 位（$2^6=64$）。块内地址需 $5$ 位（$2^5=32$）。虚拟地址 $32$ 位，页内偏移 $12$ 位（页大小 $4\ \text{KB}$）。块内地址使用 $A_4\sim A_0$，Cache 组号使用 $A_{10}\sim A_5$。  
$a[1][0]$ 的虚拟地址：起始地址 $00422000\text{H}$，偏移 $1\times 64\times 4 = 256 = 0x100$，故地址 $00422100\text{H}$。该地址块内偏移 $0$，块起始地址即为 $00422100\text{H}$。组号：取 $A_{10}\sim A_5$，$00422100\text{H}$ 低 $12$ 位 $0x100 = 0001\ 0000\ 0000\ \text{B}$，$A_{10}\sim A_5 = 000100\ \text{B} = 8$，故组号 $8$。

(4) 主存块大小 $32\ \text{B}$，数组大小 $6144\ \text{B}$，占用 $\frac{6144}{32}=192$ 个主存块。  
按行优先：每个块含 $8$ 个 int，连续访问。第一次访问某块时 Cache 缺失，随后 $7$ 次命中，故每个块命中率 $7/8$，总命中率 $7/8 = 87.5\%$。  
按列优先：先访问所有行的列 $0$，再访问列 $1$，…，最后列 $7$。每个块内 $8$ 个元素在按列访问时被依次访问。由于数组总大小 $6\ \text{KB} < 8\ \text{KB}$，且 4 路组相联，每个组最多有 $3$ 个块（$24$ 行，每行 $8$ 块，$192/64=3$），不会发生替换，故每个块第一次访问缺失，后续 $7$ 次命中，命中率仍为 $7/8$。

**易错点**：  
- 混淆页大小与块大小，计算数组跨页时忘记考虑起始地址的页内偏移（本题恰为 $0$）。  
- 计算 $a[1][0]$ 地址时忽略 $sizeof(\text{int})=4$，误用 $1\times 64$ 而非 $1\times 64\times 4$。  
- Cache 组号位选择错误，未注意 $A_{10}\sim A_5$ 正好在页内偏移 $A_{11}\sim A_0$ 范围内。  
- 判断时间局部性时误以为连续访问相邻元素即有时间局部性（实际是空间局部性）。  
- 按列访问时，误以为因跨步大导致命中率降低，忽略数组可完全装入 Cache 且无冲突的事实。

**命题规律**：  
本题综合考查虚拟存储（缺页计算）与 Cache（地址划分、命中率分析）的核心知识点，是 408 常考的综合题型。常见变式包括：改变数组大小使 Cache 容量不足、改变 Cache 映射方式（如直接映射）、加入页面置换等。复习建议：熟练掌握地址转换公式，理解存储层次的时间与空间局部性，通过手动模拟访问序列掌握 Cache 缺失率的计算方法。

# 选择题 第 16 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-36-M16_题目.png|题目]]

16.【2020统考真题】下列关于TLB和Cache的叙述中,错误的是( )

A. 命中率都与程序局部性有关  
B. 缺失后都需要去访问主存  
C. 缺失处理都可以由硬件实现  
D. 都由DRAM存储器组成

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-36-M16_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。理由：TLB 和 Cache 都应采用高速小容量存储器，通常用 $\mathrm{SRAM}$（TLB 还可能用相联存储器 $\mathrm{CAM}$）实现，不可能由 $\mathrm{DRAM}$ 组成；其余说法均可成立。

**解题切入点**：先抓住“TLB 是页表项的 Cache，Cache 是主存块的 Cache”这个本质，再用存储层次硬件实现逐一对照。打比方：算法竞赛里常把“热点结果”放进哈希表而不是放在磁盘上，因为快速缓存必须小、快、靠近处理逻辑；TLB/Cache 就是这样的“热点表”，不可能用又慢又要刷新的 $\mathrm{DRAM}$ 做主存储介质。

**推演**：

- A 正确。Cache 命中率依赖程序的时间局部性和空间局部性；TLB 存放近期用到的页表项，若程序访问的虚拟页面相对集中，TLB 命中率也会高。因此二者命中率都与程序局部性有关。

- B 正确。按统考存储层次模型：TLB 缺失后，需要到主存中的页表查找对应的页表项；Cache 缺失后，需要从主存（或下一级存储器）将数据块调入 Cache。因此“缺失后都需要去访问主存”在基础模型下成立。

- C 正确。Cache 缺失处理由硬件控制完成；TLB 缺失处理既可以由硬件自动查页表并装入 TLB（如 x86 的硬件页表行走器），也可以由软件异常处理程序完成。所以“缺失处理都可以由硬件实现”的说法成立，注意这里说的是“可以”，不是“必须”。

- D 错误。$\mathrm{DRAM}$ 速度较慢、需要动态刷新，适合做主存；Cache 和 TLB 需要与 CPU 速度匹配，通常由 $\mathrm{SRAM}$ 实现。因此“都由 DRAM 存储器组成”是错误的。

**易错点**：

- 误选 C：看到 MIPS 的 TLB 缺失由软件处理，就认为 C 错。但题目说的是“可以由硬件实现”，并不要求所有机器都必须硬件实现。
- 混淆 TLB 缺失和缺页中断：TLB 缺失时先查主存中的页表；若页表项无效、页面不在内存，才发生缺页中断，二者不是一回事。
- 误以为 Cache 中存的是主存内容，所以由 $\mathrm{DRAM}$ 组成。实际 CPU 中的 Cache 由 $\mathrm{SRAM}$ 组成，$\mathrm{DRAM}$ 是主存介质。
- 对 B 过度引申到多级 Cache：现代 CPU 中 L1 缺失可能命中 L2，但 408 基础模型中“Cache 缺失后访问主存”是成立的，不必钻牛角尖。

**命题规律**：考点是存储层次与 TLB/Cache 的硬件实现。常见变式有：比较 TLB 与 Cache 的异同、结合虚拟地址到物理地址的转换、判断缺失处理由硬件还是软件完成、考查 $\mathrm{SRAM}$/$\mathrm{DRAM}$ 的用途。复习时应把“寄存器—Cache（$\mathrm{SRAM}$）—主存（$\mathrm{DRAM}$）—磁盘”这条层次链记熟，并特别注意“可以”与“必须”、“缺失”与“缺页”等措辞差异。

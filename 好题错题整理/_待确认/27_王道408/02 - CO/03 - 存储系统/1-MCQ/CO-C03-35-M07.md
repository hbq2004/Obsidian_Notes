# 选择题 第 7 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-35-M07_题目.png|题目]]

7. 对于下列代码,以下哪种变化将使其具有更好的空间局部性 (  )

```c
int i, j, k, sum=0;
for (i=0; i<n; i++)
    for (j=0; j<n; j++)
        for (k=0; k<n; k++)
            sum += a[k][j][i];
```

(A) 将第2行与第3行互换

(B) 将第2行与第4行互换

(C) 将第5行改为 $sum += a[i] [k] [j];$

(D) 将第5行改为 $sum += a[j] [i] [k];$

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-35-M07_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。将第2行与第4行互换后，循环顺序变为 $k\to j\to i$，对 `a[k][j][i]` 的访问变为从低地址到高地址连续递增，空间局部性最好。

**解题切入点**：遇到多层循环访问多维数组，先看 C 数组的存储方式：C 语言多维数组按行优先存放，越靠右的下标地址变化越快。再看最内层循环变量对应数组的哪一个下标；如果最内层变量不是最后一个下标，访存就会“跳着走”，空间局部性差。这就像遍历矩阵时按行连续扫，而不是按列跳着扫。

**推演**：

设数组为 `int a[n][n][n]`，按行优先存放，则元素 `a[x][y][z]` 的地址为

$$
\operatorname{addr}(a[x][y][z])=\operatorname{base}+x n^2+y n+z.
$$

1. 原代码循环顺序是 `i, j, k`，访问的是 `a[k][j][i]`，最内层 $k$ 变化时地址变化量为

$$
\Delta = n^2.
$$

所以每次访问都跨过大约 $n^2$ 个元素，空间局部性很差。

2. 选项 A：交换第2行与第3行，循环变为 `j, i, k`，最内层仍是 $k$，步长仍为 $n^2$，没有改善。

3. 选项 C：改为 `a[i][k][j]`，最内层 $k$ 对应第二个下标，步长为

$$
\Delta = n,
$$

虽然比 $n^2$ 小，但仍不是连续访问，不是最优。

4. 选项 D：改为 `a[j][i][k]`，最内层 $k$ 对应最后一个下标，内层连续访问，确有改善；但在不同 $j$ 之间会跳变，不是整体连续。

5. 选项 B：第2行与第4行互换后，循环顺序为 `k, j, i`，访问 `a[k][j][i]` 时，最内层 $i$ 正好是最后一个下标，地址每次增加

$$
\Delta=1.
$$

且 $j$、$k$ 变化时地址也仍保持连续，相当于按整个数组在内存中的存放顺序依次访问，空间局部性最好。

**易错点**：

- 误以为只要“内层变量是 $k$”就一定连续；关键要看 $k$ 是数组的第几个下标。
- 容易忽略选项 B 的循环交换也是合法的优化，因为 `sum` 累加操作没有循环间数据依赖。
- 选项 C 只是把步长从 $n^2$ 减小到 $n$，不是真正的连续访问，不能选为最优。
- 选项 D 的内层确实连续，但整体不是完全按地址顺序访问；若题目问“最优”或“最好”，应选 B。

**命题规律**：

本题主要考查空间局部性、C 多维数组的行优先存储以及循环交换优化。常见变式包括二维矩阵乘法中的循环顺序调整、三维数组求和、结合 cache 命中率计算访存次数等。复习时要学会写出地址公式判断步长，并牢记：**最内层循环应尽量沿数组最后一个下标遍历，以获得最好的空间局部性**。

# 选择题 第 17 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-35-M17_题目.png|题目]]

17. 对于由高速缓存、主存、硬盘构成的三级存储体系,$CPU$访问该存储系统时发送的地址为(　)
(A) 高速缓存地址
(B) 虚拟地址
(C) 主存物理地址
(D) 磁盘地址

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-35-M17_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B（虚拟地址）。这句话的理由是：题中明确给出“高速缓存、主存、硬盘”构成三级存储体系，说明系统采用了虚拟存储技术，CPU访问该存储系统时首先发送的是虚拟地址，经地址变换后得到物理地址再访问 Cache/主存。

**解题切入点**：拿到题目先抓存储体系的组成——有“硬盘”就立刻联想到虚拟存储和地址变换。可以把这道题类比为“寄快递”：用户（CPU）在快递单上写的是虚拟的“收件人地址”（虚拟地址），而不是真正的仓库货架号（物理地址）；快递中转站（MMU）负责把虚拟地址转换成最终货架号（物理地址）。所以看到硬盘参与统一存储体系时，不应选择主存物理地址，而要选择虚拟地址。

**推演**：

存储体系分为两个层次：

- Cache-主存层次：主要解决速度问题，这一层中 Cache 和主存之间采用物理地址访问；
- 主存-硬盘层次：主要解决容量问题，硬盘承担辅存角色，支持虚拟存储器。

由于硬盘属于存储体系的一部分，程序的地址空间不可能全部装入主存，因此系统必须采用虚拟存储技术。CPU 中指令给出的地址是程序使用的虚拟地址（逻辑地址），而不是主存物理地址。

CPU 访存过程可概括为：

1. 程序计数器或指令中的操作数地址给出虚拟地址 $VA$；
2. CPU 将 $VA$ 发送给存储管理单元 MMU；
3. MMU 通过页表（通常借助 TLB 加速）将 $VA$ 变换为主存物理地址 $PA$；
4. 用 $PA$ 访问 Cache，若 Cache 未命中，再访问主存；
5. 若主存中也缺失（缺页），则由操作系统将硬盘中对应页面调入主存，再从主存读取。

例如，设虚拟地址为 $VA$，页面大小为 $2^p$，物理页框号为 $PFN$，页内偏移为 $offset$，则物理地址变换为：

$$
PA = PFN \times 2^p + offset
$$

其中 $offset = VA \bmod 2^p$。

因此，CPU“发送”给存储系统的第一个地址是虚拟地址，而不是物理地址或磁盘地址。

逐项分析选项：

- A 高速缓存地址：Cache 对 CPU 透明，CPU 不直接发送 Cache 内部的缓存地址；
- B 虚拟地址：正确，虚拟存储系统中 CPU 发送的是虚拟地址；
- C 主存物理地址：物理地址是 MMU 变换后的结果，不是 CPU 最初发送的地址；
- D 磁盘地址：磁盘地址属于辅存设备地址，CPU 不直接访问，由操作系统和 I/O 系统管理。

**易错点**：

1. 误选 C（主存物理地址）：很多同学看到“Cache 和主存”就认为 CPU 访问时发送的一定是物理地址。但题目特意加入了“硬盘”，说明该存储体系包含了虚拟存储层次。在虚拟存储系统下，CPU 发出的是虚拟地址，物理地址是 MMU 转换后的结果。
2. 误选 D（磁盘地址）：硬盘虽然是存储体系的一部分，但 CPU 不能直接按磁盘地址访问磁盘，必须通过虚拟存储缺页中断，由操作系统负责磁盘与主存之间的数据交换。
3. 混淆“虚拟地址”“逻辑地址”“有效地址”等说法：在本题中，它们指向同一个概念；做题时要注意题干措辞，若只问 Cache-主存两级体系，则答案可能为主存物理地址，但本题有三层，所以选虚拟地址。

**命题规律**：本题属于存储系统的基本概念题，重点考查“存储层次”与“地址类型”的对应关系。常见变式有：

- 将“硬盘”换成“辅存”或“外存”，考点不变；
- 结合 TLB、页表给出具体虚拟地址和物理地址位数，要求计算页号、页内偏移；
- 结合 Cache 映射方式，问“Cache 的标记比较使用的是虚拟地址还是物理地址”；
- 区分“CPU 发送的地址”“Cache 使用的地址”“主存使用的地址”。

复习建议：以存储层次为主线，理清“虚拟地址→物理地址→Cache 地址”的变换过程；重点掌握虚拟存储器的地址变换机制、TLB 的作用，以及缺页处理流程。理解不同层次对地址类型的约束，才能应对选择题和综合题。

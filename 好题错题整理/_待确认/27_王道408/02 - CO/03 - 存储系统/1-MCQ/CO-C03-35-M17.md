# 选择题 第 17 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-35-M17_题目.png|题目]]

17.对于由高速缓存、主存、硬盘构成的三级存储体系，$CPU$ 访问该存储系统时发送的地址为( )
A. 高速缓存地址
B. 虚拟地址
C. 主存物理地址
D. 磁盘地址

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-35-M17_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。因为该存储体系包含硬盘（辅存），构成虚拟存储系统，CPU 访问时发出的是虚拟地址，由操作系统/MMU 负责转换为物理地址。

**解题切入点**：抓住“高速缓存、主存、硬盘”这三级存储体系，尤其“硬盘”的出现提示了虚拟存储器。做题时先判断题设是否包含辅存，若包含辅存，则 CPU 发出的是虚拟地址；若只讨论 Cache 和主存，则通常发的是主存物理地址。可以类比比赛中的“寻址”：题目问选手手里拿的是座位号（虚拟地址）还是具体门牌号（物理地址），当有多个楼层和换乘时，他先报的是座位号。

**推演**：
三级存储体系为：
$$
\text{高速缓存(Cache)} \rightarrow \text{主存} \rightarrow \text{硬盘(辅存)}
$$
其中硬盘作为辅存，与主存构成虚拟存储系统。CPU 执行指令时，指令中给出的地址是虚拟地址（逻辑地址），例如程序计数器 PC 中的地址。CPU 将该虚拟地址送到存储管理单元 MMU，MMU 通过页表/段表等机制将其转换为物理地址，再用物理地址去访问 Cache 或主存。若主存未命中（缺页），则由操作系统将所需页面从硬盘调入主存，再继续访问。

因此，CPU 访问该存储系统时“发送”出去的地址是虚拟地址，而不是：
- A：高速缓存地址——Cache 的地址是内部存储单元索引，由硬件根据物理地址/虚拟地址映射生成，不是 CPU 发出的；
- C：主存物理地址——物理地址是虚拟地址转换后的结果，由 MMU 发送给存储系统的，不是 CPU 直接送出的；
- D：磁盘地址——磁盘地址由磁盘控制器和操作系统管理，CPU 不直接面对磁盘地址。

所以正确答案为 B。

**易错点**：
1. 误选 C：只记得“Cache-主存”结构时 CPU 发主存地址，忽略题中出现了硬盘。一旦有辅存，就属于虚拟存储系统，CPU 发的是虚拟地址。
2. 误选 A：误以为 Cache 位于最靠近 CPU，CPU 应该发 Cache 地址。实际上 Cache 对程序员透明，CPU 不感知 Cache 的存在。
3. 混淆“地址转换”责任：虚拟地址到物理地址由 MMU/操作系统完成，不是由 Cache 或磁盘控制器完成。
4. 忽略题目情境：若题目明确说“在 Cache-主存层次”，通常选主存物理地址；但本题刻意包含硬盘，应识别出虚拟存储器。

**命题规律**：该题考查存储层次与地址转换的基本概念，属于必背知识点。常见变式有：给出缺页时 CPU 发出的地址类型；问虚拟地址到物理地址由谁完成；或将三级存储体系改为“主存-辅存”问 CPU 发出的地址。复习时应梳理清楚：
- CPU 发出的地址类型由存储层次中是否包含辅存决定；
- 地址转换流程：CPU → 虚拟地址 → MMU → 物理地址 → Cache/主存；
- 注意“Cache 地址”“磁盘地址”都不是 CPU 直接发出的地址。

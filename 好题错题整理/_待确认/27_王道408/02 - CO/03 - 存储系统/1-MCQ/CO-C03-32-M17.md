# 选择题 第 17 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-32-M17_题目.png|题目]]

17. $DRAM$ 具有破坏性读出的特性,需要定时刷新,下列说法中不正确的是(  )
(A) 刷新是以行为单位的
(B) 刷新是为了给 $DRAM$ 存储单元中的存储电容重新充电
(C) 刷新是通过对存储单元进行“读但不输出数据”,即“假读”的操作来实现的
(D) $DRAM$ 内部设有专门的刷新电路,不会影响到 $CPU$ 的正常访存

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-32-M17_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。  
不正确的是 D。理由：DRAM 刷新会占用存储器的控制权，会与 CPU 访存发生冲突，可能使 CPU 等待，不能认为“不会影响 CPU 的正常访存”。

**解题切入点**：  
看到选项中出现“不会”“完全”“一定”这类绝对化表述时要格外警惕，就像算法题中看到“必然”“任意”一样，先找反例。本题四个选项都在考 DRAM 刷新的基本性质：按什么单位刷新、刷新干什么、刷新怎么实现、刷新对 CPU 有什么影响。前三个是对概念的记忆，第四个是典型的“绝对化表述”陷阱。

**推演**：  
DRAM 存储单元依靠电容上的电荷保存信息，电容存在漏电，电荷会逐渐减少，所以必须定时刷新。

- 一次刷新并不是一个单元一个单元地做，而是选中一行，把这一行所有存储单元的内容送到读出放大器放大，再重新写回，所以刷新是以“行”为单位的。  
  因此 A 正确。

- 刷新本质上是给存储单元中的电容重新充电，恢复因漏电而衰减的信号电平。  
  因此 B 正确。

- 刷新时要从存储单元读出信息，但数据不送到数据总线上、不输出给 CPU 或外部设备，而是在芯片内部立即写回，所以叫“假读”。  
  因此 C 正确。

- D 的错误在于两点：第一，刷新需要由存储器系统或内存控制器配合完成，刷新时要占用存储器的控制权；第二，刷新会使 DRAM 暂时不能进行正常的读写操作。若 CPU 此刻恰好访存，就必须等待。  
  例如集中刷新方式中会有一段“死区时间”，该时间段内所有主存访问都被暂停；分散刷新方式中每个存取周期被拉长，相当于降低内存速度；异步刷新虽然把刷新操作分散开，但若刷新请求与 CPU 访存冲突，CPU 仍可能等待。  
  因此 D 说“不会影响 CPU 的正常访存”是错误的。

综上，选 D。

**易错点**：  
1. 误以为刷新是一个单元一个单元进行的。  
   实际上刷新以“行”为单位，因为一行可以被同时读出并集中写回。

2. 误认为“假读”不是读操作。  
   “假读”是“读但不输出数据”，即数据不进数据总线，但读出放大器必须工作，以便重新放大并写回，给电容重新充电。

3. 误以为刷新不会影响 CPU 访存。  
   DRAM 刷新和 CPU 访存都要访问存储体，是竞争关系。刷新必然占用存储周期，会以等待周期或延长存取周期的方式影响 CPU。

**命题规律**：  
本题属于计算机组成原理中“存储器”部分的 DRAM 基础知识，重点考查 DRAM 与 SRAM 的差别、刷新机制和破坏性读出。常见变式有：

- 判断下列关于 DRAM 刷新说法是否正确；
- 计算刷新次数、刷新间隔、集中刷新的“死区时间”；
- 结合 DRAM 地址线复用，求所需地址线数；
- 考查破坏性读出与再生电路的配合。

复习时要抓住几个关键词：**行刷新、假读、电容充电、刷新与访存会发生冲突**。再记住三种刷新方式：集中刷新、分散刷新、异步刷新的特点和 CPU 受影响程度，就可以应对相关选择题与计算题。

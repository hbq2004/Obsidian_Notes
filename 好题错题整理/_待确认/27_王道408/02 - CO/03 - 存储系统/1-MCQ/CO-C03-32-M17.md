# 选择题 第 17 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-32-M17_题目.png|题目]]

17. $DRAM$ 具有破坏性读出的特性,需要定时刷新,下列说法中不正确的是 ( )

A. 刷新是以行为单位的

B. 刷新是为了给 $DRAM$ 存储单元中的存储电容重新充电

C. 刷新是通过对存储单元进行“读但不输出数据”,即“假读”的操作来实现的

D. $DRAM$ 内部设有专门的刷新电路,不会影响到 $CPU$ 的正常访存

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-32-M17_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：正确选项：D。一句话理由：DRAM 刷新需要占用存储周期，刷新请求与 CPU 访存冲突时会使 CPU 等待，不能说“不会影响 CPU 的正常访存”。

**解题切入点**：先抓住 DRAM 的本质：靠电容存储电荷，电荷会泄漏，且读出是破坏性的，所以必须“重新充电/再生”。然后逐一比对四个选项；看到 D 中“不会影响 CPU 正常访存”这类绝对化表述时要格外警惕，刷新是强制插入的访存操作，不可能完全不占时间。

**推演**：

1. DRAM 存储单元由一个晶体管和一个电容组成，电容中是否存有电荷表示 $0/1$。电容会漏电，因此需要定期刷新；同时，读出时电容上的电荷会被泄放，所以读出是破坏性的，读后也需要重新写入。

2. 刷新以行为单位。这是因为 DRAM 存储阵列中，同一行共用一条字线；选中一行时，可以将该行所有存储单元的电荷读出并经灵敏放大器放大后重新写回电容，从而实现整行刷新。

3. 刷新操作本质上是一次“读但不出数据”的操作，也就是“假读”。它把行中所有单元的数据读出并重新写入，但不把数据送到数据总线上，因此对 CPU 表现为不产生实际读数。

4. 刷新必须占用存取周期。无论采用集中刷新、分散刷新还是异步刷新，刷新操作都会占用存储器的时间。若 CPU 恰好要访存，遇到刷新周期就需等待；某些方式虽然缩短或分散了等待时间，但并不能保证完全不影响到 CPU 访存。

因此：

- A 正确：刷新按行进行。
- B 正确：刷新给电容重新充电，防止电荷泄漏导致信息丢失。
- C 正确：刷新是“假读”，读出后不输出，但完成重写。
- D 错误：刷新需要时间，不可能完全不影响 CPU 访存。

**易错点**：

- 误以为 B 错：有些人认为正常读写也会重写，所以不需要刷新。实际上电容电荷随时间泄漏，即使不访问也必须定时刷新。
- 误以为 C 错：刷新确实是“读”操作的一种，但数据不输出；“假读”不等于没有内部读出和重写过程。
- 误以为 A 错：刷新不是按字节或按字进行，而是按行进行，因为一行可以一次性再生。
- 误以为 D 对：看到“内部设有刷新电路”就以为完全自动化、无代价。实际上刷新电路只是产生行地址和控制信号，刷新仍然占用存储周期，CPU 访存可能被暂停或等待。

**命题规律**：本题属于 DRAM 基本概念题，考点集中在“破坏性读出、电容存储、行刷新、假读刷新、刷新对 CPU 的影响”。常见变式包括：比较 SRAM 与 DRAM、计算刷新开销/刷新周期、判断集中刷新与分散刷新的“死区”概念。复习时要把 DRAM 的“读出—再生—刷新”当作一个完整流程理解，尤其记住：刷新以行为单位、刷新是假读、刷新需占时间且可能影响 CPU 访存。

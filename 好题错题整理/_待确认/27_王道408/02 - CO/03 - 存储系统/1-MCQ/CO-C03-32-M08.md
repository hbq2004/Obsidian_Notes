# 选择题 第 8 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-32-M08_题目.png|题目]]

8. 关于 $SRAM$ 和 $DRAM$ ,下列叙述中正确的是 ( )

(A) 通常 $SRAM$ 依靠电容暂存电荷来存储信息,电容上有电荷为 1,无电荷为 0

(B) $DRAM$ 依靠双稳态电路的两个稳定状态来分别存储 0 和 1

(C) $SRAM$ 速度较慢，但集成度稍高； $DRAM$ 速度稍快，但集成度低

(D) $SRAM$ 速度较快，但集成度稍低; $DRAM$ 速度稍慢，但集成度高

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-32-M08_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。SRAM 速度快但集成度低，DRAM 速度慢但集成度高，选项 D 正确描述了这一特性。

**解题切入点**：本题是存储器类型的基础概念题，考查 SRAM 和 DRAM 的核心区别。解题时先抓住两类存储器的本质存储原理：SRAM 用双稳态触发器（锁存器），DRAM 用电容。然后比较速度与集成度的典型关系——集成度越高通常速度越慢（因为存储单元更小、寄生参数更大）。可以类比编程中的“空间换时间”或“时间换空间”思想：SRAM 用更多晶体管（面积大）换得快速度，DRAM 用更少晶体管（面积小）但需刷新（时间开销）。

**推演**：

- SRAM（静态随机存取存储器）每个存储单元由 6 个晶体管（或 4 个晶体管加电阻）构成双稳态触发器，通过正反馈保持两个稳定状态分别代表 0 和 1，无需刷新，因此存取速度快（典型访问时间 ~10ns）。但单元面积大，集成度低（每比特占用硅片面积大，容量小）。
- DRAM（动态随机存取存储器）每个存储单元由 1 个晶体管和 1 个电容构成，利用电容存储电荷表示信息，电荷泄漏需定期刷新（每 ~64ms 刷新一次），因此存取速度慢（典型访问时间 ~50ns）。但单元面积小，集成度高（每比特面积小，可制造大容量芯片）。

逐项分析：
- 选项 A：描述的是 DRAM 原理，但误写为 SRAM，错误。
- 选项 B：描述的是 SRAM 原理，但误写为 DRAM，错误。
- 选项 C：SRAM 速度应较快，DRAM 速度应较慢，且集成度关系相反，错误。
- 选项 D：SRAM 速度快（但集成度低），DRAM 速度慢（但集成度高），正确。

**易错点**：
1. **混淆原理**：将 SRAM 的触发器原理与 DRAM 的电容原理颠倒，误选 A 或 B。
2. **颠倒速度与集成度关系**：认为集成度高的 DRAM 速度更快，或集成度低的 SRAM 速度更慢，实际上 SRAM 速度快但集成度低，DRAM 速度慢但集成度高。
3. **忽略刷新**：认为 DRAM 不需要刷新，或误以为 SRAM 需要刷新，导致对速度判断错误。

**命题规律**：
- **考点定位**：计算机组成原理中存储器层次结构的基础知识，常以选择题或判断题形式考查 SRAM 与 DRAM 的存储原理、速度、集成度、功耗、刷新要求等对比。
- **常见变式**：可考查 SRAM 和 DRAM 的典型应用场景（如 Cache 用 SRAM，主存用 DRAM），或结合其他存储器（如 SDRAM、DDR、ROM）比较，也可问及刷新电路、访问时间数量级等。
- **复习建议**：熟练掌握 SRAM 与 DRAM 的存储单元结构、工作原理、优缺点对比表，并理解其与 Cache 和主存的关系。建议总结一张对比表格，包括原理、速度、集成度、功耗、刷新、成本、应用等，并注意题干中“通常”“一般”等限定词避免绝对化错误。

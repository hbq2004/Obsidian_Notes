# 选择题 第 15 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-33-M15_题目.png|题目]]

15.【2023统考真题】某计算机的 $CPU$ 有 30 根地址线,按字节编址, $CPU$ 和主存连接时,要求主存芯片占满所有可能的存储地址空间,并且 $RAM$ 区和 $ROM$ 区所分配的空间大小比是 $3:1$. 若 $RAM$ 在低地址区, $ROM$ 在高地址区,则 $ROM$ 的地址范围是 ( )

(A) 00000000H\~0FFFFFFFH
(B) 10000000H\~2FFFFFFFH
(C) 30000000H\~3FFFFFFFH
(D) 40000000H\~4FFFFFFFH

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-33-M15_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。CPU 有 30 根地址线，按字节编址，总地址空间为 $2^{30}\text{B}$，RAM 与 ROM 空间大小比为 $3:1$ 且 RAM 在低地址，故 ROM 占据高地址的 $1/4$ 空间，即从 $30000000\text{H}$ 到 $3FFFFFFF\text{H}$。

**解题切入点**：首先根据地址线条数确定总地址空间大小，再根据比例分配空间，结合高低地址顺序确定 ROM 的起始地址。

**推演**：
- CPU 有 30 根地址线，按字节编址，可寻址空间为 $2^{30}\text{B} = 1\text{GB}$，地址范围为 $00000000\text{H} \sim 3FFFFFFF\text{H}$（因为 $2^{30}=0\text{x}40000000$）。
- 设 ROM 空间大小为 $x$，则 RAM 空间大小为 $3x$，总空间 $4x = 2^{30}$，得 $x = 2^{28}\text{B} = 256\text{MB} = 0\text{x}10000000\text{H}$。
- RAM 在低地址，ROM 在高地址，故 ROM 起始地址为总空间大小减去 ROM 大小，即 $0\text{x}40000000 - 0\text{x}10000000 = 0\text{x}30000000\text{H}$，结束地址为 $0\text{x}3FFFFFFF\text{H}$。
- 因此 ROM 地址范围为 $30000000\text{H} \sim 3FFFFFFF\text{H}$，对应选项 C。

**易错点**：
1. 地址线根数与可寻址空间的关系：30 根地址线对应 $2^{30}$ 个地址，而非 $2^{30}/8$ 等。
2. 十六进制计算时，注意 $2^{30}=0\text{x}40000000$，$2^{28}=0\text{x}10000000$，避免计算错误。
3. 比例分配时，注意 RAM 和 ROM 谁占低地址、谁占高地址，不要搞反。
4. 选项 D 的 $40000000\text{H}$ 超出总地址范围，可能忽略了 CPU 地址线数限制。

**命题规律**：本题考察地址线、地址空间分配与比例计算，常见于存储器层次结构设计。常与芯片容量计算、片选信号、地址范围划分等结合。复习时需掌握地址线与寻址空间的关系，以及十六进制地址运算，注重理解“占满所有地址空间”的含义。

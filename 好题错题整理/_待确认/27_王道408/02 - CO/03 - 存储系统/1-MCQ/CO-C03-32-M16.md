# 选择题 第 16 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-32-M16_题目.png|题目]]

16. 下列关于 Flash 存储器特性与应用的说法中,正确的是 ( )
(A) 读写速度一致，均接近 DRAM 的访问速率
(B) 属于易失性存储器，断电后数据丢失
(C) 写操作前需先擦除目标块，故写速慢于读速
(D) 仅能用作辅助存储器 (如 U 盘)

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-32-M16_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。Flash 存储器是非易失性存储器，读速度快于写速度，且写操作前必须先擦除目标块，因此“写速慢于读速”正确。

**解题切入点**：拿到题目先抓关键词“Flash 存储器特性与应用”，立刻联想到 Flash 属于 ROM 类非易失性存储器，核心特性是“先擦后写、写慢读快”。就像处理算法竞赛中的“内存模型”题：先判断存储器的易失性，再比较读写速度，最后看应用场景。四个选项分别对应特性、易失性、写机制、应用范围，逐个击破即可。

**推演**：

1. **选项 A 分析**：  
   Flash 的读操作与 DRAM 相比，速度仍慢一个数量级左右；写操作更慢，且需要先擦除。因此“读写速度一致，均接近 DRAM 的访问速率”错误。  
   事实上，Flash 读速远低于 DRAM，写速又远低于读速，不可能“一致且接近 DRAM”。

2. **选项 B 分析**：  
   Flash 是 ROM 型存储器，属于**非易失性存储器**，断电后数据不丢失。U 盘、固态硬盘（SSD）断电后仍能保存数据就是明证。  
   因此“属于易失性存储器，断电后数据丢失”错误。

3. **选项 C 分析**：  
   Flash 的存储单元是基于浮栅晶体管，写入数据时需要向浮栅注入电荷，且只能将 1 写为 0（或反之，取决于类型），要将 0 恢复为 1 必须先进行块擦除操作。块擦除粒度大、耗时长，因此写操作速度明显慢于读操作。  
   这是 Flash 最典型的特性，故 C 正确。

4. **选项 D 分析**：  
   Flash 既可用作辅助存储器（U 盘、SD 卡、SSD），也可用作嵌入式系统的固件存储（BIOS/ROM）、移动设备的存储芯片，甚至在某些系统中作为主存的一部分。  
   “仅能用作辅助存储器”表述过于绝对，错误。

综上，正确选项为 C。

**易错点**：

- **易错 1：误选 A**。认为 Flash 读写都快，或者以为 Flash 是 RAM 类。实际 Flash 读速远低于 DRAM，写速更慢。
- **易错 2：误选 B**。混淆 RAM 与 ROM 的易失性。Flash 属于 ROM 家族，是非易失性的。
- **易错 3：误选 D**。只想到 U 盘，忽略 SSD、嵌入式存储、BIOS 芯片等应用。注意“仅能”是绝对化表述，通常错误。
- **易错 4：对“先擦后写”理解不深**。忘记 Flash 写操作前必须按块擦除，导致无法解释写速慢的原因。

**命题规律**：  
这是计算机组成原理中“存储器层次结构”部分的常考基础题，考点集中在 Flash 的**非易失性**、**先擦后写**、**读写速度不对称**以及**应用场景**。常见变式包括：

- 比较 Flash 与 EEPROM、DRAM、SRAM 的特性；
- 考查 Flash 的擦除单位（块）与读写单位（页/字节）的区别；
- 结合 SSD 考查地址映射、磨损均衡等扩展知识。

复习建议：熟记各类存储器的易失性、读写速度、最小访问单位，并理解 Flash“先擦后写”的硬件原因。遇到“特性与应用”类选择题时，先排除绝对化表述（如“仅能”“一定”），再对照基本特性逐项判断。

# 选择题 第 9 题

9. 下列关于 $Cache$ 的描述中,比较合理的是 (    )

$I$. 指令 $Cache$ 通常比数据 $Cache$ 具有更好的空间局部性

$II$. 由于空间局部性,适当增加 $Cache$ 块大小通常会提高命中率

$III$. 回写法的写主存操作次数少于写直达法

A. $III$

B. $I$ 和 $II$

C. $II$ 和 $III$

D. $I$ 和 $II$ 和 $III$

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-35-M09_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D（$I、II、III$ 均合理）。  
理由：指令流通常顺序取指，空间局部性较好；适当增加 Cache 块大小可利用空间局部性提高命中率；回写法只在块被替换等时刻写主存，写主存次数通常少于写直达法。

**解题切入点**：  
先不要急于逐项“凭感觉”判断，应把三句话分别定位到三个考点：局部性类型、Cache 块大小与命中率、Cache 写策略。  
这就像做算法题时先判断每个结论的适用范围：  
- $I$ 看“通常”，不要求绝对成立；  
- $II$ 看“适当”，不是“块越大越好”；  
- $III$ 看“写主存次数”，不是“写回字节数”。  
可以打比方：指令流像顺序扫描数组，空间局部性好；回写法像“先攒着最后统一写入磁盘”，写直达法像“每次修改都立刻落盘”。

**推演**：

$I$ 正确。  
程序执行时，指令地址通常由程序计数器顺序递增，因此相邻指令存放在相邻主存单元中；即使有分支和跳转，一般也只在局部区域执行。与数据访问模式相比，指令流的访问地址往往更规则、更连续，所以指令 Cache 通常具有更好的空间局部性。注意题干说“通常”，并不排除某些数据程序也有很强的空间局部性。

$II$ 正确。  
空间局部性是指：访问某个地址后，其附近地址很可能很快被访问。增大 Cache 块大小，相当于一次调入更多的相邻数据，后续访问相邻地址时更可能命中。  
但块大小不能无限增大：在 Cache 总容量固定时，块太大导致 Cache 行数减少，冲突不命中可能增加；同时一次缺失调入的代价也会增大。题干用“适当”和“通常”限定，因此说法合理。

$III$ 正确。  
写直达法每次写 Cache 时都要同时写主存；若同一块被写 $k$ 次，则产生 $k$ 次主存写。  
回写法写操作只修改 Cache 行并置“脏位”，只有在该块被替换或需要写回时才写主存。若同一块被写 $k$ 次，回写法在该块被替换时最多只需写一次主存。因此回写法的写主存操作次数通常少于写直达法。

**易错点**：  
1. 把 $I$ 绝对化，认为每条程序的数据访问都没有空间局部性；题目用“通常”限定，应理解为一般统计规律。  
2. 把 $II$ 理解成“Cache 块越大命中率越高”，忽略了块过大会导致 Cache 行数减少、冲突不命中增加；“适当”是成立前提。  
3. 比较 $III$ 时要注意比较的是“写主存次数”，不是“写回数据总量”。写回法一次写回可能是一整块，写直达法每次单个写操作都写主存；从次数上看，写回法通常更少。

**命题规律**：  
本题是 Cache 基础概念综合判断题，覆盖三个高频考点：局部性、块大小对命中率的影响、写策略。常见变式有：  
- 把 $II$ 改成“块越大越好”，考查边界条件；  
- 把 $III$ 改成“写回法一定比写直达法快”，考查速度与一致性的权衡；  
- 把 $I$ 改问“时间局部性”或“空间局部性”，考查局部性分类。  
复习时应将 Cache 的容量、块大小、相联度、写策略等参数与命中率、访存次数、一致性的关系整理成体系，并注意题干中的程度词。

# 选择题 第 2 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-35-M02_题目.png|题目]]

2. 访问 $Cache$ 系统失效时,通常不仅主存向 $CPU$ 传送信息,同时还需要将信息写入 $Cache$,在此过程中传送和写入信息的数据宽度各为 (    )
A. 块、页
B. 字、字
C. 字、块
D. 块、块

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-35-M02_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。一句话理由：Cache 失效时，主存把所需的一个“字”送给 CPU，同时把包含该字的整个“块”写入 Cache，因此传送和写入的数据宽度分别为“字、块”。

**解题切入点**：拿到题目先明确“谁与谁之间传数据”，并立刻联想到 Cache 与主存之间的数据交换单位是“块/行”，而 CPU 与主存（或 Cache）之间的数据交换单位是“字”。这就像竞赛中“缓存行失效”时要整行回填，但 CPU 只取其中需要的那个元素；本题问的正是“主存→CPU”和“主存→Cache”两个方向的交换单位。

**推演**：

1. 在 Cache 系统中，CPU 访问主存地址时，先查 Cache。若命中，则 CPU 直接从 Cache 中取一个字；若未命中（失效），则需要从主存中调入数据。

2. Cache 与主存之间的数据交换以“块”（或称为“行”）为单位。当 Cache 失效时，主存要把包含目标地址所在的那一整块数据调入 Cache，因此“写入 Cache”的数据宽度是“块”。

3. 与此同时，CPU 当前需要的只是一个具体的存储单元，通常按“字”为单位访问。因此主存在向 Cache 传送整块数据的同时，需要将 CPU 请求的那个字单独送往 CPU，即“主存向 CPU 传送信息”的数据宽度是“字”。

4. 因此，两个数据宽度分别为：传送（主存→CPU）为“字”，写入（主存→Cache）为“块”。

**易错点**：

- 误选 A：把“页”当作 Cache 与主存之间的交换单位。“页”是虚拟存储系统中主存与磁盘之间的交换单位，不是 Cache 系统的单位。
- 误选 D：认为主存向 CPU 传送的也是整块。实际上 CPU 只要求一个字，主存把整块写入 Cache 后，只需把所需字传给 CPU；若按块传 CPU，会与 CPU 的按字寻址方式矛盾。
- 误选 B：混淆两个方向，把“写入 Cache”也当成“字”。实际上 Cache 缺失时，若不整块调入，则下次访问同一块中其他字仍会失效，因此必须以块为单位回填 Cache。

**命题规律**：本题属于 Cache 基本工作原理中的“块/字”单位辨析题，是 408 高频基础考点。常见变式包括：给出 Cache 块大小，计算主存地址划分（标记、块号、块内地址）；或结合缺失时“从主存调块到 Cache，同时送字到 CPU”的时序图考查。复习时应重点掌握：CPU—Cache—主存—磁盘各级存储系统中数据交换单位依次为“字—块—页”，并能画图描述 Cache 失效时的数据流向。

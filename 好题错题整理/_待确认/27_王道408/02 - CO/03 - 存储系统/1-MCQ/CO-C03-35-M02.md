# 选择题 第 2 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-35-M02_题目.png|题目]]

2.访问 $Cache$ 系统失效时,通常不仅主存向 $CPU$ 传送信息,同时还需要将信息写入 $Cache$,在此过程中传送和写入信息的数据宽度各为( ).

(A) 块、页  
(B) 字、字  
(C) 字、块  
(D) 块、块

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-35-M02_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。Cache 失效时，CPU 当前需要的信息是“字”，而主存调入 Cache 的最小单位是“块”，所以“传送/写入”分别为“字、块”。

**解题切入点**：  
拿到题先抓住两条路径：**主存→CPU** 和 **主存→Cache**。可以用“书架取书”来类比：CPU 要一本书（一个字），发现手边书架上没有，于是从大仓库搬一箱书（一个块）放到书架上；同时先把当前需要的那本书递给 CPU。  
因此关键在于分清两个接口的交换单位：  
- CPU 与 Cache 之间：按字；  
- Cache 与主存之间：按块；  
- “页”是虚拟存储中主存与磁盘之间的单位，不能混入 Cache 层次。

**推演**：  
CPU 发出访存地址后，若 Cache 失效，则 CPU 请求的那个数据是一个“字”。  
主存需要把包含该字的整个数据块调入 Cache，因为 Cache 行与主存块的大小对应，块是 Cache 与主存之间的交换单位：

$$
\text{主存}\to Cache:\text{块}
$$

同时，CPU 当前真正要访问的不是整块，而是块内某一个“字”，所以主存传给 CPU 的数据宽度是“字”：

$$
\text{主存}\to CPU:\text{字}
$$

因此题中“传送”对应“字”，“写入 Cache”对应“块”，选 **C**。

**易错点**：  
- 错选 D：误以为主存向 CPU 传送时也按块。实际上 CPU 一次访存只需要一个字。  
- 错选 B：只记得 CPU 与 Cache 之间按字，却忽略了 Cache 与主存之间按块交换。  
- 错选 A：把“页”这个虚存单位混入 Cache 层次。Cache 与主存之间是“块”，不是“页”。  
- 规避方法：画出“CPU—Cache—主存—磁盘”的层次结构，在每条路径上标注交换单位，做题时直接对照。

**命题规律**：  
本题考点是 Cache 的基本工作原理，尤其是“字/块”两级数据交换单位。常见变式有：给出块大小 $64$ B、字长 $4$ B，问一次 Cache 缺失从主存调入多少数据，或 CPU 一次获得多少数据；也可结合 Cache 容量、块大小求标记位、块内地址位数。  
复习时建议把“CPU–Cache：字；Cache–主存：块；主存–磁盘：页/块”这一组对应关系记牢，再配合 Cache 地址结构计算题巩固。

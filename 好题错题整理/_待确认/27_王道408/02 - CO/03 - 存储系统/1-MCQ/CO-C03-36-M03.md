# 选择题 第 3 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-36-M03_题目.png|题目]]

3. 虚拟存储器的常用管理方式有段式、页式、段页式,对于它们在与主存交换信息时的单位,以下表述正确的是(  ).

(A) 段式采用“页”
(B) 页式采用“块”
(C) 段页式采用“段”和“页”
(D) 页式和段页式均仅采用“页”

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-36-M03_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。  
理由：段式以“段”为单位与主存交换，页式以“页”（物理侧也称“块/页框”）为单位交换，段页式虽然逻辑上先分段、段内再分页，但真正与主存交换信息时仍以固定大小的“页”为单位，所以“页式和段页式均仅采用‘页’”正确。

**解题切入点**  
拿到题目，第一件事不是背选项，而是明确一个核心问题：**虚拟存储器与主存交换信息时，到底是按“用户逻辑单位”交换，还是按“物理可管理单位”交换？**  
可以类比“搬家”：段式是把一大件家具整体搬，页式是把所有东西拆成统一规格的箱子搬，段页式则是先把家具按房间分类，再统一装箱子；但真正搬运时，用的还是统一箱子，而不是整个房间。  
所以看到“段页式采用段和页”时要警惕：分段只是逻辑组织，交换单位仍应是页。

**推演**  

1. **段式虚拟存储器**  
   用户程序按逻辑结构划分为若干段，如代码段、数据段、堆栈段等。每段长度可变，段内地址连续。  
   主存也按“段”来分配和管理，当需要从辅存调入信息时，以整个“段”为单位进行交换。  
   因此段式与主存交换信息的基本单位是“段”，不是“页”。  
   所以 A 错。

2. **页式虚拟存储器**  
   虚拟地址空间按固定大小划分为“页”，主存空间也按相同大小划分为“页框”，也称为“物理块”或“块”。  
   页表完成从虚拟页号到物理页框号的映射。发生缺页时，以“页”为单位从磁盘调入主存，或者以“页”为单位调出。  
   由于主存侧的物理单位常叫“块/页框”，所以有时也说“以块为单位交换”。但从虚拟存储器管理方式的角度看，基本单位仍是“页”。B 的表述“页式采用块”不够严谨，不是最佳答案。

3. **段页式虚拟存储器**  
   段页式先按逻辑结构分段，再对每一段按固定大小分页。段表记录每段对应的页表始址和段长，页表记录每页对应的物理页框号。  
   地址结构为：  
   $$
   虚拟地址 = 段号 + 段内页号 + 页内偏移
   $$  
   虽然逻辑上存在“段”，但主存与辅存交换信息时，并不以整个段为单位，而是以固定大小的“页”为单位。这样既能保留段式逻辑清晰、便于共享保护的优点，又能避免段式因段长可变导致的外碎片问题。  
   所以 C 说“段页式采用‘段’和‘页’”是错误的；D 说“段页式仅采用‘页’”是正确的。

4. 综合判断：  
   - A 错，段式采用“段”。  
   - B 表述不严谨，页式应说采用“页”或“页/块”。  
   - C 错，段页式交换信息时以“页”为单位，不以“段”为单位。  
   - D 正确。

**易错点**  

- 易误选 B：页式管理中主存确实按“块/页框”划分，且块大小等于页面大小，所以很多教材也说“以块为单位交换”。但本题更强调“虚拟存储器管理方式的交换单位”，通常表述为“页”，故 B 不是最准确选项。  
- 易误选 C：受“段页式 = 分段 + 分页”影响，误以为交换单位也是“段 + 页”。实际上“段”只是逻辑划分，物理交换必须用固定大小的“页”，否则无法有效管理主存和辅存。  
- 易误选 A：没有记清段式的基本交换单位是“段”，段长可变，所以不能以固定页交换。  
- 复习时要注意区分：**逻辑划分单位**、**物理分配单位**、**主存与辅存交换单位**。三者不一定相同，尤其段页式最容易混淆。

**命题规律**  
本题属于计算机组成原理中“存储系统—虚拟存储器”部分的基础概念题，考点为三种虚拟存储器管理方式的基本特征。常见变式包括：  
- 问“段页式地址变换需要查几次表？”  
- 问“缺页中断由哪一级机构处理？”  
- 问“页表项中需要包含哪些字段？”  
- 与 TLB、Cache 结合考查访存过程。  

复习建议：把三种管理方式做成对比表，分别写清：逻辑划分单位、物理划分单位、交换单位、地址结构、需要查的表、优点和缺点。尤其要咬准“段页式以页为单位交换”，这是选择题和简答题都容易出现的考点。

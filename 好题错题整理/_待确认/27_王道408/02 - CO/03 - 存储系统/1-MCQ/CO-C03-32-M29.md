# 选择题 第 29 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-32-M29_题目.png|题目]]

29.【2010统考真题】下列有关 $RAM$ 和 $ROM$ 的叙述中,正确的是（  ）

$I$. $RAM$ 是易失性存储器,$ROM$ 是非易失性存储器

$II$. $RAM$ 和 $ROM$ 都采用随机存取方式进行信息访问

$III$. $RAM$ 和 $ROM$ 都可用作 $Cache$

$IV$. $RAM$ 和 $ROM$ 都需要进行刷新

A. 仅 $I$ 和 $II$
B. 仅 $II$ 和 $III$
C. 仅 $I$、$II$ 和 $III$
D. 仅 $II$、$III$ 和 $IV$

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-32-M29_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A。  
I、II 正确；III 错在“Cache 通常用 SRAM 实现，而 SRAM 属于 RAM，ROM 只读不能作为 Cache”；IV 错在“ROM 不需要刷新，SRAM 也不刷新”。

**解题切入点**：  
拿到题目先抓存储器的几个基本属性：易失性、访问方式、可写性、是否需要刷新。可以打个比方：  
- RAM 像“临时变量”，掉电就丢；ROM 像“只读配置文件”，掉电仍在。  
- “随机存取”像数组按下标直接访问，而不是像磁带那样必须顺序扫描。  
- Cache 像“可读写的热数据缓存池”，必须能随时替换内容，因此不能用只读的 ROM。  
- “刷新”像定时给电容器“续电”，只有动态存储器才需要。

逐条判断题干即可。

**推演**：  

**命题 I：RAM 是易失性存储器，ROM 是非易失性存储器**  
正确。  
RAM 包括 SRAM 和 DRAM，无论哪种，断电后存储信息都会丢失；ROM 通过熔丝、浮栅等结构存储信息，断电后信息不丢失，所以是非易失性存储器。

**命题 II：RAM 和 ROM 都采用随机存取方式进行信息访问**  
正确。  
“随机存取”指可以按地址直接访问任意存储单元，访问时间与存储单元的位置无关。RAM 和 ROM 都通过地址译码选中存储单元，因此都属于随机存取存储器。ROM 虽然只读，但“只读”限制的是写入能力，不影响“随机访问”方式。

**命题 III：RAM 和 ROM 都可用作 Cache**  
错误。  
Cache 是 CPU 与主存之间的小容量高速缓冲存储器，通常用 SRAM 实现，而 SRAM 是 RAM 的一种。Cache 在运行过程中需要不断写入新调入的块、替换旧块，还要支持写操作和 cache 一致性维护，因此必须可读可写。ROM 是只读存储器，不能写入新内容，不能用作 Cache。

**命题 IV：RAM 和 ROM 都需要进行刷新**  
错误。  
刷新是针对 DRAM 而言的：DRAM 用电容存储电荷，电荷会泄漏，所以需要周期性刷新。SRAM 用双稳态触发器存储信息，不需要刷新。ROM 用非易失性结构存储信息，也不需要刷新。因此“RAM 和 ROM 都需要刷新”说法错误。

综上，正确的是 I 和 II，故选 A。

**易错点**：  
1. 误以为 ROM 不是随机存取存储器。  
   ROM 虽然只读，但它仍然按地址随机读取，属于随机存取方式。  
2. 误以为所有 RAM 都需要刷新。  
   只有 DRAM 需要刷新，SRAM 不需要刷新。  
3. 误以为 ROM 可用作 Cache。  
   Cache 必须可读可写，ROM 只读，不能支持替换和写操作。  
4. 混淆“Cache 可以用 SRAM”和“Cache 可以用 RAM”。  
   Cache 一般用 SRAM，SRAM 是 RAM 的一种；但不能说“ROM 可用作 Cache”。

**命题规律**：  
本题属于存储系统基础题，考查 RAM、ROM、SRAM、DRAM 和 Cache 的基本概念。常见变式有：  
- CPU 中的 Cache 通常采用什么存储器实现？  
- DRAM 为什么需要刷新？  
- 哪些存储器断电后信息丢失？  
- ROM 和 RAM 的访问方式有何异同？  
- 主存、Cache、磁盘分别适合用什么存储器件？

复习时应把 SRAM、DRAM、ROM、Flash 等放在一张表中对比：是否易失、是否可写、访问方式、是否需要刷新、典型用途。抓住“Cache 用 SRAM、主存用 DRAM、固件用 ROM”这条主线，这类概念题就能快速判断。

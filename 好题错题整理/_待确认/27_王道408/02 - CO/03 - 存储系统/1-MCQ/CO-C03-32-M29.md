# 选择题 第 29 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-32-M29_题目.png|题目]]

29.【2010 统考真题】下列有关 $RAM$ 和 $ROM$ 的叙述中,正确的是 (    )

I. $RAM$ 是易失性存储器,$ROM$ 是非易失性存储器

II. $RAM$ 和 $ROM$ 都采用随机存取方式进行信息访问

III. $RAM$ 和 $ROM$ 都可用作 $Cache$

IV. $RAM$ 和 $ROM$ 都需要进行刷新

(A) 仅 I 和 II

(B) 仅 II 和 III

(C) 仅 I、II 和 III

(D) 仅 II、III 和 IV

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-32-M29_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A（仅 I 和 II）。理由：RAM 是易失性存储器、ROM 是非易失性存储器，且二者都支持按地址随机访问；ROM 不能用作 Cache 且不需要刷新，因此 III、IV 错误。

**解题切入点**：看到这类存储器判断题，先抓住三个基本维度：易失性、存取方式、是否需要刷新。再用“角色分工”来类比：RAM 像可擦写的草稿纸，断电后内容消失；ROM 像刻好的石碑，内容永久保存；Cache 像手边的工作台，必须能快速读写且不能是只读的。这样定位考点后，逐条判断即可。

**推演**：

I. 判断易失性：  
RAM（Random Access Memory）在断电后信息会丢失，属于易失性存储器；ROM（Read Only Memory）断电后信息仍可保持，属于非易失性存储器。故 I 正确。

II. 判断存取方式：  
“随机存取”是指可以按地址直接访问任意存储单元，且存取时间与存储单元的物理位置无关。RAM 和 ROM 都属于主存，均支持按地址随机访问。ROM 虽然只能读出，但其读出过程也是按地址随机进行的，因此 II 正确。

III. 判断能否用作 Cache：  
Cache 需要能够快速读和写，一般用静态 RAM（SRAM）实现。ROM 是只读存储器，内容不能随时改写，无法作为 Cache 使用。故 III 错误。

IV. 判断是否需要刷新：  
刷新是针对动态 RAM（DRAM）因电容电荷泄漏而需要周期性重写的操作；静态 RAM（SRAM）不需要刷新，ROM 也不需要刷新。因此“RAM 和 ROM 都需要刷新”的说法错误，故 IV 错误。

综上，只有 I 和 II 正确，选 A。

**易错点**：

1. 误认为 RAM 都一定需要刷新。实际上只有 DRAM 需要刷新，SRAM 不需要刷新；ROM 更是完全不需要刷新。  
2. 误认为 ROM 不是随机存取。随机存取强调的是“按地址访问、访问时间与位置无关”，不是“可读可写”，ROM 同样支持按地址随机读出。  
3. 误认为 Cache 可以由任意存储器构成。Cache 要求可读可写、高速访问，ROM 不满足。  
4. 混淆“易失性”与“只读性”：易失性取决于断电后是否丢信息，与是否可写无关。

**命题规律**：考点为存储器的分类与基本性质，常与 SRAM、DRAM、EPROM、Flash 等具体器件结合考查。常见变式包括：判断某类存储器的易失性、是否需要刷新、能否用作 Cache，或与 Cache / 主存层次结构结合出题。复习时应建立一张对比表，从易失性、存取方式、读写能力、是否需要刷新、典型用途等维度整理各类存储器，并准确理解“随机存取”等术语的含义。

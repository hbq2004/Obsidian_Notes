# 选择题 第 12 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-32-M12_题目.png|题目]]

12. 下面有关$ROM$和$RAM$的叙述中,错误的是（ ）
(A) $RAM$是可读可写存储器,$ROM$是只读存储器
(B) $ROM$和$RAM$都采用随机访问方式进行读/写
(C) 系统的主存由$RAM$和$ROM$组成
(D) 系统的主存都用$DRAM$芯片实现

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-32-M12_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。系统主存由 RAM 和 ROM 组成，RAM 常用 DRAM 芯片实现，但 ROM 不是 DRAM 芯片，因此不能说“系统的主存都用 DRAM 芯片实现”。

**解题切入点**：  
这是存储器概念题。拿到题先抓住四个关键概念：RAM/ROM 的定义、随机访问方式、主存组成、DRAM 芯片定位。可以用打比方辅助判断：RAM 像“可写可擦的白板”，ROM 像“出厂刻好的展板”；随机访问像“按门牌号直接找房间”，不是像磁带那样从头顺序扫描。然后逐项排除，特别注意 D 中的“都用”这种绝对化表述。

**推演**：  

- **A 正确**：  
  RAM 是随机存取存储器，运行时可读可写，断电后信息丢失；ROM 是只读存储器，正常工作时只能读出，断电后信息不丢失。  
  所以 A 的说法正确。

- **B 不是本题错误项**：  
  随机访问是指访问任意地址的存储单元所需时间与地址无关，即
  $$
  T_{\text{访问}}(i)=T_{\text{访问}}(j),\quad \forall i,j
  $$
  RAM 和 ROM 都可以按地址直接访问目标单元，因此都属于随机访问方式。  
  需要说明：ROM 正常工作时只能读，不能写；B 的考点是“访问方式”，不是“ROM 可写”。按 408 教材语境，B 不作为错误项。

- **C 正确**：  
  系统主存通常由 RAM 和 ROM 两部分组成。RAM 用来存放运行中的程序和数据，ROM 用来存放引导程序、BIOS 等固定程序，因此 C 正确。

- **D 错误**：  
  DRAM 是动态随机存取存储器，属于 RAM 的一种，具有易失性且需要刷新；ROM 是非易失性存储器，不能用 DRAM 芯片实现。主存中的 ROM 部分不是 DRAM，而且 RAM 部分也不一定只能用 DRAM 实现。因此“主存都用 DRAM 芯片实现”是错误的。

**易错点**：  

1. **误选 B**：看到 B 中“读/写”就以为 ROM 也能写，从而认为 B 错误。其实该选项强调的是“随机访问方式”，ROM 虽然不能写，但读取时仍是随机访问。  
2. **误以为主存只有 RAM**：忽略 ROM 在主存地址空间中的作用，如 BIOS、引导程序等固化在 ROM 中。  
3. **混淆 ROM 与 DRAM**：DRAM 是易失的 RAM 芯片，ROM 是非易失的只读存储芯片，二者不能混为一谈。  
4. **被“都用”迷惑**：D 中“都用 DRAM 芯片实现”属于绝对化表述，主存中只要存在 ROM 或其他非 DRAM 芯片，该说法就不成立。

**命题规律**：  
这是 408 计算机组成原理“存储系统”部分的基础概念题，考查 ROM/RAM 的定义、随机访问方式、主存组成以及芯片类型。常见变式有：比较 SRAM 与 DRAM 的速度、集成度、刷新和价格；判断各种存储器的访问方式；考查 ROM 的类型和易失性等。复习时建议画一张对比表，从“易失性、可写性、访问方式、典型用途”几个维度对比 RAM、ROM、SRAM、DRAM、Flash 等存储器，并警惕“都、全、只、一定”等绝对化措辞。

# 选择题 第 6 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-32-M06_题目.png|题目]]

6. 下列关于存储器的说法中,不正确的是 ( )
(A) 随机存储器和只读存储器不可以统一编址
(B) 在访问随机存储器时,访问时间与存储单元的物理位置无关
(C) 随机存储器($RAM$)芯片可随机存取信息,掉电后信息会丢失
(D) 只读存储器($ROM$)芯片可随机存取信息,掉电后信息不会丢失

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-32-M06_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A。随机存储器（RAM）和只读存储器（ROM）可以统一编址，共同构成主存地址空间，因此“不可以统一编址”说法错误。

**解题切入点**：这类题考查存储器基本概念，先看每个选项中的核心关键词：“随机存取”“只读”“掉电易失”“统一编址”。可以把存储系统类比为书架：RAM 是随手可改的便签本，ROM 是印好的书，二者虽然读写特性不同，但都可以摆在同一个书架上并编上号码，也就是统一编址；而“随机存取”指的是存取时间与位置无关，不是“只能随机读不能顺序读”。

**推演**：

- 随机存取存储器（RAM）：  
  - 可读可写，属于易失性存储器，掉电后信息丢失。  
  - “随机存取”的含义是访问任意一个存储单元所需时间基本相同，与单元物理位置无关。  
  因此选项 B、C 正确。

- 只读存储器（ROM）：  
  - 可随机读出，通常不可在线写入，所以称为“只读”。  
  - 属于非易失性存储器，掉电后信息不丢失。  
  因此选项 D 正确。

- 关于统一编址：  
  计算机主存地址空间可以同时分配给 RAM 和 ROM。例如，系统程序常存放在 ROM 中，用户程序和数据放在 RAM 中，二者在同一地址总线上按地址区分，这就是统一编址。  
  设 RAM 起始地址为 $A_1$，容量为 $C_1$；ROM 起始地址为 $A_2$，容量为 $C_2$，只要地址范围不重叠即可：
  $$
  [A_1,\ A_1 + C_1 - 1] \cap [A_2,\ A_2 + C_2 - 1] = \varnothing
  $$
  所以选项 A 中“不可以统一编址”错误，即本题应选 A。

**易错点**：

1. 误以为“随机存储器”就是“可随机存取”，“只读存储器”就不是随机存取。实际上，ROM 也可以随机读出，只是不能随机写入。
2. 把“统一编址”和“读写特性一致”混淆。RAM 与 ROM 的读写特性不同，但完全可以按照统一地址空间编址，CPU 通过地址和读写控制信号区别访问。
3. 忽视“ROM 掉电不丢失”正确，但 RAM 中也有非易失性 RAM（如 NVRAM、Flash 等），不过题干中的 RAM 一般指传统易失性随机存储器，需按教材常规定义理解。

**命题规律**：本题属于存储器基础概念题，常以“下列说法不正确的是”等形式出现，考查随机存取、易失性、只读性、统一编址等核心术语。变式可能涉及 SRAM、DRAM、Cache、ROM、Flash 的对比，或给出地址范围判断 RAM/ROM 容量分配。复习时应重点掌握：  
- 随机存取的含义；  
- RAM 易失、ROM 非易失；  
- RAM/ROM 可统一编址；  
- 常见存储器分类及各自特点。

# 选择题 第 18 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-32-M18_题目.png|题目]]

18. 下列关于 $DRAM$ 和 $SDRAM$ 的说法中，不正确的是（ ）

(A) 传统 $DRAM$ 芯片与 $CPU$ 采用异步方式交换数据
(B) $SDRAM$ 芯片与 $CPU$ 采用同步方式交换数据
(C) $DRAM$ 需要定期刷新，而 $SDRAM$ 不需要定期刷新
(D) $SDRAM$ 的行缓冲器通常用 $SRAM$ 实现

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-32-M18_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。SDRAM 是“同步动态随机存储器”（Synchronous DRAM），本质上仍是 DRAM，存储单元靠电容保存电荷，必须定期刷新；C 说“SDRAM 不需要定期刷新”不正确。

**解题切入点**：拿到题目先抓概念层次：SDRAM 是 DRAM 的同步改进版，不是 SRAM。判断是否刷新，要看存储单元是用电容还是触发器；判断是同步还是异步，要看接口是否有时钟同步。可以类比：接口改成同步通信，并不改变底层数据结构的本质；SDRAM 接口同步化了，但存储单元仍是动态电容，所以仍需刷新。

**推演**：

1. 传统 DRAM：存储单元是电容，电荷会泄漏，因此必须定期刷新。传统 DRAM 没有与 CPU 时钟同步的接口，CPU 通过 $\overline{RAS}$、$\overline{CAS}$、$\overline{WE}$ 等控制信号和定时关系与它交换数据，所以它是一种异步交换方式。因此 (A) 正确。

2. SDRAM：全称 Synchronous DRAM，即同步动态随机存储器。它增加了时钟信号 CLK，地址线、控制线、数据线等都按照时钟上升沿进行采样或输出，因此 SDRAM 与 CPU 采用同步方式交换数据。因此 (B) 正确。

3. SDRAM 虽然有“Synchronous”前缀，但它仍然是动态存储器。SDRAM 的存储单元依然由电容构成，电容上的电荷会随时间泄漏，所以同样需要定期刷新。SDRAM 通常支持自动刷新、自刷新等机制，但绝不是不需要刷新。因此 (C) 错误。

4. SDRAM 为了提高访问速度，片内设置行缓冲器（row buffer），它通常用 SRAM 或静态锁存电路实现，用来暂存当前激活行的数据，减少重复打开同一行的开销。可见 (D) 正确。

综上，不正确的是 C。

**易错点**：

- 看到 “SDRAM” 中有字母 S，误以为是 SRAM。实际上 SDRAM 是 Synchronous DRAM，仍是 DRAM，必须刷新。
- 把“同步”理解成“不需要刷新”。同步只表示与时钟同步交换数据，不改变 DRAM 存储单元的动态特性。
- 把“DRAM 芯片内不可能有 SRAM”当成真理。SDRAM 的存储阵列是 DRAM，但行缓冲器可以用 SRAM/静态锁存电路实现，两者不矛盾。
- 混淆“刷新”和“重写”：DRAM 刷新不只是重新写入，而是先读出再恢复，防止电容漏电导致数据丢失。

**命题规律**：本题考查存储器分类中的 DRAM、SDRAM、SRAM 辨析，以及 DRAM 的刷新特性。常见变式包括：比较 SRAM 与 DRAM 的速度、集成度、成本、是否刷新；考查 DRAM 的集中刷新、分散刷新、异步刷新方式；考查 DDR SDRAM 在时钟上升沿和下降沿各传一次数据。复习时应牢记“是否刷新只看动态还是静态”“SDRAM 是 DRAM 的同步版本”“DDR 是 SDRAM 的双倍速率版本”这几个关键点。

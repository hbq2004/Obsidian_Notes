# 选择题 第 10 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-31-M10_题目.png|题目]]

10. 下列关于多级存储系统的说法中，正确的有（ ）

$I$. 多级存储系统是为了降低存储成本

$II$. 虚拟存储器中主存和辅存之间的数据调动对任何程序员是透明的

$III$. $CPU$ 只能与 $Cache$ 直接交换信息, $CPU$ 与主存交换信息也需要经过 $Cache$

A. 仅$I$
B. 仅$I$和$II$
C. $I$、$II$和$III$
D. 仅$II$

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-31-M10_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A（仅 I）。  
多级存储系统可以降低平均存储成本；但虚拟存储器中主存和辅存的数据调动对**应用程序员**透明、对**系统程序员**不透明，所以 II 错；CPU 并非在所有 Cache 结构中都“只能”与 Cache 直接交换信息，所以 III 错。

**解题切入点**：  
先圈出选项里的绝对化表述：“任何程序员”“只能”“也必须经过”。这类概念题就像算法竞赛里看到“一定”“所有”就想构造反例一样，把每个绝对化表述与教材结论对照。I 对应存储层次的目标，II 对应虚存的透明性，III 对应 Cache 与 CPU、主存之间的数据通路。

**推演**：  
I. 多级存储系统确实是为了在速度、容量、成本三者之间取得平衡。Cache-主存层次解决速度不匹配，主存-辅存层次解决容量问题；由于辅存容量大且单位价格低，整个存储系统的平均单位存储成本会被拉低。设各级单位价格为 $p_i$，容量为 $S_i$，则平均单位价格约为  
$$
\bar c = \frac{\sum p_i S_i}{\sum S_i}
$$
它接近大容量低价格的辅存，因此 I 正确。

II. 虚拟存储器中，主存和辅存之间的数据调动由操作系统和硬件共同完成。对普通应用程序员来说，他看不到换入换出过程，所以是透明的；但系统程序员要编写页表管理、缺页处理、换页算法等，所以虚存对系统程序员**不透明**。题干说“对任何程序员透明”，过于绝对，因此 II 错误。

III. 并非所有 Cache 结构中 CPU 都只能与 Cache 直接交换信息。例如在旁路式 Cache 结构中，Cache 未命中时 CPU 可以直接访问主存，不需要一定经过 Cache；即使某些教材采用“通过式 Cache”模型，那也只是实现方式之一，不能上升为普遍结论。因此“CPU 只能与 Cache 直接交换信息，CPU 与主存交换信息也需要经过 Cache”是错误的，III 不选。

**易错点**：  
1. 把“降低平均存储成本”理解成“一味降低总成本”，多级存储系统的本质是提高性价比，不是所有时候总成本最低。  
2. 混淆虚存透明性：Cache 的调动通常对程序员透明；虚存对应用程序员透明，但对系统程序员不透明。  
3. 把 Cache 数据通路记死成“CPU 只能访问 Cache”，忽略旁路式 Cache 以及 Cache 未命中时 CPU 可直接访问主存的情况。  

**命题规律**：  
考点是存储层次的目标、透明性划分以及 Cache 与主存的数据通路。常见变式包括：把 II 改成“虚拟存储器对应用程序员透明，对系统程序员不透明”则正确；把 III 改成“Cache 未命中时 CPU 访问主存并调入块”则正确。复习时建议列表对比 Cache-主存层次和主存-辅存层次，重点抓住“目的、管理方、透明性、数据块传送单位”这几个维度。

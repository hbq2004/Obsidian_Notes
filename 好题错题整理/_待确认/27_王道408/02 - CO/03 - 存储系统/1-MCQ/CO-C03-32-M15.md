# 选择题 第 15 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-32-M15_题目.png|题目]]

15. 下列关于存储器层次结构的说法中，错误的是 ( )

A. $Flash$ 存储器读 / 写速度差异显著，读速接近 $RAM$，写速接近 $ROM$

B. 存储器层次结构基于程序局部性原理，通常采用缓冲技术缓解层级间速率差异

C. $Cache$ 位于 $CPU$ 与主存之间，容量通常大于主存，旨在提升平均访问速率

D. 辅存（如机械硬盘）容量大、成本低但速度慢，仅作为主存的补充与备份

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-32-M15_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。Cache 是位于 CPU 与主存之间的高速小容量缓冲存储器，容量远小于主存；它保存的是主存中部分内容的副本，“容量通常大于主存”违背存储层次的基本关系。

**解题切入点**：
题目问“错误的是”，优先抓住存储层次中“容量与速度”的关系。记得一条主线：越靠近 CPU，存储器速度越快、容量越小、单位成本越高；越远离 CPU，速度越慢、容量越大、单位成本越低。看到 C 说“Cache 容量通常大于主存”，就像说“缓存表比原始数据表还大”，显然违背常识，直接锁定 C。

**推演**：
存储层次自上而下一般为：寄存器、Cache、主存、辅存。容量关系为
$$
C_{\text{cache}} \ll C_{\text{main}}, \qquad C_{\text{main}} \ll C_{\text{aux}},
$$
速度关系为
$$
T_{\text{cache}} \ll T_{\text{main}} \ll T_{\text{aux}}.
$$
也就是说，Cache 只是主存中近期使用数据的一个高速小容量副本，不可能容量大于主存。

逐项判断：

- A 正确：Flash 是可电擦写、断电不丢失的半导体存储器，读操作明显快于写/擦除操作。教材中常把 Flash 描述为“读速接近 RAM、写速较慢”，因此不能判为错误。
- B 正确：程序具有时间局部性和空间局部性，存储层次正是利用局部性原理，用 Cache、缓冲器等上层小容量高速存储器来缓解相邻层次间的速度差异。
- C 错误：Cache 位于 CPU 与主存之间没错，它确实用于提高平均访问速度，但容量应当远小于主存，不是“通常大于主存”。
- D 基本正确：辅存如机械硬盘容量大、单位成本低、速度慢，用于存放当前暂不使用的程序和数据，是主存的后备与补充。

用平均访存时间也能辅助理解：
$$
T_a = T_{\text{hit}} + (1-H)T_{\text{miss}},
$$
其中 $H$ 是命中率。Cache 的性能来自高命中率和短命中时间，而不是容量超过主存。

**易错点**：
- 误选 A：对 Flash 不熟悉，看到“读速接近 RAM”觉得夸张。要记住考研教材中 Flash 的定位是“读快写慢、非易失、可电擦写”，不要用现代 SSD 的实测延迟否定教材定性。
- 误选 D：D 中“仅作为主存的补充与备份”中的“仅”字略显绝对，但在本题语境下，辅存作为主存的后备/补充层次没有原则性错误；真正硬伤是 C 的容量关系。
- 记反容量大小：正确应为“Cache 容量 < 主存容量 < 辅存容量”，不是“Cache 容量大于主存”。

**命题规律**：
本题属于存储器层次结构的基础概念题，常考各层存储器的容量、速度、价格关系，以及 Cache、Flash、辅存等器件的特点。常见变式有：计算平均访存时间 $T_a = T_{\text{hit}} + (1-H)T_{\text{miss}}$；考查局部性原理；考查主存-辅存层次与虚拟存储器关系。复习时应把“寄存器—Cache—主存—辅存”的层次关系图记熟，重点区分“Cache 为什么小但快”和“辅存为什么大但慢”。

# 选择题 第 3 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-34-M03_题目.png|题目]]

3. 下列有关磁盘存储器读/写操作的叙述中,错误的是( )
A. 最小读/写单位可以是一个扇区
B. 采用直接存储器存取$DMA$方式进行输入/输出
C. 按批处理方式进行一个数据块的读/写
D. 磁盘存储器可与$CPU$交换盘面上的存储信息

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-34-M03_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。磁盘存储器属于外部存储器，CPU 不能直接与盘面上的数据进行交换，需通过磁盘控制器/DMA 先将数据读入主存，再由 CPU 访问。

**解题切入点**：看到“磁盘存储器读/写操作”，先锁定两个考点：磁盘是“块设备”以及外存的访问路径。可类比为：CPU 是“主人”，磁盘是“仓库”，DMA 是“搬运工”；主人不能直接去仓库翻货物，必须由搬运工把整箱货搬到主存（货架）后主人才能取用。因此“磁盘可与 CPU 直接交换盘面数据”这一类说法最可疑。

**推演**：

1. A 正确：磁盘的寻址和读写基本单位是扇区，扇区可视为一个数据块，因此最小读/写单位可以是一个扇区。

2. B 正确：磁盘与主存之间的数据交换通常采用 DMA 方式。由 DMA 控制器在磁盘存储器和主存之间成块传输数据，只在传输前/后由 CPU 进行参数设置和中断响应，减少 CPU 的 I/O 开销。

3. C 正确：磁盘读/写操作是按数据块进行的，一次可成批读/写一个或多个扇区，而不是逐字节/逐字交换。这里的“批处理”应理解为“按数据块成批处理/交换”，不是操作系统中的“批处理作业”概念。

4. D 错误：磁盘是外存，CPU 不能直接访问外存中的字或字节，也不能直接与“盘面上的存储信息”进行数据交换。实际过程是：CPU 向磁盘控制器发出读/写命令，磁盘控制器控制磁头定位，由 DMA 控制器将盘面上的扇区数据读入主存（或从主存写入盘面），之后 CPU 再通过主存访问这些数据。

**易错点**：

- 容易误选 C：把“批处理”误解为操作系统中的“批处理系统”，但本题语境是磁盘按数据块成批读写。
- 容易误把 D 当成正确：认为“CPU 可以通过 I/O 指令和磁盘交换信息”，但 CPU 只能向磁盘控制器发命令、读状态，不能直接交换盘面上的数据。
- 忽略磁盘是块设备：误以为磁盘可以按字节/字直接随机访问，导致对 A、C 的判断出错。

**命题规律**：考点集中在外存设备的“块设备”属性、I/O 控制方式（DMA），以及“CPU 不能直接访问外存”的分层存储思想。常见变式有：问磁盘与主机交换信息采用哪种 I/O 方式（DMA）；问磁盘最小读写单位（扇区/块）；问 CPU 启动磁盘 I/O 后的数据传输流程。复习时应对比内存与外存：内存按字节编址、CPU 可直接访问；磁盘按扇区/块编址、CPU 不能直接访问。数据通路可概括为：外设 $\rightarrow$ DMA 控制器 $\rightarrow$ 主存 $\rightarrow$ CPU。

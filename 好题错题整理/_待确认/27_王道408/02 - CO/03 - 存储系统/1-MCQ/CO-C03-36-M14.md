# 选择题 第 14 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-36-M14_题目.png|题目]]

14.【2015 统考真题】假定编译器将赋值语句“$x = x + 3;$”转换为指令“$add\ xaddr, 3$”，其中 $xaddr$ 是 $x$ 对应的存储单元地址。若执行该指令的计算机采用页式虚拟存储管理方式，并配有相应的 $TLB$，且 $Cache$ 使用直写方式，则完成该指令功能需要访问主存的次数至少是 ( ).

A. 0
B. 1
C. 2
D. 3

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-36-M14_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。最理想情况下（TLB、Cache 均命中），取指与读 $x$ 都无需访问主存，但 Cache 采用直写方式，写回 $x$ 时必须同时写主存，因此至少访问主存 1 次。

**解题切入点**：看到“至少”就按最优情况考虑：TLB 命中、Cache 命中、不发生缺页。再看 Cache 采用直写方式，这说明“写操作”是不可避免的访存点。指令 `add xaddr, 3` 本质是对内存单元 $xaddr$ 做“读—加—写”，所以重点在于：读可以命中 Cache，但直写方式的写必须穿透到主存。

**推演**：设完成该指令需要访问主存的次数为 $N$。最优情况下：

1. 取指令：指令 Cache 命中，不需要访问主存，次数为 0。
2. 地址翻译：$xaddr$ 是虚拟地址，TLB 命中得到物理地址，不需要到主存查页表，次数为 0。
3. 读操作数 $x$：数据 Cache 命中，不需要访问主存，次数为 0。
4. 执行加法：$x + 3$。
5. 写回结果：Cache 采用直写方式，写 Cache 的同时也必须写主存，因此至少需要 1 次主存访问。

所以：
$$
N_{\min}=0+0+0+1=1.
$$

若 Cache 采用写回方式，写命中时不立即写主存，则可以达到 0 次；但本题指定直写，因此至少为 1 次。

**易错点**：

- 误选 A：只看到 Cache 命中，忽略了直写方式要求写主存。
- 误选 C 或 D：把 TLB 缺失、Cache 缺失、页表访问都计入“至少”的情况；“至少”应取 TLB 和 Cache 全部命中。
- 混淆 TLB 与页表：TLB 命中就不需要访问主存中的页表。
- 只看“加”不看赋值：`add xaddr, 3` 是读-改-写内存单元，不能只考虑读，不考虑写回。

**命题规律**：考点是“TLB + Cache + 虚拟存储器 + 指令执行过程”的综合访存次数计算。常见变式包括：Cache 改用写回法、写分配/非写分配、TLB 缺失、需要查页表、多级 Cache、不同指令格式等。做题时应画出“虚拟地址 → TLB → 物理地址 → Cache → 主存”的访问路径，并记住：TLB/Cache 命中不访问主存；直写方式在写命中时仍必须写主存；写回方式在写命中时不立即写主存。

# 选择题 第 8 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-31-M08_题目.png|题目]]

8. 在多级存储体系中，“$Cache$－主存”结构的作用是解决（ ）的问题.

(A) 主存容量不足  
(B) 主存与辅存速度不匹配  
(C) 辅存与 $CPU$ 速度不匹配  
(D) 主存与 $CPU$ 速度不匹配

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-31-M08_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。Cache－主存结构利用程序局部性原理，通过高速缓存缓解 CPU 与主存之间速度不匹配的矛盾。

**解题切入点**：拿到题目先识别“Cache－主存”这一特定层次——它属于“速度匹配”问题，而非容量问题。可以类比算法竞赛中的“记忆化搜索”：把频繁访问的中间结果存入高速缓存，避免每次都从慢速存储器重新计算，从而提升整体速度。

**推演**：
- 多级存储体系通常分为三层：Cache（高速缓存）、主存（内存）、辅存（外存）。  
- 各层之间的主要矛盾不同：  
  - **Cache－主存层次**：CPU 的速度远高于主存，导致 CPU 经常等待主存数据。Cache 是 SRAM（静态随机存取存储器），速度接近 CPU，但容量小，通过硬件自动管理，利用局部性原理减少主存访问次数，解决速度不匹配问题。  
  - **主存－辅存层次**（虚拟存储器）：主存容量有限，无法容纳所有程序和数据，需要辅存（如硬盘）提供大容量，解决主存容量不足问题，同时辅存速度远慢于主存，因此这个层次主要解决容量问题，也涉及速度差异，但核心是容量。  
- 逐项分析选项：  
  - (A) 主存容量不足：由主存－辅存（虚拟存储器）解决，错误。  
  - (B) 主存与辅存速度不匹配：主存速度远快于辅存，但这不是 Cache－主存层次关注的问题，且辅存非直接与主存通信于该层次，错误。  
  - (C) 辅存与 CPU 速度不匹配：辅存与 CPU 之间隔着主存，通常不直接讨论该匹配，且 Cache 不介入辅存，错误。  
  - (D) 主存与 CPU 速度不匹配：正是 Cache 存在的直接原因，正确。  

因此，答案为 (D)。

**易错点**：
1. **混淆层次功能**：误以为 Cache 解决主存容量不足（这是虚拟存储器的任务）。  
   *规避*：记住“容量问题看辅存，速度问题看 Cache”。  
2. **忽略“主存”与“辅存”的区别**：选项 B 和 C 都涉及辅存，但 Cache 位于 CPU 和主存之间，不与辅存直接交互。  
   *规避*：明确存储层次中相邻层次的作用：Cache 弥补主存速度，主存弥补辅存容量。  
3. **不假思索选择“主存与辅存速度不匹配”**：部分学生可能认为主存和辅存速度差异大，但 Cache 本身不解决该问题，那是 DMA 或 I/O 技术范畴。  
   *规避*：紧扣题目中“Cache－主存”这一特定结构，不要自行扩展。

**命题规律**：
- **考点定位**：多级存储体系的分层结构及其设计目标，属基础记忆题，常出现在选择题或填空题中。  
- **常见变式**：  
  - 问“虚拟存储器解决什么问题？”→ 答案为主存容量不足。  
  - 问“Cache 的工作原理基于什么？”→ 程序局部性原理。  
  - 综合题：结合命中率、平均访问时间计算，考查 Cache 对速度提升的影响。  
- **复习建议**：  
  1. 牢记存储层次中各层的作用：Cache（速度）、主存（速度+容量）、辅存（容量）。  
  2. 理解局部性原理（时间局部性、空间局部性）如何支撑 Cache 有效性。  
  3. 掌握平均访问时间公式：$T_{\text{avg}} = H \cdot T_{\text{cache}} + (1-H) \cdot (T_{\text{cache}} + T_{\text{mem}})$，其中 $H$ 为命中率。  
  4. 对比三种映射方式（直接、全相联、组相联）的优缺点，常与计算题结合。

# 选择题 第 8 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-31-M08_题目.png|题目]]

8. 在多级存储体系中，“Cache – 主存”结构的作用是解决（　）的问题.
(A) 主存容量不足
(B) 主存与辅存速度不匹配
(C) 辅存与$CPU$速度不匹配
(D) 主存与$CPU$速度不匹配

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-31-M08_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。Cache-主存层次用高速 Cache 使 CPU 尽可能不直接等待主存，主要解决主存与 CPU 速度不匹配的问题。

**解题切入点**：  
先判断题目问的是哪一个存储层次：CPU—Cache—主存—辅存。题干点名“Cache-主存”，应立刻联想到“速度匹配”；而“主存容量不足”对应的是“主存-辅存”层次。可以打比方：CPU 是速度极快的处理者，主存是常用资料库，Cache 是放在手边的“小抄”，这样处理者大多数时候不用直奔资料库，从而跟上 CPU 的速度。

**推演**：  
多级存储体系中，相邻两层组合的目的并不相同：

- “Cache-主存”层次：Cache 采用 SRAM，速度接近 CPU；主存采用 DRAM，速度比 CPU 慢。CPU 访存时先访问 Cache，若命中则直接取得数据；若未命中再从主存取出数据，并将所在块调入 Cache。
- 由于程序具有局部性，CPU 在较短时间内通常只访问一小部分存储区域，所以 Cache 命中率可以很高。设命中率为 $H$，Cache 命中时间为 $T_c$，未命中时访问主存的总开销为 $T_m$，则平均访存时间可近似表示为  
$$
T_a = H T_c + (1-H)T_m
$$
当 $H$ 接近 1 时，$T_a$ 接近 $T_c$，即 CPU 的平均等待时间更接近 Cache 的速度，从而缓解主存与 CPU 的速度不匹配。

各选项辨析如下：

- A 错误：主存容量不足由“主存-辅存”层次解决，虚拟存储器使主存逻辑容量得到扩展；Cache 容量通常比主存更小，不能扩大主存容量。
- B 错误：“主存与辅存速度不匹配”不是 Cache-主存层次要解决的问题；主存-辅存层次主要解决容量问题。
- C 错误：CPU 不能直接访问辅存，辅存信息必须先调入主存；Cache-主存层次不承担“辅存与 CPU 速度匹配”的任务。
- D 正确：Cache-主存层次夹在 CPU 与主存之间，目的是降低 CPU 访问主存的平均延迟，解决主存与 CPU 速度不匹配的问题。

**易错点**：  
1. 混淆“Cache-主存”和“主存-辅存”的作用：一个是解决速度，一个是解决容量。  
2. 看到“速度不匹配”就选 B 或 C，忽略了究竟是哪两个部件之间的速度不匹配。  
3. 误以为 Cache 能增加主存容量：实际上 Cache 只是主存中活跃数据的副本，容量远小于主存，并不改变主存容量。

**命题规律**：  
这是 408 存储系统部分的常考基础概念题，常见变式包括：“Cache-主存层次解决什么问题”“主存-辅存层次解决什么问题”“引入 Cache 的理论基础是什么”“计算 Cache 命中率和平均访存时间”等。复习时应把 CPU、Cache、主存、辅存四个层次画成纵向结构图，对比记忆：

- Cache-主存：解决速度不匹配；
- 主存-辅存：解决容量不足；
- 引入 Cache 的理论基础：程序局部性原理。

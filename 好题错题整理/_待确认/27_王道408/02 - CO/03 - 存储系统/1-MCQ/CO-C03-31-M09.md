# 选择题 第 9 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-31-M09_题目.png|题目]]

9. 存储器分层体系结构中,存储器从速度最快到最慢的排列顺序是 ( )
(A) 寄存器－主存－Cache－辅存
(B) 寄存器－主存－辅存－Cache
(C) 寄存器－Cache－辅存－主存
(D) 寄存器－Cache－主存－辅存

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-31-M09_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。寄存器位于 CPU 内部，速度最快；Cache 位于 CPU 与主存之间，快于主存；主存快于辅存。

**解题切入点**：拿到题目先默写存储层次链：CPU → 寄存器 → Cache → 主存 → 辅存。问“速度”就按“离 CPU 由近到远”排序；好比算法竞赛中：寄存器是手里直接用的变量，Cache 是常用的哈希表，主存是普通数组，辅存是硬盘文件，越“远”越慢。

**推演**：  
存储层次按 CPU 访问的远近分为：

$$\text{寄存器} \rightarrow \text{Cache} \rightarrow \text{主存} \rightarrow \text{辅存}.$$

- 寄存器在 CPU 内部，读写最快；
- Cache 通常用 SRAM 实现，速度明显快于主存；
- 主存通常用 DRAM 实现，速度慢于 Cache；
- 辅存（磁盘、SSD、光盘等）速度最慢，数据需先调入主存才能被 CPU 访问。

若用 $T$ 表示存取时间，则

$$T_{\text{寄存器}} < T_{\text{Cache}} < T_{\text{主存}} < T_{\text{辅存}},$$

所以访问速度

$$V_{\text{寄存器}} > V_{\text{Cache}} > V_{\text{主存}} > V_{\text{辅存}}.$$

对应选项 D。A 错在主存不应排在 Cache 前；B 错在 Cache 被放到了最后；C 错在辅存不应比主存快。

**易错点**：
- 不画层次链，凭印象把 Cache 和主存顺序记反。
- 把“速度最快到最慢”与“容量最大到最小”混淆；若问容量由大到小才是辅存 > 主存 > Cache > 寄存器。
- 误以为 SSD 等辅存“很快”，但它在存储层次中仍属于辅存，访问延迟高于主存，且通常需要先成块调入主存后才能被 CPU 访问。
- 只看选项首尾，没有逐项排除。

**命题规律**：  
这是存储器层次结构的基础题，属于“记忆 + 简单推理”送分点。常见变式是：按容量、价格、速度排序；结合局部性原理问为什么要设置 Cache；或结合命中率计算平均访存时间。复习时要把“寄存器—Cache—主存—辅存”这条主线记牢，并理解后端对应的速度、容量、价格关系。

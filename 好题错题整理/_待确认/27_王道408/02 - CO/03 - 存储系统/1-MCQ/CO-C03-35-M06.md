# 选择题 第 6 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-35-M06_题目.png|题目]]

6. 局部性通常有两种不同的形式: 时间局部性和空间局部性。程序员是否编写出高速缓存友好的代码,就取决于这两方面的问题。对于下面这个函数,说法正确的是 ( )

```c
int sumvec(int v[N]){
    int i, sum=0;
    for (i=0; i<N; i++)
        sum += v[i];
    return sum;
}
```

A. 对于变量$i$和$sum$,循环体具有良好的空间局部性
B. 对于变量$i$、$sum$和$v[N]$,循环体具有良好的空间局部性
C. 对于变量$i$和$sum$,循环体具有良好的时间局部性
D. 对于变量$i$、$sum$和$v[N]$,循环体具有良好的时间局部性

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-35-M06_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。循环变量 $i$ 和累加器 $sum$ 在每次迭代中都被重复访问，所以时间局部性好；数组 $v[N]$ 是按顺序访问的，所以空间局部性好，而不是时间局部性好。

**解题切入点**：  
先看循环体访问了哪些数据，以及每次访问的地址是否相同或相邻。可以把时间局部性理解为“反复看同一页笔记”，空间局部性理解为“顺着页码一页一页往后翻”。本题中 $i$、$sum$ 是反复使用的标量变量，$v$ 是顺序扫描的数组，因此考点定位到：标量变量重用好 $\rightarrow$ 时间局部性；数组顺序访问 $\rightarrow$ 空间局部性。

**推演**：  
函数核心循环是

```c
for (i = 0; i < N; i++)
    sum += v[i];
```

- 对变量 $i$：每轮循环都要读取/更新 $i$，例如判断 `i<N`、执行 `i++`。访问的是同一个变量、同一个存储位置，因此具有良好的时间局部性。但 $i$ 是标量变量，不是按相邻地址连续访问，所以不能说它具有良好的空间局部性。

- 对变量 $sum$：每轮循环都执行 `sum += v[i]`，反复读取并更新同一个 $sum$，因此同样具有良好的时间局部性。$sum$ 也是标量变量，不体现相邻地址连续访问，因此不具备空间局部性。

- 对数组 $v$：访问序列为

$$
\operatorname{addr}(v[0]),\ \operatorname{addr}(v[0])+4,\ \operatorname{addr}(v[0])+8,\ \ldots,\ \operatorname{addr}(v[0])+4(N-1)
$$

假设 `int` 占 4 字节。这是相邻地址的连续访问，因此具有良好的空间局部性；但每个 $v[i]$ 在循环中只被读取一次，不反复访问同一个元素，所以时间局部性差。

因此：

- A 错：$i$、$sum$ 不是空间局部性好。
- B 错：$v$ 虽具有空间局部性，但 $i$、$sum$ 不能说是空间局部性好。
- C 对：$i$、$sum$ 在循环中被反复访问，具有良好时间局部性。
- D 错：$v$ 的时间局部性差。

**易错点**：  
1. 把数组的顺序访问误认为时间局部性。顺序访问是典型的空间局部性；每个元素只访问一次，时间局部性差。  
2. 把循环反复执行等同于所有数据都有时间局部性。循环体代码反复执行，不等于数组元素被反复访问，要看“同一地址是否被重复访问”。  
3. 把标量变量的循环访问误认为空间局部性。标量变量没有相邻数据流，通常体现的是时间局部性。  
4. 忽略选项 B、D 中把 $v$ 和 $i,sum$ 混在一起。$v$ 与 $i,sum$ 的局部性类型不同，不能归入同一结论。

**命题规律**：  
本题属于存储系统-Cache 部分的基础概念题，核心是时间局部性与空间局部性的区分。常见变式包括：矩阵按行/按列求和、改变数组访问步长、循环交换或分块后分析 Cache 命中率。复习时应抓住“同一地址重复访问 $\rightarrow$ 时间局部性；相邻地址连续访问 $\rightarrow$ 空间局部性”，并结合 Cache 块大小和访问步长判断哪些访问能命中。对高速缓存友好的代码，一般应让内层循环按存储顺序连续访问数据，并尽量复用已调入 Cache 的数据块。

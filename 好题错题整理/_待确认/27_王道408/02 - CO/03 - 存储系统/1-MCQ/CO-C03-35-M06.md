# 选择题 第 6 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-35-M06_题目.png|题目]]

6. 局部性通常有两种不同的形式:时间局部性和空间局部性。程序员是否编写出高速缓存友好的代码,就取决于这两方面的问题。对于下面这个函数,说法正确的是 ( )
```c
int sumvec(int v[N]){
    int i, sum=0;
    for (i=0; i<N; i++)
        sum += v[i];
    return sum;
}
```
(A) 对于变量i和$sum$,循环体具有良好的空间局部性
(B) 对于变量i、 $sum$ 和$v[N]$,循环体具有良好的空间局部性
(C) 对于变量i和$sum$,循环体具有良好的时间局部性
(D) 对于变量i、 $sum$ 和$v[N]$, 循环体具有良好的时间局部性

## DeepSeek V4 Flash Max 解析

**答案**：C。  
理由：变量 $i$ 与 $\text{sum}$ 在循环体中被反复访问，具有很好的时间局部性；数组 $v$ 是顺序访问，主要体现空间局部性，所以含 $v$ 的时间局部性选项错误。

**解题切入点**  
拿到这种题目，先把循环中访问的对象分成两类：

- 标量变量：$i$、$\text{sum}$，它们每次循环都访问同一个存储位置，属于**时间局部性**；
- 数组变量：$v[0],v[1],\dots,v[N-1]$，它们是连续内存地址，按顺序访问，属于**空间局部性**。

可以这样理解：时间局部性像“同一件工具反复使用”，空间局部性像“沿着书架顺序取书”。题目选项正是在区分这两类。

**推演**  
局部性的定义：

- **时间局部性**：某个存储位置被访问后，不久可能再次被访问；
- **空间局部性**：某个存储位置被访问后，附近的位置不久也可能被访问。

逐个分析代码中的变量：

1. 变量 $i$  
   循环中每次都要判断 `i < N`、执行 `i++`，所以 $i$ 对应的存储位置（或寄存器）被反复访问。  
   因此，$i$ 具有很好的**时间局部性**。

2. 变量 $\text{sum}$  
   每次循环都执行 `sum += v[i]`，即读取 $\text{sum}$、修改后再写回 $\text{sum}$。  
   它也是同一个存储位置被反复访问，所以具有很好的**时间局部性**。

3. 数组 $v$  
   循环按顺序访问 $v[0],v[1],\dots,v[N-1]$。  
   若设 $A_i$ 为 $v[i]$ 的地址，则数组中相邻元素地址连续：

   $$
   A_{i+1}=A_i+\text{sizeof(int)}
   $$

   因此访问序列是相邻地址上的顺序访问，具有很好的**空间局部性**。  
   但是，在单次遍历中，每个 $v[i]$ 只被访问一次，所以数组元素本身不具有明显的时间局部性。

逐项判断选项：

- A 错：$i$ 和 $\text{sum}$ 是标量变量，体现的是时间局部性，不是空间局部性；
- B 错：$v$ 确实有空间局部性，但 $i$ 和 $\text{sum}$ 不是空间局部性；
- C 对：$i$ 和 $\text{sum}$ 在循环中反复访问，时间局部性好；
- D 错：$v$ 的各个元素只访问一次，不能认为 $v$ 也具有良好时间局部性。

另外，代码参数 `int v[N]` 中的 `v[N]` 表示数组整体/长度，不是访问下标为 $N$ 的越界元素；循环实际访问的是 $v[0]\sim v[N-1]$。

**易错点**  
- 把“sum 每轮都被访问”误判为空间局部性；其实地址不变，是时间局部性。  
- 把“v 被连续访问”误判为时间局部性；其实地址相邻，是空间局部性。  
- 认为 D 正确，是因为忽略了 $v$ 的每个元素只被访问一次，单遍扫描下时间局部性很差。  
- 编译器可能把 $i$、$\text{sum}$ 优化到寄存器中，这并不改变“它们被高频复用”的结论，只是使访问层次更靠近 CPU。

**命题规律**  
本题是 408 计算机组成原理中“存储层次与局部性”的经典考点。命题人常用简短 C 程序考查：

- 区分时间局部性和空间局部性；
- 判断数组行优先、列优先访问时的高速缓存友好性；
- 考查循环交换、矩阵分块等优化方法。

常见变式如：

```c
// 按行访问二维数组，空间局部性好
int sumarrayrows(int a[M][N]) {
    int i, j, sum = 0;
    for (i = 0; i < M; i++)
        for (j = 0; j < N; j++)
            sum += a[i][j];
    return sum;
}
```

若把内外层循环交换，变成按列访问，空间局部性就会变差。复习时应重点掌握：**从被访问地址序列出发，判断是“重复访问同一地址”还是“访问相邻地址”**。

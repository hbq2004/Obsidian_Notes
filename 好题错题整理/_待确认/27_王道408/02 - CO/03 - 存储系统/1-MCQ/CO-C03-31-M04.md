# 选择题 第 4 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-31-M04_题目.png|题目]]

4. 在下列几种存储器中，$CPU$ 不能直接访问的是 ( )
(A) 硬盘
(B) 内存
(C) $Cache$
(D) 寄存器

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-31-M04_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A。CPU 不能直接访问的是硬盘，因为硬盘属于外部存储器，必须先将数据调入内存（主存）后，CPU 才能通过地址总线访问。

**解题切入点**：拿到题目先分清存储器的层次结构：CPU 能直接访问的是“内存储器”类，包括寄存器、Cache、主存（内存）；而硬盘属于“外存”，需要通过 I/O 接口与主存交换数据。可以类比做题时的“输入输出缓冲区”：CPU 不能直接读磁盘文件，必须先由操作系统把文件读入内存缓冲区，再让 CPU 处理。

**推演**：
- CPU 直接访问的存储器应当与地址总线、数据总线直接相连，且能按地址随机读写。  
- 寄存器（Register）位于 CPU 内部，是 CPU 工作寄存器的组成部分，显然可直接访问。  
- Cache 位于 CPU 与主存之间，由硬件管理，CPU 可以直接访问（如取指、取数时先访问 Cache）。  
- 内存（主存）通过存储总线与 CPU 相连，CPU 可以按地址直接读写字或字节，因此也可直接访问。  
- 硬盘属于辅助存储器，其数据不能直接在 CPU 与磁盘之间传输；CPU 必须通过磁盘控制器（I/O 接口）将磁盘数据先送入主存，然后才能访问。因此硬盘是 CPU **不能直接访问**的存储器。

综上，符合题意的是选项 A。

**易错点**：
1. 误选 C（Cache）：认为 Cache 是“高速缓冲存储器”，是给主存用的，CPU 不能直接访问。实际上，CPU 访问主存时先访问 Cache，Cache 对 CPU 是“透明”的，但是 CPU 可以直接从 Cache 中取指令和数据，因此 Cache 是可直接访问的。
2. 误选 D（寄存器）：寄存器虽然种类多（如通用寄存器、指令寄存器、程序计数器等），但都位于 CPU 内部，CPU 必然能直接访问。若把“寄存器”误认为“内存中的寄存器”则会犯错。
3. 混淆“CPU 直接访问”与“程序直接访问”：外存设备（如硬盘）的文件需经过文件系统、设备驱动程序等软件层次，但即使从硬件角度看，CPU 也不能把硬盘的扇区当作内存单元直接按地址读写。
4. 规避方法：牢记存储层次中，CPU 能直接访问的是：寄存器 → Cache → 主存；外存（硬盘、光盘、U 盘等）必须调入主存后才能被 CPU 访问。

**命题规律**：
- 考点定位：计算机组成原理中“存储器的层次结构”与“存储器的分类”。重点考查 CPU 与各类存储器的关系，属于基础概念题。
- 常见变式：  
  ① 问“下列存储器中，CPU 可以直接访问的是？”把选项换成光盘、U 盘、主存、Cache 等。  
  ② 问“虚拟存储器中，CPU 直接访问的是哪一层？”答案仍是主存（内存），外存（磁盘）作为虚拟存储器的后备存储，不直接被 CPU 访问。  
  ③ 结合“Cache 的读写过程”“程序局部性原理”等考查存储层次的作用。
- 复习建议：熟记存储层次结构图（寄存器 → Cache → 主存 → 外存），理解每层的作用、速度、价格和访问方式。尤其注意“CPU 直接访问”指的是按地址随机访问，而不是通过 I/O 方式访问。掌握这一点，这类送分题可快速作答。

# 选择题 第 2 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-33-M02_题目.png|题目]]

2. $80386DX$ 是 32 位系统，以 $4B$ 为编址单位，当在该系统中用 $8KB(8K \times 8$ 位)的存储芯片构造 $32KB$ 的存储体时，应完成存储器的 (  ) 设计.
(A) 位扩展
(B) 字扩展
(C) 字位扩展
(D) 字位均不扩展

## DeepSeek V4 Flash Max 解析

**答案**：A。  
理由：$80386DX$ 按 $4B$ 编址，$32KB$ 存储体等价于 $8K\times 32$ 位；芯片为 $8K\times 8$ 位，字数恰好相同、字长不足，因此只需位扩展。

**解题切入点**：  
先明确“目标存储体”的逻辑结构，即“总字数 × 字长”。  
- 总字数 = 存储体容量 ÷ 编址单位；  
- 字长 = 编址单位的位数。  
再看芯片规格“芯片字数 × 芯片字长”。  
把两者做除法：  
$$总芯片数 = \frac{目标存储体总字数}{芯片字数} \times \frac{目标存储体字长}{芯片字长}$$  
若字方向倍数为 $1$、位方向倍数 $>1$，就是位扩展；若位方向倍数为 $1$、字方向倍数 $>1$，就是字扩展；若两者都 $>1$，则是字位扩展。这类似于算法竞赛中先确定“数组大小”和“每个元素类型”，再决定是加行还是加列。

**推演**：  
1. $80386DX$ 是 $32$ 位系统，且题给“以 $4B$ 为编址单位”，即每个可寻址单元存放 $4B=32$ 位数据。  
2. 要构造的存储体容量为 $32KB$，因此它的存储单元数为：
   $$\frac{32KB}{4B}=\frac{32K\times 8 \text{ bit}}{4\times 8 \text{ bit}}=8K$$
   所以目标存储体可写成：
   $$8K\times 32 \text{ 位}$$
3. 所用存储芯片规格为 $8KB(8K\times 8$ 位$)$，即：
   $$8K\times 8 \text{ 位}$$
4. 比较目标存储体与芯片：
   - 字数方向：$8K / 8K = 1$，不需要字扩展；
   - 字长方向：$32 / 8 = 4$，需要将 $4$ 片芯片的数据线分别接到 $32$ 位数据总线的不同字节通道上，即位扩展。
5. 芯片总数：
   $$\frac{8K}{8K}\times \frac{32}{8}=1\times 4=4$$
   这 $4$ 片全部用于位扩展，因此应完成的是“位扩展”设计。

**易错点**：  
- 错选 B（字扩展）：只看到容量从 $8KB$ 增大到 $32KB$，认为扩大了 $4$ 倍就是字扩展。但本题按 $4B$ 编址，$32KB$ 对应 $8K$ 个存储单元，恰与芯片的 $8K$ 个字相同，字方向没有扩展。  
- 错选 C（字位扩展）：误以为既要将 $8K$ 扩展到 $32K$，又要把 $8$ 位扩展到 $32$ 位。实际上按 $4B$ 编址时没有字扩展，只有位扩展。  
- 混淆“编址单位”与“字节”：若按字节编址，$32KB$ 对应 $32K$ 个字节单元，则需字扩展；但题目明确说“以 $4B$ 为编址单位”，不能按字节编址处理。  
- 计算芯片数时不先统一单位，直接用 $32KB/8KB=4$，然后想当然选择字扩展，忽略了数据宽度的匹配问题。

**命题规律**：  
本题考查存储器扩展方式判断，是 $408$ 计算机组成原理中存储器层次结构的常考点。常见变式有：  
- 给出 CPU 地址线、数据线数量和芯片规格，要求计算芯片数量、画出连接图；  
- 把“以 $4B$ 为编址单位”改成“按字节编址”，或改成“按字编址”，答案会随之变化；  
- 结合片选信号、地址译码考查字扩展时的地址分配。  

复习建议：熟练背诵并灵活使用“芯片数 = 总字数/芯片字数 × 总字长/芯片字长”；做题时先确认编址单位和目标存储体的逻辑结构，再分别比较字数和字长，避免被“容量倍数”迷惑。

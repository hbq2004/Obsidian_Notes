# 选择题 第 11 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-32-M11_题目.png|题目]]

11. $U$盘属于（ ）类型的存储器.

(A) 高速缓存
(B) 主存
(C) 只读存储器
(D) 随机存取存储器

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-32-M11_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。理由：$U$ 盘采用闪存（Flash Memory）技术，属于只读存储器（ROM）大类，断电后信息不丢失，且可电擦除重写。

**解题切入点**：拿到题目先定位考点：存储器的分类方式。不要被“U 盘可以写入”干扰，而要把闪存芯片的物理特性与计算机组成原理中的存储器分类对应起来。可以把存储器分类想象成“不同等级的仓库”：Cache 是高速临时工位，主存是当前工作的桌面，ROM 是“只读档案柜”，RAM 是“随手可改的草稿纸”。$U$ 盘属于“可擦写的档案柜”，应归入 ROM 类。

**推演**：

存储器分类可从多个角度进行：

1. 按存储介质分类：半导体存储器、磁表面存储器、光盘存储器等。$U$ 盘内部是 Flash Memory，属于半导体存储器。

2. 按存取方式分类：
   - 随机存取：访问时间与存储位置无关，如 RAM、ROM；
   - 顺序存取：按顺序访问，如磁带；
   - 直接存取：先直接定位到大致区域再顺序查找，如磁盘。

   $U$ 盘可以按地址直接访问任意存储单元，因此它也是“随机存取”的。但是“随机存取存储器”这个术语在计算机组成原理中通常特指 RAM（Random Access Memory），而 RAM 是易失性存储器，断电后信息丢失。$U$ 盘断电后信息不丢失，不是 RAM。

3. 按是否易失分类：
   - 易失性存储器：如 SRAM、DRAM；
   - 非易失性存储器：如 ROM、Flash Memory、磁盘、光盘。

   $U$ 盘采用 Flash Memory，属于非易失性半导体存储器。

4. 按在计算机层次结构中的作用分类：
   - 高速缓存（Cache）：位于 CPU 与主存之间，速度极高，容量小，通常由 SRAM 组成；
   - 主存：直接与 CPU 交换信息，通常由 DRAM 组成；
   - 外存（辅助存储器）：如硬盘、$U$ 盘、光盘，用于长期保存信息。

   $U$ 盘属于外存，但不是选项中的“主存”，更不是“高速缓存”。

综合判断：选项中的“只读存储器”（ROM）在计算机组成原理中是一个大类，它不仅包括掩膜 ROM，还包括 PROM、EPROM、EEPROM、Flash Memory。Flash Memory 具有 ROM 的非易失性特征，同时可以进行电擦除和重写，因此 $U$ 盘属于只读存储器（ROM）类型。

故正确选项为 C。

**易错点**：

- 易错选 D（随机存取存储器）：因为 $U$ 盘确实支持随机存取，但“随机存取存储器”在计算机组成原理中特指 RAM，RAM 是易失性的，$U$ 盘断电不丢失，所以不是 RAM。要区分“随机存取方式”和“随机存取存储器”两个概念。
- 易错选 A 或 B：将 $U$ 盘误认为内存或缓存。$U$ 盘速度远低于主存和 Cache，且不是 CPU 能直接按字节访问的存储空间，不属于主存或高速缓存。
- 认为“只读存储器”不能写入，从而排除 C。实际上 ROM 大类中的 Flash Memory 支持电擦除重写，只是它的工作方式仍属于非易失性 ROM 类型。

**命题规律**：本题是 408 计算机组成原理中“存储器分类”的基础题，常以选择题形式考查。常见变式包括：固态硬盘（SSD）、SD卡、光盘、Cache、寄存器、DRAM、SRAM 等属于哪类存储器。复习时应掌握存储器按存储介质、存取方式、易失性和作用四种分类标准，尤其注意 RAM 与 ROM 的区别、Cache 与主存的关系、Flash 在 ROM 大类中的位置。这类题属于送分题，但需要概念清晰，避免被“可写”表象误导。

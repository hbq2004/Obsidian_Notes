# 选择题 第 1 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-35-M01_题目.png|题目]]

1.在高速缓存系统中，主存容量为$12MB$，$Cache$容量为$400KB$，则该存储系统的容量为$(\quad)$.
(A) $12MB+400KB$
(B) $12MB$
(C) $12MB-12MB+400KB$
(D) $12MB-400KB$

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-35-M01_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。Cache 是主存内容的副本，对 CPU 透明，不能扩大可寻址存储容量，因此该存储系统的容量仍为主存容量 $12MB$。

**解题切入点**：看到“Cache 容量”和“主存容量”同时出现，要先判断题目问的“容量”是 CPU 可寻址的存储空间，而不是物理存储芯片的总数。Cache 相当于主存的高速“影子”，它只是保存主存中一部分数据的副本，不会增加程序实际能使用的存储空间。可以类比：图书馆的“热门书架”只是馆藏图书的临时副本，不能把图书总量也算上热门书架上的副本数量。

**推演**：

设主存容量为 $C_m=12MB$，Cache 容量为 $C_c=400KB$。

Cache 中的每一块信息都是主存中某一块的副本，CPU 发出的地址仍然是主存地址。无论 Cache 是否命中，CPU 访问的对象都对应主存地址空间中的某个单元。命中时数据虽然从 Cache 读出，但该单元本身已经在主存中计过容量，不能重复计入。

因此，存储系统的有效容量由主存容量决定：

$$
C_{\text{system}}=C_m=12MB
$$

若把物理芯片容量简单相加，会得到 $12MB+400KB$，但这只是 Cache 和主存物理存储芯片容量之和，并不是 CPU 可寻址的存储系统容量。

选项 C 化简为：

$$
12MB-12MB+400KB=400KB
$$

这是把 Cache 容量当成整个系统容量，显然是错误的。选项 D $12MB-400KB$ 也没有任何物理意义，因为 Cache 不是从主存中“划走”一部分得到的，它是独立的高速缓冲存储器。

**易错点**：

1. 误选 A：最常见错误，认为存储系统容量 $=$ 主存容量 $+$ Cache 容量。事实上 Cache 对程序员透明，不是主存容量的扩展。
2. 误选 C：会被冗余的表达式迷惑，化简为 $400KB$，忘记系统容量主要由主存决定。
3. 误选 D：认为 Cache 占用了主存的一部分空间，实际上 Cache 是独立的 SRAM，不会减少主存容量。
4. 概念混淆：如果题目问的是“物理存储芯片总容量”，则可以说总和是 $12MB+400KB$；但本题问“存储系统容量”，应理解为主存可寻址容量。

**命题规律**：本题属于计算机组成原理中“存储系统层次结构”的基础概念题，常出现在选择题前几题。常见变式有：

- 给出主存容量、Cache 容量、块大小，求 Cache 行数、tag 位数；
- 结合映射方式（直接映射、组相联、全相联）计算地址结构；
- 给出命中率和访问时间，计算 Cache-主存系统的平均访问时间；
- 问“增加 Cache 能否扩大主存容量”，答案仍然是“不能”。

复习建议：牢牢抓住“Cache 是主存的副本，对程序员透明”这一原则，凡是涉及存储容量的计算，先区分“物理容量”和“可寻址容量”；再通过地址映射、命中率、缺失开销等题目加深理解。

# 选择题 第 1 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-35-M01_题目.png|题目]]

1. 在高速缓存系统中，主存容量为 $12MB$，$Cache$ 容量为 $400KB$，则该存储系统的容量为( )

(A) $12MB + 400KB$
(B) $12MB$
(C) $12MB - 12MB + 400KB$
(D) $12MB - 400KB$

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-35-M01_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。Cache 与主存构成存储层次时，Cache 对程序员透明，只是主存内容的副本，不扩大可寻址容量，因此存储系统容量仍为主存容量 $12MB$。

**解题切入点**：看到“Cache + 主存”先想一个问题：Cache 能不能增加 CPU 可访问的存储容量？不能。可以把 Cache 理解为“常用书的快捷书架”，快捷书架上的书只是书库中某些书的副本，它不会让图书馆的总藏书量变多。所以本题不是做加法，而是判断逻辑可寻址容量。

**推演**：

1. 在 Cache-主存层次中，CPU 发出的地址是主存地址，而不是 Cache 地址。
2. Cache 中保存的是主存中某些块的副本；CPU 访问时先查 Cache，若命中则直接取数，若未命中则从主存调入对应块并替换 Cache 中的旧块。
3. 因为 Cache 不单独编址，所以它不会增加 CPU 的地址空间。
4. 存储系统的逻辑容量由主存容量决定，即

$$ \text{存储系统容量} = \text{主存容量} = 12MB $$

5. Cache 容量 $400KB$ 只影响命中率、平均访问时间等性能指标，不影响存储系统的容量。

因此正确选项为 B。

**易错点**：

- 最容易误选 A：把“Cache 物理上真实存在的容量”和“存储系统可寻址容量”混为一谈。物理总容量确实是 $12MB+400KB$，但题目问的是存储系统的逻辑容量。
- 误选 C：$12MB-12MB+400KB=400KB$，这是把 Cache 容量当成了整个存储系统容量，忽略了主存才是可寻址空间的主体。
- 误选 D：$12MB-400KB$ 没有实际意义，Cache 并不占用主存地址空间。

规避方法：看到 Cache，立刻反应“缓存=副本，透明，不增加容量”；看到“容量”相关题，先区分“物理容量”和“逻辑可寻址容量”。

**命题规律**：

本题属于存储系统基础概念题，考点是 Cache 的透明性和 Cache-主存层次的工作特点。常见变式有：

- 增加 Cache 容量后，系统容量是否改变？正确：不变，但命中率可能提高。
- 给出 Cache 命中率和访问时间，求平均访问时间：$T = hT_c + (1-h)T_m$。
- 比较 Cache 和虚拟存储器：Cache 解决速度问题，不扩大容量；虚拟存储器解决容量问题，可以扩大逻辑容量。

复习建议：把 Cache 的映射方式、替换算法、写策略、命中率计算作为重点，同时要牢记“Cache 对程序员透明，不改变主存容量”这一基础结论。

# 选择题 第 10 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M10_题目.png|题目]]

10.下列不属于程序控制指令的是( )
A.无条件转移指令
B.有条件转移指令
C.中断隐指令
D.循环指令

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M10_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。中断隐指令不是指令系统中的一条真正指令，而是 CPU 响应中断时硬件自动完成的操作，因此不属于程序控制指令。

**解题切入点**：题目问“不属于程序控制指令”，关键是先明确“程序控制指令”是程序员可见的、由指令系统提供的指令，用于改变程序执行顺序；而“中断隐指令”是硬件隐式完成的中断响应过程，不是程序员可编程的指令。做题时像“分类挑选”一样：凡是能写在程序中、控制跳转的，如无条件/条件转移、循环，都是程序控制指令；凡是硬件自动完成的伪指令，都不属于指令系统。

**推演**：

程序控制指令是计算机指令系统中用于控制程序执行流向的指令，主要包括：

- 无条件转移指令：例如 `JMP addr`，执行后 PC 直接更新为目标地址，程序不再顺序执行；
- 有条件转移指令：例如 `JZ addr`，根据条件码（如 ZF、CF、SF、OF）决定是否跳转；
- 循环指令：例如 `LOOP addr`，通常利用计数器自动判断是否继续循环，本质上是条件转移的一种变体。

这些指令的共同特点是：它们都出现在指令系统中，有操作码，由 CPU 译码并执行，程序员可以在程序中显式编写。

中断隐指令则不同。当 CPU 响应中断时，需要完成“关中断、保存断点、取中断入口地址”等一系列操作。这些操作不是由某一条具体指令完成的，而是由硬件在中断响应周期自动完成的，因此被称为“中断隐指令”。它没有操作码，不在指令系统中，程序员也无法在程序中写出这条指令。所以中断隐指令不属于程序控制指令。

因此：

- A 无条件转移指令：属于程序控制指令；
- B 有条件转移指令：属于程序控制指令；
- C 中断隐指令：不属于程序控制指令；
- D 循环指令：属于程序控制指令。

故正确选项为 C。

**易错点**：

1. **误把“中断隐指令”当作指令**：名字里带“指令”二字，但它不是指令系统中的指令，而是硬件操作序列。注意区分“隐指令”与“机器指令”。
2. **混淆“中断”与“转移”**：中断会改变程序流向，但中断隐指令是响应中断的硬件行为；程序控制指令是程序主动执行的控制流指令。
3. **忽略循环指令**：循环指令在 8086 等 CPU 中确实存在（如 `LOOP`），属于程序控制指令，不要因题干常见“转移”而误选 D。

**命题规律**：本题属于指令系统与 CPU 工作方式的基础概念题，常与“指令类型分类”结合考查。常见变式包括：

- 给出具体指令（如 `CALL`、`RET`、`INT`）判断是否属于程序控制指令；
- 考查“中断隐指令”完成的操作（关中断、保存断点、取中断向量）；
- 结合指令流水线考查哪些操作由硬件完成、哪些由指令完成。

复习时建议将指令系统按功能分类整理：运算类、传送类、程序控制类、输入/输出类，并特别注意“隐指令”不属于指令系统的这个易混点。

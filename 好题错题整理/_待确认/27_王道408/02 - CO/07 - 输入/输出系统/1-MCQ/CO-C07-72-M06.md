# 选择题 第 6 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-72-M06_题目.png|题目]]

6. 下列关于 $I/O$ 指令的说法中,错误的是( )
(A) $I/O$ 指令是 $CPU$ 系统指令的一部分
(B) $I/O$ 指令是机器指令的一类
(C) $I/O$ 指令反映 $CPU$ 和 $I/O$ 设备交换信息的特点
(D) $I/O$ 指令的格式和通用指令的格式相同

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-72-M06_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D  
I/O 指令的格式通常与通用指令格式不同，例如在独立编址方式下，I/O 指令有专门的操作码和设备地址字段，而通用指令格式则包含寄存器、立即数等，因此选项(D)错误。

**解题切入点**：  
拿到题目先抓“I/O 指令”的定义和特点。I/O 指令是 CPU 与 I/O 设备交换信息的专用机器指令，属于系统指令的一部分。关键区分点在于指令格式：I/O 指令是否有独立格式？这取决于编址方式（独立编址 vs 统一编址）。可以类比算法竞赛中的“专用函数”与“通用函数”——专用函数参数固定，格式不同，而通用函数可灵活传递多种参数。

**推演**：  
1. 选项 (A)：I/O 指令是 CPU 系统指令的一部分，正确。系统指令包括特权指令、I/O 指令等，它们控制计算机核心资源。  
2. 选项 (B)：I/O 指令是机器指令的一类，正确。机器指令按功能分为算术逻辑、访存、I/O、控制等。  
3. 选项 (C)：I/O 指令反映 CPU 和 I/O 设备交换信息的特点，正确。它执行数据传输、状态查询、控制命令等操作。  
4. 选项 (D)：I/O 指令的格式和通用指令的格式相同。  
   - 在独立编址方式（如 x86 的 IN/OUT 指令）中，I/O 指令的操作码是专用的（如 x86 中 IN 指令操作码为 0xE4/0xE5），地址字段为 8 位或 16 位端口号，而通用指令（如 MOV、ADD）采用寄存器/立即数/内存地址等格式，两者明显不同。  
   - 在统一编址方式（如 ARM 的内存映射 I/O）中，没有专门的 I/O 指令，而是使用访存指令访问 I/O 设备，此时格式相同，但题目明确提及“I/O 指令”，通常指独立编址下的专用指令，且大多数教材将 I/O 指令视为格式不同于通用指令的一类。  
   因此，该说法错误。

**易错点**：  
- 混淆独立编址与统一编址：初学者可能认为统一编址下 I/O 指令格式与通用指令相同，从而误判 (D) 正确。但题目中“I/O 指令”一般指独立编址的专用指令，故格式不同。  
- 忽略“系统指令”范围：误以为 I/O 指令不是系统指令，但系统指令包括 I/O 指令、特权指令等。  
- 死记硬背：部分同学可能记错，认为 I/O 指令格式与通用指令完全相同，实际上仅统一编址时无专用 I/O 指令。

**命题规律**：  
- 考点定位：I/O 指令的基本概念、编址方式对指令格式的影响。  
- 常见变式：  
  - 将“格式相同”改为“I/O 指令一定包含在通用指令中”（错误，因独立编址有专用 I/O 指令）。  
  - 结合具体体系结构（如 x86、ARM）考查 I/O 指令特点。  
  - 考查 I/O 指令的权限（通常为特权指令）。  
- 复习建议：理解独立编址与统一编址的区别，掌握 I/O 指令的典型操作码、地址字段与通用指令的差异，可结合教材中的指令格式图对比记忆。

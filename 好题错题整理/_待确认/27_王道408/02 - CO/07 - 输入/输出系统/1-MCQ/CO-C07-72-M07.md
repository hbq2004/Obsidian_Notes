# 选择题 第 7 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-72-M07_题目.png|题目]]

7. 下列叙述中，正确的是 (    )
A. 只有 $I/O$ 指令可以访问 $I/O$ 设备
B. 在统一编址下，不能直接访问 $I/O$ 设备
C. 访问存储器的指令一定不能访问 $I/O$ 设备
D. 只有在具有专门 $I/O$ 指令的计算机中，$I/O$ 设备才可以单独编址

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-72-M07_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。I/O 单独编址（独立编址）时，必须使用专门的 I/O 指令来访问 I/O 设备；统一编址下访存指令可以直接访问 I/O 设备，因此 A、B、C 均错误。

**解题切入点**：拿到题目先抓住核心考点：**I/O 设备有哪两种编址方式**，即“统一编址”和“单独编址”。可以类比为：统一编址就像把所有对象放在同一个数组里，用普通下标操作就能访问；单独编址就像另开一个命名空间，必须用专门的接口函数去访问。本题只要分清“是否共用主存地址空间”和“用不用专门 I/O 指令”，就能定位答案。

**推演**：

1. 统一编址方式下，I/O 端口被映射到主存地址空间的某一部分。此时 CPU 访问 I/O 设备时，不需要专门的 I/O 指令，直接使用访存指令（如 load/store）即可完成输入输出。

2. 单独编址方式下，I/O 端口地址空间与主存地址空间是分开的。CPU 为了区分当前访问的是主存单元还是 I/O 端口，通常需要专门设置 I/O 指令，例如 IN、OUT，并配合相应的总线控制信号来区分总线周期。

逐项判断：

- **A 错误**：统一编址下，访问存储器的指令也可以访问 I/O 设备，并非只有 I/O 指令可以访问 I/O 设备。
- **B 错误**：统一编址下，I/O 设备可以被直接访问，因此不能说“不能直接访问”。
- **C 错误**：访问存储器的指令在统一编址下可以访问 I/O 设备，不能绝对地说“一定不能访问”。
- **D 正确**：I/O 设备单独编址必须使用专门的 I/O 指令来访问，这是独立编址方式的基本特征。

因此正确选项为 **D**。

**易错点**：

- 误以为统一编址下不能直接访问 I/O 设备，实际上统一编址就是把 I/O 当作存储器的一部分来访问。
- 误以为访存指令在任何情况下都不能访问 I/O，忽略了统一编址下访存指令就是访问 I/O 的途径。
- 误以为单独编址下也可以使用普通访存指令访问 I/O，实际上单独编址必须依靠专门 I/O 指令来表明访问 I/O 空间。
- 注意题目中“只有……才……”表达的是必要条件，D 选项的意思不是“有 I/O 指令就一定能单独编址”，而是“单独编址必须有 I/O 指令支持”。

**命题规律**：本题属于计算机组成原理中 I/O 方式的经典考点，考查 I/O 编址方式与指令系统的关系。常见变式有：给出“统一编址/独立编址”，判断能否用访存指令；给出 8086 的 IN/OUT 指令，判断其 I/O 编址方式；或结合 M/IO 控制信号区分内存访问周期和 I/O 访问周期。复习时应重点对比两种编址方式的地址空间、访问指令、是否占用主存空间、典型计算机实例，并注意“统一编址”和“单独编址”的区别不能混淆。

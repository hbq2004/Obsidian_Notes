# 选择题 第 53 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M53_题目.png|题目]]

53.【2024统考真题】 $DMA$ 控制 $I/O$ 方式下，设备的输入 / 输出由 $DMA$ 控制器控制完成，此时，$DMA$ 控制器控制的数据传输通路位于 ( ).

(A) $CPU$ 和主存之间

(B) $CPU$ 和 $DMA$ 控制器之间

(C) 设备接口和主存之间

(D) 设备接口和 $DMA$ 控制器之间

## 答案

## DeepSeek V4 Flash Max 解析

**答案**：C。DMA 方式下，数据在设备接口和主存之间直接传输，DMA 控制器只负责控制总线与传输过程，数据不经过 CPU。

**解题切入点**：先抓住 DMA 的核心特征——“在外设和主存之间直接开辟数据通路，CPU 不参与数据搬运”。可以把 DMA 控制器类比为“搬运队长”：它负责指挥（控制总线、发送读写命令），但货物（数据）并不放在队长身上，而是从设备接口直接送往主存。

**推演**：

DMA（Direct Memory Access）的基本思想是：当外设准备好数据后，由 DMA 控制器向 CPU 申请总线使用权，获得总线后，DMA 控制器直接控制外设与主存之间的数据交换，整个过程不需要 CPU 执行指令来逐个搬运数据。

在 DMA 传输过程中，涉及以下几个部件：

- 设备接口：外设与主机连接的端口，数据由外设送入设备接口；
- DMA 控制器：负责发出总线请求、地址增量、计数控制、传输结束中断等控制信号；
- 主存：数据的目的地或来源；
- CPU：在 DMA 传输期间让出总线，不参与数据传输。

注意区分“控制通路”与“数据通路”：

1. 控制通路：CPU 与 DMA 控制器之间通过中断、总线请求等信号联系，DMA 控制器向 CPU 请求总线，并在传输结束后向 CPU 发出中断。这是控制信息的通路，不是数据通路。
2. 数据通路：数据从设备接口直接送到主存，或从主存直接送到设备接口。这条通路由 DMA 控制器控制，但数据本身并不经过 CPU，也不一定经过 DMA 控制器内部（通常设备接口与主存之间通过系统总线直接进行数据传送）。

因此，题目问“DMA 控制器控制的数据传输通路位于”，应是指数据实际传输的路径，即设备接口和主存之间。

选项逐一分析：

- (A) CPU 和主存之间：这是 CPU 访问主存的数据通路，DMA 方式下数据不经过 CPU，排除。
- (B) CPU 和 DMA 控制器之间：这是控制/状态信息的通路，不是数据传输通路，排除。
- (C) 设备接口和主存之间：DMA 正是让数据在设备接口和主存之间直接传输，由 DMA 控制器控制，正确。
- (D) 设备接口和 DMA 控制器之间：数据可能经过 DMA 控制器中的缓冲寄存器，但 DMA 控制器不是数据最终存储部件，它负责控制，不是数据通路的终点，且教材中明确 DMA 的数据通路是设备与主存之间，排除。

**易错点**：

1. 误选 D：把“DMA 控制器”当成数据中转站。实际上 DMA 控制器主要承担控制功能，虽然其内部可能有数据缓冲寄存器，但 DMA 的核心特征是“设备与主存直接交换数据”，而不是“数据必须经过 DMA 控制器本身”。
2. 误选 B：混淆控制通路和数据通路。CPU 与 DMA 控制器之间传递的是总线请求、中断等控制信号，不是数据。
3. 误选 A：混淆 DMA 与程序查询/中断方式。后两者数据通常先到 CPU 再送到主存，而 DMA 方式数据不经过 CPU。

**命题规律**：本题是 2024 年统考真题，考查 DMA 方式的基本概念，属于“输入输出系统”章节的基础题。常见变式包括：DMA 传输前由谁初始化（CPU）、DMA 和中断方式的主要区别（DMA 成块传输，中断按字节/字）、DMA 控制器内部寄存器的功能（地址寄存器、计数器、状态寄存器）等。复习时应重点掌握 DMA 的三种工作方式（CPU 停等方式、周期挪用、交替访问）以及 DMA 传输的基本流程，同时对比程序查询、中断和 DMA 三种 I/O 方式的异同。

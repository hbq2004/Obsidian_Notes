# 选择题 第 13 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-72-M13_题目.png|题目]]

13. 下列有关 $I/O$ 接口功能和结构的叙述中,错误的是 ( ).

A. $I/O$ 接口中主机侧数据宽度与设备侧数据宽度总是一样的

B. $I/O$ 接口是像显卡或网卡之类的一种外设控制逻辑

C. $CPU$ 可以从 $I/O$ 接口读取状态信息,以了解接口和外设的状态

D. $CPU$ 可以向 $I/O$ 接口传送用来对设备进行控制的命令.

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-72-M13_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A。  
I/O 接口需要完成数据缓冲和格式转换，主机侧数据宽度与设备侧数据宽度可能不同，所以“总是一样的”说法错误。

**解题切入点**：  
看到“I/O 接口”的概念题，先回忆接口的功能：**数据缓冲、状态检测、控制命令、格式转换**。再看选项中是否有绝对化表述。  
选项 A 中“总是一样的”就是典型绝对化说法。可以类比算法题里“对所有输入都成立”的断言，只要举出一个反例即可否定。比如串行接口的设备侧一次传 1 位，而主机侧总线可能是 32 位或 64 位。

**推演**：  
I/O 接口是主机和外设之间的交接电路，相当于一个“翻译/缓冲层”。它需要解决：

1. 主机与外设速度不匹配；
2. 数据宽度不匹配；
3. 数据格式不匹配；
4. 状态交流与控制问题。

接口中通常设有：

- 数据缓冲寄存器：暂存数据；
- 状态寄存器：记录接口和外设的状态；
- 控制寄存器：存放 CPU 发来的控制命令。

选项 A 说“主机侧数据宽度与设备侧数据宽度总是一样的”，这显然不对。  
例如：

$$
W_H=32\text{ 位},\quad W_D=1\text{ 位}
$$

主机侧一次传输 32 位数据，而串行设备侧一次只传输 1 位。接口需要通过移位寄存器、数据缓冲寄存器完成装配/拆卸。即使设备侧是 8 位或 16 位，也不一定和主机侧相同。因此 A 错误。

选项 B：I/O 接口可以理解为外设控制逻辑，显卡、网卡等适配器内部就包含接口控制逻辑，所以 B 在统考语境下是正确的。

选项 C：CPU 可以通过读接口中的状态寄存器来了解接口和外设的状态，如“忙”“就绪”“出错”等，所以 C 正确。

选项 D：CPU 可以向接口中的控制寄存器写入命令，如启动、停止、允许中断等，再由接口转化为对外设的控制信号，所以 D 正确。

**易错点**：  
1. 误选 B：容易把显卡、网卡只当成外设，而忽略它们也是 I/O 接口/适配器的典型例子。  
2. 误以为“数据宽度不同”就是“一定不同”：正确说法是“可能不同”，不能反向绝对化。  
3. 混淆接口中寄存器的作用：状态寄存器一般只读，控制寄存器一般只写，数据寄存器可读可写。  
4. 把接口简单理解成“插座”：接口是逻辑控制电路，不是物理连接器。

**命题规律**：  
这是 408 中 I/O 接口部分的常考概念题，常以“下列说法错误的是”出现。  
常见变式：

- 接口中有哪些寄存器，各自作用是什么；
- CPU 如何通过状态寄存器了解外设状态；
- 统一编址和独立编址下如何访问接口寄存器；
- 串行接口与并行接口的宽度匹配问题。

复习建议：把 I/O 接口理解为主机与外设之间的“适配层”，重点掌握**数据缓冲、状态检测、控制命令、格式转换**这四大功能，并结合程序查询、中断、DMA 等方式理解接口在 I/O 过程中的作用。

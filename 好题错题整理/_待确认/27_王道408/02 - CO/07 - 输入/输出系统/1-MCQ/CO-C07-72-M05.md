# 选择题 第 5 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-72-M05_题目.png|题目]]

5. $I/O$的编址方式采用统一编址方式时,进行输入/输出的操作的指令是 ( )
A. 控制指令
B. 访存指令
C. 输入/输出指令
D. 都不对

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-72-M05_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。理由：统一编址方式将 I/O 端口当作主存单元，因此输入/输出操作通过“访存指令”（如 load/store）完成。

**解题切入点**：看到“编址方式”要立刻定位到两种 I/O 编址的对比：统一编址与独立编址。统一编址又称“存储器映射 I/O”，核心是“把外设寄存器当作内存单元”；独立编址才需要专门的输入/输出指令。可以类比算法竞赛中访问数据结构：统一编址就像用数组下标直接访问所有元素，而独立编址就像必须通过专门接口函数来访问。

**推演**：

统一编址方式下，CPU 把 I/O 端口（寄存器）的地址编入主存地址空间，每个 I/O 端口对应一个内存地址。这样，CPU 进行输入操作时，相当于从某个内存地址“读”数据；进行输出操作时，相当于向某个内存地址“写”数据。

指令系统中，负责从内存单元读数、向内存单元写数的指令是“访存指令”，例如：

- 输入操作：`LOAD 地址, 寄存器`，把该 I/O 端口的数据读入 CPU；
- 输出操作：`STORE 寄存器, 地址`，把 CPU 的数据写到该 I/O 端口。

因此，统一编址方式下不需要专门的“I/O 指令”，直接使用访存指令即可完成输入/输出操作。

若采用独立编址方式，则 I/O 端口单独编址，不占用主存地址空间，此时 CPU 必须使用专门的输入/输出指令（如 `IN`、`OUT`），例如 x86 中的 `IN AL, DX` 和 `OUT DX, AL`。

题目问“统一编址方式时，进行输入/输出操作的指令”，所以应选“访存指令”，即 B。

**易错点**：

1. **误选“输入/输出指令”**：这是典型错误。输入/输出指令（如 `IN`/`OUT`）只在“独立编址”方式下使用；统一编址方式下没有独立的 I/O 指令，而是用访存指令完成。
2. **误选“控制指令”**：控制指令用于改变程序执行顺序（如跳转、调用），不负责数据传送，不能用于输入/输出。
3. **混淆两种编址的地址空间**：统一编址占用主存地址空间；独立编址不占用主存地址空间，但需要专门指令。做题时先判断是“存储器映射”还是“端口映射”。

**命题规律**：考研 408 中，I/O 编址方式属于常考基础考点，常以选择题形式对比两种编址方式的指令类型、地址空间、优缺点。常见变式包括：

- 给出某地址范围，问该 I/O 是统一编址还是独立编址；
- 问独立编址使用的指令名称；
- 问统一编址的优缺点；
- 结合 DMA、中断等知识点考查 I/O 控制方式。

复习建议：把统一编址与独立编址的对比表格化记忆，重点记住“统一编址用访存指令，独立编址用专门 I/O 指令”，并理解其本质是地址空间的划分方式不同。

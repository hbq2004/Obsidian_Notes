4. 下列属于 $I/O$ 接口中寄存器的有(  )
$I$. 指令寄存器 &nbsp; $II$. 控制寄存器 &nbsp; $III$. 状态寄存器 &nbsp; $IV$. 地址寄存器 &nbsp; $V$. 数据缓冲寄存器
(A) $I$、$II$、$III$和$V$
(B) $II$、$III$和$IV$
(C) $II$、$III$和$V$
(D) $II$、$III$、$IV$和$V$

## 答案

## DeepSeek V4 Flash Max 解析

**答案**：C。I/O 接口中的基本寄存器是控制寄存器、状态寄存器和数据缓冲寄存器；指令寄存器属于 CPU，地址寄存器不属于一般 I/O 接口的基本寄存器。

**解题切入点**：先抓住“I/O 接口寄存器 = 三类端口”这条主线：命令/控制端口、状态端口、数据端口。可以类比工程接口中的“调用、状态、数据”三要素，地址信息由译码器解析。  
观察选项：I 是 CPU 内部寄存器，先排除；V 数据缓冲寄存器必有；剩下关键只需判断 IV 地址寄存器是否属于 I/O 接口。

**推演**：

I/O 接口要完成的基本功能决定了它需要的寄存器：

- CPU 要向外设发送命令，所以需要**控制寄存器**（II）。
- CPU 要查询外设是否就绪、是否出错，所以需要**状态寄存器**（III）。
- CPU 与外设之间要暂存数据，所以需要**数据缓冲寄存器**（V）。

逐项判断：

- I 指令寄存器（IR）：存放当前正在执行的指令，属于 CPU 控制器，不是 I/O 接口寄存器。
- II 控制寄存器：接收 CPU 发来的控制命令，属于 I/O 接口。
- III 状态寄存器：记录外设状态，如 BUSY、READY、ERROR，属于 I/O 接口。
- IV 地址寄存器：I/O 接口中完成“地址识别”一般依靠地址译码器，而不是地址寄存器；CPU 中的地址寄存器（MAR）不属于 I/O 接口。
- V 数据缓冲寄存器：暂存 CPU 与外部设备间传送的数据，属于 I/O 接口。

因此，属于 I/O 接口的寄存器集合为
$$
\{\mathrm{II},\ \mathrm{III},\ \mathrm{V}\}
$$

对应选项 C。

**易错点**：

1. 把“地址译码器”误认为“地址寄存器”。I/O 接口通过地址译码电路选择设备或端口，不一定设置地址寄存器。
2. 看到“地址寄存器”就联想到 DMA 控制器。本题考查一般 I/O 接口的基本寄存器，地址寄存器不是其中的基本项。
3. 漏选 V。数据缓冲寄存器是 I/O 接口中最基础的寄存器之一，用于缓冲 CPU 与外设之间的数据传送。
4. 误选 I。指令寄存器是 CPU 内部寄存器，用于存当前指令，与 I/O 接口无关。

**命题规律**：考点是 I/O 接口的基本组成及 I/O 端口分类。常见变式有：“I/O 端口分为哪几类”“下列哪个不属于 I/O 接口中的寄存器”“指令寄存器/地址寄存器属于 CPU 还是接口”。复习时重点记忆 I/O 接口的三大寄存器：数据缓冲寄存器、状态寄存器、控制寄存器，并注意“地址译码器”与“地址寄存器”的区别。

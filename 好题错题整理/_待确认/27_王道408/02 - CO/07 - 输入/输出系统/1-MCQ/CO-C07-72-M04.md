# 选择题 第 4 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-72-M04_题目.png|题目]]

4. 下列属于 $I/O$ 接口中寄存器的有（ ）

I.指令寄存器  II.控制寄存器  III.状态寄存器  IV.地址寄存器  V.数据缓冲寄存器

(A) I、II、III和V
(B) II、III和IV
(C) II、III和V
(D) II、III、IV和V

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-72-M04_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。I/O 接口中典型寄存器为控制寄存器、状态寄存器和数据缓冲寄存器，指令寄存器属于 CPU，地址寄存器通常不属于 I/O 接口的通用寄存器组。

**解题切入点**：看到“I/O 接口中的寄存器”，先分清“接口”与“CPU/存储器”的边界。这类题本质是概念辨析，可以类比“公司前台”和“公司内部部门”：I/O 接口是对外交互的“窗口”，只负责传递控制、状态和数据；而指令寄存器是 CPU 内部“车间”用的，不属于接口。做题时先排除最明显的 CPU 内部寄存器（指令寄存器），再回忆接口三大端口：数据、状态、控制，最后确认地址寄存器是否属于接口。

**推演**：

1. 明确 I/O 接口的功能：I/O 接口是 CPU 与外设之间的“桥梁”，需要完成数据缓冲、状态反馈、命令传递等功能。因此接口中必须包含能够暂存数据、反映状态、接收命令的寄存器。

2. 逐一判断选项：

   - **I. 指令寄存器（IR）**：位于 CPU 内部，用于存放当前正在执行的指令。它属于 CPU 的控制器部分，与 I/O 接口无关。排除。
   - **II. 控制寄存器**：I/O 接口中用于存放 CPU 发送给外设的控制命令，属于“控制端口”。例如启动、停止、中断允许等控制信息。正确。
   - **III. 状态寄存器**：I/O 接口中用于记录外设或接口本身的状态，如“忙/闲”“就绪/未就绪”“错误标志”等，属于“状态端口”。正确。
   - **IV. 地址寄存器**：I/O 接口中虽然有地址译码逻辑，但通常不把“地址寄存器”列为 I/O 接口的基本寄存器。CPU 访问外设时通过地址线选择接口，接口内部依靠译码电路识别端口地址，而不是像 DMA 控制器那样需要专门的地址寄存器。考研教材通常将 I/O 接口寄存器概括为数据缓冲寄存器、状态寄存器、控制寄存器三类。因此地址寄存器不属于通用答案。排除。
   - **V. 数据缓冲寄存器**：I/O 接口中用于暂存 CPU 与外部设备之间交换的数据，起到速度匹配和缓冲作用，属于“数据端口”。正确。

3. 因此，属于 I/O 接口寄存器的有：II、III、V，对应选项 C。

**易错点**：

- **误把“地址寄存器”选入**：部分同学想到 DMA 接口或某些接口芯片中有地址寄存器，但题目问的是 I/O 接口中“寄存器”的一般组成，不是特殊接口芯片。考研标准答案以“数据、状态、控制”三类端口为准。
- **误把“指令寄存器”当作接口寄存器**：指令寄存器是 CPU 控制器的一部分，与外部设备通信无关，属于干扰项。
- **对“端口”概念不熟**：I/O 端口实际上就是接口中的寄存器，数据端口对应数据缓冲寄存器，状态端口对应状态寄存器，控制端口对应控制寄存器。掌握了这个对应关系即可快速解题。

**命题规律**：本题是 408 计算机组成原理中“I/O 方式”章节的基础概念题，常以选择题形式出现，考查对 I/O 接口组成和端口类型的记忆。常见变式包括：给出具体接口芯片（如 8255、8250），问其中包含哪些端口；或结合“统一编址/独立编址”考查端口地址识别。复习时建议以唐朔飞教材为准，熟记 I/O 接口的三大寄存器（数据缓冲、状态、控制），并注意与 CPU 内部寄存器区分，同时理解“端口”就是“寄存器”的别名。

# 选择题 第 3 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-72-M03_题目.png|题目]]

3. 下列关于 $I/O$ 端口和接口的说法中,正确的是 (  )
(A) 在统一编址方式下,对主存单元和 $I/O$ 端口的存储保存措施是独立的.
(B) 在统一编址方式下,主存单元和 $I/O$ 设备是靠不同的地址线来区分的.
(C) 在独立编址方式下,主存单元和 $I/O$ 设备是靠不同的地址线来区分的.
(D) 在独立编址方式下, $CPU$ 需要设置专门的输入/输出指令访问 $I/O$ 端口.

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-72-M03_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。在独立编址方式下，I/O 端口有独立于主存的地址空间，CPU 必须设置专门的输入/输出指令（如 IN、OUT）来访问 I/O 端口。

**解题切入点**：看到“统一编址/独立编址”，立即比较二者的核心差异：地址空间是否共用、访问 I/O 需要什么指令、I/O 是否占用主存地址空间、靠什么来区分。可类比“两本号码本”：统一编址是一本号码本中划出 I/O 区段；独立编址是主存和 I/O 各用一本号码本，必须指定用哪本去查。

**推演**：

I/O 端口是 I/O 接口中可被 CPU 访问的寄存器，如数据端口、状态端口、控制端口；I/O 接口是主机与外设之间的连接部件。CPU 实际寻址的是端口，而不是整个设备。

- 在统一编址方式下，I/O 端口与主存单元共同组成同一个地址空间。CPU 把 I/O 端口当作主存单元来访问，因此可以使用普通访存指令，不需要专门的 I/O 指令。主存单元与 I/O 端口不是靠“不同的地址线”区分，而是靠地址值落在哪个地址区间来区分。故 B 错。
- 在统一编址方式下，I/O 端口占用主存地址空间，存储保护通常也按照统一地址空间管理，而不是“对主存单元和 I/O 端口分别独立设置保护措施”。故 A 错。
- 在独立编址方式下，主存地址空间与 I/O 端口地址空间分离，I/O 端口地址不占用主存地址空间。CPU 必须使用专门的输入/输出指令（如 IN、OUT）访问 I/O 端口；区分访问主存还是访问 I/O，主要靠 I/O 指令及控制信号（如 M/IO），不是靠“不同的地址线”。故 C 错、D 对。

两种编址方式的对比：

| 编址方式 | 地址空间 | 访问指令 | 如何区分 | 是否占用主存地址空间 |
|---|---|---|---|---|
| 统一编址 | 与主存共用同一个地址空间 | 普通访存指令 | 靠地址值/地址区间 | 占用 |
| 独立编址 | 与主存地址空间分离 | 专门 I/O 指令 | 靠 I/O 指令及控制信号 | 不占用 |

**易错点**：

- 误以为“独立编址靠不同地址线区分主存和 I/O”。实际上地址总线通常是同一组，独立编址依靠的是 I/O 指令和控制信号（如 M/IO）区分。
- 误以为“统一编址也需要专门 I/O 指令”。统一编址用普通访存指令访问 I/O 端口；只有独立编址需要专门 I/O 指令。
- 混淆 I/O 端口和 I/O 接口。I/O 接口包含多个端口；端口是接口中可寻址的寄存器，题目讨论的是端口的编址方式。
- 注意“I/O 端口占用主存地址空间”是统一编址的特点，“不占用主存地址空间”是独立编址的特点。

**命题规律**：本题考查 I/O 端口编址方式，是 408 组成原理中 I/O 系统部分的常考基础题。常见变式有：判断“是否需要专门 I/O 指令”“I/O 是否占用主存地址”“统一编址能否用访存指令访问端口”“独立编址如何区分主存与 I/O”等。复习时建议把两种编址方式做成对比表，抓住核心结论：统一编址“共用地址空间、用访存指令、占用主存地址、不需专门 I/O 指令”；独立编址“地址空间分离、需专门 I/O 指令、不占用主存地址、靠控制信号区分”。

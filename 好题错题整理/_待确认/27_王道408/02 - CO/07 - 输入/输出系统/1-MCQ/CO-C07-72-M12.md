# 选择题 第 12 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-72-M12_题目.png|题目]]

12. 主机和外设之间的正确连接通路是 (  )

(A) $CPU$和主存$I/O$总线一通信总线(电缆)$I/O$接口一外设

(B) $CPU$和主存$I/O$总线$I/O$接口一通信总线(电缆)一外设

(C) $CPU$和主存$I/O$接口一$I/O$总线一通信总线(电缆)一外设

(D) $CPU$和主存$I/O$接口一通信总线(电缆)一$I/O$总线一外设

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-72-M12_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。CPU 和主存先经 I/O 总线连接到 I/O 接口，再经通信总线（电缆）连接外设。

**解题切入点**：把主机到外设的连接看成一条“总线—接口—电缆—设备”的通路。I/O 接口是中间的“适配器”，一端面向主机总线，一端面向设备电缆，绝不能放到通信电缆之后。类似做题经验：接口像 USB 转接器，先接主板总线，再接设备线。

**推演**：

主机与外设之间交换信息必须经过 I/O 接口，因为外设的速度、数据格式、电平信号等与 CPU/主存差异较大。

- I/O 接口面向主机的一侧接在 I/O 总线上，CPU 和主存通过 I/O 总线向接口发送地址、数据和控制信号。
- I/O 接口面向设备的一侧通过通信总线（电缆）与外设连接，完成设备侧的数据和状态传送。

因此正确连接通路应为：

$$
\text{CPU和主存} \xrightarrow{\text{I/O 总线}} \text{I/O 接口} \xrightarrow{\text{通信总线(电缆)}} \text{外设}
$$

对应选项 B。

其他选项的错误在于：

- A：把 I/O 接口放在通信总线之后，接口未直接挂在主机一侧的 I/O 总线上。
- C：把 I/O 接口放在 I/O 总线之前，顺序颠倒。
- D：既把 I/O 接口放到 I/O 总线前，又把 I/O 总线放到设备侧，明显错误。

**易错点**：

1. 把 I/O 接口看成外设的一部分，放到通信电缆后面，会误选 A。
2. 混淆 I/O 总线和通信总线：I/O 总线用于主机与接口之间，通信总线用于接口与外设之间。
3. 只记“CPU—接口—外设”，忽略 I/O 总线在主机侧的位置。
4. 题干问的是“通路”，要求从左到右连接不断开，顺序不能颠倒。

**命题规律**：

此考点属于 408 中 I/O 系统的基础题，考查主机、I/O 接口、外设之间的连接关系。常见变式：

- 把“I/O 总线”换成“系统总线”，本质不变；
- 把“通信总线(电缆)”换成“设备连接线/通信电缆”；
- 结合 I/O 接口的数据缓冲、状态端口、中断和 DMA 请求等功能综合考查。

复习建议：牢记“I/O 接口一端接总线，一端接设备”，自己画一遍“CPU/主存 → I/O 总线 → I/O 接口 → 通信电缆 → 外设”的连接图，即可避免顺序混淆。

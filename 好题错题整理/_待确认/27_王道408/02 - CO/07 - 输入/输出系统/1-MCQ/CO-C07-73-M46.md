# 选择题 第 46 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M46_题目.png|题目]]

46.【2020统考真题】外部中断包括不可屏蔽中断($NMI$)和可屏蔽中断,下列关于外部中断的叙述中,错误的是( )

A. $CPU$处于关中断状态时,也能响应$NMI$请求

B. 一旦可屏蔽中断请求信号有效, $CPU$将立即响应

C. 不可屏蔽中断的优先级比可屏蔽中断的优先级高

D. 可通过中断屏蔽字改变可屏蔽中断的处理优先级

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M46_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。可屏蔽中断请求信号有效后，CPU 并不立即响应，而必须满足“当前指令执行完毕、CPU 处于开中断状态（IF=1）、无更高优先级中断请求”等条件，因此“立即响应”说法错误。

**解题切入点**：本题直接考查外部中断的响应条件与优先级。做题时先抓住关键词“外部中断”“NMI”“可屏蔽中断”“响应”，迅速回忆中断响应过程：CPU 在每条指令执行结束后统一查询中断请求，并依据中断允许标志（IF）和优先级决定是否响应。可以类比“任务调度”：低优先级任务发出请求后，调度器并不会立刻切换，而是要等当前任务完成，且高优先级任务不抢占时才处理。

**推演**：
1. 外部中断分为不可屏蔽中断（NMI）和可屏蔽中断（INTR）。  
   - NMI 通常用于电源故障、硬件错误等紧急事件，其请求信号不可被屏蔽。  
   - 可屏蔽中断可通过中断允许标志（IF）或中断屏蔽字来屏蔽。

2. 分析选项 A：  
   CPU 处于关中断状态时，即 IF=0，CPU 不会响应可屏蔽中断，但 NMI 不经过 IF 判断，因此 CPU 仍能响应 NMI。故 A 正确。

3. 分析选项 B：  
   可屏蔽中断的响应需要满足多个条件：
   - CPU 已完成当前指令的执行；
   - CPU 处于开中断状态（IF=1）；
   - 当前没有更高优先级的中断请求正在处理；
   - 若总线上有 DMA 请求，还需考虑总线优先级等。
   因此“一旦请求信号有效，CPU 将立即响应”显然是错误的。可屏蔽中断请求信号只是“请求”，CPU 还需要在合适的中断响应周期采样并判断，不会立即响应。

4. 分析选项 C：  
   NMI 的优先级高于可屏蔽中断。因为 NMI 通常表示严重硬件故障，必须优先处理，且其不可屏蔽性本身就体现了更高的紧急程度。故 C 正确。

5. 分析选项 D：  
   中断屏蔽字可以屏蔽某些中断源，从而改变中断处理程序之间的响应次序，即可变优先级。通过设置不同的屏蔽字，可以实现动态调整可屏蔽中断的处理优先级。故 D 正确。

综上，错误的是 B。

**易错点**：
- 误选 A：认为关中断时所有中断都不能响应，忽略了 NMI 不受 IF 控制。
- 误选 D：不理解“处理优先级”与“响应优先级”的区别，中断屏蔽字调整的是可屏蔽中断之间的处理优先级，并非完全固定不变。
- 对“立即响应”理解不到位：CPU 响应中断必须在一个指令周期结束后统一判断，不可能在指令执行中途响应，更不能“立即”。

**命题规律**：本题属于中断系统的基础概念题，2020 年统考直接考查外部中断的特性与响应条件。常见变式包括：
- 结合中断周期流程图，判断响应中断的时机；
- 比较 NMI、可屏蔽中断、内部异常（如除零、溢出）的处理优先级；
- 通过中断屏蔽字设置，分析多个中断的处理顺序；
- 考查中断隐指令（关中断、保存断点、向量地址送 PC 等）的步骤。
复习建议：掌握中断响应的完整流程，明确“请求—响应—处理—返回”各阶段的条件，牢记 IF 只影响可屏蔽中断，NMI 和内部异常不受 IF 控制。同时注意区分“响应优先级”和“处理优先级”，并通过简单例子（如两个中断同时请求）画时间轴帮助记忆。

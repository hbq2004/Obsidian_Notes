# 选择题 第 1 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-72-M01_题目.png|题目]]

1. 在统一编址的方式下,区分存储单元和$I/O$设备是靠（ ）

(A) 不同的地址码

(B) 不同的地址线

(C) 不同的控制线

(D) 不同的数据线

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-72-M01_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A。一句话理由：统一编址将存储单元和 I/O 设备纳入同一地址空间，靠不同的地址码（地址编号）来区分访问对象。

**解题切入点**：先判断考查的是“编址方式”的概念，而不是总线信号。可以类比“门牌号”：存储单元和 I/O 设备拥有各自不同的门牌号（地址码），但共用同一套“道路”（地址线、数据线），也共用同一套交通规则（控制线）。拿到题目先锁定关键词“统一编址”，立刻联想到“地址空间统一分配，用地址区分设备”。

**推演**：
- 统一编址（存储器映射 I/O）是指把 I/O 设备中的寄存器也看作存储单元，与主存单元一起按地址统一编号。
- 这样一来，CPU 访问某个地址时，该地址唯一对应一个存储单元或一个 I/O 寄存器。
- 因此，区分存储单元和 I/O 设备依靠的是**地址码本身**的不同，即地址编码不同。
- 具体总线操作中，CPU 发出的地址码经过译码后，若落在存储器地址区间，则选中存储单元；若落在 I/O 地址区间，则选中对应的 I/O 设备。
- 地址线只是传输地址码的物理线路，不能单独用来区分存储器和 I/O；控制线负责控制读写等操作，与区分对象无关；数据线只传输数据，更不承担寻址区分功能。

所以选 A。

**易错点**：
- 误选 B“不同的地址线”：统一编址下存储器和 I/O 共用地址线，靠的是地址线上的编码值不同，不是地址线本身不同。
- 误选 C“不同的控制线”：控制线用于区分读写方向等操作类型，例如 $\overline{WR}$、$\overline{RD}$，并不能区分访问的是存储器还是 I/O。
- 误选 D“不同的数据线”：数据线只是传送数据，与寻址编址无关。
- 注意与“独立编址（I/O 单独编址）”区分：独立编址时通常用专门的 I/O 指令和 $\overline{M/\overline{IO}}$ 等控制信号来区分，而统一编址只靠地址码区分。

**命题规律**：
- 考点定位：计算机组成原理中的“I/O 编址方式”，属于基础概念题，常出现在选择题或填空题。
- 常见变式：对比“统一编址”和“独立编址”的优缺点；给出某地址范围，判断哪些是 I/O 空间；结合指令系统考查“访问 I/O 是否可用普通访存指令”。
- 复习建议：牢记两种编址方式的本质区别——统一编址靠地址码区分，独立编址靠专门 I/O 指令（或控制信号）区分；并理解各自的优缺点：统一编址无需专用 I/O 指令，但占用地址空间；独立编址有专用指令，但需要额外控制信号。

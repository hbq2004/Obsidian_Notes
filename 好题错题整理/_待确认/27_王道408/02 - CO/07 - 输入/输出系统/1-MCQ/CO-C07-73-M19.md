# 选择题 第 19 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M19_题目.png|题目]]

19. 在各种 $I/O$ 方式中,中断方式的特点是（ ），$DMA$ 方式的特点是（ ）
A. $CPU$ 与外设串行工作,传送与主程序串行工作
B. $CPU$ 与外设并行工作,传送与主程序串行工作
C. $CPU$ 与外设串行工作,传送与主程序并行工作
D. $CPU$ 与外设并行工作,传送与主程序并行工作

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M19_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：第一空选 B，第二空选 D。中断方式下 CPU 与外设可并行工作，但数据传送由 CPU 在中断服务程序中完成，所以传送与主程序串行；DMA 方式下由 DMA 控制器直接控制外设与主存之间的数据传送，CPU 可继续执行主程序，所以传送与主程序并行。

**解题切入点**：先拆出题目中的两个判断维度：  
① CPU 与外设是否并行工作；  
② 数据传送与主程序是否并行工作。  
然后抓住“谁控制数据传送”这个关键：中断方式下传送由 CPU 执行中断服务程序完成，DMA 方式下传送由独立硬件 DMA 控制器完成。这类似于算法竞赛中的“多线程”思想：中断是单核 CPU 上处理外部事件，处理时必须暂停当前任务；DMA 则像硬件加速器，搬运数据不占用 CPU 的执行主程序能力。

**推演**：

1. 程序查询方式：CPU 不断查询外设状态，外设未准备好时 CPU 只能等待，所以 CPU 与外设串行；传送也由 CPU 执行，因此传送与主程序也是串行。

2. 中断方式：CPU 启动外设后，可以继续执行主程序；当外设准备就绪时发出中断请求，CPU 暂停当前主程序，转入中断服务程序完成一次数据传送。因此：

   - CPU 与外设：并行工作；
   - 数据传送与主程序：串行工作。

   对应选项 B。

3. DMA 方式：CPU 先对 DMA 控制器进行初始化，给出主存首地址、传送字数、传送方向等，然后继续执行主程序；DMA 控制器直接控制外设与主存之间的数据传送，只在传送完成或出错时中断 CPU。因此：

   - CPU 与外设：并行工作；
   - 数据传送与主程序：并行工作。

   对应选项 D。

可用下表对比：

| I/O 方式 | CPU 与外设 | 传送与主程序 |
|---|---|---|
| 程序查询方式 | 串行 | 串行 |
| 中断方式 | 并行 | 串行 |
| DMA 方式 | 并行 | 并行 |

**易错点**：

1. 误以为中断方式中 CPU 与外设串行。实际上外设准备数据期间 CPU 可以执行主程序，只有数据传送时 CPU 才被中断，因此是“并行准备、串行传送”。

2. 误以为中断方式中“传送与主程序并行”。中断服务程序本身就是 CPU 执行的程序，它打断主程序完成传送，所以传送与主程序串行。

3. 误以为 DMA 方式中传送也与主程序完全串行。DMA 传送时可能通过周期窃取占用总线，但宏观上数据传送与 CPU 执行主程序是并行进行的，不能理解为完全互不干扰。

4. 混淆“CPU 与外设并行”和“传送与主程序并行”两个维度，应分别判断。

**命题规律**：本题考查 I/O 控制方式的基本特点，重点是程序查询、中断和 DMA 三种方式的区别。常见变式有：比较三种方式的 CPU 干预频率、传送单位、响应时机；给出情境判断使用哪种 I/O 方式；考查 DMA 的工作流程、周期窃取、与中断方式的区别。复习时建议用表格横向对比“CPU 与外设是否并行、传送与主程序是否并行、传送单位、请求信号、CPU 干预程度”，并熟记中断和 DMA 的典型应用场景。

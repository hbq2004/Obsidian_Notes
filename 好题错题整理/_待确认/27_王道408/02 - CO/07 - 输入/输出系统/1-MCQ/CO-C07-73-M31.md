# 选择题 第 31 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M31_题目.png|题目]]

31. 启动一次 $DMA$ 传送，外设和主机之间将完成一个（ ）的数据传送.
(A) 字节
(B) 字
(C) 总线宽度
(D) 数据块

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M31_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D（数据块）。  
理由：DMA 方式一次启动完成的传送是以数据块为单位的成组数据传送，外设与主存之间直接交换一块连续数据，而无需 CPU 逐字干预。

**解题切入点**：  
看到“DMA 传送”立刻定位到 I/O 方式中的直接存储器存取。DMA 的核心特点是“成块传送”，因此问“启动一次 DMA 传送完成什么单位的数据传送”时，优先锁定“数据块”。可以类比“快递专车”：一次发车送一批货物，而不是一次送一个包裹。

**推演**：  
DMA（Direct Memory Access）方式的基本过程是：  
1. CPU 对 DMA 控制器进行初始化，设置传送方向、内存首址、传送字节数（或字数）等参数；  
2. 外设准备好后向 DMA 控制器发出 DMA 请求；  
3. DMA 控制器向 CPU 请求总线控制权；  
4. CPU 在总线周期结束后让出总线，DMA 控制器获得总线控制权；  
5. DMA 控制器直接控制外设与内存之间的数据传送，每传送一个数据字（或字节）占用一个总线周期，直到整个数据块传送完毕；  
6. 传送结束后，DMA 控制器向 CPU 发出中断请求，由 CPU 进行事后处理。

关键点在于：一次完整的 DMA 传送过程，是从初始化开始到传送结束，期间 DMA 控制器连续完成一批数据的传输，即一个数据块。因此“启动一次 DMA 传送”对应的单位是数据块，而不是单字节、单字或总线宽度。

若从选项区分：  
- 字节、字是程序查询方式、中断方式中每次 CPU 参与传送的单位；  
- 总线宽度是总线一次并行传输的位数，与 DMA 一次传送的数据块大小无关；  
- 数据块才是 DMA 成组传送的单位。

所以正确选项为 D。

**易错点**：  
1. **误选字节或字**：误以为 DMA 每个总线周期只传一个字节或一个字。实际上单个总线周期确实可能传一个字或字节，但“启动一次 DMA 传送”是整体过程，传的是整个数据块。  
2. **误选总线宽度**：总线宽度决定一个总线周期能传多少位，但这不是 DMA 传送的单位。  
3. **混淆“外设与主机”和“外设与 DMA 控制器”**：有些题会说外设与 DMA 控制器之间以字或字节为单位，而外设与主存之间以数据块为单位。本题明确说“外设和主机之间”，主机通常指主存，故为数据块。  
4. **忽视“启动一次”的限定**：若问“每个 DMA 周期传送多少”，则可能选字或字节；但题目问的是“启动一次 DMA 传送”的完成量，必须选数据块。

**命题规律**：  
该题属于计算机组成原理中 I/O 方式的常考基础题，重点是区分程序查询方式、程序中断方式、DMA 方式的特点。常见变式包括：  
- 问 DMA 传送前由谁进行初始化（CPU）；  
- 问 DMA 传送结束后如何通知 CPU（中断）；  
- 问 DMA 与 CPU 争用总线的方式（周期挪用、交替访问、停止 CPU 访问主存等）；  
- 问 DMA 传送过程中 CPU 是否完全空闲（可能在其他周期继续执行非访存指令）。  

复习建议：牢记三种 I/O 方式的传送单位：  
- 程序查询方式：以字/字节为单位，由 CPU 全程参与；  
- 程序中断方式：以字/字节为单位，CPU 在中断服务程序中参与；  
- DMA 方式：以数据块为单位，由 DMA 控制器控制完成，CPU 只在开始和结束时介入。  
同时注意题干中“一次启动”“一个周期”“一个总线周期”等关键词的区别。

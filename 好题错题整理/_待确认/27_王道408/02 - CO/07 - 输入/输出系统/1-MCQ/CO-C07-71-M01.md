# 选择题 第 1 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-71-M01_题目.png|题目]]

1. 在微型机系统中， $I/O$ 设备通过( ) 与主板的系统总线相连接。
(A) $DMA$ 控制器
(B) 设备控制器
(C) 中断控制器
(D) $I/O$ 端口

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-71-M01_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B（设备控制器）。理由：I/O 设备本身不能直接挂在系统总线上，必须通过“设备控制器”（即 I/O 接口电路）实现与系统总线的电气连接与协议转换。

**解题切入点**：先明确题目问的是“物理/逻辑上谁充当 I/O 设备与系统总线之间的桥梁”。这类似于把多个外设接入电脑时，每类设备都要有对应的“适配器”或“接口卡”，而不是直接靠 DMA、中断这类“工作模式”或“端口编号”来连接。抓住“连接”二字，就能排除掉功能型部件。

**推演**：

- 在微型机系统中，系统总线（如数据总线、地址总线、控制总线）是 CPU、内存和 I/O 设备之间传输信息的公共通道。
- I/O 设备种类繁多，工作速度、数据格式、电平标准与 CPU/总线差异很大，不能直接挂接在总线上。
- 因此，每个 I/O 设备都需要一个“设备控制器”作为中介。设备控制器一方面通过总线接口与系统总线相连，另一方面通过设备接口与具体的 I/O 设备相连，完成：
  - 数据缓冲；
  - 信号电平与格式转换；
  - 设备状态反馈；
  - 接收 CPU 的命令并控制设备动作。

- 具体到本题各选项：
  - **DMA 控制器**：用于实现 I/O 设备与主存之间直接传送数据，减少 CPU 干预。它需要挂接在总线上，但它不是“所有 I/O 设备连接总线”的通用部件，而是可选的专用控制部件。
  - **设备控制器**：每个 I/O 设备都必须配备，是设备与总线之间的接口，正确。
  - **中断控制器**：用于汇集和管理设备的中断请求，也不是连接设备与总线的部件。
  - **I/O 端口**：是设备控制器中可被 CPU 访问的寄存器或寄存器组，属于设备控制器的子部件，不是连接设备与总线的独立部件。

因此，I/O 设备通过“设备控制器”与主板的系统总线相连接，选项 B 正确。

**易错点**：

1. **误选 I/O 端口**：I/O 端口是设备控制器中用于 CPU 读写数据/状态/命令的寄存器地址，不是一种“连接部件”。注意区分“端口”和“接口/控制器”。
2. **误选 DMA 控制器**：DMA 只是传送数据的一种方式，且不是每个设备都必须有 DMA 控制器；普通设备仍然通过设备控制器连接总线。
3. **误选中断控制器**：中断控制器只处理中断信号，不负责 I/O 设备与总线间的电气连接与协议转换。
4. **概念混淆**：平时说“设备接口”“I/O 接口”“设备控制器”常指同一层次，但本题强调“与系统总线相连接”，应选设备控制器。

规避方法：抓住“连接”这一关键词，理解设备的接入路径为：  
$$I/O\text{ 设备} \rightarrow \text{设备控制器} \rightarrow \text{系统总线} \rightarrow \text{CPU/内存}$$

**命题规律**：  
本题属于“I/O 系统基本概念”的常考基础题，主要考查 I/O 设备的连接方式以及相关概念（设备控制器、I/O 端口、DMA、中断控制器）的区分。常见变式有：

- 考查“I/O 接口”与“I/O 端口”的区别；
- 考查设备控制器的功能（数据缓冲、状态反馈、命令译码等）；
- 结合中断和 DMA 的流程，判断各部件在 I/O 操作中的作用。

复习建议：把 I/O 系统的层次结构画清楚，熟记“设备—设备控制器—总线—主机”的链路，并对比记忆中断控制器、DMA 控制器、通道等部件的适用场景。

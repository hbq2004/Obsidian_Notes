# 选择题 第 21 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M21_题目.png|题目]]

21. 在 $DMA$ 传送方式中，由（ ）发出 $DMA$ 请求，在传送期间总线控制权由（ ）掌握.

(A) 外部设备、$CPU$
(B) $DMA$ 控制器、$DMA$ 控制器
(C) 外部设备、$DMA$ 控制器
(D) $DMA$ 控制器、内存

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M21_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。理由：DMA 传送开始时由外部设备向 DMA 控制器发出 DMA 请求；DMA 控制器获得总线控制权后，在传送期间由 DMA 控制器掌握总线控制权。

**解题切入点**：先抓住题干中的两个关键短语：“DMA 请求”和“总线控制权”。DMA 过程实际上包含两级请求：外部设备向 DMA 控制器发出“DMA 请求”，而 DMA 控制器再向 CPU 发出“总线请求”。可以把外设看成“需要搬运货物的仓库”，DMA 控制器是“搬运队长”，CPU 是“物业主管”；仓库通知搬运队长后，搬运队长向主管申请钥匙，拿到钥匙后由队长指挥搬运，主管暂时不参与。

**推演**：

1. 外部设备准备好数据或接收缓冲就绪后，向 DMA 控制器发出 DMA 请求信号，如 $DREQ$。这一步中的“DMA 请求”指外部设备请求进行 DMA 传送。

2. DMA 控制器收到请求后，向 CPU 发出总线请求信号，如 $HOLD$ 或 $BUSRQ$，请求 CPU 让出总线控制权。

3. CPU 在当前总线周期结束后响应请求，发出总线应答信号，如 $HLDA$ 或 $BUSAK$，随后 DMA 控制器获得总线控制权。

4. 在 DMA 传送期间，DMA 控制器作为总线主设备，控制地址线、数据线和读写控制线，直接在外部设备与主存之间传送数据，CPU 不再控制总线。

5. 当规定的数据块传送完成后，DMA 控制器撤销总线请求，将总线控制权交还给 CPU。

因此，第一空应为“外部设备”，第二空应为“DMA 控制器”，对应选项 C。

**易错点**：

- 易混淆“DMA 请求”和“总线请求”。外设向 DMA 控制器发出的是 DMA 请求；DMA 控制器向 CPU 发出的是总线请求。若题干把第一空改为“总线请求”，则应选 DMA 控制器。
- 易误选 A，认为传送过程中 CPU 仍掌握总线。实际上 DMA 期间 CPU 已让出总线控制权，由 DMA 控制器接管。
- 易误选 B，因为从后续流程看 DMA 控制器确实掌握总线，但第一空“发出 DMA 请求”的主体是外部设备，不是 DMA 控制器。
- 易误选 D，内存是被访问的存储部件，不可能掌握总线控制权。

**命题规律**：这是 408 中 I/O 方式部分的常考基础题，重点考查程序查询方式、中断方式和 DMA 方式之间的区别。常见变式包括：DMA 与中断的响应时机比较、DMA 传送过程中 CPU 是否可以执行其他程序、以及“周期挪用”和总线占用时间计算。复习时应画出 DMA 完整流程：外设请求 $\rightarrow$ DMA 控制器向 CPU 申请总线 $\rightarrow$ CPU 让权 $\rightarrow$ DMA 控制器传送 $\rightarrow$ 传送结束归还总线，并注意区分“DMA 请求”和“总线请求”两个概念。

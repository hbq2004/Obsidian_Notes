# 选择题 第 43 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M43_题目.png|题目]]

43.【2019统考真题】某设备以中断方式与$CPU$进行数据交换，$CPU$主频为$1GHz$，设备接口中的数据缓冲寄存器为32位，设备的数据传输率为$50kB/s$。若每次中断开销（包括中断响应和中断处理）为1000个时钟周期，则$CPU$用于该设备输入/输出的时间占整个$CPU$时间的百分比最多是( )
(A) $1.25\%$
(B) $2.5\%$
(C) $5\%$
(D) $12.5\%$

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M43_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A（$1.25\%$）。  
每次中断可传输 $4$ 字节，设备数据传输率 $50\ \text{kB/s}=50\times10^3\ \text{B/s}$，故每秒中断次数为 $\frac{50\times10^3}{4}=12500$ 次；每次中断开销 $1000$ 时钟周期，则每秒中断总周期为 $12500\times1000=12.5\times10^6$；CPU 主频 $1\ \text{GHz}=10^9$ 周期/秒，因此占比为 $\frac{12.5\times10^6}{10^9}=1.25\%$。

**解题切入点**：先识别中断方式下每次传输的数据量（缓冲寄存器宽度），再根据设备数据传输率计算每秒需要的中断次数，进而得到 CPU 用于中断处理的时钟周期数，最后与 CPU 总时钟数比较得出百分比。这类似于“任务量 / 处理能力”的比率计算。

**推演**：  
1. 设备缓冲寄存器 $32$ 位 = $4$ 字节，故每次中断可传输 $4\ \text{B}$。  
2. 设备数据传输率 $50\ \text{kB/s}$，注意此处 $1\ \text{kB}=1000\ \text{B}$（常见于数据传输率，与 CPU 主频的十进制单位一致），则每秒需传输 $50\times10^3\ \text{B}$。  
   每秒中断次数 $N = \dfrac{50\times10^3\ \text{B/s}}{4\ \text{B}} = 12500\ \text{次/秒}$。  
3. 每次中断开销 $1000$ 时钟周期，故每秒用于中断的总时钟周期数 $C_{\text{io}} = 12500 \times 1000 = 12.5\times10^6$。  
4. CPU 主频 $1\ \text{GHz}=1\times10^9$ 时钟周期/秒，因此 CPU 用于该设备 I/O 的时间占比为  
   $$ \frac{C_{\text{io}}}{1\times10^9} = \frac{12.5\times10^6}{1\times10^9} = 0.0125 = 1.25\% $$  
   题目问“最多”，即设备以最大速率连续传输时所需的最小中断处理时间比例，此即为该比例。  
5. 选项 A 正确。

**易错点**：  
- 误将 $1\ \text{kB}$ 当作 $1024\ \text{B}$，算出 $1.28\%$ 后四舍五入或认为近似 $1.25\%$，但实际考研中数据传输率常采用十进制，且 $1.28\%$ 与选项 $1.25\%$ 有偏差，应严格按十进制计算。  
- 忽略缓冲寄存器宽度，误以为每次中断传输 $1$ 字节或直接使用 $50\ \text{kB}$ 作为传输量，导致中断次数计算错误。  
- 将主频 $1\ \text{GHz}$ 换算为 $10^9$ 时误用 $2^{30}$，但时钟频率通常用十进制。

**命题规律**：  
- 考点：中断方式下 CPU 开销的计算，涉及数据传输率、缓冲寄存器大小、中断开销周期数。  
- 常见变式：改变设备数据宽度（如 $16$ 位）、中断开销周期数、或采用不同的传输速率单位，考查百分比计算。  
- 复习建议：理解中断方式中每次中断传输的数据量由缓冲寄存器决定，掌握单位换算（十进制与二进制的区分），并注意题目中单位的一致性。

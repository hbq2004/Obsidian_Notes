# 选择题 第 44 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M44_题目.png|题目]]

44.【2019 统考真题】下列关于 $DMA$ 方式的叙述中，正确的是( )

I. $DMA$ 传送前由设备驱动程序设置传送参数

II. 数据传送前由 $DMA$ 控制器请求总线使用权

III. 数据传送由 $DMA$ 控制器直接控制总线完成

IV. $DMA$ 传送结束后的处理由中断服务程序完成

(A) 仅 I、II  
(B) 仅 I、III、IV  
(C) 仅 II、III、IV  
(D) I、II、III、IV

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M44_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。  
I、II、III、IV 均正确，即设备驱动程序设置参数、DMA 控制器请求总线使用权、DMA 控制器直接控制总线完成数据传送、传送结束后的处理由中断服务程序完成。

**解题切入点**：  
本题是 DMA 方式基本概念辨析题。拿到题目先明确 DMA 的工作流程：  
“CPU/驱动设置参数 → DMA 控制器请求总线 → 获得总线后直接控制传输 → 传送结束发中断 → 中断服务程序善后”。  
可以把 DMA 想象成“外包快递”：CPU 先填好快递单（设置参数），快递公司（DMA 控制器）自己借车（请求总线）送货（直接控制总线传输），到货后通知收件人（中断），收件人验货签收（中断服务程序处理）。这样四个环节逐一对照即可。

**推演**：  
I. “DMA 传送前由设备驱动程序设置传送参数”  
DMA 传送开始前，CPU 需要执行设备驱动程序，将主存起始地址、传送字节数、设备地址等参数写入 DMA 控制器的寄存器中，然后启动 DMA。因此 I 正确。

II. “数据传送前由 DMA 控制器请求总线使用权”  
DMA 控制器若要直接控制总线进行数据传送，必须先向 CPU 发出总线请求信号，获得总线控制权后才能成为总线主设备。这一请求发生在数据传送之前。因此 II 正确。

III. “数据传送由 DMA 控制器直接控制总线完成”  
获得总线控制权后，DMA 控制器取代 CPU 成为总线主设备，在它的控制下，数据直接在设备和主存之间传送，无需 CPU 逐字干预。因此 III 正确。

IV. “DMA 传送结束后的处理由中断服务程序完成”  
DMA 传送完成后，DMA 控制器向 CPU 发出中断请求，CPU 响应后执行中断服务程序，完成如校验、状态检查、唤醒等待进程等后续工作。因此 IV 正确。  

四句均正确，故选 D。

**易错点**：  
- 误以为 II 中“数据传送前”指“第一次传送前”，从而认为后续传送不需要再请求总线，导致判错。实际上每次 DMA 传送或每批数据传送开始前都需要申请总线使用权。  
- 将 III 理解为“CPU 也参与数据传送”，DMA 方式的核心正是数据传送过程无需 CPU 干预，CPU 只在传送前后参与。  
- 混淆中断在 DMA 中的作用：DMA 传送结束后的“善后处理”由中断服务程序完成，但传送过程本身不靠中断。  
- 忽略 I 中的“设备驱动程序”，误以为参数由用户程序直接设置，实际必须经过操作系统设备驱动程序完成。

**命题规律**：  
本考点属于“输入输出系统”中 DMA 方式的经典选择题，常以判断正误的形式考查 DMA 工作流程中各阶段的参与者。常见变式包括：  
- 把 DMA 与中断方式、程序查询方式对比，要求区分“谁控制总线”“谁的传送受 CPU 干预”。  
- 把 IV 改为“DMA 结束后由 DMA 控制器直接处理”，考察中断服务程序的作用。  
- 把 II 改为“由 CPU 请求总线使用权”，考察 DMA 控制器的总线主设备地位。  

复习时应牢记 DMA 工作流程：  
“设置参数（驱动）→ 请求总线（DMA 控制器）→ 控制传送（DMA 控制器）→ 中断善后（中断服务程序）”，并注意 DMA 控制器是传送阶段的总线主设备，CPU 不参与实际数据搬运。

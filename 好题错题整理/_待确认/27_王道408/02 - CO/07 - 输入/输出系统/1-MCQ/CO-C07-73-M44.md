# 选择题 第 44 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M44_题目.png|题目]]

44.【2019 统考真题】下列关于 $DMA$ 方式的叙述中,正确的是 (    )
I. $DMA$ 传送前由设备驱动程序设置传送参数
II. 数据传送前由 $DMA$ 控制器请求总线使用权
III. 数据传送由 $DMA$ 控制器直接控制总线完成
IV. $DMA$ 传送结束后的处理由中断服务程序完成
(A) 仅 I、II
(B) 仅 I、III、IV
(C) 仅 II、III、IV
(D) I、II、III、IV

## 答案

## DeepSeek V4 Flash Max 解析

**答案**：D。I、II、III、IV 分别对应 DMA 方式的预处理、请求总线、数据传送、结束后的中断处理，均正确。

**解题切入点**：  
拿到题先不要逐句猜，而是把 DMA 工作流程拆成“预处理—数据传送—后处理”三个阶段。I 属于预处理，II 属于数据传送前的总线申请，III 是数据传送本身，IV 属于后处理。就像算法竞赛中“离线预处理 + 核心计算 + 结束后收尾”一样，分阶段对照，就能快速逐项判断。

**推演**：  
DMA 一次完整传送可分为三个阶段。

1. **预处理阶段**  
   CPU 执行设备驱动程序，对 DMA 控制器进行初始化，设置传送参数，包括传送方向、内存首地址、传送字数、外设地址等。  
   因此 I“DMA 传送前由设备驱动程序设置传送参数”正确。这里的“设备驱动程序”就是运行在 CPU 上的初始化程序，和“CPU 初始化 DMA 控制器”并不矛盾。

2. **数据传送阶段**  
   当外设准备好后，DMA 控制器向 CPU 发出总线请求信号，如 $HRQ$。CPU 在当前总线周期结束后响应，发出总线允许信号，如 $HLDA$，DMA 控制器获得总线使用权。  
   因此在数据传送前，确实由 DMA 控制器请求总线使用权，II 正确。

   获得总线控制权后，DMA 控制器直接控制地址线、数据线和控制线，使数据在外设与内存之间直接传送，不经过 CPU 内部寄存器。  
   所以 III“数据传送由 DMA 控制器直接控制总线完成”正确。

3. **后处理阶段**  
   当传送长度计数器减为 0，即一个数据块传送完成后，DMA 控制器向 CPU 发出中断请求。CPU 响应后执行中断服务程序，完成校验、决定是否继续传送等收尾工作。  
   因此 IV“DMA 传送结束后的处理由中断服务程序完成”正确。

综上所述，I、II、III、IV 均正确，选 D。

**易错点**：  
- 容易把 I 误判为错，认为应由“CPU”设置参数而不是“设备驱动程序”。实际上设备驱动程序就是运行在 CPU 上的程序，二者含义一致。  
- 容易把 II 误判为错，认为 DMA 控制器既然能直接控制总线，就不需要请求总线。实际上 DMA 控制器必须先请求总线、获得总线允许后，才能使用总线；周期挪用方式下每次挪用也要申请总线。  
- 容易把 IV 误判为错，认为 DMA 结束后全由硬件自动处理。实际上 DMA 控制器只发出中断请求，结束后的处理由中断服务程序完成。  
- 注意区分“总线请求”和“中断请求”：DMA 传送前需要总线请求以获取总线使用权；DMA 传送结束后需要中断请求以通知 CPU 做后处理。

**命题规律**：  
本题属于 I/O 方式中关于 DMA 工作过程的经典考点。常见变式包括：  
- 对比 DMA 方式与中断方式的异同；  
- 考查 DMA 控制器中的寄存器及参数；  
- 考查 DMA 传送前、中、后分别由谁完成；  
- 考查周期挪用、突发传送等具体传送方式。  

复习时建议把 DMA 流程概括为“CPU 配置 → DMA 请求总线 → DMA 控制传送 → DMA 发中断 → CPU 善后”，并和中断方式对比记忆。

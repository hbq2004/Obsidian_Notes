# 选择题 第 39 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M39_题目.png|题目]]

39.【2014统考真题】若某设备中断请求的响应和处理时间为$100\text{ns}$，每$400\text{ns}$发出一次中断请求，中断响应所允许的最长延迟时间为$50\text{ns}$，则在该设备持续工作过程中，$CPU$用于该设备的$I/O$时间占整个$CPU$时间的百分比至少是$(\quad)$
(A) $12.5\%$
(B) $25\%$
(C) $37.5\%$
(D) $50\%$

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M39_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。设备每 $400\text{ ns}$ 发出一次中断请求，每次中断需 CPU 实际服务 $100\text{ ns}$，所以最低占用率为  
$$\frac{100}{400}=25\%$$  
$50\text{ ns}$ 只是允许的响应延迟上限，不是 CPU 用于该设备的 I/O 时间。

**解题切入点**：把它看成一个周期性任务：每 $400\text{ ns}$ 到达一次请求，每次需 CPU 执行 $100\text{ ns}$。CPU 占用率只算“CPU 实际为设备服务的时间 / 请求周期”。允许延迟 $50\text{ ns}$ 类似于一个响应时限，而不是 CPU 额外忙碌时间。

**推演**：

设备持续工作，因此每隔 $400\text{ ns}$ 必定产生一次中断请求。取一个周期分析：

- 请求周期：$T=400\text{ ns}$；
- 每次中断请求的响应和处理需 CPU 花费：$t=100\text{ ns}$；
- 在一个 $400\text{ ns}$ 周期内，CPU 用于该设备的时间至少为 $100\text{ ns}$。

所以最低占比为：
$$
\eta_{\min}=\frac{t}{T}\times 100\%=\frac{100}{400}\times 100\%=25\%
$$

至于 $50\text{ ns}$，它表示 CPU 必须在请求发出后最多 $50\text{ ns}$ 内开始响应，否则设备可能丢失数据；但这 $50\text{ ns}$ 内 CPU 仍可执行其他程序，不统计为该设备的 I/O 时间，因此不能加到 $100\text{ ns}$ 上。

**易错点**：

1. 易错选 C：把允许延迟 $50\text{ ns}$ 与处理时间 $100\text{ ns}$ 相加，算成  
   $$
   \frac{100+50}{400}=37.5\%
   $$
   错因是把响应等待时限当成了 CPU 占用时间。
2. 易错选 A：只按 $50\text{ ns}$ 算，漏掉了 $100\text{ ns}$ 的响应和处理时间。
3. 忽略“至少”二字：实际可能因中断嵌套、现场保护等产生额外开销，但题目问最低占比，应按每周期必要服务时间计算。

**命题规律**：本题考查“中断方式下 CPU 时间占用率”。常见变式包括：给出设备速率和每次中断服务时间，求 CPU 开销；或与 DMA 方式比较。复习时抓住核心公式：
$$
\text{CPU 占用率}=\frac{\text{每请求的 CPU 服务时间}}{\text{请求周期}}
$$
并注意区分“设备允许等待时间/响应延迟”和“CPU 实际处理时间”。

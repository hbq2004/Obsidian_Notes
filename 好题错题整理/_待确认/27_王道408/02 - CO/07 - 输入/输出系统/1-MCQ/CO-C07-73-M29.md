# 选择题 第 29 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M29_题目.png|题目]]

29. 在 $DMA$ 方式下，数据从内存传送到外设经过的路径是（）
(A) 内存→数据总线→数据通路→外设
(B) 内存→数据总线→$DMA$→外设
(C) 内存→数据通路→数据总线→外设
(D) 内存→$CPU$→外设

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M29_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。DMA 方式下数据不经过 CPU，但需要经过 DMA 控制器中转，路径为：内存→数据总线→DMA 控制器→外设。

**解题切入点**：先抓住 DMA 方式的核心特征：**绕过 CPU、由 DMA 控制器控制数据传输**。因此看到选项中含有 CPU 或 CPU 内部数据通路的，都可以优先排除；再判断数据是否需要经过 DMA 控制器。可以把 DMA 控制器理解为“快递中转站”：CPU 不亲自搬货，但货物要经过中转站。

**推演**：

DMA 方式的基本思想是：外设与主存之间直接交换数据，由 DMA 控制器接管总线控制权，CPU 只在传输前进行预处理、传输结束后进行后处理，不参与逐字数据的传送。

对于“内存→外设”的传送，具体路径为：

1. CPU 预处理：设置 DMA 控制器中的内存起始地址、传送字数、传送方向，并启动外设；
2. DMA 控制器向 CPU 发出总线请求，获得总线控制权；
3. DMA 控制器将内存地址送到地址总线，并发出内存读命令；
4. 内存把数据送到数据总线；
5. DMA 控制器从数据总线接收数据，存入其数据缓冲寄存器中；
6. DMA 控制器再将数据送往外设，完成一次传送。

因此，数据经过的路径是：

$$
\text{内存} \rightarrow \text{数据总线} \rightarrow \text{DMA 控制器} \rightarrow \text{外设}
$$

对应选项 B。

A、C 中的“数据通路”通常指 CPU 内部各部件之间的数据传输路径，若数据经过它，实际上经过了 CPU 内部结构，不符合 DMA 方式。D 选项直接经过 CPU，显然错误。

**易错点**：

- 误以为“DMA = 直接传送”就不经过 DMA 控制器。实际上，DMA 方式中的“直接”是指不经过 CPU，而不是不经过 DMA 控制器；DMA 控制器是传送的控制者，也需要作为数据中转站。
- 混淆“数据通路”与“数据总线”。数据通路是 CPU 内部的部件，而数据总线是连接各部件和设备的公共传输线路；DMA 不经过 CPU，因此不能选含“数据通路”的 A、C。
- 误选 D，认为外设工作必须由 CPU 控制。DMA 方式下，数据传送阶段由 DMA 控制器控制总线，CPU 不参与数据传送。

**命题规律**：

本题属于 I/O 控制方式中的 DMA 方式考点，重点考查 DMA 与中断方式、程序查询方式的区别，以及 DMA 传送过程中数据的实际路径。常见变式包括：

- 改为考查“外设→内存”的数据路径；
- 考查 DMA 与中断方式在 CPU 参与程度上的差别；
- 考查 DMA 传送过程分为预处理、数据传送、后处理三个阶段，CPU 分别在什么时候介入；
- 考查“周期挪用”“CPU 暂停周期”等概念。

复习时应牢记 DMA 控制器的组成：内存地址寄存器、字计数器、数据缓冲寄存器、DMA 控制逻辑，并会画数据传送路径图，避免与 CPU 数据通路混淆。

# 选择题 第 55 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M55_题目.png|题目]]

55.【2025统考真题】下列选项中，会触发外部中断请求的事件是( )
(A) $DMA$传送结束
(B) 总线事务结束
(C) 页故障处理结束
(D) 执行断点指令

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M55_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A。DMA 传送结束时，DMA 控制器会向 CPU 发出中断请求以通知传送完成，该请求来自 CPU 外部，属于外部中断请求。

**解题切入点**：拿到题目先分清“内部异常”和“外部中断”两类事件。可以类比：CPU 像一个正在运行主流程的程序，外部中断是“外部异步通知”，如 I/O 完成信号；内部异常是程序执行本身触发的同步错误或陷阱，如除零、断点、缺页。因此，“DMA传送结束”应定位到 I/O 完成通知；“页故障”和“断点指令”应定位到 CPU 内部；“总线事务结束”只是一次总线操作的结束，不是中断请求。

**推演**：  
外部中断请求是指来自 CPU 外部的硬件通过中断请求线向 CPU 发出的异步中断信号，常见来源包括：

- 定时器时间到；
- I/O 设备完成一次数据传送；
- DMA 传送结束；
- 硬件故障、掉电等。

对选项逐一分析：

1. **A. DMA 传送结束**  
   DMA 控制器在完成一组数据传送后，需要 CPU 做后续处理，如结果校验、状态登记等，因此会通过中断请求线向 CPU 发出中断请求。该请求来源于 CPU 外部的 DMA 控制器或 I/O 设备，属于外部中断请求，故 A 正确。

2. **B. 总线事务结束**  
   总线事务结束只是总线的一次读/写操作完成，是总线协议中的正常结束阶段，例如地址段、数据段、结束段。它本身并不表示有外部设备向 CPU 发出中断请求，通常不会触发外部中断。

3. **C. 页故障处理结束**  
   页故障（缺页）本身是 CPU 执行访存指令时，由地址变换机构产生的内部异常，而不是外部中断。“页故障处理结束”只是异常处理程序执行完毕，不会因此再产生一个外部中断请求。

4. **D. 执行断点指令**  
   断点指令通常由程序主动执行，例如 x86 中的 `INT 3`，它会触发自陷或异常，属于 CPU 内部产生的同步异常，有时也叫“软中断”，但并不是来自 CPU 外部的硬件中断请求。

**易错点**：  
- 看到“页故障”中的“故障”或操作系统中“缺页中断”的说法，误以为它是外部中断。实际上，缺页是 CPU 内部异常。  
- 看到“断点指令”也叫“软中断”，误选 D。软中断/自陷属于内部异常，不是外部中断。  
- 将“DMA请求”和“DMA传送结束中断”混淆。DMA 传送过程中的“DMA请求”是向 CPU 或总线仲裁器申请总线控制权，不是中断请求；而 DMA 传送结束后产生的中断请求才是外部中断请求。  
- 误以为所有硬件硬件事件都能触发中断。总线事务结束只是总线握手完成，不一定伴随外部中断请求。

**命题规律**：本题是典型的“中断与异常分类”考点，常和 I/O 方式、操作系统缺页处理、指令执行过程结合考查。常见变式有：判断给定事件属于内部异常还是外部中断；判断可屏蔽中断与不可屏蔽中断；比较 DMA 传送结束中断与 DMA 请求的区别。复习时应整理典型分类表：  
- 内部异常：除零、溢出、缺页、非法指令、执行断点指令、自陷；  
- 外部中断：I/O 完成、定时器到、DMA 传送结束、掉电等。  
同时注意“中断”和“异常”术语在 408 不同科目中的混用，理解本质即可。

# 选择题 第 38 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M38_题目.png|题目]]

38.【2011统考真题】下列关于中断 $I/O$ 方式和 $DMA$ 方式比较的叙述中,错误的是( )

A. 中断 $I/O$ 方式请求的是 $CPU$ 处理时间,$DMA$ 方式请求的是总线使用权
B. 中断响应发生在一条指令执行结束后,$DMA$ 响应发生在一个总线事务完成后
C. 中断 $I/O$ 方式下数据传送通过软件完成,$DMA$ 方式下数据传送由硬件完成
D. 中断 $I/O$ 方式适用于所有外部设备,$DMA$ 方式仅适用于快速外部设备

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M38_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。中断 $I/O$ 方式每次传送都要 CPU 执行中断服务程序，只适合中低速外部设备，不能说“适用于所有外部设备”；$DMA$ 方式主要用于高速块设备，但也不是“仅适用于快速外部设备”。

**解题切入点**：拿到题先抓 $I/O$ 控制方式比较的核心维度：谁发出请求、响应时机、数据由谁搬、适合什么设备。类似算法竞赛中“轮询”是 CPU 死等，“中断”是事件回调，“DMA”是硬件直接批量拷贝；比的就是“谁占 CPU、何时打断、搬多少数据”。

**推演**：

逐个选项判断：

- **A 正确。** 中断 $I/O$ 方式中，外设准备好后向 CPU 发出中断请求，CPU 响应后执行中断服务程序，因此请求的是“CPU 处理时间”；$DMA$ 方式中，$DMA$ 控制器要成为总线主设备，直接控制地址线和数据线完成内存与外设之间的数据传送，因此请求的是“总线使用权”。

- **B 正确。** 中断响应发生在当前指令执行结束后，这是为了确保断点准确，便于中断返回后继续执行原程序；$DMA$ 请求响应发生在当前总线事务完成后，这是为了避免破坏正在进行的总线操作。

- **C 正确。** 中断 $I/O$ 方式中，数据传送由中断服务程序中的输入/输出指令完成，本质上是软件完成；$DMA$ 方式中，数据传送由 $DMA$ 控制器硬件自动完成，不需要 CPU 执行数据传送指令。$DMA$ 传送结束后虽然也会中断 CPU，但传送过程本身由硬件完成。

- **D 错误。** 中断 $I/O$ 方式每传送一个字节或字，CPU 都要经历“响应中断、保护现场、执行中断服务程序、恢复现场”的过程，CPU 开销很大。设外设数据率为 $r$（B/s），每次中断传送 1 B 所需平均时间为 $t$（s/B），若

$$
r t > 1
$$

则 CPU 单位时间内处理不过来，数据就会丢失。因此中断 $I/O$ 方式不适用于高速外部设备，不能说它适用于所有外部设备。同时，$DMA$ 方式通常用于高速块设备，如磁盘、网卡等，但也不宜说“仅适用于快速外部设备”。

所以错误的是 D。

**易错点**：

1. 误以为“$DMA$ 方式完全不需要 CPU”，实际上 $DMA$ 传送前仍需 CPU 初始化，传送结束后也可能发出中断通知 CPU，但数据传送过程由硬件完成。
2. 混淆响应时机：中断响应是“指令级”边界，即一条指令执行结束后；$DMA$ 响应是“总线事务/总线周期”级边界，而不是等待一整条指令执行完。
3. 把“中断 $I/O$ 方式可处理多种外设”误认为“适用于所有外部设备”，忽略了高速外设会使 CPU 来不及处理而导致数据丢失。
4. 把“$DMA$ 方式适用于高速设备”误解为“仅适用于快速设备”，这是绝对化表述，不准确。

**命题规律**：本题属于 $I/O$ 控制方式中的经典比较题，核心考点是中断 $I/O$ 与 $DMA$ 在请求对象、响应时机、数据传送方式、适用设备上的区别。常见变式包括：考查“中断响应时机”与“$DMA$ 响应时机”、$DMA$ 的周期挪用/总线占用方式、$DMA$ 传送结束后是否产生中断、$DMA$ 请求优先级等。复习时应列表对比程序查询、中断 $I/O$、$DMA$ 三种方式：谁启动、谁搬数据、传送单位、响应时机、适用设备，并理解从“CPU 全程参与”到“CPU 只在前后参与”的发展逻辑。

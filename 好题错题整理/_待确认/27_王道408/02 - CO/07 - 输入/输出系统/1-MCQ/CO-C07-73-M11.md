# 选择题 第 11 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M11_题目.png|题目]]

11. 在中断响应周期中，$CPU$ 主要完成的工作是（ ）

A. 关中断,保护断点,发中断响应信号并形成向量地址
B. 开中断,保护断点,发中断响应信号并形成向量地址
C. 关中断,执行中断服务程序
D. 开中断,执行中断服务程序

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M11_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A。中断响应周期中，CPU 通过硬件“中断隐指令”完成关中断、保护断点、发中断响应信号并形成向量地址；执行中断服务程序是后续阶段的任务。

**解题切入点**：拿到题目先明确“中断响应周期”是中断处理流程中的哪个阶段。可以把中断响应比作“接到报警后先确认警情并锁定位置”，而不是“直接去现场处理”。因此要抓住“响应”阶段的动作：关中断、保存断点、取得中断服务程序入口（向量地址）；至于“执行中断服务程序”，属于“处理”阶段，不是响应阶段的工作。

**推演**：

中断处理过程一般分为：中断请求、中断判优、中断响应、中断处理、中断返回。题目问的是“中断响应周期”，即 CPU 在一条指令执行结束后、下一条指令开始前，由硬件自动完成的一小段“中断隐指令”过程。典型操作如下：

1. 关中断：  
   将中断允许标志置为禁止状态，使 CPU 在保存断点和现场的过程中不再响应新的可屏蔽中断，保证断点信息不会被破坏。

2. 保护断点：  
   将当前程序计数器 $PC$ 的值，即被中断指令的下一条指令地址，压入栈中或存入指定寄存器，以便中断返回时恢复原执行流程：
   $$PC \rightarrow \text{堆栈}$$

3. 发中断响应信号：  
   CPU 向中断控制器或外设发出中断响应信号，表示已受理该中断请求，外设可撤销中断请求。

4. 形成向量地址：  
   根据中断源提供的中断类型号，得到中断向量地址，并送入 $PC$，从而将控制转移到对应的中断服务程序入口：
   $$PC \leftarrow \text{中断向量地址}$$

由此可见，选项 A 完整描述了中断响应周期的主要工作。

选项 B 错在“开中断”。开中断通常是在中断服务程序中完成现场保护后，为了允许响应更高优先级中断而设置的操作，不属于中断响应周期。

选项 C、D 错在“执行中断服务程序”。中断响应周期只完成“引导 CPU 进入服务程序”的准备操作，并不执行服务程序本身；执行中断服务程序发生在中断响应之后的中断处理阶段。

**易错点**：

- 误选 B：把中断服务程序中的“开中断”当作响应阶段操作。注意，响应阶段必须“关中断”，防止现场被破坏；开中断一般出现在中断服务程序内部或中断返回前。
- 误选 C 或 D：把“执行中断服务程序”归入响应周期。响应周期由硬件自动完成，只做“识别中断并准备跳转”的操作；具体服务程序由软件编写，在执行阶段完成。
- 容易遗漏“发中断响应信号”和“形成向量地址”。这两个操作同样是响应周期的重要组成部分，尤其是向量地址的形成，是向量中断方式的关键。
- 混淆“保护断点”和“保护现场”。保护断点是保存 $PC$，由硬件在响应周期完成；保护现场是保存通用寄存器等状态，通常由中断服务程序在进入后通过指令完成。

**命题规律**：

本题属于计算机组成原理中“中断系统”的经典考点，常以选择题形式出现，考查学生对中断响应周期、中断隐指令、中断处理流程的掌握程度。常见变式包括：

- 给出若干操作，判断哪些属于中断响应周期；
- 结合 8086 等具体 CPU，考查中断响应总线周期中的信号变化；
- 比较中断响应与子程序调用（转子指令）的异同；
- 结合中断向量、中断类型号，考查向量地址的形成过程。

复习建议：将中断处理流程分成“请求—判优—响应—服务—返回”五阶段，牢记响应周期由硬件完成，核心动作是“关中断、保护断点、形成向量地址”；同时注意“开中断、保护现场、恢复现场、中断返回”分别属于哪个阶段。

# 选择题 第 11 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M11_题目.png|题目]]

11. 在中断响应周期中，$CPU$主要完成的工作是( )
A. 关中断,保护断点,发中断响应信号并形成向量地址
B. 开中断,保护断点,发中断响应信号并形成向量地址
C. 关中断,执行中断服务程序
D. 开中断,执行中断服务程序

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M11_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A。中断响应周期中，CPU 自动完成关中断、保护断点、发出中断响应信号并形成向量地址，为后续执行中断服务程序做准备。

**解题切入点**：本题考察中断响应周期与中断服务程序的区别。中断响应是硬件自动完成的一系列操作，其核心是保护现场（断点）和引导到中断服务程序，而中断服务程序是软件执行的部分。因此，先定位“中断响应周期”这一阶段，明确其包含的硬件动作，即可排除执行中断服务程序等选项。

**推演**：  
中断响应周期发生在 CPU 检测到中断请求且满足响应条件时，此时 CPU 自动完成以下步骤：  
1. **关中断**：将中断允许标志（IF）置 0，防止在保护断点过程中再次被中断。  
2. **保护断点**：将当前程序计数器（PC）的值压入堆栈，以便中断返回时能恢复原程序执行。  
3. **发中断响应信号**：向中断源发送确认信号，获取中断源信息（如中断号）。  
4. **形成向量地址**：根据中断源类型（如固定向量或可编程中断控制器）生成向量地址，用于跳转到对应的中断服务程序入口。  
以上步骤在中断响应周期内由硬件自动完成，不涉及执行中断服务程序本身。因此，选项 A 准确概括了这些工作。

**易错点**：  
- 混淆“中断响应”与“中断服务”：误以为中断响应周期包括执行中断服务程序，从而错选 C 或 D。中断服务程序是在响应周期结束后，由 CPU 根据向量地址转入执行的。  
- 误认为响应周期需要“开中断”：开中断通常是在中断服务程序返回前或特定情况下，响应周期为了安全必须关中断，故 B 错误。

**命题规律**：  
- **考点定位**：中断处理过程，尤其是中断响应周期的硬件操作。  
- **常见变式**：可考查中断响应周期中是否包括保存通用寄存器（实际由中断服务程序保存），或结合多重中断、中断隐指令等概念。  
- **复习建议**：牢记中断响应周期是硬件自动完成的“关中断、保护断点、识别中断源、形成向量地址”四步，并与中断服务程序中的“保存/恢复现场、开中断、执行中断处理”区分。

16.【2017统考真题】 $I/O$ 指令实现的数据传送通常发生在( ).

(A) $I/O$ 设备和 $I/O$ 端口之间
(B) 通用寄存器和 $I/O$ 设备之间
(C) $I/O$ 端口和 $I/O$ 端口之间
(D) 通用寄存器和 $I/O$ 端口之间

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-72-M16_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。I/O 指令由 CPU 执行，完成 CPU 内部通用寄存器与 I/O 端口之间的数据传送。

**解题切入点**：先抓住题干关键词“I/O 指令”和“数据传送”。I/O 指令是 CPU 指令系统中的一类，CPU 执行指令时只能通过自身的寄存器与外部交换数据，因此要定位到“通用寄存器”与“I/O 端口”之间，而不是设备与端口之间或端口与端口之间。这就像竞赛中读入数据时必须先加载到内存/寄存器才能运算，CPU 无法直接绕过寄存器操作外部设备。

**推演**：  
I/O 端口是 I/O 接口电路中可供 CPU 直接访问的寄存器或缓冲器，每个端口有独立地址。CPU 执行 I/O 指令（如 IN、OUT）时，数据流如下：

- 输入：外部设备数据先送入 I/O 端口，再由 CPU 执行输入指令，将端口内容读入通用寄存器。
- 输出：CPU 执行输出指令，将通用寄存器中的内容写入指定的 I/O 端口，再由端口送往外部设备。

因此，I/O 指令实现的数据传送发生在“通用寄存器”和“I/O 端口”之间。用逻辑关系可表示为：

$$
\text{CPU 通用寄存器} \xleftrightarrow{I/O指令} \text{I/O 端口}
$$

而 I/O 设备与 I/O 端口之间的数据传送通常由 I/O 接口硬件控制，不属于 I/O 指令直接完成的操作。

**易错点**：  
1. 误选 A：认为 I/O 指令就是设备与端口之间传送数据，实际上设备与端口之间是接口电路内部的数据通路，由硬件控制，CPU 不通过 I/O 指令直接干预。  
2. 误选 B：缺少“端口”这一中间环节，I/O 设备不能直接与通用寄存器相连，必须先经过端口。  
3. 误选 C：端口与端口之间的传送通常由 DMA 或接口内部逻辑完成，不是 I/O 指令的功能。

**命题规律**：  
本题属于“I/O 方式”基础考点，重点考查 I/O 指令的数据通路。常见变式包括：  
- 区别三种 I/O 方式（程序查询、中断、DMA）的数据传送路径；  
- 考查“统一编址”与“独立编址”下 I/O 指令的不同形式；  
- 结合具体指令（如 IN/OUT）判断数据流向。  
复习时应牢牢掌握：CPU 与外设交换信息必须通过端口，端口是连接 CPU 与外设的桥梁，I/O 指令只负责 CPU 与端口之间的数据传送。

# 选择题 第 11 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-72-M11_题目.png|题目]]

11. 采用中断方式进行打印控制时,在打印控制接口和打印机之间交换的信息不包括 (  )
A. 打印字符点阵信息
B. 打印控制信息
C. 打印机状态信息
D. 中断请求信号

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-72-M11_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。理由：中断请求信号是打印控制接口向 CPU 发出的，属于接口与主机之间的信号，不是打印控制接口与打印机之间直接交换的信息。

**解题切入点**：先抓住题目问的是“打印控制接口和打印机之间”这一限定，而不是“打印机与主机之间”。把接口想象成打印机和主机之间的“中转站”，那么接口与打印机之间只有数据、控制、状态三类信号；中断请求是接口向“上级”（CPU）打的报告，不在此列。

**推演**：
1. 采用中断方式打印时，CPU 并不直接与打印机打交道，而是通过打印控制接口间接控制。
2. 打印控制接口与打印机之间的信号可分为三类：
   - 数据信号：待打印的字符点阵信息，由接口送给打印机。对应选项 A。
   - 控制信号：例如选通（$\text{STROBE}$）、初始化（$\text{INIT}$）等，由接口送给打印机，用于规定打印机的工作方式。对应选项 B。
   - 状态信号：例如忙（$\text{BUSY}$）、应答（$\text{ACK}$）、缺纸（$\text{PE}$）等，由打印机送给接口，反映打印机当前状态。对应选项 C。
3. 中断请求信号（$\text{INTR}$）的产生过程：打印机完成一个字符的打印后，向接口发送应答信号（$\text{ACK}$），接口在满足中断允许条件时，再向 CPU 发出中断请求（$\text{INTR}$），请求 CPU 继续送来新数据。因此 $\text{INTR}$ 是接口与 CPU 之间传送的信号，不是接口与打印机之间交换的信息。对应选项 D。
4. 综上，A、B、C 均属于打印控制接口与打印机之间交换的信息，D 不属于，故选 D。

**易错点**：
- 易误选 C，把中断请求信号当成打印机状态信息。实际上，状态信息是打印机发往接口的原始状态（如 $\text{BUSY}$、$\text{ACK}$ 等），而中断请求是接口根据这些状态和中断允许位生成并发给 CPU 的，两者层次不同。
- 易误选 A，认为打印数据是字符编码而不是“点阵信息”，但无论何种形式，它都是接口向打印机传输的数据，属于交换信息。
- 解题时应以“信号在哪里产生、在哪里被接收”来判断：只要信号的一端不在打印机上，就不属于打印机与接口之间的交换信息。

**命题规律**：本题属于 I/O 方式中“中断方式”的常考细节，重点考查接口与设备之间、接口与 CPU 之间的信号区分。常见变式包括：给出并行打印接口的多种信号，要求区分“设备侧信号”和“主机侧信号”；或结合中断响应过程，考查中断请求产生的条件。复习时建议画一张 I/O 接口与外设、CPU 的三端信号流向图，清楚每一个信号是从哪端产生、到哪端结束，并总结常见外设（键盘、打印机、磁盘）的中断交互模型。

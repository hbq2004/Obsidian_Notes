# 选择题 第 20 题

20. 下列关于程序查询方式及其工作过程的叙述中,正确的是(    )
(A) 按启动查询方式的不同，可分为软件查询方式和硬件查询方式
(B) $CPU$主要负责启动外设和查询其状态，不参与数据传送
(C) 每完成一次数据传送后,会修改主存地址和计数值
(D) $CPU$需一直查询外设的状态,直到外设准备就绪时才可去执行其他程序

## DeepSeek V4 Flash Max 解析

**答案**：C。程序查询方式在连续传送成组数据时，每完成一次数据传送后，CPU 会修改主存地址和计数值，以准备下一次传送并判断传送是否结束。

**解题切入点**：  
拿到题目先抓住“程序查询方式”的核心特征：CPU 用软件轮询外设状态、忙等待、亲自参与数据传送。这类似于写一个循环：

- 不断查询外设状态；
- 未就绪则继续查；
- 就绪则执行一次数据传送；
- 然后更新地址和计数值。

抓住“CPU 是否参与传送”“等待期间能否做其他事”“传送后做什么”这几个点，就能快速排除 A、B、D。

**推演**：  
程序查询方式的工作过程可以概括为：

1. CPU 通过 I/O 指令启动外设；
2. CPU 读取外设状态寄存器，判断外设是否准备就绪；
3. 若未就绪，CPU 继续重复查询，不能去执行其他程序，即“踏步等待”；
4. 若就绪，CPU 执行 I/O 指令完成一次数据传送：
   - 输入时：外设数据寄存器 $\to$ CPU 寄存器 $\to$ 主存；
   - 输出时：主存 $\to$ CPU 寄存器 $\to$ 外设数据寄存器。
5. 每次数据传送完成后，修改主存地址和计数值，例如：
   $$
   \text{主存地址} \leftarrow \text{主存地址} + 1,\quad
   \text{剩余计数值} \leftarrow \text{剩余计数值} - 1
   $$
   然后判断是否传送完；未完成则继续查询。

逐项分析：

- **A 错误**：程序查询方式本身就是一种软件查询方式，也称“程序轮询”。它不是“按启动查询方式的不同”分为软件查询方式和硬件查询方式。“软件查询/硬件查询”并不是程序查询方式本身的并列子类。
- **B 错误**：程序查询方式中，CPU 不仅要启动外设和查询状态，还必须执行 I/O 指令亲自参与数据传送。数据传送经过 CPU，不是外设与主存直接传送。
- **C 正确**：成组数据传送时，每完成一次数据传送后，需要修改主存地址和计数值，以确定下一次数据存放/读取的位置，并判断是否传送完毕。
- **D 错误**：程序查询方式中，外设未就绪时 CPU 只能不断查询，不能去执行其他程序；外设就绪后 CPU 应立即执行数据传送，而不是转去“执行其他程序”。若外设准备期间 CPU 可执行其他程序，那是程序中断方式的特征。

**易错点**：  
- 容易把“CPU 不参与数据传送”误认为对，实际上这是 DMA 方式的特点；程序查询方式和程序中断方式中，CPU 都参与数据传送。  
- 容易把“修改主存地址和计数值”误认为只有 DMA 才有。实际上程序查询方式中 CPU 也会修改，只是由程序完成；DMA 方式中由 DMA 控制器硬件自动完成。  
- 容易把 D 误判为正确：D 的前半句“CPU 需一直查询外设状态”是程序查询的特点，但后半句“就绪后去执行其他程序”不是，就绪后应进行数据传送。

**命题规律**：  
本题属于 I/O 控制方式的基础概念题，考点是程序查询方式的工作流程及其与中断方式、DMA 方式的区别。常见变式包括：

- 比较程序查询、程序中断、DMA 中 CPU 的参与程度；
- 判断某种说法属于哪种 I/O 控制方式；
- 考查“就绪后应做什么”“等待期间 CPU 能否做其他事”等细节。

复习时建议把几种 I/O 控制方式的启动方式、就绪发现方式、数据传送方式、CPU 参与程度、地址和计数值更新方式做成对比表，尤其区分“程序查询”和“DMA”各自的特点。

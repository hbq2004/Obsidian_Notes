# 选择题 第 50 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M50_题目.png|题目]]

50.【2023 统考真题】下列关于硬件和异常/中断关系的叙述中,错误的是 (   ).
A. $CPU$在执行一条指令的过程中检测异常事件.
B. $CPU$在执行完一条指令时检测中断请求信号.
C. 开中断时$CPU$检测到中断请求后就进行中断响应.
D. 外部设备通过中断控制器向$CPU$发中断结束信号.

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M50_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。外部设备通过中断控制器向 CPU 发出的是“中断请求信号”，不是“中断结束信号”；中断结束（EOI）由 CPU 发给中断控制器，方向正好相反。

**解题切入点**：先抓住异常与中断的本质区别：异常是 CPU 内部、与当前指令同步的事件，应在指令执行过程中发现；中断是外部异步事件，只能在指令边界采样。然后再看选项中有没有把“请求信号”和“结束信号”的方向搞反，这往往是硬件中断流程题的关键陷阱。

**推演**：

1. 异常是 CPU 在执行当前指令时产生的内部事件，例如除零、缺页、非法指令等。它们与正在执行的指令相关，因此 CPU 可以在指令执行过程中检测到异常，不需要等其他指令结束。故选项 A 正确。

2. 中断请求来自 CPU 外部，具有异步性。若在一条指令执行中间响应外部中断，可能破坏当前指令的原子性和现场完整性，所以 CPU 通常在当前指令执行结束后、取下一条指令前采样中断请求。故选项 B 正确。

3. 中断响应必须满足基本条件：

$$
\text{响应中断：开中断} \land \text{有中断请求} \land \text{当前指令已执行完}
$$

所以“开中断时 CPU 检测到中断请求后就进行中断响应”在 408 的语境下是正确的，这里的“检测到”默认指在指令边界采样到请求。故选项 C 正确。

4. 外部中断的硬件信号流向应是：

$$
\text{外设} \xrightarrow{\text{中断请求信号}} \text{中断控制器} \xrightarrow{\text{INTR}} \text{CPU}
$$

CPU 响应后发出 INTA，中断控制器向 CPU 提供中断类型号；中断服务结束后：

$$
\text{CPU} \xrightarrow{\text{EOI（中断结束命令）}} \text{中断控制器}
$$

因此，“外部设备通过中断控制器向 CPU 发中断结束信号”是错误的。外设发的是“中断请求信号”，“中断结束信号”应由 CPU 发给中断控制器。故选项 D 错误。

**易错点**：

- 容易误选 C：C 确实省略了“当前指令执行完”这个前提，但在 408 中“CPU 检测中断请求”通常指在指令边界采样，因此 C 不构成错误；D 是将信号方向彻底说反，是更明显的错误。
- 不要混淆异常和中断的检测时机：异常在指令执行过程中检测，中断在指令执行结束后检测。
- 不要混淆“请求”与“结束”信号：外设发“中断请求”，CPU 发“中断结束/EOI”。
- 注意外设一般不直接连 CPU 中断引脚，而是经过中断控制器汇集、判优后再向 CPU 发 INTR。

**命题规律**：本题考查异常/中断的基本概念和中断控制器中的硬件信号流向。常见变式有：判断中断请求、中断响应、中断结束信号的发出者与方向；结合流水线问异常在哪一级被检测；结合中断屏蔽字问响应优先级。复习时应建立一条清晰主线：外设 → 中断控制器 → CPU → 中断服务程序 → EOI，这样就能快速识别各种“信号方向说反”的干扰项。

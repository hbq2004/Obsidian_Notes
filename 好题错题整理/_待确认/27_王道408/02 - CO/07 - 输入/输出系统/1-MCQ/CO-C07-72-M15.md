# 选择题 第 15 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-72-M15_题目.png|题目]]

15.【2014统考真题】下列有关$I/O$接口的叙述中,错误的是(　　)
A. 状态端口和控制端口可以合用同一个寄存器
B. $I/O$接口中$CPU$可访问的寄存器称为$I/O$端口
C. 采用独立编址方式时,$I/O$端口地址和主存地址可能相同
D. 采用统一编址方式时,$CPU$不能用访存指令访问$I/O$端口

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-72-M15_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。统一编址（存储器映射）方式下，I/O 端口与主存单元在同一个地址空间中，CPU 可以用访存指令访问 I/O 端口，D 说“不能用”恰好说反。

**解题切入点**：先定位考点：I/O 端口的基本概念与 I/O 端口的编址方式。做这类题抓住核心区别——独立编址有两套地址空间，用专用 I/O 指令；统一编址只有一套地址空间，用访存指令。A、B 考端口定义，C、D 考编址方式，因此从“地址空间”入手即可。

**推演**：

- I/O 接口中有若干可被 CPU 直接访问的寄存器，如数据寄存器、状态寄存器、控制寄存器。这些寄存器就是 I/O 端口，因此 B 正确。

- 状态端口存放外设状态信息，控制端口存放 CPU 给外设的控制命令。二者可以用同一个寄存器实现：CPU 读出时作为状态端口，CPU 写入时作为控制端口，通过读/写信号区分。因此 A 正确。

- 独立编址方式下，I/O 端口地址与主存地址属于两个相互独立的地址空间，CPU 通过专用 I/O 指令或控制信号（如 $\overline{M/IO}$）区分访问对象。因此 I/O 端口地址和主存地址在数值上可能相同，不会引起冲突。C 正确。

- 统一编址方式下，I/O 端口地址被映射到主存地址空间中，CPU 访问 I/O 端口就是使用访存指令。例如：
  - 读状态端口：$\text{LOAD } R_1, [\text{STATUS}]$
  - 写控制端口：$\text{STORE } [\text{CTRL}], R_2$

  可见 D 说“不能用访存指令访问 I/O 端口”是错误的。

题目要求选错误项，因此答案为 D。

**易错点**：

- 容易误选 C：有人认为端口地址和主存地址相同就必然冲突。实际上独立编址时二者属于不同地址空间，由专用指令或控制信号区分，地址相同也没问题。
- 容易误选 A：觉得状态端口是输入，控制端口是输出，不能共用。实际上可以通过读/写方向使用同一个寄存器。
- 容易混淆两种编址方式下的访问指令：统一编址用访存指令，独立编址用专用 I/O 指令。如果误以为统一编址必须用专用指令，就会错选 D 或漏选 D。

**命题规律**：本题考点是 I/O 接口与端口的基本概念、I/O 端口的两种编址方式。常见变式包括：考查统一编址和独立编址各自的优缺点，或给出某个地址判断是访问主存还是访问 I/O 端口，也可与中断、DMA 结合考查。复习时应把两种编址方式的地址空间、访问指令、辨别方式、优缺点做成对比表，并注意题干中“可以”“可能”“不能”等绝对性词语，往往就是命题陷阱。

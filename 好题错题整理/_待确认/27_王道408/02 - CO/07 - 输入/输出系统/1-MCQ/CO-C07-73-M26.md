# 选择题 第 26 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M26_题目.png|题目]]

26. 磁盘和主存进行数据交换时,大致可分为四个过程: ①寻道; ②旋转; ③连续读写磁盘块; ④结束、校验。则下列关于磁盘读写过程的叙述中,错误的是（  ）

A. 在①②④三个阶段都用到了中断处理

B. 在第③阶段，$DMA$ 控制器向 $CPU$ 请求的是总线使用权

C. 在第③阶段，$DMA$ 控制器使用总线的优先级比 $CPU$ 低

D. 在第③阶段，磁盘的读写和 $CPU$ 执行其他任务是可以并行执行的

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M26_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。第③阶段 DMA 控制器使用总线的优先级应高于 CPU，以保证高速外设的数据不丢失；C 说“DMA 优先级比 CPU 低”所以错误。

**解题切入点**：看到“寻道、旋转、连续读写磁盘块、校验”以及“DMA 控制器、中断、总线优先级”等关键词，应立即定位到 I/O 方式中的 DMA 与总线仲裁。做题关键是抓住一条主线：DMA 真正传数据时不需 CPU 逐字搬运，它只是向 CPU/总线仲裁器“借总线”；CPU 主要在开始、就绪、结束校验等处进行控制或中断处理。

**推演**：

磁盘与主存以块为单位交换数据时，通常采用 DMA 方式。其四个过程可理解为：

1. ①寻道：CPU 向磁盘控制器发出寻道命令，磁头定位到目标磁道；寻道完成需要通知 CPU，以便进入下一步。
2. ②旋转：等待目标扇区转到磁头下方；扇区定位完成后，可进入真正的数据传送阶段。
3. ③连续读写磁盘块：DMA 控制器向 CPU 申请总线使用权，获得总线后直接在磁盘与主存之间传送数据，不经过 CPU 内部寄存器。
4. ④结束、校验：块传送结束后进行校验，校验完成向 CPU 发中断，由 CPU 做结束处理。

逐项判断：

- A：按题目语境，①寻道完成、②旋转就绪、④结束校验完成都需要 CPU 通过中断等方式进行状态处理，A 不是错误项。
- B：第③阶段 DMA 控制器向 CPU 请求的是总线使用权，而不是要求 CPU 逐字处理数据，正确。
- C：DMA 控制器使用总线的优先级应高于 CPU，因为外设数据连续到达，若不能及时取走可能丢失；CPU 等待一个总线周期影响较小。C 说“低于 CPU”，错误。
- D：第③阶段真正搬数据的是 DMA 控制器，CPU 可以执行其他任务；只是当 CPU 与 DMA 同时争用总线时，CPU 可能需等待，但在宏观上二者可并行，正确。

**易错点**：

- 混淆“DMA 请求”和“中断请求”。DMA 请求是请求总线使用权，不是让 CPU 执行中断服务程序；中断主要用于传输结束、校验完成等需 CPU 收尾的时刻。
- 把优先级记反。DMA 请求的总线优先级通常高于 CPU，而非低于 CPU。
- 把“并行”理解为完全同时、互不干扰。DMA 传送时 CPU 可执行不访问总线的指令，但若争用总线，CPU 会因总线仲裁而等待。

**命题规律**：本题属于 I/O 方式高频考点，常将 DMA 与程序查询、中断方式对比考查。常见变式有：“DMA 传送期间 CPU 能否执行程序”“DMA 请求与中断请求的区别”“DMA 与 CPU 的总线优先级比较”等，也可结合磁盘平均存取时间 $T_{\mathrm{access}}=T_{\mathrm{seek}}+T_{\mathrm{rot}}+T_{\mathrm{transfer}}$ 考查。复习时建议整理三种 I/O 方式的对比表，重点记 DMA 工作流程：“预处理—总线请求—数据传送—结束中断”，并牢记 DMA 总线优先级高于 CPU。

# 选择题 第 26 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M26_题目.png|题目]]

26. 磁盘和主存进行数据交换时，大致可分为四个过程：①寻道；②旋转；③连续读写磁盘块；④结束、校验。则下列关于磁盘读写过程的叙述中，错误的是 ( )

A. 在①②④三个阶段都用到了中断处理
B. 在第③阶段，$DMA$ 控制器向 $CPU$ 请求的是总线使用权
C. 在第③阶段，$DMA$ 控制器使用总线的优先级比 $CPU$ 低
D. 在第③阶段，磁盘的读写和 $CPU$ 执行其他任务是可以并行执行的

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M26_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。理由：在 DMA 方式中，DMA 控制器申请并使用总线时，其总线优先级通常比 CPU 高，以保证数据传送的实时性，而不是比 CPU 低。

**解题切入点**：看到“磁盘读写过程 + 中断 + DMA”，应立刻定位到 I/O 控制方式中的“程序中断方式”和“DMA 方式”。可以类比为：DMA 是一个“硬件搬运工”，搬运数据时必须优先上车，否则数据可能丢失；CPU 是“调度员”，只在开始和结束时被通知一下即可。因此要抓住两个核心差异：① DMA 请求的是总线使用权，不是中断；② DMA 使用总线的优先级高于 CPU。

**推演**：

磁盘与主存交换数据的四个阶段分别对应：

1. **①寻道阶段**：CPU 向磁盘控制器发送寻道命令后，磁盘控制器控制磁头移动到目标磁道。寻道完成后，磁盘控制器会向 CPU 发出**中断请求**，CPU 响应并进行相应的中断处理。因此该阶段用到了中断处理。

2. **②旋转阶段**：等待目标扇区旋转到磁头下方。当扇区就绪时，磁盘控制器会产生“设备就绪”信号，通常以中断方式通知 CPU，使 CPU 知道可以开始数据传送。因此该阶段也用到了中断处理（按教材观点）。

3. **③连续读写磁盘块阶段**：数据传送采用 DMA 方式。DMA 控制器需要获得总线的控制权，才能控制磁盘与主存直接交换数据。因此：
   - DMA 控制器向 CPU 请求的是**总线使用权**，而不是中断请求，故选项 B 正确；
   - DMA 传送具有实时性，若不能及时获得总线，可能丢失数据，所以 DMA 控制器使用总线的优先级**高于** CPU，故选项 C 错误；
   - DMA 传输过程中，CPU 可以不参与数据传送，而执行其他任务，只要不与 DMA 同时争用总线即可，因此磁盘读写和 CPU 执行其他任务可以并行进行，故选项 D 正确。

4. **④结束、校验阶段**：DMA 传送完成后，DMA 控制器向 CPU 发出**中断请求**，CPU 进行结束处理和校验（如校验数据是否正确）。因此该阶段用到了中断处理。

综上：

- 选项 A：①②④三个阶段都用到了中断处理，**正确**；
- 选项 B：③阶段 DMA 控制器向 CPU 请求的是总线使用权，**正确**；
- 选项 C：③阶段 DMA 控制器使用总线的优先级比 CPU 低，**错误**；
- 选项 D：③阶段磁盘读写和 CPU 执行其他任务可以并行，**正确**。

因此错误的是选项 C。

**易错点**：

- 容易混淆“中断请求”和“DMA 请求”。中断请求是 CPU 处理异常或外部事件，而 DMA 请求是 DMA 控制器申请总线使用权，二者本质不同。
- 容易误认为 CPU 的总线优先级一定最高。实际在 DMA 方式中，为了不丢失数据，DMA 控制器使用总线的优先级通常高于 CPU。
- 容易认为 DMA 传送过程中 CPU 完全不能工作。正确的是：DMA 占用总线时 CPU 不能使用总线，但 CPU 仍可执行不访问总线的内部操作；总体上 CPU 可与磁盘读写并行执行其他任务。
- 对“②旋转阶段”是否使用中断处理存在疑问。按统考教材观点，扇区就绪时会发生中断通知 CPU，因此 A 选项正确，不能误判 A 为错误。

**命题规律**：本考点属于 408 中“I/O 方式”的重要考点，尤其偏爱考查 DMA 方式与程序中断方式的区别。常见变式包括：判断中断/DMA 请求的对象、DMA 传送过程需要 CPU 参与的时间、总线仲裁优先级、DMA 方式下 CPU 与 I/O 设备的并行性等。复习时应重点掌握：
- 程序中断方式与 DMA 方式各自的适用场景；
- DMA 控制器的功能；
- DMA 传送的预处理、数据传送、后处理三个阶段；
- 总线仲裁中 DMA 优先级高于 CPU 的原则。

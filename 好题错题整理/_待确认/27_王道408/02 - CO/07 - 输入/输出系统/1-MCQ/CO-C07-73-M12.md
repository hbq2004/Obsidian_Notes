# 选择题 第 12 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M12_题目.png|题目]]

12. 下列关于中断 $I/O$ 方式的叙述中,错误的是(  )
(A) $CPU$ 对外部中断的响应不可能发生在一条指令的执行过程中
(B) 在中断 $I/O$ 方式下,外设接口中的寄存器和 $CPU$ 中的寄存器直接交换数据
(C) 中断请求的是 $CPU$ 时间,要求 $CPU$ 执行程序来处理发生的相关事件
(D) 只要有中断请求发生,一条指令执行结束后 $CPU$ 就进入中断响应周期

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M12_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。理由：CPU 响应中断不能只凭“有中断请求 + 指令执行结束”，还必须满足“CPU 允许中断/开中断”等条件，D 漏掉了关键条件，所以错误。

**解题切入点**：  
先找“绝对化”或“缺条件”的选项。D 中“只要……就……”是典型的绝对化表述；回忆中断响应条件：中断请求、CPU 允许中断、当前指令执行结束。可类比判题程序的 `if (中断请求 && 允许中断 && 指令结束)`，不能只判断前两个条件。同时要区分中断 I/O 与 DMA：中断 I/O 仍由 CPU 执行程序完成数据传送，DMA 才让外设与主存直接交换数据。

**推演**：  
逐项判断：

- (A) 正确。CPU 对外部中断的检测/采样通常发生在一条指令执行结束后，正在执行的指令不会中途被外部中断打断。因此“CPU 对外部中断的响应不可能发生在一条指令的执行过程中”说法正确。

- (B) 正确。中断 I/O 方式下，外设接口中的寄存器与 CPU 中的寄存器通过数据总线进行数据交换，CPU 执行输入/输出指令完成传送。这里的“直接”是相对于“不经过主存”而言，并不是说不需要 CPU 参与。

- (C) 正确。中断请求的本质是请求 CPU 暂停当前程序，转去执行中断服务程序来处理外部事件，也就是占用 CPU 时间。

- (D) 错误。CPU 响应可屏蔽中断需要满足：
$$
\text{中断请求} \land \text{CPU允许中断（开中断）} \land \text{当前指令执行结束}
$$
若 CPU 处于关中断状态或该中断被屏蔽，即使指令执行结束，CPU 也不会进入中断响应周期。因此“只要有中断请求发生，一条指令执行结束后 CPU 就进入中断响应周期”说法错误。

**易错点**：  
1. 误选 A：把“外部中断”和“内部异常”混淆。缺页、除零等异常可以在指令执行过程中被响应，但外部中断通常不可以。  
2. 误选 B：把“外设接口寄存器与 CPU 寄存器直接交换数据”误解为“不需要 CPU 参与”。中断 I/O 仍然需要 CPU 执行指令；真正免 CPU 参与的是 DMA。  
3. 误把 D 当正确：漏掉“中断允许”条件。关中断时，即使有中断请求，CPU 也不会响应。

**命题规律**：  
考点是“I/O 方式”与“中断响应过程”。常见变式包括：将 D 改为“CPU 开中断且有中断请求，指令执行结束后就响应中断”，或将 B 改为“中断 I/O 方式下外设与主存直接交换数据”来考查与 DMA 的区别。复习时应把程序查询、中断 I/O、DMA 三种方式对比记忆，重点掌握谁发请求、谁响应、谁完成数据传送、数据是否经过 CPU 或主存；同时牢记中断响应的三个条件，警惕“只要……就”“一定”等绝对化表述。

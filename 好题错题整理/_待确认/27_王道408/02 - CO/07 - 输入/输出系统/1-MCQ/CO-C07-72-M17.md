# 选择题 第 17 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-72-M17_题目.png|题目]]

17.【2021统考真题】下列选项中，不属于 $I/O$ 接口的是 (  ) .

(A) 磁盘驱动器
(B) 打印机适配器
(C) 网络控制器
(D) 可编程中断控制器

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-72-M17_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A。磁盘驱动器是外部设备（I/O 设备），不是 I/O 接口；打印机适配器、网络控制器、可编程中断控制器都属于 I/O 接口（接口/控制器电路）。

**解题切入点**：拿到题先抓概念边界：I/O 接口是主机与外部设备之间的“中介硬件”，负责数据缓冲、状态控制、地址译码、中断/DMA 管理等；I/O 设备则是完成某种输入/输出或存储功能的末端设备。可类比：设备是“干活的人”，接口是“中间的调度台/翻译官”。题目中“适配器”“控制器”“中断控制器”都是接口或接口电路，而“驱动器”指设备本身。

**推演**：
- I/O 接口又称 I/O 控制器（设备控制器），是连接系统总线与外设的硬件电路。它不代替外设完成具体功能，而是解决主机与外设之间速度、格式、时序等不匹配问题，并向 CPU 提供状态、控制、数据三类寄存器。
- 逐项判断：
  - A 磁盘驱动器：包含磁盘盘片、主轴电机、磁头及定位机构等，是实际存储设备。若为“磁盘控制器”或“磁盘适配器”，则属于接口；但本题是“驱动器”，属于 I/O 设备。
  - B 打印机适配器：例如并行打印接口/LPT 适配器，用于主机与打印机之间的连接和数据转换，属于 I/O 接口。
  - C 网络控制器：即网络适配器/网卡，负责主机与网络介质之间的数据收发、缓冲和格式转换，属于 I/O 接口。
  - D 可编程中断控制器：如 8259A，用于管理多个 I/O 设备的中断请求、优先级和中断向量，是 I/O 接口/中断控制电路。
- 因此，A 不属于 I/O 接口。

**易错点**：
- 把“磁盘驱动器”误认为“磁盘控制器”。驱动器是设备，控制器/适配器才是接口。
- 误以为“控制器”一定指设备，其实 I/O 控制器/设备控制器属于接口，如网络控制器、磁盘控制器、打印机适配器。
- 对“可编程中断控制器”缺乏认知，以为它只是 CPU 内部部件；实际上它属于 I/O 系统接口电路，用于管理中断。
- 做题时应逐字读题，注意“适配器/控制器/接口/驱动器”等关键词。

**命题规律**：
- 考点定位：I/O 系统基本概念，I/O 设备与 I/O 接口的区分。
- 常见变式：将“不属于”改为“属于 I/O 接口的是”，或将选项替换为“磁盘控制器、DMA 控制器、显卡、显示器”等，考查同一概念。
- 复习建议：建立“CPU/内存—总线—I/O 接口—I/O 设备”的层次结构；熟记常见接口（打印机适配器、网卡、显卡、磁盘控制器、中断控制器、DMA 控制器）与常见外设（磁盘驱动器、键盘、鼠标、显示器、打印机）的典型例子，并掌握 I/O 接口的基本功能。

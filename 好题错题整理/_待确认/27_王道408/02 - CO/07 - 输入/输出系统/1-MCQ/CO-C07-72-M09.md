# 选择题 第 9 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-72-M09_题目.png|题目]]

9. 在统一编址情况下,就 $I/O$ 设备而言,其对应的 $I/O$ 地址不可取的是( ).

A. 要求固定在地址高端

B. 要求固定在地址低端

C. 要求相对固定在地址的某部分

D. 可以随意在地址的任何地方

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-72-M09_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。统一编址下，I/O 端口的地址属于主存地址空间的一部分，必须相对固定在某个地址区域中，不能随意放在地址的任何地方。

**解题切入点**：  
先抓“统一编址”与“I/O 地址”。统一编址的本质是只有一个地址空间，I/O 端口和主存单元共用地址编码，所以本题不是考某个具体地址值，而是考“地址空间如何划分”。可以类比竞赛中给数据开映射表：每个 key 对应的位置必须事先确定才能查询；I/O 地址也要在系统设计时确定为一个固定区间，不能“随手放”。

**推演**：  
统一编址即存储器映射 I/O。设整个系统的地址空间为 $U$，主存单元区为 $M$，I/O 端口区为 $D$，则 $D$ 是 $U$ 的一个子集，并且
$$M \cap D = \varnothing$$
CPU 访问某个地址 $A$ 时，地址译码器判断 $A\in D$ 还是 $A\in M$：若 $A\in D$，则使能 I/O 接口；若 $A\in M$，则使能主存。

因此 $D$ 必须在设计时固定下来。它可以放在地址高端，例如
$$D=[N-k,\ N-1]$$
也可以放在地址低端，例如
$$D=[0,\ k-1]$$
也可以放在中间某一段：
$$D=[s,\ s+k-1]$$

这些都满足“相对固定在地址的某部分”，所以 A、B 作为具体设计方案并不错误，C 是更一般的正确表述。

若按 D 的说法，I/O 地址可以随意放在地址的任何地方，则会造成 I/O 区与主存区边界不确定，同一个地址可能同时被主存和 I/O 接口响应，导致总线冲突；操作系统和驱动程序也无法预知外设地址。这正与统一编址的基本要求矛盾，因此 D 不可取。

**易错点**：  
- 误选 A 或 B：A、B 只是 I/O 地址区间的两种可能安排，不是逻辑错误；题目问“不可取”，只有 D 是原则性错误。  
- 把“设计者可以自由选择”误解为“可以随意放”：设计者可以把 I/O 区放在高端、低端或中间，但一旦选定就必须固定；D 中的“随意”指没有固定规则，不能接受。  
- 混淆统一编址与独立编址：独立编址有独立的 I/O 地址空间和专用 I/O 指令；统一编址中 I/O 地址占用主存地址空间，更强调保留固定区域。

**命题规律**：  
考点是 I/O 编址方式，主要是统一编址与独立编址的地址空间安排和区别。常见变式包括：判断两种编址的优缺点、画出地址空间分配、给出地址线数量求 I/O 端口可占用范围、结合指令系统问访存指令能否访问外设等。复习时应抓住两条主线：一是“I/O 地址是否占用主存地址空间”，二是“是否有专用 I/O 指令及控制信号”。看到“统一编址”，应立刻想到“地址空间的一部分、必须固定保留区域”，从而快速排除 D。

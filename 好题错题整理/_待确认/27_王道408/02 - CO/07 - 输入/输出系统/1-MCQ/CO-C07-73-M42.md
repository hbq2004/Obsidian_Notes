# 选择题 第 42 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M42_题目.png|题目]]

42.【2018统考真题】下列关于外部 $I/O$ 中断的叙述中，正确的是（  ）
(A) 中断控制器按所接收中断请求的先后次序进行中断优先级排队
(B) $CPU$ 响应中断时，通过执行中断隐指令完成通用寄存器的保护
(C) $CPU$ 只有在处于中断允许状态时，才能响应外部设备的中断请求
(D) 有中断请求时，$CPU$ 立即暂停当前指令执行，转去执行中断服务程序

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M42_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。普通外部 I/O 中断属于可屏蔽中断，CPU 必须处于中断允许状态（$EINT=1$），并等当前指令执行完后才能响应。

**解题切入点**：看到“外部 I/O 中断”，先回忆 CPU 响应中断的条件：中断请求、CPU 允许中断、当前指令执行完毕、无更高优先级中断请求。可以把中断控制器类比为“优先队列”：它按优先级取事件，而不是按请求到达顺序；CPU 也不能在指令执行中间被“打断”，必须等当前指令这条“原子操作”结束。

**推演**：

CPU 响应外部 I/O 中断的基本流程是：

1. 外部设备发出中断请求，中断控制器进行优先级判优，并向 CPU 发出中断请求信号。
2. CPU 在当前指令执行完毕时检测中断请求；若满足中断允许条件，则进入中断响应周期。
3. 中断响应周期由硬件自动完成“中断隐指令”的操作：
   $$EINT \leftarrow 0 \quad(\text{关中断})$$
   $$PC \to \text{栈或断点保存单元}\quad(\text{保存断点})$$
   $$PC \leftarrow \text{中断服务程序入口地址（或中断向量）}$$

中断隐指令保存的是断点（$PC$）及必要的程序状态字信息，并不负责保存通用寄存器。通用寄存器属于“现场”，由中断服务程序用压栈等指令完成保护。

逐项分析：

- A 错：中断控制器按中断优先级排队/判优，不是按收到中断请求的先后次序排队。高优先级请求后到也可以优先被响应，甚至可能打断低优先级中断服务。
- B 错：中断隐指令完成的是关中断、保存断点、取中断向量等硬件操作；通用寄存器的保护由中断服务程序完成。
- C 对：普通外部 I/O 中断是可屏蔽中断，CPU 只有在中断允许状态下才响应。
- D 错：有中断请求时，CPU 不会立即暂停当前指令，而是等当前指令执行完毕后再响应。

**易错点**：

- 混淆“断点”和“现场”：断点 $PC$ 是中断隐指令保存的，通用寄存器是中断服务程序保存的。
- 误以为中断控制器是“先来先服务”：实际上是按优先级判优。
- 误以为中断请求一到，CPU 立即执行中断服务程序：CPU 必须等当前指令执行结束。
- 对“中断允许状态”理解不准确：题中“外部 I/O 中断”按可屏蔽中断理解；非屏蔽中断不受中断允许状态限制，但一般不属于普通外部 I/O 中断的考点范围。

**命题规律**：

本题属于“输入输出系统”中“中断方式”的经典考点，核心考查 CPU 响应中断的条件、中断隐指令的功能、中断控制器判优原则。常见变式有：“中断隐指令完成哪些操作”“CPU 响应中断的条件不包括什么”“中断服务程序与中断隐指令的区别”“中断屏蔽与中断优先级的关系”等。复习时应把硬件自动完成的操作与软件完成的操作分清楚，并牢记中断响应的四个条件：中断请求、允许中断、当前指令执行完毕、更高优先级中断未占用 CPU。

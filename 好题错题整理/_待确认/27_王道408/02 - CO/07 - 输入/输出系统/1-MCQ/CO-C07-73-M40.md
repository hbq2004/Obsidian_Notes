# 选择题 第 40 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M40_题目.png|题目]]

40.【2015统考真题】在采用中断$I/O$方式控制打印输出的情况下，$CPU$和打印控制接口中的$I/O$端口之间交换的信息不可能是（ ）

A. 打印字符  
B. 主存地址  
C. 设备状态  
D. 控制命令

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M40_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。中断 $I/O$ 方式下，CPU 与打印控制接口中的 $I/O$ 端口之间交换的是数据（打印字符）、设备状态和控制命令；主存地址是 DMA 方式中需要提供的信息，不属于中断 $I/O$ 方式下与打印接口端口交换的信息。

**解题切入点**：看到“中断 $I/O$ 方式”，应立刻与“程序查询方式”“DMA 方式”对照。中断 $I/O$ 是以字符为单位、由 CPU 干预完成的，CPU 每次只把“一个字符”送给接口；而“主存地址”是 DMA 控制器批量搬运数据时需要的。打比方说，中断 $I/O$ 像“文员逐字送文件到打印机”，不需要告诉打印机文件在仓库的哪个货位；DMA 才像“搬运工”，需要知道源地址和目的地址。

**推演**：

1. 打印控制接口中的 $I/O$ 端口按功能可分为：
   - 数据端口：存放要打印的字符；
   - 状态端口：反映打印机当前状态，如忙、空闲、缺纸、出错；
   - 控制端口：接收 CPU 发来的控制命令，如启动打印、允许中断等。

2. 采用中断 $I/O$ 方式控制打印输出时，大致过程是：
   - CPU 通过控制端口向打印接口发送控制命令，如“启动打印”“允许中断”；
   - 打印接口通过状态端口向 CPU 提供设备状态；
   - 当打印机可以接收新字符时，接口发出中断请求；
   - CPU 响应中断后，在中断服务程序中将要打印的字符写入数据端口；
   - 打印接口再将该字符送给打印机打印。

3. 因此，CPU 与打印控制接口中的 $I/O$ 端口之间交换的信息包括：
   - 打印字符，对应数据信息；
   - 设备状态，对应状态信息；
   - 控制命令，对应控制信息。

4. “主存地址”不会出现在 CPU 与打印接口端口的直接信息交换中。CPU 从主存中取出打印字符时，确实需要访问主存地址，但这个主存地址是送往主存的，而不是送往打印控制接口的 $I/O$ 端口。

所以不可能是“主存地址”。

**易错点**：

- 看到“打印输出”就认为传送的是打印字符，但题目问“不可能是”，打印字符恰恰是可能的。
- 容易把 DMA 方式下的“主存地址”“传送字节数”等初始化参数误认为中断 $I/O$ 方式也会交换。
- 容易混淆“主存地址”和“$I/O$ 端口地址”。CPU 访问 $I/O$ 端口时也要给出端口地址，但这是 $I/O$ 地址，不是主存地址。
- 审题不仔细，忽略“不可能”这一否定词，从而导致选错。

**命题规律**：本题属于 $I/O$ 控制方式的基础题，核心是区分程序查询、中断 $I/O$、DMA 三种方式中 CPU 与接口、主存之间的信息流向。常见变式有：考查 DMA 方式中 CPU 需要初始化哪些参数、哪种方式传送单位是“块”、哪种方式外设与主存直接交换数据、哪种方式需要 CPU 频繁干预。复习时应列表对比三种方式：数据传送单位、由谁控制传送、是否需要主存地址、中断次数、适用设备等特点。

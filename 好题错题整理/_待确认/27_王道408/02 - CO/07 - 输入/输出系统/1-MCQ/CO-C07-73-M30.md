# 选择题 第 30 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M30_题目.png|题目]]

30. 采用周期挪用进行 $DMA$ 数据传送时，每传送一个数据要占用一个(   ) 的时间.

( A ) 指令周期
( B ) 机器周期
( C ) 时钟周期
( D ) 存取周期

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M30_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。周期挪用方式下，每传送一个数据需占用一个存取周期，因为一次数据传送必须完成一次主存读或写。

**解题切入点**：拿到题目先抓“周期挪用”和“每传送一个数据”这两个关键词。DMA 传送的本质是设备与主存直接交换数据，因此要考虑主存的访问时间。“挪用”的对象是 CPU 对总线的使用权，每次挪用对应一次主存访问，即存取周期。

**推演**：DMA 周期挪用（cycle stealing）的基本过程：当设备准备好一个数据时，向 DMA 控制器发出请求；DMA 控制器向 CPU 申请总线使用权，CPU 在当前机器周期结束后让出总线；DMA 获得总线后，在总线上进行一次主存读/写，把设备中的一个数据传送到主存（或反向）。由于主存每次读/写一个存储单元所需的时间就是存取周期，因此每次 DMA 数据传送占用一个存取周期。

注意：一个存取周期可能包含若干个时钟周期；CPU 的机器周期是若干个时钟周期组成的 CPU 操作周期，它与主存存取周期虽然可能相等或不同，但 DMA 传送与 CPU 的机器周期没有必然对应关系。一个指令周期内，DMA 可能多次挪用总线，每挪用一次传送一个数据，就占用一个存取周期。

**易错点**：  
1. 误选 C：时钟周期是 CPU 时钟频率的倒数，一次主存访问往往需要多个时钟周期，不是“一个时钟周期”。  
2. 误选 B：机器周期是 CPU 完成某种基本操作的时间，DMA 传送不是 CPU 内部的机器操作，不能说是机器周期。  
3. 误选 A：指令周期是 CPU 取指并执行一条指令的时间，DMA 传送可以在指令执行过程中穿插进行，与指令周期无关。  
4. 容易忽略“每传送一个数据”这一条件：若问传送一个数据块所需时间，则需要考虑多个存取周期及请求开销，而不是一个存取周期。

**命题规律**：本考点是 DMA 三种工作方式（停止 CPU 访问主存、周期挪用、交替访问）中的“周期挪用”特点。常见变式：给出周期挪用示意图，问发生总线请求的时刻；或比较 DMA 与中断在传送单位、响应时间上的区别。复习时应理清 CPU 周期、总线周期、存取周期的关系，并牢记 DMA 数据传送的基本单位是“数据块”，而每次总线操作只传一个“数据字”，占用一个存取周期。

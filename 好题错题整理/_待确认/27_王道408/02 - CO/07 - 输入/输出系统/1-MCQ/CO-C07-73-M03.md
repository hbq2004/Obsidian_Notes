# 选择题 第 3 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M03_题目.png|题目]]

3. 关于程序中断方式和 $DMA$ 方式的叙述,错误的是（ ）.  
I. $DMA$ 的优先级比程序中断的优先级要高.  
II. 程序中断方式需要保存现场,$DMA$ 方式在传输过程中不需要保存现场.  
III. 程序中断方式的中断请求是为了报告 $CPU$ 数据的传输结束,而 $DMA$ 方式的中断请求完全是为了传送数据.  
A. 仅 II  
B. II、III  
C. 仅 III  
D. I、III

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M03_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C（仅 III）。理由：I、II 说法正确；III 把程序中断与 DMA 的“中断请求作用”颠倒了——程序中断是请求 CPU 参与数据传送/处理，而 DMA 的中断请求是在整块数据传送结束后报告 CPU 并请其做后续处理，并非“完全为了传送数据”。

**解题切入点**：看到“程序中断方式 vs DMA 方式”的叙述判断题，先抓本质：程序中断需要 CPU 介入，DMA 由 DMA 控制器直接完成数据传送，CPU 只在提出请求和结束后处理时介入。再逐条检验每句话是否触及这两个本质。就像做组合判断题可以先排掉最确定的 I 和 II，再仔细推敲 III 有没有“张冠李戴”。

**推演**：

- **I 正确**：DMA 请求的优先级通常高于程序中断请求。因为 DMA 传送数据速度快，若 CPU 不能及时响应，可能导致数据丢失；而程序中断晚一点响应一般不会造成数据丢失。所以 $P(\mathrm{DMA}) > P(\text{程序中断})$ 的说法正确。

- **II 正确**：程序中断方式中，CPU 响应中断后要转去执行中断服务程序，因此需要保存程序断点和现场信息，如 PC、PSW、通用寄存器等。DMA 方式在传输过程中，数据由 DMA 控制器控制完成，CPU 不需要执行中断服务程序，也就无需保存现场；CPU 可能暂时停止访问主存或让出总线，但其内部寄存器和程序状态没有被改变。注意题干说的是“传输过程中”，这一说法成立。

- **III 错误**：  
  程序中断方式中，每当设备准备好一个数据或完成一次数据传送，设备会向 CPU 发出中断请求，CPU 执行中断服务程序来参与本次数据传送或处理。所以程序中断请求的本质是“请求 CPU 参与传送/处理”，而不是“报告 CPU 数据传输结束”。  
  DMA 方式中，DMA 控制器完成一整块数据传送后，才向 CPU 发出中断请求，通知 CPU“传送结束”，并请 CPU 进行后续处理，例如校验数据、决定是否继续传送等。因此 DMA 的中断请求并不是“完全为了传送数据”本身，而是为了报告结束并请求后处理。  
  故 III 两处表述都错误。

综上，只有 III 错误，所以答案是 C。

**易错点**：

1. **误以为 DMA 优先级一定低于程序中断**：应记住 DMA 通常高于一般程序中断，否则高速设备可能丢数据。
2. **误以为 DMA 传输过程中需要保存 CPU 现场**：DMA 传输由硬件控制，CPU 不执行服务程序，寄存器状态不变；但 DMA 结束后的中断请求被响应时，仍需要保存现场。
3. **把中断请求目的记反**：程序中断是在传送过程中请求 CPU 介入；DMA 中断是在整块传送结束后报告完成，不是用来“逐次传送数据”的。
4. **忽略题干限定词**：II 说“传输过程中”，不能拿“DMA 结束后的中断处理”来否定它。

**命题规律**：考点是程序中断方式与 DMA 方式的区别，常以“判断叙述正误”或“对比两者特点”的选择题出现。干扰项多设置在“优先级高低”“是否需要保存现场”“中断请求的作用”“CPU 是否参与传输”等地方。变式可能给出数据传送流程，判断哪一步会打断 CPU、哪一步不打断；或结合周期挪用、总线控制、中断处理过程进行综合考查。复习时建议列表对比：是否需 CPU 干预、传送单位、请求作用、响应时机、优先级、保存现场等，并熟练背诵 408 常考结论。

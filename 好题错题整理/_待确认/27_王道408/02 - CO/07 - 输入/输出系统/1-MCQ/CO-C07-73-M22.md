# 选择题 第 22 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M22_题目.png|题目]]

22. 下列叙述中，（ ）是正确的.

A. 程序中断方式和$DMA$方式中实现数据传送都需要中断请求.

B. 程序中断方式中有中断请求,$DMA$方式中没有中断请求.

C. 程序中断方式和$DMA$方式中都有中断请求,但目的不同.

D. $DMA$要等指令周期结束时才可以进行周期窃取.

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M22_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。程序中断和 DMA 方式中都有中断请求，但前者要求 CPU 参与数据传送，后者是在 DMA 数据块传送结束后通知 CPU 做后续处理，二者目的不同。

**解题切入点**：拿到题目先区分“程序中断”和“DMA”中请求的类型与时机。程序中断靠 CPU 执行中断服务程序来传送数据；DMA 由 DMA 控制器直接传数据，不必让 CPU 逐字传送，但传送完成后会向 CPU 发中断请求。做题时可类比：程序中断是“每次都要叫 CPU 来搬东西”，DMA 是“搬运工自己搬完一车后，再向 CPU 报告完成”。锁定这个差异即可判断 A、B、C。

**推演**：

逐项分析：

A 项：程序中断方式中，I/O 设备准备好数据后发出中断请求，CPU 响应中断并执行中断服务程序完成数据传送，所以程序中断方式中实现数据传送需要中断请求。但 DMA 方式的数据传送是由 DMA 控制器直接控制主存与 I/O 设备之间传送，传送过程中不需要 CPU 逐字介入，也不需要为每个数据都发中断请求。因此“DMA 方式实现数据传送都需要中断请求”说法错误。

B 项：DMA 方式在数据传送过程中没有逐字的中断请求，但在整块数据传送结束后，DMA 控制器会向 CPU 发出中断请求，以便 CPU 进行结束处理，如数据校验、启动下一次传送等。因此“DMA 方式中没有中断请求”说法错误。

C 项：程序中断方式和 DMA 方式都有中断请求，但目的不同。程序中断请求的目的是请求 CPU 执行中断服务程序来完成数据的输入/输出；DMA 方式中的中断请求目的是告诉 CPU“数据块已经传送完成”，请 CPU 进行善后处理。二者目的不同，C 正确。

D 项：DMA 的“周期窃取”也叫周期挪用，是指 DMA 控制器在 CPU 不访存时占用一个存储周期或总线周期来传送数据，它不需要等到指令周期结束。如果 CPU 正要访存，DMA 可以让 CPU 暂停一个存储周期，然后继续执行指令。程序中断响应才需要等当前指令执行结束，DMA 周期窃取不必等指令周期结束。因此 D 错误。

综上，正确选项为 C。

**易错点**：

1. 误以为 DMA 方式完全没有中断请求。注意：DMA 数据传送本身不需要逐字中断，但传送完成后确实会发中断请求。
2. 混淆“DMA 请求”“总线请求”和“中断请求”。DMA 请求是 I/O 设备向 DMA 控制器发出的传送请求；总线请求是 DMA 控制器向 CPU 申请总线控制权；中断请求是 DMA 传送结束后向 CPU 发出的完成通知。
3. 混淆中断响应时机与 DMA 周期窃取时机。程序中断响应通常在指令周期结束时；DMA 周期窃取只需在存储周期或总线周期边界插入，不必等指令周期结束。
4. 误选 A，是因为没有注意到 DMA 是成块传送，不需要每个数据都靠中断请求让 CPU 传送。

**命题规律**：本题属于 I/O 方式概念辨析题，高频考点是程序中断方式与 DMA 方式的区别，包括请求类型、响应时机、传送单位、CPU 介入程度等。常见变式有：

- 对比程序中断与 DMA 的传送单位：程序中断通常按字/字节传送，DMA 按数据块传送；
- 考查程序中断响应时机：CPU 在当前指令周期结束时响应中断；
- 考查 DMA 周期窃取时机：可在指令执行过程中插入；
- 考查 DMA 传送完成后中断请求的作用：用于通知 CPU 进行后续处理。

复习时建议把程序查询方式、程序中断方式、DMA 方式放在一起对比，重点记忆“谁发起传送、谁控制总线、传送单位、CPU 响应时机、结束后如何通知 CPU”，这类概念题即可快速定位。

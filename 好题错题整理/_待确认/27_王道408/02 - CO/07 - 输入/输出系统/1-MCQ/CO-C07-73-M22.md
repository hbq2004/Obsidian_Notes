# 选择题 第 22 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M22_题目.png|题目]]

22. 下列叙述中，（ ）是正确的.

(A) 程序中断方式和 $DMA$ 方式中实现数据传送都需要中断请求.
(B) 程序中断方式中有中断请求, $DMA$ 方式中没有中断请求.
(C) 程序中断方式和 $DMA$ 方式中都有中断请求, 但目的不同.
(D) $DMA$ 要等指令周期结束时才可以进行周期窃取.

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M22_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。程序中断方式和 DMA 方式都有中断请求，但程序中断的请求是请求 CPU 参与数据传送，DMA 的请求是通知 CPU 一组数据传送结束，目的不同。

**解题切入点**：先画 I/O 方式流程图。程序中断方式像“每送一单货都要老板亲自跑一趟”；DMA 方式像“快递车自己把货物放进仓库，全部放完后才给老板发一条取件通知”。这道题的关键是分清“中断请求的目的”和“CPU/总线响应的时机”，尤其不能把普通中断响应的“指令周期结束”套到 DMA 周期窃取上。

**推演**：

程序中断方式中，外设准备好后向 CPU 发出中断请求，CPU 在当前指令执行结束后响应中断，进入中断服务程序，由 CPU 执行输入/输出指令完成一个数据的传送。因此，程序中断方式中的中断请求是为了“请求 CPU 来传送本次数据”。

DMA 方式中，外设通过 DMA 控制器直接与内存交换数据。DMA 控制器先申请总线，获得总线后按存储周期进行成组传送，数据不经过 CPU。整组数据传送结束后，DMA 控制器再向 CPU 发出一次中断请求，目的是通知 CPU“一组数据传送完毕”或“传送过程中出错”，而不是请求 CPU 去搬运数据。

逐项判断：

- A 错：DMA 方式实现数据传送本身不需要中断请求，DMA 是在整组数据传送结束后才发中断请求。
- B 错：DMA 方式中也有中断请求，只是它出现在 DMA 传送结束时。
- C 对：两种方式都有中断请求，但一个用于请求 CPU 传送数据，一个用于报告 DMA 传送结束，目的不同。
- D 错：周期窃取是 DMA 控制器在存储周期/总线周期级别插入访存操作，不需要等一条指令完整执行结束。只有普通中断响应才需要等当前指令周期结束。

因此正确选项是 C。

**易错点**：

- 易误选 A：误以为 DMA 也需要中断来逐次传送数据。实际上 DMA 传送过程由硬件完成，中断只用于传送结束后的通知。
- 易误选 B：看到“DMA 传送不需要 CPU 干预”，就误以为 DMA 完全没有中断请求，忽略了 DMA 结束中断。
- 易误选 D：把“程序中断响应需要等指令周期结束”张冠李戴到 DMA 周期窃取上。DMA 周期窃取发生在存储周期/总线周期级别，不等指令周期结束。
- 要区分“DMA 请求”和“DMA 结束中断”：DMA 请求是申请总线，DMA 结束中断才是向 CPU 报告传送完成。

**命题规律**：本题属于“I/O 控制方式”中的高频概念题，核心是程序中断方式与 DMA 方式的区别。常见变式包括：比较两种方式的中断目的、传送单位、CPU 参与程度、响应时机；结合总线仲裁考查 DMA 周期窃取；判断“DMA 没有中断请求”“DMA 传送一定让 CPU 停止”等绝对化表述。复习时应把程序中断、DMA 的流程画清楚，重点记住：程序中断请求是“要 CPU 传数据”，DMA 中断请求是“报告传完了”。

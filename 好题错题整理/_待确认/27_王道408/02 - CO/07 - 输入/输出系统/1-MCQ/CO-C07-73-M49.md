# 选择题 第 49 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M49_题目.png|题目]]

49.【2022 统考真题】下列关于中断 $I/O$ 方式的叙述中,不正确的是 ( )  
A. 适用于键盘、针式打印机等字符型设备  
B. 外设和主机之间的数据传送通过软件完成  
C. 外设准备数据的时间应小于中断处理时间  
D. 外设为某进程准备数据时 $CPU$ 可运行其他进程

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M49_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。中断 $I/O$ 方式要求外设准备数据的时间应大于中断处理时间，C 说“小于”，故不正确。

**解题切入点**：拿到题目先抓“中断 $I/O$ 方式”的核心场景：低速字符设备、每次传输一个数据单位、传送由中断服务程序中的软件完成、外设准备数据期间 CPU 可并行做其他事。再逐项判断；C 考查的是中断处理速度与外设准备速度之间的匹配关系，只要想“CPU 是否来得及处理”即可。

**推演**：

中断 $I/O$ 方式一次数据传送的基本过程是：

1. CPU 启动外设；
2. 外设准备数据，CPU 执行其他程序；
3. 外设准备好一个数据后发出中断请求；
4. CPU 响应中断，执行中断服务程序，通过软件完成一次数据传送；
5. 返回中断前的程序继续执行。

逐项分析：

- A 正确：键盘、针式打印机等属于低速字符型设备，每次传送的数据量小，适合使用中断 $I/O$ 方式。每次外设准备好一个字符就发一次中断，CPU 处理一次，正好匹配这类设备的速度。
- B 正确：中断 $I/O$ 方式中，外设与主机之间的数据传送由 CPU 执行中断服务程序中的输入/输出指令来完成，属于软件完成；这正是与 DMA 方式的重要区别，DMA 方式才由硬件完成数据传送。
- C 不正确：设外设准备一个数据的时间为 $T_{\text{prep}}$，一次中断处理所需时间为 $T_{\text{int}}$。为了保证 CPU 来得及处理上一个数据，不至于在未处理完时下一个数据又已准备好，应满足：
$$
T_{\text{prep}} > T_{\text{int}}
$$
也就是说，外设准备数据的时间应**大于**中断处理时间，而不是小于。若 $T_{\text{prep}} < T_{\text{int}}$，外设发中断过于频繁，CPU 可能来不及响应，会造成数据丢失或错误。
- D 正确：外设准备数据时并不占用 CPU，CPU 可以运行其他进程；只有外设准备好数据并发起中断后，CPU 才暂停当前任务去执行中断服务程序。

因此不正确的是 C。

**易错点**：

1. 把 C 的方向记反。正确关系是“外设准备数据的时间 > 中断处理时间”，而不是“小于”。若记为“小于”，就会和中断方式适用于慢速设备这一前提矛盾。
2. 误以为 B 错。有些同学认为数据传送是通过外设控制器硬件完成的，但中断 $I/O$ 中数据传送靠中断服务程序中的指令完成，本质是软件方式；DMA 才是硬件方式。
3. 误以为 D 错。中断虽然会打断 CPU，但打断发生在“外设准备完数据发出中断后”；在准备数据期间 CPU 完全可以运行其他进程。

**命题规律**：本题属于“输入输出系统”中关于中断 $I/O$ 方式基本概念的考查，重点区分程序查询方式、中断 $I/O$ 方式、DMA 方式的适用设备、CPU 参与程度、数据传送方式。常见变式包括：判断某设备适合哪种 $I/O$ 方式；比较中断方式与 DMA 方式的优缺点；给出外设速度和中断处理时间，判断是否可能丢失数据。复习时应将三种 $I/O$ 方式对比记忆，尤其注意中断方式与 DMA 方式中“谁来控制数据传送”这一关键区别。

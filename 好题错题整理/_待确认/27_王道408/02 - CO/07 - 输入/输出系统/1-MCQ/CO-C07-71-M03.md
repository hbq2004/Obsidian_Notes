# 选择题 第 3 题

3. $CRT$的分辨率为 $1024 \times 1024$ 像素,像素的颜色数为 256, 刷新存储器的每单元字长为( ),总容量为( )
A. $8B,25MB$
B. $8bit,1MB$
C. $8bit,256KB$
D. $8B,32MB$

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-71-M03_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。每个像素颜色数为 $256=2^8$，故一个像素需要 $8$ bit 存储，即每单元字长为 $8$ bit；总容量为 $1024\times1024\times 8$ bit $=1$ MB。

**解题切入点**：先把刷新存储器理解成一个“像素颜色记录表”：它要存下整屏所有像素的颜色信息。因此总容量 = 像素总数 × 每个像素所占的位数；而“每单元字长”就是每个像素对应的存储位数。类似算法题中“计算一个二维数组占据多少内存”：元素个数 × 元素大小。

**推演**：
- 分辨率为 $1024\times1024$，所以像素总数为  
  $$N=1024\times1024=2^{10}\times2^{10}=2^{20}$$
- 像素颜色数为 $256$，因为 $256=2^8$，所以每个像素的颜色编码需要  
  $$b=\log_2 256=8\text{ bit}$$
- 刷新存储器每个存储单元存放一个像素的颜色信息，因此“每单元字长”为  
  $$8\text{ bit}=1\text{ B}$$
- 总容量为  
  $$C = N \times b = 2^{20}\times 8\text{ bit} = 2^{20}\text{ B} = 1\text{ MB}$$
  注意计算机中 $1\text{ MB}=2^{20}\text{ B}=1048576\text{ B}$，而不是 $10^6$ B。

所以正确选项为 B。

**易错点**：
1. **bit 与 Byte 混淆**：字长通常是“位”，不能写成“B”；A、D 把 $8\text{ bit}$ 误写为 $8\text{ B}$。
2. **容量单位换算错误**：把 $1024\times1024$ 误当 $10^6$，导致认为容量约 $1.05$ MB，从而错误选择包含“1MB”之外的选项；应使用二进制倍数。
3. **忽略颜色数到位数的换算**：颜色数 $256$ 对应 $8$ bit，但要注意 $2^8=256$，而不是 $256$ B。
4. **混淆“总容量”与“每单元字长”**：前者是整个显存大小，后者是单个像素的位数，二者相差像素总数倍。

**命题规律**：这是计算机组成原理中“显示存储器（显存）容量计算”的经典考点。常考变式包括：
- 给出刷新频率，求显存带宽：带宽 = 显存容量 × 刷新频率；
- 给出显存容量和分辨率，反求最大颜色数；
- 结合字符显示方式，计算字符缓冲存储器的容量。

复习建议：牢记核心公式  
$$\text{显存容量}=\text{分辨率}\times\text{每像素位数}$$  
并注意单位换算：$1\text{ B}=8\text{ bit}$，$1\text{ KB}=2^{10}\text{ B}$，$1\text{ MB}=2^{20}\text{ B}$。熟练掌握后即可快速判断。

# 选择题 第 23 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M23_题目.png|题目]]

23. 以下关于 $DMA$ 方式进行 $I/O$ 的描述中,正确的是（  ）.

A. 一个完整的 $DMA$ 过程,部分由 $DMA$ 控制器控制,部分由 $CPU$ 控制

B. 一个完整的 $DMA$ 过程,完全由 $CPU$ 控制

C. 一个完整的 $DMA$ 过程,完全由 $DMA$ 控制器控制,$CPU$ 不介入任何控制

D. 一个完整的 $DMA$ 过程,完全由 $CPU$ 采用周期挪用法控制

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M23_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A。一个完整的 DMA 过程由 CPU 预处理、DMA 控制器数据传送、CPU 中断后处理三部分组成，因此部分由 CPU 控制、部分由 DMA 控制器控制。

**解题切入点**：拿到题目要先抓住“完整的 DMA 过程”与“数据传送阶段”的区别。就像算法竞赛中“读入数据、处理数据、输出结果”三个阶段可能由不同模块完成，DMA 传输中 CPU 负责“初始化和收尾”，DMA 控制器负责“大批量搬运数据”，不能把某个阶段的特点扩大成整个流程的特点。

**推演**：

一个完整的 DMA 传输过程可分为三个阶段：

1. **CPU 预处理阶段**  
   CPU 执行 I/O 指令，向 DMA 控制器写入主存起始地址、传输字节数、设备地址、传送方向等信息，并启动外设。这个阶段必须由 CPU 控制。

2. **数据传送阶段**  
   DMA 控制器取得总线控制权，控制外设与主存之间直接传送数据。CPU 不执行传送数据的程序，也不介入逐字/逐字节的传输控制。若采用周期挪用方式，DMA 控制器会临时占用一个或几个存储周期，CPU 暂时等待，但这仍然是 DMA 控制器在控制传送，而不是 CPU 控制。

3. **后处理阶段**  
   数据传送完成后，DMA 控制器向 CPU 发出中断请求，CPU 响应中断后进行校验、修改状态、决定是否继续传送等收尾工作。

因此：

- A 正确：完整过程由 CPU 和 DMA 控制器分工配合完成。
- B 错误：数据传送阶段不由 CPU 控制。
- C 错误：忽略了 CPU 在预处理和后处理阶段的控制作用，不能说是“CPU 不介入任何控制”。
- D 错误：周期挪用只是 DMA 获得总线使用权的一种方式，不是 CPU 控制整个 DMA 过程。

**易错点**：

- 把“DMA 数据传送阶段 CPU 不干预”误认为“CPU 全程不参与”，从而误选 C。
- 把“周期挪用”理解成 CPU 在控制传输。周期挪用的实质是 DMA 控制器与 CPU 竞争访存周期，并非 CPU 控制 DMA。
- 只记住 DMA 的硬件传送特点，忽略 DMA 传输前需要 CPU 初始化、传输后需要 CPU 中断处理，导致对整个流程判断错误。

**命题规律**：本题属于 I/O 方式中的高频考点，核心是 DMA 控制器与 CPU 的分工。常见变式有：判断“DMA 传送前必须由 CPU 初始化”是否正确；区别中断方式与 DMA 方式的控制方；考查 DMA 控制器中保存的寄存器；考查 DMA 与 CPU 竞争总线的方式，如停止 CPU 访存、周期挪用、交替访存。复习时应将程序查询、中断、DMA 三种 I/O 方式做成对比表，重点记忆各阶段由谁控制，并注意“完整 DMA 过程”不等于“DMA 数据传送阶段”。

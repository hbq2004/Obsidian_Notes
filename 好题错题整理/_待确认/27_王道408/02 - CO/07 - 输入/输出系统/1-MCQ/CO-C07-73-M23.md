# 选择题 第 23 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M23_题目.png|题目]]

23. 以下关于 $DMA$ 方式进行 $I/O$ 的描述中，正确的是（ ）

(A) 一个完整的 $DMA$ 过程，部分由 $DMA$ 控制器控制，部分由 $CPU$ 控制  
(B) 一个完整的 $DMA$ 过程，完全由 $CPU$ 控制  
(C) 一个完整的 $DMA$ 过程，完全由 $DMA$ 控制器控制，$CPU$ 不介入任何控制  
(D) 一个完整的 $DMA$ 过程，完全由 $CPU$ 采用周期挪用法控制

## 答案

## DeepSeek V4 Flash Max 解析

**答案**：A。完整的 DMA 过程分为“CPU 初始化—DMA 控制器传送数据—CPU 中断后处理”三个阶段，因此控制权由 DMA 控制器和 CPU 分工协作完成，而不是由某一方完全控制。

**解题切入点**：先抓住题干关键词“完整 DMA 过程”。不要只想到“DMA 传送数据时不经过 CPU”，而要想到 DMA 的完整流程。可以类比“项目经理 + 外包团队”：CPU 负责启动和验收，DMA 控制器负责中间执行，完整项目中双方都要参与控制。

**推演**：

一个完整的 DMA 传送过程通常分为三步：

1. **预处理阶段，由 CPU 控制**  
   CPU 向 DMA 控制器写入以下信息：
   - 外设/设备地址；
   - 内存起始地址；
   - 传送方向（内存 $\rightarrow$ 外设，或外设 $\rightarrow$ 内存）；
   - 传送的字节数或字数；
   - 启动 DMA 传送。

2. **数据传送阶段，由 DMA 控制器控制**  
   外设发出 DMA 请求，DMA 控制器获得总线使用权后，直接控制外设与内存之间的数据传送。  
   每传送一个数据单位，DMA 控制器内部的地址寄存器自动加 1，字计数器自动减 1，直到整块数据传送完毕。  
   这一阶段不需要 CPU 逐字/逐字节搬运数据。

3. **后处理阶段，由 CPU 控制**  
   DMA 传送结束后，DMA 控制器向 CPU 发出中断请求。  
   CPU 响应中断并执行中断服务程序，完成数据校验、判断是否继续传送等善后工作。

因此：

- B 错：DMA 数据传送阶段不是由 CPU 控制的。
- C 错：CPU 在预处理和后处理阶段必须介入，不能说“CPU 不介入任何控制”。
- D 错：周期挪用只是 DMA 控制器获得总线使用权的一种方式，不是“CPU 完全控制 DMA 过程”的体现。

所以，完整 DMA 过程部分由 DMA 控制器控制，部分由 CPU 控制，选 A。

**易错点**：

- **易错选 C**：只记住“DMA 传送数据不经过 CPU”，忽略了 DMA 开始前需要 CPU 初始化，结束后需要 CPU 做中断后处理。  
  若题干改为“DMA 数据传送阶段”，则可以说 DMA 控制器承担主要控制；但本题问“完整 DMA 过程”，不能选 C。

- **易错选 D**：把“周期挪用”误认为 CPU 的控制方式。  
  周期挪用是 DMA 控制器在 CPU 不使用总线时插入 DMA 传送，本质仍是 DMA 控制器控制传输，不是 CPU 控制整个 DMA 过程。

- **易错选 B**：把 DMA 与程序查询方式混淆。  
  程序查询/中断方式中 CPU 需要频繁介入 I/O 操作，而 DMA 方式能成块传送，CPU 只在头尾介入。

- **规避方法**：看到“完整 DMA 过程”，立刻列出“预处理—数据传送—后处理”三阶段，再分别判断每个阶段由谁控制。

**命题规律**：

该题考查 I/O 方式中的 DMA 工作过程，是 408 计算机组成原理中“I/O 方式”的高频考点。常见变式有：

- 比较 DMA 与中断方式的区别：DMA 数据传送由硬件完成，中断需要 CPU 执行中断服务程序；但 DMA 传送结束后也会用中断通知 CPU。
- 考查 DMA 控制器的组成：地址寄存器、字计数器、控制/状态寄存器、数据缓冲寄存器等。
- 考查 DMA 的传送方式：停止 CPU 访存、周期挪用、交替访存等。

复习建议：把 DMA 流程画成“三阶段图”记忆，并和程序查询方式、中断方式对比。判断“谁控制”时，一定要区分“初始化/后处理”和“数据传送”这两个不同阶段。

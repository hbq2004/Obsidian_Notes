# 选择题 第 32 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M32_题目.png|题目]]

32. 在磁盘存储器进行读/写操作之前，$CPU$ 需要对磁盘控制器或 $DMA$ 控制器进行初始化。在下列选项中，不包含在初始化信息中的是 ( )
(A) 传送信息所在的主存起始地址
(B) 传送方向 (是读磁盘还是写磁盘)
(C) 传送信息所在的通用寄存器编号
(D) 传送数据的字数或字节数

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M32_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。磁盘/DMA控制器初始化需要主存起始地址、传送方向和传送长度，不需要“通用寄存器编号”，因为 DMA 传送不经过 CPU 通用寄存器。

**解题切入点**：把 DMA 控制器看成“外设与主存之间的搬运工”。CPU 在开工前只需告诉它“从哪里搬、搬到哪、搬多少、方向如何”，也就是主存地址、传送长度和传送方向。通用寄存器是 CPU 内部的东西，DMA 传送根本不经过它，所以看到“通用寄存器编号”应立刻判断它不是初始化的必要信息。

**推演**：

在磁盘进行读/写操作之前，CPU 需要向磁盘控制器或 DMA 控制器写入初始化信息。以 DMA 方式为例，DMA 控制器要独立完成外设与主存之间的数据传送，因此必须知道：

- 主存起始地址：即本次传送的数据在主存中的起始位置。对应选项 A。
- 传送方向：是“读磁盘”还是“写磁盘”，也就是数据从磁盘到主存，还是从主存到磁盘。对应选项 B。
- 传送数据的字数或字节数：DMA 控制器需要据此进行计数，判断传送是否结束。对应选项 D。

DMA 传送的数据通路是：

$$外设 \leftrightarrow DMA控制器 \leftrightarrow 主存$$

数据不经过 CPU 的通用寄存器，因此 CPU 无需把通用寄存器编号告诉磁盘控制器或 DMA 控制器。选项 C 不属于初始化信息。

**易错点**：

1. 把 DMA 方式与程序查询方式混淆。程序查询或程序中断方式中，CPU 执行指令时可能使用通用寄存器，但 DMA 方式由硬件直接完成数据传送，不经过通用寄存器。  
2. 误以为“主存起始地址”必须通过某个通用寄存器间接提供。DMA 控制器有自己的地址寄存器，CPU 初始化时直接把主存首地址写入该寄存器即可，不需要通用寄存器编号。  
3. 如果题目选项中给出“磁盘地址（柱面号、磁头号、扇区号）”，也应属于磁盘控制器初始化信息；但本题中“通用寄存器编号”明显与磁盘/DMA 控制器无关。

**命题规律**：本题考点是 I/O 方式中的 DMA 方式，重点考查 DMA 控制器初始化信息。常见变式包括：考查 DMA 控制器内部寄存器的功能，如主存地址寄存器、字计数器、控制寄存器；或与程序中断方式对比，问“每次数据传送是否需要 CPU 干预”。复习时应把程序查询、程序中断、DMA 三种方式的初始化内容、数据传送路径、CPU 参与程度对比记忆，DMA 初始化信息可概括为：设备地址、主存首地址、传送方向、传送长度。

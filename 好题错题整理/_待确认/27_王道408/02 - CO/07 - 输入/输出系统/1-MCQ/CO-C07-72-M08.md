# 选择题 第 8 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-72-M08_题目.png|题目]]

8. 在内存地址空间与接口地址空间统一编址的计算机中，不需要的指令是（  ）

A. 数据传送类（如 $MOV$ 指令）
B. 算术、逻辑运算类（如 $ADD$、$SUB$、$AND$ 和 $OR$ 指令）
C. 输入/输出类（如 $IN$ 和 $OUT$ 指令）
D. 程序控制类（如条件转移指令和子程序调用指令）

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-72-M08_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。在统一编址（存储器映射I/O）方式下，I/O 端口与内存共用同一地址空间，访问 I/O 设备直接使用数据传送类指令（如 $MOV$）即可，无需专门的输入/输出指令。

**解题切入点**：首先抓住“内存地址空间与接口地址空间统一编址”这一关键，定位到 I/O 编址方式中的存储器映射方式。对比独立编址，统一编址的特点是将 I/O 端口当作内存单元，因此对 I/O 的访问与对内存的访问使用相同的指令，不需要专用的 IN/OUT 指令。此题要求选出“不需要”的指令，即选出在统一编址下可以省略的指令类型。

**推演**：
- 统一编址（存储器映射 I/O）：系统将 I/O 接口中的寄存器（端口）映射到内存地址空间的一部分，I/O 端口与内存单元共用同一个地址编码。CPU 访问 I/O 端口时，使用与访问内存相同的指令，如数据传送指令（$MOV$）、算术逻辑指令（$ADD$、$SUB$ 等）以及程序控制指令（条件转移、子程序调用等）。
- 数据传送类指令（如 $MOV$）用于读写内存或 I/O 端口，在统一编址中可直接用于 I/O 操作，因此必不可少。
- 算术逻辑运算类指令（如 $ADD$、$SUB$、$AND$、$OR$）用于数据处理，与 I/O 编址方式无关，任何计算机都需要。
- 程序控制类指令（如条件转移、子程序调用）用于控制程序执行流程，同样不可或缺。
- 输入/输出类指令（如 $IN$、$OUT$）是专门为独立编址（I/O 端口单独编址）设计的，用于访问 I/O 端口。在统一编址中，I/O 端口已被映射到内存空间，访问它们只需使用 $MOV$ 等内存访问指令，因此 $IN$、$OUT$ 指令不再需要。

综上，在统一编址的计算机中，输入/输出类指令是多余的，故选项 C 正确。

**易错点**：
1. 混淆独立编址与统一编址：可能误以为统一编址也需要专门的 I/O 指令，实际上统一编址取消了专用 I/O 指令，用内存访问指令代替。
2. 认为数据传送指令（$MOV$）只在统一编址中用于 I/O，而在独立编址中不能用于 I/O，从而误选 A。但注意题目问的是“不需要的指令”，独立编址需要 $IN$、$OUT$，而统一编址不需要，所以应选 C。
3. 忽略程序控制类指令的必要性：无论哪种编址方式，条件转移和子程序调用都是控制程序流程所必需的，不能省略。

**命题规律**：本题属于 I/O 编址方式的基础概念题，常见于考研 408 选择题中。考点为区分统一编址与独立编址的特点，尤其是指令集的支持差异。变式可能包括：给出统一编址系统的特点（如 I/O 地址范围、访问速度、指令使用等），或要求判断某个说法是否正确。复习时需重点掌握两种编址方式的定义、优缺点及典型指令差异，结合具体 CPU 架构（如 x86 的独立编址与 ARM 的统一编址）加深理解。

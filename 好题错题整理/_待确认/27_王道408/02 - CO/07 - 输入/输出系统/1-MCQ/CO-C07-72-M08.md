# 选择题 第 8 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-72-M08_题目.png|题目]]

8.在内存地址空间与接口地址空间统一编址的计算机中,不需要的指令是 ( )
(A) 数据传送类 (如 $MOV$ 指令)
(B) 算术、逻辑运算类 (如 $ADD$、$SUB$、$AND$ 和 $OR$ 指令)
(C) 输入/输出类 (如 $IN$ 和 $OUT$ 指令)
(D) 程序控制类 (如条件转移指令和子程序调用指令)

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-72-M08_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。  
理由：在内存地址空间与接口地址空间统一编址（即内存映射 I/O）方式下，I/O 接口的寄存器被当作内存单元来访问，因此不需要专门的输入/输出类指令（如 `IN`、`OUT`），只需使用数据传送类指令即可完成 I/O 操作。

**解题切入点**：  
先抓住题干关键词“统一编址”。这属于计算机组成原理中 I/O 编址方式的核心考点。可以类比做题经验：遇到 I/O 编址问题，先分清“内存映射编址”和“独立编址”两种模式。前者把外设寄存器“伪装”成内存地址，于是 CPU 不需要知道对方是内存还是外设；后者则需要专用指令区分。这就像在操作系统里，普通文件与设备文件统一用文件描述符访问，自然不需要专门的“设备打开指令”一样。

**推演**：  

设内存地址空间为 $\{0,1,\dots,2^n-1\}$，接口地址空间也嵌入到其中。统一编址意味着接口中可读写的寄存器被映射到若干内存地址上，例如：

$$
\text{设备状态寄存器} \leftrightarrow \text{地址 } A_1
$$

$$
\text{设备数据寄存器} \leftrightarrow \text{地址 } A_2
$$

此时，CPU 若要向设备发送数据，只需执行：

$$
\text{MOV } (A_2), \text{数据}
$$

也就是普通的数据传送指令。若要读取设备状态，则执行：

$$
\text{MOV } \text{寄存器}, (A_1)
$$

同样属于数据传送类指令。

由于没有独立的 I/O 地址空间，CPU 不需要通过 `IN`/`OUT` 指令来指明访问的是“接口”还是“内存”。因此，专门的输入/输出类指令是不必要的。

其他选项分析：

- A：数据传送类指令仍然需要，因为它承担了所有读写操作，包括访问映射后的接口地址。
- B：算术、逻辑运算类指令仍然需要，因为 CPU 负责对读入的数据进行处理，例如对状态字进行 `AND` 判断。
- D：程序控制类指令仍然需要，因为程序需要分支、循环、子程序调用等控制流能力，与 I/O 编址方式无关。

综上，只有 C 选项“输入/输出类指令”是不需要的。

**易错点**：  

- 易错选 A：有的考生认为“统一编址后只需要 MOV 指令，所以不需要数据传送类”，这正好理解反了。统一编址恰恰是把 I/O 操作转化为普通数据传送操作，因此数据传送类指令是必需的。  
- 易错选 B：认为 I/O 操作不需要运算。实际上算术逻辑指令是 CPU 执行任何计算任务的基础，删去它们计算机将无法完成基本数据处理。  
- 混淆“统一编址”与“独立编址”：独立编址（端口映射 I/O）才需要专门的 `IN`、`OUT` 指令，而统一编址不需要。  
- 注意题干问的是“不需要的指令”，而不是“最常用的指令”或“不可缺少的指令”，要严格按题意选择。

**命题规律**：  

本考点属于“输入/输出系统”的基础概念。常见命题方式有：

1. 直接给出编址方式，判断需要或不需要哪类指令（本题即此类）。  
2. 给出 `IN`、`OUT` 指令，反推地址空间编址方式是独立编址。  
3. 结合存储器访问时序或 CPU 引脚，考查统一编址时读/写控制信号的变化。  
4. 在综合题中，通过一段程序判断是访问内存还是访问接口。

复习建议：将“统一编址”与“独立编址”的优缺点对比记忆。统一编址简单、不需要专用指令、可对 I/O 进行灵活操作，但占用内存地址空间；独立编址需要专用指令，但地址空间独立，不占用内存地址。做题时先看是否有 `IN`/`OUT` 指令，有则基本可断定是独立编址，没有则可能是统一编址。这类题属于送分题，关键在于概念清晰、不混淆。

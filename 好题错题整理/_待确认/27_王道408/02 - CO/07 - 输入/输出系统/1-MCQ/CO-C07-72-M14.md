# 选择题 第 14 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-72-M14_题目.png|题目]]

14.【2012统考真题】下列选项中，在$I/O$总线的数据线上传输的信息包括(  )

$I.I/O$接口中的命令字 $II.I/O$接口中的状态字 $III.$中断类型号

A. 仅$I$、$II$
B. 仅$I$、$III$
C. 仅$II$、$III$
D. $I$、$II$、$III$

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-72-M14_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。I/O 总线的数据线是双向传输“信息内容”的通道，命令字、状态字、中断类型号都在数据线上传送。

**解题切入点**：拿到题目先按总线功能分组，区分数据线、地址线、控制线各自传什么。题目问的是“在数据线上传输的信息”，因此只需判断每项是“编码内容”还是“地址/控制时序”。可以理解为：地址线写“送到哪个门牌号”，控制线发“取件还是发件”的命令，数据线传送“包裹内容”。

**推演**：

I/O 总线按功能可分为三组：

- 数据线：双向，用于传送数据信息和编码信息。包括外设数据、CPU 写入接口的命令字、接口返回给 CPU 的状态字、中断响应时接口送出的中断类型号。
- 地址线：单向，用于传送要访问的存储单元地址或 I/O 端口地址，起“选择”作用。
- 控制线：用于传送读/写控制信号、中断请求/响应信号、总线请求/允许信号等。

逐项判断：

1. **命令字**：CPU 执行输出指令时，把命令字送往 I/O 接口中的命令寄存器，命令字本身是二进制编码信息，必须通过数据线传输。
2. **状态字**：CPU 执行输入指令读取接口状态时，I/O 接口把状态寄存器中的内容经数据线送回 CPU。
3. **中断类型号**：中断响应周期中，I/O 接口或中断控制器把中断类型号放到数据线上，CPU 读取后用于计算中断向量地址并转去执行中断服务程序。中断类型号不是地址线要传的端口地址。

因此 $I$、$II$、$III$ 三项都应在 I/O 总线的数据线上传输，选 D。

**易错点**：

- 容易把“命令字/状态字”误以为属于“控制信息”，从而认为应走控制线。实际上，控制线传送的是读/写信号、中断请求/响应等硬件控制信号；命令字、状态字是具体内容，必须走数据线。
- 容易把“中断类型号”放到地址线上。中断类型号是由 I/O 接口送给 CPU 的编号，CPU 再用它查表得到中断服务程序入口地址；不是地址线直接传送的端口地址。
- 容易忽略数据线的双向性。数据线既可以由 CPU 向接口传命令字，也可以由接口向 CPU 传状态字和中断类型号。

**命题规律**：本题属于总线分类与 I/O 方式结合的考点。常见变式有：判断某一信号（如端口地址、中断类型号、DMA 请求、读写命令）在哪种总线上传输，或结合中断响应流程、DMA 流程一起考查。复习时要抓住“数据线传内容、地址线选位置、控制线发命令/握手”的原则，并理解中断响应和 I/O 指令的执行流程。

# 综合题 第 3 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-F03_题目.png|题目]]

3.在程序查询方式的输入/输出系统中，假设不考虑处理时间，每个查询操作需要 100 个时钟周期，$CPU$ 的时钟频率为 $50\mathrm{MHz}$。现有鼠标和硬盘两个设备，而且 $CPU$ 必须每秒对鼠标进行 30 次查询，硬盘以 32 位字长为单位传输数据，即每 32 位被 $CPU$ 查询一次，传输速率为 $2 \times 2^{20}B/s$。求 $CPU$ 对这两个设备查询所花费的时间比率，由此可得出什么结论？

## 答案

## DeepSeek V4 Flash Max 解析

**答案**：鼠标查询所需 CPU 时间比率为 $6\times10^{-5}$，即 $0.006\%$；硬盘查询所需比率为 $1.048576$，即 $104.8576\%$（两台设备合计约 $104.8636\%$）。结论：仅硬盘一项的查询开销就超过了 CPU 的可用时间，程序查询方式不能用于硬盘这类高速设备，只适合鼠标等低速设备。

**解题切入点**：本题核心是“CPU 时间预算”问题。程序查询方式中，每次查询都要消耗固定时钟周期数，所以先算“设备每秒需要的查询次数”，再乘以“每次查询周期数”，最后与 CPU 每秒总周期数 $50\times10^6$ 比较。这就像算法竞赛中判断某个操作是否超时：每秒调用次数 × 每次调用开销，若超过 CPU 每秒运算预算则不可行。

**推演**：

CPU 时钟频率为 $50\mathrm{MHz}=50\times10^6\mathrm{Hz}$，即每秒有 $50\times10^6$ 个时钟周期。

每次查询需要 $100$ 个时钟周期，所以每次查询所需时间为：

$$
t_q=\frac{100}{50\times10^6}\mathrm{s}=2\times10^{-6}\mathrm{s}=2\mu\mathrm{s}
$$

### 鼠标

鼠标每秒查询 $30$ 次，因此查询占用 CPU 的比率：

$$
r_m=\frac{30\times100}{50\times10^6}=6\times10^{-5}=0.006\%
$$

也可以从时间角度看：每秒查询 $30$ 次，每次 $2\mu\mathrm{s}$，共 $60\mu\mathrm{s}$，占 $1\mathrm{s}$ 的比例仍为 $0.006\%$。

### 硬盘

硬盘传输速率为：

$$
2\times2^{20}\mathrm{B/s}=2^{21}\mathrm{B/s}
$$

$32$ 位字长 $=4\mathrm{B}$，所以每秒需要查询的次数为：

$$
n_d=\frac{2^{21}}{4}=2^{19}=524288\ \text{次/s}
$$

则硬盘查询占用 CPU 的比率：

$$
r_d=\frac{n_d\times100}{50\times10^6}
=\frac{2^{19}\times100}{50\times10^6}
=\frac{2^{20}}{10^6}
=1.048576
$$

即：

$$
r_d=104.8576\%
$$

这说明，硬盘若要保持 $2\times2^{20}\mathrm{B/s}$ 的传输速率，CPU 每秒用于查询硬盘的时间已经超过 CPU 的总时间，因此程序查询方式不能满足要求。

若把鼠标和硬盘合计，则：

$$
r_{\text{total}}
=\frac{(30+2^{19})\times100}{50\times10^6}
=\frac{52431800}{50000000}
=1.048636
=104.8636\%
$$

因此，硬盘单独一项已经使 CPU 超负荷，再加上鼠标只会更严重。

结论：程序查询方式中，CPU 需要为每个 $32$ 位字查询一次，对于硬盘这类高速设备，查询开销过大，CPU 无法承受；程序查询方式只适用于鼠标、键盘等低速设备，高速块设备应采用 DMA 等方式。

**易错点**：

1. **单位不统一**：硬盘传输率单位是 $\mathrm{B/s}$，而字长是 $32$ 位 $=4\mathrm{B}$，所以每秒查询次数应除以 $4$，不要误写成除以 $32$ 或乘以 $4$。
2. **漏乘每次查询的 $100$ 个时钟周期**：CPU 开销是“查询次数 × 每次查询周期数”，不能只算查询次数。
3. **百分比与小数混淆**：$6\times10^{-5}$ 写成百分数是 $0.006\%$，不是 $0.06\%$，也不是 $0.006$。
4. **忽略结果大于 $1$ 的含义**：硬盘查询比率 $104.8576\%>100\%$，说明 CPU 时间不够用，而不是“刚好满负荷”，要据此得出“程序查询方式不可行”的结论。

**命题规律**：考点是 I/O 方式中程序查询方式的 CPU 开销计算。常见变式有：给定 CPU 频率和每次查询周期数，求设备最高可支持传输速率；比较程序查询、中断、DMA 三种方式的 CPU 占用率；判断某设备能否使用程序查询方式。复习时应掌握核心公式：

$$
\text{CPU 占用率}=\frac{\text{每秒查询次数}\times\text{每次查询时钟周期数}}{\text{CPU 时钟频率}}
$$

并记住：程序查询方式结构简单但 CPU 开销大，只适合低速设备；高速块设备应采用 DMA 方式。

# 综合题 第 3 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-F03_题目.png|题目]]

3.在程序查询方式的输入/输出系统中，假设不考虑处理时间，每个查询操作需要100个时钟周期，$CPU$的时钟频率为$50\text{MHz}$。现有鼠标和硬盘两个设备，而且$CPU$必须每秒对鼠标进行30次查询，硬盘以32位字长为单位传输数据，即每32位被$CPU$查询一次，传输速率为$2 \times 2^{20}\text{B/s}$。求$CPU$对这两个设备查询所花费的时间比率，由此可得出什么结论?

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-F03_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：鼠标查询时间比率为 $0.006\%$，硬盘查询时间比率为 $104.86\%$。结论：程序查询方式下，CPU 用于鼠标查询的时间极少，可以接受；但用于硬盘查询的时间超过 $100\%$，说明 CPU 无法满足硬盘的查询要求，因此高速设备不宜采用程序查询方式，应采用 DMA 等方式。

**解题切入点**：首先计算每个查询操作所需的 CPU 时间，再根据设备要求的查询频率（鼠标直接给出次数，硬盘需根据传输速率和字长换算），求出每秒用于查询的总时间，最后计算该时间占 $1$ 秒的百分比，从而得出 CPU 占用率。

**推演**：  
- CPU 时钟频率 $f = 50\text{ MHz} = 50 \times 10^6\text{ Hz}$，时钟周期 $T = \frac{1}{f} = \frac{1}{50 \times 10^6} = 20\text{ ns}$。  
- 每个查询操作需 $100$ 个时钟周期，故单次查询时间 $t_q = 100 \times 20\text{ ns} = 2000\text{ ns} = 2\ \mu\text{s}$。  

**鼠标**：每秒查询 $30$ 次，$$t_{\text{mouse}} = 30 \times 2\ \mu\text{s} = 60\ \mu\text{s}$$  
CPU 时间比率 $$R_{\text{mouse}} = \frac{60\ \mu\text{s}}{1\text{ s}} = 0.00006 = 0.006\%$$  

**硬盘**：传输速率 $2 \times 2^{20}\text{ B/s} = 2^{21}\text{ B/s}$，字长 $32$ 位 $= 4\text{ B}$，每 $4$ 字节查询一次，故每秒查询次数 $$N = \frac{2^{21}\text{ B/s}}{4\text{ B}} = 2^{19} = 524288\text{ 次/秒}$$  
每秒查询时间 $$t_{\text{disk}} = 524288 \times 2\ \mu\text{s} = 1048576\ \mu\text{s} = 1.048576\text{ s}$$  
CPU 时间比率 $$R_{\text{disk}} = \frac{1.048576\text{ s}}{1\text{ s}} = 104.8576\%$$  

**结论**：程序查询方式下，CPU 对鼠标的查询仅占用 $0.006\%$ 的时间，几乎不影响 CPU 性能；但对硬盘的查询所需时间超过 $1$ 秒，说明 CPU 无法在 $1$ 秒内完成所有查询，会导致数据丢失或错误。因此，程序查询方式仅适用于低速设备，高速设备应采用中断或 DMA 等更高效的 I/O 方式。

**易错点**：  
1. 混淆单位：传输速率 $2 \times 2^{20}\text{ B/s}$ 是字节每秒，而非比特每秒，误用为比特会导致查询次数计算错误。  
2. 忽略字长换算：硬盘以 $32$ 位（$4$ 字节）为单位查询，需用传输速率除以 $4$ 得到每秒查询次数。  
3. 时钟周期计算错误：$50\text{ MHz}$ 对应 $20\text{ ns}$，而非 $0.02\ \mu\text{s}$ 等。  
4. 时间单位换算：$2000\text{ ns}$ 应正确转换为 $2\ \mu\text{s}$，避免在累乘时出错。

**命题规律**：  
- 考点：程序查询方式下 CPU 时间开销的计算，常与中断、DMA 方式对比。  
- 常见变式：改变设备参数（如查询次数、传输速率、字长）或时钟频率，要求计算 CPU 占用率；或给定最大允许占用率，反推可支持的最大传输速率。  
- 复习建议：牢固掌握基本公式（时钟周期、查询时间、每秒查询次数），理解不同 I/O 方式的特点，并通过对比记忆适用场景。

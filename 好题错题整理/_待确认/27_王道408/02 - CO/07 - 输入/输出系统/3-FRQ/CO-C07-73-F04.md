# 综合题 第 4 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-F04_题目.png|题目]]

4. 设某计算机有 4 个中断源 1、2、3、4，其硬件排队优先次序按 $1\to 2\to 3\to 4$ 降序排列，各中断源的服务程序中所对应的屏蔽字如下表所示.

| 中断源 | 1 | 2 | 3 | 4 |
| ---- | ---- | ---- | ---- | ---- |
| 1 | 1 | 1 | 0 | 1 |
| 2 | 0 | 1 | 0 | 0 |
| 3 | 1 | 1 | 1 | 1 |
| 4 | 0 | 1 | 0 | 1 |

(1) 给出上述4个中断源的中断处理次序.
(2) 若4个中断源同时有中断请求，画出 $CPU$ 执行程序的轨迹.

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-F04_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：  
(1) 由屏蔽字决定的中断处理次序（优先级由高到低）为 $3\to1\to4\to2$。  
(2) CPU 执行程序的轨迹为：  
`主程序 → 1号中断服务程序(前段) → 3号中断服务程序(完整) → 1号中断服务程序(后段) → 主程序 → 2号中断服务程序(前段) → 4号中断服务程序(完整) → 2号中断服务程序(后段) → 主程序`。  
理由：屏蔽字中 $1$ 表示屏蔽该中断源，$0$ 表示开放该中断源，因此可嵌套关系与硬件排队次序不同。

**解题切入点**：  
拿到题先区分两个概念：

- 硬件排队决定的是“中断响应次序”，题目给出为 $1\to2\to3\to4$。
- 屏蔽字决定的是“中断处理次序”，即谁可以打断谁。

可以把每个屏蔽字看成一张“门禁表”：当前运行第 $i$ 个中断服务程序时，对应位为 $0$ 的中断源可以打断它，对应位为 $1$ 的中断源被屏蔽。整理出可打断关系后，再按同时请求的情况模拟 CPU 轨迹。

**推演**：  
约定第 $i$ 行的屏蔽字为
$$
w_i=(b_{i1},b_{i2},b_{i3},b_{i4}),
$$
$b_{ij}=1$ 表示执行第 $i$ 个中断服务程序时屏蔽第 $j$ 个中断源，$b_{ij}=0$ 表示开放第 $j$ 个中断源。

逐行分析：

| 当前服务程序 | 屏蔽字 | 可打断当前程序的源 |
|---|---|---|
| 1号 | $1101$ | 只有3号 |
| 2号 | $0100$ | 1、3、4号 |
| 3号 | $1111$ | 无 |
| 4号 | $0101$ | 1、3号 |

因此：

- 3号可打断1、2、4号，且3号执行时屏蔽所有中断，所以3号处理优先级最高。
- 1号可打断2、4号，但不能打断3号，所以1号次之。
- 4号可打断2号，但1、3号可打断4号，所以4号再次。
- 2号可被1、3、4号打断，不能打断其他源，所以2号处理优先级最低。

故中断处理次序为：
$$
3\to1\to4\to2
$$

若4个中断源同时请求，CPU 轨迹如下：

```text
主程序
  → 1号中断服务程序开始
      → 3号中断服务程序完整执行
      ← 3号中断服务程序返回
  ← 1号中断服务程序继续执行并结束
  → 2号中断服务程序开始
      → 4号中断服务程序完整执行
      ← 4号中断服务程序返回
  ← 2号中断服务程序继续执行并结束
回到主程序
```

轨迹也可简写为：
```text
主程序 → 1号(前段) → 3号(完整) → 1号(后段) → 主程序
       → 2号(前段) → 4号(完整) → 2号(后段) → 主程序
```

**易错点**：  
1. 把屏蔽字含义弄反。本题中 $1$ 表示屏蔽，$0$ 表示开放；不能把 $1$ 理解为“允许中断”。  
2. 直接按硬件排队次序写处理次序为 $1\to2\to3\to4$。硬件排队只决定响应次序，处理次序由屏蔽字决定。  
3. 画轨迹时只写“1→3→4→2”这类优先级序列，而忽略中断服务程序被分成“前段”和“后段”。例如1号服务程序被3号打断，2号服务程序被4号打断。  
4. 认为4号在1号之后立即执行。实际上1号服务程序的屏蔽字第4位为 $1$，所以4号在1号执行期间被屏蔽；4号是在2号服务程序执行期间打断2号的。

**命题规律**：  
本题是中断系统的高频考点：给屏蔽字表，求中断处理次序并画 CPU 执行轨迹。常见的变式还有：

- 给出中断处理次序，要求填写屏蔽字；
- 给出轨迹，反推各中断源的屏蔽字；
- 结合“中断响应优先级”和“中断处理优先级”进行辨析。

复习时应重点掌握：响应次序由硬件排队器决定，处理次序由屏蔽字决定；屏蔽字中 $1$ 屏蔽、$0$ 开放；同时请求时，先用硬件响应次序选第一个进入的服务程序，再根据屏蔽字判断后续嵌套打断关系。

# 选择题 第 23 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-56-M23_题目.png|题目]]

23.【2014统考真题】采用指令 $Cache$ 与数据 $Cache$ 分离的主要目的是（ ）

(A) 降低 $Cache$ 的缺失损失  
(B) 提高 $Cache$ 的命中率  
(C) 降低 $CPU$ 平均访存时间  
(D) 减少指令流水线资源冲突

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-56-M23_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。指令 Cache 与数据 Cache 分离后，取指访问指令 Cache 与访存访问数据 Cache 可在同一时钟周期并行进行，主要目的是减少指令流水线中取指与访存之间的资源冲突（结构冒险）。

**解题切入点**：  
看到“分离”二字，应立刻联想到“并行访问”和“流水线资源冲突”。指令 Cache 与数据 Cache 分离是典型的类哈佛结构做法：一个管取指令，一个管取数据/写数据，两者互不争用同一个 Cache 端口。就像比赛中要同时读两个变量，如果只开一个数组就会争锁；拆成两个数组就能并行读写，减少等待。

**推演**：  
经典五段流水线为：取指 IF、译码 ID、执行 EX、访存 MEM、写回 WB。理想情况下每个周期发射一条指令，但取指和访存可能在同一周期发生冲突。

例如：

| 时钟周期 | $t_1$ | $t_2$ | $t_3$ | $t_4$ |
|---|---|---|---|---|
| $I_1$ | IF | ID | EX | MEM |
| $I_2$ |  | IF | ID | EX |
| $I_3$ |  |  | IF | ID |
| $I_4$ |  |  |  | IF |

在 $t_4$ 时刻，$I_1$ 在访存（MEM），$I_4$ 在取指（IF）。若采用统一 Cache，只有一个访问端口，不能同时完成取指和数据访存，就会产生资源冲突，流水线需要停顿。

设因资源冲突插入的停顿周期数为 $s$，则实际流水线 $CPI$ 为：

$$
CPI = 1 + s
$$

指令 Cache 与数据 Cache 分离后，$I_1$ 的访存访问数据 Cache，$I_4$ 的取指访问指令 Cache，两个 Cache 可以并行工作，从而减少甚至消除这类停顿。

再看其他选项：

- A 错误：Cache 缺失损失主要取决于下一级存储器的访问时间、替换策略等，并不因指令/数据 Cache 分离而降低。
- B 错误：在总容量一定时，分离会把容量切分为指令 Cache 和数据 Cache，可能降低命中率；即使能避免指令与数据相互干扰，也不是分离的主要目的。
- C 错误：减少资源冲突最终可能改善 CPU 平均访存时间，但这是性能优化的总目标，不是“分离”这一措施的直接、主要目的。

因此答案为 D。

**易错点**：  
1. 误选 C：看到“Cache 性能提升”就想选“降低 CPU 平均访存时间”，但题干问的是“分离”的主要目的，应聚焦于并行访问和流水线资源冲突。  
2. 误选 B：以为 Cache 分开后互不干扰，因此命中率提高。事实上固定总容量下，Cache 分开会使各自的容量变小，容量利用率不如统一 Cache 灵活。  
3. 误选 A：缺失损失与 Cache 的下一级存储层次有关，和指令/数据 Cache 是否分离没有直接关系。  
4. 不会画流水线时空图：取指 IF 与访存 MEM 在同一时刻可能都需要访问 Cache，这是判断资源冲突的关键。

**命题规律**：  
本题将“Cache 结构”与“流水线结构冒险”结合考查。常见的变式有：  
- 给定五段流水线，判断某时刻取指和访存冲突属于什么冒险；  
- 比较统一 Cache 与分离 Cache 的优缺点；  
- 考查“结构冲突/资源冲突”的解决方法。  

复习时要注意把存储层次和流水线冒险联系起来，不仅要记住“分离 Cache 是为了减少资源冲突”，还要能画出流水线时空图解释原因。

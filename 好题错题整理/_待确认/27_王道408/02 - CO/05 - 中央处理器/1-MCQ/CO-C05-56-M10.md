# 选择题 第 10 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-56-M10_题目.png|题目]]

10. 指令流水线中出现数据相关时流水线将受阻，（  ）可部分解决数据相关问题.
(A) 增加硬件资源
(B) 采用旁路技术
(C) 采用分支预测技术
(D) 以上都可以

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-56-M10_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。旁路（转发）技术通过将前一条指令的运算结果直接送到后续指令所需的部件输入端，能部分消除数据相关引起的流水线停顿；分支预测针对控制相关，增加硬件资源通常解决结构相关。

**解题切入点**：拿到题先识别“数据相关”属于数据冒险，然后回忆数据冒险的典型解决方法：旁路/转发（data forwarding）、插入气泡（stall）、编译调度、寄存器重命名等。分支预测用于控制相关，增加硬件资源用于结构相关，所以直接锁定 B。

**推演**：

1. 流水线中的“相关”分为三类：结构相关、数据相关、控制相关。  
   - 结构相关：硬件资源冲突，例如指令和数据共用一个存储器。  
   - 数据相关：指令之间存在数据依赖，后一条指令需要前一条指令的运算结果。  
   - 控制相关：分支指令改变指令流向，造成流水线冲刷。

2. 数据相关的本质是：结果还未写回寄存器，后续指令却已到读寄存器阶段。例如五段流水线 IF、ID、EX、MEM、WB 中，两条相邻指令存在写后读（RAW）相关：
   $$
   \text{ADD } R1,R2,R3 \quad;\quad \text{SUB } R4,R1,R5
   $$
   第二条指令在 ID 段读 $R1$ 时，第一条指令可能尚未到 WB 段写回 $R1$，因此流水线必须停顿。

3. 旁路（转发）技术：在 ALU 的输出端与 ALU 的输入端之间增加额外通路，使前一条指令在 EX 段或 MEM 段得到的结果直接送到后一条指令的 ALU 输入端，不必等待 WB 段写回寄存器。这样，很多 RAW 相关可以不必停顿，流水线得以继续执行。

4. 但旁路技术并不能完全消除所有数据相关。典型例子是 Load-use 相关：
   $$
   \text{LOAD } R1, [R2] \quad;\quad \text{ADD } R3, R1, R4
   $$
   Load 指令的数据要到 MEM 段末尾才有效，而 ADD 指令在 ID 段就需要 $R1$，即使采用旁路，也只能在 MEM/WB 段将结果转发给 ALU 输入端，但仍需在 ID 段停顿一个时钟周期。故题目说“可部分解决数据相关问题”。

5. 其他选项分析：
   - 增加硬件资源（A）：主要用于解决结构相关，例如将指令存储器和数据存储器分开，或增加寄存器堆的读写端口，不能直接消除数据依赖。
   - 分支预测技术（C）：用于解决控制相关，通过预测分支是否跳转来减少流水线停顿，与数据相关无关。
   - 因此 D 不正确。

**易错点**：

- 误选 D：认为三种方法都能解决数据相关，混淆了结构相关、数据相关、控制相关的解决手段。
- 误选 A：把“增加硬件资源”理解为增加更多寄存器或功能部件，但数据相关的本质是指令间的数据依赖，增加资源不能消除依赖关系。
- 误选 C：将分支预测与数据相关混淆，分支预测只针对分支指令造成的控制冒险。
- 忽略“部分解决”：旁路技术能消除大多数 ALU 运算结果的转发，但不能完全消除 Load-use 相关，因此题目强调“部分解决”。

**命题规律**：

- 考点定位：流水线冒险的分类及各自解决技术。本题直接考查数据相关对应的解决技术。
- 常见变式：  
  1. 给出具体指令序列，要求判断存在何种相关，并计算需要插入多少个气泡；  
  2. 问“下列哪项不是解决数据相关的方法”；  
  3. 结合 Load-use 数据冒险，说明为何旁路技术不能完全消除停顿；  
  4. 与分支预测、结构相关的解决技术放在一起让考生辨析。
- 复习建议：务必分清三类冒险的定义和典型解决方案，并掌握五段流水线中旁路转发的工作流程，重点理解 Load-use 相关仍需一个停顿周期的特例。可结合经典习题和思维导图强化记忆。

# 选择题 第 10 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-56-M10_题目.png|题目]]

10. 指令流水线中出现数据相关时流水线将受阻，（ ）可部分解决数据相关问题。
(A) 增加硬件资源
(B) 采用旁路技术
(C) 采用分支预测技术
(D) 以上都可以

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-56-M10_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。理由：数据相关（数据冒险）导致的流水线阻塞可通过数据转发（旁路）技术将运算结果直接送至后续指令所需位置，从而部分消除阻塞；分支预测针对的是控制相关，增加硬件资源不是直接解决数据相关的典型手段。

**解题切入点**：看到“数据相关”立即定位到流水线冒险中的“数据冒险”，而不是控制冒险或结构冒险。数据冒险的本质是后续指令需要的操作数尚未写回寄存器，旁路技术让数据“绕道”提前送到执行部件，因此是直接针对数据相关的经典优化手段。可以把旁路技术理解为“快递提前中转”，不必等包裹先回总站再发出去。

**推演**：

1. 五段流水线中典型的指令序列为：

   $$
   \text{ADD } R1, R2, R3 \qquad \text{SUB } R4, R1, R5
   $$

   ADD 在 ID 阶段读取寄存器，在 EX 阶段计算，在 WB 阶段才将结果写回 $R1$。如果严格的按顺序执行，SUB 在 ID 阶段读 $R1$ 时，ADD 尚未写回 $R1$，于是 SUB 读到的就是旧值，产生数据相关。

2. 数据相关的类型包括：

   - 写后读（RAW）：最常见的真数据相关，上例就是 RAW。
   - 写后写（WAW）：多条指令写同一寄存器，后写覆盖先写。
   - 读后写（WAR）：后写指令在旧值被读之前写入，导致旧值丢失。

   在经典五段流水线中，WAW 和 WAR 较少出现，主要处理 RAW。

3. 不采用旁路技术时，流水线必须插入“气泡”（stall）等待 ADD 完成写回，比如需要停顿 2~3 个周期，损失流水线性能。

4. 旁路技术（forwarding / bypassing）的基本原理：在 EX 阶段计算出结果后，不等到 WB 阶段写回寄存器堆，而是直接将结果通过专用数据通路送往后续指令的 ALU 输入端。这样 SUB 可以在 EX 阶段直接获得 ADD 的运算结果，从而避免停顿。

   设 ADD 在时钟周期 $T_1$ 进入 EX 阶段，$T_2$ 进入 MEM 阶段，$T_3$ 进入 WB 阶段。SUB 在 $T_2$ 进入 ID 阶段，如果 ID 阶段读寄存器得到的是旧值，但 SUB 真正使用 $R1$ 是在其 EX 阶段（$T_3$），此时 ADD 的结果已经产生，旁路电路可以在 SUB 的 EX 阶段把 ADD 的结果直接送到 ALU 输入端，于是无需气泡。

5. 旁路技术只能解决“结果已经产生但尚未写回”的数据相关；如果第一条指令的结果要到 EX 阶段末尾才能产生，而第二条指令在 EX 阶段开始就需要该结果，则仍可能需要一个气泡（load-use 冒险）。因此题干说“部分解决”，对应“可部分解决”。

6. 对比其他选项：

   - A “增加硬件资源”是一个笼统说法。增加寄存器端口、增加多体交叉存储器等可以缓解结构冒险，但对数据相关本身不产生直接消除作用。
   - C “分支预测技术”是为了解决控制相关（分支指令引起的流水线冲刷），与数据相关无关。
   - D “以上都可以”显然不成立。

因此选择 B。

**易错点**：

- 误选 D：把“增加硬件资源”当作能解决所有问题，其实增加硬件资源可以解决结构冒险；分支预测解决控制冒险；只有旁路技术直接用于数据相关。
- 混淆“数据相关”和“控制相关”：看到“流水线受阻”就以为是分支预测，但题干明确说是“数据相关”。
- 忽视“部分解决”：旁路技术不能完全消除所有数据冒险，load-use 冒险仍可能造成一次停顿，因此说“部分解决”是准确的。
- 把“编译优化”与“硬件旁路”混淆：编译时指令调度（如调整指令顺序）可以通过软件减少数据相关，但本题四个选项均为硬件技术，B 才是直接相关。

**命题规律**：

- 考点定位：指令流水线中的冒险类型与解决策略，属于计算机组成原理中流水线章节的重点概念。
- 常见变式：
  1. 给出具体指令序列，要求计算插入气泡个数或分析是否可以使用转发技术。
  2. 问“下列哪种技术可以解决控制相关？”答案通常为分支预测。
  3. 问“旁路技术解决哪类相关？”答案通常为 RAW 数据相关。
  4. 综合题中要求画出采用转发技术后的流水线时空图，并与无转发的情况对比。
- 复习建议：掌握三类冒险（结构、数据、控制）的定义、产生原因和典型对策；重点理解 RAW 的判定（先写后读，但写尚未完成）以及转发技术的动态过程；熟练分析 load-use 数据冒险为什么仍需要一个气泡。

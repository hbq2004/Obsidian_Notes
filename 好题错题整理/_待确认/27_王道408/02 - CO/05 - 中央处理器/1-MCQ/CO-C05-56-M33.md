# 选择题 第 33 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-56-M33_题目.png|题目]]

33.【2025 统考真题】下列关于 $CPU$ 中的数据通路和控制器的叙述中,错误的是(  )
(A) 通用寄存器组中应该包含程序计数器
(B) 控制器中一定包含指令操作码的译码电路
(C) 单周期 $CPU$ 中的控制器比多周期 $CPU$ 中的更简单
(D) 流水线 $CPU$ 需解决数据相关和控制相关等冒险问题

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-56-M33_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A。$PC$（程序计数器）是专用寄存器，不属于通用寄存器组；其余三项关于控制器译码、单周期/多周期控制器复杂度、流水线冒险的叙述均正确。

**解题切入点**：
先定位考点：题目考查 CPU 中数据通路与控制器的基本概念。A 考寄存器分类，B 考控制器基本组成，C 考单周期/多周期控制器的区别，D 考流水线冒险。可用排除法：B、D 明显正确，重点辨析 A 和 C。

可以这样打比方：通用寄存器组类似于算法竞赛中你维护的“变量数组”，可以按编号读写；而 $PC$ 更像是程序当前执行到的“行号/指令指针”，它由 CPU 自动维护，不能当作普通变量随意放进数组。如果把 $PC$ 放入通用寄存器组，普通运算指令就可能意外改写指令执行流。

**推演**：

- **（A）错误。**  
  $PC$（程序计数器）是专用寄存器，保存当前指令地址或下一条指令地址。通用寄存器组，如 $R_0,R_1,\dots,R_n$，用于保存参与运算的操作数、地址等数据。  
  在典型数据通路中，取指阶段需要用到：
  $$
  PC \to MAR,\quad M(MAR) \to MDR,\quad MDR \to IR
  $$
  $PC$ 专门参与取指和指令地址更新，不能与通用寄存器组混为一谈。因此 A 的说法错误。

- **（B）正确。**  
  控制器的核心任务是根据指令操作码产生各类控制信号。硬布线控制器中有操作码译码电路；微程序控制器中也必须把指令操作码映射为对应的微程序入口地址。因此控制器中一定包含指令操作码的译码电路。

- **（C）正确。**  
  单周期 CPU 每条指令在一个时钟周期内完成，控制器只需要根据当前指令产生一组控制信号，属于组合逻辑，不需要记忆当前执行到第几步。  
  多周期 CPU 把一条指令分成多个周期完成，控制器需要记录当前处于哪一步，因此必须包含状态寄存器、状态转换逻辑等，控制器更为复杂。注意这里说的是“控制器”的复杂度，不是整个 CPU 的硬件代价或性能。

- **（D）正确。**  
  流水线 CPU 中，相邻指令可能产生数据冒险（如写后读相关），转移/跳转指令会带来控制冒险，此外还可能存在结构冒险。因此必须通过数据转发、阻塞、分支预测、流水线冲刷等方式解决。

**易错点**：
- 容易把 $PC$ 当成通用寄存器。$PC$、$IR$、$MAR$、$MDR$、$PSW$ 等通常是专用寄存器，不属于通用寄存器组。
- 看到 B 中“一定”就认为表述太绝对而误选。指令译码是控制器最基本的功能，B 正确。
- 对 C 的理解要准确：单周期控制器简单，不代表单周期 CPU 整体更简单；单周期 CPU 的时钟周期往往更长，数据通路硬件冗余也可能更大。

**命题规律**：
考点集中在 CPU 组成、数据通路与控制器、单周期/多周期/流水线 CPU 的特点。常见变式有：判断 $PC/IR/MAR/MDR$ 属于哪类寄存器；比较硬布线控制器和微程序控制器；分析流水线数据冒险、控制冒险的解决办法；比较单周期、多周期、流水线 CPU 的 CPI、时钟周期和性能。复习时应把 CPU 中各类寄存器的功能、控制器组成、流水线冒险与转发机制作为必背基础，并多画数据通路图辅助理解。

# 选择题 第 1 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-57-M01_题目.png|题目]]

1. 当前设计高性能计算机的重要技术途径是 ( )
(A) 提高 $CPU$ 主频
(B) 扩大主存容量
(C) 采用非冯·诺依曼结构
(D) 采用并行处理技术

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-57-M01_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。采用并行处理技术是当前设计高性能计算机的重要技术途径，因为仅靠提高主频已遇到功耗和散热瓶颈，而并行处理能有效提升系统整体性能。

**解题切入点**：题目问的是“当前”设计高性能计算机的“重要技术途径”，关键词是“当前”和“重要”。拿到题先定位到计算机性能提升手段的发展趋势：早期靠提高 CPU 主频，后来转向多核、多处理器、并行处理等体系结构技术。可以类比算法竞赛中“优化单次循环不如并行分块处理”的思路：单点速度受限时，通过并行分摊任务才是突破瓶颈的主流方向。

**推演**：
- 选项 A：提高 CPU 主频。主频提升虽然能缩短单个指令的执行时间，但受限于功耗、散热和电流泄露等问题，现代 CPU 很难通过无限制提高主频来获得性能提升。而且主频提高不一定带来整体系统性能的线性增长，因为还受存储器带宽、总线速度等制约。因此 A 不是当前重要途径。
- 选项 B：扩大主存容量。主存容量增大可以减少缺页或缓存缺失，但容量增加不能直接提高 CPU 的计算速度，也不是设计高性能计算机的核心技术途径，而是配套措施。
- 选项 C：采用非冯·诺依曼结构。非冯·诺依曼结构（如数据流计算机、神经形态计算）是探索方向，但并非当前高性能计算机设计的主流技术途径，当前大多数高性能计算机仍是冯·诺依曼结构及其改进形式。
- 选项 D：采用并行处理技术。并行处理包括指令级并行、线程级并行、数据级并行和任务级并行等，通过多处理器、多核、GPU 加速、分布式计算等方式，突破单处理器速度极限，已成为当前高性能计算（如超算、云计算）的核心手段。因此 D 正确。

**易错点**：
- 容易误选 A：看到“高性能计算机”就选“提高主频”，但忽略了“当前”和“重要途径”的限制，主频提升已经遇到瓶颈。
- 容易误选 C：混淆“未来探索方向”和“当前重要技术途径”，非冯·诺依曼结构尚未成为主流。
- 容易误选 B：主存容量对性能有帮助，但它是“补充”而非“核心途径”，不能直接提升计算速度。
- 规避方法：抓住题干中“当前”二字，联想 CPU 频率墙、多核并行、GPU 等实际技术趋势，区分“辅助手段”和“重要技术途径”。

**命题规律**：此题属于计算机系统概述中“计算机性能评价与提高”的考点，常以选择题形式考查。常见变式包括：问“现代处理器提高性能主要依靠什么”（答案多为多核并行、指令级并行等）、“下列哪种技术不能有效提高系统性能”等。复习时需重点掌握并行技术的分类（指令级并行、线程级并行、数据级并行、任务级并行），理解主频、吞吐率、响应时间等性能指标，并关注现代计算机体系结构的发展趋势（多核、异构计算、并行处理）。建议结合典型超算案例（如神威·太湖之光、天河系列）来加深印象。

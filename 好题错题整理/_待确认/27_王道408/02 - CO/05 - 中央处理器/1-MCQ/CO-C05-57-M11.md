# 选择题 第 11 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-57-M11_题目.png|题目]]

11. 下列关于多核处理器的说法中，不正确的是（ ）

(A) 多核处理器并不能使单线程程序的执行速度加快

(B) 多核处理器在$Flynn$分类法中属于$MIMD$系统

(C) 多核处理器实际上就是在一个$CPU$上集成了多个控制核心

(D) 多核处理器通常比单核处理器的能耗更高

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-57-M11_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。多核处理器是在同一芯片/CPU 上集成多个完整的处理器核心，不是多个“控制核心”；A、B、D 的说法均符合多核处理器的一般特性。

**解题切入点**：  
拿到题先抓关键词：“多核处理器”“单线程程序”“Flynn 分类”“控制核心”“能耗”。多核处理器的“核”必须是能够独立取指、译码、执行的完整处理核心；看到“Flynn 分类”就应想到 SISD/SIMD/MISD/MIMD 四象限；看到“单线程”应立即联想到 Amdahl 定律：单线程程序无法通过增加核心数获得并行加速。

**推演**：  

1. 多核处理器的定义：将多个处理器核心（core）集成在一个物理芯片或 CPU 封装内。每个核心通常包含控制单元、运算器/ALU、寄存器文件和一级 Cache 等，可独立执行指令流。  
   因此 C 说“在一个 CPU 上集成了多个控制核心”是错误的：它把“处理器核心”缩小成了“控制核心”。控制单元只是每个核心的一部分，核心还必须具备完整的取指、译码、运算和数据通路能力。

2. 分析 A：单线程程序只有一个指令流，不能拆到多个核上并行执行。多核的收益主要体现在多道程序或多个线程并行执行上。  
   用 Amdahl 定律看：设可并行部分比例为 $p$，核心数为 $n$，则理想加速比为  
   $$
   S(n)=\frac{1}{(1-p)+p/n}.
   $$
   单线程程序可看作 $p=0$，所以 $S(n)=1$，即增加核心数本身不能加快单线程程序的执行。  
   故 A 说法正确。

3. 分析 B：Flynn 分类法按指令流和数据流组合分类。多核处理器中，每个核心可以同时执行不同的指令流，也可以处理不同的数据流，因此属于 MIMD（多指令流多数据流）系统。  
   故 B 说法正确。

4. 分析 D：多核处理器在同一芯片上集成了多份核心资源，在工艺、运行条件相近的情况下，晶体管数量和开关活动更多，功耗/能耗通常比单核处理器更高。多核的主要优势是提高并行处理能力和性能功耗比，但这并不等于绝对能耗一定更低。  
   故 D 说法正确。

综合可知，不正确的是 C。

**易错点**：  
- 误以为“多核能让所有程序提速”。实际上只有可并行的多线程程序才能利用多核优势，单线程程序不能。
- 误把“核”等同于“控制单元”或“控制器”。多核中的每个核必须是完整的处理器核心，不只包含控制逻辑。
- 容易死记“多核属于 MIMD”，却不理解原因。多核同时存在多条指令流和多条数据流，所以属于 MIMD。
- 对 D 的“能耗”不要绝对化。若比较同等工艺、同等工作负载下，多核通常总功耗更高；但性能功耗比可能更好。题目用了“通常”，不是严格的必然结论。

**命题规律**：  
本考点属于“并行体系结构”部分，常与 Flynn 分类、Amdahl 定律、单核/多核性能比较、Cache 一致性等结合命题。常见变式有：“多核处理器属于 MIMD 吗？”“多核能否加速单线程程序？”“多核与多处理器的异同”“多核对功耗的影响”。复习时应把四类 Flynn 系统及典型例子记牢，并理解“核”“线程”“进程”“并行性”等概念的区别。

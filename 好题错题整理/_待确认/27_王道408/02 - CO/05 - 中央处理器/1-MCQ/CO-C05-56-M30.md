# 选择题 第 30 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-56-M30_题目.png|题目]]

30.【2023 统考真题】 在采用“取指、译码/取数、执行、访存、写回”5 段流水线的 $RISC$ 处理器中，执行如下指令序列(第一列为指令序号)，其中 $s0$、 $s1$、 $s2$、 $s3$ 和 $t2$ 表示寄存器编号.
```
I1: add s2, s1, s0        // R[s2] ← R[s1] + R[s0]
I2: load s3, 0(s2)       // R[s3] ← M[R[s2] + 0]
I3: beq t2, s3, L1       // if R[t2] = R[s3]   jump to L1
I4: addi t2, t2, 20      // R[t2] ← R[t2] + 20
I5: L1: ....
```
若采用转发(旁路)技术处理数据冒险,采用硬件阻塞方式处理控制冒险,则在指令 $I1$~$I4$ 的执行过程中,发生流水线阻塞的指令有( )
(A) 仅 $I3$
(B) 仅 $I2$、$I4$
(C) 仅 $I3$、$I4$
(D) 仅 $I2$、$I3$、$I4$

## 答案

## DeepSeek V4 Flash Max 解析

**答案**：C。仅 $I3$、$I4$ 发生阻塞：$I3$ 因 $I2$ 的 load-use 数据冒险需要阻塞，$I4$ 因 $beq$ 分支控制冒险被硬件阻塞；$I2$ 虽依赖 $I1$，但可通过转发解决。

**解题切入点**：先找指令之间的 RAW 依赖，再看依赖结果何时产生、何时被使用。可以把每条指令看成一个“生产者→消费者”关系：普通运算结果可以转发；load 结果必须等访存段结束后才能转发；分支指令本身还会带来控制冒险。做这种题像做依赖图：先找“谁写了这个寄存器、谁要读这个寄存器”，再判断中间能不能用转发填平。

**推演**：

相关指令为：

$$
I1:\ R[s2]\leftarrow R[s1]+R[s0]
$$

$$
I2:\ R[s3]\leftarrow M[R[s2]+0]
$$

$$
I3:\ \text{if } R[t2]=R[s3] \text{ then } PC\leftarrow L1
$$

$$
I4:\ R[t2]\leftarrow R[t2]+20
$$

五段分别为：取指 IF、译码/取数 ID、执行 EX、访存 MEM、写回 WB。

1. $I1$ 与 $I2$ 之间：  
   $I1$ 写 $s2$，$I2$ 读 $s2$ 作为访存基址。$I1$ 在 EX 段末已经得到 $s2$ 的结果，$I2$ 在下一个周期进入 EX 段计算访存地址，转发器可将 $I1$ 的 EX 结果送到 $I2$ 的 EX 输入端。因此 $I2$ **不需要阻塞**。

2. $I2$ 与 $I3$ 之间：  
   $I2$ 是 load，目标寄存器 $s3$ 只有在 MEM 段结束、进入 MEM/WB 寄存器后才有效。$I3$ 的 $beq$ 需要读 $s3$ 进行比较。若 $I3$ 紧跟 $I2$ 进入流水线，它使用 $s3$ 时 load 数据还未准备好。即使有转发，load-use 冒险也需要插入一个气泡，使 $I3$ 的执行延后一拍。因此 $I3$ **发生阻塞**。

3. $I3$ 与 $I4$ 之间：  
   $I3$ 是分支指令 $beq$，会产生控制冒险。题目规定采用硬件阻塞方式处理控制冒险，因此在分支结果确定前，不能正常放行后续指令 $I4$ 进入流水线。因此 $I4$ **发生阻塞**。  
   注意：$I4$ 写 $t2$，$I3$ 读 $t2$，但 $I3$ 不写 $t2$，所以 $I4$ 的阻塞不是数据冒险，而是控制冒险。

结论：发生流水线阻塞的指令只有 $I3$、$I4$。

**易错点**：

- 误以为 $I2$ 也阻塞：$I1$ 是普通运算指令，结果可通过 EX/MEM 转发给 $I2$ 使用，不需要阻塞。
- 误以为 $I3$ 的阻塞是控制冒险：$I3$ 首先是因为等待 load 结果而阻塞，这是 load-use 数据冒险；$I4$ 才是控制冒险。
- 误以为 $beq$ 不写寄存器，所以与 $I4$ 无关：$I4$ 的阻塞确实不是因为寄存器数据冒险，而是因为分支造成的控制冒险。
- 注意分支是否实际跳转的约定：若只讨论动态执行且分支真的跳到 $L1$，$I4$ 不在动态指令流中；但本题按所列 $I1\sim I4$ 顺序考察，$I4$ 作为 $beq$ 后的顺序指令，被控制阻塞。

**命题规律**：本题是经典五段流水线的数据冒险与控制冒险综合题。常见变式包括：把 load-use 改为普通运算后的使用、把分支改为跳转指令并配合分支预测、要求画出各周期流水线状态，或要求计算阻塞周期数和 CPI。复习时要熟练掌握转发路径、load-use 阻塞条件，以及分支指令的 stall/flush 机制。

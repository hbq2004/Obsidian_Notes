# 选择题 第 9 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-53-M09_题目.png|题目]]

9. 下列关于单周期 $CPU$ 和多周期 $CPU$ 的描述中，错误的是
A. 单周期 $CPU$ 更容易支持复杂指令（如乘法、除法）
B. 单周期 $CPU$ 部件冗余大、利用率低，多周期 $CPU$ 则刚好相反
C. 单周期 $CPU$ 在 1 个时钟周期内执行一条指令，$CPI = 1$
D. 多周期 $CPU$ 至少需要 2 个时钟周期才能执行一条指令，$CPI > 1$

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-53-M09_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A。单周期 CPU 把所有指令都固定在一个时钟周期内完成，支持乘除这类复杂指令会严重拉长时钟周期、增加硬件开销，因此“更容易支持复杂指令”说反了；实际是多周期 CPU 通过分步执行更容易支持复杂指令。

**解题切入点**：看到“单周期 CPU 与多周期 CPU”，先抓两组核心对比：

- 单周期：$CPI=1$，时钟周期长，部件冗余大、利用率低，难以支持复杂指令。
- 多周期：$CPI>1$，时钟周期短，部件可分时复用，复杂指令可分解为多个步骤实现。

可以把单周期理解为“给所有题目统一安排一个能完成最难题目的整块时间”；简单题也必须等这么久，还要为不同难题准备不同专用工具。多周期则是“把每道题拆成多个小步骤，多个步骤共用同一套工具”。这样就能快速判断 A 说反了。

**推演**：

1. 单周期 CPU 中，每条指令都在 1 个时钟周期内完成，所以：
   $$
   CPI_{\text{单}}=1
   $$
   但是时钟周期必须按最慢指令所需时间设计：
   $$
   T_{\text{clk}}=\max_i T_i
   $$
   其中 $T_i$ 是第 $i$ 类指令在数据通路上所需的最短时间。因此，简单指令也被迫使用很长的时钟周期，整体效率低。

2. 对于乘法、除法这类复杂指令，单周期 CPU 必须在一个时钟周期内完成整个运算。要么使用复杂的组合逻辑乘法器、除法器，要么导致关键路径非常长。这样硬件开销大、时钟频率低、所有指令都被拖慢。所以“单周期 CPU 更容易支持复杂指令”是错误的，正确结论应该是多周期 CPU 更容易支持复杂指令。

3. 选项 B：单周期 CPU 中，不同指令不能分时复用功能部件，往往需要为最复杂指令准备足够冗余的硬件；多周期 CPU 将指令分成取指、译码、执行、访存、写回等步骤，可以在不同时钟周期复用 ALU、存储器等部件，因此“单周期部件冗余大、利用率低，多周期相反”是正确的。

4. 选项 C：单周期 CPU 每条指令只占 1 个时钟周期，因此 $CPI=1$，正确。

5. 选项 D：多周期 CPU 中一条指令至少需要取指和执行两个阶段，所以至少需要 2 个时钟周期，平均 $CPI>1$，正确。

综上，错误选项是 A。

**易错点**：

- 易错点 1：看到“单周期 $CPI=1$”就认为单周期一定更快。实际上时间公式是：
  $$
  T_{\text{CPU}}=IC\times CPI\times T_{\text{clk}}
  $$
  单周期 $CPI$ 虽小，但 $T_{\text{clk}}$ 很大；多周期 $CPI$ 大，但 $T_{\text{clk}}$ 小，不能仅凭 $CPI$ 判断快慢。

- 易错点 2：误以为单周期 CPU 控制简单，所以更容易支持复杂指令。控制简单不等于执行复杂指令容易；单周期把所有操作压进一个周期，硬件复杂度和关键路径都急剧增加。

- 易错点 3：误以为多周期 CPU 的 $CPI$ 可以等于 1。多周期 CPU 至少需要取指和执行两步，因此一条指令不可能在 1 个时钟周期内完成。

- 易错点 4：忽略“部件冗余大”的含义。单周期为满足一个周期内取指和访存等需求，往往要准备更多独立部件；多周期可以分时复用，所以硬件利用率更高。

**命题规律**：

本考点属于 408 计算机组成原理中 CPU 数据通路与控制器的常考概念。命题常见形式包括：

- 直接比较单周期、多周期、流水线 CPU 的 $CPI$、时钟周期、吞吐率、硬件利用率；
- 给出各类指令在多周期 CPU 中的周期数，计算平均 $CPI$；
- 结合“单周期时钟周期取决于最慢指令”设计计算题；
- 将单周期/多周期与微程序控制、硬布线控制结合，考查控制方式。

复习建议：熟记三者的时间模型：
- 单周期：$CPI=1$，时钟周期最长，硬件冗余大；
- 多周期：$CPI>1$，时钟周期短，硬件复用高；
- 流水线：$CPI$ 可接近 1，通过时间重叠提高吞吐率。

同时要理解“用时间换硬件”和“用硬件换时间”的权衡关系，才能在做概念辨析题时快速排除干扰项。

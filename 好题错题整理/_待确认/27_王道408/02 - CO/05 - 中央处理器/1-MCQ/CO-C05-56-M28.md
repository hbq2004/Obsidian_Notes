# 选择题 第 28 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-56-M28_题目.png|题目]]

28.【2019统考真题】在采用“取指、译码/取数、执行、访存、写回”5段流水线的处理器中，执行如下指令序列，其中 $s0$、$s1$、$s2$、$s3$ 和 $t2$ 表示寄存器编号。下列指令对中，不存在数据冒险的是 (    )
```asm
I1:  add s2, s1, s0       // R[s2] ← R[s1] + R[s0]
I2:  load s3, 0(t2)       // R[s3] ← M[R[t2] + 0]
I3:  add s2, s2, s3       // R[s2] ← R[s2] + R[s3]
I4:  store s2, 0(t2)      // M[R[t2] + 0] ← R[s2]
```
(A) $I1$ 和 $I3$
(B) $I2$ 和 $I3$
(C) $I2$ 和 $I4$
(D) $I3$ 和 $I4$

## 答案

## DeepSeek V4 Flash Max 解析

**答案**：C。  
$I2$ 写 $s3$，而 $I4$ 读的是 $s2$ 和 $t2$，且 $I2$ 不写 $s2$、$t2$，二者无“先写后读”的寄存器数据相关，所以不存在数据冒险。

**解题切入点**：拿到这种流水线题，先不要纠结每一拍怎么流动，先做“寄存器读写表”。数据冒险最常见的是 RAW（写后读）：某条指令写了一个寄存器，后面某条指令又要读这个寄存器。就像算法竞赛里查变量依赖一样，先标出每个变量的 def（写）和 use（读），再看前后是否构成依赖。

**推演**：

五段流水线为：取指、译码/取数、执行、访存、写回。判断数据冒险，主要看两条指令之间是否存在：

$$I_i \text{ 写寄存器 } r,\quad I_j \text{ 读寄存器 } r,\quad i<j$$

即后面的指令读到了前面指令准备写入的寄存器。

先列出四条指令的读写寄存器：

| 指令 | 写寄存器 | 读寄存器 |
|---|---|---|
| $I1$ | $s2$ | $s1,s0$ |
| $I2$ | $s3$ | $t2$ |
| $I3$ | $s2$ | $s2,s3$ |
| $I4$ | 无（只写存储器） | $s2,t2$ |

逐项检查：

- (A) $I1$ 与 $I3$：$I1$ 写 $s2$，$I3$ 读 $s2$，存在 RAW 数据冒险。
- (B) $I2$ 与 $I3$：$I2$ 写 $s3$，$I3$ 读 $s3$，存在 RAW 数据冒险，且是典型的 load-use 冒险。
- (C) $I2$ 与 $I4$：$I2$ 写 $s3$，但 $I4$ 不读 $s3$；$I4$ 读 $s2$ 和 $t2$，而 $I2$ 不写这两个寄存器。二者没有寄存器数据相关，因此不存在数据冒险。
- (D) $I3$ 与 $I4$：$I3$ 写 $s2$，$I4$ 的 store 数据来自 $R[s2]$，即 $I4$ 读 $s2$，存在 RAW 数据冒险。

因此只有 C 正确。

**易错点**：

1. 以为只有相邻指令之间才有数据冒险。  
   $I1$ 和 $I3$ 中间隔着 $I2$，但 $I2$ 没有改写 $s2$，所以 $I3$ 读的 $s2$ 仍然来自 $I1$，依然是数据冒险。

2. 忽略 load-use 冒险。  
   $I2$ 是 load，写入 $s3$；$I3$ 紧接着使用 $s3$，这是典型的 load-use 数据冒险。

3. 以为 store 不读寄存器。  
   `store s2, 0(t2)` 要把 $R[s2]$ 写入内存，因此它要读 $s2$ 和 $t2$，所以 $I3$ 写 $s2$ 与 $I4$ 读 $s2$ 之间仍构成 RAW。

4. 把两个指令都读同一个寄存器当成冒险。  
   $I2$ 和 $I4$ 都读 $t2$，但只是读，没有写，因此不构成数据冒险。

**命题规律**：  
本题考的是五段流水线数据冒险的识别，核心是“寄存器读写关系”而不是指令功能。常见变式有：问需要插入几个 nop、问哪些冒险可以靠转发解决、问如何调整指令顺序消除冒险、或单独考查 load-use 冒险。复习时应熟练列出每条指令的写寄存器和读寄存器，并能结合五段流水线的阶段判断数据何时产生、何时被使用。

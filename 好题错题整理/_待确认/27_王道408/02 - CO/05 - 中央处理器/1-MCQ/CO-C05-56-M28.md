28.【2019统考真题】在采用“取指、译码/取数、执行、访存、写回”5段流水线的处理器中，执行如下指令序列，其中 $s0$、$s1$、$s2$、$s3$ 和 $t2$ 表示寄存器编号。下列指令对中，不存在数据冒险的是 (    )
```asm
I1:  add s2, s1, s0       // R[s2] ← R[s1] + R[s0]
I2:  load s3, 0(t2)       // R[s3] ← M[R[t2] + 0]
I3:  add s2, s2, s3       // R[s2] ← R[s2] + R[s3]
I4:  store s2, 0(t2)      // M[R[t2] + 0] ← R[s2]
```
(A) $I1$ 和 $I3$
(B) $I2$ 和 $I3$
(C) $I2$ 和 $I4$
(D) $I3$ 和 $I4$

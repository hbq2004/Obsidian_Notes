# 选择题 第 7 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-57-M07_题目.png|题目]]

7. 双核 $CPU$ 和超线程 $CPU$ 的共同点是 (  )

(A) 都有两个内核
(B) 都能同时执行两个运算
(C) 都包含两个 $CPU$
(D) 都不会出现争抢资源的现象

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-57-M07_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。双核 CPU 有两个物理内核，超线程 CPU 只有一个物理内核但可以提供两个逻辑处理器；两者都能让两个运算/线程同时得到执行，因此共同点是“都能同时执行两个运算”。

**解题切入点**：  
遇到这类题，先分清三个概念：物理 CPU、物理内核、逻辑处理器。双核和超线程讲的是“提高并行能力”的手段。可以类比：双核是两个独立厨师同时做两道菜；超线程是一个厨师拥有两套菜谱和案板状态，可以同时兼顾两道菜，但灶台、厨具是共享的，可能会出现争抢。所以关键要抓“同时执行能力”与“资源是否共享”两条线。

**推演**：  

1. **双核 CPU**  
   一个 CPU 芯片内部集成两个完整的物理内核，每个内核都有自己的运算器、寄存器、流水线等资源；操作系统可以把两个线程/进程调度到两个内核上真正并行执行。

2. **超线程 CPU**  
   超线程技术是一种同时多线程（SMT）技术。它只复制处理器的架构状态，如程序计数器、通用寄存器、控制寄存器等，使一个物理内核在操作系统看来变成两个“逻辑处理器”。两个线程可以同时处于运行状态，共享执行单元、Cache、流水线等部件。

3. **选项判断**：  
   - A 错：双核 CPU 有两个物理内核，但超线程 CPU 并没有两个物理内核，它只是一个物理内核配两个逻辑处理器。  
   - B 对：双核 CPU 用两个物理内核执行两个线程；超线程 CPU 用两个逻辑处理器执行两个线程。从“同时执行两个运算”的意义上，二者具有共同点。  
   - C 错：双核 CPU 是“一个芯片、两个内核”，超线程 CPU 是“一个内核、两个逻辑处理器”，都不是指包含两个 CPU。  
   - D 错：双核 CPU 会争抢共享的三级缓存、内存带宽、总线等资源；超线程 CPU 更会争抢执行单元、Cache、流水线等资源，所以二者都会出现资源争抢。

因此正确答案是 B。

**易错点**：  
- 误选 A：把“逻辑处理器”当成“内核”。超线程只是复制了架构状态，并没有增加物理运算核心。  
- 误选 C：操作系统显示两个逻辑 CPU，不代表物理上有两个 CPU，也不代表有两个物理内核。  
- 误选 D：并行不意味着无冲突；双核和超线程都共享部分资源，资源争抢不可避免。  
- 容易把超线程与双核性能等同：超线程能提高资源利用率，但由于共享执行单元，性能提升通常不如真正的双核。

**命题规律**：  
本题属于计算机组成原理中“CPU 并行技术”的考点，重点考查多核 CPU、超线程、逻辑处理器之间的区别与联系。常见变式包括：判断“逻辑处理器数量与物理核心数的关系”、分析超线程为什么不能使性能翻倍、考查共享资源争抢等。复习时记住三句话即可：多 CPU 指多颗物理芯片；多核指一个芯片内有多个物理内核；超线程是一个物理内核模拟出两个逻辑处理器。

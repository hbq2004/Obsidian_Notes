# 选择题 第 27 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-54-M27_题目.png|题目]]

27.【2021统考真题】通常情况下,将汇编语言程序中实现特定功能的指令序列定义成一条伪指令(pseudoinstruction)。在下列选项中,CPU能理解并直接执行的是( )
I.伪指令 II.微指令 III.机器指令 IV.汇编指令
(A). 仅I、IV
(B). 仅II、III
(C). 仅III、IV
(D). 仅I、III、IV

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-54-M27_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。CPU 能直接执行的是微指令和机器指令；伪指令、汇编指令必须经过汇编/翻译后才能变成机器指令，CPU 本身不能直接执行。

**解题切入点**：先区分“给谁看/由谁执行”的层次：汇编语言程序是给人看的，CPU 只认二进制机器指令；在微程序控制器中，机器指令的执行又是由更底层的微指令来驱动的。做题时抓住“直接执行”四个字，凡是需要翻译、汇编、伪处理的东西都不能选。

**推演**：

1. 伪指令（I）  
   伪指令不是机器指令，它是汇编语言中为了编程方便而定义的“指令”，如 `EQU`、`DB`、`MACRO` 等。它在汇编阶段由汇编器识别并处理，不会生成对应的机器指令，也不会被 CPU 执行。  
   因此，I 不能选。

2. 微指令（II）  
   在微程序控制器中，一条机器指令被分解成若干条微指令，微指令存放在控制存储器中。CPU 中的控制器按次序读取微指令，产生微命令，控制数据通路完成操作。微指令是硬件直接执行的最底层控制命令。  
   因此，II 能选。

3. 机器指令（III）  
   机器指令是用二进制代码表示的指令，是 CPU 能直接识别并执行的指令。CPU 取指、译码、执行的对象就是机器指令。  
   因此，III 能选。

4. 汇编指令（IV）  
   汇编指令是机器指令的助记符表示，例如 `ADD R1, R2`。CPU 的硬件电路不认识助记符，必须由汇编器将汇编指令翻译成机器指令后，CPU 才能执行。  
   因此，IV 不能选。

综上，能被 CPU 理解并直接执行的只有 **II、III**，对应选项 B。

**易错点**：

- 误以为“汇编指令”是 CPU 能执行的指令。实际上汇编指令只是助记符，必须翻译成机器指令才能被 CPU 识别。
- 误以为“伪指令”是虚假无用的指令，从而不选或选错。伪指令在汇编阶段起作用，不是 CPU 执行对象。
- 对“微指令”概念不熟悉。微指令是微程序控制方式下的底层硬件指令，CPU 能直接执行；若题目讨论的是硬布线控制器，则不存在微指令，但统考中一般默认讨论微程序控制器时微指令可被直接执行。
- 混淆“汇编程序”和“汇编指令”：汇编程序是汇编器翻译整个汇编语言源程序；汇编指令是源程序中的助记符指令，二者都不是 CPU 直接执行的对象。

**命题规律**：本题考查指令系统层次结构，是计算机组成原理中的基础概念题。常见变式有：给出“机器指令、微指令、汇编指令、伪指令”多个概念，要求判断 CPU 能否直接执行、哪些属于硬件直接执行、哪些属于软件翻译后执行；或与编译器、汇编器、控制器的作用结合考查。复习时应梳理“高级语言 → 汇编语言 → 机器语言 → 微指令”的层次关系，并牢记：CPU 直接执行的是机器指令，微程序控制器中微指令也由硬件直接执行；汇编指令和伪指令都需要汇编器的加工。

# 选择题 第 27 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-54-M27_题目.png|题目]]

27.【2021统考真题】通常情况下，将汇编语言程序中实现特定功能的指令序列定义成一条伪指令（$pseudoinstruction$）。在下列选项中，$CPU$ 能理解并直接执行的是（\_\_\_\_）.

I. 伪指令  II. 微指令  III. 机器指令  IV. 汇编指令

A. 仅 I、IV
B. 仅 II、III
C. 仅 III、IV
D. 仅 I、III、IV

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-54-M27_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B（仅Ⅱ、Ⅲ）。CPU 能直接理解并执行的是微指令（微程序控制器中直接控制硬件）和机器指令（二进制代码），而伪指令和汇编指令需要经过汇编器翻译才能被 CPU 识别。

**解题切入点**：  
拿到题目先明确“CPU 直接执行”的含义——即不需要额外软件或硬件转换，硬件本身能识别并运行。这涉及指令系统的层次结构：汇编语言（伪指令、汇编指令）→ 机器语言（机器指令）→ 微程序（微指令）。通常，伪指令和汇编指令是文本形式，必须由汇编器变成机器指令；机器指令是二进制码，CPU 取指译码后执行；微指令是控制存储器中的微操作，直接由微程序控制器产生控制信号。因此，先排除需要转换的 I 和 IV，再确认 II 和 III 是否属于硬件直接执行。

**推演**：  
- **伪指令**（I）：在汇编语言中，伪指令用于定义数据、分配空间、控制汇编过程等（如 `DB`、`EQU`），它们不是机器指令，而是给汇编器处理的命令，CPU 无法直接执行。  
- **微指令**（II）：在微程序控制的 CPU 中，机器指令由微指令序列解释完成。微指令直接存储在控制存储器中，微程序控制器按顺序读取并输出控制信号，从而控制数据通路。因此，微指令是 CPU 内部直接执行的（无需额外翻译）。  
- **机器指令**（III）：机器指令是二进制编码的指令，CPU 的取指、译码、执行阶段直接识别并完成操作。这是 CPU 最直接执行的指令形式。  
- **汇编指令**（IV）：通常指汇编语言中的助记符（如 `MOV AX, BX`），它们需要经过汇编器转换成机器指令，CPU 不能直接识别文本形式的助记符。  

综上，CPU 能直接执行的只有微指令和机器指令，故选项 B 正确。

**易错点**：  
1. **混淆“汇编指令”与“机器指令”**：以为汇编指令是助记符，但 CPU 只能执行二进制码，不能直接执行文本。  
2. **忽略微指令的硬件执行特性**：误以为微指令属于软件层面，但它在微程序控制器中直接控制硬件，属于 CPU 内部直接执行。  
3. **认为伪指令可被 CPU 直接执行**：伪指令是汇编器指令，不是机器指令，必须提前转换为数据或代码。  

**命题规律**：  
- **考点定位**：指令系统的层次结构与 CPU 执行机制。  
- **常见变式**：给出不同指令形式（如宏指令、微指令、机器指令、汇编指令），判断哪些能被 CPU 直接执行；或结合微程序控制与硬布线控制对比。  
- **复习建议**：理解指令从高级语言到微指令的转化过程，重点区分“汇编指令”与“机器指令”的关系，掌握微程序控制器的基本工作原理。

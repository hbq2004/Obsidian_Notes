# 选择题 第 11 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-55-M11_题目.png|题目]]

11.【2016统考真题】异常是指令执行过程中在处理器内部发生的特殊事件，中断是来自处理器外部的请求事件。下列关于中断或异常情况的叙述中,错误的是( ).

A. “访存时缺页”属于中断
B. “整数除以0”属于异常
C. "DMA 传送结束"属于中断
D. “存储保护错”属于异常

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-55-M11_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A。缺页是处理器在访存过程中内部检测到的特殊事件，属于异常，不是中断。

**解题切入点**：拿到题先抓住题干给出的两个关键定义——“异常”发生在处理器内部，“中断”来自处理器外部。然后逐项判断事件是“处理器自己发现”还是“外部设备/控制器主动请求”。就像比赛里分清“程序自身 bug”和“外部提交的新任务”：缺页、除零、存储保护错都是程序执行过程中处理器自己遇到的“内部问题”，属于异常；而 DMA 传送结束是外部设备通过控制器向 CPU 发出的“请求通知”，属于中断。

**推演**：

1. 题干定义：  
   - 异常：指令执行过程中在**处理器内部**发生的特殊事件。  
   - 中断：来自**处理器外部**的请求事件。

2. 逐项分析：

   - **A. “访存时缺页”**  
     缺页是 CPU 访问虚拟地址时，发现该页不在主存中，由存储器管理部件（MMU）在指令执行过程中检测到并触发的一种特殊事件。它发生在处理器内部，且与当前指令的执行直接相关，因此属于**异常**（具体属于异常中的“故障”类），而不是来自外部设备的中断。因此 A 的说法错误。

   - **B. “整数除以 0”**  
     除法指令执行时，处理器检测到除数为 0，产生内部异常（常称“陷阱”或“故障”）。它是 CPU 在执行指令时主动发现的，属于异常。因此 B 正确。

   - **C. “DMA 传送结束”**  
     DMA 控制器完成一次数据传送后，通过中断请求线向 CPU 发出中断请求，这是**来自处理器外部**的请求事件，属于中断。因此 C 正确。

   - **D. “存储保护错”**  
     当程序访问不允许访问的存储区域时，CPU 在指令执行过程中检查到权限不符，产生异常。该事件由处理器内部机制发现，属于异常。因此 D 正确。

3. 综上，唯一错误的是 A。

**易错点**：

- **把“缺页”误认为中断**：有些考生觉得“缺页”要调入外存数据，需要外部存储设备参与，所以误判为中断。实际上，缺页的**触发源**是 CPU 在访存时内部的地址转换/检查机制，属于异常；后续调入页面只是异常处理程序的工作，不影响其分类。
- **混淆“内中断”与“外部中断”**：有的教材将异常称为“内中断”，将来自外部的称为“外中断”。但本题题干已明确区分“异常”和“中断”，必须按题干定义作答。
- **忘记 DMA 传送结束的请求方**：DMA 传送结束是 DMA 控制器主动向 CPU 发中断请求，请求方在 CPU 外部，故属于中断，而不是异常。
- **不注意“存储保护错”的检测位置**：存储保护错是 CPU 在访问存储单元时根据页表/段表属性检查出来，是在处理器内部产生的，不是外部事件。

**命题规律**：

- 本题是 2016 年统考真题，考查中断与异常的**基本概念辨析**，属于高频基础考点。选项常围绕“缺页”“除零”“DMA 结束”“溢出”“越权访问”等进行组合。
- 常见变式：
  - 将“缺页”与“页面置换”混淆设问；
  - 将“时钟中断”“I/O 中断”与“非法指令”“溢出”混合考查；
  - 结合中断响应过程、异常处理流程等综合题考查。
- 复习建议：熟记异常与中断的根本区别在于**触发源在 CPU 内部还是外部**；同时区分异常的类型（故障、陷阱、终止）与典型例子。做题时先看事件由谁发现、由谁发起，再判断类别，即可快速得分。

# 选择题 第 6 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-55-M06_题目.png|题目]]

6. $CPU$响应中断的时间是（ ）

A. 一条指令执行结束
B. $I/O$设备提出中断
C. 取指周期结束
D. 指令周期结束

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-55-M06_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A。CPU 响应中断是在一条指令执行结束后、下一条指令开始前，通过中断查询/中断采样来响应。

**解题切入点**：先明确“响应中断”不是“发现中断请求”。$I/O$ 设备提出中断只是外部事件，CPU 必须在合适的时机“受理”它。可以类比算法竞赛中的“事件驱动”：中断请求只是把事件挂在队列里，CPU 只有在一个天然的“检查点”才会处理它，而指令执行结束就是最常用的检查点。

**推演**：

CPU 与外设并行工作，外设随时可能发出中断请求，但 CPU 不能在任何时刻都停下当前指令去响应，因为一条指令的执行过程是不可分割的，尤其是访问内存、修改寄存器等操作必须连续完成。因此中断响应必须发生在指令的“自然边界”上。

一条指令的执行过程可分为：

- 取指周期：按 PC 取指令；
- 间址周期（若有间接寻址）：取操作数有效地址；
- 执行周期：执行指令规定的操作；
- 中断周期：若 CPU 响应中断，则执行“中断隐指令”，完成关中断、保存断点、送中断向量等操作。

其中，中断周期是 CPU **已经决定响应中断之后**进入的周期，而不是响应中断的时刻。因此：

- $I/O$ 设备提出中断：只是产生中断请求信号，CPU 尚未响应。
- 取指周期结束：此时一条指令还未执行完，不能响应中断。
- 指令周期结束：指令周期通常指取指、间址、执行、中断等周期构成的完整序列。若把“中断周期”也算进指令周期，则“指令周期结束”是在中断处理完成后，显然不是响应时刻；若按经典定义，指令周期指从取指到执行完毕，那么“指令周期结束”本质上等价于“一条指令执行结束”。但本题选项中“一条指令执行结束”更直接准确地表达了中断响应时刻。

因此，CPU 响应中断的时间是：**一条指令执行结束时**。具体来说，CPU 在每条指令执行结束后的时刻采样中断请求信号，若存在未被屏蔽的中断请求，则进入中断周期。

**易错点**：

1. 错选 B：外设提出中断只是“请求”，CPU 是否响应、何时响应还要看中断允许标志和当前指令是否执行完。
2. 错选 C：取指周期结束只完成了取指令，指令尚未执行，不能打断。
3. 错选 D：若把指令周期理解为“取指 + 间址 + 执行 + 中断”的完整周期，则指令周期结束已经完成中断处理；若理解为“取指 + 间址 + 执行”，则它和 A 等价，但 A 表述更规范，且本题默认 D 不是最优表述。
4. 注意“响应中断”与“中断处理”的区别：响应是进入中断周期的开始，处理是进入中断服务程序后的过程。

**命题规律**：

本题是中断系统的基础概念题，考查中断响应时机。408 中常与“中断隐指令”“中断周期”“向量中断”“中断屏蔽”等结合考查。常见变式包括：

- 问“CPU 在哪个周期采样中断请求” → 执行周期的结束时刻 / 指令结束时刻；
- 问“中断隐指令完成哪些操作” → 关中断、保存断点、送中断向量；
- 问“硬件响应中断的条件” → 中断请求、中断允许、一条指令执行结束、无更高优先级中断等。

复习建议：把中断全过程分成“中断请求 → 中断判优 → 中断响应 → 中断处理 → 中断返回”五个阶段，每个阶段由硬件还是软件完成要分清。尤其要记住：CPU 响应中断的时机是**指令执行结束**，响应后进入的是**中断周期**。

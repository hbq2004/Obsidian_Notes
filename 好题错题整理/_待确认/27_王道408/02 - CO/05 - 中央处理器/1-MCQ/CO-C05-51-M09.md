# 选择题 第 9 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-51-M09_题目.png|题目]]

9. 下面有关程序计数器（$PC$）的叙述中，错误的是（  ）.
A. $PC$ 中总是存放指令地址.
B. $PC$ 的值由 $CPU$ 在执行指令过程中进行修改.
C. 执行转移指令时，$PC$ 的值总是修改为转移指令的目标地址.
D. $PC$ 的位数一般和存储器地址寄存器（$MAR$）的位数一样.

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-51-M09_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。  
理由：条件转移指令执行时，若转移条件不成立，$PC$ 不会被修改为转移目标地址，而是继续顺序指向下一条指令；“总是”表述过于绝对。

**解题切入点**：  
先抓“错误的是”这一设问，再锁定 $PC$ 的功能。可以把 $PC$ 类比为程序执行中的“书签指针”：正常情况下每读完一页自动翻到下一页（顺序执行），遇到“跳转”指令时，书签是否真的跳到指定页，还要看跳转条件是否满足。所以看到“总是”这类绝对化词语，就要警惕是否忽略了条件转移的分支情况。

**推演**：  
1. 程序计数器 $PC$ 是 CPU 内部的关键寄存器，用于存放当前指令的地址或下一条指令的地址。  
   - 取指阶段：CPU 根据 $PC$ 的内容访问存储器，取出指令；同时 $PC$ 自动更新为下一条指令的地址（通常为当前 $PC$ 值加“指令长度”或加 1，取决于编址方式）。  
   - 因此，A 选项“$PC$ 中总是存放指令地址”正确。注意这里的“指令地址”指存储器中指令单元的地址，$PC$ 正是为此而设。

2. B 选项“$PC$ 的值由 CPU 在执行指令过程中进行修改”正确。  
   - 无论顺序执行还是转移执行，$PC$ 的修改都发生在 CPU 执行指令的过程中（取指后自动修改，或执行阶段根据指令类型修改）。

3. C 选项“执行转移指令时，$PC$ 的值总是修改为转移指令的目标地址”错误。  
   - 转移指令分为无条件转移和条件转移。  
   - 无条件转移（如 JMP）：$PC \gets$ 目标地址，正确。  
   - 条件转移（如 JZ、BNE 等）：只有当条件成立时，$PC$ 才被修改为目标地址；若条件不成立，$PC$ 保持顺序执行，即 $PC \gets PC + 1$（或加指令长度）。  
   - 因此“总是”不成立。

4. D 选项“$PC$ 的位数一般和存储器地址寄存器（MAR）的位数一样”正确。  
   - $PC$ 需要存放指令地址，其位数应能表示整个存储器地址空间；$MAR$ 用于存放访存地址，其位数也由地址空间决定。两者位数通常一致，都等于地址总线宽度或地址码位数。

综上，错误的是 C。

**易错点**：  
- 只看“转移指令”就认为 $PC$ 一定跳转，忽略了条件转移的“条件不成立”分支。  
- 误以为 $PC$ 只存放“当前指令地址”，实际上有些教材中 $PC$ 在取指后已指向下一条指令；但无论哪种定义，题目 A 的“指令地址”表述并不影响其正确性。  
- 将 $PC$ 与指令寄存器（IR）混淆：$IR$ 存放当前取出的指令内容，$PC$ 存放指令地址，二者功能不同。  
- 忽略 D 中“一般”两字，$PC$ 与 $MAR$ 位数一般相同，但在某些特殊设计中可能因虚地址、分段等机制不相同，题目用“一般”是合理表述。

**命题规律**：  
- 考点：CPU 内部寄存器 $PC$ 的功能、指令执行流程、转移指令的分类。  
- 常见变式：  
  1. 考查 $PC$ 在取指周期如何修改（自动加“指令长度”还是加 1，取决于编址方式）。  
  2. 结合流水线考查 $PC$ 何时更新。  
  3. 与 $IR$、$MAR$、$MDR$ 的功能对比选择。  
  4. 考查条件转移指令执行时 $PC$ 变化的两种情况。  
- 复习建议：牢固掌握 CPU 各寄存器作用及指令周期基本流程；特别注意“无条件转移”与“条件转移”对 $PC$ 的不同影响；做题时对“总是”“一定”等绝对化词语保持敏感，优先找反例。

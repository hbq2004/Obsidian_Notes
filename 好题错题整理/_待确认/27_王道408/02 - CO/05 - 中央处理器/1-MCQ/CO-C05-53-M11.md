# 选择题 第 11 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-53-M11_题目.png|题目]]

11. 下列关于单周期$CPU$与采用单总线结构的多周期$CPU$的说法中，正确的是 ( )  
(A) 单周期$CPU$可基于单总线结构实现  
(B) 运行相同程序时，单周期$CPU$的总执行时间一定更短  
(C) 多周期$CPU$可将指令和数据存放在同一单端口存储器中，而单周期$CPU$不行  
(D) 单周期$CPU$的硬件实现成本通常低于多周期$CPU$

## 答案

## DeepSeek V4 Flash Max 解析

**答案**：C。多周期 CPU 把“取指”和“访存”安排在不同时钟周期，因此可以共用一个单端口存储器；单周期 CPU 在同一个时钟周期内既要取指又要访存，无法共用一个单端口存储器。

**解题切入点**：  
先抓住单周期和多周期的本质区别：单周期是“一个时钟周期内完成一条指令的所有操作”，多周期是“一条指令分成多个时钟周期完成”。判断选项时，重点看“资源冲突”：

- 单端口存储器：同一时刻只能进行一次读/写；
- 单总线：同一时刻只能进行一次数据传送。

就像做题时只有一个共享窗口，同一时刻只允许一个任务使用；如果两个操作同时要访问同一个窗口，就会冲突。

**推演**：  

设某程序共有 $N$ 条指令，单周期 CPU 的时钟周期为 $T_{\text{单}}$，多周期 CPU 的时钟周期为 $T_{\text{多}}$，第 $i$ 条指令在多周期 CPU 中需要的时钟周期数为 $CPI_i$。

单周期 CPU 中每条指令 $CPI=1$，其总执行时间为  
$$
T_{\text{单周期}}=N T_{\text{单}}。
$$

多周期 CPU 中不同指令的 $CPI_i$ 不同，其总执行时间为  
$$
T_{\text{多周期}}=\sum_{i=1}^{N} CPI_i T_{\text{多}}。
$$

单周期的时钟周期 $T_{\text{单}}$ 必须按最长指令路径设计，因而较长；多周期的 $T_{\text{多}}$ 只需按最慢的一个微操作设计，因而较短。两者乘积没有固定大小关系，因此不能说单周期 CPU 总执行时间一定更短，B 错误。

逐项分析：

- **A 错误**：单总线结构在同一时刻只允许一个数据传送。单周期 CPU 在一个时钟周期内需要同时完成取指、读寄存器、ALU 运算、访存、写回等多个操作，必须有多条独立通路/总线配合。单总线结构更适合多周期 CPU，因为多周期 CPU 的每个时钟周期只完成一个主要微操作。

- **B 错误**：由上述公式可知，单周期 $CPI=1$ 但时钟周期长；多周期 $CPI>1$ 但时钟周期短。两者总执行时间不能直接比较，不能说单周期一定更短。

- **C 正确**：多周期 CPU 在取指周期访问指令，在访存周期访问数据，分属不同时钟周期，所以使用同一个单端口存储器不会发生冲突。单周期 CPU 对于 load/store 指令，在同一个时钟周期内既要取指令又要读/写数据，若使用同一个单端口存储器，会同时争用存储器端口，因此不行；除非使用分离的指令存储器和数据存储器，或使用双端口存储器。

- **D 错误**：单周期 CPU 为了在一个时钟周期内完成最长指令，通常需要分离的指令/数据存储器，且数据通路并行度较高，硬件实现成本通常不低。多周期 CPU 可以分时复用 ALU 和存储器，但控制逻辑更复杂，需要状态寄存器等；不能说单周期 CPU 的硬件成本通常低于多周期 CPU。

**易错点**：  

1. 误把“CPI=1”等同于“执行时间一定短”，忽略了单周期 CPU 的时钟周期很长。  
   正确比较应使用：
   $$
   T_{\text{CPU}}=\text{指令数}\times CPI \times T_{\text{clk}}。
   $$

2. 误认为单周期 CPU 不能把指令和数据放在同一个存储器中，是因为“指令和数据不能同存”。  
   实际上，关键是“同一时钟周期内是否需要两次访问存储器”。多周期分时访问，单周期同时争用。

3. 误认为多周期控制复杂，所以硬件成本一定更高。  
   控制复杂不等于数据通路硬件一定多；多周期可共享存储器、ALU 等资源，数据通路成本通常可以降低。

4. 误把“单总线”理解为系统外部总线。  
   这里讨论的是 CPU 内部数据通路结构，单总线同一时刻只能支持一个数据传送。

**命题规律**：  
这是 408 计算机组成原理中 CPU 数据通路的常考对比题，重点考查：

- 单周期、多周期 CPU 的 CPI、时钟周期、总执行时间；
- 资源冲突：单端口存储器、单总线；
- 硬件代价与控制复杂度。

常见变式包括：

- 给出指令比例，计算单周期和多周期 CPU 的平均 CPI 或总执行时间；
- 判断“单周期 CPU 一定比多周期 CPU 快”类绝对化说法；
- 结合流水线 CPU，比较吞吐率和执行时间；
- 给出数据通路图，分析哪些操作可以在同一时钟周期完成。

复习时应把“单周期、多周期、流水线”三种 CPU 的时延模型和资源复用方式对比记忆，尤其要抓住“时间换空间、空间换时间”的核心思想。

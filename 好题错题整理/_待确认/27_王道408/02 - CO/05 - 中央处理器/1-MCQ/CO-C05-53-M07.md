# 选择题 第 7 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-53-M07_题目.png|题目]]

7. 下列关于 $CPU$ 时钟信号的叙述中,错误的是（ ）
A. 处理器总是每来一个时钟信号就开始执行一条新的指令
B. 边沿触发指状态单元总在时钟上升沿或下降沿开始改变状态
C. 时钟周期以相邻状态单元之间最长组合逻辑延迟为基准确定
D. 每个时钟周期称为一个节拍，机器的主频就是时钟周期的倒数

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-53-M07_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A。处理器并非每个时钟信号都开始执行一条新指令，一条指令可能需要多个时钟周期完成。

**解题切入点**：抓住“时钟信号”与“指令周期”的关系，区分“时钟周期”与“指令周期”两个概念。就像算法竞赛中，不能把“每轮循环”都与“完成一次完整操作”混为一谈，可能一个操作需要多轮循环。

**推演**：

- 选项 A：指令周期是指从取指、译码到执行完一条指令所需的全部时间，它由若干个时钟周期（节拍）组成。例如多周期 CPU 中，一条指令分为取指、译码、执行、访存、写回等多个步骤，每一步占用一个或多个时钟周期。因此，并不是每来一个时钟信号就必然开始一条新指令，可能当前指令尚未完成。故 A 错误。

- 选项 B：边沿触发（edge-triggered）是时序逻辑中触发器的常见工作方式，状态单元（如寄存器、触发器）仅在时钟上升沿或下降沿瞬间根据输入更新状态，这正是边沿触发的定义。故 B 正确。

- 选项 C：时钟周期必须足够长，以保证信号能穿过相邻状态单元之间最长的组合逻辑路径，并在下一个时钟边沿到达之前稳定下来。因此，时钟周期的确定以相邻状态单元之间最长组合逻辑延迟为基准，同时还需考虑触发器的建立时间、保持时间等。故 C 正确。

- 选项 D：通常把一个时钟周期称为一个节拍（或拍），主频即时钟频率，为时钟周期的倒数：
  $$f = \frac{1}{T}$$
  其中 $T$ 为时钟周期，$f$ 为主频。故 D 正确。

**易错点**：

1. 混淆“时钟周期”与“指令周期”。指令周期由多个时钟周期组成，并不是一个时钟周期等于一条指令。  
2. 误以为每个时钟上升沿一定开始新指令。实际上，在非流水线多周期 CPU 中，一条指令占用多个时钟周期；即使在流水线中，每个时钟周期开始一条指令也需要指令级并行支持，且“总是”这一表述过于绝对。  
3. 忽略选项 C 中的“基准”一词——它只是说明确定时钟周期的主要依据，并没有忽略建立时间等细节，因此 C 不能被误判为错误。

**命题规律**：该考点属于“计算机系统概述”或“中央处理器”部分的时钟与时序基础，常以选择题形式考查。常见变式包括：判断指令周期与时钟周期的关系、计算主频与时钟周期、理解流水线中时钟周期的作用等。复习时应重点掌握指令周期的基本概念、时钟周期与主频的关系、触发器边沿触发原理，并能区分单周期、多周期和流水线 CPU 的时钟特性。

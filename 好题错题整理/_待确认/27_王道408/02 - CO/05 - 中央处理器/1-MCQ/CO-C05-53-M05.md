# 选择题 第 5 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-53-M05_题目.png|题目]]

5. $CPU$内部如果多个部件共享一条总线,则每个部件与总线之间需设置一个常用的器件,$CPU$控制该器件的状态，实现某个部件与总线的连接或断开。该器件是(   )

(A) 触发器  
(B) 多路选择器  
(C) 三态门  
(D) 与非门

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-53-M05_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C（三态门）。一句话理由：三态门具有高电平、低电平和高阻三种输出状态，通过控制端可使部件与总线连接（正常输出）或断开（高阻隔离）。

**解题切入点**：拿到题目先抓住“多个部件共享一条总线”和“连接或断开”这两个关键点。多个部件不能同时向总线发送数据，否则会发生总线冲突，因此每个部件都要能“断开”与总线的连接；能实现“断开”的器件一定具有高阻态，这正是三态门区别于普通逻辑门和多路选择器的核心特征。可以类比算法竞赛中“多个候选答案取最优”时的状态管理：需要有一种“无效/不参与”状态，而不是简单地在两个有效值之间切换。

**推演**：  
1. **总线共享的要求**：$CPU$ 内部的总线是共享传输介质，某一时刻只允许一个部件向总线发送数据，其他部件应处于隔离状态。若两个部件同时输出，会在总线上产生逻辑冲突，严重时可能损坏电路。

2. **器件功能对比**：  
   - 触发器：用于存储一位二进制信息，输出只有 0 或 1，没有“断开”功能。  
   - 多路选择器：用于从多路输入中选择一路输出，它本身可以有高阻输出选项，但题目问的是“每个部件与总线之间”设置的器件，且要求“控制该器件的状态”，实现“连接或断开”，更常用的专用器件是三态门。多路选择器通常用于选择数据通路，而不是直接挂在总线上的隔离器件。  
   - 三态门：输出有三种状态——逻辑 0、逻辑 1 和高阻态（Z）。当控制端有效时，输出等于输入（连接）；当控制端无效时，输出呈高阻态，等效于与总线断开。  
   - 与非门：普通逻辑门，输出只有 0 和 1，没有高阻态。

3. **三态门的工作过程**：设三态门的输入为 $D$，控制端为 $EN$，输出为 $Y$。  
   - 当 $EN=1$ 时，$Y=D$，部件与总线相连；  
   - 当 $EN=0$ 时，$Y$ 呈现高阻态，相当于该部件从总线上断开。  
   多个部件各自的 $EN$ 端由 $CPU$ 控制，同一时刻至多一个 $EN$ 有效，从而保证总线独占。

4. **结论**：该器件为三态门，选 C。

**易错点**：  
- 误选 B（多路选择器）：多路选择器用于“选择”多路输入中的一路，它的输出通常不直接具有高阻态（除非专门设计），而题目强调“连接或断开”，显然需要第三态。  
- 误选 A（触发器）：触发器只能存储状态，无法实现总线的隔离。  
- 误选 D（与非门）：与非门是普通组合逻辑门，输出固定为 0 或 1，不能断开。  
- 混淆概念：高阻态是“断开”的关键，许多同学会忽略这一点，只从“多个部件共享”想到多路选择器，但没有抓住“断开”的本质。

**命题规律**：  
- 考点定位：总线结构、总线仲裁与总线隔离的基本概念，属于计算机组成原理中“总线”章节的基础题，常与总线判优、三态门在总线上的应用结合考查。  
- 常见变式：  
  1. 给出多个部件共享总线的示意图，问哪些器件必须使用三态门；  
  2. 将三态门与集电极开路门对比，考查它们各自的应用场景；  
  3. 结合总线传输周期，问控制端信号的时序要求。  
- 复习建议：理解总线“独占”原则，掌握三态门的高阻态意义，注意与多路选择器的区别。记忆口诀：总线隔离靠三态，高阻断开不冲突。

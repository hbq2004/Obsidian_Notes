# 选择题 第 2 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-57-M02_题目.png|题目]]

2. 按照 $Flynn$ 提出的计算机系统分类方法,多处理机属于（\_\_\_\_）.

(A) $SISD$
(B) $SIMD$
(C) $MISD$
(D) $MIMD$

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-57-M02_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D（$MIMD$）。多处理机由多个处理器组成，每个处理器可独立取指并处理各自的数据，属于多指令流多数据流。

**解题切入点**：拿到题目先锁定“Flynn 分类法”这一考点，再抓住关键词“多处理机”。“多”字直接暗示指令流和数据流都是多个。可以把 Flynn 分类法理解为“CPU 的并行模式”：

- 单指令流单数据流（$SISD$）：传统单核单处理器；
- 单指令流多数据流（$SIMD$）：一条指令同时处理多个数据，如向量机、GPU 的某些运算；
- 多指令流单数据流（$MISD$）：理论上存在，实际很少；
- 多指令流多数据流（$MIMD$）：多个处理器同时执行不同指令，处理不同数据。

多处理机正符合“多个 CPU 同时工作、各自取指、各自处理数据”，因此直接定位到 $MIMD$。

**推演**：

Flynn 分类法根据计算机系统中“指令流”和“数据流”的数量关系，将计算机系统分为四类：

1. $SISD$：单指令流、单数据流。  
   传统的冯·诺依曼计算机属于此类，只有一个控制部件、一个处理器，一条指令处理一个数据。

2. $SIMD$：单指令流、多数据流。  
   一个控制部件向多个处理单元广播同一条指令，各处理单元同时对不同的数据执行该指令。例如：阵列处理机、向量计算机。

3. $MISD$：多指令流、单数据流。  
   多个处理单元对同一个数据流执行不同的指令。这种结构在现实中很少见，主要是一种理论模型。

4. $MIMD$：多指令流、多数据流。  
   多个处理器各自独立执行不同的指令，处理不同的数据。多处理机、多计算机系统都属于 $MIMD$ 类型。

题目中的“多处理机”是指由多个处理器组成的系统，多个处理器既可以并行执行不同的任务，也可以各自处理不同的数据流。因此满足：

- 指令流数量：多个（每个处理器都有自己的指令流）；
- 数据流数量：多个（每个处理器处理各自的数据）。

故多处理机属于 $MIMD$，选项 D 正确。

**易错点**：

- 容易误选 $SIMD$：$SIMD$ 强调“一条指令”同时作用于“多个数据”，典型代表是向量处理器，而多处理机中每个处理器执行的指令可以不同，因此不是 $SIMD$。
- 容易误选 $MISD$：$MISD$ 在考试中很少出现，一般只作为理论分类存在，多处理机显然不是多个指令流处理同一个数据流。
- 混淆“多处理器”与“多核处理器”：在现代语境下，多核处理器也可以视为 $MIMD$，因为每个核心可以独立取指执行不同指令，处理不同数据。

**命题规律**：

- 考点定位：Flynn 分类法是计算机系统结构的基础考点，常以选择题形式出现，考查四种分类的区分。
- 常见变式：给出一类具体系统，如向量处理机、阵列处理机、多处理机、多计算机系统，要求判断其所属类型；或给出 $SIMD$、$MIMD$ 的定义，判断描述正误。
- 复习建议：牢记四类分类的核心区别——“指令流”和“数据流”各有多少个。可以记为：

  $$SISD = 1 \text{指令流} + 1 \text{数据流}$$
  $$SIMD = 1 \text{指令流} + N \text{数据流}$$
  $$MISD = N \text{指令流} + 1 \text{数据流}$$
  $$MIMD = N \text{指令流} + N \text{数据流}$$

  同时记住典型实例：单核机是 $SISD$，向量机/GPU 是 $SIMD$，多处理机是 $MIMD$。了解 $MISD$ 的理论性即可。

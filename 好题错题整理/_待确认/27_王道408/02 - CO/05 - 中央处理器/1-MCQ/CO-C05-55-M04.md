# 选择题 第 4 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-55-M04_题目.png|题目]]

4. 以下关于异常和中断响应的叙述中,错误的是 (  )

(A) 异常事件检测由 $CPU$ 在执行每一条指令的过程中进行.
(B) 中断请求检测由 $CPU$ 在每条指令执行结束、取下条指令之前进行.
(C) $CPU$ 检测到异常事件后所做的处理和检测到中断请求后所做的处理完全相同.
(D) $CPU$ 在中断响应时会关中断、保存断点和程序状态并转到相应的中断服务程序.

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-55-M04_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。异常与中断在来源、检测时机、处理程序入口获取等方面存在差异，CPU 对二者的响应处理并不“完全相同”。

**解题切入点**：本题直接考查“异常”与“中断”两大核心概念的辨析。拿到题目首先要分清：异常是 CPU 内部产生的（如除零、缺页、溢出），中断是外部设备产生的；（也就是要区分“内因”和“外因”）。然后逐一盯住“检测时机”“响应过程”“处理是否相同”这些高频考点。可以类比算法竞赛中的“错误处理”和“外部消息通知”：一个是你自己算到一半发现出错了，一个是别人发消息给你，虽然都要保存现场去处理，但发生后“如何进入处理流程”并不完全一样。

**推演**：

- 选项 A：**正确**。异常是 CPU 在执行指令的过程中自行检测到的，例如除零、地址越界、缺页等，这些事件发生在指令执行阶段，CPU 通过内部逻辑在“执行指令时”发现异常。  
  所以 A 的说法“异常事件检测由 CPU 在执行每一条指令的过程中进行”正确。

- 选项 B：**正确**。外部中断请求由 I/O 设备等外部事件发出，CPU 不会在指令执行中途去查询，而是在每条指令执行结束、取下一条指令之前统一检测是否有中断请求。这个时间点对应指令周期的“中断周期”。  
  所以 B 正确。

- 选项 C：**错误**。虽然异常和中断响应时都要“保存断点、保存程序状态、转向处理程序”，但它们并不完全相同，主要区别有：
  1. **来源不同**：异常由 CPU 内部产生，中断由外部设备产生。
  2. **检测时机不同**：异常在指令执行过程中检测；中断在指令执行结束、取下条指令之前检测。
  3. **处理程序入口的获取方式不同**：异常根据异常类型直接确定处理程序入口；中断需要中断向量或中断类型号来获得中断服务程序入口。
  4. **是否“关中断”不完全相同**：外部中断响应通常需要“关中断”以保证响应过程不被打断；而某些异常（如缺页异常）处理后可能需要重新执行当前指令，且处理过程中往往允许更高优先级的中断打断，因此不能说处理过程完全相同。  
  所以 C 的“完全相同”过于绝对，是错误叙述。

- 选项 D：**正确**。中断响应的核心工作包括：  
  $$ \text{关中断} \rightarrow \text{保存断点} \rightarrow \text{保存程序状态字（PSW）} \rightarrow \text{识别中断源并转入中断服务程序} $$  
  这符合中断响应的标准过程，因此 D 正确。

综上，错误的是 C。

**易错点**：

1. **误以为异常和中断响应过程完全相同**。两者都要保护现场，但响应细节有差异，例如异常的处理入口由异常类型直接决定，中断需要中断向量；异常在指令执行中检测，中断在指令结束后检测。
2. **混淆“异常检测”和“中断请求检测”的时机**。异常是 CPU 执行指令过程中自己发现的；外部中断是 CPU 在指令结束、取下条指令前统一查询的。
3. **忽略“关中断”语境**。外部中断响应需要关中断，但异常处理并非一律要求“关中断”，不能把中断响应的特点直接套用到所有异常上。
4. **对“断点”理解不清晰**。断点是被打断时的下一条指令地址；异常发生时，断点可能是当前指令（需要重新执行）或下一条指令，这也会影响响应后的执行流程。

**命题规律**：

- **考点定位**：本题考查计算机组成原理中“异常和中断”的辨析，属于中断系统的基础考点。常结合指令周期、中断响应过程、中断向量、中断屏蔽等知识点命题。
- **常见变式**：
  - 给出多种事件（如除零、缺页、外部按键、DMA 结束），要求判断属于异常还是中断。
  - 结合指令流水线，考查异常/中断检测时机。
  - 考查“中断响应过程”的先后顺序，如关中断、保存断点、保存 PSW 的次序。
  - 考查异常与中断处理程序入口的获取方式。
- **复习建议**：将“异常”和“中断”做成对比表格，从产生来源、检测时机、响应过程、入口获取、是否关中断、处理程序返回等角度对比记忆；同时结合 8086 中断响应机制或经典 CPU 中 INT 指令等例子，理解“异常/中断”从发生到处理的完整流程。此知识点重在记忆，但需要在对比中理解，避免绝对化说法。

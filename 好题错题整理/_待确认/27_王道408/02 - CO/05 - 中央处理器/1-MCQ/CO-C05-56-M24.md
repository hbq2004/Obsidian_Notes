# 选择题 第 24 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-56-M24_题目.png|题目]]

24.【2016统考真题】在无转发机制的五段基本流水线(取指、译码/读寄存器、运算、访写回寄存器)中,下列指令序列存在数据冒险的指令对是( )

| 指令 | 说明 |
|------|------|
| $I1$: add R1, R2, R3; | $(R2)+(R3)\rightarrow R1$ |
| $I2$: add R5, R2, R4; | $(R2)+(R4)\rightarrow R5$ |
| $I3$: add R4, R5, R3; | $(R5)+(R3)\rightarrow R4$ |
| $I4$: add R5, R2, R6; | $(R2)+(R6)\rightarrow R5$ |

A. $I1$ 和 $I2$
B. $I2$ 和 $I3$
C. $I2$ 和 $I4$
D. $I3$ 和 $I4$

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-56-M24_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。$I_2$ 将结果写入 $R_5$，而 $I_3$ 要读 $R_5$；无转发时，$I_3$ 在译码/读寄存器阶段读到的还不是 $I_2$ 在写回阶段才写入的新值，形成 RAW 数据冒险。

**解题切入点**：  
看到“无转发机制 + 五段基本流水线”，先定位为数据冒险判定。不要直接背选项，先把每条指令的“写寄存器集合”和“读寄存器集合”写出，然后找“前一条指令写、后一条指令读同一寄存器”的边。可以类比做依赖图：若存在从前一条指令的写集合指向后一条指令读集合的边，且读发生在写之前，就是数据冒险。

**推演**：  
五段基本流水线为取指（IF）、译码/读寄存器（ID）、执行（EX）、访存（MEM）、写回寄存器（WB）。本题指令均为 ALU 指令，结果只有在 WB 段才写入寄存器堆；后一条指令在 ID 段读寄存器。因此，基本要检查的是 RAW：$W(\text{前}) \cap R(\text{后}) \neq \varnothing$。

各指令读写集合为：

| 指令 | 写寄存器 $W$ | 读寄存器 $R$ |
|---|---|---|
| $I_1$ | $\{R_1\}$ | $\{R_2,R_3\}$ |
| $I_2$ | $\{R_5\}$ | $\{R_2,R_4\}$ |
| $I_3$ | $\{R_4\}$ | $\{R_5,R_3\}$ |
| $I_4$ | $\{R_5\}$ | $\{R_2,R_6\}$ |

逐对检查：

- $I_1$ 与 $I_2$：  
  $W(I_1)\cap R(I_2)=\varnothing$，无 RAW。

- $I_2$ 与 $I_3$：  
  $$
  W(I_2)\cap R(I_3)=\{R_5\}\ne\varnothing
  $$
  $I_2$ 先写 $R_5$，$I_3$ 后读 $R_5$；若不暂停直接流入，$I_3$ 的 ID 阶段早于 $I_2$ 的 WB 阶段，所以无转发时存在 RAW 数据冒险。

- $I_2$ 与 $I_4$：  
  $W(I_2)\cap W(I_4)=\{R_5\}$，只是 WAW 相关；五段基本流水线按序写回，$I_4$ 不可能在 $I_2$ 之前写 $R_5$，故不构成该环境下的数据冒险。

- $I_3$ 与 $I_4$：  
  $R(I_3)\cap W(I_4)=\{R_5\}$，只是 WAR 相关；$I_3$ 先读 $R_5$，$I_4$ 后写 $R_5$，$I_4$ 不会破坏 $I_3$ 已经完成的读操作，故不构成数据冒险。

因此存在数据冒险的指令对只有 $I_2$ 与 $I_3$。

**易错点**：  
1. 误选 C：$I_2$ 与 $I_4$ 都写 $R_5$，但这是 WAW；按序五段流水线不会发生后一条先写回的情况。  
2. 误选 D：$I_3$ 读 $R_5$，$I_4$ 写 $R_5$，但这是 WAR；$I_3$ 的读发生在前，不会读到 $I_4$ 的新值。  
3. 把同时读同一寄存器（如 $I_1$ 与 $I_2$ 都读 $R_2$）当作冒险；读读不冲突。  
4. 忽略“无转发”：若有转发通路，$I_2$ 的 ALU 结果可以在 EX/MEM 段转发给 $I_3$，冒险可能被消除；无转发时必须停顿或重排指令。

**命题规律**：  
本题是 408 对五段流水线数据冒险的典型考查，核心是 RAW 判断。常见变式有：给出转发通路后求最少停顿周期；将某条指令换成 load 指令，考查 load-use 冒险；或要求通过指令调度消除冒险。复习时应熟练掌握 IF/ID/EX/MEM/WB 各阶段读写时序，养成“先画读写集合、再对拍流水线时空图”的做题习惯。

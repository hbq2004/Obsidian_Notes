# 选择题 第 24 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-56-M24_题目.png|题目]]

24.【2016统考真题】在无转发机制的五段基本流水线 (取指、译码/读寄存器、运算、访写回寄存器) 中，下列指令序列存在数据冒险的指令对是( )

I1: add R1, R2, R3; $(R2)+(R3) \rightarrow R1$  
I2: add R5, R2, R4; $(R2)+R(4) \rightarrow R5$  
I3: add R4, R5, R3; $(R5)+R(3) \rightarrow R4$  
I4: add R5, R2, R6; $(R2)+R(6) \rightarrow R5$

(A) $I1$ 和 $I2$  
(B) $I2$ 和 $I3$  
(C) $I2$ 和 $I4$  
(D) $I3$ 和 $I4$

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-56-M24_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B（$I_2$ 与 $I_3$）。$I_2$ 的目的寄存器是 $R5$，$I_3$ 的源寄存器包含 $R5$；无转发时 $I_3$ 在“译码/读寄存器”阶段读 $R5$ 时，$I_2$ 尚未到“写回”阶段，因此产生 RAW 数据冒险。

**解题切入点**：
先定位考点：五段流水线中的数据冒险判定。可以像算法题中“建依赖边”一样，把每条指令的目的寄存器 $D$ 和源寄存器集合 $S$ 列出来。只有“前一条指令写某个寄存器”且“后一条指令读同一个寄存器”时，才可能形成 RAW 冒险；WAW、WAR 在按序流动的基本五段流水线中不会造成需要停顿的数据冒险。

**推演**：
五段基本流水线为 IF、ID、EX、MEM、WB；寄存器在 ID 阶段读出，在 WB 阶段写回。无转发时，运算结果只能等 WB 写回后才能被后续指令读取。

列出各指令的寄存器使用情况：

| 指令 | 目的寄存器 $D$ | 源寄存器集合 $S$ |
|---|---|---|
| $I_1$ | $R1$ | $\{R2,R3\}$ |
| $I_2$ | $R5$ | $\{R2,R4\}$ |
| $I_3$ | $R4$ | $\{R5,R3\}$ |
| $I_4$ | $R5$ | $\{R2,R6\}$ |

逐项检查：

- $I_1$ 与 $I_2$：$D(I_1)=R1\notin S(I_2)=\{R2,R4\}$，无依赖。
- $I_2$ 与 $I_3$：$D(I_2)=R5\in S(I_3)=\{R5,R3\}$。$I_2$ 写 $R5$ 要到 WB 段才完成，而 $I_3$ 在 ID 段就要读 $R5$，无转发时读到的可能是旧值，因此存在 RAW 数据冒险。
- $I_2$ 与 $I_4$：二者都写 $R5$，但 $I_4$ 不读 $R5$，这是“写后写”关系；在按序五段流水线中不会产生数据冒险。
- $I_3$ 与 $I_4$：$D(I_3)=R4\notin S(I_4)=\{R2,R6\}$；$I_4$ 写 $R5$ 发生在 $I_3$ 读 $R5$ 之后，是 WAR 关系，顺序流水线中不构成数据冒险。

所以存在数据冒险的指令对是 $I_2$ 与 $I_3$，选 B。

**易错点**：
- 看到 $I_2$ 与 $I_4$ 都写 $R5$ 就误选 C，混淆了 RAW 与 WAW；基本五段顺序流水线写回按序完成，WAW 不构成数据冒险。
- 看到 $I_3$ 读 $R5$、$I_4$ 写 $R5$ 就误以为有冒险；这是 WAR，$I_3$ 先读、$I_4$ 后写，顺序流水线中不会发生。
- 忽略“无转发机制”这一条件。若有转发，$I_2 \to I_3$ 的结果可以通过转发通路提前解决；但题设无转发，必须按 WB 写回时刻判断。

**命题规律**：
考点是流水线数据冒险的判定，尤其是无转发条件下 RAW 冒险的识别。常见变式有：Load-use 冒险、有/无转发时计算停顿周期或插入 nop 数、判断转发路径等。复习时应熟练掌握五段流水线各阶段功能、寄存器读写时刻，并养成先列“目的/源寄存器”表，再用流水线时空图验证的习惯。

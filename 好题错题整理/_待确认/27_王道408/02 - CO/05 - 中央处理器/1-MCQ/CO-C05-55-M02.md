# 选择题 第 2 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-55-M02_题目.png|题目]]

2. 指令执行结果出现异常而引起的中断是（ ）
(A) $I/O$ 中断
(B) 机器校验中断
(C) 故障
(D) 外部中断

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-55-M02_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。理由：指令执行结果异常（如溢出、除零）是 CPU 内部与当前指令执行直接相关的异常事件，属于内中断中的“故障”，而非外部设备中断或机器硬件校验中断。

**解题切入点**：拿到题目先判断事件来源——是 CPU 内部执行指令产生，还是 CPU 外部（I/O、时钟等）产生；然后在内中断（异常）中进一步定位为故障、自陷还是终止。像调试程序时：程序自己算错抛异常（内中断/故障），与外部有人敲门（外部中断）不同。

**推演**：
1. 中断按触发来源分为外部中断与内部异常。
   - 外部中断：由 CPU 外部事件引起，如 I/O 设备请求、时钟中断、电源故障等；
   - 内部异常（也称内中断/异常）：由 CPU 内部正在执行的指令引起，与当前指令相关。
2. 题目关键词“指令执行结果出现异常”说明异常发生在某条指令执行的过程中（或执行结束检查结果时），是 CPU 内部根据指令操作结果检测到的异常状态，例如算术溢出、除数为零、结果校验错等。
3. 在异常分类中：
   - 故障（fault）：在指令执行过程中检测到异常，如缺页、除零、溢出、非法指令等，处理后一般回到当前指令重新执行（若可恢复）；
   - 自陷（trap）：通常由程序主动执行陷入指令触发；
   - 终止（abort）：严重硬件错误或系统错误，无法恢复。
   
   指令执行结果异常属于故障的一种。
4. 选项辨析：
   - A I/O 中断：外部设备请求，属于外部中断，与指令执行结果无关；
   - B 机器校验中断：由硬件故障（如存储器奇偶校验错、总线校验错）引起，属于硬件异常，不是指令结果异常；
   - D 外部中断：包括 I/O 中断、时钟中断等，为外部事件，不符合题意；
   - C 故障：正确定位。

因此答案为 C。

**易错点**：
- 误选 B：把“机器校验中断”当成任何异常。机器校验中断对应硬件本身故障，不是程序执行结果异常。
- 误选 D/A：把“中断”片面理解为外部中断，忽略了 CPU 内部异常。题目明确“指令执行结果”异常，属于内中断。
- 概念混淆：异常中“故障”和“自陷”要区分——前者是被动检测到的异常，后者是主动触发的系统调用/陷入指令。
- 规避方法：遇到中断分类题，先画“外部中断 vs 内部异常（故障/自陷/终止）”的分类图，再看题目事件是主动还是被动、内部还是外部。

**命题规律**：
- 考点：中断/异常分类，尤其是内部异常中故障、自陷、终止的区别。
- 常见变式：给出“除零”“缺页”“非法指令”“I/O 完成”“时钟中断”“电源故障”等事件，判断中断类型；也可能结合操作系统问“异常处理完成后是否回到当前指令重新执行”。
- 复习建议：熟记异常分类表：故障可恢复回到当前指令，自陷进入下一条指令，终止不恢复；外部中断与异常的区别；可屏蔽/不可屏蔽中断的代表。408 中常以小分选择题考查，理解后记忆即可。

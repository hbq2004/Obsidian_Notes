# 选择题 第 2 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-53-M02_题目.png|题目]]

2. 下列有关数据通路的叙述中,错误的是 ( )  
(A) 数据通路由若干组合逻辑元件和时序逻辑元件连接而成  
(B) 数据通路的功能由控制部件送出的控制信号决定  
(C) $ALU$属于操作元件,包含在数据通路中  
(D) 通用寄存器属于状态元件,但不包含在数据通路中

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-53-M02_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。通用寄存器是典型的状态元件，并且包含在数据通路中；D 的后半句“不包含在数据通路中”错误。

**解题切入点**：拿到题先把 CPU 划分为“数据通路 + 控制部件”两大块。数据通路负责数据的存储、传送与运算，控制部件负责产生控制信号。凡是指令执行中承载数据流动和运算的部件，如 $\mathrm{ALU}$、寄存器、多路选择器、总线等，都属于数据通路；所以看到“寄存器不包含在数据通路中”应立即判断其可疑。

**推演**：

1. 选项 A：数据通路本身就可以看作由组合逻辑元件和时序逻辑元件连接而成的网络。组合逻辑元件如 $\mathrm{ALU}$、加法器、多路选择器等；时序逻辑元件如通用寄存器、程序计数器 $PC$ 等。A 说法正确。

2. 选项 B：数据通路只是“执行机构”，它执行什么操作、数据从哪里来、结果送到哪里去，需要由控制部件送出的控制信号决定，例如 $\mathrm{RegWrite}$、$\mathrm{ALUSrc}$、$\mathrm{ALUop}$ 等。因此 B 说法正确。

3. 选项 C：$\mathrm{ALU}$ 是典型的操作元件，完成算术和逻辑运算，是数据通路的核心组成部件。C 说法正确。

4. 选项 D：通用寄存器属于状态元件，因为它需要在时钟控制下保存数据；但通用寄存器（寄存器堆）同样包含在数据通路中。指令执行时要从寄存器堆读源操作数，运算结果也要写回寄存器堆。因此 D 说“不包含在数据通路中”是错误的。

所以错误的是 D。

**易错点**：

- 误把“状态元件”理解为一定在控制部件中。状态元件只是说明它的输出不仅取决于当前输入，还取决于保存的历史状态，和“是否属于数据通路”没有矛盾。
- 误以为数据通路只包含组合逻辑。实际上数据通路必须包含寄存器等状态元件，否则无法保存中间结果和指令执行状态。
- 忽略控制信号的作用。数据通路本身不会自动决定执行哪个操作，必须由控制部件送出的控制信号来“指挥”。
- 没有发现 A 和 D 的矛盾：A 已说明数据通路由组合逻辑元件和时序逻辑元件连接而成，而通用寄存器是时序逻辑/状态元件，当然应包含在数据通路中。

**命题规律**：本题属于 CPU 组成中“数据通路”的基本概念题，考查数据通路的组成部件以及它与控制部件的关系。常见变式包括：判断 $\mathrm{ALU}$、寄存器堆、多路选择器、$PC$ 等部件是否属于数据通路；区分操作元件和状态元件；结合单周期或多周期数据通路图判断控制信号的作用。复习时应熟记经典单周期数据通路图，并用一条指令（如 $lw$、R 型指令）沿数据通路走一遍，这样就能自然记住各部件的归属与作用。

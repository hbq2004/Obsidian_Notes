# 选择题 第 7 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-55-M07_题目.png|题目]]

7. 下列选项中，不属于外部中断事件的是 ( )

(A) 采样定时时间到
(B) 无效操作码
(C) 打印机缺纸
(D) 键盘缓冲满

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-55-M07_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。无效操作码属于 CPU 内部异常（故障），不是外部中断事件；外部中断来自 CPU 外部，如定时器、外设请求等。

**解题切入点**：先明确“外部中断”的定义——它是由 CPU 外部设备或事件引起的中断请求，与 CPU 内部执行指令时产生的“异常”（如除零、无效操作码、缺页）严格区分。做这类题可以类比竞赛中的“事件驱动”：外部中断就像外部信号触发回调，而内部异常是程序自身执行不下去触发的错误处理。

**推演**：
- 外部中断（中断）通常包括：
  - 定时器/计数器到时，如采样定时时间到（A）；
  - I/O 设备请求，如打印机缺纸（C）、键盘缓冲满（D）。
- 内部异常（异常）是 CPU 执行指令过程中检测到的异常情况，比如：
  - 无效操作码（B）：指令译码时发现非法操作码，属于故障（fault）；
  - 除零、地址越界、缺页等。
- 因此，选项 A、C、D 都是 CPU 外部事件引起的中断，B 是内部异常，不属于外部中断。

**易错点**：
- 误认为“键盘缓冲满”是内部状态，实际上键盘缓冲属于 I/O 设备，缓冲满信号由外设控制器向 CPU 发出中断请求，是典型的外部中断。
- 混淆“定时器”与“时钟”：定时器中断多由可编程间隔定时器产生，属于外部中断；而 CPU 内部的时钟周期不属于中断事件。
- 将“无效操作码”误归为中断，因为有些教材将“异常”也统称“中断”，但本题明确问“外部中断”，需要区分内外。

**命题规律**：
- 考点为“中断与异常的分类”，是 408 常考基础概念题，常与“中断向量”“响应优先级”“现场保护”结合。
- 变式：给出事件列表问哪些是内部异常、哪些是外部中断；或结合指令执行过程判断异常类型（故障、陷阱、终止）。
- 复习建议：牢记“外部中断来自 CPU 外部”“内部异常来自 CPU 内部”，并整理典型例子：外部中断——定时器、键盘、打印机、磁盘等；内部异常——除零、无效操作码、缺页、溢出等。

# 选择题 第 16 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-54-M16_题目.png|题目]]

16. 下列说法中,正确的是( )
I. 微程序控制方式和硬布线控制方式相比较,前者可以使指令的执行速度更快
II. 若采用微程序控制方式,则可用 $\mu PC$ 取代 $PC$
III. 控制存储器可以用 ROM 元件实现
IV. 指令周期也称 CPU 时钟周期
(A) I、III
(B) II、III
(C) 只有 III
(D) I、III、IV

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-54-M16_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C（只有 III 正确）。  
理由：微程序控制比硬布线控制速度更慢；$\mu PC$ 不能取代 $PC$；控制存储器可以用 ROM 实现；指令周期不是 CPU 时钟周期。

**解题切入点**：拿到题目先定位到“中央处理器—控制单元”的概念辨析题。四个选项分别考查控制器实现方式、寄存器作用、控制存储器、时间单位。这类题像算法竞赛中“概念判断题”，先抓住每个说法的核心关键词，再逐一对照教材定义，不要被“好像见过”的感觉带偏。

**推演**：

I. 微程序控制方式和硬布线控制方式相比较，前者可以使指令的执行速度更快。  
错误。  
硬布线控制方式用组合逻辑电路直接产生控制信号，信号产生延迟小，速度更快。微程序控制方式是把控制信号编成微指令存放在控制存储器中，执行指令时需要先取微指令、再译码产生控制信号，相当于多了一层“查表”开销，因此速度更慢。

II. 若采用微程序控制方式，则可用 $\mu PC$ 取代 $PC$。  
错误。  
$PC$ 是程序计数器，用来给出主存中下一条机器指令的地址；$\mu PC$ 是微程序计数器，用来给出控制存储器中下一条微指令的地址。二者一个面向主存中的指令，一个面向控制存储器中的微指令，作用对象不同，不能相互取代。

III. 控制存储器可以用 ROM 元件实现。  
正确。  
控制存储器用来存放微程序，微程序在机器设计完成后一般固定不变，因此可以用 ROM 实现。即使某些 CPU 支持用 RAM 实现可写控制存储器（WCS），也不影响“可以用 ROM 实现”这一说法的正确性。

IV. 指令周期也称 CPU 时钟周期。  
错误。  
指令周期是指取出并执行一条指令所需的总时间。CPU 时钟周期是时钟信号重复一次的时间，通常一个指令周期包含若干个机器周期，一个机器周期又包含若干个时钟周期。指令周期和 CPU 时钟周期不是同一个概念。

综上，只有 III 正确，故选 C。

**易错点**：

- 误以为微程序控制“更灵活、更高级”所以速度更快，实际上硬布线控制速度更快，微程序控制灵活但慢。
- 混淆 $PC$ 和 $\mu PC$：$PC$ 指向主存中的指令，$\mu PC$ 指向控制存储器中的微指令。
- 看到控制存储器也可以用 RAM 实现，就认为“用 ROM 实现”是错的，但题目说的是“可以用”，不是“只能用”。
- 把指令周期、机器周期、CPU 时钟周期混为一谈，需要注意三者的层次关系：一个指令周期包含多个机器周期，一个机器周期包含多个时钟周期。

**命题规律**：本题考查控制单元的基础概念，属于 408 选择题中的常考概念题。常见变式有：比较微程序控制与硬布线控制的速度、成本、灵活性；辨析 $PC$、$IR$、$\mu PC$、$\mu IR$ 的功能；判断控制存储器是否可用 ROM 或 RAM 实现；区分指令周期、机器周期和时钟周期。复习时建议用表格对比记忆，并抓住“微程序控制是存储逻辑，硬布线控制是组合逻辑，前者灵活但慢”这条主线。

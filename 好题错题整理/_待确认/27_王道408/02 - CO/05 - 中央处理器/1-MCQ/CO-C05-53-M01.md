# 选择题 第 1 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-53-M01_题目.png|题目]]

1. 下列不属于CPU数据通路结构的是 ( )
A. 单总线结构
B. 多总线结构
C. 部件内总线结构
D. 专用数据通路结构

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-53-M01_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。一句话理由：CPU 数据通路的常见结构分为专用数据通路结构和总线结构（含单总线、多总线），并不包括“部件内总线结构”。

**解题切入点**：先明确数据通路的定义——它是 CPU 内部各部件之间传送数据的路径。分类时抓住“是否共享传输介质”这一主线：专用数据通路是每个部件间单独连线；总线数据通路则是通过共享总线连接各部件，再按总线数量分为单总线、多总线。题目中“部件内总线结构”指的是某个部件内部（如 ALU 内部）使用的总线，不属于 CPU 级数据通路的分类。

**推演**：
数据通路是 CPU 的重要组成部分，负责在寄存器、ALU、存储器等部件之间传输数据。其结构可分为两大类：

1. 专用数据通路结构：各个部件之间直接通过独立的线路连接，数据传送速度快，但连线复杂，硬件成本高，常用于高性能 CPU 内部。
2. 总线数据通路结构：通过一组共享的总线连接各部件，按总线数量又可细分为：
   - 单总线结构：所有部件共享一条总线，结构简单，但同一时刻只能有一个部件占用总线，传输效率较低。
   - 多总线结构：设置多条总线（如双总线、三总线），允许多个数据传送并行进行，提升了吞吐率。

而“部件内总线结构”不是数据通路结构的分类标准，它通常指某个功能部件（如 ALU、寄存器堆）内部连接其子模块的总线，属于部件内部实现细节，不在 CPU 数据通路结构分类的讨论范围内。

因此，选项 A、B、D 都属于 CPU 数据通路结构，只有 C 不属于。

**易错点**：
- 误把“部件内总线”当作“多总线”的一部分。注意“多总线结构”指 CPU 数据通路中多条总线用于连接各部件；而“部件内总线”是部件内部的连线，不是数据通路总体结构的分类。
- 忽略“专用数据通路结构”也是标准分类，可能误选 D。应牢记数据通路的两大类：专用数据通路结构与总线数据通路结构。
- 题目中文词语易混淆，要定位到课本中数据通路的分类表述，不要凭直觉猜测。

**命题规律**：
408 中数据通路结构属于“中央处理器”章节的基础考点，常以选择题形式直接考查分类，也可能结合“总线周期”“数据传送效率”等知识点考查。常见变式有：给出某种结构特点选择对应类型，或比较单总线与多总线的性能差异。复习时应熟记专用数据通路与总线结构的优缺点，并理解单总线、多总线对指令执行效率和冲突处理的影响；也可结合王道/唐朔飞教材中的数据通路框图进行对比记忆。

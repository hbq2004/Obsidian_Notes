# 选择题 第 14 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-51-M14_题目.png|题目]]

14. $CPU$ 中的通用寄存器, ( )
A. 只能存放数据,不能存放地址
B. 可以存放数据和地址
C. 既不能存放数据,又不能存放地址
D. 可以存放数据和地址，还可以替代指令寄存器

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-51-M14_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。通用寄存器既可以存放数据，也可以存放地址，但不能替代指令寄存器。

**解题切入点**：这是一道基本概念题，考察通用寄存器的功能定位。拿到题目先回想“通用”二字的含义：通用寄存器不预先固定用途，既可以存操作数，也可以存地址，但指令寄存器（IR）是 CPU 中专门存放当前指令的特殊寄存器，具有不可替代性。

**推演**：

1. 通用寄存器（General Purpose Register, GPR）是 CPU 内部的一组高速存储单元，通常由程序直接编址访问。

2. “通用”的含义是：它的功能不单一，既可以存放参与运算的数据（如操作数、中间结果），也可以存放内存地址（如基址、变址、栈顶指针等）。例如：
   - 存放数据：加法指令的源操作数、目的操作数；
   - 存放地址：变址寻址中用于存放偏移地址的寄存器、堆栈指针等。

3. 因此，选项 A “只能存放数据，不能存放地址”错误；选项 C “既不能存放数据，又不能存放地址”显然错误。

4. 选项 D 后半句“还可以替代指令寄存器”错误。指令寄存器（IR）是控制器的组成部分，用来存放当前正在执行的指令，其内容来自内存取指阶段，不由程序员通过通用寄存器改写。通用寄存器位于执行部件中，归程序员可见，二者功能不同，不能替代。

5. 综上，正确选项为 B：通用寄存器可以存放数据和地址。

**易错点**：

- 误选 A：只记住了寄存器存数据，忽略了地址也属于“数据”的一种，且很多寻址方式需要寄存器存地址。
- 误选 D：虽然前半句正确，但后半句“替代指令寄存器”是常见干扰。指令寄存器是 CPU 内部不可编程访问的寄存器，通用寄存器不能替代它。
- 混淆“通用寄存器”与“专用寄存器”：如程序计数器 PC、指令寄存器 IR、存储器地址寄存器 MAR 等都有专门用途，不属于通用寄存器。

**命题规律**：本题属于计算机组成原理中“CPU 内部寄存器”的基础考点，常以选择题形式出现。变式可能包括：
- 问“下列哪个寄存器不属于通用寄存器”（如 IR、PC、MAR、MDR）；
- 问“通用寄存器在指令中主要用于什么”（存放源操作数、目的操作数、地址等）；
- 结合指令寻址方式考查寄存器的作用。

复习建议：熟记 CPU 中各类寄存器的名称、功能、是否对程序员可见，注意区分通用寄存器与专用寄存器，尤其是 IR、PC、MAR、MDR 这些不可被程序员随意改写的寄存器。

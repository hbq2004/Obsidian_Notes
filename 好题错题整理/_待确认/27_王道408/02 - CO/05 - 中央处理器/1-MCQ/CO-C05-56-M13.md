# 选择题 第 13 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-56-M13_题目.png|题目]]

13. 下列指令序列中,指令 $I1$ 和 $I3$、$I2$ 和 $I3$ 之间发生数据相关。假定采用“取指、译码/取数、执行、访存、写回”五段流水线方式,那么在采用转发技术时,需要在指令 $I3$ 之前加入( )条空操作指令才能使这段程序不发生数据冒险。

```asm
I1: add r1, r0, 1    # (r1) ← (r0) + 1
I2: add r3, 12(r2)   # (r3) ← M[(r2) + 12]
I3: add r5, r3, r1   # (r5) ← (r3) + (r1)
```

A. 3
B. 2
C. 0
D. 1

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-56-M13_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。$I_1$ 与 $I_3$ 的 $r1$ 相关可被转发解决；$I_2$ 与 $I_3$ 是“访存后紧接使用”的 load-use 相关，即使采用转发技术，也需在 $I_3$ 前插入 1 条空操作。

**解题切入点**：先看两个数据相关的“结果在哪一段产生”。$I_1$ 写 $r1$ 是普通 ALU 结果，在执行段末就可转发；$I_2$ 写 $r3$ 需要访存，结果到访存段末才可用。所以瓶颈是 $I_2 \to I_3$ 的 load-use 相关，而不是 $I_1 \to I_3$。

**推演**：五段分别为 IF（取指）、ID（译码/取数）、EX（执行）、MEM（访存）、WB（写回）。若不插入空操作，三条指令的流动为：

| 周期 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|
| $I_1$ | IF | ID | EX | MEM | WB |  |  |
| $I_2$ |  | IF | ID | EX | MEM | WB |  |
| $I_3$ |  |  | IF | ID | EX | MEM | WB |

不插空操作时，$I_3$ 的 EX 在周期 5，$I_2$ 的 MEM 也在周期 5。$I_2$ 的 $r3$ 要到周期 5 结束时才从存储器读出并进入 MEM/WB 流水寄存器，最早周期 6 开始时才能转发到 EX 段。因此 $I_3$ 在周期 5 执行时拿不到 $r3$，需要把 $I_3$ 推迟 1 拍。

插入 1 条 NOP 后：

| 周期 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| $I_1$ | IF | ID | EX | MEM | WB |  |  |  |
| $I_2$ |  | IF | ID | EX | MEM | WB |  |  |
| NOP |  |  | IF | ID | EX | MEM | WB |  |
| $I_3$ |  |  |  | IF | ID | EX | MEM | WB |

此时 $I_3$ 的 EX 在周期 6，$I_2$ 的访存结果已可经 MEM/WB 转发给 $I_3$ 的 ALU 输入。设插入 $n$ 条空操作，则 $I_3$ 的 EX 在周期 $5+n$，要求：

$$
5+n \ge 6 \Rightarrow n \ge 1
$$

而 $I_1$ 的 $r1$ 可以通过 EX/MEM 或 MEM/WB 转发给 $I_3$，对 $n$ 没有额外限制，所以最少插入 1 条。

**易错点**：

- 误以为转发能消除所有数据冒险。转发能消除“结果已产生但还没写回”的情况，但 load-use 中 $I_3$ 要用 $r3$ 时，$I_2$ 的访存结果还没产生。
- 误把 $I_2$ 当成普通 ALU 指令。$I_2$ 需要访存读入 $r3$，结果比普通 ALU 指令晚一个访存段。
- 误把两个相关所需空操作相加。$I_1 \to I_3$ 不需要空操作，$I_2 \to I_3$ 需要 1 条，插入 1 条空操作可同时满足两者。
- 空操作应插在 $I_2$ 与 $I_3$ 之间；插在其他位置不能消除 load-use 冒险。

**命题规律**：408 常考“普通数据相关”与“load-use 数据相关”的区别。常见变式是把 $I_2$ 改成普通 ALU 指令，此时转发可完全消除冒险；或调整指令间隔，判断是否需要插入 NOP。复习时应掌握五段流水线的周期图，并记住结论：load-use 即使有转发，也至少要阻塞 1 拍。

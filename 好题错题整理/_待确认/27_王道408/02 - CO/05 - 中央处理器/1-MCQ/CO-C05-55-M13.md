# 选择题 第 13 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-55-M13_题目.png|题目]]

13.【2021 统考真题】异常事件在当前指令执行过程中进行检测,中断请求则在当前指令执行后进行检测。下列事件中，相应处理程序执行后，必须回到当前指令重新执行的是 ( )
A. 系统调用
B. 页缺失
C. $DMA$ 传送结束
D. 打印机缺纸

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-55-M13_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。页缺失（缺页）属于异常中的“故障（fault）”，其处理程序执行成功后必须回到当前指令重新执行，因为当前指令尚未完成。

**解题切入点**：先判断题干中的分类：异常是在当前指令执行过程中检测到的，中断请求是在当前指令执行后检测到的。然后再区分异常内部的不同类型，尤其是“自陷（trap）”和“故障（fault）”。可以类比做题经验：系统调用像主动调用一个函数，处理完继续执行下一条；缺页像是当前操作没做完，先补齐资源再回头重试当前操作；DMA 结束、打印机缺纸则像外部通知，处理完继续往下走。

**推演**：

对于外部中断，如选项 C、D，CPU 在当前指令执行完之后才响应中断，此时当前指令已经执行完毕。中断处理完成后返回断点，即下一条指令地址，而不是重新执行当前指令。

对于异常，需要进一步区分：

- 自陷（trap）：由特殊指令主动触发，例如“系统调用”。执行完该指令后进入处理程序，返回地址通常是下一条指令，因此不会重新执行当前指令。
- 故障（fault）：指令在执行过程中发现问题，例如“页缺失”。此时指令并未成功完成，CPU 需要回到当前指令重新执行。处理成功后，返回地址是当前指令地址：
  $$PC \leftarrow \text{当前指令地址（发生缺页的指令地址）}$$

具体到各选项：

A 系统调用：属于自陷，处理完后返回下一条指令。

B 页缺失：属于可恢复故障，处理程序装入所缺页面后，必须重新执行当前指令，因为当前指令的访存操作没有完成。

C DMA 传送结束：属于外设中断请求，在当前指令执行结束后检测，处理完成后返回下一条指令。

D 打印机缺纸：属于外设中断，处理完成后不重新执行当前指令。

因此只有 B 符合题意。

**易错点**：

1. 误以为所有异常处理完后都要回到当前指令重新执行。实际上“系统调用”是自陷，处理完后返回下一条指令。
2. 把“页缺失”当成普通中断。缺页是 CPU 访问内存时发现所在页不在内存，当前指令无法完成，必须重新执行。
3. 把 DMA 结束、打印机缺纸等外设事件误归入异常。它们属于中断，在指令执行结束后检测，不会回退重新执行当前指令。
4. 答题时要抓住“指令是否完成”这一关键：指令未完成则重新执行；指令已完成则返回下一条。

**命题规律**：本题考查异常与中断的区别，以及异常内部“故障”“自陷”的返回行为。常见变式包括：给出多个事件，判断哪些属于异常、哪些属于中断；或考查缺页处理完成后 PC 应指向哪里；也可能结合流水线、中断隐指令、操作系统缺页处理综合命题。复习时应重点区分：

- 中断：外部异步事件，当前指令执行完后响应，返回下一条指令；
- 异常中的故障：当前指令执行过程中产生，返回当前指令重新执行；
- 异常中的自陷：由指令主动触发，返回下一条指令。

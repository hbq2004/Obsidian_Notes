# 选择题 第 20 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-56-M20_题目.png|题目]]

20.【2010统考真题】下列不会引起指令流水线阻塞的是 (  )

(A) 数据旁路
(B) 数据相关
(C) 条件转移
(D) 资源冲突

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-56-M20_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A。数据旁路（定向/转发）是用于消除数据相关引起阻塞的技术手段，本身不会引起指令流水线阻塞；引起阻塞的是数据相关、条件转移（控制相关）和资源冲突。

**解题切入点**：拿到题目先明确“阻塞”在流水线中对应什么——只要有冒险（hazard）就可能让流水线停下来等待。流水线冒险分为结构冒险（资源冲突）、数据冒险（数据相关）、控制冒险（条件转移等）。本题问“不会引起阻塞”，也就是要找“不是冒险，而是解决冒险的技术”。数据旁路恰恰是解决数据冒险的硬件优化，不是冒险源。可以类比：数据相关是“前面车没走，后面车堵住”，数据旁路是“在旁边开一条便道绕过去”，便道本身不会造成堵车。

**推演**：

1. 流水线阻塞的本质是：某条指令需要的结果或资源在当前阶段尚不可用，流水线被迫暂停（插入气泡）或丢弃已取指令。

2. 选项中各概念分类如下：

   - 资源冲突（结构相关）：多条指令在同一时钟周期争用同一硬件部件。例如 Load 指令在 MEM 阶段访存，与下一条指令 IF 阶段取指同时争用存储器，若不采取分离指令/数据 Cache 或暂停机制，就会阻塞。因此资源冲突会引起阻塞。
   - 数据相关：例如
     $$
     \begin{aligned}
     \text{ADD } &R1, R2, R3\\
     \text{SUB } &R4, R1, R5
     \end{aligned}
     $$
     SUB 需要 ADD 的结果 $R1$，但 ADD 要经过 EX/MEM/WB 多个阶段才写回，SUB 的 ID 阶段若读取 $R1$ 则得到旧值，必须等待，造成阻塞。所以数据相关会引起阻塞。
   - 条件转移：执行分支指令时，必须等条件码生成和目标地址计算完成后，才能确定下一条指令从哪里取，流水线可能被清空或停顿，属于控制相关，会引起阻塞。即使使用分支预测，预测错误时仍要冲刷流水线，预测机制本身是对控制相关的优化，而“条件转移”这一事件本身是冒险来源。
   - 数据旁路（forwarding/bypassing）：其思想是在 ALU 计算出结果后，不等到写回寄存器，而是直接通过旁路网络将这个结果送到后续指令的 ALU 输入端。它针对“数据相关”发生，可以在很多情况下消除或减少数据冒险带来的停顿。旁路只是增加硬件通路和多路选择器，并不会使流水线等待，因此不会引入阻塞。

3. 结论：资源冲突、数据相关、条件转移都可能引起流水线阻塞；数据旁路是解决阻塞的技术，不是阻塞原因。故选 A。

**易错点**：

- 把“数据相关”错选为答案，因为看到“数据旁路”和“数据相关”都含“数据”，误以为旁路也是相关的一种。要区分“冒险”与“解决冒险的手段”。
- 误认为“条件转移”不一定会阻塞，因为有分支预测。但分支预测只是降低控制冒险影响，条件转移本身是控制相关的来源，在预测失败时仍会阻塞/冲刷。
- 误认为“资源冲突”不是阻塞，因为现代 CPU 有多个部件。但题目默认基本五段流水线，若多条指令同时访问同一资源，必须阻塞。
- 忽略“不会引起”中的“不会”，把引起阻塞的直接原因和优化方法混在一起。审题时要圈出“不会”和“引起”。

**命题规律**：

- 考点：指令流水线的冒险与处理，属于计算机组成原理中流水线章节的基础题，出现在选择题中，常与“结构相关、数据相关、控制相关”三类冒险及对应解决方案结合考查。
- 常见变式：给出具体指令序列，问哪些相关会产生阻塞；或者问“下列哪种技术可以减少数据冒险造成的停顿”；或者将数据旁路与 Load-use 冒险结合，问何时仍需暂停一拍。
- 复习建议：熟记三类冒险的定义、产生阶段和典型解决手段：
  - 资源冲突：资源重复配置（分离 Cache、多端口寄存器堆）；
  - 数据相关：数据旁路（转发）、编译器调度、插入气泡；
  - 控制相关：分支预测、延迟分支、提前计算分支条件。
  同时理解旁路不能解决所有数据冒险（如 Load-use 在五段流水线中仍可能需停顿一拍），这是加深理解的关键。

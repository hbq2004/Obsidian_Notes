# 选择题 第 13 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-53-M13_题目.png|题目]]

13. $CPU$ 的读/写控制信号的作用是 ( )
(A) 决定数据总线上的数据流方向
(B) 控制存储器操作的读/写类型
(C) 控制流入、流出存储器信息的方向
(D) 以上都是

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-53-M13_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。CPU 的读/写控制信号既决定了数据总线上的数据流方向，又标明当前存储器操作是读还是写，因此 A、B、C 均正确。

**解题切入点**：  
看到“读/写控制信号”要立刻联想到“数据总线是一条双向车道，读/写信号就是车道方向指示器”。本题是概念辨析题，不要急着选看似最直接的 B；应逐项判断 A、B、C 是否分别从不同角度描述了同一个控制作用。

**推演**：  
CPU 通过控制总线向存储器发送读/写控制信号，常见形式为 $\overline{RD}$、$\overline{WR}$，或单根 $R/W$ 信号。

读操作时：
- CPU 先给出地址；
- CPU 发出“读”控制信号；
- 存储器把该地址对应单元的数据送上数据总线；
- 数据由存储器流向 CPU。

写操作时：
- CPU 先给出地址，并把数据放到数据总线上；
- CPU 发出“写”控制信号；
- 存储器把数据总线上的数据写入指定单元；
- 数据由 CPU 流向存储器。

因此可写成：

$$
\text{读：存储器} \xrightarrow{\text{数据总线}} \text{CPU};\qquad
\text{写：CPU} \xrightarrow{\text{数据总线}} \text{存储器}
$$

由此逐项判断：

- A 正确：读/写控制信号决定数据总线上数据流的方向；读时数据由存储器到 CPU，写时数据由 CPU 到存储器。  
- B 正确：读/写控制信号明确区分当前存储器操作是“读”还是“写”。  
- C 正确：从存储器角度看，读操作是信息流出存储器，写操作是信息流入存储器。  

所以 A、B、C 均正确，答案为 D。

**易错点**：  
1. 误选 B：只注意到“读/写类型”这一个直接功能，忽略了读/写信号同样决定数据流方向。  
2. 误选 A：只关注数据总线方向，忽略了它同时也是存储器操作类型的控制信号。  
3. 看到“以上都是”就怀疑是陷阱：本题中 A、B、C 不是互斥关系，而是同一控制信号的不同侧面，D 反而是标准答案。  
4. 混淆“地址总线”和“数据总线”：地址总线由 CPU 单向输出，数据总线是双向的，其方向由读/写控制信号控制。

**命题规律**：  
本题属于“存储系统/总线”的基础概念题，常与总线分类、CPU 与主存之间的数据传送方向结合考查。常见变式有：“数据总线是单向还是双向？”、“CPU 进行读操作时数据由谁提供？”、“读/写控制信号属于哪类总线？”等。复习时应把地址总线、数据总线、控制总线的方向和功能对比记忆，并理解一次完整读/写周期中 CPU、存储器和数据总线三者之间的关系。

# 选择题 第 24 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-54-M24_题目.png|题目]]

24.【2017统考真题】下列关于主存储器 ($MM$) 和控制存储器 ($CS$) 的叙述,错误的是 ( )

(A) $MM$ 在 $CPU$ 外, $CS$ 在 $CPU$ 内  
(B) $MM$ 按地址访问, $CS$ 按内容访问  
(C) $MM$ 存储指令和数据, $CS$ 存储微指令  
(D) $MM$ 用 $RAM$ 和 $ROM$ 实现, $CS$ 用 $ROM$ 实现

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-54-M24_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。控制存储器按地址访问，而非按内容访问。

**解题切入点**：抓住主存储器与控制器存储器的本质区别。主存是 CPU 外部的存储结构，存放指令和数据，按地址随机存取；控制存储器是 CPU 内部微程序控制器的一部分，存放微指令，同样按地址寻址（通过微地址寄存器），而不是按内容访问。常见混淆是将控存误认为按内容访问（类似相联存储器），但实际控存是 ROM，使用地址译码。

**推演**：  
- 选项 A：主存储器（MM）通过总线连接到 CPU，位于 CPU 外部；控制存储器（CS）集成在 CPU 内部，用于存放微程序。该叙述正确。  
- 选项 B：主存储器按地址访问（随机存取）；控制存储器也是按地址访问（微程序顺序执行，由微地址寄存器给出地址）。控制存储器并不按内容访问，因此该叙述错误。  
- 选项 C：主存储器存储指令和数据（程序代码与数据）；控制存储器存储微指令（构成微程序）。该叙述正确。  
- 选项 D：主存储器通常由 RAM 和 ROM 共同实现（如 RAM 存放用户程序，ROM 存放系统程序）；控制存储器一般用 ROM 实现（微程序固化，但也可用可写控存，但通常为 ROM）。该叙述正确。  
综上，选项 B 为错误叙述。

**易错点**：  
1. 误认为控制存储器按内容访问，但实际控存是地址译码的 ROM，按地址读取微指令。  
2. 混淆“按内容访问”与“按地址访问”，前者是相联存储器（CAM）的特征，控存并不具备。  
3. 对控存的实现材料（ROM）理解片面，忽略现代 CPU 可能使用可写控存（如 EEPROM 或 SRAM+后备），但访问方式仍是地址寻址。

**命题规律**：  
- 考点：主存与控存的基本概念对比，包括位置、存储内容、访问方式和实现材料。  
- 常见变式：给出多句叙述判断正误，如“控存可写”“控存按地址访问”等结合微程序控制器原理。  
- 复习建议：深入理解微程序控制器中控存的工作方式，记住主存和控存都是按地址访问，但主存既存指令又存数据，控存只存微指令；同时注意“按内容访问”是相联存储器的特性。

# 选择题 第 2 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-51-M02_题目.png|题目]]

2.通用寄存器是(　)

A. 可存放指令的寄存器

B. 可存放程序状态字的寄存器

C. 本身具有计数逻辑与移位逻辑的寄存器

D. 可编程指定多种功能的寄存器

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-51-M02_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。通用寄存器是可编程指定多种功能的寄存器，可由程序员灵活用作操作数、地址、中间结果等；A、B、C分别对应指令寄存器、程序状态字寄存器、移位寄存器/计数器等专用部件。

**解题切入点**：先明确“通用”二字是相对“专用”而言的。题目考的是寄存器分类的基本概念，属于送分题。拿到题先逐个选项对号入座：指令→IR，程序状态字→PSW，计数/移位→专用计数/移位电路，剩下“可编程多种功能”自然是通用寄存器。像做选择题时先排除明显描述专用硬件的选项。

**推演**：

- **A 项**：存放指令的寄存器是指令寄存器（Instruction Register, IR），在取指阶段从内存取出指令后暂存在 IR 中，供控制器译码使用。通用寄存器不专门存放指令，故 A 错。
- **B 项**：存放程序状态字的寄存器是程序状态字寄存器（Program Status Word, PSW），用于保存条件码、中断标志、CPU 状态等，是专用寄存器，故 B 错。
- **C 项**：本身具有计数逻辑与移位逻辑的寄存器通常指计数器或移位寄存器。例如程序计数器（PC）具有计数逻辑，移位寄存器具有移位逻辑。通用寄存器本身并不必须具备这些逻辑，故 C 错。
- **D 项**：通用寄存器（General Purpose Register）是 CPU 中一组可由程序员通过指令指定其用途的寄存器。它可以存放操作数、地址、中间结果，也可用于变址、基址等寻址方式，甚至某些指令集中还可约定部分通用寄存器作特殊用途。其核心特征就是“可编程指定多种功能”，故 D 正确。

因此答案为 D。

**易错点**：

1. **误选 A**：看到“寄存器”就认为能存指令。注意指令寄存器 IR 是控制器内部专用寄存器，用户程序不能随意访问；通用寄存器存放的是数据/地址，不是指令。
2. **误选 C**：有的 CPU 的通用寄存器支持移位操作（如 `SHL`、`SHR` 指令可对累加器移位），但这只是指令功能，不代表通用寄存器“本身”具有计数与移位逻辑。选项强调“本身具有”，指向的是硬件结构上的专用计数器/移位寄存器。
3. **混淆“通用”与“多功能”**：通用寄存器并非“什么都能存”，而是“可由程序指定用途”；它与专用寄存器（IR、PC、PSW、MAR、MDR）的关键区别在于可编程性。
4. **忽视“可编程”含义**：D 中“可编程指定多种功能”就是通用寄存器的本质，看到“可编程”要联想到汇编指令中可选择不同寄存器参与运算。

**命题规律**：

- **考点定位**：计算机系统概述中 CPU 内部寄存器分类，属于基础概念题，难度低，常出现在选择题前几题。
- **常见变式**：
  - 直接问“通用寄存器不具备的功能”或“哪个不是通用寄存器用途”。
  - 结合指令执行流程，问“取指阶段存放指令的寄存器是？”（答案 IR）。
  - 结合寻址方式，问“变址寄存器属于通用寄存器还是专用寄存器？”（通常为通用寄存器）。
  - 结合性能分析，问“增加通用寄存器数量对 CPI 或访存次数的影响”（减少访存，加快执行）。
- **复习建议**：把 CPU 中常见寄存器的英文缩写和功能整理成表：IR（指令）、PC（程序计数）、PSW（状态）、MAR/MDR（访存）、通用寄存器组（数据/地址）。理解“专用”与“通用”的本质区别，做题时抓住“指令、状态、计数/移位”这些关键词即可快速定位。

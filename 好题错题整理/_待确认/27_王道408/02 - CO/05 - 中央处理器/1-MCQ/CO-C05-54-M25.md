# 选择题 第 25 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-54-M25_题目.png|题目]]

25.【2019统考真题】某指令功能为 $R[r2] \leftarrow M[r1] + MR[r0]$, 其两个源操作数分别采用寄存器、寄存器间接寻址方式。对于下列给定部件,该指令在取数及执行过程中需要用到的是 ( )
I.通用寄存器组 (GPRs)
II.算术逻辑单元 (ALU)
III.存储器 (Memory)
IV.指令译码器 (ID)
(A) 仅 $I$、$II$
(B) 仅 $I$、$II$、$III$
(C) 仅 $II$、$III$、$IV$
(D) 仅 $I$、$III$、$IV$

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-54-M25_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B（仅 I、II、III）。该指令在取数/执行时需要读 GPRs、访存 Memory、用 ALU 做加法并写回 GPRs；指令译码器 ID 在取指/译码阶段使用，不属于“取数及执行”过程。

**解题切入点**：先抓题干的阶段限定——“取数及执行”，不是“取指/译码”。因此先排除 ID。然后把指令按寻址方式拆成“读源操作数 → 运算 → 写回”几步，像表达式求值一样逐步对应硬件部件。

**推演**：

按题意，两个源操作数分别为寄存器寻址和寄存器间接寻址，指令可记为

$$
R[r2]\leftarrow R[r1]+M[R[r0]]
$$

其中 $M[R[r0]]$ 表示以 $R[r0]$ 的内容为地址访问存储器。

取数及执行过程：

1. 读 GPRs：从 $R[r1]$ 读出第一个源操作数；从 $R[r0]$ 读出地址 $A$。
2. 访存：把地址 $A$ 送 MAR，从 Memory 的 $A$ 单元读出 $M[A]$，即 $M[R[r0]]$。
3. ALU 运算：将 $R[r1]$ 与 $M[R[r0]]$ 送入 ALU 执行加法。
4. 写回 GPRs：将 ALU 结果写回 $R[r2]$。

各部件使用情况：

| 部件 | 在本题中的作用 |
|---|---|
| GPRs | 读 $r1$、读地址寄存器 $r0$、写结果到 $r2$ |
| Memory | 寄存器间接寻址所需的读操作 |
| ALU | 完成加法运算 |
| ID | 取指/译码阶段使用；取数/执行阶段不再需要 |

因此需要 I、II、III，不需要 IV，选 B。

**易错点**：

- 把“取数”误认为“取指”，从而多选 IV（指令译码器）。注意“取指/译码”和“取操作数/执行”不是同一阶段。
- 忽略寄存器间接寻址需要访存，以为只读寄存器即可；实际必须先把寄存器内容作为地址送 Memory。
- 漏掉写回目的寄存器的过程，以为 GPRs 只用于读源操作数；完整执行应包括写回。
- 认为加法使用的是专用加法器而不是 ALU；在本题部件分类中，ALU 承担加法。

**命题规律**：

本题考点是“指令执行阶段 + 数据通路 + 寻址方式”。常见变式是把源操作数换成立即数、直接、变址、相对等寻址方式，或问“取指阶段需要哪些部件”。复习时应熟记各类寻址方式的数据通路：立即数不访存；寄存器寻址只读 GPRs；寄存器间接寻址需先读 GPRs 再访存。建议用“读操作数 → 运算 → 写结果”的方法判断部件，不要死记选项。

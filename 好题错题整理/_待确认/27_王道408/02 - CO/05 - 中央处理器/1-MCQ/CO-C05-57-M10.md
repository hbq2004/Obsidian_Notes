# 选择题 第 10 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-57-M10_题目.png|题目]]

10. 下列关于多核 $CPU$ 的描述中,正确的是 (  )

(A). 各核心完全对称,拥有各自的 $Cache$
(B). 任何程序都可以同时在多个核心上运行
(C). 一颗 $CPU$ 中集成了多个完整的执行内核,可同时进行多个运算
(D). 只有使用了多核 $CPU$ 的计算机，才支持多任务操作系统

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-57-M10_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。多核 CPU 是把多个完整、独立的执行内核集成在一颗 CPU 芯片中，因此可以真正同时进行多个运算；A、B、D 都存在概念混淆或说法过于绝对的问题。

**解题切入点**：
先抓住“多核 CPU”的本质定义：多个完整执行核心集成在一颗芯片上。然后逐个排除绝对化说法。可以类比算法竞赛：增加评测机的核心数，并不表示任何代码都能自动并行加速；程序必须被拆成可并行子任务，才能真正同时用多核。

**推演**：

- 多核 CPU 的定义是：在同一个处理器芯片上集成多个完整的内核，每个内核都有独立的取指、译码、执行等部件，因此多个核心可以并行执行不同的指令流或运算。
- 选项 A：错误。多核 CPU 并不必然要求“各核心完全对称”，也存在异构多核处理器，例如 ARM 的 big.LITTLE 架构中大小核结构不同；Cache 层次也常采用私有 Cache 与共享 Cache 混合的结构，例如每个核有私有 L1/L2，多个核共享 L3。因此 A 过于绝对。
- 选项 B：错误。程序能否在多个核心上同时运行，取决于程序是否被划分为可并行执行的线程/进程。单线程串行程序即使运行在多核 CPU 上，同一时刻也只能在一个核心上执行，不能“任何程序都可以”。
- 选项 C：正确。一颗 CPU 中集成多个完整执行内核，正是多核 CPU 的核心特征；多个内核可以并行执行多个运算。
- 选项 D：错误。单核 CPU 通过操作系统的分时调度，也能实现多任务。多任务依靠操作系统在多个任务之间切换实现“并发”，并不强制要求多核 CPU。

$$
\text{并发：多个任务交替执行，宏观上“同时”，微观上可能交替；并行：多个任务真正同时执行，需要多核等多执行部件支持。}
$$

**易错点**：

1. 误选 A：把“多核 CPU”与“同构多核/SMP”混为一谈。多核 CPU 可以是同构的，也可以是异构的；Cache 也可以有私有和共享层次之分。
2. 误选 B：以为多核 CPU 能自动让所有程序并行运行。实际只有具有多个可并行线程/进程的程序，才可能被调度到多个核心上同时运行。
3. 误选 D：混淆“多任务”与“多核”。单核 CPU 配合操作系统时间片轮转就能支持多任务，只是宏观并行、微观交替。
4. 概念辨析：多核提供的是并行硬件基础，多任务操作系统提供的是并发调度能力，二者不是同一层面的概念。

**命题规律**：
本考点属于计算机组成原理中的“处理器基本概念 / 多核处理器”，常与“并发与并行”“多线程”“多任务操作系统”结合出选择题。常见变式包括：判断“多核 CPU 一定能提高程序运行速度”“单核 CPU 是否能运行多任务操作系统”“多核 CPU 与多 CPU 的区别”“Cache 一致性”等。复习时应重点分清“并发 vs 并行”“单核 vs 多核”“多线程程序 vs 多任务系统”，并警惕选项中的“任何”“只有”“完全”等绝对化表述。

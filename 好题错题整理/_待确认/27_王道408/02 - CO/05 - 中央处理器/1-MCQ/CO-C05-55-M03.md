# 选择题 第 3 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-55-M03_题目.png|题目]]

3. 访问主存时发生的校验错误属于(    )
(A) 故障
(B) 自陷
(C) 终止
(D) 外中断

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-55-M03_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C（终止）。访问主存时的校验错误属于不可恢复的硬件错误，通常导致当前程序终止，故归为异常中的“终止”。

**解题切入点**：先判断异常来源是 CPU 内部还是外部设备，访问主存时的校验错误由指令执行过程触发，是同步的 CPU 内部异常，排除外中断（D）。再区分故障（可恢复）、自陷（主动触发）与终止（不可恢复）：校验错误往往因硬件损坏而无法通过重试恢复，也非程序有意触发，因此应归为终止（C）。

**推演**：
1. **异常分类基础**：计算机系统中的异常（Exception）按来源与处理方式分为：
   - 故障（Fault）：在指令执行前或执行中检测，通常可恢复（如缺页、除零）。
   - 自陷（Trap）：由程序主动触发（如系统调用、断点），执行完当前指令后响应。
   - 终止（Aort）：严重不可恢复错误（如硬件损坏、非法指令），一旦发生程序无法继续。
   - 外中断（Interrupt）：来自 CPU 外部的异步事件（如 I/O 请求）。

2. **校验错误特性**：访问主存时发生的校验错误（如奇偶校验错、ECＣ 不可纠正错）由硬件检测到，表示存储数据已损坏。此类错误具有以下特点：
   - 同步性：与访问指令密切相关。
   - 不可恢复性：即使重新执行指令，损坏的数据仍会导致错误，无法通过“重试”纠正。
   - 非程序意图：不是程序主动设置的。

3. **匹配分类**：
   - 非外中断：错误是同步的、由 CPU 内部产生，排除 D。
   - 非自陷：自陷需程序主动触发（如 `syscall`），校验错误是硬件被动检测，排除 B。
   - 非故障：故障意味着可以尝试“重试”来恢复（如缺页后调入页再执行），但校验错误无法通过重试解决（数据已损），故不属于故障（A）。
   - 属于终止：符合终止“严重硬件错误、不可恢复、立即中止程序”的定义，故选 C。

**易错点**：
- 混淆故障与终止：误认为“检测到错误后可以重新执行指令”而选故障（A）。实际上校验错误体现的是数据本身损毁，重试不能修复正确数据。
- 误认作外中断：认为校验错误来自内存模块（外部设备），但它是同步于访存指令的内部事件，分类上不是中断。
- 误解自陷：部分考生将“校验错误”视为软件可主动检查的情况（如通过软件校验），但题目明确“访问时发生”是硬件自动检测，非程序有意。

**命题规律**：
- **考点定位**：异常分类（故障、自陷、终止、外中断的区分）。
- **常见变式**：给出具体异常（如除零、缺页、校验错、系统调用），要求判断类别；或考查各类异常的处理机制（如是否重新执行指令）。
- **复习建议**：牢记考研常见例子：故障→缺页、段错误（可恢复）；自陷→系统调用、断点；终止→内存校验错、非法指令（不可恢复）；外中断→时钟、 I/O 中断。结合指令执行流程理解各类异常的响应时机。

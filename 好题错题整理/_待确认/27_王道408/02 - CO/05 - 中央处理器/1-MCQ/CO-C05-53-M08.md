# 选择题 第 8 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-53-M08_题目.png|题目]]

8. 下列操作中，从开始到完成所持续的时间不一定等于一个时钟周期的是 ( )

I. 单总线数据通路中完成一次$主存$读操作.
II. 单周期$CPU$中执行一条完整指令.
III. 单总线数据通路中, 寄存器$R1$经内部总线传至寄存器$R2$.
IV. 流水线数据通路中, 数据从一个流水段寄存器传入下一个流水段寄存器.
V. 单周期$CPU$中完成一次$ALU$运算.

A. $I、V$
B. $I、III、V$
C. $II、III、IV$
D. $IV、V$

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-53-M08_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A（I、V）。  
一句话理由：主存读操作可能因慢速主存而插入等待周期，ALU 运算是组合逻辑延迟，二者不一定等于一个时钟周期；其余三项都是时钟同步控制下的“一拍”操作。

**解题切入点**：  
拿到题目先区分两类操作：  
- 由时钟沿控制的同步操作，如寄存器传送、流水段推进、单周期指令执行，通常是“一拍”，即一个时钟周期；  
- 由组合逻辑完成的操作，如 ALU 运算，实际耗时为门电路传播延迟，不一定等于时钟周期；  
- 主存读操作属于外部低速访问，可能需要等待周期，因此也不一定等于一个时钟周期。

可以类比为：时钟周期像“比赛的统一计时窗口”，ALU 像“运动员实际完赛用时”，主存读像“可能因外部设备速度慢而加时”的操作。

**推演**：  
设时钟周期为 $T$。

- I. 单总线数据通路中完成一次主存读操作：需要送地址、发出读命令、主存译码并返回数据。若主存速度低于 CPU，需要插入等待周期，时间可能是 $T$ 的若干倍，因此**不一定等于一个时钟周期**。
- II. 单周期 CPU 中执行一条完整指令：单周期 CPU 的定义就是所有指令在一个时钟周期内完成，因此时间**等于一个时钟周期**。
- III. 单总线数据通路中，寄存器 R1 经内部总线传至寄存器 R2：单总线虽然每一拍只能完成一次数据传送，但 R1→R2 本身只是一次数据传送，在同步寄存器传送中用一个时钟周期即可完成，因此**等于一个时钟周期**。
- IV. 流水线数据通路中，数据从一个流水段寄存器传入下一个流水段寄存器：流水线按时钟节拍推进，每一拍完成一个流水段的数据传递，因此**等于一个时钟周期**。
- V. 单周期 CPU 中完成一次 ALU 运算：ALU 是组合逻辑电路，实际完成时间是从输入稳定到输出稳定的传播延迟 $t_{\text{ALU}}$，通常小于时钟周期 $T$，因此**不一定等于一个时钟周期**。

所以，满足“不一定等于一个时钟周期”的是 I 和 V，选 A。

**易错点**：  
- 误以为 ALU 运算是“受时钟控制的操作”，忘记它是组合逻辑，实际耗时是门延迟。  
- 误以为单周期 CPU 执行一条指令可能需要多个时钟周期；单周期 CPU 的“单周期”就是要求一条指令在一个时钟周期内完成。  
- 误以为单总线上的寄存器传送需要多个时钟周期；单总线限制的是“同一时刻只能传送一个数据”，但 R1→R2 本身只有一次数据传送，一拍足够。  
- 误以为流水段寄存器之间传递数据的时间是组合逻辑延迟；在同步流水线中，数据在下一个时钟沿被打入寄存器，按一拍计算。  
- 忽略主存速度与 CPU 速度不匹配的问题，主存读操作可能需要插入等待周期。

**命题规律**：  
本题考点是“时钟周期、机器周期、指令周期”的区别，以及数据通路中同步时序操作和组合逻辑操作的区分。  
常见变式：  
- 问“一定等于一个时钟周期的是哪些”；  
- 结合多周期 CPU、总线周期、CPI 计算；  
- 结合主存存取时间判断是否影响时钟周期。  

复习建议：熟练掌握“时钟沿触发的一拍操作”和“组合逻辑延迟”两类时间模型；遇到 ALU、加法器等先判断是否组合电路，遇到访存注意等待周期；流水线中始终抓住“一个流水级一拍”的同步思想。

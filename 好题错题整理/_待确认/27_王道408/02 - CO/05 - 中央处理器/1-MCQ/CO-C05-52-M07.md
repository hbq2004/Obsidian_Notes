# 选择题 第 7 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-52-M07_题目.png|题目]]

7. 下列关于指令周期的叙述中,错误的是( ).

A. 指令周期的第一个阶段一定是取指令阶段

B. 乘法指令和加法指令的指令周期总是一样长

C. 一个指令周期可由若干时钟周期组成

D. 单周期 $CPU$ 中的指令周期就是一个时钟周期

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-52-M07_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。理由：指令周期是 CPU 取出并执行一条指令所需的全部时间，不同指令所需时钟周期数可能不同；乘法指令通常比加法指令需要更多时钟周期，因此“总是一样长”是错误的。

**解题切入点**：拿到题目先抓住“指令周期、机器周期、时钟周期”三者的层次关系。指令周期是执行一条指令的总时间，机器周期是完成一个基本操作的时间，时钟周期是 CPU 工作的最小时间单位。做这道题就像做算法题：不同操作耗时不同，不能默认所有操作时间都一样。单周期 CPU 是特殊情况，它的指令周期恰好等于一个时钟周期。

**推演**：

1. 指令周期通常可以分为取指周期、间址周期、执行周期、中断周期等，其中间址周期和中断周期不一定每个指令都有，但取指周期一定存在，并且是第一个阶段。因此 A 正确：
   $$
   \text{指令周期中必定包含取指周期，且取指周期是第一阶段}
   $$

2. 指令周期的长短取决于指令本身的复杂程度和 CPU 的硬件设计。加法指令通常只需一次加法运算，而乘法指令可能需要多次“移位—相加”操作，或者调用硬件乘法器完成运算，所需时钟周期数一般更多。因此不能说乘法指令和加法指令的指令周期总是一样长，B 错误。

3. 一般情况下，一个指令周期可由若干个机器周期组成，而一个机器周期又可由若干个时钟周期组成。因此“一个指令周期可由若干时钟周期组成”是正确的，C 正确。

4. 单周期 CPU 的含义是：每条指令的取指、译码、执行、写回等所有步骤在一个时钟周期内完成。因此在单周期 CPU 中，指令周期就是一个时钟周期，D 正确。

综上，错误的是 B。

**易错点**：

- 容易误以为所有指令的指令周期都相同，实际上指令周期因指令而异。
- 容易把单周期 CPU 的特点推广到所有 CPU，但只有单周期 CPU 中指令周期才等于一个时钟周期。
- 容易怀疑 A，认为间址周期可能在取指之前；但间址周期只出现在间接寻址时，而且必须在取指完成、获得地址之后才进行，所以取指一定是第一阶段。
- 注意 C 的方向不能反：是“若干时钟周期组成指令周期”，不是“一个时钟周期由若干指令周期组成”。

**命题规律**：

本题是计算机组成原理中的基础概念题，主要考查指令周期、机器周期、时钟周期的层次关系，以及不同指令周期长度的区别。常见变式包括：给出单周期 CPU 或多周期 CPU，判断 CPI 或时钟周期数；判断“每个指令都有间址周期”“每个指令都有中断周期”等说法是否正确。复习时应重点理解周期层次：
$$
\text{指令周期}\ \rightarrow\ \text{机器周期}\ \rightarrow\ \text{时钟周期}
$$
并结合单周期 CPU、多周期 CPU 的数据通路进行记忆，明确单周期 CPU 的 CPI 为 1。

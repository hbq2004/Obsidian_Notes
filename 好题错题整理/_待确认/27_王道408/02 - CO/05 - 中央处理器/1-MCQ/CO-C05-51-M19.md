# 选择题 第 19 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-51-M19_题目.png|题目]]

19. CPU中不包括（ ）
(A) 存储器地址寄存器
(B) 指令寄存器
(C) 地址译码器
(D) 程序计数器

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-51-M19_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。理由：地址译码器是主存（或 Cache）等存储部件内部的电路，用于地址选择存储单元，不属于 CPU 核心组成部件；CPU 中包含程序计数器（PC）、指令寄存器（IR）、存储器地址寄存器（MAR）等。

**解题切入点**：先确定“CPU”的组成边界，想清楚 CPU 核心功能是取指、译码、执行，而“地址译码”属于存储器访问时的硬件行为。类比做题：CPU 是“大脑”，存储器是“书架”，地址译码器是书架的“索引抽屉”，不在大脑里。

**推演**：

- CPU 主要包含：
  - 运算器：ALU、暂存寄存器、累加器等；
  - 控制器：程序计数器（PC）、指令寄存器（IR）、指令译码器、时序系统、控制存储器（微程序控制器中）等；
  - 寄存器组：通用寄存器、存储器地址寄存器（MAR）、存储器数据寄存器（MDR）等。
- 关键区别：
  - 存储器地址寄存器（MAR）用于存放欲访问内存单元的地址，它位于 CPU 内部，负责在 CPU 与存储器之间传递地址信息；
  - 指令寄存器（IR）用于存放当前正在执行的指令，是控制器的重要组成部分；
  - 程序计数器（PC）用于存放下一条指令的地址，也是控制器的一部分；
  - 地址译码器（Decoder）是把地址总线上的地址信号翻译成对应存储单元选取信号的电路，通常位于主存储器、Cache 或 I/O 接口中，不属于 CPU 的组成部分。

因此，四个选项中只有 C 不是 CPU 中的部件。

**易错点**：
1. 把“存储器地址寄存器”和“地址译码器”混淆。前者在 CPU 内部，是寄存器；后者是存储芯片内的译码逻辑，两者功能不同，位置不同。
2. 误认为 Cache 中的地址译码在 CPU 内部。Cache 虽常集成在 CPU 芯片中，但从组成原理上看，Cache 本身属于存储层次结构，其译码逻辑仍属于存储部件而非 CPU 核心。
3. 忽略 MAR 和 MDR 的位置。早期教材中 MAR、MDR 属于 CPU 内部寄存器，但现代 CPU 中它们可能被集成到存储器控制器中，题目语境下仍按经典结构回答。

**命题规律**：本题属于计算机系统基础中“CPU 的组成与功能”的送分题，常以选择题形式考查 CPU 内部部件与存储器部件、I/O 部件的划分。常见变式包括：
- “下列哪个不是 CPU 中的寄存器？”
- “CPU 控制器的组成不包括（）”
- “MAR、MDR 位于 CPU 还是主存？”
复习时建议以教材的经典结构图（CPU 内部框图）为基准，准确记忆 PC、IR、MAR、MDR、通用寄存器、ALU、CU 等部件的位置；同时注意区分“寄存器”和“译码器”等组合逻辑电路在层次上的归属。

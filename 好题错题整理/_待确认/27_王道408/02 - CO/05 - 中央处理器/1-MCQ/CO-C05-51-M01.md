# 选择题 第 1 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-51-M01_题目.png|题目]]

1. $CPU$ 的核心功能是执行程序,下列不属于 $CPU$ 的基本功能的是 ( )
(A) 时序控制
(B) 异常与中断处理
(C) 执行算术和逻辑运算
(D) 数据存储

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-51-M01_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。一句话理由：CPU 的基本功能包括指令控制、操作控制、时序控制、数据加工（算术与逻辑运算）以及异常/中断处理，而“数据存储”主要由存储系统完成，不属于 CPU 的基本功能。

**解题切入点**：先抓住“CPU 的基本功能”这一概念，回忆它的典型功能集合：取指令、分析指令、执行指令、控制时序、处理异常中断、进行算术逻辑运算等。可以把 CPU 比作“工厂的总调度兼加工车间”，它负责指挥和计算，但“仓库”（存储器）负责存放原料和成品，故“数据存储”不属于 CPU 的基本功能。

**推演**：
- CPU 的核心功能是执行程序，执行程序的本质是不断重复“取指令—分析指令—执行指令”的过程。
- CPU 的基本功能通常包括：
  - 指令控制：保证指令按程序规定的顺序执行；
  - 操作控制：产生并发出各种操作控制信号，控制各部件协同工作；
  - 时序控制：对各种操作进行时间上的控制，使指令按严格的时序关系执行，故选项 A 属于 CPU 基本功能；
  - 数据加工：对数据进行算术运算和逻辑运算，故选项 C 属于 CPU 基本功能；
  - 异常与中断处理：CPU 需要响应并处理程序执行过程中的异常和外部中断，故选项 B 属于 CPU 基本功能。
- 数据存储：一般由存储器（如内存、Cache）完成。CPU 内部虽有寄存器，但寄存器的功能是暂存指令、地址和中间结果，不属于 CPU 作为“执行部件”的基本功能范畴。因此选项 D 不属于 CPU 的基本功能。

**易错点**：
1. 误选 C：有些考生认为算术运算由 ALU 完成，不算 CPU 功能。但 ALU 位于 CPU 内部，数据加工正是 CPU 的核心功能之一。
2. 误选 A：忽略“时序控制”是 CPU 的基本功能。CPU 必须依靠时钟周期、机器周期等对操作进行时序协调。
3. 混淆“寄存器暂存”与“数据存储”：CPU 内部寄存器确实能存储少量数据，但题目问的是“基本功能”，数据存储整体上属于存储器的职责，不是 CPU 的基本功能。
4. 备考时注意区分“CPU 的功能”和“存储器的功能”，概念要分清楚。

**命题规律**：
- 考点定位：计算机系统组成中 CPU 的基本功能与组成结构。
- 常见变式：给出多个选项，问“哪个属于 CPU 功能”“CPU 不包含哪个部件”或“CPU 基本功能不包括”等；也可能结合指令周期、中断、时序等知识点出题。
- 复习建议：熟记 CPU 的五大基本功能（指令控制、操作控制、时序控制、数据加工、异常与中断处理），并理解 CPU 内部部件（ALU、控制器、寄存器等）各自的职责，学会与存储器、I/O 的功能进行辨析。

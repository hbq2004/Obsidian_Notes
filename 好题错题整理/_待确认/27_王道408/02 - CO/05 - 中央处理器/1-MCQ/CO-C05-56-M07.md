# 选择题 第 7 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-56-M07_题目.png|题目]]

7.下列关于流水段寄存器的叙述中,正确的是 ( )
(A) 指令译码得到的控制信号需通过流水段寄存器传递到下一个流水段
(B) 每个流水段之间的流水段寄存器位数一定相同
(C) 每个流水段之间的流水段寄存器存放的信息一定相同
(D) 用户程序可以通过指令指定访问哪个流水段寄存器

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-56-M07_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A。指令译码阶段生成的控制信号必须通过流水段寄存器锁存并逐段传递到后续流水段；其余选项因“一定相同/用户程序可访问”等说法错误。

**解题切入点**：拿到题目先抓“流水段寄存器”的功能与可见性。可以把流水段寄存器想象成工厂传送带上每个工位之间的“物料盒”：当前工位暂时不用、但后面工位要用的数据和信号，必须先放进物料盒传给下一工位。因此，见到“一定相同”“用户程序可指定访问”这类绝对化或涉及程序员可见性的说法，应重点怀疑。

**推演**：经典五段流水线为 IF、ID、EX、MEM、WB，相邻流水段之间有流水段寄存器：

$$
\text{IF/ID} \rightarrow \text{ID/EX} \rightarrow \text{EX/MEM} \rightarrow \text{MEM/WB}.
$$

1. 指令在 ID 阶段译码后，会产生控制信号。有的控制信号用于 EX 阶段，如 ALUOp、ALUSrc；有的用于 MEM 阶段，如 MemRead、MemWrite；有的用于 WB 阶段，如 RegWrite、MemtoReg。这些控制信号不能全部在 ID 阶段使用完，必须通过流水段寄存器逐段向后传递，保证后续流水段在合适的时钟周期得到正确的控制信号。因此 A 正确。

2. B 错：不同流水段之间需要保存的信息不同，所需位数并不一定相同。例如 IF/ID 可能需要保存取到的指令和 PC+4，ID/EX 需要保存控制信号、寄存器号、立即数等，EX/MEM 需要保存 ALU 结果、写寄存器号等，它们的宽度不同。

3. C 错：每个流水段寄存器存放的信息不同。IF/ID 保存取指信息，EX/MEM 保存执行结果和访存控制信息，MEM/WB 保存访存结果和回写控制信息等，不能说“一定相同”。

4. D 错：流水段寄存器是 CPU 内部为实现流水线而设置的寄存器，不属于指令集体系结构（ISA）中程序员可见的寄存器。用户程序只能通过指令访问通用寄存器、PC、存储器等，不能指定访问某个流水段寄存器。

**易错点**：
- 误以为所有流水段寄存器“都是寄存器”，所以位数一定相同、存放信息一定相同；实际上不同流水段的功能决定其内容和位数不同。
- 误以为控制信号只在译码阶段使用；实际上译码阶段产生的控制信号要分别在 EX、MEM、WB 等阶段使用，必须逐段传递。
- 误把 CPU 内部寄存器与程序员可见寄存器混为一谈；流水段寄存器对用户程序不可见。

**命题规律**：该考点主要考查流水段寄存器的作用、内容、位数以及程序员可见性。常见变式包括：给出某条指令的各阶段控制信号，判断哪些信号应写入哪一级流水段寄存器；或者判断“流水段寄存器是否对用户可见”等说法。复习时应掌握经典五段流水线的数据通路，明确 IF/ID、ID/EX、EX/MEM、MEM/WB 各自保存的典型信息即可应对。

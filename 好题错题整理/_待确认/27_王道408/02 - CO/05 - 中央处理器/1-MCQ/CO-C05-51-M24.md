# 选择题 第 24 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-51-M24_题目.png|题目]]

24.【2020统考真题】下列给出的部件中,其位数 (宽度) 一定与机器字长相同的是 ( )
I.ALU
II.指令寄存器
III.通用寄存器
IV.浮点寄存器
(A) 仅I、II
(B) 仅I、III
(C) 仅II、III
(D) 仅II、III、IV

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-51-M24_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B（仅 I、III）。ALU 和通用寄存器都在整数数据通路上，其位数与机器字长一致；指令寄存器取决于指令字长，浮点寄存器取决于浮点数据格式，均不一定等于机器字长。

**解题切入点**：拿到题先不要把“寄存器”一概而论，而要问“这个部件是为什么设计的”。机器字长是 CPU 一次能处理的数据位数，ALU 和通用寄存器都服务于整数数据运算，因此位宽必须匹配；指令寄存器服务于“取到的指令”，其宽度由指令编码长度决定；浮点寄存器服务于浮点数格式，由浮点数标准决定。就像算法竞赛中，核心运算函数的参数类型必须和变量类型一致，而命令字符串的长度和存储 double 的缓冲区长不一定要和 int 的宽度一样。

**推演**：

设机器字长为 $W$。

- **I. ALU**。ALU 是整数/定点运算部件，其输入、输出位数就是一次运算的操作数位数。CPU 以 $W$ 为基本整数处理宽度，因此 ALU 位数也为 $W$。所以 I 正确。

- **II. 指令寄存器（IR）**。IR 用于存放当前指令，其宽度至少要能容纳一条指令，因此与指令字长有关。指令字长可能为 $W$，也可能是 $W/2$ 或 $2W$，甚至可变长，不“一定”等于 $W$。所以 II 错误。

- **III. 通用寄存器**。通用寄存器用于保存整数操作数、地址和中间结果，一个寄存器应能存下一个完整的机器字，因此其位数 $=W$。所以 III 正确。

- **IV. 浮点寄存器**。浮点寄存器存放浮点数，其宽度由浮点数格式决定。例如单精度浮点数为 32 位、双精度浮点数为 64 位、扩展精度可能为 80 位。一个机器字长为 32 位的 CPU 完全可以使用 64 位浮点寄存器；机器字长为 64 位的 CPU 也可以只用 64 位浮点寄存器。因此其位数不“一定”等于 $W$。所以 IV 错误。

综上，只有 I、III 正确，选 **B**。

**易错点**：

1. 看到“指令寄存器”就默认等于机器字长。很多教材为简化模型令指令字长等于机器字长，但题目问“一定”，应排除。
2. 把所有寄存器都当成“存数据”的通用寄存器。IR、浮点寄存器、PC、MAR、MDR 等各有专门用途，位宽由各自决定因素控制。
3. 忽略浮点寄存器由浮点格式决定。双精度浮点数本身就是 64 位，和 CPU 是 32 位还是 64 位没有必然关系。
4. 对 ALU 的宽度犹豫。按 408 中机器字长的定义，ALU 的位数直接体现机器字长，因此 I 正确。

**命题规律**：

该题属于“机器字长、存储字长、指令字长”的辨析题，常以部件位宽判断的形式出现。常见变式是考查 PC、MAR、MDR、IR、累加器等部件：

- ALU、通用寄存器、累加器等：与机器字长有关；
- IR：与指令字长有关；
- MAR：与地址位数有关；
- MDR：与存储字长有关；
- PC：与可寻址地址空间/地址位数有关。

复习时建议自己列一张“部件—决定因素—典型宽度”的表格；做题时看到“一定”二字，立刻寻找反例，用 32 位/64 位 CPU 场景验证每个部件是否必然匹配机器字长。

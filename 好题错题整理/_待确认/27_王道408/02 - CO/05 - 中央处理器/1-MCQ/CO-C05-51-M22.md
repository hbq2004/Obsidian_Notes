# 选择题 第 22 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-51-M22_题目.png|题目]]

22.【2010统考真题】 下列寄存器中,汇编语言程序员可见的是( ).
A. 存储器地址寄存器 ($MAR$)
B. 程序计数器 ($PC$)
C. 存储器数据寄存器 ($MDR$)
D. 指令寄存器 ($IR$)

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-51-M22_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。  
理由：$PC$（程序计数器）中保存下一条指令的地址，汇编语言程序员可通过转移、调用、返回等指令感知并改变其值，因此是可见的；$MAR$、$MDR$、$IR$ 都是 CPU 内部工作用的寄存器，对汇编语言程序员透明。

**解题切入点**：  
考“汇编语言程序员可见”这个概念，本质是判断：寄存器是否会被指令集“直接或间接”暴露给程序员。可以把汇编语言程序员看成使用一台机器的操作员，只能看到带有“开关”和“表盘”的接口；$MAR$、$MDR$、$IR$ 就像机器内部临时缓存，数据流动时自动工作，程序员不需要也不允许直接操作它们。而 $PC$ 像“当前执行到第几条指令”的指针，跳转指令会修改它，所以它属于“可见”的寄存器。

**推演**：  
汇编语言程序员可见的寄存器，通常指能够通过汇编指令显式或隐式访问其内容的寄存器，例如通用寄存器、程序计数器 $PC$、程序状态字寄存器 $PSW$ 等。选项逐一分析：

- $MAR$：存储器地址寄存器。  
  访存时，CPU 将访问地址送入 $MAR$，该过程由硬件自动完成。指令集中没有“操作 $MAR$”的汇编指令，因此程序员不可见。

- $PC$：程序计数器。  
  它保存下一条将要执行的指令的地址。普通指令按顺序执行时，$PC$ 自动增加：
  $$PC \leftarrow PC + \text{当前指令长度}$$
  当执行转移指令、调用指令或返回指令时，程序员通过指令指定目标地址，CPU 会修改 $PC$：
  $$PC \leftarrow \text{目标地址}$$
  因此汇编语言程序员可以通过指令隐式地访问和改变 $PC$，它是可见的。

- $MDR$：存储器数据寄存器。  
  它用来暂存从存储器读出的数据或准备写入存储器的数据，是 CPU 与存储器之间的数据缓冲，完全由硬件控制，程序员不可见。

- $IR$：指令寄存器。  
  取指阶段从存储器取出指令后，指令被送入 $IR$ 保存，供译码器分析使用。程序员无法通过汇编指令读写 $IR$，因此不可见。

综上，只有 $PC$ 属于汇编语言程序员可见的寄存器，故选 B。

**易错点**：  
1. 误选 $IR$：$IR$ 保存的是“当前正在执行的指令”，容易被误认为程序员可以查看。实际上 $IR$ 是 CPU 内部控制通路的一部分，汇编程序员无法直接访问。  
2. 误以为 $PC$ 不可见，因为程序员不写“PC”这个符号。但转移指令本质就是修改 $PC$，所以 $PC$ 对汇编程序员“可见”。  
3. 混淆“用户程序员”和“汇编语言程序员”：本题范围是汇编语言层，不是高级语言层。若说“应用程序员”，可能连 $PC$ 也不必关心，但题目明确说“汇编语言程序员”。  
4. 记混 $MAR$ 和 $MDR$：一个是地址寄存器，一个是数据寄存器，都是访存过程中的内部暂存器，均不可见。

**命题规律**：  
这是 408 计算机组成原理中关于 CPU 内部结构的经典概念题，重点考查“程序员可见寄存器”与“ CPU 内部工作寄存器”的区分。常见变式有：  
- 下列哪些寄存器对程序员不可见？  
- 配合指令周期，问取指阶段会把指令送到哪个寄存器？  
- 结合汇编指令，问转移指令改变的是哪个寄存器？  
复习时应熟练掌握：  
- 程序员可见：通用寄存器、$PC$、$PSW$ 等；  
- 程序员不可见：$MAR$、$MDR$、$IR$ 以及数据通路中的各种暂存器。  
建议将寄存器按“取指、译码、执行、访存”各阶段的功能串起来理解，而不是孤立记忆名称。

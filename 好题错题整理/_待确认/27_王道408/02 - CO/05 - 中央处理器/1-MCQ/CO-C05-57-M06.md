# 选择题 第 6 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-57-M06_题目.png|题目]]

6. 下列关于超线程($HT$)技术的描述中, 正确的是(   )

A. 超线程技术可以令四核的$Intel\ Core\ i7$处理器变成八核
B. 超线程是一项硬件技术，能使系统性能大幅提升，与操作系统和应用软件无关
C. 含有超线程技术的$CPU$需要芯片组的支持才能发挥技术优势
D. 超线程模拟出的每个$CPU$核都具有独立的资源,各自工作互不干扰

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-57-M06_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。超线程（HT）是把一个物理核表现为多个逻辑处理器，而不是真正变成更多物理核；它需要芯片组、BIOS 和操作系统等平台/软件支持才能发挥优势。

**解题切入点**：先抓住 HT 的本质：同时多线程（SMT）。它在单个物理核内复制“架构状态”（程序计数器、通用寄存器等），但让多个线程共享执行部件。因此，既可以排除“变成八核”，也可以排除“与软件无关”和“独立资源互不干扰”；剩下来考察“使用条件”的 C 就是正确项。

**推演**：

- 对 A：四核 i7 支持 HT 后，每个物理核可同时运行两个线程，操作系统能看见 $4\times 2=8$ 个逻辑处理器。但这只是“四核八线程”，不是变成 8 个物理核，执行单元总数并没有翻倍。A 错。

- 对 B：HT 确实由 CPU 硬件实现，但要发挥作用，需要操作系统把逻辑处理器识别为可调度实体，并将不同的线程/进程调度到同一个物理核上；应用软件的并行性和资源需求也直接影响收益。因此“与操作系统和应用软件无关”错。B 错。

- 对 D：HT 下每个逻辑处理器有自己独立的寄存器组/PC 等架构状态，但 ALU、浮点部件、Cache、TLB、取指/译码宽度、总线带宽等大量硬件资源是共享的。两个线程会争用这些资源，并非“独立资源、互不干扰”。极端情况下，HT 的加速比 $S$ 满足 $1<S<2$；若资源争用严重，甚至可能低于 1。D 错。

- 对 C：HT 的启用和使用不只在 CPU 内部；主板芯片组/BIOS 需要能够识别多个逻辑处理器并进行中断路由，操作系统也要通过 ACPI、CPUID 等机制获得逻辑处理器信息。没有芯片组等平台支持，HT 无法真正发挥技术优势。C 对。

**易错点**：

1. 把“逻辑核”当成“物理核”。A 是典型陷阱：四核 HT 是“四核八线程”，不是八物理核。  
2. 认为 HT 一定能大幅提升性能。它利用的是共享执行资源中的空闲能力，收益与线程类型、缓存冲突、OS 调度密切相关。  
3. 看到 B 的前半句“超线程是一项硬件技术”正确就误选 B。要整体判断，后半句“与操作系统和应用软件无关”明显错误。  
4. 忽略平台支持条件。CPU 支持 HT 不等于系统一定能用，还需要芯片组、BIOS/EFI、OS 的配合。

**命题规律**：该考点属于“CPU 性能提高技术/并行技术”，重点考查 HT、多核、SMT 的概念辨析。常见变式有：判断“逻辑处理器与物理核关系”、比较超线程与多核的硬件资源差异、结合 OS 调度或 Amdahl 定律分析性能上限。复习时应把“硬件并行能力”与“软件配合条件”分开理解：硬件提供能力，操作系统和应用程序必须配合才能转化为实际加速。

# 选择题 第 8 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-52-M08_题目.png|题目]]

8.下列关于多周期$CPU$的说法中,合理的是 (    )
A. 执行各条指令的时钟周期数相同，各时钟周期的长度均匀
B. 执行各条指令的时钟周期数相同，各时钟周期的长度可变
C. 执行各条指令的时钟周期数可变,各时钟周期的长度均匀
D. 执行各条指令的时钟周期数可变,各时钟周期的长度可变

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-52-M08_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。多周期 CPU 中每条指令被划分为若干步骤，不同指令所需步骤数不同，但每个时钟周期长度固定且均匀。

**解题切入点**：先抓住题干中的两个核心变量：**执行指令的时钟周期数**和**时钟周期长度**。多周期 CPU 的核心思想是把指令执行过程“拆细”，因此周期数必然可变；而时钟周期长度是由硬件时钟驱动的，通常统一设定，长度均匀。类似算法竞赛中，不同数据规模需要的步骤数不同，但每次“基本操作”耗时固定。

**推演**：

1. 单周期 CPU 中，每条指令在一个时钟周期内完成，因此所有指令的时钟周期数相同（都是 1），但为了满足最慢指令（如乘法、访存）的需要，时钟周期长度必须足够长，所以各周期长度相同且较长，即“周期数相同、长度均匀”。

2. 多周期 CPU 将每条指令的执行过程分为取指（IF）、译码（ID）、执行（EX）、访存（MEM）、写回（WB）等若干阶段，每个阶段占用一个时钟周期。

   - 不同指令需要的阶段数不同。例如，`ADD` 可能只需要 4 个周期（IF、ID、EX、WB），而 `LOAD` 需要 5 个周期（IF、ID、EX、MEM、WB），`STORE` 也可能需要 4 个周期（IF、ID、EX、MEM）。因此，执行各条指令的时钟周期数**可变**。
   - 多周期 CPU 中每个时钟周期的长度由硬件时钟统一产生，通常取所有可能操作中最长一步所需的时间，但绝对长度固定。也就是说，每个时钟周期的时间宽度相同，即**各时钟周期的长度均匀**。

3. 对比选项：
   - A：周期数相同且长度均匀 → 这是单周期 CPU 的特点。
   - B：周期数相同但长度可变 → 不是常规设计，也无意义。
   - C：周期数可变，长度均匀 → 符合多周期 CPU。
   - D：周期数可变，长度可变 → 这是异步控制或“无时钟”设计，不属于多周期 CPU 的典型特征。

4. 因此，合理的是 C。

**易错点**：
- 把多周期 CPU 误认为“周期数可变，长度也可变”。实际上，多周期 CPU 虽然各指令周期数不同，但硬件时钟周期长度仍然是统一的。
- 混淆单周期 CPU 和多周期 CPU。单周期 CPU 周期数固定为 1，且周期长度较长；多周期 CPU 周期数可变，但周期长度较短且均匀。
- 误以为“长度可变”是流水线的特点。流水线中每个流水段耗时均匀，时钟周期长度也固定，但流水线与多周期 CPU 并非同一概念。

**命题规律**：
- 考点定位：计算机组成原理中的 CPU 时序控制方式（单周期、多周期、流水线）的基本概念辨析。
- 常见变式：
  - 考查单周期 CPU 的时钟周期长度由什么决定（最慢指令）。
  - 考查多周期 CPU 的时钟周期数受什么影响（指令类型、阶段划分）。
  - 考查流水线 CPU 与多周期 CPU 在时钟周期上的区别。
- 复习建议：对比记忆三种时序控制方式的“周期数”和“周期长度”特点，并结合典型指令（如 `LOAD`、`STORE`、`ADD`）画出多周期时序图，加深理解。

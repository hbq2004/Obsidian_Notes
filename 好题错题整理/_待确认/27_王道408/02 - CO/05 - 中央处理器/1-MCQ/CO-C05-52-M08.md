# 选择题 第 8 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-52-M08_题目.png|题目]]

8. 下列关于多周期 $CPU$ 的说法中,合理的是( )

A. 执行各条指令的时钟周期数相同，各时钟周期的长度均匀.

B. 执行各条指令的时钟周期数相同，各时钟周期的长度可变.

C. 执行各条指令的时钟周期数可变,各时钟周期的长度均匀.

D. 执行各条指令的时钟周期数可变,各时钟周期的长度可变.

## 答案

## DeepSeek V4 Flash Max 解析

**答案**：C。多周期 CPU 中，不同指令所需时钟周期数可以不同，但各时钟周期长度固定、均匀。

**解题切入点**：先抓住“多周期 CPU”这个限定词。多周期 CPU 把一条指令的执行分成若干基本步骤，每个步骤用 1 个时钟周期完成；不同指令需要的步骤数不同，所以“时钟周期数可变”。而 CPU 由统一时钟驱动，每个时钟周期的长度是固定的，所以“各时钟周期的长度均匀”。可以把多周期 CPU 理解为“同一个节拍器控制多个工序，工序多少因任务而异，但一拍时长始终相同”。

**推演**：

设某多周期 CPU 中指令 $i$ 需要的时钟周期数为 $c_i$，则执行 $n$ 条指令的总时钟周期数为

$$
\sum_{i=1}^{n} c_i
$$

平均每条指令的时钟周期数为

$$
\text{CPI}=\frac{1}{n}\sum_{i=1}^{n}c_i
$$

在多周期 CPU 中，指令被划分为取指、译码、执行、访存、写回等阶段。例如：

- `lw` 指令可能需要进行取指、译码、计算地址、访存、写回 5 个步骤，需要 5 个时钟周期；
- `beq` 指令可能只需要取指、译码、执行并修改 PC 等步骤，需要 3 个或更少的时钟周期；
- `j` 指令可能需要的时钟周期数更少。

因此：

$$
c_i \neq c_j \quad (i \neq j)
$$

即不同指令的时钟周期数不同。所以“执行各条指令的时钟周期数可变”成立。

另一方面，多周期 CPU 的控制器是有限状态机，状态转移由同一个时钟信号驱动。设每个时钟周期长度为 $P$，所有组合逻辑中最长延迟为 $d_{\max}$，则必须满足：

$$
P \ge d_{\max}
$$

才能保证每个状态内信号稳定、状态正确转移。这个 $P$ 对所有时钟周期都是一样的，因此：

$$
P_1 = P_2 = \cdots = P_k = P
$$

即各时钟周期长度均匀固定，不会随指令不同而改变。

综合可得：多周期 CPU 是“指令周期数可变，时钟周期长度均匀”，对应 C 选项。

**易错点**：

1. **把“时钟周期数可变”误写成“时钟周期长度可变”**。多周期 CPU 改变的是每条指令占用的周期个数，而不是周期本身的长短。
2. **误选 D**，认为不同指令阶段复杂度不同，所以周期长度也该不同。实际同步数字系统中通常使用单一连续时钟，时钟周期长度固定。
3. **误把多周期 CPU 和单周期 CPU 混淆**。单周期 CPU 是每条指令在一个时钟周期内完成，时钟周期长度必须按最慢指令设置；多周期 CPU 按多个短周期完成，但周期长度统一。
4. **误把多周期 CPU 和流水线混淆**。多周期 CPU 强调一条指令分多步完成，步骤数可变；流水线强调多条指令在不同阶段重叠执行，周期长度也统一。二者不同。

**命题规律**：本题属于计算机组成原理中“CPU 结构”的基础概念题，常与单周期 CPU、流水线 CPU 对比考查。常见变式包括：

- 给出某几条指令，要求计算多周期 CPU 的 CPI；
- 比较单周期、多周期、流水线 CPU 的时钟周期长度与 CPI 大小；
- 结合数据通路考查某条指令在多周期 CPU 中需要几个时钟周期；
- 考查多周期控制器的状态转移：状态数随指令操作码不同而不同。

复习时应重点理解：

$$
\text{CPU 执行时间} = \text{指令条数} \times \text{CPI} \times \text{时钟周期长度}
$$

并区分三种 CPU 设计：

- 单周期：$\text{CPI}=1$，时钟周期长；
- 多周期：$\text{CPI}>1$ 且不同指令不同，时钟周期短且均匀；
- 流水线：理想 $\text{CPI}$ 接近 1，时钟周期长度等于最慢流水段延迟。

7.微程序控制存储器属于 ( ) 的一部分.
(A) 主存
(B) 外存
(C) $CPU$
(D) 缓存

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-54-M07_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。微程序控制存储器存放微程序，属于 CPU 中控制器的一部分。

**解题切入点**：题目直接考查“微程序控制存储器”的物理归属。做题时应先定位到“微程序”这一概念，它属于控制器的实现方式，而不是存储体系中的主存、外存或缓存。

**推演**：  
微程序控制方式的基本思想是：将每条机器指令编写成一个微程序，每个微程序由若干条微指令组成，微指令按顺序存放在一个专门的存储器中。这个存储器称为控制存储器（CS，Control Store），其中存放的微程序由 CPU 中的控制器读取和执行。  
由于微程序控制存储器是控制器实现的关键部件，其访问速度要求很高，通常用 ROM 或可改写的高速存储器实现，位于 CPU 内部，不属于主存、外存或缓存。  
因此，微程序控制存储器属于 CPU 的一部分，选 C。

**易错点**：  
- 误选 A（主存）：主存存放指令和数据，而微程序存放的是更底层的控制信号序列，不直接面向程序员。  
- 误选 D（缓存）：缓存是主存与 CPU 之间的高速缓冲存储器，用来缓解速度差异，不存放微程序。  
- 关键在于分清“控制存储器”和“主存储器”的层次关系：控制存储器属于 CPU 内的控制器，主存则是独立的存储系统。

**命题规律**：  
本题属于计算机组成原理中“控制器设计”的基础概念题。常见变式包括：给出微指令格式判断字段含义、比较硬布线与微程序控制器的优缺点、计算控制存储器容量等。复习时应重点掌握微程序控制器的基本结构、微指令编码方式以及它与硬布线控制器的区别。

# 选择题 第 8 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-57-M08_题目.png|题目]]

8. 下列关于双核技术的叙述中,正确的是 (  )

(A) 双核是指主板上有两个 $CPU$
(B) 双核是利用超线程技术实现的
(C) 双核是指在 $CPU$ 上集成两个运算核心
(D) 双核 $CPU$ 是时间并行的并行计算

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-57-M08_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。双核技术是指在一个物理 CPU 芯片上集成两个独立的运算核心，而不是主板上有两个 CPU，也不是利用超线程技术实现的。

**解题切入点**：这是一道关于处理器体系结构基本概念的题目。拿到题目先抓住“双核”的定义，区分“物理核心”“逻辑处理器”“多 CPU 系统”这几个容易混淆的概念。可以类比为“一个人（物理 CPU）有两只手（两个核心）”，而不是“两个人在同一张桌子上工作（多 CPU）”，也不是“一个人假装有两只手（超线程）”。同时要注意并行计算中“时间并行”和“空间并行”的区别。

**推演**：

1. 逐项分析选项：

   - **选项 A：双核是指主板上有两个 CPU**  
     双核技术是在一个物理 CPU 芯片内集成两个完整的运算核心（core）。如果主板上安装了两个独立的 CPU 芯片，那称为“双处理器系统”（SMP，对称多处理），而不是“双核”。因此 A 错误。

   - **选项 B：双核是利用超线程技术实现的**  
     超线程技术（Hyper-Threading）是在一个物理核心中通过增加寄存器、逻辑控制等资源，使操作系统能同时调度两个线程，本质上是利用空闲执行单元提高利用率，但这两个逻辑处理器共享同一个物理核心的执行资源。双核则是两个物理上独立的运算核心，它们各自拥有独立的执行单元、寄存器、缓存等资源。双核不依赖超线程技术，甚至早期的双核（如 Intel Core 2）并不支持超线程。因此 B 错误。

   - **选项 C：双核是指在 CPU 上集成两个运算核心**  
     这是标准定义，正确。一个物理 CPU 芯片封装内含有两个独立的核心，每个核心都可以独立执行指令，能够真正并行执行多个线程。

   - **选项 D：双核 CPU 是时间并行的并行计算**  
     并行计算中，“时间并行”通常指流水线技术，即多个指令的不同阶段在时间上重叠执行；“空间并行”指多个处理单元在同一时刻各自处理不同任务。双核 CPU 属于空间并行，因为两个核心在同一时刻可以同时执行不同的指令流。即使单个核心内部可能使用流水线（时间并行），但双核强调的是多个核心的“空间并行”。因此 D 错误。

2. 综合判断：只有选项 C 正确。

**易错点**：

- 混淆“多 CPU”与“多核”。多 CPU 是指主板上物理上有多个处理器芯片，多核是指一个芯片内有多个处理核心。两者都属于空间并行，但物理形态不同。
- 混淆“超线程”与“多核”。超线程是单核模拟多个逻辑处理器，不是物理核心；多核是真正的物理核心并行。超线程并不能取代多核，二者可以同时存在（如 Intel 的 Core i7 既有四核又支持超线程）。
- 误选 D 的同学可能以为“双核上多个线程同时运行”就是时间并行，但时间并行强调微观上分时重叠（如流水线、分时复用），空间并行强调同时使用多个独立资源。双核的两个核心是同时工作的，属于空间并行。
- 注意题目问的是“正确的是”，不是“错误的是”，不要因为读题匆忙选错。

**命题规律**：这是计算机组成原理中“处理器体系结构”与“并行计算基础”的送分题，常与超线程、多核、多 CPU、单核多线程等概念结合考查。常见变式包括：  
（1）判断“超线程能否替代多核”；  
（2）区分“时间并行”与“空间并行”的典型例子（流水线是时间并行，多核/多处理器是空间并行）；  
（3）给出具体场景（如一个双核四线程的 CPU），问物理核心数和逻辑处理器数。  
复习时应理清：物理核心数、逻辑处理器数、线程数之间的关系；流水线、超标量、多核、多线程各自属于哪种并行方式；以及它们对性能提升的实际意义。

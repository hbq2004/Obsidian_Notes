# 综合题 第 5 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-53-F05_题目.png|题目]]

5. 某机主要功能部件如下图所示,其中 $M$ 为主存,$MDR$ 为主存数据寄存器,$MAR$ 为主存地址寄存器, $IR$ 为指令寄存器,$PC$ 为程序计数器(并假设当前指令地址在 $PC$ 中),$R_0\sim R_3$ 为通用寄存器,$C$、$D$ 为暂存器.

【图：功能部件框图，包含移位器、ALU、IR、PC、C、D、R0、R1、R2、R3、MDR、M、MAR】

(1) 请补充各部件之间的主要连接线(总线自己画),并注明数据流动方向.
(2) 画出“`ADD(R1),(R2)+`”指令周期流程图,该指令的含义是进行求和运算,源操作数地址在 $R_1$ 中,目标操作数寻址方式为自增型寄存器间接寻址方式(先取地址后加 1),并将相加结果写回 $R_2$ 寄存器.

## 答案

## DeepSeek V4 Flash Max 解析

**答案**：
(1) 各部件之间的主要连接线（补充后）如下：
- 在框图中增设内部数据总线（DB）和内部地址总线（AB）。
- DB 连接：PC、IR、MDR、R₀~R₃、C、D，其中 C、D 仅输入，其余双向；移位器输出接 DB。
- AB 连接：PC、IR(addr)、R₀~R₃ 的输出，经多路选择器后接 MAR 输入；MAR 输出接主存地址线。
- 专用通路：PC→MAR（直接，用于取指）。
- 主存 M：地址线接 MAR，数据线接 MDR（双向）。
- ALU：输入接 C、D，输出接移位器，移位器输出接 DB。
- 所有连线标注数据流向（箭头）。

(2) “ADD (R₁), (R₂)+”指令的周期流程图（微操作序列）如下：
- 取指周期：
   T₁: PC → MAR, Read
   T₂: M(MAR) → MDR, PC+1 → PC
   T₃: MDR → IR
- 执行周期：
   T₄: R₁ → MAR, Read
   T₅: M(MAR) → MDR, R₂ → D
   T₆: MDR → C, R₂ → MAR, Read
   T₇: M(MAR) → MDR, D+1 → R₂
   T₈: MDR → D
   T₉: C + D → R₂
（注：上述微操作假设 PC 自增由专用硬件完成，否则需通过 ALU 增加节拍。）

**解题切入点**：
首先明确指令“ADD (R₁), (R₂)+”的含义：源操作数采用寄存器间接寻址（地址在 R₁），目的操作数采用自增型寄存器间接寻址（先以 R₂ 为地址取操作数，然后 R₂ 自增 1），结果写回 R₂。接着根据框图设计数据通路，确保地址传送与数据传送能高效进行，并注意地址总线与数据总线的分离。最后按时间顺序安排微操作，利用并行性减少节拍，同时避免资源冲突。

**推演**：
1. **数据通路设计（(1)）**  
   为支持指令中的各种传送，设置内部地址总线（AB）和内部数据总线（DB）。AB 专门用于地址传送，将 PC、IR(addr)、通用寄存器的输出送到 MAR；DB 用于数据传送，连接所有寄存器、暂存器、移位器输出。增加 PC→MAR 专用通路以加速取指。ALU 输入来自 C、D，输出经移位器后接 DB。这样，取指时 PC 通过专用通路送 MAR，执行时 R₁、R₂ 通过 AB 送 MAR，同时通过 DB 传送数据。

2. **指令周期流程图（(2)）**  
   - 取指周期：T₁ 送地址并启动读主存；T₂ 接收指令到 MDR 并完成 PC 自增（假设有专用增量器）；T₃ 将指令送 IR。  
   - 执行周期：  
        T₄ 送源操作数地址；  
        T₅ 读源操作数到 MDR，同时将 R₂ 暂存到 D（为自增做准备）；  
        T₆ 将源操作数送 C，同时送目的操作数地址；  
        T₇ 读目的操作数到 MDR，同时将 D 中的 R₂ 加 1 写回 R₂（自增）；  
        T₈ 将目的操作数送 D；  
        T₉ 执行 C + D 并将结果写回 R₂。  
   该序列充分利用 AB 与 DB 的独立性，在 T₅、T₆、T₇ 中实现了并行操作，减少了节拍数。最终结果覆盖自增后的 R₂，符合题目要求。

**易错点**：
- 自增操作与结果写回 R₂ 的顺序：自增必须在取目的操作数地址后立即进行，但结果写回在后，自增值被覆盖，操作仍须执行，不可颠倒。
- 寄存器输出冲突：在 T₆ 中 MDR→C（使用 DB）与 R₂→MAR（使用 AB）可并行，但误认为同一总线则出错。
- 暂存器 C、D 的分配：C 存源操作数，D 先存 R₂（用于自增），后存目的操作数，最后相加，顺序不可混淆。
- 指令周期划分：不可遗漏取指周期，且 PC+1 的时机要正确。

**命题规律**：
本题是计算机组成原理中关于 CPU 数据通路与指令流程的典型题目，常见于 408 考研。考点包括：
- 数据通路的构建：内部总线、地址总线、专用通路的设计。
- 指令执行流程：根据寻址方式确定访存次数和操作序列。
- 微操作时序：考虑资源冲突，利用并行性优化。
- 常见变式：改变指令格式（如不同寻址方式）、增加功能部件（如多总线结构、寄存器写端口）等。  
复习建议：掌握常见数据通路结构（单总线、双总线、多总线），熟练分析指令的微操作序列，并注意画图规范。练习时多做类似习题，如“SUB (R₃), R₁”等，逐步提高。

# 综合题 第 5 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-54-F05_题目.png|题目]]

5. 设 $CPU$ 中各部件及其相互连接关系如下图所示,其中 $W$ 是写控制标志;$R$ 是读控制标志;$R1$、$R2$ 是暂存器.

【图：CPU 各部件连接关系图。左侧为存储器；右侧为 CPU，内含 $W$（写控制标志）、$R$（读控制标志）、微操作命令形成部件、$MAR$、$IR$、$PC$、$MDR$、$ACC$、$R1$、$R2$、$ALU$，各部件通过内部总线相连。】

(1) 写出指令 $ADD\#a$($\#$为立即寻址特征,隐含的操作数在 $ACC$ 寄存器中)在执行阶段所完成的微操作命令及节拍安排.

(2) 假设要求在取指周期实现 $(PC)+1 \rightarrow PC$,且由 $ALU$ 完成此操作($ALU$ 能对它的一个源操作数完成加 1 运算).以最少的节拍写出取指周期全部微操作命令及节拍安排.

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-54-F05_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：  
(1) 执行阶段微操作命令及节拍安排（最少三拍）：  
T1: ACC→R1  
T2: Ad(IR)→R2  
T3: (R1)+(R2)→ACC  
(2) 取指周期微操作命令及节拍安排（最少三拍）：  
T1: PC→MAR, PC→R1, 读存储器（R有效）  
T2: (R1)+1→PC（ALU加1结果送PC）  
T3: MDR→IR  

**解题切入点**  
拿到题目先分析数据通路：图中所有寄存器（PC、MAR、MDR、IR、ACC、R1、R2）均通过内部总线相连，ALU的输入来自暂存器R1、R2，输出连到总线（或直接通过总线驱动）。此类题型本质是“单总线结构下的微操作序列设计”，需根据指令功能确定数据流，并考虑总线冲突，将可并行（不争用总线）的微操作安排在同一节拍，以最少的节拍完成操作。类似算法竞赛中“资源约束下的调度问题”，需在有限资源（总线）下合理安排操作顺序。

**推演**  
### (1) 指令 ADD #a 执行阶段  
- 功能：立即数 a 与 ACC 内容相加，结果送回 ACC。  
- 数据通路：ACC 和 IR 的立即数字段必须通过总线分别送入 R1、R2，然后 ALU 运算，结果经总线送回 ACC。  
- 总线冲突：因为只有一条内部总线，每拍只能有一个源驱动总线，所以 ACC→R1 和 Ad(IR)→R2 不能同时进行，必须分两拍。  
- 节拍安排：  
  - T1: ACC→R1（ACC 输出总线，R1 接收）  
  - T2: Ad(IR)→R2（IR 地址字段输出总线，R2 接收）  
  - T3: (R1)+(R2)→ACC（ALU 执行加法，结果输出总线，ACC 接收）  
  共三拍，无法再减少（除非有额外专用通路，但图中无）。

### (2) 取指周期实现 (PC)+1→PC  
- 子功能：取指令（PC→MAR，读内存，MDR→IR）和 PC+1，且 PC+1 由 ALU 完成（需将 PC 值先送入 R1）。  
- 总线冲突：PC→MAR 与 PC→R1 可同时，因为 PC 输出总线后，MAR 和 R1 均可接收（同一源，多目标）。但 MDR→IR 与 (R1)+1→PC 都需要总线，不能并行。  
- 最少节拍：  
  - T1: PC→MAR, PC→R1, 读存储器（R 有效）——PC 值同时送 MAR 和 R1，并启动读。  
  - T2: (R1)+1→PC（R1 内容经 ALU 加 1，结果输出总线，PC 接收）——PC 更新。  
  - T3: MDR→IR（读完成，MDR 数据经总线送入 IR）。  
  共三拍。若将 T2 与 T3 交换，节拍数不变，仍为三拍；若尝试合并，则总线冲突，故三拍最少。

**易错点**  
1. **总线冲突忽略**：错误地将 ACC→R1 与 Ad(IR)→R2 或 MDR→IR 与 (R1)+1→PC 安排在同一拍，导致总线争用。  
2. **忘记暂存器**：直接使用 ACC 或 PC 作为 ALU 输入，但 ALU 的输入只能来自 R1/R2，必须先传送。  
3. **取指周期遗漏 PC+1**：只考虑取指令而忘记要求中必须实现的 PC+1。  
4. **节拍冗余**：未将 PC→R1 与 PC→MAR 并行，导致多出一拍；或错误地将 PC+1 后的结果暂存到 R1 再送 PC，浪费一拍。  
5. **读命令时序**：误认为读存储器操作需占用总线，实际读命令是控制信号，不占用总线，可与地址传送同拍。

**命题规律**  
- **考点定位**：CPU 指令执行流程、微操作序列设计、单总线数据通路下的操作调度。  
- **常见变式**：不同寻址方式（直接、间接、变址、相对等）的执行阶段微操作；不同指令（如 MOVE、LOAD、STORE、JMP）的微操作；取指周期中 PC+1 的实现方式（专用加法器 vs ALU）。  
- **复习建议**：  
  1. 熟练掌握典型指令（ADD、LOAD、JMP等）在单总线结构中的取指/执行微操作序列。  
  2. 理解“并行不冲突”原则：同一节拍内，多个微操作如果使用不同资源（如总线、ALU、控制信号）或同一源多个目标，可以并行。  
  3. 勤画数据流图，明确每一步使用哪些部件、占用总线与否，从而压缩节拍。  
  4. 结合历年真题（如 2009、2012、2015 等）中的数据通路题，总结常见设计模板。

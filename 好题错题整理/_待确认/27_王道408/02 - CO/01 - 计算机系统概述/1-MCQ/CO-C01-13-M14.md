# 选择题 第 14 题

![[_Attachments/题目识别/27_王道408-题目/CO-C01-13-M14_题目.png|题目]]

14.【2012统考真题】假定基准程序 $A$ 在某计算机上的运行时间为 $100s$，其中 $90s$ 为 $CPU$ 时间，其余为 $I/O$ 时间。若 $CPU$ 速度提高 $50\%$，$I/O$ 速度不变，则运行基准程序 $A$ 所耗费的时间是（ ）.

A. $55s$
B. $60s$
C. $65s$
D. $70s$

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C01-13-M14_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D（$70\mathrm{s}$）。理由：CPU 时间由 $90\mathrm{s}$ 降为 $90/(1+50\%)=60\mathrm{s}$，I/O 时间保持 $10\mathrm{s}$，总耗时为 $60+10=70\mathrm{s}$。

**解题切入点**：拿到题目先不要把总时间 $100\mathrm{s}$ 整体缩放，而要先拆分“可加速部分”和“不可加速部分”。这和算法竞赛中“优化某个函数只能减少该函数的耗时，其他部分耗时不变”是同一个道理。本题中可加速的是 $90\mathrm{s}$ 的 CPU 时间，不可加速的是 $10\mathrm{s}$ 的 I/O 时间。

**推演**：

设原总时间为

$$T_0=100\mathrm{s},$$

其中

$$T_{\text{CPU},0}=90\mathrm{s},\qquad T_{\text{IO}}=10\mathrm{s}.$$

CPU 速度提高 $50\%$，即 CPU 速度变为原来的

$$S=1+50\%=1.5.$$

CPU 执行时间与 CPU 速度成反比，所以新的 CPU 时间为

$$T_{\text{CPU},1}=\frac{T_{\text{CPU},0}}{S}
=\frac{90}{1.5}
=60\mathrm{s}.$$

I/O 速度不变，因此

$$T_{\text{IO},1}=T_{\text{IO}}=10\mathrm{s}.$$

所以总时间为

$$T_1=T_{\text{CPU},1}+T_{\text{IO},1}
=60+10
=70\mathrm{s}.$$

也可以写成 Amdahl 定律的形式。原 CPU 时间占比

$$f=\frac{90}{100}=0.9,$$

不可加速部分占比

$$1-f=0.1,$$

因此

$$T_1
=T_0\left[(1-f)+\frac{f}{S}\right]
=100\left[0.1+\frac{0.9}{1.5}\right]
=100(0.1+0.6)
=70\mathrm{s}.$$

所以正确选项为 D。

**易错点**：

1. 把“CPU 速度提高 $50\%$”误认为“CPU 时间减少 $50\%$”。正确的新 CPU 时间是 $90/(1+50\%)=60\mathrm{s}$，不是 $90\times(1-50\%)=45\mathrm{s}$，否则会错选 A。
2. 只计算新的 CPU 时间 $60\mathrm{s}$，忘记加上不变的 I/O 时间 $10\mathrm{s}$，会错选 B。
3. 对总时间 $100\mathrm{s}$ 直接按加速比缩放，忽略了只有 CPU 部分可加速、I/O 部分不可加速，这不符合 Amdahl 定律。

**命题规律**：本题属于“CPU 性能公式 / Amdahl 定律”的经典考法。408 常给出程序的 CPU 时间、I/O 时间或访存时间占比，再给某部件加速比，求新的总执行时间；变式包括“已知目标加速比，反求 CPU 速度需提高多少倍”“多个部件同时加速”“用 CPI、时钟频率等参数表示 CPU 时间”。复习时应抓住本质：

$$\text{新总时间}=\frac{\text{可加速部分原时间}}{\text{加速比}}+\text{不可加速部分原时间},$$

同时掌握 CPU 性能公式

$$T=\frac{IC\times CPI}{f}.$$

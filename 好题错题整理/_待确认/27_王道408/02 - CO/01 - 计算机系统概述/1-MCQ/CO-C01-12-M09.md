# 选择题 第 9 题

![[_Attachments/题目识别/27_王道408-题目/CO-C01-12-M09_题目.png|题目]]

9. 下列关于各种级别语言的描述中，错误的是（ ）
A. 可用高级语言和低级语言编写出功能等价的程序
B. 低级语言的执行效率一般情况下高于高级语言
C. 机器语言源程序可在机器上直接执行，而高级语言和汇编语言源程序不可以
D. 汇编语言与机器结构无关

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C01-12-M09_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。汇编语言是机器指令的符号化表示，与具体机器的指令系统、寄存器结构和寻址方式密切相关，因此“汇编语言与机器结构无关”说法错误；其余选项说法均正确。

**解题切入点**：拿到本题先抓住三个关键词：语言级别、翻译/执行方式、与硬件的关系。可以类比竞赛做题：同一算法既可以用 C++ 写，也可以用汇编写，但 C++ 要编译成可执行文件，Python 要解释器解释执行，而 CPU 真正直接执行的是机器码。因此判断选项时，只需问自己：该语言是否需要翻译？翻译后的程序是否与具体机器指令集绑定？

**推演**：

计算机程序语言由高到低大致分为高级语言、汇编语言、机器语言。它们之间的关系可表示为：

$$
\text{高级语言源程序}\xrightarrow{\text{编译或解释}}\text{机器语言程序},\qquad
\text{汇编语言源程序}\xrightarrow{\text{汇编}}\text{机器语言程序}.
$$

机器语言程序本身就是由 0/1 指令编码构成的，CPU 取指后由硬件电路直接译码并执行，无需任何翻译软件。

逐项判断：

- A 正确：高级语言和低级语言都能实现相同的算法功能，只是可读性、代码密度和执行性能不同。“功能等价”不要求性能或代码结构等价。
- B 正确：低级语言更贴近硬件，可以直接控制寄存器、内存、标志位等资源，省去高级语言编译/解释带来的额外抽象开销，因此一般情况下执行效率更高。
- C 正确：机器语言形式的程序无需翻译，加载到内存后 CPU 可直接执行；而高级语言和汇编语言源程序必须经过编译/解释/汇编后才能运行。C 中“机器语言源程序”可理解为用机器语言编写的二进制指令程序。
- D 错误：汇编语言是机器语言的助记符表示，不同机器结构有不同的指令系统、寄存器数量和寻址方式，因此汇编语言与机器结构密切相关，而不是无关。

综上，错误项为 D。

**易错点**：

- 误选 C：虽然高级语言如 Python 可以“解释执行”，但解释执行也需要解释器软件逐句翻译，不是 CPU 直接执行源程序；不能把“解释执行”等同于“直接在机器上执行”。
- 误认为 B 错：高级语言经过编译器优化后可能执行很快，但题目说的是“一般情况下”，低级语言通常更接近硬件、效率更高，不能因为个别反例否定 B。
- 误认为 A 错：高级语言和低级语言在功能上是等价的，只是实现方式、性能和可读性不同；不能用“高级语言写起来更抽象”来否定二者可编写功能等价的程序。
- 对 C 中“机器语言源程序”的措辞不必过度纠结，它本质上指用机器语言编写的二进制指令序列，重点是它不需要翻译就能被 CPU 执行。

**命题规律**：本题属于“计算机系统层次结构”的基础考点，主要考查各级语言的特点、翻译方式和执行效率。常见变式包括：

- 将“错误的是”改为“正确的是”；
- 考查编译程序、解释程序、汇编程序的区别；
- 考查汇编语言与指令系统/ISA 的关系，例如“不同 CPU 的汇编语言能否通用”；
- 考查高级语言的可移植性与低级语言的高效率之间的对比。

复习时建议记住一条主线：

$$
\text{高级语言}\xrightarrow{\text{编译/解释}}
\text{汇编语言}\xrightarrow{\text{汇编}}
\text{机器语言}\xrightarrow{\text{CPU 直接执行}}
$$

并重点背诵：汇编语言是机器语言的符号化表示，与机器结构密切相关；机器语言程序无需翻译即可执行。

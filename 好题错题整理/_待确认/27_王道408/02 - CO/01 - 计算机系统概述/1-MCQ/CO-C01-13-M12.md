# 选择题 第 12 题

![[_Attachments/题目识别/27_王道408-题目/CO-C01-13-M12_题目.png|题目]]

12.【2010统考真题】下列选项中,能缩短程序执行时间的措施是 ( )
$I$.提高 $CPU$ 时钟频率     
$II$.优化数据通路结构     
$III$.对程序进行编译优化
(A) 仅 $I$ 和 $II$
(B) 仅 $I$ 和 $III$
(C) 仅 $II$ 和 $III$
(D) $I$、 $II$、 $III$

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C01-13-M12_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。提高 $CPU$ 时钟频率、优化数据通路结构、对程序进行编译优化分别从时钟周期、$CPI$、指令条数等角度缩短程序执行时间，因此三者均有效。

**解题切入点**：拿到题目先回想程序执行时间的经典公式
$$T=IC\times CPI\times \tau=\frac{IC\times CPI}{f}$$
其中 $T$ 为 CPU 执行程序时间，$IC$ 为指令条数，$CPI$ 为每条指令平均时钟周期数，$\tau$ 为时钟周期，$f$ 为时钟频率。然后把每个措施对应到该公式中的某个因子，类似算法竞赛中优化程序：减少数据规模（对应 $IC$）、优化算法常数（对应 $CPI$）、提升机器主频（对应 $f$），都是有效的提速手段。

**推演**：  
CPU 执行程序所需时间可表示为
$$T=IC\times CPI\times \tau=\frac{IC\times CPI}{f}$$

逐项分析：

- **I. 提高 $CPU$ 时钟频率**：提高 $f$ 等价于减小时钟周期 $\tau$。在 $IC$、$CPI$ 不变的情况下，$T$ 会随之减小，因此能缩短程序执行时间。

- **II. 优化数据通路结构**：数据通路是 CPU 内部各部件之间的连接与传输路径。优化数据通路结构，例如改进流水线设计、增加功能部件、减少数据冲突与冒险、缩短关键路径等，可以降低 $CPI$，甚至可能为提高时钟频率创造条件，因此能缩短程序执行时间。

- **III. 对程序进行编译优化**：编译优化可以删除冗余指令、合并操作、优化循环、改进指令调度等，从而减少指令条数 $IC$，或使生成的指令序列更利于流水线执行以降低 $CPI$，因此也能缩短程序执行时间。

综上，$I$、$II$、$III$ 均能缩短程序执行时间，故选 D。

**易错点**：  
1. 误认为提高 $CPU$ 时钟频率一定会因存储速度不匹配而无效，但本题问的是“能缩短程序执行时间”的一般结论，提高 $f$ 确实能缩短 CPU 执行时间。  
2. 误认为只有硬件措施能提速，忽略编译优化属于软件措施，但它同样能减少指令条数或改善流水线性能，从而缩短执行时间。  
3. 忘记使用性能公式，仅凭直觉排除某项。应当始终围绕 $T=IC\times CPI/f$ 判断。  
4. 若题目强调外部 I/O 时间，则提高 CPU 频率未必缩短总时间；但本题语境是 CPU 执行程序时间，标准答案为 D。

**命题规律**：本题直接考查 CPU 性能公式
$$T=IC\times CPI\times \tau=\frac{IC\times CPI}{f}$$
常见变式包括：给出某一优化措施，问它主要影响哪个因子；结合 Amdahl 定律计算加速比；或判断“增加 Cache 容量”“指令流水线”“编译优化”等措施的作用。复习时应熟记性能公式，理解各措施对应的因子，并能区分“缩短 CPU 时间”与“缩短整个系统响应时间”的差异。

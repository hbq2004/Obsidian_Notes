# 选择题 第 4 题

![[_Attachments/题目识别/27_王道408-题目/CO-C01-12-M04_题目.png|题目]]

4. 以下关于计算机各部件功能的叙述中,错误的是 (    )  
A. 运算器 ($ALU$) 仅用来完成算术运算  
B. 存储器用来存放指令和数据  
C. 控制器负责指挥和协调计算机各部件  
D. 输入/输出设备用来完成用户和计算机之间的信息交换

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C01-12-M04_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A。运算器（ALU）不仅能完成算术运算，还能完成逻辑运算，题中“仅用来完成算术运算”说法错误；B、C、D 均为正确叙述。

**解题切入点**：先逐句抠“绝对化”表述。题目问“错误的是”，优先怀疑带有“仅”“只”等限定词的选项。A 中“仅用来完成算术运算”把 ALU 的功能收窄了，而 408 基础中 ALU 的全称是 Arithmetic and Logic Unit，即“算术逻辑单元”，必然还包含逻辑运算。这就像算法竞赛中看到“此算法只在有序数组上有效”时，要立刻检查是否忽略了对无序数据的处理条件。

**推演**：
- A 项：运算器（ALU）是计算机执行算术运算和逻辑运算的主要部件。算术运算包括加、减、乘、除等；逻辑运算包括与、或、非、异或等。因此“仅用来完成算术运算”是错误的。ALU 的英文全称也能直接佐证：Arithmetic Logic Unit。
- B 项：存储器分为主存（内存）和辅存（外存），其基本功能是存放程序（指令）和数据。冯·诺依曼体系结构中，指令和数据都以二进制形式存放在存储器中，故 B 正确。
- C 项：控制器是计算机的指挥中心，负责从存储器中取出指令、分析指令，并根据指令向各部件发出控制信号，协调运算器、存储器、输入/输出设备等工作，故 C 正确。
- D 项：输入设备将用户提供的信息（数据、程序、命令等）转换为计算机可识别的形式送入计算机，输出设备将计算机处理结果转换为用户能理解的形式呈现出来，二者共同完成用户与计算机之间的信息交换，故 D 正确。

综上，只有 A 表述有误。

**易错点**：
1. 误以为 ALU 只做算术运算，忽略逻辑运算。应对策略：牢记 ALU 的英文定义，算术逻辑单元，两类运算都包含。
2. 被“仅”字迷惑，把 A 当作“运算器功能单一”的合理描述。应对策略：遇到限定词立刻警惕，用概念外延检验。
3. 混淆“运算器”与“控制器”的功能，导致 C 项判断失误。应对策略：明确“运算器管算，控制器管指挥协调”。
4. 忽略 D 项中“输入/输出设备”是统称，误以为它只包括键盘和显示器。应对策略：I/O 设备泛指所有输入输出设备，作用是用户与计算机之间的信息交换，该说法没问题。

**命题规律**：本题属于计算机组成原理的基础概念题，直接考查冯·诺依曼体系结构中五大部件（运算器、存储器、控制器、输入设备、输出设备）的功能。常见变式包括：①给出某部件的英文缩写（如 ALU、CU、PC、IR）判断其功能；②将存储器细分为主存/辅存、Cache 等，考查存储层次；③结合指令执行流程，判断各部件在取指、译码、执行阶段的作用。复习时建议以“五大部件功能框图”为主线，熟记各部件核心职责，并对“仅”“只能”“唯一”等绝对化表述保持敏感。

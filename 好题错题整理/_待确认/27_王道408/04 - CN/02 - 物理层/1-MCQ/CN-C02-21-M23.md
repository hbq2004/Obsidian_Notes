# 选择题 第 23 题

![[_Attachments/题目识别/27_王道408-题目/CN-C02-21-M23_题目.png|题目]]

23.【2016统考真题】如下图所示,如果连接 R2 和 R3 链路的频率带宽为 8kHz,信噪比为 30dB,该链路实际数据传输速率约为理论最大数据传输速率的 50%,那么该链路的实际数据传输速率约为（ ）。

【图：两个路由器 R2 与 R3 由一条链路相连】

(A) 8kb/s  
(B) 20kb/s  
(C) 40kb/s  
(D) 80kb/s

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C02-21-M23_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：C。  
由香农公式可得理论最大数据传输速率约为 $80\text{ kb/s}$，实际速率取其 $50\%$，约为 $40\text{ kb/s}$。

**解题切入点**：题目给出“频率带宽”和“信噪比”，立刻定位到香农公式：

$$C = W\log_2(1 + S/N)$$

这就像在算法竞赛中，已知数据规模和时间限制，先求理论上限，再结合实际复杂度常数估计实际运行时间。本题给了“实际速率约为理论最大速率的 $50\%$”，相当于在求出的上限后乘 $0.5$。

**推演**：

1. 带宽单位换算：

$$W = 8\text{ kHz} = 8 \times 10^3\text{ Hz}$$

2. 信噪比换算。信噪比用 dB 表示时是：

$$\text{SNR(dB)} = 10\log_{10}(S/N)$$

题目给出 $30\text{ dB}$，所以：

$$30 = 10\log_{10}(S/N)$$

$$\log_{10}(S/N) = 3$$

$$S/N = 10^3 = 1000$$

3. 由香农公式求理论最大数据传输速率：

$$C = W\log_2(1 + S/N)$$

代入：

$$C = 8 \times 10^3 \times \log_2(1 + 1000)$$

因为 $2^{10}=1024$，所以：

$$\log_2(1001) \approx 10$$

因此：

$$C \approx 8 \times 10^3 \times 10 = 8 \times 10^4\text{ b/s} = 80\text{ kb/s}$$

4. 实际数据传输速率约为理论最大值的 $50\%$：

$$R = 50\% \times C = 0.5 \times 80\text{ kb/s} = 40\text{ kb/s}$$

所以选 **C**。

**易错点**：

- 容易把 $30\text{ dB}$ 直接当成 $S/N=30$。正确的是：
  $$S/N = 10^{30/10} = 1000$$
- 求出理论最大速率 $80\text{ kb/s}$ 后，容易忘记题目还要求“实际速率为理论最大值的 $50\%$”，从而误选 D。
- 注意香农公式中的带宽单位是 Hz，$8\text{ kHz}$ 要写成 $8\times 10^3\text{ Hz}$；不过因为比值关系，若用 kHz 计算得到的是 kb/s，量纲换算要清楚。
- 不要与奈奎斯特公式混淆。奈奎斯特公式需要知道信号电平数，而本题给出的是信噪比，应使用香农公式。

**命题规律**：该题属于 408 计算机网络中“物理层/数据通信基础”的经典考点，核心考查香农公式和 dB 与倍数之间的换算。常见变式包括：改变带宽或信噪比；给出实际利用率；与奈奎斯特公式结合，比较“有无噪声”条件下的最大数据传输速率。复习时应熟练掌握：

$$C = W\log_2(1 + S/N)$$

以及 dB 换算关系：

$$\text{SNR(dB)} = 10\log_{10}(S/N)$$

并注意区分“理论最大速率”和“实际速率”。

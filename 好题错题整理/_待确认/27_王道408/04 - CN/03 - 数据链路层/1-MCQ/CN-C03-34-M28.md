# 选择题 第 28 题

![[_Attachments/题目识别/27_王道408-题目/CN-C03-34-M28_题目.png|题目]]

28.【2019统考真题】对于滑动窗口协议,若分组序号采用3比特编号,发送窗口大小为5,则接收窗口最大是（  ）.

(A) 2

(B) 3

(C) 4

(D) 5

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C03-34-M28_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：B（3）。理由：在滑动窗口协议中，为保证序号不重叠，发送窗口与接收窗口大小之和不超过序号总数，即 $W_S + W_R \le 2^n$，本题 $n=3$，$W_S=5$，故 $W_R \le 2^3 - 5 = 3$，因此接收窗口最大为 3。

**解题切入点**：  
本题核心是滑动窗口协议的序号空间约束。如同算法竞赛中构造辅助函数或数据结构时需确保边界条件不冲突，这里需要找到发送窗口与接收窗口之和与序号总数 $2^n$ 的关系。对于任何滑动窗口协议（如 GBN、SR），为保证接收窗口向前移动后旧序号不会被误认为新序号，必须满足 $W_S + W_R \le 2^n$。抓住这个关键不等式，即可快速定位考点。

**推演**：  
- 分组序号采用 3 比特编号，则序号空间共有 $2^3 = 8$ 个不同序号（$0 \sim 7$）。  
- 设发送窗口大小为 $W_S = 5$，接收窗口大小为 $W_R$（待求最大值）。  
- 滑动窗口协议正常工作的基本条件是：发送窗口与接收窗口的大小之和不超过序号总数，否则会导致接收窗口向前移动后与发送窗口的旧序号重叠，产生二义性。即  
  $$W_S + W_R \le 2^n$$  
  代入 $n=3$，$W_S=5$：  
  $$5 + W_R \le 8 \quad \Rightarrow \quad W_R \le 3$$  
- 因此接收窗口最大可以取 3，此时 $W_S + W_R = 8$，正好占满整个序号空间，但需注意接收窗口大小不能超过发送窗口（对于 SR 协议通常要求 $W_R \le W_S$，这里 $3 \le 5$ 满足），且 $W_R$ 为正整数，故最大为 3。  
- 若 $W_R = 4$，则 $W_S + W_R = 9 > 8$，违反约束，协议无法正确工作。  
- 若协议为 GBN，则接收窗口固定为 1，但题目未指定协议类型，且选项无 1，故按通用约束求解。  

**易错点**：  
1. **混淆协议类型**：误以为题目特指 GBN 或 SR，而 GBN 的接收窗口固定为 1，SR 的发送窗口通常不超过 $2^{n-1}=4$，但本题 $W_S=5$ 已超此限，从而陷入无解或选择 5。应明确本题是通用滑动窗口协议，仅需满足 $W_S+W_R\le 2^n$。  
2. **忽略序号空间限制**：直接认为接收窗口可以等于发送窗口（5），导致选 D。未考虑序号总数有限，必须留出余量防止重叠。  
3. **误用公式**：死记硬背 $W_S \le 2^{n-1}$ 或 $W_S \le 2^n-1$，未抓住本质约束。  

**命题规律**：  
- **考点定位**：滑动窗口协议中序号空间与窗口大小的关系（$W_S+W_R \le 2^n$）。  
- **常见变式**：  
  (1) 给定接收窗口大小，求发送窗口最大值；  
  (2) 给定序号比特数，求满足条件的窗口大小组合；  
  (3) 结合 GBN 或 SR 的特定约束（如 $W_S \le 2^{n-1}$）进行判断。  
- **复习建议**：理解滑动窗口协议避免序号重叠的数学本质，不要死记硬背具体协议的限制，而是掌握通用不等式，并能灵活推导不同协议下的附加条件。

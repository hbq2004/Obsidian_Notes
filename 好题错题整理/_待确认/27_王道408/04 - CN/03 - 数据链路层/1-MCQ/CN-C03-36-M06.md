# 选择题 第 6 题

![[_Attachments/题目识别/27_王道408-题目/CN-C03-36-M06_题目.png|题目]]

6. 以下关于以太网地址的描述,错误的是（  ）

A. 以太网地址就是通常所说的 MAC 地址

B. MAC 地址也称局域网硬件地址

C. MAC 地址是通过域名解析查得的

D. 以太网地址通常存储在网卡中

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C03-36-M06_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：C。域名解析（DNS）得到的是 IP 地址，而 MAC 地址是网卡硬件地址，不能通过域名解析查得。

**解题切入点**：先抓“以太网地址”的本质——它是数据链路层使用的 MAC 地址，与网络层的 IP 地址、应用层的域名是不同层次的概念。可以类比算法竞赛中的“不同数据结构解决不同问题”：域名相当于“用户 ID”，IP 相当于“进程编号”，MAC 地址相当于“物理设备唯一标识”，DNS 是“ID→进程编号”的映射，而不是“ID→物理设备标识”的映射。定位考点后，只需判断每个选项是否把 MAC 地址与 IP 地址混淆即可。

**推演**：  
- 以太网地址即 MAC 地址，长度为 48 位，由 IEEE 分配，通常固化在网卡的 ROM 中，因此 A 正确，D 正确。  
- MAC 地址也称物理地址、硬件地址、局域网地址，它工作在数据链路层，因此 B 正确。  
- 域名解析（DNS）用于将域名映射为 IP 地址，例如 `www.example.com` 解析为 `192.0.2.1`，得到的是网络层地址，而非数据链路层的 MAC 地址。若主机需要获得目的 MAC 地址，需通过 ARP（地址解析协议）根据 IP 地址在局域网内广播查询，而不是通过 DNS。  
因此错误的是 C。

**易错点**：  
1. **混淆 DNS 与 ARP 的功能**：DNS 负责域名→IP 的映射，ARP 负责 IP→MAC 的映射。若题目出现“通过域名解析查得 MAC 地址”，必定错误。  
2. **误认为 MAC 地址是“逻辑地址”**：MAC 地址是物理地址，由网卡厂商烧录，通常不可改变（可软件修改，但硬件地址本质不变）；IP 地址才是网络层逻辑地址。  
3. **忽略层次关系**：以太网地址属于数据链路层，而域名、DNS 属于应用层，IP 属于网络层，跨层概念不能直接相互解析。  
4. **选项 C 的关键词“查得”**：若选项说“通过 ARP 查得”，则正确；说“通过 DNS 查得”则错误。

**命题规律**：  
- 考点：以太网 MAC 地址的特性、MAC 地址与 IP 地址的区别、DNS 与 ARP 的分工。  
- 常见变式：①考查 MAC 地址长度（48 位）与 IP 地址长度（IPv4 32 位、IPv6 128 位）比较；②考查 ARP 协议的作用范围（同一局域网）；③考查 MAC 地址是否可跨网络使用（不可，路由器会改写 MAC 地址）；④结合交换机、路由器工作原理考查地址封装过程。  
- 复习建议：理解 TCP/IP 协议栈各层的地址类型——应用层域名、传输层端口号、网络层 IP 地址、数据链路层 MAC 地址，并掌握 DNS、ARP、DHCP 等协议的功能边界。做此类题时，看到“域名解析”应立刻想到 IP 地址，看到“MAC 地址”应立刻想到网卡与 ARP。

# 选择题 第 27 题

![[_Attachments/题目识别/27_王道408-题目/CN-C03-34-M27_题目.png|题目]]

27.【2018统考真题】主机甲采用停止—等待协议向主机乙发送数据，数据传输速率是 $3\ \mathrm{kb/s}$，单向传播时延是 $200\ \mathrm{ms}$，忽略确认帧的传输时延。当信道利用率等于 $40\%$ 时，数据帧的长度为（ ）.

(A) 240 比特  
(B) 400 比特  
(C) 480 比特  
(D) 800 比特

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C03-34-M27_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：D，数据帧长度为 800 比特时，信道利用率恰好为 40%。

**解题切入点**：首先抓住“停止—等待协议”和“信道利用率”这两个关键词，确定考点是计算信道利用率与帧长的关系。信道利用率公式为 $U = \frac{t_T}{t_T + 2t_p}$（忽略确认帧传输时延），其中 $t_T$ 是数据帧发送时间，$t_p$ 是单向传播时延。这类似于算法竞赛中的资源利用率问题：发送时间好比算法执行时间，传播时延好比等待 I/O 的时间，而信道利用率相当于 CPU 有效工作时间占总时间的比例，需要通过调整“任务大小”（帧长）来达到目标利用率。

**推演**：  
已知数据传输速率 $R = 3\ \mathrm{kb/s} = 3000\ \mathrm{bps}$，单向传播时延 $t_p = 200\ \mathrm{ms} = 0.2\ \mathrm{s}$，忽略确认帧的传输时延。设数据帧长度为 $L$ 比特，则发送时间 $t_T = \frac{L}{R}$。  
停止—等待协议的信道利用率（忽略确认帧发送时间）为  
$$U = \frac{t_T}{t_T + 2t_p} = \frac{L/R}{L/R + 2t_p}.$$  
代入 $U = 40\% = 0.4$：  
$$\frac{L/R}{L/R + 2t_p} = 0.4.$$  
解方程：  
$$\frac{L}{R} = 0.4 \left( \frac{L}{R} + 2t_p \right) = 0.4\frac{L}{R} + 0.8t_p,$$  
$$0.6\frac{L}{R} = 0.8t_p \quad\Rightarrow\quad \frac{L}{R} = \frac{0.8}{0.6}t_p = \frac{4}{3}t_p,$$  
$$L = \frac{4}{3} R t_p = \frac{4}{3} \times 3000 \times 0.2 = \frac{4}{3} \times 600 = 800\ \mathrm{比特}.$$  
因此数据帧长度为 800 比特，对应选项 (D)。

**易错点**：  
1. 单位混淆：误将 $3\ \mathrm{kb/s}$ 当作 $3 \times 1024\ \mathrm{bps}$ 或 $3 \times 10^3\ \mathrm{bps}$ 时得出不同结果，需明确计算机网络中 $k=10^3$。  
2. 时延转换错误：将 $200\ \mathrm{ms}$ 直接当作 $200\ \mathrm{s}$ 或忘记换算成 $0.2\ \mathrm{s}$。  
3. 忘记乘以 2：传播时延是往返时间（$2t_p$），若只计算单向则导致结果偏小。  
4. 公式误用：若错误引入确认帧发送时间（虽题目已忽略），或误将信道利用率定义为 $t_T/(t_T + t_p)$，都会得到错误答案。  
**规避方法**：牢记停止—等待协议中信道利用率的标准公式，统一单位（秒、比特/秒），仔细检查每一步计算。

**命题规律**：  
- **考点定位**：停止—等待协议的信道利用率计算，是 408 计算机网络中数据链路层的基础考点，常与传播时延、发送速率、帧长结合出题。  
- **常见变式**：  
  ① 考虑确认帧的发送时间（非忽略）时，公式变为 $U = \frac{t_T}{t_T + t_A + 2t_p}$。  
  ② 采用滑动窗口协议（如 GBN、SR）时，需考虑窗口大小对利用率的影响。  
  ③ 给出目标利用率求帧长，或给出帧长求利用率，甚至结合信道带宽、帧序号等。  
- **复习建议**：熟练掌握利用率公式的推导，理解“发送时间”与“空闲时间”的构成；注意单位换算（$1\ \mathrm{kb/s}=10^3\ \mathrm{b/s}$，$1\ \mathrm{ms}=10^{-3}\ \mathrm{s}$）；多做类似题目，特别是 2018 年真题及其变式，以巩固对停止—等待协议和滑动窗口协议的理解。

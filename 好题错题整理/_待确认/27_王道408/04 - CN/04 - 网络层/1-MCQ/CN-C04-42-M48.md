# 选择题 第 48 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-42-M48_题目.png|题目]]

48. 下列关于 $ICMP$ 报文的说法中,错误的是（ ）

(A) $ICMP$ 报文封装在数据链路层帧中发送

(B) $ICMP$ 报文可以用于报告 $IP$ 数据报发送错误

(C) $ICMP$ 报文封装在 $IP$ 数据报中发送

(D) 对于已经携带 $ICMP$ 差错报文的分组,不再产生 $ICMP$ 差错报文

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-42-M48_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：A。ICMP 报文必须封装在 IP 数据报中发送，而不是直接封装在数据链路层帧中，故 A 错误。  
**解题切入点**：首先抓住 ICMP 协议的网络层定位，其报文作为 IP 数据报的数据部分传输，类似算法竞赛中构造辅助数据结构（如哈希表）来高效完成任务，而分层协议则对应分治思想，每一层只关注本层封装。  
**推演**：  
- 选项 A：ICMP 报文作为网络层协议的数据单元，必须首先封装在 IP 数据报中（即作为 IP 数据报的数据部分），然后 IP 数据报再封装在数据链路层帧中发送，因此“ICMP 报文封装在数据链路层帧中发送”的说法跳过了 IP 层，是错误的。  
- 选项 B：ICMP 的主要功能是报告 IP 数据报在传输过程中的错误，如目的不可达、超时等，因此该说法正确。  
- 选项 C：ICMP 报文直接作为 IP 数据报的数据部分，封装在 IP 数据报中发送，这是标准描述，正确。  
- 选项 D：为防止 ICMP 差错报文无限循环，规定对携带 ICMP 差错报文的分组不再产生新的 ICMP 差错报文，该说法正确。  
综上，错误选项为 A。  
**易错点**：混淆封装层次，认为 ICMP 报文直接封装在帧中而忽略 IP 层；实际上，ICMP 属于网络层，其报文必须经过 IP 封装。  
**命题规律**：考点为 ICMP 协议的封装格式与功能特性，常以选择题形式考查，类似变式包括 ICMP 差错报告机制、ICMP 与 IP 的关系等。复习时应重点记忆 ICMP 报文作为 IP 数据报的负载，并理解其差错控制规则。

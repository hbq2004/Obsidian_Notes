# 选择题 第 21 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-44-M21_题目.png|题目]]

21. 从数据封装的角度看，下列（ ）协议属于 TCP/IP 参考模型的应用层.

$I.$ OSPF

$II.$ RIP

$III.$ BGP

$IV.$ ICMP

(A) $I$、$II$

(B) $II$、$III$

(C) $I$、$IV$

(D) $I$、$II$、$III$、$IV$

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-44-M21_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：B（II、III）。  
一句话理由：从数据封装角度看，RIP 报文封装在 UDP 数据报中，BGP 报文封装在 TCP 报文段中，二者属于应用层；而 OSPF、ICMP 都直接封装在 IP 数据报中，属于网络层。

**解题切入点**：题目关键词是“数据封装角度”，因此不要按“功能”或“路由协议”想当然，而要看**协议数据单元（PDU）被谁的头部封装**。这类似于算法竞赛中构造分层数据结构：应用层数据是“负载”，交给传输层打包；传输层再交给网络层打包。ICMP、OSPF 这种网络层协议则相当于“自己就是内核逻辑”，直接放在 IP 分组里，不经过传输层。先定位每类协议在 TCP/IP 协议栈中的封装位置，立马能排除干扰项。

**推演**：TCP/IP 参考模型自下而上为：

网络接口层 $\rightarrow$ 网际层 $\rightarrow$ 传输层 $\rightarrow$ 应用层。

数据封装时，上层协议的数据作为下层协议的载荷，逐层加上头部。逐个判断：

1. **OSPF（I）**：开放最短路径优先，是内部网关路由协议。OSPF 报文直接封装在 IP 数据报中，IP 头部中协议字段为 89。因此 OSPF 属于**网际层**，不是应用层。

2. **RIP（II）**：路由信息协议，基于 UDP 传输，端口号为 520。RIP 报文先作为 UDP 数据报的数据部分，加上 UDP 头部后再封装进 IP 数据报：
   $$
   \text{RIP 报文} \rightarrow \text{UDP 数据报} \rightarrow \text{IP 数据报} \rightarrow \text{帧}
   $$
   因此从封装角度看，RIP 属于**应用层**。

3. **BGP（III）**：边界网关协议，基于 TCP 传输，端口号为 179。BGP 报文先作为 TCP 报文段的数据部分，加上 TCP 头部后再封装进 IP 数据报：
   $$
   \text{BGP 报文} \rightarrow \text{TCP 报文段} \rightarrow \text{IP 数据报} \rightarrow \text{帧}
   $$
   因此 BGP 也属于**应用层**。

4. **ICMP（IV）**：网际控制报文协议，ICMP 报文直接封装在 IP 数据报中，作为 IP 层自身的一部分，用于差错报告和网络诊断。它不经过 TCP/UDP，因此属于**网际层**，不是应用层。

综上，属于应用层的是 II、III，所以选 **B**。

**易错点**：

- **误以为所有路由协议都在同一层**：OSPF 属于网际层，RIP 和 BGP 属于应用层。注意“路由协议”不等于“网络层协议”，关键看它基于什么封装。
- **误以为 ICMP 属于应用层**：`ping`、`traceroute` 是应用命令，但它们调用的是 ICMP，而 ICMP 报文直接封装在 IP 数据报中，属于网际层。
- **忽略“数据封装”这一限定条件**：如果按功能用途判断，可能误选 OSPF；但题目要求从封装角度分析，必须看 PDU 位置。
- **混淆 TCP/IP 模型与 OSI 模型**：在 TCP/IP 参考模型中，RIP、BGP 均属于应用层；而在 OSI 模型中讨论时需另按 OSI 分层，但本题明确指定 TCP/IP 模型。

**命题规律**：本题是 408 计算机网络中“TCP/IP 分层结构”的经典考题，重点考查各层典型协议及其封装关系。常见变式有：  
- 问“直接封装在 IP 数据报中的协议有哪些”（如 ICMP、IGMP、OSPF）。  
- 问“基于 TCP/UDP 的应用层协议有哪些”（如 RIP、DNS、DHCP、BGP）。  
- 结合协议端口号或 IP 协议号进行辨析。

复习建议：建立“封装层次表”，分别记住：  
- **网络层协议**：IP、ICMP、IGMP、OSPF；  
- **传输层协议**：TCP、UDP；  
- **应用层协议**：HTTP、DNS、RIP、BGP、DHCP、FTP、SMTP 等。  
同时记住关键端口号与协议字段，做题时先定位“被谁封装”，再确定层属，即可快速得分。

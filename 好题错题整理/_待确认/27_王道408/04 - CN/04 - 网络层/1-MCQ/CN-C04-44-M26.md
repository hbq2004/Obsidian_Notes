# 选择题 第 26 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-44-M26_题目.png|题目]]

26.【2017统考真题】直接封装RIP、OSPF、BGP报文的协议分别是（  ）
(A) TCP、UDP、IP
(B) TCP、IP、UDP
(C) UDP、TCP、IP
(D) UDP、IP、TCP

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-44-M26_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：D。RIP 报文直接封装在 UDP 中，OSPF 报文直接封装在 IP 中，BGP 报文直接封装在 TCP 中，因此选 D。

**解题切入点**：拿到题目先抓“直接封装”三个字，即问某个路由协议的报文是作为哪一层协议的载荷。这相当于在算法竞赛中，先判断你要调用的“API 层级”：RIP 像“无连接 UDP 广播”，OSPF 像“raw socket 直接操作 IP 包”，BGP 像“建立 TCP 长连接可靠通信”。不要一看到路由协议就想“都走 TCP/IP”，而是要分别记住它们使用的传输层/网络层承载机制。

**推演**：

- RIP 基于距离向量算法，实现简单，周期性地交换路由表，不要求复杂的可靠传输和拥塞控制，因此直接使用 UDP 封装，端口号为 520。所以 RIP 直接封装在 UDP 中。

- OSPF 基于链路状态算法，需要快速收敛、支持组播发送链路状态更新，它不使用 TCP 或 UDP，而是直接封装在 IP 数据报中，IP 协议号字段为 89。OSPF 报文直接作为 IP 数据报的载荷，使用组播地址 224.0.0.5 和 224.0.0.6。所以 OSPF 直接封装在 IP 中。

- BGP 用于自治系统之间的路由信息交换，路由信息量大且要求可靠、有序、不丢失，因此直接使用 TCP 作为传输层协议，端口号为 179。BGP 报文作为 TCP 报文段的载荷。所以 BGP 直接封装在 TCP 中。

因此对应关系为：

$$
\text{RIP} \to \text{UDP},\qquad \text{OSPF} \to \text{IP},\qquad \text{BGP} \to \text{TCP}
$$

选 D。

**易错点**：

- 容易把 BGP 和 OSPF 的承载方式记反。BGP 是跨自治系统的路径向量协议，必须用 TCP 保证可靠；OSPF 是域内链路状态协议，直接封装在 IP 中，协议号为 89。
- 容易误以为“所有路由协议最终都要封装成 IP 包，所以都选 IP”。但题目问的是“直接封装”，OSPF 的直接上层是 IP，而 RIP 的直接上层是 UDP，BGP 的直接上层是 TCP。
- 记忆端口/协议号时注意区分：RIP 用 UDP 520，BGP 用 TCP 179，OSPF 用 IP 协议号 89，不是 TCP/UDP 端口号。
- 不要混淆：TCP、UDP 都是传输层协议，IP 是网络层协议；OSPF 虽然“直接封装在 IP 中”，但仍然属于应用层/路由协议范畴。

**命题规律**：408 中常考三大动态路由协议 RIP、OSPF、BGP 的基本特征，包括算法类型、封装协议、端口/协议号、适用范围、度量值等。常见变式有：问“某协议使用什么端口号”“OSPF 组播地址是多少”“BGP 为什么使用 TCP”“RIP 为什么使用 UDP”等。复习时建议列表横向对比：RIP（距离向量、UDP 520、适合小型自治系统内部）、OSPF（链路状态、IP 协议号 89、适合大型企业内部）、BGP（路径向量、TCP 179、适合自治系统之间）。将协议栈封装关系与端口号、协议号一起记忆，能快速应对此类选择题。

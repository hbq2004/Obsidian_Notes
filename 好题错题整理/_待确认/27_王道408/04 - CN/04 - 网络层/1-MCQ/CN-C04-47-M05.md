# 选择题 第 5 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-47-M05_题目.png|题目]]

5. 路由器主要实现（\_）的功能。

(A) 数据链路层、网络层与应用层
(B) 网络层与传输层
(C) 物理层、数据链路层与网络层
(D) 物理层与网络层

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-47-M05_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：C。路由器作为网络层设备，其“主要实现”的功能是物理层、数据链路层与网络层三层功能；它需要处理物理信号、帧的封装/解封装，并在网络层完成 IP 分组的转发。

**解题切入点**：拿到题目先抓住“路由器”这个关键设备，立刻定位到“网络层设备”这一考点。就像算法竞赛里，你想在一个复杂的链表上做查找，不能只盯着“值”本身，还必须能处理前后指针、节点结构等底层信息；分层协议也是同理：路由器做 IP 转发相当于“查路由表”，但要从物理层收比特流、从数据链路层取出帧、再解出网络层分组。所以不能只选“网络层”，而要选包含下三层的选项。

**推演**：

路由器的主要任务是：接收来自一个网络的 IP 分组，根据目的 IP 地址查找路由表，确定下一跳，再转发到另一个网络。这个“查表转发”的核心过程发生在网络层。但路由器要真正完成转发，必须逐层处理数据：

1. 物理层：接收和发送比特流，完成信号的恢复与发送；
2. 数据链路层：从物理层收到的比特流中识别帧边界，进行差错检验，解封装得到 IP 分组；发送时也要将 IP 分组封装成帧；
3. 网络层：解析 IP 分组头，提取目的 IP 地址，查路由表，决定转发端口。

因此，路由器至少要实现：

$$
\text{物理层} \to \text{数据链路层} \to \text{网络层}
$$

三个层次的功能。

逐项排除：

- A 含应用层。路由器一般不解析 HTTP、FTP、DNS 等应用层报文，不对“端到端进程通信”负责，因此错误。
- B 只含网络层与传输层，缺物理层和数据链路层，且传输层不是路由器的主要功能，因此错误。
- D 含物理层与网络层，缺少数据链路层。若没有数据链路层，路由器无法从比特流中恢复出完整的帧，也就无法取得网络层分组，因此错误。

所以正确选项为 C。

**易错点**：

1. **误以为“工作在网络层”就等于“只实现网络层”**。路由器是第三层设备，但其物理结构和协议栈必须实现下三层，否则无法接收或发送帧。
2. **误选 D**：只强调物理层和网络层，却忽略了数据链路层。没有数据链路层的帧同步与解封装，IP 分组无法被正确提取。
3. **误选 A 或 B**：传输层和应用层属于端系统（主机）的层次，路由器主要不解析 TCP/UDP 端口或应用层数据。考研中默认传统路由器不实现这些层。
4. **与交换机/集线器混淆**：集线器主要工作在物理层，交换机主要工作在数据链路层，路由器主要工作在网络层；但路由器为了实现转发，必须实现下三层。

**命题规律**：本题属于“网络设备与层次对应关系”的经典送分题，常与集线器、交换机、路由器一起考查，也可能换问法：“下列哪个设备实现物理层、数据链路层和网络层的功能？”或“IP 协议对应的层次是？”。复习时应熟记 OSI/五层模型中每一层的典型设备、典型协议与封装关系，并特别注意“设备主要实现哪几层”和“设备工作在哪一层”的区别。

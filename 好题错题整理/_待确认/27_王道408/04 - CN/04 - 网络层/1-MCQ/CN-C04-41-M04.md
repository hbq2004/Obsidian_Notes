# 选择题 第 4 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-41-M04_题目.png|题目]]

4. 在互联网中，一个路由器的路由表通常包含（ ）

(A) 目的网络和到达目的网络的完整路径

(B) 所有目的主机和到达该目的主机的完整路径

(C) 目的网络和到达该目的网络路径上的下一个路由器的 IP 地址

(D) 目的网络和到达该目的网络路径上的下一个路由器的 MAC 地址

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-41-M04_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：C。路由表的基本表项是“目的网络 + 下一跳路由器 IP 地址”，而不是完整路径或 MAC 地址。

**解题切入点**：看到“路由表”立刻想到网络层分组转发模型：路由器按目的 IP 地址的网络前缀进行最长前缀匹配，查表得到下一跳 IP。可以类比算法竞赛中在图上跑最短路：每个点（路由器）并不保存到所有点的整条路径，只保存“下一个要走的点”，也就是前驱/后继指针；完整路径是边迭代边回溯拼出来的。另一个类比：分层协议就像分布式递归分治，每层只解决本层接口问题，路由表就是本层的状态/转移表。

**推演**：
- 互联网使用 IP 地址，路由器工作在第三层（网络层）。IP 分组的目标地址是主机 IP，但该地址在网络层被分成“网络号 + 主机号”两层（无分类编址下是前缀 + 主机位）。
- 一个路由器不可能也没必要保存每个目的主机的完整路径，因为：
  1. 目的主机数量极大，表项爆炸。
  2. 网络拓扑动态变化，完整路径无法全局一致维护。
  3. 分组转发是逐跳完成的，每个路由器只需知道把分组交给哪个下一跳路由器，链路上再以 MAC 地址封装成帧。
- 因此路由表典型表项为：
  - 目的网络/前缀（含掩码或前缀长度）；
  - 下一跳路由器的 IP 地址；
  - 输出接口（有时还含度量值）。
- 题中：
  - A：“目的网络 + 完整路径”错，路径由各路由器分布式维护，路由表中不存完整路径。
  - B：“所有目的主机 + 完整路径”错，目的主机不是网络级路由依据，而且完整路径也不需要。
  - C：“目的网络 + 下一跳路由器 IP 地址”正确。
  - D：“目的网络 + 下一跳 MAC 地址”错，MAC 地址只在同一个数据链路（局域网段）内用于帧的封装和寻址；当分组跨网段时，每经过一条链路，帧的 MAC 地址都会被重写。路由表中既不可能也不需要全局存储 MAC 地址。若要找下一跳 MAC，也需要先通过 ARP 根据下一跳 IP 解析获取。

**易错点**：
- 错选 D：混淆网络层“下一跳 IP”和数据链路层“下一跳 MAC”。注意：路由器转发 IP 分组时先查路由表得到下一跳 IP，再结合输出接口的 ARP 表得到对应 MAC 地址封装帧。路由表不直接存 MAC。
- 错选 B：认为路由表要记录每个主机。实际上路由按目的网络聚合，使用网络前缀而非主机地址。
- 错选 A：认为路由器知道完整路径。互联网是逐跳转发，每个路由器只维护去往目的网络的一跳信息，完整路径是各跳合作形成的，不是某张表存下来的。

**命题规律**：
- 考点定位：网络层设备工作原理——路由表的基本组成与逐跳转发。
- 常见变式：给出具体路由表，要求根据目的 IP 地址选择下一跳（最长前缀匹配）；或与 ARP、MAC 地址封装结合，考查“查路由表得知下一跳 IP，再通过 ARP 得到 MAC”的流程。
- 复习建议：把“网络层 IP 转发”和“数据链路层帧转发”分开理解；记住路由器转发依据是目的网络（前缀），不是完整路径，也不是 MAC；可以画一条跨路由器路径，标注每跳的路由表项和帧 MAC 变化。

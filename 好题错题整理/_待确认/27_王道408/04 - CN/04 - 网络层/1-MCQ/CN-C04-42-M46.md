# 选择题 第 46 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-42-M46_题目.png|题目]]

46. 可以动态为主机配置 $IP$ 地址的协议是（ ）.
(A) $ARP$
(B) $RARP$
(C) $DHCP$
(D) $NAT$

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-42-M46_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：C。DHCP（动态主机配置协议）可为主机动态分配 IP 地址，而 ARP 用于地址解析、RARP 用于反向地址解析、NAT 用于地址转换。  
**解题切入点**：拿到题目先抓关键词“动态”“为主机配置 IP 地址”，直接定位到网络层/应用层中的地址配置协议。这就像做算法题时，先看输入输出条件：题目要求“动态分配 IP”，相当于一个“自动分配资源”的调度器，而不是“查表映射”或“地址翻译”。ARP 是“IP→MAC 的查表映射”，RARP 是“MAC→IP 的反向查表映射”，NAT 是“内网地址↔公网地址的翻译/重写”，只有 DHCP 是真正的“动态配置/分配”协议。  
**推演**：  
逐项分析各协议的功能：

- **ARP（Address Resolution Protocol，地址解析协议）**：根据已知的 IP 地址，通过广播请求解析出对应的 MAC 地址。它解决的是“已知 IP，求 MAC”的映射问题，不负责分配 IP 地址。
- **RARP（Reverse Address Resolution Protocol，反向地址解析协议）**：根据已知的 MAC 地址，向 RARP 服务器请求对应的 IP 地址。虽然它能为无盘工作站获取 IP，但它需要事先配置静态映射表，且只能“查表获取”固定 IP，不能动态分配和管理地址，现已基本被 DHCP 取代。
- **DHCP（Dynamic Host Configuration Protocol，动态主机配置协议）**：基于 UDP，采用客户/服务器模式。DHCP 服务器从地址池中动态分配 IP 地址、子网掩码、默认网关、DNS 等参数给主机，支持租约、续租和释放，完全符合“动态为主机配置 IP 地址”的描述。
- **NAT（Network Address Translation，网络地址转换）**：主要用于将私有 IP 地址转换为公网 IP 地址，以解决 IPv4 地址短缺问题。它修改 IP 报文中的源/目的地址，不负责给主机配置 IP。

因此，唯一正确选项是 C：DHCP。  
**易错点**：  
1. 误选 B（RARP）：RARP 虽然也能让主机获得 IP，但它是基于静态映射表的“反向解析”，不是“动态配置”，且不能分配子网掩码、网关等参数。  
2. 误选 A（ARP）：ARP 解决的是“IP→MAC”的映射，与“配置 IP”完全无关，属于概念混淆。  
3. 误选 D（NAT）：NAT 是地址转换/重写，不是地址分配；它不改变主机自身的 IP 配置，只是路由器在转发时改写地址。  
4. 规避方法：牢记经典口诀——ARP 查 MAC，RARP 查 IP（静态），DHCP 发 IP（动态），NAT 换地址。  
**命题规律**：  
考点定位：TCP/IP 协议栈中网络层及周边协议的功能区分，属于 408 计算机网络的基础概念题，常以单选形式出现。  
常见变式：  
- 与“无盘工作站启动时获取 IP”结合，考查 DHCP 与 RARP 的对比；  
- 与“IP 地址配置方式”结合，考查手工配置 vs DHCP；  
- 与“NAT 与 DHCP 协同工作”结合，考查家庭路由器如何同时完成地址分配与地址转换。  
复习建议：对比记忆各协议所在层次、端口号、工作方式和典型应用场景。重点掌握 DHCP 的四步交互过程（发现、提供、请求、确认）以及租约机制，并注意区分 DHCP 属于应用层协议（基于 UDP 67/68 端口），但服务于网络层 IP 地址配置。

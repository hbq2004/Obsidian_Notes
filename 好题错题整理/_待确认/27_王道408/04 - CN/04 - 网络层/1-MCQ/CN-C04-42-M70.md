# 选择题 第 70 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-42-M70_题目.png|题目]]

70.【2023统考真题】主机 168.16.84.24/20 所在子网的最小可分配 IP 地址和最大可分配 IP 地址分别是（ ）

(A) 168.16.80.1, 168.16.84.254
(B) 168.16.80.1, 168.16.95.254
(C) 168.16.84.1, 168.16.84.254
(D) 168.16.84.1, 168.16.95.254

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-42-M70_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：B（最小可分配IP地址为168.16.80.1，最大可分配IP地址为168.16.95.254）。  
**解题切入点**：先看网络前缀长度 `/20`，确定子网掩码，然后将 IP 地址与子网掩码按位与得到网络地址，再确定广播地址，即可得可分配 IP 范围。这类似于在算法竞赛中给定一个范围（如数组区间），通过掩码（类似位运算）快速定位块（分块）的起始和结束。  
**推演**：IP 地址 $168.16.84.24/20$，子网掩码前 20 位为 1，后 12 位为 0，即 $255.255.240.0$。将 IP 地址与子网掩码逐位与运算：  
- 前 16 位（$168.16$）不变。  
- 第三字节：$84$ 与 $240$，$84$ 的二进制 $01010100$，$240$ 的二进制 $11110000$，得 $01010000$ 即 $80$。  
- 第四字节：$24$ 与 $0$ 得 $0$。  
故网络地址为 $168.16.80.0/20$。  
主机部分 12 位，广播地址将主机位置 1，即第三字节后 4 位全 1 得 $01011111=95$，第四字节全 1 得 $255$，广播地址为 $168.16.95.255$。  
可分配 IP 地址范围为 $[168.16.80.1, 168.16.95.254]$。  
**易错点**：1. 误认为 IP 地址的第三字节 $84$ 就是子网起点，忽略掩码为 $240$，实际网络位由前 4 位决定。2. 计算广播地址时未将主机位全置 1，可能得到 $84.255$ 等错误结果。3. 混淆最小可分配 IP 与网络地址，忘记加 1。规避方法：严格按位运算，画出二进制。  
**命题规律**：常考给定前缀长度，求子网可分配 IP 范围。变式：给子网掩码，求指定主机所在子网；或给定子网划分，求子网地址等。复习建议：熟练掌握 IP 地址与子网掩码的二进制转换和与运算，熟悉网络地址、广播地址、可用地址范围的计算。

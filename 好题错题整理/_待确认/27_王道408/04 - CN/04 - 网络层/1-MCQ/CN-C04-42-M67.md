# 选择题 第 67 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-42-M67_题目.png|题目]]

67.【2022统考真题】若某主机的 IP 地址是 183.80.72.48,子网掩码是 255.255.192.0,则该主机所在网络的网络地址是（ ）

(A) 183.80.0.0
(B) 183.80.64.0
(C) 183.80.72.0
(D) 183.80.192.0

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-42-M67_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：B。主机所在网络的网络地址等于 IP 地址与子网掩码按位与的结果，计算得 183.80.64.0。

**解题切入点**：看到 IP 地址和子网掩码，立即想到网络地址 = IP 地址 & 子网掩码（按位与），这是 IP 子网划分的基本运算，类似算法竞赛中用位掩码提取或过滤特定比特位（如用 `x & mask` 取出标志位）。本题子网掩码不是标准类掩码，需仔细做二进制与。快速定位考点：子网编址与网络地址计算。

**推演**：  
将 IP 地址 183.80.72.48 和子网掩码 255.255.192.0 分别转为二进制：

- IP 地址：  
  183 → 10110111₂，80 → 01010000₂，72 → 01001000₂，48 → 00110000₂  
  即 10110111.01010000.01001000.00110000

- 子网掩码：  
  255 → 11111111₂，255 → 11111111₂，192 → 11000000₂，0 → 00000000₂  
  即 11111111.11111111.11000000.00000000

按位与（$1\&1=1$，其余为 $0$）：

- 第一段：10110111₂ & 11111111₂ = 10110111₂ → 183  
- 第二段：01010000₂ & 11111111₂ = 01010000₂ → 80  
- 第三段：01001000₂ & 11000000₂ = 01000000₂ → 64  
- 第四段：00110000₂ & 00000000₂ = 00000000₂ → 0  

合并得网络地址为 183.80.64.0，对应选项 (B)。

**易错点**：  
1. 粗心把子网掩码 255.255.192.0 误当成 /16 或 /24，直接取前两段或前三段得 183.80.0.0 或 183.80.72.0。  
2. 第三段按位与时忘记 192 是 11000000₂，误将 72（01001000₂）全保留得 72（即 01001000₂ & 11000000₂ 正确应为 01000000₂ = 64）。  
3. 混淆网络地址与广播地址，或误用默认类掩码（B 类默认 255.255.0.0 得 183.80.0.0）。  
**规避方法**：每次先写二进制，逐段按位与，或记住子网掩码指明网络位和主机位，直接计算。

**命题规律**：  
必考基础计算，常以选择题形式给出 IP 与掩码求网络地址、广播地址、主机数量等。变式包括：掩码非连续（极少）、求子网划分、判断是否同一子网。复习建议：熟练掌握二进制与、十进制转换，理解 CIDR 表示法。可类比位运算掩码（如 `x & 0xFFFFFF00` 取高 24 位），加深印象。

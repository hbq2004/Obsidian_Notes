# 选择题 第 3 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-45-M03_题目.png|题目]]

3. 以太网多播 IP 地址 224.215.145.230 应该映射到的多播 MAC 地址是（ ）

A. 01-00-5E-57-91-E6

B. 01-00-5E-D7-91-E6

C. 01-00-5E-5B-91-E6

D. 01-00-5E-55-91-E6

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-45-M03_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：A。`224.215.145.230` 的低 23 位是 `0x5791E6`，拼接以太网多播 MAC 前缀 `01-00-5E` 后得到 `01-00-5E-57-91-E6`。

**解题切入点**：拿到题目先定位考点：IPv4 多播地址到以太网多播 MAC 地址的映射。这本质上像一个位运算题：从 32 位 IP 地址中取出低 23 位，再拼上固定前缀 `01-00-5E`。相当于算法题里的 `ans = base | (ip & mask)`，`mask` 就是低 23 位掩码 `0x7FFFFF`。协议分层在这里很像“分治”：网络层只把必要的 23 位交给数据链路层封装，而不是把整个 IP 都传下去。

**推演**：

1. 标准映射规则：  
   以太网为 IPv4 多播保留的 MAC 前缀是 `01-00-5E`。MAC 地址后 24 位中，最高位固定为 0，只有低 23 位用于存放 IP 多播地址的低 23 位。

2. 将 IP 地址写成二进制：
   $$
   224.215.145.230 \Rightarrow 11100000\;11010111\;10010001\;11100110{}_2
   $$

3. 取最低 23 位：
   $$
   1010111\;10010001\;11100110
   $$
   补一个前导 0 后按十六进制分组：
   $$
   0101\;0111\;1001\;0001\;1110\;0110{}_2 = 0x5791E6
   $$

   也就是：
   - $215 = 0xD7$，但只取低 7 位，得到 $0x57$；
   - $145 = 0x91$；
   - $230 = 0xE6$。

4. 拼接前缀：
   $$
   01\text{-}00\text{-}5E\text{-}57\text{-}91\text{-}E6
   $$

   因此正确选项是 A。

**易错点**：

- 最容易错选 B：直接把 `215 = 0xD7` 放入 MAC 第四字节，写成 `01-00-5E-D7-91-E6`。但标准映射要求 MAC 后 24 位最高位为 0，所以只能取 $0xD7 \& 0x7F = 0x57$。
- 注意不是取 IP 整个后 24 位，而是低 23 位；IP 第二字节的最高位不参与映射。
- 注意字节顺序：IP 低 23 位对应 MAC 的第四～六字节，不能倒序。
- `01-00-5E-...` 与 `01:00:5E:...` 只是书写形式不同，含义相同。

**命题规律**：这是数据链路层以太网与网络层 IP 地址映射的常考点，408 多以选择题出现。常见变式有：给 IP 求 MAC、给 MAC 反推可能的 IP 范围、以及问多少个 IPv4 多播地址映射到同一个多播 MAC 地址。由于 IPv4 多播组号有 28 位，而 MAC 只映射低 23 位，所以 $2^{28-23}=32$ 个 IPv4 多播地址对应同一个多播 MAC。复习时记住前缀 `01-00-5E`、固定使用低 23 位，并熟练二进制/十六进制转换即可。

58.【2016 统考真题】如下图所示,假设 H1 与 H2 的默认网关和子网掩码均分别配置为 192.168.3.1 和 255.255.255.128, H3 和 H4 的默认网关和子网掩码均分别配置为 192.168.3.254 和 255.255.255.128, 则下列现象中可能发生的是 ( )

【图：网络拓扑图】
- Internet（Web服务器S 130.18.10.1）— R1 — R2 — R3 — 201.1.2.0/25
- R2 接口：L0 连接 R1（NAT）；E0 连接 201.1.1.0/24（DNS服务器 201.1.1.1）；E1 为 192.168.3.254，连接 Switch 和 Hub
- Switch 连接 H1（192.168.3.2）和 H2（192.168.3.3）
- Hub 连接 H3（192.168.3.251）和 H4（192.168.3.252）

(A) H1 不能与 H2 进行正常 IP 通信
(B) H2 与 H4 均不能访问 Internet
(C) H1 不能与 H3 进行正常 IP 通信
(D) H3 不能与 H4 进行正常 IP 通信

## DeepSeek V4 Flash Max 解析

**答案**：C。H1 的默认网关 192.168.3.1 不存在，且 H3 发往 H1 的 IP 分组无法被路由器正确转发，导致 H1 与 H3 不能正常 IP 通信。

**解题切入点**：先抓住子网掩码与默认网关的配置，判断主机所属的子网以及网关的合法性。相当于算法竞赛中通过“区间划分”判断元素归属，网关就像“出口”指针，配置错误会导致路由失败。交换机与集线器只影响物理/链路层，不影响 IP 层的子网判断。

**推演**：
1. 子网划分：子网掩码均为 $255.255.255.128$，即 $/25$。
   - H1（$192.168.3.2$）与 H2（$192.168.3.3$）属于子网 $192.168.3.0/25$（范围 $192.168.3.0\sim192.168.3.127$）。
   - H3（$192.168.3.251$）与 H4（$192.168.3.252$）属于子网 $192.168.3.128/25$（范围 $192.168.3.128\sim192.168.3.255$）。
   - 路由器 R2 接口 E1 的 IP 为 $192.168.3.254$，处于 $192.168.3.128/25$ 子网内。

2. 默认网关配置：
   - H1、H2 的网关设为 $192.168.3.1$，该地址位于 $192.168.3.0/25$ 子网，但 R2 的 E1 接口并未配置此 IP，因此没有设备拥有该地址，ARP 请求无法得到回应，故 H1、H2 无法通过网关发送任何数据。
   - H3、H4 的网关设为 $192.168.3.254$，即 R2 的 E1 接口 IP，配置正确，可以正常访问网关。

3. 通信分析：
   - **A**：H1 与 H2 同属 $192.168.3.0/25$，且通过交换机相连，可直接进行 ARP 解析与 IP 通信，故 A 错误。
   - **B**：H2 因网关错误无法访问 Internet；H4 网关正确，若路由器 R2 具有到达 Internet 的路由（通常假定如此），则 H4 可以访问 Internet，故“均不能”错误。
   - **C**：H1（$192.168.3.2$）与 H3（$192.168.3.251$）属于不同子网。H1 试图通过网关 $192.168.3.1$ 发送数据，但该网关不存在，故无法发出；H3 通过正确网关 $192.168.3.254$ 发送到 R2，R2 检查目的地址 $192.168.3.2$ 不在其直连子网 $192.168.3.128/25$ 中，且无其他路由，故丢弃分组。因此 H1 与 H3 无法通信，C 正确。
   - **D**：H3 与 H4 同属 $192.168.3.128/25$，并通过集线器相连，可直接进行 ARP 解析与 IP 通信，故 D 错误。

**易错点**：
- 误以为 H1 与 H2 的网关错误会导致它们之间无法通信（实际上同一子网内通信不需网关）。
- 认为 H3 与 H4 的 IP 地址与子网掩码不匹配（实际它们属于 $192.168.3.128/25$，是合法的）。
- 忽略路由器接口的 IP 地址决定了直连子网，导致无法转发属于另一子网的主机流量。

**命题规律**：本题属于 IP 子网划分与基本网络配置的综合题，常结合交换机/集线器出现，考查对子网、网关、ARP 及路由基本概念的理解。变式可能涉及不同子网掩码、多网关、NAT 等。复习时应重点掌握子网计算、网关的作用以及 ARP 协议的工作条件。

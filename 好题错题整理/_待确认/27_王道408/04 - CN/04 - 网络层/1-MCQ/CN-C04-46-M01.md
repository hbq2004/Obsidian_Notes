# 选择题 第 1 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-46-M01_题目.png|题目]]

1. 下列关于移动 IP 工作原理的描述中,错误的是 ( )

(A) 移动 IP 的基本工作过程可以分为代理发现、注册、分组路由与注销 4 个阶段.
(B) 节点在使用移动 IP 进行通信时,归属代理和外部代理之间需要建立一条隧道.
(C) 移动节点到达新的网络后,通过注册过程把自己新的可达信息通知外部代理.
(D) 移动 IP 的分组路由可以分为单播、广播与多播.

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-46-M01_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：C。移动节点注册时，应把自己的新转交地址（可达信息）通知**归属代理**，而不是外部代理；外部代理只负责转发注册请求/响应并维护访问列表。

**解题切入点**：考点是移动 IP 中移动节点、归属代理、外部代理的分工。拿到题先画实体关系：$MN \to HA$、$MN \to FA$。注册的本质是更新一张“位置映射表”：
$$HoA \leftrightarrow CoA$$
这类似于算法竞赛中维护哈希表 `location[home_id] = current_addr`，而持有该表的是“主节点”归属代理，外部代理只是“受理/转发节点”。所以看到“把可达信息通知外部代理”应立即判断为错误。

**推演**：设移动节点的家乡地址为 $HoA$，到外地网络后得到的转交地址为 $CoA$。

1. **代理发现**：移动节点通过代理广播发现外部代理，并获得转交地址 $CoA$。
2. **注册**：移动节点向归属代理发送注册请求，告知“当前可达地址为 $CoA$”。归属代理随后记录：
   $$HoA \to CoA$$
   若使用外部代理的转交地址，注册请求会经过外部代理转发，但最终维护绑定关系的仍是归属代理。
3. **分组路由**：通信节点向 $HoA$ 发送分组；归属代理截获后，将原 IP 分组封装到目的地址为 $CoA$ 的新 IP 分组中，经隧道送往外部代理；外部代理解封装后交给移动节点。
4. **注销**：移动节点回到家乡网络后，向归属代理注销该绑定。

因此：

- (A) 代理发现、注册、分组路由、注销四阶段正确。
- (B) 在常见的外部代理转交地址场景中，隧道确实表现为归属代理与外部代理之间的隧道。
- (C) 错误：注册应通知归属代理，而非外部代理。
- (D) 移动 IP 的分组路由可以分为单播、广播与多播，正确。

**易错点**：

- 常把“注册请求经由外部代理转发”误认为“注册信息交给外部代理”。注册的最终接收者是归属代理。
- 不要忽略“注销”阶段：移动节点回到家乡网络后需要注销，否则归属代理仍会继续截获并隧道转发分组。
- 隧道终点是转交地址 $CoA$。若 $CoA$ 是外部代理地址，则隧道在 $HA$ 与 $FA$ 之间；若使用同址转交地址，隧道终点也可以是移动节点本身。考试中默认外部代理转交地址时，隧道即 $HA$ 到 $FA$。

**命题规律**：移动 IP 是网络层的重要概念题考点，常考“谁负责注册、谁维护绑定、谁建立隧道、分组如何交付”。常见变式包括：

- 判断注册时通知的是归属代理还是外部代理；
- 给出通信过程，判断隧道起点与终点；
- 考察移动节点返回家乡后的注销过程；
- 考察三角路由、反向隧道等问题。

复习时建议画一张 $CN \to HA \to FA \to MN$ 的数据流图，把注册、隧道封装、解封装、注销的位置标清楚，即可应对此类题目。

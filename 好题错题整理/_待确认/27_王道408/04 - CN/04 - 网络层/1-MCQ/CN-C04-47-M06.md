# 选择题 第 6 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-47-M06_题目.png|题目]]

6. 下列关于路由器和路由表的说法中,正确的是（ ）

(A) 路由器处理的信息量比交换机少,因而转发速度比交换机快

(B) 对于同一目标,路由器只提供延迟最小的最佳路由

(C) 当路由表中的所有表项都不匹配时,按照默认路由进行转发

(D) 路由器不但能够根据 IP 地址进行转发,而且可以根据物理地址进行转发

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-47-M06_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：C。理由：默认路由就是在路由表中所有表项都不匹配时使用的特殊路由（若未配置默认路由则丢弃）。

**解题切入点**：先判断设备工作在哪一层，再判断转发依据。路由器是网络层设备，核心工作是根据 IP 地址进行“最长前缀匹配”；交换机是数据链路层设备，核心工作是根据 MAC 地址进行“精确匹配转发”。这就像算法竞赛中先判断题目属于“哈希/字典”还是“Trie/前缀匹配”模型：交换机查表属于精确查找，路由器查表属于最长前缀匹配，二者模型不同。题目中的“默认路由”类似于代码中的 `default` 分支或搜索失败时的 fallback，但要记住 fallback 不一定必须存在。

**推演**：

1. 选项 A 错误。路由器处理的是网络层 IP 数据报，需要解析 IP 头部、执行最长前缀匹配、TTL 减 1、重算校验和，甚至可能要分片；而交换机主要查 MAC 地址表并转发帧。路由器处理的信息量和计算复杂度通常更高，一般转发速度也不如二层交换机快。

2. 选项 B 错误。路由协议选择“最佳路由”的度量（metric）并不统一：RIP 常用跳数，OSPF 常用带宽/代价，BGP 可能考虑策略等因素。“延迟最小”只是其中一种可能的度量，不是唯一标准。并且现代路由器还可以使用等价多路径（ECMP），同一目标不一定只提供一条路由。

3. 选项 C 正确。默认路由是 IPv4 中的 $0.0.0.0/0$ 或 IPv6 中的 $::/0$，它表示“所有未匹配的目的地址都走这条路由”。所以当路由表中没有更具体的表项匹配时，就按照默认路由的下一跳转发。若路由器没有配置默认路由，则无法转发，只能丢弃。

4. 选项 D 错误。路由器的转发决策依据是网络层 IP 地址，而不是物理地址 MAC 地址。物理地址（MAC）的转发由交换机/网桥在数据链路层完成。路由器在局域网中发送帧时确实需要解析下一跳的 MAC 地址，但这是数据链路层的封装过程，不能认为是“根据物理地址转发”。

**易错点**：

- 容易误认为 C 错误，因为“必须有默认路由才能按默认路由转发”。实际上题目中的表述是在讨论默认路由的作用，默认路由本身的定义就是“没有匹配时的兜底路由”；若未配置默认路由，则丢弃，不影响 C 的正确性。
- 容易把 B 中的“最佳”直接等同于“延迟最小”。注意“最佳”由路由协议的度量决定，延迟只是可能的度量之一。
- 容易把 D 中的“路由器会查 ARP / 使用 MAC 地址”误认为“根据物理地址转发”。要区分“转发决策”和“帧封装”两个概念。

**命题规律**：本题属于计算机网络中的基础概念题，核心考查网络层设备与数据链路层设备的区别、路由表的作用及默认路由的含义。常见变式包括：给出路由表让考生计算最长前缀匹配结果；考查默认路由是否需要配置；考查 RIP/OSPF 的不同度量；考查交换机 MAC 地址表和路由器路由表的区别。复习时应紧扣 TCP/IP 分层模型，牢记“路由器看 IP、交换机看 MAC”，并熟练掌握路由表结构：目的网络、掩码、下一跳、接口，以及默认路由 $0.0.0.0/0$ 的含义。

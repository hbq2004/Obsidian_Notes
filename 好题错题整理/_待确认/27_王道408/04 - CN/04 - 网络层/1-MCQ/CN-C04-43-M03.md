# 选择题 第 3 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-43-M03_题目.png|题目]]

3. 下列关于 IPv6 地址 1422:120D:0000:0000:72A2:0000:0000:00C0 的表示中,错误的是 ( ).

(A) 1422:120D::72A2:0000:0000:00C0

(B) 1422:120D::72A2:0:0:C0

(C) 1422::120D::72A2::00C0

(D) 1422:120D:0:0:72A2::C0

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-43-M03_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：C。IPv6 地址中 `::` 只能使用一次；C 中连续出现 3 个 `::`，无法唯一还原，且不合法。

**解题切入点**：看到 IPv6 地址压缩，先数“16 位组”的个数：原地址是  
$1422:120D:0000:0000:72A2:0000:0000:00C0$，共 8 组。  
可以把 `::` 看成“连续全 0 组”的压缩占位符，类似算法竞赛中用 `...` 表示一段连续省略内容；但占位符只能用一次，否则信息丢失、无法还原。

**推演**：IPv6 地址共 128 位，即 8 个 16 位组。表示规则主要有两条：

1. 每 16 位组内的前导 0 可以省略，例如 `0000` 可写成 `0`，`00C0` 可写成 `C0`。
2. 连续的全 0 组可以用 `::` 压缩，但 `::` 只能出现一次。

原地址可看作：
$$
1422:120D:0000:0000:72A2:0000:0000:00C0
= 1422:120D:0:0:72A2:0:0:C0.
$$

逐项验证：

- A：$1422:120D::72A2:0000:0000:00C0$  
  `::` 前有 2 个显式组，后有 4 个显式组，所以 `::` 补 $8-(2+4)=2$ 个全 0 组，等价于原地址，合法。

- B：$1422:120D::72A2:0:0:C0$  
  同样 `::` 前有 2 组，后有 4 组，`::` 补 2 个全 0 组，且 `0`、`C0` 是省略前导 0 的写法，合法。

- C：$1422::120D::72A2::00C0$  
  出现了 3 个 `::`，不符合“只能出现一次”的规则，且展开方式不唯一，错误。

- D：$1422:120D:0:0:72A2::C0$  
  `::` 前有 5 个显式组，后有 1 个显式组，所以 `::` 补 $8-(5+1)=2$ 个全 0 组，等价于原地址，合法。

因此错误的是 C。

**易错点**：

1. 误以为所有连续全 0 组都要用 `::` 压缩，导致多个 `::`；正确规则是只能压缩一次。
2. 忽略 16 位组内前导 0 可以省略，如 `00C0` 写作 `C0`，但 `C0` 不能写成一个十六进制数位 `C`。
3. 不会用“显式组数 + `::` 补充组数 = 8”来验证压缩是否等价。
4. 把 `::` 当作普通的两个冒号分隔符，实际上它表示至少一个连续全 0 组。

**命题规律**：408 中 IPv6 地址表示是常考的小题，常见变式包括“选择正确/错误表示”“展开压缩地址”“判断地址中 `::` 补了多少组”。复习时记住三条核心规则：共 8 组、组内前导 0 可省、`::` 只能出现一次；多练习压缩与还原即可。

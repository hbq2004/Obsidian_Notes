# 选择题 第 6 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-42-M06_题目.png|题目]]

6. 如果 IPv4 的分组太大,会在传输中被分片,则在 ( ) 将对分片后的数据报重组.

(A) 中间路由器  
(B) 下一跳路由器  
(C) 核心路由器  
(D) 目的主机

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-42-M06_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：D。IPv4 分片后的数据报重组只在目的主机进行，中间路由器只负责分片与转发，不负责重组。

**解题切入点**：本题属于网络层 IP 分片/重组的记忆型考点。拿到题先抓“谁负责重组”：IPv4 明确规定“分片可以发生在路由器，但重组只能在目的主机”。这和算法竞赛中“分治”很相似：把大任务拆分给多个 worker 并行处理，拆分可以由任意中间节点完成，但最终合并结果只能在主调用方手里完成；中间 worker 若各自合并局部结果，反而会产生大量无效中间结果，且无法保证全局一致性。

**推演**：

IPv4 分组在传输过程中，如果数据报长度超过下一跳链路的 MTU（最大传输单元），路由器就必须将其分片。分片时，原始 IP 数据报被拆成若干较小的 IP 分片，每个分片都是一个独立的 IP 数据报，可以独立路由。

但 IPv4 规定：**分片后的重组只在目的主机进行**。原因主要有：

1. 各分片在网络中可能经过不同的路径到达目的主机，中间路由器无法保证收到同一个原始数据报的全部分片；
2. 若在每个中间路由器做重组，则需要维护大量分片状态，且一旦重组后再次遇到更小 MTU 又需分片，开销巨大；
3. IP 网络是“尽力而为”的端到端传输模型，中间层只负责转发，端到端的完整性应由目的主机负责。

用 IP 头部字段解释：原始数据报的标识字段（Identification）相同，用于标识它们属于同一个原始数据报；片偏移（Fragment Offset）以 8 字节为单位记录每个分片在原始数据报中的位置；标志字段中的 MF（More Fragments）指示是否还有后续分片。目的主机根据这些字段收集、排序并重组：

- 相同 Identification 的分片属于同一数据报；
- 按片偏移（单位为 8 字节）排序；
- 直到收到 MF = 0 的最后一个分片，再检查是否所有片都已到达；
- 若超时未收齐，则丢弃整个数据报。

因此，分片可以在传输路径上的路由器完成，但重组一定发生在目的主机。

**易错点**：

- 误选 A 或 B：以为“下一跳路由器”或“中间路由器”会顺手帮我们重组。错在忽略了 IPv4 端到端的透明性，中间路由器没有义务也通常没有能力保存所有分片。
- 误选 C：核心路由器同理，即使位于骨干网，也只做高速转发，不做重组。
- 混淆“分片”和“重组”：分片发生在路由器，重组发生在目的主机，两者位置不同。
- 考试中若题目给出具体分片偏移计算，要注意片偏移必须以 8 字节为单位，且每个分片长度应为 8 的倍数（最后一个分片除外）。

**命题规律**：本题是网络层常考的基础题，核心考点是“IPv4 分片与重组”的端点行为。常见变式包括：给出 MTU 和原始数据报长度，计算分片数量、每片长度、片偏移和 MF 标志；或判断 DF=1 时路由器能否分片。复习时建议：牢记“分片在路由器，重组在目的主机”这一原则，并熟练掌握 IP 分片计算公式：

$$ \text{片偏移} = \frac{\text{该片在原始数据报中的偏移字节数}}{8} $$

$$ \text{每片数据部分长度必须是 8 的倍数（除最后一片）} $$

同时结合 IPv6 理解：IPv6 路由器不再分片，仅由源主机进行路径 MTU 发现，这也体现了“中间节点尽量简单，端节点负责复杂功能”的设计思想。

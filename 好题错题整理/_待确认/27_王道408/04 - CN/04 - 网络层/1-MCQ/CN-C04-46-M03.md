# 选择题 第 3 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-46-M03_题目.png|题目]]

3. 若一台主机的 IP 地址为 160.80.40.20/16,则当它移动到了另一个不属于 160.80/16 子网的网络时,它将 ( ) (能否通过被访网络的路由器直接发送/接收数据报)

A. 可以直接接收和直接发送数据报,没有任何影响
B. 既不可以直接接收数据报,又不可以直接发送数据报
C. 不可以直接发送数据报,但可以直接接收数据报
D. 可以直接发送数据报,但不可以直接接收数据报

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-46-M03_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：D。理由：移动主机可以借助被访网络的路由器直接发送数据报，但发给它原 IP 地址 $160.80.40.20$ 的数据报会被普通 IP 路由送到家乡网络 $160.80/16$，不能由被访网络路由器直接接收，需要通过家乡代理/隧道转发。

**解题切入点**：拿到题目先抓住两个关键点：主机 IP 是 $160.80.40.20/16$，说明它的“家乡网络”是 $160.80.0.0/16$；移动到另一个不属于该前缀的子网后，它仍然使用原来的 IP 地址。普通 IP 路由器转发数据报时只看目的 IP，不看源 IP；而接收数据报时，别人按目的 IP 找到的是家乡网络，不是被访网络。可以类比算法竞赛：你带着一个固定编号到另一台机器上提交答案，你自己发请求很容易，但别人按你的编号回复时，消息会先送到你原来的机房，必须由原机房转发给你。

**推演**：

主机的 IP 地址为 $160.80.40.20/16$，其中网络前缀是 $160.80.0.0/16$，主机号是 $40.20$。因此该主机属于网络 $160.80/16$。

当它移动到另一个不是 $160.80/16$ 的网络时，它仍保留原 IP 地址 $160.80.40.20$。

1. 发送数据报：

   主机发送数据报时，IP 路由只根据目的 IP 地址选择转发路径。设目的地址为 $D$，源地址为 $160.80.40.20$。被访网络的路由器作为默认网关收到该数据报后，查找的是目的地址 $D$ 的路由表项，并不要求源地址必须属于被访网络。因此移动主机可以“直接发送”数据报：

   $$源地址：160.80.40.20,\quad 目的地址：D$$

   被访路由器按 $D$ 正常转发，发送过程不需要家乡代理参与。

2. 接收数据报：

   其他主机若向 $160.80.40.20$ 发送数据报，目的地址是 $160.80.40.20$。普通 IP 路由会根据最长前缀匹配，将该数据报发送到 $160.80/16$ 对应的家乡网络，而不是被访网络。

   被访网络的路由器并没有“$160.80.40.20$ 连接在本网络”这一信息，因此无法直接将数据报交付给移动主机。

   为了让移动主机能收到数据报，移动 IP 机制要求它在外地网络获得一个“转交地址”，并注册到家乡代理。家乡代理截获发给 $160.80.40.20$ 的数据报后，将其封装在隧道中发送到转交地址，再由外地代理或被访网络机制交付给移动主机。

   所以移动主机“不可以直接接收数据报”，只能通过家乡代理间接接收。

综上，正确选项为 D：可以直接发送数据报，但不可以直接接收数据报。

**易错点**：

- 错误认为“源 IP 必须属于当前子网才能发送”。实际上路由器转发只看目的 IP，所以移动主机可以用原 IP 直接发送。
- 错误认为“移动主机物理上连到被访网络，所以能直接接收”。普通 IP 路由会把目的地址送到家乡网络，被访网络路由器并不知道该主机的存在。
- 混淆“移动 IP”与“重新分配 IP 地址”两种场景。若主机到外地后重新配置一个属于被访网络的 IP，则可以正常直接收发；但本题没有改变 IP，所以不能直接接收。
- 容易把“发送”和“接收”的对称性想当然。移动 IP 中典型的“三角路由”就是：发送直接，接收通过家乡代理隧道转发。

**命题规律**：本题属于网络层“移动 IP”或“IP 路由与隧道”的考点。常考变式包括：移动主机如何获得转交地址；家乡代理如何拦截并转发数据报；隧道封装后的源/目的地址分别是什么；为什么移动主机发送数据报不需要通过家乡代理。复习时抓住四要素：家乡地址、转交地址、家乡代理、外地代理；理解“发送直连，接收隧道”的不对称性，并结合 IP 分组转发“按目的地址路由”的原理即可。

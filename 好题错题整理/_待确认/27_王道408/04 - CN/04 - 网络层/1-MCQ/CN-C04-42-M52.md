# 选择题 第 52 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-42-M52_题目.png|题目]]

52.【2011统考真题】在子网 192.168.4.0/30 中,能接收目的地址为 192.168.4.3 的 IP 分组的最大主机数是（ ）

(A) 0

(B) 1

(C) 2

(D) 4

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-42-M52_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：C。$192.168.4.0/30$ 的地址块大小为 $4$，可用主机地址只有 $192.168.4.1$ 和 $192.168.4.2$ 两个；$192.168.4.3$ 是该子网的广播地址，子网内所有主机都能接收该广播分组，所以最大主机数为 $2$。

**解题切入点**：拿到 IP 地址/子网题目，先看前缀长度 $/n$，主机位数是 $32-n$，地址块大小是 $2^{32-n}$。可以把 IPv4 地址看成 32 位整数，把子网掩码看成位掩码：$192.168.4.0/30$ 相当于只保留低 $2$ 位变化，即地址块大小为 $4$。这类似算法题中“数组长度为 4，下标 0 和下标 3 是保留位置，中间两个才是可用元素”的边界判断；目标地址低 $2$ 位全为 $1$，所以它是广播地址，不是普通主机地址。

**推演**：

- 前缀长度是 $30$，所以主机位数为：
$$32-30=2$$
- 地址块大小为：
$$2^{2}=4$$
- 对应地址为：
$$192.168.4.0,\ 192.168.4.1,\ 192.168.4.2,\ 192.168.4.3$$
- 其中主机位全为 $0$ 的是网络地址：
$$192.168.4.0$$
- 主机位全为 $1$ 的是广播地址：
$$192.168.4.3$$
- 因此可用主机地址只有：
$$192.168.4.1,\ 192.168.4.2$$

即最多 $2$ 台主机。

目的地址 $192.168.4.3$ 是该子网的定向广播地址。IP 广播分组会被同一子网内的所有主机接收，所以当子网中两台主机都存在时，都能接收到该分组，最大主机数为 $2$。

**易错点**：

- 误以为 $192.168.4.3$ 是一个可分配给主机的普通 IP，从而选 B 或 D；实际上它是广播地址。
- 误以为广播地址不能被接收，选 A；广播地址不能作为源 IP 地址，但可以作为目的 IP 地址，子网内所有主机会接收。
- 直接用 $2^{32-30}=4$ 选 D，忘记排除网络地址和广播地址。
- 对 $/30$ 子网不敏感。$/30$ 是点对点链路常用子网，可用地址只有 $2$ 个，不是 $4$ 个。

**命题规律**：本题考点是 IPv4 子网划分，重点考查对网络地址、广播地址和可用主机地址的判断。常见变式有：给一个 IP/前缀，问可用主机数、广播地址、子网掩码，或者判断某个地址能否作为源地址。复习时要熟记 $/30$、$/29$、$/28$、$/24$ 等常见前缀的地址块大小，并会写二进制主机位来判断全 $0$ 和全 $1$。

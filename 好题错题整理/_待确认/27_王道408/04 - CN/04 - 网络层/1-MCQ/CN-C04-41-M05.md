# 选择题 第 5 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-41-M05_题目.png|题目]]

5.路由器转发分组的根据是报文的（ ）

(A) 端口号
(B) *MAC地址*
(C) *IP地址*
(D) 域名

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-41-M05_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：C，路由器工作在网络层，根据报文中的 IP 地址进行转发。

**解题切入点**：首先明确题目考查的是路由器的转发依据，这属于网络层功能。路由器与交换机、主机等设备的关键区别在于其处理的数据单元（分组）和使用的地址类型。可以类比算法竞赛中的“路由表”相当于一个“哈希映射”，输入是目的 IP 地址，输出是下一跳接口；而 MAC 地址则类似于“局部物理地址”，只在同一链路内有效，不适合跨网络转发。

**推演**：
- 路由器是网络层设备，其核心功能是**分组转发**和**路由选择**。转发决策依据的是分组首部中的**目的 IP 地址**。
- 选项分析：
  - (A) 端口号：属于传输层（TCP/UDP）的标识，用于区分应用进程，路由器不查看端口号（除非是 NAT 等特殊场景，但基本转发不依赖端口号）。
  - (B) MAC 地址：属于数据链路层的地址，用于同一物理网络内的帧传输。路由器收到帧后会拆掉帧头，提取 IP 分组，因此转发时不依赖 MAC 地址（MAC 地址仅在路由器接口的下一跳链路中有用）。
  - (C) IP 地址：网络层逻辑地址，用于跨网络标识主机。路由器查询路由表，根据目的 IP 地址匹配最长前缀，决定下一跳接口。
  - (D) 域名：应用层标识，需通过 DNS 解析为 IP 地址，路由器不直接处理域名。
- 因此，正确选项为 C。

**易错点**：
- 混淆路由器与交换机（交换机根据 MAC 地址转发帧，路由器根据 IP 地址转发分组）。
- 误以为路由器会查看端口号（如访问控制列表可能涉及端口号，但基本转发依据是 IP 地址）。
- 忽略“转发”与“路由选择”的区别：转发依据是 IP 地址，路由选择是计算路由表的过程。

**命题规律**：
- 考点：网络层设备功能，特别是路由器转发依据。
- 常见变式：对比交换机、路由器、网关的转发依据；给出具体场景判断转发决策使用的地址。
- 复习建议：牢记各层设备的工作层次与处理的数据单元，理解不同地址的作用范围（IP 地址跨网络，MAC 地址本地有效）。

# 选择题 第 4 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-43-M04_题目.png|题目]]

4. 一个 IPv6 地址的简化写法为 8::D0:123:CDEF:89A,则其完整地址应该是（ ）.
(A) 8000:0000:0000:0000:00D0:1230:CDEF:8940
(B) 0008:0000:0000:0000:00D0:0123:CDEF:8940
(C) 8000:0000:0000:0000:D000:1230:CDEF:8940
(D) 0008:0000:0000:0000:00D0:0123:CDEF:089A

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-43-M04_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：D。可见 5 组，`::` 应补 3 个全 0 组，再逐组补前导 0，得到 `0008:0000:0000:0000:00D0:0123:CDEF:089A`。

**解题切入点**：看到 IPv6 压缩写法，先不要盯着单个数字，而要“数段”。IPv6 类似固定长度数组 `uint16_t addr[8]`，压缩规则类似于游程编码；`::` 是一段连续 0 的占位符。解压缩时先数可见段数 $m$，再用总段数 $8$ 减去 $m$，得到 `::` 展开为几个 0 段；最后每段不足 4 位时高位补 0。

**推演**：IPv6 完整地址固定为 8 组，每组 16 bit，写作 4 个十六进制数位；每组前导 0 可省略，连续全 0 组可用一个 `::` 替代。

给定地址
`8::D0:123:CDEF:89A`

`::` 左侧有 1 个可见组：`8`；右侧有 4 个可见组：`D0, 123, CDEF, 89A`。可见组数为
$$m=1+4=5.$$

所以 `::` 应补
$$8-m=8-5=3$$
个全 0 组。展开为
```
8 : 0000 : 0000 : 0000 : D0 : 123 : CDEF : 89A
```

再按每组 4 位、高位补 0：
```
0008 : 0000 : 0000 : 0000 : 00D0 : 0123 : CDEF : 089A
```
即
`0008:0000:0000:0000:00D0:0123:CDEF:089A`，对应选项 D。

**易错点**：
- 把 `8` 还原成 `8000`：IPv6 压缩只省略前导 0，`8` 的本意是 `0008`。
- 把 `89A` 还原成 `8940`：`89A` 应补前导 0 为 `089A`，不能自行改变右侧数字。
- 以为 `::` 只代表一个 0 组：实际要由总组数决定，本题 `::` 代表 3 个 0 组。
- 若地址中出现多个 `::` 则无法唯一展开，属于非法 IPv6 写法。

**命题规律**：考点是 IPv6 地址格式与压缩规则，属于网络层基础概念。常见变式有：给出完整地址写压缩写法、给出压缩写法选完整地址、判断压缩写法是否合法、与 IPv4 地址格式比较等。复习时记住“8 组、每组 16 bit、4 位 hex、前导 0 可省、连续 0 组用 `::` 一次”即可；做题先数可见组数，再用 $8$ 减它确定补零个数，最后逐组高位补 0。

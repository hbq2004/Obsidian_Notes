# 选择题 第 22 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-44-M22_题目.png|题目]]

22. 考虑如下图所示的子网，该子网使用了距离向量算法，下面的向量刚刚到达路由器 C：来自 B 的向量为 (5,0,8,12,6,2)；来自 D 的向量为 (16,12,6,0,9,10)；来自 E 的向量为 (7,6,3,9,0,4)。经过测量，C 到 B、D 和 E 的延迟分别为 6、3 和 5，那么 C 到达所有节点的最短路径是（ ）

A. (5,6,0,9,6,2)

B. (11,6,0,3,5,8)

C. (5,11,0,12,8,9)

D. (11,8,0,7,4,9)

【图：无向图，节点 A、B、C、D、E、F；边有 A-B、B-C、C-D、D-E、E-F、F-A、B-E、C-F】

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-44-M22_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：B。  
C 到各节点的最短距离用距离向量更新公式计算，即“把邻居向量中的每一项加上 C 到该邻居的延迟，再逐项取最小值”，结果为  
$$(11,6,0,3,5,8)$$  
所以选 B。

**解题切入点**：  
距离向量算法本质上就是分布式 Bellman-Ford 算法。可以把收到的邻居向量看作“候选子距离”，把 C 到邻居的延迟看作“边权”。对每个目的节点，计算：

$$\text{候选距离} = \text{C 到邻居的延迟} + \text{邻居到目的节点的距离}$$

然后取最小值。这类似于算法竞赛中做最短路松弛：  
$$\text{dist}[v] = \min\{\text{dist}[v],\ \text{dist}[u] + w(u,v)\}$$

不要试图把整张图重新跑一遍 Dijkstra，只需对 C 收到的这几个邻居向量做一次松弛即可。

**推演**：  
向量顺序按 $(A,B,C,D,E,F)$ 理解。

来自 B 的向量：
$$(5,0,8,12,6,2)$$
C 到 B 的延迟为 $6$，所以经 B 到各节点的候选距离为：
$$(5+6,\ 0+6,\ 8+6,\ 12+6,\ 6+6,\ 2+6) = (11,6,14,18,12,8)$$

来自 D 的向量：
$$(16,12,6,0,9,10)$$
C 到 D 的延迟为 $3$，所以经 D 到各节点的候选距离为：
$$(16+3,\ 12+3,\ 6+3,\ 0+3,\ 9+3,\ 10+3) = (19,15,9,3,12,13)$$

来自 E 的向量：
$$(7,6,3,9,0,4)$$
C 到 E 的延迟为 $5$，所以经 E 到各节点的候选距离为：
$$(7+5,\ 6+5,\ 3+5,\ 9+5,\ 0+5,\ 4+5) = (12,11,8,14,5,9)$$

逐项取最小值，同时 C 到自身的距离为 $0$：

$$
\begin{aligned}
D_C(A) &= \min(11,19,12)=11 \\
D_C(B) &= \min(6,15,11)=6 \\
D_C(C) &= 0 \\
D_C(D) &= \min(18,3,14)=3 \\
D_C(E) &= \min(12,12,5)=5 \\
D_C(F) &= \min(8,13,9)=8
\end{aligned}
$$

因此 C 的新距离向量为：

$$(11,6,0,3,5,8)$$

对应选项 B。

**易错点**：  
- 最容易出错的是“忘记加 C 到邻居的延迟”，直接把收到的向量逐项取最小值。  
- C 到自身的距离应固定为 $0$，不能取邻居向量中报告的 C 值，例如 $8$、$6$、$3$。  
- 注意向量顺序是 $(A,B,C,D,E,F)$，不要把第 3 位当成别的节点。  
- 对 F 的距离容易算成经 E：$5+4=9$，或经 D：$3+10=13$，但经 B：$6+2=8$ 更短。  
- 不要自行假设图中其他边的权值；本题更新只使用已经收到的 B、D、E 向量和对应的链路延迟。

**命题规律**：  
考点是网络层路由算法中的距离向量算法，常见于 RIP 相关选择题。出题方式通常给出若干个邻居路由器的距离向量和当前路由器到这些邻居的链路代价，要求计算更新后的路由表项。  
常见变式包括：判断更新后下一跳是否变化、结合毒性逆转/水平分割解决环路问题、比较距离向量算法与链路状态算法。复习时重点掌握 Bellman-Ford 更新公式：

$$D_x(y) = \min_v \{ c(x,v) + D_v(y) \}$$

并注意向量表项顺序和逐项取最小值的过程。

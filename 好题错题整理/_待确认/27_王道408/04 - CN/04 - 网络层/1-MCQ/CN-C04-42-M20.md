# 选择题 第 20 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-42-M20_题目.png|题目]]

20. 不考虑 NAT, 在 *Internet* 中, IP 数据报从源节点到目的节点可能需要经过多个网络和路由器。在整个传输过程中，IP 数据报头部中的（  ）

A. 源地址和目的地址都不会发生变化  
B. 源地址有可能发生变化而目的地址不会发生变化  
C. 源地址不会发生变化而目的地址有可能发生变化  
D. 源地址和目的地址都有可能发生变化.

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-42-M20_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：A。普通路由器转发 IP 数据报时，首部中的源 IP 地址和目的 IP 地址始终保持不变；题目已排除 NAT，因此选 A。

**解题切入点**：拿到题先抓“哪些字段是端到端的，哪些字段是逐跳的”。这和算法竞赛中区分“全局变量”与“局部变量”类似：路由器每跳都会重新封装链路层，并修改 TTL、首部校验和等局部字段，但不会修改标识通信双方的 IP 地址。定位考点：网络层 IP 数据报转发与首部字段变化规律。

**推演**：设源节点 IP 地址为 $S$，目的节点 IP 地址为 $D$。源节点构造 IP 数据报时，首部中源地址字段填 $S$，目的地址字段填 $D$。数据报经过中间路由器时：

- 路由器查看目的地址 $D$，根据路由表确定下一跳；
- 将 TTL 减 1；
- 重新计算首部校验和；
- 按下一跳重新封装链路层帧（可能改变 MAC 地址）。

上述过程都不改写网络层首部中的 $S$ 和 $D$。因此整个传输过程中有：

$$
S \text{ 不变},\qquad D \text{ 不变}.
$$

NAT 会改写源地址或目的地址，但题目明确“不考虑 NAT”，所以排除该例外。

**易错点**：
- 误选 B/C/D：把“MAC 地址逐跳变化”误认为“IP 地址逐跳变化”。实际上 IP 地址端到端不变，MAC 地址才逐跳变化。
- 忽略“不考虑 NAT”条件：NAT 会改写 IP 地址，但本题已排除。
- 混淆移动 IP、隧道、代理等特殊场景：普通 Internet IP 转发不改写源/目的 IP 地址。

**命题规律**：这是网络层基础考点，常与“路由器转发过程中 IP 首部哪些字段变化”结合考查。常见变式：给出 TTL、首部校验和、MAC 地址、IP 地址等，问哪些字段逐跳改变、哪些字段端到端不变。复习时建议把“IP 地址端到端不变，MAC 地址逐跳改变，TTL 和首部校验和每跳改变”做成对比表，并记清 NAT 是常见例外。

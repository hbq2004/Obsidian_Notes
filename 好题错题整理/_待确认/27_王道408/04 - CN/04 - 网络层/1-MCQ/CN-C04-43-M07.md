# 选择题 第 7 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-43-M07_题目.png|题目]]

7.【2023统考真题】下列关于 $IPv4$ 和 $IPv6$ 的叙述中,正确的是（  ）

I. $IPv6$ 地址空间是 $IPv4$ 地址空间的 96 倍

II. $IPv4$ 首部和 $IPv6$ 基本首部的长度均可变

III. $IPv4$ 向 $IPv6$ 过渡可以采用双协议栈和隧道技术

IV. $IPv6$ 首部的 $HopLimit$ 字段等价于 $IPv4$ 首部的 $TTL$ 字段

(A) 仅 I、II
(B) 仅 I、IV
(C) 仅 II、III
(D) 仅 III、IV

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-43-M07_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：D（仅 III、IV）。IPv6 地址空间是 IPv4 的 $2^{96}$ 倍，不是 96 倍；IPv6 基本首部长度固定为 40B；双协议栈和隧道技术确实是过渡技术；Hop Limit 与 TTL 功能等价。

**解题切入点**：拿到题目先逐项判断，不要凭整体印象。题目问的是“正确的是”，每个选项都是独立命题，需要分别验证。可以用算法竞赛背景来类比：地址空间大小就像算数据范围，不能只说“long long 比 int 大”，要算出 $2^{64}/2^{32}=2^{32}$ 才对；首部长度类似“定长结构体”和“动态扩展字段”的区别；分层协议可以类比分治，网络层只比较本层首部设计。

**推演**：

I. IPv4 地址长度为 32 位，IPv6 地址长度为 128 位。因此地址数量分别为：

$$2^{32},\qquad 2^{128}$$

IPv6 地址空间是 IPv4 地址空间的倍数为：

$$\frac{2^{128}}{2^{32}}=2^{96}$$

所以 IPv6 地址空间是 IPv4 的 $2^{96}$ 倍，而不是 96 倍。I 错误。

II. IPv4 首部由 20B 固定部分和可变选项部分组成，首部长度字段 IHL 以 4B 为单位，因此 IPv4 首部长度可变；但 IPv6 基本首部固定为 40B，长度不可变。IPv6 的选项通过扩展首部实现，不属于“基本首部”。所以“IPv6 基本首部长度可变”的说法错误。II 错误。

III. IPv4 向 IPv6 过渡的常用技术包括双协议栈和隧道技术。双协议栈是指节点同时运行 IPv4 和 IPv6 协议栈，隧道技术是指将 IPv6 分组封装在 IPv4 分组中传输，反之亦然。III 正确。

IV. IPv6 基本首部中的 Hop Limit 字段与 IPv4 首部中的 TTL 字段都是 8 位字段，每经过一个路由器都减 1，减到 0 时丢弃，用于限制分组在网络中的跳数，防止无限循环。IPv6 改用 Hop Limit 是更准确的命名，但二者功能等价。IV 正确。

因此正确选项为：

$$D$$

**易错点**：

1. 把 $2^{96}$ 倍误写成 96 倍。地址空间是“指数倍”，不是“96 倍”。
2. 看到 IPv6 有扩展首部，就误以为 IPv6 基本首部长度可变。实际上基本首部固定 40B，扩展首部才可能使总头部变长。
3. 对 TTL 的理解停留在“时间”上。IPv4 的 TTL 实际按跳数递减，IPv6 的 Hop Limit 更明确地表达这一语义，二者等价。
4. 忽略“基本首部”这个限定词。题干限定的是 IPv6 基本首部，不是整个 IPv6 头部扩展链。

**命题规律**：本题属于网络层 IPv4 与 IPv6 协议对比的基础题，常考地址空间大小、基本首部格式、过渡技术和字段变化。常见变式包括：IPv6 地址缩写规则、IPv6 扩展首部的作用、IPv6 取消了首部校验和、使用 Flow Label 字段、Next Header 字段与 IPv4 Protocol 字段的对应关系等。复习时建议列表对比 IPv4 与 IPv6：地址长度、首部是否定长、是否有校验和、分片方式、字段改名的对应关系，以及双协议栈、隧道技术等过渡方案。

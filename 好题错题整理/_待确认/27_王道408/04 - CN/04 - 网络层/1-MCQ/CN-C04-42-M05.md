# 选择题 第 5 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-42-M05_题目.png|题目]]

5. 当数据报到达目的网络后,要传送到目的主机,需要知道 IP 地址对应的 ( )

(A) 逻辑地址
(B) 动态地址
(C) 域名
(D) 物理地址

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-42-M05_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：D，当数据报到达到目的网络后，需通过 ARP 将 IP 地址解析为物理地址（MAC 地址）才能封装成帧并交付给目的主机。

**解题切入点**：本题考察网络层与数据链路层的地址映射关系。可以类比算法竞赛中的“哈希表查找”：网络层 IP 地址相当于“逻辑键”，而数据链路层物理地址（MAC）相当于“存储位置”，当数据报到达目标子网（即“哈希桶”）后，必须通过 ARP 协议（类似“哈希函数”）将 IP 键转换为 MAC 地址才能完成最终交付。

**推演**：
1. 数据报在因特网中逐跳路由，最终到达目的网络（即目标子网）。
2. 此时，路由器或主机需要将 IP 数据报封装成数据链路层帧，帧的传输必须依赖物理地址（MAC 地址）来标识同一网络中的具体接口。
3. 因此，需要将目的 IP 地址映射为对应的物理地址。这一映射由地址解析协议（ARP）完成，它维护一个 IP 到 MAC 的映射表。
4. 选项分析：
   - (A) 逻辑地址：即 IP 地址本身，是已知的，不需要再“知道”；
   - (B) 动态地址：通常指 DHCP 分配的暂时 IP 地址，与物理地址无关；
   - (C) 域名：属于应用层，用于标识主机，需通过 DNS 解析为 IP 地址，与本题场景无关；
   - (D) 物理地址：即 MAC 地址，是数据链路层唯一标识，正确。
5. 综上，答案为 D。

**易错点**：
- 混淆“逻辑地址”与“物理地址”：逻辑地址是 IP 地址，网络层使用；物理地址是 MAC 地址，数据链路层使用。题目中 IP 地址已知，需找的是对应的物理地址。
- 误以为“域名”是答案：域名是应用层概念，用于用户访问，与数据报到达目的网络后的交付过程无关。
- 忽略数据链路层封装要求：帧必须携带目的 MAC 地址，否则无法在同一网络中传递。

**命题规律**：
- 考点：网络层与数据链路层的地址关系、ARP 协议的作用。
- 常见变式：直接考查 ARP 协议的功能（如“IP 地址解析为 MAC 地址的协议是？”）；或结合传输过程，问“当数据报到达目的网络后，下一步需要做什么？”。
- 复习建议：理解 TCP/IP 协议栈各层地址的用途及转换机制，重点掌握 IP 地址、MAC 地址、端口号、域名的层次关系，以及 ARP、DNS 等协议的工作场景。

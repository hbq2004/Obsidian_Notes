# 选择题 第 47 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-42-M47_题目.png|题目]]

47. 若某路由器收到一个 TTL 值为 1 的 IP 数据报,则路由器的操作是 ( )

(A) 转发该 IP 数据报

(B) 仅仅丢弃该 IP 数据报

(C) 丢弃该 IP 数据报并向源主机发送类型为终点不可达的 ICMP 差错报告报文

(D) 丢弃该 IP 数据报并向源主机发送类型为时间超过的 ICMP 差错报告报文

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-42-M47_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：D。路由器收到 TTL 值为 1 的数据报时，TTL 减 1 后为 0，不能继续转发，应将数据报丢弃，并向源主机发送类型为“时间超过”的 ICMP 差错报告报文。

**解题切入点**：看到 TTL 为 1，立即想到“TTL 每经过一个路由器减 1，若减为 0 则丢弃并发送 ICMP 差错报文”。这就像算法竞赛里设置递归深度限制：深度达到上限时直接返回失败，并向调用方报错，而不是继续递归。定位考点为 IP 分组的转发过程与 ICMP 差错报文的类型区分。

**推演**：

1. IPv4 数据报首部中的 TTL（Time to Live）字段用于限制数据报在网络中经过的最大跳数，防止数据报因路由环路而无限循环。
2. 路由器收到一个需要转发的 IP 数据报时，会先将 TTL 值减 1。本题中收到时 $TTL=1$，则转发前变为：
   $$TTL' = 1 - 1 = 0$$
3. 路由器检查发现 $TTL'=0$，说明该数据报的生存时间已经耗尽，不能再转发。
4. 根据 ICMP 协议规定，当路由器因 TTL 减为 0 而丢弃数据报时，应当向源主机发送一个 **ICMP 时间超过**（Time Exceeded）差错报告报文，告知源主机该数据报在中途被丢弃。
5. 该报文属于 ICMP 差错报告，类型字段为“时间超过”，而不是“终点不可达”，因为问题不是目的地址不可达，而是 TTL 耗尽。

因此选择 D。

**易错点**：

- **误选 C**：将 TTL 耗尽误认为是“目的不可达”。终点不可达是指无法找到目的主机或目的网络，而 TTL 耗尽表示数据报在网络中转发次数超限，应发送“时间超过”而不是“目的不可达”。
- **误选 B**：只记得丢弃，忘记路由器还要发送 ICMP 差错报告报文。ICMP 的作用之一就是向源主机报告转发过程中的错误。
- **误选 A**：忽略 TTL 减 1 后的判断。即使 TTL 为 1，转发前减 1 后为 0，依然不能转发。
- **混淆“收到后减 1”与“收到时已经为 0”**：本题给出的是“收到时 TTL=1”，所以要经历减 1 再判断；若给出“TTL 为 0”则应直接丢弃，但在正常转发流程中，路由器收到数据报后先减 1，再判断是否为 0。

**命题规律**：这是 408 计算机网络中 IP 协议与 ICMP 协议结合的经典考点，重点考查 TTL 的处理流程以及 ICMP 各类差错报文的使用场景。常见变式包括：给出 TTL 初始值和经过的跳数，询问 TTL 剩余值；或结合 traceroute 原理考查“时间超过”报文的作用。复习时应熟记 IPv4 首部字段功能，尤其是 TTL 每跳减 1 的规则，并整理 ICMP 常见报文类型：不可达、重定向、时间超过、参数问题等，避免混淆。

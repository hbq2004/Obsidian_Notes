# 选择题 第 55 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-42-M55_题目.png|题目]]

55.【2012 统考真题】$ARP$ 的功能是（  ）

A. 根据 $IP$ 地址查询 $MAC$ 地址
B. 根据 $MAC$ 地址查询 $IP$ 地址
C. 根据域名查询 $IP$ 地址
D. 根据 $IP$ 地址查询域名

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-42-M55_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：A。ARP（Address Resolution Protocol，地址解析协议）的核心功能就是根据目的主机的 IP 地址查询其 MAC 地址，以便在局域网中封装数据帧。

**解题切入点**：拿到题目先抓关键词“ARP 的功能”，直接定位到网络层的地址解析协议。可以类比算法竞赛中的“哈希映射”：IP 地址相当于逻辑键（key），MAC 地址相当于物理存储位置（value），ARP 就是一张动态维护的“哈希表”，输入 key（IP）查 value（MAC）。不需要纠结底层细节，先明确方向是“IP → MAC”即可。

**推演**：

在 TCP/IP 协议栈中，网络层使用 IP 地址进行逻辑寻址，而数据链路层实际传输帧时需要使用 MAC 地址。当一台主机要向另一台主机发送 IP 数据报时，必须知道下一跳的 MAC 地址，才能封装成帧。

ARP 的查询过程：发送方在局域网内广播一个 ARP 请求分组，其中包含目标 IP 地址；网内所有主机的网卡都会收到该请求，但只有 IP 地址匹配的主机会响应一个 ARP 应答分组，把自己的 MAC 地址返回给发送方。于是：

- 输入：目标 IP 地址
- 输出：目标 MAC 地址

因此对应选项 A。

其余选项排除：

- B：根据 MAC 地址查询 IP 地址，是 RARP（Reverse ARP，逆地址解析协议）或 DHCP 等协议的功能，不是 ARP 的主要功能。
- C：根据域名查询 IP 地址，是 DNS（Domain Name System，域名系统）的功能。
- D：根据 IP 地址查询域名，是 DNS 的反向解析功能。

综上，ARP 的功能是“根据 IP 地址查询 MAC 地址”。

**易错点**：

1. 混淆 ARP 与 RARP：ARP 是 IP → MAC，RARP 是 MAC → IP。记忆技巧：ARP 用于“知道 IP 找 MAC”，因为日常通信中我们往往知道对方的 IP，但不知道其 MAC。
2. 混淆 ARP 与 DNS：DNS 是域名 → IP（正向解析）或 IP → 域名（反向解析），ARP 工作在网络层之下、数据链路层之上，解决的是同一局域网内的物理地址问题。
3. 忽略 ARP 只在同一广播域内有效：ARP 请求是广播的，但如果目标 IP 不在本网段，则需通过网关转发，这时 ARP 查询的是网关的 MAC 地址。本题不涉及，但理解这一点有助于更深层辨析。

**命题规律**：

该题属于基础概念题，考查协议功能辨析，是 408 真题中的高频送分考点。常见变式包括：

- 给出具体场景，问“主机 A 向主机 B 发送 IP 分组时，ARP 查询的是谁的 MAC 地址”（若在同一网段，查询目标主机；若跨网段，查询默认网关）。
- 与 RARP、DNS、DHCP 混合考查协议功能区分。
- 结合交换机、路由器的转发过程，考查 ARP 缓存和广播/单播特性。

复习建议：将 TCP/IP 协议栈中的常用协议按层次整理成“功能映射表”，例如：DNS（域名↔IP）、ARP（IP→MAC）、RARP（MAC→IP）、DHCP（IP 自动分配）、ICMP（差错报告）。同时注意 ARP 的报文格式、缓存机制以及“ARP 欺骗”等安全扩展，但 408 真题中以功能辨析和基本流程为主。

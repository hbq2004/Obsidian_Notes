# 综合题 第 14 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-42-F14_题目.png|题目]]

14.【2015统考真题】某网络拓扑如下图所示,其中路由器内网接口、DHCP服务器、WWW服务器与主机1均采用静态IP地址配置,相关地址信息见图中标注;主机2~N通过DHCP服务器动态获取IP地址等配置信息。回答下列问题:

【图：网络拓扑图。中心为以太网交换机，连接WWW服务器（标注IP地址111.123.15.3/24）、DHCP服务器（标注IP地址111.123.15.2/24、MAC地址00-b1-b1-b1-b1-b1）、路由器（标注IP地址111.123.15.1/24、MAC地址00-a1-a1-a1-a1-a1）以及主机1（标注IP地址111.123.15.4/24）、主机2、主机N。路由器右侧连接Internet云。】

(1) DHCP服务器可为主机2~N动态分配IP地址的最大范围是什么?主机2使用DHCP获取IP地址的过程中,发送的封装DHCPDiscover报文的IP分组的源IP地址和目的IP地址分别是多少?

(2) 若主机2的ARP表为空,则该主机访问Internet时,发出的第一个以太网帧的目的MAC地址是什么?封装主机2发往Internet的IP分组的以太网帧的目的MAC地址是什么?

(3) 若主机1的子网掩码和默认网关分别配置为255.255.255.0和111.123.15.2,则该主机是否能访问WWW服务器?是否能访问Internet?请说明理由.

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-42-F14_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：  
（1）DHCP 服务器可为主机2～N动态分配的最大 IP 范围是 $111.123.15.5\sim111.123.15.254$。主机2发送 DHCPDiscover 时，封装它的 IP 分组源 IP 为 $0.0.0.0$，目的 IP 为 $255.255.255.255$。  
（2）主机2 ARP 表为空时，访问 Internet 发出的第一个以太网帧是 ARP 请求帧，目的 MAC 为 $\text{FF-FF-FF-FF-FF-FF}$；封装主机2发往 Internet 的 IP 分组的以太网帧，目的 MAC 为路由器内网接口 MAC $00\text{-}a1\text{-}a1\text{-}a1\text{-}a1\text{-}a1$。  
（3）主机1能访问 WWW 服务器，但不能访问 Internet。因为 WWW 服务器与主机1同属 $111.123.15.0/24$，同子网内可直接通信；而访问 Internet 需经过默认网关，主机1的默认网关被错配为 DHCP 服务器 $111.123.15.2$，它不是路由器，不能把分组转发到 Internet。

**解题切入点**：  
可以把整个问题看成一张“图”：DHCP 地址池就是可用编号集合，需要从集合中剔除已占用和不可用的编号；ARP 表相当于“IP 到 MAC”的缓存，未命中时就广播查找；默认网关相当于离开本子网的出口/下一跳。拿到题目先确定子网掩码为 $255.255.255.0$，即前缀长度 $/24$，然后按“同子网直连、跨子网找网关”分层推进。网络层决定下一跳 IP，链路层再解析下一跳 MAC，这类似算法中的“分治”：先解决路由问题，再解决封装问题。

**推演**：  
由题图可知，局域网地址均为 $111.123.15.0/24$，子网掩码为 $255.255.255.0$。一个 $/24$ 子网中不能把网络地址 $111.123.15.0$ 和广播地址 $111.123.15.255$ 分配给主机。可用主机地址为：

$$111.123.15.1\sim111.123.15.254$$

其中已被静态占用的地址为：

- 路由器内网接口：$111.123.15.1$
- DHCP 服务器：$111.123.15.2$
- WWW 服务器：$111.123.15.3$
- 主机1：$111.123.15.4$

因此 DHCP 可动态分配的最大范围为：

$$111.123.15.5\sim111.123.15.254$$

主机2尚未获得 IP 地址时发送 DHCPDiscover，此时它没有合法的源 IP，因此 IP 分组源 IP 用 $0.0.0.0$ 表示“本机未配置”；目的 IP 用 $255.255.255.255$ 表示在本网广播。

主机2访问 Internet 时，目的 IP 不在本子网内，必须把 IP 分组交给默认网关，即路由器 $111.123.15.1$。由于 ARP 表为空，主机2先发送 ARP 请求解析路由器内网接口的 MAC。ARP 请求封装在以太网帧中广播发送，所以第一个以太网帧的目的 MAC 是：

$$\text{FF-FF-FF-FF-FF-FF}$$

收到 ARP 响应后，主机2把真正发往 Internet 的 IP 分组封装在以太网帧中，目的 MAC 写成路由器内网接口 MAC：

$$00\text{-}a1\text{-}a1\text{-}a1\text{-}a1\text{-}a1$$

主机1的子网掩码是 $255.255.255.0$，它与 WWW 服务器 $111.123.15.3$ 处于同一子网：

$$111.123.15.4 \text{ AND } 255.255.255.0 = 111.123.15.0$$

$$111.123.15.3 \text{ AND } 255.255.255.0 = 111.123.15.0$$

所以主机1访问 WWW 服务器时不需要经过默认网关，可以直接通过以太网交换机通信，因此能访问 WWW 服务器。  
但访问 Internet 时，目的地址不在本子网内，主机1会把分组交给默认网关 $111.123.15.2$。该地址是 DHCP 服务器，不是路由器，不能把分组转发到 Internet，因此主机1不能访问 Internet。

**易错点**：  
1. 求 DHCP 动态范围时容易忘记排除网络地址 $111.123.15.0$、广播地址 $111.123.15.255$，以及静态占用的 $111.123.15.1\sim111.123.15.4$。  
2. DHCPDiscover 的源 IP 容易误写成某个候选 IP；客户端尚未获得 IP，源 IP 应为 $0.0.0.0$，目的 IP 应为 $255.255.255.255$。  
3. ARP 表为空时，第一个以太网帧是 ARP 请求帧，目的 MAC 是广播地址 $\text{FF-FF-FF-FF-FF-FF}$，不能直接写成路由器 MAC。  
4. 封装 IP 分组的以太网帧目的 MAC 与 ARP 请求帧目的 MAC 不同；前者是路由器内网接口 MAC，后者是广播 MAC。  
5. 判断主机1能否访问 WWW 时，容易误认为必须经过默认网关；同一子网内通信不需要网关。  
6. 默认网关应配置为路由器接口 $111.123.15.1$，不能配置为 DHCP 服务器 $111.123.15.2$。

**命题规律**：  
本题是 408 常考的综合应用题，把 DHCP、ARP、IP 子网划分、默认网关放在同一个拓扑中考查。常见变式包括：修改子网掩码判断是否同网段、修改默认网关判断通信是否成功、增加路由器接口或 VLAN 后分析广播域和转发路径。复习时应按“网络层判断下一跳 IP，链路层通过 ARP 获取下一跳 MAC”的分层思路，把 DHCP 地址池计算和 ARP 广播过程熟练掌握。

# 综合题 第 7 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-42-F07_题目.png|题目]]

7. 下表是使用无类别域间路由选择(CIDR)的路由选择表,地址字段是用十六进制表示的,试指出具有下列目标地址的 IP 分组将被投递到哪一个下一站?

| 网络/掩码长度 | 下一站地 |
| :--- | :--- |
| C4.50.0.0/12 | A |
| C4.5E.10.0/20 | B |
| C4.60.0.0/12 | C |
| C4.68.0.0/14 | D |
| 80.0.0.0/1 | E |
| 40.0.0.0/2 | F |
| 00.0.0.0/2 | G |

1) C4.5E.13.87;
2) C4.5E.22.09;
3) C3.41.80.02;
4) 5E.43.91.12;

## DeepSeek V4 Flash Max 解析

**答案**：  
- 目的地址 $C4.5E.13.87$ 下一站为 **B**；  
- $C4.5E.22.09$ 下一站为 **A**；  
- $C3.41.80.02$ 下一站为 **E**；  
- $5E.43.91.12$ 下一站为 **F**。  
理由：根据最长前缀匹配原则，将每个目的地址与路由表项逐一匹配，选择掩码最长的前缀匹配项。

**解题切入点**：  
本题考点是 CIDR 路由表的最长前缀匹配查找。首先将目的地址和路由表项的网络地址都转换为二进制，然后从最长掩码开始比较，或逐一列出所有匹配项，取掩码最大的。这类似于算法竞赛中的“前缀匹配”问题，可以用构建字典树（Trie）的思想，每次匹配尽可能长的前缀。

**推演**：  
首先将路由表项的网络地址和掩码转换为二进制前缀（只列出关键位）：  
1. $C4.50.0.0/12$：前12位 $11000100\ 0101$。  
2. $C4.5E.10.0/20$：前20位 $11000100\ 01011110\ 0001$。  
3. $C4.60.0.0/12$：前12位 $11000100\ 0110$。  
4. $C4.68.0.0/14$：前14位 $11000100\ 010001$。  
5. $80.0.0.0/1$：第1位 $1$。  
6. $40.0.0.0/2$：前2位 $01$。  
7. $00.0.0.0/2$：前2位 $00$。  

逐一分析四个目的地址：  

**1) $C4.5E.13.87$**  
二进制：$11000100\ 01011110\ 00010011\ 10000111$  
- 匹配 $C4.50.0.0/12$（前12位 $11000100\ 0101$ 一致）  
- 匹配 $C4.5E.10.0/20$（前20位 $11000100\ 01011110\ 0001$ 一致）  
- 匹配 $80.0.0.0/1$（第1位为1）  
- 不匹配其他项  
最长掩码为20，下一站为 **B**。

**2) $C4.5E.22.09$**  
二进制：$11000100\ 01011110\ 00100010\ 00001001$  
- 匹配 $C4.50.0.0/12$（前12位一致）  
- 不匹配 $C4.5E.10.0/20$（第3字节前4位为 $0010$，需 $0001$）  
- 匹配 $80.0.0.0/1$  
- 不匹配其他项  
最长掩码为12，下一站为 **A**。

**3) $C3.41.80.02$**  
二进制：$11000011\ 01000001\ 10000000\ 00000010$  
- 不匹配任何 $C4$ 开头的表项（前12位不同）  
- 匹配 $80.0.0.0/1$（第1位为1）  
- 不匹配其他项  
唯一匹配掩码为1，下一站为 **E**。

**4) $5E.43.91.12$**  
二进制：$01011110\ 01000011\ 10010001\ 00010010$  
- 不匹配任何 $C4$ 开头的表项  
- 不匹配 $80.0.0.0/1$（第1位为0）  
- 匹配 $40.0.0.0/2$（前2位 $01$）  
- 不匹配其他项  
唯一匹配掩码为2，下一站为 **F**。

**易错点**：  
1. 十六进制转二进制易出错，如 $C4=11000100$，$5E=01011110$，需仔细。  
2. 掩码长度对应的前缀位数计算错误，如 $/20$ 包含第3字节前4位，容易忽略。  
3. 必须选最长掩码匹配而非最先匹配，例如 $C4.5E.13.87$ 同时匹配 $/12$ 和 $/20$，应选 $/20$。  
4. 注意特殊前缀（如 $/1$、$/2$）的匹配范围，避免遗漏或误判。

**命题规律**：  
- 考点：CIDR 路由表查找、最长前缀匹配、IP 地址二进制表示。  
- 常见变式：给出多个目标 IP 选下一跳；路由聚合（反向最长匹配）；结合子网划分。  
- 复习建议：熟练 IP 地址与二进制转换，理解前缀长度含义，多做类似练习，注意特殊前缀的匹配范围。同时掌握路由聚合原理，这是 408 常考题型。

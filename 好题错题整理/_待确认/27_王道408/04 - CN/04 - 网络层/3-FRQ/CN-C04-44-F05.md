![[_Attachments/题目识别/27_王道408-题目/CN-C04-44-F05_题目.png|题目]]

5. 【2014统考真题】某网络中的路由器运行 OSPF 路由协议，下表是路由器 R1 维护的主要链路状态信息(LSI)，下图是根据该表及 R1 的接口名构造的网络拓扑。请回答下列问题:

|---|---|---|---|---|---|
| Router ID | 10.1.1.1 | 10.1.1.2 | 10.1.1.5 | 10.1.1.6 | 标识路由器的 IP 地址 |
| Link1 ID | 10.1.1.2 | 10.1.1.1 | 10.1.1.6 | 10.1.1.5 | 所连接路由器的 Router ID |
| Link1 IP | 10.1.1.1 | 10.1.1.2 | 10.1.1.5 | 10.1.1.6 | Link1 的本地 IP 地址 |
| Link1 Metric | 3 | 3 | 6 | 6 | Link1 的费用 |
| Link2 ID | 10.1.1.5 | 10.1.1.6 | 10.1.1.1 | 10.1.1.2 | 所连接路由器的 Router ID |
| Link2 IP | 10.1.1.9 | 10.1.1.13 | 10.1.1.10 | 10.1.1.14 | Link2 的本地 IP 地址 |

| Net1 Metric | 1 | 1 | 1 | 1 | 到达直连网络 Net1 的费用 |

(1) 设路由表结构如下表所示，给出图中 R1 的路由表，要求包括到达图中子网 192.1.x.x 的路由，且路由表中的路由项尽可能少.

| 目的网络 | 下一跳 | 接口 |
| --- | --- | --- |
| 192.1.1.0/24 | - | E0 |
| 192.1.5.0/24 | 10.1.1.10 | L1 |
| 192.1.6.0/24 | 10.1.1.2 | L0 |
| 192.1.7.0/24 | 10.1.1.2 | L0 |

(2) 当主机 192.1.1.130 向主机 192.1.7.211 发送一个 $TTL = 64$ 的 IP 分组时，R1 通过哪个接口转发该 IP 分组？主机 192.1.7.211 收到的 IP 分组的 $TTL$ 是多少？

R1 通过 L0 接口转发该 IP 分组. 主机 192.1.7.211 收到的 IP 分组的 $TTL$ 是 61.

(3) 若 R1 增加一条 Metric 为 10 的链路连接 Internet，则表中 R1 的 LSI 需要增加哪些信息？

需要增加一条 Link 记录（如 Link3）：Link ID（对端路由器或网络标识），Link IP（R1 连接 Internet 的接口 IP），Metric 10；同时增加一条 Net 记录（如 Net2）：网络前缀（如 0.0.0.0/0），Metric 10.

## DeepSeek V4 Flash Max 解析

**答案**：  
(1) 路由表如下：目的网络192.1.1.0/24下一跳“-”接口E0；192.1.5.0/24下一跳10.1.1.10接口L1；192.1.6.0/24下一跳10.1.1.2接口L0；192.1.7.0/24下一跳10.1.1.2接口L0。  
(2) R1通过L0接口转发；主机192.1.7.211收到的TTL为61。  
(3) 需增加一条Link记录：Link ID（对端路由器或网络标识）、Link IP（R1连接Internet的接口IP）、Metric 10；以及一条Net记录：网络前缀0.0.0.0/0，Metric 10。  

**解题切入点**：  
本题综合考查OSPF链路状态数据库与路由计算、IP分组的TTL变化、以及路由表生成。第一步应提取LSI中的拓扑信息，将路由器视为节点、链路视为边，构建带权无向图（链路费用为权值）。这类似于算法竞赛中根据边权构造图并运行最短路径（如Dijkstra）。然后计算R1到各子网的最短路径，确定下一跳和接口。TTL问题则需明确每经过一台路由器TTL减1，注意初始TTL=64，从源到目标经过的路由器数量。增加Internet连接时，需添加默认路由的链路状态宣告（LSA），对应一个虚设的邻居（或外部网络），并计算Metric。

**推演**：  
(1) 由LSI数据可得拓扑：R1与R2直连（费用3），R1与R3直连（费用2），R2与R4直连（费用4），R3与R4直连（费用6）。各路由器直连网络费用均为1。需计算R1到各子网的最短路径：  
- 到192.1.1.0/24：直连，接口E0，下一跳无（直接交付）。  
- 到192.1.5.0/24（连R3）：R1→R3，费用2（R1-L1），下一跳R1接口IP 10.1.1.10（对端R3的接口IP），接口L1。  
- 到192.1.6.0/24（连R2）：R1→R2，费用3，下一跳10.1.1.2，接口L0。  
- 到192.1.7.0/24（连R4）：可能路径：R1→R2→R4费用3+4=7；R1→R3→R4费用2+6=8。取最小费用7，下一跳为R1到R2的接口IP 10.1.1.2，接口L0。  
故路由表如上，注意聚合：无必要，四个子网不同，保持分离。  

(2) 主机192.1.1.130属于192.1.1.0/24网段，目标192.1.7.211属于192.1.7.0/24网段。R1查找路由表，匹配192.1.7.0/24，下一跳10.1.1.2（R2），接口L0。路径：R1→R2（1跳），R2→R4（2跳），R4→目标网络（R4到达目标网络1跳）。总共经过路由器数量：源主机到R1（1跳，但TTL由R1转发时减1），实际经过R1、R2、R4三个路由器，故TTL减少3。初始TTL=64，收到时TTL=64-3=61。  

(3) R1新增一条到Internet的链路，费用10。在OSPF的LSA中，需要增加一条Link记录，描述该点到点或点到多点连接的邻居信息（若Internet视为一个虚拟节点，则Router ID可设为0.0.0.0或特定标识），Link IP为R1连接Internet的接口IP，Metric为10。同时，由于Internet是一个外部网络，通常引入默认路由，故还需增加一条Net记录（或通过AS外部LSA宣告），网络前缀为0.0.0.0/0，Metric为10（Type1或Type2默认）。  

**易错点**：  
- 错将所有链路视为无向图，但LSI表中Link ID和IP隐含方向，计算路由时需根据本地接口IP确定出接口。例如R1到R2，R1的Link1 IP是10.1.1.1，即R1的接口IP，而下一跳应为对端IP（R2的接口IP 10.1.1.2）。  
- TTL计算时，误把源主机到R1也算一跳。实际上IP分组从主机发出时TTL初始值为64，主机发送时不减，仅路由器转发时减1。故经过路由器数量应统计从R1到目标主机的所有路由器跳数，包括目标网络路由器。  
- 第3问中，只增加Link记录而忘记增加默认路由的Net记录，或Metric选择错误（应为10）。  

**命题规律**：  
本题是OSPF综合应用的经典题，考点包括：  
- 根据LSA构建拓扑并计算最短路径树  
- 填写路由表（下一跳、接口）  
- IP分组TTL值变化  
- OSPF的LSA类型（路由器LSA^2、网络LSA、汇总LSA等）与默认路由的引入。  
变式：可改变链路费用求不同路径；加入等价多路径（ECMP）要求多条下一跳；增加ASBR引入外部路由。复习建议：熟练掌握Dijkstra算法在路由计算中的应用，理解下一跳与接口的区别，以及IP分组逐跳转发时TTL的递减机制。对OSPF的LAS类型和范围（区域内、区域间、外部）有清晰认识。

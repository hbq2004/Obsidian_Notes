# 综合题 第 4 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-44-F04_题目.png|题目]]

4.【2013统考真题】假设 Internet 的两个自治系统构成的网络如下图所示，自治系统 AS1 由路由器 R1 连接两个子网构成；自治系统 AS2 由路由器 R2、R3 互连并连接 3 个子网构成。各子网地址、R2 的接口名、R1 与 R3 的部分接口 IP 地址如下图所示。请回答下列问题：

【图：AS1 中 R1 连接子网 153.14.5.0/25 和 153.14.5.128/25，R1 下方接口 IP 为 153.14.3.2，连接 R2 的 S0 接口；AS2 中 R2 的 E0 接口连接子网 194.17.20.128/25，R2 与 R3 互连，R3 上方接口为 S1，IP 为 194.17.24.2，R3 连接子网 194.17.20.0/25 和 194.17.21.0/24。】

(1) 假设路由表结构如下表所示。利用路由聚合技术，给出 R2 的路由表，要求包括到达图中所有子网的路由，且路由表中的路由项尽可能少。

| 目的网络 | 下一跳 | 接口 |
| --- | --- | --- |
| | | |

(2) 若 R2 收到一个目的 IP 地址为 194.17.20.200 的 IP 分组，R2 会通过哪个接口转发该 IP 分组？

(3) R1 与 R2 之间利用哪个路由协议交换路由信息？该路由协议的报文被封装到哪个协议的分组中进行传输？

## DeepSeek V4 Flash Max 解析

**答案**：  
(1) R2 的路由表为：

| 目的网络 | 下一跳 | 接口 |
|---|---|---|
| $153.14.5.0/24$ | $153.14.3.2$ | S0 |
| $194.17.20.0/23$ | $194.17.24.2$ | S1 |
| $194.17.20.128/25$ | —（直接交付） | E0 |

理由：将 AS1 的两个 $/25$ 子网聚合成 $153.14.5.0/24$；将 R3 侧子网聚合成 $194.17.20.0/23$，同时保留 R2 直连的 $194.17.20.128/25$ 更精确路由。最少共 3 条。

(2) R2 会通过 **E0** 接口转发。

(3) R1 与 R2 属于不同自治系统，使用 **BGP**（eBGP）；BGP 报文封装在 **TCP 报文段**中传输，TCP 端口号为 179。

**解题切入点**：  
拿到题目先抓“R2 是中心路由器”，分清哪些子网在 R1 侧、哪些在 R3 侧、哪些直连在 R2 上。路由聚合本质是“前缀区间合并”，和算法竞赛中把若干区间合并成最少区间一样；最长前缀匹配则像在 0/1 Trie 中找最深的匹配节点。跨自治系统交换路由信息，不能再用内部网关协议，应直接定位到 BGP，并注意 BGP 是跑在 TCP 上的。

**推演**：  
R2 的接口关系：S0 连 R1，S1 连 R3，E0 连 $194.17.20.128/25$。

AS1 侧两个子网：
$$
153.14.5.0/25 \quad\text{和}\quad 153.14.5.128/25
$$
它们正好组成一个 $/24$，所以聚合为：
$$
153.14.5.0/24
$$
下一跳是 R1 的接口 IP $153.14.3.2$，从 S0 发出。

AS2 侧：  
R2 直连子网是：
$$
194.17.20.128/25
$$
R3 侧子网是：
$$
194.17.20.0/25,\quad 194.17.21.0/24
$$
R3 侧两个子网可用 $194.17.20.0/23$ 概括。注意，$194.17.20.0/23$ 也覆盖了 $194.17.20.128/25$，所以必须保留一条更精确的直连路由 $194.17.20.128/25 \to E0$。转发时按最长前缀匹配，不会把 $194.17.20.128/25$ 内的目的地址错误送到 R3。

因此 R2 路由表如下：

| 目的网络 | 下一跳 | 接口 |
|---|---|---|
| $153.14.5.0/24$ | $153.14.3.2$ | S0 |
| $194.17.20.0/23$ | $194.17.24.2$ | S1 |
| $194.17.20.128/25$ | —（直接交付） | E0 |

若不聚合，需 5 条；聚合后只需 3 条。

第(2)问：目的 IP 为 $194.17.20.200$。它满足：
$$
194.17.20.200 \in [194.17.20.128, 194.17.20.255]
$$
所以匹配 $194.17.20.128/25$，同时它也匹配 $194.17.20.0/23$，但 $/25$ 前缀更长，因此选择 E0 直接交付。

第(3)问：R1 与 R2 分别属于 AS1 和 AS2，是自治系统之间的边界路由器，因此使用 BGP。BGP 使用 TCP 作为传输层协议，所以 BGP 报文先封装在 TCP 报文段中，TCP 报文段再封装进 IP 分组。

**易错点**：  
- 不能把 $194.17.20.0/25$ 和 $194.17.20.128/25$ 简单地合并成一条下一跳为 R3 的 $194.17.20.0/24$ 路由，因为后者是 R2 直连子网，下一跳不同。  
- 不能按路由表“从上到下”匹配；必须按最长前缀匹配。例如 $194.17.20.200$ 即使也匹配 $194.17.20.0/23$，仍应选择 $194.17.20.128/25$。  
- 跨自治系统不能用 RIP、OSPF 等内部网关协议，应选 BGP。  
- BGP 不是封装在 UDP 中，也不是直接封装在 IP 中；BGP 使用 TCP 端口 179。

**命题规律**：  
本题是 408 中典型的“CIDR 路由聚合 + 最长前缀匹配 + 域间路由协议”综合题。常见变式包括：给一组子网设计最少路由表项、判断某个目的 IP 的下一跳和出口接口、比较 RIP/OSPF/BGP 的封装协议。复习时应熟练掌握 IP 地址二进制划分和前缀合并，牢记 RIP over UDP、OSPF over IP、BGP over TCP 的区别。

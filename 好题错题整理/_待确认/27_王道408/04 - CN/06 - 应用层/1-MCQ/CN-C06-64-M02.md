# 选择题 第 2 题

![[_Attachments/题目识别/27_王道408-题目/CN-C06-64-M02_题目.png|题目]]

2. SMTP 基于传输层的（\_）协议，POP3 基于传输层的（\_）协议.

(A) TCP,TCP  
(B) TCP,UDP  
(C) UDP,UDP  
(D) UDP,UDP

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C06-64-M02_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：A。SMTP 与 POP3 均基于传输层的 TCP 协议，因为二者都需要可靠传输邮件数据。

**解题切入点**：看到“基于传输层的协议”，立刻定位到应用层协议与传输层端口的对应关系。可以把应用层协议看成“上层应用”，传输层协议看成“传输管道”：邮件不能丢、不能乱，所以必须选可靠管道 TCP。类比算法竞赛中，需要保证数据完整性的操作要选用“带确认的重传机制”，而不是“尽最大努力交付”的 UDP。

**推演**：

- SMTP（简单邮件传输协议）用于发送邮件，端口号为 25（或 587）。邮件内容必须可靠到达收件方，因此 SMTP 在传输层使用 **TCP**。
- POP3（邮局协议第 3 版）用于接收邮件，端口号为 110。同样需要可靠传输，因此 POP3 在传输层也使用 **TCP**。
- 常见邮件相关协议中，IMAP 也使用 TCP，Web 邮箱的 HTTP/HTTPS 也基于 TCP。

所以两个空都应填 TCP，即选项 A。

**易错点**：

1. 误以为 POP3 是“取邮件”，可以容忍丢失，从而选 UDP —— 错误。邮件数据必须完整，POP3 同样基于 TCP。
2. 把 SMTP 与 DNS、SNMP 混淆，DNS 查询可使用 UDP（主用），SNMP 也使用 UDP，但邮件协议均使用 TCP。
3. 选项 D 写成 “UDP,UDP” 属于明显干扰项，注意区分。

**命题规律**：408 网络部分常考应用层协议与传输层协议、端口号的对应关系。常见变式包括：DNS 使用 UDP/TCP（53），DHCP 使用 UDP（67/68），HTTP/HTTPS、FTP、Telnet、SMTP、POP3、IMAP 均基于 TCP。复习时应建立“应用层协议 → 传输层协议 → 端口号”的表格，并理解“可靠传输需求”是选择 TCP 的根本原因。

# 选择题 第 10 题

![[_Attachments/题目识别/27_王道408-题目/CN-C06-63-M10_题目.png|题目]]

10.一台计算机从 $FTP$ 服务器下载文件时,在该 $FTP$ 服务器上对数据进行封装的 5 个转换步骤是( )

A. 比特,数据帧,数据报,数据段,数据

B. 数据,数据段,数据报,数据帧,比特

C. 数据报,数据段,数据,比特,数据帧

D. 数据段,数据报,数据帧,比特,数据

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C06-63-M10_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：B。FTP 服务器是发送方，数据封装按“数据 → 数据段 → 数据报 → 数据帧 → 比特”的顺序进行。

**解题切入点**：先判断发送方和接收方：从 FTP 服务器下载文件，服务器负责发送，所以执行的是“封装”过程。封装是从高层到低层，逐层添加首部（或帧头/帧尾）。这和算法竞赛中“自顶向下分治、逐层传入参数”类似：每层协议只处理自己那一层的“数据结构”，再向下传递。定位到协议栈为 TCP/IP 后，关键是记住各层 PDU 名称。

**推演**：

1. FTP 属于应用层协议，传输的是应用层报文，此时数据形态为 **数据**。
2. FTP 使用 TCP 作为传输层协议，TCP 给应用层数据添加 TCP 首部，封装成 **数据段**（segment）。
3. 网络层使用 IP 协议，给数据段添加 IP 首部，封装成 **数据报**（datagram，也称 IP 分组）。
4. 数据链路层给数据报添加帧头和帧尾，封装成 **数据帧**（frame）。
5. 物理层将数据帧看作比特串，转换成在介质上传输的 **比特**（bit）。

因此，在 FTP 服务器上对数据进行封装的 5 个转换步骤是：

$$\text{数据} \rightarrow \text{数据段} \rightarrow \text{数据报} \rightarrow \text{数据帧} \rightarrow \text{比特}$$

对应选项 B。

**易错点**：

- 容易把发送方和接收方搞混：下载文件时，客户端是接收方，执行的是“解封装”；但题目问的是 **FTP 服务器**，服务器是发送方，执行“封装”。
- 容易混淆各层 PDU 名称：传输层 TCP 是“数据段”，网络层 IP 是“数据报”，数据链路层是“帧”，物理层是“比特”。
- 容易把顺序倒过来：选项 D 是“数据段 → 数据报 → 数据帧 → 比特 → 数据”，漏掉了最上层的“数据”，并且把接收方的流程误当成发送方。

**命题规律**：本题考查 TCP/IP 协议栈中“封装/解封装”过程以及各层 PDU 名称。常见变式有：给出接收方解封装顺序（比特 → 帧 → 数据报 → 数据段 → 数据），或给出 HTTP、FTP、Telnet 等具体应用层协议判断其所属层次。复习时应画清五层协议栈，标注每层 PDU 名称，并理解“发送方逐层加首部，接收方逐层去首部”的核心思想。

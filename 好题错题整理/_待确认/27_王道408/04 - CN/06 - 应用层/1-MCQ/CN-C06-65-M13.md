# 选择题 第 13 题

![[_Attachments/题目识别/27_王道408-题目/CN-C06-65-M13_题目.png|题目]]

13. 主机通过超链接 http://www.cskaoyan.com/index.html 请求浏览 Web 页 index.html,若浏览器使用流水线方式的 HTTP/1.1 协议,该 Web 页引用了同一网站上的 7 个小图像文件,假设主机到本地域名服务器和互联网上各服务器的往返时延均为 1RTT。本地域名服务器只提供递归查询服务，其他域名服务器只提供迭代查询服务，忽略其他所有时延，则从点击超链接开始到浏览器接收到所有内容为止，所需的往返时间 RTT 数最多是（  ）
(A) 5
(B) 6
(C) 7
(D) 8

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C06-65-M13_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：C（7）。  
总共最多为：DNS 解析 $4$ 个 RTT，加上 Web 传输阶段 $3$ 个 RTT（TCP 连接 $1$ + 获取 index.html $1$ + 流水线获取 7 个小图像 $1$），即 $4+3=7$ 个 RTT。

**解题切入点**：  
拿到题目先按协议栈切段：DNS 解析 → TCP 连接建立 → HTTP 请求/响应。  
这就像算法里的“串行依赖”与“批量并行”：DNS 的递归/迭代查询是串行的，每一级都要等前一级返回；而 HTTP/1.1 流水线则像一次批量请求，7 个图像可以在一个往返内批量收到，而不是分别花 7 个 RTT。

**推演**：

1. **DNS 解析（最多无缓存情况）**  
   主机访问 `www.cskaoyan.com`，需要先解析域名。

   - 主机向本地域名服务器发起递归查询：$1$ RTT；
   - 本地域名服务器向根域名服务器、`.com` 顶级域名服务器、`cskaoyan.com` 权威域名服务器依次迭代查询：各 $1$ RTT，共 $3$ RTT。

   所以 DNS 阶段最多为：
   $$
   T_{DNS}=1+3=4 \text{ RTT}
   $$

2. **TCP 建立连接**  
   获得 IP 后，浏览器需要与 Web 服务器建立 TCP 连接。TCP 三次握手需要 $1$ 个 RTT：
   $$
   T_{TCP}=1 \text{ RTT}
   $$

3. **HTTP 获取 index.html 和 7 个小图像**  
   TCP 第三次握手时，可以捎带发送 `GET /index.html`。服务器收到后返回页面，这个过程需要 $1$ 个 RTT。

   浏览器收到 index.html 后，才能解析出其中的 7 个图像 URL。由于 7 个图像在同一网站上，无需再 DNS 解析；并且浏览器使用 HTTP/1.1 流水线方式，可以在同一个 TCP 连接上连续发出 7 个图像请求，服务器也连续返回。忽略传输和处理时延，这 7 个图像总共只需要 $1$ 个 RTT。

   $$
   T_{HTTP}=1+1=2 \text{ RTT}
   $$

4. **总时间**  
   $$
   T=T_{DNS}+T_{TCP}+T_{HTTP}=4+1+2=7 \text{ RTT}
   $$

   因此选 **C**。

**易错点**：  
- 容易忘记 TCP 连接建立需要 $1$ 个 RTT，从而误选 B（6）。本题问“从点击超链接开始”，所以 Web 阶段必须从 TCP 握手开始算。  
- DNS 解析不能只算“主机到本地域名服务器”的 $1$ 个 RTT；在无缓存的最坏情况下，本地域名服务器还要迭代查询根、顶级、权威域名服务器，共 $4$ 个 RTT。  
- 容易把 7 个图像算成 $7$ 个 RTT；那是非流水线 HTTP/1.1 或 HTTP/1.0 的做法。流水线方式下，批量请求只需 $1$ 个 RTT。  
- 注意图像请求不能与 index.html 请求一起发送，因为浏览器必须收到 index.html 后才知道图像的 URL，所以 index.html 本身仍占 $1$ 个 RTT。

**命题规律**：  
本题综合考查 DNS 递归/迭代查询、TCP 连接建立、HTTP/1.1 持久连接与流水线，是 408 中典型的“RTT 计数”综合题。  
常见变式包括：改成非流水线 HTTP/1.1、HTTP/1.0、图像数量改为 $N$、考虑 DNS 缓存命中、考虑多个不同域名的图像等。  
复习时应建立固定阶段框架：**DNS 解析 → TCP 连接 → HTTP 请求/响应**，并注意区分“一次请求/响应 = 1 RTT”和“流水线批量请求 = 覆盖同一 RTT”。

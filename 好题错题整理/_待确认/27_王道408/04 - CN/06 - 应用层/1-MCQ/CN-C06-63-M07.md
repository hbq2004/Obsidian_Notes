# 选择题 第 7 题

![[_Attachments/题目识别/27_王道408-题目/CN-C06-63-M07_题目.png|题目]]

7. 下列关于 *FTP* 的叙述中, 错误的是 ( )

A. *FTP* 可以实现异构网络中计算机之间的文件传送
B. 在进行文件传输时, *FTP* 客户端和服务器之间需建立两个连接
C. *FTP* 服务器主进程在 20 端口上监听客户端的连接请求
D. *FTP* 使用 *TCP* 进行可靠传输

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C06-63-M07_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：C。FTP 服务器主进程在 **21 号端口**监听客户端的控制连接请求，而 20 端口是主动模式下用于数据传输的端口，不是监听连接请求的端口。

**解题切入点**：看到 FTP 题，立刻锁定“端口号”和“连接数”两个关键考点。可以把 FTP 的“控制连接 + 数据连接”类比为算法竞赛中的“两阶段流程”：控制连接是“主线程/调度器”，负责传递命令；数据连接是“工作线程”，负责实际搬运文件。题目问“错误的是”，相当于在代码里找一个逻辑漏洞——A、B、D 都是 FTP 的核心特性，只有 C 在端口上偷换了概念。

**推演**：

1. **FTP 的跨异构性**：FTP 工作在应用层，底层使用 TCP/IP 协议族，屏蔽了底层操作系统和硬件差异，因此可以实现异构网络中计算机之间的文件传送。故 A 正确。

2. **两个连接**：FTP 使用两个并行的 TCP 连接：
   - **控制连接**：端口 21，传输 FTP 命令和应答，贯穿整个会话；
   - **数据连接**：端口 20（主动模式）或随机端口（被动模式），用于传输文件数据。
   因此 B 正确。

3. **端口监听**：FTP 服务器的主进程（协议解释器）始终在 **21 端口**监听客户端的控制连接请求。当需要传输数据时，服务器才在主动模式下从 20 端口发起数据连接，而 20 端口并不是监听端口。C 把 20 端口误认为监听端口，所以 C 错误。

4. **可靠传输**：FTP 使用 TCP 作为传输层协议，TCP 提供面向连接的可靠字节流服务，保证文件传输的可靠性。故 D 正确。

综上，错误的是 C。

**易错点**：
- **混淆控制/数据端口**：常见错误是把 21 记成数据端口、20 记成控制端口。记忆口诀：**控制 21，数据 20**。
- **忽视主动/被动模式差异**：主动模式服务器用 20 端口连客户端，被动模式服务器指定一个随机端口由客户端连接，因此“20 端口”并非绝对的数据端口。
- **误以为 FTP 只用单一连接**：FTP 有两个连接（控制 + 数据），与 HTTP 等单连接应用不同，需特别区分。

**命题规律**：FTP 是应用层常考协议，考点集中在：
- 端口号（21 控制、20 数据）；
- 两个连接的用途与建立时机；
- 与 HTTP、SMTP、POP3 等应用层协议的端口对比。

常见变式：给出端口号判断协议、考查主动/被动模式、结合 TCP 可靠性考查传输机制。复习时建议把常见应用层协议（FTP、HTTP、SMTP、POP3、DNS、DHCP）的端口、传输层协议、连接特点整理成表，对比记忆，尤其注意“控制连接”与“数据连接”的时序关系。

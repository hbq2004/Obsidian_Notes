# 选择题 第 14 题

![[_Attachments/题目识别/27_王道408-题目/CN-C06-63-M14_题目.png|题目]]

14.【2017统考真题】下列关于FTP的叙述中，错误的是（ ）.
(A) 数据连接在每次数据传输完毕后就关闭
(B) 控制连接在整个会话期间保持打开状态
(C) 服务器与客户端的TCP20端口建立数据连接
(D) 客户端与服务器的TCP21端口建立控制连接

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C06-63-M14_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：C。FTP 的数据连接并不是“服务器去连接客户端的 TCP 20 端口”；主动模式下是服务器用 TCP 20 端口主动连接客户端的临时端口，被动模式下则是由客户端连接服务器的临时端口。

**解题切入点**：拿到题目先抓住关键词“FTP、控制连接、数据连接、20/21 端口”。这题本质是考查 FTP 双连接的“谁发起、连到谁”的细节。可以用算法竞赛的思维来类比：控制连接相当于一个常驻的 session/主循环，数据连接相当于每次任务临时创建的 worker；端口号就是约定好的“入口地址”和“回调地址”。主动模式约等于 server 主动回调 client 的临时端口，被动模式约等于 client 主动拉取 server 的临时端口。

**推演**：

FTP 使用两个并行的 TCP 连接：

- 控制连接：客户端用一个临时端口主动连接服务器的 TCP 21 端口，用于传输命令和响应，整个会话期间保持打开，直到用户退出。  
  因此选项 B、D 正确。

- 数据连接：仅在传输文件或目录列表时临时建立，每次数据传输完毕后就关闭。  
  因此选项 A 正确。

关键看数据连接的建立方式：

- 主动模式下，服务器使用 TCP 20 端口主动连接客户端的临时端口，连接端点形如：
  $$ \text{server}:20 \leftrightarrow \text{client}:\text{临时端口} $$
  注意是“客户端的临时端口”，不是“客户端的 TCP 20 端口”。

- 被动模式下，服务器开放一个临时端口，由客户端主动连接服务器该临时端口，通常也不是服务器 20 端口。

所以 C 说“服务器与客户端的 TCP 20 端口建立数据连接”是错误的。

**易错点**：

1. 混淆控制连接与数据连接的端口：控制连接是客户端连服务器 21，数据连接主动模式下是服务器 20 连客户端临时端口。
2. 误以为 FTP 数据连接一定使用 20 端口：20 端口的说法只在主动模式下成立，且是服务器端的源端口；被动模式下服务器使用临时端口。
3. 误把控制连接当作“传文件”的连接：控制连接只传命令和响应，不传文件数据。
4. 搞混“主动/被动”的发起方向：主动模式是服务器主动连客户端，被动模式是客户端主动连服务器。
5. 规避方法：画一张“连接方向图”，把控制连接、数据连接、主动/被动模式分别列出端口和发起方，就能避免这类错误。

**命题规律**：这是 2017 年统考真题，考点是 FTP 协议的双连接模型和默认端口，属于应用层协议的常考细节。常见变式包括：主动模式与被动模式的端口变化、FTP 数据连接是否持久、控制连接在整个会话期间是否一直存在、以及 FTP 与 HTTP/SMTP/POP3/DNS 等协议端口混考。复习时建议把常见应用层协议默认端口、连接模型和“谁主动发起连接”整理成表格记忆，重点区分“控制连接”和“数据连接”的生命周期。

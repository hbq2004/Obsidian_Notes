# 选择题 第 12 题

![[_Attachments/题目识别/27_王道408-题目/CN-C06-62-M12_题目.png|题目]]

12.【2016统考真题】假设所有域名服务器均采用迭代查询方式进行域名解析。当主机访问规范域名为 www.abc.xyz.com 的网站时，本地域名服务器在完成该域名解析的过程中，可能发出 DNS 查询的最少和最多次数分别是（ ）

(A) 0,3  
(B) 1,3  
(C) 0,4  
(D) 1,4

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C06-62-M12_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：C。最少为 0 次，最多为 4 次。

理由：本地域名服务器若缓存命中，可直接返回结果，不需要发出任何 DNS 查询；若缓存未命中，采用迭代查询时，需依次查询根域名服务器、`.com` 顶级域名服务器、`xyz.com` 权限域名服务器、`abc.xyz.com` 权限域名服务器，共 4 次。

**解题切入点**：拿到题先抓两个关键词：“迭代查询”和“可能”。迭代查询可以看成在多级链表或字典树中查找：每个服务器只告诉“下一跳”地址，不替本地域名服务器继续查；本地域名服务器需要自己依次访问下一层。对应算法竞赛里的“记忆化搜索”，如果缓存命中，直接返回，代价为 0；否则就沿链表/树一层层找下去。域名系统本身就像一棵多级索引树：`com → xyz.com → abc.xyz.com`。

**推演**：

设本地域名服务器发出的 DNS 查询次数为 $N$。主机向本地域名服务器发送的首次解析请求不算“本地域名服务器发出”的查询。

- 若本地域名服务器的高速缓存中已有 `www.abc.xyz.com` 对应的 IP 地址，则直接回答主机，此时
  $$
  N_{\min}=0
  $$

- 若缓存未命中，则需进行迭代查询，最坏情况下过程如下：

  1. 本地域名服务器 → 根域名服务器：查询 `www.abc.xyz.com`，根返回 `.com` 顶级域名服务器地址；
  2. 本地域名服务器 → `.com` 顶级域名服务器：查询 `www.abc.xyz.com`，返回 `xyz.com` 权限域名服务器地址；
  3. 本地域名服务器 → `xyz.com` 权限域名服务器：查询 `www.abc.xyz.com`，返回 `abc.xyz.com` 权限域名服务器地址；
  4. 本地域名服务器 → `abc.xyz.com` 权限域名服务器：查询 `www.abc.xyz.com`，得到最终 IP 地址。

  因此
  $$
  N_{\max}=4
  $$

综合得最少的可能查询次数为 0，最多的可能查询次数为 4，所以选 C。

**易错点**：

1. 不要把主机发给本地域名服务器的那一次 DNS 查询计入“本地域名服务器发出”的次数，否则会误以为最少是 1。
2. 不要漏掉 `abc.xyz.com` 这层权限域名服务器，否则会把最多算成 3。
3. 不要把 `www` 也当成一层独立授权域名服务器再查一次，否则会多算成 5；这里的 `www` 是主机名，不是需要单独查询的权限域。
4. 不要忽略“可能”二字，缓存命中时可以直接返回，因此最少可以是 0。

**命题规律**：本题考查 DNS 解析过程、迭代查询与缓存机制，是 408 计算机网络中 DNS 部分的常考选择题。常见变式包括：把迭代查询改成递归查询、给出各级缓存情况求查询次数、询问整个过程中收到/发出的 DNS 报文数量等。复习时建议画域名树，熟记解析顺序：根域名服务器 → 顶级域名服务器 → 权限域名服务器，并注意区分“查询”与“响应”、“发出”与“收到”。

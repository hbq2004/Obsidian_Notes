# 选择题 第 10 题

![[_Attachments/题目识别/27_王道408-题目/CN-C06-65-M10_题目.png|题目]]

10. 以下关于非持续连接 *HTTP* 特点的描述中，错误的是（ ）

(A) *HTTP* 支持非持续连接与持续连接

(B) *HTTP*/1.0 使用非持续连接，而 *HTTP*/1.1 的默认方式为持续连接

(C) 非持续连接中对每次请求 / 响应都要建立一次 *TCP* 连接

(D) 非持续连接中读取一个包含 100 个图片对象的 *Web* 页面，需要打开和关闭 100 次 *TCP* 连接

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C06-65-M10_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：D。非持续连接中，读取含 100 个图片对象的 Web 页面需要先获取基本 HTML 文件，再获取 100 个图片对象，共 $101$ 个对象，因此需打开/关闭 $101$ 次 TCP 连接，而非 $100$ 次。

**解题切入点**：这题本质是“计数”问题，类似算法竞赛中统计元素数量时不能漏掉初始元素/根节点。握手协议或分层协议可以看成“每次请求建立一个连接”，而 Web 页面的基本 HTML 文件本身就是一个对象，需要单独一次 TCP 连接。所以先定位考点：HTTP 的非持续连接（Non-persistent Connection）与持续连接（Persistent Connection），再数对象个数即可。

**推演**：

- 非持续连接：HTTP 客户端与服务器之间，每次请求/响应都需重新建立 TCP 连接，完成一次请求-响应后连接即关闭。
- 一个 Web 页面包含基本 HTML 文件和若干嵌入对象（图片、视频、脚本等）。设嵌入对象数为 $n$，则该页面共包含 $n+1$ 个对象（基本文件 $+$ $n$ 个嵌入对象）。
- 题目中 $n = 100$（图片对象），因此总对象数为：
$$n + 1 = 100 + 1 = 101$$
- 在非持续连接中，每个对象的获取都需要一次独立的 TCP 连接，所以 TCP 连接总次数为 $101$ 次。

因此选项 D 说“需要打开和关闭 $100$ 次 TCP 连接”是错误的，漏算了基本 HTML 文件所需的连接。

**易错点**：

1. **漏算基本 HTML 文件**：容易直接认为有 100 个图片就对应 100 次 TCP 连接，忽略访问页面本身时还需要请求 HTML 文档。规避方法：见到“包含 $k$ 个对象的页面”，先写总数 $k+1$。
2. **混淆持续连接与非持续连接**：持续连接中，多个对象可在同一 TCP 连接上按顺序或并行传输，因此连接次数可能少得多；但题目明确限定“非持续连接”，必须逐个连接。
3. **忽视 HTTP 版本特性**：B 选项本身正确，但若题目改为“HTTP/1.1 默认非持续连接”就错了，需牢记 HTTP/1.1 默认持续连接。

**命题规律**：本题属于 HTTP 协议基础考点，常以选择题形式考查非持续/持续连接的含义、TCP 连接次数计算，以及 HTTP/1.0 与 HTTP/1.1 的默认连接方式。常见变式有：

- 给定一个包含 $m$ 个对象（包括基本文件）的页面，在非持续连接下需要多少次 TCP 连接；
- 在持续连接（流水线/非流水线）下需要多少次 TCP 连接；
- 结合 RTT（往返时间）计算页面响应时间。

复习建议：将 TCP 连接建立（三次握手）与 HTTP 请求/响应关系画成时间序列图，理解“非持续连接 = 每个对象一个连接”，并牢记 HTTP/1.0 默认非持续连接、HTTP/1.1 默认持续连接。做题时先判断“对象总数”，再套连接方式，可避免低级错误。

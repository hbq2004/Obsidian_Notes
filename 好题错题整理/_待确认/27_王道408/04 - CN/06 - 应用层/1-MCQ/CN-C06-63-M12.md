# 选择题 第 12 题

![[_Attachments/题目识别/27_王道408-题目/CN-C06-63-M12_题目.png|题目]]

12. 直接封装 FTP、DNS、DHCP 报文的协议分别是（\_）

(A) TCP、UDP、UDP

(B) UDP、TCP、TCP

(C) TCP、UDP、IP

(D) UDP、UDP、UDP

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C06-63-M12_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：A。FTP 基于 TCP（控制/数据连接均用 TCP），DNS 与 DHCP 均直接封装在 UDP 中。本题直接考查“应用层协议到底跑在 TCP 还是 UDP 上”。

**解题切入点**：先明确这是一道“传输层封装关系”的记忆/辨析题，核心是分清 TCP 与 UDP 的典型应用。可类比算法竞赛中“根据业务需求选择数据结构”：FTP 要传文件、必须可靠有序，所以用“自带重传排序的 TCP”；DNS 域名查询是“一问一答、超时重试”的短请求，DHCP 是“广播找服务器、可能失败重试”的配置请求，二者都适合“无连接、轻量的 UDP”。还容易混淆的是“DNS 也用 TCP”，但那是区域传送或响应超大时的情况，常规查询直接封装 UDP。

**推演**：

1. FTP（文件传输协议）
   - 功能：可靠地传输文件，需要确认、重传、流量控制。
   - 传输层协议：TCP，使用端口 21（控制连接）和 20（数据连接）。
   - 因此 FTP 的报文不能由 UDP 封装，否则会丢包丢数据。

2. DNS（域名系统）
   - 功能：域名到 IP 地址的解析，查询过程通常是一个请求包、一个响应包。
   - 常规查询：直接封装在 UDP 中，端口 53。
   - 特殊情况：当响应报文长度超过 512 B（或 EDNS0 协商的更大值）时，或进行区域传送时，才使用 TCP。题目问“直接封装”的默认情况，应为 UDP。

3. DHCP（动态主机配置协议）
   - 功能：主机自动获取 IP 地址、子网掩码、默认网关等配置。
   - 传输层协议：UDP，客户端端口 68，服务器端口 67。
   - DHCP 报文需要广播（如 DHCP Discover），UDP 更适合广播场景；DHCP 靠客户端超时重传保证可靠性，而不是依赖 TCP。

综上，三者对应关系为：
$$
\text{FTP} \rightarrow \text{TCP},\qquad
\text{DNS} \rightarrow \text{UDP},\qquad
\text{DHCP} \rightarrow \text{UDP}.
$$

所以正确选项为 A。

**易错点**：

- 混淆 DNS 的传输层协议：很多人记得“DNS 用 UDP”，但看到选项里 DNS 对应 TCP 时犹豫。注意默认查询是 UDP，只有在区域传送或响应超长时才用 TCP。
- 混淆 DHCP 与 TFTP：DHCP 是 UDP，TFTP 也是 UDP；但 FTP 是 TCP，不要看到“F”就以为 FTP 也是 UDP。
- 记错端口号导致推理混乱：FTP 21/20、DNS 53、DHCP 67/68，端口号本身不是本题直接考点，但熟悉端口能帮助快速排除选项。
- 忽略“直接封装”的限定：题目问的是“直接”由哪个传输层协议封装，不是问“可以借助哪些协议”。例如 DNS 也可以借助 TCP，但直接封装默认是 UDP。

**命题规律**：该考点属于传输层与应用层的交界处，是 408 选择题常考的“协议栈对应关系”。常见变式包括：

- 给出一组应用层协议，问哪些使用 TCP、哪些使用 UDP，如 HTTP、FTP、SMTP、POP3、IMAP 用 TCP，DNS、DHCP、TFTP、SNMP、RIP 用 UDP。
- 结合端口号考查：如“DNS 默认端口 53，使用 UDP”，或“DHCP 客户端端口 68，服务器端口 67”。
- 结合“可靠传输需求”考原理：文件传输需要可靠，所以选 TCP；域名解析和配置获取可容忍重试，所以选 UDP。

复习建议：把常见应用层协议按“TCP 阵营”和“UDP 阵营”列表整理，并记忆典型端口；同时理解“为什么这样选”比死记更可靠——需要可靠传输、长连接、大量数据用 TCP，短请求、广播、可超时重试、低开销用 UDP。

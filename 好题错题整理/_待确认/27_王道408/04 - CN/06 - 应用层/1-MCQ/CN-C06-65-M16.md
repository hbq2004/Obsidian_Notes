# 选择题 第 16 题

![[_Attachments/题目识别/27_王道408-题目/CN-C06-65-M16_题目.png|题目]]

16.【2014统考真题】使用浏览器访问某大学的 Web 网站主页时，不可能使用到的协议是（ ）

(A) PPP

(B) ARP

(C) UDP

(D) SMTP

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C06-65-M16_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：D。SMTP 是邮件传输协议，浏览器访问 Web 网页时不会用到。

**解题切入点**：拿到题目先抓场景：浏览器访问 Web 主页，涉及从应用层到物理层的协议栈。定位考点是各层协议的实际应用场景，类似于算法竞赛中构造辅助函数对应构造计数/数据结构，分治对应分层协议，这里需要判断每个协议是否可能出现在该过程中。

**推演**：浏览器访问 Web 主页的典型流程如下：
1. 应用层：浏览器使用 HTTP/HTTPS（基于 TCP）获取网页内容。
2. 传输层：HTTP 使用 TCP，不会直接使用 UDP；但浏览器在访问前需要 DNS 解析域名，DNS 通常使用 UDP（也可用 TCP）。
3. 网络层：IP 协议必然使用，路由器转发可能涉及其他协议，但与本题选项无关。
4. 数据链路层：若主机在以太网中，ARP 用于将网关 IP 解析为 MAC 地址，因此可能用到；若通过拨号（如 PPPoE）接入，则 PPP 可能被使用。
5. SMTP 是专门用于电子邮件发送的协议，与网页浏览无关，不可能出现在该过程中。
因此，不可能使用到的协议是 SMTP。

**易错点**：常见错误是误以为 UDP 不可用（因为 HTTP 用 TCP），但忽略了 DNS 查询通常使用 UDP；或认为 PPP 一定不用，但实际在宽带拨号等场景下可能用到。规避方法：全面分析协议栈各层，结合具体应用过程逐一排查。

**命题规律**：考点集中在常见协议（如 HTTP、DNS、ARP、PPP、SMTP 等）的典型应用场景，常以选择题形式考查协议与应用的对应关系。变式可能问“发送邮件时不可能用到的协议”或“访问网页时可能用到的协议”等。复习建议：系统梳理各层协议功能，并记忆典型应用案例。

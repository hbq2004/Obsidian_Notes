# 选择题 第 13 题

![[_Attachments/题目识别/27_王道408-题目/CN-C06-62-M13_题目.png|题目]]

13.【2018统考真题】下列 TCP/IP 应用层协议中，可以使用传输层无连接服务的是（ ）.

(A) FTP  
(B) DNS  
(C) SMTP  
(D) HTTP

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C06-62-M13_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：B。DNS 可以使用传输层无连接服务（UDP）；而 FTP、SMTP、HTTP 在传统 TCP/IP 协议栈中均依赖面向连接的 TCP。

**解题切入点**：先抓题干关键词“传输层无连接服务”，它直接对应 UDP。然后判断哪个应用层协议可以运行在 UDP 之上。这就像算法竞赛中拿到“底层只支持 push/pop”的约束，先确定数据结构用栈，再选能在该 API 下实现的算法。分层协议也像分治：上层应用只需调用下层服务接口，不用关心中间细节；题目问的是“可以使用”，不是“默认必须使用”，所以只需找到能调用 UDP 服务的应用协议。

**推演**：

- 传输层主要提供两种服务：  
  TCP 面向连接，提供可靠、按序的字节流；  
  UDP 无连接，提供尽力而为的数据报服务。
- 逐个分析选项：
  - **FTP**：文件传输协议，控制连接和数据连接都要求可靠传输，使用 TCP。
  - **SMTP**：简单邮件传输协议，邮件不能丢失，要求可靠交付，使用 TCP。
  - **HTTP**：超文本传输协议，传统版本基于 TCP。
  - **DNS**：域名解析协议。客户端向 DNS 服务器发送一个查询请求，服务器返回一个响应，报文通常很短，每次查询相互独立，因此可以使用 UDP 完成，开销小、延迟低。若响应较大或进行区域传送时，DNS 也可以改用 TCP。
- 因此，四个选项中能够使用传输层无连接服务的是 **DNS**。

**易错点**：

- 误把“使用端口号”等同于“使用 TCP”。DNS 使用端口 53，但 TCP 和 UDP 共用端口号，使用端口 53 不代表必须用 TCP。
- 误以为所有应用都需要可靠传输，从而排除 DNS。实际上 DNS 查询是典型的“请求-应答”模式，单个查询丢失后可由应用层重试，因此可以优先使用 UDP。
- 用现代 HTTP/3 反驳。HTTP/3 基于 QUIC，而 QUIC 运行在 UDP 之上，但 408 考纲和 2018 年真题语境中的 HTTP 指传统基于 TCP 的版本，不应按新协议选答案。

**命题规律**：考点是 TCP/IP 协议栈中应用层协议与传输层协议的映射关系。常见变式有：直接问“下列协议中使用 UDP 的是”“DNS 可使用的传输层协议是”“某协议默认端口号”等。复习时建议把常见应用层协议按 TCP/UDP 分组记忆：TCP 族包括 FTP、SMTP、HTTP、Telnet、POP3、IMAP；UDP 族包括 DNS、DHCP、SNMP、TFTP；同时注意例外，如 DNS 也可以使用 TCP。做到“协议—端口—传输层服务”三者关联记忆。

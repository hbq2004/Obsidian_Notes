# 选择题 第 4 题

![[_Attachments/题目识别/27_王道408-题目/CN-C06-65-M04_题目.png|题目]]

4. 从某个已知的 URL 获得一个万维网文档时, 若该万维网服务器的 IP 地址开始时并不知道, 则需要用到的应用层协议有 (①)， 需要用到的传输层协议有 (②).
①
(A) FTP、HTTP
(B) DNS、FTP
(C) DNS、HTTP
(D) TELNET、HTTP
②
(A) UDP
(B) TCP
(C) UDP、TCP
(D) TCP、IP

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C06-65-M04_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：① C，② C。已知 URL 但不知道服务器 IP 时，需要先用 DNS 解析出服务器 IP，再用 HTTP 获取万维网文档；DNS 通常使用 UDP，HTTP 使用 TCP，因此传输层需要 UDP 和 TCP。

**解题切入点**：拿到题目先抓“完整流程”，不要只盯着 HTTP。可以类比算法题中的“状态转移”：输入是 URL，中间状态是“IP 未知/已知”，输出是文档。DNS 相当于一次 key-value 查询（域名 → IP），HTTP 相当于在可靠字节流信道上读取文件。分层协议栈就像模块化程序设计，每层只向上层提供服务。

**推演**：

1. 浏览器解析 URL：  
   $$
   \text{URL}=\text{scheme}://\text{host}:\text{port}/\text{path}
   $$  
   本题要获取万维网文档，$\text{scheme}$ 是 HTTP（或 HTTPS），但服务器 IP 未知，所以必须先解析域名 $\text{host}$。

2. 应用层发起 DNS 查询，将域名映射为 IP 地址。常规 DNS 查询报文封装在 UDP 中，使用端口 53。  
   因此这里需要的应用层协议是 DNS，传输层协议是 UDP。

3. 得到服务器 IP 后，HTTP 客户端与其建立 TCP 连接，发送 HTTP 请求，服务器返回 HTTP 响应，其中包含所请求的文档。  
   因此这里需要的应用层协议是 HTTP，传输层协议是 TCP。

4. FTP 用于文件传输，TELNET 用于远程登录，都与获取网页无关；IP 是网络层协议，不是传输层协议。  
   所以：  
   ① 选 DNS、HTTP；  
   ② 选 UDP、TCP。

**易错点**：

- 以为“已知 URL”就不需要 DNS：URL 中通常是域名而不是 IP，必须解析。
- 第二个空只选 TCP：忽略了 DNS 也要使用传输层服务，通常为 UDP。
- 误选 TCP、IP：IP 是网络层协议，题目问的是传输层协议。
- 误选 FTP/TELNET：这两个协议分别用于文件传输和远程登录，不能获取万维网文档。
- DNS 特殊情况下也可用 TCP，如区域传送或响应过大；但本题常规域名解析用 UDP，不影响“UDP、TCP”的结论。

**命题规律**：这是 408 中应用层与传输层结合的常考题型，常把 DNS、HTTP、TCP/UDP、端口号串起来考查。常见变式有：输入 URL 到显示页面的完整过程涉及哪些协议；若服务器 IP 已知，哪些步骤可以省略；DNS 为什么用 UDP；HTTPS 相对 HTTP 多出哪一层。复习时应按“DNS → TCP → HTTP”这条主线记忆协议族，并整理常见应用对应的传输层协议和端口号。

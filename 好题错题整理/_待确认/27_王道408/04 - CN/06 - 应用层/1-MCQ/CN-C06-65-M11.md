# 选择题 第 11 题

![[_Attachments/题目识别/27_王道408-题目/CN-C06-65-M11_题目.png|题目]]

11.若浏览器支持并行 TCP 连接，使用非持久的 HTTP/1.0 协议请求浏览 1 个 Web 页，该页中引用同一网站上的 7 个小图像文件，则从浏览器为传输 Web 页请求建立 TCP 连接开始，到接收完所有内容为止，所需的往返时间 $RTT$ 数至少是（  ）。

(A) 3
(B) 4
(C) 8
(D) 9

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C06-65-M11_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：B（4个RTT）。理由：获取HTML页面需要2个RTT，之后并行获取7个图像又需要2个RTT，总共至少4个RTT。

**解题切入点**：先识别考点——HTTP非持久连接、并行TCP连接、RTT计算，定位到应用层HTTP协议。可类比算法竞赛中的任务调度：必须完成前置任务（获取HTML）才能获得依赖任务（图像URL），然后可并行执行多个独立任务（图像获取），每个任务有固定开销（2个RTT）。目标是最大化并行度以最小化总时间。

**推演**：
- 假设往返时间 $RTT$ 固定，忽略数据传输时间（小图像文件）。
- 浏览器需获取 Web 页（HTML 文件），非持久 HTTP/1.0 要求每个对象使用单独的 TCP 连接。
  - 建立 TCP 连接：三次握手需 1 个 $RTT$（从发送 SYN 到收到 SYN+ACK）。
  - 发送 HTTP 请求并接收响应：再需 1 个 $RTT$（从发送请求到收到响应）。
  - 故获取 HTML 页面需 $2$ 个 $RTT$。在此期间，浏览器无法得知图像 URL，不能提前建立图像连接。
- 收到 HTML 响应后，浏览器解析出 7 个图像 URL，开始并行获取图像。由于支持并行 TCP 连接，可同时建立 7 个连接（假设并行数足够大）。
  - 建立所有 7 个 TCP 连接：同时发送 SYN，所有 SYN+ACK 在 $1$ 个 $RTT$ 后到达；然后同时发送 ACK（可携带 HTTP 请求），再需 $1$ 个 $RTT$ 所有响应到达。
  - 故获取全部图像也需 $2$ 个 $RTT$（从开始建立图像连接算起）。
- 总时间 = $2\ (\text{HTML}) + 2\ (\text{图像}) = 4$ 个 $RTT$。若并行连接数小于 7，则需更多 $RTT$，但题目问“至少”，故考虑最大并行度，结果为 $4$。

**易错点**：
1. 误以为 HTML 与图像可同时获取，忽略了解析 HTML 需要先得到响应，导致错选 A（3）。
2. 未考虑并行连接，认为每个对象需 2 个 $RTT$，总对象 8 个得 16（无选项），或只考虑请求响应而忽略连接建立得 8（C）。
3. 混淆非持久与持久连接，或错误认为并行连接可减少每个对象的 $RTT$ 开销。
4. 对“至少”理解偏差，按有限并行数（如 3）计算得到 8，未取理想情况。

**命题规律**：考点为 HTTP 非持久连接与并行连接下的 $RTT$ 计算，属于高频基础题。常见变式包括改变图像数量、指定并行连接数、引入持久连接或流水线等。复习建议：总结不同情况下的总时间公式，如非持久并行：$T = 2 + 2 \times \lceil n/m \rceil$（$m$ 为并行连接数，$n$ 为图像数）；持久连接非流水线：$T = 1 + n$（若连接已建立）；持久连接流水线：$T = 1 + 1$（所有对象一个 $RTT$）。通过对比强化记忆。

# 综合题 第 1 题

![[_Attachments/题目识别/27_王道408-题目/CN-C06-65-F01_题目.png|题目]]

1.在浏览器中输入 \texttt{http://cskaoyan.com} 并按回车,直到王道论坛的首页显示在其浏览器中,请问在此过程中,按照 TCP/IP 模型,从应用层到网络层都用到了哪些协议?

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C06-65-F01_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：应用层用到 **DNS、HTTP**；传输层用到 **UDP、TCP**；网络层（网际层）用到 **IP、ARP**。  
一句话理由：输入域名后需要 **DNS**（通常基于 UDP）解析 IP 地址，浏览器再用 **HTTP**（基于 TCP）获取网页，IP 负责端到端路由转发，ARP 负责解析下一跳 MAC 地址。

**解题切入点**：拿到题先抓关键流程“输入 URL → 页面显示”，这是一个典型的“浏览器访问网站”过程，可以按时间顺序拆成：域名解析 → 建立连接 → 发送请求 → 数据传输。这样就能定位到四层协议栈中的具体协议。  
这类似于在算法竞赛中构造一个完整的数据处理流水线：每个阶段有对应的“数据结构”和“操作”。例如 DNS 就是“查表”，HTTP 是“请求/响应格式”，TCP 是“可靠传输管道”，IP 是“路由寻址”，ARP 是“缓存并解析下一跳地址”。

**推演**：

1. 用户在浏览器输入 `http://cskaoyan.com`，浏览器首先要获得该域名对应的 IP 地址。  
   浏览器查本地缓存、系统 hosts 文件后，若没有，则向本地 DNS 服务器发起 DNS 查询。  
   - 应用层：**DNS**
   - 传输层：DNS 默认使用 **UDP**，端口 53
   - 网络层：DNS 报文封装为 IP 数据报发送

2. 获得 IP 地址后，浏览器向该 IP 发起 HTTP 请求。  
   因为 `http://` 默认使用 80 端口，且 HTTP 通常基于 TCP 提供可靠传输，所以：
   - 应用层：**HTTP**
   - 传输层：**TCP**，先进行三次握手建立连接
   - 网络层：TCP 报文段封装为 IP 数据报，由路由器按目的 IP 转发

3. 在 IP 数据报发送到链路上之前，主机必须知道下一跳的 MAC 地址。  
   如果 ARP 缓存中没有对应项，就广播 ARP 请求，目的主机或网关回复 ARP 应答，得到 MAC 地址后封装成以太网帧。  
   因此，网络层还需要 **ARP** 完成 IP 地址到 MAC 地址的解析。

4. 服务器收到 HTTP 请求后，返回 HTTP 响应，浏览器解析并渲染，最终显示王道论坛首页。  
   响应过程同样使用 **HTTP + TCP + IP + ARP**。

整体协议使用可表示为：

$$ \text{浏览器} \xrightarrow{\text{HTTP}} \text{TCP} \xrightarrow{\text{IP}} \text{ARP} \xrightarrow{\text{以太网帧}} \text{物理链路} $$

另外，域名解析阶段是：

$$ \text{浏览器} \xrightarrow{\text{DNS}} \text{UDP} \xrightarrow{\text{IP}} \text{ARP} \xrightarrow{\text{以太网帧}} \text{DNS服务器} $$

因此，从应用层到网络层用到的协议为：

- 应用层：**DNS、HTTP**
- 传输层：**UDP、TCP**
- 网络层：**IP、ARP**

**易错点**：

1. **只写 HTTP、TCP、IP**，漏掉 DNS 和 ARP。  
   解析域名和解析 MAC 地址是访问网页必不可少的前置过程，不能遗漏。

2. **误以为 DNS 只用 UDP**。  
   常规域名查询使用 UDP，但 DNS 也支持 TCP（如区域传送、响应超长等）。本题默认普通查询场景，答 UDP 即可；如果扩展讨论，可说明“通常 UDP，特殊场景 TCP”。

3. **混淆 ARP 的层次**。  
   在 OSI 模型中 ARP 常被归于数据链路层；在 TCP/IP 模型中，很多教材将其放在网络层/网际层讨论，408 也常在网络层中考察 ARP。答题时说明“ARP 用于解析 MAC 地址”即可，避免因层次划分争论丢分。

4. **把路由协议（OSPF、BGP）也写进去**。  
   用户主机不直接运行动态路由协议，路由器之间维护路由表时才用到，本题问的是浏览器访问过程中的协议，不应列出。

5. **忽略 DHCP**。  
   如果主机没有配置 IP 地址，确实需要 DHCP。但题目未特殊说明，默认主机已有 IP 配置，不需要额外写 DHCP。

**命题规律**：  
这是对 TCP/IP 协议栈基础的综合考查，属于高频考点。常见变式有：“输入域名后，各层分别做了什么？”、“DNS 和 HTTP 分别基于什么传输层协议？”、“ARP 在哪一层工作？”等。  
复习时建议把“打开网页”这一场景作为主线，把 DNS、HTTP、UDP、TCP、IP、ARP 的封装关系串起来，画出协议栈封装图，并理解端到端通信与逐跳转发的区别。这样不仅应对本题，也能应对相关综合题。

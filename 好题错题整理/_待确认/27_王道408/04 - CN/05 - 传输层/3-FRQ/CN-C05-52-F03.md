# 综合题 第 3 题

![[_Attachments/题目识别/27_王道408-题目/CN-C05-52-F03_题目.png|题目]]

3.一个应用程序用 $UDP$，到了 $IP$ 层将数据报再划分为 4 个数据报片发送出去。结果前两个数据报片丢失，后两个到达目的站。过了一段时间应用程序重传 $UDP$，而 $IP$ 层仍然划分为 4 个数据报片来传送。结果这次前两个到达目的站而后两个丢失。试问：在目的站能否将这两次传输的 4 个数据报片组装成为完整的数据报？假定目的站第一次收到的后两个数据片仍然保存在目的站的缓存中。

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C05-52-F03_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：不能。第一次到达的后两个分片属于标识为 $I_1$ 的 IP 数据报，第二次到达的前两个分片属于标识为 $I_2$ 的新 IP 数据报；IP 分片重组只允许组合“源 IP、目的 IP、协议、标识”都相同的分片，因此不能拼成一个完整数据报。

**解题切入点**：这题很像算法竞赛里的“按 key 分桶合并区间”。第一次到了 key 为 $I_1$ 的后半段，第二次到了 key 为 $I_2$ 的前半段；虽然区间数值上互补，但 key 不同，不能放进同一个桶。IP 分片重组的关键不是“偏移能否拼上”，而是“是否属于同一个 IP 数据报”，即看 IP 头中的标识字段。

**推演**：

IP 分片重组需要满足同一个分组键：

$$
K=(S_{\text{IP}},D_{\text{IP}},P,I)
$$

其中 $S_{\text{IP}}$ 是源 IP 地址，$D_{\text{IP}}$ 是目的 IP 地址，$P$ 是上层协议，$I$ 是 IP 数据报的标识字段。

设第一次发送的 IP 数据报为 $D_1$，标识为 $I_1$；第二次发送的 IP 数据报为 $D_2$，标识为 $I_2$。由于第二次是应用程序重传 UDP，IP 层会对这个 UDP 报文重新封装成一个新的 IP 数据报，因此正常情况下：

$$
I_1 \ne I_2
$$

把原 IP 数据报的 4 个分片按片偏移从小到大记为第 0、1、2、3 片，其中第 0 片偏移为 0。则目的站收到的情况是：

第一次到达：

$$
Q_{I_1}=\{(I_1,o_2),(I_1,o_3)\}
$$

即队列 $Q_{I_1}$ 中只有后两个分片，缺少第 0、1 片。

第二次到达：

$$
Q_{I_2}=\{(I_2,o_0),(I_2,o_1)\}
$$

即队列 $Q_{I_2}$ 中只有前两个分片，缺少第 2、3 片。

虽然从片偏移看，这两组数据报片恰好互补，但若强行合并：

$$
Q_{I_1}\cup Q_{I_2}
=
\{(I_2,o_0),(I_2,o_1),(I_1,o_2),(I_1,o_3)\}
$$

里面同时存在两个不同的标识 $I_1$ 和 $I_2$，不满足 IP 分片重组的条件。因此两个重组队列各自都不完整，目的站无法组装出完整的 IP 数据报，最终只能因重组超时将这些分片丢弃。

**易错点**：

1. 只看到“4 个分片偏移刚好互补”就认为能组装，忽略了 IP 标识字段必须相同。  
2. 把“应用程序重传 UDP”理解成“IP 层重传同一个数据报”。UDP 重传进入 IP 层后是新的 IP 数据报，标识会改变。  
3. 认为“第一次后两片还在缓存，第二次前两片到达就能补全”。实际上缓存按 $(S_{\text{IP}},D_{\text{IP}},P,I)$ 分桶，不同标识不会进入同一个重组队列。  
4. 分片重组还要求有片偏移为 0 的首片和有 MF=0 的末片；本例两个队列分别缺失首片或末片，更不可能重组。

**命题规律**：该题核心是 IPv4 分片与重组机制，尤其是标识字段的作用。常见变式有：给定 MTU 计算分片偏移、总长度和 MF 标志；判断多个分片能否重组；结合 DF 标志和路径 MTU 发现；以及 IPv4 与 IPv6 分片机制的对比。复习时建议把 IP 分片重组看成“按标识分桶的区间合并”，重点掌握标识、片偏移、MF 标志三者的关系。

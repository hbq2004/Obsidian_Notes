# 选择题 第 41 题

![[_Attachments/题目识别/27_王道408-题目/CN-C05-53-M41_题目.png|题目]]

41.【2009统考真题】主机甲与主机乙之间已建立一个 TCP 连接,主机甲向主机乙发送了两个连续的 TCP 段,分别包含 300B 和 500B 的有效载荷,第一个段的序列号为 200,主机乙正确接收到这两个数据段后,发送给主机甲的确认序列号是（ ）.

(A) 500
(B) 700
(C) 800
(D) 1000

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C05-53-M41_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：D。两个连续 TCP 段共携带 $300+500=800$B 有效载荷，第一个段序列号为 $200$，所以两个段全部正确接收后，TCP 累计确认号应为下一个期望字节序号：$200+300+500=1000$。

**解题切入点**：拿到题目先抓住三个关键量：首段序列号、每段有效载荷长度、是否“连续”。这等价于算法题中已知一段连续区间的起点和各块长度，求连续区间的“尾后指针”。TCP 的确认号就是接收方期望收到的下一个字节序号，相当于维护一个“已连续收到区间的 end 指针”，而不是单独确认每个段。

**推演**：

TCP 报文段中，序列号表示本段第一个数据字节的字节流编号。

设第一个 TCP 段的序列号为：

$$seq_1 = 200$$

第一个段有效载荷长度为 $300$B，因此它覆盖的字节范围是：

$$[200, 200+300)$$

即字节序号：

$$200, 201, \ldots, 499$$

收到第一个段后，接收方期望的下一个字节序号为：

$$200+300 = 500$$

由于两个 TCP 段是连续的，第二个 TCP 段的序列号为：

$$seq_2 = 500$$

第二个段有效载荷长度为 $500$B，因此它覆盖的字节范围是：

$$[500, 500+500)$$

即字节序号：

$$500, 501, \ldots, 999$$

主机乙正确接收到这两个数据段后，两个段共同覆盖的连续字节区间为：

$$[200, 1000)$$

TCP 使用累计确认，确认号是接收方期望收到的下一个字节序号。因此确认号为：

$$ACK = 200 + 300 + 500 = 1000$$

所以选 D。

**易错点**：

- 容易只按第一个段计算，得到 $ACK=500$，误选 A。但题目问的是“正确接收到这两个数据段后”的确认号。
- 容易把总有效载荷长度 $800$ 直接当作答案，误选 C，但确认号必须从第一个段的起始序列号 $200$ 开始累计，即 $200+800=1000$。
- 容易混淆“最后一个字节的序号”和“期望的下一个字节序号”。确认号是期望的下一个字节序号，不是最后收到的字节序号。
- 注意题目已经说明 TCP 连接已建立，不是 SYN 阶段，所以没有额外“$+1$”的序列号消耗；如果涉及 SYN/FIN 段，需额外注意它们各占一个序列号。

**命题规律**：本题是 408 计算机网络中 TCP 协议的经典考点，核心是“序列号 + 有效载荷长度 + 累计确认”。常见变式包括：给出确认号和一个段的载荷长度，求下一个段的序列号；结合超时重传、快速重传、乱序到达等问接收方回应的确认号。复习时要牢记：TCP 确认号表示“期望收到的下一个字节序号”，并注意区分数据段与 SYN/FIN 段的序列号消耗规则。

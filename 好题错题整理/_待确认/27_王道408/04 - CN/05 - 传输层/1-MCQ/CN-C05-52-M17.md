# 选择题 第 17 题

![[_Attachments/题目识别/27_王道408-题目/CN-C05-52-M17_题目.png|题目]]

17.【2025 统考真题】假设路由器实现 NAT 功能,内网中主机 H 的 IP 地址为 192.168.1.5/24。若 H 运行某应用向 Internet 发送了一个 UDP 报文段,则路由器在转发送封装该 UDP 报文段的 IP 数据报的过程中，UDP 报文段的首部字段会被修改的是( )

$I$.源端口号    $II$.目的端口号    $III$.总长度    $IV$.检验和

(A) 仅 $I$、$III$
(B) 仅 $I$、$IV$
(C) 仅 $II$、$III$
(D) 仅 $II$、$IV$

## DeepSeek V4 Flash Max 解析

**答案**：B（仅 I、IV）。NAT/NAPT 转发外出 UDP 报文时会改写源 IP 和 UDP 源端口，同时 UDP 检验和因涉及“伪首部”和源端口也必须重算；目的端口和长度字段不变。

**解题切入点**：看到“私有地址 192.168.1.5/24 + NAT 路由器 + UDP 外出”，应立刻定位到 NAT/NAPT 的地址与端口改写，以及 UDP 检验和跨层依赖。这类似算法题中的哈希映射：NAT 表就是  
$$
(192.168.1.5, P_s) \leftrightarrow (IP_{\text{公网}}, P_s')
$$
路由转发时改写映射键值；UDP 检验和相当于“完整性校验值”，一旦参与计算的 IP/端口变了，就必须重新计算，否则对端校验失败。协议分层思想类似“分治”，但 UDP 检验和通过伪首部跨到了 IP 层，所以 IP 层改动会反向影响传输层。

**推演**：设主机 H 发出 UDP 报文，其 UDP 首部为：

- 源端口：$P_s$
- 目的端口：$P_d$
- 长度：$L$，表示 UDP 首部 + 数据的总长度
- 检验和：$C$

路由器执行 NAT/NAPT 时：

1. 将 IP 首部中的源 IP 由 $192.168.1.5$ 改为公网 IP $IP_{\text{公网}}$；
2. 建立 NAT 映射：
$$
(192.168.1.5, P_s) \leftrightarrow (IP_{\text{公网}}, P_s')
$$
并把 UDP 源端口 $P_s$ 改写为 $P_s'$；
3. 目的 IP 和目的端口 $P_d$ 不变，因为这是 Internet 服务器上应用层服务的端口，NAT 不修改外出报文的目的端口；
4. UDP 长度 $L$ 不变。NAT 只是改写地址和端口，不增加或删除 UDP 数据；若“总长度”指 IP 数据报的总长度，同样不变；
5. UDP 检验和必须修改。UDP 检验和计算范围包括：
$$
\text{伪首部} + \text{UDP首部} + \text{数据}
$$
其中伪首部按顺序为：
$$
\text{源IP地址} \| \text{目的IP地址} \| 0 \| 17 \| \text{UDP长度}
$$
NAT 改写后，伪首部中的源 IP 和 UDP 首部中的源端口都发生了变化，因此旧检验和 $C$ 失效，必须重算为 $C'$。

因此 UDP 首部中被修改的字段是：I 源端口号、IV 检验和。故答案为 B。

**易错点**：

- 只记得 NAT 改 IP，忽略 NAT/NAPT 还会改写 UDP/TCP 源端口。本题选项包含源端口，应按 NAPT 理解。
- 误选“目的端口号”。外出访问 Internet 服务时，目的端口由应用层指定，NAT 不能修改。
- 混淆“总长度”和“长度字段”。UDP 首部中的长度字段是 UDP 报文总长度，NAT 不改变；IP 首部中的总长度也不因地址改写而改变。
- 忘记 UDP 检验和包含伪首部。伪首部含源 IP、目的 IP 等，所以即使 NAT 只改 IP 不改端口，检验和也必须重算；本题中源端口也改，更需重算。

**命题规律**：这是网络层 NAT/NAPT 与传输层 UDP 首部、检验和的跨层综合题。常见变式有：改为 TCP 报文段经过 NAT 时哪些字段改变；改为外网主机访问内网服务器时的反向 NAT 改写；给出 NAT 映射表判断地址和端口变化。复习时应把 UDP/TCP 首部字段、伪首部构成、NAT/NAPT 映射表放在一起对比记忆，特别注意“方向性”和“跨层检验和”。

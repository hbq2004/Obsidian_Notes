# 选择题 第 16 题

![[_Attachments/题目识别/27_王道408-题目/CN-C05-53-M16_题目.png|题目]]

16. 下列关于 $TCP$ 窗口与拥塞控制概念的描述中,错误的是（ ）

A. 接收端窗口 $(rwnd)$ 通过 $TCP$ 首部中的窗口字段通知数据的发送方

B. 发送窗口确定的依据是:发送窗口 $= \min[接收端窗口,拥塞窗口]$

C. 拥塞窗口是接收端根据网络拥塞情况确定的窗口值

D. 拥塞窗口大小在开始时可以按指数规律增长

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C05-53-M16_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：C。  
**一句话理由**：拥塞窗口（$cwnd$）是由发送方根据自己对网络拥塞状况的探测（超时、重复 ACK 等）动态调整的，不是由接收端确定；接收端只通过 TCP 首部窗口字段通告自己的接收窗口 $rwnd$。

---

**解题切入点**：  
这题考查 TCP 流量控制与拥塞控制的核心区别：`rwnd` 与 `cwnd` 分别是谁维护的？  
打个算法竞赛的比方：接收窗口 $rwnd$ 像“对端显式告诉你的内存剩余量”，拥塞窗口 $cwnd$ 像“你自己根据网络延迟/丢包情况维护的动态限流阈值”。最终发送量取二者最小值，类似“系统并发量 = min(下游队列容量, 本地限流阈值)”。  
拿到题目先看每个选项的主语：“接收端”“发送端”“网络拥塞情况”，立刻定位到 TCP 中“谁决定哪个窗口”的考点。

---

**推演**：

1. **选项 A 分析**  
   TCP 首部中有 16 位的“窗口字段”，由接收方填写，用来通告自己当前还能接收的字节数，即接收窗口 $rwnd$。  
   发送方收到 ACK 后，根据该字段限制自己未确认数据的数量，避免发送过快导致接收方缓冲区溢出。  
   因此 A 正确。

2. **选项 B 分析**  
   发送方真正能发送的数据量既要考虑接收方能力，又要考虑网络不会因拥塞而丢包太多。  
   所以：
   $$\text{发送窗口} \leq \min(rwnd, cwnd)$$
   其中：
   - $rwnd$：接收窗口，由接收端根据接收缓冲区剩余空间确定；
   - $cwnd$：拥塞窗口，由发送端根据网络拥塞情况确定。  
   因此 B 正确。

3. **选项 C 分析**  
   拥塞窗口 $cwnd$ 是发送端维护的变量。发送端通过以下现象感知网络拥塞：
   - 超时未收到 ACK；
   - 收到重复 ACK；
   - 收到显式拥塞通知（ECN）等。  
   接收端并不会探测网络拥塞，它只负责通告自己的接收缓冲能力 $rwnd$。  
   因此“拥塞窗口是接收端根据网络拥塞情况确定的窗口值”说法错误。C 错误。

4. **选项 D 分析**  
   TCP 慢启动阶段，$cwnd$ 初始值通常为一个 MSS，每经过一个 RTT，$cwnd$ 翻倍：
   $$cwnd \leftarrow 2 \times cwnd$$
   经过 $n$ 个 RTT 后：
   $$cwnd = MSS \times 2^n$$
   这是指数增长。直到 $cwnd$ 达到慢启动阈值 $ssthresh$ 后，才转入拥塞避免阶段，改为线性增长。  
   因此 D 正确。

综上，错误选项是 C。

---

**易错点**：

1. **混淆两个窗口的职责**  
   容易把 $rwnd$ 和 $cwnd$ 都当成“网络状态窗口”。  
   规避方法：记住一句话：  
   - $rwnd$：接收方管，管流量控制；  
   - $cwnd$：发送方管，管拥塞控制。

2. **误以为接收端知道网络拥塞**  
   实际上接收端只看自己的缓冲区，无法准确感知网络中间的拥塞情况；网络拥塞由发送方通过 ACK 丢失、超时等信号判断。

3. **把慢启动阶段的“指数增长”误认为错误**  
   慢启动虽然叫“慢启动”，但窗口增长是指数增长；真正线性增长的是拥塞避免阶段。  
   规避方法：记住公式：
   $$cwnd_{\text{慢启动}} = 2^n \times MSS$$
   $$cwnd_{\text{拥塞避免}} = cwnd + MSS$$

4. **忽略发送窗口限制条件**  
   实际发送窗口不是简单地等于 $rwnd$ 或 $cwnd$，而是：
   $$\text{发送窗口} = \min(rwnd, cwnd)$$
   还要保证已发送但未确认的数据量不超过该值。

---

**命题规律**：  
这是 408 计算机网络中传输层的高频概念题，常考 TCP 流量控制与拥塞控制的区别。变式包括：  
- 给定 $rwnd$、$cwnd$、$ssthresh$，计算发送窗口；  
- 判断慢启动、拥塞避免、快重传、快恢复阶段 $cwnd$ 的变化；  
- 出现超时或三个重复 ACK 后 $cwnd$ 和 $ssthresh$ 如何调整。

复习建议：把 TCP 拥塞控制的“慢启动、拥塞避免、快重传、快恢复”流程图整理清楚，重点记忆：
$$ssthresh = \frac{cwnd}{2} \quad (\text{出现拥塞时})$$
并把 $rwnd$ 和 $cwnd$ 的维护者、作用、变化规律分别列表对比。

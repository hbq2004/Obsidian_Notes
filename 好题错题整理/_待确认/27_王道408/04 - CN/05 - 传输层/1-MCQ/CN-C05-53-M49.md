# 选择题 第 49 题

![[_Attachments/题目识别/27_王道408-题目/CN-C05-53-M49_题目.png|题目]]

49.【2017统考真题】若甲向乙发起一个 TCP 连接，最大段长 $MSS=1KB, RTT=5ms$，乙开辟的接收缓存为 $64KB$，则甲从连接建立成功至发送窗口达到 $32KB$，需经过的时间至少 ( )

A. $25ms$

B. $30ms$

C. $160ms$

D. $165ms$

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C05-53-M49_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：A. $25ms$。理由：慢启动过程中，拥塞窗口初始为 $1$ MSS，每经过一个 RTT 翻倍，经过 $5$ 个 RTT 达到 $32$ MSS（即 $32$ KB），时间 $=5 \times 5 \mathrm{ms}=25\mathrm{ms}$。

**解题切入点**：  
抓住“连接建立成功”的时间起点，明确慢启动的指数增长规律。类比算法竞赛中的“倍增”思想（如快速幂），每轮操作将规模翻倍，只需 $O(\log n)$ 轮即可达到目标。本题中，需要将拥塞窗口从 $1$ KB 增长到 $32$ KB，相当于 $2^n \ge 32$，解得 $n=5$，每轮耗时一个 RTT。

**推演**：  
1. 初始条件：连接建立成功时，甲（发送方）的拥塞窗口 $cwnd = 1\ \mathrm{MSS}=1\ \mathrm{KB}$，接收方乙的通告窗口 $rwnd = 64\ \mathrm{KB}$，故发送窗口 $W = \min(cwnd, rwnd) = 1\ \mathrm{KB}$。  
2. 慢启动过程：每收到一个 ACK，$cwnd$ 增加 $1$ MSS，实际效果为每经过一个 RTT，$cwnd$ 翻倍（因为发送的数据量恰好被 ACK 确认）。  
   - 第 $1$ 个 RTT 结束：$cwnd=2$ KB；  
   - 第 $2$ 个 RTT 结束：$cwnd=4$ KB；  
   - 第 $3$ 个 RTT 结束：$cwnd=8$ KB；  
   - 第 $4$ 个 RTT 结束：$cwnd=16$ KB；  
   - 第 $5$ 个 RTT 结束：$cwnd=32$ KB。  
3. 此时 $W = \min(32, 64)=32$ KB，达到目标。所需时间 $=5 \times \mathrm{RTT} = 5 \times 5\mathrm{ms} = 25\mathrm{ms}$。

**易错点**：  
- 误将“连接建立成功”理解为从发起 SYN 开始，则会多算连接建立时间（$1$ RTT），得到 $30\mathrm{ms}$，错选 B。  
- 忽略指数增长，认为线性增长（每 RTT 增加 $1$ MSS），则需 $32$ RTT $=160\mathrm{ms}$，错选 C。  
- 将 $32$ KB 直接乘以 RTT 得到 $160\mathrm{ms}$，或 $32+1$ 个 RTT 得到 $165\mathrm{ms}$，均属概念错误。

**命题规律**：  
- 考点：TCP 慢启动中拥塞窗口的指数增长规律，以及发送窗口与接收窗口、拥塞窗口的关系。  
- 常见变式：给出初始拥塞窗口、慢启动阈值或接收窗口变化，要求计算达到某窗口大小的时间；或结合拥塞避免阶段（线性增长）进行分段计算。  
- 复习建议：熟练掌握慢启动的“每 RTT 翻倍”准则，区分“连接建立成功”与“开始发起连接”的时间起点，并注意题目中“至少”意味着理想情况（无丢包、无延迟确认）。

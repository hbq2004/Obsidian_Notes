# 选择题 第 5 题

![[_Attachments/题目识别/27_王道408-题目/CN-C05-52-M05_题目.png|题目]]

5. UDP 数据报比 IP 数据报多提供了（  ）服务.

(A) 流量控制  
(B) 拥塞控制  
(C) 端口功能  
(D) 路由转发

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C05-52-M05_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：C。UDP 在 IP 基础上主要多提供了“端口功能”，用于标识不同应用进程，而流量控制、拥塞控制、路由转发均不是 UDP 新增的服务。

**解题切入点**：拿到题目先锁定比较对象：UDP 与 IP 分别位于传输层与网络层。可以类比为：IP 负责“包裹在广域网中按地址投递到主机”，而 UDP 负责“包裹到达主机后，按端口号分发给主机上的具体应用程序”。如果把网络层比作“城市间的物流分拣”，传输层的 UDP 就是“小区物业按门牌号把快递送到具体住户”。题目问“UDP 比 IP 多提供了什么”，本质是问传输层相较于网络层新增了哪类功能，端口功能是最直接的差异。

**推演**：

- IP（网络层）提供的是主机到主机的分组交付服务，核心功能包括：寻址、路由选择、分片与重组、尽力而为交付等。IP 数据报头部中的字段只有源/目的 IP 地址，没有端口号。

- UDP（传输层）在 IP 之上运行，其数据报头部格式为：
  $$
  \underbrace{\text{源端口号}}_{\text{16 bit}} \quad
  \underbrace{\text{目的端口号}}_{\text{16 bit}} \quad
  \underbrace{\text{长度}}_{\text{16 bit}} \quad
  \underbrace{\text{校验和}}_{\text{16 bit}}
  $$
  端口号用于标识发送方和接收方的应用进程，使得数据能够从主机交付到特定进程，而 IP 只能将数据交付到主机。因此，UDP 比 IP 多提供了“端口功能”。

- 流量控制：UDP 没有滑动窗口，也不进行确认重传，因此不提供流量控制。TCP 才提供流量控制。
- 拥塞控制：UDP 没有拥塞窗口或拥塞避免机制，因此不提供拥塞控制。TCP 提供拥塞控制。
- 路由转发：路由转发是网络层（IP）的核心功能，UDP 并不提供路由转发，而是依赖 IP 层完成。

综上，UDP 数据报比 IP 数据报多提供的服务是端口功能。

**易错点**：

1. **误选 A 或 B**：看到 UDP 是传输层协议，就想当然认为传输层一定提供流量控制和拥塞控制。实际上 UDP 是无连接、不可靠的，既无流量控制也无拥塞控制。TCP 才有这两项功能。
2. **误选 D“路由转发”**：路由转发是 IP 层的基本职责，UDP 是 IP 的上层协议，它不参与路由选择，也不会替 IP 提供该服务。UDP 只是把数据交给 IP 层去发送。
3. **混淆“传输层功能”与“UDP 特有功能”**：传输层的通用功能是提供端到端的通信和复用/分用，而 UDP 只实现了其中的端口复用/分用，并未实现可靠传输、流量控制等复杂功能。

**命题规律**：本题属于网络层次功能对比的基础题，常考 TCP/UDP/IP 三者的功能差异。常见变式有：
- “TCP 比 UDP 多提供哪些服务？”答案通常是可靠传输、流量控制、拥塞控制；
- “UDP 不提供的服务有哪些？”答案通常为可靠传输、流量控制、拥塞控制、连接管理；
- “传输层和网络层的区别”则强调端口、进程粒度、端到端等。

复习建议：建立一张表格对比 IP、UDP、TCP 的头部字段和支持的服务，重点关注端口号、序号、确认号、窗口字段等与功能的对应关系。该知识点记忆性强，但容易混淆，务必从“层次职责”出发理解：网络层管主机间路由，传输层管应用进程间通信；UDP 是“尽力而为的进程间数据报交付”，TCP 是“可靠的字节流连接”。

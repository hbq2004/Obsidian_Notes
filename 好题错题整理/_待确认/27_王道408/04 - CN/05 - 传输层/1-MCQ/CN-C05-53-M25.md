# 选择题 第 25 题

![[_Attachments/题目识别/27_王道408-题目/CN-C05-53-M25_题目.png|题目]]

25.某应用程序每秒产生一个 $60B$ 的数据块,每个数据块被封装在一个 $TCP$ 报文中,然后封装在一个 $IP$ 数据报中,则最后每个数据报所包含的应用数据所占的百分比是( )(注意:$TCP$ 报文和 $IP$ 数据报的首部没有附加字段).

(A) $20\%$

(B) $40\%$

(C) $60\%$

(D) $80\%$

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C05-53-M25_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：C。每个 $60B$ 应用数据封装为 TCP 报文段后再封装为 IP 数据报，总长度为 $60+20+20=100B$，应用数据占比 $60/100=60\%$。

**解题切入点**：题目表面在问“占比”，实际考的是 TCP/IP 分层封装时每层首部的开销。先抓住两个固定首部长度：TCP 首部无附加字段时为 $20B$，IPv4 首部无附加字段时也为 $20B$。这类似算法竞赛中“嵌套结构体”或“给数据加固定元信息”：总开销等于每层元数据之和，真正有效负载是应用数据部分。分层协议可以看作“分治封装”，每层只关心自己的头部，最后算效率就是 $\text{payload}/(\text{总长度})$。

**推演**：

设应用数据长度为 $L_a=60B$。

TCP 首部固定为 $20B$，所以 TCP 报文段总长度为：
$$
L_{\text{TCP}}=L_a+20=60+20=80B
$$

IP 数据报再封装 TCP 报文段，IP 首部固定为 $20B$，所以 IP 数据报总长度为：
$$
L_{\text{IP}}=L_{\text{TCP}}+20=80+20=100B
$$

因此应用数据所占百分比为：
$$
\eta=\frac{L_a}{L_{\text{IP}}}\times 100\%=\frac{60}{100}\times 100\%=60\%
$$

所以选 C。

题目中说“每秒产生一个数据块”是干扰信息，因为求的是每个数据报内的占比，不是单位时间吞吐量。每个数据块独立封装，计算一个数据报即可。

**易错点**：

- 容易只算 TCP 封装，忘了再加 IP 首部，得到 $\frac{60}{80}=75\%$，但选项中没有，说明漏层了。
- 容易误用 UDP 首部 $8B$，但题目明确是 TCP，不能用 UDP。
- 容易追加 Ethernet 帧首部，但题目问的是“IP 数据报”，不应考虑链路层封装。
- 容易把“每秒产生一个数据块”理解为速率相关计算，实际上这里只需求单个数据报的比例，时间信息无用。

**命题规律**：本题考查 TCP/IP 参考模型的封装过程与首部开销计算，属于计网中“封装与效率”类基础题。常见变式包括：把 TCP 换成 UDP，计算 UDP 数据报中的有效载荷占比；或者给出 MTU，要求计算 IP 分片后的总长度与各分片负载；也可以把多个应用数据块合并到一个 TCP 报文中，考察减少首部开销的比例变化。复习时应牢记 TCP 首部最小长度 $20B$、IPv4 首部最小长度 $20B$、UDP 首部 $8B$，并理解应用数据、TCP 报文段、IP 数据报、帧之间的层层封装关系。

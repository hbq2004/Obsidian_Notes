# 选择题 第 3 题

![[_Attachments/题目识别/27_王道408-题目/CN-C05-52-M03_题目.png|题目]]

3. UDP数据报首部不含 ( )

(A) UDP源端口号

(B) UDP检验和

(C) UDP目的端口号

(D) UDP数据报长度

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C05-52-M03_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：无正确选项（题目选项设置错误）。UDP 首部固定为 $8$ 字节，包含源端口号、目的端口号、长度、检验和四个字段，因此 A、B、C、D 都在首部中；若题干改为“包含”，则四项全选。

**解题切入点**：看到“UDP 数据报首部不含”，立即定位到“传输层协议首部字段”的记忆型考点，本质是考查你对 UDP 首部“结构体成员”是否熟悉。可以类比算法竞赛中“给定一个结构体，问哪个成员不在结构体里”——必须先背熟结构体定义再逐项对照，而不是凭印象猜。UDP 首部就是固定 8 字节的“定长结构体”，四个成员分别是：源端口、目的端口、长度、检验和。拿着这个定义去扫选项，会发现四个选项全在结构体里，因此题目本身有误。

**推演**：  
UDP 数据报首部格式如下：

| 字段 | 位数 | 作用 |
|---|---|---|
| 源端口号 | $16$ 位 | 标识发送方应用进程端口 |
| 目的端口号 | $16$ 位 | 标识接收方应用进程端口 |
| 长度 | $16$ 位 | UDP 用户数据报总长度（首部 $8$ 字节 + 数据部分），最小值为 $8$ |
| 检验和 | $16$ 位 | 校验 UDP 首部和数据部分，IPv4 下可选但字段仍存在，不用时置 $0$ |

逐项分析：

- 选项 A“UDP 源端口号”：UDP 首部第 $0\sim15$ 位，存在。
- 选项 B“UDP 检验和”：UDP 首部第 $48\sim63$ 位，存在。
- 选项 C“UDP 目的端口号”：UDP 首部第 $16\sim31$ 位，存在。
- 选项 D“UDP 数据报长度”：UDP 首部第 $32\sim47$ 位，称为“长度”字段，其值就是 UDP 数据报长度（首部 + 数据），存在。

因此，四个选项均为 UDP 首部字段，本题没有符合“不含”的选项。

**易错点**：

1. **误以为 UDP 首部只有端口号**：很多同学只记“UDP 无连接、不可靠”，就误以为首部简单，忘记长度和检验和字段。  
2. **把“检验和可选”理解为“没有检验和字段”**：IPv4 下 UDP 检验和可以不用（置 $0$），但字段本身一定存在。  
3. **混淆 UDP 长度字段与 IP 总长度**：UDP 长度字段表示 UDP 数据报长度（UDP 首部 + UDP 数据），而 IP 总长度是 IP 首部 + IP 数据部分（其中 IP 数据部分就是整个 UDP 数据报）。  
4. **遇到四个选项都正确时硬选一个**：这暴露了题目或选项有问题，应当指出，而不是强行猜一个。平时刷题碰到这种情况要警惕题干是否印错，例如原题可能想问“TCP 首部不含”，或某个选项应为“序号”。

**命题规律**：  
408 中传输层协议首部字段是高频基础题，通常考法有：  
- 直接问“UDP 首部包含哪些字段”；  
- 对比“TCP 首部与 UDP 首部的区别”，如 TCP 有序号、确认号、窗口等，UDP 没有；  
- 计算 UDP 长度：UDP 长度 $=$ UDP 首部 $8$ 字节 $+$ 数据部分长度；  
- 考查校验和覆盖范围：UDP 校验和覆盖伪首部、UDP 首部和数据。  

复习建议：将 UDP、TCP、IP 首部字段各列一张表对比记忆，重点关注每个字段的位数和作用；尤其要记住 UDP 首部只有 $4$ 个字段，而 TCP 首部远比 UDP 复杂。遇到此类题目，先默写协议首部结构，再逐项对照选项，可避免混淆。本题若出现在正式考卷上，建议按“无正确选项/题目有误”处理，或者将 D 选项改为“数据部分”才符合“不含”的设问。

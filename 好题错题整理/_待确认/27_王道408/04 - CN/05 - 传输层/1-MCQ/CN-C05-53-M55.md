# 选择题 第 55 题

![[_Attachments/题目识别/27_王道408-题目/CN-C05-53-M55_题目.png|题目]]

55.【2021统考真题】若大小为 $12B$ 的应用层数据分别通过 1 个 UDP 数据报和 1 个 TCP 段传输,则该 UDP 数据报和 TCP 段实现的有效载荷(应用层数据)最大传输效率分别是 ( ).

(A) $37.5\%, 16.7\%$
(B) $37.5\%, 37.5\%$
(C) $60.0\%, 16.7\%$
(D) $60.0\%, 37.5\%$

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C05-53-M55_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：D。UDP 数据报有效载荷传输效率为 60%，TCP 段为 37.5%。

**解题切入点**：本题考查传输层协议头部开销对传输效率的影响。首先明确有效载荷即应用层数据大小固定为 $12\ \text{B}$，传输效率 $= \frac{\text{有效载荷}}{\text{有效载荷}+\text{头部开销}}$。对于 UDP，头部固定 $8\ \text{B}$，最小头部开销得最大效率；对于 TCP，头部最小 $20\ \text{B}$，选项法则考虑最小头部，故效率分别为 $\frac{12}{20}=60\%$ 和 $\frac{12}{32}=37.5\%$。类比算法竞赛：计算复杂度时，我们通常只考虑核心操作，忽略常数，但这里头部开销是必须计入的“额外空间”，相当于维护数据结构的额外指针占用的空间。

**推演**：UDP 数据报格式：首部 $8\ \text{B}$（源端口 $2\ \text{B}$、目的端口 $2\ \text{B}$、长度 $2\ \text{B}$、校验和 $2\ \text{B}$），数据部分为应用层数据 $12\ \text{B}$，总长度 $20\ \text{B}$，有效载荷传输效率 $= \frac{12}{20}=0.6=60\%$。TCP 段格式：首部固定部分 $20\ \text{B}$（源端口、目的端口、序号、确认号、数据偏移、保留、标志位、窗口、校验和、紧急指针），数据部分 $12\ \text{B}$，总长度 $32\ \text{B}$，有效载荷传输效率 $= \frac{12}{32}=0.375=37.5\%$。注意本题未考虑 IP 首部 $20\ \text{B}$，否则效率分别为 $30\%$ 和 $23.1\%$，不在选项中。因此最大传输效率为 UDP $60\%$，TCP $37.5\%$。

**易错点**：1. 误将 IP 首部计入，导致选项无匹配。2. 误以为 TCP 首部包含选项部分，但题目要求最大传输效率，应取最小首部即 $20\ \text{B}$。3. 计算错误：$\frac{12}{20}=60\%$，$\frac{12}{32}=37.5\%$，注意分数化简可得。

**命题规律**：本题为简单计算题，考查 UDP 和 TCP 首部长度。常作为选择题或填空题，变式包括变更数据大小或考虑 IP 首部，或改为计算开销比例。复习时需牢记：UDP 首部 $8\ \text{B}$，TCP 首部最小 $20\ \text{B}$（通常考试取最小，若涉及选项扩展则需注意最大效率取最小头部）。同时注意“最大传输效率”即头部最小的情况。

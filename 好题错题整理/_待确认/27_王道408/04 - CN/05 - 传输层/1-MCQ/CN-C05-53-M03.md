# 选择题 第 3 题

![[_Attachments/题目识别/27_王道408-题目/CN-C05-53-M03_题目.png|题目]]

3. 下列关于 TCP 的端口的叙述中,错误的是( )

(A) 客户端使用的端口号是动态规定的

(B) 端口号长度为16位

(C) 端口号用于在通信中识别进程

(D) 局域网内的计算机不能使用相同端口号

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C05-53-M03_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：D。局域网内的计算机完全可以同时使用相同的端口号，因为端口号仅在单个主机的传输层用于区分本机进程，不要求全局唯一。

**解题切入点**：拿到题目先定位考点：TCP/UDP 端口号的基本概念与作用。可以把“端口号”类比为操作系统中的进程 ID（PID），但它是网络通信中用于标识本机进程的“局部编号”，而不是像 IP 地址那样的“全局地址”。在算法竞赛中，这就像哈希表中的“桶编号”：在每个哈希表内部编号唯一即可，不同哈希表之间编号可以重复，不会冲突。所以看到“(D) 局域网内的计算机不能使用相同端口号”，立刻应意识到它混淆了“端口号局部唯一”和“IP 地址全局唯一”的概念。

**推演**：

- (A) 正确。客户端在发起连接时，通常由操作系统动态分配一个临时的端口号（即“临时端口”），范围一般为 1024～65535，因此“客户端使用的端口号是动态规定的”说法正确。  
  服务器端则常用熟知端口号（0～1023），如 HTTP 使用 80，HTTPS 使用 443。

- (B) 正确。TCP 报文段首部中，源端口和目的端口字段各占 16 位，因此端口号长度为 16 位，取值范围为 $0 \sim 2^{16}-1$，即 $0 \sim 65535$。

- (C) 正确。传输层通过端口号来标识本机上的应用进程。IP 地址标识主机，而端口号标识主机中的进程，二者结合（IP 地址 + 端口号）才能唯一确定一个网络通信端点。

- (D) 错误。端口号只要求在同一台主机内部唯一，用于区分本机不同的进程。不同主机之间可以使用相同的端口号，例如局域网中两台计算机都可以使用 80 端口运行 Web 服务，互不影响。  
  真正不能相同的是 IP 地址（在同一局域网内必须唯一），而不是端口号。

因此，错误的选项是 (D)。

**易错点**：

1. **混淆“IP 地址唯一”与“端口号唯一”**：IP 地址在局域网内全局唯一，端口号只在主机内局部唯一。  
   **规避**：记住口诀“IP 找主机，端口找进程”。

2. **误以为客户端端口号固定**：客户端端口号一般由操作系统临时分配，但某些应用也可使用固定端口（如 FTP 主动模式的源端口 20），题目说“动态规定”是从通常机制角度讲的，不算错误。  
   **规避**：重点理解临时端口与熟知端口的区别。

3. **忽略端口号长度**：TCP 报文中端口字段是 16 位，但有些同学会记成 8 位或 32 位。  
   **规避**：结合 TCP 首部格式记忆：源端口 16 位 + 目的端口 16 位，共 4 字节。

4. **不了解“端口号用于识别进程”**：有同学误以为端口号识别服务或主机。  
   **规避**：明确端口号是传输层服务访问点（TSAP），是进程在传输层的地址。

**命题规律**：

- **考点定位**：TCP/IP 协议栈中传输层的端口号概念，属于 TCP 报文首部与 Socket 编址的基础知识。常见于选择题，偶尔结合 TCP 连接、Socket 编程出题。

- **常见变式**：
  1. 给出端口号范围，判断哪些是熟知端口、注册端口、动态/私有端口。
  2. 问“IP 地址 + 端口号”唯一标识什么（答：某一台主机上的某个进程，即一个 Socket）。
  3. 问 TCP/UDP 复用和分用依靠什么字段（答：端口号）。
  4. 结合 NAT 或并发服务器，问多个连接是否可以共用一个本地端口（答：在 TCP 中，四元组（源 IP、源端口、目的 IP、目的端口）唯一标识一个连接，因此同一主机的同一端口可以与不同远端建立多个连接，但数据结构上通常用四元组区分）。

- **复习建议**：把端口号与 IP 地址、进程、Socket 的关系放在一起对比记忆，理解“端口号是主机内部概念”这一核心点；熟记 TCP 首部格式中端口号字段的 16 位长度；平时做题时遇到“不能相同”“必须唯一”这类绝对化表述，要优先怀疑其是否正确，因为网络协议中大量标识符都是“局部唯一”。

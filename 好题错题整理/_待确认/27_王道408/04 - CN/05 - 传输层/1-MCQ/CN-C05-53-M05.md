# 选择题 第 5 题

![[_Attachments/题目识别/27_王道408-题目/CN-C05-53-M05_题目.png|题目]]

5. 下列几种描述中,( )不是 TCP 的特性.

A. 比 UDP 开销大
B. 强制重传错误分组
C. 在 TCP 首部中有目标主机 IP 地址
D. 把消息分成段并在目标主机中进行重组

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C05-53-M05_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：C。TCP 是传输层协议，其首部中没有目标主机 IP 地址；目标主机 IP 地址属于网络层 IP 首部。

**解题切入点**：拿到题先做“分层定位”：TCP 属于传输层，只负责进程到进程、可靠字节流传输；IP 属于网络层，负责主机到主机的寻址。这就像算法竞赛中的“模块化”：线段树负责区间维护，不负责输入输出；输入输出由外层 IO 负责。不能把 IP 层的寻址责任塞给 TCP 层。

**推演**：

1. 先看 TCP/IP 的封装关系：

```text
应用层数据
   ↓
[ TCP 首部 | 数据 ]        ← 传输层段，TCP 首部含源端口、目的端口等
   ↓
[ IP 首部 | TCP 段 ]       ← 网络层数据报，IP 首部含源 IP、目的 IP
```

2. 逐项判断：

- A：TCP 比 UDP 开销大。  
  TCP 需要连接建立、状态维护、确认重传、流量控制、拥塞控制等，且 TCP 首部最小为 20 字节，UDP 首部只有 8 字节，所以 TCP 开销确实比 UDP 大。A 是 TCP 特性。

- B：强制重传错误分组。  
  TCP 提供可靠传输，对于丢失、出错、未确认的段，发送方会通过超时重传或快速重传机制重新发送相同序号的数据。B 在考试语境中可视为 TCP 特性。

- C：在 TCP 首部中有目标主机 IP 地址。  
  TCP 首部包含的是源端口、目的端口、序号、确认号、数据偏移、窗口、检验和、紧急指针等字段，不包含目标主机 IP 地址。目标 IP 地址在网络层 IP 首部中。C 错误。

- D：把消息分成段并在目标主机中进行重组。  
  TCP 是面向字节流的协议，会把应用层数据按 MSS 划分成 TCP 段，接收方按序号进行排序和重组。D 是 TCP 特性。

因此，正确答案是 C。

**易错点**：

- 不要把 TCP 报文段和 IP 数据报混为一谈：TCP 首部用端口标识应用进程，IP 首部用 IP 地址标识主机。
- TCP 计算校验和时会用到包含源 IP、目的 IP 的“伪首部”，但伪首部并不真正出现在 TCP 首部中。
- “重传错误分组”不要理解为把损坏后的原始分组原样重传；校验失败的分组会被丢弃，TCP 重传的是相同序号的数据段。
- D 中的“消息分成段”严格说应是“字节流分段”，TCP 不保留应用层报文边界，但考研语境下按“分段/重组”理解即可。

**命题规律**：该题考查传输层与网络层的分层职责，以及 TCP 首部字段。常见变式有：“下列哪个不是 TCP 首部字段？”、“TCP 与 UDP 的区别”、“IP 数据报首部包含什么”等。复习时最好画出 TCP/IP 封装图，熟记 TCP 首部和 IP 首部字段，并对比 TCP/UDP 在连接性、可靠性、字节流/报文、首部大小、开销上的差异。

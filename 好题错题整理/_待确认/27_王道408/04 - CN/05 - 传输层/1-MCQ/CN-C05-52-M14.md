# 选择题 第 14 题

![[_Attachments/题目识别/27_王道408-题目/CN-C05-52-M14_题目.png|题目]]

14.【2014统考真题】下列关于 UDP 的叙述中，正确的是（ ）

I.提供无连接服务  II.提供复用/分用服务  III.通过差错检验,保障可靠数据传输

(A) 仅 I  
(B) 仅 I、II  
(C) 仅 II、III  
(D) I、II、III

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C05-52-M14_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：B。UDP 提供无连接服务，并通过端口提供复用/分用；它有差错检验，但不保障可靠数据传输，因此 III 错误。

**解题切入点**：先定位考点——传输层两种典型协议的区别。UDP 的关键词是“无连接、不可靠、报文段、复用/分用、差错检验”。就像算法竞赛中构造一个“哈希表”只能用于快速查找，但无法保证数据一定不冲突、不丢失；UDP 的校验和只是“检测错误并丢弃”，而不是“可靠传输协议”的完整机制。因此看到“差错检验”要立刻反问：它能“保障可靠数据传输”吗？不能。直接锁定 I、II 正确，III 错误。

**推演**：

- 语句 I：“提供无连接服务”。UDP 在通信前不需要建立连接，也不维护连接状态，每个报文段独立发送。这一点为真。
- 语句 II：“提供复用/分用服务”。UDP 使用端口号来区分不同的应用进程：发送时多个应用进程的数据通过不同源端口号“复用”到同一 IP 层，接收时根据目的端口号“分用”给对应进程。这一点为真。
- 语句 III：“通过差错检验，保障可靠数据传输”。UDP 确实有校验和（Checksum）字段，用来检测报文段在传输过程中是否出现比特差错：
  - 发送方计算校验和并填入报文段；
  - 接收方重新计算，若发现错误则直接丢弃该报文段。
  
  但“可靠数据传输”要求的是：无差错、不丢失、不重复、按序到达，并需要确认、重传、序号、定时器等机制。UDP 既没有确认机制，也没有超时重传机制，收到出错报文后直接丢弃，不会要求发送方重发。因此，差错检验只能“发现并丢弃出错报文”，无法“保障可靠数据传输”。语句 III 为假。

综上：正确的是 I 和 II，选 B。

**易错点**：

1. **把“差错检验”误认为“可靠传输”**：UDP 虽然有校验和，但只负责检错，出错就丢，不重传、不确认。可靠传输是 TCP 的核心职责。规避方法：记住“检错≠可靠”，可靠必须要有确认与重传机制。
2. **误以为 UDP 没有差错检验**：UDP 报文段有校验和字段（IPv4 中可选，但通常使用；IPv6 中为必需），因此不能认为 UDP 不提供差错检测。
3. **误以为无连接就没有复用/分用**：无连接只表示不建立连接，但端口机制仍然存在，传输层的复用/分用是所有传输层协议的基本功能，与是否面向连接无关。
4. **对“可靠传输”定义不清**：可靠传输包含比特差错检测、丢包处理、乱序重排、重复剔除、流量控制等，UDP 只满足其中极小的部分，不能称为保障可靠。

**命题规律**：本题是 2014 年统考真题，属于传输层基础概念题，常以“下列叙述正确的是”形式出现。核心考点是 UDP 与 TCP 的对比，以及传输层协议的基本功能（复用/分用、差错检测、可靠传输）。常见变式包括：

- 直接问“UDP 有哪些功能”，选项混入“流量控制”“拥塞控制”等；
- 结合 TCP 对比，问“哪些是 TCP 有而 UDP 没有的”；
- 考查 UDP 校验和的计算或覆盖范围（伪首部、首部、数据部分）。

复习建议：归纳传输层协议功能对照表，重点区分“差错检测”与“可靠传输”两个概念；理解端口号的作用，并熟记 TCP/UDP 的报文段格式。这类送分题务必不要丢分。

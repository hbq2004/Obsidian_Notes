# 综合题 第 3 题

![[_Attachments/题目识别/27_王道408-题目/CN-C05-Q03_题目.png|题目]]

03. 一个TCP连接要发送3200B的数据. 第一个字节的编号为10010. 若前两个报文段各携带1000B的数据，最后一个报文段携带剩下的数据，写出每个报文段的序号.

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C05-Q03_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：三个报文段的 TCP 序号分别为 $10010$、$11010$、$12010$，其中最后一个报文段携带 $1200$ B 数据。

**解题切入点**：拿到题先定位考点：“TCP 报文段序号 = 本报文段所携带数据的第一个字节编号”。TCP 不是按报文段编号，而是按字节流编号。可以类比“从起点 $10010$ 开始的连续数组”，每段占用的长度就是该段携带的数据字节数；下一段起点等于上一段起点加上上一段长度。不要一上来背公式，先画一条字节流编号轴，分段标出即可。

**推演**：

设第 $i$ 个报文段的序号为 $s_i$，携带数据长度为 $l_i$。

第一个报文段：
$$s_1=10010,\quad l_1=1000$$

它携带的数据字节编号范围是：
$$[10010,\ 10010+1000-1]=[10010,\ 11009]$$

因此第二个报文段的序号为第一段之后的下一个字节编号：
$$s_2=10010+1000=11010$$

第二个报文段携带 $1000$ B，其数据字节编号范围是：
$$[11010,\ 11010+1000-1]=[11010,\ 12009]$$

总数据量为 $3200$ B，前两个报文段共携带：
$$1000+1000=2000\ \text{B}$$

所以第三个报文段携带的字节数为：
$$l_3=3200-2000=1200$$

第三个报文段的序号为：
$$s_3=11010+1000=10010+2000=12010$$

其数据字节编号范围是：
$$[12010,\ 12010+1200-1]=[12010,\ 13209]$$

验证：总数据 $3200$ B 的最后一个字节编号应为：
$$10010+3200-1=13209$$

与第三段区间终点一致，说明计算正确。

因此三个报文段的序号分别为：
$$\boxed{10010,\quad 11010,\quad 12010}$$

**易错点**：

1. 把“序号”误当成报文段计数序号，写成 $1,2,3$。TCP 序号是字节流编号，不是报文段个数编号。  
2. 计算下一段序号时，误写为 $10010+1000-1=11009$。注意 $11009$ 是第一段的最后一个字节编号，不是第二段的首字节编号；第二段首字节应是 $11010$。  
3. 忘记计算第三段长度。题意说“最后一个报文段携带剩下的数据”，前两段共 $2000$ B，所以第三段应为 $3200-2000=1200$ B，不是 $1000$ B。  
4. 将本题与三次握手中的 SYN 序号混淆。本题是连接建立后的数据传输，序号只按数据字节累加；若涉及 SYN，则 SYN 会额外消耗一个序号，但本题不需要加 $1$。

**命题规律**：

- 考点定位：TCP 报文段格式中的“序号”字段，以及 TCP 字节流编号规则，属于传输层高频基础计算题。  
- 常见变式：已知序号与数据长度，求确认号；已知确认号，求下一个期望接收的字节序号；结合累计确认、超时重传、滑动窗口计算；结合三次握手中的 SYN/ACK 序号变化出题。  
- 复习建议：熟记并区分两个核心公式：
  $$\text{序号}=\text{本报文段数据首字节编号}$$
  $$\text{确认号}=\text{期望收到对方下一个数据字节的编号}$$
  做题时先画“字节流编号轴”，把每个报文段的数据区间标出来，再按题目要求取值，不要凭感觉加减。

> 03.【解答】
> TCP 报文段的序号是指其数据部分的第一个字节的序号。因此第一个报文段的序号是 10010，序号范围 10010～11009；第二个报文段的序号是 $10010 + 1000 = 11010$，序号范围 11010～12009；第三个报文段的序号为 $11010 + 1000 = 12010$，序号范围 12010～13209。

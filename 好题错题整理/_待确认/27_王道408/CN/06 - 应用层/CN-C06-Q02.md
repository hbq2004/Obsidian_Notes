# 综合题 第 2 题

![[_Attachments/题目识别/27_王道408-题目/CN-C06-Q02_题目.png|题目]]

02. 在如下条件下，计算使用非持续方式和持续方式请求一个 Web 页面所需的时间.
1）测试的 RTT 的平均值为 150ms，一个 gif 对象的平均发送时延为 35ms.
2）一个 Web 页面中有 10 幅 gif 图片，Web 页面的基本 HTML 文件、HTTP 请求报文、TCP 握手报文大小忽略不计.
3）TCP 三次握手的第三步中捎带一个 HTTP 请求.
4）使用非流水线方式.

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C06-Q02_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：按串行、非流水线的默认情况计算，非持续方式请求该 Web 页面约需 $3650\mathrm{ms}$（$3.65\mathrm{s}$）；持续方式（非流水线）约需 $2150\mathrm{ms}$（$2.15\mathrm{s}$）。

**解题切入点**：  
拿到题目先明确两个时间量：RTT 是往返时延，$35\mathrm{ms}$ 是 gif 对象的发送时延，二者不能混用。再把“Web 页面”拆成对象：基本 HTML 文件 + 10 幅 gif，共 11 个对象。非持续连接每次取对象都要重新建立 TCP 连接；持续连接只在取 HTML 时建连一次。而“非流水线”表示后续 10 个 gif 必须一个一个地请求，不能一次性全部发出。

**推演**：  
记  
$$
R=150\mathrm{ms},\qquad D=35\mathrm{ms}
$$
基本 HTML 文件大小忽略不计，所以其发送时延为 $0$；每幅 gif 的发送时延为 $D$。

对于任意一个对象：

- 若使用新的 TCP 连接获取，由于 TCP 三次握手的第三步捎带了 HTTP 请求，则：
  - 第 1 个 RTT 完成 TCP 三次握手；
  - 第 2 个 RTT 完成 HTTP 请求/响应；
  - 若对象有发送时延 $d$，还要再加上 $d$。

  所以新连接获取一个对象的时间为：
  $$
  2R + d
  $$

- 若使用已建立的持续连接获取后续对象，不需要重新握手，只需一次 HTTP 请求/响应，则时间为：
  $$
  R + d
  $$

因此：

### 非持续方式

基本 HTML 文件需要 $2R$，10 幅 gif 每幅都需要新开 TCP 连接，每幅需要 $2R + D$。

$$
T_{\text{非持续}}
=2R+10(2R+D)
=2\times150+10(2\times150+35)
=3650\mathrm{ms}
$$

### 持续方式（非流水线）

基本 HTML 文件仍需要 $2R$；此后 10 幅 gif 在同一 TCP 连接上顺序请求，每幅需要 $R+D$。

$$
T_{\text{持续}}
=2R+10(R+D)
=2\times150+10(150+35)
=2150\mathrm{ms}
$$

对比可见，非持续方式比持续方式多出的时间正好是 10 个 gif 各自的 TCP 连接建立时间：

$$
10R=1500\mathrm{ms}
$$

**易错点**：  
1. 漏算基本 HTML 文件。即使 HTML 文件大小忽略不计，也仍需先通过 TCP 连接请求并接收该文件，不能只算 10 幅 gif。  
2. 把非持续连接的每个对象算成 $R+D$，忘记每取一个新对象都要重新建立 TCP 连接，应该是 $2R+D$。  
3. 在持续连接中，仍然把每个 gif 都算成 $2R+D$，多算了 10 次 TCP 握手。持续连接只在第一次请求 HTML 时需要建连。  
4. 忽略“非流水线”条件。若非流水线，后续对象必须等前一个对象完全收到后才能继续请求，不能直接把 10 个请求同时发出。  
5. 不要自行假设浏览器并行打开多个 TCP 连接；题目没有说明并行连接时，应按串行计算。

**命题规律**：  
本题是 408 中 HTTP 应用层与 TCP 传输层结合的典型计算题。核心公式可总结为：  

- 非持续连接：每个对象 $2RTT + D$；  
- 持续连接非流水线：第一个对象 $2RTT + D_0$，后续每个对象 $RTT + D$；  
- 持续连接流水线：第一个对象 $2RTT + D_0$，后续所有对象近似在 $1RTT + \sum D_i$ 内完成。  

复习时应注意：题目若给出对象大小和链路带宽，要先算出发送时延；若只给 RTT 和发送时延，则直接代入。变式常考“改为流水线”“使用并行连接”“对象来自不同服务器”等，需要根据题意重新画时间线，不能机械套公式。

> 02. 【解答】
> 每次进行 TCP 三次握手时，前两次握手消耗 1RTT$=150\text{ms}$，第 3 次握手的报文段捎带客户对 HTML 文件的请求，因此请求和接收基本 HTML 文件耗时 1RTT$=150\text{ms}$（其大小忽略不计时，发送时延为 $0\text{ms}$）。
> 在非持续连接方式下：
> 第一次建立 TCP 连接并传送 html 文件所需的时间为 $t_{\text{html}} = 150 + 150 = 300\text{ms}$；
> 每次建立 TCP 连接并传送一个 gif 文件所需的时间为 $t_{\text{gif}} = 150 + 150 + 35 = 335\text{ms}$；
> 所以总时间 $t_{\text{总}} = t_{\text{html}} + t_{\text{gif}} \times 10 = 300 + 335 \times 10 = 3650\text{ms}$。
> 在持续连接方式下：
> 只需要建立一次 TCP 连接，然后传送 html 文件和 $10$ 个 gif 文件。
> 总时间 $t_{\text{总}} = t_{\text{建立TCP}} + t_{\text{html}} + t_{\text{gif}} \times 10 = 150 + 150 + (150 + 35) \times 10 = 2150\text{ms}$。

# 综合题 第 7 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-Q07_题目.png|题目]]

07. 【2009 统考真题】某计算机的 CPU 主频为 $500\text{MHz}$，CPI 为 $5$（执行每条指令平均需 $5$ 个时钟周期）。假定某外设的数据传输速率为 $0.5\text{MB/s}$，采用中断方式与主机进行数据传送，以 $32$ 位为传输单位，对应的中断服务程序包含 $18$ 条指令，中断服务的其他开销相当于 $2$ 条指令的执行时间。回答下列问题，要求给出计算过程。
1) 在中断方式下，CPU 用于该外设 I/O 的时间占整个 CPU 时间的百分比是多少?
2) 当该外设的数据传输速率达到 $5\text{MB/s}$ 时，改用 DMA 方式传送数据。假定每次 DMA 传送块大小为 $5000\text{B}$，且 DMA 预处理和后处理的总开销为 $500$ 个时钟周期，则 CPU 用于该外设 I/O 的时间占整个 CPU 时间的百分比是多少（假设 DMA 与 CPU 之间没有访存冲突）?

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-Q07_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：中断方式下，CPU 用于该外设 I/O 的时间占整个 CPU 时间的 $2.5\%$；改用 DMA 方式后，该比例为 $0.1\%$。

**解题切入点**：拿到题先抓住“I/O 时间占比 = 每秒 I/O 操作次数 × 每次操作耗费的 CPU 周期数 ÷ CPU 每秒总周期数”。中断方式按“传输单位”算每秒中断次数；DMA 方式按“块大小”算每秒 DMA 次数。所有指令条数、其他开销都先折算成时钟周期，再与 CPU 主频比较。

**推演**：

CPU 主频为

$$
f=500\text{ MHz}=5\times10^8\text{ 周期/s}
$$

按本题 I/O 数据率的常用口径，$1\text{ MB/s}=10^6\text{ B/s}$。

### 1) 中断方式

每次中断传送 $32$ 位，即

$$
32\text{ bit}=4\text{ B}
$$

外设数据传输速率为 $0.5\text{ MB/s}=0.5\times10^6\text{ B/s}$，所以每秒中断次数为

$$
N_1=\frac{0.5\times10^6}{4}=1.25\times10^5\text{ 次/s}
$$

每次中断服务程序包含 $18$ 条指令，其他开销相当于 $2$ 条指令的执行时间，所以总共相当于 $20$ 条指令。已知 CPI 为 $5$，故每次中断的 CPU 开销为

$$
C_1=20\times5=100\text{ 个时钟周期}
$$

因此每秒用于该外设 I/O 的周期数为

$$
N_1C_1=1.25\times10^5\times100=1.25\times10^7
$$

占整个 CPU 时间的百分比为

$$
\eta_1=\frac{1.25\times10^7}{5\times10^8}\times100\%=2.5\%
$$

### 2) DMA 方式

外设数据传输速率达到 $5\text{ MB/s}=5\times10^6\text{ B/s}$，每次 DMA 传送 $5000\text{ B}$，所以每秒 DMA 次数为

$$
N_2=\frac{5\times10^6}{5000}=1000\text{ 次/s}
$$

每次 DMA 预处理和后处理总开销为 $500$ 个时钟周期；题设说明 DMA 与 CPU 之间没有访存冲突，所以 DMA 数据传送过程不额外占用 CPU 时间，只计算预处理和后处理开销。

每秒 CPU 用于该外设 I/O 的周期数为

$$
1000\times500=5\times10^5
$$

占整个 CPU 时间的百分比为

$$
\eta_2=\frac{5\times10^5}{5\times10^8}\times100\%=0.1\%
$$

**易错点**：

- “32 位”是 $4\text{ B}$，不是 $32\text{ B}$。如果把传输单位写成 $32\text{ B}$，每秒中断次数会少 8 倍。
- “其他开销相当于 2 条指令的执行时间”不能直接当成 2 个时钟周期，应乘以 CPI，即相当于 $2\times5=10$ 个时钟周期；稳妥做法是把所有开销统一折算成“指令条数”再乘 CPI。
- DMA 方式下不要把 5000 B 数据传送过程当作 CPU 指令执行时间。DMA 传送由 DMA 控制器完成，且题设说明无访存冲突，所以 CPU 时间只算预处理和后处理。
- 求百分比时分子分母要统一，都用“每秒时钟周期数”。不能拿 I/O 周期数和 CPU 指令条数相比。
- 注意数据率单位中 MB 的处理。本题 $5\text{ MB/s}$ 与 $5000\text{ B}$ 配合，按 $10^6\text{ B/s}$ 计算。

**命题规律**：本题定位是 I/O 方式中“中断方式与 DMA 方式的 CPU 时间开销比”计算，是中断和 DMA 对比的核心考点。常见变式有：已知 CPU 时间占比上限，反求外设最大传输速率；把 DMA 改成周期挪用或突发传送，并给出总线占用时间，求 CPU 因访存冲突额外等待的时间；或在中途中加入中断响应时间。复习时应熟练掌握：

$$
\text{每秒请求次数}\times\text{单次开销周期数}\div\text{CPU 主频}=\text{CPU 时间占比}
$$

并注意中断是按传输单位逐次传送，DMA 是按数据块成批传送。

> 07. 【解答】
> 1）按题意，外设每秒传送$0.5\text{MB}$，中断时每次传送$32\text{bit}=4\text{B}$。由于CPI为$5$，在中断方式下，CPU每次用于数据传送的时钟周期为$5\times18+5\times2=100$（中断服务程序+其他开销）。为达到外设$0.5\text{MB/s}$的数据传输速率，外设每秒申请的中断次数为$0.5\text{MB}/4\text{B}=125000$。$1$秒内用于中断的开销为$100\times125000=12500000=12.5\text{M}$个时钟周期。CPU用于外设I/O的时间占整个CPU时间的百分比为$12.5\text{M}/500\text{M}=2.5\%$。
> 2）当外设数据传输速率提高到$5\text{MB/s}$时改用DMA方式传送，每次DMA传送一个数据块，大小为$5000\text{B}$，则$1$秒内需产生的DMA次数为$5\text{MB}/5000\text{B}=1000$。CPU用于DMA处理的总开销为$1000\times500=500000=0.5\text{M}$个时钟周期。CPU用于外设I/O的时间占整个CPU时间的百分比为$0.5\text{M}/500\text{M}=0.1\%$。

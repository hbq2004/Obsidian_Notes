# 综合题 第 7 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-Q07_题目.png|题目]]

07. 【2009 统考真题】某计算机的 CPU 主频为 $500\text{MHz}$，CPI 为 $5$（执行每条指令平均需 $5$ 个时钟周期）。假定某外设的数据传输速率为 $0.5\text{MB/s}$，采用中断方式与主机进行数据传送，以 $32$ 位为传输单位，对应的中断服务程序包含 $18$ 条指令，中断服务的其他开销相当于 $2$ 条指令的执行时间。回答下列问题，要求给出计算过程。
1) 在中断方式下，CPU 用于该外设 I/O 的时间占整个 CPU 时间的百分比是多少?
2) 当该外设的数据传输速率达到 $5\text{MB/s}$ 时，改用 DMA 方式传送数据。假定每次 DMA 传送块大小为 $5000\text{B}$，且 DMA 预处理和后处理的总开销为 $500$ 个时钟周期，则 CPU 用于该外设 I/O 的时间占整个 CPU 时间的百分比是多少（假设 DMA 与 CPU 之间没有访存冲突）?

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-Q07_答案.png|答案]]


> **原书解答（OCR）**
>
> 07. 【解答】
> 1）按题意，外设每秒传送$0.5\text{MB}$，中断时每次传送$32\text{bit}=4\text{B}$。由于CPI为$5$，在中断方式下，CPU每次用于数据传送的时钟周期为$5\times18+5\times2=100$（中断服务程序+其他开销）。为达到外设$0.5\text{MB/s}$的数据传输速率，外设每秒申请的中断次数为$0.5\text{MB}/4\text{B}=125000$。$1$秒内用于中断的开销为$100\times125000=12500000=12.5\text{M}$个时钟周期。CPU用于外设I/O的时间占整个CPU时间的百分比为$12.5\text{M}/500\text{M}=2.5\%$。
> 2）当外设数据传输速率提高到$5\text{MB/s}$时改用DMA方式传送，每次DMA传送一个数据块，大小为$5000\text{B}$，则$1$秒内需产生的DMA次数为$5\text{MB}/5000\text{B}=1000$。CPU用于DMA处理的总开销为$1000\times500=500000=0.5\text{M}$个时钟周期。CPU用于外设I/O的时间占整个CPU时间的百分比为$0.5\text{M}/500\text{M}=0.1\%$。

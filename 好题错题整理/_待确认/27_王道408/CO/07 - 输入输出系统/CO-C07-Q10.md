# 综合题 第 10 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-Q10_题目.png|题目]]

10. 【2018统考真题】假定计算机的主频为500MHz，CPI为4。现有设备A和B，其数据传输速率分别为2MB/s和40MB/s，对应I/O接口中各有一个32位数据缓冲寄存器。回答下列问题，要求给出计算过程.

1）若设备A采用定时查询I/O方式，每次输入/输出都至少执行10条指令。设备A最多间隔多长时间查询一次才能不丢失数据？CPU用于设备A输入/输出的时间占CPU总时间的百分比至少是多少？

2）在中断I/O方式下，若每次中断响应和中断处理的总时钟周期数至少为400，则设备B能否采用中断I/O方式？为什么？

3）若设备B采用DMA方式，每次DMA传送的数据块大小为1000B，CPU用于DMA预处理和后处理的总时钟周期数为500，则CPU用于设备B输入/输出的时间占CPU总时间的百分比最多是多少？

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-Q10_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：  
1) 设备 A 最多 $2\mu\text{s}$ 查询一次，CPU 用于设备 A 输入/输出的时间占 CPU 总时间的百分比至少为 $4\%$；  
2) 设备 B 不能采用中断 I/O 方式，因为中断处理时间（$800\text{ns}$）远大于数据缓冲寄存器满的时间间隔（$100\text{ns}$），会导致数据丢失；  
3) 设备 B 采用 DMA 方式时，CPU 用于设备 B 输入/输出的时间占 CPU 总时间的百分比最多为 $4\%$。

**解题切入点**：  
首先抓住题目给出的基本参数（主频、CPI、数据速率、缓冲寄存器大小），根据 I/O 方式的不同，计算数据缓冲寄存器满的时间间隔，并与 I/O 操作所需时间进行比较。定时查询方式下，CPU 的查询周期必须小于等于缓冲寄存器满间隔，否则数据丢失；中断方式下，中断处理时间必须小于等于缓冲寄存器满间隔；DMA 方式下，CPU 仅参与预处理和后处理，其时间占比由数据块大小和速率决定。这类问题类似于“流水线节拍”或“传输带宽匹配”，核心是**时间约束**。

**推演**：  
1. **基本参数**  
   主频 $f = 500\text{MHz}$，时钟周期 $T_{\text{clk}} = 1/f = 2\text{ns}$。  
   CPI $=4$，每条指令平均执行时间 $= 4 \times T_{\text{clk}} = 8\text{ns}$。

2. **设备 A（定时查询 I/O）**  
   数据传输速率 $R_A = 2\text{MB/s} = 2\times10^6\text{B/s}$，缓冲寄存器 $32\text{bit} = 4\text{B}$。  
   缓冲寄存器满的时间间隔（即两次查询的最大间隔）：  
   $$T_{A,\text{max}} = \frac{4\text{B}}{2\times10^6\text{B/s}} = 2\times10^{-6}\text{s} = 2\mu\text{s}.$$  
   每次查询至少执行 $10$ 条指令，总时钟周期数为 $10 \times 4 = 40$，耗时：  
   $$T_{\text{query}} = 40 \times T_{\text{clk}} = 40 \times 2\text{ns} = 80\text{ns}.$$  
   CPU 用于设备 A 输入/输出的时间占 CPU 总时间的百分比至少为：  
   $$\eta_A = \frac{T_{\text{query}}}{T_{A,\text{max}}} \times 100\% = \frac{80\text{ns}}{2\mu\text{s}} = 0.04 = 4\%.$$

3. **设备 B（中断 I/O）**  
   数据传输速率 $R_B = 40\text{MB/s} = 40\times10^6\text{B/s}$，缓冲寄存器 $4\text{B}$。  
   缓冲寄存器满的时间间隔：  
   $$T_{B,\text{full}} = \frac{4\text{B}}{40\times10^6\text{B/s}} = 0.1\times10^{-6}\text{s} = 100\text{ns}.$$  
   每次中断响应和中断处理的总时钟周期数至少为 $400$，耗时：  
   $$T_{\text{int}} = 400 \times T_{\text{clk}} = 400 \times 2\text{ns} = 800\text{ns}.$$  
   由于 $T_{\text{int}} > T_{B,\text{full}}$（$800\text{ns} > 100\text{ns}$），在中断处理期间，数据缓冲寄存器已多次满，新数据会覆盖旧数据，导致数据丢失，故设备 B 不能采用中断 I/O 方式。

4. **设备 B（DMA 方式）**  
   每次 DMA 传送的数据块大小为 $D = 1000\text{B}$，CPU 用于预处理和后处理的总时钟周期数为 $500$，耗时：  
   $$T_{\text{CPU}} = 500 \times T_{\text{clk}} = 500 \times 2\text{ns} = 1000\text{ns} = 1\mu\text{s}.$$  
   设备 B 的数据传输速率 $R_B = 40\text{MB/s}$，所以每传送一个数据块所需的时间间隔（即数据产生时间）：  
   $$T_{\text{block}} = \frac{D}{R_B} = \frac{1000\text{B}}{40\times10^6\text{B/s}} = 25\times10^{-6}\text{s} = 25\mu\text{s}.$$  
   在 DMA 方式下，CPU 只在每个数据块传送开始前进行预处理、结束后进行后处理，不参与传送过程，因此 CPU 用于设备 B 的时间占比为：  
   $$\eta_B = \frac{T_{\text{CPU}}}{T_{\text{block}}} \times 100\% = \frac{1\mu\text{s}}{25\mu\text{s}} = 0.04 = 4\%.$$  
   由于设备 B 连续工作，该比例是固定的，即 CPU 用于设备 B 输入/输出的时间占 CPU 总时间的百分比最多为 $4\%$（若考虑 DMA 传送时间，总周期更长，比例更小，但题目给定条件已确定此值）。

**易错点**：  
- 单位换算错误：如将 $2\text{MB/s}$ 误算为 $2\times2^{20}\text{B/s}$，或忘记将主频换算为时钟周期（$1/500\text{MHz}=2\text{ns}$）。  
- 忽略 CPI：直接认为每条指令执行时间为 $1$ 个时钟周期，导致查询时间计算错误。  
- 混淆缓冲寄存器满间隔与查询周期：在定时查询中，查询周期必须小于等于缓冲寄存器满间隔，但有些同学误以为查询周期必须等于缓冲寄存器满间隔的整数倍。  
- 中断方式下，未比较中断处理时间与数据产生间隔，而直接认为中断方式可以处理任何设备。  
- DMA 方式下，误将 DMA 传送时间当成 CPU 时间，或认为 CPU 占用率包含传送时间，导致比例计算错误（如 $1\mu\text{s}/(25\mu\text{s}+1\mu\text{s})$ 的错误做法）。  
- 忽略“至少”与“最多”的含义：第一问的“至少”是指 CPU 占用百分比的最小可能值（当查询间隔最大时）；第二问的“最多”是指 DMA 方式下 CPU 占用比例的最大可能值（给定块大小，比例固定）。

**命题规律**：  
- **考点定位**：计算机组成原理中的 I/O 方式（程序查询、中断、DMA）性能分析，常结合主频、CPI、数据速率、缓冲寄存器大小等参数计算时间约束和 CPU 占用率。  
- **常见变式**：  
  - 改变数据速率或缓冲寄存器大小，要求计算查询间隔或判断中断是否可行。  
  - 改变块大小，计算 DMA 方式下 CPU 占用率，或比较不同块大小对 CPU 开销的影响。  
  - 加入多个设备，计算总 CPU 占用率，或考虑中断优先级。  
  - 结合磁盘、网络等外部设备，或考虑总线宽度、传输模式（如周期挪用、突发传送）。  
- **复习建议**：  
  - 熟练掌握主频、时钟周期、CPI、指令执行时间之间的换算关系。  
  - 理解各种 I/O 方式的工作流程，明确 CPU 的参与程度（程序查询：全程 CPU 参与；中断：CPU 在响应和处理时参与；DMA：CPU 仅在预处理和后处理时参与）。  
  - 重点掌握“数据缓冲寄存器满间隔”的计算，并将其与 I/O 操作时间比较，判断是否丢失数据。  
  - 注意单位统一（如 $1\text{MB}=10^6\text{B}$，$1\text{ms}=10^{-3}\text{s}$，$1\mu\text{s}=10^{-6}\text{s}$，$1\text{ns}=10^{-9}\text{s}$）。  
  - 通过典型例题（如本题）反复练习，强化计算速度和准确性。

> 10. 【解答】
> 1）程序定时向缓存端口查询数据，由于缓存端口大小有限，必须在传输完端口大小的数据时访问端口，以防止部分数据未被及时读取而丢失。设备 A 准备 32 位数据所用的时间为 $4\text{B}/2\text{MB} = 2\mu\text{s}$，所以最多每隔 $2\mu\text{s}$ 必须查询一次，每秒的查询次数至少是 $1\text{s}/2\mu\text{s} = 5\times10^5$，每秒 CPU 用于设备 A 输入/输出的时间至少为 $5\times10^5\times10\times4 = 2\times10^7$ 个时钟周期，占整个 CPU 时间的百分比至少是 $2\times10^7\div 500\text{M} = 4\%$。
> 2）中断响应和中断处理的时间为 $400\times(1/500\text{M}) = 0.8\mu\text{s}$，这时只需判断设备 B 准备 32 位数据要多久，若准备数据的时间小于中断响应和中断处理的时间，则数据被刷新，造成丢失。经过计算，设备 B 准备 32 位数据所用的时间为 $4\text{B}/40\text{MB} = 0.1\mu\text{s}$，因此设备 B 不适合采用中断 I/O 方式。
> 3）在 DMA 方式中，只有预处理和后处理需要 CPU 处理。设备 B 每秒的 DMA 次数最多为 $40\text{MB/s}÷1000\text{B} = 40000$，CPU 用于设备 B 输入/输出的时间最多为 $40000\times500 = 2\times10^7$ 个时钟周期，占 CPU 总时间的百分比最多为 $(2\times10^7)/500\text{M} = 4\%$。

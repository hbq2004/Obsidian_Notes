# 综合题 第 9 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-Q09_题目.png|题目]]

09. 【2016 统考真题】假定 CPU 主频为 $50\text{MHz}$，$CPI$ 为 4。设备 D 采用异步串行通信方式向主机传送 7 位 ASCII 码字符，通信规程中有 1 位奇校验位和 1 位停止位，从 D 接收启动命令到字符送入 I/O 端口需要 $0.5\text{ms}$。回答下列问题，要求说明理由。
1) 每传送一个字符，在异步串行通信线上共需传输多少位？在设备 D 持续工作过程中，每秒最多可向 I/O 端口送入多少个字符？
2) 设备 D 采用中断方式进行输入/输出，示意图如下所示：
【图：设备D采用中断方式与CPU交互的示意图：包含外设D的“工作”与“完成”状态，CPU的“启动”、“请求”、“响应”、“返回”等操作，展示了完整的中断驱动I/O流程】
I/O 端口每收到一个字符申请一次中断，中断响应需 10 个时钟周期，中断服务程序共有 20 条指令，其中第 15 条指令启动 D 工作。若 CPU 需从 D 读取 1000 个字符，则完成这一任务所需时间大约是多少个时钟周期？CPU 用于完成这一任务的时间大约是多少个时钟周期？在中断响应阶段 CPU 进行了哪些操作？

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-Q09_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：  
每传送一个字符，异步串行通信线上共需传输 $10$ 位（$1$ 位起始位 + $7$ 位数据位 + $1$ 位奇校验位 + $1$ 位停止位）；D 每秒最多可向 I/O 端口送入 $2000$ 个字符。中断方式读取 $1000$ 个字符时，完成该任务所需总时间约为 $2.5\times10^7$ 个时钟周期，CPU 用于该任务的时间约为 $9\times10^4$ 个时钟周期。中断响应阶段 CPU 完成关中断、保存断点、转入中断服务程序等操作。

**解题切入点**：  
先区分“串行线上的位格式”和“主机接收字符的速率”；再在中断 I/O 中把“设备工作时间”和“CPU 中断处理时间”分开。题中“中断服务程序第 15 条指令启动 D 工作”是关键：它说明 CPU 处理中断的时段可以与 D 准备下一字符的时段重叠。类似多线程中把 I/O 等待与计算重叠，总耗时主要由慢的一方决定。

**推演**：  
1）异步串行帧中必须有起始位，虽然题干只给出了奇校验位和停止位，但不能漏掉起始位。因此线上每位组成为：

$$1\text{ 起始位}+7\text{ 数据位}+1\text{ 奇校验位}+1\text{ 停止位}=10\text{ 位}$$

设备 D 由接收启动命令到字符送入 I/O 端口需 $0.5\text{ms}$，所以每秒最多送入字符数为：

$$\frac{1}{0.5\times10^{-3}}=2000\text{ 字符/s}$$

2）CPU 主频为 $50\text{MHz}$，所以 $0.5\text{ms}$ 对应的时钟周期数为：

$$0.5\times10^{-3}\times50\times10^6=25000\text{ 个时钟周期}$$

每次中断的 CPU 开销为中断响应时间加上中断服务程序执行时间：

$$10+20\times4=90\text{ 个时钟周期}$$

读取 $1000$ 个字符时，CPU 用于完成该任务的总时间为：

$$1000\times90=9\times10^4\text{ 个时钟周期}=1.8\text{ms}$$

由于中断服务程序第 $15$ 条指令就启动 D 工作，D 准备下一个字符的 $25000$ 个时钟周期可与 CPU 执行中断服务程序剩余部分及后续操作重叠；并且 $90$ 个时钟周期远小于 $25000$ 个时钟周期，所以整个 $1000$ 个字符任务的总耗时主要由 D 的工作时间决定：

$$T_{\text{总}}\approx1000\times25000=2.5\times10^7\text{ 个时钟周期}=0.5\text{s}$$

中断响应阶段 CPU 自动完成的操作包括：

- 发出中断响应信号，确认接受中断请求；
- 关中断，防止响应过程中被新的中断打断；
- 保存断点，即将当前 PC（以及必要时的 PSW）压栈或保存；
- 根据中断源形成中断服务程序入口地址并送入 PC，转入中断服务程序。

**易错点**：  
- 漏算起始位，误把每字符位数写成 $7+1+1=9$ 位。异步串行通信中起始位不可省略。  
- 误把总耗时算成 $1000\times(25000+90)$。因为第 $15$ 条指令已经启动 D，设备准备时间与 CPU 后续处理可重叠，题目问“大约”，应以设备工作时间为总耗时主项。  
- 混淆“中断响应阶段”与“中断服务程序”。中断响应是硬件隐指令完成，而 20 条指令的执行属于中断服务阶段。  
- 忘记用 CPI 换算指令执行时间，或把中断响应的 10 个时钟周期也乘 CPI，导致 CPU 开销算错。

**命题规律**：  
本题属于“I/O 方式”中的中断驱动 I/O，408 常结合 CPU 主频、CPI 考查时间开销计算。常见变式有：改为 DMA 方式比较 CPU 占用率；给出波特率求有效数据传输率；增加中断嵌套或中断屏蔽字判断响应顺序。复习时应熟练掌握异步串行帧格式、时钟周期换算，并会通过“启动下一设备的指令位置”判断设备与 CPU 是否并行工作。

> 09. 【解答】
> 1）每传送一个 ASCII 码字符，需要传输的位数有 1 位起始位、7 位数据位（ASCII 码字符占 7 位）、1 位奇校验位和 1 位停止位，因此总位数为 $1 + 7 + 1 + 1 = 10$。
> I/O 端口每秒最多可接收 $1000/0.5 = 2000$ 个字符。
> 2）一个字符传送时间包括：设备 D 将字符送 I/O 端口的时间、中断响应时间和中断服务程序前 15 条指令的执行时间。时钟周期为 $1 \div 50\text{MHz} = 20\text{ns}$，设备 D 将字符送 I/O 端口的时间为 $0.5\text{ms}/20\text{ns} = 2.5 \times 10^4$ 个时钟周期。一个字符的传送时间约为 $2.5 \times 10^4 + 10 + 15 \times 4 = 25070$ 个时钟周期。完成 1000 个字符传送所需的时间约为 $1000 \times 25070 = 25070000$ 个时钟周期。
> CPU 用于该任务的时间约为 $1000 \times (10 + 20 \times 4) = 9 \times 10^4$ 个时钟周期。
> 在中断响应阶段，CPU 主要进行以下操作：关中断、保存断点和程序状态、识别中断源。

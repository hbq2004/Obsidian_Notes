# 综合题 第 3 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-Q03_题目.png|题目]]

03. 在程序查询方式的输入/输出系统中，假设不考虑处理时间，每个查询操作需要 100 个时钟周期，CPU 的时钟频率为 50MHz. 现有鼠标和硬盘两个设备，而且 CPU 必须每秒对鼠标进行 30 次查询，硬盘以 32 位字长为单位传输数据，即每 32 位被 CPU 查询一次，传输速率为 $2 \times 2^{20}$ B/s. 求 CPU 对这两个设备查询所花费的时间比率，由此可得出什么结论?

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-Q03_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：CPU 对鼠标查询花费时间比率为 $0.006\%$，对硬盘查询花费时间比率为 $104.8576\%$（超过 $100\%$），说明程序查询方式只适用于低速设备，对于高速设备应采用中断或 DMA 方式。

**解题切入点**  
先计算每次查询操作的耗时（时钟周期数转化为实际时间），再根据设备参数（每秒查询次数或传输速率与字长）计算每秒的总查询时间，最后与 1 秒对比得到时间比率。注意单位换算（时钟周期→秒，字节→位等）以及比率超过 $100\%$ 的含义。

**推演**  
CPU 时钟频率 $f = 50\,\text{MHz} = 50 \times 10^6\,\text{Hz}$，时钟周期  
$$T = \frac{1}{f} = \frac{1}{50 \times 10^6} = 2 \times 10^{-8}\,\text{s} = 20\,\text{ns}.$$  
每个查询操作需要 $100$ 个时钟周期，故每次查询时间  
$$t_q = 100 \times T = 100 \times 20\,\text{ns} = 2000\,\text{ns} = 2\,\mu\text{s}.$$

**鼠标**：每秒查询 $30$ 次，总查询时间  
$$T_{\text{mouse}} = 30 \times 2\,\mu\text{s} = 60\,\mu\text{s}.$$  
时间比率  
$$\eta_{\text{mouse}} = \frac{60\,\mu\text{s}}{1\,\text{s}} = 60 \times 10^{-6} = 6 \times 10^{-5} = 0.006\%.$$

**硬盘**：传输速率 $2 \times 2^{20}\,\text{B/s}$，字长 $32\,\text{bit} = 4\,\text{B}$，故每秒查询次数  
$$N_{\text{disk}} = \frac{2 \times 2^{20}\,\text{B/s}}{4\,\text{B}} = \frac{2 \times 2^{20}}{2^2} = 2 \times 2^{18} = 2^{19} = 524288\ \text{次/秒}.$$  
总查询时间  
$$T_{\text{disk}} = N_{\text{disk}} \times t_q = 524288 \times 2\,\mu\text{s} = 1048576\,\mu\text{s} = 1.048576\,\text{s}.$$  
时间比率  
$$\eta_{\text{disk}} = \frac{1.048576\,\text{s}}{1\,\text{s}} = 1.048576 = 104.8576\%.$$

**结论**：鼠标查询仅耗费 $0.006\%$ 的 CPU 时间，对系统性能影响极小；而硬盘查询需要 $104.8576\%$ 的 CPU 时间，已超过 CPU 总处理能力，在程序查询方式下 CPU 无法及时完成所有查询，必然导致数据丢失或系统崩溃。因此，程序查询方式只适用于低速设备，对于高速设备应采用中断、DMA 等更高效的 I/O 方式。

**易错点**  
1. 单位换算错误：混淆时钟周期与时间（如 $1\,\text{ns}=10^{-9}\,\text{s}$），或误将传输速率中的 $2^{20}$ 当作 $10^6$。  
2. 字长单位混淆：$32$ 位是 $4$ 字节，计算查询次数时需除以 $4$ 而非 $32$。  
3. 忽略比率超过 $100\%$ 的物理意义，只得出数值而忽视结论。

**命题规律**  
本题是 I/O 方式中程序查询的典型计算题，常与中断、DMA 方式对比（如分别计算 CPU 开销）。考点包括：  
- 时钟周期与查询时间的换算。  
- 设备传输速率与查询次数的关系。  
- 不同速率下 CPU 的负担比较。  
复习时应重点掌握各类 I/O 方式的特点、开销计算方法，并理解为何高速设备需要中断或 DMA。


> **原书解答（OCR）**
>
> 03.【解答】
> 1）CPU 每秒对鼠标进行 30 次查询，所需的时钟周期数为 $100\times 30=3000$。CPU 的时钟频率为 $50\text{MHz}$，即每秒 $50\times 10^6$ 个时钟周期，因此对鼠标的查询占用 CPU 的时间比率为 $[3000 \div (50 \times 10^6)] \times 100\% = 0.006\%$。
> 可见，对鼠标的查询基本不影响 CPU 的性能。
> 2）对于硬盘，每 32 位（4B）被 CPU 查询一次，因此每秒查询次数为 $2 \times 2^{20}\text{B} \div 4\text{B} = 512\text{K}$；
> 则每秒查询的时钟周期数为 $100 \times 512 \times 1024 = 52.4 \times 10^6$
> 因此对硬盘的查询占用 CPU 的时间比率为 $[52.4 \times 10^6 \div (50 \times 10^6)] \times 100\% = 105\%$
> 可见，即使 CPU 将全部时间都用于对硬盘的查询，也不能满足磁盘传输的要求，因此 CPU 一般不采用程序查询方式与磁盘交换信息。

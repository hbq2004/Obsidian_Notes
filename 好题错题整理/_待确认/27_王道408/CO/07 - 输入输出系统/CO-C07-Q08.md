# 综合题 第 8 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-Q08_题目.png|题目]]

08. 【2012 统考真题】假定某计算机的 CPU 主频为 $80\text{MHz}$，CPI 为 4，平均每条指令访存 1.5 次，主存与 Cache 之间交换的块大小为 $16\text{B}$，Cache 的命中率为 $99\%$，存储器总线宽度为 32 位。回答下列问题.
1）该计算机的 MIPS 数是多少？平均每秒 Cache 缺失的次数是多少？在不考虑 DMA 传送的情况下，主存带宽至少达到多少才能满足 CPU 的访存要求？
2）假定在 Cache 缺失的情况下访问主存时，存在 $0.0005\%$ 的缺页率，则 CPU 平均每秒产生多少次缺页异常？若页面大小为 $4\text{KB}$，每次缺页都需要访问磁盘，访问磁盘时 DMA 传送采用周期挪用方式，磁盘 I/O 接口的数据缓冲寄存器为 32 位，则磁盘 I/O 接口平均每秒发出的 DMA 请求次数至少是多少？
3）CPU 和 DMA 控制器同时要求使用存储器总线时，哪个优先级更高？为什么？
4）为了提高性能，主存采用 4 体低位交叉存储模式，工作时每 $1/4$ 个存储周期启动一个体。若每个体的存储周期为 $50\text{ns}$，则该主存能提供的最大带宽是多少？

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-Q08_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：综合计算结果为：该机为 \(20\text{ MIPS}\)，平均每秒 Cache 缺失 \(3.0\times10^5\) 次，不考虑 DMA 时主存带宽至少为 \(4.8\times10^6\text{ B/s}=4.8\text{ MB/s}\)；缺页异常为 \(1.5\) 次/秒，DMA 请求至少为 \(1536\) 次/秒；总线仲裁时 DMA 控制器优先级更高；4 体低位交叉主存最大带宽为 \(3.2\times10^8\text{ B/s}=320\text{ MB/s}\)。

**解题切入点**：先把题中所有“速率”统一成一条链：主频和 CPI 得指令速率，乘每条指令访存次数得访存速率，乘缺失率得 Cache 缺失速率，乘缺页率得缺页速率；再按每次事件搬运的数据量折算带宽。DMA 优先级问题比较“谁等不起”：DMA 不及时会丢数据，CPU 等一拍不会。多体交叉存储带宽看启动间隔和每次传送的数据宽度。

**推演**：

1）CPU 主频为 \(80\text{ MHz}\)，CPI 为 \(4\)，所以每秒执行指令数为
\[
\frac{80\times10^6}{4}=20\times10^6\text{ 条/s}=20\text{ MIPS}.
\]

平均每条指令访存 \(1.5\) 次，所以访存次数为
\[
20\times10^6\times1.5=30\times10^6\text{ 次/s}.
\]

Cache 缺失率为
\[
1-99\%=1\%,
\]
故平均每秒 Cache 缺失次数为
\[
30\times10^6\times1\%=3.0\times10^5\text{ 次/s}.
\]

每次 Cache 缺失需要从主存调入一个块，块大小为 \(16\text{ B}\)，因此主存至少要提供的带宽为
\[
3.0\times10^5\times16\text{ B}
=4.8\times10^6\text{ B/s}
=4.8\text{ MB/s}.
\]

这里 Cache 命中时由 Cache 服务，不占用主存；题目说不考虑 DMA 传送，所以该值即为满足 CPU 访存要求的最小主存带宽。

2）Cache 缺失时访问主存的次数为 \(3.0\times10^5\text{ 次/s}\)，缺页率为
\[
0.0005\%=5\times10^{-6}.
\]
因此 CPU 平均每秒产生的缺页异常次数为
\[
3.0\times10^5\times5\times10^{-6}=1.5\text{ 次/s}.
\]

页面大小为 \(4\text{ KB}=4096\text{ B}\)，磁盘 I/O 接口数据缓冲寄存器为 \(32\text{ 位}=4\text{ B}\)。周期挪用方式下，每次 DMA 请求最多传送一个缓冲寄存器宽度，即 \(4\text{ B}\)。所以传送一个页面所需的 DMA 请求次数至少为
\[
\frac{4096}{4}=1024.
\]
故磁盘 I/O 接口平均每秒发出的 DMA 请求次数至少为
\[
1.5\times1024=1536\text{ 次/s}.
\]

3）CPU 和 DMA 控制器同时要求使用存储器总线时，DMA 控制器的优先级更高。

原因是：DMA 用于高速 I/O 设备与主存之间的数据传送，如果 DMA 请求不能及时得到响应，磁盘等外设接口中的数据缓冲寄存器可能被后续到达的数据覆盖，造成数据丢失；而 CPU 等待一个存储器总线周期只是暂停一拍，不会破坏已有信息，对系统的影响远小于数据丢失。因此总线仲裁时优先响应 DMA。

4）每个体的存储周期为
\[
T=50\text{ ns},
\]
4 体低位交叉存储时每 \(1/4\) 个存储周期启动一个体，所以启动间隔为
\[
\frac{T}{4}=\frac{50}{4}=12.5\text{ ns}.
\]

存储器总线宽度为 \(32\) 位，即每次可传送 \(4\text{ B}\)。稳态下，每隔 \(12.5\text{ ns}\) 完成一次 \(4\text{ B}\) 传送，因此最大带宽为
\[
\frac{4\text{ B}}{12.5\times10^{-9}\text{ s}}
=3.2\times10^8\text{ B/s}
=320\text{ MB/s}.
\]

也可理解为：一个存储周期窗口内 4 个体各完成一次 \(32\) 位传送，即
\[
\frac{4\times4\text{ B}}{50\times10^{-9}\text{ s}}
=3.2\times10^8\text{ B/s}
=320\text{ MB/s}.
\]

**易错点**：

- 计算 Cache 缺失次数时，不要用 \(20\text{ M}\) 直接乘缺失率，必须先乘每条指令访存 \(1.5\) 次。
- 注意百分号换算：\(0.0005\%=5\times10^{-6}\)，不是 \(0.0005\)。同时题中缺页率发生在“Cache 缺失后访问主存”时，基数应取 Cache 缺失次数，而不是全部访存次数。
- 计算主存带宽时要使用 Cache 块大小 \(16\text{ B}\)，不能只按总线宽度 \(32\) 位计算；总线宽度影响每次总线事务的字节数，但带宽需求最终是“每秒搬运的字节数”。
- 周期挪用 DMA 中，一次请求通常只传一个数据缓冲寄存器宽度，不能把整个 \(4\text{ KB}\) 页面当作一次 DMA 请求。
- 4 体交叉存储带宽是每 \(12.5\text{ ns}\) 传 \(4\text{ B}\)，不是每 \(12.5\text{ ns}\) 传 \(16\text{ B}\)；后者会得到 \(1.28\text{ GB/s}\) 的错误结果。
- 总线仲裁优先级不是 CPU，理由要落脚在“DMA 不及时响应可能导致数据丢失”。

**命题规律**：本题是 408 中典型的“存储系统 + CPU 性能 + I/O”综合题，核心是把主频、CPI、Cache 命中率、缺页率、DMA 传送、多体交叉存储串成一条速率计算链。常见变式包括：加入 Cache 失效开销或写回/写直达的脏块写回；将缺页率改为 TLB 命中率；将 4 体交叉改为 8 体交叉或给定总线频率求总线带宽；比较 DMA、中断和通道方式。复习时应以“每秒事件数 × 每次事件数据量”为主线，注意单位换算和百分数换算，并理解交叉存储器“启动间隔决定平均带宽”的本质。

> 08.【解答】
> 本题涉及多个考点：计算机的性能指标、存储器的性能指标、DMA 的性能分析、DMA 方式的特点及多体交叉存储器的性能分析。
> 1) 平均每秒 CPU 执行的指令数为 $80\text{M}/4 = 20\text{M}$，因此 MIPS 数为 20。平均每条指令访存 1.5 次，因此平均每秒 Cache 缺失的次数 $= 20\text{M} \times 1.5 \times (1 - 99\%) = 300\text{K}$。当 Cache 缺失时，CPU 访问主存，主存与 Cache 之间以块为传送单位，此时主存带宽为 $16\text{B} \times 300\text{k}/s = 4.8\text{MB}/s$。在不考虑 DMA 传送的情况下，主存带宽至少达到 $4.8\text{MB}/s$ 才能满足 CPU 的访存要求。
> 2) 题中假定在 Cache 缺失的情况下访问主存，平均每秒产生缺页中断 $300000 \times 0.0005\% = 1.5$ 次。因为存储器总线宽度为 32 位，所以每传送 32 位数据，磁盘控制器发出一次 DMA 请求，因此平均每秒磁盘 DMA 请求的次数至少为 $1.5 \times 4\text{KB} / 4\text{B} = 1.5\text{K} = 1536$。
> 3) CPU 和 DMA 控制器同时要求使用存储器总线时，DMA 请求的优先级更高。因为，若 DMA 请求得不到及时响应，I/O 传输数据可能丢失。
> 4) 4 体交叉存储模式能提供的最大带宽为 $4 \times 4\text{B} / 50\text{ns} = 320\text{MB}/s$。

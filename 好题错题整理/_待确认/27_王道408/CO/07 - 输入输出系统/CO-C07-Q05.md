# 综合题 第 5 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-Q05_题目.png|题目]]

05. 一个 DMA 接口可采用周期窃取方式把字符（字节）传送到存储器，它支持的最大批量为$400\text{B}$。若存储周期为$0.2\mu\text{s}$，每处理一次中断需$5\mu\text{s}$，现有的字符设备的传输速率为$9600\text{b/s}$。假设字符之间的传输是无间隙的，试问 DMA 方式每秒因数据传输占用处理器多少时间？若完全采用中断方式，又需占处理器多少时间（忽略预处理所需时间）？

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-Q05_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：DMA 方式下每秒因数据传输占用处理器 $255\,\mu\text{s}$（其中周期窃取 $240\,\mu\text{s}$，批结束中断 $15\,\mu\text{s}$）；完全采用中断方式时每秒占用 $6000\,\mu\text{s}=6\,\text{ms}$。

**解题切入点**：拿到题目先统一单位，把设备传输速率从 bit/s 换成 B/s。然后区分两种方式的处理器开销来源：  
DMA 方式下，每传送一个字节需要“窃取”一个存储周期，且每传满最大批量 $400\text{B}$ 才产生一次中断；完全中断方式下，每传送一个字符都产生一次中断。可以把 DMA 看成“批量打包”，把中断方式看成“逐个处理”，这样开销差别就很清晰。

**推演**：

字符设备的传输速率为 $9600\text{b/s}$，即

$$
9600\text{ b/s} = \frac{9600}{8}\text{ B/s} = 1200\text{ B/s}.
$$

因为一个字符等于一个字节，所以每秒需传送 $1200$ 个字节。

### 1. DMA 方式

DMA 采用周期窃取方式，每向存储器传送一个字节，需要占用一个存储周期：

$$
T_{\text{窃取}} = 1200 \times 0.2\,\mu\text{s} = 240\,\mu\text{s}.
$$

DMA 接口支持的最大批量为 $400\text{B}$，因此每 $400\text{B}$ 传送完一次，需要中断 CPU 一次。每秒中断次数为

$$
N_{\text{DMA中断}} = \frac{1200}{400} = 3\text{ 次}.
$$

每次中断处理需要 $5\,\mu\text{s}$，所以中断开销为

$$
T_{\text{DMA中断}} = 3 \times 5\,\mu\text{s} = 15\,\mu\text{s}.
$$

因此 DMA 方式每秒占用处理器总时间为

$$
T_{\text{DMA}} = T_{\text{窃取}} + T_{\text{DMA中断}}
            = 240\,\mu\text{s} + 15\,\mu\text{s}
            = 255\,\mu\text{s}.
$$

### 2. 完全中断方式

完全采用中断方式时，每传送一个字符（字节）都需要 CPU 处理一次中断。每秒传送 $1200$ 个字节，因此每秒中断 $1200$ 次。每次中断处理需 $5\,\mu\text{s}$，故

$$
T_{\text{中断}} = 1200 \times 5\,\mu\text{s} = 6000\,\mu\text{s} = 6\,\text{ms}.
$$

题目要求忽略预处理所需时间，所以这里不再额外加上中断前设备启动、现场保护等时间。

**易错点**：

1. **单位换算错误**：$9600\text{b/s}$ 是比特率，必须先除以 $8$ 得到 $1200\text{B/s}$，不能直接把 $9600$ 当成字节数。  
2. **DMA 方式漏算中断开销**：只算周期窃取的 $240\,\mu\text{s}$，忘记每批 $400\text{B}$ 结束后还有一次中断，得到错误答案。  
3. **DMA 中断次数按字节算**：DMA 不是每传一个字节都中断，而是每传完一批 $400\text{B}$ 才中断一次，每秒只有 $3$ 次。  
4. **完全中断方式按批算**：中断方式下每个字符都要中断一次，所以每秒中断 $1200$ 次，而不是 $3$ 次。  
5. **时间单位换算**：$6000\,\mu\text{s}=6\,\text{ms}$，$255\,\mu\text{s}=0.255\,\text{ms}$，要注意不要写错数量级。

**命题规律**：本题属于“输入输出系统”中 DMA 方式与中断方式的开销比较，是 408 计算机组成原理的常考计算题。核心考点是理解周期窃取每次传送一个数据单位占用一个存储周期，而 DMA 的预处理和后处理（通常以中断方式）也要占用 CPU 时间。常见变式有：  
- 把设备速率换成磁盘、网络等高速设备的数据率；  
- 把“最大批量”改成“DMA 块大小”；  
- 增加“DMA 预处理时间”要求计算总开销；  
- 要求计算 CPU 占用率，如 $\frac{255\,\mu\text{s}}{1\text{s}}=0.0255\%$ 或 $\frac{6\text{ms}}{1\text{s}}=0.6\%$。  

复习时建议总结统一公式：

$$
\text{CPU占用时间} = \text{传送/窃取时间} + \text{中断次数} \times \text{每次中断时间} + \text{预处理时间},
$$

并熟练掌握 bit 与 Byte 的换算、微秒与毫秒的换算。

> 05.【解答】

> $5\mu\text{s} \times (1200/400) = 15\mu\text{s}$

> $5\mu\text{s} \times 1200 = 6000\mu\text{s}$

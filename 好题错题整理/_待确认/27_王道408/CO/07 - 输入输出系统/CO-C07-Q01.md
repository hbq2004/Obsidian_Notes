# 综合题 第 1 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-Q01_题目.png|题目]]

01. 在 DMA 方式下，主存和 I/O 设备之间有一条物理通路相连吗.
(A) 是. 因为 DMA 方式下，主存和 I/O 设备之间有一条 I/O 总线相连.
(B) 是. 因为 DMA 方式下，主存和 I/O 设备之间有一条专用的 DMA 数据传送总线相连.
(C) 不一定. 因为 DMA 方式下，数据传送的路径取决于 DMA 控制器的类型和系统结构.
(D) 不是. 因为 DMA 方式下，主存和 I/O 设备之间没有直接的物理通路，数据传送需要通过 CPU 或 DMA 控制器.

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-Q01_答案.png|答案]]


> **原书解答（OCR）**

01.【解答】
没有。通常所说的 DMA 方式在主存和 I/O 设备之间建立一条“直接的数据通路”，使得数据在主存和 I/O 设备之间直接进行传送，其含义并不是在主存和 I/O 之间建立一条物理直接通路，而是主存和 I/O 设备通过 I/O 设备接口、系统总线及总线桥接部件等相连，建立一个信息可以相互通达的通路，这在逻辑上可视为直接相连的。其“直接”是相对于要通过 CPU 才能和主存相连这种方式而言的。

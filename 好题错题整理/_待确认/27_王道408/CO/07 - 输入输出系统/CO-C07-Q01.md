# 综合题 第 1 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-Q01_题目.png|题目]]

01. 在 DMA 方式下，主存和 I/O 设备之间有一条物理通路相连吗.
(A) 是. 因为 DMA 方式下，主存和 I/O 设备之间有一条 I/O 总线相连.
(B) 是. 因为 DMA 方式下，主存和 I/O 设备之间有一条专用的 DMA 数据传送总线相连.
(C) 不一定. 因为 DMA 方式下，数据传送的路径取决于 DMA 控制器的类型和系统结构.
(D) 不是. 因为 DMA 方式下，主存和 I/O 设备之间没有直接的物理通路，数据传送需要通过 CPU 或 DMA 控制器.

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-Q01_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 C，即“不一定”。因为 DMA 方式下，数据传送的路径取决于 DMA 控制器的类型和系统结构，可能通过系统总线、I/O 总线或专用通道，并非总存在一条固定的物理通路。

**解题切入点**：首先明确 DMA 的核心是“不经过 CPU 直接主存与设备交换数据”，但“直接”是指逻辑上无需 CPU 干预，物理上则需分析总线结构。常见误区是混淆“专用通路”与“共享总线”，应结合系统结构（如独立总线、桥接结构）判断。

**推演**：  
DMA 方式下，主存与 I/O 设备之间的数据传送有三类典型路径：
1. 若使用 **选择型 DMA 控制器**，设备与控制器之间有专用数据线，控制器通过系统总线与主存相连，此时设备与主存之间通过控制器间接连接，无直接物理线。
2. 若采用 **多路型 DMA 控制器**，多个设备共享一条 DMA 总线，该总线再通过系统总线桥接主存，同样无专用直达通路。
3. 在 **独立 I/O 总线结构**（如 PCI）中，设备挂接在 I/O 总线上，I/O 总线通过北桥芯片与主存总线相连，数据传送仍需经过桥接，物理上仍为多段总线拼接。  
因此，题中选项 A（I/O 总线直接连主存）和 B（专用 DMA 总线）均不普遍；选项 D 完全否定通路，但 DMA 控制器本身构成通路的一部分，故错误。正确答案为 C。

**易错点**：  
- 误以为 DMA 一定存在“专用数据通路”，实际多数系统共享系统总线，专用通路仅在特定高端结构中出现。  
- 将“逻辑上不经过 CPU”等同于“物理上有直接连线”，忽略桥接、总线仲裁等中间环节。  
- 忽略 DMA 控制器类型（选择型、多路型、块传输型）对路径的影响。

**命题规律**：  
- 考点：DMA 方式的基本原理、总线结构、DMA 控制器分类。  
- 常见变式：问 DMA 传送的数据流经哪些部件（如设备→DMA 控制器→主存），或比较 DMA 与中断方式的数据路径差异。  
- 复习建议：画出典型系统的总线拓扑（如单总线、多总线结构），标注 DMA 控制器位置，并区分不同 DMA 类型下的数据流动方向。

> 01.【解答】
> 没有。通常所说的 DMA 方式在主存和 I/O 设备之间建立一条“直接的数据通路”，使得数据在主存和 I/O 设备之间直接进行传送，其含义并不是在主存和 I/O 之间建立一条物理直接通路，而是主存和 I/O 设备通过 I/O 设备接口、系统总线及总线桥接部件等相连，建立一个信息可以相互通达的通路，这在逻辑上可视为直接相连的。其“直接”是相对于要通过 CPU 才能和主存相连这种方式而言的。

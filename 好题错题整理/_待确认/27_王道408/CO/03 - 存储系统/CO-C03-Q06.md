# 综合题 第 6 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-Q06_题目.png|题目]]

06.【2018统考真题】某计算机采用页式虚拟存储管理方式，按字节编址。CPU 进行存储访问的过程如下图所示。根据该图回答下列问题。

【图：展示了 CPU 发出的虚拟地址（20位虚页号+12位页内地址）如何通过 TLB 进行快速翻译。若 TLB 未命中，则通过两级页表（页目录、页表）翻译出实页号。实页号与页内地址构成物理地址。该物理地址进一步被拆分为 20 位 Cache Tag、3 位 Cache 组索引和 5 位块内偏移，用于 Cache 访问。Cache 包含多组，每组有多路，每路包含有效位、Tag 和 Data。最终，数据通过多路选择器返回。】

TLB 结构：

| Tag       | 有效位 | 实页号   |
| :-------- | :----- | :------- |
| 00324H    | 1      | F800H    |
| 0008CH    | 1      | 0040H    |
| 8C040H    | 1      | 0160H    |
| ...       | ...    | ...      |
| 04320H    | 0      | 0E80H    |

Cache 结构：

| 有效位 | Tag       | Data |
| :----- | :-------- | :--- |
| 1      | F8000H    | ...  |
| 1      | 008C0H    | ...  |
| 0      | 00400H    | ...  |
| ...    | ...       | ...  |
| 有效位 | Tag       | Data |
| 1      | F2840H    | ...  |
| 0      | 23008H    | ...  |
| 1      | 01600H    | ...  |
| ...    | ...       | ...  |

1) 主存物理地址占多少位?
2) TLB 采用什么映射方式? TLB 是用 SRAM 还是用 DRAM 实现?
3) Cache 采用什么映射方式? 若 Cache 采用 LRU 算法和回写法，则 Cache 每行中除数据（Data）、标记和有效位外，还应有哪些附加位? Cache 总容量是多少? Cache 中有效位的作用是什么?
4) 若 CPU 给出的虚拟地址为 0008 C040H，则对应的物理地址是多少? 是否在 Cache 中命中? 说明理由。若 CPU 给出的虚拟地址为 0007 C260H，则该地址所在主存块映射到的 Cache 组号是多少?

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-Q06_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：主存物理地址占 28 位；TLB 采用全相联映射，用 SRAM 实现；Cache 采用组相联映射，每行附加脏位和 LRU 位，总容量为 1120 B；虚拟地址 0008 C040H 对应的物理地址为 0040 040H，在 Cache 中不命中；虚拟地址 0007 C260H 所在主存块映射到的 Cache 组号为 3。

**解题切入点**  
- 先看懂地址转换流程：CPU 给出 32 位虚拟地址（20 位虚页号 + 12 位页内地址），通过 TLB 快速得到实页号，与页内地址拼接成物理地址；物理地址再拆分为 20 位 Cache Tag、3 位 Cache 组索引和 5 位块内偏移，用于 Cache 访问。  
- 根据物理地址的拆分位数直接得出主存物理地址长度。  
- 观察 TLB 和 Cache 的结构表格，判断映射方式：TLB 条目无索引字段，应为全相联；Cache 有组索引位，故为组相联。  
- 计算 Cache 容量时需明确组数、路数及每行附加位（LRU 位、脏位），路数可从图中每组行数推断（通常为 4 路）。  
- 对于地址翻译题，先分解虚拟地址，查 TLB 得实页号，再合成物理地址，最后按 Cache 划分判断是否命中。

**推演**  

1) **主存物理地址位数**  
   物理地址被拆分为 20 位 Tag、3 位组索引和 5 位块内偏移，故总位数为  
   $$20 + 3 + 5 = 28\ \text{位}$$

2) **TLB 的映射方式与实现材料**  
   - 从给出的 TLB 结构看，每个条目包含一个完整的 Tag，没有索引字段，因此 TLB 采用**全相联映射**（所有条目并行比较 Tag）。  
   - TLB 需要极快的访问速度，通常用 **SRAM** 实现，而非 DRAM。

3) **Cache 的分析**  
   - **映射方式**：物理地址中有 3 位 Cache 组索引，说明 Cache 分为 $2^3 = 8$ 组，每组内有多路，故采用**组相联映射**。  
   - **附加位**：  
     * 采用 LRU 替换算法，需要记录每行在组内的访问顺序，因此需**LRU 位**（用于 4 路组相联，需 2 位）。  
     * 采用回写策略，需要标记该行是否被修改过，因此需**脏位**（1 位）。  
   - **Cache 总容量**：  
     从图中可知每组有 4 路（表格中每组列出 3 行示例，但“…”表示实际为 4 路）。  
     每行数据块大小 = $2^5 = 32$ 字节 = $256$ 位，标记 20 位，有效位 1 位，脏位 1 位，LRU 位 2 位。  
     每行总位数 = $256 + 20 + 1 + 1 + 2 = 280$ 位。  
     总容量 = 组数 × 路数 × 每行位数 = $8 \times 4 \times 280 = 8960$ 位 = $1120$ 字节。  
   - **有效位的作用**：标记该行是否存储了有效数据。初始为 0，当数据加载到 Cache 后置 1；若被置为 0，则此行无效，访问时需从下一级存储器读取。

4) **地址翻译与 Cache 命中判断**  
   - **虚拟地址 0008 C040H**  
     1) 虚页号 = 高 20 位 = 0008 CH，页内地址 = 低 12 位 = 040 H。  
     2) 查 TLB：Tag = 0008 CH 有效，得实页号 = 0040 H。  
     3) 物理地址 = 实页号 $\times 2^{12}$ + 页内地址 = 0040 H $\times$ 4096 + 040 H = 0040 000 H + 040 H = 0040 040 H。  
     4) 物理地址 28 位：高 20 位 Tag = 0040 0H，中间 3 位组索引 = 010 B = 2，低 5 位偏移 = 0。  
     5) 在 Cache 中，组 2 的 Tag 为 0040 0H 的行有效位为 0，故**不命中**。  
   - **虚拟地址 0007 C260H**  
     页内地址 = 260 H，Cache 组索引取自页内地址的位 7‑5，即  
     $$(260\text{H} \gg 5) \ \&\ 7 = 13\text{H} \ \&\ 7 = 3$$  
     因此该地址所在主存块映射到的 Cache 组号为 **3**。

**易错点**  
- 物理地址位数：只数 Tag、组索引、偏移的位数之和，忽略其他未使用的位。  
- TLB 映射方式：易误认为组相联，但题目中 TLB 条目无索引，属全相联。  
- Cache 附加位：容易遗漏 LRU 位或脏位，或混淆 LRU 位的位数（需根据路数取 $\log_2$ 路数）。  
- 组索引计算：必须从物理地址的中间位（位 7‑5）提取，而不是从高位或低位直接取；页内地址的位 7‑5 在地址转换后不变，可直接计算。  
- 容量单位：总容量通常指所有位（包括标记、有效位等）的总和，而非仅数据容量。

**命题规律**  
- **考点定位**：页式虚拟存储管理、TLB 与 Cache 的地址转换与映射、Cache 容量计算。  
- **常见变式**：  
  * 改变虚拟地址位数、页大小或 Cache 参数（组数、路数、块大小）重新计算。  
  * 结合页表结构（多级页表）要求给出物理地址或计算页表开销。  
  * 改变 Cache 替换算法（如 FIFO、随机）或写策略（写直达），相应附加位会变化。  
  * 要求分析 TLB 缺失时的处理流程（查页表、缺页等）。  
- **复习建议**：  
  * 熟练掌握地址拆分：虚拟地址 → 虚页号 + 页内地址；物理地址 → Tag + 组索引 + 偏移。  
  * 理解 TLB 与 Cache 的映射方式（全相联、组相联）及其硬件实现特点。  
  * 会计算 Cache 总容量，注意每行附加位（有效位、脏位、替换位）的位数由具体策略和路数决定。  
  * 多练典型题，特别是结合图表的综合应用题，培养快速定位位域和查表的能力。

> 06. 【解答】
> 1）物理地址由实页号和页内地址拼接，因此其位数为 $16+12=28$；或直接得 $20+3+5=28$。
> 2）TLB 采用全相联映射，可把页表内容调入任意一块空 TLB 项中，TLB 中的每项都有一个比较器，没有映射规则，只要空闲就行。TLB 采用静态存储器（SRAM），读/写速度快，但成本高，多用于容量较小的高速缓冲存储器。
> 3）图中可看到，Cache 中每组有两行，因此采用 2 路组相联映射方式。因为是 2 路组相联并采用 LRU 算法，所以每行需要 1 位 LRU 位；因为采用回写法，所以每行有 1 位修改位（脏位），根据脏位判断数据是否被更新，若脏位为 1，则需要写回内存。28 位物理地址中标记字段占 20 位，组索引字段占 3 位，块内偏移地址占 5 位，因此 Cache 共有 $2^3=8$ 组，每组 2 行，每行有 $2^5=32B$；Cache 的总容量为 $8\times2\times(20+1+1+1+32\times8)=4464b=558B$。
> Cache 中有效位用来指出所在 Cache 行中的信息是否有效。
> 4）虚拟地址分为两部分：虚页号、页内地址；物理地址分为两部分：实页号、页内地址。利用虚拟地址的虚页号部分去查找 TLB 表（缺失时从页表调入），将实页号取出后和虚拟地址的页内地址拼接，形成物理地址。虚页号 0008CH 恰好在 TLB 表中对应实页号 0040H（有效位为 1，说明存在），虚拟地址的后 3 位为页内地址 040H，对应的物理地址是 0040040H。
> 物理地址为 0040040H，其中高 20 位 00400H 为标志字段，低 5 位 00000B 为块内偏移量，中间 3 位 010B 为组号 2，因此将 00400H 与 Cache 中的第 2 组两行中的标志字段同时比较，可以看出，虽然有一个 Cache 行中的标志字段与 00400H 相等，但对应的有效位为 0，而另一 Cache 行的标志字段与 00400H 不相等，因此访问 Cache 不命中。
> 因为物理地址的低 12 位与虚拟地址的低 12 位相同，即为 0010 0110 0000B。根据物理地址的结构，物理地址的后八位 01100000B 的前三位 011B 是组号，因此该地址所在的主存映射到 Cache 组号为 3。

# 综合题 第 5 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-Q05_题目.png|题目]]

05. 【2016 统考真题】某计算机采用页式虚拟存储管理方式，按字节编址，虚拟地址为 $32$ 位，物理地址为 $24$ 位，页大小为 $8\text{KB}$；TLB 采用全相联映射；Cache 数据区大小为 $64\text{KB}$，按 $2$ 路组相联映射方式组织，主存块大小为 $64\text{B}$。存储访问过程的示意图如下。

【图：存储访问过程示意图】

回答下列问题：
1）图中字段 $A \sim G$ 的位数各是多少？TLB 标记字段 $B$ 中存放的是什么信息？
2）将块号为 $4099$ 的主存块装入 Cache 时，所映射的 Cache 组号是多少？对应的 $H$ 字段内容是什么？
3）是 Cache 缺失处理的时间开销大还是缺页处理的时间开销大？为什么？
4）为什么 Cache 可以采用直写法，而修改页面内容时总是采用回写法？

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-Q05_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：  
1）字段位数：$A=13$、$B=19$、$C=13$、$D=11$、$E=6$、$F=9$、$G=9$；TLB 标记字段 $B$ 存放虚拟页号（VPN）。  
2）块号 $4099$ 的主存块映射到的 Cache 组号为 $3$，对应的 $H$ 字段内容为 $8$（十进制）。  
3）Cache 缺失处理时间开销小，缺页处理时间开销大。  
4）Cache 直写法可保证数据一致性且主存访问速度较快，开销可接受；页面修改采用回写法可避免频繁磁盘 I/O，提升性能。

**解题切入点**  
- 先根据页大小、Cache 容量与块大小等参数，确定各地址字段的位数划分（虚拟地址、物理地址、Cache 地址）。  
- 再结合示意图中字段出现的顺序，将虚拟地址、TLB、物理地址、Cache 的对应部分与 $A\sim G$ 匹配。  
- 对于块号映射问题，直接利用块号与 Cache 组索引、标记的位对应关系计算。  
- 比较 Cache 缺失与缺页的时间开销，本质是主存访问与磁盘访问的延迟差异。  
- 直写与回写的选择根据写操作的目标设备速度及一致性要求判断。

**推演**  

### 1. 字段 $A\sim G$ 的位数及 $B$ 的内容  
- **虚拟地址**：$32$ 位，页大小 $8\text{KB}=2^{13}\text{B}$，故  
  - 页内偏移（低 $13$ 位）→ 字段 $A$，位数 $13$。  
  - 虚拟页号（高 $19$ 位）→ 字段 $B$（TLB 标记），位数 $19$，存放虚拟页号（VPN）。  
- **物理地址**：$24$ 位，页大小相同，故  
  - 页内偏移（低 $13$ 位）→ 字段 $C$，位数 $13$（与 $A$ 相同）。  
  - 物理页框号（高 $11$ 位）→ 字段 $D$，位数 $11$。  
- **Cache**：  
  - 数据区 $64\text{KB}$，主存块 $64\text{B}=2^6\text{B}$，块内偏移需 $6$ 位 → 字段 $E$，位数 $6$。  
  - $2$ 路组相联，组数 $= \frac{64\text{KB}}{64\text{B}\times 2}=2^9$，组索引需 $9$ 位 → 字段 $F$，位数 $9$。  
  - 物理地址共 $24$ 位，标记位数 $=24-6-9=9$ → 字段 $G$，位数 $9$。  

### 2. 块号 $4099$ 对应的 Cache 组号与 $H$ 字段内容  
- 主存块大小 $64\text{B}$，块号 $4099$ 的物理地址为 $4099\times 64$。  
- Cache 组数 $512$，组索引取自物理地址的中间 $9$ 位（即块号 $4099$ 的低 $9$ 位）：  
  $$4099 \div 512 = 8 \text{ 余 } 3 \quad\Rightarrow\quad \text{组号}=3.$$  
- $H$ 字段为 Cache 行中的标记，其值等于物理地址的高 $9$ 位（即块号的高 $9$ 位）：  
  $$\lfloor 4099/512 \rfloor = 8.$$  
  故 $H$ 字段内容为 $8$（二进制 $000001000$）。  

### 3. Cache 缺失与缺页的时间开销比较  
- Cache 缺失：需从主存读取数据到 Cache，主存访问延迟约 $10\sim 100\text{ns}$。  
- 缺页：需从磁盘读取数据到主存，磁盘访问延迟约 $10\text{ms}$ 量级，相差 $10^5$ 倍以上。  
  因此缺页处理时间开销远大于 Cache 缺失。  

### 4. Cache 直写法与页面回写法的原因  
- **Cache 直写**：写操作时同时写入 Cache 和主存，保证数据一致性。主存速度较快（与 CPU 速度差距小于磁盘），直写不显著降低性能，且简化了 Cache 一致性协议。  
- **页面回写**：磁盘写入速度极慢（毫秒级），若每次页面修改都写回磁盘，将严重拖慢系统。页面常被多次修改，回写法仅在页面被换出时一次性写回，大幅减少磁盘 I/O 次数，提升整体性能。  

**易错点**  
1. **地址划分错误**：误将页内偏移与 Cache 块内偏移混淆，或误把物理页框号位数当作 Cache 标记位数。  
2. **组号计算错误**：块号直接取模 $512$ 得组号，但需注意块号与物理地址的对应关系（块号 $=$ 物理地址 $\gg 6$）。  
3. **$H$ 字段内容遗漏**：未理解 $H$ 是 Cache 行中的标记，其值等于物理地址的高 $9$ 位（块号 $\gg 9$），而非块号本身。  
4. **时间开销比较**：误以为 Cache 缺失开销更大（实际缺页需磁盘 I/O，远慢于主存）。  
5. **直写/回写原理混淆**：认为直写也会写磁盘，误将回写与 Cache 回写混为一谈。  

**命题规律**  
- **考点定位**：页式虚拟存储、TLB 与 Cache 的地址划分、映射关系、性能对比及写策略。  
- **常见变式**：  
  - 改变页大小、Cache 容量或组相联度，重新计算字段位数或映射关系。  
  - 结合 TLB 缺失与缺页的混合处理（如先查 TLB 再查页表）。  
  - 改用写分配/非写分配策略，或比较不同写策略的优劣。  
- **复习建议**：  
  - 熟练掌握地址结构：虚拟地址、物理地址、Cache 地址的位划分，尤其是页内偏移、块内偏移、组索引、标记的位数计算。  
  - 理解块号、物理地址、Cache 组号之间的转换关系，会进行模运算。  
  - 明确定时开销层次：寄存器 > Cache > 主存 > 磁盘，并理解直写/回写适用场景。  
  - 多做真题，训练从示意图中提取字段的能力。

> 05. 【解答】
> 1) 页大小为8KB，页内偏移地址为13位，因此 $A = B = 32 - 13 = 19$；$D = 13$；$C = 24 - 13 = 11$；主存块大小为64B，因此 $G = 6$。2路组相联，每组数据区容量有 $64\text{B} \times 2 = 128\text{B}$，共有 $64\text{KB} / 128\text{B} = 512$ 组，因此 $F = 9$；$E = 24 - G - F = 24 - 6 - 9 = 9$。
> 因此 $A = 19$，$B = 19$，$C = 11$，$D = 13$，$E = 9$，$F = 9$，$G = 6$。
> TLB中标记字段B的内容是虚页号，表示该TLB项对应哪个虚页的页表项。
> 2) 块号 $4099 = 00\ 0001\ 0000\ 0000\ 0011\text{B}$，因此所映射的 Cache 组号为 $0\ 0000\ 0011\text{B} = 3$，对应的 H 字段内容为 $0\ 0000\ 1000\text{B}$。
> 3) Cache 缺失带来的开销小，而处理缺页的开销大。因为缺页处理需要访问磁盘，而 Cache 缺失只要访问主存。
> 4) 因为采用直写法时需要同时写快速存储器和慢速存储器，而写磁盘比写主存慢很多，所以在 Cache-主存层次，Cache 可以采用直写法，而在主存-外存（磁盘）层次，修改页面内容时总是采用回写法。

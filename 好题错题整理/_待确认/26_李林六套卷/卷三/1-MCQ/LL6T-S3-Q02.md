# 选择题 第 2 题

![[_Attachments/题目识别/LL6T/LL6T-S3-Q02_题目.png|题目]]

设 $f(x) = (x - a)\ln x - x$ 有两个极值点, 则实数 $a$ 的取值范围为.
(A) $[-\frac{1}{e}, +\infty)$.
(B) $(-\frac{1}{e}, +\infty)$.
(C) $[-\frac{1}{e}, 0)$.
(D) $(-\frac{1}{e}, 0)$.

![[_Attachments/题目识别/LL6T-答案/LL6T-S3-Q02_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**
【答案】(D)
【推演】
- 选项A $[-\frac{1}{e}, +\infty)$：当 $a \ge -\frac{1}{e}$ 时，可能有一个或两个极值点，但 $a=0$ 时只有一个极值点，$a>0$ 时也只有一个，且 $a=-\frac{1}{e}$ 时无极值点，故不满足两个极值点。
- 选项B $(-\frac{1}{e}, +\infty)$：同样包含 $a\ge0$ 的部分，此时只有一个极值点，排除。
- 选项C $[-\frac{1}{e}, 0)$：包含端点 $a=-\frac{1}{e}$，此时 $f'(x)\ge0$ 恒成立，无极值点，故排除。
- 选项D $(-\frac{1}{e}, 0)$：当 $a\in(-\frac{1}{e},0)$ 时，方程 $x\ln x = a$ 有两个相异实根，且 $f''(x)\neq0$，均为极值点，符合题意。

因此，正确选项为 (D)。

**解题切入点**
本题主要考查函数极值点的存在条件，即导函数零点个数及符号判断。核心是转化为方程 $x\ln x = a$ 的实根个数问题，通过研究函数 $g(x)=x\ln x$ 的单调性和极值，确定参数 $a$ 的范围。类比算法竞赛中的“参数对函数零点个数的影响”，需注意定义域 $x>0$ 及端点行为。

**推演**
1. **求导找驻点**
   $f(x) = (x-a)\ln x - x$，定义域 $x>0$。
   $f'(x) = \ln x + \frac{x-a}{x} - 1 = \ln x + 1 - \frac{a}{x} - 1 = \ln x - \frac{a}{x}$。
   令 $f'(x)=0$，得 $\ln x = \frac{a}{x}$，即 $x\ln x = a$。

2. **分析方程 $x\ln x = a$ 的根**
   令 $g(x)=x\ln x$，$x>0$。
   $g'(x)=\ln x + 1$，令 $g'(x)=0$ 得 $x=\frac{1}{e}$。
   当 $0<x<\frac{1}{e}$ 时，$g'(x)<0$，$g(x)$ 递减；当 $x>\frac{1}{e}$ 时，$g'(x)>0$，$g(x)$ 递增。
   $g(x)$ 在 $x=\frac{1}{e}$ 处取得最小值 $g\left(\frac{1}{e}\right)=-\frac{1}{e}$。
   且 $\lim\limits_{x\to0^+}g(x)=0$，$\lim\limits_{x\to+\infty}g(x)=+\infty$，$g(1)=0$。

   因此，
   - 当 $a<-\frac{1}{e}$ 时，方程无实根，无极值点；
   - 当 $a=-\frac{1}{e}$ 时，方程有唯一实根 $x=\frac{1}{e}$，但此时 $f'(x)\ge0$ 恒成立（检验单调性），不是极值点；
   - 当 $-\frac{1}{e}<a<0$ 时，方程有两个相异实根，分别位于 $(0,\frac{1}{e})$ 和 $(\frac{1}{e},1)$ 内；
   - 当 $a=0$ 时，方程有唯一实根 $x=1$；
   - 当 $a>0$ 时，方程有唯一实根 $x>1$。

3. **判断驻点是否为极值点**
   对驻点 $x_0$ 满足 $x_0\ln x_0 = a$，代入二阶导数：
   $f''(x) = \frac{1}{x} + \frac{a}{x^2} = \frac{x+a}{x^2}$，利用 $a=x_0\ln x_0$ 得 $f''(x_0)=\frac{1+\ln x_0}{x_0}$。
   - 当 $x_0<\frac{1}{e}$ 时，$\ln x_0<-1$，$f''(x_0)<0$，为极大值点；
   - 当 $x_0>\frac{1}{e}$ 时，$\ln x_0>-1$，$f''(x_0)>0$，为极小值点。

   故在 $-\frac{1}{e}<a<0$ 时，两个驻点均为极值点，且一极大一极小。

4. **结论**
   函数 $f(x)$ 有两个极值点的充要条件是 $a\in(-\frac{1}{e},0)$。

   对应选项 (D) 正确。

**易错点**
- 易忽略定义域 $x>0$，导致多解。
- 误认为驻点一定是极值点，需验证二阶导数或单调性。例如 $a=-\frac{1}{e}$ 时驻点非极值点。
- 对 $a=0$ 时，只有一个极值点，容易误认为有两个。
- 端点值 $a=-\frac{1}{e}$ 和 $a=0$ 的取舍是常见陷阱，需结合图像和单调性准确判断。

**命题规律**
- 此类题常以“极值点个数”为载体，考查导数的应用和参数讨论，核心是转化为方程根的分布问题。
- 复习时需熟练掌握函数极值的判定方法，学会利用导数研究函数性质，并注意临界点的分析。
- 类似问题还可拓展为“拐点个数”、“切线条数”等，本质都是方程根的个数问题。

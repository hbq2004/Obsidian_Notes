# 填空题 第 14 题

![[_Attachments/题目识别/LL6T/LL6T-S1-Q14_题目.png|题目]]

设微分方程 $y''+ay'+y=0$ 的每一个解 $y(x)$ 在 $[0,+\infty)$ 上有界，则实数 $a$ 的取值范围为\\_\\_\\_\\_\\_\\_.

![[_Attachments/题目识别/LL6T-答案/LL6T-S1-Q14_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**

\boxed{a \ge 0}

**解题切入点**

这是一道考查微分方程解的有界性（稳定性）的概念题。类似于算法竞赛中判断系统是否稳定，需通过特征方程分析特征根的实部。对于二阶常系数齐次微分方程，解的有界性完全由特征根实部决定：实部为负时解指数衰减有界；实部为零时解为三角函数有界；实部为正时解指数增长无界。因此，只需确保所有特征根实部非正。

**推演**

1. 写出特征方程：$r^2 + a r + 1 = 0$。
2. 特征根：$r = \frac{-a \pm \sqrt{a^2 - 4}}{2}$。
3. 分情况讨论：
   - 当 $a^2 > 4$，即 $|a| > 2$ 时，特征根为两个不等实根。若 $a > 2$，则两根之和为 $-a < 0$，积为 $1 > 0$，故两根均为负，解为 $y = C_1 e^{r_1 x} + C_2 e^{r_2 x}$，在 $[0,+\infty)$ 上指数衰减，有界。若 $a < -2$，则两根之和为正，两根均为正，解指数增长，无界。
   - 当 $a^2 = 4$，即 $a = \pm 2$ 时，特征根为重根。$a = 2$ 时，$r = -1$，解为 $y = (C_1 + C_2 x)e^{-x}$，在 $[0,+\infty)$ 上有界（因为 $x e^{-x}$ 有界）。$a = -2$ 时，$r = 1$，解为 $y = (C_1 + C_2 x)e^{x}$，无界。
   - 当 $a^2 < 4$，即 $|a| < 2$ 时，特征根为共轭复根 $r = \alpha \pm i\beta$，其中 $\alpha = -\frac{a}{2}$，$\beta = \frac{\sqrt{4-a^2}}{2}$。解为 $y = e^{\alpha x}(C_1 \cos \beta x + C_2 \sin \beta x)$。在 $[0,+\infty)$ 上有界当且仅当 $\alpha \le 0$，即 $-\frac{a}{2} \le 0$，得 $a \ge 0$。当 $a \ge 0$ 且 $a < 2$ 时，$\alpha \le 0$，解有界（$\alpha=0$ 时三角函数有界，$\alpha<0$ 时指数衰减有界）。当 $a < 0$ 时，$\alpha > 0$，解指数增长，无界。
4. 综合所有情况，使每一个解有界的 $a$ 的取值范围为 $a \ge 0$。

**易错点**

容易忽略边界情况，如 $a=0$ 时复根实部为零，解为三角函数，有界；$a=2$ 时重根实部为负，解有界；$a$ 为正时实根均为负，有界。常见错误是误认为 $a>0$ 才保证有界，而漏掉 $a=0$；或误认为 $a \ge 2$ 时解无界，实际上 $a=2$ 有界，$a>2$ 也有界。

**命题规律**

此类问题常以微分方程解的性质（有界性、稳定性、渐近性）为背景，考查特征根法及参数讨论。复习时需熟练掌握特征根与解的形式的关系，以及实部、虚部对解的影响。对于有界性，核心是保证特征根实部非正，同时注意重根时多项式因子是否破坏有界性。建议通过画数轴或表格分情况讨论，确保不遗漏边界。

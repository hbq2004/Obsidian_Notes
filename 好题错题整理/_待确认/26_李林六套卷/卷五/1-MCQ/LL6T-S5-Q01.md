# 选择题 第 1 题

![[_Attachments/题目识别/LL6T/LL6T-S5-Q01_题目.png|题目]]

设当 $x \to 0$ 时，有 $\cot x = \frac{1+ax^2}{x+bx^3} + o(x^5)$，则.
(A) $a = \frac{2}{5}, b = -\frac{1}{15}.$
(B) $a = -\frac{2}{5}, b = \frac{1}{15}.$
(C) $a = -\frac{2}{5}, b = -\frac{1}{15}.$
(D) $a = \frac{2}{5}, b = \frac{1}{15}.$

![[_Attachments/题目识别/LL6T-答案/LL6T-S5-Q01_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**

选择题【答案】: (C) a = -2/5, b = -1/15。

【推演】逐一分析各选项：
- (A) a=2/5, b=-1/15：x项系数a-b=7/15，不匹配cot x的-1/3。
- (B) a=-2/5, b=1/15：a-b=-7/15，不匹配。
- (D) a=2/5, b=1/15：a-b=1/3，符号相反。
只有(C)满足a-b=-1/3，且x^3项系数也匹配，故正确。

**解题切入点**

考查利用泰勒展开比较系数确定参数。类似于算法竞赛中多项式展开系数匹配，将两边展开至同阶，令对应项系数相等。

**推演**

将cot x和$\frac{1+ax^2}{x+bx^3}$分别展开。

已知$\cot x = \frac{1}{x} - \frac{x}{3} - \frac{x^3}{45} + o(x^3)$（或$o(x^5)$，但此处只需到$x^3$项）。

右边：
$$
\frac{1+ax^2}{x+bx^3} = \frac{1}{x}\cdot\frac{1+ax^2}{1+bx^2} = \frac{1}{x}\left[1 + (a-b)x^2 + (b^2-ab)x^4 + \cdots\right] = \frac{1}{x} + (a-b)x + (b^2-ab)x^3 + o(x^3).
$$

比较$x$项系数：$a-b = -\frac{1}{3}$。
比较$x^3$项系数：$b^2-ab = -\frac{1}{45}$。
由后者得$b(b-a) = -\frac{1}{45}$，即$b(a-b) = \frac{1}{45}$，代入$a-b = -\frac{1}{3}$得$b\cdot(-\frac{1}{3}) = \frac{1}{45} \Rightarrow b = -\frac{1}{15}$。
代入$a-b = -\frac{1}{3}$得$a = -\frac{2}{5}$。
故$a = -\frac{2}{5}, b = -\frac{1}{15}$，对应选项(C)。

若考虑$x^5$项，则会产生矛盾，但根据选项，只有(C)满足前两项，故选择(C)。

**易错点**

1. $\cot x$的展开式易记错符号，尤其是$x^3$项系数为$-\frac{1}{45}$。
2. 右边分式展开时，注意分母的$x+bx^3$要写成$x(1+bx^2)$再展开，避免直接除出错。
3. 比较系数时，要确保展开到同阶，且注意余项$o(x^3)$或$o(x^5)$的影响。

**命题规律**

考研数学一常考此类题，通过泰勒展开或洛必达法则比较无穷小阶数确定参数，需要熟练掌握常见函数的展开式。复习时，应多练习展开式系数比较，并注意余项的处理。

注：题面中$o(x^5)$可能应为$o(x^3)$，按比较到$x^3$项理解(OCR疑误，请核对原书)。

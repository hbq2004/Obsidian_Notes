# FRQ 第 1 题

![[_Attachments/题目识别/880-XG/880-XG-C12-T2B4C-Q001_题目.png|题目]]

(1) 设向量组 $\alpha_1 = (1, 1, 1, 2)^T$, $\alpha_2 = (3, a + 4, 2a + 5, a + 7)^T$, $\alpha_3 = (4, 6, 8, 10)^T$, $\alpha_4 = (2, 3, 2a + 3, 5)^T$, $\alpha = (0, 1, 3, b)^T$.

(I) 求向量组 $\alpha_1, \alpha_2, \alpha_3, \alpha_4$ 的秩及其一个极大线性无关组;

(II) 若 $\alpha$ 不能由 $\alpha_1, \alpha_2, \alpha_3, \alpha_4$ 线性表示，求 $a, b$ 的取值.

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C12-T2B4C-Q001_答案.png|答案]]

## V4 Pro Max 解析

**考点**：含参数向量组的秩与极大线性无关组,以及能否线性表示的分类讨论。

**解**

对 $A=(\alpha_1,\alpha_2,\alpha_3,\alpha_4)$ 作行变换(同时处理增广列 $\alpha=(0,1,3,b)^T$):

$$\begin{pmatrix}1&3&4&2&|&0\\1&a+4&6&3&|&1\\1&2a+5&8&2a+3&|&3\\2&a+7&10&5&|&b\end{pmatrix}\xrightarrow{R_2-R_1,R_3-R_1,R_4-2R_1}\begin{pmatrix}1&3&4&2&|&0\\0&a+1&2&1&|&1\\0&2a+2&4&2a+1&|&3\\0&a+1&2&1&|&b\end{pmatrix}$$

$$\xrightarrow{R_3-2R_2,R_4-R_2}\begin{pmatrix}1&3&4&2&|&0\\0&a+1&2&1&|&1\\0&0&0&2a-1&|&1\\0&0&0&0&|&b-1\end{pmatrix}.$$

(I) 当 $a\ne\dfrac12$ 时,$r(A)=3$,主元列 1、2、4,极大线性无关组可取 $\{\alpha_1,\alpha_2,\alpha_4\}$($a=-1$ 时 $\alpha_2=3\alpha_1$,应取 $\{\alpha_1,\alpha_3,\alpha_4\}$);当 $a=\dfrac12$ 时第 3 行全零,$r(A)=2$,极大线性无关组为 $\{\alpha_1,\alpha_2\}$。

(II) $\alpha$ 可表示 $\iff$ 增广矩阵无矛盾行 $\iff b-1=0$ 且 $2a-1\ne 0$。故 $\alpha$ **不能**由 $\alpha_1,\alpha_2,\alpha_3,\alpha_4$ 线性表示 $\iff b\ne 1$ 或 $a=\dfrac12$。

**答案**：(I) $a\ne\frac12$ 时 $r=3$,极大线性无关组 $\{\alpha_1,\alpha_2,\alpha_4\}$($a=-1$ 时取 $\{\alpha_1,\alpha_3,\alpha_4\}$);$a=\frac12$ 时 $r=2$,极大线性无关组 $\{\alpha_1,\alpha_2\}$。(II) $\alpha$ 不能表示 $\iff b\ne 1$ 或 $a=\dfrac12$。

**易错点**：行变换要细心($R_3-R_1$ 的第三列是 $2a+2$,不是 $2a+4$);$a=\frac12$ 时出现矛盾行 $(0,0,0,0\,|\,1)$,与 $b$ 无关,永远不可表示。

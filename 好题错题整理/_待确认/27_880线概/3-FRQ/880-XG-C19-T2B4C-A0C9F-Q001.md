# FRQ 第 1 题

![[_Attachments/题目识别/880-XG/880-XG-C19-T2B4C-A0C9F-Q001_题目.png|题目]]

(1) 在区间 (0,1) 内随机取 n 个数 $X_1, X_2, \cdots, X_n$．

(I) 求最大数与最小数之间距离 d 的数学期望；

(II) 若用 Y 表示 n 个数中大于 $\frac{2}{3}$ 的个数，求 EY 和 DY．

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C19-T2B4C-A0C9F-Q001_答案.png|答案]]

## V4 Pro Max 解析

**考点**：利用次序统计量(最大值、最小值)的分布求期望,并利用二项分布求期望与方差。

**解**
(I) 记 $M=\max\{X_1,\cdots,X_n\}$，$m=\min\{X_1,\cdots,X_n\}$，则 $d=M-m$。

$X_i\sim U(0,1)$ 独立。最大值的分布函数
$$F_M(x)=P\{M\le x\}=\prod_{i=1}^{n}P\{X_i\le x\}=x^n,\quad 0<x<1,$$
故密度 $f_M(x)=n x^{n-1}$，从而
$$EM=\int_0^1 x\cdot n x^{n-1}\,dx=\frac{n}{n+1}.$$

最小值的分布:$P\{m>x\}=\prod_{i=1}^{n}P\{X_i>x\}=(1-x)^n$，密度 $f_m(x)=n(1-x)^{n-1}$，于是
$$Em=\int_0^1 x\cdot n(1-x)^{n-1}\,dx=\frac{1}{n+1}.$$

因此
$$Ed=E(M-m)=EM-Em=\frac{n}{n+1}-\frac{1}{n+1}=\boxed{\frac{n-1}{n+1}}.$$

(II) 每个 $X_i$ 大于 $\frac23$ 的概率为 $p=P\{X>\frac23\}=\frac13$，且各次独立，故 $Y\sim B(n,\frac13)$，从而
$$EY=np=\boxed{\frac{n}{3}},\qquad DY=np(1-p)=n\cdot\frac13\cdot\frac23=\boxed{\frac{2n}{9}}.$$

**答案**：(I) $Ed=\dfrac{n-1}{n+1}$；(II) $EY=\dfrac n3$，$DY=\dfrac{2n}{9}$。

**易错点**：求最大值期望时直接对分布函数求导得密度再积分,不要误用 $E M=\int_0^1 P\{M>t\}dt$ 后忘记 $\frac{1}{n+1}$ 的符号；$Y$ 是独立重复试验中的成功次数,服从二项分布,不能当超几何处理。

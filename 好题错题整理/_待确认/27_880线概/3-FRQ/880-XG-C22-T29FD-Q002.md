# FRQ 第 2 题

![[_Attachments/题目识别/880-XG/880-XG-C22-T29FD-Q002_题目.png|题目]]

(2) 设总体 $X$ 的概率密度为 $f(x; \lambda) = \begin{cases} -\lambda^x \ln \lambda, & x \geq 0, \\ 0, & x < 0 \end{cases} (0 < \lambda < 1)$，$(X_1, X_2, \cdots, X_n)$ 为总体 $X$ 的简单随机样本，求 $\lambda$ 的矩估计量.

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C22-T29FD-Q002_答案.png|答案]]

## V4 Pro Max 解析

**考点**：连续型"类几何分布"密度 $f(x)=-\lambda^x\ln\lambda$ 的矩估计。

**解**
先验证归一化:对 $0<\lambda<1$,$\ln\lambda<0$,且
$$\int_0^{+\infty}-\lambda^x\ln\lambda\,dx=-\ln\lambda\int_0^{+\infty}e^{x\ln\lambda}dx=-\ln\lambda\cdot\frac1{-\ln\lambda}=1,$$
故 $f(x)=-\lambda^x\ln\lambda\,(x\ge0)$ 确为密度。

总体一阶矩(令 $a=-\ln\lambda>0$,则 $\lambda^x=e^{-ax}$):
$$EX=\int_0^{+\infty}x\cdot(-\lambda^x\ln\lambda)dx=\int_0^{+\infty}x\cdot ae^{-ax}dx=\frac1a=\frac1{-\ln\lambda}.$$
矩估计:令 $\frac1{-\ln\hat\lambda}=\overline X$,即 $-\ln\hat\lambda=\frac1{\overline X}$,解得
$$\boxed{\hat\lambda=e^{-1/\overline X}}.$$

**答案**：$\hat\lambda=e^{-1/\overline X}$,其中 $\overline X=\frac1n\sum_{i=1}^nX_i$。

**易错点**：这是连续型密度而非离散分布,积分归一化验证不能省;$EX=1/(-\ln\lambda)$ 要用 $\int_0^\infty x e^{-ax}dx=\frac1{a^2}$ 计算。

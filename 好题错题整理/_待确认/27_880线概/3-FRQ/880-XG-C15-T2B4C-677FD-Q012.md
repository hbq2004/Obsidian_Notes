(12) 设二次型 $f(x_1, x_2, x_3) = 2(x_1^2 + x_2^2 + x_3^2) + 2a(x_1x_2 + x_1x_3 + x_2x_3)$，$a$ 为正整数。

(I) 求正交变换 $X = QY$，将 $f(x_1, x_2, x_3)$ 化为标准形；

(II) 若存在可逆矩阵 $P$，对任意 $X = (x_1, x_2, x_3)^T$，有 $f(x_1, x_2, x_3) = \|PX\|^2$。求 $a$ 的值及 $P$.

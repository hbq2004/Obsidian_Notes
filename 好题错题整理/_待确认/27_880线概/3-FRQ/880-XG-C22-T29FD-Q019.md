(19) 设随机变量 $X$ 与 $Y$ 相互独立, $X \sim N\left(0, \sigma^{2}\right)\left(\sigma > 0\right), Y$ 的分布律为 $P\{Y = -1\} = P\{Y = 1\} = \frac{1}{2}$，记 $Z = XY, Z_{1}, Z_{2}, \cdots, Z_{n}$ 为来自总体 $Z$ 的简单随机样本.

(I) 求 $Z$ 的概率密度 $f_{Z}(z)$;

(II) 求 $\sigma^{2}$ 的最大似然估计量 $\sigma^{2}$;

(III) 若 $U = \sum\limits_{i=1}^{n} a_{i} Z_{i}$，其中 $a_{i} \geqslant 0, \sum\limits_{i=1}^{n} a_{i} = 1$，求 $DU$ 的最小值.

# FRQ 第 1 题

![[_Attachments/题目识别/880-XG/880-XG-C14-T2B4C-2FE63-Q001_题目.png|题目]]

(1) 已知 $A = (\alpha_1, \alpha_2, \alpha_3)$ 是 3 阶可逆矩阵，$B$ 是 3 阶矩阵，且 $BA = (\alpha_1, -4\alpha_3, -\alpha_2)$. 求：

(I) $B$ 的全部特征值；

(II) 可逆矩阵 $P$ 和对角矩阵 $\Lambda$，使得 $P^{-1}BP = \Lambda$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C14-T2B4C-2FE63-Q001_答案.png|答案]]

## V4 Pro Max 解析

**考点**：由列分块矩阵的等式 $BA=(A$ 施以初等列变换$)$ 反推出 $B$ 与对角矩阵的相似关系，再求特征值与相似对角化。

**解**

由 $BA=(\alpha_1,-4\alpha_3,-\alpha_2)=A\cdot\begin{pmatrix}1&0&0\\0&0&-1\\0&-4&0\end{pmatrix}$。

记 $\Lambda_0=\begin{pmatrix}1&0&0\\0&0&-1\\0&-4&0\end{pmatrix}$，因 $A$ 可逆，有

$$B=A\Lambda_0 A^{-1}\ \Longrightarrow\ B\sim\Lambda_0.$$

(I) 求 $\Lambda_0$ 的特征值：

$$|\lambda E-\Lambda_0|=\begin{vmatrix}\lambda-1&0&0\\0&\lambda&1\\0&4&\lambda\end{vmatrix}=(\lambda-1)\cdot(\lambda^2-4)=(\lambda-1)(\lambda-2)(\lambda+2).$$

故 $B$ 的全部特征值为 $\lambda_1=1,\ \lambda_2=2,\ \lambda_3=-2$（三个互异特征值，$B$ 可相似对角化）。

(II) 求 $\Lambda_0$ 的特征向量：

- $\lambda=1$：$(\Lambda_0-E)=\begin{pmatrix}0&0&0\\0&-1&1\\0&-4&1\end{pmatrix}$，$x$ 自由，$-y+z=0$，取 $\xi_1=(1,0,0)^T$；
- $\lambda=2$：$(\Lambda_0-2E)=\begin{pmatrix}-1&0&0\\0&-2&1\\0&-4&2\end{pmatrix}$，$x=0,\ -2y+z=0$，取 $\xi_2=(0,1,2)^T$；
- $\lambda=-2$：$(\Lambda_0+2E)=\begin{pmatrix}3&0&0\\0&2&1\\0&4&2\end{pmatrix}$，$x=0,\ 2y+z=0$，取 $\xi_3=(0,1,-2)^T$。

令 $Q=(\xi_1,\xi_2,\xi_3)=\begin{pmatrix}1&0&0\\0&1&1\\0&2&-2\end{pmatrix}$，则 $Q^{-1}\Lambda_0 Q=\operatorname{diag}(1,2,-2)$。

于是取 $P=AQ$（可逆，因为 $A,Q$ 均可逆），即

$$P^{-1}BP=Q^{-1}(A^{-1}BA)Q=Q^{-1}\Lambda_0Q=\Lambda=\operatorname{diag}(1,2,-2).$$

**答案**：(I) $B$ 的特征值为 $1,2,-2$；
(II) $P=A\begin{pmatrix}1&0&0\\0&1&1\\0&2&-2\end{pmatrix}$（即以 $A$ 乘以 $\xi_1,\xi_2,\xi_3$ 为列的矩阵），$\Lambda=\operatorname{diag}(1,2,-2)$。

**易错点**：先把 $BA$ 的列变换写成右乘矩阵 $\Lambda_0$ 是本题关键；注意 $B=A\Lambda_0A^{-1}$ 说明 $B\sim\Lambda_0$，特征值由 $\Lambda_0$ 决定，不必展开 $B$ 的表达式。$P$ 取 $AQ$ 而非 $Q$。

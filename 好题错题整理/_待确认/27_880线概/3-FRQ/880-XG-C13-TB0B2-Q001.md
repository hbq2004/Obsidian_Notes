# FRQ 第 1 题

![[_Attachments/题目识别/880-XG/880-XG-C13-TB0B2-Q001_题目.png|题目]]

(1) 设 $A$ 是 $5 \times 4$ 矩阵，$r(A) = 2$，已知 $\alpha_1, \alpha_2, \alpha_3$ 是非齐次线性方程组 $Ax = b$ 的三个解向量，且 $\alpha_1 + \alpha_2 = (4, 6, -8, 4)^T$，$\alpha_3 = (1, 2, -1, 1)^T$，又 $(0, 1, -3, 0)^T$ 是 $Ax = 0$ 的解，求 $Ax = b$ 的通解.

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C13-TB0B2-Q001_答案.png|答案]]

## V4 Pro Max 解析

**考点**：由已知解向量的线性组合构造特解与齐次解，按解空间维数写通解。

**解**

$r(A)=2$，$A$ 为 $5\times4$，故 $Ax=0$ 的基础解系含 $4-2=2$ 个解向量。

$\alpha_1,\alpha_2,\alpha_3$ 都是 $Ax=b$ 的解，故 $A(\alpha_1+\alpha_2)=2b$，$\dfrac{\alpha_1+\alpha_2}{2}$ 是特解：

$$\frac{\alpha_1+\alpha_2}{2}=\frac{(4,6,-8,4)^T}{2}=(2,3,-4,2)^T.$$

两个特解之差是齐次解：

$$\alpha_3-\frac{\alpha_1+\alpha_2}{2}=(1,2,-1,1)^T-(2,3,-4,2)^T=(-1,-1,3,-1)^T.$$

又已知 $(0,1,-3,0)^T$ 是 $Ax=0$ 的解，且与 $(-1,-1,3,-1)^T$ 不成比例，线性无关，构成基础解系（恰 2 个，与 $r(A)=2$ 吻合）。

取特解 $\alpha_3=(1,2,-1,1)^T$，通解为

$$x=\alpha_3+k_1(-1,-1,3,-1)^T+k_2(0,1,-3,0)^T,\quad k_1,k_2\in\mathbb R.$$

验证：$A[\alpha_3+k_1\eta_1+k_2\eta_2]=b+0+0=b$ ✓。

**答案**：$x=(1,2,-1,1)^T+k_1(-1,-1,3,-1)^T+k_2(0,1,-3,0)^T$（$k_1,k_2$ 为任意常数）。

**易错点**：$\alpha_1+\alpha_2$ 本身不是解（$A(\alpha_1+\alpha_2)=2b$），必须除以 2 才作特解；齐次解个数要与 $n-r(A)=2$ 一致，两个齐次解须验证线性无关。

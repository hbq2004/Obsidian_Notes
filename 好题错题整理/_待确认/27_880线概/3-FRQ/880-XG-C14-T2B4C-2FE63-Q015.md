# FRQ 第 15 题

![[_Attachments/题目识别/880-XG/880-XG-C14-T2B4C-2FE63-Q015_题目.png|题目]]

$【例 3】$

设向量 $\beta = (b, 1, 1)^T$ 可由 $\alpha_1 = (a, 0, 1)^T, \alpha_2 = (1, a-1, 1)^T, \alpha_3 = (1, 0, a)^T$ 线性表示，且表示法不唯一。记 $A = (\alpha_1, \alpha_2, \alpha_3)$。求：

(I) $a, b$ 的值，并写出 $\beta$ 由 $\alpha_1, \alpha_2, \alpha_3$ 表示的线性表达式；

(II) 一个可逆矩阵 $P$，使得 $P^{-1}AP = \Lambda$（$\Lambda$ 为对角矩阵）.

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C14-T2B4C-2FE63-Q015_答案.png|答案]]

## V4 Pro Max 解析

**考点**：线性表示不唯一 $\iff r(A)=r(A|\beta)<3$，先定参数再写通式；后对 $A$ 求特征向量做相似对角化。

**解**

(I) 表示法不唯一 $\iff r(A)=r(A|\beta)<3$。

$$\det A=\begin{vmatrix}a&1&1\\0&a-1&0\\1&1&a\end{vmatrix}=(a-1)(a^2-1)=(a-1)^2(a+1).$$

由 $r(A)<3$ 得 $a=1$ 或 $a=-1$。

- $a=1$：$A=\begin{pmatrix}1&1&1\\0&0&0\\1&1&1\end{pmatrix}$，增广阵第 2 行为 $(0,0,0,1)$，矛盾，无解 ✗；
- $a=-1$：$A=\begin{pmatrix}-1&1&1\\0&-2&0\\1&1&-1\end{pmatrix}$，$r(A)=2$。增广阵行变换：由第 2 行 $-2y=1\Rightarrow y=-\frac12$；第 1 行 $-x+y+z=b$，第 3 行 $x+y-z=1$，两式相加得 $2y=b+1\Rightarrow -1=b+1\Rightarrow b=-2$ ✓ 相容。

故 $a=-1,\ b=-2$。通解：令 $x=t$，由 $-x+y+z=-2$ 得 $z=x-\frac32$，故

$$\beta=t\alpha_1-\frac12\alpha_2+\big(t-\frac32\big)\alpha_3,\quad t\ \text{任意}.$$

（验证第三分量：$x+y-z=t-\frac12-t+\frac32=1$ ✓）

(II) $a=-1$ 时 $A=\begin{pmatrix}-1&1&1\\0&-2&0\\1&1&-1\end{pmatrix}$。特征多项式

$$|\lambda E-A|=(\lambda+2)\big((\lambda+1)^2-1\big)=\lambda(\lambda+2)^2,$$

特征值 $0,-2,-2$。特征向量：

$$\lambda=0:\ (A-0E)x=0\Rightarrow -x+y+z=0,\ y=0,\ x-y+z=0\Rightarrow \xi_1=(1,0,1)^T;$$

$$\lambda=-2:\ (A+2E)x=0\Rightarrow x+y+z=0\Rightarrow \xi_2=(1,-1,0)^T,\ \xi_3=(1,0,-1)^T.$$

取 $P=(\xi_1,\xi_2,\xi_3)=\begin{pmatrix}1&1&1\\0&-1&0\\1&0&-1\end{pmatrix}$（$\det P=2\ne0$ ✓），则

$$P^{-1}AP=\Lambda=\operatorname{diag}(0,-2,-2).$$

**答案**：(I) $a=-1,\ b=-2$，$\beta=t\alpha_1-\frac12\alpha_2+(t-\frac32)\alpha_3$（$t$ 任意）；
(II) $P=\begin{pmatrix}1&1&1\\0&-1&0\\1&0&-1\end{pmatrix}$，$\Lambda=\operatorname{diag}(0,-2,-2)$。

**易错点**："表示法不唯一"= 增广矩阵相容且 $r(A)<3$，$a=1$ 时不满足相容性要排除；$b$ 由相容性（第 1、3 行相加消去 $x,z$）唯一确定；$\lambda=-2$ 为二重特征值，需找两个线性无关特征向量验证可对角化。

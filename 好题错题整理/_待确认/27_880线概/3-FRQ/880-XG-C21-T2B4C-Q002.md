# FRQ 第 2 题

![[_Attachments/题目识别/880-XG/880-XG-C21-T2B4C-Q002_题目.png|题目]]

(2) 设总体 $X \sim N(0, \sigma^2)$，$(X_1, X_2, \cdots, X_{10})$ 为 $X$ 的简单随机样本，求下列统计量的分布。

(I) $T_1 = \frac{7}{3} \cdot \frac{(X_1 + X_2 + X_3)^2}{X_4^2 + \cdots + X_{10}^2}$；

(II) $T_2 = \sqrt{\frac{7}{3}} \cdot \frac{X_1 + X_2 + X_3}{\sqrt{X_4^2 + \cdots + X_{10}^2}}$；

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C21-T2B4C-Q002_答案.png|答案]]

## V4 Pro Max 解析

**考点**：正态样本的线性组合标准化后构造 $F$ 与 $t$ 统计量。

**解**

$X_i$ 独立同分布 $N(0,\sigma^2)$。$X_1+X_2+X_3\sim N(0,3\sigma^2)$，故 $\dfrac{X_1+X_2+X_3}{\sqrt3\,\sigma}\sim N(0,1)$，其平方 $\dfrac{(X_1+X_2+X_3)^2}{3\sigma^2}\sim\chi^2(1)$。

又 $\dfrac{X_4^2+\cdots+X_{10}^2}{\sigma^2}\sim\chi^2(7)$，且与分子独立。

(I)

$$T_1=\frac73\cdot\frac{(X_1+X_2+X_3)^2}{X_4^2+\cdots+X_{10}^2}=\frac{\dfrac{(X_1+X_2+X_3)^2}{3\sigma^2}\Big/1}{\dfrac{X_4^2+\cdots+X_{10}^2}{\sigma^2}\Big/7}\sim F(1,7).$$

(II)

$$T_2=\sqrt{\frac73}\cdot\frac{X_1+X_2+X_3}{\sqrt{X_4^2+\cdots+X_{10}^2}}=\frac{\dfrac{X_1+X_2+X_3}{\sqrt3\,\sigma}}{\sqrt{\dfrac{X_4^2+\cdots+X_{10}^2}{7\sigma^2}}}\sim t(7).$$

**答案**：(I) $T_1\sim F(1,7)$；(II) $T_2\sim t(7)$。

**易错点**：$F$ 与 $t$ 的关系：分子标准化平方和的自由度 1，分母平方和自由度 7；$T_1=\frac73\cdot(\cdots)$ 中的系数 $\frac73$ 恰把"$\chi^2/自由度$"之比凑成标准形式，$\sigma^2$ 在约分中消去。

# FIB 第 3 题

![[_Attachments/题目识别/880-XG/880-XG-C10-TC67C-27878-Q003_题目.png|题目]]

(3)设 $A$ 是 3 阶方阵，且满足 $|A-E| = |A+2E| = |2A+3E| = 0$，则 $|2A^* - 3E| = \＿$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C10-TC67C-27878-Q003_答案.png|答案]]

## V4 Pro Max 解析

**考点**：$|A + cE| = 0$ 给出特征值;伴随矩阵特征值为 $|A|/\lambda_i$;再求 $|2A^* - 3E|$。

**解**
由 $|A - E| = 0$、$|A + 2E| = 0$、$|2A + 3E| = 0$ 得 $A$ 的三个特征值:
$$\lambda_1 = 1,\qquad \lambda_2 = -2,\qquad \lambda_3 = -\frac{3}{2}.$$
$$|A| = 1\cdot(-2)\cdot\left(-\frac32\right) = 3.$$

$A^* = |A|A^{-1}$ 的特征值为 $\dfrac{|A|}{\lambda_i}$:
$$\mu_1 = \frac{3}{1} = 3,\qquad \mu_2 = \frac{3}{-2} = -\frac{3}{2},\qquad \mu_3 = \frac{3}{-3/2} = -2.$$

$2A^* - 3E$ 的特征值为 $2\mu_i - 3$:
$$2\cdot3 - 3 = 3,\qquad 2\cdot\left(-\frac32\right) - 3 = -6,\qquad 2\cdot(-2) - 3 = -7,$$
$$|2A^* - 3E| = 3\cdot(-6)\cdot(-7) = 126.$$

**答案**：$126$.

**易错点**：$|2A + 3E| = 0$ 对应特征值 $-\dfrac32$(由 $2\lambda + 3 = 0$),不是 $-3$;伴随的特征值是 $|A|$ 除以原特征值,取倒数方向不要反。

# FIB 第 3 题

![[_Attachments/题目识别/880-XG/880-XG-C12-TC67C-Q003_题目.png|题目]]

(3) 设 3 维向量空间的两组基分别为 $\alpha_1 = (1, 2, 3)^T$, $\alpha_2 = (2, 3, 1)^T$, $\alpha_3 = (3, 1, 2)^T$; $\beta_1 = (-1, -1, 2)^T$, $\beta_2 = (-1, 2, -1)^T$, $\beta_3 = (3, 1, 2)^T$, 则从 $\alpha_1$, $\alpha_2$, $\alpha_3$ 到 $\beta_1$, $\beta_2$, $\beta_3$ 的过渡矩阵为 \_.

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C12-TC67C-Q003_答案.png|答案]]

## V4 Pro Max 解析

**考点**：过渡矩阵的计算:$(\beta)=(\alpha)P\Rightarrow P=A^{-1}B$。

**解**

记 $A=(\alpha_1,\alpha_2,\alpha_3)$,$B=(\beta_1,\beta_2,\beta_3)$。由基 $\{\alpha\}$ 到基 $\{\beta\}$ 的过渡矩阵 $P$ 满足 $(\beta_1,\beta_2,\beta_3)=(\alpha_1,\alpha_2,\alpha_3)P$,故 $P=A^{-1}B$。

$$\det A=\det\begin{pmatrix}1&2&3\\2&3&1\\3&1&2\end{pmatrix}=1\cdot(6-1)-2\cdot(4-3)+3\cdot(2-9)=5-2-21=-18,$$

$$A^{-1}=\frac1{-18}\begin{pmatrix}5&-1&-7\\-1&-7&5\\-7&5&-1\end{pmatrix},\qquad B=\begin{pmatrix}-1&-1&3\\-1&2&1\\2&-1&2\end{pmatrix},$$

$$P=\frac1{-18}\begin{pmatrix}5&-1&-7\\-1&-7&5\\-7&5&-1\end{pmatrix}\begin{pmatrix}-1&-1&3\\-1&2&1\\2&-1&2\end{pmatrix}=\frac1{-18}\begin{pmatrix}-18&0&0\\18&-18&0\\0&18&-18\end{pmatrix}=\begin{pmatrix}1&0&0\\-1&1&0\\0&-1&1\end{pmatrix}.$$

验证:$\beta_1=\alpha_1-\alpha_2=(1,2,3)^T-(2,3,1)^T=(-1,-1,2)^T$ ✓;$\beta_2=\alpha_2-\alpha_3=(-1,2,-1)^T$ ✓;$\beta_3=\alpha_3=(3,1,2)^T$ ✓。

**答案**：$P=\begin{pmatrix}1&0&0\\-1&1&0\\0&-1&1\end{pmatrix}$。

**易错点**：过渡矩阵是 $P=A^{-1}B$(不是 $AB^{-1}$);求出后可用 $(\beta)=(\alpha)P$ 的列组合关系快速验证。

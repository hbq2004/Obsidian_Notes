# MCQ 第 1 题

![[_Attachments/题目识别/880-XG/880-XG-C10-T68FF-F55DD-Q001_题目.png|题目]]

(1) 设 $A$ 是 3 阶可逆矩阵，$A^{-1}$ 的特征值为 3, 2, 1，则 $|A|$ 的代数余子式之和 $A_{11} + A_{22} + A_{33} =$ ( ).

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C10-T68FF-F55DD-Q001_答案.png|答案]]

## V4 Pro Max 解析

**考点**：代数余子式之和 $A_{11}+A_{22}+A_{33} = \mathrm{tr}(A^*)$,结合逆矩阵与特征值的关系。

**解**
$A^{-1}$ 的特征值为 $3, 2, 1$,故 $A$ 的特征值为它们的倒数:
$$\frac{1}{3},\quad \frac{1}{2},\quad 1,$$
$$|A| = \frac{1}{3}\cdot\frac{1}{2}\cdot1 = \frac{1}{6}.$$

伴随矩阵 $A^* = |A|A^{-1}$,故 $A^*$ 的特征值为 $|A|$ 乘 $A^{-1}$ 的特征值:
$$\frac{1}{6}\cdot3 = \frac{1}{2},\qquad \frac{1}{6}\cdot2 = \frac{1}{3},\qquad \frac{1}{6}\cdot1 = \frac{1}{6}.$$

$\mathrm{tr}(A^*)$ 等于特征值之和,又 $\mathrm{tr}(A^*) = A_{11} + A_{22} + A_{33}$,所以
$$A_{11} + A_{22} + A_{33} = \frac{1}{2} + \frac{1}{3} + \frac{1}{6} = 1.$$

**答案**：$A_{11} + A_{22} + A_{33} = 1$.

**易错点**：$A^*$ 的特征值是 $|A|$ 除以 $A$ 的特征值(即 $|A|$ 乘 $A^{-1}$ 的特征值),不要把 $A^*$ 的特征值当成 $A$ 的特征值;$\mathrm{tr}(A^*)$ 正是代数余子式对角元之和。

# MCQ 第 4 题

![[_Attachments/题目识别/880-XG/880-XG-C13-T68FF-Q004_题目.png|题目]]

(4) 设方程组 $\left\{\begin{array}{l} \lambda x_{1} + x_{2} + \lambda^{2} x_{3} = 0, \\ x_{1} + \lambda x_{2} + x_{3} = 0, \\ x_{1} + x_{2} + \lambda x_{3} = 0 \end{array}\right.$ 的系数矩阵为 $A$，若存在 3 阶矩阵 $B \neq 0$，使得 $AB = 0$，则必有 ( ).

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C13-T68FF-Q004_答案.png|答案]]

## V4 Pro Max 解析

**考点**：存在非零 $B$ 使 $AB=0$ 等价于齐次方程组 $AX=0$ 有非零解，由行列式定参数。

**解**

存在 3 阶矩阵 $B\ne0$ 使得 $AB=0$ $\Longleftrightarrow$ 齐次线性方程组 $AX=0$ 有非零解（取 $B$ 的某一非零列即为非零解向量；反之若 $AX=0$ 有非零解 $\eta$，取 $B=(\eta,0,0)\ne0$ 即得 $AB=0$）。

故 $AX=0$ 有非零解 $\Longleftrightarrow |A|=0$。系数矩阵

$$A=\begin{pmatrix}\lambda&1&\lambda^2\\1&\lambda&1\\1&1&\lambda\end{pmatrix},$$

$$|A|=\lambda(\lambda^2-1)-(\lambda-1)+\lambda^2(1-\lambda)=\lambda^3-\lambda-\lambda+1+\lambda^2-\lambda^3=\lambda^2-2\lambda+1=(\lambda-1)^2.$$

故 $|A|=0\Longleftrightarrow\lambda=1$。

**题目文字说明**：本题 OCR 文本只保留到"则必有 ( )."，选项缺失。若选项形如"$\lambda=1$"、"$A$ 不可逆"、"$AX=0$ 有非零解"等，正确答案即与之等价的条件 $\lambda=1$。

**答案**：$\lambda=1$（即 $|A|=(\lambda-1)^2=0$，$AX=0$ 有非零解）。

**易错点**：$AB=0$ 且 $B\ne0$ 的充要条件是 $A$ 的列向量组线性相关（$AX=0$ 有非零解）；题目选项缺失属 OCR 问题，按推导结论作答。

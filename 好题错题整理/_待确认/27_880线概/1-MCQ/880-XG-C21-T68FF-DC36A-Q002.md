# MCQ 第 2 题

![[_Attachments/题目识别/880-XG/880-XG-C21-T68FF-DC36A-Q002_题目.png|题目]]

(2) 设总体 $X \sim N(0, \sigma^2)$ ($\sigma > 0$)，$X_1, X_2, \cdots, X_n$ ($n > 1$) 为来自总体 $X$ 的简单随机样本，$\overline{X}$ 为样本均值，$S^2$ 为样本方差，则下列选项中错误的是()。

A. $\frac{\sqrt{nX}}{S} \sim t(n-1)$

B. $\frac{n\overline{X}^2}{\sigma^2} + \frac{(n-1)S^2}{\sigma^2} \sim \chi^2(n)$

C. $\frac{n\overline{X}^2}{S^2} \sim F(1, n-1)$

D. $\frac{X_i^2}{\sigma^2} + \frac{(n-1)S^2}{\sigma^2} \sim \chi^2(n)$

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C21-T68FF-DC36A-Q002_答案.png|答案]]

## V4 Pro Max 解析

**考点**：正态总体 $t$、$\chi^2$、$F$ 抽样分布结论的辨析，找出错误选项。

**解**

$X_i$ 独立同分布 $N(0,\sigma^2)$。已知 $\overline{X}\sim N(0,\frac{\sigma^2}{n})$，$\dfrac{n\overline{X}^2}{\sigma^2}\sim\chi^2(1)$，$\dfrac{(n-1)S^2}{\sigma^2}\sim\chi^2(n-1)$，且 $\overline{X}$ 与 $S^2$ 独立。

A：$\dfrac{\sqrt n\,\overline{X}}{S}\sim t(n-1)$——这正是 $t$ 统计量的定义式（$S$ 为样本标准差），正确。（题面"$\sqrt{nX}$"视为 $\sqrt n\,\overline{X}$ 之 OCR 误。）

B：$n\overline{X}^2/\sigma^2\sim\chi^2(1)$ 与 $(n-1)S^2/\sigma^2\sim\chi^2(n-1)$ 独立，独立 $\chi^2$ 之和仍为 $\chi^2$，自由度相加：$\sim\chi^2(n)$，正确。

C：$\dfrac{n\overline{X}^2}{S^2}=\dfrac{\chi^2(1)/1}{\chi^2(n-1)/(n-1)}\sim F(1,n-1)$，正确。

D：$X_i^2/\sigma^2\sim\chi^2(1)$，但 $X_i$ 与 $S^2$ **不独立**（$X_i$ 是样本的一员，参与 $S^2$ 的计算），独立 $\chi^2$ 之和的结论不成立，$X_i^2/\sigma^2+(n-1)S^2/\sigma^2$ 一般**不**服从 $\chi^2(n)$，错误。

**答案**：D。

**易错点**：$\chi^2$ 可加性要求"独立"；$X_i$ 与 $S^2$ 相关是本题陷阱——只有 $\overline{X}$ 与 $S^2$ 独立（正态总体的经典结论），单个 $X_i$ 不行。

# MCQ 第 2 题

![[_Attachments/题目识别/880-XG/880-XG-C16-T68FF-Q002_题目.png|题目]]

(2) 对任意两个事件 $A$ 和 $B$，若 $P(AB) = 0$，则()。

A. $P(A)P(B) = 0$ B. $P(A-B) = P(A)$ C. $\overline{AB} = \emptyset$ D. $AB = \emptyset$

```$latex
\begin{option}
    A.  P(A)P(B) = 0
    B.  P(A-B) = P(A)
    C.  \overline{AB} = \emptyset
    D.  AB = \emptyset
\end{option}$
```

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C16-T68FF-Q002_答案.png|答案]]

## V4 Pro Max 解析

**考点**：$P(AB)=0$ 的含义与零概率事件的性质。

**解**
$P(AB)=0$ 只说明 $AB$ 是零概率事件,并不意味 $AB=\varnothing$。利用 $A=(A-B)\cup AB$ 且两项互不相容:
$$P(A)=P(A-B)+P(AB)=P(A-B)+0,$$
即 $P(A-B)=P(A)$,故 B 正确。

干扰项分析:A 选项,$P(AB)=0$ 推不出 $P(A)P(B)=0$(如 $A,B$ 独立且 $P(A)=P(B)=\dfrac12$ 时 $P(AB)=0$ 与独立矛盾,反例取连续型均匀变量上的区间 $A=[0,1],\ B=[2,3]$,则 $P(AB)=0$ 而 $P(A)P(B)>0$);C 选项 $\overline{AB}=\varnothing$ 意味着 $AB=\Omega$,错误;D 选项 $P(AB)=0$ 推不出 $AB=\varnothing$(单点事件概率为 0 但非空)。

**答案**：B。

**易错点**："概率为 0"与"事件为空集"是两个不同概念;对连续型随机变量,单点事件概率为 0 但事件本身非空。

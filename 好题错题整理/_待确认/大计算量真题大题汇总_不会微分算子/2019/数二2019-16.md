# 数二2019-16 2019年真题

![[_Attachments/题目识别/大计算量真题大题汇总_不会微分算子-题目/数二2019-16_题目.png|题目]]

数二 19-16. (本题满分 10 分)
求不定积分 $\int \frac{3x+6}{(x-1)^2(x^2+x+1)} dx.$

---

## 答案

**答案**：
\[
\int \frac{3x+6}{(x-1)^2(x^2+x+1)}\,dx
=
-2\ln|x-1|-\frac{3}{x-1}+\ln(x^2+x+1)+C.
\]

**解题切入点**：
分母已经因式分解为一次因式的平方 $(x-1)^2$ 与不可约二次因式 $x^2+x+1$。这是标准的有理函数积分，核心方法是**部分分式分解**。拿到题目不要盲目换元，先把复杂分式拆成若干个简单分式之和；可以类比算法中的“分治思想”：按分母因子拆成小模块，每个小模块都有固定的积分公式。

**推演**：

设
\[
\frac{3x+6}{(x-1)^2(x^2+x+1)}
=
\frac{A}{x-1}
+
\frac{B}{(x-1)^2}
+
\frac{Cx+D}{x^2+x+1}.
\]

因为 $x^2+x+1$ 的判别式
\[
\Delta=1^2-4<0,
\]
所以它在实数范围内不可再分解，二次因子对应的分子应设为一次式 $Cx+D$。

去分母，得
\[
3x+6
=
A(x-1)(x^2+x+1)
+
B(x^2+x+1)
+
(Cx+D)(x-1)^2.
\]

注意到
\[
(x-1)(x^2+x+1)=x^3-1,
\]
且
\[
(Cx+D)(x-1)^2
=
C(x^3-2x^2+x)+D(x^2-2x+1).
\]

于是
\[
3x+6
=
(A+C)x^3
+
(B-2C+D)x^2
+
(B+C-2D)x
+
(-A+B+D).
\]

比较系数，得
\[
\begin{cases}
A+C=0,\\
B-2C+D=0,\\
B+C-2D=3,\\
-A+B+D=6.
\end{cases}
\]

解得
\[
A=-2,\qquad B=3,\qquad C=2,\qquad D=1.
\]

因此
\[
\frac{3x+6}{(x-1)^2(x^2+x+1)}
=
-\frac{2}{x-1}
+
\frac{3}{(x-1)^2}
+
\frac{2x+1}{x^2+x+1}.
\]

逐项积分：

\[
\int \frac{3x+6}{(x-1)^2(x^2+x+1)}\,dx
=
-2\int \frac{dx}{x-1}
+
3\int \frac{dx}{(x-1)^2}
+
\int \frac{2x+1}{x^2+x+1}\,dx.
\]

其中
\[
\int \frac{dx}{x-1}=\ln|x-1|+C,
\]
\[
\int \frac{dx}{(x-1)^2}=-\frac{1}{x-1}+C,
\]
且
\[
\frac{d}{dx}(x^2+x+1)=2x+1,
\]
所以
\[
\int \frac{2x+1}{x^2+x+1}\,dx
=
\ln(x^2+x+1)+C,
\]
这里 $x^2+x+1>0$ 恒成立，因此可不加绝对值。

故
\[
\int \frac{3x+6}{(x-1)^2(x^2+x+1)}\,dx
=
-2\ln|x-1|
-
\frac{3}{x-1}
+
\ln(x^2+x+1)
+
C.
\]

**易错点**：

1. 二次因式 $x^2+x+1$ 对应的分子必须设为 $Cx+D$，不能设成常数 $C$，否则部分分式分解形式不完备。
2. 重因式 $(x-1)^2$ 必须同时写出 $\frac{A}{x-1}$ 和 $\frac{B}{(x-1)^2}$，不能漏掉一次项。
3. 积分 $\displaystyle\int \frac{3}{(x-1)^2}\,dx=-\frac{3}{x-1}+C$，注意符号，不能误写成 $3\ln(x-1)^2$。
4. $\ln|x-1|$ 要加绝对值；而 $x^2+x+1$ 恒正，所以 $\ln(x^2+x+1)$ 可不加绝对值。
5. 若严格讨论，$x=1$ 是瑕点，原函数在 $(-\infty,1)$ 和 $(1,\infty)$ 上可分别相差常数；考试中通常写一个任意常数 $C$ 即可。

**命题规律**：

本题是有理函数不定积分的典型题，核心考点是**部分分式分解法**。常见变式包括：分母改为 $(x-a)^n(x^2+px+q)^m$、分子次数升高、或与定积分、反常积分结合。复习时应熟练掌握以下基本积分：

\[
\int \frac{dx}{x-a}=\ln|x-a|+C,
\]
\[
\int \frac{dx}{(x-a)^k}
=
\frac{1}{(1-k)(x-a)^{k-1}}+C
\quad (k\ge 2),
\]
以及二次不可约因式对应的
\[
\int \frac{2x+p}{x^2+px+q}\,dx
=
\ln(x^2+px+q)+C,
\]
\[
\int \frac{dx}{x^2+px+q}
=
\frac{2}{\sqrt{4q-p^2}}
\arctan\frac{2x+p}{\sqrt{4q-p^2}}
+C
\quad (4q-p^2>0).
\]

这类题只要分解正确，后续积分都是固定套路。

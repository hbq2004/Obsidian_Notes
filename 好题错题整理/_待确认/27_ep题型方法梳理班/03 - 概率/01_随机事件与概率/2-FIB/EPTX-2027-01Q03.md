# FIB 第 3 题

![[_Attachments/题目识别/EPTX-2027/EPTX-2027-01Q03_题目.png|题目]]

设随机事件 $A, B$ 满足条件 $A $$\cup$$ C = B $$\cup$$ C$ 和 $C - A = C - B$, 则 $$\bar{A}B\cup A\bar{B}$ = \_.

---

## V4 Flash Max 解析

**答案**: $\varnothing$ (空集)

---

**解题切入点**: 题眼在于将集合运算条件转化为对称差与补集的关系。条件 $A\cup C = B\cup C$ 等价于 $A\setminus C = B\setminus C$，即 $A\triangle B\subseteq C$；条件 $C-A = C-B$ 等价于 $C\cap A^c = C\cap B^c$，即 $C\cap(A\triangle B)=\varnothing$。两者结合推出 $A=B$，从而对称差为空。

---

**推演**: 由 $A\cup C = B\cup C$，任取 $x\in A\triangle B$，若 $x\notin C$，则 $x$ 属于 $A$ 或 $B$ 之一而不属于另一个，但 $x\notin C$ 时 $x$ 属于 $A$ 当且仅当属于 $B$，矛盾，故 $A\triangle B\subseteq C$。由 $C-A = C-B$ 即 $C\cap A^c = C\cap B^c$，任取 $x\in A\triangle B$，若 $x\in C$，则 $x$ 在 $A$ 中不在 $B$ 中（或反之），那么 $x$ 属于 $C\cap A^c$ 而不属于 $C\cap B^c$，矛盾，故 $C\cap(A\triangle B)=\varnothing$。于是 $A\triangle B\subseteq C$ 且 $A\triangle B\cap C=\varnothing$，只能 $A\triangle B=\varnothing$，即 $A=B$。因此 $\bar{A}B\cup A\bar{B}=A\triangle B=\varnothing$。

---

**易错点**: 1. 误将 $C-A$ 理解为 $C\setminus A$ 而非 $C\cap A^c$；2. 忽略条件 $A\cup C = B\cup C$ 蕴含 $A\setminus C = B\setminus C$ 的推导细节；3. 忘记对称差与补集的关系，导致无法整合两个条件。

---

**命题规律**: 集合运算与事件关系的经典题，常考利用对称差、补集、差集等工具剥离条件。类似算法竞赛中“构造辅助函数等价于构造集合映射”，将条件转化为 $A\triangle B$ 的包含关系，相当于枚举 $A\triangle B$ 中元素的状态，分属于 $C$ 和 $C^c$ 两种情况导出矛盾，最终得到 $A=B$。

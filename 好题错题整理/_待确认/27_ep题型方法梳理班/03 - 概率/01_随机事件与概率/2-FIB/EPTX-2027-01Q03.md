# FIB 第 3 题

![[_Attachments/题目识别/EPTX-2027/EPTX-2027-01Q03_题目.png|题目]]

设随机事件 $A, B$ 满足条件 $A \cup C = B \cup C$ 和 $C - A = C - B$ , 则 $\overline{A} B \cup A \overline{B} = \_\_\_\_$ .


---

## 答案

![[_Attachments/题目识别/EPTX-2027-答案/EPTX-2027-01Q03_答案.png|答案]]




---

## V4 Flash Max 解析

**答案**  
$$
\overline{A}B \cup A\overline{B} = \varnothing
$$

---
**解题切入点**  
题眼在于两个条件分别“锁定”了 $C$ 外部和 $C$ 内部的一致性：  
$A \cup C = B \cup C$ 说明在 $C$ 之外，$A$ 与 $B$ 完全一致；  
$C - A = C - B$ 说明在 $C$ 之内，$A$ 与 $B$ 也完全一致。  
这类似于算法竞赛中分别处理两个区间的约束，最终合并判断整体状态是否相同。

---
**推演**  
由  
$$
A \cup C = B \cup C
$$
两边同时减去集合 $C$，得到  
$$
(A \cup C) - C = (B \cup C) - C
$$
即  
$$
A - C = B - C.
$$

又由题设  
$$
C - A = C - B.
$$
注意到  
$$
C = (C \cap A) \cup (C - A),
$$
且 $C-A$ 与 $C\cap A$ 不相交，所以  
$$
C \cap A = C - (C - A).
$$
同理  
$$
C \cap B = C - (C - B).
$$
因为 $C - A = C - B$，故  
$$
C \cap A = C \cap B.
$$

于是  
$$
A = (A - C) \cup (A \cap C)
= (B - C) \cup (B \cap C)
= B.
$$

因此  
$$
\overline{A}B \cup A\overline{B}
= (A^c \cap B) \cup (A \cap B^c)
= A \triangle B
= \varnothing.
$$

---
**易错点**  
- 容易由 $A \cup C = B \cup C$ 直接误判为 $A=B$，但它只保证 $C$ 外部一致。  
- 容易忽略 $C-A=C-B$ 只刻画 $C$ 内部行为，不能单独推出 $A=B$。  
- 注意 $\overline{A}B$ 表示 $A^c \cap B$，不是普通乘法，也不是条件概率。  
- 忘记题目要求的是对称差 $A \triangle B$；若已推出 $A=B$，则对称差必为空集。

---
**命题规律**  
本题核心是集合运算与对称差，考查将集合等式转化为元素归属关系的能力。常见变式包括：给定类似条件证明 $A=B$，或求 $P(A \triangle B)$。出题思路类似算法竞赛中的“区间覆盖合并”或“双条件约束判定”：两个条件分别覆盖 $C$ 内和 $C$ 外，合并后才能确定全局唯一状态。

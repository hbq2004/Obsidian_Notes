# MCQ 第 275 题

![[_Attachments/题目识别/YW-2026/YW-2026-T344765-Q275_题目.png|题目]]

设 $A = (\alpha_1, \alpha_2, \cdots, \alpha_n)$ 是 $m \times n$ 矩阵, $b$ 是 $m$ 维列向量,分析以下命题,则错误的命题共有()个.

(1) $Ax = b$ 有解是 $r(A) = m$ 的必要非充分条件

(2) $Ax = b$ 有解是 $A^T x = 0$ 与 $\left( A^T \right) x = 0$ 同解的充要条件

(3) $Ax = b$ 无解是 $\left( A^T \right) x = \left( \frac{0}{1} \right)$ 有解的充要条件

(4) $Ax = b$ 无解是 $\alpha_1, \alpha_2, \cdots, \alpha_n, b$ 线性无关的必要非充分条件

A. 1

B. 2

C. 3

D. 0

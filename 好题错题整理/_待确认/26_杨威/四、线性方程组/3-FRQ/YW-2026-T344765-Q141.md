# FRQ 第 141 题

![[_Attachments/题目识别/YW-2026/YW-2026-T344765-Q141_题目.png|题目]]

设 $A$ 为 $n$ 阶矩阵, $b$ 为 $n$ 维非零列向量. $\alpha_1, \alpha_2, \cdots, \alpha_s$ 是 $Ax = b$ 线性无关的解向量, $\beta_1, \beta_2, \cdots, \beta_s$ 也是 $Ax$ $= b$ 线性无关的解向量, 其中 $s = n - r(A) + 1$. 以下命题正确的是:

(1) 方程组 $Ax = b$ 的任意解向量均可以由向量组 $\alpha_1, \alpha_2, \cdots, \alpha_s$ 线性表示.

(2) 向量组 $\alpha_1, \alpha_2, \cdots, \alpha_s$ 与 $\beta_1, \beta_2, \cdots, \beta_s$ 等价.

(3) 向量组 $\alpha_1, \alpha_2, \cdots, \alpha_s$ 所张的向量空间的维数为 $n - r(A) + 1$.

(4) $Ax = b$ 的任意解向量都在向量组 $\alpha_1, \alpha_2, \cdots, \alpha_s$ 所张的向量空间中.

(5) 向量组 $\alpha_1, \alpha_2, \cdots, \alpha_s$ 所张的向量空间中的任意向量都是 $Ax = b$ 的解向量.

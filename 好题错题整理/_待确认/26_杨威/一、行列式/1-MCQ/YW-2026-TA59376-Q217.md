# MCQ 第 217 题

![[_Attachments/题目识别/YW-2026/YW-2026-TA59376-Q217_题目.png|题目]]

设四阶矩阵 $A = (a_{ij})_{4 \times 4}$ 满足 $\sum\limits_{j=1}^{4} a_{ij} = 0$ ($i = 1, 2, 3, 4$) $M_{ij}$ 与 $A_{ij}$ 分别为元素 $a_{ij}$ 的余子式和代数余子式.

下列四个式子中必成立有()个.

① $M_{21} + M_{22} + M_{23} + M_{24} = 0$

② $A_{21} + A_{22} + A_{23} + A_{24} = 0$

③ $M_{21} = M_{22} = M_{23} = M_{24}$

④ $A_{21} = A_{22} = A_{23} = A_{24}$

A. 1

B. 2

C. 3

D. 4

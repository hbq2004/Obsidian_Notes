# FRQ 第 94 题

![[_Attachments/题目识别/YW-2026/YW-2026-T4E4366-Q094_题目.png|题目]]

设实二次型 $f(x_1, x_2, \cdots, x_n) = a(x_1^2 + x_2^2 + \cdots + x_n^2) + b(x_1 + x_2 + \cdots + x_n)^2$，$a^2 + b^2 \neq 0$。$A$ 是二次型 $f$ 的矩阵，则以下命题正确的有：

(1) $A$ 的秩只能是 $1$，$n - 1$，$n$ 这三种情况；

(2) $a$ 至少是 $A$ 的 $n - 1$ 重特征值；

(3) $n$ 维列向量 $(1, 1, \cdots, 1)^T$ 是 $A$ 的一个特征向量；

(4) 若 $n$ 维非零列向量 $\alpha$ 与 $(1, 1, \cdots, 1)^T$ 正交，则 $\alpha$ 是 $A$ 的特征向量.

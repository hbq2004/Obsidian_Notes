# FRQ 第 155 题

![[_Attachments/题目识别/YW-2026/YW-2026-T4E4366-Q155_题目.png|题目]]

2(本题满分12分)设二次型 $f(x_1, x_2, x_3) = x_1^2 + x_2^2 + 2x_3^2 - 2x_1x_3$，$g(x_1, x_2, x_3) = x_1^2 + 2x_3^2 - 2x_1x_2 - 2x_1x_3$。

(1) 求一个可逆矩阵 $C$，使得 $f(x_1, x_2, x_3)$ 可用合同变换 $x = Cy$ 化为标准形；

(2) 记 $g(x_1, x_2, x_3)$ 的矩阵为 $B$，求正交矩阵 $Q$，使得 $Q^T(C^TBC)Q$ 为对角矩阵；

(3) 求一个可逆矩阵 $T$，使得在合同变换 $x = Ty$ 下可将 $f(x_1, x_2, x_3)$ 与 $g(x_1, x_2, x_3)$ 同时化为标准形.

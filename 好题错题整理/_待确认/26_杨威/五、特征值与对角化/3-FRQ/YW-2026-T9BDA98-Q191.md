# FRQ 第 191 题

![[_Attachments/题目识别/YW-2026/YW-2026-T9BDA98-Q191_题目.png|题目]]

(23) 设 $A$ 为三阶实对称阵, $A$ 的特征值为 6, 3, 3, 特征向量为 $\alpha_1 = (1, 1, -2)^T$, $\alpha_2 = (1, -1, 0)^T$, $\alpha_3 = (2, 0, -2)^T$, $\alpha_4 = (4, 0, -4)^T$ 求:

I. $\alpha_1$, $\alpha_2$, $\alpha_3$, $\alpha_4$ 的极大线性无关组, 并将其余的向量由极大无关组线性表示;

II. $A$ 的属于特征值 $\lambda_1 = 6$ 的所有特征向量;

III. $A$.

# FRQ 第 138 题

![[_Attachments/题目识别/YW-2026/YW-2026-T9BDA98-Q138_题目.png|题目]]

设 $A, B$ 均为 3 阶非零矩阵, $A^2 = 0$. 则以下命题正确的是:

① $A$ 的秩为 1.

②矩阵 $A$、$AB + BA$ 和 $AB - BA$ 存在公共的特征值.

③矩阵 $A$、$AB + BA$ 和 $AB - BA$ 存在公共的特征向量.

④存在数 $k$ 和非零向量 $\alpha$, 使得 $k$ 是矩阵 $AB + BA$ 和 $AB - BA$ 的特征值, 且 $\alpha$ 是矩阵 $AB + BA$ 和 $AB -$ $BA$ 属于 $k$ 的特征向量.

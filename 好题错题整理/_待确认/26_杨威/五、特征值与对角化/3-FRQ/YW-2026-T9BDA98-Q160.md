# FRQ 第 160 题

![[_Attachments/题目识别/YW-2026/YW-2026-T9BDA98-Q160_题目.png|题目]]

设 $A$ 为 3 阶实矩阵, $\alpha, \beta, \gamma$ 均为 3 维非零列向量, $|A| = 2$，且 $A\alpha = 2\alpha A\beta = \beta A^T \gamma = \gamma$ 则以下正确的有:

① $\alpha^T \gamma = 0$.

②若 $\alpha^T \beta = 0$，则 $A^T = A$.

③若 $r(A - E) = 1$，则 $A^T$ 可以相似对角化.

④若 $\alpha, \beta, \gamma$ 两两正交，则 $A^T = A$.

# FRQ 第 81 题

![[_Attachments/题目识别/YW-2026/YW-2026-T9BDA98-Q081_题目.png|题目]]

设 α, β, γ 均为非零 n 维列向量, A = 2E + αβ^T, 则以下正确的有

(1) 若 γ^Tβ = 0, 则 γ 是 A 的特征向量;

(2) α 是 A 的特征向量;

(3) 若 β 是 A 的特征向量, 则 A 可以相似对角化;

(4) 若 α^Tβ ≠ 0, 则 A 可以相似对角化.

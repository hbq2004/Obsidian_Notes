# FRQ 第 245 题

![[_Attachments/题目识别/YW-2026/YW-2026-T9BDA98-Q245_题目.png|题目]]

设 $A$ 为 3 阶正交矩阵, $A^3 = E$, $\alpha$, $\beta$ 均为 3 维非零列向量, $\alpha$, $A\alpha$ 线性无关, $\alpha$, $A\alpha$, $A^2\alpha$ 线性相关. $\beta^T\alpha = \beta^T A\alpha = 0$.则以下命题正确的有()

① $\beta$ 与 $A^2\alpha$ 正交 ② $A\beta$ 与 $\alpha$ 正交 ③ $A\beta$ 与 $A\alpha$ 正交. ④ $\beta$ 是 $A$ 的特征向量.

# FIB 第 161 题

![[_Attachments/题目识别/YW-2026/YW-2026-TE732A7-Q161_题目.png|题目]]

设 $A$ 为 $n$ 阶实矩阵,则以下正确的命题共有 \_ 个.

①对任意 $n$ 维列向量 $\alpha$，都有 $A\alpha = 0$，则 $A = 0$;

②对任意 $n$ 维列向量 $\alpha$，方程组 $Ax = \alpha$ 都有解，则 $r(A) = n$;

③对任意 $n$ 维列向量 $\alpha$，都有 $\alpha^T A^T A\alpha = 0$，则 $A = 0$;

④对任意 $n$ 维列向量 $\alpha$，都有 $\alpha^T A\alpha = 0$，则 $A = 0$;

5.对任意 $n$ 维列向量 $\alpha$，都有 $\alpha^T (A + A^T) \alpha = 0$，则 $A + A^T = 0$.

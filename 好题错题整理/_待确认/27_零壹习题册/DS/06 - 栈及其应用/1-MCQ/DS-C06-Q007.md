# MCQ 第 7 题

![[_Attachments/题目识别/27_零壹习题册-题目/DS-C06-Q007_题目.png|题目]]

利用数组 $S$ 实现一个顺序栈，该栈最大容量设为 $\text{maxsize}$，已知栈底始终为 $S[0]$，栈顶指针为 $\text{top}$ 且初始时 $\text{top}$ 为 $-1$，则将元素 $e$ 入栈操作的主要步骤为（ ）.

(A) 
```
if(top<maxsize - 1) S[top++] = e;
```

(B) 
```
if(top < maxsize - 1) S[++ top ]=e;
```

(C) 
```
If(top < maxsize) S[ top++]=e;
```

(D) 
```
If(top < maxsize) S[++ top ]=e;
```

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/DS-C06-Q007_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。初始 `top=-1` 表示 `top` 是当前栈顶元素的下标，因此入栈前应判满 `top < maxsize - 1`，并且要先让 `top` 加 1 再写入元素，即 `if (top < maxsize - 1) S[++top] = e;`。

**解题切入点**：拿到题先看 `top=-1` 这个初值。它表示 `top` 是“当前栈顶元素在数组中的下标”，并不是元素个数。可以把数组想成一排编号为 $0\sim \mathrm{maxsize}-1$ 的抽屉，`top` 是最上面一个抽屉的编号；入栈时先让 `top` 走到下一个空抽屉，再放入元素。

**推演**：数组 `S` 的合法下标范围是
$$
0,1,2,\dots,\mathrm{maxsize}-1
$$
设当前栈中元素个数为 $n$。由于栈底固定在 $S[0]$，元素连续存放，且 `top` 指向栈顶元素下标，所以
$$
n=\mathrm{top}+1
$$
初始时 $n=0$，对应 $\mathrm{top}=-1$，吻合。

入栈前必须保证栈未满，即 $n<\mathrm{maxsize}$，也就是
$$
\mathrm{top}+1<\mathrm{maxsize}
$$
即
$$
\mathrm{top}<\mathrm{maxsize}-1
$$
所以判满条件应为 `top < maxsize - 1`，而不是 `top < maxsize`。

入栈时，新元素应放到原来的栈顶元素上面，即下标为 $\mathrm{top}+1$ 的位置，然后更新栈顶。因此操作应为
$$
\mathrm{top}\leftarrow \mathrm{top}+1,\qquad S[\mathrm{top}]\leftarrow e
$$
合并成 C 语句就是
$$
S[++\mathrm{top}]=e
$$
因为 `++top` 会先将 `top` 加 1，再使用新值作为下标。

逐项判断：

- A：判满条件 `top < maxsize - 1` 正确，但 `S[top++] = e` 等价于先写 `S[top]` 再让 `top` 加 1。当 `top=-1` 时会写 `S[-1]`；即使 `top>=0`，也会覆盖当前栈顶而不是写入新栈顶，错误。
- B：判满正确，`S[++top] = e` 先移动栈顶再写入，正确。
- C：判满条件错误。栈满时 $\mathrm{top}=\mathrm{maxsize}-1$，此时 `top < maxsize` 仍成立，会越界；且 `top++` 的写入位置也错误。
- D：判满条件同样错误。栈满时若执行 `S[++top] = e`，`top` 会变成 `maxsize`，访问 `S[maxsize]` 越界。

因此选 B。

**易错点**：

1. **把判满条件写成 `top < maxsize`**。  
   `top` 是下标，数组最后一个合法下标是 `maxsize - 1`。栈满时 `top == maxsize - 1`，此时 `top < maxsize` 仍为真，会溢出。

2. **混淆 `top++` 与 `++top`**。  
   `top++` 是先使用旧 `top`，再让 `top` 加 1；`++top` 是先把 `top` 加 1，再使用新值。`top=-1` 时入栈必须用 `++top`，否则可能写 `S[-1]` 或覆盖旧栈顶。

3. **忽略 `top=-1` 的含义**。  
   `top=-1` 表示空栈，当前元素个数是 $\mathrm{top}+1$。若误以为 `top` 是元素个数，会把条件和写入位置全部算错。

4. **C/D 的 `If` 大小写问题**。  
   严格按 C 语言语法，`If` 不是关键字，C/D 本身无法编译；但即使把 `If` 看作 `if`，它们的判满条件也仍然是错的。

**命题规律**：本题属于 408 数据结构中“栈和队列”的基础考点，考查顺序栈的判满条件、`top` 指针语义以及入栈操作的执行顺序。常见变式有：初始 `top=0` 时入栈应写成 `if (top < maxsize) S[top++] = e;`，出栈写成 `e = S[--top];`；或者考查两个栈共享一个数组时的判满条件。复习时应先明确 `top` 初值代表“栈顶元素下标”还是“下一个空闲位置”，再推导判空、判满和入栈/出栈代码，不要死记表达式。

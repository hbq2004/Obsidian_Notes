# MCQ 第 15 题

![[_Attachments/题目识别/27_零壹习题册-题目/DS-C06-Q015_题目.png|题目]]

15. 若元素a,b,c,d依次进栈，允许进栈、退栈操作交替进行. 除非没有可以入栈/出栈的情况下，不允许连续3次进行入/出栈工作，则可能的出栈情况有 （ ） 种.
(A) 14
(B) 9
(C) 10
(D) 11

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/DS-C06-Q015_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B（9 种）。无限制时合法进出栈序列数为卡特兰数 $C_4=14$；剔除 5 种受“连续 3 次入栈”限制的序列后，剩余 $14-5=9$ 种。

**解题切入点**：  
把进栈、出栈操作看成符号序列：入栈记作 $I$，出栈记作 $O$。合法操作序列必须满足 4 个 $I$、4 个 $O$，且任意前缀中 $I$ 的个数不少于 $O$ 的个数。这正好是括号序列计数，先想到卡特兰数；再看限制条件排除非法操作序列。

**推演**：  
设 $I$ 表示入栈，$O$ 表示出栈。  
4 个元素依次进栈，完整过程一定有 4 次入栈和 4 次出栈，所以无限制时合法操作序列数为：

$$
C_4=\frac{1}{4+1}\binom{8}{4}=14.
$$

现在加入限制。受限制的操作序列主要有 5 种，例如出现连续 3 次入栈。列出 14 种合法进出栈操作序列并判断：

| 操作序列 | 是否合法 |
|---|---|
| $IOIIIOOO$ | 否：中间出现连续 3 次入栈 |
| $IOIIOIOO$ | 是 |
| $IOIIOOIO$ | 是 |
| $IOIOIIOO$ | 是 |
| $IOIOIOIO$ | 是 |
| $IIOOIIOO$ | 是 |
| $IIOOIOIO$ | 是 |
| $IIIOOOIO$ | 否：出现连续 3 次入栈 |
| $IIOIOOIO$ | 是 |
| $IIIIOOOO$ | 否：出现连续 3 次入栈 |
| $IIIOIOOO$ | 否：出现连续 3 次入栈 |
| $IIIOOIOO$ | 否：出现连续 3 次入栈 |
| $IIOIIOOO$ | 是：最后连续出栈时已无元素可入栈，允许 |
| $IIOIOIOO$ | 是 |

所以合法序列数为：

$$
14-5=9.
$$

因为入栈顺序固定为 $a,b,c,d$，合法操作序列与出栈序列一一对应，因此可能的出栈情况共有 9 种。

**易错点**：  
- 不要直接选 $14$，那是无限制的卡特兰数，本题有限制条件。  
- 不要简单枚举 $4!=24$ 个输出排列；要先转化为 $I/O$ 操作序列判断合法性。  
- 不要误以为“进栈、退栈操作交替进行”是必须严格交替，否则只会得到 $IOIOIOIO$ 一种。  
- 注意“最后所有元素都已入栈时，只能连续出栈”，这是允许的，不能多扣。

**命题规律**：  
本题属于栈的经典考点：合法出栈序列判定与卡特兰数。常见变式包括：  
- 给定 $n$，求无限制合法出栈序列数，直接用 $C_n=\dfrac{1}{n+1}\binom{2n}{n}$；  
- 给一个出栈序列，判断是否可能；  
- 增加“连续入栈/出栈次数限制”，转化为对 $I/O$ 序列的计数。  
复习时应熟练掌握“进栈=左括号，出栈=右括号”的括号序列模型，并能用贪心或枚举判断合法性。

(A) 
```
if(top<maxsize - 1) S[top++] = e;
```

(B) 
```
if(top < maxsize - 1) S[++ top ]=e;
```

(C) 
```
If(top < maxsize) S[ top++]=e;
```

(D) 
```
If(top < maxsize) S[++ top ]=e;
```

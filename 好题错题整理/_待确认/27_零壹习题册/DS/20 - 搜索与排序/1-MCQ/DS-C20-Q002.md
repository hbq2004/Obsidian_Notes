# MCQ 第 2 题

![[_Attachments/题目识别/27_零壹习题册-题目/DS-C20-Q002_题目.png|题目]]

2. 在外部排序过程中，①置换选择排序②败者树算法③最佳归并树算法调用的先后顺序为 （ ） .

(A)①②③
(B)①③②
(C)③①②
(D)②①③

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/DS-C20-Q002_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B（①③②）。外部排序的完整流程是先用置换选择排序生成初始归并段，再通过最佳归并树规划归并方案，最后用败者树执行多路归并。

**解题切入点**：  
拿到题目先抓住“外部排序”的宏观流水线：**生成初始归并段 → 组织归并顺序 → 执行多路归并**。就像打多轮淘汰赛：先分组选出种子选手（置换选择排序），再排定赛程表（最佳归并树），最后按赛程进行比赛，每场比赛的裁判用败者树快速比较。题目问三个算法的“调用顺序”，本质是问它们在外部排序流水线中的先后角色，而不是内部细节。

**推演**：  
外部排序的基本流程为：

1. **预处理（生成初始归并段）**  
   内存无法容纳全部数据，先把文件划分为若干可以装入内存的片段。为提高初始归并段长度、减少段数，通常采用**置换选择排序**（代替普通内排序+切分），它利用内存缓冲区动态输出有序段。  
   因此，第一步调用的是 ①。

2. **规划归并树（确定归并方案）**  
   设有 $m$ 个初始归并段，采用 $k$ 路归并。为了使得归并过程中磁盘 I/O 次数最少（即带权路径长度最小），需要构造一棵 $k$ 叉**最佳归并树**（哈夫曼树），必要时补充长度为 0 的虚段。这一步在真正执行归并之前完成，决定每一轮合并哪些段、合并多少轮。  
   因此，第二步调用的是 ③。

3. **执行归并（多路归并）**  
   按照最佳归并树确定的方案，从 $k$ 个归并段中反复选出当前最小记录，写入新归并段。为了提高 $k$ 路归并中“选最小”的效率，使用**败者树**算法，使每次比较的开销从 $O(k)$ 降为 $O(\log_2 k)$。  
   因此，第三步调用的是 ②。

综上，调用顺序为：①置换选择排序 → ③最佳归并树算法 → ②败者树算法，即选项 B。

**易错点**：  
- **误选 A（①②③）**：以为先置换选择排序，再“归并”，最后“归并树”。实际上最佳归并树是归并前的“规划”，不是归并后的“总结”，必须先确定归并树才能按树执行归并。  
- **混淆“败者树”和“最佳归并树”**：败者树是执行归并时用来快速比较的数据结构；最佳归并树是归并段的组织方案（哈夫曼树思想）。一个是“工具”，一个是“蓝图”。  
- **忽略置换选择排序的作用**：误以为是普通内排序，但置换选择排序是专门生成初始归并段的算法，应放在最前面。  
- **虚段问题**：构造最佳归并树时，若 $k$ 叉树不满可能需要加虚段，但本题只问顺序，不需要具体计算。

**命题规律**：  
考点是**外部排序的整体流程**和三个关键算法的定位。常见变式包括：  
- 问“外部排序中减少初始归并段个数的手段”（答置换选择排序）。  
- 问“最佳归并树的作用”（答使总 I/O 次数最少，即带权路径长度最小）。  
- 问“败者树相比堆的优点”（答败者树更新时与父节点比较次数更少，且更适应多路归并）。  
- 综合题：给定初始归并段长度，让补虚段构造最佳归并树，并计算归并趟数或 I/O 次数。  

复习建议：把外部排序的三阶段（预处理、归并规划、归并执行）画成流程图，牢记每个算法的“位置”。不需要深究置换选择排序的内部细节，但要知道它产生的归并段平均长度为 $2l$（$l$ 为内存容量），且最佳归并树和败者树属于“亚军/锦标赛树”一族的经典应用。

# MCQ 第 6 题

![[_Attachments/题目识别/27_零壹习题册-题目/DS-C01-Q006_题目.png|题目]]

6. 现有如下代码段:
```c
int i=0;
int j=0;
while (i<n&&j<m){
    if (random_compare(i,j)||j==-1){
        i++;
        j++;
    } else {
        j=random_sub(j);
    }
}
```
其中，`random_compare` 函数是通过某种规则对两个 `int` 型参数进行比较，比较通过则返回 `true`，比较不通过返回 `false`；`random_sub` 则对传入 `int` 型参数减去某个正整数，返回值为减完后的结果，返回值最小为-1。已知 $m \leqslant n$，该算法的时间复杂度是 （ ）（提示：可以分析 $2i - j$ 的变化情况）.
(A) $O(n)$
(B) $O(mn)$
(C) $O(n\log n)$
(D) $O(n^2)$

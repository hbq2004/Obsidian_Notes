# MCQ 第 1 题

![[_Attachments/题目识别/27_零壹习题册-题目/DS-C02-Q001_题目.png|题目]]

1. 上述程序输出的结果是什么.

```
int change_add(int &x,int y) {
    int *p= &y;
    x=3;
    *p=4;
    return x+y;
}
int main() {
    int a=1,b=2,c=0;
    c = change_add(a,b);
    printf("a=%d,b=%d,c=%d",a,b,c);
    return 0;
}
```

(A) $a=3, b=4, c=7$
(B) $a=1, b=4, c=7$
(C) $a=3, b=2, c=7$
(D) $a=1, b=2, c=5$

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/DS-C02-Q001_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。因为 `change_add` 中 `x` 是引用参数，直接绑定实参 `a$，所以 `x=3` 会把 `a$ 改为 3；而 `y$ 是普通值参数，只是 `b$ 的副本，修改 `y$ 不影响 `b$，所以输出为 $a=3,b=2,c=7$。

**解题切入点**：拿到题目先看函数签名：`int change_add(int &x,int y)`。`int &x$ 说明 $x$ 是引用参数，能修改外层实参；`int y$ 说明 $y$ 是值传递，只是实参的副本。接着看 `int *p=&y;`，要立刻意识到 `p$ 指向的是形参 `y$，并不是实参 `b$。抓住“引用 vs 值传递”和“指针指向谁”这两点，就能定位考点。

**推演**：

调用前：

$$
a=1,\quad b=2,\quad c=0
$$

调用 `change_add(a,b)` 时：

- `x` 是引用参数，`x` 绑定实参 `a`，所以 `x` 是 `a` 的别名；
- `y` 是普通值参数，系统在 `change_add` 栈帧中为 `y$ 分配新空间，并把 `b$ 的值拷贝给 `y`，即：

$$
y=2,\qquad b \text{ 仍为 }2
$$

然后逐步执行函数体：

1. `int *p=&y;`

   `p` 指向的是 `change_add` 中的局部形参 `y`。

2. `x=3;`

   因为 `x` 是 `a` 的引用，所以：

   $$
   a=3
   $$

   `b` 不变。

3. `*p=4;`

   `p` 指向 `y`，所以解引用后修改的是 `y`：

   $$
   y=4
   $$

   `b` 仍然不变。

4. `return x+y;`

   此时：

   $$
   x=3,\quad y=4
   $$

   所以：

   $$
   x+y=3+4=7
   $$

   函数返回值赋给 `c`：

   $$
   c=7
   $$

因此最终：

$$
a=3,\quad b=2,\quad c=7
$$

输出：

$$
\text{a=3,b=2,c=7}
$$

对应选项 C。

**易错点**：

- 容易把 `int &x` 理解为“取出 x 的地址”。实际上在函数参数中，`&x$ 表示“引用”，即 `x` 是实参的别名；对 `x` 赋值会直接修改实参。
- 容易认为 `*p=4` 会修改 `b`。但 `p=&y` 取的是形参 `y` 的地址，而 `y` 是 `b` 的拷贝，不是 `b` 本身，所以 `b$ 不会被修改。
- 容易在计算返回值时忘记 `y` 已被改为 4。`return x+y` 用的是修改后的 `y$，所以结果是 7，而不是 3+2=5。
- 注意区分语法中的 `&`：`int &x` 里的 `&` 是引用标识，`&y` 表达式里的 `&` 是取地址运算符。

**命题规律**：本题考的是 C/C++ 函数参数传递机制，核心是“值传递、指针传递、引用传递”的区别。这在 408 数据结构中非常重要，尤其是链表、树、顺序表等算法题中常需要判断函数参数是否应为引用类型。常见变式包括：

$$
\text{swap}(int *a,int *b) \quad \text{与} \quad \text{swap}(int \&a,int \&b)
$$

的区别；

再如数据结构中的树操作：

$$
\text{Insert}(\text{BiTree} \&T)
$$

用来判断能否真正修改根节点或头指针。复习时应画函数栈帧图，明确“形参是实参的副本；引用是实参的别名；指针保存地址但指针本身也是值传递”，这样无论题目怎么变形都能快速判断实参是否被修改。

# FRQ 第 3 题

![[_Attachments/题目识别/27_零壹习题册-题目/DS-C22-Q003_题目.png|题目]]

3. 链表表示的两数相加
有两个非空的链表 $L_1$,$L_2$，分别代表两个非负整数，链表从前到后分别代表从高位到低位，每个结点存了一位数字，现要求你在不破坏原有的两个链表结构的基础上设计一算法计算这两个非负整数的和，并使用一个新的链表返回结果。除了 $0$ 之外，这两个数字不会以 $0$ 开头。例如：$L_1$ 为 $1\rightarrow 2\rightarrow 3\rightarrow 4\rightarrow 5$，$L_2$ 为 $3\rightarrow 4\rightarrow 5$，返回的链表应为 $1\rightarrow 2\rightarrow 6\rightarrow 9\rightarrow 0$；若 $L_1$ 为 $0$、$L_2$ 为 $0$，则返回 $0$。
(1) 描述算法思想；
(2) 使用 c 或 c++ 实现该算法；
(3) 写出算法的时间复杂度和空间复杂度；

## DeepSeek V4 Flash Max 解析

**答案**：本题为算法设计题，无选项。核心思路：用栈将两个链表的结点值逆序弹出，从而从低位向高位逐位相加并维护进位，再用头插法构造结果链表。

**解题切入点**：拿到题第一步要判断链表的方向。本题链表是“高位到低位”，而加法竖式必须从低位开始，所以尾部才是加法的起点。类似算法竞赛中的“大数加法”，需要先把两个数的最低位对齐。由于不允许破坏原链表，不能直接反转链表，因此自然想到用栈的“后进先出”特性完成逆序，这是应对“只能从头遍历、却要从尾计算”的经典手段。

**推演**：

设 $L_1$ 长度为 $m$，$L_2$ 长度为 $n$。

1. 遍历 $L_1$，将每个结点的值依次压入栈 $S_1$；遍历 $L_2$，将每个结点的值依次压入栈 $S_2$。此时 $S_1$、$S_2$ 的栈顶分别是两个数字的个位，栈底是最高位。
2. 同时弹出 $S_1$、$S_2$ 的栈顶元素，分别记为 $x$、$y$；若某栈已空，则该位取 $0$。令进位为 $carry$，计算：
   $$sum = x + y + carry,\qquad val = sum \bmod 10,\qquad carry = \left\lfloor \frac{sum}{10} \right\rfloor.$$
3. 用头插法将值为 $val$ 的新结点插入结果链表头部。
4. 重复步骤 2、3，直到 $S_1$、$S_2$ 均为空且 $carry=0$。返回结果链表头指针。

为什么用头插法？因为先计算得到的是低位，而题目要求返回的链表仍是高位到低位。头插法总是把新结点插到当前链表头部，于是后计算出来的高位会被放在前面，先计算出来的低位会被逐步“挤到”后面，正好满足顺序要求。

以题目例子验证：$L_1=1\to2\to3\to4\to5$，$L_2=3\to4\to5$。压栈后 $S_1$ 栈顶到栈底为 $5,4,3,2,1$；$S_2$ 为 $5,4,3$。

| 弹出值 | $sum$ | $val$ | $carry$ | 头插后的链表 |
|---|---|---|---|---|
| $x=5,y=5$ | $10$ | $0$ | $1$ | $0$ |
| $x=4,y=4$ | $9$ | $9$ | $0$ | $9\to0$ |
| $x=3,y=3$ | $6$ | $6$ | $0$ | $6\to9\to0$ |
| $x=2,y=0$ | $2$ | $2$ | $0$ | $2\to6\to9\to0$ |
| $x=1,y=0$ | $1$ | $1$ | $0$ | $1\to2\to6\to9\to0$ |

最终返回 $1\to2\to6\to9\to0$，正确。

边界情况：若 $L_1=0$、$L_2=0$，两栈各只有一个 $0$，弹出后 $sum=0$，创建结点 $0$，返回 $0$。若最高位有进位，例如 $999+1$，当所有栈元素弹出后 $carry=1$，循环条件仍成立，会再创建一个最高位结点 $1$，因此不会丢失进位。

C++ 实现如下：

```cpp
#include <stack>
using namespace std;

struct ListNode {
    int val;
    ListNode *next;
    ListNode(int x) : val(x), next(nullptr) {}
};

ListNode* addTwoNumbers(ListNode* l1, ListNode* l2) {
    stack<int> s1, s2;
    ListNode *p1 = l1, *p2 = l2;
    while (p1) {
        s1.push(p1->val);
        p1 = p1->next;
    }
    while (p2) {
        s2.push(p2->val);
        p2 = p2->next;
    }

    ListNode *head = nullptr;
    int carry = 0;
    while (!s1.empty() || !s2.empty() || carry) {
        int sum = carry;
        if (!s1.empty()) {
            sum += s1.top();
            s1.pop();
        }
        if (!s2.empty()) {
            sum += s2.top();
            s2.pop();
        }

        ListNode *node = new ListNode(sum % 10);
        node->next = head;
        head = node;

        carry = sum / 10;
    }
    return head;
}
```

时间复杂度：两个链表各遍历一次，所有结点各进栈、出栈一次，操作次数为 $O(m+n)$；每次压栈、弹栈和头插都是 $O(1)$，因此总时间复杂度为 $O(m+n)$。

空间复杂度：两个栈分别保存两个链表的所有结点值，额外空间为 $O(m+n)$。若把返回的结果链表计入空间，其结果长度为 $O(\max(m,n))$，总空间仍为 $O(m+n)$。由于题目限制不破坏原链表，不能使用原地反转来将空间降到 $O(1)$，使用栈是合理且必要的逆序手段。

**易错点**：

- 忽略链表方向：把“高位到低位”误认为“低位到高位”，直接从头开始相加。必须先通过栈或递归逆序。
- 头插法与尾插法混淆：先计算得到的是低位，若用尾插法，结果链表会变成低位在前，方向错误。必须用头插法。
- 访问空栈：两链表长度不等时，短链表对应的栈可能已空，应判断后取 $0$，不能直接对空栈执行 `top()` 和 `pop()`。
- 循环条件写错：若写成 `while (!s1.empty() && !s2.empty())`，当短链表先空时会提前退出，漏掉长链表剩余高位；若循环条件不包含 `carry`，最高位进位会丢失。正确写法是 `while (!s1.empty() || !s2.empty() || carry)`。
- 忽略最高位进位：如 $999+1$ 的结果应为 $1000$，容易错误地返回 $000$。循环条件包含 `carry` 后可避免。
- 破坏原链表：若选择先反转原链表相加再反转回来，空间可降为 $O(1)$，但会修改原链表结构，不符合题意。审题时要看清“不破坏原有链表结构”。

**命题规律**：本题属于链表与栈结合的经典应用，核心考点是“大数加法 + 链表方向 + 头插法”。在 408 中通常以算法设计题形式出现，也可能作为代码填空题。常见变式有：

1. 若链表从低位到高位存储，例如 $4\to5\to6$ 表示 $654$，则不需要栈，直接同时遍历两个链表，用尾插法构造结果即可。
2. 若允许破坏原链表，可先反转两个链表，从低位相加后再反转结果，额外空间可做到 $O(1)$。
3. 若题目要求递归实现，递归深度等价于链表长度，隐含 $O(n)$ 的栈空间，思路与用栈相同。

复习建议：熟练掌握栈的逆序作用，以及头插法、尾插法的适用场景；注意处理最高位进位、两链表长度不等、$0+0$ 等边界条件。对比 LeetCode 2（低位到高位）和 LeetCode 445（高位到低位）两道题，可以加深对链表加法问题的理解。

# FRQ 第 5 题

![[_Attachments/题目识别/27_零壹习题册-题目/DS-C22-Q005_题目.png|题目]]

5. 构建二倍树二叉排序树

我们对二叉树的某个性质做如下定义：若某个二叉树根结点的右子树规模与左子树规模的2倍的差值的绝对值不超过1，则我们称这个二叉树为二倍树。若二叉树根节点左子树的规模与右子树规模的2倍的差值绝对值不超过1，则称该二叉树为反二倍树。

现有一个有序数组A[0...n-1]，请设计一个算法，以A数组为基础构建一棵二叉排序树，使得：以深度为奇数的结点为根的子树均为二倍树，以深度为偶数的结点为根的子树均为反二倍树。注：根结点的深度记为1

(1) 简述你的算法思想.

(2) 请设计二叉树的数据结构，并以该结构为返回值实现题述算法.

(3) 分析你的算法的时间复杂度.

## DeepSeek V4 Flash Max 解析

**答案**：本题为算法设计题，无选项。核心思路是：在有序数组上递归选根，按深度奇偶分别令左/右子树规模为 $\lfloor N/3\rfloor$，从而每个结点都满足对应二倍/反二倍条件，同时保持二叉排序树性质。

**解题切入点**：拿到题先抓住条件只与“子树结点数”有关，与具体键值无关。数组已经有序，因此建 BST 只需决定根的位置；问题转化为“给定当前区间大小 $N$，左右子树大小之和为 $N-1$，如何分配左右规模”，这是典型的分治选根问题。可以类比“切蛋糕”：先按比例切一刀，再对两块递归切。

**推演**：

设当前子树大小为 $N$，左子树规模为 $L$，右子树规模为 $R$，则

$$
L+R=N-1.
$$

### 1. 奇数深度：要求二倍树

条件为

$$
|R-2L|\le 1.
$$

代入 $R=N-1-L$，得

$$
|N-1-3L|\le 1
$$

即

$$
N-2\le 3L\le N.
$$

令 $q=\lfloor N/3\rfloor$，取 $L=q$，分情况验证：

- 若 $N=3q$，则 $R=2q-1$，$|R-2L|=1$；
- 若 $N=3q+1$，则 $R=2q$，$|R-2L|=0$；
- 若 $N=3q+2$，则 $R=2q+1$，$|R-2L|=1$。

所以奇数深度时取

$$
L=\left\lfloor \frac{N}{3}\right\rfloor.
$$

### 2. 偶数深度：要求反二倍树

条件为

$$
|L-2R|\le 1.
$$

同理可得取

$$
R=\left\lfloor \frac{N}{3}\right\rfloor,
$$

此时

$$
L=N-1-R.
$$

### 3. 数据结构定义

用常见的二叉链表即可：

```c
typedef struct BTNode {
    int val;
    struct BTNode *left, *right;
} BTNode;
```

### 4. 算法实现

```c
BTNode* createNode(int val) {
    BTNode *p = (BTNode*)malloc(sizeof(BTNode));
    p->val = val;
    p->left = p->right = NULL;
    return p;
}

BTNode* buildBST(int A[], int low, int high, int depth) {
    if (low > high) return NULL;

    int N = high - low + 1;
    int q = N / 3;   // 下取整
    int rootIdx;

    if (depth % 2 == 1) {
        // 奇数深度：二倍树 |right - 2*left| <= 1
        // 左子树规模取 q
        rootIdx = low + q;
    } else {
        // 偶数深度：反二倍树 |left - 2*right| <= 1
        // 右子树规模取 q
        rootIdx = high - q;
    }

    BTNode *root = createNode(A[rootIdx]);

    root->left  = buildBST(A, low, rootIdx - 1, depth + 1);
    root->right = buildBST(A, rootIdx + 1, high, depth + 1);

    return root;
}

BTNode* construct(int A[], int n) {
    return buildBST(A, 0, n - 1, 1);   // 根深度记为 1
}
```

### 5. 正确性

- 由上述模 $3$ 分类讨论可知，当前根处一定满足对应二倍/反二倍条件。
- 因为 $A$ 有序，选 $A[rootIdx]$ 为根后，左区间元素都小于根，右区间元素都大于根，满足二叉排序树性质。
- 递归构造左右子树时深度加 $1$，奇偶性交替，因此所有深度奇偶要求都被满足。
- 空子树规模为 $0$，叶子结点也满足条件。

### 6. 时间复杂度

每个结点只会被创建一次，每个递归调用为 $O(1)$ 时间，因此总时间复杂度为

$$
O(n).
$$

递归深度最坏情况下每次子问题规模不超过原来的 $\frac{2}{3}$，所以递归栈空间为 $O(\log n)$。

**易错点**：

- 把二倍树和反二倍树的条件记反。奇数深度是 $|R-2L|\le1$，偶数深度是 $|L-2R|\le1$。
- 误把“规模”当成“高度”。这里比较的是子树结点数，不是树高。
- 奇数深度取左子树为 $\lfloor N/3\rfloor$，偶数深度取右子树为 $\lfloor N/3\rfloor$，不能统一用同一个规则。
- 忘记根深度为 $1$，或递归时没有让深度加 $1$，会导致奇偶条件整体颠倒。
- 根下标算错：奇数深度时 `rootIdx = low + q`；偶数深度时 `rootIdx = high - q`，不能一律取 `low + q`。
- 复杂度误写成 $O(\log n)$。建树必须生成 $n$ 个结点，所以至少是 $O(n)$；$O(\log n)$ 只是递归栈深度。

**命题规律**：本题属于“有序序列构造二叉排序树”的变形，核心考点是分治选根与递归建树。常见变式包括：有序数组转平衡 BST、按左右子树规模比例构造特殊树、按深度奇偶交替定义形态。复习时应掌握“由有序序列建 BST 的关键是选择根的位置”，遇到比例条件先列方程 $L+R=N-1$，再通过分类讨论确定左右规模；同时注意递归边界和深度奇偶传递。

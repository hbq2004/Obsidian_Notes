# FRQ 第 4 题

![[_Attachments/题目识别/27_零壹习题册-题目/DS-C22-Q004_题目.png|题目]]

4. 删除数组中指定元素
请设计算法删除数组 $A[0\ldots n)$ 中的所有值为 $x$ 的元素，要求时间复杂度为 $O(n)$。

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/DS-C22-Q004_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：本题无选项，正确算法为**双指针原地覆盖法**。用慢指针 $i$ 保存“当前可写入位置”，快指针 $j$ 遍历数组；若 $A[j]\neq x$，则将其覆盖到 $A[i]$ 并让 $i$ 加 1。一句话理由：每个元素至多被访问和写入一次，总时间复杂度为 $O(n)$，且无需额外数组。

**解题切入点**：拿到题目先抓“删除指定元素”和“时间复杂度 $O(n)$”这两个关键信息。如果每遇到一个 $x$ 就把后面所有元素前移，最坏会达到 $O(n^2)$，不符合要求。因此应想到**快慢指针**技巧：快指针负责在前“探路”，慢指针负责修建保留后的数组。这就像排队时把不合格的人挑走，剩下的人依次向前补位，而不是每走一步就重新排一次队。

**推演**：

设数组为 $A[0\ldots n)$，要求删除所有值为 $x$ 的元素，并返回删除后的新长度。

初始化慢指针：

$$
i=0
$$

快指针 $j$ 从 $0$ 到 $n-1$ 遍历：

$$
j=0,1,2,\ldots,n-1
$$

对于每个 $A[j]$：

- 若 $A[j]=x$，说明该元素应被删除，直接跳过；
- 若 $A[j]\neq x$，则将其保留，执行：

$$
A[i]=A[j]
$$

然后：

$$
i=i+1
$$

**循环不变式**：处理完前 $j$ 个元素后，$A[0\ldots i)$ 中保存的恰好是前 $j$ 个元素中所有不等于 $x$ 的元素，且相对顺序不变。

为什么覆盖不会出错？因为始终有 $i\le j$。已保留的元素个数不可能超过已经扫描过的元素个数，所以写入位置 $A[i]$ 要么是当前位置，要么是已经处理过的位置，绝不会覆盖尚未扫描的元素。

循环结束后，$j=n$，此时 $A[0\ldots i)$ 中保存的就是原数组中所有不等于 $x$ 的元素。

伪代码如下：

```c
int removeX(int A[], int n, int x) {
    int i = 0;
    for (int j = 0; j < n; j++) {
        if (A[j] != x) {
            A[i++] = A[j];
        }
    }
    return i;
}
```

例如：

$$
A=[1,2,3,2,4],\quad x=2
$$

依次执行：

- $j=0$，$A[0]=1\neq 2$，$A[0]=1$，$i=1$；
- $j=1$，$A[1]=2$，删除，跳过；
- $j=2$，$A[2]=3\neq 2$，$A[1]=3$，$i=2$；
- $j=3$，$A[3]=2$，删除，跳过；
- $j=4$，$A[4]=4\neq 2$，$A[2]=4$，$i=3$。

最终：

$$
A[0\ldots 3)=[1,3,4]
$$

新长度为 $3$。

时间复杂度：循环 $n$ 次，每次操作均为 $O(1)$，所以：

$$
T(n)=O(n)
$$

空间复杂度：只用了常数个辅助变量，所以：

$$
S(n)=O(1)
$$

**易错点**：

1. **每删除一个 $x$ 就移动后续所有元素**：最坏情况下数组元素几乎全是 $x$，每次移动需要 $O(n)$，总时间退化为 $O(n^2)$，不符合题目要求。
2. **新建辅助数组**：虽然也能做到 $O(n)$，但空间复杂度变为 $O(n)$；本题通常要求原地删除，应优先使用覆盖法。
3. **覆盖时写反顺序**：比如先让 $i$ 增加再赋值，可能导致数组越界或覆盖错误。必须先赋值，再 $i=i+1$。
4. **忘记返回新长度**：数组删除后实际逻辑长度变为 $i$，如果仍然按旧长度 $n$ 访问，会把尾部残留的无用元素当作有效数据。
5. **认为必须物理清除尾部元素**：算法只需保证 $A[0\ldots i)$ 是删除后的有效部分，尾部值无需处理。

**命题规律**：本题属于“顺序表元素删除”的经典考点，核心是**双指针/快慢指针**。常见变式包括：

- 删除有序数组中的重复元素；
- 将数组中所有值为 $0$ 的元素移到末尾；
- 保序删除所有满足某条件的元素；
- 将数组按奇偶划分。

复习建议：掌握“快慢指针原地覆盖”的固定模板，并能够清晰解释为什么 $i\le j$ 保证覆盖安全。做变式时，先判断题目是否要求保持相对顺序；若要求保持顺序，使用覆盖法；若不要求，还可使用“双端交换”法减少移动次数。算法设计题重在写清循环不变式和复杂度分析，考试时务必给出返回的新长度。

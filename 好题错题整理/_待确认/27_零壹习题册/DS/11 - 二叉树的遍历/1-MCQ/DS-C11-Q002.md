# MCQ 第 2 题

![[_Attachments/题目识别/27_零壹习题册-题目/DS-C11-Q002_题目.png|题目]]

2. 下面关于二叉树遍历的说法，错误的个数是 （  ） .I. 先序序列和后序序列可以确定唯一的层次遍历序列 II. 先序遍历和层次遍历序列可以唯一确定一棵二叉树 III. 中序序列加上先序、层次、后序遍历中的任意一个序列都可以唯一确定一棵二叉树
(A) 0
(B) 1
(C) 2
(D) 3

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/DS-C11-Q002_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B（错误的个数是 1，只有 II 错误）。  
一句话理由：先序序列与后序序列虽不能唯一确定二叉树，但可以唯一确定层次遍历序列；而先序序列加层次序列不能唯一确定二叉树。

**解题切入点**：拿到题目先定位为“二叉树的遍历序列与唯一确定性问题”。核心口诀是“没有中序，就分不清左右子树”，所以先序、后序、层次序列之间任意两者组合通常都不能唯一确定二叉树；只有包含中序序列的组合才能唯一确定树形。但题目 I 问的是“层次遍历序列”而不是“二叉树”，这是两个不同强度的问题，需要单独判断，不能直接套结论说错。

**推演**：

设二叉树的先序序列为 $Pre$，中序序列为 $In$，后序序列为 $Post$，层次遍历序列为 $Level$。

经典结论：

- $Pre + In$：唯一确定一棵二叉树；
- $Post + In$：唯一确定一棵二叉树；
- $Level + In$：唯一确定一棵二叉树；
- $Pre + Post$：不能唯一确定一棵二叉树，但可以唯一确定其层次遍历序列；
- $Pre + Level$：不能唯一确定一棵二叉树；
- $Post + Level$：不能唯一确定一棵二叉树。

逐条判断：

**I. 先序序列和后序序列可以确定唯一的层次遍历序列**

先序和后序不能唯一确定二叉树，因为当某个结点只有一个孩子时，无法判断该孩子是左孩子还是右孩子。例如根为 $A$，孩子为 $B$，若 $B$ 是左孩子，则 $Pre = AB$，$Post = BA$；若 $B$ 是右孩子，则 $Pre = AB$，$Post = BA$。两者的先序、后序完全相同，但树形不同。

然而，无论这个独生子是左孩子还是右孩子，它在层次遍历中仍然出现在父结点之后的下一层；它的整个子树也作为一个整体出现在对应层次，不会因为左右位置互换而改变层序。因此，所有满足同一组先序和后序的二叉树，其层次遍历序列是唯一的。

更一般地，若根有两个孩子，则先序中根后的第一个结点是左孩子，后序中根前的第一个结点是右孩子，可以区分左右；若根只有一个孩子，则左右不分不影响层序。递归地看，每一个“独生子”的左右不确定性都不会改变层次遍历序列。因此 I 正确。

**II. 先序遍历和层次遍历序列可以唯一确定一棵二叉树**

这个说法错误。给出反例：

树 $T_1$：$A$ 的左孩子为 $B$，$B$ 的右孩子为 $C$。  
其先序序列为 $A,B,C$，层次遍历序列为 $A,B,C$。

树 $T_2$：$A$ 的右孩子为 $B$，$B$ 的左孩子为 $C$。  
其先序序列同样为 $A,B,C$，层次遍历序列同样为 $A,B,C$。

两棵树的先序序列和层次遍历序列完全相同，但树形不同。因此先序序列 $+$ 层次遍历序列不能唯一确定一棵二叉树，II 错误。

**III. 中序序列加上先序、层次、后序遍历中的任意一个序列都可以唯一确定一棵二叉树**

- 中序 $+$ 先序：先序中第一个结点为根，中序中以根为界划分左、右子树，再递归构造，唯一。
- 中序 $+$ 后序：后序中最后一个结点为根，再用中序划分左右子树，递归构造，唯一。
- 中序 $+$ 层次：层次序列中第一个结点为根，用中序划分左右子树；左右子树中的结点在层次序列中保持原相对顺序，分别递归构造，唯一。

因此 III 正确。

综上，错误的个数为 $1$，选 B。

**易错点**：

1. 误以为“先序 + 后序不能唯一确定二叉树”就推出 I 错误。题目 I 说的是“层次遍历序列”，不是“二叉树”，两者结论不同。
2. 误以为“先序 + 层次序列”可以唯一确定二叉树。注意层次序列只给出结点所在层次，没有给出同一父结点下左右孩子的区分，因此会存在“链状左右摇摆”的反例。
3. 误以为“中序 + 层次序列”不能唯一确定二叉树。实际上层次序列提供全局根的位置，配合中序可以逐层划分左右子树，是能够唯一确定的。
4. 审题不清：题目问的是“错误的个数”，不是“正确的个数”，容易选成 D。
5. 判断唯一性时，只想到“能不能构造出一棵树”，而忽略“是否存在两棵不同的树同时满足条件”。反例法是这类题最快捷的验证手段。

**命题规律**：

- 考点定位：二叉树的遍历序列与“唯一确定二叉树”的充分条件。核心结论是：中序序列必不可少，先序、后序、层次分别与中序组合都能唯一确定二叉树；先序、后序、层次相互之间组合通常不能唯一确定二叉树。
- 常见变式：
  - 给出两个遍历序列，判断能否唯一确定二叉树；
  - 已知先序和中序，求后序或层次遍历序列；
  - 已知层次和中序，求先序或后序序列；
  - 判断“先序 + 后序 + 满二叉树”能否唯一确定二叉树；
  - 将本题中的“层次遍历序列”改为“结点的深度序列”等，考查对遍历性质的理解深度。
- 复习建议：熟练掌握由“先序 + 中序”“后序 + 中序”“层次 + 中序”手工构造二叉树的递归过程；对于不能唯一确定的情况，学会构造“单孩子左右摇摆”的反例；同时注意区分“确定二叉树”与“确定某种遍历序列”这两个不同层次的问题。

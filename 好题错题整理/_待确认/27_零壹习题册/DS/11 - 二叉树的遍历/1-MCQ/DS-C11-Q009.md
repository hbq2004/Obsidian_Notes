# MCQ 第 9 题

![[_Attachments/题目识别/27_零壹习题册-题目/DS-C11-Q009_题目.png|题目]]

9. 在中序遍历的递归实现算法中，函数终止的结点序列是 （  ） .
(A) 先序序列
(B) 中序序列
(C) 后序序列
(D) 层次序列

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/DS-C11-Q009_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C（后序序列）。中序递归遍历时，每个结点函数调用返回/终止的次序是“左子树 → 右子树 → 根”，即后序序列。

**解题切入点**：把递归遍历看作三个事件：函数调用、访问结点、函数返回。对应关系是：
- 函数第一次被调用/进栈顺序：先序序列；
- 执行 `visit(T)` 顺序：中序序列；
- 函数终止/返回/出栈顺序：后序序列。

题目关键词是“函数终止”，所以直接定位到“后序序列”。

**推演**：中序遍历递归实现为

```c
void InOrder(BiTree T) {
    if (T != NULL) {
        InOrder(T->lchild);
        visit(T);
        InOrder(T->rchild);
    }
}
```

设 $S(T)$ 表示以 $T$ 为根的子树中，各结点函数调用终止的次序。

对结点 $T$，执行过程是：

1. 先递归处理左子树，因此左子树中所有结点的函数先终止；
2. 然后访问 $T$；
3. 再递归处理右子树，因此右子树中所有结点的函数随后终止；
4. 最后 $T$ 自身的函数调用才终止，返回上一层。

所以有

$$
S(T)=S(T_{\text{left}})+S(T_{\text{right}})+[T]
$$

这正好是后序遍历的定义：左、右、根。

因此，中序递归遍历中“函数终止的结点序列”是后序序列，选 C。

**易错点**：

- 容易误选 B（中序序列）：因为题目开头有“中序遍历”，容易把“访问结点”的顺序当成答案。但 `visit(T)` 在左子树返回后、右子树调用前执行；而 `InOrder(T)` 这个函数本身要在右子树全部处理完后才终止。
- 容易误选 A（先序序列）：如果把“函数开始调用”的顺序当成答案，那才是先序序列；但题目问的是“终止”。
- 不要与非递归中序遍历的“出栈顺序”混淆。非递归中序遍历常用栈实现时，结点出栈后立即访问，出栈顺序是中序；但递归函数的返回/弹栈顺序是后序。
- 层次序列对应的是队列式层次遍历，不是递归深度遍历的自然结果。

**命题规律**：本题考的是递归遍历的底层执行过程，本质是函数调用栈的“压栈/弹栈”顺序。常见变式有：
- 问“函数调用顺序”选先序；
- 问“访问结点顺序”选中序；
- 问“函数终止/返回顺序”选后序；
- 问“递归工作栈中最多结点数”，等价于求树的高度。

复习时不要死背代码，要抓住“调用、访问、返回”三个事件与先序、中序、后序的对应关系，这类题就能快速判断。

# MCQ 第 14 题

![[_Attachments/题目识别/27_零壹习题册-题目/DS-C11-Q014_题目.png|题目]]

14. 对二叉树进行递归版本的后序遍历时，若访问 p 结点时，对 q 结点的访问函数处于打开状态，则 q 与 p 的关系为（ ）.

(A) q 是 p 的祖先

(B) q 是 p 的后代

(C) q 是 p 的兄弟

(D) A、B、C 都不是

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/DS-C11-Q014_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A。后序递归遍历中，访问 $p$ 时递归栈中未返回的调用都在从根到 $p$ 的路径上，因此 $q$ 是 $p$ 的祖先。

**解题切入点**：题干中的“访问函数处于打开状态”等价于“该结点的递归调用尚未返回，其活动记录仍在递归工作栈中”。看到递归遍历，第一反应是画递归调用栈；栈中保存的是从根到当前结点的路径，就像 DFS 递归时栈中保存当前搜索路径一样。

**推演**：

后序遍历递归版本：

```cpp
void PostOrder(BiTree T) {
    if (T) {
        PostOrder(T->lchild);
        PostOrder(T->rchild);
        Visit(T);
    }
}
```

递归调用栈满足：每进入一个孩子结点，就把该孩子的 `PostOrder` 调用压栈；每从一棵子树返回，就弹栈。因此任意时刻，从栈底到栈顶依次是

$$
\operatorname{PostOrder}(v_0), \operatorname{PostOrder}(v_1), \dots, \operatorname{PostOrder}(v_k)
$$

其中 $v_0$ 是根，$v_{i+1}$ 是 $v_i$ 的孩子，$v_k$ 是当前正在访问的结点。

当执行 $\operatorname{Visit}(p)$ 时，$v_k=p$。此时 $v_0, v_1, \dots, v_{k-1}$ 正好是根到 $p$ 的路径上的结点，也就是 $p$ 的祖先；这些祖先的 `PostOrder` 调用都因等待 $p$ 所在子树处理完而尚未返回。所以 $q$ 的访问函数打开，说明 $q$ 在这条祖先链上，即 $q$ 是 $p$ 的祖先。

再看另外两项：

- 若 $q$ 是 $p$ 的后代，则后序“先左右、后根”，$q$ 所在子树一定已经处理完并返回，不可能在访问 $p$ 时仍打开。
- 若 $q$ 是 $p$ 的兄弟，则兄弟子树的调用要么已经返回，要么尚未开始，不可能与访问 $p$ 的时间重叠。

故只能选 A。

**易错点**：

1. 把“访问函数打开”误解为“已经被访问输出”。实际上它表示“递归调用尚未结束”，祖先在访问 $p$ 时还没有轮到输出。
2. 记错后序顺序：后序是“左、右、根”，访问 $p$ 前其左右子树已经全部遍历完，所以 $q$ 不可能是 $p$ 的后代。
3. 误选兄弟：兄弟子树的递归调用与 $p$ 的访问在时间上不重叠；先处理的兄弟已返回，后处理的兄弟还没入栈。
4. 若不排除 $q=p$ 的平凡情形，$p$ 自身的递归调用当然也打开；但选项讨论的是不同结点间的关系，默认 $q \ne p$。

**命题规律**：考点是二叉树递归遍历与递归工作栈，属于遍历过程理解题。常见变式包括：问某时刻递归栈中保存哪些结点；问栈底到栈顶的具体序列；比较先序、中序、后序递归遍历时栈的变化。复习时应亲手画三种遍历的递归栈变化图，理解 `Visit` 的位置只决定输出顺序，不改变“递归栈保存祖先链”这一本质。

# MCQ 第 16 题

![[_Attachments/题目识别/27_零壹习题册-题目/DS-C11-Q016_题目.png|题目]]

16. 对二叉树进行递归版本的后序遍历时，若访问p结点时，对q结点的访问函数已经执行完成，则q与p的关系可能为（ ）.
(A) q是p的祖先
(B) q是p的后代
(C) q是p的兄弟
(D) B、C均可能

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/DS-C11-Q016_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D（B、C 均可能）。后序遍历中，访问 $p$ 之前，$p$ 的所有后代一定都已访问完毕；若 $q$ 是 $p$ 的左兄弟，则 $q$ 也会在 $p$ 之前访问完毕；但 $p$ 的祖先不可能在其之前访问。

**解题切入点**：  
看到“递归版本的后序遍历”，立刻写出递归框架：

$$
\operatorname{Post}(x):\quad \operatorname{Post}(x.l);\ \operatorname{Post}(x.r);\ \operatorname{visit}(x)
$$

当前执行到 $\operatorname{visit}(p)$ 时，相当于问：哪些结点的访问函数已经返回？从递归顺序看，$p$ 的子树结点已经访问完，$p$ 的祖先还没轮到。于是逐个判断选项即可。

**推演**：

递归后序代码如下：

```cpp
void PostOrder(Node* x) {
    if (x == NULL) return;
    PostOrder(x->left);
    PostOrder(x->right);
    visit(x);
}
```

当执行到 $\operatorname{visit}(p)$ 时：

1. **$q$ 可能是 $p$ 的后代**。  
   因为在后序中，$p$ 的左、右子树都会先于 $p$ 被遍历，所以 $p$ 的所有后代都已经完成访问。

   例如：

   ```
       p
      /
     q
   ```

   后序序列为：$q, p$。访问 $p$ 时，$q$ 的访问已完成。

2. **$q$ 可能是 $p$ 的兄弟**。  
   若 $p$ 是右孩子，$q$ 是左孩子，则遍历父结点时先遍历 $q$，再遍历 $p$。

   例如：

   ```
       r
      / \
     q   p
   ```

   后序序列为：$q, p, r$。访问 $p$ 时，$q$ 的访问已完成。

3. **$q$ 不可能是 $p$ 的祖先**。  
   若 $q$ 是 $p$ 的祖先，则 $p$ 在 $q$ 的子树中，而后序遍历一定是先访问子树中的结点，再访问根结点 $q$，所以访问 $p$ 时，$q$ 的访问函数不可能已经完成。

因此 A 错误，B、C 均可能，选 D。

**易错点**：

- 容易只想到“后序先访问后代”，忽略“左兄弟也会先访问”的情况。  
- 若说“$q$ 是 $p$ 的兄弟”，必须明确是**左兄弟**才成立；若 $q$ 是 $p$ 的右兄弟，则 $q$ 反而在 $p$ 之后访问。  
- “可能”表示只需构造出一种二叉树满足即可，不需要对所有二叉树都成立。  
- 不要把后序和前序混淆：前序中祖先先访问，后序中后代先访问。

**命题规律**：  
本题主要考查二叉树递归遍历顺序和递归调用栈的理解。常见变式有：

- 给出三种遍历的访问顺序，判断两个结点的关系；
- 结合递归工作栈，判断访问某结点时栈中有哪些结点；
- 将后序遍历与前序/中序结合，判断能否唯一确定二叉树。

复习时应熟记三种递归遍历的访问顺序，并通过画递归调用栈的方式理解“已完成访问”和“尚未完成访问”两类结点。

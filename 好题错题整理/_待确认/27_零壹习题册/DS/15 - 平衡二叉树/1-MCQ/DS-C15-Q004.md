# MCQ 第 4 题

![[_Attachments/题目识别/27_零壹习题册-题目/DS-C15-Q004_题目.png|题目]]

4. 按 2,1,6,5,4,3,7,8 的顺序给空的 AVL 树插入 8 个结点，则发生旋转的总次数为（双旋操作记为 2 次旋转）(    ).
(A) 3
(B) 4
(C) 5
(D) 6

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/DS-C15-Q004_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。插入过程发生右单旋、右-左双旋、左单旋各一次，双旋按 2 次计，总旋转次数为 $1+2+1=4$。

**解题切入点**：拿到题先定位为 AVL 插入的旋转计数。按插入顺序模拟，每次插入后从新结点向上找“最低失衡结点”，再判断失衡类型是 LL/RR 单旋还是 LR/RL 双旋。双旋要拆成两次单旋计数。

**推演**：

设平衡因子为
$$
BF(x)=h_L(x)-h_R(x),
$$
$|BF(x)|>1$ 则失衡。

1. 依次插入 $2,1,6,5$，树为：
```
  2
 / \
1   6
   /
  5
```
各结点均平衡，累计旋转次数 $0$。

2. 插入 $4$，4 成为 5 的左孩子：
```
      2
     / \
    1   6
       /
      5
     /
    4
```
最低失衡结点是 6，$BF(6)=2$，路径为“左-左”，对 6 做一次右单旋：
```
  2
 / \
1   5
   / \
  4   6
```
本次计 $1$ 次旋转，累计 $1$。

3. 插入 $3$，3 成为 4 的左孩子：
```
      2
     / \
    1   5
       / \
      4   6
     /
    3
```
最低失衡结点是 2，$BF(2)=-2$，其右孩子 5 的 $BF=1$，属于“右-左”失衡。需要先右旋 5，再左旋 2，即一次双旋：
```
      4
     / \
    2   5
   / \   \
  1   3   6
```
本次双旋按题意计 $2$ 次旋转，累计 $1+2=3$。

4. 插入 $7$，7 成为 6 的右孩子：
```
      4
     / \
    2   5
   / \   \
  1   3   6
           \
            7
```
最低失衡结点是 5，$BF(5)=-2$，其右孩子 6 的 $BF=-1$，属于“右-右”失衡，对 5 做一次左单旋：
```
      4
     / \
    2   6
   / \ / \
  1  3 5  7
```
本次计 $1$ 次旋转，累计 $3+1=4$。

5. 插入 $8$，8 成为 7 的右孩子：
```
      4
     / \
    2   6
   / \ / \
  1  3 5  7
           \
            8
```
此时各结点 $|BF|\le 1$，无需旋转。

因此总旋转次数为
$$
1+2+1=4.
$$

**易错点**：

- 双旋容易误算成 1 次。本题明确双旋记 2 次，所以不要只数“调整次数”。
- 容易选错失衡结点。应从新插入结点向上找“最低失衡结点”，不是路径上任意失衡结点都处理；最低处旋转后祖先会恢复平衡。
- LL/RR 与 LR/RL 容易混淆。看失衡结点到新插入结点路径的前两步方向：同向为单旋，反向为双旋。
- 插入过程中要同步更新高度/平衡因子，不能只看局部结点，否则会漏判旋转。

**命题规律**：考点是 AVL 树的插入调整与旋转计数。常见变式有：给插入序列求最终树形、求根结点、求旋转次数，或判断某序列是否为合法 AVL 插入过程。复习时应熟练掌握 LL、RR、LR、RL 四种调整，并注意双旋按两次单旋计；同时区分 AVL 删除可能沿祖先链多次旋转，而插入调整一次后通常不再需要向上继续旋转。

# MCQ 第 2 题

![[_Attachments/题目识别/27_零壹习题册-题目/DS-C07-Q002_题目.png|题目]]

用数组 $r$ 存储静态链表，结点的 `next` 域指向后继，工作指针 $j$ 指向链表中某结点，则 $j$ 后移的操作语句为 () .
(A) `j=r[j].next`
(B) `j=j+1`
(C) `j=j->next`
(D) `j=r[j]->next`

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/DS-C07-Q002_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A。静态链表中 `next` 域存放后继结点的数组下标（游标），所以 `j` 后移应写成 `j = r[j].next`。

**解题切入点**：  
看到“用数组 `r` 存储静态链表”和“结点的 `next` 域指向后继”，要立刻知道这是静态链表。静态链表里的“指针”不是 C 语言中的 `Node *` 地址，而是数组下标，也叫游标。因此移动工作指针时不能直接 `j++`，也不能用 `->`，而应该读取当前结点的 `next` 游标。

**推演**：  
静态链表的结点可表示为：

```c
typedef struct {
    ElemType data;
    int next;   // 后继结点在数组 r 中的下标
} Node;

Node r[MaxSize];
int j;         // 当前结点在数组 r 中的下标，即“游标”
```

当前工作指针为 $j$，它指向数组中的结点 $r[j]$。  
当前结点的后继下标存放在 $r[j].\text{next}$ 中，所以要将 $j$ 移动到后继结点，应执行：

$$
j = r[j].\text{next}
$$

选项分析：

- A：`j = r[j].next`，符合静态链表的移动方式，正确。  
- B：`j = j + 1`，只适用于顺序表；静态链表的逻辑顺序由 `next` 域决定，物理下标连续不代表逻辑相邻。  
- C：`j = j->next`，把 `j` 当成了真正的指针，不符合静态链表用数组下标表示“指针”的特点。  
- D：`j = r[j]->next`，`r[j]` 是结点对象而不是指针，不能用 `->` 访问成员。

因此选 A。

**易错点**：  
1. 误选 B：以为数组存储就可以 `j++`。静态链表虽然用数组存，但第 $i$ 个物理位置的结点不一定就是链表中第 $i$ 个逻辑结点。  
2. 误选 C：看到“指针”就用 `->`。静态链表中的“指针”是整型游标，不是地址。  
3. 误选 D：混淆结点对象与结点指针，`r[j]` 已经是对数组元素的访问，应使用 `.next` 而不是 `->next`。  
规避方法：先判断 `j` 的类型；标准静态链表中 `j` 是数组下标，移动语句一定类似：

```c
j = r[j].next;
```

**命题规律**：  
本题考查静态链表的基本操作，属于 408 数据结构中线性表的常考细节。常见变式有：静态链表的初始化、遍历、插入、删除，以及“判断某语句能否正确移动工作指针”等。复习时应重点理解：静态链表用游标代替指针，`next` 域存放后继结点下标，遍历时使用

$$
j = r[j].\text{next}
$$

而不是物理下标加一。

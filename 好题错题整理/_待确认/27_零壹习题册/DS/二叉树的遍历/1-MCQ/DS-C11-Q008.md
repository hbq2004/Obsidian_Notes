# MCQ 第 8 题

![[_Attachments/题目识别/27_零壹习题册-题目/DS-C11-Q008_题目.png|题目]]

8. 对某完全二叉树进行层次遍历，遍历到的第一个结点为根结点，若两个不同的结点 p 和 q 在层次遍历序列中的编号分别为 i 和 j，i 和 j 用 int 型变量记录，则下面说法错误的是 ( ).  
(A) 若 i 可以由 j 执行右移若干位得到，则 p 是 q 的祖先结点  
(B) 若 i 和 j 右移 1 位后结果相同，则 p 和 q 是兄弟结点  
(C) 若 p 和 q 深度相同，则一定存在正整数 k，使得 i 和 j 均右移 k 位后相等且不为 0  
(D) 若 p 和 q 深度不同，可能存在正整数 k，使得 i 和 j 均右移 k 位后相等且不为 0

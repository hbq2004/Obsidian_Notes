1. 上述程序输出的结果是什么.

```
int change_add(int &x,int y) {
    int *p= &y;
    x=3;
    *p=4;
    return x+y;
}
int main() {
    int a=1,b=2,c=0;
    c = change_add(a,b);
    printf("a=%d,b=%d,c=%d",a,b,c);
    return 0;
}
```

(A) $a=3, b=4, c=7$
(B) $a=1, b=4, c=7$
(C) $a=3, b=2, c=7$
(D) $a=1, b=2, c=5$

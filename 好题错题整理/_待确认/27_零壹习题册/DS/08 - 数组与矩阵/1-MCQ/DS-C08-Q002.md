# MCQ 第 2 题

![[_Attachments/题目识别/27_零壹习题册-题目/DS-C08-Q002_题目.png|题目]]

2. 稀疏矩阵进行存储时，所有存储信息中不是必须存在的是（）.
(A) 数据元素的行和列
(B) 数据元素的取值
(C) 矩阵的行数和列数
(D) 矩阵的非0元素个数

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/DS-C08-Q002_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。稀疏矩阵存储时，非 0 元素的行、列、值以及矩阵的总行数和总列数都是还原矩阵所必需的，而非 0 元素个数可以通过实际存储的元素个数统计出来，因此不是必须额外存储。

**解题切入点**：先问自己：给定这份存储信息，能否唯一还原出原稀疏矩阵？还原所需的“最小必要信息”是什么。就像做算法题时，如果只知道若干三元组而不知道矩阵尺寸，根本无法分配二维数组；但如果知道尺寸和三元组，元素个数自然就是三元组的条数，没必要再单独记一遍。

**推演**：

稀疏矩阵的常用存储结构是三元组表，每个非 0 元素用一个三元组 $(i,j,v)$ 表示，其中 $i$ 为行号，$j$ 为列号，$v$ 为取值。为了完整还原矩阵，还必须知道矩阵的总行数 $m$ 和总列数 $n$，否则即使有了全部三元组，也无法确定矩阵的边界。

逐一分析选项：

- (A) 数据元素的行和列：必须存在。每个非 0 元素必须记录其位置 $(i,j)$，否则无法确定该元素放在矩阵的哪个位置。
- (B) 数据元素的取值：必须存在。若不知道值，则非 0 元素的具体数值无法还原。
- (C) 矩阵的行数和列数：必须存在。只有知道了 $m$ 和 $n$，才能确定矩阵的规模，才能正确恢复出完整的矩阵。
- (D) 矩阵的非 0 元素个数：不是必须存在。因为三元组表的长度（或链表中的节点个数）本身就是非 0 元素个数，可以直接统计得到，无需额外存储。

因此，不属于“必须存在”的信息是矩阵的非 0 元素个数，选 D。

**易错点**：

1. **误以为非 0 元素个数必须存储**：很多教材在定义三元组顺序表时确实会用到 `mu`、`nu`、`tu` 三个头字段，其中 `tu` 是非 0 元素个数。但注意题目问的是“必须存在”，而不是“实际存储结构中通常有”。`tu` 是为了操作方便而附加的信息，从“还原矩阵”的角度并非必不可少。
2. **混淆“矩阵总行列数”和“每个元素的行列”**：两者都需要。前者确定矩阵形状，后者确定元素位置，缺一不可。
3. **忽略稀疏矩阵的本质**：稀疏矩阵只存非 0 元素，若丢失了某个元素的行列位置，矩阵将无法准确恢复；若丢失了总行列数，同样无法确定边界。

**命题规律**：本题属于数据结构中“特殊矩阵的压缩存储”章节，考点是稀疏矩阵存储结构的基本组成。常见变式包括：判断三元组表、十字链表、行逻辑链接等结构中哪些字段是必需的；或者给定三元组表和矩阵行列数，要求还原矩阵；也可能结合转置、相乘等算法，考查对 `mu`、`nu`、`tu` 等字段的作用的理解。复习时应重点掌握三元组表的定义、各字段含义，以及为什么需要它们，并注意区分“必需信息”和“辅助信息”。

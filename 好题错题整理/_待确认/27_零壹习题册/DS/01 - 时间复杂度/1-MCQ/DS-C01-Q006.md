# MCQ 第 6 题

![[_Attachments/题目识别/27_零壹习题册-题目/DS-C01-Q006_题目.png|题目]]

6. 现有如下代码段:
```c
int i=0;
int j=0;
while (i<n&&j<m){
    if (random_compare(i,j)||j==-1){
        i++;
        j++;
    } else {
        j=random_sub(j);
    }
}
```
其中，`random_compare` 函数是通过某种规则对两个 `int` 型参数进行比较，比较通过则返回 `true`，比较不通过返回 `false`；`random_sub` 则对传入 `int` 型参数减去某个正整数，返回值为减完后的结果，返回值最小为-1。已知 $m \leqslant n$，该算法的时间复杂度是 （ ）（提示：可以分析 $2i - j$ 的变化情况）.
(A) $O(n)$
(B) $O(mn)$
(C) $O(n\log n)$
(D) $O(n^2)$

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/DS-C01-Q006_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A（$O(n)$）。理由：每次循环体执行都会使势函数 $2i-j$ 至少增加 $1$，而 $2i-j$ 始终不超过 $O(n)$，所以总循环次数为 $O(n)$。

**解题切入点**：看到两个变量 $i,j$ 在循环中一个可能增加、一个可能先增后减，不要试图模拟 `random_compare` 和 `random_sub` 的具体行为。题目提示“分析 $2i-j$ 的变化情况”，这是典型的势能法/摊还分析：找一个单调增加且有上界的量，用它限制总执行次数。类似 KMP 匹配、双指针扫描等“看似两重循环”的问题，常用此法证明复杂度是线性的。

**推演**：令
$$
\Phi=2i-j
$$
初始时 $i=0,\ j=0$，所以 $\Phi_0=0$。

每次执行循环体有两种情况：

1. 若进入 `if` 分支：
$$
i\leftarrow i+1,\qquad j\leftarrow j+1
$$
则
$$
\Delta \Phi
= \big(2(i+1)-(j+1)\big)-(2i-j)
=1
$$

2. 若进入 `else` 分支：
由于 `random_sub` 对 $j$ 减去某个正整数，设
$$
j'=j-k,\qquad k\ge 1
$$
且此时 $i$ 不变，因此
$$
\Delta \Phi
= \big(2i-(j-k)\big)-(2i-j)
=k\ge 1
$$

所以无论函数具体如何执行，都有
$$
\Delta \Phi\ge 1
$$

再看 $\Phi$ 的上界。初始 $j=0$；`if` 分支使 $j$ 加 $1$，`else` 分支由题意保证返回值最小为 $-1$，所以始终有
$$
j\ge -1
$$
又因为循环条件为 $i<n$，$i$ 最多增加到 $n$，所以
$$
\Phi=2i-j\le 2n-(-1)=2n+1
$$

设循环体总共执行 $T$ 次，则因为每次 $\Phi$ 至少增加 $1$：
$$
\Phi_T\ge T
$$
而
$$
\Phi_T\le 2n+1
$$
因此
$$
T\le 2n+1=O(n)
$$

每次循环体只做常数次比较、减法、赋值操作，所以总时间复杂度为 $O(n)$。题目给出 $m\le n$，也进一步与选项 $O(n)$ 一致。

**易错点**：

- 容易误以为 `random_sub` 每次只减 $1$，于是每个 $i$ 都可能让 $j$ 从 $m$ 减到 $-1$，从而错选 $O(mn)$。实际上 $i$ 和 $j$ 的变化相互耦合，不能简单按“外层 $n$ 次、内层 $m$ 次”计算。
- 容易把 `random_compare` 理解成随机概率问题，去做期望分析；本题是求最坏时间复杂度，不需要知道具体比较规则，只需利用势函数 $2i-j$ 的单调性。
- 容易忽略 `||` 的短路作用：当 $j=-1$ 时一定进入 `if` 分支，$j$ 变为 $0$，因此 $j$ 不会无限减小，保证了 $j\ge -1$ 这一上界条件。

**命题规律**：本题属于时间复杂度分析中的摊还分析/势能法，本质上是 KMP 模式匹配中 $j$ 回退过程的复杂度模型。常见变式是给出类似代码：
```c
while (i < n && j < m) {
    if (j == -1 || s[i] == t[j]) {
        i++; j++;
    } else {
        j = next[j];
    }
}
```
求时间复杂度，答案通常是 $O(n+m)$，若已知 $m\le n$ 则选 $O(n)$。复习时应掌握：当某个变量“前进”时另一个“后退”，不要直接相乘，优先构造单调有界的势函数来证明线性复杂度。

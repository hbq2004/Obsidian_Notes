3. 下列程序段的时间复杂度是:

```c
sum=0;
for (int i=1;i<=n;i++){
    for (int j=1;j<=n;j++){
        sum++;
        i++;
    }
}
```

(A) $O(n)$
(B) $O(n^2)$
(C) $O(n\log n)$
(D) $O(\log n)$

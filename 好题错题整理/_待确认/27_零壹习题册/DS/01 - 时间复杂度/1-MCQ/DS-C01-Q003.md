# MCQ 第 3 题

![[_Attachments/题目识别/27_零壹习题册-题目/DS-C01-Q003_题目.png|题目]]

3. 下列程序段的时间复杂度是:

```c
sum=0;
for (int i=1;i<=n;i++){
    for (int j=1;j<=n;j++){
        sum++;
        i++;
    }
}
```

(A) $O(n)$
(B) $O(n^2)$
(C) $O(n\log n)$
(D) $O(\log n)$

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/DS-C01-Q003_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A（$O(n)$）。理由：内层循环每进入一次必执行 $n$ 次；而每次内层迭代都会把外层控制变量 $i$ 加 1，所以第一次内层循环执行完后 $i$ 已经超过 $n$，外层循环不再进入，总执行次数为 $n$。

**解题切入点**：  
看到两层 for 不能默认就是 $O(n^2)$。先检查循环控制变量有没有被循环体修改。本题内层有 `i++;`，也就是内层循环偷偷修改了外层变量 $i$。打个比方：外层循环像一个跑圈计数器，内层每跑一步都把总圈数加一，跑完内层这一圈后计数器已经超过终点，外层自然就结束了。做这类题要先找“谁控制循环、谁又被循环体改变”，不要只数嵌套层数。

**推演**：  
以 `sum++` 的执行次数作为基本操作计数。

将外层 `for` 改写成等价形式：

```c
i = 1;
while (i <= n) {
    j = 1;
    while (j <= n) {
        sum++;
        i++;
        j++;
    }
    i++;
}
```

内层循环中，$j$ 从 1 开始，每轮加 1，与 $i$ 无关，所以一旦进入内层循环，必然执行 $n$ 次。

设进入某次外层循环体时 $i = x$，则内层循环结束后：

$$
i = x + n
$$

随后外层 `for` 的增量 `i++` 还会执行一次，因此：

$$
i = x + n + 1
$$

初始时 $i = 1$，第一次进入外层循环体后：

$$
i = 1 + n + 1 = n+2
$$

第二次检查外层条件 $i \le n$ 时，$n+2 \le n$ 不成立，外层循环终止。因此外层循环体只进入 1 次。

总执行次数为：

$$
T(n) = 1 \cdot n = n
$$

所以 $T(n) = \Theta(n)$，时间复杂度为 $O(n)$，选 A。

**易错点**：  
1. 看到双层 for 直接选 $O(n^2)$：忽略了内层 `i++` 对外层变量 $i$ 的修改。  
   规避：先检查循环控制变量是否在循环体中被修改。

2. 误以为内层循环次数也受 $i$ 影响：内层条件只依赖 $j$，$j$ 每轮固定加 1，所以内层每次进入都执行 $n$ 次；真正变化的是外层进入次数。

3. 忘记外层 for 增量 `i++`：外层循环体结束后还会给 $i$ 再加 1。本题中即使不计这一步，第一次内层后 $i = n+1$ 已经使外层停止；但正确推导应算上外层增量，得到 $i = n+2$。

4. 误选 $O(n^2)$：虽然 $O(n^2)$ 作为宽松上界也成立，但题目通常要求最紧的时间复杂度，$\Theta(n)$ 才是准确答案。

**命题规律**：  
本题属于“循环变量被循环体修改”的时间复杂度分析，是 408 中常见的陷阱题。命题人常通过内层循环修改外层循环变量，或者用 `while` 循环改变控制变量，考查考生是否真正理解 for 循环的执行流程。常见变式包括：内层步长不为 1、外层条件为 $i < n$、内层使用 `i *= 2` 等。复习建议：遇到循环时先画变量变化表或写递推式，不要只看代码结构；掌握“实际执行次数”的分析方法，而不是机械记忆“双层循环就是 $O(n^2)$”。

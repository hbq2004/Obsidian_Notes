# MCQ 第 4 题

![[_Attachments/题目识别/27_零壹习题册-题目/DS-C01-Q004_题目.png|题目]]

4. 求以下代码段的时间复杂度:
```c
void foo(){
    int i,j,k; int count=0;
    for (i=1;i<=n;i+=2)
        for (j=1;j<=n;j++)
            for (k=1;k <=j;k++)
                count++;
}
```
(A) $O(n)$
(B) $O(n^2)$
(C) $O(n^3)$
(D) $O(n^2 \log n)$

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/DS-C01-Q004_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C  
一句话理由：三层循环次数分别为 $O(n)$、$O(n)$、$O(n)$，总次数为 $O(n^3)$。

**解题切入点**：  
拿到代码先看循环嵌套的层数和每层循环的上界，不要被 `i+=2`、`k<=j` 等细节干扰。这就好比数“总共执行多少次”，先数最外层有多少个“大回合”，再数每个大回合里“中回合”和“小回合”的数量，最后把三者乘起来（或求和）即可。

**推演**：  
最外层循环：`i=1; i<=n; i+=2`，所以 $i$ 取 $1,3,5,\dots$，共 $\lceil n/2\rceil$ 次，数量级为 $O(n)$。  
中间层循环：对每个 $i$，`j=1; j<=n; j++`，共 $n$ 次，数量级为 $O(n)$。  
内层循环：对每个 $j$，`k=1; k<=j; k++`，共 $j$ 次。  

因此总执行次数为：
$$
T(n)=\sum_{i=1}^{\lceil n/2\rceil}\sum_{j=1}^{n}\sum_{k=1}^{j}1
=\lceil n/2\rceil\sum_{j=1}^{n}j
=\lceil n/2\rceil\cdot \frac{n(n+1)}{2}.
$$

其最高阶项为 $\frac{n^3}{4}$，故时间复杂度为 $O(n^3)$。

**易错点**：  
1. 误把 `i+=2` 当作 $O(\log n)$：`i` 是线性递增，只是步长为 2，所以仍是 $O(n)$。  
2. 误以为 `k<=j` 导致复杂度变成 $O(n^2)$ 或 $O(n^2\log n)$：内层总次数是 $\sum_{j=1}^n j=O(n^2)$，再乘以外层 $O(n)$，结果是 $O(n^3)$。  
3. 忽略常系数：$\lceil n/2\rceil$ 的 $1/2$ 不影响渐进阶，但计算精确次数时要保留。

**命题规律**：  
本题是“嵌套循环求和”的经典题型，考查循环次数与规模 $n$ 的关系。常见变式有：改变步长（如 `i*=2`）、内层上界依赖外层（如 `j<=i`）、或者用 while 循环。复习时应掌握“逐层分析 + 求和公式”的方法，尤其是等差数列求和 $\sum_{j=1}^n j=\frac{n(n+1)}2$ 和对数循环（`i*=2` 为 $O(\log n)$）的区别。

4. 求以下代码段的时间复杂度:
```c
void foo(){
    int i,j,k; int count=0;
    for (i=1;i<=n;i+=2)
        for (j=1;j<=n;j++)
            for (k=1;k <=j;k++)
                count++;
}
```
(A) $O(n)$
(B) $O(n^2)$
(C) $O(n^3)$
(D) $O(n^2 \log n)$

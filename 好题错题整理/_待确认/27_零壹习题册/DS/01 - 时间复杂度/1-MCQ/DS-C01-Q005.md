5. 执行下列程序段中 func(n) 的时间复杂度为.
```cpp
int f1(int n){
    if (n==0) return 1;
    else return n * f1(n/2)+1;
}
int f2(int n){
    int count=0;
    for (int i=1;i<=n;i*=2)
        for (int j=1;j<=i;j++)
            for (int k=1;k<=j;k++)
                count++;
    return count;
}
int func(int n) {
    return f1(n)*f2(n)+f1(n)+f2(n);
}
```
(A) $O(n^2)$
(B) $O(n^3)$
(C) $O(n^2 \log n)$
(D) $O(n \log n)$

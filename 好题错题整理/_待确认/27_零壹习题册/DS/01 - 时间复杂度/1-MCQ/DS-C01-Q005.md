# MCQ 第 5 题

![[_Attachments/题目识别/27_零壹习题册-题目/DS-C01-Q005_题目.png|题目]]

5. 执行下列程序段中 func(n) 的时间复杂度为.
```cpp
int f1(int n){
    if (n==0) return 1;
    else return n * f1(n/2)+1;
}
int f2(int n){
    int count=0;
    for (int i=1;i<=n;i*=2)
        for (int j=1;j<=i;j++)
            for (int k=1;k<=j;k++)
                count++;
    return count;
}
int func(int n) {
    return f1(n)*f2(n)+f1(n)+f2(n);
}
```
(A) $O(n^2)$
(B) $O(n^3)$
(C) $O(n^2 \log n)$
(D) $O(n \log n)$

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/DS-C01-Q005_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A。`f1(n)` 的时间复杂度为 \(O(\log n)\)，`f2(n)\) 的时间复杂度为 \(\Theta(n^2)\)，`func` 只是先后调用 `f1` 和 `f2`，总时间复杂度取较大者，故为 \(O(n^2)\)。

**解题切入点**：先分别求两个辅助函数的时间复杂度，再合并。看到 `f2` 的三重循环不要直接认为是 \(O(n^3)\)，因为外层 \(i\) 只取 \(1,2,4,\dots\)，必须写成求和式判断；看到 `func` 中的 `f1(n)*f2(n)` 也不要误以为是嵌套调用而把复杂度相乘，两个函数是顺序执行的。

**推演**：

1. 分析 `f1(n)`：

当 \(n>0\) 时，每次递归调用 `f1(n/2)`，递归外只有一次乘法和一次加法，属于 \(O(1)\)。因此
\[
T_1(n)=T_1(\lfloor n/2\rfloor)+O(1),
\]
且 \(T_1(0)=O(1)\)。

递归深度约为 \(\lfloor \log_2 n\rfloor+1\)，所以
\[
T_1(n)=O(\log n).
\]

2. 分析 `f2(n)`：

设
\[
m=\lfloor \log_2 n\rfloor,
\]
则外层 `i` 的取值为
\[
1,2,4,\ldots,2^m.
\]

对于某个固定的 \(i=2^t\)，中间层 `j` 从 \(1\) 取到 \(i\)，内层 `k` 从 \(1\) 取到 \(j\)，因此内层 `count++` 的执行次数为
\[
\sum_{j=1}^{i}j=\frac{i(i+1)}2
=\frac{2^t(2^t+1)}2.
\]

所以 `f2(n)` 的总执行次数为
\[
\begin{aligned}
T_2(n)
&=\sum_{t=0}^{m}\frac{2^t(2^t+1)}2\\
&=\frac12\sum_{t=0}^{m}(4^t+2^t)\\
&=\frac{4^{m+1}-1}{6}+\frac{2^{m+1}-1}{2}.
\end{aligned}
\]

因为
\[
2^m\le n<2^{m+1},
\]
所以
\[
4^m=\Theta(n^2).
\]
故
\[
T_2(n)=\Theta(n^2).
\]

3. 分析 `func(n)`：

```cpp
return f1(n)*f2(n)+f1(n)+f2(n);
```

该表达式会执行 `f1` 两次、`f2` 两次，另有常数次算术运算。因此
\[
T_{\text{func}}(n)=2T_1(n)+2T_2(n)+O(1).
\]

代入得
\[
T_{\text{func}}(n)=O(\log n)+O(n^2)=O(n^2).
\]

所以选 **A**。

**易错点**：

- 容易把 `f2` 误判为 \(O(n^2\log n)\) 或 \(O(n^3)\)。原因是没有利用外层 \(i\) 只取 \(2^t\) 的特点，而是粗略地把每层循环都当成 \(n\)。
- 容易把 `func` 中的 `f1(n)*f2(n)` 理解为嵌套调用，从而把复杂度相乘。实际上函数调用是顺序执行，总复杂度应相加。
- 容易把 `f1` 的每次递归工作量误写成 \(O(n)\)。`n * f1(n/2)+1` 中乘法和加法在 408 中按基本运算 \(O(1)\) 处理，所以 \(T_1(n)=T_1(n/2)+O(1)\)。
- 若考虑大整数乘法，问题会变复杂，但考研 408 中默认基本算术运算时间为 \(O(1)\)。

**命题规律**：本题核心是“递归函数 + 多重循环”的渐近复杂度分析。常见变式包括：将 `f2` 外层改为 `i++`，则总次数为 \(\sum_{i=1}^{n} i(i+1)/2=\Theta(n^3)\)；将 `f2` 最内层去掉，则总次数为 \(\sum_{t=0}^m 2^t=\Theta(n)\)。复习时应把循环次数写成求和式，用等比级数估计；递归复杂度则用递推式或主定理分析。

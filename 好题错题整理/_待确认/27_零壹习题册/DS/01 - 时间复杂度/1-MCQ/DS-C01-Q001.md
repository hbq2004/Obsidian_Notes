# MCQ 第 1 题

![[_Attachments/题目识别/27_零壹习题册-题目/DS-C01-Q001_题目.png|题目]]

1. 下列代码的时间复杂度是多少?

```c
for (int i=1;i<=n;i*=2)
    for (int j=0;j<=i;j++)
        count++;
```

(A) $O(n)$

(B) $O(n \log n)$

(C) $O(\log n)$

(D) $O(n^2)$

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/DS-C01-Q001_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：A（$O(n)$）。外层循环 $i$ 按 $1,2,4,\dots$ 倍增，共约 $\log_2 n + 1$ 次；内层循环次数为 $i+1$。总执行次数为 $\sum_{i=1,2,4,\dots}^{\le n}(i+1)$，这是一个等比数列求和，其数量级由最大项 $n$ 主导，因此总时间复杂度为 $O(n)$。

**解题切入点**：看到嵌套循环，先不要急着“外层 $\log n$ 次，内层 $n$ 次”直接乘。要写出内层循环次数关于外层变量的表达式。这里内层次数是 $i+1$，而 $i$ 是以指数速度增长，所以总和是“等比数列”而不是“等差数列”。从直觉上类比：你每天走的路程翻倍，一周总路程约等于最后一天路程的两倍，而不是“天数乘最后一天路程”。因此不要用“平均次数 $\times$ 总层数”来估算，要用求和公式。

**推演**：  
设外层第 $k$ 次循环时，$i = 2^k$（$k=0,1,2,\dots$）。由于循环条件是 $i \le n$，最大 $k$ 满足 $2^k \le n$，即 $k_{\max} = \lfloor \log_2 n \rfloor$。  
内层循环从 $j=0$ 到 $j=i$，共执行 $i+1 = 2^k + 1$ 次。  
总执行次数：
$$
T(n) = \sum_{k=0}^{\lfloor \log_2 n \rfloor} (2^k + 1)
= (2^{\lfloor \log_2 n \rfloor + 1} - 1) + (\lfloor \log_2 n \rfloor + 1)
$$
由于 $2^{\lfloor \log_2 n \rfloor} \le n < 2^{\lfloor \log_2 n \rfloor + 1}$，所以 $2^{\lfloor \log_2 n \rfloor + 1} < 2n$。因此：
$$
T(n) < 2n + \log_2 n + O(1)
$$
故 $T(n) = O(n)$。

**易错点**：  
1. **误算为 $O(n\log n)$**：只看到外层 $\log n$ 次、内层最坏 $n$ 次，于是相乘。但内层次数不是恒定的 $n$，而是随 $i$ 线性变化，且 $i$ 呈指数增长，总和由最大项 $n$ 主导，而不是“平均 $n/2$ 乘以 $\log n$”（虽然平均是 $O(n/\log n)$，但乘起来仍是 $O(n)$）。  
2. **忽略常数项**：内层是 `j<=i`，所以是 $i+1$ 次，不是 $i$ 次，但不影响渐近复杂度。  
3. **混淆外层循环变量变化方式**：如果外层是 `i++`，内层 `j<=i`，则是 $1+2+\dots+n=O(n^2)$；但本题外层是 `i*=2`，因此是等比数列，切不可套用等差数列求和。

**命题规律**：这道题是时间复杂度分析的经典变式，考查“循环变量按比例变化时不能直接相乘”的思维。常见变式：  
- 外层 `for(i=1;i<=n;i*=2)` 内层 `for(j=0;j<=i;j++)`，答案 $O(n)$（本题）。  
- 若内层改为 `for(j=0;j<=n;j++)`，则总次数为 $\log_2 n \times (n+1)$，答案变为 $O(n\log n)$。  
- 若外层 `i+=k`（常数），内层 `j<=i`，则为 $O(n^2)$。  
- 若外层 `i*=2`，内层 `j*=2` 或 `j<=i` 但每次 `j+=2`，本质仍看内层总次数是否构成等比数列。  
记住口诀：**外层倍增，内层与当前 $i$ 相关时，总代价 = 最大项 $\times$ 常数因子，通常就是 $O(n)$；若内层与 $n$ 无关且固定规模，则看循环嵌套相乘。** 这类题在408中常以选择或填空形式出现，要求快速判断，不要展开求和，只需抓住主导项。

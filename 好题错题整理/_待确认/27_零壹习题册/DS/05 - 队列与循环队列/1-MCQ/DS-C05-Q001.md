# MCQ 第 1 题

![[_Attachments/题目识别/27_零壹习题册-题目/DS-C05-Q001_题目.png|题目]]

1. 与普通数组实现的队列相比，循环队列的“循环”设计的主要优势是 ( ). 
(A) 更好地入队和出队性能 
(B) 提供更大的实际容量
(C) 避免数组队列的假溢出 
(D) 易于判断队满和队空

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/DS-C05-Q001_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。循环队列通过逻辑上首尾相接的存储空间，解决了普通顺序队列中队尾已满但队首仍有空闲时无法继续入队的“假溢出”问题。

**解题切入点**：拿到本题，先明确比较对象是“普通数组实现的队列”与“循环队列”。普通顺序队列的致命短板是出队后队首位置空出，但队尾指针已到数组末端，新元素无法插入，即“假溢出”。循环队列正是针对这一问题设计，用取模运算让队尾指针绕回数组开头。这就像环形跑道上的接力区，跑完一圈还能重复使用前面的区域，而不是跑到终点就只能停下。

**推演**：

普通顺序队列用数组 $Q[0..n-1]$ 和队首、队尾指针 $front, rear$ 实现。初始时 $front = rear = 0$。入队：
$$
Q[rear] = x;\quad rear = rear + 1
$$
出队：
$$
x = Q[front];\quad front = front + 1
$$

当连续入队使 $rear = n$ 时，即使 $front > 0$（队首已有元素出队腾出空间），也无法再入队，因为 $rear$ 已到数组末尾。此时数组前部仍有空闲位置，但逻辑上队列已“满”，这种现象称为假溢出。

循环队列将数组视为首尾相接的环，入队和出队时指针均做取模运算：
$$
rear = (rear + 1) \% n,\qquad front = (front + 1) \% n
$$

当普通队列出现 $rear = n$ 且 $front > 0$ 时，循环队列会让 $rear$ 回到 $0$，继续使用下标 $0$ 到 $front-1$ 之间的空闲单元。因此，只要队列中实际元素个数小于数组容量，循环队列就能继续入队，从而彻底避免了假溢出。

需注意，循环队列本身仍可能真溢出：当 $(rear+1) \% n = front$ 时队列满，即实际元素个数达到 $n-1$（若牺牲一个存储单元区分队空队满）。它并不提供更大的实际容量，也不能天然改善入队出队的时间复杂度（入队出队仍为 $O(1)$）。至于“易于判断队满和队空”，循环队列反而因为取模后指针关系复杂，需要额外约定（如牺牲一个空格、设标志位或记录元素个数）来判断，这并非其设计优势。

**易错点**：

1. **混淆“假溢出”与“真溢出”**：假溢出是数组前部有空间但因指针到末尾而无法使用；真溢出是数组空间确实全部占满。循环队列解决的是假溢出，无法避免真溢出。
2. **误选 A**：循环队列的入队出队仍是 $O(1)$，与普通数组队列相同；若取模运算使用除法，甚至可能略慢一点，因此“更好性能”不是主要优势。
3. **误选 B**：循环队列没有扩大数组大小，只是循环复用已有空间，实际容量不可能超过数组大小。
4. **误选 D**：恰恰相反，循环队列判断队满和队空比普通队列更复杂，普通队列只需看 $rear == n$ 或 $front == rear$ 即可；循环队列需用牺牲一个单元、计数器或标志位等方式辅助判断。
5. **审题不清**：题干问“主要优势”，应直接定位到循环队列设计的根本目的——解决假溢出，而不是纠缠实现细节。

**命题规律**：本题属于数据结构中“队列”基础概念的考查，常以选择题形式出现。高频考点包括：
- 循环队列判满/判空的条件（牺牲一个单元时：队空 $front == rear$，队满 $(rear+1)\%n == front$）；
- 循环队列中元素个数的计算：$(rear - front + n) \% n$；
- 入队、出队操作的指针变化；
- 循环队列与链式队列的对比（链式队列无需循环也不会假溢出，但需额外指针存储）。

复习建议：务必亲手画图模拟循环队列的入队出队过程，尤其注意指针回绕与判满判空的边界条件；同时将顺序队列、循环队列、链式队列三者对比记忆，明确各自优缺点。这类题难度不大，关键是理解“循环”二字的本质是对下标取模，而非扩容或提速。

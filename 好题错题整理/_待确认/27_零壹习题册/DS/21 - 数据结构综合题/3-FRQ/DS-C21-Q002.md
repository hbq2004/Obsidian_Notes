# FRQ 第 2 题

![[_Attachments/题目识别/27_零壹习题册-题目/DS-C21-Q002_题目.png|题目]]

2. 顺序表扩容  
用数组实现存放 int 型数据的顺序表时，顺序表的结构如下所示：  
```c
struct Sqlist {
    int* start;    // 顺序表首元素指针
    int maxsize;   // 当前为顺序表分配的内存大小
    int length;    // 顺序表实际长度
};
```  
现定义了某 Sqlist 型变量 L，请回答下面的问题：  
(1) 请写出将该顺序表的第 $k$ 个元素（从 1 开始计数）赋值给变量 $a$ 的代码.  
(2) 当插入某元素时，发现顺序表实际长度即将超过为顺序表分配的容量时，需要对顺序表进行扩容，扩容思路为：开辟一块长度为当前 maxsize 两倍的内存空间分配给当前顺序表. 请给出该过程的主要代码.  
(3) 若采用 (2) 中方案进行扩容，现从空顺序表开始连续插入 $n$ 个元素，当 $n$ 足够大时，插入 $n$ 个元素的时间复杂度是多少?

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/DS-C21-Q002_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：本题非选择题。按“尾部追加/动态数组 `push_back`”理解：

(1) 代码：
```c
a = L.start[k - 1];
```
严谨写法：
```c
if (k >= 1 && k <= L.length)
    a = L.start[k - 1];
```

(2) 扩容主要代码：
```c
void expandSqlist(struct Sqlist *L) {
    // 设初始 maxsize > 0
    int newMax = L->maxsize * 2;
    int *newbase = (int *)malloc((size_t)newMax * sizeof(int));
    if (newbase == NULL) {
        // 内存分配失败处理，这里直接退出
        exit(1);
    }
    for (int i = 0; i < L->length; ++i)
        newbase[i] = L->start[i];   // 复制旧元素
    free(L->start);                  // 释放旧空间
    L->start = newbase;
    L->maxsize = newMax;
}

// 插入元素前判断：
if (L.length == L.maxsize)
    expandSqlist(&L);
```
扩容时 `L.length` 不变。

(3) 插入 $n$ 个元素的总时间复杂度为  
\[
O(n)
\]
均摊到单次插入为  
\[
O(1)
\]
理由：容量按两倍增长时，扩容引起的复制总量是等比级数，不超过 $2n$，其余尾部插入每次为 $O(1)$。

---

**解题切入点**：

看到 `start`、`maxsize`、`length` 三个字段，应立刻识别为“动态数组实现的顺序表”。第 (1) 题考逻辑位序与数组下标相差 $1$；第 (2) 题考扩容流程“申请新空间—复制旧元素—释放旧空间—更新字段”；第 (3) 题考动态顺序表尾部插入的均摊复杂度。

可以把扩容类比为“搬家换大房子”：每次新房面积翻倍，虽然某次搬家要搬很多东西，但总搬家成本摊到每次入住是常数。

---

**推演**：

### (1) 第 $k$ 个元素赋值给 $a$

C 语言数组下标从 $0$ 开始，题目中第 $k$ 个元素从 $1$ 开始计数，所以第 $k$ 个元素对应物理下标 $k-1$：

\[
a = L.start[k-1]
\]

### (2) 扩容过程

插入元素前发现 `L.length == L.maxsize`，说明当前表已满，无法再放下一个元素，需要扩容。

扩容步骤：

1. 申请新空间：`newMax = 2 * maxsize`；
2. 把原来的 `length` 个元素复制到新空间；
3. 释放旧空间；
4. 更新 `start` 和 `maxsize`。

注意：`length` 是实际元素个数，扩容不改变 `length`。

### (3) 均摊时间复杂度分析

设初始容量为 $m>0$，扩容后容量依次为：

\[
m,\ 2m,\ 4m,\ \ldots,\ 2^q m
\]

插入第 $n$ 个元素时，若共触发 $q$ 次扩容，则第 $i$ 次扩容前容量为 $2^{i-1}m$，扩容时需要复制的元素个数就是该容量，因此总复制量为：

\[
S(n)=m+2m+4m+\cdots+2^{q-1}m
\]

这是等比数列求和：

\[
S(n)=\frac{m(2^q-1)}{2-1}=(2^q-1)m
\]

因为触发第 $q$ 次扩容时，必有：

\[
2^{q-1}m<n
\]

所以：

\[
2^q m<2n
\]

因此：

\[
S(n)<2n
\]

即扩容复制总代价为：

\[
O(n)
\]

普通尾部插入 $n$ 次本身每次 $O(1)$，总代价也是 $O(n)$，所以：

\[
T(n)=O(n)+O(n)=O(n)
\]

均摊到单次插入：

\[
\frac{T(n)}{n}=O(1)
\]

注意：如果“连续插入”指任意位置插入，则还要加上元素移动的代价；例如每次插在表头，总移动次数为

\[
\sum_{i=1}^{n}(i-1)=\frac{n(n-1)}2=O(n^2)
\]

所以 $O(n)$ 的结论对应的是扩容场景下的表尾追加。

---

**易错点**：

- 第 $k$ 个元素误写成 `L.start[k]`，应写成 `L.start[k-1]`。
- 扩容时先 `free(L.start)` 再复制旧元素，会导致“野指针”错误；必须先复制，再释放。
- 扩容后忘记更新 `maxsize`，或者误改 `length`。
- `malloc` 申请空间时忘记乘以 `sizeof(int)`，导致空间不足。
- 错误估计复杂度为 $O(n\log n)$：虽然扩容次数是 $O(\log n)$，但每次复制量递增，等比级数求和后是 $O(n)$。
- 若初始 `maxsize = 0`，翻倍后仍为 $0$，会无限扩容，应保证初始容量为正数。

---

**命题规律**：

本考点属于 DS 中“线性表—顺序表”部分，常考：

1. 顺序表元素下标与逻辑序号关系；
2. 动态扩容的代码实现；
3. 均摊时间复杂度分析。

常见变式：

- 给出初始容量 $m$，求插入 $n$ 个元素时的总复制次数；
- 将“容量加倍”改为“容量固定增加 $c$”，此时总复制量会退化为 $O(n^2)$；
- 将“尾部插入”改为“头部插入”，需额外计算移动元素代价；
- 结合 C++ `vector` 扩容后迭代器失效等问题。

复习建议：把动态顺序表的“申请—复制—释放—更新”流程写熟练，并记住结论：

\[
\text{倍增扩容，连续表尾插入 } n \text{ 个元素的总时间为 } O(n)
\]

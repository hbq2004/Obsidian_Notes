2. 顺序表扩容  
用数组实现存放 int 型数据的顺序表时，顺序表的结构如下所示：  
```c
struct Sqlist {
    int* start;    // 顺序表首元素指针
    int maxsize;   // 当前为顺序表分配的内存大小
    int length;    // 顺序表实际长度
};
```  
现定义了某 Sqlist 型变量 L，请回答下面的问题：  
(1) 请写出将该顺序表的第 $k$ 个元素（从 1 开始计数）赋值给变量 $a$ 的代码.  
(2) 当插入某元素时，发现顺序表实际长度即将超过为顺序表分配的容量时，需要对顺序表进行扩容，扩容思路为：开辟一块长度为当前 maxsize 两倍的内存空间分配给当前顺序表. 请给出该过程的主要代码.  
(3) 若采用 (2) 中方案进行扩容，现从空顺序表开始连续插入 $n$ 个元素，当 $n$ 足够大时，插入 $n$ 个元素的时间复杂度是多少?

# MCQ 第 3 题

![[_Attachments/题目识别/27_零壹习题册-题目/CO-C06-Q003_题目.png|题目]]

3. 下列关于总线传输方向的叙述中，正确的是（ ）.
(A) 地址信息通常由主存送往 CPU
(B) 数据总线通常只能由 CPU 向外传送数据
(C) 控制总线中的各根信号线方向通常固定
(D) 状态信息通常由 CPU 送往外设

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/CO-C06-Q003_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。控制总线中每一根信号线（如读信号、写信号、中断请求等）的方向在连接时已经规定好，通常固定；其他选项方向均说反了。

**解题切入点**：看到四个选项都在说“信息从哪一方送到哪一方”，就应定位到“系统总线按信息类型划分后的方向”考点。可以类比为一次网络请求：地址是用户发给服务器的目标定位信息；数据是服务器和用户之间双向传输的载荷；而每个控制字段（如请求、应答）的发送方是协议规定死的，方向固定。于是先回忆三类总线：地址线、数据线、控制线的方向特点。

**推演**：设总线上连接 CPU、主存和 I/O 设备（接口）。

1. 地址信息：CPU 访问主存或 I/O 端口时，需要把地址放到地址总线上。因此地址信息通常由 CPU 送往主存或 I/O 接口，而不是由主存送往 CPU。  
   所以 A 错误。

2. 数据信息：数据总线用于在 CPU、主存、I/O 之间交换数据。例如 CPU 读主存时数据由主存送到 CPU，CPU 写主存时数据由 CPU 送到主存；与 I/O 设备交换数据时方向也可双向。因此“数据总线只能由 CPU 向外传送数据”错误。  
   所以 B 错误。

3. 控制信息：控制总线中既可能有 CPU 发出的控制信号，如读命令 $\overline{RD}$、写命令 $\overline{WR}$、存储器请求 $\overline{MREQ}$ 等，也可能有外设/主存发给 CPU 的信号，如中断请求 $\overline{INTR}$、就绪信号 $\overline{READY}$ 等。对某一根具体的控制线而言，它由固定的一方发出，方向是固定的；不同控制线的方向可以不同。  
   所以 C 正确。

4. 状态信息：I/O 设备或接口的状态（如忙、就绪、错误）应送往 CPU，供 CPU 查询或触发中断处理，而不是由 CPU 送往外设。  
   所以 D 错误。

因此正确选项是 **C**。

**易错点**：
- 误选 A：把地址信息当成“从主存取来的信息”。地址是 CPU 给出的访问目标，不是主存中的数据。CPU 从主存读出的是数据/指令，不是地址。
- 误选 B：只看 CPU 发出写命令的方向，忽略 CPU 还需要读主存、读外设，数据总线是双向的。
- 误选 D：混淆“控制信息”和“状态信息”。控制信息（如启动、停止）由 CPU 送往外设；状态信息（如忙、就绪）由外设送往 CPU。
- 对 C 的疑虑：控制总线整体看起来有进有出，于是以为方向不固定。实际上“每根控制线方向固定”与“控制总线整体包含多个不同方向的控制线”并不矛盾。

**命题规律**：考点定位在计算机组成原理“总线”章节中的系统总线分类，属于基础概念题。常见变式包括：判断地址总线/数据总线/控制总线的方向；给出具体信号名让考生判断发送方；结合总线周期判断读/写操作时各类信号线的时序；以及 DMA 等特殊情况下地址线可由 DMA 控制器驱动。复习时建议画一张 CPU—总线—主存/IO 的方向图，熟记：地址线为单向、数据线为双向、控制线每根方向固定但整体方向多样；同时记住常用控制信号（读、写、中断请求、就绪）的来源与去向。

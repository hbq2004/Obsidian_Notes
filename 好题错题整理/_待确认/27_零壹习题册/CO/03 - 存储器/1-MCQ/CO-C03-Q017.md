# MCQ 第 17 题

![[_Attachments/题目识别/27_零壹习题册-题目/CO-C03-Q017_题目.png|题目]]

17. 下列关于 $Cache$ 的说法中，正确的是 （  ）.
①$Cache$ 通常由 $SRAM$ 构成，主要用于缓解 $CPU$ 与主存速度不匹配.
②$Cache$ 可以扩展 $CPU$ 的可寻址主存空间，因此 $Cache$ 越大，程序可访问地址越多.
③$Cache$ 行通常与主存块大小相同，是 $Cache$ 与主存之间交换数据的单位.
④$Cache$ 中除了数据部分以外，还需要保存 $Tag$、有效位等标记信息. 若采用回写法，通常还需要脏位.
⑤$Cache$ 缺失时，系统通常只把被访问的存储单元装入 $Cache$，而不是装入主存块.
(A) ①③④
(B) ①②③
(C) ②④⑤
(D) ①③⑤

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/CO-C03-Q017_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A（①③④正确）。  
一句话理由：②错在 Cache 不能扩展 CPU 可寻址的主存空间；⑤错在 Cache 缺失时应装入整个主存块，而不是只装入被访问的存储单元。

**解题切入点**：这类组合判断题先抓“绝对化/偷换概念”的选项。  
可以这样想：Cache 是“主存副本的高速缓存”，不是 CPU 可直接扩展的地址空间；缺失装入的粒度是“块”，不是“字”。②和⑤明显违背这两个基本结论，直接排除，剩下选 A。

**推演**：

① 正确。  
Cache 通常由 $SRAM$ 构成，$SRAM$ 速度比主存所用的 $DRAM$ 快，但成本高、集成度低。它位于 CPU 与主存之间，用于缓解 CPU 与主存速度不匹配的矛盾。

② 错误。  
CPU 的可寻址主存空间由 CPU 地址线位数或地址空间大小决定。若地址位数为 $n$，则可寻址空间为 $2^n$。Cache 容量 $C$ 无论多大，都不会改变这个上限。Cache 中存放的只是主存中某些块的副本，对程序员透明，不能“扩大可寻址主存空间”。  
因此，“Cache 越大，程序可访问地址越多”是错误的。

③ 正确。  
Cache 与主存之间以“块”为交换单位。一个 Cache 行（Cache line）中数据部分的大小通常与一个主存块的大小相同，记为 $B$。设主存块大小为 $B$，Cache 行数据区大小也为 $B$。

④ 正确。  
每个 Cache 行除了数据部分，还需要保存：

- 有效位：表示该行是否存放了有效数据；
- Tag（标记）：用于判断 Cache 行中的数据是否来自当前访问的主存块；
- 脏位：若采用回写法，Cache 行被替换时如果数据被修改过，需要写回主存，因此需要脏位。

若采用写直达法，则不一定要脏位，因为每次写操作都同时写主存。

⑤ 错误。  
依据空间局部性，Cache 缺失时，不是只把被访问的存储单元装入 Cache，而是把包含该存储单元的整个主存块装入 Cache。  
即交换单位是“主存块”，不是“存储单元/字”。

综上，正确的说法是 ①③④，对应选项 A。

**易错点**：

- 容易误认为 ⑤ 正确：有人觉得“缺谁装谁”更合理，但 Cache 利用空间局部性，必须整块装入，否则命中率会大幅下降。
- 容易误认为 ② 正确：混淆“Cache 容量大”与“主存地址空间大”。Cache 是副本，不是可寻址主存本身。
- 容易漏选 ④ 中的脏位：脏位仅在回写法下需要；若是写直达法，则不必为每个 Cache 行设脏位。
- 需要注意“Cache 行”与“主存块”的关系：二者数据区大小相同，但 Cache 行还包含 Tag、有效位等开销。

**命题规律**：  
本题属于 408 中 Cache 基础概念的常考题型，考查对 Cache 组成、地址映射、缺失处理、写策略的理解。常见变式有：

- 给出 Cache 容量、块大小、地址位数，计算 Tag 位数、Cache 行数；
- 判断回写法与写直达法在缺失/命中时的处理差异；
- 考查缺块时“装入整个主存块”这一局部性原理。

复习建议：把 Cache 的“地址映射方式、块大小、命中判断、替换算法、写策略”串成一条线理解，尤其要分清“Cache 容量”与“主存地址空间”是两个独立概念。

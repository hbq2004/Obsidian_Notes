# MCQ 第 2 题

![[_Attachments/题目识别/27_零壹习题册-题目/CO-C03-Q002_题目.png|题目]]

2. 下列关于 ROM 说法中错误的有 （ ） 个.

①ROM 采用随机存取方式进行信息的访问，属于随机存储器
②传统 ROM（MROM）与 PROM 都由生产车间写入，用户不能修改
③EPROM 与 EEPROM 都可以反复擦除多次，但 EEPROM 不需要每次擦除芯片上的所有信息
④Flash 存储器读写速度差距很大，SSD 写的速度比 Flash 快的多，跟 RAM 差不多
⑤ROM 断电后信息可以一直保留，常用于构成主存的 bios 以及外存

(A) ②③④⑤
(B) ①②③⑤
(C) ②④⑤
(D) ①②⑤

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/CO-C03-Q002_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C（②④⑤）。逐项判断后，①③正确，②④⑤错误，因此错误说法共有 3 个。

**解题切入点**：拿到题目先定位考点为“ROM 的分类与特性”，在脑中画出存储器的分类树：随机存取、只读、顺序存取等，再逐项核对每种 ROM 的写入方式、擦除方式、易失性与典型用途。就像算法竞赛做枚举题：先圈出每个选项中的“关键词”，再与已知结论严格匹配，从而快速排除。

**推演**：

1. ①“ROM 采用随机存取方式进行信息的访问，属于随机存储器”  
  随机存取（Random Access）指访问任意地址的存储单元所需时间与地址无关。ROM 的读取同样是按地址直接访问，满足随机存取方式。广义上，随机存储器泛指可随机访问的存储器，RAM 与 ROM 均属于此类。故 ① 正确。  
  （注意：若将“随机存储器”狭义限定为 RAM，则会产生争议；但本题选项设计表明 ① 是正确的。）

2. ②“传统 ROM（MROM）与 PROM 都由生产车间写入，用户不能修改”  
  MROM（掩膜 ROM）由生产厂用掩膜工艺写入，出厂后用户不可修改。  
  PROM（可编程只读存储器）则由用户使用专用编程器一次性写入，写入后不可再改，但并非生产车间写入。  
  因此“都由生产车间写入，用户不能修改”错误，② 错误。

3. ③“EPROM 与 EEPROM 都可以反复擦除多次，但 EEPROM 不需要每次擦除芯片上的所有信息”  
  EPROM（紫外线擦除可编程只读存储器）需用紫外线照射整个芯片进行全片擦除，可多次擦写。  
  EEPROM（电可擦除可编程只读存储器）通过电信号即可擦除，且可按字节擦除，不必全片擦除。  
  故 ③ 正确。

4. ④“Flash 存储器读写速度差距很大，SSD 写的速度比 Flash 快的多，跟 RAM 差不多”  
  Flash（闪存）是 EEPROM 的一种，读速度比写速度快，差距较大，这一部分正确。  
  但 SSD 本身是以 Flash 为存储介质构成的，其写速度受 Flash 芯片物理特性、控制器与接口限制，不可能比 Flash 本身“快得多”，更不可能与 RAM 相当：RAM 随机访问延迟为纳秒级，SSD 的写延迟通常在微秒甚至毫秒级。  
  因此 ④ 错误。

5. ⑤“ROM 断电后信息可以一直保留，常用于构成主存的 bios 以及外存”  
  ROM 是非易失性存储器，断电后信息不会丢失；主板上的 BIOS 常固化在 ROM（现代多用 Flash ROM）中。  
  但 ROM 一般用于存放固件或系统引导程序，属于主存的一部分，而不是外存。外存（硬盘、U盘、光盘等）中的 U 盘或 SSD 使用 Flash，但 Flash 是闪存，不能笼统说“ROM 构成外存”。  
  故 ⑤ 错误。

综上，错误说法为 ②④⑤，共 3 个，对应选项 C。

**易错点**：

- 误判 ① 为错误：容易将“随机存储器”狭义理解为 RAM，忘记 ROM 也是“随机存取方式”。
- 误以为 PROM 同样由生产车间写入：PROM 是用户可编程一次写入的，不是出厂时写好的。
- 混淆 EPROM 与 EEPROM 的擦除方式：EPROM 需紫外线全片擦除，EEPROM 可电擦除且支持按字节擦除。
- 对 Flash 与 SSD 的关系不清：SSD 内部就是 Flash 芯片，其写速度不可能接近 RAM。
- 将 ROM 与外存混为一谈：ROM 用于存放 BIOS 等固件，属于主存；外存中的 Flash 不能等同于传统 ROM。

**命题规律**：  
考点定位为计算机组成原理中“存储器的层次与分类”，尤其常考 ROM 的分类（MROM、PROM、EPROM、EEPROM、Flash）及其写入/擦除方式、易失性和典型用途。  
常见变式：判断各种 ROM 的特性；选择适合存放 BIOS 或固件的存储器；比较 RAM、ROM、Flash 的读写速度；或者将本题与“存储系统”层次结构结合考查。  
复习建议：整理存储器分类树，熟记各类存储器的写入方式、擦除单位、是否易失、典型应用，并注意区分“随机存取”的广义含义与狭义 RAM 的区别；做历年真题时，重点关注选项中的绝对化表述（如“都”“不可能”“差不多”）。

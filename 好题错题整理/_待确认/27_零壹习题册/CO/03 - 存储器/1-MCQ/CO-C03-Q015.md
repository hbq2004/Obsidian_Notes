# MCQ 第 15 题

![[_Attachments/题目识别/27_零壹习题册-题目/CO-C03-Q015_题目.png|题目]]

15. C 语言数据按行优先存储。`int a[8][16][4]` 连续存放，每个 `int` 4B，下列访问方式中空间局部性最好的是（   ）.

(A)
```
for(i=0;i<8;i++) for(j=0;j<16;j++) for(k=0;k<4;k++) sum+=a[i][j][k];
```

(B)
```
for(k=0;k<4;k++) for(j=0;j<16;j++) for(i=0;i<8;i++) sum+=a[i][j][k];
```

(C)
```
for(j=0;j<16;j++) for(k=0;k<4;k++) for(i=0;i<8;i++) sum+=a[i][j][k];
```

(D)
```
for(i=0;i<8;i++) for(k=0;k<4;k++) for(j=0;j<16;j++) sum+=a[i][j][k];
```

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/CO-C03-Q015_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A。A 的循环顺序 $i,j,k$ 正好使第三个下标 $k$ 变化最快，与 C 语言按行优先存储的地址递增顺序一致，访问地址连续，空间局部性最好。

**解题切入点**：  
拿到多维数组访问题，先写地址公式，看“最内层循环变量”变化时地址跳多少。空间局部性看的是相邻两次访问地址是否靠近。C 语言按行优先存储时，**最后一个下标在内存中变化最快**。可以把数组看成一本按顺序装订的书：A 是从第 1 页依次读到最后一页，其他选项是跳着读。

**推演**：  
设 `base` 为 `a[0][0][0]` 的地址。因为 `int a[8][16][4]` 按行优先连续存放，且 `sizeof(int)=4`，所以

$$
\operatorname{addr}(a[i][j][k])
=\mathrm{base}+\bigl((i\cdot 16+j)\cdot 4+k\bigr)\cdot 4
=\mathrm{base}+256i+16j+4k\ \text{B}.
$$

因此：

- $k$ 增加 1，地址增加 $4$ B；
- $j$ 增加 1，地址增加 $16$ B；
- $i$ 增加 1，地址增加 $256$ B。

所以内存地址递增顺序应该是：$k$ 最快，$j$ 次之，$i$ 最慢。

A 的循环结构是：

```c
for (i = 0; i < 8; i++)
    for (j = 0; j < 16; j++)
        for (k = 0; k < 4; k++)
            sum += a[i][j][k];
```

其中内层是 $k$，正好对应地址增量最小的下标。更准确地说，A 的线性元素下标

$$
m=(i\cdot16+j)\cdot4+k
$$

每次循环都严格加 1，地址就是 $\mathrm{base}+4m$，因此整个数组被**按存储顺序连续访问**，空间局部性最好。

其他选项：

- B、C：最内层都是 $i$，$i$ 增加 1 时地址跳 $256$ B，空间局部性差；
- D：最内层是 $j$，$j$ 增加 1 时地址跳 $16$ B，有一定局部性，但不如 A 的连续 $4$ B 访问好。

| 选项 | 最内层变化下标 | 相邻访问地址增量 | 空间局部性 |
|---|---|---|---|
| A | $k$ | $+4$ B | 最好 |
| B | $i$ | $+256$ B | 差 |
| C | $i$ | $+256$ B | 差 |
| D | $j$ | $+16$ B | 不如 A |

**易错点**：  
1. 误以为“行优先”就是第一个下标变化最快。实际上 C 语言中**最后一个下标变化最快**。  
2. 忘记乘以 `sizeof(int)=4`。虽然比较相对大小可以不乘，但算字节地址时必须乘。  
3. 只注意外层循环，忽略内层循环。空间局部性主要由**最内层相邻两次访问的地址跨度**决定。  
4. 不要把空间局部性和时间局部性混淆。本题中每个元素只访问一次，重点看地址是否连续。

**命题规律**：  
本题属于计算机组成原理中“存储层次与 Cache 局部性”的经典考法，常与多维数组地址计算结合。常见变式有：

- 二维数组按行/列优先存储，比较不同循环顺序的 Cache 命中率；
- 给定 Cache 行大小、映射方式，计算命中次数；
- 将循环顺序改为“最内层对应最低维下标”的优化问题。

复习建议：先写出数组地址公式，判断每个下标变化时的地址步长，再结合 Cache 行大小分析空间局部性。

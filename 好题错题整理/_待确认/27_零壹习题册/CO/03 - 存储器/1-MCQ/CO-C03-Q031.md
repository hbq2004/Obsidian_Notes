31. 下列关于多级 cache 说法错误的是（ ）.

(A) 近年来，多级片内 cache 系统越来越多，一般分为 L1，L2，L3 cache，且 L1 的容量一般是最小的
(B) 采用两级 cache 的系统中，cpu 先访问 L1 cache，若 L1 cache 缺失，再从 L2 cache 中去查找，若 L2 cache 缺失，就需要访问主存来找对应的数据
(C) 多级 cache 中，所有级 Cache 均缺失而需要访问主存的次数占 CPU 总访问次数的比例叫全局缺失率，某级 cache 中缺失的次数占该级 cache 总访问次数的比例叫局部缺失率
(D) 两级 cache 中，若 CPU 需要 100 次访存，L1 cache 命中 90 次，剩下的 10 次中，L2 cache 命中次数为 8 次，有两次访问主存，则全局缺失率为 11%，L1 与 L2 的局部缺失率为 10% 与 20%

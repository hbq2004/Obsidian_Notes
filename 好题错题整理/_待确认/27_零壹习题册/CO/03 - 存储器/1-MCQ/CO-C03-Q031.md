# MCQ 第 31 题

![[_Attachments/题目识别/27_零壹习题册-题目/CO-C03-Q031_题目.png|题目]]

31. 下列关于多级 cache 说法错误的是（ ）.

(A) 近年来，多级片内 cache 系统越来越多，一般分为 L1，L2，L3 cache，且 L1 的容量一般是最小的
(B) 采用两级 cache 的系统中，cpu 先访问 L1 cache，若 L1 cache 缺失，再从 L2 cache 中去查找，若 L2 cache 缺失，就需要访问主存来找对应的数据
(C) 多级 cache 中，所有级 Cache 均缺失而需要访问主存的次数占 CPU 总访问次数的比例叫全局缺失率，某级 cache 中缺失的次数占该级 cache 总访问次数的比例叫局部缺失率
(D) 两级 cache 中，若 CPU 需要 100 次访存，L1 cache 命中 90 次，剩下的 10 次中，L2 cache 命中次数为 8 次，有两次访问主存，则全局缺失率为 11%，L1 与 L2 的局部缺失率为 10% 与 20%

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/CO-C03-Q031_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。理由：本题问“说法错误的是”，(D) 中全局缺失率应为访问主存的次数占总访问次数的比例，即 $2/100=2\%$，而不是 11%；L1 与 L2 的局部缺失率计算正确。

**解题切入点**：先抓住“缺失率”的两类定义：全局缺失率看的是 CPU 总访存次数中最终未命中任何 Cache 而落入主存的比例；局部缺失率看的是某级 Cache 自身的访问中未命中的比例。这相当于做题时先分清“分母”是什么——总访问次数还是本级 Cache 的访问次数。

**推演**：

设 CPU 总访存次数为 $N=100$。

- L1 Cache 命中 90 次，则 L1 缺失次数为 $100-90=10$ 次。  
  L1 的局部缺失率为：
  $$
  \frac{L1\text{ 缺失次数}}{L1\text{ 访问次数}}=\frac{10}{100}=10\%
  $$

- L1 缺失后访问 L2，即 L2 的访问次数为 10 次。其中命中 8 次，则 L2 缺失次数为 $10-8=2$ 次，这 2 次最终访问主存。  
  L2 的局部缺失率为：
  $$
  \frac{L2\text{ 缺失次数}}{L2\text{ 访问次数}}=\frac{2}{10}=20\%
  $$

- 全局缺失率应为“所有级 Cache 均缺失”的次数占总访存次数的比例。本题中所有级 Cache 均缺失的次数就是访问主存的次数 2 次，因此：
  $$
  全局缺失率=\frac{2}{100}=2\%
  $$

而 (D) 中给出的“全局缺失率为 11%”是错误的，正确值应为 $2\%$。选项 (A)、(B)、(C) 的表述均正确。

**易错点**：

1. **将各级局部缺失率相加作为全局缺失率**：例如将 $10\%+20\%=30\%$，或误算成 $10\%+1\%=11\%$，都是错误的。全局缺失率必须看最终访问主存的次数占总访存次数的比例。
2. **混淆 L2 的访问次数**：L2 的访问次数不是 CPU 总访存次数，而是 L1 缺失后产生的那部分访存次数，即本题中的 10 次，不是 100 次。
3. **忽视“所有级 Cache 均缺失”**：只有 L1、L2 都未命中时才会访问主存，因此全局缺失率的分母仍是 CPU 总访问次数，分子是访问主存的次数。

**命题规律**：本考点属于计算机组成原理中的 Cache 性能分析，常以选择题或综合题出现。常见变式包括：

- 给定各级 Cache 的命中率，求平均访问时间：$T_{avg}=T_{L1}+(1-h_{L1})T_{L2}+(1-h_{L1})(1-h_{L2})T_{MM}$。
- 结合局部缺失率与全局缺失率的关系，判断某级 Cache 的局部命中率变化对系统性能的影响。

复习建议：牢记定义，注意区分“分母”是总访问次数还是本级访问次数；计算时先画清访问流程，再代入公式。多练几道类似计算题即可熟练掌握。

# MCQ 第 20 题

![[_Attachments/题目识别/27_零壹习题册-题目/CO-C03-Q020_题目.png|题目]]

20. 计算机的主存容量为4MB，按字节编址，cache块8B，cache数据区大小为4KB，采用全相联，下列说法中正确的是（ ）.

(A) 每个主存块都可以映射到cache的任意一行，所以不需要算法替换位
(B) 本题中块内偏移3位，TAG为19位，跟cache数据区的容量的相关的
(C) 若采用LRU替换算法，不考虑脏位的情况下，cache的总容量为5952B
(D) Cache不需要存储片内偏移，只需要在cache中找到对应的主存块就可以了，不需要找到对应的单元

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/CO-C03-Q020_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。按题面 B 中“TAG 与 Cache 数据区容量相关”的表述，B 错；全相联 Cache 虽然每个主存块可放任意一行，但满后仍需替换算法/替换位；考虑有效位、TAG 位和 LRU 位后，Cache 总容量正好为 $5952$B。

**解题切入点**：拿到题目先做“地址结构拆分”：主存容量确定地址位数，块大小确定块内偏移位数，映射方式确定有无 index 位。然后再算 Cache 行数，并区分“数据区容量”和“标记区/控制位容量”。全相联相当于“1 组 512 路”，LRU 替换信息不能漏算。

**推演**：

主存容量为 $4\text{MB}=2^{22}\text{B}$，按字节编址，所以物理地址共有

$$
22 \text{ 位}
$$

Cache 块大小为 $8\text{B}$，因此块内偏移位数为

$$
b=\log_2 8=3
$$

采用全相联映射，没有 index 位，所以 TAG 位数为

$$
22-3=19
$$

也可理解为：主存共有

$$
\frac{2^{22}}{2^3}=2^{19}
$$

个主存块，因此 TAG 需要 $19$ 位来区分主存块。

Cache 数据区容量为 $4\text{KB}$，块大小为 $8\text{B}$，所以 Cache 行数为

$$
N=\frac{4\text{KB}}{8\text{B}}=\frac{4096}{8}=512=2^9
$$

每行需要的存储开销为：

- 数据：$8\text{B}$
- 有效位：$1$ 位
- TAG：$19$ 位
- LRU 替换位：全相合可看作 $512$ 路，每行用 $\lceil \log_2 512\rceil=9$ 位记录 LRU 信息
- 题目说不考虑脏位，所以不计脏位

因此 Cache 总容量为

$$
\begin{aligned}
C_{\text{total}}
&=4\text{KB}+512\times(19+1+9)\ \text{bit} \\
&=4096\text{ B}+512\times29\ \text{bit} \\
&=4096\text{ B}+14848\ \text{bit} \\
&=4096\text{ B}+1856\text{ B} \\
&=5952\text{ B}
\end{aligned}
$$

所以 C 正确。

其余选项：

- A 错：全相联只是“每个主存块可映射到任意一行”，但当 Cache 满时仍必须选择替换哪一行，不能因此说不需要替换算法/替换位。
- B 错：前半句“块内偏移 3 位，TAG 为 19 位”正确；但“TAG 与 Cache 数据区容量相关”不对，全相联下 TAG 位数与 Cache 容量/行数无关。
- D 错：Cache 确实不需要存储块内偏移，块内偏移由访问地址的低 $3$ 位提供；但命中后仍要用块内偏移在 $8\text{B}$ 中选中对应字节单元，不能说“不需要找到对应单元”。

**易错点**：

1. 容易漏算 LRU 位，只算“TAG + 有效位”，得到 $5376\text{B}$；但题目明确说采用 LRU 替换算法，LRU 替换信息要计入。
2. 容易把“全相联”误认为不需要替换算法；恰恰相反，全相联在替换时候选行最多，必须有替换策略。
3. 容易把“TAG 位数”和“TAG 阵列总容量”混淆。TAG 位数与 Cache 容量无关，但 TAG 阵列总容量与 Cache 行数有关。
4. 容易误以为 Cache 不需要块内偏移；偏移不存储，但要用来在命中的块内选择字节。

**命题规律**：本题考查 Cache 地址结构、全相联映射、Cache 总容量计算和 LRU 替换位。常见变式有：改为直接映射或组相联，要求计算 index、TAG；加入脏位；求“标记阵列容量”而不是“总容量”；或将 LRU 替换改为随机替换。复习时应熟记：

- 块内偏移位数 $=\log_2(\text{块大小})$
- index 位数 $=\log_2(\text{组数})$
- TAG 位数 $=$ 地址位数 $-$ 块内偏移位数 $-$ index 位数
- Cache 总容量 $=$ 数据区容量 $+$ 行数 $\times$（TAG + 有效位 + 脏位 + 替换位）

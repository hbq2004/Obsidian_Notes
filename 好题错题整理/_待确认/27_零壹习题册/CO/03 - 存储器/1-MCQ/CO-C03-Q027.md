# MCQ 第 27 题

![[_Attachments/题目识别/27_零壹习题册-题目/CO-C03-Q027_题目.png|题目]]

27. 下列对应写分配法，非写分配法说法正常的是 ( ) .
(A) 写分配法跟非写分配法都具备空间局部性
(B) 写分配法在与全写法配合的时候，在 cache 中更新数据，因此需要脏位
(C) 非写分配比写分配快的多，不需要将主存块放入 cache，效率高很多，是最好的写不命中处理方法
(D) 写分配法与全写法配合的时候是在主存中更新数据，与回写法配合时在 cache 中更新数据

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/CO-C03-Q027_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。  
写分配法决定“写不命中时是否把主存块调入 Cache”，而真正决定“更新主存还是更新 Cache”的是全写法/回写法；全写法需要更新主存，回写法更新 Cache 并置脏位。

**解题切入点**：  
拿到题目先抓住关键词“写分配法/非写分配法”和“全写法/回写法”。前者解决的是“写不命中时要不要把主存块调入 Cache”，后者解决的是“写操作最终写到 Cache 还是主存”。可以打比方：Cache 是桌面草稿纸，主存是正式档案——写分配法相当于“先把档案复印一份放到桌面再改”，非写分配法相当于“不改桌面草稿，直接改正式档案”。

**推演**：

1. 写不命中时有两种块分配策略：

   - 写分配法：把主存块调入 Cache，再修改 Cache 中的数据。由于一次调入一个块，后续可能访问块内相邻数据，因此具备空间局部性。
   - 非写分配法：不把主存块调入 Cache，而是直接修改主存中的数据。由于不调入块，通常不具备空间局部性。

2. 全写法与回写法：

   - 全写法：写命中的同时写 Cache 和主存，Cache 与主存始终一致，不需要脏位。
   - 回写法：写命中时只修改 Cache 并置脏位，只有 Cache 块被替换时才写回主存，因此需要脏位。

3. 逐项判断：

   - A 错：非写分配法不调入主存块，不具备空间局部性。
   - B 错：与全写法配合时数据会同时更新到主存，Cache 和主存一致，不需要脏位；脏位是回写法的需要。
   - C 错：非写分配法虽然省去了“调入主存块”的开销，但可能丧失空间局部性，后续频繁访问同一块时可能多次访问主存，不能说它“一定快很多”或“最好”。
   - D 对：全写法下主存会被更新；回写法下数据先在 Cache 中更新，并等替换时再写回主存。严格说，写分配法与全写法配合时 Cache 也会被更新，但 D 强调的是“全写法要更新主存”，因此 D 正确。

**易错点**：

- 误以为“写分配法 = 回写法，非写分配法 = 全写法”是绝对绑定关系。实际上二者是不同层面的策略，只是通常搭配使用：写分配法常与回写法搭配，非写分配法常与全写法搭配。
- 误以为全写法需要脏位。全写法同时写主存，Cache 和主存一致，不需要脏位；回写法才需要脏位。
- 误以为非写分配法效率一定更高。省去调块开销不等于总体效率高，还要考虑空间局部性和缺失率。
- 审题时要注意区分“写命中”和“写不命中”的处理策略，本题讨论的是写不命中的处理。

**命题规律**：  
本考点属于计算机组成原理中 Cache 写入策略的重要内容，常结合“写命中/写不命中”“全写法/回写法”“脏位”“空间局部性”一起考查。常见变式包括：判断哪种策略需要脏位、哪种策略具备空间局部性、给出访问序列分析写主存次数等。复习时应把“写分配/非写分配”与“全写/回写”的搭配关系和硬件开销记清楚，并理解它们各自的优缺点。

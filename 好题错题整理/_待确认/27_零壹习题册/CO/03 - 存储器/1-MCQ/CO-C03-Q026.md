# MCQ 第 26 题

![[_Attachments/题目识别/27_零壹习题册-题目/CO-C03-Q026_题目.png|题目]]

26. 下列关于 cache 写策略说法中正确的是 （ ）.

①全写法在写命中时，同时写入 cache 与主存

②回写法在写命中时，只写入 cache 不写入主存，同时脏位设为 1

③全写法可以与写分配法，非写分配法配合，全写通常与非写分配法配合，回写通常跟写分配法配合

④写分配法与全写法，回写法中都是一样的，都是写不命中时先在主存块中更新存储单元，在将主存块装入 cache 行中

(A) ①②③④

(B) ②③④

(C) ①③④

(D) ①②③

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/CO-C03-Q026_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。①②③正确；④错误，因为“写分配法”是写不命中时先把主存块调入 Cache，再在 Cache 中更新，而不是题中所说的“先在主存块中更新存储单元，再将主存块装入 Cache”。

**解题切入点**：  
拿到 Cache 写策略题，先分两个维度：

1. 写命中时的处理：全写法 / 回写法；  
2. 写不命中时的处理：写分配法 / 非写分配法。

可以类比“处理异常”的思路：命中是一种情况，不命中是另一种情况，不要混在一起背。先把两种情况分开，再记典型组合，就不容易错。

**推演**：

① 全写法，即 write-through，写命中时同时更新 Cache 和主存，保证主存数据始终是最新的。  
所以①正确。

② 回写法，即 write-back，写命中时只更新 Cache，不立即更新主存；因此 Cache 行与主存块不再一致，需要把脏位设为 1，等该行被替换时再写回主存。  
所以②正确。

③ 全写法可以与写分配法配合，也可以与非写分配法配合；但全写法本来就要写主存，若写不命中时还把块调入 Cache，可能造成不必要的 Cache 污染，所以通常与非写分配法配合。  
回写法因为写回延迟到替换时，所以写不命中时通常采用写分配法，先把主存块调入 Cache，再在 Cache 中更新并置脏位，这样便于以后整体写回。  
题干说的是“可以/通常”，表述不绝对，因此③正确。

④ 错误。写分配法的标准含义是：写不命中时，先把所写单元所在的主存块调入 Cache 行，再在 Cache 中更新；若配合全写法，则同时更新主存；若配合回写法，则主存不立即更新。  
题面“先在主存块中更新存储单元，再将主存块装入 Cache 行中”既不是写分配法的定义，也违背回写法“主存延迟更新”的思想。  
所以④错误。

因此正确选项为：  
$$
(D)\ ①②③
$$

**易错点**：

- 容易把“通常”误读成“必须”。例如③说“全写通常与非写分配法配合，回写通常与写分配法配合”，这是对的；如果改成“只能”，就错了。
- 容易混淆“写分配法”和“非写分配法”。  
  写分配：写不命中时调入 Cache 再写；  
  非写分配：写不命中时不调入 Cache，直接写主存。
- 容易混淆“写命中”和“写不命中”。例如回写法写命中时不写主存，但写不命中时若配合非写分配，则仍可能直接写主存。
- 容易忽略“脏位”。回写法写命中时需要置脏位为 1；全写法因为主存已更新，通常不需要脏位。

**命题规律**：  
本题是 Cache 写策略中的经典概念题，考点集中在：

- 全写法（write-through）与回写法（write-back）在写命中时的行为；
- 写分配法（write-allocate）与非写分配法（no-write-allocate）在写不命中时的行为；
- 两种策略的典型组合：
  - 全写法通常配非写分配法；
  - 回写法通常配写分配法。

常见变式包括：给出一段写操作序列，结合脏位判断某时刻 Cache 行状态；或考查多级 Cache、写缓冲与 Cache 一致性。复习时建议用“两维表格”记忆：

| 写策略 | 写命中 | 写不命中典型处理 |
|---|---|---|
| 全写法 | 写 Cache + 写主存 | 通常配非写分配，直接写主存 |
| 回写法 | 只写 Cache，置脏位 | 通常配写分配，调入 Cache 再写并置脏位 |

做题时尤其注意“通常”“可以”“只能”这类程度词，是命题人常设陷阱。

# MCQ 第 14 题

![[_Attachments/题目识别/27_零壹习题册-题目/CO-C03-Q014_题目.png|题目]]

14. 有4个存储体，通过低位交叉编址得到一个4KB的存储器，按字节编址，存储周期是40ns，忽略传输地址跟命令的时间，总线传输的时间为10ns，cpu读取：512、513、514、520、522、526、527这些单元到cpu需要的时间 (    ) .
(A) 110ns
(B) 130ns
(C) 150ns
(D) 160ns

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/CO-C03-Q014_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C（150ns）。  
理由：四体交叉存储器按流水方式工作，按题给顺序最后一次访问在 110ns 启动，再经一个存储周期 40ns 读出，故总时间为 $110+40=150$ns。

**解题切入点**：  
看到“4个存储体、低位交叉编址、存储周期、总线传输时间、多个地址”，应立刻定位到“多体交叉存储器的流水重叠”问题。这类似于算法竞赛里的“带冷却时间的任务调度”：每个存储体冷却 40ns，CPU 发出下一次访问的最早间隔是总线传输时间 10ns。所以先做两件事：①把地址映射到体号；②按顺序算出每次访问的启动时刻。

**推演**：

四体低位交叉编址，按字节编址，因此体号由地址的低 2 位决定：

$$
\text{体号}=\text{地址}\bmod 4
$$

各地址对应的体号：

| 地址 | 体号 |
|---|---|
| 512 | 0 |
| 513 | 1 |
| 514 | 2 |
| 520 | 0 |
| 522 | 2 |
| 526 | 2 |
| 527 | 3 |

同一存储体两次访问至少间隔 40ns；CPU 相邻两次请求至少间隔 10ns。按给定访问顺序，设 $s_i$ 为第 $i$ 次访问的启动时间：

| 地址 | 体号 | 启动时间 |
|---|---|---|
| 512 | 0 | 0ns |
| 513 | 1 | 10ns |
| 514 | 2 | 20ns |
| 520 | 0 | 40ns，因为体 0 上次 0ns 启动，$0+40=40$ |
| 522 | 2 | 60ns，因为体 2 上次 20ns 启动，$20+40=60$ |
| 526 | 2 | 100ns，因为体 2 上次 60ns 启动，$60+40=100$ |
| 527 | 3 | 110ns |

因此最后一次访问在 110ns 启动，再经过一个存取周期 40ns，总时间为：

$$
110+40=150\text{ns}
$$

所以选 **C**。

**易错点**：  
- 不要直接把 7 个地址当作连续地址算，$40+(7-1)\times10=100$ 会忽略同一存储体的冲突。  
- 不要误选 **D**。总线传输时间已经作为相邻访问的流水节拍体现在启动时间间隔中，不能再在最后额外加一次 10ns。  
- 注意“低位交叉编址”中体号由地址低位决定，而不是高位；本题地址 520 与 512 同属体 0，522 与 514、526 同属体 2。

**命题规律**：  
本题属于计算机组成原理中“多体交叉存储器”的常考题型。常见变式有：连续地址求最少时间、给定地址序列求访存时间、求加速比、求总线传输周期与存储周期的关系。复习时要掌握低位交叉编址的体号映射，以及“同一体间隔至少一个存储周期、不同体按总线传输周期流水启动”的计时方法。

# MCQ 第 3 题

![[_Attachments/题目识别/27_零壹习题册-题目/CO-C04-Q003_题目.png|题目]]

3. 下列选项中，与指令系统支持的操作等价的是（ ）.

I. 系统程序员可用的操作

II. ISA 规定的操作边界

III. 汇编语言支持的操作

IV. 计算机软件支持的所有操作

(A) I、II、III、IV
(B) II、III
(C) I、IV
(D) II、III、IV

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/CO-C04-Q003_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。指令系统支持的操作就是 ISA 规定的操作边界，也是汇编指令助记符对应的机器操作；系统程序员可用操作和软件支持的所有操作都是更上层的接口/组合结果，不能等同。

**解题切入点**：拿到题目先抓住“指令系统”的定义：指令系统是 CPU 硬件能直接执行的全部机器指令的集合。可以把它类比为 CPU 对外暴露的“底层 API/系统调用表”；汇编语言只是把这个 API 用助记符写出来，而系统程序员和普通软件使用的操作则是在这个 API 之上封装出来的更高层功能。因此先排除包含 I、IV 的选项，再确认 II、III。

**推演**：

设指令系统支持的操作集合为 $S$：

$$
S=\{\text{ISA 规定的可由 CPU 直接执行的机器操作}\}
$$

逐项判断：

- **I. 系统程序员可用的操作**：系统程序员可用的操作不只是指令系统，还包括系统调用、操作系统内核服务、中断/异常处理机制等；即使系统程序员能执行特权指令，也只是能使用 $S$ 中的部分/全部机器指令，不能说“可用操作”与 $S$ 等价。故错误。
- **II. ISA 规定的操作边界**：ISA（指令集体系结构）明确规定了一台计算机的指令系统包含哪些操作，因此 $S$ 就是 ISA 规定的操作边界。故正确。
- **III. 汇编语言支持的操作**：汇编指令是机器指令的助记符表示，一条真正的汇编指令对应一条机器指令，所以汇编语言在指令级支持的操作集合与 $S$ 一致。故正确。注意伪指令/宏指令是汇编器提供的，不是 CPU 指令系统支持的操作，不在本题“操作”范围内。
- **IV. 计算机软件支持的所有操作**：软件可以支持高级语言语句、库函数、算法、操作系统服务等，这些都可以由多条指令组合而成，显然比 $S$ 大得多，不等价。故错误。

因此正确项为 II、III，选 B。

**易错点**：

1. 误选 I：以为“系统程序员能执行所有机器指令”就等价。实际上系统程序员可用的操作还包括系统调用、OS 服务等，是更高层的软件接口，不是 CPU 指令系统本身。
2. 误选 IV：把“软件能实现的功能”误当成“指令系统直接支持的操作”。软件功能可以由多条机器指令组合完成，属于组合结果，不等于指令集合。
3. 对 III 产生怀疑：汇编语言中有伪指令、宏指令、伪操作，但它们不是 CPU 执行的机器操作；真正的汇编指令与机器指令一一对应。题目语境下 III 正确。
4. 混淆层次：ISA、机器指令、汇编指令、系统调用、软件功能是不同层次的概念；指令系统是硬件直接支持的操作边界，更上层的软件接口不能与其完全等价。

**命题规律**：考点是“指令系统与 ISA”的基本概念，常见出题方向为判断“指令系统、汇编语言、系统调用、软件操作”之间的关系。变式可能包括：机器指令与汇编指令是否一一对应、特权指令是否属于指令系统、软硬件接口由谁规定等。复习时应抓住一条主线：指令系统是 CPU 硬件直接执行的操作集合，是 ISA 规定的软硬件边界；汇编语言只是其符号化表示，OS 和应用程序功能是上层封装。

# MCQ 第 17 题

![[_Attachments/题目识别/27_零壹习题册-题目/CO-C04-Q017_题目.png|题目]]

17. 将图 1 的 C 语言片段转化为 32 位计算机下的 MIPS 汇编指令后如图 2 所示，已知寄存器 $s1$、$s2$、$s3$、$s5$ 分别保存着变量 $x$、$i$、$k$ 和 $A$ 数组的起始地址，则图 1 中 while 内的循环条件是（　） .

图1 代码如下：
```
int A[maxn];
//......
while(???){
    x += A[i];
    i++;
}
```

图2 代码如下：
```
Loop:  beq $s3, $s2, Exit
       add $s7, $s2, $s2
       add $s7, $s7, $s7
       add $s7, $s7, $s5
       lw  $s6, 0($s7)
       add $s1, $s1, $s6
       addi $s2, $s2, 1
       j Loop
Exit:
```

(A) $i \leqslant k$
(B) $i < k$
(C) $i > k$
(D) $i \geqslant k$

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/CO-C04-Q017_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B（$i<k$）。MIPS 中 `beq $s3, $s2, Exit` 表示当 $k=i$ 时跳出循环；而循环体末尾执行 `i++`，所以循环体实际只处理 $i=0,1,\dots,k-1$，等价于 while 条件 $i<k$。

**解题切入点**：拿到循环翻译题，先找“出口分支”。本题唯一的出口是 `beq $s3, $s2, Exit`，它说明 `$s3==$s2` 时退出，即 $k==i$ 时退出。再结合循环变量 $i$ 每次自增 1，就能把“等于时退出”转化为不等式范围，从而确定 C 语言 while 条件。

**推演**：

寄存器映射关系为：

- `$s1` 保存 $x$
- `$s2` 保存 $i$
- `$s3` 保存 $k$
- `$s5` 保存数组 $A$ 的起始地址

汇编循环主体是：

```asm
Loop:  beq $s3, $s2, Exit
       add $s7, $s2, $s2
       add $s7, $s7, $s7
       add $s7, $s7, $s5
       lw  $s6, 0($s7)
       add $s1, $s1, $s6
       addi $s2, $s2, 1
       j Loop
Exit:
```

第一条指令：

```asm
beq $s3, $s2, Exit
```

等价于：

$$
\text{if }(k == i)\ \text{goto Exit;}
$$

也就是说，循环继续条件是：

$$
i \ne k
$$

但题目选项中没有 $i\ne k$；需要进一步结合循环变量的变化判断。

再看循环体中的数组地址计算：

```asm
add $s7, $s2, $s2
```

得到：

$$
s7 = i + i = 2i
$$

```asm
add $s7, $s7, $s7
```

得到：

$$
s7 = 2i + 2i = 4i
$$

由于 32 位计算机中 `int` 占 4 字节，所以这是把下标 $i$ 换算成字节偏移量。

```asm
add $s7, $s7, $s5
```

得到：

$$
s7 = \text{Addr}(A) + 4i
$$

即 `$s7` 中保存的是 $A[i]$ 的地址。

```asm
lw $s6, 0($s7)
```

等价于：

$$
s6 = A[i]
$$

因此循环体确实执行：

$$
x = x + A[i]
$$

然后：

```asm
addi $s2, $s2, 1
```

等价于：

$$
i = i + 1
$$

由于 $i$ 每次只增加 1，假设 $i$ 从 0 开始增加，$k$ 为循环上界，则循环体会依次处理：

$$
i=0,1,2,\dots,k-1
$$

当处理完 $i=k-1$ 后，`i++` 使 $i$ 变为 $k$；下一次回到 `Loop` 时，`beq` 发现 $k==i$，于是跳转到 `Exit`。

所以循环条件等价于：

$$
i<k
$$

选项 B 正确。

**易错点**：

1. **把 `beq` 当成循环继续条件**。  
   `beq $s3, $s2, Exit` 是“相等则跳出”，不是“相等则继续”。

2. **误选 $i\le k$**。  
   如果条件写成 $i\le k$，当 $i=k$ 时 while 条件仍为真，还会执行一次 $A[k]$；但汇编中 `beq` 在 $i=k$ 时已经跳出，所以 $A[k]$ 不会被访问。

3. **忽略 32 位下 `int` 占 4 字节**。  
   地址计算中两次 `add` 是为了得到 $4i$，而不是 $2i$ 或 $i$。

4. **把严格字面等价条件 $i\ne k$ 与选项混淆**。  
   严格看第一条指令，循环继续条件是 $i\ne k$；但由于 $i$ 每次自增 1，从下方接近 $k$ 时不会越过 $k$，因此在该循环中等价为 $i<k$。

**命题规律**：本题属于计算机组成原理中 MIPS 指令系统与循环结构翻译的考点。常见变式包括：把 `beq` 改为 `bne`，或用 `slt`、`slti` 构造比较；把数组元素类型改为 `short`、`double`，从而改变地址偏移倍数；或者直接问“循环执行几次”“访问了 A 的哪些元素”。复习时应熟练掌握 MIPS 常用指令语义、循环出口写法，以及“由汇编反推 C 语言循环条件”的逆向翻译方法。

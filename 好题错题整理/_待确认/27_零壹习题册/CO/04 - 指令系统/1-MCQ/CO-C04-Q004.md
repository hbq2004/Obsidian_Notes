# MCQ 第 4 题

![[_Attachments/题目识别/27_零壹习题册-题目/CO-C04-Q004_题目.png|题目]]

4. 指令字长 16 位，每个地址码 4 位，支持操作码扩展。已知三地址指令 14 条，二地址指令 31 条，零地址指令 17 条，则最多支持（　　）条单地址指令.
(A) 13
(B) 14
(C) 15
(D) 32

背景说明：下面展示了 32 位计算机下部分 MIPS 指令的各字段含义。
R 型指令：
| op | rs | rt | rd | shamt | funct |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 6 位 | 5 位 | 5 位 | 5 位 | 5 位 | 6 位 |
op: 操作码; rs: 第一个源操作数寄存器; rt: 第二个源操作数寄存器; rd: 目的操作数寄存器; shamt: 移位指令下的移位量; funct: 功能码.
I 型指令：
| op | rs | rt | constant |
| :--- | :--- | :--- | :--- |
| 6 位 | 5 位 | 5 位 | 16 位 |
I 型指令中，op、rs 字段与 R 型指令含义相同，rt 字段在 `addi` 和 `lw` 指令中标识目的操作数寄存器，在 `sw` 指令中标识源操作数寄存器，低 16 位标识立即数或内存偏移量.
部分指令的字段编码如下表所示（表中为各字段转化为十进制后的值，指令格式中不出现的字段填写“/”）:
| 指令 | 格式 | op | rs | rt | rd | shamt | funct | constant |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| add | R 型 | 0 | | | | 0 | 32 | / |
| sub | R 型 | 0 | | | | 0 | 34 | / |
| addi | I 型 | 8 | | | / | / | / | |
| lw | I 型 | 35 | | | / | / | / | |
| sw | I 型 | 43 | | | / | / | / | |
| sll | R 型 | 0 | | | 移位数 | 0 | / | |
| srl | R 型 | 0 | | | 移位数 | 2 | / | |
请据此回答第 5~12 题.

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/CO-C04-Q004_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B（14 条）。三地址后剩 2 个 4 位操作码；二地址容量为 \(2\times2^4=32\)，用 31 条后剩 1 个 8 位前缀；该前缀可展开为 16 个 12 位单地址操作码，但 17 条零地址需占用 2 个 12 位前缀，所以单地址最多 \(16-2=14\) 条。

**解题切入点**：看到“指令字长 16 位 + 每个地址码 4 位 + 支持操作码扩展”，要立刻想到：地址码越少，操作码越长。本题本质是操作码前缀分配问题，像给不同长度的操作码分配前缀：短操作码一旦占用，长操作码就不能再以它为前缀。后面的 MIPS 背景不参与本题。

**推演**：

地址码个数为 \(a\) 时，操作码位数为：

\[
L_{\mathrm{op}}=16-4a
\]

所以：

1. **三地址指令**：  
   \(a=3\)，操作码位数 \(L=16-12=4\)。  
   共有 \(2^4=16\) 个 4 位操作码，已用 14 条，剩余：

   \[
   16-14=2
   \]

   个 4 位操作码前缀。

2. **二地址指令**：  
   \(a=2\)，操作码位数 \(L=8\)。  
   每个剩余 4 位前缀可扩展出 \(2^4=16\) 个 8 位操作码，因此共有：

   \[
   2\times16=32
   \]

   个可用二地址操作码。已用 31 条，剩余 1 个 8 位操作码前缀。

3. **单地址指令**：  
   \(a=1\)，操作码位数 \(L=12\)。  
   剩余 1 个 8 位前缀可扩展出：

   \[
   2^4=16
   \]

   个 12 位操作码。

4. **零地址指令**：  
   \(a=0\)，操作码位数 \(L=16\)。  
   每个 12 位前缀下最多可容纳：

   \[
   2^4=16
   \]

   个 16 位零地址操作码。现在需要 17 条零地址指令，因此至少占用：

   \[
   \left\lceil \frac{17}{16}\right\rceil=2
   \]

   个 12 位前缀。

所以单地址指令最多支持：

\[
16-2=14
\]

条。

**易错点**：

- 容易误选 C（15 条）。15 条是零地址指令只有 16 条时的情况；本题零地址有 17 条，必须占用 2 个 12 位前缀。
- 不要把 17 条零地址误认为占用 17 个单地址位置；一个 12 位前缀下最多能放 16 条零地址。
- 注意二地址用掉 31 条后，剩下的是“1 个 8 位操作码前缀”，不是“1 个 4 位操作码”。
- 要保证操作码前缀不冲突：一个 12 位前缀若被单地址指令占用，就不能再扩展出零地址指令；反之亦然。

**命题规律**：本题属于计算机组成原理的“指令系统”考点，考查扩展操作码设计。常见变式有：给出指令字长、地址码位数和若干类指令条数，问还能容纳多少条其他指令，或判断编码方案是否可行。复习时应掌握“地址码每减少一个，操作码就增加一个地址码的位数”的分配方法，并优先从多地址指令向少地址指令逐层分配，同时用前缀码思想检查冲突。

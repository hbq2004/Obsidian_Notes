# MCQ 第 26 题

![[_Attachments/题目识别/27_零壹习题册-题目/CO-C05-Q026_题目.png|题目]]

26. 异常与中断也是 CPU 进行指令过程中可能出现的，下图为带异常处理的数据通路设计（加粗的红、紫、黑为公共部分）。下图中 EPC 用来保存断点信息，即正在执行中的指令地址或下一条指令地址。 cause 用于记录异常原因，为 0 代表非法指令码，为 1 代表溢出。异常查询程序的入口地址为 0x8000 0180，查询程序会根据 cause 的值判断异常种类，然后执行对应处理程序。当前正在执行 add 指令，且 A 暂存的数据为 8000 0000H，B 暂存的数据为 FFFF FFFFH，则下列说法错误的是（  ）.

(A) 若执行的是 Jump 指令，则在执行阶段的数据流向由橙、红、紫构成，PCSource 为 00
(B) $A + B$ 执行后 cause=1，IntCause=1，CauseWr=1，EPCWr=1
(C) 出现异常事件后，在 EPC 保存了断点后，会让 PCSource=11，把 0x8000 0180 写入 PC
(D) 保存正在执行的指令地址时，需要将经过红色—绿色传输的地址经 ALU 直送，再通过黑色线路给到 EPC；保存下一条指令时，需要让红色—绿色传输的地址与蓝色线的 4 进行 addu 计算，得到下一条地址的值，再经过黑色线给到 EPC

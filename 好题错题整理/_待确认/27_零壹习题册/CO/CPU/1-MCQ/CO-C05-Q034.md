# MCQ 第 34 题

![[_Attachments/题目识别/27_零壹习题册-题目/CO-C05-Q034_题目.png|题目]]

34. 数据冒险中可以使用转发技术处理冒险，将数据通路生成的中间结果直接转发到 ALU 输入端，能尽可能减少流水线的阻塞. 执行下列指令序列时，下列说法错误的是 ( ).

```
I1: add $1, $2, $3    # $2 + $3 -> $1
I2: sub $4, $1, $5    # $1 - $5 -> $4
I3: lw  $6, 0($7)     # Mem[$7+0] -> $6
I4: sub $8, $6, $9    # $6 - $9 -> $8
I5: sub $10, $1, $11  # $1 - $11 -> $10
```

(A) I1 在 EX 段结束拿到新的 \$1，会发送到 I2 的 ALU 的一端，因此 I2 不会阻塞
(B) 转发技术完全解决数据冒险，包括 load-use，这里指令的执行只需要 9 个时钟周期
(C) 转发技术主要是进行 Ex/Mem 段间寄存器或 Mem/Wr 段间寄存器到 ALU 输入端的转发，需要对流水线电路添加一些硬件
(D) 转发技术只要求前面指令的新数据在后面指令的 EX 段前得到即可，即使后面的指令 ID 段拿到旧数据也没关系

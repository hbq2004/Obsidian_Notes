# MCQ 第 33 题

![[_Attachments/题目识别/27_零壹习题册-题目/CO-C05-Q033_题目.png|题目]]

33. 指令流水线中最容易出现的就是数据冒险. 下面按序执行的指令序列中出现了数据冒险，下列说法错误的是（ ）.

```
I1: add $1, $2, $3     # $2 + $3 -> $1     写入 $1
I2: sub $4, $1, $5     # $1 - $5 -> $4     读取 $1
I3: sub $6, $1, $7     # $1 - $7 -> $6     读取 $1
I4: add $1, $8, $9     # $8 + $9 -> $1     写入 $1
I5: sub $1, $10, $2    # $10 - $2 -> $1    写入 $1
```

(A) I1 与 I2 之间存在 RAW，I2 与 I3 之间存在 RAR，I3 与 I4 之间存在 WAR，I4 与 I5 之间存在 WAW，其中 RAW 会导致数据冒险

(B) WAW、WAR、RAR 都不会导致数据冒险，因为指令按序执行时，前后两个指令的 ID 之间、Wr 之间、ID 与 Wr 之间本身就有先后，所以不存在后面的指令使用前面的指令结果时，前面指令结果还没有产生的情况

(C) 使用 stall 方式后，最多需要 11 个时钟周期完成这 5 条指令

(D) 产生数据冒险时，可以采用软件插入空操作指令 nop、硬件阻塞 stall 插入气泡 bubble、转发技术、寄存器半个周期读半个周期写等方法

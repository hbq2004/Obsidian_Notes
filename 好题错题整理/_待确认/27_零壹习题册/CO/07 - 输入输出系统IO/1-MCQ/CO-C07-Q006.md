# MCQ 第 6 题

![[_Attachments/题目识别/27_零壹习题册-题目/CO-C07-Q006_题目.png|题目]]

6. 关于可编程的中断控制器的说法，下面说法错误的是 ( ) .

(A) CPU 可以通过设置中断控制器中的寄存器来控制各中断的中断响应优先级

(B) 中断控制器管理的所有中断类型均为可屏蔽中断

(C) CPU 完成一次完整的中断过程后会向中断控制器发送“中断结束”信号

(D) 中断控制器与各设备的 I/O 接口通过控制总线相连

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/CO-C07-Q006_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。  
理由：I/O 接口是通过专用的中断请求线连接到中断控制器的，而不是通过控制总线相连。

**解题切入点**：  
看到“可编程中断控制器”应马上定位到 8259A 这类中断控制芯片。考点集中在三方面：寄存器可编程设置优先级、它管理的是哪类中断、中断结束（EOI）处理流程，以及引脚/信号连接。做题时可把它想象成“调度中心”：外设通过专用电话线向调度中心报告，而不是通过公共控制总线；CPU 处理完一个任务后，也要专门通知调度中心。

**推演**：  
可编程中断控制器 8259A 的主要连接关系为：

- 与各设备 I/O 接口相连：中断请求输入线 $IR_0\sim IR_7$；
- 与 CPU 相连：$INT$ 输出接 CPU 的 $INTR$，$INTA$ 接 CPU 的中断响应信号；
- 与系统总线相连：数据线 $D_7\sim D_0$、控制线 $\overline{RD}$、$\overline{WR}$、$\overline{CS}$ 等。

逐项判断：

1. **A 正确**。CPU 可以对中断控制器中的寄存器进行编程，例如设置中断屏蔽寄存器 IMR、初始化命令字 ICW 和操作命令字 OCW，从而控制各中断的中断响应优先级和屏蔽状态。

2. **B 正确**。8259A 的 $INT$ 输出接到 CPU 的 $INTR$ 引脚，属于可屏蔽外部中断；非屏蔽中断 NMI 不经过 8259A。因此，中断控制器管理的中断类型都是可屏蔽中断。

3. **C 正确**。在一般非自动结束方式下，CPU 执行完中断服务程序后，需要向中断控制器发送“中断结束”命令 EOI，以清除中断服务寄存器 ISR 中的相应位，使较低优先级的中断能够被响应。

4. **D 错误**。设备的 I/O 接口是通过中断请求线接到中断控制器的 $IR_i$ 引脚，从而实现中断请求；不是“通过控制总线”与中断控制器相连。控制总线主要用于传送读写控制、片选等控制信号。

因此错误的是 **D**。

**易错点**：  
- 容易认为“中断请求线”属于控制总线，从而误判 D 正确。408 语境下应区分：I/O 接口到中断控制器之间是独立的中断请求线；中断控制器与 CPU 之间才有读/写、片选等控制总线信号。  
- 对 C 有疑问时，注意“自动 EOI 方式”是特殊模式，题目通常考查一般工作方式，不能以特例否定 C。  
- 对 B 有疑问时，要明确 NMI 不经过 8259A，因此“管理的中断均为可屏蔽中断”是正确的。

**命题规律**：  
考点属于计算机组成原理“输入输出系统”中的中断系统。常见变式有：  
- 考查中断控制器如何提供中断类型号/中断向量；  
- 考查中断优先级、中断屏蔽和嵌套；  
- 考查 EOI 在中断处理流程中的位置；  
- 考查 8259A 与 CPU、外设之间的信号连接。  

复习建议：把中断控制器连接图画清楚，重点记住三组连接关系——与 I/O 接口的中断请求线、与 CPU 的 $INT/INTA$、与总线的数据/控制线；再结合中断处理流程记忆 EOI 的作用。

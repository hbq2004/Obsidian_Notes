# MCQ 第 5 题

![[_Attachments/题目识别/27_零壹习题册-题目/CO-C07-Q005_题目.png|题目]]

5. 关于 RISC 风格指令集下对 I/O 端口的统一编址方式，下面说法错误的是 ( ).

(A) 使用 LOAD/STORE 指令访问 I/O 端口

(B) 访问 I/O 端口的指令使用虚拟地址而非物理地址

(C) 对访问 I/O 端口行为的特权级保护通过内存映射单元 MMU 实现

(D) 指令访问的 I/O 端口号通过数据线传送给 I/O 接口

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/CO-C07-Q005_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。统一编址（存储器映射 I/O）下，I/O 端口号本质上是地址，应通过地址线传送给 I/O 接口；数据线只负责传输数据，因此 D 错误。

**解题切入点**：  
看到“RISC 风格指令集 + I/O 端口统一编址”，应立刻定位到“存储器映射 I/O”这一考点。RISC 的访存指令只有 LOAD/STORE，所以访问 I/O 端口也必须用 LOAD/STORE；然后再辨析“地址线传端口地址、数据线传数据”即可锁定 D。可以类比“查数组”：端口号是下标，下标必须交给地址译码器，而不是混在数组元素内容里沿数据线送出去。

**推演**：

1. 统一编址方式下，I/O 端口被映射到内存地址空间中，设某个 I/O 端口的地址为 $a$，则访问该端口等价于访问地址为 $a$ 的存储单元。  
2. RISC 指令集通常只允许 LOAD/STORE 指令访问存储器和内存映射 I/O，因此访问 I/O 端口也要使用 LOAD/STORE 指令，A 正确。  
3. 若系统启用 MMU，则 LOAD/STORE 指令中的有效地址先作为虚拟地址 $v$，经 MMU 转换成物理地址 $p=\mathrm{MMU}(v)$。I/O 端口被映射在内存地址空间中时，指令访问的是虚拟地址，再由 MMU 转换成对应 I/O 端口的物理地址，所以 B 正确。  
4. MMU 的页表项中可以设置权限位，例如用户态不可访问该页；用户程序若访问未授权给它的 I/O 端口页，MMU 会产生异常，从而实现特权级保护，因此 C 正确。  
5. 统一编址下，I/O 端口号就是端口地址。CPU 访问某端口时，必须把这个端口地址放到地址线上，I/O 接口中的地址译码器根据地址线信号选中对应端口；数据线只负责传输读到的数据或要写入的数据。D 说端口号通过数据线传送，与总线分工矛盾，因此 D 错误。

**易错点**：

- 误以为 B 错：有人觉得 I/O 端口最终对应的是物理地址，所以指令也应使用物理地址。实际上指令中的地址在进入 MMU 之前是虚拟地址，物理地址由 MMU 转换后产生。
- 误以为 C 错：认为特权保护只能靠专用 I/O 指令完成。但统一编址下，通过 MMU 页表权限位完全可以实现对 I/O 端口访问的保护。
- 混淆地址线和数据线的作用：地址线用于“选择哪个端口”，数据线用于“传输数据内容”；D 的错误正是把“端口号”当成了数据。
- 误以为 A 错：RISC 没有专门访问 I/O 端口的复杂指令，统一编址时用 LOAD/STORE 访问是正常且必要的。

**命题规律**：  
本题将 I/O 端口编址方式与 RISC 指令集、MMU 结合起来考查，核心是“统一编址 vs 独立编址”的区别。常见变式有：

- 改为判断“I/O 端口号是否通过地址线传送”；
- 改为对比独立编址下使用 IN/OUT 指令和专用特权保护机制；
- 结合内存映射 I/O 的页表属性，考查用户态能否访问设备寄存器。

复习时重点抓住：统一编址下 I/O 端口是内存地址空间的一部分，RISC 用 LOAD/STORE 访问；地址走地址线，数据走数据线；MMU 负责虚实地址转换和页级特权保护。

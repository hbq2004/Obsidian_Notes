# MCQ 第 4 题

![[_Attachments/题目识别/27_零壹习题册-题目/CO-C07-Q004_题目.png|题目]]

下面各类型设备控制器的 I/O 端口的编址最适合使用统一编址方式的是（　　）.

(A) 键盘控制器
(B) DMA 控制器
(C) GPU 控制器
(D) 串口控制器

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/CO-C07-Q004_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C（GPU 控制器）。因为 GPU 控制器含有大量显存/帧缓冲，统一编址可将这些存储空间映射到主存地址空间，CPU 用访存指令即可直接读写，所以最适合统一编址。

**解题切入点**：先抓住两种编址方式的本质区别：统一编址是“I/O 端口与主存共用地址空间”，独立编址是“I/O 端口有独立地址空间，用专用 I/O 指令”。然后看哪个设备需要 CPU 直接、大量地访问其存储空间。不要一看到 DMA 就选 DMA，DMA 的重点是“不经 CPU 传数据”，而不是让 CPU 用访存指令访问大量端口。

**推演**：

设主存地址空间为 $M$，I/O 端口地址集合为 $P$。

- 统一编址：
  $$
  P\subseteq M
  $$
  即 I/O 端口地址是主存地址空间的一部分，CPU 无需专门的 I/O 指令，直接使用访存指令（如 $\text{LOAD}$、$\text{STORE}$）访问端口。

- 独立编址：
  $$
  P\cap M=\varnothing
  $$
  即 I/O 端口有独立地址空间，CPU 需要使用专门的 $\mathrm{IN}/\mathrm{OUT}$ 指令访问端口。

逐项分析：

1. **键盘控制器**：数据量小，端口少，通常只需少量状态、数据和命令寄存器，用独立编址即可，不必占用主存地址空间。

2. **DMA 控制器**：CPU 对 DMA 控制器主要进行初始化，写入内存起始地址、传输字数、控制字等，寄存器数量有限。真正的大块数据传送是由 DMA 控制器直接控制总线完成，不通过 CPU 逐字读写 I/O 端口，因此不是“最适合”统一编址的选项。

3. **GPU 控制器**：含有大量显存/帧缓冲。采用统一编址后，显存可映射到主存地址空间，CPU 可以直接用访存指令向显存写入像素数据，适合大量、快速的图形数据访问，因此最合适。

4. **串口控制器**：以字节为单位传送数据，速率较低，端口数量少，同样适合独立编址。

因此选 **C**。

**易错点**：

- **误选 DMA 控制器**：DMA 虽然传输数据量大，但数据不经过 CPU；CPU 只是配置 DMA 控制器的少量寄存器，不能把“DMA 传输大量数据”和“统一编址适合大量数据访问”混为一谈。
- **误以为统一编址适合所有高速设备**：统一编址的关键是设备存储区需要被 CPU 直接按内存方式访问，键盘、串口这类小数据量设备用独立编址更节省主存空间。
- **混淆“统一编址”与“DMA”**：统一编址解决的是 CPU 怎样访问设备寄存器/缓冲区；DMA 解决的是数据如何不经过 CPU 在外设与主存之间传送。

**命题规律**：考点是 I/O 端口编址方式的分类、特点与适用场景。常见变式有：问某设备应采用统一编址还是独立编址；给出编址特点判断属于哪种方式；考查统一编址的优缺点。复习时应牢记：统一编址 = 端口地址与主存地址合并，占主存空间，用访存指令；独立编址 = 端口地址独立，不占主存空间，用专用 I/O 指令。

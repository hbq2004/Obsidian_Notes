# MCQ 第 7 题

![[_Attachments/题目识别/27_零壹习题册-题目/CO-C07-Q007_题目.png|题目]]

7. 某计算机中的 DMA 过程采用周期挪用法，下面说法正确的是 ( ) .
(A) 总线仲裁机构在每个时钟周期检测和响应 DMA 请求
(B) 适用于 I/O 速度远小于 CPU 访存速度的场景
(C) 当 CPU 访存和 DMA 传输同时请求总线时，总线优先分配给访存操作
(D) 在每个存储周期内，DMA 控制器和 CPU 均可以访问存储器

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/CO-C07-Q007_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A。周期挪用法中，总线仲裁机构需要在每个时钟周期检测并响应 DMA 请求，以便在 CPU 放弃总线的时间隙“插入”DMA 传输，因此 A 正确。

**解题切入点**：  
拿到“周期挪用法”先定位到 DMA 的三种实现方式：停止 CPU 访存、周期挪用、交替访存。关键是区分“挪用”与“交替”的差别。可以类比为单车道收费站：CPU 是常客，DMA 是偶尔插队的应急车；管理员要时刻观察应急车是否到达，一旦到达就让常客等一个存储周期，应急车先通过。选项中的“每个时钟周期检测“正对应这种高频监听机制。

**推演**：

- 周期挪用法的基本过程是：外设准备好数据后，DMA 控制器提出总线请求；总线仲裁机构在每个时钟周期采样总线请求；若检测到 DMA 请求，则 CPU 在当前存储周期结束后让出一个存储周期，DMA 完成一次数据传送，然后立即释放总线。  
  因此，总线仲裁机构需要以时钟周期为粒度检测 DMA 请求，A 正确。

- 选项 B 说“适用于 I/O 速度远小于 CPU 访存速度的场景”。若 I/O 速度远小于 CPU 访存速度，则用程序中断方式即可满足要求，没有必要使用 DMA 硬件；DMA 主要用于高速外设数据传送，其速度虽低于主存，但传送频繁、实时性要求高。因此 B 错误。

- 选项 C 说“当 CPU 访存和 DMA 传输同时请求总线时，总线优先分配给访存操作”。DMA 传输若不能及时响应可能丢失数据，因此 DMA 请求的优先级高于 CPU 访存请求，CPU 访存可以等待。故 C 错误。

- 选项 D 说“在每个存储周期内，DMA 控制器和 CPU 均可以访问存储器”。这是“交替访存”方式的特点，而不是周期挪用法。周期挪用是 DMA 请求到来时“偶尔”挪用某个存储周期，并非每个存储周期内 CPU 和 DMA 都能访问存储器。故 D 错误。

综上，正确选项为 A。

**易错点**：

1. **误选 B**：看到“I/O 速度远小于 CPU 访存速度”就认为适合 DMA。实际上，I/O 速度过慢时中断方式即可，DMA 的成本不能体现；周期挪用适用于外设速度低于主存速度但传送实时性要求较高的场景。  
2. **误选 C**：误以为 CPU 访存优先。实际 DMA 请求的优先级通常高于 CPU 访存，因为 CPU 访存可以等待，而 DMA 不及时响应会丢失数据。  
3. **误选 D**：把“周期挪用”和“交替访存”混淆。交替访存才是每个存储周期内 CPU 和 DMA 分时访问存储器。  
4. **对 A 的怀疑**：“每个时钟周期检测”不等于“每个时钟周期都让 CPU 暂停”，而是仲裁机构需要高频采样 DMA 请求，及时响应。

**命题规律**：  
考点定位在“DMA 方式”的三种实现方式对比，以及 DMA 请求与 CPU 访存的优先级关系。常见变式有：给出外设传送速率、存储周期、CPU 访存频率，计算 DMA 挪用周期占用 CPU 的时间比例；或将 DMA 与中断方式对比；或考查“周期挪用”与“交替访存”的区别。复习时应将停止 CPU 访存、周期挪用、交替访存的特点列表对比，牢记：DMA 请求优先级高于 CPU 访存；周期挪用是“用时申请、用完即还”；交替访存是“固定时间片轮流访问”。同时注意存储周期与时钟周期的换算，这是相关计算题的易错点。

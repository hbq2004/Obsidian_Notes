# MCQ 第 3 题

![[_Attachments/题目识别/27_零壹习题册-题目/CO-C07-Q003_题目.png|题目]]

3. 键盘采用中断控制方式实现 I/O，则中断发生时，键盘输入数据位于 （ ）.
(A) 键盘设备内
(B) I/O 接口中的数据缓冲寄存器
(C) 内核缓冲区中
(D) CPU 的通用寄存器中

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/CO-C07-Q003_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。中断发生时，键盘输入数据已经由键盘设备送入 I/O 接口中的数据缓冲寄存器，等待 CPU 在中断服务程序中读取。

**解题切入点**：抓住“中断控制方式”的 I/O 数据流通路径：设备 → I/O 接口中的数据缓冲寄存器 → CPU 寄存器 → 内存。题目问“中断发生时”数据的位置，本质是考查中断请求产生时数据已经到达哪个环节。可以类比：快递到了驿站（接口缓冲寄存器）后，驿站才发短信通知你去取（发中断），而不是快递还在路上（设备内部）或已经放到你家（内存）才通知。

**推演**：

1. 键盘是一种典型的字符输入设备，采用中断控制方式时，其工作流程为：
   - 用户按下按键，键盘内部产生扫描码；
   - 键盘硬件将扫描码送入 **I/O 接口中的接收数据缓冲寄存器**；
   - 当数据缓冲寄存器准备好后，接口向 CPU 发出中断请求信号；
   - CPU 响应中断，在中断服务程序中从该数据缓冲寄存器读取数据到 CPU 通用寄存器；
   - 再将数据写入内存中的缓冲区（如内核缓冲区）。

2. 本题问“中断发生时”，即中断请求信号已经产生、但 CPU 尚未执行中断服务程序的时刻。此时：
   - 数据已被移出键盘设备，因此不在选项 A 的“键盘设备内”；
   - 数据尚未被 CPU 读取，因此不在选项 D 的“CPU 通用寄存器中”；
   - 数据尚未被写入内存，因此不在选项 C 的“内核缓冲区中”；
   - 数据正停留在接口的数据缓冲寄存器中等待读取，因此选 B。

3. 用流程时间轴表示：
   $$
   \text{按键产生扫描码} \to \text{扫描码进入接口数据缓冲寄存器} \to \text{接口发出中断请求}
   \to \text{CPU响应中断} \to \text{中断服务程序读取缓冲寄存器中的数据}
   $$
   可见，发出中断请求时，数据位于“I/O 接口中的数据缓冲寄存器”。

**易错点**：

- **误选 A（键盘设备内）**：混淆“设备内部准备数据”和“发出中断”的时机。实际上设备完成数据准备后，会将数据送到接口寄存器，然后才发中断；发中断时数据已不在设备内部。
- **误选 C（内核缓冲区）**：将“中断发生”与“中断处理完成”混淆。内核缓冲区是 CPU 读取数据后写入的内存区域，属于中断服务程序的后续操作，不是中断发生时数据所在位置。
- **误选 D（CPU 通用寄存器）**：CPU 通用寄存器是中断服务程序读取数据的“中转站”，但不是数据停留的位置。若数据已在寄存器中，说明 CPU 已经开始处理，中断已经响应，不再是“中断发生时”。

**命题规律**：

- 该题属于计算机组成原理中“I/O 控制方式”的常规考点，常与程序查询方式、中断方式、DMA 方式对比出题。核心是掌握不同方式下数据流动路径和 CPU 参与程度。
- 常见变式：
  - 问“程序查询方式时，CPU 读取数据前数据位于何处？”答案同样是接口中的数据缓冲寄存器。
  - 问“DMA 方式中，数据从设备到内存经过哪些部件？”重点考查 DMA 控制器和内存直接传输。
  - 结合中断响应过程，问“中断响应期间 CPU 做了什么？”此时需注意响应阶段不读取数据，只保存断点、关中断、识别中断源，读取数据发生在中断服务程序阶段。
- 复习建议：画清“设备 → 接口寄存器 → CPU → 内存”的数据流图，并熟记中断方式下“中断请求产生时数据已就绪于接口寄存器”这一结论；同时区分“中断响应”和“中断处理”的时序，避免混淆。

# MCQ 第 2 题

![[_Attachments/题目识别/27_零壹习题册-题目/CO-C07-Q002_题目.png|题目]]

2. 在 DMA 方式下完成磁盘与主存数据交换的过程中，CPU 发出的 I/O 命令首先到达 （  ）.
(A) DMA 控制器
(B) 磁盘控制器
(C) 主存
(D) 中断控制器

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/CO-C07-Q002_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A（DMA 控制器）。CPU 在 DMA 方式下只负责启动 DMA 控制器，I/O 命令先发往 DMA 控制器，由它后续控制磁盘控制器完成数据交换。

**解题切入点**：拿到题目先想“DMA 方式是 CPU 把数据传送控制权交给谁”。不要一看到“磁盘”就选磁盘控制器；DMA 控制器是 CPU 与设备之间的“代理”。可以类比：CPU 是老板，DMA 控制器是项目经理，磁盘控制器是施工队，老板的命令先给项目经理，再由项目经理指挥施工队。

**推演**：

DMA 方式的磁盘与主存数据交换分三个阶段：

1. 预处理阶段：  
   CPU 执行 I/O 指令，向 DMA 控制器发送本次传送所需的参数，包括设备地址、内存首地址、传送方向、传送长度等，并把 DMA 控制器的控制寄存器置为“启动”状态。这个“启动命令”就是 CPU 发出的 I/O 命令。

2. 数据传送阶段：  
   DMA 控制器申请总线控制权并获得总线后，向磁盘控制器发出具体的读/写命令；磁盘控制器驱动磁盘工作，数据在磁盘与主存之间直接传送，CPU 不逐字干预。

3. 后处理阶段：  
   数据传送结束后，DMA 控制器通过中断控制器向 CPU 发出中断请求，通知 CPU“传送完成”。

因此 CPU 发出的 I/O 命令路径为：

$$\text{CPU} \rightarrow \text{DMA 控制器} \rightarrow \text{磁盘控制器} \rightarrow \text{磁盘}$$

可见，命令首先到达 DMA 控制器，而不是磁盘控制器或主存。中断控制器只在传输结束后参与“通知”，不是命令入口。

**易错点**：

- 误选 B：看到“磁盘”就认为 CPU 直接给磁盘控制器发命令。实际上 DMA 控制器是 CPU 与设备之间的接口，磁盘控制器接受 DMA 控制器的命令。
- 误选 C：主存是数据传送的目的地/源端，不是命令接收端。
- 误选 D：中断控制器在 DMA 传送完成后用于向 CPU 发中断，不在命令入口处。

规避方法：牢记命令流向是“CPU → DMA 控制器 → 磁盘控制器”，而中断报告是在传送结束后。

**命题规律**：考点为 DMA 控制器的功能和 DMA 数据传送流程，尤其是“CPU 何时介入、DMA 何时接管总线”。常见变式有：问“DMA 传送结束后如何通知 CPU”，答案为“中断”；问“传送前参数由谁设置”，答案为“CPU”；问“DMA 与程序中断方式的主要区别”，关键在 DMA 是以数据块为单位、只在开始和结束时打扰 CPU。复习时建议把程序查询、程序中断、DMA、通道四种 I/O 方式的命令路径和 CPU 卷入程度对比记忆。

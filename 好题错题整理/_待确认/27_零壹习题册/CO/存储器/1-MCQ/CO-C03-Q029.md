29. 有如下 C 语言程序段：
```
for (int i = 0; i < 10; i++) {
    for (int j = 0; j < 72; j++) {
        a[j] = a[j] + 3;
    }
}
```

(A) 7.5%
(B) 25%
(C) 12.5%
(D) 15%

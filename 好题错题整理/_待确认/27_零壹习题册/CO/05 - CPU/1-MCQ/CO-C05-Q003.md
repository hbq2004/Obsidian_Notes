# MCQ 第 3 题

![[_Attachments/题目识别/27_零壹习题册-题目/CO-C05-Q003_题目.png|题目]]

3. CPU 的核心是控制指令执行，对应指令执行过程错误的是 （ ）.
(A) CPU 执行指令的大致过程为取指并计算下一个指令地址-> 指令译码-> 计算源操作数地址并取数-> 数据运算操作-> 计算目的操作数地址并存结果
(B) 指令执行中最常用的 4 个基本操作包含读某个单元内容并装入寄存器、将寄存器中数据存入某个单元、寄存器数据到另一寄存器或 ALU 一端、数据运算并写入寄存器
(C) 异常事件在当前指令执行过程中进行检测，中断请求则在当前指令执行后进行检测，这里的指令执行过程就是指令的执行周期，不包含取指间址等
(D) CPU 取出并执行一个指令的时间对应一个指令周期，指令周期由取指周期、间址周期、执行周期、中断周期构成

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/CO-C05-Q003_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。选项 C 把异常/中断检测中所说的“当前指令执行过程”错误地等同于“执行周期”，实际上它应指完整的指令周期，取指、间址等阶段也可能发生异常。

**解题切入点**：拿到题目先定位考点：指令周期与机器周期的划分、指令执行的基本操作、异常与中断的检测时机。看到 C 中“就是”“不包含”等绝对化关键词，应立刻警惕，它很可能把“指令周期”和“执行周期”混为一谈。

**推演**：  
指令周期是“取出并执行一条指令”所需的时间，通常由若干机器周期组成；机器周期可取为取指周期、间址周期、执行周期、中断周期等。即  
$$T_{\text{指令周期}}=\sum_{i\in S} T_{\text{机器周期}}^{(i)},\quad S\subseteq\{\text{取指,间址,执行,中断}\}.$$  
不是每条指令都必须包含全部四种周期，但这不影响 D 作为教材中通用构成表述的正确性。

- **A 正确**：它概括了取指、形成下一条指令地址、译码、取源操作数、运算、写回目的结果的宏观过程。
- **B 正确**：它对应指令执行中最常用的四种基本操作：取数、存数、传送、运算。
- **C 错误**：异常不一定只在“执行周期”内检测。例如非法操作码可能在译码阶段发现，缺页可能在取指阶段或取操作数阶段发现，地址越界可能在访存阶段发现。因此“指令执行过程”应理解为完整的指令周期，而不只是执行周期。
- **D 正确**：取指周期、间址周期、执行周期、中断周期是指令周期可能包含的机器周期；没有间址或中断请求时相应周期不出现。

**易错点**：  
1. 混淆“指令周期”和“执行周期”：指令周期包含取指、间址、执行、中断等；执行周期只是其中一部分。  
2. 误以为所有异常都发生在 ALU 运算阶段：非法操作码、缺页、地址越界等异常可能发生在取指、译码或访存阶段。  
3. 误选 D：D 是教材中的标准构成说法，不能因为“每条指令不一定都有间址周期/中断周期”就判它错。  
4. 对 A 不必过度抠字眼：A 是宏观流程，具体指令可能省略某些环节，但整体顺序没有错误。

**命题规律**：  
考点是“指令执行过程 / 指令周期 / 异常与中断的检测时机”，属于 CPU 控制器部分的基本概念。常见变式有：判断某具体指令包含哪些机器周期；区分异常与中断的响应时机；结合机器周期、时钟周期计算指令周期时间。复习时建议画清“指令周期状态图”，并把异常/中断的典型例子按阶段分类记忆。

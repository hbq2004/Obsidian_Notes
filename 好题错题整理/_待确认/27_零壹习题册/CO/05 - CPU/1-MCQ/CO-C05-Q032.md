# MCQ 第 32 题

![[_Attachments/题目识别/27_零壹习题册-题目/CO-C05-Q032_题目.png|题目]]

32. 指令流水线中可能遇到一些情况，使流水线无法正确执行后续指令，引起流水线的阻塞或停顿，称为流水线冒险。下列关于流水线冒险的说法正确的是（ ）.

(A) 冒险主要分为数据冒险与结构冒险这两种

(B) 不同指令的相同阶段使用相同部件，且一个部件每个指令只能使用一次，能避免数据冒险

(C) 若只有同一个单口寄存器组，跟单口存储器会使不同指令的ID与WR，IF与MEM这两组段出现结构冒险

(D) 流水线使用分离的指令 Cache 与数据 Cache 分别作为指令存储器、数据存储器；寄存器组读写口分离，可以半个周期读、半个周期写，都只能解决结构冒险

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/CO-C05-Q032_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。单口寄存器组会导致不同指令的 ID 与 WR 阶段争用寄存器，单口存储器会导致 IF 与 MEM 阶段争用存储器，均属于结构冒险。

**解题切入点**：拿到题目先明确“流水线冒险”的分类——结构冒险、数据冒险、控制冒险。然后逐项核对选项中的描述属于哪一类冒险，尤其要抓住结构冒险的本质是“同一部件在同一周期被多条指令同时请求”。可以把流水线想象成工厂流水线：如果两个工位都要用同一台机器，而机器只有一台，就会“堵车”，这就是结构冒险；如果后面工序需要前面工序的产品还没做好，就是数据冒险。

**推演**：

1. 选项A：  
   流水线冒险通常分为三类：**结构冒险（资源冲突）、数据冒险（数据相关）、控制冒险（分支/跳转引起的冒险）**。  
   A 只提到数据冒险和结构冒险，遗漏了控制冒险，因此 A 错误。

2. 选项B：  
   “不同指令的相同阶段使用相同部件，且一个部件每个指令只能使用一次”，描述的是多条指令在同一时刻争用同一部件，这正是**结构冒险**的定义。  
   例如，若指令存储器和数据存储器是同一个存储器，取指（IF）和访存（MEM）就可能冲突。  
   数据冒险则是由指令之间的数据依赖（如写后读 RAW）造成的，并不是因为部件共享。因此 B 把结构冒险说成能避免数据冒险，概念混淆，B 错误。

3. 选项C：  
   设流水线阶段为 IF、ID、EX、MEM、WR。  
   - 单口寄存器组只有一个读写端口，同一时刻只能进行一次读或写操作。当第 $i$ 条指令在 ID 段读寄存器时，第 $i-1$ 条指令可能正在 WR 段写寄存器，两者都要访问寄存器组，产生冲突。  
   - 单口存储器只有一个访问端口，同一周期不能同时支持取指令和访问数据。当第 $i$ 条指令在 IF 段取指时，第 $i-1$ 条指令可能正在 MEM 段访存，两者都要访问存储器，产生冲突。  
   这两组冲突都是因为资源不足，属于结构冒险。C 描述完全正确。

4. 选项D：  
   - 使用分离的指令 Cache 和数据 Cache，使 IF 与 MEM 可以并行，确实解决了“取指与访存”的结构冒险。  
   - 寄存器组读写口分离（多端口），允许同一周期内读与写同时进行，也解决了 ID 与 WR 的结构冒险。  
   但 D 中“可以半个周期读、半个周期写”并不是“读写口分离”的含义，读写口分离是提供独立的读口和写口，而不是把周期切分两半；半个周期读、半个周期写通常是对单口部件的分时复用方案。  
   此外，“都只能解决结构冒险”表述过于绝对，虽然这些方法主要解决结构冒险，但题目中 C 已是完全正确的选项，D 存在表述错误。因此 D 不正确。

综上，正确选项为 C。

**易错点**：

- **混淆结构冒险和数据冒险**：看到“同一个部件”就以为是数据冒险。记住：争用部件是结构冒险，争用数据结果才是数据冒险。
- **忽视控制冒险**：A 选项故意只列两类，容易忽略分支指令带来的控制冒险。
- **对单口部件冲突区间判断不清**：要知道 IF 与 MEM、ID 与 WR 是典型的可能同时访问同一存储/寄存器部件的阶段。
- **误解 D 中存储器/寄存器组的设计**：分离 Cache 和端口分离解决的是资源冲突，不是数据冒险；且“半个周期读、半个周期写”不属于端口分离。

**命题规律**：

- **考点定位**：计算机组成原理章节中的“流水线冒险”分类及结构冒险的识别。
- **常见变式**：
  1. 给出具体流水线序列，判断某一时刻发生的是哪种冒险；
  2. 给出解决方案，问解决的是哪类冒险；
  3. 结合数据冒险（RAW/WAR/WAW）和控制冒险（分支预测）出题。
- **复习建议**：
  1. 牢记三类冒险的名称、产生原因和典型例子；
  2. 会画简单流水线时空图，标出 IF、ID、EX、MEM、WR 的重叠区间；
  3. 掌握解决结构冒险的常见手段：部件分离（指令 Cache 与数据 Cache 分离、寄存器组多端口）、资源重复、分时复用等；
  4. 做题时先看选项中的“冒险类型”是否匹配原因，再关注细节表述是否准确，避免被绝对化词语误导。

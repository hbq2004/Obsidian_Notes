# MCQ 第 2 题

![[_Attachments/题目识别/27_零壹习题册-题目/CO-C05-Q002_题目.png|题目]]

2. 以下内容对于 CPU 描述错误的是（ ）.
(A) 早期计算机采用“存储程序”工作方法，CPU 是其中专门进行指令执行的部件
(B) CPU 在反复执行指令，指令执行不可避免出现异常中断，所以 CPU 包含异常和中断处理逻辑
(C) CPU 由数据通路与控制部件组成，控制部件需要根据指令功能生成对应的控制信号
(D) CPU 中 IR、PC、指令译码器、CU 和状态寄存器（PSW）都属于控制器

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/CO-C05-Q002_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。$PSW$（程序状态字寄存器）记录运算结果的特征状态，属于运算器而非控制器；$IR$、$PC$、指令译码器、$CU$ 才属于控制器。

**解题切入点**：拿到题先抓“CPU 内部部件归类”这个考点。就像算法竞赛里先看“数据范围”确定算法一样，本题看到 $IR$、$PC$、$PSW$、$CU$ 等名词，应立即联想到“控制器 vs 运算器”的组成图。记住一个口诀：**“PC、IR、ID、CU 是控制器；ALU、ACC、PSW、通用寄存器是运算器/数据通路”**，可快速定位错误项。

**推演**：

1. **选项 A**：早期冯·诺依曼计算机采用“存储程序”工作方式，程序和数据预先存入存储器，CPU 负责逐条取出指令并执行。说 CPU 是“专门进行指令执行的部件”是从功能角度概括，正确。

2. **选项 B**：CPU 不断取指、译码、执行，执行过程中可能发生除法溢出、缺页、外部设备请求等情况，即异常和中断。CPU 内确实包含异常/中断处理逻辑，用于保存断点、转移处理程序并恢复现场，正确。

3. **选项 C**：现代 CPU 内部可抽象为数据通路与控制部件两大部分。控制部件根据指令译码结果生成一系列控制信号，指挥数据通路完成运算和传送，正确。

4. **选项 D**：控制器的主要组成是：

   - $PC$：程序计数器，存放下一条指令地址；
   - $IR$：指令寄存器，存放当前指令；
   - 指令译码器：将操作码译成控制信号；
   - $CU$：控制单元，产生微操作控制信号；
   - 时序系统等。

   而 $PSW$ 是程序状态字寄存器，又称标志寄存器，存放运算结果的特征标志，如零标志 $ZF$、进位标志 $CF$、溢出标志 $OF$ 等。这些标志由运算器中的 $ALU$ 产生，因此 $PSW$ 通常归入运算器，而不是控制器。所以 D 错误。

**易错点**：

- **误以为 $PSW$ 与指令执行有关就属于控制器**。实际上 $PSW$ 记录的是运算结果的状态，供后续条件转移指令判断，它由运算器产生，属于运算器/数据通路。
- **混淆“控制器”和“控制部件”**：选项 C 中的“控制部件”指 $CU$，与选项 D 中大概念“控制器”不完全等同。控制器包括 $PC$、$IR$、译码器、时序系统、$CU$ 等。
- **忽略 $PC$、$IR$ 的名字**：$PC$ 是“程序计数器”，$IR$ 是“指令寄存器”，二者虽带有“寄存器”字样，但属于控制器，不能因为它们叫“寄存器”就归入运算器。
- **把 $ACC$ 与 $PC$ 混为一谈**：$ACC$ 是累加器，属于运算器；$PC$ 是程序计数器，属于控制器。做题时注意英文缩写对应功能。

**命题规律**：本题属于计算机组成原理中“CPU 的结构与功能”的经典选择题，常考控制器与运算器的部件划分、各寄存器的作用。常见变式有：

- 给出 $IR$、$MAR$、$MDR$、$PSW$、$ACC$ 等，问哪些属于控制器；
- 问“指令执行过程中，$PC$ 和 $IR$ 各起什么作用”；
- 结合指令流水线，考查 $PC$ 自动加“1”的操作属于哪个部件；
- 结合中断，考查中断向量地址与 $PSW$ 的保存位置。

复习建议：以教材的 CPU 结构框图为纲，把每个部件的英文缩写、中文名称、功能、所属大部件整理成表格；再通过历年真题反复巩固，做到“见缩写即反应出归类”。

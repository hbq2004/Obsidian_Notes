# MCQ 第 5 题

![[_Attachments/题目识别/27_零壹习题册-题目/CO-C05-Q005_题目.png|题目]]

5. 下列措施中，对于直接减少表达式计算过程中临时变量写回到主存的次数无效的是 (   ).

(A) 增加通用寄存器数量
(B) 优化编译器寄存器分配策略
(C) 增加 Cache 容量
(D) 增加页表容量

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/CO-C05-Q005_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。增加页表容量只是扩大虚拟地址到物理地址的映射规模，并不能为表达式临时变量提供更快的暂存位置，也不能减少寄存器溢出或 Cache 写回流量；A、B 是从源头减少寄存器溢出，C 可在存储层次上减少实际写回主存的次数。

**解题切入点**：

先问自己：表达式计算中的临时变量“为什么”会写回主存？根本原因是寄存器不够用，或者编译器寄存器分配不好，导致临时变量必须被“溢出”到主存。因此，能直接减少写回的措施首先应和“寄存器数量”“寄存器分配策略”有关；Cache 是主存上一层的高速缓存，可以吸收一部分写流量；页表则只负责地址映射，和数据写回没有直接关系。

可以把这个问题类比为算法竞赛中“减少中间结果落盘”：  
- 增加内存变量：对应增加通用寄存器数量；  
- 优化变量复用：对应优化编译器寄存器分配策略；  
- 加一个盘缓存：对应增加 Cache 容量；  
- 扩大文件索引表：对应增加页表容量，显然无效。

**推演**：

设某一时刻程序中同时需要保存的活跃临时变量数为 $N_{\text{live}}$，可用的通用寄存器数为 $R$。在理想寄存器分配下，必须溢出到主存的临时变量数为

$$
N_{\text{spill}}=\max(0,\;N_{\text{live}}-R)
$$

增加通用寄存器数量 $R$ 会直接减小 $N_{\text{spill}}$；优化编译器寄存器分配策略则通过缩短变量活跃区间、提高寄存器复用率，来减小同一时刻的 $N_{\text{live}}$，从而也减小 $N_{\text{spill}}$。因此 A、B 均有效。

再看 Cache。设 Cache 容量为 $C$，缺失率 $P(C)$ 一般随 $C$ 增大而降低。若 Cache 采用写回法，写主存主要发生在“脏 Cache 块被替换”时，替换次数随缺失率下降而减少，因此增大 Cache 容量可以减少真正写主存的次数。这说明 C 并不是无效措施。

页表容量 $S$ 只影响虚拟页号到物理页号的映射能力。表达式临时变量写回主存的数据通路是“寄存器 → Cache → 主存”，页表容量不参与该通路；同时增大 $S$ 既不改变 $R$，也不改变 $N_{\text{live}}$，也不改变 Cache 命中率，因此对题目所问的写回次数没有作用，故选 D。

**易错点**：

1. 误以为 Cache 只能减少“读主存”次数，忽略了写回法下增大 Cache 容量可减少脏块替换导致的写主存次数。  
2. 误以为“增加 Cache 容量不能减少编译器生成的 store 指令条数”，所以认为 C 无效。要注意区分“访存指令条数”和“实际落到主存的写次数”；在存储层次中，Cache 可以吸收一部分写流量。  
3. 误把“增加页表容量”和“减少缺页”联系起来，认为它能减少主存与外存的交换；但缺页是“主存—磁盘”之间的交换，和表达式临时变量“寄存器—主存”的写回是两回事。  
4. 如果纠结 Cache 写直达与写回策略的区别，需要注意：本题是单选题，D 在任何写策略下都没有作用，而 A、B 显然有效，所以不影响最终答案。

**命题规律**：

本题将编译优化中的寄存器分配与计算机组成原理中的存储层次结合起来，考查“减少访存/写回”的软硬件手段。常见变式有：  
- 把“表达式临时变量写回主存”换成“过程调用时保存/恢复现场”；  
- 把“增加 Cache 容量”换成“提高 Cache 命中率”“增大主存容量”；  
- 把“页表容量”换成“TLB 容量”等作为干扰项。

复习建议：建立“寄存器—Cache—主存—磁盘”的层次存储模型，明确每一层的容量和策略分别能缓解什么瓶颈；同时记住：寄存器溢出是编译器层面问题，Cache 是存储层次问题，页表是虚拟存储映射问题。做题时优先找“最无关”的选项。

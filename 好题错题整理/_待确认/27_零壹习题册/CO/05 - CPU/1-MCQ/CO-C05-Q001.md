# MCQ 第 1 题

![[_Attachments/题目识别/27_零壹习题册-题目/CO-C05-Q001_题目.png|题目]]

1. 在冯诺依曼结构计算机中，CPU 执行程序时最核心的职责是（ ）．
(A) 长期保存用户文件
(B) 按指令序列取指、译码并控制数据加工
(C) 为所有外设分配物理地址
(D) 决定磁盘文件的目录结构

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/CO-C05-Q001_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。CPU 在冯诺依曼结构中核心职责是按照指令序列完成取指、译码，并控制算术逻辑部件对数据进行加工。

**解题切入点**：拿到题目先抓“冯诺依曼结构”和“CPU 执行程序时最核心的职责”。冯诺依曼结构的核心思想是“存储程序、程序控制”，即指令和数据都存放在存储器中，CPU 自动地从存储器中逐条取出指令、分析并执行。因此要选与“取指—译码—执行”直接相关的选项，而不是存储管理、外部设备管理或文件系统等外围功能。

**推演**：

1. 冯诺依曼计算机由运算器、控制器、存储器、输入设备和输出设备五大部分组成。其本质特征是“存储程序”，即程序由一串指令组成，预先存入内存。
2. CPU 通常包含运算器和控制器。控制器负责从内存中取指令（取指）、对指令进行译码（分析指令）、生成控制信号，并控制运算器完成数据加工（执行）。
3. 设指令周期为取指周期、间址周期、执行周期与中断周期的组合，其中取指阶段 CPU 根据程序计数器 PC 给出指令地址，从主存读出指令送入指令寄存器 IR；译码阶段由操作码译码器识别操作类型；执行阶段由控制信号驱动 ALU 完成算术/逻辑运算。
4. 对比选项：
   - (A) 长期保存用户文件：属于外存（磁盘）和文件系统的功能，不是 CPU 的核心职责。
   - (B) 按指令序列取指、译码并控制数据加工：完整描述了“存储程序、程序控制”下的 CPU 工作过程，是正确项。
   - (C) 为所有外设分配物理地址：I/O 编址可能由系统设计决定，CPU 可以参与地址分配或寻址，但不是执行程序时的核心职责。
   - (D) 决定磁盘文件的目录结构：属于操作系统文件管理功能，不是 CPU 硬件职责。

因此，冯诺依曼结构中 CPU 执行程序时最核心的职责是 (B)。

**易错点**：

- 误选 (D)：看到“程序”就以为与文件管理有关，实际上 CPU 面对的是内存中的指令序列，不是磁盘目录。
- 误选 (C)：外设地址分配可能涉及 CPU，但属于系统设计/初始化问题，不是程序执行过程中的核心职责。
- 混淆“存储程序”与“程序存储”：冯诺依曼的关键是“指令和数据同等对待、按地址访问”，CPU 的核心动作是取指—译码—执行，而不是存储数据本身。
- 规避方法：凡是问“CPU 执行程序的核心职责”，优先定位到指令周期（取指、译码、执行、中断）与控制器功能，不选存储器、外设或操作系统的功能。

**命题规律**：

- 考点定位：计算机系统概述中的“冯诺依曼结构”与“CPU 的组成和功能”，属于 CO 基础概念题。
- 常见变式：  
  1. 问“冯诺依曼计算机的最根本特征” → 选“存储程序”。  
  2. 问“控制器的主要功能” → 选“取指、译码、控制执行”。  
  3. 给出指令周期流程图，判断各阶段功能。  
  4. 结合哈佛结构对比，考“指令和数据是否分开存储”。
- 复习建议：熟记冯诺依曼结构五大部件及其功能；理解“存储程序、程序控制”的含义；掌握 CPU 指令周期的基本流程（取指周期、间址周期、执行周期、中断周期），并能区分 CPU、存储器、I/O 设备、操作系统的职责边界。

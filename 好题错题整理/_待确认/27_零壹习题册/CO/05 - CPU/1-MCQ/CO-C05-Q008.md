# MCQ 第 8 题

![[_Attachments/题目识别/27_零壹习题册-题目/CO-C05-Q008_题目.png|题目]]

8. 下列对于数据通路中的组合跟状态单元说法错误的是 （ ） .
(A) 组合逻辑单元的输出只取决于当前的输入，不受时钟信号的控制.
(B) 常见的组合逻辑单元有多路选择器、加法器、算术逻辑单元、译码器，它们都需要控制信号.
(C) 寄存器是典型的状态存储元件，有输入端带写使能信号的触发器构成的暂存器，有输出端带三态门的寄存器，还有带自增/移位/复位功能的寄存器，PC一般使用带自增的寄存器.
(D) 多路选择器是多个输入端根据控制信号输出其中一个输入端的内容，译码器是根据输入的内容译码得到多位输出.

## DeepSeek V4 Flash Max 解析

**答案**：B。组合逻辑单元不一定都需要控制信号，例如加法器只需输入数据即可完成运算，不需要单独的控制信号。

**解题切入点**：
先抓“组合逻辑”和“状态单元”的本质区别：组合逻辑是无记忆的“纯函数”，输出只由当前输入决定；状态单元是有记忆的，输出还依赖之前保存的状态，需要时钟/写使能等信号控制更新。  
这就像算法里“纯函数”和“带全局状态的函数”的区别：纯函数不需要内部状态更新机制；带状态的结构才需要“时钟”和“使能”来控制状态改变。所以看到“组合逻辑单元都需要控制信号”这种绝对说法，要立刻警惕。

**推演**：

- 组合逻辑单元的输出可写为  
  $$Y = F(X)$$
  它与时钟无关，只取决于当前输入 $X$，所以 **A 正确**。

- 常见组合逻辑单元：
  - 多路选择器：$Y = D_{\mathrm{sel}}$，需要选择信号 $\mathrm{sel}$ 作为控制信号；
  - 加法器：$Y = A + B$，不需要控制信号；
  - ALU：$Y = F(A,B,\mathrm{op})$，需要操作码 $\mathrm{op}$ 控制运算类型；
  - 译码器：$n$ 位输入对应 $2^n$ 位输出，通常只需输入代码即可译码，使能端是可选的，不是必需的。

  可见“它们都需要控制信号”说法错误，因此 **B 错误**。

- 寄存器是典型的状态单元，可以有写使能、三态输出、自增、移位、复位等功能。  
  PC 需要顺序指向下一条指令，一般使用带自增功能的寄存器来实现，所以 **C 正确**。

- 多路选择器是“多路输入，由控制信号选择一路输出”；译码器是“按输入代码使对应输出线有效”，所以 **D 正确**。

故错误选项为 **B**。

**易错点**：
1. 误把“ALU 需要控制信号”推广为“所有组合逻辑都需要控制信号”，实际上加法器、与门、或门等都不需要。
2. 译码器可能有使能端，但使能端不是必需的；不能据此认为译码器一定需要控制信号。
3. 容易忽略题干问的是“错误的是”，而误选正确说法 A 或 D。
4. 不要把 PC 的“自增”理解成纯组合逻辑，PC 本质仍是状态单元，自增也是在时钟控制下完成的。

**命题规律**：
考点是“数据通路中组合逻辑单元与状态单元的分类和特征”。常见变式有：判断某个部件是组合逻辑还是状态单元；判断某个部件是否需要控制信号；结合单周期/多周期 CPU 数据通路考查 MUX、ALU、寄存器、PC、存储器等部件。复习时抓住本质：组合逻辑 = 无记忆 + 无时钟；状态单元 = 有记忆 + 由时钟/使能控制更新。

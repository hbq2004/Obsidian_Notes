# MCQ 第 30 题

![[_Attachments/题目识别/27_零壹习题册-题目/CO-C05-Q030_题目.png|题目]]

30. 指令流水线的核心段熟悉后，分析下图五段式流水线数据通路。若执行以下指令序列，下列说法错误的是 (  ).
```
add  $1,$1,$2          R1+R2->R1
sub  $3,$3,$4          R3-R4->R3
lw   $4,100($5)        M[R5+100]->R4
```
(A) 在 add 进入 Mem 阶段时，lw 指令刚进入 ID 段，sub 刚进入 EX 段，Mem 段控制信号为 MemWr=0，EX 段信号为 RegDst=1，R-type=1，ALUOp=sub .
(B) 从 add 指令开始第三个周期才有控制信号生效，对应的控制信号为 RegDst=1，R-type=1，ALUOp=add .
(C) $R1+R2$ 的结果放入 Mem/Wr 寄存器时，$R3-R4$ 的结果放入 Ex/Mem 寄存器，R5 与 imm16 放入 ID/EX 寄存器 .
(D) 若后续还有指令且不会流水线阻塞，从 add 的 IF 段开始到 load 指令的 ID 段，PC 最多有 3 个不同的值 .

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/CO-C05-Q030_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。无阻塞时，从 add 的 IF 段到 lw 的 ID 段，PC 会出现 4 个不同值，不是最多 3 个；A、B、C 均符合题图五段流水线的时序。

**解题切入点**：  
先画出五段流水线时空图，确定“第几个周期、哪条指令在哪一段”；再按“控制信号随指令逐级流动”来判断。可以把流水线比作传送带：每条指令都带着自己的“控制单”往后走，某个流水段看到的控制信号属于当前正在该段的指令，而不是其他指令。

**推演**：  

设三条指令分别为  
$I_1=\text{add }\$1,\$1,\$2$，$I_2=\text{sub }\$3,\$3,\$4$，$I_3=\text{lw }\$4,100(\$5)$。  
五段流水线无阻塞时空图为：

| 周期 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|
| add | IF | ID | EX | MEM | WB |  |  |
| sub |  | IF | ID | EX | MEM | WB |  |
| lw |  |  | IF | ID | EX | MEM | WB |

1. **A 正确**：第 4 周期时，add 在 MEM，sub 在 EX，lw 在 ID。add 是 R 型指令，不写存储器，所以 MEM 段 $MemWr=0$；sub 在 EX 段，其控制信号应为 R 型减法控制：$RegDst=1$、$R\text{-}type=1$、$ALUOp=sub$。

2. **B 正确**：add 第 1 周期 IF，第 2 周期 ID 译码产生控制信号，第 3 周期进入 EX 时才真正使用这些 EX 段控制信号。add 是 R 型加法，所以 $RegDst=1$、$R\text{-}type=1$、$ALUOp=add$。

3. **C 正确**：在第 4 周期结束的时钟边沿，add 的 ALU 结果从 EX/MEM 写入 MEM/WB（题中 Mem/Wr）；sub 的 ALU 结果写入 EX/MEM；lw 在 ID 段读出的 R5 与符号扩展立即数写入 ID/EX。三者同一时刻完成。

4. **D 错误**：设 add 地址为 $A$，则 sub、lw、下一条指令地址分别为  
$$
A,\ A+4,\ A+8,\ A+12
$$
无阻塞时 IF 每周期按 PC 取指，周期 1 到周期 4 的 PC 值分别是 $A,A+4,A+8,A+12$，共 4 个不同的值。尤其当 lw 在第 4 周期进入 ID 时，下一条指令已经在 IF 段，PC 已经取到第 4 个值，所以不是“最多 3 个”。

**易错点**：  
- 容易把 MEM 段 add 的控制信号与 EX 段 sub 的控制信号混淆；控制信号是跟指令走的。  
- “从 add 开始第三个周期”容易数错：第 1 周期 IF、第 2 周期 ID、第 3 周期 EX，控制信号在第 3 周期才真正作用于 EX 段。  
- 数 PC 时不要只看已列出的 3 条指令；从 add 的 IF 到 lw 的 ID 跨了 4 个时钟周期，第 4 周期 IF 已在取下一条指令，因此 PC 有 4 个不同值。

**命题规律**：  
考点是五段流水线时空图、流水段寄存器、控制信号随指令流动以及 PC 的变化。常见变式包括：给出某时刻各条指令所在段，判断控制信号；判断某时钟边沿哪些流水寄存器写入；结合数据冒险、转发和阻塞出题。复习时应熟练画出无阻塞时空图，并记住 IF/ID、ID/EX、EX/MEM、MEM/WB 四级流水寄存器的作用，控制信号必须随指令逐级传递。

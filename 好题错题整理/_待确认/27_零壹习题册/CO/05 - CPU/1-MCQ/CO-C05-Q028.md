# MCQ 第 28 题

![[_Attachments/题目识别/27_零壹习题册-题目/CO-C05-Q028_题目.png|题目]]

28. 指令流水线中每个指令都会经过取指段 IF 与译码/取数段 ID，下图是取指阶段的流水段电路，其中 12、16 是指令地址。下列关于指令流水线 IF 和 ID 两个阶段的说法正确的是（ ）.

【图：取指阶段流水段电路图，包含程序计数器 PC（值为 16）、加法器 Adder（加数为 4）、指令存储器 IM（地址输入为 12）、IF/ID 段间寄存器。图中标识了时钟信号 Clk、取指段 Ifetch 和译码段 Reg/Dec 的范围。】

① 图中的 16 是 IF 段结束、ID 段开始时写回 PC 中完成自增。
② 每个指令的 IF 与 ID 段都相同，是公共流水段，可以使用硬件实现，不需要控制信号。
③ IF 阶段 IM（指令存储器）是状态逻辑单元，因此 IF 阶段需要 PC→IM、IM→IF/ID 段间寄存器两个时钟。
④ $PC+4$ 放入 IF/ID 段间寄存器，是为了便于计算转移地址时使用。

(A) ①②③④
(B) ①②④
(C) ①③
(D) ②④

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/CO-C05-Q028_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。①②④正确，③错误；IF 段取指只需一个时钟周期，指令存储器的读操作不是“需要两个时钟”的状态逻辑。

**解题切入点**  
拿到题先抓住取指段的两条关键路径：  
1. PC 作为地址访问指令存储器 IM，读出指令送入 IF/ID 段间寄存器；  
2. 加法器计算 $PC+4$，既写回 PC，也送入 IF/ID 段间寄存器。  

把 IF/ID 边界看成“流水线拍照片”的时刻：PC 和 IF/ID 寄存器都在这个时钟边沿更新。这样就能判断①、③、④，再结合 IF/ID 是公共段判断②。

**推演**  
逐条分析：

1. **①正确。**  
   题图中的 16 是 $PC+4$，例如 $12+4=16$。  
   在 IF 段结束、ID 段开始的时钟边沿，$PC+4$ 写回 PC，使 PC 完成自增，为取下一条指令做准备。  
   因此“图中 16 在 IF 段结束、ID 段开始时写回 PC 完成自增”说法正确。

2. **②正确。**  
   每条指令都必须经过 IF 和 ID 段，所以 IF 和 ID 是公共流水段。  
   它们的硬件操作不随具体指令类型改变，因此可用固定的硬布线逻辑实现；这里的“不需要控制信号”是指不需要根据当前指令类型额外改变 IF/ID 本身的操作。  
   ID 段产生的控制信号是为后面 EX/MEM/WB 段服务的，不影响这一判断。

3. **③错误。**  
   指令存储器 IM 按地址读出指令时，其读操作在取指模型中等价于组合逻辑读取，不靠时钟触发。  
   IF 段只需一个时钟周期：同一周期内完成  
   $$
   \text{PC}\xrightarrow{\text{地址}} \text{IM}
   $$
   以及
   $$
   \text{IM}\xrightarrow{\text{指令}} \text{IF/ID}
   $$
   最终在时钟边沿把结果锁存到 IF/ID 寄存器。  
   不是说“PC→IM”一个时钟、“IM→IF/ID”又一个时钟。

4. **④正确。**  
   分支/转移地址常需要利用 $PC+4$ 计算，例如 MIPS 中分支目标地址为  
   $$
   (PC+4)+\text{偏移量}
   $$
   因此将 $PC+4$ 也存入 IF/ID 段间寄存器，便于 ID 段在计算转移地址时使用。

综上，正确的是①②④，选 **B**。

**易错点**  
- 误以为 IF 段要“两个时钟”：实际上 IM 的读操作是组合逻辑，真正由时钟控制的只有 PC 和 IF/ID 寄存器。  
- 误以为“不需要控制信号”表示 IF/ID 在真实流水线中完全没有控制信号；准确理解是公共段的固定操作不需要随指令类型改变控制方式。  
- 把 IF/ID 中保存的 $PC+4$ 误认为当前 PC，IF/ID 中保存的应是当前指令的 $PC+4$，用于后续转移地址计算。  
- 易把 PC 自增说成“IF 段开始时”完成；更准确地说，是在 IF 段结束、ID 段开始的时钟边沿完成写回。

**命题规律**  
本题属于指令流水线基础题，考点集中在：  
- 流水段间寄存器 IF/ID 的作用；  
- 组合逻辑与时钟控制逻辑的区分；  
- PC 自增和 $PC+4$ 的传递；  
- 公共段 IF/ID 的硬件实现特点。  

常见变式是改问“执行段 EX/访存段 MEM 中的某个元件是组合逻辑还是时序逻辑”“ID 段产生哪些控制信号”“分支转移地址如何计算”等。复习时应画一遍五段流水线数据通路，重点标出哪些部件由时钟驱动，哪些部件是组合逻辑读取，并理解 IF/ID 寄存器中 $PC+4$ 的用途。

# MCQ 第 22 题

![[_Attachments/题目识别/27_零壹习题册-题目/CO-C05-Q022_题目.png|题目]]

22. 某单周期数据通路支持 MIPS 的 R 型和 I 型指令，指令存储器延迟 3ns，寄存器堆读延迟 2ns，ALU 延迟 1ns，数据存储器延迟 5ns，寄存器堆写延迟 2ns。不考虑其他延迟，该数据通路的时钟周期为（）.

(A) 11ns
(B) 8ns
(C) 13ns
(D) 10ns

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/CO-C05-Q022_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C（13ns）。理由：单周期数据通路的时钟周期必须覆盖最长指令路径，MIPS 的 `lw` 取数指令路径最长，为 $3+2+1+5+2=13\text{ ns}$。

**解题切入点**：单周期处理器的时钟周期不由所有部件延迟之和决定，而由“最长数据通路/关键路径”决定。拿到题目先列出各类指令经过的部件，再找哪条指令路径最长；本题中 `lw` 会同时经过指令存储器、寄存器堆读、ALU、数据存储器、寄存器堆写，显然最长。

**推演**：

单周期数据通路中，每条指令在一个时钟周期内完成，因此时钟周期必须满足：

$$
T_{\text{clk}} \ge \max\{T_{\text{指令}}\}
$$

分别计算各类指令的路径延迟：

1. **R 型指令**：取指 → 读寄存器 → ALU 运算 → 写寄存器  
$$
T_R = 3 + 2 + 1 + 2 = 8\text{ ns}
$$

2. **I 型算术指令（如 `addi`）**：取指 → 读寄存器 → ALU 运算 → 写寄存器  
$$
T_{addi} = 3 + 2 + 1 + 2 = 8\text{ ns}
$$

3. **分支指令（如 `beq`）**：取指 → 读寄存器 → ALU 比较  
$$
T_{beq} = 3 + 2 + 1 = 6\text{ ns}
$$

4. **存数指令 `sw`**：取指 → 读寄存器 → ALU 计算地址 → 写数据存储器  
$$
T_{sw} = 3 + 2 + 1 + 5 = 11\text{ ns}
$$

5. **取数指令 `lw`**：取指 → 读寄存器 → ALU 计算地址 → 读数据存储器 → 写寄存器  
$$
T_{lw} = 3 + 2 + 1 + 5 + 2 = 13\text{ ns}
$$

因此：

$$
T_{\text{clk}} = \max\{8, 8, 6, 11, 13\} = 13\text{ ns}
$$

所以选 **C**。

**易错点**：

- 误选 B（8ns）：只考虑了 R 型或算术 I 型指令，忽略了 `lw` 还要访问数据存储器。
- 误选 A（11ns）：按 `sw` 存数指令路径计算，漏掉了 `lw` 最后的寄存器写延迟 $2\text{ ns}$。
- 误选 D（10ns）：可能漏算 ALU 延迟，或把部件延迟随意组合；必须严格沿数据通路累加。
- 不要把单周期时钟周期与流水线时钟周期混淆；单周期看最长指令总路径，流水线才看最慢段延迟。

**命题规律**：考点为“单周期处理器数据通路与时钟周期”，核心是找关键路径。常见变式有：给出各部件延迟求某类指令执行时间；反给时钟周期判断能否支持某条指令；或结合 CPI、流水线周期进行对比。复习时应熟记 MIPS 五类典型指令（R 型、`addi`、`lw`、`sw`、`beq`）的数据通路图，尤其记住 `lw` 是最长路径指令。

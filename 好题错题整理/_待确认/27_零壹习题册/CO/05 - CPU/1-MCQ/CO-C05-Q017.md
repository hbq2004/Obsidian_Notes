# MCQ 第 17 题

![[_Attachments/题目识别/27_零壹习题册-题目/CO-C05-Q017_题目.png|题目]]

17. 下图是引入条件转移指令 beq 后的单周期数据通路及下地址逻辑细节【图】，beq 功能为：
```
if (R[Rs] == R[Rt]) {
PC+4+(SignExt(imm16)*4) -> PC;
} else {
PC+4 -> PC;
}
```
增加了取指令部件，转移目标地址在下地址逻辑中计算，Branch=1 表示分支指令。下列说法错误的是（）.

(A) 单周期主要使用 MIPS 指令集，MIPS 指令一般都是 32 位定长的，所以 PC 自增公式是 +4，转移是自增后 +SignExt($imm16$)×4
(B) beq 指令控制信号取值为：RegWr=0，RegDst=0/1，ALUSrc=0，ExtOp=0/1，ALUctr=subu，MemtoReg=0/1，MemWr=0，Branch=1
(C) 每个指令都是 32 位，每个指令地址的低 2 位都是 00，PC 最少需要 30 位，右侧电路中转移指令为 $PC+1+SignExt(imm16) \rightarrow PC$，这 30 位就是最后取指令的地址，图中的 00 需要删除
(D) 只有 Rs 与 Rt 内容相同的时候 Zero=1，且是 beq 指令时 Branch=1，在右图电路中两个经过与门对应 MUX 的选择是 1 这一侧的结果

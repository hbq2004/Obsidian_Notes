# MCQ 第 10 题

![[_Attachments/题目识别/27_零壹习题册-题目/CO-C05-Q010_题目.png|题目]]

10. 上图右侧给出三总线数据通路，所有通用寄存器在双口寄存器堆中，允许两个寄存器内容同时输入到 A、B 总线，箭头方向就是数据流向，R1outA 对应寄存器 R1 的内容输入到 A 总线上。根据上述信息分析，下列说法错误的是（ ）.

(A) 若要实现 R1+R2->R1，比单总线数据通路快 2 个时钟，对应的控制信号为 R1outA,R2outB,add,R1inC
(B) 根据图的数据流向可知，R1 的数据要传送到 R2 上，需要 ALU 提供直送功能（mov），因为只有 ALU 可以接受 A、B 总线的数据并传到总线 C 上，提供直送功能后就可以通过总线 C 把数据写入到寄存器组里
(C) 要实现 PC->MAR,M(MAR)->MDR,MDR->IR 这一取指过程，控制信号序列可以是 PCoutB,mov,MARinC； Read； MDRoutA，IRinB
(D) 单总线结构为了防止 ALU 运算时输入与输入之间、输入与输出之间出现数据冲突，引入了一些临时寄存器，但三总线数据通路用多个总线避免了运算数据的冲突问题

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/CO-C05-Q010_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。取指最后一步 $MDR\to IR$ 的控制信号使数据从 A 总线输出，却让 IR 从 B 总线接收，数据通路不闭合，因此说法错误。

**解题切入点**：拿到题目先根据题干确定三总线数据通路的连接关系：A、B 总线是 ALU 的两个输入来源，C 总线是 ALU 输出到寄存器写口的写回通路。然后逐条把控制信号翻译成“谁输出到哪条总线、谁从哪条总线输入”，检查源和目的是否在同一总线上。这和做电路连线题一样：必须“源端总线 $=$ 目的端总线”，否则信号悬空。

**推演**：

三总线数据通路的核心特点是：寄存器堆有两个读口，可以同时把两个源操作数送到 A、B 总线；ALU 接收 A、B 总线数据，运算结果送到 C 总线；C 总线再写回寄存器。

- **(A) 正确。**  
  三总线实现 $R1+R2\to R1$ 只需要一个时钟周期：  
  \[
  R1_{outA},\ R2_{outB},\ \mathrm{add},\ R1_{inC}
  \]
  双口寄存器堆同时读出 $R1$、$R2$，ALU 运算后通过 C 总线写回 $R1$。  
  单总线数据通路通常需要 3 拍：
  \[
  R1_{out},Y_{in};\quad R2_{out},\mathrm{add},Z_{in};\quad Z_{out},R1_{in}
  \]
  所以三总线比单总线快 $3-1=2$ 个时钟周期，A 正确。

- **(B) 正确。**  
  要把 $R1$ 传送到 $R2$，图中没有从 A、B 总线直接写回寄存器组的通路，写回寄存器必须经过 C 总线；而 A、B 总线上的数据只有通过 ALU 才能送到 C 总线。因此需要 ALU 提供“直送”/`mov` 功能，把 A 或 B 总线内容原样送到 C 总线，再由 C 总线写入 $R2$。B 正确。

- **(C) 错误。**  
  取指过程前两步可写成：
  \[
  PC_{outB},\ \mathrm{mov},\ MAR_{inC}
  \]
  即 PC 送到 B 总线，ALU 直送 B 到 C 总线，MAR 从 C 总线接收，这一步没问题。  
  内存读后数据到 MDR 也没问题。  
  但最后 $MDR\to IR$ 写成：
  \[
  MDR_{outA},\ IR_{inB}
  \]
  表示 MDR 把数据放到 A 总线，而 IR 要从 B 总线接收。两条总线不同，数据通路没有接通。正确的控制信号应使源端和目的端在同一总线上，例如：
  \[
  MDR_{outB},\ IR_{inB}
  \]
  或根据图中连接改为相应匹配的输入控制信号。因此 C 错误。

- **(D) 正确。**  
  单总线中，ALU 的输入和输出共用一条总线，两个源操作数也不能同时出现在总线上；为了防止总线冲突，需要引入暂存器 $Y$ 暂存一个操作数，用 $Z$ 暂存 ALU 输出。三总线用 A、B 两条总线同时输入两个操作数，用 C 总线输出结果，避免了运算数据的总线争用。D 正确。

综上，错误说法是 C。

**易错点**：

- 容易只看到 C 选项前两步正确，忽略最后 $MDR_{outA}$ 和 $IR_{inB}$ 的总线不匹配。
- 不要把 `outA`、`inB` 看成“随便一个寄存器名”，它们分别表示“输出到 A 总线”和“从 B 总线输入”。
- 三总线中寄存器写回通常必须经过 C 总线，不是任何总线都可以直接写回寄存器。
- 单总线 ALU 运算一般是 3 拍，三总线一般是 1 拍，比较周期数时不要算成“快 3 个时钟”。

**命题规律**：本题考查数据通路中“总线结构 + 控制信号 + 微操作序列”的综合分析，是 408 常考题型。常见变式包括：单总线实现 $R_i+R_j\to R_k$、三总线实现 `mov` 传送、取指周期微操作序列、判断控制信号是否合法等。复习时建议先画数据通路简图，再把每条微操作写成“源总线 $\to$ 目的总线”的闭合路径，同时注意寄存器堆读口/写口数量以及单总线中 $Y$、$Z$ 暂存器的作用。

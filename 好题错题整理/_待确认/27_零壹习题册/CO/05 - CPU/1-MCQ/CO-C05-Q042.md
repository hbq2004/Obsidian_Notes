# MCQ 第 42 题

![[_Attachments/题目识别/27_零壹习题册-题目/CO-C05-Q042_题目.png|题目]]

Flynn 分类法中，仅为理论模型、现实中不存在的是 （ ）.  
(A) SISD  
(B) SIMD  
(C) MISD  
(D) MIMD

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/CO-C05-Q042_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C（MISD）。一句话理由：Flynn 分类法中的 MISD（多指令流单数据流）在实际计算机中尚无典型实现，仅为理论模型。

**解题切入点**：拿到题目先明确 Flynn 分类法的四个类别：SISD、SIMD、MISD、MIMD，然后逐一联想现实中的典型机器或系统。可以把 Flynn 分类法类比为“食堂窗口的排队模式”：指令流是“厨师”，数据流是“食材”。SISD 是一个厨师做一份菜，SIMD 是多个厨师同时做同一种菜的不同份，MIMD 是多个厨师各自做不同的菜；而 MISD 是多个厨师同时加工同一份食材，这在现实中很难高效落地。

**推演**：

Flynn 分类法根据指令流（Instruction Stream）和数据流（Data Stream）的数量关系，将计算机系统分为四类：

- **SISD（Single Instruction stream, Single Data stream）**：单指令流、单数据流。传统单核冯·诺依曼计算机属于此类。
- **SIMD（Single Instruction stream, Multiple Data streams）**：单指令流、多数据流。典型代表是阵列处理器、向量处理器、GPU 中的 SIMT 模式（本质上是 SIMD 的变种）。
- **MISD（Multiple Instruction streams, Single Data stream）**：多指令流、单数据流。要求多个处理单元各自执行不同指令，却同时处理同一份数据。
- **MIMD（Multiple Instruction streams, Multiple Data streams）**：多指令流、多数据流。现代多核处理器、多处理器系统、计算机集群均属于此类。

对 MISD 的分析：  
若多个处理单元 $P_1, P_2, \dots, P_n$ 同时接收同一个数据 $D$，但各自执行不同的指令 $I_1, I_2, \dots, I_n$，则输出应为多个结果 $O_1, O_2, \dots, O_n$。这种模式在理论上可以构造，但在实际硬件中往往退化为流水线结构：不同阶段执行不同指令，但同一时刻只有一个阶段在处理当前数据，并非严格意义上的“多指令流同时作用于同一数据”。因此，MISD 通常被认为仅是理论模型，没有实际系统直接采用。

综上，现实的计算机系统中，SISD、SIMD、MIMD 都有大量实例，而 MISD 仅为理论模型。

**易错点**：

1. **误选 SIMD**：部分考生误以为 SIMD 也是理论模型，但 GPU、向量机等已经广泛应用 SIMD，因此 SIMD 是现实存在的。
2. **误选 SISD**：SISD 是最经典的普通单核计算机，显然存在。
3. **误选 MIMD**：现代多核处理器、分布式系统都是 MIMD，显然存在。
4. **混淆 MISD 与流水线**：流水线是时间并行，各阶段指令不同但数据在不同时刻流经不同阶段，不是同一时刻多指令流处理同一数据，因此不能算作 MISD 的现实实现。

**命题规律**：  
本题属于计算机组成原理中“计算机系统分类”的基础考点，常以选择题形式出现。核心是牢记 Flynn 分类法的定义及典型实例。常见变式包括：给出某种具体机器（如向量机、多核处理器、单核 PC）判断其类别；或者考查 SIMD 与 MIMD 的区分；也可能结合并行计算、GPU 架构出题。复习时应整理一张表格，将四类的“指令流/数据流”特征与典型实例对应记忆，并特别注意 MISD 没有实际系统这条结论。

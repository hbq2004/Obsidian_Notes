# MCQ 第 50 题

![[_Attachments/题目识别/27_零壹习题册-题目/CO-C05-Q050_题目.png|题目]]

50. 指令流水线各阶段中，不会触发异常的是 （ ）.
(A) IF
(B) EX
(C) MEM
(D) WB

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/CO-C05-Q050_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D（WB）。写回阶段只是把运算或访存结果写回寄存器堆，不取指、不运算、不访问内存，因此一般不会触发异常。

**解题切入点**：拿到题目先明确考的是“五段流水线各阶段的功能与异常来源”。可以这样想：每个阶段干不同的事——IF 取指令、EX 运算、MEM 访存、WB 写寄存器。异常一般来自“访存”“运算”“译码”这类可能出错的操作；WB 只是内部写寄存器，行为非常“单纯”，最容易判断为不会触发异常。

**推演**：

指令流水线可抽象为五个阶段：

$$
\text{IF} \rightarrow \text{ID} \rightarrow \text{EX} \rightarrow \text{MEM} \rightarrow \text{WB}
$$

题目给出的是 IF、EX、MEM、WB，不包括 ID。逐阶段分析异常来源：

- **IF 取指阶段**：需要根据 PC 访问指令存储器/内存，可能发生缺页异常、地址越界、访问权限错误等。  
  例如：
  $$
  \text{IF: } \text{PC} \rightarrow \text{指令存储器}
  $$
  取指时若物理地址无效，就会触发异常。所以 IF 可能触发异常。

- **EX 执行阶段**：由 ALU 进行算术逻辑运算，可能发生算术溢出、除零等异常。  
  例如：
  $$
  \text{EX: } \text{ALU 计算}
  $$
  若运算结果溢出，CPU 会触发异常。所以 EX 可能触发异常。

- **MEM 访存阶段**：Load/Store 指令需要访问数据存储器，可能发生缺页异常、地址越界、访问权限错误、地址未对齐等异常。  
  所以 MEM 可能触发异常。

- **WB 写回阶段**：把结果写入寄存器堆，例如：
  $$
  \text{WB: } \text{Reg}[R_d] \leftarrow \text{ALU 结果或访存结果}
  $$
  该过程不访问内存、不进行算术运算、不译码，寄存器编号来自指令字段，取值范围固定有效。即使在 MIPS 中写入 `$0` 也只是丢弃数据，不会产生异常。因此 **WB 不会触发异常**。

所以正确选项是 **D**。

**易错点**：

1. **误选 IF**：认为“取指只是从 Cache 取指令，不会出错”。但在虚拟内存系统中，取指完全可能发生缺页异常或指令地址越界。
2. **误选 MEM**：认为“只有执行阶段会触发异常”。实际上 Load/Store 访存时也可能发生缺页、越界、未对齐等异常。
3. **把“非法指令”异常记错阶段**：非法操作码、保留指令等异常通常发生在译码 ID 阶段，本题没有给出 ID，所以不要把它误安到 IF 或 WB 上。
4. **把“写回寄存器”类比成“访存”**：寄存器堆在 CPU 内部，不存在缺页、越界等问题；写回阶段本身不会成为异常检测点。

**命题规律**：本题属于计算机组成原理中“指令流水线”与“异常/中断”结合的基础题。常见变式有：“哪个阶段可能发生缺页异常”“异常响应与流水线重启动”“精确异常的处理”等。复习时建议记住五段流水线各阶段的典型职责和典型异常：IF 取指异常、ID 非法指令、EX 溢出、MEM 访存异常、WB 无异常。同时注意区分“异常”和“外部中断”，异常是 CPU 内部执行指令时同步产生的，外部中断则是异步事件。

# MCQ 第 21 题

![[_Attachments/题目识别/27_零壹习题册-题目/CO-C05-Q021_题目.png|题目]]

21. 基于上图单周期数据通路，load 指令功能为 $M[R[Rs]+SignExt(imm16)] \to R[Rt]$；Rs 内容为 0521 1314H，指令低 16 位为 FDE9H，Rt 初始内容为 FFFD DFFFH；地址 0521 10FDH 和 0522 10FDH 内容分别为 1234 5678H、8765 4321H。下列说法错误的是（ ）.

(A) 有效数据的路径为 Rs 内容 $\to$ 经过 busA 传输，符号扩展后的 imm16$\to$ALU 执行 addu 运算得到目标地址作为 Adr 输入 $\to$ 读取数据存储器对应单元内容 $\to$ 写入 Rt

(B) Load 指令变更为 Store 指令后，对应的有效数据路径为：Rs 内容 $\to$ 经过 busA 传输，符号扩展后的 imm16$\to$ALU 执行 addu 运算得到目标地址作为 Adr 输入；同时 Rt 内容 $\to$ 经过 busB 传输作为 DataIn 输入；数据存储器依据 DataIn 数据与 Adr 地址，将数据写入对应存储单元

(C) Load 指令控制信号配置：MemtoReg = RegWr = ALUSrc = ExtOp = 1，ALUctr = addu，RegDst = MemWr = Branch = Jump = 0；Store 指令控制信号配置：RegWr = Branch = Jump = 0，ALUctr = addu，MemWr = ALUSrc = ExtOp = 1，RegDst、MemtoReg 取值任意

(D) Load 指令执行完成后，Rt 中的内容由 FFFD DFFFH 更新为 8765 4321H；Store 指令执行完成后，存储器地址 0521 10FDH 对应的存储单元内容更新为 FFFD DFFFH

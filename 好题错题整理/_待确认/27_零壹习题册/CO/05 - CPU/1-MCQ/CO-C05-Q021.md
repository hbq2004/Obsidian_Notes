# MCQ 第 21 题

![[_Attachments/题目识别/27_零壹习题册-题目/CO-C05-Q021_题目.png|题目]]

21. 基于上图单周期数据通路，load 指令功能为 $M[R[Rs]+SignExt(imm16)] \to R[Rt]$；Rs 内容为 0521 1314H，指令低 16 位为 FDE9H，Rt 初始内容为 FFFD DFFFH；地址 0521 10FDH 和 0522 10FDH 内容分别为 1234 5678H、8765 4321H。下列说法错误的是（ ）.

(A) 有效数据的路径为 Rs 内容 $\to$ 经过 busA 传输，符号扩展后的 imm16$\to$ALU 执行 addu 运算得到目标地址作为 Adr 输入 $\to$ 读取数据存储器对应单元内容 $\to$ 写入 Rt

(B) Load 指令变更为 Store 指令后，对应的有效数据路径为：Rs 内容 $\to$ 经过 busA 传输，符号扩展后的 imm16$\to$ALU 执行 addu 运算得到目标地址作为 Adr 输入；同时 Rt 内容 $\to$ 经过 busB 传输作为 DataIn 输入；数据存储器依据 DataIn 数据与 Adr 地址，将数据写入对应存储单元

(C) Load 指令控制信号配置：MemtoReg = RegWr = ALUSrc = ExtOp = 1，ALUctr = addu，RegDst = MemWr = Branch = Jump = 0；Store 指令控制信号配置：RegWr = Branch = Jump = 0，ALUctr = addu，MemWr = ALUSrc = ExtOp = 1，RegDst、MemtoReg 取值任意

(D) Load 指令执行完成后，Rt 中的内容由 FFFD DFFFH 更新为 8765 4321H；Store 指令执行完成后，存储器地址 0521 10FDH 对应的存储单元内容更新为 FFFD DFFFH

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/CO-C05-Q021_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。Load 指令的有效地址应为  
\[
0521\,1314\mathrm{H}+\mathrm{SignExt}(FDE9\mathrm{H})=0521\,10FD\mathrm{H},
\]
对应存储单元内容是 \(1234\,5678\mathrm{H}\)，所以 Rt 应更新为 \(1234\,5678\mathrm{H}\)，不是 \(8765\,4321\mathrm{H}\)。

**解题切入点**：看到 load/store 基址加偏移的地址计算，先判断 16 位立即数是“符号扩展”还是“零扩展”。本题 \(FDE9\mathrm{H}\) 的最高位是 1，因此必须符号扩展；若误按零扩展，会算出 \(0522\,10FD\mathrm{H}\)，正好会取到干扰项 \(8765\,4321\mathrm{H}\)。

**推演**：

1. 指令低 16 位为：
\[
imm16=FDE9\mathrm{H}
\]
其二进制最高位为 1，所以符号扩展为：
\[
\mathrm{SignExt}(imm16)=FFFF\,FDE9\mathrm{H}
\]
而：
\[
FFFF\,FDE9\mathrm{H}=-0000\,0217\mathrm{H}
\]

2. 计算有效地址：
\[
\begin{aligned}
EA&=R[Rs]+\mathrm{SignExt}(imm16)\\
&=0521\,1314\mathrm{H}+FFFF\,FDE9\mathrm{H}\\
&=0521\,1314\mathrm{H}-0000\,0217\mathrm{H}\\
&=0521\,10FD\mathrm{H}
\end{aligned}
\]

3. Load 指令功能为：
\[
M[R[Rs]+\mathrm{SignExt}(imm16)]\to R[Rt]
\]
所以：
\[
M[0521\,10FD\mathrm{H}]=1234\,5678\mathrm{H}
\]
因此执行 Load 后：
\[
R[Rt]\leftarrow 1234\,5678\mathrm{H}
\]

而 \(8765\,4321\mathrm{H}\) 是地址 \(0522\,10FD\mathrm{H}\) 中的内容，对应的是错误地把 \(FDE9\mathrm{H}\) 按零扩展计算得到的地址，故选项 D 错误。

4. 选项 A 描述的 Load 数据通路正确：Rs 经 busA 送 ALU，符号扩展立即数经 ALUSrc 多路选择器送 ALU，ALU 做 addu 得到访存地址，读出的数据经 MemtoReg 写回 Rt。  
选项 B 描述的 Store 数据通路正确：地址仍由 Rs 和符号扩展立即数相加得到，Rt 内容经 busB 作为 DataIn 写入数据存储器。  
选项 C 的控制信号配置也正确：Load 要写寄存器、选择 Rt、选择存储器读数据；Store 不写寄存器、要写存储器。

**易错点**：

- 最容易错的是把 \(FDE9\mathrm{H}\) 当成无符号立即数直接相加，得到 \(0522\,10FD\mathrm{H}\)，从而误选 \(8765\,4321\mathrm{H}\)。要注意 I 型指令的 16 位偏移是有符号数，必须符号扩展。
- 计算 32 位加法时要注意低 16 位产生的进位，以及符号扩展后高 16 位全为 1 的情况，但最终 Addu 结果按 32 位取模。
- Store 指令写入的是 Rt 的当前值。若 Load 之后接着执行 Store，Rt 已经变成 \(1234\,5678\mathrm{H}\)，不会再写 \(FFFD\,DFFF\mathrm{H}\)。
- Load 的 RegDst 应为 0，表示选择 Rt 作为写入寄存器；不能误认为选择 rd。

**命题规律**：本题考查单周期数据通路中 lw/sw 的访存地址计算、数据通路走向和控制信号配置。常见变式包括：更换 Rs 和 imm16 求实际访存地址；给出存储内容求写回值；给出控制信号判断指令类型；或将 load/store 与 R 型指令、分支指令对比。复习时应画清 lw/sw 数据通路，重点掌握符号扩展、ALUSrc、RegDst、MemtoReg、RegWr、MemWr 等控制信号。

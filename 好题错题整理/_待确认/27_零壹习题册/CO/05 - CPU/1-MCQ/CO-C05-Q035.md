# MCQ 第 35 题

![[_Attachments/题目识别/27_零壹习题册-题目/CO-C05-Q035_题目.png|题目]]

指令执行顺序改变导致的流水线阻塞称为控制冒险。执行下列指令序列，说法错误的是（ ）. I1: add $1$, $2$, $3$ I2: sub $4$, $5$, $6$ I3: beq $1$, $4$, LABEL I4: sub $7$, $8$, $9$ LABEL: I5: add $10$, $11$, $12$
(A) 5条指令最多需要12个周期完成
(B) 若 $1$ 与 $4$ 相等，I4 需要阻塞3个时钟
(C) 中断和异常也会导致控制冒险
(D) 指令长4B，beq立即数为2时跳转2条指令到I5

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/CO-C05-Q035_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。beq 的立即数偏移需乘以 4，且基址为 `(PC+4)`，若 I3 为 beq、目标为 I5，则立即数应为 1；为 2 时会跳到 I5 之后的一条指令，故 D 错误。

**解题切入点**：先明确流水线模型（五段、无转发、分支在 ID 判断、预测不跳转），再分析数据冒险（I3 需读 R1 和 R4）与控制冒险（分支冲刷）对周期的影响；同时回忆 MIPS 分支偏移公式：$目标地址 = (PC+4) + \text{sign\_extend}(imm \ll 2)$。这样可以同时验证 A、B、D 三个选项，C 只需判断“中断和异常也改变执行顺序即可”。

**推演**：

指令序列为：
$$I_1:\ add\ R_1,R_2,R_3,\quad R_1 \leftarrow R_2+R_3$$
$$I_2:\ sub\ R_4,R_5,R_6,\quad R_4 \leftarrow R_5-R_6$$
$$I_3:\ beq\ R_1,R_4,LABEL$$
$$I_4:\ sub\ R_7,R_8,R_9$$
$$I_5:\ add\ R_{10},R_{11},R_{12}$$

流水线采用经典五段：IF、ID、EX、MEM、WB，无数据转发，分支在 ID 阶段判断，采用“预测不跳转”策略。

**数据冒险**：I3 需要读 $R_1$ 和 $R_4$，但 $R_1$ 由 I1 写入，$R_4$ 由 I2 写入。无转发时，I3 必须等 I1、I2 都写回后才能读取。I1 在第 5 周期写回，I2 在第 6 周期写回，因此 I3 原本第 4 周期进入 ID，却要插入 3 个气泡，到第 7 周期 ID 阶段才完成。

**控制冒险**：分支在 ID 阶段判断。由于预测不跳转，I3 进入 ID 的同时（第 4 周期）会先取指 I4；当第 7 周期 I3 判断为跳转时，I4 被作废，I5 作为目标指令随后被取入。

据此排周期表（仅列关键）：
- 周期 1～3：I1 依次 IF、ID、EX；I2 依次 IF、ID；I3 IF。
- 周期 4：I1 MEM，I2 EX，I3 ID（开始停顿），I4 IF（预测顺序取到）。
- 周期 5：I1 WB，I2 MEM，I3 ID 停顿，I4 等待。
- 周期 6：I1 完成，I2 WB，I3 ID 停顿，I4 等待（此时 R1、R4 均写回）。
- 周期 7：I3 ID 完成，判断跳转：
  - 若跳转，I4 作废；下周期取 I5。
  - 若不跳转，I4 下一周期进入 ID。

无论跳转与否，I5 的 WB 都在第 12 周期完成（若跳转，I5 在周期 8 IF、9 ID、10 EX、11 MEM、12 WB；若不跳转，I4 占周期 8～11，I5 在周期 9 IF 等，最终也在 12 完成）。所以 5 条指令最多 12 周期，A 正确。

跳转成功时，I4 因 I3 的 ID 停顿，从第 4 周期被取指后一直等待，直到第 7 周期被冲刷，恰好阻塞了 3 个时钟（周期 4、5、6），故 B 正确。

中断和异常会打断当前流水线，清除已取指令，并从固定入口重新开始，属于改变执行顺序的控制冒险，C 正确。

**D 选项推导**：设 I3 地址为 $x$，则 I4 地址为 $x+4$，I5 地址为 $x+8$。MIPS 分支目标：
$$PC+4+\text{sign\_extend}(imm \ll 2)$$
要求跳到 I5，即：
$$(x+4)+4\times imm = x+8 \Rightarrow 4\times imm = 4 \Rightarrow imm=1$$
若 $imm=2$，目标为 $(x+4)+8=x+12$，是 I5 后一条指令，故 D 错误。

**易错点**：
- 计算分支偏移时忘记左移 2 位，或误以当前 PC 为基址，导致目标地址算错。
- 忽略 I3 与 I1、I2 的数据相关，导致流水线周期数少算 3 个。
- 误认为跳转成功时 I4 不执行就不计入控制冒险；实际上 I4 已被取指并被冲刷，仍占用流水线周期。
- 将中断、异常与分支冒险割裂，忘记它们同样引起控制流改变。

**命题规律**：本题综合考查流水线控制冒险、数据冒险和分支目标计算，是 408 计组常考题型。常见变式有：改变分支判断阶段（EX 或 ID）、是否支持数据转发、是否采用分支延迟槽、是否使用分支预测等。复习时应熟练掌握五段流水线时空图，能准确画出各指令的 IF/ID/EX/MEM/WB 顺序，并牢记 MIPS 分支偏移计算公式。建议多做真题，强化对“指令相关 + 分支冒险 + 周期计算”综合题的分析能力。

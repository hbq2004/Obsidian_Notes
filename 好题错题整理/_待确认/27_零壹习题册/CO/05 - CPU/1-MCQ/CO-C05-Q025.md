# MCQ 第 25 题

![[_Attachments/题目识别/27_零壹习题册-题目/CO-C05-Q025_题目.png|题目]]

25. Load 指令执行阶段功能为 $M[A + \text{SignExt}(IR\langle15:0\rangle)] \rightarrow R[IR\langle20:16\rangle]$，对应的数据流向如【图（左）】所示。 Store 指令执行阶段功能为 $B \rightarrow M[A + \text{SignExt}(IR\langle15:0\rangle)]$，对应的数据流向如【图（右）】所示。根据以上信息，下列说法错误的是（ ）.
(A) 两种指令的地址计算是一样的，它们对应的数据流向也是一样的，如两图中红色部分所示
(B) 在地址计算时控制信号为：$\text{ALUSelB}=10, \text{ALUop}=\text{addu}, \text{IorD}=\text{ALUSelA}=\text{ExtOp}=1$, $\text{PCWr}=\text{BrWr}=\text{RegWr}=\text{PCWrCond}=\text{MemWr}=\text{R-type}=\text{IRWr}=0$, 其他任意
(C) 在 load 存储器取数与写回寄存器时 $\text{MemtoReg}=1$, $\text{RegDst}=\text{MemWr}=0$; 而 store 存储器写回时只需要 $\text{MemWr}=0$
(D) 只有在执行 store 指令时，Din 端才会有 B 给出的数据，其他指令执行时，Din 端没有数据

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/CO-C05-Q025_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D（按官方/常见版本，题干（C）中“store 存储器写回时只需要 $\text{MemWr}=0$”应为 $\text{MemWr}=1$；若严格按你粘贴的题面，则 C 也明显错误）。一句话理由：B 寄存器到存储器的 Din 端是数据通路中的固定连线，并非只有 store 指令才有数据，$\text{MemWr}$ 只是决定是否真正写入存储器。

**解题切入点**：看到 Load/Store 的数据通路功能式，先抓公共路径，再抓差异路径。公共路径是二者都要用的地址计算：$A+\text{SignExt}(IR\langle15:0\rangle)$，所以应优先判断 ALUSelA、ALUSelB、ExtOp、ALUop、IorD 等信号；差异在于 Load 是“存储器→寄存器”，Store 是“寄存器→存储器”，所以重点看 MemtoReg、RegDst、MemWr 和 Din 端数据来源。

**推演**：

题干给出的两条指令功能为：

$$
\text{Load: } M[A+\text{SignExt}(IR\langle15:0\rangle)] \rightarrow R[IR\langle20:16\rangle]
$$

$$
\text{Store: } B \rightarrow M[A+\text{SignExt}(IR\langle15:0\rangle)]
$$

1. **A 正确**：两种指令的地址计算完全相同，都是 $A+\text{SignExt}(IR\langle15:0\rangle)$，对应的地址计算数据流也相同，即图中红色部分所示。

2. **B 正确**：地址计算时，ALU 左操作数选 $A$，故 $\text{ALUSelA}=1$；右操作数选符号扩展后的立即数，故 $\text{ALUSelB}=10$、$\text{ExtOp}=1$；ALU 做加法，故 $\text{ALUop}=\text{addu}$；存储器地址选 ALU 的输出，故 $\text{IorD}=1$。此时不取指、不写寄存器、不写存储器、不更新 PC，因此 $\text{PCWr}=\text{BrWr}=\text{RegWr}=\text{PCWrCond}=\text{MemWr}=\text{R-type}=\text{IRWr}=0$。

3. **C 正确（按原题应为 $\text{MemWr}=1$）**：Load 取数时读存储器，$\text{MemWr}=0$；取到的数据写回寄存器时，来源是存储器，故 $\text{MemtoReg}=1$；目的寄存器是 $IR\langle20:16\rangle$，故 $\text{RegDst}=0$。Store 是写存储器，$\text{MemWr}$ 应为 1。若题面写成 $\text{MemWr}=0$，则 C 错误。

4. **D 错误**：在数据通路中，寄存器堆第二读口送到 B 寄存器，B 的输出不仅可送 ALU 作为右操作数，也固定接到存储器的 Din 端，这是为 Store 指令准备的物理连线。其他指令（如 R 型指令）在执行时，B 寄存器同样可能有数据并出现在 Din 端，只是 $\text{MemWr}=0$，存储器不写入。因此不能说“只有在执行 store 指令时，Din 端才有 B 给出的数据”。

**易错点**：
- 容易混淆“数据线上有数据”和“存储器是否写入”。$\text{MemWr}=0$ 只是禁止写入，不代表 Din 端没有数据。
- store 是“寄存器写存储器”，所以 $\text{MemWr}$ 必须为 1；load 是“存储器读出来写寄存器”，所以 $\text{MemWr}=0$、$\text{MemtoReg}=1$。
- Load 的目的寄存器是 $rt=IR\langle20:16\rangle$，因此 $\text{RegDst}=0$，不要误以为写寄存器就一定是 $\text{RegDst}=1$。
- 地址计算用的是 $A$（rs 的值）与符号扩展立即数，不是 PC，因此 $\text{ALUSelA}=1$、$\text{ALUSelB}=10$。

**命题规律**：本题属于计算机组成原理中“指令数据通路与控制信号”的经典考法，常结合 Load/Store、R-type、Branch 的微操作序列或数据通路图，考查控制信号取值。变式包括：给一条 R-type 或 beq 指令，判断 ALUSelA、ALUSelB、IorD、MemtoReg、RegDst、MemWr 等信号；或给出控制信号反推指令类型。复习时应熟记经典 MIPS 数据通路中各阶段的控制信号，特别是 Load/Store 的公共地址计算路径与不同访存方向，并理解“数据通路固定连接”与“控制信号有效”的区别。

# MCQ 第 25 题

![[_Attachments/题目识别/27_零壹习题册-题目/CO-C02-Q025_题目.png|题目]]

25. 当 8 位计算机中运行下列 C 语言代码时，程序的输出和此时的 CF 标志位分别为（ ）.

```
unsigned int u = 186;
unsigned int s = 224;
unsigned int t = u-s;
printf(" %u\n", t);
```

(A) 218, 1
(B) 38, 1
(C) 218, 0
(D) 38, 0

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/CO-C02-Q025_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A。8 位无符号数相减 \(186-224\) 发生借位，结果为 \(218\)，CF 标志位为 1。

**解题切入点**：看到 `unsigned` 和 `CF`，应立刻定位到“无符号数加减法运算与状态标志位”。无符号数减法在不够减时会向更高位借位，即“模 \(2^8\) 运算”；CF 就记录是否发生了最高位借位。

**推演**：

设机器字长为 8 位，则无符号整数范围为 \(0\sim 255\)。

\[
u=186,\quad s=224
\]

因为 \(186<224\)，无符号减法不够减，需要向第 8 位借位。等价于：

\[
t=(186-224)\bmod 2^8=186-224+256=218
\]

写成二进制减法：

\[
\begin{array}{r}
1011\,1010\\
-\;1110\,0000\\
\hline
1101\,1010
\end{array}
\]

其中最高位发生了借位，结果：

\[
1101\,1010_2=218_{10}
\]

对于减法指令，CF 表示无符号减法的借位标志。由于 \(186<224\)，最高位向更高位借了 1，因此：

\[
CF=1
\]

所以 `printf("%u\n", t)` 输出 `218`，此时 CF 为 `1`。

**易错点**：

- 不要直接算成 \(186-224=-38\)，无符号数运算会自动按 \(2^8\) 取模，结果是 218。
- 不要把“减法借位”和“加法进位”混淆。虽然补码加法中 \(186+32=218\) 没有加法进位，但减法指令中 \(186<224\) 产生借位，所以 CF=1。
- 本题按 8 位机模型处理，`unsigned int` 按 8 位无符号数参与运算，不要默认成 32 位或 16 位。

**命题规律**：考点为“无符号数减法与 CF 标志位”，常与 C 语言无符号整数运算结合考查。常见变式有：改成加法问 CF；比较两个无符号数大小判断 CF；用 `char` 或 `short` 变量问输出值。复习时牢记：

\[
\text{无符号加法：CF=最高位进位};\qquad
\text{无符号减法：CF=最高位借位}
\]

并用二进制竖式和取模运算互相验证。

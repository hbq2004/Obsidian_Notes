# MCQ 第 31 题

![[_Attachments/题目识别/27_零壹习题册-题目/CO-C02-Q031_题目.png|题目]]

31. 在 32 位计算机中，关于 C 语言中 int 型变量和 float 型数据变量的对比，下面说法正确的是 (  ) .
(A) int 型变量和 float 型变量可以表示的有效数据个数不同
(B) 若 float 型变量小数点后数字均为 0，则可以无任何误差的转化为 int 型变量
(C) 两种变量类型相加时，会先将 int 型变量转化为 float 型变量再相加
(D) 当 float 型变量转化为 int 型变量时，会直接截断 float 型变量小数部分仅保留整数部分

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/CO-C02-Q031_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。  
一句话理由：C 语言中 `int` 与 `float` 混合相加时，按“通常算术转换”规则，`int` 型变量会先被转换为 `float` 型变量再相加，该说法无条件成立。

**解题切入点**：拿到题目先定位考点：C 语言中整型与浮点型的表示范围、精度以及类型转换规则。可以打一个比方：`float` 像“科学计数法”，尾数位数有限，所以大整数不一定能被精确表示；而两种类型相加时，首先要确定“公共类型”。做题时先排除带有“一定”“无任何误差”等绝对化说法、但又缺少前提的选项，再比较 A、C 两个与“数个数”“转换规则”相关的选项。

**推演**：

1. **A 错误。**  
   在 32 位计算机中，`int` 型变量占 32 位，`float` 型变量也占 32 位，因此两者的位模式个数都是 $2^{32}$。  
   虽然 `float` 中有 NaN、无穷大等特殊编码，但从“可存储编码个数”的角度，两者可表示的数据个数相同。所以 A 说“不同”不正确。

2. **B 错误。**  
   `float` 的尾数只有 23 位，加上隐含的 1 位，共 24 位有效二进制精度。  
   当浮点数的绝对值超过 $2^{24}$ 时，并不是所有整数都能被精确表示；而且若数值超出 `int` 的范围 $[-2^{31}, 2^{31}-1]$，转换会溢出。  
   因此“小数点后数字均为 0”并不能保证无误差转换为 `int`。

3. **C 正确。**  
   C 语言规定，`float` 与 `int` 进行算术运算时，按照“通常算术转换”（usual arithmetic conversions），`int` 会被转换为 `float`，然后以 `float` 类型进行运算。  
   例如：
   ```c
   int i = 3;
   float f = 2.5f;
   float sum = i + f;   // i 先转换为 float，再做浮点加法
   ```

4. **D 错误。**  
   在 C 语言中，将有限浮点数转换为 `int` 时，若整数部分可表示，确实会丢弃小数部分（向零截断）。  
   但如果浮点数是 NaN、无穷大，或数值超出 `int` 的表示范围，则转换行为是未定义的，不能无条件地说“直接截断小数部分仅保留整数部分”。D 缺少这个前提，所以错误。

综合可知，只有 C 说法严格成立。

**易错点**：

- 容易误选 D，因为教材常写“float 转 int 直接截断”，却忽略了 C 标准中“若整数部分无法表示则行为未定义”的前提。
- 容易误选 A，误认为 `int` 和 `float` 都是 32 位，所以可表示的有效数据个数“不同”；实际上从编码个数看，两者相同。
- 容易误以为 C 中 `float` 会先提升为 `double`，但现代标准 C 中，`float` 与 `int` 运算时，普通算术转换会把 `int` 转换为 `float`，而不是先把 `float` 提升为 `double`。

**命题规律**：本题属于计算机组成原理中“数据表示与运算”与 C 语言类型转换结合的考点。常见变式包括：给出具体数值判断 `int` 转换为 `float` 是否精确；考察 `float` 转 `int` 时向零取整；以及考察混合运算时的类型转换方向。复习时需牢记：`float` 只有约 24 位有效二进制位；类型转换要关注“公共类型”；浮点转整数要特别留意溢出与未定义行为。

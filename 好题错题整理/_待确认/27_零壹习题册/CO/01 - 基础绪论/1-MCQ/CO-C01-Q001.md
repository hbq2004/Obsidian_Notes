# MCQ 第 1 题

![[_Attachments/题目识别/27_零壹习题册-题目/CO-C01-Q001_题目.png|题目]]

1. 下面关于高级编程语言、汇编语言和机器语言之间关系的描述，错误的是 （ ）.
(A) 汇编语言与机器语言一一对应，是机器语言更符合人类使用习惯的助记符表示
(B) 高级编程语言是汇编语言或机器语言的高级抽象，具有更高的运行效率
(C) 高级编程语言必须形成二进制指令才能以可执行文件的形式保存在计算机中
(D) 同样一段高级语言程序可以编译成不同架构下的机器语言程序

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/CO-C01-Q001_答案.png|答案]]

## DeepSeek V4 Flash Max 解析
**答案**：B。高级编程语言是汇编语言或机器语言的高级抽象，但抽象层次更高并不代表运行效率更高，高级语言程序的运行效率通常低于等价的汇编/机器语言程序。

**解题切入点**：拿到题先抓住题干中的“关系”二字，逐一核对每个选项与“语言层次、翻译方式、运行效率、可移植性”的关系。凡是把“高级抽象”与“运行效率高”捆绑在一起的表述，几乎必然是错误选项。好比算法竞赛中 Python 比 C++ 高级、好写，但运行效率远低于 C++；语言越接近人类思维，离硬件越远，往往要付出性能代价。

**推演**：

1. **选项 (A)**  
   机器语言是 CPU 直接识别的二进制指令，形如 $10110000$。汇编语言用助记符（如 `MOV AX, 1`）表示机器指令，并且在不考虑伪指令、宏指令的前提下，一条汇编语句与一条机器指令基本一一对应。所以“汇编语言与机器语言一一对应，是机器语言更符合人类使用习惯的助记符表示”是正确的。

2. **选项 (B)**  
   高级编程语言是面向问题求解的语言，例如 C、Java，它确实是对汇编/机器语言的高级抽象。但“抽象层次高”与“运行效率高”是两个不同维度。  
   设 $T(H)$ 为高级语言程序执行时间，$T(A)$ 为等价汇编语言程序执行时间，则一般情况下有
   $$
   T(H) \ge T(A)
   $$
   因为高级语言程序必须先经编译或解释，翻译成机器指令后才能运行，翻译过程还可能引入类型检查、越界检查、内存管理等额外开销。因此高级语言程序的运行效率通常**低于**汇编语言程序，而不是“更高”。故 (B) 错误。

3. **选项 (C)**  
   可执行文件（如 Windows 下的 `.exe`、Linux 下的 ELF 文件）在磁盘上存放的内容最终必须是二进制机器指令。高级语言源程序若要以可执行文件形式保存在计算机中，必须经过编译、汇编、链接等步骤，形成目标机器能够直接执行的二进制指令。因此 (C) 正确。

4. **选项 (D)**  
   高级语言程序与具体指令集架构无关，具有较好的可移植性。同一段高级语言程序可以分别由 x86、ARM、MIPS 等不同架构的编译器编译，生成各自平台下的机器语言程序，这就是“交叉编译”或“多平台编译”的基础。故 (D) 正确。

综上，错误的选项是 **B**。

**易错点**：

- **误把“抽象”当“高效”**：看到“高级编程语言是汇编语言或机器语言的高级抽象”就觉得有理，忽略了后半句“具有更高的运行效率”是错误的。抽象高意味着开发效率高、可读性好，但执行效率通常反而低。
- **把 (A) 的“一一对应”绝对化**：汇编语言中伪指令、宏指令并不直接对应某一条机器指令，但在考研语境下，默认指的是“指令语句与机器指令基本一一对应”，不能因此判错。
- **对 (C) 的“必须以二进制指令形式”产生犹豫**：解释型语言（如 Python）可以直接运行源代码，不生成可执行文件；但题目已经限定“以可执行文件的形式保存在计算机中”，此时必须包含二进制机器指令。Java 的字节码 `.class` 文件也不是 CPU 可直接执行的机器指令文件，不能算作这里所说的可执行文件。
- **对 (D) 的理解偏差**：不是说同一段高级语言程序能“直接运行”在不同架构上，而是说通过不同架构的编译器“重新编译/交叉编译”后生成各自的机器语言程序。跨平台编译 ≠ 跨平台直接执行。

**命题规律**：

- **考点定位**：计算机系统的层次结构、高级语言/汇编语言/机器语言之间的关系，以及编译、解释、汇编、链接等翻译过程。
- **常见变式**：
  1. 判断某句话中“运行效率最高/最低的是哪种语言”；
  2. 比较编译执行与解释执行的特点；
  3. 给出一段高级语言程序的执行步骤，问其经过了哪些翻译阶段；
  4. 考查“为什么高级语言可移植性好而汇编语言与机器相关”。
- **复习建议**：把“语言层次—翻译方式—运行载体—执行效率”这条主线串起来记忆：
  - 高级语言：可移植性好，开发效率高，运行效率低；
  - 汇编语言：与机器指令一一对应，机器相关性高，运行效率高；
  - 机器语言：唯一能被 CPU 直接执行的语言，效率最高，但难读难写。
  同时注意区分“编译型语言”与“解释型语言”，并牢记可执行文件最终必须包含二进制机器指令。

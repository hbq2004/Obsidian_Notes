# MCQ 第 2 题

![[_Attachments/题目识别/ZYT8T/ZYT8T-S3-Q02_题目.png|题目]]

设函数 $f(x)$ 具有二阶导数，$f'(x)>0,f''(x)<0$，记 $I_1=\int_{-\pi}^{\pi}f(x)\sin x \,\mathrm{d}x,I_2=\int_{-\pi}^{\pi}f(x)\cos x \,\mathrm{d}x$，则.
(A) $I_1>0,I_2<0.$
(B) $I_1<0,I_2>0.$
(C) $I_1<0,I_2<0.$
(D) $I_1>0,I_2>0.$

![[_Attachments/题目识别/ZYT8T-答案/ZYT8T-S3-Q02_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**
【答案】: (D)

**解题切入点**
本题利用函数单调性与凹凸性判断积分符号。突破口在于利用奇偶性将积分转化为正函数在对称区间上的积分，或者通过分部积分转化为导数的积分。

**推演**
1. 判断 $I_1$ 符号：
   $I_1=\\int_{-\\pi}^{\\pi} f(x)\\sin x \\,\\mathrm{d}x$。令 $x=-t$，得 $I_1=-\\int_{-\\pi}^{\\pi} f(-t)\\sin t \\,\\mathrm{d}t$，故 $2I_1=\\int_{-\\pi}^{\\pi} [f(x)-f(-x)]\\sin x \\,\\mathrm{d}x$，所以 $I_1=\\frac{1}{2}\\int_{-\\pi}^{\\pi}[f(x)-f(-x)]\\sin x \\,\\mathrm{d}x=\\int_{0}^{\\pi}[f(x)-f(-x)]\\sin x \\,\\mathrm{d}x$（奇偶性）。由 $f'(x)>0$ 知 $f$ 单调递增，故 $x>0$ 时 $f(x)>f(-x)$，且 $\\sin x>0$，因此被积函数 $>0$，积分 $>0$，即 $I_1>0$。

2. 判断 $I_2$ 符号：
   用分部积分：$I_2=\\int_{-\\pi}^{\\pi} f(x)\\cos x \\,\\mathrm{d}x = f(x)\\sin x\\big|_{-\\pi}^{\\pi} - \\int_{-\\pi}^{\\pi} f'(x)\\sin x \\,\\mathrm{d}x = -\\int_{-\\pi}^{\\pi} f'(x)\\sin x \\,\\mathrm{d}x$。
   记 $J=\\int_{-\\pi}^{\\pi} f'(x)\\sin x \\,\\mathrm{d}x$，类似奇偶性分解得 $J=\\int_{0}^{\\pi}[f'(x)-f'(-x)]\\sin x \\,\\mathrm{d}x$。由 $f''(x)<0$ 知 $f'(x)$ 单调递减，故 $x>0$ 时 $f'(x)<f'(-x)$，即 $f'(x)-f'(-x)<0$，且 $\\sin x>0$，所以 $J<0$，从而 $I_2=-J>0$。

3. 综上，$I_1>0,\\,I_2>0$，对应选项 (D)。

4. 选项分析：
   - (A) $I_1>0,I_2<0$：$I_2$ 实际为正，故错误。
   - (B) $I_1<0,I_2>0$：$I_1$ 实际为正，故错误。
   - (C) $I_1<0,I_2<0$：两者皆正，故错误。
   - (D) $I_1>0,I_2>0$：正确。

**易错点**
1. 忽视 $f(x)$ 的符号，直接由 $\\cos x$ 在 $(0,\\pi/2)$ 正、$(\\pi/2,\\pi)$ 负而误判 $I_2$ 符号，需结合 $f$ 的凹凸性分析。
2. 分部积分时易漏负号或端点值处理不当。
3. 奇偶性分解时系数计算错误，例如忘记 $I_1$ 的 $\\frac{1}{2}$ 或 $I_2$ 的对称性。

**命题规律**
此类题常将函数性质（单调性、凹凸性）与定积分联系起来，通过分部积分、奇偶性变形转化为考察导数的符号。备考时应熟练掌握分部积分法，并善于利用对称性化简积分。

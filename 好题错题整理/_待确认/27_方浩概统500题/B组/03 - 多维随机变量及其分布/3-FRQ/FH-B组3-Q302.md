# FRQ 第 302 题

![[_Attachments/题目识别/27_方浩概统500题-题目/FH-B组3-Q302_题目.png|题目]]

302 设二维连续型随机变量 $(X,Y)$ 的分布函数为
$$F(x,y) = A\left(B + \arctan\frac{x}{2}\right)\left(C + \arctan\frac{y}{4}\right) \quad (-\infty < x, y < +\infty).$$
(1) 求 $(X,Y)$ 的边缘分布函数；
(2) 求 $(X,Y)$ 的概率密度；
(3) 求 $(X,Y)$ 的边缘概率密度；
(4) 判断随机变量 $X$ 与 $Y$ 是否独立；
(5) 求 $P\{0 < X \leqslant 2, 0 < Y \leqslant 4\sqrt{3}\}$.

---

## 答案


## DeepSeek V4 Flash Max 解析

**答案**：本题为综合题。常数为  
$A=\frac1{\pi^2},\qquad B=\frac{\pi}{2},\qquad C=\frac{\pi}{2}.$  
(1) 边缘分布函数为  
$F_X(x)=\frac12+\frac1\pi\arctan\frac{x}{2},\qquad F_Y(y)=\frac12+\frac1\pi\arctan\frac{y}{4}.$  
(2) 联合概率密度为  
$f(x,y)=\frac{8}{\pi^2(x^2+4)(y^2+16)},\quad -\infty<x,y<+\infty.$  
(3) 边缘概率密度为  
$f_X(x)=\frac{2}{\pi(x^2+4)},\qquad f_Y(y)=\frac{4}{\pi(y^2+16)}.$  
(4) $X$ 与 $Y$ 独立。  
(5)  
$P\{0<X\leqslant 2,\ 0<Y\leqslant 4\sqrt3\}=\frac1{12}.$

**解题切入点**：看到分布函数是两个一元函数的乘积，先不要急于求导，而应先利用分布函数的边界条件确定未知常数。这就像算法竞赛里先处理边界条件、初始化 base case，否则后面所有推导都会出错。定出常数后，若发现 $F(x,y)=F_X(x)F_Y(y)$，独立性就非常明显，概率也可以转化为两个一维概率相乘。

**推演**：已知  
$F(x,y)=A\left(B+\arctan\frac{x}{2}\right)\left(C+\arctan\frac{y}{4}\right).$

由分布函数性质：
$\lim_{x\to-\infty}F(x,y)=0,\qquad \lim_{y\to-\infty}F(x,y)=0,\qquad F(+\infty,+\infty)=1.$

又  
$\lim_{x\to-\infty}\arctan\frac{x}{2}=-\frac{\pi}{2},\qquad \lim_{x\to+\infty}\arctan\frac{x}{2}=\frac{\pi}{2},$
对 $y/4$ 同理。

要使 $F(-\infty,y)=0$ 对任意 $y$ 成立，必须有  
$B-\frac{\pi}{2}=0 \Rightarrow B=\frac{\pi}{2}.$
同理，要使 $F(x,-\infty)=0$ 对任意 $x$ 成立，必须有  
$C-\frac{\pi}{2}=0 \Rightarrow C=\frac{\pi}{2}.$

于是  
$F(+\infty,+\infty)=A\left(\frac{\pi}{2}+\frac{\pi}{2}\right)\left(\frac{\pi}{2}+\frac{\pi}{2}\right)=A\pi^2=1,$
所以  
$A=\frac1{\pi^2}.$

因此  
$F(x,y)=\frac1{\pi^2}\left(\frac{\pi}{2}+\arctan\frac{x}{2}\right)\left(\frac{\pi}{2}+\arctan\frac{y}{4}\right).$

(1) 边缘分布函数：

$$F_X(x)=F(x,+\infty)=\frac1{\pi^2}\left(\frac{\pi}{2}+\arctan\frac{x}{2}\right)\cdot\pi
=\frac12+\frac1\pi\arctan\frac{x}{2},$$

$$F_Y(y)=F(+\infty,y)=\frac1{\pi^2}\cdot\pi\left(\frac{\pi}{2}+\arctan\frac{y}{4}\right)
=\frac12+\frac1\pi\arctan\frac{y}{4}.$$

(2) 联合概率密度：

注意  
$$\frac{d}{dx}\arctan\frac{x}{2}=\frac{2}{x^2+4},\qquad
\frac{d}{dy}\arctan\frac{y}{4}=\frac{4}{y^2+16}.$$

所以  
$$f(x,y)=\frac{\partial^2F}{\partial x\partial y}
=\frac1{\pi^2}\cdot \frac{2}{x^2+4}\cdot \frac{4}{y^2+16}
=\frac{8}{\pi^2(x^2+4)(y^2+16)}.$$

(3) 边缘概率密度：

由边缘分布函数求导，得  
$f_X(x)=F_X'(x)=\frac{2}{\pi(x^2+4)},$
$f_Y(y)=F_Y'(y)=\frac{4}{\pi(y^2+16)}.$

(4) 判断独立性：

因为  
$F(x,y)=F_X(x)F_Y(y),$
且  
$f(x,y)=f_X(x)f_Y(y),$
所以 $X$ 与 $Y$ 相互独立。

(5) 求概率：

由独立性，  
$$P\{0<X\leqslant 2,\ 0<Y\leqslant 4\sqrt3\}
=P\{0<X\leqslant 2\}\cdot P\{0<Y\leqslant 4\sqrt3\}.$$

而  
$$P\{0<X\leqslant 2\}=F_X(2)-F_X(0)
=\left(\frac12+\frac1\pi\cdot\frac{\pi}{4}\right)-\frac12
=\frac14,$$

$$P\{0<Y\leqslant 4\sqrt3\}=F_Y(4\sqrt3)-F_Y(0)
=\left(\frac12+\frac1\pi\cdot\frac{\pi}{3}\right)-\frac12
=\frac13.$$

因此  
$$P\{0<X\leqslant 2,\ 0<Y\leqslant 4\sqrt3\}
=\frac14\cdot\frac13
=\frac1{12}.$$

也可用二维矩形概率公式验证：

$$P=F(2,4\sqrt3)-F(0,4\sqrt3)-F(2,0)+F(0,0)
=\frac58-\frac5{12}-\frac38+\frac14
=\frac1{12}.$$

**易错点**：

- 忘记先由边界条件确定 $A,B,C$，直接对含未知常数的 $F$ 求导，导致结果未归一化。
- 对 $\arctan\frac{x}{2}$ 求导时漏掉因子，正确结果是  
  $\frac{d}{dx}\arctan\frac{x}{2}=\frac{2}{x^2+4},$
  不是 $\frac{1}{1+x^2}$。
- 求边缘分布函数时，应令另一个变量趋于 $+\infty$；若误令其趋于 $-\infty$，会错误地得到 $0$。
- 矩形概率公式的四项符号容易写错，应为  
  $P\{x_1<X\leqslant x_2,y_1<Y\leqslant y_2\}=F(x_2,y_2)-F(x_1,y_2)-F(x_2,y_1)+F(x_1,y_1).$
- 未证明独立前，不能直接把二维概率拆成两个一维概率相乘。

**命题规律**：本题是典型的“二维分布函数 + 边缘分布 + 概率密度 + 独立性 + 矩形概率”综合题。常见变式包括：把系数 $2,4$ 换成一般参数，或先给联合密度求常数，再判断独立性；也可能进一步求 $P\{X\leqslant Y\}$、$P\{X+Y\leqslant a\}$ 等。本题的分布本质上可看成两个独立的柯西型随机变量的联合分布。复习时应熟练掌握分布函数的四条基本性质、混合偏导求密度、边缘分布的求法以及独立性判据。

**知识点**：二维分布函数、边缘分布、概率密度、随机变量的独立性

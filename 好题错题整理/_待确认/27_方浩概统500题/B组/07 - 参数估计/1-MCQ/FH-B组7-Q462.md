# MCQ 第 462 题

![[_Attachments/题目识别/27_方浩概统500题-题目/FH-B组7-Q462_题目.png|题目]]

462 已知总体$X$与$Y$都服从正态分布$N(\mu,\sigma^2)$，且相互独立，现从总体$X$与$Y$中抽取容量为$n$的简单随机样本，其样本方差分别为$S_X^2$，$S_Y^2$，则下列$\sigma^2$的无偏估计量中最有效的为( ).

(A) $S_X^2$
(B) $S_Y^2$
(C) $\frac{1}{2}S_X^2 + \frac{1}{2}S_Y^2$
(D) $\frac{3}{2}S_X^2 - \frac{1}{2}S_Y^2$

---

## 答案


## DeepSeek V4 Flash Max 解析

**答案**：C。四个选项都是 $\sigma^2$ 的无偏估计，但选项 C 是两个独立样本方差的等权平均，方差最小，因此最有效。

**解题切入点**：题目问“无偏估计量中最有效”，马上定位到估计量评价标准：先验证无偏，再比较方差。所给选项都是 $S_X^2,S_Y^2$ 的线性组合；只要系数和为 1 就无偏。由于两个样本独立，线性组合的方差只与系数平方和有关，因此不必算具体样本值，只需用正态样本方差的卡方分布求共同方差，再比较系数平方和。类似算法竞赛里多次独立采样取平均更稳定，等权平均比单次采样波动小。

**推演**：

设样本方差定义为
\[
S^2=\frac1{n-1}\sum_{i=1}^n(Z_i-\bar Z)^2.
\]
因为总体 $X,Y$ 均服从 $N(\mu,\sigma^2)$，且样本独立，所以 $S_X^2$ 与 $S_Y^2$ 独立，并且
\[
\frac{(n-1)S_X^2}{\sigma^2}\sim \chi^2(n-1),\qquad
\frac{(n-1)S_Y^2}{\sigma^2}\sim \chi^2(n-1).
\]
于是
\[
E(S_X^2)=E(S_Y^2)=\sigma^2,\qquad
\operatorname{Var}(S_X^2)=\operatorname{Var}(S_Y^2)=\frac{2\sigma^4}{n-1}.
\]

四个选项都可写成
\[
T_a=aS_X^2+(1-a)S_Y^2
\]
的形式。其中选项 A 对应 $a=1$，选项 B 对应 $a=0$，选项 C 对应 $a=\frac12$，选项 D 对应 $a=\frac32$。

由于
\[
E(T_a)=a\sigma^2+(1-a)\sigma^2=\sigma^2,
\]
四个选项均无偏。又因为 $S_X^2$ 与 $S_Y^2$ 独立，
\[
\operatorname{Var}(T_a)
=a^2\operatorname{Var}(S_X^2)+(1-a)^2\operatorname{Var}(S_Y^2)
=\bigl[a^2+(1-a)^2\bigr]\frac{2\sigma^4}{n-1}.
\]

要使方差最小，只需使
\[
a^2+(1-a)^2=2a^2-2a+1
\]
最小。该二次函数在
\[
a=\frac12
\]
处取得最小值。因此选项 C
\[
T_{1/2}=\frac12S_X^2+\frac12S_Y^2
\]
的方差最小。

具体比较：
\[
\operatorname{Var}(A)=\operatorname{Var}(B)=\frac{2\sigma^4}{n-1},\qquad
\operatorname{Var}(C)=\frac{\sigma^4}{n-1},\qquad
\operatorname{Var}(D)=\frac{5\sigma^4}{n-1}.
\]
故 C 最有效。

**易错点**：

1. 只检查无偏性而忽略方差：D 也是无偏的，但系数含负权重，方差反而最大，不能选。
2. 忘记 $S_X^2$ 与 $S_Y^2$ 独立，可能错误地在方差中加上协方差项；本题两个样本独立，所以无协方差项。
3. 把自由度写成 $n$：正态总体样本方差满足
\[
\frac{(n-1)S^2}{\sigma^2}\sim\chi^2(n-1),
\]
因此
\[
\operatorname{Var}(S^2)=\frac{2\sigma^4}{n-1},
\]
不是 $\dfrac{2\sigma^4}{n}$。
4. 误以为用了两个样本信息的估计量不一定比单个好；实际上等权平均会降低方差。

**命题规律**：考点为估计量的无偏性和有效性，核心工具是正态总体样本方差的卡方分布和独立变量线性组合的方差。常见变式有：求 $aS_X^2+(1-a)S_Y^2$ 中使方差最小的系数；两个样本容量不同时最优权重按自由度 $n_i-1$ 分配；若均值已知则用 $\frac1n\sum(X_i-\mu)^2$ 作估计并比较方差。复习时熟记常用统计量的分布、期望、方差即可。

**知识点**：无偏性、有效性、样本方差分布、卡方分布

# MCQ 第 484 题

![[_Attachments/题目识别/27_方浩概统500题-题目/FH-CG-Q484_题目.png|题目]]

484 设 $A_1, A_2, B$ 为随机事件且 $0 < P(B) < 1, P(A_1) > 0, P[(A_1 \cup A_2) | B] = P(A_2 | B) - P(A_1 A_2 | B)$，则下列选项中错误的是 ( ).

(A) $P(A_1 | B) = 0$
(B) $P(\overline{A_1} | B) = 1$
(C) $P[(A_1 \cup A_2) | \overline{B}] = P(A_2 | \overline{B}) - P(A_1 A_2 | \overline{B})$
(D) $P(A_1 B \cup A_2 B) = P(A_2 B)$

---

## 答案


## DeepSeek V4 Flash Max 解析

**答案**：C。题设等价于 $P(A_1|B)=0$；但由 $P(A_1)>0$、$P(\overline B)>0$ 可得 $P(A_1|\overline B)>0$，故 C 中的等式不成立。

**解题切入点**：看到条件 $P[(A_1\cup A_2)|B]$，应先在给定 $B$ 的概率空间中使用容斥公式：
$P[(A_1\cup A_2)|B]=P(A_1|B)+P(A_2|B)-P(A_1A_2|B).$
与题设比较，公共项 $P(A_2|B)-P(A_1A_2|B)$ 相消，立即得到 $P(A_1|B)=0$。这就像算法中先在等式两边“抵消公共项”，再判断剩余项是否为零。之后只需把“条件概率为 0”翻译成“与 $B$ 的交集概率为 0”，逐一判断选项。

**推演**：

由条件概率定义与事件的容斥公式：
$
P[(A_1\cup A_2)|B]
= \frac{P((A_1\cup A_2)B)}{P(B)}
= \frac{P(A_1B)+P(A_2B)-P(A_1A_2B)}{P(B)}
= P(A_1|B)+P(A_2|B)-P(A_1A_2|B).
$

题设给出：
$
P[(A_1\cup A_2)|B]
= P(A_2|B)-P(A_1A_2|B).
$

两式比较，得：
$
P(A_1|B)=0.
$

所以：

(A) 正确，因为 $P(A_1|B)=0$。

(B) 正确，因为
$
P(\overline{A_1}|B)=1-P(A_1|B)=1.
$

由 $P(A_1|B)=0$，得：
$
P(A_1B)=P(B)P(A_1|B)=0.
$

又因为 $A_1A_2B\subset A_1B$，所以：
$
P(A_1A_2B)=0.
$

于是：
$
P(A_1B\cup A_2B)
= P(A_1B)+P(A_2B)-P(A_1A_2B)
= P(A_2B).
$

故 (D) 正确。

再看 (C)。因为 $P(A_1B)=0$，所以
$
P(A_1\overline B)=P(A_1)-P(A_1B)=P(A_1)>0.
$

又 $P(\overline B)>0$，故
$
P(A_1|\overline B)=\frac{P(A_1\overline B)}{P(\overline B)}>0.
$

但在 $\overline B$ 条件下，容斥公式给出：
$
P[(A_1\cup A_2)|\overline B]
= P(A_1|\overline B)+P(A_2|\overline B)-P(A_1A_2|\overline B).
$

而 C 的右边缺少正项 $P(A_1|\overline B)$，所以 C 不成立。

**易错点**：

1. 误以为 $P(A_1|B)=0$ 与 $P(A_1)>0$ 矛盾。实际上 $P(A_1|B)=0$ 只说明 $A_1$ 与 $B$ 同时发生的概率为 $0$，并不要求 $A_1$ 本身不发生。
2. 把关于 $B$ 的条件概率结论直接搬到 $\overline B$ 上。条件不同，样本空间不同，必须重新计算。
3. 判断 (D) 时忘记 $A_1A_2B\subset A_1B$，从而漏掉 $P(A_1A_2B)=0$。
4. 忽略 $P(\overline B)>0$ 与 $P(A_1)>0$ 这两个条件；正是它们保证了 $P(A_1|\overline B)>0$，从而排除 C。

**命题规律**：本题核心是条件概率空间中的容斥公式与“概率为 0 的事件”的性质。常见变式包括：把“错误的是”改为“一定正确的是”，或把 $B$ 换成 $\overline B$ 设计干扰项。复习时应把条件概率看作“缩小样本空间后的概率”，并熟练掌握事件关系与容斥公式。

**知识点**：条件概率、容斥公式、概率为 0 的事件性质

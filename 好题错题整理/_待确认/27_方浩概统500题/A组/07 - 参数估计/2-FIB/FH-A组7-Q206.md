# FIB 第 206 题

![[_Attachments/题目识别/27_方浩概统500题-题目/FH-A组7-Q206_题目.png|题目]]

206(仅数学一) 设某产品的性能指标 $X \sim N(\mu, \sigma^2)$，现随机抽取 30 个产品进行检测，产品的性能指标的样本均值为 $\overline{X}$，样本方差为 $S^2$，则 $X$ 的标准差 $\sigma$ 的置信水平为 $0.95$ 的置信区间为 \_.

---

## 答案


## DeepSeek V4 Flash Max 解析

**答案**：按考研常用的上侧分位数记法（\(\chi_\alpha^2(n)\) 满足 \(P(\chi^2>\chi_\alpha^2(n))=\alpha\)），所求置信区间为
\[
\boxed{
\left[
\sqrt{\frac{29S^2}{\chi^2_{0.025}(29)}},\;
\sqrt{\frac{29S^2}{\chi^2_{0.975}(29)}}
\right]
}
\]
理由：因枢轴量
\[
\frac{(n-1)S^2}{\sigma^2}=\frac{29S^2}{\sigma^2}\sim \chi^2(29),
\]
取等尾概率后反解即得 \(\sigma\) 的置信区间。

**解题切入点**：拿到题目先定位估计对象：要估计的是正态总体的标准差 \(\sigma\)，不是均值 \(\mu\)。对正态总体方差作区间估计时，核心工具是 \(\chi^2\) 分布，使用枢轴量
\[
\frac{(n-1)S^2}{\sigma^2}.
\]
这就像算法竞赛中先构造一个“分布已知的辅助量”，再通过不等式反解出目标参数。

**推演**：

设样本为 \(X_1,X_2,\ldots,X_{30}\)，其中
\[
X_i\sim N(\mu,\sigma^2),
\]
且样本方差为
\[
S^2=\frac1{29}\sum_{i=1}^{30}(X_i-\overline X)^2.
\]

由正态总体抽样分布定理：
\[
\frac{(30-1)S^2}{\sigma^2}=\frac{29S^2}{\sigma^2}\sim \chi^2(29).
\]

置信水平为 \(0.95\)，故取 \(\alpha=0.05\)。按上侧分位数，有
\[
P\left(\chi^2_{0.975}(29)\le \frac{29S^2}{\sigma^2}\le \chi^2_{0.025}(29)\right)=0.95.
\]

反解不等式：
\[
\chi^2_{0.975}(29)\le \frac{29S^2}{\sigma^2}\le \chi^2_{0.025}(29),
\]
取倒数并乘以 \(29S^2\)，得
\[
\frac{29S^2}{\chi^2_{0.025}(29)}
\le \sigma^2 \le
\frac{29S^2}{\chi^2_{0.975}(29)}.
\]

因为 \(\sigma>0\)，开平方后得到标准差 \(\sigma\) 的置信区间：
\[
\boxed{
\left[
\sqrt{\frac{29S^2}{\chi^2_{0.025}(29)}},\;
\sqrt{\frac{29S^2}{\chi^2_{0.975}(29)}}
\right]
}
\]

若题目给出具体的 \(S^2\) 和 \(\chi^2\) 分位数，直接代入即可得到数值区间。

**易错点**：

1. **忘记开根号**：题目求的是 \(\sigma\)，不是 \(\sigma^2\)。若只写出 \(\sigma^2\) 的置信区间，必须再开平方。
2. **自由度写错**：因为 \(\mu\) 未知，用样本均值替代后自由度为 \(n-1=29\)，不能写成 \(n=30\)。
3. **分位数位置写反**：按上侧分位数，\(\chi^2_{0.025}(29)\) 是较大的数，\(\chi^2_{0.975}(29)\) 是较小的数。分子相同，分母大对应区间下端，分母小对应区间上端。
4. **误解置信区间含义**：置信水平 \(0.95\) 是指随机区间覆盖 \(\sigma\) 的概率为 \(0.95\)，不能说“\(\sigma\) 以 \(95\%\) 概率落在该固定区间内”。

**命题规律**：本题属于“单个正态总体方差/标准差的区间估计”，常与 \(\chi^2\) 分布、枢轴量法结合考查。常见变式包括：求 \(\sigma^2\) 的置信区间、已知 \(\mu\) 时用 \(\chi^2(n)\)、未知 \(\mu\) 时用 \(\chi^2(n-1)\)、两正态总体方差比用 \(F\) 分布等。复习时应熟练掌握三大抽样分布及其分位数记法，并会通过枢轴量反解置信区间。

**知识点**：正态总体抽样分布、\(\chi^2\) 分布、枢轴量法、置信区间

# MCQ 第 2 题

![[_Attachments/题目识别/JJ8T/JJ8T-S4-Q02_题目.png|题目]]

2. 设函数 $f(x) = \begin{cases} \frac{1}{1 + x^2}, & x \leq 0, \\ \sin x + 1, & x > 0, \end{cases}$，则 $f(x)$ 的一个原函数是(\_)。

A. $F(x) = \begin{cases} \arctan x, & x \leq 0, \\ x - \cos x, & x > 0, \end{cases}$

B. $F(x) = \begin{cases} \arctan x - 1, & x \leq 0, \\ x - \cos x, & x > 0, \end{cases}$

C. $F(x) = \begin{cases} \arctan x, & x \leq 0, \\ x + 1, & x > 0, \end{cases}$

D. $F(x) = \begin{cases} \arctan x - 1, & x \leq 0, \\ x + 1, & x > 0, \end{cases}$


---

## DeepSeek V4 Flash Max

【考点】本题考查原函数的定义：若 $F'(x)=f(x)$，则 $F(x)$ 是 $f(x)$ 的原函数。解题关键在于分段积分后，利用原函数在分段点处的连续性与可导性确定常数，这与算法竞赛中拼接状态时检查边界条件类似，必须保证“接口处”连续且导数匹配。

【解】
设 $f(x)$ 的一个原函数为 $F(x)$，则 $F'(x)=f(x)$。

当 $x \leq 0$ 时，$f(x)=\frac{1}{1+x^2}$，积分得
$$
F(x) = \arctan x + C_1 \quad (x \leq 0)
$$

当 $x > 0$ 时，$f(x)=\sin x + 1$，积分得
$$
F(x) = -\cos x + x + C_2 \quad (x > 0)
$$

由于原函数可导，故必连续。在 $x=0$ 处：
左极限：$\lim_{x\to 0^-} F(x) = \arctan 0 + C_1 = C_1$
右极限：$\lim_{x\to 0^+} F(x) = -\cos 0 + 0 + C_2 = -1 + C_2$
由连续性要求 $C_1 = -1 + C_2$，即 $C_2 = C_1 + 1$。

再验证可导性：
左导数：$(\arctan x)'|_{x=0} = \frac{1}{1+0^2}=1$
右导数：$(-\cos x + x)'|_{x=0} = (\sin x + 1)|_{x=0}=1$
左右导数相等，故可导性自动满足。

因此原函数通式为
$$
F(x) = \begin{cases} \arctan x + C_1, & x \leq 0 \\ -\cos x + x + C_1 + 1, & x > 0 \end{cases}
$$

对比选项：
- A：$x \leq 0$ 时 $C_1=0$，则 $x>0$ 时应为 $-\cos x + x + 1$，但A给的是 $-\cos x + x$，差常数1，故不满足连续性，错误。
- B：$x \leq 0$ 时 $C_1=-1$，则 $x>0$ 时为 $-\cos x + x + 0$，即 $x - \cos x$，与B一致，且连续可导，正确。
- C：$x>0$ 部分 $x+1$ 的导数为 $1$，不等于 $\sin x + 1$，故错误。
- D：$x>0$ 部分 $x+1$ 同样不满足导数条件，故错误。

【答案】正确选项为 **(B)**。

【易错点】
1. 忽略原函数必须在分段点连续，导致常数项选取错误。本题A项就是典型的“忘了加常数”的干扰项。
2. 误以为只要每段分别积分即可，忽略分段点处左右极限的一致性。
3. 对 $x>0$ 部分积分时漏掉 $-\cos x$，错选C或D。
4. 防错提醒：求分段函数的原函数，务必先积分，再令分段点处左极限=右极限确定常数，最后检查导数是否处处等于 $f(x)$。

> 题面按常规分段函数理解（OCR无误）。

【命题规律】此类题是考研数学一高频基础题，重点考查原函数定义与分段函数连续性。通常给出分段函数，要求识别正确的原函数，干扰项设计常为“常数项不匹配”或“某段积分错误”。复习建议：熟练掌握基本初等函数的积分公式，并养成“先积分、再定常数、后验导”的三步走习惯。

## V4 Flash Max 解析

**答案**: B。只有选项 B 满足：在 $x<0$ 时 $F'(x)=\dfrac{1}{1+x^2}=f(x)$，在 $x>0$ 时 $F'(x)=1+\sin x=f(x)$，且在分段点 $x=0$ 处 $F$ 连续、左右导数都等于 $1=f(0)$。

**解题切入点**: 原函数的核心条件是 $F'=f$。分段函数求原函数，先分段积分，再像算法竞赛里“合并区间”一样处理分段点：必须检查函数在分段点处连续，且左右导数相等。看到 $x>0$ 时 $f(x)=\sin x+1$，应直接想到右支原函数必须是 $x-\cos x+C$，而不是 $x+1$。

**推演**:

当 $x<0$ 时，
$$
\int \frac{1}{1+x^2}\,dx=\arctan x+C_1,
$$
所以左支候选形式为 $\arctan x+C_1$。

当 $x>0$ 时，
$$
\int(\sin x+1)\,dx=x-\cos x+C_2,
$$
所以右支候选形式为 $x-\cos x+C_2$。

因此 C、D 的右支 $x+1$ 直接排除，因为 $(x+1)'=1\neq \sin x+1$。

再看 A、B 在 $x=0$ 处的拼接。

A：
$$
F(0)=\arctan 0=0,\qquad \lim_{x\to0^+}(x-\cos x)=-1,
$$
左右极限不相等，$F$ 在 $0$ 处不连续，不可能可导，排除。

B：
$$
F(0)=\arctan0-1=-1,\qquad \lim_{x\to0^+}(x-\cos x)=-1,
$$
连续。

再验证 $x=0$ 处导数：
$$
F'_-(0)=\lim_{h\to0^-}\frac{\arctan h-1-(-1)}{h}
=\lim_{h\to0^-}\frac{\arctan h}{h}=1,
$$
$$
F'_+(0)=\lim_{h\to0^+}\frac{h-\cos h-(-1)}{h}
=\lim_{h\to0^+}\frac{h+1-\cos h}{h}=1.
$$
而 $f(0)=1$，所以 $F'(0)=1=f(0)$。

因此 B 是 $f(x)$ 的一个原函数。

**易错点**: 最容易误选 A：每段导数都对了，但忘记了原函数在分段点必须连续。A 在 $x=0$ 处出现跳跃，$F'(0)$ 不存在。另一个易错点是右支原函数误写成 $x+1$，求导后只是 $1$，不是 $\sin x+1$。自检方法：逐段求导后回代，并单独检查分段点 $x=0$ 的左右导数是否都等于 $f(0)$。

**命题规律**: 这是“分段函数的原函数与可导性”经典考法。命题人常在分段点设置常数错位，诱导只核对各段导数的考生。常见变式包括：给分段函数选原函数、用变上限积分定义 $F(x)$ 后判断可导性、讨论有间断点的函数是否存在原函数。核心思想是：连续函数必存在原函数，分段拼接时必须保证连续性，且分段点处左右导数相等。

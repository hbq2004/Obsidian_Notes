# MCQ 第 3 题

![[_Attachments/题目识别/JJ8T/JJ8T-S4-Q03_题目.png|题目]]

3. 设数列 $\{x_n\}$、$\{y_n\}$ 满足 $x_1 = y_1 = \frac{1}{2}$，$x_{n+1} = x_n - \ln(1 + x_n)$，$y_{n+1} = y_n^2$，则当 $n \to \infty$ 时(\_)。

A. $x_n$ 是 $y_n$ 的高阶无穷小

B. $y_n$ 是 $x_n$ 的高阶无穷小

C. $x_n$ 是 $y_n$ 的等价无穷小

D. $x_n$ 是 $y_n$ 的同阶但非等价无穷小


---

## DeepSeek V4 Flash Max

【考点】本题考查无穷小阶的比较，核心是把握递推数列的“增长率”信息。类比算法竞赛中比较两个递归函数的复杂度，通常取对数将乘法递推转化为线性递推，从而看出指数阶的差异。

【解】
1. 求 $y_n$ 通项：由 $y_{n+1}=y_n^2$ 且 $y_1=1/2$，归纳得 $$y_n=\left(\frac12\right)^{2^{n-1}}.$$

2. 分析 $x_n$：因为 $x_n\to 0$，利用对数展开 $$\ln(1+x_n)=x_n-\frac{x_n^2}{2}+O(x_n^3),$$ 所以 $$x_{n+1}=x_n-\ln(1+x_n)=\frac{x_n^2}{2}+O(x_n^3),$$ 故 $x_{n+1}\sim \frac12 x_n^2$。

3. 令 $u_n=\frac1{x_n}$，则 $$u_{n+1}=\frac1{x_n-\ln(1+x_n)}\sim \frac{2}{x_n^2}=2u_n^2.$$ 取对数得 $$\ln u_{n+1}\sim \ln 2+2\ln u_n.$$ 初始 $\ln u_1=\ln 2$。设 $a_n=\ln u_n$，解线性递推（忽略高阶小）得 $$a_n=(\ln 2)(2^n-1),$$ 即 $$\ln u_n\sim (\ln 2)(2^n-1).$$

4. 对 $y_n$，令 $v_n=\frac1{y_n}=2^{2^{n-1}}$，则 $$\ln v_n=2^{n-1}\ln 2.$$

5. 比较两个对数：$$\frac{\ln u_n}{\ln v_n}\sim \frac{(\ln 2)(2^n-1)}{2^{n-1}\ln 2}\sim 2.$$ 因此 $\ln u_n\sim 2\ln v_n$，即 $u_n$ 与 $v_n^2$ 同阶。精确地，由 $\ln u_n=2\ln v_n-\ln 2$ 得 $$u_n\sim \frac12 v_n^2.$$ 即 $$\frac1{x_n}\sim \frac12\cdot\frac1{y_n^2},$$ 所以 $$x_n\sim 2y_n^2.$$

6. 因此 $$\frac{x_n}{y_n}\sim 2y_n\to 0.$$ 由高阶无穷小定义，$x_n$ 是 $y_n$ 的高阶无穷小。

【答案】选 **(A)**。
逐个说明：
- (A) 正确：$\lim\frac{x_n}{y_n}=0$。
- (B) 错误：$\lim\frac{y_n}{x_n}=+\infty$，说明 $y_n$ 是比 $x_n$ 更低阶的无穷小（即 $x_n$ 高阶）。
- (C) 错误：等价无穷小要求比值极限为1，但此处为0。
- (D) 错误：同阶非等价要求比值为非零常数，但此处为0。

【易错点】易误认为两者都是“平方递推”从而同阶，但忽略了系数 $1/2$ 的影响。实际上取对数后指数基底不同，$x_n$ 约为 $2y_n^2$，比 $y_n$ 小得多。防止混淆：高阶无穷小（分子趋于0更快）对应比值极限为0。本题中 $x_n$ 是分子，$y_n$ 是分母，故 $x_n$ 高阶。另请注意，若用等价无穷小近似，$x_{n+1}\approx x_n^2/2$，但不可直接与 $y_{n+1}=y_n^2$ 比较，因为初值相同但递推系数不同。

【命题规律】此类题常以递推数列给出两个无穷小，利用对数变换或取倒数将递推化为线性关系，再比较指数阶。复习时应掌握等价无穷小替换、递推数列极限的常用方法，以及“取对数”分析阶数的技巧。

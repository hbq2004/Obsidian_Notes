# FRQ 第 18 题

![[_Attachments/题目识别/JJ8T/JJ8T-S4-Q18_题目.png|题目]]

18. (本题满分 12 分) 求函数 $f(x,y) = x^3 + y^3 - 3x^2 - 3y^2 - 9x$ 的极值.


---

## 解析（AI 生成，仅供参考）

【考点】本题考查多元函数极值的求解，核心是求驻点并用二阶偏导数判别法（AC-B²）判定极值。类比算法竞赛中，先枚举候选状态（驻点），再用凸性（Hessian矩阵）判断局部最优。

【解】\
第一步，求一阶偏导数并令其为零：\
$$f_x = \frac{\partial f}{\partial x} = 3x^2 - 6x - 9 = 3(x-3)(x+1),$$\
$$f_y = \frac{\partial f}{\partial y} = 3y^2 - 6y = 3y(y-2).$$\
令 $f_x=0, f_y=0$，得 $x=3$ 或 $-1$，$y=0$ 或 $2$，故驻点为：\
$$(3,0),\ (3,2),\ (-1,0),\ (-1,2).$$\
\
第二步，求二阶偏导数：\
$$f_{xx} = 6x - 6 = 6(x-1),\quad f_{yy} = 6y - 6 = 6(y-1),\quad f_{xy} = 0.$$\
判别式 $\Delta = f_{xx} f_{yy} - f_{xy}^2 = 36(x-1)(y-1)$。\
\
第三步，逐点判定：\
- 对于 $(3,0)$：$f_{xx}=12>0$，$f_{yy}=-6<0$，$\Delta = 12\times(-6) - 0 = -72 < 0$，故为鞍点，非极值。\
- 对于 $(3,2)$：$f_{xx}=12>0$，$f_{yy}=6>0$，$\Delta = 12\times6 = 72 > 0$，且 $f_{xx}>0$，故为极小值点。计算 $f(3,2) = 27+8-27-12-27 = -31$。\
- 对于 $(-1,0)$：$f_{xx}=-12<0$，$f_{yy}=-6<0$，$\Delta = (-12)\times(-6) = 72 > 0$，且 $f_{xx}<0$，故为极大值点。计算 $f(-1,0) = -1+0-3-0+9 = 5$。\
- 对于 $(-1,2)$：$f_{xx}=-12<0$，$f_{yy}=6>0$，$\Delta = (-12)\times6 = -72 < 0$，故为鞍点，非极值。\
\
综上，函数存在一个极大值和一个极小值。

【答案】极大值为 $f(-1,0)=5$，极小值为 $f(3,2)=-31$。\
关键给分点：① 正确求出一阶偏导并列出驻点（4分）；② 正确计算二阶偏导及判别式（3分）；③ 逐点判定并给出极值（5分）。

【易错点】\
1. 忘记令 $f_y=0$ 时 $y=0$ 或 $2$，漏掉驻点。\
2. 二阶偏导判别时，误将 $f_{xx}$ 与 $f_{yy}$ 的符号相反误判为极值（此时 $\Delta<0$ 为鞍点）。\
3. 计算函数值代入时符号错误，尤其注意 $-9x$ 在 $x=-1$ 时为正。\
防错提醒：按步骤列出所有驻点，统一套用 $\Delta = f_{xx}f_{yy}-f_{xy}^2$ 判断，不要凭直觉。\

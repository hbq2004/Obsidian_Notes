# FIB 第 11 题

![[_Attachments/题目识别/JJ8T/JJ8T-S4-Q11_题目.png|题目]]

11. 当 $x \to 0$ 时，$f(x) = a + bx + cx^2 + \sqrt{1 - x}$ 与 $g(x) = e^{2x^2} - \cos 3x$ 为等价无穷小，则 $a + b + c = \_$ .


---

## 解析（AI 生成，仅供参考）

【考点】本题考查等价无穷小的判定，关键在于将函数展开为泰勒级数，比较最低阶项的系数。类比算法竞赛中的复杂度比较：若两个函数是等价无穷小，则它们在 $x \to 0$ 时比值趋于 1，等价于它们的首项（最低阶项）系数完全相同。

【解】
1. 先展开 $f(x)$ 和 $g(x)$ 在 $x=0$ 处的泰勒级数。

   $$\sqrt{1-x} = 1 - \frac{x}{2} - \frac{x^2}{8} + O(x^3)$$

   因此

   $$f(x) = a + bx + cx^2 + 1 - \frac{x}{2} - \frac{x^2}{8} + O(x^3) = (a+1) + \left(b - \frac{1}{2}\right)x + \left(c - \frac{1}{8}\right)x^2 + O(x^3)$$

2. 展开 $g(x)$：

   $$e^{2x^2} = 1 + 2x^2 + O(x^4), \quad \cos 3x = 1 - \frac{9}{2}x^2 + O(x^4)$$

   所以

   $$g(x) = e^{2x^2} - \cos 3x = \left(1 + 2x^2\right) - \left(1 - \frac{9}{2}x^2\right) + O(x^4) = \frac{13}{2}x^2 + O(x^4)$$

3. 因为 $f(x)$ 与 $g(x)$ 是等价无穷小，当 $x \to 0$ 时两者都趋于 0，且比值趋于 1。则 $f(x)$ 的常数项必须为 0：

   $$a + 1 = 0 \Rightarrow a = -1$$

4. 常数项消去后，$f(x)$ 的最低阶项应为 $x^2$，因此一次项系数也必须为 0：

   $$b - \frac{1}{2} = 0 \Rightarrow b = \frac{1}{2}$$

5. 此时 $f(x)$ 的主项为 $\left(c - \frac{1}{8}\right)x^2$，与 $g(x)$ 的主项 $\frac{13}{2}x^2$ 相等（因为等价无穷小要求比值极限为 1，所以系数相同）：

   $$c - \frac{1}{8} = \frac{13}{2} \Rightarrow c = \frac{13}{2} + \frac{1}{8} = \frac{52}{8} + \frac{1}{8} = \frac{53}{8}$$

6. 所以

   $$a + b + c = -1 + \frac{1}{2} + \frac{53}{8} = -\frac{8}{8} + \frac{4}{8} + \frac{53}{8} = \frac{49}{8}$$

【答案】
$$\boxed{\frac{49}{8}}$$

【易错点】
- 容易只令常数项为 0 而忽略一次项系数也必须为 0，导致 $b$ 求错。
- 注意等价无穷小要求比值极限为 1，所以对应阶的系数必须严格相等，而不只是同阶。
- 泰勒展开时注意符号：$\sqrt{1-x}$ 的展开中 $x$ 项系数为 $-\frac{1}{2}$，$x^2$ 项系数为 $-\frac{1}{8}$，不要漏写负号。

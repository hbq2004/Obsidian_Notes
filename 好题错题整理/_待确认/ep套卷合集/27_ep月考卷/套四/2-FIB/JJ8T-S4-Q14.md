# FIB 第 14 题

![[_Attachments/题目识别/JJ8T/JJ8T-S4-Q14_题目.png|题目]]

14. 求曲线 $2y \sin x + x \ln y = 0$ 在 $x = \pi$ 对应点的法线方程： \_\_\_\_\_\_.


---

## DeepSeek V4 Flash Max

【考点】本题考查隐函数求导及曲线法线方程，核心是先求隐函数在指定点的导数（切线斜率），再取负倒数得法线斜率。类似算法竞赛中在函数图上求切点处的梯度方向，但此处需注意法线与切线垂直的关系。

【解】
1. **求对应点坐标**
  代入 $x = \pi$ 到曲线方程 $2y \sin x + x \ln y = 0$，得
  $$2y \sin \pi + \pi \ln y = 0 \Rightarrow 0 + \pi \ln y = 0 \Rightarrow \ln y = 0 \Rightarrow y = 1$$
  故点为 $(\pi, 1)$。

2. **隐函数求导**
  对原方程两边关于 $x$ 求导，注意 $y$ 是 $x$ 的函数：
  $$\frac{d}{dx}(2y\sin x) = 2(y'\sin x + y\cos x)$$
  $$\frac{d}{dx}(x\ln y) = \ln y + x \cdot \frac{1}{y} y'$$
  因此
  $$2(y'\sin x + y\cos x) + \ln y + \frac{x}{y} y' = 0$$
  整理得
  $$y'\left(2\sin x + \frac{x}{y}\right) = -2y\cos x - \ln y$$
  所以
  $$y' = \frac{-2y\cos x - \ln y}{2\sin x + \frac{x}{y}}$$

3. **代入点 $(\pi, 1)$ 求切线斜率**
  因为 $\sin \pi = 0$，$\cos \pi = -1$，$\ln 1 = 0$，代入得
  $$y'(\pi) = \frac{-2 \cdot 1 \cdot (-1) - 0}{2 \cdot 0 + \frac{\pi}{1}} = \frac{2}{\pi}$$
  所以切线斜率为 $\frac{2}{\pi}$。

4. **求法线斜率**
  法线斜率与切线斜率互为负倒数：
  $$k_{\text{法}} = -\frac{1}{\frac{2}{\pi}} = -\frac{\pi}{2}$$

5. **写出法线方程**
  过点 $(\pi, 1)$，斜率为 $-\frac{\pi}{2}$，点斜式：
  $$y - 1 = -\frac{\pi}{2}(x - \pi)$$
  化简得
  $$y = -\frac{\pi}{2}x + \frac{\pi^2}{2} + 1$$
  或写成一般式：
  $$\pi x + 2y - \pi^2 - 2 = 0$$

【答案】
$$\boxed{\pi x + 2y - \pi^2 - 2 = 0}$$
（或等价形式 $y = -\frac{\pi}{2}x + \frac{\pi^2}{2} + 1$）

【易错点】
- 容易忘记先求对应点的 $y$ 坐标，直接代入 $x=\pi$ 导致分母除零。
- 隐函数求导时，对 $\ln y$ 的导数漏乘 $y'$。
- 法线斜率是切线斜率的负倒数，切勿取倒数而不加负号。
- 代入 $x=\pi$ 时务必注意 $\sin \pi=0$，$\cos \pi=-1$，符号易错。

【命题规律】
隐函数求导与切线、法线是考研数学一的高频小题，常与极坐标、参数方程结合。复习时需熟练掌握隐函数求导法则，并注意几何意义：切线斜率 $k$，法线斜率 $-1/k$。多做几道类似题即可轻松应对。

## V4 Flash Max 解析

**答案**:  
法线方程为  
$$y-1=-\frac{\pi}{2}(x-\pi),$$  
即  
$$y=-\frac{\pi}{2}x+\frac{\pi^2}{2}+1.$$  
等价式：$\pi x+2y-(\pi^2+2)=0$。

**解题切入点**:  
隐式曲线求切线/法线，先代 $x=\pi$ 确定对应点，再对隐函数求导得到切线斜率，最后取负倒数得法线斜率。  
算法竞赛类比：给定约束 $F(x,y)=0$ 求局部斜率，相当于在状态点 $(\pi,1)$ 附近做“扰动分析”；$F_x dx+F_y dy=0$ 就是约束在当前点的切空间方程。

**推演**:  
令 $F(x,y)=2y\sin x+x\ln y=0$。

当 $x=\pi$ 时：
$$2y\sin\pi+\pi\ln y=0.$$
因为 $\sin\pi=0$，所以
$$\pi\ln y=0\Rightarrow \ln y=0\Rightarrow y=1.$$
对应点为 $(\pi,1)$。

对原方程两边关于 $x$ 求导，注意 $y=y(x)$：
$$2(y'\sin x+y\cos x)+\ln y+x\frac{y'}{y}=0.$$

代入 $x=\pi,\ y=1$：
$$\sin\pi=0,\quad \cos\pi=-1,\quad \ln 1=0,$$
得
$$2(0+1\cdot(-1))+0+\pi y'=0,$$
即
$$-2+\pi y'=0,$$
所以切线斜率
$$y'(\pi)=\frac{2}{\pi}.$$

法线斜率与切线斜率互为负倒数：
$$k_n=-\frac{1}{2/\pi}=-\frac{\pi}{2}.$$

过点 $(\pi,1)$ 的法线方程为
$$y-1=-\frac{\pi}{2}(x-\pi).$$

化简：
$$y=-\frac{\pi}{2}x+\frac{\pi^2}{2}+1.$$

**易错点**:  
1. 忘记先求 $y$。直接代 $x=\pi$ 求导会缺失点坐标，无法写直线方程。  
2. 隐函数求导时漏项。  
   $2y\sin x$ 是乘积，求导应为 $2(y'\sin x+y\cos x)$，其中 $y\cos x$ 很容易漏掉。  
3. 混淆切线与法线。  
   切线斜率为 $\dfrac{2}{\pi}$，法线斜率是 $-\dfrac{\pi}{2}$，不是 $\dfrac{\pi}{2}$，也不是 $\dfrac{1}{2/\pi}$。  
4. 代入点后把 $\cos\pi=-1$ 忽略。  
   $\sin\pi=0$，但 $\cos\pi=-1$，不能因为三角函数项为 $0$ 就整体忽略。  

**自检**：  
用隐函数求导公式验证：
$$F_x=2y\cos x+\ln y,\qquad F_y=2\sin x+\frac{x}{y}.$$
在 $(\pi,1)$ 处：
$$F_x=-2,\qquad F_y=\pi,$$
所以
$$y'=-\frac{F_x}{F_y}=\frac{2}{\pi}.$$
与上面结果一致。

**命题规律**:  
隐函数求导与切线、法线是考研数学一的高频小题考点。常见变式有：  
- 给定隐式方程求切线/法线；  
- 参数方程或极坐标方程求切线斜率；  
- 结合全微分求 $\dfrac{dy}{dx}$；  
- 考察隐函数存在定理，即 $F_y\neq 0$ 的条件。  

从多元微分角度看，本质是 $F_x dx+F_y dy=0$，在局部把隐式约束近似为线性方程。对算法竞赛背景来说，这类似于在约束流形上求当前点的切空间方向。若某点处 $F_y=0$，则不能直接写成 $y=y(x)$，需要讨论竖直切线，类似算法特判。

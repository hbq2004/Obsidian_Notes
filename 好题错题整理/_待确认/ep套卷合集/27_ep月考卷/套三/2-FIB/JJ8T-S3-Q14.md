# FIB 第 14 题

![[_Attachments/题目识别/JJ8T/JJ8T-S3-Q14_题目.png|题目]]

14. 求曲线 $2y \sin x + x \ln y = 0$ 在 $x = \pi$ 对应点的法线方程： \_\_\_\_\_\_.


---

## DeepSeek V4 Flash Max

【考点】本题考查隐函数求导及曲线切线、法线斜率的计算。类比算法竞赛中给定隐式关系式，需通过链式求导提取导数信息，再结合点坐标求斜率。

【解】
首先确定对应点。将 $x=\pi$ 代入原方程 $2y\sin x + x\ln y = 0$，得
$$2y\sin\pi + \pi\ln y = 0 \Rightarrow \pi\ln y = 0 \Rightarrow \ln y = 0 \Rightarrow y=1.$$
故对应点为 $(\pi,1)$。

对方程两边关于 $x$ 求导，记得 $y=y(x)$：
$$\frac{d}{dx}(2y\sin x) + \frac{d}{dx}(x\ln y) = 0.$$
逐项求导：
$$2(y'\sin x + y\cos x) + \ln y + x\cdot\frac{y'}{y} = 0.$$
整理得
$$y'\left(2\sin x + \frac{x}{y}\right) + 2y\cos x + \ln y = 0.$$
于是
$$y' = -\frac{2y\cos x + \ln y}{2\sin x + \frac{x}{y}}.$$

代入 $(\pi,1)$，有 $\sin\pi=0$, $\cos\pi=-1$, $\ln 1=0$，得
$$y'(\pi) = -\frac{2\cdot1\cdot(-1)+0}{2\cdot0+\pi} = -\frac{-2}{\pi} = \frac{2}{\pi}.$$
所以曲线在 $(\pi,1)$ 处切线斜率为 $\frac{2}{\pi}$。

法线斜率与切线斜率互为负倒数，故法线斜率为
$$k_{\text{norm}} = -\frac{1}{k_{\text{tan}}} = -\frac{\pi}{2}.$$

由点斜式得法线方程：
$$y - 1 = -\frac{\pi}{2}(x-\pi).$$
化简：
$$y = -\frac{\pi}{2}x + \frac{\pi^2}{2} + 1.$$

【答案】
$$\boxed{y - 1 = -\frac{\pi}{2}(x-\pi)\ \ \text{或}\ \ y = -\frac{\pi}{2}x + \frac{\pi^2}{2} + 1}$$

【易错点】
1. 求导时容易漏掉第一项中 $2y\sin x$ 的乘积法则，或第二项 $x\ln y$ 的乘积法则。
2. 代入点时需牢记 $\sin\pi=0$，$\cos\pi=-1$，$\ln 1=0$，避免符号错误。
3. 法线斜率是切线斜率的负倒数，切勿直接取切线斜率。
4. 注意隐函数求导时 $y$ 是 $x$ 的函数，每一项都要考虑链式法则。

【命题规律】本题考查隐函数求导与几何意义，常见于选择题或填空题。命题常给出含参隐式曲线，求某点处的切线或法线方程。复习时应熟练掌握隐函数求导法、基本初等函数导数、特殊点函数值，并注意切线斜率与法线斜率的转换。多做类似题型可提高计算准确率。

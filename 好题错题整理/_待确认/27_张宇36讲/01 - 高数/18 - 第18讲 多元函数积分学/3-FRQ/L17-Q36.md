**答案**: 第一问 $I = \dfrac{14\pi}{3}$；第二问题目信息不完整，无法计算。

**解题切入点**: 第一问是第二类曲面积分，曲面为锥面 $z=\sqrt{x^2+y^2}$ 在 $1\le x^2+y^2\le4$ 的部分，指定下侧。被积函数中含有未知连续函数 $f(xy)$，但计算结果表明含 $f$ 的项恰好抵消，最终结果与 $f$ 无关。因此，应直接利用曲面显式表达式，将曲面积分投影到 $xy$ 平面，并正确使用下侧时的转换公式（$dy\,dz = z_x\,dx\,dy,\ dz\,dx = z_y\,dx\,dy,\ dx\,dy = -\,dx\,dy$），将积分化为 $xy$ 平面上的二重积分，再化简计算。如此可避免使用高斯公式时对 $f$ 可导性的要求，简洁地得到结果。

**推演**:  
曲面 $\Sigma$: $z = \sqrt{x^2+y^2}$，$(x,y)\in D$，其中 $D=\{(x,y)\mid 1\le x^2+y^2\le4\}$，取 **下侧**。  
下侧时，法向量方向为 $(z_x,z_y,-1)$，其中 $z_x=\dfrac{x}{\sqrt{x^2+y^2}},\ z_y=\dfrac{y}{\sqrt{x^2+y^2}}$。  
有向面积元转换公式（下侧）：
$
\mathrm{d}y\,\mathrm{d}z = z_x\,\mathrm{d}x\,\mathrm{d}y,\qquad 
\mathrm{d}z\,\mathrm{d}x = z_y\,\mathrm{d}x\,\mathrm{d}y,\qquad 
\mathrm{d}x\,\mathrm{d}y = -\,\mathrm{d}x\,\mathrm{d}y.
$
这里 $\mathrm{d}x\,\mathrm{d}y$ 表示 $xy$ 平面上的正面积元。

于是
$
I = \iint_{\Sigma} P\,\mathrm{d}y\,\mathrm{d}z + Q\,\mathrm{d}z\,\mathrm{d}x + R\,\mathrm{d}x\,\mathrm{d}y
= \iint_{D} \bigl[P\,z_x + Q\,z_y + R\cdot(-1)\bigr]\,\mathrm{d}x\,\mathrm{d}y,
$
其中
$
P = x f(xy) + 2x - y,\quad
Q = y f(xy) + 2y + x,\quad
R = z f(xy) + z,\quad z = \sqrt{x^2+y^2}.
$
代入计算：
$
\begin{aligned}
P z_x &= (x f+2x-y)\frac{x}{\sqrt{x^2+y^2}} 
= \frac{x^2 f + 2x^2 - xy}{\sqrt{x^2+y^2}},\\
Q z_y &= (y f+2y+x)\frac{y}{\sqrt{x^2+y^2}} 
= \frac{y^2 f + 2y^2 + xy}{\sqrt{x^2+y^2}},\\
R\cdot(-1) &= -(z f+z) = -\sqrt{x^2+y^2}\,f - \sqrt{x^2+y^2}.
\end{aligned}
$
三式相加：
$
\begin{aligned}
P z_x+Q z_y-R &= \frac{(x^2+y^2)f + 2(x^2+y^2)}{\sqrt{x^2+y^2}} 
- \sqrt{x^2+y^2}\,f - \sqrt{x^2+y^2} \\
&= \frac{(x^2+y^2)f}{\sqrt{x^2+y^2}} + \frac{2(x^2+y^2)}{\sqrt{x^2+y^2}} 
- \sqrt{x^2+y^2}\,f - \sqrt{x^2+y^2} \\
&= \sqrt{x^2+y^2}\,f + 2\sqrt{x^2+y^2} - \sqrt{x^2+y^2}\,f - \sqrt{x^2+y^2} \\
&= \sqrt{x^2+y^2}.
\end{aligned}
$
因此
$
I = \iint_{D} \sqrt{x^2+y^2}\,\mathrm{d}x\,\mathrm{d}y.
$
区域 $D$ 为圆环 $1\le x^2+y^2\le4$，采用极坐标：$x=r\cos\theta,\ y=r\sin\theta$，$\mathrm{d}x\,\mathrm{d}y=r\,\mathrm{d}r\,\mathrm{d}\theta$，$\sqrt{x^2+y^2}=r$，积分限 $r=1\to2$，$\theta=0\to2\pi$。
$
I = \int_{0}^{2\pi}\mathrm{d}\theta \int_{1}^{2} r\cdot r\,\mathrm{d}r
= 2\pi \int_{1}^{2} r^{2}\,\mathrm{d}r
= 2\pi \left[\frac{r^{3}}{3}\right]_{1}^{2}
= 2\pi \left(\frac{8}{3}-\frac{1}{3}\right)
= \frac{14\pi}{3}.
$

**易错点**:  
1. **转换公式符号错误**：下侧时 $\mathrm{d}x\,\mathrm{d}y$ 为负，$\mathrm{d}y\,\mathrm{d}z$ 与 $\mathrm{d}z\,\mathrm{d}x$ 的符号需与 $z_x,z_y$ 同号。若误用上侧公式，会导致结果错误。  
2. **投影区域遗漏**：曲面 $z=\sqrt{x^2+y^2}$ 在 $xy$ 平面上的投影是 $1\le x^2+y^2\le4$，注意不包括 $r<1$ 部分。  
3. **化简含 $f$ 项时粗心**：计算 $Pz_x$、$Qz_y$ 时，$xy$ 项恰好与 $-R$ 中的 $f$ 项抵消，需仔细代数运算，避免符号错误。  
4. **极坐标积分**：面积元 $\mathrm{d}x\,\mathrm{d}y = r\,\mathrm{d}r\,\mathrm{d}\theta$，易漏掉 $r$。

**命题规律**: 本题属于第二类曲面积分的计算，常见考点：  
- 利用曲面显式表达式，通过转换投影公式将积分化为二重积分。  
- 含未知函数 $f$ 的积分往往通过对称性或代数运算消去，结果与 $f$ 无关，需保持化简耐心。  
- 也可用高斯公式（补上底面、下底面）并利用对称性，但需注意 $f$ 的可导性，直接投影法更稳妥。  
- 这类题常出现在考研数学一中，重点考查曲面积分的坐标转换、符号判断及基本计算能力。  
**变式**：可将曲面换为旋转抛物面等，或改变侧的方向，但方法类似。复习时需熟练掌握各类曲面的投影公式及符号约定。

# FIB 第 6 题

![[_Attachments/题目识别/27_张宇36讲-题目/L16-Q06_题目.png|题目]]

曲面 $z = x + 2y + \ln(1 + x^2 + y^2)$ 在点 $(0,0,0)$ 处的切平面方程为 \_.

---

## 答案

![[_Attachments/题目识别/27_张宇36讲-答案/L16-Q06_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**: $z = x + 2y$（或 $x + 2y - z = 0$）。

**解题切入点**: 该题考查曲面的切平面方程，属于多元函数微分学的基本应用。曲面由显式 $z = f(x,y)$ 给出，因此切平面方程可直接由 $z - z_0 = f_x(x_0,y_0)(x - x_0) + f_y(x_0,y_0)(y - y_0)$ 得到。关键是快速计算偏导数在给定点的值，类似于求一元函数切线时先求导数，再代入点斜式。

**推演**:  
曲面为 $z = f(x,y) = x + 2y + \ln(1 + x^2 + y^2)$，点 $(0,0,0)$ 满足 $f(0,0)=0$，故在曲面上。  
计算偏导数：  
$$f_x(x,y) = \frac{\partial}{\partial x}\left[x + 2y + \ln(1 + x^2 + y^2)\right] = 1 + \frac{2x}{1 + x^2 + y^2},$$  
$$f_y(x,y) = \frac{\partial}{\partial y}\left[x + 2y + \ln(1 + x^2 + y^2)\right] = 2 + \frac{2y}{1 + x^2 + y^2}.$$  
代入 $(0,0)$：  
$$f_x(0,0) = 1 + 0 = 1,\quad f_y(0,0) = 2 + 0 = 2.$$  
切平面方程为  
$$z - 0 = f_x(0,0)(x - 0) + f_y(0,0)(y - 0) \;\Longrightarrow\; z = x + 2y.$$  
也可写成 $x + 2y - z = 0$。

**易错点**:  
1. 忘记检查点是否在曲面上：本题中 $(0,0,0)$ 显然满足方程，但若漏验会导致错误。  
2. 偏导数计算错误：对 $\ln(1+x^2+y^2)$ 求导时易漏掉链式法则，或误将 $\ln$ 的导数当作 $\frac{1}{1+x^2+y^2}$ 而忘记乘以内层导数。  
3. 混淆切平面与法线方程：求切平面时需用偏导数值作为系数，而不是法向量。

**命题规律**:  
本题是考研数学一的高频基础题，考点为“显式曲面的切平面方程”。常见变式包括：  
- 曲面由隐式 $F(x,y,z)=0$ 给出，需用梯度求法向量；  
- 或曲面为参数形式，需用偏导数的链式法则。  
复习建议：熟练掌握多元函数偏导数的计算，并理解切平面的几何意义（偏导数对应切平面的斜率）。对于此类题，通常只需计算两个偏导数即可快速得分。

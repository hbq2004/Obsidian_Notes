# FRQ 第 7 题

![[_Attachments/题目识别/27_张宇36讲-题目/L08-Q07_题目.png|题目]]

求下列不定积分.

(1) $\int e^x \sin x dx;$

(2) $\int \sqrt{1+x^2} dx.$

---

## 答案

![[_Attachments/题目识别/27_张宇36讲-答案/L08-Q07_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**:  
(1) $\displaystyle\int e^x \sin x\,dx = \frac{1}{2}e^x(\sin x-\cos x)+C$，其中 $C$ 为任意常数。  
(2) $\displaystyle\int \sqrt{1+x^2}\,dx = \frac{x}{2}\sqrt{1+x^2}+\frac{1}{2}\ln\!\bigl|x+\sqrt{1+x^2}\bigr|+C$，或等价地 $\frac{x}{2}\sqrt{1+x^2}+\frac{1}{2}\operatorname{arcsinh}x+C$。

**解题切入点**:  
(1) 被积函数为指数函数与三角函数的乘积，属于“循环积分”类型。通过两次分部积分，原积分会重新出现，从而可解出积分式。也可利用欧拉公式将 $\sin x$ 化为复指数形式，但分部积分更直接。  
(2) 被积函数含 $\sqrt{1+x^2}$，是二次型根式的典型代表。常用方法有三角换元（令 $x=\tan t$）、双曲换元（令 $x=\sinh t$）或分部积分法，其中分部积分可将原积分转化为有理函数积分，最终得到标准结果。

**推演**:  
(1) 求 $\int e^x \sin x\,dx$。  
设 $I=\int e^x \sin x\,dx$。  
第一次分部积分：令 $u=\sin x$，$dv=e^x\,dx$，则 $du=\cos x\,dx$，$v=e^x$，  
$$I = e^x\sin x - \int e^x\cos x\,dx.$$  
第二次分部积分：对 $\int e^x\cos x\,dx$，令 $u=\cos x$，$dv=e^x\,dx$，则 $du=-\sin x\,dx$，$v=e^x$，  
$$\int e^x\cos x\,dx = e^x\cos x - \int e^x(-\sin x)\,dx = e^x\cos x + I.$$  
代入得  
$$I = e^x\sin x - (e^x\cos x + I) = e^x(\sin x-\cos x) - I,$$  
所以 $2I = e^x(\sin x-\cos x)$，即 $I = \frac{1}{2}e^x(\sin x-\cos x)+C$。

(2) 求 $\int \sqrt{1+x^2}\,dx$。  
方法一（三角换元）：令 $x=\tan t$，$t\in(-\frac{\pi}{2},\frac{\pi}{2})$，则 $dx=\sec^2t\,dt$，$\sqrt{1+x^2}=\sec t$，  
原积分 $=\int \sec t\cdot\sec^2t\,dt = \int \sec^3t\,dt$。  
计算 $\int \sec^3t\,dt$：  
$$\int \sec^3t\,dt = \int \sec t\cdot\sec^2t\,dt = \sec t\tan t - \int \tan t\cdot\sec t\tan t\,dt = \sec t\tan t - \int \tan^2t\sec t\,dt$$  
$$= \sec t\tan t - \int (\sec^2t-1)\sec t\,dt = \sec t\tan t - \int \sec^3t\,dt + \int \sec t\,dt.$$  
故 $2\int \sec^3t\,dt = \sec t\tan t + \int \sec t\,dt$，即  
$$\int \sec^3t\,dt = \frac{1}{2}\sec t\tan t + \frac{1}{2}\ln|\sec t+\tan t|+C.$$  
回代：$\tan t = x$，$\sec t = \sqrt{1+x^2}$（$t$ 范围内 $\sec t>0$），得  
$$\int \sqrt{1+x^2}\,dx = \frac{1}{2}x\sqrt{1+x^2}+\frac{1}{2}\ln\!\bigl|x+\sqrt{1+x^2}\bigr|+C.$$  
方法二（分部积分法）：  
$$I = \int \sqrt{1+x^2}\,dx = x\sqrt{1+x^2} - \int x\cdot\frac{x}{\sqrt{1+x^2}}\,dx = x\sqrt{1+x^2} - \int \frac{x^2}{\sqrt{1+x^2}}\,dx.$$  
而 $\int \frac{x^2}{\sqrt{1+x^2}}\,dx = \int \frac{(1+x^2)-1}{\sqrt{1+x^2}}\,dx = \int \sqrt{1+x^2}\,dx - \int \frac{dx}{\sqrt{1+x^2}} = I - \ln\!\bigl(x+\sqrt{1+x^2}\bigr)$，  
代入得 $I = x\sqrt{1+x^2} - \bigl(I - \ln(x+\sqrt{1+x^2})\bigr)$，即 $2I = x\sqrt{1+x^2} + \ln(x+\sqrt{1+x^2})$，  
所以 $I = \frac{1}{2}x\sqrt{1+x^2} + \frac{1}{2}\ln\!\bigl(x+\sqrt{1+x^2}\bigr)+C$。

**易错点**:  
(1) 分部积分两次后，容易在整理方程时符号出错，或忘记将原积分作为未知数求解。注意每次分部后要正确写出表达式，并确保循环关系成立。最后务必加上积分常数 $C$。  
(2) 三角换元时，回代要注意 $\sec t$ 的正负，此处取正根；$\int \sec^3t\,dt$ 的结果中 $\ln|\sec t+\tan t|$ 的绝对值不可遗漏。双曲换元时 $\cosh t>0$ 可省略绝对值。分部积分法中，$\int \frac{dx}{\sqrt{1+x^2}}$ 的结果是 $\ln(x+\sqrt{1+x^2})$，不要误写为 $\arcsin x$ 等。最终结果需加上常数 $C$。

**命题规律**:  
这两个积分是考研数学一中的高频考点，属于基础但重要的不定积分。它们常直接出现在计算题中，或作为复杂积分的一部分。考生需熟练掌握分部积分法处理“指数×三角”类型，以及利用三角换元（或双曲换元、分部积分）处理含 $\sqrt{x^2+a^2}$ 的积分。常见变式包括 $\int e^{ax}\sin bx\,dx$、$\int \sqrt{a^2+x^2}\,dx$、$\int \sqrt{x^2-a^2}\,dx$ 等。复习建议：强化分部积分的“循环法”和换元法，熟记常见积分公式，如 $\int \sec^3t\,dt$ 的结果、$\int \frac{dx}{\sqrt{x^2+a^2}} = \ln\!\bigl(x+\sqrt{x^2+a^2}\bigr)+C$，以及 $\int \sqrt{x^2+a^2}\,dx$ 的公式。同时注意三角换元时灵活选择三角函数或双曲函数，以简化计算。

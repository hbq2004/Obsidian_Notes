# FIB 第 20 题

![[_Attachments/题目识别/27_张宇36讲-题目/L08-Q20_题目.png|题目]]

函数 $f(x)=\begin{cases} \sqrt{1+x^2}, & x \leqslant 0, \\ (x+1)\cos x, & x > 0 \end{cases}$ 的一个原函数为( )

(A) $F(x)=\begin{cases} \ln(\sqrt{1+x^2}-x), & x \leqslant 0, \\ (x+1)\cos x - \sin x, & x > 0 \end{cases}$
(B) $F(x)=\begin{cases} \ln(\sqrt{1+x^2}-x)+1, & x \leqslant 0, \\ (x+1)\cos x - \sin x, & x > 0 \end{cases}$
(C) $F(x)=\begin{cases} \ln(\sqrt{1+x^2}+x), & x \leqslant 0, \\ (x+1)\sin x + \cos x, & x > 0 \end{cases}$
(D) $F(x)=\begin{cases} \ln(\sqrt{1+x^2}+x)+1, & x \leqslant 0, \\ (x+1)\sin x + \cos x, & x > 0 \end{cases}$

---

## 答案

![[_Attachments/题目识别/27_张宇36讲-答案/L08-Q20_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**: D

**解题切入点**: 首先判断分段函数在分段点处的连续性，确定原函数存在的条件；然后分别求两个区间的不定积分，注意原函数在分段点处必须连续，从而确定常数。本题中，选项中的 $x\leq0$ 部分求导后均为 $\frac{1}{\sqrt{1+x^2}}$，故 $f(x)$ 在 $x\leq0$ 时实际应为 $\frac{1}{\sqrt{1+x^2}}$（否则无正确选项），因此以下按此求解。

**推演**: 设 $f(x)=\begin{cases} \frac{1}{\sqrt{1+x^2}}, & x \leqslant 0, \\ (x+1)\cos x, & x > 0 \end{cases}$，求 $f(x)$ 的一个原函数 $F(x)$。

当 $x \leqslant 0$ 时，$\int \frac{1}{\sqrt{1+x^2}} dx = \ln(x+\sqrt{1+x^2}) + C_1$，故可设 $F(x)=\ln(x+\sqrt{1+x^2}) + C_1$，$x \leqslant 0$。
当 $x > 0$ 时，$\int (x+1)\cos x dx = (x+1)\sin x + \cos x + C_2$，故可设 $F(x)=(x+1)\sin x + \cos x + C_2$，$x > 0$。

由于原函数必须可导，从而必连续，故 $F(x)$ 在 $x=0$ 处连续。计算：
$\lim_{x \to 0^-} F(x) = \lim_{x \to 0^-} [\ln(x+\sqrt{1+x^2}) + C_1] = \ln(0+1) + C_1 = C_1$，
$\lim_{x \to 0^+} F(x) = \lim_{x \to 0^+} [(x+1)\sin x + \cos x + C_2] = (0+1)\cdot 0 + 1 + C_2 = 1 + C_2$，
由连续性得 $C_1 = 1 + C_2$，即 $C_1 = C_2 + 1$。

取 $C_2 = 0$，则 $C_1 = 1$，得 $F(x)=\begin{cases} \ln(x+\sqrt{1+x^2})+1, & x \leqslant 0, \\ (x+1)\sin x + \cos x, & x > 0 \end{cases}$，此即选项 (D)。（注意：$\ln(x+\sqrt{1+x^2})$ 与 $\ln(\sqrt{1+x^2}+x)$ 相同。）

也可验证 $F'(x)=f(x)$ 且 $F(x)$ 在 $x=0$ 处可导。

**易错点**: 1. 求不定积分时忘记加常数；2. 忽略原函数在分段点处的连续性，导致常数选择错误；3. 误将 $f(x)$ 在 $x\leq0$ 时当作 $\sqrt{1+x^2}$ 而找不到正确选项。

**命题规律**: 本题主要考查分段函数原函数的求法，关键在于利用原函数的连续性确定积分常数。常见变式包括改变分段函数表达式或增加参数，复习时应重点掌握基本积分公式和连续性的应用。

# FIB 第 2 题

![[_Attachments/题目识别/27_张宇36讲-题目/L13-Q02_题目.png|题目]]

$\int_{0}^{\frac{\pi}{6}} dy \int_{y}^{\frac{\pi}{6}} \frac{\cos x}{x} dx = \_\_\_\_.$

---

## 答案

![[_Attachments/题目识别/27_张宇36讲-答案/L13-Q02_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**: $\frac{1}{2}$

**解题切入点**: 题目直接计算 $\int \frac{\cos x}{x} dx$ 不是初等函数（余弦积分），因此考虑交换积分次序。观察积分区域，将其用另一种顺序描述，可以先对 $y$ 积分，从而消去分母中的 $x$，转化为简单积分。

**推演**: 原积分 $I = \int_{0}^{\frac{\pi}{6}} dy \int_{y}^{\frac{\pi}{6}} \frac{\cos x}{x} dx$ 的积分区域为  
$$D = \left\{ (x,y) \,\middle|\, 0 \le y \le \frac{\pi}{6},\, y \le x \le \frac{\pi}{6} \right\}.$$  
该区域也可表示为  
$$D = \left\{ (x,y) \,\middle|\, 0 \le x \le \frac{\pi}{6},\, 0 \le y \le x \right\}.$$  
交换积分次序得  
$$I = \int_{0}^{\frac{\pi}{6}} dx \int_{0}^{x} \frac{\cos x}{x} dy.$$  
内层积分 $\int_{0}^{x} \frac{\cos x}{x} dy = \frac{\cos x}{x} \cdot (x-0) = \cos x$，故  
$$I = \int_{0}^{\frac{\pi}{6}} \cos x \, dx = \sin x \Big|_{0}^{\frac{\pi}{6}} = \frac{1}{2}.$$

**易错点**:  
1. 交换次序时容易将上下限写反，需通过画图明确区域边界。  
2. 注意被积函数在 $x=0$ 处有奇点，但积分区域在原点附近为尖点，二重积分收敛，且交换次序后得到普通积分，结果合理。若直接考虑先对 $x$ 积分，在 $y=0$ 时内层积分发散，但外层积分仍可收敛，需谨慎处理反常性。  
3. 计算内层积分后不要忘记外层积分变量 $x$ 的范围，并正确求出 $\sin \frac{\pi}{6}$ 的值。

**命题规律**: 本题是典型的“交换积分次序”题型，常出现在填空或选择中，考查对二重积分区域的理解和变量次序的灵活转换。变式包括：被积函数为 $\frac{\sin x}{x}$、$\frac{e^{x}}{x}$ 等，或积分区域为其他形状（如 $y$ 从 $x^2$ 到 $x$ 等）。复习时应熟练掌握用不等式描述区域并交换次序的方法，以及利用先积 $y$ 消去分母的技巧。

# FIB 第 3 题

![[_Attachments/题目识别/27_张宇36讲-题目/L19-Q03_题目.png|题目]]

已知3阶方阵$A$的特征值为$-1,2,3$，则$A_{11}+A_{22}+A_{33}=$\_.

设$A=(a_{ij})$为3阶矩阵，$A_{ij}$为元素$a_{ij}$的代数余子式.若$A^{-1}$的每行元素之和均为2，且$|A|$。

---

## 答案

![[_Attachments/题目识别/27_张宇36讲-答案/L19-Q03_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**:  
第一问填 \(\boxed{1}\)。  
题干第二句“且 \(|A|\)。”信息不完整；若它单独成题，需补全条件后才能确定。以下按第一问完整小题作答。

**解题切入点**:  
看到 \(A_{11}+A_{22}+A_{33}\)，应立刻联想到伴随矩阵 \(A^*\) 的迹：
\[
A_{11}+A_{22}+A_{33}=\operatorname{tr}(A^*).
\]
题目又给的是特征值，所以关键是把“特征值”转化为“伴随矩阵的特征值”，用公式
\[
A^*=|A|A^{-1}
\]
建立桥梁。

**推演**:  
设 3 阶方阵 \(A\) 的特征值为
\[
\lambda_1=-1,\quad \lambda_2=2,\quad \lambda_3=3.
\]
则
\[
|A|=\lambda_1\lambda_2\lambda_3=-6\neq 0,
\]
所以 \(A\) 可逆，且有
\[
A^*=|A|A^{-1}.
\]

若 \(\lambda\) 是 \(A\) 的特征值，则 \(|A|/\lambda\) 是 \(A^*\) 的特征值。因此 \(A^*\) 的特征值为
\[
\frac{-6}{-1}=6,\qquad \frac{-6}{2}=-3,\qquad \frac{-6}{3}=-2.
\]

于是
\[
A_{11}+A_{22}+A_{33}
=\operatorname{tr}(A^*)
=6+(-3)+(-2)=1.
\]

也可用特征多项式验证：
\[
\det(tI-A)=(t+1)(t-2)(t-3)
=t^3-4t^2+t+6,
\]
其中 \(t\) 的系数正是 \(A_{11}+A_{22}+A_{33}\)，所以结果为 \(1\)。

补充：若第二句想问“\(A^{-1}\) 的每行元素之和均为 \(2\)”等问题，应写成
\[
A^{-1}\mathbf e=2\mathbf e,\qquad \mathbf e=(1,1,1)^T,
\]
即 \(\mathbf e\) 是 \(A^{-1}\) 的特征向量；但仅凭该条件无法唯一确定 \(\operatorname{tr}(A^*)\)。

**易错点**:  
1. 不要把 \(A_{11}+A_{22}+A_{33}\) 当成 \(A\) 的迹：
   \[
   A_{11}+A_{22}+A_{33}=\operatorname{tr}(A^*),
   \]
   而不是 \(\operatorname{tr}A=-1+2+3=4\)。  
2. 用特征多项式时，注意符号：
   \[
   \det(tI-A)
   \]
   的一次项系数才是 \(A_{11}+A_{22}+A_{33}\)；若用 \(\det(A-tI)\) 要小心符号。  
3. 若 \(A\) 不可逆，不能直接写 \(A^*=|A|A^{-1}\)；本题 \(|A|=-6\neq0\)，可以放心使用。  
4. “每行元素之和为 \(2\)”是 \(M\mathbf e=2\mathbf e\)，不是 \(\operatorname{tr}M=6\)，两者不要混淆。

**命题规律**:  
这是线性代数中“特征值 + 伴随矩阵 + 代数余子式”的经典综合考点，常以填空题出现。  
常见变式有：  
- 已知特征值求 \(|A|\)、\(\operatorname{tr}(A^*)\)、\(|A+2I|\) 等；  
- 已知 \(A^{-1}\) 的行和条件，转成 \(A^* \mathbf e=2|A|\mathbf e\)；  
- 用特征多项式系数求代数余子式之和。  

复习建议：把
\[
A^*=|A|A^{-1},\qquad \operatorname{tr}(A^*)=\sum_i\prod_{j\ne i}\lambda_j
\]
以及“行和条件就是特征向量条件”这几个要点记牢，这类题就能快速解决。

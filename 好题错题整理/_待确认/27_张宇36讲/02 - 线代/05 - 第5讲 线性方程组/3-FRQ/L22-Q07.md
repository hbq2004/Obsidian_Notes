# FRQ 第 7 题

![[_Attachments/题目识别/27_张宇36讲-题目/L22-Q07_题目.png|题目]]

设矩阵 $A=\begin{bmatrix}a&3&-4\\b&5&-7\end{bmatrix}$，若方程组 $A^2x=0$ 与 $Ax=0$ 不同解，则 $a-b=\_$．

设矩阵 $A=\begin{bmatrix}1&-1&0&-1\\1&1&0&2\end{bmatrix}$，$B=\begin{bmatrix}1&0&1&2\\1&1&a&a-1\end{bmatrix}$，向量 $\alpha=\begin{bmatrix}0\\2\end{bmatrix}$，$\beta=\begin{bmatrix}1\\0\end{bmatrix}$．

## DeepSeek V4 Flash Max 解析

**答案**  
按题面字面，此题不能确定 \(a-b\)：第一题 \(A\) 是 \(2\times 3\) 矩阵，\(A^2\) 无定义，因此 \(A^2x=0\) 不构成合法方程组；第二题只给出了矩阵和向量，没有给出待求问题，也无法作答。

若第一题原意是漏写了第三行，常见补全版本为  
\[
A=\begin{bmatrix}
a&3&-4\\
b&5&-7\\
0&0&1
\end{bmatrix},
\]
则答案为  
\[
\boxed{a-b=\frac{10}{3}}.
\]

**解题切入点**  
拿到线性代数题先做“维度检查”：\(A^2\) 要求 \(A\) 是方阵，否则矩阵乘法不合法。这就像算法题先检查数组维度，`shape` 不对就不能直接做矩阵乘法。

若 \(A\) 确为方阵，则注意：
\[
Ax=0\Rightarrow A^2x=A(Ax)=0,
\]
所以
\[
N(A)\subseteq N(A^2).
\]
题目说“不同解”，即
\[
N(A^2)\neq N(A),
\]
等价于
\[
\dim N(A^2)>\dim N(A),
\]
由秩-零化度定理即
\[
\operatorname{rank}(A^2)<\operatorname{rank}(A).
\]

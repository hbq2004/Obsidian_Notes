# MCQ 第 4 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C02-S03-Q004_题目.png|题目]]

4. 一个正在访问临界资源的进程由于申请等待 $I/O$ 操作而被中断时,它 ( )
(A) 允许其他进程进入与该进程相关的临界区
(B) 不允许其他进程进入任何临界区
(C) 允许其他进程抢占处理器,但不得进入该进程的临界区
(D) 不允许任何进程抢占处理器

## DeepSeek V4 Flash Max 解析
**答案**：  
C  

**解题切入点**：  
从临界区互斥性质出发，分析进程在临界区内因等待 $I/O$ 被阻塞时是否释放了临界资源，进而判断其他进程能否进入该临界区或能否抢占处理器。  

**推演**：  
进程正在访问临界资源，即已进入临界区，此时它持有该资源的互斥锁。若因申请 $I/O$ 而中断（阻塞），则它让出 CPU，但并未释放临界资源（锁仍被持有）。因此，其他进程若试图进入同一临界区，将因无法获得锁而被阻塞，但可以抢占 CPU 执行其他无关代码，也可以进入其他不相关的临界区。故选项 C 正确，A、B、D 均错误。  

**易错点**：  
1. 误认为进程被中断后释放了 CPU 即意味着释放了临界资源，从而允许其他进程进入临界区（混淆了 CPU 与资源）。  
2. 将“不允许其他进程进入任何临界区”绝对化，忽略了不相关临界区的独立性。  

**命题规律**：  
本题属于操作系统进程同步与互斥的基础题，常以选择题形式考查临界区、互斥、进程状态转换等概念。解题关键是将“临界资源”类比为算法竞赛中的“互斥锁 ($mutex$)”：持有锁的线程因等待 $I/O$ 而阻塞时，锁并未释放，其他线程仍无法进入临界区，但可以继续执行其他任务。

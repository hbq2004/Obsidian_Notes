# MCQ 第 7 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C03-S02-Q007_题目.png|题目]]

为使虚存系统有效地发挥其预期的作用,所运行的程序应具有的特性是( ).
(A) 该程序不应含有过多的 $I/O$ 操作
(B) 该程序的大小不应超过实际的内存容量
(C) 该程序应具有较好的局部性
(D) 该程序的指令相关性不应过多

## DeepSeek V4 Flash Max 解析
**答案**：  
C  

**解题切入点**：  
虚存系统依赖程序访问的局部性原理，这类似于算法竞赛中利用数据结构优化查询时只需访问必要数据，而非全部加载；或像在构造题中通过局部信息剪枝，避免全局搜索。因此，要使虚存有效发挥预期作用，程序应具有较好的局部性（选项 C）。  

**推演**：  
- 虚存通过“按需调页”（demand paging）和页面置换，在逻辑上提供大于物理内存的地址空间，其高效运行的关键是程序访问的局部性。时间局部性使最近访问的页面可能再次被访问，空间局部性使相邻页面也可能被访问，从而降低缺页率。  
- 类比算法竞赛：在 DFS 状态搜索中，状态转移往往集中在当前状态附近（类似时间局部性），而预先加载相邻状态（类似空间局部性）可减少重复搜索开销。  
- 选项 A：I/O 操作过多会阻塞进程，但虚存本身不限制 I/O，且 I/O 通常使用 DMA，不影响内存管理。  
- 选项 B：虚存的设计初衷正是允许程序大小超过物理内存，故无需限制。  
- 选项 D：指令相关性影响 CPU 流水线，与虚存无直接关联。  

**易错点**：  
- 误选 A：认为 I/O 操作多会降低系统效率，但虚存有效性的关键在于内存访问模式，而非 I/O 频率。  
- 误选 B：混淆虚存与实存的概念，虚存正是为了突破物理内存容量限制而设计的，程序大小超过实际内存时仍可有效运行，只要局部性良好。  
- 选项 D：属于计算机体系结构范畴，与虚存无关。  

**命题规律**：  
- 本题出自“虚拟存储器”章节，核心考查局部性原理在虚存中的作用。  
- 常见变体包括：判断哪些程序特性有利于虚存、分析局部性对缺页率的影响等。  
- 在算法竞赛中，局部性思想常体现为数组遍历顺序优化（如行优先 vs 列优先）以利用缓存，这与虚存中空间局部性对页面调度的优化本质相通。

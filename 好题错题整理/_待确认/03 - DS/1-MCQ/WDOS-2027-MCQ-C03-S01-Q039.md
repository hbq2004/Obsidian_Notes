# MCQ 第 39 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C03-S01-Q039_题目.png|题目]]

某个操作系统对内存的管理采用页式存储管理方法,所划分的页面大小（ ）
(A) 要根据内存大小确定
(B) 必须相同
(C) 要根据 CPU 的地址结构确定
(D) 要依据外存和内存的大小确定

## DeepSeek V4 Flash Max 解析
**答案**：  
B. 必须相同  

**解题切入点**：  
页式存储管理的本质是固定划分，类似算法竞赛中你将数组按固定大小分块处理（如分块算法）。页面大小必须一致，否则地址转换时无法通过简单的位运算（如 $ \text{页号} = \lfloor \text{逻辑地址} / \text{页大小} \rfloor $）直接定位，这相当于破坏了状态机中每个状态的一致性，导致映射关系混乱。

**推演**：  
页式存储管理将逻辑地址空间和物理内存都划分为等长块，页面大小固定为 $2^k$ 字节（$k$ 由硬件决定）。  
- 选项 B 正确：所有页面大小必须相同，这是页式管理的基本前提，否则页表无法统一索引，就如同 DFS 中每个状态必须有相同的结构才能进行状态转移。  
- 选项 A 错误：页面大小与内存总大小无关，内存更大只会增加页框数量，不会改变页面大小（类比图论中节点数增多但边的容量单位不变）。  
- 选项 C 错误：页面大小虽由 CPU 地址结构（如逻辑地址位数）决定，但题目问的是“所划分的页面大小”的约束，而非设计依据，且“必须相同”才是核心要求。  
- 选项 D 错误：外存（交换区）大小不影响页面大小，页面大小固定后，外存按同样大小划分块用于换入换出。  

综上，页式存储管理规定页面大小必须相同，这是系统能高效运行的基础。

**易错点**：  
1. 混淆“页面大小由什么决定”与“页面大小是否必须相同”，误选 C。实际上，页面大小由硬件设计时确定，但一旦确定，所有页面大小必须严格一致。  
2. 错误认为页面大小需根据内存大小调整，但内存容量变化只影响页框数量，不改变页面大小（如同 ICPC 中数组长度可变但元素尺寸固定）。  
3. 忽略“必须相同”是页式管理区别于段式管理的本质特征，段式管理允许段长不同，而页式要求所有页等长。

**命题规律**：  
408 操作系统常考查页式存储管理的基本概念，重点在于“固定分页”与“地址变换”的关联。此类题目常以选择题出现，干扰项多围绕“页面大小的影响因素”设误，但核心是“必须相同”这一关键特性。复习时应类比算法竞赛中的分块思想：固定块大小简化了映射计算，是系统设计中的“状态统一”原则。

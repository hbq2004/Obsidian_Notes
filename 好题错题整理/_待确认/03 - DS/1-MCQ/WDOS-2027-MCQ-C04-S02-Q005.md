# MCQ 第 5 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C04-S02-Q005_题目.png|题目]]

5. 下列选项中，( ) 不是为了提升文件系统性能的操作.
(A) $目录项分解$
(B) $文件高速缓存$
(C) $磁盘调度算法$
(D) $异步 I/O$

## DeepSeek V4 Flash Max 解析
**答案**：D

**解题切入点**：区分文件系统性能优化技术与 I/O 控制方式。文件系统性能优化主要关注减少磁盘访问时间、提高数据访问效率，而异步 I/O 是为了提高 CPU 利用率，并非直接提升文件系统性能。

**推演**：分析各选项的主要目的：
- 目录项分解（A）将目录项拆分为更细粒度的结构（如 B 树），加速目录查找，直接提升文件系统性能。
- 文件高速缓存（B）利用内存缓存文件数据，减少磁盘 I/O，提升文件系统性能。
- 磁盘调度算法（C）优化磁盘请求顺序，减少寻道时间，提升磁盘 I/O 性能，从而提升文件系统性能。
- 异步 I/O（D）允许进程发起 I/O 后立即返回，在 I/O 完成前继续执行，提高 CPU 利用率，但并未缩短磁盘访问时间或提升文件系统本身的性能，其主要目的是提升系统整体吞吐量，而非专门优化文件系统性能。

因此，D 选项不是为了提升文件系统性能的操作。

**易错点**：容易误认为磁盘调度算法属于磁盘管理而非文件系统，但磁盘调度减少寻道时间，直接改善文件系统底层的 I/O 性能，故属于文件系统性能优化措施；异步 I/O 常被误认为提升文件系统 I/O 性能，但它本质是 I/O 控制方式，侧重 CPU 与 I/O 并行，并不减少磁盘读写时间。

**命题规律**：考查对文件系统性能优化具体措施的理解，要求区分“文件系统性能”与“系统整体性能”的边界。常以选择题形式出现，可能与其他模块（如 I/O 管理）的概念混淆，需要准确记忆各技术的主要目的。

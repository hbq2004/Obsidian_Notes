# MCQ 第 42 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C05-S02-Q042_题目.png|题目]]

下列关于 SPOOLing 技术的叙述中,错误的是( ).
(A) 需要外存的支持
(B) 需要多道程序设计技术的支持
(C) 可以让多个作业共享一台独占式设备
(D) 由用户作业控制设备与输入 / 输出井之间的数据传送

## DeepSeek V4 Flash Max 解析
**答案**：
$\boxed{\text{D}}$。$\text{SPOOLing}$ 系统中，设备与输入/输出井之间的数据传送由预输入/缓输出进程控制，不由用户作业控制；用户作业只负责提交数据或发起 I/O 请求。

**解题切入点**：
可以把 $\text{SPOOLing}$ 类比为 OJ 的评测队列：外设是唯一评测机，磁盘上的井是评测队列，后台 $\text{SPOOLing}$ 进程是评测调度器，用户作业是提交代码的选手。选手不能直接控制评测机和队列之间的数据搬运，否则多个提交会互相抢占。四个选项中只有 D 把控制主体说反了。

**推演**：
- A 正确：输入井和输出井建在磁盘上，需要外存支持；没有外存就没有暂存数据的“井”。
- B 正确：预输入/缓输出进程必须与用户作业并发执行，需要多道程序设计技术支持；否则无法一边运行作业，一边完成输入/输出。
- C 正确：多个作业把输出先写到输出井，再由缓输出进程排队打印，因此一台物理上独占的打印机在逻辑上可以被多个作业共享。这类似于多线程通过任务队列共享一个工作线程，而不是每个线程直接抢占硬件。
- D 错误：设备与井之间的数据传送由 $\text{SPOOLing}$ 系统控制，而不是用户作业。用户作业只做“提交”，底层“搬运”由后台进程完成；若让用户作业控制，就等价于让生产者直接操纵共享队列的消费端，必然导致资源竞争和不一致。

**易错点**：
- 易把 C 判错：独占设备的“独占”是物理属性，但 $\text{SPOOLing}$ 通过排队共享实现了逻辑共享。
- 易把 A 漏掉：只用内存缓冲不够，输入井/输出井是磁盘存储区。
- 易把 B 误以为可有可无：没有多道程序设计，后台进程无法与用户作业并发，$\text{SPOOLing}$ 就失去意义。
- D 的陷阱在于“用户作业发起 I/O 请求”容易被误认为“用户作业控制传送”。实际上控制者是操作系统中的 $\text{SPOOLing}$ 进程，不是用户作业。

**命题规律**：
408 中 $\text{SPOOLing}$ 常以选择题考查，重点是它的成立条件、作用和控制主体。命题人喜欢把“由系统控制”偷换成“由用户作业控制”，或把“独占设备变共享设备”说反。复习时抓住一个模型：外存井 + 后台进程 + 多道程序并发 = 虚拟共享设备。看到“用户作业直接控制底层 I/O”基本可以判定错误。

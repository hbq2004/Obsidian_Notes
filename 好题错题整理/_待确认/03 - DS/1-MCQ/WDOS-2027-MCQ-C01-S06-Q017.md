# MCQ 第 17 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C01-S06-Q017_题目.png|题目]]

17. 下列关于 VMware Workstation 虚拟机的说法中,错误的是( ).

(A) 真实硬件不会直接执行虚拟机中的敏感指令

(B) 虚拟机中只能安装一种操作系统

(C) 虚拟机是运行在计算机中的一个应用程序

(D) 虚拟机文件封装在一个文件夹中,并存储在数据存储器中

## DeepSeek V4 Flash Max 解析
**答案**：B  

**解题切入点**：  
本题考察 VMware Workstation（类型 2 虚拟化）的核心特性，可类比算法竞赛中的 **构造题**——需在宿主系统上构造一个“虚拟执行环境”，让 Guest OS 以为自己独占硬件。关键理解：  
- 虚拟机是 Host OS 上的一个普通进程（应用程序），其敏感指令必须通过 VMM（虚拟机监视器）模拟，不会直接由真实硬件执行。  
- 每个虚拟机实例通常只运行一个操作系统，但技术上可以像物理机一样安装多个（如分区 + 引导管理器），故“只能安装一种”过于绝对。  
- 虚拟机文件封装在独立文件夹中，便于迁移与备份。  

**推演**：  
- 选项 A：虚拟机运行在非特权模式，敏感指令触发陷阱（类似算法中“异常处理”），由 VMM 截获并模拟，真实硬件并不直接执行。正确。  
- 选项 B：虚拟机相当于一台模拟的物理机，支持多系统安装（如双启动），尽管实际使用中通常只装一个，但“只能安装一种”技术上是错误的。  
- 选项 C：类型 2 虚拟化中，VMM（如 VMware Workstation）是 Host OS 上的应用程序，每个虚拟机是 VMM 创建的一个进程，故称“运行在计算机中的一个应用程序”合理。正确。  
- 选项 D：VMware 将虚拟机配置文件、磁盘文件等封装在一个文件夹中（类似算法竞赛中“将代码、输入数据打包”），存储于数据存储器。正确。  

**易错点**：  
混淆“虚拟机中只能安装一种操作系统”与“每个虚拟机通常只运行一种操作系统”——前者是技术限制（不存在），后者是使用习惯（类似算法中“某状态机通常只加载一种配置，但实际可加载多种”）。此外，可能误认为选项 C 中“应用程序”指虚拟机本身，实际上 VMM 才是应用程序，但虚拟机实例以进程形式存在，故可视为应用程序的一部分。  

**命题规律**：  
常以 VMware Workstation 为例考查类型 2 虚拟化特点：敏感指令处理、虚拟机文件结构、虚拟机与 VMM 的关系。后续可能结合硬件虚拟化（如 VT-x）或容器技术对比，类似算法题中“基础知识点对比”的命题风格。

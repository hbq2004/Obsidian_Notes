# MCQ 第 38 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C05-S02-Q038_题目.png|题目]]

某文件占 10 个磁盘块，现要把该文件的磁盘块逐个读入主存缓冲区，并且送到用户区进行分析，假设一个缓冲区与一个磁盘块大小相同，把一个磁盘块读入缓冲区的时间为 $100 \mu s$，将缓冲区的数据传送到用户区的时间是 $50 \mu s$，CPU 对一块数据进行分析的时间为 $50 \mu s$。在单缓冲区和双缓冲区结构下，读入并分析完该文件的时间分别是（ ）.
(A) $1500 \mu s, 1000 \mu s$
(B) $1550 \mu s, 1100 \mu s$
(C) $1550 \mu s, 1550 \mu s$
(D) $2000 \mu s, 2000 \mu s$

## DeepSeek V4 Flash Max 解析
**答案**：B（$1550 \mu s, 1100 \mu s$）

**解题切入点**：单/双缓冲的本质是 I/O 与 CPU 的流水线并行，类似于算法竞赛中“流水线调度”问题，需要分析各阶段（读入、传送、分析）的依赖关系与资源约束。单缓冲只有一个缓冲区，读入和传送不能同时进行，但读入与分析可以重叠；双缓冲有两个缓冲区，允许读入和传送同时进行，从而进一步隐藏读入时间。将问题建模为状态机，通过时间线推演即可得到总时间。

**推演**：设 $T_{\text{in}}=100\mu s$，$T_{\text{trans}}=50\mu s$，$T_{\text{cpu}}=50\mu s$，共 $n=10$ 块。

- **单缓冲**：资源约束：缓冲区唯一，故 $R_i$（读入）与 $T_i$（传送）互斥，$T_i$ 与 $C_i$（分析）互斥（争夺用户区），但 $R_i$ 可与 $C_{i-1}$ 重叠。时间线：
  - 第1块：$R_1=100$, $T_1=50$, $C_1=50$，完成于 $200\mu s$。
  - 第2块：$R_2$ 在 $C_1$ 开始（$150\mu s$）时启动，$R_2=100$ 至 $250\mu s$；$C_1$ 结束于 $200\mu s$，故 $T_2$ 从 $250$ 开始，$T_2=50$ 至 $300$，$C_2=50$ 至 $350$。
  - 后续每块重复此模式，每个新块使总时间增加 $150\mu s$（即 $T_{\text{in}}+T_{\text{trans}}$）。故总时间 $=200 + (n-1)\times150 = 200 + 1350 = 1550\mu s$。
  - 一般公式：$T_{\text{single}} = (T_{\text{in}}+T_{\text{trans}})\times n + T_{\text{cpu}}$（当 $T_{\text{cpu}} < T_{\text{in}}+T_{\text{trans}}$ 时成立）。

- **双缓冲**：两个缓冲区，允许 $R_i$ 与 $T_{i-1}$ 同时进行，且 $R_i$ 仍可与 $C_{i-1}$ 重叠，但 $T_i$ 与 $C_i$ 仍不能重叠。时间线：
  - 第1块：$R_1=100$ (0-100)，$T_1=50$ (100-150)，$C_1=50$ (150-200)。
  - 第2块：$R_2$ 在 $100\mu s$ 即与 $T_1$ 同时开始，至 $200\mu s$；$C_1$ 结束于 $200$，故 $T_2$ 从 $200$ 开始，$T_2=50$ 至 $250$，$C_2=50$ 至 $300$。
  - 后续每块：$R_i$ 与 $T_{i-1}$ 同时开始，$C_{i-1}$ 与 $R_i$ 重叠，每块分析结束时间较前一块增加 $100\mu s$（即 $T_{\text{in}}$）。故总时间 $=200 + (n-1)\times100 = 200 + 900 = 1100\mu s$。
  - 一般公式：$T_{\text{double}} = T_{\text{in}}\times n + T_{\text{trans}} + T_{\text{cpu}}$（当 $T_{\text{cpu}} < T_{\text{in}}$ 时成立，此处 $T_{\text{cpu}}=50 < 100$）。

综上，单缓冲 $1550\mu s$，双缓冲 $1100\mu s$，对应选项 B。

**易错点**：1. 误认为单缓冲下所有操作完全串行，得到 $2000\mu s$（选项 D）；2. 误认为双缓冲下传送与分析也可重叠，得到 $1000\mu s$（选项 A 的双缓冲部分）；3. 混淆单缓冲与双缓冲公式，导致两者相同（选项 C）。关键在于理解资源冲突：单缓冲中读入与传送互斥，双缓冲中读入与传送可并行，但传送与分析通常仍不能并行（因用户区冲突）。

**命题规律**：I/O 缓冲技术是操作系统常考知识点，常以计算题形式出现，重点考查流水线并行与时间重叠。解题时需画出时间线，明确各阶段依赖关系，类似于算法竞赛中“流水线调度”或“生产者-消费者”模型。掌握 $T_{\text{single}} = (T_{\text{in}}+T_{\text{trans}})\times n + T_{\text{cpu}}$ 和 $T_{\text{double}} = T_{\text{in}}\times n + T_{\text{trans}} + T_{\text{cpu}}$ 的公式适用条件（$T_{\text{cpu}} \le T_{\text{in}}$ 时），可快速求解。注意当 $T_{\text{cpu}} > T_{\text{in}}$ 时公式会变为 $T_{\text{single}} = T_{\text{cpu}}\times n + T_{\text{in}} + T_{\text{trans}}$ 等，需灵活分析。

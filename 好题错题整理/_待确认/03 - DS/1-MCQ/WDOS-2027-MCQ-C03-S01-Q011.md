# MCQ 第 11 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C03-S01-Q011_题目.png|题目]]

动态重定位的过程依赖于(\\_\\_).
(A) $I$和$II$
(B) $II$和$III$
(C) $I$、$II$和$III$
(D) $I$、$II$、$III$和$IV$

## DeepSeek V4 Flash Max 解析
**答案**：  
选 **C**（Ⅰ、Ⅱ、Ⅲ）。

**解题切入点**：  
动态重定位是“逻辑地址到物理地址的运行时映射”，可类比为竞赛中“维护一个全局偏移量 $base$，每次访问连续数组都用 $base + idx$ 计算真实下标”。它需要三个事实成立：

- 硬件知道当前进程的基址，即需要重定位寄存器；
- 每次访存时硬件都要做地址运算，即需要地址变换机构；
- 因为只用了一个基址，所以进程的地址空间必须连续，即装入时要分配连续存储区域。

而“程序执行时分配连续的存储空间”不是地址变换过程本身的必要条件，它混淆了“重定位”与“内存分配时机”。

**推演**：  
设逻辑地址为 $LA$，重定位寄存器中的基址为 $B$，则动态重定位的地址变换为

$$PA = B + LA.$$

若还有界限寄存器 $L$，则还要检查 $0 \le LA < L$，否则产生越界中断。

由此可知：

1. 必须用重定位寄存器保存 $B$，否则 CPU 不知道进程在物理内存中的起始位置；
2. $B + LA$ 的运算与越界检查必须在访存时完成，因此依赖地址变换机构；
3. 一个进程只有一个 $B$，相当于把整个逻辑地址空间看作以 $B$ 为起点的连续“数组”，所以装入时必须在物理内存中分配连续的存储区域；
4. 若进程在运行中被移动，只需把重定位寄存器改成新的 $B'$，不需要重新分配连续空间，更不是每条指令执行时都要分配内存，所以“程序执行时分配连续的存储空间”不选。

因此排除 Ⅳ，答案为 C。

**易错点**：  
- 把“动态”理解为“执行时分配内存”。动态重定位的“动态”是指地址变换发生在运行期，而不是分配动作发生在运行期。
- 忽略连续存储条件。只有一个重定位寄存器，无法覆盖不连续的物理块；若用分页/分段，则需要页表/段表等额外映射结构。
- 混淆“重定位寄存器”和“地址变换机构”。寄存器只保存基址，变换机构负责加法运算和越界检查，两者是硬件协同关系。
- 与静态重定位对比：静态重定位在装入时直接修改指令中的地址，不需要重定位寄存器，但程序移动后不能自适应；动态重定位则是“程序中的地址不动，只更新重定位寄存器”。

**命题规律**：  
- 408 常用“Ⅰ/Ⅱ/Ⅲ/Ⅳ”组合题考查概念边界，本题典型陷阱是“多选执行时分配”或“漏选连续分配”。
- 这类题像算法竞赛中的状态机题：每次访存是一次状态转移，重定位寄存器是全局状态，地址变换机构是转移函数；只要把状态设计想清楚，边界条件就不会漏。
- 后续相关考点可对比记忆：紧凑技术必须依赖动态重定位；分段/分页的地址转换是“多基址/查表”的推广。一个 $base$ 只能管一段连续数组，多个映射项才能管离散块。

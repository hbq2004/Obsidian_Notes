# MCQ 第 12 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C01-S03-Q012_题目.png|题目]]

12. 下列中断事件中,能引起外部中断的事件是（ ）

I.时钟中断 II.访管中断 III.缺页中断

(A) $I$

(B) $III$

(C) $I$ 和 $II$

(D) $II$ 和 $III$

## DeepSeek V4 Flash Max 解析
**答案**：
选 **A**（仅 $I$，时钟中断）。

**解题切入点**：
题目问的是“外部中断”，不是广义的“中断”。在 408 中，外部中断指由 CPU 外部硬件产生的异步中断，如定时器、I/O 设备等；而访管中断、缺页中断都属于 CPU 内部产生的异常。

算法竞赛类比：外部中断像是评测系统给你发了一个定时信号，你不知道它什么时候到；访管中断像是程序主动调用系统 API 请求内核服务；缺页中断像是访问内存时发现目标页不在内存，类似查哈希表发现目标桶为空，需要先加载数据再继续执行。

**推演**：
设 $I_1$ 为时钟中断，$I_2$ 为访管中断，$I_3$ 为缺页中断。按触发来源分类：
$$
O=\{I_1\},\quad C=\{I_2,I_3\}
$$
其中 $O$ 为外部中断集合，$C$ 为内部中断/异常集合。

- $I_1$ 时钟中断：由定时器硬件在 CPU 外部产生，CPU 执行完当前指令后响应，属于外部中断。
- $I_2$ 访管中断：由访管指令主动触发，属于 trap，是内部异常；相当于状态机主动转移。
- $I_3$ 缺页中断：由当前访存指令在地址转换/页表查询过程中触发，属于 fault，是内部异常；相当于状态机在访问资源时发现资源缺失，需要先补齐再继续。

因此只有 $I_1$ 符合，答案选 A。

**易错点**：
1. 不能按名字判断：访管中断、缺页中断都带“中断”二字，但都不是外部中断。
2. 缺页中断处理时可能涉及磁盘 I/O，但触发源是 CPU 内部的访存异常，不能因此误判为外部中断。
3. 外部中断是异步的，与当前指令无关；内部异常是同步的，由当前指令本身引起。
4. 时钟中断属于外部中断，不要因为时钟也是操作系统管理的对象而误判为内部中断。

**命题规律**：
这是 408 中“中断与异常分类”的高频基础考点。命题人常把外部中断、trap、fault 混在一起出组合题，干扰项往往是“名字里带中断但不是外部中断”的项。核心还是考查分类依据：看触发源在 CPU 外部还是内部，以及事件是否与当前指令同步。后续还可能结合系统调用、用户态与内核态切换、中断响应流程一起考查。

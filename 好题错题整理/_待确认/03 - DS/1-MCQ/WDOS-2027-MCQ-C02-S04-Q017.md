# MCQ 第 17 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C02-S04-Q017_题目.png|题目]]

17. 死锁的四个必要条件中,无法破坏的是 ( )
(A) 环路等待资源
(B) 互斥使用资源
(C) 占有且等待资源
(D) 非抢夺式分配

## DeepSeek V4 Flash Max 解析
**答案**：  
B（互斥使用资源）

**解题切入点**：  
死锁预防的本质是“破坏四条件之一”，但需区分哪些条件在现实系统中具有不可消除的硬件或资源特性。类比算法竞赛中的“构造题”：破坏某些条件相当于修改题目约束，但互斥性如同“必须使用互斥锁访问共享变量”一样，无法绕过（除非资源本身可共享，如只读文件）。

**推演**：  
- 死锁四条件：互斥、占有且等待、非抢占、循环等待。  
- 破坏方式：  
  - 循环等待 → 资源有序分配（类似图论中消除环，如拓扑排序）。  
  - 占有且等待 → 一次性申请所有资源（类似“打包”变量，避免中间状态）。  
  - 非抢占 → 允许抢占（类似“状态机”中强制跳转，但需保存上下文）。  
  - 互斥 → 无法被普遍破坏，因为许多资源（如打印机、临界区）天生只能互斥访问；若强行共享，则资源逻辑失效（如“打印机同时打印多份文件”导致混乱）。  
- 因此，互斥是唯一无法通过设计消除的条件，其余三个均可通过策略破坏。

**易错点**：  
- 误以为“循环等待”可被破坏（确实可通过资源编号破坏），但题目问的是“无法破坏”。  
- 混淆“非抢占”与“互斥”：非抢占可通过强占破坏（如Linux内核抢占），但互斥若被破坏，资源本身将失去排他性保护。  
- 忽略“互斥”在特定资源下可被弱化（如读锁共享），但题目默认讨论严格互斥资源（如打印机），故仍为必要条件。

**命题规律**：  
- 408 常考死锁必要条件及预防/避免策略，尤其关注“哪些条件可破坏”。  
- 类比算法竞赛：破坏死锁条件如同“修改图论模型中的边权或节点属性”，但互斥条件如同“图中必须存在单向边”这类底层约束，无法通过上层策略消除。  
- 建议结合“资源分配图”理解：循环等待对应有向环，互斥对应节点独占性，后者是更底层的硬件约束。

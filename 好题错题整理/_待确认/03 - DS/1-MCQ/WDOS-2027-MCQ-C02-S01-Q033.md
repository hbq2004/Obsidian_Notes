# MCQ 第 33 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C02-S01-Q033_题目.png|题目]]

33. 下面的叙述中,正确的是 ( )

(A) 引入线程后,处理器只能在线程间切换
(B) 引入线程后,处理器仍在进程间切换
(C) 线程的切换,不会引起进程的切换
(D) 线程的切换,可能引起进程的切换

## DeepSeek V4 Flash Max 解析
**答案**：
D

**解题切入点**：
引入线程后，要把“资源分配单位”和“调度执行单位”拆开看：

- 进程是资源分配的基本单位：拥有地址空间、文件、信号量等。
- 线程是处理机调度的基本单位：是进程内真正在 CPU 上执行的“线”。

所以判断切换问题时，关键看切换的两个线程是否属于同一个进程。可以类比算法竞赛：进程是“队伍账号”，线程是“队伍里的提交进程”；评测机从一个提交切到另一个提交时，如果还在同一队伍，只需换现场；如果换到另一个队伍，还要换账号权限、工作目录、资源配额，这就是“进程切换”。

$$
\text{线程切换} =
\begin{cases}
\text{同进程：仅切换线程上下文（寄存器、栈、TCB 等）}\\
\text{跨进程：还要切换地址空间、页表、资源表等，即进程切换}
\end{cases}
$$

**推演**：

(A) 错。不能说“处理器只能在线程间切换”。当被切换的两个线程属于不同进程时，这种线程切换同时也会引起进程切换。

(B) 错。引入线程后，调度的基本单位是线程，而不是进程；处理器不再是笼统地在“进程间切换”。

(C) 错。同一进程内的线程切换不会引起进程切换，但不同进程之间的线程切换会引起进程切换，所以“不会”太绝对。

(D) 对。线程的切换是否引起进程切换，取决于两个线程是否属于同一进程；因此“可能引起进程切换”是对的。

**易错点**：

1. 容易把“线程是调度单位”误解成“所有切换都是线程切换，不再有进程切换”。实际上，跨进程的线程切换就是进程切换。
2. 容易把“同进程线程切换不切换地址空间”当成全部情况。跨进程线程切换时，必须切换地址空间，开销也更大。
3. 要警惕绝对化表述：A 的“只能”、B 的“仍在”、C 的“不会”都是干扰点；正确选项 D 用“可能”准确描述条件情况。
4. 类比搜索状态：同一道题内的不同状态转移，只需更新局部栈帧；换一道题则要重置整个 visited 数组和上下文，这就是“跨进程线程切换”的代价。

**命题规律**：
408 常考线程与进程的关系，核心就是“资源分配单位是进程，调度执行单位是线程”。出题人喜欢用“一定、不会、只能、仍”等绝对化词设置陷阱。解题时按“同进程/跨进程”两种情况分类讨论即可。后续还可能结合内核级线程、用户级线程、上下文切换开销出题，但核心判断仍是一句话：同进程切线程，跨进程切进程。

# MCQ 第 27 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C05-S02-Q027_题目.png|题目]]

27. ( ) 是操作系统中采用的以空间换取时间的技术.
(A) SPOOLing 技术
(B) 虚拟存储技术
(C) 覆盖与交换技术
(D) 通道技术

## DeepSeek V4 Flash Max 解析
**答案**： $\boxed{\text{A}}$ ，SPOOLing 技术。SPOOLing 在磁盘上设置输入井/输出井，用磁盘空间作为缓冲，使进程不必等待慢速 I/O 设备，属于典型的“以空间换时间”。

**解题切入点**：  
先判断每个技术付出的“代价”和换来的“收益”：

- 空间换时间 $\approx$ 算法竞赛里的“打表/预处理”：多开数组，把每次计算变成 $O(1)$ 查询。
- 时间换空间 $\approx$ “懒加载/不预处理，需要时现算”：省内存，但额外耗时。

SPOOLing 是开磁盘“缓冲井”，属于多占存储换 I/O 时间；虚拟存储、覆盖/交换则要接受缺页、换入换出等时间开销，来减少物理内存占用；通道是增加硬件 I/O 处理器，不是空间 tradeoff。

**推演**：  
对 A：进程向打印机等独占设备输出时，若同步等待，CPU 会浪费大量时间。SPOOLing 把数据先写到磁盘输出井，进程立即继续运行；真正打印由假脱机进程异步完成。于是：

$$
S_{\text{disk}} \uparrow \Rightarrow T_{\text{wait}} \downarrow
$$

空间成本是磁盘井，收益是减少等待时间，所以是空间换时间。

对 B：虚拟存储只装入当前需要的页/段，缺页时再调页。缺页中断会带来额外时间 $T_{\text{fault}}$ ，但物理内存占用减少，属于时间换空间。

对 C：覆盖与交换也是把暂时不用的模块/进程换到外存，需要时再换入。多付出的是“换入换出”的调度/ I/O 时间，少占的是内存空间，仍属于时间换空间。

对 D：通道是专门负责 I/O 的处理器，用来实现 CPU 与 I/O 并行，核心是硬件并行，不是以存储空间换取时间。

**易错点**：  
1. 易错选 B：虚拟存储确实使用了外存空间，但它不是“用空间换时间”的典型；它的主代价是缺页处理时间，换来的收益是内存空间，方向与题目相反。  
2. 易错选 C：覆盖/交换和虚拟存储类似，都是内存紧张时的腾挪手段，不要看到“外存”就选。  
3. 易错选 D：通道能节省 CPU 时间，但靠的是专用硬件，不是“空间”。  
4. 可以用竞赛直觉检查：SPOOLing 像用“前缀和”把区间求和从 $O(n)$ 优化到 $O(1)$ ；虚拟存储像“不预处理、每次现算”，如果内存不够就从外部读入，时间是代价。

**命题规律**：  
这类题考察“空间-时间权衡”的典型代表。命题人常把 I/O 技术和内存管理技术混在一起，让考生区分 tradeoff 方向：

- 空间换时间：SPOOLing、缓冲、Cache 等；
- 时间换空间：虚拟存储、覆盖、交换等。

解题本质是看“代价花在哪种资源上、收益体现在哪种资源上”。把 OS 里的技术按 tradeoff 方向整理，选择题可直接秒杀。

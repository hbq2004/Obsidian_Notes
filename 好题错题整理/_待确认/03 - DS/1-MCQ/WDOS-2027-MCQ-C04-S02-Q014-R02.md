# MCQ 第 14 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C04-S02-Q014-R02_题目.png|题目]]

文件系统用位图法表示磁盘空间的分配情况，位图存于磁盘的 $32 \sim 127$ 号块中，每个盘块占 $1024B$，盘块和块内字节均从 $0$ 开始编号。假设要释放的盘块号为 $409612$，则位图中要修改的位所在的盘块号和块内字节序号分别是（ ）.
(A) $81,1$
(B) $81,2$
(C) $82,1$
(D) $82,2$

## DeepSeek V4 Flash Max 解析
**答案**：$\boxed{C}$

**解题切入点**  
位图法是磁盘空间管理的基础，每位对应一个盘块。本题将位图本身视为连续存储的磁盘块序列，需将盘块号映射为位图块号及块内偏移。可类比算法竞赛中的“一维数组分块”问题：将长度为 $N$ 的位数组划分为大小为 $8192$ 位的块，并已知每块在磁盘上的起始块号，求某位所在的块号与块内字节下标。

**推演**  
1. 每个盘块 $1024\ \text{B}$，故每块可存储 $1024\times 8 = 8192$ 位，即位图每块可表示 $8192$ 个盘块。  
2. 要释放的盘块号 $b = 409612$。  
   - 位图所在盘块号范围 $32 \sim 127$，共 $96$ 块，位图逻辑块号（从 $0$ 开始）为 $i = \lfloor b / 8192\rfloor$。  
     $$i = \left\lfloor \frac{409612}{8192} \right\rfloor = 50 \quad (\text{因为 } 8192 \times 50 = 409600)$$
   - 该位在位图块中的偏移量为 $b \bmod 8192 = 409612 - 409600 = 12$（位序从 $0$ 开始）。  
   - 所在位图块的磁盘块号 $= 32 + i = 32 + 50 = 82$。  
3. 块内字节序号（从 $0$ 开始）：$\lfloor 12 / 8 \rfloor = 1$（字节 $0$ 容纳位 $0\sim7$，字节 $1$ 容纳位 $8\sim15$）。  
4. 因此盘块号为 $82$，字节序号为 $1$，对应选项 $\text{C}$。

**易错点**  
- 位图块起始块号不是 $0$ 而是 $32$，容易忽略偏移直接使用 $i$ 作为盘块号。  
- 字节序号从 $0$ 开始，需注意 $12/8$ 的整数部分为 $1$ 而非 $2$，避免因整除误解为 $2$。  
- 位偏移计算时，可能误将 $409600$ 当作 $409612$ 的商，导致余数错误，需仔细验证乘法。

**命题规律**  
- 位图法常考查位与盘块的映射关系，本质是“大型数组的分块索引”，类似竞赛中二维数组的寻址。  
- 常结合位图自身存储位置（如本例中位图位于 $32\sim127$ 块）设置陷阱，需要区分“位图逻辑块号”与“磁盘物理块号”。  
- 计算通常涉及 $2$ 的幂（$1024$、$8$），可借助移位运算加速，但需注意边界条件。

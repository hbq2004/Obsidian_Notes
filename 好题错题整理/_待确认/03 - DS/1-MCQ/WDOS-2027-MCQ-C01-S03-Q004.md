# MCQ 第 4 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C01-S03-Q004_题目.png|题目]]

4. ( ) 是操作系统必须提供的功能。
(A) 图形用户界面 (GUI)
(B) 为进程提供系统调用命令
(C) 中断处理
(D) 编译源程序

## DeepSeek V4 Flash Max 解析
**答案**：
C。中断处理。

**解题切入点**：
题目问“必须提供”，等价于找“没有它系统就跑不起来”的底层机制。算法竞赛中判断某一步是否必要，通常看能否构造反例：没有 GUI，Linux 服务器照常运行；没有编译器，OS 照样管理进程；而没有中断/异常处理，外部事件、时钟信号、系统调用都无法进入内核。因此核心选项是 C。

**推演**：
把操作系统看成一个事件驱动的状态机：中断/异常是状态转移的触发信号，中断处理是状态转移的执行者。

- 排除 D：编译源程序是编译器/语言处理程序的工作，不属于 OS 内核必须实现的功能。
- 排除 A：GUI 只是用户接口的一种形式，去掉后仍可用命令行或批处理方式使用系统。
- 比较 B 与 C：系统调用是 OS 提供给进程的“程序接口”，它本身依赖中断/异常机制来完成用户态到内核态的切换：
$$
\text{user process} \xrightarrow{\text{系统调用/trap}} \text{interrupt/exception} \xrightarrow{\text{内核中断处理}} \text{OS service}
$$
所以 B 并不是与 C 并列的底层功能，而是建立在 C 之上的接口机制。既然题目问“必须提供的功能”，应选更底层的 C。

**易错点**：
- 误选 B：看到“系统调用”就认为 OS 一定提供，但 408 中系统调用属于“程序接口”，不是操作系统内核功能本身；系统调用的落地依然要靠中断/异常处理。
- 误选 A：GUI 只是用户友好的外壳，不是 OS 的必要组成部分。
- 误选 D：编译源程序是编译器的工作，编译器属于语言处理程序，不属于 OS 核心。
- 混淆“接口”和“功能”：接口是 OS 对外暴露的调用方式，功能是内核实际完成的工作；题目强调“必须提供的功能”时，优先找内核机制。

**命题规律**：
本题属于“操作系统概述”中的概念边界题。命题人用 GUI、系统调用、编译器、中断处理来区分“可选组件、对外接口、上层工具、内核核心机制”。以后遇到“必须/核心/基本功能”这类问法，优先找与 CPU 状态切换、资源管理、并发/共享直接相关的机制；接口类（系统调用、GUI、命令解释器）和工具类（编译器）通常是干扰项。

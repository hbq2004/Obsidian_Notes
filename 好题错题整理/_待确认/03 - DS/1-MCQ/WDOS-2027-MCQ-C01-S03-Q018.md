# MCQ 第 18 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C01-S03-Q018_题目.png|题目]]

18. 中断处理和子程序调用都需要压栈以保护现场，中断处理一定会保存而子程序调用不需要保存其内容的是 ( ).
(A) 程序计数器
(B) 程序状态字寄存器
(C) 通用数据寄存器
(D) 通用地址寄存器

## DeepSeek V4 Flash Max 解析
**答案**：
选 **B. 程序状态字寄存器（$PSW$，也称 $FLAGS$）**。中断响应需要把当前 $PC$ 和 $PSW$ 都压栈，返回时恢复；普通子程序调用只需压 $PC$ 作为返回地址，不需要自动保存 $PSW$。

**解题切入点**：
把 CPU 看成状态机：$PC$ 描述“执行地址”，$PSW$ 描述“状态标志/特权级/中断屏蔽”。函数调用就像 DFS 进入子节点，只需要记住从哪回来；中断就像 DFS 被更高优先级事件强行打断，不仅要记住回到哪，还要保存完整状态向量才能回溯。因此区别项集中在 $PC$ 与 $PSW$ 之间；而 $PC$ 两者都保存，剩下只有 $PSW$。

**推演**：
- 子程序调用：
$$
\text{CALL: } \text{压栈 } PC;\qquad \text{RET: } \text{弹栈恢复 } PC。
$$
主程序和子程序通常在同一状态/特权级下运行，$CALL$ 指令本身不压 $PSW$。

- 中断响应：
$$
\text{中断隐指令：关中断，压栈 } PC \text{ 和 } PSW，\text{取中断向量装入 } PC/PSW。
$$
$$
\text{IRET: } \text{恢复 } PSW \text{ 和 } PC。
$$
中断可能使 CPU 从用户态切到内核态、改变标志位和中断屏蔽字，所以旧 $PSW$ 必须保存；否则 $IRET$ 无法恢复被打断程序的状态。

- 通用数据/地址寄存器：属于软件“现场保护”的范畴，中断服务程序或子程序需要使用时都会自行压栈，受调用约定影响；不是 $CALL$ 与中断响应之间的必然硬件差异。故排除 $C,D$。

**易错点**：
- 不要选 $PC$：中断确实保存 $PC$，但子程序调用也保存返回地址（本质也是 $PC$），不构成区别。
- 不要笼统认为“保护现场=保存所有寄存器”：通用寄存器的保存通常是软件压栈，不是本题中硬件自动保存的“一定”差异。
- 注意区分“中断响应”和“中断服务程序”：$PC+PSW$ 的压栈是中断隐指令/硬件响应完成；通用寄存器一般由中断服务程序用软件压栈。

**命题规律**：
本题是典型的“中断 vs 子程序调用”对比题，核心就一句话：调用只压 $PC$，中断压 $PC+PSW$。在 408/组成原理中常与 $CALL/RET$、$INT/IRET$ 的压栈内容、恢复顺序一起考。复习时记小表即可：$CALL$ 保存返回地址；$INT$ 保存 $PC$ 与 $PSW$；通用寄存器由软件按需保存。

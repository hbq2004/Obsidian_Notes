# MCQ 第 4 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C04-S01-Q004_题目.png|题目]]

下列关于逻辑结构为索引文件的索引表的叙述中，（ ）是正确的。
(A) 索引表中每条记录的索引项可以有多个
(B) 对索引文件存取时，必须先查找索引表
(C) 索引表中含有索引文件的数据及其物理地址
(D) 建立索引的目的之一是减少存储空间

## DeepSeek V4 Flash Max 解析
**答案**：
B。

**解题切入点**：
抓住“索引表”本质：它是从逻辑记录/逻辑块号到物理地址的映射表。可以看作算法竞赛里的 $\mathit{pos}[\text{key}]$ 或哈希映射；数据本身在数据块里，索引表只负责告诉你“去哪一块取”。因此访问前必须先过一遍映射；建索引多花空间是为了提速，不是省空间。

**推演**：
设某个逻辑块/记录的关键字为 $k$，索引表中对应表项为 $T(k)$，则  
$$T(k) = \text{物理块号 } p_k.$$  
实际存取时：
$$ \text{先查 } T(k) \Rightarrow \text{得到 } p_k \Rightarrow \text{再访问物理块 } p_k. $$  
所以 B 正确。

逐项看：
- A：索引表可以有多个索引项，因为文件有多个记录/逻辑块；但同一个记录/逻辑块在同一张索引表中对应一个索引项。若要多关键字查找，通常建多个索引表或多级索引，而不是“一条记录对应多个索引项”。
- C：索引表保存的是“键 + 物理地址（可能还有长度等元数据）”，像 $\text{pair}(\text{key},\text{addr})$；它不保存文件数据，文件数据仍在数据块中。
- D：建立索引需要额外存储空间，是“空间换时间”，目标是提高检索速度，不能减少存储空间。

**易错点**：
- 索引表是“目录”，不是“数据仓库”；看到“数据及其物理地址”容易误选 C。
- 顺序文件定长记录可以用公式 $\text{addr}(i)=\text{base}+iL$ 直接算出地址，但索引文件不能；索引文件必须先查索引表。
- “减少存储空间”和“建索引”方向相反：索引会增加开销，只不过换来了更快的存取。
- 对映射关系不敏感：一个逻辑块/记录在同一张索引表中通常只有一个索引项；多级索引/多个索引表不是同一个表项里有多个索引项。

**命题规律**：
408 文件管理常把“顺序、链接、索引”三种结构放一起考：顺序结构靠公式计算地址，链接结构靠指针链，索引结构靠索引表映射。这类似于算法竞赛中构造 $\text{head}$、$\text{nxt}$、$\text{pos}$ 等数组：要清楚每个表存的是什么、访问时要经过哪一步。命题常以“必须先查表”“表中含数据”“建索引省空间”作干扰；掌握“映射表 + 空间换时间”即可稳定拿分。

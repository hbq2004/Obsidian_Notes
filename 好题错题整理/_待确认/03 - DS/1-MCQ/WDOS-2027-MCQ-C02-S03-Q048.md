# MCQ 第 48 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C02-S03-Q048_题目.png|题目]]

进程 $P_0$ 和进程 $P_1$ 的共享变量定义及其初值为：
boolean flag[2];
int turn=0;
flag[0]=false; flag[1]=false;
若进程 $P_0$ 和进程 $P_1$ 访问临界资源的类 C 代码如下：
void P0()  //进程 P0      void P1()  //进程 P1
{                          {
    while(true)                while(true)
    {                          {
        flag[0]=true;turn=1;       flag[1]=true;turn=0;
        while(flag[1]&&(turn==1));  while(flag[0]&&(turn==0));
        临界区;                      临界区;
        flag[0]=false;               flag[1]=false;
    }                          }
}                          }
则并发执行进程 $P_0$ 和进程 $P_1$ 时产生的情况是（\\_\\_\\_\\_\\_\\_）.
(A) 不能保证进程互斥进入临界区，会出现“饥饿”现象

## DeepSeek V4 Flash Max 解析
**答案**：
选 D：能保证进程互斥进入临界区，不会出现“饥饿”现象。题面中若只列出 A，则 A 错误。

**解题切入点**：
这是 Peterson 两进程互斥算法。$ \text{flag}[i] $ 表示“$ P_i $ 想进临界区”，$ \text{turn} $ 是冲突仲裁变量。可以把 $ (\text{flag}[0],\text{flag}[1],\text{turn}) $ 看成一个状态三元组，互斥性等价于不存在“双方都越过 while”的非法状态；$ \text{turn} $ 就是打破对称性的“最后时间戳”。$ P_0 $ 写 $ \text{turn}=1 $ 是让 $ P_1 $ 优先，$ P_1 $ 写 $ \text{turn}=0 $ 是让 $ P_0 $ 优先；当双方同时竞争时，由最后一次写入 $ \text{turn} $ 的一方决定谁让谁。

**推演**：
设 $ P_0 $、$ P_1 $ 的自旋等待条件分别为
$$
W_0=\text{flag}[1]\land(\text{turn}=1),\qquad
W_1=\text{flag}[0]\land(\text{turn}=0).
$$

互斥性：若双方都已经把 $ \text{flag} $ 置为 true，则 $ P_0 $ 能进入当且仅当 $ W_0 $ 为假，即 $ \text{turn}=0 $；$ P_1 $ 能进入当且仅当 $ W_1 $ 为假，即 $ \text{turn}=1 $。$ \text{turn} $ 不可能同时等于 0 和 1，所以二者不可能同时通过 while。若某一方是在对方 $ \text{flag} $ 尚未置 true 时先进入的，则另一方后来进入前会看到先进入者的 $ \text{flag} $ 为 true，并且自己刚把 $ \text{turn} $ 置成对方编号，因此会被 while 挡住。故互斥成立。

无饥饿 / 有限等待：设 $ P_1 $ 正在自旋，则必有 $ \text{flag}[0]=true $ 且 $ \text{turn}=0 $。此时 $ P_0 $ 最多还能完成一次临界区访问；等它退出后，若再次申请，必须先执行 $ \text{flag}[0]=true; \text{turn}=1 $。这一写操作会使 $ P_1 $ 的等待条件变为假，而 $ P_0 $ 自己却因 $ \text{flag}[1]\land(\text{turn}=1) $ 为真而等待。因此 $ P_1 $ 之后必然进入，$ P_0 $ 同理，不会饥饿。

**易错点**：
- 不要把 $ \text{turn} $ 理解为“持有者进入临界区”。$ P_0 $ 写 $ \text{turn}=1 $ 表示把优先权让给 $ P_1 $，$ P_1 $ 写 $ \text{turn}=0 $ 表示把优先权让给 $ P_0 $。
- 必须先写 $ \text{flag}[i]=true $，再写 $ \text{turn}=j $。若顺序颠倒，可能破坏 Peterson 算法的互斥性。
- 忙等待不等于饥饿。Peterson 算法有忙等，但满足有限等待，不会让某个申请者永远进不去。
- 不要被初值 $ \text{turn}=0 $ 误导；竞争结果由最后一次写 $ \text{turn} $ 决定，而不是由初值决定。

**命题规律**：
408 中看到 $ \text{flag}[2] $ 加 $ \text{turn} $ 的对称代码，几乎就是 Peterson 算法。常考“互斥、进展、有限等待、让权等待”四个条件；Peterson 满足互斥、进展、有限等待，但不满足让权等待。真题常把“能否互斥”和“是否饥饿”两两组合成选项，认出 Peterson 后可直接判定为“互斥且不饥饿”。

# MCQ 第 50 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C02-S03-Q050_题目.png|题目]]

进程 $P_1 和 $P\_2 均包含并发执行的线程, 部分伪代码描述如下。

```text
// 进程 P1
int x=0;

Thread1()
{
    int a;
    a=1;  x += 1;
}

Thread2()
{
    int a;
    a=2;  x += 2;
}
```

```text
// 进程 P2
int x=0;

Thread3()
{
    int a;
    a=x;  x += 3;
}

Thread4()
{
    int b;
    b=x;  x += 4;
}
```

下列选项中, 需要互斥执行的操作是（\\_）
(A) $a=1 与 $a=2
(B) $a=x 与 $b=x
(C) $x += 1 与 $x += 2
(D) $x += 1 与 $x += 3

## DeepSeek V4 Flash Max 解析
**答案**：$C$  

**解题切入点**：判断一对操作是否需要互斥执行，关键在于它们是否同时访问共享变量且至少有一个是写操作。若两个操作分别访问不同的变量或都是读操作，则无需互斥；否则可能产生数据竞争，需要互斥。  

**推演**：分析每个选项：  
- $A$：$a=1$ 与 $a=2$，$a$ 是线程的局部变量，每个线程拥有独立栈空间，不共享，故无需互斥。  
- $B$：$a=x$ 与 $b=x$，$x$ 是进程 $P_2$ 内的共享变量，但两个操作均为读操作，同时读不会导致数据不一致，故无需互斥。  
- $C$：$x \mathrel{+}= 1$ 与 $x \mathrel{+}= 2$，$x$ 是进程 $P_1$ 内的共享变量，且两个操作都是写操作（读－改－写复合操作），若并发执行则会出现 race condition，必须互斥。  
- $D$：$x \mathrel{+}= 1$ 与 $x \mathrel{+}= 3$，前者属于 $P_1$，后者属于 $P_2$，两者操作的是不同进程地址空间中的 $x$，互不影响，故无需互斥。  

因此，只有选项 $C$ 需要互斥执行。  

**易错点**：容易误以为 $B$ 中两个读操作同时访问共享变量也需要互斥，但读操作本身不会破坏数据一致性，只有写操作或读写同时发生才需互斥。另外，$D$ 中不同进程的变量虽然同名但实际是不同变量，常被误认为需要互斥，实际不用。  

**命题规律**：该题考察并发控制的基本概念，即互斥的适用条件。常以选择题形式出现，要求辨别哪些操作组合可能产生竞争条件。算法竞赛背景的选手可类比：$x \mathrel{+}= 1$ 与 $x \mathrel{+}= 2$ 的并发执行相当于多线程未加锁访问全局变量，类似于图论中未同步的边更新，易导致数据混乱；而局部变量 $a$ 相当于 DFS 中的递归局部变量，各线程独立，无需互斥。

# MCQ 第 17 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C01-S02-Q017_题目.png|题目]]

下列关于批处理系统的叙述中,正确的是 ( ).
$I.$ 批处理系统允许多个用户与计算机直接交互
$II.$ 批处理系统分为单道批处理系统和多道批处理系统
$III.$ 中断技术使得多道批处理系统的 $I/O$ 设备可与 $CPU$ 并行工作
(A) 仅 $II$、$III$
(B) 仅 $II$
(C) 仅 $I$、$II$
(D) 仅 $I$、$III$

## DeepSeek V4 Flash Max 解析
**答案**：
$\boxed{\text{A}}$（仅 $\text{II}$、$\text{III}$ 正确）

**解题切入点**：
批处理系统可以类比为“离线评测 / 批处理脚本”：用户把作业一次性提交，系统按批运行，运行过程中不能实时交互；而“多个用户与计算机直接交互”更像交互题或分时系统。

可以把每条命题看作独立断言逐一验证。操作系统本质上是一个事件驱动状态机：进程在运行态、就绪态、等待态之间迁移，中断就是状态迁移的触发信号；这类似于搜索中根据到达事件把新状态入队。

**推演**：
$\text{I}$ 错误。批处理系统处理的是用户成批提交的作业，用户不与计算机直接交互；即使系统中同时存在多个用户的作业，也不等于“直接交互”。

$\text{II}$ 正确。按内存中是否支持多道程序，批处理系统分为单道批处理系统和多道批处理系统。

$\text{III}$ 正确。多道批处理系统依赖中断：当一个作业发起 $\text{I/O}$ 后，CPU 不必等待，可转去执行另一个作业；$\text{I/O}$ 完成时设备发出中断，操作系统收到中断后再恢复或调度相应作业。因此 $\text{I/O}$ 设备与 CPU 可以并行/重叠工作。

所以：
\[
\text{I}=\text{false},\quad \text{II}=\text{true},\quad \text{III}=\text{true}
\]
选 $\boxed{\text{A}}$。

**易错点**：
- 不要将“批处理系统中可包含多个用户作业”误解为“多个用户直接交互”。批处理系统的关键词是“脱机、成批、无交互”；直接交互属于分时系统。
- 不要认为中断只是“打断程序”就否定 $\text{III}$。中断是异步通知机制，让 CPU 在 $\text{I/O}$ 完成后才被拉回，这正是 CPU 与 $\text{I/O}$ 并行工作的基础。
- 判断多个小命题时，要像判多组测试点一样逐个检查；不能因为 $\text{II}$ 正确就直接选“仅 $\text{II}$”，而漏判 $\text{III}$。

**命题规律**：
考查操作系统基本概念与发展分类，重点是把“交互性”“并发性”“共享性”和硬件支撑机制绑定。批处理系统按道数分：
\[
\text{批处理系统}\xrightarrow{\text{是否支持多道程序设计}}
\begin{cases}
\text{单道批处理系统}\\
\text{多道批处理系统}
\end{cases}
\]
多道并发离不开中断、通道、DMA 等机制。这种“给出几个性质，判断属于哪种系统”的题，等价于对每个性质构造真值表；后续可能会把批处理、分时、实时系统放在同一题中对比。

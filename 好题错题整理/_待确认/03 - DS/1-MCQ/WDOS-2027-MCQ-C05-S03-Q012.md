# MCQ 第 12 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C05-S03-Q012_题目.png|题目]]

下列算法中,用于磁盘调度的是（ ）.
(A) 时间片轮转调度算法
(B) $LRU$ 算法
(C) 最短寻道时间优先算法
(D) 优先级高者优先算法

## DeepSeek V4 Flash Max 解析
**答案**：  
C. 最短寻道时间优先算法

**解题切入点**：  
区分不同调度算法的应用场景：CPU 调度、磁盘调度、页面置换等。磁盘调度关注磁头移动的寻道时间，而进程调度、页面置换则有各自的目标（如响应时间、缺页率）。

**推演**：  
逐一分析选项：  
- (A) 时间片轮转调度算法是 CPU 调度算法，用于进程分配 CPU 时间片，与磁盘无关。  
- (B) $LRU$ 算法是页面置换算法，用于虚拟内存管理，选择最近最久未使用的页面换出。  
- (C) 最短寻道时间优先算法（$SSTF$）是磁盘调度算法，每次选择离当前磁头最近的请求，贪心减少寻道时间。  
- (D) 优先级高者优先算法可用于进程调度或作业调度，根据优先级决定执行顺序，不属于磁盘调度。  

因此，只有 (C) 属于磁盘调度。

**易错点**：  
容易混淆 $LRU$ 为磁盘调度，但 $LRU$ 是缓存或页面置换策略，并非直接用于磁头寻道。时间片轮转和优先级调度都是 CPU 调度，若未仔细区分调度对象（CPU、磁盘、内存）则可能误选。

**命题规律**：  
操作系统常以选择题考查调度算法的分类，要求理解不同资源管理的核心目标。最短寻道时间优先算法本质是贪心策略（类似算法竞赛中每次选局部最优解），在一维磁道模型上可视为“最近邻”贪心，但并非全局最优，与图论中的最短路径或旅行商问题有类比之处。考生需清晰记忆各类调度算法的归属与设计思想。

# MCQ 第 46 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C02-S03-Q046_题目.png|题目]]

46. 有两个优先级相同的并发程序 $P_1$ 和 $P_2$，它们的执行过程如下所示。假设当前信号量 $s1=0,s2=0$。当前的 $z=2$，进程运行结束后，$x,y$ 和 $z$ 的值分别是（ ）

| 进程 $P_1$ | 进程 $P_2$ |
| :--- | :--- |
| ... | ... |
| $y:=1$; | $x:=1$; |
| $y:=y+2$; | $x:=x+1$; |
| $z:=y+1$; | $P(s1)$; |
| $V(s1)$; | $x:=x+y$; |
| $P(s2)$; | $z:=x+z$; |
| $y:=z+y$; | $V(s2)$; |
| ... | ... |

(A) 5, 9, 9
(B) 5, 9, 4
(C) 5, 12, 9
(D) 5, 12, 4

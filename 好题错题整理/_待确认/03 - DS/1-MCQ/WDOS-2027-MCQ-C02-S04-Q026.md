| 进程名 | Allocation | Max | Available |
| :--- | :---: | :---: | :---: |
| | A B C | A B C | A B C |
| $P_0$ | 0 0 3 | 0 0 4 | x y z |
| $P_1$ | 1 0 0 | 1 7 5 | |
| $P_2$ | 1 3 5 | 2 3 5 | |
| $P_3$ | 0 0 2 | 0 6 4 | |
| $P_4$ | 0 0 1 | 0 6 5 | |

$I.1,4,0$  $II.0,6,2$  $III.1,1,1$  $IV.0,4,7$

(A) $I、II、IV$  
(B) $I、II$  
(C) 仅 $I$  
(D) $I、III$

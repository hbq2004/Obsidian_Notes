# MCQ 第 2 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C01-S01-Q002_题目.png|题目]]

下面的（ ）资源不是操作系统应该管理的.
(A) $CPU$
(B) 内存
(C) 外存
(D) 源程序

## DeepSeek V4 Flash Max 解析
**答案**：
$$\boxed{\text{D：源程序}}$$

**解题切入点**：
操作系统本质上是资源分配器，资源分配可看成“资源—请求”二分图匹配：进程请求 $CPU$ 、内存、设备等资源，OS 判断能否分配、何时分配。 $CPU$ 、内存、外存分别由处理机管理、存储器管理、设备/文件管理；源程序只是用户程序的静态形态，不是系统运行时调度和分配的资源。类比 OJ：评测系统会保存你的源码，但它真正管理的是编译后进程的 $CPU$ 、内存、I/O，而不是源码字符串本身。

**推演**：
1. 选项 $A$ （ $CPU$ ）：处理机管理。OS 在多个就绪进程间做进程/线程调度，决定谁占用 $CPU$ ，相当于算法竞赛中的任务调度。

2. 选项 $B$ （内存）：存储器管理。OS 做内存分配、回收、地址映射、页面置换，相当于维护一个“内存池”，需要处理碎片和替换策略。

3. 选项 $C$ （外存）：外存是块设备/文件系统管理对象。OS 通过文件系统维护“文件到磁盘块”的映射（如 $inode$ ），并通过 I/O 调度访问磁盘；外存也是硬件资源。

4. 选项 $D$ （源程序）：源程序是编译前的静态文本。OS 调度的是进程，不是源程序；源程序要经编译、链接、装入后，才以进程形式被 OS 管理。即使它作为文件存放在外存，文件系统管的是“文件对象”，不是把它当作可调度资源。

**易错点**：
- 不要认为“外存不是内存，因此不受 OS 管理”。OS 通过设备管理和文件系统管理外存。
- 不要混淆“源程序”和“进程”。OS 的进程管理对象不是源代码，而是运行中的程序实例。
- 不要因为“文件系统能保存源程序文件”就认为选项 D 不对；本题的“资源”指处理机、内存、设备这类系统资源，不是任意文件内容。

**命题规律**：
- 概念辨识题：从“OS 是资源管理者”出发，判断某对象是否属于 OS 管理资源。
- 喜欢用“程序/进程/作业/源程序”等词做干扰，考查基本概念边界。
- 备考建议：把四类管理对象记成“处理机、内存、设备（含外存）、文件/信息”，做选择题时先判断该对象是“静态内容”还是“运行时可分配资源”。

# FRQ 第 2 题

![[_Attachments/题目识别/WDOS-2027-FRQ/WDOS-2027-FRQ-C02-S03-Q002_题目.png|题目]]

2. 在一个仓库中可以存放 $A 和 $B 两种产品，要求：

①每次只能存入一种产品。

② $A 产品数量 $-B 产品数量 $<M，其中 $M 是正整数

③ $B 产品数量 $-A 产品数量 $<N，其中 $N 是正整数

假设仓库的容量是无限的，试用 $P,V 操作描述产品 $A 和 $B 的入库过程.

## DeepSeek V4 Flash Max 解析
**答案**：
设三个信号量：

- `mutex = 1`：互斥信号量，保证每次只能存入一种产品；
- `semA = M - 1`：A 的“入库额度”；
- `semB = N - 1`：B 的“入库额度”。

```c
semaphore mutex = 1;
semaphore semA = M - 1;
semaphore semB = N - 1;

ProcessA() {
    while (true) {
        P(semA);      // 申请一个 A 入库额度
        P(mutex);     // 进入仓库临界区
        存入一件 A 产品;
        V(mutex);     // 离开临界区
        V(semB);      // A 多了一件，B 的入库额度增加
    }
}

ProcessB() {
    while (true) {
        P(semB);      // 申请一个 B 入库额度
        P(mutex);     // 进入仓库临界区
        存入一件 B 产品;
        V(mutex);     // 离开临界区
        V(semA);      // B 多了一件，A 的入库额度增加
    }
}
```

**解题切入点**：
题目限制的不是总量，而是两种产品的数量差。设 $x=n_A-n_B$ ，则：

$$
A-B<M \iff x \le M-1
$$

$$
B-A<N \iff -x \le N-1 \iff x \ge -(N-1)
$$

所以状态只能在区间 $[-(N-1),\ M-1]$ 内移动。A 入库相当于 $x:=x+1$ ，B 入库相当于 $x:=x-1$ 。两个信号量就是这条“带状区域”的左右护栏：`semA` 管向右走还剩多少余量，`semB` 管向左走还剩多少余量。每次 A 入库消耗一个右护栏额度，同时给左护栏补一个额度；B 入库相反。这很像算法竞赛中维护差分约束或状态机：P 操作就是状态转移前的合法边界检查，而不是越界后再回滚。

**推演**：
设当前 $x=n_A-n_B$ ，并记 $s_A$、$s_B$ 为两个信号量的当前值。可以维护如下不变量：

$$
s_A=M-1-x
$$

$$
s_B=N-1+x
$$

初始时 $x=0$ ，$s_A=M-1$ ，$s_B=N-1$ ，不变量成立。

- A 入库：`P(semA)` 会等待 $s_A>0$ ，即 $M-1-x>0$ ，所以当前 $x\le M-2$ 。存入 A 后 $x'=x+1\le M-1$ ，满足 $A-B<M$ 。同时 A 使 $x$ 变大，B 的相对余量变大，因此 `V(semB)` 使 $s_B$ 恢复为 $N-1+x'$ 。
- B 入库：对称地，`P(semB)` 保证当前 $x$ 不会低到让 B 入库后越过下界。存入 B 后 $x'=x-1\ge -(N-1)$ ，满足 $B-A<N$ 。同时 `V(semA)` 使 A 的相对余量恢复。

又因为实际“存入产品”放在 `P(mutex)` 和 `V(mutex)` 之间，所以满足“每次只能存入一种产品”。仓库容量无限，因此不需要额外设置总容量信号量。

**易错点**：
- 初始化应为 `M-1`、`N-1`，不是 `M`、`N`。因为不等式是严格小于，整数条件下最多只能领先 $M-1$ 件或 $N-1$ 件。若初始化成 `M`，会允许再多存一件，直接违反条件。
- `P(额度)` 必须放在 `P(mutex)` 之前。如果先 `P(mutex)` 再等额度，进程会拿着互斥锁等待对方进程释放额度，而对方进程又无法进入临界区，形成死锁。这相当于拿了一把锁又等一个只有对方能给的资源。
- A 入库后应 `V(semB)`，B 入库后应 `V(semA)`，不能写反。存入 A 会使 $A-B$ 增大，B 的“相对落后”变小，所以释放的是 B 的额度。
- 不要因为仓库容量无限就完全不设信号量；这里的信号量限制的是“差值边界”，不是物理容量。

**命题规律**：
408 中这类 PV 操作题，核心考点就是“信号量初始值”和“P/V 顺序”。题目只要给出两个产品数量差的上界，本质上就是构造一个带上下界的计数器。解题时先把不等式化成整数区间，再用两个信号量分别看守左右边界。命题人常把这种题伪装成生产者-消费者或仓库管理问题，但本质不变：`P` 是申请本方向额度，`V` 是释放反方向额度。复习时可类比竞赛中的状态转移：每次移动前先检查当前状态是否还能向该方向走，而不是等走到非法状态再处理。

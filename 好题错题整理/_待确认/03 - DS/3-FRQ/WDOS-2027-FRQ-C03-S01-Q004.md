# FRQ 第 4 题

![[_Attachments/题目识别/WDOS-2027-FRQ/WDOS-2027-FRQ-C03-S01-Q004_题目.png|题目]]

在一个段式存储管理系统中,其段表见下表 A。试求表 B 中的逻辑地址所对应的物理地址.

## DeepSeek V4 Flash Max 解析
**答案**：
$$[0,430]\to2530,\quad [1,10]\to3510,\quad [2,500]\to\text{越界中断},\quad [3,400]\to1720,\quad [4,112]\to2062$$

注意第 3 个不是物理地址，而是因 $500 \ge 90$ 触发的越界中断。

**解题切入点**：
段式存储管理的关键是“查表 + 边界检查”。段表每一项可看作 $\text{Map}[\text{段号}] = (\text{段长}, \text{段基址})$；逻辑地址是 $(\text{段号}, \text{段内偏移})$。转换公式为：

$$ \text{物理地址} = \text{段基址} + \text{段内偏移}, \quad \text{当且仅当 } 0 \le \text{段内偏移} < \text{段长}。$$

否则视为地址越界。这就像算法竞赛中先判数组下标范围再访问数组，越界不能硬算而应“报错”。

**推演**：
题给段表等价于：

- 段 0：段长 $600$，基址 $2100$
- 段 1：段长 $40$，基址 $3500$
- 段 2：段长 $90$，基址 $100$
- 段 3：段长 $580$，基址 $1320$
- 段 4：段长 $960$，基址 $1950$

逐项计算：

- $[0,430]$：$430 < 600$，合法，$2100+430=2530$。
- $[1,10]$：$10 < 40$，合法，$3500+10=3510$。
- $[2,500]$：$500 \ge 90$，越界，产生越界中断。
- $[3,400]$：$400 < 580$，合法，$1320+400=1720$。
- $[4,112]$：$112 < 960$，合法，$1950+112=2062$。

**易错点**：
1. 先算“基址 + 偏移”而不检查段长；如 $[2,500]$ 会错误算出 $600$，实际应越界。
2. 把段式当成页式：段式不需要用偏移量按页大小取模或移位，只需查段表后“基址 + 偏移”。
3. 混淆“段长”和“基址”的顺序，把段长当基址加。
4. 题目给出的都是十进制地址，不要自行转换成十六进制或二进制；进制转换反而易错。

**命题规律**：
408 中该知识点多为“送分题”，常与页式、段页式对比出题。命题人喜欢给一张段表、几个逻辑地址，让考生写出物理地址或判断越界。本质上是一个边界受限的映射查询：

$$(\text{段号}, \text{偏移}) \xrightarrow{\text{查段表}} (\text{基址}, \text{段长}) \xrightarrow{\text{检查偏移}} \text{物理地址}$$

竞赛视角可理解为一次状态转移，重点不是算法复杂度，而是“状态是否合法”。若考段页式，只是把这条链变长：先由段号查段表得到页表起始地址，再查页表得到页框号，最后加页内偏移；每一层都要做合法性判断。抓住这个套路即可。

# FRQ 第 4 题

![[_Attachments/题目识别/WDOS-2027-FRQ/WDOS-2027-FRQ-C03-S02-Q004_题目.png|题目]]

在一个请求分页存储管理系统中,一个作业的页面走向为 $4, 3, 2, 1, 4, 3, 5, 4, 3, 2, 1, 5$, 当分配给作业的物理块数分别为 3 和 4 时,试计算采用下述页面淘汰算法时的缺页率(假设开始执行时主存中没有页面),并比较结果.
$(1)$ 最佳置换算法.
$(2)$ 先进先出置换算法.
$(3)$ 最近最久未使用算法.

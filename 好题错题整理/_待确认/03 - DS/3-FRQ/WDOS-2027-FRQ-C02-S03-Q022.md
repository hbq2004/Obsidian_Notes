# FRQ 第 22 题

![[_Attachments/题目识别/WDOS-2027-FRQ/WDOS-2027-FRQ-C02-S03-Q022_题目.png|题目]]

某进程中有 3 个并发执行的线程 thread1,thread2 和 thread3，其伪代码如下所示.

## DeepSeek V4 Flash Max 解析
**答案**：

设三个同步信号量 $S_1,S_2,S_3$，初值为：

$$
S_1=1,\quad S_2=0,\quad S_3=0
$$

P/V 操作插入如下（$P$ 等价于 wait，$V$ 等价于 signal）：

```c
semaphore S1 = 1, S2 = 0, S3 = 0;

thread1:
    while (1) {
        P(S1);
        /* 输出 A */
        V(S2);
    }

thread2:
    while (1) {
        P(S2);
        /* 输出 B */
        V(S3);
    }

thread3:
    while (1) {
        P(S3);
        /* 输出 C */
        V(S1);
    }
```

这样输出序列被固定为 $ABCABC\cdots$。

**解题切入点**：

可以把三个线程的执行顺序看成一张“前驱图”/状态机：$A$ 完成后才允许 $B$，$B$ 完成后才允许 $C$，$C$ 完成后才允许下一轮 $A$。每个信号量相当于一条容量为 $1$ 的“许可边”，初始时只有 $S_1$ 上有 $1$ 个令牌，所以唯一能启动的是 thread1；thread2、thread3 一开始都会在 $P$ 操作处阻塞。

这就像算法竞赛中构造一个环形状态机：当前状态只有一个可转移点，转移后通过 $V$ 操作“唤醒”后继状态。$P$ 类似尝试从队列中取出一个可执行状态，$V$ 类似把后继状态放入队列；区别在于这里每次只能有一个令牌在环上流动。

**推演**：

记信号量三元组为 $(S_1,S_2,S_3)$。

1. 初始状态为 $(1,0,0)$。即使调度器先运行 thread2 或 thread3，它们也会在 $P(S_2)$ 或 $P(S_3)$ 上阻塞，因此第一轮必然从 thread1 开始。
2. thread1 执行：$P(S_1)$ 后变为 $(0,0,0)$，输出 $A$，$V(S_2)$ 后变为 $(0,1,0)$。此时只有 thread2 能通过 $P(S_2)$。
3. thread2 执行：$P(S_2)$ 后变为 $(0,0,0)$，输出 $B$，$V(S_3)$ 后变为 $(0,0,1)$。此时只有 thread3 能通过 $P(S_3)$。
4. thread3 执行：$P(S_3)$ 后变为 $(0,0,0)$，输出 $C$，$V(S_1)$ 后变为 $(1,0,0)$，回到初始状态。

因此每轮恰好输出一个 $A$、一个 $B$、一个 $C$，且顺序严格为 $A,B,C$。关键不变式是任意时刻：

$$
S_1+S_2+S_3=1
$$

即整个环上只有一个令牌，所以不会出现两个线程同时进入临界区打印。

**易错点**：

- 初值不能全为 $0$：否则三个线程第一次执行 $P$ 时都会阻塞，造成死锁。
- 初值也不能全为 $1$：否则多个线程可能同时拿到令牌，输出顺序会乱。
- $P/V$ 顺序不能写反：例如 thread1 若先 $V(S_2)$ 再 $P(S_1)$，会提前放行 thread2，可能破坏 $A$ 先于 $B$ 的顺序。
- 这不是简单的“互斥锁”问题。互斥锁只能保证临界区不重叠，不能保证执行顺序；这里必须用同步信号量做“令牌传递”。
- 循环版本中，每个线程输出后必须 $V$ 下一个信号量，否则后续线程会永久阻塞；漏掉任何一个 $V$ 都相当于状态机断边。

**命题规律**：

408 操作系统中的“进程/线程同步”高频考点就是信号量实现固定顺序/前驱图。本题属于最典型的“环形前驱图 + 循环执行”模型。遇到同类题，先画依赖图，再给每条依赖边配一个信号量；唯一能开始的源点对应的入边信号量初值设为 $1$，其余设为 $0$。验证时关注“任意时刻是否只有一个令牌在流动”，这本质上和算法竞赛中验证状态机、拓扑序的思路一致。

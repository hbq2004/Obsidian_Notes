# MCQ 第 8 题

![[_Attachments/题目识别/900-GS/900-GS-AM-C02-B-Q008_题目.png|题目]]

若 $f(x)$ 为区间 $I$ 上的连续函数，且 $f(x)$ 的值域包含于 $I$，$x_1, x_2$ 为 $I$ 中任意两个不同的点，则下列命题中，正确的是（ ）

A. 若在区间 $I$ 上，$f(x) < 0$，$f''(x) > 0$，则 $f^2\left( \frac{x_1 + x_2}{2} \right) < \frac{f^2(x_1) + f^2(x_2)}{2}$。

B. 若在区间 $I$ 上，$f'(x) < 0$，$f''(x) > 0$，则 $f^2\left( \frac{x_1 + x_2}{2} \right) < \frac{f^2(x_1) + f^2(x_2)}{2}$。

C. 若在区间 $I$ 上，$f(x) > 0$，$f''(x) > 0$，则 $f\left( f\left( \frac{x_1 + x_2}{2} \right) \right) < \frac{f\left( f(x_1) \right) + f\left( f(x_2) \right)}{2}$。

D. 若在区间 $I$ 上，$f'(x) > 0$，$f''(x) > 0$，则 $f\left( f\left( \frac{x_1 + x_2}{2} \right) \right) < \frac{f\left( f(x_1) \right) + f\left( f(x_2) \right)}{2}$.

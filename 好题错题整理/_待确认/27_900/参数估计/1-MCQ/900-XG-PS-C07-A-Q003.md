# MCQ 第 3 题

![[_Attachments/题目识别/900-XG/900-XG-PS-C07-A-Q003_题目.png|题目]]

设 $X_1, X_2, \cdots, X_n$ 是来自总体 $X$ 的容量为 $n$ 的简单随机样本，记 $E(X) = \mu$, $D(X) = \sigma^2$, $\overline{X} = \frac{1}{n} \sum\limits_{i=1}^n X_i$, 
$S_1^2 = \frac{1}{n-1} \sum\limits_{i=1}^n (X_i - \overline{X})^2$, $S_2^2 = \frac{1}{n} \sum\limits_{i=1}^n (X_i - \overline{X})^2$，则下列说法中，正确的是（）
A. $S_1^2$ 是 $\sigma^2$ 的矩估计量.
B. $S_1^2$ 是 $\sigma^2$ 的最大似然估计量.
C. $S_2^2$ 是 $\sigma^2$ 的矩估计量.
D. $S_2^2$ 是 $\sigma^2$ 的最大似然估计量.

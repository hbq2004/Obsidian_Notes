# FRQ 第 3 题

![[_Attachments/题目识别/900-XG/900-XG-PS-C07-B-Q003_题目.png|题目]]

设随机变量 $X$ 的概率密度为 $f_X(x) = \begin{cases} \frac{x}{\sigma^2} e^{-\frac{x^2}{2\sigma^2}}, & x > 0 \\ 0, & x \leq 0 \end{cases}$，其中 $\sigma > 0$ 为未知参数，$X_1, X_2, \cdots, X_n$ 为来自总体 $X$ 的一个简单随机样本。

(I) 求 $\sigma^2$ 的矩估计量 $\hat{\sigma}_1^2$，并求 $E(\hat{\sigma}_1^2)$；

(II) 求 $\sigma^2$ 的最大似然估计量 $\hat{\sigma}_2^2$，并求 $E(\hat{\sigma}_2^2)$.

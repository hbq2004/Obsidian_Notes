# FIB 第 13 题

![[_Attachments/题目识别/900-XG/900-XG-LA-C04-B-Q013_题目.png|题目]]

设 3 阶矩阵 $A = (\alpha_1, \alpha_2, \alpha_3)$ 满足 $A\alpha_1 = (1, 0, 1)^T, A\alpha_2 = (0, 1, 0)^T, A\alpha_3 = (0, 0, 0)^T, \alpha_3 \neq 0$，则线性方程组 $Ax = (1, 1, 1)^T$ 的通解为 \_ .


---

## 答案

![[_Attachments/题目识别/900-答案/900-XG-LA-C04-B-Q013_答案.png|答案]]

## V4 Flash Max 解析

**答案**:  
\[
\boxed{x=\alpha_1+\alpha_2+C\alpha_3,\quad C\text{ 为任意常数}}
\]

**解题切入点**:  
思路是把右端向量拆成已知像的线性组合：
\[
(1,1,1)^T=(1,0,1)^T+(0,1,0)^T
\]
所以一个特解就是 \(\alpha_1+\alpha_2\)。  
齐次通解由 \(A\alpha_3=0\) 给出，但还需确认零空间维数只有一维，这要用秩-零化度定理。

**推演**:  
设
\[
\beta_1=A\alpha_1=(1,0,1)^T,\qquad
\beta_2=A\alpha_2=(0,1,0)^T,
\]
且
\[
A\alpha_3=0,\quad \alpha_3\ne 0.
\]

先找特解：
\[
A(\alpha_1+\alpha_2)
=A\alpha_1+A\alpha_2
=(1,0,1)^T+(0,1,0)^T
=(1,1,1)^T.
\]
所以
\[
x_p=\alpha_1+\alpha_2
\]
是 \(Ax=(1,1,1)^T\) 的一个特解。

再看齐次方程 \(Ax=0\)。  
因为 \(\beta_1,\beta_2\) 线性无关，所以
\[
\dim R(A)\ge 2.
\]
又因为 \(A\alpha_3=0\) 且 \(\alpha_3\ne0\)，所以
\[
\dim N(A)\ge 1.
\]
由秩-零化度定理：
\[
\dim R(A)+\dim N(A)=3.
\]
于是只能有
\[
\dim R(A)=2,\qquad \dim N(A)=1.
\]
因此零空间由 \(\alpha_3\) 张成，齐次通解为
\[
x_h=C\alpha_3.
\]

所以原非齐次方程的通解为
\[
x=x_p+x_h=\alpha_1+\alpha_2+C\alpha_3.
\]

验证：
\[
A(\alpha_1+\alpha_2+C\alpha_3)
=(1,0,1)^T+(0,1,0)^T+C\cdot 0
=(1,1,1)^T.
\]

**易错点**:  
- 容易只写特解 \(\alpha_1+\alpha_2\)，漏掉齐次通解。  
- 容易忘记说明零空间维数是一维；必须用“\(\beta_1,\beta_2\) 线性无关”推出秩至少为 2，再用“\(\alpha_3\ne0\) 在零空间”推出零空间至少一维，合起来才能确定齐次部分就是 \(C\alpha_3\)。  
- 不要把 \(\alpha_1+\alpha_2\) 当成可求出的具体坐标；题目没给 \(\alpha_i\) 的具体分量，答案保留向量形式即可。  
- 注意 \(A\) 不可逆，不能写成 \(x=A^{-1}(1,1,1)^T\)。

**命题规律**:  
这类题常见于填空题或选择题，核心是“线性性 + 解的结构”。给出线性变换在某些向量上的像，先凑特解，再用零空间写通解。变式可能把 \(A\alpha_3=0\) 改成 \(A\alpha_3=\beta_3\) 或给出特征向量，本质仍是利用线性组合和秩-零化度判断解空间维数。

# MCQ 第 5 题

![[_Attachments/题目识别/900-XG/900-XG-PS-C04-A-Q005_题目.png|题目]]

设 $X, Y$ 为相互独立的随机变量, $0 < p, q < 1$, 且 $p + q = 1$, $P\{X = 0\} = p, P\{X = 1\} = q, P\{Y = 0\} = q$, $P\{Y = -1\} = p$, 则()

A. $X + Y$ 与 $X - Y$ 的相关性与 $p, q$ 的取值有关.

B. $X + Y$ 与 $X - Y$ 的独立性 with $p, q$ 的取值有关.

C. $X + Y$ 与 $X - Y$ 的相关性、独立性与 $p, q$ 的取值均无关, 且 $X + Y$ 与 $X - Y$ 相关, 不独立.

D. $X + Y$ 与 $X - Y$ 的相关性、独立性与 $p, q$ 的取值均无关, 且 $X + Y$ 与 $X - Y$ 不相关, 不独立.

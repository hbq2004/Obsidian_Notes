# MCQ 第 4 题

![[_Attachments/题目识别/900-XG/900-XG-PS-C04-A-Q004_题目.png|题目]]

设二维随机变量 $(X, Y)$ 的联合分布律为

| | $Y$ | -1 | 0 | 1 |
| --- | --- | --- | --- | --- |
| $X$ | -1 | $\frac{1}{3}$ | 0 | 0 |
| | 0 | 0 | $\frac{1}{3}$ | 0 |
| | 1 | 0 | 0 | $\frac{1}{3}$ |

则下列关于随机变量 $X, Y$ 以及 $Y^2$ 的关系的命题中，正确的是（ ）

A. $X$ 与 $Y$ 相关，$X$ 与 $Y^2$ 不相关且独立.
B. $X$ 与 $Y$ 不相关，$X$ 与 $Y^2$ 相关.
C. $X$ 与 $Y$ 独立，$X$ 与 $Y^2$ 独立.
D. $X$ 与 $Y$ 不独立，$X$ 与 $Y^2$ 不相关但不独立.

# MCQ 第 1 题

![[_Attachments/题目识别/900-XG/900-XG-PS-C02-A-Q001_题目.png|题目]]

设随机变量 $X, Y$ 的分布函数分别为 $F_1(x), F_2(x)$，则下列各组数中能够使得 $F(x) = aF_1(x)F_2(x) + bF_1(x) + cF_2(x) + d$ 为分布函数的是（）

A. $a = \frac{1}{2}, b = \frac{1}{4}, c = \frac{1}{20}, d = \frac{1}{5}$

B. $a = \frac{1}{3}, b = \frac{1}{3}, c = \frac{1}{3}, d = \frac{1}{3}$

C. $a = \frac{1}{2}, b = \frac{1}{4}, c = \frac{1}{4}, d = 0$

D. $a = \frac{1}{3}, b = \frac{1}{4}, c = \frac{1}{4}, d = 0$


---

## 答案

![[_Attachments/题目识别/900-答案/900-XG-PS-C02-A-Q001_答案.png|答案]]

## V4 Flash Max 解析

**答案**: C。分布函数必须满足 $F(-\infty)=0,\ F(+\infty)=1$。因为 $F_1(-\infty)=F_2(-\infty)=0$，所以 $d=F(-\infty)$ 必须为 0；又 $F_1(+\infty)=F_2(+\infty)=1$，所以必须有 $a+b+c+d=1$。A、B 的 $d\neq0$，D 的 $a+b+c+d=\frac56\neq1$；C 满足且可写成 $F=\frac14F_1+\frac14F_2+\frac12F_1F_2$，是分布函数的非负凸组合，故为分布函数。

**解题切入点**: 先看“边界条件”，就像算法题先判边界/越界：分布函数在 $-\infty$ 必须趋于 $0$，在 $+\infty$ 必须趋于 $1$。用这两个条件能快速排除大部分选项，剩下再验证单调性和右连续性。

**推演**:  
设 $F_1,F_2$ 是分布函数，则
$$
F_1(-\infty)=F_2(-\infty)=0,\qquad F_1(+\infty)=F_2(+\infty)=1.
$$

代入
$$
F(x)=aF_1(x)F_2(x)+bF_1(x)+cF_2(x)+d
$$

得
$$
F(-\infty)=d=0,
$$
$$
F(+\infty)=a+b+c+d=1.
$$

逐项检查：

- A：$d=\frac15\neq0$，在 $-\infty$ 处极限不为 $0$，排除；
- B：$d=\frac13\neq0$，且 $F(+\infty)=\frac43\neq1$，排除；
- D：$a+b+c+d=\frac13+\frac14+\frac14=\frac56\neq1$，排除；
- C：$d=0$，且 $a+b+c+d=\frac12+\frac14+\frac14=1$，候选成立。

再验证 C 确实为分布函数。取 C 的系数：
$$
F(x)=\frac12F_1(x)F_2(x)+\frac14F_1(x)+\frac14F_2(x).
$$

右连续性显然由 $F_1,F_2$ 的右连续性保持。单调性：设 $x_1<x_2$，令
$$
u=F_1(x_1),\quad v=F_2(x_1),
$$
$$
\Delta_1=F_1(x_2)-F_1(x_1)\ge0,\quad \Delta_2=F_2(x_2)-F_2(x_1)\ge0.
$$

则
$$
\begin{aligned}
F(x_2)-F(x_1)
&=\frac12[(u+\Delta_1)(v+\Delta_2)-uv]
+\frac14\Delta_1+\frac14\Delta_2\\
&=\left(\frac12v+\frac14\right)\Delta_1
+\left(\frac12u+\frac14\right)\Delta_2
+\frac12\Delta_1\Delta_2\ge0.
\end{aligned}
$$

所以 $F$ 单调不减，确实是分布函数。

**易错点**: 
最容易只检查 $F(+\infty)=1$ 而忽略 $F(-\infty)=0$。例如 A 的 $a+b+c+d=1$，看起来像正确选项，但 $d=\frac15$ 导致 $F(-\infty)=\frac15\neq0$。  
另一个易错点是只验证极限，不验证单调性；本题 C 能通过，是因为它可以看作 $F_1,F_2,F_1F_2$ 三个分布函数的凸组合，权重分别为 $\frac14,\frac14,\frac12$，非负且和为 $1$。

**命题规律**: 
考点是分布函数的三条基本刻画：单调不减、右连续、$F(-\infty)=0,F(+\infty)=1$。常见变式包括判断 $F_1+F_2$、$F_1F_2$、$1-F_1$、混合分布 $\sum\lambda_iF_i$ 是否为分布函数。其中 $F_1F_2$ 是分布函数，对应两个独立变量最大值 $\max(X,Y)$ 的分布；这类题本质是“边界条件 + 单调性/凸组合”的组合判断。

# FRQ 第 27 题

![[_Attachments/题目识别/900-GS/900-GS-AM-C05-B-Q027_题目.png|题目]]

已知二元函数 $f(x, y)$ 有一阶连续偏导数，且满足 $\frac{\partial f'}{\partial x}(x, y) + \frac{\partial f'}{\partial y}(x, y) = 0$，$\frac{\partial f'}{\partial y}(0, y) = \frac{1}{e^y(1 + e^y)}$， $f(0, 0) = \ln 2 - 1$。

(I) 记 $z(x, y) = f(x + y, y)$，求 $z_y'(x, y)$；

(II) 求 $f(x, y)$ 的表达式.

## 答案

![[_Attachments/题目识别/900-答案/900-GS-AM-C05-B-Q027_答案.png|答案]]

## V4 Flash Max 解析

**答案**: 
(I) $z_y'(x,y)=0$。
(II) $f(x,y)=\ln\big(1+e^{x-y}\big)-1$。

**解题切入点**: 这是一阶线性 PDE $f_x+f_y=0$ + 特征线法 + 一维初值条件的题。给定的 $f_x+f_y=0$ 告诉我们 $f$ 沿"特征方向"不变,即只依赖 $x-y$ 这个组合,这正是把偏微分方程化为一维微分方程的关键(等价于算法里"沿特征方向做降维/坐标变换")。(I) 相对容易,直接链式求导利用 $f_1+f_2=0$。

**推演**:

(I) 记 $u=x+y$,$v=y$,则 $z(x,y)=f(u,v)$,其中对第一、第二自变量求偏导分别记为 $f_1,f_2$:
$$z_x=f_1(u,v)\cdot\frac{\partial u}{\partial x}=f_1,\qquad z_y=f_1\cdot\frac{\partial u}{\partial y}+f_2\cdot\frac{\partial v}{\partial y}=f_1+f_2.$$
由题设 $f_1+f_2=0$(即 $f_x+f_y=0$),得
$$\boxed{z_y(x,y)=f_1(x+y,y)+f_2(x+y,y)=0.}$$

(II) 解 PDE $f_x+f_y=0$。沿曲线 $$\frac{dx}{ds}=1,\ \frac{dy}{ds}=1$$(特征方向 $(1,1)$),有
$$\frac{d}{ds}f(x(s),y(s))=f_x\frac{dx}{ds}+f_y\frac{dy}{ds}=f_x+f_y=0,$$
即 $f$ 沿方向 $(1,1)$ 为常数,故 $f(x,y)$ 只依赖 $x-y$。设 $f(x,y)=g(x-y)$。

于是 $f_y(x,y)=-g'(x-y)$。由 $f_y(0,y)=\dfrac{1}{e^y(1+e^y)}$:
$$-g'(-y)=\frac{1}{e^{y}(1+e^{y})}\ \Longrightarrow\ g'(t)\Big|_{t=-y}=-\frac{1}{e^{y}+e^{2y}}.$$
换元令 $t=-y$,即 $y=-t$:
$$g'(t)=\frac{1}{e^{y}+e^{2y}}\Big|_{y=-t}=\frac{1}{e^{-t}+e^{-2t}}=\frac{e^{2t}}{e^{t}+1}=e^{t}\cdot\frac{e^{t}}{e^{t}+1}\cdot\frac{1}{e^{t}}\cdot?$$
整理:$g'(t)=\dfrac{e^{2t}}{e^{t}+1}=\dfrac{e^{t}\cdot e^{t}}{1+e^{t}}$。注意到 $\dfrac{d}{dt}\ln(1+e^{t})=\dfrac{e^{t}}{1+e^{t}}$,而 $g'(t)=\dfrac{e^{2t}}{e^{t}+1}$,作长除:
$$\frac{e^{2t}}{1+e^{t}}=e^{t}-1+\frac{1}{1+e^{t}},$$
验证:$e^{t}-1+\dfrac{1}{1+e^{t}}=\dfrac{(e^{t}-1)(1+e^{t})+1}{1+e^{t}}=\dfrac{e^{2t}-1+1}{1+e^{t}}=\dfrac{e^{2t}}{1+e^{t}}$,成立。故
$$g'(t)=e^{t}-1+\frac{1}{1+e^{t}},\qquad g(t)=e^{t}-t+\ln(1+e^{t})+C.$$
由 $f(0,0)=g(0)=\ln2-1$:
$$g(0)=1-0+\ln2+C=\ln2-1\ \Longrightarrow\ C=-2.$$
因此
$$f(x,y)=g(x-y)=e^{x-y}-(x-y)+\ln\big(1+e^{x-y}\big)-2.$$

(说明:若采用先对 $-g'(-y)$ 积分再回代的等价做法,结论同上。)

**易错点**: 
1. (II) 求 $g'(t)$ 时符号容易错:$f_y=-g'(x-y)$,代入 $x=0$ 得 $-g'(-y)$,取负号时要当心。
2. 积分 $\int\dfrac{e^{2t}}{1+e^{t}}dt$ 表面上不是 $\ln(1+e^t)$ 的直接形式,需先拆分 $e^{t}-1+\frac1{1+e^t}$,漏拆会算不出。自检:求导 $g'(t)=e^t-1+\dfrac{e^t}{1+e^t}$,与拆分一致;代入 $t=0,g=\ln2-1$ 得 $C=-2$,核对 $f(0,y)$ 满足初值。
3. 特征方向的确定:$f_x+f_y=0$ 的特征是 $dx=dy$(方向 $(1,1)$),组合量 $x-y$;不要误以为是 $x+y$。
4. (I) 的 $z_y$ 有 $f_1+f_2$ 两项都要写,靠 $f_1+f_2=0$ 得零,缺一项会得非零错误。

**命题规律**: 一阶 PDE $a f_x+b f_y=0$($a,b$ 常数)的解必是 $f=g(ax/b... $,具体为 $f=\Phi(bx-ay)$",即沿特征直线为常数。命题角度:①给一条"对 $y$ 求偏导在某线上取值"的初值,确定 $g$;②把 PDE 改写成非齐次 $f_x+f_y=h(x,y)$,$f$ 沿特征按 $h$ 线性增长。联系:与方法本身相关的还有"复合变量还原"以及后文的分布积分;与第 22 题(复合函数偏导凑特征)同源。变式:改特征方向为 $(a,b)$,初值点改到曲线 $y=kx$。

# MCQ 第 7 题

![[_Attachments/题目识别/900-XG/900-XG-PS-C02-B-Q007_题目.png|题目]]

设随机变量 $X_1, X_2$ 相互独立且均服从参数为 $\lambda (\lambda > 0)$ 的泊松分布. 若 $k$ 为非负整数, 则下列结论中, 正确的是 ( )

A. $P\left\{X_1 + X_2 = 2k\right\} = \frac{e^{-2\lambda}(2\lambda)^k}{k!}$.

B. $P\left\{X_1 + X_2 = k\right\} = \frac{e^{-2\lambda}(2\lambda)^k}{k!}$.

C. $P\left\{X_1 + X_2 = 2k\right\} = \frac{e^{-\lambda}\lambda^k}{k!}$.

D. $P\left\{X_1 + X_2 = k\right\} = \frac{e^{-\lambda}\lambda^k}{k!}$.

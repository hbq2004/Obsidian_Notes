# FRQ 第 3 题

![[_Attachments/题目识别/900-GS/900-GS-AM-C06-C-Q003_题目.png|题目]]

设二元函数 $f(x, y)$ 在区域 $D = \{(x, y) \mid 0 \leqslant x \leqslant 1, 0 \leqslant y \leqslant 1\}$ 上有连续的偏导数 $\frac{\partial f}{\partial x}$，$\frac{\partial f}{\partial y}$，且 $\left| \frac{\partial f}{\partial x} \right| \leqslant M$， $\left| \frac{\partial f}{\partial y} \right| \leqslant M$。已知 $f(0, 0) = f(0, 1) = f(1, 0) = f(1, 1) = 0$，证明：

$$(I)$ 在区域 $D$ 上，$\left| f(x, y) \right| \leqslant M(x + y)$；$(II) \left| \iint_{D} f(x, y) \, dx \, dy \right| \leqslant \frac{M}{2}.$$

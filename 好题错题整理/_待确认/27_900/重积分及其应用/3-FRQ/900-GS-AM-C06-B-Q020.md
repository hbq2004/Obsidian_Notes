# FRQ 第 20 题

![[_Attachments/题目识别/900-GS/900-GS-AM-C06-B-Q020_题目.png|题目]]

设函数 $f(x)$ 连续，平面区域 $D = \{ (x, y) \mid |x| + |y| \leq a \}$ ($a > 0$)。

(I) 证明：$\iint_{D} f(x+y) \, dx \, dy = a \int_{-a}^{a} f(t) \, dt$。

(II) 若 $a = \pi$，计算 $I = \iint_{D} \cos^2 A(x+y) \, dx \, dy$，其中 $A = \left[ \frac{2|x| + 2|y|}{\pi} \right]$ 表示不超过 $\frac{2|x| + 2|y|}{\pi}$ 的最大整数.

# FRQ 第 2 题

![[_Attachments/题目识别/900-GS/900-GS-AM-C06-C-Q002_题目.png|题目]]

设平面区域 $D = \{(x, y) \mid 0 \leqslant x \leqslant 2, 0 \leqslant y \leqslant 2\}$.

(I) 求二重积分 $\iint_D |x^2 + y^2 - 1| \, dx \, dy$.

(II) 设 $f(x, y)$ 在区域 $D$ 上连续，且 $\iint_D f(x, y) \, dx \, dy = -\frac{\pi}{4}$，$\iint_D f(x, y)(x^2 + y^2) \, dx \, dy = \frac{20}{3}$. 证明：存在点 $(\xi, \eta) \in D$，使得 $|f(\xi, \eta)| \geqslant 1$.

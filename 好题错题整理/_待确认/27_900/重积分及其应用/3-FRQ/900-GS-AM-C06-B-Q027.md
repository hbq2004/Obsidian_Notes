# FRQ 第 27 题

![[_Attachments/题目识别/900-GS/900-GS-AM-C06-B-Q027_题目.png|题目]]

设某物体 $A$ 占据由曲面 $z = \sqrt{1 - x^2 - y^2}$ 以及 $z = \sqrt{x^2 + y^2}$ 所围成的空间区域 $\Omega$，密度函数 $\rho(x, y, z)$ 满足 $\rho(x, y, z) = 8z + \frac{2}{\pi} \sqrt{x^2 + y^2} \iiint_{\Omega} \rho(x, y, z) \, dx \, dy \, dz$。

( I ) 求 $\rho(x, y, z)$；

( II ) 设 $A$ 的质心坐标为 $(\overline{x}, \overline{y}, \overline{z})$，证明：$\frac{4}{15} < \overline{x} + \overline{y} + \overline{z} < 1$.

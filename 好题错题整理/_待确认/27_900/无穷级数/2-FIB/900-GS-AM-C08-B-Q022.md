# FIB 第 22 题

![[_Attachments/题目识别/900-GS/900-GS-AM-C08-B-Q022_题目.png|题目]]

设 $f(x)$ 为 $[a_1, +\infty)$ 上单调增加的正值函数，满足 $\displaystyle \int_{a_1}^{+\infty} \frac{dx}{x f(x)} < +\infty$，$\{a_n\}$ 为单调增加的无界数列，且 $a_n > 0, n = 1, 2, \cdots$. 证明：

\_\_\_\_\_\_ $a_{n+1} - a_n$

(I) 级数 $\displaystyle \sum\limits_{n=1}^{\infty} \frac{a_{n+1} - a_n}{a_{n+1} f(a_{n+1})}$ 收敛；

\_\_\_\_\_\_ $\sqrt{a_n}(a_{n+1} - a_n)$

(II) 若 $a_1 = 1$，则级数 $\displaystyle \sum\limits_{n=1}^{\infty} \frac{\sqrt{a_n}(a_{n+1} - a_n)}{a_{n+1}(1 + a_n)}$ 收敛，且其值小于 $\dfrac{\pi + 1}{2}$.

# MCQ 第 2 题

![[_Attachments/题目识别/900-GS/900-GS-AM-C05-B-Q002_题目.png|题目]]

设函数 $f(x, y) =

$$$\begin{cases} \cos xy, & xy \neq 0, \\ \cos y, & x = 0, \\ \cos x, & y = 0, \end{cases}$$$

，则下列结论中，正确的是（ ）

A. 函数 $f(x, y)$ 在点 (0,0) 处连续，且 $$\frac{\partial^2f}{\partial x \partial$ y}$ 存在。

B. 函数 $f(x, y)$ 在点 (0,0) 处连续，但 $$\frac{\partial^2f}{\partial x \partial$ y}$ 不存在。

C. 函数 $f(x, y)$ 在点 (0,0) 处不连续，但 $$\frac{\partial^2f}{\partial x \partial$ y}$ 存在。

D. 函数 $f(x, y)$ 在点 (0,0) 处不连续，且 $$\frac{\partial^2f}{\partial x \partial$ y}$ 不存在.

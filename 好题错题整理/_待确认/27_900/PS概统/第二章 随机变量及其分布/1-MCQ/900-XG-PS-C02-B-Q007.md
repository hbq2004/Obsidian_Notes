# MCQ 第 7 题

![[_Attachments/题目识别/900-XG/900-XG-PS-C02-B-Q007_题目.png|题目]]

设随机变量 $X_1, X_2$ 相互独立且均服从参数为 $\lambda (\lambda > 0)$ 的泊松分布. 若 $k$ 为非负整数, 则下列结论中, 正确的是 ( )

A. $P\left\{X_1 + X_2 = 2k\right\} = \frac{e^{-2\lambda}(2\lambda)^k}{k!}$.

B. $P\left\{X_1 + X_2 = k\right\} = \frac{e^{-2\lambda}(2\lambda)^k}{k!}$.

C. $P\left\{X_1 + X_2 = 2k\right\} = \frac{e^{-\lambda}\lambda^k}{k!}$.

D. $P\left\{X_1 + X_2 = k\right\} = \frac{e^{-\lambda}\lambda^k}{k!}$.


---

## 答案

![[_Attachments/题目识别/900-答案/900-XG-PS-C02-B-Q007_答案.png|答案]]

## V4 Flash Max 解析

**答案**: B。因为 $X_1,X_2$ 独立且均服从 $P(\lambda)$，由泊松分布可加性可知 $X_1+X_2\sim P(2\lambda)$，所以  
$$P\{X_1+X_2=k\}=\frac{e^{-2\lambda}(2\lambda)^k}{k!}.$$  
A 把 $2k$ 误当成自变量 $k$，C、D 参数误用为 $\lambda$。

**解题切入点**:  
看到“两个独立泊松变量求和”，第一反应就是“泊松分布可加性”：参数相加即可。这类似于算法竞赛中遇到经典模型时直接调用已知结论，而不是现场重新推导。若忘记结论，可以用卷积或矩生成函数快速验证。

**推演**:  
令 $Y=X_1+X_2$。因为 $X_1,X_2$ 独立且都服从参数为 $\lambda$ 的泊松分布，所以 $Y$ 服从参数为 $2\lambda$ 的泊松分布，即

$$P\{Y=k\}=\frac{e^{-2\lambda}(2\lambda)^k}{k!},\qquad k=0,1,2,\dots$$

因此 B 正确。

若不使用可加性，也可直接卷积：

$$P\{Y=k\}=\sum_{i=0}^k P\{X_1=i\}P\{X_2=k-i\}$$

$$=\sum_{i=0}^k \frac{e^{-\lambda}\lambda^i}{i!}\cdot \frac{e^{-\lambda}\lambda^{k-i}}{(k-i)!}
=\frac{e^{-2\lambda}\lambda^k}{k!}\sum_{i=0}^k \binom{k}{i}
=\frac{e^{-2\lambda}(2\lambda)^k}{k!}.$$

这正好是 $P(2\lambda)$ 的分布列。

另外，矩生成函数也能验证：

$$M_Y(t)=\left(e^{\lambda(e^t-1)}\right)^2=e^{2\lambda(e^t-1)},$$

这正是 $P(2\lambda)$ 的矩生成函数。

再看 A：若事件是 $X_1+X_2=2k$，则应为

$$P\{Y=2k\}=\frac{e^{-2\lambda}(2\lambda)^{2k}}{(2k)!},$$

不是 $\frac{e^{-2\lambda}(2\lambda)^k}{k!}$。注意这里 $k$ 与 $2k$ 是两回事。

**易错点**:  
- 容易误选 A：把 $Y=2k$ 的概率错误地写成分布列中自变量取 $k$。自变量必须是 $2k$，所以幂次和阶乘都应为 $(2\lambda)^{2k}$ 和 $(2k)!$。  
- C、D 把参数写成 $\lambda$，忽略了两个独立泊松变量合并后参数相加为 $2\lambda$。  
- 自检：取 $k=1$ 时，B 给出 $P\{Y=1\}=2\lambda e^{-2\lambda}$，正确；A 给出 $P\{Y=2\}=2\lambda^2 e^{-2\lambda}$，不一定等于真实值 $2\lambda e^{-2\lambda}$。  
- 注意 $k=0$ 时 A、B 都会给出 $e^{-2\lambda}$，所以不要用 $k=0$ 检验来区分 A、B。

**命题规律**:  
“独立泊松变量之和仍为泊松分布”是数一概率论中的高频小结论。常见变式有：

1. 参数不同时：$X\sim P(\lambda_1)$，$Y\sim P(\lambda_2)$ 独立，则 $X+Y\sim P(\lambda_1+\lambda_2)$。  
2. 条件分布：给定 $X+Y=n$ 时，$X\mid X+Y=n$ 服从二项分布 $B\left(n,\frac{\lambda_1}{\lambda_1+\lambda_2}\right)$。  
3. 与大数定律、中心极限定理结合，用正态分布近似泊松分布。  

备考时把“泊松分布可加性”当作一个可直接调用的结论即可，同时要知道它依赖“独立”这一前提。

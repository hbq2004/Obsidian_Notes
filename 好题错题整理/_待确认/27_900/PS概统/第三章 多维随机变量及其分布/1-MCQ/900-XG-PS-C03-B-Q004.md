# MCQ 第 4 题

![[_Attachments/题目识别/900-XG/900-XG-PS-C03-B-Q004_题目.png|题目]]

设随机变量 X 的概率密度为 f(x), X₁, X₂, …, Xₙ 为来自总体 X 的简单随机样本. X(1) = min{X₁, X₂, …, Xₙ}, X(n) = max{X₁, X₂, …, Xₙ}. 若常数 c 满足 ∫∞ˣ f(x) dx = 1/2, 则 P{X(1) < c < X(n)} = \_\_\_\_\_\_.

A. 1 - 1/2ⁿ⁻¹. B. 1 - 1/2ⁿ. C. 1/2ⁿ. D. 1/2ⁿ¹.


---

## 答案

![[_Attachments/题目识别/900-答案/900-XG-PS-C03-B-Q004_答案.png|答案]]

## V4 Flash Max 解析

**答案**: A.  
\(P\{X_{(1)}<c<X_{(n)}\}=1-\dfrac{1}{2^{n-1}}\)。因为 \(c\) 是总体中位数，反面是“所有样本都落在 \(c\) 的同一侧”，该概率为 \(2\cdot \left(\frac12\right)^n\)。

**解题切入点**:  
不要直接求 \(X_{(1)},X_{(n)}\) 的联合密度。把每个样本看成二值变量：小于 \(c\) 记为 0，大于 \(c\) 记为 1（连续型单点概率为 0）。  
要求 \(\min<c<\max\)，等价于样本中既有 0 又有 1。算法竞赛类比：补集计数/容斥，反面就是“全 0”或“全 1”。

**推演**:  
由题设知 \(c\) 是中位数，所以对每个样本：
\[
P(X_i<c)=P(X_i>c)=\frac12
\]
且 \(P(X_i=c)=0\)。

令
\[
K=\#\{i:X_i<c\}
\]
则
\[
K\sim \mathrm{Bin}\left(n,\frac12\right)
\]

事件
\[
\{X_{(1)}<c<X_{(n)}\}
\]
要求至少有一个样本小于 \(c\)，也至少有一个样本大于 \(c\)，即
\[
1\le K\le n-1
\]

所以
\[
\begin{aligned}
P\{X_{(1)}<c<X_{(n)}\}
&=1-P(K=0)-P(K=n)\\
&=1-\left(\frac12\right)^n-\left(\frac12\right)^n\\
&=1-\frac{1}{2^{n-1}}
\end{aligned}
\]

等价地看反面：所有样本都大于 \(c\)，或所有样本都小于 \(c\)，概率为
\[
\frac{1}{2^n}+\frac{1}{2^n}=\frac{1}{2^{n-1}}
\]

**易错点**:  
- 不要认为 \(X_{(1)}\) 与 \(X_{(n)}\) 独立，不能写成两个概率相乘。  
- 只减“全部在右侧”会得到 \(1-\frac1{2^n}\)，这是错误选项 B；必须左右两侧的“全同侧”情况都减去。  
- 连续型随机变量在单点的概率为 0，所以 \(\le\) 与 \(<\)、\(\ge\) 与 \(>\) 可视为等价，不要被严格不等号干扰。  

自检：取 \(n=1\)，单个样本不可能同时小于 \(c\) 又大于 \(c\)，公式给出 \(1-\frac1{2^0}=0\)，合理；取 \(n=2\)，两样本分居 \(c\) 两侧的概率为 \(\frac12\)，公式给出 \(1-\frac12=\frac12\)，合理。  

注：按OCR最合理读法，题中积分条件应理解为 \(c\) 是总体中位数；无论原式为 \(\int_{-\infty}^{c} f(x)\,dx=\frac12\) 还是 \(\int_c^{\infty} f(x)\,dx=\frac12\)，结论相同。

**命题规律**:  
考研数学一常考“顺序统计量”与“样本落在分位数两侧的概率”。核心是：
\[
P(X_{(n)}\le x)=[F(x)]^n,\qquad
P(X_{(1)}>x)=[1-F(x)]^n
\]

本题属于其变式：把中位数 \(c\) 看作阈值，利用二项分布或补集思想求区间覆盖概率。常见变式还有求：
\[
P\{X_{(1)}>c\},\quad P\{X_{(n)}<c\},\quad P\{X_{(k)}<c<X_{(n-k+1)}\}
\]
本质上都是“独立重复 Bernoulli 试验”的计数问题。

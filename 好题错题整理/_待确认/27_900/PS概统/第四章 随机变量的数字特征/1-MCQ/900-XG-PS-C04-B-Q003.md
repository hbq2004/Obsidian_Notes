# MCQ 第 3 题

![[_Attachments/题目识别/900-XG/900-XG-PS-C04-B-Q003_题目.png|题目]]

设随机变量 X 和 Y 独立同分布, X 的概率密度为 $f(x) = \begin{cases} g(x), & x > 0, \\ 0, & x \leq 0, \end{cases}$，其中 $g(x)$ 满足对任意 $x > 0$， $g(x) > 0$，则下列说法中，正确的是（）

A. X + Y 与 X - Y 相关.

B. X + Y 与 X - Y 不相关，不独立.

C. X + Y 与 X - Y 不相关，独立.

D. X + Y 与 X - Y 不相关，是否独立与 $g(x)$ 的表达式有关.


---

## 答案

![[_Attachments/题目识别/900-答案/900-XG-PS-C04-B-Q003_答案.png|答案]]

## V4 Flash Max 解析

**答案**: B。设 $U=X+Y$，$V=X-Y$。由 $X,Y$ 同分布，
\[
\operatorname{Cov}(U,V)=\operatorname{Cov}(X+Y,X-Y)=\operatorname{Var}X-\operatorname{Var}Y=0,
\]
所以二者不相关。但 $X,Y>0$ 使 $(U,V)$ 的联合支撑被限制在 $|V|<U$，不是独立变量应有的“乘积型”支撑，因此不独立。

**解题切入点**: 算法竞赛视角：求协方差就像展开多项式/算内积，交叉项会抵消；判断独立则先看“可行域/支撑集”。若 $U,V$ 独立，联合支撑必须是边缘支撑的乘积；而这里 $U=X+Y$ 与 $V=X-Y$ 天然有约束 $|V|<U$，联合支撑是三角形，所以不可能独立。

**推演**:

1. 先证不相关。

由协方差的双线性性：
\[
\begin{aligned}
\operatorname{Cov}(X+Y,X-Y)
&=\operatorname{Cov}(X,X)-\operatorname{Cov}(X,Y)+\operatorname{Cov}(Y,X)-\operatorname{Cov}(Y,Y)\\
&=\operatorname{Var}X-\operatorname{Var}Y\\
&=0.
\end{aligned}
\]

这里 $X,Y$ 独立同分布，所以交叉协方差为 $0$，且方差相等。

2. 再证不独立。

因为 $X$ 的密度只在 $x>0$ 时为正，所以
\[
X>0,\quad Y>0\quad \text{a.s.}
\]

令
\[
U=X+Y,\quad V=X-Y.
\]
则
\[
X=\frac{U+V}{2}>0,\qquad Y=\frac{U-V}{2}>0.
\]

因此必须有
\[
U>0,\qquad -U<V<U,
\]
即
\[
|V|<U.
\]

所以 $(U,V)$ 的联合支撑是三角形区域
\[
D=\{(u,v):u>0,\ |v|<u\}.
\]

但 $U$ 的边缘支撑是 $(0,+\infty)$，$V$ 的边缘支撑是 $(-\infty,+\infty)$。若 $U,V$ 独立，联合密度应几乎处处等于边缘密度乘积，联合支撑应接近矩形区域 $(0,+\infty)\times(-\infty,+\infty)$。

取 $(u,v)=(1,2)$ 附近的小邻域：该邻域内 $v>u>0$，于是 $Y=(u-v)/2<0$，联合密度为 $0$；但 $f_U(1)>0$，$f_V(2)>0$。所以独立性所需的
\[
f_{U,V}(u,v)=f_U(u)f_V(v)
\]
在正测度集上被破坏。因此 $U,V$ 不独立。

**易错点**:

- 最容易错的是算出协方差为 $0$ 后直接选 C。注意：不相关只说明“没有线性关系”，独立是强得多的条件。
- 不要因为正态分布中 $X+Y$ 与 $X-Y$ 独立，就以为任意分布都成立。正态是特殊情形；本题分布支撑在正半轴，联合支撑已经是三角形。
- 不要忽略支撑约束：$X-Y$ 单独看可以取任意实数，但一旦和 $X+Y$ 联立，就必须满足 $|X-Y|<X+Y$。

注：题干没有显式写“方差存在”，讨论相关/不相关时按考研常规默认二阶矩存在；此为按 OCR 最合理读法。

**命题规律**:

核心考点是“协方差双线性”和“不相关与独立的关系”。常见变式是：若 $X,Y$ 独立同分布且方差为 $\sigma^2$，判断 $aX+bY$ 与 $cX+dY$ 的相关性，有
\[
\operatorname{Cov}(aX+bY,cX+dY)=\sigma^2(ac+bd).
\]
本题 $a=b=c=1$，$d=-1$，所以 $ac+bd=1-1=0$。命题时还可能结合二维正态、协方差矩阵、特征函数等知识，但本质仍是“协方差为 0 不等于独立”。

# MCQ 第 3 题

![[_Attachments/题目识别/900-XG/900-XG-LA-C03-B-Q003_题目.png|题目]]

设 $\alpha_1, \alpha_2, \alpha_3$ 与 $\beta_1, \beta_2, \beta_3$ 为 3 维列向量组的两个不同的极大无关组, 且 $(\alpha_1, \alpha_2, \alpha_3) = (\beta_1, \beta_2, \beta_3)A$. 向量 $\xi_i$ ($i=1,2,3$) 满足 $\xi_i = x_{1i}\alpha_1 + x_{2i}\alpha_2 + x_{3i}\alpha_3 = y_{1i}\beta_1 + y_{2i}\beta_2 + y_{3i}\beta_3$, 且 $(x_{1i}, x_{2i}, x_{3i}) = (y_{1i}, y_{2i}, y_{3i})B$, 则()

A. 若矩阵 $(y_{ij})$ 可逆, 则 $B=A$.

B. 若矩阵 $(y_{ij})$ 可逆, 则 $B=A^{-1}$.

C. 若矩阵 $(y_{ij})$ 可逆, 则 $B^T=A$.

D. 若矩阵 $(y_{ij})$ 可逆, 则 $B^T=A^{-1}$.

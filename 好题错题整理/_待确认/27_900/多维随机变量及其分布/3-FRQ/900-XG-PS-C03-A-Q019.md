# FRQ 第 19 题

![[_Attachments/题目识别/900-XG/900-XG-PS-C03-A-Q019_题目.png|题目]]

设 $(X, Y)$ 是二维随机变量，$X$ 的边缘概率密度为 $f_X(x) = \begin{cases} \frac{3}{2}x^2 - \frac{3}{4}x^3, & 0 < x < 2, \\ 0, & 其他. \end{cases}$

$x(0 < x < 2)$ 的条件下 $Y$ 的条件概率密度为 $f_{Y|X}(y|x) = \begin{cases} \frac{2y}{2x - x^2}, & x < y < \sqrt{2x}, \\ 0, & 其他. \end{cases}$

(I) 求 $(X, Y)$ 的联合概率密度 $f(x, y)$;

(II) 求 $Y$ 的边缘概率密度 $f_Y(y)$; (III) 求 $P\{\max\{X, Y\} \geqslant 1\}$.

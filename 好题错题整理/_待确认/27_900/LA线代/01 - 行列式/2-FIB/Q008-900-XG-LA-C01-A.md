# FIB 第 8 题

![[_Attachments/题目识别/900-XG/900-XG-LA-C01-A-Q008_题目.png|题目]]

已知 3 阶矩阵 $A = \left( \alpha_1, \alpha_2, \alpha_3 \right)$，且 $|A| \neq 0$。若 $A^2 = \left( \alpha_1 + \alpha_2 + \alpha_3, \alpha_1 + 2\alpha_2 + 4\alpha_3, \alpha_1 + 3\alpha_2 + 9\alpha_3 \right)$，则 $|A| = \_$.


---

## 答案

![[_Attachments/题目识别/900-答案/900-XG-LA-C01-A-Q008_答案.png|答案]]

## V4 Flash Max 解析

**答案**：$|A| = 2$。

**解题切入点**：$A$ 按列写为 $(\alpha_1,\alpha_2,\alpha_3)$，且 $|A|\ne 0$ 说明 $\alpha_1,\alpha_2,\alpha_3$ 是 $\mathbb{R}^3$ 的一组基。于是每个 $A\alpha_j$ 都可在"基 $(\alpha_1,\alpha_2,\alpha_3)$ 下"唯一表示，表示系数刚好组成一个过渡矩阵 $M$。把"$A^2 = A\cdot A$ 的列"与"用 $M$ 表示"这两件事对上，**两边取行列式**就消去基向量，直接得到 $\det A = \det M$。这很像算法题里"换一组坐标基底仍守恒某个量"——行列式就是坐标变换不变量（乘上过渡矩阵行列式）。

**推演**：$A^2 = A\cdot A = A(\alpha_1,\alpha_2,\alpha_3)$，其第 $j$ 列恰为 $A\alpha_j$。题给 $A^2$ 的列是：
$$\begin{aligned}
A\alpha_1 &= \alpha_1+\alpha_2+\alpha_3,\\
A\alpha_2 &= \alpha_1+2\alpha_2+4\alpha_3,\\
A\alpha_3 &= \alpha_1+3\alpha_2+9\alpha_3.
\end{aligned}$$
把上面三式写成"基右乘系数矩阵"的形式：
$$A^2 = (\alpha_1,\alpha_2,\alpha_3)\begin{pmatrix}1&1&1\\1&2&3\\1&4&9\end{pmatrix}=(\alpha_1,\alpha_2,\alpha_3)M,$$
其中 $M=\begin{pmatrix}1&1&1\\1&2&3\\1&4&9\end{pmatrix}$。

另一方面 $A^2 = A\cdot A = A(\alpha_1,\alpha_2,\alpha_3)$。两种写法相等：
$$A(\alpha_1,\alpha_2,\alpha_3) = (\alpha_1,\alpha_2,\alpha_3)M.$$
两边取行列式（$\det$ 对乘积分配）：
$$|A|\cdot|(\alpha_1,\alpha_2,\alpha_3)| = |(\alpha_1,\alpha_2,\alpha_3)|\cdot|M|.$$
因 $|A|\ne 0$，基向量组成的 $(\alpha_1,\alpha_2,\alpha_3)$ 可逆，$|(\alpha_1,\alpha_2,\alpha_3)|\ne 0$，约去得：
$$|A| = |M|.$$

再算 $|M|$（三阶直接展开）：
$$|M| = \begin{vmatrix}1&1&1\\1&2&3\\1&4&9\end{vmatrix}
= 1(18-12) - 1(9-3) + 1(4-2) = 6 - 6 + 2 = 2.$$
故 $|A| = 2$。

**易错点**：
- 常见错误：把 $A^2$ 的三个列误当作 $A\alpha_j$ 却写出 $\alpha_j$ 在标准基下的表示，丢失了"基 $(\alpha_1,\alpha_2,\alpha_3)$"这一前提。注意题中只给列向量的**线性组合**形式，必须把它翻译成"关于基 $(\alpha_1,\alpha_2,\alpha_3)$ 的坐标"，系数矩阵即 $M$。
- 常见错误：直接设 $A$ 为一个具体矩阵去硬算，或误判列与行的顺序——$M$ 的第 $j$ 列是 $A\alpha_j$ 展成基时的坐标列。
- 自检：$M$ 若主对角方向交换是否会变？展开 $|M|=2$，可再按提公因"第一行 $\times 1$，$\alpha$ 变式"复核一次。并验证 $|A|\ne0$ 的条件被用上（约 $|(\alpha_1,\alpha_2,\alpha_3)|$ 时依赖），说明结论自洽。

**命题规律**：本质是"线性变换在某组基下的表示矩阵 + 行列式是线性变换不变量的模"。命题角度常见三条：(1) 给定 $A\alpha_j$ 的线性组合求 $|A|$ 或 $\operatorname{tr}(A)$；(2) 把 $A$ 换成 $A^{-1}$ 或伴随，结合"在参数向量下的表示"；(3) 与特征值联系——上题中 $\alpha_1,\alpha_2,\alpha_3$ 一旦独立且 $A\alpha_j$ 恰为该 $\alpha$ 的组合，就类似"谱"。变式常把 $M$ 做成范德蒙德矩阵或可分离形式，此时 $|A|$ 直接读出。联系知识点：坐标变换公式、相似矩阵、行列式的"乘性"。

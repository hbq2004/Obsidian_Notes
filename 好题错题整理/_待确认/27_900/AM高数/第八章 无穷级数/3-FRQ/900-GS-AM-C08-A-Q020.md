# FRQ 第 20 题

![[_Attachments/题目识别/900-GS/900-GS-AM-C08-A-Q020_题目.png|题目]]

$$2 0 \text{记} a _ { n } = \int _ { 0 } ^ { \frac { \pi } { 4 } } \tan ^ { n } x d x . \text{证明} :\infty (I) \text{级数} \sum\limits _ { n = 1 } ^ { \infty } a _ { n } \text{发散}; \infty (II) \text{级数} \sum\limits _ { n = 1 } ^ { \infty } (- 1 ) ^ { n } a _ { n } \text{条件收敛}. $$


---

## 答案

![[_Attachments/题目识别/900-答案/900-GS-AM-C08-A-Q020_答案.png|答案]]

## V4 Flash Max 解析

**答案**: (I) $\sum a_n$ 发散;(II) $\sum(-1)^n a_n$ 条件收敛。

**解题切入点**: 这是"含参数 $n$ 的积分作通项"的级数题。第一步把它放到"标准可判定的形式"里:$a_n=\int_0^{\pi/4}\tan^n x\,dx$,作 $t=\tan x$ 换元立刻 $a_n=\int_0^1\dfrac{t^n}{1+t^2}dt$。这一下就与经典的"$\int_0^1 t^n g(t)dt\sim\dfrac{g(1)}{n}$"相接,直接给出量阶 $a_n\sim\dfrac1{2n}$。核心类比是"积分级数判敛 = 把积分量级估计成单项式/阶乘/等比,再套同敛散级数"。(II) 判断条件收敛就是"莱布尼茨条件 + 查绝对部分是否发散"两步。

**推演**:

换元 $t=\tan x$,则 $dx=\dfrac{dt}{1+t^2}$,$t\in[0,1]$:
$$
a_n=\int_0^1\frac{t^n}{1+t^2}\,dt.
$$

(I) 估计 $a_n$ 的量级。$\dfrac{1}{1+t^2}$ 在 $[0,1]$ 上连续,$\dfrac12\le\dfrac{1}{1+t^2}\le1$。一方面
$$
\int_0^1\frac{t^n}{1+t^2}dt\le\int_0^1 t^n dt=\frac{1}{n+1}.
$$
另一方面,对任意 $0<\delta<1$,
$$
\int_0^1\frac{t^n}{1+t^2}dt\ge\int_{1-\delta}^{1}\frac{t^n}{2}dt\ge\frac{(1-\delta)^n}{2}\delta.
$$
但更精确地,可证 $a_n$ 与 $\dfrac{1}{n}$ 同量级。因为对 $t\in[0,1]$,$\dfrac{1}{1+t^2}\ge\dfrac12$,故
$$
a_n\ge\frac12\int_0^1 t^n dt=\frac{1}{2(n+1)},
$$
而 $a_n\le\int_0^1 t^n dt=\dfrac{1}{n+1}$。因此
$$
\frac{1}{2(n+1)}\le a_n\le\frac{1}{n+1},
$$
即 $a_n\sim\dfrac{1}{n}$。由比较判别法,$\sum a_n$ 与调和级数 $\sum\dfrac1n$ 同敛散,故(I)发散。

(II) 先看绝对收敛性:由(I)知 $\sum a_n$ 发散,故 $\sum(-1)^n a_n$ 不绝对收敛。再看原级数:
- $a_n>0$,且
$$
a_{n+1}=\int_0^{\pi/4}\tan^{n+1}x\,dx\le\int_0^{\pi/4}\tan^n x\,dx=a_n,
$$
(因 $0\le\tan x\le1$,故 $\tan^{n+1}x\le\tan^n x$),即 $\{a_n\}$ 单调递减;
- $\lim a_n=0$ 由 $a_n\le\dfrac{1}{n+1}$ 立得。

交错级数 $\sum(-1)^n a_n$ 满足莱布尼茨判别法条件,故收敛。综上它条件收敛。

**易错点**: (I) 容易只证 $a_n\le\dfrac1{n+1}$(只能说明部分和有界不足以否定发散)误以为可比出收敛——必须给出**下界**才能判发散,即证 $a_n\ge\dfrac{1}{2(n+1)}$,用"同量级 + 与 $\sum\dfrac1n$ 同敛散"闭环。自检:$\sum\dfrac{1}{2(n+1)}$ 发散 ⇒ $\sum a_n$ 发散合理。(II) 别漏记"条件收敛 = 收敛 + 不绝对收敛"两层都要验证;$a_n$ 的单调递减源于 $\tan x\le1$,易漏这一步。

**命题规律**: "$\int_0^c(\tan x)^n\,dx$ 一类的收敛性"本质是 $a_n\sim\dfrac{\text{常数}}{n}$,发散;而 $\int_0^1 x^n dx=\dfrac1{n+1}$,除 $n$ 外;$\int_0^1(1-x)^n dx=\dfrac1{n+1}$ 也是同款。变式常把 $\tan x$ 换成 $\sin x$、$e^{-x}$ 等,量级依赖被积函数在积分区间上界点的取值。本题把"积分通项级数"与"莱布尼茨交错判别"串成一道两问,是考试高频组合。

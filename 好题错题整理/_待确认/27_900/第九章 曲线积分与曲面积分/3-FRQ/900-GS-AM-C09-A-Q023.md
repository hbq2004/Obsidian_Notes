# FRQ 第 23 题

![[_Attachments/题目识别/900-GS/900-GS-AM-C09-A-Q023_题目.png|题目]]

$$ 23 \text{设曲面} \Sigma \text{为单位球面} x^{2}+y^{2}+z^{2}=1 \text{的外侧}, \text{函数} f(x) \text{是定义在} [-1,1] \text{上的连续奇函数}, \text{计算曲} $$

面积分 $I=\iint_{\Sigma} x[f(z)+1] d y ~d z+y[f(z)-1] d z ~d x+z[f(z)+1] d x ~d y$ .

## 答案

![[_Attachments/题目识别/900-答案/900-GS-AM-C09-A-Q023_答案.png|答案]]

## V4 Flash Max 解析

**答案**: $I = \dfrac{4\pi}{3}$。$f$ 的贡献全部抵消,只剩线性部分 $x\,dy\,dz - y\,dz\,dx + z\,dx\,dy$ 对应的常值散度积分。

**解题切入点**: 被积函数里 $f(z)$ 夹在 $x,y,z$ 一次项里,整体结构是 $(x\,g,\ y\,h,\ z\,g)$ 这种"坐标×函数"形式,天然适合**高斯公式(散度定理)**。关键是看出:线性部分($\pm1$)可精确积分,而 $f$ 部分利用"奇函数在对称区间积分(竖向积分分层)为零"这个对称性消掉。这相当于算法里的**对称剪枝** —— 先判断哪些项贡献必为零,再算剩下的。

**推演**:
1. **用高斯公式化三重积分**。$\Sigma$ 为单位球外侧,$\Omega$ 为单位球体。记
$P = x[f(z)+1],\ Q = y[f(z)-1],\ R = z[f(z)+1]$,
$$I=\iiint_\Omega\Big(\frac{\partial P}{\partial x}+\frac{\partial Q}{\partial y}+\frac{\partial R}{\partial z}\Big)\,dV.$$
计算偏导:$\frac{\partial P}{\partial x}=f(z)+1$,$\frac{\partial Q}{\partial y}=f(z)-1$,$\frac{\partial R}{\partial z}=f(z)+1+z f'(z)$,故
$$\text{div}=3f(z)+1+z f'(z).$$
(严格说高斯公式要求 $f\in C^1$;本题只给连续,可用一列光滑奇函数逼近 $f$ 取极限,结论一致。)

2. **线性常数部分** $\iiint_\Omega 1\,dV = \frac43\pi$。

3. **$f$ 部分归零**。由奇函数性质:
$$\iiint_\Omega 3f(z)\,dV = \int\!\!\int_{D_{xy}}\Big[\int_{-h}^{h}3f(z)dz\Big]dx\,dy = 0,\qquad h=\sqrt{1-x^2-y^2},$$
因为 $\int_{-h}^{h}f(z)\,dz = 0$($f$ 奇)。

4. **$z f'(z)$ 项**。对固定 $(x,y)$,对竖向分层积分并用分部积分:
$$\int_{-h}^{h}z\,f'(z)\,dz = \big[z f(z)\big]_{-h}^{h}-\int_{-h}^{h}f(z)\,dz = h f(h)+h f(-h)-0 = 0,$$
最后一步因 $f$ 奇($f(-h)=-f(h)$)。故 $\iiint_\Omega z f'(z)\,dV=0$。

5. 综上 $I = \frac43\pi$。

**自检**: 令 $f\equiv 0$,退化为 $\iint_\Sigma x\,dy\,dz - y\,dz\,dx + z\,dx\,dy = \iiint_\Omega(1-1+1)dV=\frac43\pi$ ✓,与一般结论(对球面 $\iint_\Sigma z\,dxdy$ 等)一致。

**易错点**:
- 误以为需要 $f$ 可导而卡住。实际只需用"竖向分层 + 奇函数对称"消去 $f$ 与 $z f'$ 的贡献;若严谨,用光滑奇函数逼近说明连续情形也成立。
- 分部积分符号:$\int_{-h}^h z f'(z)dz = [zf(z)]_{-h}^h - \int_{-h}^h f(z)dz$,后项为 $0$,前项代入上下限时注意 $(-h)f(-h)=(-h)(-f(h))=h f(h)$,故两项相消。
- 常数部分散度别算错:$1-1+1=1$。
- 自检:取 $f(z)=z$(奇函数),坐标 $x f dydz$ 等项目在球面上外法向导数意义下的积分,代入后发现线性与 $f$ 部分仍整体为 $\frac43\pi$。

**命题规律**: 这是"被积函数含抽象函数 + 高斯公式 + 奇偶对称"的经典组题角度。命题者常给出 $f$ 奇可微,让你被"抽象函数"吓住,实则利用对称性把 $f$ 部分集体消零,只留线性项。常见变式:球心在原点且积分区域关于坐标面对称时,利用 $f$ 奇或偶一次性消去若干项;或把 $f(z)$ 换成 $f(x,y)$ 用球对称。联系到:高斯公式(散度)、三重积分计算、被积函数的奇偶对称简化。

# FRQ 第 15 题

![[_Attachments/题目识别/900-XG/900-XG-LA-C05-A-Q015_题目.png|题目]]

设 $\alpha, \beta, \gamma$ 是 3 阶矩阵 $A$ 的 3 个特征向量，其中 $\beta$ 与 $\gamma$ 为属于不同特征值的特征向量。方程组 $Ax = \beta + \gamma$ 的通解为 $x = k\alpha + \beta + \frac{1}{3}\gamma$，其中 $k$ 为任意常数。

(I) 求方程组 $Ax = \beta - \gamma$ 的通解；

(II) 若 $\alpha = (1, 1, 1)^T$，且 $A$ 的伴随矩阵 $A^*$ 为对称矩阵，求 $A^*$.

# FRQ 第 22 题

![[_Attachments/题目识别/1000-XG/1000-XG-TFDD056-Q022_题目.png|题目]]

22. (本题满分 12 分)

设随机变量 $(X, Y)$ 的概率密度为 $f(x, y) = \begin{cases} a\left(x^2 + \frac{xy}{2}\right), & 0 < x < 1, 0 < y < 2, \\ 0, & 其他. \end{cases}$

(1) 求 $a$ 的值;

(2) $X, Y$ 是否相互独立，说明理由;

(3) 计算 $P\left\{Y > 1 \mid X = \frac{1}{2}\right\}$.

## V4 Flash Max 解析

**答案**  
(1) $a=\dfrac{6}{7}$。  
(2) $X,Y$ 不独立。理由：$f_X(x)f_Y(y)\neq f(x,y)$，例如在 $x=\frac12,y=\frac12$ 处二者不相等。  
(3) $P\left\{Y>1\mid X=\frac12\right\}=\dfrac{5}{8}$。

**解题切入点**  
第一问密度含未知常数，直接利用“全平面积分等于 $1$”归一化，这类似于算法竞赛中概率 DP 先让所有状态概率和为 $1$。第二问判断独立，核心是看联合密度能否写成 $f_X(x)f_Y(y)$，不能只看支撑区域是不是矩形。第三问是连续型条件概率，必须用条件密度  
$$f_{Y|X}(y|x)=\frac{f(x,y)}{f_X(x)},$$  
不能直接写 $\frac{P(Y>1,X=1/2)}{P(X=1/2)}$，否则是 $\frac00$。

**推演**  
1. 求 $a$：

$$1=\int_0^1\int_0^2 a\left(x^2+\frac{xy}{2}\right)\,dy\,dx.$$

先算内层积分：

$$\int_0^2 \left(x^2+\frac{xy}{2}\right)\,dy
=2x^2+x.$$

所以

$$1=a\int_0^1(2x^2+x)\,dx
=a\left(\frac23+\frac12\right)
=\frac76a,$$

因此

$$a=\frac67.$$

2. 判断独立性：

求边缘密度。

$$f_X(x)=\int_0^2 \frac67\left(x^2+\frac{xy}{2}\right)\,dy
=\frac67(2x^2+x),\quad 0<x<1.$$

$$f_Y(y)=\int_0^1 \frac67\left(x^2+\frac{xy}{2}\right)\,dx
=\frac{4+3y}{14},\quad 0<y<2.$$

若 $X,Y$ 独立，则应有

$$f(x,y)=f_X(x)f_Y(y).$$

取 $x=\frac12,y=\frac12$：

$$f\left(\frac12,\frac12\right)
=\frac67\left(\frac14+\frac18\right)
=\frac{9}{28},$$

而

$$f_X\left(\frac12\right)=\frac67,\qquad
f_Y\left(\frac12\right)=\frac{11}{28},$$

$$f_X\left(\frac12\right)f_Y\left(\frac12\right)
=\frac67\cdot\frac{11}{28}
=\frac{33}{98}\neq \frac{9}{28}.$$

因此 $X,Y$ 不独立。

3. 求条件概率：

当 $0<y<2$ 时，

$$f\left(\frac12,y\right)
=\frac67\left(\frac14+\frac y4\right)
=\frac{3(1+y)}{14}.$$

又

$$f_X\left(\frac12\right)=\frac67,$$

所以

$$f_{Y|X}\left(y\mid \frac12\right)
=\frac{f\left(\frac12,y\right)}{f_X\left(\frac12\right)}
=\frac{\frac{3(1+y)}{14}}{\frac67}
=\frac{1+y}{4}.$$

因此

$$P\left\{Y>1\mid X=\frac12\right\}
=\int_1^2 \frac{1+y}{4}\,dy
=\frac14\left[y+\frac{y^2}{2}\right]_1^2
=\frac58.$$

**易错点**  
- 求 $a$ 时容易漏算 $\frac{xy}{2}$ 对 $y$ 的积分，导致 $a$ 算错。本题内层积分结果是 $2x^2+x$，不是 $2x^2$。  
- 不能因为支撑区域是矩形就说独立；独立必须满足联合密度等于边缘密度乘积。  
- 连续型条件概率不能直接使用 $P(A|B)=\frac{P(AB)}{P(B)}$，因为 $P(X=\frac12)=0$，必须用条件密度。  
- 自检：  
  $$\int_0^1 f_X(x)\,dx=1,\qquad \int_0^2 f_Y(y)\,dy=1,$$  
  且条件密度  
  $$\int_0^2 \frac{1+y}{4}\,dy=1,$$  
  所以 $\frac58$ 是合理的。

**命题规律**  
这类题是考研数学一“二维随机变量”的经典考法：先由归一化求常数，再求边缘密度并判断独立性，最后求条件概率或条件期望。常见变式包括：给定边缘密度反求联合密度、求 $E[Y|X=x]$、计算 $P\{(X,Y)\in D\}$、或进一步求协方差和相关系数。核心思想仍是：连续型联合密度决定一切，条件概率本质上是固定一个变量后，对另一个变量的密度重新归一化。

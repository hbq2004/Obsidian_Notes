# FRQ 第 22 题

![[_Attachments/题目识别/1000-XG/1000-XG-TFDD056-Q022_题目.png|题目]]

22. (本题满分 12 分)

设随机变量 $(X, Y)$ 的概率密度为 $f(x, y) = \begin{cases} a\left(x^2 + \frac{xy}{2}\right), & 0 < x < 1, 0 < y < 2, \\ 0, & 其他. \end{cases}$

(1) 求 $a$ 的值;

(2) $X, Y$ 是否相互独立，说明理由;

(3) 计算 $P\left\{Y > 1 \mid X = \frac{1}{2}\right\}$.

# MCQ 第 2 题

![[_Attachments/题目识别/1000-XG/1000-XG-T7000C5-Q002_题目.png|题目]]

2. 设 $n$ 阶方阵 $A = [\alpha_1, \alpha_2, \cdots, \alpha_n]$，$B = [\beta_1, \beta_2, \cdots, \beta_n]$，$AB = [\gamma_1, \gamma_2, \cdots, \gamma_n]$，记向量组 $I: \alpha_1, \alpha_2, \cdots, \alpha_n,$ 向量组 $J: \beta_1, \beta_2, \cdots, \beta_n$，向量组 $H: \gamma_1, \gamma_2, \cdots, \gamma_n$。如果向量组 $H$ 线性相关，则（）

A. 向量组 $I$ 线性相关

B. 向量组 $H$ 线性相关

C. 向量组 $I$ 与 $H$ 都线性相关

D. 向量组 $I$ 与 $H$ 至少有一个线性相关

---

## 答案

![[_Attachments/题目识别/1000-答案/1000-XG-T7000C5-Q002_答案.png|答案]]

## V4 Pro Max 解析

**答案**：D（即向量组 $I$ 与 $J$ 至少有一个线性相关）

**切入点**：$AB$ 的列向量组线性相关等价于 $|AB|=0$，而 $|AB|=|A|\,|B|$，把"乘积的行列式为零"拆成"两个因子至少一个为零"，正是算法里"$ab=0\Rightarrow a=0$ 或 $b=0$"的矩阵版。

**推演**

记 $A=[\alpha_1,\cdots,\alpha_n]$，$B=[\beta_1,\cdots,\beta_n]$，$AB=[\gamma_1,\cdots,\gamma_n]$。$n$ 阶方阵的列向量组线性相关 $\iff$ 行列式为零（$n$ 个 $n$ 维向量相关 $\iff$ 秩 $<n$ $\iff$ 行列式 $=0$）。

由行列式乘法公式

$$
|AB|=|A|\cdot|B|.
$$

向量组 $H$（即 $AB$ 的列）线性相关 $\iff |AB|=0 \iff |A|=0 \text{ 或 } |B|=0$。

而 $|A|=0\iff$ 向量组 $I$（$A$ 的列）线性相关；$|B|=0\iff$ 向量组 $J$（$B$ 的列）线性相关。故 $H$ 线性相关 $\Rightarrow$ $I$ 与 $J$ **至少有一个**线性相关，选 **D**。

**易错点**：⚠ 选项 B/C/D 中的 "H" 疑为 OCR 对 "J" 的误识（$H$ 已是题干中的 $\gamma$ 组，B 若写作"H 线性相关"则是题干条件的同义反复，无意义）。按经典结论 $|AB|=|A||B|$ 求解，正确结论为"$I$ 与 $J$ 至少有一个线性相关"。注意方向是"至少有一个"，不能断定"两者都相关"，也不能单独断定 $I$ 相关或 $J$ 相关。

**命题规律**：用行列式刻画"$n$ 个 $n$ 维向量线性相关"，再借 $|AB|=|A||B|$ 把乘积相关性与因子相关性联系起来，是行列式与向量组联动的经典命题。

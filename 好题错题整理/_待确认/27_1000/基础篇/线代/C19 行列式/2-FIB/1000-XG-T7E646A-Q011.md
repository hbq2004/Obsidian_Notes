# FIB 第 11 题

![[_Attachments/题目识别/1000-XG/1000-XG-T7E646A-Q011_题目.png|题目]]

11. 设 $A$ 是 3 阶矩阵, $\alpha_1, \alpha_2, \alpha_3$ 是 3 维线性无关列向量, 且满足 $A\alpha_1 = \alpha_1 + 2\alpha_2 + \alpha_3$, $A\alpha_2 = 2\alpha_1 + \alpha_2 + \alpha_3$, $A\alpha_3 = \alpha_1 + \alpha_2 + 2\alpha_3$, 则 $|A| =$ \\_.

---

## 答案

![[_Attachments/题目识别/1000-答案/1000-XG-T7E646A-Q011_答案.png|答案]]

﻿## V4 Pro Max 解析

**答案**：$|A|=-4$

**切入点**：$A$ 在基 $(\alpha_1,\alpha_2,\alpha_3)$ 下的矩阵 $B$ 的列就是 $A\alpha_j$ 的坐标；由 $AP=PB$（$P=[\alpha_1,\alpha_2,\alpha_3]$）得 $|A|=|B|$。类比"换基对角化思想提取不变量"。

**推演**

令 $P=[\alpha_1\ \alpha_2\ \alpha_3]$，则 $AP=PB$，其中
$$B=\begin{pmatrix}1&2&1\\2&1&1\\1&1&2\end{pmatrix}$$
（第 $j$ 列是 $A\alpha_j$ 在 $\alpha_1,\alpha_2,\alpha_3$ 下的坐标）。因 $\alpha$ 线性无关，$P$ 可逆，故 $A=PBP^{-1}$，$|A|=|B|$。
$$|B|=\begin{vmatrix}1&2&1\\2&1&1\\1&1&2\end{vmatrix}=1(2-1)-2(4-1)+1(2-1)=1-6+1=-4.$$

**易错点**：$B$ 的列是"$A\alpha_j$ 用 $\alpha$ 线性表出的系数"，即 $A\alpha_1=\alpha_1+2\alpha_2+\alpha_3$ 对应第 1 列 $(1,2,1)^T$；$|A|=|B|$ 因相似/共轭不改变行列式。

**命题规律**：给定线性变换在无关向量上的像，构造函数矩阵 $B$ 并用 $|A|=|B|$ 求行列式，是"线性变换 + 行列式"的固定考法。

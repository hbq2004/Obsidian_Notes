# FRQ 第 22 题

![[_Attachments/题目识别/1000-XG/1000-XG-TE8D696-Q022_题目.png|题目]]

22. 设 $A$ 是 3 阶矩阵, $\lambda_1, \lambda_2, \lambda_3$ 是 $A$ 的三个不同的特征值, 对应的特征向量分别是 $\xi_1, \xi_2, \xi_3$, 令 $\beta = \xi_1 + \xi_2 + \xi_3$. 证明:

(1) $\beta$ 不是 $A$ 的特征向量;

(2) 向量组 $\beta, A\beta, A^2\beta$ 线性无关.

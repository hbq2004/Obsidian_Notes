# MCQ 第 22 题

![[_Attachments/题目识别/1000-XG/1000-XG-TD64015-Q022_题目.png|题目]]

22. 下列二次型中,属于正定二次型的是().

A. $f_1(x_1, x_2, x_3, x_4) = (x_1 - x_2)^2 + (x_2 - x_3)^2 + (x_3 - x_4)^2 + (x_4 - x_1)^2$

B. $f_2(x_1, x_2, x_3, x_4) = (x_1 + x_2)^2 + (x_2 + x_3)^2 + (x_3 + x_4)^2 + (x_4 + x_1)^2$

C. $f_3(x_1, x_2, x_3, x_4) = (x_1 - x_2)^2 + (x_2 + x_3)^2 + (x_3 - x_4)^2 + (x_4 + x_1)^2$

D. $f_4(x_1, x_2, x_3, x_4) = (x_1 - x_2)^2 + (x_2 + x_3)^2 + (x_3 + x_4)^2 + (x_4 + x_1)^2$

---

## 答案

![[_Attachments/题目识别/1000-答案/1000-XG-TD64015-Q022_答案.png|答案]]

## V4 Pro Max 解析

**答案**：D（$f_4$）。

**切入点**：每个 $f_i$ 都是平方和，故半正定；正定 ⟺ 各线性形式无公共非零零点，即对应齐次线性方程组只有零解。类比算法竞赛：判定"齐次方程组只有平凡解"即判定矩阵满秩。

**推演**

逐项令四式为零，看是否存在非零解：

A：$x_1=x_2=x_3=x_4=x_1$，有非零解 $(1,1,1,1)$，非正定。

B：$x_1=-x_2,\ x_2=-x_3,\ x_3=-x_4,\ x_4=-x_1$，有非零解 $(1,-1,1,-1)$，非正定。

C：$x_1=x_2,\ x_2=-x_3,\ x_3=x_4,\ x_4=-x_1$，有非零解 $(1,1,-1,-1)$，非正定。

D：$x_1=x_2,\ x_2=-x_3,\ x_3=-x_4,\ x_4=-x_1$，迭代得 $x_1=-x_1\Rightarrow x_1=0$，进而全为零，仅零解，故 $f_4$ 正定。

**易错点**：平方和二次型 $f\ge0$ 恒成立，正定与否完全取决于"取到 $0$ 时是否只有 $x=0$"；判定时看的是线性形式的系数矩阵是否满秩（$r=4$），而非平方项个数。

**命题规律**：$f=\sum_i\ell_i(x)^2$ 正定 ⟺ 线性形式组 $\{\ell_i\}$ 的系数矩阵列满秩 ⟺ 齐次方程组 $\ell_i=0$ 只有零解；这是"二次型正定"与"线性方程组解"的又一桥梁。

# FRQ 第 6 题

![[_Attachments/题目识别/1000-XG/1000-XG-TD64015-Q006_题目.png|题目]]

6. 设 $f(x_1, x_2, x_3) = [x_1 + (a-2)x_2 - 2x_3]^2 + [x_1 + ax_2 + x_3]^2 + [x_1 + ax_2 + (a-2)x_3]^2$。求：

(1) 方程 $f(x_1, x_2, x_3) = 0$ 的解；

(2) 二次型 $f(x_1, x_2, x_3)$ 的规范形.

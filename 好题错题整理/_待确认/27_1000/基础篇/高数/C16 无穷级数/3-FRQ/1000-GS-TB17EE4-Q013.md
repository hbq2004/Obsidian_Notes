$$1 3 . \sum\limits_{n = 2}^{\infty} \frac { 1 } { \left( n ^ { 2 } - 1 \right) 2 ^ { n } } =$$

## 答案

![[_Attachments/题目识别/1000-答案/1000-GS-TB17EE4-Q013_答案.png|答案]]

## V4 Pro Max 解析

**答案**：$\dfrac58-\dfrac34\ln 2$。

**切入点**：分母 $n^2-1=(n-1)(n+1)$ 可拆，先部分分式分解把一项拆成两项，再分别用 $-\ln(1-x)$ 展开式求和——"拆分降维再套模板"，和算法竞赛里"把复杂结构拆成可独立处理子问题"同理。

**推演**

部分分式分解：

$$\frac{1}{n^{2}-1}=\frac{1}{(n-1)(n+1)}=\frac12\left(\frac{1}{n-1}-\frac{1}{n+1}\right)$$

于是

$$\sum_{n=2}^{\infty}\frac{1}{(n^{2}-1)2^{n}}=\frac12\left[\sum_{n=2}^{\infty}\frac{1}{(n-1)2^{n}}-\sum_{n=2}^{\infty}\frac{1}{(n+1)2^{n}}\right]$$

第一项：令 $m=n-1$，

$$\sum_{n=2}^{\infty}\frac{1}{(n-1)2^{n}}=\sum_{m=1}^{\infty}\frac{1}{m\,2^{m+1}}=\frac12\sum_{m=1}^{\infty}\frac{1}{m\,2^{m}}=\frac12\ln 2$$

第二项：令 $m=n+1$，

$$\sum_{n=2}^{\infty}\frac{1}{(n+1)2^{n}}=\sum_{m=3}^{\infty}\frac{1}{m\,2^{m-1}}=2\sum_{m=3}^{\infty}\frac{1}{m\,2^{m}}=2\left(\ln 2-\frac12-\frac18\right)=2\ln 2-\frac54$$

其中用了 $\sum_{m=1}^{\infty}\dfrac{1}{m2^m}=\ln2$，并扣掉 $m=1,2$ 两项（$\tfrac12,\tfrac18$）。

代回：

$$\text{原式}=\frac12\left[\frac12\ln 2-\left(2\ln 2-\frac54\right)\right]=\frac12\left(\frac54-\frac32\ln 2\right)=\frac58-\frac34\ln 2$$

**易错点**：两处换元的下限不同（$m\ge1$ 与 $m\ge3$），第二处必须扣两项；部分分式前面的系数 $\dfrac12$ 别丢。

**命题规律**：分母可因式分解（尤其 $n^2-1$、$n^2+a^2$）的数项级数，套路固定——先拆分、再逐个套 $-\ln(1-x)$ 或 $\ln(1+x)$ 展开式，注意各自起点的回补项。

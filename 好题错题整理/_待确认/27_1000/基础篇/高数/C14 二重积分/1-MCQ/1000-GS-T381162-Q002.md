# MCQ 第 2 题

![[_Attachments/题目识别/1000-GS/1000-GS-T381162-Q002_题目.png|题目]]

2. 设 $I_i = \iint_{D_i} e^{-(x^2 + y^2)} d\sigma, i = 1, 2, 3$，其中 $D_1 = \{(x, y) | x^2 + y^2 \leq R^2\}$，$D_2 = \{(x, y) | x^2 + y^2 \leq 2R^2\}$，$D_3 = \{(x, y) x \leq R, |y \leq R\}$，$R > 0$，则（）

A. $I_1 < I_2 < I_3$

B. $I_2 < I_3 < I_1$

C. $I_1 < I_3 < I_2$

D. $I_3^- < I_2 < I_1$

---

## 答案

![[_Attachments/题目识别/1000-答案/1000-GS-T381162-Q002_答案.png|答案]]

## V4 Pro Max 解析

**答案**：C（$I_1<I_3<I_2$）

**切入点**：被积函数 $e^{-(x^2+y^2)}>0$ 恒正，故积分随区域“单调”——区域包含得越多、积分越大，只需比出三个区域的包含关系（像集合包含的偏序）。

**推演**

- $D_1=\{x^2+y^2\le R^2\}$（半径 $R$ 的圆）；
- $D_2=\{x^2+y^2\le2R^2\}$（半径 $\sqrt2R$ 的圆）；
- $D_3=\{|x|\le R,\,|y|\le R\}$（边长为 $2R$ 的正方形）。

关系：$D_1\subset D_3\subset D_2$。理由：圆 $D_1$ 上 $|x|\le R,|y|\le R$，故 $D_1\subset D_3$；正方形顶点 $(\pm R,\pm R)$ 满足 $x^2+y^2=2R^2$，落在 $D_2$ 边界上，故 $D_3\subset D_2$。

因 $e^{-(x^2+y^2)}>0$，区域越大积分越大，故 $I_1<I_3<I_2$。

**易错点**：⚠ 题干 $D_3$ 的 `|y≤R` 疑为 `|y|≤R`（OCR 丢失左竖线），已按正方形 $[-R,R]^2$ 理解；选项 D 的 `I_3^-` 为 OCR 噪声。被积函数恒正才能用“区域越大值越大”。

**命题规律**：正被积函数比较积分，先比区域包含关系；圆与正方形的包含用顶点/边界点验证。

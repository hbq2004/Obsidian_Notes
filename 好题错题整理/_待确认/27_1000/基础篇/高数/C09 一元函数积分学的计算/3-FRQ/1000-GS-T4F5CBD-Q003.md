# FRQ 第 3 题

![[_Attachments/题目识别/1000-GS/1000-GS-T4F5CBD-Q003_题目.png|题目]]

3. 计算不定积分 $\int \ln\left(1 + \sqrt{\frac{1 + x}{x}}\right) dx (x > 0)$.

---

## 答案

![[_Attachments/题目识别/1000-答案/1000-GS-T4F5CBD-Q003_答案.png|答案]]

## V4 Pro Max 解析

**答案**：$x\ln(1+t)+\dfrac14\ln\dfrac{t+1}{t-1}-\dfrac{1}{2(t+1)}+C$，其中 $t=\sqrt{\dfrac{1+x}{x}}$

**切入点**：对数里套根式，先令 $t=\sqrt{\dfrac{1+x}{x}}$ 把结构变简单，再对 $\ln(1+t)$ 分部积分（让 $x$ 当 $v$）。像算法里「换元降复杂 + 分部消对数」。

**推演**

令 $t=\sqrt{\dfrac{1+x}{x}}=\sqrt{1+\dfrac1x}\ (>1)$，则 $t^2=1+\dfrac1x$，$x=\dfrac{1}{t^2-1}$，$dx=-\dfrac{2t}{(t^2-1)^2}dt$。

$$\int\ln\left(1+\sqrt{\frac{1+x}{x}}\right)dx=\int\ln(1+t)\,dx\ \overset{\text{分部}}{=}\ x\ln(1+t)-\int\frac{x}{1+t}\,dt$$

其中

$$\frac{x}{1+t}=\frac{1}{(t^2-1)(1+t)}=\frac{1}{(t-1)(t+1)^2}=\frac{1/4}{t-1}-\frac{1/4}{t+1}-\frac{1/2}{(t+1)^2}$$

故

$$\int\frac{x}{1+t}\,dt=\frac14\ln(t-1)-\frac14\ln(t+1)+\frac{1}{2(t+1)}+C$$

代回：

$$\int\ln\left(1+\sqrt{\frac{1+x}{x}}\right)dx=x\ln(1+t)-\frac14\ln(t-1)+\frac14\ln(t+1)-\frac{1}{2(t+1)}+C$$

**易错点**：① 换元时 $x=\dfrac1{t^2-1}$ 的微分 $dx=-\dfrac{2t}{(t^2-1)^2}dt$ 负号易丢，但分部后最终形式已合并；② 部分分式 $\dfrac1{(t-1)(t+1)^2}$ 的三项系数 $(\frac14,-\frac14,-\frac12)$ 要算准；③ 结果可写成 $x\ln(1+t)+\dfrac14\ln\dfrac{t+1}{t-1}-\dfrac1{2(t+1)}$，注意最后一项符号。

**命题规律**：复合对数 + 无理式的换元积分，套路「换元 + 分部 + 部分分式」三连。此类题答案较长，属强化型综合积分。

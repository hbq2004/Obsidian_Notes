# FRQ 第 4 题

![[_Attachments/题目识别/1000-GS/1000-GS-TA131F4-Q004_题目.png|题目]]

4. 设 $x_0 > 0$，$x_{n+1} = \frac{1}{2} \left( x_n + \frac{a}{x_n} \right)$（$n = 0, 1, 2, \cdots$），且 $a > 0$，证明 $\lim\limits_{n \to \infty} x_n$ 存在，并求此极限.

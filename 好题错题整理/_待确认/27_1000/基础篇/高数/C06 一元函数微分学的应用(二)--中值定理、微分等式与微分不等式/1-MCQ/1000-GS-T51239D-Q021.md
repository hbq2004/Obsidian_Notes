# MCQ 第 21 题

![[_Attachments/题目识别/1000-GS/1000-GS-T51239D-Q021_题目.png|题目]]

21. 设 $a_0 + \frac{a_1}{2} + \cdots + \frac{a_n}{n+1} = 0$（$a_i$ 为实数，$i = 0, 1, 2, \cdots, n$），则在区间 (0,1) 内，方程 $a_0 + a_1 x + \cdots + a_n x^n = 0$。

A. 没有实根
B. 至少有一个实根
C. 仅有一个实根
D. 是否有实根不能判定

---

## 答案

![[_Attachments/题目识别/1000-答案/1000-GS-T51239D-Q021_答案.png|答案]]

## V4 Pro Max 解析

**答案**：B（至少有一个实根）

**切入点**：条件 $\sum_{i=0}^n\frac{a_i}{i+1}=0$ 恰是多项式 $a_0x+\frac{a_1}{2}x^2+\cdots+\frac{a_n}{n+1}x^{n+1}$ 在 $x=1$ 的取值，且它在 $x=0$ 取 0。两端同为零 → 罗尔定理，构造原函数是"逆用求导"的构造题思维。

**推演**

构造函数

$$F(x)=a_0x+\frac{a_1}{2}x^2+\cdots+\frac{a_n}{n+1}x^{n+1}.$$

则 $F(x)$ 在 $[0,1]$ 上连续、$(0,1)$ 内可导，且

$$F(0)=0,\qquad F(1)=a_0+\frac{a_1}{2}+\cdots+\frac{a_n}{n+1}=0.$$

即 $F(0)=F(1)$。由罗尔定理，存在 $\xi\in(0,1)$ 使 $F'(\xi)=0$。而

$$F'(x)=a_0+a_1x+\cdots+a_nx^n,$$

故 $a_0+a_1\xi+\cdots+a_n\xi^n=0$，即方程 $a_0+a_1x+\cdots+a_nx^n=0$ 在 $(0,1)$ 内至少有一个实根。选 **B**。

**易错点**：① 不能从"$\sum\frac{a_i}{i+1}=0$"直接断定多项式有几个根——只能保证至少一个，无法推出"仅有一个"，故 C 错误、D（不能判定）也错；② 构造的 $F(x)$ 是逐项积分（$\int a_i x^i dx=\frac{a_i}{i+1}x^{i+1}$），即"由系数除以 $(i+1)$ 反推原函数"，方向不能记反。

**命题规律**：给"系数加权和为 0"证"多项式在 $(0,1)$ 内有根"，标准套路是构造 $F(x)$ 使其 $F'$ 为原多项式且 $F(0)=F(1)=0$，再用罗尔定理——"原函数 + 罗尔"是方程根存在性的核心模板。

# FRQ 第 4 题

![[_Attachments/题目识别/1000-GS/1000-GS-TB8A71A-Q004_题目.png|题目]]

4. 设 $M = \int_{-\frac{1}{2}}^{\frac{1}{2}} \left( 1 + \frac{x}{1 + x^2} \right) dx$，$N = \int_{0}^{1} \frac{(1 + x) \ln^2 (1 + x)}{x^2} dx$，$K = \int_{0}^{1} \frac{e^x}{1 + x} dx$，则（）.

---

## 答案

![[_Attachments/题目识别/1000-答案/1000-GS-TB8A71A-Q004_答案.png|答案]]

## V4 Pro Max 解析

**答案**：$N<M<K$（即 $M=1$，$N<1$，$K>1$）

**切入点**：三个定积分不直接算，用「奇偶性 + 放缩」比大小。$M$ 里 $x/(1+x^2)$ 是奇函数直接消掉；$N$ 的被积函数与 $1$ 比大小；$K$ 利用 $e^x>1+x$ 放缩。像算法里「不暴力枚举，先做剪枝与上下界估计」。

**推演**

$$M=\int_{-\frac12}^{\frac12}\left(1+\frac{x}{1+x^2}\right)dx=\int_{-\frac12}^{\frac12}1\,dx+\int_{-\frac12}^{\frac12}\frac{x}{1+x^2}\,dx=1+0=1$$

（第二项为奇函数在对称区间上的积分，等于 $0$。）

对 $N=\displaystyle\int_0^1\frac{(1+x)\ln^2(1+x)}{x^2}dx$：作 $g(x)=\dfrac{x}{\sqrt{1+x}}-\ln(1+x)$，则 $g(0)=0$ 且

$$g'(x)=\frac{1+\frac x2}{(1+x)^{3/2}}-\frac1{1+x}>0\quad(x>0)$$

（因 $(1+\frac x2)^2>1+x$），故 $g(x)>0$，即 $\ln(1+x)<\dfrac{x}{\sqrt{1+x}}$，从而 $(1+x)\ln^2(1+x)<x^2$，即被积函数 $<1$，于是 $N<\int_0^1 1\,dx=1=M$。

对 $K=\displaystyle\int_0^1\frac{e^x}{1+x}dx$：由 $e^x>1+x$ 得 $\dfrac{e^x}{1+x}>1$，故 $K>\int_0^1 1\,dx=1=M$。

综上 $N<M<K$。

**易错点**：⚠ 题干选项缺失（笔记为 FRQ 目录但问「则( )」，选项未列出），已按比较 $M,N,K$ 大小作答。核心易错：① 忽略 $x/(1+x^2)$ 的奇偶性去硬算 $M$；② $N$ 的估计要证被积函数 $<1$ 而非凭感觉；③ $\ln(1+x)<x$ 是最基础放缩，但这里需更精细的 $\ln(1+x)<x/\sqrt{1+x}$ 才能与 $1$ 比。

**命题规律**：定积分比较大小，套路是「奇偶性化简 + 被积函数放缩 + 常数基准」。$e^x>1+x$、$\ln(1+x)<x$、奇函数对称区间积分为零是三大常用工具。

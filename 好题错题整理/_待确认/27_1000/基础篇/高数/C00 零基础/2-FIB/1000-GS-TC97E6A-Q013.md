# FIB 第 13 题

![[_Attachments/题目识别/1000-GS/1000-GS-TC97E6A-Q013_题目.png|题目]]

\&13. 已知 $|x_1 - 3| < 1, |x_2 - 3| < 1.$ 求证:
（1）$4 < x_1 + x_2 < 8, |x_1 - x_2| < 2$;
（2）若 $f(x) = x^2 - x + 1$，且 $x_1 ≠ x_2$，则 $|x\_1 - x\_2| < |f(x\_1) - f(x\_2)| < 7|x\_1 - x\_2|.\\$

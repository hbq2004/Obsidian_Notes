# MCQ 第 2 题

![[_Attachments/题目识别/1000-GS/1000-GS-T95B800-Q002_题目.png|题目]]

$\begin{array}{l}2. 设有直线 L: \left\{ \begin{array}{l} x + 3y + 2z + 1 = 0, \\ 2x - y - 10z + 3 = 0 \end{array}  及平面 \pi: 4x - 2y + z - 2 = 0 ，则直线 L (). \end{array}$

A. 平行于 $\pi$

B. 在 $\pi$ 上

C. 垂直于 $\pi$

D. 与 $\pi$ 斜交

---

## 答案

![[_Attachments/题目识别/1000-答案/1000-GS-T95B800-Q002_答案.png|答案]]

## V4 Pro Max 解析

**答案**：C（直线 $L$ 垂直于平面 $\pi$）

**切入点**：直线方向向量 = 两平面法向量的叉积；再与平面法向量比较方向即可判断位置关系（类比"叉积判方向、点积判夹角"）。

**推演**

两平面法向量 $n_1=(1,3,2)$，$n_2=(2,-1,-10)$。直线方向向量
$$\vec d=n_1\times n_2=\begin{vmatrix}i&j&k\\1&3&2\\2&-1&-10\end{vmatrix}=(-28,14,-7)=-7(4,-2,1).$$

故 $\vec d\parallel(4,-2,1)$。平面 $\pi$ 的法向量恰为 $n=(4,-2,1)$，即 $\vec d\parallel n$，故直线垂直于平面。

**易错点**：方向向量可差一个非零常数倍，$-7(4,-2,1)$ 与 $(4,-2,1)$ 平行；判断"平行/在平面内/垂直/斜交"关键是方向向量与法向量关系：$\vec d\cdot n=0$ 则平行或重合，$\vec d\parallel n$ 则垂直，否则斜交。

**命题规律**：空间直线（交面式）与平面位置关系必考方向向量 = 法向量叉积，再点积定夹角；这是解析几何的"向量基本操作"模板。

# MCQ 第 4 题

![[_Attachments/题目识别/1000-GS/1000-GS-T614455-Q004_题目.png|题目]]

4. $I_1 = \int_{0}^{2\pi} \frac{\sin x}{x} \, dx$，$I_2 = \int_{0}^{2\pi} \frac{\sin x}{2\pi - x} \, dx$，$I_3 = \int_{0}^{2\pi} \frac{\sin x}{x(2\pi - x)} \, dx$，则（）

A. $I_3 < I_1 < I_2$
B. $I_3 < I_2 < I_1$
C. $I_2 < I_3 < I_1$
D. $I_1 < I_2 < I_3$

---

## 答案

![[_Attachments/题目识别/1000-答案/1000-GS-T614455-Q004_答案.png|答案]]

## V4 Pro Max 解析

**答案**：C（$I_2<I_3<I_1$）

**切入点**：注意到 $I_2$ 经换元 $u=2\pi-x$ 化为 $-I_1$；$I_3$ 的 $\dfrac1{x(2\pi-x)}$ 用 $\dfrac1x+\dfrac1{2\pi-x}$ 拆解，得到 $I_3=\dfrac{I_1+I_2}{2\pi}=0$。

**推演**

$I_2=\int_0^{2\pi}\dfrac{\sin x}{2\pi-x}dx$，令 $u=2\pi-x$，$\sin x=\sin(2\pi-u)=-\sin u$，得
$$I_2=\int_0^{2\pi}\frac{-\sin u}{u}\,du=-I_1.$$

又 $\dfrac1{x(2\pi-x)}=\dfrac1{2\pi}\Bigl(\dfrac1x+\dfrac1{2\pi-x}\Bigr)$，故
$$I_3=\int_0^{2\pi}\frac{\sin x}{x(2\pi-x)}dx=\frac1{2\pi}(I_1+I_2)=0.$$

而 $I_1=\int_0^{2\pi}\dfrac{\sin x}{x}dx>0$：由
$$\int_{\pi}^{2\pi}\frac{\sin x}{x}dx=-\int_0^\pi\frac{\sin t}{\pi+t}dt$$
得 $I_1=\int_0^\pi\sin t\Bigl(\dfrac1t-\dfrac1{\pi+t}\Bigr)dt>0$。

故 $I_2=-I_1<0=I_3<I_1$，即 $I_2<I_3<I_1$。

**易错点**：⚠ $I_2=-I_1$（换元后符号翻转）；$I_3=0$ 由被积函数关于 $x=\pi$ 反对称也可直接看出；勿误判 $I_1<0$。

**命题规律**：关于区间中点对称的积分，先看奇偶/反对称性；分母含 $x$ 与 $2\pi-x$ 时用部分分式 $\dfrac1x+\dfrac1{2\pi-x}$ 建立 $I_1,I_2,I_3$ 的线性关系，是定积分性质题的标准手法。

# FRQ 第 16 题

![[_Attachments/题目识别/1000-GS/1000-GS-TDD3E80-Q016_题目.png|题目]]

16. 设  $f(x)=|x|\sin^{2}x ,$ 则使  $f^{(n)}(0)$  存在的阶数  n  的最大值为().

---

## 答案

![[_Attachments/题目识别/1000-答案/1000-GS-TDD3E80-Q016_答案.png|答案]]

## V4 Pro Max 解析

**答案**：$2$

**切入点**：$\sin^2x=x^2-\frac13x^4+\cdots$，故 $f(x)=|x|\sin^2x=|x|^3-\frac13|x|^5+O(|x|^7)$。判断 $|x|^k$ 的求导阶数：$|x|^3$ 只有到二阶导在 0 存在，三阶导跳变。

**推演**

由 $\sin^2x=x^2-\frac13x^4+O(x^6)$，得
$$f(x)=|x|x^2-\frac13|x|x^4+O(|x|x^6)=|x|^3-\frac13|x|^5+O(|x|^7).$$

$|x|^3$ 的导数：$f'(0)=0$，$f'(x)=3x|x|$；$f''(0)=0$，$f''(x)=6|x|$；$f'''(x)=6\operatorname{sgn}x$（$x\ne0$），而
$$f'''(0)=\lim_{x\to0}\frac{6|x|-0}{x}=\lim 6\operatorname{sgn}x\ \text{不存在}.$$
故 $|x|^3$ 使 $f^{(3)}(0)$ 不存在；而 $|x|^5$（$C^4$）、$|x|^7$（$C^6$）在 0 的三阶导均存在，不影响结论。

所以 $f^{(n)}(0)$ 存在的最大阶数为 $n=2$。

**易错点**：$|x|\sin^2x$ 主部是 $|x|^3$（因 $\sin^2x\sim x^2$），其 $C^2$ 光滑但三阶导跳变；高阶项 $|x|^5,|x|^7$ 更光滑，不会降低最大阶数。$f'(x)=3x|x|$、$f''(x)=6|x|$ 在 0 连续，$f'''(x)=6\operatorname{sgn}x$ 跳变。

**命题规律**：$|x|^k$ 在 0 处属于 $C^{k-1}$，$k$ 阶导跳变；$|x|\sin^2x$ 按最低光滑项 $|x|^3$ 定最大求导阶数 2。

# MCQ 第 25 题

25. 设下列 $A, B, C$ 为任意常数，则微分方程 $y'' + 4y = \sin^2 x$ 有特解形如 $(\＿)。$

A. $A \sin^2 x$

B. $A \cos^2 x$

C. $x(A + B \cos 2x + C \sin 2x)$

D. $A + x(B \cos 2x + C \sin 2x)$

故正确答案为 D.

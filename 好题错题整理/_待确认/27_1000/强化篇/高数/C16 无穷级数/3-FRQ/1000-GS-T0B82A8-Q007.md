# FRQ 第 7 题

![[_Attachments/题目识别/1000-GS/1000-GS-T0B82A8-Q007_题目.png|题目]]

7. 设数列 $\{a_n\}, \{b_n\}$ 满足 $e^{a_n} - e^{-a_n} = a_n(e^{b_n} + e^{-b_n})$，$0 < a_n < 1$，$0 < b_n < 1$，$n = 1, 2, \cdots$，且 $\sum\limits_{n=1}^{\infty} b_n$ 收敛。

证明：(1) $a_n > b_n$，$n = 1, 2, \cdots$；

(2) $\sum\limits_{n=1}^{\infty} (b_n - a_n)$ 收敛.

---

## 答案

![[_Attachments/题目识别/1000-答案/1000-GS-T0B82A8-Q007_答案.png|答案]]

## V4 Pro Max 解析

**答案**：(1) $a_n>b_n$；(2) $\sum_{n=1}^{\infty}(b_n-a_n)$ 收敛。

**切入点**：方程 $e^{a_n}-e^{-a_n}=a_n(e^{b_n}+e^{-b_n})$ 即 $2\sinh a_n=2a_n\cosh b_n$，化为 $\frac{\sinh a_n}{a_n}=\cosh b_n$。要证 $a_n>b_n$，本质是比较 $\frac{\sinh x}{x}$ 与 $\cosh x$ 的大小；要证收敛，则用泰勒把 $a_n$ 用 $b_n$ 夹住。类比算法：把隐式关系“线性化”成可比的显式界。

**推演**

(1) 记 $f(x)=\frac{\sinh x}{x}\ (x>0)$。已知恒等式 $\frac{\sinh a_n}{a_n}=\cosh b_n$。考虑 $g(x)=\cosh x-\frac{\sinh x}{x}=\frac{x\cosh x-\sinh x}{x}$，而 $h(x)=x\cosh x-\sinh x$ 满足 $h(0)=0$，$h'(x)=x\sinh x>0\ (x>0)$，故 $h(x)>0$，即 $\frac{\sinh x}{x}<\cosh x\ (x>0)$。于是

$$\cosh b_n=\frac{\sinh a_n}{a_n}<\cosh a_n.$$

因 $\cosh$ 在 $(0,1)$ 上严格递增，得 $b_n<a_n$。

(2) 由泰勒展开：$\frac{\sinh a_n}{a_n}=\sum_{k\ge0}\frac{a_n^{2k}}{(2k+1)!}\ge 1+\frac{a_n^2}{6}$；又对 $0<b_n<1$，$\cosh b_n=\sum_{k\ge0}\frac{b_n^{2k}}{(2k)!}\le 1+b_n^2$（$k\ge2$ 时 $\frac{b_n^{2k}}{(2k)!}\le\frac{b_n^4}{24}+\cdots$，且 $b_n^4\le b_n^2$，各项和小于 $\frac12 b_n^2$）。故

$$1+\frac{a_n^2}{6}\le\cosh b_n\le 1+b_n^2\ \Longrightarrow\ a_n\le\sqrt6\,b_n.$$

于是 $0<a_n-b_n\le(\sqrt6-1)b_n$，由 $\sum b_n$ 收敛及比较判别法知 $\sum(a_n-b_n)$ 收敛，从而 $\sum(b_n-a_n)=-\sum(a_n-b_n)$ 也收敛。

**易错点**：方程要化为 $\frac{\sinh a_n}{a_n}=\cosh b_n$ 才能看清结构；证明 $a_n>b_n$ 的关键是恒等式 $\frac{\sinh x}{x}<\cosh x$（$h'(x)=x\sinh x>0$），而非直接比较 $a_n,b_n$。第 (2) 问不是证 $\sum a_n$ 与 $\sum b_n$ 的差，而是把 $a_n$ 用 $b_n$ 上界夹住再用比较判别。

**命题规律**：由超越方程给出的数列级数题，标准动作是**化成可比的显式关系**（这里 $\sinh/\cosh$），再用泰勒展开得到 $a_n$ 与 $b_n$ 的量级不等式，最后配比较判别法。$\frac{\sinh x}{x}$ 的泰勒、$\cosh x$ 的上界是本题的两把钥匙。

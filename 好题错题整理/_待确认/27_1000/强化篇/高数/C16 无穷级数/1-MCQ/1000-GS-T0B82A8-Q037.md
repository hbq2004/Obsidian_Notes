# MCQ 第 37 题

![[_Attachments/题目识别/1000-GS/1000-GS-T0B82A8-Q037_题目.png|题目]]

37. 设 $f(x) = \begin{cases} x + 1, & 0 \leq x \leq \pi, \\ 0, & -\pi \leq x < 0, \end{cases}$，$S(x) = \frac{a_0}{2} + \sum\limits_{n=1}^{\infty} (a_n \cos nx + b_n \sin nx)$ 是 $f(x)$ 以 $2\pi$ 为周期的傅里叶级数，则 $\sum\limits_{n=1}^{\infty} a_n =$（）。

A. $-\frac{\pi}{4}$

B. $\frac{\pi}{4}$

C. $-\frac{\pi}{2}$

D. $\frac{\pi}{2}$

---

## 答案

![[_Attachments/题目识别/1000-答案/1000-GS-T0B82A8-Q037_答案.png|答案]]

## V4 Pro Max 解析

**答案**：A，$-\dfrac{\pi}{4}$。

**切入点**：$\sum a_n$ 就是 $S(0)-\frac{a_0}{2}$，而 $x=0$ 是 $f$ 的间断点，用狄利克雷定理取左右极限平均。类比算法：用收敛定理在“断点”处读取级数和。

**推演**

$f(x)=x+1\ (0\le x\le\pi)$，$f(x)=0\ (-\pi\le x<0)$。在 $x=0$ 处有跳跃间断：$f(0^-)=0$，$f(0^+)=1$。由狄利克雷收敛定理，傅里叶级数在间断点收敛到左右极限的平均：

$$S(0)=\frac{f(0^-)+f(0^+)}2=\frac{0+1}{2}=\frac12.$$

又 $S(0)=\frac{a_0}{2}+\sum_{n=1}^{\infty}a_n\cos 0=\frac{a_0}{2}+\sum_{n=1}^{\infty}a_n$，故

$$\sum_{n=1}^{\infty}a_n=S(0)-\frac{a_0}{2}.$$

计算 $a_0=\frac1\pi\int_{-\pi}^{\pi}f(x)dx=\frac1\pi\int_0^{\pi}(x+1)dx=\frac1\pi\Big[\frac{x^2}{2}+x\Big]_0^\pi=\frac\pi2+1$，故 $\frac{a_0}{2}=\frac\pi4+\frac12$。于是

$$\sum_{n=1}^{\infty}a_n=\frac12-\Big(\frac\pi4+\frac12\Big)=-\frac\pi4.$$

**易错点**：$x=0$ 是间断点，$S(0)$ 取 $\frac{f(0^-)+f(0^+)}2=\frac12$，不是 $f(0)=1$；$a_0=\frac1\pi\int$（注意系数 $\frac1\pi$ 而非 $\frac2\pi$），且 $S$ 中常数项是 $\frac{a_0}{2}$。

**命题规律**：求 $\sum a_n$（或 $\sum a_n\cos$ 在某点值）的题，核心是**选一个便于读取系数的点 $x$**（通常是间断点或端点），用狄利克雷定理 $S(x)=\frac{f(x^-)+f(x^+)}2$ 反解出级数和。这是傅里叶级数求和的经典套路。

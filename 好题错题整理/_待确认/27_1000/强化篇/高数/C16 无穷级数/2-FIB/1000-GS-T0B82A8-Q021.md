# FIB 第 21 题

![[_Attachments/题目识别/1000-GS/1000-GS-T0B82A8-Q021_题目.png|题目]]

21. 设级数 $\sum\limits_{n=1}^{\infty} a_n x^n$ 的系数 $a_n$ 满足关系式 $a_n = \frac{a_{n-1}}{n} + 1 - \frac{1}{n}, n = 2, 3, \cdots, a_1 = 2$，则当 $|x| < 1$ 时，级数 $\sum\limits_{n=1}^{\infty} a_n x^n$ 的和函数 $S(x) =$ \_.

---

## 答案

![[_Attachments/题目识别/1000-答案/1000-GS-T0B82A8-Q021_答案.png|答案]]

## V4 Pro Max 解析

**答案**：$\displaystyle S(x)=e^{x}-1+\frac{x}{1-x}$。

**切入点**：由递推先猜出通项（$a_n=1+\frac1{n!}$），再分别求和 $\sum x^n$ 与 $\sum\frac{x^n}{n!}$。类比算法：递推先“打表”找规律得通项，再套已知母函数。

**推演**

由 $a_n=\frac{a_{n-1}}{n}+1-\frac1n$ 及 $a_1=2$，逐步算出 $a_1=2,\ a_2=\frac32,\ a_3=\frac76,\ a_4=\frac{25}{24}$，猜测 $a_n=1+\frac1{n!}$。代入验证：

$$\frac{a_{n-1}}{n}+1-\frac1n=\frac{1+\frac1{(n-1)!}}{n}+1-\frac1n=1+\frac{1}{n!},$$

成立。故

$$S(x)=\sum_{n=1}^{\infty}\Big(1+\frac1{n!}\Big)x^n=\sum_{n=1}^{\infty}x^n+\sum_{n=1}^{\infty}\frac{x^n}{n!}=\frac{x}{1-x}+(e^x-1).$$

**易错点**：通项 $a_n=1+\frac1{n!}$ 需先由前几项归纳猜测并回代验证；$\sum_{n=1}^{\infty}\frac{x^n}{n!}=e^x-1$（起点是 $n=1$，故减 $1$），$\sum x^n=\frac{x}{1-x}$（也始于 $n=1$）。

**命题规律**：由系数递推求幂级数和，套路是“先算前几项猜通项 → 回代验证 → 拆成已知母函数”。形如 $na_n=a_{n-1}+(n-1)$ 的递推，通项常拆成“常数 + 阶乘倒数”，和函数自然拆成 $\frac{x}{1-x}+e^x-1$。

# MCQ 第 26 题

![[_Attachments/题目识别/1000-GS/1000-GS-TDE6A7F-Q026_题目.png|题目]]

26. 当 $x \to 0$ 时，以下无穷小中，阶数最高的是（）。

A. $\int_{0}^{\sin x} (1+t)^{\frac{2}{t}} dt$

B. $\int_{0}^{\ln(1+x^2)} \sqrt{\cos^3 t} dt$

C. $\int_{0}^{x} (e^{\cos t} - e^{\sin t}) dt$

D. $\int_{0}^{x - \tan x} \arctan t dt$

---

## 答案

![[_Attachments/题目识别/1000-答案/1000-GS-TDE6A7F-Q026_答案.png|答案]]

## V4 Pro Max 解析

**答案**：D

**切入点**：比较无穷小阶数 ≈ 比较"谁更快趋近 0"。变限积分 $\int_0^{u(x)}g(t)\,dt$ 的阶由**上限 $u(x)$ 的阶**与**被积函数在 0 处的取值**共同决定,先各自定阶再相乘。

**推演**

记各无穷小为 $A,B,C,D$,比较阶数(阶数越大,趋于 0 越快)。

- A:$\int_0^{\sin x}(1+t)^{2/t}dt$。$t\to0$ 时 $(1+t)^{1/t}\to e$,故 $(1+t)^{2/t}\to e^2$,被积函数有非零极限;上限 $\sin x\sim x$。故 $A\sim e^2 x$,阶数 $1$。

- B:$\int_0^{\ln(1+x^2)}\sqrt{\cos^3 t}\,dt$。被积函数 $\sqrt{\cos^3 t}\to 1$;上限 $\ln(1+x^2)\sim x^2$。故 $B\sim x^2$,阶数 $2$。

- C:$\int_0^x(e^{\cos t}-e^{\sin t})dt$。$t=0$ 处被积函数 $e^{\cos 0}-e^{\sin 0}=e-1\neq0$,故被积函数在 $0$ 附近有非零极限,积分 $\sim(e-1)x$,阶数 $1$。

- D:$\int_0^{x-\tan x}\arctan t\,dt$。上限 $x-\tan x\sim -\dfrac{x^3}{3}$;被积函数 $\arctan t\sim t$。故 $D\sim\dfrac{1}{2}(x-\tan x)^2\sim\dfrac{x^6}{18}$,阶数 $6$。

各阶数为 $A:1,\ B:2,\ C:1,\ D:6$,阶数最高的是 D。

**易错点**：定阶要两步走——上限的阶、被积函数在 0 处的极限。A、C 中被积函数在 0 处有**非零极限**,直接乘以上限阶数;D 中被积函数 $\arctan t\sim t$ 本身再贡献一阶,且上限 $x-\tan x$ 是 $x$ 的**三阶**无穷小(两者一阶项相消),平方后才是六阶。

**命题规律**：变限积分的无穷小阶数是常考题型,套路固定——先算上限阶数,再看被积函数在 0 处是否退化;被积函数非零极限→阶数即上限阶数,被积函数也趋于 0 则用等价无穷小叠加。

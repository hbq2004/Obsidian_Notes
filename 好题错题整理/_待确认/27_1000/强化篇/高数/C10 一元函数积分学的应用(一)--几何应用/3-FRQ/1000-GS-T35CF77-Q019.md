# FRQ 第 19 题

![[_Attachments/题目识别/1000-GS/1000-GS-T35CF77-Q019_题目.png|题目]]

19. 已知函数 $f(x)$, $g(x)$ 分别满足 $f'(x) = 2\sqrt{f(x)}$, $g'(x) = \frac{g(x)}{x-2} + \frac{x-2}{x}$, $f(0) = 1$, $g(1) = 0$. 求曲线 $f(x) + g(y) = 0$ 所围图形绕直线 $x = -1$ 旋转一周所成旋转体体积.

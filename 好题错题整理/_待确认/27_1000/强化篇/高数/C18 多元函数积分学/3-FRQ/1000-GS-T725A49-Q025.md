# FRQ 第 25 题

25. 设 $a, b$ 为实数，函数 $f(x, y) = ax^2 + by^2$ 在点 (1,1) 处沿方向 $l = i + j$ 的方向导数最大，最大值为 $2\sqrt{2}$. 若 $\Sigma$ 为曲面 $x^2 + z^2 = 2z$ 被曲面 $z = \sqrt{f(x, y)}$ 所截取的部分.

(1) 求 $a, b$ 的值；

(2) 计算 $\iint_{\Sigma} z \, dS$.

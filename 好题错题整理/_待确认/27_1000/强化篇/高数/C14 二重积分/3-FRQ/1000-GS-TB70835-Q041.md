# FRQ 第 41 题

![[_Attachments/题目识别/1000-GS/1000-GS-TB70835-Q041_题目.png|题目]]

41. 设平面区域 $D = \{ (x, y) \mid 2x^2 + y^2 \leq 2\sqrt{x^2 + y^2}, y \geq x \geq 0 \}$，若 $\iint_D \frac{f(x, y)}{\sqrt{1 - x^2}} \, d\sigma = a > 0$，$f(x, y)$ 是 $D$ 上的连续函数。

(1) 计算 $\iint_D \frac{1}{\sqrt{1 - x^2}} \, d\sigma$；

(2) 证明：存在 $(\xi, \eta) \in D$，使得 $|f(\xi, \eta)| \geq \frac{\sqrt{2}}{\pi} a$.

---

## 答案

![[_Attachments/题目识别/1000-答案/1000-GS-TB70835-Q041_答案.png|答案]]

## V4 Pro Max 解析

**答案**：(1) $\sqrt2\arctan\sqrt2$；(2) 见推演

**切入点**：(1) 极坐标下边界 $2x^2+y^2\le2\sqrt{x^2+y^2}$ 化为 $r\le\frac{2}{1+\cos^2\theta}$，$y\ge x\ge0$ 化为 $\theta\in[\frac\pi4,\frac\pi2]$，被积 $\frac1{\sqrt{1-x^2}}$ 对 $r$ 积分后只剩关于 $\theta$ 的有理三角积分；(2) 用积分中值定理把 $a$ 与 $f(\xi,\eta)$ 挂钩，再用 $\arctan$ 的上界放缩。

**推演**

**(1)** 极坐标 $x=r\cos\theta,\ y=r\sin\theta$。$2x^2+y^2=r^2(1+\cos^2\theta)\le2r\Rightarrow r\le\frac{2}{1+\cos^2\theta}$；$y\ge x\ge0\Rightarrow\theta\in[\frac\pi4,\frac\pi2]$。

$$I=\iint_D\frac{1}{\sqrt{1-x^2}}\,d\sigma=\int_{\pi/4}^{\pi/2}\int_0^{2/(1+\cos^2\theta)}\frac{r}{\sqrt{1-r^2\cos^2\theta}}\,dr\,d\theta.$$

令 $u=1-r^2\cos^2\theta$：$\int_0^R\frac{r\,dr}{\sqrt{1-r^2\cos^2\theta}}=\frac{1-\sqrt{1-R^2\cos^2\theta}}{\cos^2\theta}$，其中 $R=\frac2{1+\cos^2\theta}$，$\sqrt{1-R^2\cos^2\theta}=\frac{\sin^2\theta}{1+\cos^2\theta}$。故

$$\int_0^R\cdots dr=\frac{1}{\cos^2\theta}\left(1-\frac{\sin^2\theta}{1+\cos^2\theta}\right)=\frac{2}{1+\cos^2\theta}.$$

$$I=\int_{\pi/4}^{\pi/2}\frac{2}{1+\cos^2\theta}\,d\theta.$$

令 $u=\tan\theta$：$\int\frac{d\theta}{1+\cos^2\theta}=\frac1{\sqrt2}\arctan\frac{\tan\theta}{\sqrt2}$，故

$$I=2\cdot\frac1{\sqrt2}\left[\arctan\frac{\tan\theta}{\sqrt2}\right]_{\pi/4}^{\pi/2}=\sqrt2\left(\frac\pi2-\arctan\frac1{\sqrt2}\right)=\sqrt2\arctan\sqrt2.$$

（末步用 $\arctan x+\arctan\frac1x=\frac\pi2$。）

**(2)** 由积分中值定理，存在 $(\xi,\eta)\in D$ 使

$$a=\iint_D\frac{f}{\sqrt{1-x^2}}\,d\sigma=f(\xi,\eta)\iint_D\frac{1}{\sqrt{1-x^2}}\,d\sigma=f(\xi,\eta)\cdot\sqrt2\arctan\sqrt2.$$

故 $|f(\xi,\eta)|=\dfrac{a}{\sqrt2\arctan\sqrt2}$。因 $\arctan\sqrt2<\frac\pi2$，$\sqrt2\arctan\sqrt2<\frac{\pi}{\sqrt2}$，故

$$|f(\xi,\eta)|>\frac{a}{\pi/\sqrt2}=\frac{\sqrt2}{\pi}a.$$

即 $|f(\xi,\eta)|\ge\frac{\sqrt2}{\pi}a$（严格更强）。

**易错点**：(1) 中 $\theta$ 范围是 $[\frac\pi4,\frac\pi2]$（$y\ge x\ge0$ 要求 $\cos\theta\ge0$ 且 $\sin\theta\ge\cos\theta$）；对 $r$ 积分后 $2/(1+\cos^2\theta)$ 的出现靠 $\sqrt{1-R^2\cos^2\theta}=\sin^2\theta/(1+\cos^2\theta)$ 化简；(2) 用 $\arctan\sqrt2<\frac\pi2$ 放缩即可，无需算 $\arctan\sqrt2$ 的精确值。

**命题规律**：极坐标 + 无理被积 $\frac1{\sqrt{1-x^2}}$ 用凑微分 $u=1-r^2\cos^2\theta$；积分型「存在性」结论由积分中值定理 + 对 $I$ 的上下界放缩给出，是数一证明题的标准组合。

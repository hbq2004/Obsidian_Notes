# FIB 第 14 题

![[_Attachments/题目识别/1000-GS/1000-GS-TB70835-Q014_题目.png|题目]]

$$1 4 . \int ＿ { - 1 } ^ { 1 } d y \int ＿ { - 1 } ^ { y } y \sqrt { 1 + x ^ { 2 } - y ^ { 2 } } \, d x = \boxed{ \＿ } .$$

---

## 答案

![[_Attachments/题目识别/1000-答案/1000-GS-TB70835-Q014_答案.png|答案]]

## V4 Pro Max 解析

**答案**：$\dfrac12$

**切入点**：区域是正方形中 $x\le y$ 的上三角，直接对 $y$ 逐层积分太繁；利用被积 $y\sqrt{1+x^2-y^2}$ 关于 $y$ 的奇偶结构，逐项分离奇偶部分消去半数积分。

**推演**

$$I=\int_{-1}^1 dy\,y\int_{-1}^{y}\sqrt{1+x^2-y^2}\,dx.$$

令 $b^2=1-y^2$，内层：

$$F(y)=\int_{-1}^{y}\sqrt{x^2+b^2}\,dx=\left[\frac{x}{2}\sqrt{x^2+b^2}+\frac{b^2}{2}\ln(x+\sqrt{x^2+b^2})\right]_{-1}^{y}.$$

由 $\sqrt{y^2+b^2}=1$、$\sqrt{1+b^2}=\sqrt{2-y^2}$：

$$F(y)=\frac12\left[y+b^2\ln(y+1)+\sqrt{2-y^2}-b^2\ln(-1+\sqrt{2-y^2})\right].$$

于是

$$I=\frac12\int_{-1}^1\left[y^2+yb^2\ln(y+1)+y\sqrt{2-y^2}-yb^2\ln(-1+\sqrt{2-y^2})\right]dy.$$

奇偶性：$y\sqrt{2-y^2}$、$yb^2\ln(-1+\sqrt{2-y^2})$ 关于 $y$ 为奇函数，积分为 $0$；$\int_{-1}^1 y^2dy=\frac23$。剩一项：

$$\int_{-1}^1 y\,b^2\ln(y+1)\,dy=\int_{-1}^1 y(1-y^2)\ln(y+1)\,dy=\frac13.$$

故 $I=\frac12\left(\frac23+\frac13\right)=\frac12$。

（其中 $y(1-y^2)\ln(y+1)$ 的积分：令 $u=y+1$，$\int_0^2(u-1)u(2-u)\ln u\,du=\frac13$。）

**易错点**：被积根号内是 $1+x^2-y^2$（不是 $1-x^2-y^2$），对应 $\int\sqrt{x^2+b^2}$ 的原函数（含 $\ln$）；奇偶部分务必分别判断，$\ln(-1+\sqrt{2-y^2})$ 是偶函数、乘 $y$ 后为奇函数而抵消。

**命题规律**：累次积分中「外层乘一个奇变量」时，先拆奇偶部分，奇部分直接归零；$\int\sqrt{x^2+a^2}$ 与 $\int\sqrt{a^2-x^2}$ 的原函数要分清。

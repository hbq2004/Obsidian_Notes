# MCQ 第 4 题

![[_Attachments/题目识别/880-GS/880-GS-C07-T68FF-5FF37-Q004_题目.png|题目]]

(4)设 $y_1$，$y_2$ 是一阶线性非齐次微分方程 $y' + P(x)y = Q(x)$ 的两个解，若常数 $\lambda$，$\mu$ 使得 $\lambda y_1 + \mu y_2$ 是该方程的解，$\lambda y_1 - \mu y_2$ 是对应的齐次微分方程的解，则（ ）。

A. $\lambda = -\frac{1}{2}$，$\mu = -\frac{1}{2}$

B. $\lambda = \frac{1}{2}$，$\mu = \frac{1}{2}$

C. $\lambda = \frac{1}{3}$，$\mu = \frac{2}{3}$

D. $\lambda = \frac{2}{3}$，$\mu = \frac{2}{3}$

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-T68FF-5FF37-Q004_答案.png|答案]]

## V4 Pro Max 解析

**考点**：线性方程解的结构:解的线性组合仍为解时系数满足的条件。

**解**
记 $L[y] = y' + P(x)y$。由题设 $L[y_1] = L[y_2] = Q(x)$。
$$L[\lambda y_1 + \mu y_2] = \lambda Q + \mu Q = (\lambda + \mu)Q,$$
要使 $\lambda y_1 + \mu y_2$ 仍是原方程的解,需 $(\lambda + \mu)Q = Q$,即
$$\lambda + \mu = 1.$$
$$L[\lambda y_1 - \mu y_2] = \lambda Q - \mu Q = (\lambda - \mu)Q,$$
要使它是齐次方程 $y' + P(x)y = 0$ 的解,需 $(\lambda - \mu)Q = 0$(因 $Q \not\equiv 0$),即
$$\lambda = \mu.$$
联立得 $\lambda = \mu = \dfrac12$。

**答案**：B。

**易错点**：$Q(x)$ 不恒为 0,由 $(\lambda-\mu)Q = 0$ 可推出 $\lambda = \mu$;非齐次组合条件 $\lambda+\mu=1$ 勿遗漏。

# MCQ 第 7 题

![[_Attachments/题目识别/880-GS/880-GS-C07-T68FF-5FF37-Q007_题目.png|题目]]

(7) 设 $f(x)$ 是定义在 $R$ 上的偶函数，且 $f(x) + f'(x) = 2e^x$，若 $a[f(x) - e^x] \leq x$ 在 $R$ 上恒成立，则 $a$ 的取值范围为(\_)。

A. $(-\infty, 0]$
B. $\left(-\infty, -\frac{1}{e}\right]$
C. $(-\infty, -1)$
D. $(-\infty, -e]$

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-T68FF-5FF37-Q007_答案.png|答案]]

## V4 Pro Max 解析

**考点**：偶函数定 $f(x)$,再解含参不等式恒成立求参数范围。

**解**
$f' + f = 2e^x$,即 $(fe^x)' = 2e^{2x}$,积分得
$$fe^x = e^{2x} + C\;\Longrightarrow\; f(x) = e^x + Ce^{-x}.$$
由 $f$ 为偶函数:$f(x) = f(-x)$,即 $e^x + Ce^{-x} = e^{-x} + Ce^x$,故 $(1-C)(e^x - e^{-x}) \equiv 0$,得 $C = 1$,所以
$$f(x) = e^x + e^{-x},\qquad f(x) - e^x = e^{-x}.$$
条件 $a[f(x) - e^x] \le x$ 即 $ae^{-x} \le x$,对一切 $x\in\mathbb R$ 成立。
- $x = 0$:$a \le 0$;
- $x > 0$:$a \le xe^x$,而 $xe^x$ 在 $(0,+\infty)$ 上递增、下确界为 $0$,故 $a \le 0$;
- $x < 0$:$a \le xe^x$ 恒成立需 $a \le \min\limits_{x<0}xe^x$。令 $g(x) = xe^x$,$g'(x) = e^x(1+x)$,在 $x=-1$ 取最小值 $g(-1) = -\dfrac1e$,故 $a \le -\dfrac1e$。
综合取交集:$a \le -\dfrac1e$。

**答案**：B。

**易错点**：偶函数定出 $C=1$ 是前提;$x<0$ 一侧是更强的约束($a \le -1/e$),$x>0$ 一侧只给 $a \le 0$,取交集别搞反。

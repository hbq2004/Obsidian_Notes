# MCQ 第 3 题

![[_Attachments/题目识别/880-GS/880-GS-C07-T68FF-Q003_题目.png|题目]]

(3) 微分方程 $y'' + 2y' - 3y = e^{-x} + x$ 的一个特解形式为(\_)。

A. $ae^{-x} + bx + c$

B. $axe^{-x} + x(bx + c)$

C. $axe^{-x} + bx + c$

D. $ae^x + x(bx + c)$

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-T68FF-Q003_答案.png|答案]]

## V4 Pro Max 解析

**考点**：二阶常系数非齐次方程特解形式的设定(叠加原理 + 共振判断)。

**解**
特征方程 $r^2 + 2r - 3 = 0$,根 $r = 1,\ -3$。
(1) 对非齐次项 $e^{-x}$:$\lambda = -1$ 不是特征根,特解形式 $ae^{-x}$。
(2) 对非齐次项 $x$:$0$ 不是特征根,特解形式 $bx + c$。
由叠加原理,方程 $y'' + 2y' - 3y = e^{-x} + x$ 的特解形式为
$$y_p = ae^{-x} + bx + c.$$

**答案**：A。

**易错点**：$\lambda=-1$ 与特征根 $1,-3$ 不同,不加 $x$ 因子;若题目中 $e^{-x}$ 换成 $e^x$(特征根),才需 $axe^x$。

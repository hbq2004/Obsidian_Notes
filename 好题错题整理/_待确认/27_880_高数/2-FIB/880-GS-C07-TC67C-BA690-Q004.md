(4) 微分方程 $\frac{d y}{~d x} = \frac{y - x}{y + x}$ 满足 $y(1) = 0$ 的特解为 \_ .

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-TC67C-BA690-Q004_答案.png|答案]]

## V4 Pro Max 解析

**考点**：齐次方程(一阶可化为 $u=y/x$ 型)的求解与初值定常数。

**解**
方程 $\dfrac{dy}{dx} = \dfrac{y-x}{y+x}$,令 $u = \dfrac{y}{x}$,则 $y = ux$,且 $\dfrac{dy}{dx} = u + x\dfrac{du}{dx}$。代入:
$$u + x\frac{du}{dx} = \frac{ux - x}{ux + x} = \frac{u-1}{u+1},$$
$$x\frac{du}{dx} = \frac{u-1}{u+1} - u = -\frac{u^2+1}{u+1}.$$
分离变量:
$$\frac{u+1}{u^2+1}\,du = -\frac{dx}{x}.$$
积分:
$$\frac{1}{2}\ln(u^2+1) + \arctan u = -\ln|x| + C.$$
代回 $u = \dfrac{y}{x}$:
$$\frac{1}{2}\ln\frac{x^2+y^2}{x^2} + \arctan\frac{y}{x} + \ln|x| = C
\;\Longrightarrow\; \frac{1}{2}\ln(x^2+y^2) + \arctan\frac{y}{x} = C.$$
由 $y(1)=0$:$\dfrac{1}{2}\ln 1 + \arctan 0 = 0 = C$。

**答案**：$\ln(x^2+y^2) + 2\arctan\dfrac{y}{x} = 0$。

**易错点**：$\ln\dfrac{x^2+y^2}{x^2} + 2\ln|x|$ 化简时 $\ln|x|$ 恰好抵消,不要画蛇添足;$\arctan\dfrac{y}{x}$ 在 $x<0$ 时注意主值区间,本题由 $y(1)=0$ 定常数不受影响。

# FIB 第 9 题

![[_Attachments/题目识别/880-GS/880-GS-C07-TC67C-BA690-Q009_题目.png|题目]]

(9) 设 $f(x)$ 有连续导数，对任意 $a$ 满足 $f(x+a) = \int_{x}^{x+a} \frac{t(t^2+1)}{f(t)} dt + f(x)$，且 $f(1) = \sqrt{2}$，则 $f(x) = \＿$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-TC67C-BA690-Q009_答案.png|答案]]

## V4 Pro Max 解析

**考点**：对含参变量 $a$ 的积分等式两边关于 $a$ 求导,化为可分离变量方程。

**解**
对
$$f(x+a) = \int_x^{x+a}\frac{t(t^2+1)}{f(t)}dt + f(x)$$
两边关于 $a$ 求导(利用变上限积分求导,上限 $x+a$):
$$f'(x+a) = \frac{(x+a)\big((x+a)^2+1\big)}{f(x+a)}.$$
令 $u = x+a$,得
$$f'(u) = \frac{u(u^2+1)}{f(u)}\quad\Longrightarrow\quad f(u)f'(u) = u^3 + u.$$
两边对 $u$ 积分:
$$\frac{f(u)^2}{2} = \frac{u^4}{4} + \frac{u^2}{2} + C.$$
由 $f(1) = \sqrt{2}$:$\dfrac{2}{2} = \dfrac{1}{4} + \dfrac{1}{2} + C$,得 $C = \dfrac{1}{4}$。于是
$$f(u)^2 = \frac{u^4}{2} + u^2 + \frac{1}{2} = \frac{(u^2+1)^2}{2},$$
取正号得 $f(u) = \dfrac{u^2+1}{\sqrt{2}}$。

**答案**：$f(x) = \dfrac{x^2+1}{\sqrt{2}}$。

**易错点**：等式两边关于 $a$ 求导时,右边 $f(x)$ 与 $x$ 无关视为常数;开方时由 $f(1)=\sqrt2>0$ 取正号;原式分母含 $f(t)$,需 $f\ne 0$(所得解恒正,自洽)。

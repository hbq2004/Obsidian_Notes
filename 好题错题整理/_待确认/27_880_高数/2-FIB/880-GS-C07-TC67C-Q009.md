## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-TC67C-Q009_答案.png|答案]]

## V4 Pro Max 解析

**考点**：欧拉方程,令 $x = e^t$ 化为常系数方程。

**解**
欧拉方程 $x^2y'' - xy' + y = 0\ (x>0)$。令 $x = e^t$,$D = \dfrac{d}{dt}$,则
$$xy' = Dy,\qquad x^2y'' = D(D-1)y = D^2y - Dy.$$
代入:
$$(D^2 - D - D + 1)y = (D^2 - 2D + 1)y = 0,$$
特征方程 $(r-1)^2 = 0$,二重根 $r = 1$,故
$$y = (C_1 + C_2 t)e^t = (C_1 + C_2\ln x)x.$$
由 $y(1) = 1$ 得 $C_1 = 1$;由 $y'(x) = C_1 + C_2 + C_2\ln x$ 及 $y'(1) = 1$ 得 $C_1 + C_2 = 1$,故 $C_2 = 0$。

**答案**：$y(x) = x$。

**易错点**：$x^2y'' = D(D-1)y$ 而非 $D^2y$,这是欧拉方程最常见的失分点;重根时通解含 $\ln x$ 因子。

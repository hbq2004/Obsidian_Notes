(6) 微分方程 $y'' + y = x + \cos x$ 的通解为 \_ .

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-TC67C-BA690-Q006_答案.png|答案]]

## V4 Pro Max 解析

**考点**：二阶常系数非齐次方程;$\cos x$ 与特征根 $\pm i$ 共振时特解乘 $x$。

**解**
齐次方程 $y''+y=0$ 的特征根为 $r=\pm i$,故
$$y_h = C_1\cos x + C_2\sin x.$$
(1) 对非齐次项 $x$:设 $y_{p1} = ax+b$,则 $y_{p1}'' = 0$,$ax+b = x$,得 $a=1,b=0$,即 $y_{p1} = x$。
(2) 对 $\cos x$:因 $\pm i$ 是特征根(共振),设 $y_{p2} = x(A\cos x + B\sin x)$。
$$y_{p2}' = A\cos x + B\sin x + x(-A\sin x + B\cos x),$$
$$y_{p2}'' = -2A\sin x + 2B\cos x - x(A\cos x + B\sin x),$$
$$y_{p2}'' + y_{p2} = -2A\sin x + 2B\cos x = \cos x,$$
得 $A=0,\ B=\dfrac{1}{2}$,即 $y_{p2} = \dfrac{1}{2}x\sin x$。
故通解
$$y = C_1\cos x + C_2\sin x + x + \frac{1}{2}x\sin x.$$

验证:$y''+y = 0 + (x)'' + \dfrac{1}{2}[ (x\sin x)'' + x\sin x] = x + \dfrac{1}{2}(2\cos x) = x + \cos x$ ✓。

**答案**：$y = C_1\cos x + C_2\sin x + x + \dfrac{1}{2}x\sin x$。

**易错点**：$\cos x$ 对应特解必须乘 $x$(共振);$\dfrac{1}{2}x\sin x$ 中的 $\sin$ 项别漏。

# FIB 第 8 题

![[_Attachments/题目识别/880-GS/880-GS-C07-TC67C-Q008_题目.png|题目]]

(8) 方程 $(1-x^2)y'' - xy' = 0$ 满足 $y(0) = 0, y'(0) = 1$ 的特解为 \_\_\_\_\_\_.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-TC67C-Q008_答案.png|答案]]

## V4 Pro Max 解析

**考点**：缺 $y$ 的可降阶方程(令 $p=y'$),初值定常数。

**解**
方程 $(1-x^2)y'' - xy' = 0$,缺 $y$。令 $p = y'$,则 $y'' = p'$,得
$$(1-x^2)p' - xp = 0\;\Longrightarrow\; \frac{dp}{p} = \frac{x}{1-x^2}dx.$$
积分:
$$\ln|p| = -\frac{1}{2}\ln|1-x^2| + C\;\Longrightarrow\; p = \frac{C}{\sqrt{1-x^2}}.$$
由 $y'(0) = 1$ 得 $C = 1$,$y' = \dfrac{1}{\sqrt{1-x^2}}$。再积分:
$$y = \arcsin x + C_2.$$
由 $y(0) = 0$ 得 $C_2 = 0$。

**答案**：$y = \arcsin x$。

**易错点**：$-\dfrac{1}{2}\ln|1-x^2|$ 的指数化后分母是 $\sqrt{1-x^2}$ 而不是别的;初值 $y'(0)=1$ 恰好消掉常数。

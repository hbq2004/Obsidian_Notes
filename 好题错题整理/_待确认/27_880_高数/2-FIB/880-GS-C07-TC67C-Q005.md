## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-TC67C-Q005_答案.png|答案]]

## V4 Pro Max 解析

**考点**：齐次方程(令 $u = y/x$),反双曲函数积分。

**解**
$$xy' = \sqrt{x^2+y^2} + y\;\Longrightarrow\; y' = \sqrt{1+\left(\frac{y}{x}\right)^2} + \frac{y}{x}.$$
令 $u = \dfrac{y}{x}$,$y' = u + xu'$,代入:
$$u + xu' = \sqrt{1+u^2} + u\;\Longrightarrow\; xu' = \sqrt{1+u^2}.$$
分离变量:
$$\frac{du}{\sqrt{1+u^2}} = \frac{dx}{x}\;\Longrightarrow\; \operatorname{arsinh} u = \ln|x| + C.$$
即 $\dfrac{y}{x} = \sinh(\ln|x| + C)$,亦即
$$\operatorname{arsinh}\frac{y}{x} = \ln|x| + C.$$

验证:对 $\operatorname{arsinh}\dfrac{y}{x} = \ln|x|+C$ 求导,$\dfrac{xy'-y}{x^2\sqrt{1+(y/x)^2}} = \dfrac{1}{x}$,整理得 $xy' = \sqrt{x^2+y^2}+y$ ✓。

**答案**：$\operatorname{arsinh}\dfrac{y}{x} = \ln|x| + C$,即 $y = x\sinh(\ln|x|+C)$。

**易错点**：$\int\dfrac{du}{\sqrt{1+u^2}} = \operatorname{arsinh}u$ 不要误写成 $\arctan u$;$\sqrt{x^2+y^2} = x\sqrt{1+u^2}$ 要求 $x>0$,注意符号。

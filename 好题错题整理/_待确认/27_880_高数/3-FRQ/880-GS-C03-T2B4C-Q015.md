# FRQ 第 15 题

![[_Attachments/题目识别/880-GS/880-GS-C03-T2B4C-Q015_题目.png|题目]]

(15) 设曲线 $y = \sin x \left( 0 \leqslant x \leqslant \frac{\pi}{2} \right)$，直线 $y = k$ ($0 \leqslant k \leqslant 1$) 与 $x = 0$ 所围面积为 $S_1$，$y = \sin x \left( 0 \leqslant x \leqslant \frac{\pi}{2} \right)$，$y = k$ 与 $x = \frac{\pi}{2}$ 所围面积为 $S_2$，求 $S = S_1 + S_2$ 的最小值.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C03-T2B4C-Q015_答案.png|答案]]

## V4 Pro Max 解析

**考点**：平面图形面积 + 一元函数最值。

**解**
设直线 $y=k$ 与 $y=\sin x$（$0\le x\le\frac\pi2$）的交点为 $x=\arcsin k$。
$$S_1=\int_0^{\arcsin k}(k-\sin x)\,dx=k\arcsin k-\big[1-\cos(\arcsin k)\big]=k\arcsin k-1+\sqrt{1-k^2},$$
$$S_2=\int_{\arcsin k}^{\pi/2}(\sin x-k)\,dx=\cos(\arcsin k)-k\left(\frac\pi2-\arcsin k\right)=\sqrt{1-k^2}-\frac{k\pi}{2}+k\arcsin k.$$
$$S(k)=S_1+S_2=2k\arcsin k+2\sqrt{1-k^2}-1-\frac{k\pi}{2}.$$
求导：
$$S'(k)=2\arcsin k+\frac{2k}{\sqrt{1-k^2}}-\frac{2k}{\sqrt{1-k^2}}-\frac\pi2=2\arcsin k-\frac\pi2,$$
$$S''(k)=\frac2{\sqrt{1-k^2}}>0.$$
$S'(k)=0\Leftrightarrow\arcsin k=\frac\pi4\Leftrightarrow k=\dfrac{\sqrt2}{2}$，为唯一极小值点即最小值点：
$$S_{\min}=S\left(\frac{\sqrt2}{2}\right)=2\cdot\frac{\sqrt2}{2}\cdot\frac\pi4+2\cdot\frac{\sqrt2}{2}-1-\frac\pi2\cdot\frac{\sqrt2}{2}=\sqrt2-1.$$

**答案**：$S$ 的最小值为 $\sqrt2-1$（$k=\dfrac{\sqrt2}{2}$ 时取得）。

**易错点**：$S_1,S_2$ 的分段点 $\arcsin k$ 要写对（$S_1$ 在交线左侧、$S_2$ 在右侧）；$S'$ 中两项 $\frac{2k}{\sqrt{1-k^2}}$ 恰好相消是关键，$S''>0$ 保证唯一极小。

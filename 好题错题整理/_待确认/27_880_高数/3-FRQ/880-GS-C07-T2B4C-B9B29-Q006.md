# FRQ 第 6 题

![[_Attachments/题目识别/880-GS/880-GS-C07-T2B4C-B9B29-Q006_题目.png|题目]]

(6) 设 $f(x)$，$g(x)$ 满足 $f'(x) = g(x)$，$g(x) = \int_{0}^{x} [1 - f(t)] dt + 1$，且 $f(0) = 1$，求

$I = \int_{0}^{\frac{\pi}{2}} e^{-x} [g(x) - f(x)] dx$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-T2B4C-B9B29-Q006_答案.png|答案]]

## V4 Pro Max 解析

**考点**：由 $f'=g$ 与积分等式消元化为二阶常系数非齐次方程,再算定积分。

**解**
由 $f'(x) = g(x)$ 及 $g(x) = \displaystyle\int_0^x\big[1-f(t)\big]dt + 1$ 得
$$f''(x) = g'(x) = 1 - f(x)\;\Longrightarrow\; f'' + f = 1.$$
通解 $f = C_1\cos x + C_2\sin x + 1$。由 $f(0) = 1$ 得 $C_1 = 0$;由 $f'(0) = g(0) = 1$ 得 $C_2 = 1$。故
$$f(x) = 1 + \sin x,\qquad g(x) = f'(x) = \cos x.$$
于是
$$I = \int_0^{\pi/2}e^{-x}(\cos x - 1 - \sin x)\,dx.$$
利用 $\displaystyle\int e^{-x}\cos x\,dx = \frac{e^{-x}}{2}(\sin x - \cos x)$、$\displaystyle\int e^{-x}\sin x\,dx = -\frac{e^{-x}}{2}(\sin x + \cos x)$:
$$I = \left[\frac{e^{-x}}{2}(\sin x - \cos x)\right]_0^{\pi/2}
- \left[-e^{-x}\right]_0^{\pi/2}
+ \left[\frac{e^{-x}}{2}(\sin x + \cos x)\right]_0^{\pi/2}.$$
$$= \frac{1}{2}(e^{-\pi/2} + 1) - (1 - e^{-\pi/2}) + \frac{1}{2}(e^{-\pi/2} - 1) = 2e^{-\pi/2} - 1.$$

**答案**：$f(x) = 1 + \sin x$,且 $I = 2e^{-\pi/2} - 1$。

**易错点**：$f'' = g' = 1 - f$ 中 $g(0)=1$ 是第二个初值;$\int e^{-x}\cos x\,dx$ 的公式别记反符号。

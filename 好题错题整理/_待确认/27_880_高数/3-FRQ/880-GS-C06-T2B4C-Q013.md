# FRQ 第 13 题

![[_Attachments/题目识别/880-GS/880-GS-C06-T2B4C-Q013_题目.png|题目]]

(13) 设 $D = \{(r, \theta) \mid 0 \leqslant \theta \leqslant \frac{\pi}{2}, 0 \leqslant r \leqslant 2\cos\theta, 0 \leqslant r \leqslant \frac{2}{\cos\theta + \sin\theta}\}$. 计算 $I = \iint_{D} (\cos\theta + \sin\theta) r^2 d\theta dr$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C06-T2B4C-Q013_答案.png|答案]]

## V4 Pro Max 解析

**考点**：极坐标形式的二重积分，比较两个上界取较小者，分 $\theta$ 区间逐段积分。

**解**

$$r_{\max}(\theta)=\min\left(2\cos\theta,\ \frac{2}{\cos\theta+\sin\theta}\right),\qquad \theta\in\left[0,\frac{\pi}{2}\right].$$
比较大小：$2\cos\theta\le\dfrac{2}{\cos\theta+\sin\theta}\iff\cos\theta(\cos\theta+\sin\theta)\ge1$。而
$$\cos\theta(\cos\theta+\sin\theta)=\frac{1+\cos2\theta+\sin2\theta}{2}\ge1\iff\cos2\theta+\sin2\theta\ge1\iff\theta\in\left[\frac{\pi}{4},\frac{\pi}{2}\right].$$
故 $\theta\in[0,\pi/4]$ 时 $r_{\max}=\frac{2}{\cos\theta+\sin\theta}$，$\theta\in[\pi/4,\pi/2]$ 时 $r_{\max}=2\cos\theta$。记 $g=\cos\theta+\sin\theta$：
$$I=\int_0^{\pi/4}\int_0^{\frac{2}{g}}g r^2\,dr\,d\theta+\int_{\pi/4}^{\pi/2}\int_0^{2\cos\theta}g r^2\,dr\,d\theta.$$
第一项：
$$\frac83\int_0^{\pi/4}\frac{d\theta}{g^2}=\frac83\cdot\frac12=\frac43,$$
其中 $g^2=2\sin^2(\theta+\pi/4)$，$\int_0^{\pi/4}\frac{d\theta}{g^2}=\frac12[-\cot(\theta+\pi/4)]_0^{\pi/4}=\frac12$。
第二项：
$$\frac83\int_{\pi/4}^{\pi/2}g\cos^3\theta\,d\theta=\frac83\left[\int_{\pi/4}^{\pi/2}\cos^4\theta\,d\theta+\int_{\pi/4}^{\pi/2}\sin\theta\cos^3\theta\,d\theta\right]$$
$$=\frac83\left[\left(\frac{3\pi}{32}-\frac14\right)+\frac1{16}\right]=\frac{\pi-2}{4}.$$
故
$$I=\frac43+\frac{\pi-2}{4}=\frac{3\pi+10}{12}.$$

**答案**：$\dfrac{3\pi+10}{12}$。

**易错点**：两个上界的大小在 $\theta=\pi/4$ 处切换（由 $\cos2\theta+\sin2\theta\ge1$ 判定），须分段积分；$\int\frac{d\theta}{(\cos\theta+\sin\theta)^2}$ 可用 $-\frac12\cot(\theta+\pi/4)$ 的导数直接得到。

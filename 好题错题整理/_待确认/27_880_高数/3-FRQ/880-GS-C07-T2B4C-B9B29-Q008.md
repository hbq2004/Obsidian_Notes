# FRQ 第 8 题

![[_Attachments/题目识别/880-GS/880-GS-C07-T2B4C-B9B29-Q008_题目.png|题目]]

(8) 设 $f(x)$ 满足 $f'(x) = \frac{1}{x} f(x) + x \cos x$ ($x > 0$)，且 $\lim\limits_{x \to 0^+} \frac{f(x)}{x} = 0$。

(I) 求 $f(x)$ 的表达式;

(II) 若 $y = f(x)$ 在 $[0, n\pi]$ 上与 $x$ 轴所围图形的面积为 $A_n$ ($n = 1, 2, \cdots$)，求 $\lim\limits_{n \to \infty} \frac{A_n}{(n+1)^2}$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-T2B4C-B9B29-Q008_答案.png|答案]]

## V4 Pro Max 解析

**考点**：一阶线性微分方程(用极限型初值定常数)+ 面积求和 + 数列极限。

**解**
**(I)** 方程 $f'(x) - \dfrac{1}{x}f(x) = x\cos x\ (x>0)$,积分因子 $\mu = e^{-\int\frac{dx}{x}} = \dfrac{1}{x}$:
$$\left(\frac{f}{x}\right)' = \cos x\;\Longrightarrow\; \frac{f(x)}{x} = \sin x + C,$$
故 $f(x) = x\sin x + Cx$。由 $\lim\limits_{x\to0^+}\dfrac{f(x)}{x} = \lim\limits_{x\to0^+}(\sin x + C) = C = 0$,得
$$f(x) = x\sin x.$$

**(II)** $y = x\sin x$ 在 $[0,n\pi]$ 上与 $x$ 轴围成的面积:
$$A_n = \int_0^{n\pi}|x\sin x|\,dx = \sum_{k=0}^{n-1}\int_{k\pi}^{(k+1)\pi}x|\sin x|\,dx.$$
在 $[k\pi,(k+1)\pi]$ 上 $|\sin x| = (-1)^k\sin x$,且 $\displaystyle\int x\sin x\,dx = -x\cos x + \sin x$,故
$$\int_{k\pi}^{(k+1)\pi}x|\sin x|dx = (-1)^k\left[(-x\cos x + \sin x)\right]_{k\pi}^{(k+1)\pi} = (-1)^k\cdot(2k+1)\pi(-1)^k = (2k+1)\pi.$$
于是 $A_n = \pi\sum\limits_{k=0}^{n-1}(2k+1) = \pi n^2$。

**答案**：(I) $f(x) = x\sin x$;(II) $\lim\limits_{n\to\infty}\dfrac{A_n}{(n+1)^2} = \lim\limits_{n\to\infty}\dfrac{\pi n^2}{(n+1)^2} = \pi$。

**易错点**：$|x\sin x|$ 需分段,每段 $\int x\sin x = -x\cos x + \sin x$ 代入端点时 $\cos(k\pi) = (-1)^k$ 的符号要仔细;极限结果是 $\pi$。

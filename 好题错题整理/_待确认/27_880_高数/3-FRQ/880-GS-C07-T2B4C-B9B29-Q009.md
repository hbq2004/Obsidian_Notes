# FRQ 第 9 题

![[_Attachments/题目识别/880-GS/880-GS-C07-T2B4C-B9B29-Q009_题目.png|题目]]

(9) 设 $f(t)$ 有二阶连续导数，$f(1) = f'(1) = 1$，在 $x > 0$ 的平面区域内，存在函数 $u(x, y)$，使得

$$du(x, y) = \left[ \frac{y^2}{x} + xf\left(\frac{y}{x}\right) \right] dx + \left[ y - xf'\left(\frac{y}{x}\right) \right] dy.  求  f(t)  及  f(t)  的极值. $$

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-T2B4C-B9B29-Q009_答案.png|答案]]

## V4 Pro Max 解析

**考点**：全微分存在 $\Leftrightarrow$ 混合偏导相等,反求 $f(t)$,再求极值。

**解**
设 $P = \dfrac{y^2}{x} + xf\left(\dfrac{y}{x}\right)$,$Q = y - xf'\left(\dfrac{y}{x}\right)$。由 $\dfrac{\partial P}{\partial y} = \dfrac{\partial Q}{\partial x}$:
$$\frac{\partial P}{\partial y} = \frac{2y}{x} + f'\left(\frac{y}{x}\right),$$
$$\frac{\partial Q}{\partial x} = -f'\left(\frac{y}{x}\right) - xf''\left(\frac{y}{x}\right)\left(-\frac{y}{x^2}\right) = -f'\left(\frac{y}{x}\right) + \frac{y}{x}f''\left(\frac{y}{x}\right).$$
令 $t = \dfrac{y}{x}$,则 $2t + f'(t) = -f'(t) + tf''(t)$,即
$$tf''(t) - 2f'(t) - 2t = 0.$$
令 $g = f'$:$tg' - 2g = 2t$,即 $g' - \dfrac{2}{t}g = 2$。积分因子 $t^{-2}$:
$$\left(\frac{g}{t^2}\right)' = \frac{2}{t^2}\;\Longrightarrow\; \frac{g}{t^2} = -\frac{2}{t} + C\;\Longrightarrow\; f'(t) = -2t + Ct^2,$$
$$f(t) = -t^2 + \frac{C}{3}t^3 + D.$$
由 $f(1) = 1,\ f'(1) = 1$:$-2 + C = 1$ 得 $C = 3$;$-1 + 1 + D = 1$ 得 $D = 1$。故
$$f(t) = t^3 - t^2 + 1.$$
极值:$f'(t) = 3t^2 - 2t = t(3t-2) = 0$,驻点 $t = 0,\ t = \dfrac{2}{3}$。$f''(t) = 6t - 2$:$f''(0) = -2 < 0$ 为极大,$f''\left(\dfrac{2}{3}\right) = 2 > 0$ 为极小。
极大值 $f(0) = 1$,极小值 $f\left(\dfrac{2}{3}\right) = \dfrac{8}{27} - \dfrac{4}{9} + 1 = \dfrac{23}{27}$。

**答案**：$f(t) = t^3 - t^2 + 1$;极大值 $f(0) = 1$,极小值 $f\left(\dfrac{2}{3}\right) = \dfrac{23}{27}$。

**易错点**：$\dfrac{\partial Q}{\partial x}$ 中 $xf'(\frac{y}{x})$ 求导用乘积法则,内层 $-y/x^2$ 的负号别丢;解 $f'$ 的线性方程用 $t^{-2}$ 作积分因子。

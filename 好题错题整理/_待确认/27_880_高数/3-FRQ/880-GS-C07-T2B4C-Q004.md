# FRQ 第 4 题

![[_Attachments/题目识别/880-GS/880-GS-C07-T2B4C-Q004_题目.png|题目]]

(4) 设 $f(x)$ 可导，对任何实数 $x$，$y$ 满足 $f(x+y) = e^x f(y) + e^y f(x)$，且 $f'(0) = e$，求 $f(x)$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-T2B4C-Q004_答案.png|答案]]

## V4 Pro Max 解析

**考点**：函数方程(柯西型)通过"固定 $x$、对 $y$ 求导"化为一阶线性方程。

**解**
$$f(x+y) = e^x f(y) + e^y f(x).$$
令 $y = 0$:$f(x) = e^x f(0) + f(x)$,故 $f(0) = 0$。
固定 $x$,对 $y$ 求导后再令 $y = 0$:
$$f'(x) = e^x f'(0) + e^y f(x)\Big|_{y=0}\cdot 1 = e^x\cdot e + f(x),$$
即
$$f'(x) - f(x) = e^{x+1}.$$
$$(f e^{-x})' = e^{x+1}e^{-x} = e\;\Longrightarrow\; f e^{-x} = ex + C.$$
由 $f(0) = 0$ 得 $C = 0$,故 $f(x) = exe^x = xe^{x+1}$。

验证:$f(x+y) = (x+y)e^{x+y+1}$,$e^xf(y) + e^y f(x) = e^xy e^{y+1} + e^y x e^{x+1} = (x+y)e^{x+y+1}$ ✓。

**答案**：$f(x) = xe^{x+1}$。

**易错点**：$f'(0) = e$ 直接代入 $y=0$ 后的导数式;对 $y$ 求导时 $e^y f(x)$ 的导数要完整写出。

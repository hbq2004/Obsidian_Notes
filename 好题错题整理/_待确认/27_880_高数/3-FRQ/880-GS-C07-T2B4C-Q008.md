# FRQ 第 8 题

![[_Attachments/题目识别/880-GS/880-GS-C07-T2B4C-Q008_题目.png|题目]]

(8) 设 $f(u)$ 在 $(0, +\infty)$ 内具有二阶导数，$z = xf\left(\frac{y}{x}\right) + yf\left(\frac{y}{x}\right)$ 满足

$$
x \frac{\partial^2 z}{\partial x \partial y} + 2y \frac{\partial^2 z}{\partial y^2} = \frac{y}{x}, z(x, x) = x, \left. \frac{\partial z}{\partial x} \right|＿{(x, x)} = -\frac{3}{2}.
$$

求 $f(u)$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-T2B4C-Q008_答案.png|答案]]

## V4 Pro Max 解析

**考点**：复合函数二阶混合偏导反求 $f(u)$,初值沿直线 $y=x$ 给定。

**解**
$z = xf\left(\dfrac{y}{x}\right) + yf\left(\dfrac{y}{x}\right) = (x+y)f(u)$,其中 $u = \dfrac{y}{x}$。
$$z_y = f(u) + (x+y)f'(u)\cdot\frac{1}{x} = f(u) + (1+u)f'(u),$$
$$z_{yy} = \frac{1}{x}f'(u) + \frac{1}{x}f'(u) + (1+u)\frac{1}{x}f''(u) = \frac{1}{x}\big[2f'(u) + (1+u)f''(u)\big],$$
$$z_{xy} = \frac{\partial}{\partial x}\big[f(u) + (1+u)f'(u)\big] = f'(u)\left(-\frac{y}{x^2}\right) + f'(u)\left(-\frac{y}{x^2}\right) + (1+u)f''(u)\left(-\frac{y}{x^2}\right)$$
$$= -\frac{u}{x}\big[2f'(u) + (1+u)f''(u)\big].$$
代入 $xz_{xy} + 2yz_{yy} = \dfrac{y}{x}$($=u$):
$$(-u + 2u)\big[2f' + (1+u)f''\big] = u\;\Longrightarrow\; 2f'(u) + (1+u)f''(u) = 1.$$
令 $g = f'$:$(1+u)g' + 2g = 1$。乘 $(1+u)$ 凑微分:
$$\big[(1+u)^2g\big]' = 1 + u\;\Longrightarrow\; (1+u)^2g = \frac{(1+u)^2}{2} + C,$$
$$f'(u) = \frac12 + \frac{C}{(1+u)^2}\;\Longrightarrow\; f(u) = \frac{u}{2} - \frac{C}{1+u} + D.$$
由 $z(x,x) = x$:$2x f(1) = x$ 得 $f(1) = \dfrac12$;由 $\left.\dfrac{\partial z}{\partial x}\right|_{(x,x)} = -\dfrac32$:
$$z_x = f(u) - u(1+u)f'(u)\Big|_{u=1} = f(1) - 2f'(1) = -\frac32,$$
得 $f'(1) = 1$。于是 $f'(1) = \dfrac12 + \dfrac{C}{4} = 1$ 得 $C = 2$;再由 $f(1) = \dfrac12 - 1 + D = \dfrac12$ 得 $D = 1$。

**答案**：$f(u) = \dfrac{u}{2} + 1 - \dfrac{2}{1+u}$。

**易错点**：$z_{xy}$ 中 $z_y$ 的三项都要对 $x$ 求导,每项都带 $u_x = -y/x^2$;$z_x(x,x)$ 沿直线 $y=x$ 代入时 $u=1$。

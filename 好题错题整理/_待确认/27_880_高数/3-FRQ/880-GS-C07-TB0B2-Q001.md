# FRQ 第 1 题

![[_Attachments/题目识别/880-GS/880-GS-C07-TB0B2-Q001_题目.png|题目]]

(1)设环境保持恒定温度 $20^\circC$，有一物体的温度在10s内从 $100^\circC$ 降到 $60^\circC$，若物体温度下降的速度与该物体与环境温度之差成正比，问此物体从 $100^\circC$ 降到 $25^\circC$ 需要多少时间？

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-TB0B2-Q001_答案.png|答案]]

## V4 Pro Max 解析

**考点**：牛顿冷却定律(一阶线性/可分离变量方程)的应用。

**解**
设物体温度 $T(t)$,环境温度 $T_0 = 20^\circ$C。由"温度下降速度与温差成正比":
$$\frac{dT}{dt} = -k(T - 20),$$
分离变量积分得 $T = 20 + (T_{\text{初}} - 20)e^{-kt}$。初温 $100^\circ$C:
$$T(t) = 20 + 80e^{-kt}.$$
$10\,\text{s}$ 内从 $100^\circ$ 降到 $60^\circ$:$60 = 20 + 80e^{-10k}$,得 $e^{-10k} = \dfrac12$,即 $k = \dfrac{\ln 2}{10}$。
降至 $25^\circ$C:$25 = 20 + 80e^{-kt}$,得 $e^{-kt} = \dfrac{1}{16} = 2^{-4}$,故 $kt = 4\ln 2$,于是
$$t = \frac{4\ln 2}{k} = \frac{4\ln 2}{\ln 2 / 10} = 40\ \text{s}.$$

**答案**：需要 $40$ 秒。

**易错点**：$k = \dfrac{\ln 2}{10}$ 要从 $e^{-10k}=\frac12$ 反解;注意"从 $100^\circ$ 降到 $25^\circ$"是全程时间,不要再减去前面的 10 秒。

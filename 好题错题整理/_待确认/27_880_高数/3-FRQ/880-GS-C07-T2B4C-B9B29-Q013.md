# FRQ 第 13 题

![[_Attachments/题目识别/880-GS/880-GS-C07-T2B4C-B9B29-Q013_题目.png|题目]]

(13)设上凸曲线 $y = y(x)$ ($y > 0$) 上任一点 $M(x, y)$ 处的切线与 $x$ 轴交于点 $N$，且满足 $|OM| = |ON|$， $y(0) = 1$， $y'(x) > 0$，求 $y = y(x)$。

14)设 $y = y(x)$ 是向上凸的连续曲线，其上任一点 $(x, y)$ 处的曲率为 $\frac{1}{\sqrt{1 + y'^2}}$，且此曲线上点 $(0, 1)$ 处

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-T2B4C-B9B29-Q013_答案.png|答案]]

## V4 Pro Max 解析

**考点**：几何条件(切线截距)建立微分方程,解出曲线(用 $|OM|=|ON|$ 需分析符号)。

**解**
曲线 $y = y(x)$ 上凸、$y'>0$、$y>0$。过 $M(x,y)$ 的切线为 $Y - y = y'(X - x)$,与 $x$ 轴交点 $N$ 的横坐标为 $X = x - \dfrac{y}{y'}$。条件
$$\sqrt{x^2 + y^2} = \left|x - \frac{y}{y'}\right|.$$
平方:
$$x^2 + y^2 = x^2 - \frac{2xy}{y'} + \frac{y^2}{y'^2}
\;\Longrightarrow\; y^2y'^2 + 2xyy' - y^2 = 0.$$
解关于 $y'$ 的二次方程($y'>0$):
$$y' = \frac{-x + \sqrt{x^2+y^2}}{y} = \frac{y}{\sqrt{x^2+y^2}+x}.$$
(另一支 $\dfrac{-x-\sqrt{x^2+y^2}}{y}<0$ 舍去。)改写为
$$\frac{dx}{dy} = \frac{\sqrt{x^2+y^2} + x}{y}.$$
令 $u = \dfrac{x}{y}$,则 $x = uy$,$\dfrac{dx}{dy} = u + y\dfrac{du}{dy}$,代入:
$$u + y\frac{du}{dy} = \sqrt{u^2+1} + u\;\Longrightarrow\; y\frac{du}{dy} = \sqrt{u^2+1},$$
$$\frac{du}{\sqrt{u^2+1}} = \frac{dy}{y}\;\Longrightarrow\; \operatorname{arsinh}u = \ln y + C,$$
$$u = \sinh(\ln y + C) = \frac{Cy - \frac{1}{Cy}}{2},$$
$$x = \frac{C^2y^2 - 1}{2C}\;\Longrightarrow\; C^2y^2 - 2Cx = 1.$$
由 $y(0) = 1$ 得 $C^2 = 1$,取 $C = 1$($y>0$):
$$y^2 = 1 + 2x\;\Longrightarrow\; y = \sqrt{1+2x}.$$

验证:切线 $Y - \sqrt{1+2x} = \dfrac{1}{\sqrt{1+2x}}(X-x)$,与 $x$ 轴交点横坐标 $X = x - y^2 = -x-1$,$|ON| = x+1 = \sqrt{x^2+y^2} = |OM|$ ✓;$y'' = -(1+2x)^{-3/2} < 0$ 上凸 ✓。

**答案**：$y = \sqrt{1+2x}$。

**易错点**：$|x - y/y'|$ 平方后符号信息丢失,必须结合 $y'>0$ 选根;验根时用 $y(0)=1$ 及切线几何关系双重校验。

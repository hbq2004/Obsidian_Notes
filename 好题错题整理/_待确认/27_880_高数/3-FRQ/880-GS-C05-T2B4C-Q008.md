# FRQ 第 8 题

![[_Attachments/题目识别/880-GS/880-GS-C05-T2B4C-Q008_题目.png|题目]]

(8) 设 $u(x, y)$ 有二阶连续偏导数，利用变换 $\xi = x + ay$，$\eta = x + by$，将方程 $\frac{\partial^2 u}{\partial x^2} + 4 \frac{\partial^2 u}{\partial x \partial y} + 3 \frac{\partial^2 u}{\partial y^2} = 0$ 化为 $\frac{\partial^2 u}{\partial \xi \partial \eta} = 0$，求 $a, b$ 的值.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C05-T2B4C-Q008_答案.png|答案]]

## V4 Pro Max 解析

**考点**：线性变量替换下二阶偏导方程的化简（求 $a,b$ 使交叉项方程成立）。

**解**
$\xi=x+ay$，$\eta=x+by$。链式法则：
$$u_x=u_\xi+u_\eta,\qquad u_y=a\,u_\xi+b\,u_\eta.$$
$$u_{xx}=u_{\xi\xi}+2u_{\xi\eta}+u_{\eta\eta},$$
$$u_{xy}=a\,u_{\xi\xi}+(a+b)u_{\xi\eta}+b\,u_{\eta\eta},$$
$$u_{yy}=a^{2}u_{\xi\xi}+2ab\,u_{\xi\eta}+b^{2}u_{\eta\eta}.$$

代入 $u_{xx}+4u_{xy}+3u_{yy}=0$：
$$(1+4a+3a^{2})u_{\xi\xi}+\bigl[2+4(a+b)+6ab\bigr]u_{\xi\eta}+(1+4b+3b^{2})u_{\eta\eta}=0.$$

要求化为 $u_{\xi\eta}=0$，故
$$1+4a+3a^{2}=0,\qquad 1+4b+3b^{2}=0,$$
即 $a,b\in\{-1,-\frac13\}$。又变换须非退化，$a\ne b$。

**答案**：$\{a,b\}=\{-1,-\frac13\}$（两者可互换）。

**易错点**：交叉项系数为 $2+4(a+b)+6ab$，注意 $u_{xy}$ 中交叉项系数是 $a+b$；$a=b$ 会使变换退化，须排除。

# FRQ 第 17 题

![[_Attachments/题目识别/YBS5T/YBS5T-S4-Q17_题目.png|题目]]

设函数 $f(x) = \begin{cases} x + 2x^2 \sin \frac{1}{x}, & x \neq 0, \\ 0, & x = 0. \end{cases}$

(1) 求 $f'(x)$，并讨论 $f'(x)$ 的连续性；
(2) 求 $f'\left(\frac{1}{2k\pi}\right)$，$k = \pm 1, \pm 2, \cdots$，并由此判断是否存在 $\delta > 0$，使得 $f(x)$ 在 $(-\delta, \delta)$ 内单调？

![[_Attachments/题目识别/YBS5T-答案/YBS5T-S4-Q17_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**

(1) 当 \(x\ne0\) 时，
\[
f'(x)=1+4x\sin\frac1x-2\cos\frac1x.
\]
当 \(x=0\) 时，由导数定义：
\[
f'(0)=\lim_{h\to0}\frac{f(h)-f(0)}h
=\lim_{h\to0}\left(1+2h\sin\frac1h\right)=1.
\]
所以
\[
f'(x)=
\begin{cases}
1+4x\sin\frac1x-2\cos\frac1x,&x\ne0,\\
1,&x=0.
\end{cases}
\]
\(f'(x)\) 在 \(x\ne0\) 连续；在 \(x=0\) 处 \(\lim_{x\to0}f'(x)\) 不存在，故 \(f'(x)\) 在 \(x=0\) 处不连续，为第二类振荡间断点。

(2)
\[
f'\left(\frac1{2k\pi}\right)=-1,\quad k=\pm1,\pm2,\cdots.
\]
不存在这样的 \(\delta>0\)。

关键给分点：分段点导数用定义求；非零点用求导公式；用两列子列或振荡说明导数极限不存在；用导数符号与单调性关系否定局部单调。

**解题切入点**

题中 \(2x^2\sin(1/x)\) 在 \(0\) 附近被 \(|2x^2|\) 压住，故 \(f(0)\) 处可导；但其导函数含 \(-2\cos(1/x)\)，在 \(0\) 附近高频振荡，所以导函数不连续。判断局部单调时，像算法中“在任意小邻域内找反例序列”：取 \(x_k=1/(2k\pi)\to0\)，这些点上导数为 \(-1\)，与 \(f'(0)=1\) 矛盾，故不可能单调。

**推演**

1. 求 \(x\ne0\) 的导数：
\[
f'(x)=1+4x\sin\frac1x+2x^2\cos\frac1x\cdot\left(-\frac1{x^2}\right)
=1+4x\sin\frac1x-2\cos\frac1x.
\]

2. 求 \(x=0\) 的导数：
\[
f'(0)=\lim_{h\to0}\frac{h+2h^2\sin(1/h)}h
=\lim_{h\to0}\left(1+2h\sin\frac1h\right)=1.
\]
这里 \(|2h\sin(1/h)|\le2|h|\to0\)。

3. 连续性：
在任意 \(x\ne0\)，上式是初等函数复合，连续。在 \(0\) 处，取
\[
x_k=\frac1{2k\pi}\to0,\quad f'(x_k)=-1,
\]
取
\[
y_k=\frac1{(2k+1)\pi}\to0,\quad f'(y_k)=3,
\]
所以 \(\lim_{x\to0}f'(x)\) 不存在。因此 \(f'\) 在 \(0\) 处不连续。

4. 令 \(x_k=1/(2k\pi)\)。因 \(\sin(2k\pi)=0,\cos(2k\pi)=1\)，得
\[
f'(x_k)=1+4x_k\cdot0-2\cdot1=-1.
\]
且 \(x_k\to0\)。

5. 反证法：若存在 \(\delta>0\) 使 \(f\) 在 \((-\delta,\delta)\) 上单调。
- 若单调增加，则可导点处导数必非负；但取 \(|k|\) 充分大使 \(0<|x_k|<\delta\)，有 \(f'(x_k)=-1<0\)，矛盾。
- 若单调减少，则可导点处导数必非正；但 \(f'(0)=1>0\)，矛盾。

故不存在。

**易错点**

- 勿将 \(x\ne0\) 的导数表达式直接代入 \(x=0\)，\(x=0\) 处必须用导数定义。
- \(\sin(1/x)\) 和 \(\cos(1/x)\) 在 0 处无极限，但 \(x\sin(1/x),x^2\sin(1/x)\) 有极限 0；求导后出现 \(\cos(1/x)\) 导致导数无极限。
- \(f'(0)=1\) 不等于 \(f'(x)\) 在 0 连续；也不等于 \(f\) 在 0 附近单调。判断单调要用区间上导数符号，且需排除负导数点。
- 反证时不要只看到 \(f'(0)>0\) 就认为局部单调增；高频振荡项使导数在任意小邻域内取负值。

**命题规律**

本题是典型“分段点导数 + 导函数连续性 + 局部单调性”综合题，常以 \(x^n\sin(1/x)\) 为载体。命题套路：先用定义求分段点导数，再观察导函数中 \(\cos(1/x)\) 的振荡判断不连续，最后用特殊点列破坏单调性。复习建议：熟练掌握导数定义、无穷小乘有界量、导数符号与单调性关系；对 \(\sin(1/x)\) 类振荡函数要会构造序列取不同极限。

# MCQ 第 8 题

![[_Attachments/题目识别/YBS5T/YBS5T-S3-Q08_题目.png|题目]]

设随机变量 $X$ 的分布律为 $P\{X=k\}=(1-p)^{k-1}p, k=1,2,3,\cdots$, 其中 $0<p<1$, $m,n$ 为正整数, 则 $P\{X>m+n \mid X>m\}$ ( ).

(A) 与 $m$ 无关, 与 $n$ 有关
(B) 与 $m$ 有关, 与 $n$ 无关
(C) 与 $m,n$ 均无关
(D) 与 $m,n$ 均有关

![[_Attachments/题目识别/YBS5T-答案/YBS5T-S3-Q08_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**

选择题【答案】: (A)

**解题切入点**
考查几何分布的无记忆性。几何分布是离散型分布中唯一具有无记忆性的分布，其条件概率与过去无关。

**推演**
几何分布：$P\\{X=k\\}=(1-p)^{k-1}p, k=1,2,\\dots$。
先计算$P\\{X>k\\}$：
$$P\\{X>k\\}=\\sum_{i=k+1}^{\\infty}(1-p)^{i-1}p = (1-p)^k.$$
因此，
$$P\\{X>m+n \\mid X>m\\} = \\frac{P\\{X>m+n, X>m\\}}{P\\{X>m\\}} = \\frac{P\\{X>m+n\\}}{P\\{X>m\\}} = \\frac{(1-p)^{m+n}}{(1-p)^m} = (1-p)^n.$$
而$P\\{X>n\\} = (1-p)^n$，所以条件概率等于$P\\{X>n\\}$，只与$n$有关，与$m$无关。
选项(A)正确；选项(B)错误，因为与m无关；选项(C)错误，因为与n有关；选项(D)错误，因为与m无关，与n有关。

**易错点**
易错点：误将条件概率公式写错，或者忘记$P\\{X>k\\}$的计算。注意几何分布无记忆性的推导。

**命题规律**
几何分布的无记忆性是常考知识点，常与指数分布的无记忆性结合考查。复习时需掌握几何分布的概率分布、期望方差以及无记忆性的证明与应用。

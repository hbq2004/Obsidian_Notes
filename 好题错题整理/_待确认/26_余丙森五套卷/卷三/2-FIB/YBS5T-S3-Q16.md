# FIB 第 16 题

![[_Attachments/题目识别/YBS5T/YBS5T-S3-Q16_题目.png|题目]]

设甲抛 3 次硬币，乙抛 2 次硬币，则甲所抛正面数多于乙所抛正面数的概率为 \_.

![[_Attachments/题目识别/YBS5T-答案/YBS5T-S3-Q16_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**

$$\boxed{\frac{1}{2}}$$

**解题切入点**

这题像算法竞赛里的“枚举状态+容斥/前缀和”：甲乙各自抛硬币是独立的伯努利试验，甲的正面数 $X\sim B(3,\frac12)$，乙的正面数 $Y\sim B(2,\frac12)$。破题角度就是枚举 $X$ 和 $Y$ 的可能取值，按联合分布求和 $P(X>Y)=\sum P(X=k)P(Y=j)$，本质是离散概率的枚举求和。

**推演**

设甲的正面数为 $X$，乙的正面数为 $Y$。

甲抛 3 次硬币，每次正面概率 $\frac12$，所以

$$P(X=k)=\binom{3}{k}\left(\frac12\right)^3,\quad k=0,1,2,3.$$

乙抛 2 次硬币，同理

$$P(Y=j)=\binom{2}{j}\left(\frac12\right)^2,\quad j=0,1,2.$$

甲乙抛硬币彼此独立，所以

$$
\begin{aligned}
P(X>Y)&=\sum_{k=1}^{3}\sum_{j=0}^{\min(2,k-1)}P(X=k)P(Y=j)\\
&=\left(\frac12\right)^5\sum_{k=1}^{3}\binom{3}{k}\sum_{j=0}^{\min(2,k-1)}\binom{2}{j}.
\end{aligned}
$$

逐项计算：

- $k=1$ 时，$j=0$：贡献 $\binom{3}{1}\binom{2}{0}=3$；
- $k=2$ 时，$j=0,1$：贡献 $\binom{3}{2}(\binom{2}{0}+\binom{2}{1})=3\times3=9$；
- $k=3$ 时，$j=0,1,2$：贡献 $\binom{3}{3}(\binom{2}{0}+\binom{2}{1}+\binom{2}{2})=1\times4=4$。

总贡献为 $3+9+4=16$，所以

$$P(X>Y)=\frac{16}{2^5}=\frac{1}{2}.$$

也可用对称性检验：$X$ 与 $3-Y$ 同分布，且事件 $X>Y$ 与 $3-Y>3-X$ 对称，故两部分概率相等，因此各为 $\frac12$。直接枚举更稳妥。

**易错点**

1. 忘记 $Y$ 只能取 $0,1,2$，导致 $k=1$ 时误把 $j<1$ 算成 $j=0,1$，多算一项。
2. 把 $P(X>Y)$ 误写成 $P(X-Y>0)$ 再用二项分布相减，离散情况下不能直接用正态或普通二项分布减法。
3. 漏乘 $\left(\frac12\right)^3$ 和 $\left(\frac12\right)^2$，或把分母写成 $2^3+2^2$。
4. 想当然认为“甲多抛一次所以概率大于 $\frac12$”，实际上恰好是 $\frac12$。

**命题规律**

这是典型的古典概型/伯努利试验基础题，常见于选择题或填空题第一梯队，难度不大但考计算仔细。命题人常用“多抛一次”制造直觉陷阱，或用“不少于”“不多于”改变事件边界。复习时建议把二项分布、超几何分布、几何分布的离散概率求和练熟，并养成“列分布列再求和”的固定流程。

题面按原题理解；注意题干中“甲所抛正面数多于乙所抛正面数”即 $X>Y$，无 OCR 疑误。

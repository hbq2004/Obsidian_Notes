# FIB 第 16 题

![[_Attachments/题目识别/YBS5T/YBS5T-S1-Q16_题目.png|题目]]

16. 设随机变量 $X, Y$ 独立同分布，且 $X \sim N(0, 1)$，记 $U = \max\{X, Y\}$，$V = \min\{X, Y\}$，则方差 $D(U - V) =$ \_\_\_\_\_\_\_\_\_\_\_\_.

![[_Attachments/题目识别/YBS5T-答案/YBS5T-S1-Q16_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**

$$D(U-V)=2-\frac{4}{\pi}$$

**解题切入点**

本题主要考查顺序统计量及方差计算。关键点在于发现 $U-V = |X-Y|$，从而将问题转化为求 $|X-Y|$ 的方差，其中 $X,Y$ 独立同分布 $N(0,1)$。类似算法竞赛中，将复杂结构转化为标准形式，利用已知分布性质求解。

**推演**

1. 由 $X,Y$ 独立同分布 $N(0,1)$，记 $U=\max\{X,Y\}, V=\min\{X,Y\}$，则 $U-V = |X-Y|$。

2. 令 $Z = X-Y$，则 $Z \sim N(0,2)$（因为 $E(Z)=0$，$D(Z)=D(X)+D(Y)=2$）。

3. 计算 $D(|Z|)$：$D(|Z|) = E(Z^2) - [E(|Z|)]^2$。

4. $E(Z^2) = D(Z) = 2$（因为 $E(Z)=0$）。

5. 对于 $Z \sim N(0,\sigma^2)$，$E(|Z|) = \sigma \sqrt{\frac{2}{\pi}}$。这里 $\sigma = \sqrt{2}$，故 $E(|Z|) = \sqrt{2} \cdot \sqrt{\frac{2}{\pi}} = \frac{2}{\sqrt{\pi}}$。

6. 所以 $D(|Z|) = 2 - \left(\frac{2}{\sqrt{\pi}}\right)^2 = 2 - \frac{4}{\pi}$。

7. 因此 $D(U-V) = 2 - \frac{4}{\pi}$。

**易错点**

1. 误认为 $U-V$ 与 $|X-Y|$ 不等价，或直接计算 $U,V$ 的方差协方差导致复杂计算。

2. 在计算 $E(|Z|)$ 时，误用 $\sigma$，例如忘记 $Z$ 方差为2，使用 $\sigma=1$ 导致错误。

3. 混淆 $D(|Z|)$ 与 $D(Z)$，或者忘记 $E(Z^2)=D(Z)$ 当 $E(Z)=0$。

4. 计算 $E(|Z|)$ 时，$\sqrt{\frac{2}{\pi}}$ 系数记忆错误。

**命题规律**

此类题目通常考查顺序统计量的数字特征，尤其是极差（最大值与最小值之差）的期望与方差。对于正态分布、均匀分布等常见分布，结论常考且可推广。复习时应注意掌握独立同分布随机变量函数的分布与数字特征计算方法，以及常见分布的期望、方差公式。

# FIB 第 15 题

![[_Attachments/题目识别/YBS5T/YBS5T-S2-Q15_题目.png|题目]]

已知三阶矩阵 $A$ 与三维列向量 $x$ 满足 $A^3 x + A^2 x - 3Ax = 0$，且向量组 $x, Ax, A^2 x$ 线性无关，则 $r(A) + r(E - A) =$ \_ .

![[_Attachments/题目识别/YBS5T-答案/YBS5T-S2-Q15_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**

【答案】: $$5$$

**解题切入点**

考查线性无关向量组、矩阵的秩、相似变换等知识点。破题角度：由线性无关向量组构造基，将矩阵转化为相似矩阵，通过计算相似矩阵的秩得到答案。算法竞赛类比：类似给定递推关系，通过构造友矩阵求秩。

**推演**

**方法一（基变换法）**  
1. 由条件 $A^3 x + A^2 x - 3A x = 0$ 得 $A^3 x = -A^2 x + 3A x$。  
2. 因为 $x, Ax, A^2x$ 线性无关，所以它们构成 $\mathbb{R}^3$ 的一组基。取基 $\beta_1 = x, \beta_2 = Ax, \beta_3 = A^2x$。  
3. 计算 $A$ 在此基下的矩阵 $M$：$A\beta_1 = \beta_2$，$A\beta_2 = \beta_3$，$A\beta_3 = 3\beta_2 - \beta_3$。因此 $$M = \begin{pmatrix}0&0&0\\1&0&3\\0&1&-1\end{pmatrix}$$（列向量为像在基下的坐标）。  
4. $A$ 与 $M$ 相似，故 $r(A)=r(M)$。计算 $M$ 的秩：第二行 $(1,0,3)$ 与第三行 $(0,1,-1)$ 线性无关，第一行全零，所以 $r(M)=2$，从而 $r(A)=2$。（得分点：相似得秩相等，正确计算秩）  
5. 同理，$E-A$ 在基下的矩阵为 $I-M = \begin{pmatrix}1&0&0\\-1&1&-3\\0&-1&2\end{pmatrix}$。计算行列式 $\det(I-M)=1\cdot(1\cdot2-(-3)\cdot(-1)) = -1 \neq 0$，故 $I-M$ 满秩，$r(E-A)=3$。（得分点：计算行列式判断满秩）  
6. 因此 $r(A)+r(E-A)=2+3=5$。

**方法二（特征多项式法）**（简要）  
1. 由条件得 $f(A)x=0$，其中 $f(\lambda)=\lambda^3+\lambda^2-3\lambda$。  
2. 由 $x, Ax, A^2x$ 线性无关知 $A$ 的最小多项式次数为 $3$，且整除 $f(\lambda)$，而 $f(\lambda)$ 无重因式，故最小多项式即为 $f(\lambda)$，从而特征多项式也为 $f(\lambda)$。  
3. 特征值为 $0,\ \frac{-1\pm\sqrt{13}}{2}$，$0$ 是单根，故 $r(A)=2$；$E-A$ 的特征值均非零，故可逆，$r(E-A)=3$。  
4. 和为 $5$。

**易错点**  
1. 构造基时，注意基向量的顺序，矩阵的列对应的是基向量在变换下的像在基下的坐标，顺序不能颠倒。  
2. 计算 $I-M$ 时，注意 $E-A$ 在基下的矩阵是 $I-M$，不是 $M-I$，不要弄错符号。  
3. 用特征多项式法时，需说明最小多项式等于特征多项式的原因（循环向量），否则可能被扣分。

**命题规律**  
考研线代中，经常通过线性无关向量组构造基，将矩阵转化为相似矩阵，再计算秩、行列式等。此类题综合性强，但套路明显。复习时应熟练掌握基变换、相似矩阵、秩的计算，以及矩阵多项式与最小多项式的关系。建议多练类似题目，如已知 $A^2x=Ax+x$ 等条件求秩。

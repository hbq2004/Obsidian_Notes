# MCQ 第 8 题

![[_Attachments/题目识别/YBS5T/YBS5T-S2-Q08_题目.png|题目]]

设二维随机变量 $X,Y$ 的概率密度为 $f(x,y)$，如果对任意的 $x,y \in \mathbf{R}$，有 $f(x,y) = f(y,x)$，且 $X$ 与 $Y$ 的相关系数存在，则下列结论不正确的是(\_\_\_\_\_\_).
(A) $P\{X>Y\} = P\{X<Y\}$
(B) $X$ 与 $Y$ 同分布
(C) $X-Y$ 的概率密度为偶函数
(D) $X$ 与 $Y$ 不相关

![[_Attachments/题目识别/YBS5T-答案/YBS5T-S2-Q08_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**
【答案】(D)

【推演】
- 选项(A)：由于联合密度函数关于直线 $y=x$ 对称，区域 $\lbrace x>y\rbrace$ 与 $\lbrace x<y\rbrace$ 对称且测度相等，故概率相等，$P\lbrace X>Y\rbrace=P\lbrace X<Y\rbrace$，正确。
- 选项(B)：由 $f(x,y)=f(y,x)$ 得边缘密度 $f_X(x)=\int f(x,y)dy=\int f(y,x)dy=\int f(t,x)dt=f_Y(x)$，故 $X$ 与 $Y$ 同分布，正确。
- 选项(C)：令 $Z=X-Y$，由对称性知 $(X,Y)$ 与 $(Y,X)$ 同分布，故 $Z$ 与 $-Z$ 同分布，所以 $Z$ 的概率密度为偶函数，正确。
- 选项(D)：对称性不能保证协方差为零，例如 $X,Y$ 服从均值相等、方差相等的二维正态分布，当相关系数 $\rho\neq0$ 时仍满足 $f(x,y)=f(y,x)$，但 $X$ 与 $Y$ 相关，故 $X$ 与 $Y$ 不一定不相关，因此(D)不正确。

**易错点**
1. 混淆“对称”与“独立”：对称性只说明 $X$ 与 $Y$ 地位相同，但可能相关。
2. 误以为 $X$ 与 $Y$ 同分布则一定不相关，实际上同分布与相关性无关。

**命题规律**
利用对称性考查概率、分布、数字特征的关系，常见于选择题。复习时需注意从对称性推出的结论及其局限性。

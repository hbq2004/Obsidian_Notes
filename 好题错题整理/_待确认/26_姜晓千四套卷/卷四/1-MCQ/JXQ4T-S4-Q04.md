# MCQ 第 4 题

![[_Attachments/题目识别/JXQ4T/JXQ4T-S4-Q04_题目.png|题目]]

设级数 $$\sum_{n=1}^{\infty} \frac{a^n n!}{n^n} (a>0)$$ 收敛，级数 $$\sum_{n=1}^{\infty} \frac{\sqrt{n+2}-\sqrt{n-2}}{n^a}$$ 发散，则 ( ) 。
(A) $a>e$
(B) $0<a<e$
(C) $0<a \leq \frac{1}{2}$
(D) $\frac{1}{2} \leq a < e$

![[_Attachments/题目识别/JXQ4T-答案/JXQ4T-S4-Q04_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：选择题【答案】: (C) 0<a≤1/2。

**解题切入点**：考查级数收敛性判别，利用比值判别法判断第一个级数，利用等价无穷小和p级数判断第二个级数，结合条件求交集。类比算法竞赛：用时间复杂度分析，比值判别法类似比较增长率，p级数类似积分判别法。

**推演**：完整分步求解过程。

解：对于第一个级数：$\sum_{n=1}^{\infty} \frac{a^n n!}{n^n} \ (a>0)$。设$u_n = \frac{a^n n!}{n^n}$，则$\lim_{n\to\infty} \frac{u_{n+1}}{u_n} = \lim_{n\to\infty} a \left(\frac{n}{n+1}\right)^n = \frac{a}{e}$。由比值判别法，当$\frac{a}{e}<1$即$a<e$时级数收敛；当$\frac{a}{e}>1$即$a>e$时发散；当$a=e$时，$u_n = \frac{e^n n!}{n^n}$，由斯特林公式$n! \sim \sqrt{2\pi n} \left(\frac{n}{e}\right)^n$，得$u_n \sim \sqrt{2\pi n} \to \infty$，故级数发散。所以第一个级数收敛的条件是$0<a<e$。

对于第二个级数：$\sum_{n=1}^{\infty} \frac{\sqrt{n+2}-\sqrt{n-2}}{n^a}$。先化简通项：$\sqrt{n+2}-\sqrt{n-2} = \frac{4}{\sqrt{n+2}+\sqrt{n-2}} \sim \frac{4}{2\sqrt{n}} = \frac{2}{\sqrt{n}} \ (n\to\infty)$。故通项$\sim \frac{2}{n^{a+1/2}}$。由比较判别法，该级数收敛当且仅当$a+1/2>1$即$a>1/2$；发散当$a\le 1/2$。所以第二个级数发散的条件是$0<a\le 1/2$。

同时满足第一个级数收敛且第二个级数发散，得$a$的取值范围为$(0,1/2]$（注意$a>0$）。故正确选项为(C)。

逐一分析各选项：
(A) $a>e$：第一个级数发散，不满足条件。
(B) $0<a<e$：包含$a>1/2$的部分，此时第二个级数收敛，不满足条件。
(C) $0<a\le 1/2$：完全符合条件。
(D) $1/2 \le a < e$：除了$a=1/2$外，其余$a>1/2$导致第二个级数收敛，不满足条件；仅$a=1/2$满足，但选项整体错误。

**易错点**：1. 忽略第一个级数在$a=e$时的发散情况，误以为$a<e$收敛即可，但$a=e$时发散，但本题中$a<e$才收敛，所以不影响。但更关键的是第二个级数的化简，要小心分子有理化，得到等价于$2/\sqrt{n}$，然后注意$p$级数判别。2. 注意$a=1/2$是边界，第二个级数发散，第一个收敛，所以包含在答案中。3. 有些同学可能错误地将第二个级数化为$2/n^{a+1/2}$后，误以为$a+1/2>1$收敛，所以$a>1/2$收敛，$a<1/2$发散，但忽略$a=1/2$时发散，导致误选(D)。4. 比值判别法要小心极限为1的情况，需要进一步判断。

**命题规律**：命题套路：将两个不同级数条件结合，求参数范围。常见于选择题，需要分别判断收敛性，再取交集。复习建议：熟练掌握正项级数判别法（比值、根值、比较、p级数），注意边界情况，以及分子有理化等技巧。另外，第一个级数涉及阶乘和幂，通常用比值判别法，并记住极限$a/e$。

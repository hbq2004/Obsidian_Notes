# FIB 第 12 题

![[_Attachments/题目识别/JXQ4T/JXQ4T-S1-Q12_题目.png|题目]]

设 $f(x)$ 为微分方程 $xf'(x)-f(x)=\sqrt{2x-x^2}$ 满足初始条件 $f(1)=0$ 的解,则 $\int_0^1 f(x)dx =$ \_.

![[_Attachments/题目识别/JXQ4T-答案/JXQ4T-S1-Q12_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**

【答案】$$\boxed{-\frac{\pi}{8}}$$

**解题切入点**

本题类似算法竞赛中利用等式本身化简的技巧，不必解出$f(x)$，直接对原方程两边积分，并处理$xf'(x)$的分部积分，即可将所求积分与已知积分建立联系。

**推演**

设$I=\int_0^1 f(x)dx$。对原方程 $xf'(x)-f(x)=\sqrt{2x-x^2}$ 两边同时在 $[0,1]$ 上积分：

$$\int_0^1 x f'(x) dx - \int_0^1 f(x) dx = \int_0^1 \sqrt{2x-x^2} dx$$

左端第一项用分部积分：

$$\int_0^1 x f'(x) dx = \left[ x f(x) \right]_0^1 - \int_0^1 f(x) dx = 1\cdot f(1) - 0\cdot f(0) - I = -I$$

因为$f(1)=0$，且$x f(x)|_{x=0}=0$。于是左端为 $-I - I = -2I$。

右端：$$\int_0^1 \sqrt{2x-x^2} dx = \int_0^1 \sqrt{1-(x-1)^2} dx$$ 令$t=x-1$，得 $\int_{-1}^{0} \sqrt{1-t^2} dt = \int_{0}^{1} \sqrt{1-t^2} dt = \frac{\pi}{4}$（单位圆第一象限面积）。

因此 $-2I = \frac{\pi}{4}$，解得 $I = -\frac{\pi}{8}$。

**易错点**

1. 容易试图先解微分方程再积分，导致计算量过大；
2. 分部积分时端点$0$处容易误认为需要$f(0)=0$，实则因子$x$已经保证乘积为$0$；
3. 右端积分是$[0,1]$区间，为四分之一圆面积，勿当成$\pi/2$。

**命题规律**

此类题型常考“不求解微分方程，利用已知方程进行整体积分”，通过分部积分建立所求积分与简单积分的关系。复习时应重视微分方程两边积分、分部积分的组合运用，并注意端点处理。

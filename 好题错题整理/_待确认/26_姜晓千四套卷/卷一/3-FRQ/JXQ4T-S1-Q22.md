# FRQ 第 22 题

![[_Attachments/题目识别/JXQ4T/JXQ4T-S1-Q22_题目.png|题目]]

设二维随机变量 $(X,Y)$ 的条件概率密度为

$$
f_{X|Y}(x|y)=A\mathrm{e}^{-2\left(x-\frac{y}{2}\right)^2},-\infty < x < +\infty
$$

$$
f_{Y|X}(y|x)=B\mathrm{e}^{-(y-x)^2},-\infty < y < +\infty
$$

(I) 求 $A,B$ 的值；

(II) 求 $X,Y$ 的边缘概率密度 $f_X(x),f_Y(y)$；

(III) 求 $X$ 与 $Y$ 的相关系数 $\rho_{XY}$ .

![[_Attachments/题目识别/JXQ4T-答案/JXQ4T-S1-Q22_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**

(I) $A=√(2/π)$，$B=1/√π$。

(II) $f_X(x)=1/√π·e^{-x^2}$，$f_Y(y)=1/√(2π)·e^{-y^2/2}$。

(III) $ρ_{XY}=1/√2$。

关键给分点：条件密度积分归一求 A,B；由 $f_{X|Y}f_Y=f_{Y|X}f_X$ 列相容方程；分离变量并归一化求边缘密度；用 $E[XY]=E[XE[Y|X]]$ 及方差公式求相关系数。

**解题切入点**

两个条件分布都是正态：$X|Y=y$ 服从 $N(y/2,1/4)$，$Y|X=x$ 服从 $N(x,1/2)$。题目给的是“双向条件”耦合，像算法题中由两条映射反推原串：利用联合密度两种分解式 $f=f_{X|Y}f_Y=f_{Y|X}f_X$ 把未知边缘密度分离变量；相关系数用条件期望回代即可。

**推演**

1. 求 A、B：

对固定 y，令 $t=x-y/2$，则
$$1=∫_{-∞}^{+∞}Ae^{-2(x-y/2)^2}dx=A∫_{-∞}^{+∞}e^{-2t^2}dt=A√(π/2),$$
所以 $A=√(2/π)$。

对固定 x，令 $u=y-x$，则
$$1=∫_{-∞}^{+∞}Be^{-(y-x)^2}dy=B∫_{-∞}^{+∞}e^{-u^2}du=B√π,$$
所以 $B=1/√π$。

2. 边缘密度：

由联合密度的两种分解式
$$f_{X|Y}(x|y)f_Y(y)=f_{Y|X}(y|x)f_X(x).$$
代入 A、B：
$$√(2/π)e^{-2(x-y/2)^2}f_Y(y)=1/√π·e^{-(y-x)^2}f_X(x).$$
两边乘以 $√π$：
$$√2 e^{-2(x-y/2)^2}f_Y(y)=e^{-(y-x)^2}f_X(x).$$
于是
$$f_X(x)/f_Y(y)=√2 e^{-2(x-y/2)^2+(y-x)^2}=√2 e^{-x^2+y^2/2}.$$
取对数并分离变量：
$$ln f_X(x)+x^2=ln f_Y(y)+ln√2+y^2/2=C.$$
于是
$$f_X(x)=e^C e^{-x^2}, f_Y(y)=e^C/√2·e^{-y^2/2}.$$
由 $∫_{-∞}^{+∞}f_X(x)dx=1$：
$$e^C∫_{-∞}^{+∞}e^{-x^2}dx=e^C√π=1,$$
得 $e^C=1/√π$。

因此
$$f_X(x)=1/√π·e^{-x^2}, f_Y(y)=1/√(2π)·e^{-y^2/2}.$$
代回相容式可知成立，故确为边缘密度。

3. 相关系数：

由上述边缘密度可知 X 服从 $N(0,1/2)$，Y 服从 $N(0,1)$，故
$$EX=EY=0, DX=1/2, DY=1.$$
又条件分布 $Y|X=x$ 服从 $N(x,1/2)$，给出 $E[Y|X]=X$，所以
$$E[XY]=E[XE[Y|X]]=E[X^2]=DX=1/2.$$
因此
$$ρ_{XY}=Cov(X,Y)/(√(DX)√(DY))=(1/2)/(√(1/2)·1)=1/√2.$$

**易错点**

- 高斯积分 $∫e^{-at^2}dt=√(π/a)$ 要熟记；注意本题两处的 $a$ 分别为 2 和 1。
- 不能直接把两个条件密度相乘当作联合密度；必须乘相应边缘密度，并令两种分解相等。
- 分离变量时常数 C 的位置容易错；代回验证 $f_X/f_Y$ 是否满足相容式。
- 求相关系数前先确认均值为 0；均值不为 0 时 $Cov=E[XY]-EXEY$。
- 不要看到指数里有系数就猜相关；相关系数由协方差和标准差定义计算。

**命题规律**

本题是数一概率论“条件分布反推联合分布”的典型题。命题套路：给出两个貌似独立的正态条件密度，实际隐含二维正态分布；要求由归一化、相容性、分离变量求边缘密度，再用条件期望求相关系数。复习建议：熟练掌握高斯积分、正态分布标准化、$f_{XY}=f_{X|Y}f_Y=f_{Y|X}f_X$、条件期望与方差分解公式；遇到指数二次型先合并指数或配方。

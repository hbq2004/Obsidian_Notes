# MCQ 第 24 题

![[_Attachments/题目识别/XDSM-2027/XDSM-2027-08-Q24_题目.png|题目]]

$$ 又 0 < f(x) < f(0^{-}) = \lim\limits _{x \to 0^{+}} \frac{}{x} = 1, x \in (0,1) 故 f^{-}(x) < f(x) \Rightarrow I_{3} < I_{1} 。 $$

故 $I_{3} < I_{1} < I_{2}$ 。

已知 $I_{1} = \int_{0}^{1} \frac{x}{1 + e^{x}} \, dx$, $I_{2} = \int_{0}^{1} \frac{1 - x}{1 + e^{x}} \, dx$, $I_{3} = \int_{0}^{1} \frac{1 - \cos x}{e^{x}} \, dx$, 则（）

(A) $I_{1} < I_{2} < I_{3}$

(B) $I_{3} < I_{1} < I_{2}$

(C) $I_{3} < I_{2} < I_{1}$

(D) $I_{1} < I_{3} < I_{2}$

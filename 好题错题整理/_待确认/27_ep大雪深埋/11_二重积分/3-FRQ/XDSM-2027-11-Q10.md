# FRQ 第 10 题

![[_Attachments/题目识别/XDSM-2027/XDSM-2027-11-Q10_题目.png|题目]]

设 $D: 0 \le x \le 2, 0 \le y \le 2$， 
（1）求 $A = \iint_D |xy - 1| \, dx dy$； 
（2）设 $f(x, y)$ 在 $D$ 上连续，且 $\iint_D f(x, y) \, dx dy = 0$，$\iint_D xy f(x, y) \, dx dy = 1$，证明： 
存在 $(\xi, \eta) \in D$，使 $|f(\xi, \eta)| \ge \dfrac{1}{A}$.

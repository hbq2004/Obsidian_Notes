# MCQ 第 3 题

![[_Attachments/题目识别/XDSM-2027/XDSM-2027-07-Q03_题目.png|题目]]

因为 $x_1 < \xi_1 < x_2 < \xi_2 < x_3$ 且 $f''(x) < 0$，所以 $f'(x)$ 单调递减，故 $f'(\xi_1) > f'(\xi_2)$，D 错误。综上，本题选 C。

已知 $f(x)$ 为二阶可导的正值函数，$f(0) = f'(0) = 1$，且 $f(x)f''(x) \geq [f'(x)]^2$，则（）

A. $f(2) \leq e^2 \leq \sqrt{f(1)f(3)}$。

B. $e^2 \leq f(2) \leq \sqrt{f(1)f(3)}$。

C. $\sqrt{f(1)f(3)} \leq e^2 \leq f(2)$。

D. $\sqrt{f(1)f(3)} \leq f(2) \leq e^2$.

# MCQ 第 21 题

![[_Attachments/题目识别/XDSM-2027/XDSM-2027-03-Q21_题目.png|题目]]

设函数 $f(x)$ 二阶可导，则（）

A. 若 $f(x)$ 在 $x=x_0$ 的某邻域内严格单调递增，则 $f'(x_0)>0$。

B. 若 $f''(x_0)>0$，则 $f(x)$ 在 $x=x_0$ 的某邻域内是凹的。

C. 若 $(x_0,f(x_0))$ 是 $f(x)$ 的拐点，则 $x=x_0$ 是 $f'(x)$ 的极值点。

D. 若 $x=x_0$ 是 $f'(x)$ 的极值点，则 $(x_0,f(x_0))$ 是 $f(x)$ 的拐点.

## V4 Flash Max 解析

**答案**: C。拐点是凹凸性改变点；而凹凸性由 $f'$ 的单调性决定，$f''=(f')'$，所以拐点处 $f'$ 的单调性反转，$x_0$ 是 $f'$ 的极值点。

**解题切入点**: 把 $f''$ 看作 $f'$ 的导数，先想“$f''$ 的符号 → $f'$ 的单调性 → $f$ 的凹凸性”。拐点就是 $f'$ 单调性发生反转的位置，类似算法中“维护单调性、找转折点”。A、B、D 本质上都是把“某一点的信息”误当成“邻域信息”。

**推演**:

- **C 正确**。若 $(x_0,f(x_0))$ 是拐点，则在 $x_0$ 两侧凹凸性相反，也就是 $f''$ 在两侧变号（或说 $f'$ 的单调性反转）。  
  不妨设左邻域 $f''>0$、右邻域 $f''<0$，则 $f'$ 左增右减，所以 $f'(x_0)$ 比两侧都大，$x_0$ 是 $f'$ 的极大值点；若左负右正，则 $x_0$ 是 $f'$ 的极小值点。

- **A 错**。严格单调递增只能推出 $f'(x_0)\ge 0$，不能推出 $>0$。反例：$f(x)=x^3$ 在 $x_0=0$ 处严格递增，但 $f'(0)=0$。

- **B 错**。$f''(x_0)>0$ 只是点信息，不能保证 $f''$ 在某个邻域内保持同号。例如令 $f'(x)=x+2x^2\sin(1/x^2)$（$f'(0)=0$），则 $f''(0)=1$，但 $f''(x)=1+4x\sin(1/x^2)-4\cos(1/x^2)$ 在 $0$ 的任意邻域内振荡变号，不能推出邻域内凹凸。

- **D 错**。$f'$ 有极值只说明 $f''(x_0)=0$，不能保证 $f''$ 在两侧变号。例如令 $f'(x)=x^4(2+\sin(1/x^2))$（$f'(0)=0$），则 $x=0$ 是 $f'$ 的严格极小值点；但 $f''(x)=4x^3(2+\sin(1/x^2))-2x\cos(1/x^2)$ 在任意邻域内正负振荡，所以 $(0,f(0))$ 不是拐点。

**易错点**:

- 不要把“严格单调递增”和“导数大于 $0$”互相误推；严格单调递增只能保证 $f'(x)\ge 0$。
- 不要把“一点处 $f''>0$”当成“邻域内 $f''>0$”。若题目改成“$f''$ 连续且 $f''(x_0)>0$”，B 才成立。
- C 和 D 是“充分”和“必要”方向的问题：拐点可推出 $f'$ 有极值，但 $f'$ 有极值不一定能推出拐点。

**命题规律**: 常见考法是辨析“点信息”与“邻域信息”，以及拐点、极值点、二阶导零点的关系。变式常给 $f''(x_0)=0$ 判断是否为拐点，或把条件改成“二阶连续可导”判断凹凸性。核心链条是：$f''$ 符号 ↔ $f'$ 单调性 ↔ $f$ 凹凸性，拐点即 $f'$ 单调性反转点。

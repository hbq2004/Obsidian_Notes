# MCQ 第 9 题

![[_Attachments/题目识别/XDSM-2027/XDSM-2027-02-Q09_题目.png|题目]]

设 $\{x_n\},\{y_n\},\{z_n\}$ 为数列，则以下说法： 
① 若 $x_n \le y_n \le z_n$，且 $\lim x_n = \lim z_n$，则 $\{y_n\}$ 收敛； 
② 若 $x_n \le y_n \le z_n$，且 $\lim(z_n - x_n) = 0$，则 $\{y_n\}$ 收敛； 
③ 若 $x_n \le a_n \le z_n$，且 $\lim(z_n - x_n) = 0$，则 $\{x_n\}$ 和 $\{z_n\}$ 收敛； 
④ 若 $x_n \le y_n \le z_n$，且 $\{y_n\}$ 收敛，$\lim(z_n - x_n) = 0$，则 $\{x_n\}$ 和 $\{z_n\}$ 收敛。 
正确的个数是（ ） 
A. 1 个 
B. 2 个 
C. 3 个 
D. 4 个

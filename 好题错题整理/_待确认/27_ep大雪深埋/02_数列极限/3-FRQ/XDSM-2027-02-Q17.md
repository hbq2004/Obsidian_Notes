# FRQ 第 17 题

![[_Attachments/题目识别/XDSM-2027/XDSM-2027-02-Q17_题目.png|题目]]

故 $x_n \leq a-1$，有上界；又 $x_{n+1} = x_n + \ln(a - x_n) \geq x_n$，故单调增加。记极限为 $A$，则 $A = A + \ln(a-A)$，解得 $A = a-1$。

设 $x_1 = 2$，$x_{n+1} = \frac{x_n^2}{1+x_n}$，$n = 1, 2, 3, \ldots$。

(1) 证明数列 $\{x_n\}$ 收敛，并求 $\lim x_n$；

(2) $\lim\limits_{n \to \infty} \left( \frac{x_2}{x_1} + \frac{x_3}{x_2} + \cdots + \frac{x_{n+1}}{x_n} \right)$.

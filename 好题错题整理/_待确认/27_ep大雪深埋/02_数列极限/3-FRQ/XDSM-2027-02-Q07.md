# FRQ 第 7 题

![[_Attachments/题目识别/XDSM-2027/XDSM-2027-02-Q07_题目.png|题目]]

因此由极限的保号性知，存在 $N$，当 $n > N$ 时，$0 < \frac{y_{n+1}}{y_n} < \frac{1}{4}$，故 $0 < y_n < \left(\frac{3}{4}\right)^{n-N-1} y_{N+1}$。又右端趋于 0，由夹逼准则知 $\lim y_n = \lim 2^n x_n = 0$。

设数列 $\{x_n\}$ 满足：$x_1 > 0$，$x_{n+1} = x_n - \ln(1 + x_n)$。

(1) 证明：数列 $\{x_n\}$ 收敛，并求其极限；

(2) 设 $x_1 = y_1 = \frac{1}{2}$，$y_{n+1} = y_n^2$，证明 $\lim\limits_{n \to \infty} \frac{x_n}{y_n} = 0$.

# FRQ 第 10 题

![[_Attachments/题目识别/XDSM-2027/XDSM-2027-05-Q10_题目.png|题目]]

当罗尔定理使用过程中总是找不到两个相等点时，考虑使用费马定理。设 $x_0$ 是函数 $f(x)$ 的一个极值点，若 $f'(x_0)$ 存在，则 $f'(x_0) = 0$。

设函数 $f(x)$ 在 $[-2, 2]$ 上二阶可导，且 $|f(x)| \leq 1$，又 $f^2(0) + (f'(0))^2 = 4$。证明：在 $(-2, 2)$ 内至少存在一点 $\xi$，使得 $f(\xi) + f''(\xi) = 0$.

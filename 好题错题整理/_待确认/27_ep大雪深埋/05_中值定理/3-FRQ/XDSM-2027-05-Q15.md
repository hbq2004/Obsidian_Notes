# FRQ 第 15 题

![[_Attachments/题目识别/XDSM-2027/XDSM-2027-05-Q15_题目.png|题目]]

$$\frac { m } { f ^ { \prime } ( x _ { 1 } ) } + \frac { n } { f ^ { \prime } ( x _ { 2 } ) } = m \frac { ( m + n ) x _ { 0 } } { m } + n \frac { ( m + n ) ( 1 - x _ { 0 } ) } { n } = m + n .$$

设非线性函数 $f(x)$ 在 $[a, b]$ 上连续，在 $(a, b)$ 内可导，证明：存在 $\xi \in (a, b)$，使

$$\left| f^{\prime}(\xi) \right| > \left| \frac{f(b) - f(a)}{b - a} \right| .$$

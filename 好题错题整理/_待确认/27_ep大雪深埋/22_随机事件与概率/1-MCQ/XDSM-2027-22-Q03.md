# MCQ 第 3 题

![[_Attachments/题目识别/XDSM-2027/XDSM-2027-22-Q03_题目.png|题目]]

设 $A, B, C$ 是随机事件，则 $\overline{A} \cap (\overline{B} \cup \overline{C})$ 等于（）。

A. $A \cap (\overline{B} \cap C)$
B. $A \cap (B \cap C)$
C. $(A \cup B) \cap (A \cup C)$
D. $(A \cup \overline{B}) \cap (A \cup \overline{C})$

## V4 Flash Max 解析

**答案**: 选 **C**（按 OCR 最合理读法）。题式化简后应为 $\overline{(A\cup B)\cap(A\cup C)}$，即 C 项应理解成整体取补；若严格按字面给出的 C 项没有整体补号，则四个选项均不直接等于题式。

**解题切入点**:  
看到 $\overline{B}\cup\overline{C}$，马上想到德摩根律：并的补等于补的交，交的补等于补的并。算法竞赛里可类比为 `!A && (!B || !C) = !(A || (B && C))`，连续取反时尤其注意括号边界。

**推演**:
$$
\begin{aligned}
\overline{A}\cap(\overline{B}\cup\overline{C})
&=\overline{A}\cap\overline{B\cap C}\\
&=\overline{A\cup(B\cap C)}\\
&=\overline{(A\cup B)\cap(A\cup C)}.
\end{aligned}
$$

其中：

- 第一步：$\overline{B}\cup\overline{C}=\overline{B\cap C}$；
- 第二步：$\overline{A}\cap\overline{D}=\overline{A\cup D}$，这里 $D=B\cap C$；
- 第三步：$A\cup(B\cap C)=(A\cup B)\cap(A\cup C)$，即分配律。

所以正确结果对应选项 C 的整体补集形式。

**易错点**:  
常见错误是只对 $\overline{B}\cup\overline{C}$ 用一次德摩根律，却丢掉最外层的补集；另一个错误是把 $\overline{A}\cap\overline{B\cap C}$ 误写成 $\overline{A\cap(B\cap C)}$，正确应为 $\overline{A\cup(B\cap C)}$。

自检可取值验证：取 $A=\{1\}$，$B=\{1,2\}$，$C=\{1,3\}$，则题式为 $\{2,3,4\}$，而 $\overline{(A\cup B)\cap(A\cup C)}$ 也为 $\{2,3,4\}$。若 C 项漏写整体补号，则 C 项是 $\{1\}$，正好是题式的补集，不符合。

注：按OCR最合理读法。

**命题规律**:  
该考点是事件运算中的德摩根律与分配律，常以“等价化简”或“选择与题干相同事件”的形式出现。常见变式包括 $\overline{A\cup B}$、$\overline{A\cap B}$、$\overline{\overline{A}\cup B}$ 等；后续求 $P(A\cup B)$、$P(\overline{A}B)$ 时也会反复用到“补集换交并”的技巧。

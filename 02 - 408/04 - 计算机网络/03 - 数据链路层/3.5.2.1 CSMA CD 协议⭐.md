![[Pasted image 20260707094121.png]]

真题中可能作为隐含条件：

| 常数          | 数值                   | 说明                             |
| ----------- | -------------------- | ------------------------------ |
| 以太网最小帧长     | (64B)                | 不含前导码和 SFD                     |
| 以太网最大帧长     | (1518B)              | 不含前导码和 SFD                     |
| MAC 首部      | (14B)                | 目的 MAC (6B)，源 MAC (6B)，类型 (2B) |
| FCS         | (4B)                 | 帧检验序列                          |
| 最小数据字段      | (46B)                | 保证总帧长至少 (64B)                  |
| 最大数据字段      | (1500B)              | MTU 通常为 (1500B)                |
| CSMA/CD 争用期 | (512bit\text{ time}) | 等价于发送 (64B=512bit) 所需时间        |

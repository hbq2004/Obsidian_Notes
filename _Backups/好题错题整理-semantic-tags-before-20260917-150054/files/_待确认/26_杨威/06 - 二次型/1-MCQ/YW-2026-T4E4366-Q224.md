# MCQ 第 224 题

![[_Attachments/题目识别/YW-2026/YW-2026-T4E4366-Q224_题目.png|题目]]

设二次型 $f(x_1, x_2, x_3)$ 在正交变换 $x = Py$ 下的标准形为 $2y_1^2 + 2y_2^2 + 3y_3^2$ 其中 $P = (e_1, e_2, e_3)$. 令 $Q = (e_1, -e_3, e_1 + e_2)$，则令 $x = Qy$ 可将二次型 $f(x_1, x_2, x_3)$ 化为 \_.

A. $2y_1^2 + 3y_2^2 + 2y_3^2$

B. $2y_1^2 + 3y_2^2 + 4y_3^2$

C. $2y_1^2 + 3y_2^2 + 2y_3^2 + 4y_1y_3$

D. $2y_1^2 + 3y_2^2 + 4y_3^2 + 4y_1y_3$

## V4 Flash Max 解析

**答案**: D。由正交对角化知 $f$ 对应矩阵 $A=2e_1e_1^T+2e_2e_2^T+3e_3e_3^T$。令 $x=Qy$ 后，新矩阵为  
$$Q^TAQ=\begin{pmatrix}2&0&2\\0&3&0\\2&0&4\end{pmatrix},$$  
所以二次型化为  
$$2y_1^2+3y_2^2+4y_3^2+4y_1y_3.$$

**解题切入点**: 已知正交变换下的标准形，本质是告诉你特征值和特征向量：$Ae_1=2e_1,\ Ae_2=2e_2,\ Ae_3=3e_3$。现在求任意线性替换 $x=Qy$ 后的表达式，直接用合同变换 $B=Q^TAQ$，不要重新去配方法或求正交变换。  
直观上，$Q$ 的第三列是 $e_1+e_2$，它不是单位向量且与 $e_1$ 不垂直，所以必然出现 $y_1y_3$ 交叉项，且 $y_3^2$ 系数会改变。可类比竞赛中“按列维护映射，不展开整个矩阵”。

**推演**: 设 $f(x)=x^TAx$。由题  
$$P^TAP=\operatorname{diag}(2,2,3),$$  
且 $P=(e_1,e_2,e_3)$，故  
$$A=2e_1e_1^T+2e_2e_2^T+3e_3e_3^T.$$

令  
$$Q=(q_1,q_2,q_3)=(e_1,-e_3,e_1+e_2).$$  
则新矩阵为  
$$B=Q^TAQ,\qquad b_{ij}=q_i^TAq_j.$$

先计算 $Aq_j$：  
$$Aq_1=2e_1,\qquad Aq_2=-3e_3,\qquad Aq_3=2e_1+2e_2.$$

利用 $e_i^Te_j=\delta_{ij}$，得  
$$B=\begin{pmatrix}
q_1^TAq_1&q_1^TAq_2&q_1^TAq_3\\
q_2^TAq_1&q_2^TAq_2&q_2^TAq_3\\
q_3^TAq_1&q_3^TAq_2&q_3^TAq_3
\end{pmatrix}
=
\begin{pmatrix}
2&0&2\\
0&3&0\\
2&0&4
\end{pmatrix}.$$

因此  
$$f=y^TBy=2y_1^2+3y_2^2+4y_3^2+4y_1y_3.$$

选 D。

**易错点**: 
- 不要把 $Q$ 当成正交矩阵。$Q$ 的第三列长度为 $\sqrt2$，且与第一列 $e_1$ 内积为 $1$，所以它不是正交矩阵；新表达式不是标准形，必须有交叉项。
- 合同变换方向不要写反：$x=Qy$ 代入 $x^TAx$，得到的是 $y^T(Q^TAQ)y$，不是 $QAQ^T$。
- 自检：取 $y=(1,0,0)^T$，D 中式子给出 $2$，对应 $x=e_1$，$f(e_1)=2$；取 $y=(0,0,1)^T$，D 中式子给出 $4$，对应 $x=e_1+e_2$，$f(e_1+e_2)=4$。均吻合。

**命题规律**: 本题把“正交变换化标准形”与“一般线性替换下的合同变换”结合。常见命题角度是：先通过正交标准形给出特征值和特征向量，再给一个非正交线性替换求新二次型；或反过来给 $Q^TAQ$ 判断能否对角化。联系知识点包括特征值、特征向量、正交矩阵、合同变换、惯性定理、正定性判断等。变式常把 $Q$ 换成 $(e_1,e_2,e_1+e_3)$ 或含参数的组合，核心仍是算 $Q^TAQ$。

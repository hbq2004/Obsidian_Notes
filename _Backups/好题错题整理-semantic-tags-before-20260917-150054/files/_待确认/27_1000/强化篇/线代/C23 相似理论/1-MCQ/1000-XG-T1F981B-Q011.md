11. 设 $A$，$B$ 是可逆矩阵，且 $A$ 与 $B$ 相似，则下列结论错误的是().

A. $A^T$ 与 $B^T$ 相似

B. $A^2 + A^{-1}$ 与 $B^2 + B^{-1}$ 相似

C. $A + A^T$ 与 $B + B^T$ 相似

D. $A^* - A^{-1}$ 与 $B^* - B^{-1}$ 相似

## V4 Flash Max 解析

**答案**: C。例如 $A=\begin{pmatrix}1&1\\0&2\end{pmatrix}$ 与 $B=\begin{pmatrix}1&0\\0&2\end{pmatrix}$ 相似，但 $A+A^T$ 与 $B+B^T$ 的行列式分别为 $7$ 和 $8$，相似矩阵行列式必须相同，故 C 错误。

**解题切入点**: 看到“相似”，先写成 $B=P^{-1}AP$。然后看某个表达式能否用同一个 $P$ 化为 $P^{-1}(\cdots)P$。$A^T$ 会带来 $P^T$，一般不能和原来的 $P$ 统一，所以 C 是重点怀疑对象。否定一个命题，构造反例即可；比较行列式、迹、特征值就像比较“不变量”。

**推演**:

设 $B=P^{-1}AP$，其中 $P$ 可逆。

A 正确：
$$B^T=(P^{-1}AP)^T=P^TA^T(P^{-1})^T=P^TA^T(P^T)^{-1},$$
所以 $A^T\sim B^T$。

B 正确：
$$B^2+B^{-1}=P^{-1}A^2P+P^{-1}A^{-1}P=P^{-1}(A^2+A^{-1})P,$$
所以 $A^2+A^{-1}\sim B^2+B^{-1}$。

D 正确：因为 $A,B$ 可逆且相似，所以 $\det A=\det B$，记为 $d$。  
又 $A^*=dA^{-1}$，$B^*=dB^{-1}$，于是
$$A^*-A^{-1}=(d-1)A^{-1},\qquad B^*-B^{-1}=(d-1)B^{-1}.$$
由 $A^{-1}\sim B^{-1}$，可知 $(d-1)A^{-1}\sim (d-1)B^{-1}$。

C 错误。取
$$A=\begin{pmatrix}1&1\\0&2\end{pmatrix},\qquad B=\begin{pmatrix}1&0\\0&2\end{pmatrix}.$$
令 $P=\begin{pmatrix}1&1\\0&1\end{pmatrix}$，则
$$P^{-1}AP=\begin{pmatrix}1&0\\0&2\end{pmatrix}=B,$$
所以 $A\sim B$。

但
$$A+A^T=\begin{pmatrix}2&1\\1&4\end{pmatrix},\qquad B+B^T=\begin{pmatrix}2&0\\0&4\end{pmatrix}.$$
行列式分别为
$$\det(A+A^T)=2\cdot4-1=7,\qquad \det(B+B^T)=2\cdot4=8.$$
若两矩阵相似，则行列式必须相等，因此 $A+A^T$ 与 $B+B^T$ 不相似。

**易错点**: 容易误以为“相似的矩阵经过同样表达式后仍相似”。对 $A^2+A^{-1}$ 这种只含 $A$ 的运算确实成立，但含转置 $A^T$ 时，转置会把相似变换 $P$ 变成 $P^T$，一般不再保持相似。构造反例后要检查：原题条件是否满足（这里 $A,B$ 可逆且确实相似），以及用 det/特征值等不变量验证。

**命题规律**: 相似矩阵是高频考点，常与特征值、特征向量、对角化、伴随矩阵、逆矩阵结合考查。常见命题角度有：判断 $f(A)$ 与 $f(B)$ 是否相似；判断 $A^T$ 是否相似；利用迹、行列式、秩、特征值排除相似；以及用 Jordan 标准形判断一般矩阵相似。学习时可以把相似理解为“同一个线性变换在不同基下的矩阵”，转置并不是同一个线性变换的自然操作，因此往往是反例来源。

# MCQ 第 5 题

![[_Attachments/题目识别/1000-GS/1000-GS-T79B06F-Q005_题目.png|题目]]

5. 设 $f(x) = \begin{cases} x^2 \sin \frac{1}{x}, & x \neq 0, \\ 0, & x = 0, \end{cases}$，记 $F(x) = g[f(x)]$，$g(x)$ 可导，则 $F(x)$ 在 $x = 0$ 处(\_)。

A. 不连续
B. 可导且 $F'(0) = 0$
C. 连续但不可导
D. 可导且 $F'(0) \neq 0$

---

## 答案

![[_Attachments/题目识别/1000-答案/1000-GS-T79B06F-Q005_答案.png|答案]]

## V4 Pro Max 解析

**答案**：B（可导且 $F'(0)=0$）

**切入点**：$F(x)=g[f(x)]$ 是复合函数，$f(0)=0$、$f'(0)=0$。由链式法则 $F'(0)=g'(f(0))f'(0)=g'(0)\cdot0=0$。关键是 $g$ 可导（在 $f(0)=0$ 附近），使复合可导。

**推演**

$f(x)=x^2\sin\frac1x$（$x\ne0$）、$f(0)=0$。先算 $f'(0)$：
$$f'(0)=\lim_{x\to0}\frac{x^2\sin\frac1x}{x}=\lim_{x\to0}x\sin\frac1x=0.$$
故 $f$ 在 0 连续可导且 $f(0)=0$。

由 $g$ 可导、$f$ 在 0 可导，复合函数 $F=g\circ f$ 在 0 可导，且
$$F'(0)=g'(f(0))\cdot f'(0)=g'(0)\cdot 0=0.$$

**易错点**：$g$ 只需在 $f(0)=0$ 附近可导即可（题目“$g$ 可导”默认成立）；$f'(0)=0$ 是本题的开关——不管 $g'(0)$ 是什么，乘积都是 0。不要误以为 $f'(x)$ 在 0 附近的行为（$2x\sin\frac1x-\cos\frac1x$ 振荡）会影响 $F'(0)$，复合后由链式法则在 0 点的值独立成立。

**命题规律**：内层 $f$ 在 0 可导且 $f(0)=0$、$f'(0)=0$，外层 $g$ 可导 ⇒ $F'(0)=g'(0)f'(0)=0$。复合函数在一点的可导性只依赖内外层在该点的导数，与 $f'$ 是否连续无关。

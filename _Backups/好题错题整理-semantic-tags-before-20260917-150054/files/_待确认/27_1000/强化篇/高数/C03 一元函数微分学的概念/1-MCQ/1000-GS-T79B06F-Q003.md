# MCQ 第 3 题

![[_Attachments/题目识别/1000-GS/1000-GS-T79B06F-Q003_题目.png|题目]]

3. 设 $f(x) = \begin{cases} x^2 \sin \frac{t}{x}, & x \neq 0, \\ 0, & x = 0, \end{cases}$ 其中 $t$ 为非零常数，则 $f(x)$ 在 $x = 0$ 处().

A. 不连续
B. 连续但不可导
C. 可导但 $f'(x)$ 不连续
D. 可导且 $f'(x)$ 连续

---

## 答案

![[_Attachments/题目识别/1000-答案/1000-GS-T79B06F-Q003_答案.png|答案]]

## V4 Pro Max 解析

**答案**：C（可导但 $f'(x)$ 在 $x=0$ 不连续）

**切入点**：$x^2$ 把 $\sin\frac{t}{x}$ 的振荡压住，使 $f$ 连续且可导；但求导后会产生 $t\cos\frac{t}{x}$ 这一无界振荡项，导致 $f'$ 在 0 处无极限。这是“可导 ≠ 导函数连续”的经典例子。

**推演**

连续性：$|f(x)|\le x^2\to0=f(0)$，故 $f$ 在 0 连续。

可导性：
$$f'(0)=\lim_{x\to0}\frac{x^2\sin\frac{t}{x}}{x}=\lim_{x\to0}x\sin\frac{t}{x}=0.$$

$x\ne0$ 时
$$f'(x)=2x\sin\frac{t}{x}+x^2\cos\frac{t}{x}\cdot\Big(-\frac{t}{x^2}\Big)=2x\sin\frac{t}{x}-t\cos\frac{t}{x}.$$
当 $x\to0$ 时 $2x\sin\frac{t}{x}\to0$，但 $-t\cos\frac{t}{x}$（$t\ne0$）在 $[-|t|,|t|]$ 间振荡无极限，故 $\lim_{x\to0}f'(x)$ 不存在，$f'$ 在 0 不连续。

**易错点**：⚠ 题干中 $\sin\frac{t}{x}$ 的 $t$ 为非零常数（若为 $\sin\frac1x$ 结论不变）；求导时 $\frac{d}{dx}\frac{t}{x}=-\frac{t}{x^2}$ 与 $x^2$ 相消后剩下 $-t\cos\frac tx$。$f'(0)=0$ 存在但 $f'(x)$ 在 0 无极限，两者并不矛盾。

**命题规律**：$x^2\sin\frac1x$（或 $\frac tx$）型——$x^k$ 控幅振荡：$k=1$ 连续不可导，$k=2$ 可导但导函数不连续。判断依据是求导后是否剩“无界振荡项”。

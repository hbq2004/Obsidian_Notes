# MCQ 第 37 题

![[_Attachments/题目识别/1000-GS/1000-GS-TDE6A7F-Q037_题目.png|题目]]

37. 函数 $f(x)=|x-1|^{\frac{1}{x(2-x)}}$ 的第二类间断点的个数是(\_)。

A. 0
B. 1
C. 2
D. 3

---

## 答案

![[_Attachments/题目识别/1000-答案/1000-GS-TDE6A7F-Q037_答案.png|答案]]

## V4 Pro Max 解析

**答案**：A $0$

**切入点**：把 $f(x)=|x-1|^{1/(x(2-x))}$ 写成 $e^{\frac{\ln|x-1|}{x(2-x)}}$,只需研究指数 $\dfrac{\ln|x-1|}{x(2-x)}$ 在无定义点 $x=0,1,2$ 的极限类型。

**推演**

无定义点:$x=1$(底数为 0)、$x=0,2$(指数分母为 0)。考察指数 $P(x)=\dfrac{\ln|x-1|}{x(2-x)}$:

- $x=1$:$\ln|x-1|\to-\infty$,而 $x(2-x)\to1$,故 $P(x)\to-\infty$,于是 $f(x)=e^{P(x)}\to0$,极限存在且有限,是**可去间断点**。

- $x=0$:$\ln|x-1|=\ln(1-x)\sim-x$,且 $x(2-x)\sim2x$,故 $P(x)\sim\dfrac{-x}{2x}=-\dfrac12$,两侧均有 $P\to-\dfrac12$,于是 $f(x)\to e^{-1/2}$,是**可去间断点**。

- $x=2$:令 $t=x-2$,$\ln|x-1|=\ln|1+t|\sim t=x-2$,而 $x(2-x)=x\cdot(-(x-2))\sim-2(x-2)$,故 $P(x)\sim\dfrac{x-2}{-2(x-2)}=-\dfrac12$,于是 $f(x)\to e^{-1/2}$,是**可去间断点**。

三个无定义点均为可去间断点,故第二类间断点个数为 $0$,选 A。

**易错点**：$x=0$ 与 $x=2$ 处是"$\dfrac{0}{0}$"型而非"$\infty$ 型":$\ln|x-1|$ 与 $x(2-x)$ 同时趋于 0,比值有有限极限 $-\dfrac12$;若只看 $1/(x(2-x))\to\infty$ 就误判为无穷间断点会出错。$x=1$ 处底数趋于 0 但指数趋于 1,整体极限为 0。

**命题规律**：指数型函数 $u(x)^{v(x)}$ 的间断点统一化为 $e^{v(x)\ln u(x)}$ 研究指数极限;这类"看似无穷实则有限"的反直觉结论是常考陷阱。

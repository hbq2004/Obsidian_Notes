# FRQ 第 39 题

![[_Attachments/题目识别/1000-GS/1000-GS-TB70835-Q039_题目.png|题目]]

39. 计算 $\iint_{D} \ln(xy) \, dx \, dy$，其中 $D = \{(x,y) | 1 \leq xy \leq 2, x \leq y \leq 4x, x > 0\}$.

---

## 答案

![[_Attachments/题目识别/1000-答案/1000-GS-TB70835-Q039_答案.png|答案]]

## V4 Pro Max 解析

**答案**：$2\ln^2 2-\ln2$

**切入点**：区域由 $xy\in[1,2]$、$1\le\frac yx\le4$ 界定，被积 $\ln(xy)$，换元 $u=xy,\ v=\frac yx$ 把区域拉成矩形、被积化为 $\ln u$，雅可比 $\frac1{2v}$ 分离变量。

**推演**

令 $u=xy,\ v=\frac yx$（$x>0$）。区域：$u\in[1,2]$，$v\in[1,4]$。

$$\left|\frac{\partial(u,v)}{\partial(x,y)}\right|=\left|\begin{matrix}y&x\\ -y/x^2&1/x\end{matrix}\right|=\frac{2y}{x}=2v.$$

故 $dx\,dy=\frac{1}{2v}\,du\,dv$，$\ln(xy)=\ln u$：

$$I=\iint\ln u\cdot\frac{1}{2v}\,du\,dv=\frac12\int_1^2\ln u\,du\cdot\int_1^4\frac{dv}{v}.$$

$$\int_1^2\ln u\,du=[u\ln u-u]_1^2=2\ln2-1,\qquad \int_1^4\frac{dv}{v}=\ln4=2\ln2.$$

$$I=\frac12(2\ln2-1)(2\ln2)=2\ln^22-\ln2.$$

**易错点**：$v=\frac yx$ 的雅可比是 $2v$（分子 $2y/x$），除以雅可比得 $\frac1{2v}$；$u$ 的上下限来自 $1\le xy\le2$，$v$ 来自 $1\le\frac yx\le4$。

**命题规律**：区域由 $xy=c$ 与 $\frac yx=c$ 界定、被积含 $\ln(xy)$ 时，换 $u=xy,\ v=y/x$ 使边界与函数同时简单化；对数与幂次边界常暗示这类换元。

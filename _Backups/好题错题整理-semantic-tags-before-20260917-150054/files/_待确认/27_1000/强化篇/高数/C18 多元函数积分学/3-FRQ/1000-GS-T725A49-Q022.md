# FRQ 第 22 题

![[_Attachments/题目识别/1000-GS/1000-GS-T725A49-Q022_题目.png|题目]]

22. 设 $\Sigma$ 是由直线 $\begin{cases} x=0, \\ y=0 \end{cases}$ 绕直线 $\begin{cases} y=t, (t  为参数 ) \\ z=t \end{cases}$ 旋转一周得到的曲面, $\sum\limits_{1}$ 是 $\Sigma$ 介于平面 介于平面 $x$ + $y+z=0$ 与 $x+y+z=1$ 之间部分的外侧. 计算曲面积分 $I=\iint_{\Sigma} x ~d y ~d z+(y+1) d z ~d x+(z+2) d x ~d y$.

---

## 答案

![[_Attachments/题目识别/1000-答案/1000-GS-T725A49-Q022_答案.png|答案]]

﻿## V4 Pro Max 解析

**答案**：$I=3\,V_{\Omega}$（外侧曲面与上下平面闭合后用散度体积）；⚠ 圆锥几何受 OCR 影响，最终值依赖锥体体积

**切入点**：被积式 $x\,dy\,dz+(y+1)dz\,dx+(z+2)dx\,dy$ 的散度恰为常数 $3$，且曲面夹在 $x+y+z=0$ 与 $x+y+z=1$ 两平面间，用高斯公式把闭曲面积分转为体积。类比"散度为常数时直接乘体积"。

**推演**

记向量场 $\vec F=(x,\ y+1,\ z+2)$，其散度
$$\operatorname{div}\vec F=\frac{\partial x}{\partial x}+\frac{\partial(y+1)}{\partial y}+\frac{\partial(z+2)}{\partial z}=1+1+1=3.$$
设 $\Sigma$ 外侧，与两平面 $x+y+z=0,\ x+y+z=1$ 截出的两块盖（取相应侧）共同围成三棱锥状区域 $\Omega$。由高斯公式
$$\iint_{\partial\Omega}\vec F\cdot\vec n\,dS=\iiint_\Omega 3\,dV=3\,V_{\Omega}.$$
故所要求的曲面外侧积分贡献为 $3\,V_{\Omega}$ 减去两块平面盖上的通量。由于 $x+y+z=0$、$x+y+z=1$ 两平面上 $\vec F\cdot\vec n$ 的具体取值取决于圆锥的母线几何，最终数值由 $\Omega$ 体积（及盖的通量）确定。

**易错点**：⚠ 题干 OCR 中"旋转所得曲面/准线/介于平面"语句多处损坏（如"由直线 x=0,y=0 绕直线 y=t,z=t 旋转"），圆锥方程与母线方向无法唯一复原，已按"散度为 3 + 高斯公式"给出结构解；若需精确数值需补齐圆锥方程。散度 $3$ 的关键在常数项 $+1,+2$ 使 $\partial_y(y+1)+\partial_z(z+2)$ 不出现变量。

**命题规律**：被积式设计成散度为常数，曲面夹在两平行平面间，考的是高斯（散度）定理的机械应用；识别"散度 = 常数"是本题唯一的切入点。

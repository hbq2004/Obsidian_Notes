# MCQ 第 4 题

![[_Attachments/题目识别/1000-GS/1000-GS-TB17EE4-Q004_题目.png|题目]]

4. 以下结论正确的是().

A. 若 $\sum\limits_{n=0}^{\infty} a_n^2$ 收敛，则 $\sum\limits_{n=0}^{\infty} a_n^3$ 收敛

B. 若 $\sum\limits_{n=0}^{\infty} a_n^2$ 发散，则 $\sum\limits_{n=0}^{\infty} a_n^3$ 发散

C. 若 $\sum\limits_{n=0}^{\infty} a_n^3$ 收敛，则 $\sum\limits_{n=0}^{\infty} a_n^4$ 收敛

D. 若 $\sum\limits_{n=0}^{\infty} a_n^3$ 发散，则 $\sum\limits_{n=0}^{\infty} a_n^4$ 发散

---

## 答案

![[_Attachments/题目识别/1000-答案/1000-GS-TB17EE4-Q004_答案.png|答案]]

## V4 Pro Max 解析

**答案**：A

**切入点**：利用“收敛 ⇒ 通项趋于零 ⇒ 通项绝对值最终小于 1”，把高次幂往低次幂上比较；关键是区分“绝对收敛（平方收敛）”与“可能条件收敛（立方收敛）”。

**推演**

A 正确：若 $\sum a_n^2$ 收敛，则 $a_n^2\to0$，$|a_n|\to0$，$n$ 充分大时 $|a_n|<1$，从而 $|a_n|^3\le a_n^2$。由比较判别法 $\sum|a_n|^3\le\sum a_n^2<+\infty$，故 $\sum a_n^3$ 绝对收敛。

B 错：$a_n=n^{-1/2}$，$\sum a_n^2=\sum\frac1n$ 发散，但 $\sum a_n^3=\sum n^{-3/2}$ 收敛。

C 错：$a_n=(-1)^n n^{-1/4}$，$a_n^3=(-1)^n n^{-3/4}$，$\sum a_n^3$ 收敛（莱布尼茨），但 $a_n^4=n^{-1}$ 发散。

D 错：$a_n=n^{-1/3}$，$\sum a_n^3=\sum\frac1n$ 发散，但 $\sum a_n^4=\sum n^{-4/3}$ 收敛。

**易错点**：$\sum a_n^2$ 收敛是“绝对”收敛（平方非负），可直接比较；但 $\sum a_n^3$ 收敛可能是条件收敛，不能推出 $\sum|a_n|^3$ 收敛，故 C 的反例用 $a_n=(-1)^n n^{-1/4}$。

**命题规律**：幂次比较要抓“通项趋于零”这一必要条件；构造反例常用 $n^{-\alpha}$ 与 $(-1)^n n^{-\alpha}$ 调节敛散。

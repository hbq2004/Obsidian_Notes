# FRQ 第 4 题

![[_Attachments/题目识别/1000-GS/1000-GS-TA131F4-Q004_题目.png|题目]]

4. 设 $x_0 > 0$，$x_{n+1} = \frac{1}{2} \left( x_n + \frac{a}{x_n} \right)$（$n = 0, 1, 2, \cdots$），且 $a > 0$，证明 $\lim\limits_{n \to \infty} x_n$ 存在，并求此极限.

---

## 答案

![[_Attachments/题目识别/1000-答案/1000-GS-TA131F4-Q004_答案.png|答案]]

## V4 Pro Max 解析

**答案**：极限存在,且 $\lim_{n\to\infty}x_n=\sqrt a$。

**切入点**：$x_{n+1}=\frac12\big(x_n+\frac a{x_n}\big)$ 是求 $\sqrt a$ 的牛顿迭代,用「单调有界准则」:先 AM-GM 证有下界 $\sqrt a$,再证单调递减。

**推演**

1. 有下界:对 $n\ge1$,由均值不等式
$$x_{n+1}=\frac12\Big(x_n+\frac a{x_n}\Big)\ge\sqrt{x_n\cdot\frac a{x_n}}=\sqrt a.$$
故 $x_n\ge\sqrt a$(对 $n\ge1$)。

2. 单调递减:当 $n\ge1$,$x_n\ge\sqrt a$ 即 $x_n^2\ge a$,故
$$x_{n+1}-x_n=\frac12\Big(\frac a{x_n}-x_n\Big)=\frac{a-x_n^2}{2x_n}\le0.$$

3. 由单调有界准则,$\{x_n\}$ 收敛,设 $\lim x_n=L\ge\sqrt a>0$。对递推式取极限:
$$L=\frac12\Big(L+\frac aL\Big)\Rightarrow 2L=L+\frac aL\Rightarrow L^2=a\Rightarrow L=\sqrt a.$$

**易错点**：单调性只对 $n\ge1$ 成立(需先有 $x_n\ge\sqrt a$),$x_0$ 任意 $>0$ 不保证递减;求 $L$ 时因 $L>0$ 取正根 $\sqrt a$,不能取负根。

**命题规律**：牛顿法迭代 $x_{n+1}=\frac12(x_n+\frac a{x_n})$ 收敛于 $\sqrt a$,标准套路是「均值不等式下界 + 差式定号证单调 + 单调有界 + 递推取极限」;这是数值分析中平方根迭代的经典极限模型。

# MCQ 第 3 题

![[_Attachments/题目识别/1000-XG/1000-XG-T099AC7-Q003_题目.png|题目]]

3. 对于任意事件 $A$, "$P(A) = P(\overline{A})$" 是 “$P(A) = \frac{1}{4} + [P(A)]^2$” 的().

A. 充分非必要条件
B. 必要非充分条件
C. 充分必要条件
D. 既非充分又非必要条件

---

## 答案

![[_Attachments/题目识别/1000-答案/1000-XG-T099AC7-Q003_答案.png|答案]]

## V4 Pro Max 解析

**答案**：C（充分必要条件）。

**切入点**：把两个条件都翻译成关于 $p=P(A)$ 的方程，比较解集是否一致。类比算法竞赛：两个方程同解 ⟺ 等价。

**推演**

条件一：$P(A)=P(\overline A)$ 即 $P(A)=1-P(A)$，得 $P(A)=\dfrac12$。

条件二：$P(A)=\dfrac14+[P(A)]^2$。令 $p=P(A)$：

$$p=\frac14+p^2\iff p^2-p+\frac14=0\iff\left(p-\frac12\right)^2=0\iff p=\frac12.$$

两条件的解集均为 $\{P(A)=\frac12\}$，故互为充分必要条件。

**易错点**：二次方程 $p^2-p+\frac14=0$ 是**二重根** $p=\frac12$，勿误以为有两个解；$P(A)$ 必在 $[0,1]$ 内，但此处方程解自然落在该范围。

**命题规律**：判断条件的充分/必要性，把两个命题各化为参数的方程（或不等式），比较解集包含关系；"同解"即充要，"一解集包含另一"即单侧推出。

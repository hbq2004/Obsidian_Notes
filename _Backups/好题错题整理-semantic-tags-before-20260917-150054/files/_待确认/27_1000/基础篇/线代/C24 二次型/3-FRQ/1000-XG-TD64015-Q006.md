# FRQ 第 6 题

![[_Attachments/题目识别/1000-XG/1000-XG-TD64015-Q006_题目.png|题目]]

6. 设 $f(x_1, x_2, x_3) = [x_1 + (a-2)x_2 - 2x_3]^2 + [x_1 + ax_2 + x_3]^2 + [x_1 + ax_2 + (a-2)x_3]^2$。求：

(1) 方程 $f(x_1, x_2, x_3) = 0$ 的解；

(2) 二次型 $f(x_1, x_2, x_3)$ 的规范形.

---

## 答案

![[_Attachments/题目识别/1000-答案/1000-XG-TD64015-Q006_答案.png|答案]]

## V4 Pro Max 解析

**答案**：(1) $a\neq3$ 时仅有零解 $(0,0,0)$；$a=3$ 时解为 $k(7,-3,2)^T$（$k$ 任意）。(2) $a\neq3$ 时规范形为 $z_1^2+z_2^2+z_3^2$；$a=3$ 时规范形为 $z_1^2+z_2^2$。

**切入点**：$f$ 是三个线性形式平方之和，$f=0$ 即三式同时为零；规范形只由"秩与正惯性指数"决定。类比算法竞赛：解线性方程组 + 数矩阵的秩。

**推演**

(1) 设三式为

$$y_1=x_1+(a-2)x_2-2x_3,\quad y_2=x_1+ax_2+x_3,\quad y_3=x_1+ax_2+(a-2)x_3.$$

系数矩阵 $B=\begin{pmatrix}1&a-2&-2\\ 1&a&1\\ 1&a&a-2\end{pmatrix}$。作行变换：第三行减第二行得 $(0,0,a-3)$；第二行减第一行得 $(0,2,3)$。

当 $a\neq3$：由 $a-3\neq0$ 得 $x_3=0$，再由 $2x_2+3x_3=0$ 得 $x_2=0$，回代得 $x_1=0$，仅零解。

当 $a=3$：$B$ 化为 $\begin{pmatrix}1&1&-2\\ 1&3&1\\ 1&3&1\end{pmatrix}$，两独立方程 $x_1+x_2-2x_3=0,\ x_1+3x_2+x_3=0$，解得 $x_2=-\frac32x_3,\ x_1=\frac72x_3$，即 $k(7,-3,2)^T$。

(2) $f$ 为平方和故半正定，其规范形仅含 $+$ 项，个数等于 $r(B)$。$a\neq3$ 时 $r(B)=3$，规范形 $z_1^2+z_2^2+z_3^2$；$a=3$ 时 $r(B)=2$，规范形 $z_1^2+z_2^2$。

**易错点**：规范形只看"秩 + 正惯性指数"，平方和二次型正惯性指数 = 秩，无须正交化；$a=3$ 的退化情形（秩降为 $2$）最易漏掉。

**命题规律**：$\sum_i \ell_i^2$ 型二次型，其"零点集 = 线性方程组 $\ell_i=0$ 的解"，秩 = 独立 $\ell_i$ 个数；这类题把二次型问题完全转化为线性方程组问题。

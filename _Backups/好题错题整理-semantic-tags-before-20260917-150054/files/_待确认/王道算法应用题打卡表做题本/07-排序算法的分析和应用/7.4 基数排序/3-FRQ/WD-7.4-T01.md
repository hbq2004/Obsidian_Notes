# FRQ 第 6.4.1 题

任务1：(高优先级) 6.4.1 自己设计一个长度不小于 15 的乱序链表，每个数据元素取值范围 0-99，用基数排序，最终要生成升序链表.

## 答案

![[_Attachments/题目识别/王道算法应用题打卡表做题本-答案/WD-7.4-T01_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：
以如下 15 个结点的乱序单链表为例：
$$L_0:73\to12\to58\to4\to99\to34\to66\to21\to5\to47\to89\to30\to83\to15\to26$$

采用 LSD 基数排序（先按个位分配/收集，再按十位分配/收集），借助 10 个链式队列作为桶，最终得到升序链表：
$$L:4\to5\to12\to15\to21\to26\to30\to34\to47\to58\to66\to73\to83\to89\to99$$

**解题切入点**：
看到“0~99”要立刻想到每个数最多两位，因此基数排序只需要两趟：第一趟按个位，第二趟按十位。看到“链表”，就不要用数组反复搬移元素，应该用链式队列做桶。基数排序的核心是“稳定”：后一趟排序不能破坏前一趟的相对顺序，所以每个桶必须是 FIFO 队列。这本质上就是双关键字排序：先排次要关键字个位，再排主要关键字十位。

**推演**：

1. 将 0~99 看成两位十进制数，例如 $4$ 可看成 $04$。
2. 第一趟按个位 $d=x\bmod 10$ 分配；第二趟按十位 $d=(x/10)\bmod 10$ 分配。
3. 每个桶是队列，分配时从队尾链入，收集时按桶编号 $0\sim9$ 依次首尾相接。

第一趟：按个位分配

| 桶 | 队首 → 队尾 |
|---:|---|
| 0 | 30 |
| 1 | 21 |
| 2 | 12 |
| 3 | 73 → 83 |
| 4 | 4 → 34 |
| 5 | 5 → 15 |
| 6 | 66 → 26 |
| 7 | 47 |
| 8 | 58 |
| 9 | 99 → 89 |

收集得到：
$$L_1=30\to21\to12\to73\to83\to4\to34\to5\to15\to66\to26\to47\to58\to99\to89$$

第二趟：按十位分配

| 桶 | 队首 → 队尾 |
|---:|---|
| 0 | 4 → 5 |
| 1 | 12 → 15 |
| 2 | 21 → 26 |
| 3 | 30 → 34 |
| 4 | 47 |
| 5 | 58 |
| 6 | 66 |
| 7 | 73 |
| 8 | 83 → 89 |
| 9 | 99 |

收集得到：
$$L_2=4\to5\to12\to15\to21\to26\to30\to34\to47\to58\to66\to73\to83\to89\to99$$

第二趟结束后，十位不同的元素，十位小者在前；十位相同的元素，由于第二趟稳定，第一趟得到的个位顺序被保留，所以整体升序。

C 代码核心实现如下，不新建结点，只改链：

```c
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;

typedef struct {
    LNode *front, *rear;
} Queue;

LinkList RadixSortList(LinkList L) {
    Queue Q[10];
    int i, k, d;
    LNode *p, *r, *head, *tail;

    if (L == NULL) return NULL;

    for (k = 0; k < 2; ++k) {
        for (i = 0; i < 10; ++i)
            Q[i].front = Q[i].rear = NULL;

        p = L;
        while (p != NULL) {
            r = p->next;
            d = (k == 0) ? (p->data % 10) : ((p->data / 10) % 10);
            p->next = NULL;

            if (Q[d].rear == NULL)
                Q[d].front = Q[d].rear = p;
            else {
                Q[d].rear->next = p;
                Q[d].rear = p;
            }

            p = r;
        }

        head = tail = NULL;
        for (i = 0; i < 10; ++i) {
            if (Q[i].front != NULL) {
                if (head == NULL)
                    head = Q[i].front;
                else
                    tail->next = Q[i].front;
                tail = Q[i].rear;
            }
        }

        if (tail != NULL) tail->next = NULL;
        L = head;
    }

    return L;
}
```

时间复杂度：每一趟遍历链表 $O(n)$，收集时扫描 10 个桶 $O(10)$，共 2 趟，所以总时间复杂度为 $O(2(n+10))=O(n)$。空间复杂度：上述实现不新建结点，只使用 10 个链式队列的头尾指针，因此额外空间为 $O(1)$。

**易错点**：
- 桶内必须用尾插法，不能用头插法；头插会反转同桶元素顺序，破坏稳定性。
- 0~99 必须做两趟，不能只做一趟个位排序。
- 一位数如 $4$ 的十位是 $0$，第二趟会进入 0 号桶，不能漏掉。
- 从原链表摘结点时，必须先保存后继指针，否则断链后无法继续遍历。
- 收集完必须把最后一个结点的 next 置空，防止链表成环。
- 基数排序应使用 LSD，即先低位后高位；MSD 需要分组处理，不能简单直接收集得到全局有序。

**命题规律**：
本题对应 408 排序章节中的基数排序，常以“给出一组数字，写出第一趟/第二趟分配与收集结果”的形式考查，也可能与稳定性、时间复杂度结合命题。常见变式包括：三位数 0~999 需三趟、字符串/多关键字排序、用链式队列模拟基数排序、与快速排序/堆排序比较等。复习时重点掌握 LSD 的“分配—收集”过程，理解桶必须用 FIFO 队列的原因，并会手算模拟。

基数排序、单链表、链式队列、排序稳定性

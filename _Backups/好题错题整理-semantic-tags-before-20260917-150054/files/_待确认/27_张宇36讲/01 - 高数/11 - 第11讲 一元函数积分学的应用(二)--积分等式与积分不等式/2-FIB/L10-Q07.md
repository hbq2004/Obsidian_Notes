# FIB 第 7 题

![[_Attachments/题目识别/27_张宇36讲-题目/L10-Q07_题目.png|题目]]

$I=\int_{0}^{1} \frac{\ln(1+x)}{1+x^2}dx=\_$.

---

## 答案

![[_Attachments/题目识别/27_张宇36讲-答案/L10-Q07_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**: $\displaystyle \frac{\pi}{8}\ln 2$

**解题切入点**:  
观察被积函数 $\frac{\ln(1+x)}{1+x^2}$，分母 $1+x^2$ 提示三角代换 $x=\tan\theta$，可将分母简化为 $\sec^2\theta$，积分区间变为 $[0,\frac{\pi}{4}]$，从而转化为 $\int_0^{\pi/4}\ln(1+\tan\theta)\,d\theta$。  
再通过对称变换 $\theta=\frac{\pi}{4}-t$，利用三角恒等式建立方程，直接解出积分值。这种“构造方程”的技巧在定积分中非常经典，类似算法竞赛中的“对称性消元”。

**推演**:  
令 $x=\tan\theta$，则 $dx=\sec^2\theta\,d\theta$，当 $x=0$ 时 $\theta=0$，$x=1$ 时 $\theta=\frac{\pi}{4}$。  
$$I=\int_{0}^{1}\frac{\ln(1+x)}{1+x^2}dx=\int_{0}^{\frac{\pi}{4}}\frac{\ln(1+\tan\theta)}{1+\tan^2\theta}\cdot\sec^2\theta\,d\theta=\int_{0}^{\frac{\pi}{4}}\ln(1+\tan\theta)\,d\theta.$$

再令 $\theta=\frac{\pi}{4}-t$，则 $d\theta=-dt$，当 $\theta=0$ 时 $t=\frac{\pi}{4}$，$\theta=\frac{\pi}{4}$ 时 $t=0$，  
$$I=\int_{\frac{\pi}{4}}^{0}\ln\!\left(1+\tan\!\left(\frac{\pi}{4}-t\right)\right)(-dt)=\int_{0}^{\frac{\pi}{4}}\ln\!\left(1+\tan\!\left(\frac{\pi}{4}-t\right)\right)dt.$$

利用公式 $\tan(\frac{\pi}{4}-t)=\frac{1-\tan t}{1+\tan t}$，则  
$$1+\tan\!\left(\frac{\pi}{4}-t\right)=1+\frac{1-\tan t}{1+\tan t}=\frac{2}{1+\tan t},$$
所以  
$$\ln\!\left(1+\tan\!\left(\frac{\pi}{4}-t\right)\right)=\ln2-\ln(1+\tan t).$$

代入得  
$$I=\int_{0}^{\frac{\pi}{4}}\bigl(\ln2-\ln(1+\tan t)\bigr)dt=\frac{\pi}{4}\ln2-\int_{0}^{\frac{\pi}{4}}\ln(1+\tan t)\,dt=\frac{\pi}{4}\ln2-I.$$

于是 $2I=\frac{\pi}{4}\ln2$，故  
$$I=\frac{\pi}{8}\ln2.$$

**易错点**:  
1. 三角代换后 $dx$ 与分母 $1+x^2$ 的约分不能遗漏，必须准确写出 $dx=\sec^2\theta\,d\theta$，$1+x^2=\sec^2\theta$。  
2. 对称变换时注意积分限的变化，$dt$ 前的负号会导致积分限交换，要正确处理。  
3. 化简 $\tan(\frac{\pi}{4}-t)$ 时，差角公式要准确，尤其符号。  
4. 解方程时注意 $I$ 是常数，不要忘记将 $\int\ln(1+\tan t)dt$ 与 $I$ 合并时系数为 $1$。  
5. 最终结果 $\frac{\pi}{8}\ln2$ 不能写成 $\frac{\pi\ln2}{8}$，两者等价，但需避免遗漏 $\pi$ 或 $\ln2$。

**命题规律**:  
本题是考研数学一、二中的经典定积分计算题，核心考察三角代换与对称性构造方程的技巧。常见变式包括：  
- 将 $\ln(1+x)$ 换成 $\ln(1-x)$ 或 $\ln x$，处理方法类似，但需注意区间与奇偶性。  
- 积分限改为 $[0,+\infty)$ 时，可考虑 $\frac{\ln(1+x)}{1+x^2}$ 的广义积分，结果仍与 $\ln2$ 有关。  
- 也可推广到 $\int_0^1\frac{\ln(1+ax)}{1+x^2}dx$ 等含参积分。  
复习建议：熟练掌握三角代换、对称性、区间再现公式，以及利用方程求解积分的方法。这类题目往往计算量不大，但技巧性强，是提高积分计算能力的良好素材。

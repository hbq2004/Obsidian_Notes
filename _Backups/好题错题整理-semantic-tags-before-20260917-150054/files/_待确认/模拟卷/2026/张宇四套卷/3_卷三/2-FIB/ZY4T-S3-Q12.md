# 填空题 第 12 题

![[_Attachments/题目识别/ZY4T/ZY4T-S3-Q12_题目.png|题目]]

设 $u = ze^{\frac{x}{y}} \sin(x^2 + y^2)$ ，其中 $z = z(x, y)$ 是由方程 $3x^2 + 2y^2 + 2z = 7$ 确定的隐函数，则
$$\left.\frac{\partial u}{\partial x}\right|_{(1,1)} = \_\_\_\_\_\_\_\_\_\_.$$

![[_Attachments/题目识别/ZY4T-答案/ZY4T-S3-Q12_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**

填空题【答案】：$$\boxed{2e(\cos2-\sin2)}$$

**解题切入点**

本题是“隐函数+多元复合函数”求偏导，类似算法题中先预处理依赖关系：先由隐函数方程求出中间变量 $z_x$，再沿 $u\to z,e^{x/y},\sin(x^2+y^2)$ 的依赖链用链式法则求 $u_x$，最后代点。

**推演**

1. 由方程 $3x^2+2y^2+2z=7$ 确定 $z=z(x,y)$。在点 $(1,1)$ 处：$3+2+2z=7$，得 $z=1$。

2. 对方程两边关于 $x$ 求偏导（$y$ 视为常数）：$6x+2z_x=0$，故 $z_x=-3x$。于是在 $(1,1)$ 处 $z_x=-3$。

3. 对 $u=ze^{x/y}\sin(x^2+y^2)$ 关于 $x$ 求偏导，用乘法法则与链式法则：

$$\frac{\partial u}{\partial x}=z_x e^{x/y}\sin(x^2+y^2)+ze^{x/y}\cdot\frac{1}{y}\sin(x^2+y^2)+ze^{x/y}\cos(x^2+y^2)\cdot2x.$$

4. 代入 $(x,y)=(1,1)$，$z=1,z_x=-3$：

$$\left.\frac{\partial u}{\partial x}\right|_{(1,1)}=(-3)e\sin2+e\sin2+2e\cos2=2e(\cos2-\sin2).$$

**易错点**

- 勿把 $z$ 当常数，对 $x$ 求导时漏掉 $z_x$ 项。
- $\sin(x^2+y^2)$ 对 $x$ 求导为 $\cos(x^2+y^2)\cdot2x$，不要漏乘 $2x$。
- $e^{x/y}$ 对 $x$ 求导为 $e^{x/y}\cdot\frac{1}{y}$，不要误写成 $e^{x/y}$。
- 注意先代点求 $z$，再代偏导值，避免把 $z$ 误代入为其他值。

**命题规律**

这类题是考研数学一高频小题：隐函数求导与多元复合函数求导结合，常给具体点。复习时应熟练写出复合函数偏导的“链式展开”，并养成“先求中间量、再代点”的习惯。

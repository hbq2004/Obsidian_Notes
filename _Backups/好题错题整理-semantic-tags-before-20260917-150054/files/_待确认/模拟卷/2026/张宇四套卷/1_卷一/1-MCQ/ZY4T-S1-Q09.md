# 选择题 第 9 题

![[_Attachments/题目识别/ZY4T/ZY4T-S1-Q09_题目.png|题目]]

设 $X_1, X_2, \cdots, X_{25}$ 是来自总体 $N(\mu, \sigma^2)(\sigma > 0)$ 的简单随机样本，$\Phi(x)$ 表示标准正态分布函数，考虑假设检验问题：$H_0: \mu \leqslant 10, H_1: \mu > 10$，若该检验问题的拒绝域为 $W = \{\overline{X} > 20\}$，其中 $\overline{X} = \frac{1}{25}\sum_{i=1}^{25}X_i$，当 $\mu = 20.5$ 时，该检验犯第二类错误的概率为 $1 - \Phi\left(\frac{1}{2}\right)$，则 $\sigma =$
(A) 5.
(B) 6.
(C) 7.
(D) 8.

![[_Attachments/题目识别/ZY4T-答案/ZY4T-S1-Q09_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**
本题考察假设检验中第二类错误概率的计算。由题意，犯第二类错误的概率为β = P{接受H0|H1真} = P{X̄ ≤ 20 | μ=20.5}。在μ=20.5下，X̄ ~ N(20.5, σ²/25)，标准化得β = Φ( (20-20.5)/(σ/5) ) = Φ(-2.5/σ) = 1-Φ(2.5/σ)。已知β = 1-Φ(1/2)，故Φ(2.5/σ)=Φ(1/2)，得2.5/σ=1/2，σ=5。因此正确选项为(A)。

**解题切入点**
本题主要考查假设检验中第二类错误的概念及其计算，关键在于将第二类错误概率转化为在备择假设下样本均值落在接受域的概率，并利用正态总体抽样分布进行标准化。与算法竞赛类比，相当于给定一个判定规则，求当真实参数偏离原假设时，规则未能识别异常的概率，通过标准化转化为标准正态分布函数值的比较。

**推演**
1. 明确原假设与备择假设：H₀: μ ≤ 10, H₁: μ > 10。拒绝域W = {X̄ > 20}，即当样本均值大于20时拒绝H₀。
2. 第二类错误（取伪）是指在H₁成立时（即μ>10），样本观测值未落入拒绝域，从而接受H₀的概率。当μ=20.5>10，故H₁为真，第二类错误概率β = P{接受H₀|μ=20.5} = P{X̄ ≤ 20 | μ=20.5}。
3. 在μ=20.5条件下，样本均值X̄ ~ N(μ, σ²/n) = N(20.5, σ²/25)，标准差σ/√n = σ/5。
4. 标准化：Z = (X̄ - 20.5)/(σ/5) ~ N(0,1)，则
   β = P{ X̄ ≤ 20 } = P{ Z ≤ (20-20.5)/(σ/5) } = P{ Z ≤ -0.5/(σ/5) } = P{ Z ≤ -2.5/σ } = Φ(-2.5/σ) = 1 - Φ(2.5/σ)。
5. 已知β = 1 - Φ(1/2)，故有1 - Φ(2.5/σ) = 1 - Φ(1/2) ⇒ Φ(2.5/σ) = Φ(1/2)。
   由于标准正态分布函数是严格单调递增的，所以2.5/σ = 1/2，解得σ = 5。
6. 逐一分析选项：
   (A) σ=5：代入得β=1-Φ(2.5/5)=1-Φ(0.5)=1-Φ(1/2)，符合题意，正确。
   (B) σ=6：β=1-Φ(2.5/6)=1-Φ(0.4167)≠1-Φ(0.5)，错误。
   (C) σ=7：β=1-Φ(2.5/7)=1-Φ(0.3571)≠1-Φ(0.5)，错误。
   (D) σ=8：β=1-Φ(2.5/8)=1-Φ(0.3125)≠1-Φ(0.5)，错误。
故正确答案为(A)。

**易错点**
- 易将第二类错误概率与第一类错误混淆，第二类错误是“取伪”，即H₁真时接受H₀。
- 标准化时注意分母是σ/√n，本题n=25，所以√n=5，不要误用成σ/√n。
- 注意Φ(-x)=1-Φ(x)的运用，以及标准正态分布函数单调性确保方程唯一解。
- 选项计算时需注意Φ(2.5/σ)=Φ(1/2)直接推出2.5/σ=0.5，无需查表。

**命题规律**
- 假设检验是考研数学一的重要考点，常以选择题或填空题形式出现，重点考查两类错误概率的计算。
- 通常结合正态总体抽样分布，通过标准化转化为标准正态分布处理。
- 复习时应熟练掌握假设检验的基本概念、拒绝域与接受域、两类错误的关系，以及正态总体下样本均值的分布。
- 注意与参数估计等内容结合，理解检验水平、功效等概念。

# MCQ 第 9 题

![[_Attachments/题目识别/YBS5T/YBS5T-S4-Q09_题目.png|题目]]

从 $0,1,\cdots,9$ 等十个数字中任意选出三个不同的数字. 记随机变量
$$X = \begin{cases} 0, & \text{三个数字中不含 } 0， \\ 1, & \text{三个数字中含 } 0， \end{cases} \quad Y = \begin{cases} 0, & \text{三个数字中不含 } 5， \\ 1, & \text{三个数字中含 } 5， \end{cases}$$
则 $X$ 和 $Y$ 的相关系数 $\rho_{XY} = ( \quad )$.
(A) $0$
(B) $\frac{1}{9}$
(C) $-\frac{1}{9}$
(D) $-1$

![[_Attachments/题目识别/YBS5T-答案/YBS5T-S4-Q09_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**

【答案】: (C)

【推演】: 计算得 $\rho_{XY} = -\frac{1}{9}$，故选项 (C) 正确。选项 (A) 0 为不相关时的值，但此处相关；选项 (B) $\frac{1}{9}$ 符号相反；选项 (D) $-1$ 为完全负相关，但此处不是完全线性关系。

**解题切入点**

本题考察二维随机变量的相关系数计算，需先计算联合分布与边缘分布，再利用协方差公式求解。类似算法竞赛中处理概率题，需注意古典概型计数与0-1变量的期望方差公式。

**推演**

1. 总样本空间：从 $0,\cdots,9$ 中任选3个不同数字，共有 $C_{10}^3=120$ 种等可能取法。
2. 边缘分布：$P(X=1)=\frac{C_9^2}{C_{10}^3}=\frac{36}{120}=\frac{3}{10}$，同理 $P(Y=1)=\frac{3}{10}$。
3. 联合分布：$P(X=1,Y=1)=\frac{C_8^1}{C_{10}^3}=\frac{8}{120}=\frac{1}{15}$；$P(X=1,Y=0)=P(X=1)-P(X=1,Y=1)=\frac{3}{10}-\frac{1}{15}=\frac{7}{30}$；同理 $P(X=0,Y=1)=\frac{7}{30}$；$P(X=0,Y=0)=1-\frac{3}{10}-\frac{3}{10}+\frac{1}{15}=\frac{7}{15}$。
4. 期望与方差：$E[X]=E[Y]=\frac{3}{10}$，$\operatorname{Var}(X)=E[X^2]-(E[X])^2=\frac{3}{10}-\left(\frac{3}{10}\right)^2=\frac{21}{100}$，同理 $\operatorname{Var}(Y)=\frac{21}{100}$。
5. 协方差：$E[XY]=P(X=1,Y=1)=\frac{1}{15}$，$\operatorname{Cov}(X,Y)=E[XY]-E[X]E[Y]=\frac{1}{15}-\frac{9}{100}=-\frac{7}{300}$。
6. 相关系数：$\rho_{XY}=\frac{\operatorname{Cov}(X,Y)}{\sqrt{\operatorname{Var}(X)\operatorname{Var}(Y)}}=\frac{-\frac{7}{300}}{\frac{21}{100}}=-\frac{1}{9}$。

**易错点**

- 联合分布计算容易遗漏 $P(X=0,Y=0)$ 或误用古典概型；注意计数时需考虑不含0和5的情况。
- 协方差公式中 $E[XY]$ 对应 $X=1,Y=1$ 的概率，勿用 $P(X=1)P(Y=1)$ 代替。
- 相关系数符号判断：$\rho$ 为负表明 $X$ 与 $Y$ 负相关，含0与含5同时出现概率小于独立情形。

**命题规律**

此类题目常以古典概型为背景，考查0-1随机变量的相关性与协方差计算，是概率论基础题。复习时需熟练掌握离散型随机变量的分布列、期望方差公式及相关系数性质，注意计数准确性。

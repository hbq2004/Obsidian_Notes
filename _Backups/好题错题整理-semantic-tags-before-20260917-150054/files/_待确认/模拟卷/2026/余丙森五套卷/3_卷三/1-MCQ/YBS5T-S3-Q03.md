# MCQ 第 3 题

![[_Attachments/题目识别/YBS5T/YBS5T-S3-Q03_题目.png|题目]]

设区域 $D$ 由 $x + y = \frac{1}{2}, x + y = \sqrt{\frac{\pi}{2}}$ 及两坐标轴围成，记
$$
I_1 = \iint_{D} \ln[1+(x+y)^2] \mathrm{d}x \mathrm{d}y, I_2 = \frac{\pi}{2} \iint_{D} \sin(x+y)^2 \mathrm{d}x \mathrm{d}y, I_3 = \iint_{D} (x+y)^2 \mathrm{d}x \mathrm{d}y,
$$
则 (  ).
(A) $I_2 < I_3 < I_1$
(B) $I_1 < I_3 < I_2$
(C) $I_3 < I_1 < I_2$
(D) $I_3 < I_2 < I_1$

![[_Attachments/题目识别/YBS5T-答案/YBS5T-S3-Q03_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**

【答案】: (B)

【推演】: 通过变量替换将二重积分化为一重积分，比较被积函数大小，得到 $I_1 < I_3 < I_2$，故选(B)。

选项分析：
- (A) $I_2 < I_3 < I_1$：由 $I_1 < I_3 < I_2$ 知错误。
- (B) $I_1 < I_3 < I_2$：正确。
- (C) $I_3 < I_1 < I_2$：错误，实际 $I_1 < I_3$。
- (D) $I_3 < I_2 < I_1$：错误，实际 $I_1$ 最小。

**解题切入点**

本题主要考查二重积分的计算与比较，被积函数仅依赖于 $x+y$，且区域由 $x+y$ 为常数和坐标轴围成，因此采用变量替换 $u=x+y$ 将二重积分化为定积分。然后比较定积分中被积函数的大小，利用函数单调性即可判断。

**推演**

1. 区域 $D$ 可表示为 $x\ge0,y\ge0,\frac12\le x+y\le\sqrt{\frac{\pi}{2}}$。
2. 令 $u=x+y$，则对于固定的 $u$，$x$ 从 $0$ 到 $u$，$y=u-x$，所以二重积分化为 $\int_{1/2}^{\sqrt{\pi/2}} \left(\int_0^u f(x+y) dx\right) du = \int_{1/2}^{\sqrt{\pi/2}} u f(u) du$，其中 $f$ 为被积函数。
3. 因此：
   $$I_1 = \int_{1/2}^{\sqrt{\pi/2}} u \ln(1+u^2) du,$$
   $$I_2 = \frac{\pi}{2} \int_{1/2}^{\sqrt{\pi/2}} u \sin(u^2) du,$$
   $$I_3 = \int_{1/2}^{\sqrt{\pi/2}} u^3 du.$$
4. 比较被积函数 $g_1(u)=u\ln(1+u^2)$, $g_2(u)=\frac{\pi}{2}u\sin(u^2)$, $g_3(u)=u^3$。由于 $u>0$，比较 $g_1,g_2,g_3$ 等价于比较 $h_1(u)=\ln(1+u^2)$, $h_2(u)=\frac{\pi}{2}\sin(u^2)$, $h_3(u)=u^2$。
5. 在区间 $u\in[1/2,\sqrt{\pi/2}]$ 上：
   - $u^2 > \ln(1+u^2)$ 恒成立（因为 $x>\ln(1+x)$ 对 $x>0$），故 $h_3(u)>h_1(u)$。
   - 考虑 $h_2(u)-h_3(u)=\frac{\pi}{2}\sin(u^2)-u^2$。令 $t=u^2\in[1/4,\pi/2]$，则 $h_2-h_3=\frac{\pi}{2}\sin t - t$。记 $\varphi(t)=\frac{\pi}{2}\sin t - t$，$\varphi'(t)=\frac{\pi}{2}\cos t -1$。在 $t\in[1/4,\pi/2]$ 上，$\varphi'(t)$ 从正变负，且 $\varphi(1/4)>0$，$\varphi(\pi/2)=0$，故 $\varphi(t)\ge0$，即 $h_2(u)\ge h_3(u)$，等号仅在 $u=\sqrt{\pi/2}$ 成立。因此 $h_2(u)\ge h_3(u)>h_1(u)$。
6. 所以 $g_2(u)\ge g_3(u)>g_1(u)$，积分得 $I_2 > I_3 > I_1$，即 $I_1 < I_3 < I_2$，对应选项 (B)。

**易错点**

1. 错误理解 $\sin(x+y)^2$ 的含义，将其误认为 $\sin^2(x+y)$，导致比较错误。
2. 二重积分化为累次积分时，积分限确定错误，如忘记 $x$ 从 $0$ 到 $u$ 而误将 $x$ 范围当成常数。
3. 比较函数大小时，忽略 $u$ 因子，直接比较 $f(u)$ 而忘记乘以 $u$，但此处 $u$ 为正，不影响大小关系，但需注意。
4. 未能证明 $h_2(u)\ge h_3(u)$ 的严格性，导致认为可能有相等，但积分后严格不等。

**命题规律**

本题是典型的多选题，考查二重积分的计算与比较。命题的核心在于利用变量替换简化积分，然后通过函数单调性比较大小。复习时应注重：
- 掌握二重积分的变量替换技巧，特别是被积函数和区域对称时。
- 熟记常见不等式，如 $x>\ln(1+x)$，$\sin x \le x$ 等。
- 注意带有参数的积分比较，可通过构造函数求导判断单调性。
- 此类题目常出现在考研数学一的选择题中，难度中等，需细心计算。

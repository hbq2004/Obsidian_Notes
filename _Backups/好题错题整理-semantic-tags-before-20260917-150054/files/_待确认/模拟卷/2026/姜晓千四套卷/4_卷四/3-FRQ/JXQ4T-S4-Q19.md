# FRQ 第 19 题

![[_Attachments/题目识别/JXQ4T/JXQ4T-S4-Q19_题目.png|题目]]

设 $f(x) = \frac{7+2x}{2-x-x^2}$ 在 $(-1,1)$ 内展开成 $x$ 的幂级数为 $\sum_{n=0}^{\infty} a_n x^n$.

(I) 求 $a_n$;

(II) 证明级数 $\sum_{n=0}^{\infty} \frac{a_{n+1}-a_n}{(a_n-2)(a_{n+1}-2)}$ 收敛,并求其和.

![[_Attachments/题目识别/JXQ4T-答案/JXQ4T-S4-Q19_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**
(I) $a_n = 3 + \frac{(-1)^n}{2^{n+1}}$，$n\ge 0$。
(II) 级数收敛，其和为 $-\frac{1}{3}$。

关键给分点：①部分分式分解正确；②等比级数展开得通项 $a_n$；③裂项为差分形式；④求部分和极限。

**解题切入点**
类比算法竞赛中处理级数求和，先观察通项能否裂项。本题 $a_n$ 有简单形式，分母 $(a_n-2)(a_{n+1}-2)$ 与分子 $a_{n+1}-a_n$ 直接构成差分，裂项后 telescoping 求极限。

**推演**
1. 因式分解分母：$2-x-x^2 = (x+2)(1-x)$，设 $f(x)=\frac{A}{x+2}+\frac{B}{1-x}$，解得 $A=1, B=3$。
2. 展开：$\frac{1}{x+2}=\frac{1}{2}\sum_{n=0}^{\infty}\left(-\frac{x}{2}\right)^n = \sum_{n=0}^{\infty}\frac{(-1)^n}{2^{n+1}}x^n$，$\frac{3}{1-x}=3\sum_{n=0}^{\infty}x^n$。
3. 故 $a_n = 3 + \frac{(-1)^n}{2^{n+1}}$。
4. 计算 $a_n-2 = 1 + \frac{(-1)^n}{2^{n+1}}$。
5. 通项变形：$\frac{a_{n+1}-a_n}{(a_n-2)(a_{n+1}-2)} = \frac{1}{a_n-2} - \frac{1}{a_{n+1}-2}$。
6. 部分和 $S_N = \sum_{n=0}^{N}\left[\frac{1}{a_n-2} - \frac{1}{a_{n+1}-2}\right] = \frac{1}{a_0-2} - \frac{1}{a_{N+1}-2}$。
7. $a_0 = \frac{7}{2}$，$\lim_{N\to\infty} a_{N+1} = 3$，故 $\lim_{N\to\infty}\frac{1}{a_{N+1}-2} = 1$。
8. 所以 $S = \frac{1}{3/2} - 1 = -\frac{1}{3}$，且部分和极限存在，故级数收敛。

**易错点**
- 部分分式分解时注意分母是 $(x+2)(1-x)$，不要写成 $(x+2)(x-1)$ 导致符号错误。
- 展开 $\frac{1}{x+2}$ 时系数 $\frac{1}{2}$ 和 $(-1)^n$ 易漏。
- 裂项时分子是 $a_{n+1}-a_n$，对应差分，不要反。
- 求极限时 $a_n\to 3$，所以 $\frac{1}{a_n-2}\to 1$，注意常数。

**命题规律**
本题将幂级数展开与级数求和结合，先展开求系数，再通过裂项求 telescoping 级数和。复习时应熟练掌握有理函数部分分式、等比级数展开、以及差分裂项技巧。

2. 单链表循环右移
现有一不带头结点的单链表 head，给定一常数 $k$ 使得该单链表循环向右移动 $k$ 个结点位置，返回移动后的链表. 例如下图（L 为头指针）即为 $k=2$ 的右移结果.
【图】
(1) 描述该算法的基本思想；
(2) 写出该单链表的数据结构定义，并实现该算法（只可以使用 c 或 c++ 来实现）；
(3) 写出该算法的时间复杂度和空间复杂度.

## DeepSeek V4 Flash Max 解析

**答案**：本题为无选项算法设计题。正确做法是：先遍历求表长 $n$，令 $k'=k\bmod n$；将原链表首尾相接成环，再从第 $n-k'$ 个结点后断开，返回第 $n-k'+1$ 个结点。时间复杂度 $O(n)$，空间复杂度 $O(1)$。

**解题切入点**：拿到题先判断这是单链表，只能从 `head` 沿 `next` 指针走，不能随机访问；循环右移 $k$ 位等价于把最后 $k$ 个结点整体搬到链表头部。所以不能“一次移动一个结点”地模拟，而应先求出表长、取模，再定位断开位置。可以类比“量出绳子总长，再从固定位置剪开，把两段互换”。

**推演**：

（1）算法基本思想

设原链表为：

$$
a_1 \to a_2 \to \cdots \to a_n
$$

若 $k'=k\bmod n$，且 $0<k'<n$，循环右移 $k'$ 个位置后应变为：

$$
a_{n-k'+1} \to a_{n-k'+2} \to \cdots \to a_n \to a_1 \to a_2 \to \cdots \to a_{n-k'}
$$

因此，新表头是原链表中第 $n-k'+1$ 个结点，新表尾是原链表中第 $n-k'$ 个结点。

具体做法：

- 先遍历一次，求出链表长度 $n$，并记录原尾结点；
- 令 $k'=k\bmod n$；
- 若 $k'=0$，说明右移后回到原样，直接返回原头；
- 否则将原尾结点的 `next` 指向原头结点，使链表成环；
- 从原头结点出发，走 $n-k'-1$ 步，到达新表尾；
- 将新表尾的 `next` 置空，返回新表头。

（2）数据结构定义与 C/C++ 实现

```cpp
typedef int ElemType;

typedef struct LNode {
    ElemType data;          // 数据域
    struct LNode *next;     // 指针域
} LNode, *LinkList;

LinkList rotateRight(LinkList head, int k) {
    // 空表、单结点或不需要移动的情况
    if (head == NULL || head->next == NULL || k == 0)
        return head;

    // 1. 遍历求表长 n，同时找到原尾结点 tail
    int n = 1;
    LinkList tail = head;
    while (tail->next != NULL) {
        tail = tail->next;
        ++n;
    }

    // 2. 取模，右移 n 次等于没有移动
    k = k % n;
    if (k == 0)
        return head;

    // 3. 首尾相连，形成环
    tail->next = head;

    // 4. 寻找新表尾：原链表第 n-k 个结点
    LinkList newTail = head;
    for (int i = 0; i < n - k - 1; ++i)
        newTail = newTail->next;

    // 5. 新表头是 newTail 的下一个结点，然后断开环
    LinkList newHead = newTail->next;
    newTail->next = NULL;

    return newHead;
}
```

验证示例：

原链表：

$$
1 \to 2 \to 3 \to 4 \to 5 \to \text{NULL}
$$

$n=5$，$k=2$，则 $k'=2$。成环后从原头走 $5-2-1=2$ 步到达结点 $3$，即新表尾；新表头为 $4$。最终：

$$
4 \to 5 \to 1 \to 2 \to 3 \to \text{NULL}
$$

这正是循环右移 $2$ 位的结果。

（3）时间复杂度与空间复杂度

- 求表长遍历整个链表，耗时 $O(n)$；
- 定位新表尾最多再遍历 $O(n)$ 个结点；
- 只使用了常数个辅助指针变量。

所以：

$$
T(n)=O(n),\qquad S(n)=O(1)
$$

**易错点**：

- 忘记处理空表、单结点或 $k\bmod n=0$ 的情况，可能导致空指针访问或环无法断开。
- 不先取模，$k$ 很大时会做大量无意义移动；若 $k=n$ 时还按普通方法找断点，容易越界。
- 定位断点容易多走或少走一步。可用具体例子验证，例如 $1\to2\to3\to4\to5$，$k=2$ 时新表尾应为 $3$。
- 不带头结点的链表，原来的 `head` 很可能不是新表头，必须返回 `newHead`；只修改局部变量不会影响调用者。
- 成环后如果还使用 `while (p != NULL)` 这类循环遍历，会死循环。
- 断开时忘记把新表尾的 `next` 置为 `NULL`，结果仍是循环链表。

**命题规律**：本题属于数据结构第二章“线性表”的链表算法设计题，重点考查单链表遍历、指针修改和边界条件。它与 2010 年统考“数组循环左移”是同一类问题，只是存储结构从顺序表换成了单链表。常见变式有：寻找或删除倒数第 $k$ 个结点、链表循环右移、链表按段反转、判断链表是否有环等。复习时应多画指针变化图，重点训练空表、单结点、$k=0$、$k=n$ 等边界情况，并养成“先写思想、再写代码、最后写复杂度”的答题习惯。

# MCQ 第 3 题

![[_Attachments/题目识别/27_零壹习题册-题目/DS-C04-Q003_题目.png|题目]]

3. 用计算机表示一个环（即尾元素的直接后继为首元素），下面说法正确的是（   ）.

(A) 无论采用何种物理存储方式，其逻辑结构均不是线性表

(B) 若采用不带头结点但包含首尾指针的循环单链表实现，则删除尾元素的时间复杂度为 $O(1)$

(C) 若采用数组实现，元素依次保存在数组中且元素个数为 $n$，则删除第 $k$ 个（$1 \leq k \leq n$，从1开始计数）的后继元素时需要的基本操作次数为 $O(n-k+1)$

(D) 非循环单链表不能作为该环的物理存储结构

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/DS-C04-Q003_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A。环（尾元素的直接后继为首元素）在逻辑上不存在唯一的“首/尾”，不满足线性表的逻辑特征，因此不是线性表；其余选项均有明显错误。

**解题切入点**：拿到题目先判断“环”到底是逻辑结构还是存储结构。题目明确定义了逻辑关系：“尾元素的直接后继为首元素”，所以应先从线性表的逻辑定义入手，再看各选项的存储实现和复杂度。做题时要把“逻辑结构”和“物理存储结构”分开，不要因为“循环链表”的名字就误以为逻辑上仍是线性表。

**推演**：

线性表的逻辑定义为：有限序列，存在唯一的一个首元素（无直接前驱）和唯一的一个尾元素（无直接后继），除首、尾元素外，每个元素有且仅有一个直接前驱和一个直接后继。

对于题中的“环”，尾元素的直接后继是首元素，即尾元素有直接后继，首元素有直接前驱，形成了闭合回路。这违背了线性表中“尾元素无后继、首元素无前驱”的条件，所以无论采用数组、链表还是其他物理存储方式，其逻辑结构都不是线性表。故 A 正确。

B 项：不带头结点但包含首尾指针的循环单链表实现，删除尾元素时需要找到尾元素的前驱结点，并将其 “next” 指针改为 head，同时更新尾指针。由于是单链表，无法从尾结点直接获取前驱，必须从头遍历，时间复杂度为 $O(n)$，不是 $O(1)$。B 错误。  
即使想用“复制头结点数据到尾结点，再删除头结点”的技巧，也无法在 $O(1)$ 内把尾指针正确更新为新的尾结点，因此不能使结构保持合法。

C 项：设数组下标从 $1$ 到 $n$，元素依次存放在数组中。

- 若 $k<n$，第 $k$ 个元素的后继在第 $k+1$ 个位置，删除后需要将位置 $k+2$ 到 $n$ 的元素依次前移，移动次数为 $n-(k+1)=n-k-1$，即 $O(n-k)$；
- 若 $k=n$，按环的定义，其后继是首元素，即数组中第 $1$ 个元素。删除首元素后需将第 $2$ 到第 $n$ 个元素依次前移，移动次数为 $n-1$，即 $O(n)$。

但选项给出的 $O(n-k+1)$ 在 $k=n$ 时为 $O(1)$，与实际情况 $O(n)$ 不符，故 C 错误。

D 项：非循环单链表也可以作为环的物理存储结构。例如用非循环单链表存储元素，同时额外保存一个头指针，并在遍历到尾结点时通过头指针回到首元素，就能在逻辑上表示环。物理存储结构不必要求尾结点的 “next” 指针必须直接指向首结点。因此 D 错误。

**易错点**：

1. 误以为“循环链表”的逻辑结构就是线性表，忽略了题目中“尾元素的直接后继为首元素”这一逻辑关系。  
2. 认为有“首尾指针”就能 $O(1)$ 删除尾结点，忘记了单链表找前驱需要遍历；复制删除技巧无法同时维护合法的尾指针。  
3. 数组删除后继元素时忘记处理 $k=n$ 的环绕情况，导致使用 $O(n-k+1)$ 判断失误。  
4. 把“非循环单链表”直接排除在环的存储结构之外，其实物理存储结构可以借助额外指针或规则表示逻辑上的环。

**命题规律**：本题核心考点是“逻辑结构与存储结构的关系”以及链表、数组的插入删除复杂度。常见变式包括：判断循环队列/循环链表的逻辑类型，分析带头结点与不带头结点时增删操作的复杂度，或者给定“尾指针”问队首/队尾操作是否需要遍历。复习时应熟练掌握线性表逻辑特征、单链表和循环链表各种操作的复杂度，并特别注意边界条件（如 $k=n$、空表、单结点表）对复杂度的影响。

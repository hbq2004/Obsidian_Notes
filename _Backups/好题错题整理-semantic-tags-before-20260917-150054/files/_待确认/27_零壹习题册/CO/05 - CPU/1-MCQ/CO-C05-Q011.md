# MCQ 第 11 题

![[_Attachments/题目识别/27_零壹习题册-题目/CO-C05-Q011_题目.png|题目]]

11. 在单总线数据通路中 $R1+R2 \rightarrow R3$ 过程需要三个时钟，其中 $R2+Y \rightarrow Z$ 这个时钟的详细过程如下图所示：时钟信号开始后一段时间（Clk-to-Signal）R2out 信号有效，且该时间大于锁存延迟 Clk-to-Q；控制信号有效后在 $t_0$ 时刻作用于三态门，$t_1$ 时刻三态门打开，将 R2 的内容送到总线上；经过总线传输在 $t_2$ 时刻数据到达 ALU 一端；经过 ALU 计算得到的结果在 $t_3$ 时刻到达 Z 的输入端；在下一个时钟到来之前，数据需要稳定一段时间（建立时间 $t_3$-$t_4$），同时 R2out 和 add 信号需要保持一段时间（$t_4$-$t_5$ 保持时间）.

【图为时序图，包含：Clk 时钟波形，标注 Clk-to-Q；Clk-to-Signal 信号，标注“R2的输出开始有效”；接通三态门时间；总线传输时间；$R2_{out}$ 信号波形，标注时刻 $t_0$、$t_1$；ALU时延；建立时间；保持时间；$Z_{in}$ 信号波形，标注时刻 $t_0$、$t_1$、$t_2$、$t_3$、$t_4$、$t_5$.】

若已知 Clk-to-Signal 为 10ps，Clk-to-Q 为 5ps，三态门接通时间为 3ps，总线传输时间为 15ps，ALU 延迟为 197ps，目的寄存器建立时间为 10ps，保持时间为 10ps，$R2+Y \rightarrow Z$ 完成最少需要 235ps，则 $Z \rightarrow R3$ 这一操作完成最少需要多少时间？

(A) 38ps
(B) 48ps
(C) 245ps
(D) 235ps

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/CO-C05-Q011_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。因为 \(Z\to R3\) 是 \(R1+R2\to R3\) 三个同步时钟周期中的一拍，时钟周期必须由最慢一拍 \(R2+Y\to Z\) 决定，所以至少为 235ps。

**解题切入点**：先判断这是“单总线数据通路 + 多周期 CPU”的时钟周期计算问题。拿到题目先问自己：题目问的是“某一条组合通路延迟”，还是“某一个时钟周期/操作一拍的时间”？本题说 \(R1+R2\to R3\) 需要三个时钟，因此关键不是单独算 \(Z\to R3\) 的组合延迟，而是看三拍中最慢的一拍定时钟周期。

**推演**：

\(R1+R2\to R3\) 在单总线数据通路中可分成三拍：

\[
R1\to Y,\qquad R2+Y\to Z,\qquad Z\to R3
\]

其中第二拍 \(R2+Y\to Z\) 的关键路径为：

\[
10\text{ps(Clk-to-Signal)}
+3\text{ps(三态门)}
+15\text{ps(总线)}
+197\text{ps(ALU)}
+10\text{ps(建立时间)}
=235\text{ps}
\]

而单独看 \(Z\to R3\) 的组合通路，不需要 ALU：

\[
10+3+15+10=38\text{ps}
\]

但同步单总线数据通路中，各拍共用一个时钟周期，时钟周期不能有时是 38ps、有时是 235ps，而应取所有微操作中的最大值：

\[
T_{\text{clk}}=\max\{38,235,38\}=235\text{ps}
\]

所以 \(Z\to R3\) 作为第三个时钟周期中的一拍，其完成时间至少为一个时钟周期：

\[
\boxed{235\text{ps}}
\]

选 **D**。

**易错点**：

1. **误选 A（38ps）**：38ps 只是 \(Z\to R3\) 的组合通路延迟，不是同步电路中“一拍”的完成时间。题目问的是三个时钟周期中的一拍，不是孤立的数据通路延迟。  
2. **误选 B（48ps）**：38ps 再加保持时间 10ps 得 48ps，但保持时间在时钟沿之后，不由时钟周期直接决定，不能加进最小周期。  
3. **误选 C（245ps）**：245ps 相当于给 \(R2+Y\to Z\) 又加了保持时间，即 \(235+10\)，同理，保持时间不参与时钟周期计算。  
4. **重复加 Clk-to-Q**：题干说明 Clk-to-Signal 为 10ps，大于 Clk-to-Q 的 5ps，说明源寄存器数据先稳定，控制信号后有效，所以关键路径从 Clk-to-Signal 开始计，不重复加 Clk-to-Q。

**命题规律**：考点是“单总线数据通路 + 多周期 CPU 的时钟周期计算”。常见变式有：给各部件延迟求时钟周期、求最大时钟频率、判断建立时间/保持时间是否满足。复习时牢记：一拍的最短时间 = 控制信号延迟 + 组合逻辑延迟 + 建立时间；同步多周期 CPU 的时钟周期取各拍最大值；保持时间在采样沿之后单独检查，不加入时钟周期。

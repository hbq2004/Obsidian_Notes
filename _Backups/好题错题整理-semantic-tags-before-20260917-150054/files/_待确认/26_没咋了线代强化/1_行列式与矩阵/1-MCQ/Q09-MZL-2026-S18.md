# MCQ 第 9 题

![[_Attachments/题目识别/MZL-2026/MZL-2026-S18-Q09_题目.png|题目]]

设 $n$ 阶矩阵 $A, B, C$ 满足 $r(A) + r(B) + r(C) = r(ABC) + 2n$，给出下列四个结论：

① $r(ABC) + n = r(AB) + r(C)$; ② $r(AB) + n = r(A) + r(B)$;

③ $r(A) = r(B) = r(C) = n$; ④ $r(AB) = r(BC) = n$.

其中正确的选项是（）.

(A) ①② 
(B) ①③ 
(C) ②④ 
(D) ③④

## V4 Flash Max 解析

**答案**: A（①② 正确）。题干条件等价于两次 Sylvester 秩不等式同时取等，因此①②成立；③④可用反例排除。

**解题切入点**:  
看到“三个秩的和”与“乘积的秩”相差 $2n$，应立刻想到 Sylvester 不等式：

$$r(XY)\ge r(X)+r(Y)-n$$

题目条件给出的等式，实际上是把这个下界链“夹逼”到了等号。思路类似算法竞赛中“两个 lower bound 夹出精确值”：先用一次不等式估计 $r(AB)$，再用一次估计 $r(ABC)$。

**推演**:  
设

$$a=r(A),\quad b=r(B),\quad c=r(C),\quad x=r(ABC).$$

由 Sylvester 不等式：

$$r(AB)\ge a+b-n,$$

再用一次：

$$r(ABC)=r((AB)C)\ge r(AB)+c-n.$$

所以

$$x=r(ABC)\ge r(AB)+c-n\ge a+b+c-2n.$$

题干给出

$$a+b+c=x+2n,$$

即

$$a+b+c-2n=x.$$

因此上面的不等式链变成

$$x\ge r(AB)+c-n\ge x,$$

所以两个不等号都必须取等号。

于是：

$$r(AB)+c-n=x \Rightarrow r(ABC)+n=r(AB)+r(C),$$

即①正确。

同时：

$$r(AB)=a+b-n \Rightarrow r(AB)+n=r(A)+r(B),$$

即②正确。

③④不正确。反例：取 $n=2$，$A=B=I_2$，$C=0_2$。则

$$r(A)+r(B)+r(C)=2+2+0=4,$$

而

$$r(ABC)+2n=r(0)+4=4.$$

满足题干条件，但 $r(C)=0\neq 2$，所以③错；同时 $r(BC)=r(0)=0\neq2$，所以④错。

**易错点**:  
常见错误是只写出

$$r(ABC)\ge r(A)+r(B)+r(C)-2n,$$

但没有说明两次不等式同时取等，导致无法推出①②。实际上题目等式就是一个“下界恰好达到”的信号。  
另一个误区是认为条件很强，能推出满秩；反例中用零矩阵即可说明“满秩”不是必要条件。

**命题规律**:  
这是线性代数中“秩不等式取等”的经典考法。核心是 Sylvester 不等式：

$$r(XY)\ge r(X)+r(Y)-n.$$

常见变式包括：给定 $r(A)+r(B)$ 与 $r(AB)$ 的关系，判断某个矩阵是否满秩；或者结合分块矩阵、线性方程组解的结构。掌握“乘积秩的下界”和“取等条件”是解决这类小题的关键。

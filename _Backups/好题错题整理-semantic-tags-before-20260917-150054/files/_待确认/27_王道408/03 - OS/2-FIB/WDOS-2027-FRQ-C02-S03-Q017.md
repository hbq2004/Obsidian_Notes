# FIB 第 17 题

![[_Attachments/题目识别/WDOS-2027-FRQ/WDOS-2027-FRQ-C02-S03-Q017_题目.png|题目]]

三个进程 $P_1, P_2, P_3 互斥使用一个包含 $N(N>0) 个单元的缓冲区, $P_1 每次用 $produce() 生成一个正整数并用 $put() 送入缓冲区某一空单元, $P\_2 用 $getodd() 从该缓冲区中取出一个奇数并用 $countodd() 统计奇数个数; $P_3 每次用 $geteven() 从该缓冲区中取出一个偶数并用 $counteven() 统计偶数个数。请用信号量机制实现这三个进程的同步与互斥活动, 并说明所定义的信号量的含义（要求用伪代码描述）.

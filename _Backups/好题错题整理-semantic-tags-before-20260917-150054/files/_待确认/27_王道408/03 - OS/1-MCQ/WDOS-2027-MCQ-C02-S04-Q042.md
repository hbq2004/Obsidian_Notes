# MCQ 第 42 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C02-S04-Q042_题目.png|题目]]

下列关于死锁的叙述中,正确的是 ( ).
$I.$ 可以通过剥夺进程资源解除死锁
$II.$ 死锁的预防方法能确保系统不发生死锁
$III.$ 银行家算法可以判断系统是否处于死锁状态
$IV.$ 当系统出现死锁时,必然有两个或两个以上的进程处于阻塞态
(A) 仅 $II$、$III$
(B) 仅 $I$、$II$、$IV$
(C) 仅 $I$、$II$、$III$
(D) 仅 $I$、$III$、$IV$

## DeepSeek V4 Flash Max 解析
**答案**：  
答案： $\boxed{\text{B}}$ ，即仅 $I$ 、 $II$ 、 $IV$ 正确。

**解题切入点**：  
可以把死锁处理看成图论问题：

- 死锁对应“循环等待环”；
- 预防：在资源申请规则上直接禁止成环，所以能保证系统不发生死锁；
- 避免：银行家算法是在“状态空间”中做搜索，每次分配前检查是否存在安全序列，相当于可行性剪枝；
- 检测：对当前等待图判环；
- 解除：发现环后破坏环，即剥夺资源或终止进程。

于是四个命题分别对应：  
$I$ 是“解除”，$II$ 是“预防”，$III$ 把“避免”说成“检测”，$IV$ 是环上至少两个进程在等待。

**推演**：  
1. 对 $I$ ：解除死锁的常用手段包括资源剥夺、进程回退和终止进程。剥夺某个进程占有的资源并重新分配，可以打破循环等待，故 $I$ 正确。

2. 对 $II$ ：死锁预防通过破坏死锁四个必要条件之一来避免死锁，例如资源有序分配法破坏循环等待条件，一次性申请破坏请求与保持条件。只要策略正确执行，系统确实不会发生死锁，故 $II$ 正确。

3. 对 $III$ ：银行家算法是死锁避免算法，不是死锁检测算法。它在进程请求资源时检查分配后系统是否仍处于安全状态，安全才分配。但
$$\text{安全状态} \Rightarrow \text{不会发生死锁},\qquad \text{不安全状态} \not\Rightarrow \text{当前已死锁}.$$
所以银行家算法不能判断系统当前是否处于死锁状态，故 $III$ 错误。

4. 对 $IV$ ：死锁必然存在循环等待，循环等待环上至少有 $2$ 个进程，并且每个进程都在等待被其他进程占用的资源，因此都处于阻塞态，故 $IV$ 正确。

综上，正确的是 $I$ 、 $II$ 、 $IV$ ，选 $\boxed{\text{B}}$ 。

**易错点**：  
- 最容易错的是把银行家算法当成死锁检测算法。银行家算法是“避免死锁”，它只判断当前状态是否安全，不判断当前是否已经死锁。  
- 不要把“预防”和“解除”混淆：预防是事前保证，解除是事后破坏死锁环。  
- 不安全状态不等于死锁状态：银行家算法拒绝分配可能只是为了避免未来死锁。  
- 对 $IV$ 的“必然”不要犹豫：循环等待环至少包含两个进程，环上进程都在阻塞等待资源。

**命题规律**：  
408 常把死锁的四种处理方式放在一起考：预防、避免、检测、解除。  
高频错误项就是“银行家算法可以判断系统是否处于死锁状态”，本质上是在考“避免”和“检测”的边界。  
这类题可以类比为：银行家算法是在找“安全序列”，像状态搜索；死锁检测是“当前图判环”，像 DFS/BFS 判环。  
以后遇到死锁题，先判断命题属于哪一个阶段，再对照定义即可。

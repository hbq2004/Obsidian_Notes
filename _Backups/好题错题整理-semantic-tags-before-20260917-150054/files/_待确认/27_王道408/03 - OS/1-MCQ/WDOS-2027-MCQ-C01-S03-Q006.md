# MCQ 第 6 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C01-S03-Q006_题目.png|题目]]

在中中断发生后,进入中断处理的程序属于( ).
(A) 用户程序
(B) 可能是用户程序,也可能是 OS 程序
(C) 操作系统程序
(D) 单独的程序,既不是用户程序也不是 OS 程序

## DeepSeek V4 Flash Max 解析
**答案**：  
C  

**解题切入点**：  
中断发生后，$CPU$ 自动从中断向量表中取出中断处理程序的入口地址并执行，该程序由操作系统内核预先设置，专门用于管理中断事件，因此属于操作系统程序。  

**推演**：  
中断是硬件或软件产生的信号，$CPU$ 响应后保存当前进程状态，跳转到 $OS$ 维护的中断处理程序（$ISR$）。该程序处理中断事件后恢复进程，整个过程由操作系统内核控制，不涉及用户程序。类似算法竞赛中，程序遇到运行时错误时系统会调用库函数（如段错误处理），这些函数是系统内置的，而非选手编写。  

**易错点**：  
可能误选 B，认为中断处理可能调用用户自定义函数（如信号处理）。但“进入中断处理的程序”指的是硬件直接跳转的第一段代码，它必定是 $OS$ 内核程序。用户注册的处理函数属于后续调用，其本身仍是 $OS$ 框架的一部分。这好比竞赛中 $sort$ 函数，调用它的是用户代码，但 $sort$ 本身是系统库函数，不属于用户程序。  

**命题规律**：  
中断处理程序的归属是操作系统基本概念，常与系统调用、异常对比考查。理解中断机制是掌握内核的基础，类似算法竞赛中理解底层机制（如栈帧、异常处理）有助于调试与优化，属于高频基础考点。

# MCQ 第 7 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C01-S03-Q007_题目.png|题目]]

CPU的状态分为用户态和内核态,从用户态转换到内核态的唯一途径是 ( )
(A) 修改程序状态字指令
(B) 中断屏蔽
(C) 中断
(D) 中断处理程序

## DeepSeek V4 Flash Max 解析
**答案**：
$C$：中断。

**解题切入点**：
把 CPU 状态切换看作一个双状态状态机：

$$
\text{用户态} \xrightarrow{\text{中断/异常/陷入}} \text{内核态}
$$

用户态到内核态不是靠普通指令“赋值”完成的，而是靠 CPU 对中断事件的响应机制。算法竞赛里，状态转移必须沿着合法的边走，不能在当前状态直接篡改另一个状态的信息；这里唯一合法的转移边就是“中断”。

**推演**：

- $A$：修改程序状态字指令是特权指令，用户态根本无权执行。如果在用户态强行执行，会触发“非法指令”异常，而异常属于广义中断，真正完成切换的是这个异常中断，不是修改 PSW 的指令本身。所以 $A$ 错。

- $B$：中断屏蔽只是暂时屏蔽某些可屏蔽中断，相当于在状态图上“阻断某条边”，并没有发生状态转移，也不能让用户态进入内核态。所以 $B$ 错。

- $C$：正确。这里的中断是广义中断，包括外部中断、内部异常、故障、陷阱，以及系统调用通过 `int`/`syscall` 等指令触发的陷入。CPU 响应中断时，硬件会保存现场、设置模式位为内核态，并跳转到内核入口，从而完成用户态到内核态的切换。

- $D$：中断处理程序是进入内核态之后执行的处理例程，可以理解为状态转移完成后的“回调函数”，而不是状态转移的“边”。先有中断响应并完成切换，才会运行中断处理程序。所以 $D$ 错。

**易错点**：

- 不要把“中断处理程序”当成入口。进入内核态发生在中断响应的瞬间，中断处理程序只是后续动作。
- 不要选 $A$。修改 PSW 是特权指令，用户态不能执行；用户态执行特权指令会触发异常陷入内核，但这不是指令本身在“修改状态”。
- 注意“中断”取广义概念：外部中断、内部异常、系统调用陷阱都算。若只理解成外部硬件中断，就会误判。
- “中断屏蔽”不等于“中断”，它只是控制中断是否被响应，类似剪枝，不改变状态归属。

**命题规律**：
408 非常喜欢考“用户态到内核态的唯一途径”这一结论，常与特权指令、系统调用、中断处理流程结合命题。干扰项通常设置为“修改 PSW”“中断处理程序”“中断屏蔽”等，考查是否真正理解硬件响应与操作系统处理的边界。对算法竞赛选手来说，这就是一个状态机模型：$\text{用户态}$ 到 $\text{内核态}$ 只有一条转移边，边权是“中断”；一旦进入内核态，后续执行中断处理程序就相当于在新的状态里跑 DFS 的递归处理逻辑。

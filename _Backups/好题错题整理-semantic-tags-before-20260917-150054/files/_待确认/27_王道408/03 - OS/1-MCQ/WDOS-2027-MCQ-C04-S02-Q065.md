# MCQ 第 65 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C04-S02-Q065_题目.png|题目]]

$$65.【2020 统考真题】下列选项中,支持文件长度可变、随机访问的磁盘存储空间分配方式是 (\＿).$$

(A) 索引分配  
(B) 链接分配  
(C) 连续分配  
(D) 动态分区分配

## DeepSeek V4 Flash Max 解析
**答案**：  
$\boxed{A}$

**解题切入点**：  
本题要求区分磁盘存储空间分配方式对文件长度可变性与随机访问的支持能力。在算法竞赛中，可将连续分配视为定长数组（随机访问快但无法扩容），链接分配视为单向链表（可动态增删但需顺序寻址），索引分配视为指针数组（支持随机跳跃且可动态扩展）。动态分区分配是内存管理概念，与磁盘空间分配无关。

**推演**：  
- 连续分配：文件占用连续磁盘块，通过基址+偏移直接访问，支持随机访问；但扩展时需移动大量数据，无法支持文件长度可变。  
- 链接分配（隐式链接）：每个数据块包含指向下一块的指针，文件可动态增加块，支持长度可变；但访问第 $i$ 块需从头遍历 $i$ 次，不支持随机访问。  
- 索引分配：文件拥有一个索引块（或索引表），其中记录每个数据块的地址，可随机访问任意块；通过增加索引项可动态扩展文件，支持长度可变。  
- 动态分区分配：用于内存管理，不适用于磁盘存储空间分配，故排除。  

综上，仅索引分配同时满足两个条件，答案为 $\text{A}$。

**易错点**：  
1. 误认为链接分配（如 FAT 表）可随机访问——FAT 本质是索引结构的变体，但考题中“链接分配”通常指隐式链接，不支持随机访问。  
2. 混淆动态分区分配与磁盘分配——前者是内存分配方式，后者是文件系统概念。  
3. 忽略连续分配的长度不可变性——虽随机访问快，但文件无法动态增长。

**命题规律**：  
408 真题常以对比方式考查文件分配方式的核心特性（连续/链接/索引），重点区分“随机访问”与“顺序访问”、“固定长度”与“可变长度”的对应关系。类似问题可类比数据结构：连续 $\approx$ 数组、链接 $\approx$ 链表、索引 $\approx$ 指针数组，通过特性映射快速定位答案。

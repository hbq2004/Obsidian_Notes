# 综合题 第 2 题

![[_Attachments/题目识别/27_王道408-题目/DS-C08-86-F02_题目.png|题目]]

2. 设顺序表用数组 $A[\ ]$ 表示，表中元素存储在数组下标 $1 \sim m+n$ 的范围内，前 $m$ 个元素递增有序，后 $n$ 个元素递增有序，设计一个算法，使得整个顺序表有序.
1) 给出算法的基本设计思想.
2) 根据设计思想，采用 $C/C++$ 描述算法，关键之处给出注释.
3) 说明你所设计算法的时间复杂度与空间复杂度.

3. 设有一个数组中存放了一个无序的关键序列 $K_1,K_2, \cdots ,K_n$。现要求将 $K_n$ 放在将元素排序后的正确位置上，试编写实现该功能的算法，要求比较关键字的次数不超过 $n$.

## DeepSeek V4 Flash Max 解析

**答案**：第 2 题用二路归并把数组的两个有序段 \(A[1..m]\)、\(A[m+1..m+n]\) 合并到辅助数组再写回原数组，使整个表有序，时间复杂度 \(O(m+n)\)、空间复杂度 \(O(m+n)\)；第 3 题用快速排序一趟划分思想，以 \(K_n\) 为枢轴单趟扫描，比较 \(n-1\) 次后把 \(K_n\) 放到排序后的正确分界位置，时间复杂度 \(O(n)\)、空间复杂度 \(O(1)\)。

**解题切入点**：
- 第 2 题：看到“前 \(m\) 个有序，后 \(n\) 个有序，整个表无序”，应该立刻想到归并，而不是重新排序。这就像两条已经排好队的队伍合成一条队伍，每次只需比较两队队头。
- 第 3 题：看到“把最后一个关键字放到排序后的正确位置”，并且限制“比较次数不超过 \(n\)”，这是快速排序中的划分操作。可用单指针扫描，让每个元素只和枢轴比较一次。

**推演**：

**第 2 题（归并两个有序段）**

两个有序段为：

\[
A[1..m],\quad A[m+1..m+n]
\]

用指针 \(i\) 指向第一段，\(j\) 指向第二段，\(k\) 指向辅助数组 \(B\) 的写入位置。每次比较 \(A[i]\) 和 \(A[j]\)，把较小者写入 \(B[k]\)；某一段取完后，把另一段剩余部分直接写入 \(B\)。最后把 \(B[1..m+n]\) 复制回 \(A[1..m+n]\)。

关键代码：

```cpp
void MergeTwoRuns(int A[], int m, int n) {
    int total = m + n;
    int* B = new int[total + 1];   // B[0] 不用，下标从 1 开始

    int i = 1, j = m + 1, k = 1;

    // 两段都未取完时，取较小者
    while (i <= m && j <= total) {
        if (A[i] <= A[j])
            B[k++] = A[i++];
        else
            B[k++] = A[j++];
    }

    // 若第一段有剩余
    while (i <= m)
        B[k++] = A[i++];

    // 若第二段有剩余
    while (j <= total)
        B[k++] = A[j++];

    // 写回原数组
    for (int t = 1; t <= total; ++t)
        A[t] = B[t];

    delete[] B;
}
```

正确性：两个子段分别有序，归并时每次选出的都是当前两个表头中的较小者，所以写入 \(B\) 的元素始终保持有序；某一段剩余部分一定不小于已经写入的元素，直接续接仍有序。因此最终 \(A\) 全局有序。

复杂度：每个元素被写入 \(B\) 一次、复制回 \(A\) 一次，时间 \(O(m+n)\)；辅助数组长度为 \(m+n\)，空间 \(O(m+n)\)。

**第 3 题（一趟快排划分）**

令

\[
pivot = K_n
\]

用 \(i\) 记录“小于等于枢轴的元素”应放到的位置，用 \(j\) 扫描前 \(n-1\) 个元素。每当遇到 \(A[j] \le pivot\)，就把 \(A[j]\) 交换到位置 \(i\)，然后 \(i++\)。扫描结束后，交换 \(A[i]\) 与 \(A[n]\)，则 \(K_n\) 到达正确位置。

关键代码：

```cpp
int PlaceLastKey(int A[], int n) {
    int pivot = A[n];   // 保存 K_n
    int i = 1;          // 下一个存放 <=pivot 元素的位置

    for (int j = 1; j <= n - 1; ++j) {
        if (A[j] <= pivot) {      // 每个非枢轴元素只比较一次
            int tmp = A[i];
            A[i] = A[j];
            A[j] = tmp;
            ++i;
        }
    }

    // 把枢轴放到分界位置
    int tmp = A[i];
    A[i] = A[n];
    A[n] = tmp;

    return i;   // K_n 排序后的位置
}
```

扫描结束后有：

\[
A[1..i-1] \le pivot,\qquad A[i+1..n] > pivot
\]

所以 \(K_n\) 所在位置 \(i\) 就是排序后的正确位置。若允许相等元素，则相等元素被放在枢轴左侧，枢轴位于相等块的最后一个位置，这也是合法位置。

关键字比较次数：

\[
n-1 \le n
\]

满足题目要求。

**易错点**：
1. 第 2 题容易误写成对整个数组直接排序，忽略两段已经有序，应当先用归并思想。
2. 第 2 题归并后容易忘记把辅助数组复制回原数组 \(A\)，导致原表没有更新。
3. 第 2 题下标容易写错，注意第一段是 \(1..m\)，第二段是 \(m+1..m+n\)，C/C++ 中数组实际要分配 \(m+n+1\) 个元素，下标 0 不用。
4. 第 3 题容易忘记最后交换 \(A[i]\) 与 \(A[n]\)，导致枢轴没有放到正确位置。
5. 第 3 题循环应只扫描前 \(n-1\) 个元素，不要把枢轴 \(K_n\) 自己也拿来进行关键字比较。
6. 第 3 题注意枢轴值要先保存为 `pivot`，不能在循环中反复用可能被交换掉的 \(A[n]\) 作为比较基准。

**命题规律**：
这两题分别对应 408 中“线性表的归并”和“快速排序的划分”两个高频考点。常见变式有：两个有序数组合并后求中位数、求第 \(k\) 小元素、给出一趟划分后的序列、计算快速排序比较次数和交换次数、把枢轴从最后一个元素改为第一个元素等。复习时应熟练掌握双指针归并和快速排序划分模板，注意边界条件、重复关键字的处理，并会分析时间复杂度和空间复杂度。

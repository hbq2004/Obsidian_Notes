## DeepSeek V4 Flash Max 解析

**答案**：把长度为 $n$ 的数据序列看成完全二叉树的顺序存储，只需检查所有“父结点-孩子”关系：若存在某个父结点大于其孩子结点，则不是小根堆；否则是。时间复杂度 $O(n)$，空间复杂度 $O(1)$。

**解题切入点**：

拿到“判断是否为堆”的题目，第一步要想到：堆不是普通线性有序表，而是“完全二叉树 + 堆序性”的数组存储。因此不要对序列排序，而要把数组下标映射为完全二叉树的父子关系。

可以类比：判断一棵二叉树是否为二叉搜索树，需要按中序遍历检查有序性；而判断堆只需要按数组下标检查局部父子边，因为堆序性是“局部传递”的。所以一次线性扫描即可完成。

**推演**：

设序列存放在数组 $A[1..n]$ 中，采用堆的标准顺序存储：

- 结点 $i$ 的左孩子是 $2i$；
- 结点 $i$ 的右孩子是 $2i+1$；
- 结点 $i$ 的父结点是 $\lfloor i/2 \rfloor$。

小根堆要求每个结点都不大于其孩子结点，即

$$
A[i] \le A[2i], \qquad A[i] \le A[2i+1]
$$

其中右孩子存在的前提是 $2i+1 \le n$。

由于下标大于 $\lfloor n/2 \rfloor$ 的结点都是叶子结点，所以只需要检查前 $\lfloor n/2 \rfloor$ 个分支结点。

核心算法如下：

```c
// A[1..n] 存放待判断序列，n 为序列长度
bool IsMinHeap(int A[], int n) {
    if (n <= 1) return true;             // 空序列或单元素序列都视为小根堆

    for (int i = 1; i <= n / 2; i++) {   // i = 1..floor(n/2)
        if (A[i] > A[2 * i])             // 左孩子一定存在
            return false;

        if (2 * i + 1 <= n && A[i] > A[2 * i + 1])
            return false;                 // 右孩子存在时才比较
    }

    return true;
}
```

等价写法：从第 2 个元素开始，让每个孩子都和自己的父结点比较，只要某个孩子小于父结点就返回 false：

```c
bool IsMinHeap(int A[], int n) {
    for (int i = 2; i <= n; i++)
        if (A[i] < A[i / 2])
            return false;
    return true;
}
```

如果 C 数组从 0 开始，则 parent 为 $(i-1)/2$，判断条件为：

```c
if (A[i] < A[(i - 1) / 2]) return false;
```

正确性：

- 若算法返回 false，说明存在某条父子边满足 $A[\text{parent}] > A[\text{child}]$，与“小根堆”定义矛盾，因此原序列不是小根堆。
- 若算法返回 true，说明所有父子边都满足父结点不大于孩子结点。沿任意祖先到后代的路径，值都非递减，因此任意祖先都不大于后代，满足小根堆定义。

**易错点**：

1. **下标对应错误**。1 基下标下，左孩子是 $2i$，右孩子是 $2i+1$；0 基下标下，左孩子是 $2i+1$，右孩子是 $2i+2$。不要把两者混用。

2. **漏掉右孩子存在性判断**。只检查左孩子，或者不判断 $2i+1 \le n$ 就访问右孩子，可能造成数组越界。

3. **比较符号写反**。小根堆要求父结点 $\le$ 孩子；判断失败条件是“父结点大于孩子”，即 `A[i] > A[2*i]`。

4. **只检查根结点是否最小**。根结点最小只是必要不充分条件，堆的每个子树都必须满足堆序性，所以要检查所有父子边。

5. **误以为堆是有序序列**。堆只是层序存储的完全二叉树，不是升序序列；不能用“是否有序”来判断。

**命题规律**：

本题属于“堆”的基础考点，核心是堆的顺序存储和堆序性。408 中常见命题形式有：

- 给一个序列，判断是否能构成大根堆/小根堆；
- 给定数组，画出对应的完全二叉树；
- 堆排序中的初始建堆过程；
- 堆的插入、删除后的调整过程；
- 判断完全二叉树是否为堆的算法设计。

复习建议：熟练掌握从数组下标到二叉树父子关系的映射，理解“自底向上建堆”的 $O(n)$ 过程，并会写堆排序、优先队列的调整代码。算法题中尤其注意下标从 0 还是从 1 开始，避免边界错误。

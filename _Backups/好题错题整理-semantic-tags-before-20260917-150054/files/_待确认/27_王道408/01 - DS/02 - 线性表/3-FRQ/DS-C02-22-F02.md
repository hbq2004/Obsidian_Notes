## DeepSeek V4 Flash Max 解析

**答案**：顺序表是线性表的顺序存储表示，用一组地址连续的存储单元依次存放数据元素，逻辑相邻与物理相邻一致，因此支持 $O(1)$ 随机存取；但插入/删除需要移动大量元素，平均移动次数分别为 $n/2$ 和 $(n-1)/2$，时间复杂度均为 $O(n)$。

**解题切入点**：拿到题目先判断存储结构是否“连续存储、数组实现、可按下标随机访问”；若是，就定位到顺序表。做题时可以类比“手牌是排好序的一排卡片”：按编号取牌是 $O(1)$，但往中间插牌或抽牌需要把后面的牌整体移动。因此遇到顺序表算法题，优先思考“能否从后往前移动”“能否用双指针原地覆盖”“能否利用有序性二分查找”。

**推演**：

设线性表为 $L=(a_1,a_2,\dots,a_n)$，顺序表用一段连续存储单元保存这 $n$ 个元素。

1. 地址计算公式

若每个元素占 $l$ 个存储单元，且从 0 开始编号，则第 $i$ 个元素的存储地址为：

$$
Loc(a_i)=Loc(a_0)+i\times l,\qquad 0\le i<n
$$

若从 1 开始编号，则：

$$
Loc(a_i)=Loc(a_1)+(i-1)\times l,\qquad 1\le i\le n
$$

因此按位查找任意元素只需计算地址，时间复杂度为 $O(1)$，这是顺序表最重要的特性：随机存取。

2. 顺序表的存储结构

静态分配：

```cpp
#define MaxSize 50
typedef struct {
    ElemType data[MaxSize];
    int length;
} SqList;
```

动态分配：

```cpp
typedef struct {
    ElemType *data;
    int maxSize, length;
} SeqList;
```

注意区分 `maxSize` 是容量，`length` 是当前表长。

3. 插入操作

在位置 $i$ 插入元素 $e$，合法位置为 $1\le i\le n+1$。需要将 $a_i,\dots,a_n$ 从后往前依次后移一位。

移动次数为：

$$
n-i+1
$$

若在 $n+1$ 个可能位置等概率插入，则平均移动次数为：

$$
E_{\text{ins}}=\frac{1}{n+1}\sum_{i=1}^{n+1}(n-i+1)
=\frac{1}{n+1}\cdot \frac{n(n+1)}{2}
=\frac{n}{2}
$$

所以插入操作的时间复杂度为 $O(n)$。

核心代码思路：

```cpp
bool ListInsert(SqList &L, int i, ElemType e) {
    if (i < 1 || i > L.length + 1) return false;
    if (L.length >= MaxSize) return false;
    for (int j = L.length; j >= i; --j)
        L.data[j] = L.data[j - 1];
    L.data[i - 1] = e;
    ++L.length;
    return true;
}
```

4. 删除操作

删除位置 $i$ 的元素，合法位置为 $1\le i\le n$。需要将 $a_{i+1},\dots,a_n$ 从前往后依次前移一位。

移动次数为：

$$
n-i
$$

若在 $n$ 个位置等概率删除，则平均移动次数为：

$$
E_{\text{del}}=\frac{1}{n}\sum_{i=1}^{n}(n-i)
=\frac{1}{n}\cdot \frac{n(n-1)}{2}
=\frac{n-1}{2}
$$

所以删除操作的时间复杂度也是 $O(n)$。

核心代码思路：

```cpp
bool ListDelete(SqList &L, int i, ElemType &e) {
    if (i < 1 || i > L.length) return false;
    e = L.data[i - 1];
    for (int j = i; j < L.length; ++j)
        L.data[j - 1] = L.data[j];
    --L.length;
    return true;
}
```

5. 按值查找

顺序表按值查找通常需要从第一个元素开始逐个比较。若元素等概率出现，则平均比较次数为：

$$
E_{\text{locate}}=\frac{1}{n}\sum_{i=1}^{n}i=\frac{n+1}{2}
$$

最坏情况需比较 $n$ 次，时间复杂度为 $O(n)$；若顺序表有序，则可使用二分查找，时间复杂度为 $O(\log n)$。

6. 典型综合算法：顺序表原地逆置

```cpp
void Reverse(SqList &L) {
    for (int i = 0, j = L.length - 1; i < j; ++i, --j) {
        ElemType tmp = L.data[i];
        L.data[i] = L.data[j];
        L.data[j] = tmp;
    }
}
```

时间 $O(n)$，空间 $O(1)$。

**易错点**：

- 混淆位序和数组下标：表中第 $i$ 个元素存储在 `data[i-1]`。
- 插入合法区间是 $1\le i\le n+1$，删除合法区间是 $1\le i\le n$，不能写成 `i < length`。
- 插入时必须从后往前移动，删除时必须从前往后移动，否则会覆盖未处理的元素。
- 平均移动次数容易记混：插入平均移动 $n/2$，删除平均移动 $(n-1)/2$。
- 不要把容量 `maxSize` 和表长 `length` 混用，插入前要判满，删除后要更新表长。
- 若只要求在表尾插入或删除，时间复杂度为 $O(1)$，但一般情况仍按 $O(n)$ 分析。

**命题规律**：该考点在 408 中主要考查顺序表的随机存取特性、地址计算、插入/删除的平均移动次数以及时间复杂度。综合题常见变式有：顺序表逆置、删除所有值为 $x$ 的元素、有序顺序表去重、合并两个有序顺序表、循环左移/右移、查找并交换后继元素等。复习时应熟练掌握“双指针”“从后往前移动”“覆盖法”等算法技巧，并严格分析时间复杂度和空间复杂度。

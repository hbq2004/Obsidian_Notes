# 综合题 第 14 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-23-F14_题目.png|题目]]

14. 设将 $n(n>1)$ 个整数存放到不带头结点的单链表 $L$ 中，设计算法将 $L$ 中保存的序列循环右移 $k(0<k<n)$ 个位置。例如，若 $k=1$，则将链表 $\{0,1,2,3\}$ 变为 $\{3,0,1,2\}$。要求：
1) 给出算法的基本设计思想.
2) 根据设计思想，采用 $C$ 或 $C++$ 语言描述算法，关键之处给出注释.
3) 说明你所设计算法的时间复杂度和空间复杂度.

## DeepSeek V4 Flash Max 解析

**答案**：  
将原链表“首尾相接成环”，在正数第 \(n-k\) 个结点处断开，令其后继成为新头、该结点本身成为新尾，即可完成循环右移 \(k\) 位；时间复杂度为 \(O(n)\)，空间复杂度为 \(O(1)\)。

**解题切入点**：  
单链表无法随机访问，拿到题首先要想到“必须找到断点”。循环右移 \(k\) 位，等价于把原序列分成前 \(n-k\) 个元素和后 \(k\) 个元素两段，然后交换两段顺序。因此关键是找到原链表第 \(n-k\) 个结点，作为新尾结点；其下一个结点就是新头结点。  
可以把链表想象成一列火车：先把尾车和头车接成环，再在合适位置解开，就完成了整体平移。

**推演**：  
设原链表序列为  
\[
a_1,a_2,\dots,a_n
\]
循环右移 \(k\) 位后变为  
\[
a_{n-k+1},a_{n-k+2},\dots,a_n,a_1,a_2,\dots,a_{n-k}.
\]

所以：

- 原第 \(n-k\) 个结点 \(a_{n-k}\) 成为新尾结点；
- 原第 \(n-k+1\) 个结点 \(a_{n-k+1}\) 成为新头结点。

算法步骤：

1. 遍历链表一次，求出表长 \(n\)，并记录尾结点 \(p\)；
2. 令 \(k = k \bmod n\)，若 \(k=0\) 则无需移动；
3. 从头结点出发，找到第 \(n-k\) 个结点 \(q\)；
4. 令尾结点 \(p\) 指向原头结点，形成环；
5. 令头指针指向 \(q\) 的下一个结点，即新头结点；
6. 令 \(q\) 的 next 为 `NULL`，断开环。

C++ 代码描述如下：

```cpp
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;

void CircularRightShift(LinkList &L, int k) {
    if (L == NULL || k <= 0) return;

    // 1. 求表长 n，并让 p 指向尾结点
    LNode *p = L;
    int n = 1;
    while (p->next != NULL) {
        p = p->next;
        n++;
    }

    // 2. 右移 n 位等于不变，取模处理 k
    k %= n;
    if (k == 0) return;

    // 3. q 定位到原第 n-k 个结点，即新尾结点
    LNode *q = L;
    for (int i = 1; i < n - k; i++) {
        q = q->next;
    }

    // 4. 旋转：尾结点接原头结点，再断开 q 的 next
    LNode *oldHead = L;
    LNode *newHead = q->next;

    p->next = oldHead;  // 原尾结点指向原头结点，形成环
    L = newHead;        // 新头结点
    q->next = NULL;     // 断开，q 成为新尾结点
}
```

若用纯 C 语言，可把 `LinkList &L` 改成 `LinkList *L`，函数内相应将 `L` 替换为 `*L`。

复杂度分析：

- 时间复杂度：第一次遍历求表长为 \(O(n)\)；第二次定位 \(q\) 最多走 \(O(n)\) 步，所以总时间复杂度为  
  \[
  O(n)
  \]
- 空间复杂度：只用了常数个辅助指针，因此为  
  \[
  O(1)
  \]

**易错点**：  

1. **断点位置找错**：应找第 \(n-k\) 个结点，而不是第 \(n-k+1\) 个结点。  
2. **移动步数算错**：从头结点到第 \(n-k\) 个结点，需要移动 \(n-k-1\) 步；若写成 `for (int i = 0; i < n - k; i++)` 会多走一步。  
3. **忘记断开链表**：若最后没有令 `q->next = NULL`，链表仍然成环，遍历时会死循环。  
4. **没有处理 \(k \ge n\)**：虽然题目保证 \(0<k<n\)，但更稳妥的做法是先 `k %= n`，若 `k == 0` 直接返回。  
5. **忽略不带头结点**：`L` 直接指向第一个数据结点，新头必须赋回 `L`；如果使用 C 语言，需要传入二级指针或使用引用。

**命题规律**：  
本题是“线性表”中单链表指针修改的典型综合应用题，408 中常以算法设计题形式出现。核心考点是链表的遍历、定位、断链与重接。常见变式有：循环左移 \(k\) 位、找倒数第 \(k\) 个结点、删除倒数第 \(k\) 个结点、将链表拆成两段后重新拼接等。复习时应熟练掌握“先求长度、再定位断点、最后改链”的通用方法，并养成画指针图检查边界条件的习惯。这类题目通常要求时间 \(O(n)\)、空间 \(O(1)\)。

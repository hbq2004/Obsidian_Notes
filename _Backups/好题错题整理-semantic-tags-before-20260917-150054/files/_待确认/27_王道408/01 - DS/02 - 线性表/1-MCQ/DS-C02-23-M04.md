# 选择题 第 4 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-23-M04_题目.png|题目]]

4. 下列关于线性表的说法中，正确的是( )。  

I. 顺序存储方式只能用于存储线性结构  

II. 在一个设有头指针和尾指针的单链表中，删除表尾元素的时间复杂度与表长无关  

III. 带头结点的循环单链表中不存在空指针  

IV. 在一个长度为\( n \)的有序单链表中插入一个新结点并仍保持有序的时间复杂度为\( O(n) \)  

V. 若用单链表来表示队列，则应该选用带尾指针的循环链表  


A. \( I、II \)  
B. \( I、III、IV、V \)  
C. \( IV、V \)  
D. \( III、IV、V \)

## DeepSeek V4 Flash Max 解析

**答案**：正确选项为 **D（III、IV、V）**。I、II 说法错误，III、IV、V 说法正确。

**解题切入点**：这是多个独立小判断组合的选择题，应先逐条判断，再用选项排除。核心抓手有两个：单链表删除/插入能否做到 \(O(1)\)，取决于能否直接获得前驱或插入位置；队列必须支持一端入队、另一端出队，因此要考虑两端操作的效率。

**推演**：

1. **I 错**：顺序存储方式并不是只能存储线性结构。  
   完全二叉树可以用数组顺序存储，图的邻接矩阵也可以看作顺序存储方式。顺序存储是一种物理存储手段，与“逻辑结构是否为线性”无关。

2. **II 错**：单链表中删除尾结点必须找到尾结点的前驱。  
   即使设有头指针和尾指针，由于单链表结点没有前驱指针，仍要从头开始遍历：
   ```c
   p = head;
   while (p->next != tail)
       p = p->next;
   p->next = NULL;
   free(tail);
   tail = p;
   ```
   遍历时间为 \(O(n)\)，与表长有关。只有双向链表或保存了直接前驱才能做到 \(O(1)\)。

3. **III 对**：带头结点的循环单链表中不存在空指针。  
   空表时：
   \[
   L->next = L
   \]
   非空时，最后一个结点的指针域也指向头结点 \(L\)，所以所有结点的 `next` 指针都不为空。

4. **IV 对**：在一个长度为 \(n\) 的有序单链表中插入新结点，需要先找到插入位置。  
   例如递增有序单链表插入 \(x\)：
   ```c
   p = L;
   while (p->next && p->next->data < x)
       p = p->next;
   s->next = p->next;
   p->next = s;
   ```
   查找插入位置最坏要扫描全部 \(n\) 个结点，因此时间复杂度为：
   \[
   O(n)
   \]

5. **V 对**：队列要求一端入队、一端出队。带尾指针的循环单链表可以通过尾指针直接找到队尾，也可以通过尾指针的 `next` 域在 \(O(1)\) 内找到队头，因此入队和出队都能做到 \(O(1)\)，适合用来表示队列。

因此，正确说法为 III、IV、V，选 **D**。

**易错点**：

- 不要认为有尾指针就能 \(O(1)\) 删除单链表的尾结点，单链表删除的关键是找前驱。
- 不要混淆循环链表和非循环链表：带头结点的循环单链表空表时 `head->next == head`，不是 `NULL`。
- 有序单链表插入虽然指针修改是 \(O(1)\)，但查找位置是 \(O(n)\)，且不能折半查找，因为链表不支持随机访问。
- V 本质是考查“队列两端操作效率”，带尾指针的循环单链表是一种高效链式队列实现。

**命题规律**：本题属于线性表基础概念综合判断题，常见于 408 选择题。考查点包括：顺序存储与链式存储的区别、单链表操作时间复杂度、循环链表特征、链式队列设计。复习时应重点理解“前驱关系”对链表操作复杂度的影响，并熟记常见特例：带头结点循环链表、带尾指针循环链表、有序链表插入等。变式可能考查双向链表删除尾结点、循环队列判空判满等。

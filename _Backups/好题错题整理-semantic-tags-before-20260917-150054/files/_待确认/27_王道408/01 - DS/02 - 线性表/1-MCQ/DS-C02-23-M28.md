# 选择题 第 28 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-23-M28_题目.png|题目]]

28. 有两个长度都为 $n$ 的双链表, 若以 $h_1$ 为头指针的双链表是非循环的, 以 $h_2$ 为头指针的双链表是循环的, 则下列叙述中正确的是 ( ).

(A) 对于双链表 $h_1$, 删除首结点的时间复杂度是 $O(n)$
(B) 对于双链表 $h_2$, 删除首结点的时间复杂度是 $O(n)$
(C) 对于双链表 $h_1$, 删除尾结点的时间复杂度是 $O(1)$
(D) 对于双链表 $h_2$, 删除尾结点的时间复杂度是 $O(1)$

## DeepSeek V4 Flash Max 解析

**答案**：选 **D**。以 \(h_2\) 为头指针的循环双链表可以通过 \(h_2\to prior\) 直接找到尾结点，因此删除尾结点的时间复杂度为 \(O(1)\)；而以 \(h_1\) 为头指针的非循环双链表删除尾结点需要先遍历到尾结点，时间复杂度为 \(O(n)\)。

**解题切入点**：拿到本题先抓住考点：**双链表在已知头指针的情况下，删除首/尾结点的时间复杂度**。关键不是“双链表删除一定快”，而是看目标结点能否由已知指针在常数步内到达。可以这样类比：循环双链表像环形跑道，头结点处“向前一步”是首结点，“向后一步”是尾结点；非循环双链表像一条只知道入口的胡同，要走到队尾必须从头走到尾。

**推演**：设双链表结点结构为：

```c
typedef struct DNode {
    struct DNode *prior, *next;
    ElemType data;
} DNode, *DLinkList;
```

默认链表长度 \(n\ge 1\)，下面以带头结点的情况为例分析；不带头结点时，只需注意同时修改头指针，复杂度结论不变。

### 1. 对非循环双链表 \(h_1\)

删除首结点：

```c
p = h1->next;              // p 指向首结点
h1->next = p->next;        // 头结点跨过 p
if (p->next != NULL)
    p->next->prior = h1;
free(p);
```

只进行常数次指针修改，不随 \(n\) 变化，所以删除首结点的时间复杂度为：

$$
O(1)
$$

故 **A 错**。

删除尾结点：

```c
p = h1;
while (p->next != NULL)
    p = p->next;           // 一直走到尾结点
p->prior->next = NULL;
free(p);
```

非循环双链表没有从 \(h_1\) 直接到达尾结点的指针，必须从头遍历到尾结点，最坏情况下要走 \(n\) 步，所以删除尾结点的时间复杂度为：

$$
O(n)
$$

故 **C 错**。

### 2. 对循环双链表 \(h_2\)

循环双链表中，头结点 \(h_2\) 的 \(next\) 指向首结点，\(prior\) 指向尾结点。

删除首结点：

```c
p = h2->next;              // p 指向首结点
h2->next = p->next;
p->next->prior = h2;
free(p);
```

常数次操作，时间复杂度为：

$$
O(1)
$$

故 **B 错**。

删除尾结点：

```c
p = h2->prior;             // p 直接指向尾结点
p->prior->next = h2;       // 倒数第二个结点指向头结点
h2->prior = p->prior;      // 头结点的 prior 指向倒数第二个结点
free(p);
```

不需要遍历，常数次操作，时间复杂度为：

$$
O(1)
$$

故 **D 正确**。

因此复杂度汇总为：

| 链表类型 | 删除首结点 | 删除尾结点 |
|---|---|---|
| \(h_1\) 非循环双链表 | \(O(1)\) | \(O(n)\) |
| \(h_2\) 循环双链表 | \(O(1)\) | \(O(1)\) |

**易错点**：

1. **误以为双链表删除尾结点总是 \(O(1)\)**：双链表确实可以通过尾结点的 \(prior\) 找到前驱，但非循环双链表只给头指针时，首先要遍历到尾结点，遍历本身是 \(O(n)\)。除非题目额外给出尾指针，才能做到 \(O(1)\)。
2. **把循环双链表和循环单链表混淆**：循环单链表只有 \(next\) 指针，删除尾结点仍需找前驱；但循环双链表有 \(prior\)，\(h_2\to prior\) 就是尾结点，所以可以 \(O(1)\)。
3. **忽略头结点的存在**：带头结点时，删除首结点通过 \(h_1\to next\) 可直接完成；不带头结点时，删除首结点后要更新头指针，但仍然是常数时间，不是 \(O(n)\)。
4. **边界情况处理**：长度为 1 时，删除首结点和删除尾结点实际是同一个结点，需要注意把头指针或头结点的 \(next\)、\(prior\) 置空或指向自身，但复杂度仍为 \(O(1)\)。

**命题规律**：本题属于 408 常考的“链表操作时间复杂度辨析”考点。常见变式有：单链表、循环单链表、双链表、循环双链表在带头结点/不带头结点、有尾指针/无尾指针情况下，删除首尾结点的时间复杂度；或者给定某个结点的指针，判断能否在该结点前插入或删除该结点。复习时建议自己画一张链表操作复杂度表，并熟练画出指针修改过程，不要死记结论，重点看“目标结点能否由已知指针常数步到达”。

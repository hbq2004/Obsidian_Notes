# 选择题 第 24 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-23-M24_题目.png|题目]]

24. 设对 $n(n>1)$ 个元素的线性表的运算只有 4 种: 删除第一个元素; 删除最后一个元素; 在第一个元素之前插入新元素; 在最后一个元素之后插入新元素, 则最好使用 ( )。
(A) 只有尾结点指针没有头结点指针的循环单链表
(B) 只有尾结点指针没有头结点指针的非循环双链表
(C) 只有头结点指针没有尾结点指针的循环双链表
(D) 既有头结点指针又有尾结点指针的循环单链表

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C02-23-M24_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：最好使用只有头结点指针没有尾结点指针的循环双链表（选项C），因为在这种结构下，所有四种操作（删除第一个元素、删除最后一个元素、在第一个元素之前插入、在最后一个元素之后插入）均可在 O(1) 时间内完成。

**解题切入点**：本题考察线性表两端操作的时间复杂度，核心在于如何快速访问头结点和尾结点，以及能否在 O(1) 内找到前驱。对于只在两端操作的线性表，循环双链表只需头指针即可通过头结点的 prev 直接获得尾结点，从而支持两端插入和删除；而单链表（即使有尾指针）删除最后一个元素时需遍历找到前驱，非循环双链表缺少头指针则无法快速访问头结点。因此，定位考点为“不同链表结构下两端操作的时间效率”。

**推演**：

- 记四种操作：① 删除第一个元素；② 删除最后一个元素；③ 在第一个元素之前插入；④ 在最后一个元素之后插入。
- 分析各选项：
  - **A**：只有尾指针的循环单链表。通过尾指针可 O(1) 访问头结点，支持①、③、④；但删除最后一个元素（②）时，需要找到尾结点的前驱，循环单链表无法直接获取前驱，必须遍历整个链表，时间复杂度 O(n)。
  - **B**：只有尾指针的非循环双链表。双链表可通过 prev 获取前驱，故②、④可 O(1) 完成；但缺少头指针，执行①、③时需从头遍历到尾才能找到头结点，时间复杂度 O(n)。
  - **C**：只有头指针的循环双链表。头指针可直接访问头结点，且通过头结点的 prev 可 O(1) 获得尾结点。
    - 删除第一个元素：通过头指针找到头结点，将其 next 设为新头，更新头指针，并调整尾结点（头->prev）的 next 指向新头，O(1)。
    - 删除最后一个元素：通过头->prev 找到尾结点，再通过尾->prev 找到其前驱，更新前驱的 next 指向头，并更新头->prev 为前驱，O(1)。
    - 插入在第一个元素之前：新结点插入到头结点之前，成为新头，调整相关指针（新头 prev 指向尾，新头 next 指向原头，原头 prev 指向新头，尾 next 指向新头），O(1)。
    - 插入在最后一个元素之后：通过头->prev 找到尾结点，在其后插入新结点，调整指针（尾 next 指向新结点，新结点 prev 指向尾，新结点 next 指向头，头 prev 指向新结点），O(1)。
    故所有操作均 O(1)。
  - **D**：既有头指针又有尾指针的循环单链表。头尾指针可支持①、③、④ O(1)；但②仍需遍历找到尾结点的前驱，时间复杂度 O(n)。
- 综上，只有选项 C 满足全部操作 O(1) 的要求，且无需额外空间。

**易错点**：
1. 误认为单链表有尾指针即可 O(1) 删除尾结点，忽略单链表无法直接获取前驱，必须遍历。
2. 忽略非循环双链表缺少头指针时无法快速定位头结点，导致头部操作 O(n)。
3. 混淆循环双链表与循环单链表的区别，未意识到双链表可通过 prev 快速访问前驱，而循环特性又使头尾互访 O(1)。
4. 未注意题目条件 n>1，忽略空表或单结点时的边界处理，但头尾指针操作在 n>1 时均可安全实行。

**命题规律**：本题是线性表结构选择的经典题型，常以选择题出现，考查不同链表结构对两端插入/删除操作的时间复杂度影响。常见变式包括：增加操作种类（如按值查找、指定位置插入等），或改变链表形态（如带哨兵结点、双向循环链表等）。复习时应重点掌握链表的基本操作（插入、删除、查找）在不同结构下的实现细节和时间复杂度，并善于通过画图分析指针变化。建议结合真题练习，形成对“两端操作优先考虑循环双链表”的快速反应。

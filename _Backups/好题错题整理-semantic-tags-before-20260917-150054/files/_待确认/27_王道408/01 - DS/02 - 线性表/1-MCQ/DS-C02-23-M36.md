# 选择题 第 36 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-23-M36_题目.png|题目]]

36.【2024统考真题】 已知带头结点的非空单链表 $L$ 的头指针为 $h$，结点结构为 $data$、$next$。其中 $next$ 是指向直接后继结点的指针。现有指针 $p$ 和 $q$，若 $p$ 指向 $L$ 中非首且非尾的任意一个结点，则执行语句序列“$q = p \rightarrow next; p \rightarrow next = q \rightarrow next; q \rightarrow next = h \rightarrow next; h \rightarrow next = q;$”的结果是 (  )
A. 在 $p$ 所指结点后插入 $q$ 所指结点
B. 在 $q$ 所指结点后插入 $p$ 所指结点
C. 将 $p$ 所指结点移至 $L$ 的头结点之后
D. 将 $q$ 所指结点移动到 $L$ 的头结点之后

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C02-23-M36_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 D。该语句序列先把 \(p\) 的直接后继 \(q\) 从原链表中摘下，再采用“头插法”把它插入到头结点 \(h\) 之后，因此结果是“将 \(q\) 所指结点移动到 \(L\) 的头结点之后”。

**解题切入点**：
拿到题先画出带头结点的单链表，并明确：\(p\) 是中间某个数据结点，\(q=p\to\mathit{next}\) 是 \(p\) 的直接后继。链表指针操作题的通用思路是“先保存、再摘链、后接入”：先用 `q` 保存后继，再让 `p` 跨过 `q`，最后把 `q` 接到新位置。这类似排队时把队伍中间某个人直接拉到队首。

**推演**：
设链表有 \(n\) 个数据结点，首元结点为 \(a_1\)，且 \(p=a_k\ (2\le k\le n-1)\)，则原链表可写为
\[
h\to a_1\to\cdots\to p(a_k)\to q(a_{k+1})\to a_{k+2}\to\cdots\to a_n.
\]
其中 \(a_1\to\cdots\to p\) 表示从首元结点到 \(p\) 的原链表段；若 \(k=n-1\)，则 \(a_{k+2}\) 不存在。

逐句执行：

1. `q = p->next;`  
   \(q\) 指向 \(a_{k+1}\)，即 \(p\) 的后继。

2. `p->next = q->next;`  
   把 \(q\) 从主链上摘下，使 \(p\) 直接指向 \(q\) 的原后继 \(a_{k+2}\)（若 \(q\) 是原表尾，则 \(p\to\mathit{next}=\mathrm{NULL}\)）。此时链表变为
   \[
   h\to a_1\to\cdots\to p(a_k)\to a_{k+2}\to\cdots\to a_n,
   \]
   \(q\) 已脱离主链。

3. `q->next = h->next;`  
   此时 \(h\to\mathit{next}\) 仍指向原首元 \(a_1\)，所以令 \(q\to a_1\)。

4. `h->next = q;`  
   头结点指向 \(q\)。最终链表为
   \[
   h\to q(a_{k+1})\to a_1\to\cdots\to p(a_k)\to a_{k+2}\to\cdots\to a_n.
   \]

可见只有 \(q\) 被移动到了 \(h\) 之后，成为新的首元结点；\(p\) 结点本身没有被移动。选项 A 错在把 \(q\) 误认为仍插在 \(p\) 后；选项 B 方向反了；选项 C 把移动对象错看成 \(p\)。

**易错点**：
- 把 `q = p->next` 与“在 p 后插入 q”混为一谈；实际上第 2 句先摘除了 \(q\)，后两句是头插。
- 第 3、4 句顺序不能颠倒。必须先执行 `q->next = h->next`，再执行 `h->next = q`；否则若先让 `h->next = q`，再令 `q->next = h->next`，会造成 \(q\) 指向自身，形成环。
- 要区分头结点和首元结点：`h->next` 是第一个数据结点，不是头结点本身；因此“头结点之后”就是让 \(q\) 成为第一个数据结点。
- 若 \(q\) 原本是尾结点，第 2 句会使 `p->next` 变为 `NULL`，这是正常的摘链操作；后续 `q->next = h->next` 会把 \(q\) 重新接入链表，不会访问空指针。

**命题规律**：
本题是 2024 年统考真题，考点为单链表的“摘链 + 头插”指针操作。常见变式包括：删除 \(p\) 的后继、把 \(p\) 的后继插入某结点之后、两两交换相邻结点、原地逆置单链表等；也可能要求写出对应算法或判断操作后是否断链、成环。复习时应在纸上多画链表图，并熟练记忆 `t = p->next; p->next = t->next; t->next = ...; ... = t;` 这套指针操作范式。

# 选择题 第 3 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-21-M03_题目.png|题目]]

3.在线性表中，除开始元素外，每个元素 ( )。
(A) 只有唯一的前驱元素
(B) 只有唯一的后继元素
(C) 有多个前驱元素
(D) 有多个后继元素

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C02-21-M03_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 **(A) 只有唯一的前驱元素**——在线性表中，除开始元素外，每个元素有且仅有一个直接前驱。

**解题切入点**：  
拿到题目先锁定“线性表”的逻辑结构定义。线性表是 $n$ 个数据元素的有限序列，其核心特征是“一对一”的邻接关系：除第一个元素外，每个元素有且仅有一个直接前驱；除最后一个元素外，每个元素有且仅有一个直接后继。题目明确说“除开始元素外”，所以直接定位到“前驱”性质，秒选 A。

**推演**：  
线性表可表示为：
$$
(a_1, a_2, \cdots, a_n)
$$
其中 $a_i$ 是第 $i$ 个元素。在线性表中：
- 开始元素 $a_1$ **没有前驱**；
- 除 $a_1$ 外的任一元素 $a_i (2 \le i \le n)$ 有且仅有一个直接前驱 $a_{i-1}$；
- 终端元素 $a_n$ **没有后继**；
- 除 $a_n$ 外的任一元素 $a_i (1 \le i \le n-1)$ 有且仅有一个直接后继 $a_{i+1}$。

题目问“除开始元素外，每个元素”，对应的正是“有唯一前驱”这一性质。

- (A) 只有唯一的前驱元素：正确。
- (B) 只有唯一的后继元素：这是“除终端元素外”的性质，不是本题条件。
- (C) 有多个前驱元素：违反线性表“一对一”的约束，属于非线性结构（如树、图）的特征。
- (D) 有多个后继元素：同样违反线性表定义。

**易错点**：  
1. **混淆前驱和后继的边界条件**：题目说的是“除开始元素外”，对应的是“有唯一前驱”；若说“除终端元素外”，才对应“有唯一后继”。不要看到“唯一”就选 B。  
2. **忽略“直接”二字**：线性表强调“直接前驱/直接后继”，不能理解为所有前面的元素都是前驱。例如 $a_3$ 的直接前驱只有 $a_2$，而不是 $a_1,a_2$ 都是前驱。  
3. **误选 C 或 D**：这些是树、图等多对多结构的特征，在线性表中不可能出现。

**命题规律**：  
- **考点定位**：数据结构第一章“线性表”的基本概念，属于必考的送分题，常以选择题形式出现。  
- **常见变式**：  
  1. 改为“除最后一个元素外，每个元素 ( )”，答案选 B；  
  2. 考查线性表、树、图的逻辑结构对比；  
  3. 结合存储结构考查（如顺序表、链表）对逻辑特性的影响。  
- **复习建议**：牢记线性表逻辑结构的两条性质——  
  $$
  \begin{cases}
  \text{除第一个元素外，每个元素有唯一直接前驱}\\[2pt]
  \text{除最后一个元素外，每个元素有唯一直接后继}
  \end{cases}
  $$
  可类比“一列火车车厢”：每节车厢（除车头外）前面只有一节车厢，每节车厢（除车尾外）后面也只有一节车厢。这类概念题要秒答，不丢分。

# 选择题 第 6 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-23-M06_题目.png|题目]]

6. 在一个单链表中，已知 $q$ 所指结点是 $p$ 所指结点的前驱结点，若在 $q$ 和 $p$ 之间插入结点 $s$，则执行 ( ).
A. $s \rightarrow next = p \rightarrow next; p \rightarrow next = s;$
B. $p \rightarrow next = s \rightarrow next; s \rightarrow next = p;$
C. $q \rightarrow next = s; s \rightarrow next = p;$
D. $p \rightarrow next = s; s \rightarrow next = q;$

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C02-23-M06_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选择 C。在 $q$ 与 $p$ 之间插入结点 $s$ 的核心操作是：让 $s$ 的后继指向 $p$，再让前驱 $q$ 的后继指向 $s$，即 $q \rightarrow next = s;\ s \rightarrow next = p;$。

**解题切入点**：拿到单链表插入题，先定位“插在谁和谁之间”，本质是修改前驱结点的指针。可类比排队：$q$ 是 $p$ 前面的人，现在 $s$ 要插队到二者之间，只需要让 $q$ 身后变成 $s$，让 $s$ 身后变成 $p$，队伍其余部分不被打乱。不要一上来就修改 $p$ 的指针，因为题目要求插入的位置在 $p$ 之前，而不是 $p$ 之后。

**推演**：

设单链表结点为：

$$struct\ Node \{ ElementType data;\ Node *next; \};$$

初始时，$q$ 是 $p$ 的前驱，即：

$$q \rightarrow next = p$$

在 $q$ 与 $p$ 之间插入 $s$ 后，要求最终满足：

$$q \rightarrow next = s,\qquad s \rightarrow next = p$$

逐项分析四个选项：

A 选项：

$$s \rightarrow next = p \rightarrow next;\qquad p \rightarrow next = s;$$

执行后，$s$ 被插入到 $p$ 的后面，而不是 $p$ 的前面，不符合题意。

B 选项：

$$p \rightarrow next = s \rightarrow next;\qquad s \rightarrow next = p;$$

先读取 $s \rightarrow next$，但 $s$ 尚未接入链表，其 $next$ 域未定义，属于野指针操作；并且直接修改 $p \rightarrow next$，会断掉原链表，错误。

C 选项：

$$q \rightarrow next = s;\qquad s \rightarrow next = p;$$

执行后 $q$ 的后继变成 $s$，$s$ 的后继变成 $p$，正确完成插入。虽然习惯上更推荐先执行 $s \rightarrow next = p$，再执行 $q \rightarrow next = s$，但本题中 $p$ 作为指针变量仍被保留，因此 C 的顺序不会丢失 $p$。

D 选项：

$$p \rightarrow next = s;\qquad s \rightarrow next = q;$$

执行后 $p$ 原来的后继丢失，并且形成环 $q \rightarrow p \rightarrow s \rightarrow q$，链表结构被破坏，错误。

因此答案为 C。

关键代码思路如下：

```c
// 已知 q->next == p，在 q 和 p 之间插入 s
s->next = p;   // 先让 s 指向后继 p
q->next = s;   // 再让前驱 q 指向 s
```

**易错点**：

- 容易错选 A，因为很多同学机械记忆“插入结点先接后继、再接前驱”，但 A 是把 $s$ 插到 $p$ 后面，不是插到 $q$ 和 $p$ 之间。
- 容易忽略“断链”问题。D 选项先改 $p \rightarrow next$，导致 $p$ 原来的后继结点丢失，且形成环。
- 容易对 C 选项的语句顺序产生疑问。虽然常规稳妥写法是先 $s \rightarrow next = p$，再 $q \rightarrow next = s$，但本题中 $p$ 指针仍存在，所以先改 $q \rightarrow next$ 也不会丢 $p$。
- B 选项涉及对未初始化结点指针域的读写，是典型错误写法。

**命题规律**：本题考点为单链表的插入操作，属于线性表部分的高频基础题。常见变式有：在给定结点 $p$ 后插入、在给定结点 $p$ 前插入、删除 $p$ 的后继、循环链表插入、双向链表插入等。复习时建议画图模拟指针变化，牢记“先连接新结点到后继，再修改前驱指向新结点”，同时检查是否出现断链或成环。

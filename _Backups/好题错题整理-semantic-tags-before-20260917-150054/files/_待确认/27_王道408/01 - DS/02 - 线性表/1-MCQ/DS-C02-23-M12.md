# 选择题 第 12 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-23-M12_题目.png|题目]]

12. 在线性表 $a_0,a_1, \cdots ,a_{100}$ 中, 删除元素 $a_{50}$ 需要移动 ( ) 个元素.
(A) 0
(B) 50
(C) 51
(D) 0 或 50

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C02-23-M12_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：删除元素 $a_{50}$ 需要移动的元素个数取决于线性表的存储结构。若采用顺序存储，则需移动 $a_{51}$ 到 $a_{100}$ 共 $50$ 个元素；若采用链式存储，则无需移动元素。故答案为 (D) 0 或 50。

**解题切入点**：本题考察线性表删除操作中元素移动次数的理解。首先要明确线性表是逻辑结构，其存储方式有顺序存储和链式存储两种，不同存储方式下删除操作的开销差异很大。类似算法竞赛中，常需根据数据结构特性选择最优操作，这里则需判断题目是否隐含存储方式。通常，若未特别说明，线性表指代逻辑结构，必须考虑两种可能性。

**推演**：
- 线性表 $a_0, a_1, \cdots, a_{100}$ 共有 $101$ 个元素，下标从 $0$ 到 $100$。
- 删除元素 $a_{50}$ 后，对于顺序表，需将 $a_{51}$ 至 $a_{100}$ 依次前移一位，移动元素个数为 $100 - 50 = 50$。
- 对于链表，只需修改指针（或结点引用），无需移动数据元素，移动次数为 $0$。
- 因此，移动次数为 $0$ 或 $50$，对应选项 (D)。

**易错点**：
1. 误以为线性表默认是顺序表，从而只考虑顺序存储，错误选择 B（50）或 C（51）。C 选项可能源于将 $a_{50}$ 本身也算作移动，或误认为总共有 101 个元素，删除中间元素后移动 51 个，但实际只有后面元素需要移动。
2. 忽略链式存储的可能性，导致遗漏“0”这一情形。在 408 考试中，线性表作为逻辑结构，其存储方式未指定时必须全面考虑。
3. 混淆下标与元素个数：$a_{50}$ 是第 51 个元素，后面元素是 $a_{51}$ 到 $a_{100}$ 共 50 个，而非 51 个。

**命题规律**：本题是线性表基础概念题，常出现在选择题中，考查顺序表与链表删除操作的时间复杂度与移动次数对比。类似变式包括：给定顺序表删除某位置元素需移动元素个数、链表删除操作的时间复杂度（O(1) 或 O(n) 取决于是否已知前驱）等。复习建议：深入理解线性表的逻辑结构与物理存储的差异，熟练掌握顺序表与链表的插入、删除操作在元素移动和指针修改上的区别，并注意题目中是否隐含存储方式或可选的存储方式。

# 选择题 第 26 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-23-M26_题目.png|题目]]

26. 有一个长度为$n$的循环单链表，若从表中删除首元结点的时间复杂度达到$O(n)$，则此时采用的循环单链表的结构可能是（ \_ ）。
(A) 只有表头指针，没有头结点
(B) 只有表尾指针，没有头结点
(C) 只有表尾指针，带头结点
(D) 只有表头指针，带头结点

## DeepSeek V4 Flash Max 解析

**答案**：选 A。只有表头指针且没有头结点时，删除首元结点需要先遍历找到尾结点以维持循环，最坏时间复杂度为 $O(n)$。

**解题切入点**：  
删除链表结点的本质是“找到待删结点的前驱，修改其 $\text{next}$”。循环单链表中，若不带头结点，则首元结点的前驱是尾结点；若带头结点，则首元结点的前驱就是头结点。所以本题的关键是：给定的指针结构能否 $O(1)$ 找到这个前驱。可以联想约瑟夫环中使用尾指针维护循环链表的技巧：尾指针的 $\text{next}$ 就是首元结点，而尾指针本身就是首元结点的前驱。

**推演**：

设首元结点为 $p$，删除前必须找到 $p$ 的前驱 $pre$，然后执行  
$$
pre\to \text{next}=p\to \text{next},
$$
再释放 $p$。逐项分析。

**(A) 只有表头指针，没有头结点**  

头指针 `head` 直接指向首元结点 $p$。由于没有头结点，$p$ 的前驱是尾结点，但 `head` 不能直接得到尾结点，必须从头遍历：

```c
if (head->next == head) {   // 只有一个结点
    free(head);
    head = NULL;
} else {
    p = head;
    while (p->next != head)
        p = p->next;        // 循环结束后 p 是尾结点
    p->next = head->next;   // 尾结点指向新首元
    free(head);
    head = p->next;         // 头指针指向新首元
}
```

遍历需要 $O(n)$ 时间，因此总体为 $O(n)$。

**(B) 只有表尾指针，没有头结点**  

`tail` 指向尾结点，首元结点为 $p=tail\to\text{next}$，前驱 `tail` 已知：

```c
p = tail->next;
if (p == tail) {
    free(p);
    tail = NULL;
} else {
    tail->next = p->next;
    free(p);
}
```

时间为 $O(1)$。

**(C) 只有表尾指针，带头结点**  

`tail` 指向尾结点，由循环性可知 $tail\to\text{next}$ 就是头结点。首元结点为头结点的后继，前驱头结点可由 `tail->next` 得到：

```c
h = tail->next;         // h 为头结点
p = h->next;            // p 为首元结点
h->next = p->next;
if (p == tail) tail = h; // 删除后链表为空
free(p);
```

时间为 $O(1)$。

**(D) 只有表头指针，带头结点**  

`head` 指向头结点，首元结点为 $head\to\text{next}$，前驱头结点已知：

```c
p = head->next;
head->next = p->next;
free(p);
```

时间为 $O(1)$。

综上，只有 A 的时间复杂度为 $O(n)$。

**易错点**：  

- 认为删除首元结点只要移动头指针，忽略了循环链表必须让尾结点指向新首元，否则会断链。
- 有头结点时，首元结点的前驱是头结点，不是尾结点，因此带头结点时删除首元通常可做到 $O(1)$。
- 只有尾指针带头结点时，虽然没有头指针，但 $tail\to\text{next}$ 就是头结点，仍然可以 $O(1)$ 完成操作。
- 严格按大 $O$ 记号，$O(1)$ 也属于 $O(n)$；但考研题意是“最坏情况达到线性级”，不要因此误选所有选项。
- 处理 $n=1$ 时要单独考虑指针置空，否则容易产生悬空指针。

**命题规律**：  

- 考点是循环单链表中“头指针/尾指针/头结点”的不同组合对插入、删除首尾结点时间复杂度的影响。
- 常见变式：删除尾结点、在首部/尾部插入结点、用尾指针模拟约瑟夫环等。例如“只有尾指针、不带头结点”时，在尾部插入和删除首元均为 $O(1)$；“只有头指针、带头结点”时，删除首元也为 $O(1)$。
- 复习建议：将“有无头结点”和“只有头指针/只有尾指针”两两组合画图，逐个推导插入/删除首尾结点的复杂度，尤其记住：循环链表有尾指针时，$tail\to\text{next}$ 可 $O(1)$ 得到头结点或首元结点。

# 选择题 第 29 题

29. 一个链表最常用的操作是在最后一个元素后插入一个元素和删除第一个元素,则选用 ( \_ ) 最节省时间.
(A) 不带头结点的循环单链表
(B) 双链表
(C) 单链表
(D) 不带头结点且有尾指针的循环单链表

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C02-23-M29_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 **D**。不带头结点且有尾指针的循环单链表，用尾指针 $tail$ 直接定位链尾，且 $tail\to next$ 直接指向首元结点，所以“在最后一个元素后插入”和“删除第一个元素”都能在 $O(1)$ 时间完成。

**解题切入点**：  
拿到题先把两个操作“翻译”成数据结构语言：  
1. 在最后一个元素后插入元素 = **尾部插入**；  
2. 删除第一个元素 = **头部删除**。  

因此需要同时快速访问“尾”和“头”。尾指针可以直接定位尾；而循环单链表让尾结点的 next 指向首元结点，所以一个尾指针就能同时拿到“尾”和“头”。这就像实现一个队列：如果只给队首指针，入队时必须走到队尾；如果额外维护队尾指针，并让队尾指向队首，入队和出队就都很方便。

**推演**：  
链表结点结构为：

```c
typedef struct LNode {
    ElemType data;
    struct LNode *next;
} LNode;
```

对于选项 D，设尾指针为 `tail`，则：

- `tail` 指向最后一个元素；
- `tail->next` 指向第一个元素。

### 1. 在最后一个元素后插入结点 $s$

非空表时：

```c
s->next = tail->next; // s 先指向原首元结点
tail->next = s;       // 原尾结点指向 s
tail = s;             // s 成为新的尾结点
```

用公式表示：

$$
s\to next = tail\to next,\qquad tail\to next = s,\qquad tail = s.
$$

只需常数次指针修改，时间为 $O(1)$。

### 2. 删除第一个元素

设首元结点为 $p=tail\to next$：

```c
p = tail->next;
if (p == tail) {
    tail = NULL;          // 只有一个结点时，删除后链表为空
} else {
    tail->next = p->next; // 跳过首元结点
}
free(p);
```

用公式表示：

$$
p=tail\to next,\qquad tail\to next=p\to next,\qquad free(p).
$$

同样为 $O(1)$。

相比之下：

- (A) 不带头结点的循环单链表若只有头指针，没有尾指针，尾部插入需要先遍历找到尾结点，时间为 $O(n)$；
- (B) 普通双链表若只给头指针，尾部插入仍要遍历到链尾，时间为 $O(n)$；
- (C) 单链表尾部插入也需要遍历到链尾，时间为 $O(n)$。

因此同时满足“尾部插入”和“删除第一个元素”都最省时间的应选 **D**。

**易错点**：  
- 误以为循环单链表一定能在尾部 $O(1)$ 插入；实际上若没有尾指针，从头部找尾仍需遍历。  
- 误以为双链表尾部插入一定是 $O(1)$；普通双链表若没有尾指针，仍要扫描到最后一个结点。  
- 删除首元结点时要注意指针修改顺序：先保存 `p = tail->next`，再修改 `tail->next = p->next`，最后才 `free(p)`，不能先释放再取 `p->next`。  
- 当链表只有一个结点时，删除后必须将 `tail` 置为 `NULL`，否则尾指针会悬空。  
- 空表插入第一个结点时也要单独处理：`tail = s; s->next = s;`，不能直接使用 `tail->next`。

**命题规律**：  
本题属于“线性表—链表”的经典复杂度分析，考查带头结点/不带头结点、循环/非循环、头指针/尾指针等不同存储形式对基本操作的影响。常见变式有：

- 在已知结点前/后插入或删除已知结点的时间复杂度；
- 带头结点的循环双链表用 `head->prior` 找尾；
- 用尾指针合并两个循环单链表；
- 判断某个链表结构更适合“头插尾删”或“尾插头删”等操作组合。

复习时应自己画图模拟“头插、尾插、头删、尾删”的指针变化，并把单链表、双链表、循环链表、带头结点/不带头结点、有无尾指针的时间复杂度整理成表，特别注意空表和单结点边界情况。

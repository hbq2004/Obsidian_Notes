# 选择题 第 9 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-22-M09_题目.png|题目]]

9. 在一个长度为$n$的顺序表中删除第$i(1\leqslant i\leqslant n)$个元素时，需向前移动 (  ) 个元素.

A. $n$
B. $i-1$
C. $n-i$
D. $n-i+1$

## 答案

## DeepSeek V4 Flash Max 解析

**答案**：选 C；长度为 $n$ 的顺序表中删除第 $i$ 个元素时，需向前移动 $n-i$ 个元素。

**解题切入点**：拿到题目先判断是“删除”还是“插入”。顺序表用连续存储，删除第 $i$ 个元素后，只有它**后面**的元素需要向前补位，所以移动个数就是“第 $i$ 个元素后面还剩多少个元素”。打个比方：队伍中第 $i$ 个人离开，只有他后面的人往前补位，他前面的人不动，他自己也不算“向前移动”。

**推演**：
设顺序表元素为
$$
a_1,a_2,\ldots,a_{i-1},a_i,a_{i+1},\ldots,a_n
$$
删除第 $i$ 个元素 $a_i$ 后，表变为
$$
a_1,a_2,\ldots,a_{i-1},a_{i+1},\ldots,a_n
$$
需要向前移动的是
$$
a_{i+1},a_{i+2},\ldots,a_n
$$
其个数为
$$
n-(i+1)+1=n-i
$$

所以答案选 C。

边界检验：

- 若删除第 1 个元素，即 $i=1$，需移动 $n-1$ 个，公式给出 $n-1$；
- 若删除最后一个元素，即 $i=n$，无需移动，公式给出 $0$。

关键代码思路如下：

```c
bool ListDelete(SqList &L, int i, ElemType &e) {
    if (i < 1 || i > L.length) return false;   // 位置合法性检查
    e = L.data[i - 1];                         // 取出被删元素，第 i 个元素对应下标 i-1
    int n = L.length;
    for (int j = i - 1; j < n - 1; j++)
        L.data[j] = L.data[j + 1];             // 后续元素依次前移
    L.length = n - 1;                          // 表长减 1
    return true;
}
```

循环从下标 $i-1$ 执行到 $n-2$，共执行
$$
(n-2)-(i-1)+1=n-i
$$
次，正好对应移动 $n-i$ 个元素。

删除操作的平均移动次数为
$$
\frac{1}{n}\sum_{i=1}^{n}(n-i)=\frac{n-1}{2}
$$
时间复杂度为 $O(n)$。

**易错点**：

- **与插入公式混淆**：插入到第 $i$ 个位置时，需要移动 $n-i+1$ 个元素；删除第 $i$ 个元素时，只需移动 $n-i$ 个元素。删除是“后面元素前移”，插入是“从第 $i$ 个元素开始后移”。
- **把被删元素也算进去**：容易误选 D 的 $n-i+1$，错在把 $a_i$ 本身也算作前移元素。实际上 $a_i$ 是被删除/覆盖的元素，不是向前移动的元素。
- **数组下标转换出错**：题目中的第 $i$ 个元素对应 C 语言数组下标 $i-1$。循环应写成从 `i-1` 到 `n-2`，不要写成从 `i` 到 `n-1`，否则会越界或漏移。
- **忘记边界验证**：令 $i=1$ 时应移动 $n-1$；令 $i=n$ 时应移动 $0$。若某个选项两端不满足，说明公式错误。

**命题规律**：本题属于顺序表基本操作，是 408 数据结构线性表部分的常考基础点。常见变式有：

- 已知删除位置求移动次数；
- 等概率删除时求平均移动次数 $\frac{n-1}{2}$；
- 对比插入操作的平均移动次数 $\frac{n}{2}$；
- 综合题中要求编写顺序表删除算法，或实现“删除所有值为 $x$ 的元素”等操作，需用双指针原地覆盖，达到 $O(n)$ 时间、$O(1)$ 空间。

复习建议：不要死记公式，要从“谁需要移动”推导：删除时只有被删元素后面的元素需要前移，所以是 $n-i$；插入时插入位置及其后的元素需要后移，所以是 $n-i+1$。同时要熟练写出带边界检查的插入、删除代码。

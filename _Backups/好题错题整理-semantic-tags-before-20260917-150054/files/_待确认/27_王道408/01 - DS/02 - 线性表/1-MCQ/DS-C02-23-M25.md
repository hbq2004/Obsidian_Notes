# 选择题 第 25 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-23-M25_题目.png|题目]]

25. 有两个长度为$n$的循环单链表，若要求两个循环单链表头尾相接的时间复杂度为$O(1)$，则对应两个循环单链表各设置一个指针，分别指向( )。
(A) 各自的头结点
(B) 各自的尾结点
(C) 各自的首结点
(D) 一个表的头结点，另一个表的尾结点

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C02-23-M25_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 **B**。两个循环单链表各设置一个指针时，应均指向各自的尾结点；这样才能在 $O(1)$ 时间内完成两个循环单链表的头尾相接。

**解题切入点**：拿到题先想：要把两个循环单链表接成一个循环单链表，必须要修改哪些结点？  
答案是两个链表的尾结点。因为单链表只能沿 `next` 方向走，若指针不指向尾结点，就必须从头遍历到尾，时间复杂度为 $O(n)$。这就像两列火车挂接：只知道火车头，不知道火车尾，无法 $O(1)$ 接上；必须在两个链表尾部都保存“尾车”的位置。

**推演**：设两个循环单链表为 $A$、$B$，其尾指针分别为 $r_A$、$r_B$。循环单链表中，尾结点的 `next` 指向表头方向：

- 不带头结点时：$r_A\to next$ 指向 $A$ 的首结点，$r_B\to next$ 指向 $B$ 的首结点；
- 带头结点时：$r_A\to next$ 指向 $A$ 的头结点，$r_B\to next$ 指向 $B$ 的头结点。

所以只要有两个尾指针，就能 $O(1)$ 同时取得每个链表的头/尾。连接时只需修改两次指针：

```c
// 不带头结点的循环单链表，把 B 接到 A 之后
LNode *headA = rA->next;   // 保存 A 的首结点
LNode *headB = rB->next;   // 保存 B 的首结点
rA->next = headB;          // A 的尾结点指向 B 的首结点
rB->next = headA;          // B 的尾结点指向 A 的首结点，形成大环
```

整个过程只执行常数次指针修改，不涉及遍历，因此时间复杂度为 $O(1)$。

如果只设置头结点指针或首结点指针，则要找尾结点必须从头部沿 `next` 走 $O(n)$ 次；若只一个表设尾指针、另一个表设头指针，则另一个表仍需要遍历找尾，也不能达到 $O(1)$。

**易错点**：

- 容易误选 A：头结点虽然能表示链表，但不能 $O(1)$ 找到尾结点，必须遍历。
- 容易混淆“头结点”和“首结点”：头结点是哨兵结点，首结点是第一个数据结点；二者都不直接保存尾结点位置。
- 若选 D，只给一个尾指针，另一个链表仍找不到尾，无法 $O(1)$ 完成连接。
- 改指针时要注意保存被覆盖的指针；例如必须先保存 `headA`、`headB`，再修改 `rA->next`、`rB->next`，否则会断链。

**命题规律**：本题核心考点是“循环单链表尾指针的性质”。408 中常以选择题考查指针设置，也可能在综合题中要求编写合并两个循环单链表的算法。常见变式有：带头结点与不带头结点的循环链表合并、用尾指针实现循环链表在表头/表尾插入、判断两个循环链表是否相交等。复习时记住结论：循环单链表若常做头尾操作，应保存尾指针；尾结点的 `next` 就是头结点/首结点，因此尾指针可同时提供头尾信息。

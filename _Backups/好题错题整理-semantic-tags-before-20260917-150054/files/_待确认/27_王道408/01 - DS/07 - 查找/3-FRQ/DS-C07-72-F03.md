# 综合题 第 3 题

![[_Attachments/题目识别/27_王道408-题目/DS-C07-72-F03_题目.png|题目]]

3. 已知一个有序顺序表 $A[0\cdots8n-1]$ 的表长为 $8n$, 并且表中没有关键字相同的数据元素. 假设按下述方法查找一个关键字值等于给定值 $X$ 的数据元素: 首先在 $A[7], A[15], A[23], \cdots, A[8k-1], \cdots, A[8n-1]$ 中进行顺序查找, 若查找成功, 则算法报告成功位置并返回; 若不成功, 则当 $A[8k-1] < X < A[8\times(k+1)-1]$ 时, 可确定一个缩小的查找范围 $A[8k] \sim A[8\times(k+1)-2]$, 然后可在这个范围内执行折半查找. 特殊情况: 若 $X > A[8n-1]$ 的关键字, 则查找失败.

1) 画出描述上述查找过程的判定树.

2) 计算相等查找概率下查找成功的平均查找长度.

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C07-72-F03_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：该查找方法本质是“先用顺序查找定位块（每块 8 个元素），再在块内 7 个元素中折半查找”；其判定树由 $n$ 个最大值结点构成右单链，每个最大值结点的“小于”分支挂一棵 7 结点折半判定树。等概率成功查找的平均查找长度为  
\[
ASL_{\text{succ}}=\frac{4n+21}{8}.
\]

**解题切入点**：看到 $A[7],A[15],\cdots,A[8n-1]$ 要立刻想到：这是把表分成了 $n$ 块，每块长度为 $8$，这些位置是每块的最大值。查找过程分两层：第一层在块最大值中顺序查找；第二层在确定块内前 $7$ 个元素中折半查找。计算 ASL 时不能只数一层比较次数，要“先定位块次数 + 块内折半次数”叠加。

**推演**：

令
\[
M_i=A[8i-1]\quad (i=1,2,\cdots,n)
\]
表示第 $i$ 块的最大值；第 $i$ 块内除最大值外的 7 个元素为
\[
A[8(i-1)],A[8(i-1)+1],\cdots,A[8i-2].
\]
并约定 $M_0=-\infty$，则当 $X<A[7]$ 时归入第 1 块的折半范围。

### 1. 判定树

第一层是顺序查找，因此判定树的上部是“右单链”：

```
M1=A[7] --(X>M1)--> M2=A[15] --(X>M2)--> ... --> Mn=A[8n-1]
   |                    |                              |
(X=M1)成功        (X=M2)成功                     (X=Mn)成功
   |                    |                              |
(X<M1)BT1         (X<M2)BT2                      (X<Mn)BTn
                                                  (X>Mn)失败
```

其中 $BT_i$ 表示在第 $i$ 块前 7 个元素中折半查找的判定树。由于块内只有 7 个元素，其折半判定树为：

```
              A[8i-5]
             /       \
        A[8i-7]      A[8i-3]
        /     \      /     \
A[8i-8] A[8i-6] A[8i-4] A[8i-2]
```

也就是说，块内第 4 个元素先比较；若小于它，到左侧 3 个元素中折半；若大于它，到右侧 3 个元素中折半。

### 2. 计算成功 ASL

若目标元素在第 $i$ 块中，第一层顺序查找需要比较 $M_1,M_2,\cdots,M_i$，共 $i$ 次。

- 若目标正好是 $M_i=A[8i-1]$，则总比较次数为 $i$；
- 若目标是块内前 7 个元素之一，则除了第一层的 $i$ 次比较外，还要加上块内折半比较次数。

块内 7 个元素的折半次数分别为：

\[
\begin{array}{c|ccccccc}
\text{元素} & A[8i-8] & A[8i-7] & A[8i-6] & A[8i-5] & A[8i-4] & A[8i-3] & A[8i-2]\\
\hline
\text{折半次数} & 3 & 2 & 3 & 1 & 3 & 2 & 3
\end{array}
\]

所以块内 7 个元素的折半比较次数总和为：

\[
3+2+3+1+3+2+3=17.
\]

因此第 $i$ 块 8 个元素的成功比较次数总和为：

\[
S_i
=
\underbrace{i}_{M_i}
+
\underbrace{7i+17}_{\text{块内 7 个元素}}
=
8i+17.
\]

全部 $8n$ 个元素等概率出现，故：

\[
ASL_{\text{succ}}
=
\frac{1}{8n}\sum_{i=1}^{n}S_i
=
\frac{1}{8n}\sum_{i=1}^{n}(8i+17)
=
\frac{1}{8n}\left(8\cdot\frac{n(n+1)}{2}+17n\right)
=
\frac{4n^2+21n}{8n}
=
\frac{4n+21}{8}.
\]

**易错点**：

- 容易只数第一层顺序查找次数，或只数第二层折半次数，忽略两层需要叠加。
- 第一层是顺序查找，不是折半查找，因此其平均贡献是 $(n+1)/2$，不是 $O(\log n)$。
- 注意块内折半范围是 $A[8(i-1)]\sim A[8i-2]$，长度为 $7$，不包括块最大值 $A[8i-1]$。
- 不要忘记 $X<A[7]$ 时也要进入第 1 块的折半查找；题目特殊说明只强调 $X>A[8n-1]$ 时失败。
- 7 个元素的折半判定树深度分布容易写错，应是 $1,2,2,3,3,3,3$，总和为 $17$。

**命题规律**：本题综合考查“分块查找 + 折半查找 + 判定树 + ASL 计算”。常见变式有：改变每块长度 $m$；第一层不用顺序查找而用折半查找；考查查找失败 ASL；或者给定 $n$ 求具体 ASL。复习时应熟练画出顺序查找、折半查找、分块查找的判定树，并掌握“比较次数按判定树深度累计”的计数方法。

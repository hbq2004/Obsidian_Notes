# 综合题 第 4 题

![[_Attachments/题目识别/27_王道408-题目/DS-C07-75-F04_题目.png|题目]]

4. 已知一组关键字为$\{26,36,41,38,44,15,68,12,6,51,25\}$，用链地址法解决冲突，假设装填因子$α=0.73$，散列函数的形式为$H(key)=key\%P$，$P$为不大于表长的最大素数，请回答以下问题:
1) 构造出散列函数.
2) 分别计算出等概率情况下查找成功和查找失败的平均查找长度(查找失败的计算中只将与关键字的比较次数计算在内即可).

## 答案

## DeepSeek V4 Flash Max 解析

**答案**：散列函数为 $H(key)=key\%13$；等概率查找成功平均长度 $ASL_{成功}=18/11\approx1.636$，查找失败平均长度 $ASL_{失败}=11/13\approx0.846$。

**解题切入点**：通过装填因子 $\alpha$ 和关键字个数 $n$ 估算表长 $m$，再取 $P$ 为不大于 $m$ 的最大素数，得到散列函数；利用链地址法构造散列表，统计每个哈希地址的链表长度，按公式计算 $ASL_{成功}$ 和 $ASL_{失败}$。

**推演**：

1. 确定表长 $m$ 与 $P$。  
   由 $\alpha=\frac{n}{m}$，得 $m=\frac{n}{\alpha}=\frac{11}{0.73}\approx15.07$，取 $m=\lceil15.07\rceil=16$。  
   不大于 $16$ 的最大素数为 $13$，故 $P=13$，散列函数为 $H(key)=key\%13$。

2. 构造链地址法散列表。  
   对每个关键字计算哈希值（按给定顺序插入，采用尾插法，不影响最终长度）：  
   $H(26)=0$, $H(36)=10$, $H(41)=2$, $H(38)=12$, $H(44)=5$, $H(15)=2$, $H(68)=3$, $H(12)=12$, $H(6)=6$, $H(51)=12$, $H(25)=12$。  
   得到的各地址链表长度如下（地址 $0\sim12$，$13\sim15$ 为空）：  
   $l_0=1$, $l_1=0$, $l_2=2$, $l_3=1$, $l_4=0$, $l_5=1$, $l_6=1$, $l_7=0$, $l_8=0$, $l_9=0$, $l_{10}=1$, $l_{11}=0$, $l_{12}=4$。

3. 计算 $ASL_{成功}$。  
   $ASL_{成功}= \frac{1}{n}\sum_{i=0}^{m-1} \frac{l_i(l_i+1)}{2} = \frac{1}{11}\left(\frac{1\cdot2}{2}+\frac{2\cdot3}{2}+\frac{1\cdot2}{2}+\frac{1\cdot2}{2}+\frac{1\cdot2}{2}+\frac{4\cdot5}{2}\right) = \frac{1}{11}(1+3+1+1+1+10)=\frac{18}{11}\approx1.636$。

4. 计算 $ASL_{失败}$。  
   查找失败时，关键字映射到 $0\sim12$ 的概率相等，每个地址失败需要比较的次数等于该地址链表长度（空链表比较 $0$ 次）。故  
   $ASL_{失败}= \frac{1}{P}\sum_{i=0}^{P-1} l_i = \frac{1}{13}(1+0+2+1+0+1+1+0+0+0+1+0+4)=\frac{11}{13}\approx0.846$。

**易错点**：
- 表长 $m$ 应取 $ \lceil n/\alpha \rceil $，但有时也取 $ \lfloor n/\alpha \rfloor $，需根据 $\alpha$ 近似程度选择，但不影响 $P$ 的取值（本题 $P=13$ 固定）。
- 链地址法查找失败平均长度分母应为哈希函数值域大小 $P$（即 $0\sim P-1$），而不是表长 $m$，因为失败时只可能通过这些地址访问。
- 成功平均长度计算与插入顺序无关，因为每个地址上所有关键字的比较次数之和恒为 $\frac{l(l+1)}{2}$。
- 注意只将与关键字的比较次数计入，空链表比较次数为 $0$。

**命题规律**：散列函数设计与性能分析是 408 常考点，常结合装填因子、冲突处理方法（链地址法、开放地址法）考查平均查找长度计算。常见变式包括：改变冲突处理方法（如线性探测法）、给出不同装填因子、要求计算失败 $ASL$ 时是否包含空地址比较等。复习时需熟练掌握根据装填因子确定表长的方法，以及链地址法中 $ASL_{成功}$ 与 $ASL_{失败}$ 的计算公式，注意区分分母是表长还是哈希函数值域。

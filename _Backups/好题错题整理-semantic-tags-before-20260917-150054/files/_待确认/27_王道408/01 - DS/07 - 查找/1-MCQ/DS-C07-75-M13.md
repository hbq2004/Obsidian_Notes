# 选择题 第 13 题

![[_Attachments/题目识别/27_王道408-题目/DS-C07-75-M13_题目.png|题目]]

13. 若采用链地址法构造散列表, 散列函数为 $H(key) = key \mod 17$, 则需 (①) 个链表. 这些链的链首指针构成一个指针数组, 数组的下标范围为 (②).

① A. 17
B. 13
C. 16
D. 任意

② A. 0～17
B. 1～17
C. 0～16
D. 1～16

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C07-75-M13_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：① 选 **A（17 个链表）**；② 选 **C（0～16）**。因为 $H(key)=key \bmod 17$ 的可能取值为 $0,1,2,\dots,16$，共 17 个散列地址，所以链地址法需要 17 条链表，链首指针数组下标范围为 $0\sim16$。

**解题切入点**：看到“链地址法”和“散列函数 $H(key)=key\bmod 17$”，第一反应就是“散列地址空间有多大”。除留余数法 $key \bmod p$ 的余数范围是 $0\sim p-1$，所以桶的个数就是 $p$。这就像竞赛中开桶数组时写 `vector<int> bucket[17]`，下标是 `0~16`，而不是 `1~17`。

**推演**：

1. 散列函数为
   $$
   H(key)=key \bmod 17
   $$
   对于任意关键字 $key$，可以写成
   $$
   key=17q+r,\qquad 0\le r<17
   $$
   其中 $q,r$ 为整数，$r$ 就是余数。

2. 因此 $H(key)$ 的所有可能取值为
   $$
   \{0,1,2,\dots,16\}
   $$
   一共有 $17$ 个不同的散列地址。

3. 链地址法的思想是：为每一个散列地址建立一条链表，所有散列到该地址的关键字都挂在这条链上。因此链表的个数等于散列地址的个数，即
   $$
   17
   $$

4. 这些链表的链首指针构成一个指针数组，数组下标与散列地址一一对应。散列地址范围是
   $$
   0\sim16
   $$
   所以数组下标范围也是 $0\sim16$。

用 C 语言风格可理解为：

```c
#define M 17
Node* head[M];   // head[0] ~ head[16]，共 17 个链首指针
int H(int key) {
    return key % M;   // 得到 0 ~ 16
}
```

因此：
- ① 应选 **A. 17**
- ② 应选 **C. 0～16**

**易错点**：

- 容易把 $key \bmod 17$ 的余数误认为是 $1\sim16$，忘记余数 $0$ 也存在。例如 $key=17,34,51$ 都会散列到地址 $0$。
- 容易把“数组元素个数”和“数组下标范围”混淆：有 17 个元素时，下标应为 $0\sim16$，而不是 $0\sim17$。
- ② 中 A 选项 $0\sim17$ 包含了 18 个下标，多了一个；B 选项 $1\sim17$ 虽然也有 17 个下标，但漏掉了地址 $0$；D 选项 $1\sim16$ 只有 16 个下标，均不正确。
- 不要误以为链表条数由关键字个数决定。链地址法中，即使某个散列地址为空，也需要一个空链首指针，所以链表个数始终等于散列表的桶数。

**命题规律**：本题考查散列表的构造方法、除留余数法的地址范围以及链地址法的结构。属于散列表部分的送分题，但容易在边界下标上失分。常见变式有：给定一组关键字，要求画出链地址法散列表并计算查找成功/失败的平均查找长度；或改用线性探测法处理冲突；或求装填因子 $\alpha=\dfrac{n}{m}$。复习时需重点掌握：

- 除留余数法 $H(key)=key\bmod p$ 的地址范围是 $0\sim p-1$；
- 链地址法每条链表对应一个桶；
- 指针数组长度等于桶数，下标从 $0$ 开始；
- 会计算“查找成功”和“查找失败”的平均查找长度。

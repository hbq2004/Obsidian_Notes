## DeepSeek V4 Flash Max 解析

**答案**：选 **B**。按 408 默认的 $mid=\lfloor(low+high)/2\rfloor$，8 个结点的折半查找判定树标准形态是：根结点左子树 3 个结点、右子树 4 个结点，且右子树必须为 4 结点判定树 $T(4)$；题图 B 与此一致。

**解题切入点**：不要把它当成普通“长得像平衡树”的二叉树，而要从“有序表区间递归取中值”的角度看。折半查找判定树是递归分治生成的树：每到一个区间，根把区间分成左右两段；左右两段长度由当前区间长度唯一确定。拿到题先看根结点左右子树结点数，再看每个子树是否也满足同样的递归规则。

**推演**：

设当前有序表区间长度为 $s$，取
$$
mid=\left\lfloor\frac{low+high}{2}\right\rfloor
$$

则左、右子树对应区间长度分别为
$$
|L|=\left\lfloor\frac{s-1}{2}\right\rfloor,\qquad
|R|=\left\lceil\frac{s-1}{2}\right\rceil
$$

所以对于任意结点，右子树结点数等于左子树结点数，或者比左子树结点数多 1；左子树结点数不可能比右子树多。并且左右子树本身也必须是折半查找判定树。

小规模标准判定树为：

$$
T(2):\quad \circ \to \circ
$$

根结点只有右孩子。

$$
T(3):\quad \circ(\circ,\circ)
$$

根结点有左右两个孩子。

$$
T(4):\quad \circ(\circ,\circ(\varnothing,\circ))
$$

即：根结点有左孩子、右孩子；右孩子又只有右孩子。

因此 8 个结点的标准判定树为：

$$
T(8)=T(3)\text{ 作为左子树},\quad T(4)\text{ 作为右子树}
$$

可表示为位置关系：

```text
        4
       / \
      2   6
     / \ / \
    1  3 5  7
            \
             8
```

逐项检查：

- A：根结点 $|L|=4,\ |R|=3$，与 $mid$ 下取整时“右子树不短于左子树”矛盾，排除。
- C：根结点左右子树都为 3 个结点，根层满足；但题图中它的 3 结点子树不是标准 $T(3)$，递归检查不通过，排除。
- B、D 根层都是 $|L|=3,\ |R|=4$，但只有 B 的右子树满足 $T(4)$：右子树根有左叶子，右孩子又有右孩子；D 不是该形态。

所以选 **B**。

若写成判定函数，核心思路是递归检查每个结点：

```c
bool check(Node *t, int &n) {
    if (t == NULL) { n = 0; return true; }
    int nl, nr;
    if (!check(t->lchild, nl)) return false;
    if (!check(t->rchild, nr)) return false;
    n = nl + nr + 1;
    return nl == (n - 1) / 2 && nr == n / 2;
}
```

其中除法为整数除法。

**易错点**：

1. 只比较根结点左右子树结点数，忘记递归检查子树，容易误选。
2. 把完全二叉树或平衡二叉树误认为折半查找判定树。$T(8)$ 并不是层序完全二叉树，其最下层单个结点在右链上。
3. 忽略取整方向。408 默认 $mid$ 下取整，因此右子树结点数不短于左子树；若用上取整，判定树会变成镜像。
4. “不含外部结点”意味着空指针不画成外部结点，所以判定树中可以出现单分支结点，这并不违反折半查找判定树性质。

**命题规律**：

考点是折半查找与判定树，常与二叉排序树、平均查找长度结合出题。常见变式有：给定 $n$ 画判定树、判断给定二叉树是否为判定树、计算查找成功/失败平均查找长度。复习时应自己画出 $n=1\sim15$ 的判定树，熟悉 $T(2),T(3),T(4)$ 等基本形态和取整方向，不要只背结论。

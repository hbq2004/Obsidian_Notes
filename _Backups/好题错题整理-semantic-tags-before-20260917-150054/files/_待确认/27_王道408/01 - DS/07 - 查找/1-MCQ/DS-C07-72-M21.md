## DeepSeek V4 Flash Max 解析

**答案**：选 A。$500,200,450,180$ 不能构成折半查找中的关键字比较序列；因为在 $200$ 处向右进入 $450$ 后，后面又出现 $180<200$，违反折半查找区间收缩规则。

**解题切入点**：拿到本题先不要试图假设某个具体有序表，而应把折半查找过程看成一棵“折半查找判定树”上的搜索路径。折半查找判定树本质是二叉搜索树：任意结点左子树的关键字都小于它，右子树的关键字都大于它。类比在二叉搜索树中找数：一旦在某结点处向左走，之后整条路径都在左子树中，不可能再遇到比该结点大的关键字；向右走同理。

**推演**：设比较序列为
$$a_1,a_2,\ldots,a_k.$$
在比较 $a_i$ 后，下一次比较的方向由 $a_{i+1}$ 与 $a_i$ 的大小关系决定：

- 若 $a_{i+1}<a_i$，说明目标关键字在 $a_i$ 的左半区，则之后所有被比较的关键字都必须小于 $a_i$，即
$$\forall j>i,\ a_j<a_i;$$
- 若 $a_{i+1}>a_i$，说明目标关键字在 $a_i$ 的右半区，则之后所有被比较的关键字都必须大于 $a_i$，即
$$\forall j>i,\ a_j>a_i.$$

逐项检查：

- A：$500,200,450,180$

  第一次 $500$，第二次 $200<500$，所以后面的 $450,180$ 都应小于 $500$，满足。  
  第二次 $200$，第三次 $450>200$，说明查找区间进入 $200$ 的右半区，则后面的 $180$ 必须大于 $200$，但 $180<200$，矛盾。故 A 不能构成。

- B：$500,450,200,180$

  每次都是向左走：$450<500$，$200<450$，$180<200$，且后续所有关键字都符合相对大小关系，合法。

- C：$180,500,200,450$

  $500>180$ 向右，后续 $200,450>180$；$200<500$ 向左，后续 $450<500$；$450>200$ 向右，合法。

- D：$180,200,500,450$

  $200>180$ 向右，后续 $500,450>180$；$500>200$ 向右，后续 $450>200$；$450<500$ 向左，合法。

因此只有 A 不合法。

关键判定思路可写成：

```python
def check(a):
    n = len(a)
    for i in range(n - 1):
        for j in range(i + 1, n):
            if a[i + 1] < a[i] and a[j] > a[i]:
                return False
            if a[i + 1] > a[i] and a[j] < a[i]:
                return False
    return True
```

**易错点**：

- 只检查相邻两项的大小关系。例如 A 中 $500>200<450>180$ 看起来有升有降，但真正的规则是“某点确定向左后，其右侧所有点都必须小于该点；向右后，其右侧所有点都必须大于该点”。
- 误以为比较序列必须严格单调。折半查找路径可以左右交替，如 C、D 并不单调但合法。
- 忽略“下一次比较值的方向”是由当前比较值与下一次比较值的大小关系决定的，而不是由后一个任意元素决定。

**命题规律**：本题属于查找章节中“折半查找判定树”的典型考法，考查对折半查找区间收缩过程的理解。常见变式有：判断给定比较序列是否合法、根据比较序列画出判定树、计算平均查找长度、给定查找关键字求比较次数等。复习时应熟练掌握折半查找判定树的中序有序性和平衡性，并把“每次比较后区间收缩”的思想作为判断依据。

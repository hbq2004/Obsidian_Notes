20. 将关键字 1,2,3,4,5,6,7 依次插入初始为空的红黑树 $T$, 则 $T$ 中红结点的个数是 (  ).
A. 1
B. 2
C. 3
D. 4

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C07-73-M20_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：将 $1,2,3,4,5,6,7$ 依次插入空红黑树后，最终红结点为关键字 $4,5,7$，共 $3$ 个，故选 $\boxed{\text{C}}$。

**解题切入点**：  
红黑树插入的直接模拟。拿到题目先明确：新插入结点默认染成红色，然后按二叉搜索树规则插入；只有父结点为红色时才需要调整。调整时重点看“叔叔”的颜色：父红叔红只变色；父红叔黑则旋转加变色。本题关键字升序插入，最容易形成连续右链，要逐步画图，不要凭直觉选“平衡后红结点数”之类的结论。

**推演**：  
约定：括号内 `B` 表示黑色，`R` 表示红色；空指针 `NIL` 视为黑色，图中省略。

1. 插入 $1$：根必须为黑色。

```
1(B)
```

红结点数为 $0$。

2. 插入 $2$：

```
1(B)
 \
  2(R)
```

父结点 $1$ 为黑色，无需调整。红结点数为 $1$。

3. 插入 $3$：

```
1(B)
 \
  2(R)
   \
    3(R)
```

新结点 $3$ 的父结点 $2$ 为红色，叔叔为 $1$ 的左孩子，即空结点，视为黑色。属于“右-右”型：父 $2$ 变黑，祖父 $1$ 变红，再对 $1$ 左旋。

```
    2(B)
   /   \
  1(R)  3(R)
```

红结点数为 $2$。

4. 插入 $4$：

```
    2(B)
   /   \
  1(R)  3(R)
         \
          4(R)
```

新结点 $4$ 的父结点 $3$ 为红色，叔叔 $1$ 为红色。父、叔变黑，祖父 $2$ 变红；但 $2$ 是根，最后再把根染黑。

```
    2(B)
   /   \
  1(B)  3(B)
         \
          4(R)
```

红结点数为 $1$。

5. 插入 $5$：

```
    2(B)
   /   \
  1(B)  3(B)
         \
          4(R)
           \
            5(R)
```

新结点 $5$ 的父结点 $4$ 为红色，叔叔为 $3$ 的左孩子，空结点，视为黑色。属于“右-右”型：父 $4$ 变黑，祖父 $3$ 变红，对 $3$ 左旋。

```
      2(B)
     /   \
    1(B)  4(B)
         /   \
        3(R)  5(R)
```

红结点数为 $2$。

6. 插入 $6$：

```
      2(B)
     /   \
    1(B)  4(B)
         /   \
        3(R)  5(R)
                \
                 6(R)
```

新结点 $6$ 的父结点 $5$ 为红色，叔叔 $3$ 为红色。父、叔变黑，祖父 $4$ 变红；此时 $4$ 的父结点 $2$ 为黑色，停止调整，根 $2$ 仍为黑色。

```
      2(B)
     /   \
    1(B)  4(R)
         /   \
        3(B)  5(B)
                \
                 6(R)
```

红结点数为 $2$（$4,6$）。

7. 插入 $7$：

```
      2(B)
     /   \
    1(B)  4(R)
         /   \
        3(B)  5(B)
                \
                 6(R)
                  \
                   7(R)
```

新结点 $7$ 的父结点 $6$ 为红色，叔叔为 $5$ 的左孩子，空结点，视为黑色。属于“右-右”型：父 $6$ 变黑，祖父 $5$ 变红，对 $5$ 左旋。

```
      2(B)
     /   \
    1(B)  4(R)
         /   \
        3(B)  6(B)
             /   \
            5(R)  7(R)
```

最终红结点为 $4,5,7$，共 $3$ 个。  
红结点个数变化为：

$$
0,\ 1,\ 2,\ 1,\ 2,\ 2,\ 3
$$

因此选 C。

**易错点**：  
1. 插入第一个关键字后忘记将根染黑，导致后续判断全部出错。  
2. 调整时“叔叔”找错。例如插入 $7$ 时，父结点是 $6$，祖父是 $5$，叔叔是 $5$ 的左孩子（空），不是 $4$ 或 $3$。  
3. 父红叔红与父红叔黑的处理混淆。叔红时只变色，不旋转；叔黑时才需要旋转加变色。  
4. 旋转方向判断错误。连续“右-右”应左旋，连续“左-左”应右旋；可结合二叉排序树的中序顺序检查旋转是否正确。  
5. 不要凭“升序插入一定越来越平衡”的直觉选答案，红黑树最终形态必须逐步模拟。

**命题规律**：  
本题属于红黑树基本性质与插入操作的综合考查。408 中红黑树常以选择题出现，考点集中在：插入后的红结点个数、黑高、根结点颜色、需要旋转的次数，以及和 AVL 树、B 树的对比。复习时建议熟记红黑树五条性质，并掌握插入调整口诀：父红叔红只变色；父红叔黑旋转再变色。平时可手推 $1\sim7$、$1\sim15$ 的升序插入过程，训练快速画出最终树形并数清红结点。

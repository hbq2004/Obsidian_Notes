2. $KMP$ 算法的特点是在模式匹配时，指示主串的指针 ( )。
(A) 不会变大
(B) 不会变小
(C) 都有可能
(D) 无法判断

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C04-42-M02_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：  
选 **B**。KMP 匹配过程中，主串指针 $i$ 不会变小；它只可能不变或变大。也就是说，KMP 保证主串指针不回溯。

**解题切入点**：  
看到“KMP + 主串指针”应立刻想到 KMP 的核心思想：利用已经匹配的部分信息，匹配失败时只回退模式串指针，而不让主串指针回退。可以把主串指针想成“扫描光标”，它只会继续向前或原地等待，不会回头。模式串指针才通过 $next$ 数组跳回。

**推演**：  
设主串为 $S$，模式串为 $T$，$i$ 指向主串当前字符，$j$ 指向模式串当前字符。KMP 每轮循环只有两种分支：

```c
while (i <= S.length && j <= T.length) {
    if (j == 0 || S[i] == T[j]) {   // 匹配成功，或模式串已退到首位
        i++; j++;
    } else {                        // 失配，且 j > 0
        j = next[j];                // 只回退模式串指针，i 不动
    }
}
```

用式子表示主串指针的变化：

$$
i_{t+1}=
\begin{cases}
i_t+1, & S[i_t]=T[j_t]\ \text{或}\ j_t=0,\\[2mm]
i_t, & S[i_t]\ne T[j_t]\ \text{且}\ j_t>0.
\end{cases}
$$

因此每轮结束后必有：

$$
i_{t+1}\ge i_t
$$

也就是说，主串指针 $i$ 单调不减。

具体来说：

- 当字符匹配成功时，$i$ 变大；
- 当字符失配时，主串指针 $i$ 保持不变，只把模式串指针 $j$ 修改为 $next[j]$；
- 当 $j=0$ 时说明模式串首位都无法匹配，此时主串指针 $i$ 后移一位。

所以主串指针绝不会变小。  
朴素匹配算法在失配后会让主串指针回到本次匹配起点后一个位置，因此可能变小；KMP 正是通过不回退主串指针来保证线性时间匹配。

因此：

- A 错：匹配成功时 $i$ 会变大；
- B 对：$i$ 不会变小；
- C 错：$i$ 不可能变小；
- D 错：KMP 算法行为确定，可以判断。

**易错点**：  
1. 误把“不回溯”理解为“不变”。实际上“不回溯”是“不后退”，不是“原地不动”。  
2. 误选 A。匹配成功时主串指针必须后移，所以“不会变大”明显错误。  
3. 混淆主串指针和模式串指针。失配后通过 $next$ 跳变的是模式串指针 $j$，不是主串指针 $i$。  
4. 误以为“有时变大，有时不变，所以选 C”。但 C 中的“都有可能”意味着可能变小；主串指针最多原地等待，不会后退，所以应选“不会变小”。

**命题规律**：  
本题属于 KMP 算法的基础概念题，常以选择题或填空题出现。常见变式有：计算 $next$ 数组或 $nextval$ 数组、判断匹配过程中的比较次数、说明 KMP 时间复杂度为 $O(n+m)$ 的原因。复习时要牢记：KMP 的主串指针单调不减，模式串指针通过 $next$ 回退；同时要能手工模拟 $next$ 数组的构造，理解“最长相等前后缀”与失配跳转的关系。

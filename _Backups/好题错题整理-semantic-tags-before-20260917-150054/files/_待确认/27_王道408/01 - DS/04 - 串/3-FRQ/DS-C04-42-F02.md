## DeepSeek V4 Flash Max 解析

**答案**：按教材从 1 开始编号，\(P\) 的 \(next\) 数组为 \((0,1,2,1,2,3)\)；用 KMP 匹配时主串指针不回溯，最终在 \(S\) 的第 \(7\) 个位置匹配成功，即 \(S[7..12]=P\)。

**解题切入点**：拿到题先明确 \(next\) 数组的定义：它是失配后模式串指针应跳到的新位置，不是单纯的“最长相等前后缀长度”，也不是“右移位数”。手算时可以先找出 \(P[1..j-1]\) 的最长相等真前后缀长度再加 1。KMP 的核心是“主串指针不回溯”，可以类比查错时已经读过一遍的内容不必重新读，只需根据已匹配的前后缀信息调整模式串位置。

**推演**：

设串下标从 1 开始，\(P=p_1p_2\cdots p_6\)，其中 \(P=\)'aabaac'。

### 1. 计算 \(P\) 的 \(next\) 数组

教材定义：
\[
next[j]=
\begin{cases}
0,&j=1,\\
\max\{k\mid 1<k<j,\ P[1..k-1]=P[j-k+1..j-1]\},&\text{集合非空},\\
1,&\text{集合为空}.
\end{cases}
\]

等价地，\(next[j]\) 等于 \(P[1..j-1]\) 的最长相等真前后缀长度加 1（\(j>1\)）。

\[
\begin{array}{c|cccccc}
j&1&2&3&4&5&6\\ \hline
P[j]&a&a&b&a&a&c\\
P[1..j-1]&-&a&aa&aab&aaba&aabaa\\
L_j&-&0&1&0&1&2\\
next[j]&0&1&2&1&2&3
\end{array}
\]

所以：
\[
next=(0,1,2,1,2,3).
\]

### 2. KMP 匹配过程

主串：
\[
S= aabaabaabaac
\]

初始 \(i=1,\ j=1\)。

- **第 1 趟**：从 \(i=1,\ j=1\) 开始比较：
\[
S_1=P_1,\ S_2=P_2,\ S_3=P_3,\ S_4=P_4,\ S_5=P_5,
\]
但
\[
S_6=b\ne P_6=c.
\]
失配于 \(j=6\)，令
\[
j=next[6]=3,\quad i=6\text{ 不变}.
\]
等价于模式串右移 \(6-3=3\) 位，\(P_1,P_2\) 对齐到 \(S_4,S_5\)。

- **第 2 趟**：从 \(S_6\) 与 \(P_3\) 开始比较：
\[
S_6=P_3=b,\quad S_7=P_4=a,\quad S_8=P_5=a,
\]
但
\[
S_9=b\ne P_6=c.
\]
再次失配于 \(j=6\)，令
\[
j=next[6]=3,\quad i=9\text{ 不变}.
\]
等价于模式串再右移 3 位，此时 \(P_1,P_2\) 对齐到 \(S_7,S_8\)，且由上一轮匹配与 \(next[6]=3\) 可知它们相等，不必重新比较。

- **第 3 趟**：从 \(S_9\) 与 \(P_3\) 开始比较：
\[
S_9=P_3=b,\quad S_{10}=P_4=a,\quad S_{11}=P_5=a,\quad S_{12}=P_6=c.
\]
全部匹配成功。匹配结束时 \(j=7>6\)，主串指针 \(i=13\)，所以匹配起始位置为：
\[
i-|P|=13-6=7.
\]

因此：
\[
S[7..12]=aabaac=P.
\]

核心代码思路如下：

```c
i = 1; j = 1;
while (i <= S.length && j <= P.length) {
    if (j == 0 || S[i] == P[j]) {
        i++; j++;
    } else {
        j = next[j];
    }
}
if (j > P.length) return i - P.length; // 返回匹配起始位置
else return 0;
```

**易错点**：

1. 不要把 \(next[j]\) 直接写成最长相等前后缀长度。本题 \(P[1..5]=aabaa\) 的最长相等前后缀长度为 2，但 \(next[6]=3\)，要记得加 1。
2. 计算 \(next[j]\) 时看的是 \(P[1..j-1]\)，不是 \(P[1..j]\)，也不是整个模式串。
3. KMP 失配后主串指针 \(i\) 不能回退，只能令 \(j=next[j]\)。若 \(j=0\)，则下一轮 \(i++,\ j++\)。
4. 注意下标从 1 开始还是从 0 开始。本题按考研教材常见 1 起始下标；若用 C 风格 0 下标，\(next\) 数组形式一般会以 \(-1\) 开头。

**命题规律**：本题属于“字符串模式匹配”中的 KMP 算法，408 中常以选择题形式考查 \(next\) 与 \(nextval\) 数组计算，也可能结合匹配过程考查“匹配趟数”“比较次数”和“匹配位置”。常见变式有：求优化后的 \(nextval\)、给 \(next\) 数组反推模式串、比较朴素匹配与 KMP 的匹配次数等。复习时应熟练掌握 \(next\) 的手算递推方法，并注意区分“最长相等前后缀长度”和“失配后模式串指针的新位置”。KMP 的时间复杂度为 \(O(|S|+|P|)\)，这是相对暴力匹配 \(O(|S||P|)\) 的优势。

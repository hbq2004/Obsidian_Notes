## DeepSeek V4 Flash Max 解析

**答案**：本题网络可抽象为**带权连通无向图**；LSI 可采用“LSI 头结点链 + 每个 LSI 的链路结点链”的邻接表式链式存储。按 Dijkstra 算法，$R1$ 到各子网的最短费用依次为：$192.1.1.0/24$ 费用 $1$，$192.1.5.0/24$ 费用 $3$，$192.1.6.0/24$ 费用 $4$，$192.1.7.0/24$ 费用 $8$。

**解题切入点**：看到“OSPF + Metric + 最短路径”，应立即定位到数据结构中的**带权图单源最短路径**问题；看到“链式存储结构”，联想到图的**邻接表**或类似的多级链表。手算 Dijkstra 时先画出拓扑图，再从源点出发按“当前最小距离点”逐步松弛，不要被 IP 地址干扰。

**推演**：

### 1）逻辑结构

网络可抽象为**带权连通无向图**（简称“网”），其中：

- 顶点：路由器 $R_1,R_2,R_3,R_4$，以及它们直连的子网 $N_1,N_2,N_3,N_4$；
- 边：路由器之间的链路、路由器到直连子网的链路；
- 权值：OSPF 的 Metric。

对应关系为：

$$
R_1=10.1.1.1,\quad R_2=10.1.1.2,\quad R_3=10.1.1.5,\quad R_4=10.1.1.6
$$

$$
N_1=192.1.1.0/24,\quad N_2=192.1.6.0/24,\quad N_3=192.1.5.0/24,\quad N_4=192.1.7.0/24
$$

主要边权为：

$$
R_1-R_2:3,\quad R_1-R_3:2,\quad R_2-R_4:4,\quad R_3-R_4:6
$$

$$
R_i-N_i:1\quad (i=1,2,3,4)
$$

### 2）链式存储结构设计

可设计两级链表：第一级是**路由器的 LSI 结点链**，第二级是每个 LSI 内部的**链路信息结点链**。

```c
#define MAX_ID_LEN 20

typedef struct LinkNode {
    int type;               /* 1：路由器链路；2：直连网络 */
    char id[MAX_ID_LEN];    /* type=1：邻居Router ID；type=2：网络前缀 */
    char ip[MAX_ID_LEN];    /* 本地接口IP；type=2 时可空 */
    int metric;             /* 该链路费用 */
    struct LinkNode *next;  /* 同一 LSI 中的下一条链路信息 */
} LinkNode;

typedef struct LSINode {
    char routerID[MAX_ID_LEN];  /* 本路由器 Router ID */
    LinkNode *firstLink;        /* 指向 Link1/Link2/Net1 链 */
    struct LSINode *next;       /* 指向下一个路由器的 LSI */
} LSINode;

LSINode *LSIHead;
```

对应表的链式存储示意图可简化为（只标 ID 和费用）：

### 3）Dijkstra 算法求最短路径

Dijkstra 核心松弛操作为：

$$
d[v]=\min\{d[v],\ d[u]+w(u,v)\}
$$

初始时：

$$
d(R_1)=0,\quad d(R_2)=3,\quad d(R_3)=2,\quad d(N_1)=1
$$

其余结点距离为 $\infty$。

Dijkstra 过程可表示为：

| 步骤 | 确定结点 | 更新 |
|---|---|---|
| 初始 | $S=\{R_1\}$ | $d(R_2)=3,\ d(R_3)=2,\ d(N_1)=1$ |
| 1 | $N_1(1)$ | 无 |
| 2 | $R_3(2)$ | $d(R_4)=8,\ d(N_3)=3$ |
| 3 | $R_2(3)$ | $d(R_4)=7,\ d(N_2)=4$ |
| 4 | $N_3(3)$ | 不变 |
| 5 | $N_2(4)$ | 不变 |
| 6 | $R_4(7)$ | $d(N_4)=8$ |
| 7 | $N_4(8)$ | 完成 |

注意：第 3 步与第 4 步中 $R_2$ 和 $N_3$ 的距离同为 $3$，顺序可互换，不影响最终结果。

因此 $R1$ 到各子网的最短路径及费用为：

| 目的子网 | 最短路径 | 费用 |
|---|---|---|
| $192.1.1.0/24$ | $R_1$ 直连 $192.1.1.0/24$ | $1$ |
| $192.1.5.0/24$ | $R_1 \rightarrow R_3 \rightarrow 192.1.5.0/24$ | $3$ |
| $192.1.6.0/24$ | $R_1 \rightarrow R_2 \rightarrow 192.1.6.0/24$ | $4$ |
| $192.1.7.0/24$ | $R_1 \rightarrow R_2 \rightarrow R_4 \rightarrow 192.1.7.0/24$ | $8$ |

其中 $R_1 \rightarrow R_2 \rightarrow R_4 \rightarrow 192.1.7.0/24$ 的费用为：

$$
3+4+1=8
$$

而 $R_1 \rightarrow R_3 \rightarrow R_4 \rightarrow 192.1.7.0/24$ 的费用为：

$$
2+6+1=9
$$

所以 $R_4$ 所在子网应经过 $R_2$ 到达。

**易错点**：

1. **漏加直连网络费用**：例如 $192.1.6.0/24$ 的费用不是 $R_1$ 到 $R_2$ 的 $3$，而是 $3+1=4$。
2. **误以为 $R_4$ 走 $R_3$ 更近**：$R_1\rightarrow R_3\rightarrow R_4$ 的代价是 $2+6=8$，而 $R_1\rightarrow R_2\rightarrow R_4$ 的代价是 $3+4=7$，因此到 $R_4$ 应走 $R_2$。
3. **把 Router ID 和接口 IP 混淆**：LSI 中 `ID` 表示邻居路由器，`IP` 表示本地接口 IP；存储时应保留两个字段。
4. **忽略 Dijkstra 的松弛更新**：不能因为先算出 $d(R_4)=8$ 就不再更新，后来 $R_2$ 会把它更新为 $7$。
5. **存储结构中把 Link1/Link2 名称当全局编号**：不同路由器的 Link1 是不同的物理链路，必须根据 `ID/Prefix` 区分。

**命题规律**：该题将数据结构中的**图存储**和**Dijkstra 最短路径**与计算机网络中的 **OSPF 链路状态算法**结合命题，是 408 常考的综合题型。常见变式包括：给出邻接矩阵或邻接表手算 Dijkstra、求某路由器的转发表、求最小生成树等。复习时应重点掌握图的两种存储结构、Dijkstra 的初始化与松弛过程，并理解“链路状态信息 LSI”本质上是图的邻接表信息。

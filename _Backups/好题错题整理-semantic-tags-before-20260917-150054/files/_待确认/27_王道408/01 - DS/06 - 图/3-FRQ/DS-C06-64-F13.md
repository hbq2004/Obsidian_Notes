# 综合题 第 13 题

![[_Attachments/题目识别/27_王道408-题目/DS-C06-64-F13_题目.png|题目]]

13.【2024 统考真题】 2023 年 10 月 26 日,神舟十七号载人飞船发射取得圆满成功,再次彰显了中国航天事业的辉煌成就。载人航天工程是包含众多子工程的复杂系统工程, 为了保证工程的有序开展,需要明确各子工程的前导子工程, 以协调各子工程的实施。该问题可以简化、抽象为有向图的拓扑序列问题。已知有向图 $G$ 采用邻接矩阵存储, 类型定义如下。

```c
typedef struct {
    int numVertices,numEdges;        //图的类型定义
    char VerticesList[MAXV];         //图的顶点数和有向边数
    int Edge[MAXV][MAXV];            //顶点表, MAXV 为已定义常量
} MGraph;                            //邻接矩阵
```

请设计算法: int uniquely(MGraph G), 判定 $G$ 是否存在唯一的拓扑序列, 若是, 则返回 1, 否则返回 0。要求如下。
1) 给出算法的基本设计思想.
2) 根据设计思想, 采用 $C$ 或 $C++$ 语言描述算法, 关键之处给出注释.

## DeepSeek V4 Flash Max 解析

**答案**：用 Kahn 拓扑排序算法，在每次删除顶点前统计“未删除且入度为 0”的顶点数；若每一轮该数量都恰好为 1，则拓扑序列唯一，返回 1；否则返回 0。

**解题切入点**：看到“有向图 + 拓扑序列 + 唯一性”，应立刻定位到 Kahn 算法。拓扑序列唯一不能只看初始入度为 0 的顶点个数，而要持续检查删除过程中每一轮“候选源点”的数量。可以类比走单岔路口：每一步如果只有一个可走方向，路线才唯一；一旦出现两个或两个以上可选方向，就一定存在分支。

**推演**：

### 1. 基本设计思想

设 $n=G.numVertices$。用 `indegree[i]` 表示顶点 $i$ 当前（在剩余图中）的入度，用 `removed[i]` 表示顶点 $i$ 是否已被删除。

拓扑排序过程中，任何入度为 0 的顶点都可以作为当前拓扑序列的下一个顶点。因此：

- 若当前入度为 0 的未删除顶点数 $cnt=0$，说明剩余图中没有源点，必存在环，不存在拓扑序列；
- 若 $cnt\ge 2$，说明有多个顶点都没有前驱约束，它们可以交换顺序，拓扑序列不唯一；
- 只有当 $cnt=1$ 时，当前步的选择才是被迫的、唯一的。

所以算法每轮检查一次 $cnt$，若 $cnt\ne 1$ 直接返回 0，否则删除这个唯一的源点，并将其所有后继的入度减 1。若能执行完 $n$ 轮，就说明拓扑序列唯一。

### 2. C 语言算法描述

```c
int uniquely(MGraph G) {
    int indegree[MAXV] = {0};   // 记录入度
    int removed[MAXV] = {0};    // 标记顶点是否已被删除
    int n = G.numVertices;
    int i, j, u, cnt, t;

    // 由邻接矩阵求所有顶点的入度
    // Edge[i][j] == 1 表示存在有向边 i -> j
    for (i = 0; i < n; i++) {
        for (j = 0; j < n; j++) {
            if (G.Edge[i][j] == 1) {
                indegree[j]++;
            }
        }
    }

    // 每一轮删除一个入度为0且未删除的顶点
    for (t = 0; t < n; t++) {
        cnt = 0;
        u = -1;

        // 统计当前入度为0的未删除顶点数
        for (i = 0; i < n; i++) {
            if (!removed[i] && indegree[i] == 0) {
                cnt++;
                u = i;
            }
        }

        // cnt == 0：有环；cnt >= 2：拓扑序不唯一
        if (cnt != 1) {
            return 0;
        }

        // 删除唯一源点u
        removed[u] = 1;

        // 删除u后，u的所有后继入度减1
        for (j = 0; j < n; j++) {
            if (G.Edge[u][j] == 1) {
                indegree[j]--;
            }
        }
    }

    // 所有顶点均被删除，说明存在唯一拓扑序列
    return 1;
}
```

### 3. 正确性证明

设当前剩余顶点集合为 $R$，当前入度为 0 的顶点集合为

$$
S=\{v\in R \mid \mathrm{indeg}(v)=0\}.
$$

在拓扑排序中，$S$ 中的顶点都可以作为下一个输出顶点。

- 若 $|S|=0$，则 $R$ 中每个顶点入度都大于 0。对有限有向图来说，没有入度为 0 的顶点意味着图中存在环，因此不存在拓扑序列。
- 若 $|S|\ge 2$，任取 $u,v\in S$。因为 $u$ 的入度为 0，所以不可能有边 $v\to u$；同理也不可能有边 $u\to v$。也就是说 $u,v$ 之间没有先后约束，二者可以交换顺序，因此拓扑序列不唯一。
- 若 $|S|=1$，当前顶点被唯一确定，无法选择。

因此算法每一轮都检查 $|S|$ 是否等于 1。若每一轮都等于 1，则每一步都是被迫的，最终得到唯一拓扑序列；若某一步不等于 1，则要么无拓扑序列，要么拓扑序列不唯一，均应返回 0。

### 4. 复杂度分析

- 时间：求入度需扫描整个邻接矩阵，$O(n^2)$；每轮扫描所有顶点统计入度为 0 的顶点，共 $n$ 轮，$O(n^2)$；删除顶点时扫描对应行，总共 $O(n^2)$。因此总时间复杂度为 $O(n^2)$。
- 空间：`indegree` 和 `removed` 两个数组，均为 $O(n)$。

**易错点**：

1. **只检查初始入度为 0 的顶点数**。例如图 $A\to B,\ A\to C,\ B\to D,\ C\to D$，初始只有一个源点 $A$，但删除 $A$ 后 $B,C$ 同时入度为 0，拓扑序列仍不唯一。因此必须每轮检查。
2. **忘记判环**。若当前入度为 0 的顶点数为 0，说明剩余图中有环，不存在拓扑序列。此时不能继续，应返回 0。
3. **用 DFS 后序判断唯一性**。DFS 拓扑排序的结果可能受顶点扫描顺序影响，不能简单判断唯一性；应使用 Kahn 算法中的“候选源点集合大小”来判断。
4. **更新入度时方向写反**。邻接矩阵中应使用 `G.Edge[u][j]`，即从被删除顶点 $u$ 出发的出边；若误写成 `G.Edge[j][u]`，会错误更新前驱的入度。
5. **使用队列实现时忘记检查输出顶点数**。若图中存在环，队列可能提前为空，必须保证最终输出的顶点数等于 $n$ 才能返回 1。

**命题规律**：本题是 2024 年统考真题，考查“拓扑排序唯一性”这一重要变式。核心考点仍是 Kahn 算法，但将航天工程背景抽象为有向图，考查考生对“入度为 0 的候选顶点集合大小”与“拓扑序唯一性”之间关系的理解。常见变式包括：判断有向图是否有环、输出任意拓扑序列、判断唯一拓扑序列、求关键路径等。复习时应熟练掌握邻接矩阵和邻接表两种存储方式下的拓扑排序实现，并能说明算法正确性与复杂度。唯一拓扑序还可等价理解为：拓扑序列中任意相邻两点之间都必须存在有向边，也就是图中存在一条覆盖所有顶点的有向路径。

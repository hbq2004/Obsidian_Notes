1. 图$G=(V,E)$以邻接表存储，如下图所示，试画出图$G$的深度优先生成树和广度优先生成树（假设从顶点1开始遍历）.

| ---- | ---- |
| 1 | 2 → 3 → 4 ∧ |
| 2 | 1 → 3 → 4 → 5 ∧ |
| 3 | 1 → 2 → 4 ∧ |
| 4 | 1 → 2 → 3 → 5 ∧ |

## DeepSeek V4 Flash Max 解析

**答案**：按给定邻接表从顶点 $1$ 开始遍历，深度优先生成树为链 $1-2-3-4-5$，其边集为 $T_{\mathrm{DFS}}=\{(1,2),(2,3),(3,4),(4,5)\}$；广度优先生成树以 $1$ 为根，$2,3,4$ 为 $1$ 的孩子，$5$ 为 $2$ 的孩子，其边集为 $T_{\mathrm{BFS}}=\{(1,2),(1,3),(1,4),(2,5)\}$。

**解题切入点**：看到“邻接表 + 从顶点 1 开始遍历 + 生成树”，应定位到图的 DFS/BFS。关键不是输出顶点访问序列，而是记录每条“第一次发现未访问顶点的边”。可将 DFS 想象成走迷宫“一条道走到黑，撞墙再回头”，BFS 想象成水面波纹“一圈圈扩散”；邻接表的链表顺序就是每一步的候选顺序，必须严格按题给顺序模拟。

**推演**：

由邻接表可见每条边成对出现，所以 $G$ 是无向连通图，边集为  
$$E=\{(1,2),(1,3),(1,4),(2,3),(2,4),(2,5),(3,4),(4,5)\}.$$

因为 $|V|=5$，生成树应有 $|V|-1=4$ 条边。

**DFS 过程**：

1. 访问 $1$，从 $1$ 的邻接表取第一个未访问点 $2$，树边 $(1,2)$，进入 $2$。
2. 在 $2$，$1$ 已访问，取 $3$，树边 $(2,3)$，进入 $3$。
3. 在 $3$，$1,2$ 已访问，取 $4$，树边 $(3,4)$，进入 $4$。
4. 在 $4$，$1,2,3$ 已访问，取 $5$，树边 $(4,5)$，进入 $5$。
5. 在 $5$，邻接点 $2,4$ 已访问，回溯；之后各级回溯均无新的未访问点。

注意：当回溯到 $2$ 时，$5$ 已经在 $4$ 的子树中被访问，所以 $(2,5)$ 是回边而非树边。

DFS 生成树：

```text
1 — 2 — 3 — 4 — 5
```

**BFS 过程**：

1. 访问 $1$；按邻接表 $1:2\to3\to4$，依次发现 $2,3,4$，树边为 $(1,2),(1,3),(1,4)$，将 $2,3,4$ 入队。
2. 出队 $2$；$1,3,4$ 已访问，发现 $5$，树边 $(2,5)$，$5$ 入队。
3. 出队 $3$；邻接点 $1,2,4$ 已访问。
4. 出队 $4$；邻接点 $1,2,3,5$ 已访问。
5. 出队 $5$；邻接点 $2,4$ 已访问。

由于 $2$ 比 $4$ 先出队，所以 $5$ 由 $2$ 发现，$(4,5)$ 不是树边。

BFS 生成树：

```text
      1
    / | \
   2  3  4
   |
   5
```

对应记录树边的核心代码思路：

```cpp
void DFS(int v) {
    visited[v] = true;
    for (w : adj[v])           // 按邻接表顺序
        if (!visited[w]) {
            把(v,w)加入生成树;  // 树边
            DFS(w);             // 深入
        }
}

// BFS 从顶点 1 出发：
visited[1] = true;
queue q; q.push(1);
while (q 非空) {
    v = q.front(); q.pop();
    for (w : adj[v]) {
        if (!visited[w]) {
            visited[w] = true;  // 入队时置 true，防止重复入队
            把(v,w)加入生成树;
            q.push(w);
        }
    }
}
```

**易错点**：

- **不要把访问序列当生成树**：本题 DFS 和 BFS 的顶点访问序列都是 $1,2,3,4,5$，但两棵生成树不同；要比较的是树边。
- **不要忽略邻接表顺序**：若改变邻接表顺序，DFS/BFS 生成树可能改变；必须按题给顺序模拟。
- **不要把非树边画入生成树**：生成树只能有 $|V|-1=4$ 条边；例如 DFS 中的 $(2,5)$、BFS 中的 $(4,5)$ 都不能出现在树中。
- **BFS 中 visited 应在入队时置 true**：否则会把已在队列中的顶点当成未访问，造成重复入队和错误树边。
- **不要与最小生成树混淆**：本题无权重，树边由 DFS/BFS 首次访问确定，与 Prim、Kruskal 无关。

**命题规律**：本题属于“图的遍历”基础考点。408 中常见变式有：给邻接表或邻接矩阵求 DFS/BFS 遍历序列、求生成树或生成森林、判断某序列是否可能是 DFS/BFS 序列、用 DFS/BFS 求连通分量等。复习时应熟练掌握递归栈/队列的模拟过程，并记住“树边 = 首次访问新顶点时的边”。邻接表下 DFS/BFS 时间复杂度为 $O(|V|+|E|)$，邻接矩阵下为 $O(|V|^2)$。

# 综合题 第 11 题

![[_Attachments/题目识别/27_王道408-题目/DS-C06-64-F11_题目.png|题目]]

11.【2017统考真题】使用 Prim 算法求带权连通图的最小 (代价) 生成树 ($MST$)。请回答下列问题:

【图：无向带权连通图，顶点为A、B、C、D、E，边及权重：A-B(6)、A-E(5)、A-C(4)、B-C(4)、C-E(5)、C-D(6)、D-E(4)】

1) 对上图 $G$, 从顶点 $A$ 开始求 $G$ 的 $MST$, 依次给出按算法选出的边。

2) 图 $G$ 的 $MST$ 是唯一的吗?

3) 对任意的带权连通图，满足什么条件时，其 $MST$ 是唯一的?

## DeepSeek V4 Flash Max 解析

**答案**：从 $A$ 开始用 Prim 算法，可选出边 $(A,C),(B,C),(A,D),(D,E)$ 或 $(A,C),(B,C),(A,E),(D,E)$，总权值均为 $14$；该图 $MST$ 不唯一；一般地，所有边权互不相等时 $MST$ 唯一。

**解题切入点**：  
Prim 算法是“贪心 + 已选集合扩展”：维护一个已选入生成树的顶点集合 $U$，每一步只在 **跨越 $U$ 与 $V-U$ 的边** 中选权值最小的边加入。拿到题先列出所有边权，再从起点 $A$ 出发模拟；判断 $MST$ 是否唯一，则看是否存在“同权可替换”的边。

**推演**：  

按 2017 年原题图，边权为：
\[
w(AB)=6,\ w(AC)=1,\ w(AD)=5,\ w(AE)=5,\ w(BC)=4,\ w(CD)=6,\ w(DE)=4.
\]

Prim 算法过程如下：

| 当前树中顶点集合 $U$ | 候选横切边 | 选中边 |
|---|---|---|
| $\{A\}$ | $(A,B,6),(A,C,1),(A,D,5),(A,E,5)$ | $(A,C,1)$ |
| $\{A,C\}$ | $(A,B,6),(A,D,5),(A,E,5),(B,C,4),(C,D,6)$ | $(B,C,4)$ |
| $\{A,B,C\}$ | $(A,D,5),(A,E,5),(C,D,6)$ | $(A,D,5)$ 或 $(A,E,5)$ |
| 若选 $(A,D,5)$：$\{A,B,C,D\}$ | $(A,E,5),(C,D,6),(D,E,4)$ | $(D,E,4)$ |
| 若选 $(A,E,5)$：$\{A,B,C,E\}$ | $(A,D,5),(C,D,6),(D,E,4)$ | $(D,E,4)$ |

所以 Prim 的合法输出有两种：
\[
(A,C),(B,C),(A,D),(D,E)
\]
或
\[
(A,C),(B,C),(A,E),(D,E).
\]

两棵生成树的总权值都是：
\[
1+4+5+4=14.
\]

因此图 $G$ 的 $MST$ **不唯一**。也可用割性质说明：割 $\{A\}$ 的唯一最小边是 $(A,C)$，割 $\{B\}$ 的唯一最小边是 $(B,C)$，割 $\{D\}$（或 $\{E\}$）的唯一最小边是 $(D,E)$，所以任何 $MST$ 必含这三条边；剩下连接两个连通分量时，$(A,D)$ 和 $(A,E)$ 同为最小，于是产生两种 $MST$。

关键代码思路：

```text
U = {A}; T = 空集;
while |T| < n-1:
    在边集 { (u,v) | u∈U, v∉U } 中取权值最小的边 (u,v);
    U = U ∪ {v};
    T = T ∪ {(u,v)};
```

用最小堆维护横切边可将复杂度优化到 $O(E\log V)$。

第三问：对任意带权连通图，**当所有边的权值互不相同时**，Prim 每一步的最小横切边都唯一，因此 $MST$ 唯一。这是考试常用的充分条件。严格地说，它并不是必要条件；更精确的充要判据是：任取一棵 $MST$ $T$，对每条非树边 $e=(u,v)$，都有
\[
w(e)>\max\{w(f)\mid f\in P_T(u,v)\},
\]
其中 $P_T(u,v)$ 是 $T$ 中 $u$ 到 $v$ 的路径。否则若 $w(e)$ 等于该路径上的最大边权，就可以替换得到另一棵等权 $MST$。

**易错点**：  
1. Prim 只能选“一端在 $U$、一端不在 $U$”的横切边。例如在 $U=\{A,B,C\}$ 时，$(D,E)$ 的权值虽然只有 $4$，但 $D,E$ 都不在 $U$ 中，不能马上选。  
2. 不要把 Prim 和 Kruskal 混淆：Kruskal 全局排序选边，本题 Kruskal 会先选 $(A,C),(B,C),(D,E)$，再在 $(A,D)$ 与 $(A,E)$ 中选一条，输出顺序与 Prim 不同。  
3. 不要认为“有权值相同的边，$MST$ 一定不唯一”；只有同权边能替换时才会出现多棵 $MST$。  
4. 题目未规定平局策略时，$(A,D)$ 和 $(A,E)$ 任选其一都正确，不要只写一种而否定另一种。

**命题规律**：  
考点是 Prim 算法求 $MST$、$MST$ 唯一性判断、割与环性质。常见变式有：用 Kruskal 算法重做、求 $MST$ 总权值、改变某条边的权值后判断唯一性、判断某个生成树是否为 $MST$。复习时应熟练掌握 Prim 与 Kruskal 的贪心选择过程，并能用“同权替换”解释 $MST$ 是否唯一。

# 选择题 第 4 题

![[_Attachments/题目识别/27_王道408-题目/DS-C06-62-M04_题目.png|题目]]

4. 带权有向图 $G$ 用邻接矩阵存储，则 $v_i$ 的入度等于邻接矩阵中（ ）.
(A) 第 $i$ 行非 $\infty$ 的元素个数
(B) 第 $i$ 列非 $\infty$ 的元素个数
(C) 第 $i$ 行非 $\infty$ 且非 $0$ 的元素个数
(D) 第 $i$ 列非 $\infty$ 且非 $0$ 的元素个数

## DeepSeek V4 Flash Max 解析

**答案**：选 D。顶点 \(v_i\) 的入度等于邻接矩阵中第 \(i\) 列里非 \(\infty\) 且非 0 的元素个数。

**解题切入点**：拿到题先明确邻接矩阵的行、列语义：行表示“起点”，列表示“终点”。入度是“有多少条边指向 \(v_i\)”，所以必须看第 \(i\) 列；再看带权图，矩阵中 \(\infty\) 表示无边，0 常作对角线占位，需要同时排除。

**推演**：设带权有向图 \(G=(V,E)\) 的邻接矩阵为 \(A=(a_{ij})_{n\times n}\)。按教材常见约定，有
\[
a_{ij}=
\begin{cases}
w_{ij}, & \langle v_i,v_j\rangle\in E,\\[2mm]
0, & i=j\ \text{且无自环},\\[2mm]
\infty, & \langle v_i,v_j\rangle\notin E,\ i\ne j.
\end{cases}
\]
其中 \(w_{ij}\) 是边 \(\langle v_i,v_j\rangle\) 的权值。

对于顶点 \(v_i\)，所有可能的入边形如 \(\langle v_j,v_i\rangle\)，它们在矩阵中存放在第 \(j\) 行第 \(i\) 列，也就是第 \(i\) 列。因此：
\[
\mathrm{ID}(v_i)=\bigl|\{j: a_{ji}\ne \infty \text{ 且 } a_{ji}\ne 0\}\bigr|.
\]
也就是说，统计邻接矩阵第 \(i\) 列中非 \(\infty\) 且非 0 的元素个数，即为 \(v_i\) 的入度。

**易错点**：
1. 选 B：只排除 \(\infty\)，会把对角线上的 0 也误认为一条入边，导致入度多 1。
2. 选 A 或 C：把第 \(i\) 行当成入度；实际上第 \(i\) 行表示从 \(v_i\) 出发的边，统计的是出度。
3. 忽略“带权图”背景：矩阵中存的是权值而不是简单 0/1，统计入度时数的是“有效边的条数”，不是权值之和。
4. 若题目没有特别说明，一般默认图中无自环；若有自环且权值非 0，则它也应计入入度一次。

**命题规律**：本题属于图的存储结构中的高频基础题，核心是邻接矩阵行、列与出度、入度的对应关系。常见变式包括：求第 \(i\) 行非 \(\infty\) 非 0 元素个数为出度；无向图中第 \(i\) 行非 0 元素个数为度；邻接表、逆邻接表统计入度的时间复杂度；十字链表如何快速求入度和出度等。复习时建议自己画一个带权有向图，写出邻接矩阵，分别核对每个顶点的入度、出度，特别注意对角线、\(\infty\) 和 0 的边界情况。

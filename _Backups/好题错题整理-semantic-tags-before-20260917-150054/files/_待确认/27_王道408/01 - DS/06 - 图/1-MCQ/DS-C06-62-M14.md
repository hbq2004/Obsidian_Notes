# 选择题 第 14 题

![[_Attachments/题目识别/27_王道408-题目/DS-C06-62-M14_题目.png|题目]]

14. 假设有 $n$ 个顶点、 $e$ 条边的有向图用邻接表表示, 则删除与某个顶点 $v$ 相关的所有边的时间复杂度为 ( ).
A. $O(n)$
B. $O(e)$
C. $O(n+e)$
D. $O(ne)$

## DeepSeek V4 Flash Max 解析

**答案**：选 **C，$O(n+e)$**。  
核心原因是：有向图的邻接表只存储“出边”，删除与顶点 $v$ 相关的所有边，既要删除 $v$ 的出边，也要删除所有指向 $v$ 的入边；而入边分散在其他顶点的链表中，必须遍历整个邻接表。

**解题切入点**：拿到题先分清“相关边”在无向图和有向图中的含义。无向图中，删 $v$ 的边可以直接处理 $v$ 的邻接表；但这是**有向图**，邻接表只记录了“从每个顶点出发的边”。所以“谁指向 $v$”这种入边信息无法从 $v$ 直接得到。  
可以理解为翻通讯录：$v$ 打给谁，查 $v$ 的通讯录即可；但谁打给 $v$，必须翻遍所有人的通讯录。因此代价是：$n$ 个表头 $+$ 总共 $e$ 条边，即 $O(n+e)$。

**推演**：

设 $d^+(v)$ 为顶点 $v$ 的出度。邻接表中共有 $n$ 个表头结点、$e$ 个边结点，每条有向边 $(u,w)$ 只作为边结点存储在顶点 $u$ 的链表中。

删除与 $v$ 相关的所有边，分两步：

1. **删除 $v$ 的出边**  
   遍历顶点 $v$ 的边链表，释放所有从 $v$ 出发的边结点。  
   时间复杂度为：
   $$
   O(d^+(v))
   $$

2. **删除指向 $v$ 的入边**  
   所有以 $v$ 为终点的边，都存储在其他顶点的链表中，例如边 $(u,v)$ 存放在 $u$ 的链表中。因此必须扫描所有 $n$ 个顶点表头，并检查其中的边结点。  
   所有链表的边结点总数正好是 $e$，所以这一步时间复杂度为：
   $$
   O(n+e)
   $$

总时间复杂度为：
$$
O(d^+(v)) + O(n+e) = O(n+e)
$$

关键代码思路如下：

```c
// 1. 删除 v 的所有出边
p = G.vertices[v].firstarc;
while (p != NULL) {
    q = p;
    p = p->next;
    free(q);
}
G.vertices[v].firstarc = NULL;

// 2. 删除所有指向 v 的入边
for (i = 0; i < G.vexnum; i++) {
    pre = NULL;
    cur = G.vertices[i].firstarc;
    while (cur != NULL) {
        if (cur->adjvex == v) {
            if (pre == NULL)
                G.vertices[i].firstarc = cur->next;
            else
                pre->next = cur->next;
            q = cur;
            cur = cur->next;
            free(q);
        } else {
            pre = cur;
            cur = cur->next;
        }
    }
}
```

外层循环访问 $n$ 个表头，内层循环总共访问 $e$ 个边结点，所以整体为 $O(n+e)$。

**易错点**：

- 只删除 $v$ 的出边，忽略入边，会误选 **B**。  
  但题目问的是“与 $v$ 相关的所有边”，必须包含入边。
- 把有向图的邻接表当成无向图的邻接表，以为每条边出现两次，误以为只需处理 $v$ 的链表。  
  有向图邻接表中每条边只存储一次。
- 误选 **D**，以为“每个顶点都要看所有边”是 $O(ne)$。  
  实际上所有顶点的邻接表边结点总数就是 $e$，不是每个顶点都有 $e$ 条边。
- 忽略 $n$ 这个因素，误认为 $O(e)$ 即可。  
  如果 $e=0$，仍要检查 $n$ 个空表头，所以保留 $O(n+e)$ 更严谨。

**命题规律**：  
这是 408 中“图的存储结构 + 图的基本操作复杂度”的经典考点。常见变式有：

- 邻接矩阵表示有向图，删除与 $v$ 相关的所有边，只需清空第 $v$ 行和第 $v$ 列，时间复杂度为 $O(n)$；
- 邻接表表示无向图，删除顶点 $v$ 及其关联边，需要遍历 $v$ 的邻接表并修改其他顶点的链表；
- 若题目改成“只删除从 $v$ 出发的边”，则只需 $O(d^+(v))$，但这不是本题。  

复习时要画图对比邻接矩阵、邻接表、逆邻接表等结构，重点掌握“出边能否直接找、入边能否直接找”的定位能力，再按“访问表头数 + 边结点数”统计复杂度。

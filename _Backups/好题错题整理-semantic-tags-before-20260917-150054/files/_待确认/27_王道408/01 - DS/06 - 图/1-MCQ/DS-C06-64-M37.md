A. 1,5,2,3,6,4

## DeepSeek V4 Flash Max 解析

**答案**：选 D。序列 \(5,2,1,6,3,4\) 不是拓扑序列，因为图中存在边 \(1\to2\)，要求 \(1\) 排在 \(2\) 之前，但该序列中 \(2\) 排在 \(1\) 前面。

**解题切入点**：  
拿到本题先不要枚举所有拓扑序列，而要把每条有向边看成“先后约束”。判断一个给定序列是否为拓扑序列，最直接的方法是：对每条边 \(u\to v\)，检查 \(u\) 是否在该序列中出现在 \(v\) 之前。这类似于“先修课程”约束：必须先修 \(u\)，才能修 \(v\)。本题选项中 C 和 D 很像，可优先比较：C 是 \(5,1,2\)，D 是 \(5,2,1\)，而图中有 \(1\to2\)，所以 D 很可能非法。

**推演**：  
由题图可得有向边为
\[
E=\{(1,2),(1,3),(2,3),(2,4),(2,6),(5,2),(6,4)\}.
\]

设给定序列为 \(p=(p_1,p_2,\dots,p_6)\)，记 \(\operatorname{pos}(x)\) 为顶点 \(x\) 在序列中的位置。则 \(p\) 是拓扑序列当且仅当
\[
\forall (u,v)\in E,\quad \operatorname{pos}(u)<\operatorname{pos}(v).
\]

逐项检查：

- A：\(1,5,2,3,6,4\)  
  所有边 \(u\to v\) 都满足 \(\operatorname{pos}(u)<\operatorname{pos}(v)\)，合法。

- B：\(5,1,2,6,3,4\)  
  逐边检查也均满足，例如 \(1\to2\) 中 \(1\) 在 \(2\) 前，\(6\to4\) 中 \(6\) 在 \(4\) 前，合法。

- C：\(5,1,2,3,6,4\)  
  同样满足所有边的前后约束，合法。

- D：\(5,2,1,6,3,4\)  
  对边 \(1\to2\)，有
  \[
  \operatorname{pos}(1)=3,\qquad \operatorname{pos}(2)=2,
  \]
  因此
  \[
  \operatorname{pos}(1)>\operatorname{pos}(2),
  \]
  不满足 \(1\) 在 \(2\) 之前的要求，所以 D 不是拓扑序列。

也可用 Kahn 算法验证：初始入度为 0 的顶点是 \(1\) 和 \(5\)。D 先取 \(5\) 合法；但删除 \(5\) 后，顶点 \(2\) 的入度仍为 1（来自 \(1\)），所以第二项不能取 \(2\)，只能取 \(1\)。因此 D 错误。

**易错点**：  
- 不要只检查相邻元素是否满足边关系。D 中 \(5\to2\) 是相邻且满足的，但真正错误的是隐藏在后面的 \(2\) 与 \(1\) 的相对顺序。  
- 不要把顶点编号大小当作拓扑顺序。拓扑序只由边的方向决定，例如 B 中 \(1\) 在 \(5\) 后仍然合法，因为 \(1\) 和 \(5\) 之间没有必须谁先谁后的边。  
- 使用 Kahn 算法时要记得删除顶点后更新其后继的入度，否则会误判某个顶点是否可输出。

**命题规律**：  
本题属于“图的应用——拓扑排序”，是 408 选择题的常考点。常见变式有：判断给定序列是否为拓扑序列、用 Kahn 算法模拟输出、判断拓扑序列是否唯一、检测有向图是否存在环，以及与 AOV 网、关键路径结合考查。复习时应熟练掌握 Kahn 算法和 DFS 拓扑排序，并学会用“位置数组逐边检查”的方法快速判断一个给定序列是否合法。

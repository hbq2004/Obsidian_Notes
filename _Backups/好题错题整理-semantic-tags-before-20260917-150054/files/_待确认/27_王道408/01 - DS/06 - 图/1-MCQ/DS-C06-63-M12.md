## DeepSeek V4 Flash Max 解析

**答案**：选 C。判断有向图中是否存在回路，除拓扑排序外，还可利用深度优先遍历算法（DFS），核心是：DFS 过程中若出现“后向边/回边”，即遇到某个仍在当前递归栈中的顶点，则说明有向图中存在回路。

**解题切入点**：拿到题目先定位考点：有向图判环。常见判环手段有两个：一是拓扑排序，二是 DFS 后向边。选项中的 Dijkstra 算法是求最短路径的，与判环无关；求关键路径的方法本身以有向无环图（DAG）为前提，且其内部仍依赖拓扑排序，不是独立的判环手段；普通 BFS 遇到已访问顶点也不能直接判定有向图有环。因此锁定 DFS。

**推演**：  
设图为 $G=(V,E)$，对每个顶点用三种颜色标记其 DFS 状态：

- $0$：未访问；
- $1$：已访问，但尚未结束，仍在当前递归栈中；
- $2$：已访问，且已结束返回。

DFS 判环的核心代码如下：

```
DFS(u):
    color[u] = 1
    for v in Adj[u]:
        if color[v] == 0:
            if DFS(v) == true:
                return true
        else if color[v] == 1:
            return true      # 发现后向边
    color[u] = 2
    return false

for u in V:
    if color[u] == 0:
        if DFS(u) == true:
            return true      # 有环
return false                 # 无环
```

为什么后向边等价于有向环？

- 若 DFS 发现边 $(u,v)$，且 $v$ 的状态为 $1$，则 $v$ 是 $u$ 在 DFS 树中的祖先，即存在路径 $v \leadsto u$。再加上边 $u \to v$，就形成回路：

$$
v \to \cdots \to u \to v
$$

- 反过来，若图中存在有向环 $v_1 \to v_2 \to \cdots \to v_k \to v_1$，在 DFS 过程中，环上第一个被访问的顶点一定还在递归栈中。沿环搜索时，必然会遇到一条指向该祖先顶点的边，即发现后向边，从而判定有环。

因此，DFS 判环是正确且完备的。

其他选项：

- A 求关键路径的方法：关键路径法本身要求图是 DAG，若图中有环，则无法完成关键路径计算。但它不是独立的判环算法，实际仍依赖拓扑排序判断。
- B Dijkstra 算法：用于求单源最短路径，即使图中存在正权环，Dijkstra 仍可运行，不能判环。
- D 广度优先遍历算法：普通 BFS 遇到已访问顶点可能是因为横叉边，不一定有环。例如 $1 \to 2$、$1 \to 3$、$2 \to 3$ 的 DAG 中，BFS 到 $2 \to 3$ 时，$3$ 已访问，但图无环，因此 BFS 不能直接判断有向图回路。

**易错点**：

1. 不要把“已访问”直接等同于“有环”。DFS 判环必须区分“访问中”和“已结束”；只用一个布尔 visited 数组会误判 DAG。
2. 有向图和无向图判环判据不同。无向图 BFS/DFS 遇到已访问且非父边的顶点可判环；有向图必须找后向边，普通 BFS 不可直接使用。
3. 必须从每个未访问顶点都执行 DFS，否则可能漏掉不连通部分中的环。
4. 不要把 Dijkstra 算法与判环混淆，Dijkstra 不涉及环检测。

**命题规律**：本题考查有向图判环方法，属于图论基本概念题，也常与拓扑排序、DFS 边分类结合命题。常见变式有：

- 拓扑排序输出顶点数小于图顶点数，说明图中有环；
- DFS 生成树中存在后向边，说明有向图有环；
- 求关键路径前必须保证 AOE 网无环；
- 判断无向图是否有环可用 DFS、BFS 或并查集，但有向图判环通常用拓扑排序或 DFS 后向边。

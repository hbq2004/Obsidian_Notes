# 选择题 第 15 题

![[_Attachments/题目识别/27_王道408-题目/DS-C06-64-M15_题目.png|题目]]

15. 若一个有向图的顶点不能排成一个拓扑序列,则判定该有向图( ).

(A) 含有多个出度为0的顶点
(B) 是个强连通图
(C) 含有多个入度为0的顶点
(D) 含有顶点数大于1的强连通分量

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C06-64-M15_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 D。该有向图无法拓扑排序，说明它不是有向无环图（DAG），必有有向环；有向环上的顶点互相可达，因此至少含有一个顶点数大于 1 的强连通分量。

**解题切入点**：看到“拓扑序列”要立刻想到其充要条件：  
$$ \text{有向图可拓扑排序} \iff \text{该有向图无环，即为 DAG。} $$  
不能拓扑排序，说明存在“循环依赖”。可以类比工程中的课程先修关系：如果 A 依赖 B、B 又依赖 A，就无法排出合法顺序；这些互相依赖的点一定属于同一个“强连通团体”，且人数大于 1。不要被“入度为 0”“出度为 0”这些 Kahn 算法中的表面现象带偏。

**推演**：

1. **先证明：可拓扑排序 $\iff$ 无有向环。**

   - 若有有向环 $v_1\to v_2\to\cdots\to v_k\to v_1$，则拓扑序中必须同时满足  
     $$v_1 \text{ 在 } v_2 \text{ 前},\ v_2 \text{ 在 } v_3 \text{ 前},\ldots,\ v_k \text{ 在 } v_1 \text{ 前},$$  
     形成循环矛盾，所以不可能存在拓扑序列。

   - 若一个有向图无环，则由 Kahn 算法思想：每个非空 DAG 至少存在一个入度为 0 的顶点。不断删除入度为 0 的顶点，删除顺序就是一个拓扑序列。

   因此，题设“不能排成拓扑序列”等价于“有向图中有有向环”。

2. **有向环必然落在顶点数大于 1 的强连通分量中。**

   设该有向环为  
   $$
   C:\ v_1\to v_2\to\cdots\to v_k\to v_1,\quad k\ge2.
   $$
   按 408 默认的简单有向图理解，不考虑自环，所以环长至少为 2。

   对于环上任意两个顶点 $v_i,v_j$，沿环的方向从 $v_i$ 出发一定可以到达 $v_j$，从 $v_j$ 出发也一定可以到达 $v_i$。因此环上所有顶点两两互相可达，它们同属于一个强连通分量 $S$，且  
   $$
   |S|\ge k>1.
   $$

3. **排除其他选项：**

   - A 错：如 $1\to2,\ 2\to1$ 构成有向环，不能拓扑排序，但没有出度为 0 的顶点。
   - B 错：如 $1\to2,\ 2\to1,\ 2\to3$ 不能拓扑排序，但 3 不能到达 1、2，所以整个图不是强连通图。
   - C 错：如 $1\to2,\ 2\to1$ 不能拓扑排序，但没有任何入度为 0 的顶点，更谈不上“多个”。

因此，必然正确的是 D。

**易错点**：

- 误选 B：有环不等于全图强连通。环上的顶点只是“局部强连通”，环外顶点不一定能互相到达。
- 误选 A/C：入度为 0 或出度为 0 只是拓扑排序过程中的表面现象。多个入度为 0 的有向无环图仍能拓扑排序；有环图也可能没有入度/出度为 0 的顶点。
- 对强连通分量理解不清：单个顶点本身也构成一个强连通分量，但它不一定导致拓扑排序失败。导致失败的是包含有向环的“非平凡”强连通分量，即顶点数大于 1 的强连通分量。

**命题规律**：

本题核心考点是“拓扑排序与有向图判环”以及“有向环与强连通分量的关系”。常见变式有：

- 用 Kahn 算法判断有向图能否拓扑排序：若最终仍有顶点剩余，说明有环。
- 用 DFS 判断有向图是否有环：若 DFS 过程中遇到“回边”，则有环。
- 结合强连通分量缩点：缩点后得到 DAG，可在缩点图上再求拓扑序。

复习时应牢记：  
$$
\text{拓扑排序存在} \iff \text{有向无环图} \iff \text{不存在有向环} \iff \text{不存在顶点数大于 1 的强连通分量（默认无自环）}。
$$

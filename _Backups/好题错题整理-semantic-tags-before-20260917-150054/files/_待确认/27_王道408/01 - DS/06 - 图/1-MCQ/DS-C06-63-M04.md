## DeepSeek V4 Flash Max 解析

**答案**：邻接表表示图时，$DFS$ 的时间复杂度为 $O(n+e)$，空间复杂度为 $O(n)$；$BFS$ 的时间复杂度为 $O(n+e)$，空间复杂度为 $O(n)$。对应选项依次为：**C、A、C、A**。

**解题切入点**：先定位考点：**图的遍历复杂度分析**。核心抓住两点：  
1. 每个顶点最多被访问一次；  
2. 遍历过程中，每个顶点的邻接表会被扫描一次。  
邻接表的总规模是 $O(n+e)$，所以遍历总时间一定含 $O(n+e)$ 这一项。空间复杂度则看辅助结构：$DFS$ 的递归栈（或显式栈）、$BFS$ 的队列，以及 $visited$ 数组，规模都与顶点数 $n$ 有关，因此为 $O(n)$。

**推演**：

### 一、$DFS$ 的时间复杂度

用邻接表存储图时，$DFS$ 典型代码如下：

```cpp
void DFS(int u) {
    visited[u] = true;
    // 扫描顶点 u 的邻接表
    for (p = head[u]; p != NULL; p = p->next) {
        int v = p->v;
        if (!visited[v])
            DFS(v);
    }
}

// 主过程：保证非连通图也能遍历
for (int i = 1; i <= n; i++) {
    if (!visited[i])
        DFS(i);
}
```

- 每个顶点最多作为参数进入一次 $DFS$，所以顶点处理、$visited$ 赋值、递归调用本身的次数是 $O(n)$；
- 每个顶点的邻接表只会被完整扫描一次。所有邻接表节点的总数：无向图为 $2e$，有向图为 $e$，无论如何都是 $O(e)$；
- 因此总时间复杂度为：

$$
O(n+e)
$$

### 二、$DFS$ 的空间复杂度

辅助空间包括：

- $visited$ 数组：长度为 $n$，占 $O(n)$；
- 递归调用栈：最坏情况是图退化为一条链，递归深度为 $n$，占 $O(n)$。

所以 $DFS$ 的空间复杂度为：

$$
O(n)
$$

若使用显式栈，栈的最大深度同样不会超过 $n$。

### 三、$BFS$ 的时间复杂度

$BFS$ 典型代码如下：

```cpp
void BFS(int s) {
    queue<int> q;
    visited[s] = true;
    q.push(s);

    while (!q.empty()) {
        int u = q.front();
        q.pop();

        for (p = head[u]; p != NULL; p = p->next) {
            int v = p->v;
            if (!visited[v]) {
                visited[v] = true;
                q.push(v);
            }
        }
    }
}
```

- 每个顶点最多入队、出队一次，入队/出队操作总次数为 $O(n)$；
- 每个顶点的邻接表被扫描一次，扫描总代价为 $O(e)$；

因此 $BFS$ 的时间复杂度为：

$$
O(n+e)
$$

### 四、$BFS$ 的空间复杂度

$BFS$ 的辅助空间包括 $visited$ 数组和队列：

- $visited$ 数组：$O(n)$；
- 队列中最多同时存放 $n$ 个顶点，$O(n)$。

所以 $BFS$ 的空间复杂度为：

$$
O(n)
$$

**易错点**：

1. **把时间复杂度误选为 $O(e)$**：虽然扫描邻接表的总代价是 $O(e)$，但还需要遍历所有顶点，判断 $visited$ 状态，因此必须加上 $O(n)$。邻接表对应 $O(n+e)$，邻接矩阵对应 $O(n^2)$。
2. **把空间复杂度误选为 $O(n+e)$**：题目问的是“遍历过程中”的辅助空间，不包含图本身的存储结构；递归栈、队列、$visited$ 数组都只与 $n$ 有关，所以是 $O(n)$。只有把图本身的邻接表也算进总空间时，才会出现 $O(n+e)$。
3. **忽略非连通图**：如果只从一个源点开始 $DFS$/$BFS$，可能访问不到所有顶点，但复杂度分析中通常要考虑外层循环遍历所有顶点，此时仍为 $O(n+e)$。
4. **把 $DFS$ 递归深度误判为 $O(e)$**：最坏情况是一条链，递归深度为 $n$，即 $O(n)$。

**命题规律**：本题属于“图的遍历”基础考点，常与邻接矩阵、邻接表的性能对比一起考查。常见变式有：  
- 将邻接表改为邻接矩阵，问 $DFS$/$BFS$ 复杂度，答案变为 $O(n^2)$、$O(n)$；  
- 结合无向图求连通分量、有向图求强连通分量；  
- 结合最小生成树、最短路径等算法分析复杂度。  
复习建议：牢固记住结论——“**邻接表遍历：$O(n+e)$，邻接矩阵遍历：$O(n^2)$；辅助空间均为 $O(n)$**”，并会从“顶点访问次数 + 边扫描次数”两个角度解释原因。

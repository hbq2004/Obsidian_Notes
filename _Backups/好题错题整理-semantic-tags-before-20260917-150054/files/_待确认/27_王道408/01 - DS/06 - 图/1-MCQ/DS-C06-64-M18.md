# 选择题 第 18 题

![[_Attachments/题目识别/27_王道408-题目/DS-C06-64-M18_题目.png|题目]]

18. 下列哪种图的邻接矩阵是对称矩阵？( )

(A) 有向网
(B) 无向图
(C) $AOV$网
(D) $AOE$网

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C06-64-M18_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：无向图的邻接矩阵一定是对称矩阵，故选 **(B) 无向图**。

**解题切入点**：  
先明确邻接矩阵的定义：若图中有 $n$ 个顶点，则矩阵 $A$ 是 $n\times n$ 阶方阵，其中 $A[i][j]$ 表示顶点 $v_i$ 与 $v_j$ 之间的边（或弧）的信息。判断对称性，只需看 $A[i][j]$ 是否恒等于 $A[j][i]$。这等价于：图中每一条边是否都“双向等价”。因此，要抓住“边是否有向”这一核心区别。做题时，可以类比线性代数中的对称矩阵判定：只需验证 $A^T=A$，而图论中这取决于边的方向性。

**推演**：  
1. 对于无向图，边 $(v_i,v_j)$ 与 $(v_j,v_i)$ 是同一条边，因此在邻接矩阵中 $A[i][j]=A[j][i]$（若不带权，则都为 $1$；若带权，则都为该边的权值）。所以无向图的邻接矩阵一定对称。  
2. 对于有向网（有向带权图），弧 $\langle v_i,v_j\rangle$ 与弧 $\langle v_j,v_i\rangle$ 是两条不同的弧，不一定同时存在。即便同时存在，权值也可能不同，因此 $A[i][j]$ 与 $A[j][i]$ 不一定相等，故不一定对称。  
3. $AOV$ 网是用顶点表示活动的有向无环图，其邻接矩阵表示活动之间的优先关系，显然是**有向图**的邻接矩阵，不一定对称。  
4. $AOE$ 网是用边表示活动的带权有向无环图，同样是有向图，其邻接矩阵不一定对称。  

因此，只有无向图的邻接矩阵必然对称。

**易错点**：  
- 误认为“有向网”中若弧成对出现就对称，但题目问的是“哪种图”必然对称，而不是“是否存在对称的有向网”。有向网可能对称，但并非必然。  
- 将 $AOV$ 网或 $AOE$ 网误认为无环就对称，实际上它们都是有向图，有向边的方向性决定了矩阵不一定对称。  
- 忽略“无向图”包括无向带权图：即使带权，只要边是无向的，矩阵依然对称。

**命题规律**：  
本题属于图的基本概念题，考查邻接矩阵的性质与图的类型关系。常以选择题或填空题出现，也可能与“邻接表”的存储效率、求度等考点结合。变式可能包括：判断给定邻接矩阵是否对称所对应的图；或比较有向图、无向图的邻接矩阵空间开销。复习时，应牢记：无向图邻接矩阵对称、有向图邻接矩阵不一定对称；邻接矩阵中无向图第 $i$ 行（列）非零元素个数等于顶点 $v_i$ 的度，有向图第 $i$ 行非零元素个数为出度，第 $i$ 列为入度。建议将图的存储结构与基本操作小结对比，做到看到图的类型立即反应出存储特点。

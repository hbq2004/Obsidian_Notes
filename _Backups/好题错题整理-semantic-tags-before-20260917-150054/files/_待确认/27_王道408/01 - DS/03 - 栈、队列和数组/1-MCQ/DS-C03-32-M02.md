# 选择题 第 2 题

![[_Attachments/题目识别/27_王道408-题目/DS-C03-32-M02_题目.png|题目]]

02. 队列的“先进先出”特性是指 ( ).
I. 最后插入队列中的元素总是最后被删除
II. 当同时进行插入、删除操作时,总是插入操作优先
III. 每当有删除操作时，总要先做一次插入操作
IV. 每次从队列中删除的总是最早插入的元素

(A) $I$
(B) $I$ 和 $IV$
(C) $II$ 和 $III$
(D) $IV$

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C03-32-M02_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 **(B)**。队列的“先进先出”等价于“入队顺序与出队顺序相同”，因此 **I 和 IV 正确**，II、III 错误。

**解题切入点**：拿到题先定位考点：队列是只允许在一端（队尾）插入、另一端（队头）删除的线性表。把四个选项当成“对队列操作序列的一句话模拟”即可：入队相当于排队到队尾，出队相当于从队头离开。II、III 显然不符合队列的操作规则，重点只需判断 I 和 IV。

**推演**：

设依次入队的元素为

$$
a_1,a_2,\dots,a_n
$$

队列删除时只能从队头开始，因此若这些元素最终都被删除，出队序列必为

$$
a_1,a_2,\dots,a_n
$$

即出队顺序与入队顺序完全一致。

- **I 正确**：在整个入队序列中，$a_n$ 是最后插入的元素；由于出队顺序与入队顺序相同，$a_n$ 也就是最后被删除的元素。这就是“后进后出”，是先进先出的等价说法。
- **IV 正确**：每次出队时，队头是当前队列中最早入队且尚未出队的元素，所以每次从队列中删除的总是最早插入的元素。
- **II 错误**：插入和删除是两种独立操作，队列定义中不存在“插入操作优先”的规则。
- **III 错误**：删除操作不需要以插入操作为前提。只要队列非空就可以执行删除；空队列执行删除会发生下溢，但也不能“先插入再删除”来强制满足该说法。

关键实现思路如下：

```
入队：Q[rear] = x; rear = (rear + 1) % MAXSIZE;
出队：x = Q[front]; front = (front + 1) % MAXSIZE;
```

其中 `front` 始终指向队头，而队头就是当前最早入队的元素，因此出队顺序就是入队顺序，体现 FIFO 特性。

**易错点**：

1. **误选 D**：只看到 IV，忽略了 I。注意本题中的 I 应按“完整入队序列的最后一个元素最后出队”理解，它是“先进先出”的等价表述；不能把 I 曲解成“当前队尾元素以后不能被更新”。
2. **误选 C**：II、III 是把队列操作与其他机制（如优先级、必须先插入再删除）混淆，队列并没有这种限制。
3. **与栈混淆**：栈是“后进先出”，队列是“先进先出 / 后进后出”。I 说“最后插入的最后删除”，正好是队列而非栈。

**命题规律**：

本题属于 408 数据结构中的基础概念题，考查队列的逻辑结构与 FIFO 特性。常见变式包括：给入队序列判断合法出队序列、循环队列判空/判满、队头和队尾指针变化，以及 BFS/层次遍历中队列维护节点顺序。复习时应结合顺序队列和链队列实现，重点理解 `front`、`rear` 的含义和循环队列长度公式，不要只背选项。

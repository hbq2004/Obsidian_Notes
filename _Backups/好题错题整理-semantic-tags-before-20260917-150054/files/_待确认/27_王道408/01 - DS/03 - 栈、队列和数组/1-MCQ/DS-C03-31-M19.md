# 选择题 第 19 题

19. 某栈的输入序列为$a,b,c,d$，下面的4个序列中，不可能为其输出序列的是 ( )。
A. $a,b,c,d$
B. $c,b,d,a$
C. $d,c,a,b$
D. $a,c,b,d$.

## DeepSeek V4 Flash Max 解析

**答案**：选 C。$d,c,a,b$ 不可能是该栈的输出序列。

**解题切入点**：看到“栈 + 输入/输出序列”应立刻锁定“后进先出”的合法出栈序列判定问题。不要枚举所有可能，直接用“目标输出驱动”的贪心模拟：当前栈顶正好是需要的输出就出栈；否则按输入顺序继续入栈；输入耗尽仍不能出栈则非法。这类似于括号匹配：能弹就弹，不能弹就压。

**推演**：

设栈为 $S$，输入序列为 $a,b,c,d$，$n=4$。判断任意候选输出序列是否合法的通用算法思路是：

```pseudocode
j ← 0
for x in 输出序列:
    while (S 为空 或 S.top() ≠ x) 且 j < n:
        S.push(input[j]); j ← j+1
    if S 非空 且 S.top() == x:
        S.pop()
    else:
        返回“不合法”
返回“合法”
```

贪心正确性：若当前栈顶就是要输出的 $x$，立即弹出不会错；若不弹而继续压入，$x$ 会被压在下面，之后反而更晚弹出。若栈顶不是 $x$，则 $x$ 只能还在输入序列中，必须继续入栈直到它到栈顶。

逐项验证：

A. $a,b,c,d$：  
$a$ 入、$a$ 出，$b$ 入、$b$ 出，$c$ 入、$c$ 出，$d$ 入、$d$ 出，可以得到 $a,b,c,d$。

B. $c,b,d,a$：  
$a$ 入，$b$ 入，$c$ 入，$c$ 出，$b$ 出，$d$ 入，$d$ 出，$a$ 出，可以得到 $c,b,d,a$。

C. $d,c,a,b$：  
若第一个输出是 $d$，由于 $d$ 是最后一个输入，说明前四个元素都已经入栈，此时栈中自底向上为：
$$
S_{\text{底}}:a,b,c,d:S_{\text{顶}}
$$
弹出 $d$ 后，栈中自底向上为 $a,b,c$；弹出 $c$ 后，栈中自底向上为 $a,b$，栈顶是 $b$。输入已经全部用完，无法再压入新元素，所以第三个输出只能是 $b$，不能是 $a$。因此不可能得到 $d,c,a,b$。

D. $a,c,b,d$：  
$a$ 入、$a$ 出，$b$ 入，$c$ 入，$c$ 出，$b$ 出，$d$ 入、$d$ 出，可以得到 $a,c,b,d$。

所以唯一不可能的是 C。

**易错点**：

1. 只验证前两步合法就下结论。C 的前两步 $d,c$ 是合法的，但第三步 $a$ 不合法；必须完整模拟整个序列。
2. 忽略 $d$ 是最后一个输入。$d$ 第一个出栈，意味着所有元素都已经入栈，之后不能再入栈。
3. 把栈中剩余元素顺序记反。弹出 $d,c$ 后，栈中剩余的是“自底向上 $a,b$”，栈顶是 $b$，因此不能越过 $b$ 先输出 $a$。
4. 用队列的“先进先出”思维判断栈的输出序列；栈必须满足“后进先出”。

**命题规律**：

本题是栈的基本性质题，在 408 中常以选择题出现。常见变式有：给定入栈序列 $1,2,\dots,n$，判断某个出栈序列是否合法；求可能出栈序列的总数；求实现某一出栈序列所需的最小栈容量。  
复习时应熟练掌握 $O(n)$ 的合法出栈序列模拟判定，并了解所有合法出栈序列个数为卡特兰数：
$$
C_n=\frac{1}{n+1}\binom{2n}{n}
$$
例如 $n=4$ 时，合法出栈序列数为 $C_4=14$，不是 $4!=24$。

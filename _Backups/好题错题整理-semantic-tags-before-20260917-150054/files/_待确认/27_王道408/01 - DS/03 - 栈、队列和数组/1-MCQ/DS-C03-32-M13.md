# 选择题 第 13 题

![[_Attachments/题目识别/27_王道408-题目/DS-C03-32-M13_题目.png|题目]]

13. 下列描述的几种链表中，最不适合用作链式队列的是（ ）.

A. 只带队首指针的非循环双链表
B. 只带队首指针的循环双链表
C. 只带队尾指针的循环双链表
D. 只带队尾指针的循环单链表

## DeepSeek V4 Flash Max 解析

**答案**：选 A。只带队首指针的非循环双链表，入队时必须从队头遍历到队尾，时间复杂度为 $O(n)$；其余三种都能用 $O(1)$ 时间完成入队和出队，因此最不适合。

**解题切入点**：  
链式队列的核心操作是“入队在队尾、出队在队头”。判断一个链表结构适不适合做队列，关键是看：**只给这一个指针时，能否在 $O(1)$ 时间内同时找到队头和队尾**。  
可以这样想：队列像排队，队尾是入口，队头是出口。如果只知道出口位置，而队伍是环形，绕一圈总能找到入口；如果队伍不是环形，就必须从队头走到队尾，耗时 $O(n)$。

**推演**：  
设队头为 $F$，队尾为 $R$，链式队列要求：

$$
\text{Enqueue}(x): \text{在 } R \text{ 后插入新结点并更新 } R
$$

$$
\text{Dequeue}(): \text{删除 } F \text{ 并更新 } F
$$

逐项分析：

### A. 只带队首指针的非循环双链表

- 出队：直接删除头指针所指结点，$O(1)$。
- 入队：由于链表非循环，且只有队首指针，必须从头遍历到尾结点才能插入：

```c
p = head;
while (p->next != NULL)
    p = p->next;
// 在 p 后插入新结点
```

每入队一次都需要 $O(n)$ 次遍历，故最不适合。

### B. 只带队首指针的循环双链表

循环双链表中，$head->prior$ 就是队尾 $R$。  
入队时在 $head$ 之前插入新结点，等价于在队尾之后插入；出队时删除 $head$ 并更新头指针。两者均为 $O(1)$。

### C. 只带队尾指针的循环双链表

$tail->next$ 就是队头 $F$。  
入队在 $tail$ 后插入，出队删除 $tail->next$，并修改相应前驱、后继指针。两者均为 $O(1)$。

### D. 只带队尾指针的循环单链表

$tail->next$ 指向队头。  
入队时在 $tail$ 后插入并更新 $tail$，$O(1)$；  
出队时令 $head = tail->next$。若队列不止一个结点，令 $tail->next = head->next$ 后释放 $head$；若只剩一个结点，则置 $tail = NULL$。出队仍为 $O(1)$。

| 选项 | 入队 | 出队 | 是否适合 |
|---|---:|---:|---|
| A | $O(n)$ | $O(1)$ | 最不适合 |
| B | $O(1)$ | $O(1)$ | 适合 |
| C | $O(1)$ | $O(1)$ | 适合 |
| D | $O(1)$ | $O(1)$ | 适合 |

因此选 **A**。

**易错点**：

1. 看到“双向链表”就以为头尾都能 $O(1)$ 操作。  
   实际上，双向链表只是让每个结点有前驱指针；若链表非循环且只有头指针，仍必须遍历到尾结点，$prior$ 指针不能帮助从头直接跳到尾。

2. 认为“只带队尾指针的循环单链表不能出队”。  
   错误。因为 $tail->next$ 就是队头，且 $tail$ 正好是队头的前驱，所以删除队头不需要额外找前驱。

3. 忽略空队列或只剩一个结点时的特殊处理。  
   例如 D 中出队到空时要把 $tail$ 置为 $NULL$，否则尾指针悬空。本题只考复杂度，不影响结论。

4. 混淆“最不适合”和“不能使用”。  
   A 也能实现队列，只是入队退化为 $O(n)$，不符合队列常用操作的 $O(1)$ 要求。

**命题规律**：  
本题属于“链表 + 队列”的综合题，核心考点是**链式队列中指针设置对操作复杂度的影响**。  
常见变式有：只设头指针或尾指针的循环单链表、循环双链表能否实现队列；普通单链表实现队列为什么必须同时设队头指针和队尾指针；循环队列判空/判满的条件等。  
复习建议：把“单链表、双向链表、循环链表”分别与“只带头指针、只带尾指针”组合，逐一分析入队/出队复杂度，并画图理解指针变化。结论可记为：**普通单链表做队列需要队头和队尾两个指针；循环单链表只设尾指针即可 $O(1)$ 完成入队和出队；循环双链表只设头指针或尾指针也都可以。**

# 选择题 第 20 题

![[_Attachments/题目识别/27_王道408-题目/DS-C03-33-M20_题目.png|题目]]

20.【2025 统考真题】已知算法 $A$ 用于检查字符串中各类括号是否匹配， $A$ 执行过程中使用初始为空的栈保存遇到的括号。若栈的容量是 $3$，则下列选项中，$A$ 不能处理的是 ( )。
A. $(a+[b+(c+d)/e]+f)+g-h$
B. $[a*((b+c)/(d-e)+f/g)-h]$
C. $[a*(b-(c-d)*e/(f+g))-h]$
D. $[a-(b+[c*(d+e)-f]+g+h)]$

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C03-33-M20_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 **D**。选项 D 的括号最大嵌套深度为 4，超过栈容量 3；其余选项最大栈深均为 3，容量为 3 时仍可处理。

**解题切入点**：拿到题先不要逐项硬读，而应把问题转化为“最大同时未匹配的左括号个数”。括号匹配算法中，遇到左括号就入栈，遇到匹配的右括号就出栈，因此栈中元素个数等于当前未匹配的左括号个数。栈容量为 3，就是任意时刻栈中最多只能有 3 个左括号；一旦需要压入第 4 个左括号，就会溢出。可以类比“叠盘子”：每遇到一个左括号叠一个盘子，遇到右括号取走一个盘子，容量 3 最多只能叠 3 个。

**推演**：标准括号匹配算法的容量判断思路如下：

```text
栈 st 初始为空
for ch in 表达式:
    if ch 是左括号:
        if st.size() == 3:   # 容量不足
            不能处理
        入栈 st.push(ch)
    else if ch 是右括号:
        if st.empty() or 栈顶不匹配:
            不能处理
        出栈 st.pop()
```

所以只需计算每条表达式在扫描过程中的最大栈深。

| 选项 | 达到最大深度时栈中的左括号 | 最大栈深 |
|---|---|---|
| A | `(`, `[`, `(` | $3$ |
| B | `[`, `(`, `(` | $3$ |
| C | `[`, `(`, `(` | $3$ |
| D | `[`, `(`, `[`, `(` | $4$ |

具体来看：

- A：`(a+[b+(c+d)/e]+f)+g-h` 中，括号嵌套为 `(`、`[`、`(`，最大深度为 $3$。
- B：`[a*((b+c)/(d-e)+f/g)-h]` 中，虽然左括号总数不止 3 个，但 `(d-e)` 是在 `(b+c)` 闭合之后才出现的，最大同时未匹配左括号数为 $3$。
- C：`[a*(b-(c-d)*e/(f+g))-h]` 中，`(c-d)` 和 `(f+g)` 是先后出现，而不是互相嵌套，最大深度为 $3$。
- D：`[a-(b+[c*(d+e)-f]+g+h)]` 中，读到 `[a-(b+[c*(` 时，栈中已有 `[`、`(`、`[`，再遇到 `(` 就需要压入第 4 个左括号，深度达到 $4$，超过容量 $3$。

因此，算法 $A$ 不能处理的是 **D**。

**易错点**：

- 不要把“栈容量 3”理解为只能处理 3 种括号。容量指栈中元素个数，最多同时放 3 个左括号。
- 不要用“左括号总个数”判断最大栈深。B、C 中左括号总数可能超过 3，但最大同时未匹配数只有 3。
- 达到容量 3 不算出错，只有下一次再压入左括号时才会溢出。
- 关键要看扫描顺序：若某个左括号已经先被右括号匹配弹出，则后面的新左括号不会继续增加栈深。

**命题规律**：本题属于栈的典型应用“括号匹配”，考查栈容量与最大栈深的关系，是 408 选择题中常见的计算型考点。常见变式有：给一个括号串求所需最小栈容量；给定栈容量判断能否处理；结合表达式求值或函数调用栈考查栈深。复习时应熟练掌握括号匹配算法的压栈、弹栈和栈顶匹配流程，并习惯用“扫描到每个前缀时未匹配左括号数”来手算最大栈深，避免被括号总数干扰。

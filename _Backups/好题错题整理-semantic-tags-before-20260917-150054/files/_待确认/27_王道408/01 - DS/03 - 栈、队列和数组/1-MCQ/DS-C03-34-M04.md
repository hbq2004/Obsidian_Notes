# 选择题 第 4 题

![[_Attachments/题目识别/27_王道408-题目/DS-C03-34-M04_题目.png|题目]]

4. 在二维数组 $A$ 中，假设每个数组元素的长度为 3 个存储单元，行下标 $i$ 为 $0 \sim 8$，列下标 $j$ 为 $0 \sim 9$，从首地址 $SA$ 开始连续存放。在这种情况下，元素 $A[8][5]$ 的起始地址为(   ).

(A) $SA + 141$
(B) $SA + 144$
(C) $SA + 222$
(D) $SA + 255$

## 答案

## DeepSeek V4 Flash Max 解析

**答案**：元素 $A[8][5]$ 的起始地址为 $SA+255$，对应选项 (D)。  
**解题切入点**：本题考察二维数组的地址计算，核心是确定存储方式（行优先或列优先）。考研 408 中，若不特别说明，默认按行优先存储。抓住“行下标范围 $0\sim8$（9行），列下标 $0\sim9$（10列）”和“每个元素长度 $L=3$”两个关键参数，代入行优先公式 $Loc(i,j)=SA+(i\times\text{列数}+j)\times L$ 即可快速求解。  
**推演**：  
- 二维数组 $A$ 的行下标 $i$ 从 $0$ 到 $8$，共 $9$ 行；列下标 $j$ 从 $0$ 到 $9$，共 $10$ 列。  
- 每个元素占 $3$ 个存储单元，首地址为 $SA$。  
- 按行优先存储时，元素 $A[i][j]$ 的地址为：  
  $$Loc(i,j)=SA+(i\times 10+j)\times 3$$  
  代入 $i=8,\;j=5$：  
  $$Loc(8,5)=SA+(8\times 10+5)\times 3=SA+(80+5)\times 3=SA+85\times 3=SA+255$$  
- 若按列优先存储，则 $Loc(i,j)=SA+(j\times 9+i)\times 3=SA+(5\times 9+8)\times 3=SA+53\times 3=SA+159$，与选项不符，故排除。  
- 因此正确答案为 $SA+255$，即选项 (D)。  

**易错点**：  
1. **行、列数计算错误**：行下标 $0\sim8$ 表示 $9$ 行，列下标 $0\sim9$ 表示 $10$ 列，容易误算为 $8$ 行或 $9$ 列。  
2. **存储方式混淆**：误用列优先公式会导致结果 $159$，但选项中无该值，说明题目默认行优先。若题目未明确说明，需根据上下文或选项验证。  
3. **偏移量单位**：地址偏移量是“元素个数 $\times$ 元素长度”，注意元素个数从 $0$ 开始计数，$A[8][5]$ 是第 $85$ 个元素（行优先），而非第 $8\times10+5+1$ 个。  

**命题规律**：  
- **考点定位**：二维数组的地址计算，属于“数据结构”中数组部分的常考知识点，通常以选择题或填空题形式出现。  
- **常见变式**：  
  - 改变存储方式（列优先），或给出三维数组。  
  - 改变下标起始值（如从 $1$ 开始），需调整公式。  
  - 结合元素长度（如 $4$ 字节）或特殊存储顺序（如对称矩阵压缩）。  
- **复习建议**：熟练掌握行优先和列优先地址公式，注意区分下标起始范围，并学会通过选项反推存储方式。计算时先确定行数和列数，再代入公式，避免粗心失误。

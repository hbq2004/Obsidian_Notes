# 选择题 第 16 题

![[_Attachments/题目识别/27_王道408-题目/DS-C03-32-M16_题目.png|题目]]

16. 在一个链式队列中, 假设队首指针为 $front$, 队尾指针为 $rear$, $x$ 所指向的元素需要入队, 则需要执行的操作为(   ).

A. $front = x, front = front \to next$
B. $x \to next = front \to next, front = x$
C. $rear \to next = x, rear = x$
D. $rear \to next = x, x \to next = NULL, rear = x$

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C03-32-M16_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 **D**。链式队列入队即“尾插”：先把新结点的 next 域置空，再令原队尾指向它，最后更新队尾指针，即  
$$x\to\text{next}=\mathrm{NULL};\quad rear\to\text{next}=x;\quad rear=x.$$

**解题切入点**：先判断入队操作发生在队首还是队尾。队列是 FIFO 结构，入队只能在队尾进行，因此核心指针一定是 `rear`，而不是 `front`。这能立刻排除 A、B；再比较 C、D，关键是新结点 $x$ 成为队尾后，其 `next` 必须为 `NULL`，否则会破坏链队的尾结点性质。

**推演**：

设原队尾结点为 $r$，入队前链队满足：

$$
r\to\text{next}=\mathrm{NULL},\qquad rear=r.
$$

现在将 $x$ 指向的结点入队，目标是：

$$
front \to \cdots \to r \to x \to \mathrm{NULL}
$$

因此需要做以下三步：

$$
x\to\text{next}=\mathrm{NULL};
$$

$$
r\to\text{next}=x;
$$

$$
rear=x.
$$

用 `rear` 表示原队尾，合并写成：

$$
x\to\text{next}=\mathrm{NULL},\quad rear\to\text{next}=x,\quad rear=x.
$$

对应的关键代码思路为：

```
x->next = NULL;   // 使 x 成为新的尾结点
rear->next = x;   // 原队尾链接新结点
rear = x;         // 更新队尾指针
```

选项逐个分析：

- **A**：`front = x; front = front->next;`  
  修改的是队首指针，且会丢失原队列头部信息，不是入队操作。

- **B**：`x->next = front->next; front = x;`  
  这是“在队首/头结点之后插入”，不是队尾插入，也没有更新 `rear`，错误。

- **C**：`rear->next = x; rear = x;`  
  完成了队尾链接和队尾指针更新，但没有将 $x\to\text{next}$ 置空，不严谨，可能破坏链队“尾结点 next 为 NULL”的结构。

- **D**：`rear->next = x; x->next = NULL; rear = x;`  
  完整实现了链队入队操作，正确。

若采用带头结点的链式队列，即使空队时 `rear` 也指向头结点，D 的操作依然成立。若采用不带头结点的链队且当前为空队，则需要额外处理 `front = rear = x`，但本题选项显然默认队列已有可用队尾结点。

**易错点**：

1. **误选 C**：C 看起来步骤最少，但漏掉了 $x\to\text{next}=\mathrm{NULL}$。如果 $x$ 的 next 域残留其他地址，队列尾部会出现“多余链”，破坏队列结构。
2. **操作顺序错误**：必须先让原队尾 `rear->next` 指向 $x$，再更新 `rear = x`。如果先执行 `rear = x`，原队尾结点会与队列断开，链表无法串联。
3. **混淆队首和队尾**：入队操作不修改 `front`，只有出队或处理空队时才需要修改 `front`。
4. **忘记特殊情况**：如果是不带头结点的链队且空队入队，需要将 `front` 和 `rear` 同时指向 $x$；但本题选项未涉及这种情况。

**命题规律**：本题考查链式队列的基本操作，属于“栈和队列”中的高频基础考点。408 中常见的变式包括：链队出队操作、循环队列判空判满、循环队列元素个数计算等。复习时应熟练掌握链队“队尾入、队首出”的指针变化，特别注意边界情况：空队入队、队中仅有一个元素时出队等。建议画图模拟指针变化，避免死记硬背。

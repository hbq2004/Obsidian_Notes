# 选择题 第 4 题

![[_Attachments/题目识别/27_王道408-题目/DS-C03-31-M04_题目.png|题目]]

4. 设用数组 $a[n]$ 存储一个栈，初始栈顶指针 $top=-1$，则元素 $x$ 入栈的操作是 (  ).
A. $a[-top] = x$
B. $a[top--] = x$
C. $a[++top] = x$
D. $a[top++] = x$

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C03-31-M04_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 C，即入栈操作应为 `a[++top] = x`，先移动栈顶指针再存入元素。

**解题切入点**：栈的入栈操作核心是“先移动指针，后赋值”。初始栈顶指针 `top = -1` 表示空栈，此时栈顶位置在 `a[0]` 的下标之前。入栈时，需先将指针加 1 指向第一个空位（下标 0），再存入数据。这类似于排队时先让指针指向新位置，再让元素进入。在算法竞赛中，数组模拟栈均采用此模式，务必与出栈操作（先取元素，后减指针）区分开。

**推演**：  
- 初始状态：栈空，栈顶指针 `top = -1`。  
- 入栈元素 `x` 时，应存放于栈顶的下一个空闲位置，即 `a[top+1]`。  
- 由于 `top` 当前为 `-1`，首个元素应存入 `a[0]`，因此需要先将 `top` 自增为 0，再赋值 `a[0] = x`。  
- 对应指针的自增方式：`++top` 表示先加后使用，符合要求。  
- 选项分析：  
  - A. `a[-top] = x`：语法错误，且 `-top` 是取负，逻辑混乱。  
  - B. `a[top--] = x`：先使用当前 `top`（值为 -1）再自减，导致访问越界并错误赋值。  
  - C. `a[++top] = x`：先自增 `top` 到 0，再赋值，正确。  
  - D. `a[top++] = x`：先使用 `top` 的旧值（-1）再自增，访问 `a[-1]` 越界，且赋值位置错误。  

因此，正确答案为 C。

**易错点**：  
1. 混淆 `++top` 和 `top++`：前者先加后用，后者先用后加。若误选 D，会导致栈空时入栈访问 `a[-1]` 造成越界。  
2. 忘记初始 `top = -1` 的含义：空栈时栈顶指针指向 -1，意味着第一个元素的下标是 0，必须用前置递增。  
3. 与出栈操作混淆：出栈通常用 `top--`（先取元素再减指针），而入栈必须用 `++top`。

**命题规律**：  
- 考点：栈的顺序存储结构及基本操作，重点考查指针移动与赋值顺序。  
- 常见变式：  
  - 初始栈顶指针为 0（栈顶指向下一个空位），则入栈改为 `a[top++] = x`，出栈改为 `a[--top]`。  
  - 结合栈的判空、判满条件（如 `top == -1` 空，`top == n-1` 满）进行综合设计。  
- 复习建议：理解栈的“先进后出”逻辑，亲手模拟指针变化过程，并对比不同初始值下操作符的差异。408 统考中此类基础题常在选择题或代码填空题中出现，务必熟练掌握。

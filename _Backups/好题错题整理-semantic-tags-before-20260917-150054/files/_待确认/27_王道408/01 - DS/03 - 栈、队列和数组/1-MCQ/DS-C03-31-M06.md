# 选择题 第 6 题

![[_Attachments/题目识别/27_王道408-题目/DS-C03-31-M06_题目.png|题目]]

6. 设用数组 $data[1 \dots n]$ 存储一个栈，初始栈顶指针 $top = n + 1$，则元素 $x$ 入栈的操作是（ ）。
(A) $data[-top] = x$
(B) $data[top++] = x$
(C) $data[top--] = x$
(D) $data[++top] = x$

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C03-31-M06_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 A。元素入栈应先将栈顶指针下移一格再写入，即 `data[--top] = x`；若题面 A 写为 `data[-top]`，则是排版/录入漏了一个减号。

**解题切入点**：先看 `top` 的初值。`top = n+1` 而数组下标是 $1 \sim n$，说明 `top` 一开始在数组上界之外，栈不是从低地址向高地址增长，而是从高地址向低地址增长。这类似于“弹匣从下往上压弹”：要压入一个元素，先把指针退一格，再放进去。所以关键是区分“先减后用”还是“先用后减”。

**推演**：设数组逻辑下标为 $1 \sim n$。初始空栈时
$$
top = n+1
$$
表示 $data[n]$ 尚未使用。第一个元素 $x$ 入栈后应存放在 $data[n]$，因此操作顺序应为
$$
top \leftarrow top - 1,\qquad data[top] = x
$$
即
$$
data[--top] = x
$$

一般地，若当前已有 $k$ 个元素，则
$$
top = n+1-k
$$
新元素入栈后，
$$
top' = top - 1 = n-k
$$
元素存放在 $data[top']$ 中。

用类 C 语言描述：

```c
// 初始 top = n + 1
if (top == 1) {
    // 栈满，data[1] 已被占用
}
data[--top] = x;
```

四个选项辨析：

- A：`data[--top] = x`，先令 `top = top - 1`，再存放到 `data[top]`，正确。
- B：`data[top++] = x`，先用旧值 `n+1` 作下标，越界，且 `top` 增大，错误。
- C：`data[top--] = x`，先用旧值 `n+1` 作下标，越界；`top--` 发生太晚，错误。
- D：`data[++top] = x`，`top` 变成 `n+2`，越界，错误。

因此入栈操作应为 `data[--top] = x`。

**易错点**：

1. 容易误选 C。`data[top--]` 与 `data[--top]` 不同：前者先用旧 `top` 作下标，再减；后者先减，再用新 `top` 作下标。
2. 容易受“初始 `top = 0` 时入栈用 `data[++top]`”的惯性思维影响。本题初始 `top = n+1`，栈向下增长，应使用 `--top`。
3. 忽略数组下标范围：`data[1..n]` 中没有 `data[n+1]`，所以任何先用 `n+1` 作下标存储的写法都越界。
4. 注意 `data[-top]` 如果按字面理解，不是自减，而是对 `top` 取负，既不修改 `top`，也会使用非法下标；正确写法是 `data[--top]`。

**命题规律**：本题是顺序栈的经典基础题，考查栈顶指针与数组下标的对应关系。常见变式包括：初始 `top = 0` 时的入栈 `data[++top] = x`；共享栈中左栈向右增长、右栈向左增长；或者给出栈顶指针变化过程，要求判断栈空、栈满条件。复习时要在草稿上画出数组下标和 `top` 的移动方向，分清“先动指针再存”和“先存再动指针”两类写法。

# 选择题 第 14 题

![[_Attachments/题目识别/27_王道408-题目/DS-C03-33-M14_题目.png|题目]]

14.【2014统考真题】假设栈初始为空，将中缀表达式$a/b+(c*d - e*f)/g$转换为等价的后缀表达式的过程中，当扫描到$f$时，栈中的元素依次是（）。
A. +(*- 
B. +(-* 
C. /+(*-* 
D. /+-*

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C03-33-M14_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 **B**。扫描到 $f$ 时，操作符栈自底向上为 $+,\; (,\; -,\; *$，即选项 B。

**解题切入点**：本题是经典的“中缀表达式转后缀表达式”的栈应用问题。拿到题目后先定位考点：操作符栈的入栈、出栈规则。不要先把整个后缀表达式一下写出，而是按扫描顺序模拟；重点看低优先级运算符到来时，哪些高优先级运算符已被弹出。

**推演**：

中缀表达式为：
$$
a/b+(c*d-e*f)/g
$$

转换时采用如下规则：

1. 操作数直接输出；
2. `(` 直接入栈；
3. `)` 弹出栈中运算符直到遇到 `(`，并丢弃 `(`；
4. 普通运算符 `op` 到来时，若栈顶运算符优先级不低于 `op`，则弹出栈顶运算符；重复此过程直到栈空、遇到 `(` 或栈顶优先级低于 `op$，然后将 `op` 入栈。

核心伪代码思路：

```text
while 栈非空 and 栈顶 != '(' and 优先级[栈顶] >= 优先级[当前运算符]:
    弹出栈顶并输出
将当前运算符入栈
```

逐步模拟到扫描到 $f$ 时：

| 已扫描符号 | 操作 | 操作符栈（底→顶） |
|---|---|---|
| $a$ | 输出 $a$ | 空 |
| $/$ | 入栈 | $/$ |
| $b$ | 输出 $b$ | $/$ |
| $+$ | 弹出 $/$，入栈 $+$ | $+$ |
| $($ | 入栈 | $+($ |
| $c$ | 输出 $c$ | $+($ |
| $*$ | 入栈 | $+(*$ |
| $d$ | 输出 $d$ | $+(*$ |
| $-$ | 弹出 $*$，入栈 $-$ | $+(-$ |
| $e$ | 输出 $e$ | $+(-$ |
| $*$ | 入栈 | $+(-*$ |
| $f$ | 输出 $f$，栈不变 | $+(-*$ |

因此，扫描到 $f$ 时栈中元素依次是：
$$
+,\; (,\; -,\; *
$$

所以选 **B**。

**易错点**：

1. 容易忘记 `+` 到来时要把之前的 `/` 弹出，从而误选包含 `/` 的选项 C。  
   注意：`+` 优先级低于 `/`，所以 `/` 必须先输出到后缀表达式中。

2. 容易在括号内的 `-` 到来时，不弹出前面的 `*$，导致栈中多保留一个 `*`。  
   注意：`-` 优先级低于 `*$，所以要先弹出 `*$，再压入 `-$。

3. 不要漏掉左括号 `(`。括号本身也在栈中，只有遇到 `)` 时才弹出并丢弃。

4. $f$ 是操作数，扫描到它时它只被输出，不改变操作符栈；但之前 `e*f$ 中的 `*$ 已经入栈。

**命题规律**：本题属于栈的典型应用“中缀表达式转后缀表达式”，是 408 高频考点。常见变式包括：给出转换过程求某一时刻栈的状态、给出后缀表达式求原中缀表达式、用栈计算后缀表达式等。复习时应熟练掌握运算符优先级和结合性，并多用手工模拟典型表达式，尤其注意括号内运算符的弹出时机。

## DeepSeek V4 Flash Max 解析

**答案**：利用栈的“后进先出”特性，从左到右扫描表达式，遇左括号入栈、遇右括号检查栈顶是否同类型匹配并出栈，最终栈空则括号全部配对。

**解题切入点**：看到“括号配对”立即联想到栈：右括号必须与最近出现的未匹配左括号配对，而“最近”正是栈顶位置。就像文本编辑器自动检查括号匹配、编译器的语法分析一样，从左往右扫描，用栈保存“等待配对的左括号”。做题时先明确三种括号类型和结束符 `'\0'`，再用栈模拟即可。

**推演**：

设表达式为 $E$，长度为 $n$，以 `'\0'` 结束。定义字符栈 $S$，栈顶指针 $top$ 初始为 $-1$。

算法步骤：

1. 初始化空栈 $S$；
2. 从 $E$ 的第一个字符开始扫描，设当前字符为 $c$：
   - 若 $c$ 为左括号 `(`、`[` 或 `{`，则 $c$ 入栈；
   - 若 $c$ 为右括号 `)`、`]` 或 `}`：
     - 若栈空，说明该右括号没有可配对的左括号，返回不匹配；
     - 否则取栈顶元素 $t$，若 $(c,t)$ 构成配对括号对，即 `)` 与 `(`、`]` 与 `[`、`}` 与 `{`，则弹出栈顶；否则说明类型不匹配，返回不匹配；
   - 其余字符（数字、运算符等）直接跳过，不影响括号配对；
3. 扫描结束后，若栈空，则所有左括号均被匹配，返回配对；否则存在未匹配的左括号，返回不匹配。

正确性论证：扫描过程中，栈中始终存放尚未匹配的左括号，从栈底到栈顶对应它们在表达式中出现的先后顺序。遇到右括号时，能与它配对的只能是最近的未匹配左括号，即栈顶元素；若栈顶不匹配，则内层括号未被正确闭合，整个表达式不可能配对。每次成功弹出都维护了“尚未匹配的左括号集合”，因此最终栈空当且仅当所有括号成功配对。

关键代码如下：

```c
int match(char *exp) {
    char stack[MaxSize];   // MaxSize 大于表达式长度即可
    int top = -1;
    
    for (int i = 0; exp[i] != '\0'; i++) {
        char c = exp[i];
        
        if (c == '(' || c == '[' || c == '{') {
            stack[++top] = c;          // 左括号入栈
        } else if (c == ')' || c == ']' || c == '}') {
            if (top == -1) {
                return 0;              // 右括号多余
            }
            char t = stack[top];
            if ((c == ')' && t == '(') ||
                (c == ']' && t == '[') ||
                (c == '}' && t == '{')) {
                top--;                 // 匹配成功，弹出栈顶
            } else {
                return 0;              // 类型不匹配
            }
        }
        // 其他字符直接忽略
    }
    
    return top == -1;                  // 栈空则全部匹配
}
```

复杂度分析：每个字符至多入栈一次、出栈一次，时间复杂度 $O(n)$；栈的最大深度不超过左括号数量，空间复杂度 $O(n)$，其中 $n$ 为表达式长度。

**易错点**：

- 只处理括号字符，数字、运算符等非括号字符必须跳过，不能误当作括号操作。
- 遇到右括号时，必须先判断栈是否为空，再访问栈顶元素，否则会发生越界访问。
- 弹出栈顶时必须判断括号类型是否相同，不能只判断栈非空就弹出，否则例如 `([)]` 会被错误判定为配对。
- 扫描结束后必须再检查栈是否为空，否则会漏掉左括号多余的情况，例如 `"(())("`。
- 栈容量要足够，通常可取表达式长度加 1；若用固定数组栈，应确保 `MaxSize` 足够大，或在题解中说明采用动态栈。
- 以 `'\0'` 作为结束符时，循环条件应写为 `exp[i] != '\0'`，不要遗漏字符串末尾的判断。

**命题规律**：

本题是栈的典型应用题，核心考查栈“后进先出”的特性以及边界条件处理。选择题常给出某几个括号的入栈出栈过程，要求判断匹配结果或错误位置；综合题则要求直接写出算法，常与表达式求值、中缀转后缀结合考查。常见变式有：只匹配一种括号（可用计数器代替栈）、匹配三种括号（必须用栈）、要求输出第一个不匹配位置、把括号替换为 HTML 标签或 C 语言注释等。复习建议：熟练掌握顺序栈与链栈的基本操作和代码实现，深刻理解括号匹配的模拟过程；同时练习中缀表达式转后缀、后缀表达式求值等题目，它们是同一知识点的进阶应用。

6. 设树 $B$ 是一棵采用链式结构存储的二叉树，编写一个把树 $B$ 中所有结点的左右子树进行交换的函数。

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C05-53-F06_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：采用后序（或先序）递归遍历二叉树，对每个结点交换其左右孩子指针，即可完成整棵二叉树的左右子树互换，时间复杂度为 $O(n)$，空间复杂度为 $O(h)$（$h$ 为树高）。

**解题切入点**：拿到“交换所有结点左右子树”这类题，先明确操作对象是**每个结点**的左右孩子指针，而不是只交换根结点的两个孩子。这等价于对二叉树做一次“镜像翻转”，其核心遍历框架与先序、后序、层序均一致，递归实现时只需在访问结点时交换左右指针。可以类比“整棵树翻转”：每到一个结点，先处理它的子树，再把自己左右孩子互换，或者先互换再处理子树，两种顺序都可行，但要保证每个结点恰好被处理一次。

**推演**：

二叉树链式存储的结点定义通常为：

```c
typedef struct BTNode {
    int data;                    // 数据域，可为任意类型
    struct BTNode *left, *right; // 左右孩子指针
} BTNode;
```

题目要求编写“把树 $B$ 中所有结点的左右子树进行交换”的函数，函数原型可设计为：

```c
void swapTree(BTNode *B);
```

递归思路：  
若 $B$ 为空，直接返回；否则先递归交换左子树，再递归交换右子树，最后交换 $B$ 的左、右指针。这相当于“后序交换”。也可以采用“先交换再递归”的“先序交换”，两种方式都能正确完成。

后序交换的代码如下：

```c
void swapTree(BTNode *B) {
    if (B == NULL)
        return;

    // 先递归交换左、右子树
    swapTree(B->left);
    swapTree(B->right);

    // 交换当前结点的左右孩子指针
    BTNode *temp = B->left;
    B->left = B->right;
    B->right = temp;
}
```

先序交换的代码如下：

```c
void swapTree(BTNode *B) {
    if (B == NULL)
        return;

    BTNode *temp = B->left;
    B->left = B->right;
    B->right = temp;

    swapTree(B->left);   // 注意：交换后原来的右子树变到了左子树
    swapTree(B->right);
}
```

以一棵简单的二叉树为例验证正确性。设原始二叉树为：

```
        A
       / \
      B   C
     / \   \
    D   E   F
```

调用 `swapTree` 后，逐层交换，得到：

```
        A
       / \
      C   B
     /   / \
    F   E   D
```

递归过程以“后序交换”为例，对结点 $D$、$E$、$F$ 分别处理时左右子树均为空，交换后仍为空；回到 $B$ 结点时，其左右子树 $D$ 和 $E$ 已分别处理完毕，此时交换 $B$ 的左右指针，于是 $B$ 的右孩子变为 $D$，左孩子变为 $E$；回到 $C$ 结点时，先处理其右子树 $F$（左子树为空），再交换 $C$ 的左右指针，使其左孩子变为 $F$，右孩子为空；最后在根 $A$ 处交换左右指针，完成整棵树的镜像。

若要求非递归实现，可使用栈模拟后序遍历，或使用队列进行层序遍历，每访问一个结点就交换其左右指针。层序非递归代码思路如下：

```c
void swapTree(BTNode *B) {
    if (B == NULL)
        return;
    Queue Q;          // 假设已有队列结构
    InitQueue(&Q);
    EnQueue(&Q, B);
    while (!IsEmpty(&Q)) {
        BTNode *p = DeQueue(&Q);
        BTNode *temp = p->left;
        p->left = p->right;
        p->right = temp;
        if (p->left != NULL)
            EnQueue(&Q, p->left);
        if (p->right != NULL)
            EnQueue(&Q, p->right);
    }
}
```

无论递归还是非递归，每个结点都被访问一次，时间复杂度为 $O(n)$。递归实现时，系统栈深度等于树高 $h$，最坏情况下（单支树）$h=O(n)$，最好情况下（平衡树）$h=O(\log n)$；非递归层序需要使用队列，空间复杂度为 $O(w)$，$w$ 为树的最大宽度，最坏为 $O(n)$。

**易错点**：

1. **只交换根结点**：若只写 `temp = B->left; B->left = B->right; B->right = temp;` 而没有递归处理子树，则只交换了根结点的两个孩子，子树内部并未翻转，不符合题意。  
2. **忽略空树**：递归函数必须先检查 `B == NULL`，否则访问空指针的 `left/right` 会造成段错误。  
3. **先序交换时递归参数写错**：若先交换再递归，必须意识到交换后 `B->left` 和 `B->right` 的内容已经改变，因此递归调用 `swapTree(B->left)` 和 `swapTree(B->right)` 仍能覆盖原树的所有结点，但不能写成“先调用左、右，再交换”与“先交换再调用左、右”混用。  
4. **忘记保存临时指针**：交换两个指针时，必须用 `temp` 暂存其中一个指针，否则会丢失原左子树地址。  
5. **对“左右子树交换”理解偏差**：交换的是指针域，不是数据域；若误交换数据，则无法处理结构不对称的树，且丢失了结构信息。  
6. **递归返回类型设置错误**：若函数设计为需要返回新树根（如 `BTNode*`），需注意返回值的使用；若采用 `void` 直接在原树上修改，则不需要返回。两种设计均可，但逻辑要一致。

**命题规律**：

本题是二叉树遍历的典型应用，属于 408 数据结构“树与二叉树”部分的常考操作题。考点定位为：**二叉树的递归遍历框架 + 指针操作**。常见变式包括：

- 判断一棵二叉树是否为另一棵二叉树的镜像；
- 求一棵二叉树的镜像（返回新树或原地修改）；
- 按层输出二叉树的镜像结果；
- 判断二叉树是否对称（等价于左右子树是否互为镜像）；
- 用非递归方式实现左右子树交换。

复习建议：

- 熟练掌握二叉树的先序、中序、后序、层序遍历的递归与非递归写法，并能灵活修改“访问结点”部分，本题就是在访问结点时交换左右指针。  
- 注意“交换”通常不需要返回值，但若题目要求“返回新树”，应定义新结点并递归构造，而不是直接修改原树。  
- 在 408 答题中，代码应给出结点定义、函数注释和关键步骤，时间复杂度与空间复杂度分析要完整。  
- 多练习与镜像、对称相关的题目，体会递归思想中“先处理子树再处理根”和“先处理根再处理子树”的等价性。

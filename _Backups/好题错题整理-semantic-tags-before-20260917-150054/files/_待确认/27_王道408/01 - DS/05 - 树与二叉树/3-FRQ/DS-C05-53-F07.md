# 综合题 第 7 题

![[_Attachments/题目识别/27_王道408-题目/DS-C05-53-F07_题目.png|题目]]

7. 假设二叉树采用二叉链存储结构存储，设计一个算法，求先序遍历序列中第 $k$ ($1 \leqslant k \leqslant \text{二叉树中结点数}$) 个结点的值。

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C05-53-F07_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：采用先序遍历的递归过程，用计数器记录当前已访问结点个数，当计数器等于 $k$ 时，当前结点的值即为所求。

**解题切入点**：先序遍历的顺序是“根、左、右”，题目要求的“先序遍历序列中第 $k$ 个结点”就是先序遍历时第 $k$ 次访问到的结点。因此核心是模拟先序遍历过程，并记录访问次序。这类“找遍历序列第几个结点”的题，本质上是在遍历模板上增加一个计数器，类似于竞赛中“树的遍历 + 全局变量计数”的套路。

**推演**：

1. 二叉链存储结构的结点定义一般为：
   ```cpp
   typedef struct BiTNode {
       ElemType data;                // 结点值
       struct BiTNode *lchild, *rchild;
   } BiTNode, *BiTree;
   ```

2. 设置一个计数器 `count`，初值为 0。每访问一个非空结点，`count` 加 1。当 `count == k` 时，该结点就是先序遍历序列中的第 $k$ 个结点，记录其数据值并停止继续遍历。

3. 递归算法思路：
   - 若当前结点为空，返回；
   - 否则先处理当前结点：`count++`，若 `count == k`，保存结果并返回；
   - 若尚未找到，则递归遍历左子树；
   - 若左子树中仍未找到，则递归遍历右子树。

4. 关键代码：
   ```cpp
   int count = 0;          // 全局计数器
   ElemType result;        // 保存结果
   bool found = false;     // 是否找到

   void PreOrderK(BiTree T, int k) {
       if (T == NULL || found) return;
       count++;
       if (count == k) {
           result = T->data;
           found = true;
           return;
       }
       PreOrderK(T->lchild, k);
       PreOrderK(T->rchild, k);
   }
   ```
   调用后，`result` 中即为第 $k$ 个结点的值。由于题目保证 $1 \leqslant k \leqslant \text{结点数}$，最终一定能找到。

5. 也可以使用非递归先序遍历实现：
   ```cpp
   ElemType PreOrderKNonRec(BiTree T, int k) {
       stack<BiTree> s;
       BiTree p = T;
       int count = 0;
       while (p || !s.empty()) {
           if (p) {
               count++;
               if (count == k) return p->data;
               s.push(p);
               p = p->lchild;
           } else {
               p = s.top();
               s.pop();
               p = p->rchild;
           }
       }
   }
   ```

6. 复杂度分析：每个结点至多访问一次，时间复杂度为 $O(n)$，其中 $n$ 为二叉树结点数；递归深度为树的高度，最坏情况下为 $O(n)$，平均 $O(\log n)$，非递归版本使用栈，空间复杂度类似。

**易错点**：

- 混淆先序、中序、后序的顺序。先序是“根左右”，中序是“左根右”，后序是“左右根”，题目明确要求先序，不要写错遍历顺序。
- 计数器初值或更新位置错误。必须“访问结点时”计数，而不是进入函数时计数，否则空结点也被计数。
- 忘记在找到后终止递归。若没有 `found` 标志或返回值控制，递归会继续遍历后面的结点，可能改变 `result` 或浪费时间。
- $k$ 从 1 开始，若误写成从 0 开始，会导致结果左移一个结点。
- 返回值处理不当。若用函数值返回结点值，当树空或 $k$ 不合法时容易产生歧义，建议用引用参数或全局变量保存结果，并配合布尔标志。
- 非递归实现中，注意出栈的结点不能重复计数，只有第一次访问结点时才计数。

**命题规律**：本考点属于“二叉树的遍历及其应用”，在 408 中常以选择题或综合题形式出现。常见变式有：
- 求中序、后序遍历序列中第 $k$ 个结点（只需调整访问计数语句的位置）。
- 求先序遍历序列中第 $k$ 个叶子结点的值（在访问结点时判断是否为叶子，再计数）。
- 求层次遍历序列中第 $k$ 个结点（改用队列实现层序计数）。
- 求某种遍历序列中指定结点的前驱/后继。

复习建议：熟练掌握二叉树三种遍历的递归模板和非递归写法，理解“访问结点”的时机；善于利用全局变量或引用参数在遍历过程中追加统计信息。这类题代码量小，但容易在细节上出错，平时应亲手模拟一遍递归过程。

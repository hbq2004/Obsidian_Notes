11. 假设二叉树采用二叉链表存储结构，设计一个算法，求非空二叉树$b$的宽度（具有结点数最多的那一层的结点数).

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C05-53-F11_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：对二叉树做层次遍历，逐层统计每层的结点数，取最大值即为二叉树的宽度；时间复杂度 $O(n)$，空间复杂度 $O(n)$。

**解题切入点**：题目要求“某一层有多少个结点”，层次遍历天然按层推进，所以优先想到用队列实现 BFS。核心技巧是：**每次进入循环时，先记录当前队列中结点个数，这个数就是当前层的宽度**。就像按层发水果：先数清这一层有几个人，再逐个发，并把他们的“孩子”叫到下一层排队。

**推演**：

### 1. 存储结构

二叉树采用二叉链表存储：

```c
typedef struct BiTNode {
    ElemType data;
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;
```

### 2. 算法步骤

1. 初始化队列 `Q`，将根结点 `b` 入队。
2. 令 `width = 0`。
3. 当队列不空时，重复以下操作：
   - 令 `levelCount` 为当前队列中元素的个数，即当前层结点数；
   - 更新 `width = max(width, levelCount)`；
   - 从队列中连续取出 `levelCount` 个结点，每取一个结点，若其左孩子、右孩子非空，则依次入队。
4. 队列为空时，所有层都已处理完，返回 `width`。

### 3. 核心代码

```c
int BiTreeWidth(BiTree b) {
    if (b == NULL) return 0;          // 题目说非空，这里做防御

    BiTree Q[MaxSize];                 // 队列，容量足够大
    int front = 0, rear = 0;

    Q[rear++] = b;                     // 根结点入队
    int width = 0;

    while (front < rear) {             // 队列不空
        int levelCount = rear - front; // 当前层结点数
        if (levelCount > width)
            width = levelCount;

        for (int i = 0; i < levelCount; i++) {
            BiTree p = Q[front++];     // 出队一个结点
            if (p->lchild != NULL)
                Q[rear++] = p->lchild;
            if (p->rchild != NULL)
                Q[rear++] = p->rchild;
        }
    }
    return width;
}
```

### 4. 正确性说明

设第 $l$ 层结点数为 $c_l$，则要求的是：

$$
W=\max_{l\ge 1} c_l
$$

算法维持一个不变式：**每次进入 `while` 循环时，队列中恰好存放当前这一层的全部结点**。

- 初始时，队列中只有根结点，即第 $1$ 层的全部结点，不变式成立。
- 若当前层有 $c_l$ 个结点，则 `levelCount = c_l`；将这 $c_l$ 个结点全部出队，同时把它们的左右孩子入队，恰好得到下一层的全部结点。于是下一次循环开始时，队列中又正好是下一层结点，不变式继续成立。

因此每次更新得到的 `width` 都是某一层的真实结点数，循环结束后 `width` 即为所有层结点数的最大值。

### 5. 复杂度

- 每个结点入队一次、出队一次，时间复杂度为：

$$
O(n)
$$

- 队列中最多同时存放若干层的结点，最坏情况下仍是 $O(n)$，所以空间复杂度为：

$$
O(n)
$$

**易错点**：

1. **忘记分层统计**：不能写成 `while (!QueueEmpty(Q)) { p = DeQueue(Q); ... }`，这样会把所有层的结点混在一起，无法区分层。
2. **循环条件中 `rear` 变化导致错误**：必须先用 `levelCount` 固定当前层结点数，再进行 `for` 循环；如果写成 `for (int i = 0; i < rear - front; i++)`，而循环体内 `rear` 会增加，就会把刚入队的下一层结点也当作本层结点处理。
3. **空孩子入队问题**：只有左右孩子非空才能入队，否则队列中会出现空指针，后续访问 `p->lchild` 或 `p->rchild` 会出错。
4. **根层宽度漏算**：非空二叉树根层宽度为 $1$；如果一开始把 `width` 设为 0，第一次处理根层时会更新为 1；但若设计成先处理完再统计，容易漏掉根层。
5. **将“宽度”和“高度/深度”混淆**：高度是最大层数，宽度是某一层的最大结点数，两个概念不同。

**命题规律**：

这是二叉树遍历的经典应用题，考点是**层次遍历的扩展**。408 中经常出现类似变形：求二叉树高度、判断完全二叉树、求第 $k$ 层结点数、输出每一层的最右结点、之字形层次遍历等。复习时要熟练掌握 BFS 模板和“用当前队列长度分层”的技巧。另有一种做法是用深度优先遍历，用数组记录每一层结点数，最后取最大值；但层次遍历更直观、实现更简单，考试中优先使用。

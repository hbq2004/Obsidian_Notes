## DeepSeek V4 Flash Max 解析

**答案**：

（4）在“孩子-兄弟”链表中，原树/森林中的叶结点当且仅当 `firstChild == NULL`；递归遍历 `firstChild` 和 `nextSibling` 两条指针，累计满足条件的结点数即可。

（5）树深度按 408 的层数定义：空树深度为 0，非空树深度为  
$$
D(T)=1+\max_{u\in C(T)}D(u),
$$  
其中 $C(T)$ 是以 `T->firstChild` 为表头、`nextSibling` 为后继形成的孩子链表。

**解题切入点**：

“孩子兄弟表示法”本质上就是“左孩子右兄弟”的二叉树表示：`firstChild` 相当于左指针，`nextSibling` 相当于右指针。

做题时先画出原树对应的小孩兄弟链表，把它看成一棵二叉树。于是：

- 原树中的叶结点就是没有“左孩子”的结点，因为 `firstChild == NULL` 表示没有孩子。
- 求深度时，不能直接用普通二叉树深度公式，因为 `nextSibling` 指向的是兄弟而不是孩子，向右走不增加树的深度。

**推演**：

先给出结点类型：

```c
typedef struct CSNode {
    ElemType data;
    struct CSNode *firstChild, *nextSibling;
} CSNode, *CSTree;
```

### （4）求森林叶结点数

设 $L(T)$ 表示以 $T$ 为入口的子树/森林中的叶结点数。定义

$$
\ell(T)=
\begin{cases}
1, & T\ne \text{NULL} \land T\to\text{firstChild}=\text{NULL},\\
0, & \text{其他情况}.
\end{cases}
$$

则递归式为：

$$
L(T)=
\begin{cases}
0, & T=\text{NULL},\\[2mm]
\ell(T)+L(T\to\text{firstChild})+L(T\to\text{nextSibling}), & T\ne\text{NULL}.
\end{cases}
$$

关键代码：

```c
int CountLeaves(CSTree T) {
    if (T == NULL)
        return 0;

    int add = (T->firstChild == NULL) ? 1 : 0;

    return add
        + CountLeaves(T->firstChild)
        + CountLeaves(T->nextSibling);
}
```

如果传入的是森林根链，森林中第一棵树的根通过 `nextSibling` 连着下一棵树的根，上述递归会沿 `nextSibling` 继续处理，因此可以直接求出整个森林的叶结点数。

时间复杂度为 $O(n)$，$n$ 为森林中结点总数；递归栈空间最坏为 $O(n)$。

---

### （5）递归求树的深度

设 $D(T)$ 表示以 $T$ 为根的子树的深度。若 $T=\text{NULL}$，则 $D(T)=0$。

否则，设 $T$ 的孩子集合为：

$$
C(T)=\{T\to\text{firstChild},\ (T\to\text{firstChild})\to\text{nextSibling},\ldots\},
$$

若 $T$ 没有孩子，则 $C(T)=\varnothing$，此时 $\max\varnothing=0$。

于是：

$$
D(T)=
\begin{cases}
0, & T=\text{NULL},\\[2mm]
1+\max\limits_{u\in C(T)}D(u), & T\ne\text{NULL}.
\end{cases}
$$

关键代码：

```c
int Depth(CSTree T) {
    if (T == NULL)
        return 0;

    int maxDepth = 0;

    for (CSTree p = T->firstChild; p != NULL; p = p->nextSibling) {
        int d = Depth(p);
        if (d > maxDepth)
            maxDepth = d;
    }

    return maxDepth + 1;
}
```

注意：`Depth(T)` 中的 `for` 循环是在遍历 $T$ 的孩子链表；这里的 `p->nextSibling` 表示 $T$ 的下一个孩子，而不是 $T$ 的兄弟，不要与树根节点的 `nextSibling` 混淆。

如果输入的是森林根链，想求森林深度，则在外层再沿森林根节点的 `nextSibling` 取各棵树深度的最大值即可。

时间复杂度为 $O(n)$，空间复杂度最坏为 $O(n)$。

**易错点**：

- 叶结点判定只看 `firstChild == NULL`，不能看 `nextSibling == NULL`。一个叶子仍然可以有右兄弟。
- 求深度时不要套普通二叉树公式  
  $$
  D(T)=1+\max(D(T\to\text{firstChild}),D(T\to\text{nextSibling}))
  $$  
  因为 `nextSibling` 不是孩子，不能作为深度路径。
- 若采用教材常见写法  
  $$
  D(T)=\max(D(T\to\text{firstChild})+1,\ D(T\to\text{nextSibling})),
  $$  
  这里的 $D$ 表示“兄弟森林”的高度，第二项不能加 1，否则会把兄弟链也算作深度。
- 递归出口不可漏写空指针：空树深度为 0，空森林叶结点数为 0。
- 当题目输入是森林根链时，不要只处理第一棵树，否则会漏掉后面的树。

**命题规律**：

本题是“树/森林与二叉链表存储转换”的典型考点。408 中常以孩子兄弟表示法为背景，考查：

- 统计叶结点数、度为 $k$ 的结点数；
- 求树或森林的深度；
- 树/森林与二叉树的转换；
- 判断两棵树是否同构等。

复习时要把“孩子兄弟表示法”与“二叉树遍历”统一起来：`firstChild` 是进入下一层，`nextSibling` 是同一层横向移动。抓住这个本质，这类递归算法题就能直接写出递归式和代码。

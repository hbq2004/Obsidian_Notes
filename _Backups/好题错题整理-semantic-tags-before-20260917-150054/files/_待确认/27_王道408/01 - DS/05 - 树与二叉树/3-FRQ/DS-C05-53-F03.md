## DeepSeek V4 Flash Max 解析

**答案**：采用队列对二叉树做层次遍历，并在遍历过程中记录“当前层剩余结点数”和“下一层结点数”；每当当前层处理完，层数加 1。队列为空时返回的层数就是二叉树的高度。  
时间复杂度为 $O(n)$，空间复杂度为 $O(n)$，其中 $n$ 为二叉树结点总数。

**解题切入点**：先明确递归求二叉树高度的定义：  
$$
H(\text{NULL})=0,\qquad H(T)=1+\max\big(H(T\to lchild),H(T\to rchild)\big)
$$
但题目要求非递归，因此不能直接使用递归返回值。二叉树的高度本质是“最大层数”，而层次遍历（BFS）天然逐层扫描结点。算法竞赛中有一句经验：“BFS 可以求层数/最短步数，关键是分清楚每一层的边界。”所以这道题的核心就是：**用队列做层次遍历，并识别每一层的结束位置**。

**推演**：

按 408 教材约定：空树高度为 $0$，只有一个根结点时高度为 $1$。设二叉树结点定义为：

```c
typedef struct BTNode {
    int data;
    struct BTNode *lchild, *rchild;
} BTNode;
```

用队列 $Q$ 存储待访问结点。设：

- `now`：当前层还没有出队的结点数；
- `next`：下一层已经入队的结点数；
- `level`：当前已经处理完的层数。

初始时根结点入队，所以 `now = 1, next = 0, level = 0`。

每次从队列中取出一个结点时，`now--`；如果它有左孩子或右孩子，就将其入队，同时 `next++`。当 `now == 0` 时，说明当前这一层的所有结点都已经处理完，此时队列中正好装着下一层的全部结点，于是：

$$
level \leftarrow level + 1,\qquad now \leftarrow next,\qquad next \leftarrow 0
$$

重复上述过程，直到队列为空，`level` 就是二叉树的高度。

关键代码如下：

```c
#define MaxSize 100

int BTreeHeight(BTNode *root) {
    if (root == NULL)
        return 0;

    BTNode *Q[MaxSize];
    int front = 0, rear = 0;   // 队列头、尾指针
    int level = 0;             // 高度/层数
    int now = 1;               // 当前层待处理结点数
    int next = 0;              // 下一层结点数

    Q[rear++] = root;          // 根结点入队

    while (front < rear) {
        BTNode *p = Q[front++];  // 出队一个结点
        now--;

        if (p->lchild != NULL) {
            Q[rear++] = p->lchild;
            next++;
        }
        if (p->rchild != NULL) {
            Q[rear++] = p->rchild;
            next++;
        }

        if (now == 0) {          // 当前层处理完毕
            level++;
            now = next;
            next = 0;
        }
    }

    return level;
}
```

正确性可归纳证明：开始时队列中只有第 $1$ 层结点，`now=1`。假设处理第 $k$ 层时，队列中恰好包含第 $k$ 层全部结点，`now=|L_k|$。每出队一个第 $k$ 层结点，它的孩子都属于第 $k+1$ 层，因此全部入队后，`next$ 正好是第 $k+1$ 层结点数。当 `now==0` 时，第 $k$ 层全部处理完，此时队列中恰好是第 $k+1$ 层全部结点，再令 `now=next`，于是对第 $k+1$ 层同样成立。循环结束时，所有层都已处理完，所以 `level` 就是最大层数，即二叉树高度。

教材中还有一种等价写法，用 `last` 记录“当前层最后一个结点在队列中的位置”，代码如下：

```c
int BTreeHeight(BTNode *root) {
    if (root == NULL)
        return 0;

    BTNode *Q[MaxSize];
    int front = 0, rear = 0;
    int level = 0, last = 1;

    Q[rear++] = root;

    while (front < rear) {
        BTNode *p = Q[front++];

        if (p->lchild != NULL)
            Q[rear++] = p->lchild;
        if (p->rchild != NULL)
            Q[rear++] = p->rchild;

        if (front == last) {   // 当前层出队完毕
            level++;
            last = rear;       // rear 正好是下一层最后一个结点位置
        }
    }

    return level;
}
```

两种写法本质相同，都是“层次遍历 + 分层计数”。

**易错点**：

1. **忘记空树特判**。空树高度应为 $0$，若不特判直接让根结点入队会出错。  
2. **层次遍历没有分层，直接返回错误结果**。普通 BFS 只出队、入队，无法知道何时换层，必须用 `now/next` 或 `last` 标记层边界。  
3. **`now` 和 `next` 更新顺序错误**。应先处理当前层结点，再在孩子入队时累加 `next`；当 `now==0` 后才能 `level++`，不能提前加高度。  
4. **高度初始值弄错**。408 默认根结点在第 $1$ 层，空树高度 $0$，单结点高度 $1$；若按路径长度定义（边数），初值会不同，需看清题目约定。  
5. **使用栈模拟递归时忘记保存深度**。如果用栈做非递归 DFS，压栈时必须同时压入“当前结点深度”，否则出栈后无法正确更新最大深度。  
6. **静态队列空间不足**。最坏情况下队列长度可能达到 $O(n)$，例如完全二叉树的最大层结点数约为 $n/2$，需要保证队列容量足够。

**命题规律**：考点是“二叉树的遍历及应用”，重点考查非递归遍历和辅助结构（队列/栈）的使用。常见变式包括：求二叉树宽度（最多结点层）、判断完全二叉树、求某一层结点个数、之字形打印二叉树、找二叉树中某结点的祖先等。复习时建议把“层次遍历框架”作为模板记住，能熟练手写分层计数、层内处理、边界判断；同时要会分析时间复杂度和空间复杂度。这类题在 408 中常以综合题出现，代码量不大，但边界条件和分层逻辑是得分关键。

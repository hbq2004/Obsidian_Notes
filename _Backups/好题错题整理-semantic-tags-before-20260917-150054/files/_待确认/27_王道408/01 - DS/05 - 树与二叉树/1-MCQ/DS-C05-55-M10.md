# 选择题 第 10 题

![[_Attachments/题目识别/27_王道408-题目/DS-C05-55-M10_题目.png|题目]]

10. 并查集的结构是一种 ( )。
(A) 二叉链表存储的二叉树
(B) 双亲表示法存储的树
(C) 顺序存储的二叉树
(D) 孩子表示法存储的树

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C05-55-M10_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 **B**。并查集本质是用一个数组记录每个结点的双亲下标，用若干棵树表示若干集合，因此是“双亲表示法存储的树”。

**解题切入点**：  
看到“并查集”，先想它的两个核心操作：

- $\text{Find}(x)$：从结点 $x$ 不断向上找根；
- $\text{Union}(x,y)$：把两棵树的根合并。

“向上找根”需要知道每个结点的“父亲是谁”，不需要知道“孩子是谁”。所以并查集自然对应“双亲表示法”，而不是二叉链表、顺序二叉树或孩子表示法。

**推演**：

把每个集合看成**一棵树**，树的根作为该集合的代表元素。例如集合中有元素 $1,2,\dots,n$，用数组 $\text{parent}[i]$ 表示结点 $i$ 的双亲；根结点没有双亲，通常令 $\text{parent}[\text{根}]=-1$（也可约定 $\text{parent}[\text{根}]=\text{根}$，两者只是实现约定不同）。

查找操作：

$$
\text{Find}(x)=
\begin{cases}
x, & \text{parent}[x]=-1,\\[2mm]
\text{Find}(\text{parent}[x]), & \text{parent}[x]\ne -1.
\end{cases}
$$

合并操作：

$$
\text{Union}(x,y):\quad r_x=\text{Find}(x),\quad r_y=\text{Find}(y)
$$

若 $r_x\ne r_y$，则令：

$$
\text{parent}[r_y]=r_x
$$

也就是把一棵树的根接到另一棵树的根上。

所以并查集只需要存储“双亲指针”。对应代码思路：

```c
int parent[MAXN]; // 根结点 parent[root] = -1

int Find(int x) {
    while (parent[x] >= 0)
        x = parent[x];
    return x;
}

void Union(int x, int y) {
    int rx = Find(x);
    int ry = Find(y);
    if (rx != ry)
        parent[ry] = rx;
}
```

对照选项：

- A：二叉链表存储的二叉树，每个结点有左、右孩子指针，并查集不需要孩子指针；
- B：双亲表示法存储的树，正确；
- C：顺序存储的二叉树要求按下标关系存储完全二叉树/堆，并查集的数组不是这种含义；
- D：孩子表示法存储孩子链表，但不便于“向上找根”。

因此答案为 **B**。

**易错点**：

1. **把“一维数组”误认为“顺序存储的二叉树”**。  
   并查集虽然也用数组，但数组元素存的是“双亲下标”，不是按照二叉树层序关系存储的。

2. **混淆“双亲表示法”和“孩子表示法”**。  
   并查集核心操作是向上找根，所以必须知道双亲；孩子表示法只能方便地找孩子，不方便找祖先。

3. **忽略并查集整体是森林，不是一棵树**。  
   每个集合是一棵树，多个集合并在一起就是森林。选项 B 说“树”是指树形结构，本质也涵盖森林。

4. **实现时根结点判断条件写错**。  
   若约定根结点 $\text{parent}=-1$，查找终止条件是 $\text{parent}[x]<0$；若约定根结点指向自身，则终止条件是 $\text{parent}[x]=x$。两种写法不要混用。

**命题规律**：  
考点定位在“树与森林的存储结构”以及“并查集操作”。408 中常以选择题考查并查集采用什么存储结构，也可能在综合题中结合 **Kruskal 算法求最小生成树** 或 **无向图的连通分量** 考查 $\text{Find}$ 和 $\text{Union}$ 的模拟过程。复习时要会手动画出 $\text{parent}$ 数组的变化，掌握路径压缩和按秩合并，并能说出优化后 $m$ 次操作的复杂度近似为 $O(m\alpha(n))$。

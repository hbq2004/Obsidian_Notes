# 选择题 第 32 题

32.【2009统考真题】给定二叉树如右图所示。设 $N$ 代表二叉树的根, $L$ 代表根结点的左子树, $R$ 代表根结点的右子树。若遍历后的结点序列是 3175624，则其遍历方式是 ( ).

【图：二叉树结构】

A. $LRN$

B. $NRL$

C. $RLN$

D. $RNL$

## 答案

## DeepSeek V4 Flash Max 解析

**答案**：选 **C. $RLN$**，即“右子树 → 左子树 → 根”的遍历方式。

**解题切入点**：拿到这类题，先看“根 $N$ 在遍历序列中的位置”。题目给出序列为 $3,1,7,5,6,2,4$，结合原题树形，根结点为 $4$。根在最后一位，说明该遍历一定以 $N$ 结尾，而选项中只有 $LRN$ 和 $RLN$ 以根结尾；再比较左右子树的先后顺序，即可确定是 $RLN$。

**推演**：原题二叉树结构可简写为：
```text
        4
       / \
      2   7
     / \ / \
    6  5 1  3
```
其中根为 $4$，左子树根为 $2$，右子树根为 $7$。

按题中定义：
- $LRN$：左子树 → 右子树 → 根；
- $NRL$：根 → 右子树 → 左子树；
- $RLN$：右子树 → 左子树 → 根；
- $RNL$：右子树 → 根 → 左子树。

先看右子树（根为 $7$）按 $RLN$ 遍历：
- 右子树 $7$ 的右子树只有 $3$，得 $3$；
- 左子树只有 $1$，得 $1$；
- 最后访问根 $7$。

所以右子树 $7$ 的 $RLN$ 序列为：
$$3,1,7$$

再看左子树（根为 $2$）按 $RLN$ 遍历：
- 右子树只有 $5$，得 $5$；
- 左子树只有 $6$，得 $6$；
- 最后访问根 $2$。

所以左子树 $2$ 的 $RLN$ 序列为：
$$5,6,2$$

整棵树按 $RLN$ 遍历：
$$3,1,7 \quad 5,6,2 \quad 4$$
即：
$$3,1,7,5,6,2,4$$

与题目给出的序列完全一致。

**易错点**：
1. **混淆 $LRN$ 与 $RLN$**：二者都以根结尾，但 $LRN$ 先左后右，$RLN$ 先右后左。本题右子树 $3,1,7$ 排在前，所以不是 $LRN$。
2. **混淆 $NRL$ 与 $RNL$**：$NRL$ 根在最前，$RNL$ 根在中间。本题根 $4$ 在最后，应直接排除 $B$、$D$。
3. **递归子树也要按同一遍历规则**：不能只看整棵树第一层，左右子树内部仍需按 $RLN$ 递归遍历，否则容易错判为层序或其他顺序。

**命题规律**：本题属于“二叉树遍历方式判断”，核心是 $N,L,R$ 三种顺序的排列组合。常见变式有：给定树形和遍历序列判断遍历方式；给定遍历序列反推树形；已知两种遍历序列求第三种遍历序列。复习时应熟练掌握先序、中序、后序的递归定义，并能对 $NLR,LNR,LRN,NRL,RLN,RNL$ 六种排列进行手工模拟，尤其注意“根的位置”和“左右子树整体连续性”这两个判断突破口。

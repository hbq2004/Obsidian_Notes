## DeepSeek V4 Flash Max 解析

**答案**：选 **D**（原题图版）。由权值 $\{3,5,6,9,12\}$ 构造出的哈夫曼树，根为 $35$，一侧为 $14$（其下包含 $6$ 和 $8(3,5)$），另一侧为 $21$（其下包含 $9,12$）；其带权路径长度 $WPL=78$。

**解题切入点**：  
哈夫曼树的构造本质是贪心合并。拿到题目先把所有权值看作“当前森林”中的树根权值，每次选两个最小的合并，新结点的权值等于二者之和，再放回森林继续选最小。就像打扑克时不断把当前最小的两张“牌”合成一张新“牌”，直到只剩一张为止。

**推演**：

初始森林：$\{3,5,6,9,12\}$。

| 步骤 | 当前最小两棵 | 合并新权值 | 合并后的森林 |
|---|---|---|---|
| 1 | $3,5$ | $8$ | $\{6,8,9,12\}$ |
| 2 | $6,8$ | $14$ | $\{9,12,14\}$ |
| 3 | $9,12$ | $21$ | $\{14,21\}$ |
| 4 | $14,21$ | $35$ | $\{35\}$ |

因此树形为：

```text
        35
       /  \
      14   21
     /  \  / \
    6   8 9  12
       / \
      3   5
```

其中 $8$ 是内部结点，其左右孩子为叶子 $3,5$。

带权路径长度：

$$
WPL = 6\times2 + (3+5)\times3 + (9+12)\times2
=12+24+42=78
$$

也可用所有内部结点权值之和验证：

$$
WPL = 8+14+21+35=78
$$

关键代码思路：

```cpp
priority_queue<int, vector<int>, greater<int>> q;
for (int x : {3,5,6,9,12}) q.push(x);

while (q.size() > 1) {
    int a = q.top(); q.pop();
    int b = q.top(); q.pop();
    ans += a + b;
    q.push(a + b);
}
```

若需要建树，则在每次弹出 $a,b$ 时，以 $a+b$ 为新内部结点，$a,b$ 为其左右孩子即可。

**易错点**：  
- 合并后新结点必须重新放入候选集合，不能只对原始叶子两两合并。  
- 第二次合并时，当前最小的是 $6$ 和 $8$，不是 $9$ 和 $12$，也不是 $6$ 和 $9$。这一点最容易错。  
- 哈夫曼树是满二叉树：$5$ 个叶子应有 $5-1=4$ 个内部结点，不能出现度为 $1$ 的结点。  
- 左右子树交换不算错，判断时看“包含关系/权值分组”，不要死记左右位置。

**命题规律**：  
本考点是哈夫曼树的构造、$WPL$ 计算和前缀编码。408 中常见变式有：给一组权值判断正确树形、计算带权路径长度、判断一组编码是否为哈夫曼编码。复习时务必熟练掌握“每次选两个最小权值合并”的贪心模拟过程，以及用小顶堆实现哈夫曼算法的思路。

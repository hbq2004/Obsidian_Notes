# 选择题 第 3 题

![[_Attachments/题目识别/27_王道408-题目/DS-C05-55-M03_题目.png|题目]]

3. 下列编码中，（ ）不是前缀码。

A. $\{00,01,10,11\}$
B. $\{0,1,00,11\}$
C. $\{0,10,110,111\}$
D. $\{10,110,1110,1111\}$

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C05-55-M03_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：不是前缀码的是 **B**（$\{0,1,00,11\}$），因为码字 $0$ 是 $00$ 的前缀，$1$ 是 $11$ 的前缀。

**解题切入点**：看到“前缀码”，立刻回归定义：任何一个码字都不能是另一个码字的前缀。这和查字典时“一个词不能是另一个词的词头”是一个道理。做题时先找最短码字，再检查它是否为其他更长码字的前缀；若出现“短码字是长码字开头的连续若干位”，则一定不是前缀码。

**推演**：  
前缀码的严格定义：对于编码集合 $C$，若 $\forall x,y\in C$，$x$ 不是 $y$ 的前缀且 $y$ 不是 $x$ 的前缀，则称 $C$ 为前缀码。  
逐项判断：

A. $\{00,01,10,11\}$  
所有码字长度均为 $2$，两个不同码字必在某一位不同，因此不可能互为前缀。  
即：$\{00,01,10,11\}$ 是前缀码。

B. $\{0,1,00,11\}$  
取 $0$ 和 $00$：$00$ 的前两位是 $0$，所以 $0$ 是 $00$ 的前缀。  
同理，$1$ 是 $11$ 的前缀。  
因此 $\{0,1,00,11\}$ 不是前缀码。

C. $\{0,10,110,111\}$  
检查所有可能的前缀关系：
- $0$ 与 $10,110,111$ 首字符不同，互不为前缀；
- $10$ 与 $110,111$ 开头两位分别为 $10$ 和 $11$，不同，互不为前缀；
- $110$ 与 $111$ 前两位相同，但第三位分别为 $0$ 和 $1$，互不为前缀。  
所以 $\{0,10,110,111\}$ 是前缀码。

D. $\{10,110,1110,1111\}$  
检查所有可能的前缀关系：
- $10$ 与 $110,1110,1111$ 开头两位分别为 $10$ 和 $11$，不同，互不为前缀；
- $110$ 与 $1110,1111$ 前两位相同，但第三位 $0$ 和 $1$ 不同，互不为前缀；
- $1110$ 与 $1111$ 前三位相同，但第四位 $0$ 和 $1$ 不同，互不为前缀。  
所以 $\{10,110,1110,1111\}$ 是前缀码。

综上，只有 B 不是前缀码。

**易错点**：
1. **将“前缀”与“包含子串”混淆**：例如 D 中 $110$ 包含子串 $10$，但 $10$ 不是 $110$ 的前缀，因为前缀必须从开头连续匹配，因此 D 仍是前缀码。
2. **只比较相邻长度码字，漏掉长度差更大的码对**：应逐一检查所有码字对，特别关注短码字是否是某个长码字的开头。
3. **误以为码长不同就一定是前缀码**：如 B 中 $0$ 和 $00$ 码长不同，但 $0$ 是 $00$ 的前缀，所以不是前缀码。
4. **忘记等长码天然是前缀码**：A 项等长，可直接判为前缀码，节省时间。

**命题规律**：本题是“树与二叉树”及“哈夫曼编码”部分的经典概念题，考研中常以选择题形式考查前缀码的判别。常见变式有：给定一棵二叉树，判断其叶子编码是否为前缀码；给定若干码字，判断是否满足唯一可译码；结合哈夫曼树，要求写出某个哈夫曼编码并说明它为什么是前缀码。复习时应以“前缀码 $\leftrightarrow$ 二叉树叶子节点”为桥梁，理解哈夫曼编码的构造原理，并熟练掌握逐对比较的判定方法。做题时先看有无等长码、再看最短码字是否为其他码字前缀，可快速选出正确答案。

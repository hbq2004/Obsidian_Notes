# 选择题 第 5 题

![[_Attachments/题目识别/27_王道408-题目/DS-C05-52-M05_题目.png|题目]]

5. 设高度为$h$的二叉树上只有度为0和度为2的结点, 则此类二叉树中所包含的结点数至少为( )。
(A) $h$
(B) $2h - 1$
(C) $2h + 1$
(D) $h + 1$

## DeepSeek V4 Flash Max 解析

**答案**：选 **(B) \(2h-1\)**。核心结论：没有度为 1 的结点，高度每增加 1 层，至少要增加 2 个结点。

**解题切入点**：  
先抓关键条件：“只有度为 0 和度为 2 的结点”等价于“不存在单分支结点”，即每个非叶结点都必须有 2 个孩子。题目问“至少”多少个结点，属于最值问题，可用“极端构造法”定位：要想高度达到 \(h\)，必须有一条从根到叶的长度为 \(h\) 的路径；为了省钱，只保留这条“主干”，其余分支能省则省。这样可类比为“一条链上每个非叶结点再挂一个叶子做陪衬”。

**推演**：  
按 408 教材定义，根结点为第 1 层，高度 \(h\) 表示最大层数。

设度为 2 的结点数为 \(n_2\)，叶子数为 \(n_0\)，总结点数为 \(n\)。  
因为是二叉树且没有度为 1 的结点，所以：

\[
n = n_0 + n_2
\]

树中边数 \(e = n-1\)，结点的度之和等于边数，而只有度为 2 的结点贡献孩子数，因此：

\[
2n_2 = n - 1
\]

所以：

\[
n = 2n_2 + 1
\]

要使总结点数最少，就要使度为 2 的结点数 \(n_2\) 尽可能少。

取一条从根到叶的最长路径，路径上有 \(h\) 个结点。除最后一个叶子结点外，前面 \(h-1\) 个结点都必须有孩子；但题目不允许度为 1，所以这 \(h-1\) 个结点都必须是度为 2 的结点。因此：

\[
n_2 \ge h-1
\]

于是：

\[
n = 2n_2 + 1 \ge 2(h-1)+1 = 2h - 1
\]

这个下界可以达到：构造一条含 \(h\) 个结点的“主干”路径，并给前 \(h-1\) 个主干结点各补一个叶子作为另一个孩子。这样非叶结点都有 2 个孩子，叶子结点度为 0，总结点数为：

\[
h + (h-1) = 2h - 1
\]

因此最少结点数为 \(2h-1\)。

等价递推思想为：

\[
f(1)=1,\qquad f(h)=f(h-1)+2
\]

也就是高度每增加 1，只沿主干延长一层，同时必须补一个叶子结点。

**易错点**：  
- 容易误以为普通二叉树高度为 \(h\) 时最少是 \(h\) 个结点，但本题不允许出现度为 1 的结点，所以不能选 (A)。  
- 容易把“至少”和“至多”混淆；若问最多，才是满二叉树的 \(2^h-1\)。  
- 高度按“边数”理解会写成 \(2h+1\)，但 408 中树的深度/高度按层数理解，根为第 1 层。  
- 用特殊值检验时，只代 \(h=2\) 不够，因为此时 \(2h-1=3\) 与 \(h+1=3\) 相同；应代 \(h=3\) 排除 (D)，或直接用递推式判断。  
- 注意 \(h=1\) 时只有一个根结点，选项 (A) 和 (B) 数值相同，这是特例；通式应取 \(2h-1\)。

**命题规律**：  
本题是二叉树基本性质的经典考点，常结合“度、结点数、高度”三者之间的关系命题。核心公式是：

\[
n=n_0+n_1+n_2,\qquad \text{边数}=n-1,\qquad \text{度数和}=边数
\]

对于“只有度为 0 和 2”的二叉树，还有常用结论：

\[
n_0=n_2+1
\]

变式可能考查：已知叶子数求总结点数、求完全二叉树的高度范围、求给定高度下的最大或最小结点数，以及推广到 \(k\) 叉树。复习时应掌握“找最长路径 + 极端构造法”处理最值问题，并注意区分“至少”和“至多”。

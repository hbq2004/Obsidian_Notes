37.【2014统考真题】若对右图所示的二叉树进行中序线索化，则结点 $X$ 的左右线索指向的结点分别是 ( )。
A. e,c
B. e,a
C. d,c
D. b,a

【图：二叉树结构，根为 a，左子为 b，右子为 c；b 的左子为 d，右子为 X；d 的右子为 e.】

## DeepSeek V4 Flash Max 解析

**答案**：结点 $X$ 在中序线索化后，左线索指向其中序前驱 $b$，右线索指向其中序后继 $a$，故选 **D. b, a**。

**解题切入点**：线索化不改变二叉树的中序遍历逻辑，它只是把空指针按照中序遍历序列“接上前驱/后继”。所以拿到题先写出整棵树的中序序列，再找 $X$ 前后相邻的两个结点即可，不要一上来就盯住指针逐个改。

**推演**：

题图二叉树结构可整理为：

$$
\begin{array}{c}
a \\
/ \ \backslash \\
b \quad c \\
/ \ \backslash \\
d \quad X \\
\backslash \\
e
\end{array}
$$

按中序遍历“左根右”：

1. 先遍历 $a$ 的左子树，根为 $b$；
2. 遍历 $b$ 的左子树，根为 $d$；
3. $d$ 无左孩子，访问 $d$；
4. $d$ 的右孩子是 $e$，访问 $e$；
5. 访问 $b$；
6. 访问 $b$ 的右孩子 $X$；
7. 访问根 $a$；
8. 访问 $a$ 的右孩子 $c$。

所以中序遍历序列为：

$$
\operatorname{InOrder}(T)=(d,\ e,\ b,\ X,\ a,\ c)
$$

因此，$X$ 的中序前驱是 $b$，中序后继是 $a$。

由于题图中 $X$ 是叶子结点，左右指针均为空：

- $X$ 的左指针作为线索，指向前驱 $b$；
- $X$ 的右指针作为线索，指向后继 $a$。

对应中序线索化核心代码思路：

```cpp
void InThread(ThreadNode *p, ThreadNode *&pre) {
    if (p == NULL) return;
    InThread(p->lchild, pre);          // 中序遍历左子树
    if (p->lchild == NULL) {           // 当前结点无左孩子
        p->lchild = pre;               // 左线索指向前驱
        p->ltag = 1;
    }
    if (pre != NULL && pre->rchild == NULL) { // 前驱无右孩子
        pre->rchild = p;               // 前驱的右线索指向当前结点
        pre->rtag = 1;
    }
    pre = p;                           // 更新前驱
    InThread(p->rchild, pre);          // 中序遍历右子树
}
```

执行到 $X$ 时，$pre=b$，所以 $X$ 的左线索指向 $b$；访问到 $a$ 时，$pre=X$，所以 $X$ 的右线索被设置为 $a$。

**易错点**：

- 容易把 $X$ 的右线索误判为 $c$。注意中序序列中 $X$ 后面是 $a$，然后才是 $c$，所以右线索指向 $a$。
- 容易把 $d$ 的右孩子 $e$ 的位置放错，导致中序序列写错。$e$ 在 $d$ 的右子树中，因此访问顺序是 $d,e$，不是 $e,d$。
- 不要把线索指针当作普通孩子指针。线索化后必须结合 $ltag/rtag$ 判断：若为线索，则指向中序前驱/后继。
- 如果结点原本有孩子，则对应指针不能作为线索。本题中 $X$ 是叶子，所以左右指针均可作为线索。

**命题规律**：本题属于“树与二叉树”中的线索二叉树考点，核心是考查中序遍历序列与线索指向的关系。常见变式有：求某结点的前驱/后继、给定线索树还原中序遍历序列、前序/后序线索化、线索二叉树中插入或删除结点。复习时应把三种遍历序列写熟，并自己画二叉树手写 $ltag/rtag$，再配合递归或非递归线索化代码理解。

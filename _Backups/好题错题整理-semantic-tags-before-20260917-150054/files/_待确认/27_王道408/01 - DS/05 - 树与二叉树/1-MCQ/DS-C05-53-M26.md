# 选择题 第 26 题

![[_Attachments/题目识别/27_王道408-题目/DS-C05-53-M26_题目.png|题目]]

26. 在线索二叉树中，下列说法不正确的是( ).
A. 在中序线索树中，若某结点有右孩子，则其后继结点是它的右子树的最左下结点
B. 在中序线索树中，若某结点有左孩子，则其前驱结点是它的左子树的最右下结点
C. 线索二叉树是利用二叉树的 $n+1$ 个空指针来存放结点的前驱和后继信息的
D. 每个结点通过线索都可以直接找到它的前驱和后继

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C05-53-M26_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 D。线索二叉树只是把原二叉树中的 $n+1$ 个空指针改造成线索，并不是给每个结点都增加前驱、后继两条线索；有左/右孩子的结点，其指针仍指向孩子，不能保证“每个结点都通过线索直接找到前驱和后继”。

**解题切入点**：
这是概念辨析题，考点是“线索二叉树中空指针、孩子指针与线索的关系”。拿到题目先抓两点：

1. 线索不是新增指针，而是利用原有空指针；
2. 标志位 $\text{ltag},\text{rtag}$ 用于区分“孩子”和“线索”。

看到 D 中“每个”“都”“直接”这类绝对化表述，应立刻怀疑。线索只存在于空指针处，不可能每个结点都同时拥有前驱线索和后继线索。

**推演**：

设二叉树有 $n$ 个结点。二叉链表共有 $2n$ 个指针域；除根结点外，每个结点都被一个父指针指向，所以非空指针数为 $n-1$。因此空指针数为：

$$
2n-(n-1)=n+1
$$

线索二叉树正是利用这 $n+1$ 个空指针来存放某种遍历序下的前驱/后继信息，所以 C 正确。

线索二叉树的标志位定义如下：

$$
\text{ltag}=
\begin{cases}
0, & \text{lchild 指向左孩子}\\
1, & \text{lchild 指向前驱}
\end{cases}
$$

$$
\text{rtag}=
\begin{cases}
0, & \text{rchild 指向右孩子}\\
1, & \text{rchild 指向后继}
\end{cases}
$$

对于中序线索二叉树：

- 若某结点有右孩子，则中序遍历访问完该结点后，下一步进入其右子树；右子树中第一个被访问的结点是“最左下”结点。因此 A 正确。
- 若某结点有左孩子，则中序遍历访问其左子树时，最后一个被访问的结点是“最右下”结点。因此 B 正确。

中序线索树中找后继、前驱的算法思路可写为：

```c
// 找后继
if (p.rtag == 1)
    return p.rchild;
q = p.rchild;
while (q.ltag == 0)
    q = q.lchild;
return q;

// 找前驱
if (p.ltag == 1)
    return p.lchild;
q = p.lchild;
while (q.rtag == 0)
    q = q.rchild;
return q;
```

D 的错误在于：只有原先为空的指针才能被改成线索。若某结点左右孩子都存在，则它的左右指针都指向孩子，不是线索，因此它身上不可能同时有前驱线索和后继线索。例如中序序列为 $B,A,C$ 的二叉树中，根结点 $A$ 有左右孩子，$A$ 的左右指针都不是线索；找 $A$ 的前驱需进入左子树找最右下结点，找后继需进入右子树找最左下结点。

因此“每个结点通过线索都可以直接找到它的前驱和后继”说法错误。

**易错点**：

- 误以为线索二叉树给每个结点都新增了两个线索指针，实际上只是把原有的 $n+1$ 个空指针改作他用。
- 容易把前驱/后继规则记反：  
  有右孩子时，后继为“右子树最左下”结点；  
  有左孩子时，前驱为“左子树最右下”结点。  
  可记为：“找后继，向右走一步后一直向左；找前驱，向左走一步后一直向右。”
- 忽略标志位：$\text{tag}=0$ 表示孩子，$\text{tag}=1$ 才是线索。
- 看到“每个”“都”“直接”等绝对化表述，应优先怀疑其正确性。

**命题规律**：

408 常以选择题考查线索二叉树的概念与性质，常见变式有：

- 求给定结点的前驱/后继；
- 计算 $n$ 个结点的二叉树线索化后空指针或线索数量；
- 判断某棵二叉树中线索的具体指向；
- 比较前序、中序、后序线索树查找前驱/后继的可行性。

复习时应手工画一棵小树，标出 $\text{ltag},\text{rtag}$，完整体会“中序线索树中，有右孩子则后继为右子树最左下结点，有左孩子则前驱为左子树最右下结点”，并牢记“线索来自空指针”这一根本性质。

# 选择题 第 15 题

![[_Attachments/题目识别/27_王道408-题目/DS-C05-53-M15_题目.png|题目]]

15. 若一棵二叉树的中序序列和后序序列相同，则( ).

(A) 二叉树为空树或二叉树任一结点没有左子树

(B) 二叉树为空树或二叉树任一结点没有右子树

(C) 二叉树为空树或二叉树中每个结点的度为1

(D) 二叉树为空树或二叉树为满二叉树

## DeepSeek V4 Flash Max 解析

**答案**：选 **B**。一棵二叉树的中序序列和后序序列相同，当且仅当该二叉树为空树，或每个结点都没有右子树（即退化为向左倾斜的单支树）。

**解题切入点**：中序遍历是“左—根—右”，后序遍历是“左—右—根”。两者最关键的区别在于根和右子树的相对位置：中序中根在右子树之前，后序中根在右子树之后。因此从“根在中序序列和后序序列中的位置”入手。可以类比由中序 + 后序重建二叉树的思路：后序序列最后一个元素是根，再到中序序列中找根；如果根在中序序列中不是最后一个，说明有右子树，则两序列不可能相同。

**推演**：设非空二叉树 $T$ 的根为 $r$，左子树为 $T_L$，右子树为 $T_R$，且 $|T_L|=a$，$|T_R|=b$。

中序序列为
$$
I(T)=I(T_L)\,r\,I(T_R),
$$
后序序列为
$$
P(T)=P(T_L)\,P(T_R)\,r.
$$

在中序序列中，$r$ 前面恰好有 $a$ 个结点；在后序序列中，$r$ 是最后一个结点，$r$ 前面共有 $a+b$ 个结点。若 $I(T)=P(T)$，则同一结点 $r$ 在相同序列中的位置必须相同，所以
$$
a+1=a+b+1,
$$
得到 $b=0$。因此 $T_R$ 为空，即根结点没有右子树。

此时
$$
I(T)=I(T_L)\,r,\qquad P(T)=P(T_L)\,r.
$$
因为 $I(T)=P(T)$，所以 $I(T_L)=P(T_L)$。对左子树 $T_L$ 继续做同样推理，可知 $T_L$ 的根也没有右子树。递归下去，得到结论：每个结点都没有右子树。

反过来，若每个结点都没有右子树，则对任意结点都有
$$
I(T)=I(T_L)\,r,\qquad P(T)=P(T_L)\,r.
$$
由归纳假设 $I(T_L)=P(T_L)$，立即得 $I(T)=P(T)$。空树显然也满足。故等价于选项 B。

判定代码思路如下：

```c
bool check(TreeNode* root) {
    if (root == NULL) return true;
    if (root->right != NULL) return false; // 右子树非空，中序和后序中根位置矛盾
    return check(root->left);
}
```

**易错点**：

1. 误选 A：左子树为空并不一定满足。反例：只有右孩子的链 $r\to a$，中序为 $r,a$，后序为 $a,r$，并不相同。  
2. 误选 C：非空有限二叉树必有叶子结点，叶子结点度为 $0$，不可能每个结点度都为 $1$；即使理解为“单支树”，也必须限定为向左的单支树。  
3. 忽略空树：空树的中序序列和后序序列均为空，也满足条件。  
4. 混淆根的位置：中序序列的根在左右子树之间，后序序列的根在最后；不要和先序序列的“根在前”混淆。

**命题规律**：本题属于“二叉树遍历序列性质”，常以选择题或小综合题出现。核心规律是：后序序列最后一个结点是根，用该根去中序序列中定位；若根在中序序列中位于最后，则无右子树，再递归看左子树。类似变式有：

- 前序序列 = 中序序列 $\Leftrightarrow$ 每个结点无左子树；
- 中序序列 = 后序序列 $\Leftrightarrow$ 每个结点无右子树；
- 前序序列 = 后序序列 $\Leftrightarrow$ 树为空或只有一个结点。

复习时应熟练掌握三种遍历的递归顺序，并会用“单结点、左右单支、满二叉树”等小树快速排除错误选项。

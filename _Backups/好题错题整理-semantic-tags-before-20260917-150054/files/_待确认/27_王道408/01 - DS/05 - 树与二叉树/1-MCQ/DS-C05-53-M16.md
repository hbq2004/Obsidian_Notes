## DeepSeek V4 Flash Max 解析

**答案**：由后序序列 $DABEC$ 的最后一个结点 $C$ 为根，结合中序序列 $DEBAC$ 递归划分左右子树，可得先序序列为 $CEDBA$，故选 **D**。

**解题切入点**：拿到“已知后序 + 中序，求先序”的题，先抓“根”。后序序列的最后一个结点一定是当前二叉树的根；中序序列中根的位置把中序序列分成左子树和右子树。这就好比“剥洋葱”：后序给出根，中序给出左右子树的大小，一层层递归剥开，即可重建整棵二叉树。作为选择题，可先用“后序最后一个元素是根”排除先序序列不以 $C$ 开头的选项，但关键还是要掌握完整重建过程。

**推演**：

设当前子树的后序区间为 $P[l..r]$，中序区间为 $I[p..q]$。由遍历定义：

$$
\text{后序}(T)=\text{后序}(T_L)+\text{后序}(T_R)+\text{根}
$$

$$
\text{中序}(T)=\text{中序}(T_L)+\text{根}+\text{中序}(T_R)
$$

因此，后序的最后一个元素是根；在中序中找到根后，根左边的长度就是左子树结点数，右边长度就是右子树结点数。

本题中：

$$
P=DABEC,\qquad I=DEBAC
$$

1. 后序 $DABEC$ 的最后一个元素是 $C$，所以根为 $C$。  
   在中序 $DEBAC$ 中，$C$ 在最右侧，因此 $C$ 的右子树为空，左子树的中序序列为 $DEBA$。  
   后序中对应左子树的后序序列为前 $4$ 个字符 $DABE$。

2. 对左子树 $P=DABE$，$I=DEBA$：  
   后序最后一个元素是 $E$，所以该子树根为 $E$。  
   在中序 $DEBA$ 中，$E$ 左边是 $D$，右边是 $BA$，所以：
   - $E$ 的左子树为 $D$；
   - $E$ 的右子树中序为 $BA$，后序为 $AB$。

3. 对 $E$ 的右子树 $P=AB$，$I=BA$：  
   后序最后一个元素是 $B$，所以根为 $B$。  
   在中序 $BA$ 中，$B$ 左边为空，右边为 $A$，所以 $B$ 无左孩子，右孩子为 $A$。

还原出的二叉树为：

```
      C
     /
    E
   / \
  D   B
       \
        A
```

按先序“根左右”遍历：

$$
\text{先序序列}=C\,E\,D\,B\,A=CEDBA
$$

因此选择 **D**。

关键递归代码思路如下：

```c
void rebuild(int pl, int pr, int il, int ir) {
    if (pl > pr) return;              // 空子树
    char root = post[pr];             // 后序最后一个元素是根
    int k = pos[root];                // 根在中序中的位置
    int leftLen = k - il;             // 左子树结点数

    ans.push_back(root);              // 先序：先访问根
    rebuild(pl, pl + leftLen - 1, il, k - 1);       // 左子树
    rebuild(pl + leftLen, pr - 1, k + 1, ir);       // 右子树
}
```

**易错点**：

- 误把后序序列的最后一个元素当作“最后的叶子”，实际上它是当前子树的根。  
- 划分后序序列时，不能直接按后序字符顺序随意切分，而要根据中序中根左边的长度来确定左右子树在后序中的长度。  
- 容易忽略空子树，例如本题中 $C$ 无右子树、$B$ 无左子树。忽略空子树会导致结构错误。  
- 做完后可快速验证：先序序列的第一个元素必须是整棵树的根 $C$，选项 A、B、C 均不以 $C$ 开头，只有 D 满足。

**命题规律**：本题属于“二叉树遍历序列互推”的高频考点，核心是利用二叉树的递归定义和中序序列的“左根右”结构。常见变式有：已知先序 + 中序求后序，已知后序 + 中序求先序，已知层次 + 中序重建二叉树，或进一步求树高、叶子结点、祖先关系等。复习时应熟练掌握“由根划分左右子树”的递归方法，并会用先序/后序序列快速确定根、用中序序列确定左右子树范围；若题目考查算法设计，可用哈希表记录中序位置，使重建时间复杂度达到 $O(n)$。

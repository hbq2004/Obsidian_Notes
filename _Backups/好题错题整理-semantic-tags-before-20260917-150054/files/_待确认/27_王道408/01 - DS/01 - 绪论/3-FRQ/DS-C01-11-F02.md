## DeepSeek V4 Flash Max 解析

**答案**：第 1 题三个程序段的时间复杂度分别为 $O(n)$、$O(\sqrt n)$、$O(nm)$；第 2 题以线性表的“按位查找”为例，顺序存储为 $O(1)$，链式存储为 $O(n)$。

**解题切入点**：看到代码段求时间复杂度，先找基本操作，再设循环执行次数 $T$，根据循环条件列出关于 $T$ 的不等式；看到“逻辑结构相同、运算相同、存储方式不同”，马上想到用线性表的顺序存储和链式存储对比，一个可随机存取，一个只能顺序存取。

**推演**：

**（一）程序段 ①**

```c
i=1,k=0;
while(i<n-1){
    k=k+10*i;
    i++;
}
```

基本操作可看作 `i++` 或 `k=k+10*i`。设循环体执行 $T(n)$ 次。循环变量 $i$ 从 1 开始，每次增 1，能进入循环体的条件是 $i<n-1$，所以 $i$ 依次取 $1,2,\dots,n-2$，共执行

$$
T(n)=n-2
$$

次。因此时间复杂度为

$$
O(n)
$$

**（二）程序段 ②**

```c
y=0;
while((y+1)*(y+1)<=n)
    y=y+1;
```

设循环体执行 $T$ 次。第 $T$ 次执行前 $y=T-1$，能执行则必须满足

$$
T^2 \le n
$$

执行完第 $T$ 次后 $y=T$，循环停止，说明

$$
(T+1)^2 > n
$$

因此 $T$ 是满足 $T^2 \le n < (T+1)^2$ 的整数，即

$$
T=\lfloor \sqrt{n} \rfloor
$$

时间复杂度为

$$
O(\sqrt n)
$$

**（三）程序段 ③**

```c
for(i=0;i<n;i++)
    for(j=0;j<m;j++)
        a[i][j]=0;
```

外层循环执行 $n$ 次，每次内层循环执行 $m$ 次，基本操作 `a[i][j]=0` 共执行

$$
n \times m
$$

次，时间复杂度为

$$
O(nm)
$$

**（四）第 2 题举例：线性表按位查找**

以线性表为例，逻辑结构相同，运算都是“按位查找第 $i$ 个元素”。

- 顺序存储：元素连续存放，可直接通过地址公式计算

$$
\mathrm{LOC}(a_i)=\mathrm{LOC}(a_0)+iL
$$

其中 $L$ 为每个元素占用的存储单元数。因此可以随机存取，时间复杂度为 $O(1)$。

- 链式存储：结点通过指针链接，不能直接计算第 $i$ 个元素的地址，必须从表头开始沿 `next` 指针逐个移动，类似：

```c
p = head;
k = 1;
while(p != NULL && k < i){
    p = p->next;
    k++;
}
```

最坏情况下需要遍历到表尾，时间复杂度为 $O(n)$。

所以，相同的逻辑结构、同一种运算，在不同存储方式下实现时，运算效率确实不同。

**易错点**：

- ① 中循环条件是 `i<n-1`，不是 `i<=n-1`，循环体执行 $n-2$ 次，不是 $n-1$ 次；但渐近复杂度都写作 $O(n)$。
- ② 中 $y$ 从 0 开始，且判断条件是 $(y+1)^2$，容易把执行次数写成 $\sqrt n-1$；要注意最终执行次数是 $\lfloor\sqrt n\rfloor$。
- ③ 中若题目没有说明 $m$ 是常数，不能将 $O(nm)$ 简化为 $O(n)$；只有 $m$ 为常数时才可写作 $O(n)$。
- 概念题不要误认为链表也可以随机存取；链表的“按位查找”必须遍历，顺序表之所以能 $O(1)$ 查找，是因为连续存储带来的直接地址计算。

**命题规律**：时间复杂度分析是 408 高频考点，常以选择题或综合题形式给出代码段，考查循环次数与问题规模的关系，变式包括单层循环、双层循环、对数阶循环、递归方程等。逻辑结构与存储结构的关系是第一章核心，常见变式还有“顺序表与链表在插入、删除、查找上的效率对比”，以及“数组按行优先/列优先存储的地址计算”。复习时应熟练掌握顺序存储和链式存储的三大基本操作复杂度对比表，并养成“设循环次数 $T$、列不等式”的做题习惯。

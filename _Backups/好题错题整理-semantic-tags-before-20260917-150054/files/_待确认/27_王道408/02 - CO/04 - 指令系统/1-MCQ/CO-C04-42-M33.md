# 选择题 第 33 题

![[_Attachments/题目识别/27_王道408-题目/CO-C04-42-M33_题目.png|题目]]

33.【2023统考真题】某运算类指令中有一个地址码为通用寄存器编号,对应通用寄存器中存放的是操作数或操作数的地址,$CPU$区分两者的依据是（ ）.

(A) 操作数的寻址方式
(B) 操作数的编码方式
(C) 通用寄存器的编号
(D) 通用寄存器的内容

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C04-42-M33_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A。CPU 根据指令中的“寻址方式”判断通用寄存器中存放的是操作数还是操作数的地址。

**解题切入点**：看到“通用寄存器中存放的是操作数或操作数的地址”，应立即定位到两种寻址方式：寄存器寻址与寄存器间接寻址。CPU 区分二者靠的是指令中显式给出的寻址方式字段，而不是寄存器内容本身。可以类比：一个变量的二进制值本身无法区分是“整数”还是“指针”，要靠指令/类型信息来决定如何解释它。

**推演**：

设指令中地址码给出的通用寄存器编号为 $R_i$，寄存器内容记为 $\mathrm{R}[R_i]$。

若寻址方式为寄存器寻址，则操作数就是寄存器内容：

$$
\text{操作数}=\mathrm{R}[R_i]
$$

若寻址方式为寄存器间接寻址，则寄存器内容不是操作数，而是操作数的有效地址：

$$
\text{操作数地址}=\mathrm{R}[R_i],\qquad \text{操作数}=\mathrm{M}[\mathrm{R}[R_i]]
$$

其中 $\mathrm{M}[\cdot]$ 表示按地址访问主存。

可见，同一个寄存器编号 $R_i$、同一份寄存器内容，在两种寻址方式下含义完全不同。因此：

- CPU 不能根据“通用寄存器的内容”判断，因为数据本身没有“我是地址”或“我是操作数”的标记；
- CPU 也不能根据“通用寄存器的编号”判断，因为同一个寄存器既可以用于寄存器寻址，也可以用于寄存器间接寻址；
- “操作数的编码方式”通常指操作数在机器内的表示形式，如原码、补码、IEEE 754 等，与“寄存器内容是否为地址”无关；
- CPU 是在指令译码阶段根据指令中的寻址方式字段来区分两者的。

因此，CPU 区分两者的依据是“操作数的寻址方式”，选 A。

**易错点**：

1. 误选 D（通用寄存器的内容）：认为看到内容像地址就是地址。实际同一二进制串既可以解释为数值，也可以解释为地址，硬件不能靠内容自行辨别。
2. 误选 C（通用寄存器的编号）：寄存器编号只决定“用的是哪个寄存器”，不决定“寄存器里的内容作何解释”。
3. 误选 B（操作数的编码方式）：操作数编码方式讨论的是数的表示方法，与“寄存器直接寻址/寄存器间接寻址”的区分不是同一概念。
4. 需要注意：寻址方式字段可能作为指令中独立字段出现，也可能与操作码共同译码，但本质都是 CPU 区分寻址方式的基础。

**命题规律**：本题属于 408 计算机组成原理中“指令系统”与“寻址方式”的经典考点。常见变式有：给出指令格式和寄存器内容，要求计算有效地址或操作数；比较寄存器寻址与寄存器间接寻址；结合基址寻址、变址寻址出题。复习时应重点掌握每种寻址方式的访存次数、有效地址计算方法，以及 CPU 译码阶段如何根据寻址方式字段控制数据通路。

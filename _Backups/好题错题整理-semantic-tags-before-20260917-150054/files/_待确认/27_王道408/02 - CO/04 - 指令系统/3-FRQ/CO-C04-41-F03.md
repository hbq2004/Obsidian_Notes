# 综合题 第 3 题

![[_Attachments/题目识别/27_王道408-题目/CO-C04-41-F03_题目.png|题目]]

3.在一个36位长的指令系统中，设计一个扩展操作码，使之能表示下列指令：
(1) 7条具有两个15位地址和一个3位地址的指令。
(2) 500条具有一个15位地址和一个3位地址的指令。
(3) 50条无地址指令。

4.2 指令的寻址方式
1.某机的机器字长为16位，主存按字编址，指令格式如下：

| 位号 | 15 ~ 10 | 9 ~ 8 | 7 ~ 0 |
| :---: | :---: | :---: | :---: |
| 内容 | 操作码 | X | D |

其中，$D$为位移量；$X$为寻址特征位。
$X=00$：直接寻址；$X=01$：用变址寄存器 $X_1$ 进行变址。
$X=10$：用变址寄存器 $X_2$ 进行变址；$X=11$：相对寻址。

设 $(PC)=1234H$，$(X_1)=0037H$，$(X_2)=1122H$（$H$ 代表十六进制数），请确定下列指令的有效地址：
① $4420H$
② $2244H$
③ $1322H$
④ $3521H$
⑤ $6723H$

## 3. 扩展操作码设计

**答案**：三地址指令操作码3位，用7个编码（如001~111），留000作为扩展标志；二地址指令操作码18位，前3位固定为000，后15位中留全0作为零地址扩展标志，其余32767个编码中取500个；零地址指令操作码36位，前18位固定为全0，后18位取50个编码。此方案可满足要求。

**解题切入点**：扩展操作码的核心是操作码长度随地址码减少而增加，且短操作码的编码不能是长操作码的前缀。首先确定最短操作码（三地址）的位数，留出扩展标志，然后逐级扩展，确保每级编码空间足够容纳所需指令数，并预留下一级扩展标志。

**推演**：

指令总长度36位。

- 三地址指令：地址字段为两个15位和一个3位，共33位，故操作码位数为$36-33=3$位。3位操作码有$2^3=8$种编码，需7条指令，用去7个，剩下1个作为扩展标志，设为$000$（二进制）。
- 二地址指令：地址字段为一个15位和一个3位，共18位，故操作码位数为$36-18=18$位。其前3位必须为三地址扩展标志$000$，后15位自由编码。后15位有$2^{15}=32768$种编码，需表示500条二地址指令，同时需留出零地址扩展标志。设后15位全$0$（即$000000000000000$）作为零地址扩展标志，则二地址指令可用后15位中除全$0$外的$32767$个编码，取500个即可。
- 零地址指令：无地址字段，操作码36位。其前18位必须为二地址扩展标志，即前3位$000$后15位全$0$，故前18位固定为$000000000000000000$（全0）。后18位自由编码，有$2^{18}=262144$种编码，取50个即可。

因此，方案可行。具体编码示例：
- 三地址指令：操作码 $001$ ~ $111$（二进制）。
- 二地址指令：操作码前18位为 $000$ + 后15位（非全0），取500个不同值。
- 零地址指令：操作码前18位为 $000000000000000000$，后18位取50个不同值。

**易错点**：易错点包括：1）未预留扩展标志，导致指令编码冲突；2）各级指令操作码位数计算错误；3）忽略扩展标志的编码空间，导致二地址指令或零地址指令数量不够。例如，若二地址指令后15位全0被用作二地址指令，则无法区分零地址指令。

**命题规律**：扩展操作码是计算机组成原理常考知识点，常与指令格式、地址码数量、指令条数结合。变式包括：给定指令条数，设计操作码位数或判断能否实现；给定操作码方案，计算最多指令条数。复习时需掌握扩展操作码的原理，确保短操作码不占用长操作码的前缀，并合理分配扩展标志。

## 4.2 指令的寻址方式

**答案**：
① $4420H$：有效地址为 $0020H$（直接寻址）。
② $2244H$：有效地址为 $1166H$（变址寻址，$X_2$）。
③ $1322H$：有效地址为 $1256H$（相对寻址）。
④ $3521H$：有效地址为 $0058H$（变址寻址，$X_1$）。
⑤ $6723H$：有效地址为 $1257H$（相对寻址）。

**解题切入点**：首先根据指令格式提取寻址特征位 $X$（位9~8）和位移量 $D$（位7~0），然后根据 $X$ 的值确定寻址方式，最后计算有效地址。注意 $D$ 为8位，在直接寻址中直接作为地址（高8位补0），在变址和相对寻址中需符号扩展为16位后与寄存器或PC相加。

**推演**：

指令格式：$15\sim10$位操作码，$9\sim8$位 $X$，$7\sim0$位 $D$。已知 $(PC)=1234H$，$(X_1)=0037H$，$(X_2)=1122H$。

① $4420H$
二进制：$0100\ 0100\ 0010\ 0000$
$X=00$（直接寻址），$D=0010\ 0000B=20H$，有效地址 $EA = D = 0020H$。

② $2244H$
二进制：$0010\ 0010\ 0100\ 0100$
$X=10$（变址寻址，用 $X_2$），$D=0100\ 0100B=44H$，符号扩展为 $0044H$，$EA = (X_2) + D = 1122H + 0044H = 1166H$。

③ $1322H$
二进制：$0001\ 0011\ 0010\ 0010$
$X=11$（相对寻址），$D=0010\ 0010B=22H$，符号扩展为 $0022H$，$EA = (PC) + D = 1234H + 0022H = 1256H$。

④ $3521H$
二进制：$0011\ 0101\ 0010\ 0001$
$X=01$（变址寻址，用 $X_1$），$D=0010\ 0001B=21H$，符号扩展为 $0021H$，$EA = (X_1) + D = 0037H + 0021H = 0058H$。

⑤ $6723H$
二进制：$0110\ 0111\ 0010\ 0011$
$X=11$（相对寻址），$D=0010\ 0011B=23H$，符号扩展为 $0023H$，$EA = (PC) + D = 1234H + 0023H = 1257H$。

**易错点**：易错点包括：1）$D$ 的符号扩展：若 $D$ 为负数（最高位为1），需扩展为16位补码，否则计算错误；2）直接寻址时，$D$ 即为地址，不应符号扩展；3）变址和相对寻址时，寄存器内容与 $D$ 相加，注意进位；4）正确提取 $X$ 和 $D$，注意位序，避免混淆。

**命题规律**：寻址方式计算是基础题，常结合指令格式给出指令字，要求计算有效地址。变式包括：不同寻址方式组合，加入基址寻址，或给出多组寄存器值。复习时需熟练掌握各寻址方式的定义，注意位移量的符号扩展，以及寄存器内容已知时的计算。

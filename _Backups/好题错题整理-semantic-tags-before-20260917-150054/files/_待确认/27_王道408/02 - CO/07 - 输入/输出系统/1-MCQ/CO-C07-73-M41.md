# 选择题 第 41 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M41_题目.png|题目]]

41.【2017统考真题】下列关于多重中断系统的叙述中，错误的是（ ）.
A. 在一条指令执行结束时响应中断
B. 中断处理期间 $CPU$ 处于关中断状态
C. 中断请求的产生与当前指令的执行无关
D. $CPU$ 通过采样中断请求信号检测中断请求

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M41_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。多重中断系统支持中断嵌套，不能在中断处理全过程中一直关中断；进入中断服务程序后需要开中断，以便响应更高优先级的中断请求。

**解题切入点**：看到“多重中断”要立刻联想到“中断嵌套”。题干问“错误的是”，选项 B 中“中断处理期间 CPU 处于关中断状态”过于绝对，明显与多重中断允许嵌套的特性矛盾。因此先锁定 B，再逐项验证其余说法。

**推演**：

多重中断系统的处理流程大致为：

1. CPU 在一条指令执行结束时采样中断请求信号；
2. 若检测到中断请求，CPU 进入中断响应；
3. 中断响应阶段硬件自动关中断（$\mathrm{IF}\leftarrow 0$），保存断点、识别中断源；
4. 进入中断服务程序后，先保护现场，然后开中断（$\mathrm{IF}\leftarrow 1$）；
5. 在执行中断服务程序主体时，若出现更高优先级的中断请求，CPU 可以响应，形成中断嵌套；
6. 返回前需要关中断，恢复现场，再开中断并中断返回。

所以，多重中断系统中，“关中断”只用于响应阶段、保护现场和恢复现场等临界区，而不是“整个中断处理期间”都关中断。

逐项判断：

- A 正确：外部中断请求在一条指令执行结束时被响应。
- B 错误：多重中断处理期间不能始终关中断。
- C 正确：外部中断请求由外部事件产生，与当前正在执行的指令无关；CPU 只是到指令边界才采样。
- D 正确：CPU 通过采样中断请求信号来检测中断请求。

**易错点**：

1. 把“多重中断”和“单重中断”混淆。单重中断处理过程中确实关中断，但多重中断需要开中断以实现嵌套。
2. 误以为“开中断”表示中断处理全程都开放。实际上保护现场、恢复现场等关键阶段仍需关中断。
3. 看到选项 C 想到除零异常等内部异常。注意题干讨论的是“中断请求”，主要指外部硬件中断；内部异常才与当前指令相关。
4. 误选 A。外部中断正是在当前指令执行结束时响应，若当前指令执行中发生异常，则属于另一类情况。

**命题规律**：

考点是中断系统，特别是“单重中断/多重中断”的区别、中断响应时机、开中断与关中断的位置。常见变式有：给出中断服务程序片段，判断开中断/关中断位置是否正确；结合中断屏蔽字考查中断嵌套；或将“外部中断”与“内部异常”混合命制。复习时应熟记中断处理流程：关中断 → 保存断点 → 识别中断源 → 保护现场 → 开中断 → 执行中断服务 → 关中断 → 恢复现场 → 开中断 → 中断返回。

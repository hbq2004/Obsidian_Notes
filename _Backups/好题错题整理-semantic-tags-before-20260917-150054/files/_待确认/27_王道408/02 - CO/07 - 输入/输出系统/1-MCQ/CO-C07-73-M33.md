# 选择题 第 33 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M33_题目.png|题目]]

33.【2009 统考真题】下列选项中,能引起外部中断的事件是（  ）

A. 键盘输入
B. 除数为0
C. 浮点运算下溢
D. 访存缺页

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M33_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A。键盘输入由外部设备（键盘）向 CPU 发出中断请求，属于外部中断；除数为 0、浮点运算下溢、访存缺页都是由 CPU 内部或指令执行过程引发的异常。

**解题切入点**：先判断事件是来自 CPU 外部还是 CPU 内部。外部设备（如键盘、鼠标、打印机）引起的中断是“外部中断”；CPU 执行指令过程中自身检测到的错误（如除零、缺页）属于“异常”。做题时就像写程序时分清“外部输入错误”和“内部逻辑错误”一样，来源决定分类。

**推演**：

在计算机组成原理中，“中断”有广义和狭义之分。狭义的外部中断指由 CPU 外部的设备发出的中断请求，是异步事件；而 CPU 内部在执行指令过程中发生的异常称为“内部中断”或“异常”，是同步事件。

逐一分析选项：

- **A. 键盘输入**：键盘是典型的外部 I/O 设备。当有按键按下时，键盘接口会向 CPU 发出中断请求信号（如 INTR）。CPU 在执行完当前指令后，如果中断允许标志为允许，则响应该外部中断，转到键盘中断服务程序处理输入数据。因此，键盘输入能引起外部中断。

- **B. 除数为 0**：这是 CPU 执行除法指令时，由运算器或控制器发现除数为 0 而产生的异常。它由当前指令的执行过程直接触发，属于 CPU 内部异常，不是外部设备引起的外部中断。

- **C. 浮点运算下溢**：浮点运算过程中，若运算结果的阶码小于允许的最小值，则发生下溢。这由 CPU 内部的浮点运算部件检测到，属于内部异常或特殊处理事件，并非外部中断。

- **D. 访存缺页**：CPU 访问内存时，需要经过 MMU（存储器管理单元）进行地址变换。如果页表项的有效位为 0，则产生缺页异常。该异常由 MMU 在访存过程中触发，属于内部异常（故障），也不属于外部中断。

因此，只有 A 是外部中断。

**易错点**：

- 容易把“除数为 0”误认为外部中断，实际上它是 CPU 执行指令时产生的内部异常。
- 容易把“缺页”当作中断。缺页虽然也需要操作系统介入，但它是 CPU 访存时由 MMU 检测出来的异常，属于内部事件。
- 容易把“浮点运算下溢”与“外部设备产生的中断”混淆。下溢是浮点运算单元内部状态导致的，属于内部异常。
- 判断标准不是“是否打断当前程序”，而是“事件来源在 CPU 内部还是外部”。外部中断由外部设备信号引起，异常由 CPU 自身执行指令引起。

**命题规律**：本题是 408 常考的基础概念题，主要考查“中断”与“异常”的分类，特别是外部中断与内部异常的区分。常见的变式有：给出键盘输入、时钟中断、打印机请求等外部事件，或给出除零、非法指令、缺页、溢出、越界等内部异常，要求选择属于外部中断的选项。复习时需牢记：外部中断来自 CPU 外部设备，是异步的；异常来自 CPU 内部，是同步的。特别注意缺页、除零、溢出、下溢、非法指令等都属于异常，而非外部中断。

# 选择题 第 9 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-36-M09_题目.png|题目]]

9. 下列有关缺页处理的叙述中，错误的是 ( )

A. 若对应页表项中的有效位为 0，则发生缺页

B. 缺页是一种外部中断，需要调用操作系统提供的中断服务程序来处理

C. 缺页处理过程中需根据页表中给出的磁盘地址去读磁盘数据

D. 缺页处理完后要重新执行发生缺页的指令

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-36-M09_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。缺页是 CPU 在执行指令时同步产生的内中断（异常/故障），不是外部中断；它需要调用操作系统提供的异常处理程序来处理。

**解题切入点**：拿到题先判断缺页的中断分类。缺页虽然常被称为“缺页中断”，但 408 中“中断”有广义、狭义之分：外中断专指来自 CPU 外部的异步事件，缺页属于 CPU 内部的异常。可类比：程序运行时因访问非法内存触发运行时错误（RE），这是程序内部异常，不是键盘、网络等外部信号。

**推演**：

在请求分页系统中，页表项中的有效位（存在位）$V$ 表示该页是否在主存中：

$$
V=
\begin{cases}
1, & \text{页面在主存中}\\
0, & \text{页面不在主存中}
\end{cases}
$$

- **A 正确**：进程访问某页时，若对应页表项的有效位 $V=0$，说明该页不在内存，MMU/存储管理部件会触发缺页异常。

- **B 错误**：外中断是由 I/O 设备、时钟等 CPU 外部事件引起的，与当前指令的执行无直接关系。缺页是 CPU 访存时内部产生的异常，属于“内中断”中的“故障”（fault），不是“外部中断”。它需要进入核心态，由 OS 的缺页异常处理程序完成调页。

- **C 正确**：缺页处理时，操作系统需要知道该页在外存的存放位置。在 408 教材模型中，页表项中会保存该页的磁盘地址（外存地址），缺页处理程序据此启动磁盘 I/O，将页面读入内存。

- **D 正确**：缺页发生时，当前指令尚未执行完；处理完缺页后，必须回到发生缺页的指令重新执行，而不是直接执行下一条指令。

因此错误的是 B。

**易错点**：

1. **把缺页当成外部中断**：这是本题最大陷阱。缺页是 CPU 内部同步异常，属于内中断/故障，不是外中断。
2. **混淆“有效位为 0”的含义**：有效位为 0 不是“页表项不存在”，而是“页面不在主存中”，此时仍然可能通过页表项或 OS 数据结构找到磁盘地址。
3. **忽略“重新执行指令”**：系统调用（trap）处理完通常回到下一条指令，而缺页是 fault，处理完必须重新执行原指令。
4. **对磁盘地址来源不清晰**：页表项中可保存该页的外存地址；缺页处理时要利用该地址读磁盘，不能误以为只能去文件系统从头查找。

**命题规律**：本题考点是虚拟存储中的缺页异常，以及内外中断的分类。常见变式有：判断缺页是内中断还是外中断；给出一段缺页处理流程要求排序；结合页表项的有效位、修改位、访问位考查；区分缺页“重新执行原指令”和系统调用“回到下一条指令”。复习时建议把外中断、陷阱、故障、终止做成对比表，并结合地址翻译和缺页处理流程图理解记忆。

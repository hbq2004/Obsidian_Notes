# 选择题 第 6 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-32-M06_题目.png|题目]]

6. 下列关于存储器的说法中，不正确的是（ ）

(A) 随机存储器和只读存储器不可以统一编址
(B) 在访问随机存储器时，访问时间与存储单元的物理位置无关
(C) 随机存储器（RAM）芯片可随机存取信息，掉电后信息会丢失
(D) 只读存储器（ROM）芯片可随机存取信息，掉电后信息不会丢失

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-32-M06_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A。随机存储器（RAM）和只读存储器（ROM）在内存地址空间中完全可以统一编址，因此“不可以统一编址”说法错误。

**解题切入点**：先抓住“存储器分类”与“编址方式”这两个核心概念。题目问“不正确的是”，应优先检查选项中的绝对化表述，如“不可以”“不会”“时间与位置无关”等。本题 A 选项带有绝对否定词“不可以”，需要谨慎验证。

**推演**：

1. 选项 (A)：随机存储器和只读存储器不可以统一编址。  
   在计算机系统中，CPU 访问内存时通过统一的地址总线进行寻址。内存地址空间既可以分配给 RAM，也可以分配给 ROM。例如，典型的 PC 中，低地址部分由 RAM 占据，高地址部分由 ROM（如 BIOS）占据，二者在同一个地址空间中编址，CPU 使用相同的地址信号访问它们。因此 RAM 和 ROM 完全可以统一编址，选项 A 说法错误。

2. 选项 (B)：在访问随机存储器时，访问时间与存储单元的物理位置无关。  
   RAM 的“随机存取”含义就是：任何存储单元的访问时间相同，与物理位置无关。因此 B 正确。

3. 选项 (C)：随机存储器（RAM）芯片可随机存取信息，掉电后信息会丢失。  
   RAM 是易失性存储器，掉电后数据丢失，且支持随机存取。因此 C 正确。

4. 选项 (D)：只读存储器（ROM）芯片可随机存取信息，掉电后信息不会丢失。  
   ROM 虽然名字含“只读”，但在工作原理上同样通过地址译码实现随机存取（即访问时间与位置无关），且其内容在掉电后能够保存。因此 D 正确。

综上，不正确的是 A。

**易错点**：

- 误以为“只读存储器”不能随机存取。实际上 ROM 同样支持按地址随机访问，只是写入操作受限（或不可写），不能把“只读”等同于“只能顺序存取”。
- 误以为 RAM 和 ROM 必须分在不同地址空间。实际中二者可共存于同一地址空间，通过片选信号区分，统一编址。
- 对“随机存取”概念理解不深，可能误认为 B 错误。随机存取的核心是“访问时间与位置无关”，这是相对于磁带等顺序存取介质而言的。

**命题规律**：

- 本题属于存储器基础概念题，常考 RAM、ROM 的特性（易失/非易失、随机存取）以及地址统一编址问题。
- 常见变式：给出 RAM、ROM、Cache、磁盘等存储介质，判断其访问特性；或给出某系统内存地址分配图，判断 RAM 与 ROM 的地址范围；也可结合“存储系统层次结构”考查统一编址与总线连接。
- 复习建议：牢记各类存储器的特点（易失性、可读可写性、存取方式），理解“统一编址”的含义，并注意区分“只读”与“不可随机访问”这两个不同概念。

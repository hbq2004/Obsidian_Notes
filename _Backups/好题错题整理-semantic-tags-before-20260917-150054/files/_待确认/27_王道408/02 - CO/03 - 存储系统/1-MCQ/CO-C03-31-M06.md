# 选择题 第 6 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-31-M06_题目.png|题目]]

6. 计算机的存储系统是指（ ）.
A. $RAM$
B. $ROM$
C. 主存储器
D. 寄存器、$Cache$、主存储器和外存储器

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-31-M06_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。计算机的存储系统不是某一类存储器，而是由寄存器、Cache、主存储器和外存储器按层次构成的统一存储体系；RAM、ROM 只是主存中使用的存储器件，主存也只是存储系统中的一个层次。

**解题切入点**：  
看到“存储系统”要先区别于“存储器”。只要题目出现“系统/层次”，就应立刻回忆存储层次图：CPU 寄存器 → Cache → 主存 → 外存。可以类比一支队伍：寄存器是首发核心，Cache 是快速替补，主存是主力阵容，外存是后备仓库；A、B、C 都只看到了某一个位置，只有 D 覆盖了整个体系。

**推演**：  
存储系统的层次结构为  
$$
\text{CPU 寄存器}\to \text{Cache}\to \text{主存储器}\to \text{外存储器}
$$

各层次作用如下：

- 寄存器：位于 CPU 内部，速度最快、容量最小；
- Cache：高速缓冲存储器，用于缓解 CPU 与主存之间的速度矛盾；
- 主存储器：存放当前运行的程序和数据，RAM 和 ROM 都是主存的组成部分；
- 外存储器：长期保存信息，容量大、速度慢，CPU 不能直接访问外存，需先调入主存。

逐项排除：

- A. $RAM$ 只是主存中的随机存取存储器，不能代表整个存储系统；
- B. $ROM$ 只是只读存储器，也不能覆盖整个存储系统；
- C. 主存储器只是存储层次中的一个层次，缺少寄存器、Cache 和外存；
- D. 寄存器、Cache、主存储器和外存储器共同组成完整的存储系统。

所以选 D。

**易错点**：  
- 把“存储系统”混同于“主存储器”，导致错选 C；
- 把 RAM 或 ROM 当成主存全部，甚至当成存储系统，导致错选 A 或 B；
- 忽略寄存器：寄存器虽然不是传统意义上的“主存”，但在存储层次中它是最靠近 CPU 的存储部件，属于广义存储系统；
- 不要误认为 CPU 可以直接访问外存，外存信息必须先调入主存后才能被 CPU 使用。

**命题规律**：  
本题属于 408 中“存储系统/存储层次”的基本概念题，常以选择题形式考查。常见变式有：  
- 存储层次由哪些部分组成？  
- Cache-主存层次主要解决速度问题，主存-外存层次主要解决容量问题；  
- 速度、容量、单位价格的排序比较；  
- CPU 能否直接访问外存？  

复习时应画出存储层次图，并标出各层次的速度、容量、价格和作用，理解“寄存器-主存-外存”之间如何通过硬件或操作系统协同工作。

# 选择题 第 33 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-35-M33_题目.png|题目]]

33.【2017统考真题】某 C 语言程序段如下：

```c
for (i = 0; i <= 9; i++){
    temp = 1;
    for (j=0; j <= i; j++)    temp *= a[j];
    sum += temp;
}
```

下列关于数组 $a$ 的访问局部性的描述中,正确的是（ ）

A. 时间局部性和空间局部性皆有

B. 无时间局部性,有空间局部性

C. 有时间局部性,无空间局部性

D. 时间局部性和空间局部性皆无

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-35-M33_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A。该程序对数组 $a$ 既重复访问前面的元素，又按连续下标顺序访问相邻元素，所以时间局部性和空间局部性皆有。

**解题切入点**：拿到双层循环访问数组的题目，不要先想 cache 容量或替换策略，而是先把“访问轨迹”写出来，像做算法题先手算小规模样例一样：

$$
i=0:\ a[0];\quad i=1:\ a[0],a[1];\quad i=2:\ a[0],a[1],a[2];\quad \ldots
$$

然后对照局部性定义判断：同一地址是否被重复访问？相邻地址是否在短时间内连续访问？

**推演**：

局部性定义：

- 时间局部性：某存储单元被访问后，不久后可能再次被访问。
- 空间局部性：某存储单元被访问后，其附近地址的存储单元不久后也可能被访问。

把数组下标访问序列按外层 $i$ 分组：

| 外层 $i$ | 内层访问下标 |
|---:|---|
| $0$ | $0$ |
| $1$ | $0,1$ |
| $2$ | $0,1,2$ |
| $\vdots$ | $\vdots$ |
| $9$ | $0,1,\ldots,9$ |

判断时间局部性：

对任意 $0\le k\le 9$，当外层 $i\ge k$ 时，内层循环都会访问 $a[k]$。因此 $a[k]$ 的访问次数为：

$$
10-k
$$

例如：

- $a[0]$ 被访问 $10$ 次；
- $a[1]$ 被访问 $9$ 次；
- $\ldots$
- $a[9]$ 被访问 $1$ 次。

显然数组元素存在大量重复访问，尤其 $a[0],a[1],\ldots,a[8]$ 都会被再次访问，因此有时间局部性。

判断空间局部性：

内层循环总是按：

$$
j=0,1,2,\ldots,i
$$

的顺序访问数组元素。C 语言中数组元素在内存中连续存放，$a[j]$ 与 $a[j+1]$ 的地址相邻，所以程序会在较短时间内访问连续地址的存储单元，因此有空间局部性。

综上，数组 $a$ 的访问既有时间局部性，又有空间局部性，选 A。

**易错点**：

1. 误以为“只读不写”就没有局部性。局部性包括读访问和写访问，重复读同样体现时间局部性。
2. 看到外层循环从 $a[0]$ 重新开始，误以为访问“乱跳”。实际上内层始终连续扫描，且跳回 $a[0]$ 本身就是重复访问，恰好体现时间局部性。
3. 把“局部性”和“cache 是否命中”混为一谈。局部性是程序访问模式本身的属性；即使 cache 很小导致部分数据被替换，也不能说程序没有局部性。
4. 误以为“每个元素都要被重复访问”才算时间局部性。 $a[9]$ 只访问一次，不影响整个数组访问模式具有时间局部性的结论。

**命题规律**：本题对应 408 中“存储系统—局部性原理”基础考点。常见变式包括：判断二维数组按行优先/列优先访问的局部性；给定不同步长访问数组；结合 cache 行大小、映射方式、替换策略计算命中率或缺失率。复习建议：看到数组循环，先写出下标或地址访问序列；判断时间局部性看同一地址是否重复出现，判断空间局部性看相邻地址是否连续出现；内层步长为 $1$ 通常空间局部性好，外层重复扫描同一段通常时间局部性好。

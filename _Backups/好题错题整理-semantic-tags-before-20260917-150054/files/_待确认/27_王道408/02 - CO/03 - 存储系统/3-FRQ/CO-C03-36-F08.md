# 综合题 第 8 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-36-F08_题目.png|题目]]

8.【2023统考真题】已知计算机 M 的字长为 32 位,按字节编址,采用请求调页策略的虚拟存储管理方式,虚拟地址为 32 位,页大小为 4KB;数据 Cache 采用 4 路组相联映射方式,数据区大小为 8KB,主存块大小为 32B。现有 C 语言程序段如下:

```c
int a[24][64];
...
for(i=0;i<24;i++)
    for(j=0;j<64;j++) a[i][j]=10;
```

现已知二维数组 a 按行优先存放,在虚拟地址空间中分配的起始地址为 $00422000\mathrm{H}$, $sizeof(int) = 4$, 假定在 M 上执行上述程序段之前数组 a 不在主存,且在该程序段执行过程中不会发生页面置换。问:

(1) 数组 a 分布在几个页面中?对于数组 a 的访问,会发生几次缺页异常?页故障地址各是什么?
(2) 不考虑变量 i 和 j, 该程序段的数据访问是否具有时间局部性?为什么?
(3) 该计算机 M 的虚拟地址 $(31\sim 0)$ 中哪几位用作块内地址?哪几位用作 Cache 组号?$a[1][0]$ 的虚拟地址是多少?其所在主存块对应的 Cache 组号是多少?
(4) 数组 a 占用多少主存块?假设上述程序段执行过程中数组 a 的访问不会和其他数据发生 Cache 访问冲突,则数组 a 的 Cache 命中率是多少?将循环中 i 和 j 的次序按如下方式调换:

```c
for(j=0;j<64;j++)
    for(i=0;i<24;i++)
        a[i][j]=10;
```

则数组 a 的 Cache 命中率又是多少?

## 答案

## DeepSeek V4 Flash Max 解析

**答案**  
(1) 数组 a 分布在 **2 个页面**中；执行过程中对数组 a 的访问会发生 **2 次缺页异常**，页故障地址分别为  
$$00422000\mathrm{H},\quad 00423000\mathrm{H}.$$

(2) **不具有时间局部性**。因为每个数组元素只被写入一次，不会被短时间重复访问；但按行访问连续地址，具有明显的空间局部性。

(3) 块内地址用虚拟地址的 $4\sim0$ 位；Cache 组号用虚拟地址的 $10\sim5$ 位。  
$a[1][0]$ 的虚拟地址为 $00422100\mathrm{H}$，其所在主存块对应的 Cache 组号为 **8**。

(4) 数组 a 占用 $192$ 个主存块。原循环次序下 Cache 命中率为  
$$\frac{7}{8}=87.5\%.$$  
交换 $i$、$j$ 循环次序后，Cache 命中率仍为  
$$\frac{7}{8}=87.5\%.$$

---

**解题切入点**  
先统一按字节计算：数组大小、页大小、Cache 块大小、组数。  
可以把页看成“大箱子”，Cache 块看成“小盒子”。一个 32B 的小盒子能放 8 个 int；只要小盒子没有被换出，它里面的 8 个 int 第一次访问是缺失，后面 7 次就是命中。命中率主要看“每个 Cache 块访问几次”，而不是逐个 int 数。

---

**推演**  

### (1) 页面数与缺页次数

数组元素个数为  
$$24\times64=1536,$$  
每个 int 占 4B，所以数组总大小为  
$$1536\times4=6144\mathrm{B}=6\mathrm{KB}.$$

页大小为 $4\mathrm{KB}$，起始地址 $00422000\mathrm{H}$ 的低 12 位为 0，说明数组从页边界开始。  
数组一行占  
$$64\times4=256\mathrm{B}.$$  
每个页面可以放  
$$\frac{4\mathrm{KB}}{256\mathrm{B}}=16$$  
行数组。

数组有 24 行，因此前 16 行在第 1 页，后 8 行在第 2 页。所以数组分布在 **2 个页面**中。

由于采用请求调页，且数组 a 初始不在主存，执行过程中又不会发生页面置换，所以第一次访问每个页面时都会发生一次缺页异常。  
- 第 1 页缺页由访问 $a[0][0]$ 触发，地址为  
  $$00422000\mathrm{H}.$$
- 第 2 页缺页由访问 $a[16][0]$ 触发。因为第 16 行相对数组起始地址偏移  
  $$16\times256=4096=0x1000,$$  
  所以地址为  
  $$00422000\mathrm{H}+0x1000=00423000\mathrm{H}.$$

因此共发生 **2 次缺页异常**。

---

### (2) 时间局部性

原程序按行优先依次给每个数组元素赋值，每个元素只会被写入一次，不会在短时间内被再次访问。  
因此对于数组 a 的数据访问，**没有时间局部性**。

但是访问顺序是连续的，相邻地址的数组元素会被连续访问，所以具有**空间局部性**。

---

### (3) 地址划分与 $a[1][0]$ 的 Cache 组号

Cache 数据区大小为 $8\mathrm{KB}$，块大小为 $32\mathrm{B}$，采用 4 路组相联映射，所以 Cache 组数为  
$$\frac{8\mathrm{KB}}{32\mathrm{B}\times4}=64=2^6.$$

因此需要 5 位块内地址，6 位 Cache 组号。

虚拟地址从低位开始划分：

- $4\sim0$ 位：块内地址，因为 $32\mathrm{B}=2^5\mathrm{B}$；
- $10\sim5$ 位：Cache 组号，因为共有 $64=2^6$ 组。

计算 $a[1][0]$ 的虚拟地址。  
数组按行优先存放，$a[1][0]$ 是第 1 行第 0 个元素，相对数组起始地址偏移为  
$$(1\times64+0)\times4=256=0x100.$$

所以  
$$a[1][0]\text{ 的虚拟地址}=00422000\mathrm{H}+0x100=00422100\mathrm{H}.$$

取 $00422100\mathrm{H}$ 的 $10\sim5$ 位：

$$001000_2=8.$$

因此 $a[1][0]$ 所在主存块对应的 Cache 组号为 **8**。

---

### (4) 主存块数与 Cache 命中率

数组大小为 $6144\mathrm{B}$，主存块大小为 $32\mathrm{B}$，所以数组 a 占用主存块数为  
$$\frac{6144}{32}=192.$$

Cache 共有 64 组，每组 4 路，因此可容纳  
$$64\times4=256$$  
个主存块。数组有 192 个块，平均到 64 组中，每组约  
$$\frac{192}{64}=3$$  
个块，小于 4 路，因此数组自身不会造成 Cache 组内冲突。

每个主存块大小为 $32\mathrm{B}$，可存放  
$$\frac{32}{4}=8$$  
个 int。

#### 原循环次序：行优先

按行访问时，每个 32B 主存块中的 8 个 int 会被连续访问。第一次访问该块时发生缺失，把块调入 Cache；随后同一块中的另外 7 个 int 都命中。

总访问次数为  
$$24\times64=1536.$$

每个主存块第一次访问缺失一次，共有 192 个主存块，所以缺失次数为 192，命中次数为  
$$1536-192=1344.$$

命中率为  
$$\frac{1344}{1536}=\frac{7}{8}=87.5\%.$$

#### 交换 $i$、$j$ 次序后：列优先

交换后访问顺序变为按列访问，但数组 a 的 192 个主存块仍然能够同时驻留在 Cache 中，且每个组最多只需要存放 3 个块，不超过 4 路，因此不会因为访问顺序改变而发生额外的容量缺失或冲突缺失。

每个主存块中的 8 个 int 仍然会被访问 8 次，只是访问时间间隔变大；但由于该块不会被换出，所以仍然是第一次访问缺失，后面 7 次命中。

因此命中率仍为  
$$\frac{7}{8}=87.5\%.$$

---

**易错点**  
- 容易把数组大小算成 $24\times64=1536\mathrm{B}$，忘记乘 `sizeof(int)=4`。  
- 页故障地址应写“触发缺页的虚拟地址”，而不是页面号。本题中恰好与页起始地址一致。  
- Cache 组号需要 6 位，不是 5 位，注意是 $10\sim5$ 位，不是 $9\sim5$ 位。  
- 求 $a[1][0]$ 地址时，容易把行偏移算成 $1\times64\times4=256$，要记得这是第 2 行的开始。  
- 命中率计算时，不要以为每个元素都命中；每个主存块第一次访问会缺失。  
- 本题默认按写分配处理：写缺失时也会把主存块调入 Cache。如果写成“写不分配”，命中率会完全不同。

---

**命题规律**  
这是 408 中“虚拟存储器 + Cache + 程序局部性”结合的典型题目。  
常见变式有：

- 修改 Cache 组相联度、块大小、总容量，考察组号位数和冲突缺失；
- 修改数组行列数、起始地址，考察页面跨越和页故障次数；
- 交换循环顺序，考察空间局部性、时间局部性以及 Cache 命中率变化；
- 结合 TLB、页表、物理地址索引等进一步扩展。

复习时要把“地址划分”“页故障地址”“Cache 映射”“命中率计数”这几部分练熟，尤其要会区分时间局部性和空间局部性。

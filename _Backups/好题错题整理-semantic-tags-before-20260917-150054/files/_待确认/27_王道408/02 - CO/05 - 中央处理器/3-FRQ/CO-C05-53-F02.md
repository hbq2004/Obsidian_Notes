# 综合题 第 2 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-53-F02_题目.png|题目]]

2. 设 $CPU$ 内部结构如下图所示，此外还设有 $B$、$C$、$D$、$E$、$H$、$L$ 六个寄存器(图中未画出)它们各自的输入端和输出端都与内部总线相通,并分别受控制信号控制(如 $B_{in}$ 受寄存器 $B$ 的输入控制;$B_{out}$ 受寄存器 $B$ 的输出控制),假设 $ALU$ 的结果直接送入寄存器 $Z$。要求从取指令开始,写出完成下列指令的微操作序列及所需的控制信号.

| 指令 | 操作 |
|------|------|
| ADD B, C | $(B)+(C)\rightarrow B$ |
| SUB ACC, H | $(ACC)-(H)\rightarrow ACC$ |

## 答案

## DeepSeek V4 Flash Max 解析

**答案**：  
每条指令先执行相同的取指微操作，再按操作码执行运算。

- 公共取指：
$$PC\to MAR,\quad M(MAR)\to MDR,\quad MDR\to IR,\quad (PC)+1\to PC$$
- $ADD\ B,C$ 执行：
$$B\to Y,\quad Y+C\to Z,\quad Z\to B$$
- $SUB\ ACC,H$ 执行：
$$ACC\to Y,\quad Y-H\to Z,\quad Z\to ACC$$

核心原因：CPU 是单总线结构，同一时刻总线上只能传一个数据，所以要先利用 $Y$ 暂存一个操作数；ALU 结果不能直接上总线，必须先送入 $Z$，再由 $Z$ 写回目标寄存器。

---

**解题切入点**：  
看到“CPU 内部总线”和“ALU 结果直接送入寄存器 $Z$”，立即定位到单总线数据通路题。单总线的限制是：任意一拍只能有一个寄存器向总线输出；ALU 有两个输入，但总线一次只能提供一个操作数，因此另一个操作数要先锁存到 $Y$。ALU 运算结果不能直接送回总线，于是用 $Z$ 作为结果暂存器。

可以把 $Y$ 理解成“先准备好的操作数缓冲”，把 $Z$ 理解成“运算结果中转站”。

---

**推演**：

先说明控制信号记法：$X_{out}$ 表示寄存器 $X$ 把数据送到内部总线；$X_{in}$ 表示寄存器 $X$ 从内部总线接收数据。$ALU_{add}$、$ALU_{sub}$ 分别表示 ALU 执行加法和减法。

### 1. 公共取指周期

| 微操作 | 所需控制信号 |
|---|---|
| $PC\to MAR$ | $PC_{out},\ MAR_{in}$ |
| $M(MAR)\to MDR$ | $Read,\ MDR_{in}$ |
| $MDR\to IR$ | $MDR_{out},\ IR_{in}$ |
| $(PC)+1\to PC$ | $PC_{in}$（PC 自增） |

说明：取指结束后，$CU$ 根据 $IR$ 中的操作码译码，决定进入 $ADD$ 还是 $SUB$ 的执行序列。译码是组合逻辑，不单独占用总线周期。

---

### 2. $ADD\ B,C$

指令功能：$(B)+(C)\to B$

| 微操作 | 所需控制信号 |
|---|---|
| $B\to Y$ | $B_{out},\ Y_{in}$ |
| $Y+C\to Z$ | $C_{out},\ ALU_{add},\ Z_{in}$ |
| $Z\to B$ | $Z_{out},\ B_{in}$ |

执行过程：先把 $B$ 的值放进 $Y$，再把 $C$ 的值送上总线，ALU 将 $Y$ 与总线上的 $C$ 相加，结果存入 $Z$；最后把 $Z$ 中的结果写回 $B$。

---

### 3. $SUB\ ACC,H$

指令功能：$(ACC)-(H)\to ACC$

| 微操作 | 所需控制信号 |
|---|---|
| $ACC\to Y$ | $ACC_{out},\ Y_{in}$ |
| $Y-H\to Z$ | $H_{out},\ ALU_{sub},\ Z_{in}$ |
| $Z\to ACC$ | $Z_{out},\ ACC_{in}$ |

执行过程：先把被减数 $ACC$ 存入 $Y$，再把减数 $H$ 送上总线，ALU 计算 $Y-H$，结果存入 $Z$；最后写回 $ACC$。

这里按常见教材约定：$ALU_{sub}$ 完成 $Y-(\text{总线})$。若考题图中 ALU 的减法方向相反，则需要把 $H$ 先送 $Y$，$ACC$ 送上总线，但思路相同。

---

**易错点**：

1. **单总线竞争**：同一拍不能同时让 $B_{out}$ 和 $C_{out}$ 有效，否则两个寄存器同时向总线输出，发生总线冲突。
2. **减法方向错误**：$SUB\ ACC,H$ 是被减数 $ACC$ 在前。按 $Y-$总线约定，必须先 $ACC\to Y$，再 $H$ 上总线。如果写成 $H\to Y$，会得到 $H-ACC$。
3. **忘记 $Z$ 中转**：ALU 的结果直接送入 $Z$，不能把 ALU 输出直接接到 $B$ 或 $ACC$ 的输入端，必须 $Z_{out}$ 后再写回。
4. **取指周期漏掉 $(PC)+1\to PC$**：取指不仅要取指令，还要更新 PC，否则下一条指令地址错误。若教材把 PC 自增与访存并行，则第二步可写成 $M(MAR)\to MDR,\ (PC)+1\to PC$，控制信号同时加 $PC_{in}$。
5. **控制信号 in/out 写反**：例如 $B\to Y$ 是 $B_{out},Y_{in}$，不是 $B_{in},Y_{out}$。

---

**命题规律**：  
本题属于“数据通路 + 微操作序列 + 控制信号”的综合题，是计算机组成原理的重要考点。常见变式包括：

- 改为立即数寻址、直接寻址、间接寻址的指令；
- 改为存数指令、取数指令、转移指令；
- 给出双总线或三总线结构，要求比较所需时钟周期数。

复习建议：先根据数据通路图确认 ALU 的输入来源是 $Y$ 和内部总线，结果寄存器是 $Z$；然后牢记单总线“一次只能传一个数据”的约束；最后把指令翻译成寄存器传送级微操作。取指周期和简单寄存器运算指令的微操作最好能熟练默写。

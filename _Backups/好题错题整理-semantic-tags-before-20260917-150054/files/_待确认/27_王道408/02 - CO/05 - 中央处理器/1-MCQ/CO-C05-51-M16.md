# 选择题 第 16 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-51-M16_题目.png|题目]]

16. 状态寄存器用来存放（ ）  
(A) 算术运算结果  
(B) 逻辑运算结果  
(C) 运算类型  
(D) 算术、逻辑运算及测试指令的结果状态.

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-51-M16_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。理由：状态寄存器（程序状态字寄存器）用于存放算术、逻辑运算及测试指令产生的状态标志（如零标志、进位、溢出、符号等），而非运算结果本身。

**解题切入点**：遇到这种基础概念题，先锁定“状态”二字，想清楚状态寄存器存的是“标志/条件码”，不是数据本身；类似于竞赛里记录“当前局面”而非“落子结果”，做题时抓住“标志位”这一关键。

**推演**：  
状态寄存器（Flags Register / Program Status Word, PSW）中的每一位表示 CPU 运算后的一种状态，常见的有：
- 零标志 ZF：结果为 $0$ 时置 $1$；
- 进位/借位标志 CF：无符号数运算产生进位或借位时置 $1$；
- 溢出标志 OF：有符号数运算结果超出表示范围时置 $1$；
- 符号标志 SF：结果为负数时置 $1$；
- 奇偶标志 PF：结果中 $1$ 的个数为偶数时置 $1$。

这些标志由**算术运算**（加、减、乘、除）、**逻辑运算**（与、或、异或等）以及**测试指令**（如 CMP、TEST）产生，并被后续条件转移指令使用。  
题目中 (A) 算术运算结果、(B) 逻辑运算结果 是寄存器（如累加器、通用寄存器）存放的数据；(C) 运算类型由操作码或控制器决定，均与状态寄存器功能不符。只有 (D) 准确描述了状态寄存器的内容来源。

**易错点**：
- 误选 A 或 B：混淆了“结果数据”与“结果状态”，算术/逻辑结果存入通用寄存器，而不是状态寄存器。
- 误选 C：运算类型是操作码译码的结果，由控制器处理，不是状态寄存器存储对象。
- 容易忽略“测试指令”：CMP、TEST 等指令不保存结果，只影响标志位，这是常考细节，复习时要特别记住。

**命题规律**：  
该考点属于“中央处理器”中程序状态字 PSW 的基本概念，常以选择题形式出现，还可能结合条件转移指令、标志位计算方法（如如何根据二进制结果判断 ZF、CF、OF）出题。变式包括：
- 给出运算结果，判断各标志位的值；
- 区分无符号数比较用 CF、有符号数比较用 OF 与 SF ；
- 与中断、进程切换时保存现场结合，考查 PSW 的保护与恢复。
复习建议：建立“状态字 = 标志位集合”的认知，把 8086/8088 或 MIPS 中常见标志位含义及其产生规则背熟，并通过典型例题（如 $8$ 位补码加法后求各标志位）巩固。

# 选择题 第 2 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-52-M02_题目.png|题目]]

2. 指令周期是指（  ）

A. $CPU$ 从主存取出一条指令的时间
B. $CPU$ 执行一条指令的时间
C. $CPU$ 从主存取出一条指令加上执行这条指令的时间
D. 时钟周期时间

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-52-M02_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。指令周期是指 CPU 从主存取出一条指令并执行完这条指令所需的全部时间。

**解题切入点**：先明确“周期”的层次关系：时钟周期 → 机器周期（CPU 周期）→ 指令周期。题目问的是“指令周期”，直接对应“取指令 + 执行指令”的完整过程，选项 A、B 都只描述了一半，D 是更底层的时间单位。

**推演**：

- 指令周期是 CPU 完成一条指令所需的总时间，通常包含若干个机器周期（CPU 周期），而每个机器周期又包含若干个时钟周期。
- 典型过程为：取指令（从主存取出一条指令）→ 分析指令（指令译码）→ 执行指令（包括运算、访存、写回等）。
- 因此，指令周期 = 取指令时间 + 执行指令时间，即选项 C 的描述。

用公式表示：

$$
\text{指令周期} = \text{取指周期} + \text{执行周期} \;(\text{还可能包含间址周期、中断周期等})
$$

而选项 A 只描述了“取指周期”，选项 B 只描述了“执行周期”，选项 D 把指令周期等同于时钟周期，忽略了两者之间“指令周期通常包含多个时钟周期”的事实。

**易错点**：

1. 混淆“取指周期”和“指令周期”：取指只是指令周期的第一阶段，不能代表整个指令周期。
2. 混淆“机器周期”和“指令周期”：机器周期是完成一个基本操作（如取指、间址、执行、中断）所需的时间，指令周期由多个机器周期组成。
3. 误以为所有指令的指令周期都相同：不同指令（如空操作、乘法、访存指令）所需机器周期数不同，指令周期也可能不同。
4. 忽略“主存”与“Cache/寄存器”的区别：题目明确说从主存取指令，但执行阶段也可能访问主存，C 选项完整覆盖。

**命题规律**：本题是计算机组成原理中“CPU 结构”章节的基础概念题，常与时序系统结合考查，例如给出指令周期、机器周期、时钟周期的比例关系，或指出某条指令需要几个机器周期。复习时应建立“时钟周期 < 机器周期 < 指令周期”的层次观念，并能画出典型指令的周期流程图。

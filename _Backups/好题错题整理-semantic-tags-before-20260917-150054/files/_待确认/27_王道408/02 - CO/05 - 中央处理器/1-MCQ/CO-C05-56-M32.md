# 选择题 第 32 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-56-M32_题目.png|题目]]

32.【2025统考真题】下列关于 $CPI$ 和 $CPU$ 时钟周期的叙述中,错误的是（  ）.

(A) 不同类型指令的 $CPI$ 可能不一样  
(B) 程序的 $CPI$ 与 $Cache$ 缺失率无关  
(C) 单周期 $CPU$ 的时钟周期以最耗时指令所用时间为准  
(D) 流水线 $CPU$ 的时钟周期以最长流水段所用时间为准

## DeepSeek V4 Flash Max 解析

**答案**：B。Cache 缺失率通过访存停顿直接影响程序的有效 CPI，不能说“无关”；A、C、D 的叙述均正确。

**解题切入点**：  
先抓两个核心公式：  
$$\mathrm{CPI}=\frac{\text{总时钟周期数}}{\text{指令条数}}$$
$$\text{CPU时间}=IC\times \mathrm{CPI}\times \text{时钟周期}$$
看到 B 中“无关”这种绝对化表述，应立刻意识到很可能有陷阱。Cache 缺失会造成流水线停顿或访存等待，CPI 不可能与缺失率无关。

**推演**：  

1. **CPI 的定义**  
   设某程序的指令条数为 $IC$，执行该程序所需总时钟周期数为 $N$，则  
   $$
   \mathrm{CPI}=\frac{N}{IC}
   $$
   若程序中有 $k$ 类指令，第 $i$ 类指令条数为 $I_i$，其 CPI 为 $\mathrm{CPI}_i$，则程序平均 CPI 为  
   $$
   \overline{\mathrm{CPI}}=\frac{\sum_{i=1}^{k} I_i \times \mathrm{CPI}_i}{IC}
   $$

2. **A 选项**  
   不同类型指令执行所需周期数可以不同，比如乘法指令和加法指令、访存指令和算术指令可能使用不同周期数。因此“不同类型指令的 CPI 可能不一样”正确。

3. **B 选项**  
   Cache 缺失会导致处理器进入停顿等待状态。设基础 CPI 为 $\mathrm{CPI}_{\text{base}}$，因 Cache 缺失造成的停顿 CPI 为 $\mathrm{CPI}_{\text{stall}}$，则实际有效 CPI 为  
   $$
   \mathrm{CPI}=\mathrm{CPI}_{\text{base}}+\mathrm{CPI}_{\text{stall}}
   $$
   在最简单的统一 Cache 模型中，  
   $$
   \mathrm{CPI}_{\text{stall}}=\left(\text{每条指令平均访存次数}\times \text{缺失率}\right)\times \text{缺失代价}
   $$
   因此缺失率越高，停顿周期越多，程序 CPI 越大。即使采用分离的指令 Cache 和数据 Cache，也有类似关系：  
   $$
   \mathrm{CPI}=\mathrm{CPI}_{\text{base}}+r_i p_i+f_d r_d p_d
   $$
   其中 $r_i,p_i$ 为指令 Cache 缺失率和缺失代价，$r_d,p_d$ 为数据 Cache 缺失率和缺失代价，$f_d$ 为每条指令平均数据访存次数。  
   所以“程序 CPI 与 Cache 缺失率无关”错误。

4. **C 选项**  
   单周期 CPU 中，每条指令都在一个时钟周期内完成，因此时钟周期必须能覆盖所有指令中最长的执行时间。设第 $i$ 条指令所需时间为 $t_i$，则  
   $$
   \tau \ge \max_i t_i
   $$
   即时钟周期以最耗时指令所用时间为准。C 正确。

5. **D 选项**  
   流水线 CPU 中，所有流水段在同一时钟驱动下并行工作，时钟周期必须满足最慢流水段的要求。设各流水段时间为 $d_1,d_2,\dots,d_k$，则  
   $$
   \tau \ge \max_{1\le j\le k} d_j
   $$
   因此时钟周期以最长流水段所用时间为准。D 正确。

综上，错误的是 B。

**易错点**：  
- 把“基础 CPI”和“程序实际 CPI”混淆。基础 CPI 可以不包含 Cache 缺失停顿，但程序实际 CPI 必须包含缺失停顿。  
- 认为 Cache 缺失率只影响“停顿时间”，不影响“CPI”。事实上，$CPI$ 是按总周期数除以指令条数定义的，停顿周期增加，总周期数增加，CPI 也会增加。  
- 容易在单周期和流水线的时钟周期决定因素上混淆。单周期看“最耗时指令”，流水线看“最长流水段”。若把 D 改成“最长指令所用时间”，则错误。  
- 注意 A 中“可能”不是“一定”，所以即使单周期 CPU 中所有指令 CPI 都为 1，也不能否定 A。

**命题规律**：  
本题属于计算机组成原理中“CPU 性能公式”与“Cache 对性能影响”的综合考查。常见变式有：  
- 给各类指令条数和 CPI，求程序平均 CPI；  
- 给 Cache 缺失率、缺失代价，求有效 CPI 和 CPU 时间；  
- 比较单周期、多周期、流水线 CPU 的时钟周期和性能；  
- 给出流水线段延迟，求流水线最高频率。  

复习时应熟记：
$$\text{CPU时间}=IC\times \mathrm{CPI}\times \tau$$
并准确区分基础 CPI、存储停顿 CPI、缺失率、缺失代价等概念。遇到“无关”“一定”等绝对化选项，优先用公式验证。

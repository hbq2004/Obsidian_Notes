# 选择题 第 16 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-54-M16_题目.png|题目]]

16. 下列说法中,正确的是（  ）
I. 微程序控制方式和硬布线控制方式相比较,前者可以使指令的执行速度更快
II. 若采用微程序控制方式,则可用 $\mu PC$ 取代 $PC$
III. 控制存储器可以用 $ROM$ 元件实现
IV. 指令周期也称 $CPU$ 时钟周期

A. I、III
B. II、III
C. 只有 III
D. I、III、IV

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-54-M16_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。只有说法 III 正确，微程序控制方式比硬布线控制方式速度慢，μPC 不能取代 PC，指令周期不等于 CPU 时钟周期。

**解题切入点**：本题直接考查计算机组成原理中控制器的基本概念，包括微程序与硬布线的速度对比、μPC 与 PC 的区别、控制存储器的实现以及指令周期与时钟周期的关系。解题时应对每个说法逐一判断，优先利用常识排除明显错误，如硬布线通常更快、指令周期常包含多个时钟周期等。

**推演**：

- 说法 I：微程序控制方式通过读取控制存储器中的微指令序列产生控制信号，因额外访存延迟，其速度通常慢于硬布线控制方式（硬布线直接由组合逻辑电路生成控制信号）。故 I 错误。
- 说法 II：微程序控制方式中，μPC 用于指向当前微指令地址，PC 用于指向当前指令地址，两者功能不同，不能互相取代。故 II 错误。
- 说法 III：控制存储器存放微程序，其内容在计算机运行中固定不变，通常用只读存储器（ROM）实现，也可用可编程逻辑阵列等，但 ROM 是常见实现方式。故 III 正确。
- 说法 IV：指令周期是指从取指令到执行完该指令所需的时间，通常包含若干个机器周期，每个机器周期又包含若干时钟周期；CPU 时钟周期是基本时间单位，指令周期一般大于时钟周期。故 IV 错误。

综上，仅有说法 III 正确，对应选项 C。

**易错点**：
1. 混淆微程序与硬布线的速度：误以为微程序有“微”字就更快，实际上硬布线直接硬件实现，速度更快。
2. 混淆 μPC 与 PC：两者分别用于微指令和指令，不可替换。
3. 误认为指令周期等于时钟周期：忽略指令周期由多个时钟周期构成。
4. 对控制存储器的实现理解不全面：虽然 ROM 典型，但也可用其他只读存储介质，但判断题中认为 ROM 可实现是正确的。

**命题规律**：本题属于基础概念辨析题，常出现在选择题中，考查对控制器组成、工作原理及性能对比的掌握。常见变式包括：比较微程序与硬布线控制方式的优缺点、区分 μPC 与 PC 的作用、判断时钟周期、机器周期、指令周期的关系等。复习时应重点理解各概念的定义与区别，并注意教材中标准表述。

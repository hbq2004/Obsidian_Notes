# 选择题 第 7 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-55-M07_题目.png|题目]]

7. 下列选项中,不属于外部中断事件的是( )

A. 采样定时时间到
B. 无效操作码
C. 打印机缺纸
D. 键盘缓冲满

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-55-M07_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。无效操作码是 CPU 内部译码时产生的异常（内中断），不是由 CPU 外部设备或时钟等事件引起的外部中断。

**解题切入点**：先判断中断事件的“来源”：是来自 CPU 外部，还是发生在 CPU 内部指令执行过程中。外部中断通常由 I/O 设备、定时器/时钟、硬件故障信号等触发；内部中断/异常则与当前指令执行直接相关，如非法操作码、除零、缺页等。做题时抓住“谁产生的、从哪里来”即可快速定位。

**推演**：

- 外部中断（外中断）是指由 CPU 之外的事件引起的中断，典型来源包括 I/O 设备、定时器/时钟等。
- A：采样定时时间到，通常由定时器/定时采样硬件产生，属于定时器中断，归为外部中断。
- C：打印机缺纸，是打印机设备状态变化引发的中断，属于 I/O 设备外部中断。
- D：键盘缓冲满，是键盘控制器或接口向 CPU 发出中断请求，属于 I/O 设备外部中断。
- B：无效操作码发生在 CPU 取指并译码时，发现该操作码没有对应的合法指令，是 CPU 内部硬件状态异常导致的内部异常（通常称为“故障”），不是外部事件触发的中断。

因此，不属于外部中断事件的是 B。

**易错点**：

1. 容易将“采样定时时间到”误认为内部事件：定时器/时钟硬件一般位于 CPU 外部，其中断通过外部引脚送入 CPU，应归为外部中断。
2. 容易将“无效操作码”误认为外部故障：它是由 CPU 内部译码器发现指令非法而产生的，属于内部异常/内中断。
3. 注意区分“外部中断”与“异常（内中断）”：外部中断常分为可屏蔽中断和不可屏蔽中断；而异常如无效操作码、除零等通常不受中断屏蔽标志位控制，处理机制也不同。

**命题规律**：本题属于中断分类的基础题，考查外部中断与内部异常（内中断）的判别。常见变式有：给出一组事件（除零、缺页、键盘输入、定时器定时、电源掉电等）要求分类；或结合中断响应流程、中断屏蔽、异常处理机制综合考查。复习时应熟记典型例子：外部中断包括键盘、打印机等 I/O 设备中断，定时器/时钟中断，电源掉电等；内部异常包括无效操作码、除数为零、缺页、算术溢出等，并理解两者在响应机制上的区别。

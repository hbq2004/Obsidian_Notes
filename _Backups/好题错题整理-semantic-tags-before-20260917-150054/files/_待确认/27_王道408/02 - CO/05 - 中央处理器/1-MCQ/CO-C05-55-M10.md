# 选择题 第 10 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-55-M10_题目.png|题目]]

10.【2015统考真题】内部异常（内中断）可分为故障（$fault$）、陷阱（$trap$）和终止（$abort$）三类。下列有关内部异常的叙述中,错误的是（  ）

(A) 内部异常的产生与当前执行指令相关

(B) 内部异常的检测由 $CPU$ 内部逻辑实现

(C) 内部异常的响应发生在指令执行过程中

(D) 内部异常处理后返回到发生异常的指令继续执行

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-55-M10_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。内部异常处理后并不都返回到发生异常的指令继续执行：$\mathit{fault}$ 可能返回当前指令重新执行，$\mathit{trap}$ 返回下一条指令，$\mathit{abort}$ 不返回。

**解题切入点**：拿到异常类题目，先按“来源、检测方式、响应时机、返回地址”四个要素定位。三类内部异常中最本质的区别是“处理完后返回哪里”，而选项中 D 恰恰把这个区别说成了“统一返回发生异常的指令”。可以类比程序中的 `try-catch`：有的异常要“重试当前代码”，有的异常要“继续执行后续代码”，有的异常只能“直接终止”。

**推演**：

1. 内部异常又称内中断，是由 CPU 内部发生的事件引起的，与当前正在执行的指令相关。例如除数为 $0$、地址越界、系统调用等，都是由某条指令的执行触发，因此 A 正确。

2. 内部异常不是由外部设备通过中断请求线送入 CPU 的，而是由 CPU 内部逻辑在取指、译码、执行等阶段检测出来的，例如运算器发现除零、译码器发现非法指令、存储管理部件发现缺页。因此 B 正确。

3. 内部异常由当前指令的执行触发，CPU 在指令执行过程中检测到后立即响应；相比之下，外中断通常是在当前指令执行完毕后才被响应。因此 C 正确。

4. 三类内部异常返回地址不同：

| 类型 | 触发/特点 | 处理后的返回位置 |
|---|---|---|
| $\mathit{fault}$（故障） | 当前指令执行过程中发现问题，如缺页 | 返回发生异常的指令重新执行，$PC \leftarrow PC_I$ |
| $\mathit{trap}$（陷阱） | 当前指令主动引起，如系统调用 | 返回下一条指令继续执行，$PC \leftarrow PC_{next}$ |
| $\mathit{abort}$（终止） | 严重错误，无法确定恢复位置 | 不返回，终止当前进程 |

因此 D 把 $\mathit{fault}$ 的特点扩展成了所有内部异常的特点，是错误的。

**易错点**：

- 误以为所有内部异常处理后都会返回当前指令。实际上只有可修复的 $\mathit{fault}$ 才返回当前指令；$\mathit{trap}$ 返回下一条指令，$\mathit{abort}$ 不返回。
- 不要把 C 误判为错项。C 说的是内部异常相对于外中断的响应时机：内部异常由当前指令执行触发，在当前指令周期内响应；$\mathit{trap}$ 返回下一条指令并不等于它不是由当前指令触发。
- 注意“重新执行”与“继续执行”的区别：$\mathit{fault}$ 返回当前指令后通常是从头重新执行该指令，而不是从故障点继续执行。

**命题规律**：本题考点是“内部异常的分类及返回地址”，是 408 中中断与异常机制部分的高频考点。常见变式有：给缺页、系统调用、非法指令等场景，判断属于 $\mathit{fault}$、$\mathit{trap}$ 还是 $\mathit{abort}$；或者结合中断隐指令考查保存断点、转入处理程序的过程。复习时应把“类型、触发条件、返回地址”三者绑定记忆，并与外中断的“异步、当前指令执行完后响应”对比掌握。

# 选择题 第 2 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-53-M02_题目.png|题目]]

2. 下列有关数据通路的叙述中,错误的是 ( )

A. 数据通路由若干组合逻辑元件和时序逻辑元件连接而成

B. 数据通路的功能由控制部件送出的控制信号决定

C. $ALU$ 属于操作元件,包含在数据通路中

D. 通用寄存器属于状态元件,但不包含在数据通路中

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-53-M02_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。通用寄存器是典型的状态元件，且属于数据通路的一部分；D 说“不包含在数据通路中”是错误的。

**解题切入点**：先抓住“数据通路”的定义范围：它负责数据的传输、暂存与运算，是“执行部件”的集合；控制部件（控制器）产生控制信号，但不属于数据通路。题目问“错误的是”，需要逐个判断元件归属。可以把数据通路想象成“加工流水线”：寄存器是暂存工件的仓库，ALU 是加工机床，它们都在流水线上；而控制信号是“调度指令”，来自流水线之外的控制器，不在流水线上。

**推演**：

- 数据通路是 CPU 中实现数据传送和处理的硬件路径，由**操作元件**和**状态元件**连接而成。
  - 操作元件：组合逻辑元件，如 ALU、多路选择器、加法器等，负责对数据进行运算或选择。
  - 状态元件：时序逻辑元件，如寄存器、程序计数器 PC、通用寄存器组等，负责暂存数据或状态。

- 选项 A：数据通路由若干组合逻辑元件和时序逻辑元件连接而成。  
  数据通路中既有 ALU、多路选择器等组合逻辑元件，也有通用寄存器、PC 等时序逻辑元件，二者通过总线或专用线路连接。A 正确。

- 选项 B：数据通路的功能由控制部件送出的控制信号决定。  
  控制部件（控制器）根据指令产生相应的控制信号，控制数据通路中各个元件的动作，如 ALU 执行何种运算、寄存器是否写入、多路选择器选择哪一路数据等。没有控制信号，数据通路只是一堆静态电路；有了控制信号，数据通路才按指令要求完成数据传送和处理。B 正确。

- 选项 C：ALU 属于操作元件，包含在数据通路中。  
  ALU 是组合逻辑运算部件，完成算术与逻辑运算，是数据通路的核心操作元件。C 正确。

- 选项 D：通用寄存器属于状态元件，但不包含在数据通路中。  
  通用寄存器是时序逻辑元件，确实属于状态元件；但它必须包含在数据通路中，因为指令执行时需要从通用寄存器读操作数、向通用寄存器写结果，它是数据传送与暂存的关键部分。说“不包含在数据通路中”错误。D 错误。

因此，错误的是 D。

**易错点**：

1. **混淆数据通路与控制器**：控制器产生控制信号，不属于数据通路；数据通路是被控制器控制的执行部件集合。不要把控制信号生成电路误认为数据通路的一部分。
2. **混淆“状态元件”和“在数据通路之外”**：状态元件（寄存器）恰恰是数据通路的重要组成部分。题目中的陷阱就是把通用寄存器归为状态元件，却错误地说它不在数据通路中。
3. **误以为只有 ALU 才是数据通路**：数据通路不仅包含 ALU，还包含寄存器、多路选择器、总线、三态门等。CPU 中除控制器外的数据传送与处理部件都属于数据通路。

**命题规律**：  
该题考查“数据通路”的基本组成与功能，属于计算机组成原理中 CPU 结构部分的常考概念题。常见变式包括：判断哪个部件不属于数据通路（如控制器、存储器等）、区分操作元件与状态元件、结合单周期/多周期 CPU 数据通路图考查控制信号的作用。复习时应准确记忆数据通路的组成：操作元件（ALU、多路选择器等）＋状态元件（寄存器、PC 等）＋互联线路（总线），并理解控制信号对数据通路的控制关系，可结合典型数据通路图（如 MIPS 单周期数据通路）进行强化。

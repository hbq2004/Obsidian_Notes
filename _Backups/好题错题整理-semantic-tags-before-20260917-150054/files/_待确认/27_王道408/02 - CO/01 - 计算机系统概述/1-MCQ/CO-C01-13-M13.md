# 选择题 第 13 题

![[_Attachments/题目识别/27_王道408-题目/CO-C01-13-M13_题目.png|题目]]

13.【2011统考真题】下列选项中,描述浮点数操作速度指标的是( )

A. $MIPS$
B. $CPI$
C. $IPC$
D. $MFLOPS$

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C01-13-M13_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。理由：$MFLOPS$（每秒百万次浮点运算次数）专门用于描述浮点操作速度，而 $MIPS$、$CPI$、$IPC$ 均属于通用 CPU 性能指标，不特指浮点运算。

**解题切入点**：拿到题目先看关键词：“浮点数操作速度指标”。题干已经限定了“浮点数”，因此应直接在选项中寻找与浮点运算相关的指标。四个选项都是计算机性能评价中常见的缩写，需要区分它们各自的定义和适用场景。可以类比算法竞赛中的“测速”：如果要比较两个程序谁的浮点计算能力强，不能只看总指令条数或 CPU 主频，而要看单位时间内完成了多少次浮点运算。

**推演**：

1. 明确各选项的含义：
   - $MIPS$（Million Instructions Per Second）：每秒执行百万条指令。它衡量的是 CPU 执行指令的总速度，与具体指令类型无关，属于通用指令速度指标。
   - $CPI$（Cycles Per Instruction）：执行一条指令所需的平均时钟周期数。它是衡量 CPU 执行指令效率的基本参数，不特指浮点运算。
   - $IPC$（Instructions Per Cycle）：每个时钟周期执行的指令条数，是 $CPI$ 的倒数。同样属于通用 CPU 性能指标。
   - $MFLOPS$（Million Floating-point Operations Per Second）：每秒执行百万次浮点运算。它专门用于衡量浮点运算的速度，常用于科学计算、图形处理等涉及大量浮点操作的场景。

2. 题干要求“描述浮点数操作速度指标”，即该指标必须直接反映浮点运算的执行速率。显然，只有 $MFLOPS$ 是以“浮点操作次数/秒”为单位的，因此正确选项为 D。

3. 补充辨析：虽然 $MIPS$、$CPI$、$IPC$ 也能间接影响浮点程序的运行时间，但它们不是“浮点数操作速度指标”，而是普遍适用的指令级性能指标。若题目改为“描述 CPU 整体指令执行速度”或“描述流水线效率”，则应选相应选项。

**易错点**：
- 易混淆 $MIPS$ 与 $MFLOPS$：两者都是“每秒百万次”，但前者是“百万条指令”，后者是“百万次浮点操作”。注意“浮点数操作”强调的是运算类型，而非指令条数。
- 易误选 $CPI$ 或 $IPC$：它们描述的是“每条指令所需周期数”或“每周期执行指令数”，与浮点操作没有直接关系。即使浮点运算指令的 $CPI$ 较大，$CPI$ 本身也不是“浮点数操作速度指标”。
- 忽略题干中的“浮点数”限定：如果只看“操作速度指标”，可能误认为 $MIPS$ 也合适，但题目明确限定为浮点数，必须选择与浮点操作直接相关的指标。

**命题规律**：本题属于计算机系统性能评价的基础概念题，考查对常见性能指标英文缩写及其含义的区分。常考变式包括：给出具体场景（如科学计算、数据库事务处理）要求选择合适指标；或将 $MIPS$、$MFLOPS$ 与执行时间、时钟频率等组合计算。复习时应熟记各指标定义、单位及适用场景，理解 $CPI$ 与 $IPC$ 的倒数关系，并掌握 $MIPS$、$MFLOPS$ 的计算公式：
$$
MIPS = \frac{\text{指令条数}}{\text{执行时间} \times 10^6}, \qquad
MFLOPS = \frac{\text{浮点操作次数}}{\text{执行时间} \times 10^6}.
$$
同时注意 $MFLOPS$ 是基于浮点操作次数而非指令条数，因此同一程序在不同机器上 $MFLOPS$ 值可能差异很大，需结合具体浮点操作类型分析。

# MCQ 第 522 题

![[_Attachments/题目识别/27_方浩概统500题-题目/FH-CG-Q522_题目.png|题目]]

522 设 $X_1,X_2, \cdots,X_n(n \geqslant 2)$ 为来自总体 $N(\mu,4)$ 的简单随机样本，记 $\overline{X} = \frac{1}{n} \sum_{i=1}^{n} X_i$，则下列结论中不正确的是( ).

(A) $\sum_{i=1}^{n} \left( \frac{X_i - \mu}{2} \right)^2 \sim \chi^2(n)$

(B) $\sum_{i=1}^{n} \left( \frac{X_i - \overline{X}}{2} \right)^2 \sim \chi^2(n-1)$

(C) $\frac{(X_1 - X_2)^2 + (X_3 - X_4)^2}{8} \sim \chi^2(2)$

(D) $\frac{(X_1 + X_2 - X_3 - X_4)^2}{8} \sim \chi^2(1)$

---

## 答案


## DeepSeek V4 Flash Max 解析

**答案**：D。选项 D 中 $X_1+X_2-X_3-X_4\sim N(0,16)$，正确标准化应为  
$\frac{(X_1+X_2-X_3-X_4)^2}{16}\sim \chi^2(1),$  
而题中除以 $8$，因此不是 $\chi^2(1)$。

**解题切入点**：看到“正态总体 + 平方和 + 卡方分布”，立即定位到 $\chi^2$ 分布的构造：标准正态变量的平方和。就像编程中先检查“单位/量纲”是否统一一样，这里要先检查每个平方项是否已标准化为 $N(0,1)$，再考虑自由度和独立性。

**推演**：

由题意，$X_i\sim N(\mu,4)$ 且相互独立。

**(A)**  
因为
$Z_i=\frac{X_i-\mu}{2}\sim N(0,1),$
且 $Z_1,\cdots,Z_n$ 相互独立，所以
$\sum_{i=1}^n\left(\frac{X_i-\mu}{2}\right)^2=\sum_{i=1}^n Z_i^2\sim \chi^2(n).$
故 A 正确。

**(B)**  
令
$Y_i=\frac{X_i-\mu}{2},$
则 $Y_i$ 独立同分布于 $N(0,1)$，且
$\frac{X_i-\bar X}{2}=Y_i-\bar Y,\qquad \bar Y=\frac{\bar X-\mu}{2}.$
由正态总体样本方差结论，
$$\sum_{i=1}^n\left(\frac{X_i-\bar X}{2}\right)^2
=\sum_{i=1}^n (Y_i-\bar Y)^2\sim \chi^2(n-1).$$
故 B 正确。

**(C)**  
注意
$X_1-X_2\sim N(0,8),\qquad X_3-X_4\sim N(0,8),$
且两者独立，因为它们来自互不重叠的样本指标组。于是
$\frac{X_1-X_2}{\sqrt8}\sim N(0,1),\qquad \frac{X_3-X_4}{\sqrt8}\sim N(0,1),$
且独立。因此
$$\frac{(X_1-X_2)^2+(X_3-X_4)^2}{8}
=\left(\frac{X_1-X_2}{\sqrt8}\right)^2+\left(\frac{X_3-X_4}{\sqrt8}\right)^2
\sim \chi^2(1)+\chi^2(1)=\chi^2(2).$$
故 C 正确。

**(D)**  
线性组合
$X_1+X_2-X_3-X_4\sim N(0,16),$
因为均值为
$\mu+\mu-\mu-\mu=0,$
方差为
$4+4+4+4=16.$
令
$W=\frac{X_1+X_2-X_3-X_4}{4}\sim N(0,1),$
则
$\frac{(X_1+X_2-X_3-X_4)^2}{16}=W^2\sim \chi^2(1).$
但题目中的表达式是
$\frac{(X_1+X_2-X_3-X_4)^2}{8}=2W^2,$
这是 $\chi^2(1)$ 变量的 $2$ 倍，不是 $\chi^2(1)$。

也可用期望检验：
$$E\left[\frac{(X_1+X_2-X_3-X_4)^2}{8}\right]
=\frac{16}{8}=2\neq 1=E[\chi^2(1)].$$
故 D 不正确。

**易错点**：

1. **D 的分母容易错**：$X_1+X_2-X_3-X_4$ 的方差是 $16$，平方后应除以 $16$ 才是 $\chi^2(1)$；除以 $8$ 相当于乘了 $2$。
2. **自由度混淆**：A 中直接用总体均值 $\mu$，所以自由度为 $n$；B 中用样本均值 $\bar X$ 代替 $\mu$，损失一个自由度，所以为 $n-1$。
3. **减法使方差加倍**：$X_1-X_2$ 的方差为 $8$，所以 C 的分母是 $8$，不要误写成 $4$。
4. **卡方相加必须独立**：C 中两个平方项来自不相交的样本组，所以独立；若变量之间有相关性，不能直接相加为卡方分布。

**命题规律**：本题考查正态总体下 $\chi^2$ 分布的构造、自由度以及正态变量线性组合的标准化。常见变式包括：
$\frac{(n-1)S^2}{\sigma^2}\sim \chi^2(n-1),$
$\frac{\bar X-\mu}{\sigma/\sqrt n}\sim N(0,1),$
$\frac{\bar X-\mu}{S/\sqrt n}\sim t(n-1).$
复习时应熟练掌握“标准正态变量平方和”这一基本构造，并注意自由度损失和独立性的判断。

**知识点**：卡方分布、正态总体抽样分布、样本方差、自由度

# FIB 第 511 题

![[_Attachments/题目识别/27_方浩概统500题-题目/FH-CG-Q511_题目.png|题目]]

511 甲、乙两个盒子中均有 2 只红球和 2 只白球，从甲盒中任取一球，观察颜色后放入乙盒，再从乙盒中任取一球，令 $X,Y$ 分别表示从甲盒和乙盒中取到的红球的个数，则 $X$ 与 $Y$ 的相关系数为 \_.

---

## 答案


## DeepSeek V4 Flash Max 解析

**答案**：$\boxed{\rho_{XY}=\dfrac15}$（即 $0.2$）。  
因为 $X,Y$ 均为 $0$-$1$ 变量，先算得 $P(X=1,Y=1)=\dfrac{3}{10}$，故 $\mathrm{Cov}(X,Y)=\dfrac{1}{20}$，相关系数为 $\dfrac15$。

**解题切入点**：  
题目只取两次球，$X,Y$ 都只能取 $0$ 或 $1$，因此本质是求两个“0-1变量”的相关系数。对0-1变量：

- 期望等于取 $1$ 的概率；
- 方差为 $p(1-p)$；
- 协方差为
\[
\mathrm{Cov}(X,Y)=E[XY]-EX\cdot EY,
\]
而 $E[XY]=P(X=1,Y=1)$。

所以关键不是求复杂分布，而是先由“从甲盒取到红/白”作为条件，确定乙盒中红白球的数量。可以类比算法中的“概率DP”：甲盒取球结果作为状态，转移到乙盒取红球的概率。

**推演**：  
设
\[
X=\begin{cases}
1,&\text{甲盒取到红球},\\
0,&\text{甲盒取到白球},
\end{cases}
\qquad
Y=\begin{cases}
1,&\text{乙盒取到红球},\\
0,&\text{乙盒取到白球}.
\end{cases}
\]

甲盒中有 $2$ 红 $2$ 白，所以
\[
P(X=1)=P(X=0)=\frac12.
\]

从甲盒取出一球放入乙盒后，乙盒中球数变为 $5$ 个。分两种情况：

- 若 $X=1$，即放入乙盒的是红球，则乙盒中有 $3$ 红 $2$ 白：
\[
P(Y=1\mid X=1)=\frac35.
\]

- 若 $X=0$，即放入乙盒的是白球，则乙盒中有 $2$ 红 $3$ 白：
\[
P(Y=1\mid X=0)=\frac25.
\]

于是 $Y$ 的边缘分布为
\[
P(Y=1)
=P(Y=1\mid X=1)P(X=1)+P(Y=1\mid X=0)P(X=0)
\]
\[
=\frac35\cdot\frac12+\frac25\cdot\frac12
=\frac12.
\]

因此
\[
EX=\frac12,\qquad EY=\frac12.
\]

又因为 $X,Y$ 都是 $0$-$1$ 变量，所以
\[
DX=\frac12\left(1-\frac12\right)=\frac14,
\qquad
DY=\frac12\left(1-\frac12\right)=\frac14.
\]

计算 $E[XY]$。由于 $XY=1$ 当且仅当 $X=1$ 且 $Y=1$，所以
\[
E[XY]=P(X=1,Y=1).
\]
而
\[
P(X=1,Y=1)
=P(X=1)P(Y=1\mid X=1)
=\frac12\cdot\frac35
=\frac{3}{10}.
\]

于是协方差为
\[
\mathrm{Cov}(X,Y)
=E[XY]-EX\cdot EY
=\frac{3}{10}-\frac12\cdot\frac12
=\frac{3}{10}-\frac14
=\frac{1}{20}.
\]

相关系数为
\[
\rho_{XY}
=\frac{\mathrm{Cov}(X,Y)}{\sqrt{DX\cdot DY}}
=\frac{\frac{1}{20}}{\sqrt{\frac14\cdot\frac14}}
=\frac{\frac{1}{20}}{\frac14}
=\frac15.
\]

因此 $X$ 与 $Y$ 的相关系数为 $\boxed{\dfrac15}$。

**易错点**：  
1. 误以为乙盒始终是 $2$ 红 $2$ 白，忽略从甲盒放入一球后乙盒变为 $5$ 个球，红白比例会变化。  
2. 对0-1变量，容易把 $E[XY]$ 直接写成 $EX\cdot EY$。只有 $X,Y$ 独立时才成立，本题中二者并不独立。  
3. 计算方差时忘记 $Y$ 也是0-1变量；若按一般离散型随机变量求 $E[Y^2]$ 也能做，但直接用 $p(1-p)$ 更简洁。  
4. 相关系数公式中分母是标准差之积 $\sqrt{DX\,DY}$，不要漏写根号。

**命题规律**：  
本题属于“二维随机变量的数字特征”与“条件概率”结合题。常见变式有：直接给联合分布表求协方差或相关系数；把取球过程改为有放回、不放回或增加球数；或者判断“不相关”与“独立”的关系。  
复习建议：熟练掌握 $0$-$1$ 变量的期望、方差、协方差公式，尤其是
\[
E[XY]=P(X=1,Y=1)
\]
这一常用结论。同时要养成“先条件、后边缘”的解题习惯。

**知识点**：0-1分布、协方差、相关系数、条件概率

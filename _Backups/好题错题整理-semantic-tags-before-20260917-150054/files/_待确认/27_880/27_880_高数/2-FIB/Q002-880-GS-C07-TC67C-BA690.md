# FIB 第 2 题

![[_Attachments/题目识别/880-GS/880-GS-C07-TC67C-BA690-Q002_题目.png|题目]]

(2) 微分方程 $y'' - y = \sin x$ 满足 $y(0) = 0$，$y'(0) = \frac{3}{2}$ 的特解为 \_\_\_\_\_\_.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-TC67C-BA690-Q002_答案.png|答案]]

## V4 Pro Max 解析

**考点**：二阶常系数非齐次方程:特征根法求齐次通解 + 待定系数法求特解 + 初值定常数。

**解**
齐次方程 $y''-y=0$ 的特征方程为 $r^2-1=0$,得 $r=\pm 1$,故
$$y_h = C_1e^x + C_2e^{-x}.$$
对非齐次项 $\sin x$,设特解 $y_p = A\cos x + B\sin x$:
$$y_p'' = -A\cos x - B\sin x,\qquad y_p'' - y_p = -2A\cos x - 2B\sin x = \sin x,$$
得 $A=0,\ B=-\dfrac{1}{2}$,即 $y_p = -\dfrac{1}{2}\sin x$。
故通解
$$y = C_1e^x + C_2e^{-x} - \frac{1}{2}\sin x.$$
由 $y(0)=0$ 得 $C_1+C_2=0$;由 $y'(x) = C_1e^x - C_2e^{-x} - \dfrac{1}{2}\cos x$ 及 $y'(0)=\dfrac{3}{2}$ 得 $C_1-C_2=2$。解得 $C_1=1,\ C_2=-1$。

**答案**：$y = e^x - e^{-x} - \dfrac{1}{2}\sin x$。

**易错点**：$\sin x,\cos x$ 是 $r=\pm i$ 的共振项,但本题特征根为 $\pm1$,故特解不带 $x$ 因子;不要漏掉 $\cos x$ 的试探项。

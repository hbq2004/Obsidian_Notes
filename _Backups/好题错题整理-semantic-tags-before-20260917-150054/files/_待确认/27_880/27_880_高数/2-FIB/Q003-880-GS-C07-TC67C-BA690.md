## V4 Pro Max 解析

**考点**：令 $u = y^2$ 化为一阶线性方程求解。

**解**
方程 $y' = \dfrac{y^2-x}{2y(x+1)}$ 两边乘 $2y$,令 $u = y^2$,则 $u' = 2yy'$,得
$$u' = \frac{u-x}{x+1}\quad\Longrightarrow\quad u' - \frac{1}{x+1}u = -\frac{x}{x+1}.$$
积分因子 $\mu = e^{-\int\frac{dx}{x+1}} = \dfrac{1}{x+1}$,于是
$$\left(\frac{u}{x+1}\right)' = -\frac{x}{(x+1)^2}.$$
积分:
$$\frac{u}{x+1} = -\int\frac{x}{(x+1)^2}dx = -\int\left(\frac{1}{x+1} - \frac{1}{(x+1)^2}\right)dx = -\ln|x+1| - \frac{1}{x+1} + C.$$
故
$$u = -(x+1)\ln|x+1| - 1 + C(x+1),$$
即 $y^2 = C(x+1) - 1 - (x+1)\ln|x+1|$。

验证:对 $y^2 = C(x+1)-1-(x+1)\ln(x+1)$ 求导得 $2yy' = C-\ln(x+1)-1$;而 $\dfrac{y^2-x}{x+1} = \dfrac{C(x+1)-1-(x+1)\ln(x+1)-x}{x+1} = C-\ln(x+1)-1$,一致 ✓。

**答案**：$y^2 = C(x+1) - 1 - (x+1)\ln|x+1|$。

**易错点**：见到 $yy'$ 结构优先想到 $u=y^2$ 降阶;$\int \dfrac{x}{(x+1)^2}dx$ 用拆项 $\dfrac{1}{x+1}-\dfrac{1}{(x+1)^2}$ 计算,别直接凑微分出错。

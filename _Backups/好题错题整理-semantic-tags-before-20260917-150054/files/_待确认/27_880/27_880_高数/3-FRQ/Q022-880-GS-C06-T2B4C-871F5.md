# FRQ 第 22 题

![[_Attachments/题目识别/880-GS/880-GS-C06-T2B4C-871F5-Q022_题目.png|题目]]

(22) 设 $V: 0 \leq z \leq \sqrt{R^2 - x^2 - y^2}$ ($R > 0$), 求 $I = \iiint_V (3x^2 + 5y^2 + 7z^2) \, dV$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C06-T2B4C-871F5-Q022_答案.png|答案]]

## V4 Pro Max 解析

**考点**：上半球体上的三重积分——球面坐标与对称性。

**解**

$V$ 为半径 $R$ 的上半球体：球面坐标下
$$\rho\in[0,R],\qquad \theta\in\left[0,\frac\pi2\right],\qquad \phi\in[0,2\pi],$$
体积元 $dV=\rho^2\sin\theta\,d\rho\,d\theta\,d\phi$。

区域关于 $x,y$ 轮换及各自变号对称，故 $\iiint_Vx^2=\iiint_Vy^2$。逐项计算：
$$\iiint_Vx^2\,dV
=\int_0^{2\pi}\cos^2\phi\,d\phi\int_0^{\pi/2}\sin^3\theta\,d\theta\int_0^R\rho^4\,d\rho
=\pi\cdot\frac23\cdot\frac{R^5}{5}=\frac{2\pi R^5}{15},$$
$$\iiint_Vy^2\,dV=\frac{2\pi R^5}{15},$$
$$\iiint_Vz^2\,dV
=\int_0^{2\pi}d\phi\int_0^{\pi/2}\cos^2\theta\sin\theta\,d\theta\int_0^R\rho^4\,d\rho
=2\pi\cdot\frac13\cdot\frac{R^5}{5}=\frac{2\pi R^5}{15}.$$
于是
$$I=\iiint_V(3x^2+5y^2+7z^2)\,dV
=(3+5+7)\cdot\frac{2\pi R^5}{15}=2\pi R^5.$$

**答案**：$I=2\pi R^5$。

**易错点**：半球在 $z$ 方向不对称，不能直接套全球对称结论；但逐项球面坐标计算恰好给出 $\iiint x^2=\iiint y^2=\iiint z^2=\frac{2\pi R^5}{15}$；球面坐标的 Jacobian 为 $\rho^2\sin\theta$，并注意 $\theta$（与 $z$ 轴夹角）范围为 $[0,\frac\pi2]$。

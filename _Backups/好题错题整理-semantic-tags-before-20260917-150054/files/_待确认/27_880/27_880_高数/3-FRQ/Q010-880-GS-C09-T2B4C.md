# FRQ 第 10 题

![[_Attachments/题目识别/880-GS/880-GS-C09-T2B4C-Q010_题目.png|题目]]

(10) 设曲线 $L$ 为锥面 $z = \sqrt{x^2 + y^2}$ 与圆柱面 $x^2 + y^2 = 2x$ 的交线，从 $z$ 轴正向往负向看去，$L$ 为逆时针方向，计算 $I = \int_L (y^2 + z^2) \, dx + (z^2 - x^2) \, dy + (x^2 + y^2) \, dz$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C09-T2B4C-Q010_答案.png|答案]]

## V4 Pro Max 解析

**考点**：斯托克斯公式——取锥面片为张成曲面，旋度与锥面法向点乘后化简，奇点在边界不影响。

**解**
$\mathbf F=(y^2+z^2,\ z^2-x^2,\ x^2+y^2)$，旋度

$$\nabla\times\mathbf F=(2y-2z,\ 2z-2x,\ -2x-2y).$$

$L$ 为锥面 $z=\sqrt{x^2+y^2}$ 与圆柱面 $x^2+y^2=2x$ 的交线，其投影为圆 $(x-1)^2+y^2=1$。取锥面位于 $D=\{(x-1)^2+y^2\le1\}$ 内的部分为张成曲面（法向向上，与 $L$ 从 $z$ 轴正向往负向看为逆时针成右手系），$\mathbf n dS=\left(-\dfrac{x}{z},-\dfrac{y}{z},1\right)dxdy$：

$$(\nabla\times\mathbf F)\cdot\mathbf n\,dS=(2y-2z)\left(-\frac{x}{z}\right)+(2z-2x)\left(-\frac{y}{z}\right)+(-2x-2y)=-4y.$$

$$I=\iint_D(-4y)dxdy=0\quad(\text{关于 }x\text{ 轴对称，}y\text{ 为奇函数}).$$

**答案**：$I=0$。

**易错点**：① 交线过锥面顶点 $(0,0,0)$，但顶点在 $D$ 边界上，不影响面积分；② 锥面面元向量 $\left(-\frac{x}{z},-\frac{y}{z},1\right)dxdy$ 的符号与 $L$ 方向匹配；③ 也可沿圆周参数化直接积分，但须分段处理 $z=2|\cos(t/2)|$ 的尖点，易出错。

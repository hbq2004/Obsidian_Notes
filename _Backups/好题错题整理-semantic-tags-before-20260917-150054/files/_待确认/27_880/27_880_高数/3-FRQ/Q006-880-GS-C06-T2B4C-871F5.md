# FRQ 第 6 题

![[_Attachments/题目识别/880-GS/880-GS-C06-T2B4C-871F5-Q006_题目.png|题目]]

(6) 设曲线 $(x^2 + y^2)^{\frac{3}{2}} = 2\sqrt{2}xy, x \geqslant 0, y \geqslant 0$ 所围区域为 $D$. 计算 $I = \iint_D (x + 2\sqrt{xy} - y)^2 \, dx \, dy$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C06-T2B4C-871F5-Q006_答案.png|答案]]

## V4 Pro Max 解析

**考点**：二重积分——极坐标变换化曲线为 $r=\sqrt2\sin2\theta$，展开被积函数并利用对称性化简。

**解**
令 $x=r\cos\theta$，$y=r\sin\theta$。曲线 $(x^2+y^2)^{3/2}=2\sqrt2\,xy$ 化为
$$r^3=2\sqrt2\,r^2\cos\theta\sin\theta\ \Longrightarrow\ r=\sqrt2\sin 2\theta\quad(\text{另一支 }r=0\text{ 即原点}).$$
第一象限内 $0\le\theta\le\dfrac{\pi}{2}$，故
$$D=\left\{(r,\theta):\ 0\le\theta\le\frac{\pi}{2},\ 0\le r\le\sqrt2\sin2\theta\right\}.$$

被积函数
$$(x+2\sqrt{xy}-y)^2=r^2(\cos\theta-\sin\theta+2\sqrt{\cos\theta\sin\theta})^2.$$
于是
$$I=\int_0^{\pi/2}\int_0^{\sqrt2\sin2\theta}r^3(\cos\theta-\sin\theta+2\sqrt{\cos\theta\sin\theta})^2\,dr\,d\theta.$$

内层积分 $\displaystyle\int_0^{\sqrt2\sin2\theta}r^3\,dr=\frac{(\sqrt2\sin2\theta)^4}{4}=\sin^4 2\theta$。展开平方项：
$$(\cos\theta-\sin\theta+2\sqrt{\cos\theta\sin\theta})^2
=(\cos\theta-\sin\theta)^2+4\cos\theta\sin\theta+4\sqrt{\cos\theta\sin\theta}(\cos\theta-\sin\theta)$$
$$=1+\sin 2\theta+4\sqrt{\cos\theta\sin\theta}(\cos\theta-\sin\theta).$$
交叉项中，作代换 $\theta\to\dfrac{\pi}{2}-\theta$ 时 $\sqrt{\cos\theta\sin\theta}$ 与 $\sin2\theta$ 不变、$\cos\theta-\sin\theta$ 变号，故交叉项积分为零。

所以
$$I=\int_0^{\pi/2}(1+\sin2\theta)\sin^4 2\theta\,d\theta
=\frac12\int_0^\pi\bigl(\sin^4 w+\sin^5 w\bigr)dw.$$

利用 $\displaystyle\int_0^\pi\sin^4 w\,dw=\frac{3\pi}{8}$，$\displaystyle\int_0^\pi\sin^5 w\,dw=\frac{16}{15}$，得
$$I=\frac12\left(\frac{3\pi}{8}+\frac{16}{15}\right)=\frac{3\pi}{16}+\frac{8}{15}.$$

**答案**：$I=\dfrac{3\pi}{16}+\dfrac{8}{15}$。

**易错点**：曲线 $(x^2+y^2)^{3/2}=2\sqrt2xy$ 在极坐标下为 $r=\sqrt2\sin2\theta$（四叶玫瑰线，本题取第一象限一叶，$r$ 上限随 $\theta$ 变化）；展开平方后交叉项 $4\sqrt{xy}(x-y)$ 需利用 $\theta\to\dfrac{\pi}{2}-\theta$ 对称性消去，否则积分繁难。

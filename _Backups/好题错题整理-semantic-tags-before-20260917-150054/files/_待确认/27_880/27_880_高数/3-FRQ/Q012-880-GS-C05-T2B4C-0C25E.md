# FRQ 第 12 题

![[_Attachments/题目识别/880-GS/880-GS-C05-T2B4C-0C25E-Q012_题目.png|题目]]

(12) 设 $f(x, y) = x^2 + axy + by^2$ 在点 $P(2,1)$ 处沿 $l = (0,1)$ 的方向导数取得最大值 2.

(I) 求 $a, b$ 的值;

(II) 求原点 $O(0,0)$ 到曲线 $f(x,y) = 1$ 上点的距离的最大值与最小值.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C05-T2B4C-0C25E-Q012_答案.png|答案]]

## V4 Pro Max 解析

**考点**：方向导数最大方向 = 梯度方向 + 条件极值（二次型特征值）求点到曲线的距离。

**解**
(I) 方向导数 $\frac{\partial f}{\partial l}=\nabla f\cdot l$。沿 $(0,1)$ 的方向导数即 $f_y$：
$$f_y(2,1)=2a+2b=2\Rightarrow a+b=1.$$
"沿 $(0,1)$ 取得最大值"意味着梯度方向与 $(0,1)$ 同向，故 $f_x(2,1)=0$：
$$f_x=2x+ay,\quad f_x(2,1)=4+a=0\Rightarrow a=-4,\quad b=5.$$

(II) $f(x,y)=x^{2}-4xy+5y^{2}=1$，求原点到曲线的距离即求 $x^{2}+y^{2}$ 在约束下的最值。二次型矩阵 $A=\begin{pmatrix}1&-2\\-2&5\end{pmatrix}$，特征值满足
$$\lambda^{2}-6\lambda+1=0\Rightarrow\lambda=3\pm2\sqrt2.$$
$$\min(x^{2}+y^{2})=\frac{1}{3+2\sqrt2}=3-2\sqrt2=(\sqrt2-1)^{2},$$
$$\max(x^{2}+y^{2})=3+2\sqrt2=(\sqrt2+1)^{2}.$$

**答案**：(I) $a=-4$，$b=5$；(II) 原点 $O$ 到曲线 $f=1$ 上点的距离最大值为 $\sqrt2+1$，最小值为 $\sqrt2-1$。

**易错点**："方向导数沿某方向取得最大值"是"梯度与该方向同向"（此时 $f_x=0$），不要只列 $f_y=2$ 一个方程。

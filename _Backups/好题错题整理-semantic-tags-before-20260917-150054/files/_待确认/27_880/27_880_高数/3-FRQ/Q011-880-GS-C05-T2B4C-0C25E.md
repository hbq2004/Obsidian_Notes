# FRQ 第 11 题

![[_Attachments/题目识别/880-GS/880-GS-C05-T2B4C-0C25E-Q011_题目.png|题目]]

(11) 设 $f(x, y)$ 有一阶连续的偏导数，在 (1,1) 的某邻域内，$f(x, y) = e^{x^2 + y^2 - 2} + o(\rho)$，其中 $\rho = \sqrt{(x-1)^2 + (y-1)^2}$. 又 $g(x, y) = f(e^{x-y}, xy)$.

(I) 求 $dg(x, y) \big|＿{(1,1)}$;

(II) 计算 $\lim\limits_{t \to 0} \frac{g(1 + \sin t, 1) - g(1, 1 - \tan t)}{t}$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C05-T2B4C-0C25E-Q011_答案.png|答案]]

## V4 Pro Max 解析

**考点**：由局部展开确定全微分 + 复合函数求导（链式法则）与极限计算。

**解**
(I) 由 $f(x,y)=e^{x^{2}+y^{2}-2}+o(\rho)$ 知 $f(1,1)=1$，且
$$f_x(1,1)=\left.2x\,e^{x^{2}+y^{2}-2}\right|_{(1,1)}=2,\qquad f_y(1,1)=2,$$
故 $df_{(1,1)}=2dx+2dy$。

$g(x,y)=f(u,v)$，$u=e^{x-y}$，$v=xy$。在 $(1,1)$：$u=1,\ v=1$，且 $u_x=1,\ u_y=-1,\ v_x=1,\ v_y=1$。
$$g_x=f_u u_x+f_v v_x=2+2=4,\qquad g_y=f_u u_y+f_v v_y=-2+2=0,$$
$$dg_{(1,1)}=4\,dx.$$

(II) 由可微性，$\sin t\sim t$，$-\tan t\sim -t$：
$$g(1+\sin t,1)=g(1,1)+g_x(1,1)\sin t+o(t),$$
$$g(1,1-\tan t)=g(1,1)+g_y(1,1)(-\tan t)+o(t),$$
故
$$\lim_{t\to0}\frac{g(1+\sin t,1)-g(1,1-\tan t)}{t}=g_x(1,1)+g_y(1,1)=4.$$

**答案**：(I) $dg_{(1,1)}=4dx$；(II) 极限为 $4$。

**易错点**：$g_y$ 中 $u_y=-1$ 的符号；第二问把差式拆成两个方向导数之和，$\frac{-\tan t}{t}\to-1$ 与 $\frac{\sin t}{t}\to1$ 要配好符号。

# FRQ 第 7 题

![[_Attachments/题目识别/880-GS/880-GS-C03-T2B4C-Q007_题目.png|题目]]

(7) 求下列积分:

(I) $\int_{-3}^{2} \min \{2, x^{2}\} dx$;

(II) $\int_{-1}^{x} (1 - |t|) \, dt (x \geqslant -1)$;

(III) $\int_{-1}^{1} |x - y| e^{x} dx (\|y\| \leqslant 1)$;

(IV) $\int_{0}^{\pi} \sqrt{1 - \sin x} \, dx$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C03-T2B4C-Q007_答案.png|答案]]

## V4 Pro Max 解析

**考点**：分段（最值/绝对值）函数积分 + 变上限积分。

**解**
(I) $\min\{2,x^2\}=\begin{cases}x^2,&|x|\le\sqrt2,\\2,&|x|\ge\sqrt2.\end{cases}$
$$\int_{-3}^{2}\min\{2,x^{2}\}dx=\int_{-3}^{-\sqrt2}2\,dx+\int_{-\sqrt2}^{\sqrt2}x^2\,dx+\int_{\sqrt2}^{2}2\,dx=2(3-\sqrt2)+\frac{2(\sqrt2)^3}{3}+2(2-\sqrt2)=10-\frac{8\sqrt2}{3}.$$
(II) $F(x)=\int_{-1}^x(1-|t|)dt$（$x\ge-1$）。
- $-1\le x\le0$：$F(x)=\int_{-1}^x(1+t)dt=\left[t+\frac{t^2}{2}\right]_{-1}^x=\frac{x^2}{2}+x+\frac12$；
- $x\ge0$：$F(x)=\int_{-1}^0(1+t)dt+\int_0^x(1-t)dt=\frac12+x-\frac{x^2}{2}$。
（$x\ge1$ 时 $1-t\le0$，但上述公式依然成立：$\frac12+\left[t-\frac{t^2}{2}\right]_0^x=\frac12+x-\frac{x^2}{2}$，可统一写为 $x\ge0$ 支。）
(III) $|y|\le1$，分 $x=y$ 两侧：
$$\int_{-1}^{1}|x-y|e^{x}dx=\int_{-1}^y(y-x)e^xdx+\int_y^1(x-y)e^xdx.$$
$$\int(y-x)e^xdx=e^x(y-x+1),\qquad\int(x-y)e^xdx=e^x(x-y-1),$$
故
$$\int_{-1}^{1}|x-y|e^{x}dx=\big[e^x(y-x+1)\big]_{-1}^y+\big[e^x(x-y-1)\big]_y^1=(e^y-e^{-1}(y+2))+( -ey-e^y\cdot(-1))=2e^y-ey-\frac{y+2}{e}.$$
(IV) $\sqrt{1-\sin x}=\sqrt{(\sin\frac x2-\cos\frac x2)^2}=\left|\sin\frac x2-\cos\frac x2\right|$，零点在 $x=\frac\pi2$：
$$\int_0^\pi\sqrt{1-\sin x}\,dx=\int_0^{\pi/2}\left(\cos\frac x2-\sin\frac x2\right)dx+\int_{\pi/2}^\pi\left(\sin\frac x2-\cos\frac x2\right)dx$$
$$=\left[2\sin\frac x2+2\cos\frac x2\right]_0^{\pi/2}+\left[-2\cos\frac x2-2\sin\frac x2\right]_{\pi/2}^\pi=(2\sqrt2-2)+(-2+2\sqrt2)=4\sqrt2-4.$$

**答案**：(I) $10-\dfrac{8\sqrt2}{3}$；(II) $F(x)=\begin{cases}\frac{x^2}{2}+x+\frac12,&-1\le x\le0,\\ -\frac{x^2}{2}+x+\frac12,&x\ge0;\end{cases}$
(III) $2e^y-ey-\dfrac{y+2}{e}$；(IV) $4\sqrt2-4$。

**易错点**：分段点（$|x|=\sqrt2$、$x=0$、$x=y$、$x=\pi/2$）不能漏；$\sqrt{1-\sin x}=\big|\sin\frac x2-\cos\frac x2\big|$ 开方带绝对值，须按 $x$ 与 $\frac\pi2$ 的关系去绝对值。

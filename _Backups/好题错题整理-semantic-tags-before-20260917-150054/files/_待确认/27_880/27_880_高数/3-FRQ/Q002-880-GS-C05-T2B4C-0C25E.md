# FRQ 第 2 题

![[_Attachments/题目识别/880-GS/880-GS-C05-T2B4C-0C25E-Q002_题目.png|题目]]

(2) 求函数 $f(x, y) = (1 + y)^2 + (1 + x)^2$ 在条件 $x^2 + y^2 + xy = 3$ 下的最大值.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C05-T2B4C-0C25E-Q002_答案.png|答案]]

## V4 Pro Max 解析

**考点**：条件极值——拉格朗日乘数法求约束下的最值（约束为椭圆，最值必存在）。

**解**
设 $L=(1+x)^{2}+(1+y)^{2}+\lambda(x^{2}+y^{2}+xy-3)$。

$$\begin{cases}L_x=2(1+x)+\lambda(2x+y)=0\\ L_y=2(1+y)+\lambda(2y+x)=0\end{cases}$$

两式相减：$(x-y)(2+\lambda)=0$。

情形一：$x=y$，代入约束 $3x^{2}=3\Rightarrow x=\pm1$，得 $(1,1),(-1,-1)$，$f(1,1)=8$，$f(-1,-1)=0$。

情形二：$\lambda=-2$，则 $2(1+x)-2(2x+y)=0\Rightarrow y=1-x$，代入约束：
$$x^{2}+(1-x)^{2}+x(1-x)=3\Rightarrow x^{2}-x-2=0\Rightarrow x=2\ \text{或}\ -1.$$
得 $(2,-1),(-1,2)$，$f=9$。

比较得最大值为 $9$。

**答案**：最大值 $9$（在 $(2,-1)$ 与 $(-1,2)$ 处取得）。

**易错点**：相减后要分 $x=y$ 与 $\lambda=-2$ 两种情形讨论，漏掉 $\lambda=-2$ 会丢最大值点。

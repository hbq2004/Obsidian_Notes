# FRQ 第 7 题

![[_Attachments/题目识别/880-GS/880-GS-C07-T2B4C-Q007_题目.png|题目]]

(7) 设 $f(u)$ 有二阶连续导数， $z = f\left(\sqrt{x^2 + y^2}\right)$ 满足 $\frac{\partial^2 z}{\partial x^2} + \frac{\partial^2 z}{\partial y^2} = x^2 + y^2$，求 $z$ 的表达式.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-T2B4C-Q007_答案.png|答案]]

## V4 Pro Max 解析

**考点**：复合函数拉普拉斯算子(极坐标径向分解)化为 $f$ 的常微分方程。

**解**
令 $r = \sqrt{x^2+y^2}$,$z = f(r)$。由
$$z_x = f'(r)\frac{x}{r},\qquad
z_{xx} = f''(r)\frac{x^2}{r^2} + f'(r)\left(\frac{1}{r} - \frac{x^2}{r^3}\right),$$
及对称地 $z_{yy} = f''(r)\dfrac{y^2}{r^2} + f'(r)\left(\dfrac{1}{r} - \dfrac{y^2}{r^3}\right)$,相加:
$$z_{xx} + z_{yy} = f''(r) + \frac{f'(r)}{r} = x^2 + y^2 = r^2.$$
令 $g = f'$,则
$$g' + \frac{g}{r} = r^2.$$
积分因子 $r$:
$$(gr)' = r^3\;\Longrightarrow\; gr = \frac{r^4}{4} + C\;\Longrightarrow\; f'(r) = \frac{r^3}{4} + \frac{C}{r},$$
$$f(r) = \frac{r^4}{16} + C\ln r + D.$$

**答案**：$z = \dfrac{(x^2+y^2)^2}{16} + C\ln\sqrt{x^2+y^2} + D$。

**易错点**：$z_{xx}$ 中 $f''$ 与 $f'$ 两项都要写全;$\dfrac{1}{r} - \dfrac{x^2}{r^3} = \dfrac{r^2 - x^2}{r^3} = \dfrac{y^2}{r^3}$ 的化简可减少计算量。

# MCQ 第 4 题

![[_Attachments/题目识别/880-GS/880-GS-C09-T68FF-F9755-Q004_题目.png|题目]]

(4) 设 $\Sigma$ 为曲面 $z = \sqrt{x^2 + y^2}$ 的下侧，$P = P(x, y, z)$，$Q = Q(x, y, z)$ 均为连续函数，则 $\iint_{\Sigma} P \, dy \, dz - Q \, dz \, dx = (\quad)$

A. $\iint_{\Sigma} \left( -\frac{x}{z} P + \frac{y}{z} Q \right) dx dy$

B. $\iint_{\Sigma} \left( -\frac{x}{z} P - \frac{y}{z} Q \right) dx dy$

C. $\iint_{\Sigma} \left( \frac{x}{z} P - \frac{y}{z} Q \right) dx dy$

D. $\iint_{\Sigma} \left( \frac{x}{z} P + \frac{y}{z} Q \right) dx dy$

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C09-T68FF-F9755-Q004_答案.png|答案]]

## V4 Pro Max 解析

**考点**：第二类曲面积分在曲面 $z=\sqrt{x^2+y^2}$ 下侧的投影转化公式。

**解**
对曲面 $z=z(x,y)$，$z_x=\dfrac{x}{z}$，$z_y=\dfrac{y}{z}$。下侧（法向 $z$ 分量 $<0$）的投影转化：

$$dydz=z_x\,dxdy=\frac{x}{z}dxdy,\qquad dzdx=z_y\,dxdy=\frac{y}{z}dxdy,\qquad dxdy=-dxdy.$$

因此

$$\iint_\Sigma P\,dydz-Q\,dzdx=\iint_D\left[P\cdot\frac{x}{z}-Q\cdot\frac{y}{z}\right]dxdy=\iint_\Sigma\left(-\frac{x}{z}P+\frac{y}{z}Q\right)dxdy.$$

**答案**：A。

**易错点**：① 下侧时 $dydz=+\dfrac{x}{z}dxdy$（上侧为 $-\dfrac{x}{z}dxdy$），$Q$ 项带负号使 $dzdx$ 前的系数为 $-\dfrac{y}{z}Q$ 即 $Q$ 项取 $+\dfrac{y}{z}$；② 投影转化后积分号下仍写成 $\iint_\Sigma$（或 $dxdy$ 在 $D$ 上），注意 $x^2+y^2=z^2$ 可化简；③ 本类题逐一核对 $x/z$、$y/z$ 的符号即可得分。

# MCQ 第 2 题

![[_Attachments/题目识别/880-GS/880-GS-C01-T68FF-65D83-Q002_题目.png|题目]]

(2) 设 $a > 0$，$\lim\limits_{x \to +\infty} x^a \ln \frac{\arctan(x+1)}{\arctan x} = b$，则()。

A. $a = 2, b = \frac{2}{\pi}$

B. $a = 2, b = \frac{\pi}{2}$

C. $a = 1, b = \frac{2}{\pi}$

D. $a = 1, b = \frac{\pi}{2}$

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C01-T68FF-65D83-Q002_答案.png|答案]]

## V4 Pro Max 解析

**考点**：反三角函数的差化积与无穷远处极限。

**解**

利用公式 $\arctan A-\arctan B=\arctan\dfrac{A-B}{1+AB}$（$AB>-1$ 时）：
$$\arctan(x+1)-\arctan x=\arctan\frac{1}{1+x(x+1)}=\arctan\frac{1}{x^{2}+x+1}$$
当 $x\to+\infty$ 时 $\dfrac{1}{x^{2}+x+1}\to0$，故
$$\arctan(x+1)-\arctan x\sim\frac{1}{x^{2}+x+1}\sim\frac{1}{x^{2}}$$

又 $\arctan x\to\dfrac{\pi}{2}$，于是
$$\ln\frac{\arctan(x+1)}{\arctan x}=\ln\left(1+\frac{\arctan(x+1)-\arctan x}{\arctan x}\right)\sim\frac{\arctan(x+1)-\arctan x}{\arctan x}\sim\frac{\frac{1}{x^{2}}}{\frac{\pi}{2}}=\frac{2}{\pi x^{2}}$$

所以
$$x^{a}\ln\frac{\arctan(x+1)}{\arctan x}\sim x^{a}\cdot\frac{2}{\pi x^{2}}=\frac{2}{\pi}x^{a-2}\to b$$
取有限非零极限要求 $a=2$，此时 $b=\dfrac{2}{\pi}$。

**答案**：A

**易错点**：$\arctan$ 差的化简必须用差角公式并估计 $\arctan\dfrac{1}{x^{2}+x+1}\sim\dfrac{1}{x^{2}+x+1}$；不能错误地认为 $\arctan(x+1)-\arctan x\sim\dfrac{1}{x}$。

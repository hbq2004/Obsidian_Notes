# MCQ 第 2 题

![[_Attachments/题目识别/880-GS/880-GS-C06-T68FF-Q002_题目.png|题目]]

(2)设 $D$ 是 $xOy$ 平面上以 $A(1,1)$， $B(-1,1)$， $C(-1,-1)$ 为顶点的三角形区域， $D_1$ 是 $D$ 在第一象限的部分，则 $I = \iint_D (xy + \cos x \sin y) \, dx \, dy = (\quad)$.

A. 0

B. $2\iint_{D_1} xy \, dx \, dy$

C. $2\iint_{D_1} \cos x \sin y \, dx \, dy$

D. $4\iint_{D_1} (xy + \cos x \sin y) \, dx \, dy$

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C06-T68FF-Q002_答案.png|答案]]

## V4 Pro Max 解析

**考点**:三角形区域上二重积分的直接计算——写出区域不等式后逐层积分,结合奇偶性与分区域计算判断选项。

**解**

$D$ 以 $(1,1),(-1,1),(-1,-1)$ 为顶点,即 $D=\{-1\le x\le1,\ x\le y\le1\}$(斜边 $y=x$)。

(1) 先算 $xy$ 项:

$$\iint_D xy\,dxdy=\int_{-1}^{1}x\,dx\int_{x}^{1}y\,dy=\int_{-1}^{1}\frac{x(1-x^2)}{2}dx=0.$$

(2) 再算 $\cos x\sin y$ 项:

$$\iint_D\cos x\sin y\,dxdy=\int_{-1}^{1}\cos x\,dx\int_{x}^{1}\sin y\,dy=\int_{-1}^{1}\cos x(\cos x-\cos1)\,dx$$

$$=\int_{-1}^{1}\cos^2x\,dx-2\sin1\cos1=\left(1+\frac{\sin2}{2}\right)-\sin2=1-\frac{\sin2}{2}.$$

(3) $D_1$ 为 $D$ 在第一象限的部分,即 $D_1=\{0\le x\le1,\ x\le y\le1\}$:

$$\iint_{D_1}\cos x\sin y\,dxdy=\int_0^1\cos x\,dx\int_x^1\sin y\,dy=\int_0^1\cos x(\cos x-\cos1)\,dx$$

$$=\int_0^1\cos^2x\,dx-\sin1\cos1=\left(\frac12+\frac{\sin2}{4}\right)-\frac{\sin2}{2}=\frac12-\frac{\sin2}{4}.$$

故 $2\iint_{D_1}\cos x\sin y\,dxdy=1-\frac{\sin2}{2}=I$。

逐项判断:A($I=0$)错,因为 $\iint_D\cos x\sin y=1-\frac{\sin2}{2}\ne0$;B($2\iint_{D_1}xy=\frac14\ne I$)错;D($4\iint_{D_1}(xy+\cos x\sin y)\approx1.59\ne I$)是误用"四倍"对称性,错;C 对。

**答案**:C

**易错点**:$\cos x$ 是偶函数,$\int_{-1}^1\cos x\,dx=2\sin1\ne0$,故 $\cos x\sin y$ 在 $D$ 上的积分不能靠奇偶性消掉,必须按 $D_1$ 实际计算;区域对 $y=-x$ 对称而非对坐标轴对称,"整体乘 4"是常见误判。

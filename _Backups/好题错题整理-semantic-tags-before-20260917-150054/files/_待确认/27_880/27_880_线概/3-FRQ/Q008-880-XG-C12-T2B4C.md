# FRQ 第 8 题

![[_Attachments/题目识别/880-XG/880-XG-C12-T2B4C-Q008_题目.png|题目]]

(8) 设矩阵 $A_5 \times 4$ 的秩为 2, $\alpha_1 = (1, 1, 2, 3)^T$, $\alpha_2 = (-1, 1, 4, -1)^T$, $\alpha_3 = (5, -1, -8, 9)^T$ 是方程组 $Ax = 0$ 的解向量，求 $Ax = 0$ 的解空间的一组标准正交基.

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C12-T2B4C-Q008_答案.png|答案]]

## V4 Pro Max 解析

**考点**：齐次方程组解空间的维数与施密特正交化求标准正交基。

**解**

$r(A)=2$,未知量个数为 4,故解空间维数为 $4-2=2$。

先找基:注意到

$$\alpha_3=2\alpha_1-3\alpha_2=2(1,1,2,3)^T-3(-1,1,4,-1)^T=(5,-1,-8,9)^T,$$

故 $\alpha_3$ 是多余向量,$\alpha_1,\alpha_2$ 线性无关,构成解空间的一组基。

施密特正交化:令 $u_1=\alpha_1=(1,1,2,3)^T$,$|u_1|^2=1+1+4+9=15$,$\alpha_2\cdot\alpha_1=-1+1+8-3=5$,则

$$u_2=\alpha_2-\frac{\alpha_2\cdot u_1}{|u_1|^2}u_1=(-1,1,4,-1)^T-\frac13(1,1,2,3)^T=\left(-\frac43,\frac23,\frac{10}3,-2\right)^T=\frac13(-4,2,10,-6)^T.$$

单位化:

$$q_1=\frac{u_1}{|u_1|}=\frac1{\sqrt{15}}(1,1,2,3)^T,\qquad q_2=\frac{u_2}{|u_2|}=\frac1{\sqrt{156}}(-4,2,10,-6)^T=\frac1{\sqrt{39}}(-2,1,5,-3)^T.$$

$q_1,q_2$ 即解空间的一组标准正交基。

**答案**：标准正交基为 $q_1=\dfrac1{\sqrt{15}}(1,1,2,3)^T$,$q_2=\dfrac1{\sqrt{39}}(-2,1,5,-3)^T$。

**易错点**：先由 $4-r(A)$ 定维数;三个解向量中 $\alpha_3=2\alpha_1-3\alpha_2$ 是多余的,正交化只用 $\alpha_1,\alpha_2$。

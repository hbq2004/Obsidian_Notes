# FRQ 第 5 题

![[_Attachments/题目识别/880-XG/880-XG-C18-T2B4C-Q005_题目.png|题目]]

(5) 设二维随机变量 $(X, Y)$ 的概率密度为 $f(x, y) = \begin{cases} xe^{-y}, & 0 < x < y < +\infty, \\ 0, & 其他. \end{cases}$

(I) $X$ 与 $Y$ 的边缘概率密度，并判别 $X$ 与 $Y$ 是否相互独立；

(II) $(X, Y)$ 的分布函数 $F(x, y)$；

(III) $Z = X + Y$ 的概率密度 $f_Z(z)$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C18-T2B4C-Q005_答案.png|答案]]

## V4 Pro Max 解析

**考点**：非矩形支撑 $0<x<y$ 的联合密度的边缘密度、独立性判别、分布函数分段求法与 $X+Y$ 的卷积。

**解**

区域：$0<x<y<+\infty$。先验算归一化：$\int_0^\infty\int_0^y xe^{-y}\,dxdy=\int_0^\infty \frac{y^2}{2}e^{-y}dy=\frac12\cdot2!=1$ ✓。

(I) 边缘密度：

$$f_X(x)=\int_x^\infty xe^{-y}\,dy=xe^{-x},\qquad x>0;$$

$$f_Y(y)=\int_0^y xe^{-y}\,dx=\frac{y^2}{2}e^{-y},\qquad y>0.$$

因 $f(x,y)=xe^{-y}\neq \big(xe^{-x}\big)\big(\frac{y^2}{2}e^{-y}\big)=f_X(x)f_Y(y)$，故 $X$ 与 $Y$ 不相互独立（支撑也非矩形）。

(II) 分布函数 $F(x,y)=P\{X\le x,Y\le y\}$。

- 当 $x\le0$ 或 $y\le0$ 时 $F=0$；
- 当 $0<x<y$ 时：

$$F(x,y)=\int_0^x\int_u^y ue^{-v}\,dvdu=\int_0^x u(e^{-u}-e^{-y})du=\Big[1-e^{-x}(x+1)\Big]-\frac{x^2}{2}e^{-y};$$

- 当 $0<y\le x$ 时（积分上限 $v$ 取 $y$）：

$$F(x,y)=\int_0^y\int_u^y ue^{-v}\,dvdu=1-e^{-y}(y+1)-\frac{y^2}{2}e^{-y}.$$

(III) $Z=X+Y$。卷积：对 $z>0$，$0<x<y=z-x\Rightarrow 0<x<\frac z2$，

$$f_Z(z)=\int_0^{z/2} xe^{-(z-x)}\,dx=e^{-z}\int_0^{z/2} xe^{x}\,dx=e^{-z}\Big[e^x(x-1)\Big]_0^{z/2}=e^{-z}\left[e^{z/2}\left(\frac z2-1\right)+1\right],$$

即

$$f_Z(z)=\begin{cases} e^{-z}-\dfrac z2e^{-z/2}-e^{-z/2}\cdot(-1)\ \text{整理为}\ e^{-z}-e^{-z/2}+\dfrac z2 e^{-z/2},&z>0,\\[6pt] 0,&z\le0.\end{cases}$$

**答案**：(I) $f_X(x)=xe^{-x}$，$f_Y(y)=\frac{y^2}{2}e^{-y}\ (y>0)$，$X,Y$ 不独立；(II) 分布函数按 $0<x<y$ 与 $0<y\le x$ 分段（见上）；(III) $f_Z(z)=e^{-z}-e^{-z/2}+\dfrac z2 e^{-z/2}\ (z>0)$。

**易错点**：区域 $0<x<y$ 使 $X+Y$ 的卷积上限为 $z/2$ 而非 $z$；分布函数必须分 $x<y$ 与 $x\ge y$ 两段，且 $F(+\infty,+\infty)=1$ 可作校验。

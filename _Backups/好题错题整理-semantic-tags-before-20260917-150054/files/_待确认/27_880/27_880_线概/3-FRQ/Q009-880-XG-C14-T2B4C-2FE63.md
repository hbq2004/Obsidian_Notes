# FRQ 第 9 题

![[_Attachments/题目识别/880-XG/880-XG-C14-T2B4C-2FE63-Q009_题目.png|题目]]

(9) 设 $\alpha, \beta$ 为 3 维单位列向量，且 $\alpha^T \beta = 0$，记 $A = \alpha \beta^T + \beta \alpha^T$。

(I) 证明：$A$ 相似于对角矩阵；

(II) 若存在 3 维列向量 $\gamma \neq 0$，使得 $A \gamma = 0$，记 $P = (\gamma, 2(\alpha + \beta), \beta - \alpha)$，求 $P^{-1} AP$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C14-T2B4C-2FE63-Q009_答案.png|答案]]

## V4 Pro Max 解析

**考点**：实对称矩阵 $A=\alpha\beta^T+\beta\alpha^T$（$\alpha,\beta$ 正交单位向量）的特征值结构与正交对角化。

**解**

(I) 直接构造特征向量：

$$A\alpha=\alpha\beta^T\alpha+\beta\alpha^T\alpha=0+\beta\cdot1=\beta,$$

$$A(\alpha+\beta)=\alpha(\beta^T\alpha+\beta^T\beta)+\beta(\alpha^T\alpha+\alpha^T\beta)=\alpha(0+1)+\beta(1+0)=\alpha+\beta,$$

$$A(\alpha-\beta)=\alpha(\beta^T\alpha-\beta^T\beta)+\beta(\alpha^T\alpha-\alpha^T\beta)=\alpha(0-1)+\beta(1-0)=-(\alpha-\beta).$$

故 $\alpha+\beta,\ \alpha-\beta$ 分别是特征值 $1$ 与 $-1$ 的特征向量，它们线性无关。

又 $A^T=(\alpha\beta^T+\beta\alpha^T)^T=\beta\alpha^T+\alpha\beta^T=A$，$A$ 是实对称矩阵，必可正交对角化，从而相似于对角矩阵。（也可补充：取 $\gamma\perp\alpha,\beta$ 且 $\gamma\ne0$，则 $A\gamma=0$，特征值 $0$ 的几何重数为 $3-2=1$，三个互异特征值 $1,-1,0$ 已构成对角化。）

(II) 由 $A\gamma=0$ 且 $\gamma\ne0$，仿上知 $\gamma\perp\alpha,\beta$，故 $\gamma,\ \alpha+\beta,\ \alpha-\beta$ 线性无关。设

$$P=\big(\gamma,\ 2(\alpha+\beta),\ \beta-\alpha\big).$$

注意 $\beta-\alpha=-(\alpha-\beta)$ 是特征值 $-1$ 的特征向量，$2(\alpha+\beta)$ 是特征值 $1$ 的特征向量，$\gamma$ 是特征值 $0$ 的特征向量，故

$$P^{-1}AP=\Lambda=\operatorname{diag}(0,1,-1).$$

**答案**：(I) $A$ 为实对称矩阵，可正交对角化，特征值为 $1,-1,0$；
(II) $P^{-1}AP=\operatorname{diag}(0,1,-1)$。

**易错点**：$\alpha,\beta$ 是单位正交向量，$\alpha^T\alpha=\beta^T\beta=1,\ \alpha^T\beta=0$ 必须用足；$A\gamma=0$ 蕴含 $\gamma\perp\alpha$ 且 $\gamma\perp\beta$（由 $\alpha,\beta$ 线性无关），保证 $P$ 可逆。

# FRQ 第 5 题

![[_Attachments/题目识别/880-XG/880-XG-C14-T2B4C-Q005_题目.png|题目]]

(5) 设 $A$ 是 3 阶矩阵, $\alpha_1, \alpha_2, \alpha_3$ 是线性无关的 3 维列向量, 且 $A\alpha_1 = \alpha_1 + \alpha_2 + \alpha_3$, $A\alpha_2 = 2\alpha_2 + \alpha_3$, $A\alpha_3 = 2\alpha_2 + 3\alpha_3$. 求:

(I) $A$ 的全部特征值;

(II) 可逆矩阵 $P$ 及 $\Lambda$, 使得 $P^{-1}AP = \Lambda$, 并计算 $|A - 2E|$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C14-T2B4C-Q005_答案.png|答案]]

## V4 Pro Max 解析

**考点**：由 $A$ 在已知基上的作用写出表示矩阵，求特征值、特征向量与对角化，再计算 $|A-2E|$。

**解**

记 $B=(\alpha_1,\alpha_2,\alpha_3)$。由

$$A\alpha_1=\alpha_1+\alpha_2+\alpha_3,\quad A\alpha_2=2\alpha_2+\alpha_3,\quad A\alpha_3=2\alpha_2+3\alpha_3,$$

$A$ 在基 $(\alpha_1,\alpha_2,\alpha_3)$ 下的矩阵为 $C=B^{-1}AB=\begin{pmatrix}1&0&0\\1&2&2\\1&1&3\end{pmatrix}$。

(I) $|\lambda E-C|=\begin{vmatrix}\lambda-1&0&0\\-1&\lambda-2&-2\\-1&-1&\lambda-3\end{vmatrix}=(\lambda-1)\big((\lambda-2)(\lambda-3)-2\big)=(\lambda-1)(\lambda^2-5\lambda+4)=(\lambda-1)^2(\lambda-4)$。

$A$ 的全部特征值：$1$（二重）、$4$。

(II) 求 $C$ 的特征向量：$\lambda=1$：$C-E=\begin{pmatrix}0&0&0\\1&1&2\\1&1&2\end{pmatrix}$，$x+y+2z=0$，取 $\eta_1=(1,-1,0)^T,\ \eta_2=(2,0,-1)^T$；$\lambda=4$：$C-4E=\begin{pmatrix}-3&0&0\\1&-2&2\\1&1&-1\end{pmatrix}$，$x=0,\ y=z$，取 $\eta_3=(0,1,1)^T$。

于是 $A$ 的特征向量（在标准基下表示为基向量组合）：$\xi_1=B\eta_1=\alpha_1-\alpha_2$，$\xi_2=B\eta_2=2\alpha_1-\alpha_3$，$\xi_3=B\eta_3=\alpha_2+\alpha_3$。（验证：$A(\alpha_1-\alpha_2)=A\alpha_1-A\alpha_2=(\alpha_1+\alpha_2+\alpha_3)-(2\alpha_2+\alpha_3)=\alpha_1-\alpha_2$ ✓；$A(2\alpha_1-\alpha_3)=2(\alpha_1+\alpha_2+\alpha_3)-(2\alpha_2+3\alpha_3)=2\alpha_1-\alpha_3$ ✓；$A(\alpha_2+\alpha_3)=2\alpha_2+\alpha_3+2\alpha_2+3\alpha_3=4(\alpha_2+\alpha_3)$ ✓）

$$P=(\xi_1,\xi_2,\xi_3)=(\alpha_1-\alpha_2,\ 2\alpha_1-\alpha_3,\ \alpha_2+\alpha_3),\qquad \Lambda=\operatorname{diag}(1,1,4).$$

$$|A-2E|=\prod_{i}(\lambda_i-2)=(1-2)(1-2)(4-2)=(-1)(-1)\cdot2=2.$$

**答案**：(I) $A$ 的特征值为 $1,1,4$；
(II) $P=(\alpha_1-\alpha_2,\ 2\alpha_1-\alpha_3,\ \alpha_2+\alpha_3)$，$\Lambda=\operatorname{diag}(1,1,4)$，$|A-2E|=2$。

**易错点**：$A$ 在基 $(\alpha_i)$ 下的矩阵 $C$ 与 $A$ 相似，特征值相同；把 $C$ 的特征向量左乘 $B$ 才得到 $A$ 的标准特征向量（因为 $\xi=B\eta\iff C\eta$ 是 $C$ 的特征向量）；$|A-2E|$ 用特征值乘积。

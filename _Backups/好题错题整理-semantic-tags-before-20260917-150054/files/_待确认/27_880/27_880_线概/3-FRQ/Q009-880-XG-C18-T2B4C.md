# FRQ 第 9 题

![[_Attachments/题目识别/880-XG/880-XG-C18-T2B4C-Q009_题目.png|题目]]

(9) 设二维随机变量 $(X, Y)$ 的概率密度为 $f(x, y) = \frac{1}{k}(1 + xy)e^{-\frac{1}{2}(x^2 + y^2)}$ $(k > 0, (x, y) \in \mathbb{R}^2)$.

(I) 求 $k$ 的值，并判别 $X$ 与 $Y$ 是否相互独立；

(II) 若 $Z$ 服从区间 $[- \pi, \pi]$ 上的均匀分布，且 $X$ 与 $Z$ 相互独立，求 $U = X + Z$ 的概率密度（可用 $\Phi(x)$ 表示）.

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C18-T2B4C-Q009_答案.png|答案]]

## V4 Pro Max 解析

**考点**：含 $xy$ 修正项的准正态联合密度：定常数、算边缘密度判别独立性、正态与均匀分布之和的卷积。

**解**

(I) 由归一化：

$$k=\iint_{\mathbb R^2}(1+xy)e^{-\frac{x^2+y^2}{2}}\,dxdy=\iint e^{-\frac{x^2+y^2}{2}}dxdy+\iint xy\,e^{-\frac{x^2+y^2}{2}}dxdy.$$

第一项 $=\sqrt{2\pi}\cdot\sqrt{2\pi}=2\pi$；第二项被积函数对 $x$ 为奇函数（$y$ 固定），积分为 $0$。故 $k=2\pi$。

边缘密度：

$$f_X(x)=\frac{1}{2\pi}\int_{-\infty}^{+\infty}(1+xy)e^{-\frac{x^2+y^2}{2}}dy=\frac{1}{2\pi}e^{-x^2/2}\left[\int e^{-y^2/2}dy+x\int y\,e^{-y^2/2}dy\right]=\frac{1}{2\pi}e^{-x^2/2}\cdot\sqrt{2\pi}=\frac{1}{\sqrt{2\pi}}e^{-x^2/2},$$

即 $X\sim N(0,1)$；同理 $Y\sim N(0,1)$。因 $f(x,y)=\frac{1}{2\pi}(1+xy)e^{-(x^2+y^2)/2}\neq \varphi(x)\varphi(y)$，$X$ 与 $Y$ 不相互独立（尽管协方差为 0）。

(II) $X\sim N(0,1)$ 与 $Z\sim U[-\pi,\pi]$（密度 $f_Z(z)=\frac{1}{2\pi},\ z\in[-\pi,\pi]$）独立。$U=X+Z$，卷积：

$$f_U(u)=\int_{-\infty}^{+\infty}\varphi(x)\cdot\frac{1}{2\pi}\mathbf 1_{[-\pi,\pi]}(u-x)\,dx=\frac{1}{2\pi}\int_{u-\pi}^{u+\pi}\varphi(x)\,dx=\frac{1}{2\pi}\Big[\Phi(u+\pi)-\Phi(u-\pi)\Big].$$

**答案**：(I) $k=2\pi$；$X\sim N(0,1)$，$Y\sim N(0,1)$，但 $X,Y$ 不独立；(II) $f_U(u)=\dfrac{1}{2\pi}\big[\Phi(u+\pi)-\Phi(u-\pi)\big]$。

**易错点**：$\iint xy\,e^{-(x^2+y^2)/2}dxdy=0$（奇函数）；边缘密度是标准正态，但"边缘正态且协方差为 0"推不出独立，本题恰是反例（$f$ 不是二元正态密度）。

# FRQ 第 1 题

![[_Attachments/题目识别/880-XG/880-XG-C13-T2B4C-0001F-Q001_题目.png|题目]]

(1) 设 $A$ 是 $m \times n$ 矩阵, $r(A) = n - 2$，非齐次线性方程组 $Ax = b$ 的 3 个解向量 $\alpha_1$, $\alpha_2$, $\alpha_3$ 满足 $\alpha_1 + \alpha_2 = (1, 2, 3, 4)^T$，$\alpha_2 + 2\alpha_3 = (-2, 1, 5, 3)^T$，$2\alpha_3 + 3\alpha_1 = (11, 5, -6, 7)^T$，求方程组 $Ax = b$ 的通解.

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C13-T2B4C-0001F-Q001_答案.png|答案]]

## V4 Pro Max 解析

**考点**：非齐次线性方程组解的结构——由若干解的线性组合反解特解与齐次基础解系，写出通解。

**解**

由 $r(A)=n-2$ 知 $Ax=0$ 的基础解系含 $n-(n-2)=2$ 个线性无关解向量，故只需找出 2 个线性无关的齐次解和一个特解。

设
$$\alpha_1+\alpha_2=u_1=(1,2,3,4)^T,\quad \alpha_2+2\alpha_3=u_2=(-2,1,5,3)^T,\quad 2\alpha_3+3\alpha_1=u_3=(11,5,-6,7)^T.$$

由 $\alpha_2=u_1-\alpha_1$，$\alpha_3=\dfrac{u_2-u_1+\alpha_1}{2}$，代入第三式：

$$u_2-u_1+\alpha_1+3\alpha_1=u_3 \;\Longrightarrow\; 4\alpha_1=u_3-u_2+u_1,$$

$$4\alpha_1=(11,5,-6,7)^T-(-2,1,5,3)^T+(1,2,3,4)^T=(14,6,-8,8)^T,$$

$$\alpha_1=\left(\frac72,\frac32,-2,2\right)^T.$$

因 $\alpha_1,\alpha_2,\alpha_3$ 都是 $Ax=b$ 的解，其差是齐次解：

$$\eta_1=\alpha_1-\alpha_2=2\alpha_1-u_1=(7,3,-4,4)^T-(1,2,3,4)^T=(6,1,-7,0)^T,$$

$$\eta_2=\alpha_1-\alpha_3=\alpha_1-\frac{u_2-u_1+\alpha_1}{2}=\frac{2\alpha_1-u_2+u_1}{2}=\left(5,2,-3,\frac52\right)^T.$$

$\eta_1,\eta_2$ 不成比例，线性无关，构成 $Ax=0$ 的基础解系（恰 2 个，与 $r(A)=n-2$ 吻合）。

故通解为
$$x=\alpha_1+k_1\eta_1+k_2\eta_2=\left(\frac72,\frac32,-2,2\right)^T+k_1(6,1,-7,0)^T+k_2\left(5,2,-3,\frac52\right)^T,\quad k_1,k_2\in\mathbb R.$$

**答案**：$x=\left(\dfrac72,\dfrac32,-2,2\right)^T+k_1(6,1,-7,0)^T+k_2\left(5,2,-3,\dfrac52\right)^T$（$k_1,k_2$ 为任意常数）。

**易错点**：必须先由三个已知线性组合解出某个解 $\alpha_1$（它自然是特解），再取两解之差作齐次解；差向量个数要与 $n-r(A)$ 一致，否则基础解系不完整。不要把 $\alpha_1+\alpha_2$ 直接当作解——它满足 $A(\alpha_1+\alpha_2)=2b$，只有除以 2 才是解。

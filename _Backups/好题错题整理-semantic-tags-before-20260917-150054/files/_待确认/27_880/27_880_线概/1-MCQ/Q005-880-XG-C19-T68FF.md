# MCQ 第 5 题

![[_Attachments/题目识别/880-XG/880-XG-C19-T68FF-Q005_题目.png|题目]]

(5) 设随机变量 $X$ 与 $Y$ 相互独立，且均存在非零方差，$DX \neq DY$，则().

A. $2X+1$ 与 $2Y-1$ 相关
B. $X+Y$ 与 $X-Y$ 不相关
C. $e^X$ 与 $Y+1$ 相互独立
D. $X+Y$ 与 $Y+1$ 相互独立

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C19-T68FF-Q005_答案.png|答案]]

## V4 Pro Max 解析

**考点**：独立随机变量函数的独立性;不相关与独立的区分。

**解**
$X$ 与 $Y$ 独立。独立变量的函数仍独立,这是判定 A、C 的基础。

- A 错:$2X+1$ 与 $2Y-1$ 是独立变量 $X,Y$ 的函数,故相互独立,必不相关;
- B 错:$\operatorname{Cov}(X+Y,X-Y)=DX-DY\ne0$(题设 $DX\ne DY$),故相关;
- C 对:$e^X$ 是 $X$ 的函数,$Y+1$ 是 $Y$ 的函数,$X,Y$ 独立 $\Rightarrow e^X$ 与 $Y+1$ 相互独立;
- D 错:$X+Y$ 同时含 $X$ 与 $Y$,与 $Y+1$ 一般不独立(如取 $X,Y$ 使联合概率不分解)。

选 $\boxed{C}$。

**答案**：C。

**易错点**：两个独立变量的函数必独立(只需各自只含一个变量);B 中 $DX\ne DY$ 恰好制造了相关性,是高频干扰。

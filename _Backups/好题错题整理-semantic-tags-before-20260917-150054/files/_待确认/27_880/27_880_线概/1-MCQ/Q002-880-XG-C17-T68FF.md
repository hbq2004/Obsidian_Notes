# MCQ 第 2 题

![[_Attachments/题目识别/880-XG/880-XG-C17-T68FF-Q002_题目.png|题目]]

(2)下列函数中，可作为某一随机变量的分布函数的是().

A. $F(x) = \frac{1}{1 + x^2}$

B. $F(x) = \frac{1}{\pi} \arctan x + \frac{1}{2}$

C. $F(x) = \begin{cases} \frac{1}{2}(1 - e^{-x}), & x > 0, \\ 0, & x \leq 0 \end{cases}$

D. $F(x) = \int_{-\infty}^{x} f(t)dt$，且 $\int_{-\infty}^{+\infty} f(t)dt = 1$

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C17-T68FF-Q002_答案.png|答案]]

## V4 Pro Max 解析

**考点**：分布函数四条性质（单调、右连续、$F(-\infty)=0$、$F(+\infty)=1$）判定选项。

**解**

A. $F(x)=\frac1{1+x^2}$：$\lim_{x\to+\infty}F(x)=0\ne1$，✗。
B. $F(x)=\frac1\pi\arctan x+\frac12$：$F(-\infty)=0$，$F(+\infty)=\frac1\pi\cdot\frac\pi2+\frac12=1$，$\arctan x$ 单调递增故 $F$ 单调不减，且处处连续，✓（柯西分布函数）。
C. $F(x)=\begin{cases}\frac12(1-e^{-x}),&x>0,\\0,&x\le0\end{cases}$：$\lim_{x\to+\infty}F(x)=\frac12\ne1$，✗。
D. 仅知 $\int_{-\infty}^{+\infty}f(t)\,dt=1$ 不能保证 $f(t)\ge0$（$f$ 可为负），此时 $F(x)=\int_{-\infty}^x f(t)\,dt$ 未必单调不减，✗。

**答案**：B. $F(x)=\frac1\pi\arctan x+\frac12$。

**易错点**：$\int f=1$ 但 $f$ 可为负，故 D 不保证构成分布函数；C 的极限是 $1/2$ 而非 $1$；A 两端极限都是 0。

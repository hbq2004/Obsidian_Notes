# MCQ 第 2 题

(2)设 $A$ 是 3 阶方阵，$A^*$ 是 $A$ 的伴随矩阵，$|A| = \frac{1}{2}$，则 $\left| (2A)^{-1} - 2A^* \right| = (\＿)$。

A. $\frac{1}{2}$

B. $-\frac{1}{2}$

C. $-\frac{1}{4}$

D. $\frac{1}{4}$

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C10-T68FF-F55DD-Q002_答案.png|答案]]

## V4 Pro Max 解析

**考点**：$(kA)^{-1}$ 与伴随 $A^* = |A|A^{-1}$ 的化简,利用 $|kA| = k^n|A|$ 求行列式。

**解**
$$(2A)^{-1} = \frac{1}{2}A^{-1},\qquad A^* = |A|A^{-1} = \frac{1}{2}A^{-1},$$
$$\left|(2A)^{-1} - 2A^*\right| = \left|\frac{1}{2}A^{-1} - 2\cdot\frac{1}{2}A^{-1}\right| = \left|-\frac{1}{2}A^{-1}\right|.$$

$A$ 是 3 阶方阵,$|kA| = k^3|A|$,故
$$\left|-\frac{1}{2}A^{-1}\right| = \left(-\frac12\right)^3|A^{-1}| = -\frac{1}{8}\cdot\frac{1}{|A|} = -\frac{1}{8}\cdot2 = -\frac{1}{4}.$$

干扰项辨析:
- A. $\tfrac12$:漏掉 3 阶矩阵提因子的 $(-1/2)^3$ 与负号,只算了 $|A^{-1}|$ 类;
- B. $-\tfrac12$:符号对了但没算 $k^3$ 因子;
- D. $\tfrac14$:算对了 $1/8$ 与 $|A|^{-1} = 2$ 但符号取错。

**答案**：C($-\dfrac14$)。

**易错点**：$n$ 阶矩阵 $|kA| = k^n|A|$,$n = 3$ 时系数是 $(-1/2)^3 = -1/8$;$A^* = |A|A^{-1}$ 在 $A$ 可逆时可直接整体替换。

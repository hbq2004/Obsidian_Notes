# FIB 第 3 题

![[_Attachments/题目识别/880-XG/880-XG-C18-TC67C-87580-Q003_题目.png|题目]]

(3) 设 $D = \{(x, y) \mid 0 \leqslant x \leqslant a, 0 \leqslant y \leqslant a\}$，向 $D$ 上均匀地投掷随机点，$(X, Y)$ 表示随机点的坐标，$0 < b < a$，则 $P\{|X - Y| \leqslant b\} - P\{\min(X, Y) \leqslant b\} = \＿$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C18-TC67C-87580-Q003_答案.png|答案]]

## V4 Pro Max 解析

**考点**：正方形上均匀分布，$|X-Y|\le b$ 与 $\min\{X,Y\}\le b$ 的概率（面积法）相等。

**解**

$(X,Y)$ 在 $[0,a]\times[0,a]$ 上均匀分布，总面积 $a^2$。

(I) $P\{|X-Y|\le b\}=1-P\{|X-Y|>b\}$。事件 $|X-Y|>b$ 是正方形内直线 $y=x+b$ 上方与 $y=x-b$ 下方的两个三角形，边长均为 $a-b$，每个面积 $\frac12(a-b)^2$：

$$P\{|X-Y|\le b\}=1-\frac{2\cdot\frac12(a-b)^2}{a^2}=1-\frac{(a-b)^2}{a^2}=\frac{2ab-b^2}{a^2}.$$

(II) $P\{\min\{X,Y\}\le b\}=1-P\{\min> b\}=1-P\{X>b,\ Y>b\}=1-\left(\frac{a-b}{a}\right)^2=\frac{2ab-b^2}{a^2}.$

两式相等，故

$$P\{|X-Y|\le b\}-P\{\min\{X,Y\}\le b\}=0.$$

**答案**：$0$。

**易错点**：两个概率的几何含义不同（一个靠"中间带"，一个靠"左下角"），但数值相同——都等于 $\frac{2ab-b^2}{a^2}$；$\min> b$ 等价于两个分量同时 $>b$，勿与 $\max$ 混淆。

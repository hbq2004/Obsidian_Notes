# MCQ 第 22 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C05-S03-Q022_题目.png|题目]]

22. 假设磁盘有 1000 个磁道,编号从 0 到 999,当前磁头正在 734 号磁道,且向磁道号增大的方向移动。磁道请求依次为 164,845,911,165,788,432,396,700,25,若分别用 SCAN 算法 (非 LOOK 调度) 和 SSTF 算法完成上述请求后,磁头移动的磁道数分别是（ ）
(A) 1865,1543
(B) 1688,1738
(C) 1239,1131
(D) 1239,1738

## DeepSeek V4 Flash Max 解析
**答案**：C

**解题切入点**：本题是典型的磁盘调度算法模拟题，可将磁道看作数轴上的点，磁头移动路径等价于在数轴上求总长度。SCAN 算法（非 LOOK）类似“固定方向的双指针扫描”，磁头先沿当前方向移动至磁盘物理末端（$999$），再反向移动，直到所有请求完成；SSTF 算法则类似“贪心策略”，每次选择与当前磁头距离最近的请求，如同算法竞赛中“每次选最近点”的构造。解题关键在于准确理解算法流程并逐步模拟。

**推演**：

1. SCAN 算法（非 LOOK）  
   当前磁头在 $734$，方向增大。先向增大方向移动至 $999$，途中服务所有 $\ge 734$ 的请求（$788,845,911$），移动距离 $999-734=265$。  
   掉头后向减小方向移动，服务所有 $<734$ 的请求（$700,432,396,165,164,25$），直到最后一个请求 $25$，移动距离 $999-25=974$。  
   总移动磁道数：$265+974=1239$。

2. SSTF 算法  
   模拟每一步（选择距离最近的请求）：
   - 从 $734$ 出发，最近 $700$（距离 $34$），至 $700$；
   - 从 $700$，最近 $788$（$88$），至 $788$；
   - 从 $788$，最近 $845$（$57$），至 $845$；
   - 从 $845$，最近 $911$（$66$），至 $911$；
   - 从 $911$，最近 $432$（$479$），至 $432$；
   - 从 $432$，最近 $396$（$36$），至 $396$；
   - 从 $396$，最近 $165$（$231$），至 $165$；
   - 从 $165$，最近 $164$（$1$），至 $164$；
   - 从 $164$，最后 $25$（$139$），至 $25$。  
   累计移动距离：$34+88+57+66+479+36+231+1+139=1131$。

因此，SCAN 算法移动 $1239$ 磁道，SSTF 算法移动 $1131$ 磁道，对应选项 C。

**易错点**：
- “非 LOOK 调度”易混淆：SCAN 算法必须先走到磁盘物理末端（$999$）才掉头，但掉头后服务完所有请求即可停止，无需继续走到另一末端（$0$），否则会多算 $25$ 步（得到 $1264$）。
- SSTF 模拟时，每次必须重新计算所有剩余请求与当前磁头的距离，避免遗漏或顺序错误，尤其注意距离相近的请求（如 $165$ 与 $164$）。
- 累加步数时需仔细，防止算术错误。

**命题规律**：
磁盘调度算法是操作系统 I/O 子系统的高频考点，常以计算题形式出现，重点考查 SCAN、C-SCAN、SSTF 等算法的模拟与移动距离计算。解题需像算法竞赛中“状态模拟”一样，逐步推导，理解算法本质（如 SCAN 的“固定方向”特性、SSTF 的“贪心”策略）。本题结合方向选择和贪心策略，要求考生具备严谨的模拟能力。

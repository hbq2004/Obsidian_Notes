# MCQ 第 26 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C02-S01-Q026_题目.png|题目]]

进程创建完成后会进入一个序列,这个序列称为（ ）.
(A) 阻塞队列
(B) 挂起序列
(C) 就绪队列
(D) 运行队列

## DeepSeek V4 Flash Max 解析
**答案**：C. 就绪队列

**解题切入点**：从进程生命周期状态转换入手，进程创建后立即进入就绪状态，等待 CPU 调度。类似算法竞赛中，构造好一个状态（如 BFS 的初始结点）后，将其加入待探索队列，而非立即处理。

**推演**：进程创建完成（如系统调用 `fork()`）后，进程已获得除 CPU 外的所有必要资源，处于就绪状态。此时它被放入就绪队列，等待调度器分配 CPU。阻塞队列用于等待 I/O 或事件，运行队列是正在占用 CPU 的进程集合，挂起序列并非标准进程状态术语。状态转换关系可表示为：$创建 \rightarrow 就绪 \rightarrow 运行 \rightarrow 阻塞 \rightarrow 就绪$ 等。

**易错点**：可能误认为创建后直接进入运行队列，但实际进程创建后并未立即获得 CPU，只有被调度器选中后才进入运行状态。类似算法竞赛中，构造完一个状态后不会立即展开，而是先放入队列，待后续轮次扩展。

**命题规律**：考察进程三种基本状态（就绪、运行、阻塞）的区分，常以选择题出现。需牢记进程创建后默认进入就绪状态，除非系统资源不足或特殊限制。

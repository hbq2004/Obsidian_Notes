# MCQ 第 20 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C05-S03-Q020_题目.png|题目]]

设一个磁道访问请求序列为 $55,58,39,18,90,160,150,38,184$，磁头的起始位置为 $100$，若采用 SSTF(最短寻道时间优先)算法，则磁头移动 $(\＿)$ 个磁道.
(A) $55$
(B) $184$
(C) $200$
(D) $248$

## DeepSeek V4 Flash Max 解析
**答案**：
D：$248$

**解题切入点**：
把磁头当前位置看成“状态”，把尚未服务的磁道请求看成“未访问结点”。SSTF 等价于在带权完全图上做最近邻贪心：每次从当前 $p$ 选择 $y$ ，使 $|p-y|$ 最小，并累计移动距离。和算法竞赛里的 nearest-neighbor 贪心一样，它只保证局部最近，不保证全局最优；本题只需按这个贪心规则逐步模拟。

**推演**：
设 $p$ 为当前磁道，$d$ 为本次移动距离，$T$ 为累计移动距离。

- 初始 $p=100$ 。最近请求为 $90$ ，因为 $|100-90|=10<|100-150|=50$ ，所以 $d=10,\ T=10$ 。
- $p=90$ ：剩余最近为 $58$ ，$d=|90-58|=32,\ T=42$ 。
- $p=58$ ：最近为 $55$ ，$d=3,\ T=45$ 。
- $p=55$ ：最近为 $39$ ，因为 $|55-39|=16<|55-38|=17$ ，所以 $d=16,\ T=61$ 。
- $p=39$ ：最近为 $38$ ，$d=1,\ T=62$ 。
- $p=38$ ：最近为 $18$ ，$d=20,\ T=82$ 。
- $p=18$ ：剩余为 $150,160,184$ ，最近为 $150$ ，$d=132,\ T=214$ 。
- $p=150$ ：最近为 $160$ ，$d=10,\ T=224$ 。
- $p=160$ ：只余 $184$ ，$d=24,\ T=248$ 。

所以

$$
T=10+32+3+16+1+20+132+10+24=248.
$$

即磁头移动 $248$ 个磁道，选 D。

**易错点**：
1. 不能按请求序列顺序计算，如 $100\to55\to58\to39\to\cdots$ ；序列只是到达顺序，不是服务顺序。
2. 在 $p=55$ 时不能先选 $38$ ，因为 $|55-39|=16<|55-38|=17$ ，必须先到 $39$ ，否则累计距离会变成 $250$ 。
3. $184$ 是最后一个磁头位置，不是总移动距离；选项 B 是干扰项。
4. 从 $p=18$ 后不能想当然向左向右扫描，SSTF 比较距离后应先去 $150$ ，再去 $160$ ，最后到 $184$ 。

**命题规律**：
408 常把磁盘调度算法出成计算型选择题：给请求序列和起始磁道，求 SSTF、SCAN、C-SCAN 等算法下的磁头移动量。本题对应 SSTF 的局部贪心思想，类似算法竞赛中“每次找当前状态最近的未访问点”。可先把请求排序，再模拟当前点左右邻居谁更近；考试手算时则逐步选最近请求即可。命题人也常用“最终磁道号”和“按输入顺序计算”设置干扰项，注意题目问的是累计移动距离。

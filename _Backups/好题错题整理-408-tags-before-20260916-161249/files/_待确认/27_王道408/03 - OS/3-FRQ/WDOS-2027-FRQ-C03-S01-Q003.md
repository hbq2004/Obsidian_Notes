# FRQ 第 3 题

![[_Attachments/题目识别/WDOS-2027-FRQ/WDOS-2027-FRQ-C03-S01-Q003_题目.png|题目]]

下图给出了页式和段式两种地址变换示意(假定段式变换对每段不进行段长越界检查,即段表中无段长信息).
$ (1) $ 指出这两种变换各属于何种存储管理.
$ (2) $ 计算出这两种变换所对应的物理地址.

## DeepSeek V4 Flash Max 解析
**答案**：
(1) 有页表做地址映射的变换属于基本分页存储管理；有段表做地址映射的变换属于基本分段存储管理。  
(2) 按图中逻辑地址（页号/段号为 $2$，页内地址/段内地址为 $100$，页大小/块大小为 $1\text{ KB}$）：

- 页式物理地址：$6 \times 1024 + 100 = 6244$；
- 段式物理地址：$6 \times 1024 + 100 = 6244$。

**解题切入点**：
分页和分段本质上都是“一次映射”：分页用页表把页号映射到物理块号，再拼接页内偏移；分段用段表把段号映射到段基址，再做一次加法。可以类比算法竞赛里的查表函数：分页是 `frame = page_table[page]; return concat(frame, offset);`，分段是 `base = seg_table[seg]; return base + offset;`。段表无段长信息，相当于把 `if (offset >= limit) return ERROR;` 这句越界检查注释掉了。

**推演**：
页式变换：

$$ \text{PA}_{\text{页式}} = \text{块号} \times \text{页大小} + \text{页内地址} $$

图中页号 $2$ 对应块号 $6$，页大小为 $1024\text{ B}$，页内地址为 $100$：

$$ \text{PA}_{\text{页式}} = 6 \times 1024 + 100 = 6244 $$

段式变换：

$$ \text{PA}_{\text{段式}} = \text{段基址} + \text{段内地址} $$

图中段号 $2$ 对应段基址 $6\text{ KB}$，段内地址为 $100$，且不进行段长越界检查：

$$ \text{PA}_{\text{段式}} = 6 \times 1024 + 100 = 6244 $$

**易错点**：
- 分页的物理地址不是把“块号”和“页内地址”直接当十进制拼接，而是“块号 $\times$ 页大小 $+$ 页内地址”。
- 分段是基址相加，分页是块号换掉页号；两者形式上有时算出的数相同，但含义不同。
- 题目明确说段式不检查段长，因此不能自行补一个“段长越界”判断并报错。
- 注意单位换算：$1\text{ KB} = 1024\text{ B}$，不要按 $1000$ 算。

**命题规律**：
408 常把地址变换做成“给图查表计算”的小综合题，本质是状态映射：逻辑地址的高位是下标，低位是偏移。像算法竞赛里先定义好 `mp[high]` 映射关系，再按题意输出即可。遇到分页就做“替换高位”，遇到分段就做“基址加偏移”；若以后题目给段长，则要先判断偏移是否越界，再决定是继续计算还是触发越界中断。

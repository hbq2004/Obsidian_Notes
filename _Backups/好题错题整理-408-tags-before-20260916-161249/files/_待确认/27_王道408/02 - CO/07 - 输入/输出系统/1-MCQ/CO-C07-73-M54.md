# 选择题 第 54 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M54_题目.png|题目]]

54.【2025统考真题】下列设备中，适合采用 $DMA$ 输入/输出方式的是（  ）.

$I$. 键盘  
$II$. 网卡  
$III$. 固态硬盘  
$IV$. 针式打印机  

A. 仅 $I$、$II$  
B. 仅 $II$、$III$  
C. 仅 $II$、$IV$  
D. 仅 $III$、$IV$

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M54_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：$\mathrm{B}$（仅 $\mathrm{II}$、$\mathrm{III}$）。网卡和固态硬盘都是高速、以数据包/数据块为单位进行大批量数据交换的设备，适合用 $\mathrm{DMA}$；键盘和针式打印机是低速字符设备，用中断/程序查询方式即可。

**解题切入点**：拿到题先不着急逐个判断，而要先抓住 $\mathrm{DMA}$ 的适用场景：高速、大批量、以块（包）为单位传送，CPU 只在传送前初始化和传送后做结束处理。然后把设备分类：键盘、针式打印机每次数据量小且速度慢，适合中断；网卡、固态硬盘数据量大且速度快，必须用 $\mathrm{DMA}$ 减少 CPU 负担。就像算法竞赛中“数据量大才用批量快读，手敲单字符不需要”。

**推演**：

1. $\mathrm{DMA}$ 方式的核心特点：CPU 先设置 $\mathrm{DMA}$ 控制器，包括主存首地址、传送长度、传送方向和设备地址；随后设备与主存之间由 $\mathrm{DMA}$ 控制器直接搬运数据，传送结束后才向 CPU 发出中断请求。因此 $\mathrm{DMA}$ 特别适合高速块设备，而不适合每次只有几个字节的低速字符设备。

2. 逐项分析：

   - 键盘：产生的是单个键码，数据量只有 $1\sim 2$ 个字节，且按键速率很低。用中断方式即可满足要求；若用 $\mathrm{DMA}$，为几个字节初始化一次 DMA 控制器，开销远大于收益，故 $\mathrm{I}$ 不适合。
   - 网卡：网络数据以帧/包为单位连续到达，速率可达 Gb/s 量级。现代网卡普遍通过 $\mathrm{DMA}$ 将收到的数据包直接写入内存，或将待发送数据从内存读出到网卡，故 $\mathrm{II}$ 适合。
   - 固态硬盘：属于高速块设备，读写单位是页/块，传输速率很高。其控制器与主存之间往往也使用 $\mathrm{DMA}$ 进行数据搬运，故 $\mathrm{III}$ 适合。
   - 针式打印机：机械打印速度低，一次传送的是字符或打印行，不是高速连续的大数据流。通常用中断方式逐字符/逐行输出，用 $\mathrm{DMA}$ 没有必要，故 $\mathrm{IV}$ 不适合。

3. 因此适合采用 $\mathrm{DMA}$ 的是 $\mathrm{II}$ 和 $\mathrm{III}$，选 $\mathrm{B}$。

**易错点**：

- 误选 $\mathrm{D}$：只记得“磁盘类设备适合 DMA”，漏掉网卡，又误把打印机当块设备。纠正：判断标准不是“是不是外存”，而是数据量、速度和传送单位。
- 误选 $\mathrm{C}$：知道网卡适合 $\mathrm{DMA}$，但把固态硬盘排除或把打印机纳入。固态硬盘显然属于高速块设备，打印机不是。
- 把“键盘需要及时响应”误认为“速度高”。键盘的及时性靠中断优先级保证，与 $\mathrm{DMA}$ 无关。
- 认为“任何设备都能用 DMA”。实际上，对于每次只有少量数据的字符设备，频繁初始化 DMA 控制器的开销甚至大于中断方式，因而不适合。

**命题规律**：考点是 $\mathrm{I/O}$ 方式的选用与对比，重点是 DMA 与中断的适用对象。常见变式有：给出具体设备判断适合哪种 I/O 方式；考查 DMA 传输前 CPU 的初始化工作；比较 DMA 与中断在响应过程、数据传送路径、CPU 介入程度上的区别。复习时应建立“设备速度/数据单位 → I/O 方式”的对应表：键盘、鼠标、打印机等低速字符设备用中断；磁盘、SSD、网卡等高速设备用 DMA。同时要熟记 DMA 流程：CPU 初始化 $\rightarrow$ DMA 控制器传送数据 $\rightarrow$ 传送结束发中断。

# 选择题 第 6 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-72-M06_题目.png|题目]]

6. 下列关于 $I/O$ 指令的说法中,错误的是（  ）

A. $I/O$ 指令是 $CPU$ 系统指令的一部分

B. $I/O$ 指令是机器指令的一类

C. $I/O$ 指令反映 $CPU$ 和 $I/O$ 设备交换信息的特点

D. $I/O$ 指令的格式和通用指令的格式相同

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-72-M06_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。  
I/O 指令是 CPU 指令系统（机器指令）中的一类，用于 CPU 与 I/O 设备交换信息；但其格式通常包含操作码、命令码、设备码等特殊字段，与通用指令格式并不相同，因此 D 错误。

**解题切入点**：先判断题干中的“I/O 指令”指的是哪种指令。在计算机组成原理中，讲到“I/O 指令”时，通常指专门的机器指令，用于启动、控制、测试 I/O 设备。此时应围绕“I/O 指令的格式特点”和“I/O 指令与通用指令的关系”来辨析选项。这种题就像辨认接口协议：功能相同，但报文格式可能不同，不能想当然认为“都是指令，所以格式一样”。

**推演**：  
1. CPU 的指令系统按功能可分为：运算指令、传送指令、控制指令、I/O 指令等。因此 I/O 指令属于 CPU 指令系统的一部分，故 A 正确。  
2. I/O 指令能被 CPU 直接识别和执行，是机器指令的一类，故 B 正确。  
3. I/O 指令的功能就是实现 CPU 与 I/O 设备之间的信息交换，包括启动设备、传送数据、读取状态等，故 C 正确。  
4. 专门 I/O 指令的格式一般需要包含：操作码、命令码（如读、写、控制）、设备码（用于选择具体 I/O 设备）等。而通用指令格式通常只包含操作码和地址码（或操作数本身），目的是进行运算或访存。若 I/O 指令格式与通用指令完全相同，就无法区分“访存地址”和“设备号”，也无法表达不同的 I/O 操作命令。因此 D 错误。  
5. 需要注意：如果采用统一编址（存储器映射 I/O），则访问 I/O 设备可以直接使用访存类通用指令，此时不存在专门的 I/O 指令。但本题讨论的是“I/O 指令”，说明系统采用独立编址方式，存在专门的 I/O 指令，其格式与通用指令不同。

**易错点**：  
- 误选 A：以为 I/O 指令不属于 CPU 系统指令。实际上 CPU 指令系统包含 I/O 指令。  
- 误选 B：把“机器指令”和“广义指令”混淆。I/O 指令是硬件直接执行的机器指令，不是操作系统提供的广义指令。  
- 误选 C：认为 I/O 指令只反映数据传送，忽略了状态测试和启动控制等功能。但 C 的说法是宏观正确的。  
- 最易错的是 D：在统一编址方式下，I/O 操作确实可以用通用访存指令完成，于是认为“I/O 指令格式和通用指令相同”。但本题明确说的是专门的“I/O 指令”，此时格式必然与通用指令不同。解答时要注意题目给定的语境。

**命题规律**：本题属于 I/O 方式与 I/O 指令的基础概念题。考查角度通常是：  
- I/O 指令的组成（操作码、命令码、设备码）；  
- I/O 编址方式（独立编址与统一编址）对指令格式的影响；  
- I/O 指令与通用指令的区别。  

复习时，应重点掌握“独立编址下专门的 I/O 指令”和“统一编址下使用访存指令代替 I/O 指令”这两种模型的区别，并明确各类指令在指令系统中的地位。变式可能给出某机型 I/O 指令格式，要求写出设备码位数、可支持设备数量等，需要熟悉指令格式的位段含义。

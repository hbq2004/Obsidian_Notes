# 选择题 第 1 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-71-M01_题目.png|题目]]

1.在微型机系统中，$I/O$ 设备通过（ ）与主板的系统总线相连接.

A. $DMA$ 控制器  
B. 设备控制器  
C. 中断控制器  
D. $I/O$ 端口

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-71-M01_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B（设备控制器）。  
理由：I/O 设备与主板系统总线之间不能直接相连，必须通过设备控制器（即 I/O 接口/适配器）完成信号转换、时序匹配和数据缓冲。

**解题切入点**：  
拿到题目先抓“设备”和“系统总线”之间的中间层。系统总线的速度、电平、数据格式相对统一，而外设种类繁杂，CPU 不能直接控制每一种外设。这就像算法竞赛中把底层实现封装成统一接口：设备控制器就是一个“适配器”，把各种外设的差异屏蔽掉，向上只暴露可读写的寄存器和端口。

**推演**：  
1. 微型机中，CPU、内存通过系统总线连接，但外设不是直接挂在系统总线上。外设的机械结构、电气特性和数据格式与总线差异很大，需要在二者之间加入设备控制器。  

2. 设备控制器在数据通路中的位置：
$$
\text{CPU} \longleftrightarrow \text{系统总线} \longleftrightarrow \text{设备控制器} \longleftrightarrow \text{I/O 设备}
$$

3. 设备控制器的工作方式：CPU 通过地址总线选中设备控制器中的某个 I/O 端口，控制总线发出读写命令，数据总线负责传输数据；设备控制器再根据命令产生相应的控制时序驱动外部设备。

4. 选项分析：
- A：DMA 控制器用于高速块设备与主存之间直接传输数据，是一种总线主设备，但它不是所有 I/O 设备连接总线的通用中间部件。
- B：设备控制器正确，它本身就是 I/O 接口，负责 CPU 与外设之间的信息交换。
- C：中断控制器只负责中断请求的收集、判优和转发，不承担设备与系统总线之间的数据连接。
- D：I/O 端口是设备控制器内部可编址的寄存器，是 CPU 访问设备的“窗口”，而不是连接设备与总线的部件。

因此正确选项是 B。

**易错点**：  
- 容易误选 D“I/O 端口”。I/O 端口只是设备控制器中的寄存器或其地址，CPU 通过端口访问设备，但端口本身不是连接设备与总线的实体部件。  
- 容易误选 A“DMA 控制器”。DMA 控制器用于高速数据传输，不是所有 I/O 设备的通用连接层；设备通常先通过设备控制器接入总线，再配合 DMA 控制器进行数据传送。  
- 容易误选 C“中断控制器”。中断控制器只处理中断信号通路，不是设备与系统总线之间的数据/控制通路。  
- 规避方法：记住层次结构“外设—设备控制器—系统总线—CPU”，并且区分“控制器、端口、DMA、中断”四个概念的不同职责。

**命题规律**：  
本题属于 I/O 系统的基础概念题，常考“I/O 设备通过什么与总线相连”“设备控制器的作用”“I/O 端口编址”等。变式还可能考查：  
- 设备控制器与 I/O 端口的关系；  
- 统一编址和独立编址的区别；  
- 中断控制器和 DMA 控制器在 I/O 方式中的作用。  

复习时应把“设备控制器、I/O 端口、中断控制器、DMA 控制器”放在一起对比记忆，并结合程序查询方式、中断方式和 DMA 方式理解各自的使用场景。

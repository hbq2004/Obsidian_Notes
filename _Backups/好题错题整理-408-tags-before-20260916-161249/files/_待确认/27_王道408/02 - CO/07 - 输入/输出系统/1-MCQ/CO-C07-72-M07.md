# 选择题 第 7 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-72-M07_题目.png|题目]]

7. 下列叙述中,正确的是（ ）.

(A) 只有 $I/O$ 指令可以访问 $I/O$ 设备
(B) 在统一编址下,不能直接访问 $I/O$ 设备
(C) 访问存储器的指令一定不能访问 $I/O$ 设备
(D) 只有在具有专门 $I/O$ 指令的计算机中,$I/O$ 设备才可以单独编址

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-72-M07_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。理由：I/O 设备单独编址（独立编址）时，其端口地址空间与存储器地址空间分开，需要专门的 I/O 指令来访问；而统一编址时无需专门 I/O 指令，直接用访存指令即可访问 I/O 设备。

**解题切入点**：拿到题目先锁定考点——I/O 设备的编址方式。可以把两种编址方式类比为“两本独立的电话簿”和“一本合并的电话簿”：独立编址需要特制的“I/O 专用拨号器”（专门 I/O 指令），统一编址则用普通“访存拨号器”就能打给设备。逐项对照两种方式的基本特征即可判断。

**推演**：

1. 明确两种编址方式：  
   - 统一编址：I/O 端口与存储器单元共同使用同一个地址空间，访问 I/O 设备等同于访问存储器单元，因此**普通访存指令可以直接访问 I/O 设备**。  
   - 独立编址：I/O 端口拥有独立的地址空间，与存储器地址空间不重叠，CPU 必须通过**专门的 I/O 指令**（如 IN/OUT）来访问 I/O 设备。

2. 逐项分析：

   - **(A) 只有 I/O 指令可以访问 I/O 设备**  
     错误。只有在独立编址方式下才必须用专门 I/O 指令；在统一编址方式下，访存指令也能访问 I/O 设备，所以“只有”过于绝对。

   - **(B) 在统一编址下，不能直接访问 I/O 设备**  
     错误。统一编址的实质就是允许用访存指令直接访问 I/O 设备，因此“不能直接访问”与定义矛盾。

   - **(C) 访问存储器的指令一定不能访问 I/O 设备**  
     错误。在统一编址下，I/O 设备端口被映射到存储器地址空间，访存指令访问到相应地址时，实际访问的正是 I/O 设备。因此“一定不能”不成立。

   - **(D) 只有在具有专门 I/O 指令的计算机中，I/O 设备才可以单独编址**  
     正确。单独编址（独立编址）的地址空间独立于存储器，必然需要专门的 I/O 指令来区分当前访问的是存储器还是 I/O 端口。因此，若 I/O 设备单独编址，则该计算机一定配有专门 I/O 指令。

3. 结论：正确选项为 D。

**易错点**：  
- 常见错误：误选 A，把“独立编址需要专门 I/O 指令”推广成“所有计算机都只能用 I/O 指令访问设备”，忽略了统一编址方式。  
- 误选 B 或 C，是因为没有真正理解统一编址：统一编址下 I/O 设备占用存储器地址，访存指令完全可以访问它们。  
- 规避方法：熟记两种编址方式的“地址空间是否独立”和“使用指令是否专门”两个核心区别，做题时先判断题目所述是哪种编址方式，再逐一排除绝对化表述。

**命题规律**：  
- 考点定位：I/O 设备的编址方式（统一编址 vs 独立编址）是计算机组成原理中 I/O 系统的常考基础知识点。  
- 常见变式：  
  1. 给出某种编址方式，判断是否能使用访存指令或专门 I/O 指令；  
  2. 比较两种编址方式的优缺点；  
  3. 结合具体指令（如 x86 的 IN/OUT）考查独立编址。  
- 复习建议：将统一编址与独立编址对照记忆，理解各自对指令系统、地址空间和硬件设计的影响；注意“统一编址”也称“存储器映射 I/O”，“独立编址”也称“I/O 映射 I/O”。掌握本质后可快速应对选择题和简答题。

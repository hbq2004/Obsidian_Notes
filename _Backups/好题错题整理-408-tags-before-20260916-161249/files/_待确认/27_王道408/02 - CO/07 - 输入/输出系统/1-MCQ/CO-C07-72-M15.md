# 选择题 第 15 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-72-M15_题目.png|题目]]

15.【2014统考真题】下列有关 $I/O$ 接口的叙述中,错误的是（ ）.

A. 状态端口和控制端口可以合用同一个寄存器  
B. $I/O$ 接口中 $CPU$ 可访问的寄存器称为 $I/O$ 端口  
C. 采用独立编址方式时,$I/O$ 端口地址和主存地址可能相同  
D. 采用统一编址方式时,$CPU$ 不能用访存指令访问 $I/O$ 端口

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-72-M15_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。采用统一编址时，I/O 端口被映射到主存地址空间中，CPU 可以使用访存指令访问 I/O 端口，D 说反了。

**解题切入点**：  
先抓住“错误的是”这个要求，再把选项定位到两个基本概念：I/O 端口是什么、两种 I/O 编址方式有何区别。可以这样类比：独立编址相当于内存和 I/O 各有一本“地址簿”，门牌号可以重复，但门口挂不同的锁，要用专用钥匙；统一编址则把 I/O 设备地址也写进内存地址簿，直接用普通访存指令即可。选项 D 正好与统一编址的定义相反。

**推演**：  
逐项判断：

- A 正确：I/O 接口中常见“控制/状态寄存器”。读取它时得到设备状态，写入它时发出控制命令，因此状态端口和控制端口可以合用同一个寄存器：
  $$
  \text{读同一寄存器} \rightarrow \text{获取状态};\qquad
  \text{写同一寄存器} \rightarrow \text{发送控制命令}.
  $$

- B 正确：按定义，I/O 接口中 CPU 可直接访问的寄存器称为 I/O 端口，包括数据端口、状态端口、控制端口等。CPU 通过端口地址区分它们。

- C 正确：独立编址时，主存空间和 I/O 端口地址空间是相互独立的两套地址空间。CPU 通过控制信号（如 $\overline{M/IO}$）区分当前访问的是主存还是 I/O 端口，因此 I/O 端口地址和主存地址在数值上可能相同，例如：
  $$
  \text{主存地址 }0\times2000 \quad\text{与}\quad \text{I/O 端口地址 }0\times2000
  $$
  可以由不同控制信号区分。

- D 错误：统一编址也叫存储器映射 I/O，I/O 端口地址是主存地址空间的一部分。CPU 访问 I/O 端口时，使用的正是 Load/Store 等普通访存指令，因此不能说“不能用访存指令访问”。

所以错误项是 D。

**易错点**：  
1. 把两种编址方式记反：独立编址才用专用 I/O 指令，统一编址用访存指令。  
2. 误以为独立编址下 I/O 地址与主存地址绝对不能相同；实际上地址数值可以重叠，靠控制信号区分。  
3. 误以为“状态端口和控制端口必须分开”；实际可用同一个控制/状态寄存器，读为状态、写为控制。  
4. 把 I/O 端口理解为接口外部的物理引脚；I/O 端口是接口中 CPU 可访问的寄存器或寄存器地址。

**命题规律**：  
本题是 I/O 系统的基础概念题，考点集中在“I/O 端口定义”和“两种编址方式”上。常见变式有：判断某 CPU 使用访存指令还是 IN/OUT 指令；比较统一编址和独立编址的优缺点；判断 I/O 端口地址与主存地址能否重叠。复习时建议把两种编址方式做成对照表：独立编址用专用 I/O 指令、地址空间分离、地址可重叠；统一编址用访存指令、I/O 端口占用主存地址空间。

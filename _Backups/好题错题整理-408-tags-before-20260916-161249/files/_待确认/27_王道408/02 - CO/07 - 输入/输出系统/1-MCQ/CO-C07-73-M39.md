# 选择题 第 39 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M39_题目.png|题目]]

39.【2014统考真题】若某设备中断请求的响应和处理时间为 $100ns$，每 $400ns$ 发出一次中断请求，中断响应所允许的最长延迟时间为 $50ns$，则在该设备持续工作过程中，$CPU$ 用于该设备的 $I/O$ 时间占整个 $CPU$ 时间的百分比至少是（ ）

(A) 12.5%  
(B) 25%  
(C) 37.5%  
(D) 50%

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M39_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。设备每 $400\text{ ns}$ 请求一次，每次中断响应与处理需 $100\text{ ns}$ CPU 时间，因此最少占比为 $100/400=25\%$；$50\text{ ns}$ 的最长响应延迟不是额外 CPU 开销。

**解题切入点**：先把它看成一个“周期任务”问题：请求周期 $T=400\text{ ns}$，每次服务时间 $C=100\text{ ns}$。求 CPU 占用率就是 $C/T$。不要被“最长延迟 $50\text{ ns}$”干扰，它只约束响应不能太晚，并不代表 CPU 一定要为此工作 $50\text{ ns}$。

**推演**：

设备持续工作时，每 $400\text{ ns}$ 产生一次中断请求，因此平均每秒中断次数为

$$
\frac{1}{400\text{ ns}}=\frac{1}{400\times 10^{-9}}=2.5\times 10^6
$$

每次中断请求的响应与处理需要 CPU 服务时间为

$$
100\text{ ns}=100\times 10^{-9}\text{ s}
$$

所以每秒 CPU 用于该设备 I/O 的时间为

$$
2.5\times 10^6 \times 100\times 10^{-9}=0.25\text{ s}
$$

因此 CPU 用于该设备 I/O 的时间占整个 CPU 时间的百分比至少为

$$
\frac{0.25}{1}\times 100\%=25\%
$$

等价地看，每 $400\text{ ns}$ 中至少要拿出 $100\text{ ns}$ 处理该设备的中断：

$$
\frac{100}{400}\times 100\%=25\%
$$

“中断响应所允许的最长延迟时间为 $50\text{ ns}$”表示 CPU 最多可以推迟 $50\text{ ns}$ 再响应，但这 $50\text{ ns}$ 内 CPU 仍可执行其他任务，并不计入该设备的 I/O 时间。即使最晚响应，处理结束也在请求后 $50+100=150\text{ ns}$ 处，仍远小于下一次请求间隔 $400\text{ ns}$，不会导致一个周期内需要处理多次。

**易错点**：

- 容易把 $50\text{ ns}$ 也计入 CPU 用于 I/O 的时间，误算为

$$
\frac{100+50}{400}\times 100\%=37.5\%
$$

从而错选 C。实际上最长延迟是允许 CPU“拖延”的时间，拖延期间 CPU 不一定在处理该设备。

- 容易混淆“响应和处理时间”与“允许延迟时间”：前者是 CPU 实际服务时间，后者是响应时限，不能相加。

- 单位换算容易出错：$400\text{ ns}=4\times10^{-7}\text{ s}$，$100\text{ ns}=1\times10^{-7}\text{ s}$，计算每秒中断次数时要正确换算。

**命题规律**：本题考的是中断驱动 I/O 方式下 CPU 的 I/O 时间占比，本质上就是“周期任务利用率”问题：

$$
U=\frac{\text{每次中断处理时间}}{\text{中断请求周期}}
$$

常见变式有：

- 给出中断处理时间和请求频率，求 CPU 开销率；
- 给出允许的 CPU 开销上限，反推中断请求频率或最大处理时间；
- 与 DMA 方式对比，DMA 只在传输前设置和传输后中断时占用 CPU，CPU 占用率远低于逐次中断方式。

复习建议：牢记公式“CPU 开销率 = 每秒中断次数 × 每次中断处理时间”；做题时先找“周期”和“单次服务时间”，区分“允许延迟”和“处理时间”两个概念。

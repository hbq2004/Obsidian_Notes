# 选择题 第 16 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-72-M16_题目.png|题目]]

16.【2017统考真题】$I/O$指令实现的数据传送通常发生在( )
A. $I/O$设备和$I/O$端口之间
B. 通用寄存器和$I/O$设备之间
C. $I/O$端口和$I/O$端口之间
D. 通用寄存器和$I/O$端口之间

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-72-M16_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。$I/O$ 指令（如 `IN`/`OUT`）直接完成 CPU 通用寄存器与 $I/O$ 端口之间的数据传送，故正确选项为 D。

**解题切入点**：抓住 $I/O$ 指令的执行主体是 CPU，其操作对象是 $I/O$ 端口（而非设备本身）。可以类比为 CPU 通过指令直接读写一个“接口寄存器”，而设备与端口之间的数据交换则由硬件自动完成。

**推演**：  
$I/O$ 指令是 CPU 专门用于输入/输出的指令，常见于独立编址方式（如 x86 的 `IN`/`OUT`）。其执行过程为：  
- CPU 将 $I/O$ 端口地址放在地址总线上，通过控制总线发出读/写命令。  
- 数据总线连接 CPU 通用寄存器（如 AX、AL）和 $I/O$ 端口。  
- 传送方向：  
  - 输入：$I/O$ 端口 $\rightarrow$ 通用寄存器；  
  - 输出：通用寄存器 $\rightarrow$ $I/O$ 端口。  
因此，$I/O$ 指令实现的数据传送发生在 **通用寄存器和 $I/O$ 端口之间**。  
$I/O$ 设备与 $I/O$ 端口之间的数据交换由设备控制器（硬件）完成，不依赖 $I/O$ 指令。$I/O$ 端口与 $I/O$ 端口之间没有直接数据通路。故 A、B、C 均错误。

**易错点**：  
- 误选 A（$I/O$ 设备和 $I/O$ 端口之间）：认为 $I/O$ 指令直接控制设备，实际上设备与端口间的数据传送是硬件自动完成的，$I/O$ 指令只负责与端口交互。  
- 误选 B（通用寄存器和 $I/O$ 设备之间）：$I/O$ 指令无法直接访问设备，只能通过端口地址间接操作。  
- 混淆 $I/O$ 端口与 $I/O$ 接口：端口是接口中可被 CPU 访问的寄存器，$I/O$ 指令只与端口打交道。

**命题规律**：  
- 考点：$I/O$ 指令的功能与数据传送路径，常结合 $I/O$ 编址方式（独立编址 vs 统一编址）考查。  
- 变式：可能问 $I/O$ 指令在哪种 $I/O$ 方式中使用（程序直接控制、中断驱动），或与 DMA 指令对比。  
- 复习建议：理解 $I/O$ 接口的结构，明确 CPU 通过 $I/O$ 指令只与端口交换数据，设备与端口间的数据传送由硬件控制。同时注意区分 $I/O$ 指令与 DMA 传送的区别。

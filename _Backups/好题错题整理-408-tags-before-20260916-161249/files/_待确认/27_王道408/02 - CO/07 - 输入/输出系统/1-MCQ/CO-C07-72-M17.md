# 选择题 第 17 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-72-M17_题目.png|题目]]

17.【2021统考真题】下列选项中，不属于 $I/O$ 接口的是（  ）

A. 磁盘驱动器
B. 打印机适配器
C. 网络控制器
D. 可编程中断控制器

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-72-M17_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A。磁盘驱动器属于外部设备（$I/O$设备），不是主机与外设之间的接口电路；打印机适配器、网络控制器、可编程中断控制器均属于$I/O$接口（或接口芯片）。

**解题切入点**：  
题目考的是“设备 vs 接口”的边界。做题先问：这个选项是把外设本身拿来，还是把连接外设的电路/适配器/控制器拿来？就像 USB 接口和 U 盘：U 盘是设备，USB 接口/主控电路才是接口。

**推演**：  
$I/O$接口是主机与$I/O$设备之间传送数据、控制信息、状态信息的逻辑电路/部件，常称为适配器或设备控制器。它完成地址译码、数据缓冲、格式与电平转换、状态/命令寄存等功能；而$I/O$设备是具体的外部设备，如键盘、显示器、磁盘驱动器、打印机等。

逐项看：

- A 磁盘驱动器：包括盘片、电机、磁头等，是可执行读写操作的存储设备，显然属于$I/O$设备，而不是接口。它的接口部分是磁盘适配器/磁盘控制器。
- B 打印机适配器：它是连接打印机与主机的适配电路，属于$I/O$接口，负责数据转换与传输控制。
- C 网络控制器：即网卡/网络适配器，完成主机与网络介质之间的数据收发、协议处理等工作，也属于$I/O$接口。
- D 可编程中断控制器：如 8259A，是管理多个中断请求源并协助 CPU 响应中断的接口芯片，属于$I/O$接口（系统接口逻辑），不是外设。

因此唯一不属于$I/O$接口的是 A。

**易错点**：  
1. 把“磁盘驱动器”误认为接口，因为它与主机交互频繁；但驱动器是设备，磁盘控制器/适配器才是接口。  
2. 把“网络控制器”误认为不属于接口，其实网络控制器就是网络适配器（网卡），是 $I/O$ 接口。  
3. 把“可编程中断控制器”误认为不属于接口，其实它是 $I/O$ 接口芯片，负责中断请求的汇集与优先级管理等。  
4. 记不住“适配器、控制器、接口”三者常混用：做题时不要把“控制器”只看作 CPU 内部部件，设备控制器正是 $I/O$ 接口的实现形式。

**命题规律**：  
考点是 $I/O$ 接口的层次与作用。常见变式：给出具体外设（磁盘、打印机、显示器）判断哪个不是接口，或给出接口芯片（如 8255A、8251A、8259A、8237A）判断其类型；也可能结合中断、DMA 问接口功能。复习时牢记：接口=电路部件，设备=机电装置；并熟悉常见接口芯片和适配器的归属。

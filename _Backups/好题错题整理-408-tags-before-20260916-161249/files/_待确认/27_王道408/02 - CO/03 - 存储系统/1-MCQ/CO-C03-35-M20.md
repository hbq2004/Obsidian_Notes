# 选择题 第 20 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-35-M20_题目.png|题目]]

20. 某计算机的 $Cache$ 有 16 行,块大小为 $16B$,其映射方式可配置为直接映射或 2 路组相联映射,主存按字节编址,主存单元从 0 开始编号。若依次访问下列主存单元,则不论采取上述哪种映射方式都可能引起 $Cache$ 冲突的是（ ）

A. 52 号和 102 号单元

B. 48 号和 308 号单元

C. 60 号和 160 号单元

D. 46 号和 236 号单元

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-35-M20_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B，因为只有选项 B 的两个地址在直接映射下映射到同一 Cache 行，且在 2 路组相联下映射到同一组，从而两种映射方式下都可能发生冲突。

**解题切入点**：首先明确 Cache 映射方式的核心是地址到 Cache 位置的映射规则。直接映射中，行号由块号模行数决定；组相联中，组号由块号模组数决定。本题的关键是计算每个地址的块号（地址除以块大小），然后分别求模 16（行数）和模 8（组数），找出在两种映射下都映射到相同位置（行或组）的地址对。这类似于在哈希表中判断两个键是否映射到同一个桶，桶数不同但存在包含关系。

**推演**：
- Cache 参数：16 行，块大小 $16\mathrm{B}$，主存按字节编址。
- 块号 $B = \lfloor \text{地址} / 16 \rfloor$（整数除法）。
- 直接映射行号 $L = B \bmod 16$。
- 2 路组相联：组数 $= 16 / 2 = 8$，组号 $G = B \bmod 8$。

计算各选项的块号和映射位置：

| 选项 | 地址 | 块号 $B$ | $L = B \bmod 16$ | $G = B \bmod 8$ |
|------|------|----------|------------------|-----------------|
| A    | 52   | $3$      | $3$              | $3$             |
|      | 102  | $6$      | $6$              | $6$             |
| B    | 48   | $3$      | $3$              | $3$             |
|      | 308  | $19$     | $3$              | $3$             |
| C    | 60   | $3$      | $3$              | $3$             |
|      | 160  | $10$     | $10$             | $2$             |
| D    | 46   | $2$      | $2$              | $2$             |
|      | 236  | $14$     | $14$             | $6$             |

- 在直接映射下，只有选项 B 的两地址行号相同（$3$），其余选项行号均不同。
- 在 2 路组相联下，选项 B 的两地址组号相同（$3$），其余选项组号不同。
- 由于直接映射行号相同等价于组号相同（因为 $16$ 是 $8$ 的倍数），故选项 B 是唯一在两种映射下都映射到同一 Cache 位置（直接映射同一行，组相联同一组）的地址对。因此，无论采用哪种映射方式，这两个地址都可能引起 Cache 冲突（直接映射必然冲突，组相联下因组内只有两行而可能冲突）。

**易错点**：
1. 混淆块号计算：直接使用地址模块大小得到块内偏移，而非块号。正确做法是地址除以块大小取整。
2. 忽视组相联中组数计算：行数除以路数得组数，此处为 $16/2=8$。
3. 误认为直接映射冲突的地址对在组相联下一定不冲突：实际上，直接映射冲突意味着块号模 16 相等，则模 8 必相等，故组相联下也映射到同一组，但组内多行可缓解冲突。本题中只有两个地址，组相联下不会发生替换，但题目问的是“可能引起”，即存在冲突的可能性（如组内已有其他数据），故 B 仍为正确选项。

**命题规律**：考察 Cache 映射方式的基本计算与冲突判断，常见于选择题。核心是理解地址到 Cache 位置的映射公式，并能在不同映射方式间灵活转换。变式可能包括：改变 Cache 行数、块大小、路数，或要求判断哪些地址对在特定映射下必然冲突。复习建议：熟练掌握直接映射、组相联、全相联的地址结构划分（标记、组号/行号、块内偏移），并通过大量练习强化计算能力。

# 综合题 第 5 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-35-F05_题目.png|题目]]

5. 【2013统考真题】某32位计算机，$CPU$主频为800MHz，$Cache$命中时的$CPI$为4，$Cache$块大小为32B；主存采用8体交叉存储方式，每个体的存储字长为32位、存储周期为40ns；存储器总线宽度为32位，总线时钟频率为200MHz，支持突发传送总线事务。每次读突发传送总线事务的过程包括：传送首地址和命令、存储器准备数据、传送数据。每次突发传送32B，传送地址或32位数据均需要一个总线时钟周期。请回答下列问题，要求给出理由或计算过程。

(1)$CPU$和总线的时钟周期各为多少？总线的带宽（即最大数据传输速率）为多少？
(2)$Cache$缺失时，需要用几个读突发传送总线事务来完成一个主存块的读取？
(3)存储器总线完成一次读突发传送总线事务所需的时间是多少？
(4)若程序$BP$执行过程中共执行了100条指令，平均每条指令需进行1.2次访存，$Cache$缺失率为5%，不考虑替换等开销，则$BP$的$CPU$执行时间是多少？

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-35-F05_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：(1) CPU时钟周期 $1.25\,\text{ns}$，总线时钟周期 $5\,\text{ns}$，总线带宽 $800\,\text{MB/s}$；(2) 需要 $1$ 个读突发传送总线事务；(3) 完成一次读突发传送总线事务需 $85\,\text{ns}$（或 $17$ 个总线时钟周期）；(4) BP 的 CPU 执行时间为 $1010\,\text{ns}$（或 $1.01\,\mu\text{s}$）。

**解题切入点**：首先抓住 CPU 主频与总线频率求时钟周期，再根据总线宽度计算带宽；然后分析 Cache 块大小与突发传送数据量的关系确定事务个数；接着根据突发传送三个阶段的时间和主存特性（8 体交叉、存储周期）计算事务时间；最后利用 CPI 公式和缺失率计算 CPU 执行时间，注意每条指令平均访存次数。关键是将不同部件的时间统一到 CPU 时钟周期或纳秒。

**推演**：

(1) CPU 主频为 $800\,\text{MHz}$，故 CPU 时钟周期 $T_{CPU}=1/800\,\text{MHz}=1.25\,\text{ns}$。总线时钟频率为 $200\,\text{MHz}$，故总线时钟周期 $T_{bus}=1/200\,\text{MHz}=5\,\text{ns}$。总线宽度 $32$ 位，即 $4\,\text{B}$，因此总线最大数据传输速率（带宽）为 $4\,\text{B} \times 200\,\text{MHz}=800\,\text{MB/s}$。

(2) Cache 块大小为 $32\,\text{B}$，每次读突发传送总线事务恰好传送 $32\,\text{B}$，因此只需 $1$ 个事务即可完成一个主存块的读取。

(3) 一次读突发传送总线事务包括三个阶段：
- 传送首地址和命令：需 $1$ 个总线时钟周期，即 $5\,\text{ns}$。
- 存储器准备数据：主存采用 $8$ 体交叉，每个体存储周期 $40\,\text{ns}$，块大小为 $32\,\text{B}$（$8$ 个 $32$ 位字），可同时启动所有体，故准备数据时间为 $40\,\text{ns}$（即 $8$ 个总线时钟周期）。
- 传送数据：$32\,\text{B}$ 需传送 $8$ 次 $32$ 位数据，每次 $1$ 个总线时钟周期，故需 $8$ 个周期，即 $40\,\text{ns}$。
所以总时间 $=5\,\text{ns}+40\,\text{ns}+40\,\text{ns}=85\,\text{ns}$，或 $1+8+8=17$ 个总线时钟周期。

(4) 程序 BP 执行 $100$ 条指令，平均每条指令访存 $1.2$ 次，总访存次数 $=100 \times 1.2 = 120$ 次。Cache 缺失率 $5\%$，故缺失次数 $=120 \times 5\% = 6$ 次。每次缺失需一次读突发事务，耗时 $85\,\text{ns}$，缺失总开销 $=6 \times 85\,\text{ns}=510\,\text{ns}$。Cache 命中时 CPI $=4$，CPU 时钟周期 $1.25\,\text{ns}$，指令执行时间（忽略缺失）$=100 \times 4 \times 1.25\,\text{ns}=500\,\text{ns}$。因此 CPU 总执行时间 $=500\,\text{ns}+510\,\text{ns}=1010\,\text{ns}=1.01\,\mu\text{s}$。
另解：缺失代价 $=85\,\text{ns}/1.25\,\text{ns}=68$ 个 CPU 时钟周期，平均 CPI $=4+0.05\times 68\times1.2=4+4.08=8.08$，总时间 $=100\times8.08\times1.25\,\text{ns}=1010\,\text{ns}$，结果一致。

**易错点**：
1. 混淆 CPU 时钟周期与总线时钟周期，忘记单位换算。
2. 计算总线带宽时误用突发传送条件，带宽应直接由宽度与频率得出。
3. 误认为 8 体交叉需要多个事务，或认为块大小与突发传送不一致。
4. 准备数据时间误算为多存储周期之和（如 $40+7\times5=75\,\text{ns}$），应按并行启动处理。
5. 计算缺失次数时忽略平均每条指令访存次数，或缺失代价单位换算错误。
6. 忽略 CPI 已包含命中时间而重复计算。

**命题规律**：本题综合考查时钟周期、总线带宽、突发传送、交叉存储器、Cache 缺失开销及 CPU 执行时间计算，是存储器系统与总线性能分析的典型题。常见变式：改变块大小、交叉存储体数、总线宽度、CPI 基数、缺失率等。复习建议：熟练掌握基本公式，理解交叉存储器的存取时间（并行启动与流水线启动的区别），掌握平均访存时间公式 $T_{avg}=T_{hit}+\text{缺失率}\times\text{缺失代价}$，并注意将不同部件的时间单位统一。

# 选择题 第 15 题

15.【2012统考真题】 在内部排序过程中，对尚未确定最终位置的所有元素进行一遍处理称为一趟排序。下列排序算法中，每趟排序结束都至少能够确定一个元素最终位置的方法是( )。
$I$. 简单选择排序 $II$. 希尔排序 $III$. 快速排序 $IV$. 堆排序 $V$. 2路归并排序

A. 仅$I$、$III$、$IV$
B. 仅$I$、$III$、$V$
C. 仅$II$、$III$、$IV$
D. 仅$III$、$IV$、$V$

## DeepSeek V4 Flash Max 解析

**答案**：选 **A**，即仅 **$I$ 简单选择排序、$III$ 快速排序、$IV$ 堆排序** 满足“每趟排序结束都至少能够确定一个元素最终位置”。

**解题切入点**：  
拿到题目先抓关键词：“每趟排序后至少确定一个元素的最终位置”。这等价于判断每趟排序有没有“锁定”某个元素。可以这样类比：选择排序像每次从剩余元素中挑一个最小值放到最前面；快速排序像选一个“枢轴”把它放到全局该在的位置；堆排序像每次把当前最大值“拔”出来放到末尾。这些都有明确的“定位动作”。而希尔排序和归并排序只是让序列逐步“更有序”，元素位置还没有被锁定。

**推演**：  
判断标准：若某元素经过一趟后被放到全局有序序列中的第 $i$ 个位置，并且后续所有趟都不会再移动它，则说明它已确定最终位置。

1. **简单选择排序 $I$：满足。**  
   第 $i$ 趟从无序区 $A[i..n]$ 中选出最小值，交换到 $A[i]$。  
   因为它是剩余元素中的最小值，所以它就是全局第 $i$ 小的元素，$A[i]$ 的最终位置确定。  
   关键代码如下：
   ```cpp
   for (i = 1; i <= n - 1; i++) {
       k = 在 A[i..n] 中选最小值的下标;
       swap(A[i], A[k]);   // A[i] 最终位置确定
   }
   ```

2. **希尔排序 $II$：不满足。**  
   希尔排序第 $d$ 趟只保证“相距为 $d$”的组内元素有序，即只形成局部有序，不保证某个元素已经处于全局最终位置。后面更小的增量还会使元素大范围移动。  
   例如常见增量 $d=4$ 时，序列  
   $$[8,7,6,5,4,3,2,1]$$  
   一趟后变为  
   $$[4,3,2,1,8,7,6,5],$$  
   而最终有序序列是  
   $$[1,2,3,4,5,6,7,8],$$  
   可以逐位比较，没有任何元素已经处于最终位置。因此不满足“每趟至少确定一个”。

3. **快速排序 $III$：满足。**  
   一趟快速排序就是一次划分。设枢轴元素最后停在位置 $p$，则划分后满足  
   $$A[low..p-1] \le A[p] \le A[p+1..high]。$$  
   这说明枢轴左边的元素个数已经和最终有序时相同，因此 $A[p]$ 不会再被移动，位置 $p$ 就是枢轴的最终位置。  
   所以每趟划分至少确定一个元素的位置。

4. **堆排序 $IV$：满足。**  
   以大根堆为例，输出阶段每一趟做：
   ```cpp
   for (i = n; i >= 2; i--) {
       swap(A[1], A[i]);        // A[i] 最终位置确定
       SiftDown(A, 1, i - 1);   // 调整剩余堆
   }
   ```
   交换前堆顶是当前堆中的最大值，而 $A[i+1..n]$ 已经是排好的较大元素，所以交换后 $A[i]$ 正好位于全局第 $i$ 个位置，之后不再参与调整。  
   因此每趟堆排序都能确定一个元素的最终位置。

5. **2路归并排序 $V$：不满足。**  
   2路归并排序每趟只是把相邻的有序段两两合并，使有序段长度翻倍，但尚未形成全局有序序列，元素在后续归并中仍可能被移动。  
   例如  
   $$[4,3,2,1]$$  
   第一趟归并后得到  
   $$[3,4,1,2],$$  
   而最终有序序列是  
   $$[1,2,3,4],$$  
   第一趟结束后没有元素处于最终位置。因此不满足。

综上，满足条件的算法是 $I、III、IV$，答案选 **A**。

**易错点**：  
1. 误认为希尔排序能确定最终位置：希尔排序只是“按增量分组插入排序”，组内有序不等于全局位置确定。  
2. 误认为2路归并每趟后局部有序段中的元素已经就位：局部有序不代表全局最终位置锁定，合并会跨越原有序段移动元素。  
3. 快速排序中不要把“一趟划分”理解为左右区间也必须有序；一趟后只有枢轴一定就位。  
4. 堆排序中要注意：真正定位元素的是“交换堆顶与当前堆末并调整”的输出趟，不是初始建堆。初始建堆只是预处理。

**命题规律**：  
本题属于“排序算法过程特征”的经典选择题，常与“第几趟排序后的序列”“比较次数”“排序稳定性”等考点结合命题。常见变式有：  
- 问“哪些排序每趟都能确定至少一个元素的最终位置”；  
- 给出某趟之后的序列，判断可能属于哪种排序；  
- 问“2路归并排序需要 $\lceil\log_2 n\rceil$ 趟”“希尔排序最后一趟增量 $d=1$”等。  

复习时建议将排序算法按“每趟是否定位”分类记忆：  
- 每趟至少确定一个最终位置：简单选择排序、快速排序、堆排序、冒泡排序；  
- 每趟不一定确定最终位置：直接插入排序、希尔排序、2路归并排序等。

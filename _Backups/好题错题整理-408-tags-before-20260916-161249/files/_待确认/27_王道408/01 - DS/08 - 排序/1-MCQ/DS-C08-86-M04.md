# 选择题 第 4 题

![[_Attachments/题目识别/27_王道408-题目/DS-C08-86-M04_题目.png|题目]]

4. 下列排序算法中属于稳定排序的是 (①),平均时间复杂度为 $O(n\log_2 n)$ 的是 (②),在最好的情况下，时间复杂度可以达到线性时间的有 (③). (注：多选题)

$I$.冒泡排序 $II$.堆排序 $III$.选择排序 $IV$.直接插入排序
$V$.希尔排序 $VI$.归并排序 $VII$.快速排序

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C08-86-M04_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：①为 $I、IV、VI$（冒泡排序、直接插入排序、归并排序）；②为 $II、VI、VII$（堆排序、归并排序、快速排序）；③为 $I、IV$（冒泡排序、直接插入排序）。

**解题切入点**：拿到题目应先锁定考点——排序算法的“稳定性”和“时间复杂度”。这道题本质是排序特性对照题，不需要推演具体代码，只需将七大排序算法的核心性质像比赛前背模板一样列成一张表，再逐项匹配。做题时可以先用排除法：稳定排序只有“插、冒、归”；平均复杂度为 $O(n\log_2 n)$ 的只有“快、堆、归”；最好情况能达到线性 $O(n)$ 的典型是“插入、冒泡（优化后）”。注意不要被快速排序的“快”字误导，它最好也达不到线性。

**推演**：  
将各排序算法的稳定性、平均时间复杂度、最好时间复杂度整理如下（其中冒泡排序最好情况 $O(n)$ 是指设置了交换标志的优化版本）：

| 排序算法 | 稳定性 | 平均时间复杂度 | 最好时间复杂度 |
|---------|--------|----------------|----------------|
| $I$ 冒泡排序 | 稳定 | $O(n^2)$ | $O(n)$（优化后） |
| $II$ 堆排序 | 不稳定 | $O(n\log_2 n)$ | $O(n\log_2 n)$ |
| $III$ 选择排序 | 不稳定 | $O(n^2)$ | $O(n^2)$ |
| $IV$ 直接插入排序 | 稳定 | $O(n^2)$ | $O(n)$ |
| $V$ 希尔排序 | 不稳定 | 通常约 $O(n^{1.3})$，依增量序列而定 | 不保证线性 |
| $VI$ 归并排序 | 稳定 | $O(n\log_2 n)$ | $O(n\log_2 n)$ |
| $VII$ 快速排序 | 不稳定 | $O(n\log_2 n)$ | $O(n\log_2 n)$ |

逐项说明：

1. **稳定性判断**：  
   - 冒泡排序：相邻元素比较交换，相等时不交换，稳定。  
   - 直接插入排序：从后往前找插入位置，遇到相等元素时插入其后，稳定。  
   - 归并排序：合并左右子表时，若左、右区间元素相等，先取左区间元素，稳定。  
   - 选择排序、堆排序、希尔排序、快速排序都可能跨越较长距离交换元素，破坏相等元素相对次序，不稳定。  
   因此①为 $I、IV、VI$。

2. **平均时间复杂度为 $O(n\log_2 n)$**：  
   - 堆排序：建堆 $O(n)$，然后 $n-1$ 次调整，每次向下调整 $O(\log_2 n)$，总平均 $O(n\log_2 n)$。  
   - 归并排序：递归深度 $\log_2 n$，每层合并总代价 $O(n)$，平均 $O(n\log_2 n)$。  
   - 快速排序：平均情况下划分基本均匀，递归树高度为 $\log_2 n$，每层划分总代价 $O(n)$，平均 $O(n\log_2 n)$。  
   因此②为 $II、VI、VII$。

3. **最好情况下能达到线性时间 $O(n)$**：  
   - 冒泡排序：如果序列已有序，优化版冒泡排序只需一趟扫描，发现无交换即结束，比较 $n-1$ 次，时间 $O(n)$。  
   - 直接插入排序：如果序列已有序，每个元素只需和前一元素比较一次，共约 $n$ 次比较，时间 $O(n)$。  
   - 选择排序即使序列有序，仍需比较 $\frac{n(n-1)}{2}$ 次，最好也是 $O(n^2)$。  
   - 堆排序、归并排序、快速排序最好均为 $O(n\log_2 n)$；希尔排序一般不认为能达到线性。  
   因此③为 $I、IV$。

**易错点**：  
- 误认为“选择排序是稳定的”。反例：序列 $[2_a, 2_b, 1]$，第一趟选择最小值 $1$ 与 $2_a$ 交换，得到 $[1, 2_b, 2_a]$，相等元素次序改变，故不稳定。  
- 误认为快速排序平均复杂度不是 $O(n\log_2 n)$。快速排序最坏是 $O(n^2)$，但平均和最好都是 $O(n\log_2 n)$，题中问的是平均，所以必须选。  
- 忘记冒泡排序要经过“加交换标志”优化才能达到最好 $O(n)$；若不加优化，最好也是 $O(n^2)$。  
- 把希尔排序归入稳定排序，或把归并排序归入不稳定排序。归并排序在合并时若写成“左边优先”就是稳定的；希尔排序因分组插入跨越较远，不稳定。  
- 误认为堆排序在有序时能达到线性。虽然数据有序，但堆排序仍需先建堆，再进行 $n-1$ 次堆调整，整体仍是 $O(n\log_2 n)$。

**命题规律**：该题是排序算法性质的综合考查，属 408 高频基础考点。常见变式有：  
- 要求选出“不稳定但平均 $O(n\log_2 n)$”的排序（堆排序、快速排序）；  
- 要求选出“时间复杂度和初始序列无关”的排序（选择排序、堆排序、归并排序等）；  
- 将最好、平均、最坏情况混合设置选项；  
- 结合空间复杂度出题（归并排序 $O(n)$，快速排序 $O(\log_2 n)$）。  
复习时应整理一张完整的“八大排序特性表”，包括稳定性、最好/平均/最坏时间复杂度、空间复杂度、是否与初始序列有关。记忆口诀可借鉴：“稳定排序只有插冒归；平均 $O(n\log n)$ 只有快堆归；最好线性是插冒”。平时做此类选择题时，先在草稿纸上列出特性表再对照选项，可避免遗漏。

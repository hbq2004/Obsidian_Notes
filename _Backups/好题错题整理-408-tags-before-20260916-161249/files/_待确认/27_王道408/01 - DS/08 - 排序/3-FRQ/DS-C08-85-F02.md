# 综合题 第 2 题

![[_Attachments/题目识别/27_王道408-题目/DS-C08-85-F02_题目.png|题目]]

2. 设待排序的关键字序列为 $\{12, 2, 16, 30, 28, 10, 16^{*}, 20, 6, 18\}$，试写出使用最低位优先 ($LSD$) 基数排序算法每趟排序后的结果.

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C08-85-F02_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：将序列中不足两位的数高位补 0，LSD 基数排序共需两趟：第一趟按个位分配收集后得到  
\(30,10,20,12,2,16,16^*,6,28,18\)；  
第二趟按十位分配收集后得到  
\(2,6,10,12,16,16^*,18,20,28,30\)。

**解题切入点**：先看最大关键字位数确定趟数。最大关键字是 30，是两位数，所以只需做“按个位”和“按十位”两趟。基数排序的本质是“稳定的分配—收集”，可类比为“先按牌面点数分堆，再按花色分堆”，每趟分配必须保持桶内原有顺序，否则前一趟的结果会失效。手算时用 10 个队列 \(Q_0\sim Q_9\) 模拟即可。

**推演**：

先把所有数看成两位数，不足两位高位补 0：

\[
12,02,16,30,28,10,16^*,20,06,18
\]

基数排序每趟的算法思路为：

```
for i = 0,1:            # i=0 按个位，i=1 按十位
    清空 Q[0]~Q[9]
    for x in 当前序列:
        k = (x / 10^i) % 10
        将 x 入队 Q[k]
    当前序列 = Q[0] + Q[1] + ... + Q[9]
```

第一趟：按个位分配。

非空队列为：

\[
\begin{aligned}
Q_0 &: 30,10,20\\
Q_2 &: 12,02\\
Q_6 &: 16,16^*,06\\
Q_8 &: 28,18
\end{aligned}
\]

按 \(Q_0,Q_1,\dots,Q_9\) 顺序收集，得：

\[
30,10,20,12,02,16,16^*,06,28,18
\]

去掉前导 0，即：

\[
30,10,20,12,2,16,16^*,6,28,18
\]

第二趟：在第一趟结果的基础上按十位分配。

非空队列为：

\[
\begin{aligned}
Q_0 &: 02,06\\
Q_1 &: 10,12,16,16^*,18\\
Q_2 &: 20,28\\
Q_3 &: 30
\end{aligned}
\]

按 \(Q_0,Q_1,Q_2,Q_3\) 顺序收集，得：

\[
02,06,10,12,16,16^*,18,20,28,30
\]

即最终有序序列：

\[
2,6,10,12,16,16^*,18,20,28,30
\]

因为最大位数为两位，第二趟后已按全部关键字有序，算法结束。基数排序时间复杂度为 \(O(d(n+r))\)，本题中 \(d=2,n=10,r=10\)。

**易错点**：

- 忘记把 \(2,6\) 按 \(02,06\) 处理，导致第二趟按十位分配时漏掉它们。  
- 收集顺序错误：必须按桶号 \(Q_0\to Q_9\) 的顺序收集，而不是按原序列顺序收集。  
- 破坏稳定性：\(16\) 与 \(16^*\) 关键字相同，初始顺序是 \(16\) 在前；若某趟分配或收集不稳定，最终可能变成 \(16^*,16\)，这是错误的。  
- 只做第一趟后以为排序完成；第一趟只是按个位有序，必须继续按高位排序。

**命题规律**：基数排序在 408 中主要考查“分配—收集”的手算过程、稳定性、时间复杂度 \(O(d(n+r))\)，以及 LSD 与 MSD 的区别。常见变式有：给出初始序列要求写出每趟结果、判断某排序方法是否为稳定排序、比较基数排序与快速排序/堆排序的适用场景。复习时要熟练掌握“高位补 0、低位优先、每趟稳定”三要素，并会画队列分配表。

# 选择题 第 19 题

19.【2019统考真题】对 $n$ 个互不相同的符号进行哈夫曼编码。若生成的哈夫曼树共有 115 个结点，则 $n$ 的值是 (  ).
A. 56
B. 57
C. 58
D. 60

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C05-55-M19_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：$n=58$，选 C。由哈夫曼树性质，$n$ 个叶子结点的哈夫曼树共有 $2n-1$ 个结点，故 $2n-1=115$，解得 $n=58$。

**解题切入点**：拿到“哈夫曼树结点数”的题，先抓住哈夫曼树最本质的结构特征：它是严格二叉树，即每个非叶结点都有两个孩子，度为 1 的结点不存在。于是“叶子数 $n$”和“内部结点数”之间有固定关系。就像做题时先识别模型：给了一棵树的总结点数，问叶子数，如果知道这是哈夫曼树，就可以直接用“叶子数 $=$ 内部结点数 $+1$”这个结论，而不用去画树。

**推演**：  
设 $n$ 个互不相同的符号作为 $n$ 个叶子结点。哈夫曼树的构造过程是每次从森林中选两棵根结点权值最小的树合并，生成一个新结点作为它们的父结点。  

初始时，森林中有 $n$ 棵单结点树，此时总结点数 $= n$，内部结点数 $= 0$。  
每合并一次，新增 1 个内部结点，同时两棵树合并为一棵树，树的棵数减少 1。为了把 $n$ 棵树合并成一棵树，需要合并 $n-1$ 次，因此最终内部结点数为 $n-1$。  

所以，哈夫曼树的总结点数 $N$ 为：
$$
N = \text{叶子结点数} + \text{内部结点数}
= n + (n-1) = 2n-1.
$$

题目给出 $N = 115$，于是：
$$
2n-1 = 115 \implies 2n = 116 \implies n = 58.
$$

因此 $n=58$，对应选项 C。

**易错点**：  
1. 误把哈夫曼树当作完全二叉树，套用完全二叉树的结点公式，导致错误。哈夫曼树不一定是完全二叉树，也不一定平衡。  
2. 忘记“哈夫曼树没有度为 1 的结点”这一核心条件，从而无法建立叶子数与内部结点数的关系。  
3. 构造哈夫曼树时，误以为每合并一次总节点增加 2 个，实际每次合并只新增 1 个父结点，因为参与合并的两个根结点原本已存在。  
4. 计算时粗心：$2n-1=115$ 解出 $n=58$，但可能误选 57（错误地认为内部结点是 $n$ 或 $n+1$）。

**命题规律**：  
本考点属于“哈夫曼树与哈夫曼编码”的基础性质。408 统考常以选择题形式考查：  
- 给定叶子数求总结点数，或给定总结点数求叶子数（如本题）；  
- 给定一组权值，求哈夫曼树的带权路径长度（WPL）或具体编码；  
- 判断哈夫曼编码是否为前缀码；  
- 结合“哈夫曼树中不存在度为 1 的结点”与“$n_0 = n_2 + 1$”的性质进行变形。  

复习建议：熟练掌握哈夫曼树的构造过程、结点数性质、WPL 的计算方法，并注意区分“哈夫曼树”与“完全二叉树”“二叉排序树”等不同树结构。对于 $n$ 个叶子结点的哈夫曼树，直接记住总结点数为 $2n-1$，可以快速解决此类题。

5. 假设二叉树采用二叉链表存储结构存储,试设计一个算法,计算一棵给定二叉树的所有双分支结点数.

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C05-53-F05_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：基于二叉树的后序遍历，递归统计左右子树的双分支结点数，若当前结点左右孩子均存在则加1，最终返回总和。

**解题切入点**：首先明确“双分支结点”即度为2的结点，问题转化为统计二叉树中度为2的结点个数。这道题是二叉树遍历的典型应用，类似“求叶子结点数”的变式，核心在于遍历过程中对每个结点检查其左右孩子是否都存在。从算法竞赛角度看，这类“计数”问题通常用递归解决，因为二叉树递归定义天然适合分治。拿到题目应先定位考点：二叉树的递归遍历与结点属性判断。

**推演**：  
设二叉树采用二叉链表存储，结点结构为：
```
typedef struct BiTNode {
    ElemType data;
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;
```
设计递归函数 `int CountDouble(BiTree T)`，返回以 `T` 为根的二叉树中双分支结点个数。  
递归过程：  
- 若 `T == NULL`，空树无双分支结点，返回0。  
- 否则，递归计算左子树的双分支结点数 `left = CountDouble(T->lchild)`。  
- 递归计算右子树的双分支结点数 `right = CountDouble(T->rchild)`。  
- 判断当前结点 `T`：若 `T->lchild != NULL && T->rchild != NULL`，则 `T` 是双分支结点，贡献1；否则贡献0。  
- 返回 `left + right + (T 是双分支 ? 1 : 0)`。  

代码实现如下：
```c
int CountDouble(BiTree T) {
    if (T == NULL) return 0;
    int left = CountDouble(T->lchild);
    int right = CountDouble(T->rchild);
    if (T->lchild != NULL && T->rchild != NULL)
        return left + right + 1;
    else
        return left + right;
}
```
该算法的时间复杂度为 $O(n)$（$n$ 为结点数），空间复杂度为 $O(h)$（$h$ 为树高，递归栈深度）。  
也可以用非递归遍历（如层次遍历）实现，但递归版本最直观。

**易错点**：  
1. 空树处理：忘记判断 `T == NULL` 会导致递归无法终止。  
2. 双分支条件误判：应保证左右孩子**均存在**，有些人可能误写成 `T->lchild || T->rchild` 或只检查一个。  
3. 重复计数：递归时分别统计左右子树，再判断当前结点，不会重复；若在递归调用中包含当前结点判断，需注意区分。  
4. 递归返回值类型：确保返回整型，避免隐式转换错误。

**命题规律**：  
本题属于二叉树遍历的经典应用，难度较低，但能检验对递归思想的理解。常见变式包括：求叶子结点数（度为0）、求单分支结点数（度为1）、求结点总数、求树的高度、求完全二叉树结点数等。复习时应熟练掌握递归遍历框架，并能够灵活修改“访问结点”的操作来适应不同计数需求。建议结合非递归遍历（栈、队列）进行对比练习，加深对遍历过程的理解。此外，也可以扩展为统计二叉树中度为 $k$ 的结点数，或判断二叉树是否为满二叉树等。此类题型是 408 综合应用题的必考基础，务必做到快速准确。

## DeepSeek V4 Flash Max 解析

**答案**：调用 $DFS$ 的次数正好等于连通分量数，选 **(C)**。

**解题切入点**：  
拿到题先明确“非连通无向图”与“深度优先遍历”的实现结构。$DFSTraverse$ 的本质是：从某个顶点出发调用一次 $DFS$，能且只能访问完该顶点所在的整个连通分量；若图中还有未访问顶点，说明还有新的连通分量。因此，外层循环调用 $DFS$ 的次数就等于连通分量数。可以把 $DFS$ 想象成“一支队伍去探索一个岛屿”，一座岛屿就是一个连通分量；每支队伍只能探完自己所在的岛，有几座岛就需要派几支队伍。

**推演**：  
设无向图 $G=(V,E)$ 有 $n$ 个顶点，$m$ 条边。$DFSTraverse$ 的典型实现为：

```cpp
void DFSTraverse(Graph G) {
    for (v = 0; v < G.vexnum; ++v)
        visited[v] = false;
    for (v = 0; v < G.vexnum; ++v)
        if (!visited[v])
            DFS(G, v);
}
```

$DFS(G,v)$ 从顶点 $v$ 出发，沿着无向边不断深入访问所有可达顶点。由于 $G$ 是无向图，“可达”关系正好等价于“在同一个连通分量中”。因此：

- 从某个连通分量中的任一顶点开始，一次 $DFS$ 能访问且仅能访问该连通分量的全部顶点；
- 访问完一个连通分量后，若仍有 $visited$ 为 false 的顶点，说明该顶点属于另一个连通分量，必须再次调用 $DFS$；
- 所以 $DFSTraverse$ 中调用 $DFS$ 的次数 = 图中连通分量的数目。

例如，设 $G$ 由 $2$ 个独立子图组成，第 $1$ 个有 $3$ 个顶点，第 $2$ 个有 $2$ 个顶点。第一次调用 $DFS$ 可访问第 $1$ 个子图的 $3$ 个顶点，第二次调用 $DFS$ 可访问第 $2$ 个子图的 $2$ 个顶点，不会调用第 $3$ 次。

对于非连通无向图，连通分量数至少为 $2$，该次数既不等于顶点数，也不等于边数，更不是不确定，而是确定的连通分量数。

**易错点**：  
1. **误选 A（顶点数）**：$DFS$ 是递归或借助栈实现的，内部递归访问每个顶点，但 $DFSTraverse$ 中“调用 $DFS$ 的次数”是外层调用次数，不是 $DFS$ 递归调用的总次数。  
2. **误选 D（不确定）**：虽然不同顶点出发时访问顺序不同，但外层调用次数只取决于图的连通分量个数，与起始顶点、邻接表顺序无关，因而是确定的。  
3. **与有向图混淆**：有向图中一次 $DFS$ 访问的是从起点出发可达的顶点集，不一定是强连通分量；但本题明确是无向图，所以结论简洁。

**命题规律**：  
本题直接考查 $DFS$ 遍历算法对非连通图的处理方式，属于“图的遍历”基础考点。常见变式包括：  
- 给定一个无向图的邻接表，要求写出 $DFSTraverse$ 中调用 $DFS$ 的次数；  
- 判断图是否连通：若 $DFSTraverse$ 调用 $DFS$ 的次数等于 $1$，则图连通，否则不连通；  
- 在有向图中，调用 $DFS$ 的次数不能简单等于强连通分量数，但利用 $DFS$ 可求强连通分量（Kosaraju 算法）。  

复习时应重点理解 $DFS$/$BFS$ 与连通分量的关系：无论深度优先还是广度优先，对外层循环来说，调用次数都等于连通分量数（对无向图而言）。建议动手在邻接矩阵和邻接表两种存储结构上模拟一遍遍历过程，加深印象。

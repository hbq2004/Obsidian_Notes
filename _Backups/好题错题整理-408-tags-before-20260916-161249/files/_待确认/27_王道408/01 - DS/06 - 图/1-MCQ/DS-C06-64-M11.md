## DeepSeek V4 Flash Max 解析

**答案**：选 C（$I$、$II$、$III$ 可以判断有向图是否有环；$IV$ 普通广度优先遍历不能）。

**解题切入点**：  
拿到本题先抓“有向图判环”的等价条件：一个有向图无环，当且仅当它是 DAG。因此能做的标准方法有三类：DFS 找“回边”、拓扑排序是否输出全部顶点、把判环转化为最短路径算法中的“负环检测”。  
可先判断 $IV$：普通 BFS 只有 `visited` 标记，没有 DFS 的递归栈，也没有拓扑排序的入度信息，无法区分“回边”和“交叉边”，所以不能可靠判环。四个选项中只有 C 不含 $IV$，可快速排除 A、B、D。

**推演**：

### I. 深度优先遍历
正确。  
DFS 使用三色标记：白表示未访问，灰表示在递归栈中，黑表示已结束。遍历边 $u \to v$ 时：

- 若 $v$ 是灰色，说明 $v$ 仍在当前 DFS 路径上，$u \to v$ 是一条回边，存在环；
- 若 $v$ 是白色，继续递归；
- 若 $v$ 是黑色，说明是前向边或交叉边，不能判环。

关键代码思路：

```cpp
bool dfs(u) {
    color[u] = 1;              // 灰色，进入递归栈
    for (v : adj[u]) {
        if (color[v] == 1) return true;   // 回边，有环
        if (color[v] == 0 && dfs(v)) return true;
    }
    color[u] = 2;              // 黑色，结束
    return false;
}
```

若从每个顶点出发执行 DFS 后均未发现回边，则无环。

---

### II. 拓扑排序
正确。  
拓扑排序成功，当且仅当有向图无环。使用 Kahn 算法：

- 统计每个顶点的入度；
- 把入度为 0 的顶点入队；
- 每次取出一个顶点，删除它，并将其所有后继的入度减 1；
- 若某后继入度变为 0，入队。

若最终输出的顶点数小于图中顶点总数，则说明剩余顶点无法删除，图中存在环。

关键代码思路：

```cpp
queue<int> q;
for (i = 0; i < n; i++)
    if (indeg[i] == 0) q.push(i);

int cnt = 0;
while (!q.empty()) {
    u = q.front(); q.pop(); cnt++;
    for (v : adj[u])
        if (--indeg[v] == 0) q.push(v);
}

return cnt == n;   // 相等则无环，否则有环
```

---

### III. 求最短路径
正确，但需要具体说明：不是直接用 Dijkstra，而是用最短路径算法中的负环检测。  
做法：把原图中每条边的权值设为 $-1$。于是原图中任何一个有向环，在新图中的总权值都是负数，即负权回路。

例如环 $v_0 \to v_1 \to \cdots \to v_{k-1} \to v_0$，其总权值为 $-k < 0$。  
因此“原图有环”等价于“新图有负权回路”。

Bellman-Ford 算法可以检测负权回路：若松弛 $|V|-1$ 轮后仍能继续松弛，则存在负环。  
Floyd 算法也可以检测：若算法结束后存在 $dist[i][i] < 0$，则存在负环。

所以 III 可作为判断有向图是否有环的方法。

---

### IV. 广度优先遍历
不能。  
普通 BFS 中，遇到一个已经访问过的顶点，不一定说明有环。例如下面的 DAG：

$$A \to B,\quad A \to C,\quad B \to C$$

BFS 从 $A$ 出发，先访问 $B、C$，再扩展 $B$ 时发现 $C$ 已经被访问过，但图中显然没有环。  
因此若把“访问到已访问顶点”当作判环依据，会产生误判。

同时，普通 BFS 没有递归栈，不能像 DFS 那样识别“回边”，所以不能判断有向图是否有环。

**易错点**：

1. **把 BFS 的 visited 重复访问当成有环**。  
   有向图中访问到已访问顶点可能是交叉边，不一定是回边；必须用 DFS 的灰色递归栈或拓扑排序的入度信息判断。

2. **把拓扑排序的队列实现误认为 BFS**。  
   Kahn 算法虽然也用队列，但它维护的是入度，不是普通图遍历中的层次扩展，因此不能据此说 IV 正确。

3. **认为 Dijkstra 可以判环**。  
   Dijkstra 只能处理非负权图，本身不能检测负环；判断一般有向图是否有环，要用 Bellman-Ford/Floyd 的负环检测思路。

4. **混淆有向图和无向图判环**。  
   无向图 BFS 中遇到已访问的非父结点可判环；有向图不能照搬。

**命题规律**：  
本题是图论高频考点，考查“有向图判环”的等价条件。常见变式有：

- 用 DFS 判断回边；
- 用拓扑排序输出顶点数判断是否有环；
- 用 Bellman-Ford 或 Floyd 判断负环；
- 无向图判环用并查集或 DFS/BFS；
- 在关键路径、拓扑排序综合题中隐含考查 DAG 判定。

复习时应熟练掌握 DFS 三色标记、Kahn 算法、Bellman-Ford 负环检测，并注意区分“普通遍历”和“判环算法”的边界。  
选择题中善用排除法，能有效节省时间。

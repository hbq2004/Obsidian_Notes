# 选择题 第 11 题

![[_Attachments/题目识别/27_王道408-题目/DS-C07-74-M11_题目.png|题目]]

11. 在一棵高度为 $h$ 的 $B$ 树中插入一个新关键字，假设在插入过程中读入的结点一直在内存中，根结点的高度为 $1$，且初始时未读入内存，则下列叙述中错误的是( )。
(注意，本题中的新结点是指新产生的结点，如一次分裂才产生一个新结点。)
(A) 若插入操作导致树的高度变为 $h+1$，则本次插入一定导致了根结点的分裂
(B) 若插入操作导致旧结点的分裂，则树的高度一定会变为 $h+1$
(C) 由于本次插入操作而产生的新结点的个数最多为 $h+1$
(D) 由于本次插入操作而产生的读/写磁盘的次数最多为 $3h+1$

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C07-74-M11_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：错误的是 **B**。A、C、D 均正确；B 错在“旧结点分裂”不必然导致高度增加，只有根结点分裂并新建根结点时，B 树高度才会从 $h$ 变为 $h+1$。

**解题切入点**：本题核心是 B 树插入时的“上溢分裂传播”。插入新关键字后，若叶子结点满，就分裂并把中间关键字上移到父结点；父结点若也满，则继续分裂上移。可以把这个过程类比为“进位加法”：局部进位不传到最高位，整体位数就不会增加；B 树中只有分裂一路传到根结点，树高才会增加。同时要区分“分裂次数”“新结点个数”和“磁盘读写次数”。

**推演**：

设 B 树阶数为 $m$，当前树高为 $h$，根结点为第 $1$ 层，叶子结点为第 $h$ 层。

插入过程可概括为：

```text
while (当前结点上溢) {
    分裂当前结点；
    中间关键字插入父结点；
    if (当前结点是根结点) 新建根结点，树高加1；
}
```

### 1. 判断 A

A 说：若高度变为 $h+1$，则本次插入一定导致根结点分裂。

B 树插入只会在“根结点分裂并新建根结点”时增加一层。非根结点分裂只会在本层增加一个新结点，不会改变树高。因此 A 正确。

### 2. 判断 B

B 说：若插入导致旧结点分裂，则高度一定变为 $h+1$。

这是错误的。例如一个满的叶子结点分裂，只要父结点不满，中间关键字上移到父结点后分裂就停止，树高仍然是 $h$。只有根结点分裂才会使树高增加。因此 B 错误。

### 3. 判断 C

插入路径上最多有 $h$ 个结点可能依次分裂：叶子结点、父结点、……、根结点。

- 若根结点不分裂，则最多有 $h-1$ 个非根结点分裂；
- 每个非根结点分裂产生 $1$ 个新结点；
- 若根结点也分裂，根分裂还会额外产生 $2$ 个新结点：一个新根结点和一个新兄弟结点。

所以最坏情况下新结点个数为：

$$
(h-1)+2=h+1
$$

因此 C 正确。

### 4. 判断 D

先看读盘次数：插入前要从根结点查到叶子结点，共需要读取 $h$ 个结点，即读盘 $h$ 次。

最坏情况是叶子到根结点全部发生分裂。

- 非根结点分裂：每次分裂要写回原结点，并写出新结点，共 $2$ 次写盘；
- 根结点分裂：要写回旧根结点、写新兄弟结点、写新根结点，共 $3$ 次写盘。

最坏情况下有 $h-1$ 个非根结点分裂，加上根结点分裂，写盘次数为：

$$
2(h-1)+3=2h+1
$$

总读写次数为：

$$
h+(2h+1)=3h+1
$$

若根结点不分裂，读写次数不超过 $3h-1$。因此 D 正确。

综上，错误的是 B。

**易错点**：

1. **把“发生分裂”等同于“树高增加”**。实际上只有根结点分裂才会增加高度，普通叶子或内部结点分裂不会改变树高。
2. **根分裂的新结点个数容易漏算**。根分裂不仅产生新兄弟结点，还要产生新根结点，所以最多新结点数为 $h+1$，而不是 $h$。
3. **磁盘读写次数容易漏掉搜索阶段的读盘**。插入前必须从根结点向下读取 $h$ 个结点，读盘次数为 $h$。
4. **写盘次数容易重复计数**。若父结点随后也分裂，父结点最终的写回已经包含在“该结点分裂”所计的写盘次数中，不应再额外加一次。
5. **忽略“读入结点一直在内存中”**。因为父结点已读入内存，所以分裂上移时不需要重新读父结点，否则读写次数会更大。

**命题规律**：本题属于 B 树动态操作与磁盘 I/O 计数的经典考点。408 常考 B 树插入、删除时的分裂/合并过程，以及最坏情况下的磁盘读写次数。常见变式包括：给定阶数和高度求最多/最少关键字个数、B 树插入后新结点个数、B 树删除时合并次数、B+ 树与 B 树的对比如等。复习时应亲手画一棵 3 阶 B 树，模拟连续插入和删除，重点掌握“分裂向上传播”和“根分裂才增加高度”这两个结论。

# 选择题 第 7 题

![[_Attachments/题目识别/27_王道408-题目/DS-C03-34-M07_题目.png|题目]]

7.若将 $n$ 阶上三角矩阵 $A$ 按列优先级压缩存放在一维数组 $B[1\cdots n(n+1)/2+1]$ 中，则存放到 $B[k]$ 中的非零元素 $a_{ij}(1\leqslant i,j\leqslant n)$ 的下标 $i$、$j$ 与 $k$ 的对应关系是 ( ).
A. $i(i+1)/2+j$
B. $i(i-1)/2+j-1$
C. $j(j-1)/2+i$
D. $j(j-1)/2+i-1$

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C03-34-M07_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C. \(j(j-1)/2 + i\)（按列优先存储上三角矩阵，数组下标从1开始时，非零元素 \(a_{ij}\) 在 \(B\) 中的位置 \(k = j(j-1)/2 + i\)）。

**解题切入点**：首先明确“上三角矩阵”的定义（\(i>j\) 的元素为零）和“按列优先级压缩存储”的含义（按列的顺序，每列从上到下依次存储非零元素）。然后计算在 \(a_{ij}\) 之前已经存储的元素个数：前 \(j-1\) 列的非零元素总数加上第 \(j\) 列中在 \(a_{ij}\) 之前的元素数。由于数组下标从1开始，\(k\) 等于前面元素个数加1，从而导出公式。

**推演**：对于 \(n\) 阶上三角矩阵 \(A\)，非零元素满足 \(i \le j\)。按列优先存储，即先存储第1列，再第2列，……，最后第 \(n\) 列。第 \(j\) 列有 \(j\) 个非零元素（行号 \(1,2,\dots,j\)）。因此，位于 \(a_{ij}\) 之前的元素包括：
- 第1列到第 \(j-1\) 列的所有非零元素，总数为 \(\sum_{t=1}^{j-1} t = \frac{j(j-1)}{2}\)。
- 第 \(j\) 列中行号小于 \(i\) 的元素，共 \(i-1\) 个。
所以前面元素总数 \(= \frac{j(j-1)}{2} + (i-1)\)。
由于数组 \(B\) 的下标从1开始，\(a_{ij}\) 存放在 \(B[k]\)，则 \(k = \frac{j(j-1)}{2} + (i-1) + 1 = \frac{j(j-1)}{2} + i\)。
因此，\(i,j\) 与 \(k\) 的对应关系为 \(k = \frac{j(j-1)}{2} + i\)，对应选项 C。

**易错点**：1. 混淆行优先和列优先，导致错误选择 A 或 B。2. 忽略数组下标起始位置，若下标从0开始，则公式为 \(k = \frac{j(j-1)}{2} + i - 1\)，但本题下标从1开始，故应加1。3. 混淆上三角与下三角，注意上三角矩阵 \(i>j\) 为零，非零元素在 \(i\le j\)。

**命题规律**：本题是矩阵压缩存储的经典题型，常考特殊矩阵（对称矩阵、三角矩阵、三对角矩阵）的压缩存储对应关系，既可能考按行优先也可能考按列优先，以及数组下标起始位置。复习时需熟练掌握各类矩阵的压缩公式推导，并注意区分下标从0或1开始。常见变式包括下三角矩阵、对称矩阵、三对角矩阵的按行/列优先存储公式。建议通过画图举例验证公式，增强记忆。

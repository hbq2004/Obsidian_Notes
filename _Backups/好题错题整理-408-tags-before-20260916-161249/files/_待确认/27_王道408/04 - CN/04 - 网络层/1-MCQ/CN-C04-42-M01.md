# 选择题 第 1 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-42-M01_题目.png|题目]]

1. *Internet* 的网络层含有 4 个重要的协议，分别为( ).

(A) *IP,ICMP,ARP,UDP*

(B) *TCP,ICMP,UDP,ARP*

(C) *IP,ICMP,ARP,RARP*

(D) *UDP,IP,ICMP,RARP*

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-42-M01_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：C。理由：Internet 网络层核心协议为 IP、ICMP、ARP、RARP；UDP、TCP 属于传输层协议，不能混入网络层。

**解题切入点**：拿到题目先“分层定位”，看到协议名先问它属于哪一层。这就像算法竞赛中先明确“数据范围”和“问题类型”：TCP/UDP 是传输层的“双端收发策略”，IP 是网络层的“路由寻址核心”，ICMP 是网络层的“错误报告与诊断工具”，ARP/RARP 则是网络层与链路层之间的“地址映射辅助工具”。如果把传输层协议放进网络层，就像把“堆排序”写进“图论模板”一样，类别错了。

**推演**：

1. 明确 TCP/IP 参考模型的层次划分：
   - 应用层：HTTP、FTP、DNS 等；
   - 传输层：TCP、UDP；
   - 网络层（Internet 层）：IP、ICMP、ARP、RARP、IGMP 等；
   - 网络接口层：以太网协议、PPP 等。

2. 网络层的主要职责是“路由选择 + 分组转发 + 异构网络互联”，核心协议是 IP。为了让 IP 能正常工作，还需要：
   - ICMP：报告 IP 数据报在传输过程中的差错和诊断信息（如 ping 使用 ICMP）；
   - ARP：根据 IP 地址解析出物理地址（MAC 地址）；
   - RARP：根据物理地址反查 IP 地址（早期无盘工作站使用，现已被 DHCP 取代，但经典教材仍将其列为网络层协议）。

3. 对照选项：
   - A 含 UDP，UDP 是传输层协议，排除；
   - B 含 TCP、UDP，均为传输层协议，排除；
   - D 含 UDP，排除；
   - C 恰好是 IP、ICMP、ARP、RARP，且没有传输层协议，正确。

因此选 C。

**易错点**：

- 把 ARP 误认为链路层协议。ARP 报文是封装在以太网帧中传输的，但它解决的是“IP 地址 → MAC 地址”的映射问题，服务于网络层的 IP 协议，因此教材中通常将其归入网络层。
- 忽略 RARP。RARP 现已过时，但考研 408 大纲和经典教材（如谢希仁《计算机网络》）仍会提及，做题时不能因为它“过时”就排除。
- 混淆 ICMP 与 IGMP。ICMP 是差错报告和控制报文协议，IGMP 是组播管理协议。本题问“4 个重要协议”，经典表述为 IP、ICMP、ARP、RARP，不含 IGMP。
- 看到“Internet”就只想到 IP，忘记其他辅助协议。网络层不是只有 IP，而是“IP 为主 + 多种辅助协议”。

**命题规律**：

- 考点定位：TCP/IP 协议栈的层次划分，尤其是网络层协议族。属于基础送分题，但也是高频易混点。
- 常见变式：
  1. 问“不属于网络层协议的是？”——通常给 UDP、TCP、FTP 等干扰项；
  2. 问“ARP 属于哪一层？”——常与“ARP 报文封装在以太帧中”结合考查；
  3. 问“RARP 的作用”或“被什么协议取代”——答案是被 DHCP 取代；
  4. 结合 ICMP 应用，如 ping 命令使用的协议。
- 复习建议：把 TCP/IP 各层协议整理成一张“协议-层次-作用”表格，反复默写。尤其注意 ARP、RARP、ICMP、IGMP 这些“小协议”的归属与功能。对于算法竞赛背景的同学，可以把协议栈类比为“分层设计模式”：每层只解决一类问题，层间通过标准接口交互，调试时像“分治”一样逐层定位问题。

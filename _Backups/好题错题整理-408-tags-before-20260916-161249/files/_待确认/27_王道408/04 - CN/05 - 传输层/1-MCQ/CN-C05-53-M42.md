# 选择题 第 42 题

![[_Attachments/题目识别/27_王道408-题目/CN-C05-53-M42_题目.png|题目]]

42.【2009统考真题】一个TCP连接总以$1\text{KB}$的最大段长发送TCP段,发送方有足够多的数据要发送,当拥塞窗口为$16\text{KB}$时发生了超时,若接下来的$4\text{RTT}$时间内的TCP段的传输都是成功的,则当第$4$个$RTT$时间内发送的所有TCP段都得到肯定应答时,拥塞窗口大小是( )

A. $7\text{KB}$

B. $8\text{KB}$

C. $9\text{KB}$

D. $16\text{KB}$

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C05-53-M42_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：C。超时后 $ssthresh$ 变为 $8\text{KB}$，$cwnd$ 重置为 $1\text{KB}$；前 3 个 RTT 慢开始倍增到 $8\text{KB}$，第 4 个 RTT 进入拥塞避免，全部 ACK 后 $cwnd=9\text{KB}$。

**解题切入点**：  
看到“TCP 超时 + 拥塞窗口 + 连续 RTT 成功”立即定位到 TCP 拥塞控制的状态机。关键不是算乘法，而是维护两个状态：$cwnd$ 和 $ssthresh$。和算法竞赛中的模拟题一样，把每个 RTT 看成一次迭代；慢开始是“倍增”，拥塞避免是“加 1”，超时是“先把 threshold 减半，再把 cwnd 重置为 1”。

**推演**：  
设 $MSS=1\text{KB}$。发生超时时：

$$
ssthresh \leftarrow \frac{16\text{KB}}{2}=8\text{KB},\qquad cwnd \leftarrow 1\text{KB}.
$$

之后 4 个 RTT 全部成功。在慢开始阶段，收到一个 ACK，$cwnd$ 增加 1 个 MSS；一整轮全部 ACK 后等价于 $cwnd$ 翻倍。

进行状态模拟：

- 第 1 个 RTT：发送 $1\text{KB}$，收到 ACK 后 $cwnd=2\text{KB}$；
- 第 2 个 RTT：发送 $2\text{KB}$，收到 ACK 后 $cwnd=4\text{KB}$；
- 第 3 个 RTT：发送 $4\text{KB}$，收到 ACK 后 $cwnd=8\text{KB}$，此时 $cwnd=ssthresh$；
- 第 4 个 RTT：进入拥塞避免，发送 $8\text{KB}$；全部收到 ACK 后，$cwnd$ 加 1 个 MSS：

$$
cwnd = 8\text{KB}+1\text{KB}=9\text{KB}.
$$

因此选 C。

**易错点**：  
- 超时后忘记把 $cwnd$ 重置为 $1\text{KB}$，会得到无意义结果或误选 D。
- 到达 $ssthresh=8\text{KB}$ 后继续用慢开始，第 4 个 RTT 后变成 $16\text{KB}$，错选 D；正确应切到拥塞避免。
- 混淆“第 4 个 RTT 开始时”和“第 4 个 RTT 全部 ACK 后”：前者为 $8\text{KB}$，后者为 $9\text{KB}$。
- 忽略题目单位：这里 $MSS=1\text{KB}$，所以 $cwnd$ 的 KB 数与段数一致；若 $MSS$ 不是 $1\text{KB}$，要用 $cwnd/MSS$ 换算成段数。

**命题规律**：  
本题是 408 高频基础题，考 TCP 拥塞控制在超时后的慢开始/拥塞避免状态迁移。常见变式包括：给出 3 个重复 ACK 考快重传/快恢复；给出前几轮有丢包求 cwnd 变化；或反过来问“经过几个 RTT 恢复到某个窗口”。复习时最好把拥塞控制画成状态图，并养成列表模拟 $(cwnd,ssthresh)$ 的习惯。

# 综合题 第 12 题

![[_Attachments/题目识别/27_王道408-题目/DS-C05-53-F12_题目.png|题目]]

12. 设有一棵满二叉树(所有结点值均不同)，已知其先序序列为 $pre$，设计一个算法求其后序序列 $post$.

算法思路如下：对于满二叉树，先序序列中第一个元素是根结点。随后的部分又可以按照满二叉树的性质递归地划分出左子树的先序序列和右子树的先序序列。当划分到只剩一个结点时，它既是该子树的根，也是叶子结点。后序序列的特点是根结点在最后。因此，我们可以通过递归地将根结点插入到其左右子树后序序列之后来得到整个树的后序序列。

具体的伪代码实现如下：

```c
// 假设全局变量 pre_idx 用于记录当前处理的先序序列位置
int pre_idx = 0;

void getPostOrder(Node* pre, int* post, int n, int post_idx) {
    if (pre_idx >= n) return; // 边界检查

    // 访问根结点，记录值（这里只是示例，实际可能是索引或值）
    int root_val = pre[pre_idx++];

    // 对于满二叉树，可以通过完全二叉树的性质确定左子树和右子树的大小
    // 或者根据当前子树的结点总数（通过递归参数传递）来计算
    // 这里简化表示，假设函数知道当前子树应包含的结点总数 subtree_size
    int subtree_size = ...; // 需要根据递归上下文计算

    // 递归构建左子树的后序序列
    getPostOrder(pre, post, n, post_idx); // 注意：递归过程中需要传递剩余结点数等信息

    // 递归构建右子树的后序序列
    getPostOrder(pre, post, n, post_idx); // 同上

    // 将根结点的值放入后序序列的末尾位置
    post[post_idx] = root_val;
}
```
注：上述伪代码中的 `...` 表示需要根据满二叉树的结点总数和递归深度等信息具体计算左、右子树的大小。完整的算法实现需要更精确的参数设计。

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C05-53-F12_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：利用满二叉树（完美二叉树）左、右子树结点数相等的特点，把先序序列中除根外的部分等分成左右两段，递归转换，并将根放到后序区间末尾，即可得到后序序列。

**解题切入点**：拿到“先序序列 $\to$ 后序序列”的题，首先想遍历顺序：先序是“根-左-右”，后序是“左-右-根”。但没有中序序列，不能靠结点值找左右子树分界。本题的关键是“满二叉树”这一结构信息：任意一棵子树都是满二叉树，所以左右子树结点数必然相等，分界点由长度唯一确定。可以理解为：先序序列是一串“根 + 左块 + 右块”的数据，满二叉树保证左右两块一样大，因此递归切块即可。

**推演**：设当前子树的先序区间为 $\textit{pre}[l_1..r_1]$，后序区间为 $\textit{post}[l_2..r_2]$，结点数为

$$
m = r_1 - l_1 + 1 = 2^k - 1
$$

对于满二叉树，根是 $\textit{pre}[l_1]$；左右子树结点数相等，均为

$$
\frac{m-1}{2} = \frac{r_1-l_1}{2}
$$

记为 $\text{half}$。

于是当前先序序列被切分为：

- 根：$\textit{pre}[l_1]$
- 左子树先序：$\textit{pre}[l_1+1 .. l_1+\text{half}]$
- 右子树先序：$\textit{pre}[l_1+\text{half}+1 .. r_1]$

后序序列中，左子树后序在前，右子树后序在中，根在最后，所以：

- 左子树后序区间：$\textit{post}[l_2 .. l_2+\text{half}-1]$
- 右子树后序区间：$\textit{post}[l_2+\text{half} .. r_2-1]$
- 根：$\textit{post}[r_2] = \textit{pre}[l_1]$

递归处理即可。关键代码思路如下（下标从 0 开始）：

```c
void PreToPost(ElemType pre[], int l1, int r1,
               ElemType post[], int l2, int r2) {
    if (l1 > r1) return;                 // 空子树
    int half = (r1 - l1) / 2;            // 左右子树结点数

    // 左子树
    PreToPost(pre, l1 + 1, l1 + half,
              post, l2, l2 + half - 1);
    // 右子树
    PreToPost(pre, l1 + half + 1, r1,
              post, l2 + half, r2 - 1);
    // 根放到后序末尾
    post[r2] = pre[l1];
}
```

初始调用：

```c
PreToPost(pre, 0, n - 1, post, 0, n - 1);
```

正确性可由归纳法说明：当区间长度为 1 时，直接填入根；若左右子树的递归结果正确，则当前根放在后序最后，左、右子树后序在前，整体满足“左-右-根”，故算法正确。

时间复杂度为 $O(n)$，每个结点处理常数次；空间复杂度为 $O(\log n)$，即递归栈深度。

**易错点**：

1. **区间切分错误**：根占 $\textit{pre}[l_1]$，不要把它计入左右子树；左右子树结点数应为

$$
\frac{r_1-l_1}{2}
$$

2. **后序根的位置写错**：后序序列中根在当前区间最后，即 `post[r2]`，不是 `post[l2]`。
3. **递归出口遗漏**：空子树必须直接返回，否则会数组越界。
4. **概念混淆**：若把“满二叉树”理解为“每个非叶结点都有两个孩子”的严格二叉树，则仅凭先序序列不能唯一确定后序序列。例如先序 `pre=[1,2,3,4,5]` 可对应两棵不同的严格二叉树，分别得到 `post=[2,4,5,3,1]` 和 `post=[3,4,2,5,1]`。本题应按照 408 教材中“满二叉树=完美二叉树”的定义求解。

**命题规律**：本题属于二叉树遍历序列转换的经典递归分治题。常见变式有：由后序序列求先序序列、由层序序列结合先序/后序求另一种序列、给出先序和后序判断二叉树是否唯一等。复习时应熟练掌握“先序/中序/后序/层序”两两配合重建二叉树的方法，并特别关注满二叉树的性质：结点数 $n=2^h-1$，左右子树等大，递归区间边界可用 $n=7$ 的满二叉树手动模拟验证。

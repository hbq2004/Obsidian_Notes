# 综合题 第 14 题

![[_Attachments/题目识别/27_王道408-题目/DS-C05-53-F14_题目.png|题目]]

14. 试设计判断两棵二叉树是否相似的算法。所谓二叉树 $T_1$ 和 $T_2$ 相似, 指的是 $T_1$ 和 $T_2$ 都是空的二叉树或都只有一个根结点; 或者 $T_1$ 的左子树和 $T_2$ 的左子树是相似的, 且 $T_1$ 的右子树和 $T_2$ 的右子树是相似的.

## 答案

## DeepSeek V4 Flash Max 解析

**答案**：判断两棵二叉树是否相似，只需递归比较两棵树的结构：两树都为空则相似；一空一非空则不相似；两树均非空时，递归判断左子树对左子树、右子树对右子树是否分别相似。该算法与结点数据无关。

**解题切入点**：题目给出了递归定义，关键词是“左子树相似且右子树相似”，所以应立刻定位到二叉树的递归遍历与分治。这类似算法竞赛中的“树同构”问题：不要比较结点的 `data`，只比较“形状”。拿到题先想清楚递归出口：两个空指针、一个空一个非空；其余情况交给左右子树递归。

**推演**：

设 $S(T_1,T_2)$ 表示“二叉树 $T_1$ 与 $T_2$ 相似”。由题意可写成递归式：

$$
S(T_1,T_2)=
\begin{cases}
1, & T_1=T_2=\text{NULL}\\[2mm]
0, & T_1=\text{NULL},T_2\neq\text{NULL}\ \text{或}\ T_1\neq\text{NULL},T_2=\text{NULL}\\[2mm]
S(T_1.lchild,T_2.lchild)\land S(T_1.rchild,T_2.rchild), & T_1\neq\text{NULL}\land T_2\neq\text{NULL}
\end{cases}
$$

其中 $\land$ 表示逻辑与。

第三行也覆盖了“两棵树都只有一个根结点”的情况，因为此时左右子树均为空：

$$
S(\text{NULL},\text{NULL})\land S(\text{NULL},\text{NULL})=1
$$

所以代码中不需要为“只有一个根结点”单独设分支，只需处理空指针即可。

二叉链表存储结构下的关键代码如下：

```c
typedef struct BiTNode {
    int data;                      // 相似判断中不使用 data
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;

int IsSimilar(BiTree T1, BiTree T2) {
    if (T1 == NULL && T2 == NULL)
        return 1;                  // 两棵空树相似
    if (T1 == NULL || T2 == NULL)
        return 0;                  // 一空一非空，必不相似

    return IsSimilar(T1->lchild, T2->lchild) &&
           IsSimilar(T1->rchild, T2->rchild);
}
```

**正确性说明**：若两棵树都为空，返回 $1$，符合定义；若一棵为空另一棵非空，结构上不可能相似，返回 $0$。若两棵树的根结点都非空，则由定义，两棵树相似当且仅当左子树相似且右子树相似；函数恰好递归判断了这两个条件，因此算法正确。

**复杂度分析**：设两棵树的结点数分别为 $n_1,n_2$，高度分别为 $h_1,h_2$。递归调用最多沿着两棵树对应的位置进行，遇到“一空一非空”立即返回，因此最坏时间复杂度为

$$
O(\min(n_1,n_2))
$$

递归栈深度不超过较矮树的高度，因此空间复杂度为

$$
O(\min(h_1,h_2))
$$

最坏情况下，两棵都是链状树且结构相同，空间复杂度为 $O(n)$。

**易错点**：

- 把“相似”误认为“相等”，在递归中比较 `T1->data == T2->data`。相似只比较结构，不比较数据。
- 递归出口不完整：只判断两边都为空，漏掉“一空一非空”的情况，会导致对空指针继续访问 `lchild` 或 `rchild`，程序崩溃。
- 递归组合写错：本题必须“左对左、右对右”。如果题目改为判断“镜像对称”，才需要“左对右、右对左”。
- 认为“只有一个根结点”必须单独判断。实际上该情况会被左右子树均为空的递归调用自然处理，不需要额外分支。
- 复杂度分析不准确：不是把两棵树全部遍历完，而是遇到结构不匹配就停止，所以更准确的是 $O(\min(n_1,n_2))$。

**命题规律**：本题是二叉树递归遍历的典型应用，考点为“递归出口 + 左右子树分治”。常见变式有：

1. 判断两棵二叉树是否“相等”：只需在相似的基础上增加 `T1->data == T2->data`。
2. 判断二叉树是否“镜像对称”：递归时改为比较左子树与右子树交叉位置。
3. 判断一棵二叉树是否为另一棵二叉树的子树。
4. 复制二叉树、求二叉树高度、求叶子结点数等，均可用相同递归模板。

复习建议：把二叉树的递归算法总结为“出口 + 根的处理 + 左右递归”三步；先手动画出树验证递归过程，再写代码。考试时算法思想、代码、复杂度三部分缺一不可。

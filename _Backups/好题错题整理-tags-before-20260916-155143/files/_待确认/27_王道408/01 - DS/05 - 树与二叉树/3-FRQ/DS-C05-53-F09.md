9. 在二叉树中查找值为 $x$ 的结点，试编写算法(用 $C$ 语言) 打印值为 $x$ 的结点的所有祖先，假设值为 $x$ 的结点不多于一个.

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C05-53-F09_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：采用“后序式 DFS 回溯”在二叉树中查找 $x$：若在左/右子树中找到了 $x$，则当前结点就是 $x$ 的祖先，回溯时输出当前结点；递归栈天然保存了从根到当前结点的祖先路径。

**解题切入点**：先抓住“祖先”的本质：祖先就是根结点到 $x$ 的父结点路径上的所有结点。所以先递归查找 $x$，找到后沿递归调用栈回退，回退经过的每个结点都是祖先。类比 DFS 走迷宫：找到终点后，沿递归栈往回走，每个岔路口都是“祖先”。

**推演**：

二叉树结点定义：

```c
typedef int ElemType;

typedef struct BiTNode {
    ElemType data;
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;
```

核心算法：

```c
int findAncestors(BiTree T, ElemType x) {
    if (T == NULL)
        return 0;

    // 找到 x 本身：不打印它，向上层返回“找到了”
    if (T->data == x)
        return 1;

    // 若在某个子树中找到 x，则当前结点是 x 的祖先，打印并继续向上返回
    if (findAncestors(T->lchild, x) || findAncestors(T->rchild, x)) {
        printf("%d ", T->data);
        return 1;
    }

    return 0;
}

void PrintAncestors(BiTree T, ElemType x) {
    if (findAncestors(T, x) == 0)
        printf("未找到值为 %d 的结点\n", x);
}
```

正确性说明：

- 设当前结点为 $T$，若 $T$ 的某个孩子子树中找到了 $x$，则 $T$ 一定在根到 $x$ 的路径上，因此 $T$ 是 $x$ 的祖先。
- 当递归一层层向上返回时，所有祖先都会被逐一输出。
- 当 `T->data == x` 时，只返回“找到”，不打印 $x$ 自身，符合“祖先不含结点本身”的定义。
- 题目说明值为 $x$ 的结点不多于一个，因此找到一个后即可停止，不需要继续搜索。

上述算法的输出顺序是从 $x$ 的最近祖先开始，一直输出到根结点。若题目要求按“根结点到最近祖先”的顺序输出，可在递归函数中先用辅助数组保存路径，找到 $x$ 后从数组下标 $0$ 到 $depth-1$ 输出即可。

时间复杂度：

$$
T(n)=O(n)
$$

因为每个结点最多访问常数次。空间复杂度为递归栈深度：

$$
S(n)=O(h)
$$

其中 $h$ 为二叉树高度；最坏情况下为单支树，$h=O(n)$。

**易错点**：

1. 把 $x$ 结点本身也当作祖先输出。  
   应在 `T->data == x` 时直接返回，不打印当前结点。

2. 找到 $x$ 后继续搜索另一棵子树。  
   题目说明值为 $x$ 的结点不多于一个，找到后应停止；利用 `||` 的短路性可避免多余的搜索。

3. 忽略空树判断。  
   递归入口必须先判断 `T == NULL`，否则会访问空指针。

4. 输出顺序理解错误。  
   本算法输出顺序是“最近祖先 → 根”；若要求“根 → 最近祖先”，需要先用栈或数组保存再反向输出。

5. 使用先序遍历时没有在回溯时删除当前路径。  
   如果采用“路径数组 + 先序 DFS”，进入结点时入路径，退出时必须出路径；否则数组中的结点不一定是当前路径上的祖先。

**命题规律**：本题属于“二叉树遍历 + 栈/递归回溯”的综合应用题，是 408 数据结构算法题的高频考点。常见变式有：输出根到 $x$ 的路径、求两个结点的最近公共祖先、判断是否存在根到叶子的路径和等。复习时应熟练掌握递归遍历的“进入/回溯”时机，并会用手写栈模拟非递归后序遍历；这类题目通常以代码填空或手写关键算法形式考查。

3.【2020统考真题】若任意一个字符的编码都不是其他字符编码的前缀，则称这种编码具有前缀特性。现有某字符集（字符个数 $\geqslant 2$）的不等长编码，每个字符的编码均为二进制的0、1序列，最长为 $L$ 位，且具有前缀特性。请回答下列问题：

3) 简述判定某字符集的不等长编码是否具有前缀特性的过程。

## DeepSeek V4 Flash Max 解析

**答案**：  
用二叉链表存储的**二叉树（0-1 字典树/Trie）**保存；编码对应从根到叶子结点的 $0/1$ 路径，译码时按位走到叶子并回到根；判定前缀特性等价于检查所有字符编码终点是否都是互不相同的叶子结点。

**解题切入点**：  
看到“前缀特性 + 二进制 $0/1$ 序列”，应立刻想到**二叉树路径**：$0$ 走左分支、$1$ 走右分支。前缀特性等价于“没有任何一个编码停在另一个编码路径的内部”，这很像 Trie 中判断某个单词是否为另一个单词前缀的问题。做题时先画一棵二叉树，把编码放成路径，前缀问题就变成了“叶子结点/内部结点”问题。

**推演**：

设字符集为 $C=\{c_1,c_2,\dots,c_n\}$，字符 $c_i$ 的编码为  
$$
w_i=b_{i1}b_{i2}\cdots b_{ik_i},\qquad 1\le k_i\le L.
$$

规定：二叉树中 $0$ 表示走左孩子，$1$ 表示走右孩子。把每个编码 $w_i$ 从根结点开始沿对应分支走出一条路径，终点存放字符 $c_i$。

若某个编码终点 $v$ 仍有孩子，则存在另一个编码从 $v$ 继续向下延伸，即以 $w_i$ 为前缀，矛盾。因此具有前缀特性的编码，其终点必然是叶子结点；反过来，若所有编码终点都是互不相同的叶子结点，则任一路径都不可能成为另一个不同路径的前缀。  
所以适宜的存储结构是**二叉树**，也可称为 **0-1 字典树/Trie**。

---

### 1) 数据结构

用二叉链表存储的二叉树，结点中保存：

- 左孩子指针：表示 $0$；
- 右孩子指针：表示 $1$；
- 是否为一个字符编码的结束标记，以及对应字符。

树的高度不超过最长编码长度 $L$。

---

### 2) 译码过程

从左到右扫描 $0/1$ 串，从二叉树根结点出发：

- 读入 $0$，走向左孩子；
- 读入 $1$，走向右孩子；
- 每到达一个**叶子结点**，输出该叶子存放的字符，然后**重新回到根结点**，继续译下一个字符。

关键代码如下：

```text
p = root
for bit in S:
    if bit == 0:
        p = p->left
    else:
        p = p->right

    if p == NULL:
        译码失败，S 不是合法编码串

    if p 是叶子结点:
        输出 p 中存放的字符
        p = root

if p != root:
    译码失败，说明 S 在某个编码中间结束
```

对于长度为 $m$ 的合法 $0/1$ 串，译码时间复杂度为 $O(m)$。

---

### 3) 判定是否具有前缀特性

用这些编码构造二叉树，一边插入一边判定。

设最初只有根结点。依次处理每个字符编码 $w$：

- 从根出发，按照 $0/1$ 走向左右孩子；
- 若某个分支不存在，则创建新结点；
- 若在走到 $w$ 终点之前，经过了某个已经标记为“编码终点”的结点，说明已有较短编码是当前编码的前缀，**不具有前缀特性**；
- 若 $w$ 的终点已经标记为编码终点，说明编码重复，**不具有前缀特性**；
- 若 $w$ 的终点已经有左孩子或右孩子，说明当前编码是某个更长编码的前缀，**不具有前缀特性**；
- 否则，将终点标记为编码终点，并存放对应字符。

全部编码插入完成后若没有发生冲突，则具有前缀特性。

关键代码如下：

```text
root = new node

for 每个字符 c 及其编码 w:
    p = root

    for w 中的每一位 b:
        if p 已经标记为编码终点:
            return false      // 已有编码是当前编码的前缀

        if b == 0:
            if p->left == NULL:
                p->left = new node
            p = p->left
        else:
            if p->right == NULL:
                p->right = new node
            p = p->right

    if p 已经标记为编码终点:
        return false          // 重复编码

    if p->left != NULL 或 p->right != NULL:
        return false          // 当前编码是某个更长编码的前缀

    标记 p 为编码终点，存放字符 c

return true
```

设 $n$ 个字符，全部编码总长度为 $N=\sum k_i\le nL$，则构造和判定时间复杂度为 $O(N)=O(nL)$，空间复杂度也是 $O(nL)$。

**易错点**：

- 误把字符存放在内部结点上。前缀特性要求字符编码终点必须是叶子结点，若内部结点也存放字符，则会出现一个编码是另一个编码前缀的情况。
- 译码时忘记“输出一个字符后回到根结点”。例如编码 $\{0,10,11\}$ 中，遇到 $0$ 输出后若继续留在原叶子结点，后续译码必然出错。
- 判定前缀特性时只检查“当前编码是否遇到已有叶子”，忘记检查“当前编码终点是否已有孩子”。例如先插入较长编码 $01$，再插入较短编码 $0$，此时 $0$ 的终点已有孩子，说明 $0$ 是 $01$ 的前缀。
- 认为必须用哈夫曼树。本题只要求存储具有前缀特性的不等长编码，使用任意二叉树即可；哈夫曼树只是构造满足前缀特性的二叉树的一种方法。
- 忽略重复编码。重复编码会导致一个 $0/1$ 串对应多个字符，不是合法编码。

**命题规律**：

本题是“二叉树 + 前缀编码”的典型综合题，核心考点是**哈夫曼树编码/译码的前缀特性**。常见变式有：

- 给定字符频度，构造哈夫曼树并写出前缀编码；
- 给出一组不等长编码，判断是否具有前缀特性；
- 给出一棵前缀编码树，模拟译码过程；
- 结合文件压缩求带权路径长度 WPL。

复习时需熟练掌握二叉树的路径表示、叶子结点判定、Trie 的插入与查询，并能用伪代码描述“前缀判定”过程。

# 综合题 第 5 题

![[_Attachments/题目识别/27_王道408-题目/DS-C05-52-F05_题目.png|题目]]

5. 已知一棵二叉树按顺序存储结构进行存储，设计一个算法，求编号分别为 $i$ 和 $j$ 的两个结点的最近的公共祖先结点的值.

6. 【2016统考真题】若一棵非空 $k(k \geqslant 2)$ 叉树 $T$ 中的每个非叶结点都有 $k$ 个孩子，则称 $T$ 为正则 $k$ 叉树。请回答下列问题并给出推导过程.
1) 若 $T$ 有 $m$ 个非叶结点，则 $T$ 中的叶结点有多少个?
2) 若 $T$ 的高度为 $h$(单结点的树 $h=1$)，则 $T$ 的结点数最多为多少个? 最少为多少个?

## DeepSeek V4 Flash Max 解析

**答案**：题5：在顺序存储二叉树中，编号 \(x\) 的父结点编号为 \(\lfloor x/2\rfloor\)，所以反复令 \(i,j\) 中较大者变为其父编号，直到 \(i=j\)，输出 \(T[i]\)。题6：1）叶结点数为 \((k-1)m+1\)；2）高度为 \(h\) 时，最多 \(\dfrac{k^h-1}{k-1}\) 个结点，最少 \(k(h-1)+1\) 个结点。

**解题切入点**：看到“顺序存储”和“编号 \(i,j\)”，立刻想到堆式编号关系：编号 \(x\) 的父结点是 \(\lfloor x/2\rfloor\)，祖先就是不断除以 2。看到“正则 \(k\) 叉树”，不要先画复杂树形，先抓计数关系：每个非叶结点贡献 \(k\) 个孩子，而除根以外每个结点恰好是某个非叶结点的孩子，所以“孩子总数 \(=km\)”“总结点数 \(-1\)”。

**推演**：

**题5**

按教材约定，根结点编号为 1，编号 \(x\) 的左、右孩子编号为 \(2x,2x+1\)，因此编号 \(x\) 的父结点编号为

\[
\left\lfloor \frac{x}{2} \right\rfloor .
\]

设顺序存储数组为 \(T\)，\(T[i]\) 存编号为 \(i\) 的结点的值。算法如下：

```c
ElemType CommonAncestor(SqBiTree T, int i, int j) {
    if (T[i] == EMPTY || T[j] == EMPTY)
        return EMPTY;        // 编号不存在
    while (i != j) {
        if (i > j)
            i /= 2;          // i 上移为父结点
        else
            j /= 2;          // j 上移为父结点
    }
    return T[i];             // 最近公共祖先结点的值
}
```

正确性：编号 \(x\) 的所有祖先编号集合为

\[
\left\{x,\left\lfloor\frac{x}{2}\right\rfloor,\left\lfloor\frac{x}{4}\right\rfloor,\ldots,1\right\}.
\]

若当前 \(i>j\)，则 \(i\) 不可能是 \(j\) 的祖先，因为 \(j\) 的所有祖先编号都不大于 \(j\)，所以当前 \(i\) 不可能是公共祖先；把 \(i\) 更新为其父结点后，不会丢失任何真正的公共祖先。同理处理 \(j>i\)。循环结束时 \(i=j\)，该编号就是原两个结点公共祖先中编号最大者，也就是最近的公共祖先。

循环次数不超过两个编号的深度之和，即 \(O(\log i+\log j)\)，辅助空间为 \(O(1)\)。

**题6**

设叶结点数为 \(l\)，总结点数为 \(n\)。已知非叶结点数为 \(m\)，所以

\[
n=l+m.
\]

每个非叶结点有 \(k\) 个孩子，因此所有非叶结点的孩子总数是 \(km\)。另一方面，除根结点外，每个结点都是某个非叶结点的孩子，所以孩子总数等于

\[
n-1.
\]

于是：

\[
km=n-1.
\]

因此

\[
n=km+1,
\]

叶结点数为

\[
l=n-m=(km+1)-m=(k-1)m+1.
\]

所以第 1）问答案为：

\[
\boxed{(k-1)m+1}
\]

第 2）问：

高度为 \(h\) 的树共有 \(h\) 层。若使结点数最多，则每一层都填满。根所在层记为第 0 层，则第 \(d\) 层最多有 \(k^d\) 个结点，其中 \(0\le d\le h-1\)。所以最大结点数为

\[
N_{\max}=1+k+k^2+\cdots+k^{h-1}
=\frac{k^h-1}{k-1}.
\]

要使结点数最少，应只保留一条长度为 \(h-1\) 的根到叶路径。沿这条路径在第 \(0\) 层到第 \(h-2\) 层共有 \(h-1\) 个非叶结点；每个非叶结点除了保留路径上的那个孩子外，还必须补足另外 \(k-1\) 个孩子，这些孩子都设为叶子。路径上共有 \(h\) 个结点，额外叶子数为

\[
(h-1)(k-1),
\]

所以最少结点数为

\[
N_{\min}=h+(h-1)(k-1)=k(h-1)+1.
\]

也可以由第 1）问的公式得到：高度为 \(h\) 时非叶结点数至少为 \(h-1\)，而 \(n=km+1\)，所以

\[
N_{\min}=k(h-1)+1.
\]

因此第 2）问答案为：

\[
\boxed{N_{\max}=\frac{k^h-1}{k-1}},\qquad
\boxed{N_{\min}=k(h-1)+1}.
\]

边界情况 \(h=1\) 时，两者都为 1，公式仍然成立。

**易错点**：

- 题5中除以 2 的是“结点编号”，不是结点存的值；最后输出的是 \(T[i]\) 中的值，不是编号 \(i\)。
- 顺序存储根结点编号通常从 1 开始，父结点是 \(\lfloor i/2\rfloor\)；若采用 0 下标存储，则父结点公式应改为 \(\lfloor (i-1)/2\rfloor\)。
- 若一个结点是另一个结点的祖先，循环会返回祖先结点本身，这是“最近公共祖先”的通常约定；若题目特别要求“真祖先”，则还需再输出其父结点。
- 题6计数时不要写成 \(km=n\)，忘记根结点没有父结点；正确关系是“孩子总数 \(=\) 总结点数 \(-1\)”。
- 求最少结点时不能只画一条链，因为每个非叶结点必须补足 \(k\) 个孩子；最少也要 \(k(h-1)+1\) 个结点。
- 求最多结点时不要写成 \(k^h\)，高度 \(h\) 对应 \(h\) 层，等比数列求和到 \(k^{h-1}\)。

**命题规律**：顺序存储二叉树的“编号—父结点”关系是常考点，常与最近公共祖先、判断祖先关系、堆排序等结合；正则 \(k\) 叉树的计数问题则重点考查 \(n-1=\sum \text{孩子数}\) 这一核心公式，以及“最多填满、最少留一条脊柱”的极端形态构造。复习时应熟练掌握：

\[
\text{叶结点数}=1+(k-1)\times \text{非叶结点数},
\]

并会用小例子验证边界，如 \(h=1\)、\(h=2\)、\(m=0\) 等情况。

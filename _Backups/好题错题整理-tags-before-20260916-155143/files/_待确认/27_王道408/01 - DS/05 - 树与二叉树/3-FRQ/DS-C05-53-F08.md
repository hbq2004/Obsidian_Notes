8. 已知二叉树以二叉链表存储，编写算法完成:对于树中每个元素值为$x$的结点，删除以它为根的子树,并释放相应的空间.

## DeepSeek V4 Flash Max 解析

**答案**：采用递归遍历二叉树，遇元素值为 $x$ 的结点就释放以它为根的整棵子树，并将父结点指向它的指针置空；否则继续递归左右子树，时间复杂度为 $O(n)$。

**解题切入点**：拿到题目先定位考点：二叉树链式存储、递归遍历、动态空间释放与指针修改。核心难点有两个：一是“释放整棵子树”必须用后序方式递归释放，防止内存泄漏；二是“删除后要让父结点指针不再指向已释放空间”，所以递归函数必须能修改上层指针，通常用引用或二级指针。可以类比“拆旧楼”：不仅要拆掉楼体（释放子树），还要把进出楼的路封掉（父结点指针置空），否则后续施工会误入废墟。

**推演**：

二叉树结点结构定义为：

```cpp
typedef struct BiTNode {
    int data;
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;
```

先写出释放整棵子树的函数。必须采用后序遍历，先释放左右孩子，再释放根结点：

```cpp
void FreeTree(BiTree T) {
    if (T == NULL) return;
    FreeTree(T->lchild);
    FreeTree(T->rchild);
    free(T);
}
```

然后实现删除函数。关键思想：若当前结点值为 $x$，直接释放整棵子树，并让当前指针变为 `NULL`；否则递归处理左右子树。由于需要修改实参指针，C++ 中用引用，C 中用二级指针。以 C++ 引用为例：

```cpp
void DeleteX(BiTree &T, int x) {
    if (T == NULL) return;
    if (T->data == x) {
        FreeTree(T);
        T = NULL;          // 关键：使父结点指针置空
    } else {
        DeleteX(T->lchild, x);
        DeleteX(T->rchild, x);
    }
}
```

若使用 C 语言，则参数写成二级指针：

```c
void DeleteX(BiTree *T, int x) {
    if (*T == NULL) return;
    if ((*T)->data == x) {
        FreeTree(*T);
        *T = NULL;
    } else {
        DeleteX(&(*T)->lchild, x);
        DeleteX(&(*T)->rchild, x);
    }
}
```

执行过程分析：假设原树根结点不是 $x$，则先递归删除左子树中所有值为 $x$ 的子树，再递归删除右子树中所有值为 $x$ 的子树。若某孩子结点值为 $x$，在递归调用中会释放以该孩子为根的整棵子树，并将该孩子指针置空，因此原树中不会残留指向已释放空间的指针。若根结点本身就是 $x$，则整个二叉树被释放，根指针变为 `NULL`。若某个值为 $x$ 的结点是另一个值为 $x$ 的结点的祖先，则祖先被释放时，连同后裔一起释放，后裔无需再单独处理，这正好符合“删除以它（们）为根的子树”的要求。

正确性可用归纳法说明：对任意以 $T$ 为根的树，算法结束后，所有元素值为 $x$ 的结点及其子孙均被释放且不再被引用，其余结点仍保持原来的树形结构。若 $T$ 为空，显然成立；若 $T$ 的值为 $x$，释放整棵子树，成立；若 $T$ 的值不是 $x$，由归纳假设，左右子树中值为 $x$ 的子树都被删除，而 $T$ 本身保留，因此整体满足要求。

时间复杂度：每个结点至多被访问常数次（要么在 `DeleteX` 中被检查，要么在 `FreeTree` 中被释放），故为 $O(n)$。空间复杂度为递归栈深度，最坏情况树退化为单链时为 $O(n)$，平均为 $O(\log n)$。

**易错点**：

1. **忘记置空父结点指针**：仅释放结点但未将 `T` 置空，导致父结点仍指向已释放空间，后续遍历或释放时产生“悬垂指针”。必须使用引用或二级指针，并在释放后赋 `NULL`。
2. **释放顺序错误**：若先释放根结点再释放孩子，会访问已释放内存。释放子树必须用后序遍历。
3. **对值为 $x$ 的结点继续递归**：如果释放了以当前结点为根的子树后，继续递归访问 `T->lchild`、`T->rchild`，就会操作已释放空间。应在 `T->data == x` 时直接返回。
4. **参数传递使用一级指针**：在函数内修改形参指针不会影响实参，父结点指针无法置空。C 语言必须用 `BiTree *T`，C++ 可用引用 `BiTree &T`。
5. **忽略空树**：递归或释放前不判断空指针，导致程序崩溃。
6. **内存泄漏**：只 `free(T)` 而不递归释放孩子，或忘记释放值为 $x$ 的结点的子孙结点。`FreeTree` 必须完整释放整棵子树。

**命题规律**：本题属于二叉树的递归操作类综合题，在 408 中常与遍历、指针修改、动态内存管理结合考查。常见的变式有：删除树中所有叶结点；删除所有值为 $x$ 的结点并将其左、右子树分别接入原树；释放整棵二叉树；求满足某条件的子树等。复习时需熟练掌握递归遍历框架，重点理解引用/二级指针在修改树结构时的作用，并能清晰写出“释放子树”和“更新父指针”的配合代码。平时可多练习递归函数的设计思路：先想清楚“递归边界”和“本层做什么”，再写代码。

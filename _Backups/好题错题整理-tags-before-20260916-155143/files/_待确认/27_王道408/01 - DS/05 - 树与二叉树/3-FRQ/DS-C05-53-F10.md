# 综合题 第 10 题

![[_Attachments/题目识别/27_王道408-题目/DS-C05-53-F10_题目.png|题目]]

10. 设一棵二叉树的结点结构为$(LLINK, INFO, RLINK)$，$ROOT$为指向该二叉树根结点的指针，$p$ 和 $q$ 分别为指向该二叉树中任意两个结点的指针，试编写算法 $ANCESTOR(ROOT, p, q, r)$，找到 $p$ 和 $q$ 的最近公共祖先结点 $r$.

## DeepSeek V4 Flash Max 解析

**答案**：采用递归的二叉树遍历（后序/DFS），在左右子树中分别查找 $p$、$q$；若左右两边均找到目标，则当前结点为最近公共祖先；否则返回非空的一边；若当前结点等于 $p$ 或 $q$ 则直接返回该结点。时间复杂度 $O(n)$，空间 $O(h)$。

**解题切入点**：拿到题目先明确“最近公共祖先”（LCA）的定义——深度最大的同时是 $p$、$q$ 祖先的结点。由于二叉树结点只有左右孩子指针、没有父指针，要确定祖先关系只能从根开始遍历。联想到“两条从根出发的路径最后一个共同结点”模型，而递归回溯天然能获得“从下往上”的祖先信息。类似做“链表的第一个公共结点”，但这里树的分叉多，所以用递归的左右子树返回值来合并信息。

**推演**：  
设二叉树结点类型为
```c
typedef struct BTNode {
    int info;                    // INFO
    struct BTNode *llink, *rlink; // LLINK, RLINK
} BTNode;
typedef BTNode *BiTree;
```

直接实现题目要求的算法：
```c
void ANCESTOR(BiTree root, BiTree p, BiTree q, BiTree *r) {
    // 基本情况：空结点，或当前结点就是 p/q 之一
    if (root == NULL || root == p || root == q) {
        *r = root;
        return;
    }
    BiTree left = NULL, right = NULL;
    // 在左、右子树中分别递归查找
    ANCESTOR(root->llink, p, q, &left);
    ANCESTOR(root->rlink, p, q, &right);
    if (left != NULL && right != NULL)
        *r = root;          // p、q 分居两侧，当前结点是 LCA
    else
        *r = left != NULL ? left : right;
}
```

正确性证明：  
定义函数的效果：将以 $root$ 为根的子树的求解结果写入 $r$。具体而言，若 $p$、$q$ 都在该子树中，$r$ 为它们的最近公共祖先；若只有一个目标在该子树中，$r$ 为该目标结点；若一个也没有，$r$ 为 NULL。  
- 若 $root$ 为 NULL，则子树不含目标，$r=NULL$。  
- 若 $root==p$ 或 $root==q$，则当前结点就是已找到的目标。若另一个目标也在此子树中，$root$ 必为它的祖先，因此 $root$ 就是最近公共祖先；若另一个目标不在当前子树，则先返回 $root$ 向上传递。  
- 否则递归处理左右子树。若左、右返回值均非空，说明 $p$、$q$ 分别位于 $root$ 的左右子树中，此时任何更深层的结点都不可能同时成为它们俩的祖先，故 $root$ 是最近公共祖先。若仅一边非空，说明两个目标都在那一边，答案就是那边递归得到的结果。  
由于题目保证 $p$、$q$ 在原树中，最终递归一定能返回正确结点。

时间复杂度：每个结点最多访问一次，故 $O(n)$，其中 $n$ 为结点数；递归栈深度为树高 $h$，空间复杂度 $O(h)$，最坏（链状树）为 $O(n)$。

若要求非递归实现，可先用栈进行后序遍历，分别得到从根到 $p$、$q$ 的路径，再从根开始比较两条路径，最后一个相同的结点即为 LCA。递归法在思想上与非递归路径法一致，但编码更简洁。

**易错点**：
1. 在 $root==p$ 或 $root==q$ 时继续向下搜索，导致重复访问或逻辑错误；应当直接返回。
2. 忘记处理 $root==\text{NULL}$，造成空指针解引用。
3. 当 $left$ 和 $right$ 均非空时，错误地返回 $left$ 或 $right$，而应返回当前 $root$。
4. 输出参数 $r$ 若按值传递，则无法把结果带出函数；应使用指针的指针（如 `BiTree *r`）或 C++ 引用（`BiTree &r`）。
5. 若 $p$ 或 $q$ 不在树中，递归法可能返回非预期结点；本题保证 $p$、$q$ 均为树中结点，故无需额外验证。

**命题规律**：
- 考点定位：二叉树的遍历、递归回溯、栈的应用；是 408 常考综合题。
- 常见变式：① 求二叉树中两个结点的路径；② 判断某结点是否为另一结点的祖先；③ 求一个结点的所有祖先；④ 在二叉排序树中求 LCA（可利用大小关系优化）；⑤ 三叉链表（带父指针）中求 LCA；⑥ 二叉树中距离最远的两个结点（常与 LCA 关联）。
- 复习建议：理解“递归返回值的语义”是二叉树算法题的关键；熟练书写三种遍历及非递归版本；掌握用栈或递归保存“从根到某结点路径”的技巧；做题时先画小树验证边界情况，再写代码。

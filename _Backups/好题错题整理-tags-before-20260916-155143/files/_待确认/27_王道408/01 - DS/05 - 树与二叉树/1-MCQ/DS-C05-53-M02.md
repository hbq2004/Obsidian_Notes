# 选择题 第 2 题

![[_Attachments/题目识别/27_王道408-题目/DS-C05-53-M02_题目.png|题目]]

2. 在任何一棵二叉树中, 若结点$a$有左孩子$b$、右孩子$c$, 则在结点的先序序列、中序序列、后序序列中, ( ).

(A) 结点$b$一定在结点$a$的前面

(B) 结点$a$一定在结点$c$的前面

(C) 结点$b$一定在结点$c$的前面

(D) 结点$a$一定在结点$b$的前面

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C05-53-M02_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 C。在任何二叉树中，若结点 $a$ 有左孩子 $b$、右孩子 $c$，则在先序、中序、后序三种遍历序列中，$b$ 都一定在 $c$ 的前面。

**解题切入点**：先抓住“三种遍历 + 结点相对位置”这个特征，定位到二叉树遍历的递归顺序。可以这样想：不管哪种遍历，都是“根”和“左、右子树”的递归排列，而左子树整体一定先于右子树整体被访问；因此左孩子 $b$ 与右孩子 $c$ 的相对顺序是三种遍历的“不变量”。

**推演**：

设以 $a$ 为根的局部结构为：

- 左孩子是 $b$；
- 右孩子是 $c$。

三种遍历的递归顺序是：

- 先序：根、左子树、右子树；
- 中序：左子树、根、右子树；
- 后序：左子树、右子树、根。

用代码表示就是：

```cpp
// 先序遍历
pre(T) { visit(T); pre(T->l); pre(T->r); }

// 中序遍历
in(T)  { in(T->l); visit(T); in(T->r); }

// 后序遍历
post(T){ post(T->l); post(T->r); visit(T); }
```

无论哪种遍历，对左子树的递归调用都发生在对右子树的递归调用之前。因此，以 $b$ 为根的左子树中所有结点一定在以 $c$ 为根的右子树中所有结点之前出现，特别地：

$$
b \text{ 一定在 } c \text{ 之前出现}
$$

具体到三种序列，相对先后关系为：

| 遍历方式 | 相对顺序 |
|---|---|
| 先序 | $a$ 先于 $b$，$b$ 先于 $c$ |
| 中序 | $b$ 先于 $a$，$a$ 先于 $c$ |
| 后序 | $b$ 先于 $c$，$c$ 先于 $a$ |

逐项检查选项：

| 选项 | 先序 | 中序 | 后序 |
|---|---|---|---|
| A：$b$ 在 $a$ 前 | 否 | 是 | 是 |
| B：$a$ 在 $c$ 前 | 是 | 是 | 否 |
| C：$b$ 在 $c$ 前 | 是 | 是 | 是 |
| D：$a$ 在 $b$ 前 | 是 | 否 | 否 |

所以，只有 C 在三种遍历序列中都必然成立。

**易错点**：

1. 只看先序，容易误选 D 或 B，但中序和后序不满足。
2. 只看后序，容易误选 A，但先序不满足。
3. 注意 $b$ 和 $c$ 不一定紧挨着，它们之间可能有各自子树的其他结点；题目只要求“一定在前面”，不要求相邻。
4. 解题时应把“左子树整体”和“右子树整体”看成两个先后访问的块，而不是只盯着 $a,b,c$ 三个孤立结点。

**命题规律**：

这是二叉树遍历的经典选择题，考查三种遍历的递归访问顺序，尤其是“左子树先于右子树”这一不变性质。常见变式有：判断某结点与其左/右孩子、祖先、后代在不同遍历序列中的位置；给出两种遍历序列反推二叉树；给出若干序列判断哪些可能是某种遍历结果。复习时建议把三种遍历的递归框架写熟，并养成画“根—左—右”局部图再逐项排除的习惯。

# 选择题 第 15 题

![[_Attachments/题目识别/27_王道408-题目/DS-C05-55-M15_题目.png|题目]]

15.【2014统考真题】5个字符有如下4种编码方案，不是前缀编码的是（）.
A. 01,0000,0001,001,1
B. 011,000,001,010,1
C. 000,001,010,011,100
D. 0,100,110,1110,1100

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C05-55-M15_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D 选项 $\{0,100,110,1110,1100\}$ 不是前缀编码，因为码字 $110$ 是码字 $1100$ 的前缀，违反了前缀编码的定义。

**解题切入点**：拿到题目先明确“前缀编码”的定义：任一码字都不是另一个码字的前缀。判断时可先按码字长度排序，优先检查短码字是否为长码字的前缀；或像建立字典树（Trie）一样，观察是否存在“某条路径走到了某个叶子结点后，又继续向下延伸出其他码字”。若出现“短码能在长码开头完全匹配”，则立即判定不是前缀编码。

**推演**：前缀编码要求集合中任意两个不同码字 $a$、$b$，都不满足 $a$ 是 $b$ 的前缀，或 $b$ 是 $a$ 的前缀。逐一检验各选项：

- **A**：$\{01,0000,0001,001,1\}$  
  码字 $1$ 与其他码字首字符不同，不可能成为其他码字的前缀；$01$ 与 $0000,0001,001$ 的首位均为 $0$，但第二位分别为 $1$ 和 $0$，不同，所以 $01$ 不是它们的前缀；$0000,0001,001$ 之间前两位相同，但第三位分别为 $0,0,1$，需要检查：$0000$ 与 $0001$ 前三位都是 $000$，第四位不同，不是前缀；$0000$ 与 $001$ 第三位不同，不是前缀；$0001$ 与 $001$ 第三位不同，也不是前缀。因此 A 是前缀编码。

- **B**：$\{011,000,001,010,1\}$  
  码字 $1$ 与其他码字首字符不同，不构成前缀关系。其余四个码字均为三位，且 $000$ 与 $001$ 前两位相同但第三位不同；$010$ 与 $011$ 前两位相同但第三位不同；$000$ 与 $010$、$011$ 第二位不同；$001$ 与 $010$、$011$ 第二位不同。任意两码字不存在“较短码等于较长码的前缀”，因为长度相同，若不同则不可能互为前缀。因此 B 是前缀编码。

- **C**：$\{000,001,010,011,100\}$  
  5 个码字长度均为 3。对于两个不同且等长的码字，一个码字不可能成为另一个码字的前缀（前缀要求长度严格小于或等于对方，等长时只有完全相同才可能）。因此 C 是前缀编码。

- **D**：$\{0,100,110,1110,1100\}$  
  码字 $0$ 与其他码字首字符不同，不构成前缀关系；$100$ 与 $110$ 第二位不同；$110$ 与 $1110$ 前两位相同，但第三位分别为 $0$ 和 $1$，不同，所以 $110$ 不是 $1110$ 的前缀；然而 $110$ 与 $1100$ 前三位完全相同，即 $110$ 是 $1100$ 的前缀。因此存在一个码字是另一个码字的前缀，D 不是前缀编码。

综上，不是前缀编码的是 **D**。

**易错点**：  
1. 只比较码字是否相同，忽略了“前缀”是从第一个字符开始的连续匹配。例如 $100$ 出现在 $1100$ 中，但 $100$ 不是 $1100$ 的前缀，因为 $1100$ 的前三位是 $110$。  
2. 看到 D 中 $0,100,110,1110,1100$ 都不同就误判为前缀编码，必须专门检查短码与长码开头的关系。  
3. 对前缀编码的理解偏差：前缀码并不要求所有码字长度相等，因此检查时必须穷举短码与所有更长码字的开头匹配情况。建议用“按长度从小到大排序，逐个比较”的方法避免遗漏。

**命题规律**：本题属于“字符串编码与哈夫曼树”基础考点，常以选择题或综合题形式出现。常见变式包括：  
- 给定字符出现频率，构造哈夫曼树并写出前缀编码；  
- 判断一组编码是否能作为某个哈夫曼编码；  
- 根据前缀编码构造二叉树，并要求计算 WPL。  
复习时应深刻理解前缀编码与二叉树叶子结点的对应关系：任一码字都对应二叉树中的一个叶子结点，若某个结点是另一个结点的祖先，则违反前缀编码规则。掌握“建 Trie 树判前缀”的方法，可快速解决此类问题。

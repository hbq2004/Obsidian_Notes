# 选择题 第 14 题

![[_Attachments/题目识别/27_王道408-题目/DS-C05-55-M14_题目.png|题目]]

14.【2010统考真题】 $n(n\geq2)$ 个权值均不相同的字符构成哈夫曼树，关于该树的叙述中，错误的是 ( )
A. 该树一定是一棵完全二叉树
B. 树中一定没有度为 1 的结点
C. 树中两个权值最小的结点一定是兄弟结点
D. 树中任意一个非叶结点的权值一定不小于下一层任意一个结点的权值

## DeepSeek V4 Flash Max 解析

**答案**：错误的是 **A**。哈夫曼树是带权路径长度最小的二叉树，但不一定满足完全二叉树“逐层从左到右排满”的形态；B、C、D 均为哈夫曼树的基本性质。

**解题切入点**：先定位考点为“哈夫曼树的构造与性质”。可以把哈夫曼树的构造看成贪心算法中“每次从优先队列里取两个最小权值合并”的过程；不要一看到“二叉树”就联想到完全二叉树或堆。优先队列只保证合并时权值最小，不保证树的层次形态一定“排满”。对含“一定”的选项，优先用一个合法反例去检验。

**推演**：设 \(n\) 个字符的权值分别为 \(w_1,w_2,\dots,w_n\)，且两两不同。哈夫曼树的构造规则是：每次取当前权值最小的两棵树合并，新结点的权值为二者权值之和。

- **B 正确**：每次合并产生的结点都有且仅有两个孩子；初始叶子结点度为 0。因此哈夫曼树中没有度为 1 的结点。

- **C 正确**：第一次合并时，森林中只有原来的 \(n\) 个叶子结点，且权值互不相同，所以权值最小的两个字符一定被选中合并，成为同一个新结点的左右孩子，因此它们是兄弟结点。

- **D 正确**：设任一非叶结点 \(u\) 的左右孩子为 \(x,y\)，则有
  \[
  w(u)=w(x)+w(y).
  \]
  权值非负，所以
  \[
  w(u)\ge w(x),\qquad w(u)\ge w(y).
  \]
  这里“下一层”指该非叶结点的孩子层，因此该非叶结点的权值一定不小于其下一层任一结点的权值。

- **A 错误**：举一反例。例如权值为 \(1,2,4,5\) 的 4 个字符：

  1. 合并 \(1,2\)，得权值 \(3\) 的结点；
  2. 合并 \(3,4\)，得权值 \(7\) 的结点；
  3. 合并 \(5,7\)，得根结点权值 \(12\)。

  树形为：

  ```
          12
         /  \
        5    7
            / \
           3   4
          / \
         1   2
  ```

  这棵哈夫曼树中，深度为 2 的层只有两个结点，而深度为 3 仍有叶子结点，不符合完全二叉树“除最后一层外逐层排满，且最后一层结点靠左连续”的要求。因此哈夫曼树不一定是完全二叉树，A 错误。

**易错点**：  
- 不要把哈夫曼树与完全二叉树、平衡二叉树混淆。哈夫曼树只保证带权路径长度最小，不保证形态层满。  
- 原字符权值互不相同，但哈夫曼构造中内部结点的权值可能等于某个叶子权值，这是合法的，不能因此误判。  
- 对 D 中的“下一层”要理解为“该非叶结点的孩子层”，不要误解成整棵树的下一层。  
- 选项中含“一定”时，只要找到一个合法反例即可否定该选项。

**命题规律**：本题是 408 选择题中的基础概念题，考点为哈夫曼树性质。常见变式有：给定一组权值求哈夫曼树和 WPL、判断哈夫曼树相关说法正误、结合哈夫曼编码求平均码长、与前缀码和贪心策略结合。复习时应熟练掌握“每次取两个最小权值合并”的构造过程，并用小规模例子验证抽象结论。

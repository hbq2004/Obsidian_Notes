# 选择题 第 28 题

![[_Attachments/题目识别/27_王道408-题目/DS-C05-53-M28_题目.png|题目]]

28. 若 $X$ 是二叉中序线索树中一个有左孩子的结点, 且 $X$ 不为根, 则 $X$ 的前驱为 ( ).
(A) $X$ 的双亲
(B) $X$ 的右子树中最左的结点
(C) $X$ 的左子树中最右的结点
(D) $X$ 的左子树中最右的叶结点

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C05-53-M28_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 C。$X$ 的中序前驱是 $X$ 的左子树中最右的结点，即左子树中序序列的最后一个结点；不是双亲，也不一定是左子树中最右的叶结点。

**解题切入点**：
拿到题先不要被“线索”二字带偏，先回到中序遍历定义。前驱不是树形上的父结点，而是**中序序列中紧挨在 $X$ 前面的结点**。树上定位方法可以记为：  
“先往左下走一步，再一直往右下走到不能走为止。”  
这与二叉搜索树中找前驱的思路一致。

**推演**：
设 $X$ 的左子树为 $L$，右子树为 $R$。中序遍历顺序为：
$$
\text{Inorder}(X)=\text{Inorder}(L)+[X]+\text{Inorder}(R)
$$
因此 $X$ 的前驱就是 $\text{Inorder}(L)$ 的最后一个结点。

对任意非空子树 $S$，设其左右子树为 $S_L,S_R$，则：
$$
\text{last}(S)=
\begin{cases}
\text{last}(S_R), & S_R\neq\varnothing,\\
root(S), & S_R=\varnothing.
\end{cases}
$$
所以求 $L$ 的中序最后一个结点，就是从 $L$ 的根开始，只要还有右孩子就一直向右走，最后停下的结点就是 $X$ 的前驱。这个结点正是“$X$ 的左子树中最右的结点”。

例如：
```
      P
     /
    X
   /
  A
 /
B
```
中序序列为 $B,A,X,P$，$X$ 的前驱是 $A$。这里 $A$ 不是叶结点，所以“最右的叶结点”不正确。

线索树中的关键代码如下：

```
p = X->lchild;              // X 有左孩子，ltag = 0
while (p->rtag == 0)        // 还有真实右孩子
    p = p->rchild;
return p;                   // p 即 X 的中序前驱
```

选项辨析：

- A：双亲不一定是中序前驱。
- B：$X$ 的右子树中最左的结点是中序后继，不是前驱。
- C：正确。
- D：右行到底的结点不一定为叶，可能还有左孩子。

条件“$X$ 不为根”只是为了让“双亲”这个干扰项有对象，对中序前驱的判定没有影响。

**易错点**：
1. 把前驱/后继与父子关系混淆。中序前驱只取决于左子树，与双亲无关。
2. 把前驱与后继弄反。右子树最左结点是后继。
3. 误选 D。中序前驱是“左子树中最右结点”，不要求是叶结点。
4. 在线索树中忽略线索标志。$X$ 有左孩子意味着 $ltag=0$，不能直接用左线索，而要进入左子树向右下找。

**命题规律**：
考点是中序线索二叉树中找前驱/后继。常见变式有：求中序后继、根据线索标志判断指针是孩子还是线索、给一棵具体二叉树写出某结点的前驱/后继、在前序或后序线索树中讨论前驱后继。复习时应以三种遍历序列的定义为准，画图记忆：中序前驱“左下后右到底”，中序后继“右下后左到底”，同时注意 $ltag/rtag$ 的作用。

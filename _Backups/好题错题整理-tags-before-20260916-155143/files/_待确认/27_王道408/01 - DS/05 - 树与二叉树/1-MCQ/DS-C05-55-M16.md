# 选择题 第 16 题

![[_Attachments/题目识别/27_王道408-题目/DS-C05-55-M16_题目.png|题目]]

16. 【2015 统考真题】下列选项给出的是从根分别到达两个叶结点路径上的权值序列，能属于同一棵哈夫曼树的是 ( )。
A. 24,10,5 和 24,10,7
B. 24,10,5 和 24,12,7
C. 24,10,10 和 24,14,11
D. 24,10,5 和 24,14,6

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C05-55-M16_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 D。$24,10,5$ 和 $24,14,6$ 可以出现在同一棵哈夫曼树中，对应叶子权值集合 $\{5,5,6,8\}$ 构造出的哈夫曼树；其余选项均违背“父结点权值等于两孩子权值之和”。

**解题切入点**：  
看到“从根到两个叶结点路径上的权值序列”，先不要盲目构造整棵树。哈夫曼树是严格二叉树，任意内部结点都满足：
$$
w(\text{父})=w(\text{左孩子})+w(\text{右孩子}).
$$
因此把每条路径看成“父 $\to$ 子”的相邻片段，逐段检查相邻权值是否满足“父权 = 两子权之和”；若某段出现父权不大于子权，或无法找到正的兄弟权值，就排除。最后再用哈夫曼算法的合并过程验证候选选项。

**推演**：

每条序列形如 $(\text{根},\ \text{中间结点},\ \text{叶})$。例如 $24,10,5$ 表示根为 $24$，根的一个孩子为 $10$，该孩子的一个叶子孩子为 $5$。若某个内部结点权值为 $p$，其中一个孩子权值为 $c$，则另一个孩子权值必为 $p-c>0$。

逐项判断：

- **A**：$24,10,5$ 与 $24,10,7$  
  若两个 $10$ 是根的两个不同孩子，则根的两个孩子权值都为 $10$，根权值应为 $10+10=20\ne24$，矛盾。  
  若两个 $10$ 是同一个结点，则该结点下两个孩子分别是 $5$ 和 $7$，其权值应为 $5+7=12\ne10$，矛盾。  
  因此 A 不可能。

- **B**：$24,10,5$ 与 $24,12,7$  
  根的两个孩子权值分别为 $10$ 和 $12$，则根权值应为 $10+12=22\ne24$，矛盾。  
  因此 B 不可能。

- **C**：$24,10,10$ 与 $24,14,11$  
  根的孩子权值 $10$ 和 $14$ 之和为 $24$，根这一层满足。但看 $24,10,10$：父结点权值为 $10$，孩子权值也为 $10$，则另一个孩子权值必须为 $10-10=0$，而哈夫曼树的叶权值必须为正，矛盾。  
  因此 C 不可能。

- **D**：$24,10,5$ 与 $24,14,6$  
  根的孩子为 $10$、$14$，满足 $10+14=24$。  
  对结点 $10$，孩子 $5$ 的兄弟权值为 $10-5=5$；  
  对结点 $14$，孩子 $6$ 的兄弟权值为 $14-6=8$。  
  于是叶子权值集合可为 $\{5,5,6,8\}$。按哈夫曼算法构造：
  $$
  \{5,5,6,8\}
  \xrightarrow{5+5=10}
  \{6,8,10\}
  \xrightarrow{6+8=14}
  \{10,14\}
  \xrightarrow{10+14=24}
  \{24\}.
  $$
  对应树为：根 $24$ 的两个孩子为 $10$、$14$；$10$ 的孩子为 $5$、$5$；$14$ 的孩子为 $6$、$8$。  
  因此从根到叶 $5$ 的路径为 $24,10,5$，从根到叶 $6$ 的路径为 $24,14,6$，二者属于同一棵哈夫曼树。

所以选 **D**。

**易错点**：  
1. 只检查根的孩子之和，不检查中间结点。例如 C 根满足 $10+14=24$，但 $10$ 作为父结点时出现 $10=10+0$，仍不可能。  
2. 把两个相同的权值 $10$ 误认为是同一个结点。A 中要先排除“两个 $10$ 是根的两个孩子”的情况，但该情况也会因根权值不对而失败。  
3. 忘记哈夫曼树是严格二叉树：根和每个内部结点都必须恰好有两个孩子，不能通过“根还有第三个孩子”来凑数。  
4. 选 D 后最好用哈夫曼算法模拟一遍，确认不是只满足局部关系；局部关系是必要条件，但 D 能实际构造出来。

**命题规律**：  
该题属于“哈夫曼树性质”的经典选择题，核心是把哈夫曼树抽象为“父权 = 两子权之和”的严格二叉树。常见变式有：给出若干条根到叶路径判断是否同属一棵哈夫曼树；给出叶权值求哈夫曼编码或带权路径长度；给出编码集合判断是否为合法哈夫曼编码。复习时应熟练掌握 Huffman 算法的合并过程，并能从树中反推结点权值关系；遇到路径序列题，先找父子权值约束矛盾，再用构造或编码验证。

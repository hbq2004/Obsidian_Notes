# 选择题 第 15 题

![[_Attachments/题目识别/27_王道408-题目/DS-C05-54-M15_题目.png|题目]]

15.【2009 统考真题】将森林转换为对应的二叉树, 若在二叉树中, 结点 $u$ 是结点 $v$ 的父结点的父结点, 则在原来的森林中, $u$ 和 $v$ 可能具有的关系是 ( )。
I. 父子关系
II. 兄弟关系
III. $u$ 的父结点与 $v$ 的父结点是兄弟关系
(A) 只有 $II$
(B) $I$ 和 $II$
(C) $I$ 和 $III$
(D) $I$、$II$ 和 $III$

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C05-54-M15_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 **(B) $I$ 和 $II$**。在原来的森林中，$u$ 与 $v$ 可能是父子关系，也可能是兄弟关系；不可能出现“$u$ 的父结点与 $v$ 的父结点是兄弟关系”。

**解题切入点**：  
先把“二叉树中 $u$ 是 $v$ 的父结点的父结点”翻译为一条长度为 $2$ 的祖先路径：设 $v$ 在二叉树中的父结点为 $p$，则二叉树中有 $u\to p\to v$。森林转二叉树的规则是“左孩子右兄弟”：左指针连长子，右指针连下一个兄弟（森林相邻树根也按兄弟链连接）。因此只需枚举这两条指针的左右方向组合，就能还原原森林关系。

**推演**：  
记 $a\xrightarrow{L}b$ 表示 $b$ 是 $a$ 的左孩子，$a\xrightarrow{R}b$ 表示 $b$ 是 $a$ 的右孩子。

- $a\xrightarrow{L}b$：$b$ 是 $a$ 在原森林中的长子，所以 $a$ 是 $b$ 的原森林父结点。
- $a\xrightarrow{R}b$：$b$ 是 $a$ 在原森林中的下一个兄弟；若是森林根，则相邻树根之间也按兄弟链处理。

于是对 $u\to p\to v$ 分情况：

| 二叉树路径 | 原森林中的关系 | 对应题支 |
|---|---|---|
| $u\xrightarrow{L}p\xrightarrow{L}v$ | $u$ 是 $v$ 的祖父（祖孙关系） | 题支未列 |
| $u\xrightarrow{L}p\xrightarrow{R}v$ | $p$ 是 $u$ 的儿子，$v$ 是 $p$ 的弟弟，所以 $u$ 是 $v$ 的父亲 | I |
| $u\xrightarrow{R}p\xrightarrow{L}v$ | $u$ 与 $p$ 是兄弟，$p$ 是 $v$ 的父亲，所以 $u$ 与 $v$ 是叔侄关系 | 题支未列 |
| $u\xrightarrow{R}p\xrightarrow{R}v$ | $u,p,v$ 在同一兄弟链上，$u$ 与 $v$ 是兄弟 | II |

例如：

- I 可能：原森林中 $u$ 有长子 $p$ 和次子 $v$，转换后为 $u\xrightarrow{L}p\xrightarrow{R}v$。
- II 可能：原森林中同一父亲有 $u,p,v$ 三个儿子，长幼顺序为 $u,p,v$，转换后为 $u\xrightarrow{R}p\xrightarrow{R}v$。

III 要求“$u$ 的父结点与 $v$ 的父结点是兄弟”，即 $u$ 和 $v$ 是同辈但不同父的堂/表兄弟。上表四种情况均不会得到这种关系，因此 III 不可能。

注：表中还可能出现题支未列的祖孙、叔侄关系；本题只判断 I、II、III 三个说法能否成立，不是把所有可能关系全部列在选项中，因此不影响答案。

**易错点**：  
1. 把二叉树的右孩子误认为原森林中的儿子。右孩子实际是“弟弟/相邻树根”，不是儿子。  
2. II 需要有中间兄弟 $p$。若 $u,v$ 是相邻兄弟，则二叉树中 $u$ 是 $v$ 的父结点，不是祖父，不符合题意。  
3. 容易把“$u$ 是 $v$ 的叔父”与 III 混淆。表中的 $u\xrightarrow{R}p\xrightarrow{L}v$ 是叔侄关系，不是“双方的父结点是兄弟”。  
4. 森林根之间用右链连接，属于兄弟链而不是父子链；若结点是树根，则它在原森林中没有父结点，更不可能满足 III。

**命题规律**：  
本题属于“树、森林与二叉树转换”的经典考点，核心是“孩子兄弟表示法”。命题时常给出二叉树中两个结点的祖先/距离关系，反推原森林中的关系；也可与树的遍历对应关系、叶子数/度数等结合考查。复习时把“左孩子 $=$ 长子，右孩子 $=$ 兄弟”画熟，遇到这类题先枚举左右方向组合即可。

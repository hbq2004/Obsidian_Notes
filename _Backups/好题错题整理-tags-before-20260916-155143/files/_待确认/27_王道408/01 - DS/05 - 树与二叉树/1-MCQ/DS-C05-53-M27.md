# 选择题 第 27 题

![[_Attachments/题目识别/27_王道408-题目/DS-C05-53-M27_题目.png|题目]]

27. 二叉树在线索化后，仍不能有效求解的问题是 ( ).

A. 先序线索二叉树中求先序后继
B. 中序线索二叉树中求中序后继
C. 中序线索二叉树中求中序前驱
D. 后序线索二叉树中求后序后继

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C05-53-M27_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 D。后序线索二叉树中求后序后继需要向上找双亲，不能仅靠线索有效求解。

**解题切入点**：拿到题先判断“当前结点在对应遍历序列中，相对于自己的子树处于什么位置”。  
先序是“根左右”，根最先访问，所以先序后继容易在子树内找；中序是“左根右”，前驱、后继分别向左、右子树找，也容易；后序是“左右根”，根最后访问，因此某结点的后序后继在它的子树之外，必须回溯到双亲。可以类比：线索只给了局部的“下一站”指针，若下一站在父结点方向，而没有父指针，线索就“断了”。

**推演**：

线索二叉树中约定：

- $\mathrm{ltag}=0$：左孩子指针指向左孩子；$\mathrm{ltag}=1$：左孩子指针指向前驱线索。
- $\mathrm{rtag}=0$：右孩子指针指向右孩子；$\mathrm{rtag}=1$：右孩子指针指向后继线索。

A. 先序线索二叉树中求先序后继：可以。

先序序列为“根、左、右”。若 $p$ 有左孩子，则 $p$ 的后继一定是 $p$ 的左孩子；若 $p$ 无左孩子，则后继为 $p$ 的右孩子或右线索。

```c
if (p->ltag == 0)
    return p->lchild;
else
    return p->rchild;
```

所以先序后继可以 $O(1)$ 有效求解。

B. 中序线索二叉树中求中序后继：可以。

中序序列为“左、根、右”。若 $p$ 无右孩子，则 $p\to rchild$ 就是后继线索；若 $p$ 有右孩子，则后继是 $p$ 右子树中最左下的结点。

```c
if (p->rtag == 1)
    return p->rchild;

q = p->rchild;
while (q->ltag == 0)
    q = q->lchild;
return q;
```

C. 中序线索二叉树中求中序前驱：可以。

若 $p$ 无左孩子，则 $p\to lchild$ 就是前驱线索；若 $p$ 有左孩子，则前驱是 $p$ 左子树中最右下的结点。

```c
if (p->ltag == 1)
    return p->lchild;

q = p->lchild;
while (q->rtag == 0)
    q = q->rchild;
return q;
```

D. 后序线索二叉树中求后序后继：不能有效求解。

后序序列为“左、右、根”。$p$ 是以 $p$ 为根的子树的最后一个被访问结点，所以 $p$ 的后继一定在 $p$ 的子树之外。要求后序后继，必须知道 $p$ 的双亲；而普通线索二叉树没有父指针。

若 $p$ 无右孩子，其 $rchild$ 可以作为后序后继线索，这一特例可以直接得到；但若 $p$ 有右孩子，则 $p\to rchild$ 被右孩子占用，无法存放后继线索。此时需要分情况：

- 若 $p$ 是根，则后继为空；
- 若 $p$ 是双亲的右孩子，则后继为双亲；
- 若 $p$ 是双亲的左孩子，且双亲无右孩子，则后继为双亲；
- 若 $p$ 是双亲的左孩子，且双亲有右孩子，则后继为双亲右子树在后序下的第一个结点。

这些情况都必须先找到双亲。关键代码如下：

```c
if (p == root)
    return NULL;

if (p->rtag == 1)
    return p->rchild;   // 无右孩子时，右线索可直接给出后继

f = FindParent(root, p);  // 需要额外遍历/栈，效率低

if (f->rchild == p)
    return f;             // p 是右孩子

if (f->rtag == 1)
    return f;             // p 是左孩子，且父无右孩子

// p 是左孩子，且父有右子树
q = f->rchild;
while (q->ltag == 0 || q->rtag == 0) {
    if (q->ltag == 0)
        q = q->lchild;
    else
        q = q->rchild;
}
return q;
```

因此，后序线索树中求后序后继不能仅靠线索有效求解。

综上，答案为 D。

**易错点**：

- 不要误以为“中序线索二叉树只能求中序后继”。实际上中序前驱也可以用左子树最右下结点求解。
- 不要误以为“后序线索二叉树中每个结点的 $rchild$ 都存后继线索”。只有当该结点无右孩子时，$rchild$ 才可能作为线索；有右孩子时，$rchild$ 是右孩子。
- 不要把“后序后继”和“后序前驱”混淆。后序前驱相对简单，而后序后继需要向上找双亲。
- 解题时不能只看左/右孩子是否存在，必须先看 $\mathrm{ltag}$、$\mathrm{rtag}$，避免把线索当成真实孩子。

**命题规律**：本题是线索二叉树的经典概念题，考查“不同遍历序下，线索化后能否高效求前驱/后继”。复习时抓住本质：线索只适合解决“不需要跨子树向上回溯”的情况。常见变式有：给一棵二叉树画出先序/中序/后序线索树；用线索树实现中序遍历；判断某个前驱/后继是否需要双亲指针。类似结论可对比记忆：先序求后继易，中序求前驱和后继都易，后序求后继难。

9. 在有 11 个元素的有序表 $A[1,2,\cdots,11]$ 中进行折半查找 ($\lfloor (low+high)/2 \rfloor$)，查找元素 $A[11]$ 时，被比较的元素下标依次是 ( )。

## DeepSeek V4 Flash Max 解析

**答案**：被比较的元素下标依次是 $6,9,10,11$，故选 **B**。

**解题切入点**：折半查找是“有序表上的二分定位”问题，核心是不断用中点 $\lfloor (low+high)/2 \rfloor$ 划分区间，并根据目标值与中点值的大小关系缩小区间。做题时不要直接背结论，而要“手推比较轨迹”：每次算出 $mid$，比较一次，然后更新 $low$ 或 $high$，直到命中目标。可以把折半查找想象成“猜数字游戏”——每次猜中间数，猜小了往右半区猜，猜大了往左半区猜，记录下每次猜的编号即可。

**推演**：

已知有序表 $A[1..11]$，查找目标为 $A[11]$，初始区间为 $[low, high] = [1, 11]$。

每次取 $mid = \left\lfloor \dfrac{low+high}{2} \right\rfloor$，并将 $A[mid]$ 与目标值 $A[11]$ 比较。由于有序表递增，若 $A[mid] < A[11]$，则目标在右半区间，令 $low = mid + 1$；若 $A[mid] = A[11]$，则找到。

第 1 次比较：
$$
low=1,\ high=11,\quad mid=\left\lfloor \dfrac{1+11}{2} \right\rfloor = 6
$$
比较 $A[6]$ 与 $A[11]$，因为 $6 < 11$，所以 $A[6] < A[11]$，目标在右半区，令：
$$
low = mid + 1 = 7,\quad high = 11
$$

第 2 次比较：
$$
low=7,\ high=11,\quad mid=\left\lfloor \dfrac{7+11}{2} \right\rfloor = 9
$$
比较 $A[9]$ 与 $A[11]$，因为 $9 < 11$，所以 $A[9] < A[11]$，继续向右，令：
$$
low = mid + 1 = 10,\quad high = 11
$$

第 3 次比较：
$$
low=10,\ high=11,\quad mid=\left\lfloor \dfrac{10+11}{2} \right\rfloor = 10
$$
比较 $A[10]$ 与 $A[11]$，因为 $10 < 11$，所以 $A[10] < A[11]$，继续向右，令：
$$
low = mid + 1 = 11,\quad high = 11
$$

第 4 次比较：
$$
low=11,\ high=11,\quad mid=\left\lfloor \dfrac{11+11}{2} \right\rfloor = 11
$$
比较 $A[11]$ 与 $A[11]$，相等，查找成功。

因此，被比较的元素下标依次为：
$$
6,\ 9,\ 10,\ 11
$$

对应选项为 **B**。

若用代码思路表示：

```c
int low = 1, high = 11;
while (low <= high) {
    int mid = (low + high) / 2;   // 即 floor((low+high)/2)
    compare(A[mid], target);      // 记录 mid：6,9,10,11
    if (A[mid] == target) break;
    else if (A[mid] < target) low = mid + 1;
    else high = mid - 1;
}
```

**易错点**：

1. **误把 $mid$ 当成 $(low+high)/2$ 的四舍五入**：本题明确要求 $\lfloor (low+high)/2 \rfloor$，即向下取整。例如 $(10+11)/2 = 10.5$，向下取整得 $10$，不是 $11$。
2. **更新区间时写错边界**：比较后应令 $low = mid+1$ 或 $high = mid-1$。若写成 $low = mid$ 或 $high = mid$，会造成死循环或比较轨迹错误。
3. **忽略“查找元素 $A[11]$”指的是目标位置**：比较的是 $A[mid]$ 与 $A[11]$ 的值，而不是比较下标是否相等。本题中因为元素值有序且目标就是最后一个元素，所以可按下标大小判断。
4. **忘记最后一次比较**：当 $low = high = 11$ 时仍需比较一次，不能提前结束。

**命题规律**：

本知识点属于“查找”章节的折半查找过程分析，是 408 选择题的高频基础题。常见变式包括：

- 给定查找元素，写出比较序列（本题型）；
- 给定比较序列，反推目标元素所在区间或元素个数；
- 计算折半查找的判定树深度、平均查找长度 ASL；
- 考查折半查找的适用条件（顺序存储且有序）。

复习建议：熟练掌握折半查找的判定树画法——每次取中点作为根，左右子树分别对应左右区间；同时牢记向下取整的规则。实际做题时，只需按“取中点、比较、缩区间”三步手动模拟，即可准确写出比较轨迹，避免死记硬背。

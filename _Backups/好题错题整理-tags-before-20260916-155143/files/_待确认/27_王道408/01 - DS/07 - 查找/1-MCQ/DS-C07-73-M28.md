# 选择题 第 28 题

![[_Attachments/题目识别/27_王道408-题目/DS-C07-73-M28_题目.png|题目]]

28.【2013统考真题】 若将关键字 1,2,3,4,5,6,7 依次插入初始为空的平衡二叉树 $T$，则 $T$ 中平衡因子为 0 的分支结点的个数是 ( ).

(A) 0
(B) 1
(C) 2
(D) 3

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C07-73-M28_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 **D**。将关键字 $1,2,3,4,5,6,7$ 依次插入初始为空的平衡二叉树（AVL 树）后，$T$ 成为一棵以 $4$ 为根、完全平衡的二叉树；其中平衡因子为 0 的分支结点为 $4,2,6$，共 **3** 个。

**解题切入点**：这是 AVL 树的插入模拟题。拿到题后不要只看最终关键字序列，而要按“插入 → 检查平衡因子 → 找到最小不平衡子树 → 旋转”的顺序逐步推演。可以类比“搭积木”：每插入一个新结点，就从新结点向上找第一个 $|\mathrm{BF}|=2$ 的结点，把该子树中最关键的中间结点“拎起来”当根，再重新分配左右子树。

**推演**：令空树高度为 $-1$，叶子高度为 $0$，定义
$$
\mathrm{BF}(x)=h_L(x)-h_R(x)。
$$
零点不受正负方向影响。

1. 插入 1：

```
1
```

无分支结点。

2. 插入 2：

```
1
 \
  2
```

$\mathrm{BF}(1)=-1$，无失衡；但 $1$ 是分支结点且 BF 不为 0，所以平衡因子为 0 的分支结点数为 0。

3. 插入 3：

先形成链 $1\to2\to3$，此时 $\mathrm{BF}(1)=-2$，对以 $1$ 为根的最小不平衡子树做左单旋：

```
  2
 / \
1   3
```

此时 $2,1,3$ 的 BF 都为 0，但分支结点只有 $2$，所以有 1 个。

4. 插入 4：

```
  2
 / \
1   3
     \
      4
```

无旋转。$\mathrm{BF}(2)=-1,\ \mathrm{BF}(3)=-1$，分支结点中没有 BF 为 0 的结点，所以为 0 个。

5. 插入 5：

插入后，$3$ 的 BF 为 $-2$，对以 $3$ 为根的最小不平衡子树做左单旋：

```
  2            2
 / \          / \
1   3   ->   1   4
     \          / \
      4        3   5
       \
        5
```

此时 $\mathrm{BF}(2)=-1,\ \mathrm{BF}(4)=0$，分支结点中 BF 为 0 的是 $4$，所以有 1 个。

6. 插入 6：

插入后，$2$ 的 BF 为 $-2$，对以 $2$ 为根的最小不平衡子树做左单旋：

```
  2                4
 / \              / \
1   4     ->     2   5
   / \          / \   \
  3   5        1   3   6
       \
        6
```

此时 $\mathrm{BF}(4)=0,\ \mathrm{BF}(2)=0,\ \mathrm{BF}(5)=-1$，分支结点中 BF 为 0 的是 $4,2$，所以有 2 个。

7. 插入 7：

插入后，$5$ 的 BF 为 $-2$，对以 $5$ 为根的最小不平衡子树做左单旋：

```
    4                4
   / \              / \
  2   5     ->     2   6
 / \   \          / \ / \
1   3   6        1  3 5  7
         \
          7
```

最终树为：

```
      4
     / \
    2   6
   / \ / \
  1  3 5  7
```

最终各结点 BF 都为 0：

| 结点 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|
| BF | 0 | 0 | 0 | 0 | 0 | 0 | 0 |
| 分支结点？ | 否 | 是 | 否 | 是 | 否 | 是 | 否 |

关键代码思路：AVL 插入时递归插入并回溯更新高度，若 $|\mathrm{BF}|=2$，根据孩子 BF 的正负选择单旋或双旋；最后层次遍历统计非叶结点且 $\mathrm{BF}=0$ 的个数。

**易错点**：

- 不要把“分支结点”误认为“所有 BF=0 的结点”。最终 7 个结点的 BF 都为 0，但叶子结点不算分支结点，所以不能选 7。
- 根结点 $4$ 也是分支结点，不能把根排除在外；若排除根会错选 C（2 个）。
- 插入过程中可能出现多个祖先的 BF 都为 $\pm2$，但必须找**最低失衡结点**，即最小不平衡子树的根。例如插入 5 时，应先旋转以 $3$ 为根的子树，而不是先转根结点 $2$。
- 旋转后要更新相关结点的平衡因子，不能只重排形状而忘记重新计算 BF。

**命题规律**：这是 408 中 AVL 树的经典选择题考点，常考“给定插入序列，问最终树形、根结点、平衡因子、分支/叶子结点个数”。常见变式包括：改变插入顺序、考查删除后的调整、考查 LL/RR/LR/RL 旋转次数等。复习时建议亲手完整模拟 1～7 的插入过程，熟练掌握四种旋转的适用条件；遇到统计题，先看清统计对象是“所有结点”还是“分支结点”。

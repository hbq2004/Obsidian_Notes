# 选择题 第 31 题

![[_Attachments/题目识别/27_王道408-题目/DS-C07-73-M31_题目.png|题目]]

31.【2019 统考真题】在任意一棵非空平衡二叉树 (AVL 树)$T_1$ 中，删除某结点 $v$ 之后形成平衡二叉树 $T_2$，再将 $v$ 插入 $T_2$ 形成平衡二叉树 $T_3$。下列关于 $T_1$ 与 $T_3$ 的叙述中，正确的是 ( )。
I.若 $v$ 是 $T_1$ 的叶结点，则 $T_1$ 与 $T_3$ 可能不相同
II.若 $v$ 不是 $T_1$ 的叶结点，则 $T_1$ 与 $T_3$ 一定不相同
III.若 $v$ 不是 $T_1$ 的叶结点，则 $T_1$ 与 $T_3$ 一定相同
A. 仅 I
B. 仅 II
C. 仅 I、II
D. 仅 I、III

## DeepSeek V4 Flash Max 解析

**答案**：仅 I 正确，选 **A**。  
即：若 \(v\) 是叶结点，\(T_1\) 与 \(T_3\) 可能不同；若 \(v\) 不是叶结点，则既不能说一定相同，也不能说一定不同。

**解题切入点**：本题考 AVL 树的删除、插入与旋转。拿到题先要想到：删除后可能旋转，插入后也可能旋转，不能简单认为“删除的逆操作就是插入”。对“可能/一定”类判断，最有效的方法是构造极简 AVL 树反例。

**推演**：

记平衡因子
$$
BF(x)=h(\text{左子树})-h(\text{右子树}),
$$
AVL 树要求 \(BF(x)\in\{-1,0,1\}\)。

### I 正确：\(v\) 是叶结点时，\(T_1\) 与 \(T_3\) 可能不同

构造 AVL 树：

```
        30
       /  \
      20   40
             \
              50
```

取 \(v=20\)，它是叶结点。删除 20 后：

```
        30
          \
           40
             \
              50
```

此时根 30 的平衡因子为 \(-2\)，失衡，做一次左旋，得到：

```
        40
       /  \
      30   50
```

再将 20 插入：

```
        40
       /  \
      30   50
     /
    20
```

最终 \(T_3\) 与原来的 \(T_1\) 不同，所以 I 正确。

### II 不正确：\(v\) 不是叶结点时，不一定不同

构造 AVL 树：

```
        30
       /  \
      20   40
```

取 \(v=30\)，它不是叶结点。用中序后继 40 替代删除后，得到：

```
        40
       /
      20
```

再插入 30：

```
        40
       /
      20
        \
         30
```

此时 40 失衡，且 20 的平衡因子为 \(-1\)，做 LR 双旋（先左旋 20，再右旋 40）：

```
        30
       /  \
      20   40
```

恰好恢复为原来的 \(T_1\)。因此 II 的“一定不相同”错误。

### III 不正确：\(v\) 不是叶结点时，不一定相同

构造 AVL 树：

```
        10
       /
      5
```

取 \(v=10\)，它不是叶结点。删除 10 后：

```
        5
```

再插入 10：

```
        5
          \
           10
```

这与原来的 \(T_1\) 不同，因此 III 的“一定相同”错误。

综上：只有 I 正确，选 **A**。

**易错点**：

1. 误以为“新插入的结点最终一定还是叶结点”。实际上 AVL 插入后的旋转，尤其是双旋，可能让新插入的结点变成内部结点。例如 II 的反例中，30 最终成为根，并有了两个孩子 20、40。
2. 误以为“删除 \(v\) 后再插入 \(v\) 一定恢复原树”。删除和插入的旋转不一定互逆，因此可能恢复，也可能不恢复。
3. 注意只有一个孩子的结点也属于“不是叶结点”，例如 III 的反例。

**命题规律**：本题是 AVL 树删除/插入旋转的经典选择题。常见变式有：给定删除和插入序列判断最终根结点、比较树高、判断某祖先结点的平衡因子等。复习时应熟练掌握 LL、RR、LR、RL 四种旋转的中间状态，并养成用极简 AVL 树构造反例的习惯，尤其注意“可能/一定”这类逻辑判断。

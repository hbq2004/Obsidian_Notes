14. 在平衡二叉树的基本操作中，可能发生两次旋转的操作是 ( ).

A. 添加、删除结点
B. 仅删除结点
C. 仅添加结点

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C07-73-M14_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 A（添加、删除结点）。AVL 树的插入和删除操作都可能触发 LR/RL 型双旋转，而一次双旋转就是两次基本旋转。

**解题切入点**：  
看到“两次旋转”应立刻定位到 AVL 树的四种平衡调整：LL、RR 是单旋转，LR、RL 是双旋转。不要直接把“两次旋转”等同于“删除需要多次调整”。插入时若插入位置是失衡结点的“左孩子的右子树”或“右孩子的左子树”，就需要双旋转；删除时同样可能出现这种失衡形态。

**推演**：  
设平衡因子  
$$
BF(A)=h_L(A)-h_R(A)
$$
AVL 树中任意结点满足 $|BF(A)|\le 1$。

### 1. 插入结点时可能发生两次旋转

插入新结点后，从插入位置向上找最低失衡结点 $A$。常见四种情况：

- $BF(A)=+2$，且 $BF(A.left)=+1$：LL 型，只需对 $A$ 做一次右旋。
- $BF(A)=-2$，且 $BF(A.right)=-1$：RR 型，只需对 $A$ 做一次左旋。
- $BF(A)=+2$，且 $BF(A.left)=-1$：LR 型，需要**两次旋转**：
  1. 先对 $A.left$ 左旋；
  2. 再对 $A$ 右旋。
- $BF(A)=-2$，且 $BF(A.right)=+1$：RL 型，需要**两次旋转**：
  1. 先对 $A.right$ 右旋；
  2. 再对 $A$ 左旋。

例如 LR 型中，设 $B=A.left$，$C=B.right$。先左旋 $B$，再右旋 $A$，旋转后以 $C$ 为子树根，$B$ 为 $C$ 的左孩子，$A$ 为 $C$ 的右孩子。因此插入操作可能发生两次旋转。

### 2. 删除结点时也可能发生两次旋转

删除结点后从被删结点的父结点开始向上检查。若某个祖先结点 $A$ 失衡：

- 若 $BF(A)=+2$，且 $BF(A.left)=-1$，则做 LR 型双旋转；
- 若 $BF(A)=-2$，且 $BF(A.right)=+1$，则做 RL 型双旋转。

所以删除操作同样可能发生两次旋转。并且删除后调整完一个失衡结点，其祖先仍可能失衡，因此删除操作甚至可能发生多次旋转。

关键调整代码思路如下：

```cpp
leftRotate(x):
    y = x.right
    x.right = y.left
    y.left = x
    updateHeight(x)
    updateHeight(y)
    return y

rightRotate(x):
    y = x.left
    x.left = y.right
    y.right = x
    updateHeight(x)
    updateHeight(y)
    return y

rebalance(x):
    if balance(x) == 2:
        if balance(x.left) == 1:
            return rightRotate(x)          // LL
        else:
            x.left = leftRotate(x.left)    // LR
            return rightRotate(x)
    if balance(x) == -2:
        if balance(x.right) == -1:
            return leftRotate(x)           // RR
        else:
            x.right = rightRotate(x.right) // RL
            return leftRotate(x)
    return x
```

插入时递归回溯调用 `rebalance` 后，第一个失衡结点调整完，子树高度恢复，上层不会再失衡；删除时则可能继续向上回溯，再次调用 `rebalance`，所以删除还可能发生多次平衡调整。

**易错点**：  
1. 不要因为“删除可能多次调整”就直接选 B。本题问的是“两次旋转”，LR/RL 双旋转本身就是两次基本旋转，插入也会出现。  
2. 不要只想到插入有 LR/RL，删除也可能出现 LR/RL，因此不能选“仅添加”。  
3. LR 是“先左旋后右旋”，RL 是“先右旋后左旋”，方向不要记反。  
4. 若个别教材把“双旋转”称为一次平衡调整，则“插入最多一次调整、删除可能多次调整”的说法也正确；但本题按“基本旋转次数”理解，选 A。

**命题规律**：  
考点是 AVL 树的旋转类型与插入/删除调整次数。常见变式有：给出插入序列，要求判断需要的旋转类型；给出失衡结点平衡因子和孩子平衡因子，判断 LL/RR/LR/RL；比较插入与删除操作所需调整次数。复习时应熟练掌握四种调整的触发条件，并理解插入调整后高度恢复、删除调整后可能继续向上传播的特点。

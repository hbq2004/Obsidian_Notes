## 答案

## DeepSeek V4 Flash Max 解析

**答案**：设 $T_h$ 表示高度为 $h$（即共有 $h$ 层）的平衡二叉树的最少结点数，则 $T_h=T_{h-1}+T_{h-2}+1$，算得 $T_5=12$，选 **B**。

**解题切入点**：  
拿到题目先定位考点：**平衡二叉树的高度与最少结点数之间的递推关系**。这种题和动态规划/斐波那契数列很相似，核心思想是“在满足平衡因子的前提下，把树做得尽可能瘦”。可以类比为：一棵树要长到第 $h$ 层，根必须至少有一棵子树长到第 $h-1$ 层；但为了保持平衡，另一棵子树只需长到第 $h-2$ 层即可。

**推演**：  
设 $T_h$ 表示“高度为 $h$ 层”的平衡二叉树的最少结点数。

边界条件：

- 只有 $1$ 层：至少 $1$ 个结点，所以  
  $$
  T_1=1.
  $$

- 有 $2$ 层：根结点带 $1$ 个孩子即可达到 $2$ 层，且平衡因子为 $1$，合法，所以  
  $$
  T_2=2.
  $$

对于 $h\ge 3$，根结点必须有一棵子树高度为 $h-1$ 层；另一棵子树为了满足平衡条件，高度最低可以是 $h-2$ 层。若另一棵子树低于 $h-2$ 层，根结点左右子树高度差会超过 $1$，不再是平衡二叉树。因此最小结点数满足：

$$
T_h = T_{h-1}+T_{h-2}+1.
$$

代入计算：

$$
T_3=T_2+T_1+1=2+1+1=4,
$$

$$
T_4=T_3+T_2+1=4+2+1=7,
$$

$$
T_5=T_4+T_3+1=7+4+1=12.
$$

所以具有 $5$ 层结点的平衡二叉树至少有 $12$ 个结点。

对应递推代码思路为：

```cpp
int minNodes(int h) {
    if (h == 1) return 1;
    if (h == 2) return 2;
    return minNodes(h - 1) + minNodes(h - 2) + 1;
}
```

**易错点**：  
- 误把 $T_2$ 写成 $1$ 或 $3$。两层二叉树最少只需要“根 + 一个孩子”共 $2$ 个结点。  
- 误以为根的两棵子树都要达到 $h-1$ 层。这样虽然平衡，但结点数更多；最小结构应是一棵 $h-1$ 层、另一棵 $h-2$ 层。  
- 混淆“层数”和“边数高度”。若按边数高度为 $5$ 计算，则对应 $6$ 层，结果会变成 $20$，不是本题选项；本题“5层”指根为第 $1$ 层、最深叶结点为第 $5$ 层。  
- 不要把“最多结点数”公式 $2^h-1$ 误用于求“最少结点数”。

**命题规律**：  
本题考查 AVL 树的“最少结点数与高度”的递推关系，本质是斐波那契数列的变形：

$$
T_h=T_{h-1}+T_{h-2}+1,\quad T_1=1,\ T_2=2.
$$

前几项为：

$$
1,2,4,7,12,20,\cdots
$$

常见变式有：已知平衡二叉树高度求最少结点数；已知最少结点数反推最大高度；求高度为 $h$ 的平衡二叉树最多结点数 $2^h-1$；以及 AVL 树插入/删除后的旋转判断。复习时应熟记该递推关系，并理解平衡因子与四种旋转的由来。

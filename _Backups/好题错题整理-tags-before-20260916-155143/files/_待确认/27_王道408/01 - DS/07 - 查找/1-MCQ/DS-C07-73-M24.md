## DeepSeek V4 Flash Max 解析

**答案**：插入 48 后应做 **RL 型双旋转**，重平衡后关键字 37 所在结点成为新根，其左、右子结点关键字分别为 **24、53**，故选 **C**。

**解题切入点**：AVL 树的插入题，先按二叉搜索树规则插入，再从插入位置沿父链向上找第一个 $|\mathrm{BF}|>1$ 的失衡结点；然后根据失衡结点和其较高孩子方向判断旋转类型。本题插入后失衡结点是 24，而 24 的右孩子 53 左侧偏高，属于 **RL 型**，需要“先右旋、再左旋”，不能只做一次左旋。

**推演**：

原树为：

```
         24
        /  \
       13   53
           /  \
          37   90
```

按二叉搜索树规则插入 48：

- $48<53$，进入 53 的左子树；
- $48>37$，所以 48 成为 37 的右孩子。

插入后：

```
         24
        /  \
       13   53
           /  \
          37   90
            \
             48
```

设空树高度为 0，叶结点高度为 1。插入后有关结点高度为：

$$
H(37)=2,\qquad H(53)=\max\{H(37),H(90)\}+1=\max\{2,1\}+1=3
$$

$$
H(24)=\max\{H(13),H(53)\}+1=\max\{1,3\}+1=4
$$

采用 $\mathrm{BF}=H(\text{左子树})-H(\text{右子树})$，则：

$$
\mathrm{BF}(24)=1-3=-2
$$

所以结点 24 失衡。再看其右孩子 53：

$$
\mathrm{BF}(53)=H(37)-H(90)=2-1=1
$$

失衡结点 24 的右孩子 53 左侧偏高，因此是 **RL 型**，应执行：

1. 先对 53 右旋；
2. 再对 24 左旋。

先对 53 右旋：

```
       53             37
      /  \              \
     37   90    ->       53
       \                /  \
        48             48   90
```

得到：

```
         24
        /  \
       13   37
              \
               53
              /  \
             48   90
```

再对 24 左旋，得到新平衡二叉树：

```
           37
          /  \
         24   53
        /    /  \
       13   48   90
```

因此在新平衡二叉树中，关键字 37 所在结点的左子结点是 24，右子结点是 53，对应选项 **C**。

关键旋转思路为：

```c
// A 为失衡结点 24，RL 型：先右旋其右孩子，再左旋 A
A->rchild = rightRotate(A->rchild);
A = leftRotate(A);
```

**易错点**：

1. **只插入不旋转**：插入后 48 是 37 的右孩子，但题目问的是重平衡后的新树，必须继续做 AVL 调整。  
2. **把 RL 型误判为 RR 型**：若只有一次左旋，无法使整棵 AVL 树平衡。判断关键是 $\mathrm{BF}(24)=-2$ 且 $\mathrm{BF}(53)=+1$，所以是 RL 型。  
3. **旋转方向写反**：RL 型是“先右旋、后左旋”，LR 型才是“先左旋、后右旋”。  
4. **丢掉中间子树**：右旋过程中，37 的原右孩子 48 要成为 53 的左孩子；若丢掉了 48，会破坏二叉搜索树的中序性质。  
5. **看错结点**：题目问的是 37 的左右子结点，不是原根 24 的左右子结点；重平衡后 37 已经是根结点。

**命题规律**：本题是 AVL 树插入操作的传统考点，统考中常给出一棵平衡二叉树和一次插入，要求判断旋转后树的形态、某结点孩子、根结点等。变式包括：删除结点后的再平衡、给出插入序列构造 AVL 树、要求写出若干次旋转后的层序或先序序列。复习时应熟练掌握 LL、RR、LR、RL 四种旋转的判定条件和具体步骤，并能准确画出旋转后的树形。

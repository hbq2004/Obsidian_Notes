# 选择题 第 22 题

![[_Attachments/题目识别/27_王道408-题目/DS-C07-73-M22_题目.png|题目]]

22. 在下图所示的红黑树中插入结点 2 且染成红色后,则下一步应进行的操作是 ( )。
【图：一个红黑树，根节点为8（黑），左子节点为5（黑），右子节点为12（黑）。5的左子节点为3（灰）。12的左子节点为10（灰），右子节点为14（灰）。】
(A) 左旋
(B) 右旋
(C) 变色
(D) 无须调整

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C07-73-M22_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 B（右旋）。插入 2 后，父结点 3 为红色、叔结点为黑色，且属于“LL 型”，所以下一步应对祖父结点 5 做右旋；旋转后再将 3 染黑、5 染红。

**解题切入点**：红黑树插入题先定位插入位置，再看“父结点”和“叔结点”的颜色。这里叔结点是空叶子 $\mathrm{NIL}$，在红黑树中空叶子算黑色；父结点为红、叔结点为黑时通常需要旋转，而不是变色。

**推演**：图中灰结点按红结点处理。原树为：

```text
        8B
       /  \
      5B   12B
     /     /  \
    3R    10R  14R
```

插入 2 时，按二叉排序树规则：$2<8 \to$ 左子树，$2<5 \to$ 左子树，$2<3 \to$ 成为 3 的左孩子：

```text
        8B
       /  \
      5B   12B
     /     /  \
    3R    10R  14R
   /
  2R
```

此时 2 和 3 都是红色，出现“红-红”冲突。

对结点 2 来说：

- 父结点 $p=3$：红色；
- 祖父结点 $g=5$：黑色；
- 叔结点 $u=5$ 的右孩子：$\mathrm{NIL}$，黑色。

叔结点为黑色，所以不是直接变色。又因为：

```text
2 是 3 的左孩子，3 是 5 的左孩子
```

即属于 LL 型，应对祖父结点 5 右旋。右旋后再把 3 染黑、5 染红，得到：

```text
        8B
       /  \
      3B   12B
     /  \   /  \
    2R   5R 10R  14R
```

因此本题下一步应进行的操作是右旋。

**易错点**：

- 不要把 5 的右孩子当作不存在而忽略；红黑树中空结点 $\mathrm{NIL}$ 是黑色。
- 不要把“叔结点”找错；对结点 2 来说，叔结点是祖父结点 5 的另一个孩子，不是 12。
- “变色”通常对应叔结点为红色的情形；本题叔结点为黑，所以不选 C。
- 若把 2 理解为 3 的右孩子，则属于 LR 型，需要先左旋再右旋；但本题是 LL 型，直接右旋。

**命题规律**：红黑树是 408 选择题常考内容，重点考查插入后的调整类型：叔红变色、叔黑旋转，以及 LL/LR/RR/RL 对应的旋转方向。复习时掌握红黑树五条性质、$\mathrm{NIL}$ 算黑色，并会手推插入调整即可；变式常为“插入不同结点问下一步操作”或“问最终树形”。

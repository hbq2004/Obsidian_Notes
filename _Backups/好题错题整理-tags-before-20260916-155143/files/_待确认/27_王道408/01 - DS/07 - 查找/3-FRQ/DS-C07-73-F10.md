10.编写一个递归算法,在一棵有 $n$ 个结点的、随机建立的二叉排序树上查找第 $k(1 \leqslant k \leqslant n)$ 小的元素，并返回指向该结点的指针。要求算法的平均时间复杂度为 $O(\log_2 n)$。二叉排序树的每个结点中除 $data$、$lchild$、$rchild$ 等数据成员外，增加一个 $count$ 成员，保存以该结点为根的子树上的结点个数.

## DeepSeek V4 Flash Max 解析

**答案**：利用每个结点的 $count$ 保存子树规模，把“第 $k$ 小”转化为沿二叉排序树一条路径递归下降的选择问题：每次用左子树结点数 $c_L$ 判断目标在左子树、当前根结点还是右子树，平均时间复杂度为 $O(\log_2 n)$。

**解题切入点**：题目要求“第 $k$ 小”，而二叉排序树的中序序列就是递增有序序列，因此第 $k$ 小就是中序序列中的第 $k$ 个元素。但直接做中序遍历需要 $O(n)$ 时间，不符合要求。关键要利用新增的 $count$ 成员跳过整棵左子树或右子树，把查找过程压缩成从根到目标结点的一条路径。这类似于在有序数组中用下标二分查找，只不过这里用左子树大小作为“分界下标”。

**推演**：

设当前结点为 $T$，其左子树结点数为 $c_L$，右子树结点数为 $c_R$，则：

$$
T \to count = 1 + c_L + c_R
$$

二叉排序树的中序序列为：

$$
\text{左子树中序序列} + \text{根结点} + \text{右子树中序序列}
$$

所以在以 $T$ 为根的子树中：

- 左子树中的元素是前 $c_L$ 小；
- 根结点 $T$ 是第 $c_L + 1$ 小；
- 右子树中的元素从第 $c_L + 2$ 小开始。

因此，若当前要找第 $k$ 小：

1. 若 $k = c_L + 1$，则当前结点 $T$ 就是第 $k$ 小；
2. 若 $k \le c_L$，则第 $k$ 小一定在左子树中，递归查找左子树中的第 $k$ 小；
3. 若 $k > c_L + 1$，则第 $k$ 小一定在右子树中，且是右子树中的第 $k - c_L - 1$ 小。

关键代码如下：

```c
typedef struct BSTNode {
    int data;
    struct BSTNode *lchild, *rchild;
    int count;  // 以该结点为根的子树中的结点个数
} BSTNode;

// 返回以 T 为根的二叉排序树中第 k 小结点的指针
BSTNode* SearchKth(BSTNode* T, int k) {
    if (T == NULL || k < 1 || k > T->count)
        return NULL;

    int leftCount = (T->lchild != NULL) ? T->lchild->count : 0;

    if (k == leftCount + 1)
        return T;
    else if (k <= leftCount)
        return SearchKth(T->lchild, k);
    else
        return SearchKth(T->rchild, k - leftCount - 1);
}
```

正确性可以归纳证明：对以当前结点为根的子树，左子树大小为 $c_L$，中序有序性保证左子树全部小于根、右子树全部大于根；因此目标结点所在范围可唯一确定为左子树、根或右子树。进入右子树时，因为前面已经跳过了左子树全部 $c_L$ 个结点和根结点，所以新的局部序数为 $k - c_L - 1$；进入左子树时序数不变。递归不变式成立。

时间复杂度：每次递归只沿一条路径下降，每层只做常数次判断，所以时间取决于从根到目标结点的路径长度。随机建立的二叉排序树平均高度为 $O(\log_2 n)$，因此平均时间复杂度为 $O(\log_2 n)$。最坏情况下，二叉排序树退化为单链时，时间复杂度为 $O(n)$。递归栈空间平均为 $O(\log_2 n)$。

**易错点**：

- 不要把当前结点的 $count$ 当成左子树大小。$count$ 是以该结点为根的整棵子树的结点数，判断时应使用 `T->lchild->count`，而不是 `T->count`。
- 进入右子树时，必须把 $k$ 减去 `leftCount + 1`；进入左子树时，$k$ 保持不变。
- 判断当前结点是否是答案时，应使用 $k = c_L + 1$，而不是 $k = 1$ 或 $k = T \to count$。
- 递归出口要考虑空树和非法 $k$，返回 `NULL`。
- $count$ 必须维护正确。在建树或插入结点时，沿路径经过的每个结点都要更新 $count$；若只给定普通二叉排序树而没有维护 $count$，需要先通过一次后序遍历初始化 $count$。
- 不要在算法中使用中序遍历找第 $k$ 个，那样平均时间复杂度仍为 $O(n)$，不满足题目要求。

**命题规律**：本题是“二叉排序树 + 顺序统计量”的经典综合题，核心是用子树结点数 $count$ 实现一次递归路径选择。类似思想也出现在 B 树中：用结点内关键字个数决定查找分支。常见变式有：查找第 $k$ 大元素（可先求 $n - k + 1$，再调用本算法）、删除或插入后维护 $count$、要求写迭代版本、或把二叉排序树改为平衡二叉树后要求最坏情况 $O(\log_2 n)$。复习时要注意区分“随机二叉排序树的平均复杂度”和“最坏复杂度”，并熟练掌握利用子树规模进行递归剪枝的思路。

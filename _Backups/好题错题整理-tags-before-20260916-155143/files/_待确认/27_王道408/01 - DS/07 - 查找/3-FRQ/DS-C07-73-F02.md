## DeepSeek V4 Flash Max 解析

**答案**：  
按序列 $(40,72,38,35,67,51,90,8,55,21)$ 依次插入建立二叉排序树，得到以 $40$ 为根的 BST；等概率查找成功时平均查找长度为  
$$\mathrm{ASL}_{成功}=\frac{32}{10}=3.2.$$

**解题切入点**：  
拿到题先把考点定位为“二叉排序树的构造”和“平均查找长度”。二叉排序树的形状由插入顺序决定，**不能先排序再建树**；应模拟 BST 插入过程：从根开始，小往左、大往右，直到空位置插入。求查找成功 ASL 时，注意根结点的查找长度是 $1$，不是 $0$。

**推演**：  
从空树开始按给定序列插入，每个关键字的插入路径可概括为：

- $40$：根结点；
- $72$：$40$ 的右孩子；
- $38$：$40$ 的左孩子；
- $35$：$38$ 的左孩子；
- $67$：$72$ 的左孩子；
- $51$：$67$ 的左孩子；
- $90$：$72$ 的右孩子；
- $8$：$35$ 的左孩子；
- $55$：$51$ 的右孩子；
- $21$：$8$ 的右孩子。

对应二叉排序树为：

```text
40
├── 左：38
│   └── 左：35
│       └── 左：8
│           └── 右：21
└── 右：72
    ├── 左：67
    │   └── 左：51
    │       └── 右：55
    └── 右：90
```

用中序遍历验证：  
$$8,21,35,38,40,51,55,67,72,90$$  
中序序列递增，符合二叉排序树性质。

查找成功时，每个结点的查找长度等于该结点所在层数，根结点层数为 $1$。统计各层结点数：

| 层数 $l$ | 结点 | 个数 |
|---|---|---|
| $1$ | $40$ | $1$ |
| $2$ | $38,72$ | $2$ |
| $3$ | $35,67,90$ | $3$ |
| $4$ | $8,51$ | $2$ |
| $5$ | $21,55$ | $2$ |

因此总比较次数为  
$$
1\cdot1+2\cdot2+3\cdot3+2\cdot4+2\cdot5
=1+4+9+8+10=32.
$$

共有 $10$ 个结点，等概率时每个结点查找概率为 $\frac{1}{10}$，所以  
$$
\mathrm{ASL}_{成功}
=\frac{1}{10}\left(1\cdot1+2\cdot2+3\cdot3+2\cdot4+2\cdot5\right)
=\frac{32}{10}=3.2.
$$

关键代码思路：  
插入过程即  
```cpp
Node* insert(Node* root, int key) {
    if (root == NULL) return new Node(key);
    if (key < root->key) root->left = insert(root->left, key);
    else if (key > root->key) root->right = insert(root->right, key);
    return root;
}
```
对序列中每个关键字依次调用即可；统计 ASL 时用 `dfs(root, 1)` 返回所有结点查找长度之和。

**易错点**：  
- 不要把根结点的查找长度算成 $0$，BST 查找成功时根结点也要比较一次。  
- 不能把给定序列先排序再建树，否则树形会改变，ASL 也会改变。  
- 插入 $21$ 时路径是 $40\to38\to35\to8$，因为 $21>8$，所以 $21$ 是 $8$ 的右孩子，不能漏掉 $8$ 这一层。  
- 查找成功 ASL 除以结点总数 $10$；不要把查找失败 ASL 混入。  
- 若用“深度”代替“层数”，会得到 $22/10=2.2$，这是常见错误；正确应使用“层数”或“深度 $+1$”。

**命题规律**：  
这是 408 中二叉排序树的基础综合题，常考“给定序列建 BST + 求 ASL”。常见变式有：计算查找失败 ASL、判断删除/插入后 BST 的形状、利用中序有序性判断 BST、与平衡二叉树/折半查找判定树比较等。复习时要熟练掌握 BST 的插入模拟和层数统计，并能把“查找长度”与“树高、层数”准确对应。

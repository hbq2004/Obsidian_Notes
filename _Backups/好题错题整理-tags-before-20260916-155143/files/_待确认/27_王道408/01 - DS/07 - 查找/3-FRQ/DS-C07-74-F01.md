1. 给定一组关键字 $\{20,30,50,52,60,68,70\}$，给出创建一棵 3 阶 $B$ 树的过程.

## 答案

## DeepSeek V4 Flash Max 解析

**答案**：按给定关键字序列依次插入，遇结点上溢就取中位关键字上移分裂，最终得到如下 3 阶 $B$ 树：

```text
          [52]
         /    \
      [30]    [68]
      /  \    /  \
   [20] [50][60] [70]
```

**解题切入点**：拿到题先识别考点：这是 $B$ 树插入，不是普通 BST。3 阶 $B$ 树就是 2-3 树，每个结点最多 2 个关键字。做题思路是逐关键字模拟插入；遇到“满结点再插入”就上溢分裂，像竖式加法“满二进一”一样把中位数进位给父结点。

**推演**：3 阶 $B$ 树中，$m=3$，所以每个结点最多 $3$ 棵子树、最多 $3-1=2$ 个关键字；非根结点至少有 $\lceil 3/2\rceil=2$ 棵子树，即至少 $1$ 个关键字。插入后若某结点有 3 个关键字，取第 2 个关键字上移，左右两部分分裂为两个结点。

1. 插入 $20,30$：
$$[20]\xrightarrow{\text{插入 }30}[20,30]$$

2. 插入 $50$：$[20,30,50]$ 上溢，中位数 $30$ 上移：
```text
       [30]
      /    \
   [20]    [50]
```

3. 插入 $52$：沿右子树到 $[50]$，得 $[50,52]$：
```text
       [30]
      /    \
   [20]  [50,52]
```

4. 插入 $60$：$[50,52,60]$ 上溢，中位数 $52$ 上移进根：
```text
       [30,52]
      /   |   \
   [20] [50]  [60]
```

5. 插入 $68$：到 $[60]$ 插入，得 $[60,68]$：
```text
       [30,52]
      /   |   \
   [20] [50] [60,68]
```

6. 插入 $70$：$[60,68,70]$ 上溢，$68$ 上移，根临时成为 $[30,52,68]$，也上溢；再取 $52$ 上移为新根，原根分裂成 $[30]$ 和 $[68]$：
```text
          [52]
         /    \
      [30]    [68]
      /  \    /  \
   [20] [50][60] [70]
```

关键代码思路：从根向下找到叶结点并插入；若当前结点关键字数超过 $2$，取中间关键字上移，把原结点分裂成左右两个结点；若父结点不存在就新建根；否则把中间关键字插入父结点并继续向上检查。

**易错点**：
- 把 3 阶误认为最多 3 个关键字。3 阶指最多 3 棵子树，最多 2 个关键字。
- 分裂时选错中位数，如 $[50,52,60]$ 应上移 $52$，不是 $50$ 或 $60$。
- 分裂内部结点时只分关键字，忘分孩子指针。最后一步必须把 $[20]、[50]$ 分给 $[30]$，把 $[60]、[70]$ 分给 $[68]$。
- 根上溢后忘记增加树高，或把原根继续当新根。根分裂时原根被拆成两个结点，新根只含中位关键字。
- 只处理叶子溢出，不沿父结点继续处理。上溢可能向上传播，必须回溯到不再溢出为止。

**命题规律**：本考点在 408 中属于“查找”部分的 $B$ 树，常以选择题形式考查插入/删除后的树形、结点关键字数范围、树高与最少结点数等。常见变式包括：给定序列构造 4 阶或 5 阶 $B$ 树、给定 $B$ 树删除关键字后合并/借位、$B$ 树与 $B+$ 树对比。复习时应亲手画 3~5 遍插入和删除过程，牢记关键字数范围
$$ \lceil m/2\rceil-1 \le n \le m-1 $$
（根结点可少至 1 个关键字），且子树数 = 关键字数 + 1。

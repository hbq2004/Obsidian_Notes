## DeepSeek V4 Flash Max 解析

**答案**：开放地址法删除记录时不能直接“置空”，必须给该位置打上“已删除”标记（惰性删除），以保证探测序列的连续性；拉链法删除记录时可直接在对应的冲突链表中摘除该结点，不影响其他记录的查找。

**解题切入点**：拿到题目先抓住“删除后，查找还能不能正确进行”这一核心问题。散列表的插入和查找都依赖于“空位置”作为终止条件；如果删除后把位置变成空，就可能截断其他记录原本的探测路径。因此，删除方式取决于冲突处理方法：开放地址法中存在逻辑上的探测序列，拉链法中每个链表互相独立，删除策略自然不同。

**推演**：

### 1. 开放地址法

设散列表长为 $m$，哈希函数为 $H(key)$，采用线性探测时探测序列为：

$$
h_i = (H(key)+d_i)\bmod m,\quad i=0,1,2,\dots
$$

其中 $d_0=0$。

查找关键字 $key$ 时，沿着该探测序列依次检查：

- 若某个位置关键字等于 $key$，查找成功；
- 若遇到“空”位置，则查找失败；
- 若遇到“已删除”位置，则 **不能停止**，必须继续探测。

为什么不能直接置空？看一个例子：

设 $m=11$，$H(key)=key\bmod 11$。依次插入 $47$、$58$、$69$：

- $47\bmod11=3$，放入位置 $3$；
- $58\bmod11=3$，位置 $3$ 冲突，线性探测到位置 $4$；
- $69\bmod11=3$，位置 $3、4$ 冲突，探测到位置 $5$。

此时若直接删除 $47$，将位置 $3$ 置为空。再查找 $69$ 时，先探测位置 $3$，发现为空，立即判断“不存在”，但 $69$ 实际在位置 $5$，查找失败。

因此，删除 $47$ 时只能将位置 $3$ 标记为“已删除”（Deleted），不能标记为“空”（Empty）。查找 $69$ 时：

- 位置 $3$：已删除，继续；
- 位置 $4$：不是 $69$，继续；
- 位置 $5$：找到 $69$。

所以删除操作应为：

1. 按探测序列查找该记录；
2. 若找到，将该位置标记为“已删除”；
3. 插入新记录时，遇到“空”或“已删除”的位置都可以放入。

当“已删除”标记过多时，查找性能会下降，此时可以重建散列表或进行再散列，真正清除这些标记。

### 2. 拉链法

拉链法中，每个散列地址对应一条链表，链表中的结点都是哈希地址相同的记录。

删除记录时，直接在该地址对应的链表中删除该结点即可。因为每条链表只属于一个散列地址，各链表之间没有逻辑上的探测路径交叉，删除某个结点不会影响其他记录的查找路径。

若用单链表实现，删除时需记录前驱结点：

```c
bool hashDelete(int key) {
    int addr = H(key);
    Node *p = table[addr];
    Node *pre = NULL;
    while (p != NULL && p->key != key) {
        pre = p;
        p = p->next;
    }
    if (p == NULL) return false;   // 未找到
    if (pre == NULL)
        table[addr] = p->next;     // 被删结点是链首
    else
        pre->next = p->next;       // 摘除结点
    free(p);
    return true;
}
```

若删除的是链首结点，要更新散列表的表头指针；若删除中间结点，则修改前驱的 `next` 指针。平均时间复杂度为 $O(1+\alpha)$，其中 $\alpha = n/m$ 为装载因子。

**易错点**：

- 最容易犯的错误：开放地址法中直接将被删记录所在位置置为“空”，导致后续同义词记录“查找不到”。
- 开放地址法中查找时遇到“已删除”标记就停止，这仍然会截断探测序列，必须继续探测。
- 插入时认为“已删除”位置不可用，会导致散列表过早满；正确做法是“已删除”位置可以插入新记录。
- 拉链法删除链首结点时忘记更新表头指针，导致该链表丢失。
- 删除后不释放结点，造成内存泄漏，尤其用 C/C++ 实现时要注意 `free` 或 `delete`。

**命题规律**：本题属于散列表的常考综合应用点。408 中经常以选择题形式考查“开放地址法中能否直接删除记录”，或以散列表的插入、查找、删除过程为背景出小题，也可能在大题中要求模拟删除后的散列表状态，并说明查找过程。复习时要重点理解三种状态：“空”、“已删除”、“有记录”；掌握开放地址法与拉链法在插入、查找、删除上的本质差异。变式可能涉及线性探测、二次探测、双散列等，但删除原则完全一致：开放地址法用“删除标记”，拉链法直接删结点。

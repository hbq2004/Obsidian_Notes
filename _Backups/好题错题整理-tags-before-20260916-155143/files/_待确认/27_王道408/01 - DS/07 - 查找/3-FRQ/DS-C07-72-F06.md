# 综合题 第 6 题

![[_Attachments/题目识别/27_王道408-题目/DS-C07-72-F06_题目.png|题目]]

632. 已知一个$n$阶矩阵$A$和一个目标值$k$。该矩阵无重复元素，每行从左到右升序排列，每列从上到下升序排列。请设计一个在时间上尽可能高效的算法，判断矩阵中是否存在目标值$k$。例如，矩阵为

$$
\begin{bmatrix}
1 & 4 & 7 \\
2 & 5 & 8 \\
3 & 6 & 9
\end{bmatrix}
$$

，目标值为8，判断存在。要求：

1) 给出算法的基本设计思想。

2) 根据设计思想，采用$C$或$C++$语言描述算法，关键之处给出注释。

3) 说明你的算法的时间复杂度和空间复杂度。

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C07-72-F06_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：从矩阵右上角（或左下角）开始，利用行、列递增性，每次比较后排除一行或一列，可在 $O(n)$ 时间、$O(1)$ 空间内判断目标值 $k$ 是否存在。

**解题切入点**：  
看到“行递增、列递增”的矩阵查找，先定位为“杨氏矩阵/二维有序表”问题。暴力扫描是 $O(n^2)$，逐行二分是 $O(n\log n)$，都不是最优。关键要找一个“拐角”：右上角元素既是当前行的最大值，又是当前列的最小值。于是类似在隐式二叉搜索树中查找：目标小时向左，目标大时向下，每走一步排除一整行或一整列。

**推演**：

1. **基本设计思想**

设当前未排除子矩阵为  
$$
S_{i,j}=\{A[r][c]\mid i\le r<n,\ 0\le c\le j\},
$$
初始 $i=0$，$j=n-1$，即整个矩阵。$A[i][j]$ 是 $S_{i,j}$ 的右上角元素。

- 若 $A[i][j]=k$，则找到目标值。
- 若 $A[i][j]>k$：在 $S_{i,j}$ 中，$A[i][j]$ 是第 $j$ 列的最小值，而该列从上到下递增，所以该列所有元素都大于 $k$，可排除第 $j$ 列，令 $j\leftarrow j-1$。
- 若 $A[i][j]<k$：在 $S_{i,j}$ 中，$A[i][j]$ 是第 $i$ 行的最大值，而该行从左到右递增，所以该行所有元素都小于 $k$，可排除第 $i$ 行，令 $i\leftarrow i+1$。

每次排除一行或一列后，若目标值存在，仍必在缩小的子矩阵中。循环终止时只有两种情况：找到了目标值，或未排除区域为空，即目标值不存在。

2. **C++ 代码描述**

```cpp
#include <vector>

bool searchMatrix(const std::vector<std::vector<int>>& A, int k) {
    int n = (int)A.size();
    if (n == 0) return false;

    int i = 0, j = n - 1;            // 从右上角开始
    while (i < n && j >= 0) {
        if (A[i][j] == k) {
            return true;             // 找到目标值
        }
        if (A[i][j] > k) {
            --j;                     // 当前列未排除部分都大于 k，排除该列
        } else {
            ++i;                     // 当前行未排除部分都小于 k，排除该行
        }
    }
    return false;                    // 搜索区域为空，目标不存在
}
```

3. **时间复杂度与空间复杂度**

- 每个循环中，要么 $i$ 增加 1，要么 $j$ 减少 1。$i$ 最多从 $0$ 增加到 $n$，$j$ 最多从 $n-1$ 减少到 $-1$，因此最多执行 $O(n)$ 次比较。
- 每次比较和指针移动都是 $O(1)$。
- 时间复杂度：$O(n)$。
- 空间复杂度：$O(1)$，只使用了常数个辅助变量。

题中矩阵目标值为 $8$：右上角 $A[0][2]=7<8$，排除第 $0$ 行；新右上角 $A[1][2]=8$，返回 `true`。

**易错点**：

- 不能从左上角或右下角开始。左上角是当前区域最小值，目标更大时右边和下边都可能，无法唯一排除；右下角同理。
- 方向不能记反：从右上角开始时，若当前值大于 $k$，应 `j--`；若当前值小于 $k$，应 `i++`。
- 终止条件应写为 `while (i < n && j >= 0)`，不能写成 `i <= n` 或 `j > 0`，否则可能越界访问。
- 不要误以为整个矩阵展平后完全有序而直接做一维二分；本题只保证行内、列内有序。
- 不要采用暴力 $O(n^2)$ 或逐行二分 $O(n\log n)$，不符合“时间上尽可能高效”的要求。

**命题规律**：

本题属于“有序矩阵/二维数组上的减治查找”，是 408 综合题中常考的算法设计题。常见变式包括：

- 将 $n$ 阶方阵改为 $m\times n$ 矩阵，算法不变，时间复杂度为 $O(m+n)$；
- 要求输出目标值的位置，只需在找到时返回下标 $(i,j)$；
- 要求统计矩阵中小于或大于某个值的元素个数，也可用同一双指针路径完成。

复习时应熟记“右上角/左下角拐点法”，并掌握用“循环不变式”说明正确性；同时注意边界条件和复杂度分析。

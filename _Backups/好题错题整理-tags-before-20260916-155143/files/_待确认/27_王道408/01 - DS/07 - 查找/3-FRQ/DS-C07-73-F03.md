## DeepSeek V4 Flash Max 解析

**答案**：按二叉排序树规则插入，每次从新结点向上检查平衡因子，并对最小不平衡子树做 $LL/RR/LR/RL$ 旋转；本序列最终得到以 $34$ 为根、左右子树根分别为 $23$ 和 $107$ 的平衡二叉排序树。过程中插入 $15$ 时 $LL$ 右旋，插入 $115$ 时 $RR$ 左旋，插入 $28$ 和 $107$ 时均为 $RL$ 双旋。

**解题切入点**：拿到题先定位为 AVL 树的插入问题。插入分两步：先按 BST 规则把新结点放到合适位置；再从新结点向上找第一个 $|BF|=2$ 的结点，只旋转这棵“最小不平衡子树”。可以类比“搭积木时某一层歪了，只扶正歪掉的那一小块，不用拆整栋楼”。做题时先在关键结点旁标好平衡因子，避免看错旋转对象。

**推演**：

约定空树高度为 $0$，单结点高度为 $1$，且

$$
BF(T)=h_{\text{左}}-h_{\text{右}}
$$

### 1. 插入 $34$

$$34$$

根结点，平衡。

### 2. 插入 $23$

```text
  34
 /
23
$$

$BF(34)=1$，合法。

### 3. 插入 $15$

插入后：

```text
    34
   /
  23
 /
15
```

此时 $BF(34)=2$，且新结点 $15$ 位于 $34$ 的左孩子 $23$ 的左子树，属 $LL$ 型，对 $34$ 右旋：

```text
    23
   /  \
  15   34
```

### 4. 插入 $98$

插入后：

```text
     23
    /  \
   15   34
          \
           98
```

$BF(34)=-1$，$BF(23)=-1$，均合法，无需旋转。

### 5. 插入 $115$

插入后：

```text
     23
    /  \
   15   34
          \
           98
             \
             115
```

$BF(34)=-2$，且 $34$ 的右孩子 $98$ 的 $BF=-1$，属 $RR$ 型，对 $34$ 左旋：

```text
     23
    /  \
   15   98
       /  \
      34  115
```

### 6. 插入 $28$

插入后：

```text
         23
        /  \
       15   98
           /  \
          34  115
         /
        28
```

$BF(23)=-2$，且 $23$ 的右孩子 $98$ 的 $BF=+1$，属 $RL$ 型，应先对 $98$ 右旋，再对 $23$ 左旋。

先右旋 $98$：

```text
       23
      /  \
     15   34
         /  \
        28   98
               \
               115
```

再左旋 $23$：

```text
        34
       /  \
      23   98
     / \     \
    15  28   115
```

### 7. 插入 $107$

插入后：

```text
        34
       /  \
      23   98
     / \     \
    15  28   115
             /
            107
```

$BF(98)=-2$，且 $98$ 的右孩子 $115$ 的 $BF=+1$，属 $RL$ 型，先右旋 $115$，再左旋 $98$。

先右旋 $115$：

```text
        34
       /  \
      23   98
     / \     \
    15  28   107
                \
                115
```

再左旋 $98$：

```text
        34
       /  \
      23  107
     / \  /  \
    15 28 98 115
```

此时所有结点的平衡因子绝对值均不超过 $1$，最终中序遍历仍为：

$$
15,23,28,34,98,107,115
$$

说明二叉排序树性质没有被破坏。

**关键代码思路**：递归插入后更新高度，再判断四种失衡情况：

```text
bal = height(root.left) - height(root.right)

if bal > 1 and key < root.left.key:
    return rightRotate(root)

if bal < -1 and key > root.right.key:
    return leftRotate(root)

if bal > 1 and key > root.left.key:
    root.left = leftRotate(root.left)
    return rightRotate(root)

if bal < -1 and key < root.right.key:
    root.right = rightRotate(root.right)
    return leftRotate(root)
```

**易错点**：

- 平衡因子方向不能混淆。若定义 $BF=h_{\text{左}}-h_{\text{右}}$，则 $LL$ 对应 $BF=2$ 且左孩子 $BF=1$；$RR$ 对应 $BF=-2$ 且右孩子 $BF=-1$。
- 找错失衡结点。例如插入 $28$ 后，最小不平衡子树根是 $23$，不是 $34$ 或 $98$。
- $LR$ 与 $RL$ 旋转顺序不能反。$RL$ 必须先右旋右孩子，再左旋当前结点；本题插入 $28$、$107$ 都是 $RL$，若只做单旋，树仍可能不平衡。
- 旋转时注意“中间子树”的重挂。例如 $RL$ 双旋中，$34$ 的左子树 $28$ 在左旋 $23$ 时要挂到 $23$ 的右子树上，不能丢失。
- 插入后不要只检查根结点，要沿插入路径向上逐一检查祖先的平衡因子。

**命题规律**：本题属于“查找”章节中平衡二叉树（AVL）的插入操作，是 408 选择题和综合应用题的常考题型。常见变式有：给出插入序列画 AVL 树；判断某次插入后的旋转类型；计算等概率查找成功或失败的平均查找长度；比较 BST 与 AVL 的树高和查找性能；以及代码填空或旋转函数设计。复习时应熟练掌握四种旋转的树形变化，并养成用中序遍历检查 BST 性质、用平衡因子检查平衡性的习惯。

# 选择题 第 3 题

![[_Attachments/题目识别/27_王道408-题目/DS-C01-12-M03_题目.png|题目]]

3. 某算法的时间复杂度为 $O(n^2)$, 则表示该算法的 ( ).

A. 问题规模是 $n^2$
B. 执行时间等于 $n^2$
C. 执行时间与 $n^2$ 成正比
D. 问题规模与 $n^2$ 成正比

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C01-12-M03_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 C。算法时间复杂度为 $O(n^2)$ 表示算法执行时间的增长率和 $n^2$ 的增长率同阶，即通常所说“执行时间与 $n^2$ 成正比”。

**解题切入点**：本题是概念题，考点是“时间复杂度”与“大 $O$ 记号”的含义。拿到题目先想清楚：$n$ 是问题规模，$T(n)$ 是执行时间或基本运算次数，$O(n^2)$ 描述的是 $T(n)$ 随 $n$ 增大时的增长趋势，而不是绝对时间，也不是问题规模本身。

**推演**：

设问题规模为 $n$，算法执行时间为 $T(n)$。  
时间复杂度为 $O(n^2)$，按教材中的渐近含义可理解为：当 $n$ 足够大时，$T(n)$ 的增长量级与 $n^2$ 一致，即存在正常数 $C$ 和 $n_0$，使

$$
T(n) \le C n^2 \quad (n \ge n_0)
$$

严格地说，大 $O$ 表示的是“上界”，但本题按 408 教材的常规理解，$O(n^2)$ 表示算法的执行时间按 $n^2$ 的量级增长。

逐项判断：

- A 错：问题规模是 $n$，不是 $n^2$。$n^2$ 只是时间复杂度的增长函数。
- B 错：执行时间不一定等于 $n^2$。例如实际执行时间可能是

$$
T(n)=3n^2+2n+1
$$

它仍然是 $O(n^2)$，但不等于 $n^2$。时间复杂度忽略常数因子和低阶项。
- C 对：$O(n^2)$ 表示执行时间随 $n^2$ 同阶增长。例如若

$$
T(n)\approx C n^2
$$

则当 $n$ 变为 $2n$ 时，执行时间约变为原来的 $4$ 倍，这就是“与 $n^2$ 成正比”的增长趋势。
- D 错：问题规模仍然是 $n$，不能说问题规模与 $n^2$ 成正比。

因此正确答案是 C。

**易错点**：

- 容易误选 B：把 $O(n^2)$ 理解为“执行时间恰好是 $n^2$”。实际上 $O$ 只刻画数量级，$T(n)=2n^2+100n$ 也是 $O(n^2)$。
- 容易误选 A 或 D：混淆“问题规模”和“时间复杂度函数”。问题规模是算法输入数据量 $n$，$n^2$ 是复杂度函数，不是问题规模。
- 若从严格数学定义看，$O(n^2)$ 只说明不超过 $n^2$ 的常数倍，$T(n)=n\log n$ 也满足 $O(n^2)$。但考研 408 教材语境中，本题选项 C 是最恰当的理解。

**命题规律**：本题属于“算法效率度量”中的基础概念题，常以选择题形式考查。常见变式包括：给出双层循环求时间复杂度：

```c
for (i = 0; i < n; i++)
    for (j = 0; j < n; j++)
        x++;
```

其时间复杂度为 $O(n^2)$。还会考查 $O$、$\Omega$、$\Theta$ 的区别，以及常见复杂度排序：

$$
O(1) < O(\log n) < O(n) < O(n\log n) < O(n^2) < O(n^3) < O(2^n)
$$

复习时要重点理解“时间复杂度是增长趋势，不是精确运行时间”，并熟练根据循环层数和递归式判断复杂度。

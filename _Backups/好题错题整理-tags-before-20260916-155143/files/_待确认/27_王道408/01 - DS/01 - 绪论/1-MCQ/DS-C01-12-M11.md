# 选择题 第 11 题

![[_Attachments/题目识别/27_王道408-题目/DS-C01-12-M11_题目.png|题目]]

11. 下列函数代码的时间复杂度是 (  ).
```cpp
int Func(int n){
    if(n==1) return 1;
    else return 2*Func(n/2)+n;
}
```
(A) $O(n)$
(B) $O(n\log_2 n)$
(C) $O(\log_2 n)$
(D) $O(n^2)$

## DeepSeek V4 Flash Max 解析

**答案**：选 C，时间复杂度为 $O(\log_2 n)$。

**解题切入点**：拿到递归函数先不要急着列 $T(n)=...$，先数清楚递归调用出现了几次。`2*Func(n/2)` 中 `*2` 是普通乘法，不是两次递归调用；递归调用只有 `Func(n/2)` 一次。因此问题规模每次减半且只走一条链，类似二分查找，应优先定位到 $O(\log n)$。

**推演**：设 $T(n)$ 为 `Func(n)` 的执行时间。按 408 的约定，比较、乘法、加法、返回等基本操作均为常数时间。

当 $n=1$ 时：
$$T(1)=O(1)$$

当 $n>1$ 时：
$$T(n)=T(\lfloor n/2\rfloor)+O(1)$$

原因是代码中只调用了一次 `Func(n/2)`，随后做一次乘法、一次加法并返回，这些都是常数时间；没有循环，所以非递归部分不是 $O(n)$，而是 $O(1)$。

展开求解，为简单起见令 $n=2^k$：
$$T(2^k)=T(2^{k-1})+c=\cdots=T(1)+kc=O(k)=O(\log_2 n)$$

用递归树看，递归树是一条链，只有一个分支，深度约为 $\lfloor\log_2 n\rfloor+1$，每层工作量为 $O(1)$，所以：
$$T(n)=\Theta(\log_2 n)$$

补充：若把返回值记为 $F(n)$，则返回值满足：
$$F(n)=2F(n/2)+n,\quad F(1)=1$$

解得 $F(n)=\Theta(n\log_2 n)$，但这是函数返回值的量级，不是时间复杂度，不能据此选 B。

**易错点**：

1. 把 `2*Func(n/2)` 误认为两次递归调用。实际上 `2` 只是乘数，递归调用次数仍为 1。
2. 把返回值递推式 $F(n)=2F(n/2)+n$ 当成时间递推式，从而误选 B。这里的 `+n` 只是常数时间的加法，不是 $O(n)$ 的合并开销。
3. 忽略 C/C++ 中 `n/2` 的整数除法；这不影响渐近复杂度，递归深度仍为 $O(\log n)$。
4. 若题目改成 `return Func(n/2)+Func(n/2)+n;`，那才是两次递归调用；在常数合并下时间复杂度为 $O(n)$，但本题不是这种写法。

**命题规律**：本题属于“递归函数时间复杂度”的经典辨析题，常用递推展开、递归树或主定理解题。主定理也可验证：
$$T(n)=T(n/2)+O(1),\quad a=1,\ b=2,\ f(n)=O(1)$$

因为 $f(n)=\Theta(n^{\log_2 1})=\Theta(1)$，所以 $T(n)=\Theta(\log n)$。

常见变式：

- `return 2*Func(n/2)+n;`：一次递归调用，$O(\log n)$；
- `return Func(n/2)+Func(n/2)+n;`：两次递归调用，若合并为 $O(1)$，则 $T(n)=2T(n/2)+O(1)=O(n)$；
- 若两次递归调用且每层合并需要 $O(n)$，则 $T(n)=2T(n/2)+O(n)=O(n\log n)$。

复习建议：先画递归树，确认“分支数”等于代码中递归调用的次数，再列 $T(n)$ 递推式；不要被乘数和返回值干扰。

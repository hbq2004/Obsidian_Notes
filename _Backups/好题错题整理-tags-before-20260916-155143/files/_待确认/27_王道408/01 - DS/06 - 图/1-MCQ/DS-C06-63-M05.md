## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C06-63-M05_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 A。标准图的广度优先遍历中，顶点一旦入队就被 `visited` 标记为已访问，之后不会再次入队，所以每个顶点的入队次数最多为 $1$ 次。

**解题切入点**：拿到题先抓住两个关键：**队列**和 `visited` 标记。队列是 BFS 的辅助结构，用来保证“先访问到的顶点先扩展”，而 `visited` 数组决定一个顶点是否会被重复发现。可以类比比赛报名：入队就是报名成功，报名后名单上已有名字，后面再来都不再受理；所以每个顶点入队次数不可能超过一次。

**推演**：

设图 $G=(V,E)$，标准 BFS 伪代码如下：

```c
for (i = 0; i < G.vexnum; i++)
    visited[i] = FALSE;
InitQueue(Q);

for (i = 0; i < G.vexnum; i++) {
    if (!visited[i]) {
        visited[i] = TRUE;
        EnQueue(Q, i);

        while (!QueueEmpty(Q)) {
            DeQueue(Q, u);
            for (w = FirstNeighbor(G, u); w >= 0; w = NextNeighbor(G, u, w)) {
                if (!visited[w]) {
                    visited[w] = TRUE;
                    EnQueue(Q, w);
                }
            }
        }
    }
}
```

对任意顶点 $x$，入队只能发生在以下两种情况：

1. 作为某个遍历起点 $i$ 被 `!visited[i]` 判断通过后入队；
2. 作为某个已出队顶点 $u$ 的邻接点 $w$，且 `!visited[w]` 判断通过后入队。

但无论哪种情况，顶点 $x$ 入队时都会立即执行：

$$
visited[x] = \text{TRUE}
$$

此后 $visited[x]$ 在本次遍历中不会再被置为 $\text{FALSE}$。因此，之后任何其他顶点再通过邻接关系访问到 $x$ 时，都会因为 `!visited[x]` 为假而无法让 $x$ 入队。

所以，每个顶点最多入队 $1$ 次。若是一次完整的图的广度优先遍历，则每个顶点实际入队 $1$ 次；若只是从某个源点开始 BFS，则不可达顶点入队 $0$ 次，但也不会超过 $1$ 次。

因此答案是：

$$
\text{A. } 1
$$

**易错点**：

1. **误以为无向图中一个顶点会被多个邻接点重复入队。**  
   实际上第一个发现它的邻接点会将其入队并立即标记 `visited`，后续邻接点再遇到它时已经访问过，不会入队。

2. **混淆“邻接点检查次数”和“入队次数”。**  
   无向图中每条边会被两个端点各检查一次，但检查到已访问顶点时不会入队。检查次数可以很多，入队次数仍最多一次。

3. **使用“出队时才标记 visited”的非标准写法。**  
   如果只在出队时标记，顶点可能被多个邻接点重复入队。408 和教材默认采用“入队时立即标记”的标准 BFS 写法。

4. **忽略非连通图。**  
   非连通图通过外层循环逐个检查顶点，但每个顶点仍只会在第一次被发现时入队一次，不会因为图不连通而重复入队。

**命题规律**：本题属于图遍历的基础概念题，考查 BFS 中队列和 `visited` 标记的作用。常见变式包括：BFS 的时间复杂度为什么是 $O(|V|+|E|)$、邻接矩阵和邻接表下 BFS 复杂度不同、BFS 生成树是否唯一、DFS 中栈的最大深度等。复习时要把 BFS/DFS 伪代码逐行理解清楚，尤其注意 `visited` 的赋值时机；多画图模拟入队、出队过程，能有效避免此类概念题出错。

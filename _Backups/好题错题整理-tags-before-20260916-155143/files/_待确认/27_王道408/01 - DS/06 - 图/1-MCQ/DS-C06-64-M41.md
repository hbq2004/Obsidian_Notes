# 选择题 第 41 题

![[_Attachments/题目识别/27_王道408-题目/DS-C06-64-M41_题目.png|题目]]

41.【2020统考真题】修改递归方式实现的图的深度优先搜索（$DFS$）算法,将输出（访问）顶点信息的语句移到退出递归前（执行输出语句后立刻退出递归）。采用修改后的算法遍历有向无环图$G$，若输出结果中包含$G$中的全部顶点,则输出的顶点序列是$G$的（ ）。
(A) 拓扑有序序列
(B) 逆拓扑有序序列
(C) 广度优先搜索序列
(D) 深度优先搜索序列

## DeepSeek V4 Flash Max 解析

**答案**：选 **B（逆拓扑有序序列）**。修改后的 DFS 把输出语句移到递归返回前，输出顺序等价于 DFS 的“完成时间”顺序；对有向无环图 \(G\)，该序列是逆拓扑有序序列。

**解题切入点**：  
拿到题目先看“输出语句在递归前还是递归后”。原 DFS 是“先输出、再递归”，所以输出的是普通 DFS 先序序列；本题改为“先递归完所有邻接点，退出递归前再输出”，即 DFS 后序/完成时间序列。可类比 DFS 求拓扑排序的常见实现：`dfs(v); 把 v 压入栈;` 最后弹栈才是拓扑序；如果直接输出完成顺序，得到的是逆拓扑序。

**推演**：  
修改后的 DFS 核心代码思路如下：

```c
void DFS(Graph G, int v) {
    visited[v] = TRUE;
    for (w = FirstNeighbor(G, v); w != -1; w = NextNeighbor(G, v, w))
        if (!visited[w])
            DFS(G, w);
    printf("%d ", v);   // 退出递归前输出，输出后立即返回
}
```

设 \(G\) 是有向无环图，任取一条边 \(u \to v\)。在 DFS 过程中：

- 若 \(v\) 尚未被访问，则在处理 \(u\) 时会递归进入 \(v\)，\(v\) 一定在 \(u\) 返回前输出，所以 \(v\) 先于 \(u\) 输出；
- 若 \(v\) 正在递归栈中，说明存在路径 \(v \rightsquigarrow u\)，与边 \(u \to v\) 会构成回路，这与“有向无环图”矛盾，因此这种情况不会出现；
- 若 \(v\) 已经被访问完毕，则 \(v\) 早已输出，当然先于 \(u\) 输出。

因此，对任意边 \(u \to v\)，都有 \(v\) 先于 \(u\) 输出。  
设输出序列为

\[
\langle v_1, v_2, \ldots, v_n \rangle
\]

则对任意边 \(v_i \to v_j\)，必有 \(j < i\)，也就是每个顶点的后继都排在其前面，这正是逆拓扑有序序列。若将该序列倒序，才是拓扑有序序列。

例如 \(A \to B \to C\)，修改后从 \(A\) 开始输出为 \(C, B, A\)，它是逆拓扑序；而 \(A, B, C\) 才是拓扑序。

**易错点**：  
- 容易误选 **D**：修改后仍然是 DFS，但不是普通 DFS 先序序列，而是 DFS 后序序列。  
- 容易误选 **A**：DFS 确实可以用来求拓扑序列，但通常是“完成时压栈，最后弹栈输出”，直接按完成时间输出得到的是逆拓扑序。  
- `visited` 标记必须在进入递归时置位，不能随输出语句移到末尾，否则会造成重复访问或死循环。  
- 题目强调“有向无环图”是必要的；如果图中有环，则不存在拓扑有序序列，上述推理也会因回路而不成立。

**命题规律**：  
本题考点是“DFS 遍历序列”与“拓扑排序/逆拓扑排序”的关系。常见变式包括：已知 DFS 先序或后序序列，判断是否为拓扑序；用 DFS 完成时间判断有向图是否有环；用栈实现 DFS 拓扑排序。复习时应多画有向无环图手动模拟 DFS，分清“访问时输出”和“退出时输出”，并理解“完成时间递减才是拓扑序”这一关键结论。

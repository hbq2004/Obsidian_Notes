## DeepSeek V4 Flash Max 解析

**答案**：  
核心是“用邻接表的边去填矩阵”：先把矩阵所有元素置为 0，然后遍历每个顶点的边链表，遇到邻接点 $j$ 就把 $A[i][j]$ 置 1（网图则置权值）。完整转换时间复杂度为 $O(n^2)$，其中遍历链表部分为 $O(n+e)$；辅助空间为 $O(1)$。

**解题切入点**：  
拿到题先明确：邻接表本身就是“按顶点分行存储边”的结构，而邻接矩阵是“按顶点对存储边”。  
所以不要用两层循环枚举矩阵格子，再去邻接表里查边，那样会重复扫描链表、效率低。正确做法是反向操作：直接遍历每个顶点的边链表，每遇到一条边，就在矩阵对应位置“打勾”。

这就像做签到表：与其一个一个格子问“这个位置有人吗”，不如直接遍历每个人名下的名单，在表格里勾出他该出席的位置。

**推演**：  
设顶点编号为 $0 \sim n-1$，用 $N(i)$ 表示顶点 $i$ 的邻接点集合（有向图中表示出边终点集合）。则邻接矩阵 $A$ 满足：

$$
A[i][j]=1 \iff j \in N(i)
$$

若是带权图，则：

$$
A[i][j]=
\begin{cases}
w(i,j), & (i,j)\in E\\
0\text{ 或 }\infty, & (i,j)\notin E
\end{cases}
$$

因此，转换算法只需做两件事：

1. 初始化矩阵所有元素为 0；
2. 对每个顶点 $i$，扫描其边链表，对链表中每个结点 $p$，令：

$$
A[i][p\to adjvex]=1
$$

若带权，则令：

$$
A[i][p\to adjvex]=p\to weight
$$

关键代码如下：

```c
#define MaxVertexNum 100

typedef struct ArcNode {
    int adjvex;               // 该边/弧指向的顶点编号
    // int weight;            // 带权图使用
    struct ArcNode *nextarc;
} ArcNode;

typedef struct VNode {
    int data;                 // 顶点信息
    ArcNode *firstarc;        // 第一条边
} VNode;

typedef struct {
    VNode adjlist[MaxVertexNum];
    int n, e;                 // 顶点数、边/弧数
} ALGraph;

typedef struct {
    int vexs[MaxVertexNum];
    int edges[MaxVertexNum][MaxVertexNum];
    int n, e;
} MGraph;

void ListToMat(ALGraph *G, MGraph *M) {
    int i, j;
    ArcNode *p;

    M->n = G->n;
    M->e = G->e;

    // 1. 初始化矩阵，所有位置先看作无边
    for (i = 0; i < G->n; i++) {
        M->vexs[i] = G->adjlist[i].data;
        for (j = 0; j < G->n; j++)
            M->edges[i][j] = 0;
        // 若用 INF 表示无边，则初始化为 INF
    }

    // 2. 遍历邻接表，把每条边填入矩阵
    for (i = 0; i < G->n; i++) {
        p = G->adjlist[i].firstarc;
        while (p != NULL) {
            M->edges[i][p->adjvex] = 1;      // 无权图
            // M->edges[i][p->adjvex] = p->weight;  // 带权图
            p = p->nextarc;
        }
    }
}
```

正确性说明：  
初始化后矩阵所有位置都为 0，保证“无边”的位置正确。  
外层循环处理顶点 $i$ 时，内层循环恰好遍历 $L[i]$ 中所有边结点；每个边结点 $p$ 表示一条从 $i$ 到 $p\to adjvex$ 的边/弧，因此将 $A[i][p\to adjvex]$ 置 1 是必要且充分的。  
最终每个链表结点都被处理一次，所以不漏边、不多边。

对于无向图，标准邻接表中边 $(i,j)$ 既会出现在 $L[i]$ 中，也会出现在 $L[j]$ 中，因此算法会分别写入 $A[i][j]$ 和 $A[j][i]$，矩阵自然对称，不需要再单独写对称位置。

复杂度分析：  
初始化矩阵需要 $O(n^2)$；遍历邻接表，有向图是 $O(n+e)$，无向图链表总长度为 $2e$，也记为 $O(n+e)$。  
因此完整算法时间复杂度为：

$$
O(n^2)
$$

如果题目约定矩阵已经预先清零，则转换主体为：

$$
O(n+e)
$$

辅助空间为 $O(1)$；邻接矩阵本身占 $O(n^2)$ 空间。

**易错点**：  
1. **忘记初始化矩阵**。C 语言中局部数组元素不是默认 0，必须显式清零。  
2. **用矩阵去找链表**。不要写“枚举 $i,j$，再扫描邻接表判断边是否存在”的算法，这样会把复杂度退化到 $O(n^2 \times \text{平均度})$。  
3. **盲目写对称位置**。对无向图，标准邻接表已经两边都存，所以不需要额外写 $A[j][i]$；对有向图，若写 $A[p\to adjvex][i]=1$，会错误地产生反向边。  
4. **带权图仍然赋 1**。如果是网图，应该赋权值，无边位置应初始化为 0 或 $\infty$，不要和权值 0 混淆。  
5. **下标从 1 开始的情况**。若顶点编号从 1 开始，矩阵应开成 $(n+1)\times(n+1)$，循环从 1 到 $n$，核心逻辑不变。

**命题规律**：  
本题属于“图的存储结构”中的高频基础题，408 常考两种存储结构之间的转换、时间/空间复杂度比较，以及基于不同存储结构实现 DFS/BFS 的差别。

常见变式有：

- 邻接矩阵转换为邻接表：扫描矩阵每一行，对非零元素创建边结点；
- 带权图的转换：把 1 换成权值，把 0 换成 $\infty$；
- 求顶点的度、出度、入度；
- 判断任意两个顶点之间是否存在边。

复习时建议把邻接表和邻接矩阵的结构体定义、转换代码、复杂度分析一起记忆，重点关注“有向图/无向图”“无权图/带权图”“下标从 0 开始/从 1 开始”这三个易混点。

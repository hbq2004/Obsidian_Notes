typedef struct {

## DeepSeek V4 Flash Max 解析

**答案**：核心思路是遍历邻接矩阵，统计每个顶点的出度和入度，输出所有“出度大于入度”的顶点并返回个数；时间复杂度为 \(O(n^2)\)，附加空间为 \(O(n)\)。

**解题切入点**：看到“K 顶点”，应立刻把它转化为“出度与入度的大小比较”。邻接矩阵中，第 \(i\) 行的非零元素个数是顶点 \(v_i\) 的出度，第 \(i\) 列的非零元素个数是 \(v_i\) 的入度。因此只需要一次矩阵遍历完成度数统计，再一次扫描顶点表输出即可。可以类比比赛中的“净胜分”：出度是胜场，入度是负场，K 顶点就是净胜分为正的选手。

**推演**：

设图有 \(n=G.numVertices\) 个顶点，顶点记为 \(v_0,v_1,\dots,v_{n-1}\)。邻接矩阵满足：

\[
A[i][j]=1 \iff \text{存在有向边 } v_i \to v_j
\]

则：

\[
\operatorname{out}(v_i)=\sum_{j=0}^{n-1} A[i][j]
\]

\[
\operatorname{in}(v_i)=\sum_{j=0}^{n-1} A[j][i]
\]

\(v_i\) 是 K 顶点当且仅当：

\[
\operatorname{out}(v_i) > \operatorname{in}(v_i)
\]

算法步骤：

1. 初始化两个数组 `outdeg`、`indeg` 为 0。
2. 双重循环遍历邻接矩阵。
3. 若 `G.Edge[i][j] == 1`，说明存在边 \(v_i \to v_j\)，则：
   - `outdeg[i]++`，表示 \(v_i\) 的出度加 1；
   - `indeg[j]++`，表示 \(v_j\) 的入度加 1。
4. 遍历所有顶点，若 `outdeg[i] > indeg[i]`，输出 `G.VerticesList[i]`，计数加 1。
5. 返回计数。

正确性说明：每条有向边 \(v_i \to v_j\) 在邻接矩阵中唯一对应一个元素 `Edge[i][j]`，扫描一次矩阵后，所有顶点的出度和入度都被完整统计。之后按 K 顶点的定义比较并输出，因此不会漏掉或重复。

C/C++ 代码描述如下：

```c
int printVertices(MGraph G) {
    int indeg[MAXV] = {0};
    int outdeg[MAXV] = {0};
    int n = G.numVertices;
    int cnt = 0;
    int i, j;

    // 遍历邻接矩阵，统计出度和入度
    for (i = 0; i < n; i++) {
        for (j = 0; j < n; j++) {
            if (G.Edge[i][j] == 1) {   // 存在有向边 i -> j
                outdeg[i]++;           // 起点 i 的出度 +1
                indeg[j]++;            // 终点 j 的入度 +1
            }
        }
    }

    // 所有度数统计完成后，再比较输出
    for (i = 0; i < n; i++) {
        if (outdeg[i] > indeg[i]) {
            printf("%c ", G.VerticesList[i]);
            cnt++;
        }
    }

    return cnt;
}
```

复杂度分析：矩阵扫描需要 \(O(n^2)\) 时间，输出扫描需要 \(O(n)\) 时间，因此总时间复杂度为：

\[
O(n^2)
\]

辅助数组大小为 \(2n\)，故空间复杂度为 \(O(n)\)。由于题目给定邻接矩阵，\(O(n^2)\) 的时间复杂度已是该存储结构下的自然下界。

**易错点**：

1. **搞混行和列的含义**：`Edge[i][j]` 表示从 \(v_i\) 到 \(v_j\) 的边，所以出度更新在 `i`，入度更新在 `j`，不要颠倒。
2. **边统计边输出**：扫描完第 \(i\) 行后，`outdeg[i]` 已经确定，但 `indeg[i]` 可能还没统计完，因为后面行中仍有指向 \(v_i\) 的边。必须等整个矩阵扫描结束后再输出。
3. **把 `numEdges` 当作顶点数**：循环次数应使用 `G.numVertices`，不是 `G.numEdges`。
4. **忘记返回值或忘记输出**：题目要求既输出 K 顶点，又返回个数，二者缺一不可。
5. **自环处理**：若存在自环 \(v_i \to v_i\)，该边会使 `outdeg[i]` 和 `indeg[i]` 都加 1，相互抵消，不会影响 K 顶点判断；按普通边处理即可。

**命题规律**：本题属于“图的基本概念 + 邻接矩阵存储”的常规综合题，重点考查有向图中出度、入度与邻接矩阵行、列之间的对应关系。常见变式包括：改为邻接表存储求 K 顶点、统计“入度等于出度”的顶点、求出入度差最大的顶点、判断图中是否存在 K 顶点等。复习时应熟练掌握邻接矩阵、邻接表、逆邻接表等多种存储方式下度数的计算方法，并注意在算法题中先写设计思想，再写代码，最后补充时间、空间复杂度。

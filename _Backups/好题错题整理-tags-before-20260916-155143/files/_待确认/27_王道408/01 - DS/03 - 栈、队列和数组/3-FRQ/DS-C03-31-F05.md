## DeepSeek V4 Flash Max 解析

**答案**：将两个栈的栈底固定在共享数组的两端，$S1$ 从低地址向高地址增长，$S2$ 从高地址向低地址增长，用两个栈顶指针“相向而行”，以 $\text{top}_1+1=\text{top}_2$ 作为栈满条件，即可实现共享存储区上 $S1$、$S2$ 的入栈与出栈操作。

**解题切入点**：拿到题目应先明确“栈顶相向、迎面增长”的含义：两个栈底不动，栈顶指针向中间靠拢。可以把它类比为“双指针相向移动”问题：左指针从 $-1$ 出发向右，右指针从 $\text{maxsize}$ 出发向左，两个指针相遇或相邻时空间耗尽。因此，核心考点是顺序栈的指针移动方向与栈满/栈空判断条件。

**推演**：

设共享栈的存储区为数组 `data[0..maxsize-1]`，定义两个栈顶指针：

- $\text{top}_1$：$S1$ 的栈顶指针，初始化为 $-1$，表示 $S1$ 为空；
- $\text{top}_2$：$S2$ 的栈顶指针，初始化为 $\text{maxsize}$，表示 $S2$ 为空。

$S1$ 入栈时，先使 $\text{top}_1$ 加 $1$，再写入元素；$S2$ 入栈时，先使 $\text{top}_2$ 减 $1$，再写入元素。两个指针迎面移动，中间的空闲区域被逐渐占用。

栈满条件：当 $\text{top}_1+1=\text{top}_2$ 时，两个栈顶指针相邻，中间没有任何空闲单元，此时无论向哪个栈入栈都会溢出，因此判定为栈满。即：
$$
\text{栈满} \iff \text{top}_1+1=\text{top}_2
$$

栈空条件：

- $S1$ 空：$\text{top}_1=-1$；
- $S2$ 空：$\text{top}_2=\text{maxsize}$。

共享栈的数据结构定义如下：

```c
#define maxsize 100

typedef struct {
    int data[maxsize];
    int top1, top2;   // 两个栈顶指针
} SharedStack;
```

初始化算法：

```c
void InitStack(SharedStack &S) {
    S.top1 = -1;          // S1 空
    S.top2 = maxsize;     // S2 空
}
```

入栈算法（按栈号 $i$ 区分 $S1$ 和 $S2$）：

```c
bool Push(SharedStack &S, int i, int x) {
    if (S.top1 + 1 == S.top2)   // 栈满
        return false;

    if (i == 1) {
        S.data[++S.top1] = x;   // S1 入栈：先移指针，再存元素
    } else if (i == 2) {
        S.data[--S.top2] = x;   // S2 入栈：先移指针，再存元素
    } else {
        return false;           // 栈号不合法
    }
    return true;
}
```

出栈算法：

```c
bool Pop(SharedStack &S, int i, int &x) {
    if (i == 1) {
        if (S.top1 == -1)       // S1 空
            return false;
        x = S.data[S.top1--];   // 取出栈顶元素，指针回退
    } else if (i == 2) {
        if (S.top2 == maxsize)  // S2 空
            return false;
        x = S.data[S.top2++];   // 取出栈顶元素，指针向高端回退
    } else {
        return false;
    }
    return true;
}
```

也可以将 $S1$、$S2$ 分别写成独立的函数，如 `Push1`、`Push2`、`Pop1`、`Pop2`，其核心思想完全相同。

时间复杂度：入栈、出栈操作均为 $O(1)$。空间复杂度：整个共享栈占用固定大小的数组，为 $O(\text{maxsize})$。

**易错点**：

1. **栈满条件误写为 $\text{top}_1=\text{top}_2$**。两个指针相邻但未重合时已经无空闲空间，若等到相等再判断，可能已经发生越界覆盖。正确条件是 $\text{top}_1+1=\text{top}_2$。
2. **$S2$ 入栈方向写反**。$S2$ 从高端向低端增长，应用 `data[--top2] = x`，而不是 `data[top2++] = x` 或 `data[++top2] = x`。
3. **$S2$ 出栈边界条件错误**。$S2$ 空栈时 $\text{top}_2=\text{maxsize}$，不能误用 $\text{top}_2=-1$ 或 $\text{top}_2=0$ 作为空栈判断。
4. **初始化指针错误**。$\text{top}_1$ 初始化为 $-1$，$\text{top}_2$ 初始化为 $\text{maxsize}$，保证空栈判断统一。
5. **入栈前未判满、出栈前未判空**。这会导致数组越界或读到无效数据。
6. **忽略栈号参数 $i$ 的合法性检查**。在实际代码中应增加对 $i=1,2$ 的判断，避免非法访问。

**命题规律**：该题是顺序栈的经典变式，常见于“共享栈”相关的选择题或代码填空题。考点集中在：栈满条件、两个栈顶指针的移动方向、空栈判断、入栈/出栈操作步骤。变式可能包括：将共享栈改为“栈顶指针指向栈顶元素的下一个位置”，此时满/空条件和操作顺序会相应变化；或者要求画出共享栈在若干次入栈、出栈后的状态图；或者多个栈共享同一存储区。复习建议：牢牢掌握“指针指向栈顶元素”与“指针指向栈顶元素下一位置”两套规则，遇到共享栈时先明确两个栈的起始栈底位置，再按照“先判满/空、再移动指针、再存取元素”的步骤写出代码，即可应对此类题目。

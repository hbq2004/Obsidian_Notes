# 综合题 第 4 题

![[_Attachments/题目识别/27_王道408-题目/DS-C03-31-F04_题目.png|题目]]

4. 设单链表的表头指针为 $L$, 结点结构由 $data$ 和 $next$ 两个域构成, 其中 $data$ 域为字符型. 设计算法判断该链表的全部 $n$ 个字符是否中心对称. 例如， $xyx$、 $xyyx$ 都是中心对称的.

## DeepSeek V4 Flash Max 解析

**答案**：用辅助栈保存链表前 $\lfloor n/2\rfloor$ 个字符，再从后半段开始依次与栈顶弹出的字符比较；若全部相等，则中心对称，否则不对称。时间复杂度 $O(n)$，空间复杂度 $O(n)$（栈中最多 $\lfloor n/2\rfloor$ 个字符）。

**解题切入点**：  
中心对称就是“回文”。数组/顺序表判断回文常用两个指针从两端向中间走；但单链表只有 `next`，不能方便地从后往前遍历。因此考点立刻定位为：**用栈的“后进先出”特性把前半段逆序**，栈顶正好是后半段当前字符需要比对的对象。做题经验上，这等价于“把纸条前半段抄到另一张纸上，再从后半段倒着比对”。

**推演**：

设链表字符序列为 $a_1,a_2,\dots,a_n$。中心对称等价于

$$
a_i=a_{n+1-i},\qquad i=1,2,\dots,\lfloor n/2\rfloor.
$$

算法步骤如下：

1. 若 $n\le 1$，直接返回 `true`。  
2. 令 $p$ 指向第一个数据结点（若带头结点，则令 $p=L\to next$；若不带头结点，则令 $p=L$）。  
3. 初始化栈 `S`，栈顶下标 `top = -1`。  
4. 将前 $\lfloor n/2\rfloor$ 个字符依次入栈，`p` 同步后移。  
5. 若 $n$ 为奇数，则中间字符不需要比较，令 `p = p->next` 跳过它。  
6. 从后半段开始，每次弹出栈顶字符与 `p->data` 比较；若不等，返回 `false`；若相等，继续后移 `p`。  
7. 若结束后栈空，说明所有对称位置都匹配，返回 `true`，否则返回 `false`。

关键代码思路如下：

```c
bool judge(LinkList L, int n) {   // L 指向第一个数据结点
    if (n <= 1) return true;

    char S[n / 2];                // 辅助栈，容量为 floor(n/2)
    int top = -1;
    LinkList p = L;               // 若带头结点，则 p = L->next

    for (int i = 0; i < n / 2; i++) {
        S[++top] = p->data;
        p = p->next;
    }

    if (n % 2 == 1)               // 奇数个字符，跳过中间结点
        p = p->next;

    while (p != NULL) {
        if (top == -1 || S[top] != p->data)
            return false;
        top--;
        p = p->next;
    }

    return top == -1;
}
```

正确性说明：  
当 $n=2m$ 为偶数时，栈中依次保存 $a_1,\dots,a_m$，出栈顺序是 $a_m,\dots,a_1$；后半段从 $a_{m+1}$ 开始比较，第 $j$ 组比较为 $a_{m+j}$ 与 $a_{m-j+1}$，正好满足 $a_i=a_{n+1-i}$。  
当 $n=2m+1$ 为奇数时，中间字符 $a_{m+1}$ 不需要比较，跳过它后，后半段从 $a_{m+2}$ 开始，第 $j$ 组比较为 $a_{m+1+j}$ 与 $a_{m-j+1}$，同样满足对称条件。  
因此算法正确。

若题目没有显式给出 $n$，可先用快慢指针找中点并同步入栈：

```c
fast = slow = 第一个数据结点;
while (fast != NULL && fast->next != NULL) {
    push(slow->data);
    slow = slow->next;
    fast = fast->next->next;
}
if (fast != NULL)          // 奇数长度，跳过中间结点
    slow = slow->next;
while (slow != NULL) {
    if (pop() != slow->data) return false;
    slow = slow->next;
}
```

**易错点**：

- 奇数长度时忘记跳过中间结点。例如 `abcba` 中 `c` 不应参与比较，若不跳过会误判。
- 只把前 $\lfloor n/2\rfloor$ 个字符入栈，不要把全部 $n$ 个字符都入栈；否则后半段没有内容可比较。
- 带头结点和不带头结点混淆：带头结点时第一个数据结点是 `L->next`，不带头结点时是 `L`。
- 空链表、$n=1$ 都应视为中心对称，需要先处理边界。
- 出栈前要检查栈是否为空，循环结束后要检查栈是否为空；不能只凭“比较完所有结点”就返回真。

**命题规律**：  
本题是“线性表 + 栈”的典型综合题，核心是把链表只能单向遍历的缺点用栈弥补。常见变式有：

1. 题目不给出 $n$：用快慢指针找中点，或用一次遍历计数。  
2. 要求空间 $O(1)$：可先找中点，再反转后半段链表后比较，但会修改原链表。  
3. 改为双链表判断中心对称：可直接用两个指针从两端向中间移动。  
4. 改为顺序表/字符串判断回文：用双指针即可。

复习时应重视算法思想、边界条件和复杂度分析，不要只背代码；尤其要熟练区分带头结点与不带头结点、奇数长度与偶数长度的处理。

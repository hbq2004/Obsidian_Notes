2. 若元素的入栈序列为 $A,B,C,D,E$，运用栈操作，能否得到出栈序列 $B,C,A,E,D$ 和 $D,B,A,C,E$？为什么.

## DeepSeek V4 Flash Max 解析

**答案**：第2题中，出栈序列 $B,C,A,E,D$ 可以得到，$D,B,A,C,E$ 不能得到；第3题(1)中合法序列为 **A、D**，非法序列为 B、C；(2) 可用“栈深度计数器”扫描序列判断，合法条件等价于：任意前缀中 $I$ 的个数不少于 $O$ 的个数，且整个序列中 $I$ 和 $O$ 的个数相等。

**解题切入点**：栈的核心特性是“后进先出”。判断一个出栈序列是否可能，关键是看某个元素出栈时，它上面的元素是否已经被弹出。对 $I/O$ 操作序列，则不需要关心具体元素，只需要关心栈中元素个数，这等价于“括号匹配”：$I$ 看作左括号，$O$ 看作右括号，合法序列就是任意前缀中右括号不多于左括号，且总左括号数等于总右括号数。

**推演**：

### 第2题

1. $B,C,A,E,D$ 可以得到，操作过程如下：

\[
A\text{入},\ B\text{入},\ B\text{出},\ C\text{入},\ C\text{出},\ A\text{出},\ D\text{入},\ E\text{入},\ E\text{出},\ D\text{出}
\]

出栈顺序正好是：

\[
B,C,A,E,D
\]

2. $D,B,A,C,E$ 不能得到。理由如下：

若第一个出栈元素是 $D$，则在 $D$ 出栈前，$A,B,C,D$ 都必须已经入栈，且 $A,B,C$ 都还留在栈中。弹出 $D$ 后，栈中自底向上为：

\[
A,B,C
\]

此时栈顶是 $C$。要想第二个出栈元素是 $B$，必须先弹出 $C$，但这样 $C$ 就会比 $B$ 先出栈，与目标序列中 $C$ 在 $B$ 之后矛盾。因此该序列不合法。

### 第3题(1)

设 $d_k$ 表示前 $k$ 个操作后栈中元素个数，若 $I$ 记 $+1$，$O$ 记 $-1$，则合法序列必须满足：

\[
d_k \ge 0 \quad (1 \le k \le n),\qquad d_n = 0
\]

逐个判断：

| 序列 | 栈深度变化 | 结论 |
|---|---|---|
| A. `IOIIOIOO` | $1,0,1,2,1,2,1,0$ | 合法 |
| B. `IOOIIOO` | $1,0,-1,\dots$ | 非法，第 3 个 $O$ 时栈已空 |
| C. `IIIOIOIO` | $1,2,3,2,3,2,3,2$ | 非法，终态不为空 |
| D. `IIIOOIOO` | $1,2,3,2,1,2,1,0$ | 合法 |

所以合法序列是 **A、D**。

说明：若教材中 B 项原写作 `IOOIIO`，结论也不变，因为第 3 个字符 $O$ 发生时栈已经为空，仍然非法。

### 第3题(2)

判定算法：用一个整型变量 `top` 模拟栈中元素个数，遇到 `I` 则入栈，`top++`；遇到 `O` 则出栈，但出栈前必须保证栈不空，即 `top > 0`。扫描结束后，若 `top == 0`，则合法。

关键代码如下：

```c
bool judge(char S[], int n) {
    int top = 0;                 // 栈中元素个数，初始为空
    for (int i = 0; i < n; i++) {
        if (S[i] == 'I') {
            top++;               // 入栈
        } else if (S[i] == 'O') {
            if (top == 0) {      // 栈空时不能出栈
                return false;
            }
            top--;               // 出栈
        }
    }
    return top == 0;             // 终态必须为空栈
}
```

时间复杂度为 $O(n)$，空间复杂度为 $O(1)$。

**易错点**：

- 只检查前缀中 $I$ 的个数不少于 $O$，却忘记最后 $I$ 和 $O$ 的总数必须相等；例如 C 项 `IIIOIOIO` 前缀没有下溢，但终态不为空，所以非法。
- 只检查总数相等，却忽略过程中栈空时不能出栈；例如 B 项若为 `IOOIIO`，$I$ 和 $O$ 个数相等，但第 3 个字符 $O$ 时已经下溢，仍然非法。
- 判断出栈序列时，容易忽略“被压在下面的元素”。例如要第一个弹出 $D$，则 $A,B,C$ 都在 $D$ 下面，$C$ 会挡住 $B$，所以 $B$ 不可能紧接着 $D$ 出栈。
- 算法实现时，遇到 `O` 必须先判断 `top == 0`，再执行 `top--`；反过来会出错。

**命题规律**：本题考点是栈的后进先出性质和合法出入栈序列的判定。常见变式有：给出入栈序列判断某个出栈序列是否合法；判断 $I/O$ 操作序列是否合法；求合法出栈序列的数量，即卡特兰数：

\[
\frac{1}{n+1}\binom{2n}{n}
\]

复习时应熟练掌握“栈模拟”和“前缀计数”两种方法：判断出栈序列时用栈模拟，判断 $I/O$ 序列时用计数器模拟栈深。这类题既可以出选择题，也可以出算法设计题，属于栈部分的必会题型。

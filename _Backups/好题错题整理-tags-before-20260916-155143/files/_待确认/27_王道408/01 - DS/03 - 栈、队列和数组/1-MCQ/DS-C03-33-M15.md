# 选择题 第 15 题

![[_Attachments/题目识别/27_王道408-题目/DS-C03-33-M15_题目.png|题目]]

15.【2015 统考真题】 已知程序如下:
```cpp
int S(int n)
{   return (n<=0)?0:S(n-1)+n;    }
void main()
{   cout<<S(1);  }
```
程序运行时使用栈来保存调用过程的信息，自栈底到栈顶保存的信息依次对应的是(   )。
A. $main(\ ) \rightarrow S(1) \rightarrow S(0)$
B. $S(0) \rightarrow S(1) \rightarrow main(\ )$
C. $main(\ ) \rightarrow S(0) \rightarrow S(1)$
D. $S(1) \rightarrow S(0) \rightarrow main(\ )$

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C03-33-M15_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 A。程序运行到最深时，调用栈自栈底到栈顶依次为 $main() \rightarrow S(1) \rightarrow S(0)$。

**解题切入点**：看到递归函数，首先想“函数调用栈”的压栈与弹栈过程。题目问“自栈底到栈顶保存的信息”，本质是问“调用发生的先后顺序”：先调用者压栈，后调用者压栈在上。按调用链画出：`main` 调用 `S(1)`，`S(1)` 调用 `S(0)`，所以栈底到栈顶就是 `main -> S(1) -> S(0)`。

**推演**：

1. 程序从 `main` 开始执行，遇到 `cout << S(1);` 时，需要调用函数 `S(1)`。系统将 `main` 的返回地址等信息压入栈中，此时栈中自底向上为：

$$
main()
$$

2. 进入 `S(1)`，参数 $n=1$，判断 `n <= 0` 为假，因此需要计算：

$$
S(n-1)+n = S(0)+1
$$

为了得到 `S(0)` 的值，程序继续调用 `S(0)`，系统将 `S(1)` 的调用现场压入栈中，此时栈中自底向上为：

$$
main() \rightarrow S(1)
$$

3. 进入 `S(0)`，参数 $n=0$，判断 `n <= 0` 为真，函数直接返回 0，不再产生新的函数调用。此时栈中自底向上为：

$$
main() \rightarrow S(1) \rightarrow S(0)
$$

4. 之后 `S(0)` 返回并弹栈，`S(1)` 得到结果 $0+1=1$，返回并弹栈，最后 `main` 继续执行并输出 1。

因此，在递归调用最深时刻，栈底到栈顶保存的信息依次对应：

$$
main() \rightarrow S(1) \rightarrow S(0)
$$

对应选项 A。

**易错点**：

- 容易把“弹出顺序”当成“栈底到栈顶顺序”。本题弹出顺序是 $S(0) \rightarrow S(1) \rightarrow main()$，但题目问的是保存信息的自底向上顺序，即压栈顺序。
- 容易忽略 `main` 本身也需要入栈。`main` 是调用者，必须先于所有被调函数入栈，所以栈底一定是 `main`。
- 容易误选 C：$main() \rightarrow S(0) \rightarrow S(1)$，这是错误的，因为调用顺序是先 `S(1)` 后 `S(0)`，先调用的应压在下面，后调用的应压在上面。

**命题规律**：本题属于“栈的应用——函数调用与递归”的经典考点。常见变式包括：给出递归函数，问栈中保存的信息顺序、栈的最大深度、递归输出结果，或结合二叉树、图的遍历考查递归调用过程。复习时不仅要会写递归，还要能画出递归调用树，理解函数调用栈的压栈、弹栈过程，以及栈中保存的返回地址、参数、局部变量等信息。

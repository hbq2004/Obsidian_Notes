# 选择题 第 11 题

![[_Attachments/题目识别/27_王道408-题目/DS-C03-31-M11_题目.png|题目]]

11. 链栈 (不带头结点) 执行 $Pop$ 操作,并将出栈的元素存在 $x$ 中,应该执行 ( )。
A. $x = top;top = top \rightarrow next$
B. $x = top \rightarrow data$
C. $top = top \rightarrow next;x = top \rightarrow data$
D. $x = top \rightarrow data;top = top \rightarrow next$

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C03-31-M11_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 D。链栈（不带头结点）中，$top$ 直接指向栈顶元素结点，$Pop$ 并存入 $x$ 的核心操作是  
$$
x=top\to data;\qquad top=top\to next
$$

**解题切入点**：  
先抓住“不带头结点”这个条件：此时 $top$ 就是链表第一个数据结点，也就是栈顶结点。$Pop$ 操作本质上就是“删除单链表第一个结点，并返回它的值”。所以关键是两点：

1. 必须先取原栈顶数据：$x=top\to data$；  
2. 再移动栈顶指针：$top=top\to next$。

可以类比单链表的“头删”：先把头结点的值抄下来，再把头指针指向下一个结点。若先移动指针，原栈顶结点就丢了。

**推演**：  
设链栈结点结构为：

```c
typedef struct SNode {
    ElemType data;
    struct SNode *next;
} SNode, *LinkStack;
```

不带头结点时，$top$ 直接指向栈顶元素结点。完整的 $Pop$ 逻辑应包括：

```c
if (top == NULL)   // 空栈，下溢
    return;

p = top;           // 暂存原栈顶结点
x = p->data;       // 取出栈顶元素
top = p->next;     // 栈顶指针后移
free(p);           // 释放原栈顶结点
```

题干只考查核心语句，不要求写释放过程。对照选项：

- **A**：$x=top$ 没有取数据，若 $x$ 是元素类型，类型也不匹配；错误。
- **B**：$x=top\to data$ 只取出了栈顶元素，但没有更新 $top$，栈顶没有“弹出”，错误。
- **C**：$top=top\to next;\ x=top\to data$ 先把 $top$ 移到下一个结点，再取数据，取到的是原来第二个结点的数据，而不是被弹出的栈顶元素；错误。
- **D**：先 $x=top\to data$ 保存原栈顶元素，再 $top=top\to next$ 让栈顶指向下一个结点，正确。

因此选 **D**。

**易错点**：  
1. **先移动 $top$ 再取值**：这是最常见的错误。执行 $top=top\to next$ 后，原栈顶结点已经丢失，$x$ 会取到新栈顶的值。  
2. **只取值不更新 $top$**：如选项 B，栈顶没有变化，下一次 $Pop$ 又会得到同一个元素，不符合栈的“删除栈顶”语义。  
3. **把 $x=top$ 当作取元素**：$x$ 应保存栈顶结点的数据域 $top\to data$，而不是保存结点指针。  
4. **混淆带头结点与不带头结点**：本题不带头结点，$top$ 直接指向栈顶元素；若带头结点，则栈顶元素在 $top\to next$，操作对象会不同。

**命题规律**：  
本题属于栈的链式存储结构基本操作题，考查 $Push/Pop$ 中指针修改顺序。408 中常见变式有：

- 将“不带头结点”改为“带头结点”，$Pop$ 操作变为处理 $top\to next$；
- 考查入栈 $Push$ 操作，如 $s\to next=top;\ top=s$；
- 要求写出完整 $Pop$，并考虑是否释放结点；
- 与“栈空判断”结合，不带头结点判空条件是 $top==NULL$。

复习建议：把顺序栈和链栈的 $Push$、$Pop$ 用两个具体结点手推一遍，记住“先取值，后改指针；先保存，再释放”。这类题不需要死背选项，画图模拟即可快速得出答案。

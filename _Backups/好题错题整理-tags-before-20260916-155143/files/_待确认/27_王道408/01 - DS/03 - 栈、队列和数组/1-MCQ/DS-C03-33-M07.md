# 选择题 第 7 题

![[_Attachments/题目识别/27_王道408-题目/DS-C03-33-M07_题目.png|题目]]

7. 设有如下递归函数，在 $func(func(5))$ 的执行过程中，第 $4$ 个被执行的 $func$ 函数是 ( )。
```c
int func(int x){
    if(x<=3) return 2;
    else return func(x-2)+func(x-4);
}
```
(A) $func(2)$
(B) $func(3)$
(C) $func(4)$
(D) $func(5)$

## 答案

## DeepSeek V4 Flash Max 解析

**答案**: 第4个被执行的函数是 $func(4)$，对应选项 (C)。

**解题切入点**: 本题考察递归函数调用顺序的理解。需要模拟递归调用过程，注意函数调用顺序：先计算内层 $func(5)$，再在其递归过程中调用其他函数，最后返回后调用外层 $func$。类似于树的深度优先遍历，先深入内层调用，再返回外层。

**推演**: 
- 调用 $func(func(5))$ 时，首先计算内层 $func(5)$，这是第1个执行的 $func$。
- $func(5)$ 中 $x=5>3$，执行 $\text{return } func(3)+func(1)$。
  - 假设从左到右求值，先调用 $func(3)$（第2个），$func(3)$ 满足 $x\leq3$，直接返回 $2$。
  - 再调用 $func(1)$（第3个），$func(1)$ 满足 $x\leq3$，直接返回 $2$。
  - $func(5)$ 返回 $2+2=4$。
- 然后调用外层 $func(4)$（第4个），$func(4)$ 中 $x=4>3$，执行 $\text{return } func(2)+func(0)$，后续调用 $func(2)$ 和 $func(0)$ 分别为第5、6个。
因此第4个执行的是 $func(4)$。

**易错点**: 1. 误以为第一个执行的是外层 $func$，实际应先计算参数，所以内层 $func(5)$ 是第一个。2. 混淆递归展开顺序，可能将 $func(4)$ 内部的调用误认为更早，但外层 $func(4)$ 在 $func(5)$ 返回后才被调用，其内部调用必然更晚。3. 加法求值顺序（左到右或右到左）可能影响中间调用顺序，但本题中前三个始终是 $func(5)$ 和两个直接返回的调用，第四个始终是 $func(4)$，不受影响。

**命题规律**: 递归函数调用顺序是常考题型，常结合栈、递归深度、函数调用次数等。类似题目可能要求计算调用次数、输出结果或分析递归过程。复习时应熟练模拟递归调用，注意调用顺序与返回值，并理解递归展开的层次关系。

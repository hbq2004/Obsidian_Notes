# 选择题 第 8 题

![[_Attachments/题目识别/27_王道408-题目/DS-C03-32-M08_题目.png|题目]]

8. 假设用数组$Q[MaxSize]$实现循环队列，队首指针$front$指向队首元素的前一位置，队尾指针$rear$指向队尾元素，则判断该队列为空的条件是（ ）.
A. $Q.rear == (Q.front + 1)\% MaxSize$
B. $(Q.rear + 1)\% MaxSize == Q.front + 1$
C. $(Q.rear + 1)\% MaxSize == Q.front$
D. $Q.rear == Q.front$

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C03-32-M08_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 **D**。在此约定下，循环队列为空的条件是队尾指针与队首指针重合，即 $Q.rear = Q.front$。

**解题切入点**：
- 先明确指针语义：$front$ 指向队首元素的**前一个位置**，$rear$ 指向队尾元素。
- 把循环队列想成环形跑道上的两个指针：队空是二者重合；队满是 $rear$ 的下一个位置追上 $front$。
- 该题对应循环队列“牺牲一个存储单元”的约定，因此最多存储 $MaxSize-1$ 个元素。

**推演**：

设 $M=MaxSize$。非空时，队首元素实际存储在

$$
(Q.front+1)\bmod M
$$

处，因为 $front$ 指向队首元素的前一位置。

入队操作：

$$
Q.rear=(Q.rear+1)\bmod M,\qquad Q[Q.rear]=x
$$

出队操作：

$$
Q.front=(Q.front+1)\bmod M,\qquad x=Q[Q.front]
$$

初始为空时，令 $Q.front=Q.rear$。入队、出队过程中，队列长度可表示为

$$
L=(Q.rear-Q.front+M)\bmod M
$$

当 $L=0$ 时队列为空，即

$$
(Q.rear-Q.front+M)\bmod M=0
$$

由于 $Q.front$ 和 $Q.rear$ 都在 $[0,M-1]$ 内，上式等价于

$$
Q.rear=Q.front
$$

所以判空条件为 **D**。

而队满条件为

$$
(Q.rear+1)\bmod M=Q.front
$$

对应选项 **C**，因此 C 是“判满”而不是“判空”。

关键代码思路：

```c
bool isEmpty() {
    return front == rear;              // 队空
}

bool isFull() {
    return (rear + 1) % MaxSize == front;  // 队满
}
```

选项辨析：

- A：$Q.rear=(Q.front+1)\bmod M$，表示队列中只有一个元素，不是队空。
- B：$Q.front+1$ 没有取模，在 $front=MaxSize-1$ 时会越界，不是合法判空条件。
- C：是队满条件。
- D：是队空条件。

**易错点**：
- 混淆“队空”和“队满”。本题中 D 是队空，C 是队满。
- 忘记 $front$ 指向队首元素的前一位置，导致实际队头下标算错。
- 取模运算不完整，例如 B 中 $front+1$ 没有对 $MaxSize$ 取模，边界处会出错。
- 误以为 $Q.rear=(Q.front+1)\bmod M$ 是队空，实际上这是“只有一个元素”的条件。

**命题规律**：
- 考点是循环队列中不同指针定义下的队空、队满判断，属于高频基础题。
- 常见变式：改变 $front$、$rear$ 的指向含义，问队空/队满条件；求队列元素个数；判断能否区分队空和队满。
- 复习建议：不要死背公式，自己用 $MaxSize=5$ 的小数组模拟入队、出队过程，理解“牺牲一个存储单元”的原因，并熟练掌握

$$
(Q.rear-Q.front+MaxSize)\bmod MaxSize
$$

这一长度公式。

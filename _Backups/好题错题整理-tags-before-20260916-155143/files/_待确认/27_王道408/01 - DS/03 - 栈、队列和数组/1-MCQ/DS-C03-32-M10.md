# 选择题 第 10 题

![[_Attachments/题目识别/27_王道408-题目/DS-C03-32-M10_题目.png|题目]]

10. 假设用 $A[0...n]$ 实现循环队列，$front$、$rear$ 分别指向队首元素的前一个位置和队尾元素。若用 $(rear + 1) \% (n + 1) == front$ 作为队满标志，则 ( )。
(A) 可用 $front == rear$ 作为队空标志
(B) 队列中最多可有 $n + 1$ 个元素
(C) 可用 $front > rear$ 作为队空标志
(D) 可用 $(front + 1) \% (n + 1) == rear$ 作为队空标志

## DeepSeek V4 Flash Max 解析

**答案**：选 A。循环队列采用牺牲一个存储单元来区分队空和队满，队空条件为 $front == rear$，最大容量为 $n$（数组长度为 $n+1$，但有一个位置始终空着）。

**解题切入点**：先看数组下标范围 $0\sim n$，可知数组长度为 $n+1$；再看指针语义：$front$ 指向队首元素的前一个位置，$rear$ 指向队尾元素。这种定义下，入队时先移动 $rear$ 再存入，出队时先移动 $front$ 再取出。这种“牺牲一格”的做法就像保留一个“安全哨位”，专门用来区分“空”和“满”两种状态。

**推演**：设数组长度 $N=n+1$。初始时 $front=rear=0$，队列为空。入队操作：
$$
rear=(rear+1)\%N,\quad A[rear]=x
$$
出队操作：
$$
front=(front+1)\%N,\quad x=A[front]
$$
因为 $front$ 指向队首元素的前一个位置，所以当队列为空时，$front$ 与 $rear$ 重合，即 $front==rear$。若队列满时也出现 $front==rear$，则与队空无法区分，因此规定：当 $rear$ 再走一步就追上 $front$ 时判定为满，即
$$
(rear+1)\%N == front
$$
此时数组中有一个位置始终空着，实际存储的元素数为 $N-1=n$ 个，而不是 $n+1$ 个。

选项 C 中 $front>rear$ 只能用于非循环的顺序队列，循环队列中指针大小关系随取模运算不断变化，不能作为判空条件。选项 D 中 $(front+1)\%N == rear$ 表示 $front$ 的后一格就是 $rear$，此时队列中恰有 $1$ 个元素，不是队空。只有 A 正确。

**易错点**：  
1. 误以为数组长度为 $n+1$ 就能存储 $n+1$ 个元素，忽略队满判断必须空出一个位置，因此最大元素数应为 $n$。  
2. 混淆 $front$ 直接指向队首元素和指向队首前一格这两种不同定义，导致入队、出队时指针移动顺序判断错误。  
3. 用 $front>rear$ 判断循环队列空满，这是顺序队列的思维，循环队列必须结合取模运算比较。  
4. 选项 D 容易被误认为队空条件，实际上它对应“队列中有一个元素”的情况。

**命题规律**：考点为循环队列的判空、判满及容量计算。常见变式包括：①给出不同的指针指向方式，求队空/队满条件；②求队列中元素个数公式
$$
(rear - front + N) \% N
$$
③结合入队、出队操作判断指针变化；④若改用计数器法或标志位法，判空判满条件如何变化。复习建议：务必画图理解指针移动过程，牢记“牺牲一格”法的结论：$front==rear$ 为空，$(rear+1)\%N==front$ 为满，最大元素数为 $N-1$。此类题目在 408 中属于基础题，但细节容易出错。

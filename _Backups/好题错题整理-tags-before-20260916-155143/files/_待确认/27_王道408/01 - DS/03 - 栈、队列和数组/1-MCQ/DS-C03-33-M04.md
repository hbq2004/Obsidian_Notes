# 选择题 第 4 题

![[_Attachments/题目识别/27_王道408-题目/DS-C03-33-M04_题目.png|题目]]

4. 利用栈求表达式的值时，设立运算数栈 $OPEN$。假设 $OPEN$ 只有两个存储单元，则在下列表达式中，不会发生溢出的是 ( )。

A. $A - B * (C - D)$
B. $(A - B) * C - D$
C. $(A - B * C) - D$
D. $(A - B) * (C - D)$

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C03-33-M04_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 B，即 $(A-B)*C-D$。用标准算符优先法求值时，运算数栈 $OPEN$ 的最大深度为 2，刚好不会溢出。

**解题切入点**：  
看到“栈求表达式”和“运算数栈 $OPEN$ 只有两个存储单元”，首先要定位到“栈在表达式求值中的应用”。题目真正问的是：在扫描表达式过程中，$OPEN$ 中最多会同时压入几个操作数/中间结果。  
关键不是看操作数总个数，而是看运算何时被“合并”：每读入一个操作数，$OPEN$ 深度 $+1$；每执行一次二元运算，由于弹出两个操作数、压入一个结果，$OPEN$ 深度 $-1$。括号和高优先级运算符会推迟这种合并，导致操作数积压，从而溢出。

**推演**：  
标准算符优先法需要两个栈：运算符栈 $OPTR$ 和运算数栈 $OPEN$。核心流程是：

```text
遇到操作数：
    若 OPEN 深度已为 2，则再压入就会溢出；
    否则压入 OPEN。

遇到 '('：
    压入 OPTR。

遇到 ')'：
    不断弹出 OPTR 栈顶运算符并执行，直到遇到 '('；
    弹出 '('。

遇到运算符 op：
    当 OPTR 非空且栈顶不是 '(' 且 OPTR 栈顶优先级 >= op 的优先级时，
    弹出 OPTR 栈顶运算符并执行；
    最后将 op 压入 OPTR。
```

每次执行二元运算：

```text
b = OPEN.pop()
a = OPEN.pop()
OPEN.push(a op b)
```

所以执行一次二元运算，$OPEN$ 深度净减 1：

$$d \to d-1$$

而每读入一个操作数：

$$d \to d+1$$

题目中 $OPEN$ 容量为 2，因此只要某次要压入操作数时 $OPEN$ 已经有两个元素，就会溢出。

逐项分析：

| 选项 | 关键过程 | 结论 |
|---|---|---|
| A：$A - B * (C - D)$ | 读到 $C$ 时，$OPEN$ 中已有 $A,B$；此时 $*$ 和 $($ 都没有触发运算，再压 $C$ 需要第 3 个存储单元 | 溢出 |
| B：$(A-B)*C-D$ | 读 $A,B$ 后深度为 2；遇到 `)` 执行 $A-B$，深度降为 1；读 $C$ 后深度为 2；遇到后面的 `-` 时先执行栈顶 `*`，深度降为 1；再读 $D$ 后深度为 2 | 不溢出，最大深度为 2 |
| C：$(A-B*C)-D$ | 读到 $C$ 时，$OPEN$ 中已有 $A,B$；$B*C$ 要等 `)` 才计算，再压 $C$ 需要第 3 个存储单元 | 溢出 |
| D：$(A-B)*(C-D)$ | 第一个括号算完后，$OPEN$ 中剩 $T=A-B$；进入第二个括号读到 $C$ 后深度为 2；$C-D$ 的 `-` 要等 `)` 才执行，所以读到 $D$ 时还要压 $D$，深度变 3 | 溢出 |

也可用后缀式验证 B：

$$(A-B)*C-D \Rightarrow AB-C*D-$$

后缀式求值时，$OPEN$ 的深度序列为：

$$1,2,1,2,1,2,1$$

最大深度为 2，因此只有 B 不会溢出。

**易错点**：  
1. 只数变量个数：四个表达式都有 4 个操作数，但栈深不同，关键看运算何时执行。  
2. 忽略优先级和括号的“推迟作用”：如 D 中 $C-D$ 的减号已经入栈，但在遇到 `)` 前不会计算，导致读 $D$ 时栈满。  
3. 混淆运算符栈和运算数栈：题目限制的是 $OPEN$，运算符栈可能更复杂，但不能用运算符栈深度代替运算数栈深度判断。  
4. 忘记同级运算符左结合：如 $A-B-C$ 应先算左边的 `-`；本题主要涉及括号和高低优先级，但手算时仍要按“优先级不低于当前运算符则先弹出”的规则模拟。

**命题规律**：  
本题属于“栈的应用——表达式求值”的经典考法。命题人常把中缀表达式求值、后缀表达式求值、运算符栈/运算数栈容量结合考查。常见变式有：

- 给后缀表达式，问运算数栈至少需要几个单元；
- 给中缀表达式，问运算符栈或运算数栈的最大深度；
- 给出某时刻两个栈中的内容；
- 中缀转后缀过程中栈的变化。

复习建议：熟练掌握算符优先法的模拟过程，能手写两个栈的变化；理解“读入操作数 +1、执行二元运算 $-1$”的本质。遇到选择题，先找“是否有某次读操作数前栈已满”，可以快速判断。

## DeepSeek V4 Flash Max 解析

**答案**：该序列按关键字递增排序，最小交换次数为 \(5\) 次（按简单选择排序，每趟把当前最小元素交换到应占位置；若从“任意交换两个元素使序列有序”的通用交换模型看，也正好是 \(5\) 次）。

**解题切入点**：

看到“交换次数”要先和“比较次数”区分开。排序中有多个指标：

- 比较次数：如简单选择排序固定为 \(\frac{n(n-1)}2\)；
- 交换次数：简单选择排序每趟最多交换 1 次，因此交换次数通常远小于比较次数；
- 移动次数：交换一次相当于移动 3 次。

本题问“最小交换次数”，应优先想到**简单选择排序**。它的思想是：第 \(i\) 趟在剩余元素中选出最小元素，若它不在第 \(i\) 个位置，就把它交换到第 \(i\) 个位置。如果已经在正确位置，则不交换，所以交换次数不是固定的 \(n-1\)。  
可以理解为：每次把“当前剩余牌堆中的最小牌”放到前面；找最小牌需要很多比较，但换位置很少。

**推演**：

设初始序列为

$$
(3,7,6,9,7,1,4,5,20)
$$

按升序排序。简单选择排序的模拟过程如下：

| 趟数 | 当前序列 | 选出的最小元素 | 交换后序列 | 累计交换次数 |
|---|---|---|---|---|
| 第1趟 | \((3,7,6,9,7,1,4,5,20)\) | 1 | \((1,7,6,9,7,3,4,5,20)\) | 1 |
| 第2趟 | \((1,7,6,9,7,3,4,5,20)\) | 3 | \((1,3,6,9,7,7,4,5,20)\) | 2 |
| 第3趟 | \((1,3,6,9,7,7,4,5,20)\) | 4 | \((1,3,4,9,7,7,6,5,20)\) | 3 |
| 第4趟 | \((1,3,4,9,7,7,6,5,20)\) | 5 | \((1,3,4,5,7,7,6,9,20)\) | 4 |
| 第5趟 | \((1,3,4,5,7,7,6,9,20)\) | 6 | \((1,3,4,5,6,7,7,9,20)\) | 5 |
| 第6趟 | \((1,3,4,5,6,7,7,9,20)\) | 7 | 已在正确位置，不交换 | 5 |

此后序列已经有序，不需要再交换。

所以简单选择排序的交换次数为：

$$
5
$$

也可以用“置换环”说明为什么这是最少交换次数：

把最终有序位置与原位置对应起来，若两个 7 按最优方式对应到最终两个 7 的位置，置换可分解为

$$
(1\;2\;6)(3\;5\;7)(4\;8)(9)
$$

共有 4 个环，其中非平凡环长度为 \(3,3,2\)。排好一个长度为 \(L\) 的环至少需要 \(L-1\) 次交换，因此至少需要

$$
(3-1)+(3-1)+(2-1)=5
$$

次交换。上面选择排序正好用了 5 次，所以答案就是：

$$
\boxed{5}
$$

若写代码统计交换次数，核心思路是：

```c
int selectSortCount(int a[], int n) {
    int cnt = 0;
    for (int i = 0; i < n - 1; i++) {
        int min = i;
        for (int j = i + 1; j < n; j++)
            if (a[j] < a[min]) min = j;
        if (min != i) {
            swap(a[i], a[min]);
            cnt++;
        }
    }
    return cnt;
}
```

**易错点**：

1. **把“交换次数”当成“比较次数”**  
   简单选择排序的比较次数是固定的 \(36\) 次，但交换次数只有 \(5\) 次，二者不能混淆。

2. **在元素已经就位时仍算一次交换**  
   第 6 趟之后最小元素已经在正确位置，不应再交换。若每趟都“强行交换”，会错误地算成 6 次甚至 8 次。

3. **把冒泡排序的交换次数套到本题**  
   冒泡排序的相邻交换次数等于逆序数。本题若按冒泡排序算，逆序数不是 5，而是 15；题目问的是“最小交换次数”的选择排序模型，不是冒泡排序。

4. **对重复关键字 7 处理不当**  
   两个 7 是相同关键字，排序后不需要区分谁在谁前面。模拟时只要保证最终为

   $$
   (1,3,4,5,6,7,7,9,20)
   $$

   即可，不必纠结两个 7 的原始位置。

**命题规律**：

本题属于排序章节的基础综合题，考点是**简单选择排序过程与交换次数统计**。常见变式有：

- 给出序列，问第几趟简单选择排序后的结果；
- 统计排序过程中的比较次数、交换次数、移动次数；
- 判断排序算法是否稳定；
- 结合快速排序、堆排序、冒泡排序等，比较不同算法的交换次数。

复习建议：熟练掌握各排序算法的手工模拟，尤其是“每一趟后序列长什么样”“交换发生在哪两个位置”“重复关键字如何处理”。408 中排序题常以小题或综合题形式出现，重点考查对排序过程的理解，而不是只背复杂度结论。

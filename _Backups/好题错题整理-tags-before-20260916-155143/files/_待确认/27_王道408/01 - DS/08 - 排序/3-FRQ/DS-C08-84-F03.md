3. 若只想得到一个序列中第 $k(k \geq 5)$ 个最小元素之前的部分的排序序列，则最好采用什么排序算法？

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C08-84-F03_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：最好采用**堆排序**。其核心是：将序列建成最小堆后，连续取 $k$ 次堆顶，即可在 $O(n+k\log n)$ 时间内得到前 $k$ 个最小元素的升序序列；当 $k$ 远小于 $n$ 时，时间复杂度接近 $O(n)$。

**解题切入点**：拿到题目先抓住“第 $k$ 个最小元素之前的部分的排序序列”——这是“部分排序”需求，不需要整个序列有序，只需前 $k$ 个最小元素按序输出。这立刻让人想到选择排序类算法，因为每趟选择都能确定一个最小元素。但简单选择排序每趟找最小值需线性扫描，复杂度为 $O(nk)$；而堆排序通过最小堆把每次找最小值的代价降到 $O(\log n)$，因此最优。这类似于“在一堆牌中只挑最小的几张并按序排好”，与其反复从头到尾寻找，不如先把牌整理成小根堆，每次从堆顶取一张，再调整一次，效率更高。

**推演**：设序列长度为 $n$，目标为输出前 $k$ 个最小元素且按从小到大排序。

1. 直接对整个序列排序，如快速排序、归并排序，时间复杂度为 $O(n\log n)$，即使只需前 $k$ 个元素，也要完成全排序，做了大量无用功。

2. 考虑“每趟确定一个最小值”的选择类算法：

   - **简单选择排序**：做 $k$ 趟，第 $i$ 趟从第 $i$ 到第 $n$ 个元素中选出最小者放到第 $i$ 个位置。比较次数为  
     $$
     (n-1)+(n-2)+\cdots+(n-k)=kn-\frac{k(k+1)}{2}=O(nk)。
     $$
     当 $k$ 很小但 $n$ 很大时，$O(nk)$ 较大。

   - **堆排序（最小堆）**：先建最小堆，建堆时间为 $O(n)$。堆顶即为当前最小元素，输出堆顶后，将堆尾元素移到堆顶，再向下调整，每次调整耗时不超过树高 $O(\log n)$。连续取 $k$ 次堆顶，总时间为  
     $$
     T(n,k)=O(n)+k\cdot O(\log n)=O(n+k\log n)。
     $$
     取出的 $k$ 个堆顶依次就是第 $1$ 小、第 $2$ 小、……、第 $k$ 小的元素，天然是有序序列。  
     关键代码思路如下：
     ```
     buildMinHeap(a);              // 对原数组建最小堆，O(n)
     for i = 1 to k:
         output a[0];              // 当前最小值
         a[0] = a[n - i];          // 堆尾元素移至堆顶
         siftDown(a, 0, n - i - 1);// 调整堆
     ```

3. 为什么不是快速排序？快速排序的划分思想可以快速定位第 $k$ 小元素（即快速选择），期望时间为 $O(n)$，但划分结束后左半部分并不有序；要得到“前 $k$ 个元素的有序序列”，还需对左半部分再进行一次排序，额外代价至少为 $O(k\log k)$。而且快速选择最坏情况会退化到 $O(n^2)$，而堆排序最坏情况仍为 $O(n+k\log n)$，稳定性更好，因此堆排序更“稳妥最优”。

综上，为了得到前 $k$ 个最小元素的有序序列，堆排序是最合适的选择。

**易错点**：
- 误答“快速排序”：快速排序只能高效定位第 $k$ 小，不能直接产生有序的前 $k$ 个元素；且最坏情况可能退化。
- 误答“简单选择排序”：虽然做 $k$ 趟也能得到前 $k$ 个有序最小元素，但复杂度为 $O(nk)$，不如堆排序的 $O(n+k\log n)$。
- 混淆“只找第 $k$ 小”与“前 $k$ 个有序序列”：前者只求一个元素，后者要求前 $k$ 个元素有序，必须多做排序步骤。
- 堆的类型用错：若直接取最小元素，应建**小根堆**；若用“大小为 $k$ 的大根堆维护前 $k$ 小”，得到的是无序集合，还需要额外排序。
- 以为堆排序必须全部排完才能取前 $k$ 个：实际上取够 $k$ 次堆顶即可停止，无需完整堆排序。

**命题规律**：本题是排序章节的经典应用题，核心考查“部分排序”场景下的算法选择。常见变式有：  
- 只求第 $k$ 小的元素：可用快速选择（期望 $O(n)$）或堆排序（$O(n+k\log n)$）；  
- 求前 $k$ 个最大元素：可维护大小为 $k$ 的小根堆，遍历序列，时间复杂度 $O(n\log k)$；  
- 如果要求前 $k$ 个元素本身有序，则需在维护堆后再对这 $k$ 个元素排序，或直接用最小堆取 $k$ 次。  

复习时应熟练掌握堆的建堆、调整过程及其复杂度，并注意区分“选择排序”和“堆排序”在部分排序问题中的差异，做到能根据实际需求选择最优算法。

## DeepSeek V4 Flash Max 解析

**答案**：令 $m=\lfloor n/2\rfloor$。用“快速选择”找到第 $m$ 小元素（下标 $m-1$），把数组划分成前 $m$ 个最小元素和后 $n-m$ 个最大元素，则 $|n_1-n_2|$ 最小，且在此基础上 $|S_1-S_2|$ 最大。平均时间复杂度 $O(n)$，辅助空间 $O(1)$。

**解题切入点**：先抓住两个条件的优先级：个数差最小是首要约束，它只由 $n$ 的奇偶性决定；在这个约束下，和差最大等价于“把最小的 $\lfloor n/2\rfloor$ 个元素放一边，其余放另一边”。因此不需要全排序，只需要找一个“第 $m$ 小元素”并把数组划分成两半。这就像查成绩时不需要把全班成绩完整排序，只要找到第 $m$ 名，前面的就是最小的 $m$ 个人。

**推演**：

1. 个数差最小  
   因为 $n_1+n_2=n$，所以  
   - $n$ 为偶数时，$|n_1-n_2|$ 最小为 $0$，两组各 $n/2$；
   - $n$ 为奇数时，$|n_1-n_2|$ 最小为 $1$，两组分别为 $\lfloor n/2\rfloor$ 和 $\lceil n/2\rceil$。

   统一记
   $$
   m=\left\lfloor \frac n2\right\rfloor
   $$
   最终应把数组分成 $m$ 个元素和 $n-m$ 个元素两组。

2. 和差最大  
   设数组从小到大排序后为
   $$
   b_0\le b_1\le \cdots \le b_{n-1}.
   $$
   要使 $|S_1-S_2|$ 最大，应该让前 $m$ 个最小元素作为 $A_1$，后 $n-m$ 个最大元素作为 $A_2$，即
   $$
   S_1=\sum_{i=0}^{m-1}b_i,\qquad S_2=\sum_{i=m}^{n-1}b_i.
   $$
   最大差值为
   $$
   |S_1-S_2|_{\max}=\sum_{i=m}^{n-1}b_i-\sum_{i=0}^{m-1}b_i.
   $$

   交换论证：如果 $A_1$ 中存在元素 $x$，$A_2$ 中存在元素 $y$，且 $x>y$，那么交换 $x,y$ 后，$S_1$ 减少、$S_2$ 增加，因此 $S_2-S_1$ 增大，与最优矛盾。所以 $A_1$ 必须取最小的 $m$ 个元素。

3. 快速选择算法  
   不需要真正排序。利用快速排序的 `Partition` 思想：选择一个枢轴，划分后枢轴到达其最终位置。如果枢轴下标正好是 $m-1$，则停止；如果小于 $m-1$，只处理右侧；如果大于 $m-1$，只处理左侧。这本质是“快速选择”。

   核心 C/C++ 代码如下：

```cpp
// 一次快速排序划分：把 A[low..high] 按 pivot 分成两部分
int Partition(int A[], int low, int high) {
    int pivot = A[low];          // 取第一个元素为枢轴
    while (low < high) {
        while (low < high && A[high] >= pivot) --high;
        A[low] = A[high];
        while (low < high && A[low] <= pivot) ++low;
        A[high] = A[low];
    }
    A[low] = pivot;
    return low;                  // 返回枢轴最终位置
}

// 快速选择：使得 A[k] 是第 k+1 小元素
void QuickSelect(int A[], int n, int k) {
    int low = 0, high = n - 1;
    while (low < high) {
        int pos = Partition(A, low, high);
        if (pos == k) return;
        else if (pos < k) low = pos + 1;
        else high = pos - 1;
    }
}

// 主算法：返回最大和差
long long MaxSumDiff(int A[], int n) {
    int m = n / 2;               // A1 中元素个数为 floor(n/2)
    QuickSelect(A, n, m - 1);    // 使前 m 个元素是最小的 m 个

    long long S1 = 0, S2 = 0;
    for (int i = 0; i < m; ++i) S1 += A[i];
    for (int i = m; i < n; ++i) S2 += A[i];

    return S2 - S1;              // S2 是较大的一边
}
```

算法结束后，`A[0..m-1]` 就是 $A_1$，`A[m..n-1]` 就是 $A_2$。注意这两部分内部不一定有序，但左边所有元素都不大于右边所有元素。

4. 复杂度  
   `Partition` 每次扫描当前区间，平均情况下枢轴接近中间，快速选择只处理一侧，因此
   $$
   T(n)=T\left(\frac n2\right)+O(n)=O(n).
   $$
   最坏情况为 $O(n^2)$，通常题目问平均复杂度，故答案为 $O(n)$。  
   上述代码采用原地划分和迭代写法，不使用额外数组，辅助空间为 $O(1)$。

**易错点**：

- 不要把目标理解成“在所有划分中同时让个数差最小且和差全局最大”。正确顺序是：先使个数差最小，再在这个前提下使和差最大。
- 下标容易错：要找的是下标 $m-1$，不是下标 $m$。例如 $n=5$ 时，$m=2$，应使下标 $1$ 成为第 $2$ 小元素，而不是下标 $2$。
- 不要用完整快速排序或堆排序。快速排序要处理两侧，时间复杂度 $O(n\log n)$；快速选择只处理一侧，平均 $O(n)$。
- 划分后不要认为数组已经完全有序，只需保证前 $m$ 个元素都不大于后 $n-m$ 个元素即可。
- 如果写成递归快速选择，递归栈平均是 $O(\log n)$；本题使用迭代实现，空间才是 $O(1)$。

**命题规律**：本题核心是“快速排序划分思想 + 第 $k$ 小元素选择”，是 408 高频考点。常见变式包括：找中位数、找最小的 $k$ 个数、把数组按第 $k$ 小元素划分、按某种条件使两边和差最大或最小。复习时应能熟练默写 `Partition` 和 `QuickSelect`，注意边界条件、枢轴选择和“只处理一侧”这个关键优化点。

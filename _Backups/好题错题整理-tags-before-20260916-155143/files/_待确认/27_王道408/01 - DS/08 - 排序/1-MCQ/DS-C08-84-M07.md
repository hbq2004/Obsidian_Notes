# 选择题 第 7 题

![[_Attachments/题目识别/27_王道408-题目/DS-C08-84-M07_题目.png|题目]]

7. 构建$n$个记录的初始堆, 其时间复杂度为( ); 对$n$个记录进行堆排序, 最坏情况下其时间复杂度为( ).

A. $O(n)$
B. $O(n^2)$
C. $O(\log_2 n)$
D. $O(n \log_2 n)$

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C08-84-M07_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：第一空选 A（$O(n)$），第二空选 D（$O(n\log_2 n)$）。

**解题切入点**：拿到题先区分两个阶段：一是“建初始堆”，二是“堆排序”。建堆不是把 $n$ 个元素依次插入空堆，而是把无序数组看成完全二叉树，从最后一个非叶结点开始向下调整，即 Floyd 建堆法，所以是 $O(n)$。堆排序在建堆之后还要执行 $n-1$ 次“交换堆顶与末尾元素 + 向下调整”，每次调整代价与树高有关，为 $O(\log_2 n)$，因此总复杂度为 $O(n\log_2 n)$。

**推演**：

### 1. 建初始堆的时间复杂度

用数组 $A[0..n-1]$ 存储堆，下标从 0 开始。建大根堆的核心代码如下：

```c
void siftDown(int A[], int k, int n) {
    while (2 * k + 1 < n) {          // k 有左孩子
        int j = 2 * k + 1;           // 左孩子下标
        if (j + 1 < n && A[j + 1] > A[j])
            j++;                     // j 指向较大的孩子
        if (A[k] >= A[j]) break;     // 已经满足堆序
        swap(A[k], A[j]);
        k = j;                       // 继续向下调整
    }
}

void buildHeap(int A[], int n) {
    for (int i = n / 2 - 1; i >= 0; i--)
        siftDown(A, i, n);
}
```

其中 `n / 2 - 1` 是最后一个非叶结点的下标。叶子本身已经是单结点堆，不需要调整。

设高度为 $h$ 的结点做一次 `siftDown`，最多向下移动 $h$ 层，代价为 $O(h)$。在完全二叉树中，高度为 $h$ 的结点数 $N_h$ 满足：

$$
N_h \le \frac{n}{2^h}
$$

因为每个高度为 $h$ 的结点至少有 $2^h$ 个后代结点。因此建堆总代价为：

$$
T_{\text{build}}
= \sum_{h=1}^{\lfloor \log_2 n \rfloor} N_h \cdot O(h)
= O\left(\sum_{h=1}^{\infty} \frac{n h}{2^h}\right)
= O(n)
$$

所以第一空选 A，$O(n)$。

### 2. 堆排序最坏时间复杂度

建好初始堆后，堆排序反复执行：

```c
for (int i = n - 1; i > 0; i--) {
    swap(A[0], A[i]);       // 把当前最大元素放到末尾
    siftDown(A, 0, i);      // 对前 i 个元素重新调整成堆
}
```

第 $i$ 轮时堆的大小为 $i$，根结点下沉最多经过 $\lfloor \log_2 i \rfloor$ 层，因此一趟调整最多为 $O(\log_2 i)$。排序阶段总代价为：

$$
T_{\text{sort}}
= \sum_{i=1}^{n-1} O(\log_2 i)
= O(n\log_2 n)
$$

再加上建堆的 $O(n)$，总时间复杂度为：

$$
T(n)
= T_{\text{build}} + T_{\text{sort}}
= O(n) + O(n\log_2 n)
= O(n\log_2 n)
$$

堆排序最坏情况下仍然是 $O(n\log_2 n)$，所以第二空选 D。

**易错点**：

1. **把“建堆”当成“依次插入”**：如果逐个把元素插入空堆，每次插入需要向上调整 $O(\log_2 n)$，总代价是 $O(n\log_2 n)$；但题目中的“构建初始堆”通常指 Floyd 筛选法建堆，时间复杂度为 $O(n)$。  
2. **误选 $O(n^2)$**：堆排序不是简单选择排序，它利用完全二叉树的结构，每趟找最大值只需要 $O(\log_2 n)$，不需要扫描整个数组。  
3. **忽略建堆阶段**：堆排序总时间不是只有“ $n-1$ 次调整”，还要加上建堆，但 $O(n)$ 被 $O(n\log_2 n)$ 主导，所以最终仍是 $O(n\log_2 n)$。  
4. **下标混淆**：从 0 开始存储时，最后一个非叶结点是 $\lfloor n/2 \rfloor - 1$；从 1 开始存储时才是 $\lfloor n/2 \rfloor$，做题时要看清下标起点。

**命题规律**：

本题属于排序章节的常考点，重在考查堆排序两个阶段的复杂度辨析。常见变式有：

- 给一个无序数组，要求写出建堆后的序列；
- 模拟堆排序每一趟的结果；
- 比较堆排序、快速排序、归并排序的最好、最坏、平均时间复杂度；
- 考查堆排序的稳定性与空间复杂度。

复习时应熟记：堆排序时间 $O(n\log_2 n)$，最坏情况也为 $O(n\log_2 n)$，空间 $O(1)$，不稳定；建初始堆 $O(n)$；插入和删除堆顶均为 $O(\log_2 n)$。

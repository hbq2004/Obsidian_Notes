6. 向具有$n$个结点的堆中插入一个新元素的时间复杂度为(  )，删除一个元素的时间复杂度为(  )

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C08-84-M06_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：向堆中插入一个新元素和“删除一个元素”（教材默认指删除堆顶元素）的时间复杂度均为 $O(\log_2 n)$，因此两空均选 **C**。

**解题切入点**：  
看到堆，先抓住两点：堆是完全二叉树；堆用数组层序存储。插入/删除后的调整只会沿“叶子到根”或“根到叶子”的一条路径进行，而 $n$ 个结点的完全二叉树高度是 $O(\log_2 n)$。所以复杂度不由“数组中大量元素移动”决定，而由堆高决定，类似“上浮/下沉”的过程。

**推演**：  
设堆为小根堆，数组下标从 1 开始，结点 $i$ 的父结点为 $\lfloor i/2 \rfloor$，左、右孩子为 $2i$、$2i+1$。

含 $n$ 个结点的完全二叉树的高度为  
$$
h=\lfloor \log_2 n \rfloor
$$
即任意根叶路径长度不超过 $O(\log_2 n)$。

### 1. 插入一个新元素

插入时要先保持完全二叉树结构，因此把新元素放到数组末尾 $a[n+1]$，然后向上调整：

- 若新元素比父结点小，则与父结点交换；
- 继续向上比较，直到满足堆序或到达根结点。

最坏情况下，新元素从叶子一路上升到根，经过 $O(\log_2 n)$ 层，每次只做常数次比较和交换，所以插入时间复杂度为：
$$
O(\log_2 n)
$$

### 2. 删除一个元素

删除操作默认删除堆顶元素：

- 用堆中最后一个元素覆盖堆顶；
- 然后从根向下调整；
- 小根堆中与较小的孩子比较，若破坏堆序则交换，继续向下调整，直到满足堆序或到达叶子。

最坏情况下，从根下滤到叶子，同样经过 $O(\log_2 n)$ 层，因此删除时间复杂度为：
$$
O(\log_2 n)
$$

关键代码思路如下（小根堆）：

```cpp
// 插入：向上调整
void insert(int a[], int &n, int x) {
    a[++n] = x;
    for (int i = n; i > 1 && a[i] < a[i / 2]; i /= 2)
        swap(a[i], a[i / 2]);
}

// 删除堆顶：向下调整
int deleteTop(int a[], int &n) {
    int top = a[1];
    a[1] = a[n--];          // 用最后一个元素补到堆顶
    int i = 1;
    while (2 * i <= n) {
        int j = 2 * i;      // 左孩子
        if (j + 1 <= n && a[j + 1] < a[j])
            j++;            // 选较小的孩子
        if (a[j] < a[i]) {
            swap(a[i], a[j]);
            i = j;
        } else {
            break;
        }
    }
    return top;
}
```

**易错点**：  

- 不要把堆的插入/删除理解为“数组中大量元素整体移动”，否则会误选 $O(n)$。堆通过沿根叶路径交换调整，不需要移动 $O(n)$ 个元素。
- 不要把“一次删除”和“堆排序 $n$ 次删除”混淆。$O(n\log_2 n)$ 是堆排序整体的复杂度，不是一次删除的复杂度。
- 不要和“建堆”混淆：建堆可以做到 $O(n)$，而单次插入/删除是 $O(\log_2 n)$。
- 若题目额外要求“删除任意值且不知其位置”，则还需先线性查找，查找为 $O(n)$；但 408 教材中堆的删除默认指删除堆顶元素。

**命题规律**：  
这是数据结构堆部分的基础考点，常与堆排序、优先队列、Top-K 问题、Dijkstra 算法优化结合考查。常见变式有：连续插入 $m$ 个元素的总复杂度为 $O(m\log(n+m))$；连续删除 $m$ 次的总复杂度为 $O(m\log n)$；建堆复杂度为 $O(n)$；堆排序总复杂度为 $O(n\log_2 n)$。复习时应做到能手写插入、删除堆顶的“上滤/下滤”过程，并牢记“堆高决定操作复杂度”。

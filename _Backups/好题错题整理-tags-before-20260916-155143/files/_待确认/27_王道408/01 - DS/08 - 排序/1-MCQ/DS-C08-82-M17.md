17.【2012统考真题】对同一待排序序列分别进行折半插入排序和直接插入排序，两者之间可能的不同之处是( ).
A. 排序的总趟数
B. 元素的移动次数
C. 使用辅助空间的数量
D. 元素之间的比较次数

## DeepSeek V4 Flash Max 解析

**答案**：D（元素之间的比较次数）。折半插入排序只是将查找插入位置的方式由直接插入排序的顺序查找改为折半查找，所以排序总趟数、元素移动次数和辅助空间均相同，元素之间的比较次数可能不同。

**解题切入点**：  
拿到题目先抓住“插入排序家族”的公共流程：每一趟把一个元素插入前面的有序区，插入过程包含“查找位置”和“移动元素”两个动作。折半插入排序只优化“查找位置”，不优化“移动元素”。类似地在算法竞赛中，用 `lower_bound` 在 `vector` 中找到插入位置后，`insert` 仍需线性搬移元素；二分只影响查找比较的代价。

**推演**：  
设待排序序列为 $A[1..n]$，第 $i$ 趟将 $A[i]$ 插入有序区 $A[1..i-1]$。

直接插入排序的核心过程为  
```c
tmp = A[i]; j = i - 1;
while (j >= 1 && tmp < A[j]) {
    A[j + 1] = A[j];
    j--;
}
A[j + 1] = tmp;
```

折半插入排序的核心过程为  
```c
tmp = A[i]; low = 1; high = i - 1;
while (low <= high) {
    mid = (low + high) / 2;
    if (tmp < A[mid]) high = mid - 1;
    else low = mid + 1;
}
for (j = i - 1; j >= low; j--)
    A[j + 1] = A[j];
A[low] = tmp;
```

逐项比较：

- **总趟数**：两种算法都从第二个元素开始，依次处理到最后一个元素，共 $n-1$ 趟，因此相同。
- **元素移动次数**：取稳定的插入策略时，两种算法对同一序列得到的插入位置相同。设第 $i$ 趟的插入位置为 $p_i$，则移动次数均为
  $$
  \sum_{i=2}^{n}(i-p_i).
  $$
  两者都需要把 $A[p_i],\dots,A[i-1]$ 后移一位，所以移动次数相同；最坏为 $\frac{n(n-1)}{2}$，最好为 $0$。
- **辅助空间**：两者都只需要常数个临时变量，空间复杂度均为 $O(1)$。
- **比较次数**：直接插入排序用顺序查找，比较次数为线性级，最坏为  
  $$
  \sum_{i=2}^{n}(i-1)=\frac{n(n-1)}{2}=O(n^2).
  $$
  折半插入排序每趟在长度为 $i-1$ 的有序区上折半查找，最坏比较次数为  
  $$
  \lfloor\log_2(i-1)\rfloor+1,
  $$
  总比较次数为  
  $$
  \sum_{i=2}^{n}\bigl(\lfloor\log_2(i-1)\rfloor+1\bigr)=O(n\log n).
  $$
  查找机制不同，因此比较次数可能不同。例如逆序序列时折半插入的比较次数明显更少；但已升序序列中，直接插入每趟只需 1 次比较，折半插入反而需要约 $\lceil\log_2 i\rceil$ 次比较。

因此只有 D 是两者之间可能的不同之处。

**易错点**：  
1. 误以为“折半插入排序减少了移动次数”。实际上移动次数完全不变，折半只减少查找插入位置时的比较次数。  
2. 误以为折半插入排序的比较次数一定更少。它在最好情况（如已升序）下不一定比直接插入少；只能说平均/最坏情况下通常更优。  
3. 忽略稳定性。如果折半查找对相等关键字的处理不当，可能把新元素插到相等元素之前，改变插入位置，从而破坏稳定性并改变移动次数；标准实现应把相等时继续向右搜索。  
4. 误以为折半插入排序总时间复杂度变成 $O(n\log n)$。由于移动次数仍为 $O(n^2)$，总时间复杂度仍是 $O(n^2)$。

**命题规律**：  
本题核心考点是“插入排序变体的性质比较”，尤其是查找优化与移动开销的区分。408 中常以“同一序列”“可能的不同之处”等方式考查排序算法性质。常见变式有：问“折半插入排序比直接插入排序节省的是什么”（答案：比较次数）；问“两者移动次数是否相同”；或将希尔排序与直接插入排序对比考查稳定性、复杂度；或要求计算给定序列两种排序的比较/移动次数。复习时应把各排序算法的比较次数、移动次数、稳定性、辅助空间和总时间复杂度放在一起对比，并动手写一遍直接插入与折半插入的代码，体会“查找方式不同、搬移方式相同”。

# 选择题 第 14 题

![[_Attachments/题目识别/27_王道408-题目/DS-C08-85-M14_题目.png|题目]]

14. 下列各种排序算法中，（ ）需要的附加存储空间最大.
(A) 快速排序
(B) 堆排序
(C) 归并排序
(D) 插入排序

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C08-85-M14_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 (C) 归并排序。四种算法中，归并排序需要 $O(n)$ 的辅助数组来完成合并，附加存储空间最大。

**解题切入点**：  
先明确“附加存储空间”指的是**除待排序数组本身外额外开辟的内存空间**，不是时间复杂度。拿到排序题先想“排序性质四件套”：时间、空间、稳定性、是否原地排序。本题只考空间，直接对照各排序算法的空间复杂度即可。

可以这样类比：归并排序像把两副牌合并，需要额外一张“空桌子”临时铺开所有牌；插入排序和堆排序基本是原地挪动，几乎不需要额外桌子；快速排序只需要“便签”记录待排序区间，但不需要把整副牌复制一份。

**推演**：  
设待排序元素个数为 $n$，逐项分析：

1. **插入排序**：  
   直接插入排序只需一个临时变量保存当前待插入元素，或者用“哨兵”，因此附加空间为  
   $$O(1)$$

2. **堆排序**：  
   建堆和堆调整都在原数组上进行，交换元素时只用常数个临时变量，因此附加空间为  
   $$O(1)$$

3. **快速排序**：  
   快速排序在划分时是原地进行的，主要额外空间来自递归调用栈，需要保存待排序区间的边界。平均情况下递归深度为 $O(\log n)$，最坏情况下会退化为 $O(n)$。按教材常规空间复杂度表，取平均情况：  
   $$O(\log n)$$

4. **归并排序**：  
   二路归并排序在合并两个有序序列时，需要把待合并区间复制到一个辅助数组中，辅助数组长度最大为 $n$。加上递归栈 $O(\log n)$，总附加空间为  
   $$O(n)+O(\log n)=O(n)$$

合并过程关键思路如下：

```text
B[0..len-1] = A[low..high]           // 复制到辅助数组，长度 len = high-low+1
i = 0; j = mid-low+1                 // i 指向左段，j 指向右段
for k = low to high:
    if j >= len || (i < mid-low+1 && B[i] <= B[j]):
        A[k] = B[i++]
    else:
        A[k] = B[j++]
```

这段代码中辅助数组 `B` 的长度最大为 $n$，所以归并排序空间复杂度为 $O(n)$。

综合比较：

| 选项 | 算法 | 附加存储空间 |
|---|---|---|
| A | 快速排序 | 平均 $O(\log n)$ |
| B | 堆排序 | $O(1)$ |
| C | 归并排序 | $O(n)$ |
| D | 插入排序 | $O(1)$ |

因此最大的是归并排序，选 **C**。

**易错点**：  
- 容易把快速排序的递归栈忽略，认为它也不需要额外空间。实际上快速排序不是严格的“原地排序”，平均需要 $O(\log n)$ 的递归栈空间，但比归并排序的 $O(n)$ 小。  
- 如果额外强调“最坏情况”，快速排序递归深度可能达到 $O(n)$，这时它与归并排序同为 $O(n)$；但本题按教材常规空间复杂度表考查，答案仍是归并排序。  
- 容易误以为归并排序每层递归都要开一个长度为 $n$ 的数组，从而错算成 $O(n\log n)$。实际上同一时刻最多只需要一个长度为 $O(n)$ 的合并缓冲区，因此总空间是 $O(n)$。  
- “附加存储空间”不包括待排序数组本身，只算额外申请的空间。

**命题规律**：  
这是 408 中排序章节的高频基础题，考查排序算法的**空间复杂度**。常考变式包括：  
- “归并排序的空间复杂度是 $O(n)$”；  
- “快速排序平均/最坏空间复杂度”；  
- “哪些排序算法是原地排序”；  
- “归并排序是否稳定”等。  

复习时应把常见排序算法的时间复杂度（最好、平均、最坏）、空间复杂度、稳定性汇总成表记忆，并动手写一遍快速排序和二路归并排序，理解快排递归栈和归并辅助数组的来源。

# 选择题 第 10 题

10. 有一组数据 $(15,9,7,8,20,-1,7,4)$，用堆排序的筛选方法建立的初始小根堆为 ( )。

(A) $-1,4,8,9,20,7,15,7$
(B) $-1,7,15,7,4,8,20,9$
(C) $-1,4,7,8,20,15,7,9$
(D) $A$、$B$、$C$均不对

## DeepSeek V4 Flash Max 解析

**答案**：建立的初始小根堆为序列 $-1,4,7,8,20,15,7,9$，对应选项 (C)。

**解题切入点**：堆排序的筛选方法建堆，即将序列视为完全二叉树，从最后一个非叶子节点（下标 $\lfloor n/2 \rfloor$）开始，依次向前对每个节点进行向下调整（Sift Down），使以该节点为根的子树成为小根堆。这样可保证最终整个树满足堆性质。本题的关键是严格按照“筛选法”的步骤，先调整下标 $4$ 的节点，再调整 $3,2,1$，每次交换后必须继续向下调整直到子树也满足堆性质。

**推演**：  
初始序列 $(15,9,7,8,20,-1,7,4)$，$n=8$，最后一个非叶子节点下标 $4$。完全二叉树结构如下（下标从 $1$ 开始）：
```
        1:15
      /      \
    2:9      3:7
   /   \    /   \
 4:8  5:20 6:-1 7:7
/
8:4
```
从下标 $4$ 开始向前调整：

1. **调整节点 $4$（值 $8$）**：左孩子是 $8$（值 $4$），$8>4$，交换，得 $4$（节点 $4$）和 $8$（节点 $8$）。序列变为 $(15,9,7,4,20,-1,7,8)$。
2. **调整节点 $3$（值 $7$）**：左孩子 $6$（值 $-1$），右孩子 $7$（值 $7$），较小孩子为 $-1$，$7>-1$，交换，得 $-1$（节点 $3$）和 $7$（节点 $6$）。序列变为 $(15,9,-1,4,20,7,7,8)$。
3. **调整节点 $2$（值 $9$）**：左孩子 $4$（值 $4$），右孩子 $5$（值 $20$），较小孩子为 $4$，$9>4$，交换，得 $4$（节点 $2$）和 $9$（节点 $4$）。序列变为 $(15,4,-1,9,20,7,7,8)$。  
   检查节点 $4$（新值 $9$）：左孩子 $8$（值 $8$），$9>8$，交换，得 $8$（节点 $4$）和 $9$（节点 $8$）。序列变为 $(15,4,-1,8,20,7,7,9)$。
4. **调整节点 $1$（值 $15$）**：左孩子 $2$（值 $4$），右孩子 $3$（值 $-1$），较小孩子为 $-1$，$15>-1$，交换，得 $-1$（节点 $1$）和 $15$（节点 $3$）。序列变为 $(-1,4,15,8,20,7,7,9)$。  
   检查节点 $3$（新值 $15$）：左孩子 $6$（值 $7$），右孩子 $7$（值 $7$），较小孩子 $7$，$15>7$，交换，得 $7$（节点 $3$）和 $15$（节点 $6$）。序列变为 $(-1,4,7,8,20,15,7,9)$。  
   节点 $6$（值 $15$）为叶子，调整结束。

最终得到序列 $(-1,4,7,8,20,15,7,9)$，与选项 C 一致。

**易错点**：  
- **建堆顺序错误**：必须从 $\lfloor n/2 \rfloor$ 开始向前调整，而不是从第一个节点开始；若从根节点开始向下调整，无法保证整体堆性质（仅适用于插入建堆）。  
- **向下调整不彻底**：交换后未检查被交换的孩子子树是否被破坏，导致堆性质不满足（如调整节点 $2$ 时，交换后节点 $4$ 仍需继续向下调整）。  
- **小根堆与大根堆混淆**：小根堆要求父节点小于等于孩子，比较时取较小孩子交换，方向不可弄反。  
- **索引混淆**：数组下标从 $0$ 或 $1$ 开始易导致孩子节点计算错误，建议统一按完全二叉树性质（左孩子 $2i$，右孩子 $2i+1$）处理。

**命题规律**：  
- **考点定位**：堆排序的建堆过程（筛选法）是数据结构“排序”章节常考知识点，常以选择题或填空题形式考查初始堆序列、建堆比较次数、交换次数等。  
- **常见变式**：①给定序列建大根堆；②给出建堆后的序列，要求判断建堆过程是否正确；③结合堆排序完整过程，考查每次筛选后的结果。  
- **复习建议**：熟练掌握完全二叉树下标性质，亲手模拟建堆过程至少 2-3 遍，注意每次向下调整的完整步骤（交换后继续向下直到叶子），理解“筛选法”的核心思想——从最后一个非叶子节点开始，自底向上保证每个子树为堆。

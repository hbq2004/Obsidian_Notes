12. 堆排序分为两个阶段：第一阶段将给定的序列构造成一个初始堆，第二阶段逐次输出堆顶元素，并调整使其保持堆的性质。设有给定序列 $\{48,62,35,77,55,14,35,98\}$，若在堆排序的第一阶段将该序列构造成一个大根堆，则交换元素的次数为 (    ) 。
(A) 5

## DeepSeek V4 Flash Max 解析

**答案**：共需要交换 **6** 次，选 **B**；构造出的初始大根堆为  
$$\{98,77,35,62,55,14,35,48\}.$$

**解题切入点**：  
构造初始堆要用“自下而上”的筛选法：从最后一个非叶结点开始，逐个向下调整，使每个子树都满足大根堆性质。  
做题时先定位下标关系，采用 1-based 存储：

- 结点 $i$ 的左孩子为 $2i$，右孩子为 $2i+1$；
- 最后一个非叶结点下标为 $\lfloor n/2\rfloor$；
- $n=8$，所以从下标 $4$ 开始往前调整。

可以把它理解为“先修好底层小堆，再向上合并”，避免上层调整后又破坏下层。

**推演**：  
给定序列为
$$48,\ 62,\ 35,\ 77,\ 55,\ 14,\ 35,\ 98.$$

用 1-based 下标表示，初始完全二叉树如下：

$$
\begin{array}{cccccccc}
1&2&3&4&5&6&7&8\\
48&62&35&77&55&14&35&98
\end{array}
$$

大根堆要求：父结点不小于孩子结点。筛选时总是与较大的孩子比较，若父结点小于较大孩子，则交换。

关键调整代码如下：

```c
cnt = 0;
for (i = n / 2; i >= 1; --i) {
    p = i;
    while (2 * p <= n) {
        j = 2 * p;                      // 左孩子
        if (j + 1 <= n && A[j + 1] > A[j])
            j++;                        // 取较大的孩子
        if (A[j] > A[p]) {
            swap(A[p], A[j]);           // 交换
            cnt++;
            p = j;                      // 继续向下调整
        } else {
            break;
        }
    }
}
```

逐次调整过程如下。

1. 调整下标 $i=4$，结点 $77$：  
   孩子为 $98$，$98>77$，交换一次。  
   序列变为：
   $$48,\ 62,\ 35,\ 98,\ 55,\ 14,\ 35,\ 77.$$
   累计交换次数：$1$。

2. 调整下标 $i=3$，结点 $35$：  
   孩子为 $14$ 和 $35$，较大孩子为 $35$，但 $35$ 不大于 $35$，所以不交换。  
   累计交换次数仍为 $1$。

3. 调整下标 $i=2$，结点 $62$：  
   孩子为 $98$ 和 $55$，$98>62$，交换；  
   继续向下，$62$ 与孩子 $77$ 比较，$77>62$，再交换。  
   本次交换 $2$ 次。  
   累计交换次数：$1+2=3$。

4. 调整下标 $i=1$，根结点 $48$：  
   孩子为 $98$ 和 $35$，$98>48$，交换；  
   继续向下，$48$ 与 $77$ 比较，$77>48$，交换；  
   继续向下，$48$ 与 $62$ 比较，$62>48$，交换。  
   本次交换 $3$ 次。  
   累计交换次数：$3+3=6$。

最终得到大根堆：
$$\{98,77,35,62,55,14,35,48\}.$$

因此交换元素的次数为 $6$，选 **B**。

**易错点**：  

1. 容易从 $i=1$ 开始向下调整，这是错误顺序；建堆必须从最后一个非叶结点 $\lfloor n/2\rfloor$ 开始向前调整。  
2. 不要把第二阶段“输出堆顶后的调整”算进来，题目只问第一阶段建堆。  
3. 本题有一个重复值 $35$：下标 $3$ 的结点是 $35$，孩子中也有 $35$。大根堆允许“父等于子”，因此不交换；若误算一次，就会得到 $7$，选错 C。  
4. 注意区分“交换次数”和“移动次数”：一次交换通常计为一次 swap，不是三次移动。

**命题规律**：  
这是堆排序的常考点，主要考查：

- 初始堆的构造过程；
- 大根堆/小根堆的调整规则；
- 建堆过程中的交换次数、比较次数；
- 给出序列写出初始堆或某一步调整结果。

常见变式包括：

- 改成小根堆；
- 问“比较次数”而不是“交换次数”；
- 问输出堆顶元素后的调整过程；
- 将序列长度增大，考查建堆的时间复杂度 $O(n)$。

复习时要熟练掌握完全二叉树的下标关系，并会手算模拟“筛选法”建堆，特别注意相等元素不交换这一细节。

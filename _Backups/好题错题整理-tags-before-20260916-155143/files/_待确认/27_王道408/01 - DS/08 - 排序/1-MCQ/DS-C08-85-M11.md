# 选择题 第 11 题

![[_Attachments/题目识别/27_王道408-题目/DS-C08-85-M11_题目.png|题目]]

11. 设线性表中每个元素有两个数据项 $k_1$ 和 $k_2$, 现对线性表按以下规则进行排序: 先看数据项 $k_1$, $k_1$ 值小的元素在前, 大的元素在后; 在 $k_1$ 值相同的情况下, 再看 $k_2$, $k_2$ 值小的元素在前, 大的元素在后.
满足这种要求的排序算法是(   ).
A. 先按 $k_1$ 进行直接插入排序, 再按 $k_2$ 进行简单选择排序
B. 先按 $k_2$ 进行直接插入排序, 再按 $k_1$ 进行简单选择排序
C. 先按 $k_1$ 进行简单选择排序, 再按 $k_2$ 进行直接插入排序
D. 先按 $k_2$ 进行简单选择排序, 再按 $k_1$ 进行直接插入排序

## 答案

## DeepSeek V4 Flash Max 解析

**答案**：选 D。应先按次要关键字 $k_2$ 排序，再按主要关键字 $k_1$ 做一次稳定排序；直接插入排序稳定，简单选择排序（交换实现）不稳定，所以“先按 $k_2$ 简单选择排序，再按 $k_1$ 直接插入排序”正确。

**解题切入点**：  
本题是双关键字排序，等价于按 $(k_1,k_2)$ 字典序排序。拿到题目应马上想到基数排序中的 LSD 思想：**次要关键字先排，主要关键字最后用稳定排序收尾**。这里 $k_1$ 是主关键字，$k_2$ 是次关键字；因此最后一趟必须按 $k_1$ 排，且必须保证稳定。选项中最后按 $k_1$ 排的有 B、D，但 B 最后用简单选择排序，不稳定，故排除。

**推演**：  
题目要求的目标顺序是：

$$
x \text{ 排在 } y \text{ 前} \iff x.k_1<y.k_1 \lor (x.k_1=y.k_1 \land x.k_2\le y.k_2)
$$

正确做法是：

1. 第一遍按 $k_2$ 排序，使全表 $k_2$ 值非递减；
2. 第二遍按 $k_1$ 做**稳定排序**，使全表 $k_1$ 值非递减。

证明：设第一遍后序列为 $S'$，它按 $k_2$ 非递减。第二遍对 $S'$ 做稳定排序后得到 $S$。任取 $S$ 中两条记录 $x$ 在 $y$ 前：

- 因为第二遍按 $k_1$ 排序，所以 $x.k_1\le y.k_1$；
- 若 $x.k_1<y.k_1$，已满足题目要求；
- 若 $x.k_1=y.k_1$，因为第二遍稳定，$x,y$ 的相对顺序与 $S'$ 中一致，而 $S'$ 按 $k_2$ 非递减，所以 $x.k_2\le y.k_2$。

因此最终序列满足“先按 $k_1$，$k_1$ 相同再按 $k_2$”的要求。

选项辨析：

- A、C：最后一遍都在按 $k_2$ 全局排序，会打乱 $k_1$ 的主序，错误。例如 $(1,1),(2,0)$ 会被排成 $(2,0),(1,1)$。
- B：虽然也是先 $k_2$ 后 $k_1$，但最后用简单选择排序。简单选择排序用交换实现，不稳定。反例：$A=(1,1), B=(1,2), C=(0,100)$，按 $k_2$ 插入排序后为 $A,B,C$；再按 $k_1$ 简单选择排序时，$C$ 被换到最前面，得到 $C,B,A$，其中 $k_1=1$ 的两条记录 $k_2$ 变成 $2$ 在 $1$ 前，错误。
- D：先按 $k_2$ 简单选择排序，只要求 $k_2$ 值有序，不稳定不影响；再按 $k_1$ 直接插入排序，直接插入是稳定的，所以正确。

关键代码思路如下：

```c
// 第一趟：按 k2 简单选择排序
for (i = 0; i < n - 1; i++) {
    min = i;
    for (j = i + 1; j < n; j++)
        if (L[j].k2 < L[min].k2)
            min = j;
    swap(L[i], L[min]);
}

// 第二趟：按 k1 直接插入排序，注意用 > 保证稳定
for (i = 1; i < n; i++) {
    temp = L[i];
    j = i - 1;
    while (j >= 0 && L[j].k1 > temp.k1) {
        L[j + 1] = L[j];
        j--;
    }
    L[j + 1] = temp;
}
```

**易错点**：  
1. 不要先按 $k_1$ 再按 $k_2$，最后一遍按 $k_2$ 全局排序会破坏 $k_1$ 的主序。  
2. 不要误选 B。B 也是“先 $k_2$ 后 $k_1$”，但最后用简单选择排序，不稳定；交换操作可能打乱 $k_1$ 相同元素的 $k_2$ 顺序。  
3. 不要认为第一遍也必须稳定。第一遍只需要让 $k_2$ 值全局有序；不稳定只影响 $k_2$ 相同元素的相对次序，而这些元素本身不需要再区分。  
4. 写插入排序时，必须用 `>` 而不是 `>=` 比较，否则会移动相等关键字元素，破坏稳定性。

**命题规律**：  
本题考点是**排序稳定性**与**多关键字排序**，本质是基数排序中“低位优先 LSD + 稳定排序”的思想。常见变式有：给出两趟排序操作，判断能否得到字典序结果；或问第一趟、第二趟应分别采用稳定还是不稳定的排序；也可延伸到基数排序的正确性分析。复习时应熟记常见排序稳定性：直接插入、冒泡、归并、基数排序稳定；简单选择、希尔、快速、堆排序不稳定。做多关键字排序题时，始终问自己：**最后一趟对主关键字是否稳定？**

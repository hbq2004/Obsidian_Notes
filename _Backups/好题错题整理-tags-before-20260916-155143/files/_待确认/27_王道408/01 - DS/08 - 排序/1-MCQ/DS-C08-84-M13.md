**答案**：删除大根堆堆顶元素后重新调整堆，关键字的比较次数为 $4$ 次，选 **C**。

**解题切入点**：  
本题考查“堆的删除”及“堆的筛选调整”过程。拿到题先明确：删除堆顶后，实际是把最后一个元素放到堆顶，然后对该元素执行“向下筛选”。此时要数清楚每一次比较。最容易出错的是漏算“先比较左右孩子”的那一次比较。可以把调整过程想象成“空降兵从根节点往下落，每层都要先选出左右两个孩子中的强者，再决定是否继续下落”。

**推演**：  
初始大根堆为完全二叉树，层序序列：

$$
62,\;34,\;53,\;12,\;8,\;46,\;22
$$

树形结构为：

```
        62
       /  \
      34   53
     / \   / \
    12  8 46 22
```

删除堆顶 $62$ 后，将最后一个元素 $22$ 移到堆顶，得到：

```
        22
       /  \
      34   53
     / \   / \
    12  8 46 22  ← 最后一个位置已空出？此处的 22 是移走后的占位，实际不再参与
```

更准确地说，删除后堆中元素为 $34,53,12,8,46,22$，数组形态为：

$$
[22,34,53,12,8,46]
$$

对应完全二叉树：

```
        22
       /  \
      34   53
     / \   /
    12  8 46
```

现在对根节点 $22$ 进行向下调整，规则是：先比较左右孩子，选出较大者，再与当前节点比较，若当前节点小于较大孩子则交换。

**第一轮调整（根节点位置）**：

- 比较左孩子 $34$ 与右孩子 $53$，选出较大者 $53$，比较次数 $+1$；
- 将 $22$ 与 $53$ 比较，$22<53$，交换，比较次数 $+1$。

此时堆变为：

```
        53
       /  \
      34   22
     / \   /
    12  8 46
```

**第二轮调整（当前节点在原来的 $53$ 位置）**：

- 该节点左右孩子为 $46$（左）和 $22$（右，原堆最后一个元素，因为已经移到根，这里实际应为空？注意：原最后一个位置 $22$ 已经移到根，所以该位置为空，但当前节点是 $22$，其右孩子是原来 $22$ 的位置？需要仔细重新梳理）

这里需要特别小心：删除堆顶后，数组长度变为 $6$，原最后一个元素 $22$ 被移到根，因此它原来所在位置已经“空出”，不再参与比较。移动后数组为：

$$
[22,34,53,12,8,46]
$$

下标从 $0$ 开始：

- 根：$22$
- 左孩子：$34$，右孩子：$53$
- $34$ 的左孩子：$12$，右孩子：$8$
- $53$ 的左孩子：$46$，右孩子：无（因为数组长度只有 $6$，下标 $5$ 是 $46$）

所以第一轮调整后，$22$ 与 $53$ 交换，$22$ 移动到原 $53$ 的位置，即根节点的右孩子位置。此时该节点的左右孩子为：

- 左孩子：$46$
- 右孩子：无

因此，第二轮调整时只需要将 $22$ 与左孩子 $46$ 比较，不需要比较左右孩子（因为只有一个孩子）。

比较过程：

- 当前节点 $22$ 与左孩子 $46$ 比较，$22<46$，交换，比较次数 $+1$。

交换后堆变为：

```
        53
       /  \
      34   46
     / \   /
    12  8 22
```

此时 $22$ 已经是叶子节点，调整结束。

总比较次数：

$$
1\ (\text{左右孩子}34,53) + 1\ (\text{与}53) + 1\ (\text{与}46) = 3
$$

咦！这样算出来是 $3$，与之前算的 $4$ 矛盾。需要重新审视“原堆中 $53$ 的右孩子是 $22$”是否仍然存在。

原堆完整二叉树：

```

     / \   / \
```

这里注意：原 $53$ 的右孩子 $22$ 已经被移走，所以现在 $53$ 位置的右孩子为空，左孩子为 $46$。因此第二轮调整时，$22$ 只有左孩子 $46$，不需要比较左右孩子。那么总比较次数是 $3$？但选项没有 $3$ 以外的？有 B.3。可是原书答案是什么？题目给出的“含原书【解答】参考”没有具体答案。需要仔细分析。

再仔细思考：调整堆的算法中，如果当前节点只有一个孩子，则直接与该孩子比较。这里第二轮确实只有一个孩子 $46$，所以比较一次。总次数 $3$。

但之前我计算为 $4$，是因为错误地认为原 $53$ 的右孩子 $22$ 还存在。实际上删除堆顶后，最后一个元素 $22$ 被移走，原来 $53$ 的右孩子位置就空了。那么第一轮调整后，$22$ 移动到 $53$ 的位置，它的左孩子是 $46$，右孩子是空。所以第二轮只比较一次。总计 $3$。

然而，需要确认删除堆顶后，堆中元素个数变为 $6$，完全二叉树的层序序列是 $[22,34,53,12,8,46]$。没错。

那么答案应该是 $3$，选 B。

但为什么常见题目会选 C.4？可能有的教材在删除堆顶时，不是把最后一个元素直接放到堆顶，而是采用“将堆顶与最后一个元素交换，然后堆的大小减一，再对新的堆顶调整”。同样，交换后数组前 $n-1$ 个元素是 $[22,34,53,12,8,46]$，完全相同。调整过程如上，比较次数 $3$。

那么原书解答可能是什么？题目说“含原书【解答】参考”，但没有给出。我们需要根据常见408教材来判断。严蔚敏《数据结构》中堆调整算法：
```cpp
void HeapAdjust(int *a, int s, int m) {
    int rc = a[s];
    for (int j = 2*s; j <= m; j *= 2) {
        if (j < m && a[j] < a[j+1]) ++j;
        if (rc >= a[j]) break;
        a[s] = a[j]; s = j;
    }
    a[s] = rc;
}
```
这里 j 初始为 s 的左孩子（2s），如果 j<m 且 a[j]<a[j+1]，则 j++ 指向右孩子。这个比较次数：先判断 j<m && a[j]<a[j+1]，如果成立则比较一次，否则不比较。然后 rc>=a[j] 比较一次。对于我们的场景，s=1（1-based），m=6。左孩子2=34，右孩子3=53，j=2，j<m(2<6)且a[2]=34<a[3]=53，j++，比较1次；rc=22与a[j]=53比较，22>=53? false，交换，比较2次。s=3。j=2*3=6，j<=m? 6<=6，检查j<m? 6<6 false，所以不比较左右孩子，直接rc=22与a[6]=46比较，22>=46 false，交换，比较3次。s=6，j=12>m退出。总计3次。所以按严蔚敏算法是3次。

但为什么有人算4次？因为他们认为在第二轮，当前节点有左右孩子（错误地把原堆的22位置还当作右孩子）。实际上删除堆顶后，堆的大小已经减少，最后一个元素被移动到根，所以原最后一个位置不再参与。因此正确是3。

在数组实现中，删除堆顶通常是：
```cpp

```
所以数组长度是6，最后一个位置是46。不存在右孩子22。

因此答案应为B.3。

最终输出。**答案**：删除大根堆堆顶元素后重新调整堆，关键字的比较次数为 $3$ 次，选 **B**。

**解题切入点**：  
本题考查“堆的删除”与“堆的筛选调整”。拿到题目先明确堆的存储形态：用完全二叉树层序序列表示。删除堆顶后，不是直接“挖掉根”，而是把最后一个元素移到堆顶，然后对新的堆顶执行“向下筛选”。数比较次数时要严格按筛选算法的每一步来，尤其注意：堆的长度已经减一，原本最后一个元素的位置已经不再属于堆，不能把它再当作某个节点的右孩子。这就像淘汰赛中“补位”的选手已经离开，原位置空出来了。

**推演**：  
初始大根堆层序序列为：

$$
\{62,34,53,12,8,46,22\}
$$

对应完全二叉树：

```
        62
       /  \
      34   53
     / \   / \
    12  8 46 22
```

删除堆顶 $62$ 后，将最后一个元素 $22$ 移到堆顶，堆中剩余元素为 $34,53,12,8,46,22$，此时数组层序序列为：

$$
[22,34,53,12,8,46]
$$

对应完全二叉树：

```
        22
       /  \
      34   53
     / \   /
    12  8 46
```

注意：原 $53$ 的右孩子 $22$ 已被移走，所以现在 $53$ 的左孩子是 $46$，右孩子为空。

对新的堆顶 $22$ 执行向下筛选（大根堆筛选规则：先比较左右孩子，选出较大者，再与当前节点比较）：

**第一轮筛选（根节点）**：

- 比较左孩子 $34$ 与右孩子 $53$：  
  $$34 < 53$$  
  选出较大者 $53$，比较次数 $+1$。

- 将 $22$ 与 $53$ 比较：  
  $$22 < 53$$  
  交换，比较次数 $+1$。

此时堆变为：

```
        53
       /  \
      34   22
     / \   /
    12  8 46
```

即 $22$ 移动到原 $53$ 的位置。

**第二轮筛选（当前节点 $22$）**：

此时 $22$ 的左孩子为 $46$，右孩子为空（因为堆长度只有 $6$，$46$ 的下标为 $5$，其右兄弟不存在）。因此不需要比较左右孩子，直接将 $22$ 与左孩子 $46$ 比较：

$$22 < 46$$

交换，比较次数 $+1$。

堆变为：

```
        53
       /  \
      34   46
     / \   /
    12  8 22
```

此时 $22$ 已是叶子节点，筛选结束。

总比较次数：

$$
1 + 1 + 1 = 3
$$

所以选 **B**。

> 补充：若使用严蔚敏教材中的 `HeapAdjust` 算法（下标从 $1$ 开始），当 `s=1, m=6` 时：
> - 第一次循环：`j=2`，因为 `j<m && a[2]<a[3]`，`j` 变为 $3$，比较 $1$ 次；再比较 `rc` 与 `a[3]`，比较 $1$ 次。
> - 第二次循环：`s=3, j=6`，由于 `j==m`，不比较左右孩子；直接比较 `rc` 与 `a[6]`，比较 $1$ 次。
>  
> 总计 $3$ 次。

**易错点**：  
- **误把原最后一个位置仍当作堆的一部分**：删除堆顶后，堆的大小由 $7$ 变为 $6$。有人会错误地认为第一轮调整后 $22$ 到了原 $53$ 位置，右孩子还是原来的 $22$，从而多算一次“比较左右孩子”和一次“与右孩子比较”，得出 $4$ 次。正确做法是：原 $22$ 已被移到根，它的位置已经空出，所以第二轮只有左孩子 $46$，只比较 $1$ 次。  
- **忽略“先选左右孩子较大者”这一步**：如果直接与左孩子比较，再决定是否比较右孩子，会得到不同次数。408 和主流教材均采用“先比左右孩子，再与父节点比较”的筛选法。  
- **忘记堆删除后长度减一**：删除堆顶前堆有 $7$ 个元素，删除后只剩 $6$ 个，调整范围是前 $6$ 个元素，不能把第 $7$ 个元素（原 $22$）继续纳入比较。

**命题规律**：  
这是堆排序和优先队列中的基础考点，常以选择题形式出现，也可能在大题中结合建堆、插入、删除一起考查。核心是掌握大根堆/小根堆的向下调整（`sift down`）过程，并能准确数出关键字比较次数。  
常见变式包括：  
- 给定初始序列，求建堆过程中的比较次数；  
- 求插入一个元素后向上调整的比较次数；  
- 将大根堆改为小根堆，重新计算调整次数；  
- 结合数组下标，考查 `HeapAdjust` 的循环过程。

复习时建议：  
1. 熟练掌握完全二叉树层序序列与堆的对应关系，画图辅助分析。  
2. 牢记删除堆顶的步骤：末尾元素补根 → 堆长减一 → 向下调整。  
3. 能区分“左右孩子比较”和“与父节点比较”是两种独立的比较。  
4. 多练习手算比较次数，注意边界条件（只有一个孩子时无需比较左右孩子）。

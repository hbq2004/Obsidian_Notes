# 选择题 第 12 题

![[_Attachments/题目识别/27_王道408-题目/DS-C08-86-M12_题目.png|题目]]

12. 一台计算机具有多核$CPU$，可以同时执行相互独立的任务。归并排序的各个归并段可以并行执行，在下列排序算法中，不可以并行执行的有( )。
$I$.基数排序 &emsp; $II$.快速排序 &emsp; $III$.冒泡排序 &emsp; $IV$.堆排序
(A) $I$、$III$
(B) $I$、$II$
(C) $I$、$III$、$IV$
(D) $II$、$IV$

## DeepSeek V4 Flash Max 解析

**答案**：选 C：$I$、$III$、$IV$（基数排序、冒泡排序、堆排序）不可以并行执行；快速排序可以并行执行。

**解题切入点**：

判断排序算法能否并行，关键看算法能否被拆成若干个“互不等待、互不依赖”的独立子任务。题干给了基准：归并排序的各个归并段可以并行执行，因为各归并段排序互不干扰，最后再合并即可。

如果一个算法的某一步必须依赖上一步产生的完整数组状态，例如“后一步要读前一步的全局结果”，那么它就不适合多核并行。

**推演**：

以归并排序为参照：归并排序先把序列分成多个子区间，各子区间独立排序，最后合并，因此可以并行。

1. **基数排序（按考研常规的 LSD 基数排序）**：

$$ \text{for } i=0,1,\ldots,d-1:\ \text{按第 } i \text{ 位分配} \rightarrow \text{收集} $$

第 $i+1$ 趟必须使用第 $i$ 趟收集后的全局序列。相邻两趟之间存在严格先后依赖，不能拆成多个互不相关的子问题并行完成，所以不可并行。

2. **快速排序**：

设一次划分后枢轴元素下标为 $p$，则

$$
A[l..p-1]\le A[p]\le A[p+1..r]
$$

划分完成后，左右两个子区间互不影响，可以分别交给两个 CPU 并行执行：

$$
\text{task}_1:\mathrm{QuickSort}(A,l,p-1),\qquad
\text{task}_2:\mathrm{QuickSort}(A,p+1,r)
$$

所以快速排序可以并行。

3. **冒泡排序**：

每趟冒泡的相邻交换形如：

$$
\text{if } A[j]>A[j+1],\ \text{交换 } A[j]\text{ 与 }A[j+1]
$$

相邻两对比较共享元素 $A[j+1]$，前一次交换会直接影响后一次比较；并且下一趟排序依赖上一趟排序后的数组状态。虽然存在“奇偶交换排序”这类并行变体，但标准冒泡排序本身不可并行。

4. **堆排序**：

建堆后，排序阶段为：

$$
\text{for } i=n \text{ downto } 2:\ 
\text{swap}(A[1],A[i]);\ \mathrm{SiftDown}(A,1,i-1)
$$

每取出一个当前堆顶元素，都要调整堆；后一次取堆顶依赖前一次调整后的堆状态，多个核不能同时独立完成多次“取堆顶并调整”的操作。因此堆排序的主过程是串行的，不可并行。

综上，不可并行的有 $I$、$III$、$IV$，答案为 C。

**易错点**：

- 误以为快速排序的“划分”本身难并行，就认为快速排序不可并行。实际上划分完成后左右两个子区间完全独立，完全可以并行递归排序。
- 误以为基数排序“单趟分配”可并行，就认为整个基数排序可并行。按 408 常规算法，基数排序的趟与趟之间必须串行，不能判为可并行。
- 误以为冒泡排序有并行版本“奇偶交换排序”，就认为冒泡排序可并行。题目中的冒泡排序指标准算法，不能拿变体替代。
- 误以为堆排序“建堆”过程可并行，就认为整个堆排序可并行。堆排序中反复“取堆顶—调整堆”的主过程是严格串行的。
- 审题要看清问的是“不可以并行执行”，不是“可以并行执行”。

**命题规律**：

- 考点是排序算法过程理解，以及多核 CPU 下“独立任务划分”的并行思维。
- 常见变式有：把题目改为“可以并行执行的有”；把基数排序换成希尔排序、简单选择排序；结合外部排序考查多路归并与并行归并段。
- 复习建议：不要只背排序算法的时间复杂度、空间复杂度和稳定性。对每种排序算法都要问三个问题：每趟之后是否产生独立子问题？下一步是否依赖上一步的全局结果？能否把不同部分交给多个 CPU 同时执行？典型可并行的是快速排序和归并排序；典型不可并行的是冒泡排序、堆排序和常规 LSD 基数排序。

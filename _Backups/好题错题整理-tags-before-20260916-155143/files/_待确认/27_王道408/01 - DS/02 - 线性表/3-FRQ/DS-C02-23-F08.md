# 综合题 第 8 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-23-F08_题目.png|题目]]

8. 设$A$和$B$是两个单链表(带头结点), 其中元素递增有序。设计一个算法从$A$和$B$中的公共元素产生单链表$C$, 要求不破坏$A$、$B$的结点.

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C02-23-F08_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：用两个指针分别从 $A$、$B$ 的首元结点开始同步扫描，比较当前元素值：小者对应指针后移；相等时新建结点，把公共元素复制到新结点中尾插到 $C$，然后两个指针同时后移。这样得到递增有序的 $C$，且不改变 $A$、$B$ 的任何结点。

**解题切入点**：看到“两个单链表元素递增有序”，应立刻定位为“有序表的归并”类问题。不要写双重循环对每个 $A$ 结点到 $B$ 中查找，那样最坏是 $O(nm)$。利用有序性，可以用双指针依次比较，像“两有序数组合并求交集”一样：每次只移动较小者，相等则输出并同时移动。这是有序表算法题最常用的双指针模板。

**推演**：

设 $A$、$B$ 都是带头结点的单链表，首元结点分别记为：

$$
pa = A\rightarrow \text{next},\qquad pb = B\rightarrow \text{next}
$$

$C$ 也带头结点，用一个尾指针 $r$ 始终指向 $C$ 的最后一个结点，方便尾插。

核心过程如下：

1. 初始化：

$$
C = (LinkList)\text{malloc}(\text{sizeof}(LNode))
$$

令：

$$
r = C,\quad r\rightarrow \text{next} = \text{NULL}
$$

2. 循环条件：

$$
while(pa \neq \text{NULL} \ \&\& \ pb \neq \text{NULL})
$$

3. 比较：

- 若 $pa\rightarrow data < pb\rightarrow data$，说明 $pa$ 当前结点的值不可能出现在 $B$ 的剩余部分中，执行：

$$
pa = pa\rightarrow \text{next}
$$

- 若 $pa\rightarrow data > pb\rightarrow data$，同理执行：

$$
pb = pb\rightarrow \text{next}
$$

- 若 $pa\rightarrow data = pb\rightarrow data$，说明该值是 $A$、$B$ 的公共元素，新建结点 $s$，将其尾插到 $C$：

$$
s = (LinkList)\text{malloc}(\text{sizeof}(LNode))
$$

$$
s\rightarrow data = pa\rightarrow data,\quad s\rightarrow next = \text{NULL}
$$

$$
r\rightarrow next = s,\quad r = s
$$

然后两个指针同时后移：

$$
pa = pa\rightarrow \text{next},\qquad pb = pb\rightarrow \text{next}
$$

4. 循环结束后，令：

$$
r\rightarrow next = \text{NULL}
$$

因为只要有其中一个链表扫描完，后面就不可能再出现公共元素。

关键代码思路如下：

```c
LinkList Intersection(LinkList A, LinkList B) {
    LNode *pa = A->next, *pb = B->next;
    LinkList C = (LinkList)malloc(sizeof(LNode));
    LNode *r = C;

    while (pa != NULL && pb != NULL) {
        if (pa->data < pb->data) {
            pa = pa->next;
        } else if (pa->data > pb->data) {
            pb = pb->next;
        } else {
            LNode *s = (LNode*)malloc(sizeof(LNode));
            s->data = pa->data;
            s->next = NULL;
            r->next = s;
            r = s;

            pa = pa->next;
            pb = pb->next;
        }
    }

    r->next = NULL;
    return C;
}
```

时间复杂度：每轮循环至少有一个指针前进，$A$、$B$ 中每个结点最多被扫描一次，所以若：

$$
n = |A|,\qquad m = |B|
$$

则：

$$
T(n,m) = O(n+m)
$$

空间复杂度：除了结果链表 $C$ 外，只用了常数个辅助指针，因此额外辅助空间为：

$$
O(1)
$$

结果链表 $C$ 本身需要 $O(k)$ 的空间，其中 $k$ 为公共元素个数。

**易错点**：

1. 直接连接 $A$ 或 $B$ 中的公共结点到 $C$。  
   题目明确要求“不破坏 $A$、$B$ 的结点”，因此不能直接修改 $A$、$B$ 的指针，必须新建结点并复制数据。

2. 忘记最后将 $r\rightarrow next$ 置空。  
   尾插结束后如果不置空，$C$ 的尾结点指针可能悬空，导致链表不完整。

3. 相等时只移动一个指针。  
   当前两个值相等，说明这两个结点都已经被“消费”掉，应该同时移动 $pa$ 和 $pb$；否则可能造成重复比较，甚至破坏 $O(n+m)$ 的复杂度保证。

4. 比较大小关系时移动错指针。  
   应该移动“值较小”的那一侧指针，因为较小值不可能在另一个有序表中出现。

5. 对“递增”的理解。  
   本题“递增有序”默认严格递增，所以不需要考虑重复值。如果题目改为“非递减有序”且要求集合式交集，则还要考虑跳过重复元素，避免输出重复公共值。

**命题规律**：该题考查“有序单链表的归并”这一核心操作，是 408 链表算法题的高频考点。常见的变式包括：求两个有序链表的交集、并集、差集，合并两个有序链表，或者要求原地利用结点、不申请新结点等。复习时应把“双指针扫描有序表”的方法作为模板，熟练掌握带头结点链表的尾插法、头插法以及指针移动的边界条件；写代码前先画图模拟，可以显著降低出错率。

# 综合题 第 6 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-23-F06_题目.png|题目]]

6. 设 $C = \{a_1, b_1, a_2, b_2, \cdots, a_n, b_n\}$ 为线性表，采用带头结点的单链表存放，设计一个就地算法，将其拆分为两个线性表，使得 $A = \{a_1, a_2, \cdots, a_n\}$，$B = \{b_n, \cdots, b_2, b_1\}$.

## DeepSeek V4 Flash Max 解析

**答案**：一趟扫描即可完成：奇数位置结点 \(a_i\) 用尾插法接到 \(A\) 尾部，偶数位置结点 \(b_i\) 用头插法插入 \(B\) 头部，从而得到 \(A=\{a_1,a_2,\cdots,a_n\}\)、\(B=\{b_n,\cdots,b_2,b_1\}\)。时间复杂度 \(O(n)\)，辅助空间 \(O(1)\)。

**解题切入点**：拿到题先比较两个目标序列：\(A\) 与原表奇数位置顺序一致，\(B\) 则要求偶数位置反序。单链表只能向后遍历，不能从尾部反向构造，而“头插法”恰好天然产生逆序。所以定位考点为：单链表原地拆分 + 尾插法保序 + 头插法逆序。类比整理牌：\(A\) 按摸牌顺序往后放，\(B\) 要求每次新摸到的牌都压在最上面，最后 \(B\) 自然就是反序。

**推演**：

原链表结构为：

$$
C \to a_1 \to b_1 \to a_2 \to b_2 \to \cdots \to a_n \to b_n \to \text{NULL}
$$

目标拆成：

$$
A \to a_1 \to a_2 \to \cdots \to a_n \to \text{NULL}
$$

$$
B \to b_n \to \cdots \to b_2 \to b_1 \to \text{NULL}
$$

核心做法：让指针 \(p\) 依次指向 \(a_i\)。每次先把 \(a_i\) 尾插到 \(A\)，然后 \(p\) 后移到 \(b_i\)，再把 \(b_i\) 头插到 \(B\)。因为 \(b_1,b_2,\cdots,b_n\) 依次头插，所以最终 \(B\) 中顺序正好是 \(b_n,\cdots,b_2,b_1\)。

C++ 风格核心代码如下：

```c
typedef struct LNode {
    ElemType data;
    struct LNode *next;
} LNode, *LinkList;

void splitList(LinkList C, LinkList &A, LinkList &B) {
    A = C;                               // 原头结点作为 A 的头结点
    B = (LinkList)malloc(sizeof(LNode)); // 为 B 分配头结点，常数空间
    B->next = NULL;

    LNode *p = A->next;  // p 指向 a_i
    LNode *ra = A;       // ra 始终指向 A 的尾结点
    LNode *q;

    while (p != NULL) {
        // a_i 尾插到 A
        ra->next = p;
        ra = p;
        p = p->next;     // p 移到 b_i

        if (p != NULL) {
            q = p->next; // 保存下一个 a_{i+1}

            // b_i 头插到 B
            p->next = B->next;
            B->next = p;

            p = q;       // p 回到 a_{i+1}
        }
    }

    ra->next = NULL;     // A 表尾置空，断开与 B 的残留连接
}
```

正确性证明：

进入第 \(i\) 次循环前，前 \(i-1\) 对结点已处理完：  
\(A\) 中为 \(a_1 \to a_2 \to \cdots \to a_{i-1}\)，  
\(B\) 中为 \(b_{i-1} \to \cdots \to b_2 \to b_1\)，  
指针 \(p\) 指向 \(a_i\)。

一次循环后：

- \(a_i\) 被接到 \(A\) 尾部，所以 \(A\) 变为 \(a_1 \to \cdots \to a_i\)；
- \(b_i\) 被头插到 \(B\)，所以 \(B\) 变为 \(b_i \to b_{i-1} \to \cdots \to b_1\)；
- \(p\) 通过预先保存的 \(q\) 指向下一个 \(a_{i+1}\)。

归纳可知，循环结束后：

$$
A = a_1 \to a_2 \to \cdots \to a_n
$$

$$
B = b_n \to b_{n-1} \to \cdots \to b_1
$$

最后将 \(ra \to \text{next}\) 置空，保证 \(A\) 不再链到原来的 \(b_n\) 等结点上。

时间复杂度：每个结点只被扫描和处理常数次，所以为 \(O(n)\)。  
辅助空间：只使用了常数个指针变量和一个 \(B\) 的头结点，没有新建任何数据结点，所以为 \(O(1)\)。

**易错点**：

- 头插 \(b_i\) 前必须先用 `q = p->next` 保存后继。若先执行 `p->next = B->next`，则后半段链表会丢失。
- `B` 的头插顺序不能写反。正确顺序是先 `p->next = B->next`，再 `B->next = p`；若先改 `B->next`，会丢失原 `B` 表头。
- 最后不能忘记 `ra->next = NULL`。否则 \(A\) 的尾结点仍可能指向原来的 \(b_n\)，导致 \(A\) 中混入 \(B\) 的结点。
- 若用尾插法构造 \(B\)，得到的是 \(b_1 \to b_2 \to \cdots \to b_n\)，与题目要求的 \(b_n \to \cdots \to b_1\) 相反。
- 如果每取一个 \(b_i\) 都新建结点，则空间复杂度变为 \(O(n)\)，不符合“就地”要求。

**命题规律**：本题属于“单链表原地重排、拆分”的经典代码题。408 常将头插法、尾插法、链表逆置和链表拆分结合考查。常见变式有：拆成 \(A=\{a_1,\cdots,a_n\}\)、\(B=\{b_1,\cdots,b_n\}\)（两个都正序，则都用尾插法）；把一个链表按奇偶位置拆成两个链表；或者拆完后将两个链表再合并。复习时建议多画指针变化图，牢记“头插法逆序、尾插法保序”，并注意保存被修改结点的后继。

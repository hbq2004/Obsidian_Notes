# 综合题 第 10 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-22-F10_题目.png|题目]]

10.【2010统考真题】设将 $n (n>1)$ 个整数存放到一维数组 $R$ 中。设计一个在时间和空间两方面都尽可能高效的算法。将 $R$ 中保存的序列循环左移 $p (0<p<n)$ 个位置，即将 $R$ 中的数据由 $(X_0,X_1,\cdots,X_{n-1})$ 变换为 $(X_p,X_{p+1},\cdots,X_{n-1},X_0,X_1,\cdots,X_{p-1})$。要求：
1) 给出算法的基本设计思想。
2) 根据设计思想，采用 $C$ 或 $C++$ 或 $Java$ 语言描述算法，关键之处给出注释。
3) 说明你所设计算法的时间复杂度和空间复杂度.

## DeepSeek V4 Flash Max 解析

**答案**：采用“三次逆置”算法：先将前 $p$ 个元素逆置，再将后 $n-p$ 个元素逆置，最后将整个数组逆置，即可完成循环左移 $p$ 位；时间复杂度 $O(n)$，空间复杂度 $O(1)$。

**解题切入点**：拿到题先识别本质：循环左移 $p$ 位就是把数组从中间分成两段，把前一段 $A$ 和后一段 $B$ 交换成 $BA$。如果开辅助数组，时间 $O(n)$、空间 $O(n)$，不符合“空间高效”；于是想到用“逆置”操作原地交换两段。可以类比：手里两叠牌 $A$、$B$，要原地交换成 $B,A$，把两叠牌分别倒过来，再整叠倒过来即可。

**推演**：

### 1. 基本设计思想

设原数组为

$$
R=(X_0,X_1,\cdots,X_{n-1})
$$

令

$$
A=(X_0,X_1,\cdots,X_{p-1}),\qquad
B=(X_p,X_{p+1},\cdots,X_{n-1})
$$

则原数组可记为 $(A,B)$，目标是变成 $(B,A)$。

定义“逆置”操作：把一段区间 $[l,r]$ 中的元素倒序排列。

算法步骤：

1. 逆置前 $p$ 个元素：$\mathrm{reverse}(R,0,p-1)$；
2. 逆置后 $n-p$ 个元素：$\mathrm{reverse}(R,p,n-1)$；
3. 逆置整个数组：$\mathrm{reverse}(R,0,n-1)$。

### 2. 正确性证明

记 $\operatorname{rev}(S)$ 表示序列 $S$ 的逆序。

执行第一步后：

$$
(A,B)\longrightarrow (\operatorname{rev}(A),B)
$$

执行第二步后：

$$
(\operatorname{rev}(A),B)
\longrightarrow
(\operatorname{rev}(A),\operatorname{rev}(B))
$$

执行第三步后：

$$
(\operatorname{rev}(A),\operatorname{rev}(B))
\longrightarrow
\operatorname{rev}\big((\operatorname{rev}(A),\operatorname{rev}(B))\big)
$$

利用公式

$$
\operatorname{rev}(PQ)=\operatorname{rev}(Q)\operatorname{rev}(P)
$$

得到：

$$
\operatorname{rev}\big((\operatorname{rev}(A),\operatorname{rev}(B))\big)
=
\operatorname{rev}(\operatorname{rev}(B))\operatorname{rev}(\operatorname{rev}(A))
=
(B,A)
$$

因此最终结果正好是循环左移 $p$ 位。

例如 $R=(1,2,3,4,5)$，$n=5$，$p=2$：

- 逆置前 2 个：$(2,1,3,4,5)$；
- 逆置后 3 个：$(2,1,5,4,3)$；
- 整体逆置：$(3,4,5,1,2)$。

结果正确。

### 3. C 语言代码实现

```c
// 将数组 R 中 [left, right] 区间逆置
void reverse(int R[], int left, int right) {
    while (left < right) {
        int temp = R[left];
        R[left] = R[right];
        R[right] = temp;
        left++;
        right--;
    }
}

// 将数组 R 循环左移 p 位
void leftShift(int R[], int n, int p) {
    p = p % n;                     // 题目已给 0<p<n，这里保证通用性
    if (p == 0 || n <= 1) return;

    reverse(R, 0, p - 1);          // 逆置前 p 个元素
    reverse(R, p, n - 1);          // 逆置后 n-p 个元素
    reverse(R, 0, n - 1);          // 整体逆置
}
```

### 4. 复杂度分析

- 第一次逆置长度为 $p$，时间 $O(p)$；
- 第二次逆置长度为 $n-p$，时间 $O(n-p)$；
- 第三次逆置长度为 $n$，时间 $O(n)$。

总时间复杂度：

$$
O(p)+O(n-p)+O(n)=O(n)
$$

空间上只使用了若干临时变量，没有借助额外辅助数组，因此空间复杂度为：

$$
O(1)
$$

**易错点**：

1. **逆置顺序记错。**  
   左移 $p$ 位是“前 $p$ 个逆置、后 $n-p$ 个逆置、整体逆置”。如果把顺序写成“整体逆置、前 $n-p$ 个逆置、后 $p$ 个逆置”，结果也正确，但下标容易写错。

2. **数组下标越界。**  
   C 语言下标从 0 开始，第二次逆置应写成 `reverse(R, p, n - 1)`，不能写成 `reverse(R, p, n)`，否则会把 `R[n]` 这一越界位置也纳入操作。

3. **忽略 $p$ 与 $n$ 的关系。**  
   本题已给 $0<p<n$，可以直接用；若题目改为任意 $p$，应先执行 `p = p % n`。因为循环左移 $n$ 位等于不变。

4. **使用额外数组。**  
   如果开一个辅助数组复制，虽然时间也是 $O(n)$，但空间为 $O(n)$，不满足“空间尽可能高效”的要求。

5. **把复杂度写成 $O(np)$。**  
   若采用“每次左移一位，重复 $p$ 次”的朴素算法，时间复杂度为 $O(np)$；三次逆置法才是 $O(n)$。

**命题规律**：本题是 408 中典型的“顺序表/数组原地操作”综合题，核心考点是逆置操作与复杂度分析。常见变式包括：循环右移 $p$ 位、判断字符串旋转、数组部分逆置等。复习时应重点掌握“三次逆置”的模型，并且明白其背后的序列恒等式：先局部逆置、再整体逆置，可以交换两段子序列的位置。答题时要先写设计思想，再给代码，最后明确说明时间复杂度和空间复杂度，尽量做到代码简洁、边界清晰。

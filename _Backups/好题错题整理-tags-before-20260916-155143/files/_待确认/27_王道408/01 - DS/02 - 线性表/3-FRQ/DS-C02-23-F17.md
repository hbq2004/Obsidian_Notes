# 综合题 第 17 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-23-F17_题目.png|题目]]

17.【2009 统考真题】已知一个带有表头结点的单链表,结点结构为

| $data$ | $link$ |
| --- | --- |

假设该链表只给出了头指针 $list$. 在不改变链表的前提下，请设计一个尽可能高效的算法,查找链表中倒数第 $k$ 个位置上的结点 ($k$ 为正整数). 若查找成功,算法输出该结点的 $data$ 域的值,并返回 $1$; 否则,只返回 $0$. 要求:

1) 描述算法的基本设计思想.

2) 描述算法的详细实现步骤.

3) 根据设计思想和实现步骤，采用程序设计语言描述算法 (使用 $C$、 $C++$ 或 $Java$ 语言实现), 关键之处请给出简要注释.

## DeepSeek V4 Flash Max 解析

**答案**：采用双指针一次扫描链表：第一个指针先走 $k$ 步，若提前遇空则返回 0；两指针再同步走，当第一个指针走到尾后时，第二个指针正好指向倒数第 $k$ 个结点，输出其 data 并返回 1。时间复杂度 $O(n)$，空间复杂度 $O(1)$。

**解题切入点**：  
看到“单链表”和“倒数第 $k$ 个”，首先想到正数第 $n-k+1$ 个，但 $n$ 未知。最直接的思路是先遍历求 $n$ 再找，但那样需要两趟扫描。更优的是“双指针/尺取法”：让一个指针先走 $k$ 步，另一个再同步出发，相当于保持 $k$ 个结点的间隔；这就像赛跑时让领跑者先跑 $k$ 步，当领跑者到终点时，后者距终点正好 $k$ 步。题目明确“不改变链表”，所以不能原地逆置；要求“尽可能高效”，所以要往 $O(n)$ 时间、$O(1)$ 空间的双指针方案上想。

**推演**：  
设链表的数据结点为 $A_1,A_2,\ldots,A_n$，要查找的是 $A_{n-k+1}$。

1. **基本设计思想**：  
   使用两个指针 $p,q$，初始都指向第一个数据结点。先让 $p$ 向后移动 $k$ 次；若中途 $p$ 变为 NULL，说明 $n<k$，不存在倒数第 $k$ 个结点，返回 0。若 $p$ 成功移动了 $k$ 次，则 $p$ 比 $q$ 领先 $k$ 个链接。接着让 $p,q$ 同步向后移动，直到 $p$ 变为 NULL，此时 $q$ 正好落后表尾 $k$ 个位置，即 $q$ 指向倒数第 $k$ 个结点。

2. **详细实现步骤**：  
   - 若 $k\le 0$，返回 0（题目说 $k$ 为正整数，防御性处理）。  
   - $p=q=list\to link$，$count=0$。  
   - while $p\neq$ NULL 且 $count<k$：$p=p\to link$，$count++$。  
   - 若 $count<k$，说明链表长度小于 $k$，返回 0。  
   - while $p\neq$ NULL：$p=p\to link$，$q=q\to link$。  
   - 输出 $q\to data$，返回 1。

3. **正确性证明**：  
   第一个循环结束时，若成功，则 $p$ 相对初始位置向后移动了 $k$ 步。若 $k<n$，$p=A_{k+1}$，$q=A_1$；若 $k=n$，$p=$ NULL，$q=A_1$。无论哪种情况，$p$ 都相对 $q$ 领先 $k$ 个链接。

   第二个循环中，$p,q$ 每轮同步走一步，因此二者之间的“步数差”恒为 $k$。当 $p$ 走到 NULL 时，说明 $p$ 已经越过表尾，而 $q$ 仍在表中，且从 $q$ 到表尾 NULL 恰好还有 $k$ 步。因此 $q$ 是倒数第 $k$ 个结点。更形式化地，$q$ 从 $A_1$ 走了 $n-k$ 步，指向 $A_{n-k+1}$；而 $A_{n-k+1}$ 从尾部数正是第 $k$ 个。

   若第一个循环提前因 $p=$ NULL 结束，则 $count<k$，说明 $n<k$，返回 0 是正确的。

4. **代码实现（C 语言，假设数据域为 int）**：
```c
#include <stdio.h>

typedef struct LNode {
    int data;
    struct LNode *link;
} LNode, *LinkList;

int FindKthFromEnd(LinkList list, int k) {
    if (k <= 0) return 0;          // 防御：k为正整数，但若非法直接失败

    LNode *p = list->link;         // p 先走
    LNode *q = list->link;         // q 跟随
    int count = 0;

    // p 先走 k 步
    while (p != NULL && count < k) {
        p = p->link;
        count++;
    }

    if (count < k) return 0;       // 链表中结点数不足 k

    // p、q 同步后移
    while (p != NULL) {
        p = p->link;
        q = q->link;
    }

    printf("%d\n", q->data);       // 输出倒数第 k 个结点的 data
    return 1;
}
```
代码中完全没有修改结点的 link 域，符合“不改变链表”的要求。

**易错点**：  
1. 步数差写错：有人让 $p$ 先走 $k-1$ 步，然后用 `while (p->link != NULL)` 判断；这与“先走 $k$ 步，用 `p != NULL` 判断”是两种写法，混用会差一位。建议固定一种并用小链表验证。  
2. 忘记检查 $k>$ 链表长度：若链表只有 3 个结点而 $k=5$，第一个循环结束后 $p$ 已经为 NULL，若不判断 `count < k` 就直接进入第二步，$q$ 会停在错误位置或产生空指针。  
3. 空表处理：`list->link` 可能为 NULL，若代码一开始就 `q->data` 会崩溃；上述循环和长度检查能自动排除。  
4. 没有利用头结点：指针应指向第一个数据结点 `list->link`，而不是头结点 `list`，否则定位会整体偏移一位。  
5. 为省事用逆置或递归：会修改链表或使用 $O(n)$ 的栈空间，不符合题目“不改变链表”和“尽可能高效”的要求。

**命题规律**：  
本题是 408 链表双指针的经典考题，核心考查单链表遍历、双指针同步/异步移动、边界条件分析和复杂度分析。常见变式包括：删除倒数第 $k$ 个结点（需保存或定位前驱）、查找中间结点（快指针一次走两步）、判断链表是否有环（快慢指针）、找两个链表的交点等。复习时应熟练掌握“快慢指针”模型，画图模拟 $k=1$、$k=n$、$k>n$、空表四类边界；代码要能手写，注意 C 语言中结构体指针的写法。408 算法题一般要求“时间尽可能高效”，双指针的 $O(n)$ 时间、$O(1)$ 空间方案通常是首选。

# 综合题 第 11 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-22-F11_题目.png|题目]]

11.【2011统考真题】一个长度为$L(L\geq1)$的升序序列$S$，处在第$\lfloor L/2 \rfloor$个位置的数称为$S$的中位数。
例如，若序列$S_1=(11,13,15,17,19)$，则$S_1$的中位数是15，两个序列的中位数是含它们所有元素的升序序列的中位数。例如，若$S_2=(2,4,6,8,20)$，则$S_1$和$S_2$的中位数是11。现在有两个等长升序序列$A$和$B$，试设计一个在时间和空间两方面都尽可能高效的算法，找出两个序列$A$和$B$的中位数。要求：
1) 给出算法的基本设计思想。
2) 根据设计思想，采用$C$或$C++$或$Java$语言描述算法，关键之处给出注释。
3) 说明你所设计算法的时间复杂度和空间复杂度。

## DeepSeek V4 Flash Max 解析

**答案**：采用“比较两个等长有序序列当前区间的中位数，成对舍去不可能包含中位数的区间”的减治算法，时间复杂度为 $O(\log n)$，空间复杂度为 $O(1)$。

**解题切入点**：  
看到“两个有序序列 + 找中位数”，不要先想全部归并，而应想到中位数本质上是“第 $k$ 小元素”。两个序列等长是中点比较法的关键：每次比较双方中位数，可以一次性排除一半元素，类似“两个有序队伍找第 $n$ 名，比较两队当前队长，淘汰弱队前半段和强队后半段”。

注意：题面若写成 $\lfloor L/2\rfloor$，与例子矛盾；按 2011 统考原题及例子，中位数位置应为第 $\lceil L/2\rceil$ 个元素。因此两个长度为 $n$ 的序列合并后长度为 $2n$，要找的是第 $n$ 个元素（偶数长度时取下中位数）。

**推演**：

设 $A,B$ 长度均为 $n$。维护两个等长区间：

$$A[l_A..r_A],\qquad B[l_B..r_B]$$

初始时：

$$l_A=l_B=0,\qquad r_A=r_B=n-1$$

当前区间长度为 $m$。取两个区间的下中位数位置：

$$
p=\left\lfloor\frac{l_A+r_A}{2}\right\rfloor,\qquad
q=\left\lfloor\frac{l_B+r_B}{2}\right\rfloor
$$

比较 $A[p]$ 与 $B[q]$：

- 若 $A[p]=B[q]$，则该值就是中位数，直接返回。
- 若 $A[p]<B[q]$，则中位数不可能在 $A$ 中较小的一半，也不可能在 $B$ 中较大的一半，舍去这两部分。
- 若 $A[p]>B[q]$，对称处理。

具体舍去规则如下：

| 当前区间长度 $m$ | $A[p]<B[q]$ | $A[p]>B[q]$ |
|---|---|---|
| 奇数 | 令 $l_A=p,\ r_B=q$ | 令 $r_A=p,\ l_B=q$ |
| 偶数 | 令 $l_A=p+1,\ r_B=q$ | 令 $r_A=p,\ l_B=q+1$ |

每次舍去两边相同数量的元素，所以 $A,B$ 的当前区间仍然等长。当两个区间都只剩 1 个元素时，中位数就是这两个元素中较小的一个。

C++ 描述如下：

```cpp
int findMedian(int A[], int B[], int n) {
    int lA = 0, rA = n - 1;
    int lB = 0, rB = n - 1;

    while (lA < rA || lB < rB) {
        int midA = lA + (rA - lA) / 2;
        int midB = lB + (rB - lB) / 2;

        if (A[midA] == B[midB])
            return A[midA];

        int len = rA - lA + 1;  // 两个区间长度始终相等

        if (A[midA] < B[midB]) {
            if (len % 2 == 0) {          // 偶数长度
                lA = midA + 1;
                rB = midB;
            } else {                     // 奇数长度
                lA = midA;
                rB = midB;
            }
        } else {
            if (len % 2 == 0) {
                rA = midA;
                lB = midB + 1;
            } else {
                rA = midA;
                lB = midB;
            }
        }
    }

    return A[lA] < B[lB] ? A[lA] : B[lB];
}
```

正确性简要说明：  
每次循环开始时，要找的中位数都是当前两个等长区间合并后的第 $m$ 小元素。若 $A[p]<B[q]$，则 $A$ 中被舍去的较小元素一定排在第 $m$ 小元素之前，$B$ 中被舍去的较大元素一定排在第 $m$ 小元素之后；两边舍去数量相同，所以中位数仍在剩余区间中。$A[p]>B[q]$ 时对称。循环结束时两个区间各剩 1 个元素，合并后长度为 2，其中位数即较小者。

时间复杂度：每轮区间长度大致减半，共 $O(\log n)$ 轮，每轮只做常数次比较，因此时间复杂度为 $O(\log n)$。  
空间复杂度：只使用了常数个变量，因此空间复杂度为 $O(1)$。

**易错点**：

1. 容易把偶数长度序列的中位数误认为是“中间两个数的平均值”。本题按统考定义取第 $\lceil L/2\rceil$ 个，即下中位数，不是平均值。
2. 更新区间时容易忽略奇偶性。奇数长度时，中位数本身需要保留；偶数长度时，下中位数可能要被舍去。不能只写“保留右半/左半”而不区分奇偶。
3. 循环结束后应返回 `min(A[lA], B[lB])`，不是 `max`。因为只剩下两个元素时，题目要求的中位数是第 $n$ 个，即较小者。
4. 若用递归实现，空间复杂度会变成 $O(\log n)$；题目要求“时间和空间两方面都尽可能高效”，因此应采用迭代写法，空间复杂度保持 $O(1)$。

**命题规律**：

本题核心考点是“两个有序序列的中位数 / 第 $k$ 小元素”，属于典型的减治思想。408 中常以“等长升序序列”为条件，要求设计时间和空间都高效的算法。常见变式有：

- 找两个不等长有序数组的第 $k$ 小元素；
- 找两个有序数组的上中位数或下中位数；
- 允许 $O(n)$ 时间时的归并计数法。

复习时建议掌握“比较中位数、舍去一半”的二分思想，熟练写出奇偶分支代码，并理解循环不变量。能证明每次舍去的元素确实不可能成为答案，是这类题得高分的关键。

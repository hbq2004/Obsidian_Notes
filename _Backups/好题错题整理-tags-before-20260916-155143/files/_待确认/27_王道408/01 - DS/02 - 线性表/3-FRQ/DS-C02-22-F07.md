# 综合题 第 7 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-22-F07_题目.png|题目]]

7. 已知在一维数组$A[m+n]$中依次存放两个线性表$(a_1,a_2,a_3,\cdots,a_m)$和$(b_1,b_2,b_3,\cdots,b_n)$。编写一个函数，将数组中两个顺序表的位置互换，即将$(b_1,b_2,b_3,\cdots,b_n)$放在$(a_1,a_2,a_3,\cdots,a_m)$的前面。

## DeepSeek V4 Flash Max 解析

**答案**：采用“三次逆置”算法：先将整个数组 $A[m+n]$ 逆置，再分别逆置前 $n$ 个元素和后 $m$ 个元素，即可原地将 $(b_1,b_2,\cdots,b_n)$ 移到 $(a_1,a_2,\cdots,a_m)$ 前面。时间复杂度 $O(m+n)$，空间复杂度 $O(1)$。

**解题切入点**：看到“两个连续块整体交换位置”，且要求高效、省空间，应立刻想到“逆置”。逆置一个区间只需要双指针交换，空间为 $O(1)$。这等价于字符串题中“翻转整个句子，再翻转每个单词”的思路：先整体倒序，再把每一块内部倒回来。

**推演**：

设原数组为两个块的拼接：
$$
X=(a_1,a_2,\cdots,a_m),\qquad Y=(b_1,b_2,\cdots,b_n)
$$
原数组为：
$$
XY=(a_1,\cdots,a_m,b_1,\cdots,b_n)
$$

记 $\operatorname{Rev}(S)$ 表示将序列 $S$ 逆置，则逆置满足：
$$
\operatorname{Rev}(PQ)=\operatorname{Rev}(Q)\operatorname{Rev}(P)
$$

三次逆置过程如下：

第一次，逆置整个数组：
$$
XY \xrightarrow{\text{整体逆置}}
\operatorname{Rev}(Y)\operatorname{Rev}(X)
=(b_n,\cdots,b_1,a_m,\cdots,a_1)
$$

第二次，逆置前 $n$ 个元素，即逆置 $\operatorname{Rev}(Y)$：
$$
(b_n,\cdots,b_1,a_m,\cdots,a_1)
\xrightarrow{\text{逆置前 }n\text{ 个}}
(b_1,\cdots,b_n,a_m,\cdots,a_1)
$$

第三次，逆置后 $m$ 个元素，即逆置 $\operatorname{Rev}(X)$：
$$
(b_1,\cdots,b_n,a_m,\cdots,a_1)
\xrightarrow{\text{逆置后 }m\text{ 个}}
(b_1,\cdots,b_n,a_1,\cdots,a_m)
$$

最终得到：
$$
YX=(b_1,b_2,\cdots,b_n,a_1,a_2,\cdots,a_m)
$$

关键代码如下，下标采用 C 语言 0 起始：

```c
void Reverse(ElemType A[], int left, int right) {
    for (int i = left, j = right; i < j; ++i, --j) {
        ElemType tmp = A[i];
        A[i] = A[j];
        A[j] = tmp;
    }
}

void Exchange(ElemType A[], int m, int n) {
    if (m <= 0 || n <= 0) return;
    Reverse(A, 0, m + n - 1);  // 整体逆置
    Reverse(A, 0, n - 1);      // 逆置前 n 个，即 b 块
    Reverse(A, n, m + n - 1);  // 逆置后 m 个，即 a 块
}
```

每次逆置长度为 $L$ 的区间需要 $\lfloor L/2 \rfloor$ 次两两交换，三次逆置共不超过 $m+n$ 次交换，因此时间复杂度为 $O(m+n)$；算法只使用一个临时变量完成交换，空间复杂度为 $O(1)$。

**易错点**：

- 边界下标容易写错：0 起始下标下，前 $n$ 个元素是 $[0,n-1]$，后 $m$ 个元素是 $[n,m+n-1]$，不是 $[0,n]$ 或 $[n+1,m+n]$。若题目或教材采用 1 起始下标，则三次调用应为：
  $$
  \operatorname{Reverse}(A,1,m+n),\quad
  \operatorname{Reverse}(A,1,n),\quad
  \operatorname{Reverse}(A,n+1,m+n)
  $$

- 逆置顺序不能乱：必须“先整体逆置，再分别逆置前 $n$ 个和后 $m$ 个”。如果只逆置前 $m$ 个和后 $n$ 个而不做整体逆置，结果会变成 $(a_m,\cdots,a_1,b_n,\cdots,b_1)$，不符合要求。

- 容易忽略空表情况：若 $m=0$ 或 $n=0$，不需要交换，代码中应加保护，避免无意义或越界的逆置区间。

- 不要申请额外数组：若复制整个数组到辅助空间再写回，虽然可实现，但空间复杂度为 $O(m+n)$，不符合本题常见的“原地高效”要求。

**命题规律**：本题是 408 线性表部分的常考题型，核心考点是“顺序表/数组的原地逆置”和“块交换”。常见变式包括：数组循环左移或右移 $k$ 个位置、将数组中的前 $p$ 个元素与后 $q$ 个元素互换、字符串中单词顺序翻转等。复习时应熟记 `Reverse(A, left, right)` 模板，并养成“先抽象成 $XY \to YX$，再用三次逆置”的解题习惯；答题时务必同时写出算法思想、关键代码、时间复杂度和空间复杂度。

4. 设在一个带表头结点的单链表中,所有结点的元素值无序,试编写一个函数,删除表中所有处于给定的两个值(作为函数参数给出)之间的元素(若存在).

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C02-23-F04_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：以 $low=\min(x,y)$、$high=\max(x,y)$ 为区间，单趟扫描带头结点的单链表，凡满足 $low < p\to data < high$ 的结点均用前驱指针摘除并释放；时间复杂度 $O(n)$、空间复杂度 $O(1)$。（若题意把端点也算作“之间”，把两个不等号改为 $\le$ 即可。）

**解题切入点**：看到“单链表 + 删除”，先抓两个关键：单链表只能向后访问，所以删除一个结点必须知道它的前驱；元素无序，不能利用有序性提前终止，只能完整扫描一遍。可以类比排队检查：要摘掉队伍中某个不合格者，必须先“拉住”他前一个人，让前一个人的指针改指向他的下一个人，然后再继续检查后面的人。

**推演**：

设两个给定值为 $x,y$，先将其归一化为：

$$
low=\min(x,y),\quad high=\max(x,y)
$$

带头结点的单链表结构：

```c
typedef int ElemType;
typedef struct LNode {
    ElemType data;
    struct LNode *next;
} LNode, *LinkList;
```

删除区间内元素的函数如下：

```c
void DeleteBetween(LinkList L, ElemType x, ElemType y) {
    // 统一 low <= high
    if (x > y) {
        ElemType tmp = x;
        x = y;
        y = tmp;
    }

    ElemType low = x, high = y;

    LNode *pre = L;       // 头结点，作为第一个数据结点的前驱
    LNode *p  = L->next;  // 当前待检查结点

    while (p != NULL) {
        if (p->data > low && p->data < high) {
            // 摘除 p
            pre->next = p->next;
            free(p);
            p = pre->next;   // pre 不动，继续检查后继
        } else {
            // p 保留，pre 和 p 同步后移
            pre = p;
            p = p->next;
        }
    }
}
```

正确性说明：

- 算法始终维护 `pre` 是 `p` 的前驱。初始时 `p=L->next`，前驱正是头结点 `L`。
- 当 `p` 需要删除时，令 `pre->next = p->next`，绕过 `p`，再释放 `p`，链表不断。
- 当 `p` 不需要删除时，`pre` 和 `p` 都向后移动一位，保持前驱关系。
- 循环结束时 `p==NULL`，所有满足条件的结点都已被删除，其他结点全部保留。

若题目将“两个值之间”理解为闭区间，即删除满足：

$$
low \le p\to data \le high
$$

则只需把判断条件改为：

```c
if (p->data >= low && p->data <= high)
```

复杂度：

$$
T(n)=O(n),\quad S(n)=O(1)
$$

因为每个结点只被访问一次，且只用了常数个辅助指针。

**易错点**：

- 删除结点后错误移动 `p`：不能在 `free(p)` 后再写 `p = p->next`，应先用 `pre->next = p->next` 保存后继，或先保存 `p->next` 再释放。
- 忘记处理 $x>y$ 的情况。若不交换，可能导致区间为空，一个结点也删不掉。
- 忘记利用头结点。带头结点时 `pre` 初始为 `L`，删除首元结点也不需要单独修改头指针；如果不带头结点，则删除首结点时要特殊处理。
- 端点条件不清。“介于两个值之间”通常按开区间处理，若题目要求含端点，要改为 `>=` 和 `<=`。
- 忽略连续删除的情况。删除一个结点后 `pre` 不能移动，因为下一个结点可能也要删除；若删除后直接让 `pre=p`，会跳过本应检查的结点。
- 边界测试不全。应测试空表、删除第一个数据结点、删除最后一个结点、连续删除多个结点等情况。

**命题规律**：这是 408 线性表部分的经典基础算法题，考查单链表的遍历与前驱指针维护。常见变式有：删除值等于给定值的所有结点、删除值大于/小于给定值的结点、删除区间外的结点、有序链表去重、链表逆置、合并两个有序链表等。复习时应熟练掌握带头结点的单链表操作模板，画图模拟指针变化，尤其注意空表、删头、删尾、连续删除四类边界情况。

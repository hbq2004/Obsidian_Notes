# 综合题 第 13 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-22-F13_题目.png|题目]]

13.【2018 统考真题】给定一个含 $n(n\geq 1)$ 个整数的数组，请设计一个在时间上尽可能高效的算法，找出数组中未出现的最小正整数. 例如，数组 $\{-5, 3, 2, 3\}$ 中未出现的最小正整数是 1；数组 $\{1, 2, 3\}$ 中未出现的最小正整数是 4. 要求：
1) 给出算法的基本设计思想.
2) 根据设计思想，采用 $C$ 或 $C++$ 语言描述算法，关键之处给出注释.
3) 说明你所设计算法的时间复杂度和空间复杂度.

## DeepSeek V4 Flash Max 解析

**答案**：  
采用“原地哈希/桶排序”思想：未出现的最小正整数只可能落在 $[1,n+1]$，因此只需关心数组中的 $1\sim n$。把值 $x$ 放到下标 $x-1$ 处，重排后第一个 $A[i]\ne i+1$ 的位置就对应缺失值 $i+1$；若全部对应，则答案为 $n+1$。时间复杂度 $O(n)$，额外空间 $O(1)$。

**解题切入点**：  
先抓“最小未出现正整数”这个关键：$n$ 个整数最多只能覆盖 $1\sim n$ 这 $n$ 个正整数，所以答案不可能超过 $n+1$。因此数组中的负数、$0$、大于 $n$ 的数都不影响答案。  
这题的模型很像“一个萝卜一个坑”：把正整数 $x$ 放进第 $x-1$ 个坑，最后看哪个坑空着。不要直接排序，排序是 $O(n\log n)$，不够“时间尽可能高效”。

**推演**：

### 1. 核心思想

只需判断 $1,2,\dots,n$ 中哪些数在数组中出现过。  
若 $1\sim n$ 全部出现，则答案就是 $n+1$；否则第一个没出现的正整数一定在 $[1,n]$ 中。

算法分两步：

- **重排**：遍历数组，若当前值 $x$ 满足 $1\le x\le n$，就把它交换到下标 $x-1$ 处，使“值 $x$ 放到位置 $x-1$”。
- **扫描**：重排结束后，若存在 $i$ 使得 $A[i]\ne i+1$，则 $i+1$ 就是未出现的最小正整数；否则返回 $n+1$。

为什么重排时要用 `while`？因为交换后，当前位置 $A[i]$ 会变成一个新的值，这个新值可能仍然需要继续放到它该去的位置，所以必须循环处理。

### 2. C 语言代码

```c
int findMissMin(int A[], int n) {
    int i;

    // 原地重排：把值 x 放到下标 x-1
    for (i = 0; i < n; ++i) {
        while (A[i] >= 1 && A[i] <= n) {   // 只处理可能成为答案的值
            int x = A[i];
            if (A[x - 1] == x) {
                break;                     // x 已在正确位置，或是重复值
            }
            // 交换 A[i] 和 A[x-1]
            int tmp = A[x - 1];
            A[x - 1] = x;
            A[i] = tmp;
        }
    }

    // 扫描第一个“位置与值不对应”的位置
    for (i = 0; i < n; ++i) {
        if (A[i] != i + 1) {
            return i + 1;
        }
    }

    return n + 1;   // 1~n 全部出现
}
```

### 3. 正确性证明

设算法结束时数组为 $A'$。

- 对任意 $k\in[1,n]$，如果 $k$ 在原数组中出现，则算法一定会在某个时刻把 $k$ 放到 $A'[k-1]$。因为每次交换都会把当前值放到它对应的下标位置，而已经放好的正确位置不会被后续交换破坏。
- 因此扫描时若发现 $A'[i]\ne i+1$，说明 $i+1$ 没有出现；而前面 $0\sim i-1$ 位置都已经满足 $A'[j]=j+1$，所以 $1\sim i$ 都已出现。故 $i+1$ 就是最小未出现正整数。
- 若扫描完所有位置都满足 $A'[i]=i+1$，说明 $1\sim n$ 全部出现，最小未出现正整数只能是 $n+1$。

### 4. 复杂度分析

- 时间复杂度： `while` 中每次成功交换都会让至少一个值永久处于正确位置；正确位置总数最多为 $n$，所以总交换次数不超过 $n$。扫描一遍也是 $O(n)$，故总时间复杂度为 $O(n)$。
- 空间复杂度：只使用了若干临时变量，额外空间为 $O(1)$。

**易错点**：

- 没有意识到答案范围是 $[1,n+1]$，把大于 $n$ 的正数也当作有效值处理，导致越界和多余操作。
- 使用 `A[i]` 作为数组下标前忘记判断 $1\le A[i]\le n$。例如 $A[i]=-5$ 或 $A[i]=100$ 时，`A[A[i]-1]` 会越界。
- 只对每个位置交换一次，而没有使用 `while`。例如数组 `[2,3,4,5,1]`，若每个位置只交换一次，最终 $3$ 不能回到正确位置，会误判答案。
- 重复值处理不当。当 `A[x-1] == x` 时应当跳出循环，否则可能原地死循环。
- 返回值写错。答案对应 $i+1$，不是 $i$；全部对应时返回 $n+1$，不是 $0$。

**命题规律**：  
本题考点是“值域与下标对应 + 鸽巢原理”，属于 408 算法设计题中的高频模型。常见变式包括：

- 用辅助计数数组标记 $1\sim n$ 是否出现，时间 $O(n)$、空间 $O(n)$，这是更直观的写法，考试中也常用；
- 不允许修改原数组时，使用辅助数组更稳妥；
- 类似题型还有“找第一个缺失的数”“找重复数”“判断是否为 $1\sim n$ 的排列”等。

复习时要重点掌握：先由元素个数确定答案范围，再设计 $O(n)$ 的桶/标记算法，并且会用“每次交换固定一个正确位置”来说明摊还时间复杂度。

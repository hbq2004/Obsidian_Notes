## DeepSeek V4 Flash Max 解析

**答案**：利用循环双链表可双向访问的特点，从首尾两个方向同时向中间“夹逼”比较数据结点，若所有对应结点值均相等，则链表对称；否则不对称。时间复杂度 $O(n)$，空间复杂度 $O(1)$。

**解题切入点**：先抓住两个关键词：“带头结点”和“循环双链表”。带头结点意味着头结点只是哨兵，真正的数据从 `L->next` 开始，到 `L->prior` 结束；循环双链表则让尾结点可以直接通过 `L->prior` 找到。判断对称本质上就是判断“回文”：左右两个指针向中间移动，逐个比较对应数据，这和数组回文判断的双指针思想完全一致。不要想着先反转链表或开辅助数组，双链表天然支持前驱，直接两端扫描即可。

**推演**：设带头结点的循环双链表为 $L$，头结点不计入数据。令：

- 左指针 $p$ 指向第一个数据结点：$p = L\to\text{next}$；
- 右指针 $q$ 指向最后一个数据结点：$q = L\to\text{prior}$。

每次比较 $p$ 和 $q$ 的数据域：

- 若 `p->data != q->data`，则不对称，直接返回 `false`；
- 若相等，则 $p$ 向后移动，$q$ 向前移动，继续比较。

循环何时结束？需要分情况：

- 若数据结点个数为奇数，最终 $p$ 和 $q$ 会同时指向中间结点，即 $p == q$，此时中间结点不需要与别人比较，所有对应结点已经比较完毕；
- 若数据结点个数为偶数，最终 $p$ 和 $q$ 会“交叉”成为相邻关系，即 $p$ 在 $q$ 的右侧且相邻，对应为 `p->prior == q`，此时所有对应结点也已比较完毕；
- 若链表为空，则 $p = q = L$，同样满足 $p == q$，空表视为对称。

因此循环条件可以写成：

```c
while (p != q && p->prior != q) {
    if (p->data != q->data)
        return false;
    p = p->next;
    q = q->prior;
}
return true;
```

完整代码如下：

```c
typedef struct DNode {
    ElemType data;
    struct DNode *prior, *next;
} DNode, *DLinkList;

bool isSymmetric(DLinkList L) {
    DNode *p = L->next;   // 第一个数据结点
    DNode *q = L->prior;  // 最后一个数据结点

    while (p != q && p->prior != q) {
        if (p->data != q->data)
            return false;
        p = p->next;
        q = q->prior;
    }
    return true;
}
```

正确性证明简述：循环开始前，$p$ 指向左端第一个未比较结点，$q$ 指向右端第一个未比较结点；每比较一对相等结点后，$p$、$q$ 同时向中间移动，因此循环不变量始终成立。若某次比较不相等，则序列不对称。若循环正常结束，要么 $p == q$，说明奇数个结点且中间结点无需配对；要么 `p->prior == q`，说明偶数个结点且所有左右结点对都已比较完毕。因此返回 `true` 当且仅当链表对称。

时间复杂度：每个数据结点最多被比较一次，为 $O(n)$；只用常数个指针变量，空间复杂度 $O(1)$。

**易错点**：

1. **循环结束条件写错**。常见错误是写成 `while (p != q && p->next != q)`。这会在偶数个结点时漏掉中间一对数据的比较。例如 4 个结点时，当 $p$ 指向第 2 个结点、$q$ 指向第 3 个结点时，`p->next == q` 成立，循环提前结束，漏比第 2、3 个结点。正确写法是 `p != q && p->prior != q`，或者等价地写成 `p != q && q->next != p`。

2. **忘记头结点不参与比较**。带头结点链表的数据范围是 `L->next` 到 `L->prior`，不能把头结点也当作数据结点比较。

3. **空表和单结点表处理错误**。空表只有一个头结点，$p$、$q$ 都指向头结点；单结点表 $p$、$q$ 相等。这两种情况都应返回对称，循环条件应能自动处理。

4. **指针移动方向写反**。$p$ 从左向右移动，用 `p = p->next`；$q$ 从右向左移动，用 `q = q->prior`。循环双链表中二者不可混淆。

**命题规律**：本题属于“链表算法设计”中的经典双指针问题，考查循环双链表的基本操作、边界条件分析和算法时间复杂度分析。常见变式包括：判断单链表是否回文（需快慢指针找中点并反转后半部分）、判断双链表是否对称、链表就地逆置、求链表中间结点等。复习时应重点掌握带头结点链表的结构特点，以及对空表、单结点、奇偶长度等边界情况的处理；同时要习惯用“两个指针向中间夹逼”的框架解决对称类问题。

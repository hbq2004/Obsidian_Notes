15.单链表有环,是指单链表的最后一个结点的指针指向了链表中的某个结点 (通常单链表的最后一个结点的指针域是空的)。试编写算法判断单链表是否存在环.
1) 给出算法的基本设计思想。
2) 根据设计思想，采用$C$或$C++$语言描述算法，关键之处给出注释。
3) 说明你所设计算法的时间复杂度和空间复杂度。

## DeepSeek V4 Flash Max 解析

**答案**：采用快慢指针（Floyd 判圈算法）：设置 `slow` 和 `fast` 两个指针，`slow` 每次走 1 步，`fast` 每次走 2 步；若 `fast` 遇到 `NULL`，则无环；若 `slow == fast`，则有环。时间复杂度为 $O(n)$，空间复杂度为 $O(1)$。

**解题切入点**：先抓住“链表有环”的本质：链表没有正常终点，遍历会无限循环。因此不能只靠“走到 `NULL` 判断结束”。可以类比环形跑道上的追及问题：两人同向跑，速度不同，在直道上快者先到终点；在环形跑道上，快者最终会从后面追上慢者。于是想到用“快慢指针”来判断链表是否有环。考点定位在线性表的链表操作、双指针技巧和时空复杂度分析。

**推演**：

设单链表结点结构为：

```c
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;
```

判断链表是否存在环的算法设计思想如下：

1. 设置两个指针 `slow` 和 `fast`，初始都指向链表头结点。
2. 在循环中，`slow` 每次向后移动一个结点，`fast` 每次向后移动两个结点。
3. 如果链表中不存在环，那么 `fast` 一定先遇到空指针 `NULL`，此时返回“无环”。
4. 如果链表中存在环，那么 `fast` 永远不会遇到 `NULL`，并且由于 `fast` 比 `slow` 快，二者在环内一定会相遇。当 `slow == fast` 时返回“有环”。

C 语言代码如下：

```c
int hasCycle(LinkList L) {
    // 空表或只有一个结点且无环，直接返回 0
    if (L == NULL || L->next == NULL)
        return 0;

    LinkList slow = L;   // 慢指针，每次走一步
    LinkList fast = L;   // 快指针，每次走两步

    // 快指针每次要走两步，必须保证 fast 和 fast->next 都不为空
    while (fast != NULL && fast->next != NULL) {
        slow = slow->next;         // 慢指针走一步
        fast = fast->next->next;   // 快指针走两步

        if (slow == fast)          // 相遇，说明链表中有环
            return 1;
    }

    return 0;   // 快指针遇到 NULL，链表正常结束，无环
}
```

算法正确性分析：

- 若无环，链表长度为 $n$。快指针每次走两步，最多经过 $\lceil n/2 \rceil + 1$ 次判断就会遇到 `NULL`，因此时间复杂度为 $O(n)$。
- 若有环，设环外长度为 $m$，环长为 $L$。慢指针最多走 $m$ 步进入环；进入环后，快指针相对于慢指针每轮前进 $1$ 步，因此快指针一定能在不超过 $L$ 步内追上慢指针，所以总步数不超过 $m+L=n$，时间复杂度仍为 $O(n)$。

空间复杂度：只使用了 `slow` 和 `fast` 两个辅助指针，为 $O(1)$。

**易错点**：

- 循环条件不能只写 `fast != NULL`，还必须判断 `fast->next != NULL`，否则执行 `fast->next->next` 时可能访问空指针。
- 必须先移动指针再比较 `slow == fast`。如果一开始就判断，由于初始时 `slow == fast`，会误判为有环。
- 不能试图用“记录访问过的结点”或“给结点加标记”的方法，因为这会额外占用 $O(n)$ 空间，且可能修改链表结构。
- 注意空链表和单结点链表的特殊情况，应直接返回无环；但如果单结点指向自身，则是有环，上述代码仍能正确判断。
- 时间复杂度应写成 $O(n)$，不要误写成 $O(n^2)$。

**命题规律**：本题是“链表”部分的经典算法题，考点是快慢指针（Floyd 判圈算法）。408 中常以综合应用题形式出现，也可能在选择题中考查“能否判断链表有环”或“空间复杂度要求”。常见变式包括：

1. 判断链表是否有环，并找出环的入口结点；
2. 判断两个链表是否相交（可将一个链表首尾相连，转化为判环问题）；
3. 求链表中间结点、倒数第 $k$ 个结点，同样可用快慢指针。

复习时建议熟练掌握快慢指针的证明过程、边界条件处理，并能手写无语法错误的 C/C++ 代码，同时会分析时间复杂度和空间复杂度。

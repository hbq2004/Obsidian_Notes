## DeepSeek V4 Flash Max 解析

**答案**：采用“辅助标记数组 + 前驱指针”单遍扫描单链表；对每个结点按 $|data|$ 查重，首次出现则保留并标记，重复出现则删除。链表扫描/删除部分为 $O(m)$，辅助空间为 $O(n)$；若计入标记数组初始化，严格总时间为 $O(m+n)$。

**解题切入点**：  
本题要“保留第一次出现”，所以不能排序，必须按链表原顺序判断。判断一个绝对值是否出现过，最自然的做法是哈希思想；而题目又给出 $|data|\le n$（按统考原题理解；若只有 $data\le n$，则负数的绝对值上界不明确），所以直接用大小为 $n+1$ 的数组做“哈希表”即可。链表删除必须知道前驱结点，因此还要维护一个前驱指针。

**推演**：

### 1) 基本设计思想

申请辅助数组：
$$
visited[0..n]
$$
其中 $visited[k]=1$ 表示绝对值 $k$ 已经出现过并已被保留，$visited[k]=0$ 表示未出现过。

从链表头开始扫描，设当前结点为 $p$，其前驱为 $pre$。令：
$$
x=|p\to data|
$$

- 若 $visited[x]=0$，说明这是第一个绝对值等于 $x$ 的结点，保留它，并置 $visited[x]=1$；
- 若 $visited[x]=1$，说明前面已经有绝对值等于 $x$ 的结点被保留，删除当前结点 $p$。

因为扫描顺序就是链表原顺序，所以保留下来的结点一定是每个绝对值第一次出现的结点。

例如示例：  
$21,-15,-15,-7,15$  
绝对值 $15$ 第一次出现在 $-15$，因此后面的 $-15$ 和 $15$ 都被删除，结果为 $21,-15,-7$。

### 2) 单链表结点类型定义

```c
typedef struct LNode {
    int data;
    struct LNode *link;
} LNode;
```

### 3) C 语言算法描述

```c
#include <stdlib.h>

typedef struct LNode {
    int data;
    struct LNode *link;
} LNode;

void DeleteAbsDup(LNode *head, int n) {
    // 申请大小为 n+1 的标记数组，初始为 0
    int *visited = (int *)calloc(n + 1, sizeof(int));
    if (visited == NULL) return;

    LNode *pre = NULL;  // 前驱指针
    LNode *p = head;     // 当前结点

    while (p != NULL) {
        // 取绝对值，作为数组下标
        int x = (p->data >= 0) ? p->data : -(p->data);

        if (visited[x] == 0) {
            // 第一次出现，保留
            visited[x] = 1;
            pre = p;
            p = p->link;
        } else {
            // 绝对值已经出现过，删除 p
            LNode *tmp = p;
            pre->link = p->link;  // 跳过 p
            p = p->link;
            free(tmp);
        }
    }

    free(visited);
}
```

说明：在执行 `else` 时，`pre` 一定不为空，因为同一个绝对值第一次出现时已经被保留，所以一定有前驱。

### 4) 正确性简述

扫描到结点 $p$ 时，$visited[x]$ 记录了“绝对值 $x$ 是否已在前面出现过”。  
若为 0，则 $p$ 是绝对值 $x$ 的第一次出现，保留；  
若为 1，则前面已有同绝对值结点被保留，按题意应删除 $p$。  
删除时通过 $pre$ 修改 `link`，链表不断裂。因此算法结束时，每个绝对值只保留第一次出现的结点。

### 5) 复杂度分析

设链表长度为 $m$。每个结点最多被扫描一次，删除操作也是 $O(1)$，所以链表处理部分为：
$$
O(m)
$$

辅助数组大小为 $n+1$，空间复杂度：
$$
O(n)
$$

若严格计入 `calloc` 清零数组的 $O(n)$ 时间，则总时间复杂度为：
$$
O(m+n)
$$

统考常见简写只统计链表扫描部分，也常写为“时间复杂度 $O(m)$，空间复杂度 $O(n)$”。

**易错点**：

1. **忘记取绝对值**：直接使用 `p->data` 作为数组下标，遇到负数会越界。应先计算 $x=|p->data|$。
2. **数组大小开成 $n$**：绝对值最大可以是 $n$，应申请 $n+1$ 个元素，下标范围是 $0\sim n$。
3. **删除后继续访问已释放结点**：不能先 `free(p)` 再 `p=p->link`，应先保存临时指针，或用 `p=pre->link` 更新。
4. **忘记维护前驱指针**：单链表删除必须修改前驱的 `link`，否则链表会断。
5. **辅助数组未初始化**：用 `malloc` 后不初始化，`visited[x]` 是随机值，可能误判。应使用 `calloc` 或 `memset` 清零。

**命题规律**：

本题是 408 线性表链表题的典型考法：**链表操作 + 值域受限 + 空间换时间**。  
看到“$|data|\le n$”这类条件，应立刻想到用数组做哈希标记。  
常见变式有：

- 将“绝对值去重”改为“普通数值去重”；
- 将“保留第一次出现”改为“保留最后一次出现”，可先反转链表，再套用本题算法，最后再反转回来；
- 若没有值域限制，可使用哈希表，期望时间复杂度仍为 $O(m)$，空间 $O(m)$；
- 若要求 $O(1)$ 空间，则往往只能用双重循环，时间复杂度变为 $O(m^2)$。

复习时应熟练掌握“哑结点/前驱指针 + 辅助标记数组”的链表题套路，并注意在代码中体现删除操作和复杂度分析。

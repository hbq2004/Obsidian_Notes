# 选择题 第 21 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-23-M21_题目.png|题目]]

21. 对于一个带头结点的循环单链表$L$，判断该表为空表的条件是( ).
(A). 头结点的指针域为空
(B). $L$的值为$NULL$
(C). 头结点的指针域与$L$的值相等
(D). 头结点的指针域与$L$的地址相等

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C02-23-M21_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 **C**。带头结点的循环单链表为空时，头结点的指针域指向头结点自身，即等价于 `L->next == L`，也就是题干中的“头结点的指针域与 L 的值相等”。

**解题切入点**：拿到题先抓住两个关键词：**带头结点** 和 **循环**。带头结点说明即使表为空，头结点也存在，$L$ 不可能是 `NULL`；循环说明链表中没有空指针，尾结点要么指向头结点，空表时头结点指向自己。所以可以先排除 A、B，再比较 C、D 中对“L 的值”和“L 的地址”的表述差异。

**推演**：

设头指针为 $L$，头结点为 $H$。因为 $L$ 是指向头结点的指针，所以 $L$ 的值就是头结点 $H$ 的地址：

$$
L = \&H
$$

对于带头结点的循环单链表：

- 非空时，尾结点的 `next` 指向头结点 $H$；
- 空表时，没有数据结点，头结点 $H$ 的 `next` 也应指向自身，以维持循环结构：

$$
H\to next = \&H
$$

又因为 $L$ 的值就是 $\&H$，所以：

$$
H\to next = L
$$

在 C 语言风格的代码中即为：

```c
L->next == L
```

选项分析：

- **A**：头结点的指针域为空。这是**普通带头结点单链表**的判空条件，不是循环单链表。
- **B**：$L$ 的值为 `NULL`。这意味着头结点都不存在，不符合“带头结点”的条件。
- **C**：头结点的指针域与 $L$ 的值相等。$L$ 的值就是头结点的地址，正确。
- **D**：头结点的指针域与 $L$ 的地址相等。$L$ 的地址是指针变量自身的地址，即 `&L`，与头结点地址不是一回事。

因此选 **C**。

**易错点**：

1. 误选 A：把循环单链表和普通单链表混淆。普通带头结点单链表判空用 `L->next == NULL`；循环单链表空表时头结点应指向自身。
2. 误选 B：把“带头结点链表为空”理解成“$L$ 为 `NULL`”。事实上带头结点链表的头结点始终存在，$L$ 指向头结点，不会是 `NULL`。
3. 混淆 C 和 D：C 中“$L$ 的值”是头结点的地址；D 中“$L$ 的地址”是指针变量自己的地址。链表结点的 `next` 域存放的是结点地址，所以应比较的是 $L$ 的值，而不是 $\&L$。

**命题规律**：本题属于链表基础结构题，408 常考“带头结点/不带头结点”“循环/非循环”链表中的判空、判尾条件。常见变式有：

- 带头结点循环单链表判尾：`p->next == L`；
- 普通带头结点单链表判空：`L->next == NULL`；
- 不带头结点单链表判空：`L == NULL`。

复习时应画图理解指针指向，并牢记 `L`、`*L`、`&L` 的区别，避免在指针语义上失分。

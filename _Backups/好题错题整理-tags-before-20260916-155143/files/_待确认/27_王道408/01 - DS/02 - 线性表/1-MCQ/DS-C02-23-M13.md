# 选择题 第 13 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-23-M13_题目.png|题目]]

13. 通过含有 $n(n>1)$ 个元素的数组 $a$, 采用头插法建立单链表 $L$, 则 $L$ 中的元素次序 $(\quad)$.
(A) 与数组 $a$ 的元素次序相同
(B) 与数组 $a$ 的元素次序相反
(C) 与数组 $a$ 的元素次序无关
(D) 以上都错误

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C02-23-M13_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 B。采用头插法时，每次新结点都插到链表最前面，因此最终链表中的元素次序与数组 \(a\) 的元素次序相反。

**解题切入点**：先定位考点：单链表的建立方式——头插法。头插法的本质是“后来的元素放到最前面”，类似栈的后进先出；而尾插法才是“先进先出”，保持原次序。做题时画出空链表，逐个插入元素即可快速判断。

**推演**：

设数组元素依次为：

$$
a_0,a_1,\dots,a_{n-1}
$$

按通常顺序从 \(a_0\) 到 \(a_{n-1}\) 依次取元素，用头插法建立带头结点的单链表 \(L\)。

关键代码如下：

```c
L->next = NULL;               // 初始为空表
for (int i = 0; i < n; i++) {
    s = (Node*)malloc(sizeof(Node));
    s->data = a[i];
    s->next = L->next;        // 新结点指向当前首元结点
    L->next = s;              // 头结点指向新结点
}
```

模拟插入过程：

插入 \(a_0\) 后：

$$
L \to a_0 \to \Lambda
$$

插入 \(a_1\) 后：

$$
L \to a_1 \to a_0 \to \Lambda
$$

插入 \(a_2\) 后：

$$
L \to a_2 \to a_1 \to a_0 \to \Lambda
$$

由此归纳，插入完所有元素后：

$$
L \to a_{n-1} \to a_{n-2} \to \cdots \to a_1 \to a_0 \to \Lambda
$$

所以链表从首元结点到尾结点的元素次序为：

$$
a_{n-1},a_{n-2},\dots,a_1,a_0
$$

恰好是数组 \(a\) 的逆序。

因此答案为 B。

**易错点**：

- 容易把“头插法”和“尾插法”混淆。尾插法按顺序插入到链表尾部，最终与数组次序相同；头插法每次都插入头部，最终与数组次序相反。
- 写代码时指针顺序容易错。必须先执行 `s->next = L->next;`，再执行 `L->next = s;`；如果先修改 `L->next`，会丢失原链表。
- 若题目没有特别说明，默认按数组下标从 \(0\) 到 \(n-1\) 的顺序取元素建表。如果改成从数组尾部向前扫描，结论会不同。
- 无头结点时，头插法核心为 `s->next = L; L = s;`，最终结论仍然是逆序。

**命题规律**：本题是数据结构线性表部分的经典选择题，考查头插法对链表元素次序的影响。常见变式有：给出输入序列，要求写出头插法建立链表后的输出序列；比较头插法和尾插法的区别；或者利用头插法实现单链表的原地逆置。复习时建议亲手画 3 个以上结点的建表过程，并牢记“头插逆序、尾插同序”这一结论。

# 选择题 第 7 题

![[_Attachments/题目识别/27_王道408-题目/DS-C02-23-M07_题目.png|题目]]

7. 给定有 $n$ 个元素的一维数组，建立一个有序单链表的最低时间复杂度是 ( ).
(A) $O(1)$
(B) $O(n)$
(C) $O(n^2)$
(D) $O(n\log_2 n)$

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/DS-C02-23-M07_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 D，$O(n\log_2 n)$。核心是先对一维数组进行基于比较的排序，再顺序扫描有序数组，用尾插法建立有序单链表，总时间复杂度为 $O(n\log_2 n)$。

**解题切入点**：  
题目要求建立的是“有序”单链表，而数组未说明已经有序，所以不能只扫描一遍数组。先定位考点：排序的时间下界 + 链表建表操作。单链表不支持随机访问，无法在链表中做二分查找；如果每读入一个数组元素就插入当前有序链表，每次需要顺序查找插入位置，代价很高。  
可以类比：逐个插入有序链表就像在排好的队伍中反复“插队”，每次都要先找到位置；而先把所有人按号排好，再依次牵手串成队，效率最高。

**推演**：  
最优做法分两步。

1. 先用基于比较的排序算法将数组升序排序。  
   例如堆排序、归并排序，最坏时间复杂度为  
   $$
   O(n\log_2 n)
   $$

2. 扫描有序数组，依次创建结点并尾插到单链表中。  
   关键代码思路如下：
   ```
   head = NULL; tail = NULL;
   for i = 0 to n-1:
       p = new Node(A[i]);
       if tail == NULL:
           head = tail = p;
       else:
           tail->next = p;
           tail = p;
   ```
   每个元素尾插耗时 $O(1)$，共 $n$ 个元素，所以建表耗时 $O(n)$。

总时间复杂度：
$$
O(n\log_2 n)+O(n)=O(n\log_2 n)
$$

为什么不能低于 $O(n\log_2 n)$？  
在基于比较的排序模型下，排序 $n$ 个元素的下界是 $O(n\log_2 n)$。如果建立有序单链表能在 $o(n\log_2 n)$ 时间内完成，那么遍历这个有序链表就能在 $O(n)$ 时间内得到有序序列，等价于完成了一次排序，这与比较排序下界矛盾。因此最优复杂度为 $O(n\log_2 n)$。

对比低效做法：若每读一个数组元素就插入当前有序单链表，查找插入位置平均需要 $O(n)$，总时间为 $O(n^2)$，不是最优。

**易错点**：  
- 容易错选 C，$O(n^2)$：这是“边插入边建有序链表”的复杂度，但它不是最低时间复杂度。  
- 容易错选 B，$O(n)$：这是“扫描数组建链表”的复杂度，但只能保持数组原有顺序，不能保证链表按值有序；除非题目明确说明数组已经有序。  
- 容易忽略比较排序下界：未给出元素值域等特殊条件时，不能默认使用计数排序、基数排序做到 $O(n)$。本题按通用比较排序模型处理，应选 D。  
- 若题目额外说明“数组已经有序”，则只需扫描一次建表，选 B；但本题没有该条件。

**命题规律**：  
本题综合考查“排序时间下界”和“链表建表操作”，是 408 复杂度分析常见题型。常见变式有：  
- 给定无序数组，建立有序单链表：$O(n\log_2 n)$；  
- 给定有序数组，建立单链表：$O(n)$；  
- 给定无序单链表，建立有序单链表：可用链表归并排序，$O(n\log_2 n)$；  
- 给定无序数组，建立堆：$O(n)$，因为建堆不要求全局有序。  

复习时应重点理解比较排序下界、数组与链表在随机访问能力上的差异，以及“排序”和“建表”两个阶段是否可以分离。

# FRQ 第 4 题

![[_Attachments/题目识别/WDOS-2027-FRQ/WDOS-2027-FRQ-C03-S02-Q004_题目.png|题目]]

在一个请求分页存储管理系统中,一个作业的页面走向为 $4, 3, 2, 1, 4, 3, 5, 4, 3, 2, 1, 5$, 当分配给作业的物理块数分别为 3 和 4 时,试计算采用下述页面淘汰算法时的缺页率(假设开始执行时主存中没有页面),并比较结果.
$(1)$ 最佳置换算法.
$(2)$ 先进先出置换算法.
$(3)$ 最近最久未使用算法.

## DeepSeek V4 Flash Max 解析
**答案**：
访问串长度 $N=12$，缺页率 $=$ 缺页次数 $/12$。

| 物理块数 $m$ | OPT | FIFO | LRU |
| :-: | :-: | :-: | :-: |
| $3$ | $7$ 次，$7/12\approx 58.33\%$ | $9$ 次，$9/12=75\%$ | $10$ 次，$10/12\approx 83.33\%$ |
| $4$ | $6$ 次，$6/12=50\%$ | $10$ 次，$10/12\approx 83.33\%$ | $8$ 次，$8/12\approx 66.67\%$ |

比较结果：$m=3$ 时本串表现为 OPT $<$ FIFO $<$ LRU；$m=4$ 时表现为 OPT $<$ LRU $<$ FIFO。FIFO 从 $m=3$ 到 $m=4$ 缺页次数由 $9$ 增至 $10$，出现 Belady 异常；OPT 和 LRU 随 $m$ 增大而下降。

**解题切入点**：
把物理块看成容量为 $m$ 的缓存，页面走向看成请求序列。每次访问先判断是否在内存中：命中 $H$，缺页 $F$。缺页时若还有空闲块直接装入；否则按算法淘汰一个页面。

算法竞赛视角：这就是状态机模拟。

- OPT 是离线贪心，需要“向后看”：淘汰下一次使用位置最远的页；以后不再使用的页，下一次使用距离视为 $+\infty$。
- FIFO 就是普通队列：新页入队，淘汰队首；命中时队列不动。
- LRU 是按最近访问时间排序的列表：淘汰最久未使用的页；命中时要“刷新”该页的访问时间。

**推演**：
约定：$F$ 为缺页，$H$ 为命中；初始装入也计缺页。

- **OPT，$m=3$**：
  - 第 $4$ 次访问 $1$ 时，$4$ 下次在第 $5$ 次，$3$ 下次在第 $6$ 次，$2$ 下次在第 $10$ 次，所以淘汰 $2$。
  - 第 $7$ 次访问 $5$ 时，$4$ 下次在第 $8$ 次，$3$ 下次在第 $9$ 次，$1$ 下次在第 $11$ 次，所以淘汰 $1$。
  - 第 $10$ 次访问 $2$ 时，$4,3$ 以后不再用，$5$ 第 $12$ 次还要用，任选一个无未来页淘汰，例如淘汰 $4$。
  - 第 $11$ 次访问 $1$ 时，仍保留第 $12$ 次要用的 $5$，淘汰另一个无未来页，例如淘汰 $3$。
  - 缺页位置：$1,2,3,4,7,10,11$，共 $7$ 次。

- **OPT，$m=4$**：
  - 前 $4$ 次装入 $4,3,2,1$，第 $5,6$ 次命中。
  - 第 $7$ 次访问 $5$ 时，$4,3,2,1$ 下次分别在第 $8,9,10,11$ 次，最远的是 $1$，淘汰 $1$。
  - 第 $8,9,10$ 次命中；第 $11$ 次访问 $1$ 时，$5$ 第 $12$ 次还用，从 $4,3,2$ 中任选淘汰，例如淘汰 $2$，第 $12$ 次命中。
  - 缺页位置：$1,2,3,4,7,11$，共 $6$ 次。

- **FIFO，$m=3$**：
  - FIFO 队列模拟，命中不调整队列。
  - 第 $4,5,6,7$ 次分别淘汰 $4,3,2,1$；第 $8,9$ 次命中；第 $10,11$ 次分别淘汰 $4,3$；第 $12$ 次命中。
  - 缺页位置：$1,2,3,4,5,6,7,10,11$，共 $9$ 次。

- **FIFO，$m=4$**：
  - 第 $5,6$ 次命中但队列不变，所以第 $7$ 次访问 $5$ 时队首仍是 $4$，淘汰 $4$。
  - 随后第 $8\sim 12$ 次访问 $4,3,2,1,5$ 均缺页，分别淘汰 $3,2,1,5,4$。
  - 缺页位置：$1,2,3,4,7,8,9,10,11,12$，共 $10$ 次，出现 Belady 异常。

- **LRU，$m=3$**：
  - 第 $4$ 次访问 $1$ 时淘汰最久未用的 $4$。
  - 第 $5$ 次访问 $4$ 淘汰 $3$；第 $6$ 次访问 $3$ 淘汰 $2$；第 $7$ 次访问 $5$ 淘汰 $1$。
  - 第 $8,9$ 次命中；第 $10$ 次访问 $2$ 淘汰 $5$；第 $11$ 次访问 $1$ 淘汰 $4$；第 $12$ 次访问 $5$ 淘汰 $3$。
  - 缺页位置：$1,2,3,4,5,6,7,10,11,12$，共 $10$ 次。

- **LRU，$m=4$**：
  - 第 $7$ 次访问 $5$ 时，$2$ 最久未用，淘汰 $2$。
  - 第 $8,9$ 次命中；第 $10$ 次访问 $2$ 时淘汰 $1$；第 $11$ 次访问 $1$ 时淘汰 $5$；第 $12$ 次访问 $5$ 时淘汰 $4$。
  - 缺页位置：$1,2,3,4,7,10,11,12$，共 $8$ 次。

**易错点**：
- 初始为空时，前 $m$ 次“装入”也算缺页，不能只把“淘汰后装入”计入缺页。
- FIFO 命中时不能把被访问页面移到队尾；只有缺页淘汰后才把新页面放到队尾。这是 FIFO 和 LRU 的关键区别。
- OPT 看“未来下一次使用距离”，不是看“过去多久没用过”。以后不再使用的页距离是 $+\infty$，应优先淘汰；但若某页马上还要用，不能为了“以后也不用”之外的理由淘汰它。
- FIFO 会出现 Belady 异常：物理块数增加，缺页次数反而增加，不能凭“块越多越好”的直觉判断。
- 本串中 $m=3$ 时 FIFO 缺页比 LRU 少，这只是该引用串上的个案，不能推出 FIFO 整体优于 LRU。

**命题规律**：
408 中页面置换是内存管理部分的常考手算模拟题，通常给一个短页面走向、两三个算法、两个不同物理块数，要求计算缺页率并比较。

本质上就是状态机模拟：状态是当前内存页面集合，加上 FIFO 的队列顺序或 LRU 的时间戳顺序；每次访问是一次转移。竞赛视角下，OPT 类似知道完整询问后的离线贪心，LRU 类似每次命中都要更新优先级的在线策略，FIFO 就是普通队列。

命题人常在两个地方设陷阱：一是 FIFO 命中后队列不更新，二是 FIFO 的 Belady 异常。掌握“按规则逐项模拟，不跳步、不凭直觉”即可稳定得分。

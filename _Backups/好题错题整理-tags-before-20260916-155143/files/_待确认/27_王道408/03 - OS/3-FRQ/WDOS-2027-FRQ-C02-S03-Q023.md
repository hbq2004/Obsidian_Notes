# FRQ 第 23 题

![[_Attachments/题目识别/WDOS-2027-FRQ/WDOS-2027-FRQ-C02-S03-Q023_题目.png|题目]]

有 $n(n \ge 3)$ 名哲学家围坐在一张圆桌边，每名哲学家交替地就餐和思考。在圆桌中心有 $m(m \ge 1)$ 个碗，每两名哲学家之间有一根筷子。每名哲学家必须取到一个碗和两侧的筷子后，才能就餐，进餐完毕，将碗和筷子放回原位，并继续思考。为使尽可能多的哲学家同时就餐，且防止出现死锁现象，请使用信号量的 $P$， $V$ 操作 [$wait()$, $signal()$ 操作] 描述上述过程中的互斥与同步，并说明所用信号量及初值的含义.

## DeepSeek V4 Flash Max 解析
**答案**：  
定义如下信号量并设置初值：  
- 信号量 $bowl$：表示碗的数目，初值 $m$，用于对碗的互斥使用。  
- 信号量 $chopstick[i]$（$i=0,1,\dots,n-1$）：表示第 $i$ 根筷子，初值 $1$，用于对筷子的互斥使用。  
- 信号量 $limit$：用于限制同时就餐的哲学家数量，初值 $n-1$，防止死锁。  

哲学家 $i$ 的进程描述如下（$P$ 即 $wait()$，$V$ 即 $signal()$）：  
```
void philosopher(int i) {
    while (true) {
        think();
        P(limit);                // 申请进入就餐资格
        P(bowl);                 // 取碗
        P(chopstick[i]);         // 取左筷
        P(chopstick[(i+1)%n]);   // 取右筷
        eat();
        V(chopstick[i]);         // 放左筷
        V(chopstick[(i+1)%n]);   // 放右筷
        V(bowl);                 // 放碗
        V(limit);                // 释放就餐资格
    }
}
```

**解题切入点**：  
本题是哲学家就餐问题的变种，在原问题基础上增加了碗这一共享资源，使得哲学家需同时获取两种资源（碗和两侧筷子）才能就餐。从资源分配角度看，每个哲学家需要 $1$ 个碗和 $2$ 根筷子，筷子是相邻互斥的，碗是全局互斥的，这类似于图论中的匹配问题：碗相当于全局资源，筷子相当于边约束，同时就餐的哲学家集合在圆桌上必须是一个独立集（相邻两人不能同时就餐），且人数不超过碗数。因此理论最大同时就餐人数为 $\min(m, \lfloor n/2 \rfloor)$。为防止死锁，需避免循环等待，类比算法竞赛中构造安全序列或设计状态机，我们可以通过限制同时竞争资源的人数来破坏死锁条件，或者采用 AND 型信号量同时申请所有资源。

**推演**：  
首先分析资源需求：每个哲学家需要 $1$ 个碗和 $2$ 根筷子，碗有 $m$ 个，筷子有 $n$ 根（每两哲学家之间一根）。筷子是互斥资源，且由于环形排列，相邻哲学家不能同时使用同一根筷子，所以最多同时就餐人数受限于筷子：$2k \le n$ 且环形排列下最大 $k = \lfloor n/2 \rfloor$。同时受限于碗：$k \le m$，故理论最大并发 $k_{\max} = \min(m, \lfloor n/2 \rfloor)$。我们的目标是设计无死锁方案，且允许达到 $k_{\max}$。  

然后分析死锁原因：若每个哲学家都先拿左筷再拿右筷，当所有哲学家同时拿起左筷时，将无人能拿到右筷，形成死锁。加入碗后，若先拿碗再拿筷子，也可能因筷子死锁。防止死锁的常见方法有：1）限制同时就餐人数不超过 $n-1$，保证至少一根筷子空闲；2）采用 AND 型信号量同时申请所有资源；3）规定拿筷顺序（如奇偶不同）等。  

我们选择方法1），因为它简单且不降低并发度。设置信号量 $limit$ 初值 $n-1$，控制同时进入拿资源的人数。哲学家必须先 $P(limit)$ 获得资格，然后 $P(bowl)$ 取碗，再依次 $P$ 左筷和右筷。由于最多 $n-1$ 人同时竞争筷子，必然有至少一根筷子未被占用，因此不会出现所有哲学家各拿一根筷子等待另一根的局面，从而打破死锁循环。同时，$limit$ 初值 $n-1 \ge \lfloor n/2 \rfloor$，不会限制最大并发；碗信号量 $bowl$ 初值 $m$ 直接限制碗的使用；筷子信号量 $chopstick[i]$ 确保互斥。这样，在 $m$ 和 $n$ 允许下，可实现 $k_{\max}$ 人同时就餐。

**易错点**：  
- 易忽略碗的资源限制，只考虑筷子，导致信号量设置不全。  
- 直接使用 $limit = n$ 或 $limit = m$ 等初值错误：若 $limit$ 初值为 $n$，则可能发生死锁；若 $limit$ 初值小于 $n-1$ 且小于 $k_{\max}$，则会限制并发，达不到“尽可能多”的要求。  
- 拿资源顺序不当：若先拿筷子再拿碗，且 $limit$ 控制，也能避免死锁，但可能造成筷子被占用而碗未拿到，降低效率；但必须确保 $limit$ 的 $P$ 操作在获取任何资源之前，否则可能无法防止死锁。  
- 忘记释放资源：哲学家就餐后需依次释放筷子、碗和 $limit$，顺序与申请相反。  
- 未考虑 $n$ 和 $m$ 的具体关系：若 $m=1$，则同时就餐人数最多 $1$，方案仍需保证无死锁。

**命题规律**：  
本题是经典同步问题“哲学家就餐”的拓展，考察多资源分配下的同步与互斥，以及死锁预防策略。命题人常通过在经典问题中增加资源或改变条件来考查考生对信号量机制的理解和灵活运用能力。解题关键是将问题转化为资源分配模型，确定最大并发量，并选择合适的死锁预防方法（如限制人数、AND 型信号量、资源顺序等）。这类题目在考研 408 中频繁出现，要求考生掌握信号量的定义、P/V 操作的使用，并能分析同步与互斥关系。常见变体包括：增加碗、增加服务员、改变资源请求顺序等。考生应熟练掌握经典解法，并能根据题目条件灵活调整，类似于算法竞赛中经典题目的变体，需要构造出安全且高效的同步方案。

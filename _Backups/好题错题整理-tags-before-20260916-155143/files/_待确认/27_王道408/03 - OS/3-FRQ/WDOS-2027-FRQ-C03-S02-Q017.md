# FRQ 第 17 题

![[_Attachments/题目识别/WDOS-2027-FRQ/WDOS-2027-FRQ-C03-S02-Q017_题目.png|题目]]

17. 某请求分页系统的页面置换策略如下：从 0 时刻开始扫描，每隔 5 个时间单位扫描一轮驻留集（扫描时间忽略不计）且本轮未被访问过的页框将被系统回收，并放入空闲页框链尾，其中内容在下一次分配之前不清空。当发生缺页时，若该页曾被使用过且还在空闲页链表中，则重新放回进程的驻留集中；否则，从空闲页框链表头部取出一个页框。忽略其他进程的影响和系统开销。初始时进程驻留集为空。目前系统空闲页的页框号依次为 32,15,21,41。进程 P 依次访问的 < 虚拟页号, 访问时刻 > 为 $<1,1>$，$<3,2>$，$<0,4>$，$<0,6>$，$<1,11>$，$<0,13>$，$<2,14>$。请回答下列问题：
(1) 当虚拟页为 $<0,4>$ 时，对应的页框号是什么？
(2) 当虚拟页为 $<1,11>$ 时，对应的页框号是什么？说明理由。
(3) 当虚拟页为 $<2,14>$ 时，对应的页框号是什么？说明理由。
(4) 这种方法是否适合于时间局部性好的程序？说明理由.

## DeepSeek V4 Flash Max 解析
**答案**：
(1) 页框号 $21$ 。

(2) 页框号 $32$ 。理由：页 $1$ 在 $t=1$ 时被装入 $32$ 号页框，但 $t=10$ 扫描时它在本轮未被访问，因此 $32$ 被回收并放入空闲链表；$t=11$ 再次访问页 $1$ 时虽然缺页，但页 $1$ 此前使用过且仍在空闲链表中，所以直接将其重新放回驻留集，页框号仍为 $32$ 。

(3) 页框号 $41$ 。理由：到 $t=14$ 时页 $2$ 从未被使用过，也不在空闲链表中，所以只能从空闲链表头部取页框；此时空闲链表头部仍为最初未分配的 $41$（$32,15$ 是回收后放在 $41$ 之后，且 $t=11$ 又摘除了 $32$）。

(4) 适合。时间局部性好的程序意味着刚访问过的页面很可能在不久后再次被访问；该策略在扫描回收后仍保留页框内容，且被回收页面若在空闲链表中被再次访问，可以直接重新放回驻留集，不必从磁盘调入，相当于给被换出页面一个“二次机会”。

**解题切入点**：
把整个过程看成离散事件模拟，而不是一次性计算。每个虚拟页有状态：
$$
\text{未分配} \to \text{驻留} \to \text{空闲待复活} \to \text{驻留}
$$
其中“空闲待复活”就是已经被扫描回收、但内容未清空且仍在空闲链表中的状态。

空闲链表本质上是一个队列：全新分配从头部取，回收时挂到尾部；但“复活”时可以从链表中间摘除对应页框。因此只需维护两个结构：驻留集映射、空闲链表顺序。

**推演**：

| 时刻 | 事件 | 驻留集 | 空闲链表 |
|---|---|---|---|
| 初始 | 尚未访问 | $\varnothing$ | $32\to15\to21\to41$ |
| $t=1$ | 访问页 $1$，缺页，取表头 $32$ | $\{1\to32\}$ | $15\to21\to41$ |
| $t=2$ | 访问页 $3$，缺页，取表头 $15$ | $\{1\to32,3\to15\}$ | $21\to41$ |
| $t=4$ | 访问页 $0$，缺页，取表头 $21$ | $\{1\to32,3\to15,0\to21\}$ | $41$ |
| $t=5$ | 扫描；页 $1,3,0$ 本轮都被访问过，无回收 | 同上 | $41$ |
| $t=6$ | 访问页 $0$，命中 | 同上 | $41$ |
| $t=10$ | 扫描；页 $1,3$ 未被访问，回收 $32,15$ 到链尾 | $\{0\to21\}$ | 头部仍为 $41$，尾部含 $32,15$ |
| $t=11$ | 访问页 $1$，缺页；页 $1$ 在空闲链表中，摘除 $32$ 并放回驻留集 | $\{0\to21,1\to32\}$ | $41\to15$ |
| $t=13$ | 访问页 $0$，命中 | 同上 | $41\to15$ |
| $t=14$ | 访问页 $2$，缺页；页 $2$ 从未使用，不在空闲链表，取表头 $41$ | $\{0\to21,1\to32,2\to41\}$ | $15$ |

所以三个时刻对应的页框号分别是 $21,32,41$。

**易错点**：
- 不要把空闲链表中的页面当成“已经彻底丢失”；本题中页 $1$ 被回收后仍然可以“复活”，这是核心分支。
- 不要忘记扫描发生在 $t=5,10,15$，且 $t=11$ 的访问在 $t=10$ 扫描之后，所以页 $1$ 已经被回收、在空闲链表中。
- 不要误以为 $t=14$ 分配页 $2$ 时会取到 $32$ 或 $15$；$32,15$ 是回收后放到链尾的，$41$ 始终在链头，且 $32$ 又被页 $1$ 复活摘除。
- 策略评价题不要只答“适合”或“不适合”，要抓住“减少磁盘 I/O”这一关键：页框内容未清空，再次访问时可能免于从外存调入。

**命题规律**：
408 对页面置换的考查不局限于 OPT、FIFO、LRU、Clock 的固定推演，而喜欢给出自定义策略，让考生按规则模拟。本质上是一道“状态机 + 队列操作”的模拟题：每次访问先查驻留集，缺页再查空闲链表，周期扫描则按访问情况回收。

这类题要像竞赛中写模拟题一样，不按真实时间逐单位推，而是只处理有事件发生的时间点：访问事件和扫描事件。最后的策略评价题则要围绕局部性与磁盘 I/O 开销展开，尤其是“内容保留在空闲链表中”这一设计。

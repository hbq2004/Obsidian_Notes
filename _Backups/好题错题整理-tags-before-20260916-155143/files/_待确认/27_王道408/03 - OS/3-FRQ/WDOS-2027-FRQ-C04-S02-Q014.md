# FRQ 第 14 题

![[_Attachments/题目识别/WDOS-2027-FRQ/WDOS-2027-FRQ-C04-S02-Q014_题目.png|题目]]

14. 【2018统考真题】某文件系统采用索引结点存放文件的属性和地址信息，簇大小为 $4KB$。每个文件索引结点占 $64B$，有 $11$ 个地址项，其中直接地址项 $8$ 个，一级、二级和三级间接地址项各 $1$ 个，每个地址项长度为 $4B$。请回答下列问题：
(1) 该文件系统能支持的最大文件长度是多少？(给出计算表达式即可)
(2) 文件系统用 $1M(1M=2^{20})$ 个簇存放文件索引结点，用 $512M$ 个簇存放文件数据。若一个图像文件的大小为 $5600B$，则该文件系统最多能存放多少个这样的图像文件？
(3) 若文件 $F1$ 的大小为 $6KB$，文件 $F2$ 的大小为 $40KB$，则该文件系统获取 $F1$ 和 $F2$ 最后一个簇的簇号需要的时间是否相同？为什么？

## DeepSeek V4 Flash Max 解析
**答案**：
(1) 一个簇可放 $4KB/4B=2^{10}$ 个地址项，所以最大文件长度为  
$$L_{\max}=4KB\times(8+2^{10}+2^{20}+2^{30})=2^{15}+2^{22}+2^{32}+2^{42}~B.$$

(2) 最多能存放 $2^{26}=64M$ 个这样的图像文件。

(3) 不同。F1 的最后一个簇号在 inode 的直接地址项中；F2 的最后一个簇号需先读一级间接索引块才能得到，所以 F2 比 F1 多一次磁盘访问。

**解题切入点**：
把多级索引看成“一棵按需展开的树”：inode 是根，直接地址项是直接指向数据簇的指针，一级、二级、三级索引是中间节点。最大文件长度就是这棵树能覆盖的数据簇总数；获取某个簇号，就是求从根到目标叶子的路径深度。第 (2) 问像资源限制下的瓶颈问题：每个文件需要 1 个 inode 和 2 个数据簇，最终数量取两类资源的较小值。第 (3) 问比较的是查找层数，层数越多，磁盘 I/O 越多。

**推演**：
1. 每个簇可放地址项数：
$$n=\frac{4KB}{4B}=2^{10}.$$
直接地址项覆盖 $8$ 个簇；一级间接覆盖 $2^{10}$ 个簇；二级间接覆盖 $2^{10}\times2^{10}=2^{20}$ 个簇；三级间接覆盖 $2^{30}$ 个簇。因此：
$$L_{\max}=(8+2^{10}+2^{20}+2^{30})\times4KB.$$

2. inode 总数为：
$$\frac{2^{20}\times4KB}{64B}=2^{26}.$$
一个 $5600B$ 文件需要 $\lceil5600/4096\rceil=2$ 个数据簇。数据簇总数为 $512M=2^{29}$ 个，按数据簇最多能放 $2^{29}/2=2^{28}$ 个文件；按 inode 最多能放 $2^{26}$ 个文件。取两者较小值，得 $2^{26}$。

3. F1 为 $6KB$，占用 $2$ 个簇，最后一个簇号在 inode 的第 $2$ 个直接地址项中。F2 为 $40KB$，占用 $10$ 个簇；$8$ 个直接地址项覆盖前 $8$ 个簇，剩余 $2$ 个簇需要通过一级间接索引块寻址，最后一个簇号在一级间接索引块的第 $2$ 个表项中。因此 F2 比 F1 多读一个索引块。若 inode 不在内存，则 F1、F2 分别需 $1$ 次、$2$ 次访盘；若 inode 已在内存，则分别需 $0$ 次、$1$ 次访盘，总之时间不同。

**易错点**：
- 不要把间接地址项本身当成只指向 1 个数据簇。一级间接地址项指向的是一个索引块，该块内还能放 $2^{10}$ 个地址。
- 最大长度中不要给二级、三级乘上“2”“3”等层数因子，它们是嵌套关系：二级覆盖 $2^{10}\times2^{10}$ 个数据簇，不是 $2\times2^{10}$。
- $5600B$ 要向上取整为 $2$ 个簇，不能按 $5600/4096$ 的小数值计算。
- 第 (2) 问容易忘记 inode 也是瓶颈；文件数必须同时受 inode 数和数据簇数限制，取 $\min$。
- 第 (3) 问容易误以为 $40KB$ 需要二级间接。直接 $8$ 簇覆盖 $32KB$，一级间接还能覆盖 $4MB$，所以 $40KB$ 只需一级间接。

**命题规律**：
408 中“多级索引 + 磁盘容量/寻址时间”是高频考点，本质是给定“树的分叉数”和“层数”求覆盖范围。解题时先算每层最多能索引多少簇，再逐步展开。该题把容量计算、资源瓶颈和访问次数放在一起，正好对应算法竞赛里的“建树/倍增求覆盖范围、资源限制取瓶颈、BFS/DFS 搜索层数决定代价”。复习时注意与多级页表、磁盘地址转换等题目对比，核心都是“表项大小和块大小决定每层能放多少地址”。

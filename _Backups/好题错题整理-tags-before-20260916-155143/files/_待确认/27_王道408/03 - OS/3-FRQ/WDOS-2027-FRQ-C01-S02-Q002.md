# FRQ 第 2 题

![[_Attachments/题目识别/WDOS-2027-FRQ/WDOS-2027-FRQ-C01-S02-Q002_题目.png|题目]]

2. 设某计算机系统有一个 $CPU$、一台输入设备、一台打印机。现有两个进程同时进入就绪态，且进程 $A$ 先得到 $CPU$ 运行，进程 $B$ 后运行。进程 $A$ 的运行轨迹为: 计算 $50ms$，打印信息 $100ms$，再计算 $50ms$，打印信息 $100ms$，结束。进程 $B$ 的运行轨迹为: 计算 $50ms$，输入数据 $80ms$，再计算 $100ms$，结束。画出它们的甘特图，并说明:
(1) 开始运行后，$CPU$ 有无空闲等待? 若有，在哪段时间内等待? 计算 $CPU$ 的利用率。
(2) 进程 $A$ 运行时有无等待现象? 若有，则在何时发生等待现象?
(3) 进程 $B$ 运行时有无等待现象? 若有，则在何时发生等待现象?

## DeepSeek V4 Flash Max 解析
**答案**：
(1) CPU 有空闲等待，空闲时间段为 $100\text{ms}\sim150\text{ms}$，CPU 利用率 $\displaystyle\frac{250}{300}\approx83.33\%$。  
(2) 进程 $A$ 运行时无等待现象。  
(3) 进程 $B$ 运行时在 $180\text{ms}\sim200\text{ms}$ 等待 CPU。

**解题切入点**：
从多道程序并发执行的角度，将系统资源（CPU、打印机、输入设备）视为互斥访问的临界资源，进程的执行轨迹可看作资源请求序列。本题类似算法竞赛中的“资源分配”问题，需要模拟时间线，确定每个时刻各个资源被哪个进程占用，从而找出进程等待和资源空闲的时间段。可以类比构造辅助函数的思想，将进程状态变化视为状态机，通过时间推进来更新状态。

**推演**：
首先，根据进程 $A$ 和 $B$ 的运行轨迹，列出所有操作的时间长度。设 $t=0$ 时 $A$ 开始运行，$B$ 处于就绪态。模拟过程如下：

- $0\sim50\text{ms}$：$A$ 使用 CPU 计算，$B$ 等待 CPU（就绪）。
- $50\text{ms}$ 时，$A$ 计算完毕，释放 CPU，申请打印机（开始打印）；$B$ 获得 CPU，开始计算。
- $50\sim100\text{ms}$：$A$ 打印（占用打印机），$B$ 计算（占用 CPU），两者并行。
- $100\text{ms}$ 时，$B$ 计算完毕，释放 CPU，申请输入设备（开始输入）；$A$ 仍在打印。
- $100\sim150\text{ms}$：$A$ 打印（占用打印机），$B$ 输入（占用输入设备），CPU 空闲。
- $150\text{ms}$ 时，$A$ 打印完毕，释放打印机，申请 CPU 开始第二次计算；此时 CPU 空闲，$A$ 立即获得 CPU。
- $150\sim180\text{ms}$：$A$ 计算（占用 CPU），$B$ 输入（占用输入设备）。
- $180\text{ms}$ 时，$B$ 输入完毕，释放输入设备，申请 CPU 开始第二次计算；但 CPU 被 $A$ 占用，因此 $B$ 进入等待 CPU 状态。
- $180\sim200\text{ms}$：$A$ 计算，$B$ 等待 CPU。
- $200\text{ms}$ 时，$A$ 计算完毕，释放 CPU，申请打印机开始第二次打印；此时打印机空闲，$A$ 立即获得打印机；同时 CPU 空闲，$B$ 获得 CPU 开始第二次计算。
- $200\sim300\text{ms}$：$A$ 打印（占用打印机），$B$ 计算（占用 CPU）。
- $300\text{ms}$ 时，$A$ 打印结束，$B$ 计算结束，所有进程终止。

根据以上模拟，甘特图如下（时间单位：ms，每个字符块代表 $10\text{ms}$）：

```
时间: 0    50    100   150   200   250   300
进程A: ██████计算███████打印████████████计算████████████打印████████
进程B: ██等待CPU██████计算████████输入██████████等待CPU████████计算████████
CPU:   ██A█████████B████████空闲████████A████████████B████████████████████
```

(1) CPU 空闲时间段为 $100\text{ms}\sim150\text{ms}$，共 $50\text{ms}$。总运行时间 $300\text{ms}$，CPU 忙时间为 $250\text{ms}$，利用率为 $\frac{250}{300}\approx83.33\%$。  
(2) 进程 $A$ 在运行过程中每次申请资源（CPU 或打印机）时，该资源均空闲，故无等待现象。  
(3) 进程 $B$ 在 $180\text{ms}\sim200\text{ms}$ 内因申请 CPU 而等待，故有等待现象。

**易错点**：
- 易将初始时刻 $0\sim50\text{ms}$ 内 $B$ 的就绪等待误计入 $B$ 的“运行时”等待，从而错误回答 $B$ 有等待；但本题中 $B$ 尚未开始运行，故不计入。
- 易忽略 $100\sim150\text{ms}$ 的 CPU 空闲，因为 $A$ 打印和 $B$ 输入同时进行，CPU 未被使用。
- 可能误认为 $A$ 第二次打印时需等待打印机释放，但打印机在此之前已被 $A$ 释放，故无等待。
- 混淆设备是否可并行：打印机和输入设备是不同设备，可同时工作；但同一设备必须互斥。

**命题规律**：
- 常考多道程序并发执行下的甘特图绘制、资源利用率计算、进程等待分析。
- 通过给定进程运行轨迹（计算与 I/O 交替），要求考生模拟系统调度，理解 CPU 与 I/O 设备的并行性。
- 与算法竞赛中“模拟时间线”的题目类似，需要细心维护每个时间点的资源状态。
- 通常以非抢占式调度为背景，进程主动放弃 CPU（如 I/O 请求），强调资源互斥和进程状态转换。

# MCQ 第 10 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C04-S02-Q010-R02_题目.png|题目]]

若用 $8$ 个字(字长 $32$ 位)组成的位示图管理内存,即位示图有 $8$ 行、$32$ 列,行号和列号均从 $1$ 开始,则块号为 $100$ 的内存块所对应位示图的位置是 ( ).
(A) 字号为 $3$,位号为 $5$
(B) 字号为 $4$,位号为 $4$
(C) 字号为 $3$,位号为 $4$
(D) 字号为 $4$,位号为 $5$

## DeepSeek V4 Flash Max 解析
**答案**：D

**解题切入点**：从算法竞赛视角，位示图相当于一个 $8\times 32$ 的二维布尔数组，块号是内存块的线性索引。题目要求将一维块号映射到二维坐标（行号、列号）。在操作系统教材中，块号通常从 $0$ 开始，行号、列号从 $1$ 开始，映射公式为：行号 $= \lfloor \text{块号} / 32 \rfloor + 1$，列号 $= (\text{块号} \bmod 32) + 1$。这类似于在竞赛中，给定一个一维数组下标，将其转换为二维矩阵的行列下标（行列均从 $1$ 开始）。

**推演**：代入块号 $100$ 到公式：行号 $= \lfloor 100 / 32 \rfloor + 1 = 3 + 1 = 4$，列号 $= (100 \bmod 32) + 1 = 4 + 1 = 5$。因此，位示图中字号（行号）为 $4$，位号（列号）为 $5$，对应选项 D。

**易错点**：混淆块号起始编号。若误将块号视为从 $1$ 开始，则公式变为行号 $= \lfloor (100-1)/32 \rfloor +1 = 4$，列号 $= (100-1) \bmod 32 + 1 = 4$，会误选 B。此外，行号、列号是否从 $0$ 开始也是常见陷阱，但题目已明确从 $1$ 开始。算法竞赛中，处理二维数组索引时也需仔细确认起始点，避免 off-by-one 错误。

**命题规律**：位示图是内存管理的基础考点，常以选择题形式考查块号与位置的双向转换。解题本质是除法和取模运算，属于送分题。类似问题在算法竞赛中常见于将一维序列映射到二维网格（如棋盘、图像处理），需注意下标约定。

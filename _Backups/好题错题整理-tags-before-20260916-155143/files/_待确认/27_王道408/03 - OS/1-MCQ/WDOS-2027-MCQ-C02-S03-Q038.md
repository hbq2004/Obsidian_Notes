# MCQ 第 38 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C02-S03-Q038_题目.png|题目]]

在 Peterson 算法中, $turn$ 变量的作用是（ ）.
(A) 表示轮到哪个线程进入临界区
(B) 表示哪个线程先发出访问请求
(C) 表示哪个线程后发出访问请求
(D) 表示哪个线程已进入临界区

## DeepSeek V4 Flash Max 解析
**答案**：
A

**解题切入点**：
Peterson 算法的核心是结合 `flag` 数组与 `turn` 变量实现两个线程的互斥。其中 `turn` 变量扮演了“谦让”的角色，当两个线程同时试图进入临界区时，`turn` 决定了谁能获得访问权。这类似于算法竞赛中“构造题”里设置一个“回合制”的标记，或者像状态机中“当前轮到谁”的状态位，使得竞争条件被优雅地化解。

**推演**：
考虑线程 $i$ 和 $j$（$i \neq j$）的典型代码：
```c
// 线程 i
flag[i] = true;
turn = j;
while (flag[j] && turn == j) {} // 忙等
// 临界区
flag[i] = false;
```
- 当两个线程同时请求时，它们都会将自己的 `flag` 置为 `true`，并设置 `turn` 为对方。由于 `turn` 是共享变量，最后写入的值会覆盖之前的。假设线程 $i$ 最后设置 `turn = j$，则 `turn` 的最终值为 $j$。
- 此时，线程 $i$ 检查 `while (flag[j] && turn == j)` 条件：由于 `flag[j]` 为 `true` 且 `turn == j$，所以线程 $i$ 进入忙等。而线程 $j$ 检查 `while (flag[i] && turn == i)`：因为 `turn == j$ 而不是 $i$，条件不成立，所以线程 $j$ 进入临界区。
- 因此，后设置 `turn` 的线程 $i$ 会谦让，允许对方 $j$ 进入。`turn` 的值实际上指示了“如果两个线程都想进入，那么轮到谁进入”。更准确地说，当 `turn == i$ 时，线程 $i$ 可以进入（因为对方等待），所以 `turn` 表示“轮到哪个线程进入临界区”。

**易错点**：
1. **混淆 `flag` 与 `turn` 的作用**：`flag` 表示线程的“意愿”（是否想进入临界区），而 `turn` 表示“优先权”（当意愿冲突时谁先进入）。不能将 `turn` 理解为进入状态的标记（选项 D 错误）。
2. **误认为 `turn` 记录请求顺序**：`turn` 的值由最后设置它的线程决定，并不反映先来后到（选项 B、C 错误）。实际上，若两个线程先后请求，后请求的线程将 `turn` 设为对方，导致对方先进入，这类似于“后发制人”的谦让策略。

**命题规律**：
Peterson 算法是操作系统中经典的软件互斥方案，常以选择题或简答题形式考查。通常要求理解 `flag` 和 `turn` 各自的作用，以及算法如何满足互斥、前进、有限等待等条件。掌握其核心思想（通过 `turn` 变量打破死锁）即可快速识别正确选项。在算法竞赛背景下，可类比为“双人博弈中的轮流标记”或“状态机中的状态转移变量”，关键在于理解其作为“当且仅当冲突时决定胜者”的语义。

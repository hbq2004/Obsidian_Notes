# MCQ 第 23 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C03-S01-Q023_题目.png|题目]]

为了提高搜索空闲分区的速度，在大、中型系统中往往采用基于索引搜索的动态分区分配算法，以下不属于基于索引搜索的动态分区分配算法的是（ ）

(A) 快速适应算法  
(B) 伙伴系统  
(C) 哈希算法  
(D) 最佳适应算法

## DeepSeek V4 Flash Max 解析
**答案**：D

**解题切入点**：区分动态分区分配算法的分类，特别是基于索引搜索的算法与顺序搜索算法的区别。基于索引搜索的算法通过维护索引结构（如链表、位图、哈希表）快速查找空闲分区，类似于在算法竞赛中用哈希表或平衡树优化查找；而最佳适应算法属于顺序搜索法，需要遍历所有空闲分区，类似暴力枚举。

**推演**：动态分区分配算法中，基于索引搜索的算法包括快速适应算法（Quick Fit）、伙伴系统（Buddy System）和哈希算法（Hash Algorithm）。快速适应算法为每个常用大小维护一个空闲链表，分配时直接索引到对应链表，时间复杂度 $O(1)$；伙伴系统将内存按 $2$ 的幂划分，通过位图和二叉树索引管理空闲块，分配时通过索引快速找到合适大小的块；哈希算法使用哈希表将空闲分区按大小映射，实现快速查找。而最佳适应算法（Best Fit）通常需要扫描整个空闲分区链表或使用有序数据结构（如平衡树）来查找最接近需求大小的空闲分区，但传统实现中属于顺序搜索，不属于基于索引搜索的范畴。因此，不属于基于索引搜索的算法是最佳适应算法。

**易错点**：可能误认为伙伴系统不是基于索引搜索，但伙伴系统通过位图索引实现快速查找，属于索引搜索；也可能混淆快速适应算法与最佳适应算法，快速适应算法是索引搜索，最佳适应算法是顺序搜索。注意题目强调“基于索引搜索”，因此只有顺序搜索的算法才不属于。

**命题规律**：考查动态分区分配算法的分类和特点，特别是对快速适应算法、伙伴系统等基于索引搜索的算法的理解。在操作系统考研中，常将最佳适应算法与基于索引搜索的算法对比，要求考生区分顺序搜索与索引搜索。类似地，在算法竞赛中，将暴力枚举优化为哈希表或平衡树也是常见考点，这里体现的是系统设计中的空间换时间思想。

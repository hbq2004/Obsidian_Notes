# MCQ 第 20 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C03-S02-Q020_题目.png|题目]]

在某分页存储管理的系统中，逻辑地址为 $16$ 位，页面大小为 $1KB$，第 0,1,2,3 号页依次存放在 3,7,11,10 号页框中，则逻辑地址 $0A6FH$ 对应的物理地址为（ ）.
(A) $1E6FH$
(B) $2E6FH$
(C) $DE6FH$
(D) $EE6FH$

## DeepSeek V4 Flash Max 解析
**答案**：
$(B)\ 2E6FH$

**解题切入点**：
分页存储管理的地址转换核心是：逻辑地址 $=$ 页号 $\times$ 页面大小 $+$ 偏移，物理地址 $=$ 页框号 $\times$ 页面大小 $+$ 偏移。解题时先根据页面大小确定页内偏移位数，进而提取页号和偏移，然后查页表得到页框号，最后计算物理地址。该过程相当于算法竞赛中“数组查表 $+$ 位运算”操作，页表视为 $map$ 数组，页号作为下标，页框号作为值，物理地址即为 $map[page\_number] \times PAGE\_SIZE + offset$。

**推演**：
页面大小 $1KB = 2^{10}B$，故偏移占 $10$ 位，逻辑地址 $16$ 位，页号占 $6$ 位。  
逻辑地址 $0A6FH$ 的二进制为 $0000\ 1010\ 0110\ 1111_2$（共 $16$ 位）。  
取高 $6$ 位得页号 $000010_2 = 2$，取低 $10$ 位得偏移 $10\ 0110\ 1111_2 = 0x26F = 623$。  
根据页表，页号 $2$ 对应页框号 $11$（十进制）。  
物理地址 $= 11 \times 1024 + 623 = 11264 + 623 = 11887$。  
转换为十六进制：$11887 \div 16 = 742\cdots15$（$F$），$742 \div 16 = 46\cdots6$，$46 \div 16 = 2\cdots14$（$E$），$2 \div 16 = 0\cdots2$，得 $0x2E6F = 2E6FH$。  
故答案为 $(B)$。

**易错点**：
1. 页号与页框号混淆：页号是逻辑地址中的索引，页框号是物理内存中的块号，不能直接使用页号作为物理地址的高位。  
2. 偏移量提取错误：未根据页面大小正确划分位段，例如误将 $0A6F$ 的高 $8$ 位 $0A$ 当作页号，而实际页面大小 $1KB$ 要求偏移为 $10$ 位，页号仅为 $6$ 位。  
3. 进制转换与进位失误：计算 $11 \times 1024 = 0x2C00$ 加上 $0x26F$ 时，易发生加法错误，如误得 $0xDE6F$ 等。  
4. 忽略逻辑地址位数：$0A6F$ 是 $4$ 位十六进制，需补足 $16$ 位再划分，否则可能漏掉高位零。  
以上错误类似于算法竞赛中“数组下标越界”、“位运算掩码错误”或“十六进制加法疏忽”，需细心检验。

**命题规律**：
分页地址转换是操作系统内存管理的必考基础题，通常以选择题形式出现，考查地址成分提取、页表映射和简单计算。解题关键在于确定页内偏移长度，并正确进行二进制/十六进制运算。该题在408中属于“送分题”，但要求计算准确，类似算法竞赛中的“简单模拟题”，若不注意细节（如进制转换、位运算）则容易失分。掌握此题型后，可进一步学习多级页表、快表等进阶内容。

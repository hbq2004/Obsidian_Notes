# MCQ 第 33 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C03-S01-Q033_题目.png|题目]]

33. 下面的（ ）方法有利于程序的动态链接.
(A) 分段存储管理
(B) 分页存储管理
(C) 可变式分区管理
(D) 固定式分区管理

## DeepSeek V4 Flash Max 解析
**答案**：$\boxed{A}$

**解题切入点**：动态链接要求程序在运行时动态加载并链接模块，因此内存管理需以逻辑单位（段）为基础，支持独立地址空间和动态加载。从算法竞赛角度看，这类似于构造题中按功能模块独立编译，再链接组装。

**推演**：动态链接的关键是模块在运行时加载和链接，需要内存管理提供逻辑分段和独立地址映射。分段存储管理将程序按逻辑分段，每个段有独立基址和界限，通过段表实现地址转换 $\text{物理地址} = \text{段表}[\text{段号}].\text{基址} + \text{段内偏移}$ ，支持模块独立加载和动态链接，如同在竞赛中用多个源文件单独编译后链接。分页存储管理将程序分为固定大小页，页无逻辑意义，页表映射基于页号，不便于模块间符号解析，不利于动态链接。可变式分区和固定式分区只管理内存分配，不涉及程序逻辑结构，无法支持动态链接。因此，有利的是分段存储管理。

**易错点**：易混淆动态链接与动态装入（运行时加载但不链接），或误认为分页管理也能通过虚拟内存实现动态链接。实际上，分页的页是固定大小，无法体现逻辑模块，且页表映射不直接支持符号解析，如同将代码按固定大小切割后无法保持函数完整性。

**命题规律**：考察不同存储管理方式对动态链接的支持，属于基础概念题，常与静态链接、动态装入等对比。理解每种管理方式的特点即可正确作答，如同算法竞赛中根据题目要求选择合适的数据结构或算法。

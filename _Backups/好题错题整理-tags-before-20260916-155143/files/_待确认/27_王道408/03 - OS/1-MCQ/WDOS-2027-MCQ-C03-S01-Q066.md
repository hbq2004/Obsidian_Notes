# MCQ 第 66 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C03-S01-Q066_题目.png|题目]]

66.【2017 统考真题】某计算机按字节编址，其动态分区内存管理采用最佳适应算法，每次分配和回收内存后都对空闲分区链重新排序。当前空闲分区信息如下表所示。

分区始址 $20K$ $500K$ $1000K$ $200K$
分区大小 $40KB$ $80KB$ $100KB$ $200KB$

回收起始地址为 $60K$、大小为 $140KB$ 的分区后，系统中空闲分区的数量、空闲分区链第一个分区的起始地址和大小分别是（ ）
(A) $3$、$20K$、$380KB$
(B) $3$、$500K$、$80KB$
(C) $4$、$20K$、$180KB$
(D) $4$、$500K$、$80KB$

## DeepSeek V4 Flash Max 解析
**答案**：B

**解题切入点**：  
类似算法竞赛中的“区间合并与排序”问题。回收一个分区相当于插入一个区间，并合并相邻空闲区间，然后对所有区间按大小升序排序（即最佳适应策略的排序规则）。如同在 ICPC 中，将区间按长度排序后，第一个元素即为最小长度区间。

**推演**：  
- 当前空闲分区（已按大小升序排列）：  
  - $20K$（$40KB$）  
  - $500K$（$80KB$）  
  - $1000K$（$100KB$）  
  - $200K$（$200KB$）  
- 回收分区：起始地址 $60K$，大小 $140KB$，即区间 $[60K, 200K)$（或 $[60K, 199K]$）。它与前邻 $20K$ 分区（$[20K, 60K)$）和后邻 $200K$ 分区（$[200K, 400K)$）均地址连续，故合并为一个新空闲分区：起始 $20K$，大小 $40+140+200=380KB$，即区间 $[20K, 400K)$。  
- 合并后，空闲分区变为三个：  
  - $20K$（$380KB$）  
  - $500K$（$80KB$）  
  - $1000K$（$100KB$）  
- 按最佳适应算法要求，对空闲分区链按大小递增重新排序，得到：  
  - $500K$（$80KB$）  
  - $1000K$（$100KB$）  
  - $20K$（$380KB$）  
- 所以空闲分区数量为 $3$，链首分区起始地址 $500K$，大小 $80KB$。

**易错点**：  
- 忽略分区合并：只合并一边或认为不合并，导致数量为 $4$（如误以为 $60K$ 与 $20K$ 不连续，或 $200K$ 与 $60K$ 不连续）。注意地址连续判断：$前驱始址+前驱大小 = 回收始址$ 且 $回收始址+回收大小 = 后继始址$，则两边合并。  
- 排序规则混淆：若误用地址排序（首次适应），则链首为 $20K$（$380KB$），误选 $A$。最佳适应核心是“按大小升序”，如同算法竞赛中按权重排序后贪心。

**命题规律**：  
- 动态分区分配回收操作（合并相邻空闲区）是常见考点，结合最佳适应算法的排序规则。通常先回收合并，再排序。类似数据结构中“区间合并”+“自定义排序”。可类比：将空闲分区视为“区间”，回收即“插入区间”并合并，然后按“长度”排序输出第一个。本题难度中等，但需谨慎处理边界。

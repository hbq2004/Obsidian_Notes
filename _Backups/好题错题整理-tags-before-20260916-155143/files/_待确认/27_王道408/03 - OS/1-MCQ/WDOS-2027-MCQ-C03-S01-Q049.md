# MCQ 第 49 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C03-S01-Q049_题目.png|题目]]

49. 在分段存储管理方式中，（ ）
(A) 以段为单位，每段是一个连续存储区
(B) 段与段之间必定不连续
(C) 段与段之间必定连续
(D) 每段是等长的

## DeepSeek V4 Flash Max 解析
**答案**：
A

**解题切入点**：
从分段存储管理的基本定义入手，理解“段”是逻辑上独立的模块，在内存中连续存放，但段与段之间无需连续。这类似于算法竞赛中将复杂问题分解为多个独立子任务，每个子任务对应一个连续代码块，但子任务间的内存布局可以离散，类似于构造题中模块化设计，每个模块内部连续，模块间可任意放置。

**推演**：
- 选项 A：正确。每个段（如代码段、数据段）在内存中是一块连续存储区，对应逻辑上的连续空间。
- 选项 B：错误。段与段之间可能连续（如相邻段正好分配在相邻区域），故“必定不连续”说法绝对。
- 选项 C：错误。段与段之间通常不连续，但也可以连续，故“必定连续”不正确。
- 选项 D：错误。段长度由逻辑模块决定，如主程序段、子程序段长度各异，不固定，类似于算法中不同函数模块的代码长度不同。

类比算法竞赛：每个段 $S_i$ 就像一个连续的子数组，内部地址连续，但不同段之间可以像散列存储的数组块一样离散分布，且长度 $L_i$ 可变，由逻辑结构决定。

**易错点**：
1. 混淆分段与分页：分页是固定大小（页长 $2^k$），分段是可变长度，这是关键区别。
2. 误以为段之间必须连续或不连续，实际是离散存储但允许连续，需注意“必定”等绝对化表述。
3. 忽略段内连续而段间不连续的核心特征，可能误选 B 或 C，就像在算法竞赛中误以为子问题必须连续排列。

**命题规律**：
考查分段存储管理的基本概念，常与分页对比出现。此类题通常要求选择正确描述或区分不同管理方式的特点。掌握“段内连续、段间离散、段长可变”即可快速作答，类似于熟记算法模板中的核心条件。

# MCQ 第 44 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C05-S02-Q044_题目.png|题目]]

44. 【2022 统考真题】下列关于驱动程序的叙述中,不正确的是 ( )

(A) 驱动程序与 $I/O$ 控制方式无关

(B) 初始化设备是由驱动程序控制完成的

(C) 进程在执行驱动程序时可能进入阻塞态

(D) 读/写设备的操作是由驱动程序控制完成的

## DeepSeek V4 Flash Max 解析
**答案**：A

**解题切入点**：从算法竞赛视角看，驱动程序相当于“硬件适配器”，其具体实现依赖于底层 $I/O$ 控制方式（如中断、DMA），类似于编写数据结构时，实现细节依赖于存储方式，但对外接口一致。因此，选项 (A) 声称“驱动程序与 $I/O$ 控制方式无关”明显错误，是本题切入点。

**推演**：逐一分析选项：
- (A) 驱动程序必须根据设备采用的 $I/O$ 控制方式（如程序循环、中断驱动、DMA 等）编写控制逻辑，例如设置中断向量、初始化 DMA 控制器等，故与 $I/O$ 控制方式有关，因此 (A) 不正确。
- (B) 初始化设备（如设置寄存器、启动设备）是驱动程序的基本职责，正确。
- (C) 进程执行驱动程序调用时，若 $I/O$ 操作不能立即完成，进程会进入阻塞态等待（如等待磁盘中断），类似状态机中等待事件，正确。
- (D) 驱动程序负责将读写请求翻译为硬件指令，控制设备完成数据传送，正确。
所以不正确的是 (A)。

**易错点**：易误认为驱动程序是通用的、与硬件无关，但实际驱动程序是硬件相关的，必须与特定 $I/O$ 控制方式匹配。此外，进程在执行驱动程序时可能阻塞，这一点也容易被忽略。

**命题规律**：本题属于操作系统设备管理中的基本概念题，通常以“不正确的是”形式考查对驱动程序职责的理解。类似算法竞赛中的概念判断题，需要准确记忆各模块功能。在 $408$ 统考中，此类题目常出现在选择题中，考生需注意细节辨析。

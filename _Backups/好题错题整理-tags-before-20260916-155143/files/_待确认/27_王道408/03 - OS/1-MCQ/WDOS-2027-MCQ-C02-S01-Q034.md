# MCQ 第 34 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C02-S01-Q034_题目.png|题目]]

34. 下列关于线程的叙述中,正确的是( )

(A) 线程包含 CPU 现场,可以独立执行程序

(B) 每个线程都有自己独立的地址空间

(C) 每个进程只能包含一个线程

(D) 同一进程中的线程间通信也必须使用系统调用函数

## DeepSeek V4 Flash Max 解析
**答案**：  
选 (A)。线程是进程内的一条执行流，包含 $\text{CPU}$ 现场（程序计数器、寄存器组、栈等），可以被独立调度执行。

**解题切入点**：  
核心是区分“资源分配单位”和“调度单位”。进程是资源分配的基本单位，拥有独立地址空间；线程是调度执行的基本单位，共享所属进程的地址空间。类比算法竞赛：进程像一张全局图，线程像在图上的多个并行搜索分支——每个分支有自己的递归栈（$\text{CPU}$ 现场），但共享同一个邻接表（进程地址空间）。因此，凡是说线程有独立地址空间、一个进程只能有一个线程、线程通信必须走系统调用，基本都是错的。

**推演**：  
- (A) 线程由 $\text{TCB}$ 管理，保存 $\text{CPU}$ 现场（寄存器、程序计数器、栈指针），因此可以被调度并独立执行。这就像一轮 DFS 中，每个递归调用都有自己的栈帧和局部变量，切换递归分支时保存当前状态，恢复后继续执行，所以 (A) 正确。  
- (B) 同一进程内的线程共享进程的地址空间，只有各自的栈、寄存器这些运行现场是私有的。若每个线程都有独立地址空间，那它就成了进程而非线程。类比：多个搜索分支共享全局数组，但每个分支有自己的局部变量；不能说每个分支都有独立的全局数组，故 (B) 错误。  
- (C) 一个进程可以创建多个线程，现代操作系统普遍支持多线程进程。这相当于一次搜索任务中允许有多个搜索分支并行推进，而非只允许一条路径，故 (C) 错误。  
- (D) 同进程线程间可以直接通过共享内存读写通信，不需要系统调用；只有跨进程通信或需要内核介入的同步原语才可能用到系统调用。类比：两个搜索分支可以直接修改同一个全局变量，不需要“通知操作系统”来传话，故 (D) 错误。

**易错点**：  
- 误把“线程有独立栈和寄存器”扩大为“线程有独立地址空间”，混淆执行现场与资源所有权。  
- 误以为线程间通信也像进程间通信那样必须使用系统调用，忽略共享地址空间这一核心优势。  
- 对 $\text{CPU}$ 现场理解模糊：线程切换需要保存/恢复现场，但这不意味着线程拥有自己的地址空间。  
- 看到“独立执行程序”时犹豫，其实线程共享代码段，但执行流确实是独立的，这正是“可独立调度”的含义。

**命题规律**：  
- 高频考点为进程与线程的对比：资源分配单位、调度单位、地址空间、通信方式。  
- 正确选项通常落在“线程包含 $\text{CPU}$ 现场、作为独立调度单位”这类描述上；错误项常设为“独立地址空间”“必须使用系统调用”等绝对化表述。  
- 复习时抓两条主线：进程是资源容器，线程是执行流；线程共享进程地址空间，所以通信成本低、切换开销小。遇到此类题，优先排除“独立地址空间”和“必须系统调用”的干扰项。

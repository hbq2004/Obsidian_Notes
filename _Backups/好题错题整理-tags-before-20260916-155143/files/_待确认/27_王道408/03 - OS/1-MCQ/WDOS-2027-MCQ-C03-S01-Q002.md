# MCQ 第 2 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C03-S01-Q002_题目.png|题目]]

下列关于内存保护的描述中,错误的是 ( )
(A) 一个进程不能未被授权就访问另外一个进程的内存空间
(B) 内存保护可以仅通过操作系统(软件)来满足,不需要处理器(硬件)的支持
(C) 内存保护的方法有界地址保护和上下限地址保护
(D) 一个进程不能直接跳转到另一个进程的指令地址中

## DeepSeek V4 Flash Max 解析
**答案**：
$$\boxed{B}$$

**解题切入点**：
核心是区分“操作系统负责管理规则”和“处理器硬件负责在访问现场强制检查”。可以把每个进程的地址空间看作算法竞赛中相互隔离的命名空间；操作系统是出题人，硬件才是运行时真正执行越界检查的判题机。没有硬件保护，只靠软件约定，就像不开 AddressSanitizer 却要求选手自觉不越界，比赛一跑就崩。

**推演**：

- 选项 A：正确。未经授权的进程不能访问另一个进程的内存空间，这正是内存保护的隔离目标。
- 选项 B：错误。内存保护不能仅靠操作系统软件实现。以基址 $+$ 限长方式为例，设基址寄存器为 $B$ ，限长寄存器为 $L$ ，每次访存时硬件必须检查逻辑地址 $A$ 是否满足 $0 \le A < L$ ，满足后才有物理地址 $PA = B + A$ ；若不满足，立即触发越界异常。这个“每次访存都检查”的动作必须由硬件完成，操作系统无法在 CPU 已经发出的访存请求上做实时拦截。
- 选项 C：正确。有界地址保护（基址 $+$ 限长）和上下限地址保护都是经典内存保护方法。上下限方式用两个寄存器保存下界 $D$ 和上界 $U$ ，每次访问内存时硬件检查物理地址 $P$ 是否满足 $D \le P \le U$ ，越界则产生异常。
- 选项 D：正确。每个进程都有独立地址空间；跳转指令只能跳到当前进程地址空间内的目标。跨进程访问或跳转必须通过操作系统提供的受控机制完成，不能直接跳转到另一个进程的指令地址中。

所以错误的是 B。

**易错点**：

1. 把“操作系统可以管理内存保护”误认为“操作系统可以单独实现内存保护”。操作系统只能初始化、切换、保存相关寄存器；真正在每条访存指令路径上做检查的是硬件。
2. 对术语不熟：有界地址保护通常指基址 $+$ 限长寄存器，上下限地址保护则是上界/下界寄存器，二者本质都是边界检查。
3. 误以为选项 D 与共享内存矛盾。共享内存是经过操作系统授权的显式映射，不是“直接跳转”；没有授权时，跨进程跳转和访问都是非法的。
4. 混淆越界与缺页：越界是访问了本进程地址空间之外的非法地址，缺页是合法虚拟页不在内存；二者触发机制不同，但都需要硬件发现、操作系统善后。

**命题规律**：

408 操作系统在内存管理部分很喜欢考“软硬件分工”和“地址保护机制”。看到“仅通过软件”“不需要硬件”“只要操作系统”这类绝对化表述，基本是陷阱。同族考点还包括：

- TLB（快表）是硬件，页表由操作系统维护；
- 地址转换和越界检查由硬件完成；
- 缺页异常由硬件触发、操作系统处理；
- 页式、段式、段页式中的保护位检查也发生在访存通路上。

算法竞赛视角下，可以把硬件理解成评测机的强制 Runtime Error 检测，操作系统只是制定规则；规则再完善，没有强制检测机制，进程照样可以“踩内存”。遇到这种题，优先锁定那些否定硬件作用的选项。

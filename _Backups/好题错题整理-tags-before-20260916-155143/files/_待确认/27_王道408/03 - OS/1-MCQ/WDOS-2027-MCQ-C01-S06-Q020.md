# MCQ 第 20 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C01-S06-Q020_题目.png|题目]]

下列选项中,需要在操作系统进行初始化过程中创建的是 ( ).
(A) 中断向量表
(B) 文件系统的根目录
(C) 硬盘分区表
(D) 文件系统的索引结点表

## DeepSeek V4 Flash Max 解析
**答案**：
A

**解题切入点**：
题眼在“初始化过程中创建”。操作系统初始化是在内存中建立易失性运行结构的过程；而磁盘上持久化的元数据（根目录、inode 表、分区表）早在分区或格式化阶段就创建好了。中断向量表可看成一张“中断号到处理函数入口”的跳转表，属于每次操作系统启动时都必须重建的内存结构。这就像算法竞赛中区分“运行期 `build()` 的动态转移表”和“已经在输入文件里给出的静态图数据”。

**推演**：
- 选项 A：CPU 收到中断后，需要按中断号跳到对应的中断服务程序，等价于维护映射
$$
T[n]=\operatorname{addr}(\operatorname{ISR}_n),\quad n=0,1,\dots,255
$$
操作系统初始化时必须先把这张表填好，否则中断一到就相当于“跳转到未初始化地址”，系统直接崩溃。
- 选项 B、D：文件系统的根目录和索引结点表（inode 表）是磁盘上的元数据。执行格式化（如 `mkfs`）时创建根目录、分配 inode 表并初始化位图；操作系统启动时只是挂载并读取它们，不是再次创建。类比：数据已经持久化在文件里，程序只需读入，而不是每次运行都重新生成。
- 选项 C：硬盘分区表由分区工具写入磁盘固定区域（MBR/GPT），操作系统初始化只能解析它，不能凭空创建。

排除 B、C、D，选 A。

**易错点**：
- 把“启动时需要用到”当成“初始化时需要创建”。根目录、分区表、inode 表启动时都要用，但它们是之前已经持久化好的数据。
- 以为中断向量表由 BIOS 或硬件固化。BIOS 只是在实模式准备临时向量表；操作系统进入保护模式/长模式后要重新建立自己的 IDT/中断向量表。
- 混淆“inode 表”与“单个文件的 inode”。创建文件只是从已有的 inode 表里分配一个表项；整个 inode 表在文件系统创建时建立。
- “操作系统初始化”不等于“把整个计算机的所有数据重新生成一遍”，它只负责内核运行所需的核心内存结构。

**命题规律**：
本题属于操作系统启动/初始化阶段的易混点，命题人常把“内存态控制结构”和“磁盘持久化结构”混排考查。解题时先判断对象存储在哪里：内存中的核心表通常是初始化时创建；磁盘上的元数据通常是分区/格式化时创建。后续可能换成“超级块、页表、PCB、GDT”等同类选项，本质都是生命周期判断题。竞赛角度理解就是：分清“编译期/预处理期确定的静态表”和“运行期必须 `build()` 的动态状态机转移表”，即可快速排除干扰项。

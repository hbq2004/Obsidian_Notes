# MCQ 第 20 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C02-S01-Q020_题目.png|题目]]

20. 进程在处理器上执行时，（）

(A) 进程之间是无关的,具有封闭特性

(B) 进程之间都有交互性,相互依赖、相互制约,具有并发性

(C) 具有并发性,即同时执行的特性

(D) 进程之间可能是无关的,但也可能是有交互性的

## DeepSeek V4 Flash Max 解析
**答案**：D

**解题切入点**：

把“进程集合”看成图的顶点集 $V=\{P_1,P_2,\dots,P_n\}$，进程之间是否有共享资源、通信或同步需求，决定了它们之间有没有“边”。这道题实际上在考“进程之间关系”的判定，而不是在考“并发/并行”的字面定义。每个进程可以看成一个状态机 $M_i$：无关进程的状态转移互不读取对方状态；交互进程的状态转移需要耦合对方状态，就像 DFS/BFS 中从当前状态跳转到邻接状态时，需要维护全局 $visited$ 集合一样。

**推演**：

- 若两个进程无共享数据、无通信，它们就是无关的，图中表现为孤立点。这就像两个互相独立的子问题，可以分开搜索，彼此状态互不可见。
- 若两个进程通过共享内存、信号量、管道或消息队列协作，它们就是有交互性的，图中表现为 $P_i$ 与 $P_j$ 之间有边。它们会相互依赖、相互制约，就像两个并发搜索共享同一个全局状态时，必须处理同步与冲突。
- 因此，进程间关系既不是“全空图”，也不是“完全图”，而是一般图：边集 $E$ 可能为空，也可能非空。所以 D 的“可能……也可能……”才是正确描述。
- 并发性不等于“同时执行”。并发是多个进程在一段时间内交替推进；并行才是多个进程在同一时刻真正同时运行。C 把并发说成“同时执行”，在单 CPU 场景下尤其错误。
- 封闭性是“程序顺序执行”的特征；并发环境下进程执行可能被中断，资源被共享，因此不能说所有进程之间都具有封闭特性。

**易错点**：

- 误选 C：将“并发”与“并行/同时执行”混为一谈。可类比单线程事件循环与多线程并行：一个事件循环只能在时间片上交替处理请求，不是真正同时执行。
- 误选 A：把“封闭性”当成并发进程的普遍性质，实际上封闭性属于顺序执行的前提假设。
- 误选 B：把“交互性”当成所有进程的必然属性；独立进程完全可以并发执行，不需要通信和相互制约。
- 做题时优先警惕绝对化表述：A 的“都无关”、B 的“都有交互性”都只需要举出一个反例即可推翻。

**命题规律**：

408 中这类题常用“绝对化表述”和“概念偷换”制造干扰。A、B 是全称命题，容易通过反例排除；C 是偷换概念，把“并发”偷换成“同时执行”。复习时可以把三组概念做成对比表：

- 顺序执行：封闭、可再现；
- 并发执行：间断、失去封闭、不可再现；
- 并行执行：同一时刻真正同时运行。

做选择题时先找绝对化词和定义偷换词，往往能快速定位正确项。

# MCQ 第 31 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C03-S02-Q031_题目.png|题目]]

下列选项中，( ) 不是页面换进换出效率的影响因素.
(A) 页面置换算法
(B) 已修改页面写回磁盘的频率
(C) 磁盘数据读入内存的频率
(D) CPU 与内存交换的速度

## DeepSeek V4 Flash Max 解析
**答案**：
$\text{(D)}$

**解题切入点**：
页面换进换出效率 实质是 磁盘 $\text{I/O}$ 效率，受置换算法（影响缺页率）、读写频率影响。$\text{CPU}$ 与内存交换速度 属于内存访问范畴，不直接影响磁盘 $\text{I/O}$，故不是影响因素。

**推演**：
- 页面置换算法（A）：不同算法（如 $\text{LRU}$、$\text{FIFO}$）导致缺页率不同，缺页次数越多，换进换出越频繁，效率越低。类比竞赛中解题策略选择，策略优劣直接影响结果时间。
- 已修改页面写回磁盘的频率（B）：写回频率高则写磁盘次数增加，开销大；若采用延迟写回可减少 $\text{I/O}$，但需权衡一致性。类似竞赛中写回缓存策略，同步写入保证数据安全但慢，异步写入快但需注意数据丢失。
- 磁盘数据读入内存的频率（C）：读入频率直接决定 $\text{I/O}$ 负载，频率越高，换进换出开销越大。类比竞赛中数据读取频率，若频繁读取大量数据，则 $\text{I/O}$ 成为瓶颈。
-  $\text{CPU}$ 与内存交换的速度（D）：只影响 $\text{CPU}$ 访问内存的快慢，与页面置换时从磁盘读写数据的过程无关。页面换进换出的瓶颈在磁盘，而非内存总线，如同竞赛中若题目是 $\text{I/O}$ 密集型，则 $\text{CPU}$ 速度再快也无法提升 $\text{I/O}$ 效率。

**易错点**：
易混淆“页面换进换出效率”与“进程内存访问效率”。认为 $\text{CPU}$ 与内存交换速度慢会导致进程等待，从而影响页面置换效率。但页面换进换出特指磁盘与内存之间的页面交换，其效率由磁盘 $\text{I/O}$ 性能主导，内存访问速度仅影响缺页后的处理时间（如更新页表），但整体效率仍由磁盘决定。如同在算法竞赛中，若输入输出是瓶颈，优化计算逻辑无法显著提升整体运行时间。

**命题规律**：
考察对操作系统内存管理页面置换机制的理解，常与计算机组成原理中磁盘 $\text{I/O}$ 性能、内存访问速度概念结合。此类题要求区分不同层次存储系统的速度差异，明确页面换进换出的瓶颈在磁盘 $\text{I/O}$。命题者常设置一个与内存访问相关的干扰项，如 $\text{CPU}$ 与内存交换速度，需考生判断其是否属于页面置换过程。掌握“页面换进换出”涉及磁盘 $\text{I/O}$，而“内存访问”涉及总线，则易答对。

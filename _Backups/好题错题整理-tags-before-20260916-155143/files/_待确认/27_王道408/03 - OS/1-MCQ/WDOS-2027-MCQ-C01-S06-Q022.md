# MCQ 第 22 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C01-S06-Q022_题目.png|题目]]

下列关于虚拟化技术的叙述中，错误的是.
(A) 操作系统可以运行在虚拟机上
(B) 虚拟化技术支持在一台计算机上构建多个虚拟机
(C) 虚拟机监控程序 (VMM) 与操作系统的特权级相同
(D) 虚拟化技术支持在一台计算机上模拟不同的指令集体系结构

## DeepSeek V4 Flash Max 解析
**答案**：  
C。VMM 必须运行在比客户操作系统（Guest OS）更高的特权级，而不是与操作系统“同级”。

**解题切入点**：  
看到“虚拟化”＋“特权级”，本质是在问“谁有资格直接控制硬件、谁只能申请使用硬件”。  
这就像在 ICPC 里，评测系统必须比被评测程序权限更高，才能拦截系统调用、做沙箱隔离；VMM 就是整个虚拟化系统的“评测系统/超管”，必须能拦截 Guest OS 的特权指令。  
所以优先检查特权级描述，C 就是设错点。

**推演**：  
1. 虚拟化 = VMM 把一台物理机抽象成多台虚拟机。每个 Guest OS 以为自己独占硬件，实际上 CPU、内存、I/O 都由 VMM 统一分配。这类似于把一个大问题拆成多个独立子问题，VMM 是全局调度器；也像二分图匹配中，VMM 负责把物理资源匹配给多个虚拟机，不能与被匹配者同层。  
2. 特权级模型为：

$$ \text{VMM 特权级} > \text{Guest OS 特权级} > \text{普通用户程序特权级} $$

经典模型下，VMM 运行在最高特权级，Guest OS 被“降级”到较低特权级；Guest OS 执行特权指令时会陷入 VMM，由 VMM 模拟执行。这就相当于状态机中，Guest OS 的每次特权操作都要经过 VMM 这个唯一合法转移入口。  
3. 若 VMM 与 Guest OS 同级，Guest OS 就能直接执行特权指令、访问真实硬件，虚拟机隔离性立刻失效，因此 C 错。  
4. A、B 是虚拟化的基本能力；D 可通过解释执行或二进制翻译实现跨 ISA 模拟（如 QEMU），也正确。所以错误的是 C。

**易错点**：  
- 误以为 VMM 和操作系统都是“系统软件”，所以特权级相同；实际上关键是“客户操作系统”必须低于 VMM。  
- 把 D 的“模拟不同指令集体系结构”误判为错。广义虚拟化/模拟器可以通过二进制翻译做到跨 ISA 运行。  
- 注意比较对象：C 中的“操作系统”应理解为虚拟机里的 Guest OS，VMM 的特权级高于它，而不是同级。

**命题规律**：  
408 常把虚拟化放在操作系统概述或中断/系统调用附近考查，设错点集中在“特权级”“VMM 职责”“虚拟化与模拟的区别”。复习时抓住分层模型：

$$ \text{VMM} \to \text{Guest OS} \to \text{应用程序} $$

遇到虚拟化题，先圈出“特权级”“VMM”“Guest OS”，基本就能秒杀。

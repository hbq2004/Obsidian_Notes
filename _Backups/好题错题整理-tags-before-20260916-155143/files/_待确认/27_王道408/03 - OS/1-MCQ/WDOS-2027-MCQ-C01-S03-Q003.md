# MCQ 第 3 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C01-S03-Q003_题目.png|题目]]

下列关于系统调用的说法中，正确的是（ ）.
$I$. 用户程序使用系统调用命令，该命令经过编译后形成若干参数和陷入指令
$II$. 用户程序使用系统调用命令，该命令经过编译后形成若干参数和屏蔽中断指令
$III$. 用户程序创建一个新进程,需使用操作系统提供的系统调用接口
$IV$. 当操作系统完成用户请求的系统调用功能后,应使 CPU 从内核态转到用户态
(A) $I$、$III$
(B) $III$、$IV$
(C) $I$、$III$、$IV$
(D) $II$、$III$、$IV$

## DeepSeek V4 Flash Max 解析
**答案**：
$\boxed{\text{C}}$，即 $I$、$III$、$IV$ 正确，$II$ 错误。

**解题切入点**：
系统调用可以理解为 OS 给用户程序提供的“内核 API”。用户态程序不能直接修改 PCB、页表、设备等特权资源，只能像“提交评测请求”一样通过系统调用接口请内核代做；这个请求在指令层面靠陷入指令发起，而不是靠屏蔽中断指令。整个过程是状态机： $\text{用户态}\xrightarrow{\text{陷入指令}}\text{内核态}\xrightarrow{\text{系统调用返回}}\text{用户态}$ 。

**推演**：
- $I$ 正确：用户程序中的系统调用命令编译后，对应为“传参数 + 陷入指令”（访管指令）。执行陷入指令后，CPU 从用户态切换到内核态，进入内核中的系统调用处理程序。
- $II$ 错误：屏蔽中断指令是控制 CPU 是否响应外部中断的特权操作，不是系统调用的入口；用户程序不能通过它来请求 OS 服务。
- $III$ 正确：创建新进程需要内核分配 PCB、初始化地址空间和资源，用户程序只能通过系统调用接口（如 fork）请求 OS 完成，不能在用户态自行“构造”进程对象。
- $IV$ 正确：系统调用处理完成后，OS 要恢复现场并返回，使 CPU 从内核态回到用户态，用户程序才能继续执行。

因此选 $\boxed{\text{C}}$。

**易错点**：
- 将“陷入指令”误记为“屏蔽中断指令”。系统调用需要主动陷入内核，而屏蔽中断会关掉外部中断，二者作用完全不同。
- 忽略 $IV$：系统调用返回时必然伴随 CPU 从内核态回到用户态；这不是进程状态变化，而是 CPU 模式变化。
- 以为用户程序可以自己创建进程或直接操作硬件。从算法竞赛类比：用户程序只是调用方，不能自己修改评测机内核数据结构，必须提交系统调用申请。
- 把系统调用当普通函数调用。普通函数调用不切换 CPU 状态，系统调用会经历用户态 $\to$ 内核态 $\to$ 用户态。

**命题规律**：
408 喜欢将“系统调用、中断/异常、用户态/内核态、特权指令”组合出题。见到“陷入指令/访管指令”视为系统调用的入口；见到“屏蔽中断、直接 I/O、修改页表”等用户态不可执行操作，基本都是干扰项。记牢三拍流程：用户态传参 $\to$ 陷入内核执行服务 $\to$ 返回用户态，即可快速定位答案。

# MCQ 第 16 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C05-S01-Q016_题目.png|题目]]

16. 将系统调用参数翻译成设备操作命令的工作由（ ）完成.
(A) 用户层 $I/O$
(B) 设备无关的操作系统软件
(C) 中断处理
(D) 设备驱动程序

## DeepSeek V4 Flash Max 解析
**答案**：  
D. 设备驱动程序

**解题切入点**：  
题干问“翻译成设备操作命令”的是哪一层。设备操作命令必须知道具体设备控制器的命令寄存器、状态寄存器、数据寄存器，这是典型的“设备相关”信息。像构造题先构造辅助函数一样，先画出 $\text{I/O}$ 软件层次调用链，最靠近控制器、持有设备私有知识的软件层就是设备驱动程序。

**推演**：  
下发命令的主链路为：

$$
\text{用户层 }\text{I/O} \xrightarrow{\text{系统调用}} \text{设备无关 OS 软件} \xrightarrow{\text{抽象 I/O 请求}} \text{设备驱动程序} \xrightarrow{\text{设备操作命令}} \text{设备控制器}
$$

严格说，设备无关 OS 软件先把系统调用参数整理成抽象请求，设备驱动程序再把它翻译成设备控制器能执行的命令。

1. 用户层 $\text{I/O}$ 只负责把编程接口封装成系统调用，类似 `main` 读入参数后调用 `solve()`，不接触硬件。  
2. 设备无关 OS 软件负责设备命名、保护、缓冲、分配与错误报告；它把请求交给正确的驱动程序，但不掌握具体控制器命令。设备分配可类比图论匹配：只决定“谁用哪个资源”，不决定“命令字怎么写”。  
3. 设备驱动程序负责把逻辑读写请求翻译成控制器命令，例如把“读第 $k$ 个逻辑块”写成 $(\text{cmd}=\text{read},\ \text{block}=k,\ \text{buf}=\dots)$。它相当于把算法思路翻译成底层指令。  
4. 中断处理只是设备完成后的异步回调，负责状态更新和进程唤醒，不负责翻译。  

所以答案是设备驱动程序。

**易错点**：  
- 容易误选 B“设备无关 OS 软件”。设备无关软件也做映射或转换，但它是通用逻辑，不知道具体设备控制器寄存器，不能生成设备操作命令。  
- 不能选 C“中断处理”。中断是异步事件处理，不是请求下发时的参数翻译。  
- 用户层 $\text{I/O}$ 即使做了格式化和缓冲，也仍是“调用者”，不是“执行者”。

**命题规律**：  
408 常以“四个 $\text{I/O}$ 软件层次分别负责什么”出题，选项混入中断、DMA、用户层。做题关键是抓“设备相关性”：凡是涉及具体硬件控制、控制器寄存器、设备操作命令，答案基本落在设备驱动程序。复习时可以把 $\text{I/O}$ 过程看成状态机：上层传递状态，驱动执行具体状态转移，中断就像 DFS/BFS 中的回溯与收尾回调。

# MCQ 第 6 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C02-S04-Q006_题目.png|题目]]

死锁的避免是根据 $(\＿\＿)$ 采取措施实现的.
(A) 配置足够的系统资源
(B) 使进程的推进顺序合理
(C) 破坏死锁的四个必要条件之一
(D) 防止系统进入不安全状态

## DeepSeek V4 Flash Max 解析
**答案**：D。死锁的避免不是靠破坏四个必要条件，而是在资源分配时动态判断分配后系统是否仍安全；若会进入不安全状态就拒绝分配。典型算法是银行家算法。

**解题切入点**：
- 区分概念：预防 = 破坏必要条件；避免 = 防止进入不安全状态；检测与解除 = 事后处理。
- 竞赛类比：每次资源申请相当于一次状态转移，先做一次“可完成性 DFS/BFS”，看分配后是否还能到达“所有进程结束”的终态；不能到达就剪枝。
- 题眼是“安全状态 / 安全序列”，要联想到银行家算法。

**推演**：
1. 死锁四个必要条件同时满足才可能死锁：
$$
M \land H \land N \land C \Rightarrow \text{可能发生死锁}
$$
破坏其中一个条件属于预防，因此 C 不是避免。
2. A“配置足够的系统资源”不是通用的 OS 死锁避免手段。
3. B 中“使进程的推进顺序合理”只是在描述安全状态时出现的安全序列 $P_1,P_2,\ldots,P_n$ 的直观说法；银行家算法依据的是“分配后是否存在安全序列 / 是否安全”，即是否防止系统进入不安全状态。
4. 避免算法在每次分配前检查：若分配后系统处于安全状态则分配，否则拒绝。这正好对应 D。

**易错点**：
- 别把 C 当成答案：死锁预防才是破坏必要条件，死锁避免是动态安全检查。
- B 是强干扰项：“安全序列”确实是一种推进顺序，但题目问“避免死锁根据什么措施”，应选“防止系统进入不安全状态”。
- 注意：
$$
\text{死锁状态} \Rightarrow \text{不安全状态},\quad \text{不安全状态} \not\Rightarrow \text{死锁状态}
$$
避免算法要求系统始终处于安全状态，而不是等死锁发生后再解除。

**命题规律**：
408 经常将“预防、避免、检测与解除”放在一起考概念辨析，或者结合银行家算法考安全序列。看到“避免”就锁定“安全状态判断”；看到“破坏四个必要条件”就锁定“预防”；看到“检测/解除”就锁定“事后处理”。复习时把四类方法做成对比表最稳妥。

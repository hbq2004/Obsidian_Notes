# MCQ 第 13 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C02-S01-Q013_题目.png|题目]]

在单处理器系统中，若同时存在 $10$ 个进程，则处于就绪队列中的进程最多有 ( ) 个.
(A) $1$
(B) $8$
(C) $9$
(D) $10$

## DeepSeek V4 Flash Max 解析
**答案**：
C. $9$

**解题切入点**：
在单处理器系统中，CPU 一次只能执行一个进程，故处于运行态的进程最多 $1$ 个。就绪队列中的进程是已经获得除 CPU 外所有资源、等待 CPU 调度的进程。要使就绪队列中进程数最多，应让所有非运行进程都处于就绪态，即没有进程阻塞或挂起，从而得到最多 $9$ 个就绪进程。

**推演**：
总进程数 $N=10$，单处理器下运行态进程数 $R_{\text{run}} \le 1$。若需最大化就绪队列长度 $L_{\text{ready}}$，应令 $R_{\text{run}}=1$ 且其余 $N-1$ 个进程全部就绪（无阻塞/挂起）。故 $L_{\text{ready}} \le N-1 = 9$。这类似于算法竞赛中的“单核任务调度”：一个 CPU 核心同时只能处理一个任务，其余任务在等待队列中排队，最大等待队列长度就是任务总数减去正在执行的任务数（$1$）。若考虑进程状态机（如就绪 $\rightarrow$ 运行 $\rightarrow$ 阻塞），则本题相当于在状态转移图中构造“最多就绪节点数”的极值情形，即运行态固定 $1$ 个，其余节点均标记为就绪态。

**易错点**：
- 误认为 CPU 空闲时所有 $10$ 个进程都可以在就绪队列，却忽略了“就绪队列非空”会立即触发调度，使 CPU 运行一个进程，从而不可能保持 $10$ 个同时就绪。  
- 混淆“就绪”与“阻塞”：若将阻塞进程计入就绪队列，则会低估 $L_{\text{ready}}$ 的最大值；但本题求最大值，应假设无阻塞。  
- 忽略单处理器隐含的“同一时刻最多一个运行进程”这一基本约束。

**命题规律**：
本题是操作系统进程管理中的基础概念题，核心考查单处理器下进程状态与就绪队列的关系。通常以选择题形式出现，分值 $1\sim2$ 分，难度低。类似题目还可能出现“最多有多少个进程处于阻塞态”等变体，掌握“运行态最多 $1$ 个”即可快速求解。在算法竞赛视角下，这类问题相当于“资源分配”中的“单资源互斥”模型，类似于图论匹配中一个资源只能匹配一个任务，剩余任务排队等待。

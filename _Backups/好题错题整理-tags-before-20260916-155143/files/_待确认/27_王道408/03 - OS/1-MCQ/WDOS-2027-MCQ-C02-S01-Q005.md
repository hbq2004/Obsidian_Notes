# MCQ 第 5 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C02-S01-Q005_题目.png|题目]]

5. 下列关于并发进程特性的叙述中,正确的是( )
(A) 进程是一个动态过程,其生命周期是连续的
(B) 并发进程执行完毕后,一定能够得到相同的结果
(C) 并发进程对共享变量的操作结果与执行速度无关
(D) 并发进程的运行结果具有不可再现性.

## DeepSeek V4 Flash Max 解析
**答案**：
D

**解题切入点**：
本题是概念辨析题，核心是“并发使进程失去封闭性，运行结果不确定”。可以把并发执行看成一个状态机：每个进程当前执行到第几条指令是状态，调度器每次选一个进程走一步，相当于 DFS/BFS 搜索所有合法交错路径。算法竞赛里 DFS 顺序通常不影响最终答案，是因为状态转移满足可交换性；并发进程对共享变量的读写不满足可交换性，所以不同调度路径可能得到不同结果。

**推演**：
先看 A：进程确实具有动态性，但并发进程的推进是“执行—暂停—执行”的间断过程，调度、I/O、锁等待都会打断它。因此不能把它描述为连续推进。

再看 B 和 C。共享变量操作往往不是一条不可分割的指令。以 $x=x+1$ 为例，实际可拆为：

\[
P_i:\ \mathrm{LOAD}\ x,\ \mathrm{ADD}\ 1,\ \mathrm{STORE}\ x
\]

假设初值 $x=0$，两个进程各执行一次：

- 串行执行：$P_1$ 完整做完，$P_2$ 再完整做完，结果 $x=2$；
- 交错执行：$P_1$ 先读 $x=0$，$P_2$ 也读 $x=0$，然后 $P_2$ 写 $1$，$P_1$ 也写 $1$，最终 $x=1$。

所以并发进程对共享变量的操作结果与执行速度、相对顺序有关。B 的“一定相同”和 C 的“与速度无关”都错。

D 是教材中并发进程的典型特征：由于失去封闭性，并发进程的运行结果不可再现。这里的“不可再现”不是“每次一定不同”，而是“多次运行不保证相同”。

**易错点**：
- 易误选 A：A 前半句“进程是动态过程”没问题，但后半句“连续”是陷阱。要区分“进程实体一直存在”和“进程在 CPU 上连续执行”；并发特性强调执行具有间断性。
- 易把 B 想成“没有共享变量时结果相同”而犹豫：但题目考查的是并发进程的一般特性，尤其是涉及共享变量时的表现。
- 易把 D 绝对化：不可再现性不等于完全无规律，通过同步机制（信号量、互斥锁）可以把临界区操作约束成原子操作，相当于给并发状态机加限制，使结果可再现。

**命题规律**：
408 操作系统喜欢考顺序程序与并发程序的对比：顺序性、封闭性、可再现性对应间断性、失去封闭性、不可再现性。干扰项常用“一定”“无关”“连续”等绝对化表述来诱导。看到这类词，应回到“异步并发会造成结果不确定”这一主线。算法竞赛视角下：并发无同步就是没有保证可交换性的多路状态搜索；同步机制就是剪枝和约束，保证无论搜索顺序如何，最终结果一致。

# MCQ 第 12 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C02-S01-Q012_题目.png|题目]]

在任何时刻,一个进程的状态变化（\\_）引起另一个进程的状态变化.

(A) $必定$
(B) $一定不$
(C) $不一定$
(D) $不可能$

## DeepSeek V4 Flash Max 解析
**答案**：
C. 不一定

**解题切入点**：
从进程状态转换的触发条件与调度机制切入，类比算法竞赛中的“状态机转移”：一个状态的变化是否必然引起另一个状态变化？取决于转移条件是否满足。在操作系统中，进程状态变化（如运行 $\to$ 阻塞）可能触发 CPU 调度，进而导致另一进程状态变化（如就绪 $\to$ 运行），但这一连锁反应非必然发生，类似于 BFS 中一个节点出队不一定导致邻居入队（若邻居已访问）。

**推演**：
考虑极端情况：
- 单进程系统：唯一进程的状态变化（如运行 $\to$ 终止）不会引起其他进程状态变化，因为没有其他进程。
- 多进程系统：若当前进程从运行变为阻塞，且就绪队列为空，则不会引起任何进程状态变化；若就绪队列非空，则调度器会选择一个进程投入运行，引发其状态从就绪变为运行。
因此，一个进程的状态变化不一定引起另一个进程的状态变化，答案为 $\text{C}$。

**易错点**：
1. 误以为“必定”：忽略了无其他进程或就绪队列为空的情形。
2. 误以为“一定不”或“不可能”：忽略了调度器在进程阻塞或时间片用完时可能切换进程。
3. 类比算法竞赛：若将进程状态视为图节点，状态变化视为边，则“一个变化引起另一个变化”类似于“节点出队必导致邻居入队”，但若无邻居（类似单进程）或邻居已访问（类似就绪队列空），则不会发生。

**命题规律**：
考查对进程状态转换与调度关系的理解，常以选择题形式出现，需要区分“必然”与“可能”。类似题目还涉及“进程状态变化是否一定导致 CPU 切换”等。掌握调度触发条件与进程生命周期即可。

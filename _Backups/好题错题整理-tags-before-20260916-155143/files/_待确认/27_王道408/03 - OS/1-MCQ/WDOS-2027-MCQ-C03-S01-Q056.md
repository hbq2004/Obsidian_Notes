# MCQ 第 56 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C03-S01-Q056_题目.png|题目]]

56. 下列关于分页和分段的描述中,正确的是 ( )
(A) 分段是信息的逻辑单位,段长由系统决定
(B) 引入分段的主要目的是实现离散分配并提高内存利用率
(C) 分页是信息的物理单位,页长由用户决定
(D) 页面在物理内存中只能从页面大小的整数倍地址开始存放

## DeepSeek V4 Flash Max 解析
**答案**：D  
**解题切入点**：分页与分段的核心区别在于单位性质、长度决定者及主要目的。分页是物理单位，页长固定由系统决定，目的为离散分配与利用率，页面必须对齐到页框；分段是逻辑单位，段长可变由用户决定，目的为模块化、共享与保护。  
**推演**：  
- (A) 分段是逻辑单位正确，但段长由用户（程序逻辑）决定，而非系统决定，故错误。  
- (B) 引入分段的主要目的是方便编程、信息共享与保护，而非离散分配和提高利用率（后者是分页的主要目的），故错误。  
- (C) 分页是物理单位正确，但页长由系统决定（通常为 $2^n$ 大小，如 4KB），用户不可决定，故错误。  
- (D) 分页要求页面在物理内存中的起始地址是页面大小的整数倍，即页框对齐，这是硬件地址转换的基础，故正确。  
**易错点**：混淆分页与分段的目的，易误认为分段也以提高利用率为主（实则分段产生外部碎片）；误认为页长可由用户指定（实则系统固定，类似算法竞赛中固定块大小的数组分块）；误认为段长由系统决定（实则由用户逻辑定义，如结构体字段长度）。  
**命题规律**：分页与分段常以对比形式考查概念、目的与特性。命题点集中在单位性质、长度决定者、主要目的、地址对齐方式。需精确记忆，避免张冠李戴。结合算法竞赛背景：分页如同按固定大小 $2^k$ 分块，起始地址为块大小整数倍，可用位运算快速计算物理地址（类似状态压缩中的偏移量）；分段则类似构造结构体，段长由逻辑内容决定，访问时需基址加段内偏移，如同图论中按节点属性分组存储，灵活但需处理碎片。

# MCQ 第 46 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C05-S02-Q046_题目.png|题目]]

当键盘中断服务例程执行结束时，所输入数据的存放位置是( ).
(A) 用户缓冲区
(B) CPU中的通用寄存器
(C) 内核缓冲区
(D) 键盘控制器的数据寄存器

## DeepSeek V4 Flash Max 解析
**答案**：C. 内核缓冲区

**解题切入点**：本题考察键盘中断服务例程执行结束时输入数据的归宿，关键在于区分硬件寄存器、内核缓冲区与用户缓冲区在中断处理流程中的角色。中断服务例程作为生产者，负责从设备读取数据并暂存，供后续消费者使用。

**推演**：键盘中断类似于算法竞赛中的事件驱动模型，中断服务例程（ISR）是事件处理函数。当键盘按下，键盘控制器产生中断，ISR 首先从键盘控制器的数据寄存器（D 选项）读取扫描码，这好比从硬件 FIFO 中弹出一个元素。随后，ISR 将解码后的字符放入内核缓冲区（如 TTY 缓冲区），这是一个共享的环形队列，类似于生产者-消费者模型中的缓冲区。ISR 作为生产者，完成数据入队后结束，此时数据已被移动到内核缓冲区，而用户进程（消费者）通过系统调用（如 `read`）从内核缓冲区拷贝到用户缓冲区（A 选项）。因此，ISR 结束时数据存放在内核缓冲区。

**易错点**：易误选 D（键盘控制器的数据寄存器），但 ISR 已读取数据，寄存器内容被消耗后不再保留，类似忘记清空输入流导致重复读取。易误选 A（用户缓冲区），但 ISR 运行在内核态，无法直接访问用户进程的地址空间，必须通过系统调用在进程上下文完成数据传递，这如同算法竞赛中不同线程不能直接访问对方私有变量，而需通过共享内存（内核缓冲区）通信。

**命题规律**：操作系统 I/O 子系统常考中断处理流程，特别是键盘中断的典型路径（设备寄存器 → 内核缓冲区 → 用户缓冲区）。掌握生产者-消费者模型在中断处理中的应用，以及用户态与内核态的数据隔离机制，是解答此类问题的核心。类似题型还涉及磁盘、网卡等设备的中断处理，本质均为“硬件触发 → 内核暂存 → 用户读取”的流水线模型。

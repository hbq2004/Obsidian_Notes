# MCQ 第 42 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C04-S02-Q042_题目.png|题目]]

42. 在树形目录结构中,文件已被打开后,对文件的访问采用 ( )
(A) 文件符号名
(B) 从根目录开始的路径名
(C) 从当前目录开始的路径名
(D) 文件描述符

## DeepSeek V4 Flash Max 解析
**答案**：$D$ （文件描述符）

**解题切入点**：文件打开后，操作系统会分配一个文件描述符（或文件句柄），后续的读写操作均通过该描述符直接访问文件对象，而不需要再次进行路径解析。这类似于算法竞赛中，对数据进行预处理后，使用索引或指针直接访问，避免重复的搜索开销。

**推演**：在树形目录结构中，文件定位通常需要路径名（绝对或相对），但路径解析涉及目录项的遍历，效率较低。文件打开时，系统在内核中创建文件对象，并返回一个文件描述符，该描述符是一个整数索引，指向进程的文件描述符表，进而指向文件对象。此后，对文件的访问（如读、写、定位）只需提供文件描述符，系统通过该索引快速找到文件对象，无需重新解析路径。这正如在算法竞赛中，我们常通过 DFS/BFS 遍历图并记录节点编号，之后直接使用编号进行状态转移，而不是每次重新搜索节点。

**易错点**：① 混淆“打开前”与“打开后”的访问方式：打开前需通过路径名（符号名或路径）定位，打开后应使用文件描述符。② 误认为打开后仍使用路径名，但路径名每次访问都需要重新解析，效率低且不安全（可能被重命名或删除）。③ 不理解文件描述符的本质是进程-文件映射的索引，而非文件本身。

**命题规律**：操作系统文件管理部分常考文件打开、关闭、读写操作的实现机制，尤其是文件描述符、文件指针、文件表等概念。该题属于基础概念题，通常出现在选择题中，考查对文件访问流程的理解。类似题目可能涉及文件共享、打开文件计数等。

# MCQ 第 11 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C03-S02-Q011_题目.png|题目]]

11. 虚拟地址指的是（ ）

(A) 程序访问内存时使用的地址
(B) 访问内存总线上的地址
(C) 内存与磁盘交换数据时使用的地址
(D) 寄存器的地址

## DeepSeek V4 Flash Max 解析
**答案**：  
A。虚拟地址又称逻辑地址，是程序在指令中直接使用的访存地址；物理地址才是最终送到内存总线的地址。

**解题切入点**：  
把“地址”按流水线分成两个阶段：程序/CPU 发出的是虚拟地址，MMU 完成映射后得到的是物理地址。类比算法竞赛里的“离散化”或“映射”：你在代码里用节点编号 $u$ 去访问图，真正的存储位置是 `head[u]` 或某种哈希槽位；$u$ 是逻辑上的“虚拟”编号，机器实际找的槽位是物理地址。题目问“虚拟地址”就从使用者视角找答案：程序视角的地址，而不是总线视角。

**推演**：  
- 虚拟地址在分页系统中可写成 $VA=(p,d)$，其中 $p$ 是页号，$d$ 是页内偏移。  
- 页表把页号映射成物理页帧号 $f$，地址转换关系为：  
$$
PA=(f,d)=(\text{页表}[p],d)
$$  
所以地址在转换前仍是虚拟地址，转换后才上内存总线。  
- 选项 A 对应“程序访问内存时使用的地址”，即 CPU 发出的逻辑/虚拟地址，正确。  
- 选项 B 是物理地址，因为内存总线上传输的是 MMU 翻译后的实际地址。  
- 选项 C 是磁盘交换区或外存地址，与虚拟地址不在同一地址空间。  
- 选项 D 的寄存器地址只是寄存器编号，不是内存虚拟地址。

**易错点**：  
- 不要把虚拟地址和物理地址混为一谈：程序里打印的指针值通常是虚拟地址，不是内存条上的真实物理地址。  
- 不要认为虚拟地址“只在换入换出时出现”；程序每次访存都先使用虚拟地址，再由 MMU 转换。  
- 不要选 B：地址总线/内存总线上的地址是物理地址，不是虚拟地址。  
- “程序访问内存时使用的地址”不是指“最终地址”，而是指“程序视角/指令中给出的地址”。

**命题规律**：  
408 常以这种“定义辨析”小题考查虚拟存储器基本概念，常与页式存储、段式存储、MMU 地址转换结合。解题关键是从“谁产生、谁使用、谁翻译”判断：程序产生虚拟地址，MMU 翻译，内存接收物理地址。类似算法题中“逻辑节点编号 vs 实际数组下标”的映射关系，看到“总线”“内存条”“物理页框”就想到物理地址；看到“程序/指令/逻辑/虚拟”就想到虚拟地址。

# MCQ 第 15 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C01-S02-Q015_题目.png|题目]]

15. 下列关于操作系统的叙述中，正确的是（ ）
(A) 批处理操作系统必须在响应时间内处理完一个任务
(B) 实时操作系统须在规定时间内处理完来自外部的事件
(C) 分时操作系统必须在周转时间内处理完来自外部的事件
(D) 分时操作系统必须在调度时间内处理完来自外部的事件

## DeepSeek V4 Flash Max 解析
**答案**：
B。

**解题切入点**：
把三种系统看成不同的调度模型：

- 批处理 = 离线批量任务，优化吞吐量，不要求单任务截止时间；
- 分时 = 在线轮转调度，目标是响应时间短，但不是硬 deadline；
- 实时 = 带 deadline 的在线调度，外部事件必须满足  
$$
F_i \le d_i
$$
其中 $F_i$ 是处理完成时刻，$d_i$ 是该事件的截止时刻。

这就像算法竞赛中“必须在 time limit 前 AC，否则 TLE”的硬约束。

**推演**：
逐项判断：

- A 错：批处理系统是“攒一批、跑一批”的离线模式，主要看吞吐量，不承诺在响应时间内完成单个任务。
- B 对：实时系统用 deadline 衡量正确性；外部事件未在规定时间内处理完，相当于功能失败。
- C 错：分时系统关注首次响应时间 $T_{\text{resp}}$，不是周转时间 $T_{\text{turn}}$；它不保证某个外部事件一定在周转时间内处理完。
- D 错：分时系统按时间片 $q$ 轮转；一个事件若在一个时间片内没跑完，会先被切换出去，等下一轮继续，并不是“必须在调度时间内处理完”。

**易错点**：
- 不要把“响应快”当成“保证处理完”。分时系统只是尽快给出首次响应，不承诺一个时间片内完成。
- 区分 $T_{\text{resp}}$ 与 $T_{\text{turn}}$：
$$
T_{\text{resp}} = T_{\text{首次响应}} - T_{\text{提交}},\quad
T_{\text{turn}} = T_{\text{完成}} - T_{\text{提交}}
$$
- 选项中的“必须”是关键词。批处理、分时即使延迟较大也不会立刻判系统错误；只有实时系统把“是否在 deadline 前完成”作为正确性的一部分。

**命题规律**：
- 408 基础概念题常把批处理、分时、实时的指标混在一起考，识别关键词即可：
  - 外部事件 + 规定时间 + 必须处理完 $\to$ 实时；
  - 时间片轮转 + 交互 + 响应时间 $\to$ 分时；
  - 批量 + 吞吐量 + 减少人工干预 $\to$ 批处理。
- 后续变体可能考“硬实时/软实时”或“分时的响应时间指标”，本质仍是看是否存在硬截止时间。

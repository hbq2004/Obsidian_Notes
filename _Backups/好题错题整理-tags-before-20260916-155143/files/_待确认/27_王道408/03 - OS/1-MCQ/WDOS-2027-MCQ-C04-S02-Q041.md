# MCQ 第 41 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C04-S02-Q041_题目.png|题目]]

41. 下列关于文件与文件系统的说法中,错误的是（ ）
$I$.一个文件在同一系统中、不同的存储介质上的复制文件,应采用同一种物理结构
$II$.对一个文件的访问,常由用户访问权限和用户优先级共同限制
$III$.文件系统采用树形目录结构后,对于不同用户的文件,其文件名应该不同
$IV$.为防止系统故障造成系统内文件受损,常采用存取控制矩阵方法保护文件
(A) $II$
(B) $I$、$III$
(C) $I$、$III$、$IV$
(D) 全选

## DeepSeek V4 Flash Max 解析
**答案**：$D$

**解题切入点**：本题类似算法竞赛中的多重约束判断题，需要像验证构造方案合法性一样逐项分析文件系统核心概念。关键点在于理解物理结构、访问控制、目录结构、文件保护各自的适用场景，如同在算法中需要根据不同数据规模选择不同数据结构。

**推演**：
- $I$：不同存储介质（如磁盘、光盘）的物理特性存在差异，文件物理结构需适配介质，正如算法中不会用同一种数据结构处理所有数据规模，故 $I$ 错误。
- $II$：文件访问常由用户权限（读、写、执行）限制，用户优先级主要用于进程调度，不直接参与文件访问控制，故 $II$ 错误。
- $III$：树形目录下不同用户文件可置于不同路径，允许同名文件存在，如同树中不同分支节点可以同名，故 $III$ 错误。
- $IV$：存取控制矩阵用于防止未授权访问，系统故障保护需依靠备份、日志、冗余等机制，而非存取控制矩阵，故 $IV$ 错误。
因此，$I$、$II$、$III$、$IV$ 均错误，应选 $D$。

**易错点**：易误认为 $II$ 正确，将优先级与访问权限混淆；误认为 $IV$ 正确，将存取控制矩阵当成系统故障保护方法。类似在算法竞赛中混淆不同算法的作用（如将排序算法误用于查找）。

**命题规律**：本题属于文件系统基础知识综合题，常以“下列说法中错误的是”形式出现，覆盖物理结构、目录结构、访问控制、保护方法等。备考时需准确记忆各概念定义，注意区分功能，如同区分不同算法适用场景，必要时可结合图论匹配（资源分配）、状态机（访问控制流程）等思想辅助理解。

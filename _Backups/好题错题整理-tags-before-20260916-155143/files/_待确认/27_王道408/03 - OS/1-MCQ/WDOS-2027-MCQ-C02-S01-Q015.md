# MCQ 第 15 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C02-S01-Q015_题目.png|题目]]

系统进程所请求的一次 $I/O$ 操作完成后,将使进程状态从（ ）
(A) 运行态变为就绪态
(B) 运行态变为阻塞态
(C) 就绪态变为运行态
(D) 阻塞态变为就绪态

## DeepSeek V4 Flash Max 解析
**答案**：（D）阻塞态 $\to$ 就绪态

**解题切入点**：抓住“I/O 操作完成”这一事件，即进程等待的 I/O 结束，因此进程从阻塞态被唤醒，进入就绪态等待 CPU 调度。这类似于算法竞赛中，当你发起一个异步读文件操作，数据未到达时线程被挂起（阻塞），数据到达后线程被唤醒进入就绪队列，等待 CPU 执行后续代码。

**推演**：进程三态模型中，运行态进程发出 I/O 请求时，状态从 $运行态$ 变为 $阻塞态$；当 I/O 操作完成时，状态从 $阻塞态$ 变为 $就绪态$。因此本题选 D。状态转换图可视为一个简单状态机，其中 $阻塞态 \to 就绪态$ 是唯一的转移边，触发条件正是 I/O 完成。

**易错点**：易将“I/O 完成”与“I/O 请求”混淆，误选 B（$运行态 \to 阻塞态$）。注意题干中“完成后”三字，明确是事件结束而非开始，对应的是从阻塞态唤醒。

**命题规律**：基础概念题，考查进程三态模型及其转换条件。在 408 真题中常以选择题形式出现，要求考生准确区分不同事件的转换方向。此类题目通常为送分题，但需注意细节，避免因粗心落入“请求”与“完成”的陷阱。

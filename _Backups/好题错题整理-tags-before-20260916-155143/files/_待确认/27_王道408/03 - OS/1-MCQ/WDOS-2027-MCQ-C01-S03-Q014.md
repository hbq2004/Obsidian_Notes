# MCQ 第 14 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C01-S03-Q014_题目.png|题目]]

14. 下列关于系统调用和一般过程调用的说法中,正确的是 ( )

(A) 两者都需要将当前 $CPU$ 中的 $PSW$ 和 $PC$ 的值压栈,以保存现场信息

(B) 系统调用的被调用过程一定运行在内核态

(C) 一般过程调用的被调用过程一定运行在用户态

(D) 两者的调用过程与被调用过程一定都运行在用户态

## DeepSeek V4 Flash Max 解析
**答案**：B  

**解题切入点**：区分系统调用与一般过程调用的本质：是否发生 CPU 状态切换（用户态/内核态）。系统调用由用户程序发起，通过陷阱或中断进入内核，被调用过程在内核态执行；一般过程调用不改变 CPU 状态，调用过程与被调用过程在同一特权级（通常为用户态，但也可能均为内核态，故“一定在用户态”错误）。同时，系统调用因涉及状态切换，硬件自动保存 $\mathrm{PSW}$ 和 $\mathrm{PC}$ 等现场信息；而一般过程调用只需保存 $\mathrm{PC}$（返回地址），通常不涉及 $\mathrm{PSW}$。  

**推演**：分析每个选项：  
- (A) 一般过程调用只需保存 $\mathrm{PC}$ 即可，无需保存 $\mathrm{PSW}$（程序状态字），故错误。  
- (B) 系统调用通过陷阱或中断进入内核，被调用过程执行内核代码，一定运行在内核态，正确。  
- (C) 一般过程调用若发生在内核态（如内核内部函数调用），被调用过程也在内核态，并非一定在用户态，故错误。  
- (D) 系统调用的调用过程在用户态，被调用过程在内核态，故错误。  

**易错点**：误认为一般过程调用一定在用户态，忽略内核中也有函数调用；或混淆系统调用与一般过程调用现场保存的差异（$\mathrm{PSW}$ 是否保存）。算法竞赛类比：系统调用如同使用 `#include <sys/types.h>` 中的系统级函数，需要切换到内核态执行，类似竞赛中调用底层 API 进行权限操作；一般过程调用如同自定义函数，仅在当前状态内部流转。  

**命题规律**：常考状态切换、特权级、现场保存等核心区别，常以选择题形式考查概念辨析。结合算法竞赛思想：可视为“状态机”模型——系统调用引发状态从用户态跳转到内核态（类似 DFS 中的递归进入深层），而一般过程调用不改变状态（如同同一层循环内的函数调用）。注意区分硬件自动保存的现场信息（$\mathrm{PSW}$、$\mathrm{PC}$）与软件保存的寄存器。

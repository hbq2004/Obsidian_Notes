# MCQ 第 15 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C03-S02-Q015_题目.png|题目]]

15. 下面关于请求页式系统的页面调度算法中,说法错误的是（ ）

A. 一个好的页面调度算法应减少和避免抖动现象

B. $FIFO$ 算法实现简单,选择最先进入主存储器的页面调出

C. $LRU$ 算法基于局部性原理,首先调出最近一段时间内最长时间未被访问过的页面

D. $CLOCK$ 算法首先调出一段时间内被访问次数多的页面

## DeepSeek V4 Flash Max 解析
**答案**：
D。

**解题切入点**：
页面调度算法本质上就是“缓存淘汰策略”。先想清楚每个算法维护的“键”是什么：

- FIFO 看进入主存的时间；
- LRU 看最近一次被访问的时间；
- CLOCK 看访问位 $A \in \{0,1\}$ ；
- LFU 看访问次数。

选项 D 把 CLOCK 描述成“访问次数多则先淘汰”，这实际是把 LFU 的计数思想嫁接到 CLOCK 上。CLOCK 只维护 1 位访问状态，类似竞赛中“环形队列 + 状态翻转”，而不是“计数器 + 堆/排序”。

**推演**：

- A 正确：好的页面调度算法应降低缺页率。抖动是缺页频繁、系统大量时间用于换页的现象，好的算法能减少缺页，从而减少和避免抖动。

- B 正确：FIFO 就是维护一个先进先出队列，最先进入主存的页面在队首，缺页时淘汰队首，实现简单。

- C 正确：LRU 利用局部性原理，按“最近访问时间”排序，淘汰最长时间未被访问过的页面。

- D 错误：CLOCK 算法沿环形队列扫描访问位：

$$
\begin{aligned}
&\text{若 } A=1:\quad A\leftarrow 0,\ \text{指针后移，继续扫描}\\
&\text{若 } A=0:\quad \text{淘汰当前页}
\end{aligned}
$$

所以 CLOCK 首先调出的是“最近未被访问过”的页，而不是“一段时间内被访问次数多”的页。被访问次数多的页通常 $A=1$ ，扫描时会获得“第二次机会”，不会被首先调出。CLOCK 并不统计访问次数。

**易错点**：

- 容易把 CLOCK 和 LFU 混淆。LFU 用计数器统计访问频率，CLOCK 只用访问位 $A$ 判断“最近是否被访问过”。
- 选项 A 中的“避免抖动”容易被误判为绝对化表述，但教材语境下确实把“减少和避免抖动”作为好页面调度算法的目标。
- CLOCK 只是 LRU 的近似实现，不是精确 LRU；精确 LRU 需要记录所有页的最近访问时间。
- 改进型 CLOCK 还引入修改位 $M$ ，优先淘汰 $(A,M)=(0,0)$ 的页面，但依然不按访问次数淘汰。

**命题规律**：

408 常把 FIFO、LRU、CLOCK、LFU 放在一起做概念辨析，干扰项往往故意混用“进入时间”“最近访问时间”“访问次数”“访问位”。复习时要能手算模拟：

- FIFO：队列；
- LRU：栈或时间戳；
- CLOCK：环形指针 + 访问位；
- 改进型 CLOCK：$(A,M)$ 四级顺序 $(0,0)\rightarrow(0,1)\rightarrow(1,0)\rightarrow(1,1)$ 。

见到“访问次数”应优先想到 LFU/MFU，而不是 CLOCK；见到“访问位”优先想到 CLOCK。这类题和竞赛中的“状态维护方式识别”一样，先确定每个算法维护了什么状态，再判断选项。

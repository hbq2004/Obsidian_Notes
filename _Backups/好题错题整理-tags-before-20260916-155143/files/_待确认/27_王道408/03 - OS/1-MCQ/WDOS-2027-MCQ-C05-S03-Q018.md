# MCQ 第 18 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C05-S03-Q018_题目.png|题目]]

设磁盘的转速为 3000 转/分,盘面划分为 10 个扇区,则读取一个扇区的时间为 ( ).
(A) $20ms$
(B) $5ms$
(C) $2ms$
(D) $1ms$

## DeepSeek V4 Flash Max 解析
**答案**： (C) $2ms$

**解题切入点**： 读取一个扇区的时间实质是扇区通过磁头的时间，即传输时间。已知磁盘转速和每磁道扇区数，可计算旋转一圈的时间，再除以扇区数即得。

**推演**： 转速 $3000\ \text{转/分}$ 转换为每转时间 $T = \frac{60\ \text{s}}{3000} = 0.02\ \text{s} = 20\ \text{ms}$。盘面划分为 $10$ 个扇区，每个扇区占 $1/10$ 圈，故读取一个扇区的时间 $t = \frac{T}{10} = \frac{20\ \text{ms}}{10} = 2\ \text{ms}$。类似算法竞赛中，将一圈视为总资源，扇区数即等分数量，传输时间即单份资源占用时间。

**易错点**： 易混淆为平均旋转延迟（半圈时间 $10\ \text{ms}$）或一圈时间 $20\ \text{ms}$。注意题目明确“读取一个扇区”指数据从盘面读出过程，不包含寻道和等待旋转的额外延迟。

**命题规律**： 磁盘读写时间计算是操作系统 I/O 子系统常考基础题，常与转速、扇区数、寻道时间等结合。本题仅考查传输时间，属简单送分题，但需看清题干是否含“平均”二字以区分旋转延迟。

# MCQ 第 52 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C03-S02-Q052_题目.png|题目]]

某进程访问页面的序列如下所示 [注意：抖动和工作集已从最新大纲中删除]。..., 1, 3, 4, 5, 6, 0, 3, 2, 3, 2, | 0, 4, 0, 3, 2, 9, 2, 1, ... 若工作集的窗口大小为 6, 则在 $t$ 时刻的工作集为（ ）.
(A) $\{6,0,3,2\}$
(B) $\{2,3,0,4\}$
(C) $\{0,4,3,2,9\}$
(D) $\{4,5,6,0,3,2\}$

## DeepSeek V4 Flash Max 解析
**答案**：A. $\{6,0,3,2\}$

**解题切入点**：工作集定义为在给定时刻 $t$，最近 $\tau$ 次（窗口大小）页面访问的集合（去重）。本题 $\tau = 6$，$t$ 时刻对应竖线所在位置，即刚刚完成竖线前的最后一个页面访问（$2$）。因此，取 $t$ 时刻往前的 $6$ 次访问：$6,0,3,2,3,2$，去重后得到 $\{6,0,3,2\}$，匹配选项 A。

**推演**：
1. 确定 $t$ 时刻：竖线分隔了已访问和待访问页面，$t$ 时刻为竖线前的最后一次访问（即 $2$）完成后的瞬间。
2. 提取最近 $6$ 次访问：从该 $2$ 向前数 $6$ 个，按时间顺序（从早到晚）为 $6,0,3,2,3,2$。
3. 去重得到集合：$\{6,0,3,2\}$。
4. 对照选项，A 正确。

**易错点**：
- 误将窗口大小理解为不同页面数，导致取最近 $6$ 个不同页面（如 $6,0,3,2,?$），但工作集基于最近 $\tau$ 次访问，不要求页面互异。
- 错误定位 $t$ 时刻，可能取竖线右侧的页面（如 $0,4,0,3,2,9$）得到 $\{0,4,3,2,9\}$（C 选项），或取竖线前 $6$ 个不同页面得到 $\{4,5,6,0,3,2\}$（D 选项）。
- 混淆工作集与驻留集（物理内存中实际驻留的页面），工作集仅反映最近访问模式，不涉及页框分配。

**命题规律**：工作集是操作系统内存管理的重要概念，常以页面访问序列和窗口大小为背景，考查定义理解与简单计算。类似算法竞赛中的“滑动窗口求种类数”，只需维护最近 $\tau$ 个访问的页面集合即可。题目通常直接给出序列和窗口大小，要求计算某时刻的工作集，难度较低，但需仔细定位时刻并正确去重。

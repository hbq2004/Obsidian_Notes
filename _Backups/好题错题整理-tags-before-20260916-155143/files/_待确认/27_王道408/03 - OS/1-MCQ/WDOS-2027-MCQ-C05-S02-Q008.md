# MCQ 第 8 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C05-S02-Q008_题目.png|题目]]

下列各种算法中，( ) 是设备分配常用的一种算法.
(A) 首次适应
(B) 时间片分配
(C) 最佳适应
(D) 先来先服务

## DeepSeek V4 Flash Max 解析
**答案**：D

**解题切入点**：设备分配算法属于操作系统 I/O 子系统，核心是管理多个进程对独占设备的请求顺序。常见算法有先来先服务、优先级调度、时间片轮转等。区分内存管理中的动态分区算法（如首次适应、最佳适应）与 CPU 调度中的时间片轮转是本题关键。

**推演**：
- 选项 A 首次适应、选项 C 最佳适应：两者均用于内存动态分区分配，依据空闲块列表搜索策略分配内存，不涉及设备分配。
- 选项 B 时间片分配：典型 CPU 进程调度算法，将 CPU 时间周期性地分配给进程，与设备分配无关。
- 选项 D 先来先服务：设备分配中常用的一种策略，即按进程请求设备的先后顺序排队，依次分配，如打印机、磁带机等独占设备的管理。在竞赛语境中，这类似于队列的 FIFO 处理，简单无饥饿，但可能产生“队头阻塞”效应。

**易错点**：混淆内存管理算法与设备分配算法。首次适应、最佳适应是内存分配中的“空闲分区搜索”算法，类似算法竞赛中“贪心选择”的不同策略；而先来先服务是设备分配里的“排队机制”，如同队列模拟的 BFS 层序遍历。用户若对内存管理不熟，可能误选 A 或 C。

**命题规律**：408 常考概念辨析，将不同模块的算法混合作为选项，要求考生准确归类。内存管理、I/O 管理、CPU 调度三者的算法极易混淆，复习时需对比记忆。本题本质是“设备分配”的常识题，难度较低，但提醒考生注意分类整理。

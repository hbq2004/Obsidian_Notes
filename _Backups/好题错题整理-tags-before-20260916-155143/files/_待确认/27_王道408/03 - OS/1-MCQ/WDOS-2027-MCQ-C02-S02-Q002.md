# MCQ 第 2 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C02-S02-Q002_题目.png|题目]]

进程从创建态转换到就绪态的工作由（ ）完成.
(A) 进程调度
(B) 中级调度
(C) 高级调度
(D) 低级调度

## DeepSeek V4 Flash Max 解析
**答案**：C. 高级调度  

**解题切入点**：进程从创建态转换到就绪态是首次进入内存的过程，对应高级调度（长程调度）的职责。高级调度决定哪些作业从外存调入内存并创建进程，使其进入就绪态，而低级调度（进程调度）负责从就绪态到运行态，中级调度负责挂起与激活。  

**推演**：  
- 创建态到就绪态需要初始化 $PCB$ 并加入就绪队列，此时尚未获得 $CPU$，因此不涉及进程调度（低级调度）。  
- 低级调度（进程调度）专门负责 $CPU$ 分配，即从就绪态到运行态；中级调度负责内存与交换区之间的状态转换（如挂起态与就绪态）。  
- 高级调度（作业调度）是唯一直接处理创建态→就绪态的调度，它决定多道程序的道数，类似于算法竞赛中的“构造题”——先制定整体框架（接纳哪些作业），再交由后续步骤细化执行。  

**易错点**：  
- 混淆“进程调度”与“高级调度”：进程调度常被称为“低级调度”，易误选 (A) 或 (D)，但二者本质相同，均不是本题答案。  
- 误以为创建态自动变为就绪态，无需调度；实际上，在批处理系统中，高级调度必须显式选择作业创建进程，否则系统资源无法合理分配。  

**命题规律**：  
- 408 常以选择题考查三种调度（高级、中级、低级）的职责与对应状态转换，属于基础记忆题，需结合进程状态图牢固掌握。  
- 类比算法竞赛：高级调度 ≈ 构造题中初始状态的选定，中级调度 ≈ 状态机中的挂起/恢复操作，低级调度 ≈ DFS/BFS 中每一步的具体执行顺序（即 $CPU$ 调度算法）。

# MCQ 第 65 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C02-S01-Q065_题目.png|题目]]

下列选项中,可能会将进程唤醒的事件是( ).

$I.$ $I/O$ 结束
$II.$ 某进程退出临界区
$III.$ 当前进程的时间片用完
(A) 仅 $I$
(B) 仅 $III$
(C) 仅 $I$、$II$
(D) $I$、$II$、$III$

## DeepSeek V4 Flash Max 解析
**答案**：
(C) 仅 $I$、$II$

**解题切入点**：
把进程状态转换看成一个状态机：  
唤醒的本质是「阻塞态 $\to$ 就绪态」；调度是「就绪态 $\to$ 运行态」；时间片用完则是「运行态 $\to$ 就绪态」。  
这就像算法竞赛里，BFS 中一个结点从“未入队/不可达”变为“已入队”，才算被唤醒；而队列轮转只是改变队头，不会让新结点入队。题目问“可能唤醒进程”，就是要找哪些事件能把进程从等待队列移入就绪队列。

**推演**：
- 对 $I$：$I/O$ 结束会触发中断，内核找到等待该 $I/O$ 的进程，并将其从阻塞态唤醒到就绪态，因此 $I$ 正确。
- 对 $II$：某进程退出临界区时，会释放互斥锁或信号量。若已有进程因等待该临界资源而阻塞，则可能将其唤醒；若没有等待者，则不唤醒。题干说“可能”，因此 $II$ 正确。
- 对 $III$：当前进程时间片用完，当前进程从运行态变为就绪态，调度器再从就绪队列选一个进程运行。这属于抢占/调度，不是“阻塞态 $\to$ 就绪态”的唤醒，因此 $III$ 错误。

所以选 (C) 仅 $I$、$II$。

**易错点**：
- 容易把 $II$ 判错：有人看到“退出临界区不一定有人等”就排除它，但题目问的是“可能”，只要存在唤醒等待进程的情况就成立。
- 容易把 $III$ 判对：时间片用完确实会引起进程切换，但被切换出去的进程原本在运行，被切换进来的进程原本在就绪队列；没有进程从阻塞态被唤醒。
- 要区分“唤醒”和“调度”：唤醒是等待队列 $\to$ 就绪队列；调度是就绪队列 $\to$ 运行队列。两者经常先后发生，但概念不同。

**命题规律**：
408 常把进程状态转换与信号量/临界区结合，用“可能唤醒”考查阻塞与调度的本质区别。解题时先画出三态状态机，再看事件影响哪条迁移边。若事件只造成“运行态 $\to$ 就绪态”或“就绪态 $\to$ 运行态”，就不算唤醒。这类题也常以“唤醒后需要调度，但调度不等于唤醒”作为命题陷阱。

# MCQ 第 15 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C01-S06-Q015_题目.png|题目]]

检查分区表是否正确，确定哪个分区为活动分区，并在程序结束时将该分区的启动程序（操作系统引导扇区）调入内存加以执行，这是（ ）的任务.
(A) $MBR$
(B) 引导程序
(C) 操作系统
(D) $BIOS$

## DeepSeek V4 Flash Max 解析
**答案**：  
这是 $MBR$ 的任务，故应选 (A) $MBR$。

**解题切入点**：  
计算机系统启动过程是一个多阶段状态机：$BIOS$ 加载 $MBR$，$MBR$ 负责解析分区表、选择活动分区并加载其引导扇区。类比竞赛中的“条件判断”与“递归下降”，$MBR$ 根据输入（分区表）检查合法性并决定下一阶段入口（活动分区引导）。题目所述“检查分区表、确定活动分区、调入执行其启动程序”完全吻合 $MBR$ 的职责。

**推演**：  
1. $BIOS$ 完成自检后，将硬盘第一个物理扇区（$MBR$）读入内存 $0x7C00$ 处并跳转执行。  
2. $MBR$ 程序验证扇区末尾两字节是否为 $0x55AA$ 以确保分区表正确。  
3. 扫描分区表项，寻找标志为 $0x80$ 的活动分区；若未找到则报错。  
4. 将活动分区的第一个扇区（$VBR$，即操作系统引导扇区）读入内存并跳转执行，由其继续加载操作系统内核。  

故“检查”“确定”“调入执行”全部由 $MBR$ 完成，答案选 (A)。

**易错点**：  
- 误认为 $BIOS$ 解析分区表，实际上 $BIOS$ 只负责加载 $MBR$ 而不处理分区内容。  
- 混淆“引导程序”与 $MBR$：题目明确是“该分区的启动程序”，指活动分区中的引导代码，所描述的是 $MBR$ 对其的加载动作，而非该引导程序自身。类比递归调用：$BIOS$ 是主调函数，$MBR$ 是分发子任务者，活动分区引导是被调函数。职责层次分明，否则易误选 B 或 C。  

**命题规律**：  
常以选择题考查 $BIOS$、$MBR$、操作系统引导程序的分工，核心是启动流程 $BIOS \rightarrow MBR \rightarrow$ 活动分区引导 $\rightarrow$ 操作系统。在考研 $408$ 中，这类题要求准确记忆各组件边界，可将启动链视为线性状态转移，$MBR$ 充当“任务转发器”——类似图论中根据条件选择后继节点的中间状态。理解每一层只做固定事，即可避开陷阱。

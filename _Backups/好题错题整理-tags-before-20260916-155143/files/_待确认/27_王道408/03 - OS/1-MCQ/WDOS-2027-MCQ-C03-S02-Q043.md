# MCQ 第 43 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C03-S02-Q043_题目.png|题目]]

在缺页处理过程中，操作系统执行的操作可能是（ ）.
(I) 修改页表
(II) 磁盘 $I/O
(III) 分配页框
(A) 仅 $I、$II
(B) 仅 $II
(C) 仅 $III
(D) $I、$II 和 $III

## DeepSeek V4 Flash Max 解析
**答案**：
D。缺页处理本质上是一次缓存未命中处理，I、II、III 均可能在缺页处理过程中发生。

**解题切入点**：
把虚拟内存看成算法竞赛里的“懒加载 + 记忆化搜索”。页表项的有效位就是 `vis` 数组；缺页就是访问到 `vis[u] == false` 的状态。此时需要从外存读入数据（磁盘 $I/O$ ），在物理内存中申请一个槽位（分配页框），再把映射关系写回页表（修改页表）。因此不能把缺页处理只理解成“读盘”。

**推演**：
缺页中断发生后，操作系统处理的过程可以看作页表项状态从 $0$ 变为 $1$ 的状态转移：

1. 硬件访问页表时发现有效位为 $0$ ，触发缺页中断；
2. 操作系统为缺失页分配一个页框；若空闲页框不足，还会按置换算法淘汰一个页，必要时将脏页写回外存；
3. 从磁盘或交换区读入缺失页，这是磁盘 $I/O$ 操作；
4. 修改页表项：置有效位为 $1$ 、填入页框号，并更新访问位、脏位等；
5. 重新执行导致缺页的指令。

所以缺页处理过程中可能涉及修改页表、磁盘 $I/O$ 和分配页框，选 D。

**易错点**：
- 不能把“页面置换”和“缺页处理”看成两件无关的事：没有空闲页框时的置换只是缺页处理中的一步。
- 不要因为“不是每次缺页都一定有磁盘 $I/O$ ”就排除 II；题干问的是“可能是”，只要存在换入/换出的情况即可。
- 分配页框不是地址转换硬件完成的，而是操作系统内存管理模块完成的；硬件只负责发现缺页并陷入内核。

**命题规律**：
这是 408 中“虚拟内存 / 缺页中断”的经典组合题，命题人常用“可能是 / 一定是”来设置干扰项。算法竞赛视角下，这就是“cache miss”的处理流程：分配 cache line、从低速存储取数、更新 tag/valid 位。复习时应把缺页处理、页面置换、页表项位（有效位、脏位、访问位）串成一个状态机，后续很容易与 LRU、Clock 或 TLB 结合出题。

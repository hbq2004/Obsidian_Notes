# MCQ 第 11 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C04-S02-Q011_题目.png|题目]]

11. 下列关于目录检索的论述中,正确的是 ( )
(A) 散列法具有较快的检索速度,因此现代操作系统中都用它来替代传统的顺序检索方法
(B) 在利用顺序检索法时,对树形目录应采用文件的路径名,且应从根目录开始逐级检索
(C) 在利用顺序检索法时,只要路径名的一个分量名未找到,就应停止查找
(D) 利用顺序检索法查找完成后,即可得到文件的物理地址

## DeepSeek V4 Flash Max 解析
**答案**：
C

**解题切入点**：
目录检索本质是路径解析。把目录树看作一棵有根树，路径名就是从根目录或当前目录出发的一条链；顺序检索就是沿着这条链逐级查找。路径上任意一个中间分量不存在，后面的分量就不可能再找到，所以必须立刻停止。这类似于 DFS/BFS 中某个状态不可达时直接剪枝返回。A、B、D 分别犯了“绝对化”“以偏概全”“概念层次错位”的错误。

**推演**：
- A 错：散列法平均查找速度是 $O(1)$，但有哈希冲突、扩容、难以支持顺序遍历等问题；现代操作系统并不会“都用它来替代”顺序检索，而是会根据目录大小和场景选择线性表、B 树、哈希等多种方式。这就像算法竞赛里 $\mathrm{unordered\_map}$ 并不总是优于排序后二分查找。
- B 错：树形目录确实使用路径名，但路径名分为绝对路径名和相对路径名。绝对路径名从根目录开始，例如 $/a/b$；相对路径名从当前工作目录开始，例如 $a/b$。所以“应从根目录开始逐级检索”只适用于绝对路径，不能说所有顺序检索都从根目录开始。
- C 对：设路径 $P = (d_1, d_2, \dots, d_k, f)$，顺序检索时先在起点目录中找 $d_1$，再在 $d_1$ 对应目录中找 $d_2$，依此类推。若某个分量 $d_i$ 找不到，则后续路径必然不可达，继续查找没有意义，应立即停止。
- D 错：顺序检索完成后得到的是目录项，或者说 inode 号，并不直接等于物理地址。以 UNIX 为例，目录项形如 $(文件名, inode号)$，拿到 inode 号后还要读入 inode，再通过 inode 中的磁盘块映射得到物理地址。链路是：
$$
\text{路径名} \xrightarrow{\text{顺序检索}} \text{目录项/inode号} \xrightarrow{\text{读inode}} \text{物理盘块地址}
$$
所以“查找完成即可得到物理地址”不准确。

**易错点**：
- 容易把“路径名”默认成“绝对路径名”，从而误选 B；实际上相对路径名从当前目录开始。
- 容易把“找到目录项”当成“已经拿到物理地址”。目录项、inode/FCB、物理盘块地址是不同层次的概念。
- 看到“散列法快”就选 A，忽略了“都用它来替代”这种绝对化表述。
- 容易在 C 和 D 之间犹豫；C 是路径查找的“剪枝条件”，D 是概念错位。

**命题规律**：
408 很喜欢用“都”“应”“即可”这类绝对化词设置干扰项，正确选项往往是“边界条件/停止条件”这种精确描述。目录检索常与“打开文件”“绝对/相对路径”“inode/FCB”结合考查。复习时可以把路径解析类比成图论中的 DFS 路径搜索：起点由绝对/相对路径决定，中间节点不存在就提前返回；路径查找的结果只是“找到节点”，要得到“物理地址”还需访问节点的元数据。

# MCQ 第 18 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C02-S01-Q018_题目.png|题目]]

并发进程失去封闭性,是指( )
(A) 多个相对独立的进程以各自的速度向前推进
(B) 并发进程的执行结果与速度无关
(C) 并发进程执行时,在不同时刻发生的错误
(D) 并发进程共享变量,其执行结果与速度有关

## DeepSeek V4 Flash Max 解析
**答案**：  
D．并发进程共享变量，其执行结果与速度有关  

**解题切入点**：  
封闭性（$\text{isolation}$）指进程的执行结果仅取决于自身，不受外界干扰。失去封闭性即进程间因共享变量而产生交互，导致结果与各进程的相对推进速度（$\text{relative speed}$）相关，这正是并发程序不确定性的根源。类比算法竞赛中的多线程调试：若共享全局数组未加锁，每次运行结果可能不同，速度差异（如线程调度顺序）直接决定最终输出。  

**推演**：  
- A 项描述多个进程独立推进，属于并发执行的基本表现，但未触及结果受干扰的本质。  
- B 项宣称结果与速度无关，恰恰是封闭性保持时的特征，与题意相反。  
- C 项提及不同时刻发生错误，仅为并发可能引发的现象之一，并非失去封闭性的定义。  
- D 项准确指出共享变量导致结果与速度相关，即失去封闭性的核心：进程的执行不再独立，外部环境（调度顺序）可改变其语义。  

**易错点**：  
- 混淆“并发执行”与“失去封闭性”：前者是进程同时推进，后者强调结果受外界影响。  
- 误选 B，认为结果与速度无关是并发性质，实则封闭性未破坏时才成立。  
- 忽略“共享变量”这一关键前提，失去封闭性必定对应资源竞争（如 $\text{race condition}$），类似图论中共享边权的多源最短路径问题，不同访问顺序导致不同解。  

**命题规律**：  
- 常以基本概念形式出现，考查对封闭性、并发不确定性等核心术语的理解。  
- 与“进程同步”“互斥”“临界区”等章节衔接，为后续死锁、信号量等机制铺垫。  
- 选项设计常包含“执行速度”“共享变量”“结果相关”等关键词，通过对比定义与反面描述设置干扰。

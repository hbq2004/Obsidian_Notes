# MCQ 第 3 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C03-S02-Q003_题目.png|题目]]

3. 进程在执行中发生了缺页中断，经操作系统处理后，应让其执行 ( ) 指令.
(A) 被中断的前一条
(B) 被中断的那一条
(C) 被中断的后一条
(D) 启动时的第一条

## DeepSeek V4 Flash Max 解析
**答案**：B（被中断的那一条）

**解题切入点**：缺页中断发生时，指令尚未执行完毕，操作系统将页面调入内存后，必须重新执行该指令，故选择被中断的那一条。这类似于算法竞赛中，当访问数组元素发现缓存缺失时，需先加载数据再重新访问。

**推演**：缺页中断属于异常（故障），CPU 在执行指令过程中若发现所需页面不在内存，则暂停当前指令，保存现场，转入操作系统缺页处理程序。处理完成后，进程的程序计数器（$PC$）恢复为中断前该指令的地址，从而重新执行原指令。类比于 DFS/BFS 状态搜索，当遇到未展开的状态时，先展开该状态（加载页面），再回溯继续搜索，而非直接跳过。因此，恢复执行的是被中断的那一条指令。

**易错点**：易与普通中断（如 I/O 中断）混淆，普通中断返回后执行下一条指令；而缺页中断属于异常，指令未完成，需重新执行原指令。算法竞赛中类似误区：处理中断时误以为应跳过当前指令，实际应重新执行。

**命题规律**：考查异常与中断的区别，聚焦缺页中断的处理流程。常与普通中断、系统调用等对比，需理解 CPU 在异常发生时对指令执行状态的恢复机制。类似算法竞赛中区分“错误处理”与“正常返回”的流程差异。

# MCQ 第 3 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C02-S01-Q003_题目.png|题目]]

3. 进程与程序的根本区别是（ ）

(A) 静态和动态特点
(B) 是不是被调入内存
(C) 是不是具有就绪、运行和等待三种状态
(D) 是不是占有处理器

## DeepSeek V4 Flash Max 解析
**答案**：  
$\boxed{A}$

**解题切入点**：  
从概念本质入手，区分“进程”与“程序”的核心定义——程序是静态的指令集合，进程是动态的执行过程。这类似于算法竞赛中，你写好的代码文件（程序）是静态模板，而它在评测机上的运行、等待输入、输出结果的过程（进程）才是动态的实体。

**推演**：  
- 选项 A：进程具有动态性（创建、调度、撤销），程序是静态的代码映像，这是二者的根本区别。  
- 选项 B：程序被调入内存后可能成为进程，但并非所有被调入内存的程序都是进程（如常驻内存的库），且这一描述只是现象，不是本质。  
- 选项 C：就绪、运行、等待是进程的典型状态，程序本身不具备这些状态，但这是动态性的具体表现，而非根本区别。  
- 选项 D：进程可能占有处理器，程序不占有，但这也是动态执行的结果，同样不是根本原因。  

因此，只有 A 直接揭示了“动态 vs 静态”这一最本质的对立，如同 DFS 状态搜索中，状态机（进程）在不断变迁，而状态定义（程序）是固定不变的。

**易错点**：  
- 误以为“程序必须调入内存才能成为进程”是根本区别，实际上调入内存只是进程创建的一个步骤，且程序本身也可被调入内存而不作为进程存在（如模块）。  
- 混淆“进程状态”与“程序状态”，程序无状态变化，但进程的状态只是动态性的子集。  
- 认为“占有处理器”是关键，但进程在等待时并不占有处理器，而程序从未占有过，所以该描述不具普遍性。

**命题规律**：  
- 408 选择题常以“根本区别”“本质特征”设问，考查对核心概念的精确理解。  
- 类似“进程与程序”“进程与线程”“死锁与饥饿”等对比题，需抓住定义最底层的差异（如动静、粒度、资源归属等）。  
- 答题时避免被表面现象混淆，应回归教材定义：进程是程序的执行过程，程序是静态的代码集合。

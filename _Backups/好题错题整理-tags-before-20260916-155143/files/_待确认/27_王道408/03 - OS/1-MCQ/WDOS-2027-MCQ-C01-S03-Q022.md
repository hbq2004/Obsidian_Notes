# MCQ 第 22 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C01-S03-Q022_题目.png|题目]]

假定下列指令已装入指令寄存器,则执行时不可能导致 $CPU$ 从用户态变为内核态(系统态)的是( ).
(A) $DIV R0, R1; (R0)/(R1) \rightarrow R0$
(B) $INT n$; 产生软中断
(C) $NOT R0$; 寄存器 $R0$ 的内容取非
(D) $MOV R0, addr$; 把地址 $addr$ 处的内存数据放入寄存器 $R0$

## DeepSeek V4 Flash Max 解析
**答案**：$\text{(C)}$

**解题切入点**：用户态→内核态只能通过中断或异常触发，如同算法竞赛中程序遇到除零、段错误会触发运行时错误（$RE$、$SEGFAULT$）而中断执行，而普通运算（如位取反）则不会。本题即判断各指令是否为可能引发异常或主动陷入的“危险操作”。

**推演**：
- $\text{(A) DIV R0, R1}$：除法，当 $R1=0$ 时产生除零异常（类似 $a/b$ 且 $b=0$ 导致 $RE$），迫使 $CPU$ 进入内核态处理。
- $\text{(B) INT n}$：软中断指令，主动产生中断（类似调用系统函数），必然导致 $CPU$ 进入内核态。
- $\text{(C) NOT R0}$：寄存器取反，纯逻辑运算（类似 $\sim a$），不涉及内存访问或特殊条件，不会产生任何异常，故不可能发生状态切换。
- $\text{(D) MOV R0, addr}$：访存，若 $addr$ 无效或权限不足（类似访问非法指针导致 $SEGFAULT$），会触发缺页或保护异常，从而切换到内核态。

**易错点**：容易忽略 $\text{(D)}$ 的内存访问可能引发异常（如缺页），而误以为其安全；或认为 $\text{(A)}$ 的除法总是正常，忘记除零情况。在算法竞赛中，这两类错误恰是常见运行时错误，而 $\text{(C)}$ 的位运算则绝对安全。

**命题规律**：$408$ 操作系统常以具体指令为载体，考查状态切换的触发条件。核心是理解异常和中断的区分：主动陷入（如 $INT$）一定切换，被动异常（如除零、缺页）可能切换，纯运算指令永不切换。此类题需结合计算机组成原理的指令执行知识，但本质是识别“危险操作”是否可能发生。

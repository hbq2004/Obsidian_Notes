# MCQ 第 23 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C05-S02-Q023_题目.png|题目]]

SPOOLing 系统由（$\＿$）组成.
(A) 预输入程序、井管理程序和缓输出程序
(B) 预输入程序、井管理程序和井管理输出程序
(C) 输入程序、井管理程序和输出程序
(D) 预输入程序、井管理程序和输出程序

## DeepSeek V4 Flash Max 解析
**答案**：

选 A。SPOOLing（假脱机）系统由“预输入程序、井管理程序和缓输出程序”组成。

**解题切入点**：

这是设备管理中的概念题。SPOOLing 的核心不是普通的“输入→处理→输出”，而是用磁盘上的“井”把慢速 I/O 和 CPU 执行解耦。

用算法竞赛的视角看，它很像“异步评测 / 缓存提交”三段式：

- 预输入：把外部数据提前读入队列或缓冲区；
- 井管理：负责队列和缓冲区的分配、中转；
- 缓输出：把结果延迟统一输出。

所以看到“井”“预输入”“缓输出”这些关键词，就不会选泛泛的“输入程序 / 输出程序”。

**推演**：

SPOOLing 系统要模拟“脱机输入输出”的效果，必须由三个功能模块构成：

1. 预输入程序：将作业或数据从低速外设预先读入磁盘输入井。这相当于“批量预读”。
2. 井管理程序：统一管理输入井和输出井，负责把输入井数据交给进程，把进程输出写入输出井。这相当于“内存池管理器 / 队列调度器”。
3. 缓输出程序：将输出井中的数据在合适时机再送到输出设备，完成真正的输出。这相当于“延迟落盘 / 异步刷新”。

数据流可以写成：

$$
\text{外设} \xrightarrow{\text{预输入程序}} \text{输入井} \xrightarrow{\text{井管理程序}} \text{进程} \xrightarrow{\text{井管理程序}} \text{输出井} \xrightarrow{\text{缓输出程序}} \text{外设}
$$

因此，A 选项的“预输入”“井管理”“缓输出”三个限定词，正好体现 SPOOLing 的异步和后台特征。B 的“井管理输出程序”不是标准模块名称；C、D 中的“输入程序 / 输出程序”太笼统，缺少“预”和“缓”的关键语义。

**易错点**：

- 容易误选 C 或 D，因为只记住了“输入程序、输出程序”，但 SPOOLing 强调的是“预输入”和“缓输出”。
- 不要把“井管理程序”拆成“输入井管理程序”和“输出井管理程序”，标准说法是一个井管理程序统一管理输入井和输出井。
- 不要把“程序组成”和“部件组成”混淆。题目问 SPOOLing 由哪些程序组成时，选三程序；若问由哪些部件组成，可能会涉及输入井、输出井、输入缓冲区、输出缓冲区等。

**命题规律**：

这是设备管理中的低频概念题。408 更常考 SPOOLing 的性质：将独占设备改造为共享设备、提高 I/O 速度、实现虚拟设备等。

遇到这类题，像做“读题找关键限定词”的签到题：选项中必须同时出现“预输入”“井管理”“缓输出”。可以把三程序理解成控制路径，把输入井 / 输出井理解成数据路径，类似算法题中“队列管理 + 缓存刷新”的分工。

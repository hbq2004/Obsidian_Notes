# MCQ 第 60 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C02-S01-Q060_题目.png|题目]]

下列关于进程和线程的叙述中,正确的是 ( ).
(A) 不管系统是否支持线程,进程都是资源分配的基本单位
(B) 线程是资源分配的基本单位,进程是调度的基本单位
(C) 系统级线程和用户级线程的切换都需要内核的支持
(D) 同一进程中的各个线程拥有各自不同的地址空间

## DeepSeek V4 Flash Max 解析
**答案**：
$$ \boxed{\text{A}} $$

在支持线程的系统中，线程是 CPU 调度的基本单位，进程仍是资源分配的基本单位；在不支持线程的传统系统中，进程同时承担资源分配和调度两种角色。因此 A 正确。

**解题切入点**：
先抓住两个维度：资源所有权和 CPU 执行权。进程像一个“资源容器”，线程是容器内的“执行流”。用算法竞赛类比：进程是全局的“可用背包/预算”，线程是在同一张状态图上并发推进的多路 DFS；调度就是决定下一步让哪条路径前进，资源分配就是决定哪些资源属于哪个“容器”。

**推演**：
1. 设系统线程支持情况为 $s \in \{0,1\}$。当 $s=0$ 时，进程既是资源分配单位，也是调度单位，所以“进程是资源分配基本单位”成立；当 $s=1$ 时，进程依然持有地址空间、文件描述符、信号量等资源，线程只保留 $PC$、$SP$ 和寄存器上下文。因此 A 成立。

2. B 把概念互换了：线程是调度单位，进程是资源分配单位；在无线程系统中，进程还是调度单位。所以 B 错。

3. 设用户级线程为 $T_u$，内核级线程（系统级线程）为 $T_k$。$T_u$ 的切换由用户态线程库通过保存/恢复上下文完成，不需要陷入内核；$T_k$ 的切换需要内核完成。C 说“都需要内核支持”，错。

4. 同一进程中的各线程共享进程的虚拟地址空间，类似于多个 DFS 分支共享同一张图；每个线程可有独立栈和寄存器，但不是“各自不同的地址空间”。D 错。

**易错点**：
- 容易把“线程有自己的栈和寄存器”误解为“线程有自己的地址空间”。实际上栈只是进程地址空间内的一块区域，寄存器属于 CPU 上下文，地址空间仍归进程共享。
- 容易混淆“资源分配单位”和“调度单位”：引入线程后，资源分配单位仍是进程，调度单位才变成线程。
- 用户级线程切换不需要内核支持，但不是说用户级线程永远不会进入内核；它若执行系统调用仍会陷入内核，只是“用户级线程之间的切换”不经过内核调度器。

**命题规律**：
408 概念题常把进程/线程、资源分配/调度、用户态/内核态组合成选项，像“选项乱序 + 偷换概念”的基础题。解题时先写好标准模板：
$$ \text{进程}=\text{资源容器},\quad \text{线程}=\text{执行流}, $$
然后逐项对照，避免被某个半句正确的选项带走。此类题通常 1 分，但属于必须拿下的概念送分题。

# MCQ 第 52 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C04-S02-Q052_题目.png|题目]]

设置当前工作目录的主要目的是（ ）
(A) 节省外存空间
(B) 节省内存空间
(C) 加快文件的检索速度
(D) 加快文件的读/写速度

## DeepSeek V4 Flash Max 解析
**答案**：C  

**解题切入点**：  
题目要求区分文件系统概念。在算法竞赛中，路径搜索类似 BFS 或 DFS 的起点选择——设置当前工作目录相当于固定一个“源点”，相对路径只需从该点开始解析，避免每次从根节点（全局起点）遍历全树，从而减少目录项查找次数，加快检索速度。  

**推演**：  
文件系统通过目录树组织文件，绝对路径从根目录 `/` 开始逐级查找，相对路径则从当前工作目录（CWD）开始。当 CWD 位于深层目录时，相对路径仅需解析剩余分支，路径长度缩短，目录项读入次数减少，因此检索速度提升。这与算法竞赛中预处理起点以缩小搜索范围（如构造 BFS 的源点集）本质相同。选项 A、B：CWD 仅是一个指针，不占用额外外存或内存，故不节省空间；选项 D：读写速度取决于磁盘 I/O 与缓存，与路径解析无关，CWD 不直接加速数据传送。  

**易错点**：  
容易误选 D，误以为“当前工作目录”常用于文件读写就能加速读写。实际需区分“文件检索”与“文件读写”：检索是路径解析过程，读写是数据传输过程，两者分属不同阶段。CWD 只影响路径解析效率，不改变磁盘 I/O 速度。  

**命题规律**：  
考察文件系统基本概念，聚焦当前工作目录的功能。常以选择题出现，背景为相对路径与绝对路径的解析机制。结合算法竞赛视角，可类比搜索剪枝——通过设置起点减少状态空间，从而提升搜索效率。

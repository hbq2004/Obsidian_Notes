# MCQ 第 27 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C03-S02-Q027_题目.png|题目]]

27. 请求分页存储管理的主要特点是（ ）
(A) 消除了页内零头
(B) 扩充了内存
(C) 便于动态链接
(D) 便于信息共享

## DeepSeek V4 Flash Max 解析
**答案**：
B（扩充了内存）。请求分页本质是虚拟存储技术，它“从逻辑上扩充内存”，而不是物理内存变大。

**解题切入点**：
请求分页 = 基本分页 + 请求调页 + 页面置换。它允许进程只装入部分页面即可运行，缺页时 OS 再调入。这很像算法竞赛里的“动态开点线段树”：不一次性把整个区间建满，而是用到哪个结点才分配哪个结点，因此小内存也能解决大逻辑空间问题。题干问“主要特点”，就是在问虚拟存储带来的核心收益：逻辑上扩大内存。

**推演**：
设进程逻辑地址空间大小为 $L$，物理内存大小为 $M$。基本分页要求进程全部页面都驻留内存；请求分页可以在 $L \gg M$ 时仍运行，因为只驻留当前需要的页面。

- 对于 A：页面大小固定，最后一页仍会产生页内零头，请求分页不会消除它；分段存储才能避免页内零头。
- 对于 C：动态链接更适合分段管理，因为段是逻辑信息单位，可独立编译、链接和共享；分页的页是物理等分单位，与程序逻辑结构无关。
- 对于 D：信息共享也是分段的优点，分页虽然可以共享页面，但“便于共享”不是请求分页的主要特点。
- 对于 B：请求调页 + 页面置换使进程的逻辑空间可以大于物理内存，给用户一种内存被扩充的感觉，因此 B 正确。

**易错点**：
- 不要把分页的“消除外部碎片”误记成“消除页内零头”。分页消除的是外部碎片，仍然存在页内零头；选项 A 用“页内零头”反向干扰。
- 不要把“动态链接”“信息共享”选成答案，这两个是分段存储管理的经典优点。
- “扩充了内存”不能理解为物理内存扩容，应表述为“逻辑上扩充内存”或“提供虚拟内存”。

**命题规律**：
408 喜欢对比“分页 / 分段 / 请求分页 / 虚拟存储”的特点。记住这张映射关系：
- 分页 $\rightarrow$ 定长分配、无外部碎片、有页内零头。
- 分段 $\rightarrow$ 按逻辑模块划分、便于共享和动态链接、有外部碎片。
- 请求分页 / 虚拟存储 $\rightarrow$ 按需调页、逻辑上扩充内存。

这类题本质是“特点匹配 + 排除法”，类似竞赛中看到“支持区间修改”就联想到懒标记线段树，看到“按需建点”就联想到动态开点，关键词一对应即可快速锁定答案。

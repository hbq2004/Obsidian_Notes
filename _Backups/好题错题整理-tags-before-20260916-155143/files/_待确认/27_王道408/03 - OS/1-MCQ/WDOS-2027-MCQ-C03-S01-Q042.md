# MCQ 第 42 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C03-S01-Q042_题目.png|题目]]

以下存储管理方式中,不适合多道程序设计系统的是 ( ).
(A) 单用户连续分配
(B) 固定式分区分配
(C) 可变式分区分配
(D) 分页式存储管理方式

## DeepSeek V4 Flash Max 解析
**答案**：  
A  

**解题切入点**：  
判断存储管理方式能否同时容纳多个进程。多道程序设计系统要求内存可驻留多道程序并隔离，而单用户连续分配将内存仅分给一个用户进程，不支持多道，故不适合。  

**推演**：  
- 单用户连续分配：内存分为系统区与用户区，用户区一次只供一个进程使用，无法实现多道。  
- 固定式分区分配：内存划分为多个固定分区，每分区可加载一道程序，支持多道。  
- 可变式分区分配：动态创建分区，可容纳多道程序。  
- 分页式存储管理：通过页表映射，支持多道程序并发执行。  

因此，选项 A 不符合多道系统要求。  

**易错点**：  
- 误以为固定分区分配不适应多道，实际它是早期多道系统的典型方案。  
- 混淆单用户连续分配与可变分区：前者是单道，后者是多道。  
- 对“多道”理解不深，忽略单用户连续分配只适用于单任务系统。  

**命题规律**：  
常考各存储管理方式对多道程序、虚拟内存等特性的支持。结合算法竞赛背景：单用户连续分配如同只允许一个全局变量（单例），而多道程序需要多个变量共存，类似竞赛中只开一个数组 vs 动态开多个数组；或像 DFS 只维护一个状态栈，而 BFS 需队列存储多个节点，无法并行处理多分支。

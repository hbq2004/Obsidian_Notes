# MCQ 第 67 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C02-S01-Q067_题目.png|题目]]

67.【2020 统考真题】下列关于父进程与子进程的叙述中,错误的是（ ）
A. 父进程与子进程可以并发执行
B. 父进程与子进程共享虚拟地址空间
C. 父进程与子进程有不同的进程控制块
D. 父进程与子进程不能同时使用同一临界资源

## DeepSeek V4 Flash Max 解析
**答案**：B

**解题切入点**：

题干是概念辨析题，等价于判断四个关于进程的命题真假。算法竞赛类比：看到“父子进程”要立刻想到 `fork` 相当于把当前状态复制一份，复制出的状态有独立的上下文，而不是共享同一个状态。只有线程才类似“共享全局变量的多入口搜索”，父子进程是独立的“状态节点”。

**推演**：

- A 正确：`fork` 后父进程与子进程都是独立调度实体，PCB 都会进入就绪队列。单 CPU 上可以交替执行，多 CPU 上可以并行执行，所以父子进程可以并发执行。
- B 错误：子进程创建时会复制父进程的虚拟地址空间，$V_{child}$ 是 $V_{parent}$ 的内容拷贝，但页表、地址映射、PCB 中的内存管理信息是独立的。即使 Linux 采用写时复制（COW），也只是物理页暂时共享且只读，虚拟地址空间本身并不共享。只有线程才共享虚拟地址空间。
- C 正确：每个进程有唯一的进程控制块 PCB，父子进程是两个进程，$PCB_p \neq PCB_c$，PID 也不同。
- D 正确：临界资源要求互斥访问，任何两个进程都不能同时使用同一临界资源，父子进程也不例外。父进程与子进程若要使用同一临界资源，也必须通过锁、信号量等机制互斥。

因此错误的是 B。

**易错点**：

- 容易把“写时复制”理解成“共享虚拟地址空间”。实际上 COW 只是物理内存优化，类似可持久化线段树共享未修改结点，但逻辑上每个版本仍是独立结构。
- 容易混淆进程与线程：线程共享虚拟地址空间；进程之间，包括父子进程，地址空间是隔离的。
- 容易误以为父进程调用 `wait()` 等待子进程，所以父子进程不能并发执行。`wait()` 只是某一时刻的同步行为，并不代表二者没有并发执行的能力。
- 对“临界资源”要按定义判断：互斥使用。父子关系不会获得同时进入同一临界区的特权。

**命题规律**：

408 常把“进程概念”“父子进程与 fork”“临界资源”组合成一道单选题，核心是区分进程与线程：进程是资源分配单位，线程是 CPU 调度单位。解题时像算法竞赛对拍一样逐项找反例：B 的反例就是 `fork` 后父子进程具有各自独立的虚拟地址空间。只要抓住“进程地址空间隔离、线程地址空间共享”这一主线，就不容易被 COW 等优化细节干扰。

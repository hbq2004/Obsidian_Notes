# MCQ 第 30 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C02-S02-Q030_题目.png|题目]]

30. 分时操作系统通常采用（ ）调度算法来为用户服务.

(A) 时间片轮转
(B) 先来先服务
(C) 短作业优先
(D) 优先级

## DeepSeek V4 Flash Max 解析
**答案**：A. 时间片轮转

**解题切入点**：分时操作系统以“交互性”和“公平性”为首要目标，要求每个用户都能及时获得响应。这类似于算法竞赛中多任务并发处理，需要一种“轮询”机制来均分 CPU 资源，避免某个任务长时间独占。

**推演**：分时系统将 CPU 时间划分为若干等长的小片段 $\Delta t$（时间片），每个用户任务按到达顺序依次占用一个时间片，执行完毕或时间片耗尽则切换下一个。这种“轮转”策略天然保证了所有任务在宏观上同时推进，响应时间可预测。对比其他选项：
- 先来先服务缺乏交互性，长任务会阻塞后续任务；
- 短作业优先虽然平均等待时间短，但长任务可能饥饿，且无法保证交互；
- 优先级调度可能导致低优先级任务长期得不到服务，不符合“公平”原则。
因此，时间片轮转是分时系统的标准算法。

**易错点**：容易将“分时系统”与“实时系统”混淆，误以为优先级调度能更好满足用户需求。但分时系统强调“公平分摊”，而非“紧急优先”。在算法竞赛中，这类似于使用“轮询”而非“贪心”来分配资源，避免某个进程（或线程）被饿死。

**命题规律**：常将各类调度算法（FCFS、SJF、优先级、RR）与操作系统类型（批处理、分时、实时）配对考查。解题关键是抓住操作系统设计目标：批处理→吞吐量（短作业优先），分时→交互响应（时间片轮转），实时→截止时间（优先级，可抢占）。类似竞赛中根据题目限制选择算法：$O(n^2)$ 暴力 vs $O(n \log n)$ 优化，这里设计的“目标”决定了“算法”的选择。

# MCQ 第 60 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C03-S02-Q060_题目.png|题目]]

60.【2025统考真题】在页式虚拟存储管理系统中，确定进程正常运行所需的最少页框数时下列因素中需要考虑的是 ( )

(A) 代码段长度
(B) 进程的虚拟地址空间大小
(C) 物理内存大小
(D) 指令系统支持的寻址方式

## DeepSeek V4 Flash Max 解析
**答案**：  
D：指令系统支持的寻址方式。

**解题切入点**：  
本题问的是“最少页框数”，而不是“最多能分配多少页框”。最少页框数是一个硬性下界，它要保证 CPU 能完整执行任意一条指令。类比算法竞赛：一次 DFS 至少需要的系统栈大小不由输入文件总行数决定，而由单次 DFS 的最大递归深度决定；同理，进程最少页框数不由代码总长度、虚拟地址空间大小决定，而由“单条指令执行时最多会同时触碰多少个页面”决定，这恰好由指令系统支持的各种寻址方式规定。

**推演**：  
一条指令执行时，CPU 可能需要同时访问以下页面：

- 指令本身所在的页；
- 源操作数所在的页；
- 目的操作数所在的页；
- 间接寻址时地址指示字所在的页。

若某条指令需要 $k$ 个不同的页面同时在内存中，则该进程至少要有 $k$ 个页框，否则指令无法完整地取指、取数和写回。

因此，最少页框数为：

$$
N_{\min}=\max_{I}\{\text{执行指令 } I \text{ 时需同时驻留的页面数}\}
$$

这个最大值由指令系统的寻址方式决定。

选项分析：

- $A$ 代码段长度：只影响代码页总数，可请求调页，不必全部驻留；
- $B$ 进程的虚拟地址空间大小：只影响进程可能拥有的页面总数，不是同时驻留的下限；
- $C$ 物理内存大小：决定系统最多能分配多少个页框，而不是进程正常运行所需的最少页框数；
- $D$ 指令系统支持的寻址方式：直接决定一条指令最多能引用多少个不同页面，因此必须考虑。

**易错点**：  
容易误选 $A$ 或 $C$。代码段长、虚拟空间大只代表“页面总量”大，不代表“同时驻留”的页框数大；物理内存大小决定的是页框数上限，而本题问的是下限。  
还要注意：计算一条指令所需页面时，不能只数操作数页面，还要考虑指令本身所在页；若指令跨页，甚至可能涉及多个指令页。另需区分“最少页框数”和“工作集大小”，工作集依赖程序局部性，而最少页框数是 ISA 层面的硬约束。

**命题规律**：  
408 常把虚拟内存的分配策略、缺页率、页框数等概念混在一起考。本题是典型的“硬约束 vs 软资源”题：寻址方式决定一条指令最多访问几个页，这是硬件层面的硬约束；代码长度、虚拟空间、物理内存都是规模或容量层面的软资源。见到“最少/最小/必要条件”，先想“是什么限制了它不能更小”，而不是“什么资源越大越好”。这就像图论匹配中，限制匹配能否继续扩大的常是度数约束，而不是顶点总数。

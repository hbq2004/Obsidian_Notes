# MCQ 第 29 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C05-S02-Q029_题目.png|题目]]

下面关于独占设备和共享设备的说法中，不正确的是（ ）.
(A) 打印机、扫描仪等属于独占设备
(B) 对独占设备往往采用静态分配方式
(C) 共享设备是指一个作业尚未撤离，另一个作业即可使用，但每个时刻只有一个作业使用
(D) 对共享设备往往采用静态分配方式

## DeepSeek V4 Flash Max 解析
**答案**：  
不正确的是 $\boxed{D}$。核心配对关系是
$$
\text{独占设备} \leftrightarrow \text{静态分配},\qquad
\text{共享设备} \leftrightarrow \text{动态分配}.
$$
共享设备若采用静态分配，就等价于把可并发共享的资源变成作业级独占资源，违背定义。

**解题切入点**：  
从“资源分配”切入。可以把设备看成图论中的资源节点，作业看成请求者；独占设备是容量为 $1$ 的互斥节点，共享设备是可被多路复用的共享节点。静态分配 = 一开始就把节点匹配给一个作业并锁到结束；若共享设备也这样做，其他请求全部阻塞，“共享”语义失效。所以看到“共享设备 + 静态分配”应直接判错。

**推演**：  
- (A) 打印机、扫描仪是临界资源，同一时间只能由一个作业使用，属于独占设备，正确。  
- (B) 独占设备往往采用静态分配：作业运行前分配，作业撤离后释放，正确。  
- (C) 共享设备允许多个作业在宏观上交替使用，即一个作业尚未撤离，另一个作业也可使用；每个时刻底层 I/O 可能只有一个作业在真正传输，体现“宏观共享、微观串行”，正确。  
- (D) 对共享设备应采用动态分配，按需申请、用完释放；静态分配会破坏共享性，错误。  

因此选 D。

**易错点**：  
1. 不要把 C 的“每个时刻只有一个作业使用”误认为独占。共享设备是“一段时间内的共享”，不是“同一瞬间所有作业同时操作设备”。  
2. 区分物理独占与虚拟共享：打印机是物理独占设备，但可用 SPOOLing 技术改造成虚拟共享设备。  
3. 记忆分配方式时，要抓住“是否允许长期独占”：独占设备可静态分配，共享设备只能动态分配。

**命题规律**：  
408 常考“设备分类 $\leftrightarrow$ 分配方式”的概念配对，属于送分题。算法竞赛中这类似“资源匹配/调度”模型：判断一个策略是否合法，看它是否破坏资源的不变量。静态分配会破坏共享设备“可被多个作业分时复用”的不变量，所以就是错误项。掌握“独占 / 共享 / 虚拟”三者的关系，考试时用排除法可直接定位答案。

# MCQ 第 36 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C04-S02-Q036_题目.png|题目]]

文件系统在创建一个文件时,为它建立一个 ( ).
(A) 文件目录项
(B) 目录文件
(C) 逻辑结构
(D) 逻辑空间

## DeepSeek V4 Flash Max 解析
**答案**：选 $A$ 。创建文件时，文件系统首先要在父目录中为该文件建立一个目录项（即 $FCB$ ，文件控制块），记录文件名、文件类型、权限、物理位置等元数据。这相当于把“新文件”登记进目录树。

**解题切入点**：把创建文件看成向字典插入一个键值对：文件名是 $key$ ，元数据/物理地址是 $value$ ；目录项就是这个键值对。目录文件是存放大量目录项的容器，逻辑结构和逻辑空间则是文件被创建后需要确定或维护的属性，不是创建时新建的那个对象。所以切入点就是问自己：新建文件时，系统需要在目录树中产生的最小数据结构是什么？答案是目录项。

**推演**：
1. 创建文件 $f$ 时，系统在父目录的目录文件中增加一个目录项，记录 $f$ 的文件名和索引信息；这个目录项通常就是 $FCB$ 。
2. 父目录的目录文件已经存在，因此创建普通文件不需要新建目录文件。若要创建的是新目录，才需要新建目录文件，并放入 `.` 和 `..` 等目录项。
3. 文件的逻辑结构（顺序、链接、索引等）是文件内容如何组织，属于文件属性，最终记录在 $FCB$ 或 $inode$ 中，而不是创建时额外“建立”一个逻辑结构。
4. 逻辑空间是操作系统为文件提供的抽象地址范围，逻辑地址到物理块的映射发生在读写时，和“创建文件时建立目录项”不在同一层面。

类比竞赛：创建文件 = 新建一个链表节点并 `push_back` 到目录链表/哈希表中；目录项就是节点，目录文件就是容器，逻辑结构是你未来如何遍历节点的方式。故选 $A$ 。

**易错点**：
- 误选 $B$ ：创建文件不是创建目录文件。目录文件是目录项的集合，创建普通文件只是更新已有的父目录文件，相当于给 `vector` 添加元素，而不是新建 `vector` 。
- 误选 $C$ ：逻辑结构是文件的组织形式，不是文件系统为新建文件建立的存储实体；它只是被记录下来的属性。
- 混淆“目录项”与“索引节点”：在 Unix/Linux 中，$inode$ 保存文件元数据，目录项保存文件名到 $inode$ 的映射；创建文件会分配 $inode$ 并插入目录项，二者配合，但题目问“为它建立一个”，最直接的是目录项。

**命题规律**：408 中这类题考查文件系统基础概念，尤其是目录项、$FCB$ 、$inode$ 的职责。命题人常通过“创建、打开、删除文件时系统分别做什么”来区分概念。这就像竞赛中给定一个操作，问底层数据结构如何变化：创建文件 $=$ 在字典中插入键值对，打开文件 $=$ 获取字典中的 value 并建立进程与文件的关联，删除文件 $=$ 从字典中移除键值对并处理引用计数。记住这个类比，此类送分题不会再错。

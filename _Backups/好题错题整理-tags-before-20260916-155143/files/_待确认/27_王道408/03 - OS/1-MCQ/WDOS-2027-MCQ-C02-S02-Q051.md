# MCQ 第 51 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C02-S02-Q051_题目.png|题目]]

下列事件中，可能引起进程调度程序执行的是 ( ) $I.$ 中断处理结束 $II.$ 进程阻塞 $III.$ 进程执行结束 $IV.$ 进程的时间片用完.
(A) 仅 $I$、$III$
(B) 仅 $II$、$IV$
(C) 仅 $III$、$IV$
(D) $I$、$II$、$III$ 和 $IV$

## DeepSeek V4 Flash Max 解析
**答案**：  
D。四个事件均可能触发进程调度程序执行。

**解题切入点**：  
调度程序的本质是：当 CPU 当前占用者不再适合继续占用时，从就绪队列中选一个进程。这类似于算法竞赛中的“事件驱动”自动机：进程状态是节点，调度触发点是边上的条件；每次状态迁移后都需要判断是否要执行“选择函数”。题目问的是哪些事件会“可能”触发，而不是“一定”触发，所以抓住一点：运行进程是否可能被移出 CPU，或就绪队列是否有新成员需要抢占。

**推演**：  
用状态机视角，$R$ 表示运行、$Q$ 表示就绪、$B$ 表示阻塞、$T$ 表示终止。

- $I$ 中断处理结束：中断处理完成后，可能唤醒某阻塞进程进入就绪队列，也可能当前进程时间片已到。例如 I/O 中断唤醒高优先级进程，则可能抢占当前进程，触发调度；若无变化，则不会。因此是“可能”。
- $II$ 进程阻塞：运行进程发出 I/O 请求后从 $R \to B$，CPU 立即空闲，必须执行调度程序选新进程。这相当于图论匹配中某个顶点失效后需要重新找增广路。
- $III$ 进程执行结束：运行进程从 $R \to T$，CPU 释放，必须调度。
- $IV$ 时间片用完：分时系统中当前进程从 $R \to Q$，虽然 CPU 并未空闲，但策略要求换人，因此时钟中断处理结束后会重新调度。

综上，$I$、$II$、$III$、$IV$ 都是可能触发调度的时机，选 D。

**易错点**：  
1. 误以为 $I$ 不是调度时机：中断处理结束不等于一定调度，但“可能”调度；尤其时钟中断处理结束会检查时间片，I/O 中断处理结束可能唤醒高优先级进程。  
2. 把“进程阻塞”与“进程睡眠”混淆：只要当前运行进程阻塞，CPU 就空闲，必须调度。  
3. 将“时间片用完”只当作中断而非调度：时间片用完是时钟中断，中断处理结束后会重新调度。  
4. 要注意“可能引起”与“必然引起”的区别；若题目改为“必然引起”，则 $I$ 不能选，但本题是“可能”。

**命题规律**：  
408 常以“调度时机”命题，本质考查对进程状态转换和中断处理流程的理解。选项常混合“中断”“阻塞”“结束”“时间片”等状态转移事件，容易通过“是否必然调度”来设置陷阱。复习时把调度时机总结为：当前进程不能继续运行（阻塞/结束）、当前进程不值得继续运行（时间片用完/被抢占）、系统中可能产生新就绪进程（中断唤醒）三类即可。与算法竞赛对比，相当于记住状态转移图中哪些边会触发“重新选择最优解”的贪心策略，遇到选择题直接按状态迁移判断。

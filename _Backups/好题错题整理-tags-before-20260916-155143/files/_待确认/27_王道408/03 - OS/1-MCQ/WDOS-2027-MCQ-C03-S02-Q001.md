# MCQ 第 1 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C03-S02-Q001_题目.png|题目]]

1. 下列关于存储管理的叙述中,正确的是（\\_\\_\\_\\_）

(A) 存储保护的目的是限制内存的分配

(B) 在内存为 $M$、有 $N$ 个用户的分时系统中,每个用户占用 $M/N$ 的内存空间

(C) 在虚拟内存系统中,只要磁盘空间无限大,作业就能拥有任意大的编址空间

(D) 实现虚拟内存管理必须有相应硬件的支持

## DeepSeek V4 Flash Max 解析
**答案**：  
D  

**解题切入点**：  
逐一分析各选项对存储管理核心概念的描述，重点区分存储保护、分时内存分配、虚拟地址空间上限及硬件依赖。需结合操作系统原理判断唯一正确的叙述。  

**推演**：  
- **A 选项**：存储保护的目的是防止进程越界访问（如越界读写），而非限制内存分配。类似算法竞赛中数组访问需检查下标是否越界，保护的是访问合法性，而非限制分配量。  
- **B 选项**：分时系统对内存并非均分，而是按进程需求动态分配，与时间片轮转的 CPU 调度不同。这好比多线程任务中的资源分配，并非简单平均，而是按需调度。  
- **C 选项**：虚拟内存系统虽能提供比物理内存更大的地址空间，但编址空间上限由 CPU 地址位数决定（如 $32$ 位最大 $4\text{GB}$），磁盘容量不影响地址空间大小。这类似哈希表的键空间受限于哈希函数输出位数，而非存储介质大小。  
- **D 选项**：虚拟内存的实现依赖硬件支持，如内存管理单元（MMU）负责地址转换，页表等机制也需硬件配合。没有硬件支撑，地址映射和缺页处理无法高效完成，如同某些算法需要 GPU 或 SIMD 等硬件加速才能实现。  

**易错点**：  
- 易误选 C，认为“磁盘无限大则编址空间无限”，忽略地址位数对虚拟地址空间的根本限制。  
- 可能错选 B，因分时系统易被误认为资源均分，实则内存分配与 CPU 调度策略不同。  
- A 选项的“限制分配”与“保护”概念混淆，需注意存储保护的核心是访问控制而非分配限制。  

**命题规律**：  
考查虚拟内存的实现条件，强调硬件支持的必要性，是操作系统基础知识的常考细节。通过反例（如地址位数限制）区分概念，要求考生准确理解存储保护、分时内存分配与虚拟地址空间的实际含义。

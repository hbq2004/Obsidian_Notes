# MCQ 第 19 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C05-S01-Q019_题目.png|题目]]

在接收和处理一个输入设备的中断的过程中，一定不由硬件来完成的工作是( ).
(A) 判断产生中断的类型
(B) CPU模式由用户态切换到内核态
(C) 主机获取设备输入
(D) 保存用户程序的断点

## DeepSeek V4 Flash Max 解析
**答案**：\boxed{C}

**解题切入点**：从硬件自动完成的“中断响应”步骤（关中断、保存断点、模式切换、中断向量识别）与软件完成的“中断处理”步骤（保护现场、中断服务、恢复现场）的分工入手。类似算法竞赛中，底层硬件相当于预定义的模板函数（如中断向量自动跳转），而软件处理则相当于自定义的 `solve()` 函数，需要手动读取输入数据。

**推演**：
- (A) 判断中断类型：硬件可通过中断向量表自动完成（向量中断），也可由软件查询中断状态寄存器完成（非向量中断），故硬件可能完成，不满足“一定不由硬件”。
- (B) CPU 模式由用户态切换到内核态：中断响应时硬件自动将 CPU 模式切换为内核态，一定由硬件完成。
- (C) 主机获取设备输入：在中断服务程序中，CPU 通过 I/O 指令或内存映射 I/O 读取设备数据，该操作由软件指令显式执行，硬件无法自动完成“获取并处理”的动作（除非 DMA，但 DMA 传输在中断前或独立于中断处理过程），故一定由软件完成。
- (D) 保存用户程序的断点：硬件自动将当前 PC 和 PSW 压入栈或指定寄存器，一定由硬件完成。

因此，只有 C 一定不由硬件完成。

**易错点**：易误认为“判断中断类型”在任何情况下都由硬件完成，从而排除 A；但非向量中断中类型识别由软件通过查询实现，故 A 并非绝对硬件完成。而“主机获取设备输入”常被误认为可由 DMA 硬件完成，但 DMA 传输本身不是中断处理过程中的必要步骤，且中断处理程序中的读取操作必须由软件指令完成，故 C 是唯一正确选项。

**命题规律**：考察中断处理过程中硬件与软件职责的划分，属于操作系统基础知识。常以选择题形式出现，要求区分“硬件自动完成”与“软件完成”的步骤。类似考点还包括中断向量、中断响应、现场保护等。掌握中断流程的各个阶段归属即可快速作答。

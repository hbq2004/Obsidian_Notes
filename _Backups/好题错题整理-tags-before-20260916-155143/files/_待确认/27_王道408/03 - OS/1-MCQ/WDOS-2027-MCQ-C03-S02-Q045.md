# MCQ 第 45 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C03-S02-Q045_题目.png|题目]]

下列关于虚拟存储器的叙述中,正确的是（）
(A) 虚拟存储只能基于连续分配技术
(B) 虚拟存储只能基于非连续分配技术
(C) 虚拟存储容量只受外存容量的限制
(D) 虚拟存储容量只受内存容量的限制

## DeepSeek V4 Flash Max 解析
**答案**：
B

**解题切入点**：
虚拟存储器的核心是“部分装入、按需调入/置换”，必须把逻辑地址与物理地址解耦。这就像算法题里面对一个大值域稀疏数组：不可能直接开 `int a[1<<64]`，只能用 `unordered_map` 或多级索引做映射。页表就是“虚拟页号 → 物理页框号”的映射表，页面在内存中散落存放，因此虚拟存储只能基于**非连续分配技术**。连续分配相当于要求整个数组连续存放，无法只加载部分元素却保持原下标可访问。

**推演**：
设 CPU 虚拟地址长度为 $n$ 位，则进程可寻址的虚拟地址空间上限为
$$
V_{\max}=2^n
$$
个编址单元。这个上限由地址结构决定，不是由内存或外存单独决定；同时每个虚拟页/段在外存中要有后备存储，所以实际虚拟存储容量还受外存容量限制。

逐项判断：

- A 错：连续分配无法按页/段离散换入换出，无法实现请求调入和置换。
- B 对：请求分页、请求分段、段页式都属于非连续分配，利用页表/段表完成地址映射。
- C 错：只受外存限制忽略了地址宽度限制。例如 $n=32$ 时，即使外存容量超过 $4\text{ GB}$，虚拟地址空间也不可能超过 $2^{32}$ 个可编址字节。
- D 错：只受内存限制否定了外存对虚拟存储的扩展作用，与“从逻辑上扩充内存”的初衷矛盾。

因此选 B。

**易错点**：
1. 误以为“虚拟存储就是外存当内存用”，所以容量只受外存限制。实际上，CPU 地址位数是硬上限，外存容量是另一个约束，二者共同限制。
2. 误以为“连续分配 + 交换/覆盖”也能实现虚拟存储。交换是把整个进程换入换出，覆盖需要程序员控制；虚拟存储是按页/段离散换入，必须有页表/段表。
3. 分段式虽然段内连续，但段与段之间可以离散存放，仍属于非连续分配；不要看到“段内连续”就误判为连续分配。
4. 内存中的物理页框只是当前驻留集，类似 Cache；内存越大只是缺页越少，并不能增大虚拟地址空间上限。

**命题规律**：
408 中虚拟存储常考概念辨析，选项常围绕“连续/非连续”“内存/外存容量”“地址结构”设置陷阱。核心结论是：虚拟存储实现基于**非连续分配** + 请求调入 + 置换；容量受**地址结构**限制，并受**外存容量**限制，内存容量不决定虚拟存储容量上限。看到“只能”和“只受”要高度警惕，这类绝对化表述通常是在考边界条件。

# MCQ 第 23 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C05-S01-Q023_题目.png|题目]]

本地用户通过键盘登录系统时,首先获得键盘输入信息的程序是(\\_).
(A) 命令解释程序
(B) 中断处理程序
(C) 系统调用服务程序
(D) 用户登录程序

## DeepSeek V4 Flash Max 解析
**答案**：
B. 中断处理程序。

键盘输入属于外部硬件事件，按键产生中断后，CPU 响应中断并执行键盘中断处理程序，由它从键盘控制器读取扫描码/字符码。用户登录程序等只能读到内核缓冲区中已经处理过的数据，因此“首先获得”的是中断处理程序。

**解题切入点**：
题干关键词是“首先获得”。键盘是典型的中断驱动字符设备，一次按键等价于一个外部中断事件。在算法竞赛中，这类似于外部事件触发一个高优先级回调函数：回调先取得原始事件，主程序之后才从全局队列中取数据。这里的“回调”就是操作系统的中断处理程序。

**推演**：
1. 用户按键，键盘控制器将按键扫描码放入寄存器，并向 CPU 发送中断请求。
2. CPU 保存当前现场，根据中断向量跳转到键盘中断处理程序（ISR）。
3. ISR 从键盘控制器寄存器中读取扫描码并放入内核输入缓冲区，这是软件第一次获得键盘输入信息。
4. 登录程序随后通过系统调用 $\mathrm{read}()$ 读取数据，系统调用服务程序负责把内核缓冲区数据复制到用户空间。
5. 命令解释程序（shell）通常登录成功后才启动，因此不可能最先获得登录输入。

整体流程：

\[
\text{按键}\xrightarrow{\text{硬件中断}}\text{中断处理程序（ISR）}\xrightarrow{\text{内核缓冲区}}\text{系统调用服务程序}\xrightarrow{\text{read() 返回}}\text{用户登录程序}
\]

**易错点**：
- 误选 D：用户登录程序只是最终消费用户名/密码的业务程序，它不会直接访问键盘控制器。
- 误选 C：系统调用服务程序是用户进程调用 $\mathrm{read}()$ 时提供的内核服务，等中断处理程序把数据放入缓冲区后才能复制数据，不是第一手来源。
- 误选 A：命令解释程序是登录成功后才与用户交互的 shell，与“键盘登录”阶段无关。
- 不要把“用户最终看到输入”当成“最先获得输入”，题问的是第一站。

**命题规律**：
这是典型的“I/O 数据路径”题，命题人用“首先/最后”这类词考查中断处理、系统调用、用户程序之间的层次关系。核心链路是：

\[
\text{外设中断}\rightarrow \text{ISR 读取数据}\rightarrow \text{内核缓冲区}\rightarrow \text{系统调用返回}\rightarrow \text{用户程序}
\]

掌握这条链路后，类似题可秒杀。竞赛中类比为：事件回调先拿到原始事件，主逻辑再从队列中消费事件；回调执行之前，业务代码不可能获得输入。

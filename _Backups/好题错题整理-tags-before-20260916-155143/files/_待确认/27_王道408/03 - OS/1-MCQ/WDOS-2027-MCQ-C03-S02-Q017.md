# MCQ 第 17 题

![[_Attachments/题目识别/WDOS-2027-MCQ/WDOS-2027-MCQ-C03-S02-Q017_题目.png|题目]]

在请求分页存储管理中,若采用 FIFO 页面淘汰算法,则当可供分配的页帧数增加时,缺页中断的次数 ().
(A) 减少
(B) 增加
(C) 无影响
(D) 可能增加也可能减少

## DeepSeek V4 Flash Max 解析
**答案**：D（可能增加也可能减少）

**解题切入点**：FIFO 页面置换算法存在 Belady 异常，即分配的页帧数增多时，缺页中断次数可能不降反升。从算法竞赛视角看，这类似于贪心策略中的反常现象，提醒我们增加资源不一定优化性能，需要具体分析访问模式，如同构造题中需构造反例证明算法非最优。

**推演**：FIFO 算法维护一个队列，按页面调入顺序淘汰。当帧数增加时，队列长度增大，但淘汰页面的时机也随之改变。例如，经典访问序列 $1,2,3,4,1,2,5,1,2,3,4,5$，帧数 $3$ 时缺页 $9$ 次，帧数 $4$ 时缺页 $10$ 次，体现了 Belady 异常。因此，缺页中断次数可能增加也可能减少，故选项 D 正确。

**易错点**：容易误以为帧数增加必然减少缺页次数，忽略 FIFO 和 Clock 算法可能产生的 Belady 异常。而 LRU 和 OPT 算法无此异常，但 LRU 实现成本高，OPT 为理想模型。解题时需注意区分不同算法特性。

**命题规律**：常以选择题或判断题形式考查 Belady 异常的概念，要求判断哪些算法可能发生，或给定序列计算缺页次数对比。也常与 LRU、OPT 一并出题，突出 FIFO 的缺点及异常现象。

# 选择题 第 15 题

![[_Attachments/题目识别/27_王道408-题目/CO-C06-61-M15_题目.png|题目]]

15. 总线中,有些信息是单向传输的,有些信息是双向传输的,下列说法中正确的是( ).

A. 数据信息是单向传输的,由内存或外设传送至 $CPU$

B. 地址信息是单向传输的,由 $CPU$ 发送至内存或外设

C. 控制信息是双向传输的,由 $CPU$ 发送至内存或外设,也可反向

D. 状态信息是双向传输的,由 $CPU$ 发送至内存或外设,也可反向

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C06-61-M15_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。数据总线是双向的；地址总线虽单向，但地址不一定只能由 CPU 发出，DMA 控制器等总线主设备也可以发出；控制总线整体上是双向的；状态信息则是由内存/外设发往 CPU，不是由 CPU 发出。

**解题切入点**：  
拿到题目先建立“总线主设备/从设备”模型。主设备通常是 CPU，但也可能是 DMA 控制器；主设备发出地址和命令，从设备返回状态，数据在主、从设备之间双向传送。只要分清“谁主动发、谁被动收”，这类方向题就不会乱。

**推演**：  
系统总线按传输内容分为数据总线、地址总线和控制总线。

1. **数据信息**是双向传输的。  
   CPU 从内存或外设读数据时，数据由内存/外设传到 CPU；CPU 向内存或外设写数据时，数据由 CPU 传到内存/外设。  
   因此 A 错。

2. **地址信息**是单向传输的，但发送方不一定是 CPU。  
   通常 CPU 访存或访问 I/O 时，地址由 CPU 发出：
   $$
   \mathrm{CPU} \to \mathrm{内存/外设}
   $$
   但在 DMA 方式下，DMA 控制器获得总线控制权后，也可以作为主设备向内存/外设发送地址：
   $$
   \mathrm{DMA\ 控制器} \to \mathrm{内存/外设}
   $$
   所以 B 中“由 CPU 发送至内存或外设”说得太绝对，B 错。

3. **控制信息**整体上是双向传输的。  
   控制总线中既有 CPU 发出的读/写命令、中断响应等信号，也有内存/外设发给 CPU 的中断请求、准备就绪等信号：
   $$
   \mathrm{CPU} \to \mathrm{内存/外设}
   $$
   $$
   \mathrm{内存/外设} \to \mathrm{CPU}
   $$
   需要注意：这不是说同一根控制线既能输入又能输出，单根控制线的方向是固定的，但控制总线整体方向是双向的。因此 C 正确。

4. **状态信息**是单向传输的，通常由内存/外设发往 CPU，而不是由 CPU 发往内存/外设：
   $$
   \mathrm{内存/外设} \to \mathrm{CPU}
   $$
   因此 D 错。

**易错点**：  
- 容易误选 B：只记得“地址总线单向”，却忽略 DMA 控制器也可以作为主设备发送地址。  
- 容易误以为“控制总线双向”就是每根控制线都可以双向传输；实际上每根控制线的方向固定，只是整个控制总线中既有输入信号又有输出信号。  
- 容易混淆控制信息和状态信息：控制信息可双向，但状态信息一般是从设备发给 CPU 的单向信息。

**命题规律**：  
本题属于总线基础题，考点是总线分类、信息传输方向和总线主/从设备。常见变式有：结合 DMA 考查“谁可以成为总线主设备”，结合中断考查“中断请求线的方向”，或者结合数据线/地址线数量考查寻址空间和总线宽度。复习时抓住“主设备发地址和控制，从设备回状态，数据可双向”这一主线即可。

# 选择题 第 3 题

![[_Attachments/题目识别/27_王道408-题目/CO-C06-62-M03_题目.png|题目]]

3. 同步控制方式是（ ）

(A) 只适用于 $CPU$ 控制的方式
(B) 只适用于外部设备控制的方式
(C) 由统一的时序信号控制的方式
(D) 所有指令执行时间都相同的方式

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C06-62-M03_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。同步控制方式的核心是“由统一的时序信号（时钟）控制”，而不是限定仅用于 CPU 或外部设备，也不要求所有指令执行时间都相同。

**解题切入点**：这是一道计算机组成原理中控制器控制方式的基础概念题。拿到题目先抓关键词“同步控制”，立即联想到控制器的三种控制方式：同步控制、异步控制、联合控制。同步控制的本质是“统一时钟、固定时序”，而不是“同步=时间相同”。可以类比算法竞赛中的同步控制：整个程序统一由一个“心跳”驱动，所有操作都在这个心跳的节拍上完成，不关心单个步骤到底占几个节拍。

**推演**：

首先明确控制器的基本控制方式有三种：

1. **同步控制方式**：由统一的时序信号（通常是一个基准时钟）控制各部件的工作。任何指令的执行都在固定的时钟周期序列中完成，控制器按统一的节拍发出微命令。

2. **异步控制方式**：没有统一的时钟，采用“应答”方式，由前一操作完成后发出“完成”信号来启动下一操作，即按需控制。

3. **联合控制方式**：同步与异步相结合，大部分操作采用同步控制，少数时间不确定的操作采用异步控制。

逐项分析选项：

- **(A) 只适用于 CPU 控制的方式**：错误。同步控制不仅用于 CPU 内部，也可用于 CPU 与外部设备之间的同步。例如，外设通过统一的时钟与主机交换数据，也是同步控制方式。同步控制并不是 CPU 的专利。

- **(B) 只适用于外部设备控制的方式**：错误。同步控制广泛应用于 CPU 内部各功能部件（运算器、寄存器、总线等）的控制。例如，CPU 的微程序控制器通常采用同步控制方式。

- **(C) 由统一的时序信号控制的方式**：正确。这是同步控制方式的定义性特征。它用一个统一的时钟信号（如 CPU 的主频时钟）作为时序基准，所有操作都在这个基准时钟的节拍下进行。虽然不同指令可能需要不同的时钟周期数，但每个时钟周期的长度和相位是一致的。

- **(D) 所有指令执行时间都相同的方式**：错误。同步控制只保证“时序信号统一”，并不保证“指令执行时间相同”。不同指令（如简单加法与复杂乘法）所需机器周期数可以不同，只不过每个机器周期都由统一的时钟控制。若所有指令执行时间都相同，那是另一种极端设计（如单周期处理器），但“同步控制”并不等于“单周期”。

综上，只有选项 C 正确。

**易错点**：

- **误把“同步”理解为“时间相同”**：这是最常见的错误。同步强调“统一的节拍”，而不是“一样的时长”。例如多周期 CPU 中每条指令的周期数不同，但仍然是同步控制。
- **误以为同步控制只能用于 CPU 内部**：同步控制也可用于外部设备与主机之间的数据传送，如同步总线传输。因此 A、B 都以“只适用于”来设陷阱。
- **混淆“同步控制”与“异步控制”**：异步控制没有统一时钟，而同步控制必须有统一时序信号。当题目出现“握手”“应答”等字眼时，应选异步控制；出现“统一时钟”“统一节拍”时，应选同步控制。

**命题规律**：本题考查控制器控制方式的基本概念，属于计算机组成原理中的低难度高频考点。命题者常将“同步控制”“异步控制”“联合控制”以及“指令周期”“机器周期”等概念混在一起考查。常见变式包括：

- 给出具体时序图或总线握手过程，判断是同步控制还是异步控制；
- 给出多周期 CPU 的控制器设计，提问其控制方式是同步还是异步；
- 对比单周期 CPU 与多周期 CPU，分析是否属于同步控制。

复习建议：牢固掌握同步控制和异步控制的核心区别——是否有统一时钟信号；理解“同步控制不要求执行时间相同”这一关键点；平时做题时注意选项中的绝对化词语（如“只适用于”“所有”），这些往往是错误选项的标志。

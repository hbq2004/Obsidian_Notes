# 选择题 第 12 题

![[_Attachments/题目识别/27_王道408-题目/CO-C06-62-M12_题目.png|题目]]

12. 下列关于计算机总线的叙述中，正确的是（ ）.

A. 现代高速总线普遍采用并行同步方式以提高带宽
B. 突发传输过程中，$CPU$ 需在每个时钟周期通过地址线发送待访问字的完整地址
C. 计算机系统中的所有总线共享同一时钟信号与控制协议
D. 采用总线事务分离技术可避免总线空闲等待，提升总线利用率

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C06-62-M12_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。总线事务分离技术把一次事务分成“请求”和“应答”两个阶段，从设备准备数据期间可以让出总线给其他主设备使用，从而避免因等待而空占总线，提升总线利用率；A、B、C 均不正确。

**解题切入点**：先定位考点：总线传输方式与总线事务过程。A 考现代高速总线是并行还是串行；B 考突发传输的地址发送方式；C 考全系统总线是否统一；D 考分离事务的作用。可以类比多线程调度：一个线程等待 I/O 时若一直占着 CPU 就会空转，分离事务相当于“让出总线”，而不是等待时继续占用。

**推演**：

- **A 错**：并行传输看似能一次传多位、提高带宽，但在很高时钟频率下，并行线之间会产生时钟偏移和串扰，导致信号难以同步。现代高速总线普遍采用串行差分传输方式，例如 PCIe、USB、SATA 等，而不是“并行同步”。因此 A 不正确。

- **B 错**：突发传输也叫猝发传输，只需在事务开始阶段发送一次起始地址，随后按地址自动递增连续传送多个数据字，不需要每个时钟周期都通过地址线发送完整地址。若每个字都要单独发地址，那就不是突发传输。因此 B 不正确。

- **C 错**：计算机系统中不同总线可能工作在不同时钟频率下，也采用不同控制协议，例如 CPU 总线、存储总线、I/O 总线等，它们之间常通过桥接芯片连接。不可能要求“所有总线”共享同一时钟信号与控制协议。因此 C 不正确。

- **D 对**：普通总线事务中，主设备发出地址后要等待从设备准备数据，此时总线若一直被占用，就会造成“总线空闲等待”。采用分离事务后，请求子事务和应答子事务分开；请求发出后，总线可被仲裁给其他主设备使用，待从设备数据准备好后再申请总线完成应答。这样就把等待时间与其他事务重叠，从而提高总线利用率。因此 D 正确。

**易错点**：

1. 误以为并行一定比串行快而选 A。实际上高频下并行总线存在串扰、时钟偏移等问题；现代高速总线常通过串行高频率和差分信号来提升带宽。
2. 混淆“突发传输”和“分离事务”。突发传输仍会连续占用总线，只是地址只发一次；分离事务则在等待从设备响应时释放总线。
3. 对 C 中的“所有总线”不够敏感。不同总线类型可以有不同的时钟和协议，之间需要桥接转换。
4. 对 D 理解成“分离事务让总线永不空闲”。分离事务只能避免“等待从设备响应”造成的空占；若总线上没有其他事务请求，总线仍可能空闲。

**命题规律**：这是 408 计算机组成原理中“总线”部分的常见判断题，重点考查总线分类、传输方式、突发传输、分离事务等概念。命题时常把多个易混说法放在一起，让考生判断正误。常见变式包括：比较并行与串行、同步与异步；判断突发传输过程；考查分离事务与总线利用率的关系；结合总线带宽计算 $B = f \times W$ 出题。复习时应牢记总线事务的基本阶段：请求→仲裁→地址→数据→结束，并重点区分突发传输、分离事务和总线流水线三种提高总线利用率的手段。

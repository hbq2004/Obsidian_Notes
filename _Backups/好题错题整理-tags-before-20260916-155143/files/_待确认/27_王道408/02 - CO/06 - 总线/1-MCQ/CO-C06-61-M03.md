# 选择题 第 3 题

![[_Attachments/题目识别/27_王道408-题目/CO-C06-61-M03_题目.png|题目]]

3. 系统总线用来连接（ ）

(A) 寄存器和运算器部件
(B) 运算器和控制器部件
(C) $CPU$、主存和外设部件
(D) 接口和外部设备

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C06-61-M03_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。系统总线是连接 CPU、主存和 I/O 设备（外设经 I/O 接口挂接）的公共通信线路，因此选 C。

**解题切入点**：  
拿到题先按部件的物理位置分层：寄存器、运算器、控制器都在 CPU 内部；主存和外设（通过 I/O 接口）在 CPU 外部。题目问的是“系统总线”，不是“片内总线”或“设备总线”。这就像做图论题先看点是同一层还是跨层：A、B 的点都在 CPU 这一个结点内部，C 才是 CPU、主存、外设三个结点之间的通信边。

**推演**：

1. 总线按层级通常分为：
   - 片内总线：连接 CPU 内部寄存器、运算器、控制器等部件；
   - 系统总线：连接 CPU、主存和 I/O 设备（外设通过 I/O 接口挂接）；
   - 通信总线：用于计算机系统之间的通信。

2. 系统总线内部又分为：
   - 数据总线：双向传输数据；
   - 地址总线：由 CPU 发出，选择存储单元或 I/O 端口；
   - 控制总线：传送读写控制、中断请求等控制信号。

3. 逐个选项判断：
   - A：“寄存器和运算器部件”都在 CPU 内部，连接它们的是片内总线，不是系统总线；
   - B：“运算器和控制器部件”也都在 CPU 内部，属于 CPU 内部总线连接，不是系统总线；
   - C：“CPU、主存和外设部件”正是系统总线的连接范围，外设通过 I/O 接口挂在系统总线上；
   - D：“接口和外部设备”之间属于设备级连接，不是系统总线的主要连接对象。

因此正确选项是 C。

**易错点**：  
- 容易误选 A 或 B，因为“总线”一词在 CPU 内部也很常见；要注意“系统总线”是连接 CPU、主存和 I/O 设备的主干总线。
- D 有迷惑性：I/O 接口与外部设备之间是设备连接，不是系统总线；系统总线的边界一般到 I/O 接口为止，外设再通过接口接入系统。
- 不要把“系统总线”和“片内总线”混为一谈；系统总线连接的是主机中的大部件，而不是 CPU 内部的小部件。

**命题规律**：  
考点是总线层次与分类、系统总线的组成。常见变式包括：区分数据总线、地址总线、控制总线的方向和作用；已知地址线 $n$ 根，求最大可寻址范围 $2^n$；或把片内总线、系统总线、通信总线放在一起辨析。复习时建议画出“CPU 内部总线 — 系统总线 — 通信总线”的层次图，并熟记系统总线三组线的连接对象与方向特点。

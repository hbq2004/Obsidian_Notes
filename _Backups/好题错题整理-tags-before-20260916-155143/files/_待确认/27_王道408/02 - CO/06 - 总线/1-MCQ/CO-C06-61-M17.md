# 选择题 第 17 题

![[_Attachments/题目识别/27_王道408-题目/CO-C06-61-M17_题目.png|题目]]

17.【2010统考真题】 * 下列选项中的英文缩写均为总线标准的是 ( )

A. $PCI$、$CRT$、$USB$、$EISA$

B. $ISA$、$CPI$、$VESA$、$EISA$

C. $ISA$、$SCSI$、$RAM$、$MIPS$

D. $ISA$、$EISA$、$PCI$、$PCI\text{-}Express$

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C06-61-M17_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。$ISA$、$EISA$、$PCI$、$PCI\text{-}Express$ 均为常见总线标准，其余选项中均混入了非总线标准缩写。

**解题切入点**：这是“找异类”式概念判断题。先圈定自己最有把握的缩写，优先排除含明显非总线标准的选项。总线标准多与扩展槽、外设接口相关；而 $CPI$、$MIPS$ 是性能指标，$CRT$ 是显示设备，$RAM$ 是存储器，均不属于总线标准。

**推演**：逐项分析。

A 项：$PCI$、$USB$、$EISA$ 都是总线标准；但 $CRT$ 是阴极射线管（Cathode Ray Tube），属于显示器件，不是总线标准。故排除。

B 项：$ISA$ 是总线标准；$VESA$ 本身是视频电子标准协会（Video Electronics Standards Association），若指局部总线通常用 $VLB$（VESA Local Bus），不能简单把 $VESA$ 算作总线标准；$CPI$（Cycles Per Instruction）是每条指令所需时钟周期数，属于性能指标，不是总线标准。故排除。

C 项：$ISA$ 是总线标准，$SCSI$ 是小计算机系统接口，可作为总线/接口标准；但 $RAM$ 是随机存取存储器，不是总线标准；$MIPS$ 是每秒百万条指令，属于性能指标，也不是总线标准。故排除。

D 项：$ISA$（工业标准体系结构）、$EISA$（扩展工业标准体系结构）、$PCI$（外设部件互连）、$PCI\text{-}Express$（PCIe）均为总线标准。故 D 正确。

**易错点**：

- 把 $VESA$ 当成总线标准：$VESA$ 是组织名称，其制定的局部总线标准常写作 $VLB$ 或 $VL\text{-}Bus$。
- 把 $SCSI$ 排除：$SCSI$ 是外设总线/接口标准，但 C 项中还有 $RAM$、$MIPS$ 这些明显非总线项，不影响判断。
- 混淆性能指标与总线标准：$CPI$、$MIPS$ 是衡量计算机性能的指标，不能归入总线标准。
- 对缩写不熟：把 $CRT$ 误认为总线相关术语，实际 $CRT$ 是显示设备。

**命题规律**：考点定位在“总线的分类与常见总线标准”，属于识记型题目。常见变式是更换一组缩写，例如混入 $AGP$、$PCIe$、$USB$、$SATA$、$IDE$、$SCSI$ 等总线/接口标准，干扰项常为 $CPI$、$MIPS$、$RAM$、$ROM$、$CRT$、$LCD$ 等。复习时应整理常见总线标准的中英文全称和分类，特别注意区分组织名（如 $VESA$）与具体总线标准（如 $VLB$），考点清晰，难度不大。

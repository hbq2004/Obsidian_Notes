# 选择题 第 11 题

![[_Attachments/题目识别/27_王道408-题目/CO-C04-43-M11_题目.png|题目]]

11. 下列有关调用指令(转子指令)的叙述中,错误的是( )

A. 与高级语言源程序中的过程调用相对应,一次过程调用对应一条调用指令
B. 指令执行时必须保留返回地址,调用指令随后一条指令的地址是返回地址
C. 嵌套调用时返回地址通常保存在栈中,非嵌套调用时可保存在特定寄存器中
D. 指令执行时将无条件转移到目标地址处,转移目标地址无须在指令中明显给出

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C04-43-M11_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。调用（转子）指令虽是无条件转移到子程序入口，但必须先保存返回地址；其转移目标地址必须由指令以直接或间接方式给出，不能完全“无须在指令中明显给出”。

**解题切入点**：拿到题目先抓“调用指令 = 无条件转移 + 保存返回地址”这两个关键点。然后逐项判断每句话是在考“返回地址”还是“目标地址”。好比写代码时调用函数：编译器生成一条 `call func`，CPU 既要知道 `func` 的入口地址，也要知道调用完回到哪里继续执行，两个信息缺一不可。

**推演**：

- A 正确。高级语言中的过程调用在机器指令层面由调用指令实现；一次过程调用对应一条调用指令。参数传递、栈帧调整等由其他指令完成，不影响“控制转移本身对应一条调用指令”。

- B 正确。设调用指令地址为 $A$，指令长度为 $L$，取指完成后 $PC = A+L$，该地址就是调用指令后一条指令的地址，也就是返回地址。调用时必须保存它，子程序返回时再恢复 $PC$。

- C 正确。嵌套调用时，后一次调用会覆盖前一次调用尚未使用的返回地址，因此通常把返回地址压入栈中，按后进先出方式保存；非嵌套调用时返回地址不会被覆盖，可保存在特定寄存器中。

- D 错误。调用指令执行时确实是无条件转移到目标地址处，但目标地址必须由指令给出。它可以是直接地址，也可以通过寄存器、存储器间接给出，但指令中至少要给出寻址所需的寄存器号或存储单元信息；若完全无须给出，CPU 无法知道转子到何处。

**易错点**：

1. 误判 A：认为高级语言过程调用还需要传参、建栈帧，不可能只对应一条指令。要区分“过程调用的控制转移”和“完整的过程调用序列”；真正执行“保存返回地址 + 转移”的是那一条调用指令。
2. 把返回地址记成调用指令本身的地址。返回地址是调用指令后一条指令的地址，不是调用指令地址。
3. 混淆调用指令和返回指令。返回指令的目标地址可从栈或链接寄存器获得，不需要明显给出；但调用指令必须给出子程序入口地址相关信息。
4. 把“间接给出目标地址”误认为“无须给出目标地址”。间接寻址时，指令中仍然要给出寄存器号或存储器地址。

**命题规律**：该题考查指令系统中的“调用/转子指令”机制，常见变式包括：调用指令执行时 $PC$、栈指针如何变化；为什么嵌套调用和递归要用栈保存返回地址；`CALL` 与 `JMP` 的区别；RISC-V/MIPS 中 `jal`、`bl`、`ret` 等指令如何保存和恢复返回地址。复习时抓住“保存返回地址 + 无条件转移到子程序入口”两步，并与普通无条件转移指令对比即可。

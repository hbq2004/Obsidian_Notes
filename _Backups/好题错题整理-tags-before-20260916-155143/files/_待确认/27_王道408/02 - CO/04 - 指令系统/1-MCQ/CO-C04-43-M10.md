# 选择题 第 10 题

![[_Attachments/题目识别/27_王道408-题目/CO-C04-43-M10_题目.png|题目]]

10. 下列关于循环结构语句的机器级代码表示的叙述中，错误的是（ ）.

A. 一定至少包含一条条件转移指令
B. 不一定包含无条件转移指令
C. 循环结束条件可以用一条比较指令 CMP 来实现
D. 循环体内执行的指令不包含条件转移指令

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C04-43-M10_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。循环体内部可以嵌套 `if`、`switch` 等分支结构，对应机器码中会出现条件转移指令，因此“循环体内执行的指令不包含条件转移指令”说法过于绝对，是错误的。

**解题切入点**：拿到题先抓住循环机器码的两个关键：条件判断和跳回循环头。循环至少要有一个“判断是否退出”的条件转移；但需不需要无条件转移，取决于条件判断放在循环入口还是循环出口。选项中的“一定”“不一定”“不包含”都是绝对化表述，逐一用典型汇编骨架检验即可。

**推演**：

条件转移指令的语义是：

$$
PC \leftarrow 
\begin{cases}
\text{目标地址}, & \text{条件成立}\\
PC + \ell, & \text{条件不成立}
\end{cases}
$$

无条件转移指令的语义是：

$$
PC \leftarrow \text{目标地址}
$$

对选项逐一分析。

A 正确：对于通常讨论的带结束条件的循环，机器码中至少需要一条条件转移指令，用来根据循环条件决定继续循环还是退出循环。如果没有条件转移，就无法实现“条件的循环”。

B 正确：循环不一定包含无条件转移指令。例如 `do-while` 型循环可翻译为：

```asm
loop:
    循环体主体
    CMP 结束条件
    Jcc loop       ; 条件满足则跳回循环
```

这里只用了一条条件转移指令，没有无条件转移指令。

C 正确：循环结束条件可以通过比较指令 `CMP` 设置条件码，再配合条件转移指令完成判断。`CMP` 不改变目标操作数，只影响标志位，是常用的循环条件比较方式。

D 错误：循环体内可以嵌套分支结构，例如：

```c
while (i < N) {
    if (a[i] < 0) count++;
    i++;
}
```

其机器级代码片段可能是：

```asm
.Lloop:
    cmp i, N
    jge .Lexit       ; 外层循环控制的条件转移
    cmp a[i], 0
    jge .Lskip       ; 循环体内 if 语句对应的条件转移
    inc count
.Lskip:
    inc i
    jmp .Lloop
.Lexit:
```

其中 `jge .Lskip` 就是循环体内执行到的条件转移指令。因此不能断言循环体内的指令一定不包含条件转移指令。

**易错点**：

- 误以为循环一定需要无条件转移指令；实际上 `do-while` 型循环可以只用条件转移跳回循环头。
- 误以为循环体一定是“直线代码块”；循环体内可以包含 `if`、`switch`、`?:`、`&&`、`||` 等，都会产生条件转移。
- 注意 `CMP` 本身不跳转，它只设置条件码；需要配合 `Jcc` 条件转移指令才能实现循环结束条件判断。
- 不要用 `while(1);` 这类无限循环特例去否定 A。统考本题默认讨论的是具有循环结束条件的普通循环结构。

**命题规律**：考点是高级语言循环结构到机器级代码的映射，重点考查条件转移指令、无条件转移指令、比较指令的配合关系。常见变式有：`while` 与 `do-while` 翻译差异、循环体内嵌套条件分支的机器代码、`break` 和 `continue` 对应的跳转指令等。复习时应多画控制流图，尤其注意“不一定”“一定不”这类绝对化表述，举出反例即可快速判断。

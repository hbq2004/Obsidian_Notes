# 选择题 第 22 题

![[_Attachments/题目识别/27_王道408-题目/CO-C04-42-M22_题目.png|题目]]

22. 下列关于指令寻址与数据寻址的描述中,错误的是

(A) 中断响应时,中断隐指令的执行不属于指令寻址的范畴

(B) 指令格式中,每个操作数字段均需通过显式编码或隐含约定确定其寻址方式

(C) 在含 $Cache$ 的系统中,指令访存遵循"$Cache$ 优先"原则,未命中时再访问主存

(D) 数据寻址方式不属于指令集体系结构($ISA$)规定的内容

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C04-42-M22_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。理由：数据寻址方式（如立即、直接、间接、变址、基址等）是指令集体系结构（ISA）明确规定的核心内容，而非“不属于 ISA 规定的内容”。

**解题切入点**：拿到题目先区分两个核心概念——**指令寻址**与**数据寻址**。指令寻址解决“下一条要执行的指令在哪里”，数据寻址解决“本条指令的操作数在哪里”。选项 D 直接考察 ISA 的范畴，需要知道 ISA 规定了指令格式、寻址方式、寄存器、数据类型等。可类比算法竞赛中“接口规范”：题目给你的输入输出格式、数据范围就是 ISA，任何解法都必须遵守它；寻址方式是 CPU 与编译器之间的“接口约定”，当然属于 ISA。

**推演**：

逐项分析：

- **选项 A**：中断响应时，CPU 硬件自动执行“中断隐指令”，其功能包括关中断、保存断点、取出中断服务程序入口地址等。这个过程中“保存断点、转向中断服务程序”涉及 PC 的更新，但它是中断响应机制的硬件操作，不是指令系统中真正存在的指令，更不属于“指令寻址”的范畴。指令寻址只讨论**程序内正常取指过程**中如何确定下一条指令地址（顺序寻址 $PC \leftarrow PC + 1$ 或跳跃寻址）。因此 A 正确。

- **选项 B**：指令中每个操作数字段都必须能确定其寻址方式。寻址方式可以通过操作码隐含约定（例如某些机器中加法指令的操作数默认为寄存器寻址），也可以在指令中设置专门的寻址方式字段（显式编码）。无论哪种方式，都不是“无来源”的。因此 B 正确。

- **选项 C**：在包含 $Cache$ 的存储系统中，CPU 访存（包括取指令）首先访问 $Cache$。若命中，直接从 $Cache$ 取得指令；若未命中，才访问主存，并可能将所在块调入 $Cache$。这就是“$Cache$ 优先”原则，即局部性原理的具体体现。因此 C 正确。

- **选项 D**：数据寻址方式的定义直接决定指令如何解析操作数，例如：
  - 立即寻址：操作数在指令中；
  - 直接寻址：有效地址 $EA = A$，其中 $A$ 为指令中地址字段；
  - 间接寻址：$EA = (A)$；
  - 变址寻址：$EA = A + (IX)$；
  - 基址寻址：$EA = A + (BR)$。
  
  这些寻址规则必须由 ISA 规定，编译器和汇编器才能生成正确的机器指令，CPU 才能按照统一规则译码执行。因此“数据寻址方式不属于 ISA 规定的内容”是错误的。

综上，错误的是 D。

**易错点**：

1. **误选 A**：认为“中断隐指令”中有“指令”二字，且保存断点涉及 PC，就以为它属于指令寻址。实际上“中断隐指令”是硬件自动完成的中断响应操作，不是程序指令，更不属于指令寻址。
2. **误选 C**：有的同学认为指令访存应先访问主存，再判断是否在 $Cache$，这是对存储层次工作方式的误解。CPU 先访问 $Cache$，命中则不再访问主存；未命中才访问主存，同时进行替换或调入。
3. **误选 B**：忽略了“隐含约定”也是一种确定寻址方式的方式，以为必须显式设置寻址方式字段，这是对指令格式设计不熟悉。
4. **对 ISA 范畴记忆不清**：ISA 不仅包含指令助记符和操作码，还包含寻址方式、寄存器定义、数据类型、存储器模型等。本题 D 正是考查这一点。

**命题规律**：

本考点属于“指令系统”部分，重点考查指令寻址与数据寻址的基本概念、ISA 的组成、存储系统中 $Cache$ 的工作方式。常见变式包括：
- 给出具体指令，判断其寻址方式；
- 结合中断过程，判断哪些操作属于中断隐指令；
- 结合 $Cache$ 命中率，计算平均访存时间；
- 判断某句关于 ISA 的描述是否正确。

复习建议：将指令寻址（下一条指令地址）与数据寻址（操作数地址）彻底区分开；熟记常见数据寻址方式的地址计算公式与有效地址 $EA$ 的求法；理解 ISA 是整个软硬件接口的“公约”，凡是编译器和 CPU 都需要共同遵守的规则都属于 ISA 内容。做选择题时，对“绝对化”或“归属错误”的表述要特别敏感。

# 选择题 第 4 题

![[_Attachments/题目识别/27_王道408-题目/CO-C04-43-M04_题目.png|题目]]

4. 某 C 语言程序中对数组变量 $b$ 的声明为 `int b[10][5];`，有一条 `for` 语句如下：

```c
for (i=0; i<10; i++)
  for (j=0; j<5; j++)
    sum += b[i][j];
```

假设执行到 `sum += b[i][j];` 时，`sum` 的值在 `eax` 中，`b[i][0]` 所在地址在 `edx` 中，`j` 在 `esi` 中，则 `sum += b[i][j];` 所对应的指令（Intel 格式）可以是（ ）

(A) `add dword ptr eax, [edx + esi * 4]`
(B) `add dword ptr eax, [esi + edx * 4]`
(C) `add dword ptr eax, [edx + esi * 2]`
(D) `add dword ptr eax, [esi + edx * 2]`

## DeepSeek V4 Flash Max 解析

**答案**：A。理由：`b[i][j]` 的地址为 `b[i][0]` 所在地址（`edx`）加上 `j * sizeof(int)`，即 `edx + esi * 4`，因此对应指令为 `add dword ptr eax, [edx + esi * 4]`。

**解题切入点**：拿到题目先识别“数组元素地址如何计算”。`b` 是 `int` 型二维数组，`int` 占 4 字节，所以 `b[i][j]` 相对于 `b[i][0]` 的偏移量是 `j * 4`。题目已经给出 `b[i][0]` 地址在 `edx`，`j` 在 `esi`，因此只需要把 `edx` 当作基址，`esi` 乘以比例因子 4 作为变址。这种“基址 + 变址 × 比例”的寻址方式，类似算法竞赛中“用指针头地址加下标偏移”的访问思路。

**推演**：

二维数组 `int b[10][5]` 在内存中按行优先连续存放。对于第 $i$ 行第 $j$ 列元素：

- $b[i][0]$ 的地址已经存放在寄存器 `edx` 中；
- $j$ 的值存放在寄存器 `esi` 中；
- 每个 `int` 元素占 4 字节；
- 因此：
  $$
  \text{addr}(b[i][j]) = \text{addr}(b[i][0]) + j \times 4
  $$
  即：
  $$
  \text{addr} = [edx]_{地址} + [esi]_{值} \times 4
  $$

Intel 格式的寻址表达式为：
$$
[edx + esi * 4]
$$

`sum` 在 `eax` 中，指令要将内存单元 `b[i][j]` 的值加到 `eax`，因此指令应为：
```
add dword ptr eax, [edx + esi * 4]
```
其中 `dword ptr` 表示内存操作数大小为双字（4 字节），与 `int` 类型一致。

对比选项：

- A：`[edx + esi * 4]`，正确；
- B：`[esi + edx * 4]`，把 `edx` 当成了比例变址，比例因子应为 4 但 `edx` 是基址，明显错误；
- C：`[edx + esi * 2]`，比例因子 2 与 `int` 的 4 字节不符；
- D：`[esi + edx * 2]`，基址/变址关系及比例因子均错误。

**易错点**：

1. 混淆基址与变址：`edx` 保存的是本行首元素地址，应作为基址；`esi` 保存的是列下标，应作为变址。不能把二者颠倒。
2. 比例因子弄错：题目明确 `int` 占 4 字节，因此下标 `j` 要乘以 4，不能写成 2 或 1。
3. 忽略 `dword ptr` 的作用：这里内存操作数是 4 字节，选项均给出 `dword ptr`，但实际考试中要留意操作数大小与类型匹配。
4. 指令格式记忆偏差：Intel 格式中 `比例因子 * 变址 + 基址` 写成 `[基址 + 变址 * 比例]`，比例因子必须是 1、2、4、8 之一，本题只能用 4。

**命题规律**：本题属于“指令系统”与“数据的表示和存储”结合型考点，主要考查 Intel 指令的寻址方式与 C 语言数组地址计算的映射。常见变式有：把数据类型换成 `short`（比例因子 2）或 `char`（比例因子 1）；把 `b[i][0]` 地址换成 `b` 首地址，此时还要加上 $i \times 5 \times \text{元素大小}$；或者给出 `b[j][i]` 等不同下标顺序。复习时应掌握：

- 数组元素的地址公式：$\text{addr}(a[i]) = \text{base} + i \times \text{size}$；
- Intel 寻址的通用形式：`[基址 + 变址 × 比例 + 偏移]`；
- 不同数据类型对应的比例因子（`char=1`、`short=2`、`int=4`、`double=8`）；
- 寄存器中存放地址还是数值要看清，避免基址/变址颠倒。

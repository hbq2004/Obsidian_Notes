# 综合题 第 1 题

![[_Attachments/题目识别/27_王道408-题目/CO-C04-43-F01_题目.png|题目]]

1.【2017统考真题】在按字节编址的计算机 $M$ 上，f1 部分源程序（阴影部分）如下。将 f1 中的 int 都改成 float，可得到计算 $f(n)$ 的另一个函数 f2.

```c
int f1(unsigned n) {
    int sum=1, power=1;
    for(unsigned i=0; i<=n-1; i++) {
        power *= 2;
        sum += power;
    }
    return sum;
}
```

对应的机器级代码（包括指令的虚拟地址）如下：

```asm
1   00401020   55             push ebp
...   ...         ...
    for(unsigned i=0; i<=n-1; i++)
...   ...         ...
20  0040105E   39 4D F4      cmp dword ptr [ebp-0Ch], ecx
...   ...         ...
    { power *= 2;
...   ...         ...
23  00401066   D1 E2         shl edx, 1
...   ...         ...
    return sum;
...   ...         ...
35  0040107F   C3            ret
```

其中，机器级代码行包括行号、虚拟地址、机器指令和汇编指令.

(1) 计算机 $M$ 是 RISC 还是 CISC? 为什么?

(2) f1 的机器指令代码共占多少字节? 要求给出计算过程.

(3) 第 20 条指令 cmp 通过 $i$ 减 $n-1$ 实现对 $i$ 和 $n-1$ 的比较. 在执行 f1(0) 的过程中，当 $i=0$ 时，cmp 指令执行后，进位/借位标志 $CF$ 的内容是什么? 要求给出计算过程.

(4) 第 23 条指令 shl 通过左移操作实现了 power*2 运算，那么在 f2 中能否用 shl 指令实现 power*2? 为什么?

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C04-43-F01_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：
(1) CISC，因为指令长度可变（如 push 1B、cmp 3B、shl 2B、ret 1B），符合 CISC 特征。  
(2) 96 字节。计算过程：第 1 条指令地址 0x00401020，第 35 条指令（ret）地址 0x0040107F，ret 占 1B，函数结束地址为 0x00401080，故代码总字节数 = 0x00401080 - 0x00401020 = 0x60 = 96。  
(3) CF = 1。执行 f1(0) 时 n=0，n-1 = 0 - 1（无符号），结果为 0xFFFFFFFF。cmp 执行 i - (n-1) = 0 - 0xFFFFFFFF，无符号减法产生借位，故 CF=1。  
(4) 不能。因为 float 采用 IEEE 754 标准，其二进制位分为符号、阶码和尾数，左移会破坏该结构，不能正确实现乘以 2；而整数左移低位补 0 等价于乘以 2。f2 中应使用浮点乘法指令或加法指令。

**解题切入点**  
拿到题目先快速扫描整体：给出 C 代码与部分汇编/机器指令，涉及指令集架构、代码长度计算、标志位判断和浮点运算。①从指令长度是否固定判断 RISC/CISC；②利用已给虚拟地址求差得到代码长度；③结合无符号减法规则分析 CF；④区分整数与浮点数的表示方式，判断左移的适用性。类似算法竞赛中“读题定位知识点，再套用规则”的思路。

**推演**  
(1) 观察指令：push ebp 为 1 字节（55），cmp dword ptr [ebp-0Ch], ecx 为 3 字节（39 4D F4），shl edx, 1 为 2 字节（D1 E2），ret 为 1 字节（C3）。指令长度不统一，且 x86 架构属于典型的 CISC，故答案为 CISC。  

(2) 已知第 1 条指令虚拟地址 0x00401020，第 35 条指令（ret）虚拟地址 0x0040107F，ret 占 1 字节，故函数代码结束地址为 0x00401080。代码总字节数：  
$$0x00401080 - 0x00401020 = 0x60 = 96 \text{ 字节}$$  
也可通过第 1 条与第 20 条、第 20 条与第 23 条等地址差验证连续性，但直接用首尾地址差最简洁。  

(3) 执行 f1(0) 时，n=0，n-1 在无符号整数下为 0xFFFFFFFF。cmp 指令执行 $i - (n-1)$，即 $0 - \text{0xFFFFFFFF}$。无符号减法中，若被减数小于减数，则产生借位，进位/借位标志 CF=1。计算过程：  
$$0 - \text{0xFFFFFFFF} = 1 \text{（有借位）}$$  
故 CF=1。  

(4) 整数用补码表示，左移一位（低位补 0）相当于乘以 2。而 float 遵循 IEEE 754 标准，32 位 float 由 1 位符号、8 位阶码、23 位尾数构成。左移操作会随机改变符号、阶码和尾数，无法得到乘以 2 的正确结果。例如，将浮点数的二进制位左移，可能使阶码增加，但尾数部分也会被移位，导致数值错误。因此 shl 指令不能用于 float 类型实现乘以 2。

**易错点**  
- 对 CISC 的判断：误以为指令条数多就是 CISC，关键看指令长度是否固定与寻址方式是否丰富。  
- 代码长度计算：未考虑最后一条指令占用的字节，或直接用最后一条指令地址减第一条指令地址（少加了最后一条指令的长度）。  
- CF 标志位：混淆无符号减法与带符号减法，或忽略 n=0 时 n-1 的无符号溢出。  
- 浮点左移：误以为左移对任何数据类型都等价于乘以 2，忽略了浮点数的特殊表示。

**命题规律**  
- 考点：指令集架构（RISC/CISC）、指令编码与地址计算、条件标志位（CF）、整数与浮点数的表示与运算。  
- 常见变式：给定不同汇编片段判断架构；通过地址差计算代码长度；结合循环条件分析标志位；将整数运算改为浮点并考察指令可行性。  
- 复习建议：熟记 CISC 与 RISC 的典型特征（如 x86 指令长度可变、ARM 固定长度）；掌握十六进制地址计算；理解无符号减法 CF 的生成规则（借位时 CF=1）；深入理解 IEEE 754 标准，区分整数与浮点数的运算指令。

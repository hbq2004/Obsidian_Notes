# 选择题 第 32 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M32_题目.png|题目]]

32. 在磁盘存储器进行读/写操作之前，$CPU$ 需要对磁盘控制器或 $DMA$ 控制器进行初始化。在下列选项中，不包含在初始化信息中的是（ ）.

(A) 传送信息所在的主存起始地址  
(B) 传送方向（是读磁盘还是写磁盘）  
(C) 传送信息所在的通用寄存器编号  
(D) 传送数据的字数或字节数

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M32_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。DMA/磁盘控制器初始化需要给出主存起始地址、传送方向和传送长度，以确定数据从哪里来、到哪里去、搬多少；DMA 传送不经过 CPU 通用寄存器，因此不需要通用寄存器编号。

**解题切入点**：先定位考点：DMA 控制器初始化。看到“不包含”，可逐项对照 DMA 工作所需的参数：数据位置、方向、长度、设备命令。好比给一个自动搬运硬件下任务，只需要告诉它“仓库地址、搬运方向、搬运件数”，不需要告诉它“程序里某个局部变量叫什么”。

**推演**：

1. DMA 方式下，数据在主存与磁盘之间直接传送，不需要 CPU 逐字/逐字节搬运。CPU 在传送前要做“初始化”工作，即向磁盘控制器/DMA 控制器写入控制信息。  
2. DMA 控制器需要知道本次传送的完整任务，至少包括：

   - 主存首地址：数据在主存中的起始位置，DMA 控制器才能确定从哪个内存单元开始读/写；
   - 传送方向：是“磁盘读入内存”还是“内存写往磁盘”，DMA 控制器据此产生相应的存储器读/写控制和 I/O 读/写控制；
   - 传送字数或字节数：DMA 控制器需要知道本次数据块的长度，以便在传送完指定数量后停止并发出中断。

   可用集合表示为：
   $$
   \text{DMA 初始化信息}=\{\text{主存起始地址},\text{传送方向},\text{传送长度}\}
   $$

3. 逐项分析选项：

   - A 主存起始地址：必须包含。没有它，DMA 不知道数据放在内存哪里。
   - B 传送方向：必须包含。读磁盘和写磁盘对应数据流方向相反，控制逻辑必须知道方向。
   - C 通用寄存器编号：不需要。DMA 的数据通路是“磁盘/DMA 控制器/主存”，不经过 CPU 通用寄存器。
   - D 传送字数或字节数：必须包含。没有长度，DMA 无法判断何时结束。

4. 因此正确答案是 C。

**易错点**：

1. 误以为“传送方向”是 CPU 自己执行指令控制的，不用告诉 DMA。实际上 DMA 控制器需要方向信号才能正确控制数据流向。
2. 把 DMA 与程序查询方式、中断方式混淆。程序查询/中断方式中，CPU 可能用通用寄存器暂存数据；但 DMA 方式下数据不经过通用寄存器。
3. 忽略“传送字数/字节数”的作用。它是 DMA 控制器中“字计数器”的初值，决定本次传送何时结束。
4. 把“DMA 控制器中的寄存器”误当成“CPU 通用寄存器”。题目问的是通用寄存器编号，属于 CPU 内部资源，DMA 初始化不会涉及。

**命题规律**：本题属于 I/O 方式中的高频考点，主要考查 DMA 控制器的初始化和 DMA 的工作特点。常见变式有：“DMA 控制器中不包含哪些寄存器”“DMA 传送前 CPU 应完成哪些工作”“DMA 传送结束后如何通知 CPU”“DMA 方式与中断方式的区别”。复习时应重点掌握 DMA 的数据通路、初始化参数、DMA 控制器基本寄存器（主存地址寄存器、字计数器、控制/状态寄存器、数据缓冲寄存器），并注意与程序查询和中断方式进行对比。

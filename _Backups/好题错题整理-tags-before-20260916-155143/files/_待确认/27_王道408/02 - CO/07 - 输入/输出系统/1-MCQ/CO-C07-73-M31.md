# 选择题 第 31 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M31_题目.png|题目]]

31. 启动一次 $DMA$ 传送，外设和主机之间将完成一个（ ）的数据传送。

A. 字节  
B. 字  
C. 总线宽度  
D. 数据块

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M31_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。一次 DMA 传送是以数据块为单位在外设与主机之间成批交换数据，因此选 D。

**解题切入点**：看到“DMA 传送”，先要抓住 DMA 与传统程序控制方式（查询、中断）的本质区别：CPU 只负责初始化，之后由 DMA 控制器接管总线，成块地搬运数据。做题时可类比“快递整箱运输”：DMA 不是每次只送一件，而是把一整箱货（数据块）一次性交给对方，CPU 只需在开头写好地址和数量。

**推演**：
DMA（Direct Memory Access）用于高速外设与内存之间直接交换数据。其工作过程通常分为三个阶段：

1. 预处理：CPU 向 DMA 控制器写入主存起始地址、传送方向、数据块长度等参数，然后启动 DMA。
2. 数据传送：DMA 控制器接管总线，按总线周期连续完成数据块中各个数据单元的传送。每传送一个数据单元，DMA 控制器修改地址计数器并判断是否为最后一个单元。
3. 后处理：数据块传送完毕后，DMA 控制器向 CPU 发出中断请求，报告传送结束。

由上述过程可知，CPU 在预处理阶段给出的“数据块长度”决定了本次 DMA 传送的总规模。DMA 每次“启动”对应一次完整的成块传送，而不是只传送一个字节、一个字或一个总线宽度。需要注意的是：
- 单个总线周期内，DMA 可传送的数据量受总线宽度限制（如一次传送 32 位，即一个字）；
- 但“启动一次 DMA 传送”指的是连续完成整个数据块，而不是只完成一个总线周期。

因此，外设和主机之间一次 DMA 传送完成一个数据块的数据传送，答案选 D。

若从选项辨析角度：
- A. 字节：程序查询方式或中断方式可以按字节传送，不是 DMA 的基本单位。
- B. 字：单次总线操作可传一个字，但不是“启动一次 DMA 传送”的完整语义。
- C. 总线宽度：决定每次总线操作能传多少个二进制位，与“启动一次 DMA 传送”的单位不同。
- D. 数据块：DMA 正是以数据块为传送单位，故正确。

**易错点**：
1. 混淆“单次总线操作”与“一次 DMA 传送”。单次总线操作传送 $\text{总线宽度}$ 位（通常为一个字），而一次 DMA 传送包含多次总线操作，整体形成一个数据块。若只看 DMA 控制器与内存之间每次握手，容易误选 B 或 C。
2. 把 DMA 与中断传送方式混淆。中断方式每次传送一个字节或一个字，需要 CPU 介入；DMA 则成块传送，CPU 只在预处理和后处理时介入。抓住“成块”这一特征即可避开 A、B。
3. 忽略题目问的是“外设和主机之间”。外设与主机之间的数据传送在 DMA 方式下以数据块为逻辑单位，而不是以总线宽度为物理单位。

**命题规律**：这是计算机组成原理中“输入输出系统”部分的常见基础题，考查 DMA 方式的基本概念。常见变式包括：
- 问 DMA 传送前 CPU 需要初始化哪些参数（主存起始地址、传送字节数、传送方向等）；
- 问 DMA 与中断方式的区别（传送单位、CPU 介入时机、优先级等）；
- 结合总线宽度计算 DMA 传送速率，例如总线宽度为 $32$ 位、时钟频率为 $f$，则理论最高传输率为 $4f$ 字节/秒；
- 考查 DMA 传送过程中 CPU 与外设并行工作的特点。

复习建议：重点掌握 DMA 的工作流程、传送单位、与中断方式的对比，以及 DMA 控制器内部寄存器的功能（地址寄存器、字数计数器、控制/状态寄存器等）。做题时先抓住“DMA = 成块传送”这一核心，再结合总线周期和时钟频率进行定量计算。

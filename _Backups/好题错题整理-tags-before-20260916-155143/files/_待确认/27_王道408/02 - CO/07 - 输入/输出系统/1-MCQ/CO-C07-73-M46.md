# 选择题 第 46 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M46_题目.png|题目]]

46.【2020统考真题】外部中断包括不可屏蔽中断（$NMI$）和可屏蔽中断，下列关于外部中断的叙述中，错误的是（ ）.
(A) $CPU$处于关中断状态时，也能响应$NMI$请求
(B) 一旦可屏蔽中断请求信号有效，$CPU$将立即响应
(C) 不可屏蔽中断的优先级比可屏蔽中断的优先级高
(D) 可通过中断屏蔽字改变可屏蔽中断的处理优先级

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M46_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。可屏蔽中断请求信号有效只是 CPU 响应的必要条件，CPU 还必须在开中断状态、当前指令执行结束后并满足判优条件时才能响应，不能“立即响应”。

**解题切入点**：看到“外部中断、$NMI$、可屏蔽中断”，应立即定位到中断响应条件与中断优先级。可以把 CPU 比作正在执行任务的处理单元：$NMI$ 是“不可屏蔽的最高紧急警报”，即使总开关关闭也能响；可屏蔽中断是“普通中断请求”，必须总开关打开且当前任务结束后才会受理。

**推演**：

外部中断分为不可屏蔽中断（$NMI$）和可屏蔽中断（如 $INTR$）。

- 对于 $NMI$，它不受中断允许标志的影响。即使 $CPU$ 处于“关中断”状态，$NMI$ 请求仍可被响应，因此选项 A 正确。
- 对于可屏蔽中断，$INTR$ 信号有效并不代表 $CPU$ 会立即响应。$CPU$ 必须满足：当前指令执行结束；处于开中断状态；没有更高优先级的中断请求，或判优后选中该中断。因此“一旦请求有效就立即响应”说法错误，选项 B 错误。
- 在外部中断范围内，$NMI$ 的优先级高于可屏蔽中断，因此选项 C 正确。
- 中断屏蔽字可以屏蔽或开放某些可屏蔽中断源，从而改变各可屏蔽中断之间的“处理优先级”，例如实现多重中断时让高优先级中断打断低优先级中断服务程序。因此选项 D 正确。

所以错误的是 B。

**易错点**：

- 误以为“关中断”能屏蔽所有中断，实际上 $NMI$ 不受中断允许位影响，仍然可以响应。
- 误以为中断请求有效就一定会立即响应，忽略了“当前指令执行完毕”“开中断”“判优”等条件。
- 混淆“响应优先级”和“处理优先级”。硬件判优确定的响应优先级通常固定，但中断屏蔽字可以改变中断的处理优先级，因此 D 不是错误项。

**命题规律**：

本题属于外部中断的基本概念题，核心考点是 $NMI$ 与可屏蔽中断的响应条件、优先级关系以及中断屏蔽字的作用。常见变式包括：结合中断允许标志 $IF$ 判断哪些中断能被响应、判断中断响应时机、考查多重中断中屏蔽字如何决定中断嵌套关系。复习时应重点掌握“中断响应是有条件的”，并明确区分“响应优先级”和“处理优先级”。

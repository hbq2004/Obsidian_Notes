# 选择题 第 50 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M50_题目.png|题目]]

50.【2023统考真题】下列关于硬件和异常/中断关系的叙述中,错误的是（ ）

A. $CPU$在执行一条指令的过程中检测异常事件

B. $CPU$在执行完一条指令时检测中断请求信号

C. 开中断时$CPU$检测到中断请求后就进行中断响应

D. 外部设备通过中断控制器向$CPU$发中断结束信号

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M50_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。外部设备通过中断控制器发给 CPU 的是“中断请求信号”，并非“中断结束信号”；中断结束信号（EOI）通常由 CPU 发送给中断控制器（或由中断控制器自动发出）。

**解题切入点**：先抓住异常与中断在“检测时机”上的根本区别——异常是 CPU 内部产生的同步事件，在指令执行过程中检测；外部中断是异步事件，只能在指令执行完的边界检测。再看各选项涉及的信号方向，特别是“中断请求”和“中断结束”很容易被偷换概念。

**推演**：

- **A 正确**：异常（如除零、缺页、溢出等）与当前正在执行的指令相关，必须在指令执行过程中检测，才能确定异常发生在哪条指令、哪个阶段。若等到指令执行完才检测，就无法精确定位异常原因。

- **B 正确**：外部中断请求来自 CPU 外部，何时到来不可预知。为避免打断当前未执行完的指令，CPU 只在每条指令执行结束的时刻统一检测中断请求信号，以决定是否进入中断响应周期。

- **C 正确**：中断响应的条件可概括为：
  $$响应 = 中断请求 \land 开中断 \land 当前指令执行完$$
  当 CPU 处于“开中断”状态时，在指令执行完的采样点检测到中断请求，就会进入中断响应。C 的表述是这一过程的简写，不算原则性错误。

- **D 错误**：外部设备需要申请中断时，是向中断控制器发出“中断请求信号”（如 INT），再由中断控制器向 CPU 发出中断请求。而“中断结束信号”（EOI）是在中断服务程序结束前后，由 CPU 发送给中断控制器，用于通知本次中断处理完毕，并非外部设备通过中断控制器向 CPU 发送。

**易错点**：

1. **混淆异常和中断的检测时机**：异常在指令执行过程中检测，外部中断在指令执行完检测，两者不能颠倒。
2. **误认为 C 错**：C 省略了“当前指令执行完毕”这一条件，但结合 B 可知中断请求本来就在指令执行完时检测，故 C 不是明显错误；应优先找更硬的概念错误 D。
3. **信号方向不清**：常把“中断请求信号”和“中断结束信号”混为一谈，答题时要注意是“谁发给谁”。
4. **忽略中断响应的必要条件**：响应需要同时满足有请求、开中断、指令执行完，缺少任意一个都不能进入中断响应。

**命题规律**：本题属于“异常与中断”的硬件机制，是 408 常考点。常见变式有：考查中断响应的完整条件、中断隐指令的执行内容、中断向量与中断服务程序入口地址的关系、中断屏蔽字的设置等。复习时应把“中断请求→中断允许→指令执行完→中断响应→中断服务→中断返回”的完整流程串起来，并注意区分异常与中断、中断请求与中断结束信号，可结合时序图加深记忆。

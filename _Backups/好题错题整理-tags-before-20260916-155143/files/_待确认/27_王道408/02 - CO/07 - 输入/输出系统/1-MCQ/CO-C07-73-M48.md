# 选择题 第 48 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M48_题目.png|题目]]

48.【2021统考真题】下列关于多重中断系统中 $CPU$ 响应中断的叙述,错误的是( ).

(A) 仅在用户态(执行用户程序)下,$CPU$ 才能检测和响应中断  
(B) $CPU$ 只有在检测到中断请求信号后,才会进入中断响应周期  
(C) 进入中断响应周期时,$CPU$ 一定处于中断允许(开中断)状态  
(D) 若 $CPU$ 检测到中断请求信号,则一定存在未被屏蔽的中断源请求信号

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M48_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A。理由：CPU 在核心态（管态）下同样能检测和响应中断，并非仅限于用户态。

**解题切入点**：题目考查多重中断系统中 CPU 响应中断的基本条件，关键在于理解中断响应与 CPU 当前运行状态（用户态/核心态）无关，而与中断允许标志位（开中断）有关。可类比“安检流程”：无论乘客是普通旅客（用户态）还是工作人员（核心态），只要安检通道开放（开中断），有警报（中断请求）就会触发检查（响应中断）。

**推演**：
- 选项 A：中断响应是 CPU 在每条指令执行结束后，根据中断请求信号和中断允许标志决定是否进入中断响应周期。CPU 在核心态（执行操作系统内核程序）时，同样可能响应中断（例如内核程序运行时发生时钟中断或 I/O 中断），因此“仅在用户态下”是错误的。
- 选项 B：中断响应周期由中断请求信号触发，若无中断请求，CPU 正常执行下一条指令，不会进入中断响应周期。故正确。
- 选项 C：中断响应周期只在 CPU 处于开中断（中断允许）状态时才会进入；若关中断，即使有中断请求，CPU 也会延迟响应。故正确。
- 选项 D：CPU 检测到的中断请求信号通常是经过中断屏蔽字筛选后的有效信号，若检测到，则表明至少有一个未被屏蔽的中断源发出了请求。故正确。

综上，A 为错误选项。

**易错点**：
1. 误认为核心态（管态）下 CPU 不响应中断，实际上核心态通常允许响应高优先级中断（如紧急硬件故障），只是部分中断可能被屏蔽。
2. 混淆“中断响应”与“中断处理”：中断响应是硬件自动完成的操作（如关中断、保存断点、取中断向量），而中断处理由软件完成。响应条件与开中断直接相关，但与用户态/核心态无必然联系。

**命题规律**：本题属于中断基础概念识记类题目，常以“下列说法正确的是/错误的是”形式出现。常见变式包括：判断中断响应条件（是否必须开中断、是否必须结束当前指令）、中断响应周期完成的动作、中断屏蔽的作用等。复习时应重点掌握中断响应流程（指令执行结束→检测中断请求→若开中断且无更高优先级中断则响应），并区分用户态和核心态下中断响应的异同。

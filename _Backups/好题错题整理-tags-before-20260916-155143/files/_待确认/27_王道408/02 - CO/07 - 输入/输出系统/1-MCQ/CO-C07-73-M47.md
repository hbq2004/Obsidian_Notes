# 选择题 第 47 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M47_题目.png|题目]]

47.【2020统考真题】若设备采用周期挪用 $DMA$ 方式进行输入和输出,每次 $DMA$ 传送的数据块大小为 512 字节，相应的 $I/O$ 接口中有一个 32 位数据缓冲寄存器。对于数据输入过程，下列叙述中，错误的是 ( )

A. 每准备好 32 位数据,$DMA$ 控制器就发出一次总线请求

B. 相对于 $CPU$,$DMA$ 控制器的总线使用权的优先级更高

C. 在整个数据块的传送过程中,$CPU$ 不可以访问主存储器

D. 数据块传送结束时,会产生“$DMA$ 传送结束”中断请求

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M47_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C，在周期挪用 DMA 方式下，CPU 仍可访问主存，只是优先级低于 DMA；叙述“CPU 不可以访问主存储器”错误。

**解题切入点**：抓住“周期挪用”关键词，它区别于成组（突发）传送方式：每次 DMA 只占用一个或几个内存周期，其余时间 CPU 可以正常访问主存。定位到选项 C 对 CPU 可否访问主存的描述，应指整个数据块传送期间，据此判断。

**推演**：  
- 周期挪用 DMA 的特点：外设每准备好一个数据单元（32 位，即 4 字节），DMA 控制器就发出一次总线请求，获得总线控制权后传送一个数据，然后立即释放总线。  
- 因此，对于 512 字节的数据块，需传送 128 次（$512/4=128$），每次传送仅占用一个总线周期，其余时间总线归 CPU 控制，CPU 可以访问主存储器（只是当两者冲突时，DMA 优先）。  
- 选项 A：每准备好 32 位数据，DMA 就请求一次总线，正确。  
- 选项 B：DMA 请求优先级高于 CPU，以保证数据不丢失，正确。  
- 选项 C：整个数据块传送过程中，CPU 仍可访问主存（仅在被 DMA 窃取周期时等待一个周期），故“不可以访问”错误。  
- 选项 D：数据块传送完成后，DMA 控制器向 CPU 发送中断请求，进行结束处理，正确。

**易错点**：  
- 混淆周期挪用与成组（突发）传送：成组传送时，DMA 连续占用总线，CPU 在此期间无法访问主存；而周期挪用是交替占用，CPU 仍可访问。  
- 误以为 DMA 传送期间 CPU 完全不能访问主存，忽略了周期挪用的交替特性。

**命题规律**：  
- 考点定位：DMA 传送方式（周期挪用、成组传送、交替访问）的区别与特点。  
- 常见变式：比较不同方式下 CPU 与 DMA 的总线使用权、对主存访问的影响；结合数据块大小和缓冲寄存器宽度计算传送次数；与中断方式对比。  
- 复习建议：深入理解三种 DMA 方式的总线控制权切换时机，区分“每次传送窃取一个周期”与“连续占用多个周期”的差异，通过典型例题强化记忆。

# 选择题 第 3 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-72-M03_题目.png|题目]]

3. 下列关于 $I/O$ 端口和接口的说法中,正确的是 ( )

A. 在统一编址方式下,对主存单元和 $I/O$ 端口的存储保存措施是独立的
B. 在统一编址方式下,主存单元和 $I/O$ 设备是靠不同的地址线来区分的
C. 在独立编址方式下,主存单元和 $I/O$ 设备是靠不同的地址线来区分的
D. 在独立编址方式下,$CPU$ 需要设置专门的输入/输出指令访问 $I/O$ 端口

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-72-M03_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。在独立编址方式下，主存与 I/O 端口各自有独立的地址空间，CPU 必须使用专门的输入/输出指令（如 IN、OUT）访问 I/O 端口。

**解题切入点**：题目考查 I/O 端口两种编址方式。先抓住核心区别：**统一编址**本质是把 I/O 端口当作主存单元来编址，用访存指令访问；**独立编址**则是 I/O 端口单独编址，必须用专用 I/O 指令访问。再看选项，A 考保护措施，B/C 考区分方式，D 考指令，核心区别一出来就能定位答案。

**推演**：

I/O 接口中可供 CPU 访问的寄存器称为 I/O 端口，通常分为数据端口、状态端口和控制端口。CPU 访问 I/O 端口有两种编址方式。

1. 统一编址（存储器映射编址）：
   - I/O 端口与主存单元在同一个地址空间中统一编号，I/O 端口占用主存地址空间的一部分。
   - CPU 访问 I/O 端口时，使用普通访存指令（load/store），不需要专门的 I/O 指令。
   - 主存和 I/O 不是靠“不同的地址线”区分的，而是靠地址译码器根据地址落在哪个地址范围来选择主存或 I/O。故 B 错。
   - 由于 I/O 端口已纳入主存地址空间，存储保护/管理逻辑通常统一作用在这些地址上；说“保护措施独立”不符合统一编址的特点。故 A 错。

2. 独立编址（I/O 映射编址）：
   - I/O 端口与主存单元分别编址，形成两个相互独立的地址空间。
   - CPU 区分当前访问的是主存还是 I/O，主要依靠指令类型和 CPU 输出的控制信号，如 $M/\overline{IO}$，而不是靠“不同的地址线”。故 C 错。
   - 由于 I/O 使用独立地址空间，CPU 必须设置并执行专门的输入/输出指令（如 IN、OUT）才能访问 I/O 端口，访存指令不能访问 I/O 端口。故 D 对。

因此正确选项为 D。

**易错点**：
- 易把“地址范围不同”误写成“地址线不同”。地址线只是传送地址的公共通路，区分主存/I/O 的是地址译码结果或专用指令/控制信号。
- 易误认为统一编址下仍需专用 I/O 指令。事实上统一编址直接用访存指令访问 I/O 端口，只有独立编址才必须用专用 I/O 指令。
- 易忽视 A 中的“独立”：统一编址下 I/O 端口与主存共享一个地址空间，存储保护/管理措施不是相互独立的。

**命题规律**：
考点定位为“I/O 端口编址方式”，是 408 选择题常考基础题。常见变式包括：判断某种编址方式下使用什么指令、是否占用主存地址空间、优缺点比较，以及结合 $M/\overline{IO}$ 控制信号或 IN/OUT 指令考查编址方式。复习时建议整理对比表：

- 统一编址：同一地址空间、用访存指令、不设专用 I/O 指令、占用主存地址空间；
- 独立编址：独立地址空间、用专用 I/O 指令、不占用主存地址空间、需 $M/\overline{IO}$ 等控制信号区分。

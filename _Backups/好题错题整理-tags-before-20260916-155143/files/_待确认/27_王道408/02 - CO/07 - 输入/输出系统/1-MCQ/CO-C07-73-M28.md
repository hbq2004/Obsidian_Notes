# 选择题 第 28 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M28_题目.png|题目]]

28. 在 $DMA$ 方式传送数据的过程中,由于没有破坏( )的内容,所以 $CPU$ 可以正常工作(访存除外).

A. 程序计数器
B. 程序计数器和寄存器
C. 指令寄存器
D. 堆栈寄存器

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M28_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。DMA 传送数据不经过 CPU、不打断 CPU 当前程序，因此不破坏程序计数器和寄存器的内容，CPU 仍可继续执行程序（仅因总线被占用而暂时不能访存）。

**解题切入点**：拿到题先抓“DMA 方式”和“CPU 可以正常工作”这两个关键词，立刻联想到 DMA 与中断的核心区别：中断要“保护现场”，DMA 不破坏“现场”。所谓现场就是程序计数器和寄存器。可以把 DMA 理解成“硬件搬运工”，CPU 是“老板”，搬运工只在需要占用总线时让老板暂停一下手头工作，但老板办公桌上的文件和当前看到的位置都不被动。

**推演**：
- DMA 传送数据时，数据流是“外设 ↔ 主存”直接进行，由 DMA 控制器控制，不经过 CPU 内部寄存器，也不需要 CPU 执行指令来搬数据。
- 因此，DMA 操作不会修改 CPU 中的：
  - 程序计数器（PC）：它保存着 CPU 即将执行指令的地址，DMA 不会改变它；
  - 通用寄存器：保存着程序运行的中间结果，DMA 不访问它们。
- 所以 CPU 可以继续执行原来程序。唯一受影响的环节是：DMA 与 CPU 可能同时访问主存，需要争夺总线使用权。若 DMA 采用周期窃取（周期挪用）方式，CPU 会在某个访存周期暂停访存，但 CPU 内部状态不变。
- 对比：中断方式中，CPU 响应中断后必须保护断点（PC）和现场（寄存器内容），因为中断会打断当前程序，执行中断服务程序，返回时要恢复现场。DMA 则不需要，因为 DMA 不打断程序执行。
- 因此“没有破坏的内容”应指程序计数器和寄存器。选项 B 正确。

**易错点**：
- 误选 A：只想到程序计数器是“断点”，但忽略通用寄存器同样不能被破坏，DMA 不改变它们，且题目问的是“内容”包括寄存器。
- 误选 C：指令寄存器（IR）保存当前正在执行的指令，DMA 不执行指令，自然不会改 IR，但“CPU 正常工作”的关键是 PC 和寄存器，IR 会被 CPU 自己正常更新，不是 DMA 破坏的对象。
- 误选 D：堆栈寄存器（SP）属于寄存器的一部分，但表达不完整，且不是最核心的“现场”概念。
- 混淆中断和 DMA：中断需要保护现场，DMA 不需要保护现场。注意题干“访存除外”说明 DMA 只可能占用总线而使 CPU 访存暂停，并不破坏 CPU 内部状态。

**命题规律**：考点是 DMA 方式的特点及其与中断方式的区别，属于“输入输出系统”中的高频基础题。常考变式包括：DMA 是否破坏程序计数器、DMA 与中断的现场保护差异、DMA 传送期间 CPU 能否执行指令（能，但不能访存）、DMA 的三种工作方式（CPU 停止法、周期窃取、交替访存）。复习时应着重对比“中断”和“DMA”两条主线，理解“谁控制传送、是否打断程序、是否保护现场、CPU 能否继续工作”这几个维度。

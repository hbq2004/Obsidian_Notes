# 选择题 第 20 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M20_题目.png|题目]]

20. 下列关于程序查询方式及其工作过程的叙述中,正确的是（ ）

A. 按启动查询方式的不同，可分为软件查询方式和硬件查询方式

B. $CPU$ 主要负责启动外设和查询其状态，不参与数据传送

C. 每完成一次数据传送后,会修改主存地址和计数值

D. $CPU$ 需一直查询外设的状态,直到外设准备就绪时才可去执行其他程序

## 答案

## DeepSeek V4 Flash Max 解析

**答案**：C。程序查询方式中，$CPU$ 通过程序启动外设并反复查询其状态，设备就绪后 $CPU$ 亲自执行输入/输出指令完成数据传送；每传送一个数据，程序都要修改主存地址和计数值，以进行下一轮传送。

**解题切入点**：定位考点为“程序查询方式的工作流程”。拿到题目先画出流程：启动外设 → 查询状态 → 就绪后传送数据 → 修改主存地址与计数值 → 判断是否完成。抓住“$CPU$ 全程参与”这一核心特征，可迅速排除“CPU 不参与数据传送”“就绪后去执行其他程序”等错误说法。

**推演**：

- **A 错**：程序查询方式本身就是一种软件查询方式，并不存在“按启动查询方式不同分成软件查询方式和硬件查询方式”这种分类。常见的程序查询方式可按查询时机分为**独占查询**和**定时查询**，而不是“软件/硬件查询”。

- **B 错**：程序查询方式中，$CPU$ 不仅负责启动外设和查询状态，还负责实际的数据传送。数据通过 $CPU$ 读写接口中的数据缓冲寄存器，再与主存交换，因此 $CPU$ 完全参与数据传送。

- **C 对**：程序查询方式采用循环程序控制一次完整的数据交换。每完成一次数据传送，$CPU$ 都要修改主存地址（指向下一存储单元）和计数值（剩余传送次数），以便继续传送后续数据，最后判断传送是否结束。

- **D 错**：$CPU$ 确实需要一直查询外设状态，直到外设准备就绪；但就绪后 $CPU$ 要做的是**立即进行数据传送**，而不是“去执行其他程序”。整个传送过程中 $CPU$ 无法离开去做别的事，这正是程序查询方式“踏步等待”的特点。

**易错点**：

1. **把 $C$ 误判为 DMA 的特点**：DMA 方式中主存地址和计数值由 DMA 控制器自动修改，而程序查询方式中由 $CPU$ 执行程序修改，二者修改者不同。
2. **误读 $D$**：外设“准备就绪”只是可传送数据，不是“CPU 可去执行其他程序”的信号；在程序查询方式中，CPU 就绪后还要继续参与传送。
3. **被 $A$ 迷惑**：教材中“软件查询/硬件查询”不是程序查询方式的分类；程序查询方式属于软件查询方式。

**命题规律**：本题属于 $I/O$ 控制方式对比的常考选择题，常将程序查询方式与程序中断方式、DMA 方式混合考查。常见变式包括：判断某种描述属于哪种 $I/O$ 方式、比较三种方式下 $CPU$ 的角色与数据传送路径、给出流程图判断是“程序查询”还是“中断”等。复习时应重点掌握：

- 程序查询方式：$CPU$ 主动查询、全程参与、踏步等待；
- 程序中断方式：$CPU$ 响应中断、由中断隐指令进入服务程序；
- DMA 方式：$CPU$ 只在前后干预，传送由 DMA 控制器完成。

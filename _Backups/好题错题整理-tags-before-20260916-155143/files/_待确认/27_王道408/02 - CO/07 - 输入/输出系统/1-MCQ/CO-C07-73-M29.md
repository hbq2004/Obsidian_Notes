# 选择题 第 29 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M29_题目.png|题目]]

29. 在 $DMA$ 方式下,数据从内存传送到外设经过的路径是 ( ).

(A) 内存 $\to$ 数据总线 $\to$ 数据通路 $\to$ 外设  
(B) 内存 $\to$ 数据总线 $\to$ $DMAC$ $\to$ 外设  
(C) 内存 $\to$ 数据通路 $\to$ 数据总线 $\to$ 外设  
(D) 内存 $\to$ $CPU$ $\to$ 外设

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M29_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。DMA 方式下数据传送不经过 CPU，而是由 DMA 控制器（DMAC）控制，并经数据总线完成，因此路径为：内存 → 数据总线 → DMAC → 外设。

**解题切入点**：拿到题目先抓两个关键词：“DMA 方式”和“内存传到外设”。DMA 的实质是“直接存储器存取”，传送过程中 CPU 不参与数据搬运，所以应该先排除含有 CPU 的选项；再判断数据要经过的是 CPU 内部的“数据通路”还是 DMA 控制器。可理解为：普通中断传送像“快递到 CPU 中转站转一圈再发出”，而 DMA 像“专线物流”，由 DMAC 作为硬件调度/中转，数据直接在外设与内存之间流动。

**推演**：DMA 方式下，数据从内存传送到外设时，整个传送过程大致如下：

1. 传送前，CPU 对 DMAC 进行初始化，设置内存首地址、传送字数、传送方向等。
2. 当外设准备好后，DMAC 向 CPU 发出总线请求；CPU 释放总线控制权。
3. DMAC 获得总线控制权后，把内存地址送到地址总线，并发出“内存读、外设写”的控制信号。
4. 内存按地址读出数据，将数据放到数据总线上；数据经数据总线送入 DMAC，再由 DMAC 送往外设。

因此完整数据传送路径为：

$$
\text{内存} \to \text{数据总线} \to \text{DMAC} \to \text{外设}
$$

选项分析：

- A 错：路径中出现“数据通路”，通常指 CPU 内部寄存器与 ALU 之间的数据通路；DMA 数据不进入 CPU 内部。
- B 对：数据经过数据总线，并由 DMAC 控制/中转到外设。
- C 错：内存不能先接 CPU 内部数据通路再到数据总线，且“数据通路”不是 DMA 传送部件。
- D 错：数据经过 CPU，是程序查询或程序中断方式的特点，不是 DMA。

**易错点**：

- 误选 D：DMA 虽然需要 CPU 做初始化和结束后处理，但数据传送阶段不经过 CPU。
- 误选 A 或 C：把“数据通路”当作传送通路。实际上“数据通路”常指 CPU 内部通路，DMA 不应经过它；而“数据总线”才是系统总线中负责数据传送的线路。
- 混淆方向：本题是“内存 → 外设”，即 DMA 输出方向；若题目问“外设 → 内存”，则是从外设经 DMAC 到数据总线再写入内存。

**命题规律**：本题属于 I/O 控制方式中的常考点，重点考查 DMA 与程序查询、程序中断方式在数据通路上的区别。常见变式有：外设到内存的 DMA 传送路径、DMA 传输前 CPU 要做哪些初始化、DMA 传送结束后如何通知 CPU、DMA 与中断的配合等。复习时应把三种 I/O 方式的数据通路对比记忆：程序查询/中断通常经过 CPU 中转，而 DMA 不经过 CPU，但必须经过数据总线和 DMAC。

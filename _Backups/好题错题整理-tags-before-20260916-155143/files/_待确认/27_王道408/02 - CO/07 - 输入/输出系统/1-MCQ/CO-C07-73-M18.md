# 选择题 第 18 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M18_题目.png|题目]]

18. 在 $CPU$ 响应中断时,保护两个关键的硬件状态是（ ）

A. $PC$ 和 $IR$
B. $PC$ 和 $PSW$
C. $AR$ 和 $IR$
D. $AR$ 和 $PSW$

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M18_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。一句话理由：CPU 响应中断时，必须保存程序断点（$PC$）和程序状态字（$PSW$），以便中断返回后能恢复原程序的执行现场。

**解题切入点**：拿到题目先抓“响应中断”这一动作，区分“中断响应”与“中断处理”。中断响应是硬件自动完成的一套“保存现场、转向中断服务程序”的流程，其核心是保证断点能恢复；因此要优先联想到 $PC$ 和 $PSW$。这就像算法竞赛中发生“异常跳转”时，必须先记住当前执行到哪一行（$PC$）和当前全局状态（$PSW$），否则跳出去就回不来了。

**推演**：
- CPU 响应中断时，硬件自动完成以下关键操作：
  1. 关中断（通常通过设置 $PSW$ 中的中断允许位）；
  2. 保存断点，即将当前指令的下一指令地址（即程序断点）压入栈或存入特定单元；
  3. 保存程序状态字 $PSW$，包括条件码、中断允许位、处理器优先级等；
  4. 将中断服务程序的入口地址送入 $PC$，转入中断处理。

- 因此，最关键的两个硬件状态是：
  - $PC$：保存程序断点，保证中断返回后能继续执行原程序；
  - $PSW$：保存程序状态，保证返回后 CPU 的工作状态与中断前一致。

- 选项分析：
  - A 选项中 $IR$（指令寄存器）保存的是当前正在执行的指令，中断响应时该指令已经执行完毕，其内容不再需要保存。
  - C 选项中 $AR$（地址寄存器）是 CPU 访存时暂时保存地址的内部寄存器，属于流水线/执行部件中的临时信息，中断响应不负责保存这类临时数据。
  - D 选项中 $AR$ 同样不是关键硬件状态；而 $PSW$ 虽然需要保存，但少了 $PC$。
  - B 选项中 $PC$ 和 $PSW$ 正好是中断响应时最核心的硬件状态，故选 B。

**易错点**：
- 混淆“中断响应”与“中断处理”：中断处理中可能需要保存通用寄存器等更多现场，但响应阶段硬件只自动保存 $PC$ 和 $PSW$。
- 误选含 $IR$ 的选项：$IR$ 是“当前指令”，执行完就失效，无需恢复。
- 误把 $AR$ 当作必须保存的状态：$AR$ 只是临时地址寄存器，不是程序可见的现场状态。
- 需注意“断点”与“指令地址”的关系：断点通常是 $PC$ 的值，而不是 $IR$ 中的指令。

**命题规律**：
- 考点定位：中断系统的基本概念，中断响应过程与现场保护。
- 常见变式：考查中断隐指令的具体操作（如关中断、保存断点、转中断服务程序）；考查“中断返回时需要恢复哪些寄存器”与“响应时需要保存哪些寄存器”的区别；或结合栈操作考查保护断点的顺序。
- 复习建议：在操作系统与组成原理中反复对比“中断响应”“中断处理”“中断返回”三个阶段各自的硬件/软件职责；牢记硬件自动完成的最小必要集：$PC$ 和 $PSW$，其余现场（通用寄存器等）一般由中断服务程序通过指令保存。

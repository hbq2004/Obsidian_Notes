# 选择题 第 4 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M04_题目.png|题目]]

4. 下列关于程序中断方式和 $DMA$ 方式的说法中,错误的是（  ）
I. 程序中断过程是由硬件和中断服务程序共同完成的
II. 在每条指令的执行过程中,每个总线周期要检查一次有无中断请求
III. 检测有无 $DMA$ 请求,一般安排在一条指令执行过程的末尾
IV. 中断服务程序的最后指令是无条件转移指令
V. 中断响应判优是根据中断屏蔽字来确定中断的优先级

(A) I、III、IV
(B) II、III、IV、V
(C) II、IV、V
(D) II、III、IV

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M04_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。I 正确，II、III、IV、V 均错误，故错误说法为 II、III、IV、V。

**解题切入点**：  
先抓住三组关键词：检查时机、最后指令、判优依据。可以把程序中断理解为“指令级断点”：一条指令完整执行完才响应；DMA 则是“总线级周期挪用”：当前总线周期结束后即可插入一次数据传送，不必等到指令结束。题中 II、III 正是在故意互换这两个时机。

**推演**：  
I. 程序中断过程由“中断响应”和“中断服务”两部分组成。中断响应由硬件自动完成（关中断、保存断点 $\text{PC}$ 和程序状态字 $\text{PSW}$、识别中断源等）；中断服务由中断服务程序完成。因此“硬件+中断服务程序共同完成”正确。

II. 程序中断请求的采样一般在一条指令执行结束后进行，而不是在每个总线周期都检查。若每个总线周期都检查中断请求，开销过大，也不能保证当前指令执行的完整性，因此错误。

III. DMA 采用周期挪用方式，CPU 一般在一个总线周期（机器周期）结束后检测 DMA 请求并让出总线，DMA 可发生在一条指令执行过程中。“安排在一条指令执行过程的末尾”是程序中断的响应时机，不是 DMA 的，因此错误。

IV. 中断服务程序的最后一条指令应为“中断返回指令”（如 $\text{IRET}$），它要恢复断点 $\text{PC}$、$\text{PSW}$ 和现场；无条件转移指令只改变 $\text{PC}$，不能恢复现场，因此错误。

V. 中断响应判优（多个中断同时请求时先响应谁）由硬件判优电路/排队器或软件查询程序决定；中断屏蔽字用于屏蔽某些中断源，可以改变中断的处理优先级、控制多重中断嵌套，但不能作为中断响应判优的依据，因此错误。

**易错点**：  
- 混淆检查时机：程序中断在指令边界检查，DMA 在总线周期/机器周期边界检查。  
- 误以为中断服务程序最后是无条件转移指令；正确应是中断返回指令，需恢复 $\text{PC}$ 和 $\text{PSW}$。  
- 误把中断屏蔽字当成响应判优的依据；屏蔽字影响处理优先级，不影响硬件响应判优。  
- 忽略 I：中断响应是硬件完成的，中断服务是软件完成的，不能只说软件。

**命题规律**：  
考点常为“程序中断方式与 DMA 方式的区别”。常见变式有：中断隐指令完成哪些操作、DMA 与中断的优先级比较、周期窃取发生在哪个周期、中断屏蔽字能否改变响应优先级。复习时可用对比表列出“请求时机、响应时机、传送单位、CPU 介入程度、优先级”，并记住关键句：中断以指令为边界，DMA 以总线周期为边界；中断响应靠硬件，服务靠软件；返回用专用中断返回指令；屏蔽字只改变处理优先级。

# 选择题 第 5 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-72-M05_题目.png|题目]]

5. $I/O$ 的编址方式采用统一编址方式时,进行输入/输出的操作的指令是（ ）.

A. 控制指令
B. 访存指令
C. 输入/输出指令
D. 都不对

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-72-M05_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。统一编址方式（存储器映射方式）下，I/O 端口被当作存储器单元，CPU 通过访存指令来完成输入/输出操作。

**解题切入点**：先判断题干问的是“编址方式”与“所用指令类型”的对应关系。类似做题经验：看到“统一编址”要立刻联想到“内存映射”，即 I/O 地址是内存地址空间的一部分，所以操作 I/O 就像访问内存一样，用访存指令；看到“独立编址”则对应专门的输入/输出指令。

**推演**：

I/O 编址方式主要有两种：

1. **统一编址方式**（存储器映射方式）：将 I/O 端口地址与主存地址统一编在同一个地址空间中，I/O 端口占用一部分主存地址。CPU 访问这些地址时，无论是对主存还是对 I/O 端口，都使用同一种指令——访存指令（如 $\text{LOAD}$、$\text{STORE}$）。例如：

   $$\text{LOAD} \ R_1, \ 4000H$$

   若 $4000H$ 是某个 I/O 端口的地址，则该指令就是一次输入操作。

2. **独立编址方式**（I/O 映射方式）：I/O 端口地址与主存地址相互独立，CPU 必须使用专门的输入/输出指令（如 $\text{IN}$、$\text{OUT}$）来访问 I/O 端口，并通过控制信号（如 $\overline{M/\text{IO}}$）区分当前访问的是主存还是 I/O。

本题明确说明“采用统一编址方式”，因此进行输入/输出操作时，CPU 不设专门的 I/O 指令，而是使用访存指令。故正确选项为 B。

**易错点**：

- **误选 C**：看到“输入/输出操作”就默认选“输入/输出指令”，但统一编址方式下没有专用 I/O 指令，专用 I/O 指令是独立编址方式的特征。
- **误选 A**：控制指令主要用于控制 CPU 内部操作或程序执行顺序（如转移、停机等），与 I/O 数据传送无直接关系。
- **混淆两种编址方式**：统一编址 = 访存指令；独立编址 = 专用 I/O 指令。应重点区分。

**命题规律**：

- **考点定位**：I/O 编址方式与指令类型的对应关系，属于计算机组成原理中 I/O 系统的基础知识。
- **常见变式**：
  - 问“独立编址方式下使用哪种指令？”答案：专用输入/输出指令。
  - 问“统一编址方式相比独立编址方式的优点/缺点？”统一编址无需专用指令、可对 I/O 进行算术逻辑运算，但占用主存地址空间；独立编址不占用主存空间，但需要专用指令和额外控制信号。
  - 给出某 I/O 端口地址范围，判断采用的是哪种编址方式。
- **复习建议**：将两种编址方式进行对比表格记忆，抓住“指令类型”“是否占主存地址”“CPU 如何区分访问对象”等关键点，并通过少量典型例题巩固。

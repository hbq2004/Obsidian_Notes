# 选择题 第 2 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-72-M02_题目.png|题目]]

2. 下列功能中,属于 $I/O$ 接口的功能的是（  ）.

$I$. 数据格式的转换
$II$. $I/O$ 过程中错误与状态检测
$III$. $I/O$ 操作的控制与定时
$IV$. 与主机和外设通信

(A) $I$ 和 $IV$
(B) $I$、$III$ 和 $IV$
(C) $I$、$II$ 和 $IV$
(D) $I$、$II$、$III$ 和 $IV$

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-72-M02_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D（$I$、$II$、$III$ 和 $IV$）。  
理由：$I/O$ 接口是主机与外设之间的“桥梁”，数据格式转换、错误与状态检测、操作控制与定时、以及与主机和外设通信都属于其基本功能。

**解题切入点**：  
先明确“$I/O$ 接口”的定位：它位于系统总线与外设之间，承担“翻译、缓冲、控制、联络”等职责。可以把接口想象成两个不同语言的人之间的翻译兼秘书：既要听懂主机的话并传给外设（通信），也要把外设的“方言”转成主机能理解的形式（格式转换），还要盯着双方是否出错（状态检测），并决定什么时候该干什么（控制与定时）。四个选项逐一核对这些职责即可，不必死记硬背。

**推演**：  
$I/O$ 接口（$I/O$ interface，常称适配器）的功能可以归纳为以下几类：

1. **数据格式的转换（$I$）**  
   外设的数据格式往往与主机内部总线格式不同。例如串行设备传输的是位串，而主机内部以字节或字为单位并行传输，接口需要完成“串—并转换”或“并—串转换”；还可能涉及电平转换、码制转换等。因此 $I$ 正确。

2. **$I/O$ 过程中错误与状态检测（$II$）**  
   接口需要随时记录并反映设备和数据传输的状态，如设备是否“忙”（busy）、是否“就绪”（ready）、有无奇偶校验错误或机械故障等。主机可通过读取接口中的状态寄存器来了解这些信息，从而决定下一步操作。因此 $II$ 正确。

3. **$I/O$ 操作的控制与定时（$III$）**  
   接口要协调主机与外设的工作节奏。外设速度通常远慢于主机，接口需提供握手信号、定时信号或等待机制，以确保数据在正确的时间点被写入或读出；同时还要根据主机命令控制外设启动、停止等操作。因此 $III$ 正确。

4. **与主机和外设通信（$IV$）**  
   接口必须能够在主机一侧与系统总线通信（如接收地址译码、数据传送、中断请求等），又要在外设一侧与外设通信（如发送控制信号、接收状态信号、传送数据）。这种“两侧通信”是接口存在的基础。因此 $IV$ 正确。

综上，四项都是 $I/O$ 接口应具备的功能，故选 D。

**易错点**：  
- 只选“与主机和外设通信”和“数据格式转换”，漏掉“错误与状态检测”或“控制与定时”。  
- 误认为“控制与定时”只是 CPU 或 DMAC 的工作，而忽略接口内部的命令寄存器和定时逻辑。  
- 应对方法：从接口的组成结构出发，回忆其典型内部部件——数据缓冲寄存器、状态寄存器、控制寄存器、地址译码电路、定时/控制逻辑等，每一部分对应一类功能，即可全面覆盖。

**命题规律**：  
这是“$I/O$ 系统”部分的基础概念题，常以“下列属于接口功能的是”“接口与端口的区别”等形式出现，也可能结合串行接口、并行接口、USB 控制器等具体例子考查格式转换与通信功能。复习时建议把“$I/O$ 接口的功能”与“接口的组成（数据寄存器、状态寄存器、控制寄存器）”“$I/O$ 端口的编址方式”联系起来，形成知识网络；同时注意区分“接口”与“端口”：端口是接口中可编址的寄存器，而接口是包含端口及其控制逻辑的整体。此类题目难度低，只要抓住“桥接、缓冲、转换、控制、检测”几个关键词即可稳拿分。

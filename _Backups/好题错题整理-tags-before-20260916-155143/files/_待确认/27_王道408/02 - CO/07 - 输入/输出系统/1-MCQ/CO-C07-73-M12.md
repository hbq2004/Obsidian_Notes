# 选择题 第 12 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M12_题目.png|题目]]

12. 下列关于中断 $I/O$ 方式的叙述中,错误的是( )
A. $CPU$ 对外部中断的响应不可能发生在一条指令的执行过程中
B. 在中断 $I/O$ 方式下,外设接口中的寄存器和 $CPU$ 中的寄存器直接交换数据
C. 中断请求的是 $CPU$ 时间,要求 $CPU$ 执行程序来处理发生的相关事件
D. 只要有中断请求发生,一条指令执行结束后 $CPU$ 就进入中断响应周期

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M12_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。中断请求只是进入中断响应周期的必要条件；还必须满足当前指令执行结束、CPU 开中断、该中断未被屏蔽且优先级足够等条件，才能进入中断响应周期。

**解题切入点**：拿到本题先定位到“程序中断方式”的中断响应条件与数据传送路径。不要被“直接交换”“只要有……就……”这类绝对化表述带偏；可以类比竞赛中的“事件触发”：触发信号到了，不一定马上执行回调，还要看全局开关和优先级。

**推演**：

- A 正确。外部中断请求可能随时到达，但 CPU 只在一条指令执行结束后采样中断请求；若满足条件，则进入中断响应周期。因此外部中断响应不会发生在一条指令的取指、译码、执行等阶段内部。

- B 正确。中断 I/O 方式下，数据传送由 CPU 执行 I/O 指令完成。例如输入时：
  $$
  R_i \leftarrow D_{\text{port}}
  $$
  输出时：
  $$
  D_{\text{port}} \leftarrow R_i
  $$
  其中 $D_{\text{port}}$ 为外设接口中的数据缓冲寄存器/数据端口，$R_i$ 为 CPU 中的通用寄存器。因此 B 说的是“CPU 寄存器—接口寄存器”之间的传送，不是 DMA 那种外设与主存直接交换。

- C 正确。中断请求占用的是 CPU 时间：CPU 暂停当前程序，转去执行中断服务程序处理事件。

- D 错误。进入中断响应周期需要多个条件同时成立。对可屏蔽中断：
  $$
  \text{当前指令执行结束}\land EINT=1 \land \text{存在未被屏蔽的中断请求} \land \text{优先级满足}
  $$
  $EINT=1$ 表示 CPU 开中断。D 只看到了“有中断请求”这一条，忽略了开中断、屏蔽和优先级条件，故错误。

**易错点**：

- 把“外设接口寄存器—CPU 寄存器交换数据”误判为 DMA。DMA 是外设与主存之间直接交换数据，无需 CPU 逐字干预。
- 把“中断请求在执行过程中到达”等同于“CPU 在执行过程中响应中断”。请求到达是异步的，但响应通常发生在指令结束后。
- 忽略中断允许条件。“有请求”和“被响应”不是一回事。

**命题规律**：考点是中断 I/O 方式的基本概念、中断响应条件和数据通路。常见变式有：判断中断响应条件；比较程序查询、程序中断、DMA 三种方式的 CPU 参与程度与传送单位；结合中断屏蔽字考查优先级。复习时可用表格对比三类 I/O 方式，并熟记中断响应必要条件。

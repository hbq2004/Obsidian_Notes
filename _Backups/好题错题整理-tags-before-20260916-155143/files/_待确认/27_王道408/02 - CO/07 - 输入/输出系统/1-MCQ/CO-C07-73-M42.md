# 选择题 第 42 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M42_题目.png|题目]]

42.【2011统考真题】下列关于外部 I/O 中断的叙述中,正确的是（ ）
A. 中断控制器按所接收中断请求的先后次序进行中断优先级排队
B. $CPU$ 响应中断时,通过执行中断隐指令完成通用寄存器的保护
C. $CPU$ 只有在处于中断允许状态时,才能响应外部设备的中断请求
D. 有中断请求时,$CPU$ 立即暂停当前指令执行,转去执行中断服务程序

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M42_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。外部 I/O 中断属于可屏蔽中断，CPU 只有在中断允许状态下才能响应；A、B、D 的表述均与中断机制不符。

**解题切入点**：拿到题目先定位考点为“中断响应过程”。选项中涉及“中断控制器排队”“中断隐指令”“中断允许状态”“响应时机”四个细节，直接对应三组知识：中断优先级如何判优、中断隐指令做什么、外部可屏蔽中断的响应条件。可以把 CPU 处理中断想象成处理并发任务：不会一到请求就打断当前任务，而要等一个任务边界；现场由中断服务程序自己保存；调度器按优先级而不是按到达顺序选任务。

**推演**：

A 错。中断控制器对多个中断请求是“按优先级排队”，不是“按请求到达的先后次序排队”。若多个不同优先级的中断请求同时到达，中断控制器会优先受理优先级高的请求，先到的不一定先被响应。因此不能笼统地说按接收先后次序排队。

B 错。$CPU$ 响应中断时执行的中断隐指令不是一条真正的机器指令，而是中断响应周期内自动完成的一组硬件操作，主要内容为：
$$
\text{关中断} \Rightarrow \text{保存断点（PC 等）} \Rightarrow \text{将中断服务程序入口地址送入 PC} 。
$$
它不负责保护通用寄存器。通用寄存器的现场保护通常由中断服务程序开头用压栈指令完成。

C 对。外部 I/O 中断属于可屏蔽中断，CPU 响应它需要满足相关条件。可屏蔽中断的响应条件可写成：
$$
\text{当前指令执行结束} \land \text{CPU处于开中断状态（如 } \mathrm{IF}=1 \text{）} \land \text{有中断请求}。
$$
因此“CPU只有在处于中断允许状态时，才能响应外部设备的中断请求”正确。

D 错。外部中断请求到来后，CPU 不能立即暂停正在执行的指令，必须等当前指令执行结束后，进入中断响应周期，才可能转去执行中断服务程序。

**易错点**：

1. 容易把“保存断点”误记为“保存所有现场”。中断隐指令保存的是 $PC$，不是通用寄存器；通用寄存器由中断服务程序或额外硬件保护。
2. 容易忽略响应时机：CPU 不是在任意时刻响应外部中断，而是在当前指令执行结束后。
3. 看到“中断允许状态”可能想到不可屏蔽中断不受 $\mathrm{IF}$ 控制；但本题说的是外部 I/O 设备产生的中断，属于可屏蔽中断，不是不可屏蔽中断。
4. 误以为中断控制器是“先到先服务”。实际上它按优先级判优，不是按请求到达顺序排队。

**命题规律**：该题考查中断响应全过程。常见变式有：判断中断隐指令完成的操作、中断响应条件、现场保护由谁完成、中断优先级与排队方式、可屏蔽/不可屏蔽中断的区别。复习时应按时间线梳理：
$$
\text{中断请求} \rightarrow \text{当前指令结束} \rightarrow \text{中断判优/响应} \rightarrow \text{中断隐指令} \rightarrow \text{中断服务程序（保护现场、处理、恢复现场）} \rightarrow \text{中断返回}。
$$
并重点区分哪些操作由硬件自动完成，哪些由中断服务程序软件完成。

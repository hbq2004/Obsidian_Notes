# 选择题 第 8 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M08_题目.png|题目]]

8. 在下列情况下,可能不发生中断请求的是（  ）

A. $DMA$ 操作结束

B. 一条指令执行完毕

C. 机器出现故障

D. 执行“软中断”指令

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M08_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。一条指令执行完毕只是 CPU 检查/响应中断的时机，并不等同于产生中断请求，因此可能没有任何中断请求发生。

**解题切入点**：  
题目考查“中断请求”与“中断响应时机”的辨析。拿到题先判断：每个选项是“产生请求的中断源”，还是“CPU 响应的条件”。可以用“举手提问”打比方：中断源是举手的学生，中断请求是“举手”这个动作；“一条指令执行完毕”相当于老师讲完一道题后抬头看，学生不一定举手。

**推演**：  
先明确两个概念：

- 中断请求：由中断源发出，如 I/O 设备、DMA 控制器、定时器、硬件故障、软中断指令等。
- 中断响应：CPU 在满足条件时进入中断处理过程，通常需要满足：CPU 开中断、有中断请求、当前指令执行完毕。

逐项分析：

A. **DMA 操作结束**  
DMA 控制器在数据块传送完成后，会向 CPU 发出中断请求，通知 CPU 进行后续处理，如数据校验、结果判断等。因此属于中断源，会产生中断请求。

B. **一条指令执行完毕**  
CPU 每条指令执行结束后，会检查是否有中断请求，但此时不一定有设备请求或异常发生。  
“指令执行完毕”只是中断响应的**时间条件**，不是中断请求的来源。因此可能不发生中断请求。

C. **机器出现故障**  
硬件故障、电源异常等属于故障类内部中断，CPU 必须及时处理，因此会产生中断请求或异常。

D. **执行“软中断”指令**  
如 $INT\ n$ 指令，执行时会主动产生一个内部中断/陷阱，必定向 CPU 请求转入中断处理程序。

因此，唯一“可能不发生中断请求”的是 B。

**易错点**：  
- 误把“一条指令执行完毕”当成中断请求：它是中断响应的前提，但不是中断源。  
- 误以为 DMA 操作结束不一定产生中断：标准 DMA 接口中，DMA 传送结束通常以中断请求方式通知 CPU，这是考点，不要因“DMA 传送不占用 CPU”而混淆。  
- 混淆“中断请求”和“中断响应”：有请求不一定响应，因为可能被屏蔽或未开中断；但无请求一定不会进入中断响应。本题问的是请求是否发生。

**命题规律**：  
考点是中断源分类与中断响应过程。常见变式包括：“哪些事件一定会产生中断请求”“哪些属于内中断/外中断”“中断响应需要满足哪些条件”等。复习时应理清：  
- 中断源：外部设备、DMA、时钟、硬件故障、软中断、异常等；  
- 中断响应条件：开中断、有请求、当前指令执行完毕。  

注意区分“请求”“响应”“中断周期”三个层面，这是考研 CO 常设陷阱之处。

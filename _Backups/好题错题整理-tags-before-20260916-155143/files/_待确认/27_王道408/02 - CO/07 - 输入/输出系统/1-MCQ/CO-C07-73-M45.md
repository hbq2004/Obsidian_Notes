# 选择题 第 45 题

45.【2020统考真题】下列事件中,属于外部中断事件的是（ ）

I.访存时缺页 II.定时器到时 III.网络数据包到达

A. 仅I、II
B. 仅I、III
C. 仅II、III
D. I、II和III

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M45_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。缺页属于 CPU 内部异常（故障），定时器到时和网络数据包到达均属于来自 CPU 外部的硬件中断事件。

**解题切入点**：先明确“外部中断”的定义：由 CPU 外部的硬件设备发出的中断请求，具有异步性。然后逐个判断事件是来自 CPU 内部还是外部硬件。可类比“程序执行中的突发事件”与“外界打来的电话”：缺页是程序自己执行时撞上的“内部故障”，定时器、网络数据包则是外部设备主动“来电”通知 CPU。

**推演**：

中断按来源可分为两大类：

1. **外部中断**：由 CPU 外部设备（如定时器、I/O 设备）发出中断请求信号引起，与当前执行的指令无直接因果关系，是异步事件。例如：
   - 定时器到时：定时器是外部硬件，其信号通过中断请求线送入 CPU；
   - 网络数据包到达：网卡等外部设备检测到数据后向 CPU 发出中断。

2. **内部异常**：由 CPU 执行指令过程中内部产生的事件，与当前指令直接相关，是同步事件。例如：
   - 缺页：CPU 访问内存时，由 MMU（存储管理部件）检查发现页不在内存中，从而产生一个内部异常（缺页故障）。它是由“访存”这一内部操作直接触发的，不是外部设备发出的中断信号。

因此：

- I. 访存时缺页：内部异常（故障），不属于外部中断。
- II. 定时器到时：外部中断。
- III. 网络数据包到达：外部中断。

正确选项为 C（仅 II、III）。

**易错点**：

- 误把“缺页”当作外部中断。缺页虽然需要操作系统参与处理，但其触发源是 CPU 访存时的内部检测逻辑（MMU），属于内部异常（故障），不是外部设备发来的中断请求。
- 混淆“异步”与“同步”。外部中断与当前指令无关，随时可能发生；而缺页、除零等异常由正在执行的指令引起，具有同步性。
- 把“定时器”与“内部时钟”混淆。CPU 内部有时钟产生节拍脉冲，但这里“定时器到时”通常指可编程间隔定时器（如 8253/8254）等外部硬件设备，属于外部中断源。

**命题规律**：

考点为中断与异常的分类，是 408 计算机组成原理中“输入输出系统”部分的常考点。常见变式包括：缺页、除零、非法指令、系统调用、定时器、I/O 完成、电源故障等事件的中断/异常归类。复习时应抓住“来源是否在 CPU 外部”和“是否与当前指令同步”两个判断标准，并结合典型例子强化记忆，同时注意区分“异常（故障/陷阱/终止）”与“外部中断”在响应方式上的不同。

# 选择题 第 36 题

![[_Attachments/题目识别/27_王道408-题目/CO-C07-73-M36_题目.png|题目]]

36.【2011统考真题】某计算机处理器主频为 $50\mathrm{MHz}$，采用定时查询方式控制设备 $A$ 的 $I/O$，查询程序运行一次所用的时钟周期数至少为 $500$。在设备 $A$ 工作期间，为保证数据不丢失，每秒需对其查询至少 $200$ 次，则 $CPU$ 用于设备 $A$ 的 $I/O$ 的时间占整个 $CPU$ 时间的百分比至少是（ ）

A. $0.02\%$

B. $0.05\%$

C. $0.20\%$

D. $0.50\%$

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C07-73-M36_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C，0.20%。  
CPU 用于设备 A 的 I/O 时间占整个 CPU 时间的百分比至少为 $0.20\%$，对应选项 C。

**解题切入点**：  
计算 I/O 操作占用的 CPU 时间比例，核心是求出每秒因查询消耗的时钟周期数，再除以 CPU 每秒总时钟周期数。注意“至少”对应最小比例，直接使用给定的最小查询次数和最少时钟周期数即可。

**推演**：  
- 处理器主频 $50\,\mathrm{MHz}$，即每秒时钟周期数 $50 \times 10^6$。  
- 每次查询需 $500$ 个时钟周期，每秒至少查询 $200$ 次，故每秒查询消耗的时钟周期数至少为 $200 \times 500 = 10^5$。  
- 比例 $= \dfrac{10^5}{50 \times 10^6} = 0.002 = 0.20\%$。

**易错点**：  
- 误将百分比计算为 $0.02\%$（如 $10^5 / 50 \times 10^6 = 0.002$ 后错误地认为 $0.002\%$）。  
- 忽略“至少”条件，使用多余的查询次数或时钟周期数导致比例偏大。

**命题规律**：  
- 考点：定时查询方式下 CPU 开销的计算，常与主频、时钟周期、查询次数结合。  
- 变式：可改为中断方式或 DMA 方式，比较不同 I/O 方式的 CPU 占用率。  
- 复习建议：熟练频率与周期的换算，掌握各类 I/O 方式的性能分析。

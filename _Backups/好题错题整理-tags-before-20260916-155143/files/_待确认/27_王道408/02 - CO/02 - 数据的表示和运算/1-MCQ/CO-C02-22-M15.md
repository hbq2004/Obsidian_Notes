# 选择题 第 15 题

![[_Attachments/题目识别/27_王道408-题目/CO-C02-22-M15_题目.png|题目]]

15. 若 $[X]_补 = X_0.X_1X_2\cdots X_n$，其中 $X_0$ 为符号位，$X_1$ 为最高数位。若（ ），则当补码左移时，将会发生溢出。

(A) $X_0=X_1$

(B) $X_0\neq X_1$

(C) $X_1=0$

(D) $X_1=1$

## DeepSeek V4 Flash Max 解析

**答案**：B。理由：补码左移时，符号位保持不变，最高数位进入符号位会导致符号改变；只有当符号位与最高数位不同（$X_0 \ne X_1$）时，左移后符号位由 $X_1$ 取代，才会发生溢出。

**解题切入点**：  
看到“补码左移”“溢出”要立刻联想到定点数移位运算的硬件规则：左移一位相当于将每一位向左移动，最右边的空位补 0，而符号位被移出，最高数位 $X_1$ 成为新的符号位。溢出发生在“新的符号位与原符号位不同”。这就像排队时把队伍最前面的人移走，第二个人顶到第一个位置；如果第二个人的“身份”和第一个人不同，队伍性质就变了。

**推演**：  
设补码形式为  
$$[X]_{\text{补}} = X_0.X_1X_2\cdots X_n,$$  
其中 $X_0$ 为符号位，$X_1$ 为最高数值位。

左移一位（算术左移）的规则：所有位向左移动一位，最低位补 0，符号位 $X_0$ 被丢弃。因此左移后得到的新的符号位就是原来的 $X_1$：
$$[2X]_{\text{补}} = X_1.X_2X_3\cdots X_n0.$$

补码能正确表示 $2X$ 的前提是 $2X$ 仍在原补码表示范围内，即符号位不应改变。换言之，左移后符号位应与原符号位相同：
$$X_1 = X_0.$$

所以，当 $X_1 \ne X_0$ 时，左移后符号位由 $X_0$ 变为 $X_1$，数值符号发生改变，运算结果超出补码表示范围，发生溢出。

例如：
- 若 $X_0=0$（正数），$X_1=1$，左移后符号位变为 1，正数变负数，溢出。
- 若 $X_0=1$（负数），$X_1=0$，左移后符号位变为 0，负数变正数，溢出。

因此发生溢出的条件是 $X_0 \ne X_1$，选 B。

**易错点**：  
1. 误认为“左移一位就是乘以 2，所以只有符号位变化才是溢出”。其实补码左移时符号位被丢弃，新的符号位直接取自最高数值位，因此只需比较 $X_0$ 与 $X_1$。  
2. 误选 A：$X_0=X_1$ 时，左移后符号位不变，不会发生溢出，这是正常移位的情况。  
3. 忽略“补码左移”中的“算术左移”语义，误以为左移后符号位不变；实际上算术左移中符号位会移出，由次高位补上。  
4. 混淆“补码右移”的规则（右移时符号位保持不变，并在左侧补符号位），而左移恰恰相反。

**命题规律**：  
考点为补码的移位运算与溢出判断。常见变式包括：  
- 给出具体补码，判断左移/右移后结果是否正确；  
- 判断“补码左移一位相当于乘以 2”的条件；  
- 结合溢出判断电路（符号位与最高数值位是否相同）出题。  
复习时应熟练掌握补码的移位规则、算术移位与逻辑移位的区别，并理解溢出产生的本质：运算结果超出可表示范围导致符号位改变。可借助几个典型数（如 $[+1]_{\text{补}}=0.1$，$[-1]_{\text{补}}=1.1$，$[-\frac12]_{\text{补}}=1.1$ 左移后符号位变化）来检验结论。

# 选择题 第 45 题

![[_Attachments/题目识别/27_王道408-题目/CO-C02-23-M45_题目.png|题目]]

45.【2025统考真题】某32位计算机按字节编址,采用小端方式存放数据,编译器按边界对齐方式为下列C语言结构型数组变量 `employee` 分配存储空间。

```c
struct  record{
    int id;
    char name[10];
    int salary;
} employee[200];
```

若 `employee` 的首地址为 $0000\ \mathrm{A0B0H}$, `employee[1].id` 的机器数为 $1234\ \mathrm{5678H}$, 则该机器数中的 $56\mathrm{H}$ 所在存储单元的地址是

A. $0000\ \mathrm{A0C3H}$

B. $0000\ \mathrm{A0C4H}$

C. $0000\ \mathrm{A0C5H}$

D. $0000\ \mathrm{A0C6H}$

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C02-23-M45_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C（56H所在存储单元的地址为 $0000\ \mathrm{A0C5H}$）。  
理由：结构体 `record` 按边界对齐后大小为20字节，`employee[1]` 首地址为 `employee` 首地址加20，即 $0000\ \mathrm{A0C4H}$；小端模式下 `employee[1].id` 的机器数 $1234\ 5678\mathrm{H}$ 在内存中低字节在前，$56\mathrm{H}$ 位于起始地址后的第2字节，故地址为 $0000\ \mathrm{A0C5H}$。

**解题切入点**：  
本题是“结构体大小计算 + 数组地址偏移 + 小端存储”的综合题。拿到题目先找关键信息：按字节编址、小端、边界对齐、结构体数组。首先定位考点：计算结构体大小（需考虑对齐填充）和数组元素地址，然后理解小端存储的字节顺序。可以类比竞赛中内存布局的“填格子”问题，先算出每个格子（结构体）的宽度，再找偏移量。

**推演**：  
1. 计算结构体 `record` 大小（按边界对齐）：  
   - `int id`：4字节，偏移0。  
   - `char name[10]`：10字节，每个char按1字节对齐，偏移4，结束于13。  
   - `int salary`：需4字节对齐，当前偏移14（非4倍数），填充2字节到16，然后占4字节（16~19）。  
   - 结构体总大小 = 20字节（最大成员对齐4，20是4的倍数，无需尾部填充）。  
   所以每个 `record` 占20字节（$0\mathrm{x14}$）。  

2. 数组 `employee[200]` 连续存放，已知首地址 $0000\ \mathrm{A0B0H}$。  
   - `employee[1]` 的起始地址 = 首地址 + $1\times 20 = 0000\ \mathrm{A0B0H} + 0\mathrm{x14} = 0000\ \mathrm{A0C4H}$。  
   - `employee[1].id` 是结构体第一个成员，故其地址即为 $0000\ \mathrm{A0C4H}$。  

3. 小端存储：32位整数 $1234\ 5678\mathrm{H}$ 在内存中按字节从低地址到高地址依次为：$78\mathrm{H}$、$56\mathrm{H}$、$34\mathrm{H}$、$12\mathrm{H}$。  
   - $78\mathrm{H}$ 存于地址 $0000\ \mathrm{A0C4H}$，$56\mathrm{H}$ 存于 $0000\ \mathrm{A0C5H}$，$34\mathrm{H}$ 存于 $0000\ \mathrm{A0C6H}$，$12\mathrm{H}$ 存于 $0000\ \mathrm{A0C7H}$。  
   - 故 $56\mathrm{H}$ 所在存储单元地址为 $0000\ \mathrm{A0C5H}$。  

**易错点**：  
- 误认为结构体大小为 $4+10+4=18$ 字节，忽略对齐填充（`salary` 需从4的倍数开始）。  
- 计算 `employee[1]` 地址时直接加1而不是加偏移量（误以为 `employee[1]` 是相邻元素）。  
- 小端顺序混淆，以为高字节在低地址，导致 $56\mathrm{H}$ 地址计算错误。  
- 误将 `employee[1].id` 地址当成 `employee[0]` 的末尾地址（$A0C3H$）而加1得到 $A0C4H$，但实际 $56\mathrm{H}$ 在第二个字节，应加1得到 $A0C5H$。  

**命题规律**：  
- 常考结构体大小计算（对齐方式）与数组地址偏移，结合字节序（大端/小端）考查内存分布。  
- 变式：改变结构体成员类型（如 `short`、`double`）、改变对齐规则（如 `#pragma pack`）或改用大端存储。  
- 复习建议：熟练掌握结构体对齐规则（成员对齐到自身大小倍数，总大小对齐到最大成员大小倍数），并通过画内存布局图来强化理解；同时牢记小端“低地址存低字节”的原则，多练习类似题目。

# 选择题 第 28 题

![[_Attachments/题目识别/27_王道408-题目/CO-C02-23-M28_题目.png|题目]]

28.【2011统考真题】$float$型数据通常用$IEEE754$单精度格式表示。若编译器将$float$型变量$x$分配在一个32位浮点寄存器$FR1$中，且$x=-8.25$，则$FR1$的内容是( )

(A) $C1040000H$  
(B) $C2420000H$  
(C) $C1840000H$  
(D) $C1C20000H$

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C02-23-M28_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A（$C1040000H$）。因为 $-8.25$ 的 IEEE 754 单精度浮点表示为 $1\ 10000010\ 00001000000000000000000$，即十六进制 $C1040000H$。

**解题切入点**：首先明确题目考查 IEEE 754 单精度浮点数的表示方法。拿到题目后，应立刻将十进制数 $-8.25$ 转换为二进制，再进行规格化，然后按符号位、指数（偏置）、尾数分别编码，最后组合成十六进制，与选项对比即可。这类似于算法竞赛中处理进制转换与位运算的基本功。

**推演**：
1. 将 $-8.25$ 转换为二进制：整数部分 $8 = (1000)_2$，小数部分 $0.25 = (0.01)_2$，故 $8.25 = (1000.01)_2$。
2. 规格化：$1000.01 = 1.00001 \times 2^3$，所以指数 $e = 3$，尾数部分 $f = 00001$（隐含最高位 $1$）。
3. 符号位 $s = 1$（负数）。
4. 指数偏移：$E = e + 127 = 3 + 127 = 130 = (10000010)_2$。
5. 尾数 $M$ 为 $23$ 位，在 $f$ 后补 $0$：$M = 00001000000000000000000$。
6. 组合 $32$ 位二进制：$s\ E\ M = 1\ 10000010\ 00001000000000000000000$。
7. 分组为 $4$ 位：$1100\ 0001\ 0000\ 0100\ 0000\ 0000\ 0000\ 0000$，对应十六进制 $C1040000H$。

因此，$FR1$ 的内容为 $C1040000H$，对应选项 (A)。

**易错点**：
1. 忘记隐含的 $1$，将尾数直接写成 $00001$ 但未补足 $23$ 位，或错误地认为规格化后尾数部分为 $00001$ 时整个尾数是 $00001000000000000000000$，但可能遗漏前导零或顺序错乱。
2. 指数偏移量计算错误，可能误用 $128$ 或 $1023$ 等（单精度偏移 $127$，双精度 $1023$）。
3. 二进制小数转换错误，如 $0.25$ 误为 $0.01$ 正确，但有时会混淆。
4. 符号位处理错误，正数 $s=0$，负数 $s=1$。
5. 十六进制写作时字节顺序混淆，但本题是寄存器表示，直接按高位到低位。

**命题规律**：
- 该考点为 IEEE 754 浮点数表示，是考研 408 常考基础题。
- 常见变式包括：给定十六进制表示求十进制值；给定十进制数求表示（正数、负数、小数、整数）；特殊值（无穷大、NaN、非规格化数）的表示。
- 复习建议：熟练掌握 IEEE 754 单精度/双精度格式，包括符号位、指数偏移、尾数隐含位，并能熟练进行十进制与二进制、十六进制的转换。注意 $0$ 的表示及特殊值边界。

# 选择题 第 1 题

![[_Attachments/题目识别/27_王道408-题目/CO-C02-23-M01_题目.png|题目]]

1. 在C语言的不同类型的数据混合运算中,要先转换成同一类型后进行运算。设一表达式中包含有 $int$、$long$、$char$ 和 $double$ 类型的变量与数据,则表达式最后的运算结果是( ),这4种类型数据的转换规律是( ).

A. $long$, $int \rightarrow char \rightarrow double \rightarrow long$
B. $long$, $char \rightarrow int \rightarrow long \rightarrow double$
C. $double$, $char \rightarrow int \rightarrow long \rightarrow double$
D. $double$, $char \rightarrow int \rightarrow double \rightarrow long$

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C02-23-M01_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：选 **C**。理由：含 `double` 的混合算术表达式最终按 `double` 计算；这四种类型从低到高的自动转换链是 `char → int → long → double`。

**解题切入点**：看到“不同类型数据混合运算”和“转换成同一类型”，应立刻定位到 C 语言的“隐式类型转换/寻常算术转换”。可把它类比成“多级别比赛”：`double` 是最高等级，只要 `double` 出现，最终结果就按 `double` 算；`char` 等级最低，要先提升为 `int`。先看第一空：结果应为 `double`，排除 A、B；再比较转换规律，C 是从低到高，D 出现了 `double→long` 的“降级”，故排除 D。

**推演**：

C 语言中，不同类型混合运算时会自动进行类型转换，核心规则可记为：

$$
\mathrm{char}<\mathrm{int}<\mathrm{long}<\mathrm{double}
$$

具体到本题：

1. `char` 属于整型，参与运算时先做“整型提升”，转为 `int`。
2. `int` 与 `long` 混合运算时，低等级的 `int` 转为 `long`。
3. `long` 与 `double` 混合运算时，只要出现 `double`，`long` 再转为 `double`。
4. 因此，只要表达式中含有 `double`，最终整个算术表达式的类型是 `double`，而不是 `long`。

例如，设变量为：

$$
c:\mathrm{char},\quad i:\mathrm{int},\quad l:\mathrm{long},\quad d:\mathrm{double}
$$

计算 $c+i+l+d$ 时：

- $c+i$：`char` 提升为 `int`，结果为 `int`；
- $(c+i)+l$：`int` 转为 `long`，结果为 `long`；
- $((c+i)+l)+d$：`long` 转为 `double`，结果为 `double`。

所以第一空是 `double`，转换规律是：

$$
\mathrm{char}\rightarrow \mathrm{int}\rightarrow \mathrm{long}\rightarrow \mathrm{double}
$$

对应选项 **C**。

**易错点**：

- 误选 A 或 B：以为最大的整型是 `long`，忽略了 `double` 的等级更高。
- 误选 D：`char→int→double→long` 中出现了 `double→long`，这是降级转换，C 语言在隐式转换中不会这样做。
- 要注意 `char` 不是直接转为 `double`，而是先做整型提升为 `int`。
- 题目问的是“表达式中混合运算的结果”，不是“赋值后的结果”。如果赋值给 `long`，当然会发生截断，但那不是表达式本身的运算类型。
- 严格说，C 语言是每个运算符分别做转换，不是把所有类型一次性整体转换；但在本题类型等级链中，结果一致。

**命题规律**：本题属于 C 语言“隐式类型转换”与表达式求值的基础考点，在 408 中常与“数据的表示和运算”结合考查。常见变式有：

- 给出 `char + int`，问结果类型；
- 给出 `int + double`，问 `sizeof` 结果；
- 给出 `int` 与 `unsigned int` 混合，考查有符号数转为无符号数的特殊规则；
- 给出强制类型转换，如 `(int)3.7`，考查截断规则。

复习时应牢记类型等级链：`char < int < long < double`，并理解“有 `double` 则按 `double` 算”的本质；同时要留意 `unsigned` 参与时规则更复杂，不能只死记低到高顺序。

# 选择题 第 6 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-57-M06_题目.png|题目]]

6. 下列关于超线程 ($HT$) 技术的描述中，正确的是（ ）.

A. 超线程技术可以令四核的 $IntelCorei7$ 处理器变成八核

B. 超线程是一项硬件技术，能使系统性能大幅提升，与操作系统和应用软件无关

C. 含有超线程技术的 $CPU$ 需要芯片组的支持才能发挥技术优势

D. 超线程模拟出的每个 $CPU$ 核都具有独立的资源,各自工作互不干扰

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-57-M06_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。超线程技术把一个物理核模拟成多个逻辑处理器，但它不是物理上增加核心，必须要有芯片组及操作系统等软硬件配合才能发挥作用，因此选 C。

**解题切入点**：先抓住考点：超线程（Hyper-Threading，HT）本质上是一种硬件级的线程级并行技术，是 Intel 的同时多线程技术。可以这样理解：一个物理核好比“一个厨房”，超线程只是在这个厨房里多放了几份菜单和记账本（逻辑处理器），并不是多开了几个厨房。因此，看到“四核变八核”“完全独立”“不需要软件支持”等说法都要先怀疑。

**推演**：

1. 超线程技术只是把一个物理核在操作系统看来变成多个逻辑处理器，而不是增加物理核心。

   设物理核数为 $n$，开启超线程后，操作系统看到的逻辑处理器数通常为 $2n$。但物理核数仍然是 $n$：

   $$
   2n \ne n
   $$

   因此，四核 Intel Core i7 开启超线程后，只是被识别为“四核八线程”或“8 个逻辑处理器”，并不是真正变成八核。选项 A 错误。

2. 超线程技术确实是硬件技术，但它要发挥效果，不能离开操作系统和应用软件。

   操作系统要能够识别和调度多个逻辑处理器，应用程序也要有多个线程可并行执行。若程序是单线程的，超线程带来的提升很小，甚至可能因资源争用而下降。所以“与操作系统和应用软件无关”以及“系统性能大幅提升”都不正确。选项 B 错误。

3. 超线程技术要真正生效，不仅 CPU 本身要支持，还需要主板芯片组和 BIOS 的支持，操作系统也需要能识别多个逻辑处理器。

   芯片组提供中断控制、处理器间通信和逻辑处理器枚举等支持；若芯片组或 BIOS 不支持超线程，系统可能只能识别一个逻辑处理器。因此，选项 C 正确。

4. 超线程模拟出的逻辑处理器共享同一个物理核中的执行资源，例如算术逻辑单元、浮点运算部件、Cache、总线等。

   每个逻辑处理器有自己独立的一套体系结构状态，如通用寄存器、程序计数器、控制寄存器等，但执行资源是共享的，因而多线程之间会互相争用资源，不可能做到“各自工作互不干扰”。选项 D 错误。

综上，正确选项是 C。

**易错点**：

- 把“逻辑处理器”误认为“物理核心”。超线程让四核变成“八线程”，不是说变成“八核”。
- 认为“硬件技术就不需要软件支持”。超线程需要操作系统调度多线程，也需要应用软件有并行任务。
- 认为超线程一定能“大幅提升”性能。实际提升幅度取决于负载；某些单线程或资源密集型任务甚至可能性能下降。
- 忽略超线程逻辑处理器共享物理执行资源。它们并非资源完全独立，存在竞争和干扰。

**命题规律**：

本题属于计算机组成原理中“处理器的并行技术”这一考点，重点考查超线程技术与多核、多处理器之间的区别。常见变式有：

- 给出“四核八线程”，问物理核数和逻辑处理器数；
- 将超线程与多核、多处理器进行对比；
- 结合操作系统中的进程/线程概念，考查超线程对调度的影响。

复习时要注意理解同时多线程（SMT）的硬件思想：一份执行资源，多份体系结构状态。对比记忆“多核”是多个物理执行核心，而“超线程”只是提高单个核心的执行资源利用率。

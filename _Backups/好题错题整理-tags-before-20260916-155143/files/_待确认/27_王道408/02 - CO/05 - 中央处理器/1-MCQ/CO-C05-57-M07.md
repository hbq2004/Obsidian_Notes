# 选择题 第 7 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-57-M07_题目.png|题目]]

7. 双核 $CPU$ 和超线程 $CPU$ 的共同点是（  ）

(A) 都有两个内核
(B) 都能同时执行两个运算
(C) 都包含两个 $CPU$
(D) 都不会出现争抢资源的现象

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-57-M07_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。双核 CPU 与超线程 CPU 都能让两个线程/进程“同时”得到执行，但双核依靠物理上的两个内核，超线程则依靠一个物理内核模拟出的两个逻辑内核。

**解题切入点**：看到“共同点”先分别回忆两者的硬件组织方式：双核是“物理多核”，超线程是“逻辑多核”。然后对比选项，排除涉及物理数量、“包含两个 CPU”、资源争抢等绝对化表述。好比算法竞赛中“多线程并行”与“单线程分时切换”都能提高吞吐量，但底层物理资源完全不同，题目在考你对“物理并行”与“逻辑并行”的区分。

**推演**：

1. 双核 CPU：一个 CPU 封装内集成两个物理内核，每个内核有独立的运算部件、寄存器等，可以真正同时执行两个运算。

2. 超线程 CPU：一个物理内核通过增加寄存器等资源，模拟出两个逻辑处理器，操作系统能看到两个逻辑 CPU，可同时调度两个线程。但两个逻辑处理器共享同一个物理内核的执行资源（如算术逻辑单元、缓存等），所以并不是完全独立的物理并行，但确实能同时执行两个线程的部分运算。

3. 对比选项：

   - (A) “都有两个内核”：错。超线程 CPU 只有一个物理内核，只是逻辑上表现为两个核。
   - (B) “都能同时执行两个运算”：正确。双核 CPU 由两个物理内核并行执行；超线程 CPU 由两个逻辑处理器同时处理两个线程，虽然共享资源，但宏观上确实可以同时执行两个运算。
   - (C) “都包含两个 CPU”：错。双核和超线程 CPU 都是单个 CPU 芯片，双核是两个核，超线程是一个核模拟两个逻辑处理器，都不是“两个 CPU”。
   - (D) “都不会出现争抢资源的现象”：错。双核 CPU 可能争抢共享缓存、内存带宽；超线程 CPU 更要争抢执行单元、缓存等资源。

**易错点**：

- 误认为超线程 CPU 有两个物理内核，从而选 A 或 C。实际上超线程是在一个物理核内增加逻辑处理器，不是物理双核。
- 误认为超线程不能“同时”执行两个运算，从而排除 B。注意超线程虽然共享执行资源，但在操作系统层面可以同时调度两个线程，且两个线程的指令可以交替/并行地使用空闲部件，因此说“同时执行两个运算”在宏观上是成立的。
- 被“抢资源”迷惑：以为双核相互独立不抢资源，但共享 cache、内存控制器等仍会争抢，因此 D 必错。

**命题规律**：本题属于计算机组成原理中“CPU 性能提高技术”的基础概念题，常与流水线、多核、超线程等内容结合考查。常见变式包括：判断双核、超线程的硬件结构、逻辑处理器数量、资源争抢原因，或结合操作系统并发概念辨析“并行”与“并发”。复习时应重点理解物理核、逻辑核、线程级并行（TLP）三者的关系，并能用示意图说明超线程如何共享执行资源。

# 选择题 第 2 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-51-M02_题目.png|题目]]

2. 通用寄存器是 ( )

(A) 可存放指令的寄存器  
(B) 可存放程序状态字的寄存器  
(C) 本身具有计数逻辑与移位逻辑的寄存器  
(D) 可编程指定多种功能的寄存器

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-51-M02_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。通用寄存器是可编程指定多种功能的寄存器，既能存放操作数，也可存放地址或中间结果，而其他选项分别描述的是指令寄存器、程序状态字寄存器和具有特定逻辑的移位/计数寄存器。

**解题切入点**：先定位考点为“通用寄存器”的功能定义。可用算法竞赛中“多功能变量”作比：通用寄存器就像一个可被程序自由指定用途的“临时变量”，而不是硬件固定功能的专用寄存器。抓住“通用”二字，即可排除所有“固定功能”的描述。

**推演**：  
通用寄存器（General Purpose Register）是 CPU 中一组由程序员通过指令显式访问的寄存器，其具体用途不是由硬件固定，而是由指令系统中的操作码和寻址方式决定。例如，在指令 `ADD R1, R2` 中，R1、R2 可存放操作数；在 `LOAD R1, [addr]` 中，R1 又存放从内存读入的数据；在 `MOV R1, #imm` 中，R1 存放立即数。因此它“可编程指定多种功能”。

逐项分析：  
- A 项“可存放指令的寄存器”是指令寄存器（IR），用于存放当前正在执行的指令，功能固定，不是通用寄存器。  
- B 项“可存放程序状态字的寄存器”是程序状态字寄存器（PSW/Flags），用于保存条件码、中断标志等状态信息，功能固定。  
- C 项“本身具有计数逻辑与移位逻辑的寄存器”描述的是计数器（如程序计数器 PC）或移位寄存器，它们内部含有特定硬件逻辑，不是通用寄存器的本质特征。  
- D 项“可编程指定多种功能”准确概括了通用寄存器的核心特点，即通过指令指定其保存操作数、地址、中间结果等多种数据，故正确。

**易错点**：  
1. 误选 A：混淆了 IR（指令寄存器）与通用寄存器。IR 专门存放指令，而通用寄存器存放的是数据或地址，不能存放指令（在冯·诺依曼结构中指令和数据都存于存储器，但寄存器分工不同）。  
2. 误选 B：PSW 是专用寄存器，存放状态标志，不具有通用性。  
3. 误选 C：计数/移位逻辑属于专用硬件功能，通用寄存器本身通常不具备这些逻辑，其功能靠 ALU 等部件配合实现。  
规避方法：牢记各类寄存器的“专用”功能，通用寄存器的关键词是“可编程指定”，不绑定单一用途。

**命题规律**：  
本题属于计算机组成原理中“CPU 内部寄存器”基础题，常以选择题形式考查寄存器分类与功能。变式可能包括：给出某寄存器功能描述，判断其名称（如 IR、PC、PSW、MAR、MDR、通用寄存器）；或将通用寄存器与其他专用寄存器混合，要求区分。复习时应重点掌握各类寄存器的功能定义、在指令执行流程中的作用，并注意“通用”与“专用”的根本区别。

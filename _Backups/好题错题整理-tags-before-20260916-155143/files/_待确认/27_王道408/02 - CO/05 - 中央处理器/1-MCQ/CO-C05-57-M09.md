# 选择题 第 9 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-57-M09_题目.png|题目]]

9. 下列有关多核 $CPU$ 和单核 $CPU$ 的描述中,错误的是（ ）.

A. 双核的频率为 $2.4GHz$,那么其中每个核心的频率也是 $2.4GHz$

B. 同等性能下,采用双核 $CPU$ 可以降低计算机系统的功耗和体积

C. 多核 $CPU$ 共用一组内存,数据共享

D. 所有程序在多核 $CPU$ 上运行速度都快

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-57-M09_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。并非所有程序都能利用多核并行；串行程序在多核 CPU 上通常不会自动加快，甚至还可能因为调度、同步等额外开销而变慢。A、B、C 都是多核 CPU 的通常正确表述。

**解题切入点**：先找绝对化、极端化表述。D 中“所有程序……都快”属于全称肯定，只需举出反例即可否定。本题考点是多核 CPU 的基本特点：多核通过并行提高吞吐能力，但收益受程序本身并行度的限制。可类比算法竞赛中多线程并行：若线程间同步频繁或任务本身不可拆分，开更多线程不会更快，反而增加调度开销。

**推演**：

对 A：双核 CPU 的标称频率 $2.4\mathrm{GHz}$ 通常指每个核心的时钟频率为 $2.4\mathrm{GHz}$，两个核心各自按此频率工作，并非把频率相加为 $4.8\mathrm{GHz}$。故 A 正确。

对 B：多核 CPU 把多个处理核心集成在同一芯片内。动态功耗近似为
$$
P_d \propto C V^2 f,
$$
在目标性能相同的前提下，双核可以降低单核所要求的主频 $f$，并可相应降低电压 $V$，从而降低功耗；多核集成也有利于减小系统体积。故 B 正确。

对 C：多核 CPU 的多个核心共用一组主存，通过共享内存进行数据通信；每个核心可以有私有 cache，但主存是共享的。故 C 正确。

对 D：设程序中可并行部分比例为 $p$，使用 $n$ 个核心的理论加速比满足 Amdahl 定律：
$$
S(n)=\frac{1}{(1-p)+p/n}.
$$
若 $p=1$，理论上 $S(n)=n$；但若 $p<1$，加速比受串行部分限制；若 $p=0$，$S(n)=1$。再加上线程调度、同步和 cache 一致性带来的额外开销，实际运行速度甚至可能小于 1。所以“所有程序在多核 CPU 上运行速度都快”错误。

**易错点**：

1. 误把双核 CPU 频率理解为“两核频率之和”，如认为 $2.4\mathrm{GHz}$ 双核总频率为 $4.8\mathrm{GHz}$；实际上双核的 $2.4\mathrm{GHz}$ 通常指每个核心的频率。
2. 误以为多核 CPU “一定”省电、体积小；B 成立的前提是“同等性能/设计目标”下，并非任何情况下都成立。
3. 误以为多核 CPU 各核心各有独立内存；实际上主存（一组内存）是共享的，cache 可私有也可共享。
4. 对“所有”“都”“一定”等绝对化表述不敏感；应首先想到全称命题可能被反例推翻。

**命题规律**：本题属于计算机组成原理中“多核 CPU 的基本概念”和“并行性能模型”。常见变式包括：判断多核 CPU 的优点，计算 Amdahl 定律加速比，区分多核 CPU、多 CPU 和超线程，考查共享内存与 cache 一致性。复习时应理解多核为何能降低功耗和体积、为何不是对所有程序都有加速，并牢记绝对化选项往往是错误项。可结合 Amdahl 定律做题：只要程序存在不可并行部分，加速比就有上限。

# 选择题 第 2 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-54-M02_题目.png|题目]]

2. 在组合逻辑控制器中,微操作控制信号的形成主要与（ ）信号有关.

A. 指令操作码和地址码
B. 指令译码信号和时钟
C. 操作码和条件码
D. 状态信息和条件

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-54-M02_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B（指令译码信号和时钟）。  
一句话理由：组合逻辑控制器的微操作控制信号由组合逻辑电路直接产生，必须同时依靠指令译码信号确定“发什么控制信号”，依靠时钟/节拍信号确定“何时发”。

**解题切入点**：  
先判断控制器类型：组合逻辑控制器又称硬布线控制器，不是微程序控制器，它没有控制存储器，而是用门电路直接产生控制信号。所以解题关键就在于“这个组合逻辑电路的输入有哪些”。可以类比数字电路设计题：先写真值表的输入列，输入主要包括指令译码信号和时钟节拍信号；状态条件只是条件类指令的辅助输入。由此排除地址码、单独条件码等干扰项。

**推演**：  
1. 一条指令的执行过程按机器周期和时钟节拍划分。例如取指周期又可以分成若干节拍，每个节拍发出对应的微操作控制信号。  
2. 指令寄存器中的操作码需要经过指令译码器译码，产生指令译码信号 $D_i$。这些信号用来区分当前执行的是哪条指令，从而决定执行阶段应发出哪些微操作控制信号。  
3. 时钟信号经节拍发生器产生节拍信号 $T_j$，用来表示当前处于哪一个时钟周期。微操作控制信号必须按时序发出，所以时钟/节拍信号是必不可少的。  
4. 不考虑条件类指令时，某微操作控制信号 $C_i$ 可写成最基本的逻辑函数形式：
$$C_i = f(D_i, T_j)$$
其中 $D_i$ 是指令译码信号，$T_j$ 是时钟节拍信号。条件码/状态条件只在条件转移等特殊情况下参与，是辅助输入，不是“主要”共性输入。

逐项分析：

- A 错：地址码主要用于形成操作数地址，不是控制信号形成的主要依据。  
- B 对：指令译码信号和时钟节拍是组合逻辑控制器生成微操作控制信号的核心输入。  
- C 错：缺少时钟/节拍信号，无法按时序产生微操作。  
- D 错：状态信息和条件只能作为辅助输入，缺少指令译码信号，无法区分不同指令。

**易错点**：  
- 误选 A：把指令的组成“操作码 + 地址码”误当成控制器的输入，忽略了地址码主要用于寻址。  
- 误选 C：只看到操作码和条件码，忽略组合逻辑控制器必须有时钟/节拍信号来控制时序。  
- 误选 D：状态信息和条件虽然会参与条件转移等操作，但不能作为主要控制信号来源，因为它不能区分指令。  
- 混淆“操作码”和“指令译码信号”：操作码需要先经过译码器，变成独立的译码信号后，才能作为组合逻辑控制器的输入。  
- 若题目改成“微程序控制器”，则不能选 B，而应选与微指令、微地址相关的说法。

**命题规律**：  
考点是控制器两种实现方式的原理对比，重点考查组合逻辑控制器的输入信号、产生方式及特点。常见变式包括：比较硬布线控制器和微程序控制器的速度、规整性、可修改性；考查微程序控制器中微操作控制信号来自微指令字段译码；给出某条指令的微操作序列，判断控制器应根据哪些信号产生控制信号。复习时应把“指令译码信号、时钟/节拍信号、状态条件”三个关键词联系起来，并与微程序控制器进行对比记忆。

# 选择题 第 1 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-51-M01_题目.png|题目]]

1. $CPU$的核心功能是执行程序,下列不属于$CPU$的基本功能的是( )
A. 时序控制
B. 异常与中断处理
C. 执行算术和逻辑运算
D. 数据存储

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-51-M01_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。CPU 的基本功能不包括“数据存储”，数据存储主要由存储系统（主存、辅存等）完成；CPU 的基本功能通常是指令控制、操作控制、时间控制（时序控制）和数据加工（算术逻辑运算），异常与中断处理也是 CPU 的重要功能。

**解题切入点**：拿到题目先明确“CPU 的基本功能”这一概念，不要被“核心功能是执行程序”带偏。可以把 CPU 理解为“指挥中心”和“加工车间”：它负责取指令、分析指令、执行指令、控制时序，并处理突发事件；而“存放数据”是“仓库”（存储器）的职责。因此定位考点为：CPU 的功能划分。

**推演**：

CPU 的基本功能可以从它执行程序的过程中归纳出来：

1. **指令控制**：CPU 必须按顺序取出指令、分析指令并执行指令，保证程序按规定的次序运行。
2. **操作控制**：一条指令往往由若干操作组成，CPU 要产生并管理这些操作的控制信号，控制各部件协调工作。
3. **时间控制**：各种操作都有严格的时序关系，CPU 需要提供时序信号，使各操作按时间节拍进行，这就是**时序控制**。
4. **数据加工**：CPU 通过算术逻辑单元（ALU）完成算术运算和逻辑运算，即对数据进行加工处理。

此外，CPU 还必须具备**异常与中断处理**能力，以便在程序执行过程中响应外部中断或内部异常，转去执行相应的处理程序。

从选项看：

- A. 时序控制：属于 CPU 基本功能中的“时间控制”。
- B. 异常与中断处理：属于 CPU 的重要功能，负责中断响应与处理。
- C. 执行算术和逻辑运算：对应“数据加工”，是 CPU 的核心运算功能。
- D. 数据存储：存储器（主存、Cache、辅存等）负责存储数据和指令。CPU 内部的寄存器虽然可以暂存数据，但“数据存储”本身不是 CPU 的基本功能，而是存储系统的功能。

因此，不属于 CPU 基本功能的是 D。

**易错点**：

1. **误选 B（异常与中断处理）**：有些同学认为中断处理不属于“基本功能”，但中断机制是现代 CPU 必备的功能，异常与中断处理是 CPU 的重要组成部分，因此在 408 中应将其视为 CPU 的功能。
2. **误选 C（执行算术和逻辑运算）**：容易把 CPU 的“基本功能”和“运算器功能”混在一起。运算器功能是数据加工，但 CPU 还包括控制器功能，整体上数据加工仍属于 CPU 基本功能。
3. **误选 A（时序控制）**：时序控制是控制器的重要工作，是 CPU 执行指令时必不可少的环节，不能排除。
4. **把“CPU 内部寄存器”与“数据存储”混淆**：CPU 内部有通用寄存器、状态寄存器等，但它们的功能是参与运算和暂存中间结果，不是大容量数据的存储场所。“数据存储”整体上由存储系统完成。

**命题规律**：本考点属于计算机组成原理中的“CPU 的功能与结构”，常以选择题形式考查 CPU 与存储器、I/O 设备之间的功能划分。常见变式包括：

- 给出若干功能，要求选出“属于 CPU 基本功能”或“不属于 CPU 基本功能”的项；
- 将 CPU 功能与运算器、控制器、存储器的功能进行辨析；
- 结合指令执行过程，考查指令控制、操作控制、时间控制的具体体现。

复习建议：熟记 CPU 基本功能的四个关键词“指令控制、操作控制、时间控制、数据加工”，并补充“中断处理”这一重要功能。做题时先抓住功能主体——CPU 负责“控制”和“计算”，存储由内存负责，I/O 由接口负责，这样就能快速排除错误选项。

# 选择题 第 1 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-53-M01_题目.png|题目]]

1.下列不属于 $CPU$ 数据通路结构的是(  )

(A) 单总线结构  
(B) 多总线结构  
(C) 部件内总线结构  
(D) 专用数据通路结构

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-53-M01_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。CPU 数据通路常见结构包括单总线结构、多总线结构和专用数据通路结构，“部件内总线结构”不属于其分类。

**解题切入点**：先明确“数据通路”是 CPU 内部各功能部件（寄存器、ALU 等）之间传输数据的路径组织方式。题目问“不属于”，只需回忆课本中数据通路结构的经典分类，排除法即可。这就像算法竞赛里考“以下哪种排序不是稳定排序”，先把常见稳定排序列出来，剩下的就是答案。

**推演**：

1. 数据通路（Data Path）是 CPU 中寄存器与寄存器、寄存器与 ALU 之间进行数据传送的路径。其结构设计直接决定 CPU 内部并行性和控制方式。
2. 按总线组织形式，数据通路结构通常分为：
   - **单总线结构**：所有寄存器输出端和输入端都连接在同一条总线上，结构简单，但同一时刻只能传输一个数据，冲突较多，效率低。
   - **多总线结构**：使用两条或更多总线连接各部件，可同时传输多个数据，提高并行性，如双总线、三总线结构。
   - **专用数据通路结构**：各部件之间直接通过专用线路连接，不经过共享总线，延迟小、并行度高，但连线复杂、硬件开销大。
3. 选项 C“部件内总线结构”并不是描述 CPU 整体数据通路的组织形式，而是指某个功能部件内部（如 ALU 内部、寄存器内部）用于连接其子部件的总线。它属于部件内部的设计细节，不属于 CPU 数据通路结构的宏观分类。
4. 因此，不属于 CPU 数据通路结构的是 C。

**易错点**：
- 误以为“部件内总线”也是总线结构的一种，从而漏选。区分标准是：数据通路结构讨论的是**CPU 内部各寄存器、ALU 等部件之间**的互连方式，而不是某个部件内部的连线。
- 容易与“片内总线”混淆。片内总线指芯片内部的总线，但本题说的是“部件内总线”，更强调部件内部，与数据通路分类无关。
- 复习时可将三种经典结构对比记忆：单总线（简单但慢）、多总线（折中）、专用数据通路（快但复杂）。

**命题规律**：
- 考点定位于“CPU 内部结构”中的数据通路概念，属于计算机组成原理的基础知识，常以选择题形式考查。
- 常见变式：给出某种结构特点，要求判断属于哪种数据通路；或考查单总线/多总线结构的性能比较（如时钟周期、冲突次数）；也可能结合指令周期分析总线占用情况。
- 复习建议：熟记数据通路的三种经典结构及其优缺点；理解“部件内总线”与“数据通路”的层次差异；可结合具体 CPU 模型（如 MIPS 单周期、多周期）分析数据通路图，增强直观理解。

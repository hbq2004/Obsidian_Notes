# 选择题 第 5 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-53-M05_题目.png|题目]]

5. $CPU$内部如果多个部件共享一条总线,则每个部件与总线之间需设置一个常用的器件,$CPU$控制该器件的状态,实现某个部件与总线的连接或断开。该器件是（ ）

(A) 触发器
(B) 多路选择器
(C) 三态门
(D) 与非门

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-53-M05_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。多个部件共享总线时，需要通过三态门控制部件与总线的连接/断开，高阻态可实现隔离。

**解题切入点**：看到“共享一条总线”和“连接或断开”，立刻想到总线仲裁与隔离问题。多个部件不能同时向总线输出数据，否则会发生逻辑冲突；因此需要一种能“断开”输出的器件。打比方：这就像多个人合用一部电话（总线），每个人讲话前必须用开关把自己的话筒接入线路，不用时则断开，否则大家同时说话就会乱套。这里“开关”就是三态门。

**推演**：

总线是一组共享传输介质，多个部件（如 CPU 内部寄存器、ALU 等）的输出端若都直接连到同一条总线上，则当多个部件同时向总线输出不同电平时，会在总线上产生逻辑冲突（“线与”或“线或”会造成不确定状态，甚至损坏电路）。因此，每个部件的输出端必须经过一个可控的隔离器件，平时使其输出呈高阻态（相当于断开），需要该部件驱动总线时再使能。

这个器件需要满足：

- 输出有三种状态：逻辑 0、逻辑 1、高阻态 Z；
- 高阻态时对总线没有影响，相当于“断开”；
- 控制端由 CPU 发出的控制信号决定处于正常输出还是高阻态。

三态门（三态缓冲器/三态驱动器）恰好具有上述功能。其真值关系为：

- 使能端 $EN=1$ 时，输出 $Y = A$（或取反，视具体类型而定），即正常输出；
- 使能端 $EN=0$ 时，输出 $Y = Z$（高阻态），即与总线断开。

因此，CPU 通过控制各个三态门的使能端，就可以在同一时刻只让一个部件向总线输出数据，实现分时共享。

其他选项辨析：

- 触发器：用于存储一位信息，没有高阻态，不能隔离；
- 多路选择器：用于从多个输入中选择一个输出，但多个部件本身仍需先经过三态门或类似机制接入总线，且多路选择器不是用来“断开/连接”的；
- 与非门：普通逻辑门，输出只有 0 和 1，没有高阻态，无法实现断开。

**易错点**：

1. 误选多路选择器：多路选择器确实可以选择多个输入之一，但它要求所有输入信号一直有效，而总线上多个部件输出信号可能随时变化，若直接用多路选择器仍无法彻底隔离不选中的部件的输出，也不能解决输出端相互驱动的问题。总线共享的标准做法是三态门。
2. 误选触发器：触发器只能存储信息，无法实现输出与总线的隔离。
3. 混淆“高阻态”与“断开”的概念：高阻态是一种输出状态，相当于该器件对总线呈现极高阻抗，不影响总线上其他信号，这正是实现“断开”的方式。
4. 忽视 CPU 控制信号：题目强调“CPU 控制该器件的状态”，三态门的使能端正是由 CPU 控制的，符合题意。

**命题规律**：

本题属于计算机组成原理中“总线”章节的基础概念题，考查总线结构中的信号隔离与共享机制。常见变式包括：

- 考查三态门的功能描述或真值表；
- 结合总线数据传输过程，问某部件不向总线输出数据时其输出应处于什么状态（高阻态）；
- 在总线仲裁或 DMA 传送原理中，隐含使用三态门实现设备与总线的隔离。

复习建议：重点理解三态门与普通逻辑门、触发器的区别，掌握“高阻态”在总线共享中的作用，并能联系 CPU 内部总线的实际连接方式（如寄存器输出端通过三态门接总线）进行记忆。此类题目属于送分题，注意基础概念辨析即可。

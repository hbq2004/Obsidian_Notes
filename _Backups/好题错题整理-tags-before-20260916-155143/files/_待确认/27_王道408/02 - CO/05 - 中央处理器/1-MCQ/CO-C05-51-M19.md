# 选择题 第 19 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-51-M19_题目.png|题目]]

19. $CPU$中不包括（  ）

A. 存储器地址寄存器

B. 指令寄存器

C. 地址译码器

D. 程序计数器

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-51-M19_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。CPU 中包含 $\mathrm{MAR}$、$\mathrm{IR}$、$\mathrm{PC}$ 等寄存器或接口寄存器；地址译码器是主存中用来选择存储单元的部件，不属于 CPU。

**解题切入点**：题目问“CPU 中不包括”，相当于做“部件归属”判断题。先回忆 CPU 的组成框图，再把选项逐个归类。看见“地址译码”要立刻联想到“主存根据地址找到对应存储单元”，而不是 CPU 内部的译码功能。

**推演**：

CPU 的主要功能是取指令、分析指令和执行指令，其组成可记为：

$$
\mathrm{CPU} = \text{运算器} + \text{控制器} + \text{寄存器组} + \text{内部总线/接口逻辑}
$$

其中控制器包含 $\mathrm{PC}$、$\mathrm{IR}$ 等，接口逻辑包含 $\mathrm{MAR}$、$\mathrm{MDR}$ 等。

- 选项 A：存储器地址寄存器 $\mathrm{MAR}$  
  保存 CPU 当前要访问的存储单元地址，是 CPU 与主存之间的地址接口寄存器，通常属于 CPU。CPU 先把地址送入 $\mathrm{MAR}$，再通过地址总线送到主存。

- 选项 B：指令寄存器 $\mathrm{IR}$  
  保存当前正在执行的指令，属于控制器。指令的操作码部分由指令译码器译码，产生控制信号。

- 选项 D：程序计数器 $\mathrm{PC}$  
  保存待取指令的地址，取指后自动修改为下一条指令地址，属于控制器，是 CPU 必不可少的寄存器。

- 选项 C：地址译码器  
  主存中有大量存储单元，CPU 送来的地址只是并行二进制信号，必须经过地址译码器译码，才能选中某一个或某一组存储单元。地址译码器位于主存内部，不属于 CPU。

因此，A、B、D 都属于 CPU 或 CPU 的接口部件，C 不在 CPU 中。

**易错点**：
- 容易把“地址译码器”和“指令译码器”混淆。CPU 内的是指令译码器，用来翻译 $\mathrm{IR}$ 中的操作码；主存内的是地址译码器，用来翻译地址信号。
- 有的同学误以为 $\mathrm{MAR}$ 在主存中。按 408 教材的划分，$\mathrm{MAR}$、$\mathrm{MDR}$ 通常作为 CPU 与主存之间的接口寄存器放在 CPU 一侧。
- 注意题干是“不包括”，不要只凭“CPU 包含译码器”的印象去选，要明确是“地址译码器”还是“指令译码器”。

**命题规律**：
- 本考点是计算机系统层次结构中 CPU 与主存的部件划分，属于基础题。
- 常见变式：把选项换成“主存中不包括”“CPU 中属于控制器的部件是”“下列哪个不是 CPU 中的寄存器”等。
- 复习建议：画一张“CPU—主存—I/O”的系统框图，标注各部件的归属；重点记住 $\mathrm{PC}$、$\mathrm{IR}$、$\mathrm{MAR}$、$\mathrm{MDR}$ 的功能与位置，以及“指令译码器在 CPU，地址译码器在主存”这一对应关系。

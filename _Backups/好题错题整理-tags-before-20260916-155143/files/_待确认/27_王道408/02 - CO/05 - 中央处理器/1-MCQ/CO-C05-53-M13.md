# 选择题 第 13 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-53-M13_题目.png|题目]]

13. $CPU$的读 / 写控制信号的作用是（ ）
(A) 决定数据总线上的数据流方向
(B) 控制存储器操作的读 / 写类型
(C) 控制流入、流出存储器信息的方向
(D) 以上都是

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-53-M13_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。读/写控制信号同时决定了数据总线上数据流的方向、存储器操作的读/写类型，以及流入/流出存储器的信息方向，因此以上说法都正确。

**解题切入点**：看到“读/写控制信号”应立刻联想到 CPU 与存储器之间的控制总线。读/写信号本质上是 CPU 对外发出的控制信息，它同时影响数据总线的方向、存储器内部操作类型以及信息流动方向。可以类比为“双向道路上的红绿灯”：灯亮“读”时，数据从存储器流向 CPU；灯亮“写”时，数据从 CPU 流向存储器。本题属于概念辨析题，需要判断每个选项是否为读/写控制信号的直接作用，而不是只选其中一个片面说法。

**推演**：

CPU 通过系统总线与存储器、I/O 接口相连。系统总线按功能分为地址总线、数据总线和控制总线。

- 数据总线用于传输数据信息，是双向传输的：CPU 从存储器读数据时，数据由存储器流向 CPU；CPU 向存储器写数据时，数据由 CPU 流向存储器。数据总线上数据的具体流向，需要由控制信号来指示。  
- CPU 发出的读/写控制信号（如 $\overline{RD}$、$\overline{WR}$ 或 $R/W$）是控制总线上的关键信号。当 $R/W=1$ 时表示读，当 $R/W=0$ 时表示写（具体高/低电平定义因系统而异，但功能都是区分读和写操作）。

逐项分析：

(A) 决定数据总线上的数据流方向  
读操作时，数据总线上的数据从存储器（或输入设备）传向 CPU；写操作时，数据从 CPU 传向存储器（或输出设备）。显然，读/写控制信号决定了数据总线的数据流方向，A 正确。

(B) 控制存储器操作的读/写类型  
存储器芯片内部需要根据读写控制信号选择进行读操作还是写操作。例如 SRAM 芯片的写使能信号 $WE$ 有效时执行写，无效时执行读。因此 B 正确。

(C) 控制流入、流出存储器信息的方向  
读操作时信息流出存储器进入 CPU；写操作时信息从 CPU 流入存储器。读/写控制信号直接决定了这一方向，C 正确。

(D) 以上都是  
由于 A、B、C 均正确，故 D 为正确答案。

**易错点**：

1. **只选 B 而漏选 A、C**：有些考生认为读/写控制信号只是“控制存储器读还是写”，忽略了它同时决定数据总线方向和流入流出存储器的方向。实际上这三个说法是从不同角度描述同一个控制信号的作用，并不矛盾。  
2. **混淆数据流方向与数据总线方向**：数据总线本身是双向的，但某一时刻只能一个方向传输；读/写信号正是用来切换这个方向的，所以 A 正确。  
3. **误以为 D 是“以上都是”而犹豫**：在 408 选择题中，“以上都是”只要前三个描述都合理，就不能轻易排除；尤其在这类概念题中，D 往往是正确答案。  
4. **忽视控制信号的具体电平定义**：有些教材用 $R/W$，有些用 $\overline{RD}$、$\overline{WR}$，但本质都是区分读/写的控制信号，不影响本题结论。

**命题规律**：

本题属于计算机组成原理中“系统总线与接口”或“存储器与 CPU 的连接”部分的概念考查，难度较低，主要考查对 CPU 控制信号作用的理解。常见变式有：给出具体信号名（如 $\overline{RD}$、$\overline{WR}$）判断其作用；结合三态门说明数据总线为何需要双向控制；或者在存储器扩展题中，要求连接读写控制引脚。复习时建议：一是掌握总线分类（地址、数据、控制）及各信号作用；二是理解读/写周期中数据总线上信息的流向；三是能区分“控制信号”与“数据信号”“地址信号”的功能差异。这类基础题一定要拿满分。

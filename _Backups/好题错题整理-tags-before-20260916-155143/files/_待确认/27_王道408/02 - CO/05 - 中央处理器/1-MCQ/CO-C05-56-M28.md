# 选择题 第 28 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-56-M28_题目.png|题目]]

28.【2019统考真题】在采用“取指、译码/取数、执行、访存、写回”5段流水线的处理器中，执行如下指令序列，其中 $s0$、$s1$、$s2$、$s3$ 和 $t2$ 表示寄存器编号。下列指令对中，不存在数据冒险的是（ ）

I1: add $s2, s1, s0$     // $R[s2] \leftarrow R[s1] + R[s0]$
I2: load $s3, 0(t2)$     // $R[s3] \leftarrow M[R[t2] + 0]$
I3: add $s2, s2, s3$     // $R[s2] \leftarrow R[s2] + R[s3]$
I4: store $s2, 0(t2)$    // $M[R[t2] + 0] \leftarrow R[s2]$

A. $I1$ 和 $I3$
B. $I2$ 和 $I3$
C. $I2$ 和 $I4$
D. $I3$ 和 $I4$

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-56-M28_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C（I2 与 I4 之间无寄存器数据依赖，故不存在数据冒险）

**解题切入点**：首先明确每条指令读/写的寄存器，然后检查各指令对之间是否存在写后读（RAW）相关，这是流水线数据冒险的主要来源。注意 load 指令写目标寄存器，store 指令读源寄存器。

**推演**：
- I1: `add $s2, $s1, $s0` → 写 $s2$，读 $s1, s0$。
- I2: `load $s3, 0($t2)` → 写 $s3$，读 $t2$。
- I3: `add $s2, $s2, $s3` → 写 $s2$，读 $s2, s3$。
- I4: `store $s2, 0($t2)` → 读 $s2$ 和 $t2$，写内存。

对选项分析：
- A（I1 与 I3）：I1 写 $s2$，I3 读 $s2$，存在 RAW，故有数据冒险。
- B（I2 与 I3）：I2 写 $s3$，I3 读 $s3$，存在 RAW，故有数据冒险。
- C（I2 与 I4）：I2 写 $s3$，I4 读 $s2$，无公共寄存器，无数据依赖，故无数据冒险。
- D（I3 与 I4）：I3 写 $s2$，I4 读 $s2$，存在 RAW，故有数据冒险。

因此，只有 C 对不存在数据冒险。

**易错点**：易误认为 I4 写 $s2$（实际 store 是写内存，读寄存器），或忽略 I3 读 $s2$ 与 I1 写 $s2$ 的依赖；注意 load 指令写目标寄存器，后续指令使用该寄存器即产生 RAW。

**命题规律**：常以指令序列形式考查数据冒险的识别，重点是 RAW 和 load-use 延迟。复习时应熟练掌握各指令的读/写行为，并能在流水线中分析数据相关。

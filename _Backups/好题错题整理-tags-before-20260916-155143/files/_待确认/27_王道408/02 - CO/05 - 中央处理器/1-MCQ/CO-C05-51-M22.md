# 选择题 第 22 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-51-M22_题目.png|题目]]

22.【2010统考真题】下列寄存器中,汇编语言程序员可见的是（\_\_\_\_）

(A) 存储器地址寄存器($MAR$)
(B) 程序计数器($PC$)
(C) 存储器数据寄存器($MDR$)
(D) 指令寄存器($IR$)

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-51-M22_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。程序计数器 $PC$ 是汇编语言程序员可见的寄存器，程序员可以通过转移、调用、返回等指令显式修改它；而 $MAR$、$MDR$、$IR$ 属于 CPU 内部工作寄存器，对程序员透明，不可直接访问。

**解题切入点**：看到“汇编语言程序员可见”立刻定位到“指令集体系结构中的程序员可见状态”这一考点。可以这样类比：可见寄存器相当于编程时能直接操作的“公共变量”，而 $MAR$、$MDR$、$IR$ 是 CPU 内部自动使用的“临时变量”，程序员完全不关心它们何时被写入、读出。

**推演**：  
汇编语言程序员能够通过指令直接读写或间接影响的寄存器称为“程序员可见寄存器”。常见的有：

- 通用寄存器（如 $AX$、$BX$、$CX$、$DX$ 等）；
- 程序计数器 $PC$（也称指令指针 $IP$）；
- 程序状态字寄存器 $PSW$ 或标志寄存器。

$PC$ 虽然由 CPU 自动更新，但程序员可以通过转移指令（如 `JMP`）、调用指令（如 `CALL`）、返回指令（如 `RET`）显式改变其值，因此它属于程序员可见寄存器。

再看其余三个：

- 存储器地址寄存器 $MAR$：用于存放欲访问内存单元的地址，由 CPU 自动填入，程序员无法用指令指定；
- 存储器数据寄存器 $MDR$：用于存放从内存读入或写入内存的数据，是数据通路的暂存器；
- 指令寄存器 $IR$：用于存放当前正在执行的指令，完全由控制单元控制。

这三个寄存器都是 CPU 内部工作寄存器，对汇编语言程序员“透明”，即程序员在编写汇编程序时不需要、也无法直接访问它们。

因此正确选项为 B。

**易错点**：

1. 将 $IR$ 和 $PC$ 混淆。$PC$ 存的是“下一条指令的地址”，程序员通过跳转指令可以改变它；$IR$ 存的是“当前正在执行的指令”，程序员无法用指令指定。
2. 认为 $MAR$、$MDR$ 与内存有关，就误以为它们也可被程序员访问。实际上它们只是 CPU 与内存之间的“周转寄存器”，由硬件自动控制。
3. 判断标准不统一。牢记：能否在汇编指令中显式写出该寄存器名或通过指令效果影响它，是判断“程序员可见”的核心标准。

**命题规律**：  
本题属于计算机组成原理中“CPU 内部结构”与“指令集体系结构”的交叉考点。常见变式有：

- 给出多个寄存器，问哪些对汇编程序员可见；
- 结合指令周期，问在取指、间址、执行、中断等阶段分别用到哪些寄存器；
- 结合流水线，问哪些寄存器需要由硬件自动保存和恢复；
- 结合中断，问中断隐指令保存的是 $PC$ 还是 $IR$。

复习建议：熟记 $PC$、$IR$、$MAR$、$MDR$、通用寄存器、状态寄存器等核心寄存器的功能与可见性，并结合具体指令（如 `JMP`、`CALL`）理解 $PC$ 的程序员可见性。这样既能应对选择题，也能为后续指令流水线、中断等综合题打下基础。

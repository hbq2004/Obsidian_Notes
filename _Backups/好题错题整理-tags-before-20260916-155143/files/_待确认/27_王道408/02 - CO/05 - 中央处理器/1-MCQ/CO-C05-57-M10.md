# 选择题 第 10 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-57-M10_题目.png|题目]]

10. 下列关于多核 $CPU$ 的描述中,正确的是 (  )

A. 各核心完全对称,拥有各自的 $Cache$

B. 任何程序都可以同时在多个核心上运行

C. 一颗 $CPU$ 中集成了多个完整的执行内核,可同时进行多个运算

D. 只有使用了多核 $CPU$ 的计算机,才支持多任务操作系统

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-57-M10_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C（一颗 CPU 中集成了多个完整的执行内核，可同时进行多个运算）  
**解题切入点**：本题直接考查多核 CPU 的基本定义。拿到题目应首先定位考点为“多核处理器概念”，核心是区分“多核”与“多任务”“并行”等易混淆点。将每个选项与多核 CPU 的特征一一对照，排除明显错误或表述不准确的选项。  
**推演**：  
- **选项 A**：多核 CPU 各核心通常对称（同构），但并非绝对（如大小核异构架构）；缓存方面，每个核心拥有私有的 L1 缓存，但通常共享 L2 或 L3 缓存，因此“拥有各自的 Cache”表述不全面，忽略了共享缓存的存在，故 A 错误。  
- **选项 B**：程序能否在多个核心上同时运行取决于其是否被设计为多线程/多进程，且需要操作系统的调度支持。单线程程序只能在一个核心上运行，因此“任何程序都可以”的说法错误。  
- **选项 C**：多核 CPU 的定义即为在一个芯片上集成多个完整的执行内核，每个内核能独立执行指令，从而支持真正的并行运算，C 正确。  
- **选项 D**：多任务操作系统通过时间片轮转等机制，在单核 CPU 上也能实现并发多任务，因此多核并非多任务操作系统的必要条件，D 错误。  
**易错点**：  
- 易误选 A，错误认为多核 CPU 一定完全对称且每个核心拥有所有缓存。实际上，缓存通常分层次，私有缓存与共享缓存并存，且异构多核已逐渐普及。  
- 易与“多线程”“超线程”混淆，需注意多核是物理核心并行，而超线程是单核模拟多线程。  
**命题规律**：  
- 考点：多核 CPU 的基本概念、特征及其与多任务、并行性的关系。  
- 常见变式：结合“多核 vs 多 CPU”“缓存结构”“并行计算条件”等出题。  
- 复习建议：准确理解多核 CPU 的定义，掌握其缓存层次结构（私有/共享），明确“多核”与“多任务”并不等价，同时注意区别“对称多核”与“异构多核”的现代趋势。

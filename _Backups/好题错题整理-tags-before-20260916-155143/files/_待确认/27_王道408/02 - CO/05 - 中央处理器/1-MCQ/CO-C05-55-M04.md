# 选择题 第 4 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-55-M04_题目.png|题目]]

4. 以下关于异常和中断响应的叙述中,错误的是 ( )

A. 异常事件检测由 $CPU$ 在执行每一条指令的过程中进行  
B. 中断请求检测由 $CPU$ 在每条指令执行结束、取下条指令之前进行  
C. $CPU$ 检测到异常事件后所做的处理和检测到中断请求后所做的处理完全相同  
D. $CPU$ 在中断响应时会关中断、保存断点和程序状态并转到相应的中断服务程序

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-55-M04_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。  
理由：异常与中断在检测时机、来源、断点含义等方面不同，CPU 对二者的响应处理并非“完全相同”。

**解题切入点**：  
先抓住“异常”和“中断”这对核心概念的区别：异常是 CPU 内部、与当前指令同步发生的事件；中断是外部设备等发出、与当前指令异步发生的事件。做题时可以类比程序中的“同步错误”和“异步信号”：同步错误只能在执行语句过程中发现，异步信号只能在一条语句执行完、下一条语句开始前处理。

**推演**：

异常（exception）又称“内中断”，通常由 CPU 执行指令过程中发生的内部事件引起，例如：

- 除零异常；
- 溢出异常；
- 缺页异常；
- 非法指令、非法地址等。

因此，CPU 需要**在执行每条指令的过程中检测是否发生异常事件**。选项 A 正确。

中断（interrupt）又称“外中断”，由 CPU 外部的设备或事件发出请求，例如：

- I/O 设备完成数据传送；
- 时钟中断；
- 电源故障等。

这些外部请求与当前正在执行的指令没有固定时间关系，因此 CPU 通常只在**每条指令执行结束、取下一条指令之前**统一检测一次中断请求。若满足响应条件，则在指令边界进入中断响应。选项 B 正确。

CPU 响应中断时的基本过程为：

1. **关中断**，阻止在保存现场期间再次响应新的中断；
2. **保存断点**，即保存当前程序计数器 PC 的值；
3. **保存程序状态字 PSW** 或现场信息；
4. **识别中断源**，根据中断号/中断向量找到对应的中断服务程序入口；
5. 转到相应的中断服务程序执行。

因此选项 D 正确。

选项 C 说“CPU 检测到异常事件后所做的处理和检测到中断请求后所做的处理完全相同”，这是错误的。异常和中断并不完全相同：

- 异常是 CPU 内部产生的，和当前指令同步；中断是外部请求，和当前指令异步。
- 异常可能在指令执行过程中被检测到，而中断只能在指令边界被采样。
- 异常发生后保存的断点可能是当前指令、下一条指令，甚至可能是不精确的；普通中断发生后保存的断点通常就是下一条指令的地址。
- 异常处理往往需要根据异常类型进一步区分，如故障（fault）、自陷（trap）、终止（abort），其处理方式不同。

所以错误项为 C。

**易错点**：

1. **把“异常”和“中断”混为一谈**。异常是内部同步事件，中断是外部异步事件，二者检测时机不同。
2. **误以为 CPU 每执行一条指令都会发生异常**。A 项的意思是“检测异常”这个动作在每条指令执行过程中都会进行，而不是每条指令都必然发生异常。
3. **看到“完全相同”这类绝对化表述时不够敏感**。说完全相同通常过于绝对，容易是错误的题眼。
4. **忽略断点含义的差别**。中断响应的断点一般指下一条指令地址；异常响应的断点需要看异常类型，比如缺页异常需要重新执行当前指令。

**命题规律**：  
本题属于计算机组成原理“输入输出系统”中的中断系统部分，重点考查异常与中断的区别、中断响应的基本过程。常见变式有：

- 判断异常和中断检测时机；
- 考查中断响应周期中的“中断隐指令”；
- 考查断点保存的是哪条指令的地址；
- 考查故障、自陷、终止的区别。

复习时应把“异常”和“中断”做成对比表格，从来源、同步性、检测时机、响应断点、处理方式等方面记忆，同时熟练掌握中断响应过程的先后顺序。

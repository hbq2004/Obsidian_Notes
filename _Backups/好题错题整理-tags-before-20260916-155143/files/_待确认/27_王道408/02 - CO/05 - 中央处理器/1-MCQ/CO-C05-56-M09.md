# 选择题 第 9 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-56-M09_题目.png|题目]]

9. 下列关于结构冒险的叙述中,正确的是（ ）

I. 结构冒险是指多条指令在同一时钟周期争用同一个硬件资源

II. 规定每条指令只能在指定流水段访问特定功能部件,可减少结构冒险

III. 通过重复设置功能部件（如多个 $ALU$）可以避免结构冒险

IV. 将数据 $Cache$ 与指令 $Cache$ 分离,可解决取指和取数同时访存引起的结构冒险

(A) I、II、IV  
(B) I、II、III  
(C) I、III、IV  
(D) I、II、III 和 IV

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-56-M09_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D（I、II、III、IV）。四句分别对应结构冒险的定义、访问时序约束、资源重复和 Cache 分离，均正确。

**解题切入点**：先定位考点：流水线三类冒险中的“结构冒险”，又称“资源冲突”。拿到题目先抓住“多条指令同一时刻争用同一硬件资源”这个定义，再逐条检查：I 是定义；II、III、IV 是常见的减少/避免结构冒险的手段。不要把结构冒险和数据冒险、控制冒险混为一谈。

**推演**：

1. **I 正确。** 结构冒险的本质是资源冲突：在流水线重叠执行过程中，多条指令可能处于不同流水段，恰好同一时钟周期需要访问同一个硬件资源，例如同一个存储器、同一个 $\mathrm{ALU}$ 或同一个寄存器堆端口。

2. **II 正确。** 规定每条指令只能在指定流水段访问特定功能部件，相当于把指令对硬件资源的访问时间窗口固定下来，避免指令随意占用功能部件，从而减少资源争用。例如把取数、运算、写回等操作安排在确定的流水段，使资源访问更有序。题目说的是“可减少”，不是“一定能完全消除”，因此表述正确。

3. **III 正确。** 通过重复设置功能部件，例如设置多个 $\mathrm{ALU}$，可以让多条同时需要运算的指令分别使用不同的 $\mathrm{ALU}$，从而避免因 $\mathrm{ALU}$ 数量不足而导致的结构冒险。这是解决结构冒险的常用方法之一。

4. **IV 正确。** 如果指令和数据共用一个 Cache 或主存，则一条指令在 $IF$ 段取指、另一条指令在 $MEM$ 段取数或存数时，可能在同一时钟周期争用存储器。将指令 Cache 与数据 Cache 分离后，取指和访存可同时进行，因此可以解决这类结构冒险。

综上，I、II、III、IV 都正确，故选 D。

**易错点**：

- 容易把 II 误判为错，认为“规定访问流水段”不能避免访存冲突。实际上 II 说的是“可减少”，是一种设计约束，正确。
- 容易把 III 绝对化，认为多个 $\mathrm{ALU}$ 不能避免所有结构冒险。但题目考察的是“资源重复可以避免相应资源导致的结构冒险”，多个 $\mathrm{ALU}$ 是典型例子。
- 容易把结构冒险和数据冒险混淆：数据冒险由数据依赖引起，不能靠分离 Cache 或增加 $\mathrm{ALU}$ 解决；结构冒险才是硬件资源争用问题。
- 注意题干措辞：“可减少”不等于“完全消除”，“可避免”也是针对相应资源冲突而言，不要过度引申。

**命题规律**：本题属于流水线冒险中的基础概念题，考点是结构冒险的定义和解决方法。常见变式有：判断某条叙述属于结构冒险、数据冒险还是控制冒险；给出具体流水线部件数量，判断是否会发生资源冲突；或将 I-Cache 与 D-Cache 分离、多个 $\mathrm{ALU}$、插入暂停等解决手段混合在一起考查。复习时应重点记忆三类冒险的成因和典型对策：结构冒险用“暂停、重复部件、分离 Cache、规定访问流水段”解决；数据冒险用“转发、暂停”解决；控制冒险用“分支预测、延迟槽、暂停”解决。

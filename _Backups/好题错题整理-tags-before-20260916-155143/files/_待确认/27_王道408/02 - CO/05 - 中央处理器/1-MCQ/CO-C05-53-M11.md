# 选择题 第 11 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-53-M11_题目.png|题目]]

11. 下列关于单周期$CPU$与采用单总线结构的多周期$CPU$的说法中,正确的是（  ）

A. 单周期$CPU$可基于单总线结构实现
B. 运行相同程序时,单周期$CPU$的总执行时间一定更短
C. 多周期$CPU$可将指令和数据存放在同一单端口存储器中,而单周期$CPU$不行
D. 单周期$CPU$的硬件实现成本通常低于多周期$CPU$.

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-53-M11_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。多周期 CPU 分步执行，可在不同时钟周期分别取指和访存，因此指令和数据可共用同一单端口存储器；单周期 CPU 在同一时钟周期内既要取指又可能访存，若用同一单端口存储器必然冲突。

**解题切入点**：先抓住“单周期/多周期”的本质区别：单周期用硬件并行换 CPI=1，多周期用时间分步换硬件复用。题目中的“单总线”和“单端口存储器”本质都是“同一时刻只能完成一次数据传送/访问”，所以应重点判断是否会发生同一时刻的访问冲突。可类比算法题中的“互斥资源同一时刻只能服务一个请求”：要么增加资源副本（单周期），要么分时复用（多周期）。

**推演**：

A 错误。单总线结构意味着同一时刻总线上只能传输一个数据。单周期 CPU 在一个时钟周期内既要取指，又要完成读寄存器、ALU 计算、写回；load/store 指令还需要在同一时钟周期内访问数据存储器。若采用单总线，这些并行的数据传送无法同时完成。若把它们分时完成，就不再是“单周期”了，所以单周期 CPU 不能基于单总线结构实现。

B 错误。设程序指令数为 $N$。单周期 CPU 每条指令用 1 个时钟周期，但时钟周期必须覆盖最长指令（如 load）的完整路径，记为 $t_s$，所以

$$
T_s=N t_s
$$

多周期 CPU 把一条指令分成若干步，平均每条指令需要 $\overline{CPI}_m>1$ 个时钟周期，但其时钟周期只需覆盖最长的一个功能段，记为 $t_m<t_s$，所以

$$
T_m=N\cdot \overline{CPI}_m\cdot t_m
$$

由于 $\overline{CPI}_m>1$ 且 $t_m<t_s$，两者乘积大小不定，不能推出“单周期总执行时间一定更短”。

C 正确。多周期 CPU 的取指和数据访存在不同时钟周期进行，每个时钟周期至多访问一次存储器，因此可以使用一个单端口存储器同时存放指令和数据。单周期 CPU 的 load/store 指令在同一时钟周期内既要取指，又要访问数据存储器；若指令和数据放在同一个单端口存储器中，就会发生访问冲突。因此单周期 CPU 通常需将指令存储器和数据存储器分开，或使用双端口存储器。

D 错误。单周期 CPU 为在一个周期内完成指令，需要提供足够并行的数据通路资源，通常要分离指令存储器和数据存储器，硬件成本较高。多周期 CPU 分步执行，可以复用同一套 ALU、存储器和总线，虽然控制逻辑较复杂，但数据通路硬件通常更省。因此“单周期 CPU 的硬件实现成本通常低于多周期 CPU”说反了。

**易错点**：

1. 误以为单周期 CPU 也能用单总线：只看到单周期 CPI=1，没看到单周期内部需要同时进行多次数据传送。规避：牢记单总线是“同一时刻只能传一个数据”。
2. 误以为单周期一定更快：只比较 CPI，不比较时钟周期长度。规避：执行时间统一用 $T=IC\times CPI\times \tau$ 估算。
3. 误以为指令和数据共用存储器与“单周期/多周期”无关：关键在于同一时钟周期内是否同时发生两次存储器访问。
4. 误以为多周期控制复杂所以硬件成本更高：单周期主要贵在数据通路资源，多周期通过分时复用降低成本。

**命题规律**：本题考点是单周期 CPU 与多周期 CPU 的对比，核心包括 CPI、时钟周期、总执行时间，以及指令/数据存储器与总线结构的关系。常见变式有：给出单周期和多周期的时钟频率、平均 CPI，计算并比较总执行时间；或将单周期、多周期、流水线三者放在一起比较。复习时应重点掌握性能公式 $T=IC\times CPI\times \tau$，并理解单周期“空间并行”、多周期“时间复用”的资源取舍关系。

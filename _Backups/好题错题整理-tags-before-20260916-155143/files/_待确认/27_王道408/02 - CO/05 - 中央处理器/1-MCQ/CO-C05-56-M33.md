# 选择题 第 33 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-56-M33_题目.png|题目]]

33.【2025统考真题】下列关于 $CPU$ 中的数据通路和控制器的叙述中,错误的是（ ）
A. 通用寄存器组中应该包含程序计数器
B. 控制器中一定包含指令操作码的译码电路
C. 单周期 $CPU$ 中的控制器比多周期 $CPU$ 中的更简单
D. 流水线 $CPU$ 需解决数据相关和控制相关等冒险问题

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C05-56-M33_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A。程序计数器（PC）是专用寄存器，不属于通用寄存器组，因此“通用寄存器组中应该包含程序计数器”说法错误。

**解题切入点**：本题是概念辨析题，考查 CPU 内部基本组成。拿到题目应先逐一核对每个选项对应的硬件常识：寄存器分类、控制器功能、单周期/多周期控制方式区别、流水线冒险。可以类比编程中的“变量与常量”：通用寄存器组就像可自由读写的“变量”，PC 则像是运行时环境专用的“指令指针”，不能混入通用变量集合。

**推演**：

- 选项 A：通用寄存器组通常由一组程序员可见的通用寄存器（如 R0~R31）组成，用于存放操作数和运算结果；PC 是专门用来指示下一条指令地址的寄存器，属于 CPU 内部专用寄存器，并不包含在通用寄存器组中。因此 A 错误。
- 选项 B：控制器是 CPU 的“指挥中心”，它接收指令的操作码字段，通过译码电路产生相应的控制信号，因此指令操作码的译码电路是控制器的基本组成部分。B 正确。
- 选项 C：单周期 CPU 在一个时钟周期内完成一条指令，控制器只需根据当前指令直接产生一组控制信号，通常采用组合逻辑实现，结构较简单；多周期 CPU 将一条指令分成多个步骤，控制器需要状态机或微程序来控制不同步骤的时序，复杂度更高。因此单周期控制器比多周期更简单。C 正确。
- 选项 D：流水线 CPU 将指令执行过程重叠，可能引起结构相关、数据相关和控制相关，需要采用转发、停顿、分支预测等手段解决。D 正确。

综上，错误的是 A。

**易错点**：
- 误以为 PC 属于寄存器就一定在通用寄存器组中，混淆“寄存器”与“通用寄存器组”的概念。
- 误认为单周期控制器比多周期更复杂，因为单周期指令执行时间长、CPI=1，但控制器本身确实更简单；注意区分“硬件简单”与“时间效率低”。
- 忽略控制器必须有指令译码电路，但微程序控制器中微地址译码仍然存在，不能否定操作码译码的必要性。

**命题规律**：这是 408 常考的硬件组成细节题，常以“下列说法错误的是”形式出现。常见变式包括：区分专用寄存器与通用寄存器、单周期/多周期/流水线控制器的特点、数据通路与控制器的关系。复习时应以教材为基础，重点掌握各部件功能分类和现代 CPU 中控制器的两种实现方式（组合逻辑、微程序），并注意概念间的对比记忆。

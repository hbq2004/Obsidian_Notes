# 综合题 第 1 题

![[_Attachments/题目识别/27_王道408-题目/CO-C05-54-F01_题目.png|题目]]

1. 若某机主频为 200MHz，每个指令周期平均为 2.5 个 $CPU$ 周期，每个 $CPU$ 周期平均包括 2 个主频周期,问:

(1) 该机平均指令执行速度为多少 $\text{MIPS}$?

(2) 若主频不变，但每条指令平均包括 5 个 $CPU$ 周期，每个 $CPU$ 周期又包含 4 个主频周期，平均指令执行速度又为多少 $\text{MIPS}$?

(3) 由此可得出什么结论?

## DeepSeek V4 Flash Max 解析

**答案**：(1) 40 MIPS；(2) 10 MIPS；(3) 在相同主频下，指令执行速度与每个指令所需的主频周期数成反比，即指令执行速度取决于主频和指令的复杂度（每个指令的平均 CPU 周期数及每个 CPU 周期的主频周期数）。提高主频或减少每个指令的平均主频周期数可以提高指令执行速度。

**解题切入点**：首先厘清主频、CPU 周期、指令周期之间的关系。MIPS（每秒百万条指令）是衡量指令执行速度的常用单位，其计算式为 $\text{MIPS} = \frac{\text{主频 (MHz)}}{\text{每条指令平均所需的主频周期数}}$。因此，本题的关键是将题目给出的“每个指令周期平均为 2.5 个 CPU 周期”和“每个 CPU 周期平均包括 2 个主频周期”等条件，转化为每条指令消耗的主频周期数。

**推演**：
(1) 主频 $f = 200\ \text{MHz}$，即每秒 $200 \times 10^6$ 个主频周期。
   每个指令周期平均为 $2.5$ 个 CPU 周期，每个 CPU 周期平均包含 $2$ 个主频周期，故每条指令平均所需的主频周期数为：
   $$CPI_{\text{主频}} = 2.5 \times 2 = 5$$
   则平均指令执行速度：
   $$\text{MIPS} = \frac{200\ \text{MHz}}{5} = 40\ \text{MIPS}$$

(2) 主频不变，仍为 $200\ \text{MHz}$。每条指令平均包括 $5$ 个 CPU 周期，每个 CPU 周期包含 $4$ 个主频周期，故每条指令平均所需的主频周期数为：
   $$CPI_{\text{主频}} = 5 \times 4 = 20$$
   则平均指令执行速度：
   $$\text{MIPS} = \frac{200\ \text{MHz}}{20} = 10\ \text{MIPS}$$

(3) 对比 (1) 和 (2) 可知，主频相同，但 (2) 中每条指令所需的主频周期数更多，导致指令执行速度下降。因此，结论是：在相同主频下，指令执行速度与每条指令平均所需的主频周期数成反比；计算机的指令执行速度不仅取决于主频，还取决于指令的复杂程度（即 CPU 周期数及每个 CPU 周期内的主频周期数）。要提高指令执行速度，可提高主频或减少每条指令的平均主频周期数（如优化指令集、改进微架构等）。

**易错点**：
- 直接使用主频（Hz）计算 MIPS 时，忘记将主频单位转换为 MHz 或忘记除以 $10^6$。本题主频已给出 200 MHz，可避免此错误。
- 混淆 CPU 周期与主频周期，或误将“每个指令周期平均为 2.5 个 CPU 周期”当作主频周期数直接代入。
- 计算 (2) 时弄错乘除关系，如将 5 个 CPU 周期和 4 个主频周期相加而非相乘。
- 忘记 MIPS 的含义是“百万条指令每秒”，因此直接使用主频数值除以周期数即可，无需额外换算。

**命题规律**：
- 本题是计算机组成原理中关于“指令执行速度”的基础计算题，常以填空题或简答题形式出现。
- 考点：主频、CPU 周期、指令周期之间的关系，以及 MIPS 的计算。
- 常见变式：给出主频和 CPI（每条指令的 CPU 周期数）及每个 CPU 周期包含的主频周期数，求 MIPS；或给出 MIPS 和主频，反推 CPI 等。
- 复习建议：理解“主频周期”是 CPU 内部最小时钟单位，“CPU 周期”通常由多个主频周期构成，“指令周期”由多个 CPU 周期构成。牢记 MIPS 的计算公式 $\text{MIPS} = \frac{\text{主频 (Hz)}}{\text{每条指令的主频周期数} \times 10^6}$，并注意单位换算。

# 综合题 第 7 题

7.【2009统考真题】某计算机字长16位，采用16位定长指令字结构，部分数据通路结构如下图所示。图中所有控制信号为1时表示有效，为0时表示无效。例如，控制信号$MDRinE$为1表示允许数据从$DB$打入$MDR$，$MDRin$为1表示允许数据从总线打入$MDR$。假设$MAR$的输出一直处于使能状态。加法指令“$ADD(R1),R0$”的功能为$(R0)+((R1)) \rightarrow (R1)$，即将$R0$中的数据与$R1$的内容所指主存单元的数据相加，并将结果送入$R1$的内容所指主存单元中保存。

## DeepSeek V4 Flash Max 解析

**答案**：执行阶段共需 5 个节拍（C5～C10），关键流程为：用 `R1` 送地址 → 读内存 → 先锁存 `R0` → 与 `MDR` 中的数相加 → 结果经 `MDR` 写回内存。节拍表如下：

| 时钟 | 功能 | 有效控制信号 |
| :--- | :--- | :--- |
| C5 | $MAR \leftarrow (R1)$ | $R1out,\ MARin$ |
| C6 | $MDR \leftarrow M(MAR)$ | $MemR,\ MDRinE$ |
| C7 | $A \leftarrow (R0)$ | $R0out,\ Ain$ |
| C8 | $Z \leftarrow (A)+(MDR)$ | $MDRout,\ Add,\ Zin$ |
| C9 | $MDR \leftarrow (Z)$ | $Zout,\ MDRin$ |
| C10 | $M(MAR) \leftarrow (MDR)$ | $MemW$ |

**解题切入点**：拿到题先不要被“数据通路图”吓住，先把指令 `ADD (R1), R0` 的功能拆成“取源操作数 → 运算 → 存回结果”三个子任务。本题中的源操作数一个在内存、一个在寄存器 `R0`，目标地址还在同一内存单元，所以 `MAR` 要一直保存 `R1` 的地址。把微操作想象成状态机：每一个节拍至多允许一个部件向总线送数，其余信号只是“打拍”接收数据。

**推演**：

1. 指令译码后进入执行阶段。指令要求把 `R1` 所指内存单元中的数与 `R0` 相加，结果送回原内存单元，因此必须先取地址、再取内存数。

2. **送地址**：将 `R1` 作为内存地址送入 `MAR`，由 `MAR` 一直输出到存储器的地址端：
   $$MAR \leftarrow (R1)$$
   有效控制信号为：
   $$R1out,\ MARin$$

3. **读内存操作数**：按 `MAR` 给出的地址读主存，数据从数据总线 `DB` 打入 `MDR`。这里要用 `MDRinE`，因为 `MDRinE` 专门表示“从 DB 打入 MDR”；不能用 `MDRin`（那是从内部总线打入 MDR）：
   $$MDR \leftarrow M(MAR)$$
   有效控制信号为：
   $$MemR,\ MDRinE$$

4. **锁存一个 ALU 输入**：由于单总线数据通路不能同时让 `R0` 和 `MDR` 都驱动总线，必须先取其中一个存入 ALU 的输入暂存器 `A`。这里按指令中 `R0` 为先，先把 `R0` 锁存到 `A`：
   $$A \leftarrow (R0)$$
   有效控制信号为：
   $$R0out,\ Ain$$

5. **执行加法**：把 `MDR` 送上内部总线，与已经在 `A` 中的 `R0` 相加，结果存入 ALU 输出暂存器 `Z`：
   $$Z \leftarrow (A) + (MDR)$$
   有效控制信号为：
   $$MDRout,\ Add,\ Zin$$

   注意：同一节拍不能出现 `R0out, MDRout, Add` 同时有效，因为两个源同时驱动总线会产生冲突。由于 `R0` 已在 `A` 中，本拍只需让 `MDR` 上总线。

6. **结果送 MDR**：ALU 的结果在 `Z` 中，要写回内存必须经过 `MDR`，所以把 `Z` 的内容送到 `MDR`。此时数据来自内部总线，因此用 `MDRin`：
   $$MDR \leftarrow (Z)$$
   有效控制信号为：
   $$Zout,\ MDRin$$

7. **写回内存**：因为 `MAR` 没有改变，仍保存着 `R1` 的内容，且题设说明 `MAR` 的输出一直处于使能状态，所以写回时无需重新送地址，只需写主存信号：
   $$M(MAR) \leftarrow (MDR)$$
   有效控制信号为：
   $$MemW$$

**易错点**：

- **混淆 `MDRinE` 与 `MDRin`**：读内存时数据从 `DB` 进 `MDR`，必须用 `MDRinE`；运算结果从内部总线进 `MDR`，必须用 `MDRin`。二者写反会答错关键信号。
- **同一节拍让 `R0out` 和 `MDRout` 同时有效**：单总线结构不能同时有两个源部件向总线输出，否则发生总线冲突。
- **忘记结果必须经过 `MDR` 写回**：存数指令或“结果送内存”类指令，不能直接把 ALU 输出接到数据总线，必须先把结果打入 `MDR`，再由 `MemW` 写主存。
- **写回时额外再送一遍地址**：由于 `MAR` 输出一直使能，`MAR` 仍等于 `R1`，所以不需要 `R1out, MARin`，否则反而可能改变 `MAR` 或多占一个节拍。
- **把取指阶段信号混入执行阶段**：`PCout`、`PC+1`、`IRin` 等在取指/译码阶段已经用过，执行阶段不应再出现。

**命题规律**：本题是“数据通路 + 微操作信号”的经典综合题，几乎每年 408 都可能以类似形式考查。常见变式有：改成 `SUB`、`AND`、`STORE`、`LOAD`，或者指令改为 `ADD R0, (R1)`（结果送回寄存器）。复习时要以“单总线数据通路”为模板，掌握每一个微操作的节拍划分原则：  
1. 先确定“源”和“目的”分别连在哪条总线上；  
2. 每个节拍只能有一个源部件使能输出；  
3. 运算类指令通常用 ALU 输入暂存器 `A` 先锁存一个操作数，再用总线送第二个操作数，结果先暂存到 `Z`，再到目的寄存器或 `MDR`；  
4. 访问内存必须经过 `MAR/MDR`，并区分从 `DB` 打入还是从内部总线打入。

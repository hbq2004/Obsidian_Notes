# 选择题 第 10 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-31-M10_题目.png|题目]]

10. 下列关于多级存储系统的说法中，正确的有（ ）
I. 多级存储系统是为了降低存储成本
II. 虚拟存储器中主存和辅存之间的数据调动对任何程序员是透明的
III. CPU 只能与 Cache 直接交换信息，CPU 与主存交换信息也需要经过 Cache
A. 仅 I
B. 仅 I 和 II
C. I、II 和 III
D. 仅 II

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-31-M10_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A（仅 I）。  
一句话理由：I 正确；II 错在把“应用程序员透明”扩大为“任何程序员”，III 错在把 Cache 当成 CPU 与主存之间的唯一通路。

**解题切入点**：  
拿到题目先定位“多级存储系统”常考的三个方面：目的、透明性、数据通路。可以把它类比为“本地高速缓存 + 远端大仓库”：常用数据放近处是为了整体性能更好、平均成本更低，但系统管理员能看到调度过程；访问远端数据也不是非要先经过本地缓存。重点抓“任何”“只能”“必须经过”这类绝对化表述。

**推演**：  
I 正确。多级存储系统采用“寄存器—Cache—主存—辅存”的层次结构，用高速小容量存储器提高速度，用低速大容量存储器扩大容量、降低成本。从整体看，CPU 获得的速度接近高速缓存，存储容量接近辅存，平均每位存储成本下降。因此“为了降低存储成本”在考试中通常视为正确说法，更准确地说，是降低平均存储成本。

II 错误。虚拟存储器中主存和辅存之间的数据调动由操作系统和硬件共同完成，对**应用程序员**是透明的；但**系统程序员**需要了解页表、缺页处理、地址转换等机制，不能说“对任何程序员透明”。所以 II 错。

III 错误。CPU 访问 Cache 命中时，直接从 Cache 取得信息；若 Cache 未命中，CPU 需要访问主存，将对应数据块调入 Cache，再读取所需字。也就是说 CPU 可以和 Cache 交换信息，也可以和主存交换信息，Cache 并不是 CPU 与主存之间唯一的必经之路。所以“只能与 Cache 直接交换信息”和“必须经过 Cache”都过于绝对，III 错。

综上，只有 I 正确，选 A。

**易错点**：  
1. 误以为 II 正确。注意“主存—辅存层次”对应用程序员透明，但对系统程序员不透明；而 Cache—主存层次通常对各类程序员都透明。  
2. 误以为 III 正确。Cache 是为提高访问速度而设置的，但 CPU 未命中 Cache 时仍需访问主存，不能说“只能”通过 Cache。  
3. 误以为 I 错。多级存储系统的目标是速度、容量、成本三者的折中，能降低平均存储成本，因此 I 是正确的。

**命题规律**：  
考点集中在多级存储层次的目的、各级存储器对程序员的透明性、CPU 与 Cache/主存之间的数据通路。常见变式有：  
- 判断“Cache 对哪些程序员透明”“虚拟存储器对哪些程序员透明”；  
- 判断“CPU 能直接访问哪些存储器”；  
- 结合 Cache 命中与未命中过程考查数据流向。  
复习时把“Cache—主存层次”和“主存—辅存层次”的透明性对照表背熟，并注意题目中“任何”“只能”“必须”等绝对化表述往往是陷阱。

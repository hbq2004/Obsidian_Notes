# 选择题 第 18 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-36-M18_题目.png|题目]]

18.【2024统考真题】对于页式虚拟存储管理系统,下列关于存储器层次结构的叙述中,错误的是（ ）

A. $Cache$－主存层次的交换单位为主存块,主存－外存层次的交换单位为页.

B. $Cache$－主存层次替换算法由硬件实现,主存－外存层次替换算法由软件实现.

C. $Cache$－主存层次可采用回写法,主存－外存层次通常采用回写法.

D. $Cache$－主存层次可采用直接映射方式,主存－外存层次通常采用直接映射方式.

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-36-M18_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。页式虚拟存储中，虚页经页表可映射到主存任意空闲页框，不是 Cache 中“直接映射”的固定位置映射；主存-外存层次通常具有全相联映射的特点。

**解题切入点**：  
本题把两个存储层次放在一起考，核心是“谁管、以多大单位换、怎么找、写了怎么办”。先定位考点：Cache-主存是硬件管理，主存-外存是操作系统管理；再逐项检查四个属性即可。可以类比：Cache 的映射像“固定编号格子”，虚拟存储的页表像“台账登记任意存放位置”。

**推演**：  
A 正确。Cache 与主存之间一次传送一个主存块；页式虚拟存储中主存与外存之间一次传送一页。故交换单位分别为主存块、页。

B 正确。Cache 缺失时的块替换必须在一个访存周期附近完成，不能等待操作系统，因此替换算法由硬件实现；缺页时页面替换属于操作系统内存管理功能，由软件实现页面置换算法（LRU、Clock 等），硬件只提供访问位、脏位等支持。

C 正确。Cache 可以采用写直达法或回写法；主存-外存层次由于外存速度太慢，不能在每次写主存时都写外存，因此通常只把“修改过”的页在淘汰时写回外存，即回写法，对应页表项中的修改位（脏位）。

D 错误。Cache 可以采用直接映射：主存块地址中索引位确定唯一可放的行号。而页式虚拟存储中，

$$VA=(VPN,w),\qquad PA=(PPN,w),\qquad PPN=PT[VPN]$$

即通过页表把虚页号映射到物理页框号，虚页可装入任意空闲页框，位置不固定，也没有 Cache 直接映射中“只能放入唯一位置”的限制。因此不能把“主存-外存层次通常采用直接映射方式”作为正确叙述。

**易错点**：  
1. 记反交换单位：Cache-主存是“块”，主存-外存是“页/段”。  
2. 误以为页面置换也由硬件完成：硬件只负责缺页异常、引用位/修改位等，算法由 OS 软件实现。  
3. 误以为虚拟存储用写直达法：由于辅存太慢，虚拟存储常使用回写（脏位）策略。  
4. 混淆映射方式：Cache 三种映射中直接映射不适用于虚拟存储；页表实现的是全相联式映射特性。  
5. 审题不清：题干要求“错误的是”，不要因为 A、B、C 都正确而不敢选 D。

**命题规律**：  
考点是存储器层次结构中“Cache-主存”和“主存-外存”的对照：管理单位、地址映射、替换算法、写策略。常见变式包括：结合 TLB 考查 Cache/页表/缺页处理；给替换算法判断由硬件还是 OS 实现；给出 Cache 写直达/回写和虚拟存储脏位；或比较直接映射、组相联、全相联在 Cache 与虚拟存储中的适用性。复习时应按“管理单位—映射方式—查找机制—替换策略—写策略”列表横向对比，并记住一个原则：越靠近 CPU 的层次越依赖硬件，越靠近外存的层次越依赖 OS 软件。

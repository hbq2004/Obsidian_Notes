# 选择题 第 26 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-32-M26_题目.png|题目]]

26. 下列关于单体多字存储器的说法中,不正确的是( )

A. 单体多字存储器主要解决主存容量太小的问题

B. 单体多字存储器中,每个存储单元存储多个字

C. 指令与数据的连续存放有利于单体多字存储器提高主存的读/写速度

D. 过多的跳转指令会严重影响单体多字存储器的工作效率

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-32-M26_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A。单体多字存储器通过增加每个存储单元存放的字数，使一次访存能读出多个字，主要目的是提高主存带宽/读写速度，而不是解决主存容量太小的问题。

**解题切入点**：  
拿到题目先锁定考点：主存性能优化中的“并行存储”技术。看到“单体多字”就要立刻想到“一个存储周期读出多个字”，对应的是速度/带宽问题；选项中若出现“容量太小”，多半是干扰项。  
可以类比算法竞赛中的“批量读入”：一次性读入一块连续数据再处理，比逐个访问快得多；但如果程序总是随机跳转，批量读入的优势就会大打折扣。这与 C、D 选项的逻辑一致。

**推演**：  
设机器字长为 $W$ 位，传统单体单字存储器按字编址，有 $N$ 个存储单元，则总容量为  
$$C = N \times W \quad (\text{bit})$$

单体多字存储器中，每个存储单元存放 $k$ 个机器字，即每个存储单元的位宽变为 $kW$。若仍要存储 $N$ 个字，则存储单元数为 $N/k$，所以总容量为  
$$C' = \frac{N}{k} \times kW = N W = C$$

因此，单体多字存储器并没有扩大主存容量，只是改变了存储体的组织方式，使一个存储周期能读出 $k$ 个字。

若存储周期为 $T$，则单体单字存储器的带宽为  
$$B = \frac{W}{T}$$

单体多字存储器的带宽为  
$$B' = \frac{kW}{T} = kB$$

所以它的核心作用是提高主存带宽，即提高读写速度，而不是解决容量问题，故 A 不正确。

B 正确：单体多字存储器的“多字”就是指每个存储单元存放多个字。  
C 正确：指令和数据连续存放时，一次读出的多个字都能被使用，因此能有效提高读写速度。  
D 正确：跳转指令会使后续连续读出的多个字失效，导致已读出的数据无法充分利用，从而严重影响效率。

**易错点**：  
1. **混淆“容量”与“带宽”**：单体多字通过增加存储字长提高一次访存读出的位数，提高的是速度，不是容量。  
2. **误认为“每单元存多字”一定增大容量**：容量取决于总存储位数，存储单元数相应减少，总容量不变。  
3. **混淆“单体多字”与“多体交叉存储器”**：单体多字是一个存储体内每单元存多字；多体交叉是多个存储体并行工作，二者都能提高带宽，但结构不同。  
4. **忽略连续性对单体多字的影响**：如果指令/数据不连续，或者频繁跳转，一次读出的多个字可能只有部分有效，效率会下降。

**命题规律**：  
本题属于存储器层次结构中“主存性能优化”的考点，重点考查单体多字存储器的定义、作用及适用场景。常见变式包括：  
- 判断“单体多字是为了扩大主存容量”是否正确；  
- 比较单体多字与多体交叉存储器的优缺点；  
- 结合指令执行流程，分析跳转指令对流水线或存储带宽的影响；  
- 计算带宽：给出存储周期和每周期读出字数，要求计算带宽提升倍数。  

复习时应抓住各类并行存储器的本质特征：单体多字靠“加宽”，多体交叉靠“增加体数”，双端口靠“增加访问端口”。同时要会用带宽公式分析性能变化，并理解连续访问与随机跳转对并行存储效率的影响。

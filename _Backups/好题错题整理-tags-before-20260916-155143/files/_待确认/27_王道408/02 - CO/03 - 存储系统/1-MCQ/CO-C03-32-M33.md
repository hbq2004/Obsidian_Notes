# 选择题 第 33 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-32-M33_题目.png|题目]]

33.【2015统考真题】下列存储器中,在工作期间需要周期性刷新的是（ ）

(A) SRAM  
(B) SDRAM  
(C) ROM  
(D) Flash

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-32-M33_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B（SDRAM）。SDRAM 属于动态随机存储器（DRAM），电容电荷会泄漏，因此工作期间需要周期性刷新；SRAM、ROM 和 Flash 均不需要周期性刷新。

**解题切入点**：先抓住“周期性刷新”这一关键动作，它只与存储介质的工作原理有关。可以把存储器想象成“水桶”：DRAM 用“电容”存电荷，就像漏水的桶，必须定期加水（刷新）；SRAM 用“双稳态触发器”锁存状态，就像卡住的开关，不掉电就不会翻转。题目给出的四种存储器中，只有 SDRAM 是 DRAM 类型，因此直接锁定答案。

**推演**：

1. **SRAM（静态随机存取存储器）**  
   SRAM 使用六管 MOS 管构成的双稳态触发器存储信息。只要电源不断，触发器状态就能稳定保持，不需要刷新。特点是速度快、功耗较高、集成度低，常用于 Cache。

2. **SDRAM（同步动态随机存取存储器）**  
   SDRAM 是 Synchronous Dynamic Random Access Memory，本质属于 DRAM。DRAM 利用电容上存储的电荷表示“0”和“1”。电容会缓慢放电，电荷不能长期保持，因此必须在信息丢失之前对其进行“刷新”（重新充电）。例如，典型刷新周期为 64 ms，在此期间必须对所有行完成一次刷新。所以 SDRAM 在工作期间需要周期性刷新。

3. **ROM（只读存储器）**  
   ROM 是非易失性存储器，数据在制造或写入后可以长期保存，不需要刷新。它依靠电路结构（如熔丝、MOS 管的有无）存储信息，断电也不丢失。

4. **Flash（闪存）**  
   Flash 是 EEPROM 的一种，属于非易失性存储器，通过浮栅晶体管存储电荷。浮栅被绝缘层包围，电荷泄漏非常缓慢，可以长期保存数据，不需要周期性刷新。其写入需要先擦除，且擦写次数有限，但没有“刷新”操作。

综上，只有 SDRAM 需要在工作期间周期性刷新，故选 B。

**易错点**：

- 误选 A（SRAM）：看到“RAM”就以为需要刷新，但 SRAM 是静态的，不需要刷新；只有 DRAM（包括 SDRAM）需要刷新。
- 误选 D（Flash）：Flash 虽然也用电容/浮栅存电荷，但其电荷泄漏极慢，且设计为非易失，不需要周期刷新；不能把“电荷存储”等同于“需要刷新”。
- 概念混淆：SDRAM 中的“同步”指与系统时钟同步，不是“需要刷新”的原因；真正原因在于它是动态存储器（DRAM）。
- 规避方法：记住“需要刷新”是 DRAM 的独有特征，而 SDRAM、DDR、DDR2/DDR3/DDR4 等都是 DRAM 类型，均需要刷新；SRAM、ROM、Flash 都不需要。

**命题规律**：本题属于存储器基础知识的常规考点，重点考查各类存储器的特性对比。常见变式包括：
- 问“下列存储器中，断电后信息丢失的是？”（答案通常是 SRAM、DRAM 等随机存取存储器）
- 问“下列关于 DRAM 刷新的说法，正确的是？”（考查刷新方式、刷新单位、刷新与读写的关系等）
- 结合 Cache 和主存层次，问 SRAM 和 DRAM 分别用作哪一级存储。

复习建议：将存储器按“易失性”“随机访问性”“是否需要刷新”三个维度整理成表格，并理解刷新操作的本质（电容电荷再生）。同时注意区分“刷新”与“重写”，刷新是按行进行的，不影响存储内容。

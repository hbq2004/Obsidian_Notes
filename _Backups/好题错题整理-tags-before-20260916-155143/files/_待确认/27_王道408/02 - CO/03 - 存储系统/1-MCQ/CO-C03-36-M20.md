20.【2024统考真题】下列事件中,不是在 $MMU$ 地址转换过程中检测的是(  ).

A. 访问越权  
B. $Cache$ 缺失  
C. 页面缺失  
D. $TLB$ 缺失

## 答案

## DeepSeek V4 Flash Max 解析

**答案**：B。MMU 地址转换过程中检测的是访问越权、页面缺失和 TLB 缺失；Cache 缺失由 Cache 控制器在物理地址访问 Cache 时检测，不在 MMU 地址转换过程中。

**解题切入点**：拿到题目先明确“MMU 地址转换”这条流水线到底包含哪些环节。可以把 MMU 理解成“翻译官 + 门卫”，它的任务是完成虚拟地址到物理地址的转换，并在转换时核对权限、有效位等；Cache 缺失则是“仓库调度员”发现货物不在眼前货架上的事，发生在地址翻译完成后真正访问数据的一侧。要区分两类“缺失”：TLB 缺失是地址转换快表的缺失，属于 MMU 地址转换内部事件；Cache 缺失是数据/指令 Cache 的缺失，属于存储层次访问事件。

**推演**：

MMU 的核心功能是将 CPU 发出的虚拟地址 $VA$ 转换为物理地址 $PA$。一个典型地址转换流程为：

1. CPU 发出虚拟地址 $VA$；
2. MMU 先查 TLB（Translation Lookaside Buffer），即地址转换快表；
   - 若 TLB 命中，直接得到物理页号；
   - 若 TLB 缺失，则需要访问内存中的页表继续完成地址转换。
3. 在获得页表项后，MMU 检查页表项中的有效位、访问权限位等：
   - 若页表项有效位为 0，说明该页不在主存中，产生缺页异常（页面缺失）；
   - 若当前访问方式（读、写、执行）违反了页表项中的权限位，产生访问越权异常。
4. 完成地址转换得到物理地址 $PA$ 后，CPU 才用 $PA$ 访问 Cache。

由此可逐一判断：

- A. **访问越权**：MMU 在查页表或 TLB 时，需要检查访问权限位，因此是 MMU 地址转换过程中检测的。
- C. **页面缺失**：MMU 在查页表时发现对应页表项不在主存中（有效位为 0），会触发缺页异常，因此是 MMU 地址转换过程中检测的。
- D. **TLB 缺失**：TLB 本身属于 MMU 的一部分，地址转换的第一步就是查 TLB，TLB 未命中直接发生在 MMU 内部，因此也是 MMU 地址转换过程中检测的。
- B. **Cache 缺失**：Cache 缺失发生在物理地址已经生成之后，由 Cache 控制器通过比较 tag 判断是否命中。若未命中，则向主存或下一级 Cache 请求数据。该过程与“虚拟地址到物理地址”的转换无关，因此不是 MMU 地址转换过程中检测的。

综上，正确选项为 B。

**易错点**：

1. **混淆 TLB 缺失与 Cache 缺失**：TLB 是地址转换的高速缓存，属于 MMU 范畴；Cache 是数据/指令的高速缓存，位于地址转换之后。TLB 缺失不等于 Cache 缺失。
2. **误以为缺页由操作系统直接检测**：缺页异常虽然由操作系统处理，但“发现缺页”这一步是由 MMU 在地址转换过程中检查页表项有效位完成的，MMU 产生缺页异常信号后，OS 才介入。
3. **忽略访问越权也属于地址转换检查**：页表项或 TLB 项中通常包含读、写、执行权限位，MMU 在地址转换时必须同时进行权限检查。
4. **不清楚事件发生顺序**：正确顺序是“虚拟地址 → TLB → 页表 → 物理地址 → Cache → 主存”，Cache 缺失发生在最后一个环节，不在 MMU 地址转换阶段。

**命题规律**：本题属于计算机组成原理中“存储系统”与“虚拟内存”的交叉考点，重点考查 MMU、TLB、页表、Cache 之间的边界关系。常见变式有：给出一次访存过程，要求判断某个异常（如缺页、缺段、TLB 缺失、Cache 缺失）发生在哪一阶段；或结合多级页表、快表命中率、Cache 命中率综合出题。复习时应画清“虚拟地址 → TLB → 页表 → 物理地址 → Cache → 主存”的完整流程图，明确每一步由哪个硬件部件完成、哪些事件会产生异常，并注意区分“TLB 缺失”和“页面缺失”：TLB 缺失时仍可能在页表中找到对应页，不一定会缺页。

# 选择题 第 7 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-35-M07_题目.png|题目]]

7. 对于下列代码,以下哪种变化将使其具有更好的空间局部性 ( ).

```c
int i, j, k, sum=0;

for (i=0; i<n; i++)

    for (j=0; j<n; j++)

        for (k=0; k<n; k++)

            sum += a[k][j][i];
```

A. 将第 2 行与第 3 行互换  
B. 将第 2 行与第 4 行互换  
C. 将第 5 行改为 sum += a[i][k][j];  
D. 将第 5 行改为 sum += a[j][i][k];

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-35-M07_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。将第2行与第4行互换后，循环顺序变为 $k\to j\to i$，访问 $a[k][j][i]$ 时最内层 $i$ 正好是数组第三维下标，整个访问序列按内存地址连续递增，空间局部性最好。

**解题切入点**：看到三维数组 $a[k][j][i]$，应立刻想到 C 语言数组按行优先存储、最后一个下标变化最快。空间局部性优化就是“让最内层循环变量对应最后一个下标”，理想情况下外层到内层的循环顺序还应与下标从高维到低维一致，形成顺序扫描。打比方：二维数组应按“行优先”一行一行读，而不是按列跳着读。

**推演**：

设数组为 $a[n][n][n]$，元素类型为 `int`，按行优先存储，则地址偏移为

$$a[k][j][i]\text{ 的地址偏移}=k\cdot n^2+j\cdot n+i.$$

原代码的最内层循环是 $k$，因此 $k$ 每增加 1，地址偏移改变 $n^2$，步长很大，空间局部性差。

逐项分析：

- **A**：互换第2行和第3行后，内层仍是 $k$，访问仍为 $a[k][j][i]$，步长仍为 $n^2$，不改善。

- **B**：互换第2行和第4行后，循环变为

  ```c
  for (k=0; k<n; k++)
      for (j=0; j<n; j++)
          for (i=0; i<n; i++)
              sum += a[k][j][i];
  ```

  此时地址偏移为

  $$k n^2 + j n + i.$$

  从内层 $i$ 到中层 $j$ 再到外层 $k$，地址偏移依次对应低权位、中权位、高权位，整个访问序列就是 $0,1,2,\dots,n^3-1$ 的连续扫描，空间局部性最好。

- **C**：改为 $a[i][k][j]$，地址偏移为 $i n^2 + k n + j$，内层 $k$ 每加 1 地址改变 $n$，不是连续访问，空间局部性仍不好。

- **D**：改为 $a[j][i][k]$，地址偏移为 $j n^2 + i n + k$。内层 $k$ 每加 1 地址确实连续，但中层 $j$ 每加 1 地址跳变 $n^2$，整体访问序列不是顺序连续的；相比 B，空间局部性较差。因此单选题选最佳答案 B。

**易错点**：

1. 误选 D：D 虽然使最内层 $k$ 对应的下标连续，但整体上 $j$ 变化时会造成大跨度跳变；B 则使整段内存按顺序扫描，空间局部性更好。严格说 D 也比原代码有所改善，但 408 单选题通常按“最佳”理解，答案取 B。
2. 误以为 C 语言中第一个下标变化最快：C 语言按行优先存储，最后一个下标变化最快。
3. 混淆空间局部性与时间局部性：本题每个数组元素只访问一次，没有重复访问，所以重点看相邻两次访问的地址是否接近。

**命题规律**：这是计算机组成原理“存储层次与局部性”的高频考点，常结合 C 语言数组布局出题。常见变式包括：考查二维数组按行/列访问的 cache 命中率、循环交换优化、矩阵转置/乘法中的局部性。复习时应熟练掌握行优先地址计算公式，并会判断“最内层循环变量是否对应存储中连续变化的下标”。

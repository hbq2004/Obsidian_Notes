# 选择题 第 11 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-35-M11_题目.png|题目]]

11. 已知某程序运行期间，$L1Cache$ 的命中率为 94%，而 $L2Cache$ 的局部命中率（在 $L1$ 不命中情况下的命中率）为 85%。请问该存储系统的全局命中率（$CPU$ 的访存请求最终在 $L1$ 或 $L2$ 中得到满足的比例）是多少？

(A) 97.9%
(B) 98.5%
(C) 99.1%
(D) 99.4%

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-35-M11_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。  
$L1$ 命中率与 $L1$ 未命中后由 $L2$ 命中的比例相加，全局命中率为 $99.1\%$。

**解题切入点**：  
看到“局部命中率”要立刻想到它是在上一层未命中条件下的条件概率，不是直接占总访存次数的比例。可以把两级 Cache 看作两道筛网：第一道筛掉 $94\%$，剩下 $6\%$ 的请求再经过第二道筛网，第二道筛网又能筛掉其中的 $85\%$，所以最终漏掉的只有 $6\% \times 15\%$。

**推演**：  
设 $CPU$ 发起的总访存次数为 $N$。

$L1Cache$ 命中率为 $94\%$，即：

$$N_1 = 0.94N$$

这部分请求已经在 $L1$ 中得到满足。

$L1$ 未命中次数为：

$$N_{\text{miss1}} = (1 - 0.94)N = 0.06N$$

$L2Cache$ 的局部命中率是“在 $L1$ 不命中情况下的命中率”，即条件命中率：

$$P(\text{L2 hit} \mid \text{L1 miss}) = 85\%$$

因此，$L1$ 未命中且 $L2$ 命中的请求数为：

$$N_2 = 0.06N \times 0.85 = 0.051N$$

全局命中率定义为 $CPU$ 的访存请求最终在 $L1$ 或 $L2$ 中得到满足的比例：

$$
\text{全局命中率}
= \frac{N_1 + N_2}{N}
= 0.94 + 0.06 \times 0.85
= 0.94 + 0.051
= 0.991
= 99.1\%
$$

所以正确选项为：

$$C$$

**易错点**：  
- 把 $L2$ 的局部命中率 $85\%$ 直接当作全局命中率的一部分参与相加，误算为 $94\% + 85\% = 179\%$，这是概念性错误。  
- 忘记“局部命中率”是条件概率，应该乘上 $L1$ 的失配率 $6\%$。  
- 若题目给出 $L2$ 的“全局命中率”，才可以直接相加或按总次数计算；但本题明确说明是“在 $L1$ 不命中情况下的命中率”，必须使用乘法。  
- 计算时把 $6\% \times 85\%$ 算成 $5.1\%$ 后，最终结果应为 $94\% + 5.1\% = 99.1\%$，不要漏加 $L1$ 本身的命中部分。

**命题规律**：  
这是 Cache 层次结构中的经典考点，重点考查“局部命中率”与“全局命中率”的区别。常见变式包括：  
- 给出 $L1$、$L2$ 的命中率，求平均访存时间；  
- 给出各级命中率和访问时间，求 $CPU$ 因 Cache 缺失产生的额外停顿；  
- 反向给出全局命中率和 $L1$ 命中率，反推 $L2$ 的局部命中率。  

复习时应掌握统一公式：

$$P_{\text{global}} = P_1 + (1 - P_1)P_2$$

其中 $P_1$ 为 $L1$ 命中率，$P_2$ 为 $L2$ 局部命中率。做题时先标记清楚每个概率是“全局”还是“局部”，再代入公式即可。

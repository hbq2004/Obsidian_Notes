# 选择题 第 16 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-36-M16_题目.png|题目]]

16.【2020 统考真题】下列关于 $TLB$ 和 $Cache$ 的叙述中,错误的是（ ）

A. 命中率都与程序局部性有关

B. 缺失后都需要去访问主存

C. 缺失处理都可以由硬件实现

D. 都由 $DRAM$ 存储器组成

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-36-M16_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。TLB 和 Cache 都应由 SRAM 构成，而不是 DRAM；A、B、C 的叙述均正确。

**解题切入点**：拿到题目先抓住两个核心概念：“TLB 是什么”和“Cache 是什么”。TLB 是页表项的缓存，Cache 是主存块的缓存；两者都是 CPU 与主存之间的高速缓冲部件，因此都要用更快的 SRAM，而不是主存所用的 DRAM。可以类比：TLB 是“页表的缓存”，Cache 是“主存数据的缓存”，它们都靠程序局部性提高命中率。

**推演**：

- 选项 A：  
  程序局部性包括时间局部性和空间局部性。Cache 命中率与程序局部性密切相关；TLB 作为页表项的缓存，其访问模式同样与程序对页面的访问局部性有关。因此 A 正确。

- 选项 B：  
  TLB 缺失时，需要根据页表基址寄存器查页表，而页表存放在主存中，因此需要访问主存来获得页表项。Cache 缺失时，需要把缺失的那一块从主存调入 Cache，因此也需要访问主存。若考虑多级 Cache，最终还是要到主存取得数据。因此 B 正确。

- 选项 C：  
  Cache 缺失处理通常由硬件直接完成；TLB 缺失处理既可以由硬件完成（如 x86 的硬件页表遍历），也可以由软件完成（如 MIPS 的软件重填）。题干说“都可以由硬件实现”，指的是两者缺失处理都存在硬件实现的可能，因此 C 正确。

- 选项 D：  
  主存（内存条）使用 DRAM，而 Cache 和 TLB 处于 CPU 内部或紧邻 CPU，需要更高速度，通常用 SRAM 实现。SRAM 速度快但集成度低、功耗大，适合做 Cache 和 TLB；DRAM 速度慢但集成度高、成本低，适合做主存。说 TLB 和 Cache 由 DRAM 组成是错误的。因此 D 错误。

综上，错误的是 D。

**易错点**：

- 误以为 TLB 缺失只能由软件处理。实际上不同体系结构不同：有的用硬件查页表，有的用软件异常例程，但“可以由硬件实现”这句话是对的。
- 误以为“Cache 缺失后都需要访问主存”在多级 Cache 下不成立。应理解为缺失后最终需要向更低一级存储器（包括主存）取数据，题干的表述在 408 语境下是正确的。
- 容易忽略 TLB 和 Cache 的存储介质。两者都要求高速，因此一般用 SRAM，不可能用 DRAM。做题时看到“DRAM”要警惕。
- 把 TLB 和 Cache 的作用混为一谈。TLB 缓存的是“虚拟地址到物理地址的映射关系”，Cache 缓存的是“主存中的数据或指令”。

**命题规律**：本题属于“存储系统”中的基础概念辨析题，常将 TLB、Cache、页表、主存放在一起考查。变式可能包括：问 TLB 缺失对 Cache 是否影响、Cache 命中时是否依然需要访问主存、TLB 和 Cache 的访问顺序等。复习时应重点掌握：  
1. TLB 是页表项的 Cache，Cache 是主存块的 Cache；  
2. 两者都用 SRAM 实现；  
3. 两者的命中率都与程序局部性有关；  
4. TLB 缺失可以由硬件或软件处理，Cache 缺失通常由硬件处理；  
5. TLB 访问在前，Cache 访问在后：先由 TLB 完成地址转换，再用物理地址访问 Cache。

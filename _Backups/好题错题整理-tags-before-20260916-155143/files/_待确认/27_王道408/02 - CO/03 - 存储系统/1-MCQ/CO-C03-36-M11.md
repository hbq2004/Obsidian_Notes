# 选择题 第 11 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-36-M11_题目.png|题目]]

11. 虚拟存储器中的页表有快表和慢表之分,下面关于页表的叙述中正确的是( ).

A. 快表与慢表都存储在内存中,但快表比慢表容量小

B. 快表采用了优化的搜索算法,因此查找速度快

C. 快表比慢表的命中率高,因此快表可以得到更多的搜索结果

D. 快表采用相联存储器件组成,按照查找内容访问,因此比慢表查找速度快

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-36-M11_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。快表（TLB）由相联存储器组成，按查找内容并行访问，因此比访问内存中的慢表查找速度快。

**解题切入点**：看到“快表/慢表”，应立刻定位到虚拟存储器中的地址变换：慢表是存放在主存中的完整页表，快表是 CPU/MMU 中的 TLB，相当于页表项的高速缓存。做题时先抓住“快表为什么快”这个核心：不是因为容量大、算法优化，而是因为采用了相联存储器按内容访问。打个比方：慢表是一本完整的大字典，快表是手边只记常用单词的卡片；卡片不是“优化了查字典的算法”，而是单独放出来供快速对照。

**推演**：

1. 在页式虚拟存储器中，CPU 发出的虚拟地址需要经过页表转换成物理地址。若只访问慢表，则每次地址变换都要先访问一次主存中的页表，再访问目标内存单元，速度较慢。

2. 快表（TLB）内部保存了近期常用的“虚页号 $\to$ 实页号”映射项。它采用相联存储器（CAM），按内容并行比较虚拟页号，而不是按地址顺序查找。因此快表命中时，可以直接得到实页号，省去一次访问主存中慢表的时间。

3. 设 TLB 访问时间为 $t_{TLB}$，内存访问时间为 $t_m$，TLB 命中率为 $h$，则进行一次地址变换并访问数据的平均时间约为：
$$
T = h(t_{TLB}+t_m) + (1-h)(t_{TLB}+2t_m)
= t_m + t_{TLB} + (1-h)t_m.
$$
可见 TLB 命中能减少一次访问内存慢表的开销；但“查找快”的直接原因不是命中率高，而是相联存储器并行比较。

4. 逐项判断：

- A 错：快表不在内存中，而是位于 CPU 中的相联存储器或 MMU 内；慢表才在主存中。虽然“快表比慢表容量小”本身通常成立，但前半个结论错误。
- B 错：快表不是靠“优化的搜索算法”变快，而是靠相联存储器硬件并行比较，属于按内容访问。
- C 错：快表命中率高源于程序访问的局部性，但不能由此推出“快表可以得到更多的搜索结果”，慢表是完整页表，与快表不是同一层面的“命中率”比较。
- D 对：相联存储器支持按内容寻址，并行比较，因此查找速度快于按地址访问内存中的慢表。

**易错点**：

- 误以为快表也存储在主存中，只是容量小。实际快表在 CPU/MMU 内，是相联存储器。
- 误把“相联存储器按内容并行比较”理解成“查找算法优化”。这是硬件结构问题，不是算法问题。
- 误选 C：快表命中率高确实是局部性带来的，但不是本题问的“查找快”的根本原因；“更多搜索结果”更是无意义的说法。
- 不要把 TLB 与普通 Cache 混淆：TLB 缓存的是页表项，属于页表的高速缓存，不是数据或指令的 Cache。

**命题规律**：本题属于虚拟存储器基础概念题，常考 TLB 与页表的区别、相联存储器的特点、地址变换过程。常见变式包括：给出虚拟地址、页大小、TLB 命中率和访问时间，求平均访存时间；或问“TLB 中存放的是什么”；或将快表与 Cache、缺页中断结合考查。复习时应抓住“快表是页表的 Cache”这一主线，熟记相联存储器按内容访问并行查找的特点，并与操作系统中的页表、缺页处理联系起来。

# 选择题 第 9 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-31-M09_题目.png|题目]]

9. 存储器分层体系结构中,存储器从速度最快到最慢的排列顺序是( )
(A) 寄存器－主存－Cache－辅存
(B) 寄存器－主存－辅存－Cache
(C) 寄存器－Cache－辅存－主存
(D) 寄存器－Cache－主存－辅存

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-31-M09_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：D。存储器从速度最快到最慢的顺序是：寄存器 → Cache → 主存 → 辅存。

**解题切入点**：看到“速度最快到最慢”的排列，立刻想到存储层次结构是围绕“CPU-主存”速度差距设计的金字塔：越靠近 CPU 越贵、越快、容量越小；越远离 CPU 越慢、越便宜、容量越大。可以类比做算法题时的“缓存优化”：最快的数据永远放在寄存器或 CPU 内部，其次是各级缓存，再是内存，最后才是磁盘/SSD。

**推演**：  
存储器层次结构自上而下依次为：

- **寄存器**：位于 CPU 内部，与 ALU 直接相连，速度最快，通常在一个时钟周期内完成读写。
- **Cache**（高速缓存）：位于 CPU 和主存之间，用来缓解 CPU 与主存之间的速度差异，速度比主存快一个数量级以上，但比寄存器慢。
- **主存（内存）**：直接与 Cache 或总线相连，容量较大，速度比 Cache 慢，但比辅存快得多。
- **辅存（外存）**：如磁盘、SSD 等，容量最大，速度最慢。

因此按速度从快到慢排列为：

$$
\text{寄存器} \rightarrow \text{Cache} \rightarrow \text{主存} \rightarrow \text{辅存}
$$

对应选项为 D。

**易错点**：

1. **把 Cache 和主存次序搞反**：有些同学以为 Cache 是“缓存”，可能位于主存之后，但实际上 Cache 是 CPU 与主存之间的高速缓冲存储器，速度远快于主存。
2. **把辅存放在 Cache 前面**：辅存（如硬盘）虽然容量大，但机械硬盘或 SSD 的访问延迟远高于内存，更不可能比 Cache 快。
3. **混淆“存储器层次结构”与“存储系统组成”**：层次结构强调的是按速度/容量/价格分层，而不是按物理位置或接口顺序。
4. **死记硬背**：应理解每一层存在的意义——寄存器存当前指令/操作数，Cache 缓存近期要用的数据，主存运行程序，辅存永久保存数据，各层速度递减。

**命题规律**：  
这是计算机组成原理中的基础送分题，几乎每年都可能以选择题形式出现。考法通常是：

- 直接给出多个存储器，要求按速度、容量或价格排序；
- 结合“局部性原理”问 Cache 的作用；
- 结合“访存时间”计算题，如命中率与平均访问时间公式 $T = H \cdot T_c + (1-H) \cdot T_m$；
- 结合“虚拟存储器”考查主存与辅存的关系。

复习建议：牢记层次结构图（寄存器 → Cache → 主存 → 辅存），理解各层的作用与速度差异，最好能记住数量级关系（寄存器约 1ns，Cache 约几 ns，主存约几十 ns，辅存约几 ms）。这样无论题目如何变式，都能快速定位。

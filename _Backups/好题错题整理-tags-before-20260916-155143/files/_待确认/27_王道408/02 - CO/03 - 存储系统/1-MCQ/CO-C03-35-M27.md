# 选择题 第 27 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-35-M27_题目.png|题目]]

27.若计算机按字编址，$Cache$ 数据区容量为 $8K$ 字，主存块大小为 $512$ 字，主存地址空间为 $1M$ 字，采用 $2$ 路组相联映射方式。每次根据主存地址访问 $Cache$ 时，需要同时进行（ ）次标记位的比较，每次需要比较的位数是（ ）。

A. $2,8$  
B. $2,16$  
C. $4,8$  
D. $4,16$

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-35-M27_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A。  
主存地址共 $20$ 位，块内偏移 $9$ 位，组索引 $3$ 位，所以标记字段为 $8$ 位；2 路组相联每组有 2 个 Cache 行，因此需同时比较 2 个标记，每次比较 8 位。

**解题切入点**：拿到题目先做“地址划分”：主存地址 = 标记 + 组索引 + 块内偏移。就像哈希表一样，先按“组号”找到唯一一个 Cache 组，组内有 2 个空位，再把这 2 个空位上的“标签”和来访地址的“标签”同时比较。比较次数 = 相联度路数，比较位数 = 标记字段位数。

**推演**：

题目说“按字编址”，所以地址单位是“字”，不需要再考虑字节内偏移。

1. 主存地址空间为 $1M$ 字，即
   $$1M=2^{20}$$
   所以主存地址总位数为 $20$ 位。

2. 主存块大小为 $512$ 字，即
   $$512=2^9$$
   因此块内偏移字段为 $9$ 位。

3. Cache 数据区容量为 $8K$ 字，即
   $$8K=2^{13}$$
   Cache 总块数为
   $$\frac{2^{13}}{2^9}=2^4=16$$

4. 采用 2 路组相联映射，则每组有 2 个 Cache 行，所以组数为
   $$\frac{16}{2}=8=2^3$$
   因此组索引字段为 $3$ 位。

5. 标记字段位数为主存地址位数减去块内偏移位数、组索引位数：
   $$20-9-3=8$$

6. 访问 Cache 时，先用组索引选中对应组；因为是 2 路组相联，该组内有 2 个 Cache 行，所以需要把主存地址中的 8 位标记，分别与该组中 2 个 Cache 行各自保存的 8 位标记同时比较。因此：

   - 同时比较次数：$2$ 次；
   - 每次比较位数：$8$ 位。

答案为 A。

**易错点**：

- 容易把“比较次数”误算成 Cache 组数或 Cache 总块数。实际上比较次数只由相联度决定：2 路相联就同时比较 2 个标记。
- 容易把“组索引位数”算成 $\log_2(16)=4$ 位，但这是直接映射的算法；组相联必须先除以路数，得到组数 8，所以组索引位数是 $3$ 位。
- 注意不要把“标记位”理解成“标记项”。标记项通常还包含有效位、脏位等，本题只问“标记位”即 Tag 的位数，是 8 位。
- 如果题目改为“按字节编址”，还要在块内偏移中额外考虑字节偏移位数；但本题明确“按字编址”，不要多算。

**命题规律**：本题是 Cache 地址结构的基础题，核心公式为

$$t=\log_2(\text{主存大小})- \log_2(\text{块大小})-\log_2(\text{Cache 组数})$$

常见变式包括：求标记存储总容量、求组索引位数、求比较器个数、求 Cache 总容量（含标记项），以及结合命中率计算平均访问时间。复习时要熟练掌握“地址划分”“相联度与比较次数”的关系。

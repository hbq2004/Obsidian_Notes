# 选择题 第 27 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-32-M27_题目.png|题目]]

27. 多模块存储器之所以能提高存储器的访问速度,是因为( )

A. 采用了高速元器件  
B. 各模块有独立的读  
C. 采用了信息预读技术  
D. 模块内各单元地址连续

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-32-M27_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。多模块存储器通过将地址空间分割到多个具有独立读写电路的存储模块中，使各模块可并行或交叉工作，从而在不提高单模块速度的前提下提高存储器的访问带宽。

**解题切入点**：先抓住“多模块存储器”的本质——它是一种**并行结构**，而不是靠“更快”的器件。类似算法竞赛里用分块并行或流水线来优化 IO，而不是单纯提高单次操作的常数。定位考点为“存储器的并行访问技术”。

**推演**：

多模块存储器分为**单体多字**、**多体并行**、**多体交叉**等结构，其核心思想是设置多个存储模块（体），每个模块拥有**独立的地址寄存器、数据寄存器、读写控制电路**。设总模块数为 $m$，每个模块的存取周期为 $T$，则：

- 若各模块串行独立工作，同一时间内只能访问一个模块，等效带宽仍受限于单模块的 $1/T$；
- 若采用交叉编址，连续地址分布在相邻模块中，CPU 可在 $T$ 时间内启动 $m$ 个模块的访问，使它们重叠工作。理想情况下，每 $T/m$ 时间能完成一次数据传送，等效带宽提高到原来的 $m$ 倍。

因此，速度提升的根本来源是**多个模块可以同时进行各自的读写操作**，即“各模块有独立的读（写）电路”，而不是因为使用了更快的元器件（A）、预读技术（C）或地址连续（D）。

- A 错：采用高速元器件是任何存储器都可以做到的，不是“多模块”特有的原因。
- C 错：信息预读是 cache 或流水线中的技术，多模块本身不依赖预读。
- D 错：模块内地址连续不能使模块间并行工作；恰恰相反，交叉编址要求**相邻地址分布在不同的模块**，才能并行。

**易错点**：

1. **误选 A**：把“速度提高”等同于“元器件更快”，而忽略结构并行性。
2. **误选 C**：将多模块存储与指令预取、cache 预读混淆。多模块依赖的是模块级并行，不是预取。
3. **误选 D**：搞反编址方式。多体交叉存储要求地址交叉，而“模块内地址连续”是顺序编址，反而不能并行访问连续地址。
4. **表述不完整**：选项 B 虽不完整，但“独立的读”隐含独立的读写控制电路，是最本质原因；考试中应选最符合原理的选项。

**命题规律**：本题属于“存储系统”基础概念题，常与**多体交叉存储器的带宽计算**、**编址方式（高位/低位交叉）**、**存储周期与总线传输周期关系**等结合考查。复习时应掌握：

1. 多模块存储器的结构示意图与工作原理；
2. 交叉存储的公式：设模块数 $m$，存取周期 $T$，总线传输周期 $\tau = T/m$ 时，连续读取 $n$ 个字所需时间 $t = T + (n-1)\tau$；
3. 与 cache、DMA、流水线等“提速手段”的区分。

**记忆口诀**：多模块提速靠并行，独立读写是根本；高位扩展容量，低位交叉提带宽。

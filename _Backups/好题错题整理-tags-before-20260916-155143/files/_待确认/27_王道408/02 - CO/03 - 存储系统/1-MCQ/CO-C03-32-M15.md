# 选择题 第 15 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-32-M15_题目.png|题目]]

15. 下列关于存储器层次结构的说法中,错误的是（ ）.

A. $Flash$ 存储器读/写速度差异显著,读速接近 $RAM$,写速接近 $ROM$
B. 存储器层次结构基于程序局部性原理,通常采用缓冲技术缓解层级间速率差异
C. $Cache$ 位于 $CPU$ 与主存之间,容量通常大于主存,旨在提升平均访问速率
D. 辅存(如机械硬盘)容量大、成本低但速度慢,仅作为主存的补充与备份

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-32-M15_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。Cache 是位于 CPU 与主存之间的小容量高速缓冲存储器，容量远小于主存；选项说“容量通常大于主存”错误。

**解题切入点**：看到“存储器层次结构”，先画出层次金字塔：寄存器 → Cache → 主存 → 辅存。越靠近 CPU，速度越快、单位成本越高、容量越小；越远离 CPU，容量越大、速度越慢、单位成本越低。本题是选非题，C 中“Cache 容量通常大于主存”与这个基本关系直接矛盾，可快速锁定。

**推演**：

1. 存储器层次结构的基本关系是  
$$
\text{寄存器} \to \text{Cache} \to \text{主存} \to \text{辅存}
$$  
其中 Cache 容量远小于主存，主存容量远小于辅存；但速度关系恰好相反。

2. 存储器层次结构之所以有效，依赖程序局部性原理：
   - 时间局部性：刚访问过的数据很可能再次访问；
   - 空间局部性：访问过的地址附近的数据很可能被访问。  
   因此可以把主存中近期可能用到的内容复制到更小更快的 Cache 中，提高 CPU 访问的命中率。

3. 设命中率为 $H$，Cache 访问时间为 $T_c$，主存访问时间为 $T_m$，则平均访问时间可写成  
$$
T_a = H T_c + (1-H)T_m
$$  
命中率越高，$T_a$ 越接近 $T_c$，这正是 Cache 提升平均访问速率的原因。Cache 容量越大命中率可能越高，但容量不可能大于主存。

4. 逐项判断：
   - A：Flash 是非易失性半导体存储器，读速度快、写速度明显慢，统考教材中常表述为“读速接近 RAM，写速显著变慢”，不是本题错误项。
   - B：存储器层次结构基于局部性原理，通过 Cache、缓冲等缓解层级间速度差异，正确。
   - C：Cache 逻辑上位于 CPU 与主存之间，容量远小于主存，说“容量通常大于主存”错误。
   - D：辅存容量大、成本低、速度慢，作为主存的后备和补充，正确。

**易错点**：

- 最容易把 Cache 和主存的容量关系记反。Cache 靠近 CPU，容量小、速度快；主存容量大、速度慢。看到“Cache 容量大于主存”应直接判错。
- 不要误以为 Cache 是扩大主存容量用的。Cache 只是主存部分内容的副本，不是大容量存储设备。
- 不要因为 D 中“仅作为主存的补充与备份”中的“仅”字过于绝对而误选；在存储器层次结构语境下，辅存正是作为主存的后备和补充存在的。
- A 中“写速接近 ROM”字面比较特殊，但本题考点不是深究 ROM 的写速度，而是 Flash 读快写慢的特点，不必在此纠结。

**命题规律**：本题考查存储器层次结构、Cache 特性、局部性原理和辅存定位。常见变式有：判断 Cache/主存/辅存的容量、速度、价格排序；结合局部性原理说明 Cache 为什么有效；计算 Cache 命中率和平均访问时间；区分 Cache—主存层次与主存—辅存层次的实现机制。复习时应熟记层次结构金字塔，并弄清每级存储器的角色差异。

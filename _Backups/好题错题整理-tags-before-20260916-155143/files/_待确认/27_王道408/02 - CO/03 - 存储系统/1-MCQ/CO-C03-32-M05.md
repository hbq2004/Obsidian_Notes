# 选择题 第 5 题

![[_Attachments/题目识别/27_王道408-题目/CO-C03-32-M05_题目.png|题目]]

5. 下列关于随机存储器的说法中,正确的是（ \_ ）.

A. 半导体 $RAM$ 中的信息可读可写,且断电后仍能保持记忆.  
B. $DRAM$ 是易失性 $RAM$,而 $SRAM$ 中的存储信息是不易失的.  
C. 半导体 $RAM$ 是易失性 $RAM$,但只要电源不断电,所存信息是不丢失的.  
D. 半导体 $RAM$ 是非易失性 $RAM$.

---

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CO-C03-32-M05_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C  
半导体 RAM（包括 SRAM 和 DRAM）都是易失性存储器，断电后数据丢失，但只要电源持续供电且刷新（对 DRAM 而言）正常，信息可保持。

**解题切入点**：  
本题考察 RAM 的易失性本质。首先抓住“随机存储器”定义，直接定位到存储器的分类（易失 vs 非易失）。易错点在于混淆 SRAM 与 DRAM 的易失性，以及断电保持特性。可类比“白板上的字”：电源相当于白板，断电即擦除，但正常供电时内容可保持（DRAM 需定时刷新，相当于不断重写）。

**推演**：  
1. 半导体 RAM（随机存取存储器）包括静态 RAM（SRAM）和动态 RAM（DRAM）。  
2. 易失性定义：断电后存储信息丢失。  
   - SRAM 用触发器存储，断电后触发器状态丢失，故易失。  
   - DRAM 用电容电荷存储，断电后电荷泄漏，故易失。  
3. 选项分析：  
   - **A**：说“断电后仍能保持记忆”，与易失性矛盾，错误。  
   - **B**：DRAM 是易失性正确，但 SRAM 也是易失性，故“不易失”错误。  
   - **C**：承认半导体 RAM 是易失性，且强调“电源不断电，信息不丢失”。对于 SRAM，只要电源稳定，数据稳定；对于 DRAM，需要刷新电路（通常集成在内存控制器中）不断刷新，确保电容电荷不丢失，因此只要电源不断电且刷新正常，信息可保持。故 C 正确。  
   - **D**：称 RAM 为非易失性，明显错误。  

综上，C 为唯一正确选项。

**易错点**：  
- 误以为 SRAM 是非易失性（实际上 SRAM 只是比 DRAM 更快、无需刷新，但断电仍丢失）。  
- 忽略 DRAM 必须刷新才能保持数据，但题目中“只要电源不断电”隐含了正常工作条件（刷新电路持续供电），因此 C 的表述在常规意义上成立。  
- 混淆 RAM 与 ROM（只读存储器，非易失性）。

**命题规律**：  
- 考点：存储器的易失性分类，RAM 与 ROM 的区别，SRAM 与 DRAM 的特性。  
- 常见变式：  
  - 直接问“下列哪种存储器是易失性/非易失性”。  
  - 结合刷新、功耗、速度等对比 SRAM 与 DRAM。  
- 复习建议：  
  - 牢记易失/非易失的典型代表：RAM（SRAM、DRAM）易失；ROM（掩模 ROM、PROM、EPROM、EEPROM、Flash）非易失。  
  - 理解 SRAM 与 DRAM 的工作原理（触发器 vs 电容），从而自然记住易失性及刷新需求。  
  - 注意题目陷阱：如“断电后仍能保持”必须针对非易失性存储器，不可混淆。

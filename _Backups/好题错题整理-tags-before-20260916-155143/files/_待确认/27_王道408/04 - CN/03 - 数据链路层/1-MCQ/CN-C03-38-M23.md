# 选择题 第 23 题

![[_Attachments/题目识别/27_王道408-题目/CN-C03-38-M23_题目.png|题目]]

23.【2016 统考真题】若主机 $H2$ 向主机 $H4$ 发送一个数据帧，主机 $H4$ 向主机 $H2$ 立即发送一个确认帧，则除 $H4$ 外，从物理层上能够收到该确认帧的主机还有（ ）

【图：网络拓扑图，包含路由器 R2、交换机 Switch、集线器 Hub 以及四台主机 H1、H2、H3、H4。R2 的 E1 接口 IP 地址为 192.168.3.254，连接到 Switch；Switch 连接 H1（IP 地址 192.168.3.2）和 H2（IP 地址 192.168.3.3），并连接到 Hub；Hub 连接 H3（IP 地址 192.168.3.251）和 H4（IP 地址 192.168.3.252）。】

A. 仅 $H2$
B. 仅 $H3$
C. 仅 $H1$、$H2$
D. 仅 $H2$、$H3$

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C03-38-M23_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：D。H4 发出确认帧后，Hub 会将该帧广播到除 H4 外的其他端口，因此 H3 能收到；Switch 根据 MAC 地址表只转发给 H2，所以 H1 收不到。除 H4 外能收到确认帧的是 H2、H3。

**解题切入点**：拿到题目先根据设备类型确定“谁在什么层次工作”：Hub 是物理层设备，不识别 MAC 地址；Switch 是数据链路层设备，会学习并查表转发。问“从物理层上能够收到”，等价于问“哪些主机对应链路上会出现该帧的比特流”，而不是问“哪些主机最终会把帧上交给网络层”。算法竞赛类比：Hub 相当于“向所有邻居广播”，Switch 相当于“按 `map<MAC, port>` 查表后定向投递”；分层协议类似分治，每层只处理自己该处理的信息。

**推演**：

设 $M_{H2}$ 表示 H2 的 MAC 地址，$M_{H4}$ 表示 H4 的 MAC 地址。

1. H2 先向 H4 发送数据帧。Switch 收到该帧后，会记录源 MAC 地址 $M_{H2}$ 与入端口的对应关系，即学习到 $M_{H2}$ 对应的端口是连接 H2 的端口。因此后续若收到目的地址为 $M_{H2}$ 的帧，Switch 知道应该向 H2 所在端口转发。

2. H4 收到数据帧后，立即向 H2 发送确认帧。该帧从 H4 发出后先到达 Hub。

3. Hub 工作在物理层，不检查目的 MAC 地址，而是把收到的信号从除 H4 所在端口外的所有其他端口转发出去。由于 H3 和 Switch 都连接在 Hub 上，所以：
   - H3 会在物理层收到该确认帧；
   - Switch 也会收到该确认帧。

4. Switch 收到确认帧后，查看目的地址为 $M_{H2}$，在 MAC 地址表中查到该地址对应 H2 所在端口，于是只向 H2 端口转发该帧。因此 H2 收到确认帧，而 H1 收不到。

所以，除 H4 外，从物理层上能够收到该确认帧的主机是 H2 和 H3，答案选 D。

**易错点**：

1. 把交换机当成集线器，认为 Switch 也会向所有端口广播。实际上 Switch 会学习 MAC 地址，已知目的地址时只向对应端口转发。
2. 忽略 Hub 的广播特性。确认帧虽然目的地址是 H2，但 Hub 不做过滤，H3 照样会在物理层收到该帧。
3. 混淆“物理层收到”和“链路层接收上送”。H3 的网卡会在 MAC 层因目的地址不匹配而丢弃该帧，但题目问的是物理层能否收到，因此 H3 应被计入。
4. 忽略初始数据帧的作用。正是因为 H2 先发送了数据帧，Switch 才学习到 $M_{H2}$ 对应的端口，回程确认帧才能被定向转发给 H2。

**命题规律**：本题是 408 中“局域网与网络设备”的经典考法，重点考查 Hub、Switch 的分层工作原理和交换机 MAC 地址学习/转发规则。常见变式包括：问 H2 到 H4 的数据帧哪些主机能收到、交换机 MAC 表为空时是否泛洪、ARP 请求/响应的传播范围、计算碰撞域或广播域数量等。复习时应紧扣分层模型：Hub/中继器工作在物理层，交换机/网桥工作在数据链路层，路由器工作在网络层；并熟练掌握交换机“学习、泛洪、转发、丢弃”的基本规则。

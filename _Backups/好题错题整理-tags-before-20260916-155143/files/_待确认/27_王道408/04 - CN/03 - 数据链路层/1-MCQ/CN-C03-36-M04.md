# 选择题 第 4 题

![[_Attachments/题目识别/27_王道408-题目/CN-C03-36-M04_题目.png|题目]]

4. 网卡实现的主要功能在（ ）

(A) 物理层和数据链路层
(B) 数据链路层和网络层
(C) 物理层和网络层
(D) 数据链路层和应用层

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C03-36-M04_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：A。网卡既负责物理层比特流的收发与编码，又负责数据链路层的成帧、MAC 地址识别和差错控制，因此主要工作在物理层和数据链路层。

**解题切入点**：拿到这道题，先明确“网卡”是一个硬件设备，而不是协议或软件进程，所以要立刻联系“设备与OSI层次”的对应关系。这就像算法竞赛中，我们要先判断题目考察的是“数据结构”还是“算法思想”，然后套用相应的模板。网卡可以类比为竞赛中处理输入输出的底层封装：它既要处理物理信号（对应物理层），又要完成帧的封装与解析（对应数据链路层），而不负责 IP 路由（网络层）或应用程序数据（应用层）。

**推演**：

1. 网卡（NIC，Network Interface Card）是计算机与传输介质之间的硬件接口，核心功能包括：
   - 物理层功能：发送时将比特流转换为适合在介质上传输的信号（如曼彻斯特编码、差分编码等），接收时将信号还原为比特流；
   - 数据链路层功能：发送时把网络层下发的 IP 分组封装成帧，加上 MAC 地址和帧校验序列（FCS）；接收时检查帧的目的 MAC 地址，只有匹配才接收并解封装，同时进行差错检测（CRC）。

2. 从 OSI 七层模型看：
   - 物理层：负责比特流的透明传输、编码、调制、同步等；
   - 数据链路层：负责将比特组装成帧，进行 MAC 寻址和差错控制。

   网卡在这两层都有明确任务，因此它跨越物理层和数据链路层。

3. 网络层功能（如 IP 地址寻址、路由选择）由操作系统中的 TCP/IP 协议栈或路由器完成，网卡本身不实现网络层；应用层功能更与网卡无关。因此 B、C、D 都不正确。

综合可知，正确答案为 A。

**易错点**：

- 常见错误：认为网卡有 MAC 地址，只属于数据链路层，而忘记物理层功能。实际上网卡直接连接网线或无线介质，必须完成信号收发与编码，属于物理层。
- 常见错误：看到网卡支持“IP 校验和卸载”等功能，误认为网卡也实现网络层。注意这些是现代硬件加速特性（如 TOE、checksum offload），不是网卡实现的基本主要功能，考研题目通常从基础分层模型出发。
- 规避方法：记忆“设备与分层”的对应口诀：物理层设备（中继器、集线器）、数据链路层设备（网桥、交换机）、网络层设备（路由器）；网卡是特殊的“跨两层”设备，横跨物理层和数据链路层。

**命题规律**：本考点属于“计算机网络体系结构”中的基础题，考查硬件设备与 OSI/TCP/IP 层次的对应关系。常见变式包括：集线器工作在物理层、交换机工作在数据链路层、路由器工作在网络层，以及“网卡实现哪两层功能”等。复习时应从物理层和数据链路层的功能定义入手，并结合实际设备（网卡、交换机、路由器）的功能划分来记忆，尤其注意设备往往可能横跨相邻两层，不能只看单一功能标签。

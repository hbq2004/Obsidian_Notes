# 选择题 第 19 题

![[_Attachments/题目识别/27_王道408-题目/CN-C03-38-M19_题目.png|题目]]

19.【2009 统考真题】以太网交换机进行转发决策时使用的 PDU 地址是（ ）

(A) 目的物理地址  
(B) 目的 IP 地址  
(C) 源物理地址  
(D) 源 IP 地址

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C03-38-M19_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：A。以太网交换机工作在数据链路层，其转发决策依据帧（PDU）中的**目的物理地址（目的 MAC 地址）**，而非 IP 地址或源地址。

**解题切入点**：拿到题目先锁定“以太网交换机”属于哪一层设备，以及“转发决策”对应数据处理中的“查表路由”。算法竞赛中常把“交换机”类比为一个“哈希表容器”：它用某个 key 去查表得到发送端口。问题就是 key 是哪个字段。数据链路层的“帧”自带源/目的 MAC 地址，交换机只关心“这帧要送给谁”，因此 key 是 **目的 MAC 地址**，而不是发送者，也不是网络层的 IP。

**推演**：

1. 明确 PDU 层次：
   - 物理层 PDU 是比特流；
   - 数据链路层 PDU 是**帧**，其地址字段包含源 MAC 地址和目的 MAC 地址；
   - 网络层 PDU 是**分组/包**，其地址字段包含源 IP 地址和目的 IP 地址。
2. 以太网交换机是**二层设备**，它不解析 IP 报头，只解析帧头部。
3. 交换机内部维护一张 **MAC 地址表**，记录“MAC 地址 → 端口”的映射。当帧到达时：
   - 交换机读取帧的**目的 MAC 地址**；
   - 查表：
     - 若表中有该目的 MAC 对应的端口，则从该端口转发；
     - 若表中无记录，则向除接收端口外的所有端口广播（泛洪）；
   - 同时，交换机还会学习**源 MAC 地址**，将其与接收端口绑定，但这一步是“学习”而非“转发决策”。
4. 因此，转发决策使用的地址是**目的物理地址**，即选项 A。

**易错点**：

- **误选 B（目的 IP 地址）**：混淆了交换机与路由器。路由器工作在网络层，才使用目的 IP 地址进行转发决策。
- **误选 C（源物理地址）**：把“地址学习”当成“转发决策”。源 MAC 地址用于建立 MAC 地址表，不是决定从哪个端口发出。
- **误选 D（源 IP 地址）**：既混淆了层次，又混淆了源地址作用。
- **规避方法**：记住一句话——“交换机用**目的 MAC** 转发，用**源 MAC** 学习；路由器用**目的 IP** 转发”。

**命题规律**：

- 考点定位：以太网交换机的工作原理、各层 PDU 地址字段、二层与三层设备的区别。
- 常见变式：
  - 考查交换机 MAC 地址表的建立过程；
  - 对比集线器、交换机、路由器转发依据；
  - 给出帧结构，问交换机如何处理未知目的 MAC 地址；
  - 结合 ARP 协议，分析“发送帧时如何知道目的 MAC 地址”。
- 复习建议：把 OSI 各层设备与 PDU 对应关系记熟，尤其注意“物理层设备（集线器）不处理地址，数据链路层设备（交换机）处理 MAC 地址，网络层设备（路由器）处理 IP 地址”。做题时先判断设备所在层次，再判断转发使用的地址字段。

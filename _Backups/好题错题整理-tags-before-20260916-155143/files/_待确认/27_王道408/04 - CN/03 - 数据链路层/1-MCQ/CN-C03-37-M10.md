# 选择题 第 10 题

![[_Attachments/题目识别/27_王道408-题目/CN-C03-37-M10_题目.png|题目]]

10. PPP 中的 LCP 帧的作用是（\_\_）.

A. 在建立状态阶段协商数据链路协议的选项
B. 配置网络层协议
C. 检查数据链路层的错误,并通知错误信息
D. 安全控制,保护通信双方的数据安全

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C03-37-M10_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：A。LCP（Link Control Protocol）帧用于在 PPP 链路建立阶段协商数据链路层的各项选项，如最大接收单元（MRU）、认证协议、协议字段压缩等。

**解题切入点**：拿到题目先抓“PPP”和“LCP”两个关键词，定位到数据链路层 PPP 协议的两层结构：LCP 管链路本身，NCP 管网络层协议配置。可以类比算法竞赛中的“初始化配置”和“业务逻辑”分离：LCP 是主程序启动时的参数解析与初始化模块，NCP 才是对接具体上层“插件”的适配器。不要把链路层配置与网络层配置混在一起。

**推演**：

PPP 协议栈可以划分为：

- 物理层：提供串行链路的比特传输；
- 数据链路层：PPP 帧封装 + LCP；
- 网络层：由 NCP（如 IPCP、IPXCP）配置各种网络层协议。

PPP 链路建立过程如下：

1. **链路建立阶段**：双方发送 LCP 的 Configure-Request、Configure-Ack、Configure-Nak、Configure-Reject 等报文，协商链路参数，如 MRU、认证协议、魔术字、协议字段压缩、地址与控制字段压缩等。
2. **认证阶段（可选）**：若 LCP 协商出认证协议，则进行 PAP 或 CHAP 认证。
3. **网络层协议配置阶段**：LCP 协商完成后，调用相应的 NCP 配置网络层协议，例如 IPCP 为对端分配 IP 地址。
4. **链路终止阶段**：通过 LCP 的 Terminate-Request 和 Terminate-Ack 关闭链路。

因此，LCP 帧只负责数据链路层的建立、配置、维护和终止，不配置网络层协议，也不负责数据加密。差错检测主要由 PPP 帧中的 FCS（帧校验序列）完成；安全认证由 PAP/CHAP 完成，且认证协议本身只是 LCP 协商的一个选项。

所以 A 正确。

**易错点**：

- 误选 B：混淆 LCP 与 NCP，IPCP 才是配置 IP 等网络层协议的协议。
- 误选 C：PPP 中负责检错的是 FCS，LCP 可以测试链路，但“检查数据链路层错误并通知错误信息”不是 LCP 帧的主要作用。
- 误选 D：PAP/CHAP 属于认证协议，可由 LCP 协商启用，但其作用是身份认证，不是保护通信数据安全；数据加密通常由 IPsec 或上层安全协议完成。

**命题规律**：

- 考点定位：PPP 协议的分层结构、LCP 与 NCP 的职责区分、链路建立过程。
- 常见变式：给出一段 PPP 链路建立流程，问某阶段由哪个协议完成；或给出 LCP 协商字段，问其作用；也可能与 HDLC 帧格式对比。
- 复习建议：熟记 PPP 的“链路建立—认证—网络配置—链路终止”流程，分清 LCP 与 NCP 的职责。可用一句话辅助记忆：“LCP 管链路，NCP 管网络”。

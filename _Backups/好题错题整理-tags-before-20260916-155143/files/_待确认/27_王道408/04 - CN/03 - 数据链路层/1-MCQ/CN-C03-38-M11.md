# 选择题 第 11 题

![[_Attachments/题目识别/27_王道408-题目/CN-C03-38-M11_题目.png|题目]]

11. 下列关于广播式网络的说法中,错误的是( )

(A) 共享广播信道  
(B) 不存在路由选择问题  
(C) 可以不要网络层  
(D) 不需要服务接入点

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C03-38-M11_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：D。广播式网络共享广播信道、同一广播域内无路由选择，因此可以不需要网络层；但分层网络中相邻层之间必须通过“服务接入点（SAP）”来提供/调用服务，D 说“不需要”错误。

**解题切入点**：拿到题先抓“广播式网络”和“错误的是”，定位考点为“广播式网络的特点”与“分层体系结构中的服务接入点”。算法竞赛类比：广播式网络就像共享内存或消息总线，向总线广播一次，所有进程都能收到，不需要为每个目的结点算“最短路径/下一跳”；但进程要使用该功能仍需固定的 API 接口，不能因为广播方便就把接口定义省掉。

**推演**：

设广播域中结点集合为 $V$，源点为 $s \in V$。$s$ 发送帧 $F$ 后，
$$
\forall v \in V \setminus \{s\},\quad v \text{ 都能收到 } F.
$$
因此帧的交付不依赖中间结点的“逐跳选路”，只需在帧中写明目的地址，由目的地址判断是否接收。

- A 正确：广播式网络的定义就是所有结点共享广播信道。
- B 正确：同一广播域内没有多条可供选择的转发路径，不存在路由选择问题。
- C 正确：网络层的核心功能之一是路由选择；如果只是单个广播网络、不与其他网络互连，就可以不设网络层，由数据链路层完成寻址与交付。注意 C 说的是“可以”，不是“必须”。
- D 错误：服务接入点（SAP）是分层结构中相邻层之间的服务接口。只要网络采用分层体系结构，上层要使用下层服务就必须通过 SAP；例如 IEEE 802 局域网中的 LLC 子层通过 LSAP 向上层协议提供服务。广播式网络也不能省略 SAP。

**易错点**：

1. 把 B 绝对化：B 的“不存在路由选择问题”指同一个广播网络内部；多个广播网络互连成互联网时，网络层仍要处理路由，但不能因此认为 B 错。
2. 把 C 判错：误以为“没有网络层就不能通信”。单个广播域中，链路层目的地址（如 MAC 地址）已足以完成本域交付。
3. 把“无路由”等同“无寻址”：广播式网络仍需要目的地址，只是不需要路径选择。
4. 误以为 SAP 可有可无：SAP 是层间服务接口，不是某个具体协议，只要分层提供服务，就必须有对应服务访问点。

**命题规律**：

本题属于“网络分类 + OSI 分层服务”的基础概念题。常见变式包括：判断 Ethernet/ATM 分别是广播式还是点对点式；问广播式网络需要解决哪些问题，如共享信道、信道争用、寻址等；把 SAP 与端口、MAC 地址、IP 地址混在一起辨析。复习时应把“广播域内部”和“多个网络互连”分开：前者可无路由、可省网络层；后者必须要有网络层；同时记住 SAP 是层间接口，不能省略。

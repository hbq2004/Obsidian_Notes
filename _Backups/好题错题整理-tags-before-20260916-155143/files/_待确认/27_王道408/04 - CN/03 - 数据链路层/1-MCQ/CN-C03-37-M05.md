# 选择题 第 5 题

![[_Attachments/题目识别/27_王道408-题目/CN-C03-37-M05_题目.png|题目]]

5. 现在大量的计算机是通过诸如以太网这样的局域网连入广域网的,而局域网与广域网的互连是通过（ ）实现的.

(A) 路由器  
(B) 资源子网  
(C) 桥接器  
(D) 中继器

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C03-37-M05_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：A。一句话理由：局域网与广域网的互连发生在网络层，需依靠路由器进行不同网络间的分组转发与路由选择。

**解题切入点**：先抓住“互连”二字的层次含义——局域网与广域网是不同网络，互连需要工作在网络层的设备；这类似于算法竞赛中“不同数据结构的接口对接”：你不能用底层硬件直接拼接，而是需要一个“适配器/转发器”来根据地址表决定数据往哪走。路由器就是那个根据 IP 地址做“路由决策”的核心调度器。

**推演**：

- 局域网（如以太网）工作在物理层和数据链路层，其内部用 MAC 地址通信；广域网（如 Internet 骨干）则主要通过 IP 地址在网络层寻址。
- 将局域网接入广域网，必须完成“链路层帧 → 网络层分组 → 链路层帧”的转换与转发，同时要能选择到达目的网络的最佳路径。
- 在 OSI/RM 中，完成网络层互连的设备是**路由器**（Router）。
- 选项辨析：
  - (B) 资源子网：属于计算机网络组成的逻辑划分（资源子网 + 通信子网），不是具体互连设备。
  - (C) 桥接器（网桥）：工作在数据链路层，用于连接同类型或相似类型的局域网，不能连接异构网络（局域网与广域网）。
  - (D) 中继器：工作在物理层，仅放大/再生信号，不进行地址识别和路径选择，无法实现网络互连。

因此，局域网与广域网互连必须通过路由器实现。

**易错点**：

1. **混淆“互连”与“连接”**：中继器、集线器只是物理层的“连接”，不解决网络层地址和路由问题；桥接器只能连接 MAC 层相同的局域网，不能连接局域网与广域网。  
2. **忽视网络层地址差异**：局域网内通信靠 MAC 地址，广域网/互联网通信靠 IP 地址，只有路由器能同时处理这两种地址并完成转发。  
3. **误选“桥接器”**：桥接器能连接两个以太网，但无法连接“局域网”和“广域网”这种不同网络体系，因为广域网接口协议和地址结构不同。  
4. **记忆口诀**：物理层中继器、链路层网桥/交换机、网络层路由器、高层网关。

**命题规律**：

- 考点定位：OSI/RM 或 TCP/IP 体系结构中各层互连设备的功能区分，属于计算机网络基础高频选择题。
- 常见变式：
  1. 给出具体场景（如“两个以太网互连”选网桥/交换机；“不同网络互连”选路由器；“延长传输距离”选中继器）。
  2. 结合“冲突域/广播域”考查：路由器隔离冲突域和广播域，网桥/交换机隔离冲突域但不隔离广播域。
  3. 与“网关”概念辨析：广义网关可工作在高层，路由器是最常见的网关设备。
- 复习建议：把“物理层—数据链路层—网络层—传输层及以上”对应的典型设备（中继器、集线器、网桥、交换机、路由器、网关）列表对比，重点记忆各自工作的层次、处理的地址类型和能否隔离冲突域/广播域。

# 选择题 第 3 题

![[_Attachments/题目识别/27_王道408-题目/CN-C03-31-M03_题目.png|题目]]

3. 下列选项中,不属于数据链路层协议功能的是(  )

(A) 定义数据格式  
(B) 提供节点之间的可靠传输  
(C) 控制对物理传输介质的访问  
(D) 为终端节点隐蔽物理传输的细节.

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C03-31-M03_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：D。数据链路层负责相邻节点间链路上的帧传输，功能包括封装成帧、差错控制、流量控制、可靠传输和介质访问控制；而“为终端节点隐蔽物理传输的细节”是网络层（更高层）的端到端职责，不属于数据链路层功能。

**解题切入点**：  
拿到题目先“划层”：数据链路层的关键词是“相邻节点 / 链路 / 帧 / MAC”；一旦选项中出现“终端节点”“端到端”“物理网络差异”等词，就要怀疑它不是数据链路层功能。  
可以类比算法竞赛：数据链路层像只处理“一条边/一段区间”的局部函数；网络层像全局最短路，负责端到端可达；D 相当于“把底层存储/IO 细节封装成高层 API 暴露给全局调用”，这是一个全局抽象，不是单段链路的局部协议能完成的事。

**推演**：  
在 OSI 参考模型中，数据单元的传递关系可以表示为

$$
\text{物理层}\xrightarrow{\text{比特流}}\text{数据链路层}\xrightarrow{\text{帧}}\text{网络层}\xrightarrow{\text{分组}}\text{传输层}\xrightarrow{\text{报文段}}\text{应用层}
$$

数据链路层的主要功能包括：

1. **封装成帧**：把网络层下发的数据报加上帧首部和帧尾部，形成帧。帧格式、字段含义都是由数据链路层协议定义的，因此 A“定义数据格式”属于数据链路层功能。
2. **差错控制与可靠传输**：数据链路层会在帧中添加校验码（如 CRC），发现错误后可丢弃或请求重发；采用确认重传机制时，能在“相邻节点之间”提供可靠传输。因此 B“提供节点之间的可靠传输”属于数据链路层功能，注意这里说的是相邻节点，不是端到端。
3. **介质访问控制**：在广播式共享信道上，需要决定哪个节点能占用物理介质，例如 CSMA/CD、CSMA/CA、令牌协议等，这是数据链路层 MAC 子层的功能，因此 C 正确。
4. **流量控制、链路管理、透明传输等**：也属于数据链路层功能。

再看 D：“为终端节点隐蔽物理传输的细节”。

- “终端节点”通常指端系统，而不是链路上相邻的两个接口。数据链路层只负责把帧从链路的这一段传到相邻的另一段，不能单独为两个终端节点提供端到端的逻辑通信。
- 屏蔽底层的物理网络差异、让上层感觉不到具体物理传输方式，是网络层的主要职责之一；传输层再进一步负责端到端的通信。数据链路层没有这种面向终端节点的全局抽象能力。
- 常见干扰是“透明传输”：数据链路层的透明传输是指帧的数据部分中出现与定界符相同的比特组合时仍能正确传输，而不是“向终端节点隐蔽物理传输细节”。

所以，D 不属于数据链路层协议功能。

**易错点**：  
- 误选 B：很多考生认为“可靠传输只属于传输层”。实际上传输层提供的是端到端可靠传输，而数据链路层也可以提供相邻节点之间的可靠传输，例如 HDLC、802.11 ARQ 等。  
- 误选 C：介质访问控制容易误判为物理层功能。物理层只负责比特信号和线路接口，“何时能占用共享介质”由数据链路层的 MAC 子层控制。  
- 误选 D：容易把“隐蔽物理传输细节”和“透明传输”混为一谈。链路层的透明传输是帧内数据的转义/填充问题，不是面向终端节点屏蔽物理层细节。  
- 忽略“相邻”与“端到端”的区别：数据链路层只说 node-to-node，网络层/传输层才说 end-to-end。

**命题规律**：  
考点是 OSI/TCP/IP 各层功能边界的区分，尤其常考数据链路层的功能集合。常见变式包括“下列哪项不属于物理层功能”“可靠传输由哪些层提供”“MAC 属于哪一层”“透明传输的含义是什么”等。复习时建议把各层按“数据单元、典型协议、典型设备、核心关键词”列表整理，遇到“帧、相邻节点、MAC”对应数据链路层；遇到“端到端、进程通信、选路、异构网络”立刻向更高层找答案。

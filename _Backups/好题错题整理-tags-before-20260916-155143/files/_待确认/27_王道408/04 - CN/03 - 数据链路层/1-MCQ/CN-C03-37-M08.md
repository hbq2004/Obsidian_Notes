# 选择题 第 8 题

![[_Attachments/题目识别/27_王道408-题目/CN-C03-37-M08_题目.png|题目]]

8. 以下对 $PPP$ 的描述中,错误的是 ( )

A. 具有差错控制能力

B. 仅支持 $IP$

C. 支持动态分配 $IP$ 地址

D. 支持身份验证

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C03-37-M08_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：B。PPP 并不是“仅支持 IP”，它通过 NCP 可支持多种网络层协议；A、C、D 都是 PPP 的典型功能（差错检测、动态分配 IP、身份验证）。

**解题切入点**：拿到本题先定位为“数据链路层协议 PPP 特性”题。单项错误题应优先抓“绝对化表述”，例如“仅支持 IP”中的“仅”字几乎必错。可以类比算法竞赛：不能把接口只实现成支持一种数据类型，PPP 的 NCP 机制就相当于“协议协商/多态适配”，不同的上层协议对应不同的控制协议；而“动态分配 IP”则类似运行时通过控制逻辑动态申请资源，由 IPCP 完成。

**推演**：

PPP 协议由三部分组成：

1. 将上层数据封装到串行链路的封装方法；
2. 链路控制协议 LCP，负责建立、配置、测试和释放链路，也支持身份验证；
3. 网络控制协议 NCP，针对不同的网络层协议进行参数协商。

PPP 帧格式大致为：

$$
\text{标志}(0x7E)\ |\ \text{地址}(0xFF)\ |\ \text{控制}(0x03)\ |\ \text{协议}\ |\ \text{信息}\ |\ \text{FCS}\ |\ \text{标志}(0x7E)
$$

其中“协议字段”用于标识上层协议，例如：

- $0x0021$ 表示 IP；
- $0x8021$ 表示 IPCP；
- $0xC021$ 表示 LCP；
- $0xC023$ 表示 PAP；
- $0xC223$ 表示 CHAP。

协议字段的存在说明 PPP 可以封装多种网络层协议，而不仅仅是 IP，因此 B 错误。

对于各选项：

- A 正确：PPP 帧含有 FCS 字段，接收方通过 CRC 检测错误，出错帧会被丢弃，因此 PPP 具有差错检测/控制能力。
- B 错误：PPP 支持 IP，但也支持其他网络层协议。
- C 正确：通过 IPCP 可以协商并动态分配 IP 地址。
- D 正确：LCP 支持身份验证协议，如 PAP、CHAP。

所以错误的是 B。

**易错点**：

- 容易选 A：认为 PPP 没有重传和纠错机制，就不算“差错控制”。实际上 PPP 有 FCS 差错检测并丢弃错误帧，属于差错控制中的检测手段；考研中通常将“差错检测”视为“差错控制能力”。
- 容易选 C：忽略 IPCP 的作用。PPP 支持通过 NCP 中的 IPCP 动态协商 IP 地址。
- 容易选 D：不知道 PPP 支持 PAP 和 CHAP 两种身份验证方式。
- 混淆 PPP 与 HDLC：HDLC 是面向比特的可靠传输协议，PPP 是面向字节的、支持多协议封装的协议，两者不要混记。

**命题规律**：本题的核心考点是 PPP 协议的功能与组成，常见变式包括：PPP 由哪几部分组成？LCP 和 NCP 分别负责什么？PPP 是否支持身份验证？PPP 与 HDLC 的区别？PPP 是否可靠传输？复习时应重点掌握 PPP 的三层结构、帧格式中的协议字段、FCS 的作用，以及 PAP/CHAP 的认证功能。

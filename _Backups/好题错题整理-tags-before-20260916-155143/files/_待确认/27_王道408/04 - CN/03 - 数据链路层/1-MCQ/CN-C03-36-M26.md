# 选择题 第 26 题

![[_Attachments/题目识别/27_王道408-题目/CN-C03-36-M26_题目.png|题目]]

26. 无线局域网不使用 CSMA/CD 而使用 CSMA/CA 的原因是,无线局域网( ).

(A) 不能同时收发,无法在发送时接收信号

(B) 难以实现冲突检测,存在隐蔽站和暴露站问题

(C) 由于广播特性,不会出现冲突

(D) 覆盖范围很小,不进行冲突检测不影响正确性

## DeepSeek V4 Flash Max 解析

**答案**：B。无线局域网难以实现冲突检测，且存在隐蔽站和暴露站问题，所以不能照搬有线以太网的 CSMA/CD，需改用 CSMA/CA 来避免碰撞；A 只是“难以实现冲突检测”的一个物理原因。

**解题切入点**：拿到题先抓“CSMA/CD 与 CSMA/CA 的核心差异”。CSMA/CD 是“边发边听、冲突后中止”，要求站点能同时发送和接收；CSMA/CA 是“尽量在发送前避免冲突”，不再依赖发送时检测碰撞。这就像算法竞赛中做并发判重：有线环境可以“CAS 读回”立刻发现冲突，无线环境读不到现场，只能改为“随机退避 + 确认重传”的策略。

**推演**：
- 有线以太网能使用 CSMA/CD，是因为站点在发送数据时仍能检测信道上的信号变化；一旦检测到冲突，立即停止发送并执行二进制指数退避。
- 无线局域网不满足这一条件：
  1. 无线网卡通常是半双工工作，发送时难以同时接收信号，所以“边发边听”在物理上不可靠；
  2. 更关键的是隐蔽站问题：A 向 B 发送时，C 也在向 B 发送，但 A、C 互相听不见，冲突只发生在接收端 B，发送端 A、C 无法检测到；
  3. 还存在暴露站问题：C 能听到 B 的发送，但 C 发给 D 并不会干扰 B，若只用物理载波侦听会误判信道忙，降低信道利用率。
- CSMA/CA 的思路是“避免冲突”而不是“检测冲突”：发送前先监听，信道空闲后还要等待 DIFS 并随机退避；用 RTS/CTS 预约信道并设置 NAV，可缓解隐蔽站问题；接收方正确收到帧后回复 ACK，发送方收不到 ACK 就重传。
- 因此，B 最完整。A 只是其中“难以实现冲突检测”的物理原因之一；C 说广播特性不会冲突是错误的，广播共享信道仍可能冲突；D 也不成立，覆盖范围小不等于不需要处理冲突。

**易错点**：
- 容易误选 A。A 本身不是错误，但不完整；“不能同时收发”只解释了半双工导致的检测困难，没有覆盖隐蔽站和暴露站问题。
- 混淆 CSMA/CD 与 CSMA/CA：CD 是“碰撞后检测并重传”，CA 是“碰撞前尽量避免，靠 ACK 确认”。
- 误以为无线信道是广播就不会冲突。广播只表示多个站点能收到信号，不代表多个发送不会互相干扰。
- 注意 RTS/CTS 主要用于缓解隐蔽站问题；暴露站问题虽然也需要考虑，但 CSMA/CA 并不能完全消除它。

**命题规律**：这是无线局域网协议中的高频考点。常考 CSMA/CA 与 CSMA/CD 的对比、隐蔽站/暴露站判断、RTS/CTS/NAV 的作用，以及 ACK 确认机制。复习时建议把“有线以太网 CSMA/CD”和“无线局域网 CSMA/CA”做成对比表，记住核心一句话：有线靠“检测”，无线靠“避免”。

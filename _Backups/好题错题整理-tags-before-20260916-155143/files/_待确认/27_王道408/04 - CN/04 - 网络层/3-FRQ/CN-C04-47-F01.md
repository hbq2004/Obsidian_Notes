# 综合题 第 1 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-47-F01_题目.png|题目]]

1. 某个单位的网点由 4 个子网组成，结构如下图所示，其中主机 $H1$、$H2$、$H3$ 和 $H4$ 的 $IP$ 地址和子网掩码见下表。

| 主机 | $IP$ 地址 | 子网掩码 |
|------|-------------|-------------|
| $H1$ | 202.99.98.18 | 255.255.255.240 |
| $H2$ | 202.99.98.35 | 255.255.255.240 |
| $H3$ | 202.99.98.51 | 255.255.255.240 |
| $H4$ | 202.99.98.66 | 255.255.255.240 |

【图：网络拓扑图，包含 4 个子网 Net1、Net2、Net3、Net4，路由器 R1、R2、R3，主机 H1、H2、H3、H4。各子网连接关系及 IP 地址标注如下：Net1 连接 H1 和 R1，IP 地址为 202.99.98.17；Net2 连接 H2 和 R1、R2，IP 地址为 202.99.98.33；Net3 连接 H3、R2、R3，IP 地址为 202.99.98.49；Net4 连接 H4 和 R3，IP 地址为 202.99.98.65。】

(1) 请写出路由器 $R1$ 到 4 个子网的路由表。

(2) 试描述主机 $H1$ 发送一个 $IP$ 数据报到主机 $H2$ 的过程（包括物理地址解析过程）.

## DeepSeek V4 Flash Max 解析

**答案**：

（1）$R1$ 到 4 个子网的路由表为：

| 目的网络 | 子网掩码 | 下一跳 | 出接口 |
|---|---|---|---|
| $202.99.98.16$ | $255.255.255.240$ | 直接交付 | $Net1$（$R1$ 接口 $202.99.98.17$） |
| $202.99.98.32$ | $255.255.255.240$ | 直接交付 | $Net2$（$R1$ 接口 $202.99.98.33$） |
| $202.99.98.48$ | $255.255.255.240$ | $202.99.98.34$（$R2$ 的 $Net2$ 接口） | $Net2$ |
| $202.99.98.64$ | $255.255.255.240$ | $202.99.98.34$（$R2$ 的 $Net2$ 接口） | $Net2$ |

注：若题图中未给出 $R2$ 在 $Net2$ 的接口地址，后两行的下一跳应写为“$R2$ 在 $Net2$ 的接口地址”；常见标注为 $202.99.98.34$。

一句话：$R1$ 直连 $Net1$、$Net2$；到 $Net3$、$Net4$ 都必须先交给 $R2$。

（2）$H1$ 发数据报到 $H2$ 时，$H1$ 发现 $H2$ 和自己不在同一子网，因此先把 IP 数据报发给默认网关 $R1$。$H1$ 用 ARP 解析 $R1$ 在 $Net1$ 接口的 MAC 地址，封装成帧发给 $R1$；$R1$ 查路由表发现 $H2$ 在直连子网 $Net2$ 上，再用 ARP 解析 $H2$ 的 MAC 地址，重新封装成帧发给 $H2$。整个过程中 IP 源地址和目的地址不变，MAC 地址逐跳改变。

**解题切入点**：

拿到题先做“地址定界”：每个主机 IP 与子网掩码相与，得到子网网络地址。这就像算法题里先算 `x & mask` 确定数据属于哪个桶，子网划分本质上就是按掩码分桶。

然后画拓扑、标接口 IP，区分“直连路由”和“间接路由”。直连路由下一跳为空；间接路由的下一跳必须是当前路由器直连网络上的相邻路由器接口，不能跨网络乱指。这类似图算法中只记录“下一跳”，而不是记录完整路径。

第二问是典型“分层分治”：网络层负责端到端 IP 寻址，链路层用 ARP 解决相邻一跳的 MAC 解析。不要把网络层和链路层混在一起。

**推演**：

子网掩码 $255.255.255.240$ 等价于前缀 $/28$，每个子网有 $2^{32-28}=16$ 个地址。

将主机 IP 与掩码逐位相与：

$$
\begin{aligned}
&202.99.98.18 \land 255.255.255.240 = 202.99.98.16,\\
&202.99.98.35 \land 255.255.255.240 = 202.99.98.32,\\
&202.99.98.51 \land 255.255.255.240 = 202.99.98.48,\\
&202.99.98.66 \land 255.255.255.240 = 202.99.98.64.
\end{aligned}
$$

所以：

- $Net1$：$202.99.98.16/28$，可用地址 $202.99.98.17 \sim 202.99.98.30$；
- $Net2$：$202.99.98.32/28$，可用地址 $202.99.98.33 \sim 202.99.98.46$；
- $Net3$：$202.99.98.48/28$，可用地址 $202.99.98.49 \sim 202.99.98.62$；
- $Net4$：$202.99.98.64/28$，可用地址 $202.99.98.65 \sim 202.99.98.78$。

$R1$ 直接连接 $Net1$ 和 $Net2$，所以到这两个子网是直连路由。  
$R1$ 与 $Net3$、$Net4$ 不直接相连，必须先发给 $R2$。由于 $R1$ 只和 $R2$ 在 $Net2$ 上直连，因此下一跳必须是 $R2$ 在 $Net2$ 上的接口地址，出接口为 $Net2$。

因此 $R1$ 的路由表如“答案”中所示。

下面分析 $H1 \to H2$ 的过程：

1. $H1$ 用子网掩码与 $H2$ 的 IP 相与：
   $$
   202.99.98.35 \land 255.255.255.240 = 202.99.98.32
   $$
   而 $H1$ 自己所在网络是 $202.99.98.16$，二者不同，所以 $H1$ 不能直接把帧发给 $H2$，必须交给默认网关 $R1$。

2. $H1$ 的默认网关是 $R1$ 在 $Net1$ 的接口 $202.99.98.17$。$H1$ 需要知道 $R1$ 的 MAC 地址，于是：
   - 若 ARP 缓存中没有 $202.99.98.17$ 对应的 MAC，$H1$ 在 $Net1$ 上广播 ARP 请求；
   - 请求内容是：“$202.99.98.17$ 的 MAC 地址是什么？”
   - $R1$ 收到后发现自己对应这个 IP，就单播回复自己的 MAC 地址。

3. $H1$ 封装以太网帧：
   - 目的 MAC：$R1$ 在 $Net1$ 接口的 MAC；
   - 源 MAC：$H1$ 的 MAC；
   - IP 数据报中：源 IP 为 $202.99.98.18$，目的 IP 为 $202.99.98.35$。

4. $R1$ 收到帧后去掉帧头，取出 IP 数据报，查路由表：
   - 目的 IP $202.99.98.35$ 匹配 $202.99.98.32/28$，且该网络是 $R1$ 直连的 $Net2$，所以 $R1$ 直接转发给 $H2$，不需要再发给 $R2$。

5. $R1$ 在 $Net2$ 上解析 $H2$ 的 MAC：
   - $R1$ 广播 ARP 请求：“$202.99.98.35$ 的 MAC 地址是什么？”
   - $H2$ 发现目标 IP 是自己，就单播回复自己的 MAC 地址。

6. $R1$ 重新封装帧：
   - 目的 MAC：$H2$ 的 MAC；
   - 源 MAC：$R1$ 在 $Net2$ 接口的 MAC；
   - IP 数据报的源 IP、目的 IP 不变，$R1$ 转发时 TTL 减 1，IP 头校验和重新计算。

7. $H2$ 收到帧后，发现目的 MAC 是自己，去掉帧头，交给 IP 层，发现目的 IP 也是自己，再上交上层协议。

**易错点**：

- 把主机 IP 当成网络地址。路由表中的“目的网络”必须是子网网络地址，不能填 $202.99.98.17$、$202.99.98.35$ 等主机地址。
- 把 /28 的块大小算错。$255.255.255.240$ 不是 $16$ 台主机，而是 $16$ 个地址，其中可用主机地址只有 $14$ 个。
- 下一跳选错。$R1$ 到 $Net3$、$Net4$ 的下一跳必须是 $R2$ 在 $Net2$ 上的接口地址，不能写成 $R2$ 在 $Net3$ 上的接口地址，也不能写成 $R3$ 的接口地址。
- 在 $H1 \to H2$ 过程中，$H1$ 不应该去 ARP 解析 $H2$ 的 MAC。因为 $H2$ 不在 $H1$ 所在子网，ARP 请求不能跨路由器。
- 认为 MAC 地址端到端不变。实际上每经过一个路由器，源 MAC 和目的 MAC 都会重新封装；IP 地址才保持不变。

**命题规律**：

这道题综合考查子网划分、路由表构造、IP 分组转发和 ARP 协议，是 408 计算机网络的重点综合题型。

常见变式有：

- 给出一组主机 IP 和掩码，要求写出某路由器到各子网的路由表；
- 要求说明某个主机跨网段通信时 ARP 请求的目标 IP 和 MAC 地址；
- 结合路由聚合、最长前缀匹配、默认路由出题；
- 把路径变长，例如 $H1 \to H4$，要求描述经过多个路由器时的封装变化。

复习建议：熟练掌握“IP 与掩码相与求网络地址”、直连路由与间接路由的区别、ARP 请求广播/应答单播、以及“IP 地址端到端不变，MAC 地址逐跳改变”这一核心结论。

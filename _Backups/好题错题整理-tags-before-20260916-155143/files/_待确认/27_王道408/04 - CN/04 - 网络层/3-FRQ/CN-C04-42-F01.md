# 综合题 第 1 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-42-F01_题目.png|题目]]

1.一个数据报长度为 $4000\mathrm{B}$（首部长度固定为 $20\mathrm{B}$）。现经过一个网络传送，但此网络能够传送的最大数据长度为 $1500\mathrm{B}$。IP 分片时，首部长度不变。试问应当划分为几个短一些的数据报片?各数据报片的数据字段长度、片段偏移字段和 MF 标志应为何值？

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-42-F01_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：划分为 3 个数据报片。各数据报片的数据字段长度、片段偏移字段和 MF 标志值分别为：  
- 第 1 片：数据长度 $1480\ \mathrm{B}$，偏移 $0$，MF $=1$；  
- 第 2 片：数据长度 $1480\ \mathrm{B}$，偏移 $185$，MF $=1$；  
- 第 3 片：数据长度 $1020\ \mathrm{B}$，偏移 $370$，MF $=0$。  

**解题切入点**：  
先抓关键数据：总长度 $4000\ \mathrm{B}$（首部 $20\ \mathrm{B}$）、MTU $=1500\ \mathrm{B}$。核心是 IP 分片规则：每片数据长度必须是 $8\ \mathrm{B}$ 的倍数（除最后一片），每片都带 $20\ \mathrm{B}$ 首部。这类似于算法竞赛中按固定块大小（块大小 $=$ MTU $-$ 首部）切割数组，并注意对齐边界。

**推演**：  
1. 原始数据报的数据部分长度：  
   $$4000\ \mathrm{B} - 20\ \mathrm{B} = 3980\ \mathrm{B}$$  
2. 每片最大数据长度（受 MTU 限制）：  
   $$1500\ \mathrm{B} - 20\ \mathrm{B} = 1480\ \mathrm{B}$$  
   且 $1480$ 是 $8$ 的倍数（$1480 / 8 = 185$），满足对齐要求。  
3. 分片数：  
   $$\left\lceil \frac{3980}{1480} \right\rceil = \lceil 2.689\ldots \rceil = 3$$  
4. 各片数据字段长度：  
   - 第 1 片：$1480\ \mathrm{B}$  
   - 第 2 片：$1480\ \mathrm{B}$  
   - 第 3 片：$3980 - 1480 \times 2 = 1020\ \mathrm{B}$（最后一片，不必是 $8$ 的倍数）  
5. 片段偏移字段（以 $8\ \mathrm{B}$ 为单位）：  
   - 第 1 片：$0$  
   - 第 2 片：$1480 / 8 = 185$  
   - 第 3 片：$(1480 + 1480) / 8 = 2960 / 8 = 370$  
6. MF 标志：  
   - 第 1、2 片：MF $=1$（后面还有分片）  
   - 第 3 片：MF $=0$（最后一片）  

**易错点**：  
- 忘记减掉首部长度，直接使用 $4000$ 作为数据长度。  
- 未检查数据长度是否为 $8$ 的倍数（前几片必须对齐，最后一片允许任意）。  
- 偏移量计算错误，误将总长度或总偏移直接填入，忘记除以 $8$。  
- MF 标志设置颠倒，最后一片误设为 $1$。  

**命题规律**：  
IP 分片是 408 计算机网络必考知识点，常结合 MTU、标志位（DF、MF）和偏移量计算。变式包括：给定分片结果求原始数据报长度、判断是否允许分片（DF 标志）、或考虑 IP 选项导致首部长度变化。复习时应熟练掌握分片规则，多做数值计算练习，注意单位换算和边界条件。

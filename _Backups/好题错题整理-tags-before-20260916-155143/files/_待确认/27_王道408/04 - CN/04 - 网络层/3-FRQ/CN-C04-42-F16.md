# 综合题 第 16 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-42-F16_题目.png|题目]]

16.【2020统考真题】某校园网有两个局域网,通过路由器 R1、R2 和 R3 互联后接入 Internet, S1 和 S2 为以太网交换机. 局域网采用静态 IP 地址配置,路由器部分接口以及各主机的 IP 地址如下图所示.

【图：网络拓扑图】Internet 云经 R1 接入；R1 顶部接口 203.10.2.1/30 连 Internet，左侧接口 203.10.2.2/30 连 R2，右侧接口 203.10.2.5/30 连 R3。R2 为 NAT，其局域网接口 192.168.1.1 连交换机 S1；S1 下接 Web服务器 192.168.1.2 和 H1 192.168.1.3。R3 为 NAT，其局域网接口 192.168.1.1 连交换机 S2；S2 下接 H2 192.168.1.2 和 H3 192.168.1.3。R2 与 R1 之间为 203.10.2.2/30，R3 与 R1 之间为 203.10.2.6/30。

假设 NAT 转换表结构为:

| 外网 |  | 内网 |  |
| IP 地址 | 端口号 | IP 地址 | 端口号 |
| | | | |

(1) 为使 H2 和 H3 能够访问 Web 服务器(使用默认端口号),需要进行什么配置?

(2) 若 H2 主动访问 Web 服务器时, 将 HTTP 请求报文封装到 IP 数据报 $P$ 中发送, 则 H2 发送的 $P$ 的源 IP 地址和目的 IP 地址分别是什么? 经过 R3 转发后, $P$ 的源 IP 地址和目的 IP 地址分别是什么? 经过 R2 转发后, $P$ 的源 IP 地址和目的 IP 地址分别是什么?

## DeepSeek V4 Flash Max 解析

**答案**：

（1）需要在 R2 上配置静态 NAT/端口映射，使外网地址端口 $203.10.2.2:80$ 映射到 Web 服务器 $192.168.1.2:80$，即：

$$(203.10.2.2,\ 80) \leftrightarrow (192.168.1.2,\ 80)$$

H2、H3 应通过 `http://203.10.2.2` 访问 Web 服务器，默认端口为 80。同时，R3 需要对 H2/H3 发出的数据报做源 NAT，把源 IP 改为 R3 的外网接口地址 $203.10.2.6$。

（2）H2 主动访问 Web 服务器时，IP 数据报 $P$ 的源/目的 IP 变化如下：

| 位置 | 源 IP 地址 | 目的 IP 地址 |
|---|---|---|
| H2 发送时 | $192.168.1.2$ | $203.10.2.2$ |
| 经过 R3 转发后 | $203.10.2.6$ | $203.10.2.2$ |
| 经过 R2 转发后 | $203.10.2.6$ | $192.168.1.2$ |

---

**解题切入点**：

这题的核心考点是 **NAT/NAPT 与私有地址重叠**。可以把两个局域网看成两个“命名空间”，里面都有 `192.168.1.2` 这个“同名变量”。H2 和 Web 服务器恰好同名，所以 H2 不能直接拿 `192.168.1.2` 去访问服务器，否则要么访问的是自己，要么会被同网段的 ARP 误导。

这种问题类似算法竞赛里“给冲突数据加上一层映射/哈希表”：  
R2 做的是“目的地址映射”，把对外地址 $203.10.2.2:80$ 映射到内部 Web 服务器；R3 做的是“源地址映射”，把 H2/H3 的私有源地址隐藏成自己的公网接口地址。

---

**推演**：

1. Web 服务器的真实地址是局域网中的 $192.168.1.2$，但 H2 自己也叫 $192.168.1.2$，所以 H2 无法直接用该地址访问 Web 服务器；H3 如果用 `192.168.1.2` 访问，也会被 ARP 解析到 H2，而不是 Web 服务器。

2. 因此，Web 服务器对外只能通过 R2 的公网接口地址 $203.10.2.2$ 提供服务。HTTP 默认端口号为 80，所以 R2 需要配置静态端口映射：

$$203.10.2.2:80 \longrightarrow 192.168.1.2:80$$

3. H2 发送 HTTP 请求时，目的 IP 必须写 $203.10.2.2$。H2 发现目的地址不在本网段，于是把数据报交给默认网关 R3。

   H2 发出的 IP 数据报：

$$\text{源 IP}=192.168.1.2,\quad \text{目的 IP}=203.10.2.2$$

4. R3 是 NAT 路由器，它把来自 H2 的私有源地址转换为自己的外网接口地址：

$$\text{源 IP}=203.10.2.6,\quad \text{目的 IP}=203.10.2.2$$

5. 数据报经 R1 路由到 R2。R2 收到目的地址为 $203.10.2.2:80$ 的数据报后，根据 NAT 表把目的地址改写为 Web 服务器 $192.168.1.2$，源地址保持不变：

$$\text{源 IP}=203.10.2.6,\quad \text{目的 IP}=192.168.1.2$$

6. 回程时，Web 服务器先发给 $203.10.2.6$；R2 反向把源地址改写为 $203.10.2.2$；R3 再反向把目的地址改写为 H2 的 $192.168.1.2$。这样 H2 看到的连接对端就是 $203.10.2.2:80$。

---

**易错点**：

1. **目的地址搞成 Web 服务器的私有地址**  
   容易误写为“H2 发送给 $192.168.1.2$”。但 H2 自己就是 $192.168.1.2$，H3 发往 $192.168.1.2$ 也会被 ARP 解析到 H2，无法到达 Web 服务器。

2. **R3 的方向弄反**  
   R3 是源 NAT，负责把 H2/H3 的私有源 IP 改成 $203.10.2.6$；R2 是目的 NAT/端口映射，负责把目的 IP 从 $203.10.2.2$ 改成 $192.168.1.2$。

3. **误以为经过 R2 后源 IP 变成 $203.10.2.2$**  
   在请求方向上，R2 只改目的地址，源地址仍是 R3 的外网地址 $203.10.2.6$。$203.10.2.2$ 是在回程时 R2 才作为源地址出现的。

4. **忘记默认端口号 80**  
   HTTP 默认端口是 80；R2 的 NAT 表必须把外网端口 80 映射到内网端口 80。

---

**命题规律**：

这是网络层 NAT 的经典考法，常结合私有地址重叠、静态 NAT/NAPT、HTTP 默认端口一起考查。变式可能包括：

- 给出 NAT 表，要求补全端口映射；
- 考查回程路径的源/目的 IP；
- 考查普通 NAT 与 NAPT 的区别；
- 结合 ARP、交换机、默认网关考查数据报的封装与转发。

复习时建议重点掌握：  
NAT 只修改 IP 地址（NAPT 还修改端口号）；  
方向判断要看“内网主动访问外网”还是“外网主动访问内网服务器”；  
端口映射是静态配置，普通 NAT 是动态转换。

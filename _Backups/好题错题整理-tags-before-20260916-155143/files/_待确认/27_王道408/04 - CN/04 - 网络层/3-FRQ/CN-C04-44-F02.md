# 综合题 第 2 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-44-F02_题目.png|题目]]

2. P206在某个使用 RIP 的网络中, B 和 C 互为相邻路由器,其中表 1 为 B 的原路由表,表 2 为 C 广播的距离向量报文 \<目的网络,距离\>。

表 1

| 目的网络 | 距 离 | 下 一 跳 |
| --- | --- | --- |
| N1 | 7 | A |
| N2 | 2 | C |
| N6 | 8 | F |
| N8 | 4 | E |
| N9 | 4 | D |

表 2

| 目的网络 | 距 离 |
| --- | --- |
| N2 | 15 |
| N3 | 2 |
| N4 | 8 |
| N8 | 2 |
| N7 | 4 |

(1) 试求路由器 B 更新后的路由表并说明主要步骤.

(2) 当路由器 B 收到发往网络 N2 的 IP 分组时,应该做何处理?

## 答案

## DeepSeek V4 Flash Max 解析

**答案**：  
（1）B 更新后的路由表为：

| 目的网络 | 距离 | 下一跳 | 说明 |
| --- | --- | --- | --- |
| N1 | 7 | A | C 未通告，不变 |
| N2 | 16 | C | 不可达，不能用于转发 |
| N3 | 3 | C | 新增 |
| N4 | 9 | C | 新增 |
| N6 | 8 | F | C 未通告，不变 |
| N7 | 5 | C | 新增 |
| N8 | 3 | C | 原为 4，下一跳 E；新路径更短，更新 |
| N9 | 4 | D | C 未通告，不变 |

其中距离 16 在 RIP 中表示“不可达/无穷大”。  
（2）B 收到发往网络 N2 的 IP 分组时，查路由表发现 N2 的距离为 16，即没有有效路由，因此不转发，丢弃该 IP 分组，通常还应向源主机发送 ICMP 目的网络不可达报文。

**解题切入点**：  
RIP 的更新本质就是分布式 Bellman-Ford 的“松弛”操作。C 广播距离向量后，B 应把 C 当作中转点，所以 B 经 C 到某网络的距离为“C 到该网络的距离 + 1”。这很像算法竞赛中跑最短路时，用邻居给的临时距离去松弛当前距离；但要注意：如果原路由的下一跳就是这个邻居，即使新距离变大也必须更新，否则会保留过时路由、造成环路。

**推演**：  
设 C 广播的目的网络为 $N$，距离为 $D_C(N)$。因为 B 和 C 相邻，所以 B 经 C 到 $N$ 的候选距离为：

$$
d_B(N)=D_C(N)+1
$$

C 广播的各项转换成 B 的候选表项如下：

| C 广播项 | B 经 C 的候选距离 |
| --- | --- |
| N2, 15 | N2, 16 |
| N3, 2 | N3, 3 |
| N4, 8 | N4, 9 |
| N8, 2 | N8, 3 |
| N7, 4 | N7, 5 |

RIP 合并规则为：

1. 若原路由表中没有该目的网络，且候选距离小于 16，则新增该表项；
2. 若原路由表中有该目的网络，且原下一跳就是 C，则无论候选距离变大还是变小，都用新距离替换；
3. 若原路由表中有该目的网络，但原下一跳不是 C，则只在候选距离更小时替换；
4. 距离 16 表示不可达。

逐项判断：

- N2：原表有 N2，且下一跳就是 C，所以必须更新为 $15+1=16$，不可达。
- N3：原表没有，新增，距离 $2+1=3$，下一跳 C。
- N4：原表没有，新增，距离 $8+1=9$，下一跳 C。
- N8：原表有 N8，下一跳是 E，距离 4；候选距离 $2+1=3<4$，更新为下一跳 C，距离 3。
- N7：原表没有，新增，距离 $4+1=5$，下一跳 C。

N1、N6、N9 未被 C 通告，因此保持不变。

所以更新后的路由表为：

| 目的网络 | 距离 | 下一跳 |
| --- | --- | --- |
| N1 | 7 | A |
| N2 | 16 | C |
| N3 | 3 | C |
| N4 | 9 | C |
| N6 | 8 | F |
| N7 | 5 | C |
| N8 | 3 | C |
| N9 | 4 | D |

N2 的距离为 16，表示不可达；若只列出有效路由，也可等价地不写 N2 这一项。

**易错点**：  
- 容易把 C 广播的 N2 距离 15 直接当成 B 到 N2 的距离，忘记必须加 1，得到 $15+1=16$。  
- 容易对 N2 使用“新距离更大就不更新”的规则，导致保留过时的距离 2。原表下一跳就是 C 时，必须无条件用新值更新。  
- 容易忽略 RIP 中 16 表示不可达，把 16 当成一个可用的普通跳数。  
- 对 N8 要注意原下一跳是 E，不是 C，所以需要比较 $3<4$ 后决定更新；对新增网络 N3、N4、N7 要记得距离加 1。

**命题规律**：  
本题是 RIP 协议的高频考点，核心考查距离向量更新算法、16 跳限制和不可达路由的处理。常见变式包括：给出相邻路由器的 RIP 报文，要求更新路由表；某网络故障后判断下一跳是否更新；把 RIP 与 OSPF、BGP 对比。复习时应重点掌握 RIP 的四条更新规则，并理解“下一跳相同必须更新、下一跳不同取更短”的原因，这对理解路由环路和毒性反转也很有帮助。

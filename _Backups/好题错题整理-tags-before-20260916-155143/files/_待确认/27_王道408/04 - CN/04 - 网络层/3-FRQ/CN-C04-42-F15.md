# 综合题 第 15 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-42-F15_题目.png|题目]]

15.【2018统考真题】某公司的网络如下图所示。IP 地址空间 192.168.1.0/24 均分给销售部和技术部两个子网，并已分别为部分主机和路由器接口分配了 IP 地址，销售部子网的 MTU=1500B，技术部子网的 MTU=800B。回答下列问题：

【图：左侧为销售部子网，已分配地址 192.168.1.1~192.168.1.20；中间为路由器，接口 F0 的 IP 为 192.168.1.126，MTU=1500B，接口 F1 的 IP 为 192.168.1.254，MTU=800B；右侧为技术部子网，已分配地址 192.168.1.129~192.168.1.208。】

(1) 销售部子网的广播地址是什么？技术部子网的子网地址是什么？若每台主机仅分配一个 IP 地址，则技术部子网还可以连接多少台主机？

(2) 假设主机 192.168.1.1 向主机 192.168.1.208 发送一个总长度为 1500B 的 IP 分组，IP 分组的首部长度为 20B，路由器在通过接口 F1 转发该 IP 分组时进行了分片。若分片时尽可能分为最大片，则一个最大 IP 分片封装数据的字节数是多少？至少需要分为几个分片？每个分片的片偏移量是多少？

## DeepSeek V4 Flash Max 解析

**答案**  
(1) 销售部子网广播地址：$192.168.1.127$；技术部子网子网地址：$192.168.1.128$；技术部子网还可连接 $45$ 台主机。  
(2) 一个最大 IP 分片封装数据的字节数为 $776$ B；至少需要 $2$ 个分片；第 $1$ 片偏移量为 $0$，第 $2$ 片偏移量为 $97$。

**解题切入点**  
题目考查子网划分与 IP 分片。先抓住“均分两个子网”定位子网掩码加 $1$ 位，再根据已分配地址确定具体子网。计算广播地址只需将主机位全置 $1$，子网地址则主机位全 $0$。可用主机数需排除子网地址和广播地址，并减去已占用的地址（包括路由器接口）。IP 分片问题中，MTU 限制导致数据部分需拆解，注意“尽可能分为最大片”要满足 $8$ 字节对齐，类似竞赛中按块大小对齐数据；片偏移相当于分块索引，单位是 $8$ 字节，计算时需用数据长度除以 $8$。可将子网看作内存分区，MTU 看作缓冲区上限，分片看作消息分块，偏移量看作块号。

**推演**  

(1) 原 $192.168.1.0/24$ 均分两个子网，则子网掩码变为 $/25$（即 $255.255.255.128$），每个子网包含 $2^{7}=128$ 个 IP 地址。子网 $1$：$192.168.1.0/25$（地址范围 $0\text{–}127$），子网 $2$：$192.168.1.128/25$（地址范围 $128\text{–}255$）。根据已分配地址，销售部主机 $1\text{–}20$ 及路由器接口 $126$ 均在 $0\text{–}127$，故销售部子网为 $192.168.1.0/25$，技术部子网为 $192.168.1.128/25$。

- 销售部子网广播地址：主机位全 $1$，即 $192.168.1.127$。  
- 技术部子网子网地址：主机位全 $0$，即 $192.168.1.128$。  
- 技术部子网可用主机地址数：$2^{7}-2=126$。已分配主机地址 $192.168.1.129\text{–}192.168.1.208$ 共 $80$ 个，路由器接口 $192.168.1.254$ 占用 $1$ 个，合计 $81$ 个。故还可连接 $126-81=45$ 台主机。

(2) 原始 IP 分组总长度 $1500$ B，首部 $20$ B，数据部分 $1480$ B。技术部子网 MTU=$800$ B，故分片时每个 IP 分片总长度不超过 $800$ B，首部 $20$ B，数据部分最大 $780$ B。但片偏移字段以 $8$ B 为单位，数据部分长度必须是 $8$ 的倍数，因此最大数据部分为 $8 \times \lfloor 780/8 \rfloor = 8 \times 97 = 776$ B。

需分片数：$\lceil 1480 / 776 \rceil = 2$ 片。

第 $1$ 片：数据 $776$ B，片偏移 $0$；  
第 $2$ 片：数据 $1480-776 = 704$ B，片偏移 $776/8 = 97$（片偏移以 $8$ B 为单位，故 $97$ 合法）。

**易错点**  
- 子网划分时，容易误以为均分后子网掩码仍为 $/24$，或混淆广播地址与子网地址。  
- 计算技术部子网剩余主机数时，容易忘记扣除路由器接口占用，或忽略已分配主机范围的具体个数（如 $129\text{–}208$ 是 $80$ 个而非 $208-129=79$）。  
- 分片时，直接取 $780$ B 作为最大数据长度，忽略 $8$ 字节对齐要求；片偏移计算时误用字节数直接作为偏移量，或忘记除以 $8$。  
- 分片数可能因误用 $780$ 而算得 $2$ 片，但实际 $780$ 不可用，需调整为 $776$，本例结果相同，但若数据长度不同可能出错。

**命题规律**  
本题是网络层核心考点：子网划分与 IP 分片。常见变式包括：不等长子网划分、不同 MTU 场景、分片后重组条件、标识字段与标志位（DF、MF）等。复习时需熟练掌握子网掩码、广播地址、主机数计算，以及 IP 分片机制（MTU、数据对齐、片偏移单位、标志位）。建议结合真题练习，特别注意 $8$ 字节对齐和片偏移的计算，并理解分片后路由器不重组，仅目的主机重组。

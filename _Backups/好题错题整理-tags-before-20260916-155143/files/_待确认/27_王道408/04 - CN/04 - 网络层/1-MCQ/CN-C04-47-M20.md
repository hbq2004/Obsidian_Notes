# 选择题 第 20 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-47-M20_题目.png|题目]]

20.【2012统考真题】下列关于 $IP$ 路由器功能的描述中,正确的是（ ）

I.运行路由协议,设备路由表

II.监测到拥塞时,合理丢弃 $IP$ 分组

III.对收到的 $IP$ 分组头进行差错检验,确保传输的 $IP$ 分组不丢失

IV.根据收到的 $IP$ 分组的目 的 $IP$ 地址,将其转发到合适的输出线路上

A. 仅 $III$、$IV$

B. 仅 $I$、$II$、$III$

C. 仅 $I$、$II$、$IV$

D. $I$、$II$、$III$、$IV$

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-47-M20_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：C。I、II、IV 正确，III 错误；路由器会对 IP 分组首部做差错检验，但 IP 是“尽力而为”服务，不能“确保传输的 IP 分组不丢失”。

**解题切入点**：拿到题先定位考点：路由器是网络层设备，核心功能只有两件事——路由选择（routing）和分组转发（forwarding）。I、IV 正好对应这两件事；II 对应拥塞时的丢包策略；III 要拆开看，“做差错检验”是真的，但“确保不丢失”是假的。这就像算法竞赛里先明确对象的数据结构：路由器不是可靠传输设备，不能保证端到端不丢包；分层协议的思想类似分治，各层只负责自己的职责，网络层尽力而为，可靠传输交给上层 TCP。

**推演**：
1. **I 正确**：路由器运行 RIP、OSPF、BGP 等路由协议，通过交换路由信息生成并更新路由表/转发表。  
2. **II 正确**：路由器可以监测网络拥塞状况，当拥塞发生时，通过尾丢弃、随机早期检测等策略合理丢弃部分 IP 分组，以缓解拥塞。  
3. **III 错误**：IPv4 路由器确实会对收到的 IP 分组首部进行校验，若校验失败则丢弃该分组。但 IP 本身是尽力而为服务，没有确认和重传机制，不可能“确保传输的 IP 分组不丢失”。可靠传输要由 TCP 等上层协议保证。  
4. **IV 正确**：路由器收到 IP 分组后，根据分组的目的 IP 地址查找路由表/转发表，确定下一跳和输出线路，将其转发出去。

因此正确的是 I、II、IV，选 C。

**易错点**：
- 只看 III 的前半句“对 IP 分组头进行差错检验”，忽略后半句“确保不丢失”，导致误判。实际上前半句是路由器确实会做的事，但后半句违背 IP 的尽力而为模型。  
- 把“首部差错检验”等同于“可靠传输”。IP 首部校验只能发现首部错误，不能纠错、不能重传；校验失败反而会丢弃分组，造成丢失。  
- 误以为拥塞控制只属于传输层，路由器不参与。实际上路由器可以通过队列管理和丢包策略参与网络层拥塞控制。  
- 混淆路由器与交换机的转发依据：路由器根据目的 IP 地址转发，交换机根据目的 MAC 地址转发。

**命题规律**：本题属于网络层“路由器功能”与“IP 服务模型”的结合考点，408 常见题型是判断式选择题。常见变式有：判断“IP 是否保证不丢失、不重复、按序到达”（都不保证）；比较路由器与交换机的功能；考查路由协议与路由表、转发表的关系；考查 IPv4 首部校验和等。复习时抓住分层思想：网络层负责路由选择与分组转发，提供尽力而为服务；可靠传输由传输层负责。

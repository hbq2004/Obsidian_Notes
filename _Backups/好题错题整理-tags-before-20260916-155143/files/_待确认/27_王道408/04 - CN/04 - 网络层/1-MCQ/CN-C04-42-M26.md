# 选择题 第 26 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-42-M26_题目.png|题目]]

26. 某网络的一台主机的 IP 地址是 200.15.10.6/29，其配置的默认网关地址是 200.15.10.7，这样配置后发现主机无法 *PING* 通任何远程设备，原因是 (    ).

A. 默认网关的地址不属于这个子网
B. 默认网关的地址是子网中的广播地址
C. 路由器接口的地址是子网的广播地址
D. 路由器接口的地址是多播地址

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-42-M26_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：B。因为 $200.15.10.6/29$ 所在子网的广播地址是 $200.15.10.7$，默认网关被配置成广播地址，无法正常转发数据。

**解题切入点**：拿到题目先盯住“IP/掩码”和“网关地址”，立即把 `/29` 转成块大小，确定网络地址和广播地址。这就像算法竞赛中给定数组下标和块大小，先算桶的左右边界，再判断元素是普通元素还是边界哨兵；这里广播地址就是“右哨兵”，不能当正常主机或网关使用。

**推演**：

- `/29` 表示网络前缀占 $29$ 位，主机位有 $32-29=3$ 位，因此子网内地址数为：
  $$2^3=8$$
- 子网掩码为：
  $$255.255.255.248$$
  因为最后一段是：
  $$11111000_2 = 248$$
- 主机 IP 为 $200.15.10.6$，只看最后一段 $6$：
  $$6 = 00000110_2$$
  与掩码最后一段 $248 = 11111000_2$ 按位与：
  $$00000110_2 \ \&\ 11111000_2 = 00000000_2 = 0$$
  所以网络地址为：
  $$200.15.10.0$$
- 广播地址 = 网络地址 $+$ 子网地址数 $-1$：
  $$200.15.10.0 + 7 = 200.15.10.7$$
- 可分配给主机的合法地址范围是：
  $$200.15.10.1 \sim 200.15.10.6$$

现在主机 IP 是 $200.15.10.6$，是合法主机地址；但默认网关 $200.15.10.7$ 是该子网的广播地址。主机要 PING 通远程设备，必须把 IP 数据报交给默认网关转发；可是网关地址是广播地址，不能作为路由器接口的单播地址使用，主机也无法通过 ARP 正常解析到该网关的 MAC 地址，因此无法通信。

**易错点**：

- 误以为 $200.15.10.7$ 不属于该子网：实际上它和 $200.15.10.6$ 同在 $200.15.10.0/29$ 子网内，但它是广播地址。
- 混淆网络地址和广播地址：本子网网络地址是 $.0$，广播地址是 $.7$。
- 选 C 时要注意：如果路由器接口地址真是 $.7$，那确实也是广播地址，但题干直接描述的是“主机配置的默认网关地址为 $.7$”，更准确的原因是默认网关地址是广播地址；路由器接口本就不应配置成广播地址。
- 计算可用主机数时不要忘记减 $2$：
  $$2^3 - 2 = 6$$
  即 $200.15.10.1 \sim 200.15.10.6$。

**命题规律**：考查 IPv4 子网划分与特殊地址的识别，尤其是网络地址、广播地址、可用主机范围。常见变式有：给 IP/前缀求网络地址和广播地址；判断某地址能否作为主机 IP；判断默认网关配置是否合法。复习时要熟练掌握“前缀长度 → 子网块大小 → 网络地址/广播地址”的快速计算方法，并记住：默认网关必须是本子网内一个可用的单播主机地址。

# 选择题 第 41 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-42-M41_题目.png|题目]]

41. 位于不同子网中的主机之间相互通信时,下列说法中正确的是( )

(A) 路由器在转发IP数据报时,重新封装源硬件地址和目的硬件地址.

(B) 路由器在转发IP数据报时,重新封装源IP地址和目的IP地址.

(C) 路由器在转发IP数据报时,重新封装目的硬件地址和目的IP地址.

(D) 源站点可以直接进行ARP广播得到目的站点的硬件地址.

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-42-M41_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：A。不同子网的主机通信必须经过路由器，路由器在转发 IP 数据报时，会重新封装“源 MAC 地址和目的 MAC 地址”，但源/目的 IP 地址不变；ARP 广播不能跨子网获得目的主机的硬件地址。

**解题切入点**：拿到题先抓“不同子网”和“路由器转发”这两个关键词，考点立即定位到“IP 转发过程中的封装变化”和“ARP 的作用范围”。这可以类比算法竞赛里的分治思想：网络分层是分治，每层只负责自己的接口；路由器相当于一个“合并点/中转节点”，它只修改当前链路上的“指针”（MAC 地址），不修改数据里的“关键字”（IP 地址）。ARP 则像本地哈希表查询，只能查当前局部的映射，不能跨节点直接查到远端信息。

**推演**：

设主机 A 与主机 B 位于不同子网。A 要发送 IP 数据报到 B，过程如下：

1. A 用目的 IP 地址和子网掩码判断出 B 不在同一子网，所以 A 不能直接把帧发给 B，而是把数据报发往默认网关，即路由器 $R$。

2. A 需要知道 $R$ 在 A 所在子网的 MAC 地址。A 发送 ARP 广播请求“谁的 IP 是 $R$ 的接口 IP？”。注意：ARP 请求是数据链路层广播帧，路由器不会把这种广播帧转发到其他子网。因此，A 不可能直接通过 ARP 获得 B 的 MAC 地址。故选项 D 错误。

3. A 构造发送给 $R$ 的帧：
   $$
   \text{帧头}：\text{源MAC}=A,\quad \text{目的MAC}=R
   $$
   $$
   \text{IP 数据报}：\text{源IP}=A,\quad \text{目的IP}=B
   $$

4. 路由器 $R$ 收到帧后，拆掉帧头，取出 IP 数据报，根据目的 IP 地址 $B$ 查路由表，确定下一跳或出接口。如果下一跳仍是路由器，则 $R$ 再把 IP 数据报封装到新帧中，新的帧头为：
   $$
   \text{源MAC}=R\text{ 的出口接口 MAC},\quad \text{目的MAC}=下一跳路由器接口 MAC
   $$
   如果 $R$ 直接连接 B 所在的子网，则目的 MAC 就是 B 的 MAC：
   $$
   \text{源MAC}=R,\quad \text{目的MAC}=B
   $$

5. 在整个转发过程中，IP 数据报中的源 IP 地址 $A$ 和目的 IP 地址 $B$ 始终不变（在不涉及 NAT 的情况下）。故选项 B 错误。

6. 选项 C 说“重新封装目的硬件地址和目的 IP 地址”，错误在于：目的硬件地址会随链路变化，但目的 IP 地址不会被路由器改写。故 C 错误。

因此，路由器在转发 IP 数据报时，真正被重新封装的是源硬件地址和目的硬件地址，即选项 A 正确。

**易错点**：

- 混淆 MAC 地址和 IP 地址：IP 地址是全球逻辑地址，跨网络不变；MAC 地址是链路层物理地址，只在当前局域网内有意义，因此每跳都要重新封装。
- 认为 ARP 广播是 IP 层广播，可以跨路由器传播。实际上 ARP 工作在数据链路层，广播帧只能在本广播域内传播，路由器隔离广播域。
- 忽略“默认网关”概念：A 要发给不同子网的主机时，目的 MAC 应该是路由器的 MAC，而不是目的主机的 MAC。
- 误以为路由器会修改源/目的 IP 地址。除非题目明确说明 NAT 等场景，否则基本 IP 转发中 IP 地址不变。
- 选项 C 的错误要抓稳：MAC 地址确实每跳会变，但 IP 地址不变，不能把两者捆在一起说“重新封装”。

**命题规律**：这是 408 计算机网络中“网络层”和“数据链路层”交界处的经典考点，常考形式有：ARP 请求是否跨网络、路由器转发时改哪些地址、同一子网与不同子网通信时目的 MAC 分别是什么。复习时应以分层模型为主线，理解“IP 数据报不变，帧不断被重新封装”的核心思想，并熟练区分“源/目的 IP”和“源/目的 MAC”的变化时机。变式题常结合 NAT、VLAN、IPv6 邻居发现等概念，但底层判断逻辑相同。

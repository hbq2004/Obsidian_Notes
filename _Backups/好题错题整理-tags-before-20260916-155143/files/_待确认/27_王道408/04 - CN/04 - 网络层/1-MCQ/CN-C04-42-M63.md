# 选择题 第 63 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-42-M63_题目.png|题目]]

63.【2018统考真题】路由器 R 通过以太网交换机 S1 和 S2 连接两个网络, R 的接口、主机 H1 和 H2 的 IP 地址与 MAC 地址如下图所示。若 H1 向 H2 发送一个 IP 分组 P, 则 H1 发出的封装 P 的以太网帧的目的 MAC 地址、H2 收到的封装 P 的以太网帧的源 MAC 地址分别是 ( )

【图：网络拓扑图。左侧为交换机 S1，连接主机 H1 和路由器 R 的左侧接口；右侧为交换机 S2，连接路由器 R 的右侧接口和主机 H2。图中标注：H1 的 IP 为 192.168.3.2，MAC 为 00-1a-2b-3c-4d-52；H2 的 IP 为 192.168.4.2，MAC 为 00-a1-b2-c3-d4-62；R 左侧接口 IP 为 192.168.3.1，MAC 为 00-1a-2b-3c-4d-51；R 右侧接口 IP 为 192.168.4.1，MAC 为 00-a1-b2-c3-d4-61。】

A. 00-a1-b2-c3-d4-62、00-1a-2b-3c-4d-52

B. 00-a1-b2-c3-d4-62、00-a1-b2-c3-d4-61

C. 00-1a-2b-3c-4d-51、00-1a-2b-3c-4d-52

D. 00-1a-2b-3c-4d-51、00-a1-b2-c3-d4-61

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-42-M63_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：D。H1 与 H2 不在同一网络，H1 发出的以太网帧应先发送给默认网关 R 的左侧接口；R 再转发给 H2 时会重新封装以太网帧，因此 H2 收到帧的源 MAC 是 R 的右侧接口。所以答案依次为 $00\text{-}1a\text{-}2b\text{-}3c\text{-}4d\text{-}51$、$00\text{-}a1\text{-}b2\text{-}c3\text{-}d4\text{-}61$。

**解题切入点**：拿到题先判断“源、目的 IP 是否在同一网络”。若不在同一网络，则不能直接把帧发给目的主机，而要先发给默认网关（路由器接口）。这类似于算法竞赛中在图上转发消息：IP 地址是全局的“目标编号”，MAC 地址只是当前这一段链路上的“下一跳指针”，每次经过路由器都要重新绑定指针，而不是修改全局目标。

**推演**：

图中两个网络可看作：

$$
N_1=192.168.3.0/24,\qquad N_2=192.168.4.0/24
$$

H1 的 IP 是 $192.168.3.2$，H2 的 IP 是 $192.168.4.2$，二者不在同一网段。

H1 构造 IP 分组 $P$ 后，IP 层给出的源、目的 IP 为：

$$
\text{源IP}=192.168.3.2,\qquad \text{目的IP}=192.168.4.2
$$

但 H1 不能直接把以太网帧的目的 MAC 写成 H2 的 MAC，因为 H2 不在 H1 所在局域网中。H1 必须把帧发给默认网关 R 的左侧接口 $192.168.3.1$，对应 MAC 为 $00\text{-}1a\text{-}2b\text{-}3c\text{-}4d\text{-}51$。

所以：

| 位置 | 目的 MAC | 源 MAC |
|---|---|---|
| H1 发出的帧 | R 左侧接口 | H1 |
| R 转发给 H2 的帧 | H2 | R 右侧接口 |

R 收到 H1 的帧后，剥离以太网帧头，看到目的 IP 为 $192.168.4.2$，发现该地址在自己的直连网络 $192.168.4.0/24$ 中，于是从右侧接口重新封装以太网帧发送给 H2。此时源 MAC 必须是 R 右侧接口的 MAC：

$$
00\text{-}a1\text{-}b2\text{-}c3\text{-}d4\text{-}61
$$

而目的 MAC 是 H2 的 MAC：

$$
00\text{-}a1\text{-}b2\text{-}c3\text{-}d4\text{-}62
$$

因此选 D。

**易错点**：

1. 把 H1 发出帧的目的 MAC 误认为 H2 的 MAC。H1 与 H2 不在同一 IP 网络，不能直接跨网段在数据链路层发送，必须先经路由器转发。
2. 把 H2 收到帧的源 MAC 误认为 H1 的 MAC。MAC 地址是逐跳变化的，路由器会剥离旧帧头并重新封装，所以 H2 收到帧的源 MAC 是 R 的出口接口，而不是原始主机 H1。
3. 混淆交换机与路由器的行为：以太网交换机不修改帧，路由器才负责跨网络转发并改写 MAC 地址。

**命题规律**：本题核心考点是“IP 地址端到端不变，MAC 地址逐跳变化”，以及默认网关的作用。常见变式有：反向考查 H2 向 H1 发送时的 MAC 地址；考查 ARP 解析过程；考查经过路由器后 IP 分组中源、目的 IP 是否改变。复习时应画清每一跳的帧头变化，牢记“路由器隔离广播域并重新封装数据链路层帧”。

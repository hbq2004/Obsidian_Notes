# 选择题 第 59 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-42-M59_题目.png|题目]]

59.【2016统考真题】在上题的图中,假设连接 R1、R2 和 R3 之间的点对点链路使用地址 201.1.3.x/30, 当 H3 访问 Web 服务器 S 时, R2 转发出去的封装 HTTP 请求报文的 IP 分组是源 IP 地址和目的 IP 地址, 它们分别是 ( )

(A) 192.168.3.251、130.18.10.1  
(B) 192.168.3.251、201.1.3.9  
(C) 201.1.3.8、130.18.10.1  
(D) 201.1.3.10、130.18.10.1

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-42-M59_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：D。R2 是 NAT 边界路由器，转发出去时把源 IP 从 H3 的私网地址 $192.168.3.251$ 改写为 R2 出口链路上的公网地址 $201.1.3.10$，目的 IP 保持 Web 服务器 S 的地址 $130.18.10.1$ 不变。

**解题切入点**：  
先抓住“数据流的观察点”。本题问的是“R2 转发出去”的 IP 分组，而不是“H3 刚发出时”的 IP 分组。这就像算法题里不能把初始状态当作某一中间状态；R2 是 NAT 边界，是源 IP 发生“状态转换”的位置。定位考点为：NAT 地址转换、IP 分组端到端寻址、$/30$ 子网划分。可以把 NAT 理解为一个“哈希映射”：内部私网地址映射为外部公网地址，目的地址则像全局变量一样不变。

**推演**：

1. H3 构造 HTTP 请求时，原始 IP 分组中：
   - 源 IP 是 H3 的地址：$192.168.3.251$
   - 目的 IP 是 Web 服务器 S 的地址：$130.18.10.1$

2. H3 所在网络是私网，$192.168.3.251$ 不能在公网中直接路由，所以 R2 作为 NAT 路由器，在转发出去时会把源 IP 改写为 R2 出口接口的公网地址。

3. 由题图/上题条件可知，R2 出口所在链路为 $201.1.3.8/30$。该子网地址范围是：

$$
201.1.3.8 \sim 201.1.3.11
$$

其中：
- $201.1.3.8$ 是网络地址，不能用作接口 IP；
- $201.1.3.11$ 是广播地址；
- 可用主机地址只有 $201.1.3.9$ 和 $201.1.3.10$。

题图中 R2 在该链路上的接口地址为 $201.1.3.10$，因此 R2 转发出去的 IP 分组源 IP 被改写为：

$$
201.1.3.10
$$

4. NAT 只改变源 IP，不改变本次请求的目的 IP。目的地址始终是 Web 服务器 S 的地址：

$$
130.18.10.1
$$

因此答案为 D：源 IP 为 $201.1.3.10$，目的 IP 为 $130.18.10.1$。

**易错点**：  
- 容易选 A，把 H3 刚发出时的源 IP $192.168.3.251$ 当成 R2 转发后的源 IP，忽略了 NAT 改写。  
- 容易选 B，把下一跳路由器接口地址 $201.1.3.9$ 当成目的 IP。注意：IP 分组的目的 IP 是端到端的主机地址 S，不是下一跳路由器接口地址。  
- 容易选 C，把 $201.1.3.8$ 当作可用地址。但在 $/30$ 子网中，$201.1.3.8$ 是网络地址，不可分配给接口使用。  
- 应对方法：先画出路径，标出 NAT 转换点；再检查 $/30$ 子网的可用地址范围；最后区分“源/目的 IP”和“下一跳 IP”。

**命题规律**：  
本题综合考查 NAT 和 IP 地址划分，是 408 计算机网络常考的“地址转换 + 分组的端到端寻址”问题。常见变式有：问 R3 继续转发时的源 IP/目的 IP；问 NAT 表项；问响应报文从 S 返回 H3 时 R2 如何转换源/目的地址；或者把 $/30$ 改成 $/29$、$/28$ 等。复习时应重点掌握 NAT/NAPT 的原理，明确“普通路由器不改变源/目的 IP，NAT 路由器会改写地址；目的 IP 始终是端到端目的主机地址，下一跳地址只用于路由与封装”。

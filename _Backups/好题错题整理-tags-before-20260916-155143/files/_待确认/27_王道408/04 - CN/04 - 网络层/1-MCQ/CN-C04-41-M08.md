# 选择题 第 8 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-41-M08_题目.png|题目]]

8. 下列协议中,属于网络层协议的是( )

$I$. IP\qquad $II$. TCP\qquad $III$. FTP\qquad $IV$. ICMP

(A) $I$ 和 $II$
(B) $II$ 和 $III$
(C) $III$ 和 $IV$
(D) $I$ 和 $IV$

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-41-M08_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：D；IP 和 ICMP 是网络层协议，TCP 和 FTP 分别属于传输层和应用层。

**解题切入点**：拿到题目先识别每个协议在 TCP/IP 协议栈中的层次归属，快速定位考点为“网络层协议识别”。可以类比算法竞赛中的“分治策略”——网络层相当于分治中的“合并”阶段，负责数据包的路由与转发；IP 和 ICMP 如同分治中的“合并”函数，而 TCP（传输层）和 FTP（应用层）则对应分治中的不同子模块，各司其职。

**推演**：
- IP（$I$）：Internet Protocol，核心网络层协议，负责数据包的路由和转发，属于网络层。
- TCP（$II$）：Transmission Control Protocol，传输层协议，提供可靠的面向连接的数据传输服务。
- FTP（$III$）：File Transfer Protocol，应用层协议，用于文件传输。
- ICMP（$IV$）：Internet Control Message Protocol，虽封装在 IP 数据报中，但其功能是网络层辅助协议（错误报告、诊断等），故归为网络层。  
  因此，属于网络层协议的是 $I$ 和 $IV$，对应选项 D。

**易错点**：
- 误认为 ICMP 是传输层协议（因为其报文封装在 IP 中，但功能属于网络层辅助）。
- 混淆 IP 与 TCP 的层次（TCP 是传输层，IP 是网络层）。
- 忽略 FTP 明显属于应用层，可能误将其归为传输层。  
  规避方法：熟记 TCP/IP 协议栈各层典型协议，建立清晰的层次映射。

**命题规律**：  
- 考点：网络层协议识别，常与传输层、应用层协议混合考查。  
- 常见变式：加入 ARP、RARP、IGMP、OSPF 等网络层协议，或要求区分不同层次。  
- 复习建议：掌握 TCP/IP 协议栈各层核心协议（如网络层的 IP、ICMP、ARP、IGMP；传输层的 TCP、UDP；应用层的 HTTP、FTP、DNS 等），并理解其封装关系。

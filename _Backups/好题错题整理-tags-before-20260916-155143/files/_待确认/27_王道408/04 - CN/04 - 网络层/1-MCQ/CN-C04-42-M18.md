# 选择题 第 18 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-42-M18_题目.png|题目]]

18. $IP$ 规定，一些特殊的 $IP$ 地址一般是不会被指派的，下列说法错误的是（ ）

A. 0.0.0.0 可以作为 $DHCP$ 客户的源 $IP$ 地址

B. 路由器不会转发目的 $IP$ 地址是 255.255.255.255 的 $IP$ 数据报

C. 127.0.0.1 可以作为目的 $IP$ 地址，但不能作为源 $IP$ 地址

D. 路由器可以转发目的 $IP$ 地址的主机号为全 1 的 $IP$ 数据报

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-42-M18_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：C。$127.0.0.1$ 是回环地址，既可以作为目的地址，也可以作为源地址（只是含该源地址的 IP 数据报不能离开本机）。因此 C 说“不能作为源 IP 地址”是错误的。

**解题切入点**：拿到题先抓“特殊 IP 地址”的语义分类，而不是逐项硬背。可以像算法题里构造一张“分类表/哈希表”一样，把每个特殊地址打上标签：  
- $0.0.0.0$：仅作源地址；  
- $255.255.255.255$：仅作目的地址，不转发；  
- $127.0.0.1$：本机环回，源/目的均可；  
- 主机号全 1：直接广播，路由器可转发。  
然后再逐项比对选项。

**推演**：

A 正确。$0.0.0.0$ 表示“本网络上的本主机”。DHCP 客户机在还没有获得 IP 地址时，会使用 $0.0.0.0$ 作为源 IP 地址发送报文。

B 正确。$255.255.255.255$ 是有限广播地址，只能作为目的地址，并且路由器不会转发它，因为该地址不包含网络号，路由器无法确定应转发到哪个网络。

C 错误。$127.0.0.1$ 属于环回地址 $127.0.0.0/8$。本机向 $127.0.0.1$ 发送数据时，数据报不会出现在外部链路上，而是在本机协议栈内部环回。在实际环回通信中，它可以作为目的地址，也可以作为源地址。比如本机执行 `ping 127.0.0.1` 时，回环接口上的报文源地址和目的地址都可以是 $127.0.0.1$。

D 正确。目的 IP 地址的主机号为全 1 时，表示某个网络的直接广播地址，例如：

$$
\text{网络号} + \underbrace{111\cdots 1}_{\text{主机号全 1}}
$$

它仍包含网络号，因此路由器可以按网络号路由，把数据报转发到目标网络，再在该网络上广播。

| 特殊地址 | 源/目的限制 | 路由器处理 |
|---|---|---|
| $0.0.0.0$ | 可作为源地址 | 不作为普通目的地址转发 |
| $255.255.255.255$ | 只能作为目的地址 | 不转发 |
| $127.0.0.1$ | 源、目的均可，但仅限本机环回 | 不离开本机 |
| 主机号全 1 | 只能作为目的地址 | 可按网络号转发 |

**易错点**：

- 混淆“有限广播”和“直接广播”。  
  $255.255.255.255$ 是有限广播，路由器不转发；主机号全 1 是直接广播，路由器可以按网络号转发。
- 误以为 $127.0.0.1$ 只能作目的地址。  
  正确说法是：$127.0.0.1$ 在本机内部环回时可以作源地址，也可以作目的地址；只是不能作为离开本机的源 IP 地址。
- 对 $0.0.0.0$ 感到反常。  
  DHCP 客户机尚未分配 IP 时，确实可以用 $0.0.0.0$ 作为源地址。
- 看到“广播”就认为路由器一定不转发。  
  关键看是否包含网络号；包含网络号的直接广播可转发，$255.255.255.255$ 才不转发。

**命题规律**：本题考查 IPv4 特殊地址的语义，是网络层的常考基础点。常见变式有：判断某个地址能否作为源/目的地址；给出子网或网络号求广播地址；结合 DHCP 考查报文源/目的地址；判断路由器是否会转发某个目的地址。复习时建议把特殊 IP 地址整理成表：源地址、目的地址、能否被路由器转发，并重点区分有限广播与直接广播。

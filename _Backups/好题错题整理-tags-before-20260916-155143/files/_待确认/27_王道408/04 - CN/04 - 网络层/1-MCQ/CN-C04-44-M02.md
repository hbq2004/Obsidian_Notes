# 选择题 第 2 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-44-M02_题目.png|题目]]

2. 下列关于路由算法的描述中,错误的是( ).

(A) 静态路由有时也被称为非自适应算法.

(B) 静态路由所使用的路由选择一旦启动就不能修改.

(C) 动态路由也称自适应算法,会根据网络的拓扑变化和流量变化改变路由决策.

(D) 动态路由算法需要实时获得网络的状态.

## 答案

## DeepSeek V4 Flash Max 解析

**答案**：B。静态路由是管理员手工配置、运行中不会自动改变，但并非“一旦启动就不能修改”，需要时完全可以由管理员重新配置修改。

**解题切入点**：拿到题目先抓关键词“静态路由/动态路由”“非自适应/自适应”“能否修改”。这本质是路由算法分类题，对应算法竞赛里的“离线算法 vs 在线算法”：静态路由就像打一张固定查表，表可以手工换，但不会随输入自动更新；动态路由则像在线算法，需要不断读取当前状态并更新数据结构。所以看到“一旦启动就不能修改”这种绝对化表述，就要警惕。

**推演**：

路由算法通常分为两大类：

- **静态路由**，又称**非自适应算法**。它由网络管理员手工配置路由表，路由选择不根据当前网络流量和拓扑自动调整。因此选项 A 正确。

- 静态路由虽然不会自动变化，但管理员可以通过重新配置来修改它，例如手动添加、删除或更改某条路由。也就是说，“静态”对应的是“不自动适应”，而不是“不可修改”。因此选项 B 的“一旦启动就不能修改”说法错误。

- **动态路由**，又称**自适应算法**。它会根据网络拓扑变化、链路状态变化甚至流量变化，自动更新路由选择。因此选项 C 正确。

- 动态路由要做出自适应决策，必须获得当前网络状态信息，例如链路是否可用、距离、时延、带宽等。RIP、OSPF、BGP 等动态路由协议都会通过报文交换状态信息。因此选项 D 正确。

逐一判断后，只有 B 表述错误。

**易错点**：

1. **把“静态”等同于“不可改”**  
   静态路由是“不能自动改”，不是“不能改”。手工重新配置完全可以修改静态路由表。

2. **误以为 D 中“实时获得网络状态”太绝对而判错**  
   这里的“实时”是相对于动态自适应而言的，指算法需要及时获取当前网络状态，并不要求像硬实时系统那样严格。即使 RIP 周期更新、OSPF 事件触发更新，也都属于动态获取状态。

3. **因 RIP 只看跳数而质疑 C 中“流量变化”**  
   动态路由的通用定义确实包含根据拓扑变化和流量变化调整路由；具体协议是否真的考虑流量属于实现细节，不能因此说 C 错误。

**命题规律**：本题考点是**路由算法的分类与基本特征**。常见变式有：判断静态/动态路由的适用场景、比较二者开销与适应性、考查 RIP/OSPF/BGP 属于动态路由、给出网络故障场景选择适合的路由算法。复习时建议抓住核心二分法：**静态 = 人工配置 + 非自适应；动态 = 自动获取状态 + 自适应更新**。遇到“绝对化”选项，优先考虑是否存在反例。

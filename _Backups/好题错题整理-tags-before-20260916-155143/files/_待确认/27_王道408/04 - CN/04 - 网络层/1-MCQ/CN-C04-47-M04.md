# 选择题 第 4 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-47-M04_题目.png|题目]]

4. 一个局域网与在远处的另一个局域网互联，则需要用到（ ）

(A) 物理通信介质和集线器
(B) 网间连接器和集线器
(C) 路由器和广域网技术
(D) 广域网技术

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-47-M04_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：C。  
一个局域网与远处的另一个局域网互联，必须通过**路由器**连接，并借助**广域网技术**提供长距离传输链路；单纯靠物理介质、集线器或广域网技术都不完整。

**解题切入点**：  
先抓住关键词“局域网”和“远处另一个局域网”。局域网通常是同一广播域/同一网络，而远处互联意味着跨越地理距离、可能跨越不同网络。这相当于算法中“两个独立数据结构要合并通信”，不能只靠局部指针，而需要“全局路由表”和“跨域传输协议”。把“路由器”看成网络层的“分发器/路由表”，把“广域网技术”看成底层“远程通信管道”，两者缺一不可。分层协议的设计思想也类似分治：物理层管“bit 怎么传”，网络层管“分组往哪儿走”，跨远距离时两者都要有。

**推演**：  
1. 两个局域网互联，首先需要确定它们是否属于同一个网络。题干没有说明它们属于同一网络，且“远处”通常意味着地理位置相距很远，一般要通过广域网互联，属于**不同网络**或至少跨越多个网络。  
2. 若只是一个局域网内部扩展，可以用集线器、交换机等设备，但这些设备工作在物理层或数据链路层，不能隔离广播域，也不能完成跨网络的路由选择。集线器只是多端口转发器，收到信号后就向所有端口转发，无法判断目的地址是否在另一个局域网，更不能解决远距离传输所需的链路技术。  
3. 远程互联必须经过广域网链路，例如租用线路、光纤、卫星链路等，这些属于广域网技术。但仅有链路还不够，两个局域网之间需要“路由器”作为网关：  
   - 路由器工作在网络层，负责解析 IP 地址；  
   - 路由器根据路由表选择最佳路径，将数据报从一个网络转发到另一个网络；  
   - 路由器连接不同网络时，会隔离广播域，并使用统一的网络层协议（如 IP）屏蔽底层广域网技术的差异。  
4. 因此完整条件是：  
$$
\text{局域网} \xrightarrow{\text{路由器}} \text{广域网链路} \xrightarrow{\text{路由器}} \text{局域网}
$$  
对应选项 C：“路由器和广域网技术”。

**易错点**：  
- **选 A**：以为只要有物理介质和集线器就能长距离连接。实际上集线器只扩大冲突域，无法隔离网络，更不能路由；远处互联也不是简单拉根网线。  
- **选 B**：“网间连接器”太模糊，若指中继器或网桥，仍无法完成跨广域网的路由选择；集线器也不具备网络层转发能力。  
- **选 D**：只强调广域网技术，容易忽略路由器。广域网技术只提供物理/数据链路层的传输通道，如果没有路由器做网络层互连，两个局域网无法正确找到对方并转发数据。  
- 要区分“局域网内部互联”和“局域网之间远程互联”：内部多用交换机，远程多用路由器和广域网。

**命题规律**：  
本题属于计算机网络基础题，考点是“网络互连设备与广域网技术”。命题常见变式包括：  
- 给出多个设备（中继器、网桥、交换机、路由器），问哪个设备可以连接不同网络；  
- 询问“不同局域网互连必须工作在哪一层”，答案往往是网络层；  
- 结合 IP 地址和路由表，问路由器如何转发数据报。  
复习时建议牢记 OSI/RM 各层设备：物理层（中继器、集线器）、数据链路层（网桥、交换机）、网络层（路由器）。同时理解“局域网远程互连 = 路由器 + 广域网链路”这一经典场景，类似算法中“局部数据结构 + 全局调度器”才能完成跨域任务。

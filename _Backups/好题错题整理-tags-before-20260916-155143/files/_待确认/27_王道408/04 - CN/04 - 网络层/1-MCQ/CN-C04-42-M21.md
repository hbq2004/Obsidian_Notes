# 选择题 第 21 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-42-M21_题目.png|题目]]

21. 把 IP 网络划分成子网,这样做的好处是（  ）.

(A) 增加冲突域的大小
(B) 增加主机的数量
(C) 减少广播域的大小
(D) 增加网络的数量

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-42-M21_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：C。划分子网可以将一个大广播域拆分为多个较小的广播域，从而减少每个子网内的广播流量范围。

**解题切入点**：本题是网络层基础概念题，核心是理解“子网划分”的目的。可以类比算法竞赛中的“分治”思想：一个大数组全量扫描（广播）代价高，就把它切分成多个块，每个块内部处理，缩小影响范围。子网划分就是按 IP 地址前缀把网络分成若干独立管理、独立广播的小区域，而不是为了增加主机数量或扩大冲突域。

**推演**：

1. 明确几个概念：
   - **冲突域**：同一物理介质上可能发生冲突的设备集合，属于数据链路层概念，由交换机和网桥隔离，而不是由 IP 子网划分直接改变。
   - **广播域**：能收到同一广播帧（如 ARP 广播）的主机集合，默认情况下路由器可以隔离广播域，而交换机不能。
   - **IP 子网划分**：把一个大网络的主机地址段按“网络号 + 子网号 + 主机号”重新分割，形成多个逻辑子网。

2. 划分子网后，每个子网是一个独立的广播域。原本一个较大网络中的所有主机处于同一个广播域，任意主机发广播，全网都能收到；划分子网后，广播只在本子网内部传播，路由器不会转发跨子网的广播，因此广播域大小变小。

3. 选项分析：
   - (A) 增加冲突域的大小：错误。划分子网不改变物理链路层冲突域；现代交换网络本身已经隔离冲突域。
   - (B) 增加主机的数量：错误。子网划分只是重新分配主机位，并不会增加主机总数，甚至由于子网号占用主机位，会减少每个子网的可分配主机数。
   - (C) 减少广播域的大小：正确。每个子网成为一个更小的广播域，广播被限制在子网内部。
   - (D) 增加网络的数量：严格说划分子网后逻辑网络（子网）的数量确实变多了，但这并不是划分子网的主要“好处”，而是手段/结果；而且题目问好处时，减少广播域是更核心的目的。若单看“增加网络数量”也不是本质优点，因为数量增加的同时每个网络容量减小，管理成本可能增加。因此选 C。

**易错点**：

- 误选 D：看到“子网划分”就认为子网数量增加。但“增加网络数量”是划分后的现象，不是划分子网所追求的好处；划分子网的核心动机是隔离广播、优化管理。
- 混淆冲突域与广播域：冲突域由集线器/交换机隔离，广播域由路由器隔离。划分子网与广播域直接相关，与冲突域无直接关系。
- 误认为子网划分能增加主机数：子网划分会占用主机位作为子网位，实际可用主机数通常减少，不可能增加总主机数。

**命题规律**：该题属于网络层 IP 地址规划的基础考点，常考子网掩码、子网划分的目的、广播域/冲突域的判定等。常见变式包括：给定 IP 和子网掩码求子网数量、主机范围、广播地址；或判断哪些设备能隔离广播域/冲突域。复习时应重点理解 IP 地址结构、子网掩码的作用，以及路由器、交换机、集线器对广播域和冲突域的隔离行为，同时注意“划分子网”与“VLAN”在隔离广播域上的异同。

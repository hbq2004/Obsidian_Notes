# 选择题 第 7 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-41-M07_题目.png|题目]]

7. 在互联网中，*IP*分组的传输需要经过源主机和中间路由器到达目的主机，通常（ ）
(A) 源主机和中间路由器都知道*IP*分组到达目的主机需要经过的完整路径
(B) 源主机和中间路由器都不知道*IP*分组到达目的主机需要经过的完整路径
(C) 源主机知道*IP*分组到达目的主机需要经过的完整路径,而中间路由器不知道
(D) 源主机不知道*IP*分组到达目的主机需要经过的完整路径,而中间路由器知道

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-41-M07_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：B。源主机和中间路由器都不知道 IP 分组到达目的主机需要经过的完整路径，因为互联网采用逐跳（hop‑by‑hop）转发，每个节点仅根据目的地址和路由表选择下一跳，不维护全局路径信息。

**解题切入点**：首先定位考点为网络层的分组转发与路由原理。核心是“逐跳转发”原则：分组每到达一个节点（源主机或路由器），该节点只关心下一跳，而不关心整个路径。可以类比算法中的“贪心”思想——每一步只做局部最优决策，无需全局视图；或者像在迷宫中只看路标，不看全程地图。

**推演**：  
1. 源主机发送 IP 分组时，将目的 IP 地址填入分组头，然后根据本地路由表（或默认网关）决定下一跳路由器，并将分组发送给该路由器。  
2. 中间路由器收到分组后，同样只根据目的 IP 地址查询自己的路由表，得到下一跳，继续转发。  
3. 此过程重复，直到分组到达与目的主机在同一网络的路由器，后者直接交付给目的主机。  
4. 在整个过程中，任何节点都只掌握下一跳信息，不具备完整路径。因此，选项 A、C、D 均错误，B 正确。

**易错点**：  
- 误认为源主机通过 traceroute 或路由跟踪工具可以知道路径，但那是事后测试，实际转发时源主机并不事先知道完整路径。  
- 混淆“虚电路”与“数据报”：虚电路在网络建立时确定路径，节点需维护连接状态；而 IP 是数据报方式，无连接，逐跳独立决策。  
- 忽略“源路由选项”（如 LSRR）的存在，但该选项仅在特殊情况下使用，且题目是针对互联网常规情况，默认不开启。

**命题规律**：  
- 常考网络层两种转发方式（数据报 vs 虚电路），以及路由器的基本工作模式。  
- 变式可能包括：问主机是否知道本机 MAC 地址、ARP 过程等，或结合 IPv6 路由扩展头部。  
- 复习建议：理解 IP 分组“无连接、尽力而为”的特点，并用“逐跳转发”这一核心思想串联路由选择、分组转发、路由表等知识点。

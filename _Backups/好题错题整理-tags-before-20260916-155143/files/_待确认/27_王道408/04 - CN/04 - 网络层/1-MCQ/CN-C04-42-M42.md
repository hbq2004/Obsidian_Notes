# 选择题 第 42 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-42-M42_题目.png|题目]]

42. 路由器收到目的 IP 地址为 255.255.255.255 的分组,则路由器的操作是（ ）.

(A) 丢弃该 IP 分组  
(B) 从所有其他接口转发该 IP 分组  
(C) 通过路由表中的默认路由转发该 IP 分组  
(D) 通过路由表中的特定主机路由转发该 IP 分组

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-42-M42_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：A。路由器收到目的 IP 地址为 255.255.255.255（有限广播地址）的分组时，应直接丢弃，不应转发。  
**解题切入点**：首先识别目的地址 255.255.255.255 为有限广播地址，该地址仅用于本地网络广播，路由器必须隔离广播域，因此不会转发此类分组。类比算法竞赛中“局部变量仅在当前作用域有效”，广播地址的“作用域”限制在本地链路，路由器作为跨网络设备，必须放弃这种“局部”数据。  
**推演**：  
- 255.255.255.255 是 IPv4 的有限广播地址，表示网络号为全 1，主机号为全 1，其范围仅限于本网段。  
- 路由器的主要功能是连接不同网络，转发 IP 分组时需依据路由表。对于广播地址，路由器通常不转发，以避免广播风暴。  
- 根据 RFC 1812《路由器需求》规定，路由器收到目的地址为有限广播地址（255.255.255.255）的 IP 分组时，除特殊情形（如 DHCP 中继）外，应丢弃。  
- 因此，路由器不会从其他接口转发，也不会匹配路由表中的默认路由或特定主机路由，直接丢弃。  
**易错点**：  
- 误认为 255.255.255.255 是“广播”就应转发给所有接口，忽略“有限”的含义。  
- 混淆有限广播与定向广播（如 192.168.1.255），定向广播可以被路由器转发（但可配置禁止），而有限广播永不被转发。  
- 考虑 DHCP 场景时认为路由器必须转发，实际上 DHCP 中继需特殊配置，且路由器收到的仍是单播或广播分组，但题目无特殊说明，默认为普通路由器行为。  
**命题规律**：  
- 考点：IPv4 特殊地址（有限广播地址）的路由器处理方式，属于网络层基础概念。  
- 常见变式：考查定向广播地址（如 192.168.1.255）的处理、路由器对广播分组的默认策略、DHCP 中继对广播的处理等。  
- 复习建议：牢记 IPv4 特殊地址（环路、私有、广播、多播）及其作用域，理解路由器广播隔离原则，区分“有限广播”与“定向广播”。

# 选择题 第 2 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-43-M02_题目.png|题目]]

2. 与 IPv4 相比，IPv6( )

A. 采用32位 IP 地址
B. 增加了首部字段数量
C. 不提供 QoS 保障
D. 没有提供检验和字段

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-43-M02_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：D。IPv6 首部取消了校验和字段，以简化每跳处理；其他选项均与事实不符。

**解题切入点**：立即定位 IPv6 相对于 IPv4 的核心变化，包括地址长度、首部结构、QoS 支持、校验和等。可将 IPv6 的简化首部视为“去冗余”设计，类似于算法竞赛中优化数据结构，去掉冗余字段以提升效率。

**推演**  
- A：IPv6 地址长度为 128 位，IPv4 为 32 位，故错误。  
- B：IPv6 固定首部长度仅 40 字节，字段数量比 IPv4 少（去掉了 IHL、标识、标志、片偏移、校验和等），故错误。  
- C：IPv6 通过流标签（Flow Label）和优先级字段提供 QoS 保障，故错误。  
- D：IPv6 首部无校验和，依赖链路层差错检测，每跳不再计算校验和，减少转发开销，正确。

**易错点**  
- 误认为 IPv6 地址长度仍是 32 位（实际是 128 位）。  
- 混淆首部字段数量：IPv6 虽然扩展了选项，但固定首部字段减少，不能简单认为“增加”。  
- 忽略 IPv6 的流标签机制，错误以为 IPv6 不提供 QoS。

**命题规律**  
- 考点：IPv6 与 IPv4 的区别，常见于选择题，重点记忆地址长度、地址表示、首部格式、QoS 支持、校验和、分片等。  
- 变式：可考查 IPv6 地址书写、邻居发现、无状态地址自动配置等。  
- 复习建议：对比 IPv4 与 IPv6 首部，列出增删字段，理解设计动机（如简化、扩展性、安全性）。

# 选择题 第 51 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-42-M51_题目.png|题目]]

51.【2010统考真题】若路由器 $R$ 因为拥塞丢弃 $IP$ 分组，则此时 $R$ 可向发出该 $IP$ 分组的源主机发送的 $ICMP$ 报文类型是（  ）

(A) 路由重定向  
(B) 目的不可达  
(C) 源点抑制  
(D) 超时

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-42-M51_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：C。路由器因拥塞丢弃 IP 分组时，可向源主机发送 ICMP **源点抑制（Source Quench）** 报文，让源主机降低发送速率。

**解题切入点**：先抓住题干中的两个关键词：“拥塞丢弃”和“源主机”。在计算机网络中，拥塞丢弃的语义是“我（路由器）处理不过来了，请你（源主机）发慢一点”，这对应 ICMP 的“源点抑制”。可以类比算法竞赛中的评测系统：如果某个节点的待处理任务队列溢出，系统不会说“你访问的路径不存在”，而会说“当前压力过大，请降低请求频率”——这就是背压（backpressure）思想。题目本质是在考察 ICMP 各报文类型与触发场景的一一对应关系。

**推演**：

ICMP 位于网络层，封装在 IP 数据报中，用于报告差错或提供网络诊断信息。当路由器 $R$ 因拥塞丢弃 IP 分组时，它需要通知源主机“网络现在太拥挤，请降低发送速率”。ICMP 中专门用于拥塞控制的报文是**源点抑制**，其类型值为 4，代码为 0。

逐个选项分析：

- **路由重定向（Redirect）**：用于告诉主机“你发送到某个目的地的数据报，应该走另一个更好的下一跳路由器”。它与拥塞无关，对应的是路由选择的优化问题。
- **目的不可达（Destination Unreachable）**：当路由器或主机无法转发数据报时发送，例如网络不可达、主机不可达、端口不可达等。虽然路由器丢弃分组也可能导致目的不可达，但本题明确说明原因是“拥塞”，而不是“找不到路径”，因此不应选 B。
- **源点抑制（Source Quench）**：当路由器因拥塞丢弃分组时，向源主机发送该报文，要求其降低发送速率。这正是题目描述的场景。
- **超时（Time Exceeded）**：当 IP 数据报的 TTL（生存时间）减为 0 时，路由器丢弃该数据报，并发送超时报文。本题没有提及 TTL，因此不选 D。

因此，只有选项 C 符合题意。

**易错点**：

1. **混淆“目的不可达”与“拥塞丢弃”**：目的不可达表示“目的地无法找到”或“端口不存在”，而拥塞丢弃表示“网络资源不足”。前者是拓扑或服务问题，后者是流量控制问题。
2. **误选“超时”**：看到“丢弃”就联想到 TTL=0。但题干的条件是“拥塞”，不是“TTL 过期”，必须抓住错误原因。
3. **忽略“源点抑制”已废弃的事实**：ICMP 源点抑制在现代网络中已被 RFC 1812 标记为不建议使用，实际实现中可能不会发送。但考研 408 以经典教材和统考大纲为准，遇到该知识点仍应选“源点抑制”。
4. **把 ICMP 和 TCP 拥塞控制混淆**：源点抑制是网络层的 ICMP 报文，而 TCP 的拥塞控制（慢启动、拥塞避免等）是传输层机制，两者层次不同，不能混为一谈。

**命题规律**：本题属于网络层的经典基础题，考查 ICMP 各报文类型的应用场景。常见变式包括：给出“TTL 减为 0”选“超时”，给出“端口不可达”选“目的不可达”，给出“默认路由错误”选“路由重定向”。复习时建议对比记忆 ICMP 的四大差错报文及其触发条件，并注意其与 TCP/IP 协议栈层次的关系。后续遇到类似题目，先判断“丢弃原因”或“错误类型”，再对应 ICMP 报文即可避免失分。

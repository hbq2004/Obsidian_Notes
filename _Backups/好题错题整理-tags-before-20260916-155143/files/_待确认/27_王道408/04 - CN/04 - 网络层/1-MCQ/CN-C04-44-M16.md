# 选择题 第 16 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-44-M16_题目.png|题目]]

16. 下列关于 OSPF 协议的描述中,最准确的是 ( )

(A) OSPF 协议根据链路状态法计算最佳路由

(B) OSPF 协议是用于自治系统之间的外部网关协议

(C) OSPF 协议不能根据网络通信情况动态地改变路由

(D) OSPF 协议只适用于小型网络

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-44-M16_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：A。OSPF 的核心是基于链路状态（Link State）算法计算最短/最佳路由，且属于自治系统内部使用的内部网关协议。

**解题切入点**：先判断协议“身份”：是自治系统内部还是外部？再判断“机制”：是距离向量还是链路状态？这就像算法竞赛中拿到题先看数据范围与问题类型——先确定所属模型，再选对应算法。OSPF 的定位是“域内、链路状态、动态、可扩展”，而 B/D/C 分别在外网协议、动态性、规模适用性上设错，直接排除。

**推演**：

1. OSPF（Open Shortest Path First，开放最短路径优先）是一个**自治系统内部**使用的路由协议，即内部网关协议（IGP, Interior Gateway Protocol）。它不属于外部网关协议（EGP），因此选项 B 错误。

2. OSPF 采用**链路状态法**：每个路由器通过泛洪（Flooding）发送链路状态通告（LSA），最终所有路由器形成一致的链路状态数据库（LSDB）。在此基础上，利用最短路径优先（SPF）算法，例如 Dijkstra 算法，计算到各目的地的最短路径。Dijkstra 算法的核心公式为：
   $$d(v) = \min\{d(v), d(u) + w(u,v)\}$$
   其中 $d(v)$ 为源点到 $v$ 的当前最短距离，$w(u,v)$ 为边 $(u,v)$ 的权值。因此，选项 A 正确。

3. 当网络拓扑或链路代价发生变化时，OSPF 会重新泛洪 LSA，并重新运行 SPF 计算，从而动态更新路由表。因此，选项 C“不能动态改变路由”错误。

4. OSPF 支持划分区域（Area）来减少 LSA 泛洪范围，具有很好的层次化扩展性，适用于大型网络。因此，选项 D“只适用于小型网络”错误。

综上，四个选项中只有 A 的描述准确。

**易错点**：

- **混淆 IGP 与 EGP**：OSPF 是内部网关协议，而 BGP 才是自治系统之间的外部网关协议。看到“自治系统之间”应立刻排除。
- **混淆距离向量与链路状态**：RIP 是距离向量，OSPF 是链路状态。距离向量“只告诉邻居我听说的距离”，链路状态“广播全网拓扑，自己算最短路径”。
- **误认为动态路由都能自适应**：OSPF 能根据链路 cost 变化动态调整，C 项是明显反向陷阱。
- **误认为链路状态协议只适合小网**：OSPF 通过分区域、分层设计，恰恰是为中大型网络设计的；小网常用 RIP 或静态路由。

**命题规律**：该题属于“路由协议基础概念”的高频考点，常以“下列说法正确的是/错误的是”形式出现，选项通常混入 IGP/EGP、距离向量/链路状态、静态/动态、小型/大型网络等维度。复习时应把 RIP、OSPF、BGP 做成对比表，分别从适用范围、算法原理、度量标准、更新方式、收敛速度等方面对比记忆。同时注意“最准确”类题目优先选机制描述最本质的选项，而不是泛泛的正确表述。

# 选择题 第 57 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-42-M57_题目.png|题目]]

57.【2015统考真题】某路由器的路由表如下所示：

| 目的网络 | 下一跳 | 接口 |
| --- | --- | --- |
| 169.96.40.0/23 | 176.1.1.1 | S1 |
| 169.96.40.0/25 | 176.2.2.2 | S2 |
| 169.96.40.0/27 | 176.3.3.3 | S3 |
| 0.0.0.0/0 | 176.4.4.4 | S4 |

若路由器收到一个目的地址为 169.96.40.5 的 IP 分组，则转发该 IP 分组的接口是（ ）

A. S1  
B. S2  
C. S3  
D. S4

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-42-M57_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：C。根据最长前缀匹配规则，目的地址 169.96.40.5 同时匹配三个特定前缀，但 /27 前缀最长，故转发接口为 S3。

**解题切入点**：拿到题目应首先定位到 IP 分组转发的最长前缀匹配考点。将每个路由表项视为一个“匹配规则”，目的地址要在所有匹配规则中选出前缀长度最长的那个。这类似于算法竞赛中，当有多个可行解时，选择约束条件最严格的解（如区间覆盖问题中选取覆盖端点最小区间，或字符串匹配中选取最长公共前缀）。

**推演**：  
将目的地址与各网络前缀转换为二进制，逐条判断匹配情况。

目的地址 $169.96.40.5$ 的二进制表示为  
$$
169.96.40.5 = 10101001.01100000.00101000.00000101
$$

1. 前缀 $169.96.40.0/23$：网络部分为前 23 位，即 $10101001.01100000.0010100$（第三字节前 7 位）。目的地址的前 23 位与之完全相同，故匹配。  
2. 前缀 $169.96.40.0/25$：网络部分为前 25 位，即 $10101001.01100000.00101000.0$（第四字节第 1 位）。目的地址的前 25 位与之完全相同，故匹配。  
3. 前缀 $169.96.40.0/27$：网络部分为前 27 位，即 $10101001.01100000.00101000.000$（第四字节前 3 位）。目的地址的前 27 位与之完全相同，故匹配。  
4. 默认路由 $0.0.0.0/0$ 匹配所有地址。

三条特定前缀均匹配，根据最长前缀匹配原则，选择前缀长度最大的条目（/27 大于 /25 和 /23），对应接口 S3。  
因此，转发接口为 S3。

**易错点**：常见错误是误以为 /23 或 /25 是最长匹配，未仔细比较前缀长度；或混淆子网掩码，错误认为 $169.96.40.5$ 不在 /27 范围内（实际 $5$ 在 $0$–$31$ 内）。规避方法：将地址和掩码一并转换为二进制，逐位比较，确保准确计算前缀长度和匹配范围。

**命题规律**：本题是典型的 IP 分组转发选择题，核心考点为最长前缀匹配及子网掩码的理解。常见变式包括：给定多个前缀和目的地址，要求选择匹配接口；或给出路由表要求构造聚合网络等。复习建议：熟练掌握 IP 地址二进制转换，理解前缀长度与子网掩码的关系，并多做二进制计算练习以提高准确性与速度。

# 选择题 第 69 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-42-M69_题目.png|题目]]

69.【2023统考真题】某网络拓扑如下图所示,其中路由器 R2 实现 NAT 功能。若主机 H 向 Internet 发送 1 个 IP 分组,则经过 R2 转发后,该 IP 分组的源 IP 地址是（ ）

【图：网络拓扑图。左侧为 Internet 云，经路由器 R1 连接到路由器 R2；R1 与 R2 之间链路上标注“195.123.0.34/30”；R2 为 NAT 路由器，其右侧连接主机 H，R2 右侧接口标注为“192.168.0.1”；主机 H 标注为“192.168.0.3”。】

A. 195.123.0.33  
B. 195.123.0.35  
C. 192.168.0.1  
D. 192.168.0.3

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-42-M69_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：A。经过 R2 的 NAT 转换后，源 IP 地址被替换为 R2 的外网接口 IP 地址，即 $195.123.0.33$。

**解题切入点**：首先定位 NAT 路由器，明确其功能是将私有 IP 转换为公网 IP。然后分析拓扑中的链路地址分配，确定 R2 的外网接口 IP。类似算法竞赛中的地址映射（如哈希表），将内部私有地址 $\mapsto$ 外部公网地址，此处映射为目标 $195.123.0.33$。

**推演**：主机 H 的 IP 为 $192.168.0.3$（私有地址）。当它向 Internet 发送 IP 分组时，分组首先到达 R2。R2 实现 NAT，会将源 IP 地址替换为自身面向外网的接口 IP 地址，以便在 Internet 中路由。  
R2 与 R1 之间链路标注 “$195.123.0.34/30$”，表示该链路使用 $30$ 位掩码，子网为 $195.123.0.32/30$，可用主机地址为 $195.123.0.33$ 和 $195.123.0.34$，广播地址为 $195.123.0.35$。通常，这两个可用地址分别分配给 R2 和 R1 的接口。由于 R2 的内网接口已是私有地址 $192.168.0.1$，其外网接口必须使用公网 IP。选项 $195.123.0.33$ 符合要求，而 $195.123.0.34$ 未出现在选项中，$195.123.0.35$ 为广播地址不可用作主机源 IP，私有地址 $192.168.0.1$ 和 $192.168.0.3$ 在 NAT 后不会被保留。因此，R2 转发后源 IP 地址为 $195.123.0.33$。

**易错点**：
- 误以为 NAT 不改变源 IP，错选 D（$192.168.0.3$）或 C（$192.168.0.1$）。
- 混淆 R2 的外网接口与内网接口，错选 C。
- 未正确分析 $/30$ 子网，误将广播地址 $195.123.0.35$ 当作可用地址。
- 对 NAT 转换时机理解不清，误以为在 R1 转发后才改变源 IP。

**命题规律**：本题将 NAT 原理与子网划分结合考查，属于 408 计算机网络常见综合题。复习时应重点掌握：
- NAT 的工作过程（私有地址 $\to$ 公网地址）及典型配置。
- 子网划分与地址分配（尤其是 $/30$ 点对点链路）。
- 常见变式：结合 NAPT、静态 NAT 或动态 NAT 进行多选；在 IPv6 环境中考查 NAT 的局限性。

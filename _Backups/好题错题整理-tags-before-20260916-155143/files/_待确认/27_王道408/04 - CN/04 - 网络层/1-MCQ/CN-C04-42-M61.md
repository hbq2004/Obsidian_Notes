# 选择题 第 61 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-42-M61_题目.png|题目]]

61.【2017统考真题】下列 IP 地址中,只能作为 IP 分组的源 IP 地址但不能作为目的 IP 地址的是( ).
(A) 0.0.0.0
(B) 127.0.0.1
(C) 200.10.10.3
(D) 255.255.255.255

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-42-M61_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：A。$0.0.0.0$ 是“本主机上的本机”保留地址，只能作为 IP 分组的源 IP 地址，不能作为目的 IP 地址。

**解题切入点**：拿到题先抓“源/目的限制”这个属性，本质上就是找特殊 IP 地址里的“哨兵值”。和算法竞赛中构造 dummy 结点类似：$0.0.0.0$ 像一个“初始化占位符”，只在发送方还没有真实地址时使用，不能作为接收方地址；而 $255.255.255.255$ 则是相反的“广播哨兵”，只能作为目的地址，不能作为源地址。所以看到“只能源、不能目的”，优先锁定 $0.0.0.0$。

**推演**：

逐项分析四个选项：

1. $0.0.0.0$  
   全 0 地址在 IPv4 中表示“本主机在本网络上”。当主机尚未获得 IP 地址时，例如在 DHCP 发现阶段，会用 $0.0.0.0$ 作为源 IP 地址发出请求；它不能作为目的 IP 地址，因为任何主机都不会以全 0 地址作为自己的目的地址。  
   所以，$0.0.0.0$ 只能作源地址，不能作目的地址。

2. $127.0.0.1$  
   属于环回地址 $127.0.0.0/8$。该地址用于本机测试，分组不会真正发到链路上，而是由协议栈直接回送。  
   它既可以作源地址，也可以作目的地址，例如访问本机服务时目的地址可以是 $127.0.0.1$。

3. $200.10.10.3$  
   这是一个普通的公网单播地址，既可作为源 IP 地址，也可作为目的 IP 地址，不满足题目要求。

4. $255.255.255.255$  
   全 1 地址是受限广播地址，用于向本网络内所有主机广播。它只能作为目的 IP 地址，不能作为源 IP 地址。  
   与题目要求方向相反。

因此，唯一满足“只能作为源 IP 地址但不能作为目的 IP 地址”的是 $0.0.0.0$。

**易错点**：

- 误选 $127.0.0.1$：误以为环回地址只能作源，不能作目的。实际上环回地址既能作源也能作目的，常用于测试本机协议栈。  
- 误选 $255.255.255.255$：它是“只能作目的，不能作源”的地址，与题目要求正好相反。  
- 忽略 DHCP 场景：记住 DHCP Discover 中源 IP 是 $0.0.0.0$，目的 IP 是 $255.255.255.255$，就可以区分这两个特殊地址的方向。  
- 做题时容易漏看“只能”二字，导致把普通单播地址 $200.10.10.3$ 也纳入考虑；普通单播地址源和目的都能用。

**命题规律**：

本题考查 IPv4 特殊保留地址，是网络层的高频基础考点。常见变式有：

- 问“只能作为目的地址但不能作为源地址”，答案通常是 $255.255.255.255$。  
- 结合 DHCP 过程，问 DHCP Discover 报文的源 IP 和目的 IP。  
- 结合环回地址，问 ping $127.0.0.1$ 测试的是本机哪一层协议栈。  

复习建议：把特殊 IP 地址整理成表，按“全 0、全 1、环回、私网、组播、有限广播”分类，重点记住每个地址“能否作源、能否作目的”的方向属性。

# 选择题 第 30 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-42-M30_题目.png|题目]]

30.为了解决 $IP$ 地址耗尽的问题,可以采用以下一些措施,其中治本的是( )

A. 划分子网

B. 采用无类别的编址 $CIDR$

C. 采用网络地址转换 $NAT$

D. 采用 $IPv6$

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-42-M30_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：D. 采用 IPv6。IPv6 通过 128 位地址从根本上解决了 IPv4 地址空间不足的问题，而其他选项仅是缓解手段。

**解题切入点**：先明确“治本”的含义——从根源上消除问题，而非仅仅延缓或压缩。IP 地址耗尽的根源是 IPv4 地址空间（32 位）有限，所以必须扩大地址空间。这类似于算法竞赛中，若数据规模超出数组容量，改用哈希表（动态扩展）才是治本，而优化遍历顺序或压缩数据只是治标。

**推演**：
- 选项 A（划分子网）：将 IP 地址的主机号部分划分为子网号，提高地址利用率，但并未增加地址总数，属于管理优化。
- 选项 B（CIDR）：取消传统 A/B/C 类划分，通过可变长子网掩码聚合路由，减少路由表条目并灵活分配，但 IPv4 地址空间仍为 32 位，总量不变。
- 选项 C（NAT）：允许多个私有 IP 共享一个公网 IP，通过端口号区分不同会话，缓解了公网地址短缺，但本质上仍是复用已有地址，且破坏了端到端透明性。
- 选项 D（IPv6）：将地址长度扩展到 128 位，使地址空间几乎无限，从容量上彻底解决地址耗尽问题，因此是治本之策。

**易错点**：
- 误以为 CIDR 或 NAT 能“解决”地址耗尽，混淆了“缓解”与“根治”。CIDR 仅提高分配效率，NAT 仅实现多对一复用，均未增加地址总数。
- 忽略“治本”要求，可能选择直观上有效的选项（如 NAT 常用于家庭网络），但不知其局限性。

**命题规律**：
- 考点：IPv4 地址耗尽问题的解决方案分类，区分治标与治本。
- 常见变式：问“下列哪项能长期缓解/根本解决 IP 地址短缺？”或“属于过渡技术的是？”。
- 复习建议：理解每种技术的原理与局限，牢记 IPv6 是唯一从地址空间角度解决问题的方案。同时注意 NAT 仅适用于局域网，且 IPv6 的推广才是根本方向。

# 选择题 第 7 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-47-M07_题目.png|题目]]

7.(未使用 $CIDR$) 当一个 $IP$ 分组进行直接交付时,要求发送方和目的站具有相同的( )

A. $IP$地址  
B. 主机号  
C. 端口号  
D. 子网地址

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-47-M07_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：D。一句话理由：IP 分组直接交付要求发送方和目的站处于同一子网，即二者的子网地址相同。

**解题切入点**：拿到题目先抓“交付方式”的分类判断：直接交付是“同网段内直接传”，间接交付是“跨网段需要路由器转发”。可以类比算法竞赛中的分块思想：如果数据在当前块内，直接暴力/本地处理；如果不在当前块，必须跳转到另一个块。这里的“块号”就是子网地址，判断方法就是把源 IP 和目的 IP 分别与子网掩码做按位与，结果相同则同块、可直接交付；结果不同则跨块、需交给路由器。

**推演**：  
IP 分组交付分为两种：

1. 直接交付：目的主机与源主机在同一子网内，发送方直接将 IP 分组封装成帧，通过底层网络送给目的主机，不经过路由器。
2. 间接交付：目的主机不在同一子网内，发送方必须将分组交给路由器，由路由器逐跳转发。

判断是否在同一子网的方法：

设源 IP 地址为 $IP_S$，目的 IP 地址为 $IP_D$，子网掩码为 $M$，则：

- 源子网地址：
$$
IP_S \land M
$$
- 目的子网地址：
$$
IP_D \land M
$$

其中 $\land$ 表示按位与运算。

若
$$
IP_S \land M = IP_D \land M
$$
则说明源主机和目的主机属于同一个子网，此时采用直接交付。

未使用 CIDR 时，IP 地址采用分类编址并结合子网划分，子网地址由“网络号 + 子网号”组成，主机号只是子网内部主机的编号。直接交付只要求“子网地址”相同，不要求主机号相同，更不要求 IP 地址相同。

例如：  
源 IP 为 $202.113.10.5$，目的 IP 为 $202.113.10.9$，子网掩码为 $255.255.255.0$，则：

$$
202.113.10.5 \land 255.255.255.0 = 202.113.10.0
$$

$$
202.113.10.9 \land 255.255.255.0 = 202.113.10.0
$$

两者子网地址相同，因此发送方可以直接交付。

因此正确选项为 D。

**易错点**：

1. 误选 B（主机号相同）：主机号相同但网络号/子网号不同，仍然不属于同一子网，必须通过路由器间接交付。
2. 误选 A（IP 地址相同）：在同一子网内，每台主机的 IP 地址必须唯一，发送方和目的站是两个不同主机，IP 地址不可能相同；如果相同则是地址冲突，不是正常交付。
3. 误选 C（端口号）：端口号是传输层概念，IP 分组交付发生在网络层，不涉及端口号。
4. 混淆“网络地址”与“子网地址”：若未划分子网，则直接比较网络号；若划分子网，则必须比较子网地址。题目说“未使用 CIDR”但考查子网划分场景，应选“子网地址”。

**命题规律**：本考点属于 408 中网络层 IP 分组的转发与交付。常见变式包括：

- 给出源 IP、目的 IP、子网掩码，判断采用直接交付还是间接交付；
- 计算目的子网地址，与路由表项匹配；
- 结合 ARP：直接交付时用目的 IP 查询 ARP；间接交付时用下一跳路由器 IP 查询 ARP。

复习建议：牢牢掌握“源/目的 IP 分别与子网掩码按位与，比较子网地址”的流程，多做位运算与子网划分的习题，同时注意区分“直接交付”和“间接交付”在 ARP 使用上的差别。

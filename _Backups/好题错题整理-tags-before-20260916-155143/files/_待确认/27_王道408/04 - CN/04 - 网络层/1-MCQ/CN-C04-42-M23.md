# 选择题 第 23 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-42-M23_题目.png|题目]]

23. 一台主机有两个 IP 地址,一个地址是 192.168.11.25,另一个地址可能是( )

A. 192.168.11.0

B. 192.168.11.26

C. 192.168.13.25

D. 192.168.11.24

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-42-M23_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：C。理由：一台主机的多个 IP 地址应属于不同网络；192.168.11.25 属于网络 192.168.11.0/24，而 192.168.13.25 属于另一个网络 192.168.13.0/24，故可能为另一 IP 地址。

**解题切入点**：拿到题目先抓“一台主机有两个 IP 地址”这个条件，考点立即定位到 IP 地址与网络接口的关系：IP 地址标识的是主机的一个网络接口，多接口主机的不同接口应连接不同网络。这好比算法竞赛中，同一个容器里不同“桶”保存不同类型的数据，如果硬塞进同一“桶”会造成冲突和混乱；这里同一主机的两个 IP 地址应放在不同“网络桶”中。

**推演**：

192.168.11.25 是 C 类地址，默认子网掩码为 255.255.255.0，即 /24。其网络号为前 3 个字节：

$$192.168.11.25 \land 255.255.255.0 = 192.168.11.0$$

所以 192.168.11.25 所在网络为：

$$192.168.11.0/24$$

逐一检查选项：

- A. 192.168.11.0：网络号是 192.168.11，主机号全 0，这是网络地址，不能分配给主机。
- B. 192.168.11.26：网络号为 192.168.11，与给定地址同网，不能作为同一主机的另一 IP 地址。
- D. 192.168.11.24：网络号也为 192.168.11，与给定地址同网，同样不符合要求。
- C. 192.168.13.25：其网络号为：

$$192.168.13.25 \land 255.255.255.0 = 192.168.13.0$$

与 192.168.11.0 不同网，因此可以作为该主机的另一个 IP 地址。

**易错点**：

- 易误选 B 或 D：认为同一主机多配几个同网段 IP 也合理；但考研 408 中强调多接口主机的不同接口应处于不同网络，否则会造成路由与 ARP 解析混乱。
- 易误选 A：忽略 192.168.11.0 是 C 类网络地址，主机号全 0，不能分配给主机。
- 分不清分类编址：192.168.x.x 是 C 类私有地址，默认掩码为 255.255.255.0；若当作 CIDR 而没有给掩码，则按传统分类地址判断。

**命题规律**：本题主要考查 IP 地址的分类、网络号与主机号的计算，以及“IP 地址标识主机接口”这一核心概念。常见变式有：给一个 IP 地址，判断哪些地址可作同主机的另一地址；给出掩码和子网划分，判断同主机多 IP 是否属于不同子网；或者结合网络地址、广播地址一起考查。复习时应重点掌握 A/B/C 类地址的默认掩码、网络号/主机号划分，以及多接口主机的编址规则。

# 选择题 第 7 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-42-M07_题目.png|题目]]

7. 在 $IP$ 首部的字段中，与分片和重组无关的字段是 ( )

(A) 总长度
(B) 标识
(C) 标志
(D) 片偏移

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-42-M07_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：A。理由：IP 首部中专门用于分片与重组的字段是标识、标志、片偏移；总长度只是描述数据报/分片本身的长度，并非分片重组的控制字段。

**解题切入点**：拿到题先定位考点：IP 数据报首部字段功能。分片重组本质上类似算法竞赛中的“大任务拆子任务再合并”：标识相当于“批次 id”，片偏移相当于“子任务在原序列中的下标”，标志相当于“是否为最后一个子任务”，而总长度只是每个子任务的数据量信息，不是分片重组的“控制逻辑”。因此要区分“分片后会被改动的字段”和“专门用于分片重组的字段”。

**推演**：

IP 首部固定部分主要字段如下：

| 字段 | 作用 | 与分片/重组的关系 |
|---|---|---|
| 总长度 | 表示整个 IP 数据报（首部 + 数据）的总字节数 | 分片后每个分片的总长度会被重新计算，但它只是长度信息，不决定如何拆分或如何拼接 |
| 标识（Identification） | 同一原始数据报的所有分片具有相同的标识 | 重组时用于识别哪些分片属于同一个数据报，**相关** |
| 标志（Flags） | 共 3 位，其中 DF 禁止分片，MF 表示“还有分片” | 控制分片行为；MF 用于判断当前分片是否为最后一个，**相关** |
| 片偏移（Fragment Offset） | 指出该分片在原数据报中的相对位置（以 8 字节为单位） | 重组时按片偏移顺序拼接，**相关** |

具体到选项：

- 标识（B）：必选，因为接收方必须依据标识把不同来源的分片区分开。
- 标志（C）：必选，DF 决定能否分片，MF 决定分片是否结束，都直接参与分片重组。
- 片偏移（D）：必选，重组时没有片偏移就不知道每个分片在原数据报中的位置。
- 总长度（A）：虽然分片后每个分片都有总长度，但它只是“这个分片本身有多长”的描述，并不是为了分片/重组而专门设计的字段。即使不分片，总长度也照样存在；分片时修改总长度是“分片带来的结果”，而不是“用于分片/重组的依据”。

因此，与分片和重组无关的字段是总长度，选 A。

**易错点**：

1. **误以为“总长度在分片后会变化，所以相关”**。分片时总长度确实会减小并重新计算，但相关字段是指“主动参与控制分片与重组”的字段；总长度只是被动修改，不属于分片重组的核心字段。
2. **混淆“标识”与“协议”**。标识是标识同一个数据报的不同分片，不是标识上层协议。协议字段与分片无关。
3. **记混片偏移单位**。片偏移以 8 字节为偏移单位，计算分片时要注意数据部分长度必须是 8 的倍数。本题不考计算，但复习时需牢记。
4. **忽略标志位的三位含义**。标志位不是单一位，而是 3 位：第一位保留，第二位 DF（禁止分片），第三位 MF（还有分片）。DF=1 时若需要分片则丢弃并发送 ICMP 差错报文；MF=1 表示后面还有分片，MF=0 表示这是最后一个分片。

**命题规律**：

- 考点定位：IP 协议首部字段的功能，属于网络层基础考点。408 中常以选择题形式考查，也会在综合题中结合 IP 分片计算（给出总长度、片偏移、DF/MF 等）出现。
- 常见变式：
  - “与分片和重组有关的字段是哪些？”答案为标识、标志、片偏移。
  - 给出 MTU，要求计算分片数量、每片长度、片偏移、MF 标志等，注意总长度和片偏移的单位换算。
  - 给出几个分片的标识/片偏移，判断哪些属于同一数据报。
- 复习建议：把 IPv4 首部固定字段逐项理解，熟记每个字段的比特位和含义；重点掌握分片过程的三字段（标识、标志、片偏移），并配合例题练习分片计算。可类比算法竞赛中“分块处理”的思维：批次 id（标识）+ 块偏移（片偏移）+ 结束条件（MF），即可快速定位考点。

# 选择题 第 31 题

![[_Attachments/题目识别/27_王道408-题目/CN-C04-42-M31_题目.png|题目]]

31. 下列对 *IP* 分组的分片和重组的描述中，正确的是（ ）.

(A) *IP* 分组可以被源主机分片，并在中间路由器进行重组

(B) *IP* 分组可以被路径中的路由器分片，并在目的主机进行重组

(C) *IP* 分组可以被路径中的路由器分片，并在中间路由器上进行重组

(D) *IP* 分组可以被路径中的路由器分片，并在最后一跳的路由器上进行重组

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C04-42-M31_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：B。IP 分组可被路径中的路由器分片，但重组只能在目的主机进行。

**解题切入点**：这题考的是 IP 协议的分片与重组机制，属于网络层基础概念。可以类比分布式计算中的“数据分块传输”任务：中间节点只负责把大任务切成小块继续转发，绝不能在中途把小块拼回去，否则会引入额外延迟和复杂度；只有最终接收方（目的主机）才有权恢复完整数据。所以看到“分片”和“重组”这两个动作，先问两个问题：谁可以分片？谁可以重组？对应选项逐一排除即可。

**推演**：

1. IP 分组在传输过程中，可能经过不同 MTU（最大传输单元）的网络。当分组长度超过下一跳网络的 MTU 时，就需要分片。

2. 分片权限：IPv4 规定，源主机和路径中的路由器都可以对 IP 分组进行分片。因为路由器转发的接口可能链路过小，无法直接转发原分组。因此“源主机分片”不是唯一途径，路由器也可以分片。

3. 重组权限：IPv4 规定，分片后的各个 IP 分组（分片）只在目的主机进行重组，中间路由器不负责重组。这是因为：
   - 若在中间路由器重组，则路由器必须等待所有分片到达，可能大量占用缓存，且一旦某个分片丢失，整个分组作废，效率极低；
   - 不同分片可能经由不同路径到达同一路由器，等待重组会破坏无状态转发原则；
   - 最终目的主机拥有完整的接收上下文，重组后上交给传输层，语义最清晰。

4. 逐项分析选项：
   - (A) 说“源主机分片，中间路由器重组”——错在“中间路由器重组”。
   - (B) 说“路径中的路由器分片，目的主机重组”——符合 IPv4 分片与重组规则，正确。
   - (C) 说“路由器分片，中间路由器重组”——错在“中间路由器重组”。
   - (D) 说“路由器分片，最后一跳的路由器重组”——最后一跳路由器仍是路由器，不是目的主机，错。

5. 补充说明：IPv6 中只有源主机可以分片，路由器不再分片，但重组仍然在目的主机进行。本题未限定 IPv4/IPv6，但 408 默认讨论 IPv4，且选项 B 的表述符合 IPv4 标准。

**易错点**：

- 易错选 (C) 或 (D)，误以为“中间路由器”或“最后一跳路由器”可以重组。实际上任何路由器都不重组分片，包括最后一跳路由器（除非该路由器本身就是目的主机的接入设备，但严格说那已不属于“路由器转发”语义）。
- 混淆 IPv4 与 IPv6：IPv6 中路由器不能分片，但重组仍在目的主机。若题目改为 IPv6，则必须选“源主机分片，目的主机重组”。
- 忽略“源主机也可以分片”这一事实：分片并非路由器专属，源主机在发送前也可能根据已知 MTU 分片。
- 分片大小要按 8 字节整数倍（除最后一个分片外）计算偏移，但本题不涉及计算，只需记得“重组只在目的主机”。

**命题规律**：

- 考点定位：网络层 IP 协议的分片与重组机制，常与 MTU、DF/MF 标志、片偏移计算联合出题。
- 常见变式：
  1. 给出 IP 分组长度、MTU，计算分片数、每片长度、片偏移、MF 标志；
  2. 结合路径 MTU 发现（PMTUD）讨论 DF 置位时的行为；
  3. 区分 IPv4 与 IPv6 的分片差异；
  4. 判断某个选项是否“正确”时，常设陷阱在“重组位置”上。
- 复习建议：牢记一句口诀——“分片可中间，重组只在端”。同时熟记 IPv4 分片相关字段：标识（Identification）、标志（DF、MF）、片偏移（Fragment Offset），并能完成简单计算题。

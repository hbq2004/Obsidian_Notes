# 综合题 第 14 题

![[_Attachments/题目识别/27_王道408-题目/CN-C05-53-F14_题目.png|题目]]

14.【2016统考真题】假设下图中的 H3 访问 Web 服务器 S 时，S 为新建的 TCP 连接分配了 20KB（K=1024）的接收缓存，最大段长 MSS=1KB，平均往返时间 RTT=200ms。H3 建立连接时的初始序号为 100，且持续以 MSS 大小的段向 S 发送数据，拥塞窗口初始阈值为 32KB；S 对收到的每个段进行确认，并通告新的接收窗口。假定 TCP 连接建立完成后，S 端的 TCP 接收缓存仅有数据存入而无数据取出。请回答下列问题.

【图：网络拓扑图。包含 Internet、Web 服务器 S（IP 地址 130.18.10.1）、路由器 R1、R2、R3、NAT、DNS 服务器（IP 地址 201.1.1.1）、Switch（交换机）、Hub（集线器）、主机 H1（IP 地址 192.168.3.2）、H2（IP 地址 192.168.3.3）、H3（IP 地址 192.168.3.251）、H4（IP 地址 192.168.3.252）。图中标注有 201.1.2.0/24、201.1.3.0/24、201.1.2.0/25 等网络。右上角文字说明：R1~R3 为路由器；Switch 为 100Base-T 交换机；Hub 为 100Base-T 集线器；主机 H1~H3 的默认域名服务器均配置为 201.1.1.1。】

(1) 在 TCP 连接建立过程中，H3 收到的 S 发送过来的第二次握手 TCP 段的 SYN 和 ACK 标志位的值分别是多少？确认序号是多少？

(2) H3 收到的第 8 个确认段所通告的接收窗口是多少？此时 H3 的拥塞窗口变为多少？H3 的发送窗口变为多少？

(3) H3 的发送窗口等于 0 时，下一个待发送的数据段序号是多少？H3 从发送第 1 个数据段到发送窗口等于 0 时刻为止，平均数据传输速率是多少？（忽略段的传输时延）

(4) 若 H3 与 S 之间通信已经结束，在 t 时刻 H3 请求断开该连接，则从 t 时刻起，S 释放该连接的最短时间是多少？

## DeepSeek V4 Flash Max 解析

**答案**  
(1) SYN=1，ACK=1，确认序号=101。  
(2) 接收窗口=12KB，拥塞窗口=9KB，发送窗口=9KB。  
(3) 下一个待发送数据段序号=20581，平均数据传输速率=20KB/s。  
(4) 最短时间=300ms。

**解题切入点**  
本题综合考查TCP的拥塞控制（慢启动）与流量控制（接收窗口），以及连接建立与释放。解题时首先抓住关键参数：接收缓存20KB、MSS=1KB、初始序号100、拥塞窗口阈值32KB，并注意“仅有数据存入而无取出”意味着接收窗口单调递减。通过模拟发送窗口（min(cwnd, rwnd)）的动态变化，逐步推导各阶段的状态。可类比算法竞赛中的“滑动窗口限流”，慢启动类似指数增长，接收窗口相当于资源上限，需仔细维护窗口边界。

**推演**  
(1) TCP连接建立第二次握手由服务器S发送SYN+ACK段，故SYN=1，ACK=1；确认序号为客户端初始序号加1，即$100+1=101$。

(2) H3数据段序号从101开始，每段1KB（1024B）。S初始接收窗口$rwnd=20\text{KB}$，每收一段减少1KB。H3拥塞窗口初始$cwnd=1\text{KB}$（默认），慢启动阈值$32\text{KB}$，每收到一个ACK，$cwnd$增加1KB。模拟发送过程（也可用RTT轮次分析）：  
- 第1~7个ACK后，S已收7KB，$rwnd=13\text{KB}$，$cwnd=8\text{KB}$。  
- 第8个ACK（对应段8）到达时，S已收8KB，通告$rwnd=12\text{KB}$；此时$cwnd$由8增至9KB；发送窗口$=\min(cwnd, rwnd)=9\text{KB}$。  
故答案：接收窗口12KB，拥塞窗口9KB，发送窗口9KB。

(3) 当发送窗口为0时，$rwnd=0$，即S已收满20KB。共发送20个数据段，段20结束序号$=101+20\times1024-1=20580$，故下一待发序号$=20581$。  
从发送第1段到收到段20的ACK（发送窗口变为0）经历5个RTT：第1RTT发1段，第2RTT发2段，第3RTT发4段，第4RTT发8段，第5RTT发5段，总时间$5\times200\text{ms}=1000\text{ms}=1\text{s}$，总数据20KB，平均速率$\frac{20\text{KB}}{1\text{s}}=20\text{KB/s}$。

(4) H3主动断开连接，发送FIN。S收到FIN后立即发送ACK+FIN（假设无数据），H3收到后发送ACK。S从收到FIN到收到ACK需1RTT（$\frac{RTT}{2}$发送FIN，$\frac{RTT}{2}$接收ACK），加上从t到S收到FIN的$\frac{RTT}{2}$，故最短时间$=1.5\times200\text{ms}=300\text{ms}$。

**易错点**  
- 忽略初始拥塞窗口为1MSS（考研常按1处理，若默认其他值需按题目说明）。  
- 误认为发送窗口仅由拥塞窗口决定，忽略接收窗口限制。  
- 序号计算错误：初始序号100，第一个数据段从101开始，且MSS=1KB=1024B。  
- 平均速率计算时，错误地将时间截止到发送完最后一个段，而非收到确认使窗口变为0的时刻。  
- 连接释放时间计算中，忽略S收到FIN后的传输延迟，或认为S能立即关闭（实际需等待ACK）。

**命题规律**  
- 考点：TCP拥塞控制（慢启动、拥塞窗口）、流量控制（接收窗口）、连接管理（三次握手、四次挥手）。  
- 常见变式：改变接收缓存大小、MSS、RTT，或加入拥塞避免阶段、超时重传等。  
- 复习建议：熟练掌握TCP滑动窗口机制，理解慢启动与拥塞避免的窗口变化，会模拟丢包情况；注意初始条件（如初始序号、窗口单位）和常见默认值（如初始cwnd=1MSS）。

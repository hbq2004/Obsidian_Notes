# 选择题 第 26 题

![[_Attachments/题目识别/27_王道408-题目/CN-C05-53-M26_题目.png|题目]]

26. 假设 TCP 客户与 TCP 服务器的通信已结束，端到端的往返时间为 $RTT$。$t$ 时刻 TCP 客户请求断开连接，则从 $t$ 时刻起 TCP 服务器释放该连接的最短时间是 ( )

(A) $0.5RTT$
(B) $1RTT$
(C) $1.5RTT$
(D) $2RTT$

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C05-53-M26_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：C。从客户请求断开连接（发送 FIN）到服务器释放连接（收到对 FIN 的 ACK），最短需要 $1.5RTT$。

**解题切入点**：首先明确 TCP 连接释放的四次挥手过程，但服务器可以立即响应，合并 ACK 和 FIN 报文段，从而缩短时间。类似算法竞赛中通过构造（如辅助数组）来优化时间复杂度，这里通过合并报文段来优化时间。

**推演**：设 $t=0$ 时客户发送 FIN，单向传播时延为 $\frac{RTT}{2}$。
- $t=\frac{RTT}{2}$：服务器收到 FIN，立即发送 ACK 和 FIN（可合并为一个报文段）。
- $t=RTT$：客户收到 ACK 和 FIN，立即发送 ACK。
- $t=RTT+\frac{RTT}{2}=1.5RTT$：服务器收到 ACK，进入 CLOSED 状态。
因此，服务器释放连接的最短时间为 $1.5RTT$。

**易错点**：容易误以为必须四次挥手且不能合并，从而认为需要 $2RTT$；或者忽略服务器响应时间，误以为 $1RTT$。注意，服务器收到 FIN 后必须发送 ACK，但 FIN 可随后立即发送，因此客户收到 ACK 和 FIN 的时间是 $RTT$，再发送 ACK 到服务器需 $\frac{RTT}{2}$，总时间 $1.5RTT$。

**命题规律**：TCP 连接释放是考研常考知识点，重点考察状态转换和时间计算。常见变式包括计算客户释放连接的时间（需考虑 $2MSL$）或同时关闭的情况。复习时应熟练掌握 TCP 状态变迁图，注意主动关闭和被动关闭的时间差异。

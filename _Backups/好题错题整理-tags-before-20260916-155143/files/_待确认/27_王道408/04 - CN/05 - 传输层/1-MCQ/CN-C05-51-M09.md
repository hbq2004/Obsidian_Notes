# 选择题 第 9 题

![[_Attachments/题目识别/27_王道408-题目/CN-C05-51-M09_题目.png|题目]]

9. 下列关于 $TCP$ 和 $UDP$ 端口的说法中,正确的是 ( ).

(A) $TCP$ 和 $UDP$ 分别拥有自己的端口号,它们互不干扰,可以共存于同一台主机.

(B) $TCP$ 和 $UDP$ 分别拥有自己的端口号,但它们不能共存于同一台主机.

(C) $TCP$ 和 $UDP$ 的端口没有本质区别,但它们不能共存于同一台主机.

(D) 当一个 $TCP$ 连接建立时,它们互不干扰,不能共存于同一台主机.

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C05-51-M09_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：A  
TCP 与 UDP 拥有相互独立的端口号空间，可同时存在于同一台主机且互不干扰。

**解题切入点**  
本题核心考察传输层端口的概念，重点在于理解端口号的作用域与协议绑定。可以把 TCP 和 UDP 比喻成算法竞赛中两套独立的编号系统（例如 ACM 和 OI 各自使用自己的题目编号），即使出现相同的编号（如“1001”），由于属于不同系统，不会发生冲突，且可以同时运行而互不影响。

**推演**  
传输层协议 $\text{TCP}$ 和 $\text{UDP}$ 各自维护独立的端口号空间，其数值范围均为 $0 \sim 65535$，但逻辑上完全隔离。这意味着同一台主机上可以同时存在一个 $\text{TCP}$ 端口 $53$ 和一个 $\text{UDP}$ 端口 $53$（例如 DNS 服务同时使用这两个端口），它们互不干扰。因此：  

- **选项 A** 正确描述了这一特性，即“分别拥有自己的端口号，互不干扰，可以共存”。  
- **选项 B** 错误，因为二者完全能够共存。  
- **选项 C** 错误，端口有协议本质区别（所属协议栈不同），且能共存。  
- **选项 D** 错误，TCP 连接建立过程与端口独立性无关，共存也是允许的。  

故正确选项为 A。

**易错点**  
- **错误概念**：认为端口号在整个主机中必须全局唯一，忽略协议类型。  
- **规避方法**：牢记端口号只在所属协议内部唯一，TCP 和 UDP 的端口空间是相互独立的。  
- **常见混淆**：将“端口号范围相同”误解为“端口冲突”，需明确区分“相同数值”与“同一资源”。

**命题规律**  
- **考点定位**：传输层基础概念，端口号的作用与独立性。  
- **常见变式**：判断同一端口号能否同时用于 TCP 和 UDP；问 TCP 与 UDP 通信是否受相同端口号影响。  
- **复习建议**：理解端口号是“协议相关”的，不同协议即使使用相同数字也无冲突；结合应用实例（如 DNS 使用 TCP 53 和 UDP 53）加深记忆。

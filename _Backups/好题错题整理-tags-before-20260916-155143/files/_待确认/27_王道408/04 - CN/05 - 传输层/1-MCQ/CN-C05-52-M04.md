# 选择题 第 4 题

![[_Attachments/题目识别/27_王道408-题目/CN-C05-52-M04_题目.png|题目]]

4. UDP 数据报中的长度字段（  ）

(A) 不记录数据的长度
(B) 只记录首部的长度
(C) 只记录数据部分的长度
(D) 包括首部和数据部分的长度

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C05-52-M04_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：D。UDP 长度字段的值为 UDP 首部（固定 8 字节）与数据部分长度之和，即整个 UDP 数据报的长度。

**解题切入点**：拿到题目先定位协议报文格式。UDP 是传输层协议，其首部只有 4 个字段：源端口、目的端口、长度、校验和。本题就是考查“长度字段的覆盖范围”。这类似算法竞赛中看到一个结构体里的 `size` 字段，需要先确认它表示整个结构体占用空间还是仅数据域大小；不能想当然地当成数据长度。同时，协议分层如同分治/封装，每层只负责本层头部与载荷，UDP 长度是传输层封装长度，不包含 IP 首部。

**推演**：UDP 数据报由 UDP 首部和数据部分组成。UDP 首部固定为 8 字节，包括：

- 源端口：16 位；
- 目的端口：16 位；
- 长度：16 位；
- 校验和：16 位。

设 UDP 数据部分长度为 $d$ 字节，则 UDP 数据报总长度为 $8 + d$ 字节。UDP 长度字段的值为：

$$
L = 8 + d
$$

因此：

- 若 $d = 0$，则 $L = 8$，这是 UDP 长度字段的最小值；
- 长度字段不是只记录数据长度，因为 $L$ 中包含了 8 字节首部；
- 长度字段也不是只记录首部长度，否则 $L$ 恒为 8，无法表示不同长度的数据报；
- 长度字段当然记录了数据部分的长度，但它同时包含首部长度，因此完整语义是“包括首部和数据部分的长度”。

所以正确选项为 D。

**易错点**：

1. 误选 C：把 UDP 长度字段当成纯数据长度，忘记 UDP 首部固定 8 字节也要计入。记住公式 $L = 8 + d$，已知长度 $L$ 求数据长度时用 $d = L - 8$。
2. 误选 B：如果只记录首部，则所有 UDP 数据报的长度字段都相同，无法区分数据报大小，不符合设计目的。
3. 与 IP 总长度混淆：IP 总长度包含 IP 首部，而 UDP 长度不包含 IP 首部，只包含 UDP 首部 + UDP 数据。计算时应先减去 IP 首部长度。
4. 单位混淆：UDP 长度字段以字节为单位，不是以位为单位。
5. UDP 校验和中使用的伪首部包含 UDP 长度字段，但伪首部本身不是 UDP 数据报的一部分，不计入该长度字段。

**命题规律**：本题属于传输层 UDP 报文格式的基础考点。常见变式有：已知 UDP 长度字段值为 $L$，求数据部分长度为 $L - 8$；已知 IP 总长度为 $T$、IP 首部长度为 $I$，则 UDP 数据报长度为 $T - I$，UDP 数据长度为 $T - I - 8$。复习时建议画图记忆 UDP 首部四个字段，并与 TCP 首部、IP 首部对照，理解“每一层长度字段覆盖本层首部与载荷”的封装思想。

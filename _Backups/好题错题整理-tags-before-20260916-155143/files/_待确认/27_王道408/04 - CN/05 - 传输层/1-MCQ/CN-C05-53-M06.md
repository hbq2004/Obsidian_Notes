# 选择题 第 6 题

![[_Attachments/题目识别/27_王道408-题目/CN-C05-53-M06_题目.png|题目]]

6. 下列几种字段中,包含在 TCP 首部中而不包含在 UDP 首部中的是( )
(A) 目的端口号
(B) 序列号(序号)
(C) 检验和
(D) 目的 IP 地址

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C05-53-M06_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：B（序列号）。TCP 首部有序号，而 UDP 首部没有序号；目的端口号和检验和二者都有，目的 IP 地址属于 IP 首部。

**解题切入点**：拿到题目先明确“这是传输层协议首部字段的集合对比题”。可以类比算法竞赛中比较两个结构体/集合：先分别列出 TCP 首部和 UDP 首部的“字段集合”，再求差集。本题相当于问：哪个元素属于 $F_{\text{TCP}}$ 而不属于 $F_{\text{UDP}}$。同时要注意“分层协议”思想：IP 地址属于网络层，不应混入传输层首部。

**推演**：

TCP 首部主要字段为：
$$
F_{\text{TCP}}=\{\text{源端口},\text{目的端口},\text{序号},\text{确认号},\text{数据偏移},\text{保留},\text{标志位},\text{窗口},\text{检验和},\text{紧急指针},\text{选项}\}
$$

UDP 首部字段为：
$$
F_{\text{UDP}}=\{\text{源端口},\text{目的端口},\text{长度},\text{检验和}\}
$$

对选项逐一判断：

| 选项 | 字段 | TCP 首部 | UDP 首部 |
|---|---|---|---|
| A | 目的端口号 | 有 | 有 |
| B | 序列号（序号） | 有 | 无 |
| C | 检验和 | 有 | 有 |
| D | 目的 IP 地址 | 无 | 无 |

因此，满足“包含在 TCP 首部中而不包含在 UDP 首部中”的只有序列号。

补充说明：TCP 伪首部在校验和计算时会包含源 IP 地址、目的 IP 地址、协议号、TCP 长度等，但伪首部不随 TCP 报文段传输，也不属于 TCP 首部的实际字段。UDP 校验和计算也会用到伪首部，但目的 IP 地址同样不属于 UDP 首部。

**易错点**：

- 易误选 C“检验和”：TCP 和 UDP 首部都包含检验和字段，不能因为 UDP 不可靠就认为它没有检验和。
- 易误选 A“目的端口号”：TCP 和 UDP 都是传输层协议，都需要通过目的端口号交付给上层应用。
- 易误选 D“目的 IP 地址”：目的 IP 地址属于 IP 数据报首部，不是传输层首部；TCP 伪首部虽然参与校验和计算，但不是 TCP 首部的一部分。
- 常见误区是把“序号”理解成所有传输数据都需要，实际上只有面向字节流、需要可靠传输的 TCP 才有序号，UDP 没有。

**命题规律**：本题属于“TCP/UDP 报文段首部字段辨析”，是 408 计算机网络中传输层的高频基础考点。常见变式有：“TCP 首部与 UDP 首部共有的字段”“UDP 首部有而 TCP 首部没有的字段”“伪首部中出现的字段”等。复习时应将 TCP 首部、UDP 首部、IP 首部字段分别列表记忆，并结合“应用层→传输层→网络层”的封装顺序理解字段归属。

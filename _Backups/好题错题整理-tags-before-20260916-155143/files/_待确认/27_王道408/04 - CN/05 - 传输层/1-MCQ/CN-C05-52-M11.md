# 选择题 第 11 题

![[_Attachments/题目识别/27_王道408-题目/CN-C05-52-M11_题目.png|题目]]

11.一个 UDP 数据报的数据字段长度为 $9192\mathrm{B}$,若在数据链路层要采用以太网来传送,则应当将其划分为 IP 数据报片的片数是(  )

(A) 6  
(B) 7  
(C) 8  
(D) 9

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C05-52-M11_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：B。UDP 数据报总长度为 $8+9192=9200\ \mathrm{B}$，而以太网 MTU 为 $1500\ \mathrm{B}$，去掉 IP 首部 $20\ \mathrm{B}$ 后每片最多携带 $1480\ \mathrm{B}$，所以片数为  
$$\left\lceil \frac{9200}{1480}\right\rceil=7.$$

**解题切入点**：这题本质是一个“分块计数”问题：已知总数据量和单块容量上限，求最少块数，即“向上取整”。竞赛中类似“把长度为 $n$ 的数组分成若干块，每块大小不超过 $k$，求块数”，直接算 $\lceil n/k\rceil$ 即可。但网络分层就像给每个数据块加头部开销：以太网 MTU 限制的是整个 IP 数据报，不是 IP 数据部分，所以必须先减去 IP 首部 $20\ \mathrm{B}$，得到每片最多携带的上层数据量 $1480\ \mathrm{B}$。

**推演**：

1. 以太网 MTU 为 $1500\ \mathrm{B}$，即一个 IP 数据报的总长度最多为 $1500\ \mathrm{B}$。
2. IPv4 首部固定长度为 $20\ \mathrm{B}$，因此一个 IP 分片最多能携带的上层数据为  
   $$1500-20=1480\ \mathrm{B}.$$
3. UDP 数据报由 UDP 首部和 UDP 数据字段组成。题中给出 UDP 数据字段长度为 $9192\ \mathrm{B}$，UDP 首部占 $8\ \mathrm{B}$，所以 UDP 数据报总长度为  
   $$9192+8=9200\ \mathrm{B}.$$
4. 这个 UDP 数据报整体作为 IP 层的数据部分进行分片，每片最多携带 $1480\ \mathrm{B}$，所以片数为  
   $$\left\lceil \frac{9200}{1480}\right\rceil = 7.$$
5. 验证：  
   $$6\times 1480=8880<9200,$$  
   而 7 片容量为  
   $$7\times 1480=10360\ge 9200.$$  
   因此前 6 片每片数据载荷为 $1480\ \mathrm{B}$，最后一片数据载荷为  
   $$9200-6\times1480=320\ \mathrm{B}.$$

分片情况如下：

| 片序 | 数据载荷 | 片总长度 | 片偏移 | MF |
|---|---:|---:|---:|---:|
| 1 | 1480 B | 1500 B | 0 | 1 |
| 2 | 1480 B | 1500 B | 185 | 1 |
| 3 | 1480 B | 1500 B | 370 | 1 |
| 4 | 1480 B | 1500 B | 555 | 1 |
| 5 | 1480 B | 1500 B | 740 | 1 |
| 6 | 1480 B | 1500 B | 925 | 1 |
| 7 | 320 B | 340 B | 1110 | 0 |

所以应当划分为 7 个 IP 数据报片。

**易错点**：

- 容易漏加 UDP 首部 $8\ \mathrm{B}$。本题中 $9192$ 是 UDP 数据字段长度，不是 UDP 数据报总长度。
- 容易直接用 $1500$ 作为每片数据载荷上限，忘记减去 IP 首部 $20\ \mathrm{B}$。正确单片数据上限是 $1480\ \mathrm{B}$。
- 忘记 IP 分片偏移以 $8\ \mathrm{B}$ 为单位，因此除最后一片外，每片数据载荷必须是 $8$ 的倍数。这里 $1480=185\times8$，恰好满足。
- 混淆“IP 数据报总长度”和“IP 数据部分长度”。IP 数据报总长度包含 IP 首部，而分片计数一般看需要承载的上层数据总量。

**命题规律**：这是 IPv4 分片的经典计算题，核心考点是以太网 MTU、IP 首部长度、UDP/TCP 首部长度和分片偏移单位。常见变式有：给出 IP 数据报总长度求分片数、求各片偏移量、判断 MF/DF 标志，或者结合 UDP/TCP 首部求“最小分片数”。复习时应牢记：  
$$\text{每片最大数据载荷}=\text{MTU}-\text{IP首部长度},$$  
$$\text{分片数}=\left\lceil\frac{\text{IP层待传数据总长度}}{\text{每片最大数据载荷}}\right\rceil.$$  
同时要建立“逐层封装”模型：应用数据 → UDP/TCP 首部 → IP 首部 → 以太网帧，才能准确判断 MTU 限制的是哪一层。

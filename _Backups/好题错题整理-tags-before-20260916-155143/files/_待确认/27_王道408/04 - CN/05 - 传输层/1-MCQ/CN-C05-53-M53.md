# 选择题 第 53 题

![[_Attachments/题目识别/27_王道408-题目/CN-C05-53-M53_题目.png|题目]]

53.【2020 统考真题】若主机甲与主机乙建立 TCP 连接时, 发送的 SYN 段中的序号为 1000, 在断开连接时, 主机甲发送给主机乙的 FIN 段中的序号为 5001, 则在无任何重传的情况下, 甲向乙已经发送的应用层数据的字节数为 ( ).

A. 4002

B. 4001

C. 4000

D. 3999

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C05-53-M53_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：C。甲向乙已经发送的应用层数据字节数为 $5001-1000-1=4000$；SYN 占一个序号，FIN 的序号是数据发送完后的下一个待用序号，不计入应用数据。

**解题切入点**：拿到题目先抓“TCP 序号计数”和“SYN、FIN 各占一个序号”。可以把 TCP 发送序列号理解为一个全局计数器：SYN 相当于先让计数器加 1，之后每发送 1 字节应用数据计数器再加 1，FIN 报文中的序号就是“当前计数器快照”，而不是再执行一次加 1 后的值。

**推演**：

- 建立连接时，甲发出的 SYN 段序号为 $1000$，所以甲的初始发送序号 $\mathrm{ISN}=1000$。
- SYN 虽然不携带应用层数据，但占用一个序号。因此 SYN 之后，应用层数据的第一个字节从序号 $1001$ 开始编号。
- 设甲向乙发送的应用层数据为 $N$ 字节，则这些数据字节占用的序号为
  $$1001,\ 1002,\ \dots,\ 1000+N.$$
- 发送完这些数据后，甲的下一个待用序号是
  $$1001+N.$$
- 断开连接时，甲发送的 FIN 段序号是 $5001$，因此
  $$1001+N=5001,$$
  解得
  $$N=4000.$$

等价地：
$$N=\text{FIN 序号}-\text{SYN 序号}-1=5001-1000-1=4000.$$

验证：应用数据占用序号 $1001\sim 5000$，共
$$5000-1001+1=4000$$
个字节。FIN 本身占用序号 $5001$，但它不属于应用层数据。

**易错点**：

- 直接算 $5001-1000=4001$，会忘记 SYN 占一个序号。
- 多减 FIN：$5001-1000-2=3999$。FIN 虽然占一个序号，但题目统计的是“已经发送的应用层数据”，FIN 的序号是数据之后的下一个序号，不能再减一个 FIN。
- 若把 $1000$ 到 $5001$ 的所有序号端点都数进去，会得到 $4002$，这是把 SYN 和 FIN 都当成了数据字节。
- 注意只统计甲发送给乙的数据，乙发送给甲的数据不影响甲的发送序号。

**命题规律**：考点是 TCP 报文段序号与字节流编号，以及 SYN、FIN 对序号的消耗。常见变式有：已知建立连接时的 SYN 序号和断开连接时的 FIN/ACK 序号，求实际数据量；或结合三次握手、累计确认求下一个待发送序号。复习时要记住：每个数据字节占用一个序号，SYN 和 FIN 各占一个序号，ACK 不占序号。建议画 TCP 连接建立、数据传输、连接释放的时间轴，并在每个报文段上标注 seq 和 ack，熟练后可直接用
$$N=\text{FIN 序号}-\text{ISN}-1$$
求解（纯 FIN 且无重传、无数据的情况）。

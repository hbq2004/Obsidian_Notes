# 选择题 第 4 题

![[_Attachments/题目识别/27_王道408-题目/CN-C05-53-M04_题目.png|题目]]

4. 下列几种描述中，（\_）不是 \textit{TCP} 服务的特点.

A. 字节流
B. 全双工
C. 可靠
D. 支持广播

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C05-53-M04_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：D。支持广播不是 TCP 服务的特点；TCP 是点对点的传输层协议，只支持单播，不支持广播。

**解题切入点**：拿到题先明确题目在问“TCP 服务的特点”，属于传输层 TCP/UDP 协议特性对比。可以这样比喻：在算法竞赛中，TCP 就像“带确认的、按字节流处理的点对点管道”，而广播更像“向全体节点散播消息”的广播式传播；TCP 没有“广播”这个操作，只有 UDP 等才支持广播。

**推演**：

TCP（Transmission Control Protocol）是面向连接的、可靠的、基于字节流的传输层协议。其核心特点包括：

1. **面向连接**：通信前需经过三次握手建立连接，通信结束后四次挥手释放连接。
2. **可靠传输**：通过序号、确认、超时重传、流量控制、拥塞控制等机制保证数据按序、无差错地到达。
3. **字节流**：TCP 把应用层交下来的数据看成无结构的字节流，不保留消息边界。
4. **全双工**：TCP 连接的两端可以在任何时候发送和接收数据，两个方向的数据流相互独立。
5. **点对点**：TCP 连接只能连接两个端点，一台主机不能通过一个 TCP 连接同时向多个主机发送数据，因此不支持广播。

需要特别区分：

- TCP 是**一对一的单播通信**，不支持一对多的广播或组播。
- UDP 是无连接的、不可靠的、基于数据报的协议，**支持广播和组播**。

综上，选项 A、B、C 都是 TCP 服务的特点，D“支持广播”不是 TCP 的特点。因此选 D。

**易错点**：

- **误以为 TCP 可靠=绝对不丢**：TCP 的可靠是通过确认和重传实现的逻辑可靠性，物理链路中断时数据仍可能丢失，但协议层会检测并重传。
- **误以为“字节流”支持消息边界**：TCP 是字节流，不保留应用消息边界；UDP 才保留消息边界。
- **混淆“全双工”与“半双工”**：TCP 是真正意义上的全双工，两端可同时收发；若只说“双向通信”，还需进一步判断是否同时。
- **误认为 TCP 也能支持广播**：广播需要一对多发送，TCP 必须建立点到点连接，因此无法实现广播；广播/组播是 UDP 的特性。

**命题规律**：该题属于 408 计算机网络中“传输层”高频基础题，考查 TCP 与 UDP 的核心特点辨析。常见变式有：

- 下列哪个不是 UDP 的特点？
- TCP 与 UDP 在“连接性、可靠性、字节流/报文流、单播/广播”上的对比。
- 结合“三次握手、四次挥手”考查 TCP 面向连接的特点。

复习建议：将 TCP/UDP 特点做成对比表格，重点记忆关键差异：

| 协议 | 连接性 | 可靠性 | 传输单位 | 通信方式 |
|---|---|---|---|---|
| TCP | 面向连接 | 可靠 | 字节流 | 单播 |
| UDP | 无连接 | 不可靠 | 报文 | 单播/广播/组播 |

同时要理解这些特点背后的机制（如 TCP 的序号、确认、重传，UDP 的无状态性），这样在综合题中才能灵活判断。

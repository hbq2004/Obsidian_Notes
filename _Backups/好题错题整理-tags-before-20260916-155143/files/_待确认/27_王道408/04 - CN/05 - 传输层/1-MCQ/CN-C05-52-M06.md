# 选择题 第 6 题

![[_Attachments/题目识别/27_王道408-题目/CN-C05-52-M06_题目.png|题目]]

6. 下列关于 UDP 的描述,正确的是（ ）

(A) 给出数据的按序投递
(B) 不允许多路复用
(C) 拥有流量控制机制
(D) 是无连接的

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C05-52-M06_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：D（UDP 是无连接的）。UDP 不提供可靠传输、不保证按序到达、无流量控制，但支持多路复用/多路分解，且通信前无需建立连接。

**解题切入点**：看到“下列关于 UDP 的描述”，先锁定传输层协议的两大阵营：UDP 与 TCP。可以类比算法竞赛中的“暴力和优化”：TCP 是自带排序、重试、限流的“重型封装”，UDP 是“裸传输”——直接扔数据包，不保证送达顺序，也不管网络拥不拥挤。题目问“正确的是”，本质上是在排除那些把 TCP 特性安到 UDP 头上的选项。抓住“无连接”这个最关键标签，立刻定位到 D。

**推演**：  
UDP（User Datagram Protocol，用户数据报协议）在 RFC 768 中定义，其特点是：

1. **无连接**：发送数据前不需要三次握手，也不维护连接状态。每个 UDP 报文独立发送，因此选项 D 正确。
2. **不保证按序投递**：UDP 把数据报交给 IP 层后，各数据报可能走不同路径，到达顺序可能乱序，接收方也不负责重排。因此 A“给出数据的按序投递”错误，这是 TCP 的职责。
3. **支持多路复用/多路分解**：UDP 通过源端口号和目的端口号实现多路复用与多路分解。多个应用进程可以各自使用不同端口同时发送/接收，因此 B“不允许多路复用”错误。
4. **无流量控制**：UDP 没有滑动窗口、没有拥塞控制，也不会根据接收方能力调整发送速率，因此 C“拥有流量控制机制”错误。

综上，只有 D 正确。形式化地看：设 $P$ 为“UDP 具有的性质”，则  
$$
P_{\text{UDP}} = \{\text{无连接}, \text{尽力而为}, \text{支持多路复用}, \text{报文头部开销小}\}
$$  
而按序投递、流量控制、可靠传输都不属于 $P_{\text{UDP}}$，所以排除 A、B、C。

**易错点**：  
- **把“无连接”误认为“不可复用”**：无连接指的是不需要建立连接，而不是不能多路复用。端口机制依然存在，所以 B 是典型干扰项。  
- **把“不保证按序投递”与“错误”混淆**：UDP 确实可能乱序，但题目问的是“正确的是”，不能选错误的描述。  
- **把“无流量控制”理解成“没有拥塞控制”**：UDP 既无流量控制也无拥塞控制，但两者不同。流量控制是接收方约束发送方，拥塞控制是网络约束发送方；UDP 两者都没有，所以 C 错误。  
- **只看“UDP 不可靠”就选 D，但不确定其他选项**：建议逐个排除，避免被“按序投递”这类强干扰项迷惑。

**命题规律**：  
这是传输层基础送分题，几乎每年 408 都会以选择或填空形式考查 UDP 与 TCP 的对比。常见变式包括：  
- “下列关于 TCP 的描述正确的是”与本题对称。  
- “UDP 适合哪些应用”如 DNS、视频直播、语音通话，因为容忍丢包但要求低延迟。  
- “UDP 报文首部字段”考查源端口、目的端口、长度、校验和，共 8 字节。  
复习建议：把 TCP 和 UDP 的差异做成对比表——连接、可靠、按序、流量控制、拥塞控制、首部开销、复用方式、适用场景。理解“无连接 + 尽力而为”是 UDP 的核心，其他特性都能从这两点推导出来。

# 选择题 第 9 题

![[_Attachments/题目识别/27_王道408-题目/CN-C05-52-M09_题目.png|题目]]

9. 下列关于 $UDP$ 检验的描述中,错误的是 ( )

A. $UDP$ 检验和字段是可选的,若源主机不想计算检验和,则应置其为全 0

B. 在计算检验和的过程中,需要生成一个伪首部,源主机需要把该伪首部发送给目的主机

C. 检验出 $UDP$ 数据报出错时,可以丢弃或交付给上层

D. $UDP$ 检验和还能检验 $IP$ 数据报的源 $IP$ 地址和目的 $IP$ 地址

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C05-52-M09_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：B。伪首部只参与 UDP 检验和的计算，并不会随 UDP 数据报发送给目的主机；目的主机需要根据 IP 首部中的源/目的 IP、协议号等信息重新构造伪首部进行校验。其余选项：A 是 IPv4 下 UDP 检验和可选的约定；C 是 UDP 检错后的处理方式；D 由伪首部中的源/目的 IP 地址保证。

**解题切入点**：  
看到“UDP 检验”，立即定位到传输层 UDP 的差错检测，核心是“伪首部 + 反码求和”。可以把伪首部理解成竞赛里构造哈希时的“辅助元数据”或“辅助状态”：它参与计算，但不进入最终发送的有效载荷；接收端必须能由本地已有信息重建同样的状态，才能完成校验。本题问“错误的是”，B 直接说“源主机需要把伪首部发送给目的主机”，这与伪首部的定义矛盾，应优先锁定。

**推演**：  

UDP 检验和的覆盖范围是：

$$
\text{伪首部} + \text{UDP 首部} + \text{UDP 数据}
$$

IPv4 下的伪首部为 12 字节：

$$
\underbrace{\text{源 IP 地址}}_{4\text{ B}}+
\underbrace{\text{目的 IP 地址}}_{4\text{ B}}+
\underbrace{0}_{1\text{ B}}+
\underbrace{\text{协议号}=17}_{1\text{ B}}+
\underbrace{\text{UDP 长度}}_{2\text{ B}}
$$

源端计算检验和的过程：

1. 若 IPv4 下不想使用 UDP 检验和，则将检验和字段置为全 0。
2. 若使用检验和，则在 UDP 报文前临时拼接伪首部；若数据为奇数字节，则计算时补一个 0 字节，但不发送该补位字节。
3. 将伪首部 + UDP 首部 + UDP 数据按 16 bit 分组，做二进制反码求和。
4. 将求和结果取反，作为检验和填入 UDP 首部；若计算出的检验和为 0，则发送时填全 1，避免与“未计算检验和”的 0 混淆。

目的端校验时，同样根据收到的 IP 首部和 UDP 首部重建伪首部，然后对“伪首部 + UDP 数据报（含收到的检验和字段）”做反码求和。若结果为全 1，则认为无误；否则说明出错。

逐项判断：

- A：正确。IPv4 下 UDP 检验和字段可以置 0，表示源主机未计算检验和。
- B：错误。伪首部只在计算检验和时临时使用，不随报文发送。
- C：正确。检测到 UDP 数据报出错时，可以丢弃，也可以交付给上层并给出差错报告；但 UDP 不会自动重传。
- D：正确。伪首部包含源 IP 地址和目的 IP 地址，因此 UDP 检验和能检验这两个地址是否出错。

**易错点**：  

- 误以为伪首部会随 UDP 数据报一起发送。实际上伪首部是“虚拟”的，只参与计算，不占传输带宽。
- 误以为 UDP 检验和在任何场景下都可选。严格说，IPv4 下 UDP 检验和可选；IPv6 下 UDP 检验和是必选的。
- 混淆全 0 与全 1：源主机不用检验和时填全 0；计算出的检验和为 0 时发送全 1。
- 误以为 UDP 检验和能检验整个 IP 首部。伪首部只涉及源/目的 IP、协议号和 UDP 长度，并不检验 TTL 等 IP 首部字段。
- 对 C 容易产生疑问：检测出错后是否可以交付上层？教材中允许“丢弃或交付上层并给出差错报告”，但这不是可靠传输。

**命题规律**：  
本考点在 408 中通常以概念辨析题出现，考查 UDP 检验和的可选性、伪首部组成、检错后的处理方式。常见变式包括：

- 给出若干字段，判断哪些属于 TCP/UDP 伪首部；
- 比较 TCP 与 UDP 检验和，TCP 检验和必选；
- 结合 IPv6 判断“UDP 检验和可选”是否正确；
- 判断 UDP 检验和能否检验 IP 地址、端口、长度等。

复习时建议把 UDP、TCP、IPv4、IPv6 的检验和规则做成对比表，重点记住：伪首部“参与计算但不传输”，以及它包含源 IP、目的 IP、协议号、TCP/UDP 长度。

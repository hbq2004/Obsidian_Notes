# 选择题 第 13 题

![[_Attachments/题目识别/27_王道408-题目/CN-C05-52-M13_题目.png|题目]]

13. 在进行跨网络的 IP 通信时,不考虑 NAT,传输层使用 UDP 进行封装,数据链路层采用以太网 MAC 帧进行封装,则下列字段中一定保持不变的是（ ）

I. UDP 总长度    II. UDP 检验和    III. FCS 帧检验序列    IV. 目的 MAC 地址

V. 目的 IP 地址    VI. IP 检验和

A. V
B. I、II、V
C. IV、VI
D. III、IV、V

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C05-52-M13_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：B。跨网络且无 NAT 时，UDP 报文端到端不变，目的 IP 地址也不变；而 MAC 地址、FCS、IP 检验和都会逐跳或逐帧发生变化。

**解题切入点**：先区分“端到端”字段和“逐跳”字段。可以把整个通信看成一次在分布式系统上的数据传递：UDP/IP 的端到端信息类似于算法中对象的“全局 key/ID”，中间路由器不改；MAC 地址和 FCS 则类似于每次进入新容器时重新打包的“局部缓存/校验值”。跨网络的关键是路由器参与，路由器的处理边界在网络层：它只看并修改 IP 头，不碰 UDP，但每转发一次都会重新封装以太网帧。

**推演**：

设源主机为 $S$，目的主机为 $D$，中间经过路由器 $R_1, R_2, \dots$。

逐项判断：

1. **I. UDP 总长度**：保持不变。  
   UDP 首部中的“长度”字段 $L_{\mathrm{UDP}}$ 表示 UDP 首部加 UDP 数据的长度，它在源端生成后就是整个 UDP 报文的一个固有属性。中间路由器只处理 IP 层，不会修改 UDP 首部。即使 IP 层发生分片，也只改变 IP 首部的“总长度”“片偏移”“MF”等字段，UDP 首部中的长度字段仍保持原值。

2. **II. UDP 检验和**：保持不变。  
   UDP 检验和计算时使用伪首部、UDP 首部和数据。伪首部中包含源 IP 地址和目的 IP 地址。题目明确“不考虑 NAT”，因此源/目的 IP 地址不变；UDP 协议号固定，UDP 长度和数据也不变，所以 UDP 检验和无需重新计算，保持不变。

3. **III. FCS 帧检验序列**：一定变化。  
   FCS 是以太网帧的 CRC 校验值，由每个发送以太网帧的节点计算。跨网络时，路由器会拆除旧帧、重新封装新帧，帧中的目的 MAC、源 MAC 等都会改变，FCS 必然重新计算。

4. **IV. 目的 MAC 地址**：一定变化。  
   在以太网中，MAC 地址是逐跳寻址的。源主机先把 IP 包发给默认网关，此时目的 MAC 是网关 MAC；路由器再把它封装成下一跳的帧，目的 MAC 变成下一跳设备的 MAC；最后一跳目的 MAC 才是目的主机 MAC。因此目的 MAC 地址在整个过程中不保持恒定。

5. **V. 目的 IP 地址**：保持不变。  
   不考虑 NAT 时，IP 地址是端到端地址，路由器根据目的 IP 查表转发，但不会修改目的 IP 地址。

6. **VI. IP 检验和**：一定变化。  
   IPv4 首部中有 TTL 字段，每经过一个路由器 TTL 都要减 1。TTL 改变后，IP 首部内容改变，因此 IP 首部检验和必须重新计算。若发生分片，IP 首部的总长度、片偏移等也会改变，也会导致 IP 检验和变化。

因此，正确项为 I、II、V，对应选项 B。

**易错点**：

- **误把“IP 检验和”当作端到端不变**：IP 首部中 TTL 每跳都变，所以 IP 检验和一定逐跳重算。
- **误以为 IP 分片会改变 UDP 长度和 UDP 检验和**：分片是 IP 层行为，UDP 首部作为载荷片段的一部分，其内容不被修改。
- **误把“目的 MAC 地址”理解为最终目的主机地址**：MAC 地址只在一个以太网段内有效，跨网络时每跳都会重写。
- **忽略 NAT 条件**：若存在 NAT，源/目的 IP 可能被改写，UDP 伪首部变化，UDP 检验和就需要重新计算；本题明确不考虑 NAT，因此不能错误套用该变化。

**命题规律**：这是 408 中典型的“端到端 vs 逐跳”字段判断题。常见变式包括：引入 NAT 判断 TCP/UDP 检验和是否变化；考察 IP 分片对 IP 首部字段的影响；对比以太网 MAC 地址与 IP 地址的寻址区别。复习时应建立分层表：IP 地址、UDP/TCP 端口、TCP/UDP 数据是端到端属性；MAC 地址、FCS、IP 检验和、TTL 是逐跳/逐帧属性。理解“路由器只修改 IP 头，不修改传输层内容；链路层每跳重新封装”是快速解题的关键。

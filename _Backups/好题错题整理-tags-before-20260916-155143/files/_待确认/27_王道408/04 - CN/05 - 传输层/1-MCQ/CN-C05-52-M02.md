# 选择题 第 2 题

![[_Attachments/题目识别/27_王道408-题目/CN-C05-52-M02_题目.png|题目]]

2. 下列关于 UDP 的描述中,错误的是( )

A. UDP 报头主要包括端口号、长度、检验和等字段

B. UDP 长度字段是 UDP 数据报的长度,包括伪首部的长度

C. UDP 检验和对伪首部、UDP 报文头及应用层数据进行检验

D. 伪首部包括 IP 分组报头的一部分

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C05-52-M02_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：B。UDP 长度字段是 UDP 数据报的长度，包括 UDP 首部和数据，但不包括伪首部，伪首部仅用于校验和计算。

**解题切入点**：本题考察 UDP 协议首部格式与校验和机制。先从选项逐一比对 UDP 规范：伪首部是虚拟结构，仅在计算校验和时使用，其长度不计入 UDP 长度字段。可将伪首部理解为构造的“辅助校验数据结构”，类似于算法竞赛中临时构造的辅助数组，用于高效计算但并不改变原始数据。

**推演**：
- UDP 首部固定 8 字节，包含源端口、目的端口、长度、校验和四个字段，每个字段 2 字节。选项 A 正确。
- 长度字段占 2 字节，表示 UDP 数据报的总长度（首部+数据），单位为字节，最小为 8（无数据）。伪首部是校验和计算时临时添加的 12 字节结构，包含源 IP、目的 IP、填充 0、协议号（17）和 UDP 长度，但 UDP 长度字段本身并不包含伪首部。因此选项 B 错误。
- 校验和计算覆盖伪首部、UDP 首部和 UDP 数据，选项 C 正确。
- 伪首部从 IP 数据报首部提取源 IP 地址、目的 IP 地址、协议字段以及 UDP 长度，选项 D 正确。

**易错点**：
- 混淆“长度字段”与校验和中的“伪首部长度”：伪首部中的 UDP 长度字段与 UDP 首部中的长度字段值相同，但伪首部本身不计入 UDP 长度。
- 错误认为检验和只检验 UDP 首部或数据：实际必须包括伪首部以验证数据报是否到达正确目的地。
- 误以为伪首部是真实传输的一部分：伪首部只在计算和验证校验和时存在，网络传输中不出现。

**命题规律**：
- 常以选择题或填空题形式考查 UDP 首部字段含义、校验和范围及伪首部组成。
- 变式：将 UDP 与 TCP 对比，如 TCP 首部长度、校验和范围；或结合 IP 层考查伪首部字段来源。
- 复习建议：牢记 UDP 首部四个字段及其顺序（源端口、目的端口、长度、校验和），理解伪首部结构（12 字节：源 IP、目的 IP、0、协议、UDP 长度），并明确长度字段不包括伪首部。

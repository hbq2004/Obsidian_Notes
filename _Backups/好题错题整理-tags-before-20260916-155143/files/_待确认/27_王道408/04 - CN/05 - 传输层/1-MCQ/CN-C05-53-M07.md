# 选择题 第 7 题

![[_Attachments/题目识别/27_王道408-题目/CN-C05-53-M07_题目.png|题目]]

7. 下列关于 $TCP$ 报头格式的描述中,错误的是( )

(A) 报头长度为 $20\sim 60B$,其中固定部分为 $20B$

(B) 端口号字段依次表示源端口号与目的端口号

(C) 报头长度总是 $4$ 的倍数个字节

(D) $TCP$ 检验和伪首部中 $IP$ 分组头的协议字段为 $17$

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C05-53-M07_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：D。TCP 校验和伪首部中的协议字段应为 6，不是 17；17 是 UDP 的协议号。A、B、C 的表述均正确。

**解题切入点**：拿到题先判断题支分别对应 TCP 报文首部的哪个部分。A、C 考“首部长度”和“数据偏移”字段；B 考端口号字段顺序；D 考 TCP 校验和伪首部。可以像算法竞赛里先确定结构体字段一样：TCP 首部就是一个“结构体”，数据偏移是 4 bit 的“块大小”字段，伪首部则相当于计算校验时额外加入的“类型标签”，防止不同协议的数据互相干扰。

**推演**：

TCP 报文段首部由固定部分和选项部分构成。固定部分共 $20$ 字节：

- 源端口号：$16$ bit  
- 目的端口号：$16$ bit  
- 序号：$32$ bit  
- 确认号：$32$ bit  
- 数据偏移、保留位、控制位：共 $16$ bit  
- 接收窗口：$16$ bit  
- 校验和：$16$ bit  
- 紧急指针：$16$ bit  

所以固定部分正好是 $20$ 字节。TCP 选项部分最多 $40$ 字节，因此 TCP 报头总长度为

$$
20 \sim 60\ \text{B}
$$

故 A 正确。

端口号字段依次为源端口号、目的端口号，各占 $16$ bit，因此 B 正确。

TCP 首部中的“数据偏移”字段占 $4$ bit，单位是 $4$ 字节，即一个 32 bit 字。若数据偏移值为 $m$，则报头长度为

$$
L=4m
$$

其中 $m$ 的取值范围为 $5\sim 15$，所以

$$
L_{\min}=4\times5=20\ \text{B},\qquad L_{\max}=4\times15=60\ \text{B}
$$

因此 TCP 报头长度一定是 $4$ 的倍数个字节，故 C 正确。

TCP 校验和计算时要加上 $12$ 字节的伪首部，伪首部包含源 IP 地址、目的 IP 地址、保留字段、协议字段和 TCP 报文段长度。其中协议字段的值应取自 IP 首部中的协议字段，对 TCP 而言应为 $6$，而不是 $17$。$17$ 是 UDP 的协议号，因此 D 错误。

**易错点**：

- 容易把“数据偏移”直接当成字节数，从而误以为 C 错误。实际上数据偏移的单位是 $4$ 字节，所以报头长度必为 $4$ 的倍数。
- 容易记混 TCP 与 UDP 的协议号：TCP 是 $6$，UDP 是 $17$。D 项就是用 $17$ 作干扰。
- 容易忽略伪首部并不随 TCP 报文发送，只参与校验和计算。若发送端和接收端对伪首部中协议字段理解不一致，校验和会失败。
- 容易把 TCP 校验和覆盖范围记成只覆盖 TCP 首部；实际覆盖范围是“伪首部 + TCP 报文段”。

**命题规律**：本题考查 TCP 报文段首部格式和校验和伪首部，属于传输层高频考点。常见变式有：

- 给出数据偏移值，求 TCP 报头长度或选项长度；
- 给出一个 TCP 首部的十六进制表示，要求识别字段；
- 将 TCP 与 UDP 的协议号混在一起考查；
- 考查 TCP/UDP 校验和伪首部的字段构成。

复习时应能默画 TCP 首部结构图，熟记固定首部 $20$ 字节、最大首部 $60$ 字节、数据偏移单位是 $4$ 字节、TCP 协议号为 $6$、UDP 协议号为 $17$，并理解伪首部在校验中的作用。

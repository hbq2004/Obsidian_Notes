# 选择题 第 45 题

![[_Attachments/题目识别/27_王道408-题目/CN-C05-53-M45_题目.png|题目]]

45.【2011统考真题】主机甲与主机乙之间已建立一个 TCP 连接,主机甲向主机乙发送了 3 个连续的 TCP 段，分别包含 $300\mathrm{B}$、$400\mathrm{B}$ 和 $500\mathrm{B}$ 的有效载荷，第 3 个段的序号为 900。若主机乙仅正确接收到第 1 个段和第 3 个段，则主机乙发送给主机甲的确认序号是（  ）

A. 300  
B. 500  
C. 1200  
D. 1400

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C05-53-M45_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：B。主机乙只正确收到第 1 段和第 3 段，中间第 2 段丢失；TCP 确认号是累计的，所以仍指向缺失的第 2 段首字节序号 500。

**解题切入点**：  
这就像在算法题中维护一个“连续前缀指针”：收到若干区间后，指针只能沿着连续覆盖的区域前进，遇到空洞就必须停下。TCP 的每个段可看成区间 $[seq, seq+len)$，而 ACK 就是这个连续前缀指针的下一个位置。这里第 3 段虽然到了，但它和已经连续收到的第 1 段之间缺了第 2 段，因此前缀指针停在 500。

**推演**：  
设第 1 段序号为 $x$。  
TCP 段序号表示该段有效载荷首字节的序号，因此：

- 第 1 段：序号 $x$，有效载荷 $300\mathrm{B}$；
- 第 2 段：序号 $x+300$，有效载荷 $400\mathrm{B}$；
- 第 3 段：序号 $x+300+400=x+700$，有效载荷 $500\mathrm{B}$。

题目给出第 3 段序号为 900：

$$x+700=900$$

所以：

$$x=200$$

于是各段覆盖的字节范围为：

- 第 1 段：$[200,500)$，即字节 200 到 499；
- 第 2 段：$[500,900)$，即字节 500 到 899；
- 第 3 段：$[900,1400)$，即字节 900 到 1399。

主机乙正确收到第 1 段和第 3 段，但第 2 段丢失。  
TCP 的确认号是累计确认，表示“下一个期望收到的字节序号”。乙已经连续收到 200 到 499，但 500 到 899 缺失，所以它期望的下一个字节是 500：

$$\text{ACK}=x+300=200+300=500$$

因此答案为 B。

**易错点**：  
1. **把累计确认当成逐段确认**：收到第 3 段就认为 ACK 可以推进到 900 或 1400，这是错误的。TCP 确认号不能跳过缺失数据。  
2. **直接用第 3 段序号加第 3 段长度**：$900+500=1400$ 只是第 3 段之后的下一个序号，但前提是第 2 段已经收到。  
3. **忘记先用前两段长度反推第 1 段序号**：不要误把 900 当作第 1 段序号，否则后续计算全部错位。  
4. **混淆“字节序号”和“载荷长度”**：ACK 是字节流中的序号，不是收到的字节数。

**命题规律**：  
本题是 408 高频考点，考查 TCP 序号与确认号的关系、累计确认机制，以及乱序到达时的处理。常见变式有：给出 ACK 和发送窗口求下一个可发送序号；给出多个收到的段判断应返回的 ACK；结合超时重传、快速重传、SACK 等考查。复习时抓住核心：  
- TCP 报文段的序号 = 有效载荷首字节序号；  
- ACK = 接收方期望收到的下一个连续字节序号；  
- 乱序到达的段不会推进累计 ACK。

# 选择题 第 8 题

![[_Attachments/题目识别/27_王道408-题目/CN-C05-51-M08_题目.png|题目]]

8. 下列哪个 TCP 熟知端口号是错误的?(    )

(A) TELNET:23
(B) SMTP:25
(C) HTTP:80
(D) FTP:24

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C05-51-M08_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：D。FTP 的熟知端口号是 20（数据）和 21（控制），不是 24；TELNET 为 23，SMTP 为 25，HTTP 为 80，均正确。

**解题切入点**：这是一道“背诵＋辨析”型题目，考查 TCP/IP 应用层协议的熟知端口号。拿到题先逐个回忆常见协议端口，像查哈希表一样：TELNET→23、SMTP→25、HTTP→80、FTP→21/20。如果只记得“FTP 是 21”，就能立刻发现 D 选项的 24 是干扰项。这类似于竞赛中背常见数据结构的复杂度结论：不需要现场推导，但必须记准边界值。

**推演**：

熟知端口号（Well-Known Port）范围为 $0\sim1023$，由 IANA 统一分配，供服务器端常用服务使用。常见协议对应关系如下：

- TELNET：远程登录协议，使用 TCP 端口 $23$，用于明文传输远程会话。
- SMTP：简单邮件传输协议，使用 TCP 端口 $25$，用于发送邮件（邮件服务器之间传递）。
- HTTP：超文本传输协议，使用 TCP 端口 $80$，用于 Web 内容传输。
- FTP：文件传输协议，使用两个 TCP 端口：
  - 控制连接端口：$21$，用于传输命令；
  - 数据连接端口：$20$，用于传输文件数据。

逐一核对选项：

(A) TELNET: $23$，正确；
(B) SMTP: $25$，正确；
(C) HTTP: $80$，正确；
(D) FTP: $24$，错误，FTP 控制端口为 $21$，数据端口为 $20$，不存在 $24$ 作为 FTP 的熟知端口。

因此，错误的选项为 D。

**易错点**：

1. **混淆 FTP 的两个端口**：FTP 使用 20 和 21，控制端口 21，数据端口 20。考试常将“21”写成“24”或“22”（SSH 端口）来干扰。
2. **混淆 SMTP 与 POP3/IMAP**：SMTP 是 25，而 POP3 是 110，IMAP 是 143。注意“发信”与“收信”协议端口不同。
3. **混淆 TELNET 与 SSH**：TELNET 是 23，SSH 是 22，题目若出“SSH:23”也是错误项。
4. **只看选项表面**：本题 D 项“FTP:24”非常像端口 21 的“近亲”干扰，若对 FTP 端口记忆不牢，容易误选。规避方法是把常见协议端口做成表格反复记忆，并注意端口与协议功能绑定。

**命题规律**：这是 408 网络部分的高频识记题，通常出现在选择题前几题，难度低，但要求准确记忆。常见变式有：给出“协议:端口”配对找错误、给出端口找对应协议、混合 TCP/UDP 端口（如 DNS:53、DHCP:67/68）、给出传输层协议判定（如 TFTP 用 UDP 69）。复习建议：将应用层协议按“协议—端口—传输层协议—典型场景”整理成表，重点记忆易混项：FTP(20/21)、SSH(22)、TELNET(23)、SMTP(25)、DNS(53)、HTTP(80)、POP3(110)、IMAP(143)、HTTPS(443)。这类题属于送分题，务必不丢分。

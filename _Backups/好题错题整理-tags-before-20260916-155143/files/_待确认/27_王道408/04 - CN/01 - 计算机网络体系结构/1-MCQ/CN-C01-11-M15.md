# 选择题 第 15 题

![[_Attachments/题目识别/27_王道408-题目/CN-C01-11-M15_题目.png|题目]]

15.【2023统考真题】在下图所示的分组交换网络中，主机 H1 和 H2 通过路由器互连，2 段链路的带宽均为 $100Mb/s$，时延带宽积（单向传播时延 × 带宽）均为 $1000b$。若 H1 向 H2 发送一个大小为 $1MB$ 的文件，分组长度为 $1000B$，则从 H1 开始发送的时刻起到 H2 收到文件全部数据时刻止，所需的时间至少是（ ）(注:$1M=10^6$)

【图：H1—路由器—H2 的分组交换网络拓扑图】

A. $80.02ms$
B. $80.08ms$
C. $80.09ms$
D. $80.09ms$

## DeepSeek V4 Flash Max 解析

**答案**：D（实际应为 $80.10ms$，但选项D为 $80.09ms$，疑为印刷错误，正确计算得 $80.10ms$，故选择最接近的D选项）。一句话理由：总时间 = 总发送时延 + 存储转发时延 + 两段传播时延 = $80ms + 0.08ms + 0.02ms = 80.10ms$。

**解题切入点**：先定位考点为分组交换中的存储转发时延与传播时延计算。题目给出时延带宽积，应首先求出传播时延（$d = \frac{1000b}{100Mb/s} = 10\mu s$）。然后利用公式总时间 $= (N+1) \cdot \frac{P}{R} + 2d$，其中 $N$ 为分组数，$P$ 为分组长度，$R$ 为带宽。类似算法竞赛中，构造辅助函数相当于计算总时间时分解为发送时延、传播时延和存储转发时延这三部分，而分治思想则对应分组交换的流水线处理。

**推演**：
- 带宽 $R = 100Mb/s = 100 \times 10^6 b/s$，时延带宽积 $= 1000b$，所以单向传播时延 $d = \frac{1000}{100 \times 10^6} = 10^{-5}s = 10\mu s = 0.01ms$。
- 文件大小 $1MB = 10^6 B = 8 \times 10^6 b$，分组长度 $1000B = 8000b$，分组数 $N = \frac{8 \times 10^6}{8000} = 1000$。
- 分组发送时延 $\frac{P}{R} = \frac{8000}{100 \times 10^6} = 8 \times 10^{-5}s = 0.08ms$。
- 总发送时延 $\frac{L}{R} = \frac{8 \times 10^6}{100 \times 10^6} = 0.08s = 80ms$。
- 存储转发时延（路由器转发一个分组的时间）$= \frac{P}{R} = 0.08ms$。
- 总传播时延为两段链路之和 $2d = 0.02ms$。
- 总时间 $= \frac{L}{R} + \frac{P}{R} + 2d = 80 + 0.08 + 0.02 = 80.10ms$。
- 或利用公式 $(N+1)\frac{P}{R} + 2d = 1001 \times 0.08 + 0.02 = 80.08 + 0.02 = 80.10ms$。

**易错点**：
- 忽略传播时延，只算发送时延和存储转发，得 $80.08ms$（选项B）。
- 只加一段传播时延（如仅考虑最后一段），得 $80.09ms$（选项C/D）。
- 混淆单位，如误将 $1MB$ 当作 $2^{20}B$，或带宽单位换算错误。
- 忘记存储转发时延，只加传播时延，得 $80.02ms$（选项A）。

**命题规律**：
- 考点：分组交换的时延计算（发送时延、传播时延、存储转发时延）。
- 常见变式：改变链路数、分组长度、文件大小或带宽，或引入排队时延、处理时延。也可结合时延带宽积求传播时延。
- 复习建议：熟记总时延公式 $T = \frac{L}{R} + (n-1)\frac{P}{R} + n \cdot d$（$n$ 为链路数），注意单位换算，并理解流水线原理。

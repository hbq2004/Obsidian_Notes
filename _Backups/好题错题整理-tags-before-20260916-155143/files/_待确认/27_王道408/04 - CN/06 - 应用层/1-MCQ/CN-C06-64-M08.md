# 选择题 第 8 题

![[_Attachments/题目识别/27_王道408-题目/CN-C06-64-M08_题目.png|题目]]

8.【2012统考真题】若用户1与用户2之间发送和接收电子邮件的过程如下图所示,则图中①、②、③阶段分别使用的应用层协议可以是（  ）

【图：电子邮件发送接收过程示意图，左侧为用户1，向右箭头①连接用户1的邮件服务器，再向右箭头②连接用户2的邮件服务器，再向右箭头③连接用户2】

(A) SMTP、SMTP、SMTP  
(B) POP3、SMTP、POP3  
(C) POP3、SMTP、SMTP  
(D) SMTP、SMTP、POP3

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C06-64-M08_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：D。  
① 发送方用户代理向邮件服务器发送邮件使用 SMTP，② 邮件服务器之间转发邮件也使用 SMTP，③ 接收方用户代理从邮件服务器接收邮件使用 POP3，故正确选项为 D。

**解题切入点**：  
拿到题目先看示意图，抓住三个阶段的通信主体：① 用户1→用户1的邮件服务器，② 用户1的邮件服务器→用户2的邮件服务器，③ 用户2的邮件服务器→用户2。考点是电子邮件应用中 SMTP 和 POP3 各自的职责。  
**算法竞赛类比**：就像 OJ 系统中，选手提交代码（类似①）用 HTTP/POST，评测服务器之间同步数据（类似②）用内部 API（类似 SMTP 的“推送”），选手最终获取结果（类似③）用 HTTP/GET（类似 POP3 的“拉取”）。核心是区分“发送/转发”与“接收”使用的不同协议。

**推演**：  
- 电子邮件系统采用“用户代理—邮件服务器—邮件服务器—用户代理”架构。  
- SMTP（Simple Mail Transfer Protocol）是“推”协议，用于发送邮件和邮件服务器间的转发，即用户代理向邮件服务器提交邮件（①）以及邮件服务器之间中继邮件（②）均使用 SMTP。  
- POP3（Post Office Protocol version 3）是“拉”协议，用于用户代理从邮件服务器获取邮件（③），即接收方从自己的邮箱中读取邮件。  
因此，①、②、③ 依次对应 SMTP、SMTP、POP3，选项 D 正确。

**易错点**：  
- **混淆 SMTP 与 POP3 的功能**：误以为接收邮件也用 SMTP，或发送邮件用 POP3。需牢记 SMTP 专用于“发送/转发”，POP3（或 IMAP）专用于“接收/拉取”。  
- **忽略用户代理与邮件服务器间的差异**：认为用户代理发送邮件时直接使用 POP3 提交，但实际标准中用户代理向邮件服务器发送邮件仍然使用 SMTP（提交端口 587 或 25）。  
- **老版本干扰**：部分早期教材可能描述用户代理通过 SMTP 发送，通过 POP3 接收，但现代系统仍以此为准，注意区分。

**命题规律**：  
- **考点定位**：应用层协议中的电子邮件协议（SMTP、POP3、IMAP），常结合工作流程图考查协议使用场景。  
- **常见变式**：  
  - 将③改为 IMAP（选项不变时仍选 D，因为 POP3 和 IMAP 同类，但若选项给出 IMAP 则需判断）；  
  - 考查邮件服务器之间的中继协议（仍是 SMTP）；  
  - 考查用户代理向邮件服务器提交时可能使用的其他协议（如 HTTP 接口，但标准仍是 SMTP）。  
- **复习建议**：  
  1. 熟悉电子邮件系统结构（用户代理、邮件服务器、协议角色）。  
  2. 记忆 SMTP 用于发送和转发，POP3/IMAP 用于接收。  
  3. 结合真题图例，反复练习，避免混淆“推”与“拉”。

# 选择题 第 3 题

![[_Attachments/题目识别/27_王道408-题目/CN-C06-61-M03_题目.png|题目]]

3. 下面关于客户/服务器模型的描述，（ ）存在错误。

I.客户端必须提前知道服务器的地址,而服务器则不需要提前知道客户端的地址

II.客户端主要实现如何显示信息与收集用户的输入,而服务器主要实现数据的处理

III.浏览器显示的内容来自服务器

IV.客户端是请求方,即使连接建立后,服务器也不能主动发送数据

A. I、IV  
B. III、IV  
C. 仅 IV  
D. 仅 III

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C06-61-M03_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：C（仅 IV 错误）。客户端是请求方，但连接建立后服务器完全可以主动向客户端发送数据，因此 IV 错误。

**解题切入点**：先抓住客户/服务器模型的核心特征：客户端主动发起请求，服务器被动监听并提供服务。可以类比算法竞赛中的“在线评测系统”：提交代码的程序必须提前知道评测服务的地址，而评测服务端只需监听请求；连接建立后，评测服务端也能主动向客户端推送结果或反馈，而不是只能被动等待。逐条判断时，先找最明显的错误项，IV 显然与“连接建立后可双向通信”矛盾。

**推演**：

逐条分析：

- I 正确：客户端是主动发起连接的一方，必须提前知道服务器的地址（例如通过 DNS 解析得到 IP 地址和端口）。服务器则一般在固定端口监听，不需要提前知道客户端的地址；当客户端发送请求后，服务器从报文中的源地址即可获得客户端地址，并据此进行响应。

- II 正确：在客户/服务器模型中，客户端主要负责用户界面显示、接收用户输入等表示层功能；服务器主要负责数据处理、存储和核心业务逻辑，因此该描述符合典型 C/S 模型的分工。

- III 正确：浏览器是典型的 Web 客户端，它向服务器发送 HTTP 请求后，浏览器所显示的主要页面内容来自服务器的响应。即使存在本地缓存，缓存内容的原始来源也是服务器，因此该说法正确。

- IV 错误：连接建立后，通信双方并不是一方只能发送、另一方只能接收。例如 TCP 连接建立后是全双工通信，服务器可以在收到请求后主动发送响应数据，也可以通过 HTTP/2 Server Push、WebSocket 等机制向客户端推送数据。因此“即使连接建立后，服务器也不能主动发送数据”的说法是错误的。

综上，只有 IV 存在错误，故选 C。

**易错点**：

- 误以为服务器不需要知道客户端地址。实际上服务器在收到客户端请求后，能从 IP 报文的源地址和 TCP 报文的源端口获得客户端地址，只是不需要“提前知道”。
- 误以为浏览器显示的内容可能来自本地缓存，因此 III 错误。需要注意，缓存只是临时副本，原始来源仍是服务器。
- 混淆“服务器不能主动建立连接”与“服务器不能主动发送数据”。服务器通常不主动向客户端发起连接，但连接建立后可以主动发送数据。
- 将 C/S 模型简单理解为“客户端只会发，服务器只会收”，忽略了 TCP 等传输层协议提供的是全双工通信。

**命题规律**：该题考查计算机网络的客户/服务器模型基本概念，属于应用层基础考点。常见变式有：判断关于 C/S 模型与 P2P 模型的描述；结合 TCP 三次握手后双方通信是否对称；结合 HTTP 请求/响应模型判断浏览器与服务器的数据流向。复习时应重点掌握 C/S 模型中客户端和服务器的角色划分、地址获取方式、连接建立方式和数据传输方向，同时注意现代 Web 中的服务器推送机制，避免把传统“请求-响应”模式绝对化。

# 选择题 第 9 题

![[_Attachments/题目识别/27_王道408-题目/CN-C06-62-M09_题目.png|题目]]

9.（）可以将其管辖的主机名转换为主机的 IP 地址.

A. 本地域名服务器
B. 根域名服务器
C. 授权域名服务器
D. 代理域名服务器

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C06-62-M09_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：C。授权域名服务器对其负责的区域（zone）具有权威性，能将“管辖范围内”的主机名解析为对应的 IP 地址；本地域名服务器只是查询入口，根域名服务器只负责引导到下级服务器，代理域名服务器主要做转发。

**解题切入点**：  
看到“管辖的主机名”立刻定位到 DNS 的分区与权威性概念。DNS 是一个分布式数据库，主机名到 IP 的最终映射存放在该域名所在区域的授权域名服务器上。算法竞赛类比：这就像分布式哈希表/分片查询中的“分片所有者”；根域名服务器相当于路由索引，本地域名服务器相当于缓存层，而授权域名服务器才是真正持有最终数据的节点。

**推演**：  
1. DNS 域名空间按树形结构划分成若干“区”。每个区由授权域名服务器管理，授权域名服务器保存该区的资源记录，例如将主机名映射到 IPv4 的 A 记录、映射到 IPv6 的 AAAA 记录。  
2. 在典型解析过程中，主机把查询先发给本地域名服务器；本地服务器若缓存未命中，会迭代询问根域名服务器和顶级域名服务器，最终到达目标域名所在区域的授权域名服务器。  
3. 根域名服务器不保存具体主机名到 IP 的映射，它只负责告诉查询者“下一级该去找哪个顶级域名服务器”。  
4. 本地域名服务器虽然有缓存，也可能帮助用户完成解析，但它并不是因为“管辖”而拥有该映射；代理域名服务器则更像转发层，不维护管辖区域。  
5. 因此，能将“其管辖的主机名”转换为 IP 地址的服务器是授权域名服务器。

**易错点**：  
- 误选 A：实际使用中主机最先联系的是本地域名服务器，但本地服务器不一定拥有该主机名和 IP 的映射，它只是递归解析入口或缓存。题目强调“管辖”，应选权威者。  
- 误选 B：根域名服务器只负责顶级域名服务器的定位，不保存普通主机名映射。  
- 误选 D：代理域名服务器只负责转发/缓存，不保存管辖区域的数据。  
- 注意：现实中一台服务器可以同时是本地域名服务器和授权域名服务器，例如校园网 DNS；但按题目选项的功能角色区分，答案仍是 C。

**命题规律**：  
- 考点定位：应用层 DNS 协议，考查 DNS 服务器分类与域名解析过程。  
- 常见变式：结合递归查询/迭代查询的流程，判断某一回答是“权威回答”还是“缓存回答”；或问“负责一个区域的域名服务器是什么”。  
- 复习建议：把 DNS 树、区域、服务器角色画成分层图；记住“本地是入口，根/顶级是导航，授权是最终数据源”，并掌握 DNS 默认用 UDP 53、区域传送用 TCP 53 等常见细节。

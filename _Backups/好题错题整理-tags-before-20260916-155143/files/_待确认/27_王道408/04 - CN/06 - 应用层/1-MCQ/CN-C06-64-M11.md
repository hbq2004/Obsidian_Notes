# 选择题 第 11 题

![[_Attachments/题目识别/27_王道408-题目/CN-C06-64-M11_题目.png|题目]]

11.【2018统考真题】无须转换即可由 SMTP 直接传输的内容是（ ）

A. JPEG 图像

B. MPEG 视频

C. EXE 文件

D. ASCII 文本

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C06-64-M11_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：D. ASCII文本。SMTP 设计之初只支持 7 位 ASCII 码，其他格式（如JPEG、MPEG、EXE）需要经过 MIME 编码转换后才能传输，而 ASCII 文本可直接传输。

**解题切入点**：抓住“无须转换”即 SMTP 原生支持的格式，定位到 SMTP 的基本特性——只处理 ASCII 文本，类似算法竞赛中“原始接口只接受特定类型数据，其他类型必须封装转换”的思路。

**推演**：SMTP（简单邮件传输协议）在 RFC 821 中定义，其传输信道仅支持 7 位 ASCII 字符，且每行不超过 1000 字符。二进制文件（如 JPEG、MPEG、EXE）或包含非 ASCII 字符的文本必须通过 MIME（多用途互联网邮件扩展）进行编码（如 Base64 或 Quoted-Printable）转换为 ASCII 字串才能传输。因此，只有纯 ASCII 文本无需额外转换即可直接由 SMTP 传输。

**易错点**：混淆“可直接传输”与“现在普遍支持”，误以为 SMTP 已原生支持所有类型；或忽略 MIME 扩展的作用，认为 SMTP 本身就能传输附件。正确区分协议核心功能与扩展机制。

**命题规律**：常考 SMTP 与 MIME 的关系，以及 SMTP 的 ASCII 限制。变式可问“需要 MIME 编码的有哪些”或“SMTP 不能直接传输的内容”。复习时应重点掌握 SMTP 的原始设计（RFC 821）及 MIME 的扩展作用。

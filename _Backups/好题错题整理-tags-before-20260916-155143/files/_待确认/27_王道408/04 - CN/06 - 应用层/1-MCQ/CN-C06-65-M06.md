# 选择题 第 6 题

![[_Attachments/题目识别/27_王道408-题目/CN-C06-65-M06_题目.png|题目]]

6.使用鼠标单击一个万维网文档时,若该文档除有文本外,还有三幅 gif 图像,则在 HTTP/1.0 中需要建立（ ）次 TCP 连接.

(A) 4  
(B) 3  
(C) 2  
(D) 1

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C06-65-M06_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：A。  
HTTP/1.0 默认采用非持久连接，一个 TCP 连接只传输一个 HTTP 对象；该页面有 1 个 HTML 主文档和 3 幅 gif 图像，共 4 个对象，所以需要建立 4 次 TCP 连接。

**解题切入点**：  
先抓两个关键词：**“HTTP/1.0”** 和 **“文档 + 三幅 gif 图像”**。前者决定连接策略，后者决定需要请求的对象个数。  
可以类比算法竞赛中的“每次任务都要重新初始化”模型：HTTP/1.0 相当于不能复用连接池，每个对象都要单独建立一次 TCP 会话；因此连接次数 = 对象个数。

**推演**：  
用户点击一个万维网文档时，浏览器要获取的完整页面包括：

- 1 个 HTML 主文档；
- 3 幅 gif 图像。

所以需要请求的对象总数为：

$$N = 1 + 3 = 4$$

HTTP/1.0 默认是非持久连接：每个 TCP 连接上最多完成一次 HTTP 请求/响应，传输完一个对象后连接关闭。因此：

$$N_{\text{TCP}} = N = 4$$

即浏览器需要先后或并行建立 4 次 TCP 连接来获取这 4 个对象。

注意：虽然每建立一次 TCP 连接都要经历三次握手，但本题只统计“建立的 TCP 连接次数”，不统计 RTT 或握手次数。

**易错点**：  
- 误选 D：把 HTTP/1.1 的默认持久连接套用到 HTTP/1.0 上。HTTP/1.1 默认一个 TCP 连接可以传输多个对象，但题目限定的是 HTTP/1.0。  
- 误选 B：只数了 3 幅 gif 图像，漏掉了 HTML 主文档本身。主文档也需要一次独立的 HTTP 请求和 TCP 连接。  
- 混淆“连接数”和“RTT 数”：这里只问 TCP 连接次数，不涉及握手往返时间。  
- 忽略 Keep-Alive 扩展：408 默认按 HTTP/1.0 非持久连接处理，除非题目明确说明使用了保持连接扩展。

**命题规律**：  
考点是 HTTP 的持久连接与非持久连接，常结合页面中的对象个数进行计数。  
常见变式：把题干改成 HTTP/1.1，则默认使用持久连接，4 个对象可以共用同一条 TCP 连接，答案变为 1；还可能进一步考察非流水线、流水线或 RTT 计算。  
复习建议：把 HTTP/1.0、HTTP/1.1 非流水线、HTTP/1.1 流水线的连接策略整理对比，并熟悉与 TCP 三次握手、RTT 计算结合的综合题。

# 选择题 第 8 题

![[_Attachments/题目识别/27_王道408-题目/CN-C06-62-M08_题目.png|题目]]

(A) 202.120.66.68 域名服务器  
(B) 11.2.8.6 域名服务器  
(C) 202.113.16.10 域名服务器  
(D) 可以从这3个域名服务器中任选一个

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C06-62-M08_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：A（202.120.66.68 域名服务器）；主机通常按配置顺序依次尝试域名服务器，优先使用第一个，因此首选 202.120.66.68。

**解题切入点**：抓住“主机配置多个域名服务器时的使用顺序”这一关键点。这类似于算法竞赛中“多级缓存”或“备选方案”策略，优先使用第一个，后续依次作为降级选项，保证容错性。

**推演**：在 DNS 系统中，主机可以配置多个域名服务器（主、备等）。当需要域名解析时，操作系统会依次向列表中的服务器发送查询请求，顺序固定。若第一个服务器超时或不可达，则尝试第二个，以此类推。因此，给定三个 IP 地址 202.120.66.68、11.2.8.6、202.113.16.10，主机将首先向第一个 202.120.66.68 发送查询。选项 D“任选一个”不符合实际机制，因为顺序是确定的，并非随机选择。

**易错点**：
- 误认为主机可以同时向多个服务器查询或随机选取，忽略顺序尝试的默认行为。
- 混淆本地域名服务器与根域名服务器，但本题仅涉及主机配置顺序，不涉及服务器类型。
- 在实际网络环境中，若第一个服务器响应但返回错误，是否继续尝试取决于具体实现，但题目通常默认按顺序尝试直至成功。

**命题规律**：考点为 DNS 主机配置与查询顺序，属于基础记忆类题目。常见变式包括：更换 IP 顺序、询问第二个服务器何时被使用、或结合递归/迭代查询过程。复习时应理解 DNS 查询的基本流程（主机->本地域名服务器->根等），并注意主机配置多个服务器时的顺序优先级。

# 选择题 第 3 题

![[_Attachments/题目识别/27_王道408-题目/CN-C06-65-M03_题目.png|题目]]

3. $TCP$ 和 $UDP$ 的一些端口保留给一些特定的应用使用。为 $HTTP$ 保留的端口号为（  ）.

(A) $TCP$ 的 80 端口  
(B) $UDP$ 的 80 端口  
(C) $TCP$ 的 25 端口  
(D) $UDP$ 的 25 端口

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C06-65-M03_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：A。HTTP 默认使用 TCP 的 80 端口，因为 HTTP 需要可靠传输。

**解题切入点**：先抓“协议 + 端口 + 传输层协议”三个关键信息。这就像算法竞赛里看到“哈希表”要先确定“键值类型和哈希函数”一样：看到应用层协议，第一反应是它基于 TCP 还是 UDP，然后才是默认端口。本题只需记忆/推导 HTTP 既要求可靠性又属于 Web 浏览场景，因此必选 TCP 80。

**推演**：

1. 区分传输层协议：
   - TCP：面向连接、可靠、按序、字节流，适合文件传输、网页浏览、邮件等需要可靠性的应用。
   - UDP：无连接、不可靠、开销小，适合实时音视频、DNS 查询等允许丢包的应用。

2. HTTP（HyperText Transfer Protocol）用于传输网页资源，必须保证数据完整、有序到达，因此底层使用 TCP。

3. 常见应用层协议默认端口：
   - HTTP：TCP 80
   - HTTPS：TCP 443
   - FTP：TCP 20/21
   - SMTP：TCP 25
   - DNS：UDP 53（也可用 TCP）
   - DHCP：UDP 67/68

4. 对照选项：
   - A：TCP 的 80 端口 ✔
   - B：UDP 的 80 端口 ✘（HTTP 不用 UDP）
   - C：TCP 的 25 端口 ✘（25 是 SMTP）
   - D：UDP 的 25 端口 ✘（SMTP 用 TCP 25）

因此选 A。

**易错点**：

- 混淆 25 端口与 SMTP：25 是邮件发送协议 SMTP 的端口，不是 HTTP。
- 混淆 TCP/UDP：误以为 HTTP 也支持 UDP，实际上 HTTP 要求可靠传输，必须用 TCP；HTTP/3 虽基于 QUIC（UDP），但这是后续演进，不是传统 408 考点默认语境。
- 记忆口诀误区：只记“80 端口”而忽略传输层协议，导致选 B。应注意端口是绑定在具体传输层协议上的。

**命题规律**：这是网络应用层的常考基础题，属于“协议-端口-传输层协议”三要素匹配。常见变式包括：HTTPS 的 443、FTP 的 20/21、SMTP 的 25、DNS 的 53、DHCP 的 67/68 等。复习时建议整理一张“应用层协议默认端口 + TCP/UDP”表格，并与传输层特性（可靠/不可靠）联动记忆，考试时先判断协议特性，再记端口，不易混淆。

# 选择题 第 4 题

![[_Attachments/题目识别/27_王道408-题目/CN-C06-61-M04_题目.png|题目]]

4. 下列关于客户/服务器模型的说法中，错误的是( )

(A) 服务器专用于完成某些服务，而客户机则作为这些服务的使用者

(B) 客户机通常位于前端，服务器通常位于后端

(C) 客户机和服务器通过网络实现协同计算任务

(D) 客户机是面向任务的，服务器是面向用户的

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C06-61-M04_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：D。客户机才是面向用户的（用户交互、发起请求），服务器是面向任务的（处理请求、提供服务），选项 D 把两者说反了。

**解题切入点**：拿到题目先抓客户/服务器模型中的“身份职责”：客户机是请求方，服务器是服务方。用算法竞赛打比方：客户机就像你本地的提交代码与查看题面的编辑器/终端，面向你（用户）交互；服务器就像评测机，只关心“编译、跑样例、判分”这些任务，不面向任何用户操作。把“谁面对用户、谁执行任务”理清即可秒杀。

**推演**：

逐项判断：

- 选项 A：服务器专用于完成某些服务，客户机作为服务的使用者。这正是 C/S 模型的基本分工，**正确**。
- 选项 B：客户机通常位于前端，服务器通常位于后端。前端负责与用户交互，后端负责集中处理，**正确**。
- 选项 C：客户机和服务器通过网络实现协同计算任务。客户机发出请求，服务器返回结果，两者通过网络协作，**正确**。
- 选项 D：客户机是面向任务的，服务器是面向用户的。在实际模型中：
  - 客户机是**面向用户**的：它直接面对用户，提供交互界面，收集用户请求并展示结果；
  - 服务器是**面向任务**的：它接收请求，执行具体服务逻辑，对多客户端的请求进行并发处理。

因此选项 D 的表述与事实相反，**错误**。

所以答案为 D。

**易错点**：

1. **概念张冠李戴**：误以为“服务器功能强大，所以面向用户；客户机功能单一，所以面向任务”。实际上“面向用户”指直接与用户交互，“面向任务”指专门执行服务逻辑，与机器性能无关。  
2. **混淆 C/S 与 B/S**：B/S 中浏览器是通用客户端，本质仍是客户机面向用户，服务器面向任务。  
3. **忽略“请求—服务”方向**：牢记客户机主动请求，服务器被动响应，可帮助判断职责归属。

**命题规律**：

该题考查计算机网络应用层的基本体系结构，属于概念记忆型题目，难度低，常与 P2P 模型对比出现。常见变式：
- 给出具体场景判断属于 C/S 还是 P2P；
- 比较 C/S 与 P2P 在可扩展性、可靠性、管理维护上的差异；
- 结合 TCP/IP 协议栈，指出客户机与服务器使用的套接字调用过程。

复习建议：将 C/S 模型的核心特征总结为“角色固定、请求/响应、服务器集中管理”，并对比 P2P 中“每台主机既是客户机又是服务器”的特点；同时结合一次 Web 访问过程（浏览器→DNS→HTTP→服务器响应）理解“前端/后端”的实际含义。

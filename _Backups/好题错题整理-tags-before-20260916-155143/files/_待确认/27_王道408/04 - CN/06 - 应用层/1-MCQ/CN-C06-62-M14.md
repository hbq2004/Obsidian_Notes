# 选择题 第 14 题

![[_Attachments/题目识别/27_王道408-题目/CN-C06-62-M14_题目.png|题目]]

14.【2020统考真题】假设下图所示网络中的本地域名服务器只提供递归查询服务，其他域名服务器均只提供迭代查询服务；局域网内主机访问 Internet 上各服务器的往返时间（RTT）均为 10ms，忽略其他各种时延。若主机 H 通过超链接 http://www.abc.com/index.html 请求浏览纯文本 Web 页 index.html，则从单击超链接开始到浏览器接收到 index.html 页面为止，所需的最短时间与最长时间分别是（ ）

【图：网络拓扑示意图，左侧局域网内包含本地域名服务器和主机 H，通过路由器连接 Internet 云；Internet 云内有 com 顶级域名服务器、根域名服务器、abc.com 域名服务器和 www.abc.com 服务器。】

A. 10ms, 40ms  
B. 10ms, 50ms  
C. 20ms, 40ms  
D. 20ms, 50ms

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C06-62-M14_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：A。最短为 $10\mathrm{ms}$：本地域名服务器缓存命中，只需一次 HTTP 取页往返；最长为 $40\mathrm{ms}$：本地域名服务器未命中时，需对根、com、abc.com 三次迭代查询，再加一次 HTTP 取页往返。

**解题切入点**：拿到题先分清 DNS 的递归/迭代查询路径：主机 H 只与本地域名服务器交互，本地域名服务器再向“根 → com → abc.com”逐级迭代查询。最短/最长对应“缓存命中/未命中”。这类似于算法竞赛里的多级缓存/多级索引查找：命中时 $O(1)$，未命中时要沿层级逐级向上找，每层一次远程访问。

**推演**：

设 $R=10\mathrm{ms}$。

最短时间：本地域名服务器已有 `www.abc.com` 的 IP 缓存，不需要访问 Internet 上的其他域名服务器。主机 H 请求 `index.html`，Web 服务器返回页面，共 $1$ 个 RTT：

$$
T_{\min}=R=10\mathrm{ms}
$$

最长时间：本地域名服务器无缓存，需要迭代查询：

1. 本地域名服务器向根域名服务器查询 `www.abc.com`，根域名服务器返回 `com` 顶级域名服务器地址：$1$ 个 RTT；
2. 本地域名服务器向 `com` 顶级域名服务器查询，返回 `abc.com` 域名服务器地址：$1$ 个 RTT；
3. 本地域名服务器向 `abc.com` 域名服务器查询，返回 `www.abc.com` 的 IP：$1$ 个 RTT；
4. 主机 H 再向 `www.abc.com` 发送 HTTP 请求并接收 `index.html`：$1$ 个 RTT。

因此：

$$
T_{\max}=3R+R=4R=40\mathrm{ms}
$$

注意：主机到本地域名服务器属于局域网内通信，按题干“忽略其他各种时延”处理，不计入给定 RTT。

**易错点**：

- 最容易误把“主机 H 到本地域名服务器”的查询/响应也算作一个 $10\mathrm{ms}$ 的 RTT，从而错选 D（$20\mathrm{ms},50\mathrm{ms}$）。但题目只给出“主机访问 Internet 上各服务器”的 RTT，本地域名服务器在局域网内，不应额外计入。
- 容易少算 `com` 顶级域名服务器，以为只需查根和 `abc.com`；实际上 `abc.com` 是 `com` 下的域名，必须先通过根找到 `com`，再通过 `com` 找到 `abc.com`。
- 容易多算重复查询，例如把“根 → com → abc.com”理解成 4 次；正确是 3 次迭代 DNS 查询。

**命题规律**：考点是 DNS 的递归/迭代查询过程与 RTT 时延计算。常见变式包括：改变域名层级数（如 `www.abc.com.cn`）、加入多个 Web 对象或图片增加 HTTP 请求次数、考虑本地缓存是否命中、区分持久连接与非持久连接。复习时应画清查询时序图，重点数清“跨 Internet 的 RTT 次数”，不要额外计入局域网内的通信时延。

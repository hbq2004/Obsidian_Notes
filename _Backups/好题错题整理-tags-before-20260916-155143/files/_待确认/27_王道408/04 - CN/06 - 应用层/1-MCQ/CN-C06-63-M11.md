# 选择题 第 11 题

![[_Attachments/题目识别/27_王道408-题目/CN-C06-63-M11_题目.png|题目]]

11.FTP支持两种方式的传输:ASCII 方式和 Binary(二进制) 方式。通常文本文件采用( )方式,而图像、声音等非文本文件采用( )方式传输.

(A) ASCII,Binary  
(B) Binary,ASCII  
(C) ASCII,ASCII  
(D) Binary,Binary

## 答案

## DeepSeek V4 Flash Max 解析

**答案**：A。FTP 中文本文件通常用 ASCII 模式传输，图像、声音等非文本文件用 Binary（二进制）模式传输。

**解题切入点**：拿到题目先抓“文件类型”与“是否允许数据被转换”的关系。FTP 的 ASCII 方式和 Binary 方式，本质上是两种“打开文件”的模式。这就像算法竞赛中读文件时，文本文件要按字符处理并考虑换行符，而图片、压缩包必须用二进制模式读入，不能经过文本模式的自动转换；一旦用错，数据就会被改变。所以考点定位在应用层 FTP 的传输模式设计理由。

**推演**：

- FTP 传输文件时，可以选择文件的传输类型，常用两种：ASCII 方式和 Binary 方式。
- 对于文本文件，不同操作系统对换行符、字符编码的表示不同。ASCII 模式的作用是：发送端将本地文本文件转换成标准的 NVT-ASCII 形式，接收端再转换回自己系统的文本表示形式。因此，文本文件采用 ASCII 方式传输，能实现跨平台的文本兼容。
- 对于图像、声音等非文本文件，文件中每一个字节都代表实际数据，不能做任何转换。Binary 方式直接将文件作为二进制字节流逐字节发送，不做任何编码或换行符转换，接收端原样保存，从而保证文件内容与源文件完全一致。
- 如果反过来：用 ASCII 方式传输图像/声音，某些字节可能被错误解释为控制字符或换行符，导致文件损坏；用 Binary 方式传输文本虽然能保留原始字节，但无法自动处理跨平台文本格式差异。因此题目中“通常”的搭配是：

文本文件 $\to$ ASCII 方式，非文本文件 $\to$ Binary 方式。

所以正确选项为 A。

**易错点**：

- 最常见错误是选 B，把 Binary 当成“所有文件都能用的方式”，忽略了题目强调的是“通常”和“文件类型”。
- 注意 ASCII 模式并不只是处理英文字符，它还会做换行符、字符编码等转换，因此不能用于图片、音频等二进制文件。
- 不要认为“Binary 方式更高级，所以文本也能用 Binary 代替”。文本文件用 Binary 方式虽然也能传，但失去了跨平台文本转换的意义，不符合 FTP 设计中的“通常”选择。
- 本题容易与 FTP 端口混淆，但题目问的是传输文件的数据格式，不是控制连接/数据连接；控制连接 TCP 21、数据连接 TCP 20 是另一个常考考点。

**命题规律**：本题属于应用层 FTP 的基础记忆题，难度低。常见变式有：问 FTP 默认传输模式是 ASCII；问传输 `.png`、`.mp3` 等文件应选哪种方式；或者将 FTP 与 TFTP、HTTP 对比。复习时建议把应用层常见协议按“端口、传输层协议、典型特点”列表整理，FTP 重点记忆双连接、主动/被动模式、ASCII/Binary 传输模式及其设计原因，不要只背选项。

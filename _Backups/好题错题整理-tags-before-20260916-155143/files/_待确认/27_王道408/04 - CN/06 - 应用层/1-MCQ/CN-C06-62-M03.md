# 选择题 第 3 题

![[_Attachments/题目识别/27_王道408-题目/CN-C06-62-M03_题目.png|题目]]

3. DNS 属于（ ）模型方式.
(A) C/S
(B) B/S
(C) P2P
(D) 拉/推

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C06-62-M03_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：A。DNS 采用客户端‑服务器模型，客户端发起查询请求，服务器返回响应，属于典型的 C/S 模式。  

**解题切入点**：首先判断应用层协议的网络架构模型。DNS 的核心是域名解析，整个过程由客户端主动请求、服务器被动响应，角色明确不对称，这直接定位到 C/S 模型。可以类比用户访问数据库：客户端发送查询，服务器处理并返回结果，与 C/S 的思想一致。  

**推演**：DNS 体系中，客户端（如操作系统中的解析器）向 DNS 服务器发送查询报文，服务器经过递归或迭代查找后给出应答。这是典型的请求‑响应模式，且服务器是固定提供服务的节点，客户端是动态发起请求的节点，因此满足 C/S 模型。B/S 是 C/S 在 Web 应用下的特例，而 DNS 服务器并非专门为浏览器服务，故不选 B/S。P2P 模型强调节点对等、互相提供服务，DNS 中客户端与服务器角色不对称，因此不是 P2P。拉/推是数据分发方式，DNS 确实使用“拉”的方式（客户端主动拉取数据），但题目问的是“模型方式”，通常指网络应用架构模型，而非具体的数据传输模式，因此最佳答案是 C/S。  

**易错点**：容易误选 B/S，因为浏览器常使用 DNS；但 B/S 特指浏览器‑服务器架构，DNS 是独立的基础设施，并不属于 Web 应用范畴。也有误选 P2P 的，认为 DNS 是分布式系统，然而 DNS 的层次结构依然保持明确的客户‑服务器角色，并非对等。  

**命题规律**：考查常见网络应用的基本架构模型，要求掌握 C/S、P2P、B/S 的区别，并熟悉 DNS、HTTP、FTP 等典型协议所属模型。复习时注意区分“拉/推”通常是数据分发方式，而非架构模型，避免混淆。

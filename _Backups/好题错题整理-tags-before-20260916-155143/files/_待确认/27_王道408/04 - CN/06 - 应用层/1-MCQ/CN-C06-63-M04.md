# 选择题 第 4 题

![[_Attachments/题目识别/27_王道408-题目/CN-C06-63-M04_题目.png|题目]]

4. 下列关于 FTP 连接的叙述中,正确的是( )

A. 控制连接先于数据连接被建立,并先于数据连接被释放

B. 数据连接先于控制连接被建立,并先于控制连接被释放

C. 控制连接先于数据连接被建立,并晚于数据连接被释放

D. 数据连接先于控制连接被建立,并晚于控制连接被释放

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C06-63-M04_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：C。控制连接先于数据连接建立，并晚于数据连接释放。  

**解题切入点**：首先抓住关键——FTP 使用两个独立的连接：控制连接（端口 21，传输命令与响应）和数据连接（端口 20，传输实际数据）。从算法竞赛角度可类比为主线程与工作线程：控制连接相当于主线程，负责调度与通信，在整个会话中保持；数据连接相当于工作线程，仅在需要时创建，任务完成后立即销毁。因此控制连接的生命周期更长，必然先建立、后释放。  

**推演**：FTP 会话的典型流程如下：  
1. 客户端主动与服务器 21 端口建立 TCP 连接，即控制连接。  
2. 通过控制连接发送命令（如 LIST、RETR、STOR）。  
3. 当需要传输数据时，根据模式（主动/被动）建立数据连接，传输文件或目录列表。  
4. 数据传输完成后，立即关闭数据连接。  
5. 用户输入 QUIT 命令后，关闭控制连接。  
可见控制连接先于数据连接建立，且在所有数据连接都关闭后才释放。选项 A、B、D 均与顺序矛盾，故 C 正确。  

**易错点**：部分考生可能误以为数据是主要目的，从而认为数据连接先建立（如选 B 或 D）。实际上控制连接是命令通道，必须先建立；数据连接仅在需要时临时建立，且可能多次创建（每次传输新建数据连接）。此外，FTP 的主动/被动模式不影响这一顺序，仅改变数据连接建立的方向。  

**命题规律**：本题直接考查 FTP 协议的基本原理，重点在于控制连接与数据连接的生命周期关系。常见变式包括：给出时间点判断连接状态、区分主动/被动模式对连接建立的影响、结合端口号（21 与 20）考查。复习时应深入理解 FTP 工作流程，并对比其他应用层协议（如 HTTP 的持久连接）以加深记忆。

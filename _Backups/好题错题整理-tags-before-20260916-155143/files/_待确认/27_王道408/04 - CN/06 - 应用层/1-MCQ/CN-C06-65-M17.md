# 选择题 第 17 题

![[_Attachments/题目识别/27_王道408-题目/CN-C06-65-M17_题目.png|题目]]

17.【2015统考真题】某浏览器发出的 HTTP 请求报文如下图所示，下列叙述中,错误的是( )

```http
GET /index.html HTTP/1.1
Host: www.test.edu.cn
Connection: Close
Cookie: 123456
```

(A) 该浏览器请求浏览 *index.html*
(B) *index.html* 存放在 www.test.edu.cn 上
(C) 该浏览器请求使用持续连接
(D) 该浏览器曾经浏览过 www.test.edu.cn

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C06-65-M17_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：C。因为请求头中 `Connection: Close` 表示非持续连接，而非持续连接，故选项 C 错误。

**解题切入点**：遇到 HTTP 请求报文分析题，首先定位请求行（方法、URL、版本）和关键头部字段。本题中 `Connection: Close` 是核心线索，它直接表明连接类型（非持续），与持续连接 `keep-alive` 相反。类似算法比赛中，通过构造辅助数据结构（如哈希表）快速定位关键信息，这里就是抓住头部字段的含义。

**推演**：
- 请求行 `GET /index.html HTTP/1.1` 表明请求资源为 `/index.html`，方法为 GET，版本为 HTTP/1.1。
- `Host: www.test.edu.cn` 指定目标主机，即资源所在服务器。
- `Connection: Close` 是 HTTP/1.1 中的可选字段，默认 HTTP/1.1 使用持续连接，但显式声明 `Close` 则要求服务器在响应后关闭连接，即非持续连接。
- `Cookie: 123456` 表示浏览器携带了该 Cookie，通常由之前与该服务器的交互获得，说明曾访问过该网站。
- 逐一验证选项：
  - (A) 请求行中 `GET /index.html` 即请求浏览 index.html，正确。
  - (B) `Host` 字段指示资源存放服务器，正确。
  - (C) `Connection: Close` 表示非持续连接，而非持续连接，故错误。
  - (D) 存在 Cookie 表明曾访问过该服务器，正确。

**易错点**：
- 混淆 `Connection: Close` 与 `Connection: keep-alive`，误以为 HTTP/1.1 默认持续连接则所有请求都是持续连接，忽略显式字段的覆盖作用。
- 忽略 Cookie 的存在意义，认为 Cookie 可任意发送，但通常只有之前访问过才会获得并携带。
- 误认为 `Host` 字段指定的是代理或缓存，实际是源服务器主机名。

**命题规律**：
- 考点：HTTP 请求报文结构、常见头部字段（Connection、Cookie、Host）的含义与作用。
- 变式：可改为给出响应报文，考查状态码、Content-Type 等；或结合 HTTP/1.0/1.1 版本差异比较连接方式。
- 复习建议：熟记 HTTP 请求行格式、关键头部字段（Host、Connection、Cookie、User-Agent 等），理解持续连接与非持续连接的区别，以及 Cookie 的交互机制。

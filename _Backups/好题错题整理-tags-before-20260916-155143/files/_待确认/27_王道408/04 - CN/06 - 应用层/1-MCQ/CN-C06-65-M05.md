# 选择题 第 5 题

![[_Attachments/题目识别/27_王道408-题目/CN-C06-65-M05_题目.png|题目]]

5. 万维网上的每个页面都有唯一的地址,这些地址统称为( )
(A) IP地址
(B) 域名地址
(C) 统一资源定位符
(D) WWW地址

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C06-65-M05_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：C。统一资源定位符（URL）是万维网每个页面的唯一地址，相当于为每个资源分配了一个全局可访问的标识符。

**解题切入点**：题目问的是“万维网上的每个页面都有唯一的地址”，直接对应 URL 的定义。可类比算法竞赛中每个题目都有唯一的编号（如 `CF 1800A`），URL 就是网页的“唯一 ID”，它规定了访问该资源所使用的协议、服务器地址和路径。

**推演**：万维网使用统一资源定位符（URL）来唯一标识每个页面。URL 的语法格式为：  
`<协议>://<主机>:<端口>/<路径>?<查询>`  
例如 `http://www.example.com:80/index.html?page=1`。  
- IP 地址（A选项）是网络层的逻辑地址，用于标识主机或路由器接口，不包含协议和路径信息，因此不是页面地址。  
- 域名地址（B选项）是 IP 地址的别名，便于记忆，但域名本身不能直接定位到具体页面，必须结合协议和路径才能构成完整的页面地址。  
- WWW 地址（D选项）是一个笼统的称呼，并非专业术语，无法精确定位资源。  
因此，只有 URL 能唯一标识万维网上的页面，选 C。

**易错点**：  
1. 混淆域名与 URL：认为在浏览器地址栏输入的域名就是页面地址，但域名只是 URL 的一部分，缺少协议和路径无法定位页面。  
2. 误认为 IP 地址是页面地址：IP 地址只标识主机，不能定位到具体页面或文件。  
3. 忽略“统一”含义：URL 中“统一”指全球统一格式，而其他选项无此特性。

**命题规律**：  
- 考点：URL 的基本概念及其与 IP 地址、域名的区别，属于计算机网络基础必考内容。  
- 常见变式：给出一个 URL 字符串，要求判断其组成部分（如协议、主机、路径）；或给出具体场景，选择正确的资源定位方式。  
- 复习建议：熟记 URL 的组成（协议、主机、端口、路径、查询），理解其与 DNS、IP 地址的关系，并通过实际例子（如 `http://www.example.com:8080/path`）巩固区分。

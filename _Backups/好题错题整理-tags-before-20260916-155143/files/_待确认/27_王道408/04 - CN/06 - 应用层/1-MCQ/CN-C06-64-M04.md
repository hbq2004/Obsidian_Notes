# 选择题 第 4 题

![[_Attachments/题目识别/27_王道408-题目/CN-C06-64-M04_题目.png|题目]]

4. 用 Firefox(浏览器) 在 Gmail 中向邮件服务器发送邮件时，使用的是（ ）协议。

(A) HTTP  
(B) POP3  
(C) P2P  
(D) SMTP

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C06-64-M04_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：A（HTTP）。理由：用户通过 Firefox 浏览器访问 Gmail 网页发送邮件时，浏览器与 Gmail Web 服务器之间使用 HTTP/HTTPS 协议传递邮件内容；SMTP 是邮件服务器之间或邮件客户端与邮件服务器之间的投递协议，不是浏览器与 Web 服务器之间的协议。

**解题切入点**：拿到题目先抓关键主语——“Firefox(浏览器)”和场景“Gmail”，这立刻锁定为 *Web 邮件*（网页版邮箱）模式，而不是传统的邮件客户端（如 Outlook）直连邮件服务器的模式。考点是应用层协议的“分段”关系：浏览器和 Gmail 服务器之间走 HTTP，Gmail 服务器向收件方邮件服务器投递时才走 SMTP。可以类比算法竞赛中的“分层处理”：你本地的编辑器通过 HTTP 把代码提交到 OJ 后端，OJ 后端再通过内部服务调用判题机；判题机才是真正执行编译运行的“SMTP”。因此，前端请求使用的协议和底层投递使用的协议必须区分开。

**推演**：

1. 用户在 Firefox 中打开 Gmail 网页，填写邮件并点击“发送”。这个操作发生在浏览器和 Gmail 的 Web 服务器之间。
2. 浏览器是 Web 客户端，它只能与 Web 服务器进行 HTTP/HTTPS 通信，将邮件内容（收件人、主题、正文等）封装在 HTTP 请求中提交给 Gmail 服务器。
3. Gmail 服务器收到 HTTP 请求后，再以邮件客户端的身份通过 SMTP 协议与收件人的邮件服务器通信，完成实际投递。

通信路径可表示为：
$$
\text{Firefox} \xrightarrow{\text{HTTP/HTTPS}} \text{Gmail Web 服务器} \xrightarrow{\text{SMTP}} \text{收件人邮件服务器}
$$

4. 题目问“用 Firefox 在 Gmail 中向邮件服务器发送邮件时”所用的协议，指的是用户操作直接涉及的链路，即浏览器到 Gmail 服务器的这一段，因此是 HTTP。
5. 选项辨析：
   - **A. HTTP**：浏览器与 Web 服务器之间的标准协议，正确。
   - **B. POP3**：用于从邮件服务器接收邮件，与发送无关，错误。
   - **C. P2P**：电子邮件采用客户/服务器模式，不是对等网络模式，错误。
   - **D. SMTP**：用于邮件发送，但在本题场景中它位于 Gmail 服务器与收件方服务器之间，不是 Firefox 直接使用的协议，错误。

**易错点**：最常见的是误选 **D. SMTP**，理由是“发送邮件当然用 SMTP”。要特别注意题干中的“Firefox 浏览器”和“Gmail”这两个限定词——如果是使用 Outlook、Foxmail 等邮件客户端直接配置 SMTP 服务器发送邮件，则选 SMTP；但网页版邮箱中，浏览器只通过 HTTP/HTTPS 与 Web 服务器交互。另注意 HTTPS 是 HTTP 的安全版本，在考试中若选项只有 HTTP，应视为同类而选之。

**命题规律**：考查应用层协议的典型使用场景，尤其是电子邮件系统中 SMTP、POP3、IMAP 与 Web 访问协议 HTTP 的区别。常见变式有：问“用 Outlook 发送邮件使用什么协议？”（选 SMTP），“用浏览器登录网页邮箱接收邮件使用什么协议？”（选 HTTP/HTTPS），“Foxmail 接收邮件使用什么协议？”（选 POP3 或 IMAP）。复习时应熟记各协议的功能、默认端口（HTTP 80，HTTPS 443，SMTP 25/465/587，POP3 110，IMAP 143）以及它们分别位于通信路径的哪一段。注意结合“端到端路径逐跳分析”的方法，避免张冠李戴。

# 选择题 第 2 题

![[_Attachments/题目识别/27_王道408-题目/CN-C06-62-M02_题目.png|题目]]

2. 下列说法错误的是( )

(A) $Internet$ 上提供客户访问的主机一定要有域名

(B) 同一域名在不同时间可能解析出不同的 $IP$ 地址

(C) 多个域名可以指向同一台主机 $IP$ 地址

(D) $IP$ 子网中的主机可以由不同的域名服务器来维护其映射

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C06-62-M02_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：A  
理由：Internet 上主机只需要 IP 地址即可被访问，域名并非必需，选项 (A) 表述过于绝对。

**解题切入点**  
本题直接考查 DNS 系统的基本概念与域名的作用。类似算法竞赛中理解“指针”与“别名”的关系：域名是 IP 地址的易记别名，但并非必须；同一域名可对应不同 IP（如负载均衡），多个域名可指向同一 IP（如虚拟主机）。  
**考点定位**：DNS 域名解析、IP 地址与域名的关系。  
**注意**：仔细区分“可以由”与“一定要有”的绝对化表述。

**推演**  
- 选项 (A)：Internet 上客户访问主机时，可以通过 IP 地址直接访问，不需要域名。例如，在浏览器中直接输入 `192.168.1.1` 即可访问对应主机。因此“一定要有域名”错误。  
- 选项 (B)：DNS 支持动态更新、负载均衡（如轮询），同一域名在不同时间可能解析出不同的 IP 地址。例如，大型网站为提高可用性常使用多台服务器，DNS 轮流返回不同 IP。正确。  
- 选项 (C)：一台主机可以配置多个域名（如虚拟主机），多个域名指向同一 IP 地址是常见做法。正确。  
- 选项 (D)：DNS 采用分布式数据库，一个 IP 子网中的主机记录可以由多个域名服务器（如主、从服务器）共同维护。正确。  

综上，只有选项 (A) 错误。

**易错点**  
1. 绝对化表述：“一定要有”容易让人误以为域名是必要条件，实际非必需。  
2. 混淆“域名”与“IP”的等价程度：域名是方便记忆的标识，但底层通信仍依赖 IP。  
3. 对负载均衡场景不熟悉：觉得同一域名应固定对应同一 IP，忽略 DNS 轮询等动态解析机制。  

**命题规律**  
- 考点：DNS 的基本概念、域名与 IP 的对应关系（多对多）、域名解析的灵活性。  
- 变式：常以选择题考查“域名与 IP 地址的关系”，如“域名解析是否必须”“一个域名是否只能对应一个 IP”等。  
- 复习建议：理解 DNS 系统的层次结构与解析过程，关注绝对化表述（如“必须”“一定”）往往是错误选项；结合实例（如负载均衡、虚拟主机）加深记忆。

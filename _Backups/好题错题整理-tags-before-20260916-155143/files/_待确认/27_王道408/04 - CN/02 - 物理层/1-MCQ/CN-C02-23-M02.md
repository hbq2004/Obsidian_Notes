# 选择题 第 2 题

![[_Attachments/题目识别/27_王道408-题目/CN-C02-23-M02_题目.png|题目]]

2.为了使数字信号传输得更远,可采用的设备是( \_ )

(A) 中继器
(B) 放大器
(C) 网桥
(D) 路由器

---

## 答案

![[_Attachments/题目识别/27_王道408-答案/CN-C02-23-M02_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**：A。中继器工作在物理层，能对已衰减、失真的数字信号进行“再生”后继续传输，因此可延长数字信号的传输距离。

**解题切入点**：  
看到“数字信号”和“传输得更远”，应立刻定位到物理层。数字信号传不远的核心原因是波形衰减、畸变，而不是单纯“幅度不够”。所以需要的是能“整形恢复”的设备，而不是简单放大。这就像算法竞赛中某个中间状态被污染后，不能靠整体乘一个系数来修复，而要在关键步骤重新计算恢复；中继器就是给数字信号做“重建”。

**推演**：  
数字基带信号可以看作脉冲序列 $s(t)$。经过信道传输后，由于信道带宽有限、衰减和噪声影响，接收端信号近似为

$$r(t)=s(t)*h(t)+n(t),$$

其中 $h(t)$ 是信道冲激响应，$n(t)$ 是噪声。传输距离越长，衰减和码间串扰越严重。

若采用**放大器**，假设增益为 $A$，则输出为

$$A r(t)=A\left[s(t)*h(t)+n(t)\right].$$

有用信号和噪声被一起放大，信噪比不会改善：

$$\mathrm{SNR}_{\text{out}}=\frac{A^2P_s}{A^2P_n}=\frac{P_s}{P_n},$$

所以放大器适合模拟信号，但不适合数字信号的再生。

若采用**中继器**，它不是简单放大，而是对接收到的数字信号进行“判决—再生”：

$$\hat{s}(t)=\mathrm{Regenerate}\left(r(t)\right),$$

即识别数字信号中的 0/1 电平，重新生成一个干净、完整的波形再发送出去。这样噪声和畸变不会沿线路不断累积，因此数字信号可以传输得更远。

选项分析：

- **中继器**：物理层设备，再生数字信号，正确。  
- **放大器**：主要用于模拟信号，会放大噪声，不能恢复数字波形。  
- **网桥**：数据链路层设备，按 MAC 地址转发帧，不是物理信号再生设备。  
- **路由器**：网络层设备，按 IP 地址转发分组，主要实现网络互连，不是信号再生设备。

**易错点**：  
1. **误选 B“放大器”**：把模拟信号的处理方法套到数字信号上。数字信号应“再生”而不是“放大”。  
2. **误选 C 或 D**：网桥和路由器确实能扩大网络覆盖范围，但题目问的是“数字信号传输得更远”，应选物理层对信号进行再生的中继器。  
3. **忽略中继器级联限制**：中继器不能无限串联，经典以太网遵循“5-4-3 原则”，否则冲突域过大、定时关系无法保证。

**命题规律**：  
本题属于物理层基础题，常考“设备—层次—功能”的对应关系。常见变式有：

- 模拟信号传输更远用**放大器**；  
- 数字信号传输更远用**中继器**；  
- 中继器、集线器、网桥、交换机、路由器分别属于哪一层；  
- 哪些设备隔离冲突域、哪些设备隔离广播域。

复习时建议按层次整理设备功能表：物理层设备重在“信号再生”，数据链路层设备重在“按 MAC 地址转发”，网络层设备重在“按 IP 地址转发”。

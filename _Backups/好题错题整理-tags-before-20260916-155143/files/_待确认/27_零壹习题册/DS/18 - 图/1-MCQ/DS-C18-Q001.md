# MCQ 第 1 题

![[_Attachments/题目识别/27_零壹习题册-题目/DS-C18-Q001_题目.png|题目]]

1. 现存在一个无向图 $G$，存在 20 个度为 $k$ 的顶点，4 个度为 $j$ 的顶点，30 个度为 $h$ 的顶点，6 个度为 $i$ 的顶点，剩余的全部是度为 0 的结点 $z$ 个，则 $G$ 的边有多少条？

(A) $20k + 4j + 30h + 6i$
(B) $10k + 2j + 15h + 3i$
(C) $10k + 2j + 15h + 3i + z$
(D) 无法确定

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/DS-C18-Q001_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。理由：无向图中所有顶点度数之和等于边数的 2 倍，所以边数为 $\dfrac{20k+4j+30h+6i}{2}=10k+2j+15h+3i$。

**解题切入点**：拿到题先不要试图画出图，而应立刻想到“握手定理”：每条边会给两个端点各贡献 1 度，因此所有顶点的度数和是边数的 2 倍。这和统计聚会握手次数一样，每两次“握手”对应一条边。

**推演**：  
设无向图 $G$ 的边数为 $m$。由握手定理：

$$
\sum_{v \in V} \deg(v) = 2m
$$

现在统计所有顶点的度数和：

- 20 个度为 $k$ 的顶点贡献 $20k$；
- 4 个度为 $j$ 的顶点贡献 $4j$；
- 30 个度为 $h$ 的顶点贡献 $30h$；
- 6 个度为 $i$ 的顶点贡献 $6i$；
- $z$ 个度为 0 的顶点贡献 $z \cdot 0 = 0$。

因此：

$$
2m = 20k + 4j + 30h + 6i
$$

两边除以 2：

$$
m = 10k + 2j + 15h + 3i
$$

所以选 **B**。

注意：题干说“存在一个无向图 $G$”，已经隐含 $20k+4j+30h+6i$ 必须是偶数；否则不存在这样的无向图，但这不影响边数公式的形式。

**易错点**：

1. 容易直接选 A：把度数总和 $20k+4j+30h+6i$ 当成边数。错在每条边被两个端点各数了一次，必须除以 2。
2. 容易选 C：把 $z$ 个度为 0 的结点也加进边数公式。度为 0 的顶点对总度数的贡献是 $0$，所以 $z$ 不应出现。
3. 容易选 D：认为不知道具体图结构就无法确定边数。实际上握手定理说明，只要知道各类度数的顶点个数，边数就已经被唯一确定。
4. 忽略存在性：若度数和为奇数，则不可能构成无向图。但题目明确说明图存在，因此不必额外担心。

**命题规律**：本题考点是“握手定理”与度数列性质，是 408 数据结构中图论部分的基础考点。常见变式包括：已知边数反推顶点度数、判断度数序列是否可简单图化、求正则图或完全图的边数、有向图中 $\sum$入度 $=$ $\sum$出度 $=$ 边数。复习时应熟练掌握“无向图度数和 $=2m$”“有向图入度和 $=$ 出度和 $=m$”，并注意每条边对度数的贡献。

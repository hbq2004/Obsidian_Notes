# MCQ 第 10 题

![[_Attachments/题目识别/27_零壹习题册-题目/DS-C11-Q010_题目.png|题目]]

10. 在中序遍历的递归实现算法中，函数启动的结点序列是 （ ） .
(A) 先序序列
(B) 中序序列
(C) 后序序列
(D) 层次序列

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/DS-C11-Q010_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：A。中序遍历递归实现中，函数“启动/进入”的结点序列是先序序列；中序序列只是 `visit(T)` 被执行的序列。

**解题切入点**：拿到题先抓住“函数启动”和“访问结点”不是同一件事。递归遍历的代码中，代码放在函数入口、左右递归之间、右递归之后，分别对应先序、中序、后序。这就像 DFS：进入结点时记录是前序，从左子树回来后记录是中序，回溯时记录是后序。

**推演**：中序遍历的递归实现为

```c
void InOrder(BiTree T) {
    if (T != NULL) {
        InOrder(T->lchild);
        visit(T);
        InOrder(T->rchild);
    }
}
```

设 $F(T)$ 表示对以 $T$ 为根的子树执行中序遍历时，“函数启动”的结点序列，空树不计，$+$ 表示序列拼接。

当 $T$ 非空时：

1. 调用 `InOrder(T)`，首先启动结点 $T$；
2. 接着执行 `InOrder(T->lchild)`，启动左子树中的结点；
3. 左子树返回后执行 `$visit(T)$`，这不是“函数启动”；
4. 最后执行 `InOrder(T->rchild)`，启动右子树中的结点。

因此

$$
F(T)=\langle T\rangle+F(T\to\text{lchild})+F(T\to\text{rchild})
$$

这正是先序遍历的递归定义：

$$
\text{Pre}(T)=\langle T\rangle+\text{Pre}(T\to\text{lchild})+\text{Pre}(T\to\text{rchild})
$$

所以“函数启动”的结点序列是先序序列。

例如二叉树：

```
      A
     / \
    B   C
   / \
  D   E
```

函数启动顺序为：

$$
A,B,D,E,C
$$

这正是先序序列；而中序访问顺序是：

$$
D,B,E,A,C
$$

因此选 **A**。

**易错点**：
- 把“函数启动”等同于“访问结点”，误选 B。中序指的是 `visit(T)` 在左右递归之间，而函数入口在递归体最前面，所以入口顺序是“根左右”。
- 与“函数返回/结束顺序”混淆。递归中序遍历的返回顺序是左子树、右子树、根，属于后序序列；本题问“启动”，不是“返回”。
- 忽略空指针调用；空树不产生结点，不影响结点序列。

**命题规律**：考点是二叉树递归遍历与递归工作栈的时序关系。常见变式有：
1. 中序遍历递归实现中“函数返回”的结点序列是后序序列；
2. 递归调用入栈/出栈顺序与先序、后序序列的对应；
3. 非递归遍历中“第一次/第二次/第三次经过结点”对应先序/中序/后序。

复习建议：记住“进入函数 = 先序，左右之间 = 中序，返回之后 = 后序”，并亲自模拟一棵三结点二叉树的递归栈，分清“启动、访问、返回”三个时刻。

# MCQ 第 1 题

![[_Attachments/题目识别/27_零壹习题册-题目/CO-C07-Q001_题目.png|题目]]

1. 下面各类数据或其它信息中，通过控制总线传输的是 （ ）.

(A) 中断控制器中的中断类型号

(B) I/O 接口控制寄存器中的命令字

(C) 将数据写入 I/O 数据寄存器时的“写入”命令

(D) CPU 访问的 I/O 端口号

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/CO-C07-Q001_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：C。将数据写入 I/O 数据寄存器时的“写入”命令是 CPU 发出的控制信号，通过控制总线传输。

**解题切入点**：拿到题目先分清三类总线各传什么：地址总线传地址，数据总线传数据/编码，控制总线传控制信号。本题是“信息通过哪类总线传输”，逐一识别选项的信息类型即可。

**推演**：
总线按功能分为三类：
- 地址总线（AB）：传输地址信息，用于选择存储单元或 I/O 端口，一般是单向的。
- 数据总线（DB）：传输数据信息，包括真正的数据、指令、状态字、命令字等二进制编码，是双向的。
- 控制总线（CB）：传输控制信号，如时钟、复位、读写命令、中断响应、总线请求/允许等。

对选项逐一分析：
- (A) 中断类型号：由中断控制器在中断应答周期发出，它只是一个编号（如中断向量号），属于数据信息，经数据总线送给 CPU。
- (B) I/O 接口控制寄存器中的命令字：CPU 要将其写入控制寄存器，这个“命令字”在总线上是以数据形式传输的（内容为控制命令，但物理传输属于数据总线）；地址总线给出控制寄存器地址，控制总线给出写信号，因此命令字本身并不是通过控制总线传输。
- (C) “写入”命令：这是 CPU 向接口发送的写控制信号（如 IOW 信号），用于控制接口将数据总线上的数据写入数据寄存器，它属于控制信号，由控制总线传输。
- (D) I/O 端口号：端口号是端口地址，由 CPU 输出，通过地址总线传输。

综上，只有 C 中的“写入”命令是控制总线传输的信息。注意题目中“将数据写入 I/O 数据寄存器时的‘写入’命令”强调的是“写入”这个控制动作，而非被写入的数据。

**易错点**：
1. 误选 B：认为“命令字”是控制信息，从而以为走控制总线。纠错：CPU 与 I/O 接口交换的“命令字”“状态字”“数据”均通过数据总线，控制总线只传引起动作的控制信号。
2. 误选 A：中断类型号虽有“中断”背景，但它实际上是数据信息，不是中断响应信号。
3. 误选 D：端口号看似是“访问 I/O 端口的信息”，但它是地址，走地址总线。
4. 审题不清：题目问“通过控制总线传输的”，要选的是控制信号而不是控制信息/数据。注意区分“控制信息”与“控制信号”。

**命题规律**：
- 考点：总线分类及各类总线的传输对象，常结合 I/O 接口、中断、DMA 等知识点出题。
- 常见变式：给出一组信号，判断属于哪类总线；或问“CPU 响应中断时用于回答中断请求的是哪个信号，走哪类总线”；或结合 DMA 的 HRQ/HLDA 等信号。
- 复习建议：熟记三类总线的典型信号（读写命令、中断响应、总线请求/允许属于控制总线；地址、端口号属于地址总线；数据、指令、命令字、状态字、中断类型号属于数据总线）；做题时先给选项中的“信息”分类，再对号入座。

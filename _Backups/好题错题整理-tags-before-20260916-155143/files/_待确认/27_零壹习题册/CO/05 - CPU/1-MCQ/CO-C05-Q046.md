# MCQ 第 46 题

![[_Attachments/题目识别/27_零壹习题册-题目/CO-C05-Q046_题目.png|题目]]

46. 某共享存储多处理器统一编址，处理器用 load/store 访问所有存储模块；访问本地存储快于远程存储；每个处理器有 Cache，通过目录维护一致性。下列说法正确的是 ( ).  
(A) 该系统属于 UMA，因为统一编址  
(B) 该系统属于 NUMA，且可称为 CC-NUMA  
(C) 该系统属于 SISD，因为每条指令访问一个地址  
(D) 该系统不需要 Cache 一致性机制

---

## 答案

![[_Attachments/题目识别/27_零壹习题册-答案/CO-C05-Q046_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：B。统一编址只说明有一个共享地址空间，“访问本地存储快于远程存储”说明访存时间不均匀，属于 NUMA；每个处理器有 Cache 且用目录维护一致性，因此可称为 CC-NUMA。

**解题切入点**  
先抓两个题眼：**“本地存储快于远程存储”** 和 **“目录维护一致性”**。前者直接决定 UMA/NUMA 的区分：UMA 的“Uniform”指访问时间均匀，NUMA 的“Non-Uniform”指访问时间随存储位置变化；后者说明系统有 Cache 一致性机制，且用的是目录协议。  
像做算法题一样，看到关键特征就应快速定位：`本地快/远程慢 → NUMA`，`目录 + Cache 一致性 → CC-NUMA`。

**推演**  

1. 系统“统一编址，处理器用 load/store 访问所有存储模块”，说明所有存储模块在同一个物理地址空间中。这是共享存储多处理机的基础，但**不足以判断 UMA**。

   UMA 要求任意处理器访问任意存储模块的时间大致相同：
   $$
   T_{\mathrm{access}}(P_i, M_j)\approx T_{\mathrm{access}}(P_k, M_l),\quad \forall i,j,k,l.
   $$

   但题中给出：
   $$
   T_{\mathrm{access}}(P_i, M_{\mathrm{local}})<T_{\mathrm{access}}(P_i, M_{\mathrm{remote}}).
   $$

   因此该系统不满足 UMA，而满足 NUMA。所以选项 A 错误。

2. 每个处理器都有 Cache，多个 Cache 可能同时保存同一个内存块的副本。若不维护一致性，一个处理器写后，其他处理器可能读到旧值，因此必须有 Cache 一致性机制。题中说“通过目录维护一致性”，说明使用的是目录协议，而不是不需要一致性。所以选项 D 错误。

3. 综合来看：系统有 NUMA 特征，又通过目录协议保证 Cache 一致性，所以属于 **CC-NUMA（Cache-Coherent NUMA）**。选项 B 正确。

4. 从 Flynn 分类看，多处理器系统有多个处理器同时取指执行，属于 **MIMD**，不是 SISD。选项 C 说“每条指令访问一个地址”所以是 SISD，这是错误的；访存指令访问几个地址与 Flynn 分类无关。

**易错点**  

- **混淆“统一编址”和“UMA”**  
  统一编址只代表单一地址空间，UMA 中的“Uniform”指 Uniform Memory Access，即访问时间均匀。NUMA 同样可以统一编址。

- **忽视“本地存储快于远程存储”这个关键条件**  
  只要有本地/远程访存速度差异，就不可能是 UMA。这是判断 NUMA 的最直接依据。

- **误以为“有目录维护一致性”等于“不需要一致性”**  
  目录协议正是用来维护 Cache 一致性的，而不是免除一致性机制。

- **Flynn 分类记错**  
  共享存储多处理器通常属于 MIMD；不能根据单条 load/store 指令访问一个地址判断为 SISD。

**命题规律**  
考点定位在“多处理机系统”与“并行体系结构”：UMA/NUMA/CC-NUMA 的区分、Cache 一致性协议、Flynn 分类。  
常见变式：给出 SMP 和总线监听协议 → UMA；给出分布式共享存储且本地/远程速度不同 → NUMA；再给出目录协议维护一致性 → CC-NUMA。  
复习建议：抓住三类关键特征——地址空间是否统一、访存时间是否均匀、Cache 一致性如何维护。掌握“目录 vs 监听”的适用场景，就能快速解这类概念辨析题。

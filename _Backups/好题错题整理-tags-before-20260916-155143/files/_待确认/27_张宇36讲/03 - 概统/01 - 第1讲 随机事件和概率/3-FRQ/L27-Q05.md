# FRQ 第 5 题

![[_Attachments/题目识别/27_张宇36讲-题目/L27-Q05_题目.png|题目]]

对任意的事件 $A,B,C$，证明：
$(1)P(AB) + P(AC) + P(BC) \leqslant P(A) + P(B) + P(C)$；
$(2)$ 当 $P(ABC) = \frac{1}{2}$ 时， $P(AB) + P(AC) + P(BC) \geqslant P(A) + P(B) + P(C) - \frac{1}{2}$。

五、用最值关系式处理事件概率

设 $X,Y$ 为连续型随机变量，且 $P\{X \geqslant 0, Y \geqslant 0\} = \frac{3}{4}, P\{X \geqslant 0\} = P\{Y \geqslant 0\} = \frac{4}{5}$，求下列事件

## 答案

![[_Attachments/题目识别/27_张宇36讲-答案/L27-Q05_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**: 
- (1) 不等式 $P(AB)+P(AC)+P(BC) \le P(A)+P(B)+P(C)$ 成立。
- (2) 当 $P(ABC)=\frac{1}{2}$ 时，不等式 $P(AB)+P(AC)+P(BC) \ge P(A)+P(B)+P(C)-\frac{1}{2}$ 成立。
- 对于第二个问题，由于题目不完整，我们假设常见问题为求 $P(X<0,Y<0)$ 和 $P(X\ge0 \cup Y\ge0)$，则结果为 $P(X<0,Y<0)=\frac{3}{20}$，$P(X\ge0 \cup Y\ge0)=\frac{17}{20}$。若题目有其他要求，可类似计算。

**解题切入点**: 
- 证明题：利用概率的加法公式（容斥原理）将 $P(A)+P(B)+P(C)$ 与 $P(AB)+P(AC)+P(BC)$ 联系起来，得到恒等式，然后利用概率的非负性和有界性得出结论。
- 计算题：根据概率的加法公式和事件的运算关系，利用已知条件求解未知事件的概率。常用技巧是将 $X<0,Y<0$ 视为 $X\ge0 \cup Y\ge0$ 的补集，从而利用容斥原理。

**推演**: 
- 证明题：
  (1) 由概率的加法公式（容斥原理）：
  $$P(A\cup B\cup C) = P(A)+P(B)+P(C)-P(AB)-P(AC)-P(BC)+P(ABC).$$
  移项得：
  $$P(A)+P(B)+P(C)-[P(AB)+P(AC)+P(BC)] = P(A\cup B\cup C) - P(ABC).$$
  由于 $P(A\cup B\cup C) \ge P(ABC)$（因为 $ABC \subseteq A\cup B\cup C$，概率单调），所以右边 $\ge 0$，即
  $$P(A)+P(B)+P(C) \ge P(AB)+P(AC)+P(BC),$$
  故(1)得证。
  (2) 同样由上述恒等式：
  $$P(AB)+P(AC)+P(BC) = P(A)+P(B)+P(C) - P(A\cup B\cup C) + P(ABC).$$
  代入 $P(ABC)=\frac{1}{2}$，得
  $$P(AB)+P(AC)+P(BC) = P(A)+P(B)+P(C) - P(A\cup B\cup C) + \frac{1}{2}.$$
  要证明 $P(AB)+P(AC)+P(BC) \ge P(A)+P(B)+P(C) - \frac{1}{2}$，即证
  $$P(A)+P(B)+P(C) - P(A\cup B\cup C) + \frac{1}{2} \ge P(A)+P(B)+P(C) - \frac{1}{2},$$
  化简得 $-P(A\cup B\cup C) + \frac{1}{2} \ge -\frac{1}{2}$，即 $P(A\cup B\cup C) \le 1$。由于任何事件的概率不超过1，所以不等式成立，故(2)得证。

- 计算题（假设）：
  已知 $P\{X\ge0\}=P\{Y\ge0\}=\frac{4}{5}$，$P\{X\ge0,Y\ge0\}=\frac{3}{4}$。
  求 $P\{X\ge0 \cup Y\ge0\}$ 和 $P\{X<0,Y<0\}$。
  由概率的加法公式：
  $$P\{X\ge0 \cup Y\ge0\} = P\{X\ge0\}+P\{Y\ge0\}-P\{X\ge0,Y\ge0\} = \frac{4}{5}+\frac{4}{5}-\frac{3}{4} = \frac{8}{5}-\frac{3}{4} = \frac{32}{20}-\frac{15}{20} = \frac{17}{20}.$$
  又因为 $\{X<0,Y<0\} = \overline{\{X\ge0 \cup Y\ge0\}}$（对立事件），所以
  $$P\{X<0,Y<0\} = 1 - P\{X\ge0 \cup Y\ge0\} = 1 - \frac{17}{20} = \frac{3}{20}.$$
  其他概率如 $P\{X\ge0,Y<0\}$ 等也可类似求出。

**易错点**: 
- 证明题中，容易忘记使用容斥原理，而试图用单调性直接推导，导致错误。例如，虽然 $P(AB) \le P(A)$，但三个不等式相加不一定能得到结论，因为 $P(AB)+P(AC)$ 可能大于 $P(A)+P(B)+P(C)$ 中的某些项，需要谨慎。正确方法是用容斥原理建立恒等式。
- 证明(2)时，注意不要误以为 $P(A\cup B\cup C) \ge P(ABC)$ 是必要条件，实际上这里只用到 $P(A\cup B\cup C) \le 1$，这是显然的，但需要从恒等式出发。
- 计算题中，注意事件 $\{X<0,Y<0\}$ 的对立事件是 $\{X\ge0 \text{ 或 } Y\ge0\}$，而不是 $\{X\ge0, Y\ge0\}$，容易混淆。另外，注意概率的加法公式不要漏项。

**命题规律**: 
- 证明题考察概率的基本性质（非负性、规范性、可加性）和容斥原理，是概率论的基础题型。常见变式包括证明其他概率不等式，如 $P(AB) \ge P(A)+P(B)-1$，$P(A\cup B) \le P(A)+P(B)$ 等。复习时应熟练掌握概率的加法公式和概率的单调性。
- 计算题考察利用概率的加法公式和事件的运算关系求概率，是概率论的基本计算。常见变式包括已知部分概率求其他概率，如 $P(A\cup B)$、$P(A\cap B)$、$P(A-B)$ 等，有时也涉及条件概率。复习时应熟练掌握事件的运算和概率的加法公式、条件概率公式等。

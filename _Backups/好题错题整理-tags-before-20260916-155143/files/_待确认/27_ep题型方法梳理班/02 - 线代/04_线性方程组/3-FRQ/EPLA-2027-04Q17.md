## V4 Flash Max 解析

**答案**：齐次线性方程组 $AX=0$ 与 $A^T AX=0$ 同解。

---
**解题切入点**：题眼是“同解”即解集合相等。在算法竞赛中，证明两个集合相等通常需要双向包含；这里对应两个方向：$AX=0 \Rightarrow A^TAX=0$ 显然，而反向需要挖掘 $A^TA$ 的“能量”含义。构造 $X^T A^T A X = (AX)^T(AX) = \|AX\|^2$，相当于给判定条件找一个不变量/势能函数，用平方和为零推出向量为零。

---
**推演**：先证 $AX=0$ 的解都是 $A^TAX=0$ 的解。设 $X_0$ 满足 $AX_0=0$，则  
$$A^TAX_0 = A^T(AX_0) = A^T0 = 0,$$  
所以 $X_0$ 是 $A^TAX=0$ 的解。

再证 $A^TAX=0$ 的解都是 $AX=0$ 的解。设 $X_1$ 满足 $A^TAX_1=0$，两边左乘 $X_1^T$，得  
$$X_1^T A^T A X_1 = 0.$$  
注意 $X_1^T A^T = (AX_1)^T$，于是  
$$(AX_1)^T(AX_1) = 0.$$  
记 $Y = AX_1 \in \mathbb{R}^m$，则 $Y^TY = \sum_{i=1}^m y_i^2 = 0$，故 $Y=0$，即 $AX_1=0$。因此 $A^TAX=0$ 的解也都是 $AX=0$ 的解。

综上，两个方程的解集合互相包含，故 $AX=0$ 与 $A^TAX=0$ 同解。

---
**易错点**：  
- 反向推导时忘记左乘 $X^T$，或试图“约去” $A^T$，但矩阵乘法不满足消去律。  
- 将 $Y^TY=0$ 与 $Y=0$ 等同，必须基于实向量；若在复数域应改为 $A^H A X=0$ 并核实实矩阵条件，否则需要用 $Y^HY=0$ 推导。  
- 只证一个方向就下结论，忘记同解需要双向包含。  
- 忽视两个方程个数不同（$m$ 与 $n$）不代表解集不同，解集是未知量维度上的子集，与方程个数无关。

---
**命题规律**：这是线性代数的“超级经典结论”，常用于证明 $\operatorname{rank}(A^TA)=\operatorname{rank}(A)$、最小二乘法的法方程、线性回归中正规方程的解与原方程解的关系。常见变式包括：复数域版本 $AX=0$ 与 $A^H A X=0$ 同解；更一般地，若 $G$ 是正定矩阵，则 $AX=0$ 与 $A^T G A X=0$ 同解。出题思路往往要求考生掌握“同解”的证明框架：先正向后反向，反向时利用二次型构造非负平方和——这就像算法竞赛中通过构造势能函数来证明状态可达/不可达，或者用双指针双向逼近来判断集合相等。

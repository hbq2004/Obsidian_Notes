# MCQ 第 13 题

![[_Attachments/题目识别/EPLA-2027/EPLA-2027-04Q13_题目.png|题目]]

已知 $\beta_1, \beta_2$ 是非齐次线性方程组 $Ax=b$ 的两个不同的解，$\alpha_1, \alpha_2$ 是对应齐次线性方程组 $Ax=0$ 的基础解系，$k_1, k_2$ 为任意常数，则方程组 $Ax=b$ 的通解（一般解）是（ ）.

(A) $k_1\alpha_1 + k_2(\alpha_1 + \alpha_2) + \frac{\beta_1 - \beta_2}{2}$.
(B) $k_1\alpha_1 + k_2(\alpha_1 - \alpha_2) + \frac{\beta_1 + \beta_2}{2}$.
(C) $k_1\alpha_1 + k_2(\beta_1 + \beta_2) + \frac{\beta_1 - \beta_2}{2}$.
(D) $k_1\alpha_1 + k_2(\beta_1 - \beta_2) + \frac{\beta_1 + \beta_2}{2}$.

## V4 Flash Max 解析

**答案**: (B) $k_1\alpha_1 + k_2(\alpha_1 - \alpha_2) + \frac{\beta_1 + \beta_2}{2}$.

---

**解题切入点**: 非齐次线性方程组通解的结构是“齐次通解 + 非齐次特解”。题眼在于：给定的 $\beta_1, \beta_2$ 是特解，它们的和与差分别对应特解和齐次解；基础解系 $\alpha_1, \alpha_2$ 是齐次解空间的基，但选项中齐次部分使用了它们的线性组合，需要验证这些组合是否仍构成一组基（即线性无关且能表示整个齐次解空间）。类似于算法竞赛中，构造辅助函数时需确保变换后的基与原基等价，枚举状态时需覆盖所有可能。

---

**推演**: 

1. 非齐次方程 $Ax=b$ 的通解结构：$x = x_h + x_p$，其中 $x_h$ 为齐次通解，$x_p$ 为一个特解。

2. 已知 $\beta_1, \beta_2$ 是 $Ax=b$ 的两个不同解，则：
   - $A(\beta_1 + \beta_2) = A\beta_1 + A\beta_2 = b + b = 2b$，所以 $A\left(\frac{\beta_1+\beta_2}{2}\right) = b$，即 $\frac{\beta_1+\beta_2}{2}$ 是一个特解。
   - $A(\beta_1 - \beta_2) = A\beta_1 - A\beta_2 = b - b = 0$，所以 $\beta_1 - \beta_2$ 是齐次解，但 $\frac{\beta_1-\beta_2}{2}$ 也是齐次解。

3. 齐次方程 $Ax=0$ 的基础解系为 $\alpha_1, \alpha_2$，故齐次通解为 $k_1\alpha_1 + k_2\alpha_2$，其中 $k_1, k_2$ 为任意常数。

4. 逐一验证选项：
   - **选项 (A)**: 齐次部分 $k_1\alpha_1 + k_2(\alpha_1+\alpha_2) = (k_1+k_2)\alpha_1 + k_2\alpha_2$，令 $c_1=k_1+k_2,\ c_2=k_2$，则 $c_1, c_2$ 可取任意实数，故齐次部分等价于 $c_1\alpha_1+c_2\alpha_2$，但特解部分 $\frac{\beta_1-\beta_2}{2}$ 是齐次解，非特解，因此整体仍为齐次解，不是非齐次通解。
   - **选项 (B)**: 齐次部分 $k_1\alpha_1 + k_2(\alpha_1-\alpha_2) = (k_1+k_2)\alpha_1 - k_2\alpha_2$，令 $c_1=k_1+k_2,\ c_2=-k_2$，则 $c_1, c_2$ 任意，故齐次部分等价于 $c_1\alpha_1+c_2\alpha_2$。特解部分 $\frac{\beta_1+\beta_2}{2}$ 是特解。因此 (B) 为通解。
   - **选项 (C)**: 齐次部分含 $k_2(\beta_1+\beta_2)$，而 $\beta_1+\beta_2$ 不是齐次解（$A(\beta_1+\beta_2)=2b\neq0$），故整体不是 $Ax=b$ 的解（除非 $k_2$ 固定），不符合通解定义。
   - **选项 (D)**: 齐次部分 $k_1\alpha_1 + k_2(\beta_1-\beta_2)$，其中 $\beta_1-\beta_2$ 是齐次解，但 $\alpha_1$ 与 $\beta_1-\beta_2$ 可能线性相关（如 $\beta_1-\beta_2 = \alpha_1$ 时，只能表示一维子空间），不能保证生成整个二维齐次解空间，故不一定为通解。

5. 因此，只有 (B) 满足通解条件。

---

**易错点**: 
- 误将 $\frac{\beta_1-\beta_2}{2}$ 当作特解（实际是齐次解），导致错选 (A) 或 (C)。
- 忽略 $\beta_1-\beta_2$ 与 $\alpha_1$ 可能线性相关，认为 (D) 中 $k_1\alpha_1 + k_2(\beta_1-\beta_2)$ 一定能表示所有齐次解，但未验证线性无关性。类似算法竞赛中，枚举状态时若遗漏了某些线性组合，会导致解空间不完整。
- 混淆“任意常数”与“固定常数”，如 (C) 中 $k_2$ 任意时整体不满足方程。

---

**命题规律**: 
- 考点：非齐次线性方程组通解结构，基础解系的性质，线性无关性判断。
- 常见变式：将基础解系换成其他线性组合，或特解换成其他形式（如 $\beta_1$ 与 $\beta_2$ 的线性组合），要求判断哪个表达式是通解。也可改为填空题，直接写出通解形式。
- 出题思路：考查对通解结构本质的理解，而非死记硬背。需要灵活运用“齐次解空间基的等价变换”和“特解的构造”，类似于算法竞赛中通过构造辅助函数或变换状态空间来简化问题。

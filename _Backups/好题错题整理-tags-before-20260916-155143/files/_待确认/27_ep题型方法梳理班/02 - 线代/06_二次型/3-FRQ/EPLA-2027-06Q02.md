# FRQ 第 2 题

![[_Attachments/题目识别/EPLA-2027/EPLA-2027-06Q02_题目.png|题目]]

设二次型 $f(x_1, x_2, x_3) = 2(a_1 x_1 + a_2 x_2 + a_3 x_3)^2 + (b_1 x_1 + b_2 x_2 + b_3 x_3)^2$，记 $\boldsymbol{\alpha} = \begin{bmatrix} a_1 \\ a_2 \\ a_3 \end{bmatrix}$，$\boldsymbol{\beta} = \begin{bmatrix} b_1 \\ b_2 \\ b_3 \end{bmatrix}$，证明二次型 $f$ 对应的矩阵为 $2\boldsymbol{\alpha}\boldsymbol{\alpha}^{\mathrm{T}} + \boldsymbol{\beta}\boldsymbol{\beta}^{\mathrm{T}}$；

## V4 Flash Max 解析

**答案**: 二次型 $f$ 对应的矩阵为 $2\boldsymbol{\alpha}\boldsymbol{\alpha}^{\mathrm{T}} + \boldsymbol{\beta}\boldsymbol{\beta}^{\mathrm{T}}$。

---

**解题切入点**: 将二次型 $f$ 表示为向量内积的平方，利用二次型与对称矩阵的关系：对于任意列向量 $\boldsymbol{x}$，有 $(\boldsymbol{\alpha}^{\mathrm{T}}\boldsymbol{x})^2 = \boldsymbol{x}^{\mathrm{T}}(\boldsymbol{\alpha}\boldsymbol{\alpha}^{\mathrm{T}})\boldsymbol{x}$，同理 $(\boldsymbol{\beta}^{\mathrm{T}}\boldsymbol{x})^2 = \boldsymbol{x}^{\mathrm{T}}(\boldsymbol{\beta}\boldsymbol{\beta}^{\mathrm{T}})\boldsymbol{x}$。因此 $f = \boldsymbol{x}^{\mathrm{T}}(2\boldsymbol{\alpha}\boldsymbol{\alpha}^{\mathrm{T}} + \boldsymbol{\beta}\boldsymbol{\beta}^{\mathrm{T}})\boldsymbol{x}$，即得对应矩阵。

---

**推演**: 令 $\boldsymbol{x} = \begin{bmatrix} x_1 \\ x_2 \\ x_3 \end{bmatrix}$，则 $a_1x_1+a_2x_2+a_3x_3 = \boldsymbol{\alpha}^{\mathrm{T}}\boldsymbol{x}$，$b_1x_1+b_2x_2+b_3x_3 = \boldsymbol{\beta}^{\mathrm{T}}\boldsymbol{x}$。于是
$$
f = 2(\boldsymbol{\alpha}^{\mathrm{T}}\boldsymbol{x})^2 + (\boldsymbol{\beta}^{\mathrm{T}}\boldsymbol{x})^2 = 2(\boldsymbol{x}^{\mathrm{T}}\boldsymbol{\alpha})(\boldsymbol{\alpha}^{\mathrm{T}}\boldsymbol{x}) + (\boldsymbol{x}^{\mathrm{T}}\boldsymbol{\beta})(\boldsymbol{\beta}^{\mathrm{T}}\boldsymbol{x}) = \boldsymbol{x}^{\mathrm{T}}(2\boldsymbol{\alpha}\boldsymbol{\alpha}^{\mathrm{T}})\boldsymbol{x} + \boldsymbol{x}^{\mathrm{T}}(\boldsymbol{\beta}\boldsymbol{\beta}^{\mathrm{T}})\boldsymbol{x} = \boldsymbol{x}^{\mathrm{T}}(2\boldsymbol{\alpha}\boldsymbol{\alpha}^{\mathrm{T}} + \boldsymbol{\beta}\boldsymbol{\beta}^{\mathrm{T}})\boldsymbol{x}.
$$
由于 $\boldsymbol{\alpha}\boldsymbol{\alpha}^{\mathrm{T}}$ 和 $\boldsymbol{\beta}\boldsymbol{\beta}^{\mathrm{T}}$ 均为对称矩阵，其线性组合 $2\boldsymbol{\alpha}\boldsymbol{\alpha}^{\mathrm{T}} + \boldsymbol{\beta}\boldsymbol{\beta}^{\mathrm{T}}$ 也是对称矩阵，故它就是二次型 $f$ 对应的矩阵。

---

**易错点**: 1. 误将 $(\boldsymbol{\alpha}^{\mathrm{T}}\boldsymbol{x})^2$ 直接写成 $\boldsymbol{x}^{\mathrm{T}}\boldsymbol{\alpha}\boldsymbol{\alpha}^{\mathrm{T}}\boldsymbol{x}$ 时忽略顺序，但注意 $\boldsymbol{\alpha}^{\mathrm{T}}\boldsymbol{x}$ 是标量，其平方等于 $(\boldsymbol{\alpha}^{\mathrm{T}}\boldsymbol{x})^{\mathrm{T}}(\boldsymbol{\alpha}^{\mathrm{T}}\boldsymbol{x}) = \boldsymbol{x}^{\mathrm{T}}\boldsymbol{\alpha}\boldsymbol{\alpha}^{\mathrm{T}}\boldsymbol{x}$，其中 $\boldsymbol{\alpha}\boldsymbol{\alpha}^{\mathrm{T}}$ 是 $3\times3$ 矩阵，不可交换顺序。2. 忘记二次型矩阵必须是对称的，但本题中 $2\boldsymbol{\alpha}\boldsymbol{\alpha}^{\mathrm{T}} + \boldsymbol{\beta}\boldsymbol{\beta}^{\mathrm{T}}$ 自然对称，无需额外对称化。3. 系数 $2$ 容易遗漏或误乘。

---

**命题规律**: 本题主要考查二次型的矩阵表示，尤其是将多个线性形式的平方和转化为矩阵乘积。这是一种常见技巧，类似于算法竞赛中“构造辅助函数”将复杂表达式转化为简洁的矩阵运算（如将状态转移用矩阵乘法表示）。常见变式包括：给出 $(\boldsymbol{a}_i^{\mathrm{T}}\boldsymbol{x})^2$ 的线性组合，求对应矩阵；或利用该形式判断二次型的正定性（如 $\boldsymbol{\alpha}$ 与 $\boldsymbol{\beta}$ 线性无关时秩为 $2$ 等）。出题思路常以“证明”形式出现，要求考生熟练掌握二次型与对称矩阵的一一对应关系。

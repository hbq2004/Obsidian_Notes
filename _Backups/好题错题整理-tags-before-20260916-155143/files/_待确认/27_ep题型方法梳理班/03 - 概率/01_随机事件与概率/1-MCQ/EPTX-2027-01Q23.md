# MCQ 第 23 题

设 $A, B, C$ 三个事件相互独立，则下列命题错误的是( ).

(A) $A+B$ 与 $C$ 必相互独立 
(B) $AB$ 与 $C$ 必相互独立 
(C) $A-B$ 与 $AB$ 必相互独立 
(D) $A-B$ 与 $C$ 必相互独立

## V4 Flash Max 解析

**答案**: (C) $A-B$ 与 $AB$ 必相互独立是错误的。

---

**解题切入点**: 本题考察事件独立性的定义与运算，题眼在于“三个事件相互独立”意味着所有两两独立且三重交概率等于乘积。对于每个选项，只需验证 $P(X \cap Y) = P(X)P(Y)$ 是否由独立性保证。尤其注意 $A-B$ 与 $AB$ 的交集为空，而概率乘积一般不为零，故不独立，类似于构造题中“空集与任何非零集”不可能独立。

---

**推演**: 设 $A,B,C$ 相互独立，则  
$$
P(A\cap B)=P(A)P(B),\quad P(A\cap C)=P(A)P(C),\quad P(B\cap C)=P(B)P(C),\quad P(A\cap B\cap C)=P(A)P(B)P(C).
$$  
逐一验证：  

- (A) $A+B$ 与 $C$：  
  $$P((A\cup B)\cap C)=P(A\cap C)+P(B\cap C)-P(A\cap B\cap C)=P(A)P(C)+P(B)P(C)-P(A)P(B)P(C)=P(C)[P(A)+P(B)-P(A)P(B)],$$  
  $$P(A\cup B)P(C)=[P(A)+P(B)-P(A\cap B)]P(C)=[P(A)+P(B)-P(A)P(B)]P(C),$$ 相等，故独立。  

- (B) $AB$ 与 $C$：  
  $$P((A\cap B)\cap C)=P(A\cap B\cap C)=P(A)P(B)P(C)=P(A\cap B)P(C),$$ 独立。  

- (C) $A-B$ 与 $AB$：  
  $A-B = A\cap B^c$，与 $AB = A\cap B$ 的交集为 $\varnothing$，故  
  $$P((A-B)\cap AB)=0,$$  
  而  
  $$P(A-B)P(AB)=[P(A)-P(A\cap B)]P(A\cap B)=[P(A)-P(A)P(B)]P(A)P(B)=P(A)^2P(B)(1-P(B)),$$  
  一般非零，仅当 $P(A)=0$ 或 $P(B)=0$ 或 $1$ 时相等，但非必然，故不独立。  

- (D) $A-B$ 与 $C$：  
  $$P((A\cap B^c)\cap C)=P(A\cap C)-P(A\cap B\cap C)=P(A)P(C)-P(A)P(B)P(C)=P(A)P(C)(1-P(B)),$$  
  $$P(A\cap B^c)P(C)=[P(A)-P(A\cap B)]P(C)=[P(A)-P(A)P(B)]P(C)=P(A)P(C)(1-P(B)),$$ 独立。  

因此仅 (C) 错误。

---

**易错点**: 误以为 $A-B$ 与 $AB$ 可能独立，忽略两者交集恒为空，而概率乘积通常非零，这类似于枚举状态时漏掉“空集概率为零”的边界条件。另外，计算 $P(A-B)$ 时易错误写成 $P(A)-P(B)$ 或遗忘与 $B$ 独立关系。

---

**命题规律**: 常考事件代数运算的独立性判定，核心是把握独立性的定义与集合运算性质。常见变式包括：将 $A-B$ 换成 $A \triangle B$（对称差）或 $A^c$ 等，并考察与原始事件的独立性。出题思路类似算法竞赛中“构造反例”或“验证条件是否充分”，需熟练运用概率的加法和乘法公式并注意空集的特例。

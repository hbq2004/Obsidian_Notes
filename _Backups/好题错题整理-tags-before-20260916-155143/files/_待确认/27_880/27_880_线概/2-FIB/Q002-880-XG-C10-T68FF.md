# FIB 第 2 题

![[_Attachments/题目识别/880-XG/880-XG-C10-T68FF-Q002_题目.png|题目]]

(2) 设 $\beta_1, \beta_2, \alpha_1, \alpha_2, \alpha_3$ 均是 4 维列向量，且 $|A| = |\beta_1, \alpha_1, \alpha_2, \alpha_3| = 1, |B| = |\beta_2, \alpha_1, 3\alpha_2, \alpha_3| = 3$，则 $|A + B| =$ \_.

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C10-T68FF-Q002_答案.png|答案]]

## V4 Pro Max 解析

**考点**：行列式的列线性性质与列数乘。

**解**
$$A + B = (\beta_1 + \beta_2,\ 2\alpha_1,\ 4\alpha_2,\ 2\alpha_3),$$
每列提出数因子:
$$|A+B| = 2\cdot4\cdot2\cdot\big|\beta_1+\beta_2,\ \alpha_1,\ \alpha_2,\ \alpha_3\big| = 16\big|\beta_1+\beta_2,\ \alpha_1,\ \alpha_2,\ \alpha_3\big|.$$

按第一列线性可加:
$$\big|\beta_1+\beta_2,\ \alpha_1,\ \alpha_2,\ \alpha_3\big| = \big|\beta_1,\alpha_1,\alpha_2,\alpha_3\big| + \big|\beta_2,\alpha_1,\alpha_2,\alpha_3\big| = 1 + \big|\beta_2,\alpha_1,\alpha_2,\alpha_3\big|.$$

又由 $|B| = \big|\beta_2,\alpha_1,3\alpha_2,\alpha_3\big| = 3\big|\beta_2,\alpha_1,\alpha_2,\alpha_3\big| = 3$,得 $\big|\beta_2,\alpha_1,\alpha_2,\alpha_3\big| = 1$。故
$$|A+B| = 16(1+1) = 32.$$

**答案**：$32$.

**易错点**：第 2、4 列的数因子 2、4 各提一次,共 $16$;$\beta_1 + \beta_2$ 拆列时按列线性、符号不变。

# FIB 第 2 题

![[_Attachments/题目识别/880-XG/880-XG-C19-TC67C-14DE7-Q002_题目.png|题目]]

(2) 设随机变量 $X_1, X_2, \cdots, X_n$ 独立同分布，且有相同的概率密度，则概率 $P\left\{X_n > \min\{X_1, X_2, \cdots, X_{n-1}\right\}$ = \_\_\_\_\_\_.

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C19-TC67C-14DE7-Q002_答案.png|答案]]

## V4 Pro Max 解析

**考点**：独立同分布样本的对称性:每个 $X_i$ 成为最大值的概率相等。

**解**
$X_1,\cdots,X_n$ 独立同分布且为连续型(有相同的概率密度),故任意两个取等号的概率为 0,$n$ 个变量的大小顺序等可能,共有 $n!$ 种等可能排列。
事件 $\{X_n>\min\{X_1,\cdots,X_{n-1}\}\}$ 等价于 $X_n$ 是 $n$ 个变量中的最大值,由对称性其概率为
$$\frac{1}{n}.$$

**答案**：$\dfrac1n$。

**易错点**：连续型变量"相等"概率为 0,可直接用对称性;"$X_n$ 是最大"与"$X_n>\min(\text{其余})$"等价,勿被 $\min$ 的写法迷惑。

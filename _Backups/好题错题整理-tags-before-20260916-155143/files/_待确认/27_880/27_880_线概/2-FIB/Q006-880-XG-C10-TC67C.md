# FIB 第 6 题

![[_Attachments/题目识别/880-XG/880-XG-C10-TC67C-Q006_题目.png|题目]]

(6) 设 $A$ 是 $n$ 阶方阵，且 $AA^T = E$， $|A| < 0$，则 $|A + E| = \＿$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C10-TC67C-Q006_答案.png|答案]]

## V4 Pro Max 解析

**考点**：正交矩阵 $|A| = \pm 1$,利用 $|A + E| = |A|\cdot|E + A^T|$ 的"自指"关系求值。

**解**
$AA^T = E \Rightarrow |A|^2 = 1 \Rightarrow |A| = \pm1$;又 $|A| < 0$,故 $|A| = -1$。

$$|A + E| = \big|A(E + A^T)\big| = |A|\cdot\big|E + A^T\big|.$$
转置不改变行列式,$|E + A^T| = |(E + A)^T| = |E + A|$,故
$$|A + E| = -|A + E|,$$
$$2|A + E| = 0 \implies |A + E| = 0.$$

**答案**：$0$.

**易错点**：$|A| < 0$ 定出 $|A| = -1$(正交矩阵行列式只能 $\pm1$);关键是凑出 $|A+E|$ 自指,不必展开 $A$。

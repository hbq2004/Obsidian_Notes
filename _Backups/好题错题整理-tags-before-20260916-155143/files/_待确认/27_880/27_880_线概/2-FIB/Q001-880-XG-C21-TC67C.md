# FIB 第 1 题

![[_Attachments/题目识别/880-XG/880-XG-C21-TC67C-Q001_题目.png|题目]]

(1) 从总体 $X \sim N(3.4, 6^2)$ 中抽取样本 $(X_1, X_2, \cdots, X_n)$，$\overline{X} = \frac{1}{n} \sum\limits_{i=1}^{n} X_i$，若 $\overline{X}$ 位于 (1.4, 5.4) 内的概率不小于 0.95，则样本容量 $n$ 至少应取 \_\_\_\_\_\_。(已知 $\Phi(1.96) = 0.975$)

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C21-TC67C-Q001_答案.png|答案]]

## V4 Pro Max 解析

**考点**：正态总体样本均值的抽样分布与分位数反解样本容量。

**解**

$X\sim N(3.4,6^2)$，$\overline{X}\sim N\left(3.4,\ \frac{6^2}{n}\right)$，标准差 $\sigma_{\overline X}=\frac{6}{\sqrt n}$。

$$P\{1.4<\overline{X}<5.4\}=P\left\{\left|\frac{\overline{X}-3.4}{6/\sqrt n}\right|<\frac{2}{6/\sqrt n}\right\}=2\Phi\left(\frac{\sqrt n}{3}\right)-1.$$

要求不小于 $0.95$：

$$2\Phi\left(\frac{\sqrt n}{3}\right)-1\ge0.95\ \Longrightarrow\ \Phi\left(\frac{\sqrt n}{3}\right)\ge0.975\ \Longrightarrow\ \frac{\sqrt n}{3}\ge1.96,$$

$$\sqrt n\ge5.88\ \Longrightarrow\ n\ge34.57\ \Longrightarrow\ n\ge35.$$

**答案**：$n$ 至少取 $35$。

**易错点**：区间 $(1.4,5.4)$ 关于均值 $3.4$ 对称，半宽 $2$；分位数 $\Phi(1.96)=0.975$ 对应双侧 $0.95$；$n$ 是整数，向上取整到 $35$（$n=34$ 时 $\sqrt{34}/3\approx1.944<1.96$ 不满足）。

# MCQ 第 2 题

![[_Attachments/题目识别/880-XG/880-XG-C21-T68FF-Q002_题目.png|题目]]

(2)设随机变量 $X$，$Y$ 均服从 $N(0,1)$，则（）

A. $X + Y$ 服从正态分布

B. $X^2 + Y^2$ 服从 $\chi^2$ 分布

C. $\frac{X^2}{Y^2}$ 服从 $F$ 分布

D. $X^2$ 与 $Y^2$ 均服从 $\chi^2$ 分布

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C21-T68FF-Q002_答案.png|答案]]

## V4 Pro Max 解析

**考点**：$\chi^2$ 分布的定义（标准正态的平方）与"独立"条件的辨析。

**解**

题面只说 $X,Y\sim N(0,1)$，**未给出 $X,Y$ 独立**。

A：$X+Y$ 服从正态分布需 $X,Y$ 联合正态（独立是最常见充分条件），仅边缘正态不能保证，错误。

B：$X^2+Y^2\sim\chi^2$ 需 $X^2,Y^2$（即 $X,Y$）独立，题面未给，错误。

C：$\dfrac{X^2}{Y^2}\sim F$ 分布需 $X,Y$ 独立，题面未给，错误。

D：$X\sim N(0,1)\Rightarrow X^2\sim\chi^2(1)$；同理 $Y^2\sim\chi^2(1)$。单变量平方服从 $\chi^2(1)$ 与独立性无关，正确。

**答案**：D。

**易错点**：$\chi^2$ 可加性、$t$ 与 $F$ 的构造都依赖独立性假设；本题考的是 $\chi^2$ 分布的**单变量定义**——标准正态的平方恒为 $\chi^2(1)$，与另一个变量无关。

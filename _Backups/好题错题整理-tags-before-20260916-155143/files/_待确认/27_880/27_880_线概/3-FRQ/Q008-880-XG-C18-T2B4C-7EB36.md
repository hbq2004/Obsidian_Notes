# FRQ 第 8 题

![[_Attachments/题目识别/880-XG/880-XG-C18-T2B4C-7EB36-Q008_题目.png|题目]]

(8) 设随机变量 $X$ 与 $Y$ 相互独立且服从同一分布，当 $x \leqslant 0$ 时，$X$ 的概率密度 $f(x) = 0$；当 $x > 0$ 时，$f(x)$ 满足方程 $f'(x) + 2xf(x) = 0, Z = \sqrt{X^2 + Y^2}$，求：

(I) $Z$ 的分布函数与概率密度；

(II) $DZ$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C18-T2B4C-7EB36-Q008_答案.png|答案]]

## V4 Pro Max 解析

**考点**：由微分方程定密度（截断正态型），求 $Z=\sqrt{X^2+Y^2}$ 的分布（极坐标变换）与方差。

**解**

(I) 对 $x>0$，$f'(x)+2xf(x)=0\Rightarrow \frac{f'(x)}{f(x)}=-2x\Rightarrow \ln f(x)=-x^2+C$，即 $f(x)=ce^{-x^2}\ (x>0)$。由归一化

$$1=\int_0^{+\infty} ce^{-x^2}\,dx=c\cdot\frac{\sqrt\pi}{2}\Rightarrow c=\frac{2}{\sqrt\pi}.$$

故 $f(x)=\dfrac{2}{\sqrt\pi}e^{-x^2}\ (x>0)$，$X$ 与 $Y$ 独立同分布。

设 $Z=\sqrt{X^2+Y^2}$。对 $z>0$：

$$F_Z(z)=P\{X^2+Y^2\le z^2\}=\frac{4}{\pi}\iint\limits_{\substack{x>0,y>0\\ x^2+y^2\le z^2}} e^{-(x^2+y^2)}\,dxdy.$$

极坐标：$x=r\cos\theta,\ y=r\sin\theta$，第一象限 $\theta\in[0,\frac\pi2]$：

$$F_Z(z)=\frac{4}{\pi}\int_0^z\int_0^{\pi/2} e^{-r^2}r\,d\theta dr=\frac{4}{\pi}\cdot\frac{\pi}{2}\cdot\frac{1-e^{-z^2}}{2}=1-e^{-z^2}.$$

故 $F_Z(z)=\begin{cases}1-e^{-z^2},&z>0,\\ 0,&z\le 0,\end{cases}$，$f_Z(z)=2ze^{-z^2}\ (z>0)$。

(II) $DZ=E[Z^2]-(EZ)^2$。令 $t=z^2$：

$$E[Z^2]=\int_0^\infty z^2\cdot 2ze^{-z^2}dz=2\int_0^\infty z^3e^{-z^2}dz=\int_0^\infty te^{-t}dt=1;$$

$$E[Z]=\int_0^\infty z\cdot 2ze^{-z^2}dz=2\int_0^\infty z^2e^{-z^2}dz=2\cdot\frac{\sqrt\pi}{4}=\frac{\sqrt\pi}{2}.$$

$$DZ=1-\left(\frac{\sqrt\pi}{2}\right)^2=1-\frac{\pi}{4}.$$

**答案**：(I) $F_Z(z)=\begin{cases}1-e^{-z^2},&z>0,\\0,&z\le0,\end{cases}$，$f_Z(z)=\begin{cases}2ze^{-z^2},&z>0,\\0,&z\le0;\end{cases}$ (II) $DZ=1-\dfrac{\pi}{4}$。

**易错点**：微分方程解出 $f(x)=ce^{-x^2}$ 后由 $\int_0^\infty e^{-x^2}dx=\frac{\sqrt\pi}{2}$ 定 $c$；$E[Z]$ 用到 $\int_0^\infty z^2e^{-z^2}dz=\frac{\sqrt\pi}{4}$，$E[Z^2]$ 换元 $t=z^2$ 化为 $\Gamma$ 函数。

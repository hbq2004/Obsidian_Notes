# FRQ 第 6 题

![[_Attachments/题目识别/880-XG/880-XG-C19-T2B4C-Q006_题目.png|题目]]

(6)设二维随机变量 $(X,Y)$ 服从区域 $D=\{(x,y) \mid 0 \leqslant x \leqslant 2, 0 \leqslant y \leqslant 2\}$ 上的均匀分布.求:

(I). $Z=X+Y$ 的概率密度;

(II). $E(Z^2)$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-XG-C19-T2B4C-Q006_答案.png|答案]]

## V4 Pro Max 解析

**考点**：均匀分布上独立变量之和的密度(卷积/几何法),以及用方差公式求二阶矩。

**解**
(I) $(X,Y)\sim U([0,2]\times[0,2])$,联合密度 $\frac14$。$Z=X+Y$,由卷积公式(或面积法),对 $0\le z\le 2$:
$$F_Z(z)=P\{X+Y\le z\}=\frac{1}{4}\cdot\frac{z^2}{2}=\frac{z^2}{8},\quad f_Z(z)=\frac{z}{4};$$
对 $2<z\le4$,$P\{X+Y\le z\}=1-\frac{(4-z)^2}{8}$,$f_Z(z)=\frac{4-z}{4}$。故
$$\boxed{f_Z(z)=\begin{cases}\dfrac{z}{4},&0\le z\le2,\\[6pt]\dfrac{4-z}{4},&2<z\le4,\\[6pt]0,&\text{其他}.\end{cases}}$$

(II) $E(Z^2)=E\big[(X+Y)^2\big]=E(X^2)+E(Y^2)+2EX\cdot EY$。$X,Y\sim U(0,2)$:
$$EX=EY=1,\qquad E(X^2)=E(Y^2)=\frac{2^2}{3}=\frac43,$$
$$E(Z^2)=\frac43+\frac43+2\cdot1\cdot1=\boxed{\frac{14}{3}}.$$

**答案**：(I) $f_Z(z)$ 为分段三角形密度(见上);(II) $E(Z^2)=\dfrac{14}{3}$。

**易错点**：求 $E(Z^2)$ 直接展开成 $X,Y$ 的矩最省力,不必对密度积分;卷积密度的分段点在 $z=2$,两段在端点处取值连续。

# FRQ 第 23 题

![[_Attachments/题目识别/880-GS/880-GS-C09-T2B4C-6D656-Q023_题目.png|题目]]

(23) 设曲面 $S$ 为球面 $x^2 + y^2 + z^2 = 4z$ 与锥面 $z = \frac{\sqrt{x^2 + y^2}}{\sqrt{3}}$ 所围，且位于锥面上方部分的立体表面，流速场为 $A(x, y, z) = \left( \frac{1}{3} x^3 + x^2 y + x^2 z, \frac{1}{3} y^3 + y^2 z, \frac{1}{3} z^3 \right)$，求 $A(x, y, z)$ 从曲面 $S$ 内部流向外部的流量 $\Phi$.

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C09-T2B4C-6D656-Q023_答案.png|答案]]

## V4 Pro Max 解析

**考点**：高斯公式求流量（第二类曲面积分），散度 $(x+y+z)^2$ 按对称性化简后用球坐标。

**解**
流量 $\Phi=\oiint_S\mathbf A\cdot\mathbf n\,dS=\iiint_\Omega\operatorname{div}\mathbf A\,dV$，其中 $S$ 为立体 $\Omega$ 的封闭表面（外侧）。

$$\operatorname{div}\mathbf A=(x^2+2xy+2xz)+(y^2+2yz)+z^2=(x+y+z)^2.$$

$\Omega$ 由球面 $x^2+y^2+z^2=4z$ 与锥面 $z=\dfrac{\sqrt{x^2+y^2}}{\sqrt3}$（即 $\phi=\dfrac\pi6$）围成，球坐标下 $\rho=4\cos\phi$，$\rho\in[0,4\cos\phi]$，$\phi\in\left[0,\dfrac\pi6\right]$。因 $\Omega$ 绕 $z$ 轴旋转对称，$\iiint_\Omega(xy+xz+yz)dV=0$，故

$$\Phi=\iiint_\Omega(x^2+y^2+z^2)dV=\int_0^{2\pi}d\theta\int_0^{\pi/6}\sin\phi\,d\phi\int_0^{4\cos\phi}\rho^4d\rho=2\pi\int_0^{\pi/6}\frac{(4\cos\phi)^5}{5}\sin\phi\,d\phi.$$

$$\int_0^{\pi/6}\cos^5\phi\sin\phi\,d\phi=\frac16\left(1-\cos^6\frac\pi6\right)=\frac{37}{384},$$

**答案**：$\Phi=2\pi\cdot\dfrac{4^5}{5}\cdot\dfrac{37}{384}=\dfrac{592\pi}{15}$。

**易错点**：① 球面方程化为 $\rho=4\cos\phi$（球心 $(0,0,2)$、半径 $2$）；② 锥面 $\phi=\pi/6$；③ $(x+y+z)^2$ 的交叉项靠旋转对称性消去，避免展开后繁琐积分。

# MCQ 第 5 题

![[_Attachments/题目识别/880-GS/880-GS-C07-T68FF-5FF37-Q005_题目.png|题目]]

(5) 设 $y_1(x)$ 与 $y_2(x)$ 是非齐次微分方程 $y' + P(x)y = Q(x)$ 的两个解。若 $\lambda y_1(x) + \mu y_2(x)$ 仍是该方程的解，则 $e^{\lambda^3 + \mu^3}$ 的最小值为（）。

A. $e^{-1}$

B. $e^{\frac{1}{2}}$

C. $e^{\frac{1}{4}}$

D. $e^{\frac{1}{3}}$

---

## 答案

![[_Attachments/题目识别/880-答案/880-GS-C07-T68FF-5FF37-Q005_答案.png|答案]]

## V4 Pro Max 解析

**考点**：线性方程解的结构 + 均值不等式求最值。

**解**
设 $L[y] = y' + P(x)y$,$L[y_1] = L[y_2] = Q$。由
$$L[\lambda y_1 + \mu y_2] = (\lambda + \mu)Q = Q,$$
得 $\lambda + \mu = 1$。于是
$$\lambda^3 + \mu^3 = (\lambda + \mu)^3 - 3\lambda\mu(\lambda + \mu) = 1 - 3\lambda\mu.$$
由 $\lambda\mu \le \left(\dfrac{\lambda+\mu}{2}\right)^2 = \dfrac14$,得
$$\lambda^3 + \mu^3 \ge 1 - \frac34 = \frac14,$$
等号当 $\lambda = \mu = \dfrac12$ 时取得。故 $e^{\lambda^3+\mu^3} \ge e^{1/4}$。

**答案**：C。

**易错点**：$\lambda^3+\mu^3$ 用恒等式展开为 $1-3\lambda\mu$;$\lambda\mu \le 1/4$ 由 AM-GM 得到,别忘了 $\lambda+\mu=1$ 这个约束。

# MCQ 第 423 题

![[_Attachments/题目识别/27_方浩概统500题-题目/FH-B组6-Q423_题目.png|题目]]

423 设$X_{1}, X_{2}, \cdots, X_{10}$是来自正态总体$X$的简单随机样本，$X$服从正态分布$N(0, \sigma^{2})(\sigma>0)$，$Y^{2}=\frac{1}{10} \sum_{i=1}^{10} X_{i}^{2}$，则 ( ).

(A) $X^{2} \sim \chi^{2}(1)$  
(B) $Y^{2} \sim \chi^{2}(10)$  
(C) $\frac{X}{Y} \sim t(10)$  
(D) $\frac{X^{2}}{Y^{2}} \sim F(1,10)$

---

## 答案


## DeepSeek V4 Flash Max 解析

**答案**：按通常理解，正确选项为 **C、D**；若原题规定为单选题，则题干不严谨，无唯一正确项。  
一句话理由：  
\[
\frac{X}{\sigma}\sim N(0,1),\qquad 
\frac{10Y^{2}}{\sigma^{2}}\sim \chi^{2}(10),
\]
且二者独立，所以
\[
\frac{X}{Y}\sim t(10),
\]
平方后得
\[
\frac{X^{2}}{Y^{2}}\sim F(1,10).
\]

**解题切入点**：  
看到零均值正态样本的平方和，先想 \(\chi^2\) 分布，但要注意标准化系数；看到形如
\[
\frac{\text{标准正态}}{\sqrt{\chi^2/\text{自由度}}}
\]
的结构，定位为 \(t\) 分布；看到两个独立 \(\chi^2\) 之比，定位为 \(F\) 分布。另外要记得：若 \(T\sim t(n)\)，则 \(T^2\sim F(1,n)\)，所以 C、D 其实是成对出现的。

**推演**：  
设
\[
Z_i=\frac{X_i}{\sigma}\sim N(0,1),\qquad i=1,2,\cdots,10,
\]
且相互独立。因此
\[
V=\sum_{i=1}^{10}Z_i^2
=\frac{1}{\sigma^2}\sum_{i=1}^{10}X_i^2
\sim \chi^2(10).
\]

又
\[
Y^2=\frac{1}{10}\sum_{i=1}^{10}X_i^2
=\frac{\sigma^2}{10}V,
\]
所以
\[
\frac{10Y^2}{\sigma^2}=V\sim \chi^2(10).
\]
因此 B 错；正确形式应为
\[
\frac{10Y^2}{\sigma^2}\sim \chi^2(10),
\]
而不是 \(Y^2\sim \chi^2(10)\)。

再看 A。因为
\[
X\sim N(0,\sigma^2),
\]
所以
\[
\left(\frac{X}{\sigma}\right)^2\sim \chi^2(1).
\]
即
\[
\frac{X^2}{\sigma^2}\sim \chi^2(1),
\]
故
\[
X^2\sim \sigma^2\chi^2(1),
\]
不是 \(\chi^2(1)\)，所以 A 错。

按通常约定，取 \(X\) 为与样本独立的总体随机变量，令
\[
Z=\frac{X}{\sigma}\sim N(0,1),
\]
则 \(Z\) 与 \(V\) 独立。于是
\[
\frac{X}{Y}
=
\frac{\sigma Z}{\sqrt{\sigma^2 V/10}}
=
\frac{Z}{\sqrt{V/10}}.
\]
由 \(t\) 分布定义：
\[
\frac{Z}{\sqrt{V/10}}\sim t(10),
\]
所以 C 正确。

进一步，
\[
\frac{X^2}{Y^2}
=
\frac{\sigma^2 Z^2}{\sigma^2 V/10}
=
\frac{Z^2}{V/10}
=
\frac{Z^2/1}{V/10}.
\]
因为
\[
Z^2=\left(\frac{X}{\sigma}\right)^2\sim \chi^2(1),
\qquad V\sim \chi^2(10),
\]
且二者独立，所以由 \(F\) 分布定义：
\[
\frac{X^2}{Y^2}
=
\frac{\chi^2(1)/1}{\chi^2(10)/10}
\sim F(1,10).
\]
因此 D 也正确。

**易错点**：  
1. 漏掉标准化系数：  
   \(X^2\sim \chi^2(1)\) 和 \(Y^2\sim \chi^2(10)\) 都是错的，必须写成
   \[
   \frac{X^2}{\sigma^2}\sim \chi^2(1),\qquad
   \frac{10Y^2}{\sigma^2}\sim \chi^2(10).
   \]
2. 忽略独立性条件：  
   \(t\) 分布和 \(F\) 分布都要求分子、分母独立。若把 \(X\) 理解为样本中的某一个 \(X_i\)，则 \(X\) 与 \(Y\) 不独立，C、D 都不成立。因此应明确 \(X\) 是与样本独立的总体随机变量。  
3. 忽略 \(T^2\) 与 \(F\) 的关系：  
   若 \(T\sim t(n)\)，则 \(T^2\sim F(1,n)\)。所以不能说 C 对而 D 错。

**命题规律**：  
本题主要考查三大抽样分布：\(\chi^2\) 分布、\(t\) 分布、\(F\) 分布。常见变式有：
\[
\frac{\bar X-\mu}{S/\sqrt n}\sim t(n-1),
\]
以及两独立正态总体方差比的 \(F\) 分布。复习时要熟练掌握三大分布的构造式，并特别注意标准化系数和分子分母的独立性。

**知识点**：  
\(\chi^2\)分布、\(t\)分布、\(F\)分布、样本平方和标准化

# FRQ 第 5 题

![[_Attachments/题目识别/1000-GS/1000-GS-TB8A71A-Q005_题目.png|题目]]

5. 设 $f(x)$ 是 $(0, +\infty)$ 内的正值连续函数，且 $f'(x) < 0$，$g(x) = \int_{1}^{x} f(t) \, dt$，则 $g\left(\frac{1}{2}\right)$ 和 $g\left(\frac{3}{2}\right)$ 的可能取值是（）.

---

## 答案

![[_Attachments/题目识别/1000-答案/1000-GS-TB8A71A-Q005_答案.png|答案]]

## V4 Pro Max 解析

**答案**：$g\!\left(\dfrac12\right)<0<g\!\left(\dfrac32\right)$（即 $g\left(\dfrac12\right)$ 为负、$g\left(\dfrac32\right)$ 为正）

**切入点**：$g(x)=\int_1^x f(t)\,dt$ 的正负由积分区间的「方向」决定：下限 $1$ 为基准点，$x<1$ 时积分为负、$x>1$ 时为正。$f'(x)<0$（递减）只影响幅度，不影响符号。像算法里判断「前缀和相对基准的符号」。

**推演**

已知 $f(x)>0$（正值连续函数），$f'(x)<0$（单调递减）。

$$g\!\left(\frac12\right)=\int_1^{\frac12}f(t)\,dt=-\int_{\frac12}^1 f(t)\,dt<0$$

（因 $f>0$，正区间的积分为正，前面加负号得负。）

$$g\!\left(\frac32\right)=\int_1^{\frac32}f(t)\,dt>0$$

故 $g\left(\dfrac12\right)<0<g\left(\dfrac32\right)$。

若需进一步估计幅度，由 $f$ 递减：对 $t\in[\frac12,1]$ 有 $f(t)\ge f(1)$，故 $0>g(\frac12)\ge-\dfrac{f(1)}2$；对 $t\in[1,\frac32]$ 有 $f(t)\le f(1)$，故 $0<g(\frac32)\le\dfrac{f(1)}2$。

**易错点**：⚠ 题干选项缺失（笔记为 FRQ 目录但问「可能取值是( )」），已按符号判定作答。核心易错：① 把 $\int_1^{1/2}$ 误写成 $\int_{1/2}^1$ 而丢负号；② 以为 $f'(x)<0$ 会影响 $g$ 的符号——$f$ 递减只说明被积函数减小，符号仍由 $f>0$ 和积分方向决定；③ 下限不是 $0$ 而是 $1$，基准点变了。

**命题规律**：变上限积分符号判定题。核心：$f>0$ 时 $\int_a^b f$ 的符号由 $a,b$ 大小关系决定；$f$ 的单调性用于进一步放缩估计范围。

# MCQ 第 2 题

![[_Attachments/题目识别/1000-GS/1000-GS-TEB891F-Q002_题目.png|题目]]

2. 设二阶可导函数 $y = f(t)$ 表示某人在 10 分钟内心跳次数的变化曲线，如图所示.则关于此人心跳次数的增长速度，说法正确的是().

A. 0~3 分钟增速变大; 7~10 分钟增速变大    B. 0~3 分钟增速变大; 7~10 分钟增速变小

C. 0~3 分钟增速变大; 7~10 分钟增速变大    D. 0~3 分钟增速变小; 7~10 分钟增速变小

---

## 答案

![[_Attachments/题目识别/1000-答案/1000-GS-TEB891F-Q002_答案.png|答案]]

## V4 Pro Max 解析

**答案**：**B**（0~3 分钟增速变大；7~10 分钟增速变小）

**切入点**：「增速」是 $y=f(t)$ 的一阶导数 $f'(t)$，「增速变大/变小」是 $f'(t)$ 的增减，即二阶导数 $f''(t)$ 的符号。这就像算法里「看单调性 → 看凸性」——一阶看方向，二阶看加速度，别把「跳得快」和「跳得越来越快」混为一谈。

**推演**

设 $y=f(t)$ 表示 $t$ 时刻的累计心跳次数，则：

- 增长速度 $=$ $f'(t)$（斜率）；
- 增速变大 $\iff f'(t)$ 递增 $\iff f''(t)>0 \iff$ 曲线向上凹（凹向上）；
- 增速变小 $\iff f'(t)$ 递减 $\iff f''(t)<0 \iff$ 曲线向下凹（凹向下）。

由题图（S 形「先加速后减速」的典型增长曲线）可知：$0\sim 3$ 分钟曲线凹向上（$f''>0$，斜率越来越大，增速变大）；$7\sim 10$ 分钟曲线凹向下（$f''<0$，斜率越来越小，增速变小）。

**易错点**：⚠ 题干选项 A 与 C 内容完全相同（OCR 疑误，原 C 应为「0~3 增速变小；7~10 增速变大」之类），本题依赖曲线凹凸判断。核心易错是把「增速」（斜率）当成「曲线值」，或把「增速变大」误解为「$f'(t)$ 为负」。记住：问的是 $f''$ 的符号，不是 $f$ 或 $f'$ 的正负。

**命题规律**：图像信息题 + 导数物理意义题。判定「增速的增减」即判定二阶导数符号（凹凸性），这是导数几何/物理意义的高频考法。

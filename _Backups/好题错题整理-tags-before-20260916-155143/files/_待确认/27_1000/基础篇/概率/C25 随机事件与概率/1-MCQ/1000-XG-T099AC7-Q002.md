# MCQ 第 2 题

![[_Attachments/题目识别/1000-XG/1000-XG-T099AC7-Q002_题目.png|题目]]

2. 甲、乙两个篮球队进行比赛，假设有三种可能的结局：甲胜，乙胜与平局。考虑事件 $A = \{甲胜而乙负\}$，则 $\overline{A} = ($ )。

A. $B_1 = \{甲负而乙胜\}$

B. $B_2 = \{平局\}$

C. $B_3 = \{甲胜或平局\}$

D. $B_4 = \{乙胜或平局\}$

---

## 答案

![[_Attachments/题目识别/1000-答案/1000-XG-T099AC7-Q002_答案.png|答案]]

## V4 Pro Max 解析

**答案**：D（$B_4=\{$乙胜或平局$\}$）。

**切入点**：三种结局（甲胜、乙胜、平局）互斥且完备，"甲胜"与"乙负"是同一事件，故 $A=\{$甲胜$\}$ 是单个结果；其对立事件是其余两个结果之并。类比算法竞赛：样本空间的补集。

**推演**

"甲胜而乙负"即"甲胜"（甲胜 ⟺ 乙负）。故 $A=\{$甲胜$\}$。样本空间由三种互斥结果组成，$\overline A$ 为"非甲胜"，即 $\{$乙胜或平局$\}$。

**易错点**：不要把 $\overline A$ 写成"乙胜"（那是另一单个结果，漏了平局）；"甲胜"与"乙负"等价，是同一事件而非两个事件。

**命题规律**：互斥完备事件组的对立事件 = 其余结果之并；解这类题先明确"哪几个基本事件"以及"事件 A 究竟包含哪些基本事件"。

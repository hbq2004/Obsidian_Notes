# MCQ 第 3 题

![[_Attachments/题目识别/1000-XG/1000-XG-TA9276F-Q003_题目.png|题目]]

3. 设总体 $X$ 和 $Y$ 相互独立，且都服从正态分布 $N(0, \sigma^2)$，$X_1, X_2, \cdots, X_n$ 和 $Y_1, Y_2, \cdots, Y_n$ 分别是来自总体 $X$ 和 $Y$ 且容量都为 $n$ 的两个简单随机样本，样本均值，样本方差分别为 $\overline{X}, S_X^2$ 和 $\overline{Y}, S_Y^2$，则()。

A. $\overline{X} - \overline{Y} \sim N(0, \sigma^2)$

B. $S_X^2 + S_Y^2 \sim \chi^2(2n-2)$

C. $\frac{\overline{X} - \overline{Y}}{\sqrt{S_X^2 + S_Y^2}} \sim t(2n-2)$

D. $\frac{S_X^2}{S_Y^2} \sim F(n-1, n-1)$

## V4 Flash Max 解析

**答案**：D。因为 $S_X^2$ 与 $S_Y^2$ 独立，且各自标准化后服从 $\chi^2(n-1)$，二者各除自由度后相比正好消去 $\sigma^2$，所以  
$$F=\frac{S_X^2}{S_Y^2}\sim F(n-1,n-1).$$

**解题切入点**：  
看到“两个正态总体 + 样本均值 + 样本方差”，第一反应就是抽样分布四大模板：$N(0,1)$、$\chi^2$、$t$、$F$。不要整体硬猜，先把每个选项拆成已知分布模板来匹配。这就像算法题里看到复杂表达式，先识别经典模板；两个独立 $\chi^2$ 除以自由度后相比就是 $F$，所以 D 最直接。

**推演**：  
按考研数学常用定义  
$$S^2=\frac1{n-1}\sum_{i=1}^n (X_i-\bar X)^2.$$

因为两总体独立，所以两组样本独立，从而 $\bar X$ 与 $\bar Y$ 独立，$S_X^2$ 与 $S_Y^2$ 独立。

1. 样本均值分布：  
$$\bar X\sim N\left(0,\frac{\sigma^2}{n}\right),\qquad \bar Y\sim N\left(0,\frac{\sigma^2}{n}\right).$$
所以  
$$\bar X-\bar Y\sim N\left(0,\frac{2\sigma^2}{n}\right),$$
不是 $N(0,\sigma^2)$，A 错。

2. 正态总体样本方差性质：  
$$\frac{(n-1)S_X^2}{\sigma^2}\sim \chi^2(n-1),\qquad 
\frac{(n-1)S_Y^2}{\sigma^2}\sim \chi^2(n-1),$$
且二者独立。由 $\chi^2$ 分布可加性，  
$$\frac{(n-1)(S_X^2+S_Y^2)}{\sigma^2}\sim \chi^2(2n-2).$$
所以 $S_X^2+S_Y^2$ 本身不是 $\chi^2(2n-2)$，B 错。

3. 构造 $t$ 统计量：  
令  
$$U=\frac{\bar X-\bar Y}{\sqrt{2\sigma^2/n}}\sim N(0,1),$$
$$V=\frac{(n-1)(S_X^2+S_Y^2)}{\sigma^2}\sim \chi^2(2n-2),$$
且 $U$ 与 $V$ 独立。于是  
$$\frac{U}{\sqrt{V/(2n-2)}}=
\frac{\bar X-\bar Y}{\sqrt{(S_X^2+S_Y^2)/n}}
\sim t(2n-2).$$
选项 C 的分母缺少 $\sqrt n$，所以 C 错。

4. 样本方差比：  
$$F=
\frac{\frac{(n-1)S_X^2/\sigma^2}{n-1}}
{\frac{(n-1)S_Y^2/\sigma^2}{n-1}}
=
\frac{S_X^2}{S_Y^2}
\sim F(n-1,n-1).$$
D 正确。

**易错点**：  
- 容易把 $\bar X-\bar Y$ 的方差写成 $\sigma^2$，实际上是 $\dfrac{2\sigma^2}{n}$。  
- 看到 $S_X^2+S_Y^2$ 就选 $\chi^2$，漏掉了标准化：必须是  
  $$\frac{(n-1)(S_X^2+S_Y^2)}{\sigma^2}\sim \chi^2(2n-2).$$
- $t$ 统计量要记成“差值除以标准误”：  
  $$\widehat{\mathrm{Var}}(\bar X-\bar Y)=\frac{S_X^2}{n}+\frac{S_Y^2}{n}=\frac{S_X^2+S_Y^2}{n},$$
  所以正确分母是 $\sqrt{(S_X^2+S_Y^2)/n}$，不是 $\sqrt{S_X^2+S_Y^2}$。  
- D 可以自检：$\sigma^2$ 在 $F$ 统计量中约掉了，所以不需要知道 $\sigma^2$ 具体值，形式很干净。

**命题规律**：  
该考点是抽样分布基本定理的直接判断。常见变式有：  
- 问 $\dfrac{\bar X-\bar Y}{\sqrt{(S_X^2+S_Y^2)/n}}\sim t(2n-2)$；  
- 问 $\dfrac{(n-1)(S_X^2+S_Y^2)}{\sigma^2}\sim \chi^2(2n-2)$；  
- 若两总体方差不同，则  
  $$\frac{S_X^2/\sigma_X^2}{S_Y^2/\sigma_Y^2}\sim F(n-1,n-1).$$

记忆核心：正态总体样本方差标准化后是 $\chi^2$；两个独立 $\chi^2$ 各除自由度后相比是 $F$；差值除以样本方差构成的标准误是 $t$。

# FRQ 第 7 题

![[_Attachments/题目识别/1000-GS/1000-GS-T424E5D-Q007_题目.png|题目]]

7. 设数列 $\{x_n\}$ 满足 $0 < x_n < \frac{\pi}{2}$, $\cos x_{n+1} - x_{n+1} = \cos x_n$, $n = 1, 2, \dots$.

(1) 证明 $\lim\limits_{n \to \infty} x_n$ 存在并求其值;

(2) 计算 $\lim\limits_{n \to \infty} \frac{x_{n+1}}{x_n^2}$.

---

## 答案

![[_Attachments/题目识别/1000-答案/1000-GS-T424E5D-Q007_答案.png|答案]]

## V4 Pro Max 解析

**答案**：(1) $\lim x_n=0$；(2) $\dfrac{1}{2}$

**切入点**：由 $\cos$ 在 $(0,\frac\pi2)$ 上严格递减，把递推式 $\cos x_{n+1}-x_{n+1}=\cos x_n$ 转成单调性；再用 Taylor 展开求 $\frac{x_{n+1}}{x_n^2}$。这像“隐式递推”——先定方向，再定阶。

**推演**

(1) 递推式即 $x_{n+1}=\cos x_{n+1}-\cos x_n$。若 $x_{n+1}\ge x_n$，则 $\cos x_{n+1}\le\cos x_n$，得 $x_{n+1}=\cos x_{n+1}-\cos x_n\le0$，与 $x_{n+1}>0$ 矛盾；故 $x_{n+1}<x_n$，即 $\{x_n\}$ 严格递减。又有下界 $0$，故收敛，设 $\lim x_n=A\ge0$。对递推式取极限：$\cos A-A=\cos A\Rightarrow A=0$。

(2) 由 $x_{n+1},x_n\to0$，Taylor：$\cos x=1-\frac{x^2}{2}+O(x^4)$，故
$$x_{n+1}=\cos x_{n+1}-\cos x_n=\frac{x_n^2-x_{n+1}^2}{2}+O(x_n^4).$$
两边除以 $x_n^2$：
$$\frac{x_{n+1}}{x_n^2}=\frac12-\frac{x_{n+1}^2}{2x_n^2}+O(x_n^2).$$
由上式知 $x_{n+1}=O(x_n^2)$，故 $\frac{x_{n+1}}{x_n}\to0$，从而 $\frac{x_{n+1}^2}{2x_n^2}\to0$。于是
$$\lim_{n\to\infty}\frac{x_{n+1}}{x_n^2}=\frac12.$$

**易错点**：⚠ 单调性结论是 $x_{n+1}<x_n$（$\cos$ 递减 → 差为负），注意方向；极限值 $A=0$ 不能漏证（取极限时 $x_{n+1},x_n$ 同趋于 $A$）。第 (2) 问务必先建立 $x_{n+1}=O(x_n^2)$ 再消去 $\frac{x_{n+1}^2}{x_n^2}$。

**命题规律**：$x_{n+1}=\cos x_{n+1}-\cos x_n$ 型“隐式递推”用单调性+极限方程定零点，再用 $\cos$ 的 Taylor 展开把邻项差降到 $x_n^2$ 阶求比率。

# FRQ 第 36 题

![[_Attachments/题目识别/1000-GS/1000-GS-TB3F679-Q036_题目.png|题目]]

36. 设平面曲线 $y = y(x)$ 满足 $y(0) = 1$，$y'(0) = 0$，且对曲线上任意点 $P(x, y)$ ($x > 0$)，沿曲线从点 $(0, 1)$ 到点 $P(x, y)$ 的弧长等于该曲线在点 $P(x, y)$ 的切线斜率。

(1) 求 $y(x)$ ($x > 0$)；

(2) 求 $y(x)$ 与 $x = \ln 2$ 及坐标轴所围平面区域 $D$ 的形心.

---

## 答案

![[_Attachments/题目识别/1000-答案/1000-GS-TB3F679-Q036_答案.png|答案]]

## V4 Pro Max 解析

**答案**：(1) $y=\cosh x$；(2) 形心 $\left(\ln 2-\dfrac13,\ \dfrac13\ln 2+\dfrac{5}{16}\right)$。

**切入点**：弧长 $s=\int_0^x\sqrt{1+(y')^2}\,dt$，条件"弧长 = 切线斜率"即 $y'=\int_0^x\sqrt{1+(y')^2}\,dt$，求导得 $y''=\sqrt{1+(y')^2}$；由 $y(0)=1,y'(0)=0$ 解得双曲函数。

**推演**

**(1)** $y'(x)=\displaystyle\int_0^x\sqrt{1+(y')^2}\,dt$，求导：
$$y''=\sqrt{1+(y')^2}.$$
令 $p=y'$，则 $p'=\sqrt{1+p^2}$，$\operatorname{arsinh}p=x+C$。由 $p(0)=0$ 得 $C=0$，故 $p=\sinh x$，即 $y'=\sinh x$。积分 $y=\cosh x+C$，由 $y(0)=1$ 得 $C=0$，故 $y=\cosh x$。

**(2)** 区域 $D=\{(x,y):0\le x\le\ln2,\ 0\le y\le\cosh x\}$。面积
$$A=\int_0^{\ln2}\cosh x\,dx=\sinh(\ln2)=\frac34.$$
$\bar x=\dfrac{1}{A}\iint_D x\,dA$，其中
$$\iint_D x\,dA=\int_0^{\ln2}x\cosh x\,dx=\big[x\sinh x-\cosh x\big]_0^{\ln2}=\frac34\ln2-\frac14,$$
故 $\bar x=\dfrac{\frac34\ln2-\frac14}{3/4}=\ln2-\dfrac13$。

$\bar y=\dfrac{1}{A}\iint_D y\,dA$，其中
$$\iint_D y\,dA=\frac12\int_0^{\ln2}\cosh^2x\,dx=\frac12\int_0^{\ln2}\frac{1+\cosh2x}{2}dx=\frac12\left[\frac12\ln2+\frac{\sinh(2\ln2)}{4}\right].$$
因 $\sinh(2\ln2)=\dfrac{4-1/4}{2}=\dfrac{15}{8}$，得 $\iint_D y\,dA=\dfrac14\ln2+\dfrac{15}{64}$，故
$$\bar y=\frac{\frac14\ln2+\frac{15}{64}}{3/4}=\frac13\ln2+\frac{5}{16}.$$

**易错点**：① $y''=\sqrt{1+(y')^2}$ 的初值 $y'(0)=0$ 由"弧长为 0 时斜率 $=0$"或直接由条件在 $x=0$ 处给出；② 形心公式 $\bar y=\dfrac{\iint y\,dA}{A}$，$\iint y\,dA$ 是 $\int_0^{\ln2}\frac{\cosh^2x}{2}dx$，勿漏 $\frac12$；③ $\cosh^2x$ 用二倍角降幂再积分。

**命题规律**：弧长、面积等几何量设出变上限积分求导转微分方程，解出曲线后再算几何量（形心/体积）；类比算法里"先建模解出状态，再算目标量"。

# MCQ 第 2 题

![[_Attachments/题目识别/1000-GS/1000-GS-T0B82A8-Q002_题目.png|题目]]

2. 若级数 $\sum\limits_{n=1}^{\infty} |u_n v_n|$ 发散，则().

A. $\sum\limits_{n=1}^{\infty} n |u_n|$ 收敛且 $\sum\limits_{n=1}^{\infty} \frac{|v_n|}{n}$ 收敛

B. $\sum\limits_{n=1}^{\infty} n |u_n|$ 发散且 $\sum\limits_{n=1}^{\infty} \frac{|v_n|}{n}$ 收敛

C. $\sum\limits_{n=1}^{\infty} n |u_n|$ 收敛或 $\sum\limits_{n=1}^{\infty} \frac{v_n}{n}$ 发散

D. $\sum\limits_{n=1}^{\infty} n |u_n|$ 收敛或 $\sum\limits_{n=1}^{\infty} \frac{v_n}{n}$ 发散

---

## 答案

![[_Attachments/题目识别/1000-答案/1000-GS-T0B82A8-Q002_答案.png|答案]]

## V4 Pro Max 解析

**答案**：$\displaystyle\sum_{n=1}^{\infty} n|u_n|$ 与 $\displaystyle\sum_{n=1}^{\infty}\frac{|v_n|}{n}$ 中**至少一个发散**（即“发散或发散”型结论；原题选项 OCR 疑有错漏，见易错点）。

**切入点**：由 $|u_nv_n|=(n|u_n|)\cdot\frac{|v_n|}{n}$，把“乘积发散”翻译成“两个因子不能同时收敛”，用反证 + 平方收敛的技巧。类比算法：$ab$ 不收敛 ⇒ $a,b$ 不能都收敛，本质是**反证法**取逆否。

**推演**

假设 $\sum n|u_n|$ 与 $\sum\frac{|v_n|}{n}$ **都收敛**。因收敛级数通项趋于 $0$，故 $n|u_n|\to0$、$\frac{|v_n|}{n}\to0$，当 $n$ 充分大时 $n|u_n|<1$、$\frac{|v_n|}{n}<1$，于是

$$(n|u_n|)^2<n|u_n|,\qquad \Big(\frac{|v_n|}{n}\Big)^2<\frac{|v_n|}{n},$$

由比较判别法知 $\sum(n|u_n|)^2$ 与 $\sum(\frac{|v_n|}{n})^2$ 都收敛。再由均值不等式

$$|u_nv_n|=(n|u_n|)\cdot\frac{|v_n|}{n}\le\frac12\Big[(n|u_n|)^2+\big(\tfrac{|v_n|}{n}\big)^2\Big],$$

推得 $\sum|u_nv_n|$ 收敛，与题设发散矛盾。故二者**至少一个发散**。

**易错点**：⚠ 选项 C、D 在 OCR 中完全相同（均为“$n|u_n|$ 收敛或 $\frac{v_n}{n}$ 发散”），且正确结论应为“**发散或发散**”，原文疑为“收敛/发散”被误识别或漏写绝对值；本题按逻辑逆否求解，不臆造选项。注意 $|v_n|$ 与 $v_n$ 之别，以及“通项趋零 ⇒ 平方被线性控制”这一过渡。

**命题规律**：“乘积 $a_nb_n$ 发散 ⇒ 某因子发散”的固定套路：先假设两因子都收敛，用“收敛 ⇒ 通项趋零 ⇒ $a_n^2\le Ca_n$”叠加均值不等式推出乘积收敛，即反证。掌握 $a_n\to0$ 时 $a_n^2\le C a_n$ 的放缩可秒判。

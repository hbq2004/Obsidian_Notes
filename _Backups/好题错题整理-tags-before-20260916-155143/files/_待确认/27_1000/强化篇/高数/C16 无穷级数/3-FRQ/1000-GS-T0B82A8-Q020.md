# FRQ 第 20 题

![[_Attachments/题目识别/1000-GS/1000-GS-T0B82A8-Q020_题目.png|题目]]

20. 设数列 $\{a_n\}$ 满足 $a_1 = 1$，$(n + 1)a_{n+1} = \left(n + \frac{1}{2}\right)a_n$，证明：当 $|x| < 1$ 时，幂级数 $\sum\limits_{n=1}^{\infty} a_n x^n$ 收敛，并求其和函数.

---

## 答案

![[_Attachments/题目识别/1000-答案/1000-GS-T0B82A8-Q020_答案.png|答案]]

## V4 Pro Max 解析

**答案**：$|x|<1$ 时收敛，和函数 $\displaystyle S(x)=\sum_{n=1}^{\infty}a_nx^n=\frac{2}{\sqrt{1-x}}-2$。

**切入点**：先由递推解出通项 $a_n=\frac{2}{4^n}\binom{2n}{n}$，比值判别证收敛，再利用中心二项式系数的母函数 $\sum\binom{2n}{n}t^n=\frac{1}{\sqrt{1-4t}}$ 求和。类比算法：递推求通项 → 母函数闭合。

**推演**

由 $(n+1)a_{n+1}=(n+\frac12)a_n$ 得 $a_{n+1}=\frac{n+\frac12}{n+1}a_n$，故

$$a_n=\prod_{k=1}^{n-1}\frac{k+\frac12}{k+1}=\frac{\frac32\cdot\frac52\cdots\frac{2n-1}{2}}{n!}=\frac{(2n-1)!!}{2^{n-1}n!}=\frac{2}{4^n}\binom{2n}{n}.$$

（用到 $(2n-1)!!=\frac{(2n)!}{2^nn!}$、$\binom{2n}{n}=\frac{(2n)!}{(n!)^2}$。）

比值判别：$\left|\frac{a_{n+1}x^{n+1}}{a_nx^n}\right|=\frac{n+\frac12}{n+1}|x|\to|x|<1$，故 $|x|<1$ 时收敛。求和：

$$\sum_{n=1}^{\infty}a_nx^n=\sum_{n=1}^{\infty}\frac{2}{4^n}\binom{2n}{n}x^n=2\sum_{n=1}^{\infty}\binom{2n}{n}\Big(\frac{x}{4}\Big)^n.$$

由 $\sum_{n=0}^{\infty}\binom{2n}{n}t^n=\frac{1}{\sqrt{1-4t}}$，令 $t=\frac{x}{4}$ 得

$$S(x)=2\Big(\frac{1}{\sqrt{1-x}}-1\Big)=\frac{2}{\sqrt{1-x}}-2.$$

**易错点**：通项要化成双阶乘/二项式系数形式，别停留在连乘；$\frac{2}{4^n}\binom{2n}{n}$ 中分母是 $4^n$ 而非 $2^n$，务必对应 $t=\frac{x}{4}$。求和起点是 $n=1$，故要减去 $n=0$ 项 $2$，得到 $\frac{2}{\sqrt{1-x}}-2$ 而非 $\frac{2}{\sqrt{1-x}}$。

**命题规律**：递推式给系数 + 求幂级数和，套路是“解递推得 $a_n$ → 识别成二项式系数/已知母函数 → 套 $\sum\binom{2n}{n}t^n=\frac1{\sqrt{1-4t}}$”。中心二项式系数母函数是幂级数求和的高频工具。

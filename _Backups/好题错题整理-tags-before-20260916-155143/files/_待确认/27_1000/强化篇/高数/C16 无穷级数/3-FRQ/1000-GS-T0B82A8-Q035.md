# FRQ 第 35 题

35. 求级数 $\sum\limits_{n=1}^{\infty} \frac{(-1)^{n}}{n(2n-1)}$ 的和.

---

## 答案

![[_Attachments/题目识别/1000-答案/1000-GS-T0B82A8-Q035_答案.png|答案]]

## V4 Pro Max 解析

**答案**：$\displaystyle\sum_{n=1}^{\infty}\frac{(-1)^n}{n(2n-1)}=\ln2-\frac{\pi}{2}$。

**切入点**：部分分式 $\frac{1}{n(2n-1)}=\frac{2}{2n-1}-\frac1n$，再分别化为 $\arctan$（莱布尼茨）级数与 $\ln$ 级数。类比算法：分式拆成两个已知级数的线性组合。

**推演**

设 $\frac{1}{n(2n-1)}=\frac{A}{n}+\frac{B}{2n-1}$，通分比较得 $A=-1,\ B=2$，故

$$\frac{1}{n(2n-1)}=\frac{2}{2n-1}-\frac1n.$$

于是

$$\sum_{n=1}^{\infty}\frac{(-1)^n}{n(2n-1)}=2\sum_{n=1}^{\infty}\frac{(-1)^n}{2n-1}-\sum_{n=1}^{\infty}\frac{(-1)^n}{n}.$$

其中 $\sum_{n=1}^{\infty}\frac{(-1)^n}{2n-1}=\sum_{k=0}^{\infty}\frac{(-1)^{k+1}}{2k+1}=-\sum_{k=0}^{\infty}\frac{(-1)^k}{2k+1}=-\frac\pi4$，$\sum_{n=1}^{\infty}\frac{(-1)^n}{n}=-\ln2$。故

$$=2\Big(-\frac\pi4\Big)-(-\ln2)=\ln2-\frac\pi2.$$

**易错点**：部分分式系数 $A=-1,B=2$（$\frac{2}{2n-1}$ 前是加号）；$\sum\frac{(-1)^n}{2n-1}=-\frac\pi4$ 的符号要与 $\sum\frac{(-1)^n}{2n+1}=\frac\pi4$ 区分（首项为负）；$\sum\frac{(-1)^n}{n}=-\ln2$。

**命题规律**：交错级数 $\sum(-1)^n\frac{1}{n(an+b)}$ 求和，套路是**部分分式**拆成 $\sum\frac{(-1)^n}{2n-1}$（对应 $\frac\pi4$ 的莱布尼茨级数）与 $\sum\frac{(-1)^n}{n}$（对应 $\ln2$）的线性组合。两条标准级数 $\sum_{n\ge0}\frac{(-1)^n}{2n+1}=\frac\pi4$、$\sum_{n\ge1}\frac{(-1)^{n+1}}n=\ln2$ 是核心工具。

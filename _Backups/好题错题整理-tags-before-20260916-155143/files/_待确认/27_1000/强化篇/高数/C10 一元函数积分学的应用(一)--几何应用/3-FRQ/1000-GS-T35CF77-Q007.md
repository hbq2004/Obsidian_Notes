# FRQ 第 7 题

![[_Attachments/题目识别/1000-GS/1000-GS-T35CF77-Q007_题目.png|题目]]

7. 求曲线 $y = e^{-\frac{x}{2}} \sqrt{\sin x}$ ( $x \geqslant 0$ ) 绕 x 轴旋转一周所成旋转体的体积.

---

## 答案

![[_Attachments/题目识别/1000-答案/1000-GS-T35CF77-Q007_答案.png|答案]]

## V4 Pro Max 解析

**答案**：$V=\dfrac{\pi}{2(1-e^{-\pi})}$

**切入点**：曲线只在 $\sin x\ge0$ 的区间（$x\in[2k\pi,(2k+1)\pi]$）有意义，旋转体积是逐段积分再对等比级数求和。

**推演**

$y^2=e^{-x}\sin x$。仅在 $\sin x\ge0$ 处曲线存在，故

$$V=\pi\sum_{k=0}^{\infty}\int_{2k\pi}^{(2k+1)\pi}e^{-x}\sin x\,dx.$$

由 $\displaystyle\int e^{-x}\sin x\,dx=-\frac{e^{-x}}{2}(\sin x+\cos x)$：

$$\int_{2k\pi}^{(2k+1)\pi}e^{-x}\sin x\,dx=\frac{e^{-(2k+1)\pi}}{2}+\frac{e^{-2k\pi}}{2}=\frac{e^{-2k\pi}}{2}(1+e^{-\pi}).$$

于是

$$V=\pi\sum_{k=0}^{\infty}\frac{e^{-2k\pi}(1+e^{-\pi})}{2}=\frac{\pi(1+e^{-\pi})}{2}\cdot\frac{1}{1-e^{-2\pi}}=\frac{\pi}{2(1-e^{-\pi})}.$$

**易错点**：$\sin x<0$ 的区间曲线不存在，不能对 $x\ge0$ 全轴直接积分（会含负贡献）；最后用 $\frac{1+e^{-\pi}}{1-e^{-2\pi}}=\frac1{1-e^{-\pi}}$ 化简。

**命题规律**：含周期因子的广义旋转体积题，先算单段、再对公比 $e^{-2\pi}$ 求和，是"定积分 + 等比级数"的组合拳。

# MCQ 第 7 题

![[_Attachments/题目识别/1000-XG/1000-XG-T54D811-Q007_题目.png|题目]]

7. 设 $A, B, C$ 均为 $n$ 阶矩阵, $r(AB) \leq r(BA)$, 记 $[O_{B} \ AB]$, $[B_{AB} \ BC]$, $[BA_{O} \ BAC]_{B}$ 的秩分别为 $r_{1}, r_{2}, r_{3}$, 则().

A. $r_{2} \leq r_{3} \leq r_{1}$

B. $r_{2} \leq r_{1} \leq r_{3}$

C. $r_{1} \leq r_{2} \leq r_{3}$

D. $r_{3} \leq r_{2} \leq r_{1}$

## V4 Flash Max 解析

答案：D. $r_3 \le r_2 \le r_1$

解析：  
$[B, BC]$ 的列空间为 $\operatorname{im}B + \operatorname{im}(BC)$，而 $\operatorname{im}(BC)\subseteq \operatorname{im}B$，故 $r_2 = r(B)$。  
$[BA, BAC]$ 的列空间为 $\operatorname{im}(BA) + \operatorname{im}(BAC)$，且 $\operatorname{im}(BAC)\subseteq \operatorname{im}(BA)$，故 $r_3 = r(BA)$。  
又 $\operatorname{im}(BA)\subseteq \operatorname{im}B$，所以 $r_3\le r_2$。  
而 $[B, AB]$ 的列空间包含 $\operatorname{im}B$，故 $r_1\ge r(B)=r_2$。  
因此 $r_3\le r_2\le r_1$。

# MCQ 第 8 题

![[_Attachments/题目识别/1000-XG/1000-XG-TE43DC7-Q008_题目.png|题目]]

8. 设 $A, B$ 均为 $n$ 阶矩阵, $|B| \neq 0$, $\alpha$ 为 $n$ 维非零列向量, 则“$\alpha$ 是 $AB$ 的特征向量”是“$B\alpha$ 是 $BA$ 的特征向量”的().

A. 充分必要条件
B. 充分非必要条件
C. 必要非充分条件
D. 既非充分又非必要条件

---

## 答案

![[_Attachments/题目识别/1000-答案/1000-XG-TE43DC7-Q008_答案.png|答案]]

## V4 Pro Max 解析

**答案**：A. 充分必要条件

**切入点**：$|B|\neq 0$ 说明 $B$ 可逆，而 $BA=B(AB)B^{-1}$，即 $AB$ 与 $BA$ 相似。相似变换下特征向量恰好通过 $B$ 搬运——这就像图论里"同构"保持邻接结构、只在顶点间做一一对应重标号：$\alpha$ 与 $B\alpha$ 就是同一个特征结构在两个基下的表达。

**推演**

设 $P=B$，则

$$BA=B(AB)B^{-1},$$

即 $BA$ 与 $AB$ 相似。

**(1) 充分性**：若 $\alpha$ 是 $AB$ 的特征向量，则存在 $\lambda$ 使 $AB\alpha=\lambda\alpha$。两端左乘 $B$：

$$BA\,(B\alpha)=B(AB\alpha)=B(\lambda\alpha)=\lambda\,(B\alpha).$$

又因 $B$ 可逆且 $\alpha\neq 0$，故 $B\alpha\neq 0$，所以 $B\alpha$ 是 $BA$ 的（非零）特征向量。✅

**(2) 必要性**：若 $B\alpha$ 是 $BA$ 的特征向量，则存在 $\mu$ 使 $BA\,(B\alpha)=\mu\,(B\alpha)$，即

$$B(AB\alpha)=B(\mu\alpha).$$

因 $B$ 可逆，左乘 $B^{-1}$ 得 $AB\alpha=\mu\alpha$；又 $\alpha\neq 0$，故 $\alpha$ 是 $AB$ 的特征向量。✅

两方向均成立，故为**充分必要条件**。

**易错点**：⚠ 关键在 $|B|\neq 0$ 只能"推两次"：充分性用它保证 $B\alpha\neq 0$，必要性用它保证能左乘 $B^{-1}$ 消去 $B$。若 $B$ 不可逆，结论一般不再等价。书写时务必点明 $B\alpha\neq 0$，否则 $B\alpha$ 只是"满足 $BA$ 特征方程式的向量"，不构成特征向量（特征向量必须非零）。

**命题规律**：这类"$AB$ 与 $BA$ 特征结构"题的核心套路是把 $BA$ 写成 $B(AB)B^{-1}$ 证相似，再用"相似矩阵同谱、特征向量经 $P$ 搬运"一步到位。同类题型常考 $AB$ 与 $BA$ 的非零特征值相同、$|A|=0$ 时 $AB$ 与 $BA$ 的 0 特征值重数差等。

# FRQ 第 22 题

![[_Attachments/题目识别/900-GS/900-GS-AM-C09-A-Q022_题目.png|题目]]

计算曲面积分 $I = \iint_{\Sigma} \frac{xzdydz + 2ydzdx + 3zdxdy}{\left( x^2 + \frac{y^2}{2} + z \right)^{\frac{1}{2}}}$，其中 $\Sigma$ 是曲面 $y = \sqrt{2(1 - z - x^2)}$ ($z \geq 0$) 的上侧.


---

## 答案

![[_Attachments/题目识别/900-答案/900-GS-AM-C09-A-Q022_答案.png|答案]]

## V4 Flash Max 解析

**答案**: $I = \dfrac{4\sqrt2}{3}\pi$。

**解题切入点**: 先看被积函数分母 $\sqrt{x^2 + \frac{y^2}{2} + z}$,若它在曲面上恰好等于一个常数,积分就能大幅化简——这对应"先化简再积分"的判断。立即把曲面上恒成立的等式找出来:由 $y = \sqrt{2(1 - z - x^2)}$,两边平方得 $y^2 = 2(1 - z - x^2)$,即 $x^2 + \dfrac{y^2}{2} + z = 1$。故在 $\Sigma$ 上分母恒等于 $1$!

**推演**:
1. **化简被积函数**。曲面上 $x^2 + \frac{y^2}{2} + z = 1$,所以
$$\iint_\Sigma \frac{xz\,dy\,dz + 2y\,dz\,dx + 3z\,dx\,dy}{\sqrt{x^2+\frac{y^2}{2}+z}} = \iint_\Sigma \big( xz\,dy\,dz + 2y\,dz\,dx + 3z\,dx\,dy \big).$$
记 $P = xz,\ Q = 2y,\ R = 3z$。

2. **把曲面写成 $z = z(x,y)$ 的形式确定区域**。由 $y=\sqrt{2(1-z-x^2)}\ (y\ge 0,\ z\ge 0)$ 改写为
$$z = 1 - x^2 - \frac{y^2}{2},\qquad y \ge 0,\quad z \ge 0 \iff x^2 + \frac{y^2}{2} \le 1,\ y \ge 0.$$
投影区域 $D = \{(x,y): x^2 + \frac{y^2}{2} \le 1,\ y \ge 0\}$。

3. **上侧定向转换为二重积分**。曲面为 $z=z(x,y)$ 时,取"上侧"(法向量与 $z$ 轴正方向夹角为锐角):
$$\iint_\Sigma P\,dy\,dz + Q\,dz\,dx + R\,dx\,dy = \iint_D \big( -P\,z_x - Q\,z_y + R\big)\,dx\,dy.$$
这里 $z_x = -2x$,$z_y = -y$,故
$$-P z_x - Q z_y + R = xz \cdot 2x + 2y \cdot y + 3z = 2x^2 z + 2y^2 + 3z.$$

4. **换元到圆域便于积分**。令 $u = x,\ v = \frac{y}{\sqrt2}$,则 $y = \sqrt2\,v$,$dx\,dy = \sqrt2\,du\,dv$,区域变为 $u^2+v^2\le 1,\ v\ge 0$。此时 $z = 1 - u^2 - v^2$,被积函数化为
$$2u^2(1-u^2-v^2) + 2(\sqrt2 v)^2 + 3(1-u^2-v^2) = 3 - u^2 + v^2 - 2u^4 - 2u^2v^2.$$

5. **极坐标积分**。令 $u=r\cos\theta,\ v=r\sin\theta$,半圆 $r\in[0,1],\ \theta\in[0,\pi]$,并利用 $\cos^4+\cos^2\sin^2=\cos^2$:
$$I = \sqrt2\int_0^\pi\!\int_0^1 \big(3 - r^2\cos 2\theta - 2r^4\cos^2\theta\big)\,r\,dr\,d\theta.$$
其中 $\int_0^\pi\cos 2\theta\,d\theta = 0$,$\int_0^\pi\cos^2\theta\,d\theta = \frac{\pi}{2}$,于是
$$I = \sqrt2\Big(3\cdot\frac12\cdot\pi - 2\cdot\frac16\cdot\frac{\pi}{2}\Big) = \sqrt2\Big(\frac{3\pi}{2}-\frac{\pi}{6}\Big) = \sqrt2\cdot\frac{4\pi}{3} = \frac{4\sqrt2}{3}\pi.$$

**易错点**:
- 忘记先化简分母 $=1$,直接带着根号去积分,计算量剧增且极易出错。应先由曲面方程平方出恒等式。
- 上侧定向的符号:$\iint P\,dy\,dz+Q\,dz\,dx+R\,dx\,dy$ 对 $z=z(x,y)$ 上侧化为 $\iint_D(-P z_x - Q z_y + R)dx\,dy$,$z_x,z_y$ 前的负号不能丢。
- 换元 $v=y/\sqrt2$ 时 $dx\,dy$ 的雅可比因子 $\sqrt2$ 必须乘上,否则答案差常数倍。
- 自检:令 $r\to$ 积分对称性,含 $\cos2\theta$ 项在半圆上积分为零,符合对称预期;数值上 $\frac{4\sqrt2\pi}{3}\approx 5.92$ 量级与半椭球面积相当,合理。

**命题规律**: 这是"被积函数分母在曲面上恒为常数"的典型构造 —— 往往来自 $x^2+\frac{y^2}{2}+z=1$ 这类扭曲椭球,考查"先化简+上侧定向+重积分"三层。常见变式:分母取平方再对曲面用高斯公式(补平面闭合);或把曲面积分换成都归结到投影区域的二重积分。联系第二类曲面积分与第一类(利用法向量),以及旋转体/椭球参数化的极坐标换元技巧。

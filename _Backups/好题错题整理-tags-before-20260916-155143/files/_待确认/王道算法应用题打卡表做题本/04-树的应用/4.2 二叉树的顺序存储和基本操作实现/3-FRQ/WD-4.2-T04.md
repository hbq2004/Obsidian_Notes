# FRQ 第 3.1.4 题

![[_Attachments/题目识别/王道算法应用题打卡表做题本-题目/WD-4.2-T04_题目.png|题目]]

任务 3：(高优先级)3.1.4 基于上述定义，写一个函数
```c
int leftChild(i)
```
返回结点 $i$ 的左孩子编号.

---

## 答案

![[_Attachments/题目识别/王道算法应用题打卡表做题本-答案/WD-4.2-T04_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：在二叉树顺序存储（按完全二叉树编号，根结点编号为 1）中，结点 $i$ 的左孩子编号为 $2i$。因此最简实现为：

```c
int leftChild(int i) {
    return 2 * i;
}
```

若要求“无左孩子时返回 0”，则需要知道结点总数 $n$，可写成：

```c
int leftChild(int i, int n) {
    if (i < 1 || 2 * i > n) return 0;
    return 2 * i;
}
```

但按原函数签名（只有参数 $i$），通常默认结点 $i$ 的左孩子存在，直接返回 $2i$ 即可。

**解题切入点**：看到“编号”“左孩子”这两个关键词，应立刻联想到完全二叉树的顺序存储结构。这就像用数组实现堆时，知道了下标 $i$，它的左孩子就是下标 $2i$、右孩子就是 $2i+1$，不需要真的“建树”，而是直接通过算术关系寻址，时间复杂度为 $O(1)$。

**推演**：设二叉树按层序编号，根结点编号为 $1$，然后按照自上而下、自左向右的顺序编号。对于编号为 $i$ 的结点，设它位于第 $h$ 层（根为第 $1$ 层），则第 $h$ 层起始编号为 $2^{h-1}$，因此结点 $i$ 是该层第 $i - 2^{h-1} + 1$ 个结点。

它的左孩子位于第 $h+1$ 层，第 $h+1$ 层起始编号为 $2^h$。在完全二叉树中，上一层每个结点对应下一层的两个连续结点（左、右孩子），所以结点 $i$ 的左孩子是第 $h+1$ 层的第 $2(i - 2^{h-1} + 1) - 1$ 个结点。于是左孩子编号为：

$$
2^h + \left[2(i - 2^{h-1} + 1) - 1\right] - 1
= 2^h + 2i - 2^h
= 2i.
$$

因此，结点 $i$ 的左孩子编号为 $2i$。同理，右孩子编号为 $2i + 1$，双亲编号为 $\lfloor i/2 \rfloor$。

**易错点**：
1. 编号从 $1$ 开始，而不是从 $0$ 开始。若从 $0$ 开始，左孩子编号才是 $2i+1$，本题默认从 $1$ 开始，所以是 $2i$。
2. 容易把 $2i$ 和 $2i+1$ 记反：$2i$ 是左孩子，$2i+1$ 是右孩子。
3. 忽略边界条件：若 $2i > n$，结点 $i$ 没有左孩子，但原函数只有 $i$ 一个参数，无法判断；若题目要求返回 $0$ 表示不存在，则需要额外传入结点总数 $n$ 或使用全局变量。
4. 不要误以为需要遍历二叉树才能找到左孩子，顺序存储下直接计算即可。

**命题规律**：本题属于“二叉树顺序存储结构”的基础计算题，考查完全二叉树中父子结点编号关系。常见变式包括：求右孩子编号 $2i+1$、求双亲编号 $\lfloor i/2 \rfloor$、判断某结点是否为叶子结点、求指定结点的层次等。复习时应熟练掌握编号公式，并注意与链式存储结构区分；同时可以结合堆排序中的数组下标操作加深理解。

**知识点**：完全二叉树、顺序存储结构、二叉树性质

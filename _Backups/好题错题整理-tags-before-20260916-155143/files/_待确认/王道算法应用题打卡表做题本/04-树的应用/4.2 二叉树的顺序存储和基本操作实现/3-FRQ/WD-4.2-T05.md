# FRQ 第 3.1.5 题

任务4：(高优先级)3.1.5 基于上述定义，写一个函数 $int\ rightChild(i)$，返回结点 $i$ 的右孩子编号.

## 答案

![[_Attachments/题目识别/王道算法应用题打卡表做题本-答案/WD-4.2-T05_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：  
在顺序存储的完全二叉树中，若结点编号从 0 开始，则结点 $i$ 的右孩子编号为  
$$
rightChild(i)=2i+2
$$  
且右孩子存在时需要满足 $2i+2<n$，其中 $n$ 为顺序存储数组中的结点个数；不存在时返回 $-1$。  
若题目定义根结点编号从 1 开始，则公式改为 $2i+1$，存在条件为 $2i+1 \le n$。

按常见的“根结点编号为 0”实现：

```c
#define MaxSize 100

typedef struct {
    int data[MaxSize];
    int n;      // 当前顺序存储二叉树中的结点个数
} SqBiTree;

SqBiTree T;

// 返回结点 i 的右孩子编号；不存在或 i 非法时返回 -1
int rightChild(int i) {
    if (i < 0 || i >= T.n) {
        return -1;
    }
    int r = 2 * i + 2;
    if (r >= T.n) {
        return -1;
    }
    return r;
}
```

**解题切入点**：  
看到“返回结点 $i$ 的右孩子编号”应立刻联想到二叉树顺序存储，也就是“数组模拟完全二叉树/堆”的下标映射关系。这类题的核心不是递归，而是找编号公式。拿到题目先确认根结点编号是 0 还是 1：根编号为 0 时右孩子是 $2i+2$，根编号为 1 时右孩子是 $2i+1$。可类比堆排序中数组存堆的写法。

**推演**：  
在顺序存储中，二叉树按层序编号。以根结点编号为 0 为例：

- 根结点 0 的左、右孩子编号分别为 1、2；
- 结点 $i$ 之前的结点为 $0,1,\dots,i-1$，共 $i$ 个结点；
- 在补成完全二叉树的编号框架中，这 $i$ 个结点共有 $2i$ 个孩子位置，依次占据编号 $1$ 到 $2i$；
- 因此结点 $i$ 的左右孩子从 $2i+1$ 开始：
  - 左孩子：$2i+1$；
  - 右孩子：$2i+2$。

所以：
$$
rightChild(i)=2i+2
$$

右孩子是否存在，要看对应位置是否在有效存储范围内：
$$
2i+2 < n
$$

若超出范围，说明该右孩子不存在，返回 $-1$。

若根结点编号从 1 开始，则结点 $i$ 之前的结点有 $i-1$ 个，其孩子位置从 2 开始，因此左孩子为 $2i$，右孩子为 $2i+1$。

**易错点**：  
1. 混淆 0 编号和 1 编号：根编号为 0 时右孩子是 $2i+2$，根编号为 1 时右孩子是 $2i+1$，一定先确认题目定义。  
2. 不判越界：若直接返回 $2i+2$，可能返回一个不存在的结点编号；在代码题中要判断 $2i+2<n$。  
3. 用 0 表示“不存在”要小心：如果根结点编号从 0 开始，0 是合法根结点编号，不能用来表示空；通常返回 $-1$。  
4. 如果是普通二叉树补空后顺序存储，光用 $2i+2<n$ 判断还不够，还需要判断数组对应位置是否为规定的空标记，例如 `EMPTY`。

**命题规律**：  
这是二叉树顺序存储的基础考点，常以选择题或代码填空题形式出现。常见变式有：求左孩子、求双亲、判断叶子结点、判断是否为完全二叉树、堆排序中的数组下标关系等。复习时应把“结点编号从 0 开始”和“从 1 开始”两套公式都记住，并通过堆排序、二叉堆题目反复熟练。

# FRQ 第 ZT-06 题

![[_Attachments/题目识别/王道算法应用题打卡表做题本-题目/WD-ZT-T06_题目.png|题目]]

任务6：(必做) 2014应用题：42题 王道书6.4.6_大题_10 (页码244)
【2014统考真题】某网络中的路由器运行 OSPF 路由协议，下表是路由器 R1 维护的主要链路状态信息(LSI)，R1 构造的网络拓扑图是根据题下表及 R1 的接口名构造出来的网络拓扑。请回答下列问题：

| Link2 ID | 10.1.1.5     | 10.1.1.6     | 10.1.1.1     | 10.1.1.2     | 所连路由器的Router ID    |

(1) 本题中的网络可抽象为数据结构中的哪种逻辑结构？针对表中的内容，设计合理的链式存储结构，以保存表中的链路状态信息(LSI)。

## DeepSeek V4 Flash Max 解析

**答案**：

(1) 该网络可抽象为**无向带权连通图**。路由器是顶点，路由器之间的链路是边，链路 Metric 是边权；各路由器直连的 `192.1.x.x/24` 子网可看作连在对应路由器上的叶子顶点。由于图中存在环，不是树，而是图。

(2) 链式存储采用“LSI 链 + 链路结点链 + 直连网络结点链”的结构。类型定义和存储示意图见“推演”。

(3) R1 到各子网的最短路径为：

| 目的子网 | 最短路径 | 费用 |
|---|---|---|
| 192.1.1.0/24 | R1 → 该子网 | 1 |
| 192.1.5.0/24 | R1 → R3 → 该子网 | 3 |
| 192.1.6.0/24 | R1 → R2 → 该子网 | 4 |
| 192.1.7.0/24 | R1 → R2 → R4 → 该子网 | 8 |

---

**解题切入点**：

看到“OSPF”“链路状态信息 LSI”“Dijkstra”就应该立刻定位到**数据结构中的图**。OSPF 的链路状态数据库本质上就是一张带权图：每一条 LSI 中的 Link 都描述了一条边，Net 描述了一个直连网络。做题时先不要着急算最短路，先把 LSI 表“翻译”成拓扑图；图建对了，Dijkstra 就是常规计算。类似算法竞赛中“最短路题必须先建图，再跑算法”。

---

**推演**：

### 1. 还原网络拓扑

由 LSI 表中的 Link 关系可以还原出如下拓扑：

```text
    192.1.1.0/24       192.1.6.0/24
         |1                 |1
        R1 ------3--------- R2
        |                   |
        2                   4
        |                   |
        R3 ------6--------- R4
         |                  |
         |1                 |1
    192.1.5.0/24       192.1.7.0/24
```

对应关系为：

- R1 与 R2 之间：费用 3；
- R1 与 R3 之间：费用 2；
- R2 与 R4 之间：费用 4；
- R3 与 R4 之间：费用 6；
- R1、R2、R3、R4 分别直连 `192.1.1.0/24`、`192.1.6.0/24`、`192.1.5.0/24`、`192.1.7.0/24`，费用均为 1。

因此这是**无向带权图**。

### 2. 链式存储结构设计

可以设计如下结点类型：

```c
// 邻接路由器链路结点，对应 LSI 中的 Link1、Link2 等
typedef struct LinkNode {
    char neighborID[16];   // 对端路由器 Router ID
    char localIP[16];      // 本端接口 IP，即 Link IP
    int metric;            // 链路费用
    struct LinkNode *next;
} LinkNode;

// 直连网络结点，对应 LSI 中的 Net1 等
typedef struct NetNode {
    char prefix[20];       // 网络前缀，如 "192.1.1.0/24"
    int metric;            // 到达该直连网络的费用
    struct NetNode *next;
} NetNode;

// 每个路由器对应一个 LSI 头结点
typedef struct LSANode {
    char routerID[16];     // 路由器 Router ID
    LinkNode *linkHead;    // 邻接链路链表头
    NetNode *netHead;      // 直连网络链表头
    struct LSANode *next;  // 指向下一个 LSI
} LSANode;

// 整个链路状态数据库
typedef struct {
    LSANode *head;         // LSDB 链头
} LSDB;
```

对应表的链式存储示意图如下，图中用 `(对端ID, 本端IP, Metric)` 表示一个 LinkNode，用 `(网络前缀, Metric)` 表示一个 NetNode：

```text
LSDB头 → [R1 LSI] → [R2 LSI] → [R3 LSI] → [R4 LSI] → ∧

R1 LSI:
  linkHead → (R2, 10.1.1.1, 3) → (R3, 10.1.1.9, 2) → ∧
  netHead  → (192.1.1.0/24, 1) → ∧

R2 LSI:
  linkHead → (R1, 10.1.1.2, 3) → (R4, 10.1.1.13, 4) → ∧
  netHead  → (192.1.6.0/24, 1) → ∧

R3 LSI:
  linkHead → (R4, 10.1.1.5, 6) → (R1, 10.1.1.10, 2) → ∧
  netHead  → (192.1.5.0/24, 1) → ∧

R4 LSI:
  linkHead → (R3, 10.1.1.6, 6) → (R2, 10.1.1.14, 4) → ∧
  netHead  → (192.1.7.0/24, 1) → ∧
```

### 3. Dijkstra 求 R1 到各子网的最短路径

以 R1 为源点，将子网也作为叶子顶点纳入 Dijkstra 计算。

初始：

- $d(R1)=0$；
- 经过 R1 可得到：
  - $d(R2)=3$
  - $d(R3)=2$
  - $d(192.1.1.0/24)=1$

按 Dijkstra 的选点顺序可整理为：

| 次序 | 确定对象 | 费用 | 最短路径 |
|---|---|---|---|
| 1 | R1 | 0 | 起点 |
| 2 | 192.1.1.0/24 | 1 | R1 → 192.1.1.0/24 |
| 3 | R3 | 2 | R1 → R3 |
| 4 | R2 | 3 | R1 → R2 |
| 5 | 192.1.5.0/24 | 3 | R1 → R3 → 192.1.5.0/24 |
| 6 | 192.1.6.0/24 | 4 | R1 → R2 → 192.1.6.0/24 |
| 7 | R4 | 7 | R1 → R2 → R4 |
| 8 | 192.1.7.0/24 | 8 | R1 → R2 → R4 → 192.1.7.0/24 |

其中第 4 步和第 5 步中，$R2$ 与 `192.1.5.0/24` 的最短费用都为 3，因此选点顺序可以交换，不影响最终结果。

最终 R1 的 SPF 树可表示为：

```text
R1
├── 192.1.1.0/24 (1)
├── R3 (2)
│    └── 192.1.5.0/24 (3)
└── R2 (3)
     ├── 192.1.6.0/24 (4)
     └── R4 (7)
          └── 192.1.7.0/24 (8)
```

注意：R4 虽然也可以由 R3 到达，费用为 $2+6=8$，但由 R2 到达费用为 $3+4=7$，所以 R4 的最短路径是 **R1 → R2 → R4**。

---

**易错点**：

1. **把 Link IP 当作目的地址或网段**。表中的 `Link1 IP`、`Link2 IP` 是本端接口 IP，不是对端网络地址，也不是边权。
2. **忘记加直连网络的 Metric**。Dijkstra 算到路由器后，还要加上该路由器到直连子网的费用 1。例如 R1 到 R2 的费用是 3，到 `192.1.6.0/24` 的费用是 $3+1=4$。
3. **提前停止更新 R4**。R4 先可能通过 R3 得到费用 8，但后来通过 R2 可更新为 7；Dijkstra 中必须保留较小的候选值。
4. **用邻接矩阵回答链式存储**。题目明确要求链式存储，应使用邻接表/LSI 链式结构，而不是只写邻接矩阵。

---

**命题规律**：

该题是“数据结构 + 计算机网络”的经典结合题。考点定位在**图的逻辑结构、图的链式存储、Dijkstra 算法**，背景是 OSPF 链路状态路由协议。常见的变式有：

- 给出路由表/LSI，要求画拓扑图；
- 用 Dijkstra 求单源最短路径；
- 把 OSPF 换成 RIP，则可能改为距离向量算法；
- 要求写出路由表下一跳和费用。

复习时要注意：能根据路由协议信息还原出图结构，能手算 Dijkstra，并熟练掌握邻接表、邻接矩阵的定义与适用场景。

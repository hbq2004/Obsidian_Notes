# FRQ 第 ZT-13 题

![[_Attachments/题目识别/王道算法应用题打卡表做题本-题目/WD-ZT-T13_题目.png|题目]]

任务 13: (必做) 2021 应用题: 42 题 王道书 8.5.4_大题_3 (页码 369)
【2021统考真题】已知某排序算法如下：
```c
void cmpCountSort(int a[], int b[], int n){
    int i, j, *count;
    count=(int *)malloc(sizeof(int)*n);//C++语言: count=new int[n];
    for(i=0;i<n;i++)    count[i]=0;
    for(i=0;i<n-1;i++)
        for(j=i+1;j<n;j++)
            if(a[i]<a[j])    count[j]++;
            else              count[i]++;
    for(i=0;i<n;i++)    b[count[i]]= a[i];
    free(count);        //C++语言: delete count;
}
```
请回答下列问题.
1) 若有 `int a[]={25, -10, 25, 10, 11, 19}, b[6];`，则调用 `cmpCountSort(a,b,6)` 后数组 b 中的内容是什么?
2) 若 a 中含有 n 个元素，则算法执行过程中，元素之间的比较次数是多少?
3) 该算法是稳定的吗？若是，阐述理由；否则，修改为稳定排序算法.

## 答案

![[_Attachments/题目识别/王道算法应用题打卡表做题本-答案/WD-ZT-T13_答案.png|答案]]

## DeepSeek V4 Flash Max 解析

**答案**：  
1. 调用后 \(b=\{-10,10,11,19,25,25\}\)。  
2. 元素之间的比较次数为 \(\frac{n(n-1)}{2}\)。  
3. 该算法不稳定。将原代码中的 `if (a[i] < a[j])` 改为 `if (a[i] <= a[j])`，即相等时给右边的元素 `count[j]++`，其余不变，即可得到稳定排序。

**解题切入点**：  
看到两层循环对每个数对比较一次，并用 `count` 数组记录“名次”，应立刻定位到“基于比较的计数排序变体”。关键是想清楚 `count[i]` 到底表示“有几个元素应排在 \(a[i]\) 前面”。稳定性问题只需要看相等元素由谁计数：原代码在相等时走 `else`，给左边的元素计数，所以相等元素的相对次序会被颠倒。

**推演**：  

### (1) 求原算法下数组 \(b\)

原算法中，`count[i]` 的语义为：

\[
count[i]=|\{k<i:a[k]<a[i]\}|+|\{j>i:a[j]\le a[i]\}|
\]

即：前面比它小的元素个数，加上后面小于等于它的元素个数。

对 \(a=\{25,-10,25,10,11,19\}\)：

| \(i\) | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---:|---:|---:|---:|---:|---:|
| \(a[i]\) | 25 | -10 | 25 | 10 | 11 | 19 |
| \(count[i]\) | 5 | 0 | 4 | 1 | 2 | 3 |

赋值过程为：

\[
b[5]=25,\quad b[0]=-10,\quad b[4]=25,\quad b[1]=10,\quad b[2]=11,\quad b[3]=19
\]

所以：

\[
b=\{-10,10,11,19,25,25\}
\]

### (2) 比较次数

内层循环对每一对 \((i,j)\)（其中 \(0\le i<j\le n-1\)）执行一次元素比较，因此总比较次数为：

\[
\sum_{i=0}^{n-2}(n-i-1)=\frac{n(n-1)}{2}
\]

该次数与初始数据排列无关，最好、最坏、平均都是 \(\frac{n(n-1)}{2}\)。

### (3) 稳定性分析与修改

原算法不稳定。例如取：

\[
a[0]=2,\quad a[1]=2
\]

原代码执行：

\[
a[0]<a[1]
\]

为假，所以执行 `count[0]++`，得到：

\[
count[0]=1,\quad count[1]=0
\]

于是：

\[
b[1]=a[0],\quad b[0]=a[1]
\]

后一个 2 排到了前一个 2 的前面，相对次序改变，因此不稳定。

修改为稳定排序算法如下：

```c
void cmpCountSortStable(int a[], int b[], int n) {
    int i, j, *count;
    count = (int *)malloc(sizeof(int) * n);

    for (i = 0; i < n; i++)
        count[i] = 0;

    for (i = 0; i < n - 1; i++)
        for (j = i + 1; j < n; j++)
            if (a[i] <= a[j])   // 仅将 < 改为 <=
                count[j]++;
            else
                count[i]++;

    for (i = 0; i < n; i++)
        b[count[i]] = a[i];

    free(count);
}
```

修改后，对于任意一对 \(i<j\)：

- 若 \(a[i]\le a[j]\)，则 \(a[j]\) 在稳定排序后应排在 \(a[i]\) 后面，所以 `count[j]++`；
- 若 \(a[i]>a[j]\)，则 \(a[i]\) 在稳定排序后应排在 \(a[j]\) 后面，所以 `count[i]++`。

因此修改后的 `count[i]` 正好是稳定排序后 \(a[i]\) 应存放的下标：

\[
count[i]=|\{k:a[k]<a[i]\}|+|\{k<i:a[k]=a[i]\}|
\]

从左到右执行 \(b[count[i]]=a[i]\)，相等元素会按原下标递增顺序放入 \(b\)，所以算法稳定。

**易错点**：  
- 误以为元素比较次数与输入数据有关。本算法没有提前终止机制，永远比较 \(\frac{n(n-1)}{2}\) 次。  
- 把循环变量的比较也算入“元素比较次数”。题目问的是 \(a[i]\) 与 \(a[j]\) 之间的比较。  
- 稳定性反例不能选 `{2,1}`，必须选有相等元素的数组，例如 `{2,2}`，才能看出相对次序是否改变。  
- 修改稳定性时，只改最后赋值方向不能解决问题；必须改变相等元素的计数归属，让相等时给右边的元素计数。

**命题规律**：  
408 常以“给一段排序代码，要求判断排序结果、比较次数、稳定性”的形式出题。该题本质是计数排序变体，重点考查 `count` 数组的语义和相等元素的处理。复习时应将常见排序算法的比较次数、稳定性、空间复杂度对比记忆，并练习通过小规模反例验证稳定性。

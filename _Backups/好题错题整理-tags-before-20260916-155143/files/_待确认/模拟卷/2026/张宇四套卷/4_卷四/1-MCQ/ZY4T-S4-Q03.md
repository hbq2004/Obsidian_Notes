# 选择题 第 3 题

![[_Attachments/题目识别/ZY4T/ZY4T-S4-Q03_题目.png|题目]]

已知 $y_1 = x e^x + e^{2x}$ 和 $y_2 = x e^x + e^{-x}$ 是二阶常系数非齐次线性微分方程的两个解，则此方程为
(A) $y'' - y' + 2y = e^x + 2x e^x$.
(B) $y'' - y' - 2y = e^x - 2x e^x$.
(C) $y'' - y' + 2y = e^{2x} - e^{-x}$.
(D) $y'' - y' - 2y = x e^x + e^{2x}$.

![[_Attachments/题目识别/ZY4T-答案/ZY4T-S4-Q03_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**
选择题【答案】: (B)

**解题切入点**
本题考查二阶常系数非齐次线性微分方程解的结构。已知两个特解，其差为齐次解，从而确定齐次方程特征根，再代入特解求非齐次项。类似算法竞赛中，已知两个解求递推式，利用差分消去非齐次项。

**推演**
1. 设微分方程为 $y'' + p y' + q y = f(x)$，其中 $p,q$ 为常数。
   $y_1 = x e^x + e^{2x}$，$y_2 = x e^x + e^{-x}$ 均为特解，则 $y_1 - y_2 = e^{2x} - e^{-x}$ 满足齐次方程 $y'' + p y' + q y = 0$。
2. 齐次解 $z = e^{2x} - e^{-x}$ 应被特征根 $r=2$ 和 $r=-1$ 线性表示，故特征方程为 $(r-2)(r+1)=0$，即 $r^2 - r -2 = 0$，所以齐次方程应为 $y'' - y' - 2y = 0$，因此 $p = -1, q = -2$。
   据此排除选项 (A) 和 (C)，因为它们的齐次部分为 $y'' - y' + 2y = 0$，特征根为复数。
3. 剩余 (B) 和 (D) 的齐次部分均为 $y'' - y' - 2y = 0$。
   计算非齐次项 $f(x)$。
   取特解 $y = x e^x$（因为 $y_1$ 减去齐次解 $e^{2x}$ 即得 $x e^x$，同理 $y_2$ 减去 $e^{-x}$ 也得 $x e^x$，故 $x e^x$ 也是特解）。
   代入 $y'' - y' - 2y$：
   $y = x e^x$，$y' = (1+x)e^x$，$y'' = (2+x)e^x$，
   $y'' - y' - 2y = (2+x)e^x - (1+x)e^x - 2x e^x = (1-2x)e^x = e^x - 2x e^x$。
   因此 $f(x) = e^x - 2x e^x$，对应选项 (B)。
4. 验证选项 (D)：$f(x) = x e^x + e^{2x}$，代入 $y_1$ 左端已得 $e^x - 2x e^x$，不相等，故 (D) 错误。

综上，正确选项为 (B)。

**易错点**
- 误以为 $y_1$ 和 $y_2$ 的差 $e^{2x} - e^{-x}$ 就是齐次通解，但可能遗漏齐次解还包含 $x e^x$ 部分？实际上 $x e^x$ 不是齐次解，齐次解只有 $e^{2x}$ 和 $e^{-x}$。这里 $x e^x$ 是非齐次特解。
- 特征根确定后，方程中 $y'$ 的系数符号易错。注意 $y'' - y' - 2y = 0$ 对应特征根 $2$ 和 $-1$，不要写成 $y'' + y' - 2y$。
- 代入选项验证时，可直接代入 $y_1$ 或 $y_2$ 到各选项，检查等式是否成立，但需注意非齐次项形式。

**命题规律**
- 利用解的结构反推微分方程是常见题型，常结合特征根、特解形式考查。
- 复习时应熟练掌握二阶常系数线性微分方程解的结构，齐次通解与非齐次特解的关系，以及通过代入法确定非齐次项。
- 类似题目可先求齐次方程再求非齐次项，或直接代入验证排除。

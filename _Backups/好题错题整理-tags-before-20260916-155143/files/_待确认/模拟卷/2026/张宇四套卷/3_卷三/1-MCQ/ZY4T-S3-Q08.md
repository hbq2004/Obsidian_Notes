# 选择题 第 8 题

![[_Attachments/题目识别/ZY4T/ZY4T-S3-Q08_题目.png|题目]]

设随机变量 $X$ 的概率密度为

$$
f(x)=\frac{1}{2}e^{-|x|}, x \in (-\infty, +\infty),
$$

则

(A) $X$ 与 $|X|$ 不相关，$X$ 与 $|X|$ 不相互独立.
(B) $X$ 与 $|X|$ 不相关，$X$ 与 $|X|$ 相互独立.
(C) $X$ 与 $|X|$ 相关，$X$ 与 $|X|$ 不相互独立.
(D) $X$ 与 $|X|$ 相关，$X$ 与 $|X|$ 相互独立.

![[_Attachments/题目识别/ZY4T-答案/ZY4T-S3-Q08_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**

【答案】：(A)。

【推演】：

- **相关性判断**：
  计算协方差 $\operatorname{Cov}(X, |X|) = E[X|X|] - E[X]E[|X|]$。
  由于 $f(x)$ 是偶函数，$E[X]=0$；而 $x|x|$ 是奇函数，故 $E[X|X|] = \int_{-\infty}^{\infty} x|x| \cdot \frac12 e^{-|x|} dx = 0$。
  因此协方差为0，$X$ 与 $|X|$ 不相关。选项 (C)(D) 中“相关”错误。

- **独立性判断**：
  取 $x=-2, y=1$，则事件 $\{X \le -2, |X| \le 1\}$ 为空集，概率为0；
  而 $P(X \le -2) = \int_{-\infty}^{-2} \frac12 e^{x} dx = \frac12 e^{-2} > 0$，$P(|X| \le 1) = \int_{-1}^{1} \frac12 e^{-|x|} dx = 1 - e^{-1} > 0$，所以 $P(X\le -2)P(|X|\le 1) > 0$。
  不满足 $P(X\le x, |X|\le y)=P(X\le x)P(|X|\le y)$，故 $X$ 与 $|X|$ 不独立。

综合：(A) 正确。

**解题切入点**

本题核心是“相关”与“独立”的关系。利用对称分布计算协方差可快速判断相关性，而独立性需构造反例或直接验证分布函数，注意不相关不一定独立（反之独立必不相关）。

**推演**

详细推演过程如下：

1. **求 $E[X]$**：因为 $X$ 服从拉普拉斯分布，对称于0，故 $E[X]=0$。

2. **求 $E[X|X|]$**：
   $$
   E[X|X|] = \int_{-\infty}^{\infty} x|x| \cdot \frac12 e^{-|x|} dx = 0 \quad (\text{奇函数在对称区间积分为}0)。
   $$

3. **协方差**：$\operatorname{Cov}(X,|X|) = 0 - 0 \cdot E[|X|] = 0$，故不相关。

4. **独立性检验**：选择反例 $x=-2, y=1$：
   - $P(X\le -2, |X|\le 1) = P(X\le -2, -1\le X \le 1) = 0$；
   - $P(X\le -2) = \frac12 e^{-2} > 0$，$P(|X|\le 1) = 1-e^{-1} > 0$，故乘积 $>0$。
   - 两者不等，因此不独立。

**易错点**

- 容易误认为“独立则相关系数为0”而反推“相关系数为0则独立”——这是错误的，需通过定义或反例验证独立性。
- 计算 $E[X|X|]$ 时注意奇偶性，否则可能会错误地算成非零。
- 独立性检验需用事件概率等式，不要只看函数关系。

**命题规律**

常考“相关性与独立性”的关系，给出对称分布或特殊分布，利用协方差公式和独立性定义进行判断。复习时注意积累常见分布（如正态、均匀、拉普拉斯）的性质，并学会用反例快速排除。

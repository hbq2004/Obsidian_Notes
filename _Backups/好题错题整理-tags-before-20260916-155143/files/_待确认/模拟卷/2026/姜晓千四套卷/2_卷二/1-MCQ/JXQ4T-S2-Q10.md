# MCQ 第 10 题

![[_Attachments/题目识别/JXQ4T/JXQ4T-S2-Q10_题目.png|题目]]

设随机变量 $X$ 的概率分布为 $P\{X = n+1\} = \frac{1}{3} P\{X = n\}, n = 1, 2, \cdots$，则 $EX = ( \quad )$.
(A) $\frac{2}{3}$
(B) $\frac{3}{2}$
(C) $\frac{1}{3}$
(D) $3$

![[_Attachments/题目识别/JXQ4T-答案/JXQ4T-S2-Q10_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**

选择题【答案】：(B)。

**解题切入点**

题中给出相邻概率的递推比，本质是等比分布的分布列；算法竞赛视角就是“已知等比数列公比，先由总和为 1 求首项，再求加权和”。

**推演**

设 $p_k=P\{X=k\}$。由
$$P\{X=n+1\}=\frac13P\{X=n\},\quad n=1,2,\cdots$$
得
$$p_{n+1}=\frac13p_n,\qquad p_k=p_1\left(\frac13\right)^{k-1}\quad(k\ge1).$$

由概率归一性：
$$1=\sum_{k=1}^{\infty}p_k=p_1\sum_{k=1}^{\infty}\left(\frac13\right)^{k-1}=p_1\cdot\frac{1}{1-\frac13}=\frac32p_1,$$
故
$$p_1=\frac23.$$

于是
$$EX=\sum_{k=1}^{\infty}kp_k=p_1\sum_{k=1}^{\infty}k\left(\frac13\right)^{k-1}.$$
令 $q=\frac13$，利用
$$\sum_{k=1}^{\infty}kq^{k-1}=\frac{1}{(1-q)^2},$$
得
$$EX=\frac23\cdot\frac{1}{(1-\frac13)^2}=\frac23\cdot\frac94=\frac32.$$

逐一分析选项：

- (A) $\frac23$：这是 $p_1=P\{X=1\}$，不是 $EX$，排除。
- (B) $\frac32$：与上面计算结果一致，正确。
- (C) $\frac13$：只是递推公比，不是 $EX$，排除。
- (D) $3$：这是 $EX^2$ 的干扰值。事实上 $E[X(X-1)]=\frac32$，$EX^2=E[X(X-1)]+EX=3$，但不是 $EX$，排除。

关键给分点：正确写出 $p_k=p_1(1/3)^{k-1}$，由 $\sum p_k=1$ 求 $p_1=2/3$，并用 $\sum kq^{k-1}=1/(1-q)^2$ 求期望。

**易错点**

1. 必须先由 $\sum p_k=1$ 求 $p_1$，不能直接把 $p_1$ 当作概率和或期望。
2. 递推是 $p_{n+1}=\frac13p_n$，所以第 $k$ 项是 $\left(\frac13\right)^{k-1}p_1$，指数不要写错。
3. 求期望时不要用 $\sum q^{k-1}$ 代替 $\sum kq^{k-1}$，前者是概率和，后者才是期望加权和。
4. 选项中的 $\frac13$ 是公比，$\frac23$ 是首项；$3$ 是 $EX^2$，不是 $EX$，均不能选。

**命题规律**

这类题以递推形式给出分布列，考归一化和期望；本质是几何分布。复习时要熟记 $\sum_{k=1}^{\infty}kx^{k-1}=\frac{1}{(1-x)^2}$（$|x|<1$）以及几何分布的期望公式。选项常把“首项”“公比”“二阶矩”“期望”混在一起设陷阱，计算要落实到 $EX$。

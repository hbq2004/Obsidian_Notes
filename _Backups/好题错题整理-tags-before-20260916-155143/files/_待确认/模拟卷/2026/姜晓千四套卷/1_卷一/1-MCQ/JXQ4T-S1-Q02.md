# MCQ 第 2 题

![[_Attachments/题目识别/JXQ4T/JXQ4T-S1-Q02_题目.png|题目]]

设 $f(x)$ 在 $[0,1]$ 上可导,满足 $f'(x)<f(x)$,且 $f(0)=1$,则 ( ).

(A) $\int_0^1 f(x)dx < 1$

(B) $\int_0^1 f(x)dx > 1$

(C) $\int_0^1 f(x)dx < e-1$

(D) $\int_0^1 f(x)dx > e-1$

![[_Attachments/题目识别/JXQ4T-答案/JXQ4T-S1-Q02_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**

选择题【答案】: (C)
【推演】逐一分析各选项对错/干扰项：
- 对于选项(A)和(B)，通过构造反例可知积分可能大于1也可能小于1，故(A)(B)均不一定成立。
- 对于选项(C)和(D)，由条件构造辅助函数$g(x)=e^{-x}f(x)$，利用导数证明$g(x)$严格递减，从而$f(x)<e^x$，积分得$\int_0^1 f(x)dx < \int_0^1 e^x dx = e-1$，故(C)正确，(D)错误。

**解题切入点**

考查知识点：导数不等式、积分不等式、构造辅助函数。
破题角度：看到条件$f'(x)<f(x)$，联想到微分方程$y'=y$，构造$e^{-x}f(x)$将其导数与条件联系起来，通过单调性得到$f(x)$与$e^x$的大小关系，进而积分比较。类比算法竞赛中，常通过构造势能函数或变换将不等式转化为单调性。

**推演**

1. 由$f(x)$在$[0,1]$可导，$f'(x)<f(x)$，考虑辅助函数$g(x)=e^{-x}f(x)$。
2. 求导：$g'(x)=e^{-x}f'(x)-e^{-x}f(x)=e^{-x}(f'(x)-f(x))<0$，所以$g(x)$在$[0,1]$上严格单调递减。
3. 因此对任意$x\in(0,1]$，有$g(x)<g(0)=e^{0}f(0)=1$，即$e^{-x}f(x)<1$，从而$f(x)<e^x$。
4. 在$[0,1]$上积分：$\int_0^1 f(x)dx < \int_0^1 e^x dx = e^x\big|_0^1 = e-1$。
5. 对于选项(A)(B)：取$f(x)=1$（满足$f'(x)=0<1=f(x)$，$f(0)=1$），则$\int_0^1 1dx=1$，但条件为严格不等式，但$f(x)=1$是允许的，此时积分等于1，但选项要求严格不等，排除(A)(B)因为不能确定；再取$f(x)=1+0.5x$（满足条件），积分$=1.25>1$，故积分可能大于1也可能小于1，故(A)(B)均不正确。
6. 综上，正确选项为(C)。

**易错点**

- 容易忽略$f(x)$可能大于1，错误认为$f(x)$递减。实际上$f'(x)<f(x)$不能保证$f'(x)$的符号，不能直接判断$f(x)$单调性。
- 构造辅助函数时，需注意$e^{-x}$的因子，常见错误是直接构造$e^{-x}f(x)$但忘记求导符号。
- 积分比较时，注意是严格不等式，因为$g(x)$严格递减，所以$f(x)<e^x$严格，积分严格小于。

**命题规律**

- 这类题常考：给定导数不等式，通过构造$e^{kx}$或$e^{-kx}$的辅助函数，利用单调性得到函数不等关系，再积分或比较函数值。
- 复习建议：熟练掌握构造$e^{\int p(x)dx}$这种积分因子，处理形如$f'(x)+p(x)f(x)>0$或$<0$的不等式。
- 类似题目可推广到$f'(x)<kf(x)$，构造$e^{-kx}f(x)$。

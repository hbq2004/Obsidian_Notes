# MCQ 第 1 题

![[_Attachments/题目识别/ZYT8T/ZYT8T-S5-Q01_题目.png|题目]]

设 $f\left(\frac{1}{x}\right) = x + \sqrt{1+x^2} (x \neq 0)$，则 $x=0$ 是 $f(x)$ 的.
(A) 连续点.
(B) 跳跃间断点.
(C) 可去间断点.
(D) 第二类间断点.

![[_Attachments/题目识别/ZYT8T-答案/ZYT8T-S5-Q01_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**
正确答案是 (D) 第二类间断点。

**解题切入点**
考查函数表达式求解与间断点分类。通过换元法求出 $f(x)$ 的表达式，注意绝对值处理；然后分别计算 $x\to 0$ 时的左右极限，根据极限情况判断间断点类型。

**推演**
1. 令 $t = \frac{1}{x}$，则 $x = \frac{1}{t}$，代入得 $f(t) = \frac{1}{t} + \sqrt{1+\frac{1}{t^2}} = \frac{1}{t} + \sqrt{\frac{t^2+1}{t^2}} = \frac{1}{t} + \frac{\sqrt{t^2+1}}{|t|}$。所以 $f(x) = \frac{1}{x} + \frac{\sqrt{1+x^2}}{|x|}\ (x\neq 0)$。

2. 考虑 $x\to 0$ 时的情况：
   - 当 $x\to 0^+$，$|x|=x$，故 $f(x)=\frac{1}{x} + \frac{\sqrt{1+x^2}}{x} = \frac{1+\sqrt{1+x^2}}{x}$。由于 $\sqrt{1+x^2}\to 1$，分子 $\to 2$，分母 $\to 0^+$，故 $f(x)\to +\infty$。
   - 当 $x\to 0^-$，$|x|=-x$，故 $f(x)=\frac{1}{x} + \frac{\sqrt{1+x^2}}{-x} = \frac{1-\sqrt{1+x^2}}{x}$。利用等价无穷小：$1-\sqrt{1+x^2} \sim -\frac{x^2}{2}$，所以 $f(x) \sim -\frac{x}{2} \to 0$。

3. 因此，左极限为 $0$，右极限为 $+\infty$，两者不相等且右极限不存在（无穷大），故 $x=0$ 是第二类间断点（无穷间断点）。

4. 选项分析：
   - (A) 连续点：错，因为 $f(0)$ 无定义且极限不存在。
   - (B) 跳跃间断点：错，因为左右极限至少有一个为无穷，不是有限跳跃。
   - (C) 可去间断点：错，因为左右极限不相等且右极限无穷。
   - (D) 第二类间断点：正确。

**易错点**
容易忽略绝对值处理，直接写成 $f(x)=\frac{1}{x}+\frac{\sqrt{1+x^2}}{x}$，导致在 $x<0$ 时符号错误，从而误判为跳跃间断点或可去间断点。注意换元后开方要加绝对值。

**命题规律**
这类题常考通过变量代换求函数表达式，并结合分段函数讨论间断点；复习时注意函数定义域和绝对值处理，以及左右极限的计算。

# FRQ 第 22 题

![[_Attachments/题目识别/ZYT8T/ZYT8T-S7-Q22_题目.png|题目]]

设某商品每天的供应量 $X$ 的概率密度为 $f(x)=\begin{cases} x e^{-x}, & x \geq 0, \\ 0, & x < 0. \end{cases}$ 若每天的供应量相互独立，求

(1) 3 天总供应量的概率密度;

(2) 连续 3 天中最大供应量的概率密度.

![[_Attachments/题目识别/ZYT8T-答案/ZYT8T-S7-Q22_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**
(1) 设三天总供应量 $S_3=X_1+X_2+X_3$，概率密度为：当 $z≥0$ 时，$f_{S_3}(z)=z^5 e^{-z}/120$；当 $z<0$ 时，$f_{S_3}(z)=0$。

(2) 设最大供应量 $M=max(X_1,X_2,X_3)$，概率密度为：当 $x≥0$ 时，$f_M(x)=3x e^{-x}[1-(x+1)e^{-x}]^2$；当 $x<0$ 时，$f_M(x)=0$。

关键给分点：识别 $X$ 为 Gamma(2,1)；用卷积或 Gamma 可加性求三天总和；先求 $F_X(x)$ 再用 $F_M=F_X^3$ 并求导；分段范围不能丢。

**解题切入点**
考查独立随机变量之和与最大值的分布。求和对应卷积（生成函数/Gamma 可加性），最大值对应 CDF 的幂；类似算法中“独立分支分别处理后再合并”。

**推演**
1. 单日分布：$f_X(x)=x e^{-x}$，$x≥0$，即 $X$ 服从 Gamma(2,1)（形状参数2，速率参数1）。
2. 三天总供应量：先算两天 $Y=X_1+X_2$。由卷积，
$f_Y(y)=∫_0^y t e^{-t}(y-t)e^{-(y-t)}dt=e^{-y}∫_0^y t(y-t)dt=y^3 e^{-y}/6$。
再加第三天 $S_3=Y+X_3$：
$f_{S_3}(s)=∫_0^s [u^3 e^{-u}/6](s-u)e^{-(s-u)}du=e^{-s}/6∫_0^s u^3(s-u)du=s^5 e^{-s}/120$。
因此 (1) 得证。归一化自检：$∫_0^∞ s^5 e^{-s}/120 ds=Γ(6)/120=1$。
3. 最大值：先求单日 CDF：
$F_X(x)=P(X≤x)=∫_0^x t e^{-t}dt=1-(x+1)e^{-x}$，$x≥0$。
连续三天最大值 $M=max(X_1,X_2,X_3)$ 满足
$F_M(x)=P(X_1≤x,X_2≤x,X_3≤x)=F_X(x)^3$。
求导得
$f_M(x)=3F_X(x)^2 f_X(x)=3x e^{-x}[1-(x+1)e^{-x}]^2$，$x≥0$；$x<0$ 时为 0。
等价展开为 $3x e^{-x}-6x(x+1)e^{-2x}+3x(x+1)^2e^{-3x}$。

**易错点**
1. 最大值不是把密度三次方；必须先求 CDF 再求导，链式法则会产生因子 3。
2. 求 $F_X$ 时勿漏 $-(x+1)e^{-x}$；用分部积分核对。
3. 卷积计算中常数和积分限易错；可借助 Gamma(6) 的 $Γ(6)=120$ 检查。
4. 分段 $x<0$ 或 $z<0$ 密度为 0 不能省略。

**命题规律**
这类题常把常见分布的可加性与顺序统计量结合，考查卷积和分布函数法。备考时熟记指数/Gamma 可加性、最大值最小值公式；遇到和用卷积或矩母函数，遇到最值用 CDF 取幂。

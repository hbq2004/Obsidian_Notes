# FRQ 第 18 题

![[_Attachments/题目识别/ZYT8T/ZYT8T-S7-Q18_题目.png|题目]]

设 $u = u(x,y)$ 具有二阶连续偏导数,且满足 $\frac{\partial^2 u}{\partial x \partial y} = x^2 y, u(x,0) = -x^2 + 2, u(1,y) = \cos y$ .求

(1) $u = u(x,y)$ 的表达式;

(2) $u(x,y) - \cos y$ 的极值.

![[_Attachments/题目识别/ZYT8T-答案/ZYT8T-S7-Q18_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**
(1) $u(x,y)=\frac{1}{6}x^3y^2-x^2+\cos y-\frac{1}{6}y^2+1$。
(2) $u(x,y)-\cos y$ 的极大值为 $1$，在点 $(0,0)$ 处取得（无极小值）。
关键给分点：积分求原函数并利用边界条件得4分，求驻点得2分，极值判别得2分，结论得2分。

**解题切入点**
本题是已知混合偏导数和边界条件求原函数，类比算法竞赛中的“积分回代”题型，利用逐步积分并利用边界条件确定待定函数。第二问是典型的无条件极值问题，求驻点后用AC-B²判别。

**推演**
(1) 由 $\frac{\partial^2 u}{\partial x \partial y}=x^2y$，先对$x$积分得 $\frac{\partial u}{\partial y}=\int x^2ydx=\frac{1}{3}x^3y+\varphi(y)$，再对$y$积分得 $u=\int\left(\frac{1}{3}x^3y+\varphi(y)\right)dy=\frac{1}{6}x^3y^2+\Phi(y)+\psi(x)$，其中$\Phi(y)=\int\varphi(y)dy$，$\psi(x)$为任意函数。
代入边界条件 $u(x,0)=-x^2+2$ 得 $\psi(x)+\Phi(0)=-x^2+2$，即 $\psi(x)=-x^2+2-\Phi(0)$。
代入 $u(1,y)=\cos y$ 得 $\frac{1}{6}y^2+\Phi(y)+\psi(1)=\cos y$，即 $\Phi(y)=\cos y-\frac{1}{6}y^2-\psi(1)$。
将 $\psi(1)= -1+2-\Phi(0)=1-\Phi(0)$ 代入得 $\Phi(y)=\cos y-\frac{1}{6}y^2-1+\Phi(0)$。
于是 $u(x,y)=\frac{1}{6}x^3y^2+\psi(x)+\Phi(y)=\frac{1}{6}x^3y^2+(-x^2+2-\Phi(0))+\left(\cos y-\frac{1}{6}y^2-1+\Phi(0)\right)=\frac{1}{6}x^3y^2-x^2+\cos y-\frac{1}{6}y^2+1$。
(2) 令 $v(x,y)=u(x,y)-\cos y=\frac{1}{6}x^3y^2-x^2-\frac{1}{6}y^2+1$。
求偏导：
$v_x=\frac{1}{2}x^2y^2-2x = x\left(\frac{xy^2}{2}-2\right)=0$，
$v_y=\frac{1}{3}x^3y-\frac{1}{3}y = \frac{1}{3}y(x^3-1)=0$。
解得驻点 $(0,0)$，$(1,2)$，$(1,-2)$。
二阶偏导：
$v_{xx}=xy^2-2$，$v_{yy}=\frac{1}{3}(x^3-1)$，$v_{xy}=x^2y$。
在$(0,0)$：$A=-2$，$B=0$，$C=-\frac{1}{3}$，$AC-B^2=\frac{2}{3}>0$且$A<0$，故为极大值点，极大值$v(0,0)=1$。
在$(1,2)$和$(1,-2)$：$A=2$，$C=0$，$B=\pm2$，$AC-B^2=-4<0$，为鞍点，无极值。
因此 $u(x,y)-\cos y$ 的极大值为 $1$，在 $(0,0)$ 处取得。

**易错点**
- 积分时容易遗漏任意函数，导致无法正确利用边界条件。
- 边界条件代入顺序要清晰，可先利用$u(x,0)$确定$\psi(x)$与$\Phi(0)$的关系，再利用$u(1,y)$消去$\Phi(0)$。
- 多元函数极值判别时注意$AC-B^2$的正负以及$A$的符号，防止误判。

**命题规律**
本题将偏微分方程积分求解与多元函数极值结合，是考研数学一常见的“一题多知识点”综合题。复习时应熟练掌握混合偏导数求原函数的方法（通过积分并代边界条件），以及无条件极值的判别步骤。注意训练计算准确性。

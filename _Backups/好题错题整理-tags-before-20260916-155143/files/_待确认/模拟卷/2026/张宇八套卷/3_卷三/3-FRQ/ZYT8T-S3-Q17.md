# FRQ 第 17 题

![[_Attachments/题目识别/ZYT8T/ZYT8T-S3-Q17_题目.png|题目]]

求曲线 $y = x^{3}\left(\mathrm{e}^{\frac{1}{x}}+\mathrm{e}^{-\frac{1}{x}}-2\right)$ 的全部渐近线.

![[_Attachments/题目识别/ZYT8T-答案/ZYT8T-S3-Q17_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**
曲线 $y=x^3(e^{1/x}+e^{-1/x}-2)$ 的全部渐近线为：垂直渐近线 $x=0$，斜渐近线 $y=x$。

关键给分点：①正确求出斜渐近线斜率 $a=1$；②截距 $b=0$；③指出 $x=0$ 为垂直渐近线（需说明两侧极限为无穷）。

**解题切入点**
本题考察渐近线的定义与求法。本质是分析与求极限，类似算法竞赛中“扫描线”往往需考虑端点行为：对 $x\to\infty$ 和 $x\to 0$ 分别作泰勒展开或等价替换，即可确定渐近线类型。

**推演**
1. 确定定义域：$x\neq 0$。
2. 垂直渐近线：仅可能 $x=0$。
令 $t=\frac1x$，则 $x\to0^+ \iff t\to+\infty$，
$$y = \frac{e^t+e^{-t}-2}{t^3} \sim \frac{e^t}{t^3} \to +\infty;$$
$x\to0^- \iff t\to-\infty$，
$$y \sim \frac{e^{-t}}{t^3} \to -\infty.$$
故 $x=0$ 为垂直渐近线。
3. 斜渐近线：设 $y=ax+b$，
斜率 $a=\lim\limits_{x\to\infty}\frac{y}{x} = \lim\limits_{x\to\infty} x^2(e^{1/x}+e^{-1/x}-2)$。
令 $t=\frac1x\to0$，则
$$a=\lim_{t\to0}\frac{e^t+e^{-t}-2}{t^2}=1$$（泰勒展开：$e^t+e^{-t}-2=t^2+\frac{t^4}{12}+O(t^6)$）。
截距 $b=\lim\limits_{x\to\infty}(y-x)=\lim\limits_{t\to0}\frac{e^t+e^{-t}-2-t^2}{t^3}=0$。
故斜渐近线为 $y=x$。
4. 综上，全部渐近线为 $x=0$ 与 $y=x$。

**易错点**
- 勿忘求垂直渐近线时需分别考察 $x\to0^+$ 和 $x\to0^-$，两者趋于不同方向无穷，仍为垂直渐近线。
- 斜渐近线计算 $a$ 与 $b$ 时，务必使用同一 $t$ 变换，且展开到足够阶数（如 $t^4$）保证求 $b$ 时极限为0。
- 不要误判水平渐近线：$x\to\infty$ 时 $y$ 与 $x$ 同阶，趋于无穷，不收敛。

**命题规律**
渐近线是历年数学一的高频考点，常结合泰勒展开、极限计算。复习时需掌握三类渐近线的判别方法，并熟练运用泰勒公式处理含指数、三角等复杂函数。类似题目还可变形为求参数使曲线具有指定渐近线，需理解渐近线本质是函数在无穷远处的线性逼近。

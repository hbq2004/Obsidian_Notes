# FRQ 第 17 题

![[_Attachments/题目识别/ZYT8T/ZYT8T-S2-Q17_题目.png|题目]]

求 $f(x) = \int_{0}^{1} |\ln|x-t|| \mathrm{d}t (0 \le x \le 1)$ 的最大值.

![[_Attachments/题目识别/ZYT8T-答案/ZYT8T-S2-Q17_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**
\[
\max_{0\le x\le1} f(x)=1+\ln2
\]
当且仅当 \(x=\frac{1}{2}\) 时取得。

关键给分点：
1. 因 \(0\le x,t\le1\)，故 \(|x-t|\le1\)，于是 \(\ln|x-t|\le0\)，所以
\[
f(x)=-\int_0^1\ln|x-t|\,dt.
\]
2. 用 \(\int\ln|u|\,du=u\ln|u|-u\) 算得
\[
f(x)=1-x\ln x-(1-x)\ln(1-x).
\]
3. 对 \(x\in(0,1)\) 求导得 \(f'(x)=\ln\frac{1-x}{x}\)，驻点 \(x=\frac{1}{2}\)，且为最大值点。
4. \(f\left(\frac{1}{2}\right)=1+\ln2\)，端点值 \(f(0)=f(1)=1\)，故最大值为 \(1+\ln2\)。

**解题切入点**
因积分区间 \([0,1]\) 上 \(|x-t|\le1\)，\(\ln|x-t|\le0\)，所以外层绝对值等价于添负号；积分结果是二进制熵函数 \(h(x)=-x\ln x-(1-x)\ln(1-x)\) 再加 1。算法竞赛中可看作“在区间上找一点使到各点的 \(-\log\) 距离积分最大”，最优点在对称中心 \(x=\frac{1}{2}\)。

**推演**
1. 化简被积函数。对任意 \(x,t\in[0,1]\)，有 \(|x-t|\in[0,1]\)，故 \(\ln|x-t|\le0\)，于是
\[
|\ln|x-t||=-\ln|x-t|.
\]
因此
\[
f(x)=-\int_0^1\ln|x-t|\,dt.
\]
（\(t=x\) 处为瑕点，但 \(\int_0^\varepsilon-\ln u\,du\to0\)，原积分收敛。）

2. 计算积分。令 \(u=t-x\)，则
\[
\int\ln|t-x|\,dt=\int\ln|u|\,du=u\ln|u|-u+C.
\]
所以
\[
\begin{aligned}
\int_0^1\ln|x-t|\,dt
&=\left[(t-x)\ln|t-x|-(t-x)\right]_0^1\\
&=(1-x)\ln(1-x)+x\ln x-1.
\end{aligned}
\]
于是
\[
f(x)=1-x\ln x-(1-x)\ln(1-x),\quad 0\le x\le1,
\]
其中端点处理解 \(0\ln0=0\)。

3. 求最大值。对 \(0<x<1\) 求导：
\[
f'(x)=-(\ln x+1)+\ln(1-x)+1
=\ln\frac{1-x}{x}.
\]
令 \(f'(x)=0\)，得 \(x=\frac{1}{2}\)。当 \(0<x<\frac{1}{2}\) 时 \(f'(x)>0\)，当 \(\frac{1}{2}<x<1\) 时 \(f'(x)<0\)，故 \(x=\frac{1}{2}\) 为唯一最大值点。

4. 计算最大值：
\[
f\left(\frac{1}{2}\right)=1-\frac{1}{2}\ln\frac{1}{2}-\frac{1}{2}\ln\frac{1}{2}=1+\ln2.
\]
端点：
\[
f(0)=\lim_{x\to0^+}\left(1-x\ln x-(1-x)\ln(1-x)\right)=1,
\]
同理 \(f(1)=1\)。由于 \(1+\ln2>1\)，所以
\[
\boxed{\max_{0\le x\le1}f(x)=1+\ln2}.
\]

**易错点**
- 符号易错：在 \([0,1]\) 上 \(\ln|x-t|\le0\)，绝对值打开后是 \(-\ln|x-t|\)，不是本身。
- 瑕积分误判：\(t=x\) 处被积函数无界，但是可积瑕点；使用原函数时该处极限为 0，不影响定积分。
- 端点 \(x=0,1\) 不能直接代入 \(x\ln x\)，要按极限理解 \(x\ln x\to0\)。
- 对 \((1-x)\ln(1-x)\) 求导易错符号，最好写出 \(-\ln(1-x)-1\)。

**命题规律**
含参变量积分与最值结合是考研数学一常见命题角度，尤其喜欢用 \(\ln|x-t|\) 这种带瑕点的“对数核”来考积分求导或直接积分。复习时熟记 \(\int\ln|u|du=u\ln|u|-u\)，并会处理 \(|x-t|\) 在区间内的符号；以后遇到类似 \(\int_a^b\ln|x-t|dt\)，可先算出 \(x\ln x+(1-x)\ln(1-x)\) 型表达式，再结合单调性/凹凸性求最值。

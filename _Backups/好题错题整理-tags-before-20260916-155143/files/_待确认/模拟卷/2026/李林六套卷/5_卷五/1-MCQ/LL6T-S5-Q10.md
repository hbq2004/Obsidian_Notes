# 选择题 第 10 题

![[_Attachments/题目识别/LL6T/LL6T-S5-Q10_题目.png|题目]]

设 $X_1, X_2, \cdots, X_n$ 是来自总体 $X \sim N(0,1)$ 的简单随机样本，
$$Y = \frac{1}{m} \left( \sum_{i=1}^{m} X_i \right) + \frac{1}{n-m} \left( \sum_{i=m+1}^{n} X_i \right)^2 (m < n),$$
则 $E(Y)$ 与 $D(Y)$ 分别为.
(A) $0, n.$
(B) $0, 2.$
(C) $n, 2n.$
(D) $2, 4.$

![[_Attachments/题目识别/LL6T-答案/LL6T-S5-Q10_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**

按最合理读法，题干应为
$$Y=\frac{1}{m}\left(\sum_{i=1}^{m}X_i\right)^2+\frac{1}{n-m}\left(\sum_{i=m+1}^{n}X_i\right)^2.$$

【答案】: (D) $2,4$。  
(A)(B)(C) 均为干扰项，不正确。

**解题切入点**

两个互相独立的样本块分别除以各自的“根号样本量”后都是标准正态，平方后为两个独立 $\chi^2(1)$ 变量；合并即 $\chi^2(2)$。类似算法竞赛中把独立子问题分别求解再合并，直接套用已知分布模板。

**推演**

令
$$U=\frac{1}{\sqrt m}\sum_{i=1}^{m}X_i,\qquad V=\frac{1}{\sqrt{n-m}}\sum_{i=m+1}^{n}X_i.$$

因为 $X_i\sim N(0,1)$ 且相互独立，
$$\sum_{i=1}^{m}X_i\sim N(0,m),\qquad \sum_{i=m+1}^{n}X_i\sim N(0,n-m).$$

所以
$$U\sim N(0,1),\qquad V\sim N(0,1),$$
且 $U$ 与 $V$ 独立（前者只用前 $m$ 个样本，后者只用后 $n-m$ 个样本）。

于是 $U^2\sim\chi^2(1)$，$V^2\sim\chi^2(1)$，由卡方分布可加性：
$$Y=U^2+V^2\sim\chi^2(2).$$

对 $\chi^2(k)$ 分布，有 $E=k$，$D=2k$。故
$$E(Y)=2,\qquad D(Y)=4.$$

选项分析：
- (D) $2,4$ 正确。
- (A) $0,n$：误以为第一项期望为 $0$ 且把第二项方差错算为 $n$；不合 $\chi^2(2)$ 的矩。
- (B) $0,2$：若只算 $U^2$ 或忽略第一项的方差贡献，会得到期望 $0$ 或方差 $2$；但两项都要计入。
- (C) $n,2n$：把两个独立标准正态平方和误当作 $\chi^2(n)$，自由度错成 $n$；实际自由度是 $2$。

**易错点**

1. 第一项没有平方是常见 OCR/抄写错误；原式两个括号都应当平方，才能得到选项中的结果。
2. 不要混淆 $\frac1m(\sum X_i)^2$ 与 $\frac1m\sum X_i^2$：前者是“和的平方除以 $m$”，后者是“平方和除以 $m$”。
3. 注意 $\frac1m(\sum X_i)^2$ 可写成 $(\frac1{\sqrt m}\sum X_i)^2$，不是样本均值的平方。
4. 卡方分布自由度合并：两个独立 $\chi^2(1)$ 相加得 $\chi^2(2)$，不是 $\chi^2(n)$。

**命题规律**

本题是典型“标准正态平方和”套路：将样本块通过除以各自的 $\sqrt{m}$、$\sqrt{n-m}$ 化为标准正态，再平方得到 $\chi^2(1)$，合并求期望方差。复习时需熟记正态分布线性性、$\chi^2$ 分布定义与矩，以及独立性条件；看到“和式平方 + 分母为样本量”应立刻联想到卡方分布。

题面按第一项含平方：
$$Y=\frac{1}{m}\left(\sum_{i=1}^{m}X_i\right)^2+\frac{1}{n-m}\left(\sum_{i=m+1}^{n}X_i\right)^2$$

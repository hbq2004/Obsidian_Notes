# 选择题 第 10 题

![[_Attachments/题目识别/LL6T/LL6T-S6-Q10_题目.png|题目]]

设 $X_1,X_2,\cdots,X_{2n}$ 为来自总体 $X \sim N(0,1)$ 的简单随机样本，记 $T_1 = \sum_{i=1}^{2n}\left(X_i - \frac{1}{2n}\sum_{i=1}^{2n}X_i\right)^2, T_2 = \frac{1}{2}\sum_{i=1}^{2n}X_i^2 + \sum_{i=1}^n X_{2i-1}X_{2i}$，则

A. $E(T_1) = 2n, D(T_2) = n$
B. $E(T_1) = n, D(T_2) = 2n-1$
C. $E(T_2) = n, D(T_1) = 2(2n-1)$
D. $E(T_2) = 2n, D(T_1) = 2n-1$

![[_Attachments/题目识别/LL6T-答案/LL6T-S6-Q10_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**
选择题【答案】: (C)

**解题切入点**
本题考查样本离差平方和与二次型统计量的期望方差。关键点：利用正态总体下样本方差服从卡方分布的性质，以及通过配方法将$T_2$化为独立正态变量平方和，从而快速得到期望和方差。类似算法竞赛中利用卡方分布性质直接计算统计量数字特征。

**推演**
第一步：分析$T_1$。由于$X_i\sim N(0,1)$且独立，样本均值$\bar{X}=\frac{1}{2n}\sum_{i=1}^{2n}X_i$，则离差平方和$T_1=\sum_{i=1}^{2n}(X_i-\bar{X})^2$服从自由度为$2n-1$的卡方分布，即$T_1\sim \chi^2(2n-1)$。因此$E(T_1)=2n-1$，$D(T_1)=2(2n-1)$。

第二步：分析$T_2$。将$T_2$改写：
$$
T_2 = \frac12\sum_{i=1}^{2n}X_i^2 + \sum_{i=1}^n X_{2i-1}X_{2i} = \frac12\sum_{i=1}^n\bigl(X_{2i-1}^2+X_{2i}^2+2X_{2i-1}X_{2i}\bigr) = \frac12\sum_{i=1}^n (X_{2i-1}+X_{2i})^2.
$$
令$Y_i = X_{2i-1}+X_{2i}$，则$Y_i\sim N(0,2)$且相互独立。于是$\frac12 Y_i^2 \sim \chi^2(1)$，故$T_2 = \sum_{i=1}^n \frac12 Y_i^2 \sim \chi^2(n)$。所以$E(T_2)=n$，$D(T_2)=2n$。

第三步：选项检验。
- (A) $E(T_1)=2n$ (错误,应为$2n-1$), $D(T_2)=n$ (错误,应为$2n$).
- (B) $E(T_1)=n$ (错误), $D(T_2)=2n-1$ (错误).
- (C) $E(T_2)=n$ (正确), $D(T_1)=2(2n-1)$ (正确).
- (D) $E(T_2)=2n$ (错误), $D(T_1)=2n-1$ (错误).

因此正确选项为C。

**易错点**
1. 混淆$T_1$与样本方差$S^2$的关系，$T_1=(2n-1)S^2$，$E(T_1)=(2n-1)\sigma^2$，这里$\sigma^2=1$，故$E(T_1)=2n-1$，容易误认为$2n$。
2. 计算$T_2$的期望时，忽略$X_{2i-1}X_{2i}$的期望为0，但方差计算中交叉项可能产生协方差，需注意独立性和二次型方差公式。
3. 配方法时符号错误，导致自由度判断失误。

**命题规律**
本题综合考查了正态总体下样本方差分布、卡方分布的性质以及二次型统计量的期望方差，是考研数学一概率统计中的常见题型。复习时应熟练掌握常用统计量的分布（如$\chi^2$、$t$、$F$）及其数字特征，并学会通过配方法或矩阵法简化二次型统计量。注意区分样本方差与离差平方和，牢记卡方分布的期望和方差公式。

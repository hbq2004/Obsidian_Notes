# 填空题 第 13 题

![[_Attachments/题目识别/LL6T/LL6T-S2-Q13_题目.png|题目]]

设 $f(x,y)=\int_{x^2+y^2}^{\frac{y}{x}} e^{-t^2}dt$，则 $x\frac{\partial f}{\partial x}+y\frac{\partial f}{\partial y}$ 的极小值为 \\_\\_\\_\\_\\_.

![[_Attachments/题目识别/LL6T-答案/LL6T-S2-Q13_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**

所求表达式为 $L = x f_x + y f_y = -2(x^2+y^2)e^{-(x^2+y^2)^2}$，令 $t=x^2+y^2>0$，则 $L=-2te^{-t^2}$。对 $t$ 求导得极小值点 $t=\frac{1}{\sqrt{2}}$，故极小值为 $-\frac{\sqrt{2}}{\sqrt{e}}$。

【答案】

$$-\frac{\sqrt{2}}{\sqrt{e}}$$

**解题切入点**

考查变限积分求导与多元函数极值。可类比算法竞赛中“复合函数求导后化简”：先算偏导再组合，发现欧拉组合后变量分离。

**推演**

设 $a=x^2+y^2$，$b=\frac{y}{x}$，由变限积分求导公式：
$$f_x = e^{-b^2} b_x - e^{-a^2} a_x = -\frac{y}{x^2}e^{-y^2/x^2} - 2x e^{-(x^2+y^2)^2},$$
$$f_y = e^{-b^2} b_y - e^{-a^2} a_y = \frac{1}{x}e^{-y^2/x^2} - 2y e^{-(x^2+y^2)^2}.$$
则
$$x f_x + y f_y = -\frac{y}{x}e^{-y^2/x^2} - 2x^2 e^{-(x^2+y^2)^2} + \frac{y}{x}e^{-y^2/x^2} - 2y^2 e^{-(x^2+y^2)^2} = -2(x^2+y^2)e^{-(x^2+y^2)^2}.$$
令 $t=x^2+y^2>0$，则 $L=-2te^{-t^2}$。求导：
$$\frac{dL}{dt}= -2 e^{-t^2} + 4t^2 e^{-t^2} = 2e^{-t^2}(2t^2-1).$$
令为零，得 $t^2=\frac12$，又 $t>0$，故 $t=\frac{1}{\sqrt2}$。且 $t<1/\sqrt2$ 时 $L'<0$，$t>1/\sqrt2$ 时 $L'>0$，所以该点为极小值点。极小值为
$$L\left(\frac{1}{\sqrt2}\right) = -2\cdot \frac{1}{\sqrt2} e^{-1/2} = -\sqrt2 e^{-1/2} = -\frac{\sqrt2}{\sqrt e}.$$

**易错点**

1. 忘记对上下限同时求导，漏项。  
2. 计算 $x f_x + y f_y$ 时未合并同类项，导致复杂化。  
3. 误认为极小值在 $t=0$ 取到，注意 $x\neq0$，但 $t$ 可趋近0，极限为0，但极小值负值。  
4. 忽略 $x\neq0$ 导致的定义域限制，但最终极值点可达到。

**命题规律**

常见套路：将变限积分与偏导结合，通过构造 $x f_x + y f_y$ 消去复杂项，化为单变量问题。复习时注意总结“欧拉组合”型题，熟练链式法则。

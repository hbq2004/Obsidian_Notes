# 选择题 第 2 题

![[_Attachments/题目识别/LL6T/LL6T-S1-Q02_题目.png|题目]]

下列函数在 $x=0$ 处不可导的是.
(A) $|x|\int_0^x \sin t^2 dt.$
(B) $|\sin(x-\sin x)|.$
(C) $\int_{-1}^x \sqrt{|t|} \ln|t| dt.$
(D) $\sqrt{e^{|x|}}.$

![[_Attachments/题目识别/LL6T-答案/LL6T-S1-Q02_答案.png|答案]]


## DeepSeek V4 Flash Max 解析

**答案**
选择题【答案】：(D)。
四个选项中，只有 (D) 在 $x=0$ 处的左右导数不相等；其余三个在 $x=0$ 处均可导，且导数为 $0$。

**解题切入点**
判断 $x=0$ 处可导性，本质是看 $f(x)$ 在 $0$ 处能否写成 $f(0)+a x+o(x)$。若展开式中出现 $|x|$ 的一次项，则左右斜率相反，不可导；若函数是 $o(x)$ 甚至更高阶小量，则导数为 $0$。类似算法竞赛中检查“一阶近似”是否唯一。

**推演**
(A) 设 $F(x)=\int_0^x \sin t^2\,dt$。由 $\sin t^2\sim t^2$（$t\to0$），得
$$F(x)\sim \frac{x^3}{3},\quad x\to0.$$
因此
$$f_A(x)=|x|F(x)\sim \frac{x^3|x|}{3}=O(x^4).$$
于是
$$\frac{f_A(x)-f_A(0)}{x}=\frac{f_A(x)}{x}=O(|x|^3)\to0,$$
所以 $f_A'(0)=0$，可导。

(B) 当 $x\to0$ 时，
$$x-\sin x=\frac{x^3}{6}+o(x^3),$$
且 $\sin(x-\sin x)\sim x-\sin x$。于是
$$f_B(x)=|\sin(x-\sin x)|\sim \frac{|x|^3}{6}.$$
所以
$$\frac{f_B(x)-f_B(0)}{x}=\frac{f_B(x)}{x}\sim \frac{|x|^3}{6x}\to0,$$
故 $f_B'(0)=0$，可导。这里绝对值里面的量是 $3$ 阶无穷小，不是一阶，绝对值不会产生尖点。

(C) 令 $\varphi(t)=\sqrt{|t|}\ln|t|$（$t\neq0$），并补充定义 $\varphi(0)=0$。因为 $\sqrt{|t|}\ln|t|\to0$（$t\to0$），$\varphi(t)$ 在 $0$ 处连续。于是
$$f_C(x)=\int_{-1}^x \varphi(t)\,dt$$
是 $\varphi(t)$ 的变上限积分。由微积分基本定理，
$$f_C'(0)=\varphi(0)=0,$$
可导。回代自检：用定义同样有 $\frac1h\int_0^h\varphi(t)dt\to\varphi(0)=0$。

(D) $$f_D(x)=\sqrt{e^{|x|}}=e^{|x|/2}.$$
当 $x\to0$ 时，
$$e^{|x|/2}=1+\frac{|x|}{2}+o(|x|).$$
右导数：
$$\lim_{x\to0^+}\frac{f_D(x)-1}{x}=\lim_{x\to0^+}\frac{x/2+o(x)}{x}=\frac12.$$
左导数：
$$\lim_{x\to0^-}\frac{f_D(x)-1}{x}=\lim_{x\to0^-}\frac{-x/2+o(x)}{x}=-\frac12.$$
左右导数不相等，所以 (D) 在 $x=0$ 处不可导。

**易错点**
1. 不要把 (B) 中的绝对值直接判为不可导。$|u|$ 在 $u=0$ 处不可导，但此时 $u=\sin(x-\sin x)\sim x^3/6$，复合后是 $O(|x|^3)$，一阶导数存在且为 $0$。
2. (A) 中 $\int_0^x\sin t^2\,dt$ 是 $x^3$ 阶，不是 $x$ 阶；再乘 $|x|$ 后为 $x^4$ 阶，用导数定义极限为 $0$。
3. (C) 中被积函数在 $0$ 处极限为 $0$，补充定义后连续，可直接用变上限积分求导；不要误以为 $\ln|t|\to-\infty$ 一定不可积。
4. (D) 的“尖点”来自 $|x|$ 位于指数 $e^{|x|/2}$ 中，一次项系数为 $1/2$，左右导数符号相反。用链式法则会遇到 $|x|'$ 不存在，应改用左右导数或展开式判断。

**命题规律**
本题是典型的概念题，将导数定义、等价无穷小、变上限积分、绝对值函数综合在一起。命题人常把“不可导点”藏在 $|x|$ 或 $|u(x)|$ 中，并利用高阶无穷小制造干扰。复习时应熟练展开 $\sin x$、$x-\sin x$、$e^u$、$\int_0^x t^2\,dt$ 等基本量，并坚持用 $\lim\frac{f(x)-f(0)}{x}$ 判断可导性。
